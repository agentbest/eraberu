# アイキャッチのバリエーション追加（2026年11月27日）

ユーザーの「同じ画像ばかりではなく微妙に変えて」という依頼に対応。既存の21画像を参照し、組み込みimage_genの編集で各テーマの別構図を1点ずつ生成。色・材質・主題を保ちつつ視点、小物、配置を変えた。元画像は維持し、別名の21画像を追加、計42点とした。

2構図と3種類の見出し配置（中央・上寄せ・下寄せ、ラベルの色・余白・表示サイズの違い）の126組み合わせを、全2,000記事へ固定で割り当てた。42点のイラストを共有しており、2,000点を個別に生成したという意味ではない。

`cover-directions.json` に画像IDと文字配置を保存。本文、一覧、検索、OG・Twitter画像を記事ごとに一致させ、ページを見るたびに変わるランダム表示にはしていない。新記事の追加で既存記事の画像がずれない。未登録の新記事にはslugに基づく安定した選択を使う。

ハブ一覧は実際の並び順（target→日本語タイトル）を使って交互に割り当てた。21ハブの1,979の隣接箇所で、同じ画像が続く箇所は0件。トップで並ぶ「費用相場」と「見積もり」も別画像になっている。タグ・検索など異なる並べ方では同じ画像が隣り合うことはあり得る。

全2,000記事で画像・見出し配置・OG・構造化データ・検索画像の一致を検査。42画像と126組み合わせが使われていることを確認。ブラウザーで全42画像の読み込み、追加画像の構図、スマートフォンの一覧と横はみ出しがないことを確認した。本文・記事の情報基準日・全記事の承認済みASP広告は維持。

公開用素材は `assets/media-covers/`、最終プロンプトと参照元は `cover-assets.json`。追加した原画は作業ワークスペースの `outputs/eraberu-cover-originals/*-v2.png` に保存。
