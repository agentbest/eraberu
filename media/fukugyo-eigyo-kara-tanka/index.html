営業の経験を生かして人事の副業を始める人は、人事の経験は浅くても、相手の関心を引き出して口説く力や、数字で進み具合を追う習慣を持っています。採用は、会社を候補者に売り込み、選考という商談を進める仕事でもあります。営業の力は、スカウトの返信を増やしたり、選考の途中で候補者が離れるのを防いだりする場面で生きます。結論から書くと、営業からの転身の副業単価は、口説く力と数字で追う習慣を、スカウトの運用や選考の改善の成果物にして値付けし、人事の経験が浅い部分は範囲を絞って受けると、無理のない金額になります。

人事の副業の単価には公的な統計がなく、案件の範囲や依頼先で大きく変わるため、この記事では金額の相場は書きません。自分の単価を組み立てる手順と、案件の見つけ方を書きます。営業からの転身で何が売れるかは営業からの転身で人事の副業をするで詳しく書いています。

値付けにつながる作業

営業の経験は、次のような採用の作業に置き換えると、値付けしやすくなります。

営業としての経験採用の副業で切り出せる作業時間が増える条件
相手の関心を引き出し、口説いてきたスカウトの文面の作成と、返信を見た見直し職種が多い
見込み客を絞り込んできたスカウトの対象の条件の設計対象が広い、条件があいまい
商談の進み具合を数字で追ってきた応募から内定までの数字の見方と、止まっている段階の改善記録がばらばら
失注の理由を振り返ってきた選考の途中の辞退の理由の聞き取りと、改善の提案辞退が多い

作業ごとに時間を見積もり、自分の時間単価を掛けます。時間単価の考え方は本業の年収と副業単価の関係で書いています。スカウトの運用の単価の考え方はスカウト代行の副業単価でも書いています。

人事の経験が浅い部分は範囲を絞る

営業からの転身では、人事の経験が浅いことを正直に扱うことが大切です。最初は、営業の力がそのまま生きる作業に範囲を絞って受けてください。

  1. 営業の力が生きる作業を選ぶ：スカウトの文面と運用、選考の数字の見方、辞退の理由の聞き取りなど
  2. 経験の浅い作業は受けないか、学びながら受ける：労働条件の決め方や評価の制度など、人事の専門の知識が要る作業は、最初は受けない
  3. 成果物ごとに時間を見積もる：慣れない作業ほど時間がかかるため、少し多めに見積もる
  4. 経験を積んだら範囲を広げる：案件を重ねて人事の知識がついたら、受ける範囲を広げる

経験の浅い作業を安い単価で受けて経験を積む、という考え方もありますが、依頼先にとっては質の低い成果物を受け取ることになりかねません。得意な作業で成果を出し、信頼を得てから範囲を広げるほうが、長い目で見て単価を上げやすくなります。

エラベルの見解

営業からの転身でよくある失敗は、候補者を「売り込む相手」として扱いすぎることです。営業の口説く力は強みですが、候補者に会社の良い面だけを伝えて入社させると、入社後のずれから早く辞めることにつながります。営業では受注がゴールでも、採用では入社後に活躍して続くことがゴールです。

担当する側から見ると、価値があるのは、口説く力を、候補者の不安を聞き出し、会社の実態を正直に伝えることに使えることです。返信率を上げる文面と、入社後のずれを防ぐ伝え方を両立できる人は、依頼先から頼られます。

求人の表示と委託募集の決まり

採用の作業を受けるときは、募集に関わる決まりを守る必要があります。職業安定法第5条の4は、労働者の募集を行う者や募集受託者などが広告などで募集に関する情報を提供するときに、虚偽の表示や誤解を生じさせる表示をしてはならないと定めています。スカウトの文面や求人で、条件を実際よりよく見せる表現は避けてください。

職業安定法第36条は、労働者を雇用しようとする者が、その被用者以外の者に報酬を与えて労働者の募集に従事させようとするときは、厚生労働大臣の許可を受けなければならないと定めています。これは雇う側の依頼先に求められる手続きですが、副業で報酬を受けてスカウトなどの募集の作業をする形がこれにあたるかどうかは、作業の中身によって判断が分かれます。依頼先と作業の範囲を確かめ、必要であれば依頼先から労働局に確認してもらってください。個別の判断は弁護士にご確認ください。

案件の見つけ方と、受けるときの条件

営業の経験を活かせる採用の案件は、次のような場所で見つけやすくなります。

  • スカウトの返信が少ない会社：スカウトの媒体を契約したが、文面や対象の絞り込みがうまくいっていない会社
  • 営業職の採用に困っている会社：営業の仕事を知る人に、営業職の採用を手伝ってほしい会社
  • 人事の副業の仲介サービス：営業の経験と、スカウトや数字の改善が得意なことを登録しておく

業務委託で受ける場合は、特定受託事業者に係る取引の適正化等に関する法律（フリーランス法）第3条が、業務委託事業者に、給付の内容、報酬の額、支払期日などを書面または電磁的方法で直ちに明示することを求めています。

本業に勤めながら副業をする場合は、厚生労働省の「副業・兼業の促進に関するガイドライン」が示すとおり、まず勤め先の副業・兼業に関するルールを確認し、秘密保持義務や競業避止義務を意識してください。本業の顧客の採用を手伝う場合は、本業との関係にとくに注意してください。20万円を超える副収入がある場合は、確定申告が必要です。個別の判断は弁護士・税理士にご確認ください。

エラベルの見解

もう一つ見てほしいのは、営業からの転身は、営業職の採用で強みが最も生きるということです。営業職の採用では、求人を書く人や面接する人が営業の仕事の実態を知らないと、候補者に響く伝え方ができず、見極めもずれます。営業の経験者なら、どんな人が営業で成果を出すかを、実感をもって判断できます。

最初の案件は、営業職の採用の手伝いから始めると、経験がそのまま成果につながりやすくなります。営業職の採用で成果を出した実績は、ほかの職種の採用の案件を受けるときの信頼にもなります。

よくある質問

営業からの転身の副業単価の相場はいくらですか

案件の範囲や依頼先によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。作業ごとに時間を見積もり、自分の時間単価を掛けて単価の根拠をつくってください。

人事の経験がなくても採用の副業はできますか

スカウトの運用や選考の数字の改善など、営業の力が生きる作業なら受けられます。労働条件の決め方や評価の制度など、人事の専門の知識が要る作業は、経験を積んでから受けるほうが無理がありません。

営業の成果報酬のように、採用の成果で報酬を受けてもよいですか

成果報酬の形で受けることもできますが、採用できるかどうかは依頼先の条件や選考の進め方にも左右されます。作業の時間に見合う報酬になるか、成果の定義を契約で決めてから受けてください。
