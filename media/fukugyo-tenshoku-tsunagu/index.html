人事副業 / 両立・スキル

副業から転職につながるか｜人事の副業が転職につながるのは「依頼側からの誘い」「実績を職務経歴書に書ける」「自分の向き不向きが分かる」の三つの形。ただし、副業を転職の手段にすると案件が続かず、本業との線も崩れる。転職は副業の目的ではなく、結果として起きることとして扱う

副業を始めるとき、「これが転職につながるかもしれない」と考える人は多い。依頼側から誘われる、実績が職務経歴書に書ける、自分に合う会社が分かる。実際に、副業は転職につながるのか。結論を先に書くと、人事の副業が転職につながる形は三つあり、「依頼側から誘われる」「副業の実績を職務経歴書に書ける」「自分の向き不向きが分かる」です。三つとも実際に起きます。ただし、副業を転職の手段として始めると、案件が続かず、本業との線も崩れます。依頼側は、転職先を探している人ではなく、範囲の仕事を丁寧にする人を求めていて、転職の意図が見えると、案件の関係が変わります。転職は、副業の目的ではなく、副業を丁寧に続けた結果として起きることとして扱う。この扱い方が、転職につながる可能性を最も高くします。退職後の副業は退職後に副業から始めるに、職務経歴書の書き方は副業用の職務経歴書に、本業との線は本業と利益相反になる案件にまとめています。

転職につながる三つの形

副業が転職につながる形は、三つに分かれます。それぞれ、起き方と条件が違います。

形起き方条件注意
一、依頼側から誘われる案件の中で動き方を見た依頼側の担当者や経営者が、「社員として来ないか」と言う案件を丁寧に終え、依頼側の社内で信用ができている。依頼側に採用の枠がある誘いの受け方に線がある。登録先の規約と、本業との関係を確認する
二、実績を職務経歴書に書ける副業で受けた範囲と、状態の変化を、転職用の職務経歴書に書く依頼側の許可の範囲で書ける形にしている。守秘の線を越えない依頼側の名前や数値は書けないことが多い。範囲と構造で書く
三、自分の向き不向きが分かる複数の依頼側で動くことで、合う規模、業界、働き方が分かる複数の案件を経験している。振り返りをしている「合わない」だけで転職を決めない。本業でも試せることがある

三つの要点は、どれも「副業を丁寧に続けた結果」として起きることです。「一」は、案件を丁寧に終えなければ起きません。「二」は、範囲を書面で決め、記録を残していなければ書けません。「三」は、複数の案件を経験しなければ分かりません。転職を目的にして副業を始めると、この三つの前提である「丁寧に続ける」が崩れます。副業の始め方は人事の副業の始め方に、続け方は案件が続かない原因の切り分けに書いています。

依頼側から誘われたときの受け方と線

「一」の、依頼側から誘われる形は、最も直接的な転職の入口です。ただし、受け方に線があります。

場面線進め方
登録先を通した案件で誘われた登録先の規約で、依頼側による担当者の直接雇用に条件があることが多い。規約を確認し、窓口に相談する「ありがたい話なので、登録先の規約を確認したうえでお返事します」と伝え、窓口に相談する。直接契約の誘いを受けたら
本業の会社と競合や取引の関係がある依頼側から誘われた本業の会社との関係で、転職に制限がある場合がある。就業規則と契約を確認する「本業との関係を確認したうえで」と伝え、就業規則と、本業との契約を確認する。個別の判断は専門家にご確認ください
案件の途中で誘われた案件の範囲を終えるまでは、案件の関係のまま進める。転職の話で案件が止まらないようにする「案件を区切りまで終えてから、改めてお話しさせてください」と伝える
誘いを受けるか迷っている副業で見た依頼側と、社員として入る依頼側は違う。社内の働き方、評価、給与を、副業では見えていない「社員としての条件を伺ってから判断したい」と伝え、条件を見てから決める
誘いを断る断っても、案件の関係は続けられる。「今は本業を続けたいが、案件は続けたい」と伝える断り方は丁寧に。断った後も、案件を同じ丁寧さで続ける

線の要点は、「登録先を通した案件の誘いは、窓口に相談してから進める」ことです。登録先は、依頼側と担当者をつないだ立場で、担当者の直接雇用に条件を設けていることがあります。規約を確認せずに進めると、登録先との関係が崩れ、転職しなかった場合に、案件の入口を失います。エラベルでは、依頼側が担当者を選ぶ仕組みで、こうした場面の相談は窓口が受けます。誘いは嬉しいものですが、線を確認してから進めることで、転職しても、しなくても、関係が残ります。

案件を丁寧に終えた担当者には、依頼側から次の案件や社員としての誘いが来ることがあります。範囲と条件を登録しておいてください

担当者として登録する

エラベルの見解

担当する側から見ると、依頼側から社員として誘われる担当者は、転職を目的にしていない人です。誘われる人は、範囲の仕事を丁寧にし、依頼側の仕組みの中で動き、判断の所在を守り、いつでも引き継げる状態を作っています。依頼側は、その動き方を見て「社内にいてほしい」と感じます。転職を目的にして副業をしている人は、案件の中で依頼側の社内に入り込もうとし、判断の所在を越え、依頼側に「この人は何をしに来ているのか」と思われて、案件が続きません。

見ていて差がつくのは、誘われたときに、案件を止めずに区切りまで進めているかです。誘われて舞い上がり、案件の手が止まる人は、依頼側が「社員になったらもっと止まるのでは」と感じ、誘いが立ち消えになることがあります。誘われても、案件を区切りまで同じ丁寧さで進め、区切りがついてから転職の話をする人は、依頼側の信用がさらに上がり、社員としての条件も良い形になっています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、こうした場面の相談は窓口で受け、登録先の規約と依頼側の意向を確認したうえで進める形にしています。副業の動き方そのものが、転職の面接になっています。

副業の実績を職務経歴書に書ける形

「二」の、副業の実績を職務経歴書に書く形は、書き方に条件があります。

書けること書けないこと書き方
受けた範囲（工程）依頼側の会社名（許可がない場合）「〇〇業界の数十名規模の企業で、スカウトの運用と求人票の改善を担当」
状態の変化（構造）数値（依頼側の情報。許可がない場合）「候補者の返信が来ない状態から、返信が来る状態に、文面と送る相手の見直しで改善」
自分が作った型依頼側の社内の仕組み、候補者の情報「面接官向けの準備資料の型を作り、依頼側に残した」
稼働の形単価、契約の条件「週に数時間、複数の依頼側で並行」
依頼側からの評価（許可があれば）依頼側の担当者の名前「更新を重ねて継続」「別の部署にも紹介された」
期間依頼側が特定できる組み合わせ「〇年〇月から〇か月」

書き方の要点は、「依頼側の名前と数値は、許可がなければ書かない」ことです。転職用の職務経歴書は、転職先の人事が読むもので、依頼側の情報がそこに載ると、守秘の線を越えます。範囲と構造と型で書けば、依頼側を特定せずに、何ができるかが伝わります。逆に、案件の中で範囲を書面で決め、状態の変化を記録し、型を残していなければ、書けることがありません。職務経歴書に書ける形は、案件の中で作ります。書き方は副業用の職務経歴書に、記録の残し方は稼働報告の書き方に、事例の書き方は事例の書き方に整理しています。

副業で分かる向き不向き

「三」の、向き不向きが分かる形は、転職の判断材料として最も確かなものですが、読み方に注意が要ります。

副業で分かること読み方転職の判断に使うとき
合う規模数十名規模で一人で全部を持つのが合うか、数百名規模で分業するのが合うか本業と違う規模で動いてみて、どちらで力が出るか
合う業界候補者の層、採用の速さ、社内の判断の速さが業界で違う副業で触れた業界で、自分の判断が通るか
合う働き方判断を任される方が合うか、仕組みの中で動く方が合うか副業は「仕組みの中で動く」が基本。判断を任される働き方は、副業では試しにくい
合う人事の工程スカウト、面接の設計、採用の型づくり、労務など、どの工程で力が出るか副業で受けた工程と、本業の工程を比べる
本業で足りないもの副業で「これは本業にない」と感じたもの本業で足せないか、先に試す。転職しなくても足せることがある
副業を続けるのが合うか一つの会社に属さず、複数で動く方が合うか転職ではなく、副業の比重を上げる、独立する、という選択肢もある

読み方の要点は、「副業で見えるのは、依頼側の外側からの景色」だということです。副業では、依頼側の仕組みの中で範囲の仕事をするので、社員として入ったときの評価、給与、社内の人間関係は見えていません。「この会社が合う」と副業で感じても、社員として入ると違うことがあります。逆に、「本業に足りないもの」が副業で見えたら、転職の前に、本業で足せないかを試します。副業で得たものの学び方は副業で学び続けるに、次の選択肢は副業から次のステップへに書いています。

複数の依頼側で範囲の仕事を経験した担当者は、自分に合う規模と工程が分かり、次の選択肢が広がります。範囲と条件を登録しておいてください

副業を転職の手段にしたときの崩れ方

副業を転職の手段として始めると、どこが崩れるかを見ておきます。

崩れるところ何が起きるか
案件の選び方「転職先になりそうな会社」で選び、範囲と条件で選ばない。合わない案件を受けて、続かない
案件の中での動き方依頼側の社内に入り込もうとし、判断の所在を越え、範囲外に手を出す。依頼側が「何をしに来たのか」と感じる
依頼側との関係転職の意図が見えると、依頼側は「この人は案件が目的ではない」と感じ、任せる範囲を狭める
本業との線本業の会社と関係のある依頼側を選ぶ、本業の情報を持ち込む、といった形で利益相反の線を越える。本業と利益相反になる案件
副業の許可本業に「転職のための副業」と見えると、許可の前提が崩れる。副業許可の申請の出し方
転職しなかったとき誘われなかった、条件が合わなかったときに、副業を続ける理由がなくなり、やめる

崩れ方の要点は、「転職の意図は、依頼側に見える」ことです。案件の選び方、動き方、質問の仕方に、転職の意図は表れます。依頼側は、範囲の仕事を丁寧にする人を求めていて、転職先を探している人を求めていません。意図が見えた時点で、案件の関係が変わり、転職につながる「一」「二」「三」のどれも起きにくくなります。転職につながる可能性を最も高くするのは、転職を目的にしないことです。動き方の基本は評価される副業人材の共通点に整理しています。

本業との線を守りながら進める順番

転職を目的にせず、結果として転職につながる可能性を残す順番です。

順番内容
一、副業の許可と利益相反の線を確認する本業の就業規則と、副業の許可の条件を確認する。本業と関係のある依頼側は避ける
二、範囲と条件で案件を選ぶ転職先になりそうかで選ばない。範囲が合い、稼働の枠に収まる案件を選ぶ
三、案件を丁寧に終える記録と型を残し、言った通りに動き、終了時に一言添える。これが「一」（誘い）の前提
四、書ける形で記録を残す範囲、状態の変化、作った型を、依頼側の情報を含まない形で記録する。これが「二」（職務経歴書）の前提
五、複数の案件を経験し、振り返る合う規模、業界、工程を、案件ごとに振り返る。これが「三」（向き不向き）の前提
六、誘われたら、線を確認してから進める登録先の規約、本業との関係を確認し、案件は区切りまで進める
七、転職を決めるときは、副業で見えていないものを確認する社員としての条件、評価、社内の働き方を、副業の景色と分けて確認する
八、転職しても、しなくても、副業の関係を残す転職先で副業を続けられるか確認する。続けられないなら、丁寧に引き継いで終える

順番の要点は、「一」から「五」までが、転職と関係なく、副業を丁寧に続けるための順番だということです。転職につながる三つの形は、すべてこの順番の結果として起きます。転職のために何かを足す必要はなく、副業を丁寧に続けることが、そのまま転職の可能性になります。「八」の、転職先で副業を続けられるかは、転職の条件を見るときに確認しておきます。引き継ぎはいつ辞めても困らない状態を作るに、本業の許可は副業は会社にばれるかに書いています。

エラベルの見解

相談で最も多い思い込みは、「副業を転職の足がかりにするなら、転職先になりそうな会社の案件を選ぶべきだ」というものです。実際には、転職先になりそうかで案件を選ぶと、範囲と条件が合わない案件を受けることになり、続かず、動き方も崩れ、依頼側に転職の意図が見えて、転職にもつながりません。転職につながっている担当者は、範囲と条件で案件を選び、丁寧に終え、その結果として誘われたり、職務経歴書に書ける実績ができたりしています。

順番として、本業の許可と利益相反の線を確認し、範囲と条件で案件を選び、丁寧に終え、書ける形で記録を残し、複数の案件を振り返り、誘われたら登録先の規約と本業との関係を確認して案件を区切りまで進め、転職を決めるときは副業で見えていないものを確認し、転職してもしなくても副業の関係を残す。この順番で、副業は転職の手段ではなく、転職を含む次の選択肢を広げるものになります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、丁寧に続けた担当者に依頼側から声がかかる場面があり、その場面の相談は窓口で受けています。転職は、副業の目的ではなく、副業を丁寧に続けた先に、選べる選択肢の一つとして残るものです。

まとめ

  • 副業が転職につながる形は依頼側から誘われる・実績を職務経歴書に書ける・向き不向きが分かるの三つ。どれも丁寧に続けた結果として起きる
  • 誘われたら登録先の規約と本業との関係を確認し、案件は区切りまで進めてから話を進める
  • 職務経歴書には依頼側の名前と数値は許可がなければ書かず、範囲・状態の変化・型で書く
  • 副業で見えるのは依頼側の外側からの景色。社員としての条件と評価は別に確認する
  • 副業を転職の手段にすると案件の選び方・動き方・依頼側との関係・本業との線が崩れる
  • 順番は許可と線の確認 → 範囲で選ぶ → 丁寧に終える → 書ける記録 → 振り返り → 誘いは線を確認 → 見えていないものを確認 → 関係を残す

よくある質問

副業の依頼側から社員に誘われましたが、本業の会社にどう伝えればよいですか

まず、誘いを受けるかどうかを、社員としての条件を見てから決めます。決める前に本業に伝える必要はありません。受けると決めたら、通常の転職と同じ手順で、本業に退職の意思を伝えます。副業先への転職であることを伝えるかどうかは、本業の就業規則と、副業の許可の条件によります。本業と副業先に取引や競合の関係がある場合は、就業規則の制限を確認し、個別の判断は専門家にご確認ください。退職の場面の考え方は退職後に副業から始めるに整理しています。

転職活動の面接で、副業のことを話してよいですか

話して構いませんが、依頼側の名前、数値、社内の情報は出しません。「〇〇業界の数十名規模の企業で、スカウトの運用と求人票の改善を、週に数時間で受けていた」と、範囲と構造で話します。面接官が依頼側の名前を聞いても、「守秘の約束があるので、業界と規模までにさせてください」と答えます。この答え方自体が、守秘の線を守れる人だという評価になります。転職先で副業を続けたい場合は、面接の段階で副業の可否を確認しておきます。

副業をしていると、転職に不利になることはありますか

転職先が副業を認めていない場合、「入社後は副業をやめられるか」を聞かれることがあります。続けたいなら、副業を認めている会社を選ぶか、面接で条件を確認します。また、副業の稼働で本業の成果が落ちていると、本業の評価が下がり、転職の材料である本業の実績が弱くなります。副業の稼働は、本業の成果を落とさない枠に収めます。稼働の枠は週何時間から受けられるかに、時間の確保は本業と両立する時間の作り方に書いています。

あわせて読む

  • 独立を考える目安｜人事の副業から独立を考えるなら「収入が本業に並んだか」ではなく、「本業の枠を外しても案件の入口が複数あり、断っている案件があり、最悪の月でも生活が回る蓄えがある」の三つで見る。独立は収入の額ではなく、入口と余裕で決める
  • 平日日中の連絡にどう対応するか｜人事の副業で平日日中の連絡は「即応する」でも「無視する」でもなく、「日中は返せないことを先に伝え、急ぎの定義と経路を一つだけ決め、それ以外は夜にまとめて返す」形で対応する。日中に返し始めると、依頼側の期待が変わり、本業の時間が消える
  • 副業を本業にする判断｜人事の副業を本業にするかどうかは「副業のほうが楽しいか」ではなく、「本業を辞めたい理由と、副業を本業にしたい理由を分けて書き出し、副業を本業にしても消えない理由が残るか」で決める。辞めたい理由で決めると、本業にした副業で同じことが起きる
  • 取っておくと役に立つ資格｜人事の副業で資格は「案件を取る条件」にはならず、「範囲の言葉を裏付ける材料」と「法令に関わる場面で線を引く判断力」として役に立つ。取る前に、自分の範囲のどこを裏付けたいかを決める
