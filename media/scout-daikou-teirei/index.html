スカウト代行との定例会は、多くの場合、担当者が数字を読み上げ、発注側が「分かりました、引き続きお願いします」と返して終わります。三十分が過ぎ、何も変わらず、次の定例会でも同じ数字が読み上げられます。結論を先に書くと、定例会は報告を聞く場ではなく、次の期間に何を変えるかを決める場にしてください。報告はレポートで済ませ、定例会では決めることだけに時間を使います。レポートに入れてもらう項目はレポートに入れてもらう項目にまとめています。

定例会で起きがちなこと

定例会がうまく機能しない形は、だいたい決まっています。

一つ目は、報告の読み上げに時間の大半が使われることです。レポートに書いてあることを、担当者が口頭でなぞります。出席者は聞いているだけで、終わる頃には議論の時間が残っていません。

二つ目は、決める人がいないことです。採用の担当者が出席していても、対象を変える、文面を変える、媒体を足す、といった判断の権限を持っていないことがあります。「持ち帰って確認します」で終わり、次の定例会まで何も動きません。

三つ目は、議題が決まっていないことです。何を話すかがその場で決まるので、直近で目についたことに時間が流れます。前回の決定がどうなったかを確認しないまま、新しい話題に移ります。

四つ目は、頻度と時間が運用の規模に合っていないことです。送信量が少ない時期に毎週一時間の定例会を組むと、話すことが無くなり、雑談か報告の繰り返しになります。

これらは、定例会の設計を最初に決めていないことから起きます。頻度、出る人、議題の型、決め方。この四つを最初に決めておくと、ほとんど防げます。

頻度と時間

頻度は、判断の周期に合わせます。対象や文面を変えた結果が数字に出るまでには、送信から返信、面談設定までの時間がかかります。変えた翌週に結果を判断しても、まだ出ていません。週に数十通以上を送る規模なら隔週、それより少なければ月次が目安です。

立ち上げの最初の一か月だけは、週次にする価値があります。初回の文面、対象の条件、返信への対応の型が固まるまでは、直す回数が多くなるためです。型が固まったら、隔週か月次に落とします。

時間は三十分を上限にします。報告をレポートで済ませていれば、決めることに三十分あれば足ります。一時間を確保すると、時間を埋めるために報告が長くなります。短く設定し、足りなければ延ばすほうが、時間の使い方が引き締まります。

頻度と議題の型は、担当者と最初の週に決められます

出る人

発注側からは、決められる人が一人出ます。対象・文面・媒体・予算のうち、少なくとも対象と文面を変える判断ができる人です。その人がいれば、他の出席者は不要です。多くの人が出ると、意見は増えますが決定は減ります。

決められる人が採用の担当者でない場合（経営者や事業側の責任者が持っている場合）、その人を毎回出席させるのは難しいことがあります。その場合は、採用の担当者に「対象と文面の変更はこの範囲まで自分で決めてよい」という権限を渡しておきます。権限の範囲が決まっていれば、持ち帰りは減ります。範囲を超える判断（予算、媒体の追加、募集の停止）だけを持ち帰りにします。

代行側からは、実際に運用している担当者が出ます。営業の窓口だけが出て、運用の担当者が出ない形は避けてください。数字の背景や候補者の反応を知っているのは運用の担当者で、その人がいないと見立ての議論ができません。

議題の型：順番を固定する

議題は毎回同じ順番にします。型があると、準備ができ、抜けがなくなります。

一.前回決めたことの結果。 前回の定例会で「対象を絞る」「一段落目を変える」と決めたなら、それをやったか、数字はどう動いたか。ここから始めないと、決定が実行されたかどうかを誰も追わなくなります。

二.段階ごとの数字で、どこが落ちているか。 レポートはあらかじめ読んでいる前提で、読み上げはしません。担当者が「今期はここで落ちている」と見立てを一言で言い、それに対する質問を受けます。

三.候補者の声。 返信や辞退の理由から、数字に出ない情報を共有します。求人票や条件に問題がある場合は、ここで見つかります。

四.次の期間に何を変えるか。 担当者が案を出し、発注側が決めます。案が複数あるなら、一つに絞ります。一度に複数を変えると、どれが効いたか分からなくなります。

五.発注側の宿題。 求人票の修正、面談の日程枠の確保、社内への確認。代行側だけでなく、発注側にも動くことがあります。ここを明示しないと、代行側だけが動いて、発注側で止まります。

五つで三十分です。一と四に時間を寄せ、二と三は短くします。

エラベルの見解

相談で最も多いのは、「定例会をやっているのに、運用が変わらない」というものです。話を聞くと、定例会で決めていることが無いか、決めても実行されていないかのどちらかです。

決めていない定例会は、議題の四番目が無い形です。報告を聞き、質問をし、「引き続きお願いします」で終わります。担当者側も、変える案を出して却下されるより、現状維持のほうが安全なので、案を出さなくなります。

決めても実行されない定例会は、議題の一番目が無い形です。決めたことを次回の冒頭で確認しないので、実行されたかどうかを誰も追いません。担当者が忙しければ、そのまま流れます。

どちらも、議題の型を固定するだけで直ります。「前回決めたことの結果」から始め、「次に何を変えるか」で終わる。この二つを毎回必ずしも長く話す必要はありませんが、抜かさないことが要です。

決め方：一つずつ変える

定例会で決めるときの原則は、一度に一つだけ変えることです。

対象を絞り、文面を直し、送る時間帯も変えた。翌期に返信率が上がったとき、どれが効いたのかは分かりません。下がったときも同じで、何を戻せばよいかが分かりません。一つずつ変えれば、効果の判断ができます。

変えるものの優先順位は、影響の大きい順です。多くの場合、対象、一段落目、文面の残り、送る時間帯の順です。対象がずれていれば、文面をどれだけ直しても返信は増えません。時間帯は、他が整ってから最後に調整するものです。

決めたことは、その場で記録します。「何を」「いつから」「誰が」「次回どう判断するか」。四つが書いてあれば十分です。記録は発注側が持ち、次回の冒頭で読み上げます。代行側の議事録に頼ると、契約が終わったときに手元に残りません。

形骸化したときの立て直し

運用が安定すると、定例会で話すことが減ります。数字が横ばいで、変えるものも無い。そのとき、惰性で続けるか、やめるかの判断が要ります。

まず、頻度を落とします。隔週なら月次に、月次なら隔月に。話すことが無いのに集まると、時間を埋めるための報告が増え、定例会の質が下がります。

次に、議題を「変えること」から「広げること」に切り替えます。安定した運用を別の職種に広げる、別の媒体を試す、返信後の対応を面談の設計まで広げる。運用の範囲を広げる話は、定例会でしか出ません。

それでも話すことが無いなら、定例会を止めて、レポートだけにします。必要が出たときに臨時で集まる形にすれば、時間の無駄はなくなります。定例会は目的ではなく手段です。目的が果たされているなら、無理に続ける必要はありません。

エラベルの見解

担当する側から見ると、定例会で最も効くのは「発注側が宿題を持ち帰って、次回までにやってくる」ことです。文面と対象を代行側でどれだけ直しても、求人票の役割の記述が曖昧なまま、面談の日程枠が確保されないまま、社内の承認が下りないままでは、数字は動きません。

代行に出すと、運用は代行側が動かすものだと考えがちです。実際には、対象と文面は代行側、求人票と面談体制は発注側、という分業です。定例会の五番目の議題「発注側の宿題」が毎回空欄の会社は、代行側だけが動いていて、片方の車輪だけが回っている状態です。

担当者を選ぶときは、「発注側にも宿題を出してくる担当者」を選んでください。頼まれたことだけをやり、発注側に何も求めない担当者は、扱いやすく見えますが、数字が止まったときに打ち手がありません。「求人票のここを直してください」「面談の枠を先に押さえてください」と言ってくる担当者のほうが、結果として速く進みます。

まとめ

  • 定例会は報告を聞く場ではなく、次に何を変えるかを決める場。報告はレポートで済ませる
  • 頻度は判断の周期に合わせる。立ち上げは週次、安定後は隔週か月次。時間は三十分
  • 発注側からは決められる人が一人。権限を渡して持ち帰りを減らす
  • 代行側からは運用の担当者が出る。営業の窓口だけでは議論できない
  • 議題は前回の結果 → 落ちている段階 → 候補者の声 → 次に変えること → 発注側の宿題の順で固定
  • 一度に一つだけ変える。優先は対象 → 一段落目 → 文面 → 時間帯
  • 決めたことは発注側が記録し、次回の冒頭で確認する
  • 話すことが無くなったら、頻度を落とすか、範囲を広げる話に切り替えるか、止める

よくある質問

定例会に経営者が出るべきですか

対象と文面を変える判断を採用の担当者に渡せるなら、経営者は出なくて構いません。予算や媒体の追加、募集の停止など、権限を超える判断だけを持ち帰りにします。経営者が毎回出ると、報告のための資料づくりに時間が使われ、定例会が報告会に戻りやすくなります。

定例会をオンラインで済ませても問題ないですか

問題ありません。三十分の判断の場なので、オンラインのほうが調整しやすい場合が多いです。ただし、立ち上げの最初の一回だけは、求人票や社内の状況を共有するために、対面か長めのオンラインで時間を取る価値があります。

担当者が変える案を出してきません

案を出して却下された経験があるか、変える権限が自分には無いと考えているかのどちらかであることが多いです。「次に何を変えるか、案を一つ出してください」と毎回求め、出てきた案は一度は試してみてください。試された経験があると、担当者は案を出すようになります。
