副業禁止の会社に勤めている場合｜黙って始めず、規程の中身と理由から確かめる

人事の副業に興味があっても、勤めている会社の就業規則に「副業禁止」と書かれていて、最初の一歩を踏み出せない人がいます。人事の仕事をしている人ほど、規程を破ることの重さを知っているので、なおさら迷うはずです。結論から書くと、黙って始めるのはおすすめしません。一方で、規程に「禁止」と書かれていても、その中身や運用は会社によって違い、相談や申請で認められる余地がある場合もあります。まず規程の中身と、会社が制限している理由を確かめるところから始めてください。

以下は厚生労働省の「副業・兼業の促進に関するガイドライン」に沿った一般的な整理です。個別の規程が有効かどうか、副業が規程違反に当たるかどうかは、事案ごとに判断されます。具体的な判断が必要な場合は、社会保険労務士・弁護士にご確認ください。

ガイドラインが示す考え方

厚生労働省のガイドラインは、副業・兼業に関する裁判例について、労働者が労働時間以外の時間をどのように利用するかは、基本的には労働者の自由であると説明しています。そのうえで、会社が副業を制限することが許されるのは、例えば次の場合だと解されているとしています。

  1. 労務提供上の支障がある場合
  2. 業務上の秘密が漏洩する場合
  3. 競業により自社の利益が害される場合
  4. 自社の名誉や信用を損なう行為や信頼関係を破壊する行為がある場合

また、厚生労働省が平成30年1月に改定したモデル就業規則では、「労働者は、勤務時間外において、他の会社等の業務に従事することができる」とされていることも紹介されています。ガイドラインは、企業の対応として、裁判例を踏まえれば原則として副業・兼業を認める方向とすることが適当であり、副業・兼業を禁止したり一律に許可制にしたりしている企業は、自社の業務に支障をもたらすものかどうかを今一度精査したうえで、そのような事情がなければ、原則として認める方向で検討することが求められる、としています。

黙って始めないほうがよい理由

ガイドラインの考え方を知ると、「禁止規定があっても、実際には問題にならないのでは」と考えたくなるかもしれません。ガイドラインは、裁判例において、許可などの手続を求める規定に形式的に抵触しても、職場秩序に影響せず、労務提供に支障を生じさせない程度・態様のものは禁止違反に当たらないとして懲戒処分を認めていない例があると紹介しています。ただし、これは個別の事案での判断であって、黙って始めてよいという意味ではありません。

人事の副業には、他の副業より慎重になるべき事情があります。人事は、本業の会社の採用計画、人件費、社員の個人情報など、秘密性の高い情報に触れる仕事です。副業で他社の採用を手伝えば、ガイドラインのいう業務上の秘密の漏洩や競業を疑われやすい立場にあります。同じ業界の会社から依頼が来ることも多く、採用の場で本業の関係者と顔を合わせることもあります。黙って始めて後から知られると、規程の解釈以前に、信頼関係の問題になります。

エラベルの見解

担当者として登録を考えている人から、「会社は副業禁止なのですが、登録だけしてもよいですか」と相談されることがあります。そのときにお伝えしているのは、登録や準備と、実際に案件を受けることは分けて考えてほしいということです。経験の棚卸しをしたり、どんな案件があるかを知ったりすることは、すぐに副業を始めなくてもできます。

一方で、案件を受けるのは、本業の会社の規程を確かめ、必要な手続きを済ませてからにしてください。人事の副業は、依頼側の採用に責任を持つ仕事です。途中で本業の会社から止められて手を引くことになれば、依頼側の採用が止まり、候補者にも迷惑がかかります。規程の問題を片づけてから始めるほうが、依頼側にとっても、あなたにとっても安全です。

規程の中身を確かめる

就業規則に「副業禁止」と書かれていても、その中身は会社によって違います。確かめるポイントは次のとおりです。

確かめる点見るところ
全面禁止か、許可制・届出制か就業規則の副業・兼業の条文。「許可なく」「届け出なく」などの条件が付いているか
何を理由に制限しているか競業、秘密保持、長時間労働の防止など、条文や社内の説明に理由が書かれているか
例外や申請の手続き申請書の様式や窓口があるか。過去に認められた例があるか
制限の対象雇用されて働く副業だけか、業務委託や個人での活動も含むか

人事の仕事をしている人なら、自社の規程の運用実態も知りやすい立場にあるはずです。「禁止」と書かれていても、実際には申請すれば認められている例があるかもしれません。逆に、規程は許可制でも、実際にはほとんど認められていない会社もあります。条文と運用の両方を確かめてください。

会社に相談するときの進め方

規程を確かめたうえで副業をしたい場合は、会社に相談します。ガイドラインは、労働者は副業・兼業を希望する場合、まず自身が勤めている企業のルールを確認し、そのルールに照らして業務内容や就業時間などが適切な副業・兼業を選択する必要がある、としています。また、副業・兼業に係る相談や自己申告をしたことにより不利益な取扱いをすることはできない、とも述べています。

相談するときは、ガイドラインが挙げる4つの場合に当たらないことを、具体的に示すと話が進みやすくなります。

  1. 労務提供上の支障がないこと：副業の時間を週何時間までと決め、本業の勤務時間外に行うことを示す
  2. 秘密が漏れないこと：本業の情報を使わず、副業先の情報も本業に持ち込まないことを約束する
  3. 競業しないこと：本業と競合する会社や取引先からは受けない範囲を示す
  4. 信用を損なわないこと：副業の内容と依頼先の種類を説明する

人事の副業なら、業務委託で、採用の実務を週に数時間、本業と競合しない業界の会社から受ける、という形が説明しやすい例です。具体的な形が決まっているほど、会社も判断しやすくなります。

エラベルの見解

会社に相談するときに、もう一つ伝えてほしいのが、副業の経験を本業にどう還元できるかです。ガイドラインでも、副業・兼業のメリットとして、労働者が社内では得られない知識やスキルを獲得できることが挙げられています。人事の副業で他社の採用を見ることは、本業の採用の改善にもつながります。

担当する側から見ていると、副業が認められた人の多くは、「お金を稼ぎたい」ではなく「経験の幅を広げて本業にも生かしたい」という形で相談しています。もちろん、副業の情報を本業に持ち込まないことが前提です。そのうえで、他社の仕組みを見て得た視点を本業で生かせることを伝えれば、会社にとっても検討する理由ができます。

まとめ

  • ガイドラインは、会社が副業を制限できるのは労務提供上の支障、秘密の漏洩、競業、信用の毀損などの場合と整理している
  • モデル就業規則は、勤務時間外に他の会社等の業務に従事できるとする形に改定されている
  • 人事は秘密性の高い情報に触れるため、黙って始めない。登録や準備と、案件を受けることは分けて考える
  • 規程の条文と運用の両方を確かめ、許可制・届出制・例外の有無を把握する
  • 相談するときは、4つの場合に当たらないことを具体的な働き方で示す

よくある質問

副業禁止の規定は無効ではないのですか

ガイドラインは、裁判例を踏まえて会社が副業を制限できる場合を整理していますが、すべての禁止規定が無効になると述べているわけではありません。規程が有効かどうか、自分の副業が違反に当たるかどうかは、個別の事情で判断されます。判断が必要な場合は、社会保険労務士や弁護士にご相談ください。

業務委託なら副業に当たらないのではないですか

会社の規程が、雇用されて働く副業だけを対象にしているのか、業務委託や個人での活動も含むのかは、条文によって違います。業務委託でも規程の対象になる場合は多いので、自己判断せず、規程の文言と会社の運用を確かめてください。

相談したら不利な扱いを受けないか心配です

ガイドラインは、副業・兼業に係る相談や自己申告をしたことにより不利益な取扱いをすることはできないとしています。相談するときは、副業の具体的な形と、本業に支障が出ないことを示す準備をしておくと、話し合いが進みやすくなります。
