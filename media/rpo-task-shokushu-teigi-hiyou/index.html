ジョブディスクリプション（職務記述書）は、その職種で何をするのか、どんな責任を持つのか、どんな経験や力が必要なのかを書き出した文書です。求人原稿や面接の評価、入社後の役割の確認など、採用のさまざまな場面の土台になります。ジョブディスクリプションの作成を外部に頼むとき、文章を書く作業は外部に任せられますが、その中身は現場にしかありません。結論から書くと、ジョブディスクリプション作成の外注は、聞き取り・整理・執筆・確認に分け、現場から仕事を聞き出す工程に工数がかかることを前提に、職種の数と仕事の整理の度合いから見積もると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

工程に分ける

ジョブディスクリプションの作成は、次の工程に分けられます。

工程中身担い手
聞き取り現場の責任者や、その職種で働く社員から仕事の中身を聞く外部が進められる。社内は話す時間が要る
整理聞いた仕事を、目的・責任・業務・必要な経験に分けて整理する外部が担える
執筆ジョブディスクリプションの形にまとめる外部が担える
確認現場の責任者と人事が、内容が実態と合っているかを確かめる社内が担う

外部に頼むと、整理と執筆の手間は大きく減ります。一方で、聞き取りに応じる時間と、確認の時間は社内に残ります。とくに聞き取りは、ジョブディスクリプションの質を左右します。現場の責任者が忙しく、聞き取りの時間が十分に取れないと、一般的な職種の説明をなぞった内容になりがちです。詳しい切り分けはジョブディスクリプション作成は代行に出せるかで書いています。

この記事の課題を、外部の支援で補うなら。記事内で、依頼できる業務と相談時の確認事項を紹介しています。

工数は職種の数と仕事の整理の度合いで変わる

ジョブディスクリプション作成の工数は、次の要素で変わります。

  1. 職種の数：一つの職種か、複数の職種か。似た職種をまとめて書けるか
  2. 仕事の整理の度合い：その職種の仕事がすでに整理されているか、人によって担当がばらばらか
  3. 聞き取りの対象：一つの職種について、何人に話を聞くか
  4. 使い道：求人原稿に使うだけか、評価や等級の制度にもつなげるか

とくに二つ目は見落とされやすい点です。同じ職種名でも、社員によって担当している仕事がばらばらな会社では、ジョブディスクリプションを書く前に、その職種の役割そのものを整理する必要があります。この場合、聞き取りと整理の工数が大きくなります。

エラベルの見解

ジョブディスクリプション作成の外注で多いのは、文書は整ったのに、現場の実態と合っていないケースです。聞き取りが短く、現場の責任者が思い描く理想の仕事を書いた結果、実際に働く社員の仕事とずれてしまう。入社した人が、書かれていた仕事と実際の仕事が違うと感じて辞めてしまうこともあります。

外部に頼むなら、現場の責任者だけでなく、その職種で今働いている社員からも話を聞いてもらってください。理想と実態の両方を聞くことで、実態に沿いながら、これから期待する役割も書けます。同じ料金・同じ業務範囲でも、聞き取りの相手を丁寧に選んでくれる担当者かどうかで、ジョブディスクリプションの使いやすさが変わります。

業務と就業場所の変更の範囲

ジョブディスクリプションは、求人で明示する労働条件とも関係します。厚生労働省のリーフレットによると、2024年4月1日施行の改正職業安定法施行規則により、求職者等に明示しなければならない労働条件に、従事すべき業務の変更の範囲、就業場所の変更の範囲などが追加されました。リーフレットでは、「変更の範囲」とは、雇入れ直後にとどまらず、将来の配置転換など今後の見込みも含めた、締結する労働契約の期間中における変更の範囲のことをいうと説明されています。

ジョブディスクリプションを書くときは、入社直後の仕事だけでなく、将来どこまで仕事や勤務地が変わりうるかも整理しておくと、求人の条件を明示するときにも使えます。外部に頼む場合も、変更の範囲について社内の考え方を伝え、求人の条件と食い違わないように確認してください。ジョブディスクリプション作成の進め方はジョブディスクリプション作成の進め方で書いています。

料金の形と品質の見方

ジョブディスクリプション作成を外部に頼むときの料金の形は、職種ごとの成果物、複数職種をまとめた一式、採用の運用とまとめた月額などがあります。

品質は、次の点で確かめられます。

  • 実態と合っているか：その職種で働く社員が読んで、自分の仕事だと感じるか
  • 使えるか：求人原稿、面接の評価、入社後の役割の確認にそのまま使えるか
  • 変更の範囲が整理されているか：将来の仕事や勤務地の変わりうる範囲が書かれているか

エラベルの見解

ジョブディスクリプションで、もう一つ考えてほしいのは、更新し続けることです。事業や組織が変われば、職種の仕事も変わります。一度書いたジョブディスクリプションを何年も使い続けると、実態とのずれが大きくなります。

採用のたびに見直す、組織の変更があったときに見直す、といった更新のきっかけを決めておいてください。外部に頼む場合も、最初の作成だけでなく、見直しのときに手伝ってもらえるかを確かめておくと安心です。

よくある質問

ジョブディスクリプション作成を外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。職種の数、聞き取りの範囲、使い道をそろえて見積もりを取り、比べてください。

ジョブディスクリプションは求人原稿と同じものですか

求人原稿は候補者に向けて会社や仕事の魅力を伝えるもので、ジョブディスクリプションは仕事の中身や責任、必要な経験を整理したものです。ジョブディスクリプションを土台にすると、求人原稿や面接の評価に一貫性が生まれます。

すべての職種で作る必要がありますか

すべての職種で一度に作る必要はありません。採用の予定がある職種や、役割があいまいで採用に苦労している職種から作るのが現実的です。
