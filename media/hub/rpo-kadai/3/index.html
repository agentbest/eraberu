採用代行｜採用の課題から考える

応募が来ない、面接に来ない、辞退が続く。課題を分解して、外に任せる部分を決める。 採用代行の「採用の課題から考える」に関する記事100本の一覧です。

すべての記事（100本）3／3ページ

  • 動画を採用に使うべきか｜「動画を作る」の前に、「文章と写真で伝わらないもの」があるかで決め、あるなら短く、社内で、実態のまま 採用に動画を使う会社が増え、自社でも作るべきか迷っている。制作会社に頼むと費用がかかり、社内で作ると質が不安。作っても見られるか分からない。動画を使うかの判断で起きていること、動画でしか伝わらないもの、使う判断と使わない判断、社内で作る型、プロに頼む範囲、置き場と使い方、効果の見方、外注する範囲を整理しました。 採用の課題
  • 内定辞退が続くときに見直す3点｜「速さ」「条件の出し方」「内定後の接点」を順に見る 内定を出しても、辞退が続く。面接までは良かったのに、最後で失う。内定辞退は、他社との比較で負ける形と、自社の対応で失う形があり、後者は直せます。辞退の時点と理由の分け方、見直す三点（内定までの速さ・条件の出し方・内定後の接点）、それぞれの直し方、辞退理由の集め方、面接段階に原因がある場合、外注する範囲を整理しました。 採用の課題
  • 内定辞退の理由を正しく集める方法｜「一身上の都合」の先を、聞く人・聞き方・時期で引き出す 内定辞退の理由を聞いても「一身上の都合」「他社に決めました」で終わる。本当の理由が集まらないと、対策が打てません。理由が集まらない三つの原因（聞く人・聞き方・時期）、本音が出やすい聞く人、選択肢と一言の聞き方、辞退の直後と少し後の二回、集めた理由の記録と分類、理由を社内に戻す形、集められない場合の代わりを整理しました。 採用の課題
  • 日程調整が遅くて候補者が流れる｜「往復の回数」と「社内で止まる日数」を数えて、先に枠を空ける 応募や返信から面接までの日程調整で、候補者が離れていく。原因は、候補者の都合ではなく、候補日を出すまでに社内で止まる日数と、往復の回数です。日数が消える場所の数え方、面接者の枠を先に空ける設計、候補日の出し方、日程調整を担う人と裁量、複数の面接者がいる場合、外注する範囲を整理しました。 採用の課題
  • 年収交渉で毎回折り合わない｜内定の場で初めて額を出すのをやめて、面接の早い段階からすり合わせる 内定を出すと、候補者の希望と提示が合わず、交渉が長引き、辞退される。毎回同じことが起きる。折り合わない構造、面接の早い段階で希望を聞く型、提示の額の決め方、交渉の場での伝え方、上げられないときの選択肢、紹介会社経由の場合の進め方、外注する範囲を整理しました。 採用の課題
  • 年齢構成が偏っている｜「若手を採る」「シニアを採る」の前に、偏りで何が困るかを特定し、役割と育成と採用の三つで直す 社員の年齢が一つの層に偏っていて、数年後に一斉に退職する、若手がいなくて技術が継承されない、中堅がいなくて管理職が育たない。「若手を採ろう」と求人を出すが来ない。偏りで起きていること、何が困るかの特定、年齢で採らない理由、役割と育成と採用の三つの直し方、年齢の偏りを直す採用の設計、時間の見込み、外注する範囲を整理しました。年齢に関する採用の扱いは、法令上の定めがあるので専門家に確認します。 採用の課題
  • 媒体を増やしすぎて管理できない｜増やした媒体を減らし、残す媒体の運用を一枚に揃える 応募を増やそうと媒体を足していったら、五つも六つも動いていて、どこに何を出しているか分からない。応募の見落とし、返信の遅れ、契約の自動更新、費用の膨張。媒体が増えすぎた会社で起きていること、棚卸しの手順、減らす基準、残す媒体の運用を揃える型、応募の窓口を一本にする方法、再び増やさないための約束、外注する範囲を整理しました。 採用の課題
  • 繁忙期に採用が止まる｜「忙しいから止まる」を前提に、止まらない工程と、止めてよい工程を先に分ける 毎年、決まった時期に現場が忙しくなり、採用が止まる。面接の日程が組めず、応募への返信が遅れ、候補者が流れる。繁忙期が明けると採用を再開するが、また一から。繁忙期に止まる構造、止まらない工程と止めてよい工程の分け方、繁忙期の前にやること、繁忙期の中で回す型、繁忙期の後の立て直し、年間の採用の時期の設計、外注する範囲を整理しました。 採用の課題
  • 必須要件と歓迎要件の線が引けない｜「無いと三か月で詰まるか」の一つの問いで線を引き、面接で確かめて直す 求人票の要件が、全部「必須」に見えるか、全部「歓迎」で曖昧か。何を必須にして、何を歓迎にするか、社内で決められない。線が引けない構造、線を引く一つの問い、必須にしてはいけないもの、歓迎の使い方、線を引いた後の書き方、面接での確かめ方と直し方、外注する範囲を整理しました。 採用の課題
  • 評価基準が言語化できていない｜「良い人」を定義しようとせず、「通した人と落とした人の違い」から言葉を作る 面接で「良い」「弱い」と言うが、何が良くて何が弱いのかを言葉にできない。面接官ごとに違い、候補者にも紹介会社にも説明できない。基準が言語化できていない会社で起きていること、言語化できない原因、過去の判定から言葉を作る手順、観察できる言葉の作り方、基準の書面の型、基準を使って直す運用、外注する範囲を整理しました。 採用の課題
  • 不合格連絡が遅い・出していない｜「言いにくい」を理由にせず、期限・文面・理由の三つを型にして、全員に出す 不合格の連絡が一週間以上遅れる、または出していない。候補者から「結果はまだですか」と問い合わせが来て、口コミには「連絡が来ない会社」と書かれている。不合格連絡が遅れる・出ない構造、出さないことの損失、期限の決め方、文面の型、理由を書くかどうかと書き方、紹介会社経由の場合、運用の型、外注する範囲を整理しました。 採用の課題
  • 不採用にした人にもう一度声をかけたい｜「前に落とした」を隠さず、「なぜ今回は合うと思うか」を一人ずつ伝える 以前不採用にした人が、今回の募集には合うかもしれない。声をかけたいが、「落としておいて」と思われないか、どう伝えればよいか、そもそも連絡してよいのかが分からない。声をかけにくい構造、声をかけてよい人とかけないほうがよい人、伝え方の型、当時の面接官が送る意味、選考の進め方、断られたときの扱い、外注する範囲を整理しました。個人情報の扱いは専門家に確認します。 採用の課題
  • 副業人材から本採用につなげる｜「良い人だから誘う」ではなく、最初から本採用の可能性を置いて設計する 副業で関わってもらっている人が良い働きをしていて、本採用に誘いたい。ただ、本人は本業があり、条件も役割も副業とは違う。どう切り出すか、どう設計するかが分からない。副業から本採用で起きていること、最初から可能性を置く設計、本採用を切り出す時期と伝え方、役割と条件の組み直し、本人の本業との関係、断られた場合の関係の続け方、外注する範囲を整理しました。 採用の課題
  • 複数職種を同時に採用できない｜「全部を同時に」をやめて、職種ごとに工程を分け、共通の工程を一つにまとめる 営業、エンジニア、事務を同時に募集しているが、どれも中途半端で、一つも決まらない。人事が一人で全職種の応募と面接と連絡を回し、どの職種も遅れる。同時に採れない構造、職種ごとに違う工程と共通の工程、同時に回す設計、並行の数の目安、職種ごとの担当と面接官、月次で見る一枚、外注する範囲を整理しました。 採用の課題
  • 未経験採用に踏み切るか迷っている｜「経験者が採れないから」ではなく、「育てる型があるか」で決める 経験者が採れず、未経験を採るかどうか迷っている。採って育てられるのか、育つまでの負担は誰が持つのか、辞めたら無駄になるのではないか。未経験採用に迷う理由の整理、踏み切る前に確認すること、未経験でも採れる役割と採れない役割、未経験を見極める観点、育てる型の作り方、経験者採用と並行する設計、外注する範囲を整理しました。 採用の課題
  • 面接で何を聞けばよいか分からない｜「良い質問」を探すのをやめて、観点ごとに「過去の場面を聞く」型で作る 面接の時間になっても、何を聞けばよいか分からず、経歴の確認と雑談で終わる。候補者の何が分かったのかも分からない。聞くことが無い構造、質問の前に決める観点、過去の場面を聞く型、観点ごとの質問の例、聞いてはいけないこと、深掘りの仕方、質問を直す運用、外注する範囲を整理しました。 採用の課題
  • 面接のドタキャン・無断欠席を減らす｜「来ない理由」は候補者ではなく、日程と連絡の設計にある 面接の当日に来ない、連絡も無い。候補者の質の問題に見えますが、多くは日程の遠さ、確認の連絡の欠落、選考の温度の低下で起きます。欠席が起きる四つの理由、日程の設計（近さ・候補者が選ぶ・確認）、面接前の連絡の型、欠席された後の対応、欠席率の見方、外注する範囲を整理しました。 採用の課題
  • 面接官が足りない｜「一人が全部を見る」をやめて、段階を分け、観点を絞り、面接官を増やす 採用が増えて、面接官が足りない。責任者一人に面接が集中し、日程が組めず、責任者も疲弊する。面接官が足りない構造、段階ごとに面接官を分ける設計、面接の観点を絞って面接官を増やす方法、新しい面接官の準備、面接の回数と時間を減らす工夫、外部の面接官を使う場合、外注する範囲を整理しました。 採用の課題
  • 面接官によって評価がばらつく｜「見る目」を揃えるのではなく、観点と基準と記録を揃える 同じ候補者を、Aさんは通し、Bさんは落とす。面接官によって評価がばらつき、誰の判断を信じてよいか分からない。ばらつきが起きる構造、観点を揃える方法、通す基準を書面にする方法、記録の型、面接官同士のすり合わせ、ばらつきを見える化する運用、外注する範囲を整理しました。 採用の課題
  • 要員計画と採用計画がつながっていない｜「何人要るか」と「何人採るか」を、同じ表の同じ行に置く 経営企画が作る要員計画と、人事が作る採用計画が、別々に存在している。要員計画は年度の人員の合計、採用計画は求人の一覧。二つが対応しておらず、採っても要員が埋まらない、採る必要が無い求人が動いている。つながっていない構造、つなげる一つの表、表の作り方、更新の運用、部門との合意、ずれが出たときの扱い、外注する範囲を整理しました。 採用の課題
