「リファレンスチェックを入れたいが、前職の上司に連絡するのは人事の手が回らない」という相談は、管理職や専門職の採用で増えています。出せる部分はあります。ただ、リファレンスチェックは候補者の同意を前提に、第三者から候補者の情報を集める工程なので、「誰が何をどこまで聞くか」を会社が決めずに外に出すと、候補者との信頼を損ね、集めた情報の扱いで問題が起きます。手間の話の前に、目的と範囲と扱いを会社が決めることが要ります。結論を先に書くと、リファレンスチェックは、「確認項目と目的の決定」「実施するかどうかの判断」「結果を採否にどう反映するかの決定」「結果の扱いの決まり」は会社が持ち、「候補者への説明と同意の手続き・推薦者への依頼と日程・質問票に沿った聞き取り・記録の作成・結果の整理」は代行に出せます。この記事は一般的な整理で、個人情報の取得と第三者からの情報収集に関わる部分は、専門家にご確認ください。専門のサービスを使う場合の仕様は、提供元の公式情報でご確認ください。

「決める」と「集める」を分ける

リファレンスチェックを工程に分けると、次のようになります。

一つ目は、何のために、何を確かめるかを決めることです。「経歴の事実の確認」なのか、「働きぶりの傾向を面接の補足として知る」なのか、「管理職としての振る舞いを聞く」なのか。目的で聞く相手と項目が変わります。会社が決めます。案は外の人が出せます。

二つ目は、どの候補者に、選考のどの段階で実施するかを決めることです。全員か、最終面接の後か、内定の前か。会社が決めます。

三つ目は、候補者に説明し、同意を得ることです。何を、誰に、どう聞くか、結果をどう扱うかを説明し、同意を文書で得る。説明の文面と手続きは外の人ができ、同意は会社の名で得ます。

四つ目は、候補者が挙げた推薦者に依頼し、日程を決めることです。外の人ができます。

五つ目は、質問票に沿って聞き取り、記録を作ることです。質問票の案は外の人が作り、会社が決める。聞き取りと記録は外の人ができます。

六つ目は、結果を整理し、会社に渡すことです。項目ごとに「推薦者はこう答えた」と整理する。外の人ができます。評価や採否の意見は付けません。

七つ目は、結果を採否にどう反映するかを決めることです。会社が決めます。

八つ目は、結果の扱いの決まりです。誰が見られるか、候補者に開示するか、保管と廃棄。会社が決め、代行はそれに沿います。

八つのうち、一と二の決定、三の同意、七の決定、八の決まりは会社が持ち、それ以外は外に出せます。

代行に出せる工程と出せない工程

工程会社が持つ代行に出せる
目的と確認項目決める目的に合わせた項目の案
誰に・どの段階で実施するか決める選考の流れに合わせた段階の案
候補者への説明と同意会社の名で同意を得る説明の文面、手続きの案内、同意の記録
推薦者への依頼と日程―依頼の連絡、日程の調整、再連絡
質問票決める項目ごとの質問の案
聞き取りと記録―質問票に沿った聞き取り、答えの記録
結果の整理―項目ごとに答えを整理して渡す。評価は付けない
採否への反映決める―
結果の扱いの決まり決める決まりに沿って扱う

表の要点は、「結果の整理」で代行が評価を付けないことです。推薦者の答えを「良い」「悪い」に変えるのは判断であり、会社が持ちます。代行が渡すのは、「この項目について、推薦者はこう答えた」という記録です。

もう一つの要点は、「候補者への説明と同意」が会社の名で行われることです。候補者から見て、誰が自分の情報を集めるのかが分からない形は、信頼を損ねます。代行が説明の手続きを回す場合も、同意は会社が得る形にします。

エラベルの見解

相談で最も多い思い込みは、「リファレンスチェックは前職に電話して評判を聞くこと」というものです。実際には、候補者の同意なく前職に問い合わせる形は、候補者の信頼を損ね、情報の扱いでも問題になります。ある会社では、最終面接の後に人事が候補者の前職の知り合いに「それとなく」聞いていて、それを候補者が知って辞退したことがありました。担当者が入って、目的を「管理職としての振る舞いの傾向を知る」に絞り、候補者に何を誰に聞くかを説明して同意を得る手続きを作り、候補者が挙げた推薦者に質問票で聞く形にしたところ、候補者からの反発は無くなり、聞き取りの内容も面接では見えなかった点を補うものになりました。リファレンスチェックで差がつくのは、聞き出す技術ではなく、候補者に対して「何を誰にどう聞くか」を先に開示できているかです。

この記事の課題を、外部の支援で補うなら。記事内で、依頼できる業務と相談時の確認事項を紹介しています。

代行に出したほうがよい状況

次の状況では、リファレンスチェックの手続きを代行に出したほうが進みます。

一つ目は、目的と項目は決まっているが、推薦者への依頼と日程と聞き取りに人事の時間が取れないときです。手続きを外に出すと、内定までの日数が延びません。

二つ目は、聞き取りをする人によって聞き方が変わり、記録がばらついているときです。質問票に沿って一人が聞き、項目ごとに記録する形にすると、揃います。

三つ目は、管理職や専門職の採用で、面接では見えない「チームでの振る舞い」を補いたいときです。目的を絞って項目を作る作業を外に出すと、聞き取りが面接の補足として使えます。

四つ目は、候補者への説明の文面と同意の手続きが整っておらず、都度対応になっているときです。文面と手続きの型を外に出すと、候補者ごとの差が無くなります。

代行に出さないほうがよい状況

逆に、次の状況では、リファレンスチェックを外に出しても進みません。

一つ目は、何のために実施するかが決まっていないときです。目的の無い聞き取りは、聞く項目が定まらず、結果も使われません。先に目的を決めるか、実施しません。

二つ目は、候補者への説明と同意の手続きを踏まずに実施しようとしているときです。同意の無い形は、外に出しても出さなくても問題があります。手続きを先に整えます。

三つ目は、結果の扱いの決まりが無いときです。推薦者から得た情報は候補者に関する情報で、しかも第三者の発言です。誰が見られるか、候補者に開示するか、保管と廃棄をどうするかを決め、代行との契約に入れます。法令に関わる部分は専門家にご確認ください。

四つ目は、結果で採否を決めたいが、その基準を説明できないときです。「推薦者がこう言ったので不採用」を候補者に対して持てないなら、結果を採否の決定要因にせず、面接の補足にとどめます。

担当者の選び方

リファレンスチェックの手続きを任せる担当者は、次の点で選びます。

一つ目は、候補者の同意を前提とした手続きを設計した経験があるかです。「前職に電話する」ではなく、「候補者に説明し、同意を得て、候補者が挙げた推薦者に聞く」流れを説明できる人。

二つ目は、質問票に沿って聞き、答えをそのまま記録できるかです。答えを自分の印象で言い換えない人。

三つ目は、結果を整理するときに、評価や採否の意見を付けずに渡せるかです。判断を会社に残す姿勢のある人。

四つ目は、情報の扱いに慎重で、決まりに沿って扱えるかです。推薦者の発言を会社の関係者以外に出さない、候補者の情報を目的外に使わない、といった決まりを守れる人。担当者の経歴の見方は担当者の経歴の見方に書いています。

出す前に用意しておくもの

リファレンスチェックの手続きを代行に出す前に、次を用意しておくと、最初の一週間が速くなります。

一つ目は、目的と確認項目です。決まっていなければ、担当者が案を出して会社が決めます。

二つ目は、誰に、どの段階で実施するかです。全員か、特定の職位以上か、最終面接の後か内定の前か。

三つ目は、候補者への説明の文面と、同意の取り方です。何を、誰に、どう聞くか、結果をどう扱うかを説明し、文書で同意を得る形。担当者が案を作れますが、会社の名で行います。法令に関わる部分は専門家にご確認ください。

四つ目は、結果の扱いの決まりと、代行との契約です。閲覧の範囲、候補者への開示、保管と廃棄。

五つ目は、結果を採否にどう反映するかの考え方です。決定要因にするのか、面接の補足にするのか。

六つ目は、専門のサービスを使う場合は、その規約です。外部の代行が関わることについて制限が無いかを確認します。仕様は提供元の公式情報でご確認ください。

エラベルの見解

担当する側から見ると、リファレンスチェックで最も効くのは、「質問票を目的に沿って五つ以内に絞る」ことと、「記録に評価を書かない」ことの二つです。前者で推薦者の負担が減って協力が得やすくなり、後者で会社が自分の基準で読めます。推薦者は候補者の前職の上司や同僚で、忙しい中で時間を割いてくれます。二十項目の質問票は答えてもらえず、五項目なら答えてもらえます。実施するかどうか、結果を採否にどう使うかは会社の判断であり、情報の取得と扱いに関わる部分は専門家にご確認いただくようお伝えしています。

まとめ

  • リファレンスチェックは「決める」と「集める」に分かれる。目的と項目・実施の判断・採否への反映・結果の扱いの決まりは会社。説明の文面と手続き・推薦者への依頼と日程・質問票に沿った聞き取り・記録・結果の整理は代行に出せる
  • 候補者の同意が前提。同意は会社の名で得る。同意の無い形は外に出しても出さなくても問題がある
  • 代行の記録は「推薦者はこう答えた」まで。評価と採否の意見は付けない
  • 出したほうがよいのは手続きに時間が取れない・聞き方がばらつく・面接の補足にしたい・説明と同意の型が無いとき
  • 出さないほうがよいのは目的が無い・同意の手続きが無い・結果の扱いの決まりが無い・採否の基準を説明できないとき
  • 担当者は同意を前提とした手続きの設計経験・答えをそのまま記録する・評価を付けない・情報の扱いの慎重さで選ぶ

よくある質問

候補者に知らせずに前職に聞いてはいけないのですか

候補者の同意なく第三者から候補者の情報を集める形は、候補者との信頼を損ねるうえ、個人情報の取得の観点でも問題になり得ます。一般に、候補者に目的と範囲を説明し、同意を得たうえで、候補者が挙げた推薦者に聞く形が取られています。個別の判断は専門家にご確認ください。

推薦者が候補者の知り合いなら、良いことしか言わないのでは

推薦者は候補者が挙げるので、否定的な話は出にくい傾向があります。それでも、質問票を「良い人ですか」ではなく「この場面でどう動きましたか」のように場面を聞く形にすると、推薦者の答えから傾向は読めます。目的を「経歴の事実の確認」と「働きぶりの傾向」にとどめ、採否の決定要因にしない使い方なら、この偏りは問題になりにくくなります。

結果が良くなかったとき、内定を取り消せますか

結果を採否にどう反映するかは、実施の前に会社が決めておきます。内定の後に実施して結果で取り消す形は、法令に関わる問題が生じ得るので、実施の段階を内定の前にするか、結果を決定要因にしないかを、事前に決めます。個別の判断は専門家にご確認ください。
