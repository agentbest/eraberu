面接官トレーニングを外注したときの費用と工数の目安｜研修の時間より「現場に戻ってからの定着」に工数がかかる

業務別に任せる面接官トレーニング 更新日 2026-10-16

面接官によって評価がばらつく、面接で候補者の印象が悪くなって辞退される、といった悩みから、面接官のトレーニングを外部に頼む会社があります。研修を受ければ、面接の進め方や評価の仕方を学べます。ただ、研修を受けただけでは、現場の面接は変わらないことが多いのです。研修で学んだことを実際の面接で使い、振り返りを重ねて、はじめて面接の質が上がります。結論から書くと、面接官トレーニングの外注は、評価の基準づくり・研修・面接への同席や振り返りに分け、現場に戻ってからの定着に工数をかける見積もりにすると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

工程に分ける

面接官トレーニングの仕事は、次の工程に分けられます。

工程中身担い手
評価の基準づくり何を見て、どう評価するかを決める外部が手伝える。決定は社内
研修面接の進め方、質問の仕方、評価の付け方、聞いてはいけないことを学ぶ外部が担える
面接への同席実際の面接に同席し、進め方や評価について助言する外部が担える
振り返り面接官どうしで評価を突き合わせ、ずれを話し合う外部が進行を担える。参加は面接官

研修だけを頼む見積もりは、費用が分かりやすい一方で、現場の面接が変わるかどうかは分かりません。面接への同席や振り返りまで含めて頼むと、研修で学んだことが実際の面接に定着しやすくなります。詳しい切り分けは面接官トレーニングは代行に出せるかで書いています。

研修に含めたい決まり

面接官トレーニングでは、面接の技術だけでなく、採用選考に関する決まりも学ぶ必要があります。

東京労働局の案内では、採用選考は、応募者の基本的人権を尊重すること、応募者の適性と能力に基づいた基準により行うことを基本的な考え方としています。そのうえで、本籍・出生地、家族、住宅状況、生活環境・家庭環境、宗教、支持政党、人生観・生活信条、尊敬する人物、思想、労働組合や社会運動、購読新聞・雑誌・愛読書などに関することを、面接で尋ねるなどして把握することは、就職差別につながるおそれがあるとされています。

また、男女雇用機会均等法第5条は、事業主は労働者の募集及び採用について、性別にかかわりなく均等な機会を与えなければならないとし、労働施策総合推進法第9条は、厚生労働省令で定めるときは、募集及び採用について年齢にかかわりなく均等な機会を与えなければならないとしています。

面接官が雑談のつもりで家族のことを聞いてしまう、といったことは起こりがちです。研修では、聞いてはいけないことと、その理由を具体的な質問の例で学べるようにしてください。

エラベルの見解

面接官トレーニングの外注で多いのは、研修の満足度は高いのに、面接の評価のばらつきが減らないケースです。研修では評価の付け方を学んでも、現場に戻ると、それぞれの面接官が自分の感覚で評価してしまう。評価の基準が言葉になっていないことが、その原因であることがよくあります。

外部に頼むなら、研修の前に評価の基準を一緒に言葉にしてもらってください。基準があれば、研修でその基準を使った評価の練習ができ、現場でも同じ基準で評価できます。同じ料金・同じ業務範囲でも、基準づくりから研修、振り返りまでつなげて設計してくれる担当者かどうかで、面接の質が変わります。

工数の見積もり方

面接官トレーニングの工数は、次の要素で変わります。

  1. 面接官の人数：研修や振り返りに参加する面接官の数
  2. 評価の基準があるか：基準がなければ、基準づくりから始める
  3. 同席の回数：実際の面接に何回同席して助言するか
  4. 振り返りの頻度：研修のあと、どのくらいの頻度で振り返りの場を設けるか

研修そのものは短い時間で終わりますが、同席と振り返りは、面接官の人数と回数に比例して工数が増えます。面接官の時間も社内の工数として見積もりに入れてください。面接官トレーニングの進め方は面接官トレーニングの進め方で書いています。

料金の形と効果の確かめ方

面接官トレーニングを外部に頼むときの料金の形は、研修一回ごと、研修と同席・振り返りをまとめた形、月額で継続して頼む形などがあります。エラベルでは、採用決定時に1名10万円（税別）という形で、担当者を選んで採用の実務を任せられる仕組みを用意しています。

効果は、次の点で確かめてください。

  • 評価のばらつき：同じ候補者に対する面接官どうしの評価のずれが減っているか
  • 候補者の反応：面接のあとの辞退が減っているか、面接で会社の印象がよくなったという声があるか
  • 入社後の定着：面接で評価の高かった人が、入社後に活躍しているか

エラベルの見解

面接官トレーニングで、もう一つ考えてほしいのは、面接は候補者が会社を選ぶ場でもあることです。面接官が候補者を評価することばかりに意識を向けると、候補者からは尋問のように感じられ、会社の印象が悪くなります。

研修では、評価の仕方と同じくらい、候補者に会社の魅力を伝え、候補者の疑問に答える力を身につけてください。候補者が面接を通じて会社をより知りたいと思えれば、承諾の割合も上がります。

まとめ

  • 面接官トレーニングは評価の基準づくり・研修・同席・振り返りに分ける
  • 研修だけでなく、現場に戻ってからの定着（同席と振り返り）に工数をかける
  • 研修には、採用選考時に配慮すべき事項や、性別・年齢にかかわりない均等な機会の決まりを含める
  • 研修の前に評価の基準を言葉にしておく
  • 効果は評価のばらつき、候補者の反応、入社後の定着で確かめる

よくある質問

面接官トレーニングを外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。面接官の人数、評価の基準づくりの有無、同席と振り返りの回数をそろえて見積もりを取り、比べてください。

研修を一回受ければ十分ですか

研修だけでは、現場の面接が変わらないことが多いです。研修のあとに実際の面接への同席や振り返りを重ねることで、学んだことが定着します。

面接で聞いてはいけないことはどこで確認できますか

都道府県労働局や厚生労働省の公正採用選考に関するページで、採用選考時に配慮すべき事項が案内されています。研修の資料にも、具体的な質問の例とあわせて含めてください。
