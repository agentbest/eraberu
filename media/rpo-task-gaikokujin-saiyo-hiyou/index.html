外国人の採用は、日本人の採用と同じ流れに加えて、在留資格の確認や、入社後の手続きといった独自の工程があります。募集や選考の進め方にも、言葉や文化の違いへの配慮が必要です。外国人採用の実務を外部に頼むことはできますが、在留資格の確認など、雇う会社が責任を持つべきことは外部に任せきりにできません。結論から書くと、外国人採用の外注は、募集・選考・在留資格の確認・入社後の手続きに分け、雇う会社に残る責任を押さえたうえで見積もると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。法令の扱いは一般的な整理です。在留資格の判断や申請などの個別の判断は、出入国在留管理庁や行政書士などの専門家にご確認ください。

工程に分ける

外国人採用の実務は、次の工程に分けられます。

工程中身担い手
募集外国人の候補者に届く媒体や経路で求人を出す。必要に応じて多言語で書く外部が担える
選考書類選考、面接、日本語の力や仕事の経験の確認外部が一部を担える。合否は社内
在留資格の確認候補者の在留資格で、予定している仕事ができるかを確かめる社内が責任を持つ。専門家の確認を受ける
入社後の手続き外国人雇用状況の届出、生活の立ち上げの支援社内が届出の責任を持つ。支援は外部が担える

外部に頼みやすいのは、募集と選考の一部、入社後の生活の支援です。在留資格の確認と外国人雇用状況の届出は、雇う会社の責任として社内で行う必要があります。詳しい切り分けは外国人採用の実務は代行に出せるかで書いています。

雇う会社に残る責任

外国人を雇う会社には、法律で定められた責任があります。

出入国管理及び難民認定法第73条の2第1項は、事業活動に関し、外国人に不法就労活動をさせた者などを処罰の対象としています。同条第2項は、外国人の活動が在留資格に応じた活動に属しないことなどを知らなかったことを理由として、処罰を免れることはできないとし、ただし過失がないときはこの限りでないとしています。つまり、候補者の在留資格で予定している仕事ができるかを確かめずに雇うと、知らなかったでは済まない場合があるということです。

また、労働施策総合推進法第28条第1項は、事業主は、新たに外国人を雇い入れた場合またはその雇用する外国人が離職した場合には、その者の氏名、在留資格、在留期間などについて確認し、厚生労働大臣に届け出なければならないと定めています。

外部に採用の実務を頼む場合も、在留資格の確認と届出の責任は雇う会社にあると考えて、社内で誰が担うかを決めておいてください。在留資格で認められる仕事の範囲の判断は、専門家に確認することをおすすめします。

エラベルの見解

外国人採用の外注で多いのは、募集と面接は外部がうまく進めたのに、在留資格の確認で内定が止まるケースです。候補者の経歴や持っている在留資格では、予定していた仕事ができないことが内定の直前に分かり、選考がやり直しになる。候補者にも会社にも負担が大きくなります。

外部に頼むなら、書類選考の段階で在留資格の種類と期限を確かめ、予定している仕事と合うかの見通しを立てる工程を含めてもらってください。判断が難しい場合は、早い段階で専門家に確認する流れを決めておくと、内定の直前で止まることを防げます。同じ料金・同じ業務範囲でも、在留資格の見通しを早めに立ててくれる担当者かどうかで、選考の手戻りが変わります。

工数の見積もり方

外国人採用の実務の工数は、次の要素で変わります。

  1. 募集の経路と言語：多言語での求人や、外国人向けの媒体を使うか
  2. 候補者の所在：日本にいる候補者か、海外から呼び寄せる候補者か。海外からの場合、手続きの期間と工数が増える
  3. 在留資格の手続き：在留資格の変更や新たな申請が必要か
  4. 入社後の支援の範囲：住まいや生活の立ち上げ、日本語の学習などの支援をどこまで行うか

海外から候補者を呼び寄せる場合や、在留資格の申請が必要な場合は、入社までの期間が長くなり、その間の連絡や手続きの工数も増えます。外国人採用の進め方は外国人採用の実務の進め方で書いています。

料金の形と品質の見方

外国人採用の実務を外部に頼むときの料金の形は、採用が決まったときの支払い、月額固定、募集や選考の一部をまとめた形などがあります。在留資格の申請の手続きは、外部の採用の担当者ではなく、資格を持つ専門家が担う領域であることにも注意してください。

品質は、次の点で確かめられます。

  • 在留資格の見通しの早さ：選考の早い段階で、在留資格と仕事の合い方が確かめられているか
  • 候補者への説明の分かりやすさ：条件や手続きが、候補者に分かる言葉で説明されているか
  • 入社後の定着：入社した外国人の社員が、職場に定着しているか

エラベルの見解

外国人採用で、もう一つ考えてほしいのは、受け入れる職場の準備です。採用がうまくいっても、職場の側に受け入れる準備がないと、入社した人が孤立して辞めてしまうことがあります。仕事の指示が伝わりにくい、相談できる人がいない、といったことが原因になります。

採用の前に、仕事の手順を分かりやすく書く、相談役の社員を決める、といった準備を進めてください。外部に入社後の支援を頼む場合も、職場の準備と組み合わせることで、定着の効果が高まります。

よくある質問

外国人採用の実務を外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。募集の経路、候補者の所在、在留資格の手続きの有無、入社後の支援の範囲をそろえて見積もりを取り、比べてください。

在留資格の確認も外部に任せられますか

確認の作業を手伝ってもらうことはできますが、在留資格で予定している仕事ができるかを確かめる責任は、雇う会社にあると考えてください。判断が難しい場合は、出入国在留管理庁や行政書士などの専門家にご確認ください。

外国人雇用状況の届出は誰が行いますか

労働施策総合推進法第28条により、外国人を雇い入れた事業主、または雇用する外国人が離職した事業主が届け出ることとされています。届出の方法や期限は、厚生労働省やハローワークの案内で確認してください。
