採用広報・オウンドメディアを外注したときの費用と工数の目安｜記事の本数より「取材に出る社員の時間」が効く

採用広報やオウンドメディアは、求人広告では伝えきれない会社の様子や働く人の姿を、記事や動画で発信する取り組みです。候補者が応募する前に会社を知る手がかりになり、選考に進んだ人の理解を深める効果もあります。外部に頼めば、企画や執筆の手間は減りますが、記事の中身をつくるのは社員の話です。結論から書くと、採用広報の外注は、企画・取材・執筆・公開・振り返りの工程に分け、取材に出る社員の時間という見えにくい工数まで含めて見積もり、成果を応募や面談での反応で確かめると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

工程に分ける

採用広報の仕事は、次の工程に分けられます。

工程中身担い手
企画誰に、何を伝えるかを決め、記事の題材を選ぶ外部が案を出せる。最終的な方向は社内が決める
取材社員に話を聞く、職場の写真を撮る外部が進められる。社員は話す時間が要る
執筆記事を書く、動画を編集する外部が担える
確認と公開内容に誤りがないか確かめ、公開する社内の確認が要る
振り返り記事の読まれ方、応募や面談での反応を見る外部が集計できる。方針は社内が決める

外部に頼むと、企画の案出し、執筆、公開の作業は大きく減ります。一方で、取材に応じる社員の時間と、公開前の確認の時間は社内に残ります。記事の本数を増やすほど、この社内の時間も増えます。詳しい切り分けは採用広報・オウンドメディアは代行に出せるかで書いています。

見えにくい工数は社員の取材の時間

採用広報の見積もりで見落としやすいのが、取材に出る社員の時間です。記事を一本つくるには、取材の日程を合わせ、話をし、原稿を確認するという時間が、取材される社員にかかります。現場の社員は本業で忙しいため、取材の時間が確保できず、記事の公開が遅れることもよくあります。

見積もりを取るときは、次の点を確かめてください。

  1. 記事の本数と頻度：月に何本、どのくらいの頻度で公開するか
  2. 取材の対象：一本あたり何人の社員に話を聞くか
  3. 確認の流れ：誰が、何回確認するか
  4. 写真や動画の有無：撮影の手間がかかるか

本数を多く約束する見積もりは、取材を減らして、手元の資料だけで書いている可能性があります。取材の時間を減らしたい場合は、一回の取材で複数の記事の素材を集める、質問を事前に渡しておく、といった工夫を外部に提案してもらうと、社員の負担を抑えながら記事の質を保てます。社員の声が入らない記事は、他社の採用記事と見分けがつきにくくなります。

エラベルの見解

採用広報の外注で多いのは、記事の本数は増えたのに、応募が増えないケースです。記事が誰に向けたものなのかが決まっておらず、会社の紹介や社員の一般的な話が並んでいるだけ、ということがよくあります。

外部に頼むなら、最初に「どんな人に、どんな疑問に答えるために書くのか」を一緒に決めてください。たとえば、エンジニアの候補者が面接でよく聞く質問に答える記事、未経験の人が入社後の育成について知りたいことに答える記事、といった形です。同じ料金・同じ業務範囲でも、候補者の疑問から記事を企画してくれる担当者かどうかで、記事が採用に役立つかが変わります。

内容の正確さ

採用広報の記事で、仕事の内容や働き方、条件に触れる場合は、内容の正確さに気をつけてください。職業安定法第5条の4は、労働者の募集を行う者などが、広告等により労働者の募集に関する情報を提供するときは、虚偽の表示または誤解を生じさせる表示をしてはならず、正確かつ最新の内容に保たなければならないと定めています。

採用広報の記事は、求人そのものではなくても、候補者が会社の働き方を判断する材料になります。社員の話を記事にするときに、一部の部署の働き方を会社全体のことのように書いていないか、古い情報が残っていないかを、公開前と定期的に確かめてください。採用広報の進め方は採用広報・オウンドメディアの進め方で書いています。

料金の形と成果の確かめ方

採用広報を外部に頼むときの料金の形は、記事の本数ごと、月額固定、企画から運用までの一式などがあります。エラベルでは、採用決定時に1名10万円（税別）という形で、担当者を選んで採用の実務を任せられる仕組みを用意しています。

成果は、記事の閲覧数だけでなく、次の点で確かめてください。

  • 応募者の反応：応募の理由や面接で、記事を読んだと話す候補者がいるか
  • 面談や面接での理解：候補者が会社のことを理解したうえで面接に来ているか
  • 辞退の理由の変化：会社のことが分からないことによる辞退が減っているか

エラベルの見解

採用広報で、もう一つ考えてほしいのは、選考の中で記事を使うことです。記事は、公開して読まれるのを待つだけでなく、スカウトの文面に添えたり、面接の前に候補者に送ったりすることで、より役に立ちます。

外部に記事をつくってもらったら、スカウトや面接の担当者にも記事を共有し、候補者に合わせて送る仕組みをつくってください。選考の中で使われる記事は、本数が少なくても採用に効きます。

まとめ

  • 採用広報は企画・取材・執筆・確認と公開・振り返りに分ける
  • 見えにくい工数は取材に出る社員の時間。本数を増やすほど社内の時間も増える
  • 記事はどんな人のどんな疑問に答えるかから企画する
  • 働き方や条件に触れるときは、正確で最新の内容に保つ
  • 成果は閲覧数だけでなく、応募者の反応や面接での理解で確かめ、記事を選考の中で使う

よくある質問

採用広報・オウンドメディアを外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。記事の本数、取材の有無、写真や動画の有無をそろえて見積もりを取り、比べてください。

記事は何本くらい出せばよいですか

本数より、候補者の疑問に答える記事がそろっているかが大切です。面接でよく聞かれる質問や、辞退の理由になりやすい点から、答えるべき題材を洗い出し、そこから本数を決めるのが現実的です。

社員が取材に協力してくれない場合はどうすればよいですか

取材の目的と、記事がどう採用に役立つかを社員に伝えることが大切です。取材の時間を短くする、質問を事前に渡す、といった工夫で負担を減らすこともできます。協力してくれた社員の記事が採用につながったことを共有すると、次の協力も得やすくなります。
