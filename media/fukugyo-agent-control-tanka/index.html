人材紹介会社のコントロールの副業単価の目安と決め方｜紹介会社の数と推薦の量で時間が決まる

人材紹介会社のコントロールは、依頼先の会社に代わって、複数の紹介会社とのやりとりの窓口を担う仕事です。紹介会社に求人の中身を説明し、推薦された候補者の書類を確認して返答し、選考の結果を伝え、紹介会社ごとの成果を記録する。人材紹介会社とやりとりした経験がある人事経験者に向いた副業です。この仕事の時間は、件数よりも、紹介会社の数と推薦の量で決まります。結論から書くと、人材紹介会社のコントロールの単価は、紹介会社の数・推薦の量・選考の連絡にかかる時間から組み立て、月額で受けるなら上限を決めておくと、無理のない単価になります。

単価は依頼先や業務の範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

時間を決めるもの

人材紹介会社のコントロールの作業は、次のように分けられます。

作業中身時間のかかり方
求人の説明紹介会社の担当者に、求人の中身や求める人物像を伝える紹介会社の数に比例する
推薦への返答推薦された候補者の書類を確認し、選考に進めるかを返答する推薦の数に比例する
選考の連絡面接の日程調整、結果の連絡、不合格の理由の共有選考に進んだ人数に比例する
紹介会社ごとの記録推薦の数、通過率、採用の実績を記録する紹介会社の数と推薦の量で変わる
関係の維持定期的な情報共有、紹介会社の見直しの提案一定の頻度で発生する

単価を組み立てるときは、依頼先が契約している紹介会社の数と、月の推薦の量を最初に確かめてください。紹介会社が多く、推薦も多い依頼先ほど、時間がかかります。そのうえで、1か月にかかる時間を見積もり、自分の時間単価を掛けて単価の根拠にしてください。時間単価の考え方は本業年収と副業単価の関係で書いています。

月額で受けるときの上限

人材紹介会社のコントロールは、毎月継続して発生する仕事なので、月額で受けることが多くなります。月額で受けるときは、次の上限を決めておいてください。

  1. 紹介会社の数：何社までの窓口を担うか
  2. 推薦への返答の件数：月に何件までの推薦に返答するか
  3. 対応の時間帯：推薦への返答を、どの時間帯に、どのくらいの速さで行うか

推薦への返答は、速さが大切です。返答が遅れると、紹介会社は依頼先への推薦の優先順位を下げ、良い候補者を他の会社に回すようになります。副業で受ける場合、本業の時間中は返答できないことがあるため、返答の目安を正直に伝えてください。

エラベルの見解

人材紹介会社のコントロールの単価で多い失敗は、紹介会社が増えるたびに作業が増え、月額が見合わなくなることです。依頼先が採用を急ぐと、契約する紹介会社を増やすことがあります。紹介会社が増えれば、求人の説明や関係の維持の作業も増えますが、月額は最初のまま、ということがよくあります。

受ける前に、紹介会社の数が増えたときに月額を見直すことを、契約で決めておいてください。担当する側から見て、紹介会社ごとの成果を記録して、成果の出ていない紹介会社の見直しを依頼先に提案できる人ほど、作業を増やさずに採用の結果を上げられ、依頼先からの信頼も高まります。

自分で候補者を紹介しない

人材紹介会社のコントロールを担っていると、知り合いの中に依頼先に合いそうな人がいて、紹介したくなることがあります。ここで気をつけたいのが、職業安定法の決まりです。

職業安定法第4条は、「職業紹介」を、求人及び求職の申込みを受け、求人者と求職者との間における雇用関係の成立をあっせんすることと定め、手数料や報酬を受けて行うものを「有料の職業紹介」としています。そして第30条は、有料の職業紹介事業を行おうとする者は、厚生労働大臣の許可を受けなければならないと定めています。

紹介会社とのやりとりの窓口を担うことと、自分で候補者を見つけて依頼先に紹介し、その紹介に対して報酬を受けることは別の話です。後者は、内容によっては職業紹介に当たる可能性があります。知り合いを紹介したい場合は、報酬の有無や形を含めて、依頼先とどう扱うかを確かめ、必要に応じて都道府県労働局などに確認してください。人材紹介会社のコントロールの仕事の中身は人材紹介会社のコントロールの副業の仕事で書いています。

単価を上げていくには

人材紹介会社のコントロールで単価を上げていくには、次のことが役に立ちます。

  • 紹介会社ごとの成果を見える化する：推薦の数、通過率、採用の実績を紹介会社ごとに並べ、依頼先に報告する
  • 不合格の理由を具体的に伝える：紹介会社に理由を具体的に伝えることで、次の推薦の質を上げる
  • 紹介会社の見直しを提案する：成果の出ている紹介会社に絞ることを提案し、依頼先の採用の効率を上げる

エラベルの見解

人材紹介会社のコントロールで、もう一つ考えてほしいのは、紹介会社と依頼先の両方から信頼されることです。紹介会社にとっても、依頼先の窓口が明確で、返答が早く、不合格の理由が具体的な会社は、推薦しやすい相手です。窓口を担う人が紹介会社から信頼されると、良い候補者が優先して推薦されるようになります。

この信頼は、単価には直接表れにくいものの、依頼先の採用の結果を大きく左右します。結果が出れば、依頼先からの評価が上がり、単価の見直しや、他の採用業務への広がりにつながります。

まとめ

  • 人材紹介会社のコントロールの単価は、紹介会社の数・推薦の量・選考の連絡の時間から組み立てる
  • 月額で受けるなら、紹介会社の数、推薦への返答の件数、対応の時間帯の上限を決める
  • 紹介会社が増えたときに月額を見直すことを契約で決めておく
  • 自分で候補者を紹介して報酬を受けることは、職業紹介の許可に関わる可能性がある。依頼先と確かめ、必要に応じて労働局に確認する
  • 紹介会社ごとの成果の見える化と、見直しの提案で単価を上げる

よくある質問

人材紹介会社のコントロールの副業単価の相場はいくらですか

依頼先や業務の範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。紹介会社の数と月の推薦の量を確かめ、1か月にかかる時間を見積もって、自分の時間単価を掛けて単価の根拠をつくってください。

推薦への返答はどのくらいの速さが求められますか

依頼先や紹介会社によって違いますが、返答が遅れると紹介会社の推薦の優先順位が下がることがあります。副業で受ける場合は、返答の目安を最初に依頼先と紹介会社に伝えておいてください。

知り合いを依頼先に紹介してもよいですか

報酬を受けて紹介する場合、内容によっては職業紹介に当たる可能性があり、有料の職業紹介事業には厚生労働大臣の許可が必要です。報酬の有無や形を含めて依頼先とどう扱うかを確かめ、必要に応じて都道府県労働局などに確認してください。
