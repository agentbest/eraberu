「面接官のトレーニングをしてほしい」と頼まれて、面接の心得を一時間の講義にすると、その場では頷かれ、翌週の面接は元のままです。講義が悪いのではなく、面接官が困っているのは「心得」ではなく、「この求人で、何を聞き、どう記録し、自分が決めるのか」という具体だからです。結論を先に書くと、**面接官トレーニングは、講義ではなく、段ごとの一枚の読み合わせ・模擬の場面で掘る練習・実際の記録の振り返りの三つで行い、面接官の三つの不安（何を聞くか・どう記録するか・自分が決めるのか）に順に答え、一回で終わらせず月に一度の振り返りで続けます。**一枚の作り方は[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)に、質問集と評価シートは[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)と[評価シートを作る](/media/fukugyo-skill-hyouka-sheet/)に、研修を案件として受ける形は[研修講師の副業の実務](/media/fukugyo-kensyu-koushi-shigoto/)に書いています。ここでは、面接官向けに絞ります。

## 講義が残らない理由

| 講義の中身 | 面接官に起きること |
|---|---|
| 「面接官は会社の顔です」 | 分かっている。行動は変わらない |
| 「バイアスに気をつけましょう」 | 何をどう気をつけるかが分からない |
| 一般的な質問例の一覧 | この求人で何を聞くかは分からない |
| 評価の心得 | 記録の形が無ければ、印象のまま |
| 一回きり | 翌週の面接で戻る |

面接官が欲しいのは、自分が次に出る面接で使える一枚と、それを使ってみた後に「これでよかったか」を確かめる場です。トレーニングは、その二つを渡すことです。

## 三つの中身

| 中身 | やること | 時間の考え方 |
|---|---|---|
| 一枚の読み合わせ | 段ごとの一枚（役割・観点・聞き方・基準・聞かないこと・記録の形）を、面接官と一緒に読む | 短く。面接の直前でもできる |
| 模擬の場面で掘る練習 | 担当者が候補者役で、一般論の答えを返す。面接官が掘る問い（状況・役割・判断・行動・結果）で事実に戻す | 観点一つ分でよい |
| 実際の記録の振り返り | 面接官が書いた評価シートを、面接官と一緒に読む。事実の欄が事実か、判断が基準に照らしているか | 月に一度。一人分でよい |

三つのうち、最も効くのは三つ目です。自分の記録を読み返すと、「事実のつもりが印象だった」「基準に無い理由で判断していた」と、面接官自身が気づきます。担当者が指摘するより、自分で気づくほうが残ります。

### エラベルの見解

担当する側から見ると、面接官トレーニングで最も差がつくのは、面接官の「三つの不安」に順番どおりに答えているかです。面接官が最初に持つ不安は、「何を聞けばよいか」「どう記録すればよいか」「自分が合否を決めるのか」の三つで、講義はこの三つに答えていません。一枚の読み合わせで一つ目に、記録の形で二つ目に、「観点ごとの判断は面接官、最終の決定は決める人」と役割を分けて三つ目に答えると、面接官は安心して面接に出られます。三つ目に答えないと、面接官は「自分が落としたら責任を取らされる」と思い、全員を「迷う」にします。エラベルで担当者を選ぶ企業には、「面接官は、自分が合否を決めるのだと思っていませんか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、読み合わせの最初に、「あなたが決めるのは観点ごとの三択で、最終の決定は〇〇さんです」と、決める人の名前を出して伝えること。

## 三つの不安に答える順

| 順 | 不安 | 答え方 |
|---|---|---|
| 一 | 何を聞けばよいか | 一枚の観点と主の問い。「聞き方はご自身の言葉で」 |
| 二 | どう記録すればよいか | 評価シートの事実と判断。「事実は候補者の言葉で、判断は三択」 |
| 三 | 自分が決めるのか | 「観点ごとの三択はあなた、最終は〇〇さん」。多数決にしないことも |

この順で答えた後に、「聞いてはいけない問い」を伝えます。最初に禁止事項から入ると、面接官は身構え、残りを聞かなくなります。

## 聞いてはいけない問いの扱い方

性別、年齢、国籍、家族の状況、出身地、宗教や思想、健康の状態などに触れる問いは、募集や採用で法令上の決まりがあると一般に整理されています。トレーニングでは、法令の解釈を担当者が説明せず、「一覧にある問いは聞かない。雑談で出やすい言い回しも一覧にある。聞いてしまったら記録せず、〇〇さんに伝える」と、行動だけを伝えます。一覧の範囲と根拠は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

面接官から「なぜ聞いてはいけないのか」と問われたら、「法令上の整理があり、詳細は専門家の確認によります。ここでは聞かない、で揃えます」と答え、担当者が解釈を語りません。

## 経営者や現場の責任者を「受講者」にしない

| やりがちなこと | 起きること | 代わりに |
|---|---|---|
| 経営者を研修に呼ぶ | 来ないか、来ても「自分は分かっている」で終わる | 最終の一枚を個別に持って行き、五分で読み合わせる |
| 現場の責任者に「面接の基本」を教える | 現場の経験を否定されたと感じる | 現行の問いを一枚に取り込み、「〇〇さんの問いは観点〇〇に入れました」と伝える |
| 全員を一部屋に集める | 段が違う面接官に同じ話をすることになる | 段ごとに、その段の一枚で |

トレーニングは「教える」ではなく「揃える」です。揃える相手が上位の人ほど、個別に、短く、その人の言葉を取り込んで行います。導入の順番は[構造化面接を導入する](/media/fukugyo-skill-kouzou-mensetsu/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「トレーニングは一回やれば終わり」というものです。実際には、一回の読み合わせで変わるのは最初の数回の面接だけで、記録の振り返りを続けないと戻ります。月に一度、面接官一人につき一人分の評価シートを一緒に読む。それだけで、事実の欄が事実になり、判断が基準に沿うようになります。担当者の稼働は月に短時間で済み、依頼側にとっても負担が軽い。「研修」という言葉で大きな枠を取るより、「振り返り」という小さな枠を続けるほうが残ります。受ける側がその場で使える判断としては、トレーニングの提案を「初回の読み合わせ＋月一回の振り返り」の形で出し、効果は「記録が揃うこと」までに限定して伝えること。「面接の精度が上がる」「良い人が採れる」とは言いません。

## 記録の振り返りのやり方

| 手順 | 中身 |
|---|---|
| 一 | 面接官が書いた評価シートを一人分、面接官と一緒に開く |
| 二 | 事実の欄を読む。「これは候補者が語った言葉ですか、印象ですか」と聞く |
| 三 | 判断の欄を読む。「この判断は、基準のどの一行に照らしましたか」と聞く |
| 四 | 迷うが付いた観点で、次の段に引き継がれたかを見る |
| 五 | 面接官が「次はこう聞く」と自分で言ったことを、一行で残す |

担当者は評価しません。問いを投げ、面接官が自分で気づく形にします。振り返りの記録に、候補者の氏名は書かず、観点と気づきだけを残します。振り返りの形は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)の「振り返る形」と共通です。

## 踏み込まない線

| 線 | 理由 |
|---|---|
| 面接官の「適性」を評価しない | 揃えるのは型。人の評価は依頼側の人事の領域 |
| 合否の判断を担当者が示さない | 決めるのは依頼側 |
| 法令の解釈を語らない | 行動（聞かない）だけを伝え、根拠は専門家へ |
| 面接官の人事評価に使わない | トレーニングの記録が評価に使われると、面接官が本音で振り返らなくなる |

トレーニングの記録の扱いは、依頼側と最初に決めます。「振り返りは面接官の評価には使わない」を合意に入れます。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「一時間の研修を」と言う | 「初回は一枚の読み合わせと模擬で短く、月一回の振り返りで続けます」と形を提案する |
| 面接官が集まらない | 集めない。段ごとに、面接の直前に個別で読み合わせる |
| 模擬の練習を嫌がる | 観点一つ分、二〜三分で。担当者が候補者役で一般論を返すだけ |
| 振り返りで面接官が防御的になる | 担当者が評価しない形を先に伝える。「私が指摘するのではなく、一緒に読みます」 |
| 経営者が面接の型を使わない | 最終の一枚を「決め手と候補者の迷いへの答え」に絞り、個別に五分で |

## まとめ

- 講義は残らない。面接官が欲しいのは**次の面接で使える一枚と、使った後に確かめる場**
- 中身は**一枚の読み合わせ・模擬で掘る練習・実際の記録の振り返り**の三つ。最も効くのは振り返り
- 面接官の不安は**何を聞くか・どう記録するか・自分が決めるのか**。この順で答え、決める人の名前を出す
- 聞いてはいけない問いは**行動だけを伝え、解釈を語らない**。個別の判断は専門家にご確認ください
- 経営者と現場の責任者は**受講者にせず、個別に短く、その人の言葉を取り込む**
- **一回で終わらせず、月に一度の振り返り**。効果は「記録が揃う」までに限定して伝える
- 面接官の適性評価・合否・法令の解釈に踏み込まない。振り返りは人事評価に使わない

## よくある質問

### 面接官が多く、全員の振り返りをする稼働がありません

段ごとに一人ずつ、月に一人分で足ります。全員を毎月見る必要はなく、順番に回します。振り返った面接官が、同じ段の他の面接官に「事実の欄はこう書く」と伝える形になれば、担当者の稼働はさらに減ります。振り返りの記録（観点と気づき）を共有の場所に置き、他の面接官も読める形にします。

### 依頼側から「面接官の合格・不合格を判定してほしい」と言われました

面接官の適性の評価はしません。「揃えるのは型で、人の評価は御社の人事の領域です」と伝えます。代わりに、「記録が揃っているか（事実の欄が事実か、判断が基準に沿っているか）」を段ごとに見て、揃っていない段の一枚を直す提案をします。個人の評価ではなく、型の改善として返します。

### トレーニングをしたのに、入社後のミスマッチが減りません

トレーニングで変わるのは記録の揃い方までで、ミスマッチの原因は要件・募集・内定後にもあります。入社後のずれを、評価シートの記録に戻って見ると、「観点が足りなかった」「迷うを引き継がずに通した」「要件そのものがずれていた」のどれかが見えます。それを要件の一枚と面接の設計に戻します。原因の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。トレーニングの効果を「ミスマッチが減る」と約束していないことが、ここで効きます。
