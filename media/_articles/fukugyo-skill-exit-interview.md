退職が決まった人に、直属の上司が「理由は何か」と聞くと、「一身上の都合です」で終わります。本人は、上司に本当の理由を言う理由が無く、言えば残りの日々が気まずくなり、言っても何も変わらないと思っています。退職面談は、聞き方を変えれば材料が出る場で、材料が出れば、次の人が同じ場所で辞めることを防げます。結論を先に書くと、**退職面談の設計は、目的を引き止めではなく「次の人が同じ理由で辞めないための材料」に置き、直属の上司ではない人が、決まった直後と最終日の前の二回聞き、「入社前に思っていたことと違ったこと」「辞めようと思った最初の時期」「残る条件があったとすれば」の型で本人の言葉を引き出し、記録は分類と要約に留め、結果を離職の分析に戻し、退職の手続きや条件には触れない形で行います。**離職の分析は[離職の分析](/media/fukugyo-skill-rishoku-bunseki/)に、理由の集め方の考え方は[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に、退職の場面への関わりの線は[退職や解雇の場面への関わり方](/media/fukugyo-taishoku-kanyo/)に書いています。ここでは、面談の設計の型に絞ります。

## 「一身上の都合」しか出ない理由

| 面談の形 | 本人に起きること |
|---|---|
| 直属の上司が聞く | 上司が理由の一部かもしれず、言えない |
| 「理由は何ですか」と直接聞く | 「一身上の都合」が最も無難な答え |
| 引き止めの場になっている | 本音を言うと引き止められると思い、言わない |
| 最終日の直前に一回だけ | 手続きの話に紛れ、時間が無い |
| 記録が上司に渡る | 言えば残りの日々が気まずい |
| 言っても何も変わらない | 過去の退職者の声が使われた形跡が無い |

本音が出るのは、「聞く人が上司でない」「引き止めの場でない」「記録が上司に渡らない」「言ったことが次の人のために使われる」の四つが揃ったときです。

## 目的は「次の人のための材料」

| 目的にしないこと | 目的にすること |
|---|---|
| 引き止め | 引き止めは別の場で、上司と経営者が。面談に持ち込まない |
| 本人の評価や責任の追及 | 本人の言葉を、そのまま材料として受け取る |
| 手続きの説明 | 手続きは人事の別の場で |
| 上司へのフィードバック | 個人の話は上司に渡さず、傾向として仕組みに戻す |

目的を最初に本人に伝えます。「引き止めではなく、次に入る人が同じことで困らないように、お聞きします」。この一言で、本人の話す内容が変わります。

### エラベルの見解

担当する側から見ると、退職面談で最も差がつくのは、「辞める理由」を直接聞かず、「入社前に思っていたことと違ったこと」から聞けるかです。受ける側は、「なぜ辞めるのですか」と聞き、「一身上の都合」を受け取って終わります。「入社前に、この会社について思っていたことで、実際は違ったことはありますか」と聞くと、本人は理由ではなく事実を語り、それが求人票・面接・受け入れのずれの材料になります。次に「辞めようと思った最初の時期はいつ頃ですか」と聞くと、離職の分析の「時期」が埋まります。エラベルで担当者を選ぶ企業には、「退職面談で、『なぜ辞めるか』以外の問いを用意していますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、面談の型の最初の問いを「違ったこと」にし、「理由」という言葉を型から外すこと。

## 誰が、いつ聞くか

| 決めること | 中身 |
|---|---|
| 誰が | 直属の上司ではない人。人事、または別の部門の責任者。担当者が聞くかは契約と依頼側の決まりで |
| 一回目 | 退職が決まった直後。「違ったこと」「最初の時期」を中心に |
| 二回目 | 最終日の前。「残る条件があったとすれば」「次の人に伝えたいこと」。一回目より本音が出やすい |
| 時間 | 短く。三十分以内 |
| 場所 | 上司や同僚から離れた場所。オンラインでも |

二回に分けるのは、決まった直後は感情が動いていて、最終日の前は落ち着いて話せることが多いからです。一回しか取れないなら、最終日の前の一回にします。

## 聞く型

| 順 | 問い | 引き出したいもの |
|---|---|---|
| 一 | 「入社前に思っていたことで、実際は違ったことはありますか」 | 求人票・面接・内定後・受け入れのずれ |
| 二 | 「辞めようと思った最初の時期は、いつ頃ですか。そのとき何がありましたか」 | 時期と、きっかけの場面 |
| 三 | 「その後、続けようと思い直したことはありますか。何があれば続けられたと思いますか」 | 残る条件。直す場所の候補 |
| 四 | 「仕事の中身、上司との接点、この先の見通し、働き方のうち、一番大きかったのはどれですか」 | 理由の分類 |
| 五 | 「次に入る人に、伝えておいたほうがよいことはありますか」 | 求人票と受け入れの材料 |

全部を聞かなくて構いません。本人が話したいところを深く聞きます。掘り方は[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)の「状況・役割・判断・行動・結果」と同じで、評価はしません。「私的な事情」は、本人が自分から言った範囲で受け取り、聞き出しません。

## 記録の形

| 欄 | 中身 | 書かないこと |
|---|---|---|
| 番号 | 一覧の番号。氏名は別に | 氏名 |
| 時期 | 入社後の節目のどこか | — |
| 違ったこと | 本人の言葉の要約。段階（求人票・面接・内定後・受け入れ）の分類 | 個人の詳細 |
| 最初の時期ときっかけ | 要約 | 上司や同僚の名前 |
| 残る条件 | 要約 | — |
| 理由の分類 | 仕事の中身・上司との関係・見通し・働き方・私的な事情・その他 | 私的な事情の中身 |
| 次の人への伝言 | 要約 | — |

記録は人事が扱い、直属の上司には渡しません。上司に戻すのは、部門の傾向として、離職の分析の一枚を通してです。記録の共有の範囲と保管は、依頼側の決まりに従います。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「退職面談で聞いたことを、上司に伝えて改善してもらう」というものです。実際には、個人の話が上司に渡ると、次の退職者は「言えば上司に伝わる」と知り、話さなくなります。渡すのは、離職の分析の一枚（時期・段階・理由の分類の件数）で、「〇部門で、上司との接点が理由の分類に〇件」という傾向までです。傾向で直す場所（1on1の型、評価の面談の型）を決め、上司はその仕組みで動きます。受ける側がその場で使える判断としては、記録の形に「上司の名前」の欄を作らず、面談の冒頭で「お話は上司には渡しません。傾向として仕組みを直す材料にします」と本人に伝えること。

## 結果を戻す先

| 材料 | 戻す先 |
|---|---|
| 「違ったこと」の段階 | 早期なら、求人票・面接・内定後・受け入れの一枚。[離職の分析](/media/fukugyo-skill-rishoku-bunseki/) |
| 「最初の時期」 | 時期の分類。定着の節目の見直し。[定着まで見る](/media/fukugyo-skill-teichaku/) |
| 「残る条件」 | 直す場所の候補。等級・評価・1on1・役割 |
| 「理由の分類」 | それ以降の離職の分析 |
| 「次の人への伝言」 | 求人票の「任せる仕事」「一緒に働く人」の実態の言葉。オンボーディングの「変わったこと」 |

戻す先が決まっていると、面談が「聞いて終わり」になりません。月に一度、退職面談の記録を分類し、離職の分析の一枚を更新します。

## 触れない線

| 線 | 理由 |
|---|---|
| 退職の手続き、条件、有給の扱い | 人事と専門家の領域。面談に混ぜない |
| 引き止め、条件の提示 | 別の場で、上司と経営者が。面談は材料を聞く場 |
| ハラスメントなど深刻な話が出たとき | 面談の中で扱わず、依頼側の窓口につなぐ手順を型に。判断は依頼側と専門家 |
| 本人の評価、責任の追及 | しない |
| 担当者が本人と直接面談するか | 契約と依頼側の決まりで。基本は依頼側の人事が行い、担当者は型と記録の形 |

退職の手続きや条件、深刻な事案の扱いには法令上の整理があると一般に整理されています。依頼側の決まりと専門家の確認に従い、担当者は関与しません。個別の判断は専門家にご確認ください。線の詳細は[退職や解雇の場面への関わり方](/media/fukugyo-taishoku-kanyo/)と[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 直属の上司が面談している | 人事か別の部門の責任者に。上司は引き止めの場を別に |
| 「理由は」と聞いている | 型の一（違ったこと）から。「理由」の言葉を外す |
| 記録が上司に渡っている | 人事に留め、傾向だけを分析の一枚で |
| 一回しか取れない | 最終日の前の一回に |
| 本人が「特にありません」 | 「次に入る人に伝えたいこと」から。話しやすい |
| 深刻な話が出た | 面談を止め、窓口につなぐ手順で。担当者は判断しない |

## まとめ

- 「一身上の都合」しか出ないのは、**上司が聞き、引き止めの場で、記録が上司に渡り、使われない**から
- 目的は**次の人が同じ理由で辞めないための材料**。本人に最初に伝える
- **直属の上司ではない人が、決まった直後と最終日の前の二回**
- 型は**「違ったこと」→「最初の時期」→「残る条件」→「分類」→「次の人への伝言」**。「理由」を直接聞かない
- 記録は**分類と要約**。氏名と上司の名前を書かず、人事に留める
- 結果は**離職の分析の一枚に戻し**、直す場所を決める
- **手続き・条件・引き止め・深刻な事案には触れない**。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側から「退職面談で引き止めてほしい」と言われました

引き止めと材料の面談は分けます。引き止めは、上司と経営者が、条件や役割の提示を含めて行う場で、担当者は関わりません。担当者が設計するのは材料の面談で、「引き止めの場ではない」と本人に伝えることで本音が出ます。両方を一つの面談でやると、どちらも成り立ちません。引き止めの判断と条件は依頼側で、法令上の整理が関わる場合は専門家に確認します。

### 退職者が「話したくない」と言います

無理に聞きません。「次に入る人に伝えたいことが一つでもあれば」と、一つだけ聞き、無ければ終えます。話したくない人の記録は「面談辞退」とし、分析では「不明」に分類します。話したくない退職者が続くなら、面談の設計（誰が聞くか、記録の扱いの伝え方）に問題がある可能性があるので、型を見直します。

### 担当者が直接、退職者と面談する契約を頼まれました

依頼側の決まりで認められ、本人が「会社の外の人に話す」ことに同意していれば、担当者が聞く形もあり得ます。その場合も、記録の形は同じで、個人の詳細を担当者の手元に残さず、分類と要約を依頼側の人事に渡します。本人の私的な事情、健康、ハラスメントに関わる話が出たら、担当者は扱わず、依頼側の窓口につなぎます。範囲は契約に書きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。
