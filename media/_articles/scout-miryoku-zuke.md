スカウトで、自社の魅力を伝えたい。ただ、書こうとすると「成長できる環境」「裁量がある」「アットホームな職場」しか出てこない。どの会社も同じことを書いていて、候補者には届かない。社内で「うちの魅力は何か」を話し合っても、抽象語が並ぶだけで終わる。結論を先に書くと、**魅力が言葉にならないのは、「自社の魅力」を探しているからです。「自社の魅力」は、誰にとっての魅力かが無く、抽象語になります。代わりに、「この候補者が、この役割で、得るもの」を探します。それは、候補者の経歴と状況によって違い、事実の場面で書けます。「成長できる」ではなく、「入社三か月で〇〇を一人で担当し、半年で△△を決める側になる」。事実の場面が、候補者にとっての魅力です**。自社紹介の範囲は[自社紹介はどこまで書くか](/media/scout-kaisha-shoukai/)に、他社との比較は[他社と比べて自社が良いのか分からない](/media/rpo-hikaku-dekinai/)にまとめています。

## 魅力が言葉にならない構造

自社の魅力が言葉にならないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「自社の魅力」を探している | 「誰にとって」が無い。全員向けの魅力は、抽象語になる |
| 抽象語で考えている | 「成長」「裁量」「風通し」。どの会社も言えて、候補者には比べる材料にならない |
| 社内の「良いところ」を並べている | 社員にとっての良さと、候補者にとっての魅力は違う |
| 事実の場面が無い | 「裁量がある」と言うが、「何を決められるか」の場面が出てこない |
| 候補者の側から見ていない | 候補者が、いま何に困り、何を求めているかを考えていない |
| 全員に同じ魅力を送っている | 動いていない経験者にも、若手にも、同じ「成長できる」 |
| 「魅力＝良いところ」と思っている | 大変なところ、変えたいところも、候補者によっては魅力（「変える役割」を求める人） |
| 魅力を探す手順が無い | 会議で「うちの魅力は」と話しても、出てこない |

構造の大半は、「誰にとっての魅力か」が無いことです。候補者を置けば、言葉になります。

## 「自社の魅力」と「候補者にとっての魅力」の違い

二つは、違うものです。

| | 自社の魅力 | 候補者にとっての魅力 |
|---|---|---|
| 主語 | 会社 | この候補者 |
| 問い | 「うちの良いところは何か」 | 「この候補者は、この役割で、何を得るか」 |
| 出てくる言葉 | 抽象語（成長、裁量、風通し） | 事実の場面（三か月で〇〇を担当、△△を決める側に） |
| 誰に届くか | 誰にも（全員向けは、誰の判断の材料にもならない） | この候補者に |
| 相手で変わるか | 変わらない | 変わる。経歴と状況で、得るものが違う |
| 他社との違い | 出にくい（どの会社も同じ言葉） | 出やすい（この候補者にとって、他社では得られないもの） |
| 書く場所 | — | 一段落目の「役割との対応」、二段落目の「役割」、三段落目の「人と実態」 |

違いの要点は、「主語を候補者にする」ことです。「うちは成長できる」ではなく、「あなたは、この役割で、三か月後にこうなる」。

「自社の魅力」を探す会議は、抽象語で終わります。「この候補者（具体的な一人）が、この役割で何を得るか」を考える作業は、事実で書けます。

## 候補者が得るものの六つの型

候補者が役割で得るものは、六つの型に分かれます。候補者の経歴と状況で、どの型が魅力になるかが変わります。

| 型 | 中身 | 魅力になる候補者 | 事実の場面の例の形 |
|---|---|---|---|
| 一、決められる範囲が広がる | 前職より、自分で決められることが増える | 前職で裁量が小さかった人、承認の階層に疲れた人 | 「〇〇を自分で決め、承認は責任者一人で翌日に」 |
| 二、担う範囲が広がる | 一つの職種に閉じず、隣の領域も担える | 分業に閉じていた人、幅を広げたい人 | 「△△に加えて、□□の企画も担う」 |
| 三、経験が新しい場面で活きる | いまの経験を、別の段階・別の事業で使える | 同じことの繰り返しに飽きた人、経験を試したい人 | 「〇〇のご経験を、立ち上げの段階で」 |
| 四、次の役割が見える | 一〜三年後に、どの役割に進めるか | 頭打ちを感じている人、次を探している人 | 「一年後に〇〇の責任者、その先に△△」 |
| 五、働き方が変わる | 時間、場所、柔軟さの実態が、いまより合う | 働き方に困っている人 | 「リモート中心で、週に一度の出社」 |
| 六、人と環境が変わる | 誰と働くか、どういう空気か、経営者との距離 | 人間関係に疲れた人、経営者と近くで働きたい人 | 「事業責任者の〇〇と直接。経営者と週に一度話す」 |

六つの型の要点は、「候補者の経歴と状況で、どれが刺さるかが違う」ことです。前職で裁量が小さかった人には一が、分業に閉じていた人には二が、働き方に困っている人には五が。

六つを全部書くと、長くなり、どれも薄くなります。候補者ごとに、一つか二つを選びます。

## 事実の場面で書く方法

選んだ型を、抽象語ではなく、事実の場面で書きます。

| 抽象語 | 事実の場面 |
|---|---|
| 成長できる | 「入社三か月で〇〇を一人で担当し、半年で△△を決める側になります」 |
| 裁量がある | 「提案の内容と価格を担当者が決め、承認は責任者一人で翌日に下ります」 |
| 幅広い経験ができる | 「営業に加えて、〇〇の企画から実行まで担います」 |
| キャリアアップできる | 「一年後に〇〇の責任者を、その先に△△の立ち上げを任せる予定です」 |
| 働きやすい | 「リモート中心で、週に一度の出社。〇〇の制度を実際に使っている人が△名」（数字は自社の記録） |
| アットホーム、風通しが良い | 「事業責任者の〇〇と直接やり取りし、経営者とは週に一度話します」 |
| やりがいがある | 「〇〇の顧客の△△の課題を、自分の提案で解決する場面が、月に数回あります」 |
| 安定している | 「〇〇の事業を△年続けていて、この役割はその中心です」（年数は自社の事実） |

書き方の要点は、「場面・時期・人・数」で書くことです。「三か月で」「〇〇を」「責任者一人で」「週に一度」。数字は自社の記録から、出典を明記できるものだけ。

事実の場面は、「入社した人の実際」から取ります。「入社して三か月で〇〇を担当した人がいる」という事実があれば、書けます。無ければ、書きません。良く見せた場面は、面談か入社後に「違う」と分かり、離れます。

### エラベルの見解

相談で最も多い失敗は、「スカウトの文面に『成長できる環境』『裁量がある』『風通しが良い』を書き続けて、返信が来なかった。社内で『うちの魅力は』を三回会議したが、同じ言葉しか出なかった」というものです。主語が会社で、抽象語でした。「入社三か月の〇〇さんが、いま何を担当しているか」を聞き、「三か月で△△を一人で担当し、半年で□□を決める側になった」と事実の場面で書いたら、同じ会社、同じ役割で、返信が来ました。魅力は、会議で探すものではなく、入社した人の実際にありました。

見ていて差がつくのは、担当者が「入社した人の実際」を聞くかどうかです。「御社の魅力は何ですか」と経営者に聞いて抽象語を受け取る担当者と、「入社して三か月の方は、いま何を担当していますか。一年の方は」と、実際の場面を聞く担当者がいます。後者の文面は、事実で書かれ、候補者に届きます。

発注側にできるのは、「うちの魅力は」の会議をやめて、担当者に「入社した人の三か月、半年、一年の実際」を渡すことです。

## 候補者ごとに変える部分

魅力は、候補者ごとに変えます。変え方です。

**経歴から、「いま何に困っていそうか」を読む。** 大きな会社で長い→裁量と承認の遅さ。同じ職種で長い→幅と次の役割。転職が数回→人と環境、働き方。経歴は、困りごとの手がかりです。ただし、推測を断定しない。

**六つの型から、一つか二つを選ぶ。** 読んだ困りごとに対応する型。「裁量が小さそう」なら一、「幅を広げたそう」なら二。

**選んだ型を、一段落目の「役割との対応」に入れる。** 「〇〇のご経験が、当社の□□を決める役割で活きる。承認は責任者一人で翌日に」。魅力は、一段落目の対応の中に。

**二段落目の役割の記述で、選んだ型の場面を厚くする。** 型が一（決められる範囲）なら、「何を決めるか」を具体的に。型が四（次の役割）なら、「なぜ今」と「一年後」を。

**三段落目の人と実態で、型を裏付ける。** 型が六（人と環境）なら、一緒に働く人を厚く。型が五（働き方）なら、実態を。

**返信が来たら、二通目で確認する。** 「〇〇に困っていらっしゃると想像しましたが、いかがですか」。推測を確認し、ずれていれば直す。

**推測が外れても、失礼にならない書き方。** 「〇〇のご経験から、△△を求めていらっしゃるのではと考えました。違っていたら、ぜひ教えてください」。断定せず、仮説として。

変える部分の要点は、「経歴から困りごとを読み、六つから選び、一段落目の対応に入れる」ことです。全文を変えるのではなく、選ぶ型と、その場面だけを変えます。

## 魅力を探す聞き取り

「候補者にとっての魅力」の材料は、社内の会議ではなく、聞き取りで集めます。

| 聞く相手 | 聞くこと | 得られるもの |
|---|---|---|
| 入社して三か月・半年・一年の人 | 「いま何を担当していますか」「入社時と比べて、何ができるようになりましたか」「前の会社と比べて、違うところは」 | 事実の場面（型一〜四）。他社との違い |
| 他社から入社した人 | 「前の会社に無くて、ここにあるものは」「前の会社にあって、ここに無いものは」 | 候補者にとっての魅力と、隠さない大変さ |
| 辞退しなかった人 | 「他社と迷って、なぜここを選びましたか」 | 決め手になった型 |
| 辞退した人（差し支えなければ） | 「決め手は何でしたか」 | 自社に足りない型、または伝えられていなかった型 |
| 現場の責任者 | 「この役割で、自分で決められることは何ですか」「入社した人は、何か月で何を任せられますか」 | 型一と四の事実 |
| 経営者 | 「この役割の人と、どのくらい話しますか」「なぜこの役割が要りますか」 | 型六と、役割の位置 |
| 面接で候補者 | 「何を重く見て会社を選んでいますか」 | 候補者の層ごとに、刺さる型の傾向 |

聞き取りの要点は、「入社した人と、辞退しなかった人」です。この二つが、最も確かな「候補者にとっての魅力」の源です。社内の会議で出る「うちの魅力」より、「他社から来て、ここにあると感じたもの」のほうが、候補者に届きます。

聞き取った内容は、本人の同意のうえで、文面と採用サイトに使います。

## 外注する場合の範囲

魅力の言語化を、スカウト代行に出す場合の範囲です。

**出せる工程。** 現状の文面の抽象語の点検、「自社の魅力」から「候補者にとっての魅力」への置き換えの整理、聞き取りの設計と実行（入社した人、他社から来た人、辞退しなかった人、現場の責任者、経営者）、六つの型ごとの事実の場面の整理（役割ごと）、抽象語を事実の場面に書き換える作業、候補者ごとの型の選び方の基準（経歴から困りごとを読む型）、一段落目の対応への入れ方の型、二通目での確認の文面、面接での「何を重く見るか」の記録と層ごとの傾向の蓄積、採用サイトへの反映。

**社内に残す判断。** 公開してよい事実の範囲（入社した人の話の公開は本人の同意）、事実の場面の正確さの確認（良く見せない）、聞き取りに応じる社員の指名、型の承認。

**外注の効きどころ。** 魅力の言語化は、社内では「うちの魅力は」の会議で抽象語に終わりやすい領域です。担当者が「候補者にとって」に置き換え、入社した人に聞き、事実の場面に書き換えれば、言葉になります。担当者は複数の会社のスカウトを見ているので、「この抽象語は、この事実の場面で書ける」「この層には、この型が刺さる」の型を持ち込めます。ただし、事実の場面は自社の実際からで、担当者が作ることはできません。

**外注しても動かない場合。** 社内が抽象語を譲らない、入社した人への聞き取りを認めない、事実より良く見せることを求める。社内の判断で、代行を替えても直りません。

魅力は、候補者を主語にし、事実の場面で書けば、言葉になります。外注は、置き換えと聞き取りと書き換えを担う手段です。

### エラベルの見解

担当する側から見ると、魅力の相談で最も多いのは、「大変なところを隠そうとする」ことです。「うちは忙しい」「まだ仕組みが無い」を、魅力の反対だと思って書かない。ただ、「仕組みが無いから、自分で作れる」「忙しいが、三か月で任される」は、変える役割や早い成長を求める候補者にとっては、魅力です。

大変なところを隠すと、面談か入社後に分かり、離れます。「仕組みがまだ無く、作る側に回っていただきます」と書けば、それを求める候補者が来て、続きます。魅力は、良いところだけではありません。

発注側にできるのは、「大変なところ」も、「それを求める候補者にとっての魅力」として、事実で書くことを許すことです。

- 言葉にならないのは**自社の魅力を探す・抽象語・社員の良いところ・場面が無い・候補者の側から見ない・全員に同じ・良いところだけ・手順が無い**構造
- 「自社の魅力」（主語が会社、抽象語、全員向け、他社と同じ）と「候補者にとっての魅力」（主語が候補者、事実の場面、相手で変わる、他社との違いが出る）は違う。主語を候補者に
- 六つの型は**決められる範囲・担う範囲・経験が新しい場面で活きる・次の役割・働き方・人と環境**。候補者の経歴と状況で刺さる型が違う。一つか二つを選ぶ
- 事実の場面は**場面・時期・人・数**で。「成長できる」→「三か月で〇〇を担当、半年で△△を決める側に」。入社した人の実際から。良く見せない
- 候補者ごとに**経歴から困りごとを読み・六つから選び・一段落目の対応に入れ・二段落目と三段落目で裏付け・二通目で確認・仮説として書く**
- 聞き取りは**入社した人・他社から来た人・辞退しなかった人・辞退した人・現場の責任者・経営者・面接の候補者**。入社した人と辞退しなかった人が最も確か
- 外注できるのは**点検・置き換え・聞き取り・型ごとの事実の整理・書き換え・選び方の基準・入れ方の型・確認の文面・傾向の蓄積・サイトへの反映**。社内に残るのは**公開の範囲・正確さの確認・社員の指名・型の承認**

## よくある質問

### 「成長できる」「裁量がある」以外に、本当に魅力がありません

「自社の魅力」を探しているから、抽象語しか出ません。「入社して三か月の〇〇さんは、いま何を担当していますか」「他社から来た△△さんが、前の会社に無くてここにあると感じたものは」と、入社した人の実際を聞きます。「三か月で〇〇を一人で担当」「承認が翌日に下りる」「経営者と週に一度話す」のような事実の場面が、ほぼ例外なく出てきます。それが、候補者にとっての魅力です。会議で探すのではなく、入社した人に聞きます。

### 候補者ごとに魅力を変えると、会社の一貫性が無くなりませんか

会社の事実は一つで、変えません。変えるのは、「六つの型のうち、この候補者にどれを前に出すか」です。裁量が小さかった人には「決められる範囲」を、働き方に困っている人には「働き方の実態」を、同じ会社の事実の中から選んで前に出します。全部の型を全員に書くと、長くなり、どれも薄くなります。一貫性は事実にあり、前に出す型は候補者で変えます。

### 大変なところは、書かないほうがよいですか

隠すと、面談か入社後に分かり、離れます。「仕組みがまだ無く、作る側に回っていただきます」「立ち上げの段階で、忙しい時期があります」は、変える役割や早い成長を求める候補者にとっては魅力で、それを求めない候補者には、応募の前に判断してもらえる材料です。大変なところを事実で書き、「それを求める人」に届けます。良いところだけを書いた文面は、合わない人を集め、合う人に届きません。
