育児で数年、仕事から離れていた。以前は人事の仕事をしていたが、今は本業に戻る前の準備として、あるいは、本業に戻りながら少しずつ、副業で人事の経験を活かしたい。ただ、空白の期間があり、最新の道具も分からず、稼働の枠も小さい。売れるものがあるのか。結論を先に書くと、**育児からの復職で副業を始めるなら、離れていた期間を「空白」として説明するのではなく、「離れる前の人事の経験」と「育児中に身についた段取りと時間の使い方」を、「今の稼働の枠で何ができるか」に組み替えて売ります。依頼側が知りたいのは、空白の理由ではなく、「この範囲を、この稼働で、任せられるか」です。空白の説明より、枠と範囲の明示が先です。**育児との両立の設計は[子育てと両立する](/media/fukugyo-kodomo/)に、時間帯が読めない前提の業務の選び方は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)に、経験が浅いときの案件は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)にまとめています。

## この経歴の何が売れるか

育児からの復職で売れるものは、二つに分かれます。離れる前の経験と、育児中に身についたものです。

| 売れるもの | 中身 | 依頼側にとっての価値 |
|---|---|---|
| 離れる前の人事の経験（工程） | 求人票の作成、スカウトの運用、応募者の対応、面接の設計、入社の手続きなど、担当していた工程 | 工程の経験は、数年離れても消えない。型を持っている |
| 離れる前の人事の経験（判断） | 「この職種はこう探す」「この段階でこう見る」という判断の観点 | 判断の観点は、道具が変わっても使える |
| 育児中に身についた段取り | 限られた時間で優先順位をつけ、予定が崩れても立て直す | 副業の稼働は細切れで、段取りの力がそのまま効く |
| 育児中に身についた時間の使い方 | 早朝や決まった時間帯に集中して作業する | 稼働の時間帯が固定でき、依頼側が予定を組みやすい |
| 育児中に触れた採用の外側の視点 | 保育園や地域の集まりで見た、働く側の事情。復職する側の目線 | 育児中の候補者や、復職者の採用で、候補者の事情が分かる |
| 復職を考える側の目線 | 自分が復職の条件を考えた経験 | 依頼側が育児中の人材を採用するときの、求人票と条件の設計に効く |

売れるものの要点は、「離れる前の工程と判断の経験は、数年で消えない」ことです。道具は変わりますが、「求人票は仕事の中身を先に書く」「面接の前に評価の観点を揃える」という型と判断は、道具に関係なく使えます。空白を気にして経験を小さく見せると、依頼側にも小さく見えます。離れる前の工程を、そのまま棚卸しします。棚卸しの仕方は[副業用の職務経歴書](/media/fukugyo-shokumu-keirekisho/)に、プロフィールの書き方は[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

## 売りにくい点とその扱い

育児からの復職で売りにくい点は三つあり、それぞれ扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 空白の期間 | 「感覚が鈍っているのでは」「すぐに動けるか」 | 空白の理由を長く説明しない。「〇年まで人事で△△を担当。育児で離れ、〇年から副業で再開」と一行で。その後に、今できる工程を並べる |
| 最新の道具を知らない | 「今の採用管理の仕組みやスカウト媒体を使えるか」 | 道具は依頼側のものに合わせると伝える。「道具は御社のものに合わせます。工程と判断は持っています」。始める前に、主要な道具の画面を一度見ておく |
| 稼働の枠が小さく、時間帯が読めない | 「突発で止まるのでは」「日中に動けないのでは」 | 枠と時間帯を先に示す。「早朝と、火・木の夜。週〇時間。子どもの体調で止まる日は朝に連絡し、翌稼働日に再開」。止まる前提で受けられる工程を選ぶ |

扱い方の要点は、「空白の説明を一行で済ませ、その後に今できる工程を並べる」ことです。空白を長く説明すると、依頼側の注意が空白に向きます。一行で済ませ、「今、この工程を、この枠でできる」に注意を向けます。依頼側が判断するのは、空白ではなく、範囲と枠です。道具の学び直しは[学び直しの進め方](/media/fukugyo-gakushuu/)に、採用管理の仕組みの扱いは[ATSを扱えると何が変わるか](/media/fukugyo-ats-skill/)に、止まる日の伝え方は[子育てと両立する](/media/fukugyo-kodomo/)に整理しています。

### エラベルの見解

担当する側から見ると、育児からの復職で副業を始めて続いている人と、最初の案件が取れない人の差は、経験の長さや空白の長さではなく、「空白の説明に力を使っているか、範囲と枠の明示に力を使っているか」です。取れない人は、プロフィールの最初に空白の理由と不安を書き、依頼側は「本人が不安なら」と感じています。続いている人は、離れる前の工程を並べ、今の枠と時間帯と止まる日の扱いを明示し、依頼側は「この範囲をこの枠で頼める」と判断しています。

見ていて差がつくのは、育児中に身についた段取りを、依頼側に伝わる言葉に言い換えているかです。「育児で忙しかった」では伝わりませんが、「限られた時間で優先順位をつけ、予定が崩れても立て直す習慣がある。稼働は早朝に固定し、その中で仕上げる」と言えば、依頼側は細切れの稼働で回せる担当者だと分かります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠と時間帯を小さくても明確に示している担当者に、その枠で十分な依頼側がついています。育児からの復職は、空白ではなく、枠の明示で始まります。

## 案件の探し方

育児からの復職の段階に合わせて、探す案件と探し方が変わります。

| 段階 | 探す案件 | 探し方 |
|---|---|---|
| 本業に戻る前（準備の時期） | 締め切りが柔らかく、時間帯が読めなくても回る工程。求人票の改善、スカウト文面の作成、面接官向けの準備資料 | 登録先に、枠と時間帯と止まる日の扱いを登録する。以前の職場や知人に、範囲と枠を一言で伝える |
| 本業に時短で戻った直後 | 一件だけ、週に数時間。本業と子育ての枠が固まるまで増やさない | 登録先の一件だけ。本業の副業の許可を確認してから |
| 本業と子育ての枠が固まった後 | 枠を少し広げ、以前の工程に近い範囲へ | 登録先の条件を更新する。以前の依頼側に再開を伝える |
| 復職者の採用に関わる案件 | 育児中の人材や復職者を採用する依頼側の、求人票と条件の設計、候補者の事情に合わせた面談の設計 | 自分の復職の経験を、範囲の一言に入れる。「育児中の人材の採用に、当事者の目線で」 |

探し方の要点は、「本業に戻る前の準備の時期に、締め切りが柔らかい工程で一件受ける」ことです。本業に戻ってから副業を始めると、本業と子育ての枠が固まる前に副業が乗り、崩れます。戻る前に一件受けて、稼働の感覚と道具に慣れておけば、戻った後も枠を守れます。本業の許可は、戻る前に確認しておきます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、本業の許可は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。育児からの復職で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 離れる前の工程の経験 | 工程の経験があれば、未経験の単価にはならない | 空白を理由に、自分から単価を下げない |
| 稼働の枠の小ささ | 枠が小さいことは、単価を下げる理由にならない。月額の総額が小さくなるだけ | 時間あたりの単価と、月の総額を分けて考える |
| 止まる日があること | 止まる日の扱いを先に決めていれば、単価には影響しない | 締め切りに余裕を持たせる形で受ける |
| 最新の道具を知らないこと | 道具の習得の時間を、最初の案件では単価に含めない形もある | 「最初の一か月は道具に慣れる期間として、この単価で」と自分から提案してもよいが、二か月目からは戻す |
| 復職者の採用の当事者の目線 | 特定の依頼側には、経験として評価される | 範囲の一言に入れる |
| 契約の形 | 時間で受けるか、成果物で受けるか | 時間帯が読めないなら、成果物で受ける方が、止まる日の影響が小さい |

単価の要点は、「空白を理由に、自分から単価を下げない」ことです。空白があると、「安くしないと取れない」と感じますが、依頼側が払うのは工程と判断に対してで、空白に対してではありません。離れる前の工程の経験があるなら、その工程の単価で受けます。枠が小さい分は、月の総額が小さくなるだけで、時間あたりの単価を下げる理由にはなりません。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、契約の形は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

育児からの復職で副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、離れる前の工程を全部書き出す | 担当していた工程と、判断の観点。空白は一行で |
| 二、育児中に身についたものを、依頼側に伝わる言葉にする | 段取り、時間の使い方、復職者の目線 |
| 三、今の稼働の枠と時間帯と止まる日の扱いを決める | 家族と共有してから。[子育てと両立する](/media/fukugyo-kodomo/) |
| 四、枠で回る工程を選ぶ | 締め切りが柔らかく、日中の対応が要らない工程 |
| 五、本業に戻る前なら、本業の副業の許可を先に確認する | 戻ってから始めない |
| 六、主要な道具の画面を一度見ておく | 使えなくてよい。「見たことがある」状態に |
| 七、登録先に、範囲と枠と時間帯と止まる日の扱いを登録する | 空白の説明は一行 |
| 八、一件を小さく受け、丁寧に終える | 続けられることを確かめてから広げる |

順番の要点は、「一」の、離れる前の工程を全部書き出すことを最初にやることです。空白があると、自分の経験を小さく見積もり、「大したことはしていなかった」と書き出しを省きます。書き出せば、工程の数と判断の観点が見え、売れるものが分かります。空白の期間より、離れる前の経験の方が長いことがほとんどです。棚卸しの仕方は[副業用の職務経歴書](/media/fukugyo-shokumu-keirekisho/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「育児で離れていたから、未経験と同じ扱いで、安く受けるしかない」というものです。実際には、離れる前の工程と判断の経験は消えておらず、依頼側が払うのはその工程に対してです。空白を理由に単価を下げて受けると、その単価が続き、復職後に枠を広げても単価が戻りません。工程の単価で、小さい枠から受ける。それが、復職後に続く形です。

順番として、離れる前の工程を全部書き出し、育児中に身についたものを依頼側に伝わる言葉にし、稼働の枠と時間帯と止まる日の扱いを家族と決め、枠で回る工程を選び、本業の許可を確認し、道具の画面を一度見て、登録先に範囲と枠を登録し、一件を小さく受けて丁寧に終える。この順番で、育児からの復職の副業は、「空白を埋めるもの」から「経験を枠に合わせて売るもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、枠が小さくても範囲と時間帯を明示している担当者に、その条件で十分な依頼側がついています。復職の副業は、空白の説明ではなく、範囲と枠の明示から始まります。

## まとめ

- 育児からの復職で売れるのは**離れる前の工程と判断の経験、育児中に身についた段取りと時間の使い方、復職者の当事者の目線**
- **空白の説明は一行で済ませ、今できる工程と枠を並べる**。依頼側が判断するのは空白ではなく範囲と枠
- 売りにくい点は**空白・最新の道具・稼働の枠**。道具は依頼側のものに合わせ、枠と止まる日の扱いは先に示す
- 案件は**本業に戻る前の準備の時期に、締め切りが柔らかい工程で一件**から。本業の許可は戻る前に確認
- 単価は**空白を理由に自分から下げない**。工程の単価で、枠が小さい分は月の総額が小さくなるだけ
- 順番は**工程の棚卸し → 言い換え → 枠と止まる日の扱い → 工程の選択 → 許可 → 道具の確認 → 登録 → 一件を小さく**

## よくある質問

### 離れていた期間に、採用の道具や媒体が変わっていて、ついていけるか不安です

道具は依頼側のものに合わせるので、事前に使いこなせる必要はありません。「道具は御社のものに合わせます。工程と判断は持っています」と伝え、始める前に主要な道具の画面を一度見ておけば足ります。依頼側が担当者に求めるのは、道具の操作ではなく、「求人票をどう直すか」「候補者をどう見るか」の判断です。判断は道具が変わっても使えます。道具の学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に、採用管理の仕組みは[ATSを扱えると何が変わるか](/media/fukugyo-ats-skill/)に整理しています。

### 本業への復職と副業を、同時に始めてもよいですか

避けることをお勧めします。本業に戻った直後は、本業と子育ての枠が固まっておらず、そこに副業が乗ると崩れます。本業に戻る前に一件を小さく受けて稼働の感覚を取り戻すか、本業に戻って枠が固まってから（数か月後）副業を始めるかの、どちらかにします。戻る前に始めるなら、本業の副業の許可を先に確認します。両立の設計は[本業と副業の両立｜崩れる原因と防ぎ方](/media/fukugyo-ryouritsu/)に書いています。

### 離れる前の人事の経験が短く、売れるものが少ない気がします

離れる前の経験が短くても、担当した工程が一つでもあれば、その工程は売れます。求人票の作成だけ、応募者の対応だけ、でも構いません。工程を一つに絞り、「この工程を、この枠で」と示せば、依頼側はその工程を頼めます。経験が短い場合の案件の選び方は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に、人事の肩書きがない場合は[人事未経験が副業でできること](/media/fukugyo-mikeiken-jinji-fukugyo/)に整理しています。
