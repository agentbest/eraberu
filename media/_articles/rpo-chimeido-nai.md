媒体に求人を出す。同じ職種で、誰もが知っている会社の求人が隣に並ぶ。候補者は、知っている会社から見る。自社の求人は、開かれもしない。「知名度が無いから、応募が来ない」。結論を先に書くと、**知名度は、短期間では上がりません。上げようとするより、「知らない会社に応募する理由」を求人票と経路で作ります。候補者は、知っている会社に応募しているのではなく、「自分に合いそうだと分かる会社」に応募しています。分かる材料を出せば、知らない会社でも応募は来ます**。スカウトで知名度の無さを乗り越える書き方は[知名度のない会社のスカウト](/media/scout-chimeido-nai-kaisha/)に、待遇で大手に勝てない場合は[待遇で大手に勝てない](/media/rpo-kyugyo-jouken/)にまとめています。

## 知名度が無い会社で起きていること

知名度が無い会社の採用では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 求人が開かれない | 媒体の一覧で、知っている会社名から見られる。知らない会社名は飛ばされる |
| 開かれても、応募に進まない | 会社名で検索しても情報が無い。「どんな会社か分からない」で離れる |
| 応募が来ても、条件で決めている人が多い | 会社を知らないので、条件だけで比べている。条件で負ければ終わり |
| 面接で「御社を初めて知りました」と言われる | 候補者は、自社を知らずに来ている。面接で一から説明する |
| 内定を出しても、家族や知人に反対される | 「聞いたことがない会社」で、周囲が不安になる |
| 「知名度を上げよう」に予算と時間が向く | 広告、SNS、記事。効果が出るまで時間がかかり、採用は待てない |
| 知名度のある会社と、同じ土俵で戦っている | 同じ媒体で、同じ書き方で、同じ条件で。知名度で負ける |

知名度が無いことは、変えにくい事実です。事実を変えようとするより、事実の上で応募が来る設計をします。

## 知名度の代わりになるもの

候補者が「知っている会社」に応募するのは、知っていることで安心できるからです。安心の材料は、知名度以外にもあります。

| 知名度の代わり | 中身 |
|---|---|
| 役割の明確さ | 「何を決める役割か」「誰と働くか」「どこまで担うか」。役割が明確なら、会社を知らなくても、自分がやることが分かる |
| 一緒に働く人の顔 | 誰と働くかが見える。写真と、具体的な話。会社を知らなくても、人を知れば安心する |
| 事業の中身 | 「何をしている会社か」を、一般の人が分かる言葉で。業界の中では知られていても、一般には知られていないことが多い |
| 取引先や実績 | 誰と仕事をしているか。公開できる範囲で。取引先の知名度が、自社の信用になることがある |
| 働き方の実態 | リモート、時間、休日、裁量。実態が具体的なら、判断の材料になる |
| 選考の速さと丁寧さ | 返信が当日、面接が一週間以内。知らない会社でも、対応が良ければ「ちゃんとした会社」と受け取る |
| 経営者の言葉 | 何のためにこの事業をやっているか、なぜこの役割が要るか。経営者の顔と言葉は、小さい会社の強み |
| 候補者を知っている人の紹介 | 社員の紹介、取引先の紹介。知っている人からの紹介は、知名度より強い |

知名度は、これらの材料が無くても応募が来る「代わり」です。材料があれば、知名度は要りません。

## 求人票で「知らない会社」を乗り越える

求人票の書き方で、「知らない会社」の壁を下げます。

**一行目で、事業と役割を言い切る。** 「〇〇（一般の人が分かる言葉）をしている会社で、△△を決める役割です」。会社名で興味を引けないなら、事業と役割で引きます。

**「なぜこの役割が要るのか」を書く。** 「事業がこう変わり、この役割が要るようになった」。理由があれば、候補者は「自分が要る場所」と感じます。

**一緒に働く人を、具体的に書く。** 「〇〇の経験がある責任者と、△△を担当するメンバー二名と働きます」。人が見えれば、会社を知らなくても想像できます。

**事業の中身を、一般の言葉で書く。** 業界の用語を使わない。「〇〇業界向けの△△」ではなく、「〇〇をする人が、△△で困っていることを、□□で解決している」。

**取引先や実績を、公開できる範囲で書く。** 取引先の社名が公開できるなら書く。できないなら、「〇〇業界の大手数社」のように。実績の数字は自社の記録から、出典を明記して。

**経営者の言葉を、短く入れる。** 「この事業を始めた理由」「この役割に来てほしい人」。一段落で。

**条件は、正確に。** 知名度が無い分、条件を良く見せたくなりますが、実態と違えば面接で離れます。

**選考の流れと速さを書く。** 「書類の判断は三日以内、面接は二回、内定まで三週間」。知らない会社でも、「対応が速い」は安心の材料です。

求人票は、「知っている会社の求人」と同じ書き方では負けます。知らない会社だからこそ、役割と人と理由で書きます。

## 知名度に頼らない経路

媒体の一覧で知名度のある会社と並ぶ経路は、不利です。並ばない経路を使います。

**スカウト型。** 候補者の一覧に並ぶのではなく、自社から候補者に届ける。「知らない会社」の壁は、文面の一段落目で乗り越えます。書き方は[知名度のない会社のスカウト](/media/scout-chimeido-nai-kaisha/)に書いています。

**社員の紹介。** 社員の知り合いは、社員を通じて会社を知っています。知名度は要りません。具体的に頼み、結果を戻します。

**取引先や知人の紹介。** 経営者や責任者の関係から。「こういう人を探している」と伝えておきます。

**紹介会社。** 紹介会社の担当者が、候補者に自社を説明します。担当者に会社と現場を理解してもらえば、知名度の代わりに担当者の言葉が働きます。理解してもらう方法は[紹介会社の推薦の質が低い](/media/rpo-agent-shitsu/)に書いています。

**職種や業界に特化した媒体。** 総合型の媒体より、特化型は「その職種を探している人」が見ていて、会社名より役割で見られます。

**業界の集まりや、勉強会。** 業界の中では知られている会社なら、業界の場で「採っている」と伝えることが効きます。

**カジュアル面談。** 応募の手前で、「話を聞く」だけの場を用意します。知らない会社に応募するのは重いですが、話を聞くのは軽いです。

経路の選び方は[どの媒体を使えばよいか分からない](/media/rpo-media-erabenai/)にも書いています。知名度が無い会社は、「並ばない経路」の比重を上げます。

### エラベルの見解

相談で最も多い失敗は、「知名度が無いので、まず知名度を上げようと、SNSと広告に半年の予算を使い、採用は止まったまま」というものです。半年後、SNSの閲覧は増えましたが、応募は変わりませんでした。知名度は、半年では上がりません。同じ半年で、求人票を役割と人と理由で書き直し、スカウトと社員の紹介に切り替えていれば、採れていました。知名度を上げることと、いま採ることは、別の仕事です。

見ていて差がつくのは、担当者が「知名度が無い前提で設計する」かどうかです。「知名度を上げましょう」と言う担当者と、「知名度は要りません。求人票の一行目を事業と役割にして、スカウトの一段落目で乗り越えて、面談で人を見せます」と、無い前提で組む担当者がいます。後者は、いま採れます。

発注側にできるのは、「知名度を上げたい」と「いま採りたい」を分けて、担当者には後者を依頼することです。

## 候補者が会社を調べたときの受け皿

求人を見た候補者は、会社名で検索します。そのときに何が出るかで、応募に進むかが決まります。

**会社のサイトに、採用の情報がある。** 事業の説明と、採用のページ。無ければ、「実態が無い会社」に見えます。

**採用ページに、候補者が知りたいことがある。** 役割、人、働き方の実態、選考の流れ。作り方は[採用サイトを作ったのに効果がない](/media/rpo-shanai-chinmoku/)に書いています。

**経営者の顔と言葉がある。** 小さい会社は、経営者が会社そのものです。経営者が見えれば、会社が見えます。

**口コミサイトに、書き込みがあれば、向き合っている。** 知名度が無い会社は、口コミが少ないか無いことが多いです。あれば、[口コミサイトの評価が低い](/media/rpo-kuchikomi-warui/)の向き合い方で。

**事業の情報が、検索で出る。** 取引先の事例、業界のメディアの記事、公的な認定など。公開できるものは、サイトに載せます。

**「何も出てこない」状態を無くす。** 検索して何も出なければ、候補者は応募しません。最低限、会社のサイトと採用ページ。

受け皿は、知名度を上げるためではなく、「調べた候補者が離れない」ためのものです。

## 知名度を少しずつ作る

いま採ることと分けて、知名度を少しずつ作る方法です。時間がかかるので、採用とは別の仕事として続けます。

**採用の場面で、会社を知った人を増やす。** 面接に来た候補者、スカウトに返信した候補者、カジュアル面談に来た人。採れなくても、会社を知った人が増えます。丁寧に対応すれば、その人が誰かに話します。

**社員が、外で話せる状態にする。** 社員が知り合いに「うちの会社は〇〇をしている」と一言で説明できる材料を持たせます。事業の説明の一文と、採用ページのリンク。

**業界の中での認知を、一般の認知に広げる。** 業界の中で知られているなら、業界の外の人にも分かる言葉で、事業を説明する材料を作ります。

**経営者が、外に出る。** 業界の集まり、勉強会、メディアの取材。経営者の顔が見える会社は、知られやすくなります。

**入社した人の話を、公開する。** 「こういう人が、こういう理由で入社した」。本人の同意のうえで。次の候補者への材料であり、知名度の積み上げでもあります。

**SNSや記事は、続けられる頻度で。** 効果が出るまで時間がかかります。担当者と頻度を決め、採用の成果と切り離して続けます。

知名度を作る仕事は、一年、二年の単位です。いまの採用は、知名度が無い前提で進めます。

## 外注する場合の範囲

知名度の問題を、採用代行に出す場合の範囲です。

**出せる工程。** 知名度の代わりになる材料の整理、求人票の書き直し（事業と役割の一行目、理由、人、実績、経営者の言葉）、経路の見直し（スカウト、社員の紹介、紹介会社、特化型媒体、カジュアル面談）、スカウト文面の作成と運用、紹介会社への会社の説明、受け皿の点検と足りないものの整理、採用ページの初版、面接での会社の説明の型、カジュアル面談の設計と進行。

**社内に残す判断。** 事業の説明の言葉の決定、公開できる取引先と実績の範囲、経営者の言葉、条件の決定、知名度を作る仕事の担当と予算。

**外注の効きどころ。** 知名度が無い会社の採用は、「知らない会社に応募する理由」を作る設計の問題です。担当者は複数の知名度の無い会社を見ているので、「役割と人と理由で乗り越える」型を持ち込めます。スカウトの一段落目、求人票の一行目、面談での説明は、担当者が作れます。

**外注しても動かない場合。** 経営者が「知名度を上げれば解決する」を譲らない、事業の説明を業界の言葉から変えない、条件を良く見せることをやめない。社内の判断で、代行を替えても直りません。

知名度は、いまの採用の前提であり、変える対象ではありません。外注は、前提の上で設計する速さを上げる手段です。

### エラベルの見解

担当する側から見ると、知名度の相談で最も多いのは、「事業の説明が、業界の言葉でしか書けない」ことです。「〇〇業界向けの△△ソリューション」。業界の人には分かりますが、候補者には分かりません。候補者が分からなければ、応募しません。

「〇〇をする人が、△△で困っていることを、□□で解決している」と、一般の言葉に直す。それだけで、求人票の一行目が変わり、スカウトの一段落目が変わります。知名度が無い会社の壁の半分は、言葉の壁です。

発注側にできるのは、担当者に「事業を、一般の人に一文で説明してほしい」と頼み、その一文を経営者が確認することです。

## まとめ

- 知名度が無いと**求人が開かれない・応募に進まない・条件で決められる・面接で初めて知られる・周囲に反対される・知名度向上に予算が向く・同じ土俵で戦う**
- 代わりになるのは**役割の明確さ・一緒に働く人・事業の中身・取引先と実績・働き方の実態・選考の速さ・経営者の言葉・紹介**
- 求人票は**一行目で事業と役割・なぜ要るか・人を具体的に・事業を一般の言葉で・実績を公開できる範囲で・経営者の言葉・条件は正確に・選考の流れ**
- 経路は**スカウト・社員の紹介・取引先と知人・紹介会社・特化型媒体・業界の場・カジュアル面談**。並ばない経路の比重を上げる
- 受け皿は**会社のサイト・採用ページ・経営者の顔と言葉・口コミへの向き合い・事業の情報・何も出ない状態を無くす**
- 知名度を作るのは**採用で知った人を増やす・社員が外で話せる・業界の外の言葉・経営者が外に出る・入社者の話・SNSは続けられる頻度で**。一年二年の仕事で、いまの採用と分ける
- 外注できるのは**材料の整理・求人票・経路・スカウト・紹介会社への説明・受け皿・面接の説明・面談**。社内に残るのは**事業の言葉・公開の範囲・経営者の言葉・条件・知名度の仕事の担当と予算**

## よくある質問

### 知名度を上げるために、SNSや広告に投資すべきですか

いまの採用とは分けて判断します。知名度は、SNSや広告で半年、一年で上がるものではなく、上がっても採用に直結するとは限りません。いまの採用は、知名度が無い前提で、求人票と経路と受け皿を設計します。知名度を作る仕事は、続けられる頻度で、採用の成果と切り離して続けます。両方をやるなら、予算と担当を分けます。

### 面接で「御社を初めて知りました」と言われます

知名度が無い会社では、当たり前のことです。動揺せず、「〇〇をしている会社で、この役割が要る理由はこうです」と、事業と役割と理由を一般の言葉で説明します。説明の型を面接官全員に渡し、誰が話しても同じ説明になるようにします。候補者が「知らなかったが、分かった」と帰れば、面接は成功です。「知らなかった」を「知っていてほしかった」と受け取らないことです。

### 内定者の家族が「聞いたことがない会社」と反対しています

候補者が家族に説明できる材料を渡します。会社のサイト、採用ページ、事業の一般の言葉での説明、取引先や実績の公開できる範囲、経営者の顔と言葉。「家族の方に見せてください」と、材料を渡します。必要なら、家族が同席する面談や、経営者との面談を用意します。周囲の不安は、材料が無いことから来ます。材料があれば、不安は減ります。
