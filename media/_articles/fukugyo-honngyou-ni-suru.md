副業のほうが本業より手応えがある。本業は組織の中で動きが遅く、副業は自分の判断で進められる。このまま副業を本業にしてしまいたい。ただ、それが正しい判断なのか、勢いなのかが分からない。結論を先に書くと、**副業を本業にするかどうかは、「副業のほうが楽しいか」ではなく、「本業を辞めたい理由」と「副業を本業にしたい理由」を分けて書き出し、副業を本業にしても消えない理由が残るかで決めます。辞めたい理由（上司が合わない、評価が低い、組織が遅い）で副業を本業にすると、本業にした副業の依頼側で同じことが起き、逃げ場がなくなります。本業にしたい理由（この範囲の仕事を軸にしたい、複数の会社で動く形が合う、判断を自分で持ちたい）が、辞めたい理由を除いても残るなら、本業にする判断の土台があります。理由を分けて書き出す。これが判断の最初の作業です。**独立の目安は[独立を考える目安](/media/fukugyo-dokuritsu/)に、副業をやめる判断は[副業をやめるとき](/media/fukugyo-yameru/)に、次の選択肢は[次の案件につなげる](/media/fukugyo-tsugi-e/)にまとめています。

## 「辞めたい理由」と「本業にしたい理由」を分ける

副業を本業にしたいという気持ちは、二つの理由が混ざっています。分けて書き出します。

| 種類 | 例 | 副業を本業にすると |
|---|---|---|
| 辞めたい理由（本業の側にある） | 上司や同僚と合わない、評価が低い、組織の判断が遅い、やりたい仕事ができない、給与が上がらない | 本業にした副業の依頼側にも、合わない担当者、遅い判断、範囲外の仕事はある。理由は消えず、場所が変わるだけ |
| 本業にしたい理由（副業の側にある） | この範囲の仕事を軸にしたい、複数の会社で動く形が合う、自分で判断して動きたい、範囲と成果が直接つながる働き方がよい | 副業を本業にすることで、その理由が満たされる。辞めたい理由がなくても残る理由 |
| 混ざっている理由 | 「副業のほうが楽しい」「副業のほうが認められる」 | 楽しさや認められ方の多くは、本業との対比で感じている。本業がなくなると、対比も消える |

分ける要点は、「辞めたい理由を除いても、本業にしたい理由が残るか」を見ることです。辞めたい理由だけで副業を本業にすると、本業にした副業で、合わない依頼側、遅い判断、範囲外の仕事に、今度は逃げ場なく向き合うことになります。本業にしたい理由が残るなら、それを軸に判断を進めます。残らないなら、本業の側の問題を、転職や異動で解決する方が先です。転職との関係は[副業から転職につながるか](/media/fukugyo-tenshoku-tsunagu/)に書いています。

## 副業を本業にすると変わる四つのこと

副業を本業にすると、副業のときには見えていなかった四つのことが変わります。

| 変わること | 副業のとき | 本業にすると |
|---|---|---|
| 一、案件を選ぶ基準 | 範囲と条件で選べる。合わなければ断れる | 収入のために、範囲や条件が合わない案件も受けたくなる。選ぶ基準が崩れやすい |
| 二、依頼側との関係 | 「本業がある人」として、対等に近い関係。依頼側も無理を言いにくい | 「この人はこれで生活している」と見られ、依頼側が範囲外や条件の引き下げを言いやすくなる |
| 三、成果と生活の距離 | 成果が出なくても、生活は本業の給与で回る | 成果が契約の更新に直結し、更新が生活に直結する。判断が短期に寄る |
| 四、自分の位置づけ | 「〇〇社の人事で、副業もしている」 | 「独立した人事」。本業の会社名という信用がなくなり、範囲と実績だけで見られる |

四つの要点は、「一」と「二」が、副業のときの強みを失わせることです。副業で依頼側から評価されていた理由の一つは、範囲と条件で案件を選び、合わなければ断れる余裕でした。本業にすると、その余裕が減り、選ぶ基準が崩れ、依頼側との関係も変わります。この変化に備えるのが、独立の三つの目安（入口の複数化、断っている案件、最悪の月の蓄え）で、目安を満たしていれば、本業にしても余裕を保てます。目安は[独立を考える目安](/media/fukugyo-dokuritsu/)に整理しています。

### エラベルの見解

担当する側から見ると、副業を本業にして続いている人と、本業にして苦しくなる人の差は、副業のときの手応えの大きさではなく、「辞めたい理由で決めたか、本業にしたい理由で決めたか」です。辞めたい理由で決めた人は、本業にした後、依頼側の担当者と合わない、依頼側の判断が遅い、範囲外を頼まれる、といった、本業で嫌だったことと同じことに、今度は収入を握られた状態で向き合い、本業のときより苦しくなっています。本業にしたい理由で決めた人は、同じことが起きても、「この範囲の仕事を軸にする」という理由が残っているので、案件を替える判断ができています。

見ていて差がつくのは、本業にした後も、副業のときの案件の選び方を守っているかです。副業のときは範囲と条件で選んでいた人が、本業にした途端に、収入のために範囲外の案件を受け始めると、依頼側からの評価が下がり、単価も下がり、副業のときより条件が悪くなります。副業のときの選び方を守れているのは、独立の目安を満たしてから本業にした人で、断る余裕が残っているからです。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲を明確にしている担当者ほど、本業にした後も範囲の合う依頼側から選ばれ続けています。本業にするかどうかの判断は、理由の分け方と、選び方を守れる余裕の二つで決まります。

## 本業にする前に試せること

副業を本業にするかどうかを、いきなり決めなくても、判断の材料を集める方法があります。

| 試せること | 内容 | 分かること |
|---|---|---|
| 本業を休んで副業だけの期間を作る | 長期の休暇や、休職が取れるなら、その期間を副業だけで過ごす | 副業だけの毎日が、想像と同じか。収入が途切れたときの心理的な負担 |
| 副業の枠を一段広げる | 本業を続けたまま、副業の稼働を少し増やす | 稼働が増えたとき、案件の選び方と質を保てるか |
| 本業を短時間の勤務に変える | 会社の制度があれば、勤務日や時間を減らして副業の比重を上げる | 本業の給与が減った状態で、副業の収入で生活の感覚がどう変わるか |
| 本業の側の問題を解決してみる | 異動を願い出る、上司に相談する、転職を検討する | 辞めたい理由が、本業の会社の中で解決できるか。解決できるなら、副業を本業にする必要がない |
| 「本業にした自分」の一週間を書き出す | 稼働、案件の数、収入、休み、判断する場面を、具体的に書く | 書けないところが、見えていないところ |
| 独立している人に、最初の一年を聞く | 同じ立場で独立した人に、最初の一年で困ったことを聞く | 副業のときには見えていない、途切れ、税と保険、信用の作り直し |

試せることの要点は、「本業の側の問題を解決してみる」を先にやることです。辞めたい理由が、異動や上司への相談で解決するなら、副業を本業にしなくても、本業と副業の両立が続けられます。それでも本業にしたい理由が残るなら、判断の土台が確かめられたことになります。試す順番は、費用と戻しやすさで、「本業の側の問題を解決してみる」「副業の枠を一段広げる」「本業を休んで副業だけの期間を作る」の順です。仲間への聞き方は[同じ立場の仲間を作る](/media/fukugyo-nakama/)に、稼働の広げ方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

## 判断の材料になる副業の記録

副業を本業にするかどうかは、感覚ではなく、副業の記録で判断します。記録がなければ、まず残します。

| 記録 | 見ること | 判断への使い方 |
|---|---|---|
| 案件ごとの範囲と稼働と単価 | 範囲の広さ、稼働の実態、単価の幅 | 本業にしたとき、どの範囲と単価で枠が埋まるか |
| 案件の入口 | 登録先、再依頼、紹介、発信、本業のつながりの、どれから来たか | 本業を離れて残る入口がどれだけあるか |
| 断った案件 | 条件は合うが枠がなくて断った件数 | 本業にして枠を広げたとき、埋まる案件があるか |
| 途切れた期間 | 案件がゼロだった期間と、その理由 | 本業にしたとき、途切れの頻度と長さ |
| 依頼側からの評価と更新 | 更新された案件、切られた案件と、その理由 | 本業にしたとき、続く案件の割合 |
| 副業で嫌だったこと | 合わない担当者、範囲外の依頼、遅い判断 | 本業にした後も、同じことが起きる前提で耐えられるか |

記録の要点は、「副業で嫌だったこと」も記録しておくことです。副業を本業にしたい気持ちが強いときは、副業の良い面だけを見がちですが、副業にも、合わない担当者や範囲外の依頼はあります。本業にすると、それに向き合う時間が増え、逃げ場がなくなります。副業で嫌だったことを、本業で嫌だったことと並べて見ると、副業を本業にしても消えないものが分かります。記録の残し方は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に、収入の記録は[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に整理しています。

## 本業にした後に起きやすい崩れ方

副業を本業にした後、どこが崩れやすいかを知っておくと、備えられます。

| 崩れ方 | 何が起きるか | 備え |
|---|---|---|
| 案件の選び方が崩れる | 収入のために範囲外や条件の合わない案件を受け、質が落ち、評価が下がる | 断る基準を書いて貼っておく。断る余裕を蓄えで作る |
| 稼働が増えすぎる | 上限がなくなり、休みがなくなり、質が落ちる | 週の稼働の上限を、本業があったときと同じように決める |
| 依頼側との関係が変わる | 「これで生活している人」と見られ、範囲外や条件の引き下げを言われやすくなる | 範囲を書面で決め、範囲外は見積もりで返す。[業務範囲を書面で固める](/media/fukugyo-scope/) |
| 途切れで判断が鈍る | 収入ゼロの月に、条件を下げて埋めようとする | 最悪の月の蓄えを持ち、途切れは想定内として扱う |
| 一人の判断に疲れる | 相談相手がいなくなり、判断を抱え込む | 同じ立場の仲間と、判断を相談できる関係を作る。[相談できる相手を持つ](/media/fukugyo-mentor/) |
| 本業で嫌だったことが再現する | 依頼側で、合わない担当者、遅い判断、範囲外の依頼に向き合う | 「本業にしたい理由」を書いたものを見直し、案件を替える判断をする |

崩れ方の要点は、どれも「副業のときの余裕がなくなること」で起きることです。副業のときは、本業の給与と、断る余裕と、稼働の上限があり、それが選び方と関係と判断を支えていました。本業にすると、その支えを自分で作る必要があります。独立の三つの目安と、記録と、仲間が、その支えになります。関係の作り方は[信頼を積む小さな行動](/media/fukugyo-shinrai/)に、契約を切られたときの動き方は[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/)に書いています。

## 判断の順番

副業を本業にするかどうかを決める順番です。

| 順番 | 内容 |
|---|---|
| 一、辞めたい理由と本業にしたい理由を分けて書く | 本業の側の理由と、副業の側の理由を、別の紙に書く |
| 二、辞めたい理由を、本業の中で解決できないか試す | 異動、相談、転職。解決できるなら、両立を続ける |
| 三、辞めたい理由を除いて、本業にしたい理由が残るか見る | 残らなければ、本業にする判断はしない |
| 四、副業の記録を見る | 範囲、稼働、入口、断った案件、途切れ、評価、嫌だったこと |
| 五、独立の三つの目安を確かめる | 入口の複数化、断っている案件、最悪の月の蓄え。[独立を考える目安](/media/fukugyo-dokuritsu/) |
| 六、本業にする前に試せることをやる | 副業の枠を広げる、短時間の勤務、休んで副業だけの期間 |
| 七、崩れ方への備えを作る | 断る基準、稼働の上限、範囲の書面、蓄え、仲間 |
| 八、戻る道を残して決める | 期限を決め、目安が保てなければ雇用に戻ると決めておく |

順番の要点は、「一」から「三」で、理由が確かめられなければ、「四」以降に進まないことです。理由が「辞めたい」だけなら、副業を本業にしても解決しません。理由が残ってから、記録と目安で数字を確かめ、試せることを試し、備えを作って、戻る道を残して決めます。この順番を踏めば、副業を本業にする判断は、勢いではなく、確かめた結果になります。本業の離れ方は[退職後に副業から始める](/media/fukugyo-taishoku-go/)に、引き継ぎは[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「副業のほうが本業より手応えがあるなら、本業にしたほうがよい」というものです。実際には、手応えの多くは、本業との対比と、副業の枠の中で選べる余裕から来ています。本業にすると対比は消え、余裕も減り、手応えは変わります。本業にして続いている人は、手応えではなく、「この範囲の仕事を軸にしたい」という理由が、辞めたい理由を除いても残っていて、その理由を軸に、案件の選び方を守っています。

順番として、辞めたい理由と本業にしたい理由を分け、辞めたい理由は本業の中で解決できないか試し、本業にしたい理由が残るかを見て、副業の記録と独立の目安で数字を確かめ、試せることを試し、崩れ方への備えを作り、戻る道を残して決める。この順番で、副業を本業にする判断は、逃げる判断ではなく、選ぶ判断になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲を明確にし、案件の選び方を守っている担当者が、本業にした後も選ばれ続けています。本業にするかどうかは、楽しさではなく、残る理由で決めるものです。

## まとめ

- 副業を本業にするかは**辞めたい理由と本業にしたい理由を分け、辞めたい理由を除いても本業にしたい理由が残るか**で決める
- 辞めたい理由で決めると**本業にした副業で同じことが起き、逃げ場がなくなる**
- 本業にすると変わるのは**案件を選ぶ基準・依頼側との関係・成果と生活の距離・自分の位置づけ**
- 決める前に**本業の側の問題を解決してみる・副業の枠を広げる・休んで副業だけの期間を作る**
- 判断の材料は**副業の記録（範囲・稼働・入口・断った案件・途切れ・評価・嫌だったこと）**と独立の三つの目安
- 本業にした後の崩れ方に**断る基準・稼働の上限・範囲の書面・蓄え・仲間**で備え、戻る道を残す

## よくある質問

### 本業が嫌で、副業を本業にしたいです。この理由ではだめですか

だめではありませんが、その理由だけで決めると、本業にした副業で同じことが起きたときに、逃げ場がなくなります。本業が嫌な理由（上司、評価、判断の遅さ）は、依頼側にもあります。まず、本業の嫌な理由を、異動や相談や転職で解決できないかを試し、それでも「この範囲の仕事を軸にしたい」という理由が残るなら、本業にする判断の土台があります。本業の側の解決を先に試すのは、副業を本業にした後の自分を守るためです。転職との比較は[副業から転職につながるか](/media/fukugyo-tenshoku-tsunagu/)に整理しています。

### 副業を本業にした後、また雇用に戻ることはできますか

戻ることはできますが、戻りやすさは、離れ方と、独立中の実績の残し方で変わります。本業を丁寧に引き継いで離れ、会社との関係を残しておけば、戻る道の一つになります。独立中の案件を、範囲と状態の変化と型で記録しておけば、転職用の職務経歴書に書けます。最初から「一年やって目安が保てなければ戻る」と期限を決めておくと、戻る判断が遅れません。職務経歴書の書き方は[副業用の職務経歴書](/media/fukugyo-shokumu-keirekisho/)に書いています。

### 家族に、副業を本業にしたいと言い出せません

家族が心配するのは、収入の途切れと、その先の生活です。「本業にしたい」という気持ちではなく、副業の記録（入口の種類、断った案件、途切れた期間）と、最悪の月の蓄えと、戻る道を、数字と期限で示すと、家族は判断の材料を持てます。気持ちだけで伝えると、家族は反対するしかありません。数字と期限で伝えれば、家族と一緒に判断できます。独立の目安の数字は[独立を考える目安](/media/fukugyo-dokuritsu/)に整理しています。
