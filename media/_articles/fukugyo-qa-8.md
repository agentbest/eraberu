人事の経験はあるが、住んでいるのは地方で、依頼側の多くは都市部にありそうだ。会いに行けない自分に、案件が来るのか。来ても、対面を求められて断ることになるのではないか。結論を先に書くと、**人事の副業の工程の多くは、スカウトの検索と送信、候補者への連絡、日程調整、記録の整備、求人票の作成、面接の準備など、リモートで完結します。地方在住でもできます。決めるのは住所ではなく、「対面の頻度をどこまで受けるか」「通信と作業の環境が整っているか」「依頼側の稼働時間帯と合うか」の三つです。**逆に、地元の企業の採用を支援する案件では、地方在住のほうが、地域の媒体や候補者の動きを知っている分、有利になります。地方在住で受けられる業務の整理は[地方在住でも受けられるか](/media/fukugyo-chiiki/)に、リモートで完結する案件の見分け方は[フルリモートで完結する案件](/media/fukugyo-remote/)に、対面が要る場面は[対面が必要になる場面](/media/fukugyo-taimen/)にまとめています。

## 地方在住が影響しない工程と影響する工程

人事の副業の工程を、住所が影響するかどうかで分けます。

| 工程 | 地方在住の影響 | 理由 |
|---|---|---|
| スカウトの検索と送信 | 影響しない | 媒体の管理画面で完結する |
| 候補者への連絡、一次返信 | 影響しない | メールやチャット、媒体のメッセージで完結する |
| 日程調整 | 影響しない | オンラインの面接なら、場所は関係ない |
| 求人票の作成 | 影響しない | 依頼側とのやり取りはオンラインで済む |
| 記録の整備、稼働報告 | 影響しない | 依頼側の仕組みの中で完結する |
| 面接の準備（面接官への資料） | 影響しない | 資料の作成と共有はオンライン |
| 依頼側との定例 | ほぼ影響しない | オンラインの定例が多い。対面を求める依頼側もある |
| 面接の同席 | 影響する | 対面の面接なら、その場にいる必要がある。オンラインの面接なら影響しない |
| 説明会や採用イベントの運営 | 影響する | 会場での対応が要ることが多い |
| 依頼側の社内の人との関係づくり | 一部影響する | 対面のほうが早いことはあるが、オンラインでも積み重ねで作れる |

工程の要点は、「影響する工程は、範囲から外せば済む」ことです。面接の同席や説明会の運営を範囲から外し、リモートで完結する工程だけを範囲にすれば、地方在住であることは依頼側にとって問題になりません。範囲の絞り方は[受ける範囲の決め方](/media/fukugyo-scope/)に書いています。

## 対面の頻度で案件を選ぶ

案件を選ぶとき、「対面がゼロか、月に一度か、週に一度か」で分けて考えます。

| 対面の頻度 | 案件の特徴 | 地方在住との相性 |
|---|---|---|
| ゼロ | 依頼側がリモートでの採用に慣れている。定例も面接もオンライン | 合う。住所を気にする必要が無い |
| 契約の最初と節目だけ | 初回の打ち合わせと、更新のときに対面。それ以外はオンライン | 合う。年に数回の移動で済むなら、移動の費用と時間を条件に入れる |
| 月に一度程度 | 定例の一部が対面、または月に一度の社内の会議に出る | 移動の負担次第。費用の扱いを契約で決める |
| 週に一度以上 | 出社に近い形。面接の同席や社内の人との調整が中心 | 合わない。範囲を変えるか、受けない |

頻度の要点は、「契約の前に、対面の頻度を依頼側に聞く」ことです。「リモートで」と言われていても、依頼側の担当者の頭の中では「たまには来てほしい」があることがあります。「対面の頻度はどのくらいを想定していますか」「移動の費用の扱いはどうなりますか」を最初に聞いておけば、後で「来てほしい」と言われて困ることが減ります。契約の前の確認は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に、対面を求められたときの扱いは[対面が必要になる場面](/media/fukugyo-taimen/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「地方在住だと、依頼側から選ばれにくい」というものです。実際には、依頼側の担当者が担当者を選ぶとき、住所を見ている場面はほとんどありません。見ているのは、範囲と経歴と稼働の条件です。範囲がリモートで完結する工程で、稼働の時間帯が依頼側の営業時間と合っていれば、住所が都市部か地方かは、判断に入っていません。

見ていて差がつくのは、地方在住を「制約」として伝えるか、「条件」として伝えるかです。「地方なので対面は難しいのですが」と伝えると、依頼側は制約として受け取ります。「リモートで完結する範囲でお受けし、対面は年に数回の節目なら対応できます」と伝えると、依頼側は条件として受け取り、その条件に合う案件かを判断します。エラベルでは、担当者の対面の可否と頻度を登録の時点で聞き、依頼側の相談と合わせて提示しています。地方在住の担当者が、リモートで完結する範囲で依頼側から選ばれている例は珍しくありません。

## 地方だから受けやすい案件

地方在住が不利にならないだけでなく、有利になる案件があります。

| 案件 | なぜ地方在住が有利か |
|---|---|
| 地元の企業の採用支援 | 地域の媒体、地域の候補者の動き、地元の学校や転職の事情を知っている。都市部の担当者には分からない |
| 地方に拠点を持つ会社の、その拠点の採用 | 拠点の周辺の候補者の市場を知っている。対面が要る場面でも、近い |
| 都市部の会社が、地方の人材を採用したい案件 | 地方の候補者がどの媒体を見て、何を気にするかを知っている |
| 地方への移住を伴う採用 | 移住する側の不安（住まい、家族、生活）が分かり、候補者の対応で強い |
| 地方の同業の集まりや紹介 | 地元の人事の集まりで、地元の企業の相談が回ってくる。[同じ立場の仲間を作る](/media/fukugyo-nakama/) |

有利になる要点は、「地域の候補者の市場を知っていること」が、都市部の担当者には無い強みになることです。地方の企業は、都市部の採用の型がそのまま効かないことが多く、地域を知っている担当者を求めています。範囲の一言に「〇〇地域の採用」を入れると、その地域の依頼側から声がかかりやすくなります。地域で絞る戦い方は[地方在住でも受けられるか](/media/fukugyo-chiiki/)に、範囲の一言の作り方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に書いています。

## 始める前に整える通信と作業の環境

地方在住でリモートの案件を受けるとき、環境の面で整えておくことがあります。

| 整えること | 内容 | 要点 |
|---|---|---|
| 通信の回線 | オンラインの定例や面接に耐える回線。自宅の固定の回線が基本 | 不安定だと、定例や面接の同席で信頼を失う。[ネットワーク環境の注意](/media/fukugyo-vpn/) |
| 作業の場所 | 家族の声や生活の音が入らない場所。画面を周りに見られない場所 | 候補者の情報を扱うので、家族と共用の場所は避ける |
| 端末 | 副業用の利用者かアカウントで分けた端末 | [私物端末で作業してよいか](/media/fukugyo-tanmatsu/) |
| 稼働の時間帯 | 依頼側の営業時間と重なる時間が、週にどれだけ取れるか | 依頼側との定例と、候補者への返信は、依頼側の営業時間に近いほうがよい |
| 移動の手段と費用 | 対面が要る場合、依頼側の所在地までの移動の時間と費用 | 契約で費用の扱いを決める。自分持ちなら単価に含めるか、別に請求するか |
| 郵送や書類の扱い | 契約書や請求書が紙の場合の郵送 | 電子契約や電子の請求が多いが、紙が要る依頼側もある |

環境の要点は、「通信の回線」です。地方在住であること自体は依頼側に問題視されませんが、定例の途中で回線が切れる、面接の同席で音声が途切れる、が続くと、「リモートで任せられない」になります。回線が不安定な場所なら、固定の回線を整えるか、安定する場所で定例と面接だけ行う形にします。

## 依頼側に伝えること

地方在住であることを、依頼側にどう伝えるかで、受け取られ方が変わります。

| 伝えること | 伝え方 |
|---|---|
| 居住地 | 「〇〇地方在住で、リモートを基本にしています」。都道府県まで。市区町村は要らない |
| 対面の可否と頻度 | 「対面は、契約の最初と節目なら対応できます。月に一度以上は難しいです」 |
| 稼働の時間帯 | 「平日の夜と、土日の午前に稼働します。御社の営業時間中の定例は、〇曜の〇時なら可能です」 |
| 通信の環境 | 「自宅に固定の回線があり、オンラインの定例と面接の同席に問題ありません」 |
| 移動の費用の扱い | 「対面の際の移動の費用は、〇〇の形でお願いしたいです」 |
| 地域の強み（あれば） | 「〇〇地域の採用については、地域の媒体と候補者の動きを把握しています」 |

伝える要点は、「できないこと」ではなく「できる形」で伝えることです。「地方なので対面は無理です」ではなく、「対面は契約の最初と節目なら対応できます」と、できる範囲を示します。依頼側は、できる範囲で判断します。プロフィールへの書き方は[プロフィールの書き方](/media/fukugyo-profile/)に整理しています。

## 対面を求められたときの扱い

リモートで始めた案件で、途中で対面を求められることがあります。そのときの扱いです。

| 求められ方 | 扱い |
|---|---|
| 契約の節目（更新、新しい職種の開始）で一度 | 対応できるなら対応する。移動の費用と時間は、契約で決めた扱いで |
| 社内の人への紹介のために一度 | 対応できる範囲で。オンラインでの紹介で代替できないかを提案する |
| 面接の同席を対面で | 範囲に入っていなければ、範囲の話として扱う。オンラインの面接なら同席できることを伝える |
| 毎週来てほしい | 契約の前提と違う。「リモートを前提にお受けしているので、毎週の対面は難しいです。〇〇の形なら」と、線を引く。[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/) |
| 急に「明日来てほしい」 | 地方在住では物理的に難しいことを伝え、オンラインでの対応を提案する |
| 依頼側の情報管理の都合で、社内の端末を使う必要が出た | 依頼側に貸与の端末を郵送してもらうか、範囲を変える。[私物端末で作業してよいか](/media/fukugyo-tanmatsu/) |

扱いの要点は、「契約の前提（リモート）を、依頼側と最初に文面で共有しておく」ことです。前提が文面にあれば、途中で対面を求められたとき、「契約の前提と違う」と事実として話せます。前提が口頭だけだと、「最初はそう言っていたが」になり、線が引きにくくなります。

### エラベルの見解

担当する側から見ると、地方在住で長く続いている人は、地方であることを説明せず、リモートで完結する範囲と、対面の可否と頻度を条件として伝えています。依頼側の担当者は、その条件で判断し、合う案件なら住所を気にしません。地方であることを繰り返し説明する人は、自分で制約を強調してしまい、依頼側にも制約として伝わります。

順番として、範囲をリモートで完結する工程に絞り、対面の可否と頻度と稼働の時間帯を条件にし、通信と作業の環境を整え、依頼側には「できる形」で伝え、契約の前提を文面に残す。地域の強みがあれば、範囲の一言に入れる。この順番で、地方在住は制約ではなく、条件の一つになります。エラベルでは、担当者の居住地より、対面の可否と稼働の時間帯を登録で聞いており、依頼側の相談と合わせるときも、その条件で見ています。住所で選ばれる仕組みではありません。

## まとめ

- 人事の副業の工程の多くは**リモートで完結する**。地方在住でもできる
- 決めるのは住所ではなく**対面の頻度・通信と作業の環境・稼働の時間帯**の三つ
- 対面の頻度は**ゼロ・節目だけ・月に一度・週に一度以上**で分け、契約の前に依頼側に聞く
- **地元の企業や地方の拠点の採用**では、地域の市場を知っている地方在住が有利
- 始める前に**通信の回線・作業の場所・端末・稼働の時間帯・移動の費用の扱い**を整える
- 依頼側には**「できないこと」ではなく「できる形」**で伝え、契約の前提を文面に残す
- 途中で対面を求められたら**契約の前提を事実として話し、オンラインでの代替を提案する**

## よくある質問

### 依頼側の営業時間に、本業があって稼働できません。それでも受けられますか

候補者への返信や日程調整は、依頼側の営業時間の外でも回ることが多く、平日の夜や土日の午前の稼働で受けられる案件はあります。ただし、依頼側との定例は営業時間内が多いので、週に一度、営業時間内に定例の時間が取れるかを見ます。取れなければ、定例を短い文面の報告に替える形を依頼側と相談します。稼働の時間帯を条件として伝えれば、合う案件が提示されます。平日の夜の稼働の置き方は[平日の夜に副業をする](/media/fukugyo-heijitsu-yoru/)に書いています。

### 都市部の依頼側と、地方の依頼側で、単価は違いますか

単価は、依頼側の所在地ではなく、範囲と稼働と依頼側の予算で決まります。地方の依頼側だから安い、都市部だから高い、という決まりは無く、案件ごとに違います。地域の強みを活かせる案件では、その強みを範囲に含めて単価の根拠にできます。単価の決め方は[最初の1件の価格の決め方](/media/fukugyo-shoninka/)に整理しています。所在地で単価を決めつけず、範囲と稼働で決めます。

### 移動の費用は、誰が持つのが一般的ですか

一般に、依頼側が求める対面の移動の費用は、依頼側が負担するか、単価に含める形で契約に入れることが多いとされていますが、案件によって違います。契約の前に「対面の際の移動の費用は、どのような扱いになりますか」と聞き、文面で残します。自分から対面を希望する場合は、自分持ちになることもあります。費用の扱いが契約に無いまま対面が発生すると、後でもめるので、最初に決めておきます。経費としての扱いは[経費にできるもの](/media/fukugyo-keihi/)を見たうえで、専門家にご確認ください。
