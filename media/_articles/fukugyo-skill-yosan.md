「今期の採用予算を組むのを手伝ってほしい」と頼まれると、金額の話から始めたくなります。ただ、依頼側の予算が途中で足りなくなったり、逆に余ったりするのは、金額の見積もりが甘いからではなく、「何に、どういう性質の費用が、採用計画のどこに対応して出るか」の構造が無いからです。構造が無い予算は、去年と同じ額を置いて、途中で崩れます。結論を先に書くと、**採用予算は、金額の前に、費目の分け方・固定と変動の区別・採用計画との対応の構造を一枚にし、変動費は計画の人数と経路に紐づけ、見直しの周期と費目の付け替えの判断を依頼側に置き、金額や相場は担当者が断定せず見積もりを取ってから並べ、費用対効果は測る形を先に置いて組みます。**会社側から見た立て方は[採用予算の立て方](/media/rpo-yosan-sakutei/)に、予算が無いときの順番は[採用予算がない中で何から手を付けるか](/media/rpo-yosan-nai/)に、採用計画は[採用計画を作る](/media/fukugyo-skill-keikaku/)に書いています。ここでは、予算の構造の型に絞ります。

## 「去年と同じ額」で崩れる理由

| 組み方 | 何が起きるか |
|---|---|
| 去年の総額をそのまま | 今年の採用の人数と経路が違うのに、額だけ同じ |
| 費目を分けていない | どこに使ったかが分からず、途中で「残りいくら」しか見えない |
| 固定と変動を分けていない | 採用の人数が増減したときに、どの費目が動くかが分からない |
| 採用計画と別に組む | 計画で経路を変えたのに、予算は去年の経路のまま |
| 見直しの周期が無い | 期末に足りない、または余る |

予算は、採用計画の「経路と人数」を、費用の側から見た一枚です。計画と別に組むと、計画が変わった瞬間にずれます。

## 金額の前に決める構造

| 決めること | 中身 |
|---|---|
| 費目の分け方 | 何に使うかの分類。下の型 |
| 固定と変動 | 採用の人数に関係なく出る費用（固定）と、人数や経路で動く費用（変動） |
| 採用計画との対応 | 各費目が、計画のどの経路・どの人数に対応するか |
| 見直しの周期 | 四半期か月か。誰が見て、誰が付け替えを決めるか |
| 測る形 | 費目ごとに、何を数えれば効いたかが分かるか |

金額は、構造が決まってから、各費目に見積もりを取って置きます。順番を逆にすると、金額に構造を合わせることになります。

### エラベルの見解

担当する側から見ると、予算で最も差がつくのは、「変動費を採用計画の人数と経路に紐づけて書けるか」です。受ける側は、費目ごとに「年間いくら」と置きます。ただ、紹介会社の費用は「紹介経由で採る人数」で動き、スカウト媒体の費用は「使う期間と送る数」で動き、面接の稼働は「面接の回数」で動きます。「紹介経由で〇人採るなら、紹介の費目はこの構造で動く」と、人数と経路に紐づけて書けば、計画が変わったときに予算も一緒に動きます。エラベルで担当者を選ぶ企業には、「予算の各費目は、採用計画の何人・どの経路に対応していますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、予算の一枚の各費目の横に、「対応する経路と人数」の列を作ること。空欄の費目は、固定費か、計画に無い支出です。

## 費目の型

| 費目 | 固定か変動か | 対応する計画の項目 | 測る形 |
|---|---|---|---|
| 求人媒体（掲載型） | 掲載の期間と枠で固定に近い | 掲載型で採る人数 | 掲載期間中の応募の数、一次に進んだ数 |
| スカウト媒体 | 期間と送信の枠で固定に近い。送る数で変動する部分も | スカウト経由で採る人数 | 返信の数、面談の数 |
| 紹介会社 | 変動。採った人数で動く | 紹介経由で採る人数 | 推薦の数、一次に進んだ数、入社の数 |
| ツール（ATS、日程調整） | 固定 | 全体 | 記録の揃い、日数の短縮 |
| 外部の担当者（副業、代行） | 契約の形で固定か変動 | 担当する工程 | 担当する工程のKPI |
| 社内の稼働 | 面接の回数で変動 | 面接の段の数と候補者の数 | 面接の回数と日数 |
| 入社後（研修、オンボーディング） | 入社の人数で変動 | 入社の人数 | 定着の節目 |

費目の分け方は依頼側の会計の区分に合わせます。上の型は考え方で、名称と区分は依頼側の決まりに従います。費用の内訳の考え方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、媒体費と代行費を分ける理由は[媒体費と代行費を分けて見るべき理由](/media/rpo-baitai-hi-betsu/)に書いています。

## 金額と相場を担当者が断定しない

| やらないこと | やること |
|---|---|
| 「媒体の掲載は〇〇円くらい」 | 「媒体に見積もりを取ってから並べる。料金は期間と枠で変わる」 |
| 「紹介の手数料は一般に〇%」 | 「紹介会社との契約の条件を依頼側が確認する。契約ごとに違う」 |
| 「採用一人あたりの費用の相場は〇〇円」 | 「御社の去年の記録から、費目ごとの実績を出す。外部の相場は条件が違う」 |
| 総額を担当者が提案する | 費目と構造を担当者が作り、金額は見積もりと依頼側の判断で埋める |

金額の断定は、契約の段階で違っていたときに担当者の信頼を落とし、依頼側の予算の判断を誤らせます。担当者は構造と「確認する項目」を作り、金額は依頼側が見積もりを取って置きます。費用の判断は依頼側です。

## 費用対効果は測る形を先に

| 費目 | 効いたかを見る数字 | 見る時期 |
|---|---|---|
| 掲載型の媒体 | 応募の数、一次に進んだ数 | 掲載期間の終わり |
| スカウト媒体 | 返信の数、面談の数 | 月次 |
| 紹介会社 | 推薦の数、一次に進んだ数 | 月次 |
| ツール | 日数の短縮、記録の揃い | 四半期 |
| 外部の担当者 | 担当する工程のKPI | 月次 |

「費用対効果が見えない」のは、効果が無いからではなく、測る形が無いからです。予算の一枚に「測る形」の列を作り、期の途中で費目ごとに見られるようにします。測る形の考え方は[費用対効果が見えない](/media/scout-daikou-kadai-hiyou/)に、KPIは[KPIを設計する](/media/fukugyo-skill-kpi/)に書いています。効いたかどうかの数字は件数で並べ、割合や単価で断定しません。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「予算は期の初めに決めたら、期の終わりまで固定」というものです。実際には、採用計画の経路が途中で変わり、効いていない費目と効いている費目が期の途中で分かれます。見直しの周期（四半期か月）を先に決め、「使わなかった費目を、効いている費目に回す」判断を、誰が、どの数字を見て行うかを一枚に書いておく。それが無いと、期末に「余った」「足りない」になります。付け替えの判断は依頼側で、担当者は「この費目はこの数字で効いていない、この費目は効いている」を件数で並べるまでです。受ける側がその場で使える判断としては、予算の一枚に「見直しの日」を先に三つ書いておくこと。日が書いてあれば、見直しは行われます。

## 予算の一枚

| 列 | 中身 |
|---|---|
| 費目 | 依頼側の会計の区分に合わせた名称 |
| 固定／変動 | どちらか |
| 対応する経路と人数 | 採用計画の該当の行 |
| 金額 | 依頼側が見積もりを取って置く。担当者は空欄で渡す |
| 測る形 | 効いたかを見る数字と時期 |
| 見直しの日 | 三つ |
| 付け替えを決める人 | 依頼側の一人 |

金額の列を空欄で渡すのは、担当者が金額を断定しないためです。「構造は作りました。金額は見積もりを取ってから、この列に入れてください」と伝えます。予算の承認や会計の処理は依頼側の領域で、税務や会計の扱いに関わる点は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。

## 踏み込まない線

| 線 | 理由 |
|---|---|
| 金額と相場を断定しない | 条件で変わる。契約の段階で違えば信頼が落ちる |
| 総額を担当者が決めない | 費用の判断は依頼側 |
| 会計・税務の処理に関わらない | 専門家の領域 |
| 外部の相場や統計を持ち込まない | 依頼側の条件と合わない |
| 紹介会社や媒体との契約条件を担当者が交渉しない | 契約の範囲外。依頼側が行う |

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が総額だけを決めたがる | 費目と構造の一枚を先に作り、総額は費目の合計として後から見る形に |
| 金額を担当者に聞かれる | 「見積もりを取ってから」と伝え、確認する項目を並べる |
| 採用計画が無い | 予算の前に採用計画を。計画が無い予算は去年の写しになる |
| 費目が細かすぎる | 上の型の七つ前後に。細かい内訳は依頼側の会計で |
| 費用対効果を聞かれるが測る形が無い | 一枚に「測る形」の列を足す。今期は測る形を置くことが成果 |
| 期末に余った・足りない | 見直しの日を三つ書き、付け替えの判断を依頼側の一人に |

## まとめ

- 「去年と同じ額」で崩れるのは、**費目・固定と変動・計画との対応の構造が無い**から
- 金額の前に**構造の一枚**。費目・固定／変動・対応する経路と人数・測る形・見直しの日・決める人
- 変動費は**採用計画の人数と経路に紐づける**。計画が変われば予算も動く
- **金額と相場を担当者が断定しない**。金額の列は空欄で渡し、依頼側が見積もりを取って埋める
- **費用対効果は測る形を先に**。件数で並べ、割合や単価で断定しない
- 見直しの周期と付け替えは**依頼側の判断**。担当者は効いている費目と効いていない費目を件数で並べるまで
- 会計・税務・契約の交渉に踏み込まない。**個別の判断は専門家にご確認ください**

## よくある質問

### 依頼側から「この予算で何人採れるか」を聞かれました

「何人採れるか」は、経路ごとの過去の記録（応募から入社までの件数）が無ければ答えられません。記録があれば、「去年、この経路でこの費用でこの件数だった」と、依頼側の実績を並べます。記録が無ければ、「今期は費目ごとに測る形を置いて、来期に答えられるようにする」と伝えます。担当者が推測で人数を言うと、その数字が目標になり、根拠の無い責任を負うことになります。

### 予算が少なく、有料の経路が使えないと言われました

費用のかからない工程（求人票の見直し、日程の速さ、記録の揃い、リファラルの仕組み）から手を付ける順番を提案します。有料の経路を足す前に、いまの経路の詰まりを直すほうが、少ない費用で動くことが多い。順番の考え方は[採用予算がない中で何から手を付けるか](/media/rpo-yosan-nai/)に書いています。有料の経路を足すかどうかは、詰まりが直った後に、依頼側が判断します。

### 副業の担当者の費用は、予算のどの費目に入りますか

「外部の担当者」の費目で、契約の形（月額、時間単価、工程ごと）によって固定か変動かが変わります。担当者自身の費用の扱いを、担当者が予算の一枚で提案することは、利益が絡むので慎重にします。「この費目の金額は、契約の条件で御社が入れてください」と、自分の費用の欄も空欄で渡します。契約の形は[見積もりの出し方](/media/fukugyo-mitsumori/)に、利益相反の線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。
