キャリアコンサルタントとして、働く人の相談を受けてきた。転職の相談、職場の悩み、次の一歩の整理。人事の部署にいたわけではないが、候補者がどう考え、何で迷い、何で決めるかは、誰よりも知っている。この経験は、企業側の採用の副業で売れるのか。結論を先に書くと、**キャリアコンサルタントの経験は、「候補者の側から採用を見る」工程で売れます。売れるのは、「候補者との面談の設計と実施」「辞退と早期離職の理由の聞き取り」「入社後の定着の面談」「求人票を候補者の目線で直す」の四つです。依頼側の多くは、候補者が何を考えて応募し、辞退し、辞めるかが見えておらず、候補者の側から見られる人が求められています。ただし、「相談を受けます」という売り方では、依頼側には伝わりません。「依頼側の採用の〇〇の工程を、候補者の目線で」と、企業側の工程で売ります。**人事未経験の売り方は[人事未経験が副業でできること](/media/fukugyo-mikeiken-jinji-fukugyo/)に、候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に、ヒアリングの技法は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)にまとめています。

## この経歴の何が売れるか

キャリアコンサルタントの経験を、企業側の採用の工程に置き換えた棚卸しです。

| キャリアコンサルタントの経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 相談者の本音を引き出す面談の技法 | 候補者との面談で、転職の理由、求めるもの、迷いを引き出し、依頼側と合うかを確かめる | 面談が会社の説明で終わり、候補者の本音が分からない依頼側が多い |
| 転職で人が決める理由と迷う理由を知っている | 辞退の理由を、当たり障りのない答えの奥まで聞き、求人票と条件と面談に反映する | 辞退の理由が「他社に決めた」で止まっている依頼側が多い |
| 職場の悩みと離職の理由を聞いてきた | 早期離職の理由を聞き取り、採用と受け入れのどこを直すかを示す | 早期離職が続き、原因が分からない依頼側が多い |
| 入社後の適応の支援 | 入社後の定着の面談（最初の数か月）を設計し、実施する | 採用で終わり、入社後の面談が無い依頼側が多い |
| 求人票を相談者と一緒に読んできた | 求人票を「候補者が読んでどう感じるか」で直す。社内の言葉を候補者の言葉に | 求人票が社内の言葉で書かれている依頼側が多い |
| 多様な職種と経歴の人を見てきた | 依頼側が想定していない経歴の候補者の可能性を示す | 候補者の要件が狭く、母集団が作れない依頼側が多い |
| 相談者の立場を守る姿勢 | 候補者の個人情報と心情を守りながら、依頼側に必要なことだけを伝える | 候補者への配慮が無く、評判が落ちている依頼側が多い |

売れるものの要点は、「依頼側は候補者の側が見えていない」ことです。採用の工程は企業側で設計されていて、候補者がその工程をどう感じ、どこで迷い、なぜ辞退し、なぜ辞めるかは、企業側からは見えません。キャリアコンサルタントは、その見えない側を、面談の技法と経験で見せられます。企業側の実務の経験が無くても、この工程で売れます。面談の設計は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、候補者対応は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

## 売りにくい点とその扱い

キャリアコンサルタントの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 相談と採用の立場の違い | 「候補者の味方になって、うちの採用に不利なことをするのでは」「候補者に転職をやめるよう助言するのでは」 | 立場を最初に示す。「依頼側の採用のために、候補者の目線を使います。候補者の相談を受ける立場ではなく、依頼側と候補者が合うかを確かめる立場です」 |
| 守秘の線が二重になる | 「候補者から聞いたことを、どこまで依頼側に伝えるのか」 | 候補者に「依頼側に伝えること」を最初に示し、伝える範囲を決める。候補者の心情と個人情報は守り、採用の判断に要ることだけを伝える |
| 企業側の工程を知らない | 「内定の出し方、条件の提示、採用管理の仕組みを知らないのでは」 | 範囲を、面談、辞退と離職の理由、定着、求人票の翻訳に絞る。工程の運用と条件は依頼側 |

扱い方の要点は、「立場を最初に示す」ことです。キャリアコンサルタントの転身で依頼側が最も警戒するのは、「候補者の味方になる」ことです。相談者の立場を守る姿勢は、キャリアコンサルタントの土台ですが、企業側の副業では、「依頼側の採用のために候補者の目線を使う」立場に立ちます。候補者の相談を受ける立場と、依頼側の採用を担う立場は違い、副業では後者です。この違いを、自分の中で整理し、依頼側と候補者の両方に示します。守秘の線は[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、判断の線は[業務範囲を書面で固める](/media/fukugyo-scope/)に、企業側の工程の学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に整理しています。

### エラベルの見解

担当する側から見ると、キャリアコンサルタントから転身して続いている人と、最初の案件が取れないか一件で終わる人の差は、「相談を受けます」と言うか、「辞退と早期離職の理由を候補者から聞き取り、採用と受け入れのどこを直すかを示します」と言うかです。前者は依頼側に「うちの採用と何の関係が」と映り、後者は「うちの詰まりはそこだ」と映ります。候補者の目線は、企業側の工程に置き換えて示せば、依頼側にとって強く伝わります。

見ていて差がつくのは、候補者との面談で、「候補者の相談に乗る」形になっていないかです。キャリアコンサルタントの習慣で、面談が候補者の悩みの相談になり、候補者に「この会社は合わないかも」と助言してしまう人は、依頼側から「候補者を減らす人」と見られ、続きません。「依頼側と候補者が合うかを一緒に確かめる」形に徹し、合わない場合は依頼側に「合わない理由」を材料として渡す人は、依頼側から「見極めが確かな人」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、候補者の目線を企業側の工程で示し、立場を明確にしている担当者に、候補者の側が見えていない依頼側がついています。キャリアコンサルタントの転身は、技法の高さではなく、立場の整理で始まります。

## 案件の探し方

キャリアコンサルタントから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 候補者との面談の設計と実施 | 面談の技法で入れる | 「候補者の本音を引き出し、依頼側と合うかを確かめる面談」を範囲の一言に |
| 辞退の理由の聞き取りと反映 | 転職で人が決める理由を知っている | 「辞退の理由を奥まで聞き、求人票と条件と面談に反映する」を示す |
| 早期離職の理由の聞き取りと、採用と受け入れの見直し | 離職の理由を聞いてきた | 「早期離職が続く依頼側」を範囲の一言に |
| 入社後の定着の面談 | 適応の支援の経験で入れる | 「最初の数か月の面談を設計し、実施する」を示す |
| 求人票を候補者の目線で直す | 求人票を相談者と読んできた | 「候補者が読んでどう感じるかで直す」を示す |
| 候補者の要件の見直し | 多様な経歴を見てきた | 「想定していない経歴の候補者の可能性を示す」を提案の形で |

探し方の要点は、「早期離職が続いている依頼側」を狙うことです。採用がうまくいかない依頼側は多いですが、その中で「採れるが辞める」依頼側は、原因が候補者の側にあることが多く、キャリアコンサルタントの目線が最も効きます。辞める理由を聞き取り、採用と受け入れのどこを直すかを示せば、依頼側の採用の費用が下がり、価値が明確に見えます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、面談で聞かれることは[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。キャリアコンサルタントの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 面談の技法の専門性 | 候補者の本音を引き出す面談は、人事経験者でも得意な人が少なく、評価される | 「企業側は未経験だから安く」ではなく、面談の工程の単価で |
| 早期離職の削減の価値 | 早期離職は依頼側の採用の費用と時間を消すので、それを減らす価値は高い | 離職の理由の聞き取りと見直しは、成果物で受けやすい |
| 面談の回数で受けやすい工程 | 候補者との面談、定着の面談は、回数で受けやすい | 一回あたりの単価と、月の回数の上限を決める |
| 判断を含まない範囲 | 合否の判断は依頼側。自分は面談の結果を材料として渡す | 判断を引き受けない |
| 資格を持っていること | 資格そのものが単価を上げるわけではないが、面談の技法の根拠として示せる | 資格ではなく、面談で何ができるかで示す |
| 最初の案件 | 企業側の実績が無いので、範囲を絞って小さく | 単価を下げるのではなく、範囲と回数を小さくする |

単価の要点は、「面談の回数で受ける形を、最初に決める」ことです。候補者との面談と定着の面談は、一回あたりの時間が読みやすく、回数で受けると単価の議論が明確になります。「面談は一回〇分、月に〇回まで」と決め、それを超える場合は相談する形にします。時間で受けると、面談の準備と記録の時間が含まれず、持ち出しになります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、資格の考え方は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

キャリアコンサルタントから企業側の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、相談で聞いてきた「転職で決める理由・迷う理由・辞める理由」を、企業側の工程に置き換えて書き出す | 相談者の個人情報を含まない形で |
| 二、「候補者の相談を受ける立場」と「依頼側の採用を担う立場」の違いを、自分の言葉で書く | 立場の整理 |
| 三、候補者に伝えることと、依頼側に伝えることの、守秘の線を決める | 二重の守秘の線 |
| 四、企業側の主要な工程と言葉を一通り学ぶ | 応募から入社までの流れ、内定と条件、採用管理の仕組み |
| 五、範囲を、面談、辞退と離職の理由、定着、求人票の翻訳に絞る | 運用と条件と判断は依頼側 |
| 六、「依頼側の採用の〇〇の工程を、候補者の目線で」の一言を作る | 「相談を受けます」とは言わない |
| 七、登録先に、範囲を企業側の工程で登録する | 面談の設計、辞退と離職の理由、定着の面談 |
| 八、早期離職が続いている依頼側で、離職の理由の聞き取りを一件受け、型を残す | 次の範囲を広げる材料に |

順番の要点は、「二」の立場の違いを、自分の言葉で書いておくことです。キャリアコンサルタントの土台は相談者の立場を守ることで、企業側の副業に入るとき、その土台と依頼側の採用の目的が衝突する場面があります。「依頼側と候補者が合うかを確かめる」という立場に立てば、候補者を守ることと依頼側の採用を担うことは衝突しません。合わない候補者を無理に進めないことは、候補者にも依頼側にも利益があります。この整理を、面談の前にしておきます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「キャリアコンサルタントは働く人の側なので、企業側の採用の副業とは相性が悪い」というものです。実際には、依頼側は候補者の側が見えておらず、候補者がなぜ応募し、辞退し、辞めるかを見せられる人を求めています。相性が悪いのは、立場を整理せずに候補者の相談に乗る形で入る場合で、「合うかを確かめる」立場に立てば、候補者の目線は企業側の採用で最も価値のある視点になります。

順番として、相談で聞いてきた理由を企業側の工程に置き換え、立場の違いを自分の言葉で書き、二重の守秘の線を決め、企業側の工程と言葉を学び、範囲を面談と理由の聞き取りと定着と求人票の翻訳に絞り、工程と目線を結びつけた一言を作り、登録先に工程で登録し、早期離職が続く依頼側で一件受けて型を残す。この順番で、キャリアコンサルタントの転身は、「立場が違う転身」から「見えない側を見せる形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、候補者の目線を企業側の工程で示し、立場を明確にしている担当者に、候補者の側が見えていない依頼側がついています。キャリアコンサルタントの転身は、技法ではなく、立場の整理で始まります。

## まとめ

- キャリアコンサルタントの経験は**「候補者の側から採用を見る」工程**で売れる。**面談の設計・辞退と早期離職の理由の聞き取り・定着の面談・求人票の翻訳**の四つ
- **「相談を受けます」ではなく「依頼側の採用の〇〇の工程を、候補者の目線で」**と企業側の工程で売る
- 売りにくい点は**相談と採用の立場の違い・二重の守秘・企業側の工程**。「合うかを確かめる」立場を最初に示し、守秘の線を決め、範囲を絞る
- 面談で**候補者の相談に乗る形にならない**。合わない場合は依頼側に理由を材料として渡す
- 案件は**早期離職が続いている依頼側**から。候補者の側に原因があることが多く、目線が最も効く
- 単価は**面談を回数で受け、判断は依頼側に**。資格ではなく面談で何ができるかで示す

## よくある質問

### 候補者との面談で、候補者から「この会社はどう思いますか」と聞かれました

依頼側の採用を担う立場なので、候補者の相談に乗る形で「合わないかも」と助言することは避けます。「私は御社と候補者が合うかを確かめる立場なので、気になる点があれば教えてください。それを踏まえて、御社の担当者から答えられるようにします」と、候補者の懸念を聞き取り、依頼側に材料として渡します。候補者の懸念は、依頼側の求人票と条件と面談を直す材料になり、候補者にも依頼側にも利益があります。候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に整理しています。

### 候補者から聞いたことを、依頼側にどこまで伝えてよいですか

面談の前に、候補者に「御社の採用の判断に要ることは依頼側に伝えます。個人的な事情や心情は、候補者の了解が無ければ伝えません」と示し、伝える範囲を決めておきます。採用の判断に要ること（転職の理由、求める条件、懸念）は伝え、家庭の事情や健康や過去の職場の人間関係など、判断に要らないことは伝えません。迷うときは、候補者に「これは依頼側に伝えてよいですか」と確認します。個人情報の線は[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に書いています。

### 相談の仕事（個人向け）と、企業側の副業を、同時にやってよいですか

同時にやること自体は可能ですが、二つの線を引きます。一つは、相談の仕事で受けた相談者を、副業の依頼側の候補者として紹介しないこと。相談者の立場を利用する形になり、相談の信頼を失います。もう一つは、副業の依頼側の候補者を、相談の仕事の相談者として扱わないこと。立場が混ざり、候補者にも依頼側にも不利益が出ます。二つの仕事の相手を、完全に分けます。資格に伴う規範や、職業紹介に関わる線は、個別の判断を専門家にご確認ください。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。
