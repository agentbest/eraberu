本業が忙しくなった、家族の事情が変わった、思ったより合わなかった。副業をやめたいが、今の案件をどうすればよいのか、依頼側や登録先にどう伝えればよいのか、やめたら二度と戻れないのかが分からない。結論を先に書くと、**副業をやめるなら、「今の案件を区切りまで終え、引き継ぎを残し、依頼側と登録先に理由を添えて伝え、再開できる形で閉じる」の順で進めます。やめる理由が何であれ、案件の途中で消える形でやめると、依頼側の信用と、登録先での評価と、戻れる道が全部消えます。逆に、区切りまで終えて丁寧に閉じれば、やめても関係は残り、事情が変わったときに再開できます。やめ方で、戻れる道が決まります。**引き継ぎの残し方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に、無理なときの伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、契約を切られたときの動き方は[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/)にまとめています。

## やめる判断の種類を分ける

「副業をやめたい」には、三つの種類があり、進め方が違います。まず、自分がどれかを決めます。

| 種類 | 状態 | 向いている場面 | 進め方の違い |
|---|---|---|---|
| 一時停止 | 一定の期間、新しい案件を受けない。今の案件は区切りまで終える。登録先の登録は残す | 本業の繁忙期、家族の事情、体調。数か月から一年で戻れそうなとき | 期間を決めて、依頼側と登録先に「〇月まで受けられない」と伝える |
| 縮小 | 案件の数か稼働を減らす。一件だけ残す、稼働を半分にする | 全部やめたいわけではなく、枠が減ったとき | 残す案件と、終える案件を決め、終える案件を区切りまで進める |
| 終了 | 副業を完全にやめる。登録先の登録も止める | 副業が合わなかった、本業に専念したい、転職や独立で副業の形が変わる | 全部の案件を区切りまで終え、引き継ぎを残し、登録先を退会するか休止にする |

種類の要点は、「終了」を選ぶ前に、「一時停止」か「縮小」で足りないかを見ることです。やめたいと感じるとき、多くは稼働が枠を超えているか、合わない案件が一件あるかのどちらかで、副業そのものが合わないわけではありません。一時停止か縮小で、稼働と合わない案件を外せば、続けられることがあります。それでも「終了」なら、終了として丁寧に閉じます。稼働の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、続かない原因は[案件が続かない原因の切り分け](/media/fukugyo-tsuzukanai/)に書いています。

## やめる前に確かめること

やめると決める前に、やめたい理由が、副業そのものの問題か、今の案件の問題か、枠の問題かを確かめます。

| 確かめること | 見方 | 分かったら |
|---|---|---|
| やめたい理由は、今の案件か、副業そのものか | 今の案件を終えたら続けたいか、別の案件でも同じか | 今の案件の問題なら、その案件を終えて続ける。[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/) |
| 稼働が枠を超えていないか | 週の稼働が、決めた枠の何倍になっているか | 枠を超えているなら、縮小で足りる |
| 本業や家族の事情は、一時的か | 繁忙期、家族の事情、体調が、数か月で変わるか | 一時的なら、一時停止で足りる |
| 副業の目的が果たされたか | 始めたときの目的（経験、収入、次の準備）が達成されたか | 達成されたなら、終了は自然な区切り |
| やめたら困ることがあるか | 収入、経験の継続、登録先の評価、依頼側との関係 | 困るものがあるなら、縮小か一時停止で残す |
| 疲れているだけではないか | 休みが取れていないか、今の案件が重いか | 休んでから決める。疲れているときの判断は終了に寄る |

確かめる要点は、「疲れているときに終了を決めない」ことです。やめたいと感じるときの多くは、稼働が枠を超えて疲れているか、合わない案件を抱えているときで、その状態で決めると、終了に寄ります。今の案件を区切りまで終え、少し休んでから決めると、一時停止や縮小で足りることが分かります。それでも終了なら、その判断は確かなものです。案件の重さの切り分けは[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に整理しています。

### エラベルの見解

担当する側から見ると、副業をやめた人のうち、後で戻ってきて続いている人と、戻れなくなった人の差は、やめた理由ではなく、やめ方です。案件を区切りまで終え、引き継ぎを残し、依頼側と登録先に理由を添えて伝えた人は、事情が変わって戻ってきたときに、依頼側の担当者が覚えていて、登録先の評価も残っていて、すぐに案件が始まっています。案件の途中で連絡が途絶えた人は、理由が本業の繁忙や体調であっても、依頼側と登録先に「途中で消える人」として残り、戻ってきても案件が回りにくくなっています。

見ていて差がつくのは、やめるときに「終了」と「一時停止」を分けて伝えているかです。「副業をやめます」と伝えると、依頼側と登録先は、その人を候補から外します。「〇月まで受けられませんが、その後は再開したい」と伝えると、候補に残り、時期が来たら声がかかります。同じ「今は受けない」でも、伝え方で戻れる道が変わります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、休止の設定と再開の連絡があれば、依頼側の候補に戻れる形にしています。やめ方は、やめた後の自分を守る作業です。

## 今の案件の終わらせ方

やめると決めても、今の案件は区切りまで終えます。終わらせ方の順番です。

| 順番 | 内容 |
|---|---|
| 一、契約の区切りを確認する | 契約期間、更新の時期、終了の予告の期間を、契約書で確認する |
| 二、区切りまでの範囲を決める | 区切りまでに終えること、終えないことを、依頼側と書面で決める。新しい範囲は受けない |
| 三、依頼側に、区切りで終えることを早めに伝える | 更新の一か月前など、契約に予告の期間があればそれに従う。無ければ、依頼側が次の手を打てる期間を取る |
| 四、引き継ぎの資料を残す | 記録、型、進行中の候補者の状態、依頼側の社内の連絡先を、依頼側が読める形に |
| 五、後任がいれば引き継ぐ | 依頼側が後任を決めたら、資料を渡し、質問に答える期間を取る |
| 六、終了時に一言添える | 「ここまでで区切りとさせてください。ありがとうございました」。再開の意思があれば、それも添える |
| 七、依頼側の情報を返す | 端末や資料に残る依頼側の情報を、契約に従って返すか削除する |
| 八、終了の確認を書面で残す | 終了日、引き継いだもの、未払いの精算を、メールなどで残す |

終わらせ方の要点は、「三」の、早めに伝えることです。依頼側は、担当者が抜けると、後任を探すか、社内で吸収するかを決める必要があり、そのための時間が要ります。直前に伝えると、依頼側の採用が止まり、信用が消えます。契約に予告の期間があればそれに従い、無くても、依頼側が次の手を打てる期間を取ります。引き継ぎの残し方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に、情報の返し方は[依頼側の情報の分け方](/media/fukugyo-jouhou-bunri/)に、契約期間の考え方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に書いています。

## 依頼側と登録先への伝え方

やめることを、依頼側と登録先にどう伝えるかで、戻れる道が変わります。

| 相手 | 伝えること | 伝え方 | 避けること |
|---|---|---|---|
| 依頼側の担当者 | 区切りで終えること、理由（一言）、引き継ぎの予定、再開の意思の有無 | 「本業の事情で、〇月の区切りで終えさせてください。引き継ぎの資料は〇日までに」と早めに、口頭と書面で | 理由を詳しく話す。依頼側への不満を理由にする。直前に伝える。連絡を絶つ |
| 登録先の窓口 | 一時停止か縮小か終了か、期間、理由（一言） | 「〇月まで新規は受けられません。今の案件は区切りまで終えます」。終了なら退会か休止の手続きを聞く | 案件の途中で登録を消す。窓口に伝えずに依頼側とだけ話す |
| 進行中の候補者（自分が連絡している場合） | 担当が変わること | 依頼側の担当者と相談し、依頼側から伝えてもらう形に | 自分から候補者に「やめる」と伝える |
| 同じ立場の仲間 | 一時停止か終了か、案件を回してもらう相手として残るか | 「〇月まで受けられない」「範囲に合う案件があれば、□□さんへ」 | 何も言わずに消える |
| 本業の会社（許可を得ていた場合） | 副業をやめること、または休止すること | 許可の手続きに従って報告する | 報告しない |

伝え方の要点は、「理由は一言で、不満は言わない」ことです。やめる理由が依頼側への不満であっても、それを理由として伝えると、関係が壊れ、戻れなくなります。「本業の事情で」「家族の事情で」と一言で伝え、丁寧に閉じます。不満があるなら、契約の区切りで終えることが、その不満への答えです。断り方の型は[断り方](/media/fukugyo-kotowaru/)に、無理なときの伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

## 再開できる形で閉じる

「終了」のつもりでも、事情は変わります。再開できる形で閉じておきます。

| 残すもの | 内容 |
|---|---|
| 登録先の登録 | 退会ではなく休止にできるなら、休止にする。プロフィールは残す |
| 依頼側の担当者との連絡の経路 | 副業用のメールは残す。終了時に「事情が変わったらお声がけください」と添える |
| 自分の記録 | 案件ごとの範囲、状態の変化、型を、依頼側の情報を含まない形で残す。再開時のプロフィールと職務経歴書に使う |
| 型と資料 | 求人票の型、スカウトの型、面接の準備資料の型など、自分が作った汎用の型は残す |
| 屋号・名刺・サイト | 屋号とサイトは残しても費用がかからなければ残す。有料のものは休止にする。[屋号を付けるか](/media/fukugyo-yagou/) |
| 同じ立場の仲間との関係 | 案件を回し合う関係は、副業をやめても残す。再開時の入口になる |
| 税と手続きの記録 | 副業の収入と経費の記録は、申告の期間に応じて残す。要否は専門家にご確認ください。[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/) |

残すものの要点は、「登録先の登録を消さない」ことです。副業を終了するとき、登録を全部消したくなりますが、再開するときに、登録先の評価と過去の案件の記録は、ゼロから作り直せません。休止にできるなら休止にし、プロフィールを残しておけば、再開時に条件を更新するだけで、候補に戻れます。記録の残し方は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に、再開時のプロフィールは[副業用の職務経歴書](/media/fukugyo-shokumu-keirekisho/)に書いています。

## やめた後に残るものと消えるもの

副業をやめると、何が残り、何が消えるかを分けておきます。丁寧に閉じるかどうかで、残るものが変わります。

| 残るもの（丁寧に閉じた場合） | 消えるもの（途中で消えた場合） |
|---|---|
| 依頼側の担当者の記憶。「頼んでよかった人」として残り、事情が変わったら声がかかる | 依頼側の記憶は「途中で消えた人」になり、声はかからない |
| 登録先の評価と過去の案件の記録 | 登録先の評価が下がり、候補から外れる |
| 副業で得た経験と型。本業にも転職にも使える | 経験は残るが、実績として書ける形（丁寧に終えた案件）がない |
| 同じ立場の仲間との関係。再開時の入口 | 仲間にも「消えた人」として残る |
| 自分の範囲の一言。再開時にそのまま使える | 範囲の一言は残るが、それを裏づける終え方がない |
| 再開の道。休止の登録、連絡の経路、記録 | 再開の道が細く、ゼロから作り直す |

残るものと消えるものの要点は、「副業をやめても、やめ方が丁寧なら、ほとんどのものが残る」ことです。副業で得た経験と型と関係は、やめても消えません。消えるのは、途中で消えた場合だけです。やめる理由が何であれ、区切りまで終え、引き継ぎを残し、理由を添えて伝え、再開できる形で閉じる。この順番で、副業は「やめたら終わり」ではなく、「いつでも戻れるもの」になります。副業で得たものの整理は[副業で学び続ける](/media/fukugyo-gakushuu/)に、次の選択肢は[次の案件につなげる](/media/fukugyo-tsugi-e/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「副業をやめるなら、依頼側に迷惑をかける前に、早く消えたほうがよい」というものです。実際には、早く消えることが、最も迷惑をかけるやめ方です。依頼側は、担当者が抜けた後の採用を止められず、後任を探すか、社内で吸収するかの時間が要ります。区切りまで終え、引き継ぎを残し、早めに伝えることが、依頼側への配慮であり、自分の戻れる道を残す方法でもあります。

順番として、やめる判断が一時停止か縮小か終了かを分け、疲れているときに終了を決めず、今の案件は契約の区切りまで終え、範囲を書面で決め、早めに伝え、引き継ぎの資料を残し、終了時に一言添え、依頼側の情報を返し、登録先には休止か終了かを伝え、登録と連絡の経路と記録を残して閉じる。この順番で、副業のやめ方は、消えるものではなく、閉じるものになります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、丁寧に閉じた担当者が休止から戻ってきたとき、依頼側の候補に戻れる形にしています。やめ方は、副業の最後の仕事であり、次の副業の最初の仕事です。

## まとめ

- 副業をやめるなら**今の案件を区切りまで終え、引き継ぎを残し、理由を添えて伝え、再開できる形で閉じる**
- やめる判断は**一時停止・縮小・終了**を分ける。終了の前に一時停止か縮小で足りないかを見る
- **疲れているときに終了を決めない**。今の案件を終えて休んでから決める
- 依頼側には**早めに、理由は一言、不満は言わず**、引き継ぎの予定と再開の意思を添えて伝える
- **登録先の登録は消さず休止に**。連絡の経路、記録、型、仲間との関係を残す
- 丁寧に閉じれば**依頼側の記憶・登録先の評価・経験と型・仲間・再開の道**が残る。途中で消えると全部消える

## よくある質問

### 本業が急に忙しくなり、今の案件を続けられません。すぐにやめてよいですか

すぐに消える形は避け、依頼側に「本業の事情で稼働が取れなくなった」と早めに伝え、区切りまでの範囲を相談します。区切りまで続けられないなら、「〇日までに引き継ぎの資料を残し、△日で終えさせてください」と、依頼側が次の手を打てる期間を取ります。契約に終了の予告の期間があれば、それに従います。稼働を減らして続けられるなら、縮小を先に提案します。無理なときの伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、稼働の相談は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に整理しています。

### 依頼側との関係が原因でやめたいのですが、理由をどう伝えればよいですか

依頼側への不満を理由として伝えることは避けます。「本業の事情で」「稼働の枠が取れなくなったので」と一言で伝え、契約の区切りで終えます。不満を伝えても、関係が良くなることはなく、戻れる道が消えるだけです。契約の区切りで終えることが、その不満への答えです。登録先を通した案件なら、窓口に事情を伝えておくと、次の案件の選び方に活かせます。契約の区切りの考え方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に書いています。

### 一度やめてから、再開するときは何から始めればよいですか

登録先の登録を休止にしていれば、プロフィールと条件を更新して再開します。以前の依頼側の担当者に、「事情が落ち着いたので、〇〇の範囲で再開しました」と一言送ります。範囲の一言と、過去の案件の記録が残っていれば、プロフィールと職務経歴書はすぐに作れます。再開時は、稼働の枠を以前より小さめに置き、続けられることを確かめてから広げます。声がかかる状態の作り方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に整理しています。
