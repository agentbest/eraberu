採用戦略の壁打ちを初めて受けるとき、見えにくいのは「打ち合わせの前後に何をするか」です。募集文には「採用アドバイザー」「月に二回の打ち合わせ」とだけあり、実際には、打ち合わせの前に前回の数を読んで選択肢の構造を用意し、打ち合わせの後に決めたことと理由と見る数を書面にして両方に送る。この前後が無い壁打ちは、話して終わり、三か月で「何が変わったか」を問われて終わります。結論を先に書くと、**1案件は「契約前→初回→二回目以降→区切り→終了と更新」の五つの段階で進み、契約前に範囲・回数と時間・相手・数を出す人・実行する人・書面の型・採用以外の相談の扱い・評価を決め、初回は全体を聞いて数の有無を確かめてずれている箇所を一つに絞り、二回目以降は前回の書面と数から始めて選択肢を出し会社が決めて書面にし、三か月ごとの区切りで決めたことと数の推移を並べて続ける形を見直し、引き継げる形で終えます。**案件の型と求められる経験は[採用戦略の壁打ちの副業案件](/media/fukugyo-saiyo-senryaku-fukugyo/)に、初回の打ち合わせの一般的な進め方は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に書いていますので、ここでは「壁打ちの1案件の流れ」に絞ります。

## 契約前：決めておくこと

壁打ちは、範囲が曖昧なまま始まりやすい仕事です。「相談相手」という言葉の中に、何が入り何が入らないかを、契約前に決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 単発か、月次か、計画作りの伴走か、人事の責任者の相談相手か。実行を含まないこと | 「じゃあやってください」と実行を持たされる |
| 回数と一回の時間 | 月に何回、一回何分。準備と書面の時間を含めた見積もり | 当日の時間だけで見積もり、準備と書面が無償になる |
| 相手は誰か | 経営者か、人事の責任者か、両方か。現場に聞けるか | 人事の責任者と話した内容が経営者に届かない |
| 数を出す人 | 毎月、応募・面接・内定・承諾・辞退・経路の内訳を誰が出すか。出せないなら最初の一回で表を作るか | 印象の話で終わる |
| 実行する人 | 決めたことを誰が実行するか。いないなら実行は別の範囲として見積もるか | 決めても動かず、毎回同じ話になる |
| 書面の型 | 決めたこと・理由・見る数・次回、の四つ。誰に送るか | 話が残らず、三か月後に何が変わったか言えない |
| 採用以外の相談の扱い | 評価、組織、退職などの相談が来たときの扱い（区切りで別に、範囲外として記録） | 範囲が広がり、採用の話が薄くなる |
| 評価 | 何で評価されるか（決めたことの数と実行、数の推移、書面の質か。採用の人数か） | 実行されなかった結果で評価される |

止まりやすいのは、「まず一度お話を」で始めて、そのまま契約になるときです。一度目の話のあとに、範囲と数を出す人と実行する人と書面の型を書面にして、契約にします。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 初回：全体を聞き、数を確かめ、一つに絞る

初回は、選択肢を出しません。いまの採用の全体を聞き、数があるかを確かめ、ずれている箇所を一つに絞り、書面にします。初回から「こうすべき」を言うと、前の会社の正解を押しつける形になります。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 全体を聞く（人数の計画、経路とその配分、要件、選考の段階と速さ、条件、定着、誰が何を決めているか） | 経営者か人事の責任者の時間。過去の数 | 「何に困っていますか」から入り、困っている箇所だけを聞く |
| 数の有無を確かめる（応募・面接・内定・承諾・辞退・経路の内訳が、月ごとに出るか） | 数の共有 | 数が無いまま次に進む |
| 数が無いなら、数を出す表を一緒に作る（項目、出す人、出す日） | 出す人の確定 | 自分が数を集める役になる |
| ずれている箇所を一つに絞る（経路か、要件か、選考の速さか、条件か、定着か。数と構造で） | 絞ることへの合意 | 全部を並べて、全部を直そうとする |
| 書面（聞いたこと、数の状態、絞った箇所と理由、次回に持ってきてもらう数、次回の日程） | 書面を読む時間 | 書面を送らない |

止まりやすいのは、初回で経営者が「うちの課題はこれだ」と言い、その話だけで終わるときです。経営者が言う課題は、全体の一部です。全体を聞いてから、数と構造で絞ります。絞り方は[課題の言語化](/media/fukugyo-kadai-teigi/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「初回に数の有無を確かめて、無ければ表を作る回に変えられるか」で、その後の全部が決まります。数が無いまま月次の壁打ちを始めると、二回目も三回目も、経営者の印象と担当者の一般論の話になり、「決めたこと」が数で確かめられず、契約が終わります。エラベルで担当者を選ぶ企業には、「初回は全体を聞いて数の状態を確かめます。数が無ければ、最初の一か月は数を出す表を作ることに使います」と、私たちから先に伝えています。受ける側がその場で使える判断としては、初回の書面に「数の状態」の欄を作っておくこと。「応募と面接は出るが、経路の内訳と辞退の理由が出ない」と書いておけば、二回目に何を持ってきてもらうかが決まります。数の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 二回目以降：前回の書面と数から始め、選択肢を出し、会社が決め、書面に

二回目から、壁打ちの本体です。毎回、同じ順で進めます。

| 順 | やること | 落とし穴 |
|---|---|---|
| 準備（前日まで） | 前回の書面を開き、持ってきてもらう数を確認し、絞った箇所について選択肢の構造（二〜三つ、それぞれの数の見込みの構造・要る資源・期間・外に出せる部分）を用意する | 準備せずに当日に考える |
| 始め方 | 前回の書面の「決めたこと」と「見る数」から始める。「何が動きましたか。数はどう変わりましたか」 | 「最近どうですか」から始める |
| 選択肢を出す | 絞った箇所について、「AならこうBならこう」を数と構造で並べる。自分の見立てがあれば理由付きで添える | 「こうすべき」で押す。選択肢が一つ |
| 会社が決める | その場で決めるか、次回までに決めるか、決めないか。決めない選択も書面に | 決めるまで待てず、自分が決める |
| 書面（当日か翌日） | 決めたこと・理由・見る数・次回、の四つ。両方に送る。前回からの変化が分かる形 | 送らない。長すぎて読まれない |
| 範囲外の記録 | 採用以外の相談、実行の依頼は、書面の「範囲外」の欄に記録し、区切りで扱う | その場で引き受ける |

止まりやすいのは、始め方を「最近どうですか」にして、経営者の近況の話で時間が過ぎることです。前回の書面から始めれば、話は決めたことに戻ります。選択肢の出し方は[提案のまとめ方](/media/fukugyo-teian/)に、書面の残し方は[議事録の残し方](/media/fukugyo-gijiroku/)に、範囲外の扱いは[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に書いています。

## 区切り：三か月ごとに、決めたことと数の推移を並べる

三か月ごとに、区切りの回を持ちます。見るのは、その月の数ではなく、「決めたこと」の一覧と、数の推移です。

| 見ること | 読み方 | 次の形 |
|---|---|---|
| 決めたことの一覧と、実行されたか | 決めたが実行されないことが多いなら、実行する人がいない | 実行の体制を会社に決めてもらう。壁打ちの回数を減らす |
| 数の推移（絞った箇所の数が動いたか） | 動いたなら、次に絞る箇所へ。動かないなら、絞った箇所が違ったか、実行が足りないか | 次の三か月で絞る箇所を決める |
| 範囲外の記録 | 採用以外の相談が多いなら、経営者の関心が採用から離れている | 範囲を広げる（別の見積もり）か、回数を減らすか、型を残して終えるか |
| 書面が読まれているか | 前回の書面を開いても経営者が覚えていないなら、書面が長い | 書面を短くする |

止まりやすいのは、区切りを持たずに月次を続けるときです。同じ話が三回続いていても、区切りが無いと気づけません。三か月ごとに、続ける形を会社と一緒に見直します。経営者の関心が離れたときの二択は[経営者直下の案件](/media/fukugyo-keieisha-chokka/)に書いています。

### エラベルの見解

同じ料金・同じ回数でも、結果が分かれるのは、区切りの回で「決めたことの一覧を並べられるか」です。書面を残していない担当者は、三か月後に「何が変わったか」を問われて、「いろいろ相談に乗りました」としか言えず、契約が終わります。毎回の書面を残していた担当者は、「この三か月で決めたことは七つ、実行されたのは五つ、絞った箇所の数はこう動きました。実行されなかった二つは、実行する人がいなかったので、次の三か月はそこを決めましょう」と並べられ、契約が続き、範囲の見直しの話ができます。壁打ちの成果は、話の質ではなく、書面の積み重ねで見えます。エラベルで長く続いている担当者は、区切りの回の資料を、毎回の書面をそのまま並べるだけで作っています。受ける側がその場で使える形としては、毎回の書面を一つの表に積んでいくこと。区切りの資料を別に作らないことが、続ける秘訣です。

## 終了と更新：引き継ぎと次の提案

契約の期間が来たら、更新か終了かを会社が決めます。どちらでも、引き継げる形にして終えます。

- **残すもの。** 決めたことと理由と見る数の一覧（全回分）、数を出す表とその出し方、絞った箇所の推移、範囲外の記録
- **返すもの。** 共有された資料、数の表へのアクセス。会社の採用の数と条件を、自分の手元に残さず、他の依頼側に話さない
- **次の提案。** 更新するなら、次の三か月で絞る箇所と回数。終了するなら、社内で月次の見直しを回す型（書面の型と、数を見る順）

止まりやすいのは、終了時に「またいつでも」で終わり、型を残さないことです。書面の型と数を見る順を残せば、会社は自分たちで月次の見直しを回せます。引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 情報の扱い

壁打ちでは、会社の採用の数、条件、予算、経営者の考え、組織の事情を聞きます。それを他の依頼側や本業に持ち込みません。逆に、本業や他の依頼側の数や条件を、この会社の判断の材料にしません。公開されている構造の話に留めます。書面は会社の管理する場所に置くか、両方に送って自分の手元には残さない形にします。経営者から聞いた組織や個人の事情は、書面に書かず、会社の外で話しません。利益相反の見分け方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 稼働時間は何で決まるか

一回の壁打ちにかかる時間は、当日の時間だけでなく、「準備（前回の書面と数を読み、選択肢の構造を用意する）」と「書面（決めたことと理由と見る数を書いて送る）」を足したものです。準備と書面を足すと、当日の倍近くになることが多い。受ける前に「一回あたり、準備と書面でどれだけ足すか」を決めて見積もりに入れます。数を出す表を作る回や、計画作りの伴走は、通常の回より長くなります。数値は案件ごとに違うので、最初の三か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→初回→二回目以降→区切り→終了と更新**の五つの段階
- 契約前に**範囲・回数と時間・相手・数を出す人・実行する人・書面の型・採用以外の扱い・評価**を決める。「まず一度」のあとに書面にして契約に
- 初回は**全体を聞き、数の有無を確かめ、一つに絞り、書面に**。選択肢は出さない。数が無ければ表を作る回に変える
- 二回目以降は**前回の書面と数から始める→選択肢を数と構造で→会社が決める→当日か翌日に書面→範囲外は記録**。「最近どうですか」から始めない
- 区切りは**三か月ごとに決めたことの一覧と数の推移を並べ、続ける形を見直す**。毎回の書面を一つの表に積んでおく
- 終了時は**一覧・数の表・推移・範囲外の記録**を残し、社内で回す型を渡す
- 会社の数と条件は**他に持ち込まず、他の数と条件をこの会社に持ち込まない**

## よくある質問

### 経営者が打ち合わせの日程を直前に動かします

壁打ちは経営者の予定に左右されやすい仕事です。契約前に、月の回数を「実施できた回数」ではなく「確保した枠」で数える形にし、直前の変更の扱い（前日までの変更は振り替え、当日の変更は実施扱い、など）を決めておきます。決めていないと、準備した回が流れ、準備の時間が無償になります。動くことが続くなら、区切りの回で、経営者の関心が採用から離れていないかを見ます。

### 人事の責任者の相談相手として入っていて、経営者には会えません

人事の責任者が経営者に出す提案を、一緒に整理するのが仕事になります。書面は、人事の責任者が経営者にそのまま出せる形（選択肢と数と構造）で作ります。経営者の反応は人事の責任者から聞き、次回に反映します。経営者に直接会えないことは問題ではありませんが、「経営者が何を決めたか」が書面に残る形にしないと、決めたことが追えません。人事の責任者に、経営者の決定を書面に書き足してもらいます。

### 「こうすべき」と言わないと、頼りないと思われませんか

自分の見立てを、理由と数と構造を付けて「私ならこちらを選びます」と言うのは構いません。避けるのは、理由の無い断定と、会社が違う選択をしたときに引き下がらないことです。選択肢を出し切ったうえで見立てを添える人は、頼りないとは思われません。逆に、選択肢を出さずに「こうすべき」だけを言う人は、二回目までは頼もしく見えて、三回目に「うちには合わない」と言われます。
