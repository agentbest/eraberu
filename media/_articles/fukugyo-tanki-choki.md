依頼側は「早く応募を増やしてほしい」と言う。自分から見ると、求人票も選考の流れも整っていないので、先にそこを直さないと応募が来ても決まらない。仕組みを整えたいが、それには時間がかかり、その間に「何も変わらない」と思われそうだ。結論を先に書くと、**短期の成果と中長期の施策は、どちらかを選ぶものではなく、順番の問題です。最初の数週間で目に見える成果を一つ出し、その信頼を使って中長期の型づくりを通します。順番を逆にして型づくりから始めると、依頼側には「何も動いていない」と映り、型ができる前に契約が切れます。**短期の成果は、中長期の施策の一部を切り出して先に出す形にすると、二つが別の作業になりません。最初の数週間の進め方は[早い段階で成果を出す](/media/fukugyo-quick-win/)に、依頼側の期待のすり合わせは[期待値のすり合わせ](/media/fukugyo-kitai-chousei/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)にまとめています。

## 短期と中長期がぶつかる構造

依頼側と外部の担当者で、見ている時間の長さが違います。この差が、ぶつかりの元です。

| 立場 | 見ている時間 | 求めるもの | 不安 |
|---|---|---|---|
| 依頼側の担当者 | 今月から数か月 | 応募が増える、面接が入る、内定が出る | 外部に頼んだのに何も変わらない、と上長に言われる |
| 依頼側の上長 | 四半期から半年 | 採用の数字。予算に見合う成果 | 外部の費用が無駄になっている |
| 外部の担当者（自分） | 半年から一年 | 求人票、選考の流れ、媒体の運用の型が整い、自走できる状態 | 型を整える前に、応募だけ増やしても決まらず、評価が下がる |

構造の要点は、「依頼側の担当者の不安は、上長への説明にある」ことです。担当者は、外部に頼んだことを社内で説明する立場で、数週間で何も見せられないと、担当者自身の立場が危うくなります。自分が中長期を見ていても、担当者が短期で説明できるものを渡さないと、担当者は自分を守れず、契約を続ける理由を失います。依頼側の社内の構造は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に書いています。

## 順番を決める理由

短期を先にするのは、依頼側に合わせるためだけではなく、中長期の施策を通すためでもあります。

| 短期を先にする理由 | 内容 |
|---|---|
| 信頼が無いと中長期の提案は通らない | 「求人票を直したい」「選考の流れを変えたい」は、依頼側の社内に踏み込む提案。何も出していない外部の人の提案は通らない |
| 短期の成果が、中長期の必要性を示す | 応募が増えたのに決まらなければ、依頼側は「選考の流れに問題がある」と自分で気づく。外部が言うより早い |
| 担当者が社内で説明できる | 短期の成果があれば、担当者は上長に「動いている」と言え、中長期の施策の時間を確保できる |
| 現状の把握が進む | 短期の成果を出す過程で、依頼側の実態（応募の経路、辞退の理由、面接官の時間）が見える。中長期の施策の精度が上がる。[現状把握のしかた](/media/fukugyo-genjou-haaku/) |
| 契約が続く | 短期の成果が無いまま数か月経つと、更新されない。中長期の施策は、契約が続いて初めて意味を持つ |

理由の要点は、「中長期の施策は、依頼側の社内に踏み込む提案なので、信頼が先に要る」ことです。求人票の要件を絞る、面接官の時間を固定する、選考の段階を減らす。どれも依頼側の社内の決め方を変える提案で、外部の人が最初から言っても通りません。短期の成果で「この人の言うことは当たる」と思われてから言うと、通ります。提案の通し方は[提案の仕方](/media/fukugyo-teian/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「依頼側が短期の成果ばかり求めるのは、採用を分かっていないからだ」というものです。実際には、依頼側の担当者は、採用に時間がかかることを分かっていることが多く、それでも短期の成果を求めるのは、社内で説明する材料が要るからです。担当者を「分かっていない人」と見て中長期の話を続けると、担当者は社内で説明できず、外部の担当者を守れなくなります。

見ていて差がつくのは、中長期の施策を「担当者が社内で説明できる形」に切り出しているかです。「選考の流れを整えます」は説明しにくく、「面接の日程が組めずに辞退している候補者を減らすため、面接官の枠を週に固定します」は説明できます。後者は中長期の施策の一部ですが、担当者は上長に「辞退が減る」と説明でき、数週間で結果も見えます。エラベルでは、担当者が依頼側と最初に話すとき、最初の数週間で見せるものと、その後に整えるものを分けて伝える形をお願いしています。分けて伝えられる担当者は、中長期の施策まで任されています。

## 最初に出す短期の成果の選び方

短期の成果は、何でもよいわけではありません。中長期の施策につながるものを選びます。

| 選ぶ基準 | 内容 | 例 |
|---|---|---|
| 数週間で見える | 一か月以内に、依頼側が「変わった」と分かる | スカウトの返信が来始める、面接の日程が組めるようになる |
| 依頼側の管理の数字で見える | 自分の推定ではなく、依頼側のATSや媒体の管理画面で見える | 返信数、面接の設定数、辞退の理由の内訳 |
| 中長期の施策の一部である | 型づくりの最初の一歩になっている。後で捨てるものではない | 文面の型を作って送る（型が残る）、面接の枠を固定する（流れの一部が整う） |
| 依頼側の社内を変えずにできる | 最初の数週間は、依頼側の決め方に踏み込まずにできることを選ぶ | 求人票を変えずに、スカウトの相手の絞り方を変える |
| 失敗しても損が小さい | 効かなかったときに、依頼側の採用が悪くならない | 文面を変える（戻せる）、送る相手を変える（戻せる） |

選び方の要点は、「中長期の施策の一部である」ことです。短期の成果のために、後で捨てる作業をすると、二重の稼働になります。文面の型を作って送れば、返信が短期の成果で、型が中長期の資産です。面接の枠を固定すれば、辞退の減少が短期の成果で、枠の運用が選考の流れの一部です。短期と中長期を別の作業にせず、同じ作業の「早く見える部分」と「後に残る部分」として設計します。最初の数週間の具体的な進め方は[早い段階で成果を出す](/media/fukugyo-quick-win/)に、案件の最初の時期の全体は[案件の最初の時期の進め方](/media/fukugyo-shoki-90nichi/)に書いています。

## 中長期の施策を短期の成果に乗せて通す

短期の成果が出たら、その結果を使って中長期の施策を提案します。提案は、短期の成果の延長として出します。

| 短期の成果 | それが示すこと | 乗せる中長期の施策 |
|---|---|---|
| スカウトの返信が来始めた | 相手の絞り方と文面が合っている | 「返信の質を上げるため、求人票の要件を三つに絞りたい」 |
| 面接の枠を固定して辞退が減った | 日程の問題が辞退の原因だった | 「選考の段階を一つ減らし、内定までの期間を短くしたい」 |
| 返信は来たが面接に進まない | 一次対応か面接の内容に問題がある | 「面接官に渡す準備の資料を型にしたい」 |
| 面接に進んだが内定を辞退される | 条件の提示か、内定後の連絡に問題がある | 「内定者への連絡の型と、条件の提示の順番を整えたい」 |
| 応募は増えたが、担当者の対応が追いつかない | 社内の工数が足りない | 「一次対応の範囲を私に広げるか、記録の型で担当者の手間を減らしたい」 |

乗せ方の要点は、「短期の成果の結果が、次の問題を示している」形にすることです。「返信は来たが面接に進まない」という結果は、依頼側が自分で見て分かります。そこで「面接の準備を整えたい」と言えば、依頼側は「そうだね」となります。結果を見せずに「面接の準備を整えたい」と言えば、「なぜ」となります。中長期の施策は、自分の意見ではなく、短期の結果が示した次の課題として出します。課題の定義の仕方は[課題の定義のしかた](/media/fukugyo-kadai-teigi/)に整理しています。

## 依頼側との配分の合意

短期と中長期の配分は、自分の中で決めるだけでなく、依頼側と合意しておきます。合意が無いと、中長期の稼働が「何をしているか分からない時間」に見えます。

| 合意すること | 内容 |
|---|---|
| 最初の数週間の目標 | 「まず〇〇を動かし、〇週間後に返信の状況を見る」と、短期の成果の中身と時期を決める |
| その後の配分 | 「短期の成果が出たら、稼働の一部を型づくりに使う」と、配分が変わることを先に伝える |
| 中長期の施策の中身と時期 | 「〇か月目から求人票と選考の流れを整える。効果が見えるのは〇か月後」と、時間がかかることを先に伝える |
| 稼働報告での見せ方 | 短期の成果と中長期の施策を、報告の中で分けて書く。「今月の結果」と「整えていること」を別の欄に。[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/) |
| 配分を見直す節目 | 「〇か月目の定例で配分を見直す」と、節目を決めておく |

合意の要点は、「配分が変わることを先に伝える」ことです。最初の数週間は短期に全振りし、その後に中長期の稼働が増える。この変化を伝えずに稼働の中身を変えると、依頼側は「最近、成果が見えなくなった」と感じます。先に伝えていれば、「型づくりの時期に入った」と理解されます。期待のすり合わせは[期待値のすり合わせ](/media/fukugyo-kitai-chousei/)に書いています。

## 途中で配分を直す節目

配分は固定ではなく、節目で直します。直す節目を決めておくと、迷いません。

| 節目 | 見ること | 直し方 |
|---|---|---|
| 短期の成果が出たとき | 依頼側の担当者が社内で説明できる状態になったか | 中長期の稼働を増やす。短期の成果の維持は最小の稼働で |
| 短期の成果が出ないとき | 選んだ短期の成果が合っていたか。数週間で見えるものだったか | 別の短期の成果に切り替える。中長期はまだ始めない |
| 中長期の施策の効果が見えたとき | 型が回り始め、依頼側の社内で使われているか | 次の中長期の施策に移るか、稼働を減らして維持に回るか |
| 依頼側の採用の山 | 面接や内定が集中する時期 | 中長期の施策を一時止め、短期の対応に戻す。山が過ぎたら戻す |
| 契約の更新 | 短期と中長期の両方の成果を並べて、次の期の配分を決める。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) | 次の期は、型が整った分、短期の稼働が減り、中長期か維持に回る |
| 依頼側の担当者が替わったとき | 新任は短期の成果を求める。中長期の施策の途中でも、新任向けに短期の成果をもう一度出す | 一時的に短期に戻し、信頼を作り直してから中長期に戻る |

節目の要点は、「依頼側の担当者が替わったら、短期からやり直す」ことです。前任との信頼で通っていた中長期の施策は、新任には「何をしているか分からない時間」です。新任が社内で説明できる短期の成果を、もう一度出してから、中長期に戻ります。担当者の交代への備えは[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)にも書いています。

## 短期だけを求められ続けるときの扱い

短期の成果を出しても、依頼側が中長期の施策に関心を示さず、短期の成果だけを求め続けることがあります。

| 状況 | 扱い |
|---|---|
| 担当者は理解しているが、上長が短期しか見ない | 担当者と一緒に、上長向けの説明を作る。「短期の成果を続けるには、型が要る」と、短期の維持の話として中長期を出す |
| 依頼側が「型は要らない、応募だけ増やしてほしい」と明言している | 範囲をそこに絞る。型づくりは自分の側で最小限にし、依頼側には求めない。中長期を無理に通さない |
| 短期の成果が頭打ちになった | 頭打ちの理由が中長期の施策の不在にあることを、結果で示す。「返信は来るが決まらない」という数字を依頼側の管理の数字で見せる |
| 短期の稼働だけで枠が埋まる | 中長期の稼働が取れないなら、それは範囲と稼働の話。更新のときに配分を提案する |
| それでも変わらない | 依頼側の判断として受け入れる。自分の評価は、依頼側が求めたものを出したかで決まる。型づくりは次の案件で |

扱いの要点は、「中長期を無理に通さない」ことです。依頼側が短期だけを求めていて、それが依頼側の判断なら、外部の担当者はその範囲で成果を出すのが役割です。中長期の施策が要ると自分が思っていても、依頼側が求めていないなら、それは自分の意見であって、依頼側の課題ではありません。依頼側の判断に踏み込む線は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)に、範囲の線は[受ける範囲の決め方](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、中長期の施策まで任されている人は、最初の数週間で短期の成果を出し、その結果を根拠に中長期を提案し、依頼側と配分を合意しています。中長期から始めた人は、型が整う前に「何も変わらない」と言われ、更新されずに終わっています。どちらも中長期を見ていて、違うのは順番だけです。

順番として、案件の最初に「数週間で見せるもの」と「その後に整えるもの」を分けて依頼側に伝え、まず前者を出し、その結果を根拠に後者を提案し、配分が変わることを先に伝え、節目で直す。この順番なら、短期と中長期はぶつからず、同じ作業の早く見える部分と後に残る部分になります。エラベルでは、依頼側が担当者を選ぶとき、「最初の数週間で何を見せるか」と「その後にどう整えるか」を分けて話せる担当者が選ばれています。短期と中長期は、どちらかではなく、順番です。

## まとめ

- 短期と中長期は**どちらかではなく順番**。最初の数週間で目に見える一つを出し、その信頼で中長期を通す
- ぶつかる構造は**依頼側の担当者が社内で説明する材料を求めている**こと。担当者を守れる短期の成果が要る
- 短期の成果は**数週間で見え・依頼側の管理の数字で見え・中長期の施策の一部であり・社内を変えずにでき・失敗しても損が小さい**ものを選ぶ
- 中長期の施策は**短期の結果が示した次の課題**として出す。自分の意見ではなく、結果の延長で
- 配分は**依頼側と合意**し、**変わることを先に伝え**、稼働報告で分けて見せる
- 節目で直す。**担当者が替わったら短期からやり直す**。短期だけを求められ続けるなら**無理に通さず、依頼側の判断として受け入れる**

## よくある質問

### 短期の成果が出るまでに、想定より時間がかかっています

数週間で見える成果を選んだつもりでも、依頼側の事情（面接官の時間、承認の流れ）で遅れることがあります。遅れている理由が自分の側なら短期の成果を切り替え、依頼側の側なら、その事情を依頼側の担当者と共有し、「〇〇が整えば〇週間で見える」と、依頼側の側で動かせることを示します。遅れの理由を報告に書いておけば、「何も出ていない」ではなく「ここで止まっている」と伝わります。報告の書き方は[報告のしかた](/media/fukugyo-houkoku/)に整理しています。

### 中長期の施策に、依頼側の社内の協力が要りますが、協力が得られません

面接官の時間の確保、求人票の承認、選考の流れの変更は、依頼側の社内の決め方に関わり、外部の担当者だけでは動かせません。担当者に「この施策には〇〇の協力が要る。得られないなら、この施策は保留にし、得られる範囲でできる〇〇に切り替える」と伝え、依頼側に選んでもらいます。協力が得られないまま施策を進めると、稼働だけが使われて結果が出ず、評価が下がります。社内の協力が要る場面の動き方は[現場との調整](/media/fukugyo-genba-chousei/)に書いています。

### 中長期の型が整ったら、自分の稼働が減って契約が終わりませんか

型が整うと、短期の稼働は減りますが、型の維持と改良、次の課題への対応は残ります。依頼側が「型が整ったので自走する」と判断すれば、それは契約の自然な終わり方で、依頼側の評価は高く、次の紹介につながります。型を整えないことで契約を延ばそうとするより、整えて終えるほうが、次の案件の入口が増えます。契約の続け方は[継続してもらうために](/media/fukugyo-keizoku/)に、終わり方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に整理しています。
