リモートで進めてきた副業の案件で、初めて対面の打ち合わせが入った。先方は名刺を出すだろうから、こちらも何か渡すべきだが、本業の名刺を渡すわけにはいかない。副業用に作るとしても、会社名の欄に何を書き、肩書を何にするかが決まらない。結論を先に書くと、**本業の名刺は副業では使わず、対面の予定が決まってから、副業用の名刺を一種類だけ作れば足ります。書くのは「公開する名前」「肩書ではなく担当できる業務の範囲」「副業用の連絡先」の三つで、会社名の欄は無くて構いません。**リモートで完結する案件のうちは、名刺そのものが要りません。対面が発生する場面の整理は[対面が必要になる場面](/media/fukugyo-taimen/)に、公開する名前の決め方は[本名を出さずに受けられるか](/media/fukugyo-honmyo/)にまとめています。

## 本業の名刺を使ってはいけない理由

手元にあるからと本業の名刺を渡すのは、副業の中で最も避けたいことの一つです。渡した瞬間に、副業の相手に本業の会社名と部署と連絡先が伝わり、以後の連絡が本業の窓口に届く可能性が生まれます。

| 起きること | 何が問題か |
|---|---|
| 本業の会社名が副業の相手に伝わる | 副業の相手が本業の会社に連絡を取れる。本業に副業が知られる経路になる |
| 本業の会社の名前で副業をしているように見える | 相手は「その会社の人が来た」と受け取る。会社の信用を副業に使う形になり、本業の規定に触れることがある |
| 本業の連絡先に副業の連絡が届く | 本業のメールや電話に副業の案件の話が入り、本業の情報と混ざる |
| 本業の会社と副業の相手が同業だった場合 | 利益相反の問題が表に出る。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |

本業の名刺は、本業の会社が自社の業務のために持たせているもので、副業の場で使うことは、多くの会社で想定されていません。規定に明記が無くても、会社の名前と信用を私的な仕事に使ったと受け取られれば、副業の許可そのものに影響します。就業規則の扱いは会社で違うので、個別の判断は専門家にご確認ください。

「名刺が無いと失礼になる」と考えて本業の名刺を出すくらいなら、名刺を持たずに「副業で受けており、名刺は用意していません」と言うほうが、相手の受け取り方は良い傾向があります。副業で受けていることは相手も知っているので、名刺が無いこと自体は問題になりません。

## 名刺が要る場面と要らない場面

副業の案件で名刺が要る場面は、思っているより少ないです。作る前に、自分の案件で対面がどのくらい発生するかを見ます。

| 場面 | 名刺が要るか |
|---|---|
| リモートの定例、チャットでのやり取り | 要らない。登録先のプロフィールと契約書で相手は把握している |
| 依頼側との初回の対面の打ち合わせ | あるとよい。相手が出すので、こちらも渡せると話が早い |
| 依頼側の社内の関係者（現場の面接官など）に紹介される場面 | あるとよい。担当者以外に、誰が来ているかを伝える手段になる |
| 候補者との面談に同席する場面 | 慎重に。候補者に副業の担当者の連絡先を渡すかは、依頼側と決める |
| 依頼側の代理として外部（媒体の営業、紹介会社）と会う場面 | 依頼側と相談する。依頼側の名前で動くなら、依頼側が用意する名刺の話になる |
| 勉強会や交流会 | あるとよい。案件の入口になることがある。[勉強会や交流会の使い方](/media/fukugyo-benkyoukai/) |

要点は、「依頼側の社内の人に紹介される場面」と「候補者と会う場面」を分けて考えることです。前者は、自分が誰かを伝える名刺で足ります。後者は、候補者に副業の担当者の個人の連絡先を渡すことになるので、依頼側の窓口を通す形にするのが一般的で、自分の名刺を渡すかどうかは依頼側の判断に合わせます。候補者との接し方の線引きは[候補者への対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「副業用の名刺には、それらしい会社名か屋号が要る」というものです。実際には、依頼側は名刺の会社名で判断していません。副業で受けていることは契約の時点で分かっているので、名刺に会社名が無くても「個人で受けている人」として受け取られるだけです。むしろ、実態の無い屋号や、法人のような名前を載せると、依頼側の経理や法務が「契約の相手はこの名前の会社なのか、個人なのか」と確認に来て、手間が増えます。

依頼側が名刺で見ているのは、名前の読み方、連絡先、この人に何を頼めるかの三つです。肩書の欄に「採用担当」「人事コンサルタント」と書くより、「スカウト運用・求人票作成」のように担当できる業務を書くほうが、相手はその場で話を範囲に寄せられます。名刺は自分を大きく見せる道具ではなく、相手が範囲を思い出す道具だと考えると、書くものが決まります。

## 副業用に作るときの項目の決め方

対面の予定が決まったら、副業用の名刺を一種類だけ作ります。項目は少ないほうがよく、迷いやすい欄ごとに、書くものと書かないものを決めておきます。

| 欄 | 書くもの | 書かないもの |
|---|---|---|
| 名前 | 公開する名前。契約の名前と分けている場合は、公開のほうを書き、契約書との対応は依頼側に伝えておく | 本業の会社での通称や、本名を出さないと決めているなら本名 |
| 会社名・屋号 | 無くてよい。開業していて屋号があれば書いてもよい | 本業の会社名。法人に見える架空の名前 |
| 肩書 | 担当できる業務の範囲。「採用オペレーション支援」「スカウト運用・求人票作成」など | 「代表」「コンサルタント」のように範囲が分からない語。本業の役職 |
| 連絡先 | 副業用のメールアドレス。必要なら副業用の電話番号 | 本業のアドレス。個人の私用の電話番号 |
| 住所 | 無くてよい。求められることはほとんどない | 自宅の住所。本業の会社の住所 |
| サイト・SNS | 副業用のプロフィールがあれば載せる | 本業に関わるもの |

肩書の欄が最も迷うところですが、ここは「範囲」で書くと決めると楽になります。範囲の切り方は登録先のプロフィールと同じで、[受ける範囲の決め方](/media/fukugyo-scope/)の考え方をそのまま使えます。プロフィールの一行目と名刺の肩書を同じ言葉にしておくと、依頼側が登録先で見た情報と、名刺の情報が一致し、相手が混乱しません。

連絡先は、副業用に分けたものを載せます。本業のアドレスや私用の電話番号を載せると、副業の連絡が本業や私生活に入り込みます。メールアドレスと端末の分け方は[情報の取り扱いと端末の分離](/media/fukugyo-security/)に、副業用のメールの運用は[メールの書き方と運用](/media/fukugyo-mail/)に整理しています。

## 渡し方と受け取った名刺の扱い

名刺を作ったら、渡し方と、受け取った名刺の置き場所も決めておきます。副業では、受け取った名刺の扱いが、依頼側の情報の扱いと直結します。

| 場面 | やること |
|---|---|
| 渡すとき | 「副業として個人でお受けしています」と一言添える。会社名が無い理由を先に言えば、相手は聞かなくて済む |
| 依頼側の社内の人から受け取ったとき | 依頼側の関係者の情報として、副業用の置き場所に保管する。本業の名刺入れや本業の連絡先の管理に混ぜない |
| 候補者から受け取ったとき | 候補者の個人情報として、依頼側の管理に従う。自分の手元に残さず、依頼側に渡すか、依頼側の指示で処分する。[個人情報の扱い](/media/fukugyo-kojin-jouhou/) |
| 案件が終わったとき | 依頼側の関係者の名刺は、契約の終了時の情報の扱いに沿って処分か返却する。[引き継ぎの進め方](/media/fukugyo-hikitsugi/) |
| 名刺の情報を連絡に使うとき | 依頼側の関係者に直接連絡してよいかは、窓口の担当者に確認する。勝手に連絡先を使わない |

扱いの要点は、「受け取った名刺を、本業のものと同じ場所に置かない」ことです。本業の名刺入れや、本業の会社の連絡先管理に副業の相手の情報が入ると、本業の情報と副業の情報の分離が崩れます。副業用の名刺入れを一つ用意し、案件ごとに分けて保管し、終わったら処分する流れにしておくと、後で困りません。

## 増やさずに続ける工夫

名刺は一度作ると、案件や肩書が変わるたびに作り直したくなります。副業では、名刺の種類を増やさず、一種類で長く使えるようにしておくほうが、管理の手間が減ります。

| 工夫 | 内容 |
|---|---|
| 変わる情報を載せない | 単価、稼働の条件、支援先の名前は載せない。変わるたびに作り直すことになる |
| 肩書を範囲の総称にする | 「スカウト運用」だけだと、求人票の案件が増えたときに合わなくなる。「採用オペレーション支援」のように一段広い言葉にする |
| 少ない枚数で作る | 対面の頻度は多くない。大量に作ると、情報が変わったときに残りが無駄になる |
| 案件ごとの名刺を作らない | 依頼側の名前を入れた名刺は、依頼側が用意するもの。自分で作らない |
| 登録先のプロフィールを正とする | 名刺の情報が古くなったら、相手には登録先のプロフィールを案内する。名刺は入口で、正はプロフィール |

工夫の要点は、「名刺を正の情報にしない」ことです。正の情報は登録先のプロフィールやサイトに置き、名刺は名前と連絡先と範囲の総称を伝える入口に徹します。こうしておくと、範囲が広がっても名刺は作り直さずに済み、相手には「詳しくはこちらに」と案内できます。サイトを持つかどうかの判断は[自分のサイトは要るか](/media/fukugyo-hp/)に書いています。

### エラベルの見解

担当する側から見ると、名刺で困る人は、名刺そのものより「公開する名前」と「範囲の言葉」が決まっていないことが原因です。名前と範囲が決まっていれば、名刺の項目は写すだけで決まります。決まっていないと、名刺を作る段階で初めて「本名を出すのか」「肩書は何か」を考えることになり、対面の直前に迷います。

順番としては、登録の時点で公開する名前と担当できる業務の範囲を決め、それをプロフィールに書き、対面の予定が入ったらプロフィールの一行目を名刺の肩書に写す。この流れなら、名刺のために新しく決めることはありません。エラベルでは、登録の際に名刺の提出を求めていませんし、依頼側との面談もリモートで始まることが多いので、名刺が無いまま最初の案件に入る方が大半です。対面の予定が入ってから作れば間に合います。

## まとめ

- **本業の名刺は副業で使わない**。本業の会社名と連絡先が相手に渡り、会社の信用を副業に使う形になる
- 名刺が要るのは**依頼側との対面の打ち合わせ・社内の関係者への紹介・勉強会や交流会**。リモート完結なら要らない
- 候補者と会う場面は**依頼側の窓口を通す**のが一般的で、自分の名刺を渡すかは依頼側に合わせる
- 作るなら**公開する名前・範囲を書いた肩書・副業用の連絡先**の三つ。会社名は無くてよく、架空の屋号は付けない
- 受け取った名刺は**本業のものと混ぜず、案件ごとに分け、終わったら処分か返却**。候補者の名刺は依頼側の管理に従う
- 続けるには**変わる情報を載せない・肩書を範囲の総称にする・少ない枚数・案件ごとに作らない・正はプロフィール**

## よくある質問

### 副業用の名刺に、本名を書かなくてもよいですか

公開する名前を契約の名前と分けている場合は、名刺には公開する名前を書き、契約書との対応を依頼側の担当者に伝えておけば、実務は回ります。ただし、依頼側の社内の人が名刺の名前で契約書を探すと見つからないことがあるので、担当者には先に伝えておきます。本名を出すかどうかの判断そのものは、[本名を出さずに受けられるか](/media/fukugyo-honmyo/)に整理しています。

### 対面の予定が急に入り、名刺が間に合わないときはどうすればよいですか

名刺が無いまま行って構いません。渡された名刺は受け取り、「副業として個人でお受けしており、名刺は用意していません。連絡先はメールでお送りします」と伝え、その日のうちに副業用のアドレスから挨拶のメールを送れば、相手の手元には連絡先が残ります。名刺を急いで作るために、本業の名刺を代用することだけは避けてください。

### 依頼側から「うちの会社の名刺を持ってほしい」と言われたら、受けてよいですか

依頼側の名前で候補者や外部の会社と接する場面では、依頼側が自社の名刺を用意することがあります。受けるかどうかは、契約上の立場と、依頼側の名前で動く範囲を確認してから決めます。依頼側の社員として振る舞うことになると、契約の形や責任の範囲に関わるので、契約書の内容と照らし、迷う場合は専門家にご確認ください。本業の会社との関係でも、他社の名刺を持つことが規定に触れないかを見ておく必要があります。
