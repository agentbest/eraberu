副業を始めたら、本業の評価が下がるのではないか。上司に「最近、集中していない」と言われたら、副業のせいだと思われるのではないか。副業は本業にどう響き、どこまでなら響かないのか。結論を先に書くと、**副業が本業に響くかどうかは、副業の稼働の量ではなく、「睡眠を削っているか」「本業の時間に副業の連絡を見ているか」「本業の評価が下がったら止めると決めているか」の三つで決まります。週に十時間の副業でも、睡眠を確保し、本業の時間に副業に触れず、評価の指標を持っていれば響きません。週に三時間でも、夜中まで稼働し、本業中に依頼側の連絡を返し、評価を見ていなければ響きます。響く前に、本業の評価を測る指標を自分で持ち、下がったら止めると決めておく。これが、本業を守りながら副業を続ける形です。**疲れの扱いは[疲労とどう付き合うか](/media/fukugyo-tsukare/)に、時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、本業に知られる経路は[副業は会社にばれるか](/media/fukugyo-qa-1/)にまとめています。

## 響く形と響かない形

同じ副業でも、本業に響く形と響かない形があります。違いを見ます。

| 響く形 | 響かない形 |
|---|---|
| 夜中まで稼働し、睡眠を削っている | 睡眠を確保した残りで稼働。早朝か、決まった夜の時間帯 |
| 本業の時間に、副業の連絡を見て返している | 本業の時間は副業の端末を開かない。連絡は稼働時間に |
| 本業の会議中に、副業のことを考えている | 本業と副業の切り替えの時間を持つ。通勤で切り替える |
| 本業の端末や回線で副業をしている | 端末と回線を完全に分ける |
| 本業の繁忙期も、副業の枠を変えない | 本業の繁忙期は、副業を縮める |
| 本業の評価を見ていない | 本業の評価の指標を自分で持ち、月に一度見る |
| 副業の方が楽しく、本業を手抜きしている | 本業を優先する順番を決めている。評価が下がったら止める |
| 本業の情報や人脈を副業に使っている | 本業と副業の情報と関係を分ける。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |

違いの要点は、「稼働の量」がどちらの列にも入っていないことです。本業に響くのは、量ではなく、睡眠、本業の時間の侵食、切り替え、端末、繁忙期の対応、評価の確認、優先順位、情報の分離です。これらは、量を減らさなくても直せます。逆に、量を減らしても、夜中の稼働と本業中の連絡が続けば、響きます。時間帯の選び方は[早朝の稼働という選択](/media/fukugyo-hayaasa/)に、端末の分け方は[私物端末で作業してよいか](/media/fukugyo-tanmatsu/)に書いています。

## 影響が出る三つの経路

副業が本業に響く経路は、三つに分かれます。

| 経路 | 何が起きるか | 本業での現れ方 | 防ぎ方 |
|---|---|---|---|
| 一、睡眠 | 夜の稼働で睡眠が削れ、日中の集中が落ちる | 会議で頭が回らない、ミスが増える、午後に眠い | 睡眠時間を先に確保し、残りで稼働。夜の稼働を早朝に変える |
| 二、本業の時間の侵食 | 本業の時間に副業の連絡を見る、返す、考える | 本業の作業が遅れる、話しかけられて反応が遅い、離席が増える | 本業の時間は副業の端末を開かない。稼働しない時間帯を依頼側に伝える |
| 三、気持ちの持ち出し | 副業の悩み（成果が見えない、依頼側との関係）を本業に持ち込む。逆に、副業の方が楽しく、本業への意欲が下がる | 本業の会議で上の空、本業の同僚への態度が変わる、本業の仕事を「つまらない」と感じる | 切り替えの時間を持つ。副業の悩みは副業の中で扱う。本業を優先する順番を決めておく |

経路の要点は、「二」の本業の時間の侵食が、最も本業の評価に直結することです。睡眠不足は自分で気づけますが、本業の時間に副業の連絡を見ることは、「少しだけ」と積み重なり、自分では気づかないまま、周囲からは「最近、反応が遅い」「離席が多い」と見られます。本業の時間は副業の端末を開かない、と物理的に決めます。連絡の時間帯は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、切り替えは[通勤時間の使い方](/media/fukugyo-tsuukin/)に整理しています。

### エラベルの見解

担当する側から見ると、副業が本業に響いて止まる人は、稼働が多い人ではなく、本業の時間に副業の連絡を返している人です。依頼側から見ると、平日の日中に返事が早い担当者は「対応が速い」と映りますが、その速さは本業の時間を削って出ています。本業で「反応が遅い」「離席が多い」と見られ始め、評価が下がり、副業を止めることになります。逆に、「平日の日中は返せません。連絡は夜か翌朝に返します」と最初に伝えている担当者は、依頼側もその前提で動き、本業の時間が守られ、続いています。

見ていて差がつくのは、本業の評価を測る指標を自分で持っているかです。本業の評価は、年に一度の面談でしか分からないと思いがちですが、日々の指標（締め切りを守れているか、会議で発言できているか、上司や同僚からの依頼に即答できているか）で、自分で測れます。持っている人は、指標が下がった時点で副業を縮め、面談の前に戻しています。持っていない人は、面談で評価が下がったことを知り、そのときには副業を止めるしかなくなっています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、本業の時間を守り、稼働しない時間帯を明確にしている担当者が、依頼側との関係も安定しています。本業を守ることが、副業を続ける条件です。

## 本業の評価を自分で測る指標

本業の評価は、年に一度の面談を待たず、自分で測ります。指標の例です。

| 指標 | 見方 | 下がっているサイン |
|---|---|---|
| 締め切り | 本業の締め切りを、余裕を持って守れているか | 直前になる、遅れが出る |
| 会議での発言 | 会議で発言し、議論に参加できているか | 発言が減る、上の空になる |
| 依頼への反応 | 上司や同僚からの依頼に、その場で答えられているか | 「後で」が増える、返事が遅れる |
| ミス | 本業でのミスの頻度 | 以前より増えている |
| 上司の言葉 | 「最近どう?」「大丈夫?」と聞かれる回数 | 増えている |
| 同僚との関係 | 雑談、相談、手伝いの頻度 | 減っている。「忙しそう」と言われる |
| 本業への意欲 | 本業の仕事を面白いと感じるか、次の課題に取り組む気持ちがあるか | 「つまらない」「早く帰りたい」が増える |
| 離席と私用 | 本業の時間に、副業の連絡を見た回数 | 一日に何度も見ている |

指標の要点は、「上司の言葉」を、早い兆候として見ることです。「最近どう?」「大丈夫?」と聞かれるのは、上司が変化に気づいている合図です。この時点で副業を縮めれば、評価には響きません。聞かれたことを「気にしすぎ」と流すと、次は面談で評価として出ます。月に一度、指標を見て、下がっていれば副業の枠を縮めます。記録の仕方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、枠の縮め方は[長く続けるための設計](/media/fukugyo-choki/)に書いています。

## 影響が出たときの止め方

指標が下がったら、副業を縮めるか、止めます。止め方の順番です。

| 順番 | 内容 |
|---|---|
| 一、指標のどれが下がったかを見る | 締め切りなら本業の時間の侵食、会議なら睡眠か気持ち、意欲なら気持ち |
| 二、経路を特定する | 睡眠か、本業の時間の侵食か、気持ちの持ち出しか |
| 三、経路に合わせて直す | 睡眠なら夜の稼働を止める。侵食なら本業中に端末を開かない。気持ちなら切り替えの時間を作る |
| 四、直して一か月で戻らなければ、副業の枠を半分にする | 稼働を半分に、案件を一件に |
| 五、それでも戻らなければ、一時停止する | 本業の評価を戻すことを優先し、副業は区切りまで |
| 六、依頼側には、枠の変更として伝える | 「本業の事情で、来月から稼働を〇時間に」「〇月まで一時停止」 |
| 七、本業の評価が戻ったら、小さい枠から再開する | 戻ったことを指標で確認してから |
| 八、再開時に、経路の対策を設計に入れる | 同じ経路で同じことが起きないように |

止め方の要点は、「四」と「五」の、本業の評価を戻すことを優先することです。副業を続けたい気持ちが強いと、「もう少し様子を見る」と縮めるのを遅らせますが、本業の評価は一度下がると戻すのに時間がかかります。副業は一時停止すれば戻れますが、本業の評価は戻りにくい。優先順位は本業です。一時停止の伝え方は[副業をやめるとき](/media/fukugyo-yameru/)に、依頼側への伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

## 本業に良い影響を出す条件

副業は、本業に響くだけでなく、良い影響を出すこともあります。その条件です。

| 良い影響 | 出る条件 | 出ない条件 |
|---|---|---|
| 他社の採用の型を知り、本業の採用に活かせる | 副業で得た「型」（依頼側の情報を含まない汎用の型）を、本業に持ち帰る | 依頼側の情報を本業に持ち込む（守秘の線を越える） |
| 判断を自分で持つ経験が、本業での提案に活きる | 副業で範囲の中の判断を任され、結果を見ている | 副業でも判断を依頼側に丸投げしている |
| 本業の仕組みの良さと課題が、外から見えるようになる | 複数の会社の採用を見て、比較できる | 一件だけで、比較がない |
| 本業の時間の使い方が引き締まる | 副業の枠があるので、本業を時間内に終える意識が強まる | 副業のために本業を早く切り上げる（手抜き） |
| 人事の市場での自分の位置が分かり、本業での目標が明確になる | 副業で自分の範囲と単価を確かめている | 副業を転職の逃げ場として見ている |

条件の要点は、「依頼側の情報ではなく、型を持ち帰る」ことです。副業で得たものを本業に活かすのは良いことですが、依頼側の会社名、候補者、条件を本業に持ち込むと、守秘の線を越えます。「スカウト文面の型」「面接の準備資料の型」のような、依頼側が特定されない汎用の型を持ち帰ります。逆に、本業の情報を副業に持ち出すことも同じです。線の引き方は[守秘の線を越える](/media/fukugyo-shippai-8/)に、利益相反は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、学びの整理は[副業で学び続ける](/media/fukugyo-gakushuu/)に書いています。

## 影響を防ぐ順番

本業への影響を防ぎながら副業を続ける順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の評価の指標を決める | 締め切り、会議、依頼への反応、ミス、上司の言葉、同僚との関係、意欲、離席 |
| 二、睡眠時間を先に確保する | 副業の稼働は、睡眠を確保した残りで |
| 三、本業の時間は副業の端末を開かないと決める | 依頼側に「平日の日中は返せません」と伝える |
| 四、端末と回線を分ける | 本業の端末と回線で副業をしない |
| 五、切り替えの時間を持つ | 通勤、散歩など、本業と副業の間に頭を切り替える時間 |
| 六、本業の繁忙期は副業を縮めると決めておく | 繁忙期の時期を先に依頼側に伝える |
| 七、月に一度、指標を見る | 下がっていれば、経路を特定して直す |
| 八、指標が戻らなければ、副業を縮めるか一時停止する | 本業の評価を優先 |

順番の要点は、「一」の指標を、副業を始める前に決めることです。始めてから決めると、「始める前はどうだったか」が分からず、下がったかどうかを判断できません。始める前に、今の締め切りの守り方、会議での発言、依頼への反応を書いておき、始めてから比べます。副業の許可を得るときにも、この指標を会社に示せば、「本業に響かないか」という懸念に答えられます。許可の申請は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「副業の稼働を少なくすれば、本業に響かない」というものです。実際には、稼働が少なくても、夜中に稼働して睡眠を削り、本業の時間に依頼側の連絡を返していれば、響きます。逆に、稼働が多くても、睡眠を確保し、本業の時間に触れず、評価の指標を見ていれば、響きません。本業への影響は、量ではなく、経路で決まります。

順番として、本業の評価の指標を副業を始める前に決め、睡眠を先に確保し、本業の時間は副業の端末を開かず、端末と回線を分け、切り替えの時間を持ち、本業の繁忙期は縮めると決め、月に一度指標を見て、戻らなければ副業を縮めるか一時停止する。この順番で、副業は「本業に響くかもしれないもの」から「本業を守る設計の中で続けるもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、平日の日中に返せないことを明確にしている担当者が、本業を守りながら依頼側との関係も保っています。本業を守ることは、副業を続けるための最初の条件です。

## まとめ

- 本業に響くかは**稼働の量ではなく、睡眠・本業の時間の侵食・気持ちの持ち出しの三つの経路**で決まる
- 最も評価に直結するのは**本業の時間に副業の連絡を見ること**。本業の時間は副業の端末を開かない
- 本業の評価は**自分で測る指標**（締め切り・会議・依頼への反応・ミス・上司の言葉・同僚との関係・意欲・離席）を持ち、月に一度見る
- **「最近どう?」と聞かれたら早い兆候**。その時点で副業を縮める
- 指標が下がったら**経路を特定して直し、戻らなければ枠を半分、それでも戻らなければ一時停止**。本業の評価を優先
- 本業に良い影響を出すには**依頼側の情報ではなく型を持ち帰る**。指標は副業を始める前に決める

## よくある質問

### 副業を始めてから、上司に「最近、疲れてる?」と言われました。副業がばれていますか

ばれているかどうかより、上司が変化に気づいている、という合図として受け止めます。この時点で、睡眠、本業の時間の侵食、気持ちの持ち出しのどれが起きているかを見て、直します。多くは睡眠か、本業中に副業の連絡を見ていることが原因です。副業を伝えていない場合は、伝えてよい状態にできるかを、この機会に考えます。伝えている場合は、「副業の枠を縮めます」と自分から伝えると、上司の懸念が消えます。伝えてよい状態の作り方は[副業は会社にばれるか](/media/fukugyo-qa-1/)に整理しています。

### 本業の繁忙期に、副業の締め切りが重なります。どちらを優先すればよいですか

本業を優先します。副業の依頼側には、繁忙期の時期を先に伝えておき、「〇月は本業の繁忙期のため、稼働を減らします。締め切りに余裕をいただけますか」と、繁忙期に入る前に相談します。重なってから伝えると、副業の締め切りを落とすか、本業を削るかになり、どちらも響きます。繁忙期の時期が分かっているなら、年の初めに依頼側に伝え、その期間の稼働を先に縮めておきます。伝え方は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、繁忙期の設計は[長く続けるための設計](/media/fukugyo-choki/)に書いています。

### 副業の方が楽しく、本業への意欲が下がっています。これは本業への影響ですか

影響です。意欲の低下は、「気持ちの持ち出し」の経路で、本業の評価に響き始める前の兆候です。副業の方が楽しい理由を分けて見ます。「範囲が明確で成果が見える」「判断を任される」なら、本業でも同じ状態を作れないかを試します。「本業が嫌だから副業が楽しい」なら、本業の側の問題を解決する方が先です。副業を本業の逃げ場にすると、本業の評価が下がり、副業を続ける土台も崩れます。本業を辞める判断は疲れていない状態で、理由を分けてから。考え方は[副業を本業にする判断](/media/fukugyo-honngyou-ni-suru/)に整理しています。
