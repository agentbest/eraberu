副業で人事を受けていると、「候補者のSNSは見てよいのか」と聞かれます。公開されているのだから見てよいはずだ、という感覚と、なんとなく後ろめたい感覚が同居していて、社内で結論が出ないまま各自が勝手に見ている、という状態の会社が少なくありません。結論を先に書くと、**指針（平成11年労働省告示第141号）は、個人情報を収集する手段として「本人により公開されている個人情報を収集する」を挙げている一方で、同じ項で「業務の目的の達成に必要な範囲内で、当該目的を明らかにして個人情報を収集すること」とし、思想及び信条、労働組合への加入状況、人種・民族・社会的身分・門地・本籍・出生地その他社会的差別の原因となるおそれのある事項は収集してはならない、と定めています。**つまり、手段として公開情報を見ることと、そこで何を集めてよいかは、別の段階の話です。個別の判断は弁護士やハローワーク・都道府県労働局にご確認ください。面接での質問の線引きは[面接で聞いてはいけないこと](/media/fukugyo-law-shitsumon-ng/)に、第三者から聞く場合は[リファレンスチェックの法的注意](/media/fukugyo-law-reference/)にまとめています。

## 二段階で考える

SNS調査の議論がこじれるのは、二つの問いを混ぜているからです。分けて並べると、こうなります。

**第一の問い：手段として適法か。**指針は、個人情報を収集する際の手段について、「本人から直接収集し、本人の同意の下で本人以外の者から収集し、又は本人により公開されている個人情報を収集する等の手段であって、適法かつ公正なものによらなければならない」と定めています。**「本人により公開されている個人情報を収集する」は、手段として明記されています。**

一方、個人情報保護法第20条第1項は「個人情報取扱事業者は、偽りその他不正の手段により個人情報を取得してはならない」と定めています。本人が公開していないもの、たとえば鍵のかかったアカウントに素性を偽って近づく、共通の知人を装って閲覧を求める、といった形は、この段階で外れます。

**第二の問い：何を集めてよいか。**手段が適法でも、集めてよい範囲は別に決まっています。職業安定法第5条の5第1項は、求人者を含む主体に対して「その業務の目的の達成に必要な範囲内で、厚生労働省令で定めるところにより、当該目的を明らかにして求職者等の個人情報を収集し、並びに当該収集の目的の範囲内でこれを保管し、及び使用しなければならない」と定めています。指針は、これを受けて収集してはならない個人情報を挙げています。

- イ 人種、民族、社会的身分、門地、本籍、出生地その他社会的差別の原因となるおそれのある事項
- ロ 思想及び信条
- ハ 労働組合への加入状況

**ここが実務の核心です。**SNSは、この三つが最も出やすい場所です。支持政党、宗教、社会運動への参加、労働組合の活動、出身地に関する投稿。公開されているからといって、これらを採用選考で把握してよいことにはなりません。手段の話と、範囲の話は、別々に通す必要があります。

## 公正な採用選考の枠から見ると

厚生労働省の「公正な採用選考の基本」のページは、採用選考の基本的な考え方として「応募者の基本的人権を尊重すること」と「応募者の適性・能力に基づいた基準により行うこと」を挙げ、根拠の一つとして職業安定法第5条の5および指針（平成11年労働省告示第141号）を示しています。

そして「採用選考時に配慮すべき事項」のページでは、配慮すべき事項が三つの区分で挙げられています。**（b）本来自由であるべき事項（思想・信条にかかわること）の把握**には、宗教に関すること、人生観・生活信条などに関すること、思想に関すること、購読新聞・雑誌・愛読書などに関すること、支持政党に関すること、尊敬する人物に関すること、労働組合・学生運動などの社会運動に関すること、が並びます。

**SNSに出ているものと、そのまま重なります。**何を読んでいるか、誰を尊敬しているか、どの立場を支持しているか。面接で聞けば問題になることが、タイムラインには並んでいます。同じページの**区分（c）採用選考の方法**には「身元調査など」も挙げられています。

**（a）本人に責任のない事項**も同様です。本籍・出生地に関すること、住宅状況に関すること、家族に関すること、生活環境・家庭環境などに関すること。SNSの投稿からは、これらも見えてしまいます。

個人情報保護法の側では、第20条第2項が、法定の場合を除き「あらかじめ本人の同意を得ないで、要配慮個人情報を取得してはならない」と定めています。要配慮個人情報は、同法第2条第3項で「本人の人種、信条、社会的身分、病歴、犯罪の経歴、犯罪により害を被った事実その他本人に対する不当な差別、偏見その他の不利益が生じないようにその取扱いに特に配慮を要するものとして政令で定める記述等が含まれる個人情報」と定義されています。SNSで見えるものの中には、この定義に入るものがあります。

### エラベルの見解

担当する側から見ると、SNS調査の相談で最初にやるべきなのは、可否を答えることではなく、**すでに誰かが見ている前提で話を始めること**です。「見てよいか」と聞かれる時点で、現場の面接官や採用担当は、たいてい候補者の名前を検索しています。ここで「やめてください」とだけ言っても、見ることをやめさせるのは難しく、見たことを言わなくなるだけです。記録に残らない形で選考に影響するほうが、会社にとっては危険です。

実務で効くのは、「見るかどうか」ではなく「見た情報をどう扱うか」を先に決めることです。公開情報を見た結果として、支持政党や宗教や社会運動への参加が分かってしまった場合、それを評価に使わない、記録に書かない、他の面接官に共有しない、という扱いを明文にします。そのうえで、そもそも検索を採用プロセスの一部にしない、という運用を選ぶなら、なぜそうするのかを説明できる形にします。禁止ではなく設計として渡すと、現場が守ります。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、現場が実際に守る運用に落とせる人は、制度まわりの案件で指名されます。

## 会社に渡す運用ルール

副業の人事が作るのは、次の形です。個別の適否の判断は弁護士やハローワーク・都道府県労働局にご確認ください。

| 作るもの | 中身 |
|---|---|
| 方針の一文 | 採用選考で候補者のSNSを閲覧するか、しないか。会社としての立場を一つに決める |
| 見る場合の目的 | 何の判断のために見るのか。職業安定法第5条の5の「業務の目的の達成に必要な範囲」に載る言葉で書く |
| 見てよい範囲 | 職務に関する発信（技術記事、登壇、制作物、業務に関する公開プロフィール）に限る、など |
| 見た情報で使わないもの | 指針イ・ロ・ハ、公正採用選考の（a）（b）に当たる事項、要配慮個人情報 |
| やらないことの一覧 | 素性を偽った友達申請、鍵アカウントへの接触、知人を介した閲覧、候補者本人への閲覧の要求 |
| 記録の扱い | スクリーンショットを取らない、評価シートに書かない、選考記録に混ぜない |
| 見てしまったときの対応 | 誰に言わないか、評価にどう反映しないか、記録にどう残さないか |
| 担当の限定 | 誰が見るか。面接官が各自で検索する形にしない |
| 候補者への説明 | 見る運用にするなら、利用目的をどう示すか（個人情報保護法第17条・第21条） |

**職務に関する発信は別に考えられます。**候補者自身が職務の実績として公開しているもの、たとえば技術記事、登壇資料、公開しているポートフォリオ、仕事用のプロフィールは、適性・能力に関わる情報です。これらは、候補者に「見てよいですか」と聞いて、本人から示してもらう形にすると、目的も範囲もはっきりします。本人から直接収集する形に寄せられるので、設計としても素直です。

**個人情報保護法の手続も付いてきます。**同法第17条第1項は利用目的を「できる限り特定しなければならない」、第21条第1項は「個人情報を取得した場合は、あらかじめその利用目的を公表している場合を除き、速やかに、その利用目的を、本人に通知し、又は公表しなければならない」と定めています。SNSの閲覧を採用プロセスに組み込むなら、この手続も設計に含めます。集めた情報の保存と消去については[候補者情報の保有期間](/media/fukugyo-law-kouhosha-jouhou/)に整理しています。

### エラベルの見解

外に出してよいのは、方針の一文、見る場合の目的と範囲、やらないことの一覧、記録の扱い、見てしまったときの対応、候補者への説明の設計までで、「この投稿を理由に見送ってよいか」「この運用が法令に適合しているか」といった個別の判断は、弁護士やハローワーク・都道府県労働局の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この相談で会社に一番効くのは、採用の精度の話に戻すことです。SNSを見たくなる動機は、たいてい「見極めに自信がない」ことにあります。選考で何を確かめるかが決まっていないから、外側の情報で埋めようとする。ここを、評価基準の設計と面接の質問の設計に戻すと、SNSを見る動機そのものが下がります。実際、職務要件を書き直して面接の質問を作り直したあとに「そういえばSNSは見なくなった」と言われることがあります。可否の議論で終わらせず、なぜ見たくなったのかを扱うのが、この案件の勘どころです。エラベルでは、依頼側が担当者を選べるので、選考設計まで戻して提案できる人は、そこを経歴に書いておくと選ばれます。

## まとめ

- 判断は二段階。**手段として適法か**と、**何を集めてよいか**を分けて考える
- 指針は収集の手段として「**本人により公開されている個人情報を収集する**」等を挙げ、適法かつ公正なものに限っている
- 個人情報保護法第20条第1項は「**偽りその他不正の手段により個人情報を取得してはならない**」と定めている
- 集めてよい範囲は職業安定法第5条の5の「**業務の目的の達成に必要な範囲内**」。指針は思想及び信条、労働組合への加入状況、人種・民族・社会的身分・門地・本籍・出生地等を**収集してはならない**としている
- 公正採用選考の配慮すべき事項（b）は、**宗教・人生観・思想・購読新聞・支持政党・尊敬する人物・社会運動**。SNSに出やすいものと重なる
- 実務では「見るか見ないか」より、**見た情報をどう扱うか**を先に明文化する。個別の判断は弁護士や労働局にご確認ください

## よくある質問

### 公開されているアカウントなら、見ても問題ないのではないですか

指針（平成11年労働省告示第141号）は、収集の手段として「本人により公開されている個人情報を収集する」を挙げているので、手段の段階では文言に載ります。ただし同じ項は、業務の目的の達成に必要な範囲内で当該目的を明らかにして収集することとしたうえで、思想及び信条、労働組合への加入状況、人種・民族・社会的身分・門地・本籍・出生地その他社会的差別の原因となるおそれのある事項は収集してはならない、と定めています。公開されているかどうかと、採用選考で把握してよいかどうかは、別の段階の話です。個別の判断は弁護士やハローワーク・都道府県労働局にご確認ください。

### 見てしまって、支持政党が分かってしまいました

厚生労働省の「採用選考時に配慮すべき事項」では、支持政党に関することは（b）本来自由であるべき事項に挙げられており、指針も思想及び信条を収集してはならない事項としています。実務としては、評価に使わない、評価シートに書かない、他の面接官に共有しない、という扱いを取るのが無難です。繰り返し起きるようなら、個々の面接官が各自で検索する運用そのものを見直します。扱いの適否は弁護士やハローワーク・都道府県労働局にご確認ください。

### 候補者の技術記事や登壇資料を見るのも、SNS調査に当たりますか

候補者自身が職務の実績として公開しているものは、適性・能力に関わる情報なので、配慮すべき事項として挙げられているものとは性質が違います。ただ、運用としては、会社が勝手に探すより、応募のときに「職務に関する公開物があれば教えてください」と本人から示してもらう形にするほうが、目的も範囲もはっきりします。本人から直接収集する形に寄るので、指針の収集の手段の文言にも素直に載ります。設計に迷う場合は、弁護士やハローワーク・都道府県労働局にご確認ください。
