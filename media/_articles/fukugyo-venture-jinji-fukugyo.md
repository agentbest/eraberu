ベンチャー企業の人事として、社員が年に倍になるような時期に、採用の数と質と速さを同時に求められ、採用の仕組みも評価も受け入れも、無い状態から作りながら回してきた。この経験は、副業で売れるのか。ベンチャーの人事の経験は、勢いと熱量で回っていたように見え、落ち着いた会社には通じないと感じる人が多いところです。結論を先に書くと、**ベンチャーの人事の経験は、「組織が急に大きくなる中で、採用の数と質と速さを同時に求められ、仕組みを作りながら回してきた」型で売れます。売れるのは、「急な増員を回す採用の設計」「採用と組織づくりの接続」「資金と事業の段階に合わせた採用の優先順位」「仕組みがない状態から作る型」の四つです。落ち着いた会社でも、新しい事業や拠点で急に人を増やす局面はあり、そこでは既存の人事のやり方が通じず、ベンチャーの人事の型が効きます。「ベンチャーの人事でした」ではなく、「これから人が増える会社で、増える前に仕組みを作る」と売ります。**創業直後の経験は[スタートアップの人事が副業でできること](/media/fukugyo-startup-jinji-fukugyo/)に、その経験の評価のされ方は[スタートアップ人事の経験は評価されるか](/media/fukugyo-startup-keiken/)に、中小企業の経験は[中小企業の人事が副業でできること](/media/fukugyo-chusho-jinji-fukugyo/)にまとめています。

## この経歴の何が売れるか

ベンチャーの人事の経験を、依頼側の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| ベンチャーの人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 短い期間に多くの人を、複数の職種で同時に採ってきた | 増員の計画（いつ、どの職種を、何人、どの順番で）と、同時に回す体制の設計 | 急に人を増やす局面で、何から手を付ければよいか分からない依頼側が多い |
| 採用のたびに組織の形が変わる中で、要件と配置を決めてきた | 「今の組織に足りない人」ではなく「半年後の組織に要る人」で要件を書く型 | 今の欠員だけを見て採用し、増えた後に役割が重なる依頼側が多い |
| 資金と事業の段階に合わせて、採用の優先順位を変えてきた | 事業の段階（立ち上げ、拡大、安定）に合わせて、採る職種と順番を決める判断 | 全職種を同時に募集して、どれも決まらない依頼側が多い |
| 採用の仕組み（要件の型、面接の流れ、記録、受け入れ）を、無い状態から作ってきた | 人事の仕組みがない会社で、最初に作る一つから順番に作る型 | 仕組みが何もなく、担当者の記憶で回っている依頼側が多い |
| 現場のリーダーを面接官に育ててきた | 面接に慣れていない管理職を、短い手引きと同席で面接官にする型 | 管理職が急に増えて、面接官が育っていない依頼側が多い |
| 入った人が多くて受け入れが追いつかない中で、定着の工夫をしてきた | 同時に多くの人が入るときの受け入れ（教える人の分担、最初の一か月の型、相談の相手） | 一度に人が入ると受け入れが崩れ、早く辞める依頼側が多い |
| 会社の変化を候補者に伝え、変化を楽しめる人を見極めてきた | 「変わり続ける会社」に合う人の見極めと、その伝え方 | 変化に耐えられない人を採って、すぐ辞められる依頼側が多い |

売れるものの要点は、「増える前に仕組みを作り、増えている最中に回す型」です。多くの会社の人事は、人数が安定している状態で仕組みを回しており、急に増える局面では、要件が追いつかず、面接官が足りず、受け入れが崩れます。ベンチャーの人事は、その局面を日常として回してきており、「増える前に何を作り、増えている最中に何を回すか」の型を持っています。この型は、新しい事業や拠点や資金の調達で急に人を増やす会社に、そのまま合います。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

ベンチャーの人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 「勢いでやってきた」に見える | 「ベンチャーは勢いで採っていただけで、仕組みはないのでは」。自分でも、何が仕組みで何が勢いだったかを分けていない | 勢いの中で作った仕組みを、順番と型として書き出す。「最初に作ったのは要件の型、次に面接の流れ、次に受け入れ」と、作った順番で語る |
| 自社の熱量に頼っていた | 「会社の勢いと経営者の魅力で人が来ていたのでは」。自分にとっても、熱量のない会社で人を集める技術がない不安 | 熱量で集まった部分は正直に認め、「集まった後を回す仕組み」を主に売る。集める工程は依頼側の魅力を候補者の言葉に置き換えるところから作り直す前提で入る |
| 落ち着いた会社に合わない | 「うちは急に増えないので、関係ない」 | 「急に増える局面」は落ち着いた会社にもあると示す。新しい事業、新しい拠点、資金の調達、事業の承継。その局面に備える設計として売る |

扱い方の要点は、「勢いの中で作った仕組みを、作った順番で語る」ことです。ベンチャーの人事の経験がある人は、自分の経験を「大変だった」「何でもやった」と語りがちで、それが依頼側には「勢いでやっていた人」に聞こえます。「人が増える前に要件の型を作り、増え始めたら面接の流れと記録を作り、一度に入るようになったら受け入れの分担を作った」と、作った順番で語れば、同じ経験が「仕組みを順番に作れる人」として伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、ベンチャーの人事から転身して続いている人と、面談で止まる人の差は、「何人採ったか」を語るか、「何を先に作ったか」を語るかです。止まる人は、年に何十人採った話と、いかに大変だったかを語り、依頼側の経営者は「うちはそんなに採らない」と感じて終わります。続いている人は、「御社は、この一年で何人くらい増える予定ですか。増えたとき、誰が面接をしますか」と聞き、依頼側が「十人くらい。面接は私と、たぶん現場のリーダー」と答えたところで、「それなら、増える前に、要件の型と、リーダーが使う面接の手引きだけ作っておくと、増え始めても崩れません」と返します。経営者は、増える前に備える発想がなかったことに気づき、そこから頼みます。

見ていて差がつくのは、「変わり続ける会社に合う人」の見極めを、依頼側の会社の変化の度合いに合わせているかです。ベンチャーの人事の経験がある人は、「変化を楽しめる人」を要件に入れる癖がありますが、落ち着いた会社でそれを前に出すと、依頼側の社員との間でずれが出ます。「御社の変化は、事業が増えるが、働き方は大きく変わらない。それなら、新しいことに前向きだが、安定した進め方を好む人が合います」と、依頼側の変化の度合いに合わせて要件を調整した人は、採った人が定着し、依頼側から「うちに合う人の言葉が初めて決まった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「これから人が増える会社で、増える前に仕組みを作る」と局面の言葉で書いている担当者に、増員を控えた依頼側がついています。ベンチャーの人事の転身は、大変さを語ることではなく、作った順番を語るところから始まります。

## 案件の探し方

ベンチャーの人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 資金の調達や新規の事業で、これから人を増やす依頼側 | 急な増員の経験でそのまま入れる | 「この一年で人を増やす予定の依頼側」を探す |
| 増員の計画と、同時に回す体制の設計 | 複数の職種を同時に採ってきた経験で入れる | 「何から手を付ければよいか分からない依頼側」を探す |
| 仕組みがない状態から、最初の一つを作る | ゼロから作ってきた経験で入れる | 「担当者の記憶で回っている依頼側」を探す |
| 現場のリーダーを面接官にする型 | 面接官を育ててきた経験で入れる | 「管理職が急に増えた依頼側」を探す |
| 一度に人が入るときの受け入れの設計 | 受け入れが追いつかない中で工夫してきた経験で入れる | 「一度に入ると崩れる依頼側」を探す |
| 半年後の組織から逆算した要件づくり | 組織の形が変わる中で要件を決めてきた経験で入れる | 「増えた後に役割が重なる依頼側」を探す |

探し方の要点は、「これから人が増える会社」から入ることです。人数が安定している会社では、ベンチャーの型は既存の人事と重なるか、必要とされません。資金を調達した、新しい事業を始める、拠点を増やす、事業を継いで体制を変える、といった局面にある会社では、既存のやり方が通じず、ベンチャーの型が唯一の打ち手になります。案件の相談で「これから増やしたい」「今のやり方では回らなくなりそう」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。ベンチャーの人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 増員の計画の成果物 | 増員の計画と体制の設計は、成果物として形が明確 | 一式の成果物で受ける |
| 仕組みを作る工程 | 要件の型、面接の流れ、記録、受け入れは、成果物で受けやすい | 作る順番ごとに成果物で受ける |
| 増員の最中の運用 | 増えている最中に回す運用は、稼働が読みにくく、月額で幅を持たせる | 月額で受け、増員の山に合わせて範囲を見直す |
| 局面の価値 | 増員の局面で崩れる損失は依頼側に分かりやすく、価値が見えやすい | 「増えても崩れなかった」を成果として残す |
| 熱量に頼れないこと | 集める工程は、最初の月に成果が出にくい | 集める工程は範囲に入れないか、途中の成果で見せる |
| 仕組みが残ること | 作った仕組みは依頼側に残るので、作って終わりになると契約が続かない | 「次に作る仕組み」を提案して更新の根拠にする |
| 成果報酬の扱い | 採用の成否は依頼側の判断と現場の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「仕組みは作る順番ごとに成果物で、増員の最中は月額で幅を持たせる」ことです。ベンチャーの人事の経験で受ける工程は、要件の型、面接の流れ、受け入れと、作る順番ごとに成果物が明確で、成果物で受けると単価の根拠が伝わります。増えている最中の運用は稼働が読みにくいので、月額で受け、増員の山に合わせて範囲を見直す形にします。仕組みは依頼側に残るので、「次に作る仕組み」を提案して更新の根拠を作ります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

ベンチャーの人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、資金と事業と社員の情報の守秘の条件を確認する | ベンチャーは事業の情報の守秘が重い。個別の判断は専門家に |
| 二、「人が増える中で、何を、どの順番で作ったか」を、会社の情報を含まない型として書き出す | 要件の型、面接の流れ、記録、受け入れの作った順番 |
| 三、勢いと熱量で回っていた部分と、仕組みで回っていた部分を、正直に分ける | 集める工程は熱量、回す工程は仕組み |
| 四、「大変だった」を「作った順番」に言い換える | 人数と苦労ではなく、順番と型で語る |
| 五、得意な工程（増員の計画・仕組みづくり・面接官の育成・受け入れ・半年後の要件）と、薄い工程（熱量のない会社で集める、落ち着いた会社の空気）を分ける | 正直に示す準備 |
| 六、範囲を、増員の計画、最初の仕組み、面接官の型、受け入れ、半年後の要件に絞る | 集める工程は最初は範囲外か、作り直す前提で |
| 七、「これから人が増える会社で、増える前に仕組みを作る」の一言を作る | 「ベンチャーの人事でした」で終わらせない |
| 八、登録先に、範囲と、作った順番の型と、増員を控えた依頼側に向いていることを登録する | これから増える依頼側 |
| 九、増員の計画か最初の仕組みづくりを一件受け、「増えても崩れなかった」形を残す | 次の仕組みに広げる材料に |

順番の要点は、「三」の正直な分け方と「四」の言い換えです。ベンチャーの人事の経験は、会社の勢いと経営者の熱量に支えられていた部分と、自分が作った仕組みで回っていた部分が混ざっていて、分けずに語ると「勢いの人」に見えます。集める工程は熱量、回す工程は仕組み、と分けて認め、仕組みを作った順番で語れば、同じ経験が「順番に作れる人」として伝わります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「ベンチャーの人事の経験は、ベンチャーでしか通じない」というものです。実際には、落ち着いた会社にも、新しい事業や拠点や資金の調達や事業の承継で、急に人を増やす局面があり、そのとき既存の人事のやり方は通じません。増える前に何を作るか、増えている最中に何を回すか、一度に入る人をどう受け入れるか。ベンチャーの人事が日常として回してきたこの型は、その局面にある会社にとって、持っていない打ち手です。通じないのは、勢いと熱量の話のまま持ち込む場合で、作った順番で語れば、会社の種類は関係ありません。

順番として、本業の規定と守秘の条件を専門家に確認し、作った順番を会社の情報を含まずに書き出し、勢いと仕組みを正直に分け、大変さを順番に言い換え、得意な工程と薄い工程を分け、範囲を増員の計画と最初の仕組みと面接官と受け入れと半年後の要件に絞り、増える前に仕組みを作る一言を作り、登録先に範囲と型を登録し、一件受けて増えても崩れなかった形を残す。この順番で、ベンチャーの人事の経験は「ベンチャーでしか通じないもの」から「増員の局面にある会社の打ち手」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、増員の局面の工程を明確にし、集める工程の扱いを示している担当者に、これから増える依頼側がついています。ベンチャーの人事の転身は、大変さを語ることではなく、作った順番を語るところから始まります。

## まとめ

- ベンチャーの人事の経験は**「組織が急に大きくなる中で、採用の数と質と速さを同時に求められ、仕組みを作りながら回してきた」型**で売れる。**急な増員の設計・採用と組織の接続・段階に合わせた優先順位・ゼロから作る型**の四つ
- **「ベンチャーの人事でした」ではなく「これから人が増える会社で、増える前に仕組みを作る」**と売る
- 売りにくい点は**「勢いでやってきた」に見える・自社の熱量に頼っていた・落ち着いた会社に合わない**。作った順番で語り、熱量と仕組みを正直に分け、「急に増える局面」は落ち着いた会社にもあると示す
- 案件は**これから人が増える会社**から。資金の調達・新規の事業・拠点の増設・事業の承継が入り口
- 単価は**仕組みは作る順番ごとに成果物、増員の最中は月額で幅を持たせる**。成果報酬は最初は避け、可否は専門家に確認
- 「変化を楽しめる人」の要件は、**依頼側の変化の度合いに合わせて調整する**

## よくある質問

### 前の会社の急成長は、経営者と事業の魅力で人が集まっていただけで、自分の仕組みではなかった気がします

その感覚は正しく、正直に分けることが出発点です。集まった部分は経営者と事業の魅力で、集まった後を回した部分（要件の型、面接の流れ、記録、受け入れ）は自分の仕組みです。副業で売るのは後者で、「集める工程は依頼側の魅力を候補者の言葉に置き換えるところから作り直します」と示せば、熱量に頼っていたことは弱みになりません。回す仕組みを作った順番で語れば、依頼側には「順番に作れる人」として伝わります。経験の評価のされ方は[スタートアップ人事の経験は評価されるか](/media/fukugyo-startup-keiken/)に、評価される担当者の共通点は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に整理しています。

### 依頼側から「うちはベンチャーみたいに急には増えない」と言われました

「急に増える」の規模を、依頼側に合わせて言い換えます。「年に十人増えるだけでも、面接官が足りず、受け入れが崩れることがあります。増える前に要件の型と面接の手引きだけ作っておくと、その規模でも崩れません」と、依頼側の増え方で語ります。それでも増えない会社なら、ベンチャーの型は合わないので、正直に伝えて、合う担当者につなぎます。合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

### 前の会社の資金や事業の情報を、副業の面談で話してよいですか

話しません。資金の調達の額や時期、事業の数字、社員の情報は、前の会社のものであり、守秘の条件に関わります。ベンチャーは、公開前の事業の情報の守秘が重く、退職後も条件が残ることがあります。話せるのは、「人が増える中で、何を、どの順番で作ったか」の型だけで、規模や時期や数字は伏せます。個別の判断は、弁護士や社会保険労務士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に整理しています。
