保育業界の運営法人が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。年度の切り替わりに離職が集中し、募集が間に合わない。配置の基準に合う資格と人数の要件が無く、採っても足りない。保育の方針と行事と持ち帰りの仕事と担任の形の実態を先に出さず、入職後に離れる。園の種類と潜在保育士で経路が違うのに、一つの媒体で募集している。園長の面接の枠が取れず、日程が延びて、他の園で決まる。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**保育業界の採用課題は、時期・配置・実態・経路・枠の五つに分解し、自社の記録（離職の時期と理由、配置に足りなかった人数、辞退と早期離職の理由、園と経路ごとの応募の数、段階ごとの日数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、年度末に紹介会社へ費用を使って埋め、方針が合わずに離れて、次の年度末にまた埋める、という往復になります。代行に出す工程の切り分けは[保育業界の採用代行](/media/rpo-hoiku-rpo/)に、職種としての母集団形成は[保育士の母集団形成](/media/rpo-hoikushi-boshuudan/)に書いています。ここでは、保育業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 時期 | 年度末に退職が集中し、切り替わりまでに埋まらない | 離職の時期と理由。退職の申し出から切り替わりまでの日数 |
| 配置 | 採ったが、資格の区分と年齢ごとの人数で配置に足りない | 配置に足りなかった人数。要件に区分と人数が無い |
| 実態 | 面接で「持ち帰りはありますか」。入職後に「方針が違う」「一人担任と聞いていない」 | 辞退と早期離職の理由が「方針」「持ち帰り」「担任」「行事」 |
| 経路 | 現役の保育士は来るが潜在保育士が来ない。認可は来るが小規模が来ない | 園と経路ごとの応募の数 |
| 枠 | 日程が延びて「他の園で決まった」 | 段階ごとの日数。園長の枠の数 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 離職の時期と理由、退職の申し出から切り替わりまでの日数 | 年度末に集中していれば時期。逆算の設計が先 |
| 二 | 要件に資格の区分と年齢ごとの人数があるか。配置に足りなかった人数 | 無ければ配置 |
| 三 | 辞退と早期離職の理由 | 「方針」「持ち帰り」「担任」「行事」なら実態 |
| 四 | 園と経路ごとの応募の数 | 偏りがあれば経路 |
| 五 | 段階ごとの日数 | 長ければ枠 |

一が最初なのは、保育は年度の暦で動くため、時期の逆算が無いと、他の四つを直しても切り替わりに間に合わないからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

保育業界で最も多い詰まりは「時期」で、しかも毎年同じことが起きているのに逆算が設計されていないことです。退職の申し出は年度の後半に集まり、そこから募集を始めると、掲載・応募・面接・見学・内定・入職の段を切り替わりまでに通せません。結果、紹介会社に急いで頼み、方針を確かめる時間が無く採り、合わずに離れる。逆算とは、「切り替わりの何か月前に応募が何名要るか」を前の年度の記録（応募から入職までの日数と、段ごとの通過の比率）から決め、退職の申し出を待たずに募集を始めることです。エラベルで担当者を選ぶ企業には、「来年度の募集は、いつから始める予定ですか」を、私たちから先に聞いています。答えが「退職の申し出が出てから」なら、代行の前に逆算の設計です。人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

## 時期の課題：年度末に集中する

| 状態 | 直し方 |
|---|---|
| 退職の申し出が出てから募集を始める | 前の年度の記録から逆算し、申し出を待たずに募集を始める |
| 離職の理由を記録していない | 退職面談で「方針」「持ち帰り」「担任」「行事」「人間関係」「条件」「私的な事情」に分けて記録 |
| 年度の途中の欠員に対応できない | 途中の入職を受け入れる型（複数担任からの開始、教える人）を作り、通年で募集を開く |

離職の理由のうち「持ち帰り」「担任」「行事」は、実態と受け入れの問題で直せます。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 配置の課題：区分と人数が要件に無い

| 状態 | 直し方 |
|---|---|
| 「保育士募集」だけで、資格の区分と年齢ごとの人数が無い | 会社と専門家で、配置の基準に合う区分と人数を整理し、「どの園で、何歳児に、何名」を決める |
| 採ってから配置に足りないと分かる | 書類の一次確認で区分を照合し、園と年齢ごとの充足を一覧で見る |
| 補助の職種（子育て支援員など）と保育士の区別が無い | 区分ごとに求人票を分ける |

配置の基準は、法令上の整理があると一般に整理されているため、会社と専門家で整理します。代行は照合と充足の一覧まで。個別の判断は専門家にご確認ください。要件の作り方は[保育士の採用要件の作り方](/media/rpo-hoikushi-youken/)に書いています。

## 実態の課題：方針と持ち帰りと担任を先に出していない

| 求人票に無いこと | 書き方 |
|---|---|
| 保育の方針 | 「〇〇を大切にする保育で、一日はこう流れる」の実態 |
| 行事の多さ | 「年間の行事はこれで、準備はこう分担する」の実態 |
| 持ち帰りの仕事 | 「書類の時間を園で確保しているか、していないか」の実態 |
| 担任の形 | 「一人担任か複数担任か。最初は複数担任から」の実態 |
| 園長の人柄と職員の構成 | 見学で会う。年齢の構成、勤続の長さ |
| 離職の状況 | 「昨年度は何名が離れ、理由はこうだった」を面接で語れるか |

見学を選考の段に置き、保育の場面を見てもらうと、候補者が方針の相性を判断でき、入職後のずれが減ります。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

### エラベルの見解

保育業界で見落とされやすいのは「潜在保育士」が別の経路で動くことです。資格を持ちながら働いていない人は、現役の保育士向けの媒体を見ておらず、動く理由も「時間」「持ち帰りの有無」「担任の形」「ブランクへの受け入れ」で、現役とは違います。同じ求人票を同じ媒体に出して「潜在保育士が来ない」と言うのは、届く場所にも届く言葉にも出していないからです。「短時間の勤務」「持ち帰り無し」「最初は複数担任」「ブランクの方の受け入れの型」を会社が決め、地域の経路と自治体の窓口と知人と復職の支援の場に出す。エラベルで担当者を選ぶ企業には、「潜在保育士に向けた求人票と経路を、現役向けと分けていますか」を、私たちから先に聞いています。分けていなければ、媒体を増やす前に分け方です。経路の組み合わせは[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に書いています。

## 経路の課題：園の種類と潜在保育士で違う

| 対象 | 動く理由 | 合う経路 |
|---|---|---|
| 現役の保育士（認可・中規模以上） | 方針、行事と持ち帰りの少なさ、教育の体制 | 掲載型、学校、紹介 |
| 現役の保育士（小規模） | 少人数、方針の相性、園長の人柄 | 地域の経路、知人 |
| 潜在保育士 | 時間、持ち帰り無し、複数担任、ブランクの受け入れ | 地域の経路、自治体の窓口、知人、復職の支援の場 |
| 新卒 | 実習の印象、教育の体制、最初の一年の型 | 学校、実習の受け入れ |
| 補助の職種 | 家の近く、時間 | 地域の掲載型 |

園の種類と対象ごとに求人票と経路を分け、園と経路ごとに応募の数を記録します。

## 枠の課題：園長が保育と保護者対応で手一杯

| 状態 | 直し方 |
|---|---|
| 日中の面接が取れない | 午睡の時間、降園の後、オンライン、の枠を週に一つ先に預かる |
| 候補者の希望を聞いてから調整 | 枠を預かっているので、候補を三つ出して即日で確定 |
| 面接と見学が別の日 | 同じ日に組み、保育の場面を見てもらう |
| 園長が全段に出る | 一次（書類の照合と一次対応）を外に出し、園長は面接と見学だけ |
| 複数の園で同時に進み、法人の担当者が追いつかない | 園をまたいだ日程の運用を外に出す |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 時期 | 前の年度の記録からの逆算、募集の開始の運用 | 通年で受け入れる型、離職の理由の記録 |
| 配置 | 書類での区分の照合、園と年齢ごとの充足の一覧 | 区分と人数の整理（会社と専門家） |
| 実態 | 求人票に落とす作業、見学の日程 | 実態を語る。見学で何を見せるか |
| 経路 | 対象ごとの経路の運用 | 潜在保育士への条件の決定、求人票の実態 |
| 枠 | 日程の運用、園をまたいだ調整 | 枠の形を変えて出す |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[保育業界で採用代行が機能する条件・機能しない条件](/media/rpo-hoiku-jirei/)に書いています。

## まとめ

- 「採れない」には**時期・配置・実態・経路・枠**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は離職の時期と理由と、切り替わりまでの日数
- 最も多い詰まりは**時期**で、毎年同じなのに逆算が無い。退職の申し出を待たずに始める
- **資格・配置の基準は会社と専門家**。個別の判断は専門家にご確認ください
- 実態（方針・行事・持ち帰り・担任の形）を**先に出し、見学を段に**
- 経路は**園の種類と潜在保育士で分ける**
- 枠は**午睡の時間・降園の後・オンラインで週に一つ**先に預かる

## よくある質問

### 保育士は業界全体で足りないので、自社だけでは直せないのではないですか

同じ地域で離職が少なく、年度末の募集が落ち着いている園はあります。違いは、逆算で早く始めているか、持ち帰りの仕事を園で吸収しているか、複数担任から始めているか、潜在保育士に届く求人票と経路を分けているか、です。「業界全体」にすると、直す場所が消えます。五つを記録で確かめ、一つずつ直しても採れないなら、条件の判断に進みますが、それは五つを確かめた後です。

### 年度末まで時間が無く、いまから逆算しても間に合いません

今年度は間に合わないことを前提に、いまある応募からの入職を増やす（返事を翌営業日中に返す、面接と見学を同じ日に組む、枠を先に預ける）ことに絞ります。並行して、今年度の記録（応募から入職までの日数、段ごとの通過の比率、辞退の理由）を残し、来年度の逆算に使います。今年度の記録が無いと、来年度も同じことが起きます。記録を残すことが、いまできる最も大きな対策です。

### 方針を求人票に書くと、応募が減りませんか

方針に合わない人の応募は減り、合う人の応募は増えます。方針を書かずに応募を増やしても、面接で「方針が合わない」と辞退され、入職して離れます。応募の数ではなく、面接に進んだ人数と入職後の定着で比べると、書いたほうが多い。行事の多さと持ち帰りの実態も同じで、隠して採ると離職で戻ってきます。実態を書いて応募が減るなら、それは実態を変える判断（持ち帰りを園で吸収する、行事を見直す）の材料で、会社が決めます。
