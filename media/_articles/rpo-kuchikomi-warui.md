口コミサイトに、自社の評価が載っている。点数は低く、「残業が多い」「評価が不透明」「上司による」といった書き込みが並ぶ。候補者は面接の前に見ていて、面接で「口コミにこう書かれていますが」と聞かれる。辞退の理由に「口コミを見て」と言われたこともある。結論を先に書くと、**口コミの評価は消せません。消そうとするより、書かれている中身を「事実で直せるもの」「過去のもの」「見方の違い」「事実でないもの」に分け、直せるものを直し、直したことと直せないことを面接で先に話します。口コミに書かれていることを、自社から先に話す会社は、候補者から信用されます**。スカウトの場面での向き合い方は[口コミを見られる前提の設計](/media/scout-kuchikomi-taisaku/)に、代行の対応が口コミに書かれる話は[代行の対応が口コミに書かれるリスク](/media/rpo-kuchikomi/)にまとめています。

## 口コミの評価が低い会社で起きていること

口コミの評価が低い会社では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 応募の前に離れている | 求人を見た候補者が会社名で検索し、口コミを見て、応募しない。応募の数からは見えない |
| 面接で口コミについて聞かれる | 候補者は見ている。聞かれたときに面接官が動揺する、否定する、で不信になる |
| 辞退の理由になる | 内定の後に口コミを見て（または家族が見て）、辞退。理由を「口コミ」と言う人と、言わない人がいる |
| 社内が口コミを見ていない | 責任者も人事も、自社の口コミを読んだことが無い。候補者だけが読んでいる |
| 「消したい」「書き込みをやめさせたい」に気持ちが向く | 消せないものに時間を使い、直せるものに手が回らない |
| 書き込みの中身を分けていない | 「残業が多い」と「上司が怒鳴る」と「三年前の話」が、同じ重さで扱われている |
| 面接官が、口コミの内容を知らない | 聞かれても答えられず、「そんなことはない」と否定して、候補者の信用を失う |

口コミの評価は、候補者の判断の材料の一つです。材料を消すことはできませんが、材料の読み方を変えることはできます。

## 書き込みの中身を分ける

最初に、自社の口コミを全部読み、中身を分けます。

| 分類 | 例 | 向き合い方 |
|---|---|---|
| 事実で、いまも続いていて、直せるもの | 「残業が多い」「評価の基準が分からない」「研修が無い」 | 直す。直したことを面接で話す |
| 事実だが、過去のもので、いまは変わっているもの | 「三年前の上司の話」「旧オフィスの話」「制度の変更前の話」 | 変わったことを、事実で面接で話す |
| 事実だが、直せないもの、または直さないと決めたもの | 「給与が業界の平均より低い」「裁量が少ない役割がある」 | 隠さず、そのうえで自社を選ぶ理由を話す |
| 見方の違い | 「裁量が大きすぎて放置される」と「裁量が大きくて成長できる」が同じ事実 | 「こういう人には合わない、こういう人には合う」を面接で話す |
| 事実でないもの | 書き込みの内容が、事実と異なる | 運営側への対応（後述）。面接では事実を話す |
| 個人への攻撃、私的な内容 | 特定の人への攻撃、私的な事情 | 運営側への対応。面接では触れない |

分けると、「全部が悪い」ではなく、「直せるものが三つ、過去のものが二つ、見方の違いが一つ」のように見えます。分けることが、対処の始まりです。

分ける作業は、責任者と人事と、現場の責任者で行います。現場の責任者は、「これは事実」「これは違う」を判断できます。

## 直せるものを直す

「事実で、いまも続いていて、直せるもの」は、直します。

**口コミは、退職者と現職者の声。** 書かれていることは、社内で言えなかった不満です。採用の問題である前に、組織の問題です。直せば、採用だけでなく、定着も変わります。

**直す優先順位は、書き込みの多さと、直しやすさで。** 多く書かれていて、直しやすいものから。「評価の基準が分からない」なら、基準を書面にして社員に共有する。「研修が無い」なら、最初の一か月の予定を作る。

**直したことを、社内に伝える。** 直しても、社員が知らなければ、口コミは変わりません。「こういう声があったので、こう変えた」と、社員に伝えます。

**直したことを、記録する。** いつ、何を、どう変えたか。面接で話す材料になり、次の口コミの変化と照らし合わせられます。

**直せないと決めたものは、決めた理由を持つ。** 「給与の水準は、いまの事業の状況では上げられない」と決めたなら、その理由を持ちます。面接で聞かれたときに、隠さず話せます。

**制度の変更は、規程と法令に沿う。** 評価の制度、労働時間の管理、研修の制度の変更は、社内の規程と法令に沿い、専門家に確認します。

直すことは、時間がかかります。ただ、直し始めたことは、面接で話せます。「直しました」でなくても、「こういう声があり、こう変え始めています」は、候補者に伝わります。

## 直せないものへの向き合い方

直せないもの、過去のもの、見方の違いには、向き合い方があります。

**過去のものは、変わった事実を話す。** 「三年前にそういう状況がありました。その後、上司が替わり、制度がこう変わりました」。過去を否定せず、変わったことを事実で。

**直せないものは、隠さず、選ぶ理由を添える。** 「給与の水準は、同じ職種の他社より低い場合があります。そのうえで、役割の裁量と、この事業に関わる意味を重く見る方に来ていただいています」。隠すと、入社後に不信になります。

**見方の違いは、「合う人・合わない人」で話す。** 「裁量が大きい分、放置されていると感じる人もいます。自分で決めて進めたい人には合い、細かい指示が欲しい人には合いません」。候補者が自分で判断できる材料にします。

**口コミの点数は、点数として認める。** 「点数は低いです」と認めたうえで、中身の分類を話します。点数を否定すると、候補者は「見ていないのか」「隠しているのか」と感じます。

**他社と比べない。** 「他社も同じような口コミがある」は、候補者には言い訳に聞こえます。自社の話だけをします。

向き合い方の要点は、「否定しない」「隠さない」「変わったことと変わらないことを分けて話す」の三つです。

### エラベルの見解

相談で最も多い失敗は、「口コミを消そうとして、運営側に削除を求め続け、半年何も変わらず、その間に直せるものを何も直さなかった」というものです。削除は、事実でない書き込みや規約に反するものには可能性がありますが、事実の書き込みは消えません。半年後、口コミは同じで、候補者の離れ方も同じでした。最初に中身を分けて、「評価の基準が分からない」を基準の書面化で直し、「研修が無い」を一か月の予定で直し、面接で「こういう声があったので、こう変えました」と話し始めたら、辞退が減りました。

見ていて差がつくのは、担当者が「自社の口コミを全部読んで、分類して持ってくる」かどうかです。「口コミは気にしなくてよい」と言う担当者と、「読んで分類しました。直せるものが三つ、過去のものが二つ。面接で先に話す文を作りました」と持ってくる担当者がいます。後者は、口コミを面接の材料に変えます。

発注側にできるのは、担当者に「口コミを消したい」ではなく、「口コミを分類して、直せるものと、面接で話す文を作ってほしい」と依頼することです。

## 面接で先に話す型

口コミについて、候補者に聞かれる前に、自社から話します。

| 場面 | 話す型 |
|---|---|
| 一次面接の冒頭か終盤 | 「口コミサイトをご覧になったかもしれません。点数は低いです。書かれていることについて、こちらからお話しします」 |
| 直したもの | 「〇〇という声があり、△△を変えました。変えた後、社内ではこう変わっています」 |
| 過去のもの | 「〇〇は三年前の状況です。その後、こう変わりました」 |
| 直せないもの | 「〇〇は、いまも変わっていません。そのうえで、この役割を選ぶ理由はこうだと考えています」 |
| 見方の違い | 「〇〇は、合う人と合わない人がいます。〇〇な方には合い、△△な方には合いません」 |
| 候補者への問い | 「口コミを見て、気になったことがあれば、聞いてください。事実のとおりお答えします」 |
| 面接官への準備 | 口コミの分類と、話す型を、面接官全員に書面で渡す。面接官が知らない状態を無くす |

先に話すと、候補者は「この会社は隠さない」と受け取ります。聞かれてから答えると、「聞かれたから答えた」になります。同じ内容でも、順番で信用が変わります。

面接官への準備が要点です。一人の面接官が「そんなことはない」と否定すれば、他の面接官が先に話した信用が消えます。

## 社員に書いてもらう是非

「社員に良い口コミを書いてもらえば、評価が上がる」という考えがあります。

**強要や指示は、避ける。** 「良いことを書いてください」と指示する形は、社員の不信と、書き込みの不自然さを生みます。口コミサイトの規約に反する場合もあり、発覚すれば会社の信用を失います。規約は各サイトの公式の案内で確認します。

**「書いてもよい」と伝えることは、できる。** 「口コミサイトに、率直な意見を書いてもらって構いません」と伝えるのは、指示ではありません。良いことも悪いことも、率直に。

**率直な口コミが増えれば、偏りは減る。** 退職者の不満だけが書かれている状態に、現職者の率直な声が加われば、全体の見え方は変わります。ただし、それを目的に誘導しない。

**直したことを社内に伝えることが、先。** 直したことを社員が知り、実感すれば、書き込みは自然に変わります。書いてもらうことより、直すことです。

**書き込みの内容に、会社が関与しない。** 内容を確認する、修正を求める、は避けます。

社員の口コミは、会社が操作するものではなく、会社が変わった結果として変わるものです。

## 口コミサイトの運営側への対応

事実でない書き込み、個人への攻撃、私的な内容には、運営側への対応があります。

**各サイトの規約と、申し立ての仕組みを確認する。** サイトごとに、削除や修正の申し立ての仕組みと、対応の基準があります。公式の案内で確認します。

**事実でないことを、事実で示す。** 申し立てには、「事実と異なる」ことの根拠が要ります。感情ではなく、事実で。

**個人への攻撃や、私的な内容は、規約に反することが多い。** 特定の社員への攻撃、私的な事情の書き込みは、規約で禁止されていることがあります。

**事実の書き込みは、消えない前提で。** 「残業が多い」が事実なら、消えません。消そうとする時間を、直すことに使います。

**法的な対応が要る場合は、専門家に相談する。** 名誉を毀損する内容、営業を妨害する内容など、法的な対応の可能性がある場合は、専門家に相談します。

**企業からの返信の機能があるサイトでは、返信を検討する。** 一部のサイトには、企業が口コミに返信できる機能があります。返信する場合は、否定ではなく、「ご指摘の点は、こう変えました」の形で。仕組みは各サイトの公式の案内で確認します。

運営側への対応は、事実でないものと、規約に反するものに限ります。事実の書き込みへの対応は、直すことと、面接で話すことです。

## 外注する場合の範囲

口コミの問題を、採用代行に出す場合の範囲です。

**出せる工程。** 自社の口コミの読み込みと分類、直せるものの整理と優先順位の案、直したことの記録の型、面接で先に話す文の作成、面接官向けの書面、候補者からの質問への答えの型、辞退の理由の記録（口コミが理由かどうか）、運営側への申し立ての整理（規約の確認と事実の整理）、企業からの返信の文案。

**社内に残す判断。** 直すかどうかの決定、制度の変更、直せないと決める判断、運営側への申し立ての決定、法的な対応、社員への伝え方。

**外注の効きどころ。** 口コミの分類は、社内の人が読むと感情が入り、「全部がひどい」か「全部が言いがかり」になりがちです。外部の担当者が読んで分類すると、「直せるものが三つ」のように冷静に分けられます。面接で先に話す文と、面接官向けの書面は、担当者が作れます。

**外注しても動かない場合。** 責任者が「口コミは言いがかり」を譲らない、直せるものを直さない、面接官が書面を読まない。社内の判断で、代行を替えても直りません。

口コミは、消せないものです。外注は、消せないものを、面接の材料に変える手段です。

### エラベルの見解

担当する側から見ると、口コミの相談で最も多いのは、「責任者が自社の口コミを読んでいない」ことです。「口コミが悪いらしい」と人事から聞いて、読まずに「消せないのか」と言う。読めば、書かれていることの大半が、社内で言われていた不満と同じだと分かります。

読んで、分類して、直せるものを直す。それを面接で先に話す。この流れを回した会社は、口コミの点数が変わる前に、辞退が減ります。候補者は、点数より、「この会社は口コミにどう向き合っているか」を見ています。

発注側にできるのは、責任者が自社の口コミを全部読むことです。読まずに対処はできません。

## よくある質問

### 口コミを削除してもらうことは、できますか

事実でない書き込み、個人への攻撃、私的な内容、規約に反するものは、各サイトの申し立ての仕組みで対応できる可能性があります。事実の書き込み（「残業が多い」が事実の場合など）は、消えない前提で向き合います。申し立ての仕組みと基準は各サイトの公式の案内で確認し、法的な対応が要る場合は専門家に相談します。削除に時間を使うより、直せるものを直し、面接で先に話すほうが、採用への効果は早いです。

### 面接で口コミについて聞かれたら、どう答えればよいですか

否定せず、隠さず、分類して答えます。「点数は低いです」と認め、「〇〇は直しました」「△△は三年前の状況で、いまはこうです」「□□はいまも変わっておらず、そのうえで選ぶ理由はこうです」。聞かれる前に自社から話すほうが、信用されます。面接官全員に、分類と話す型を書面で渡し、一人が「そんなことはない」と否定する状態を無くします。

### 社員に良い口コミを書いてもらうのは、効果がありますか

強要や指示は避けます。社員の不信と書き込みの不自然さを生み、規約に反する場合もあります。「率直な意見を書いてもらって構わない」と伝えることはできますが、内容に会社が関与しません。効果があるのは、直せるものを直し、直したことを社員に伝えることです。社員が変化を実感すれば、書き込みは自然に変わります。書いてもらうことより、直すことが先です。
