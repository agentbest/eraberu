副業を始めたいが、本業の会社に知られたくない。規定では認められているようだが、周りに副業をしている人はおらず、言い出しにくい。知られずに続けられるのか、どこから知られるのか。結論を先に書くと、**副業が本業の会社に知られる経路は、「税や保険の処理」「本人の言動と発信」「依頼側や候補者との接点」「本業の端末や回線の使用」の四つに整理できます。四つのうち、自分で防げるのは後の三つで、最初の一つは制度の仕組みによるもので、自分だけでは防げないとされています。**だから、「ばれないか」を考えるより、「知られても問題ない状態にできるか」を先に考えるほうが、続けやすくなります。規定で認められているなら、届け出て始めるのが最も確かです。届け出の書き方は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、本業との線引きは[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分離は[情報の取り扱いと端末の分離](/media/fukugyo-security/)にまとめています。税と制度の仕組みは、専門家にご確認ください。

## 知られる経路の四つ

副業が本業の会社に知られる経路を、四つに分けます。経路ごとに、防げるかどうかが違います。

| 経路 | 内容 | 自分で防げるか |
|---|---|---|
| 一、税や保険の処理 | 副業の収入に伴う税や保険の処理で、本業の会社の側に情報が届く経路があるとされている | 制度の仕組みによる。自分だけでは防げないとされる。仕組みと対処は専門家に |
| 二、本人の言動と発信 | 同僚に話す、SNSで発信する、実名で経歴を公開する | 防げる。話さない、発信の名前と内容を分ける |
| 三、依頼側や候補者との接点 | 依頼側が本業の会社と関係がある、候補者が本業の関係者だった、依頼側の担当者が本業の同僚と知り合い | 一部防げる。競合と接点を受ける前に確認する |
| 四、本業の端末や回線の使用 | 本業の端末で副業の作業をする、本業の回線で副業のサービスに接続する、本業のメールで連絡する | 防げる。端末・回線・アカウントを分ける |

四つの要点は、「一」が自分だけでは防げないとされていることです。副業の収入に伴う処理で本業の会社に情報が届く経路については、制度と自治体と本業の会社の処理によって扱いが変わり、一律には言えません。「こうすれば防げる」という情報を見かけても、自分の状況に当てはまるかは、専門家に確認しないと分かりません。この経路がある以上、「ばれない」前提で始めることには限界があります。税の処理は[確定申告はどうするか](/media/fukugyo-qa-10/)を見たうえで、専門家にご確認ください。

## 経路ごとに自分で防げること

自分で防げる三つの経路について、具体の対処です。

| 経路 | 防ぐ対処 | 要点 |
|---|---|---|
| 本人の言動 | 本業の同僚、上司、取引先に副業の話をしない。飲み会や雑談でも | 「一人にだけ」が広がる。伝えるなら正式に届け出る |
| 本人の発信 | 発信の名前を本名と分ける。本業の会社名、本業の採用の内情、本業で作った成果物を発信に含めない | [実名で発信するか](/media/fukugyo-honmyou-hasshin/)、[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/) |
| 経歴の公開 | 経歴の一覧の場所や自分のサイトに、本業の会社名と副業を並べて書かない | [自分のサイトは要るか](/media/fukugyo-hp/) |
| 依頼側との接点 | 受ける前に、依頼側と本業の会社の事業・候補者・人の重なりを確認する。重なるなら受けない | [本業の会社に競合はいないか](/media/fukugyo-qa-14/) |
| 候補者との接点 | 本業で接した候補者には副業で接しない。候補者が本業の関係者だと分かったら、依頼側に伝えて外れる | [個人情報の扱い](/media/fukugyo-kojin-jouhou/) |
| 端末と回線 | 副業の作業は私物の端末、自宅の回線、副業用のアカウントで。本業の端末・回線・メールは一切使わない | [私物端末で作業してよいか](/media/fukugyo-tanmatsu/)、[ネットワーク環境の注意](/media/fukugyo-vpn/) |
| 名刺 | 本業の名刺を副業で使わない | [名刺をどうするか](/media/fukugyo-meishi/) |

防ぐ要点は、「本業の端末・回線・メールを一切使わない」ことです。本業の昼休みに本業の端末で副業の連絡を見る、本業の回線で副業のサービスに接続する、といった行為は、本業の会社の記録に残り、最も分かりやすく知られる経路になります。加えて、本業の規定に触れることが多く、副業の許可の有無以前の問題になります。端末と回線の分離は、「ばれないため」というより、本業の規定を守るために要ります。

### エラベルの見解

相談で最も多い思い込みは、「気をつけていれば、副業は本業に知られずに続けられる」というものです。実際には、税や保険の処理という経路があるとされていて、自分の言動と端末を分けても、それだけで「知られない」と言い切ることはできません。知られない前提で始めた人が、後で知られたときに困るのは、副業をしていたことより、隠していたことです。規定で認められている副業を隠していたことで、会社との関係が悪くなる例があります。

見ていて差がつくのは、「ばれないか」で始めるか、「伝えてよい状態にしてから」始めるかです。本業の規定を読み、認められているなら届け出て、本業の会社の情報を持ち込まず、競合しない案件を受け、端末を分ける。この状態で始めた人は、知られても問題が無く、知られることを心配しながら続ける負担がありません。エラベルでは、登録の際に本業の規定で副業が認められているかを聞き、届け出が要る場合は届け出てから始めることを勧めています。隠して続ける副業は、担当者にとっても依頼側にとっても、途中で止まるリスクになります。

## 隠す前提で始めると起きること

「ばれないように」を前提に始めると、副業の進め方そのものに影響が出ます。

| 起きること | 内容 |
|---|---|
| 発信ができない | 実名で発信できず、案件の入口が一つ減る |
| 経歴が書けない | 副業の実績を経歴に書けず、次の案件や転職で使えない |
| 依頼側に本業の業界を言えない | 競合の確認ができず、後で重なりが分かる |
| 対面や紹介を避ける | 本業の関係者に会う可能性のある場面を避け、案件が限られる |
| 知られたときに隠していたことが問題になる | 規定で認められていても、隠していたことで信頼を失う |
| 常に不安が続く | 続けている間、ずっと「知られないか」を気にする。それ自体が負担になる |
| 税の処理で無理をする | 「知られないため」に処理を歪めると、別の問題が起きる。処理は専門家に |

起きることの要点は、「隠す前提は、副業の入口と出口を狭める」ことです。発信も経歴も紹介も、隠していると使えません。副業を続け、広げていくには、伝えてよい状態のほうが、圧倒的に動きやすくなります。発信の入口は[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/)に、経歴の使い方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に書いています。

## 伝えてよい状態の作り方

「知られても問題ない状態」を、始める前に作る手順です。

| 手順 | 内容 |
|---|---|
| 一、本業の規定を読む | 就業規則の副業の条項。禁止か、届出制か、許可制か、自由か。競業の制限と、秘密保持の範囲 |
| 二、認められているなら届け出る | 届出制か許可制なら、様式に沿って届け出る。会社の懸念（時間、競業、情報、健康）を先に潰す書き方で。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/) |
| 三、本業の情報を持ち込まない線を引く | 本業の候補者、採用の進め方、社内の情報を副業で使わない。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 四、競合しない案件だけ受ける | 事業・候補者・情報の三つの軸で重ならない依頼側。[本業の会社に競合はいないか](/media/fukugyo-qa-14/) |
| 五、端末・回線・アカウントを分ける | 本業のものを一切使わない |
| 六、本業の時間に副業をしない | 本業の勤務時間中に副業の作業や連絡をしない。昼休みも本業の端末と回線は使わない |
| 七、本業の稼働と健康を守る | 副業で本業の稼働が落ちない枠にする。[稼働時間の上限](/media/fukugyo-kadou-jikan/) |

作り方の要点は、「二」の届け出です。規定で認められているなら、届け出て始めれば、「知られるか」という問いそのものが消えます。届け出が通らない場合や、禁止されている場合は、始めるかどうかの判断が先で、隠して始めることは勧めません。届け出の書き方と、断られたときの扱いは[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。規定の解釈は、専門家にご確認ください。

## 伝えない選択をする場合の線

規定で認められていて届け出も不要、または届け出たうえで周りには言わない、という選択もあります。その場合の線です。

| 状況 | 線 |
|---|---|
| 規定で自由で、届け出が不要 | 会社に伝える義務は無い。ただし、競業と情報と端末の線は守る。同僚に話すかは自分の判断 |
| 届け出たが、同僚には言わない | 会社の窓口には伝えてあるので、知られても問題は無い。同僚に言わないのは私的な判断で構わない |
| 上司にだけ伝える | 上司との信頼の関係で伝えることは、後で問題になりにくい。[人事1年目でもできること](/media/fukugyo-1nenme/)にも書いた考え方 |
| 規定が曖昧で、届け出が要るか分からない | 会社の窓口に「このような副業は届け出が要るか」を確認する。確認せずに始めない |
| 規定で禁止されている | 隠して始めることは勧めない。始めるなら、規定の変更を待つか、転職を含めて考える。判断は専門家に |

線の要点は、「会社に伝えることと、同僚に話すことは別」だということです。規定に沿って会社に伝えてあれば、同僚に話さないのは私的な選択で、問題になりません。会社に伝えず同僚にだけ話す、は最も危ない形で、同僚から会社に伝わったときに「隠していた」になります。伝えるなら会社の正式な経路で、話さないなら誰にも、が分かりやすい線です。

## 本業の規定と専門家に確認すべきこと

「ばれるか」に関わることのうち、自分で判断せず確認すべきことを分けておきます。

| 確認すること | 誰に | なぜ |
|---|---|---|
| 副業の可否と、届け出の要否 | 本業の会社の規定、窓口 | 会社ごとに違う。規定を読んで分からなければ窓口に |
| 競業の制限の範囲 | 本業の会社の規定、専門家 | 「同業」の定義が事業か、候補者の重なりまで含むか |
| 秘密保持の範囲 | 本業の会社の誓約書、専門家 | 本業で知った候補者の情報や採用の進め方が対象か |
| 税や保険の処理で本業に届く経路と、その扱い | 税理士、社会保険労務士 | 制度と自治体と本業の処理で変わる。一律に言えない |
| 本業の勤務時間や健康に関わる規定 | 本業の会社の規定、専門家 | 副業の稼働が本業に影響しないことを、どう示すか |
| 届け出が断られた場合の扱い | 専門家 | 断られる理由と、それに対する対処 |

確認の要点は、「税や保険の処理の経路は、専門家に自分の状況を伝えて聞く」ことです。この経路は、調べれば情報が出てきますが、自分の状況（本業の会社の処理、自治体、収入の形）で扱いが変わり、当てはまるかどうかは専門家にしか判断できません。「こうすれば防げる」という情報を鵜呑みにして処理を歪めると、別の問題が起きることがあります。処理の全体は[確定申告はどうするか](/media/fukugyo-qa-10/)に書いています。

### エラベルの見解

担当する側から見ると、副業を長く続けている人は、「ばれるか」を気にしていません。本業の規定を読み、認められているなら届け出て、本業の情報を持ち込まず、競合しない案件を受け、端末を分けている。この状態なので、知られても困らず、発信も経歴も紹介も使えています。隠して始めた人は、入口が狭く、常に不安を抱え、知られたときに隠していたことで信頼を失い、副業と本業の両方に影響が出ています。

順番として、本業の規定を読み、届け出が要るなら届け出て、本業の情報と競合と端末の線を引き、本業の時間に副業をしない、と決めてから始める。税や保険の処理は専門家に聞く。この順番で、「ばれるか」は「伝えてある」に変わり、副業は隠すものではなく、本業と並べて持てるものになります。エラベルでは、登録の際に本業の規定で副業が認められているかを聞き、届け出てから始めることを勧めています。担当者が安心して続けられることが、依頼側にとっても、案件が途中で止まらない土台になります。

## まとめ

- 知られる経路は**税や保険の処理・本人の言動と発信・依頼側や候補者との接点・本業の端末や回線**の四つ
- **税や保険の処理の経路は自分だけでは防げない**とされる。仕組みと扱いは専門家に
- 自分で防げるのは**言動と発信・接点・端末と回線**。特に本業の端末・回線・メールは一切使わない
- 隠す前提で始めると**発信・経歴・紹介が使えず、常に不安が続き、知られたときに隠していたことが問題になる**
- 伝えてよい状態は**規定を読む→届け出る→情報を持ち込まない→競合しない→端末を分ける→本業の時間に副業をしない→本業の稼働と健康を守る**
- **会社に伝えることと同僚に話すことは別**。伝えるなら会社の正式な経路で
- 規定・競業・秘密保持・税と保険の処理は、**自分で判断せず確認する**

## よくある質問

### 規定では副業が認められていますが、周りに副業をしている人がおらず、届け出づらいです

届け出づらさは、規定の問題ではなく、社内の空気の問題です。届け出は会社の窓口に対して行うもので、同僚に知らせるものではありません。窓口に届け出て、同僚には言わない、という形は、規定に沿っていて、問題になりません。届け出の書き方は、会社が持つ懸念（時間、競業、情報、健康）を先に潰す形にすると、通りやすくなります。書き方は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。

### 届け出たら、上司から「本業に集中してほしい」と言われました

規定で認められている副業について、上司の個人的な意見で止められることは、本来は無いはずですが、上司との関係は続くので、一方的に押し切るのは勧めません。「本業の稼働と成果は落とさない。副業は本業の時間外で、週にこの枠だけ」と、上司の懸念に具体で答え、様子を見てもらう形にします。それでも認められない場合は、規定と上司の意見のどちらが優先されるかを、会社の窓口か専門家に確認します。上司との関係で迷う場合の考え方は[人事1年目でもできること](/media/fukugyo-1nenme/)にも書いています。

### 「住民税を自分で納める形にすれば、ばれない」と聞きました

税の処理に関する情報は、自分の状況（本業の会社の処理、自治体、収入の形）で扱いが変わり、一律に「こうすれば」とは言えません。見聞きした方法が自分に当てはまるかは、専門家に自分の状況を伝えて確認してください。処理の方法だけで「知られない」と考えるより、規定に沿って届け出て、知られても問題ない状態にするほうが、確かです。税の処理は[確定申告はどうするか](/media/fukugyo-qa-10/)を見たうえで、専門家にご確認ください。
