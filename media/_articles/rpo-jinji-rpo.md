人事の採用には、他の職種に無い構造があります。人事がいないから人事を採るのに、採用を回す人事がいない。経営者や総務の担当者が兼務で募集を出し、応募の対応に追われ、面接で「この人が人事として回せるか」を判断できない。この構造のため、人事の採用は、代行に出す価値が最も大きい職種の一つです。ただし、代行に出せるのは採用を回す工程で、「自社の人事に何を任せるか」「経営が人事に委ねる範囲」は、代行には決められません。結論を先に書くと、**人事採用で代行に出せるのは「探す・届ける・一次対応する・進捗を回す」で、「自社の人事の役割（採用・労務・制度・育成のどれを、どこまで）の決定・経営が委ねる範囲の設計・人事としての判断の質の評価」は社内に残す**のが線です。役割が決まっていない募集は、「人事経験者」の肩書で探すことになり、来た人が自社で回せません。役割の分け方と最初の一人に求めるものは[人事担当そのものが採用できない](/media/rpo-jinji-saiyo/)に、人事が一人で回らない構造は[人事が一人で回らない](/media/rpo-jinji-hitori-kadai/)にまとめています。

## 人事採用が他の職種と違う点

一つ目は、採用を回す人がいないことです。他の職種の採用では、人事が募集を出し、応募に対応し、面接を組みます。人事の採用では、その人事がいない。経営者か総務の兼務が、本業の合間に回すことになり、対応が遅れ、応募者が離れます。

二つ目は、評価する人がいないことです。人事としての判断の質（採用の要件をどう作るか、労務の相談にどう答えるか、経営と現場の間でどう動くか）を、人事のいない社内で評価できる人がいない。経営者が「感じが良い」で判断すると、入社後に「回せない」となります。

三つ目は、「人事」の中身が広いことです。採用、労務（給与、社会保険、勤怠）、制度（評価、等級、規程）、育成、組織の設計。一人で全部を深く持つ人は少なく、「人事経験者」で探すと、自社が最も困っていることと違う領域の人が来ます。

四つ目は、経営者が人事に委ねる範囲で、求める人が変わることです。採用の判断を委ねるのか、経営者が全部決めるのか。労務の判断を任せるのか、社労士に頼るのか。委ねる範囲が曖昧だと、人事の経験者は「経営者の指示で動くだけ」と感じて離れます。

五つ目は、人事の候補者が、会社の採用の進め方を見て判断することです。人事の候補者は、応募から面接までの対応の速さ、求人票の質、面接の進め方を、「この会社の人事の水準」として見ます。採用の進め方が雑だと、経験者ほど見送ります。

この五つから、代行に出せる工程と、代行に出す価値が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 自社の人事の役割の決定（採用・労務・制度・育成のどれを、どこまで） | 残す | 自社の困りごとから。社内にしか分からない |
| 経営が委ねる範囲の設計 | 残す | 採用の判断、労務の判断をどこまで人事に |
| 社労士や外部との分担 | 残す | 労務のどこまでを社内で |
| 要件の決定 | 残す | 役割と範囲から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（役割と範囲が決まっていれば） | 人事の候補者が「この会社の人事の水準」として見るので、質が要る |
| 媒体の選定と運用 | 任せられる | 人事に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 役割に合わせた検索と、文面の個別化 |
| 応募者への一次対応 | 任せられる | 社内に回す人がいないので、ここが最も効く |
| 書類の一次絞り | 条件付き | 役割（採用・労務・制度・育成）の分類は任せられる。判断の質は残す |
| 人事としての判断の質の評価 | 残す | 経営者と、人事の分かる人（外部でも）が面接で聞く |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断 |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡 |

線の要点は、「採用を回す工程は、社内に回す人がいないぶん、代行に出す価値が大きい」ことです。一方で、役割と委ねる範囲は、代行には決められません。

### エラベルの見解

相談で最も多いのは、「人事がいないので、人事の採用も含めて全部お願いしたい」というご相談です。気持ちは分かりますが、「自社の人事に何を任せるか」を決めていない状態で全部を出すと、代行は「人事経験者」で探すしかなく、来た人が自社の困りごと（採用が回らないのか、労務が回らないのか）と違う領域の人になります。役割を決めるのは、代行ではなく経営者です。

見ていて差がつくのは、「自社が最も困っていることを一つに絞って、最初の一人の役割を決めているか」です。「採用が回らない」なら、採用を回す人事。「労務が属人化している」なら、労務を整える人事。「評価制度が無い」なら、制度を作る人事。一つに絞れば、要件が決まり、代行は探す・届ける・回す工程で力を出せます。エラベルでは、人事の案件をお受けする前に、依頼側の経営者に「最も困っていること」を一つ伺い、最初の一人の役割を一緒に決めています。役割の分け方は[人事担当そのものが採用できない](/media/rpo-jinji-saiyo/)に詳しく書いています。

## 代行に出す前に社内で確認すること

代行に出す前に、社内で揃えておくことを六つ挙げます。

- **最初の一人の役割が一つに決まっているか。** 採用か、労務か、制度か、育成か。「全部」は市場に少なく、いても一人では回らない
- **経営が委ねる範囲が決まっているか。** 採用の合否、労務の判断、制度の設計をどこまで人事に。経営者が全部決めるなら、それを正直に
- **社労士や外部との分担が決まっているか。** 労務の手続きは社労士か社内か。就業規則の作成は誰が
- **人事を評価する人がいるか。** 経営者だけでは判断の質を評価しにくい。外部の人事の分かる人（顧問、社労士、知人の人事）を用意する
- **人事がいない間の採用の進め方が決まっているか。** 一次対応、面接の日程、内定の連絡を、誰が（代行か、経営者か）どう回すか
- **人事の候補者に見せる「自社の人事の状態」を整理しているか。** いま誰が何をしていて、何が属人化していて、何が止まっているか。正直に

六つのうち、一つ目と二つ目が最も重要です。役割と委ねる範囲が決まれば、他は整理できます。

## 人事がいない会社で人事を評価する組み方

人事のいない社内で、人事の候補者の判断の質を評価する組み方を三つ示します。

一つ目は、外部の人事の分かる人（顧問、社労士、知人の人事、他社の人事責任者）に、要件の整理と面接の同席を頼むことです。「自社の状態で、どの役割の人が現実的か」を整理してもらい、面接で判断の質を聞いてもらう。

二つ目は、面接で、自社の実際の困りごとを題材に、候補者の進め方を聞くことです。「採用が回らない」なら「最初の一か月で何をしますか」、「労務が属人化している」なら「何から整理しますか」。経営者でも、進め方の筋道は判断できます。

三つ目は、代行の担当者に、人事の候補者の経歴の読み方（役割の分類、担った範囲）を任せ、経営者は面接で判断の質に集中することです。代行が「この候補者は採用の実務を〇年、労務は未経験」と分類して渡せば、経営者は「採用を回せるか」に絞って聞けます。

どの組み方でも、「判断の質の評価を代行に任せない」ことは同じです。

## 代行を選ぶときの確認項目

| 確認項目 | 聞き方 | 見るポイント |
|---|---|---|
| 人事採用の経験 | 「人事の採用で、採用担当と労務担当の両方の募集を担当しましたか」 | 役割の違いを分かっているか |
| 経歴の読み方 | 「『人事全般を担当』という経歴を、どう読みますか」 | 役割と範囲を確かめる姿勢があるか |
| 人事がいない状況の理解 | 「人事がいない会社で、採用の進め方をどう設計しますか」 | 一次対応から内定まで、社内に回す人がいない前提で設計できるか |
| 求人票の質 | 「人事の候補者に見られる求人票として、何に気をつけますか」 | 人事の候補者が求人票の質を見ることを分かっているか |
| 評価の扱い | 「人事としての判断の質の評価はどう進めますか」 | 「御社と人事の分かる方で」と答えるか |
| 担当者 | 「担当する方の経歴を教えてください」 | 人事の経験があるか。人事の採用は人事の経験者が担当すると質が上がる。[担当者の経歴を確認する](/media/rpo-tantousha-keireki/) |

確認の要点は、「担当者が人事の経験者か」です。人事の採用では、担当者が人事の実務を知っていると、経歴の読み方、求人票の質、候補者との会話の全部が変わります。

## 代行に出したあとに起きること

| 起きること | 戻し方 |
|---|---|
| 役割の違う人事経験者が応募してくる | 求人票の一行目で役割を示す。検索の条件を役割で分ける |
| 面接で「経営者は人事の判断をどこまで委ねるか」と聞かれ、答えが曖昧 | 委ねる範囲を決め、求人票とスカウトに書く |
| 経営者が面接で判断の質を評価できず、「感じが良い」で決める | 外部の人事の分かる人を面接に。自社の困りごとを題材に進め方を聞く |
| 入社後、経営者が採用も労務も全部決めて、人事が離れる | 委ねる範囲を採用の前に決め、守る |
| 代行が判断の質を評価し始める | 「評価は社内と人事の分かる人で」と戻す |

戻し方の要点は、「経営者が委ねる範囲を、求人票の段階で正直に書く」ことです。「人事を任せる」と書いて実際は経営者が全部決める、が人事の離職を最も生みます。

### エラベルの見解

担当する側から見ると、人事の採用で最も難しいのは、依頼側の経営者が「人事に何を委ねるか」を決めることです。経営者は「人事を任せたい」と言いますが、採用の合否を自分が決め続けるのか、労務の判断を任せるのかは、決めてみないと分かりません。ここが曖昧なまま募集すると、人事の経験者が来て、入社後に「経営者が全部決める」と分かって離れます。

エラベルでは、人事の案件をお受けするとき、依頼側の経営者に「最初の一人の役割」と「委ねる範囲」を直接伺っています。決まっていれば、担当者は最初の週から役割に合う経歴を探し、人事のいない社内の代わりに採用の工程を回せます。決まっていなければ、担当者の最初の仕事は、この二つを整理する打ち合わせの進行になります。人事の採用は、代行に出す価値が最も大きい職種の一つですが、役割と委ねる範囲だけは、経営者が決めるものです。

## まとめ

- 人事採用で代行に出せるのは**探す・届ける・一次対応する・進捗を回す**。社内に回す人がいないぶん価値が大きい。**役割の決定・経営が委ねる範囲・判断の質の評価**は社内に残す
- 他の職種と違うのは**採用を回す人がいない・評価する人がいない・「人事」の中身が広い・委ねる範囲で求める人が変わる・候補者が採用の進め方を人事の水準として見る**
- 代行に出す前に**最初の一人の役割・委ねる範囲・社労士との分担・評価する人・人事がいない間の進め方・自社の人事の状態の整理**を確認
- 人事がいない会社で評価するには**外部の人事の分かる人を面接に・自社の困りごとを題材に進め方を聞く・代行に経歴の分類を任せて経営者は判断の質に集中**
- 代行を選ぶときは**担当者が人事の経験者か**を見る
- **経営者が委ねる範囲を求人票の段階で正直に書く**

## よくある質問

### 人事がいないので、採用の全部を代行に任せたいのですが

採用を回す工程（探す、届ける、一次対応、日程、進捗、内定後の連絡）は、全部任せられます。人事がいない会社では、ここを任せる価値が最も大きい。ただし、「自社の人事に何を任せるか」「経営者が何を委ねるか」「候補者の判断の質をどう見るか」は、代行には決められません。この三つを経営者が決め、面接には経営者と外部の人事の分かる人が出る、という形にすれば、それ以外は全部代行で回せます。「全部」の中身を、回す工程と決める工程に分けて考えてください。

### 「人事全般ができる人」を一人採りたいのですが

採用も労務も制度も育成も、一人で深く回せる人は市場に少なく、いても条件が高く、一人で全部を抱えて疲弊します。自社が最も困っていることを一つに絞り、その役割の人を最初の一人として採り、他の領域は社労士や外部で補うか、二人目で採る形が現実的です。「全般」で募集すると、全部の領域の人が応募し、自社の困りごとと違う領域の人を採ることになります。役割の分け方は[人事担当そのものが採用できない](/media/rpo-jinji-saiyo/)を参照してください。

### 経営者の自分が面接をしても、人事として良いかどうか分かりません

二つの方法があります。一つは、外部の人事の分かる人（顧問、社労士、知人の人事、他社の人事責任者）に面接の同席を頼み、判断の質を聞いてもらうこと。もう一つは、自社の実際の困りごとを題材に、「最初の一か月で何をしますか」と候補者に聞き、進め方の筋道を見ること。進め方の筋道（何から手を付け、誰に何を聞き、何を決めるか）は、人事の経験が無い経営者でも判断できます。「感じが良い」で決めるより、進め方で決めるほうが、入社後のずれが減ります。
