飲食業界の会社が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。応募への返事が店長に残って遅く、先に返事が来た店で決まっている。店長の面接の枠がアイドルの時間帯に決まっておらず、日程が延びる。営業時間と土日と繁忙の実態が求人票に無く、入店後に離れる。離職が採用を上回って、募集が止まらない。調理師と店長候補をホールと同じ型で探して、届かない。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**飲食業界の採用課題は、速さ・枠・実態・離職・型の五つに分解し、自社の記録（応募から返事までの時間、面接の設定までの日数、早期離職の理由、募集の回数、型ごとの応募の数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、媒体を増やして応募を集め、返事の遅さで流し、入店した人が実態で離れる、という結果になります。代行に出す工程の切り分けは[飲食業界の採用代行](/media/rpo-inshokugyo-rpo/)に、職種ごとの母集団形成は[飲食店スタッフの母集団形成](/media/rpo-inshoku-boshuudan/)に書いています。ここでは、飲食業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 速さ | 応募は来るが、面接に来ない。「他で決まった」 | 応募から返事までの時間 |
| 枠 | 面接の日程が応募者の希望と合わず、延びる | 面接の設定までの日数。店長の枠の数 |
| 実態 | 入店後すぐ辞める。「営業時間と土日が聞いていたのと違う」 | 早期離職の理由が「働き方」「シフト」 |
| 離職 | 募集が止まらない | 離職の時期と理由。募集の回数 |
| 型 | 調理師と店長候補が来ない | 型ごとの応募の数と経路 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 応募から返事までの時間 | 当日中でなければ速さ。最初に |
| 二 | 面接の設定までの日数 | 数日を超えるなら枠 |
| 三 | 早期離職の理由 | 「働き方」「シフト」なら実態 |
| 四 | 離職の時期と募集の回数 | 採用を上回っていれば離職 |
| 五 | 型ごとの応募の数と経路 | 調理師と店長候補が少なければ型 |

一と二が最初なのは、費用がかからず、直せば同じ応募の数から入店が増えるからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

飲食業界で最も多い詰まりは「速さ」と「枠」で、しかも両方が店長の営業の構造で起きています。営業中は応募を見られず、閉店後に見て翌日に返し、面接はアイドルの時間帯にしか組めず、応募者の希望と合わずに延びる。その間に応募者は他の店で決まります。「返事と日程は店長の外で当日中に。面接の枠はアイドルの時間帯に週に二つ、先に決めて、その候補を応募者に出す」。応募者の希望を聞いてから調整する形をやめるだけで、面接に来る人が増えます。エラベルで担当者を選ぶ企業には、「応募に当日中に返事が返り、面接の候補を即日で出せていますか」を、私たちから先に聞いています。返っていなければ、媒体を増やす前に返事と枠の設計です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 速さの課題：返事が店長に残っている

| 遅れる場所 | 直し方 |
|---|---|
| 応募への返事 | 店長以外の窓口（本部か外）が当日中に。営業中と閉店後の応募も |
| 面接の候補の提示 | 枠を先に預かり、返事と一緒に候補を出す |
| 面接の結果 | 当日か翌日に。入店の日を面接で決める |

## 枠の課題：アイドルの時間帯に決まっていない

| 状態 | 直し方 |
|---|---|
| 応募者の希望を聞いてから店長に確認 | アイドルの時間帯（昼と夜の営業の間）か営業の前後に、週に二つ先に決める |
| 枠が一つで埋まる | 二つ以上。埋まらなければ解放 |
| 店長が全段に出る | 一次（返事と日程）を外に出し、店長は面接だけ |
| 複数の店舗で店長の枠がばらばら | 店舗ごとに枠を一覧に |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 実態の課題：営業時間と土日が求人票に無い

| 求人票に無いこと | 書き方 |
|---|---|
| 営業時間とシフトの形 | 「〇時から〇時の営業で、シフトは〇時間の単位」の実態 |
| 土日と祝日 | 「土日のどちらかは入る」など、実態 |
| 繁忙の時間帯と時期 | 「〇時台が最も忙しい。〇月は繁忙」の実態 |
| 一緒に働く人と最初の一週間 | 教える人、最初に覚えること（ホールの流れ、キッチンの持ち場） |
| まかないや休憩の実態 | あれば実態のまま |

実態を先に書くと応募は減りますが、減るのは「その実態では働かない人」で、入店後に離れる人です。求人票の型は本部が作り、店舗の実態を店長が埋めます。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

### エラベルの見解

飲食業界で見落とされやすいのは「離職」を採用の課題として扱うことです。「飲食は辞めるもの」で、辞めた分を採り続ける。退職の理由を集めると、「営業時間と土日が聞いていたのと違った」「最初の一週間に誰も教えてくれなかった」「店長との関係」が並び、どれも実態と受け入れと店長の接点の問題で、直せます。店長の負担（返事と日程）を外に出し、受け入れの時間を作ることが、離職を減らす最初の一手です。エラベルで担当者を選ぶ企業には、「直近で辞めた方の理由を、実態・受け入れ・店長との関係・条件のどれかで分けていますか」を、私たちから先に聞いています。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 離職の課題：採用を上回っている

| 離職の理由 | 直す場所 |
|---|---|
| 営業時間と土日が聞いていたのと違う | 求人票の型に実態を |
| 最初の一週間に誰も教えてくれなかった | 受け入れの一枚（教える人、最初の一週間の到達点） |
| 店長との関係 | 店長の接点の型。店長の負担を減らす |
| 条件 | 会社の判断 |
| 私的な事情 | 直す場所は無い。上の四つを確かめた後 |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 型の課題：調理師と店長候補をホールの型で

| 職種の型 | 合う経路 | 要件の言葉 |
|---|---|---|
| ホール・キッチンのパート・アルバイト | 地域の経路、店頭、知人 | 「シフトに入れる曜日と時間帯」 |
| 調理師 | 紹介、掲載型、知人 | 「〇〇の型の店で、〇〇の規模の仕込みと営業を担った経験」。技能は実技で |
| 店長候補 | 掲載型、スカウト、登用 | 「〇〇の型の店で、〇〇の規模のチームと売上を担った経験」 |
| 本部 | スカウト、紹介 | 部門の責任者の要件 |

型ごとに経路と要件を分け、型ごとに応募の数を記録します。調理師の要件の作り方は[調理師の採用要件の作り方](/media/rpo-chourishi-youken/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 速さ | 応募への返事、候補の提示 | 面接の結果を当日に |
| 枠 | 日程の運用 | 枠をアイドルの時間帯に週に二つ出す |
| 実態 | 求人票の型に落とす作業 | 実態を店長が埋める |
| 離職 | 退職の記録の型、分類 | 受け入れの一枚、店長の接点 |
| 型 | 型ごとの経路の運用、一次対応 | 調理師の技能の見極め、店長候補の登用の道筋 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[飲食業界で採用代行が機能する条件・機能しない条件](/media/rpo-inshokugyo-jirei/)に書いています。

## まとめ

- 「採れない」には**速さ・枠・実態・離職・型**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は応募から返事までの時間と、面接の設定までの日数
- 最も多い詰まりは**速さと枠**で、店長の営業の構造で起きている。返事は店長の外で当日中に、枠はアイドルの時間帯に週に二つ先に
- 実態（営業時間・土日・繁忙・一緒に働く人）を**求人票の型に店長が埋める**
- 「飲食は辞めるもの」をやめ、**離職の理由を分けて受け入れと実態を直す**
- 調理師と店長候補は**ホールの型と分けて**

## よくある質問

### アイドルの時間帯は仕込みで、面接の枠を取れません

仕込みの中の三十分を、週に二回だけ先に決めます。「応募者の希望に合わせて都度」より、「決まった二枠を応募者に提示」のほうが、店長の仕込みの予定も乱れません。枠が埋まらない週は前日に解放し、仕込みに戻します。それでも取れないなら、営業の前（開店の一時間前）か営業の後（閉店の後）の三十分にします。枠が無いと、代行が集めても面接に来ません。

### 応募者が面接に来ない（無断で来ない）ことが多いです

来ないのは、返事が遅くて他で決まったか、面接の日が遠かったか、当日の連絡が無かったかのどれかが多い。当日中に返し、面接を数日以内に置き、前日にリマインドを送るだけで、来る割合が変わります。それでも来ない人は、複数に応募して先に決まった人で、速さで負けた結果です。来なかった数を記録し、返事の時間と面接までの日数と並べると、どこで負けているかが分かります。

### 店長が「自分で採用したい。外に出したくない」と言います

決めるのは店長のままで、外に出すのは「返事と日程」だけです。「応募者は先に返事が来た店に行く。営業中に返事はできない。返事と日程は外で当日中に、面接と受け入れは店長で」と、分担で話します。一店舗で「返事を分けたら面接に来る人が増えた」記録が出れば、店長は納得します。全店舗を一度に変えず、応募が多く返事が遅れている店舗から始めます。
