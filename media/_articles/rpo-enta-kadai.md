エンタメ業界の会社（映像、音楽、アニメ、ライブとイベント、芸能プロダクション、配信）が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。憧れで応募は多いのに、制作の山の稼働と収入の型でずれて、数か月で離れる。実績が作品に紐づいて担当の範囲が読めず、評価がプロデューサーごとの「センス」で、通過が少ない。プロデューサーと監督が現場で不在で、面接の枠が取れず、日程が延びる。社員と業務委託と作品ごとの契約で経路と文面が違うのに、一つの求人票で募集している。作品の企画が通ってから人を集めて、開始に間に合わない。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**エンタメ業界の採用課題は、実態・評価・枠・契約と経路・時期の五つに分解し、自社の記録（離職の時期と理由、面接官ごとの通過と不通過の理由、段ごとの日数、契約の形と経路ごとの応募と通過、企画から参加までの日数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、応募の山から採り、離れて、また応募の山から採る、という往復になります。エンタメ業界では応募が多いので、往復が見えにくい。代行に出す工程の切り分けは[エンタメ業界の採用代行](/media/rpo-enta-rpo/)に書いています。ここでは、エンタメ業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 実態 | 応募は多い。採ると制作の山で離れる。「思っていたのと違う」 | 離職の時期と理由が「稼働」「収入」「下積み」「関われる範囲」 |
| 評価 | 応募は来るが通過が少ない。プロデューサーによって通る人が違う | 面接官ごとの通過の差。不通過の理由が「センス」「弱い」の印象 |
| 枠 | 最終の前に「他で決まった」。現場と撮影で面接が入らない | 段ごとの日数。枠が取れるまでの日数 |
| 契約と経路 | 社員は来るが業務委託が来ない（またはその逆）。文面が合わない | 契約の形と経路ごとの応募と通過 |
| 時期 | 企画が通ってから集め、開始に間に合わない。終わると余る | 企画から参加までの日数。通年の母集団の有無 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 離職の時期と理由 | 「稼働」「収入」「下積み」「範囲」なら実態。応募の数に惑わされない |
| 二 | 面接官ごとの通過の差、不通過の理由 | 差が大きく理由が印象なら評価 |
| 三 | 段ごとの日数、辞退の理由 | 「他で決まった」「遅い」なら枠 |
| 四 | 契約の形と経路ごとの応募と通過 | 偏りがあれば契約と経路 |
| 五 | 企画から参加までの日数 | 開始に間に合っていなければ時期 |

一が最初なのは、エンタメ業界では応募が多く、「母集団は足りている」と見えて、実態のずれで離れていることが隠れるからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

エンタメ業界で最も多い詰まりは「実態」で、しかも「応募が多いから採用は問題ない」で見えなくなっていることです。憧れで応募は集まり、採り、制作の山の稼働と収入の型と下積みの期間で離れ、また応募の山から採る。往復の速さは、応募の多さで隠れます。退職面談で理由を集めると、「稼働が思っていたより激しい」「収入の型を聞いていなかった」「作品に関われる範囲が末端だった」が並び、どれも入社前に伝えられたことです。「制作の山の稼働」「収入の型」「最初の一年で関われる範囲」を求人票の先頭に書くと、応募は減り、面接に進む人の定着が上がります。エラベルで担当者を選ぶ企業には、「離れた人の理由は、入社前に伝えていたことですか」を、私たちから先に聞いています。答えが「伝えていなかった」なら、代行の前に実態の書き出しです。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 実態の課題：憧れで集まり、実態で離れる

| 求人票に無いこと | 書き方 |
|---|---|
| 制作の山の稼働 | 「制作の山はこう詰まり、終われば谷がある」の実態 |
| 収入の型 | 「固定か、作品ごとか、最初の一年の型」の実態 |
| 下積みの期間と関われる範囲 | 「最初の一年で担う工程と、判断を任される時期の目安」の実態 |
| 作品に名前が載るまで | 「載る条件と、道のり」の実態 |
| 最初の作品と教える人 | 「最初の作品、教える人、制作の山の設計」の実態 |
| 離職の状況 | 「昨年は何名が離れ、理由はこうだった」を面接で語れるか |

実態を書いて応募が減るのは、絞り込みが効いている印です。応募の数ではなく、面接に進んだ人数と定着で見ます。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 評価の課題：実績が作品に紐づき、センスで決まる

| 状態 | 直し方 |
|---|---|
| 「〇〇の作品に参加」で担当の範囲が読めない | 「作品・工程・役割・判断の範囲」で照合の基準を決める |
| 評価が「センス」「感覚」の印象 | 観点（課題の設定、表現の幅、担当の範囲、作品への貢献の説明）と基準を決め、記録 |
| プロデューサーごとに通過が違う | 観点ごとの記録で差を見せ、基準を揃える |
| 課題の講評が印象 | 課題の観点と基準を決め、講評を記録に残す |
| 「良い人がいない」で経路を増やす | 不通過の理由を観点ごとに集計してから経路を判断 |

評価は社内で直す部分で、代行は記録の型を担えます。観点の揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

## 枠の課題：プロデューサーと監督が現場で不在

| 状態 | 直し方 |
|---|---|
| 候補者が出てから責任者の空きを探す | 枠を週に一つ（現場の無い日、朝一番、オンライン）先に預かり、即日で確定 |
| 課題の講評と面接が別の日 | 同じ日に組む |
| 責任者が全段に出る | 最終だけに絞り、一次は制作の責任者が観点で見る |
| 撮影と公演の期間は選考が止まる | 期間を先に共有し、代行が候補者に伝えて待ちを設計する |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

### エラベルの見解

エンタメ業界で見落とされやすいのは「契約の形」で経路と文面が違うことです。社員として長く関わりたい人と、作品ごとに関わりたい人では、動く理由も来る経路も違います。社員は方針と育成と安定で動き、掲載型と学校と紹介で来ます。業務委託と作品ごとの契約は、作品の内容と条件と期間で動き、同業の知人と個人の経路と過去に関わった人で来ます。全部を「制作スタッフ募集」の一本で出すと、どちらにも刺さらず、契約の形が曖昧なまま面接に進んで、条件の段で辞退されます。契約の形ごとに求人票と経路を分け、形ごとに応募と通過を記録する。契約の形の決定と線引きは、法令上の整理があると一般に整理されているため、会社と専門家で整理し、個別の判断は専門家にご確認ください。エラベルで担当者を選ぶ企業には、「社員と業務委託で、求人票と経路を分けていますか」を、私たちから先に聞いています。分けていなければ、経路を増やす前に分け方です。

## 契約と経路の課題：社員・業務委託・作品ごとで違う

| 契約の形 | 動く理由 | 合う経路 | 文面の先頭 |
|---|---|---|---|
| 社員 | 方針、育成、安定、長く関わる | 掲載型、学校、紹介 | 育成と最初の一年の範囲 |
| 業務委託 | 作品の内容、条件、期間、他の仕事との両立 | 同業の知人、個人の経路、過去に関わった人 | 作品と期間と条件 |
| 作品ごとの契約 | 作品の内容、関わる工程、次につながるか | 過去に関わった人、同業の知人、制作会社 | 作品と工程と期間 |

契約の形ごとに求人票と経路を分け、形ごとに応募と通過を記録します。線引きは会社と専門家で整理します。指揮命令の線引きは[採用代行と人材派遣の違い](/media/rpo-haken-tono-chigai/)に書いています。

## 時期の課題：企画が通ってから集める

| 状態 | 直し方 |
|---|---|
| 企画が通ってから募集を始める | 企画の見込みから逆算し、通年で母集団を持つ |
| 通年の母集団が無い | 過去に関わった人と要件に合う候補者の記録を持ち、定期に連絡する |
| 作品が終わると余る | 作品をまたいで乗せられる要件の設計。人数の計画と企画の見込みを同じ表に |

人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に、過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 実態 | 求人票に落とす作業、退職面談の型と記録 | 実態を語る。制作の山の設計を決める |
| 評価 | 観点ごとの記録の型、「作品・工程・役割」の照合 | 照合の基準と観点の決定、責任者の間の揃え方 |
| 枠 | 日程の運用、段ごとの記録、撮影の期間の待ちの設計 | 枠の形を変えて出す |
| 契約と経路 | 形ごとの求人票の作り直しと経路の運用 | 契約の形の決定と線引き（会社と専門家） |
| 時期 | 通年の母集団の運用、定期の連絡、記録 | 企画の見込みの共有、人数の計画 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[エンタメ業界で採用代行が機能する条件・機能しない条件](/media/rpo-enta-jirei/)に書いています。

## まとめ

- 「採れない」には**実態・評価・枠・契約と経路・時期**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は離職の時期と理由。応募の数に惑わされない
- 最も多い詰まりは**実態**で、「応募が多いから問題ない」で隠れている。実態を先頭に書いて絞る
- **評価**は「作品・工程・役割」の照合の基準と、センスの観点を言葉にして記録する
- **枠**は現場の無い日・朝一番・オンラインで週に一つ先に預かる
- **契約の形ごとに求人票と経路を分ける**。線引きは会社と専門家。個別の判断は専門家にご確認ください
- 時期は**企画の見込みから逆算し、通年で母集団を持つ**

## よくある質問

### 実態を書くと憧れが冷めて、応募が来なくなりませんか

憧れだけの応募は減り、実態を知ったうえで来る応募は残ります。憧れだけで採ると、制作の山で離れ、また採る往復になり、現場の負担はむしろ増えます。応募の数ではなく、面接に進んだ人数と一年後の定着で比べると、実態を書いたほうが多い。実態を書いて誰も来ないなら、それは実態を変える判断（制作の山の分担、収入の型）の材料で、会社が決めます。

### 作品ごとの契約で人を集めるので、採用という感覚がありません

作品ごとの契約でも、「誰に、いつ、どう声をかけ、条件をどう伝え、記録をどう残すか」は採用の工程と同じです。過去に関わった人の記録が個人の頭の中にあり、企画が通ってから慌てて声をかけ、条件の伝え方が人によって違う、という状態なら、五つの課題のうち時期と契約と経路が詰まっています。記録と定期の連絡と条件の型を整えると、次の作品で集める速さが変わります。契約の形の線引きは会社と専門家で整理します。

### アニメの制作進行で、採っても続きません

制作進行は、工程の調整と締め切りと関係者の間に立つ役割で、「作品を作りたい」憧れで入ると実態とずれやすい職種です。求人票に「一日の流れ」「関係者の数」「締め切りの前の詰まり方」「進行から先の道のり」を書き、面接で語る。受け入れでは、最初の作品で教える人と、制作の山の前に一度は経験させる設計を決める。実態を先に出して合う人に絞ることと、受け入れの設計の二つで、続く人が増えます。
