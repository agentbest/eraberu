銀行や証券、保険やカード会社の人事として、新卒の大量の選考を回し、専門性の高い中途を採り、規程と手順と記録の中で人事を動かし、コンプライアンスの線を守ってきた。この経験は、人事の部門が小さい会社が多い副業で売れるのか。金融機関の人事は手順が重く、大きい会社の看板があったから成り立っていたと感じる人が多いところです。結論を先に書くと、**金融機関の人事の経験は、「規程と手順と記録を前提に、大量の新卒と、専門性の高い中途を、抜けなく公平に採ってきた」型で売れます。売れるのは、「手順と記録で回す採用の設計」「新卒の大量選考を回す仕組み」「専門職の中途の要件と評価の型」「コンプライアンスと採用の線の整理」の四つです。人事の部門が小さい会社では、採用の手順がなく、面接の記録が残らず、決めた理由を説明できず、採用に関わる法令や情報の扱いが曖昧なまま動いています。「銀行・保険の人事でした」ではなく、「抜けなく、公平に、説明できる採用の手順を作る」と売ります。**教育機関の人事の経験は[教育機関の人事が副業でできること](/media/fukugyo-kyouiku-jinji-fukugyo/)に、人事企画の経験は[人事企画が副業でできること](/media/fukugyo-jinji-kikaku-fukugyo/)に、新卒採用の経験は[新卒採用担当が副業でできること](/media/fukugyo-shinsotsu-tantou-fukugyo/)にまとめています。なお、法令に関わる個別の判断は、社会保険労務士・弁護士にご確認ください。

## この経歴の何が売れるか

金融機関の人事の経験を、人事の部門が小さい会社の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| 金融機関の人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 規程と手順に沿って、記録を残しながら採用を回してきた | 応募から内定までの手順を決め、面接の記録を残し、決めた理由を後から説明できる形にする | 手順がなく、記録が残らず、決めた理由を説明できない依頼側が多い |
| 新卒の大量の応募を、選考の段階ごとに回してきた | 応募が多いときに、段階ごとの基準と人数と日程を設計し、漏れなく回す仕組み | 応募が多いと処理が追いつかず、連絡が漏れる依頼側が多い |
| 専門性の高い中途（審査、運用、システム、法務）を採ってきた | 専門職の要件を「できること」と「証拠」で書き、専門性を評価する面接の型 | 専門職の要件が曖昧で、面接官が評価できない依頼側が多い |
| 採用に関わる法令と、情報の扱いの線を守ってきた | 応募者の個人情報の扱い、面接で聞いてはいけないこと、内定と契約の書面の整合を、採用の流れに組み込む | 採用に関わる法令と情報の扱いが曖昧な依頼側が多い |
| 複数の面接官と複数の段階で、基準を揃えてきた | 面接官の目線を、基準と記録と振り返りで揃える仕組み | 面接官の判断がばらつく依頼側が多い |
| 内定から入社までの手続きを、抜けなく回してきた | 内定の後の書類と連絡と条件の整合を、期日で管理する流れ | 内定の後の対応が遅れて辞退される依頼側が多い |
| 監査や検査に耐える記録の残し方をしてきた | 採用の記録を、後から第三者が見ても分かる形で残す | 記録が担当者の頭の中にしかない依頼側が多い |

売れるものの要点は、「抜けなく、公平に、説明できる採用の手順を作れる」ことです。人事の部門が小さい会社の採用は、担当者の記憶と経営者の直感で動いており、手順も記録もありません。それで回っているうちはよいのですが、応募が増えたとき、面接官が増えたとき、採用の判断でもめたとき、法令や情報の扱いで問題が起きたときに、一気に止まります。金融機関の人事は、そうならない手順を日常として回してきており、その型を小さい会社に合わせて軽くして持ち込めます。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に書いています。

## 売りにくい点とその扱い

金融機関の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 重い手順に見える | 「金融の手順をそのまま持ち込まれたら、うちの採用が止まる」。自分にとっても、手順を軽くした経験がない不安 | 手順を「基準・記録・説明」の三つに絞り、小さい会社の速さに合わせて軽くした形を先に見せる。「金融で十段階だった手順を、御社では三段階にするとこうなる」と示す |
| 自社の看板の大きさ | 「金融の名前があったから応募が来ていたのでは」。自分にとっても、知らない会社の名前で人を集める技術がない不安 | 母集団を集める工程（媒体、スカウト、読ませる文面）は経験が薄いことを認め、範囲に入れないか、別の担当者と組む。売るのは「集まった後の手順」だと最初に分ける |
| 小さい会社の速さとの差 | 「週単位で決める採用に、月単位の感覚は合わない」 | 手順の中身は変えず、期間だけを圧縮する。即決が要る場面でも、記録と基準を残す最低限の形を用意する |

扱い方の要点は、「手順を軽くした形を先に見せ、集める工程は範囲に入れない」ことです。金融機関の人事の経験がある人は、重い手順をそのまま語り、依頼側の経営者は「うちには無理」と感じます。「基準を先に決める、記録を一行残す、決めた理由を一言で説明できるようにする」の三つに絞り、小さい会社の速さで回る形を見せれば、同じ経験が「うちに足りないもの」として伝わります。母集団を集める工程は、金融の看板があったから成り立っていた部分が大きいので、正直に範囲から外します。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、金融機関の人事から転身して続いている人と、面談で止まる人の差は、手順を「金融の形」で語るか、「軽くした形」で語るかです。止まる人は、金融の選考の段階と規程の話をそのまま語り、依頼側の経営者は「うちはそんなに待てないし、そこまで要らない」と感じて終わります。続いている人は、「御社の面接の記録は、どこに残っていますか」と聞き、依頼側が「担当者の頭の中と、メールに少し」と答えたところで、「一行の記録と、三つの基準だけで、決めた理由が後から説明できる形にします」と、軽い形を見せます。経営者は、自分の会社の採用が「説明できない状態」にあることに気づき、そこから頼みます。

見ていて差がつくのは、採用に関わる法令と情報の扱いの線を、「判断」ではなく「見つけて専門家につなぐ」役割として持ち込んでいるかです。金融機関の人事の経験がある人は、コンプライアンスの線を知っているので、依頼側から判断を求められ、つい答えてしまいます。副業の担当者はその判断の責任を負えません。「面接で聞いてはいけないことの一覧」「応募者の情報の扱いの手順」「内定と契約の書面の整合の確認項目」を採用の流れに組み込み、判断が要る点は「ここは社労士か弁護士に確認しましょう」と線を引いた人は、依頼側から「初めて採用の法令の不安が消えた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「抜けなく、公平に、説明できる採用の手順を作る」と手順の言葉で書いている担当者に、手順がなくて困っている依頼側がついています。金融機関の人事の転身は、手順の重さではなく、軽くした手順と、判断せずにつなぐ線から始まります。

## 案件の探し方

金融機関の人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 金融・保険・不動産・士業など、手順と記録が求められる業界の依頼側の採用 | 業界の言葉と法令の意味が分かり、説明の手間がない | 同じ業界か、手順が求められる業界の依頼側を探す |
| 採用の手順と記録の型づくり | 手順と記録で回してきた経験でそのまま入れる | 「決めた理由を説明できない依頼側」を探す |
| 応募が多いときの段階ごとの選考の設計 | 新卒の大量選考の経験で入れる | 「応募が多くて処理が追いつかない依頼側」を探す |
| 専門職の中途の要件と評価の型 | 専門性の高い中途を採ってきた経験で入れる | 「専門職の要件が曖昧な依頼側」を探す |
| 採用に関わる法令と情報の扱いの流れへの組み込み | コンプライアンスの線を守ってきた経験で入れる | 「採用の法令が不安な依頼側」を探す |
| 内定から入社までの手続きの流れ | 抜けなく回してきた経験で入れる | 「内定の後の対応が遅れる依頼側」を探す |

探し方の要点は、「手順と記録が求められる会社」から入ることです。速さだけが求められる採用では、金融機関の型は重すぎます。手順と記録が求められる業界（金融、保険、不動産、士業、医療）、応募が多くて処理が追いつかない会社、面接官が増えて判断がばらつく会社、採用の法令や情報の扱いに不安がある会社では、金融機関の型が唯一の打ち手になります。案件の相談で「後から説明できない」「法令が不安」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。金融機関の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 手順と記録の型の成果物 | 手順の一覧、面接の記録の型、基準の一枚、法令と情報の扱いの手順は、成果物として形が明確 | 一式の成果物で受ける |
| 段階ごとの選考の設計 | 応募が多いときの設計は、成果物で受けやすい | 一式の成果物で受ける |
| 手順の運用 | 作った手順を採用のたびに回す運用は、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 重い手順に見えること | 「重い」と思われると、単価より前に頼まれない | 軽くした形を先に見せる |
| 集める工程を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 法令の判断を含まないこと | 判断を含まない範囲は責任が明確で、専門家への橋渡しは依頼側にとって価値がある | 「判断が要る点を見つけて専門家につなぐ」を範囲に明記する |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「手順と記録と基準の型は成果物で、運用は月額で受け、法令の判断を含まない」ことです。金融機関の人事の経験で受ける工程は、手順と記録と基準という成果物が明確で、成果物で受けると単価の根拠が伝わります。作った手順を回す運用は月額で受け、更新の根拠にします。法令に関わる部分は、判断せずに見つけてつなぐ役割として範囲に明記し、責任の線を引きます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

金融機関の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、社員と応募者の情報の守秘の条件を確認する | 金融機関は兼業の規程が厳しいことが多い。個別の判断は専門家に |
| 二、法令の判断を副業でしないと決め、「一般にこう整理されている」「ここは専門家に」の線を自分の言葉で書く | 責任の線 |
| 三、金融の採用の手順を、「基準・記録・説明」の三つに絞って、会社の情報を含まない型として書き出す | 手順の中身 |
| 四、その手順を、小さい会社の速さに合わせて軽くした形を作る | 「十段階を三段階に」の形 |
| 五、得意な工程（手順・記録・段階の設計・専門職の評価・法令と情報の線・内定の後）と、薄い工程（媒体・スカウト・読ませる文面）を分ける | 正直に示す準備 |
| 六、範囲を、手順と記録の型、段階の設計、専門職の要件、法令と情報の流れ、内定の後に絞る | 集める工程は最初は範囲外 |
| 七、「抜けなく、公平に、説明できる採用の手順を作る」の一言を作る | 「銀行・保険の人事でした」で終わらせない |
| 八、登録先に、範囲と、軽くした手順と、法令の判断を含まないことを登録する | 手順がなくて困っている依頼側 |
| 九、手順と記録の型づくりを一件受け、「決めた理由を説明できた採用」を残す | 次の工程に広げる材料に |

順番の要点は、「二」の線と「四」の軽くする作業です。金融機関の人事の経験がある人は、法令の知識を持っているので判断を求められ、つい答えてしまいますが、副業ではその責任を負えません。判断せずに見つけてつなぐ役割と決め、言葉を用意しておきます。手順は、金融の形のまま持ち込むと重すぎるので、小さい会社の速さで回る形に軽くしてから見せます。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「金融機関の人事は、大きい会社の看板と手順があったから成り立っていたので、小さい会社では通じない」というものです。実際には、小さい会社の採用は手順も記録もないまま動いており、応募が増えたとき、面接官が増えたとき、判断でもめたとき、法令や情報の扱いで問題が起きたときに止まります。金融機関の人事が日常として回してきた「抜けなく、公平に、説明できる手順」は、その会社にとって、持っていない打ち手です。通じないのは、金融の形のまま持ち込む場合で、軽くした形で見せれば、規模は関係ありません。看板があったから成り立っていたのは、集める工程だけです。

順番として、本業の規定と守秘の条件を専門家に確認し、法令の判断をしない線を自分の言葉で書き、手順を基準・記録・説明に絞って書き出し、小さい会社の速さに合わせて軽くし、得意な工程と薄い工程を分け、範囲を手順と記録と段階と専門職と法令の流れに絞り、説明できる手順を作る一言を作り、登録先に範囲と軽くした手順と線を登録し、一件受けて説明できた採用を残す。この順番で、金融機関の人事の経験は「大きい会社でしか通じないもの」から「小さい会社の採用を説明できる形にする型」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、手順の工程を明確にし、集める工程と法令の判断を含まないことを示している担当者に、手順がなくて困っている依頼側がついています。金融機関の人事の転身は、手順の重さではなく、軽くした手順と、判断せずにつなぐ線から始まります。

## まとめ

- 金融機関の人事の経験は**「規程と手順と記録を前提に、大量の新卒と、専門性の高い中途を、抜けなく公平に採ってきた」型**で売れる。**手順と記録の設計・新卒の大量選考・専門職の中途・コンプライアンスの線**の四つ
- **「銀行・保険の人事でした」ではなく「抜けなく、公平に、説明できる採用の手順を作る」**と売る
- 売りにくい点は**重い手順に見える・自社の看板の大きさ・小さい会社の速さとの差**。手順を「基準・記録・説明」に絞って軽くし、集める工程は範囲外と示し、期間だけを圧縮する
- 案件は**手順と記録が求められる会社**から。「後から説明できない」「法令が不安」が入り口
- 単価は**手順と記録の型は成果物、運用は月額**で。法令の判断を含まない。成果報酬は最初は避け、可否は専門家に確認
- 法令に関わる個別の判断は、**社会保険労務士・弁護士にご確認ください**

## よくある質問

### 依頼側から「面接でこの質問をしてよいか」と聞かれました。答えてよいですか

一般的な整理として知っていることは、「一般にはこう整理されています」と前置きして伝えて構いません。ただ、依頼側の業種や職種に照らした個別の判断は、副業の担当者が責任を負えないので、「御社の場合は社労士か弁護士に確認しましょう」と、判断が要る点を見つけて専門家につなぐ役割に徹します。面接で聞いてはいけないことの一覧を、採用の流れに組み込んでおけば、質問のたびに判断を求められることは減ります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に整理しています。

### 金融機関に勤めながら副業をしてよいのでしょうか

金融機関は兼業の規程が厳しいことが多く、届出や許可が要ること、業種によっては認められないことがあります。本業の会社の規程と、社員と応募者の情報の守秘の条件を先に確認します。同じ業界の依頼側の案件は、利益相反と情報の線に関わるので、避ける判断になることもあります。個別の判断は、所属する会社の規程を確認したうえで、社会保険労務士や弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

### 媒体やスカウトで人を集めた経験がありません。案件が取れないのではないですか

集める工程の経験が薄いことは隠さず、「媒体とスカウトは御社の担当者か別の担当者が、私は集まった後の手順と記録と基準と、内定の後の流れを担います」と分担を示します。集める工程が得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。手順と記録がなくて困っている依頼側には、集める技術より「説明できる手順」が求められており、そこでは集める工程の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
