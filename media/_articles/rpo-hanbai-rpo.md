販売スタッフの採用を代行に出すか迷う会社は、「店舗ごとに求人を出しているが応募が来ず、店長が面接に追われている」「求人票を作って媒体に出す工程はお願いしたいが、店の実態を知らない人に販売の採用が回せるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、業態と商材と店舗と雇用の形の整理・シフトと土日祝の方針・ノルマと評価の方針の開示範囲・異動の方針・要件の決定・接客の姿勢の評価・合否の判断は社内に残す**のが線です。販売スタッフは、業態と商材と立地で母集団が違い、雇用の形と時間帯で届く層が変わり、候補者が「シフトと土日祝」「ノルマと評価」「店長の人柄」を最初に確かめます。店舗ごとの実態を候補者に伝わる形で書き、店長の面接の負担を減らすことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じく時間帯ごとに層が変わる倉庫の線は[倉庫・物流スタッフ採用を代行に出す判断基準](/media/rpo-soko-rpo/)にまとめています。

## 販売スタッフ採用が他の職種と違う点

一つ目は、業態と商材と店舗の立地で求める人と母集団が違うことです。業態は、アパレル、雑貨、家電、食品、ドラッグストア、携帯や通信、化粧品。商材によって、接客の深さ（提案型か、レジと品出し中心か）と、商品知識の要る度合いが違います。立地は、路面店、商業施設のテナント、駅ナカ、郊外の大型店。商業施設なら営業時間と休館日に縛られ、駅ナカなら早番と遅番の幅が広い。「販売スタッフ募集」だけでは、どの業態のどの立地でどう働くかが候補者に伝わりません。

二つ目は、雇用の形と時間帯で届く層が変わることです。正社員かパートかアルバイトか。早番、遅番、土日祝、平日の昼。午前の主婦層、夕方と土日の学生、フルタイムのフリーターや異業種からの転向、日中のシニア。一つの求人票で全部を集めようとすると、どの層にも届きません。

三つ目は、候補者が「シフトと土日祝の勤務」「店舗の場所と異動」「ノルマと個人目標の有無と評価」「店長の人柄」「閉店時間と遅番」「立ち仕事とレジと品出しの割合」「店長への道筋」を最初に確かめることです。販売は、シフトが生活を決め、土日祝に出られるかが家族との時間を決め、ノルマの有無と評価が働き方を決め、店長の人柄が続けられるかを決めます。「販売業務全般」「ノルマなし」では、この判断ができません。

四つ目は、母集団の中心が主婦層と学生とフリーターと異業種からの転向にあり、店舗の近くに住む人が動くことです。販売は、店舗に通う仕事で、店舗の周辺の求人を見ている人に届けます。異業種からの転向（飲食、事務、コールセンター）は、接客の経験が活きる層です。

五つ目は、店長は店を回していて、採用の工程を回す人がいないことです。店長は売り場と接客とシフトと在庫を回していて、面接の時間を取るのも、応募者に当日返信するのも難しい。本部の人事が回そうとしても、店舗ごとの実態を知らず、求人票が全店共通の抽象的なものになります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 業態と商材と店舗と雇用の形の整理 | 残す | どの店舗で、どの商材を、正社員かパートかアルバイトか、どの時間帯で任せるか。社内にしか分からない |
| シフトと土日祝の方針の決定 | 残す | 週何日から、固定か変動か、土日祝の勤務の頻度、希望が通る率。店長と本部が決める |
| ノルマと評価の方針の開示範囲の決定 | 残す | 個人目標の有無、評価の仕方、達成しなかったときの扱いを、どこまで正直に書くか。本部が決める |
| 異動の方針の決定 | 残す | 店舗の異動の有無と範囲と頻度、転居を伴うか。本部が決める |
| 要件の決定 | 残す | 業態と商材と雇用の形から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（店舗ごとの実態と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。店舗ごとに分けて |
| 媒体の選定と運用 | 任せられる | 販売スタッフと店舗周辺の層に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 業態と時間帯と勤務地に合わせた検索と、担当してきた店舗や前職に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、店舗の見学の案内 |
| 店長・エリアマネージャーの面接の日程の確保 | 任せられる | 店の合間（開店前、平日の昼）に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 業態・時間帯・勤務地・雇用の形の分類は任せられる。接客の姿勢の評価は残す |
| 接客の姿勢の評価 | 残す | 店長が面接と店舗での様子で見る |
| 店舗の実態とノルマと評価の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断。時給と手当と社員割引で条件の幅がある |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。初日のシフトと服装を伝える連絡 |

線の要点は、「業態と商材と店舗と雇用の形、シフトと土日祝の方針、ノルマと評価の方針が、募集の前に店舗ごとに決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の生活と性格で続けられるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「全店共通の求人票を出しているが応募が来ず、店長が面接と返信に追われて売り場が回らない」というご相談です。求人票を見ると、「販売スタッフ募集。接客、レジ、品出し。シフト制。ノルマなし。経験者優遇」で、どの店舗かも、商材も、時間帯の選択肢も、土日祝の頻度も、ノルマの実態（個人目標はあるか）も、店長のことも無い。候補者は「どの店でどう働くか分からない」「ノルマなしと書いてあるが個人目標はあるのだろう」と判断し、店舗の周辺で実態の分かる求人にしか動きません。

見ていて差がつくのは、「店舗ごとの実態を一文で言えるか」です。「〇〇駅前の商業施設のアパレルの店舗で、接客と品出しとレジ。パートで週三日から、早番の〇時から〇時か遅番の〇時から〇時、土日祝は月に〇回程度で希望は相談できる。個人目標は無く、店全体の目標を店長と一緒に見る。異動は同じ市内の二店舗の間で、転居は無い。店長は〇〇の経験が長く、『まず商品を好きになってもらうことから』と言っている。社員割引あり」。一文で実態が分かれば、候補者は自分の生活と性格で判断できます。エラベルでは、販売の案件をお受けする前に、依頼側に「店舗ごとの業態と商材と雇用の形」と「シフトと土日祝とノルマと評価の方針」を伺い、店舗ごとに一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：業態と商材と店舗と雇用の形と時間帯。** どの店舗で、どの商材を、正社員かパートかアルバイトか、どの時間帯で。接客の深さ（提案型か、レジと品出し中心か）。店舗の立地と営業時間と休館日。最も足りない時間帯はどこか。

**二つ目：シフトと土日祝の方針。** 週何日から、固定か変動か、シフトの決め方（希望の出し方、決まる時期）、土日祝の勤務の頻度と希望が通る率、繁忙期（セール、年末）の扱い。

**三つ目：ノルマと評価の方針。** 個人目標の有無、店全体の目標の扱い、評価の仕方（売上か、接客の質か、シフトへの協力か）、達成しなかったときの扱い、昇給と店長への道筋。「ノルマなし」と書くなら、個人目標が本当に無いか。

**四つ目：異動と店舗の実態。** 異動の有無と範囲と頻度、転居を伴うか。店舗ごとの実態（客層、忙しい時間帯、立ち仕事の時間、品出しの重さ、閉店後の作業）、店長の人柄と教え方、離職の状況と原因。正直に把握します。

**五つ目：店長やエリアマネージャーが、面接にどのくらい時間を出せるか。** 開店前や平日の昼に、面接の枠と店舗の見学の時間をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 店長の関与のさせ方

販売スタッフの採用では、店長の関与が要ります。面接で接客の姿勢を見る、店舗を見せる、シフトとノルマと評価の実態を正直に話す。しかし店長は売り場を回していて、面接と返信に追われて売り場が回らない、という状態になりがちです。

関与を取り付けるには、「採用の工程のどこを店長から外すか」を具体的に示すことです。「求人票と返信と日程の調整は代行が担い、店長は面接の三十分だけ」。そして、負担を最小にする形で頼みます。面接の枠は代行が開店前や平日の昼に押さえる、経歴は代行が整理して渡す、実態の説明の要点は代行が用意する。店長がやるのは、接客の姿勢を見ることと、店舗を見せて実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で店長が「シフトとノルマと評価の実態」を話すことの価値を、店長自身に理解してもらうことです。販売の候補者は、本部の話より、店長の話を信じ、店長がどういう人かを最も気にしています。店長が「土日祝は月に〇回程度で、希望は相談できる。個人目標は無く、店全体の目標を一緒に見る。まず商品を好きになってもらうことから」と話すと、候補者は「この店長の下なら続けられる」と判断します。

## 代行を選ぶときの確認項目

販売スタッフの採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に小売や店舗の経験があるか。** 販売そのものでなくても、小売の本部や店舗の運営、販売スタッフの採用を回した経験。業態と商材と立地の違い、シフトの組み方、ノルマと評価の実態の見方を知っているか
- **店舗ごとの実態を求人票にどう書くか、案を出せるか。** 全店共通の「販売業務全般」で済まさず、店舗ごとに商材と時間帯と土日祝とノルマと店長を書けるか
- **店舗周辺の層に届く媒体と経路の経験。** 地域の求人、主婦層と学生とフリーターと異業種からの転向に届く経路、時間帯ごとに分けた募集、店舗の掲示や顧客への声かけ。経路ごとの経験
- **店長の負担を減らす設計。** 返信と日程の調整と一次対応を店長から外し、面接だけを残す形にできるか
- **店長の日程を押さえる段取り。** 開店前や平日の昼に面接の枠を確保する方法。店舗の見学を組み込めるか

五つのうち、一つ目と四つ目が大きい。小売を知らない担当者は、全店共通の抽象的な求人票を作り、店長の負担を減らせず、店舗の周辺の層に届きません。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、販売スタッフの採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「『ノルマなし』と書くなら、個人目標の実態を確かめさせてほしい」と言われることです。「ノルマなし」と書いて、面接や入社後に「個人目標はある」と分かれば、辞退と離職を生みます。個人目標があるなら、その実態（数字の目安、達成しなかったときの扱い）を書き、無いなら「店全体の目標」の見方を書きます。

二つ目は、応募者の時間帯の希望と経路が分かれることです。午前の主婦層、夕方と土日の学生、フルタイムのフリーター、異業種からの転向（飲食、事務、コールセンター）、日中のシニア。それぞれ時間帯と土日祝の許容と動く理由が違い、店舗の足りない時間帯と合うかも違います。代行の担当者に分類をしてもらい、時間帯と店舗を組み合わせます。

三つ目は、「店長の人柄」と「離職の状況」で候補者が判断を変えることです。販売の候補者は、店舗の周辺で、その店の評判（店長が厳しい、人がすぐ辞める）を知っています。隠しても伝わっているので、店長が実態を正直に話し、離職が続いているなら原因と対策を話すことで、候補者の判断が変わります。

### エラベルの見解

担当する側から見ると、販売スタッフの採用で最も効くのは、「全店共通の求人票をやめて、店舗ごとにシフトと土日祝とノルマと店長を書く」ことと、「返信と日程の調整を店長から外す」ことです。販売の候補者は、店舗の周辺で、その店の実態で判断します。全店共通の「販売業務全般。シフト制。ノルマなし」は、どの店の候補者にも届きません。そして、店長が返信と日程に追われている店は、応募が来ても返信が遅れて他店に決まります。

エラベルでは、販売の案件で担当者を紹介するとき、最初の一週間で店長と本部から「店舗ごとの業態と商材と雇用の形と時間帯」「シフトと土日祝の方針」「ノルマと評価の実態」「店長の人柄と教え方」を聞き取り、店舗ごとに一文にするところから始めてもらっています。接客の姿勢の評価は店長が面接と店舗で行い、返信と日程の調整と一次対応は担当者が回します。

## まとめ

- 販売スタッフ採用が他と違うのは**業態と商材と立地で母集団が違う・雇用の形と時間帯で届く層が変わる・候補者がシフトと土日祝とノルマと評価と店長と異動を最初に確かめる・母集団の中心が主婦層と学生とフリーターと異業種からの転向で店舗の近くに住む人が動く・店長は店を回していて採用の工程を回す人がいない**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、業態と商材と店舗と雇用の形・シフトと土日祝の方針・ノルマと評価の方針・異動の方針・要件・接客の姿勢の評価・合否は残す**
- 代行に出す前に**店舗ごとの業態と商材と雇用の形と時間帯、シフトと土日祝の方針、ノルマと評価の方針、異動と店舗の実態、店長の面接の時間**を確認する
- 店長の関与は**採用の工程のどこを店長から外すかを示し、負担を面接だけにして、実態を話す価値を理解してもらう**
- 代行を選ぶときは**小売の経験・店舗ごとの書き方・店舗周辺の層に届く経路・店長の負担を減らす設計・日程の段取り**を確認する
- 出したあとは**「ノルマなし」の実態を確かめる必要が表に出る・時間帯の希望と経路が分かれる・店長の人柄と離職の状況で判断が変わる**。判断は店長と本部、材料は代行

## よくある質問

### 「ノルマなし」と書いてよいのですか

個人目標が本当に無く、達成しなかったときの扱いも無いなら、書けます。個人目標があるのに「ノルマなし」と書くと、面接や入社後に分かって辞退と離職を生み、店舗の周辺の評判も下がります。個人目標があるなら、「個人目標はあり、数字の目安は〇〇程度。達成しなかったときに給与が減ることは無く、店長と一緒に振り返る」のように実態を書きます。個人目標が無いなら、「店全体の目標を店長と一緒に見る。個人の数字で評価しない」と書きます。「ノルマなし」の言葉だけより、実態のほうが信じられます。

### 店舗が多く、店舗ごとに求人票を分けると手間が増えませんか

全店共通の求人票は、どの店の候補者にも届かず、応募が来ない状態が続きます。店舗ごとに分けるのは、共通の型（業態と商材、雇用の形、ノルマと評価の方針、異動の方針、社員割引）に、店舗ごとの項目（場所と立地、時間帯の選択肢、土日祝の頻度、店長の言葉、足りない時間帯）を差し込むだけです。この手間は、代行に出せる工程で、店舗ごとの項目は店長から一度聞き取れば済みます。店舗が多いほど、この型の価値は大きくなります。

### 店長が面接に出る時間がありません

店長の時間を面接の三十分だけにする形にします。求人票の作成、返信、日程の調整、一次対応、店舗の見学の案内、内定後の連絡を代行が担い、店長がやるのは「接客の姿勢を見る」「店舗を見せて実態を話す」の二つだけ、開店前か平日の昼の三十分で。それでも出られないなら、エリアマネージャーか経験の長いスタッフが店舗で出て、店長は短時間だけ顔を出します。店長が出ない面接は、候補者に「店長がどういう人か分からない」と読まれ、辞退の原因になります。
