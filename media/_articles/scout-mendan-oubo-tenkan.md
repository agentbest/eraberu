スカウトから面談まで進む。面談は和やかで、候補者も「興味があります」と言う。面談の担当者は「良い人だった」と言う。ところが、その後、応募が来ない。「考えます」で止まる。追いかけても、返事が無い。返信率も面談設定率も悪くないのに、面談の後で落ちる。結論を先に書くと、**面談から応募への転換率は、「面談で口説く」ことでは上がりません。「面談で話すこと」「面談の相手」「面談後の連絡」「応募の入り口の軽さ」「止まった人への材料」の五つを設計し、面談の後に候補者が自分で動ける状態にします。面談の後に候補者が止まるのは、応募する理由が足りないからではなく、応募するために必要な情報と入り口と後押しが無いからです**。面談の設定までは[面談設定率をどう上げるか](/media/scout-mendan-settei-ritsu/)に、面談の後の追客は[追客（フォローアップ）の設計](/media/scout-tsuiokuri/)にまとめています。

## 転換率が上がらない構造

面談の後で候補者が止まるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 面談で話すことが決まっていない | 雑談と経歴の確認で終わり、候補者が「応募するかを判断する材料」を持ち帰れない |
| 面談の相手が判断の材料を出せない | 人事だけで、役割の中身や一緒に働く人のことが話せない |
| 面談後の連絡が無いか、遅い | 「ありがとうございました」で終わり、次に何をすればよいかが無い |
| 応募の入り口が重い | 「履歴書と職務経歴書を送ってください」で止まる。書類を整える時間が要る |
| 「考えます」への材料が無い | 「その後いかがですか」しか送れず、候補者の迷いに答えていない |
| 面談が選考になっている | 「見極め」の空気で、候補者が評価される側になり、応募の意欲が下がる |
| 条件の話が無い | 年収や働き方が話されず、候補者が「聞きにくい」まま止まる |

構造の大半は、「面談の後に候補者が動くために必要なものが渡っていない」ことです。渡せば、動きます。

## 転換率の定義と段階

面談から応募までを、段階に分けます。

| 段階 | 定義 | 落ちる理由 |
|---|---|---|
| 面談の実施 | 面談が行われた | — |
| 面談後の連絡 | 翌営業日に、感謝と次の流れを送った | 送っていない、遅い、次の流れが無い |
| 候補者の反応 | 前向き、質問、「考えます」、辞退 | 材料が足りない、条件が不明、入り口が重い |
| 応募の意思 | 応募する意思を示した | 「考えます」のまま止まる |
| 応募の手続き | 書類の提出など、応募の手続きが完了した | 手続きが重く、途中で止まる |

段階の要点は、「応募の意思」と「応募の手続き」を分けることです。意思はあるのに手続きで止まる候補者は、入り口の設計の問題です。意思が固まらない候補者は、面談で話すことと材料の問題です。分けて見ると、直す箇所が変わります。

## 五つの設計

転換率を上げる、五つの設計です。

| 設計 | 内容 |
|---|---|
| 面談で話すこと | 候補者が応募を判断するための材料を、面談で渡す。役割の中身、一日の流れ、一緒に働く人、条件の幅、選考の流れ。候補者の懸念を聞き、答える |
| 面談の相手 | 役割の責任者か、一緒に働く人。人事だけの面談は、判断の材料が出せない |
| 面談後の連絡 | 翌営業日に、感謝と、面談で話した要点の再掲と、次の流れと、応募の入り口。面談の相手から一言 |
| 応募の入り口の軽さ | 「応募の意思を一言いただければ、書類は媒体の経歴で代えます」など、最初の一歩を軽く。書類は後から |
| 止まった人への材料 | 「考えます」の候補者に、面談で出なかった材料（補足、一緒に働く人との接点、条件の詳細）を添えて一度 |

五つの要点は、「面談で判断の材料を渡し、面談後に入り口を軽くする」ことです。面談で材料が渡っていれば、候補者は面談の後に自分で判断できます。入り口が軽ければ、判断した候補者はすぐ動けます。

## 面談で話すことの型

面談で、候補者に渡す判断の材料の型です。「口説く」のではなく、判断できる情報を渡します。

| 項目 | 内容 | 話す人 |
|---|---|---|
| 役割の中身 | 何をする役割か、最初の三か月に何をするか、一年後に何ができているか | 責任者 |
| 一日の流れ | 実際の一日。会議の量、一人で動く時間、顧客との接点 | 一緒に働く人 |
| 一緒に働く人 | チームの人数、役割の分担、誰と最も関わるか | 責任者か一緒に働く人 |
| 会社の今 | 事業の状態、最近の変化、これから作るもの。良い面だけでなく、課題も | 責任者 |
| 条件の幅 | 年収の幅、働き方（出社とリモート）、勤務地、雇用の形。「面接で」と先送りしない | 人事か責任者 |
| 選考の流れ | 応募の後、何回、誰と、何を、どれくらいの期間で | 人事 |
| 候補者の懸念 | 「気になっていることはありますか」と聞き、答える。答えられないことは「確認して連絡します」 | 全員 |
| 応募の入り口 | 「応募いただく場合は、一言いただければ、こちらで進めます」 | 人事 |

型の要点は、「課題も話す」ことと「条件の幅を出す」ことです。良い面だけの面談は、候補者に「本当のところが分からない」と思わせ、判断を保留させます。条件が出ない面談は、「聞きにくい」まま止まります。面談を選考にしない設計は[カジュアル面談が選考になってしまう](/media/rpo-casual-mendan-kadai/)に書いています。

### エラベルの見解

相談で最も多い失敗は、「面談は人事が担当し、会社の紹介と経歴の確認をして、『ご興味があればご応募ください』で終わっていた。候補者は皆『前向きに考えます』と言ったが、応募は一割も来なかった」というものです。面談で判断の材料が渡っておらず、条件も話されず、入り口は「書類を送ってください」でした。面談の相手を責任者にし、役割の中身と一日の流れと条件の幅を話す型にし、面談後の翌日に責任者から一言と「一言いただければ進めます」の入り口に変えたら、応募が増えました。候補者は口説かれたのではなく、判断できるようになっただけです。

見ていて差がつくのは、面談の相手が「課題を話せるか」です。良い面だけを話す相手と、「正直、ここはまだ整っていません。そこを一緒にやってほしい」と言える相手がいます。後者の面談の後は、候補者が応募します。課題を聞いた候補者は、「本当のことを話してくれた」と受け取り、判断できます。

発注側にできるのは、面談の相手に、「良い面と、課題を一つ、話してください」と頼むことです。

## 面談後の連絡の型

面談の翌営業日に送る連絡の型です。感謝だけで終わらせません。

| 要素 | 内容 |
|---|---|
| 感謝 | 一文 |
| 面談の要点の再掲 | 「本日お話しした役割の〇〇、条件の△△、選考の流れ□□」。候補者が持ち帰った材料を、文字で残す |
| 面談の相手からの一言 | 「〇〇についてのお考えが印象に残りました。一緒に働けたらと思います」。二文。相手の名前で |
| 次の流れ | 「ご応募いただく場合は、このメールに一言ご返信ください。書類は媒体のご経歴で代えられます」 |
| 質問の受け口 | 「ご質問があれば、面談の〇〇にも直接お聞きいただけます」 |
| 期限の目安 | 急かさない。「〇日頃までにご連絡いただけると、選考の日程を組みやすいです」。無くてもよい |
| 断りやすさ | 「今回は見送られる場合も、一言いただければ幸いです。今後もご連絡させてください」 |

型の要点は、「要点の再掲」と「入り口」です。面談で話したことは、候補者の記憶から数日で薄れます。文字で残せば、判断の材料が手元に残ります。入り口が「一言ご返信ください」なら、判断した候補者はその場で動けます。面談後の連絡の速さは[スカウトはスピードでどれだけ変わるか](/media/scout-sokudo/)に書いています。

## 止まった人への材料

「考えます」で止まった候補者に、何を送るかです。「その後いかがですか」は送りません。

| 止まった理由（推定） | 送る材料 |
|---|---|
| 役割の中身がまだ見えない | 役割の詳細の補足。一日の流れの具体。一緒に働く人との短い接点の提案 |
| 条件が気になっている | 条件の詳細。幅の中でどう決まるか。「ご希望を伺えれば、具体的にお答えします」 |
| 会社に不安がある | 会社の今の補足。課題と、それにどう取り組んでいるか。公開の記事や資料 |
| 他社と比べている | 比べる材料を渡す。「他社とご検討中でしたら、比較のためにお答えできることがあればお聞かせください」 |
| 時期が合わない | 時期を聞く。「〇月以降なら」なら、その時期に合わせた流れを提案 |
| 選考が重そう | 選考の流れの詳細と、短縮できる部分。「面談の内容を踏まえ、一次はご省略できます」など |
| 理由が分からない | 「迷っている点があれば、お聞かせください。面談の〇〇も直接お答えします」。一度だけ |

材料の要点は、「面談で出なかったものを送る」ことです。面談で話したことの繰り返しは、材料になりません。面談の記録から、話せなかったこと、候補者が聞かなかったが気にしていそうなことを拾い、それを送ります。一度送って反応が無ければ、一週間後にもう一度。それで終わりです。

## 記録と振り返り

転換率を見るための記録です。

| 項目 | 内容 |
|---|---|
| 面談の相手 | 誰が面談したか。相手ごとに転換率が違うか |
| 面談で話したこと | 型の項目のうち、話せたもの。条件を話したか、課題を話したか |
| 面談後の連絡 | 翌営業日に送ったか。相手の一言があったか |
| 候補者の反応 | 前向き、質問、「考えます」、辞退。「考えます」の理由（推定） |
| 材料の送付 | 何を送ったか、反応 |
| 応募の意思と手続き | 意思の日、手続きの完了の日。意思から手続きまでの日数 |
| 月次 | 面談の相手ごと、話した項目ごとの転換率。「条件を話した面談」と「話さなかった面談」の差 |

記録の要点は、「話した項目と転換率を並べる」ことです。「条件を話した面談」の転換率が高ければ、条件を話すことの効果が自社の記録で分かります。面談の相手ごとの差も、相手の選び方の材料になります。候補者ごとの段階の管理は[候補者CRMの作り方](/media/scout-crm/)に書いています。

## 外注する場合の範囲

面談から応募への転換率の改善を、スカウト代行に出す場合の範囲です。

**出せる工程。** 面談で話すことの型の作成（社内から聞き取って）、面談の相手への型の共有と面談前の準備の資料、面談後の連絡の型の作成と翌営業日の送信、面談の相手からの一言の下書きと依頼、応募の入り口の設計（一言で応募、書類は後から）、止まった人への材料の作成と送付、候補者の質問への一次対応（事実は社内から）、記録と月次の振り返り、面談の相手ごと・項目ごとの転換率の報告。

**社内に残す判断。** 面談の相手の決定（責任者、一緒に働く人）、面談で話す事実の提供（役割の中身、一日の流れ、条件の幅、会社の課題）、条件の幅を面談で出すことの決定、応募の入り口を軽くすることの決定（書類の扱い、選考の省略の可否）、面談の相手からの一言を送ることの協力、面談の実施そのもの。

**外注の効きどころ。** 転換率は、「面談で材料を渡し、翌日に要点と入り口を送り、止まった人に材料を送る」運用で、社内では「面談は和やかに、その後は待つ」になりやすい工程です。担当者が型を作り、面談の相手に準備を渡し、翌日の連絡と材料の送付を型で回し、記録で相手と項目ごとの差を出せば、転換率は面談の設計から動きます。担当者は複数の会社の面談を見ているので、「この項目を話すと動く」「この入り口で手続きが止まらない」を持ち込めます。ただし、面談の実施と、話す事実と、条件と入り口の決定は、社内でしか行えません。

**外注しても動かない場合。** 面談の相手を人事だけにして変えない、条件を面談で出さない、課題を話さない、応募の入り口を「書類を送ってください」から変えない、面談の相手が翌日の一言を送らない。社内の判断で、代行を替えても直りません。

面談から応募への転換率は、面談で判断の材料を渡し、翌日に要点と軽い入り口を送り、止まった人に面談で出なかった材料を送れば、口説かなくても動きます。外注は、型の作成と翌日の連絡と材料の送付と記録を担う手段です。

### エラベルの見解

担当する側から見ると、転換率の相談で最も多いのは、「応募の入り口が重い」ことです。面談で候補者の意思は固まっている。ところが、「では履歴書と職務経歴書をお送りください」と言われ、書類を整えるのに一週間かかり、その間に他社が決まる。意思はあったのに、手続きで落ちています。

「応募のご意思を一言いただければ、書類は媒体のご経歴で代え、正式な書類は選考が進んでからで結構です」。この一文で、意思がある候補者は当日に動けます。書類は、後からで足ります。

発注側にできるのは、応募の手続きを「一言で始められる」形にすることを、人事と選考の担当者で決めることです。

## まとめ

- 上がらないのは**話すことが無い・相手が材料を出せない・面談後の連絡が無い・入り口が重い・材料が無い・選考になっている・条件の話が無い**構造
- 段階は**実施→面談後の連絡→反応→応募の意思→手続き**。意思と手続きを分ける
- 設計は**話すこと（判断の材料）・相手（責任者か一緒に働く人）・面談後の連絡（要点と入り口）・入り口の軽さ（一言で、書類は後）・止まった人への材料（面談で出なかったもの）**
- 話すことは**役割の中身・一日の流れ・一緒に働く人・会社の今（課題も）・条件の幅・選考の流れ・懸念・入り口**。課題と条件を出す
- 面談後は**感謝・要点の再掲・相手の一言・次の流れ・質問の受け口・期限の目安・断りやすさ**。翌営業日
- 材料は**役割の補足・条件の詳細・会社の補足・比較の材料・時期・選考の短縮・迷いを聞く**。面談の繰り返しは送らない
- 記録は**相手・話した項目・面談後の連絡・反応・材料・意思と手続き・月次**。話した項目と転換率を並べる
- 外注できるのは**型・準備の資料・翌日の連絡・一言の下書き・入り口の設計・材料・一次対応・記録・報告**。社内に残るのは**相手・事実・条件の決定・入り口の決定・一言の協力・面談の実施**

## よくある質問

### 面談で条件（年収）を話すと、選考の前に決まってしまいませんか

幅で話します。「この役割の年収の幅は〇〇から△△で、ご経験と選考を踏まえて決まります」。確定の額ではなく、幅と決まり方です。幅が話されないと、候補者は「聞きにくい」まま止まり、応募の判断ができません。幅を聞いて「合わない」と分かる候補者は、応募の前に分かるほうが、双方の時間を使いません。条件の出し方は[スカウト段階で条件を出すか](/media/scout-kyuuyo-teiji/)と[候補者への年収提示を代行に任せてよいか](/media/rpo-nenshu-kaiji/)に書いています。

### 「考えます」と言われたら、どれくらい待つべきですか

翌営業日に面談後の連絡を送り、一週間後に材料を一度、さらに一週間後にもう一度。合計三通で、三週間ほどです。それで反応が無ければ、追うのをやめ、三か月後にプールから再送の対象にします。「決めてください」とは書きません。待つのではなく、材料を送って、候補者が判断できる状態にします。追客の段階ごとの型は[追客（フォローアップ）の設計](/media/scout-tsuiokuri/)に書いています。

### 面談の相手（責任者）が「応募を促すのは自分の役割ではない」と言います

促す必要はありません。責任者に頼むのは、「役割の中身と一日の流れと課題を話す」ことと、「翌日に二文を自分の名前で送る」ことの二つだけです。どちらも口説くことではなく、判断の材料を渡すことです。「口説いてください」と頼むと断られますが、「役割の話をしてください」なら引き受けてもらえます。応募を促すのは、面談後の連絡の入り口の設計で、人事と担当者の仕事です。
