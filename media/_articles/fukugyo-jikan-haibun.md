副業の稼働は週に六時間と決めた。ただ、その六時間の中で、作業に全部使ってしまい、依頼側への連絡が遅れ、記録も残らず、次の稼働で前回の続きを思い出すところから始まる。稼働の時間を、何にどう配分すればよいのか。結論を先に書くと、**副業の時間配分は、「稼働の何割を何に使うか」と割合で決めるのではなく、「作業」「連絡」「判断待ちの催促」「記録」「学び」の五つに、稼働の中の順番と上限を決めることで安定します。作業に全部を使うと、連絡と記録が溜まり、次の稼働が思い出しで消え、結果として作業の時間も減ります。稼働の始めに催促と連絡の確認、中に作業、終わりに記録と連絡、と順番を固定し、作業以外に上限を置く。この形で、稼働の時間が全部、前に進む時間になります。**タスク管理は[タスク管理のしかた](/media/fukugyo-tasuku-kanri/)に、複数案件の配分は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、時間の枠の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)にまとめています。

## 配分が崩れる典型

副業の時間配分が崩れる典型を見ます。どれも、稼働の時間が足りないのではなく、配分の問題です。

| 崩れ方 | 何が起きるか | 結果 |
|---|---|---|
| 作業に全部を使う | 連絡と記録が後回しになる | 依頼側が待つ。次の稼働が思い出しで消える |
| 連絡に全部を使う | 依頼側の連絡を読み、返し、また読み、で稼働が終わる | 作業が進まず、成果が出ない |
| 判断待ちを催促しない | 依頼側の判断が来ないまま、自分の作業も止まる | 何週間も止まり、依頼側も忘れる |
| 記録を残さない | 稼働の記録、状態の変化の記録がない | 報告が書けない。見積もりの根拠がない。成果が見えない |
| 学びに使いすぎる | 道具の勉強、記事の読み込みで稼働が終わる | 案件が進まない |
| 稼働の始めに何をするか決めていない | 連絡を読み始めて、そのまま流される | 作業に入るのが遅れる |
| 稼働の終わりの時刻を決めていない | 作業が延び、記録と連絡が飛ぶ | 次の稼働に響く |

典型の要点は、「作業に全部を使う」が、最も多く、最も気づきにくいことです。作業は目に見えて進むので、作業に使うことが正しく感じられます。ただ、連絡と記録が溜まると、依頼側が待ち、次の稼働が思い出しで消え、結果として作業の時間も減ります。作業以外に上限を置きつつ、作業以外をゼロにしない。この配分が、稼働の時間を全部、前に進める時間にします。稼働の記録は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、連絡の時刻は[連絡の速さをどう担保するか](/media/fukugyo-renraku-sokudo/)に書いています。

## 稼働の中の五つの使い道と順番

稼働の時間は、五つの使い道に分かれます。それぞれの役割と、稼働の中の順番です。

| 使い道 | 役割 | 稼働の中の順番 | 上限の目安 |
|---|---|---|---|
| 一、判断待ちの催促 | 止まっているものを動かす。依頼側が忘れているものを思い出させる | 稼働の最初。期限が来ている判断待ちを催促する | 数分 |
| 二、連絡の確認 | 依頼側の連絡を読み、今日の作業に影響するものを拾う | 催促の次。読むだけで、返さない | 五分から十分 |
| 三、作業 | 求人票、スカウト文面、面接の準備資料など、範囲の中の成果を作る | 稼働の中心 | 稼働の三分の二程度 |
| 四、記録 | タスクの一枚の更新、稼働の記録、状態の変化の記録 | 作業の後。連絡の前 | 十分 |
| 五、連絡の返信 | 作業の結果と、次の予定と、判断の依頼を、まとめて返す | 稼働の最後 | 十五分から二十分 |
| （学び） | 道具、人事の知識、型の改善 | 稼働の中には入れない。別の枠か、通勤で | 稼働の外 |

順番の要点は、「催促を最初に、返信を最後に」することです。催促を最初にすれば、依頼側はその日のうちに判断でき、次の稼働で判断が返っています。返信を最後にすれば、作業の結果を返信に入れられ、「対応しました」「次は〇〇を△日に」と書けます。連絡の確認を最初にして返信もその場でやると、返信で稼働が終わり、作業に入れません。「読むのは最初、返すのは最後」で分けます。学びは、稼働の中に入れると作業を圧迫するので、稼働の外に置きます。学びの枠は[学び直しの進め方](/media/fukugyo-gakushuu/)に、通勤での学びは[通勤時間の使い方](/media/fukugyo-tsuukin/)に整理しています。

### エラベルの見解

担当する側から見ると、同じ週六時間の稼働で、成果が出る担当者と出ない担当者の差は、作業の速さではなく、稼働の中の順番です。成果が出る担当者は、稼働の最初に判断待ちを催促し、依頼側の判断がその日のうちに返り、次の稼働で判断を待たずに進めています。出ない担当者は、判断待ちを催促せず、作業を進めようとして判断が要るところで止まり、稼働の時間が「待ち」で消えています。同じ六時間でも、催促の数分で、次の稼働の中身が変わります。

見ていて差がつくのは、稼働の終わりの時刻を決め、その前に記録と返信の時間を確保しているかです。作業に集中すると、終わりの時刻を過ぎ、記録と返信を飛ばして閉じる人が多くいます。飛ばした記録は次の稼働の思い出しになり、飛ばした返信は依頼側の待ちになり、両方が次の稼働を削ります。「作業は二十一時四十分まで。そこから記録と返信」と時刻で区切っている担当者は、作業を途中で切っても、次の稼働の始めが速く、結果として作業の時間が増えています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠が小さくても、判断待ちを動かし、返信の時刻を守る担当者が、依頼側から「進めてくれる人」として選ばれています。時間配分は、割合ではなく、順番です。

## 一稼働の中の型

一稼働（たとえば二時間）の中の型を、時刻で決めておきます。

| 時刻（二時間の例） | 使い道 | 内容 |
|---|---|---|
| 開始から五分 | タスクの一枚を見る | 次の一手、判断待ちの期限、締め切りを確認する |
| 五分から十分 | 判断待ちの催促 | 期限が来ている判断待ちを、選択肢と期限つきで催促する |
| 十分から二十分 | 連絡の確認 | 依頼側の連絡を読む。今日の作業に影響するものを拾う。返さない |
| 二十分から百分 | 作業 | 次の一手を進める。一枚は見ない。連絡も見ない |
| 百分から百十分 | 記録 | タスクの一枚を更新する。稼働の記録を書く。状態の変化があれば書く |
| 百十分から百二十分 | 連絡の返信 | 作業の結果、次の予定、判断の依頼を、まとめて返す |

型の要点は、「作業の時間に、連絡もタスクの一枚も見ない」ことです。作業の途中で連絡を見ると、返したくなり、返すと作業に戻れず、作業が細切れになります。作業の時間は作業だけ、と決め、連絡は最初に読み、最後に返す。二時間の稼働なら、作業に八十分を確保でき、それが成果になります。一時間の稼働なら、各段階を半分にし、作業に四十分を確保します。稼働の長さの決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、作業の集中は[早朝の稼働という選択](/media/fukugyo-hayaasa/)に書いています。

## 週の中の配分

一稼働の中の型とは別に、週の中で、依頼側ごと、作業の種類ごとに配分を決めます。

| 配分の軸 | 決め方 | 例 |
|---|---|---|
| 依頼側ごと | 稼働の日で依頼側を分ける。一稼働に一依頼側 | 「火曜はA、木曜はB、土曜は両方の記録と振り返り」 |
| 作業の種類ごと | 締め切りが固い作業を週の前半に、柔らかい作業を後半に | 「火曜にスカウト文面（今週送信）、木曜に求人票（来週まで）」 |
| 締め切りと定例 | 定例の前の稼働で、定例の材料を作る | 「定例が金曜なら、木曜に報告の材料」 |
| 判断待ちの回収 | 週の前半に催促し、後半に判断が返る形に | 「火曜に催促、木曜に判断を受けて進める」 |
| 記録と振り返り | 週の最後の稼働の一部を、週の記録と翌週の一枚の整理に | 「土曜の最後の三十分」 |
| 余白 | 週に一稼働分は、予定を入れない。突発と遅れの吸収に | 「日曜は予定を入れない」 |

配分の要点は、「余白を一稼働分、先に置く」ことです。週の稼働を全部埋めると、依頼側の突発、自分の体調、家族の事情で一稼働が飛んだときに、締め切りが落ちます。一稼働分を空けておけば、飛んでも吸収でき、飛ばなければ学びか休みに使えます。余白は、無駄ではなく、締め切りを守るための配分です。複数の依頼側の割り当ては[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、休みの枠は[休む設計](/media/fukugyo-yasumi/)に整理しています。

## 配分が偏ったときの兆候と直し方

配分は、気づかないうちに偏ります。兆候と直し方です。

| 兆候 | 偏り | 直し方 |
|---|---|---|
| 依頼側から「連絡が遅い」と言われた | 作業に偏り、返信が飛んでいる | 返信の時間を稼働の最後に固定し、時刻で区切る |
| 次の稼働の始めに、前回の続きを思い出している | 記録が飛んでいる | 記録の時間を作業の後に固定する |
| 判断待ちが何週間も止まっている | 催促が飛んでいる | 催促を稼働の最初に固定する |
| 稼働の時間が全部連絡で終わる | 連絡に偏っている。作業の時間に連絡を見ている | 連絡は最初に読み、最後に返す。作業中は見ない |
| 作業が進んでいるのに、報告が書けない | 状態の変化の記録がない | 記録の時間に、状態の変化を一行書く |
| 稼働の枠が毎週埋まり、突発で締め切りが落ちる | 余白がない | 週に一稼働分の余白を置く |
| 学びに稼働の時間を使い、案件が進まない | 学びが稼働の中に入っている | 学びを稼働の外に出す |

兆候の要点は、「依頼側から連絡が遅いと言われた」が、最も分かりやすい兆候だということです。作業に偏っている人は、自分では「頑張っている」と感じていて、偏りに気づきません。依頼側の言葉で気づいたら、作業の時間を削ってでも、返信の時間を稼働の最後に固定します。作業を少し減らして返信を確保する方が、依頼側の評価も、次の稼働の速さも上がります。連絡の担保は[連絡の速さをどう担保するか](/media/fukugyo-renraku-sokudo/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に書いています。

## 配分を決める順番

時間配分を決める順番です。

| 順番 | 内容 |
|---|---|
| 一、一稼働の長さを決める | 一時間か二時間。稼働の枠から |
| 二、一稼働の中の順番を時刻で決める | 一枚を見る、催促、連絡の確認、作業、記録、返信 |
| 三、作業以外の上限を決める | 催促と確認で十五分、記録で十分、返信で二十分、など |
| 四、作業の時間に連絡を見ないと決める | 通知を切る |
| 五、週の中で、依頼側と作業の種類を稼働の日に割り当てる | 「火曜はA、木曜はB」 |
| 六、週に一稼働分の余白を置く | 予定を入れない稼働 |
| 七、学びを稼働の外に出す | 別の枠か、通勤で |
| 八、月に一度、稼働の記録で配分の実態を見る | 作業と連絡と記録の実際の時間。偏りがあれば直す |

順番の要点は、「二」と「三」で、稼働の中の順番と上限を、時刻で決めることです。「作業を多めに、連絡は少なめに」と割合で決めると、実際の稼働では守れません。「二十分から百分は作業、百十分から返信」と時刻で決めれば、時計を見るだけで守れます。時間配分は、割合ではなく、時刻です。稼働の記録での確認は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、稼働の枠の設計は[長く続けるための設計](/media/fukugyo-choki/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「稼働の時間が足りないから、成果が出ない」というものです。実際には、稼働の時間が同じでも、順番と上限を決めている担当者は成果が出ていて、決めていない担当者は、作業に偏って連絡と記録が飛び、次の稼働が思い出しと待ちで消えています。足りないのは時間ではなく、順番です。順番を決めれば、同じ時間で成果が出ます。

順番として、一稼働の長さを決め、中の順番を時刻で決め、作業以外の上限を決め、作業中は連絡を見ず、週の中で依頼側と作業の種類を稼働の日に割り当て、一稼働分の余白を置き、学びを稼働の外に出し、月に一度記録で実態を見る。この順番で、時間配分は「作業に全部使って溢れるもの」から「順番で全部が前に進むもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠が小さくても、判断待ちを動かし、記録を残し、返信の時刻を守る担当者が、依頼側から続けて選ばれています。時間配分は、割合ではなく、順番と時刻です。

## まとめ

- 時間配分は**割合ではなく、稼働の中の順番と上限**で決める。作業に全部を使うと連絡と記録が飛び、次の稼働が消える
- 五つの使い道は**判断待ちの催促（最初）・連絡の確認（読むだけ）・作業（中心）・記録・連絡の返信（最後）**。学びは稼働の外
- **連絡は最初に読み、最後に返す**。作業の時間には連絡もタスクの一枚も見ない
- 一稼働の型を**時刻で決める**。「二十分から百分は作業、百十分から返信」
- 週の中では**依頼側を稼働の日で分け、締め切りが固い作業を前半に、一稼働分の余白を先に置く**
- 「連絡が遅い」と言われたら**作業に偏っている兆候**。作業を削ってでも返信の時間を最後に固定する

## よくある質問

### 一時間の稼働しか取れません。五つ全部をやる時間がありません

一時間なら、一枚を見るのに三分、催促に二分、連絡の確認に五分、作業に四十分、記録に五分、返信に五分、と縮めます。作業が四十分でも、催促と記録と返信が入っていれば、次の稼働が思い出しと待ちで消えず、四十分が全部前に進みます。五つを飛ばして作業に六十分使うと、次の稼働の最初の二十分が思い出しで消え、結果として作業は四十分になります。短い稼働ほど、順番が効きます。短い稼働の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に整理しています。

### 作業中に依頼側から急ぎの連絡が来たら、作業を止めてよいですか

急ぎの定義（その日のうちに依頼側の採用が止まるもの）に当たるなら、止めて対応します。当たらないなら、作業を続け、最後の返信でまとめて返します。急ぎの定義と経路を先に決めておけば、作業中に見る必要があるのは急ぎの経路（電話など）だけで、他の通知は切っておけます。定義が決まっていないと、全部の連絡が「急ぎかもしれない」となり、作業が細切れになります。急ぎの定義は[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)に書いています。

### 記録に十分もかけるのは、もったいない気がします

記録の十分は、次の稼働の最初の二十分を守るための十分です。記録がなければ、次の稼働で前回の続きを思い出し、稼働の記録がなければ月末の申告で思い出し、状態の変化の記録がなければ報告のときに思い出します。思い出す時間を合計すると、記録の十分より長くなります。記録は、その稼働のためではなく、次の稼働と月末と報告のための投資です。記録の型は[稼働ログの付け方](/media/fukugyo-log/)に、状態の変化の記録は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に整理しています。
