一度スカウトを送って、返信が無かった候補者に、もう一度送ってよいのか。送りすぎると「しつこい」と嫌がられ、口コミに書かれるかもしれない。送らないと、「たまたま見ていなかっただけ」の候補者を逃す気がする。何回まで、どのくらいの間隔で、何を変えて送ればよいのか、決まっていない。結論を先に書くと、**同じ候補者に送る回数は、「何回まで」の数で決めるものではなく、「間隔」「送る理由」「内容の変化」の三つで決めるものです。返信が無い相手には、二度目までは送ってよく、三度目以降は「新しい理由」（新しい役割、会社の変化、相手の状況の変化）があるときだけです。同じ内容を、短い間隔で、理由なく繰り返すことが、「しつこい」の正体です**。追客の設計は[追客（フォローアップ）の設計](/media/scout-tsuiokuri/)に、返信が来ない場合の全体は[スカウトの返信が来ない](/media/rpo-scout-henshin-nai/)にまとめています。媒体ごとの再送の規約と仕組みは、公式の案内で確認します。

## 回数で迷う構造

送る回数で迷うのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「何回まで」の数で考えている | 「三回まで」「五回まで」の数を探している。数は、間隔と理由と内容で意味が変わる |
| 間隔を決めていない | 一週間後に送るのか、三か月後に送るのか。同じ「二回目」でも、間隔で印象が違う |
| 同じ内容を繰り返している | 一度目と同じ文面を、もう一度。「読んでいないと思って」が透ける |
| 送る理由が無い | 「返信が無かったから」だけ。相手にとっての新しい理由が無い |
| 「しつこい」の境目を知らない | 何がしつこく見えるかを、候補者の側から考えていない |
| 送ってはいけない相手を分けていない | 「送らないでほしい」と言った人、辞退した人にも、送っている |
| 媒体の規約を確認していない | 同じ候補者への送信に関する規約や仕組みがある媒体がある。公式の案内で確認していない |
| 記録が無い | 誰に、いつ、何回送ったかが記録に無く、重複して送る |

構造の大半は、「数で考えている」ことと「記録が無い」ことです。

## 回数ではなく三つの条件で決める

送るかどうかを、三つの条件で決めます。

| 条件 | 中身 | 満たさない場合 |
|---|---|---|
| 一、間隔 | 前回から、相手の状況が変わりうる期間が空いているか。二度目は二〜三週間以上、三度目以降は三か月以上が目安 | 短い間隔の再送は、「催促」に見える |
| 二、送る理由 | 相手にとっての新しい理由があるか。新しい役割、会社の変化、相手の経歴や状況の変化、前回の内容の補足 | 理由の無い再送は、「読んでいないと思っている」に見える |
| 三、内容の変化 | 前回と違うことを書いているか。件名、一段落目、役割、次の一歩のどれかが変わっているか | 同じ内容の再送は、「一斉送信の再送」に見える |

三つの条件の要点は、「三つが揃えば、回数は問題にならない」ことです。三か月ごとに、新しい役割で、違う内容を送るなら、三回目でも「しつこい」とは見えません。逆に、一週間ごとに同じ内容を送れば、二回目で「しつこい」です。

三つが揃わないなら、送りません。「返信が無かったから、もう一度」だけでは、条件二と三を満たしません。

## 二度目の送り方

返信が無かった相手への、二度目の送り方です。二度目までは、理由が「前回の補足」でも送れます。

| 項目 | 二度目の型 |
|---|---|
| 間隔 | 二〜三週間以上。一度目が読まれていない可能性と、読んで迷っている可能性の両方に対応する期間 |
| 件名 | 一度目と変える。「先日ご連絡した件」ではなく、新しい切り口（役割の別の面、相手の経歴の別の部分） |
| 一段落目 | 「先日、〇〇のご経験についてご連絡しました。改めて」と、一度目に触れたうえで、前回と違う部分に触れる |
| 長さ | 一度目より短く。一画面以内。「一言だけ」の形 |
| 理由 | 「前回、△△についてお伝えできていなかったので」「□□の点を補足したく」。補足の形 |
| 次の一歩 | 一度目と同じか、より軽く。「ご質問だけでも」「一言のご返信でも」 |
| 断りやすさ | 「ご興味が無ければ、今後のご連絡は控えます」。二度目で、意思を聞く |
| 送り主 | 一度目と同じ人。人が変わると、「別の一斉送信」に見える |

二度目の要点は、「一度目に触れ、補足の理由で、短く、断りやすく」です。一度目と同じ文面を再送する形は、二度目でも避けます。

「ご興味が無ければ、今後のご連絡は控えます」を入れることで、三度目以降を送るかどうかの判断材料（返信が無い＝興味が無い可能性が高い）が得られます。二通目の文面の詳細は、このシリーズの次の記事で扱います。

## 三度目以降を送る理由

二度目にも返信が無かった相手に、三度目以降を送るのは、「新しい理由」があるときだけです。

| 新しい理由 | 中身 | 間隔の目安 |
|---|---|---|
| 新しい役割 | 前回と違う役割の募集が出た。相手の経歴に、前回より合う | 三か月以上 |
| 会社の変化 | 事業の段階、体制、働き方の制度が変わった。相手が気にしていそうな点が変わった | 三か月以上 |
| 相手の状況の変化 | 相手の経歴や公開の情報が更新された（新しい役職、転職の意向の公開など）。公開の範囲で | 変化が見えたとき |
| 時期 | 賞与の後、年度の変わり目など、動きやすい時期。ただし、時期だけを理由にしない | 時期に合わせて |
| 前回の内容への具体的な補足 | 前回の役割について、条件や体制で伝えていなかった大きな点がある | 一か月以上 |
| 相手からの間接の反応 | 相手が自社の採用サイトを見た、SNSに反応した、など（媒体や道具で分かる範囲で。個人情報の扱いは規程と法令に沿って） | 反応が見えたとき |

新しい理由の要点は、「相手にとって、前回と違う判断の材料がある」ことです。「返信が無かったから」「まだ募集しているから」は、相手にとっての新しい理由ではありません。

新しい理由が無ければ、三度目以降は送りません。送らないことも、運用です。

### エラベルの見解

相談で最も多い失敗は、「返信が無い候補者に、一週間ごとに同じ文面を三回送り、『しつこい』と口コミに書かれた」というものです。間隔が短く、理由が無く、内容が同じでした。二度目は二〜三週間後に、一度目に触れたうえで補足の理由で短く、「ご興味が無ければ控えます」を添え、三度目は新しい役割が出たときだけ、三か月以上空けて、に変えたら、「しつこい」は消え、二度目で返信が来る率が上がりました。回数ではなく、間隔と理由と内容でした。

見ていて差がつくのは、担当者が「三度目を送らない判断」をできるかどうかです。「返信が無いので、もう一度送ります」と繰り返す担当者と、「二度目までは補足で送ります。三度目は、新しい役割か会社の変化があるときだけです。無ければ送りません」と、送らない判断をする担当者がいます。後者は、候補者の信用を守ります。

発注側にできるのは、担当者に「回数の上限」ではなく「三つの条件」を渡し、「送らない判断」を認めることです。

## 送ってはいけない相手

三つの条件に関わらず、送ってはいけない相手です。

| 送ってはいけない相手 | 理由 |
|---|---|
| 「今後の連絡は不要」と返信した人 | 意思の表明。送れば、規約と信用の両方で問題 |
| 二度目の「ご興味が無ければ控えます」に返信が無かった人（三度目以降） | 興味が無い可能性が高い。新しい理由があっても、慎重に |
| 選考で辞退した人（辞退から短い期間） | 辞退の理由が解決されていなければ、送っても同じ。[過去の応募者への再アプローチ](/media/scout-kako-oubosha/)の考え方で、理由が変わったときだけ |
| 不採用にした人（短い期間） | 不採用の理由が要件なら、要件が変わったときだけ。[不採用にした人にもう一度声をかけたい](/media/rpo-fugouhi-saikatsuyou/) |
| 媒体で「スカウトを受け取らない」設定の人 | 媒体の仕組みで送れないか、送ってはいけない。公式の案内で確認 |
| 既に別の担当者や別の名義から送っている人 | 重複。記録で防ぐ |
| 別の役割で最近送った人 | 「複数の役割で送っている＝誰でもよい」に見える。間隔を空ける |
| 明らかに要件と合わない人 | 一度目から送るべきでない。二度目以降はなおさら |

送ってはいけない相手の要点は、「意思の表明」と「重複」です。「不要」と言った人に送ることは、最も避けます。記録が無いと、重複が起きます。

## 間隔の目安

送る間隔の目安です。自社の記録で調整します。

| 場面 | 間隔の目安 | 理由 |
|---|---|---|
| 一度目→二度目（返信無し） | 二〜三週間以上 | 読んでいない可能性と、迷っている可能性の両方に対応。一週間以内は催促に見える |
| 二度目→三度目（新しい理由あり） | 三か月以上 | 相手の状況が変わりうる期間。新しい役割や会社の変化が出る期間 |
| 辞退した人→再アプローチ | 辞退の理由が変わってから。目安は半年以上 | 理由が変わっていなければ同じ結果 |
| 不採用にした人→再アプローチ | 要件が変わってから。目安は半年以上 | 要件が同じなら同じ結果 |
| 返信があり、その後止まった人→再連絡 | 一〜二週間 | 対話の途中。「先日の件、いかがですか」の形。再送ではなく、対話の続き |
| 面談の後、応募の意思が無い人→再連絡 | 一週間後に一度、その後は三か月以上 | 面談の後の設計。[スカウトのCTAは面談か応募か](/media/scout-cta/) |
| 「今は動けない」と返信した人 | 相手が言った時期、または半年後 | 相手の言った時期を尊重 |

間隔の要点は、「返信が無い相手には長く、対話の途中の相手には短く」です。返信が無い相手への短い間隔は催促、対話の途中の相手への長い間隔は放置に見えます。

## 媒体の規約と候補者の意思

再送は、媒体の規約と候補者の意思に沿います。

**媒体の規約を確認する。** 同じ候補者への送信の回数や間隔に関する規約、再送の仕組み（同じ相手に再送できるか、再送は別の送信として数えられるか）は、媒体によって違います。公式の案内で確認します。

**「受け取らない」の設定を尊重する。** 媒体で候補者がスカウトを受け取らない設定にしている場合、送れないか、送ってはいけません。

**「今後の連絡は不要」の意思を、記録して守る。** 返信で意思が示されたら、記録し、送りません。担当者が替わっても守られる形に。

**複数の名義や複数の担当者からの重複を防ぐ。** 記録を一つにし、送る前に確認します。[複数名義でスカウトを送る](/media/scout-fukusuu-meigi/)。

**候補者の個人情報の扱い。** 送信の記録、返信の内容、意思の表明は、個人情報です。規程と法令に沿って扱い、専門家に確認します。

**媒体の外への連絡。** 媒体で返信が無いからと、媒体の外（別の連絡先）に送ることは、規約と信用の両方で問題になることがあります。公式の案内で確認し、避けます。

規約と意思の要点は、「確認せずに送らない」ことと「不要と言われたら送らない」ことです。

## 記録と運用

再送を、記録して運用します。

| 項目 | 運用 |
|---|---|
| 送信の記録 | 誰に、いつ、何回目、どの役割で、どの文面の型で、送り主は誰か。候補者ごとに |
| 意思の記録 | 「今後の連絡は不要」「今は動けない（時期）」「別の役割なら」など、返信の内容を記録 |
| 送る前の確認 | 記録を見て、前回からの間隔、回数、意思の表明、重複を確認してから送る |
| 二度目の運用 | 一度目から二〜三週間後に、一度目の返信が無い相手を抽出し、補足の理由で短く送る。「控えます」を添える |
| 三度目以降の運用 | 新しい理由（役割、会社の変化）が出たときに、記録から「三か月以上空いていて、意思の表明が無い」相手を抽出 |
| 送らない判断の記録 | 「三度目は送らない」と決めた相手と理由も記録。次の担当者が同じ判断をできるように |
| 効果の記録 | 二度目の返信率、三度目の返信率を、一度目と比べる。二度目が効いていれば続け、効いていなければ間隔か内容を見直す |
| 見直し | 三か月に一度。間隔の目安、二度目の型、三度目の理由の基準を、記録で見直す |

記録の要点は、「送る前に、記録を見る」ことです。記録を見ない再送が、重複と「しつこい」を生みます。

## 外注する場合の範囲

同じ候補者への送信の頻度を、スカウト代行に出す場合の範囲です。

**出せる工程。** 三つの条件（間隔・理由・内容の変化）の運用の決まりの作成、二度目の型の作成、三度目以降の理由の基準の作成、送ってはいけない相手の一覧、媒体の規約と仕組みの確認、送信と意思の記録の型と運用、送る前の確認の手順、二度目の抽出と送信、三度目以降の抽出（新しい理由が出たとき）と送信、送らない判断の記録、二度目と三度目の効果の記録と見直し、複数の名義や担当者の重複の防止。

**社内に残す判断。** 三つの条件の基準の承認（間隔の目安など）、三度目以降を送る「新しい理由」の判断（新しい役割、会社の変化）、意思の表明への対応の方針、個人情報の扱いの方針（専門家との連携）、送り主の名義。

**外注の効きどころ。** 再送は、「記録を見て、条件を確認して、送るか送らないかを決める」運用の継続が要り、社内では「返信が無いのでもう一度」になりやすい工程です。担当者が記録を一つにし、条件で判断し、二度目は補足で短く、三度目は理由があるときだけ、と回せば、「しつこい」は起きず、二度目の返信は取れます。担当者は複数の会社の再送を見ているので、「この間隔と内容なら二度目で返信が来る」の型を持ち込めます。ただし、媒体の規約は担当者も公式の案内で確認します。

**外注しても動かない場合。** 社内が「返信が無ければ何度でも」を求める、意思の表明を無視する、記録を一つにしない。社内の判断で、代行を替えても直りません。

再送は、回数ではなく、間隔と理由と内容で決まります。外注は、条件で判断し、記録して回す手段です。

### エラベルの見解

担当する側から見ると、再送の相談で最も多いのは、「送らない判断ができない」ことです。「返信が無いのはもったいない」「もう一度送れば読むかもしれない」で、理由の無い再送を繰り返し、「しつこい」になる。

二度目は補足で送り、「ご興味が無ければ控えます」を添える。返信が無ければ、三度目は新しい理由が出るまで送らない。「送らない」は、機会を捨てることではなく、候補者の信用を守ることです。信用が残っていれば、三か月後に新しい役割で送ったとき、読まれます。

発注側にできるのは、担当者に「送らない判断」を認め、「送信数」ではなく「返信数と信用」で評価することです。

## よくある質問

### 返信が無い候補者に、何回まで送ってよいですか

「何回まで」の数では決まりません。二度目は、二〜三週間以上空けて、一度目に触れたうえで補足の理由で短く、「ご興味が無ければ今後の連絡は控えます」を添えて送れます。三度目以降は、新しい理由（新しい役割、会社の変化、相手の状況の変化）があるときだけ、三か月以上空けて送ります。理由が無ければ送りません。一週間ごとに同じ内容を送る形が「しつこい」の正体で、三か月ごとに新しい理由で違う内容を送るなら、三回目でも「しつこい」とは見えません。媒体の規約は公式の案内で確認します。

### 二度目を送るとき、一度目と同じ文面でよいですか

同じ文面は避けます。「読んでいないと思って再送した」と見えます。件名を変え、一段落目で「先日、〇〇のご経験についてご連絡しました。改めて」と一度目に触れ、前回と違う部分（役割の別の面、相手の経歴の別の部分、伝えていなかった補足）を短く書きます。一度目より短く、一画面以内。次の一歩は「ご質問だけでも」と軽く。「ご興味が無ければ、今後のご連絡は控えます」を添えて、意思を聞きます。二通目の文面の詳細は、このシリーズの次の記事で扱います。

### 「今後の連絡は不要」と返信が来ました

記録して、送りません。担当者が替わっても、別の名義からも、別の役割でも、送りません。意思の表明を無視した送信は、媒体の規約と候補者の信用の両方で問題になります。返信には、「承知しました。ご連絡ありがとうございました」と一言返して、終わります。翻意を促さない。記録を一つにし、送る前に確認する手順があれば、誤って送ることは防げます。
