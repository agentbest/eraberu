副業の案件は、人のつながりから来ると聞く。ただ、自分は人事のつながりが少なく、交流会に出ても名刺が増えるだけで、案件にはつながらない。何をどう作れば、副業に効くネットワークになるのか。結論を先に書くと、**副業で効くネットワークは、人数ではなく、「自分の範囲を一言で言える相手」が、四つの種類にそれぞれ数人いる状態です。四つは、「同じ立場で副業をしている人」「以前の依頼側の担当者」「依頼側の社内で一緒に動いた人」「地域や業界の人事」です。名刺の数を増やしても、相手が自分の範囲を知らなければ、案件が出たときに思い出されません。会った相手に範囲を伝え、伝えた相手を四つの種類で数人ずつ持つ。これが、副業に効くネットワークです。**声がかかる状態の作り方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に、仲間の作り方は[同じ立場の仲間を作る](/media/fukugyo-nakama/)に、紹介の頼み方は[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/)にまとめています。

## 副業で効くネットワークの四つの種類

副業に効くネットワークは、四つの種類に分かれ、それぞれ役割が違います。

| 種類 | 誰か | 副業での役割 | 案件の入口になる形 |
|---|---|---|---|
| 一、同じ立場で副業をしている人 | 人事の経験を活かして副業をしている人 | 判断の相談、案件の回し合い、範囲の違いを知り合う | 相手の範囲に合わない案件が、自分に回ってくる。[同じ立場の仲間を作る](/media/fukugyo-nakama/) |
| 二、以前の依頼側の担当者 | 過去に案件で一緒に動いた依頼側の人事の担当者 | 次の採用のときに声がかかる。転職先で声がかかる | 担当者が「前に頼んだ人」として思い出す。[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/) |
| 三、依頼側の社内で一緒に動いた人 | 面接官、現場の責任者、別の外部の担当者 | 別の部署や別の会社で採用が始まったときに、名前が挙がる | 「あのとき一緒に動いた人」として思い出される |
| 四、地域や業界の人事 | 地元の企業の人事、依頼側の業界の人事の集まりの人 | 地域や業界の採用の相談が回ってくる | 「〇〇地域の採用なら」「〇〇業界なら」で思い出される。[地方在住でもできるか](/media/fukugyo-qa-8/) |

四つの要点は、「二」と「三」が、案件の入口として最も強いことです。以前の依頼側の担当者と、その社内で一緒に動いた人は、自分の動き方を実際に見ていて、範囲も分かっています。案件が出たとき、「前に頼んだ人」として最初に思い出されます。「一」と「四」は、範囲を伝えておけば、案件を回し合う入口になります。四つの種類を、意識して分けて持ちます。

## 人数より範囲の伝達が効く理由

ネットワークを人数で数えると、副業には効きません。理由を見ます。

| 人数を増やすと | 範囲を伝えた相手を増やすと |
|---|---|
| 名刺は増えるが、相手は自分が何をする人か知らない | 相手が「〇〇なら△△さん」と言える |
| 案件が出ても、相手は自分を思い出さない | 案件が出たとき、相手の頭の中で自分が候補に上がる |
| 連絡を取る相手が多すぎて、続かない | 数人なので、連絡が続く |
| 相手にとって自分は「会った人の一人」 | 相手にとって自分は「〇〇の人」 |
| 交流会に出続けることが目的になる | 会った相手に範囲を伝えることが目的になる |

理由の要点は、「相手の頭の中に、自分の範囲が残っているか」で、ネットワークの価値が決まることです。案件は、相手の頭の中で「この人なら」と思い出されたときに来ます。思い出される材料は、名刺ではなく、範囲の一言です。会った相手に、範囲を一言で伝え、相手が人に言える形にしておく。それが、ネットワークを作る作業の中身です。範囲の一言の作り方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「人事のネットワークが無いから、副業の案件が来ない」というものです。実際には、案件が続いている担当者のネットワークは広くなく、以前の依頼側の担当者が数人、同じ立場の人が数人、地域や業界の人事が数人、という程度です。広さではなく、その数人が自分の範囲を一言で言えることが、案件の入口になっています。ネットワークが無いと感じている人の多くは、会った相手はいるのに、範囲を伝えていないだけです。

見ていて差がつくのは、案件が終わったときに、依頼側の担当者と社内の人に「次に採用の手が要るときは、〇〇の範囲でお声がけください」と一言添えているかです。添えている人は、案件が終わっても、その依頼側の担当者と社内の人が、ネットワークの「二」と「三」として残り、数か月後に別の採用や別の会社から声がかかっています。添えていない人は、案件が終わると関係も終わり、毎回探しに行くことになっています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、依頼側の担当者が別の会社に移ったときに、同じ担当者を選び直す場面があります。ネットワークは、作りに行くものより、案件の中で自然に残るものが強いです。

## 種類ごとの作り方

四つの種類ごとに、作り方が違います。どれも、名刺を配ることではなく、範囲を伝えることです。

| 種類 | 作り方 | 範囲の伝え方 |
|---|---|---|
| 一、同じ立場の人 | 勉強会、副業の集まり、登録先のつながり、発信で知り合う。副業をしていることを、話してよい場所では話す | 「スカウトの運用と求人票を、週に数時間で受けている」と、工程と稼働で |
| 二、以前の依頼側の担当者 | 案件の中で、記録と型を残し、言った通りに動く。終了時に一言添える。連絡の経路を残す | 「次に採用の手が要るときは、〇〇の範囲で」と終了時に |
| 三、依頼側の社内で一緒に動いた人 | 面接官や現場の責任者と、担当者を通して丁寧に動く。準備の資料を渡す、日程を丁寧に組む | 直接は伝えにくい。担当者を通して「外部の〇〇さんは、〇〇を担当していた」と伝わる形に |
| 四、地域や業界の人事 | 地域の人事の集まり、業界の団体の集まりに、年に数回出る。地元の企業の採用の話を聞く | 「〇〇地域の採用」「〇〇業界の採用」を範囲の一言に入れる |

作り方の要点は、「二」の以前の依頼側の担当者が、作りに行くものではなく、案件の中で自然にできるものだということです。案件で言った通りに動き、記録と型を依頼側に残し、終了時に一言添える。それだけで、担当者はネットワークの一人になります。案件を丁寧に終えることが、ネットワークを作る最も確かな方法です。終了時の一言は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に、社内の人との関係は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に整理しています。

## 会った後に残す形

会った相手が、ネットワークとして残るかどうかは、会った後の形で決まります。

| 残す形 | 内容 |
|---|---|
| 範囲を伝えた相手の一覧を持つ | 種類、名前、範囲を伝えた日、相手の範囲や立場、連絡の経路。表計算の一枚で。依頼側の情報は書かない |
| 会った翌日に一言送る | 「昨日はありがとうございました。〇〇の範囲で受けているので、お困りの方がいればお声がけください」 |
| 相手の範囲と状況を覚えておく | 相手が何をしていて、何に困っているかを覚え、自分の範囲に合わない案件を相手に回せるようにする |
| 頻度を決めずに、変化があったら伝える | 範囲が広がった、稼働が変わったときに、一言伝える。定期の連絡は続かない |
| 相手から頼まれたら、短く返す | 相談も紹介も、短く返す。返さないと、相手の頭から消える |
| 発信で範囲を見せ続ける | 直接連絡しなくても、発信で「〇〇の範囲の人」として思い出される。[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/) |

残す形の要点は、「会った翌日に一言送る」ことです。会った場では、相手は多くの人と話していて、自分の範囲は残っていません。翌日に「〇〇の範囲で受けている」と一言送れば、相手の頭の中に範囲が残り、相手は返信で自分の範囲を教えてくれることもあります。この一言が、名刺を渡すことの何倍も効きます。連絡の型は[メールの書き方と運用](/media/fukugyo-mail/)に書いています。

## ネットワークを案件の入口にする条件

ネットワークがあっても、案件の入口にならないことがあります。入口になる条件です。

| 条件 | 内容 | 満たさないと |
|---|---|---|
| 相手が自分の範囲を一言で言える | 「〇〇なら△△さん」と、相手が第三者に言える | 案件が出ても思い出されない |
| 相手が自分の連絡先を持っている | 副業用のメールか、登録先のプロフィール | 思い出しても連絡できない |
| 相手が自分の受けられる条件を知っている | 稼働の時間帯、いつから受けられるか、対面の可否 | 「今は無理かも」と遠慮して声をかけない |
| 相手にとって自分が「頼んでよかった人」である（二と三） | 案件の中で、言った通りに動き、記録を残した | 「前に頼んだが、また頼むかは」となる |
| 相手に案件を回したことがある（一と四） | 自分の範囲に合わない案件を、相手に回した | 一方的に受ける関係は続かない |
| 依頼側の情報を持ち込んでいない | 相手との会話で、依頼側や候補者の話を出していない | 「この人は外で話す」と見られ、案件を回されない |

条件の要点は、「相手が自分の範囲を一言で言える」が、全部の土台だということです。範囲が伝わっていなければ、他の条件が揃っていても、案件は来ません。逆に、範囲が伝わっていれば、連絡先と条件を添えるだけで、案件の入口になります。条件の伝え方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に整理しています。

## 依頼側の情報を持ち込まない線

ネットワークの会話は、依頼側の情報が漏れる場面でもあります。線を引いておきます。

| 場面 | 線 | 代わりに |
|---|---|---|
| 同じ立場の人との会話 | 依頼側の会社名、候補者、合意した条件を出さない | 「〇〇業界の数十名規模の会社で、こういう範囲を受けている」と構造で |
| 以前の依頼側の担当者との会話 | 今の依頼側の話を出さない。以前の依頼側の社内の情報を、担当者が異動した先で話さない | 自分の範囲と条件の話だけ |
| 依頼側の社内の人との会話 | 担当者を通す。社内の人間関係に踏み込まない | 自分の範囲の工程の話だけ。[社内の力関係に巻き込まれる](/media/fukugyo-shippai-5/) |
| 地域や業界の人事との会話 | 依頼側が特定できる話をしない。業界が狭いと、業界と規模で特定される | 判断の仕方と、自分の範囲の話 |
| 案件を回し合うとき | 回す相手に、依頼側の情報を渡さない。依頼側の了解を得てから、依頼側と相手を直接つなぐ | 「こういう範囲の相談があるが、受けられるか」と構造で聞き、了解が取れたら依頼側から連絡してもらう |
| ネットワークの一覧 | 依頼側の情報を書かない | 相手の範囲と立場と連絡の経路だけ |

線の要点は、「案件を回し合うとき、依頼側の情報を自分から相手に渡さない」ことです。自分の範囲に合わない相談を仲間に回すとき、依頼側の会社名や求人の内容を伝えたくなりますが、それは依頼側の情報です。「こういう範囲の相談がある」と構造で聞き、相手が受けられるなら、依頼側の了解を得て、依頼側から相手に連絡してもらう形にします。守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に、紹介の礼儀は[知人紹介で受けるときの注意](/media/fukugyo-shoukai/)に書いています。

## 広げすぎないための上限

ネットワークは、広げるほどよいわけではありません。副業の枠の中で、続けられる上限を決めます。

| 上限 | 内容 |
|---|---|
| 四つの種類に、数人ずつ | 合わせて十数人で足りる。それ以上は、範囲を伝えても続かない |
| 集まりは年に数回 | 毎月出ると、副業の枠を圧迫する。年に数回、範囲を伝えられる場に |
| 連絡は変化があったときだけ | 定期の連絡は続かない。範囲や稼働が変わったときに一言 |
| 発信で範囲を見せる形を軸にする | 直接の連絡を減らし、発信で「〇〇の範囲の人」として残る形に |
| 案件の稼働が減ったら、ネットワークの活動を先に減らす | ネットワークは案件の稼働の余りで。削るのはネットワーク |
| 一覧が増えすぎたら、範囲を伝えた相手だけに絞る | 名刺だけの相手は一覧から外す |

上限の要点は、「四つの種類に数人ずつで足りる」ことです。案件の入口として機能するのは、範囲を伝え、連絡が続く相手で、それは数人ずつで十分です。人数を増やそうとして集まりに出続けると、副業の枠が減り、案件の稼働が落ち、ネットワークの「二」（以前の依頼側の担当者）が育たなくなります。案件を丁寧に回すことが、最も強いネットワークを作ります。稼働の優先は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に整理しています。

### エラベルの見解

担当する側から見ると、案件が続いている人のネットワークは広くなく、以前の依頼側の担当者と、その社内で一緒に動いた人と、同じ立場の人と、地域や業界の人事が、数人ずつです。その数人が、自分の範囲を一言で言え、案件が出たときに思い出してくれています。広いネットワークを作りに行っている人は、名刺は多くても、範囲を伝えた相手が少なく、案件の入口になっていません。

順番として、範囲を一言にし、案件の中で言った通りに動いて記録と型を残し、終了時に担当者と社内の人に一言添え、同じ立場の人と地域や業界の人事に会ったら翌日に範囲を一言送り、四つの種類の一覧を持ち、変化があったら伝え、依頼側の情報は持ち込まず、案件の稼働が減ったらネットワークの活動を先に減らす。この順番で、ネットワークは作りに行くものではなく、案件の中で自然に残るものになります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、依頼側の担当者との関係が、次の案件の入口として残りやすい形になっています。ネットワークの価値は、人数ではなく、自分の範囲を言える相手の数です。

## まとめ

- 副業で効くネットワークは**人数ではなく、範囲を一言で言える相手が四つの種類（同じ立場・以前の依頼側の担当者・依頼側の社内の人・地域や業界の人事）に数人ずつ**
- **以前の依頼側の担当者と社内の人**が最も強い入口。案件の中で言った通りに動き、終了時に一言添えれば残る
- 会った相手には**翌日に範囲を一言送る**。名刺より効く
- 入口になる条件は**範囲を言える・連絡先を持っている・条件を知っている・頼んでよかった人である・案件を回したことがある・情報を持ち込んでいない**
- ネットワークの会話でも**依頼側の情報を出さない**。案件を回すときは構造で聞き、依頼側の了解を得て依頼側から連絡してもらう
- 上限は**四つの種類に数人ずつ・集まりは年に数回・連絡は変化があったとき・案件の稼働が減ったら先に減らす**

## よくある質問

### 交流会に出ても、副業の話をしてよいか分からず、範囲を伝えられません

本業に副業を伝えている場合は、本業の関係者がいない場なら、副業の話をして構いません。伝えていない場合は、本業の関係者がいる可能性のある場では話さず、副業の集まりや、同じ立場の人だけの場で話します。話すときは、「人事の副業で、〇〇の範囲を受けている」と一言で足り、依頼側の名前や案件の中身は出しません。副業を伝えてよい状態の作り方は[副業は会社にばれるか](/media/fukugyo-qa-1/)に整理しています。

### 以前の依頼側の担当者に、案件が終わってから連絡する理由がありません

終了時に一言添えていなかった場合、後から理由なく連絡するのは負担になります。範囲が広がった、稼働の条件が変わった、という「近況」を伝える形なら、年に一度程度、自然に連絡できます。「〇〇の範囲を広げました。次に採用の手が要るときはお声がけください」と一言。相手の頭の中の情報が新しくなり、案件が出たときに思い出されやすくなります。連絡の頻度は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に書いています。

### 同じ立場の人に案件を回したいのですが、依頼側の情報をどこまで伝えてよいですか

依頼側の会社名、求人の内容、条件は伝えません。「〇〇業界の数十名規模の会社で、△△の範囲の相談がある。受けられるか」と構造で聞き、相手が受けられるなら、依頼側に「範囲が合う人がいるので、紹介してよいか」と了解を取り、依頼側から相手に連絡してもらいます。自分が依頼側の情報を相手に渡す形は、守秘の線を越えます。窓口を通している案件なら、窓口に相談し、窓口が紹介する形にします。紹介の進め方は[紹介につなげる](/media/fukugyo-shoukai-renkei/)に整理しています。
