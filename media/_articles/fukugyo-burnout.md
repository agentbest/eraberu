副業を始めた頃は楽しかったのに、いつからか、依頼側の連絡を見るのが重い。手が動かない。やめたいわけではないが、続けられる気もしない。これは燃え尽きなのか、どう防げばよかったのか。結論を先に書くと、**副業で燃え尽きるのは、稼働が多い人ではなく、「成果が見えない案件を、休みなく、一人で抱えている人」です。燃え尽きは、三つの条件が重なったときに起きます。「成果が見えない」「休みがない」「一人で抱えている」の三つです。防ぐには、稼働の上限より先に、この三つを外します。成果を状態で見える化し、休みを固定し、判断を相談できる相手を持つ。燃え尽きは、意志の弱さではなく、設計の欠けで起きます。設計を直せば、防げます。**休みの設計は[休む設計](/media/fukugyo-yasumi/)に、疲労との付き合い方は[疲労とどう付き合うか](/media/fukugyo-tsukare/)に、続ける設計は[長く続けるための設計](/media/fukugyo-choki/)にまとめています。体調に不安があるときは、副業の設計の前に、医療機関にご相談ください。

## 燃え尽きが起きる三つの条件

燃え尽きは、稼働の量ではなく、三つの条件が重なったときに起きます。

| 条件 | 何が起きているか | 副業でよくある形 |
|---|---|---|
| 一、成果が見えない | 頑張っているのに、何が良くなったか分からない。依頼側からの反応がない | 採用が決まらない時期が続く。依頼側が結果を伝えてくれない。自分の範囲の成果が、採用の可否に埋もれる |
| 二、休みがない | 本業の外の時間が全部副業になり、頭が切り替わる日がない | 週末も夜も副業。案件が途切れたときが休みのつもりで、途切れない |
| 三、一人で抱えている | 判断を相談する相手がいない。依頼側にも本業にも言えない | 副業を周囲に伝えていない。同じ立場の仲間がいない。依頼側の担当者とも相談の関係がない |

三つの要点は、どれか一つでは燃え尽きないことです。成果が見えなくても、休みがあれば回復します。休みがなくても、成果が見えていれば続きます。一人でも、成果と休みがあれば大丈夫です。三つが重なったときに、回復の手段がなくなり、燃え尽きます。防ぐには、三つのうち、一つでも外しておくことです。成果の見え方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、休みは[休む設計](/media/fukugyo-yasumi/)に、相談相手は[相談できる相手を持つ](/media/fukugyo-mentor/)に書いています。

## 燃え尽きの兆候の段階

燃え尽きは、ある日突然ではなく、段階を経て進みます。早い段階で気づけば、直せます。

| 段階 | 兆候 | この段階でやること |
|---|---|---|
| 一、張り切りすぎ | 案件が楽しく、枠を超えて稼働している。休みを取らない | 枠と休みを固定する。楽しいときこそ上限を守る |
| 二、疲れが抜けない | 週明けに疲れが残る。副業の日が来るのが少し重い | 週の休みを入れる。稼働を一段減らす |
| 三、反応が鈍る | 依頼側の連絡を見るのが遅れる。返信を後回しにする。質が落ちる | 一週間、副業を止める。成果を状態で書き出す。相談する |
| 四、意味が見えない | 何のためにやっているか分からない。「どうせ」と思う | 案件を区切りまで終え、一時停止する。休んでから設計を作り直す |
| 五、動けない | 手が動かない。連絡を開けない。本業にも響く | 依頼側に一時停止を伝える。副業の設計より先に、体調を整える。医療機関にも相談する |

段階の要点は、「三」の、反応が鈍る段階で止めることです。「二」までは、休みを入れれば戻ります。「三」に入ると、質が落ち、依頼側との関係にも響き始めます。ここで一週間止め、成果を書き出し、相談すれば、「四」に進まずに戻れます。「三」を「もう少し頑張れば」と越えると、「四」「五」に進み、戻るのに時間がかかります。止め方は[副業をやめるとき](/media/fukugyo-yameru/)の一時停止の形に、伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

### エラベルの見解

担当する側から見ると、燃え尽きて止まる担当者は、稼働が多い人ではありません。稼働が少なくても、採用が決まらない時期が続き、依頼側から反応がなく、休みを取らず、誰にも相談していない人が、止まっています。逆に、稼働が多くても、自分の範囲の成果を状態で記録し、週に一日は休み、仲間に判断を相談している人は、採用が決まらない時期でも続いています。燃え尽きの原因は、量ではなく、三つの条件です。

見ていて差がつくのは、「成果が見えない」時期に、自分の範囲の成果を状態で書き出しているかです。採用の可否は、担当者の範囲の外で決まることが多く、可否だけを見ていると、頑張りが全部無駄に見えます。「スカウトの返信が来ない状態から、来る状態になった」「面接官の準備が整っていない状態から、整った状態になった」と、範囲の中の状態の変化を書き出している人は、可否に関わらず成果が見え、燃え尽きません。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲の中の成果を状態で示せる担当者が、採用の可否に関わらず依頼側から評価されています。燃え尽きは、成果の見方で防げる部分が大きいものです。

## 条件ごとの防ぎ方

三つの条件を、それぞれ外す方法です。

| 条件 | 防ぎ方 | 具体的に |
|---|---|---|
| 一、成果が見えない | 成果を「採用の可否」ではなく「範囲の中の状態の変化」で見る | 案件の開始時に、範囲の中の「今の状態」を書き、月に一度「変わった状態」を書く。依頼側にも状態で報告する。[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/) |
| | 依頼側に、結果を教えてもらう約束をする | 「候補者の結果は、可否だけでも教えてください」と契約のときに |
| | 小さな区切りを自分で作る | 「今週はスカウト文面の型を一つ作る」と、自分の範囲で完結する区切り |
| 二、休みがない | 週に一日、副業に触れない日を固定する | 曜日で固定し、家族と依頼側に伝える。[休む設計](/media/fukugyo-yasumi/) |
| | 年に数回、数週間の休みを先に入れる | 年の初めにカレンダーに入れる |
| | 案件が終わったら、数日置いてから次を始める | 振り返りと休みを置く |
| 三、一人で抱えている | 同じ立場の仲間を持つ | 判断を相談できる相手を、数人。[同じ立場の仲間を作る](/media/fukugyo-nakama/) |
| | 依頼側の担当者と、相談できる関係を作る | 判断に迷うことは、依頼側に聞く。一人で決めない。[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/) |
| | 家族に、副業の状況を月に一度話す | 依頼側の情報は含めず、疲れ具合と状況を。[家族の理解を得る](/media/fukugyo-kazoku/) |

防ぎ方の要点は、「一」の、成果を状態で見ることを、最初にやることです。休みと相談相手は、設計として作れますが、成果の見方は、案件の中で毎回やることです。案件の開始時に「今の状態」を書いておかないと、後から「何が変わったか」が分かりません。開始時の状態を書き、月に一度、変わった状態を書く。この習慣が、燃え尽きを防ぐ最も確かな方法です。状態の書き方は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に書いています。

## 兆候が出たときの止め方

兆候の「三」以降が出たら、止めます。止め方の順番です。

| 順番 | 内容 |
|---|---|
| 一、一週間、副業を止めると決める | 「もう少し」ではなく、期間を決めて止める |
| 二、依頼側に伝える | 「体調の都合で、一週間稼働を止めます。〇日に再開します。進行中の〇〇は△△の状態です」 |
| 三、副業の端末を閉じる | 通知を切り、端末を離す。連絡は再開時に |
| 四、止めている間に、成果を状態で書き出す | 案件ごとに、開始時の状態と、今の状態。可否ではなく状態で |
| 五、三つの条件のどれが欠けていたかを見る | 成果が見えなかったか、休みがなかったか、一人だったか |
| 六、欠けていた条件を、設計に足す | 状態の記録、休みの固定、相談相手 |
| 七、再開するか、一時停止を延ばすかを決める | 一週間で戻らなければ、一時停止を一か月に延ばす。案件は区切りまで |
| 八、再開するなら、枠を一段小さくする | 止める前の枠で再開しない。小さく戻す |

止め方の要点は、「一」の、期間を決めて止めることです。「疲れたら休む」では、疲れているときは休む判断ができません。「一週間止める」と決め、依頼側に伝え、端末を閉じます。一週間で戻らなければ、一か月に延ばします。止めている間に、成果を状態で書き出すと、「頑張っていたのに意味がなかった」という感覚が、「状態はここまで変わっていた」に変わることが多いです。一時停止の伝え方は[副業をやめるとき](/media/fukugyo-yameru/)に、疲れの扱いは[疲労とどう付き合うか](/media/fukugyo-tsukare/)に整理しています。

## 燃え尽きた後の戻り方

燃え尽きて止まった後、戻るときの順番です。急いで戻ると、繰り返します。

| 順番 | 内容 |
|---|---|
| 一、体調が戻るまで、副業のことを考えない | 設計の見直しも、体調が戻ってから。不安があれば医療機関に |
| 二、三つの条件のどれが欠けていたかを、落ち着いてから見る | 止めている間に書き出したものを見る |
| 三、欠けていた条件を、設計に足す | 状態の記録、休みの固定、相談相手 |
| 四、枠を、止める前の半分程度に置く | 戻れることを確かめてから広げる |
| 五、成果が見えやすい案件から再開する | 範囲が明確で、状態の変化が分かりやすい工程 |
| 六、依頼側に、再開と枠を伝える | 「〇日から、週〇時間で再開します。範囲は□□に絞ります」 |
| 七、再開して一か月で、兆候が出ていないかを見る | 「二」の疲れが抜けない段階が出ていたら、枠をさらに小さく |
| 八、三か月続いたら、枠を少しずつ広げる | 広げるたびに、三つの条件を確認する |

戻り方の要点は、「四」の、枠を半分程度に置くことです。燃え尽きる前の枠で再開すると、同じ条件で同じことが起きます。半分で戻り、三か月続いたら広げる。戻れることを確かめながら広げる方が、結果として早く元の枠に戻れます。再開の相談は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に、枠の広げ方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

## 防ぐための設計の順番

燃え尽きを防ぐための設計を、始めるときに作る順番です。

| 順番 | 内容 |
|---|---|
| 一、案件の開始時に、範囲の中の「今の状態」を書く | 成果を状態で見る土台 |
| 二、月に一度、「変わった状態」を書く | 依頼側にも状態で報告する |
| 三、週に一日の休みを固定する | 曜日で。家族と依頼側に伝える |
| 四、年の休みを先に入れる | 年の初めに |
| 五、相談できる相手を数人持つ | 同じ立場の仲間、依頼側の担当者、家族 |
| 六、兆候の段階を知っておく | 「反応が鈍る」段階で止めると決めておく |
| 七、止め方を決めておく | 一週間止める、依頼側に伝える、端末を閉じる |
| 八、年に一度、三つの条件を確認する | 成果が見えているか、休みがあるか、一人になっていないか |

順番の要点は、「一」と「二」の、成果を状態で見る習慣を、案件の最初から入れることです。燃え尽きの三つの条件のうち、休みと相談相手は後からでも足せますが、成果の見方は、案件の開始時の状態を書いていないと、後から足せません。案件を受けたら、最初に「今の状態」を書く。この一つで、燃え尽きの最大の条件が外れます。続ける設計は[長く続けるための設計](/media/fukugyo-choki/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「燃え尽きたのは、自分が弱いからだ」というものです。実際には、燃え尽きた人は、弱いのではなく、成果が見えない案件を、休みなく、一人で抱えていただけです。同じ人が、成果を状態で見て、週に一日休み、相談相手を持てば、続いています。燃え尽きは、意志の問題ではなく、設計の問題で、設計は直せます。

順番として、案件の開始時に範囲の中の状態を書き、月に一度変わった状態を書き、週に一日の休みを固定し、年の休みを先に入れ、相談できる相手を数人持ち、兆候の段階を知り、反応が鈍る段階で一週間止めると決め、年に一度三つの条件を確認する。この順番で、燃え尽きは「起きてから対処するもの」から「設計で防ぐもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲の中の成果を状態で示し、稼働しない日を明確にしている担当者が、長く選ばれ続けています。燃え尽きを防ぐ設計は、続ける設計そのものです。

## まとめ

- 燃え尽きは**稼働の量ではなく、成果が見えない・休みがない・一人で抱えている、の三つが重なったとき**に起きる
- 三つのうち**一つでも外せば燃え尽きない**。最初に外すのは「成果が見えない」
- 成果は**採用の可否ではなく、範囲の中の状態の変化**で見る。案件の開始時に今の状態を書く
- 兆候は**張り切りすぎ → 疲れが抜けない → 反応が鈍る → 意味が見えない → 動けない**。反応が鈍る段階で止める
- 止めるときは**一週間と期間を決め、依頼側に伝え、端末を閉じ、成果を状態で書き出し、欠けていた条件を足す**
- 戻るときは**枠を半分に置き、成果が見えやすい案件から、三か月続いたら広げる**。体調に不安があれば医療機関へ

## よくある質問

### 燃え尽きているのか、ただ疲れているのか、区別がつきません

疲れは、休めば戻ります。週に一日の休みを二週間続けて、副業の日が重くなくなれば、疲れです。休んでも副業の連絡を開けない、意味が見えない、と感じるなら、燃え尽きの段階に入っています。区別がつかないときは、疲れとして扱い、まず休みを固定します。それで戻らなければ、一週間止めて、三つの条件を見ます。体調の不安（眠れない、食欲がない、本業にも響く）があれば、副業の設計より先に医療機関にご相談ください。疲れの扱いは[疲労とどう付き合うか](/media/fukugyo-tsukare/)に整理しています。

### 依頼側に「体調の都合で止める」と伝えるのが怖いです。信用が落ちませんか

期間と再開日と、進行中のものの状態を添えて伝えれば、信用は落ちません。落ちるのは、伝えずに反応が鈍る状態が続くことです。「反応が鈍る」段階では、依頼側はすでに「返事が遅い」と感じていて、その状態を続ける方が信用に響きます。「一週間止めて、〇日に再開します。〇〇は△△の状態です」と伝えれば、依頼側は予定を組めます。伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、進行中のものの共有は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

### 採用が決まらない時期が長く、成果が見えません。どう見ればよいですか

採用の可否は、自分の範囲の外で決まることが多く、可否で成果を見ると、頑張りが全部無駄に見えます。自分の範囲の中で、開始時と今で何が変わったかを書き出します。「スカウトの返信が来ない状態から、来る状態になった」「面接の日程が組めない状態から、組める状態になった」など、状態の変化を並べます。それを依頼側にも報告し、「可否は別として、範囲の中はここまで変わった」と共有します。状態の見方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、定義の仕方は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に整理しています。
