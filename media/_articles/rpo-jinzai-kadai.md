人材業界の会社（人材紹介、人材派遣、求人媒体、採用の支援）が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。キャリアアドバイザーと営業の離職が採用を上回り、募集が止まらない。担当者が顧客の採用と兼務で、自社の応募への返事が数日遅れる。目標と成果報酬と稼働の実態を先に出さず、同業の候補者に見抜かれて辞退される。職種で経路が違うのに、一つの求人票で募集している。経営者の面接の目が厳しく、通過が少ない。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**人材業界の採用課題は、離職・速さ・実態・職種・評価の五つに分解し、自社の記録（職種ごとの離職の時期と理由、応募から返事までの日数、辞退の理由、職種と経路ごとの応募の数、面接の通過と不通過の理由）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、採用の型を知っているだけに「もっと母集団を」と経路を増やし、採って、離れて、また募集する、という往復になります。代行に出す工程の切り分けは[人材業界の採用代行](/media/rpo-jinzai-rpo/)に書いています。ここでは、人材業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 離職 | キャリアアドバイザーと営業の募集が止まらない。半年以内に離れる | 職種ごとの離職の時期と理由。募集の回数 |
| 速さ | 応募への返事が数日後。日程が延びて「他社で決まった」 | 応募から返事までの日数。段階ごとの日数 |
| 実態 | 面接で「月の目標は」「成果報酬の条件は」「昨年の離職は」と聞かれて辞退 | 辞退の理由が「目標」「稼働」「成果報酬」「離職の多さ」 |
| 職種 | 営業は来るがキャリアアドバイザーが来ない（またはその逆）。未経験は来るが経験者が来ない | 職種と経路ごとの応募の数 |
| 評価 | 応募は来るが面接で通らない。経営者の一言で落ちる | 面接の通過と不通過の理由。面接官ごとの通過の差 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 職種ごとの離職の時期と理由、募集の回数 | 離職が採用を上回っていれば離職。入口より先に |
| 二 | 応募から返事までの日数、段階ごとの日数 | 数日後なら速さ |
| 三 | 辞退の理由 | 「目標」「稼働」「成果報酬」「離職の多さ」なら実態 |
| 四 | 職種と経路ごとの応募の数 | 偏りがあれば職種 |
| 五 | 面接の通過と不通過の理由、面接官ごとの差 | 通過が少なく理由が曖昧なら評価 |

一が最初なのは、離職を止めずに入口を直しても、穴を埋め続けることになるからです。人材業界の会社は入口の型を知っているので、入口から直したくなりますが、順番は離職からです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

人材業界で最も多い詰まりは「離職」で、しかも「この業界は辞めるもの」で片付けられていることです。退職面談で理由を集めると、「目標が最初から高かった」「教える人がいなかった」「同行が無く、一人で面談に出された」「成果報酬の条件が聞いていたのと違った」が並びます。最初の三つは受け入れの問題で、直せます。最初の三か月の目標を抑え、教える人を決め、面談と商談に同行する。それだけで、半年以内の離職が減る会社があります。エラベルで担当者を選ぶ企業には、「入社した方は、何か月目から目標を持ち、誰が同行しましたか」を、私たちから先に聞いています。答えが「一か月目から一人で」なら、代行の前に受け入れの設計です。営業の離職の分け方は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。

## 離職の課題：「業界だから」で片付けている

| 離職の理由 | 直す場所 |
|---|---|
| 目標が最初から高かった | 受け入れの体制（最初の三か月の目標、到達点） |
| 教える人がいなかった、同行が無かった | 教える人を決める。面談と商談への同行の型 |
| 成果報酬の条件が聞いていたのと違った | 求人票と面接で実態を。条件の表示は会社と専門家 |
| 稼働が長かった | 実態を先に出す。稼働の実態は会社の判断 |
| 顧客と候補者の板挟み | 上司との接点の型。案件の配分 |
| 条件 | 会社の判断 |
| 私的な事情 | 直す場所は無い。上を確かめた後 |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 速さの課題：自社の採用が後回し

| 状態 | 直し方 |
|---|---|
| 担当者が顧客の採用と兼務で、自社の応募は後回し | 自社の一次対応を外に出す。または自社の採用の時間を週の枠で先に確保 |
| 候補者の希望を聞いてから経営者に確認 | 経営者の枠を週に一つ先に預かり、候補を三つ出して即日で確定 |
| 面接とロールプレイが別の日 | 同じ日に組む |
| 自社の応募の記録が顧客の記録に混ざっている | 自社の採用の一覧を分ける |

顧客には「翌営業日中に返してください」と言いながら、自社は数日後、という状態は珍しくありません。枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 実態の課題：同業の候補者に覆えない

| 求人票に無いこと | 書き方 |
|---|---|
| 月の目標 | 「〇〇の型で、月の目標はこう決まる」の実態 |
| 成果報酬の比率と条件 | 「固定と成果の比率、成果の条件」の実態。表示は会社と専門家で整理 |
| 面談と架電の件数 | 「一日の面談と架電の目安」の実態 |
| 稼働の長さ | 「一週間の時間の使い方」の実態 |
| 離職の状況 | 「昨年は何名が離れ、理由はこうだった」を面接で語れるか |
| 受け入れ | 「最初の三か月は目標を抑え、同行する」の実態 |

同業からの候補者は業界の型を知っているので、覆うと辞退されます。実態を語り、厳しい部分は変える判断の材料にします。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

### エラベルの見解

人材業界で見落とされやすいのは「評価」の詰まりです。経営者や責任者が業界出身で、面接で候補者を見る目が厳しく、「この人は売れない」「傾聴ができていない」の一言で落ちる。応募が来ているのに通過が少なく、「良い人がいない」と経路を増やす。ところが不通過の理由を観点ごとに記録すると、面接官ごとに通過の差があり、観点が揃っていないことが分かります。「売れるか」を「新規の経験」「数字への向き合い方」「顧客との関係の作り方」に分け、基準を決め、記録する。それだけで、同じ応募の数から通過が増えることがあります。エラベルで担当者を選ぶ企業には、「面接の不通過の理由を、観点ごとに記録していますか」を、私たちから先に聞いています。記録が無ければ、経路を増やす前に観点の整理です。観点の揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

## 職種の課題：求める人と経路が違う

| 職種 | 動く理由 | 合う経路 |
|---|---|---|
| キャリアアドバイザー（未経験） | 人の役に立ちたい、対人の経験を活かしたい | 隣接の業界（販売、接客、教育）に届く経路、掲載型 |
| キャリアアドバイザー（経験者） | 領域の専門性、紹介の型、成果報酬の条件 | 同業に届く経路、知人、紹介 |
| 法人営業 | 新規の裁量、数字、成果報酬 | 営業の経験者に届く経路、紹介 |
| コーディネーター | 調整と速さ、対人 | 掲載型、隣接の業界 |
| 両面 | 両方を担う裁量 | 同業に届く経路、知人 |

職種ごとに求人票と経路を分け、職種と経路ごとに応募の数を記録します。経路の組み合わせは[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に書いています。

## 評価の課題：経営者の目が厳しい

| 状態 | 直し方 |
|---|---|
| 「売れない」「傾聴ができていない」の一言で落ちる | 観点（新規の経験、数字への向き合い方、対人の型）と基準を先に決める |
| 面接官ごとに通過の差がある | 観点ごとの記録で差を見せ、基準を揃える |
| 未経験に経験者の基準を当てている | 未経験は「受け入れで育つか」の観点に変える |
| ロールプレイの評価が印象 | ロールプレイの観点と基準を決め、記録する |

評価は社内で直す部分で、代行は記録の型を担えます。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 離職 | 退職面談の型、職種ごとの記録の分類 | 受け入れの体制（最初の三か月の目標、教える人、同行） |
| 速さ | 一次対応、日程の運用、自社の採用の一覧 | 経営者の枠の形を変えて出す |
| 実態 | 求人票に落とす作業 | 実態を語る。厳しい部分を変える判断 |
| 職種 | 職種ごとの経路の運用 | 職種の分け方と求人票の実態 |
| 評価 | 観点ごとの記録の型 | 観点と基準の決定。面接官の揃え方 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[人材業界で採用代行が機能する条件・機能しない条件](/media/rpo-jinzai-jirei/)に書いています。

## まとめ

- 「採れない」には**離職・速さ・実態・職種・評価**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は職種ごとの離職の時期と理由と募集の回数
- 最も多い詰まりは**離職**で、「業界だから」で片付けられている。最初の三か月の目標と同行で直せる
- **速さ**は自社の採用が後回しになる構造。一次対応を外に出すか、週の枠で先に確保
- **実態は覆わず整える**。同業の候補者は知っている。表示は会社と専門家
- 職種ごとに**求人票と経路を分ける**
- **評価**は観点と基準を先に決め、不通過の理由を記録する

## よくある質問

### 採用の会社なので、課題の分解は自分たちでできます

できます。ただ、「できる」と「やれている」は別で、顧客の採用を優先すると自社の記録が残らず、分解の材料が無いことが多い。まず自社の採用の一覧（職種ごとの応募、返事の日数、面接の通過と理由、辞退の理由、離職の時期と理由）を顧客の記録と分けて作る。それが揃えば、分解は自社でできます。揃っていなければ、記録の型だけを外に出す形もあります。

### 未経験を採って育てたいのですが、育つ前に辞めます

育つ前に辞めるのは、受け入れの問題です。未経験は、最初の三か月の目標を抑え、教える人を決め、面談と商談に同行し、到達点を一枚にする。それが無いまま「未経験歓迎」で採ると、入社の日から目標を持たされて離れます。加えて、未経験の面接では「売れるか」ではなく「受け入れで育つか」（対人の型、学ぶ姿勢、数字への向き合い方）を観点にします。経験者の基準を未経験に当てると、通過が少ないうえに、通過した人も合いません。

### 成果報酬の条件を求人票に書いてよいのですか

書き方には、報酬の表示に関わる法令上の整理があると一般に整理されているため、会社と専門家（社労士等）で整理します。個別の判断は専門家にご確認ください。整理したうえで、実態と違う書き方をしないことが要です。「固定と成果の比率」「成果の条件」「最初の三か月の扱い」を実態のまま書き、面接でも同じ説明をする。書いた条件と入社後の条件が違うことが、離職の理由の上位に来ます。
