保育士の採用を代行に出すか迷う園は、「これまで人材紹介会社に頼んできたが、成功報酬が重く、自園で採れる形にしたい」「求人票を作って媒体に出す工程はお願いしたいが、保育の実態を知らない人に保育士の採用が回せるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、園の種類と保育の方針と業務の整理・配置と担任の方針・持ち帰り仕事と書類の実態の開示・要件の決定・保育の姿勢と子どもとの関わりの評価・合否の判断は社内に残す**のが線です。保育士は、国家資格で母数が限られ、法令上の配置基準が関わり、業界が人材紹介会社に依存してきたという、看護師や薬剤師と共通する事情があります。加えて、「保育の方針への共感」と「持ち帰り仕事と書類の量」が、候補者の判断の中心にあり、資格を持ちながら働いていない潜在保育士が母集団の大きな部分にあります。「自園で採る仕組みを作り、保育の方針と実態を正直に示し、潜在保育士に届ける」ことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じ資格職の看護師の線は[看護師採用を代行に出す判断基準](/media/rpo-kangoshi-rpo/)にまとめています。

## 保育士採用が他の職種と違う点

一つ目は、園の種類と保育の方針で求める人と市場が違うことです。園の種類は、認可保育園、小規模保育、企業主導型、認定こども園、認可外。規模と年齢の構成と運営の形が違います。保育の方針は、子どもの自主性を重んじる保育か、一斉に活動する保育か、行事を多くするか少なくするか、外遊びをどのくらいするか。方針への共感が無いと、保育士は続きません。「保育士募集」だけでは、どの園のどの方針かが候補者に伝わりません。

二つ目は、国家資格で母数が限られ、法令上の配置基準が関わることです。保育士は資格が無いと担任を持てず、子どもの年齢と人数に対する配置の基準があります。一人が辞めるとクラスが回らなくなる構造で、採用の遅れが園の運営に直結します。配置基準と資格の扱いは、法令と制度で定められているので、専門家にご確認ください。

三つ目は、資格を持ちながら働いていない潜在保育士が、母集団の大きな部分になることです。保育士の資格を持ちながら、持ち帰り仕事と書類の量、人間関係、給与、子育てとの両立で離れた人が多く、その層が「戻ってもよいと思える園」を探しています。潜在保育士に届く求人票と経路が無いと、母集団の大きな部分を外します。

四つ目は、候補者が「保育の方針と行事の多さ」「担任の形（複数担任か一人担任か）」「持ち帰り仕事と書類の量」「休みと有給」「園長の人柄と人間関係」「保護者対応」「自分の子を預けられるか」を最初に確かめることです。保育士は、園の実態で働き続けられるかが決まります。方針が合うか、行事の準備で持ち帰りが出るか、書類（指導計画、連絡帳、日誌）にどのくらい時間がかかるか、休みの希望が通るか、園長がどういう人か、保護者対応を一人で抱えるか、自分の子を同じ園や近くに預けられるか。「保育業務全般」では、この判断ができません。

五つ目は、園長や主任は保育に入っていて、採用の工程を回す人がいないことです。園長は保育と保護者対応と職員の管理を回していて、面接の時間を取るのも難しい。運営法人の事務が回そうとしても、園の実態を知らず、求人票が抽象的になります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 園の種類と保育の方針と業務の整理 | 残す | どの園で、どの方針で、どの年齢のクラスを任せるか。社内にしか分からない |
| 配置と担任の方針の決定 | 残す | 複数担任か一人担任か、配置基準をどう満たすか、採る人にどのクラスを任せるか。法令に関わるので専門家に確認 |
| 持ち帰り仕事と書類の実態の開示範囲の決定 | 残す | 行事の準備と書類の量の実態と、減らす取り組みを、どこまで正直に書くか。園長と法人が決める |
| 要件の決定 | 残す | 園の種類と方針と業務から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（園の種類と方針と業務と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。保育の方針を園長の言葉で |
| 媒体の選定と運用 | 任せられる | 保育士と潜在保育士に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 園の種類と年齢と勤務地に合わせた検索と、担当してきた園に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、園見学の案内。潜在保育士にはブランクへの不安に答える連絡 |
| 園長・主任の面接の日程の確保 | 任せられる | 保育の合間（午睡の時間など）に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 園の種類・年齢・勤務地・資格・ブランクの分類は任せられる。保育の姿勢の評価は残す |
| 保育の姿勢と子どもとの関わりの評価 | 残す | 園長や主任が面接と見学で見る |
| 園の実態と方針の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 園の判断 |
| 条件の決定と提示 | 残す | 園の判断。経験の評価、担任の手当で条件の幅がある |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。年度の区切りに合わせた入職日の調整 |

線の要点は、「園の種類と保育の方針と業務、配置と担任の方針、持ち帰り仕事と書類の実態の開示範囲が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「方針が合うか」「この園で働き続けられるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「保育士をずっと紹介会社で採ってきたが、成功報酬が重く、自園で採る形にしたい。ただ、自園で求人を出しても応募が来ない」というご相談です。求人票を見ると、「保育士募集。クラス担任。経験者優遇。アットホームな園です」と書かれていて、園の種類も、保育の方針も、担任の形も、持ち帰り仕事と書類の量も、休みも、園長のことも無い。保育士はこれを読んで、「どの方針の園でどう働くか分からない」と判断し、紹介会社経由で実態を聞ける求人にしか動きません。

見ていて差がつくのは、「保育の方針と園の実態を一文で言えるか」です。「〇〇駅近くの認可保育園で、定員〇〇人、子どもの自主性を重んじる保育。行事は年に〇回で、準備は勤務時間内に収める方針。担任は複数担任で、採る人には〇歳児クラスを主任と一緒に。書類は簡素化して持ち帰りはほぼ無く、残業は月に〇時間程度。休みの希望はほぼ通る。園長は〇〇の経験が長く、『子どもと一緒に遊ぶ時間を一番大事にしたい』と言っている。職員の子どもを園で預かれる」。一文で方針と実態が分かれば、方針に共感する人も、持ち帰り仕事を避けたい人も、子育てとの両立を求める人も、自分向けかを判断できます。エラベルでは、保育士の案件をお受けする前に、依頼側に「園の種類と方針と業務」と「担任と持ち帰り仕事と書類の方針」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：園の種類と保育の方針と業務。** どの園で、どの方針で、どの年齢のクラスを任せるか。定員と年齢の構成、行事の回数と準備の形、外遊びの頻度、保育の考え方を園長の言葉で。

**二つ目：配置と担任の方針。** 複数担任か一人担任か、配置基準をどう満たしているか、採る人が入ることでどう変わるか、フリーの保育士がいるか。法令に関わるので、専門家に確認します。

**三つ目：持ち帰り仕事と書類の実態と、減らす取り組み。** 行事の準備の持ち帰りの実態、書類（指導計画、連絡帳、日誌）にかかる時間、簡素化や電子化の取り組み、残業の実態、休みの希望が通る率、有給の取り方。正直に把握し、「どこまで書くか」を決めます。

**四つ目：いまの園の状態と実態。** 誰がどのクラスを担当していて、何が属人化していて、何が止まっているか。園長が保育にも入っていて回らない、一人担任のクラスがある、離職が続いて教える余裕が無い、保護者対応を特定の人が抱えている。離職の状況と原因。正直に把握します。

**五つ目：園長や主任が、面接にどのくらい時間を出せるか。** 保育の合間（午睡の時間、延長保育の前）に、面接の枠と園見学の時間をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 園長の関与のさせ方

保育士の採用では、園長や主任の関与が要ります。面接で保育の姿勢を見る、園を見せる、方針と実態を正直に話す。しかし園長は保育と保護者対応を回していて、「採用は法人の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると園長がどう楽になるか」を具体的に示すことです。「この人が入れば、園長が保育に入らなくて済む」「一人担任のクラスが複数担任になる」。そして、負担を最小にする形で頼みます。面接の枠は代行が午睡の時間に押さえる、経歴は代行が整理して渡す、実態の説明の要点は代行が用意する。園長がやるのは、保育の姿勢を見ることと、園を見せて方針と実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で園長が「保育の方針」を自分の言葉で話すことの価値を、園長自身に理解してもらうことです。保育士の候補者は、法人の話より、園長の話を信じ、園長がどういう人かを最も気にしています。園長が「子どもと一緒に遊ぶ時間を一番大事にしたい。行事は減らして、準備は勤務時間内に。書類は簡素化した。持ち帰りはさせない」と話すと、候補者は「方針が明確で、正直な園長」と判断します。

## 代行を選ぶときの確認項目

保育士の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に保育園や保育業界の経験があるか。** 保育士そのものでなくても、園の運営法人の管理部門や、保育士の採用を回した経験。園の種類の違い、保育の方針の見方、配置基準の存在、持ち帰り仕事と書類の実態を知っているか
- **保育の方針と園の実態を求人票にどう書くか、案を出せるか。** 「保育業務全般」「アットホーム」で済まさず、方針と行事と担任の形と持ち帰り仕事と書類と休みと園長を書けるか
- **保育士と潜在保育士に届く媒体と経路の経験。** 保育士向けの媒体、スカウト、養成校とのつながり、潜在保育士の復職、子育て中の層、紹介会社との併用の設計。経路ごとの経験
- **紹介会社への依存から自園採用へ移す設計。** 紹介会社を使い続けながら、自園で採る仕組みをどう作るか。費用と離職の見え方を整理できるか
- **園長の日程を押さえる段取り。** 保育の合間に面接の枠を確保する方法。園見学を組み込めるか

五つのうち、一つ目と三つ目が大きい。保育業界を知らない担当者は、園の実態を書けず、潜在保育士に届く経路を持たず、紹介会社経由の応募との差が出ません。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、保育士の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「持ち帰り仕事と書類の実態を正直に書かないと、潜在保育士に届かない」と言われることです。潜在保育士が離れた理由の多くが持ち帰り仕事と書類の量で、それが求人票に無いと「同じことが起きる園」と読まれます。実態と、減らす取り組みを書くことで、この層に届きます。減らす取り組みが無いなら、採用の前に園長と作ります。

二つ目は、応募者の経路と事情が分かれることです。保育士の経験者、潜在保育士の復職、子育て中でパートや短時間を希望する人、新卒、別の園の種類からの転向。それぞれ持っているものと動く理由と不安が違い、任せるクラスと合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることと、不安に答える内容を変えます。

三つ目は、「園長の人柄」と「離職の状況」で候補者が判断を変えることです。保育士は、同じ地域の園の評判を保育士同士のつながりで知っています。離職が続いていることを隠しても、候補者は知っています。隠すより、「離職が続いた原因と、それに対して何をしているか」を園長が正直に話すことで、候補者の判断が変わります。

### エラベルの見解

担当する側から見ると、保育士の採用で最も効くのは、「保育の方針を園長の言葉で書き、持ち帰り仕事と書類の実態と減らす取り組みを正直に書く」ことです。保育士の候補者は、方針への共感で「この園で保育をしたいか」を判断し、持ち帰り仕事と書類の実態で「働き続けられるか」を判断します。潜在保育士は、この二つで「戻ってもよいか」を判断します。「保育業務全般。アットホームな園」の求人票では、紹介会社への依存から抜けられません。

エラベルでは、保育士の案件で担当者を紹介するとき、最初の一週間で園長と法人から「園の種類と方針と業務」「配置と担任の方針」「持ち帰り仕事と書類の実態と減らす取り組み」「実態」を聞き取り、園長の言葉で一文にするところから始めてもらっています。保育の姿勢と子どもとの関わりの評価は園長が面接と見学で行い、配置基準と資格の扱いは、専門家にご確認いただくようお伝えしています。

## まとめ

- 保育士採用が他と違うのは**園の種類と保育の方針で求める人と市場が違う・国家資格で母数が限られ配置基準が関わる・潜在保育士が母集団の大きな部分・候補者が園の実態（方針と行事・担任の形・持ち帰り仕事と書類・休み・園長・保護者対応・自分の子を預けられるか）を最初に確かめる・園長は保育に入っていて採用の工程を回す人がいない**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、園の種類と方針と業務・配置と担任の方針・持ち帰り仕事と書類の実態の開示・要件・保育の姿勢の評価・合否は残す**
- 代行に出す前に**園の種類と方針と業務、配置と担任の方針（専門家に確認）、持ち帰り仕事と書類の実態と減らす取り組み、いまの園の状態と実態、園長の面接の時間**を確認する
- 園長の関与は**採用でどう楽になるかを示し、負担を最小にして、保育の方針を自分の言葉で話す価値を理解してもらう**
- 代行を選ぶときは**保育業界の経験・方針と実態の書き方・潜在保育士に届く経路・紹介会社から自園採用へ移す設計・日程の段取り**を確認する
- 出したあとは**持ち帰り仕事と書類の実態を書く必要が表に出る・経路と事情が分かれる・園長の人柄と離職の状況で判断が変わる**。判断は園長と法人、材料は代行

## よくある質問

### 紹介会社をやめて、自園だけで採れるようになりますか

いきなりやめるのではなく、併用しながら自園の比重を上げる形が現実的です。自園の求人票に保育の方針と実態を園長の言葉で書き、保育士向けの媒体とスカウトを動かし、潜在保育士と子育て中の層に届け、直接の応募が増えてきたら、紹介会社の利用を絞ります。年度の途中で辞める人の穴を急いで埋める配置は紹介会社で、年度に向けた計画的な採用は自園で、という分け方から始める園が多い。離職が減れば、採用の数そのものが減ります。

### 持ち帰り仕事があるのが実態です。正直に書くと来ませんか

隠して面接や入職後に分かるほうが、辞退と離職を生みます。「行事の準備で年に数回、持ち帰りが出ることがある。書類は簡素化して、連絡帳は電子化し、指導計画は勤務時間内に書く時間を確保している。残業は月に〇時間程度」のように、実態と、減らす取り組みを一緒に書きます。持ち帰りを完全に避けたい人は見送りますが、「減らそうとしている園」には、潜在保育士も応募します。減らす取り組みが無いなら、採用の前に園長と作ります。持ち帰り仕事と書類の量で離れた保育士は多く、そこに手を打たない園は、採用を増やしても離職が続きます。

### 職員の子どもを園で預かる制度は、訴求になりますか

子育て中の保育士と潜在保育士には、最も大きな訴求の一つです。「自分の子を預けながら働けるか」は、この層が最初に確かめる項目で、同じ園で預かれる、近くの園と提携している、保育料の補助がある、のどれかがあれば、求人票の前半に書きます。制度が無い場合も、「時短」「土曜の勤務の免除」「急な休みへの対応」を書くことで、この層に届きます。制度の設計と運営に関わる要件は、専門家にご確認ください。
