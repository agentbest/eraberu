経営者が、数年後の引退を考え始めた。社内には、部門を任せている幹部はいるが、会社全体を継げる人はいないと感じている。家族に継ぐ人もいない。「外から後継者を採る」という選択肢が浮かぶが、何を求め、どう探し、どう継がせればよいか、分からない。外から来た人に、会社を任せてよいのかという不安もある。結論を先に書くと、**後継者を外から採るかどうかは、「採る・採らない」で考える前に、「何を継がせるか」「内部の候補はいないか」「時間はどのくらいあるか」の三つを並べます。並べれば、外から採る、内部を育てる、両方を組み合わせる、事業の承継の形そのものを変える、のどれかが見えます。外から採る場合も、「経営者を採る」のではなく、「継がせる期間を一緒に過ごす人を迎える」形で設計します**。CxOの探し方は[CxOクラスをどう探すか](/media/rpo-cxo-saiyo/)に、幹部の採用は[幹部・管理職が採用できない](/media/rpo-kanbu-saiyo/)にまとめています。事業の承継には法務・税務・金融の判断が関わるので、専門家（弁護士、税理士、金融機関、承継の専門家）に確認します。

## 後継者を外から採るかの判断で起きていること

後継者を外から採るかを考える経営者に、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 「社内にいない」と決めている | 内部の幹部を「会社全体は無理」と見ているが、育てる時間と支援を与えていない |
| 「何を継がせるか」が曖昧 | 経営そのものか、事業の一部か、株式か、経営者の人脈か。分けていない |
| 時間の見込みが無い | 「数年後」が、三年か十年か。時間で、取れる選択肢が変わる |
| 外から採ることへの不安が、判断を止めている | 「外の人に任せてよいのか」で、動かない |
| 「経営者を採る」と思っている | 経営者は採れない。「継がせる期間を一緒に過ごす人」を迎える |
| 家族、社内、取引先、金融機関への伝え方が無い | 誰に、いつ、何を伝えるか。決めていないので、動けない |
| 承継の専門家に相談していない | 法務・税務・金融の判断が要るのに、採用の話として考えている |
| 経営者自身が、引き際を決めていない | 「引退を考えている」が、「いつ、どこまで手放すか」が無い |

後継者の問題は、採用の問題である前に、承継の問題です。採用は、承継の設計の一部です。

## 判断の前に並べる三つ

「採る・採らない」の前に、三つを並べます。

**一、何を継がせるか。** 経営そのもの（会社全体の判断と責任）、事業の運営（日々の経営の執行）、株式（所有）、経営者の人脈と信用、経営者にしかできない特定の仕事。全部を一人に継がせるのか、分けるのか。「経営は外から迎えた人に、株式は家族に」「事業の運営は内部の幹部に、経営の判断は外から」のように、分けられます。

**二、内部の候補はいないか。** 「会社全体は無理」と決める前に、内部の幹部に、外部の支援（経営の顧問、育成の型、経営の一部を任せる経験）を付けて育てる可能性を見ます。「いない」なら、いない理由を明確に。「いる」なら、育てる時間と、外から採る場合との比較。

**三、時間はどのくらいあるか。** 経営者が引退までに使える時間。三年なら、外から迎えて継がせる期間としては短く、内部を育てるには足りないかもしれません。十年なら、内部を育てる選択肢が広がります。時間で、取れる選択肢が変わります。

三つを並べると、選択肢が見えます。

| 並べた結果 | 選択肢 |
|---|---|
| 内部に候補がいて、時間がある | 内部を育てる。外部の支援を付ける |
| 内部に候補がいて、時間が短い | 内部の候補に、外から経営の一部を担う人を迎えて支える |
| 内部に候補がいなくて、時間がある | 外から迎えて、継がせる期間を長く取る。または、内部の若手を長期で育てる |
| 内部に候補がいなくて、時間が短い | 外から迎えて、継がせる期間を集中する。または、承継の形そのものを変える（事業の譲渡、統合など。専門家に確認） |

「外から採るべきか」の答えは、三つを並べた結果として出ます。並べずに「採るべきか」を考えても、答えは出ません。

## 外から採る場合に決めること

外から後継者候補を迎えると決めた場合、探す前に決めることがあります。

| 決めること | 中身 |
|---|---|
| 継がせる範囲 | 経営の判断、事業の運営、株式、人脈と信用。どこまでを、いつまでに |
| 継がせる期間 | 迎えてから、経営者が手放すまで。一年か、三年か、五年か。期間で、迎える人の形が変わる |
| 迎える形 | 最初から後継者として迎えるか、まず経営幹部（COOなど）として迎えて、期間の中で見極めるか。後者が多い |
| 経営者の役割の変化 | 期間の中で、経営者が何を手放し、何を持ち続けるか。段階で |
| 株式と所有の設計 | 迎えた人に株式を渡すか、渡すなら形と時期。家族の持分。専門家（弁護士、税理士）に確認 |
| 報酬と契約の形 | 報酬の幅、役員か従業員か、期間、見極めの時期。専門家に確認 |
| 見極めの時期と、合わなかった場合 | 「三年後に、後継者として進めるかを判断する」。合わなかった場合の扱い（経営幹部として残るか、離れるか） |
| 社内と社外への伝え方 | 誰に、いつ、何を（後述） |
| 経営者自身の引き際 | 「いつ、どこまで手放すか」。経営者が決めていないと、迎えた人は動けない |

決めることの要点は、「継がせる期間」と「迎える形」です。「経営者を採る」のではなく、「まず経営幹部として迎え、期間の中で継がせながら見極める」形が、現実的です。

株式、契約、税務の判断は、採用の判断とは別に、専門家に確認します。

## 届く経路と見極め

後継者候補は、CxOと同じく、求人では探せません。経路と見極めです。

**経路。** 経営者の人脈、取引先や金融機関からの紹介、承継の専門家からの紹介、経営幹部に特化した紹介会社、経営者の集まり、顧問や社外役員の立場から。経路の使い方は[CxOクラスをどう探すか](/media/rpo-cxo-saiyo/)と同じです。加えて、承継に特化した仲介や支援の仕組みがあり、公式の案内で確認します。

**見極めの観点。** CxOの観点（決めた経験と責任、経営者との関係の作り方、段階への理解、価値観）に加えて、後継者に特有の観点があります。

| 後継者に特有の観点 | 確認の仕方 |
|---|---|
| 会社を「継ぐ」意思 | 「経営幹部として働く」と「会社を継ぐ」は違う。「継ぐ」ことへの意思と覚悟があるか |
| 経営者の価値観との近さと、違いの許容 | 会社の歴史、判断の積み重ね、社員との関係を、尊重しつつ、自分の判断で変えられるか |
| 社員と取引先からの信頼の作り方 | 「外から来た後継者」を、社員と取引先がどう受け入れるか。その作り方を語れるか |
| 経営者の引き際との呼吸 | 経営者が手放す速さと、迎えた人が引き取る速さが合うか |
| 家族や株主との関係 | 家族が株式を持つ場合、その関係を作れるか |
| 長い時間の覚悟 | 継がせる期間（数年）を、一緒に過ごす覚悟があるか |

見極めは、時間をかけます。顧問や社外役員の立場で関わってもらい、実際の判断の場面で見る形が、最も確かです。

## 継がせる期間の設計

外から迎えた後、継がせる期間を設計します。

| 段階 | 経営者 | 迎えた人 | 期間の目安 |
|---|---|---|---|
| 一、把握 | 会社の全体を見せる。判断の理由を話す | 事業、社員、取引先、財務を把握する。まだ大きな判断はしない | 半年〜一年 |
| 二、一部を任せる | 事業の運営の一部を渡す。判断を見守る | 渡された範囲で判断する。経営者と週に一度以上話す | 一年〜 |
| 三、見極め | 「後継者として進めるか」を、両者で判断する | 「継ぐ」意思を、改めて確認する | 迎えてから一〜三年の間 |
| 四、経営の判断を渡す | 経営の判断の大半を渡す。経営者は相談役に | 経営の判断を担う。経営者に相談しつつ、自分で決める | 見極めの後、一〜二年 |
| 五、手放す | 代表を交代する。株式の移転（設計に沿って）。経営者は退く、または会長など | 代表として経営する | 設計に沿って |

期間の要点は、「段階で渡す」ことと「見極めの時期を先に決める」ことです。段階が無く「全部を一度に」では、迎えた人も社員も混乱します。見極めの時期が無いと、「いつまでも経営者が手放さない」か「準備が無いまま交代」になります。

経営者の役割の変化は、経営者自身の覚悟の問題でもあります。「手放す」と決めた範囲は、手放します。手放さない経営者の下では、後継者は育ちません。

株式の移転、代表の交代、契約の変更は、専門家（弁護士、税理士、金融機関）に確認しながら進めます。

### エラベルの見解

相談で最も多い失敗は、「社内に後継者がいないと決めて、外から『後継者』として迎え、最初から『次の社長』と社内に伝え、半年で社員と取引先が離れ、本人も辞めた」というものです。継がせる期間の設計が無く、見極めの時期も無く、最初から「次の社長」でした。「まず経営幹部として迎え、一年かけて把握し、一部を任せ、三年目に後継者として進めるかを判断する」形にしていれば、社員も取引先も受け入れる時間があり、本人も会社も見極められました。

見ていて差がつくのは、担当者が「後継者の採用」を「承継の設計の一部」として扱うかどうかです。「後継者候補の求人を出しましょう」と言う担当者と、「まず、何を継がせるか、内部の候補、時間の三つを並べましょう。承継の専門家と一緒に。外から迎えるなら、経営幹部として迎えて、継がせる期間を設計します」と、承継から入る担当者がいます。後者は、経営者の判断を止めません。

発注側にできるのは、「後継者を採りたい」を、「承継をどう設計するか」に置き直し、採用の担当者と承継の専門家の両方と話すことです。

## 社内と社外への伝え方

後継者を外から迎えることを、誰に、いつ、何を伝えるかです。

| 相手 | いつ | 何を |
|---|---|---|
| 家族（株式を持つ、または関係する） | 探す前 | 承継の方針、株式の設計。専門家を交えて |
| 既存の幹部 | 探す前 | 「内部に候補がいない」と判断した理由、外から迎える方針、幹部の今後の役割。個別に、経営者から |
| 社員全体 | 迎えた後、把握の段階が終わってから | 「経営幹部として迎えた」。最初から「後継者」とは言わない。見極めの後に「後継者として進める」 |
| 取引先 | 一部を任せる段階から | 「経営幹部として、この領域を担う」。経営者が同行して紹介する |
| 金融機関 | 探す前、または迎える前 | 承継の方針と、迎える人の位置づけ。金融機関は承継に関心が高い |
| 迎えた人本人 | 迎える前 | 継がせる範囲と期間と見極めの時期、合わなかった場合の扱い、経営者の引き際 |

伝え方の要点は、「最初から後継者と言わない」ことと「既存の幹部に先に説明する」ことです。「次の社長」と最初に伝えると、社員も取引先も身構え、迎えた人は把握の時間を持てません。既存の幹部への説明が無いと、幹部が離れます。

## 外注する場合の範囲

後継者候補を外から迎える設計を、採用代行に出す場合の範囲です。

**出せる工程。** 三つ（継がせるもの・内部の候補・時間）を並べる整理の支援、内部の候補の育成の可能性の整理、外から迎える場合に決めることの整理（承継の専門家との連携の橋渡し）、経路の設計（経営者の人脈への声かけの整理、経営幹部に特化した紹介会社への説明の同席、承継の仕組みの案内）、候補者との連絡と日程、見極めの観点と対話の場の設計、顧問や社外役員の立場から始める形の設計、継がせる期間の段階の型、社内と社外への伝え方の型と文面、見極めの時期の振り返りの型。

**社内に残す判断。** 何を継がせるかの決定、内部の候補の判断、外から迎える決定、継がせる期間と見極めの時期の決定、経営者の引き際の決定、株式と契約の設計（専門家との連携）、相性と「継ぐ」意思の判断、家族・幹部・社員・取引先・金融機関への説明。

**外注の効きどころ。** 後継者の採用は、承継の設計の一部で、採用の担当者だけでは進められません。担当者ができるのは、採用に関わる部分（経路、連絡、見極めの場、伝え方の型）と、承継の専門家との橋渡しです。担当者は複数の会社のCxOと幹部の採用を見ているので、「経営幹部として迎えて期間の中で見極める」形の設計を持ち込めます。承継の法務・税務・金融は、専門家の領域です。

**外注しても動かない場合。** 経営者が引き際を決めない、何を継がせるかを決めない、既存の幹部に説明しない、承継の専門家に相談しない。社内の判断で、代行を替えても直りません。

後継者は、承継の設計の中で迎えます。外注は、採用に関わる部分を整え、専門家と橋渡しする手段です。

### エラベルの見解

担当する側から見ると、後継者の相談で最も多いのは、「経営者が、引き際を決めていない」ことです。「数年後に引退したい」と言うが、「いつ、何を、どこまで手放すか」が無い。迎えた人は、何を引き取ればよいか分からず、経営者は「まだ任せられない」と手放さない。数年経っても、何も変わらない。

「三年後に代表を交代する。一年目は把握、二年目は事業の運営を渡す、三年目に経営の判断を渡す」と、経営者が自分の引き際を段階で決める。それが無いと、後継者は育ちません。外から迎えるか内部を育てるかより先に、経営者の引き際です。

発注側（この場合は経営者自身）にできるのは、「いつ、何を、どこまで手放すか」を、自分で一枚に書くことです。それが、承継の出発点です。

## まとめ

- 起きているのは**社内にいないと決めている・何を継がせるかが曖昧・時間の見込みが無い・不安で止まる・経営者を採ると思っている・伝え方が無い・専門家に相談していない・引き際を決めていない**
- 判断の前に**何を継がせるか（経営・運営・株式・人脈）・内部の候補（育てる支援を付けて）・時間**の三つを並べる。並べた結果で選択肢が見える
- 外から迎えるなら**継がせる範囲・期間・迎える形（まず経営幹部として）・経営者の役割の変化・株式の設計・報酬と契約・見極めの時期と合わなかった場合・伝え方・引き際**を決める。専門家に確認
- 経路はCxOと同じく**人脈・取引先と金融機関・承継の専門家・経営幹部に特化した紹介会社・経営者の集まり・顧問や社外役員から**。見極めは**継ぐ意思・価値観の近さと違いの許容・信頼の作り方・引き際との呼吸・家族との関係・長い時間の覚悟**を時間をかけて
- 継がせる期間は**把握→一部を任せる→見極め→経営の判断を渡す→手放す**の段階で。見極めの時期を先に決め、経営者は手放すと決めた範囲を手放す
- 伝え方は**家族と幹部と金融機関には探す前・社員には迎えた後に経営幹部として・取引先には一部を任せる段階から・本人には迎える前に全部**。最初から後継者と言わない
- 外注できるのは**三つの整理・決めることの整理・専門家との橋渡し・経路・連絡と日程・見極めの場・顧問の形・期間の型・伝え方の型・振り返り**。社内に残るのは**継がせるもの・内部の判断・迎える決定・期間と時期・引き際・株式と契約・相性と意思の判断・説明**

## よくある質問

### 社内に後継者がいないので、外から採るしかないですか

「いない」と決める前に、内部の幹部に外部の支援（経営の顧問、育成の型、経営の一部を任せる経験）を付けて育てる可能性を、時間と合わせて見ます。時間があれば内部を育てる選択肢があり、時間が短ければ外から迎える選択肢が現実的になります。「何を継がせるか」を分ければ、「事業の運営は内部の幹部に、経営の判断は外から迎えた人に」のような組み合わせもあります。承継の形そのものを変える選択肢（事業の譲渡、統合など）は、専門家に確認します。

### 外から来た人に、会社を任せてよいのか不安です

最初から「後継者」として迎えず、「経営幹部」として迎え、把握と一部を任せる期間を経て、見極めの時期に「後継者として進めるか」を判断する形にします。数年の期間の中で、実際の判断の場面で相性と「継ぐ」意思を見られます。合わなければ、経営幹部として残るか離れるかを、最初に決めた扱いに沿って。不安は、「一度に全部を任せる」ことから来ます。段階で渡せば、不安は判断に変わります。

### 後継者の話を、社員にいつ伝えればよいですか

既存の幹部には、探す前に、経営者から個別に。「内部に候補がいないと判断した理由」と「幹部の今後の役割」を。社員全体には、迎えた後、把握の段階が終わってから、「経営幹部として迎えた」と。最初から「後継者」「次の社長」とは言いません。社員も取引先も身構え、迎えた人は把握の時間を持てなくなります。見極めの後に「後継者として進める」と伝えます。伝える順番と時期を間違えると、幹部が離れ、社員が動揺し、迎えた人が孤立します。
