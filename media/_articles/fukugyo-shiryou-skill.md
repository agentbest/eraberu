依頼側に出す提案の資料に、休日の半分を使った。見栄えは整ったが、担当者からは「上長に見せるので、要点を一枚にしてもらえますか」と言われた。資料を作る力は本業で鍛えたつもりだったが、副業では何かが違う。結論を先に書くと、**人事の副業で要る資料作成の力は、見栄えの良い資料を作る力ではなく、「依頼側の担当者が読まずに社内に回せる」資料を、短時間で作る力です。担当者は、資料を自分で読むだけでなく、上長や面接官に回します。回す先の人が、一枚で分かり、判断できる形になっていることが、資料の価値です。磨き方は、「読む人と次の動きを先に決める」「骨格を四段で固定する」「型を持って埋める」「回された先の反応で直す」の四つで、作る時間を減らしながら、伝わる資料になります。**資料の種類と一枚の形は[資料の作り方](/media/fukugyo-shiryou/)に、提案の一枚は[提案のまとめ方](/media/fukugyo-teian/)に、報告の一枚は[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/)にまとめています。

## 副業の資料が本業の資料と違う点

本業で資料を作り慣れている人ほど、副業で同じ作り方をして、ずれます。違いを見ます。

| 項目 | 本業の資料 | 副業の資料 |
|---|---|---|
| 読む人 | 社内の人。前提を共有している | 依頼側の担当者と、担当者が回す先の上長や面接官。前提を共有していない |
| 読む時間 | 会議で説明する時間がある | 説明の場が無いことが多い。読むだけで分かる必要がある |
| 作る時間 | 業務時間の中で、数日かけられる | 副業の枠の中で、数十分から数時間 |
| 目的 | 社内の合意、承認 | 依頼側の担当者が社内に回し、判断してもらう |
| 見栄え | 求められることがある | 求められない。一枚の表と箇条書きで足りる |
| 分量 | 十数枚でも読まれる | 一枚。長いと回されない |
| 情報の扱い | 社内の情報を前提に書ける | 依頼側の情報は依頼側の資料に。自分の側に残る資料には入れない |

違いの要点は、「読む人が、担当者ではなく、担当者が回す先の人」だということです。担当者は、資料を受け取ると、自分で読んで判断するだけでなく、上長に「外部からこういう提案が来ている」と回します。回す先の人は、案件の経緯を知らず、説明を聞く時間も無い。その人が一枚で分かる資料でないと、担当者は自分で要約し直すことになり、それが「要点を一枚に」という言葉になります。担当者の社内の立場は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に書いています。

## 資料の目的は、担当者が社内に回せること

副業の資料の目的を、一つに絞ります。担当者が読んで理解することではなく、担当者が読まずに社内に回せることです。

| 資料の状態 | 担当者がやること | 結果 |
|---|---|---|
| 十数枚で、経緯から結論まで | 読んで、要約して、上長向けに一枚を作り直す | 担当者の時間を使う。回されるのが遅れるか、回されない |
| 一枚で、結論と根拠と選択肢と依頼が並んでいる | そのまま上長に転送する | 上長がその場で判断できる。担当者の時間を使わない |
| 一枚だが、自分の意見が結論として書かれている | 上長に回すと「外部の意見でやり方を変える」形になり、担当者が説明に困る | 回されない。[改善提案の伝え方](/media/fukugyo-kaizen-teian/) |
| 一枚だが、依頼側の情報（候補者の名前、社内の事情）が入っている | 回す前に、その部分を消す必要がある | 回されるのが遅れる。情報の扱いで信頼を失う |

目的の要点は、「担当者が転送するだけで済むか」で資料を見ることです。作った資料を、担当者の立場で「これをそのまま上長に送れるか」と読み直し、送れないなら、送れない理由（長い、意見が結論になっている、情報が入っている）を直します。この問いだけで、資料の作り方が変わります。

### エラベルの見解

相談で最も多い思い込みは、「副業の資料は、本業の資料より簡単でよい」というものです。半分は正しく、分量と見栄えは簡単でよいのですが、設計は本業より難しくなります。本業の資料は、読む人が前提を知っていて、説明の場もあるので、多少長くても伝わります。副業の資料は、前提を知らない人が、説明無しに、一枚で判断できる必要があり、設計の精度が要ります。分量を減らすことと、設計を粗くすることは別です。

見ていて差がつくのは、資料を作る前に「この資料は、誰が、読んだ後に何をするか」を決めているかです。決めている人は、「上長が、来期の予算を判断する」と決め、その判断に要ることだけを一枚に入れます。決めていない人は、「提案の資料」として、経緯も根拠も選択肢も全部入れ、長くなります。エラベルでは、担当者が依頼側に出す資料を、「担当者がそのまま社内に回せる一枚」の形で作ることをお願いしています。資料の価値は、作った量ではなく、回された先で判断が進むかで決まります。

## 読む人と次の動きを先に決める

「一」の、資料を作る前に決めることです。この二つが決まれば、入れるものと入れないものが決まります。

| 決めること | 内容 | 例 |
|---|---|---|
| 読む人 | 担当者か、担当者が回す上長か、面接官か、経理か | 「担当者が上長に回す。上長は採用の経緯を知らない」 |
| 次の動き | 読んだ人が、読んだ後に何をするか | 「上長が、面接官の枠の固定を承認するか判断する」 |
| その判断に要るもの | 次の動きをするために、読む人が知る必要のあること | 「現状の事実（日程の確定までの日数と辞退）、選択肢（固定する・しない）、それぞれの手間と効果」 |
| 要らないもの | 読む人の判断に関係ないこと | 「案件の経緯、自分の稼働の詳細、他の工程の状況」 |

決める要点は、「要らないもの」を先に決めることです。資料が長くなるのは、要らないものを入れるからです。「上長が枠の固定を判断する」なら、案件の経緯も、自分の稼働も、他の工程も要りません。要るのは、事実と選択肢と手間と効果だけです。読む人の判断に要るものだけを入れれば、一枚に収まります。読む人の立場で読む習慣は[文章力をどう磨くか](/media/fukugyo-writing/)にも書いています。

## 四段の骨格

「二」の、資料の骨格です。どの資料も、この四段で固定します。順番を変えません。

| 段 | 内容 | 分量の目安 | 要点 |
|---|---|---|---|
| 一、結論（読む人が判断すること） | この資料で、読む人に判断してほしいこと、または伝えたい一つのこと | 一行から二行 | 冒頭に置く。最後まで読まないと分からない形にしない |
| 二、根拠（事実） | 結論に至る事実。依頼側の記録の数字、以前との比較 | 表で三行から五行 | 自分の意見や推測は入れない。[数字で語る](/media/fukugyo-suuji/) |
| 三、選択肢 | 取りうる手を二つか三つ。現状維持を含む。それぞれの手間と効果 | 表で二行から三行 | 自分が勧める一つだけを書かない |
| 四、依頼（誰に、いつまでに、何を） | 読む人に、いつまでに何を決めてほしいか。自分が次にやること | 一行から二行 | 期限が無いと動かない |

四段の要点は、「一」の結論を「読む人が判断すること」として書くことです。「面接官の枠を固定すべきです」は自分の意見で、「面接官の枠の固定について、ご判断をお願いします」は判断の依頼です。前者は、上長に回すと「外部の意見」になり、後者は「判断の材料」になります。同じ内容でも、書き方で回されるかどうかが変わります。提案の一枚の作り方は[提案のまとめ方](/media/fukugyo-teian/)に整理しています。

## 型を持って埋める

「三」の、型を持って短時間で作る形です。四段の骨格を、資料の種類ごとに型にしておき、毎回埋めます。

| 資料の種類 | 型（四段の中身） | 作る時間の目安 |
|---|---|---|
| 月次の稼働報告 | 結論：今月の一つの数字を比較で。根拠：工程別の時間と状態の変化の表。選択肢：無し（確認したいことがあれば）。依頼：確認したいことと期限 | 記録が整っていれば短時間 |
| 提案 | 結論：判断してほしいこと。根拠：事実の表。選択肢：二つか三つと手間と効果。依頼：誰がいつまでに | 事実が集まっていれば一時間程度 |
| 課題の構造の一枚 | 結論：止まっている工程。根拠：工程ごとの出口の数字。選択肢：原因の候補と範囲。依頼：自分の範囲で取り組む一つと、依頼側に判断してほしいこと | 記録から数字を取る時間が中心。[課題を構造化する](/media/fukugyo-kouzou-ka/) |
| 型の文書（文面の型、手順） | 結論：この型で何をするか。根拠：構造と順番。選択肢：無し。依頼：使う人と使い方 | 案件の中で作ったものを整えるだけ |
| 更新時の条件の見直し | 結論：範囲と稼働と単価の見直しの提案。根拠：一期分の記録。選択肢：範囲に入れる・戻す・止める。依頼：更新の判断の期限 | 記録が毎月整っていれば短時間。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |

型の要点は、「根拠の事実が、毎月の記録から取れる状態にしておく」ことです。資料を作る時間の多くは、事実を集める時間です。稼働ログと依頼側の記録が毎月整っていれば、根拠の表は記録から写すだけで、資料は短時間で作れます。記録が無いと、資料を作るたびに数字を集め直すことになり、時間がかかります。記録の整え方は[稼働ログの付け方](/media/fukugyo-log/)に書いています。

## やりがちな失敗

副業の資料で、本業の癖から起きる失敗です。

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 経緯から書く | 結論に辿り着く前に、読む人が止まる | 結論を冒頭に。経緯は要らない |
| 全部の選択肢を出す | 読む人が選べない | 二つか三つ。現状維持を含む |
| 自分の意見を結論にする | 上長に回すと「外部の意見」になる | 「判断してほしいこと」として書く |
| 見栄えに時間をかける | 副業の枠を圧迫する。見栄えは判断に関係ない | 一枚の表と箇条書き。装飾は要らない |
| 依頼側の情報を自分の資料に入れる | 自分の側に依頼側の情報が残る。回すときに消す必要がある | 依頼側の情報を含む資料は依頼側の共有に置き、自分の側には構造だけ。[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/) |
| 数字に出典が無い | 上長が「本当か」と疑う | 依頼側の記録の出どころを添える |
| 依頼に期限が無い | 判断が来ない | 「〇日までに」を入れる |
| 一度で完璧にしようとする | 出すのが遅れる | 一枚の粗い版を先に出し、反応で直す |

失敗の要点は、「経緯から書く」が最も多いことです。本業の資料は、経緯を共有して合意を作る形が多く、その癖で副業の資料も経緯から書きます。副業の資料は、経緯を知らない人が判断するもので、経緯は判断に要りません。結論を冒頭に置き、経緯は削ります。

## 回された先の反応で直す

「四」の、資料の反応を見て直す仕組みです。文章と同じで、反応で磨きます。

| 見る反応 | 何が分かるか | 直す場所 |
|---|---|---|
| 担当者から「要点を一枚に」と言われた | 長い。回せない | 結論を冒頭に、根拠を表に、分量を一枚に |
| 担当者から「これはどういう意味か」と聞かれた | 読む人が知らない前提が入っている | 前提を一行足すか、その部分を削る |
| 担当者が上長に回したと言った | 回せる形になっている | そのまま |
| 上長から質問が戻ってきた | 質問の内容が、資料に無かったもの | 次からその項目を入れる |
| 判断が来ない | 依頼の期限が無いか、判断する人に届いていない | 期限を入れる。誰が判断するかを確認する |
| 資料を出した後に、担当者が自分で作り直した | 担当者が使える形になっていなかった | 担当者が作り直した形を見せてもらい、次からその形にする |

反応の要点は、「担当者が作り直した形を見せてもらう」ことです。担当者が自分で作り直したなら、その形が、その依頼側の社内で通る形です。見せてもらい、次から最初からその形で作れば、担当者の手間は消え、自分の資料は依頼側の型に合います。依頼側の型に合わせる考え方は[クライアントのツールに合わせる](/media/fukugyo-kokyaku-tool/)に整理しています。

## 資料に入れてはいけないもの

副業の資料には、情報の扱いの線があります。入れてはいけないものを決めておきます。

| 入れないもの | 理由 | 代わりに |
|---|---|---|
| 候補者の名前と経歴 | 個人情報。資料が回るほど、広がる | 人数と工程で。「一次面接の評価待ちが〇名」。[個人情報の扱い](/media/fukugyo-kojin-jouhou/) |
| 他の依頼側の事例 | 守秘の線を越える | 自分の判断の仕方として。[他社事例をどう扱うか](/media/fukugyo-benchmark/) |
| 依頼側の社内の人の評価 | 「面接官の〇〇さんが遅い」は人の評価で、回すと問題になる | 工程で。「面接の評価の段階で止まっている」 |
| 自分の意見を事実のように | 「文面が悪い」は意見 | 事実で。「返信が先月から減っている」 |
| 出典の無い数字 | 上長が疑う。根拠にならない | 依頼側の記録から、出どころを添えて |
| 本業の会社の情報 | 本業の情報の持ち出し | 入れない |
| 自分の側に残す資料に、依頼側の情報 | 案件の終了時に消す必要が出る | 依頼側の情報を含む資料は依頼側の共有に。自分の側には構造だけ |

入れないものの要点は、「資料は回るので、回った先で問題にならないか」で見ることです。担当者にだけ見せるつもりの資料が、上長や面接官に回り、そこに候補者の名前や人の評価が入っていれば、問題になります。誰に回っても問題無い形で作ります。情報の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に書いています。

### エラベルの見解

担当する側から見ると、資料で評価されている人は、資料を作る時間が短い人です。読む人と次の動きを先に決め、四段の骨格に、毎月整っている記録から事実を写し、一枚で出し、担当者が回した先の反応で直している。時間が短いのに、回され、判断が来ています。資料に時間がかかっている人は、本業の癖で経緯から書き、見栄えを整え、意見を結論にし、依頼側の情報を入れ、長くなって回されず、担当者に作り直されています。

順番として、作る前に読む人と次の動きと要らないものを決め、結論・根拠・選択肢・依頼の四段に型で埋め、依頼側の情報と人の評価と出典の無い数字を入れず、一枚で出し、担当者が回したかどうかと、回された先の反応を見て直す。この順番で、資料作成は本業の資料とは別の力として磨かれます。エラベルでは、担当者が依頼側に出す資料を「担当者がそのまま社内に回せる一枚」の形で作ることをお願いしています。資料の力は、作る技術ではなく、回された先で判断が進む設計です。

## まとめ

- 副業の資料の力は**見栄えではなく、担当者が読まずに社内に回せる一枚を短時間で作る力**
- 本業の資料と違い、**読む人は担当者が回す先の人で、前提を知らず、説明の場が無い**
- 作る前に**読む人・次の動き・その判断に要るもの・要らないもの**を決める
- 骨格は**結論（判断してほしいこと）→根拠（事実）→選択肢（現状維持を含む）→依頼（誰にいつまでに）**の四段で固定
- **型を持ち、毎月整った記録から事実を写して埋める**。記録が資料の時間を決める
- 失敗は**経緯から書く・全部出す・意見を結論に・見栄え・依頼側の情報を入れる・出典が無い・期限が無い・完璧を目指す**
- **担当者が回したか、回された先の反応**で直す。担当者が作り直した形があれば、それに合わせる
- **候補者の情報・他社の事例・人の評価・出典の無い数字・本業の情報**は入れない

## よくある質問

### 依頼側から、スライドで十数枚の資料を求められました

依頼側の社内の形式がスライドなら、それに合わせますが、中身は四段の骨格を保ちます。一枚目に結論（判断してほしいこと）、二枚目に根拠の表、三枚目に選択肢、四枚目に依頼、と四枚で足りることが多く、十数枚にする必要はありません。「社内の形式に合わせて作りますが、判断に要ることを四枚に絞ります」と伝えれば、担当者は多くの場合、短いほうを歓迎します。依頼側の形式に合わせる考え方は[クライアントのツールに合わせる](/media/fukugyo-kokyaku-tool/)に書いています。

### 資料を出しても、担当者が上長に回してくれません

回されない理由を、担当者に聞きます。長い、意見が結論になっている、情報が入っている、担当者の社内の型と違う、のどれかであることが多く、理由が分かれば直せます。聞きにくければ、「この資料を上長の方にそのまま送っていただける形になっていますか。直したほうがよい点があれば教えてください」と、担当者が使える形にすることを目的にして聞きます。回されない資料は、作っても判断が進まないので、回される形に直すことが先です。

### 資料を作る時間が、副業の枠を圧迫します

時間がかかる原因は、多くの場合、事実を集める時間と、見栄えを整える時間です。事実は、毎月の稼働ログと依頼側の記録が整っていれば写すだけになり、見栄えは一枚の表と箇条書きで足りるので削れます。それでもかかるなら、資料の種類ごとに型を作り、埋めるだけにします。最初の一枚を作る時間は要りますが、二回目からは型に埋めるだけで、短くなります。型の作り方は[資料の作り方](/media/fukugyo-shiryou/)に整理しています。
