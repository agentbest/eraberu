副業で最初に頼まれることが多いのは、新しい求人票を書くことではなく、「いまある求人原稿を直してほしい」です。開いてみると直したいところだらけで、全部書き直したくなります。ただ、全部書き直した原稿は、依頼側に「うちの言葉ではない」と戻され、承認が遅れ、結局は元の原稿に近い形に落ち着きます。結論を先に書くと、**求人原稿の書き直しは、ゼロから書かず、原稿を六つの要素に分解して「欠けている要素」と「抽象語」を見つけ、欠けを足す→抽象語を仕事の言葉に直す→順番を入れ替える→削る、の順で、差分と理由を添えて渡します。**新しく書く場合の型は[ジョブディスクリプションを書く](/media/fukugyo-skill-jd/)に、案件として受ける形は[求人原稿のライティングの副業案件](/media/fukugyo-kyujin-raiting-fukugyo/)に書いています。ここでは、既存の原稿を直す手順に絞ります。

## ゼロから書き直してはいけない理由

| 全部書き直すと起きること | なぜ起きるか |
|---|---|
| 「うちの言葉ではない」と戻される | 元の原稿には、社内で通っている言い回しや、過去に揉めて決まった表現が入っている |
| 承認に時間がかかる | 差分が見えず、依頼側が全文を読み直すことになる |
| 直した理由が伝わらない | 何をなぜ変えたかが分からず、次の原稿で同じことが繰り返される |
| 実は良かった部分が消える | 元の原稿の「任せる仕事」の欄が具体だったのに、整えた文章に置き換わって薄くなる |

書き直しの仕事の価値は、文章のうまさではなく、「どこが効いていなくて、なぜか」を示し、最小の変更で効く形にすることです。

## 直す前に確かめる三つのこと

| 確かめること | 聞き方 | 分かること |
|---|---|---|
| 誰が書いたか | 「この原稿は、どなたが、いつ書かれましたか」 | 現場が書いたなら仕事の欄は残す。前任の担当者や媒体の営業が書いたなら、会社の言葉ではない可能性 |
| どこで止まっているか | 「応募が来ないのか、来ても合わないのか、面接で辞退されるのか」 | 止まる場所で直す欄が変わる。来ないなら見出しと冒頭、合わないなら必須と任せる仕事、辞退なら最初の三か月と一緒に働く人 |
| 何を残すか | 「この原稿で、変えたくない表現はありますか」 | 揉めて決まった表現、法務が見た表現、社長の言葉。ここは触らない |

三つ目を聞かずに直すと、触ってはいけないところを触って、全体が戻されます。

### エラベルの見解

担当する側から見ると、書き直しで最も差がつくのは「どこで止まっているか」を聞いてから手を付けるかどうかです。応募が来ない原稿と、応募は来るが合わない原稿は、直す欄が逆です。来ないなら、見出しと冒頭の「この役割がある理由」を直し、必須はむしろ減らす。合わないなら、見出しはそのままで、任せる仕事と必須を具体にして、合わない人が自分で判断して離れるようにする。止まる場所を聞かずに「全体を読みやすく」直すと、どちらの問題も動きません。エラベルで担当者を選ぶ企業には、「応募数と、書類の通過率と、面接の辞退率のどれが困っていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、依頼側が「とにかく直してほしい」としか言わないときは、媒体の管理画面で応募数と通過数を見せてもらうこと。数字が出なければ、「来ない・合わない・辞退」のどれかを一つ選んでもらってから始めます。

## 原稿を六つの要素に分解する

既存の原稿を、六つの要素に振り分けます。振り分けられない文は「その他」に置きます。

| 要素 | 元の原稿のどこに当たるか | よくある状態 |
|---|---|---|
| この役割がある理由 | 冒頭、会社紹介の中 | 無い。会社の沿革だけがある |
| 任せる仕事 | 「仕事内容」 | 「幅広い業務」「〜など」で終わる。十個以上並ぶ |
| 最初の三か月 | 無いことが多い | 無い |
| 一緒に働く人 | 「配属先」「チーム構成」 | 人数だけ。上長と隣の部門が無い |
| 求める経験 | 「応募資格」「必須・歓迎」 | 必須が多い。性質の言葉が必須に入っている |
| この会社で得られるもの | 「魅力」「当社について」 | 長い。どの会社にも書けることが並ぶ |

振り分けると、「欠けている要素」と「抽象語で書かれている要素」が見えます。これが診断です。診断を一枚にして依頼側に見せると、「どこを直すか」の合意が先に取れます。

## 直す優先順位

| 順 | 何をするか | なぜこの順か |
|---|---|---|
| 一 | 欠けている要素を足す | 無いものを足すのが最も効く。特に「最初の三か月」と「この役割がある理由」 |
| 二 | 抽象語を仕事の言葉に直す | 「幅広い業務」「主体性」を、任せる仕事と経歴の言葉に。置き換えの表は[ジョブディスクリプションを書く](/media/fukugyo-skill-jd/)に |
| 三 | 順番を入れ替える | 仕事が先、会社が後。読む人は仕事から確かめる |
| 四 | 削る | 必須を三〜五つに。得られるものを、比べる相手との差が出る点だけに。任せる仕事を時間の比率が大きい順に |

文章の表現を整えるのは、四つが終わってからです。表現を先に直すと、効かない原稿がきれいになるだけです。

足すための材料が無いときは、いまうまくやっている人に「入った頃の三か月」を聞きます。聞き方は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)に書いています。

## 修正案の出し方：差分と理由

修正案は、全文の置き換えではなく、差分で見せます。

| 出し方 | 中身 |
|---|---|
| 元の文と直した文を並べる | 一要素ごとに。表か二列で |
| 理由を一行添える | 「応募者が自分の経歴と照らせるように、仕事の中身を書きました」 |
| 材料の出どころを書く | 「〇〇さんへの聞き取りから」「要件の一枚から」 |
| 変えていない箇所を明示する | 「この段落は、いただいた指示のとおり残しています」 |
| 判断を依頼側に残す | 「必須の〇〇は歓迎に下げる案ですが、判断はお任せします」 |

差分で出すと、依頼側は変えた箇所だけ読めばよく、承認が早くなります。理由が添えてあると、次の原稿で同じ直しが要らなくなります。修正の履歴は残し、誰の指摘でどこを直したかを書いておきます。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「直した原稿を渡せば仕事は終わり」というものです。実際には、書き直しの仕事は、直した原稿を媒体に載せて、止まっていた場所の数字が動いたかを見るところまでです。応募が来ない原稿を直したなら、載せ替えてから一定期間の応募数を、合わない原稿を直したなら書類の通過率を、依頼側と一緒に見ます。動かなければ、診断が違っていたか、原稿以外（媒体・条件・タイミング）が原因です。「原稿を直したのに変わらない」を、原稿のせいにも依頼側のせいにもせず、次の仮説に進みます。受ける側がその場で使える判断としては、修正案を渡すときに「載せ替え後、何を、いつ見るか」を一行添えること。これが無いと、成果が誰にも見えないまま終わります。数字の見方は[成果の数字の扱い](/media/fukugyo-suuji/)に書いています。

## 依頼側に確認してもらう順番

| 順 | 確認する人 | 確認すること |
|---|---|---|
| 一 | いまうまくやっている人 | 直した「任せる仕事」「最初の三か月」が実態と合っているか |
| 二 | 現場の責任者 | 必須の増減に問題が無いか |
| 三 | 元の原稿を書いた人（分かる場合） | 変えた理由を伝え、残した箇所を示す。飛ばすと後で戻される |
| 四 | 経営者・依頼側の決まりに従った確認 | 表現の可否。専門家の確認が要る表現があるか |

元の原稿を書いた人を飛ばして上に上げると、その人が後から「なぜ変えたのか」と戻すことがあります。三番目に置き、先に理由を伝えておきます。

## 書いてはいけない表現の扱い

元の原稿に、性別や年齢などを条件にする表現や、それを示唆する言い回しが残っていることがあります。募集や採用で法令上の決まりがあると一般に整理されている項目は、依頼側の決まりと専門家の確認に従い、修正案では「この表現は、経歴の言葉に置き換える案です」として、判断を依頼側に渡します。収入や昇進を保証する表現、実態と違う待遇の記載も同じです。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## 媒体の制約に合わせる

| 制約 | 合わせ方 |
|---|---|
| 文字数の上限 | 六つの要素の順番は守り、各要素を短くする。「任せる仕事」と「最初の三か月」は削らず、「得られるもの」と会社紹介を削る |
| 項目が固定されている | 「仕事内容」の欄に、この役割がある理由（一文）→任せる仕事→最初の三か月→一緒に働く人の順で入れる |
| 媒体の規約で書けない表現 | 媒体の規約を優先し、書けない旨を依頼側に伝える |
| 複数の媒体に同じ原稿を載せている | 一本の原稿を直し、媒体ごとの差分は最後に。媒体ごとにゼロから直さない |

媒体の仕様は変わるので、規約は依頼側か媒体の担当者に確認します。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 直したいところが多すぎる | 「どこで止まっているか」に戻り、その欄だけ直す。残りは次の回に |
| 依頼側が元の表現に戻したがる | 「残す」に入れる。理由を聞いて、次の原稿の判断材料にする |
| 足す材料が無い | いまうまくやっている人に三十分。取れなければ、欄を「確認待ち」と明記して仮に置く |
| 修正案を全文で出してしまい、承認が止まる | 差分の表に作り直し、変えていない箇所を明示して出し直す |
| 直した後の数字を誰も見ない | 修正案に「載せ替え後、何をいつ見るか」を添える。見る日を依頼側の予定に入れてもらう |

## まとめ

- **ゼロから書き直さない**。元の原稿には社内で通っている言葉と、揉めて決まった表現がある
- 直す前に**誰が書いたか・どこで止まっているか・何を残すか**の三つを聞く
- 原稿を**六つの要素に分解**し、欠けと抽象語を見つける。診断を一枚にして合意を先に取る
- 直す順は**欠けを足す→抽象語を仕事の言葉に→順番を入れ替える→削る**。表現を整えるのは最後
- 修正案は**差分と理由**で出す。変えていない箇所を明示し、判断は依頼側に残す
- 確認は**いまうまくやっている人→現場の責任者→元の原稿を書いた人→上**の順
- 載せ替え後に**何をいつ見るか**を添える。動かなければ次の仮説へ
- 表現の可否は依頼側の決まりと専門家に。**個別の判断は専門家にご確認ください**

## よくある質問

### 元の原稿が長すぎて、六つの要素に分解するのに時間がかかります

長い原稿ほど、「その他」に入る文が多くなります。まず六つの要素に当たる文だけを拾い、残りは「その他」にまとめて、量だけを依頼側に伝えます。「六つの要素に当たるのは全体の一部で、残りは会社紹介と重複でした」と示すと、削る合意が取りやすくなります。分解に一時間以上かかるなら、原稿の問題ではなく、材料（要件の一枚・ターゲット像）が無い状態なので、聞き取りに戻ります。

### 依頼側が「うちの魅力をもっと書いてほしい」と言います

「得られるもの」の欄に、比べる相手との差が出る点だけを残す方針を伝えます。魅力を増やすと、読む人が仕事にたどり着く前に閉じる、という構造を説明します。依頼側が挙げる魅力は、一度全部書き出してもらい、「これは同業の他社にも書けますか」で一つずつ分けます。他社にも書ける魅力は削り、この会社だけの点を残します。削った魅力は、会社紹介ページや面接での説明に回します。

### 修正案を出したら、依頼側が「もっと大胆に変えてほしい」と言いました

「どこで止まっているか」を再確認します。大胆に変えたい理由が「応募が全く来ない」なら、見出しと冒頭を大きく変える案を追加で出します。理由が「なんとなく古い」なら、表現の問題ではなく、原稿の構成（六つの要素の欠け）が問題なので、欠けを足す案を先に見てもらいます。大胆さは、変える量ではなく、止まっている場所に効くかどうかで測ります。見出しの付け方は[求人タイトルの付け方](/media/fukugyo-skill-midashi/)に書いています。
