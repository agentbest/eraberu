本業が急に忙しくなり、副業で受けているスカウトの送信を、知人の人事経験者に一部やってもらえないかと考える。あるいは、受けた範囲の中に自分の得意でない工程があり、そこだけ他の人に回したい。結論を先に書くと、**人事の副業で受けた業務は、再委託を前提にしないのが基本です。回してよいのは、「契約書に再委託を認める条項がある、または禁止されていない」「依頼側に誰に何を回すかを伝えて了解を得た」「回す相手が情報の扱いで依頼側と同じ約束をする」の三つが揃ったときだけで、一つでも欠けるなら回しません。**忙しいときの逃げ道は、再委託ではなく、依頼側と範囲や稼働を見直すことです。業務委託の契約では、依頼側が「この人に頼む」と決めて契約しているので、黙って他の人に回すことは、一般に契約上の問題になると整理されています。個別の契約の解釈は、弁護士などの専門家にご確認ください。チームで受ける形にする話は[チームで動くときの分担](/media/fukugyo-chiimu/)に、複数人で最初から受ける形は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)にまとめています。

## 再委託を前提にしない理由

副業の案件で、受けた業務を他の人に回すことが問題になるのは、依頼側が「誰がやるか」を見て契約しているからです。

| 理由 | 何が起きるか |
|---|---|
| 依頼側は本人の経歴で決めている | 別の人が動くと、依頼側が選んだ前提が崩れる。担当が替わったのと同じ |
| 契約書に再委託の禁止が入っていることが多い | 業務委託の契約書には、一般に再委託を禁じるか、事前の書面の承諾を要する条項があると整理されている |
| 秘密保持は本人と結んでいる | 回した相手は秘密保持の対象外。候補者の情報がその人に渡った時点で、約束の外に出る |
| 媒体のアカウントは本人に発行されている | 回した相手が同じアカウントを使うと、媒体の規約に触れることがある |
| 責任の所在が曖昧になる | 回した相手のミスは、依頼側から見れば本人のミス。だが本人は内容を把握していない |

理由の要点は、「依頼側は人を選んでいる」ことです。副業の業務委託は、会社に頼むのではなく、その人に頼む形が多く、その人が動くことが契約の前提になっています。黙って他の人に回すと、依頼側が知ったときに、契約の話だけでなく信頼の話になります。依頼側から契約を切られる場面の一つがこれで、[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/)に書いた「理由が言われない終了」の中には、再委託が発覚したことが含まれることがあります。

## 契約書で見る条項

再委託を考える前に、依頼側と結んだ契約書を読みます。見る場所は決まっています。

| 条項 | 書かれていること | 読み方 |
|---|---|---|
| 再委託の条項 | 「乙は本業務を第三者に再委託してはならない」「甲の事前の書面による承諾なく」など | 禁止なら回さない。承諾があれば可なら、書面で承諾を取る手順に入る |
| 秘密保持の条項 | 情報を開示してよい相手の範囲 | 「本業務の遂行に必要な範囲の従業員」のような書き方なら、副業の個人には従業員がいないので、回す相手は対象外になりやすい |
| 個人情報の取り扱いの条項 | 候補者の情報を扱う人の範囲と、扱い方 | 回す相手が候補者の情報に触れるなら、依頼側の同意と、相手の約束が要る |
| 担当者の指定 | 業務を行う者として本人の名前が書かれているか | 書かれていれば、他の人が行うことは契約の前提から外れる |
| 契約の解除の条項 | 解除の理由に「再委託の禁止に違反したとき」が入っているか | 入っていれば、黙って回すことが解除の理由になる |

条項の要点は、「禁止されていないから回してよい」とは読まないことです。再委託の条項が無くても、秘密保持や個人情報の条項で、回す相手が情報を扱えない形になっていることが多く、実質的に回せません。条項の読み方に迷う場合は、契約書を持って専門家に相談してください。契約の内容を最初に確認する場面は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「作業の一部なら、依頼側に言わずに手伝ってもらっても問題ない」というものです。実際には、依頼側から見て「作業の一部」と「業務」の区別はありません。スカウトの送信を一通でも他の人が行えば、候補者の情報をその人が見たことになり、依頼側の情報管理の約束の外に出ます。作業の大小ではなく、依頼側の情報に触れる人が増えたかどうかで、依頼側は判断します。

依頼側に伝えたうえで手伝ってもらう形なら、了解が出ることは珍しくありません。依頼側の担当者は、稼働が回らないことより、知らないうちに人が増えていることを嫌います。「本業の繁忙で、この期間だけ送信の工程をこの人に手伝ってもらいたい。候補者の情報の扱いは同じ約束をさせる」と先に伝えれば、依頼側は判断できます。伝えずに回して後で分かるのと、伝えて断られるのでは、後者のほうが関係は続きます。エラベルは依頼側が担当者を見て選ぶ仕組みなので、選んだ人以外が動くときは、その前に依頼側へ伝えることをお願いしています。

## 依頼側に伝えて了解を得る手順

三つの条件が揃いそうなら、依頼側に伝えて了解を得ます。手順は、伝える内容を先に整理しておくと短く済みます。

| 手順 | 内容 |
|---|---|
| 一、回す工程と期間を限る | 「スカウトの検索と送信のうち、送信だけ」「来月末まで」のように、工程と期間を限って伝える。範囲全体を回すのは、再委託ではなく担当の交代 |
| 二、回す相手を伝える | 名前と、その工程の経験を伝える。依頼側が「この人なら」と判断できる材料を出す |
| 三、情報の扱いを揃える | 回す相手が、依頼側との秘密保持と同じ内容を守る約束をすることを伝える。相手と自分の間でも書面にする |
| 四、アカウントと連絡の窓口を決める | 媒体のアカウントは依頼側に相手の分を発行してもらう。依頼側との連絡は自分が窓口のまま |
| 五、書面で承諾をもらう | 契約書に「書面による承諾」とあれば、メールでもよいので文面で残す |
| 六、責任は自分に残る | 相手の工程の品質は自分が確認し、依頼側への報告は自分が出す |

手順の要点は、「一」の工程と期間を限ることです。範囲の全体を長期に回すのは、再委託ではなく担当の交代で、依頼側から見れば別の人と契約し直す話になります。一部の工程を限られた期間だけ回すなら、依頼側は自分が担当者であることを前提に判断できます。相手との間の取り決めをどう書くか、契約の形として問題がないかは、専門家にご確認ください。

## 情報の扱いで変わること

再委託で最も注意するのは、候補者と依頼側の情報が、自分以外の人に渡ることです。工程によって、渡る情報の量が違います。

| 回す工程 | 渡る情報 | 注意 |
|---|---|---|
| スカウトの検索（候補のリスト作り） | 媒体上の候補者のプロフィール | 媒体のアカウントを共有しない。相手の分を依頼側に発行してもらう |
| スカウトの送信 | 候補者のプロフィールと、依頼側の求人の情報 | 送信の文面に依頼側の内部の情報が入っていないか確認する |
| 応募者への一次対応 | 候補者の連絡先、履歴書、やり取りの履歴 | 個人情報の中心。回すなら、依頼側の個人情報の扱いの約束を相手にも適用する |
| 日程調整 | 候補者の連絡先と、依頼側の面接官の予定 | 依頼側の社内の情報に触れる。相手の連絡先が候補者に見える形になる |
| 記録の入力 | 候補者の評価と選考の状況 | 評価は最も慎重に扱う情報。回さないほうがよい |

情報の要点は、「候補者の連絡先と評価に触れる工程は回さない」ことです。検索のリスト作りのように、媒体上の公開情報の範囲で済む工程なら、相手の分のアカウントを発行してもらえば、渡る情報を限れます。一次対応や記録の入力は、候補者の個人情報の中心に触れるので、回すより、依頼側と稼働を見直すほうが安全です。情報の種類ごとの扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[情報の取り扱いと端末の分離](/media/fukugyo-security/)に書いています。

## 再委託せずに乗り切る方法

再委託を考えるのは、たいてい本業の繁忙で稼働が足りなくなったときです。再委託より先に、依頼側と範囲や稼働を見直す方法があります。

| 方法 | 内容 |
|---|---|
| 稼働を一時的に下げることを伝える | 「今月は週の稼働をこれだけに下げたい」と先に伝える。依頼側は、黙って遅れるより、先に言われるほうを選ぶ。[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/) |
| 工程の優先順位を依頼側と決める | 全部を薄くやるより、「送信は続け、記録の整理は来月に回す」のように優先を決める |
| 依頼側の社内に一時的に戻す | 依頼側に人事担当がいれば、一部の工程を期間限定で社内に戻してもらう |
| 依頼側に別の担当者を追加してもらう | 自分が回すのではなく、依頼側が別の外部の担当者を契約する。窓口を通していれば、窓口に相談する |
| 契約の更新の節目で範囲を直す | 恒常的に足りないなら、更新のときに範囲を小さくする。[契約期間の目安](/media/fukugyo-keiyaku-kikan/) |

方法の要点は、「先に伝える」ことです。再委託を考える段階は、すでに稼働が足りていない段階で、依頼側にはまだ見えていません。見える前に伝えれば、依頼側と一緒に方法を選べます。見えてから分かると、遅れの説明と再委託の発覚が重なり、信頼を失います。

### エラベルの見解

担当する側から見ると、再委託を考える人の多くは、受けた範囲が最初から一人の稼働に対して大きすぎます。本業が忙しくなる前提で範囲を決めていないので、繁忙期に入ると足りなくなり、誰かに回したくなります。順番として、範囲を決めるときに「本業が最も忙しい月でも回る量」を上限にしておけば、再委託を考える場面はほとんど来ません。

それでも足りなくなったときは、回す相手を探す前に、依頼側に稼働を下げることを伝える。依頼側が別の担当者を足す判断をするなら、窓口を通していればその窓口が候補を出せます。エラベルでは、依頼側が担当者を追加したいときは、いまの担当者を通さず、依頼側が新しく選ぶ形にしています。担当者が自分で人を連れてきて回すのではなく、依頼側が選び直す。この形なら、情報の扱いも契約も依頼側との間で整い、いまの担当者の責任の範囲も変わりません。

## まとめ

- 再委託は**前提にしない**。依頼側は人を選んで契約しており、黙って回すと契約と信頼の両方の問題になる
- 回してよいのは**契約書で禁止されていない・依頼側の了解がある・相手が情報の扱いで同じ約束をする**の三つが揃ったときだけ
- 契約書で見るのは**再委託・秘密保持・個人情報・担当者の指定・解除の条項**。禁止が無くても情報の条項で回せないことが多い
- 了解を得るなら**工程と期間を限る・相手を伝える・情報の扱いを揃える・アカウントを分ける・書面で残す・責任は自分に残す**
- **候補者の連絡先と評価に触れる工程は回さない**。回すなら媒体上の公開情報で済む工程まで

## よくある質問

### 家族に、送信の作業だけ手伝ってもらうのも再委託になりますか

家族であっても、自分以外の人が候補者の情報に触れれば、依頼側の秘密保持の約束の外に出ます。相手が誰かではなく、依頼側の情報に触れる人が増えたかどうかで考えます。手伝ってもらうなら、依頼側に伝えて了解を得る手順は同じです。家族だからと伝えずに手伝ってもらい、後で分かった場合の影響は、知人に回した場合と変わりません。

### 契約書に再委託の条項が無い場合は、回してよいですか

条項が無いことは、回してよいことを意味しません。秘密保持や個人情報の条項で、情報を扱える人が本人に限られていることが多く、その場合は実質的に回せません。条項が無く、情報の条項でも読み取れない場合でも、依頼側に伝えて了解を得てから回すのが安全です。契約書の読み方に迷う場合は、専門家にご確認ください。

### 依頼側から「誰かに手伝ってもらってよい」と口頭で言われました

口頭で言われた場合も、文面で残しておきます。「先日お話しした、〇〇の工程を〇〇さんに手伝ってもらう件、来月末までの期間で進めます。情報の扱いは同じ約束をさせます」のようにメールを送り、返信をもらえば、書面の承諾に近い形になります。契約書に「書面による承諾」とある場合は、メールで足りるかも含めて、依頼側に確認しておくと後で困りません。
