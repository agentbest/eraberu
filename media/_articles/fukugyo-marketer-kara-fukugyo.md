マーケティングの仕事をしてきた。広告の文面、数字の分析、顧客の経路の設計。人事の仕事はしたことがないが、採用も「人を集めて、選んで、動いてもらう」という点でマーケに似ている気がする。副業で人事に転身できるのか、何が売れるのか。結論を先に書くと、**マーケターの経験は、「候補者を顧客として見る」形で、そのまま採用に転用できます。売れるのは、「求人票とスカウト文面の改善」「採用の数字の設計と報告」「母集団の経路の設計」の三つです。ただし、「マーケの経験を人事に活かします」と抽象的に売ると、依頼側には伝わりません。「採用の〇〇の工程を、マーケの△△の技能で」と、工程と技能を結びつけて売ります。依頼側が頼むのは、マーケの経験ではなく、採用の工程です。**人事未経験の売り方は[人事未経験が副業でできること](/media/fukugyo-mikeiken-jinji-fukugyo/)に、未経験の区分は[人事未経験でも受けられる仕事はあるか](/media/fukugyo-mikeiken/)に、数字の見せ方は[数字で語る](/media/fukugyo-suuji/)にまとめています。

## この経歴の何が売れるか

マーケターの技能を、採用の工程に置き換えた棚卸しです。

| マーケの技能 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 読み手を決めて文面を書く | 求人票を「候補者が何を見て応募を決めるか」で書き直す | 求人票が社内の言葉で書かれていて、候補者に届いていない依頼側が多い |
| 短い文面で反応を得る | スカウト文面を、一通目で返信をもらう構成にする | スカウトの返信が来ない依頼側が多い |
| 数字で状態を見る（漏斗） | 応募、書類、面接、内定、入社の各段階の数を並べ、どこで落ちているかを見る | 「応募が少ない」としか見えていない依頼側に、落ちている段階を示せる |
| 数字を報告に落とす | 採用の状態を、依頼側の経営層に伝わる形で報告する | 採用の報告が感覚で語られている依頼側に、数字の報告の型を渡せる |
| 経路の設計 | 候補者がどこから来るか（媒体、紹介、直接応募、発信）を設計し、経路ごとに見る | 一つの媒体に頼っている依頼側に、経路の分散を提案できる |
| 試して直す習慣 | 求人票やスカウト文面を、複数の案で出し、反応で直す | 一度書いた求人票を直さない依頼側に、直す型を渡せる |
| 顧客の声を聞く | 辞退の理由、応募しなかった理由を聞き、文面と条件に反映する | 辞退の理由を聞いていない依頼側が多い |
| 発信の設計 | 会社の採用の発信（採用ページ、記事、SNS）を、候補者向けに設計する | 採用の発信が無い、または社内向けの言葉になっている依頼側 |

売れるものの要点は、「候補者を顧客として見る」という一つの視点で、マーケの技能がほぼ全部、採用の工程に置き換わることです。求人票は商品の説明、スカウト文面は初回の接触、採用の漏斗は顧客の獲得の漏斗、辞退の理由は顧客の離脱の理由。この置き換えができれば、人事の肩書きが無くても、依頼側にとっての価値は明確です。文章の技能は[文章力をどう磨くか](/media/fukugyo-writing/)に、数字の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に、データの扱いは[データを扱うスキル](/media/fukugyo-data-skill/)に書いています。

## 売りにくい点とその扱い

マーケターの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 採用の判断の経験が無い | 「候補者の良し悪しを判断できるのか」 | 判断を売らない。文面、数字、経路の工程を売り、候補者の判断は依頼側が持つと線を引く |
| 候補者を「顧客」と同じに扱う線 | 「候補者を数字だけで見て、一人の人として扱わないのでは」「個人情報を広告のデータのように扱うのでは」 | 候補者は顧客とは違う点を、最初に示す。個人情報の扱いの線を守る。数字は段階の数で見て、個人を数字で扱わない |
| 人事の仕組みと言葉を知らない | 「採用管理の仕組み、面接の進め方、内定の出し方が分からないのでは」 | 主要な工程と言葉を一通り学ぶ。分からないことは聞く。自分の範囲を文面と数字と経路に絞り、仕組みの運用は依頼側に置く |

扱い方の要点は、「候補者は顧客とは違う点を、最初に示す」ことです。マーケの視点は強みですが、依頼側は「候補者を数字だけで見る人」を警戒します。「候補者の個人情報は広告のデータとは違い、取得と利用の目的の範囲で扱います」「数字は段階の数で見ますが、一人一人の判断は御社が持ちます」と、最初に線を示せば、マーケの視点は強みとして受け取られます。個人情報の線は[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、判断の線は[業務範囲を書面で固める](/media/fukugyo-scope/)に、人事の仕組みの学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に整理しています。

### エラベルの見解

担当する側から見ると、マーケターから転身して続いている人と、最初の案件が取れない人の差は、「マーケの経験を人事に活かします」と言うか、「求人票を候補者の目線で書き直し、応募から入社までの段階の数で落ちているところを示します」と言うかです。前者は依頼側に「何をしてくれるのか分からない」と映り、後者は「その工程を頼める」と映ります。マーケの経験は、抽象的に語ると伝わらず、工程で語ると強く伝わります。

見ていて差がつくのは、採用の数字を「段階の数」で見せて、「個人の数字」で見せていないかです。マーケの習慣で、候補者一人一人に点数をつけて並べる形で報告すると、依頼側は「人を数字で扱う人」と感じ、警戒します。「応募から書類の通過までで落ちている」「面接の後に辞退が多い」と、段階の数で見せる人は、依頼側に「採用の構造が見えた」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、文面と数字と経路の工程を明確にし、候補者の扱いの線を示している担当者に、その工程を頼みたい依頼側がついています。マーケの転身は、視点の置き換えと、線の提示で始まります。

## 案件の探し方

マーケターから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 求人票の改善 | 文面の技能で入れる。判断は依頼側 | 「候補者の目線で求人票を書き直す」を範囲の一言に。自分が書いた広告の文面の実績を、求人票に置き換えて示す |
| スカウト文面の作成と改善 | 短い文面で反応を得る技能で入れる | 「一通目で返信をもらう構成」を示す |
| 採用の漏斗の設計と報告 | 数字の技能で入れる | 「段階の数で落ちているところを示す」を示す。数字は依頼側のものを使い、外部の数値を持ち込まない |
| 母集団の経路の設計 | 経路の技能で入れる | 「一つの媒体に頼らない経路の分散」を提案の形で |
| 採用の発信の設計 | 発信の技能で入れる | 「採用ページや記事を候補者向けに設計する」を示す |
| マーケ職の採用 | 自分の職種の候補者の目線が分かる | 「マーケ職の候補者が求人票のどこを見るか分かる」を示す。最初の案件に向く |

探し方の要点は、「マーケ職の採用から入る」ことです。自分の職種なら、候補者が何を見ているか、求人票のどこが響くか、スカウトのどの一言に反応するかが分かり、人事の経験が無くても依頼側にとって価値があります。マーケ職の採用で一件受け、求人票とスカウト文面と漏斗の型を作れば、他の職種にも広げられます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、発信からの案件は[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。マーケターの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 文面と数字と経路の技能の強さ | 技能が強ければ、その技能が要る工程では、人事経験者と同等以上に評価される | マーケの実績を、採用の工程に置き換えて示す |
| 採用の判断を含まない範囲 | 判断を含まない範囲は、判断を含む範囲より単価は下がる | 最初は判断を含まない範囲で、実績を作る |
| 成果物で受けやすい工程 | 求人票一本、スカウト文面一式、漏斗の報告の型、は成果物で受けやすい | 成果物で受けると、単価の議論が明確になる |
| 自分の職種の採用 | マーケ職の採用では、職種の理解が評価される | 他の職種より単価を下げない |
| 数字の報告の型 | 依頼側の経営層に伝わる報告の型は、依頼側にとって価値が高い | 型を作って残す形で、更新の根拠にする |
| 最初の案件 | 人事の実績が無いので、範囲を絞って小さく | 単価を下げるのではなく、範囲と時間を小さくする |

単価の要点は、「マーケの技能が要る工程では、人事経験者と同等以上に評価される」ことです。求人票の文面、スカウト文面、漏斗の設計は、人事の経験者でも得意な人は多くなく、マーケの技能を持つ人が入ると、依頼側の採用が目に見えて変わります。「人事未経験だから安く」ではなく、「この工程はマーケの技能で」と、工程の単価で受けます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に、型の残し方は[実績の積み上げ方](/media/fukugyo-jisseki-tsumu/)に整理しています。

## 始める順番

マーケターから人事の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、マーケの技能を、採用の工程に置き換えて書き出す | 文面、数字、経路、発信、試して直す、声を聞く |
| 二、候補者は顧客とは違う点を、自分の言葉で書く | 個人情報の扱い、判断の所在、一人一人の扱い |
| 三、主要な採用の工程と言葉を一通り学ぶ | 応募から入社までの流れ、面接の進め方、採用管理の仕組み |
| 四、範囲を、文面と数字と経路に絞る | 判断と仕組みの運用は依頼側 |
| 五、マーケ職の採用を、最初の範囲にする | 候補者の目線が分かる職種から |
| 六、「採用の〇〇の工程を、マーケの△△の技能で」の一言を作る | 「マーケの経験を人事に」とは言わない |
| 七、登録先に、範囲を工程で登録する | 求人票、スカウト文面、漏斗の報告、経路の設計 |
| 八、成果物で一件受け、型を残す | 求人票の型、スカウト文面の型、報告の型 |

順番の要点は、「二」の、候補者は顧客とは違う点を、自分の言葉で書いておくことです。マーケの視点で入る担当者への依頼側の懸念は、「候補者を数字だけで扱うのでは」の一点に集まります。この懸念に、最初の面談で自分の言葉で答えられれば、マーケの視点は懸念ではなく強みになります。書いておかないと、面談で聞かれたときに答えに詰まり、懸念が残ります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「マーケから人事への転身は、全く別の分野への挑戦だ」というものです。実際には、候補者を顧客として見れば、求人票は商品の説明、スカウトは初回の接触、漏斗は獲得の漏斗、辞退は離脱で、マーケの技能はほぼ全部、採用の工程に置き換わります。別の分野ではなく、同じ技能の別の応用です。ただ、候補者は顧客とは違う点があり、その線を示すことが、転身の条件です。

順番として、マーケの技能を採用の工程に置き換え、候補者は顧客とは違う点を自分の言葉で書き、採用の工程と言葉を学び、範囲を文面と数字と経路に絞り、マーケ職の採用から始め、工程と技能を結びつけた一言を作り、登録先に工程で登録し、成果物で一件受けて型を残す。この順番で、マーケからの転身は、「別の分野への挑戦」から「同じ技能の別の応用」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、文面と数字と経路の工程を明確にし、候補者の扱いの線を示している担当者に、その工程を頼みたい依頼側がついています。マーケの転身は、視点の置き換えと線の提示で始まります。

## まとめ

- マーケの技能は**「候補者を顧客として見る」形で採用に転用**できる。売れるのは**求人票とスカウト文面・採用の数字の設計と報告・母集団の経路の設計**
- **「マーケの経験を人事に」ではなく「採用の〇〇の工程を、マーケの△△の技能で」**と工程で売る
- 売りにくい点は**採用の判断・候補者の扱いの線・人事の仕組み**。判断は依頼側に置き、候補者は顧客とは違う点を最初に示す
- 数字は**段階の数で見せ、個人の数字で見せない**。個人情報の線を守る
- 案件は**マーケ職の採用から**。求人票・スカウト文面・漏斗の報告は成果物で受けやすい
- 単価は**マーケの技能が要る工程では人事経験者と同等以上**。「未経験だから安く」ではなく工程の単価で

## よくある質問

### マーケの数字の分析を、採用でもそのままやってよいですか

段階の数（応募、書類、面接、内定、入社）で落ちているところを見る分析は、そのまま使えます。避けるのは、候補者一人一人に点数をつけて並べる形と、個人情報を広告のデータのように扱う形です。候補者の情報は、取得と利用の目的の範囲で扱い、分析は段階の数で行い、個人の判断は依頼側が持ちます。数字の使い方は[数字で語る](/media/fukugyo-suuji/)に、個人情報の線は[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に整理しています。

### 依頼側から「採用のマーケティングを全部見てほしい」と言われました。受けてよいですか

「全部」は範囲が広すぎ、判断と仕組みの運用まで含んでしまいます。「求人票とスカウト文面の改善」「漏斗の設計と月次の報告」「経路の分散の提案」と、工程に分けて、最初は一つか二つで受けます。「全部」で受けると、候補者の判断や内定の出し方まで期待され、人事の経験が無い部分で崩れます。範囲を工程で絞り、成果が出たら次の工程を足す形にします。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、範囲の広がりへの対処は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に書いています。

### 人事の実績が無いので、プロフィールに書けることがありません

人事の実績ではなく、マーケの実績を採用の工程に置き換えて書きます。「広告の文面で反応を〇〇から△△に変えた」は、「文面の改善で反応を変えた経験。求人票とスカウト文面に応用」と書けます。「顧客の獲得の漏斗を設計し、落ちている段階を直した」は、「段階の数で落ちているところを見て直す経験。採用の漏斗に応用」と書けます。数値を書く場合は、自分の実績で、前の職場の情報を含まない範囲で。マーケの実績は、置き換えれば全部、採用の実績の根拠になります。書き方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。
