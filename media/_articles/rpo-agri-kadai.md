農業法人や生産者（露地、施設、畜産、加工と販売）が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。繁忙期の前に毎年ゼロから募集して、間に合わない。移住の希望や農業への憧れで来た人が、天候と体力と収入の型でずれて、一年で離れる。住居と移動と地域の生活の情報が求人票に無く、応募の前で止まる。通年の中核と季節の雇用と外国人の受け入れで経路と文面が違うのに、一つの求人票で募集している。経営者が現場に出ていて、応募への返事が遅れ、面接と体験の枠が取れない。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**農業業界の採用課題は、季節・実態・生活・雇用の形・枠の五つに分解し、自社の記録（毎年の募集の開始の時期と充足、離職の時期と理由、応募の前で止まった問い合わせ、雇用の形と経路ごとの応募、応募から返事までの日数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、繁忙期の前に慌てて集め、憧れで来た人が離れ、次の年にまた慌てる、という往復になります。代行に出す工程の切り分けは[農業業界の採用代行](/media/rpo-agri-rpo/)に書いています。ここでは、農業業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 季節 | 繁忙期の前に足りない。毎年同じ | 募集の開始の時期と充足。前の年に来た人の記録の有無 |
| 実態 | 憧れで来て、天候と体力と単調な期間と収入の型で離れる | 離職の時期と理由が「体力」「天候」「収入」「思っていたのと違う」 |
| 生活 | 問い合わせはあるが応募まで来ない。「住むところは」で止まる | 応募の前で止まった理由が「住居」「移動」「家族」 |
| 雇用の形 | 通年の中核が来ない。季節の人は来るが続かない。外国人の受け入れが整っていない | 雇用の形と経路ごとの応募と定着 |
| 枠 | 返事が数日後。面接と体験が繁忙期に入らない | 応募から返事までの日数。段階ごとの日数 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 募集の開始の時期と充足、前の年に来た人の記録 | 毎年同じ時期に足りず記録が無ければ季節。逆算と記録が先 |
| 二 | 離職の時期と理由 | 「体力」「天候」「収入」「違う」なら実態 |
| 三 | 応募の前で止まった理由 | 「住居」「移動」「家族」なら生活 |
| 四 | 雇用の形と経路ごとの応募と定着 | 偏りがあれば雇用の形 |
| 五 | 応募から返事までの日数 | 数日後なら枠 |

一が最初なのは、農業は季節で動くため、逆算と記録が無いと、他の四つを直しても繁忙期に間に合わないからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

農業業界で最も多い詰まりは「季節」で、しかも毎年同じことが起きているのに、前の年に来た人の記録が経営者の頭の中にしか無いことです。繁忙期の前に募集を出し、集まった人で乗り切り、閑散期に離れ、次の年にまた募集を出す。前の年に来た人のうち「また来たい」人がいても、連絡先と作業の記録が会社に無く、声をかける型が無い。「毎年来る人の記録」（誰が、どの作業を、どれくらい、どう働いたか、また来たいか）を会社に置き、繁忙期の前に定期の連絡をする。それだけで、毎年の募集の負担が変わり、作業を知っている人が戻ります。エラベルで担当者を選ぶ企業には、「去年の繁忙期に来た人の一覧は、会社にありますか」を、私たちから先に聞いています。無ければ、代行の前に記録の型です。過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 季節の課題：毎年ゼロから集める

| 状態 | 直し方 |
|---|---|
| 繁忙期の直前に募集を出す | 作付けと出荷の計画から逆算し、繁忙期の何か月前に何名の応募が要るかを決めて始める |
| 前の年に来た人の記録が無い | 作業・期間・働き方・また来たいかを記録し、会社に置く |
| 毎年来る人に声をかける型が無い | 繁忙期の前に定期の連絡。作業と期間と住居を先に伝える |
| 閑散期に離れる | 通年の中核と季節の雇用を分けて設計する。閑散期の作業（加工、販売、整備）で通年にできる部分を見る |

人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

## 実態の課題：憧れで来て、実態で離れる

| 求人票に無いこと | 書き方 |
|---|---|
| 天候と体力 | 「暑さ寒さ、雨の日の作業、一日の体の使い方」の実態 |
| 作業の一日と単調な期間 | 「一日の流れと、同じ作業が続く期間」の実態 |
| 収入の型 | 「通年か季節か、固定か出来高か、繁忙期と閑散期の差」の実態 |
| 繁忙期の稼働 | 「繁忙期の一日の長さと休みの取り方」の実態 |
| 最初の一か月 | 「最初の作業、教える人、体を慣らす期間」の実態 |
| 離職の状況 | 「昨年は何名が離れ、理由はこうだった」を面接で語れるか |

体験を選考の段に置き、繁忙期の作業を一日でも経験してもらうと、入社後のずれが減ります。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 生活の課題：住居と移動と地域の情報が無い

| 求人票に無いこと | 書き方 |
|---|---|
| 住居 | 「会社が用意するか、本人が探すか。用意する場合の形と場所」 |
| 移動 | 「車が要るか、会社の車があるか、最寄りまでの手段」 |
| 地域の生活 | 「買い物、病院、学校、役場までの距離と手段」 |
| 家族 | 「家族と来られるか、家族の仕事と学校の情報」 |
| 地域との関係 | 「最初の三か月に会社がつなぐ場（集まり、行事）」 |
| 本人が用意するもの | 「会社が用意するものと、本人が用意するもの」を分けて |

生活の情報を一枚にして求人票に添えると、応募の前で止まっていた人が応募まで来ます。

### エラベルの見解

農業業界で見落とされやすいのは「雇用の形」で経路と文面と受け入れが違うことです。通年の中核は、長く働く人で、農業の学校と移住の窓口と経験者の経路から来て、育成と生活の設計で決まります。季節の雇用は、毎年来る人と新しい人で、期間と作業と住居で決まります。外国人の受け入れは、在留の整理が前提で、受け入れの体制で決まります。全部を「農作業スタッフ募集」の一本で出すと、通年の中核に向けた文面で季節の人が来ず、季節の文面で中核が来ません。雇用の形ごとに求人票と経路と受け入れを分け、形ごとに応募と定着を記録する。在留と契約の形は、法令上の整理があると一般に整理されているため、会社と専門家で整理し、個別の判断は専門家にご確認ください。エラベルで担当者を選ぶ企業には、「通年と季節と外国人で、求人票と経路を分けていますか」を、私たちから先に聞いています。分けていなければ、経路を増やす前に分け方です。

## 雇用の形の課題：通年・季節・外国人で違う

| 雇用の形 | 動く理由 | 合う経路 | 受け入れの要 |
|---|---|---|---|
| 通年の中核 | 農業で生きる、育成、独立の道、生活の設計 | 農業の学校、移住の窓口、経験者の経路、紹介 | 育成の型、生活の立ち上げ、地域とのつなぎ |
| 季節の雇用 | 期間と作業と住居、他の季節の仕事との組み合わせ | 毎年来る人、季節の経路、地域の掲載型、知人 | 最初の一週間の作業、住居、期間の終わりの連絡 |
| 外国人の受け入れ | 在留の形に沿う。受け入れの体制 | 整理された形に沿った経路 | 生活の立ち上げ、言葉、地域とのつなぎ。判断は会社と専門家 |
| 加工と販売 | 接客と企画、農業の外からの転身 | 隣接の職種に届く経路、地域の掲載型 | 商品と現場の理解 |

雇用の形ごとに求人票と経路を分け、形ごとに応募と定着を記録します。外国人の受け入れの手順は[外国人採用の実務の進め方](/media/rpo-task-gaikokujin-saiyo-susumekata/)に書いています。

## 枠の課題：経営者が現場に出ている

| 状態 | 直し方 |
|---|---|
| 応募への返事が数日後 | 一次対応を外に出す。返事は翌営業日中 |
| 面接と体験が繁忙期に入らない | 朝の作業の前、雨の日、オンライン、の枠を週に一つ先に預かる |
| 面接と体験が別の日 | 同じ日に組む。遠方の候補者は一泊で体験と面接と地域の案内を組む |
| 経営者が全段に出る | 一次（書類の照合と一次対応と生活の情報の案内）を外に出し、経営者は面接と体験と受け入れだけ |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 季節 | 毎年来る人の記録の型、定期の連絡、逆算の運用 | 作付けと出荷の計画の共有、通年と季節の分け方 |
| 実態 | 求人票に落とす作業、体験の日程 | 実態を語る。繁忙期の稼働と収入の型を決める |
| 生活 | 生活の情報を一枚にする作業、案内 | 住居と車の用意、地域とのつなぎ |
| 雇用の形 | 形ごとの求人票の作り直しと経路の運用 | 形の決定と在留・契約の整理（会社と専門家） |
| 枠 | 一次対応、日程の運用 | 枠の形を変えて出す |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[農業業界で採用代行が機能する条件・機能しない条件](/media/rpo-agri-jirei/)に書いています。

## まとめ

- 「採れない」には**季節・実態・生活・雇用の形・枠**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は募集の開始の時期と、前の年に来た人の記録
- 最も多い詰まりは**季節**で、毎年同じなのに記録が経営者の頭の中。会社に置いて定期の連絡
- 実態（天候・体力・単調な期間・収入の型）を**先に出し、体験を段に**
- **生活の情報を一枚にして求人票に添える**
- 雇用の形ごとに**求人票と経路と受け入れを分ける**。在留・契約の形は会社と専門家。個別の判断は専門家にご確認ください
- 枠は**朝の作業の前・雨の日・オンラインで週に一つ**先に預かる

## よくある質問

### 農業は人気が無いので、自社だけでは直せないのではないですか

同じ地域で毎年の募集が落ち着き、移住者が定着している法人はあります。違いは、毎年来る人の記録を持っているか、実態を先に出しているか、生活の情報を添えているか、雇用の形で分けているか、返事が速いか、です。「農業は人気が無い」にすると、直す場所が消えます。五つを記録で確かめ、一つずつ直しても採れないなら、条件の判断に進みますが、それは五つを確かめた後です。

### 移住の希望者は多いのに、応募まで来ません

応募の前で止まる理由を問い合わせの記録で分けます。「住むところが分からない」「車が要るか分からない」「家族の仕事と学校が分からない」なら生活の情報の不足で、一枚にして添えるだけで応募まで来る人が増えます。「収入が分からない」なら実態の不足です。問い合わせに返事が遅れているなら枠の問題です。止まる理由を分けずに「移住者は本気でない」と片付けると、直せる部分が消えます。

### 外国人を受け入れたいのですが、何から始めればよいですか

在留の形と受け入れの体制の判断は、法令上の整理があると一般に整理されているため、会社と専門家（行政書士等）で整理するところからです。個別の判断は専門家にご確認ください。整理ができてから、整理された形に沿った経路と求人票と受け入れ（生活の立ち上げ、言葉、地域とのつなぎ）を作ります。代行は整理された形に沿った運用と記録を担い、判断には踏み込みません。受け入れの分け方は[外国人採用に踏み出せない](/media/rpo-gaikokujin/)に書いています。
