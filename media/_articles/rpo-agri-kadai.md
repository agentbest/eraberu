農業法人や生産者の採用課題は、季節ごとの必要人数、作業と条件の説明、住居・移動等の生活情報、通年と季節の雇用、返信・面談の体制などに分けて確認できます。これらは確認の観点であり、原因が五つのどれか一つに限られるわけではありません。募集の到達と応募・辞退、職務条件、未回答と経過日数、採用期限を一緒に見て、緊急度と影響に応じて並行して直す工程も決めます。代行に出す工程の切り分けは[農業業界の採用代行](/media/rpo-agri-rpo/)に書いています。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 季節 | 繁忙期の前に足りない。毎年同じ | 募集の開始の時期と充足。前の年に来た人の記録の有無 |
| 実態 | 憧れで来て、天候と体力と単調な期間と収入の型で離れる | 離職の時期と理由が「体力」「天候」「収入」「思っていたのと違う」 |
| 生活 | 問い合わせはあるが応募まで来ない。「住むところは」で止まる | 応募の前で止まった理由が「住居」「移動」「家族」 |
| 雇用の形 | 通年の中核が来ない。季節の人は来るが続かない。外国人の受け入れが整っていない | 雇用の形と経路ごとの応募と定着 |
| 枠 | 返事が数日後。面接と体験が繁忙期に入らない | 応募から返事までの日数。段階ごとの日数 |

複数の要因が同時に影響することがあります。本人が伝えた理由と推測・未確認を分け、記録の件数・期間と職務条件を添えます。原因を一つに確定するまで対応を待たず、未返信の解消や条件・掲載内容の確認など、急ぐ作業と詳しく調べる作業を分担します。

## 記録と合わせて確認する観点

| 観点 | 確認する記録 | 追加で確かめること |
|---|---|---|
| 季節と人数 | 募集開始と必要人数・期限、過去の充足 | 計画・条件と応募経路、過去候補の連絡意向 |
| 作業と条件 | 辞退・離職の理由、事前説明と本人の理解 | 職務実態と条件の差、未回答や受け入れ体制 |
| 生活情報 | 問い合わせと回答、止まった段階 | 情報不足か用意・条件自体の不一致か |
| 雇用区分と経路 | 通年・季節等の応募と選考の件数 | 求人内容、経路の到達、職務との適合 |
| 返信と面談 | 受付・返信・承認・日程確定までの時点 | 担当と不在時、面談枠、候補者の都合 |

繁忙期が近い場合は募集計画の確認を急ぎますが、いつも季節の課題から順に直すとは限りません。条件と求人に不一致がある、未返信がたまっているなどの場合は、候補者への影響が大きい工程を先に修正します。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

季節の採用を確認するときは、前年の必要人数・募集開始・充足、再び働く意向と連絡条件を記録します。業界全体で季節の課題が最も多いと断定せず、自社でどの工程が止まったかを確かめます。過去に働いた人への連絡も、本人の希望、今回の仕事と条件、情報の保存・利用条件を確認して計画し、戻る人数を保証するものとしません。過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 季節の課題：毎年ゼロから集める

| 状態 | 直し方 |
|---|---|
| 繁忙期の直前に募集を出す | 作付けと出荷の計画から逆算し、繁忙期の何か月前に何名の応募が要るかを決めて始める |
| 前の年に来た人の記録が無い | 作業・期間・働き方・また来たいかを記録し、会社に置く |
| 毎年来る人に声をかける型が無い | 繁忙期の前に定期の連絡。作業と期間と住居を先に伝える |
| 閑散期に離れる | 通年の中核と季節の雇用を分けて設計する。閑散期の作業（加工、販売、整備）で通年にできる部分を見る |

人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

## 実態の課題：憧れで来て、実態で離れる

| 求人票に無いこと | 書き方 |
|---|---|
| 天候と体力 | 「暑さ寒さ、雨の日の作業、一日の体の使い方」の実態 |
| 作業の一日と単調な期間 | 「一日の流れと、同じ作業が続く期間」の実態 |
| 収入の型 | 「通年か季節か、固定か出来高か、繁忙期と閑散期の差」の実態 |
| 繁忙期の稼働 | 「繁忙期の一日の長さと休みの取り方」の実態 |
| 最初の一か月 | 「最初の作業、教える人、体を慣らす期間」の実態 |
| 離職の状況 | 「昨年は何名が離れ、理由はこうだった」を面接で語れるか |

見学・体験を設ける場合は、目的・内容・日程と実施担当、本人の意向、費用と実施条件を確認します。一律に繁忙期の一日作業を求めず、職務理解に必要な方法を現場と候補者の状況に合わせて検討します。実施すれば定着が改善すると保証せず、説明と本人の理解、入社後のずれを記録します。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 生活の課題：住居と移動と地域の情報が無い

| 求人票に無いこと | 書き方 |
|---|---|
| 住居 | 「会社が用意するか、本人が探すか。用意する場合の形と場所」 |
| 移動 | 「車が要るか、会社の車があるか、最寄りまでの手段」 |
| 地域の生活 | 「買い物、病院、学校、役場までの距離と手段」 |
| 家族 | 「家族と来られるか、家族の仕事と学校の情報」 |
| 地域との関係 | 「最初の三か月に会社がつなぐ場（集まり、行事）」 |
| 本人が用意するもの | 「会社が用意するものと、本人が用意するもの」を分けて |

生活の情報をまとめる際は、会社が用意するものと本人が用意するもの、費用・利用条件と確認先を分けます。情報を一枚渡せば応募が増えるとは限らず、実際の住まい・移動や収入の条件が本人に合うかも確認します。案内後に残った質問と応募・辞退の理由を記録して見直します。

### エラベルの見解

農業業界で見落とされやすいのは「雇用の形」で経路と文面と受け入れが違うことです。通年の中核は、長く働く人で、農業の学校と移住の窓口と経験者の経路から来て、育成と生活の設計で決まります。季節の雇用は、毎年来る人と新しい人で、期間と作業と住居で決まります。外国人の受け入れは、在留の整理が前提で、受け入れの体制で決まります。全部を「農作業スタッフ募集」の一本で出すと、通年の中核に向けた文面で季節の人が来ず、季節の文面で中核が来ません。雇用の形ごとに求人票と経路と受け入れを分け、形ごとに応募と定着を記録する。在留と契約の形は、法令上の整理があると一般に整理されているため、会社と専門家で整理し、個別の判断は専門家にご確認ください。分けていなければ、経路を増やす前に分け方です。

## 雇用の形の課題：通年・季節・外国人で違う

| 雇用の形 | 動く理由 | 合う経路 | 受け入れの要 |
|---|---|---|---|
| 通年の中核 | 農業で生きる、育成、独立の道、生活の設計 | 農業の学校、移住の窓口、経験者の経路、紹介 | 育成の型、生活の立ち上げ、地域とのつなぎ |
| 季節の雇用 | 期間と作業と住居、他の季節の仕事との組み合わせ | 毎年来る人、季節の経路、地域の掲載型、知人 | 最初の一週間の作業、住居、期間の終わりの連絡 |
| 外国人の受け入れ | 在留の形に沿う。受け入れの体制 | 整理された形に沿った経路 | 生活の立ち上げ、言葉、地域とのつなぎ。判断は会社と専門家 |
| 加工と販売 | 接客と企画、農業の外からの転身 | 隣接の職種に届く経路、地域の掲載型 | 商品と現場の理解 |

雇用の形ごとに求人票と経路を分け、形ごとに応募と定着を記録します。外国人の受け入れの手順は[外国人採用の実務の進め方](/media/rpo-task-gaikokujin-saiyo-susumekata/)に書いています。

## 枠の課題：経営者が現場に出ている

| 状態 | 直し方 |
|---|---|
| 応募への返事が数日後 | 一次対応を外に出す。返事は翌営業日中 |
| 面接と体験が繁忙期に入らない | 朝の作業の前、雨の日、オンライン、の枠を週に一つ先に預かる |
| 面接と体験が別の日 | 同じ日に組む。遠方の候補者は一泊で体験と面接と地域の案内を組む |
| 経営者が全段に出る | 一次（書類の照合と一次対応と生活の情報の案内）を外に出し、経営者は面接と体験と受け入れだけ |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 季節 | 毎年来る人の記録の型、定期の連絡、逆算の運用 | 作付けと出荷の計画の共有、通年と季節の分け方 |
| 実態 | 求人票に落とす作業、体験の日程 | 実態を語る。繁忙期の稼働と収入の型を決める |
| 生活 | 生活の情報を一枚にする作業、案内 | 住居と車の用意、地域とのつなぎ |
| 雇用の形 | 形ごとの求人票の作り直しと経路の運用 | 形の決定と在留・契約の整理（会社と専門家） |
| 枠 | 一次対応、日程の運用 | 枠の形を変えて出す |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[農業業界で採用代行が機能する条件・機能しない条件](/media/rpo-agri-jirei/)に書いています。

## まとめ

- 季節・作業と条件・生活情報・雇用区分・返信体制を確認の観点として使う
- 原因を一つと決めず、本人の理由と未確認を分け、期間と件数をそろえる
- 採用期限と候補者への影響から、急ぐ作業と詳しく調べる作業を分担する
- 過去候補への連絡は本人の意向と保存・利用条件、今回の仕事を確認する
- 情報の不足と条件そのものの不一致を分け、作業・生活の実態を伝える
- 在留・資格・契約の個別判断は専門家との分担を確認する
- 見学体験と面談は実施条件・目的・担当と本人の都合をそろえる

## よくある質問

### 農業は人気が無いので、自社だけでは直せないのではないですか

地域や職務の候補者数、条件、採用期限など、自社だけで変えにくい要因もあります。まず到達・応募と辞退、条件と回答・日程の記録を分け、改善できる工程と経営判断が必要な条件を並行して確認します。すべての工程を順に直し終えるまで条件や別の採用経路の検討を待つ必要はありません。

### 移住の希望者は多いのに、応募まで来ません

本人が伝えた理由と未回答を記録し、情報がないのか、住まい・移動や収入等の実際の条件が合わないのかを分けます。生活情報をまとめただけで応募が増えると決めず、用意できる内容と費用・条件を説明し、回答後に残った質問と応募・辞退を確認します。返信が遅い場合は担当と承認・不在時の体制も並行して見直します。

### 外国人を受け入れたいのですが、何から始めればよいですか

在留の形と受け入れの体制の判断は、法令上の整理があると一般に整理されているため、会社と専門家（行政書士等）で整理するところからです。個別の判断は専門家にご確認ください。整理ができてから、整理された形に沿った経路と求人票と受け入れ（生活の立ち上げ、言葉、地域とのつなぎ）を作ります。代行は整理された形に沿った運用と記録を担い、判断には踏み込みません。受け入れの分け方は[外国人採用に踏み出せない](/media/rpo-gaikokujin/)に書いています。
