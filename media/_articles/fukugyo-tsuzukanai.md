副業を始めて三か月。最初は張り切っていたが、本業が忙しくなって稼働が落ち、案件の更新を断り、そのまま止まっている。周りの続いている人と自分の何が違うのかが分からない。結論を先に書くと、**人事の副業が続かない理由は、人事の能力ではなく、「稼働の上限を決めていない」「範囲を一言で言えない」「記録を残していない」「本業と副業を混ぜている」「一件目の経験で副業そのものを判断している」の五つに、ほぼ収まります。どれも、始める前か、止まりかけた時点で直せます。**続いている人は、人事の経験が長いのではなく、この五つを最初に整えている人です。信頼を積む行動は[信頼を積む小さな行動](/media/fukugyo-shinrai/)に、向いている人の特徴は[人事の副業に向いている人](/media/fukugyo-tekisei/)に、向いていない人の特徴は[向いていない人](/media/fukugyo-mukanai/)にまとめています。

## 続かない理由が能力ではない理由

止まった人の多くは「自分には向いていなかった」と結論づけますが、止まり方を見ると、能力とは別のところで止まっています。

| 止まり方 | 本人の解釈 | 実際に起きていたこと |
|---|---|---|
| 本業が忙しくなって止まった | 「両立は無理だった」 | 繁忙期を織り込まずに稼働を決めていた。繁忙期に枠が消えた |
| 案件が来なくなって止まった | 「需要が無かった」 | 範囲が「採用全般」で、依頼側も紹介者も何を頼めるか分からなかった |
| 依頼側と合わなくて止まった | 「副業は人間関係が難しい」 | 一件目の依頼側との相性を、副業そのものの相性と取り違えた |
| 収入が見合わなくて止まった | 「割に合わない」 | 稼働の記録が無く、実際の時間単価が分からないまま安く受け続けた |
| 疲れて止まった | 「体力が持たない」 | 本業の時間と副業の時間が混ざり、休む時間が消えていた |

理由の要点は、「能力の問題に見えるものの多くが、準備の問題である」ことです。「両立は無理だった」は、繁忙期を織り込めば両立できたかもしれず、「需要が無かった」は、範囲を一言にすれば声がかかったかもしれません。能力の問題だと結論づけると、直せるものを直さずに終わります。

## 五つの共通点と直し方

五つの共通点は、それぞれ直し方が決まっています。

| 共通点 | 何が起きるか | 直し方 |
|---|---|---|
| 一、稼働の上限を決めていない | 案件が来るたびに受け、本業の繁忙期に枠が消え、全部が止まる | 本業の繁忙期でも守れる週の枠を先に決め、枠に入る案件だけ受ける。[稼働時間の上限](/media/fukugyo-kadou-jikan/) |
| 二、範囲を一言で言えない | 依頼側も紹介者も何を頼めるか分からず、声がかからない。来た案件が範囲と合わず、疲れる | 「スカウトの運用と求人票」のように、工程で二つか三つに絞る。[受ける範囲の決め方](/media/fukugyo-scope/) |
| 三、記録を残していない | 稼働の実態が分からず、安く受け続ける。更新のときに根拠が無い。実績が書けない | 稼働ログと判断のメモを、初日から。[稼働ログの付け方](/media/fukugyo-log/) |
| 四、本業と副業を混ぜている | 本業の時間に副業の連絡を見て、副業の時間に本業を引きずり、休む時間が消える。情報も混ざる | 端末・アカウント・時間を分ける。本業の時間中は副業に触れない。[情報の取り扱いと端末の分離](/media/fukugyo-security/) |
| 五、一件目で副業そのものを判断する | 一件目の依頼側との相性や結果を、副業の向き不向きと取り違え、二件目に行かない | 一件目は「型を覚える一件」と決め、判断は三件目まで保留する。[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/) |

五つの要点は、「一」の稼働の上限が、他の四つの土台になることです。上限が決まっていれば、範囲もそれに合わせて絞れ、記録も上限と比べるために付け、本業との線も上限を守るために引け、一件目も上限の中で試せます。上限が無いと、他の四つを整えても、繁忙期に全部が崩れます。

### エラベルの見解

相談で最も多い思い込みは、「続かなかったのは、人事の経験が足りなかったからだ」というものです。実際には、登録して数か月で止まった方と、数年続いている方を比べると、人事の経験の年数に差はほとんどありません。差があるのは、最初に稼働の上限を決めたか、範囲を一言にしたか、記録を付けたか、の三つです。経験が長くても、この三つが無い方は止まり、経験が浅くても、三つがある方は続いています。

見ていて差がつくのは、止まりかけたときの解釈です。続いている方は、本業が忙しくなったとき、「今月は稼働を下げる」と依頼側に伝えて枠を守り、忙しさが過ぎたら戻しています。止まった方は、同じ状況で「副業は無理だった」と解釈し、案件を終え、その後も戻っていません。同じ出来事が、片方では「稼働の調整」、もう片方では「副業の終わり」になっています。エラベルでは、登録の時点で稼働の上限と範囲を聞き、その中で案件を提示していますが、それは上限と範囲が続くための土台だからです。

## 止まる前に出る兆し

止まる人には、止まる数週間前から、共通の兆しが出ています。兆しの段階で気づけば、直せます。

| 兆し | 何が起きているか | 直し方 |
|---|---|---|
| 稼働ログを付けなくなった | 記録の習慣が崩れ、実態が見えなくなっている | その日から付け直す。抜けた分は埋めない |
| 依頼側への返信が翌日になり始めた | 副業の枠が本業に侵食されている | 枠を見直す。返信の時間を依頼側に伝え直す |
| 「今週は無理だが来週は」が続いている | 遅れを次週に送り続けている | 依頼側に稼働を下げると伝える。[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/) |
| 副業のことを考えると気が重い | 範囲が合わない案件を受けているか、稼働が上限を超えている | 案件の範囲と稼働を見直す。合わないなら更新の節目で終える。[合わない案件の見分け方](/media/fukugyo-awanai-anken/) |
| 本業の時間中に副業の連絡を見ている | 本業と副業の線が消えている | 本業の時間中は副業の端末を開かない、と決め直す |
| 休みの日が無くなった | 本業と副業で週の全部が埋まっている | 予備の枠を空け、休む日を先に置く。[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/) |
| 「副業は向いていないかも」と思い始めた | 一件目の結果や相性を、副業全体に広げている | 一件目の何が合わなかったかを、範囲・稼働・依頼側の相性に分けて見る |

兆しの要点は、「稼働ログを付けなくなった」が最初に出ることです。記録が止まるのは、稼働が枠を超えて、記録する余裕が消えたか、記録を見たくない状態になったかのどちらかです。ログが止まったら、それ自体を「上限を超えている合図」として扱い、稼働を見直します。

## 止まりかけたときの立て直し

兆しが出て、止まりかけたときの立て直しの順番です。案件を減らす前に、やることがあります。

| 手順 | 内容 |
|---|---|
| 一、稼働ログで実態を見る | 先月と今月の稼働を、工程ごとに見る。どこが増えているか。記憶ではなく記録で |
| 二、増えている原因を分ける | 本業の繁忙か、範囲の広がりか、案件の数か、自分の見積もりの甘さか |
| 三、依頼側に伝える | 「〇月は稼働を下げたい」と、先に伝える。黙って遅らせない。[遅れそうなときの連絡](/media/fukugyo-okure-renraku/) |
| 四、範囲か稼働を直す | 範囲の広がりなら範囲を戻す。案件の数なら更新の節目で減らす。見積もりの甘さなら次の期限に余裕を |
| 五、休む日を先に置く | 副業の枠を減らすとき、減らした分を休む日にする。別の案件で埋めない |
| 六、止めるかどうかは、直した後に決める | 直しても回らないなら、案件を減らすか、一度止める。直す前に止めない |

立て直しの要点は、「六」の、直す前に止めないことです。止まりかけたときに、そのまま止めると、「副業は無理だった」という結論だけが残り、次に始めるときも同じところで止まります。直してから止めれば、「稼働の上限をこう決めれば回る」という知見が残り、再開のときに使えます。範囲の戻し方は[範囲が広がっていくとき](/media/fukugyo-scope-creep/)に、更新の節目での見直しは[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。

## 一度止めた後に再開する形

一度止めた人が再開するとき、前と同じ形で始めると、同じところで止まります。再開の形を変えます。

| 前に止まった原因 | 再開の形 |
|---|---|
| 本業の繁忙で止まった | 繁忙期の月を先に決め、その月は稼働を落とすと最初から依頼側に伝える形で受ける |
| 案件が来なくて止まった | 範囲を一言にし、登録先のプロフィールと経歴の場所を同じ言葉にしてから再開する。[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/) |
| 依頼側と合わなくて止まった | 合わなかった点（範囲、稼働、依頼側の体制）を言葉にし、次はその点を契約の前に確認する |
| 収入が見合わなくて止まった | 稼働ログを付け、実際の時間単価を見てから単価を決める。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) |
| 疲れて止まった | 前より小さい枠で始める。休む日を先に置く。案件は一件から |
| 何となく止まった | 五つの共通点のどれに当たっていたかを見る。当たっていたものを直してから |

再開の要点は、「前より小さく始める」ことです。止まった経験があると、「今度こそ」と大きく始めがちですが、止まった原因を直した効果は、小さく始めたほうが確かめやすい。小さく始めて回ることを確かめ、それから広げます。登録先に再登録するときは、止まっていた期間のことを気にする必要はなく、範囲と稼働を今の状態で書き直せば足ります。再開の考え方は[次の案件へ広げる](/media/fukugyo-tsugi-e/)にも書いています。

### エラベルの見解

担当する側から見ると、長く続いている人は、止まりかけたことが無い人ではなく、止まりかけたときに「副業の終わり」ではなく「稼働の調整」として扱った人です。本業が忙しくなれば稼働を下げ、案件が合わなければ更新で終え、疲れれば枠を減らす。そのたびに依頼側に伝え、記録を残し、落ち着いたら戻す。この繰り返しが、数年の継続になっています。

順番として、始める前に稼働の上限と範囲を決め、初日から記録を付け、本業と分け、一件目を「型を覚える一件」と決める。止まりかけたら、ログで実態を見て、原因を分け、依頼側に伝え、範囲か稼働を直し、休む日を置き、それでも回らないなら減らす。この順番で、副業は「続けるもの」ではなく「調整しながら回すもの」になります。エラベルでは、登録の際に稼働の上限と範囲を聞き、止まりかけたときも窓口を通して依頼側と稼働を調整できる形にしています。続かないのは、能力ではなく、調整の仕組みが無いことが原因です。

## まとめ

- 続かない理由は能力ではなく**稼働の上限を決めていない・範囲を言えない・記録が無い・本業と混ぜる・一件目で判断する**の五つ
- **稼働の上限が他の四つの土台**。繁忙期でも守れる枠を先に決める
- 止まる兆しは**ログが止まる・返信が翌日になる・「来週は」が続く・気が重い・本業中に副業を見る・休みが消える・「向いていないかも」**
- 立て直しは**ログで実態を見る→原因を分ける→依頼側に伝える→範囲か稼働を直す→休む日を置く→それでも回らないなら減らす**。直す前に止めない
- 再開は**前より小さく**。止まった原因を直した形で、一件から
- 止まりかけたときの解釈が分かれ目。**「副業の終わり」ではなく「稼働の調整」**として扱う

## よくある質問

### 一件目の依頼側と合わず、副業そのものが向いていない気がします

一件目の「合わなかった」を、範囲・稼働・依頼側の体制の三つに分けて見ます。範囲が合わなかったなら範囲の問題、稼働が合わなかったなら枠の問題、依頼側の体制（判断が遅い、担当者が変わる）が合わなかったなら依頼側の問題で、どれも副業の向き不向きではありません。三つのどれにも当たらず、人事の業務そのものが合わないと感じるなら、それが向き不向きの話です。一件目で判断せず、三件目まで保留すると、区別がつきます。

### 本業が異動で忙しくなり、当分は稼働が取れません。止めるしかないですか

止めるのではなく、「休止」の形にします。依頼側には「〇月まで稼働を止め、〇月に再開の見込み」と伝え、案件は更新の節目で一度終えるか、依頼側と相談して休止します。登録先には、稼働の条件を「〇月以降なら」に書き換えておけば、その時期に声がかかります。止めると再開の入口が消えますが、休止なら残ります。休止の伝え方は[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/)に整理しています。

### 続いている人は、どのくらいの稼働で回しているのですか

人によって違いますが、続いている人に共通するのは、稼働の量ではなく、「本業の繁忙期でも守れる枠」で決めていることです。週に数時間でも、それが繁忙期でも守れる量なら続き、週に多くの時間を取っていても、閑散期の量で決めていれば繁忙期に止まります。自分の稼働は、他の人と比べず、自分の本業の最も忙しい月を基準に決めます。決め方は[稼働時間の上限](/media/fukugyo-kadou-jikan/)に書いています。
