内定を出した候補者が、大手の内定と比べて、自社を辞退する。年収も、福利厚生も、休日も、大手のほうが良い。「待遇で勝てないから、採れない」。結論を先に書くと、**待遇で大手と同じ土俵で戦えば、負けます。土俵を変えます。「大手にはない条件」を見つけて前に出し、「大手を選ばない人」に届く経路と書き方にします。待遇で決める候補者は、大手に行きます。待遇以外で決める候補者に、待遇以外の材料を渡します**。知名度が無い場合は[知名度がなくて応募が集まらない](/media/rpo-chimeido-nai/)に、提示年収の見直しは[提示年収が市場と合っていない](/media/rpo-nenshu-awanai/)にまとめています。

## 待遇で大手に勝てない会社で起きていること

待遇で大手に勝てない会社の採用では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 内定の後に、大手と比べて辞退される | 候補者は複数社を受けていて、最後に条件で並べる。並べれば負ける |
| 求人票が、大手と同じ項目で書かれている | 年収、福利厚生、休日。同じ項目で並べば、大手が上に見える |
| 「待遇を上げないと採れない」と思っている | 上げても大手には届かず、上げた分だけ社内の整合が崩れる |
| 大手を受けている候補者ばかり集まっている | 総合型の媒体で、大手と同じ層に届けている。その層は大手を選ぶ |
| 自社の良さを、待遇の言葉でしか言えない | 「アットホーム」「風通しが良い」は、待遇の代わりにならない |
| 辞退の理由を「条件」で一括りにしている | 条件で負けたのか、条件以外で負けたのかを分けていない |
| 面接官が、大手との違いを説明できない | 「大手のほうが良いですよね」と、面接官自身が思っている |

待遇で勝てないことは、事実です。事実を変えるより、勝負する場所を変えます。

## 大手と比べられる構造

候補者が大手と自社を比べるのは、次の構造です。

**同じ媒体で、同じ職種で、同じ層に届けている。** 総合型の媒体で「〇〇職」と検索すれば、大手と自社が並びます。並んだ時点で、比べられます。

**求人票の項目が、同じ。** 年収、賞与、福利厚生、休日、勤務地。同じ項目で並べれば、数字の大きいほうが勝ちます。

**候補者が、複数社を同時に受けている。** 大手の内定を持っている候補者に、自社の内定を出せば、比べられます。

**候補者の判断の軸が、「条件」になっている。** 面接の中で、条件以外の軸（役割、裁量、人、事業）を候補者に渡していなければ、条件で判断します。

**面接官が、比べられる前提で話していない。** 「大手と迷っていますか」と聞かず、辞退の連絡で初めて知る。

構造を変えるのは、「届ける層」「求人票の項目」「判断の軸」「面接での話し方」の四つです。

## 大手にはない条件の見つけ方

待遇以外で、大手にはない条件を見つけます。

| 大手にはないもの | 中身 | 見つけ方 |
|---|---|---|
| 裁量の大きさ | 決められる範囲、決めるまでの速さ、承認の階層の少なさ | 「この役割で、自分で決められることは何か」を現場の責任者に聞く |
| 役割の広さ | 一つの職種に閉じない、隣の領域も担える | 「この役割の人が、実際にやっていることの幅」を聞く |
| 経営者との距離 | 経営者と直接話せる、経営の判断が見える | 経営者が面接や面談に出るか、入社後に接点があるか |
| 事業の成長の段階 | これから作る段階に関われる、作った実感が持てる | 事業の段階と、この役割が何を作るかを整理する |
| 成長の速さ | 任される時期が早い、責任が早く来る | 入社した人が、何か月で何を任されたかの実例 |
| 働き方の柔軟さ | リモート、時間、場所の自由度。制度ではなく実態 | 実態を、社員に聞く |
| 人の近さ | 誰と働くかが見える、チームが小さい | 一緒に働く人の顔と話 |
| 評価の直接さ | 評価する人が近く、成果が見えやすい | 評価の仕組みと、実態 |
| 専門性の深さ | 特定の領域で、大手より深い | 事業の中で、大手にはない深さがあるか |

見つけ方の要点は、「現場の責任者と、入社した人に聞く」ことです。人事や経営者が考える「自社の良さ」は、待遇の言葉か、抽象語（アットホーム）になりがちです。現場と入社した人は、具体的な場面で語れます。

見つけた条件は、事実であることが前提です。「裁量が大きい」と書いて、実態が承認だらけなら、入社後に離れます。

## 大手を選ばない人への届け方

待遇で決める人は、大手を選びます。待遇以外で決める人に届けます。

**届ける層を、変える。** 総合型の媒体で大手と並ぶ層ではなく、スカウト型で「裁量」「成長の段階」「事業の中身」に反応する人に届けます。スカウトの文面は、大手にはない条件を一段落目に。

**「大手を経験して、次を探している人」に届ける。** 大手にいて、裁量の小ささ、決定の遅さ、役割の狭さに不満を持つ人は、います。その人には、「大手にはない条件」がそのまま刺さります。

**「大手を受けていない人」に届ける。** 紹介会社や社員の紹介で、大手を軸に探していない人。紹介会社に、自社が「大手を選ばない人に合う会社」であることを理解してもらいます。

**求人票の一行目を、待遇ではなく、役割と裁量にする。** 「年収〇〇円」で始まる求人票は、大手と比べられます。「△△を自分で決めて進める役割」で始まる求人票は、役割で見られます。

**カジュアル面談で、人と事業を先に見せる。** 応募の前に、一緒に働く人と、事業の中身を見せます。条件で並べる前に、条件以外の判断の軸を渡します。

**面接で、「大手と迷っていますか」と聞く。** 迷っているなら、隠さず、「待遇では届きません。そのうえで、この役割にはこれがあります」と、比べる材料を渡します。

届ける層を変えれば、「待遇で負ける」場面そのものが減ります。

### エラベルの見解

相談で最も多い失敗は、「大手に勝てないので、年収を上げた。それでも辞退が続いた」というものです。上げても大手には届かず、上げた分だけ既存社員との整合が崩れ、候補者は相変わらず条件で並べて大手を選びました。届けている層が「大手を受けている層」のままだったからです。スカウトの一段落目を「裁量」と「事業の段階」に変え、大手の経験者で次を探している人に届けたら、年収を上げる前の水準で採れました。

見ていて差がつくのは、担当者が「大手にはない条件」を現場から引き出せるかどうかです。「御社の良さは何ですか」と人事に聞いて「アットホームです」で終わる担当者と、現場の責任者に「この役割で自分で決められることは何ですか」と聞き、入社した人に「何か月で何を任されましたか」と聞いて、具体的な場面を集める担当者がいます。後者の材料は、大手と比べても負けません。

発注側にできるのは、担当者を現場の責任者と入社した人に会わせることです。人事の言葉だけでは、待遇以外の条件は出てきません。

## 条件の見せ方

見つけた条件を、求人票と面接でどう見せるかです。

| 場面 | 見せ方 |
|---|---|
| 求人票の一行目 | 待遇ではなく、役割と裁量。「〇〇を自分で決めて進める役割」 |
| 求人票の本文 | 大手にはない条件を、具体的な場面で。「入社三か月で△△を任された人がいます」（自社の記録から） |
| 待遇の項目 | 隠さず、正確に。「年収は同じ職種の大手より低い場合があります」と書く会社もある。誇張しない |
| 条件の並べ方 | 待遇を最後に。役割、裁量、人、事業、働き方の実態、そして待遇 |
| 面接での説明 | 「待遇では届きません。そのうえで」と、先に認めてから、大手にはない条件を話す |
| 一緒に働く人 | 面接に、現場の責任者と、入社した人を出す。人が見えれば、待遇以外の軸ができる |
| 経営者 | 最終面接か、内定後の面談に経営者が出る。大手では会えない距離を見せる |
| 入社後の見通し | 「一年後にこの役割、三年後にこの役割」。制度と実態に沿って。誇張しない |

見せ方の要点は、「待遇を隠さない」ことです。隠せば、内定の後に分かり、辞退と不信になります。「待遇では届かない」を先に認めた会社は、候補者に信用されます。

## 辞退の理由の分け方

「条件で辞退」を、分けて記録します。

**待遇の差で辞退。** 年収、福利厚生、休日の差。自社が届かない差なのか、届く差なのか。届く差なら、上げる判断の材料。届かない差なら、届ける層を変える材料。

**待遇以外の差で辞退。** 事業の安定、知名度、周囲の反対、役割の内容。待遇と混ぜない。

**自社の対応で辞退。** 返信が遅い、面接が遅い、面接官の印象。待遇の問題ではなく、自社の問題。直せる。

**候補者の軸が、最初から待遇だった。** 面接の早い段階で「待遇で決める」と分かっていたなら、届ける層の問題。

**辞退の理由を、候補者と紹介会社から聞く。** 「条件」と言われたら、「どの条件ですか」と一段深く聞きます。

**月に一度、分類して見る。** 「待遇の差」が多ければ届ける層と見せ方、「自社の対応」が多ければ選考の速さと面接官。

分けて記録すれば、「待遇で負けている」が本当かどうかが分かります。多くの会社で、「自社の対応」と「待遇以外の差」が、思っているより多いです。

## 待遇を上げる判断

見せ方と届ける層を変えても、待遇を上げる判断が要る場面はあります。

**上げる判断の前提。** 大手にはない条件を前に出し、届ける層を変え、辞退の理由を分けて、それでも「届く差」で辞退が続いている。

**上げるなら、大手に並ぶためではなく、市場の水準に合わせるため。** 大手に並ぶのは無理です。同じ規模の会社の水準と比べて、負けているなら、上げる判断。比べ方は[提示年収が市場と合っていない](/media/rpo-nenshu-awanai/)に書いています。

**年収以外の待遇で、上げられるものを探す。** 休日、働き方の柔軟さ、手当。年収を上げられなくても、他で上げられるものがあります。制度の変更は社内の規程と法令に沿い、専門家に確認します。

**既存社員との整合を、先に決める。** 新しく採る人の待遇を上げれば、既存社員との差が出ます。役割で分けるか、既存社員も見直すか。

**「上げない」も判断。** 上げずに、届ける層と見せ方で採る。その判断をしたなら、待遇で辞退されることを受け入れ、待遇以外で決める候補者に集中します。

待遇を上げるかどうかは、経営者の判断です。人事と担当者は、上げる前にできることを全部やり、記録を持って判断を仰ぎます。

## 外注する場合の範囲

待遇で大手に勝てない問題を、採用代行に出す場合の範囲です。

**出せる工程。** 大手と比べられる構造の整理、大手にはない条件の聞き取り（現場の責任者と入社した人）、求人票の書き直し（一行目、本文、条件の並べ方）、届ける層の設計（スカウト、紹介会社、社員の紹介、カジュアル面談）、スカウト文面の作成と運用、紹介会社への「大手を選ばない人に合う会社」の説明、面接での説明の型と面接官向けの書面、辞退の理由の記録と分類、待遇を上げる判断の材料の一枚。

**社内に残す判断。** 大手にはない条件の事実の確認、待遇の決定、既存社員との整合、面接官の指名、経営者の面接への参加。

**外注の効きどころ。** 待遇で勝てない会社の採用は、「土俵を変える設計」の問題です。担当者は複数の会社で、大手と競合しない届け方を見ているので、届ける層と見せ方の型を持ち込めます。現場と入社した人からの聞き取りは、外部の担当者のほうが具体的な場面を引き出しやすいことがあります。

**外注しても動かない場合。** 経営者が「待遇を上げれば解決する」か「待遇は上げない、他も変えない」を譲らない、現場が聞き取りに応じない、面接官が「大手のほうが良い」と思ったまま面接に出る。社内の判断で、代行を替えても直りません。

待遇で勝てないことは、変えにくい事実です。外注は、事実の上で土俵を変える速さを上げる手段です。

### エラベルの見解

担当する側から見ると、待遇の相談で最も多いのは、「面接官が、自社を大手より下だと思っている」ことです。面接で候補者に「大手と迷っていますか」と聞かれて、「まあ、大手のほうが安定していますよね」と面接官が言う。候補者は、その一言で決めます。

面接官が自社の「大手にはない条件」を具体的に語れなければ、候補者に伝わりません。面接官向けの書面に、「待遇では届かない。そのうえで、この役割にはこれがある」を、具体的な場面で書き、面接官全員が同じことを語れる状態にします。

発注側にできるのは、面接官が「自社を選ぶ理由」を語れるかを、面接の前に確認することです。語れない面接官は、候補者を大手に送ります。

## まとめ

- 待遇で勝てないと**内定後に比べて辞退・同じ項目の求人票・上げれば採れると思う・大手を受ける層が集まる・待遇の言葉でしか言えない・辞退を条件で一括り・面接官が説明できない**
- 比べられる構造は**同じ媒体と層・同じ項目・複数社の同時受験・判断の軸が条件・比べられる前提で話していない**。届ける層・項目・軸・話し方を変える
- 大手にはない条件は**裁量・役割の広さ・経営者との距離・事業の段階・成長の速さ・働き方の実態・人の近さ・評価の直接さ・専門性**。現場の責任者と入社した人に聞く。事実であること
- 届け方は**層を変える・大手経験者で次を探す人・大手を受けていない人・一行目を役割と裁量に・面談で人と事業を先に・迷っているか聞く**
- 見せ方は**一行目・具体的な場面・待遇は隠さず正確に・待遇を最後に・先に認めてから・人を出す・経営者を出す・見通しは制度のとおり**
- 辞退は**待遇の差（届くか届かないか）・待遇以外の差・自社の対応・軸が最初から待遇**に分けて記録し、月に一度見る
- 上げる判断は**前提を満たしてから・大手に並ぶためでなく市場の水準に・年収以外の待遇・既存社員との整合・上げないも判断**
- 外注できるのは**構造の整理・聞き取り・求人票・層の設計・スカウト・紹介会社への説明・面接の型・辞退の記録・判断の材料**。社内に残るのは**事実の確認・待遇の決定・整合・面接官・経営者の参加**

## よくある質問

### 待遇を上げないと、本当に採れませんか

待遇で決める候補者は、上げても大手に届かなければ大手に行きます。待遇以外で決める候補者は、待遇を上げなくても、大手にはない条件が具体的に見えれば来ます。届けている層が「大手を受けている層」なら、層を変えます。辞退の理由を分けて記録し、「届く差」で辞退が続いているなら、市場の水準に合わせて上げる判断をします。大手に並ぶために上げるのは、無理があります。

### 「アットホーム」「風通しが良い」は、大手にはない条件になりませんか

抽象語は、候補者の判断の材料になりません。どの会社にも書けるからです。「裁量が大きい」も、抽象語のままでは同じです。「この役割で、〇〇を自分で決められます。承認は責任者一人で、翌日には決まります」「入社三か月で△△を任された人がいます」のように、具体的な場面で書きます。場面は、現場の責任者と入社した人に聞けば出てきます。人事の言葉で書かないことです。

### 内定者が大手の内定と迷っています

隠さず、比べる材料を渡します。「待遇では届きません。そのうえで、この役割にはこれがあります」と、大手にはない条件を具体的な場面で。一緒に働く人と、経営者との面談を用意します。候補者の判断の軸を聞き、軸が待遇なら、無理に引き止めません。軸が役割や裁量や事業なら、その軸で材料を渡します。決めるのは候補者で、自社は材料を出し切るところまでです。
