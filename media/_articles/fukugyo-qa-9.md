副業を始めるなら、収入を安定させるために、最初から複数の依頼側を持ちたい。ただ、契約で禁じられていないか、依頼側に隠すべきなのか、自分の時間で回るのかが分からない。結論を先に書くと、**複数の依頼側を同時に持つことは、多くの契約で禁じられておらず、できます。ただし、「稼働の枠が足りる」「依頼側ごとに情報を分けられる」「依頼側どうしが競合しない」「依頼側に複数を持っていることを伝えてある」の四つが前提です。**最初から複数を持とうとするより、一件目を数か月回して、自分の枠と型を確かめてから二件目を考えるほうが、両方が続きます。複数の案件の稼働の見立ては[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、スケジュールの組み方は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)にまとめています。契約の解釈は、専門家にご確認ください。

## 受けられるかどうかを決める四つの条件

複数を同時に持てるかは、意欲ではなく、四つの条件で決まります。

| 条件 | 内容 | 満たしていない状態 |
|---|---|---|
| 一、稼働の枠が足りる | 本業の繁忙期でも守れる週の枠に、二件の工程が入る | 一件目で枠が埋まっている。閑散期の枠で二件目を考えている |
| 二、情報を分けられる | 依頼側の情報を依頼側の仕組みに置き、自分の側で混ぜない。頭の中で「どこで知ったか」を分けられる | 一件目の文面や候補者の傾向を、二件目でそのまま使おうとしている |
| 三、競合しない | 依頼側どうしが、事業でも候補者でも重ならない | 同じ職種を同じ地域で同じ時期に採用している |
| 四、依頼側に伝えてある | 複数の案件を持っていることを、依頼側が知っている。契約に制限があれば従っている | 隠している。契約の専念の条項を読んでいない |

四つの要点は、「三」の競合が、依頼側どうしの関係だということです。本業との競合とは別に、依頼側Aと依頼側Bが同じ候補者を取り合う関係なら、両方を受けることは、どちらにとっても不利益になります。受ける前に、職種・地域・時期の重なりを見ます。競合の見方は[本業の会社に競合はいないか](/media/fukugyo-qa-14/)と同じ三つの軸で、依頼側どうしに当てはめます。

## 一件目と二件目の間に置く期間

最初から複数を持たず、一件目を回してから二件目を考える理由は、一件目で分かることが多いからです。

| 一件目で分かること | 二件目にどう効くか |
|---|---|
| 自分の週の枠に、一件の工程が実際にどれだけ入るか | 二件目の工程が枠に入るかを、推測ではなく実績で判断できる。[稼働ログの付け方](/media/fukugyo-log/) |
| 自分の型（文面、手順、報告）が固まる | 二件目は型を使い回せるので、一件目より稼働が少なくて済む |
| 依頼側の仕組みに合わせる感覚 | 二件目で別の仕組みに合わせるときの負担が読める |
| 本業の繁忙期に、一件でも回るか | 一件で繁忙期を越えられなければ、二件は回らない |
| 情報を分ける習慣 | 一件目で依頼側の情報を自分の側に置かない習慣ができていれば、二件目で混ざらない |
| 自分の範囲の一言 | 一件目の経験で範囲が絞れ、二件目は範囲が合う案件を選べる |

期間の要点は、「一件目で本業の繁忙期を一度越える」ことです。繁忙期を越えてみないと、自分の枠が本当にどれだけかが分かりません。閑散期の感覚で二件目を受けると、繁忙期に両方が止まります。一件目を数か月、できれば繁忙期を含む期間回してから、二件目を考えます。最初の数か月の進め方は[案件の最初の時期の進め方](/media/fukugyo-shoki-90nichi/)に、一件目の後の広げ方は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「複数の依頼側を持っていることは、依頼側に隠したほうがよい」というものです。実際には、依頼側の担当者は、副業の担当者が他にも案件を持っていることを想定していて、隠されるほうを嫌います。隠していて後で分かると、「他の案件を優先しているのでは」「うちの情報が他に流れているのでは」と疑われます。最初から「他に一件、別の業界の案件を持っています。稼働は週にこれだけを御社に確保します」と伝えれば、担当者は安心します。

見ていて差がつくのは、伝えるときに「稼働の確保」と「情報の分離」を一緒に言っているかです。「他にも案件があります」だけでは、担当者は稼働と情報の両方を心配します。「御社の稼働はこの枠で固定し、御社の情報は御社の仕組みの中だけで扱います」と添えれば、担当者の心配は消えます。エラベルでは、担当者が複数の依頼側を持つとき、依頼側どうしの業界と職種の重なりを見て提示しており、依頼側にも担当者が他の案件を持っていることを前提に伝えています。隠さない仕組みのほうが、担当者も依頼側も動きやすくなります。

## 依頼側に伝えるべきこと

複数を持つとき、依頼側に伝えることを整理しておきます。

| 伝えること | 伝え方 | 伝えないこと |
|---|---|---|
| 他に案件を持っていること | 「他に一件、別の業界の案件を持っています」 | 他の依頼側の会社名 |
| 他の案件の業界と職種 | 「〇〇業界で、〇〇職の採用の支援です」 | 他の依頼側の採用の状況、条件、候補者 |
| この依頼側に確保する稼働 | 「御社には週にこの枠を固定します」 | 他の案件の稼働の詳細 |
| 情報の分離 | 「御社の情報は御社の仕組みの中だけで扱い、他の案件と混ぜません」 | ― |
| 競合しないこと | 「他の案件と、業界も職種も重なっていません」 | ― |
| 稼働が重なる時期の扱い | 「両方の山が重なる時期は、先にお伝えして優先を相談します」 | ― |

伝える要点は、「他の依頼側の会社名は出さない」ことです。業界と職種を伝えれば、依頼側は競合の有無を判断でき、会社名まで出す必要はありません。会社名を出すと、他の依頼側との秘密保持に触れることがあります。依頼側が「どこの会社か」と聞いた場合は、「業界と職種でご判断いただければ」と返します。依頼側との条件の話し方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。

## 複数を回すときに起きやすい問題

複数を持つと、一件では起きなかった問題が起きます。先に知っておくと、防げます。

| 問題 | 何が起きるか | 防ぎ方 |
|---|---|---|
| 山が重なる | 両方の面接や内定が同じ週に集中し、どちらかが止まる | 予備の枠を空ける。先に伝えて優先を決める。[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/) |
| 情報が混ざる | 一件目の文面や候補者の傾向を二件目で使う | 型は依頼側の情報を抜いた構造だけを自分の側に。[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/) |
| ツールの切り替えで混同する | 別の依頼側のATSに入力する、別のチャットに送る | ブラウザのプロファイルを案件ごとに分ける。[ツールを統一するか合わせるか](/media/fukugyo-tool-toitsu/) |
| 請求と締め日が重なる | 月末に両方の報告と請求が重なり、どちらかが締めに遅れる | 締め日を一枚に並べ、前倒しする。[請求のタイミング](/media/fukugyo-seikyuu-timing/) |
| 候補者が重なる | 両方の依頼側の候補として同じ人が出てくる | 受ける前に競合を見る。出てきたら、片方では接しない |
| 片方に偏る | 面白い案件、単価の高い案件に稼働が寄り、もう片方が疎かになる | 枠を固定し、枠の中で動く。偏りは稼働ログで見る |
| 本業の繁忙期に両方が止まる | 枠が消え、二件とも遅れる | 繁忙期の枠で二件目を判断する。繁忙期は両方に同じ配り方で稼働を下げる |

問題の要点は、「片方に偏る」が、本人が気づきにくいことです。面白い案件や単価の高い案件に自然に時間が寄り、もう片方の依頼側から見ると「最近、動きが鈍い」となります。枠を案件ごとに固定し、稼働ログで偏りを見ることで、気づけます。

## 受けられる数の見立て方

「何件まで受けられるか」は、数ではなく、枠で決まります。

| 手順 | 内容 |
|---|---|
| 一、繁忙期の枠を出す | 本業の最も忙しい月に、副業に使える週の時間 |
| 二、一件目の実績を見る | 一件目の工程が、週に何時間使っているか。稼働ログから |
| 三、残りの枠を出す | 繁忙期の枠から、一件目の実績と、予備の枠を引く |
| 四、二件目の工程を当てはめる | 二件目の範囲の工程が、残りの枠に入るか。入らなければ範囲を絞るか、受けない |
| 五、定例と締め日の重なりを見る | 二件の定例と締め日が、自分の枠の中で重ならずに置けるか |
| 六、三件目以降も同じ | 枠が残っていれば受けられ、残っていなければ受けない。数の上限は決めない |

見立ての要点は、「数の上限を先に決めない」ことです。「三件まで」と決めると、三件の範囲の合計が枠を超えて崩れるか、枠が余っているのに受けないかになります。枠に入るかで判断すれば、案件の範囲によって、二件で埋まることも、四件入ることもあります。枠の決め方は[稼働時間の上限](/media/fukugyo-kadou-jikan/)に書いています。

## 断り方

二件目の相談が来て、枠に入らないとき、断り方で次の機会が変わります。

| 状況 | 断り方 |
|---|---|
| 枠に入らない | 「いまの稼働では受けられません。〇月以降なら枠が空く見込みです」と、時期を添える |
| 範囲を絞れば入る | 「この範囲の全部は難しいですが、〇〇の工程だけなら受けられます」と、範囲を絞って提案する |
| 競合する | 「別の案件と職種が重なるため、お受けできません」と、理由を一言。他の依頼側の名前は出さない |
| 一件目を回し始めたばかり | 「一件目の稼働が固まるまで、数か月お待ちいただけますか」と、時期を示す |
| 合う仲間がいる | 「私は受けられませんが、この範囲が合う方を紹介できます」と、仲間につなぐ。[同じ立場の仲間を作る](/media/fukugyo-nakama/) |

断り方の要点は、「時期か範囲か仲間か、どれか一つを添える」ことです。「受けられません」だけで終えると、その依頼側からは次の声がかかりません。「〇月以降なら」「この工程なら」「この人なら」のどれかを添えれば、断っても入口が残ります。断り方の型は[断り方](/media/fukugyo-kotowaru/)に整理しています。

### エラベルの見解

担当する側から見ると、複数の依頼側を長く持てている人は、二件目を受ける前に、一件目で本業の繁忙期を越えています。繁忙期を越えて「一件でも回る」と分かってから二件目を受けているので、二件目でも繁忙期に崩れません。最初から二件で始めた人は、最初の繁忙期で両方が止まり、両方の依頼側との関係を一度に失っています。

順番として、一件目を繁忙期を含む数か月回し、稼働ログで一件目の実績を見て、残りの枠に二件目の工程が入るかを見て、競合が無いことを確かめ、依頼側に伝えてから受ける。この順番で、複数を持つことは収入の安定になり、逆の順番では両方を失う原因になります。エラベルでは、担当者が二件目以降を受けるとき、稼働の枠と、依頼側どうしの重なりを見て提示しており、担当者の側にも一件目の実績を踏まえた判断をお願いしています。複数を持てるかは、意欲ではなく、枠と仕組みで決まります。

## まとめ

- 複数の依頼側を持つことは**多くの契約でできる**。前提は**稼働の枠・情報の分離・競合しない・依頼側に伝えてある**の四つ
- **一件目で本業の繁忙期を一度越えてから**二件目を考える。繁忙期の枠で判断する
- 依頼側には**他に案件があること・業界と職種・確保する稼働・情報の分離・競合しないこと**を伝え、他の依頼側の会社名は出さない
- 起きやすい問題は**山の重なり・情報の混在・ツールの混同・締め日の重なり・候補者の重なり・片方への偏り・繁忙期の同時停止**
- 受けられる数は**数ではなく枠**で決める。数の上限を先に決めない
- 断るときは**時期か範囲か仲間か**、どれか一つを添える

## よくある質問

### 契約書に「専念義務」のような条項があります。複数は受けられませんか

条項の内容によります。「他の業務に従事してはならない」のような制限があれば、複数を持つことがその契約に反する可能性があります。「本業務に支障を及ぼさない範囲で」のような書き方なら、稼働を確保できれば問題にならないことが多いと整理されています。条項の意味と、自分の場合に当てはまるかは、契約の前に依頼側に確認するか、専門家にご確認ください。窓口を通す案件では、窓口の取り決めも確認します。

### 二件目を受けたら、一件目の依頼側に伝える必要がありますか

伝えます。一件目の契約に制限が無くても、担当者は「稼働が減るのでは」と心配するので、「二件目を受けますが、御社の稼働はこの枠で変わりません」と先に伝えれば、心配は消えます。伝えずに後で分かると、稼働が変わっていなくても「隠していた」と受け取られます。伝えるのは、二件目の契約が決まった時点で、業界と職種と、一件目の稼働が変わらないことを、短く伝えます。

### 複数を持つと、収入は安定しますか

一件が終わっても収入が全部消えない、という意味では安定します。ただし、二件の稼働が枠を超えていれば、両方が崩れて収入が全部消えることもあります。安定させるのは案件の数ではなく、枠の中で回っていることです。収入の見立ては、案件ごとの契約の期間と更新の見込みを含めて、年間で考えます。見立て方は[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に整理しています。
