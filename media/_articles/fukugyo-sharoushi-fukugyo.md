社会保険労務士として、労務と手続きと制度を扱ってきた。採用は人事の領域で、自分の仕事は入社の後からだと思っていた。ただ、依頼側の採用が、条件の整合や手続きでつまずく場面を何度も見てきた。この経験は、採用の副業で売れるのか。結論を先に書くと、**社会保険労務士の経験は、採用の副業では、「採用の条件と受け入れを、労務の目で先に整える」工程で売れます。売れるのは、「求人票の条件と社内の制度の整合」「内定から入社までの手続きの設計」「入社後の定着と労務の接続」「採用の判断で労務の懸念を先に示す」の四つです。採用の現場では、求人票の条件が社内の制度と食い違う、内定の後に手続きが滞る、入社後に条件の認識がずれる、という労務の側の詰まりが多く、労務の目で先に整えられる人が求められています。ただし、士業としての業務と、採用の副業は分けて受けます。資格に基づく業務の範囲、独占業務の扱い、名称の使い方は、資格の規範と所属団体と専門家にご確認ください。**法改正の追い方は[法改正の追い方](/media/fukugyo-houkaisei/)に、資格の考え方は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に、法人や事務所で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)にまとめています。

## この経歴の何が売れるか

社会保険労務士の経験を、採用の工程に置き換えた棚卸しです。ここで扱うのは、採用の副業として受けられる工程で、士業としての業務そのものではありません。

| 社労士の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 就業規則と労働条件を扱ってきた | 求人票に書く条件（勤務の形、時間、休日、手当の考え方）が、社内の規則と整合しているかを、公開前に確かめる | 求人票の条件と実態が食い違い、入社後に問題になる依頼側が多い |
| 入社の手続きを扱ってきた | 内定から入社までに、依頼側と候補者が何を、いつ、どの順で行うかの流れを設計する | 内定の後に手続きが滞り、候補者の不安が辞退につながる依頼側が多い |
| 労働条件の明示の実務を知っている | 内定時に候補者に示す条件の項目と、示し方の流れを整える（内容の法的な判断は士業の業務として、別に扱う） | 条件の示し方が曖昧で、入社後に「聞いていない」となる依頼側が多い |
| 定着と離職の労務の側を見てきた | 入社後の最初の期間に、条件の認識のずれ、勤務の形の不一致を、早く拾う仕組みを作る | 入社後に労務の相談が出てから対応している依頼側が多い |
| 制度の変化を追ってきた | 採用の条件や手続きに影響する制度の変化を、依頼側に「確認が要る」と早く知らせる | 変化に気づかず、古い条件で採用している依頼側が多い |
| 経営者と労務の話をしてきた | 採用の判断（この条件で採るか、この形で受け入れるか）で、労務の側の懸念を先に示す | 採ってから労務の問題に気づく依頼側が多い |
| 手続きの正確さ | 採用の記録、候補者の情報、条件の記録を、正確に残す型を作る | 記録が散らばり、後で確認できない依頼側が多い |

売れるものの要点は、「採用の後に起きる労務の問題を、採用の前に整えられる」ことです。多くの依頼側で、採用と労務は別々に扱われ、採用が決まってから労務の側で問題が見つかります。求人票の条件、内定の流れ、受け入れの設計を、労務の目で先に整えれば、その問題は起きません。採用の実務の経験が無くても、この工程で売れます。ただし、条件の内容そのものの法的な判断や、手続きの代行は、士業の業務として別に扱い、採用の副業の範囲には入れません。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、法改正の追い方は[法改正の追い方](/media/fukugyo-houkaisei/)に書いています。

## 売りにくい点とその扱い

社会保険労務士の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 士業の業務との線 | 「社労士に頼むのと、採用の副業で頼むのと、何が違うのか」「手続きも全部やってくれるのか」 | 採用の副業として受けるのは、採用の工程の中で労務の目で整える部分。手続きの代行や法的な判断は、士業の業務として別の契約で、または依頼側の顧問の社労士に。線を契約の前に示す |
| 採用の実務を知らない | 「求人票を書く、スカウトを送る、面接を設計する、はできるのか」 | 範囲を、条件の整合、手続きの設計、定着との接続、懸念の先出しに絞る。実務は依頼側か実務の担当者と分担 |
| 独占業務と名称の扱い | 「副業で社労士の名称を使ってよいのか」「所属団体の規範に触れないか」 | 資格の名称の使い方、副業の可否、業務の範囲は、資格の規範と所属団体と専門家にご確認ください。採用の副業は、士業の業務とは別の契約として、範囲を明確にして受ける |

扱い方の要点は、「士業の業務と採用の副業を、最初から分けて示す」ことです。依頼側は、社労士の資格を持つ人に対して、「手続きも法的な判断も全部やってくれる」と期待します。その期待のまま採用の副業を受けると、範囲が広がり、士業の業務としての責任と、副業の契約の範囲が混ざります。「採用の副業で受けるのはここまで。手続きの代行と法的な判断は、士業の業務として別に、または顧問の社労士に」と、契約の前に線を引きます。この線の引き方自体が、資格の規範に関わるため、始める前に所属団体と専門家にご確認ください。実務の学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に、資格の考え方は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に整理しています。

### エラベルの見解

担当する側から見ると、社会保険労務士の経験で採用の副業を続けている人と、一件で終わる人の差は、労務の知識の深さではなく、「士業の業務と採用の副業の線を、最初に引いているか」です。一件で終わる人は、線を引かずに受け、依頼側から手続きの代行や法的な判断を次々に求められ、副業の契約の範囲と士業の責任が混ざり、続けられなくなっています。続いている人は、「採用の副業では、求人票の条件の整合と、内定から入社の流れの設計と、定着の仕組みを担います。手続きと法的な判断は別に」と最初に示し、依頼側もその前提で頼んでいます。

見ていて差がつくのは、採用の判断の場で、労務の懸念を「止める」形ではなく「先に整える」形で出しているかです。労務の目で見ると、採用の条件や受け入れの形に懸念が見つかることが多く、「それは問題です」と止める形で出すと、依頼側の採用が止まり、「採用を邪魔する人」と見られます。「この条件で採るなら、ここを先に整えておけば問題になりません」と、整える形で出す人は、依頼側から「採用を安全に進めてくれる人」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、労務の目で採用を整える工程を明確にし、士業の業務との線を示している担当者に、労務の側の詰まりを抱えた依頼側がついています。社労士の転身は、知識ではなく、線と出し方で始まります。

## 案件の探し方

社会保険労務士の経験から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 求人票の条件と社内の制度の整合の確認 | 就業規則と条件を扱ってきた経験で入れる | 「求人票を公開する前に、条件が社内の制度と合っているかを確かめる」を範囲の一言に |
| 内定から入社までの流れの設計 | 手続きを扱ってきた経験で入れる | 「内定の後、候補者が不安にならない流れ」を示す |
| 入社後の定着の仕組み | 定着と離職の労務の側を見てきた | 「最初の期間に条件の認識のずれを拾う仕組み」を提案の形で |
| 採用の判断への労務の懸念の先出し | 経営者と労務の話をしてきた | 「採る前に、労務の側の懸念を整える」を示す |
| 採用の記録と条件の記録の型 | 手続きの正確さで入れる | 「後で確認できる記録の型」を示す |
| 人事の担当者がいない規模の依頼側 | 労務と採用が両方とも経営者の手元にある | 登録先で、人事の担当者がいない規模の依頼側を選ぶ |

探し方の要点は、「求人票の公開前の確認」から入ることです。依頼側にとって分かりやすく、範囲が明確で、士業の業務との線も引きやすい工程です。求人票の条件が社内の制度と食い違っている依頼側は多く、公開前に整えることで、入社後の問題を防げます。一件受けて、条件の整合の型を作れば、内定の流れと定着の仕組みに広げられます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、経営者との面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。社会保険労務士の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 士業の業務の単価との比較 | 士業の業務の報酬と、採用の副業の単価は、決まり方が違う | 士業の報酬を採用の副業に持ち込まない。採用の工程の単価で |
| 労務の目での整合の価値 | 入社後の問題を防ぐ価値は、依頼側にとって分かりやすい | 「防いだ問題」を成果として示せる形にする |
| 成果物で受けやすい工程 | 求人票の条件の確認、内定の流れの設計、記録の型は、成果物で受けやすい | 成果物で受けると、士業の業務との線も明確になる |
| 継続の助言 | 採用の判断への懸念の先出しは、月額の顧問の形で受けやすい | 月に何回、何時間、と枠を決めて月額に |
| 実務を含めるか | 実務を含めると、実務の工程の単価が混ざる | 実務は分けて、依頼側か実務の担当者に |
| 契約の形 | 個人で受けるか、事務所で受けるか。資格の名称を使うか | 契約と税と規範の扱いが変わるため、所属団体と専門家にご確認ください |

単価の要点は、「士業の業務の報酬を、採用の副業に持ち込まない」ことです。士業の業務の報酬は、独占業務と責任の重さで決まっていて、採用の副業の単価とは別物です。持ち込むと、依頼側と合わず、士業の業務と副業の線も曖昧になります。採用の工程の単価で、成果物と月額で受け、士業の業務は別の契約にします。契約の形と資格の名称の扱いは、所属団体と専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、法人や事務所で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)に整理しています。

## 始める順番

社会保険労務士から採用の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、副業の可否、資格の名称の使い方、士業の業務との線を、所属団体と専門家に確認する | 始める前に。規範に関わる |
| 二、これまで見てきた「採用の後に起きた労務の問題」を、顧客の情報を含まない型で書き出す | 採用の前に整えられたものを抜き出す |
| 三、採用の副業で受ける範囲を、条件の整合、手続きの流れの設計、定着との接続、懸念の先出しに絞る | 手続きの代行と法的な判断は範囲に入れない |
| 四、採用の主要な工程と言葉を一通り学ぶ | 母集団、選考、決定の流れ |
| 五、懸念を「止める」ではなく「整える」形で出す言い方を、自分の言葉で書く | 出し方の準備 |
| 六、「採用の条件と受け入れを、労務の目で先に整える」の一言を作る | 「社労士です」だけで終わらせない |
| 七、登録先に、範囲と、士業の業務との線を登録する | 人事の担当者がいない規模の依頼側を選ぶ |
| 八、求人票の条件の確認を一件、成果物で受け、型を残す | 内定の流れと定着に広げる材料に |

順番の要点は、「一」の、所属団体と専門家への確認を、最初にやることです。社会保険労務士の副業は、資格の規範、独占業務、名称の使い方に関わり、個人の判断で始めると、後から問題になることがあります。副業の可否と、士業の業務との線を確認してから、範囲を決め、案件を探します。確認した線は、依頼側との契約にも書きます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「社労士の仕事は入社の後からで、採用の副業とは関係がない」というものです。実際には、採用の後に起きる労務の問題の多くは、求人票の条件、内定の流れ、受け入れの設計で防げるもので、労務の目で採用を先に整える工程は、依頼側にとって価値が高いです。関係がないのではなく、採用の前に労務の目を入れる工程が、これまで無かっただけです。ただし、士業の業務と採用の副業の線は、始める前に所属団体と専門家に確認し、契約で明確にすることが条件です。

順番として、副業の可否と線を所属団体と専門家に確認し、採用の後に起きた労務の問題を型で書き出し、範囲を条件の整合と手続きの流れと定着と懸念の先出しに絞り、採用の工程と言葉を学び、懸念を整える形で出す言い方を書き、労務の目で先に整える一言を作り、登録先に範囲と線を登録し、求人票の条件の確認を一件成果物で受ける。この順番で、社労士の転身は、「入社の後の人」から「採用を安全に進める人」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、労務の目で採用を整える工程を明確にし、士業の業務との線を示している担当者に、労務の側の詰まりを抱えた依頼側がついています。社労士の転身は、知識ではなく、線と出し方で始まります。

## まとめ

- 社会保険労務士の経験は、採用の副業では**「採用の条件と受け入れを、労務の目で先に整える」工程**で売れる。**条件の整合・内定から入社の流れの設計・定着との接続・懸念の先出し**の四つ
- **士業の業務と採用の副業は分けて受ける**。手続きの代行と法的な判断は範囲に入れず、別の契約か顧問の社労士に
- 副業の可否、資格の名称の使い方、業務の線は**始める前に所属団体と専門家に確認**する
- 懸念は**「止める」ではなく「整える」形で出す**。採用を邪魔する人ではなく、安全に進める人に
- 案件は**求人票の公開前の条件の確認**から。範囲が明確で、線も引きやすい
- 単価は**士業の報酬を持ち込まず、採用の工程の成果物と月額で**。契約の形は所属団体と専門家に確認

## よくある質問

### 依頼側から、採用の副業の中で、入社の手続きの代行も頼まれました

採用の副業の契約の範囲には入れず、「手続きの代行は、士業の業務として別の契約で受けるか、御社の顧問の社労士にお願いする形にさせてください」と分けます。採用の副業の中に手続きの代行を混ぜると、副業の契約の範囲と士業の責任が混ざり、報酬の決まり方も混ざります。別の契約で受ける場合の可否と形は、資格の規範と所属団体と専門家にご確認ください。範囲の分け方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### 採用の判断で、労務の側の懸念を伝えたら、依頼側の採用が止まりそうです

懸念の伝え方を、「止める」から「整える」に変えます。「この条件では問題です」ではなく、「この条件で採るなら、ここを先に整えておけば問題になりません。整える方法は〇〇と△△です」と、採用を進めるための整え方を添えて伝えます。整え方の中に法的な判断が要る部分があれば、その部分は士業の業務として別に、または顧問の社労士に確認する形を示します。伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に、通らなかったときは[提案が通らなかったとき](/media/fukugyo-hantai-sareta/)に書いています。

### 社労士の資格を、プロフィールに書いてよいですか

資格の名称の使い方は、資格の規範と所属団体の定めに従います。採用の副業のプロフィールで名称を使う場合、士業の業務と採用の副業の線が曖昧にならないよう、「採用の副業で担う範囲」と「士業の業務として別に受ける範囲」を分けて書きます。名称を使うことで、依頼側の期待が士業の業務の範囲まで広がることがあるため、線の明示が要ります。個別の判断は、所属団体と専門家にご確認ください。プロフィールの書き方は[プロフィールの書き方](/media/fukugyo-profile/)に、資格の考え方は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に整理しています。
