介護業界の会社が採用代行を検討するとき、動機は「介護職が常に足りず、施設長が採用に追われている」「新しい施設の開設に人が間に合わない」であることが多い。ただ、介護の採用は、他の業界と違う難しさがあります。職種が分かれ、資格の区分が配置と加算に関わって法令上の整理があり、施設と在宅と通所で働き方の型が違い、夜勤と身体的な負担の実態が定着を左右し、常に募集している状態で施設長が疲弊している。結論を先に書くと、**介護業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、資格と配置の要件の決定・現場の見極め・夜勤と働き方の実態の判断・受け入れは社内に残さないと、採れても配置できず、離れます。**代行に出す前に、難しさを自社の状況で分解し、職種と型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[介護職採用を代行に出す判断基準](/media/rpo-kaigo-rpo/)や[看護師採用を代行に出す判断基準](/media/rpo-kangoshi-rpo/)に書いています。ここでは、介護業界で共通する切り分けに絞ります。

## 介護業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 職種が分かれる | 介護職・看護職・相談員・機能訓練・事務・調理で、経路も要件も違う | 一つの代行で全部は回らない |
| 資格が配置と加算に関わる | 資格の区分で担える業務と配置が変わり、加算の要件にも関わる。法令上の整理がある | 要件に資格をどう置くかは会社と専門家。代行は照合まで |
| 施設・在宅・通所で働き方が違う | 夜勤の有無、移動の有無、利用者との関わり方が型で違う | 型ごとに求人票と経路が要る |
| 夜勤と身体的な負担の実態 | 夜勤の回数、身体的な負担、利用者の状態が求人票に無いと入職後に離れる | 実態を先に出すかで応募と定着が変わる |
| 常に募集している | 離職が多く、募集が止まらず、施設長と管理者が疲弊 | 採用の入口だけ直しても、受け入れと実態が合わなければ繰り返す |

五つのうち、代行で解決できるのは母集団形成と速さで、資格・見極め・実態・受け入れの判断は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 資格と配置の要件の決定 | 残す | 配置と加算に関わる。会社と専門家。法令上の整理がある |
| 夜勤と働き方の実態の判断（求人票に何を書くか） | 残す | 施設長と管理者 |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の型の施設で、〇〇の状態の利用者の〇〇を担った経験」に。代行が整え、管理者が確認 |
| 母集団形成（型ごとの経路） | 任せられる | 地域の経路、学校、紹介会社、資格の区分に合う媒体。型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 常に募集している状態で最も負担が大きい工程 |
| 書類の一次確認 | 一部任せられる | 「資格の区分・型・担った範囲」の照合は外で。現場の適性は社内 |
| 現場の見極め（面接、見学、体験） | 残す | 施設長と現場の管理者 |
| 配置の判断（施設、フロア、夜勤） | 残す | 管理者 |
| 受け入れ（最初の三か月、教える人、夜勤の開始の時期） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 施設をまたいで一つの一覧 |

「資格と配置の要件」は、介護に特有の残す工程で、法令上の整理があると一般に整理されているため、会社と専門家が決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

介護業界で多くの会社が見落とすのは、「常に募集している」状態が採用の入口の問題ではなく、離職の問題であることです。応募を増やし、採り、数か月で離れ、また募集する。代行に「もっと集めて」と頼んでも、穴を埋めるだけで費用が出続けます。退職面談で理由を集めると、「夜勤の開始が早すぎた」「教える人がいなかった」「利用者の状態が聞いていたのと違った」「人間関係」が並び、どれも受け入れと実態の問題です。エラベルで担当者を選ぶ企業には、「直近で辞めた方は、入職から何か月で、夜勤はいつから入っていましたか」を、私たちから先に聞いています。答えが「一か月目から一人で夜勤」なら、代行の前に受け入れの設計です。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種と型 | 介護職・看護職・相談員・事務のどれを、施設・在宅・通所のどの型で採るか |
| 資格と配置の要件 | 資格の区分と配置と加算の関係。必須か、取得の支援か。法令上の整理は専門家に確認済みか |
| 夜勤と働き方の実態 | 夜勤の回数と開始の時期、身体的な負担、利用者の状態を、求人票に書くか |
| 離職の理由 | 退職面談の記録があるか。実態・受け入れ・人間関係・条件のどれか |
| 受け入れ | 最初の三か月の教える人、夜勤の開始の時期、到達点が施設ごとにあるか |
| 面接と見学の枠 | 施設長と管理者の枠を週に決まった数出せるか |
| 記録の形 | 施設をまたいで一つの一覧があるか |

「資格と配置の要件」は、採用の前に会社と専門家で整理しておきます。整理が無いまま採ると、採った人を配置できないか、加算の要件に関わることが起きます。

## 職種と型ごとに代行の型が違う

| 職種・型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| 介護職（施設） | 地域の経路と学校と資格の区分に合う媒体の運用、一次対応 | 現場の見極め、夜勤の実態、受け入れ。[介護職の採用要件の作り方](/media/rpo-kaigo-youken/) |
| 介護職（在宅・通所） | 地域の経路、一次対応 | 移動と一人での対応の実態、見極め |
| 看護職 | 紹介会社と資格の区分に合う媒体、一次対応 | 医療の判断の範囲の要件、見極め |
| 相談員・機能訓練 | 掲載型と紹介、一次対応 | 資格の区分と役割の要件 |
| 未経験・若手 | 学校と地域の経路、資格の取得の支援を書いた求人票 | 育てる体制 |

「介護の採用に強い代行」でも、施設と在宅と通所の型を分けて持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種と型ごとの経路 | 「施設の介護職と、在宅の介護職で、経路と文面をどう変えますか」 |
| 資格の扱い | 「資格の区分を書類でどう照合しますか。配置と加算に関わる判断は社内と専門家で持ちます」 |
| 夜勤の実態の扱い | 「夜勤の回数と開始の時期を、求人票と初回の連絡でどう伝えますか」 |
| 常に募集している状態への対応 | 「募集が止まらない施設で、離職の理由をどう採用に戻しますか」 |
| 担当者の経歴 | 「担当する方は、介護業界のどの職種と型の採用を、どの工程で担った経験がありますか」 |
| 記録の置き場所 | 「施設をまたぐ記録はどこに置きますか。契約が終わったら」 |
| 費用の構造 | 「月額に含まれる工程と施設の数は」 |

費用は、含まれる工程と施設の数で変わり、金額の相場を先に聞くより「同じ工程・同じ施設数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 応募は来るが、資格の区分で配置できない | 要件に区分が無い | 会社と専門家で区分を整理し、要件と一次確認に |
| 面接や見学で「夜勤は聞いていない」と辞退 | 実態を先に出していない | 求人票と初回の連絡に |
| 採れたが、数か月で離れて、また募集 | 受け入れ（教える人、夜勤の開始の時期）が無い | 退職面談で理由を分け、受け入れの一枚 |
| 施設の開設に間に合わない | 開設の計画と採用の一枚が無い | 数か月前に一枚で準備 |
| 施設長が面接に出られず日程が延びる | 枠を預かっていない | 週に一枠を先に |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「資格の区分」「実態」「受け入れ」「計画」「枠」に戻ります。

### エラベルの見解

介護業界で「実態を求人票に書くと応募が減る」という懸念は、どの会社にもあります。ただ、夜勤の回数や利用者の状態を書かずに採った人は、入職後に「聞いていない」で離れ、募集を繰り返します。実態を書くと応募は減りますが、減るのは「その実態では働かない人」で、残った応募は定着します。見学と体験を選考の段に置くと、候補者が実態を見て判断でき、入職後のずれが減ります。エラベルは担当者を工程ごとに選べる形にしているので、「実態を書いた求人票での地域の経路の運用と一次対応と記録」を担当者が担い、施設長と管理者は「見極めと配置と受け入れ」に絞る、という組み方ができます。実態の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## まとめ

- 介護業界の難しさは、**職種の分かれ・資格と配置と加算・型で違う働き方・夜勤と負担の実態・常に募集**の五つ
- **母集団形成・一次対応・日程・記録は任せられ、資格と配置の要件・見極め・実態の判断・受け入れ・条件は残す**
- **資格・配置・加算は会社と専門家**。法令上の整理がある。代行は照合まで。個別の判断は専門家にご確認ください
- 「常に募集している」は**離職の問題**。夜勤の開始の時期と教える人から直す
- 職種と型（施設・在宅・通所）ごとに**経路と代行の型が違う**
- 実態を先に出し、**見学と体験を段に**。応募は減り、定着が上がる

## よくある質問

### 施設長が「面接は自分でやる。時間が無い」と言います

現場の見極めは施設長にしかできません。施設長の負担を減らすには、一次（書類の照合と一次対応と日程）を外に出し、施設長の面接を週に一枠、先に預かります。「三十分の面接」と「合わない人を教え直す時間」を比べれば、面接のほうが軽い。施設長が全段に出る形をやめ、面接と見学だけにします。枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

### 未経験を採って、資格を取ってもらいながら育てたいです

資格の無い間に担える業務と、取得の支援の中身（費用の扱い、時間の確保、取れなかった場合）を、会社と専門家で先に決めます。受け入れの体制（教える人、最初の三か月の到達点、夜勤の開始の時期）も先に。決めずに「入職後に取ってください」で採ると、担える業務が無いか、支援の話で揉め、早期に離れます。要件と求人票には区分（必須・取得の支援・歓迎）を同じ形で書きます。個別の判断は専門家にご確認ください。

### 紹介会社を使っていますが、費用が重く、推薦もずれます

紹介会社に渡している要件が「介護職の経験者」のままなら、ずれるのは当然です。「〇〇の型の施設で、〇〇の状態の利用者の〇〇を担った経験」と「資格の区分」と「夜勤の実態」の一枚を依頼書として渡し、見送りの理由を要件の言葉で戻すと、推薦が変わります。費用の判断は会社のもので、紹介経由と地域の経路の候補者の記録（推薦から入職までの数と日数）を並べて、経路の比重を決めます。紹介会社との付き合い方は[紹介会社の推薦の質が低い](/media/rpo-agent-shitsu/)に書いています。
