副業で人事を受けていると、有期契約の扱いで止まっている会社に出会います。契約書は毎年更新しているが、なぜ一年なのか誰も説明できない。五年で切っているが、根拠が曖昧。更新の判断を現場の感覚で決めている。結論を先に書くと、**労働契約法第18条第1項は「同一の使用者との間で締結された二以上の有期労働契約…の契約期間を通算した期間…が五年を超える労働者が、当該使用者に対し、現に締結している有期労働契約の契約期間が満了する日までの間に、当該満了する日の翌日から労務が提供される期間の定めのない労働契約の締結の申込みをしたときは、使用者は当該申込みを承諾したものとみなす」と定めています。**会社が承諾するかどうかを選べる仕組みではありません。個別の判断は弁護士や労働基準監督署にご確認ください。待遇差の扱いは[同一労働同一賃金](/media/fukugyo-law-doitsu-roudou/)に、募集時の明示は[募集時の労働条件明示](/media/fukugyo-law-boshuu-jouken/)にまとめています。

## 契約を結ぶときの枠

**契約期間の上限（労働基準法第14条第1項）。**「労働契約は、期間の定めのないものを除き、一定の事業の完了に必要な期間を定めるもののほかは、**三年**（次の各号のいずれかに該当する労働契約にあつては、**五年**）を超える期間について締結してはならない」。五年となるのは、**高度の専門的知識等を有する労働者**（当該高度の専門的知識等を必要とする業務に就く者に限る）と、**満六十歳以上の労働者**との間に締結される労働契約です。

**必要以上に短くしない配慮（労働契約法第17条第2項）。**「使用者は、有期労働契約について、その有期労働契約により労働者を使用する目的に照らして、**必要以上に短い期間を定めることにより、その有期労働契約を反復して更新することのないよう配慮しなければならない**」。三か月契約を繰り返す運用は、この条文の視界に入ります。

**期間中の解雇（労働契約法第17条第1項）。**「使用者は、期間の定めのある労働契約…について、**やむを得ない事由がある場合でなければ**、その契約期間が満了するまでの間において、労働者を解雇することができない」。期間の定めのない契約の解雇よりも、要件が厳しく書かれています。解雇の枠組みは[解雇の要件](/media/fukugyo-law-kaiko/)にまとめています。

**明示すべき事項。**労働基準法施行規則第5条第1項は、労働契約の期間に関する事項（第一号）、**有期労働契約を更新する場合の基準に関する事項（第一号の二。通算契約期間又は更新回数に上限の定めがある場合には当該上限を含む）**、就業の場所及び従事すべき業務に関する事項（変更の範囲を含む。第一号の三）などを挙げています。同条第5項は、**無期転換申込権が発生する有期労働契約の締結の場合**について、無期転換申込みに関する事項と、申込みに係る無期労働契約の労働条件を加えて明示することを定めています。

## 無期転換の数え方

**第18条第1項。**要件は三つです。

1. **同一の使用者**との間で締結された**二以上の有期労働契約**であること（契約期間の始期の到来前のものを除く）
2. その契約期間を**通算した期間が五年を超える**こと
3. 労働者が、**現に締結している有期労働契約の契約期間が満了する日までの間に**、満了日の翌日から労務が提供される**期間の定めのない労働契約の締結の申込み**をすること

この三つが揃うと「**使用者は当該申込みを承諾したものとみなす**」。会社に拒否の余地はありません。

**転換後の労働条件。**同項後段は「当該申込みに係る期間の定めのない労働契約の内容である労働条件は、**現に締結している有期労働契約の内容である労働条件（契約期間を除く。）と同一の労働条件**（当該労働条件（契約期間を除く。）について**別段の定めがある部分を除く**。）とする」と定めています。**自動的に正社員になるわけではありません。**期間の定めだけが外れます。別段の定めを置くなら、あらかじめ設計が要ります。

**クーリング（第18条第2項）。**一の有期労働契約の満了日と次の有期労働契約の初日との間に、いずれの契約期間にも含まれない期間（**空白期間**）があり、その空白期間が**六月**以上であるときは、空白期間前に満了した有期労働契約の契約期間は通算契約期間に算入しない、とされています。ただし、空白期間の直前に満了した契約の期間（間に空白期間がないときは通算した期間）が**一年に満たない場合**は、その契約期間に**二分の一を乗じて得た期間を基礎として厚生労働省令で定める期間**以上であるとき、とされています。

**「六か月空ければリセット」は、常に正しいわけではありません。**直前の契約期間が一年未満の場合は、必要な空白期間も短くなる仕組みです。実務では、契約期間と空白の実績を並べて数えます。

## 雇止めの三つの手続

契約を更新しないときは、条文と告示の両方を見ます。

**労働契約法第19条（雇止め法理）。**有期労働契約であって次の各号のいずれかに該当するものについて、契約期間が満了する日までの間に労働者が更新の申込みをした場合、または満了後遅滞なく締結の申込みをした場合であって、「使用者が当該申込みを拒絶することが、**客観的に合理的な理由を欠き、社会通念上相当であると認められないとき**は、使用者は、**従前の有期労働契約の内容である労働条件と同一の労働条件で当該申込みを承諾したものとみなす**」。

- 一 **過去に反復して更新されたことがある**ものであって、更新しないことにより終了させることが、期間の定めのない労働契約を締結している労働者に解雇の意思表示をすることにより終了させることと**社会通念上同視できる**と認められること
- 二 **契約期間の満了時に更新されるものと期待することについて合理的な理由がある**と認められること

**告示（平成15年厚生労働省告示第357号）。**労働基準法第14条第2項に基づく基準です。現在は五条からなります。

| 条 | 内容 |
|---|---|
| 第1条 | 契約の**変更又は更新に際して通算契約期間又は更新回数の上限を定め、又はこれを引き下げようとするとき**は、**あらかじめ、その理由を労働者に説明しなければならない** |
| 第2条 | **三回以上更新し、又は雇入れの日から起算して一年を超えて継続勤務している者**に係る有期労働契約（あらかじめ更新しない旨明示されているものを除く）を更新しないこととしようとする場合は、**少なくとも契約の期間の満了する日の三十日前までに予告**しなければならない |
| 第3条 | 第2条の場合において、労働者が更新しないこととする理由について**証明書を請求したときは、遅滞なくこれを交付**しなければならない。更新されなかった場合において、更新しなかった理由について証明書を請求されたときも同様 |
| 第4条 | **一回以上更新し、かつ、雇入れの日から起算して一年を超えて継続勤務している者**に係る契約を更新しようとする場合は、実態及び労働者の希望に応じて、**契約期間をできる限り長くするよう努めなければならない** |
| 第5条 | 労働基準法施行規則第5条第5項に規定する事項（無期転換申込みに関する事項等）を明示する場合には、労働契約法第3条第2項の規定の趣旨を踏まえて**就業の実態に応じて均衡を考慮した事項について説明するよう努めなければならない** |

**第1条が、実務でいちばん見落とされます。**「五年を超える前に更新上限を入れておこう」という発想で就業規則や契約書を変えると、**あらかじめ理由を説明する義務**がかかる形です。後出しで上限を作る運用は、この条文を通らなければなりません。

### エラベルの見解

担当する側から見ると、この案件で最初にやるのは**数えること**です。有期契約者の一覧を作り、初回の雇入れ日、これまでの契約期間、空白期間、通算の年数、次の更新日、無期転換申込権が発生する時期を並べます。この表がない会社が驚くほど多く、作った時点で「来月で五年を超える人が三人います」と分かります。

そこから先が本題です。無期転換したあと、その人をどう扱うのかを会社が決めていない。第18条第1項は、別段の定めがある部分を除き、契約期間以外の労働条件は同一になると書いています。つまり、何も決めなければ、**期間の定めだけが外れた同じ待遇の人**が生まれます。それでよいのか、新しい区分を作るのか、正社員に寄せるのか。ここを決めるのが、人事の仕事です。

実務で勧めているのは、無期転換を「避けるもの」として扱わないことです。更新上限を入れて五年前に切る設計は、告示第1条の説明義務がかかるうえ、第19条の雇止め法理の射程にも入ります。何より、仕事を覚えた人を手放すことになります。むしろ、無期転換後の区分を先に作り、本人にも道筋を示すほうが、採用の負担が下がります。制度の整理が採用の成果に直結する、分かりやすい領域です。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この転換の設計をやり切った経験は、経歴に書いておくと効きます。

## 会社に渡すもの

副業の人事が作るのは、次の形です。個別の適否の判断は弁護士や労働基準監督署にご確認ください。

| 作るもの | 中身 |
|---|---|
| 有期契約者の台帳 | 初回雇入れ日、契約期間の履歴、空白期間、通算年数、次回更新日、申込権の発生時期 |
| 契約期間の方針 | なぜその期間なのか。労働契約法第17条第2項の配慮を踏まえた説明 |
| 更新基準 | 労基則第5条第1項第一号の二の「更新する場合の基準」。上限がある場合はその上限 |
| 更新の判断手順 | 誰が、いつまでに、何を見て判断するか。現場任せにしない |
| 雇止めの予告 | 告示第2条の対象者を判定し、三十日前までの予告を出す段取り |
| 理由の証明書 | 告示第3条。請求があったときの様式と交付の手順 |
| 更新上限を入れる場合 | 告示第1条の「あらかじめ理由を説明する」段取りと記録 |
| 無期転換の受け皿 | 第18条の「別段の定め」を置くのか。置くなら区分・待遇・職務の範囲 |
| 明示書類 | 労基則第5条第5項の無期転換申込みに関する事項。告示第5条の説明 |
| 申込みの受け方 | 書面か口頭か。受けたときの社内の流れ。拒否できない前提の運用 |

**申込みは拒否できません。**第18条第1項は「承諾したものとみなす」と書いています。会社に「認める・認めない」の判断はありません。申込みを受け付ける窓口と記録の残し方を先に決めておくと、現場が迷いません。

**社会保険と雇用保険の扱いも連動します。**無期転換や契約期間の変更は、適用の判断に関わることがあります。[社会保険の適用範囲](/media/fukugyo-law-shakai-hoken/)と[雇用保険の適用範囲](/media/fukugyo-law-koyou-hoken/)もあわせてご覧ください。

### エラベルの見解

外に出してよいのは、台帳、契約期間の方針、更新基準と判断手順、予告と証明書の段取り、無期転換の受け皿の設計、明示書類の雛形までで、「この雇止めが客観的に合理的な理由を欠き社会通念上相当でないと認められるか」「この更新上限が有効か」といった個別の判断は、弁護士や労働基準監督署の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この領域で信頼されるのは、**「切れるかどうか」に答えないこと**です。相談の入口は、たいてい「この人を更新しないことはできますか」です。ここで答えを出すのは弁護士の仕事で、副業の人事がやると会社も自分も危うくなります。答える代わりに出すのは、材料です。更新の履歴、更新時にどう伝えてきたか、更新基準を明示していたか、他の有期契約者はどう扱ってきたか。第19条第2号の「更新されるものと期待することについて合理的な理由」は、こうした事実の積み重ねで判断される領域なので、事実を整理して弁護士に渡すところまでが、こちらの仕事です。

そして、ほとんどの場合、この整理の過程で会社は気づきます。更新基準を示さずに毎年自動で更新してきたこと、面談で「来年もよろしく」と言ってきたこと。そこから先は、今回どうするかより、来年以降どう運用するかの話になります。そちらのほうが、会社にとっては価値があります。エラベルでは、依頼側が担当者を選べるので、この線を守れる人は、制度まわりで長く頼まれます。

## まとめ

- 契約期間の上限は**労働基準法第14条第1項**で原則三年。高度の専門的知識等を有する者と**満六十歳以上**の者は五年
- **労働契約法第17条第1項**は、期間中の解雇に「**やむを得ない事由**」を求め、第2項は必要以上に短い期間の反復更新への配慮を定めている
- **第18条**の無期転換は、通算五年を超える労働者が申込みをしたときに「**承諾したものとみなす**」。転換後は、別段の定めがある部分を除き、**契約期間以外は同一の労働条件**
- クーリングは空白期間**六月**が基本だが、直前の契約期間が一年に満たない場合は**二分の一を基礎として省令で定める期間**になる
- **第19条**の雇止め法理は、反復更新により**解雇と社会通念上同視できる**場合と、**更新されると期待する合理的な理由**がある場合が対象
- 告示は、**更新上限を定める・引き下げるときの事前の理由説明**、**三十日前までの雇止めの予告**、**理由の証明書の交付**、**契約期間をできる限り長くする努力**、**無期転換後の労働条件の説明**を定めている。個別の判断は弁護士や労働基準監督署にご確認ください

## よくある質問

### 五年になる前に契約を終わらせれば、無期転換は起きませんか

無期転換申込権は、労働契約法第18条第1項により通算契約期間が五年を超える労働者に生じるものなので、形式的にはそのとおりです。ただし、更新上限を新たに定めたり引き下げたりする場合は、告示第1条により、あらかじめその理由を労働者に説明しなければならないとされています。また、更新しないことについては同法第19条の枠組みがあり、反復更新により解雇と社会通念上同視できる場合や、更新されると期待することについて合理的な理由がある場合には、拒絶が客観的に合理的な理由を欠き社会通念上相当と認められないときは、申込みを承諾したものとみなされます。個別の判断は弁護士や労働基準監督署にご確認ください。

### 無期転換したら、正社員と同じ待遇にする必要がありますか

労働契約法第18条第1項後段は、無期労働契約の労働条件について「現に締結している有期労働契約の内容である労働条件（契約期間を除く。）と同一の労働条件（当該労働条件（契約期間を除く。）について別段の定めがある部分を除く。）とする」と定めています。契約期間の定めが外れるだけで、他の労働条件は原則として引き継がれる形です。別段の定めを置く場合は、就業規則等での設計が要ります。あわせて、短時間・有期雇用労働法の対象からは外れる一方で、社内の均衡をどう考えるかという課題は残ります。設計の個別の判断は、弁護士や社会保険労務士にご確認ください。

### 雇止めの予告は、誰に対して必要ですか

告示第2条は、当該契約を三回以上更新し、又は雇入れの日から起算して一年を超えて継続勤務している者に係る有期労働契約（あらかじめ当該契約を更新しない旨明示されているものを除く）を更新しないこととしようとする場合に、少なくとも当該契約の期間の満了する日の三十日前までに予告しなければならない、と定めています。さらに第3条は、労働者が更新しないこととする理由について証明書を請求したときは遅滞なく交付すること、更新されなかった場合に理由の証明書を請求されたときも同様であることを定めています。対象者の判定と手続については、労働基準監督署にご確認ください。
