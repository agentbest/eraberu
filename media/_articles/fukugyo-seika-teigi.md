契約のとき、依頼側から「成果を出してほしい」と言われ、「頑張ります」と答えた。三か月経って、依頼側は「採用がまだ決まっていない」と言い、自分は「スカウトの返信は増えている」と言う。どちらも正しいが、噛み合わない。結論を先に書くと、**成果は、契約の前に「自分で動かせる範囲の中にある」「依頼側の記録で測れる」「いつの時点で見るかが決まっている」の三つを満たす形で定義しておきます。「採用が決まること」を成果にすると、面接官の判断や条件の提示のような、自分が動かせない要因で評価が決まります。**自分の範囲がスカウトの運用なら、成果は「返信と面接の設定」までで、その先は依頼側の範囲です。定義を文面にして依頼側と合意しておけば、三か月後に噛み合わないことは起きません。数字に出ない業務の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、期待のすり合わせは[期待値のすり合わせ](/media/fukugyo-kitai-chousei/)に、成果報酬の契約の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)にまとめています。

## 定義しないまま始めると起きること

成果の定義が無いまま始めると、依頼側と自分の間で、別々の成果を見ることになります。

| 起きること | 内容 |
|---|---|
| 依頼側は採用の数字で見る | 「何人採用できたか」が依頼側の成果。自分の範囲がそこに直接つながらなくても、そこで評価される |
| 自分は稼働の量で見る | 「何通送ったか」「何件調整したか」が自分の成果。依頼側には稼働の量にしか見えない |
| 途中で「成果が無い」と言われる | 定義が無いので、依頼側はいつでも「まだ成果が無い」と言える。反論の根拠が無い |
| 更新の判断が曖昧になる | 成果が定義されていないので、更新するかどうかを依頼側は感覚で決める |
| 範囲外の要因で評価が決まる | 面接官の判断、条件の提示、社内の承認の遅れで採用が決まらないと、それが自分の評価になる |
| 稼働報告に何を書けばよいか分からない | 何を成果として報告するかが決まっていないので、報告が稼働の量の羅列になる |

起きることの要点は、「範囲外の要因で評価が決まる」ことです。スカウトの運用を受けている担当者が、面接官の判断で内定が出なかったことで「成果が無い」と評価されることは、定義が無い案件でよく起きます。定義があれば、「返信と面接の設定は目標に達している。その先は依頼側の範囲で、ここで止まっている」と、事実として分けられます。範囲の線は[受ける範囲の決め方](/media/fukugyo-scope/)に整理しています。

## 成果の定義の三つの条件

成果として置いてよいものは、三つの条件を満たすものだけです。

| 条件 | 内容 | 満たさない例 |
|---|---|---|
| 自分で動かせる範囲の中にある | 自分の稼働と判断で変えられる。他の人の判断や社内の承認に依存しない | 「内定数」（面接官と候補者の判断に依存）、「入社数」（条件と候補者の事情に依存） |
| 依頼側の記録で測れる | 依頼側のATSや媒体の管理画面で確認できる。自分の推定や自己申告ではない | 「候補者の満足度」（記録が無い）、「文面の質」（測れない） |
| いつの時点で見るかが決まっている | 「三か月後に」「毎月」のように、見る時期が決まっている | 「そのうち増える」（時期が無い）、「採用が決まるまで」（いつか分からない） |

条件の要点は、「自分で動かせる範囲の中にある」ことです。採用は、スカウト、応募、書類、面接、条件、承諾と続き、外部の担当者が動かせるのはその一部です。自分の範囲の出口（スカウトなら「面接の設定」、日程調整なら「確定までの日数と辞退」）を成果にし、その先は依頼側の範囲として分けます。外部の立場で動かせない部分は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「採用が決まることを成果にしないと、依頼側は納得しない」というものです。実際には、依頼側の担当者は、採用が決まるかどうかに外部の担当者が動かせない要因が多いことを知っています。担当者が困るのは、成果が「採用」でないことではなく、「では何を見ればよいのか」が無いことです。「返信と面接の設定をここまで持っていく。その先は御社の面接と条件で決まる」と分けて示せば、担当者は「見るところが分かった」と納得します。

見ていて差がつくのは、自分の範囲の出口を、依頼側の記録で測れる形にしているかです。「良い候補者を集める」は測れず、「面接の設定に至った候補者の数と、面接官の評価で通過した割合」は測れます。後者なら、自分の範囲（設定まで）と依頼側の範囲（評価）が数字で分かれ、どちらで止まっているかが毎月見えます。エラベルでは、依頼側と担当者の契約のときに、担当者の範囲の出口を成果として置き、その先を依頼側の範囲として分ける形をお願いしています。この分け方をしている案件は、「成果が無い」という曖昧な終わり方をしていません。

## 業務の種類ごとの成果の置き方

自分の範囲の出口は、業務の種類で変わります。代表的な置き方です。

| 業務 | 自分で動かせる出口（成果に置く） | その先（依頼側の範囲） |
|---|---|---|
| スカウトの運用 | 送信数に対する返信の割合、返信から面接の設定に至った数 | 面接の評価、内定、承諾 |
| 求人票の作成 | 掲載後の応募数と、応募者の要件との合致の割合 | 書類選考の判断、面接 |
| 一次対応と日程調整 | 提示から確定までの日数、日程の理由での辞退の数、候補者からの問い合わせの数 | 面接の内容、評価 |
| 面接の準備 | 面接官が準備の資料を受け取った時期、面接の開始の遅れ、面接官からの準備の不足の指摘 | 面接の評価 |
| 内定者への連絡 | 連絡の頻度、内定者からの不安の連絡の数、承諾までの期間 | 条件の内容、承諾の判断 |
| 記録の整備 | 記録の抜けの数、担当者が状況を確認しに来る回数 | 記録を使った判断 |
| 採用の型づくり（中長期） | 型が文書になっているか、依頼側の社内で使われているか、型を使った工程の所要時間 | 型を使い続けるかの判断 |

置き方の要点は、「その先」を明示することです。自分の出口だけを書くと、依頼側は「その先はどうなるのか」と感じます。「その先は御社の面接で決まるので、面接の通過率は御社の記録で一緒に見ましょう」と、その先も見ることを添えれば、自分の範囲だけを守っているように見えません。自分の範囲と採用の数字の間の一段のつなげ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、短期と中長期の分け方は[短期成果と中長期施策のバランス](/media/fukugyo-tanki-choki/)に書いています。

## 採用の数字を成果にしてはいけない理由

「内定数」「入社数」を成果に置きたくなる場面はありますが、外部の担当者の成果としては避けます。

| 理由 | 内容 |
|---|---|
| 自分で動かせない要因が多い | 面接官の判断、条件の提示、候補者の事情、社内の承認。どれも自分の稼働で変えられない |
| 依頼側の側の問題が自分の評価になる | 面接官の時間が取れない、条件が市場と合わない、承認が遅い。これらで採用が止まると、自分の成果が無いことになる |
| 短期の稼働に偏る | 内定を早く出すために、要件を緩めたり、候補者を急がせたりする動機が生まれる。依頼側の採用の質を下げる |
| 中長期の型づくりが評価されない | 型を整えても、その期に内定が出なければ成果ゼロになる |
| 成果報酬の話に変わる | 採用の数字を成果にすると、報酬もそれに連動する話になりやすい。[成果報酬型は受けるべきか](/media/fukugyo-seika/) |

理由の要点は、「依頼側の側の問題が自分の評価になる」ことです。採用が止まる原因の多くは、依頼側の社内にあります。それを自分の成果として引き受けると、依頼側の側の問題を指摘しにくくなり、問題が直らないまま自分の評価だけが下がります。自分の出口を成果に置き、その先は依頼側と一緒に見る形にすれば、依頼側の側の問題も事実として示せます。

## 依頼側との合意の文面

成果の定義は、契約の前に文面で合意します。契約書に入れる場合も、別紙やメールで残す場合も、内容は同じです。

| 項目 | 書くこと | 例 |
|---|---|---|
| 一、自分の範囲 | 担当する工程 | 「スカウトの検索・送信・一次返信・面接の設定まで」 |
| 二、成果の指標 | 自分で動かせる出口を、依頼側の記録で測れる形で | 「送信に対する返信の割合と、面接の設定に至った数。御社の媒体の管理画面とATSで確認」 |
| 三、見る時期 | 毎月か、節目か | 「毎月の稼働報告で。三か月目の定例で一期分を振り返る」 |
| 四、その先の扱い | 自分の範囲の先を、誰がどう見るか | 「面接の評価以降は御社の範囲。通過率は御社の記録で一緒に見る」 |
| 五、目標の水準（置く場合） | 最初の数か月は水準を置かず、実績を見てから置く | 「最初の三か月は現状の把握とし、四か月目から水準を置く」 |
| 六、見直しの節目 | 定義を直す時期 | 「範囲が変わったとき、更新のとき」 |

文面の要点は、「五」の水準を最初から置かないことです。案件の最初は、依頼側の現状（返信の割合、辞退の理由）が分からず、水準を置いても根拠がありません。最初の数か月は指標を「測る」だけにし、実績が出てから水準を置くと、双方が納得できる水準になります。現状の把握は[現状把握のしかた](/media/fukugyo-genjou-haaku/)に、条件の合意の仕方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。契約書への入れ方は、専門家にご確認ください。

## 途中で定義を直す節目

成果の定義は、一度決めたら固定ではありません。直す節目を決めておきます。

| 節目 | 直すこと |
|---|---|
| 範囲が変わったとき | 工程が増えれば、出口も変わる。日程調整が加わったなら、「確定までの日数」を指標に足す。[範囲が広がっていくとき](/media/fukugyo-scope-creep/) |
| 最初の数か月が過ぎたとき | 測っただけの指標に、水準を置く。実績の平均を起点にし、「ここから上げる」の形で |
| 依頼側の採用の方針が変わったとき | 職種や人数が変われば、指標の意味が変わる。同じ「返信の割合」でも、職種で水準が違う |
| 型が整ったとき | 中長期の施策の成果（型の文書化、社内での使用）を、指標に足す。[短期成果と中長期施策のバランス](/media/fukugyo-tanki-choki/) |
| 更新のとき | 一期分の指標を並べ、次の期の定義を決める。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |
| 担当者が替わったとき | 新任に定義を改めて伝え、合意し直す。前任との合意は新任に引き継がれていない |

節目の要点は、「担当者が替わったとき」です。前任と合意した成果の定義を新任が知らず、新任が採用の数字で評価し始めることは、よく起きます。新任が来たら、最初の打ち合わせで「前任と、このように成果を見ることで合意していました」と文面を見せ、合意し直します。担当者の交代への備えは[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

## 成果報酬との違い

成果の定義と、成果報酬は別のものです。混ざると、報酬の話が採用の数字に引きずられます。

| 項目 | 成果の定義 | 成果報酬 |
|---|---|---|
| 目的 | 依頼側と自分が同じものを見るため | 報酬の額を成果に連動させるため |
| 置くもの | 自分で動かせる出口 | 契約で決めた「成果」（多くは内定や入社） |
| 報酬との関係 | 直接は連動しない。固定の報酬の中で、評価と更新の材料になる | 直接連動する |
| 向く場面 | すべての案件 | 成果の定義が自分で動かせる範囲にあり、依頼側の側の要因が小さい場合だけ |
| 混ざると起きること | 「成果の定義があるなら、報酬もそれに連動させよう」と依頼側が言い出す | 採用が決まらない理由が依頼側の側にあっても、報酬が無い |

違いの要点は、「成果の定義は、報酬とは別に、評価と更新の材料として置く」ことです。定義を置いたからといって、報酬をそれに連動させる必要はありません。依頼側が連動を求めてきたら、成果報酬の話として別に考え、自分で動かせない要因が大きいなら受けません。成果報酬の判断は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

### エラベルの見解

担当する側から見ると、契約の前に成果の定義を文面にしている人は、「成果が無い」という曖昧な理由で終わることがありません。終わるときも、「指標はここまで達したが、その先の面接で止まっており、それは御社の範囲」と事実で分けられ、依頼側もそれを認めています。定義を置かずに始めた人は、採用が決まらない理由が依頼側の側にあっても、自分の成果が無いことになり、指摘もできないまま終わっています。

順番として、契約の前に自分の範囲の出口を決め、依頼側の記録で測れる形にし、見る時期を決め、その先を依頼側の範囲として分け、水準は数か月後に置く、と文面にする。この順番で、成果の話は交渉ではなく確認になります。エラベルでは、依頼側と担当者の契約のときに、担当者の範囲の出口を成果として置き、その先を依頼側と一緒に見る形を整えています。担当者を選べる仕組みは、担当者の成果を正しく見られる仕組みでもあり、そのためには、何を成果とするかを先に決めておくことが前提です。

## まとめ

- 成果は**自分で動かせる範囲の中にある・依頼側の記録で測れる・いつ見るかが決まっている**の三つで定義する
- 定義が無いと**依頼側は採用の数字で、自分は稼働の量で見て噛み合わず、範囲外の要因で評価が決まる**
- 自分の範囲の**出口**を成果に置き、**その先は依頼側の範囲**として分け、一緒に見ることを添える
- **採用の数字を成果にしない**。動かせない要因が多く、依頼側の側の問題が自分の評価になり、短期に偏る
- 文面には**範囲・指標・時期・その先の扱い・水準（最初は置かない）・見直しの節目**を書く
- **範囲の変化・数か月後・方針の変化・型の完成・更新・担当者の交代**で直す。成果の定義と成果報酬は別

## よくある質問

### 依頼側が「成果は採用が決まること」と譲りません

「採用が決まることが最終の目標であることは同じです。そのうえで、私の範囲で動かせるのはここまでなので、ここを毎月見て、その先は御社の面接と条件で一緒に見ましょう」と、目標と指標を分けて伝えます。目標（採用）は共有し、指標（自分の出口）を分ける形です。それでも「内定数だけで評価する」と言われるなら、自分で動かせない要因で評価される契約になるので、受けるかどうかを慎重に判断します。成果報酬の形を求められた場合は[成果報酬型は受けるべきか](/media/fukugyo-seika/)を見てください。

### 指標を置いたら、その数字だけを追う稼働になりそうです

指標は、依頼側と同じものを見るためのもので、それだけを追うためのものではありません。「返信の割合」を指標にしても、返信の質が下がれば面接の設定に至らず、次の指標で見えます。指標は自分の範囲の出口に置き、その先も一緒に見る形にしておけば、出口の数字だけを追う稼働にはなりません。指標が一つだと偏るなら、出口の数字と、その先の一段（面接の通過率など）の二つを並べて見ます。

### 中長期の型づくりは、どう成果に置けばよいですか

型づくりの成果は、「型が文書になっているか」「依頼側の社内で使われているか」「型を使った工程の所要時間が減ったか」の三つで置けます。どれも依頼側の記録や共有で確認でき、自分で動かせる範囲にあります。「型ができたことで採用が決まった」は、その先の要因が多いので成果に置かず、型の完成と使用を成果にし、採用の数字はその先として一緒に見ます。短期の成果との配分は[短期成果と中長期施策のバランス](/media/fukugyo-tanki-choki/)に書いています。
