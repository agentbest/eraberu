副業に興味はあるが、契約書を自分で読んで、請求書を自分で作って、税の処理も自分で、と考えると、事務の負担が重そうで踏み出せない。人事の仕事はできても、事務は本業では経理や法務がやってくれていた。結論を先に書くと、**請求や契約を自分でやるかどうかは、案件の入口で変わります。企業と直接契約するなら、契約書の確認と請求書の作成と入金の管理は自分でやります。仲介サービスや登録型の窓口を通すなら、契約の型と請求の集約の多くを窓口が担い、自分がやるのは稼働の報告と振込先の登録程度になります。**どちらの入口でも、「受ける範囲」「締め日と支払日」「振込先の口座」の三つは自分で決めておく必要があり、これは事務というより、副業の条件そのものです。事務の負担は、最初の一件で型を作れば、二件目からは繰り返しになります。契約の期間の考え方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に、報酬の支払いの時期は[支払いサイトの確認](/media/fukugyo-shiharai-site/)に、確定申告は[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/)にまとめています。税や契約の解釈は、専門家にご確認ください。

## 案件の入口で分担が変わる

「自分でやるのか」の答えは、案件がどこから来るかで決まります。

| 入口 | 契約 | 請求 | 入金 | 自分がやること |
|---|---|---|---|---|
| 企業と直接契約 | 依頼側の契約書を自分で読み、条件を確認して結ぶ | 自分で請求書を作り、依頼側の経理に送る | 自分の口座に依頼側から振り込まれる。入金の確認も自分 | 全部 |
| 知人の紹介で直接契約 | 同じ。紹介者を通して条件が決まることがある | 同じ | 同じ | 全部。誰に請求するかを最初に確認 |
| 仲介サービス経由 | サービスの利用規約と、案件ごとの条件に同意する形。契約書を一から読む場面は少ない | サービスの画面で稼働を報告し、サービスが依頼側に請求する | サービスから、手数料を引いた額が振り込まれる | 稼働の報告と、振込先の登録 |
| 登録型の窓口経由 | 窓口と依頼側の契約の下で、窓口と自分の間の取り決めがある | 窓口の形式で稼働を報告し、窓口が依頼側と請求を扱う | 窓口から振り込まれる | 稼働の報告と、振込先の登録。窓口によって異なる |

分担の要点は、「直接契約は全部自分、窓口経由は報告と口座だけ」という違いです。事務の負担を減らしたいなら、最初の一件は窓口経由で始め、事務の型を覚えてから直接契約に広げる順番があります。逆に、直接契約で始めると、最初の一件で契約書の確認と請求書の型を作ることになり、負担は重いですが、その後の案件で使える型が手元に残ります。入口ごとの受け取り方の違いは[決済・振込先の準備](/media/fukugyo-kessai/)に、窓口の使い分けは[副業マッチングサービスの使い分け](/media/fukugyo-platform/)に書いています。

## 直接契約で自分がやること

企業と直接契約する場合、自分がやる事務を、時期ごとに並べます。

| 時期 | やること | 要点 |
|---|---|---|
| 契約の前 | 依頼側から契約書の案をもらい、範囲・期間・報酬・支払いの時期・秘密保持・再委託・終了の条項を読む | 読んで分からない条項は、依頼側に聞くか、専門家に確認する。分からないまま結ばない。[条件のすり合わせ](/media/fukugyo-jouken-suriawase/) |
| 契約のとき | 契約書に署名か捺印。電子契約のことも多い | 控えを自分の側に保管する |
| 稼働中 | 稼働ログを付け、月次の稼働報告を出す | 請求の根拠になる。[稼働ログの付け方](/media/fukugyo-log/) |
| 締め日の前 | 請求書を作り、依頼側の経理に送る。稼働報告と一緒に | 請求書の型を一度作れば、月ごとに日付と額だけ変える。[請求書の書き方](/media/fukugyo-seikyuusho/) |
| 支払日 | 入金を確認し、記録に残す | 遅れていれば確認する。[報酬が支払われないときの対処](/media/fukugyo-mibarai/) |
| 年の終わり | 一年の入金と経費をまとめ、申告の要否を確認する | 要否と方法は専門家に。[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/) |
| 契約の終了 | 最後の請求、アカウントの停止、資料の返却 | 終了の条項に沿って。[引き継ぎの進め方](/media/fukugyo-hikitsugi/) |

直接契約の要点は、「契約書を読んで分からない条項を、分からないまま結ばない」ことです。本業で契約書を読む機会が無かった人は、秘密保持や再委託や終了の条項の意味が分からないことがあります。依頼側の担当者に「この条項はどういう意味ですか」と聞くことは失礼ではなく、分からないまま結んで後で困るほうが、双方にとって損です。条項の解釈は、弁護士などの専門家にご確認ください。

### エラベルの見解

相談で最も多い思い込みは、「事務ができないと、副業はできない」というものです。実際には、契約と請求の事務は、最初の一件で型を作れば、二件目からは月に一度、決まった日に、決まった形で繰り返すだけになります。負担が重いのは最初の一件だけで、そこを窓口経由で始めれば、型を覚えながら人事の仕事に集中できます。事務ができないから始められない、という人の多くは、最初の一件の負担を、ずっと続く負担だと思っています。

見ていて差がつくのは、事務を「人事の仕事とは別の面倒なもの」と見るか、「副業の条件を自分で決める行為」と見るかです。範囲を決めるのは契約の一部で、締め日を確認するのは請求の一部で、口座を分けるのは入金の一部です。どれも、自分の副業の条件を自分で持つために要ることで、窓口に任せても、この三つは自分で決めます。エラベルでは、依頼側との契約と請求の集約を窓口が担い、担当者は稼働の報告と振込先の登録で済む形にしていますが、範囲・稼働・条件は担当者自身が決め、それを窓口が依頼側との契約に反映しています。事務を減らすことはできても、条件を決めることは代わりにできません。

## 窓口や仲介を通すときに自分がやること

窓口や仲介を通す場合、事務の多くは窓口が担いますが、自分がやることは残ります。

| やること | 内容 | 要点 |
|---|---|---|
| 窓口の規約と取り決めを読む | 窓口と自分の間の取り決め（手数料、支払いの時期、契約の形、禁止事項） | 依頼側との契約書を読む場面は少ないが、窓口との取り決めは読む |
| 振込先の口座を登録する | 副業用の口座を窓口に登録する | [決済・振込先の準備](/media/fukugyo-kessai/) |
| 稼働を報告する | 窓口の形式で、期限までに | 期限を過ぎると翌月扱いになることがある |
| 手数料を理解する | 契約した単価と、実際の入金額の差 | 「入金が少ない」と慌てない。登録時に確認 |
| 依頼側との条件の変更は窓口を通す | 範囲や単価の見直しは、依頼側に直接ではなく窓口に | 窓口の契約と食い違わないように。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |
| 入金の記録を自分でも付ける | 窓口からの入金を、自分の記録表に | 年の終わりの申告の材料になる |
| 窓口の契約の範囲を知る | 依頼側から直接受ける案件、依頼側からの紹介の扱いに制限があるか | 知らずに直接受けると、窓口との取り決めに反する |

窓口経由の要点は、「依頼側との条件の変更は窓口を通す」ことです。窓口が依頼側と契約している案件で、担当者が依頼側と直接条件の話をすると、窓口の契約と食い違います。範囲や単価を変えたいときは、窓口に伝え、窓口が依頼側と話す形にします。窓口によって取り決めが違うので、登録の時点で確認します。

## どちらでも自分で決めておく三つ

直接契約でも窓口経由でも、自分で決めておかないと事務が回らないものが三つあります。

| 決めること | 内容 | 決めないとどうなるか |
|---|---|---|
| 受ける範囲 | どの工程を受け、どの工程を受けないか | 契約書の範囲の条項が曖昧になり、範囲外の依頼が来る。[受ける範囲の決め方](/media/fukugyo-scope/) |
| 締め日と支払日 | 依頼側（または窓口）の締め日、支払日、請求書が届く必要のある日 | 請求が締めに間に合わず、支払いが一か月ずれる。[請求のタイミング](/media/fukugyo-seikyuu-timing/) |
| 振込先の口座 | 副業専用の本人名義の口座 | 本業の給与と混ざり、年の終わりに集計できない。[決済・振込先の準備](/media/fukugyo-kessai/) |

三つの要点は、「事務ではなく、副業の条件である」ことです。範囲は契約の中身で、締め日は請求の日を決めるもので、口座は入金の受け皿です。窓口に事務を任せても、この三つは自分の副業の条件なので、自分で決めます。決めておけば、直接契約でも窓口経由でも、事務は決まった形の繰り返しになります。

## 最初の一件で迷いやすい点

最初の一件では、事務の細かい点で迷います。迷いやすい点と、扱いです。

| 迷う点 | 扱い |
|---|---|
| 契約書に「業務委託」とあるが、雇用と何が違うのか | 一般に、業務委託は成果や業務の遂行に対する契約で、雇用のような指揮命令の関係ではないと整理されています。副業の多くは業務委託。違いの詳細と自分の契約の位置づけは専門家に |
| 請求書に何を書けばよいか | 宛名、日付、項目、額、振込先、自分の名前と連絡先。依頼側の経理が指定する項目があれば従う。[請求書の書き方](/media/fukugyo-seikyuusho/) |
| 登録番号を求められた | 要否は自分の状況で変わる。「確認して連絡します」と返し、専門家に確認する |
| 源泉徴収の話が出た | 依頼側の経理の処理で、入金額が請求額と違うことがある。仕組みは専門家に。入金の記録に差を書いておく |
| 印鑑が要るのか | 電子契約なら不要のことが多い。紙なら認印で済むことが多いが、依頼側に確認 |
| 屋号や開業届が要るのか | 最初の一件には要らない。[屋号を付けるか](/media/fukugyo-yagou/)。開業届の要否は専門家に |
| 経費は何が入るのか | 副業に直接要った支出。[経費にできるもの](/media/fukugyo-keihi/)。判断は専門家に |

迷う点の要点は、「分からないことは、依頼側に聞くか、専門家に確認し、推測で進めない」ことです。契約や税は、推測で進めて後で直すことが難しい領域です。「確認して連絡します」と返して、それで契約が止まることはほとんどありません。分からないことの聞き方は[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/)に整理しています。

## 専門家に確認すべきこと

事務のうち、自分で判断せず、専門家に確認すべきものを分けておきます。

| 確認すること | 誰に | なぜ |
|---|---|---|
| 契約書の条項の意味と、自分にとっての不利 | 弁護士 | 秘密保持、再委託、終了、損害の条項は、後で戻せない |
| 確定申告の要否と方法 | 税理士 | 収入の規模と本業の状況で変わる |
| 登録番号、開業届、経費の扱い | 税理士 | 自分の状況で変わり、一律に答えられない |
| 本業の会社の規定との関係 | 社会保険労務士、または本業の会社の窓口 | 副業の許可、届け出、競業の制限 |
| 業務委託と雇用の線 | 弁護士、社会保険労務士 | 契約の形が実態と合っているか |
| 報酬の未払いへの対応 | 弁護士 | 催告の後の手続き |

専門家の要点は、「最初の一件の契約書と、最初の年の申告」の二つだけは、専門家に一度見てもらうと、その後の案件で使える判断の型ができることです。毎回頼む必要はなく、最初の型を作るときに一度確認しておけば、二件目からは自分で判断できる部分が増えます。本業の会社の規定は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に書いています。

### エラベルの見解

担当する側から見ると、事務で止まっている人は、事務が難しいのではなく、「全部を自分で、最初から、完璧に」やろうとしています。最初の一件を窓口経由で始めれば、契約と請求の多くは窓口が担い、自分は範囲と締め日と口座を決めて、稼働を報告するだけで回ります。その一件で事務の型を覚えてから、直接契約に広げれば、契約書の確認と請求書の作成も、型があるので回ります。

順番として、範囲と締め日と口座の三つを決め、最初の一件は窓口経由で始めて型を覚え、契約書と申告は最初に一度だけ専門家に見てもらい、二件目からは型の繰り返しにする。この順番なら、事務は副業の障害にはなりません。エラベルでは、依頼側との契約と請求の集約を窓口が担い、担当者は範囲・稼働・条件を決めて稼働を報告する形にしています。担当者が人事の仕事に集中できるように事務を引き受けることが、窓口の役割の一つです。

## まとめ

- 請求や契約を自分でやるかは**案件の入口で変わる**。直接契約は全部自分、窓口経由は報告と口座だけ
- 直接契約では**契約書を読み・請求書を作り・入金を確認し・年の終わりに申告を確認し・終了時に整理する**。分からない条項は結ぶ前に聞く
- 窓口経由でも**窓口の取り決めを読み・口座を登録し・稼働を報告し・手数料を理解し・条件の変更は窓口を通す**
- どちらでも**受ける範囲・締め日と支払日・振込先の口座**は自分で決める。事務ではなく副業の条件
- 最初の一件で迷う点は**依頼側に聞くか専門家に確認し、推測で進めない**
- **最初の契約書と最初の年の申告**は専門家に一度見てもらい、型を作る。二件目からは繰り返し

## よくある質問

### 事務が本当に苦手です。それでも副業はできますか

できます。最初の一件を窓口経由で始めれば、契約の型と請求の集約は窓口が担い、自分がやるのは範囲と締め日と口座を決めること、稼働を報告すること、入金を記録することの三つです。この三つは、表計算の一枚と、月に一度の報告で回ります。事務が苦手な人が止まるのは、直接契約で始めて、契約書と請求書と申告を一度に抱えたときです。順番を変えれば、事務は副業の障害になりません。

### 依頼側から「契約書は不要、口約束で」と言われました

口約束は避け、簡単でも文面を残します。範囲、期間、報酬、支払いの時期、秘密保持の五つをメールで送り、「この内容で進めます」と返事をもらえば、契約書が無くても取り決めの記録になります。依頼側が文面を嫌がる場合、後で範囲や報酬でもめたときに、自分を守るものが無くなります。文面の残し方と条件の合意の仕方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。契約の形として問題がないかは、専門家にご確認ください。

### 窓口を通した案件で、依頼側から「次は直接契約で」と言われました

窓口と自分の間の取り決めで、窓口経由の依頼側と直接契約することが制限されていることがあります。依頼側に返事をする前に、窓口に「依頼側から直接契約の話があった」と伝え、窓口の取り決めを確認します。制限があるなら、その旨を依頼側に伝え、窓口経由のまま続けます。制限が無い場合も、窓口に伝えてから進めるほうが、関係を保てます。窓口の取り決めは、登録の時点で読んでおくと、この場面で迷いません。
