施工管理の採用要件を作ると、「施工管理技士の資格」「経験五年以上」「大型案件の経験」「建築も設備も分かる方」「即戦力」「協調性のある方」と膨らみます。経験者の母数が少ない市場で、配置する現場を決めずに、経営者や工事部長が「理想の人」を要件にしてしまうことが原因です。膨らんだ要件は、該当する人が市場にほとんどいないか、該当しても他社に決まるか、資格を必須にして入社後に取得できる人を外してしまうかのどれかになります。結論を先に書くと、**施工管理の要件は「配置する現場」から決め、必須を「その現場の種類と規模に近い工事を回した経験」「竣工まで一通り回した経験」「配置に法令上必要な資格（要るなら）」の三つに絞り、それ以外の種類・大型の経験・配置に不要な資格・年数は歓迎に回す**と、該当する人が現れ、面接で確かめるべきことも決まります。種類と規模と資格の整理は[施工管理採用を代行に出す判断基準](/media/rpo-sekou-kanri-rpo/)に、母集団形成は[施工管理の母集団形成](/media/rpo-sekou-kanri-boshuudan/)にまとめています。

## 施工管理で要件が膨らむ理由

施工管理の要件が膨らむ理由は、三つあります。

一つ目は、配置する現場を決めずに要件を作ることです。「施工管理が足りない」で募集を始めると、どの現場に入れるかが決まっておらず、「どの現場でも回せる人」が要件になります。実際には、入れる現場の種類と規模が決まれば、要件はそこに近い経験で足ります。

二つ目は、資格を「あったほうが安心」で必須にすることです。施工管理技士の資格は、現場の規模や請負の形によって、法令上の配置に関わります。配置に要る現場に入れるなら必須ですが、要らない現場に入れるなら、入社後の取得を前提にできます。区別せずに必須にすると、経験があって資格が無い人（取得前の若手、職人からの転向者）が外れます。配置に関わる法令上の要件は、行政書士など専門家にご確認ください。

三つ目は、経験者の母数が少ない市場で、「理想の人」を要件にすることです。「大型案件の経験があり、建築も設備も分かり、資格があり、即戦力」の人は、市場にほとんどいないか、いても他社が先に決めています。要件を理想で書くほど、該当者がいなくなります。

三つを合わせると、「現場を決めずに、理想の経験と安心のための資格を並べ、人柄の形容詞を足す」のが、膨らむ構造です。

## 必須と歓迎を分ける基準

基準は、「その要件が無いと、配置する現場を回せないか」です。回せないなら必須、あれば早いなら歓迎です。

| 要件 | 必須か歓迎か | 理由 |
|---|---|---|
| 配置する現場の種類（建築・土木・設備・電気・内装）に近い工事を回した経験 | 必須 | 種類が違うと、すぐには回せない。「施工管理経験」ではなく種類で書く |
| 配置する現場の規模に近い工事の経験 | 必須（規模の差が大きい場合）／歓迎（近い場合） | 小規模の経験者に大型を任せるのは難しいが、少し大きい程度なら回る |
| 着工から竣工まで一通り回した経験 | 必須 | 一部の工程だけの経験では、一人で現場を持てない |
| 配置に法令上必要な資格 | 必須（配置に要る現場の場合）／歓迎・入社後取得（要らない現場の場合） | 現場の規模と請負の形で決まる。専門家に確認 |
| 他の種類の工事の経験 | 歓迎 | あれば配置の幅が広がる。無くても配置する現場は回る |
| 大型案件の経験 | 歓迎（配置する現場が大型でない場合） | 大型の経験者が小規模の現場で力を発揮するとは限らない |
| 経験年数 | 歓迎 | 年数より、種類と規模と竣工までの経験のほうが効く |
| 職人・協力会社との関係の作り方 | 面接で確かめる | 経歴で確かめられない。所長が面接で聞く |
| 「即戦力」「協調性」「責任感」 | 要件から外す | 経歴で確かめられず、面接で確かめる項目。要件に書いても絞れない |

表の要点は、「施工管理経験〇年」「資格必須」を、配置する現場を決めずに書かないことです。年数ではなく、「どの種類と規模を、竣工まで」回したかで書きます。資格は「配置に要るか」で決めます。

もう一つの要点は、「大型案件の経験」を必須にしないことです。配置する現場が中規模なら、中規模を竣工まで回した経験のほうが、大型の一部工程を担った経験より効きます。

### エラベルの見解

相談で多いのは、「施工管理の要件を『施工管理技士必須、経験五年以上、大型案件経験、即戦力』にしたが、応募がまったく来ない」というご相談です。配置する現場を聞くと、中規模の新築で、法令上の配置は別の社員が担っていて、採る人には資格が無くても回せる現場でした。それなら要件は「中規模の新築を竣工まで回した経験」で足り、資格も大型も年数も、該当者を減らしているだけでした。

見ていて差がつくのは、「配置する現場を決めてから要件にしているか」です。「〇〇の中規模新築に入れる」→必須は「中規模の建築を竣工まで回した経験」、資格は「入社後取得を支援」、大型は歓迎。ここまで決めれば、要件は一つか二つで済み、該当する人が現れます。エラベルでは、施工管理の担当者に、要件を書く前に「採る人をどの現場に入れるか」を経営者と工事部長に決めてもらっています。

## 必須を三つに絞る手順

手順は四つです。

**一つ目：採る人を入れる現場を決める。** 場所、種類、規模、工期、いまの段階。決まっていなければ、直近で入る可能性のある現場を二つか三つ挙げ、共通する種類と規模を出します。

**二つ目：その現場を回すために、無いと困る経験を書き出す。** 「同じ種類の工事を回した」「近い規模を回した」「竣工まで一通り回した」など。書き出したら、「これが無いと本当に回らないか」を一つずつ問います。

**三つ目：資格の要否を、配置から決める。** その現場で法令上どの配置が要るか。採る人がその配置を担うなら必須、別の社員が担うなら「入社後取得」に。専門家に確認します。

**四つ目：残りを歓迎に回し、形容詞を外す。** 他の種類、大型、年数、配置に不要な資格は歓迎に。「即戦力」「協調性」「責任感」は要件から外し、面接で所長が確かめる項目に移します。

手順の要点は、二つ目で「本当に回らないか」を問うことです。「大型案件の経験」は、配置する現場が中規模なら「回らない」ではありません。「経験五年」は、三年で中規模を竣工まで回した人がいるなら「回らない」ではありません。問うたびに必須が減り、三つに近づきます。

## 経歴で確かめられる要件と、面接で所長が確かめる要件

要件を、経歴（職務経歴書、スカウト媒体のプロフィール）で確かめられるものと、面接で所長が確かめるものに分けます。

経歴で確かめられるのは、「担った工事の種類と規模」「着工から竣工まで回したか、一部の工程か」「持った現場の数」「資格の有無と取得時期」「何年か」です。書類の段階で、必須の三つはここで確かめます。施工管理の経歴は、工事名と規模と担当工程が並ぶ形が多く、種類と規模と竣工までの経験は読み取れます。

面接で所長が確かめるのは、「段取り（工程表をどう組み、遅れをどう取り戻したか）」「職人・協力会社との関係の作り方」「安全と品質の管理で、どこまで自分で判断したか」「トラブルの場面（天候、資材の遅れ、設計の変更）でどう動いたか」「一人で現場を持てるか、まだ補佐が要るか」です。要件の「即戦力」「協調性」「責任感」は、この五つに翻訳して、所長が確かめます。

確かめる方法は、過去の具体的な現場を聞くことです。「一番苦労した現場で、何が起きて、どう動きましたか」「工程が遅れたとき、どこで取り戻しましたか」「職人ともめた場面はありますか。どう収めましたか」。答えの中身より、具体的な場面が出てくるかと、その場面で自分が判断したか、上に聞いたかを見ます。所長が面接に出られない場合は、工事部長か経験の長い施工管理が出ます。所長の時間の確保は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に、面接の設計は[面接の構造](/media/rpo-kouzou-mensetsu/)に書いています。

## 転向元ごとの要件の書き方

施工管理の候補者は、転向元によって持っているものが違います。要件の書き方も、転向元を意識して変えます。

| 転向元 | 経歴で確かめる | 面接で所長が確かめる | 要件に書くときの注意 |
|---|---|---|---|
| ゼネコンの施工管理 | 担った現場の規模と種類、担当工程 | 大型の一部工程しか経験が無い場合、一人で現場を持てるか。小規模での動き方に慣れるか | 「大型案件の経験」が該当するが、竣工まで一通り回したかを確かめる |
| サブコンの施工管理 | 担った設備や電気の種類 | 元請の側で全体を見られるか（元請に移る場合） | 設備の現場に配置するなら合う。建築の現場なら種類が違う |
| 地場の建設会社 | 地域と担った工事の種類、竣工までの経験 | 自社の現場との違い。所長との相性 | 必須の三つがそのまま該当しやすい |
| ハウスメーカー | 担った棟数と工程の管理 | 非住宅の現場に慣れるか。一現場に腰を据える動き方 | 種類が違うので、住宅から非住宅への移行を面接で確かめる |
| 職人から施工管理へ | 担った工種と年数、施工管理の補佐の経験 | 全体を見る動き方に移れるか。書類と工程管理 | 必須の「竣工まで回した経験」を満たさないことが多い。教える体制がある場合だけ、要件を下げて別枠で。資格は入社後取得 |
| 設計事務所から施工側へ | 設計の経験、現場に関わった場面 | 現場での判断に慣れるか | 必須の三つは満たさない。教える体制がある場合だけ別枠で |

表の要点は、「ゼネコン出身」を高く見すぎないことです。大型の一部工程だけの経験では、中規模の現場を一人で持てないことがあります。「竣工まで一通り回した経験」を必須に入れ、面接で確かめます。

## 要件が決まらないときの原因

要件を作ろうとして決まらないとき、原因は要件ではなく、その前にあります。

一つ目は、配置する現場が決まっていないことです。「足りないから採る」で止まっていると、要件は「どの現場でも回せる人」になり、決まりません。直近で入る現場を決めるか、候補の現場の共通点を出します。

二つ目は、資格の要否を「配置」ではなく「安心」で決めていることです。配置に要るか要らないかを専門家に確認し、要らないなら「入社後取得」に下げます。

三つ目は、経験者と未経験を同じ要件で書こうとしていることです。経験者の募集に「未経験歓迎」を足すと、経験者は「誰でもいい会社」と読んで見送り、未経験者は経験者の要件を見て見送ります。分けて出します。

四つ目は、所長や工事部長が要件に関わっていないことです。総務や経営者だけで作ると、「理想の人」になります。所長に「この現場を回すのに、最低限何が要るか」を聞くと、「同じ種類を竣工まで回していれば、あとは教えられる」のように、要件が下がることが多い。

四つのどれかが決まっていないなら、要件より先にそれを決めます。

## 代行に出せる工程

要件作りの工程を、社内で持つものと外に出せるものに分けます。

| 工程 | 社内で持つ | 外に出せる |
|---|---|---|
| 配置する現場の決定 | 経営者と工事部長が決める | 候補の現場の共通点を整理する |
| 資格の要否の決定 | 配置から決め、専門家に確認 | 考え方を示す |
| 必須と歓迎の振り分け | 最終判断（所長の意見を入れる） | 基準に沿った振り分け案。「理想の人」になっている要件を指摘 |
| 経歴で確かめる項目の設計 | ― | 書類の見方（工事名・規模・担当工程の読み方）、スカウトの検索条件への変換 |
| 面接で確かめる項目の設計 | 所長が確かめたいこと | 形容詞を具体的な現場の質問に翻訳。所長の時間を最小にする段取り |
| 求人票・スカウト文面への反映 | 確認 | 要件を文面に落とす。経験者と未経験を分けて出す |

分け方の要点は、「配置する現場・資格の要否・所長の意見は社内で決め、翻訳と振り分けと段取りは外に出せる」ことです。現場の分かる人は社内にいるので、外に出すのは「所長の意見を聞き取って要件に落とし、経歴を読み、面接の段取りをする」役です。担当者に建設業の経験があると、経歴の読み方と所長との話し方が変わります。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

### エラベルの見解

担当する側から見ると、施工管理の要件で最も効くのは、「資格必須」を配置から見直すことと、「大型案件の経験」を歓迎に下げることです。この二つが、経験者の少ない市場で、該当者をさらに減らしている要件です。配置する現場を決め、所長に「最低限何が要るか」を聞くと、要件は「同じ種類を竣工まで回した経験」の一つに近づくことが多い。

エラベルでは、施工管理の案件で担当者を紹介するとき、最初の一週間で「採る人を入れる現場」を経営者と工事部長に決めてもらい、所長に「最低限何が要るか」を聞き取り、そこから必須三つを作るところまでをお願いしています。資格の配置に関わる法令上の要件は、専門家にご確認いただくようお伝えしています。

## まとめ

- 施工管理の要件が膨らむ理由は**配置する現場を決めずに作る・資格を安心で必須にする・少ない市場で理想の人を書く**の三つ
- 基準は**「無いと配置する現場を回せないか」**。必須は**種類と規模に近い工事を回した経験・竣工まで一通り回した経験・配置に法令上必要な資格（要るなら）**の三つ
- **他の種類・大型・年数・配置に不要な資格は歓迎**。**形容詞は要件から外し、所長が面接で確かめる項目に**
- 手順は**配置する現場を決める→無いと困る経験を書き出して問う→資格の要否を配置から決める→残りを歓迎に**
- 経歴で確かめるのは**種類・規模・竣工まで回したか・現場の数・資格・年数**。所長が面接で確かめるのは**段取り・職人との関係・安全と品質の判断・トラブルでの動き・一人で持てるか**
- 「ゼネコン出身」を高く見すぎない。**大型の一部工程だけでは中規模を一人で持てないことがある**
- 決まらないときは**配置する現場・資格の要否・経験者と未経験の分離・所長の関与**のどれかが先に決まっていない

## よくある質問

### 施工管理技士の資格を必須にしないと、現場に配置できないのでは

配置する現場の規模と請負の形によります。法令上の配置に資格が要る現場で、採る人がその配置を担うなら必須です。別の社員がその配置を担っていて、採る人は現場を回す役なら、資格が無くても配置できることがあり、「入社後取得を支援」で母集団を広げられます。「配置」と「安心」を分けて、配置に要るかを行政書士など専門家にご確認ください。

### 「経験五年以上」は書かないほうがよいのですか

年数だけの要件は、大型の一部工程を五年担った人と、中規模を三年で二現場竣工まで回した人を、逆に評価します。書くなら「中規模の建築を竣工まで回した経験（目安として三年程度）」のように、種類と規模と竣工までの経験に年数を添える形にします。年数の目安が無いと不安な場合も、「〇年」より「竣工まで回した現場の数」のほうが、経歴で確かめやすく、該当する人に届きます。

### 経験者がいないので、要件を下げて未経験を採るべきですか

要件を「下げる」のではなく、「分ける」ことをお勧めします。経験者の要件に「未経験歓迎」を足すと、経験者は「誰でもいい会社」と読んで見送り、未経験者は経験者の要件を見て見送ります。経験者の募集はそのまま、未経験や職人からの転向者の募集は別枠で、「教える所長」「資格取得までの道筋」「最初に持たせる現場の規模」を書いて出します。二つの募集は、求人票もスカウトの文面も分けます。
