「評価制度を作って、公平にしたい」という依頼で、観点を並べて五段階の点数を付ける仕組みを作ると、評価者は全員に三か四を付け、社員は「何で決まったか分からない」と言い、納得はむしろ下がります。評価の納得は、点数の公平さではなく、「なぜその評価になったかを、事実で説明できるか」で決まります。結論を先に書くと、**評価制度の設計は、等級の期待から観点を三〜五つ起こし、観点ごとに行動の言葉を置き、評価の面談を本人の事実を聞く場として設計し、記録を事実と判断を分けた形にする四つで組み、処遇への接続と法令上の整理は依頼側と専門家に置き、評価者の目線合わせは記録の読み合わせで行い、最初の期間の分布と反応で直します。**案件として受ける形は[評価制度の設計の副業の実務](/media/fukugyo-hyouka-seido-shigoto/)に、三つのつながりは[人事制度を設計する](/media/fukugyo-skill-jinji-seido/)に書いています。ここでは、評価の設計の型に絞ります。

## 「点数を公平に」から始めると納得が下がる

| 点数から始める形 | 何が起きるか |
|---|---|
| 観点ごとに五段階 | 評価者は中央に寄せる。差が出ない |
| 総合点で並べる | 観点の重みが均等になり、等級の期待とずれる |
| 点数の根拠が無い | 本人に「なぜ三か」を説明できない |
| 「コミュニケーション力」に点数 | 行動の言葉が無く、印象の数値化 |
| 面談が結果を伝える場 | 本人は言われるだけで、納得しない |

選考の評価シートと同じ構造です。点数ではなく、観点ごとに「事実」と「判断」を分けて残せば、説明できる評価になります。評価シートの型は[評価シートを作る](/media/fukugyo-skill-hyouka-sheet/)に書いています。

## 設計の四つ

| 決めること | 中身 |
|---|---|
| 観点 | 等級の期待から起こす。三〜五つ。「この段階の人に期待すること」を、行動で |
| 行動の言葉 | 観点ごとに、「期待どおり」「期待を超える」「期待に届かない」が、どういう行動かを一行ずつ |
| 評価の面談 | 結果を伝える場ではなく、本人の事実（その期間に何をしたか）を聞き、観点に照らす場 |
| 記録 | 観点ごとに、事実（本人と評価者が確認した場面）と判断（三段階）。総合点を作らない |

四つのうち、最初に作るのは観点と行動の言葉です。等級が無い会社では、「役割ごとの期待」を等級の代わりに置きます。等級の考え方は[人事制度を設計する](/media/fukugyo-skill-jinji-seido/)に書いています。

### エラベルの見解

担当する側から見ると、評価制度で最も差がつくのは、「行動の言葉」を、依頼側で実際に起きた場面から起こせるかです。受ける側は、観点ごとに「主体性：自ら課題を見つけて行動する」のような一般的な定義を置きます。それは、どの会社にも書ける言葉で、評価者は自分の部下の行動と照らせません。「この会社で、この段階の人が、期待どおりに動いた場面」を、評価者に「去年、良かったと思った場面を一つ」と聞いて起こすと、「顧客の要望が変わったとき、上司に聞く前に代替案を二つ用意して持ってきた」のような、この会社の行動の言葉になります。エラベルで担当者を選ぶ企業には、「評価の観点の言葉は、御社で実際にあった場面から作られていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、行動の言葉を作るとき、評価者に「良かった場面」と「期待に届かなかった場面」を一つずつ聞き、その場面から言葉を起こすこと。個人の名前は書きません。

## 観点と行動の言葉の起こし方

| 順 | 中身 |
|---|---|
| 一 | 等級（または役割）ごとの期待を、一文で。「この段階の人には、〇〇を一人で回すことを期待する」 |
| 二 | 期待を三〜五つの観点に分ける。仕事の中身に関わるもの（成果の出し方）と、動き方に関わるもの（周りとの関わり） |
| 三 | 評価者に、観点ごとに「良かった場面」「届かなかった場面」を一つずつ聞く |
| 四 | 場面から、「期待どおり」「超える」「届かない」の行動の言葉を一行ずつ |
| 五 | 依頼側（経営者と評価者）が確認。他社にも書ける言葉が残っていれば、場面に戻る |

観点は、等級が上がると変わります。段階ごとに観点の一枚を作り、段階の数だけ一枚があります。一枚に収まらない段階は、期待が多すぎます。

## 評価の面談の型

| 段 | 中身 |
|---|---|
| 一 | 本人が、期間中に取り組んだことを、観点ごとに場面で話す。「〇〇の観点で、この期間に一番大きかった場面は」 |
| 二 | 評価者が、自分が見た場面を足す。本人と評価者で事実を確認する |
| 三 | 観点ごとに、行動の言葉に照らして、三段階のどれかを本人と評価者で確認する |
| 四 | 食い違いがあれば、事実の欄に両方を書き、判断は評価者が行い、理由を伝える |
| 五 | 次の期間の期待を、観点ごとに一言 |

面談は「結果を伝える場」ではなく、「事実を確認して照らす場」です。先に評価者が結果を決めて伝えると、本人は反論するか黙るかで、納得が生まれません。面談の型は、[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)の「事実と判断を分ける」と同じ考え方です。

## 記録の形

| 項目 | 事実 | 判断 |
|---|---|---|
| 観点一 | 本人と評価者が確認した場面。一〜三行 | 期待どおり／超える／届かない |
| 観点二 | 同上 | 同上 |
| 観点三 | 同上 | 同上 |
| 次の期間の期待 | 観点ごとに一言 | — |
| 本人の意見 | 食い違いがあれば、本人の言葉で | — |

総合点は作りません。処遇への接続（昇給、昇格）は、観点ごとの判断を依頼側の制度で対応させ、その対応の構造と法令上の整理は依頼側と専門家で決めます。担当者は記録の形を作るまでです。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「評価者の目線合わせは、評価の前に研修で行うもの」というものです。実際には、研修で観点の説明を聞いても、評価者は自分の部下の場面と照らせず、評価のときに印象に戻ります。目線が合うのは、評価の後に、評価者同士が「記録の事実の欄」を読み合わせ、「この事実で、この判断でよいか」を確かめるときです。最初の評価の期間は、この読み合わせを一度入れる。それで、行動の言葉の解釈が揃い、次の期間から判断が近づきます。受ける側がその場で使える判断としては、最初の評価の期間の予定に、「評価者の記録の読み合わせ」の日を最初から入れておくこと。研修の代わりに、この日を置きます。面接官の揃え方（[面接官トレーニングを行う](/media/fukugyo-skill-mensetsukan/)）と同じ型です。

## 処遇への接続と法令上の整理

評価の結果を昇給・昇格・賞与にどう対応させるかは、報酬の制度と原資の判断で、依頼側が決めます。対応の変更が労働条件に関わる場合は、法令上の整理があると一般に整理されていて、規程の変更や手続きは専門家（社労士等）の確認に従います。担当者は「観点ごとの判断が、処遇にどう対応するかの構造の案」を出すまでで、額や率は扱いません。個別の判断は専門家にご確認ください。

## 最初の評価の期間で見ること

| 見ること | 読み方 |
|---|---|
| 判断の分布 | 全員が「期待どおり」なら、行動の言葉が粗いか、評価者が中央に寄せている。読み合わせへ |
| 面談の実施 | 行われていない評価者がいれば、型の負担が大きい。短くする |
| 本人の意見の欄 | 食い違いが多い観点は、行動の言葉が曖昧 |
| 評価者の困りごと | 「この観点は見えない」が多ければ、観点を見直す |

分布は件数で見て、割合で断定しません。見えたことは、観点と行動の言葉の見直しの材料にし、直すかは依頼側が決めます。

## 評価の情報の扱い

評価の記録は、個人の処遇に関わる情報で、扱いに注意が要ります。担当者は、記録の形を作り、分布と困りごとを傾向として見るまでで、個人の評価の結果を手元に置きません。読み合わせに同席する場合も、個人の名前を記録しません。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が点数の表を求める | 事実と判断を分ける形を示し、総合点が納得を下げる構造を伝える |
| 行動の言葉が一般的 | 評価者の「場面」から起こし直す |
| 面談が結果の通知になっている | 型の一（本人が場面を話す）から始める形に |
| 評価者が全員を「期待どおり」に | 読み合わせを入れる。行動の言葉を場面で具体に |
| 処遇への対応を担当者に求められる | 構造の案まで。額と率と規程は依頼側と専門家 |
| 個人の評価の結果が手元に残る | 傾向だけを記録。終了時に消す |

## まとめ

- 「点数を公平に」から始めると納得が下がる。**事実で説明できる評価**にする
- 設計は**観点・行動の言葉・面談・記録**の四つ
- 観点は**等級の期待から三〜五つ**。行動の言葉は**依頼側で実際にあった場面**から
- 面談は**本人が場面を話し、事実を確認して照らす場**。結果の通知にしない
- 記録は**事実と判断を分け、総合点を作らない**
- **処遇への接続と法令上の整理は依頼側と専門家**。額と率と規程に踏み込まない。個別の判断は専門家にご確認ください
- 目線合わせは**研修ではなく記録の読み合わせ**。最初の期間に日を入れる
- 個人の評価の結果を手元に置かない

## よくある質問

### 依頼側から「評価に数字の目標（売上など）を入れたい」と言われました

数字の目標は、観点の一つとして置けますが、観点の全部を数字にすると、数字に出ない役割（後輩の育成、他部門との調整）が評価されず、その役割を担う人が離れます。「成果の観点に数字を、動き方の観点に行動の言葉を」と分けて置く形を提案します。目標の水準を担当者が決めることはしません。

### 評価者が「部下の場面を見ていないので評価できない」と言います

見ていないのが実態なら、面談の型の一（本人が場面を話す）で、本人から事実を聞く形にします。評価者が見ていなくても、本人が語った場面を行動の言葉に照らせば、判断はできます。次の期間に向けて、評価者が場面を見る接点（週次の短い確認）を置く提案をします。「見ていない」を「評価できない」で終わらせず、事実を集める型に変えます。

### 制度を入れた後、社員から「前より厳しくなった」と言われました

行動の言葉が「期待どおり」の水準を明確にしたことで、これまで印象で「良い」とされていた人が「期待どおり」になった、という構造が多い。それ自体は制度が機能している証拠ですが、説明が足りないと「厳しくなった」と受け取られます。導入の説明で、「点数が下がるのではなく、基準が見えるようになる」を伝える資料を、依頼側が使える形で作ります。処遇に不利益が出る場合の扱いは、法令上の整理があるので専門家に確認します。
