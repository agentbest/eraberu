副業で人事を受けていると、この相談はどの会社でも出てきます。「社員ではなく業務委託で頼みたい」「フリーランスに常駐してもらいたい」「副業の人を週三日入れたい」。会社は、社会保険や残業代の話をしたいのではなく、単に柔軟に人を使いたいだけのことが多いのですが、形によっては、契約書の表題と実態が食い違います。結論を先に書くと、**労働基準法第9条は「労働者」を「職業の種類を問わず、事業又は事務所…に使用される者で、賃金を支払われる者をいう」と定義しており、労働基準法研究会報告（昭和60年12月19日）は「『労働者性』の判断に当たっては、雇用契約、請負契約といった形式的な契約形式のいかんにかかわらず、実質的な使用従属性を、労務提供の形態や報酬の労務対償性及びこれらに関連する諸要素をも勘案して総合的に判断する必要がある」としています。**つまり、契約書に「業務委託契約書」と書いても、それだけでは決まりません。個別の判断は弁護士や労働基準監督署にご確認ください。請負の現場での線引きは[偽装請負にならない業務設計](/media/fukugyo-law-gisou-ukeoi/)に、業務委託側の保護は[フリーランス保護法の実務影響](/media/fukugyo-law-freelance-hou/)にまとめています。

## 出発点は二つの基準

報告は、まず条文の読み方から始めています。

「労働基準法第9条は、その適用対象である『労働者』を『使用される者で、賃金を支払われる者をいう』と規定している。これによれば、『労働者』であるか否か、すなわち『労働者性』の有無は『**使用される＝指揮監督下の労働**』という労務提供の形態及び『**賃金支払**』という報酬の労務に対する対償性、すなわち報酬が提供された労務に対するものであるかどうかということによって判断されることとなる。この二つの基準を総称して、『**使用従属性**』と呼ぶこととする」。

そのうえで、こう続きます。「しかしながら、現実には、指揮監督の程度及び態様の多様性、報酬の性格の不明確さ等から、具体的事例では…これらの基準によって『労働者性』の判断をすることが困難な場合がある。このような限界的事例については、『使用従属性』の有無…を判断するに当たり、『**専属度**』、『**収入額**』等の諸要素をも考慮して、総合判断する」。

**構造はこうです。**本体は「指揮監督下の労働」と「報酬の労務対償性」の二つ。これで決まらない限界的な事例で、「事業者性」「専属性」などの補強要素を足して総合判断する。会社に説明するときも、この二層構造から入ると伝わります。

## 指揮監督下の労働を見る四つの目

報告は「指揮監督下の労働」の判断基準を、次のように整理しています。

**イ 仕事の依頼、業務従事の指示等に対する諾否の自由の有無。**「『使用者』の具体的な仕事の依頼、業務従事の指示等に対して諾否の自由を有していれば、他人に従属して労務を提供するとは言えず、対等な当事者間の関係となり、**指揮監督関係を否定する重要な要素**となる。これに対して、具体的な仕事の依頼、業務従事の指示等に対して拒否する自由を有しない場合は、一応、指揮監督関係を推認させる重要な要素となる」。ただし、包括的な仕事を受諾した以上その一部について拒否の自由が制限される場合や、専属下請のように事実上拒否できない場合があり、「直ちに指揮監督関係を肯定することはできず、その事実関係だけでなく、契約内容等も勘案する必要がある」とも書かれています。

**ロ 業務遂行上の指揮監督の有無。**業務の内容及び遂行方法について具体的な指揮命令を受けていることは「指揮監督関係の基本的かつ重要な要素」。ただし「**通常注文者が行う程度の指示等に止まる場合には、指揮監督を受けているとは言えない**」。また、命令・依頼等により**通常予定されている業務以外の業務に従事することがある場合**は、一般的な指揮監督を受けているとの判断を補強する重要な要素になる、とされています。

**ハ 拘束性の有無。**「勤務場所及び勤務時間が指定され、管理されていることは、一般的には、指揮監督関係の基本的な要素である」。ただし業務の性質上や安全確保上、必然的に指定される場合があり、「当該指定が業務の性質等によるものか、業務の遂行を指揮命令する必要によるものかを見極める必要がある」。

**ニ 代替性の有無（指揮監督関係の判断を補強する要素）。**本人に代わって他の者が労務を提供することが認められているか、本人の判断で補助者を使うことが認められているか。「**労務提供の代替性が認められている場合には、指揮監督関係を否定する要素のひとつ**となる」。

**報酬の労務対償性。**報告は、労働基準法第11条の賃金の定義を引いたうえで、「報酬が『賃金』であるか否かによって逆に『使用従属性』を判断することはできない」としつつ、「**報酬が時間給を基礎として計算される等労働の結果による較差が少ない、欠勤した場合には応分の報酬が控除され、いわゆる残業をした場合には通常の報酬とは別の手当が支給される**等報酬の性格が使用者の指揮監督の下に一定時間労務を提供していることに対する対価と判断される場合には、『使用従属性』を補強することとなる」としています。

**ここが実務で一番当たります。**副業の人事の報酬を「時給×稼働時間」で設計し、休んだら差し引き、多く働いたら追加で払う。この形は、報告の文言にそのまま当てはまります。

### エラベルの見解

担当する側から見ると、この相談は**会社を守る仕事であると同時に、自分を守る仕事**です。業務委託で入ったつもりが、実態としては指揮命令を受け、時間で管理され、他の仕事を受ける余裕がない状態になる。この形は、会社にとっては後から労働者性を争われることになり、副業側にとっては残業代も社会保険もない長時間労働になります。どちらも幸せになりません。

実務で効くのは、**契約の文言ではなく、働き方の設計に手を入れること**です。報告が挙げている要素を、そのまま設計項目として使えます。依頼を断れる余地を残す。成果物や役務の範囲を先に決めて、日々の進め方は任せてもらう。常駐の時間を固定せず、打ち合わせの時間だけ合わせる。報酬を月額固定か成果ベースにして、時間単価での精算にしない。他の案件を受けることを制限しない。これらを最初の合意でつくっておくと、双方が楽になります。エラベルでは、依頼側が担当者の経歴を見て選び、担当者も条件が合うときだけ受ける形にしているので、この設計は最初の条件の詰めに直結します。

## 補強要素と、会社に渡す点検表

報告は、限界的事例で使う補強要素として、次を挙げています。

**事業者性の有無。**「イ 機械、器具の負担関係」（本人が所有する機械・器具が著しく高価な場合には「自らの計算と危険負担に基づいて事業経営を行う『事業者』としての性格が強く、『労働者性』を弱める要素となる」）、「ロ 報酬の額」（同様の業務に従事している正規従業員に比して著しく高額である場合には「事業者」に対する代金の支払と認められ、労働者性を弱める要素となる）、「ハ その他」（**業務遂行上の損害に対する責任を負う、独自の商号使用が認められている**等を事業者としての性格を補強する要素とする裁判例がある）。

**専属性の程度。**「特定の企業に対する専属性の有無は、直接に『使用従属性』の有無を左右するものではなく、特に専属性がないことをもって労働者性を弱めることとはならないが、『労働者性』の有無に関する判断を補強する要素のひとつ」。イとして、他社の業務に従事することが制度上制約され、また時間的余裕がなく事実上困難である場合は「専属性の程度が高く、いわゆる経済的に当該企業に従属していると考えられ」労働者性を補強する。ロとして、**報酬に固定給部分がある、業務の配分等により事実上固定給となっている、その額も生計を維持しうる程度のものである**等、報酬に生活保障的な要素が強いと認められる場合も、同様に補強する。

**その他。**裁判例が労働者性を肯定する判断の補強事由としているものとして、**①採用、委託等の際の選考過程が正規従業員の採用の場合とほとんど同様であること、②報酬について給与所得としての源泉徴収を行っていること、③労働保険の適用対象としていること、④服務規律を適用していること、⑤退職金制度、福利厚生を適用していること**が挙げられています。

**⑤は現場でよく起きます。**業務委託の人に社員と同じ研修を受けさせる、社内表彰の対象にする、福利厚生を使わせる。善意でやっていることが、後から補強事由として見られる可能性があります。

副業の人事が作るのは、次の形です。個別の適否の判断は弁護士や労働基準監督署にご確認ください。

| 点検する項目 | 見るところ |
|---|---|
| 依頼の受け方 | 個別の依頼を断れるか。断った実績があるか |
| 業務の進め方 | 遂行方法まで指示しているか。注文者が通常行う程度に止まっているか |
| 通常業務以外 | 契約外の作業を頼んでいないか |
| 場所と時間 | 常駐や勤務時間の指定があるか。業務の性質による必然か、管理のためか |
| 代替性 | 本人以外が担当することや補助者を使うことを認めているか |
| 報酬の決め方 | 時間給ベースか。欠勤控除や残業手当に相当するものがあるか |
| 機械・器具 | 誰が用意しているか |
| 損害の責任 | 業務遂行上の損害の責任をどちらが負う契約か |
| 専属性 | 他社の業務を制約していないか。時間的に事実上困難になっていないか |
| 選考過程 | 社員の採用と同じ選考をしていないか |
| 税と保険 | 源泉徴収の扱い、労働保険の適用 |
| 社内制度 | 服務規律、研修、表彰、福利厚生、退職金の適用 |

**フリーランス法との関係。**特定受託事業者に係る取引の適正化等に関する法律は、業務委託の相手方が「個人であって、従業員を使用しないもの」等であることを前提に、取引条件の明示や報酬の支払期日、契約解除の予告などを定めています。**業務委託として整えるなら、この法律の義務も同時にかかる**ので、契約書と明示書面はセットで設計します。

### エラベルの見解

外に出してよいのは、働き方の設計、契約書と明示書面の項目立て、点検表、社内制度の適用範囲の整理までで、「この働き方が労働者に当たるか」「この契約は有効か」といった個別の判断は、弁護士や労働基準監督署の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この案件で一番大事なのは、**会社に「業務委託で使いたい理由」を言葉にしてもらうこと**です。理由が「社会保険料を抑えたい」「残業代を払いたくない」であれば、その動機のまま設計すると、実態が雇用に寄ったまま名前だけ業務委託という形になります。逆に、理由が「専門性のある人に、限られた範囲を任せたい」「常勤では採れない人に来てもらいたい」であれば、設計は自然と業務委託の形に近づきます。動機と形が一致していれば、点検表の項目はだいたい素直に通ります。ここを聞かずに契約書だけ直しても、半年後に元に戻ります。エラベルでは、依頼側が担当者を選び、担当者も条件を見て受ける形なので、最初にこの話ができる人ほど、案件が長続きしています。

## まとめ

- 労働基準法第9条は、労働者を「**事業又は事務所に使用される者で、賃金を支払われる者**」と定義している
- 判断は**契約の形式のいかんにかかわらず、実質で行う**。本体は「**指揮監督下の労働**」と「**報酬の労務対償性**」の二つ（使用従属性）
- 指揮監督下の労働は、**諾否の自由／業務遂行上の指揮監督／拘束性／代替性**の四つで見る
- 報酬が**時間給ベースで、欠勤控除があり、残業に別の手当が出る**形は、使用従属性を補強する
- 限界的事例では、**事業者性**（機械器具の負担、報酬の額、損害の責任、商号）と**専属性**（他社業務の制約、固定給・生活保障的性格）で総合判断する
- 裁判例は、**社員と同じ選考／給与所得としての源泉徴収／労働保険の適用／服務規律／退職金・福利厚生**を、労働者性を肯定する補強事由としている。個別の判断は弁護士や労働基準監督署にご確認ください

## よくある質問

### 契約書に「業務委託契約」と書いてあれば大丈夫ですか

労働基準法研究会報告は「『労働者性』の判断に当たっては、雇用契約、請負契約といった形式的な契約形式のいかんにかかわらず、実質的な使用従属性を、労務提供の形態や報酬の労務対償性及びこれらに関連する諸要素をも勘案して総合的に判断する必要がある場合がある」としています。契約書の表題だけでは決まりません。実務では、報告が挙げている要素（諾否の自由、業務遂行上の指揮監督、拘束性、代替性、報酬の決め方、事業者性、専属性など）を項目にして、実態を点検します。個別の判断は弁護士や労働基準監督署にご確認ください。

### 業務委託の人に、社内の研修を受けてもらってもよいですか

報告は、裁判例が労働者性を肯定する判断の補強事由としているものとして、採用・委託等の際の選考過程が正規従業員とほとんど同様であること、給与所得としての源泉徴収、労働保険の適用、服務規律の適用、退職金制度や福利厚生の適用を挙げています。社内制度の適用は、この文脈で見られる可能性があります。業務の遂行に必要な情報提供（システムの使い方、扱う情報の取り決めなど）と、社員向けの人材育成とを分けて設計するのが実務です。適否の個別の判断は、弁護士や労働基準監督署にご確認ください。

### 報酬を時給で決めたいと言われました

報告は、報酬が時間給を基礎として計算される等労働の結果による較差が少ない、欠勤した場合には応分の報酬が控除される、残業をした場合には通常の報酬とは別の手当が支給される、といった性格が認められる場合には「使用従属性」を補強することとなる、としています。時給での見積りそのものが直ちに問題になるわけではありませんが、欠勤控除や時間外の割増に相当する精算まで行う形は、報告の文言に近づきます。実務では、想定稼働から月額を決めて固定で支払い、大きく超える場合に協議する形が採られることがあります。個別の設計の判断は、弁護士にご確認ください。
