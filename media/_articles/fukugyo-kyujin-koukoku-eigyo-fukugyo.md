求人広告の営業として、多くの企業に媒体を提案し、原稿を一緒に作り、掲載後の反応を見てきた。人事の部署にいたわけではないが、求人広告の使い方は誰よりも知っている。この経験は、人事の副業で売れるのか。結論を先に書くと、**求人広告の営業の経験は、「媒体の選び方と原稿の作り方と反応の見方」で売れます。売れるのは、「依頼側に合う媒体の選定」「求人原稿の作成と改善」「掲載後の反応の見方と直し方」「媒体の営業との交渉の代行」の四つです。依頼側の多くは、媒体を選ぶ根拠がなく、原稿を媒体の営業に任せきりで、掲載後の反応を見ずに次の媒体に移っています。媒体を売る側にいた人が、使う側に立つと、この詰まりがそのまま埋まります。「媒体を売っていた」ではなく、「媒体を使う側に立って、選び、書き、直す」と売ります。ただし、媒体の料金と仕様は変わるため、記事では書かず、依頼側と一緒に公式の情報で確認します。**求人原稿のライティングの副業は[求人原稿のライティングの副業案件](/media/fukugyo-kyujin-raiting-fukugyo/)に、原稿の実務は[求人原稿のライティングの副業の実務](/media/fukugyo-kyujin-raiting-shigoto/)に、前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)にまとめています。

## この経歴の何が売れるか

求人広告の営業の経験を、依頼側の側に立った工程に置き換えた棚卸しです。

| 営業の経験 | 使う側の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 複数の媒体の特性を知っている | 依頼側の職種、地域、規模、予算で、どの媒体が合うかを、根拠つきで選ぶ | 媒体を営業に勧められるまま選んでいる依頼側が多い |
| 多くの企業の原稿を作ってきた | 求人原稿を、依頼側の魅力と候補者の目線で書く。媒体ごとの構成の型 | 原稿を媒体の営業に任せきりで、自社の言葉になっていない依頼側が多い |
| 掲載後の反応を見てきた | 閲覧、応募、面接の段階で反応を見て、原稿と条件のどこを直すかを決める | 反応を見ずに「この媒体は駄目だった」と次に移る依頼側が多い |
| 媒体の営業と交渉してきた | 依頼側の側に立って、媒体の営業に掲載の条件や原稿の修正を交渉する | 媒体の営業に言われるままの依頼側が多い |
| 多業種の採用を見てきた | 業種と職種ごとに、どの媒体で、どの原稿の型で応募が来やすいかの型 | 「うちの業種は応募が来ない」と諦めている依頼側に、型を示せる |
| 応募が来ない原稿の共通点を知っている | 原稿の診断（何が足りず、何が多いか）の型 | 原稿の何が悪いか分からない依頼側 |
| 予算の使い方を見てきた | 限られた予算を、どの媒体に、どの時期に、どう配分するかの設計 | 予算が一つの媒体に偏っている依頼側 |

売れるものの要点は、「売る側にいたからこそ、使う側の詰まりが見える」ことです。求人広告の営業は、依頼側が媒体を選ぶ根拠を持たず、原稿を任せきりにし、反応を見ないことを、営業の側から何度も見てきています。その詰まりを、使う側に立って埋める。これが、求人広告の営業の経験の売り方です。ただし、媒体の料金と仕様は変わるため、記事や提案の中で断定せず、依頼側と一緒に公式の情報で確認します。原稿の作り方は[求人原稿のライティングの副業の実務](/media/fukugyo-kyujin-raiting-shigoto/)に、文章の技能は[文章力をどう磨くか](/media/fukugyo-writing/)に、数字の見方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 売りにくい点とその扱い

求人広告の営業の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 売る側から使う側への切り替え | 「結局、前の会社の媒体を勧めるのでは」「媒体を売りたいだけでは」 | 「私は媒体を売りません。御社の側に立って、合う媒体を根拠つきで選び、原稿を書き、反応を見て直します」と最初に示す。特定の媒体に偏らない選定の型を持つ |
| 前の会社との線 | 「前の会社の顧客の情報や、料金の内部の情報を持ち込むのでは」。自分にとっても、退職後の競業と守秘 | 前の会社の顧客と競合する依頼側を避け、前の会社の料金や内部の情報を持ち込まない。媒体の情報は公式のものだけを使う。退職後の条件を確認する |
| 料金の情報の扱い | 「媒体の料金を教えてほしい」と依頼側に求められる | 料金と仕様は変わるため、自分の記憶で答えず、依頼側と一緒に公式の情報を確認する形にする。前の会社で知った内部の料金は使わない |

扱い方の要点は、「媒体を売らない、と最初に示す」ことです。求人広告の営業の転身で依頼側が最も警戒するのは、「結局、媒体を売りに来たのでは」ということです。「私は媒体を売りません。御社の側に立ちます」と最初に示し、特定の媒体に偏らない選定の型（職種、地域、規模、予算で選ぶ根拠）を持てば、警戒は消えます。料金と仕様は、前の会社で知った内部の情報を使わず、公式の情報を依頼側と一緒に確認します。前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、求人広告の営業から転身して続いている人と、警戒されて案件が取れない人の差は、媒体の知識の量ではなく、「媒体を売らない、と最初に示しているか」です。取れない人は、前の会社の媒体を中心に話し、依頼側は「営業が来た」と感じ、案件になりません。続いている人は、「御社の職種と地域と予算なら、この媒体とこの媒体が候補で、理由はこうです。料金は公式の情報で一緒に確認しましょう」と、使う側の言葉で話し、依頼側から「初めて根拠のある媒体の選び方を聞いた」と評価されています。

見ていて差がつくのは、掲載後の反応を見て直す工程を、範囲に入れているかです。依頼側の多くは、掲載して応募が来なければ「この媒体は駄目だった」と次に移り、原稿と条件を直していません。求人広告の営業は、反応を見て原稿を直すと応募が変わることを、営業の側から何度も見てきています。「掲載して終わりではなく、反応を見て、原稿と条件を直すところまで」を範囲に入れている人は、依頼側の媒体の費用を無駄にせず、「同じ媒体で応募が変わった」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、媒体を売らず、選定と原稿と反応の工程を明確にしている担当者に、媒体の使い方で詰まっている依頼側がついています。求人広告の営業の転身は、知識ではなく、立場の切り替えで始まります。

| 掲載後の反応の見方と直し方 | 反応を見てきた経験で入れる | 「掲載したが応募が来ない依頼側」を範囲の一言に |
| 媒体の営業との交渉の代行 | 交渉してきた経験で入れる | 「媒体の営業に言われるままの依頼側」に、依頼側の側で交渉する形を |

探し方の要点は、「掲載したが応募が来ない依頼側」から入ることです。依頼側にとって、掲載の費用を払ったのに応募が来ないことは、最も分かりやすい損失で、原稿と反応の見方で直せることが多く、求人広告の営業の経験が最も効きます。一件で応募を変えられれば、媒体の選定と予算の配分に広げられます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、原稿の副業の始め方は[求人原稿のライティングで副業を始めるには](/media/fukugyo-kyujin-raiting-hajimekata/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。求人広告の営業の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 原稿の技能の直接性 | 原稿は最初から書け、依頼側にとって即戦力 | 「人事未経験だから」と下げない。原稿の工程の単価で |
| 成果物で受けやすい工程 | 原稿一本、媒体の選定の根拠、予算の配分の設計は、成果物で | 成果物で受けると、単価の議論が明確になる |
| 反応を見て直す継続 | 掲載後の反応の見方と直しは、月額で受けやすい | 月に何本、何回、と枠を決めて月額に |
| 媒体の営業との交渉の代行 | 依頼側の費用を下げる価値は分かりやすい | 「下げた費用」ではなく、交渉の代行の工程として単価に |
| 媒体からの報酬を受けないこと | 媒体を売らない立場なので、媒体からの紹介の報酬は受けない | 依頼側からの報酬だけで。媒体からの報酬を受けると、選定の根拠が疑われる |
| 前の会社との契約の条件 | 退職後の競業と守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「媒体からの報酬を受けず、依頼側からの報酬だけで受ける」ことです。求人広告の営業の転身では、媒体との関係が残っていて、媒体からの紹介の報酬を受けられることがありますが、受けると「媒体を売る側」に戻り、依頼側から見た選定の根拠が疑われます。依頼側の側に立つなら、依頼側からの報酬だけで受け、媒体の選定は根拠だけで行います。前の会社との契約に退職後の条件がある場合は、それを確認し、個別の判断は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

求人広告の営業から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、前の会社との契約の条件（退職後の競業、守秘、顧客との接触）を確認する | 個別の判断は専門家に |
| 二、前の会社の顧客と競合する依頼側を、避ける対象として書き出す | 前の会社との線 |
| 三、「媒体を売らない。依頼側の側に立つ」を、自分の言葉で書く | 立場の切り替え |
| 四、媒体の選定の根拠の型（職種、地域、規模、予算）を、特定の媒体に偏らない形で作る | 料金と仕様は公式の情報で確認する前提 |
| 五、原稿の診断と書き直しの型を、自分の言葉で作る | 前の会社の原稿の資産は持ち込まない |
| 六、「媒体を使う側に立って、選び、書き、直す」の一言を作る | 「求人広告の営業でした」で終わらせない |
| 七、登録先に、範囲と、媒体を売らない線を登録する | 掲載したが応募が来ない依頼側 |
| 八、原稿の診断と書き直しを一件、成果物で受け、反応を見て直すところまで回す | 選定と予算の配分に広げる材料に |

順番の要点は、「三」の立場の切り替えを、自分の言葉で書いておくことです。求人広告の営業は、媒体を売る側の言葉が体に染みついていて、無意識に媒体の良さを語ります。「媒体を売らない。依頼側の側に立つ」と言葉にし、面談で「営業が来た」と感じさせない話し方を用意します。媒体の情報は、前の会社の内部の情報ではなく、公式の情報だけを使う、と決めておきます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「求人広告の営業は媒体を売る仕事で、人事の副業とは立場が逆だ」というものです。実際には、依頼側の詰まり（媒体を選ぶ根拠が無い、原稿を任せきり、反応を見ない）は、営業の側から最もよく見えていて、使う側に立てば、その詰まりをそのまま埋められます。立場が逆なのではなく、立場を切り替えれば、最も詰まりが見える経験です。切り替えの条件は、媒体を売らないこと、前の会社の情報を持ち込まないこと、料金と仕様は公式の情報で確認することの三つです。

順番として、前の会社との契約の条件を確認し、競合する依頼側を避ける対象として書き出し、媒体を売らない立場を自分の言葉で書き、特定の媒体に偏らない選定の型を作り、原稿の診断と書き直しの型を自分の言葉で作り、使う側に立って選び書き直す一言を作り、登録先に範囲と線を登録し、原稿の診断と書き直しを一件成果物で受けて反応を見て直すところまで回す。この順番で、求人広告の営業の転身は、「媒体を売る側」から「媒体を使う側の詰まりを埋める人」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、媒体を売らず、選定と原稿と反応の工程を明確にしている担当者に、媒体の使い方で詰まっている依頼側がついています。求人広告の営業の転身は、知識ではなく、立場の切り替えで始まります。

## まとめ

- 求人広告の営業の経験は**「媒体の選び方と原稿の作り方と反応の見方」**で売れる。**媒体の選定・原稿の作成と改善・反応の見方と直し方・媒体の営業との交渉の代行**の四つ
- **「媒体を売っていた」ではなく「媒体を使う側に立って、選び、書き、直す」**と売る。「媒体を売らない」を最初に示す
- 売りにくい点は**売る側から使う側への切り替え・前の会社との線・料金の情報の扱い**。前の会社の顧客と内部の情報は持ち込まず、料金と仕様は公式の情報で確認
- **掲載して終わりではなく、反応を見て直すところまで**を範囲に入れる
- 案件は**掲載したが応募が来ない依頼側**から。原稿の診断と書き直しで応募を変える
- 単価は**媒体からの報酬を受けず、依頼側からの報酬だけで**。原稿と選定は成果物、反応の見方は月額。前の会社との条件は専門家に確認

## よくある質問

### 依頼側から「一番安い媒体はどれか」と聞かれました。前の会社で料金を知っているので答えられます

前の会社で知った内部の料金は使わず、公式の情報を依頼側と一緒に確認する形にします。料金と仕様は変わるものであり、前の会社の内部の情報を使うことは守秘の線を越えます。「料金は変わるので、候補の媒体の公式の情報を一緒に確認しましょう。選ぶ根拠は、料金だけでなく、御社の職種と地域で応募が来やすいかです」と、根拠の型で答えます。「一番安い」ではなく「御社に合う」で選ぶことが、使う側に立つ担当者の価値です。線の引き方は[守秘の線を越える](/media/fukugyo-shippai-8/)に整理しています。

### 前の会社の媒体を、依頼側に勧めてよいですか

依頼側の職種、地域、規模、予算で、根拠つきで合うなら、候補の一つとして示して構いません。ただし、前の会社の媒体だけを勧める、前の会社の媒体を優先する、前の会社から紹介の報酬を受ける、という形は、「媒体を売る側」に戻ることになり、依頼側の信頼を失います。候補を複数示し、根拠を並べ、依頼側が選ぶ形にし、媒体からの報酬は受けません。前の会社との契約に、退職後の条件がある場合は、それも確認します。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

### 原稿は書けますが、掲載の後の運用（応募者の対応、面接）は経験がありません

範囲を、媒体の選定、原稿の作成と改善、反応の見方と直し方、交渉の代行に絞り、応募者の対応と面接は依頼側か実務の担当者が担う形にします。「掲載までと、掲載後の反応を見て直すところまでを担います。応募者の対応と面接は御社で」と示せば、範囲が明確です。掲載後の工程も担いたいなら、応募者の対応の型を学び、小さく受けて経験を作ります。エラベルのような登録先では、工程ごとに担当者を分けて依頼できる依頼側もあります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、応募者の対応は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に整理しています。
