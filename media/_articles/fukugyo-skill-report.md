月末に「今月のレポートをください」と言われ、やったこと（スカウトを何通、面接の日程を何件、求人票を直した）を並べて送ると、依頼側からの返事は「ありがとうございます」だけで、何も動きません。作業の一覧は、担当者が働いたことは伝わっても、依頼側が判断する材料になっていないからです。レポートは、稼働の証明ではなく、決める人が次を決めるための一枚です。結論を先に書くと、**採用のレポートは、期間・KPI三つと見る指標・詰まりの段と根拠・手当てとその結果・判断してほしいこと・次にやることの構造で一枚にし、週次と月次で中身を変え、数字は件数で断定せず、悪い数字を隠さずに読み方を添え、判断してほしいことには選択肢と期限を付けます。**報告の三層は[報告のしかた](/media/fukugyo-houkoku/)に、頻度は[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/)に、会社側が求める項目は[採用代行のレポートに入れてもらう項目](/media/rpo-report-koumoku/)に書いています。ここでは、一枚の型に絞ります。

## 作業の一覧が読まれない理由

| 作業の一覧 | 決める人に起きること |
|---|---|
| 「スカウト〇通送信」 | それで何が起きたかが分からない |
| 「面接日程〇件調整」 | 速かったのか遅かったのかが分からない |
| 「求人票を修正」 | 何を直して、応募がどう変わったかが分からない |
| 「順調です」 | 判断することが無い |
| 長い | 読まれない |

決める人が知りたいのは、「数字はどうか」「どこが詰まっているか」「自分は何を決めればよいか」の三つです。作業は、その根拠として一行あれば足ります。

## 読者は決める人

| 読者 | 知りたいこと | 一枚での扱い |
|---|---|---|
| 決める人（経営者、採用の責任者） | 数字・詰まり・判断すること | 主。一枚の先頭から |
| 依頼側の人事の担当 | 次にやること、止まっていること | 一枚の後半 |
| 現場の面接官 | 自分の段の候補者の動き | 別に、段ごとの一行 |

一枚は決める人に向けて書き、人事の担当と面接官には、必要な部分だけを切り出します。全員に同じ一枚を送ると、誰にも刺さりません。

### エラベルの見解

担当する側から見ると、レポートで最も差がつくのは、「判断してほしいこと」の欄があるかどうかです。受ける側は、レポートを「報告」として、事実を並べて終わります。ただ、決める人は、事実を読んで自分で判断を組み立てる時間がありません。「一次の日数が詰まりです。面接官の枠を週二枠預かる案と、一次を人事だけにする案があります。〇日までにどちらかをお決めください」と書いてあれば、決める人はその場で決められます。エラベルで担当者を選ぶ企業には、「担当者のレポートに、御社が決めることが書いてありますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、一枚を書き終えたら、「判断してほしいこと」の欄が空でないかを確かめること。空なら、詰まりが見えていないか、担当者が自分で決めてしまっているかのどちらかです。

## 一枚の構造

| 順 | 欄 | 中身 |
|---|---|---|
| 一 | 期間 | 週か月。前回との比較の対象 |
| 二 | KPI三つと見る指標 | 件数で。前回の件数を横に。[KPIを設計する](/media/fukugyo-skill-kpi/)の三つ |
| 三 | 詰まりの段と根拠 | ファネルの一枚から。数か日数か理由か。[採用ファネルを可視化する](/media/fukugyo-skill-funnel/) |
| 四 | 手当てとその結果 | 前回決めた手当てを実行したか。数字がどう動いたか。「この件数では断定できない」も含めて |
| 五 | 判断してほしいこと | 選択肢と、それぞれの代償と、期限 |
| 六 | 次にやること | 担当者がやること。依頼側にやってほしいこと |
| 七 | 止まっていること | 確認待ち、判断待ち、記録の欠け |

七つで一枚です。作業の一覧は、四の「手当て」の根拠として一行ずつ入れば足ります。

## 週次と月次で中身を変える

| 頻度 | 中身 | 長さ |
|---|---|---|
| 週次 | 二（KPIの件数）、六（次にやること）、七（止まっていること）だけ | 数行 |
| 月次 | 七つ全部。ファネルの一枚を添付 | 一枚 |
| 区切り（案件の節目） | 月次に加えて、期間全体で直したことと、直っていないこと | 一〜二枚 |

週次に七つ全部を入れると、作る時間が稼働を圧迫し、読む側も飽きます。週次は「動いている」と「止まっている」が分かれば足ります。三層の考え方は[報告のしかた](/media/fukugyo-houkoku/)に書いています。

## 数字は件数で、断定しない

| 断定する書き方 | 置き換え |
|---|---|
| 「返信率が〇%に上がりました」 | 「返信は先月〇件、今月〇件。送った数は同じ。この件数では傾向として断定できない」 |
| 「手当てが効きました」 | 「手当ての後、一次の日数は短くなった。同時期に面接官の枠が増えた影響もある」 |
| 「順調です」 | 「KPI三つのうち二つが前月と同じ水準、一つが下。下の理由は〇〇」 |
| 「市場が厳しい」 | 「応募の数は前月より少ない。求人票と媒体は前月と同じ。外の要因の可能性はあるが、まず求人票のタイトルを試す」 |

割合は、件数が少ないと大きく揺れます。件数のまま並べ、揺れることを添えます。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「悪い数字は、良く見える言い方に変えて書く」というものです。実際には、悪い数字を柔らかく書いたレポートは、決める人が詰まりに気づく時期を遅らせ、後で「なぜ早く言わなかったのか」になります。悪い数字は、そのまま書き、隣に「読み方」（何が原因の候補か、次に何を試すか）を添えます。読み方が添えてあれば、悪い数字は「担当者が見えている」証拠になり、信頼はむしろ上がります。受ける側がその場で使える判断としては、一枚の中で一番悪い数字を、隠さずに二の欄の先頭に置くこと。先頭にあると、決める人はそこから読み、判断してほしいことにつながります。

## 判断してほしいことの書き方

| 要素 | 中身 |
|---|---|
| 何を決めてほしいか | 一文。「一次の面接官の枠を増やすか、一次を人事だけにするか」 |
| 選択肢 | 二つか三つ。それぞれの代償（稼働、費用、候補者への影響）を一行 |
| 担当者の案 | どれを勧めるか、理由を一行。決めるのは依頼側 |
| 期限 | いつまでに決めてほしいか。過ぎたらどうなるか（候補者が流れる、来月も同じ詰まり） |

「ご検討ください」で終えると、検討されません。選択肢と期限があれば、決める人はその場で決められます。提案の一枚の型は[提案のまとめ方](/media/fukugyo-teian/)に書いています。

## 作る時間を稼働に含める

| 頻度 | 作る時間の考え方 |
|---|---|
| 週次 | 一覧と記録から数行。短く |
| 月次 | ファネルの一枚の更新と、七つの欄。一枚に収める |

レポートを作る時間を稼働に含めずに引き受けると、作る時間が無くなり、作業の一覧に戻ります。見積もりの段階で、「月次のレポートに要する時間」を工程として入れます。見積もりの型は[見積もりの出し方](/media/fukugyo-mitsumori/)に、資料の作り方は[資料の作り方](/media/fukugyo-shiryou/)に書いています。

## 担当者が替わっても同じ形で

| 残すもの | 置き場所 |
|---|---|
| 七つの欄の型（空の一枚） | 依頼側の共有の場所 |
| 過去のレポート | 同じ場所に、期間の順で |
| 数字の出どころ（一覧のどの列から数えたか） | 型の末尾に一行 |

型が残っていれば、次の担当者も同じ形で出せ、依頼側は過去と比べられます。担当者ごとに形が変わると、比較ができなくなります。引き継ぎの形は[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が作業の一覧を求める | 作業は「手当て」の根拠として一行ずつ。一覧は別紙にして、一枚は七つの欄で |
| 「判断してほしいこと」が書けない | 詰まりが見えていない。ファネルの一枚に戻る |
| 数字が悪く、書きにくい | そのまま書き、読み方を添える。先頭に置く |
| 長くなる | 七つの欄を各二行以内に。ファネルは添付に |
| 決める人が読まない | 「判断してほしいこと」を件名か冒頭に。期限を付ける |
| 作る時間が無い | 週次を数行に減らす。月次の時間を稼働に含める |

## まとめ

- 作業の一覧は稼働の証明で、**判断の材料ではない**
- 読者は**決める人**。人事の担当と面接官には必要な部分だけ
- 一枚は**期間・KPIと見る指標・詰まりと根拠・手当てと結果・判断してほしいこと・次にやること・止まっていること**の七つ
- **週次は数行、月次は一枚**。区切りで直したことと直っていないこと
- 数字は**件数で、断定しない**。悪い数字は隠さず先頭に置き、読み方を添える
- 判断してほしいことは**選択肢・代償・担当者の案・期限**。「ご検討ください」で終えない
- 作る時間を**稼働に含める**。型を残して担当者が替わっても同じ形で

## よくある質問

### 依頼側から「もっと詳しいレポートを」と言われました

何を詳しくしたいかを聞きます。「作業の詳細」なら別紙に、「数字の内訳」ならファネルの一枚の経路別・求人別を添付に、「候補者ごとの状況」なら一覧を共有の場所で見てもらう形に、と分けます。一枚そのものは長くしません。詳しさは添付で足し、一枚は決める人が読む長さを保ちます。

### レポートに候補者の氏名を書いてよいですか

一枚には書きません。段階ごとの数と、詰まりと、判断することで足ります。特定の候補者について判断してほしいこと（内定を出すか、条件をどうするか）がある場合は、応募の番号か媒体のIDで書き、詳細は一覧か記録を見てもらいます。レポートは共有の範囲が広がりやすいので、個人情報を載せない形にします。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

### 手当ての結果が出るまで時間がかかり、月次で報告できることがありません

「実行したが、結果はまだ」と書きます。実行したこと自体が報告で、結果が出る時期（次の月、次の次の月）を添えます。結果が出る前に次の手当てを重ねると、どちらが効いたか分からなくなるので、「今月は結果待ち。新しい手当ては入れない」も判断として書きます。検証の考え方は[文面を検証する](/media/fukugyo-skill-ab-test/)と同じです。
