同じように副業をしている知人は、依頼側から次々と更新と紹介をもらっている。自分は人事の経験年数では負けていないのに、更新が続かない。何が違うのかが分からない。結論を先に書くと、**依頼側から評価される副業人材の共通点は、経験の長さではなく、「担当できる範囲が明確」「依頼側の仕組みの中で動く」「判断の所在を守る」「成果を状態の変化で見せる」「いつでも引き継げる状態にしている」の五つです。**依頼側の担当者は、外部の担当者を「任せて安心か」で見ていて、その判断の材料はこの五つに集まります。経験年数は、五つを持っている人の中で比べられる二次的なものです。信頼を積む日々の行動は[信頼を積む小さな行動](/media/fukugyo-shinrai/)に、続かない人の共通点は[続かない人の共通点](/media/fukugyo-tsuzukanai/)に、向いている人の特徴は[人事の副業に向いている人](/media/fukugyo-tekisei/)にまとめています。

## 依頼側が評価している軸

依頼側の担当者が外部の担当者をどう評価しているかを、担当者の立場から見ます。

| 担当者の立場 | 評価の軸 | なぜその軸か |
|---|---|---|
| 社内に説明する | 何を任せているか、一言で言えるか | 上長や面接官に「外部の人に〇〇を頼んでいる」と言える必要がある |
| 情報を管理する | 依頼側の仕組みの中で動いているか | 候補者の情報が外部の担当者の手元に散らばると、担当者の責任になる |
| 判断の責任を持つ | 外部の担当者が判断に踏み込まないか | 合否や条件を外部が決めると、担当者が説明できない |
| 上長に成果を報告する | 成果を、上長が分かる言葉で受け取れるか | 稼働の量ではなく、何が変わったかを上長に言いたい |
| 担当者自身が異動することがある | 自分がいなくなっても続く形か | 引き継げない外部の担当者は、担当者の異動と一緒に切れる |

軸の要点は、「担当者は自分の立場を守れるかで見ている」ことです。担当者は、外部の担当者の能力を評価しているのではなく、その人に任せることで自分の社内の立場が保てるかを見ています。五つの共通点は、すべて担当者の立場を守るものです。担当者の社内の構造は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に書いています。

## 五つの共通点

五つの共通点は、それぞれ担当者の評価の軸に対応しています。

| 共通点 | 中身 | 担当者から見た価値 |
|---|---|---|
| 一、範囲が明確 | 「スカウトの運用と求人票」のように工程で言え、受けないことも言える | 担当者が社内に「外部に〇〇を頼んでいる」と一言で言える。[受ける範囲の決め方](/media/fukugyo-scope/) |
| 二、依頼側の仕組みの中で動く | 候補者の情報をATSの中で扱い、記録を依頼側の共有に残し、自分のツールに持ち出さない | 担当者がいつでも状況を見られ、情報管理の責任を負わずに済む。[クライアントのツールに合わせる](/media/fukugyo-kokyaku-tool/) |
| 三、判断の所在を守る | 合否、条件、社内の優先は依頼側に返し、自分の範囲の判断は自分でする。線を議事録に残す | 担当者が「外部が勝手に決めた」と言われずに済む。[権限がないと動けない場面](/media/fukugyo-kengen-nai/) |
| 四、成果を状態の変化で見せる | 「送信〇通」ではなく「日程の理由の辞退が無くなった」と、上長が分かる言葉で報告する | 担当者が上長に「外部に頼んでこう変わった」と言える。[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/) |
| 五、いつでも引き継げる | 記録が依頼側にあり、型が文書になり、判断の所在が残っている | 担当者が異動しても、外部の担当者が止まっても、採用が続く。[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/) |

五つの要点は、「五」の引き継げる状態が、他の四つの結果として自然にできることです。範囲が明確で、依頼側の仕組みの中で動き、判断の所在を残し、成果を報告に書いていれば、引き継ぎに必要なものはすでに依頼側の側にあります。五つは別々の努力ではなく、一つの動き方の五つの面です。

### エラベルの見解

相談で最も多い思い込みは、「評価されるには、人事の経験が長く、実績が多いことが要る」というものです。実際には、依頼側の担当者が「また頼みたい」と言う人と、経験年数や実績の数は、ほとんど相関していません。経験が長くても、範囲が「採用全般」で、自分のツールで候補者を管理し、合否に口を出し、報告が稼働の量で、記録が手元にしか無い人は、更新されていません。経験が浅くても、五つを持っている人は、更新と紹介が続いています。

見ていて差がつくのは、「担当者の立場で考えているか」です。評価される人は、担当者が社内で何を説明し、何の責任を持ち、何に困っているかを見て、その困りごとを減らす形で動いています。評価されない人は、自分の仕事の質を上げることに集中していて、担当者の立場を見ていません。仕事の質は同じでも、担当者の立場を守る形で動く人が、担当者から評価されます。エラベルでは、依頼側が担当者を選ぶ仕組みなので、選んだ後に「選んでよかった」と担当者が感じるかどうかを見ていますが、その判断は、この五つに集まっています。

## 評価されない人との違い

五つの共通点を、評価されない人の動き方と並べると、違いが見えます。

| 場面 | 評価される人 | 評価されない人 |
|---|---|---|
| 範囲を聞かれた | 「スカウトの検索と送信、一次返信、面接の設定まで。評価と合否は御社で」 | 「採用のことなら何でも」 |
| 候補者の情報の置き場 | 依頼側のATSの中だけ。自分の端末に保存しない | 自分の表計算やクラウドで管理し、結果だけ報告する |
| 候補者から条件を聞かれた | 「担当者に確認して回答します」と返し、依頼側の回答を伝える | 「たぶん〇〇です」と自分で答える |
| 月次の報告 | 工程別の時間と、状態の変化と、次の見込みを一枚に | 「今月は〇通送り、〇件対応しました」 |
| 依頼側の担当者が異動した | 新任が記録と型を見て、そのまま続けられる | 新任が「何をどこまで頼んでいたか分からない」と言い、契約が切れる |
| 提案 | 事実→影響→選択肢の形で、判断を依頼側に返す | 「こうすべきです」と結論から言う |
| 遅れそうなとき | 分かった時点で新しい期限と影響を伝える | 期限を過ぎてから謝る |

違いの要点は、「同じ仕事をしていても、依頼側の側から見える形が違う」ことです。スカウトを同じ数だけ送っていても、ATSの中で送って記録が残っている人と、自分の表で管理して結果だけ報告する人では、担当者から見える安心感が違います。仕事の中身より、仕事の見え方が、評価を分けます。報告の形は[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/)に、提案の形は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

## 評価が更新と紹介につながる仕組み

五つを持っていると、担当者の中で何が起き、それが更新と紹介にどうつながるかを見ます。

| 担当者の中で起きること | つながる先 |
|---|---|
| 「任せて安心」と感じる | 更新の判断が「続けるか」ではなく「次の期もお願いします」から始まる。[契約更新のされ方](/media/fukugyo-koushin/) |
| 上長に説明しやすい | 上長が「外部に頼んでよかった」と言い、予算が続く |
| 自分の立場が守られている | 担当者が外部の担当者を「自分を助けてくれる人」と見る。範囲を広げる相談が来る |
| 別の会社の人事に話したくなる | 「うちで頼んでいる人がいる」と自分の話として話す。紹介が起きる。[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/) |
| 異動しても連れて行ける | 担当者が転職先で採用を任されたとき、思い出して声をかける |
| 一度の失敗が許される | 遅れや誤りが「この人でも」で済む。関係が切れない |

仕組みの要点は、「担当者が自分の話として、外部の担当者を人に話す」ことです。紹介は、頼んで起きるものではなく、担当者が話したくなって起きます。話したくなるのは、担当者自身が「頼んでよかった」と感じ、その理由を一言で言えるときです。五つの共通点は、その一言の材料になります。

## 経験が浅くても評価される理由

五つの共通点は、経験の長さを前提にしていません。経験が浅い人が評価される理由は、ここにあります。

| 共通点 | 経験の長さとの関係 |
|---|---|
| 範囲が明確 | 経験が浅いほど、範囲は小さく明確になる。「型に沿った送信と一次返信」は、一年目でも言える。[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/) |
| 依頼側の仕組みの中で動く | 経験に関係なく、最初の一件から守れる。慣れたツールが無いほうが、依頼側のツールに合わせやすい |
| 判断の所在を守る | 経験が浅いほど、自分で判断せず依頼側に返す習慣が付きやすい。経験が長いと、自分の判断で進めがち |
| 成果を状態の変化で見せる | 報告の書き方の問題で、経験とは無関係 |
| いつでも引き継げる | 記録の習慣の問題で、経験とは無関係 |

理由の要点は、「経験が長いことが、五つの妨げになることがある」ことです。経験が長い人は、範囲を広く言い、慣れたツールを使い、自分の判断で進め、報告を省きがちです。それは本業の社内では評価されても、外部の担当者としては、担当者の立場を守らない動き方になります。経験が浅い人は、その癖が無い分、五つを最初から守れます。経験の浅い時期の始め方は[人事1年目でもできること](/media/fukugyo-1nenme/)に書いています。

## 自分の評価を確かめる方法

自分が依頼側からどう評価されているかは、担当者に聞いても「大丈夫です」と返ってくるので、行動で確かめます。

| 確かめること | 見方 |
|---|---|
| 担当者が聞きに来るか | 「あの候補者は」「今どうなっている」と聞きに来なければ、二と五は整っている |
| 更新の話がどこから始まるか | 「続けますか」なら様子見。「次の期も」なら評価されている |
| 範囲を広げる相談が来るか | 「これもお願いできないか」と来るなら、一と三が信頼されている |
| 担当者が上長の言葉を伝えてくるか | 「上長が『外部に頼んでよかった』と言っていた」と伝わるなら、四が効いている |
| 担当者の異動の後、新任から連絡が来るか | 来るなら五が整っている。来なければ、記録と型が依頼側に残っていない |
| 別の会社から紹介で声がかかるか | かかるなら、担当者が自分の話として話している |
| レビューを頼んだとき、具体の言葉が返ってくるか | 「助かっています」だけなら、まだ一言で言える材料が無い。[レビューをもらう](/media/fukugyo-review/) |

確かめる要点は、「担当者が聞きに来ないこと」が、最も分かりやすい合図だということです。聞きに来ないのは、無関心ではなく、聞かなくても分かる状態にあるからです。聞きに来る担当者がいるなら、二（仕組みの中で動く）と五（引き継げる）のどこかが欠けています。

### エラベルの見解

担当する側から見ると、依頼側から評価され続けている人は、自分の仕事の質より、依頼側の担当者が社内で困らないかを先に考えています。担当者が上長に説明する言葉、担当者が情報管理で負う責任、担当者が異動したときに残るもの。それを整えてから、自分の仕事の質を上げています。順番が逆の人は、仕事の質が高くても、担当者の立場を守らない形になり、評価が上がりません。

順番として、案件の最初に範囲を一言にし、依頼側の仕組みの中で動くことを決め、判断の所在を議事録に残し、報告を状態の変化で書き、記録と型を依頼側に残す。この五つを最初の一か月で整えれば、経験の長さに関わらず、担当者から「任せて安心」の評価が得られます。エラベルでは、依頼側が担当者を選ぶとき、経歴の長さより、この五つを持っているかを見て提示しています。選ばれる担当者は、経験の長さではなく、依頼側の立場を守る動き方で選ばれています。

## まとめ

- 評価される共通点は**範囲が明確・依頼側の仕組みの中で動く・判断の所在を守る・成果を状態で見せる・いつでも引き継げる**の五つ。経験の長さではない
- 依頼側の担当者は**自分の社内の立場が守れるか**で外部の担当者を見ている。五つはすべて担当者の立場を守るもの
- 同じ仕事でも**依頼側の側から見える形**が違う。仕事の中身より見え方が評価を分ける
- 五つが揃うと**更新が確認になり・上長の評価が続き・範囲が広がり・紹介が起き・失敗が許される**
- **経験が長いことが妨げになることがある**。経験が浅い人は五つを最初から守れる
- 評価は**担当者が聞きに来ないか・更新の始まり方・範囲の相談・上長の言葉・新任からの連絡・紹介**で確かめる

## よくある質問

### 五つのうち、最初に整えるべきものはどれですか

「範囲が明確」からです。範囲が一言で言えないと、依頼側の担当者は社内に説明できず、他の四つを整えても「何を頼んでいる人か」が曖昧なままです。範囲を工程で二つか三つに絞り、受けないことも言えるようにしてから、依頼側の仕組みの中で動く、判断の所在を残す、と順に整えます。範囲の決め方は[受ける範囲の決め方](/media/fukugyo-scope/)に、プロフィールへの書き方は[プロフィールの書き方](/media/fukugyo-profile/)に整理しています。

### 五つを守っているつもりですが、更新されませんでした

更新されない理由が、自分の側にあるか、依頼側の側にあるかを分けます。依頼側の予算、方針の変更、担当者の異動、採用の終了は、依頼側の側の理由で、五つを守っていても更新されません。自分の側の理由なら、五つのどれが欠けていたかを、担当者が聞きに来ていたか、報告の形、記録の置き場で振り返ります。更新されなかったときの整理は[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/)に書いています。

### 本業では評価が高いのに、副業では評価されにくいのはなぜですか

本業の社内では、自分の判断で進める、慣れたツールで効率よく動く、範囲を広く持つ、が評価されます。外部の担当者としては、それが担当者の立場を守らない動き方になります。本業の評価の軸と、外部の担当者の評価の軸は違い、本業で評価が高い人ほど、その癖を副業に持ち込みやすくなります。副業では、自分の判断より依頼側の判断を、慣れたツールより依頼側のツールを、広い範囲より明確な範囲を、と切り替えることが要ります。切り替えの考え方は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に整理しています。
