副業で人事を受けていると、採用の支援をしている中で「業績が厳しいので、内定を取り消せないか」と相談されることがあります。内定は「まだ入社していないから自由に取り消せる」と考えている依頼先がありますが、そうではありません。この記事は、採用内定の取消しの前提を、厚生労働省の資料が引用する最高裁判決と、若者雇用促進法に基づく指針に沿って整理したものです。結論を先に書くと、**厚生労働省のパンフレットは、最高裁の判決として、採用内定通知のほかには労働契約締結のための特段の意思表示が予定されていない場合、企業からの採用内定通知は労働者からの労働契約の申込みに対する承諾であり、誓約書の提出と相まって、就労の始期を定めた解約権を留保した労働契約が成立したと解する、という内容を引用しています。そのうえで、採用内定の取消事由は、採用内定当時知ることができず、また知ることが期待できないような事実であって、これを理由として取り消すことが解約権留保の趣旨・目的に照らして客観的に合理的と認められ社会通念上相当として是認することができるものに限られる、とされています。**個別の事案の判断は弁護士にご確認ください。内定辞退への対応は[内定辞退への対応](/media/fukugyo-law-naitei-jitai/)に、解雇は[解雇の要件](/media/fukugyo-law-kaiko/)にまとめています。

## 最高裁が示した枠組み

厚生労働省のパンフレット「適切な労務管理のポイント」には、裁判例（最高裁第二小法廷 昭和54年7月20日判決）として、次の内容が引用されています。

「採用内定の実態は多様であるため、その法的性質を一義的に論断することはできないが、採用内定通知のほかには労働契約締結のための特段の意思表示が予定されていない場合、企業からの採用内定通知は労働者からの労働契約の申込みに対する承諾であり、誓約書の提出と相まって、就労の始期を定めた解約権を留保した労働契約が成立したと解する。採用内定の取消事由は、採用内定当時知ることができず、また知ることが期待できないような事実であって、これを理由として採用内定を取消すことは、解約権留保の趣旨、目的に照らして客観的に合理的と認められ社会通念上相当として是認することができるものに限られる。」

ここから読み取れることを整理します。

| 読み取れること | 実務での意味 |
|---|---|
| 実態は多様で、性質を一義的に論断できない | 「内定＝常に労働契約成立」でも「内定＝単なる予約」でもない。自社の内定の出し方の実態を確かめる |
| 労働契約が成立したと解される場合がある | その場合、取消しは解雇に準じた枠組みで判断される |
| 取消事由は、内定当時知ることができず、知ることが期待できないような事実 | 内定を出した時点で知っていた（知り得た）事情を理由にはできない |
| 客観的に合理的と認められ、社会通念上相当として是認できるものに限られる | 労働契約法第16条と同じ言葉づかい |

**適用される規定。**同パンフレットは、採用内定により労働契約が成立したと認められる場合、採用内定取消しには労働契約法第16条のほか、労働基準法第20条、第22条等の規定が適用される、としています。つまり、解雇予告（第20条）と、退職時の証明（第22条）の枠組みが関わります。

**やむを得ない事情で取り消す場合。**パンフレットでは、やむを得ない事情で採用内定取消しをする場合、使用者は、解雇予告等の解雇手続を適正に行うこと、採用内定者が採用内定取消しの理由について証明書を請求した場合は遅滞なく交付すること、を行う必要がある、と説明されています。

## 指針が求めること

**若者雇用促進法に基づく指針。**厚生労働省のリーフレット「若者の募集・採用等に関する指針」では、青少年の雇用の促進等に関する法律（若者雇用促進法）に基づき、若者を募集・採用等する事業主などが講ずべき措置をまとめた指針として、「青少年の雇用機会の確保及び職場への定着に関して事業主、特定地方公共団体、職業紹介事業者等その他の関係者が適切に対処するための指針」が紹介されています。

リーフレットには、内定取消しについて次の内容が示されています。「労働契約が成立したと認められる場合には、客観的に合理的な理由を欠き、社会通念上相当であると認められない採用内定取消しは無効とされることに十分に留意し、採用内定取消しを防止するため、最大限の経営努力などを行うこと。やむを得ない事情により採用内定取消しなどを行う場合には、就職先の確保について最大限の努力を行うこと。」

**ハローワークへの通知。**リーフレットでは、職業安定法施行規則第35条第2項により、採用内定取消しなどを行おうとする事業主は、所定の様式により、あらかじめ公共職業安定所等に通知することとなっている、と注記されています。厚生労働省のパンフレットにも、やむを得ない事情で採用内定取消しまたは入職時期繰下げをするときは、あらかじめハローワーク等に通知を行うことが必要だと説明されています。

**新規学校卒業者について。**パンフレットは、事業主の一方的な都合による新規学校卒業者に対する採用内定取消しおよび入職時期繰下げは、その円滑な就職を妨げるものであり、特に採用内定取消しは、対象となった学生および生徒本人ならびに家族に計り知れないほどの打撃と失望を与えるとともに、社会全体に対しても大きな不安を与えるものであり、決してあってはならない重大な問題である、としています。

**入社日の扱い。**パンフレットでは、採用内定時に定められていた入社日は変更しないものの、事業主の都合で休業させ実際の就業をさせない措置（自宅待機）を行う場合には、その期間について労働基準法第26条に定める休業手当を支払う必要がある、とされています。また、事業主の都合で入社日を延期する措置（入社日の延期）を行う場合には、原則として採用内定者の合意を得る必要がある、と説明されています。

### エラベルの見解

担当する側から見ると、この相談を受けたときにまず伝えるべきは、「内定の取消しは、解雇に準じた枠組みで判断され得る」という点です。相談で見ていると、経営は「まだ入社していないから大丈夫」と考えていることが多く、そこを直さないと話が進みません。そのうえで、厚生労働省のパンフレットが挙げる選択肢を並べます。入社日は変えずに自宅待機とする場合は休業手当が要ること、入社日を延期する場合は原則として本人の合意が要ること、取消しに至る場合はハローワーク等への通知と解雇の手続が要ること。

もう一つ大事なのは、「取消事由は内定当時知ることができず、知ることが期待できないような事実に限られる」という点です。業績の悪化を理由にする場合、内定を出した時点でその見通しをどこまで持っていたかが問われ得ます。採用の計画を立てた時期、内定を出した時期、業績が変わった時期を時系列で整理すると、依頼先自身も状況を冷静に見られます。この整理は、採用の支援をしている副業の人事だからこそ作れます。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、採用と制度の両方を扱える人は、この局面で選ばれます。

## 人事が踏む手続

副業の人事が整える手続です。取消しの可否の判断は弁護士に渡します。

| 段階 | やること |
|---|---|
| 前提の確認 | 自社の内定の出し方（通知の内容、誓約書の有無、その後の手続）を確かめ、労働契約が成立したと解される実態かを整理する |
| 時系列 | 採用計画、内定の時期、事情が変わった時期、判明した事実の時期を並べる |
| 回避の検討 | 取消しを防止するための経営努力として何ができるか（配置の変更、入社時期の調整、他の費用の見直し）を並べて記録する |
| 代替の選択肢 | 入社日を変えずに自宅待機（休業手当が必要）、入社日の延期（原則として本人の合意が必要） |
| 専門家への相談 | 取消しの可否、手続の適法性を弁護士に確認する |
| 通知 | 職業安定法施行規則に基づく公共職業安定所等への通知（あらかじめ、所定の様式で） |
| 解雇の手続 | 解雇予告等の手続を適正に行う |
| 証明書 | 取消しの理由について証明書を請求されたら、遅滞なく交付する |
| 就職先の確保 | やむを得ない事情により行う場合、就職先の確保について最大限の努力を行う |
| 本人への伝え方 | 誰が、いつ、どう伝えるか。一方的な通知で終わらせない |

**新規学校卒業者は特に。**厚生労働省のパンフレットが「決してあってはならない重大な問題」と明記している以上、新卒の内定取消しは、他の手段を尽くしたうえでの最後の選択になります。就職先の確保への努力も、指針に明記されています。

### エラベルの見解

外に出してよいのは、内定の出し方の実態の整理、時系列の作成、回避の選択肢の整理と記録、代替の選択肢（自宅待機、入社日の延期）の説明、通知と手続の期限の一覧、本人への伝え方の設計までで、「この内定は取り消せるか」「この事由は取消事由に当たるか」といった判断は、弁護士の範囲です。

担当する側から見ると、この領域で副業の人事にできる最も価値のある仕事は、実は平時にあります。内定通知に何を書き、誓約書を取るのか、内定から入社までの間に何をするのか。これを設計しておくと、いざというときに「自社の内定がどういう性質か」を説明できます。逆に、内定の出し方が担当者ごとに違い、書面も残っていない依頼先では、状況の整理から始めることになります。採用の運用を設計してきた人が、この平時の設計を担えます。エラベルでは、依頼側が担当者を選べるので、採用の設計から入れる人は、この領域でも頼まれています。

## まとめ

- 厚生労働省が引用する最高裁の判決は、採用内定通知のほかに特段の意思表示が予定されていない場合、**就労の始期を定めた解約権を留保した労働契約が成立したと解する**、という内容
- **取消事由は、採用内定当時知ることができず、また知ることが期待できないような事実**であって、**客観的に合理的と認められ社会通念上相当として是認することができるものに限られる**
- 労働契約が成立したと認められる場合、**労働契約法第16条のほか、労働基準法第20条（解雇予告）、第22条（証明書）等**が適用される
- 採用内定取消しなどを行おうとする事業主は、**あらかじめ公共職業安定所等に通知**することとされている（職業安定法施行規則）
- **自宅待機**の場合は労働基準法第26条の休業手当、**入社日の延期**は原則として採用内定者の合意が必要
- やむを得ない事情により行う場合は、**就職先の確保について最大限の努力**を行うこととされている。可否の判断は弁護士にご確認ください

## よくある質問

### 「まだ入社していないから、自由に取り消せる」と言われました

厚生労働省が引用する最高裁の判決は、採用内定通知のほかに特段の意思表示が予定されていない場合、就労の始期を定めた解約権を留保した労働契約が成立したと解する、という内容です。労働契約が成立したと認められる場合、取消しには労働契約法第16条のほか、労働基準法第20条、第22条等の規定が適用される、と説明されています。「自由に取り消せる」という前提は、この整理と合いません。まず自社の内定の出し方の実態を整理し、弁護士に確認する形にします。

### 内定を出した後に、経歴の虚偽が分かりました

判決が示す枠組みでは、取消事由は採用内定当時知ることができず、また知ることが期待できないような事実であって、これを理由として取り消すことが解約権留保の趣旨・目的に照らして客観的に合理的と認められ社会通念上相当として是認することができるものに限られる、とされています。実務としては、いつ何が判明したか、内定を出した時点で知り得たか、その事実が業務にどう関わるかを整理して、弁護士に渡します。可否の判断は副業の人事が出す場所ではありません。

### 業績の悪化を理由に、入社時期を遅らせたいと言われました

厚生労働省のパンフレットでは、入社日は変更しないものの事業主の都合で休業させ実際の就業をさせない措置（自宅待機）を行う場合には、その期間について労働基準法第26条に定める休業手当を支払う必要があるとされ、入社日を延期する措置を行う場合には原則として採用内定者の合意を得る必要がある、と説明されています。あわせて、入職時期繰下げについても、あらかじめハローワーク等に通知を行うことが必要とされています。費用と手続を整理して経営に示し、判断は弁護士に確認しながら進めます。
