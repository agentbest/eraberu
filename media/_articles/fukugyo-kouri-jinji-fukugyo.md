小売や飲食、ホテルやレジャーの人事として、多くの店舗の採用を回し、アルバイト・パートと社員を採り分け、店長に面接を任せ、辞める人が多い中で人数を保ってきた。この経験は、人事の副業で売れるのか。小売・サービスの採用は「数を回す」仕事に見え、一人ひとりを丁寧に採る会社には合わないと感じる人が多いところです。結論を先に書くと、**小売・サービスの人事の経験は、「多くの店舗で、多くの人を、店長と一緒に、短い期間で、採って辞めさせずに回してきた」型で売れます。売れるのは、「多店舗・多人数の採用を回す仕組み」「店長を面接官にする型」「アルバイト・パートと社員の採用の使い分け」「辞める前提の体制づくり」の四つです。業界の外でも、拠点が複数あり、現場の管理者が採用を担い、人の出入りが多い会社（物流の拠点、介護の施設、コールセンター、クリニックの多店舗展開）は、同じ構造で困っています。「店舗の人事でした」ではなく、「多くの人を、現場の管理者と一緒に、止まらずに採る仕組みを作る」と売ります。**医療・介護の人事の経験は[医療・介護の人事が副業でできること](/media/fukugyo-iryou-jinji-fukugyo/)に、建設業の人事の経験は[建設業の人事が副業でできること](/media/fukugyo-kensetsu-jinji-fukugyo/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)にまとめています。

## この経歴の何が売れるか

小売・サービスの人事の経験を、業界の内外の採用の工程に置き換えた棚卸しです。在籍した会社の店舗の内情は含めず、「型」として抜き出します。

| 小売・サービスの人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 多くの店舗の採用を、本部から仕組みで回してきた | 拠点ごとの欠員と応募を一つの表で見て、本部と拠点の分担で回す仕組み | 拠点ごとに採用がばらばらで、本部が状況を把握できない依頼側が多い |
| 店長に面接を任せ、基準を揃えてきた | 現場の管理者が面接官になるための、短い手引きと記録の型と基準の揃え方 | 現場の管理者が面接に慣れておらず、基準がばらつく依頼側が多い |
| アルバイト・パートと社員を、採用の経路と条件と面接で使い分けてきた | 雇用の形ごとに、経路・条件・面接の深さ・受け入れを分けて設計する | 雇用の形の違いを整理せず、同じ流れで採用している依頼側が多い |
| 辞める人が多い前提で、人数を保つ体制を作ってきた | 「辞めることを前提に、常に募集し、早く受け入れ、辞める理由を戻す」体制 | 辞めるたびに慌てて募集し、人数が保てない依頼側が多い |
| 短い期間で応募から入店までを回してきた | 応募から入社までの日数を縮める流れ（即日の連絡、面接の即決、入社の準備の前倒し） | 応募から面接までが遅く、他社に取られる依頼側が多い |
| 求人媒体を多く使い、費用と応募を比べてきた | 媒体の費用対効果を、拠点と職種ごとに比べる型 | 媒体に払い続けて、どれが効いているか分からない依頼側が多い |
| 入店の直後の離職を減らす受け入れを工夫してきた | 最初の一週間の受け入れ（教える人を決める、シフトの配慮、声をかける仕組み） | 入ってすぐ辞める依頼側が多い |

売れるものの要点は、「多くの人を、現場の管理者と一緒に、止まらずに採る仕組み」です。一人ひとりを丁寧に採る会社の人事は、採用の数が増え、拠点が増え、現場の管理者が面接を担うようになったとき、仕組みがなくて止まります。小売・サービスの人事は、その状態を日常として回してきており、拠点と人数が増えた会社に、仕組みを持ち込めます。「数を回す」経験は、「仕組みで回す」経験です。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

小売・サービスの人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 少人数の採用との差 | 「うちは年に数人しか採らない。数を回す経験は合わない」。自分にとっても、一人を深く見る採用の経験が薄い不安 | 「数を回す」ではなく「仕組みで回す」と語る。少人数の会社でも、拠点や現場の管理者が採用を担う会社には仕組みが要る。少人数で一人を深く見る採用は範囲に入れない |
| 専門職の採用の薄さ | 「技術職や専門職の採用はできるのか」 | 専門職の採用は範囲に入れないか、経験が薄いことを示す。売るのは「多人数・多拠点・現場の管理者」の型だと最初に分ける |
| 「アルバイトの採用」と見られる | 「アルバイトの採用と、社員の採用は違う」と軽く見られる | アルバイト・パートと社員を使い分けてきた経験として語る。「雇用の形ごとに経路と条件と面接の深さを分けてきた」は、社員の採用にも効く |

扱い方の要点は、「『数を回す』を『仕組みで回す』に言い換える」ことです。小売・サービスの人事の経験がある人は、自分の経験を「たくさん採った」と語りがちで、それが少人数の会社には「合わない」と聞こえ、専門職の会社には「軽い」と聞こえます。「拠点が複数あり、現場の管理者が面接を担い、人の出入りがある会社で、本部と拠点の分担と、店長を面接官にする型と、辞める前提の体制で回してきた」と語れば、同じ経験が、拠点と人数が増えて仕組みがない会社に「今のうちに必要なもの」として伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、小売・サービスの人事から転身して続いている人と、面談で止まる人の差は、「何人採ったか」を語るか、「何を仕組みにしたか」を語るかです。止まる人は、年間の採用の人数と店舗の数を語り、依頼側の経営者は「うちはそんなに採らない」と感じて終わります。続いている人は、「御社では、誰が面接をしていますか。拠点ごとの欠員は、誰が見ていますか」と聞き、依頼側が「各拠点の責任者がそれぞれ」と答えたところで、「それなら、本部から見える表と、責任者が面接官になるための一枚の手引きがあると回ります」と返します。経営者は、拠点が増えて採用が見えなくなっていることに気づき、そこから頼みます。

見ていて差がつくのは、店長を面接官にする型を、依頼側の現場の管理者に合わせて軽くしているかです。小売・サービスの人事の経験がある人は、店長向けの面接の手引きを持っていますが、そのまま持ち込むと、依頼側の現場の管理者には「店の面接のやり方」に見えます。「見る点を三つ」「聞き方を一つずつ」「記録は一行」と、依頼側の職種に合わせて一枚に作り直し、現場の管理者が十分で読める形にした人は、面接が現場で回るようになり、依頼側から「初めて拠点の責任者が面接をやってくれた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「多くの人を、現場の管理者と一緒に、止まらずに採る仕組みを作る」と仕組みの言葉で書いている担当者に、拠点が増えて困っている依頼側がついています。小売・サービスの人事の転身は、採った数ではなく、仕組みの言葉から始まります。

## 案件の探し方

小売・サービスの人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 小売・飲食・ホテル・レジャーの依頼側の採用 | 業界の言葉と店舗の事情が分かり、説明の手間がない | 同じ業界の依頼側を探す |
| 拠点ごとの欠員と応募を本部で見る仕組み | 多店舗を本部から回してきた経験でそのまま入れる | 「拠点が増えて採用が見えなくなった依頼側」を探す |
| 現場の管理者を面接官にする手引きと記録の型 | 店長を面接官にしてきた経験で入れる | 「現場の責任者が面接に慣れていない依頼側」を探す |
| 雇用の形ごとの採用の流れの設計 | アルバイト・パートと社員を使い分けてきた経験で入れる | 「雇用の形を整理せずに採用している依頼側」を探す |
| 辞める前提の体制と受け入れの設計 | 人数を保ってきた経験で入れる | 「辞めるたびに慌てる依頼側」を探す |
| 媒体の費用対効果の比べ方 | 多くの媒体を比べてきた経験で入れる | 「媒体に払い続けて効果が分からない依頼側」を探す |

探し方の要点は、「拠点が増えて、採用が回らなくなった会社」から入ることです。一拠点で年に数人採る会社では、小売・サービスの型は重すぎます。拠点が増え、現場の管理者が面接を担うようになり、人の出入りが増えて、本部が状況を把握できなくなった会社では、小売・サービスの型が唯一の打ち手になります。業界の外では、物流の拠点、介護の施設、コールセンター、クリニックや塾の多店舗展開が、同じ構造です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。小売・サービスの人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 仕組みの成果物 | 本部の表、面接の手引き、雇用の形ごとの流れ、受け入れの手順は、成果物として形が明確 | 一式の成果物で受ける |
| 拠点の数 | 拠点が多いほど、仕組みの価値と運用の稼働が増える | 拠点の数を範囲と月額に反映する |
| 運用の継続 | 作った仕組みを回す運用は、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 「アルバイトの採用」と見られること | 軽く見られると単価が下がる | 雇用の形の使い分けと仕組みの言葉で示す |
| 媒体の費用の見直し | 媒体の費用を減らせる設計は、依頼側の支出に直接効き、価値が見えやすい | 「媒体の費用が減った分」を成果として示せる形に |
| 専門職を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 採用の成否は依頼側の条件と現場の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「仕組みは成果物で、運用は月額で受け、拠点の数を反映する」ことです。小売・サービスの人事の経験で受ける工程は、本部の表と面接の手引きと受け入れの手順という成果物が明確で、成果物で受けると単価の根拠が伝わります。拠点が多いほど運用の稼働が増えるので、拠点の数を月額に反映します。媒体の費用の見直しは、依頼側の支出に直接効くので、価値を示しやすいです。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

小売・サービスの人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、店舗と従業員の情報の守秘の条件を確認する | 個別の判断は専門家に |
| 二、「多くの店舗で多くの人をどう回してきたか」を、会社と店舗の情報を含まない仕組みの型として書き出す | 本部と拠点の分担、店長の面接の型、雇用の形の使い分け、辞める前提の体制 |
| 三、「数を回した」を「仕組みで回した」に言い換える | 人数と店舗数ではなく、分担と手引きと体制で語る |
| 四、得意な工程（多拠点・多人数・現場の管理者・雇用の形・辞める前提）と、薄い工程（一人を深く見る採用、専門職の採用）を分ける | 正直に示す準備 |
| 五、範囲を、本部の表、面接の手引き、雇用の形ごとの流れ、受け入れ、媒体の比べ方に絞る | 専門職の採用は最初は範囲外 |
| 六、「多くの人を、現場の管理者と一緒に、止まらずに採る仕組みを作る」の一言を作る | 「店舗の人事でした」で終わらせない |
| 七、面接の手引きの見本を、架空の職種で一枚作る | 面談で見せる道具。前の会社の手引きは使わない |
| 八、登録先に、範囲と、業界の内側の経験と、仕組みの言葉の一言を登録する | 拠点が増えて回らない依頼側 |
| 九、本部の表か面接の手引きを一件受け、「拠点の責任者が面接をした」形を残す | 業界の外に広げる材料に |

順番の要点は、「三」の言い換えと「七」の見本です。「たくさん採った」は、少人数の会社には合わず、専門職の会社には軽く聞こえます。「分担と手引きと体制で回した」と言い換え、面接の手引きを一枚見せれば、同じ経験が「仕組みを作れる人」として伝わります。前の会社の手引きは、会社のものなので使わず、自分の型で新しく作ります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「小売・サービスの採用は数を回すだけで、一人ひとりを見る採用には向いていない」というものです。実際には、拠点が増え、現場の管理者が面接を担い、人の出入りが増えた会社は、業界を問わず「一人ひとりを見る」やり方のまま止まっており、仕組みがありません。本部と拠点の分担、現場の管理者を面接官にする型、雇用の形の使い分け、辞める前提の体制。小売・サービスの人事が日常として回してきたこの型は、その会社にとって、持っていない打ち手です。向いていないのではなく、必要になる段階が違うだけです。

順番として、本業の規定と守秘の条件を専門家に確認し、回してきた仕組みを会社の情報を含まずに書き出し、数を仕組みに言い換え、得意な工程と薄い工程を分け、範囲を本部の表と手引きと流れと受け入れに絞り、止まらずに採る仕組みを作る一言を作り、手引きの見本を一枚作り、登録先に範囲と一言を登録し、一件受けて拠点の責任者が面接をした形を残す。この順番で、小売・サービスの人事の経験は「数を回すだけのもの」から「拠点が増えた会社の採用を仕組みで回す形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、仕組みの工程を明確にし、専門職を含まないことを示している担当者に、拠点が増えて困っている依頼側がついています。小売・サービスの人事の転身は、採った数ではなく、仕組みの言葉から始まります。

- 売りにくい点は**少人数の採用との差・専門職の採用の薄さ・「アルバイトの採用」と見られる**。「数」を「仕組み」に言い換え、専門職は範囲外と示し、雇用の形の使い分けとして語る
- 案件は**拠点が増えて採用が回らなくなった会社**から。物流の拠点・介護の施設・コールセンター・多店舗のクリニックや塾も同じ構造
- 単価は**仕組みは成果物、運用は月額**で。拠点の数を反映する。成果報酬は最初は避け、可否は専門家に確認
- 面接の手引きは、**依頼側の職種に合わせて一枚に軽く作り直す**。前の会社の手引きは使わない

## よくある質問

### 一拠点で年に数人しか採らない会社から相談がありました。受けてよいですか

仕組みが要る段階かどうかを見ます。一拠点で、経営者か人事が自分で面接をし、人の出入りが少ない会社では、多拠点・多人数の型は重すぎ、依頼側の期待とずれます。「今は仕組みより、一人を深く見る採用のほうが合っていると思います」と正直に伝え、拠点が増える段階になったら、と線を引くほうが、信頼が残ります。受けるなら、辞める前提の体制や受け入れの手順など、少人数でも効く部分に範囲を絞ります。合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### 前の会社の面接の手引きや採用のマニュアルを、副業で使ってよいですか

使いません。会社の業務で作った手引きとマニュアルは、一般に会社のものと整理されることが多く、持ち出して使うと守秘と著作の線に問題が出ます。型（見る点の絞り方、記録の軽さ、店長への渡し方）は自分の経験として使えますが、手引きそのものは、依頼側の職種に合わせて新しく作ります。個別の判断は、弁護士や社会保険労務士にご確認ください。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

### 社員の採用の経験が少なく、アルバイト・パートの採用が中心でした。案件が取れますか

アルバイト・パートと社員を採り分けてきた経験を、「雇用の形ごとに経路と条件と面接の深さを分けてきた」型として語ります。社員の採用の経験が少ないことは隠さず、「社員の採用のうち、現場の管理者を面接官にする型と、拠点ごとの欠員を見る仕組みは同じ型で担えます。一人を深く見る採用は、御社の担当者か別の担当者と組みます」と分担を示します。業界の外でも、パートや契約社員の割合が多い会社（物流、介護、コールセンター）では、雇用の形の使い分けの経験が直接効きます。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、評価される担当者の共通点は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に整理しています。
