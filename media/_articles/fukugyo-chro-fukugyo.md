人事責任者やCHROとして、経営会議に出て、人員計画を事業計画と合わせ、採用の優先順位を決め、人事の部門を束ねてきた。この経験は、副業で売れるのか。責任者の経験は、手を動かす工程から離れているぶん、何を売ればよいかが分かりにくいと感じる人が多いところです。結論を先に書くと、**CHROの経験は、「経営の議論に人事の言葉で入り、採用を事業計画とつなぎ、決める順番を知っている」型で売れます。売れるのは、「採用計画と事業計画の接続」「採用の優先順位の判断」「経営者の壁打ち」「人事機能の立ち上げの設計」の四つです。人事の責任者がいない会社では、経営者が採用と人事の判断を一人で抱えており、決めるための材料と順番を用意できる人を求めています。「責任者でした」ではなく、「経営者が決めるための材料と順番を用意する」と売ります。**人事マネージャーの経験の売り方は[人事マネージャー経験を活かす](/media/fukugyo-manager/)に、経営者・役員の経験は[経営者・役員が副業でできること](/media/fukugyo-kigyou-keiei-fukugyo/)に、人事コンサルタントの経験は[人事コンサルタントが副業でできること](/media/fukugyo-consultant-jinji-fukugyo/)にまとめています。

## この経歴の何が売れるか

CHROの経験を、依頼側の会社で使える工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| CHROの経験 | 依頼側の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 事業計画から人員計画を引いてきた | 事業の目標から、いつ・どの職種を・何人採るかを逆算し、採用の計画に落とす | 採用が「欠員が出たら募集する」の繰り返しになっている依頼側が多い |
| 採用の優先順位を決めてきた | 複数の募集が同時に走るとき、どれを先に埋め、どれを止めるかの判断の型 | 全職種を同時に募集して、どれも決まらない依頼側が多い |
| 経営会議で人事の議題を通してきた | 採用の予算・体制・条件を、経営者が判断できる材料と順番で出す | 人事の議題が経営会議で後回しになる依頼側が多い |
| 人事の部門を立ち上げ、束ねてきた | 人事の機能を、どの順番で・誰が・どこまで持つかを設計する | 最初の人事担当者の役割が決まらない依頼側が多い |
| 報酬と等級の枠組みを決めてきた | 採用の条件を、既存の社員との整合で判断する枠組み | 採用のたびに条件が場当たりになる依頼側が多い |
| 経営者と人事の判断で対立し、調整してきた | 経営者の意向と現場の実情の間で、どこを譲りどこを守るかの整理 | 経営者の一言で採用の方針が揺れる依頼側が多い |
| 採用の失敗の責任を取ってきた | 採用の判断で何が起きると取り返しがつかないかを知っている | 失敗の型を知らないまま採用を進める依頼側が多い |

売れるものの要点は、「経営者が一人で抱えている判断を、材料と順番に分けて渡せる」ことです。人事の責任者がいない会社では、経営者が採用の計画も優先順位も条件も一人で決めており、相談する相手がいません。CHROの経験は、その判断を経営者と同じ目線で分解し、決められる形に整えるところで効きます。手を動かす工程を売るのではなく、決める工程を売ります。経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に書いています。

## 売りにくい点とその扱い

CHROの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 手を動かす工程の薄さ | 「スカウトの文面を書いたり、日程を調整したり、自分で動いてくれるのか」。自分にとっても、実務から離れて久しいという不安 | 手を動かす工程は範囲に入れないか、別の担当者と組む形にする。売るのは「決める工程」だと最初に示す |
| 規模の差 | 「大きい会社の責任者だった人に、うちの規模の採用が分かるのか」 | 大きい会社の仕組みをそのまま持ち込まず、依頼側の規模で「最初に決める一つ」に絞る。仕組みの話より、順番の話をする |
| 肩書の重さ | 「責任者だった人に、細かい相談を頼みにくい」「単価が高そう」 | 肩書ではなく工程で名乗る。「経営者の壁打ちを月に何回」「採用計画の作成を一式」と、範囲と形を先に示す |

扱い方の要点は、「責任者の肩書を、工程の言葉に置き換える」ことです。CHROという肩書は、依頼側にとって頼もしい反面、何を頼めばよいか分からず、高そうに見えます。「事業計画から採用の計画を引く」「複数の募集の優先順位を決める」「経営者の判断の壁打ちをする」と工程で示せば、依頼側は自分の詰まりと照らして頼めます。手を動かす工程が薄いことは隠さず、その工程は別の担当者に、と分担を示します。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、大きい会社の経験の扱いは[スタートアップ人事の経験は評価されるか](/media/fukugyo-startup-keiken/)の逆の視点として参考になります。

### エラベルの見解

同じ「人事責任者の経験」でも、担当者として選ばれ続ける人と、最初の面談で止まる人の差は、経営者の話をどこまで聞いてから口を開くかです。止まる人は、自分が前の会社で作った仕組みを先に語ります。等級の枠組み、採用の会議体、評価の制度を、依頼側の規模に関係なく並べるので、経営者は「うちにはまだ早い」と感じて終わります。選ばれる人は、経営者が今いちばん困っている判断を一つ聞き出し、「それを決めるには、この材料をこの順番で見ます」と返します。

見ていて差がつくのは、判断の材料を「経営者が自分で決めた」と感じられる形で渡せているかです。CHROの経験がある人は、答えを持っているので、つい答えを先に言います。ただ、依頼側の経営者は、自分で決めたい人が多く、答えを渡されると反発するか、依存するかのどちらかになります。材料と順番を渡し、決めるのは経営者に残した人は、「相談できる相手ができた」と評価され、契約が続いています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、肩書ではなく「経営者が決めるための材料と順番を用意する」と工程で書いている担当者に、人事の責任者がいない依頼側がついています。

## 案件の探し方

CHROから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 採用計画の作成 | 事業計画から人員計画を引いてきた経験でそのまま入れる | 「事業の目標から、いつ・どの職種を・何人採るかを一緒に決める」を範囲の一言に |
| 採用の優先順位の整理 | 複数の募集が同時に走っている依頼側に効く | 「募集が多くてどれも決まらない依頼側」を探す |
| 経営者の壁打ち | 人事の責任者がいない会社の経営者は、相談相手がいない | 「月に何回、何分」と形を決めて示す |
| 最初の人事担当者の役割の設計 | 人事の部門を立ち上げた経験で入れる | 「初めて人事を採る依頼側」を範囲の一言に |
| 採用の条件の枠組みづくり | 報酬と等級の枠組みを決めてきた経験で入れる | 「採用のたびに条件が場当たりになる依頼側」を探す |
| 採用の方針の言語化 | 経営者の意向と現場の実情を整理してきた経験で入れる | 「経営者の一言で方針が揺れる依頼側」を探す |

探し方の要点は、「人事の責任者がいない会社」から入ることです。人事の部門があり、責任者がいる会社では、CHROの経験は既存の責任者と役割が重なり、頼みにくいものになります。人事の責任者がいない会社では、経営者が判断を一人で抱えており、CHROの経験は重ならずに効きます。会社の規模ではなく、「決める人が経営者しかいない」ことを探す基準にします。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、注意したい依頼の型は[注意したほうがよい依頼](/media/fukugyo-chuui-kigyou/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。CHROの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 決める工程の価値 | 経営者の判断に関わる工程は、手を動かす工程より一回あたりの価値が見えにくく、見えれば高い | 「何が決まったか」を成果として残す |
| 壁打ちの形 | 回数と時間で受けやすい | 月に何回・何分で決める |
| 採用計画の作成 | 成果物で受けやすい | 一式の成果物で受ける |
| 手を動かす工程を含まないこと | 含まない範囲は、含む範囲より月額は下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 肩書による期待 | 責任者の肩書で単価の期待が上がるが、依頼側が頼みにくくもなる | 工程で示し、肩書で値付けしない |
| 稼働時間の少なさ | 決める工程は稼働時間が短く、時間単価だけで見ると高く見える | 時間ではなく回数か成果物で受ける |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「壁打ちは回数で、採用計画は成果物で受ける」ことです。決める工程は稼働時間が短く、時間単価で出すと依頼側に高く見え、時間を増やせば単価が下がる構造になります。回数か成果物で受ければ、時間の長さではなく、決まったことと出来上がったもので価値を示せます。成果報酬は、採用の成否が依頼側の判断に左右されることから、最初は避け、可否は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

CHROから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、役員や責任者としての守秘と競業の条件を確認する | 個別の判断は専門家に |
| 二、前の会社で決めてきたことを、会社の内情を含まない「判断の型」として書き出す | 事業計画から人員計画を引く順番、優先順位の決め方、経営者との調整の型 |
| 三、得意な工程（決める工程）と、薄い工程（手を動かす工程）を分ける | 正直に示す準備 |
| 四、範囲を、採用計画、優先順位、壁打ち、人事機能の設計、条件の枠組みに絞る | 手を動かす工程は最初は範囲外か、別の担当者と組む |
| 五、「経営者が決めるための材料と順番を用意する」の一言を作る | 「責任者でした」で終わらせない |
| 六、壁打ちは月に何回・何分、採用計画は一式と、形を決める | 単価を工程と形で出す |
| 七、登録先に、範囲と、形と、手を動かす工程の分担を登録する | 人事の責任者がいない依頼側 |
| 八、壁打ちか採用計画を一件受け、「何が決まったか」を残す | 次の案件に広げる材料に |

順番の要点は、「二」の判断の型の書き出しです。CHROの経験は、判断の積み重ねで、本人の中では当たり前になっていて、言葉にしないと依頼側に見えません。「事業の目標から、どの順番で人員計画を引くか」「募集が重なったとき、何を基準に先に埋めるか」「経営者の意向と現場の実情が食い違ったとき、どこから整理するか」を、会社の内情を含まない型として書いておくと、面談でも登録先でもそのまま使えます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、本業との時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「責任者の経験は、大きい会社でしか使えない」というものです。実際には、人事の責任者がいない会社ほど、経営者が採用と人事の判断を一人で抱えており、決める工程を分けて持てる人を求めています。使えないのは、大きい会社の仕組みをそのまま持ち込む場合で、依頼側の規模で「最初に決める一つ」に絞れば、CHROの経験は小さい会社で最も効きます。

順番として、本業の規定と守秘と競業の条件を専門家に確認し、判断の型を会社の内情を含まずに書き出し、決める工程と手を動かす工程を分け、範囲を決める工程に絞り、経営者が決めるための材料と順番を用意する一言を作り、壁打ちと採用計画の形を決め、登録先に範囲と形と分担を登録し、一件受けて何が決まったかを残す。この順番で、CHROの経験は「大きい会社でしか使えないもの」から「経営者の判断を支える形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、決める工程を明確にし、手を動かす工程の分担を示している担当者に、人事の責任者がいない依頼側がついています。CHROの転身は、肩書ではなく、判断の型を言葉にするところから始まります。

## まとめ

- CHROの経験は**「経営の議論に人事の言葉で入り、採用を事業計画とつなぎ、決める順番を知っている」型**で売れる。**採用計画と事業計画の接続・優先順位の判断・経営者の壁打ち・人事機能の設計**の四つ
- **「責任者でした」ではなく「経営者が決めるための材料と順番を用意する」**と売る
- 売りにくい点は**手を動かす工程の薄さ・規模の差・肩書の重さ**。分担を示し、規模に合わせて「最初に決める一つ」に絞り、肩書ではなく工程で名乗る
- 案件は**人事の責任者がいない会社**から。会社の規模ではなく、決める人が経営者しかいないことを基準に
- 単価は**壁打ちは回数、採用計画は成果物**で。時間単価で見せない。成果報酬は最初は避け、可否は専門家に確認
- 答えを渡さず、**材料と順番を渡し、決めるのは経営者に残す**

## よくある質問

### 経営者から「全部任せたい」と言われました。責任者の経験があるので、任されてもよいと思うのですが

範囲を決めずに全部を受けると、手を動かす工程まで含めて期待され、稼働時間が読めなくなります。「決める工程は私が、手を動かす工程は御社の担当者か別の担当者が」と分担を最初に書面で示します。全部任せたいという言葉は、経営者が判断を一人で抱えて疲れているという意味であることが多く、決める工程を引き取れば、その疲れは解消されます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。

### 本業でまだ責任者の立場にいます。副業をしても問題ないでしょうか

本業の会社の副業の規定と、役員や責任者として負っている守秘と競業の条件を先に確認します。責任者の立場では、一般の社員より広い守秘と競業の義務を負っていることがあり、同じ業界の会社の案件は避ける判断になることもあります。依頼側の会社と本業の会社の関係も見ます。個別の判断は、社会保険労務士や弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、案件ごとの情報の扱いは[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### 手を動かす工程を長くやっていないので、依頼側に「実務ができない」と思われないか心配です

手を動かす工程が薄いことは、隠さずに示します。「スカウトの送信や日程の調整は、御社の担当者か別の担当者が。私は、誰に・どの順番で・何人送るかを決めるところを持ちます」と分担を示せば、依頼側は頼み方が分かります。実務ができないことを補おうとして手を動かす工程を受けると、稼働時間が読めなくなり、単価の根拠も崩れます。手を動かす担当者と組む形は、エラベルのような登録先では可能なことがあります。分担の型は[人事マネージャー経験を活かす](/media/fukugyo-manager/)に、報告の形は[報告のしかた](/media/fukugyo-houkoku/)に整理しています。
