副業の案件が増えてきて、法人として受けたほうがよいのではと考え始める。あるいは、すでに自分の会社を持っていて、副業の案件もそちらで受けたい。結論を先に書くと、**人事の副業を法人として受けるかどうかは、「依頼側が法人との契約を求めているか」「受ける範囲が個人の稼働を超えて広がるか」「法人を維持する手間を本業と両立できるか」の三つで決めます。この三つに当てはまらないうちは、個人で受けるほうが動きやすく、依頼側との契約も早く進みます。**最初の一件を法人で受けるために会社を作る必要はなく、個人で数件を回してから考えても遅くありません。設立の要否、税や社会保険の扱い、本業の会社の規定との関係は状況で大きく変わるので、個別の判断は税理士・社会保険労務士などの専門家にご確認ください。屋号の判断は[屋号を付けるか](/media/fukugyo-yagou/)に、直接契約の入口は[企業から直接受けるには](/media/fukugyo-chokusetsu/)にまとめています。

## 依頼側から見た個人と法人の違い

法人にするかを考える前に、依頼側から見て何が変わるかを押さえます。依頼側の担当者にとって、個人と法人の違いは、契約の手続きと支払いの手続きの違いとして現れます。

| 見る人 | 個人で受ける場合 | 法人で受ける場合 |
|---|---|---|
| 依頼側の担当者 | 本人の経歴と範囲で判断する。契約は業務委託が多い | 同じく本人の経歴で判断する。会社としての実績を聞かれることもある |
| 依頼側の法務 | 個人との業務委託の型で契約する。会社によっては個人との契約に社内の手続きが要る | 法人間の契約の型で進む。登記や会社情報の確認がある |
| 依頼側の経理 | 支払いの際に源泉徴収などの処理が要る場合がある。要否は専門家に | 法人への支払いとして処理する。請求書の記載事項が変わることがある |
| 依頼側の情報管理 | 本人が情報を扱う前提で、秘密保持は本人と結ぶ | 法人と結ぶ。誰が実際に扱うかを別途確認されることがある |

違いの要点は、依頼側の「担当者」の判断はどちらでも変わらず、「法務」と「経理」の手続きが変わることです。会社によっては、個人との契約に社内の手続きが多く、法人でないと契約しにくいところがあります。逆に、法人だと登記事項や会社情報の提出を求められ、個人より手続きが増える場合もあります。どちらが早いかは依頼側の会社の仕組みで決まるので、契約の前に依頼側に「個人と法人のどちらが進めやすいか」を聞いておくと、無駄な準備が減ります。

## 法人が向く場面と向かない場面

法人として受けることが向く場面は限られています。自分の案件の状況を、次の表に当てて見ます。

| 向く場面 | なぜ向くか |
|---|---|
| 依頼側が「法人でないと契約できない」と言っている | 個人との契約の手続きが社内に無い会社がある。ここは法人の有無で案件が決まる |
| 受ける範囲が自分一人の稼働を超え、他の人と分担する | 複数人で受ける契約は、法人を窓口にするほうが依頼側にとって分かりやすい。[チームで動くときの分担](/media/fukugyo-chiimu/) |
| 直接契約が複数あり、本業を離れて続ける見込みがある | 副業から独立へ移る段階では、法人の維持の手間に見合うことがある |
| すでに法人を持っていて、維持の手間が増えない | 新しく作るのではなく、既存の法人で受けるなら、追加の手間は小さい |

| 向かない場面 | なぜ向かないか |
|---|---|
| 最初の一件で、個人でも契約できる | 法人を作る手間と維持の費用に、案件の規模が見合わない |
| 仲介サービスや登録型の窓口を通している | 窓口が契約の形を整えているので、法人にする理由が無い |
| 本業の会社の規定で、法人の役員になることに制限がある | 副業の許可とは別に、役員の就任に届け出や禁止がある会社がある。規定の確認と、解釈は専門家に |
| 法人の手続きに使う時間が、本業と副業の合間に取れない | 決算や届け出の手間が続き、本業の繁忙期と重なると回らなくなる |

向く・向かないの要点は、「依頼側の都合」と「自分の維持の手間」の二つを天秤にかけることです。依頼側が法人を求めていて、その案件を受けたいなら法人が要ります。求めていないなら、個人で受けるほうが軽く、条件も早く決まります。時間の面での両立は[副業の時間を確保する](/media/fukugyo-jikan-kakuho/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「法人にすれば単価が上がる」というものです。実際には、依頼側が払う額は、誰が・週何時間・どの範囲を担当するかで決まっていて、契約の相手が個人か法人かで変わることはほとんどありません。法人にすると、請求書に載る名前が会社になるだけで、稼働する人と範囲は同じです。依頼側の担当者も、そのことは分かっています。

差が出るのは、単価ではなく「契約に進む速さ」です。依頼側の法務に個人との契約の型が無い会社では、法人でないと社内の手続きに時間がかかり、場合によっては案件が流れます。逆に、個人との契約に慣れている会社では、法人だと登記事項の確認が加わって遅くなります。法人にするかどうかは、単価の話ではなく、受けたい依頼側がどちらで契約しやすいかの話として考えると、判断が早くなります。

## 契約と請求で変わる項目

法人として受けると決めたら、個人のときと変わる項目を押さえます。ここが揃っていないと、依頼側の経理と法務の確認で止まります。

| 項目 | 個人で受ける場合 | 法人で受ける場合 |
|---|---|---|
| 契約の当事者 | 本人 | 法人。実際に稼働する人を契約書に書くことがある |
| 秘密保持 | 本人と結ぶ | 法人と結ぶ。稼働する人の範囲を明記する |
| 請求書の発行者 | 本人の名前（屋号を併記できる） | 法人名。記載事項は経理の指定に従う |
| 振込先 | 本人名義の口座 | 法人名義の口座。開設に時間がかかることがある |
| 稼働の報告 | 本人が出す | 法人として出すが、内容は同じ |
| 契約の終了・更新 | 本人が判断する | 法人として判断するが、実態は同じ |
| 税・社会保険の扱い | 個人の所得として扱う。詳細は専門家に | 法人の売上と役員報酬の扱いになる。詳細は専門家に |

変わる項目の要点は、「契約の当事者が法人になっても、稼働する人は自分である」ことを、契約書と秘密保持の中で明確にすることです。依頼側は、法人と契約しても、実際に候補者の情報を扱うのが誰かを知りたがります。稼働する人の名前を契約書に書き、その人以外が情報を扱わないことを秘密保持に入れておくと、依頼側の情報管理の確認が通りやすくなります。情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[情報の取り扱いと端末の分離](/media/fukugyo-security/)に整理しています。

## 本業との関係で注意すること

法人として受ける場合、本業の会社との関係で、個人で受けるときより注意する点が増えます。

| 注意 | 内容 |
|---|---|
| 役員就任の規定 | 副業の許可とは別に、他社の役員になることを届け出制や禁止にしている会社がある。就業規則を確認し、解釈は専門家に。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/) |
| 法人の事業内容 | 本業の会社と競合する事業内容にすると、利益相反の問題が表に出る。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 法人の名前 | 本業の会社名に寄せない。検索で本業の関係者の目に触れたとき、会社の信用を使っていると受け取られる |
| 法人の連絡先と住所 | 本業の会社の情報を使わない。自宅の住所を公開する場合は、その影響も考える |
| 本業の時間との切り分け | 法人の手続き（届け出、決算、口座の管理）を本業の時間に行わない |
| 本業の会社に知られる経路 | 法人の登記は公開情報で、役員の名前が載る。本業に副業を伝えていない場合、経路が一つ増える |

注意の要点は、「役員就任の規定」です。副業の許可が出ていても、他社の役員になることは別の規定で扱われていることがあります。ここを確認せずに法人を作ると、副業の許可そのものが問題になることがあります。規定の内容と、自分の状況での扱いは、就業規則を読んだうえで、専門家に確認してください。

## 続けるための決め方

法人にするかどうかを一度で決めず、段階で決めると、無理が出ません。

| 段階 | 決めること |
|---|---|
| 最初の一件から数件 | 個人で受ける。仲介や登録型の窓口を通し、契約の形は窓口に合わせる |
| 直接契約が増えてきた | 依頼側に「個人と法人のどちらが進めやすいか」を聞く。法人を求める依頼側が続くなら検討に入る |
| 他の人と分担する案件が出た | 法人を窓口にするかを考える。分担の形が先で、法人はその手段 |
| 本業を離れる見込みが出た | 法人の維持の手間に見合うかを、収入の見立てと合わせて考える。[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/) |
| 検討に入ったら | 税理士・社会保険労務士に、自分の状況で法人にすると何が変わるかを聞く。設立は聞いた後 |

決め方の要点は、「法人を先に作らない」ことです。案件が無いうちに法人を作ると、維持の手間だけが先に来ます。依頼側の都合と、受ける範囲の広がりと、本業との両立が揃ったときに、専門家に聞いてから作る順番にしておくと、作った後に「要らなかった」となりにくくなります。

### エラベルの見解

外に出してよいのは「法人として契約し、法人として請求する」までで、ここから先の「稼働する人を法人の中で入れ替える」ことを依頼側に伝えずに行うと、信頼を失います。依頼側は、法人と契約していても、経歴を見て「この人に頼む」と決めています。法人だからといって、途中で別の人に稼働を移すと、依頼側から見れば担当者が勝手に替わったことになります。

担当者を選べる仕組みを窓口にしているエラベルでは、依頼側が「誰が入るか」を見て決める前提なので、法人として受ける場合でも、稼働する人が誰かを先に明確にし、替えるときは依頼側の了解を得るようにお願いしています。法人は契約と請求の器であって、稼働する人を隠す器ではありません。この線を守れば、個人でも法人でも、依頼側との関係は同じように続きます。

## まとめ

- 法人で受けるかは**依頼側が法人を求めているか・範囲が一人の稼働を超えるか・維持の手間を両立できるか**の三つで決める
- 依頼側の**担当者の判断は変わらず、法務と経理の手続きが変わる**。どちらが早いかは依頼側の会社の仕組みで決まる
- 向くのは**法人でないと契約できない依頼側・複数人での分担・独立の見込み・既存の法人がある**とき
- 契約と請求で変わるのは**当事者・秘密保持・請求書の発行者・振込先・税と社会保険の扱い**。稼働する人は明記する
- 本業との関係では**役員就任の規定・事業内容・名前・連絡先・時間の切り分け・知られる経路**に注意する
- 決め方は**個人で数件→依頼側に聞く→分担や独立の見込み→専門家に聞く→設立**の順。設立や税の判断は専門家に

## よくある質問

### 依頼側から「法人でないと契約できない」と言われたら、どうすればよいですか

まず、その依頼側の法務に、個人との業務委託の型が本当に無いのかを担当者に確認してもらいます。個人との契約の前例が無いだけで、手続きを踏めばできる会社もあります。それでも法人が要るなら、その案件だけのために法人を作るかは、案件の規模と期間と、他に法人を求める依頼側が続きそうかで判断します。一件のために作るのは見合わないことが多く、仲介サービスを通して契約の相手を仲介側にする方法が取れることもあります。

### すでに自分の法人があります。副業の案件をそちらで受けても問題ないですか

法人の事業内容に人事や採用の支援が含まれているか、本業の会社の規定で他社の役員としての活動が認められているか、法人の名前や事業が本業と競合しないかを確認します。この三つが問題なければ、既存の法人で受けることは、新しく作るより手間が小さいです。ただし、法人の売上と役員報酬の扱いは個人で受ける場合と変わるので、税理士に確認してください。

### 法人にすると、本業の会社に副業が知られやすくなりますか

法人の登記は公開情報で、役員の名前が載るので、経路は一つ増えます。個人で受ける場合と比べて、検索や登記の確認で見つかる可能性は上がります。本業の会社に副業を伝えていない場合は、法人にする前に、副業の許可と役員就任の規定を確認し、伝える形を先に整えるほうが、後で困りません。規定の解釈と自分の状況での扱いは、専門家にご確認ください。
