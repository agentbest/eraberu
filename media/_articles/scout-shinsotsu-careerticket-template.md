キャリアチケットのスカウト文面は、他の媒体の型をそのまま持ち込むと空振りします。この媒体は、企業が**どの価値観に共感したか**を学生側に見せる仕組みになっているからです。結論を先に書くと、**キャリアチケット就職スカウトの文面は「共感した価値観を名指しで書く」「フレームワークで書かれた自己PR・ガクチカの中身に触れる」「差し出すものを一通に一つだけ置く」の三つで設計します**。なお、送信通数や料金は公開されていないため、契約前に運営に確認してください。以下は、2026年9月23日時点で公式サイトおよび運営会社の公式発表に記載されている内容に基づいて整理しています。運用の組み方は[キャリアチケットの運用スケジュールと送信計画](/media/scout-shinsotsu-careerticket-unyou/)にまとめています。

## 仕組みから逆算する

**学生側に何が見えるか。**公式サイトは、キャリアチケット就職スカウトの特徴として「キャリアチケット就職スカウトでは、あなたの価値観に共感した企業だけが、オファーを送ります。**どんな価値観に共感したかも分かるので**、キャリアに対する自分の考え方と合っているか判断しやすくなります」としています。

**ここが文面設計の起点です。**企業がどの価値観に反応したかが学生に伝わる仕組みなので、**文面でも同じ価値観に触れていないと、ちぐはぐになります**。システムが「この価値観に共感した」と示しているのに、本文が会社紹介から始まっていると、学生は違和感を持ちます。

**スカウトとは何か。**同サイトのよくある質問は、「『スカウト』とは何ですか？」に対して「**企業から個別面談や選考スキップなどのご案内が届くこと**です。スカウトを受けることで企業と連絡を取り選考に進むことができます」と答え、「※**企業によりスカウトの内容は異なります**。またスカウトは辞退することもできますのでご安心ください」と補足しています。

**差し出すものが決まっています。**個別面談か、選考スキップか。ここが文面の「何をしてほしいか」の部分になります。

**企業はどう探しているか。**同じくよくある質問は「企業は学生をどのような方法で探していますか？」に対して「**記載いただいたプロフィール情報を元に学生検索を行います**。自分の個性や人柄が伝わるようにプロフィールを充実させましょう」と答えています。

**プロフィールに何が入るか。**公式サイトは、次の機能を挙げています。

| 機能 | 公式サイトの説明 |
|---|---|
| **価値観（5つの質問）** | 「5つの質問に答えるだけで、あなたのキャリアに対する考え方が明確になります。自分が大切にしている価値観がわかると、どのような企業で働きたいのかが見えてきます」 |
| **フレームワーク機能** | 「決められた質問に回答していくだけで**自己PRとガクチカ**を簡単に作成できます。伝わりやすい文章が書けると、企業からオファーが届きやすくなります」 |
| **他己分析** | 「依頼しづらい他己分析も、アプリから簡単に依頼できます。**親しい人からの意見を取り入れる**ことで、他の学生とは差別化された自分だけの自己PRやガクチカを企業にアピールできるようになります」 |

**「きゃりしる」も材料になります。**2025年9月19日の公式発表は、キャリア性格診断「きゃりしる」のリリースを伝えています。「自分の性格や行動傾向を分析し、仕事上での自分自身のタイプや特徴、性格バランス、強みを可視化できるキャリア性格診断ツール」で、**全16種のキャリアタイプ**から判定され、結果には**性格バランス**、**強みを表す3つのキーワード**、仕事で困ったときの対処法が含まれる、とされています。

**フレームワークで書かれている、という前提。**自己PRとガクチカが「決められた質問に回答していくだけ」で作られているということは、**学生によって構成が似ている**ということです。だからこそ、**内容の固有の部分**を拾わないと、どの学生にも当てはまる文面になります。

## 冒頭三行に何を置くか

**型。**

| 行 | 置くもの | 書き方 |
|---|---|---|
| 一行目 | **共感した価値観を名指しする** | 「◯◯を大切にされている、という点に目が留まりました」 |
| 二行目 | **自己PR・ガクチカの具体に触れる** | 「△△の経験で、□□をされたと書かれていましたね」 |
| 三行目 | **差し出すものを一つだけ置く** | 「一度30分、個別にお話しできませんか」 |

**一行目で価値観に触れる理由。**システム側で「どの価値観に共感したか」が学生に見えているので、本文の一行目がそれと一致していると、**一貫した一通**になります。逆に、価値観の表示と本文がずれていると、テンプレートだと気づかれます。

**二行目は「書かれていた内容」に触れます。**フレームワークで作られた文章でも、**何をやったか**は学生ごとに違います。その部分を引いて、自社の仕事とどう結びつくかを一文で書く。「素晴らしい経験ですね」のような感想は、書かないほうが伝わります。

**他己分析の記述があれば、そこを拾います。**他己分析は「親しい人からの意見を取り入れる」機能なので、本人が自分では書かない言葉が入っていることがあります。**第三者から見た強み**は、面談で話を広げる材料にもなります。

**三行目は一つに絞ります。**個別面談、選考スキップ、イベントへの招待。三つ並べると選べません。相手の状況に応じて一つを選びます。

| 差し出すもの | 向く相手 |
|---|---|
| **イベントへの招待** | まだ企業を絞っていない時期。価値観は合うが接点がない |
| **個別面談** | 価値観と自己PRの両方が自社と重なる |
| **選考スキップ** | 志望度が高そう、または競合が多そうで早く会いたい |

**会社紹介は四行目以降です。**冒頭が会社の説明から始まると、学生は「一斉送信だ」と判断します。会社の話は、価値観に触れたあとに置きます。

### エラベルの見解

依頼側から見ると、この媒体の文面で一番よくある失敗は、**自社の価値観を言葉にしないまま送ること**です。「成長環境があります」「風通しがいい会社です」。どの会社も言うので、学生の価値観と当たりません。

実務で最初にやるのは、**社員へのヒアリング**です。なぜこの会社にいるのか、どういうときに面白いと感じるか、どういう人と働きたいか、前の会社と何が違うか。三人から五人に三十分ずつ聞いて、出てきた言葉をそのまま並べます。会社案内から拾った言葉では、この質感は出ません。

そして、出てきた言葉を**価値観の側の言葉**に翻訳します。「裁量が大きい」ではなく「入社半年で自分の判断で進められた」。「チームワーク」ではなく「詰まったときに誰かが横に来る」。具体の一段下に降ろすと、学生の価値観と当たりやすくなります。

もう一つ、**運営の調査が課題を示しています**。レバレジーズ株式会社が2023年6月に公表した調査（ダイレクトリクルーティング利用経験のある企業の採用担当者123名、2023年3月20日〜28日、webアンケート）では、デメリットとして「採用候補となる求職者を探すのに時間がかかる（61.7%）」「スカウトの返信率が悪い（55.0%）」「十分な人数確保ができない（43.3%）」「スカウト文面を作成するのに時間がかかる（30.0%）」が挙げられています。**文面づくりに時間がかかるのは、共通の課題**です。だからこそ、素材を先に集めて使い回せる形にしておくと、運用が続きます。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、ヒアリングから入る担当者かどうかを、面談で確かめてみてください。

## 二通目と、点検

**二通目の条件は運営に確認します。**再送の可否と条件（前回送信からの間隔、上限の回数）は公開されていません。二通目を設計に入れるかどうかは、契約前に確かめてください。

**送れる場合の書き分け。**

| 状態 | 二通目に置くもの |
|---|---|
| **反応がない** | 一通目と違う価値観に触れる。同じ切り口を繰り返しても結果は変わらない |
| **迷っていそう** | 負担の軽いものに差し替える（選考スキップ→イベント招待、面談→資料） |

**文面の点検表。**

| 点検する項目 | 見るところ |
|---|---|
| 一行目 | **共感した価値観を名指し**しているか。システム側の表示と一致しているか |
| 二行目 | 自己PR・ガクチカの**具体的な記述**に触れているか。感想で終わっていないか |
| 三行目 | 差し出すものが**一つ**に絞られているか |
| 会社の言葉 | 「成長環境」「風通し」のような、どの会社でも言える語になっていないか |
| 長さ | 冒頭三行で用件が分かるか。会社説明が先に来ていないか |
| 学年 | 卒業年度に合った内容か。インターンの案内を最終学年に送っていないか |
| 差し出すものの整合 | 選考スキップと書いて、実際に選考を飛ばせる設計になっているか |
| 辞退の前提 | 公式サイトは「スカウトは辞退することもできます」としている。押しの強さを見直す |
| 素材の更新 | 社員ヒアリングの言葉を、半年に一度は足す |

**卒業年度の扱いに注意します。**公式サイトのよくある質問は「どの卒業年度の学生が利用できますか？」に対して「**まだ卒業していない全ての卒業年度の学生にご利用いただけるサービス**です」と答えています。複数の学年が同時に登録している前提なので、**学年に合わない案内を送らない**ようにします。低学年にインターン、最終学年に本選考、という出し分けが要ります。

**「選考スキップ」は約束です。**公式サイトが「個別面談や選考スキップなどのご案内」と書いている以上、学生は文面に書かれた内容を期待します。社内で選考を飛ばす合意が取れていないのに書くと、面談の場で食い違います。**書く前に、選考フローのどこを飛ばすかを決めます。**

**プロフィールの充実度に差があります。**公式サイトのよくある質問は「『スカウト』を受けるにはどうすれば良いですか？」に対して「登録後からスカウトを受け取ることは可能ですが、**プロフィールの各項目を入力するほどスカウトを受けとりやすくなります**」と答えています。裏を返すと、**記載の薄い学生には書ける材料が少ない**ということです。冒頭三行に書ける具体がない相手には、送らないという判断もあります。

### エラベルの見解

依頼側から見ると、文面を外に出すときの心配は「自社らしさが消えること」です。この媒体は価値観で当てる設計なので、その心配は他の媒体より大きくなります。

防ぐ方法は一つで、**言葉の素材を会社から出すこと**です。外注先に「御社の魅力を書いてください」と頼むと、どの会社でも通じる文面が返ってきます。逆に、社員の言葉を三十個渡せば、そこから選んで組み立てられます。**素材を出すのは会社の仕事、組み立てるのが外注先の仕事**という分け方にすると、両方が回ります。

そして、素材集めは一度やれば一年使えます。募集が変わっても、会社の中身は変わらないからです。**最初にヒアリングを依頼範囲に入れるか**で、その後の文面の質が決まります。

もう一つ、返信が来たあとの設計を先に決めておきます。学生は複数社を並行して見ているので、返信の速さが面談設定率に直結します。文面の型を整えることと、返信の体制を作ることはセットです。エラベルは依頼側が担当者を選べる仕組みなので、文面だけでなく返信までの流れを設計できる担当者かどうかを、面談で確かめてみてください。

## まとめ

- この媒体は、企業が**どの価値観に共感したかが学生側に分かる**仕組み。文面の一行目も同じ価値観に触れる
- スカウトとは「**企業から個別面談や選考スキップなどのご案内が届くこと**」。差し出すものは一通に一つ
- プロフィールは**価値観（5つの質問）／フレームワーク機能で作る自己PR・ガクチカ／他己分析**で構成される。**きゃりしる**（全16種のキャリアタイプ）もある
- 企業は「**記載いただいたプロフィール情報を元に学生検索**」を行う。**各項目を入力するほどスカウトを受け取りやすくなる**とされており、記載の薄い学生は書ける材料が少ない
- **まだ卒業していない全ての卒業年度**の学生が利用できるサービス。学年に合った案内を出し分ける
- 送信通数・料金・再送の条件は公開されていない。**契約前に運営にご確認ください**

## よくある質問

### 文面に何を書けば反応が変わりますか

公式サイトは、キャリアチケット就職スカウトについて「あなたの価値観に共感した企業だけが、オファーを送ります。どんな価値観に共感したかも分かるので、キャリアに対する自分の考え方と合っているか判断しやすくなります」としています。学生側には、どの価値観に共感されたかが見える仕組みです。したがって、本文でも同じ価値観に触れ、さらに自己PRやガクチカに書かれた具体に触れると、一貫した一通になります。仕様は変わるので、公式の案内でご確認ください。

### 学生のプロフィールは全員同じ形式ですか

公式サイトは、フレームワーク機能について「決められた質問に回答していくだけで自己PRとガクチカを簡単に作成できます」としています。質問の形式は共通でも、書かれている経験や取り組みは学生ごとに違います。また、他己分析の機能について「親しい人からの意見を取り入れることで、他の学生とは差別化された自分だけの自己PRやガクチカを企業にアピールできるようになります」とされており、第三者の視点が入った記述が含まれる場合があります。文面では、その固有の部分に触れます。

### 「選考スキップ」と書いてよいですか

公式サイトのよくある質問は、スカウトについて「企業から個別面談や選考スキップなどのご案内が届くことです」とし、「※企業によりスカウトの内容は異なります」と補足しています。したがって、選考スキップを案内するかどうかは企業ごとの設計です。書く場合は、選考フローのどの段階を飛ばすのかを社内で決めてから書きます。決めないまま書くと、面談の場で食い違いが起きます。運用の可否は、運営にご確認ください。
