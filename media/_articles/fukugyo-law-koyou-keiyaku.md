副業で人事を受けると、「雇用契約書の雛形を作ってほしい」と頼まれます。このとき最初に確かめるのは、**その会社が作りたいのは契約書なのか、通知書なのか**です。法令が求めているのは明示であって、双方の署名がある契約書そのものではありません。結論を先に書くと、**労働基準法第15条第1項は「使用者は、労働契約の締結に際し、労働者に対して賃金、労働時間その他の労働条件を明示しなければならない。この場合において、賃金及び労働時間に関する事項その他の厚生労働省令で定める事項については、厚生労働省令で定める方法により明示しなければならない」と定め、施行規則第5条が事項と方法を具体化しています。**個別の判断は労働基準監督署や社会保険労務士にご確認ください。2024年4月の追加事項は[労働条件明示義務の改正点](/media/fukugyo-law-roudou-jouken-meiji/)に、募集段階の明示は[募集時の労働条件明示](/media/fukugyo-law-boshuu-jouken/)にまとめています。

## 明示すべき事項の一覧

労働基準法施行規則第5条第1項が挙げる十三項目です。ただし書きにより、第一号の二は有期労働契約であって更新する場合があるものの締結の場合に限り、第四号の二から第十一号までは使用者がこれらに関する定めをしない場合はこの限りでない、とされています。

| 号 | 事項 |
|---|---|
| 一 | 労働契約の期間に関する事項 |
| 一の二 | 有期労働契約を更新する場合の基準に関する事項（**通算契約期間又は更新回数に上限の定めがある場合には当該上限を含む**） |
| 一の三 | **就業の場所及び従事すべき業務に関する事項（就業の場所及び従事すべき業務の変更の範囲を含む）** |
| 二 | 始業及び終業の時刻、所定労働時間を超える労働の有無、休憩時間、休日、休暇並びに労働者を二組以上に分けて就業させる場合における就業時転換に関する事項 |
| 三 | 賃金（退職手当及び第五号に規定する賃金を除く）の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに**昇給に関する事項** |
| 四 | 退職に関する事項（**解雇の事由を含む**） |
| 四の二 | 退職手当の定めが適用される労働者の範囲、退職手当の決定、計算及び支払の方法並びに退職手当の支払の時期に関する事項 |
| 五 | 臨時に支払われる賃金（退職手当を除く）、賞与及び第八条各号に掲げる賃金並びに最低賃金額に関する事項 |
| 六 | 労働者に負担させるべき食費、作業用品その他に関する事項 |
| 七 | 安全及び衛生に関する事項 |
| 八 | 職業訓練に関する事項 |
| 九 | 災害補償及び業務外の傷病扶助に関する事項 |
| 十 | 表彰及び制裁に関する事項 |
| 十一 | 休職に関する事項 |

**事実と異なるものにしない。**同条第2項は「使用者は、法第十五条第一項前段の規定により労働者に対して明示しなければならない労働条件を**事実と異なるものとしてはならない**」と定めています。

**無期転換の場合の追加（第5項）。**「その契約期間内に労働者が労働契約法第十八条第一項の無期転換申込みをすることができることとなる有期労働契約の締結の場合においては、…**労働契約法第十八条第一項の無期転換申込みに関する事項**並びに当該申込みに係る期間の定めのない労働契約の内容である労働条件のうち第一項第一号及び第一号の三から第十一号までに掲げる事項とする」。

## 書面でなければならない範囲と、電子交付

**ここが、実務でよく混同されます。**「明示すべき事項」と「書面で明示すべき事項」は範囲が違います。

**書面等が必要な事項（第3項）。**「法第十五条第一項後段の厚生労働省令で定める事項は、**第一項第一号から第四号までに掲げる事項（昇給に関する事項を除く。）**とする」。つまり、契約期間、更新基準（更新上限を含む）、就業の場所及び従事すべき業務（変更の範囲を含む）、労働時間関係、賃金関係（昇給に関する事項を除く）、退職に関する事項（解雇の事由を含む）です。

**方法（第4項）。**「法第十五条第一項後段の厚生労働省令で定める方法は、労働者に対する前項に規定する事項が明らかとなる**書面の交付**とする。ただし、当該労働者が同項に規定する事項が明らかとなる次のいずれかの方法によることを**希望した場合**には、当該方法とすることができる」として、次を挙げています。

- 一 **ファクシミリを利用してする送信**の方法
- 二 **電子メールその他のその受信をする者を特定して情報を伝達するために用いられる電気通信の送信**の方法（**当該労働者が当該電子メール等の記録を出力することにより書面を作成することができるものに限る**）

**電子交付には二つの条件があります。**労働者がその方法を**希望**したこと、そして**出力して書面を作成できる**ものであること。社内ポータルに置いて見てもらう形は、この文言に当てはまりません。希望の確認を記録に残す運用が要ります。

**無期転換の場合の書面等の範囲（第6項）。**無期転換申込みをすることができることとなる有期労働契約の締結の場合は、第3項の事項に加えて「**労働契約法第十八条第一項の無期転換申込みに関する事項**並びに当該申込みに係る期間の定めのない労働契約の内容である労働条件のうち第一項第一号及び第一号の三から第四号までに掲げる事項（昇給に関する事項を除く。）」が対象になります。

**試用期間の扱い。**募集の段階については、職業安定法施行規則第4条の2第6項が「法第五条の三第一項から第三項までの規定による明示は、**試みの使用期間中の従事すべき業務の内容等と当該期間が終了した後の従事すべき業務の内容等とが異なる場合には、それぞれの従事すべき業務の内容等を示すことにより行わなければならない**」と定めています。労働契約の締結時も同じで、試用期間中と後で労働条件が異なるなら、両方が分かる書き方にします。試用期間の設計は[試用期間の扱い](/media/fukugyo-law-shiyou-kikan/)にまとめています。

### エラベルの見解

担当する側から見ると、この仕事で最初にほどくのは「契約書か通知書か」という問いです。法令が求めているのは**使用者から労働者への明示**なので、通知書の交付で足ります。一方、会社が双方署名の契約書にしたがるのは、**合意した証拠を残したい**からです。どちらが良いという話ではなく、目的が違います。

実務では、**一枚にまとめる**形を勧めています。法定の明示事項を満たした内容を本文に置き、末尾に双方の署名欄を付ける。こうすると、明示義務も果たせて、合意の記録も残ります。二つの書類を別々に作ると、記載が食い違ったときに困ります。

もう一つ、実務で効くのは、**就業規則との役割分担**を決めることです。休職、表彰及び制裁、災害補償、安全衛生といった事項は、個別に書くより就業規則に委ねるほうが管理しやすい。ただし、施行規則第5条第1項は定めをする場合の明示を求めているので、「詳細は就業規則第◯条による」と条番号まで書いて、就業規則が周知されている状態にしておきます。労働契約法第7条は、合理的な労働条件が定められている就業規則を周知させていた場合に労働契約の内容がそれによると定めているので、**周知が前提**です。ここが抜けている会社は多く、指摘すると喜ばれます。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この整理をやった経験は、経歴に書いておくと効きます。

## パート・有期の追加事項と、契約の前後

**短時間・有期雇用労働法第6条第1項。**「事業主は、短時間・有期雇用労働者を雇い入れたときは、速やかに、当該短時間・有期雇用労働者に対して、労働条件に関する事項のうち労働基準法第十五条第一項に規定する厚生労働省令で定める事項以外のものであって厚生労働省令で定めるもの（…「特定事項」という。）を**文書の交付その他厚生労働省令で定める方法**により明示しなければならない」。

**特定事項（同法施行規則第2条第1項）は四つです。**

- 一 **昇給の有無**
- 二 **退職手当の有無**
- 三 **賞与の有無**
- 四 **短時間・有期雇用労働者の雇用管理の改善等に関する事項に係る相談窓口**

**「有無」を書く点がポイントです。**労働基準法の側では「昇給に関する事項」が書面の対象から除かれていますが、パート・有期については**昇給の有無**を文書で明示する形になっています。賞与・退職手当も同じです。「ある／ない」をはっきり書きます。

**事実と異なるものにしない。**同施行規則第2条第2項は「事業主は、法第六条第一項の規定により短時間・有期雇用労働者に対して明示しなければならない労働条件を**事実と異なるものとしてはならない**」と定めています。第3項は、電子的な方法によることを**当該短時間・有期雇用労働者が希望した場合**に限る旨を定めています。

**同法第6条第2項**は、特定事項および労働基準法第15条第1項の省令事項以外の労働条件についても、文書の交付等により明示するよう**努める**ものとしています。

**第14条第1項の説明義務も、雇入れ時です。**短時間・有期雇用労働者を雇い入れたときは、速やかに、第8条から第13条までの措置の内容について説明しなければならないとされています。待遇差の整理は[同一労働同一賃金](/media/fukugyo-law-doitsu-roudou/)にまとめています。

**契約の成立と理解の促進。**労働契約法第6条は「労働契約は、労働者が使用者に使用されて労働し、使用者がこれに対して賃金を支払うことについて、労働者及び使用者が合意することによって成立する」と定めています。第4条は、労働契約の内容の理解を深めるようにすることと、「労働者及び使用者は、労働契約の内容（期間の定めのある労働契約に関する事項を含む。）について、**できる限り書面により確認するものとする**」旨を定めています。

副業の人事が作るのは、次の形です。個別の適否の判断は労働基準監督署や社会保険労務士にご確認ください。

| 作るもの | 中身 |
|---|---|
| 様式の骨格 | 施行規則第5条第1項の十三項目。書面必要の範囲（第一号〜第四号、昇給を除く）を明確に |
| 雇用区分ごとの版 | 正社員／契約社員／パート。パート・有期版には**特定事項の四つ**を足す |
| 変更の範囲の欄 | 就業の場所・従事すべき業務。雇入れ直後と変更の範囲を分けて書く |
| 有期の欄 | 契約期間、更新の基準、更新上限の有無と内容 |
| 無期転換の版 | 申込権が発生する更新時用。申込機会と転換後の労働条件 |
| 就業規則への委任 | 委任する項目と、参照する条番号。就業規則の周知状況を確認 |
| 交付の運用 | 誰が、いつ渡すか。電子交付なら**本人の希望**の確認と記録 |
| 保存 | 交付した控えをどこに保存するか。入社手続の流れに組み込む |
| 説明の段取り | パート・有期の第14条第1項の説明。誰が、何を話すか |

**入社手続の流れに組み込みます。**明示は内定後・入社前の段階で行うのが実務です。入社日当日にまとめて渡す運用だと、条件の食い違いが判明したときに手遅れになります。入退社の手続全体は[入退社手続きの流れ](/media/fukugyo-law-nyuutai-shoku/)にまとめています。

**モデル様式を使います。**厚生労働省は、労働条件明示のリーフレットの巻末にモデル労働条件通知書を収録しています。自社の様式と突き合わせると、欠けている欄がすぐ見つかります。

### エラベルの見解

外に出してよいのは、様式の骨格、雇用区分ごとの版、交付と保存の運用、就業規則への委任の設計、説明の段取りまでで、「この記載で明示として足りるか」「この条件が法令に適合しているか」といった個別の判断は、労働基準監督署や社会保険労務士、弁護士の範囲です。

担当する側から見ると、雇用契約書の仕事で一番効くのは、**渡す場面の設計**です。書類を整えても、入社初日に他の書類と一緒に束で渡して「ここにサインを」で終わっている会社が多い。これだと、本人は読みません。そして三か月後に「聞いていた話と違う」が起きます。

実務で勧めているのは、内定通知のあと、入社の二週間前までに送り、**質問を受ける時間を一回取る**ことです。労働契約法第4条第1項は、労働契約の内容について労働者の理解を深めるようにするものとする、と定めています。条文の趣旨にも沿いますし、何より入社後の齟齬が減ります。五分の電話でも効果があります。

そして、この場面で出てくる質問は、会社にとっての宝です。「変更の範囲に書いてある全国というのは、実際どのくらい動くのですか」「昇給の有無に『有』とありますが、どういう基準ですか」。答えられない質問が出たら、そこが制度の空白です。書類を整える作業が、制度を整える入口になる。この折り返しができる人が、長く頼まれています。エラベルでは、依頼側が担当者を選べるので、この経験は経歴に書いておくと効きます。

## まとめ

- 労働基準法第15条第1項が求めるのは**明示**。双方署名の契約書でなくても、通知書の交付で足りる
- 明示すべき事項は**施行規則第5条第1項の十三項目**。**一号の三に就業の場所及び従事すべき業務の変更の範囲**が含まれる
- **書面等が必要なのは第一号から第四号まで（昇給に関する事項を除く）**。範囲が違う点に注意
- 電子交付は、**労働者が希望**し、かつ**出力して書面を作成できる**ものに限られる
- パート・有期には、短時間・有期雇用労働法第6条第1項の**特定事項（昇給の有無・退職手当の有無・賞与の有無・相談窓口）**が加わる
- 明示した労働条件を**事実と異なるものとしてはならない**（労基則第5条第2項、パート有期則第2条第2項）。個別の判断は労働基準監督署にご確認ください

## よくある質問

### 雇用契約書と労働条件通知書は、どちらが必要ですか

労働基準法第15条第1項が求めているのは労働条件の明示であり、使用者から労働者への一方向の通知で足ります。一方、労働契約法第6条は労働契約が合意により成立すると定め、第4条第2項は労働契約の内容について「できる限り書面により確認するものとする」としています。実務では、法定の明示事項を満たした本文に双方の署名欄を付けて一枚にまとめる形が多く採られます。二種類を別々に作ると記載の食い違いが起きやすいためです。様式の選択については、社会保険労務士にご確認ください。

### メールで送っても明示したことになりますか

労働基準法施行規則第5条第4項は、書面の交付を原則としたうえで、ただし書きで、労働者が希望した場合にファクシミリの送信または電子メール等の送信によることができるとしています。電子メール等については「当該労働者が当該電子メール等の記録を出力することにより書面を作成することができるものに限る」とされています。したがって、本人の希望があることと、出力して書面にできることの二つが条件です。社内システムで閲覧させるだけの形は、この文言に当てはまりません。希望の確認を記録に残す運用が実務です。

### パートの契約書には何を足せばよいですか

短時間・有期雇用労働法第6条第1項は、労働基準法第15条第1項の省令事項以外のものであって厚生労働省令で定めるもの（特定事項）を文書の交付等により明示しなければならないと定めています。同法施行規則第2条第1項は、特定事項として、昇給の有無、退職手当の有無、賞与の有無、短時間・有期雇用労働者の雇用管理の改善等に関する事項に係る相談窓口の四つを挙げています。あわせて、同法第14条第1項は、雇い入れたときに、速やかに、第8条から第13条までの措置の内容について説明しなければならないと定めています。個別の様式の適否は、都道府県労働局雇用環境・均等部（室）や社会保険労務士にご確認ください。
