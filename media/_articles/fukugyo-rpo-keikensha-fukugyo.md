採用代行の会社で、複数の企業の採用を、工程ごとに切り出して回してきた。スカウトの送信、応募者の対応、日程調整、面接の同席、報告。この経験は、副業で最もそのまま使えるはずだが、会社の体制と型と看板が無い状態で、一人でどこまでできるのか。結論を先に書くと、**採用代行の経験は、「工程を切り出して、型で回し、報告する」形で、そのまま副業に売れます。売れるのは、「工程の切り出しと範囲の設計」「型での運用（スカウト、応募者の対応、日程調整、面接の同席）」「複数社の並行の管理」「依頼側への報告と窓口」の五つです。副業の依頼側が求めているのは、まさに採用代行が提供してきた「工程を任せる」形です。ただし、副業は一人で受けるので、会社の体制（複数人、システム、上長の確認）と型と看板が無い前提に組み替えます。「代行会社にいました」ではなく、「この工程を、この型で、一人で回します」と売ります。**スカウト代行の副業の実務は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に、面接代行の案件は[面接代行の副業案件](/media/fukugyo-mensetsu-daikou-fukugyo/)に、前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)にまとめています。

## この経歴の何が売れるか

採用代行の経験を、一人で受ける副業の工程に置き換えた棚卸しです。前の会社の型と顧客の情報は含めず、自分の経験から作った型として抜き出します。

| 採用代行の経験 | 副業の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 工程を切り出して受けてきた | 依頼側の採用を工程に分解し、「ここからここまで」を範囲として設計する | 「何を任せてよいか分からない」依頼側が多い |
| 型で回してきた | スカウト、応募者の対応、日程調整、面接の同席を、型（手順、文面、記録）で回す | 担当者が変わると崩れる依頼側に、型を残せる |
| 複数社を並行で回してきた | 複数の依頼側を、情報を混ぜずに、稼働の枠の中で回す | 副業で複数の案件を受けるときの土台 |
| 依頼側に報告してきた | 週次と月次の報告の型。段階の数、状態の変化、判断が要ること | 報告の型が無く、進捗が見えない依頼側が多い |
| 依頼側との窓口を担ってきた | 依頼側の担当者との定例、判断の仰ぎ方、範囲外の依頼の扱い | 外部に任せた経験が無く、窓口の作り方が分からない依頼側 |
| 様々な規模と業界の採用を見てきた | 依頼側の規模と業界で、どこで詰まりやすいかの型 | 「うちだけがうまくいかない」と感じている依頼側に、型を示せる |
| 立ち上げと引き継ぎをしてきた | 案件の始め方（要件の聞き取り、初期の設計）と、終わり方（引き継ぎの資料） | 外部に任せる始め方と終わり方を知らない依頼側 |

売れるものの要点は、「副業の依頼側が求めている形が、採用代行の形そのもの」だということです。工程を切り出し、型で回し、報告する。人事の副業で最も多い依頼はこの形で、採用代行の経験者は、それを仕事として回してきています。置き換えの手間はほとんどなく、変えるのは「会社の体制で回していたものを、一人で回す」部分だけです。工程の分解は[業務範囲を書面で固める](/media/fukugyo-scope/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に、並行の管理は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に書いています。

## 売りにくい点とその扱い

採用代行の経験者の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 会社の体制と看板が無い | 「会社なら複数人で回していたが、一人で回せるのか」「システムや上長の確認が無い状態で、質を保てるのか」 | 一人で回せる範囲に絞る。会社の体制で回していた量ではなく、稼働の枠で回せる量を示す。品質の確認は、自分の型（チェックの一覧）で代える |
| 前の会社との線 | 「前の会社の顧客を持ってくるのでは」「前の会社の型や資料を使うのでは」 | 前の会社の顧客と競合する依頼側を避け、前の会社の型と資料は持ち込まず、自分の経験から作った型を使う。退職後の競業と守秘の条件を確認する |
| 依頼側の期待との差 | 「代行会社と同じ量と速さを期待される」 | 契約の前に、一人で回せる量と速さを示す。「代行会社の一人分」ではなく「副業の稼働の枠で回せる分」で範囲を決める |

扱い方の要点は、「会社の体制で回していた量を、副業の稼働の枠に落とす」ことです。採用代行の経験者は、会社では複数人と仕組みで大量の工程を回していて、その感覚で副業を受けると、一人の稼働の枠を超えます。「スカウトは週に何通」「応募者の対応は何件まで」と、稼働の枠で回せる量を先に決め、依頼側に示します。前の会社との線は、退職後の競業と守秘の条件を確認し、前の会社の顧客と型と資料を持ち込みません。前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、稼働の枠は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、採用代行の経験者で副業を続けている人と、最初の案件で崩れる人の差は、工程の腕ではなく、「会社の量を副業に持ち込んでいないか」です。崩れる人は、会社で回していた量の感覚で「これくらいなら」と受け、一人の稼働の枠を超え、締め切りを落とし、依頼側から「代行会社より遅い」と見られています。続いている人は、稼働の枠で回せる量を契約の前に示し、「副業の稼働なので、ここまで。それ以上は範囲を分けます」と線を引き、その中で会社と同じ質の型で回し、依頼側から「一人でもきちんと回る」と評価されています。

見ていて差がつくのは、会社の型と自分の型を分けているかです。採用代行の会社には、会社が作った文面の型、手順の型、報告の型があり、それをそのまま副業で使うと、前の会社の資産の持ち出しになります。続いている人は、会社の型から「自分が学んだ考え方」だけを抜き出し、自分の言葉と構成で型を作り直しています。作り直した型は自分の資産で、どの依頼側にも使えます。エラベルでは、依頼側が担当者を選ぶ仕組みなので、工程と型と一人で回せる量を明確にしている担当者に、工程を任せたい依頼側がついています。採用代行の経験者の転身は、腕ではなく、量の組み替えと型の作り直しで始まります。

## 案件の探し方

採用代行の経験者から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| スカウトの運用（範囲を絞って） | 型で回してきた経験でそのまま入れる | 「週に何通、この型で」と量を示す。前の会社の顧客と競合しない依頼側 |
| 応募者の対応と日程調整 | 型で回してきた経験で入れる | 「応募から面接の設定までを、型で漏れなく」を範囲の一言に |
| 面接の同席と記録 | 面接に同席してきた経験で入れる | 「面接の記録と評価の観点の整理」を示す。判断は依頼側 |
| 報告の型の設計 | 報告してきた経験で入れる | 「週次と月次の報告の型」を成果物の形で |
| 外部に任せるのが初めての依頼側の、範囲の設計と窓口 | 立ち上げをしてきた経験で入れる | 「初めて外部に任せる依頼側の、範囲の設計と始め方」を範囲の一言に |
| 型を残して引き継ぐ案件 | 引き継ぎをしてきた経験で入れる | 「担当者が変わっても回る型を残す」を提案の形で |

探し方の要点は、「外部に任せるのが初めての依頼側」を狙うことです。採用代行の経験者は、依頼側が外部に任せるときの始め方（要件の聞き取り、範囲の設計、窓口の作り方、報告の型）を知っています。初めての依頼側は、その始め方が分からず止まっていて、経験者が入ると最初の一巡が回ります。一巡が回れば、工程を広げられます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、スカウト代行の最初の一件は[スカウト代行で副業を始めるには](/media/fukugyo-scout-daikou-hajimekata/)に、面接代行の始め方は[面接代行で副業を始めるには](/media/fukugyo-mensetsu-daikou-hajimekata/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。採用代行の経験者の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 代行会社の料金との比較 | 代行会社の料金は、会社の体制と看板と複数人の工数で決まっていて、個人の単価とは別物 | 会社の料金を副業に持ち込まない。個人の工程の単価で |
| 型で回せる直接性 | 最初の月から型で回せ、依頼側にとって即戦力 | 「未経験の分野だから」と下げない。工程の単価で |
| 量で受ける工程 | スカウトの送信、応募者の対応は、量と月額で受けやすい | 「週に何通、月に何件まで」と量の上限を決めて月額に |
| 成果物で受ける工程 | 報告の型、範囲の設計、引き継ぎの資料は、成果物で | 成果物で受けると、単価の議論が明確になる |
| 一人で回せる量の上限 | 会社の量を持ち込むと、単価あたりの稼働が持ち出しになる | 稼働の枠で回せる量を先に決め、超える分は範囲を分ける |
| 前の会社との契約の条件 | 退職後の競業と守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「量の上限を、単価より先に決める」ことです。採用代行の経験者は、量で受ける工程に慣れていて、量の上限を決めずに月額で受けると、依頼側の期待が会社の量になり、稼働が持ち出しになります。「週に何通」「月に何件」と上限を決め、その量に対する月額にし、超える分は別の範囲として見積もります。前の会社との契約に退職後の条件がある場合は、それを確認し、個別の判断は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、超過の扱いは[超過稼働の扱い](/media/fukugyo-choka-kadou/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

採用代行の経験者から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、前の会社との契約の条件（退職後の競業、守秘、顧客との接触）を確認する | 個別の判断は専門家に |
| 二、前の会社の顧客と競合する依頼側を、避ける対象として書き出す | 前の会社との線 |
| 三、会社の型から「自分が学んだ考え方」だけを抜き出し、自分の言葉と構成で型を作り直す | 会社の文面、手順、報告の型は持ち込まない |
| 四、副業の稼働の枠で回せる量を決める | 「週に何通」「月に何件」。会社の量を持ち込まない |
| 五、範囲を、一人で回せる工程に絞る | スカウト、応募者の対応、日程調整、面接の同席、報告、範囲の設計 |
| 六、「この工程を、この型で、一人で回します」の一言を作る | 「代行会社にいました」で終わらせない |
| 七、登録先に、範囲と量の上限を登録する | 外部に任せるのが初めての依頼側 |
| 八、一つの工程を、量の上限つきの月額で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「三」の型の作り直しを、案件を探す前にやることです。採用代行の会社の型は、会社の資産で、そのまま副業で使うと持ち出しになります。会社の型から「なぜこの手順なのか」「なぜこの文面なのか」という考え方だけを抜き出し、自分の言葉と構成で作り直す。作り直した型は自分の資産で、前の会社との線も守れます。型の作り方は[事例の書き方](/media/fukugyo-jirei-kakikata/)に、流用の線は[事例を流用しない](/media/fukugyo-jirei-ryuuyou/)に、自己紹介は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「採用代行の経験があれば、副業はそのまま同じことをすればよい」というものです。実際には、そのまま同じことをしようとすると、会社の量と型と看板が無い状態で、一人の稼働の枠を超え、前の会社の資産を持ち出す形になります。同じなのは工程の考え方で、変えるのは量と型と立場です。量を稼働の枠に落とし、型を自分の言葉で作り直し、一人で回せる範囲に絞った人が、最も直接的に売れる経験を安全に売れています。

順番として、前の会社との契約の条件を確認し、競合する依頼側を避ける対象として書き出し、会社の型から考え方だけを抜き出して自分の型を作り直し、稼働の枠で回せる量を決め、範囲を一人で回せる工程に絞り、この工程をこの型で一人で回す、の一言を作り、登録先に範囲と量の上限を登録し、一つの工程を量の上限つきの月額で受けて型を残す。この順番で、採用代行の経験者の転身は、「会社の量と型を持ち込む危ういもの」から「一人で回せる工程を型で売るもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、工程と型と一人で回せる量を明確にしている担当者に、工程を任せたい依頼側がついています。採用代行の経験者の転身は、腕ではなく、量の組み替えと型の作り直しで始まります。

## まとめ

- 採用代行の経験は**「工程を切り出して、型で回し、報告する」形**で、そのまま副業に売れる。**工程の切り出し・型での運用・並行の管理・報告・窓口**の五つ
- 副業は**一人で受ける**ので、会社の体制と型と看板が無い前提に組み替える。**「代行会社にいました」ではなく「この工程を、この型で、一人で回します」**
- **会社の量を持ち込まない**。稼働の枠で回せる量を契約の前に示し、超える分は範囲を分ける
- **会社の型を持ち込まず、考え方だけを抜き出して自分の型を作り直す**。前の会社の顧客と競合する依頼側は避け、退職後の条件は専門家に確認
- 案件は**外部に任せるのが初めての依頼側**から。始め方（範囲の設計、窓口、報告の型）を知っている
- 単価は**量の上限を先に決め、量は月額、設計は成果物**で。代行会社の料金は持ち込まない

## よくある質問

### 前の会社で担当していた顧客から、直接、副業で頼みたいと言われました

前の会社との契約の条件（退職後の顧客との接触、競業、守秘）を確認し、条件に触れるなら受けません。条件に触れなくても、前の会社の顧客をそのまま副業で受ける形は、前の会社から見て「顧客を持ち出した」と映り、関係を壊します。依頼側には「前の会社との関係で、直接はお受けできません」と伝え、期間を置くか、前の会社を通す形を提案します。個別の判断は専門家にご確認ください。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、直接契約の誘いは[直接契約の誘いを受けたら](/media/fukugyo-chokusetsu/)に整理しています。

### 会社では週に何百通も送っていましたが、副業でも同じ量を期待されます

副業の稼働の枠で回せる量を、契約の前に示します。会社の量は、複数人と仕組みで回していた量で、一人の稼働の枠では回りません。「私の稼働は週〇時間なので、スカウトは週〇通まで。それ以上が必要なら、範囲を分けるか、別の担当者と分担する形にさせてください」と伝えます。量を示さずに受けると、依頼側の期待が会社の量になり、稼働が持ち出しになって崩れます。量の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、分担の形は[チームで動くときの分担](/media/fukugyo-chiimu/)に書いています。

### 会社で使っていた文面や手順の資料を、副業で使ってよいですか

会社の文面と手順の資料は会社の資産なので、そのまま使いません。資料から「なぜこの構成なのか」「なぜこの手順なのか」という考え方を抜き出し、自分の言葉と構成で作り直します。作り直した型は自分の資産で、前の会社との線も守れます。作り直す手間は要りますが、その過程で型の理解が深まり、依頼側の規模と業界に合わせて直せるようになります。型の作り方は[事例の書き方](/media/fukugyo-jirei-kakikata/)に、流用の線は[事例を流用しない](/media/fukugyo-jirei-ryuuyou/)に整理しています。
