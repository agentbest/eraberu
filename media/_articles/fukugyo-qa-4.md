副業に興味はあるが、本業と家庭で、週に使える時間は限られている。人事の副業は、週に何時間あれば受けられるのか。少なすぎると相手にされないのではないか。結論を先に書くと、**人事の副業に必要な時間は、案件の範囲で決まり、一律の答えはありません。候補者への返信や日程調整のように、毎日の短い枠で回る工程もあれば、スカウトの文面の作成や求人票のように、まとまった枠が要る工程もあります。先に決めるべきは、週の時間の量ではなく、「本業の繁忙期でも固定できる枠」がどこにあるかです。**固定できる枠が週に数時間でも、その枠に入る工程の案件はあります。逆に、閑散期に多くの時間があっても、繁忙期に消える時間で受けた案件は止まります。固定できる時間の考え方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、一週間の置き方は[1週間のスケジュール例](/media/fukugyo-schedule/)にまとめています。

## 時間の量より、枠の固定が先である理由

「週に何時間」で考えると、時間の量に目が行きますが、依頼側が見ているのは量ではなく、固定されているかです。

| 依頼側が見ていること | なぜ |
|---|---|
| 候補者への返信が、決まった時間に来るか | 候補者を待たせない。「毎日夜に返信が来る」なら依頼側は予定を組める |
| 定例の時間が固定できるか | 週に一度、同じ曜日の同じ時間に話せるか |
| 繁忙期に止まらないか | 本業が忙しい月でも、最低限の工程が回るか |
| 稼働の見込みが立つか | 「週に〇時間」ではなく「〇曜と〇曜の夜、土曜の午前」のように、いつ動くかが分かるか |

見ている要点は、「量が多くても、いつ動くか分からない人より、量が少なくても、いつ動くかが決まっている人が選ばれる」ことです。「空いた時間に週に十時間くらい」より、「火曜と木曜の夜に二時間ずつと、土曜の午前に二時間」のほうが、依頼側は候補者への返信と定例の時間を組め、任せやすくなります。固定できる枠の見つけ方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

## 工程ごとに要る枠の種類

人事の副業の工程を、要る枠の種類で分けます。自分の枠がどの種類かで、受けられる工程が決まります。

| 工程 | 要る枠 | 特徴 |
|---|---|---|
| 候補者への返信、一次対応 | 毎日の短い枠 | 数十分でも、毎日あることが大切。返信の速さが要る |
| 日程調整 | 毎日の短い枠 | 候補者と面接官の間の往復。短い枠の複数回で回る |
| スカウトの送信 | 短い枠の複数回、またはまとまった枠 | 送信そのものは短時間で分けられる。相手の絞り込みはまとまった枠 |
| スカウトの検索と文面の作成 | まとまった枠 | 集中が要る。細切れでは進まない |
| 求人票の作成 | まとまった枠 | 依頼側とのやり取りを含めて、数回のまとまった枠 |
| 面接の準備（面接官への資料） | まとまった枠 | 面接の前に、候補者ごとに |
| 記録の整備 | 短い枠の末尾 | こまめに。溜めると重くなる |
| 依頼側との定例 | 定例の枠（週に一度、固定） | 依頼側の営業時間に近いことが多い |
| 稼働報告と請求 | まとまった枠（月に一度） | 締め日に合わせて |
| 採用の型づくり（中長期） | まとまった枠 | 求人票の見直し、選考の流れの整理。時間がかかる |

工程の要点は、「毎日の短い枠があれば、候補者への返信と日程調整の案件は受けられる」ことです。まとまった枠が取れなくても、毎日夜に短い時間が固定できるなら、一次対応と日程調整を範囲にした案件は回ります。まとまった枠がある人は、文面や求人票の工程を範囲に入れられます。枠の種類で範囲を決めれば、時間の量で悩まなくなります。範囲の決め方は[受ける範囲の決め方](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「週に十時間以上無いと、副業は受けられない」というものです。実際には、登録の相談で「週に数時間しか固定できない」という方でも、その数時間が毎日の短い枠として固定できるなら、候補者への返信と日程調整を範囲にした案件で続いている例があります。逆に、「週に二十時間は取れる」という方でも、その時間が閑散期の空き時間で、繁忙期に消えるなら、受けた案件は繁忙期に止まります。

見ていて差がつくのは、「本業の最も忙しい月」を基準に枠を決めているかです。最も忙しい月でも固定できる枠だけを副業の枠にしている人は、通年で止まらず、依頼側から「安定している」と評価されます。閑散期の感覚で枠を決めた人は、繁忙期に「今月は無理です」が続き、依頼側の信頼を失います。エラベルでは、登録の際に「本業が最も忙しい月でも固定できる枠」を聞き、その枠に入る範囲の案件を提示しています。時間の量ではなく、枠の固定で案件を合わせています。

## 週の枠の置き方の型

固定できる枠を、週の中にどう置くかの型です。自分の生活に合う型を選びます。

| 型 | 枠の置き方 | 向く工程 | 向く人 |
|---|---|---|---|
| 平日の夜 | 平日の数日、夜に一〜二時間 | 候補者への返信、日程調整、短い作業 | 帰宅後に時間が取れる人。[平日の夜に副業をする](/media/fukugyo-heijitsu-yoru/) |
| 早朝 | 平日の朝、出勤前に一時間 | 返信、記録、短い作業。集中が要る作業も | 朝型の人。[早朝に副業をする](/media/fukugyo-hayaasa/) |
| 週末のまとまった枠 | 土曜か日曜の午前に数時間 | 文面の作成、求人票、面接の準備、報告 | 平日は取れないが週末は取れる人。[週末に副業をする](/media/fukugyo-shuumatsu/) |
| 平日の夜と週末の組み合わせ | 平日の夜に短い枠、週末にまとまった枠 | 毎日の対応とまとまった作業の両方 | 最も多くの範囲を受けられる型 |
| 昼休みの短い枠 | 本業の昼休みに数十分 | 返信の確認程度。本業の端末と回線は使わない | 本業の規定と、端末と回線の分離ができる人に限る |

型の要点は、「平日の夜と週末の組み合わせ」が、最も多くの範囲を受けられることです。毎日の短い枠で候補者への返信を回し、週末のまとまった枠で文面や求人票を作れば、多くの案件の範囲に対応できます。片方しか無い場合は、その枠に合う工程に範囲を絞ります。昼休みの枠は、本業の規定と情報の分離の問題があるので、返信の確認程度にとどめ、本業の端末と回線は使いません。時間帯ごとの注意は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

## 時間帯で変わる受けられる工程

枠の量だけでなく、時間帯が依頼側の営業時間と重なるかで、受けられる工程が変わります。

| 時間帯 | 依頼側の営業時間との関係 | 受けられる工程 | 受けにくい工程 |
|---|---|---|---|
| 平日の夜 | 重ならない | 候補者への返信（候補者も夜に見ることが多い）、文面の作成、記録 | 依頼側との定例（依頼側が夜に対応できれば可）、面接官との調整の即時対応 |
| 早朝 | 重ならない | 返信、記録、集中が要る作業 | 定例、即時の調整 |
| 週末 | 重ならない | まとまった作業、報告、型づくり | 依頼側との連絡、候補者の対応の一部（週末に返信を嫌う候補者もいる） |
| 平日の日中（本業が無い日や、勤務の形で日中が空く人） | 重なる | 定例、面接官との調整、依頼側の社内の人との連絡、面接の同席 | ― |

時間帯の要点は、「依頼側との定例だけは、営業時間に近い時間に一枠取れるか」です。他の工程は営業時間の外でも回りますが、定例は依頼側の担当者の都合で決まり、営業時間内が多い。週に一度、営業時間に近い時間（昼休み、始業前、終業直後）に定例の枠が取れれば、他は夜と週末で回ります。取れなければ、定例を短い文面の報告に替える形を依頼側と相談します。定例の形は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に整理しています。

## 少ない時間で始める形

固定できる枠が週に数時間しか無い場合の、始め方の形です。

| 手順 | 内容 |
|---|---|
| 一、枠を書き出す | 本業の最も忙しい月でも固定できる枠を、曜日と時間帯で書く。「火・木の夜に一時間、土曜の午前に二時間」 |
| 二、枠に入る工程を選ぶ | 毎日の短い枠があれば返信と日程調整。まとまった枠があれば文面や求人票。両方が無ければ、返信と記録 |
| 三、範囲を工程で一言にする | 「候補者への一次返信と日程調整」のように、枠に入る工程だけを範囲にする |
| 四、一件だけ受ける | 枠に入る範囲の案件を一件。複数は受けない |
| 五、稼働ログで実績を見る | 一件で枠がどれだけ埋まるかを、数か月の実績で見る。[稼働ログの付け方](/media/fukugyo-log/) |
| 六、余りがあれば範囲を広げる | 枠に余りがあれば、次の更新で工程を一つ足す。無ければそのまま続ける |

少ない時間の要点は、「範囲を小さくして一件だけ受ける」ことです。週に数時間で、範囲を「候補者への一次返信と日程調整」に絞れば、依頼側にとっては「毎日返信が来る人」として価値があり、自分にとっては枠に収まります。小さく始めて、実績で枠の余りを見て、広げる。この順番なら、少ない時間でも止まりません。小さい範囲の案件の見つけ方は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に、最初の一件の進め方は[案件の最初の時期の進め方](/media/fukugyo-shoki-90nichi/)に書いています。

## 時間が足りないと感じたときの見直し

始めてから「時間が足りない」と感じたら、時間を増やす前に、見直すことがあります。

| 感じていること | 実際に起きていること | 見直し |
|---|---|---|
| 枠を超えて作業している | 範囲が枠より大きいか、範囲外の依頼が増えている | 稼働ログで工程ごとの時間を見る。範囲外なら依頼側と範囲の話。[範囲が広がっていくとき](/media/fukugyo-scope-creep/) |
| 返信が追いつかない | 毎日の短い枠が無いか、枠の外で返信している | 返信の時間を決め、候補者に「返信は夜になる」と伝える |
| まとまった作業が進まない | まとまった枠が無いのに、まとまった作業を範囲に入れている | 範囲からまとまった作業を外すか、週末に枠を作る |
| 本業が忙しくなって枠が消えた | 閑散期の枠で決めていた | 繁忙期でも固定できる枠に置き直す。[稼働が合わなくなったら](/media/fukugyo-qa-12/) |
| 休みが無くなった | 本業と副業で週が埋まっている | 予備の枠と休む日を先に置く。[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/) |
| 時間はあるのに疲れる | 枠の置き方が生活と合っていない | 型を変える。夜が合わないなら早朝、平日が合わないなら週末 |

見直しの要点は、「時間を増やす前に、範囲と枠の置き方を見る」ことです。時間が足りないと感じる理由の多くは、範囲が枠より大きいか、枠の置き方が生活と合っていないかで、時間を増やしても解決しません。範囲を枠に合わせ、枠を生活に合わせれば、同じ時間で回ります。それでも足りないなら、そのときに時間を増やすか、範囲を減らすかを決めます。

### エラベルの見解

担当する側から見ると、長く続いている人の稼働時間は、人によって幅があり、「週に何時間」に共通の答えはありません。共通しているのは、本業の最も忙しい月でも固定できる枠だけを副業の枠にし、その枠に入る範囲の案件を受けていることです。時間が多い人が続いているのではなく、枠が固定されている人が続いています。

順番として、本業の最も忙しい月を思い浮かべ、その月でも固定できる枠を曜日と時間帯で書き出し、枠の種類（毎日の短い枠か、まとまった枠か）に合う工程を範囲にし、一件だけ受け、稼働ログで実績を見て、余りがあれば広げる。この順番で、「週に何時間必要か」という問いは、「自分の枠に何が入るか」という問いに変わり、答えが出ます。エラベルでは、登録の際に固定できる枠を聞き、その枠に合う範囲の案件を提示しています。時間の量で選ばれる仕組みではなく、枠と範囲の相性で合わせる仕組みです。

## まとめ

- 必要な時間は**案件の範囲で決まり、一律の答えは無い**。先に決めるのは時間の量ではなく**本業の繁忙期でも固定できる枠**
- 依頼側が見ているのは**量ではなく、いつ動くかが決まっているか**
- 工程は**毎日の短い枠で回るもの（返信、日程調整）とまとまった枠が要るもの（文面、求人票）**に分かれる。枠の種類で範囲を決める
- 枠の置き方は**平日の夜・早朝・週末・組み合わせ**。組み合わせが最も広い範囲を受けられる
- **定例だけは営業時間に近い一枠**が要る。取れなければ文面の報告に替える
- 少ない時間なら**範囲を小さくして一件だけ受け、実績で余りを見て広げる**
- 足りないと感じたら**時間を増やす前に、範囲と枠の置き方を見直す**

## よくある質問

### 毎日は無理で、週末しか時間が取れません。受けられますか

週末のまとまった枠だけなら、文面の作成、求人票、面接の準備、記録の整備、型づくりのように、まとまった枠で進む工程を範囲にした案件は受けられます。候補者への返信と日程調整は、平日に返信できないと候補者を待たせるので、範囲から外すか、依頼側の社内で回してもらいます。「週末のまとまった作業」と範囲を絞って伝えれば、その範囲で依頼側が求める案件があります。週末の枠の使い方は[週末に副業をする](/media/fukugyo-shuumatsu/)に書いています。

### 時間はあるのですが、本業の繁忙期がいつか読めません

繁忙期が読めないなら、枠を小さめに固定し、範囲もそれに合わせて絞ります。読めない繁忙期が来たときに、枠が小さければ守りやすく、範囲が狭ければ止めずに済みます。数か月回すと、繁忙期の時期が見えてくるので、そのときに枠を置き直します。読めないうちは、「読めない前提で小さく始める」のが、止まらない形です。本業の繁忙が読めない時期の始め方は[人事1年目でもできること](/media/fukugyo-1nenme/)にも書いています。

### 依頼側から「もっと時間を増やしてほしい」と言われました

枠に余りがあれば、増やす範囲と稼働と単価を一緒に見直します。余りが無ければ、「いまの枠が上限で、これ以上は本業に影響します」と伝え、増やせない理由を稼働の上限として説明します。枠を超えて増やすと、本業か体調に影響し、結果として依頼側の案件も止まります。依頼側が量を求めているなら、範囲を絞って質を保つか、依頼側が別の担当者を足すかを相談します。無理な依頼の伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。
