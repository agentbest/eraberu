スカウトの返信率は見ている。面談の数も分かる。ただ、そこから応募、選考、内定、入社まで、何人が残るのかが分からない。途中で消える候補者が多い気がする。内定を出しても辞退される。一人採るのに何通送ればよいかも、答えられない。結論を先に書くと、**スカウト経由の歩留まりは、「返信率」で見るのをやめ、送信・返信・面談・応募・選考・内定・入社の七段を、「数」「日数」「落ちた理由」で並べます。スカウト経由の候補者は、自分から応募した人と違い、「声をかけられた側」なので、面談の後と内定の後に特有の落ち方をします。段ごとに落ちた理由を記録すれば、直す箇所は一か所ずつ見えます**。採用全体の詰まりの見方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に、見る指標の全体は[スカウト運用で見るべき指標](/media/scout-shihyou/)にまとめています。

## 歩留まりが見えない構造

スカウト経由の歩留まりが見えないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 返信率までしか見ていない | 代行の報告が返信率で終わり、面談以降は社内で起きるので誰も数えていない |
| 経路を分けていない | 応募者全体の歩留まりはあるが、スカウト経由と公募経由が混ざっている |
| 落ちた理由が無い | 「辞退」で一括りにし、どの段で、なぜ落ちたかが無い |
| 日数を見ていない | 数は落ちていないが、段から段までが長く、その間に他社に決まっている |
| 内定の後を見ていない | 内定を出したら終わりと思い、辞退と入社後の早期の退職を数えていない |
| 目標が「送信数」 | 「月に何通」が目標で、「何人採るために何通か」の逆算が無い |
| スカウト経由の特性を知らない | 公募と同じ歩留まりを期待し、面談の後の落ちに驚く |

構造の大半は、「面談以降を数えていない」ことです。面談以降は社内で起きるので、社内が数えないと、歩留まりは返信率で止まります。

## 七つの段と落ち方

スカウト経由の候補者が通る七つの段と、段ごとの落ち方です。

| 段 | 数 | 落ち方 | 主に効く要素 |
|---|---|---|---|
| 送信 | 送った通数 | — | 対象、文面 |
| 返信 | 返信が来た数 | 読まれない、響かない、届く相手が違う | 件名、一段落目、対象 |
| 面談 | 面談に至った数 | 返答が遅い、日程が決まらない、位置づけが重い | [面談設定率をどう上げるか](/media/scout-mendan-settei-ritsu/) |
| 応募 | 応募の意思を示した数 | 判断の材料が無い、入り口が重い | [面談から応募への転換率](/media/scout-mendan-oubo-tenkan/) |
| 選考 | 選考を通過した数 | 要件と合わない（対象のずれ）、選考が長い、選考中の辞退 | 対象の絞り、選考の設計 |
| 内定 | 内定を出した数、承諾した数 | 条件、他社、内定後の接点の不足 | 条件の出し方、内定後の設計 |
| 入社 | 入社した数、一定期間の定着 | 入社前の辞退、早期の退職 | 入社前の接点、入社後の受け入れ |

七つの要点は、「送信から返信」だけがスカウトの工程で、残りの五段は社内の工程だということです。スカウト経由の歩留まりの大半は、社内の工程で決まります。代行の報告が返信率で終わるなら、残りは社内が数えます。

## スカウト経由に特有の落ち方

自分から応募した候補者と比べて、スカウト経由の候補者に特有の落ち方です。

| 段 | 特有の落ち方 | 理由 |
|---|---|---|
| 面談の後 | 「考えます」で止まる率が高い | 声をかけられた側なので、応募の意思がまだ固まっていない。面談で判断の材料を渡さないと動かない |
| 選考の途中 | 「やはり今回は」の辞退が多い | 転職を急いでいない。選考が長いと、動機が薄れる |
| 内定の後 | 他社の内定との比較で辞退が多い | 複数の会社から声がかかっている層。条件だけでなく、内定後の接点が要る |
| 入社の前 | 現職の引き止めで辞退がある | 現職に不満があって動いたわけではない。引き止めに揺れる |
| 入社の後 | 「思っていたのと違う」の早期の退職 | スカウトの文面と面談で伝えた役割と、実際の役割がずれていると起きる |

特有の要点は、「動機が固まっていない段階で接点が始まる」ことです。公募の候補者は応募の時点で動機がありますが、スカウトの候補者は面談の後に動機を作ります。面談の後、選考中、内定後、入社前の接点が、公募より多く要ります。

## 段ごとの直し方

七段のうち、落ちている段ごとの直し方です。返信までの段は他の記事に譲り、面談以降を中心に書きます。

| 落ちている段 | 直し方 |
|---|---|
| 面談→応募 | 面談で判断の材料（役割の中身、一日の流れ、条件の幅、課題）を渡す。翌日に要点と軽い入り口を送る。[面談から応募への転換率](/media/scout-mendan-oubo-tenkan/) |
| 応募→選考の通過 | 落ちる理由が「要件と合わない」なら、対象の絞りを直す。「選考中の辞退」なら、選考の日数を短くし、選考中の接点を入れる |
| 選考→内定の承諾 | 条件を幅で早く出す。内定後に、一緒に働く人との接点、迷いを聞く場、期限の相談。[内定辞退が続くときに見直す三点](/media/rpo-jitai-ooi/) |
| 内定→入社 | 入社前の接点（月に一度の連絡、チームとの顔合わせ）。現職の引き止めへの備えを、内定時に話しておく |
| 入社→定着 | スカウトの文面と面談で伝えた役割を、入社後の実際と合わせる。ずれがあるなら、文面と面談の側を実際に合わせる |

直し方の要点は、「落ちた理由を記録してから直す」ことです。「選考で落ちる」でも、要件と合わないのか、辞退なのかで、直す箇所は対象か選考かに分かれます。理由の記録が無いと、直す箇所が決まりません。辞退の理由の集め方は[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に書いています。

### エラベルの見解

相談で最も多い失敗は、「返信率が良いので順調だと思っていたが、一年で入社がゼロだった。面談以降を数えていなかったので、どこで落ちているか分からず、担当者は『もっと送りましょう』と言っていた」というものです。七段を並べると、面談から応募で八割が落ちていました。面談は人事だけで、条件も課題も話されていませんでした。送信数はそのままで、面談の相手を責任者にし、話すことの型を作り、翌日の連絡と入り口を変えたら、応募が増え、半年で入社に至りました。送信を増やしても、面談の後の落ちは変わりません。

見ていて差がつくのは、発注側が「面談以降を自分で数える」かです。代行の報告の返信率で終わる会社と、「面談以降は社内で起きるので、人事が段ごとに数えます」と言う会社があります。後者は、直す箇所が毎月決まります。

発注側にできるのは、面談以降の五段を、人事が月に一度、数と理由で数えて、担当者と一緒に見ることです。

## 歩留まりの表の作り方

七段の歩留まりを見る表の、最低限の形です。

| 列 | 内容 |
|---|---|
| 月 | 集計の月 |
| 役割 | 役割ごとに分ける。役割で歩留まりが大きく違う |
| 経路 | スカウト経由。公募や紹介と分ける |
| 段ごとの数 | 送信、返信、面談、応募、選考の通過、内定（提示と承諾）、入社 |
| 段ごとの率 | 前の段に対する率 |
| 段ごとの日数 | 段から段までの平均の日数 |
| 落ちた理由の内訳 | 段ごとに、落ちた理由の区分と数。「要件と合わない」「辞退（他社）」「辞退（時期）」「辞退（条件）」「連絡が途絶えた」など |
| 前月との比較 | 段ごとの率と日数の変化。何を変えたかを添える |

表の要点は、「落ちた理由の内訳」です。数と率だけの表は、「どこで落ちたか」までしか分かりません。理由があれば、「なぜ落ちたか」が分かり、直す箇所が決まります。理由の記録は、候補者CRMの「辞退・見送り」の段階に理由を書くことで溜まります。[候補者CRMの作り方](/media/scout-crm/)に書いています。

## 目標の逆算

「何人採るために何通送るか」を、歩留まりの表から逆算します。

| 手順 | 内容 |
|---|---|
| 一 | 採用の目標人数を決める（役割ごと） |
| 二 | 自社の直近の歩留まりの表から、段ごとの率を取る |
| 三 | 入社の目標から、内定の承諾、内定の提示、選考の通過、応募、面談、返信、送信の順に、率で割り戻す |
| 四 | 出た送信数が、母集団と稼働で出せる数か確認する |
| 五 | 出せないなら、送信を増やすのではなく、落ちている段の率を上げる。率が上がれば、必要な送信数は減る |
| 六 | 月ごとに、実績で率を更新し、逆算をやり直す |

逆算の要点は、「五」です。必要な送信数が出せない数になったとき、送信を増やす方向ではなく、歩留まりを上げる方向に進みます。面談から応募の率を上げれば、同じ送信数で入社は増えます。一般の歩留まりの数字は自社に当てはまらないので、逆算は自社の表の率で行います。

## 外注する場合の範囲

スカウト経由の歩留まりの改善を、スカウト代行に出す場合の範囲です。

**出せる工程。** 七段の表の設計と、送信から面談までの記録、面談以降の記録の依頼と回収（社内が書いたものの集約）、段ごとの率と日数の集計、落ちた理由の区分の設計と集計、落ちている段の特定と直し方の提案、送信から応募までの段の改善の実施、選考以降の段の改善の提案（接点の型、連絡の下書き）、目標の逆算と月次の更新、月次の報告。

**社内に残す判断。** 面談以降の段の記録（面談、応募、選考、内定、入社は社内で起きる）、落ちた理由の記録（辞退の理由を聞くのは社内の人）、選考の設計の変更（日数、回数、省略）、条件の出し方の決定、内定後と入社前の接点の実施（責任者、チーム）、採用の目標人数の決定、入社後の役割を文面と面談に合わせることの判断。

**外注の効きどころ。** 歩留まりは、「七段を数え、理由を記録し、落ちている段を直す」運用で、社内では「返信率で終わる」か「送信を増やす」になりやすい工程です。担当者が表を設計し、送信から面談までを記録し、面談以降の記録を集約し、段ごとの率と理由を出し、直す箇所を提案すれば、歩留まりは一段ずつ上がります。担当者は複数の会社の歩留まりを見ているので、「この役割はこの段で落ちる」「この接点で内定の辞退が減る」を持ち込めます。ただし、面談以降の記録と改善の実施は、社内でしか行えません。

**外注しても動かない場合。** 面談以降を社内が数えない、辞退の理由を聞かない、選考の設計を変えない、内定後の接点を責任者が持たない、「送信を増やせば入社も増える」と考える。社内の判断で、代行を替えても直りません。

スカウト経由の歩留まりは、七段を数・日数・理由で並べ、特有の落ち方を段ごとに直せば、送信を増やさずに入社が増えます。外注は、表の設計と集計と送信から応募までの改善と選考以降の提案を担う手段です。

### エラベルの見解

担当する側から見ると、歩留まりの相談で最も多いのは、「内定の後を数えていない」ことです。内定を出した時点で「採用できた」と扱い、承諾、入社、定着を追っていない。スカウト経由の候補者は、内定の後に他社と比べ、現職に引き止められ、入社後に「思っていたのと違う」と辞めることが、公募より起きやすい。内定の数だけ見ていると、入社と定着で落ちていることに気づきません。

内定の提示と承諾を分けて数え、入社と一定期間の定着まで追う。それだけで、内定後の接点と入社後の受け入れが、歩留まりの一部として見えます。

発注側にできるのは、内定の後の三段（承諾、入社、定着）を、人事が数えて、スカウトの担当者と共有することです。担当者は、文面と面談で伝える役割を、定着の結果から直せます。

## まとめ

- 見えないのは**返信率まで・経路を分けない・理由が無い・日数を見ない・内定の後を見ない・目標が送信数・特性を知らない**構造
- 段は**送信・返信・面談・応募・選考・内定・入社**の七つ。返信までがスカウト、残りは社内の工程
- 特有の落ち方は**面談の後の「考えます」・選考中の辞退・内定後の他社との比較・入社前の引き止め・入社後のずれ**。動機が固まる前に接点が始まる
- 直し方は**面談で材料と翌日の入り口・要件のずれなら対象、辞退なら選考の日数と接点・条件を幅で早く、内定後の接点・入社前の接点・文面と面談を実際に合わせる**
- 表は**月・役割・経路・段ごとの数と率と日数・落ちた理由の内訳・前月との比較**。理由の内訳が要
- 逆算は**目標→率で割り戻す→出せる数か→出せないなら率を上げる→月次で更新**。送信を増やす前に率を上げる
- 外注できるのは**表の設計・送信から面談の記録・面談以降の集約・集計・理由の区分・特定と提案・送信から応募の改善・選考以降の提案・逆算・報告**。社内に残るのは**面談以降の記録・理由の記録・選考の設計・条件・内定後と入社前の接点・目標・役割を合わせる判断**

## よくある質問

### スカウト経由の歩留まりの目安はありますか

役割、層、媒体、面談の設計、選考の設計で大きく変わるので、外の目安は当てはまりません。自社の役割ごとの直近の数字が目安です。最初の三か月は、目安を持たずに七段を数え、三か月分の率を「自社の基準」にします。そこから、段ごとに前月と比べます。一般の数字と比べて一喜一憂するより、自社の段ごとの率が動いたかを見ます。

### 面談以降の記録を、誰が書けばよいですか

面談の当日に面談した人（責任者など）が段階を一つ動かし、応募と選考は人事、内定と入社は人事、辞退の理由は候補者と最後に接した人。名前で決めます。書く量は、一人につき一行です。「人事が書く」ではなく「〇〇さんが、その日に」まで決めないと、書かれません。記録の表は候補者CRMで、[候補者CRMの作り方](/media/scout-crm/)に書いています。

### 内定を出しても、他社に決まってしまいます

内定後の接点が無いか、条件の出し方が遅いか、選考中に候補者の動機を作れていないかのどれかです。内定の辞退の理由を、候補者と最後に接した人が聞き、記録します。「他社」が多いなら、内定後に一緒に働く人との接点と、迷いを聞く場と、期限の相談を入れます。「条件」が多いなら、面談の段階で幅を出します。理由が無いと直せないので、理由を聞く型を先に作ります。[内定辞退が続くときに見直す三点](/media/rpo-jitai-ooi/)と[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に書いています。
