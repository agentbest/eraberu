企業の採用担当として、求人票を書き、媒体に出し、スカウトを送り、応募者に連絡し、日程を組み、面接に同席し、内定を出し、入社の準備をしてきた。この経験は、副業で売れるのか。採用担当の仕事は幅が広く、「何でもやってきた」ことが、かえって何を売ればよいか分からない原因になります。結論を先に書くと、**採用担当の経験は、「募集から入社までの全工程を、自分の手で、同時に、回してきた」型で売れます。売れるのは、「工程ごとの実務そのもの」「工程の間の詰まりを見つける目」「現場と候補者の両方への連絡の型」「一人で回すための段取り」の四つです。人事の部門が小さい会社の副業案件は、その多くが「工程の一部を、すぐに、手を動かして回してほしい」というもので、採用担当の経験はその依頼に最も近いところにあります。「採用をやっていました」ではなく、「工程のどこを頼まれても、翌週から回せる」と売ります。**スカウトを軸にした社内リクルーターの売り方は[社内リクルーターが副業でできること](/media/fukugyo-shanai-recruiter-fukugyo/)に、新卒採用の経験は[新卒採用担当が副業でできること](/media/fukugyo-shinsotsu-tantou-fukugyo/)に、採用マネージャーの経験は[採用マネージャーが副業でできること](/media/fukugyo-saiyo-manager-fukugyo/)にまとめています。

## この経歴の何が売れるか

採用担当の経験を、副業の案件の形に置き換えた棚卸しです。在籍した会社の採用の内情は含めず、「型」として抜き出します。

| 採用担当の経験 | 副業の案件への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 求人票を書き、媒体に出してきた | 求人原稿の作成と媒体の運用 | 求人票を書く時間がなく、古い原稿を出し続けている依頼側が多い |
| スカウトを送り、返信を追ってきた | スカウトの文面と送信と追客の運用 | スカウトを送る時間がない依頼側が多い |
| 応募者に連絡し、日程を組んできた | 応募者への連絡と日程調整の代行 | 連絡が遅れて候補者が離れる依頼側が多い |
| 面接に同席し、一次の面接を担ってきた | 一次の面接の代行、面接の記録 | 面接に出る人がいない依頼側が多い |
| 内定から入社までの準備をしてきた | 内定の後の連絡と入社の準備の運用 | 内定の後の対応が遅れて辞退される依頼側が多い |
| 全工程を一人で同時に回してきた | 工程の間で何が詰まるか（求人票が古くて応募が来ない、連絡が遅くて辞退される）を見つけ、先に手を打つ | 詰まりの場所が分からず、媒体を変え続ける依頼側が多い |
| 現場の管理職と候補者の両方に連絡してきた | 現場には「この候補者をいつまでに見てほしい」、候補者には「次はこう進む」と、両方が動く連絡の型 | 現場と候補者の間で連絡が止まる依頼側が多い |
| 一人で複数の募集を段取りしてきた | 週の中で、どの工程を、どの順番で、どれだけの時間で回すかの段取り | 担当者が一人で、段取りがなくて溺れている依頼側が多い |

売れるものの要点は、「工程の実務を、頼まれた翌週から回せる」ことです。人事の副業の案件で最も多いのは、「担当者が足りない」「この工程だけ誰かにやってほしい」という依頼で、そこで求められるのは設計や助言ではなく、手を動かして回す力です。採用担当の経験は、その依頼にそのまま応えられます。そのうえで、全工程を一人で回してきた人は、頼まれた工程の前後で何が詰まっているかが見え、「連絡の代行を頼まれたが、求人票が古くて応募が来ていない」と気づけます。この目が、実務だけの担当者との差になります。求人原稿の案件は[求人原稿のライティングの副業案件](/media/fukugyo-kyujin-raiting-fukugyo/)に、スカウトの案件は[スカウト代行の副業案件](/media/fukugyo-scout-daikou-fukugyo/)に、面接の案件は[面接代行の副業案件](/media/fukugyo-mensetsu-daikou-fukugyo/)に書いています。

## 売りにくい点とその扱い

採用担当の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 「何でもできる」は何も伝わらない | 「採用を全部やっていました」と言われても、依頼側は何を頼めばよいか分からない。自分でも得意な工程を一つに絞れない | 工程を並べ、「翌週から回せる工程」と「得意な工程」を分けて示す。最初の案件は得意な工程一つで入り、全工程が見えることは後から効かせる |
| 自社の看板の有無 | 本業では会社の名前で候補者が返信していた。副業では依頼側の名前で、知らない会社の名前で動く | 「知らない会社の名前で候補者を動かす」技術は、本業の経験に無いことを認め、文面と連絡の型を依頼側の会社に合わせて作り直す前提で入る |
| 本業との重なり | 本業でも採用をしていて、同じ職種・同じ媒体で依頼側の採用をすると、候補者と情報が重なる | 本業と同じ職種・同じ業界の案件は避けるか、本業の会社の許可と守秘の線を確認する。個別の判断は専門家に |

扱い方の要点は、「全工程を並べたうえで、最初は一つの工程で入る」ことです。採用担当の経験がある人は、「全部できます」と言いたくなりますが、依頼側は「全部」を頼む予算も範囲も持っていないことが多く、「この工程だけ」を探しています。工程を一覧にして、翌週から回せるものに印を付け、得意な一つで入ります。入った後、前後の工程の詰まりが見えたら、「ここも詰まっています」と伝え、範囲が広がります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、本業との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、採用担当から転身して続いている人と、最初の案件で終わる人の差は、頼まれた工程の外に目を向けるかどうかです。終わる人は、頼まれた工程を丁寧に回し、成果が出ないと「頼まれたことはやりました」で止まります。連絡の代行を頼まれ、連絡は早くなったが、求人票が古くて応募が来ないので、成果が出ないまま契約が終わります。続いている人は、同じ状況で「連絡は早くなりましたが、応募が少ないのは求人票が古いからだと思います。次の週に原稿を一本書き直してみてもよいですか」と伝え、依頼側は「そこまで見てくれるのか」と感じて契約を広げます。

見ていて差がつくのは、依頼側の会社の名前で候補者を動かす文面を、本業の型のまま使っていないかです。採用担当の経験がある人は、本業の会社の名前があるから返信が来ていた文面を、そのまま依頼側で使いがちで、知らない会社の名前では返信が来ません。依頼側の会社の名前を知らない候補者が、それでも読む理由（その人の経歴のどこを見たか、この会社の何がその人に合うか）を文面の最初に置き直した人は、返信が戻り、依頼側から「うちの名前でも返ってくるようになった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「工程のどこを頼まれても翌週から回せる」と工程の一覧で書いている担当者に、担当者が足りない依頼側がついています。採用担当の転身は、経験の幅ではなく、頼まれた工程の外を見る目から始まります。

## 案件の探し方

採用担当から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| スカウトの文面と送信の運用 | 本業で回してきた工程でそのまま入れる | 「スカウトを送る時間がない依頼側」を探す |
| 応募者への連絡と日程調整 | 本業で回してきた工程で入れる。稼働が読みやすい | 「連絡が遅れている依頼側」を探す |
| 求人原稿の作成と媒体の運用 | 求人票を書いてきた経験で入れる。成果物で受けやすい | 「求人票が古い依頼側」を探す |
| 一次の面接の代行と記録 | 面接に同席してきた経験で入れる | 「面接に出る人がいない依頼側」を探す |
| 内定の後の連絡と入社の準備 | 入社の準備をしてきた経験で入れる | 「内定の後で辞退される依頼側」を探す |
| 一人の担当者の段取りの手伝い | 一人で回してきた経験で入れる | 「担当者が一人で溺れている依頼側」を探す |

探し方の要点は、「稼働が読みやすい工程から入る」ことです。連絡と日程調整、スカウトの送信は、一回あたりの時間が読みやすく、本業と並行しても稼働が崩れにくいので、最初の案件に向いています。面接の代行は、時間が固定されるので本業との調整が要ります。求人原稿は成果物で受けられます。最初の案件で稼働と単価の感覚をつかんでから、工程を広げます。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、週の稼働の目安は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。採用担当の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 工程の実務の単価 | 実務の工程は、依頼側が「作業」として見るので、時間単価は設計や助言より下がりやすい | 時間で受けるなら、工程の前後の詰まりを見つける目を単価の根拠に加える |
| 稼働の読みやすさ | 連絡と送信は時間が読みやすく、月額で受けやすい | 月に何時間で決める |
| 成果物の工程 | 求人原稿は成果物で受けやすい | 一本いくらの形で |
| 面接の代行 | 一回あたりの時間が固定で、回数で受けやすい | 一回いくらの形で |
| 全工程が見えること | 工程の一つを受けながら前後の詰まりを見つけられる人は、実務だけの人より単価を上げやすい | 「詰まりを見つけて提案した」を報告で残す |
| 複数の依頼側の掛け持ち | 実務の工程は稼働が読みやすく、複数の案件を持ちやすい | 案件ごとの情報を分けて管理する |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「実務の工程は時間か回数か成果物で受け、全工程が見えることを単価の根拠に加える」ことです。採用担当の経験で受ける案件は、実務の工程が中心なので、時間単価は設計や助言の案件より下がる傾向があります。ただ、実務だけの担当者と違い、工程の前後の詰まりを見つけられることが、単価を上げる根拠になります。「連絡を代行しながら、求人票の古さに気づいて提案した」ことを報告で残すと、更新のときに単価の話がしやすくなります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に、掛け持ちの考え方は[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/)に整理しています。

## 始める順番

採用担当から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、候補者の情報と採用の内情の守秘の条件を確認する | 本業と同じ職種・業界の案件の可否も。個別の判断は専門家に |
| 二、募集から入社までの工程を一覧にし、「翌週から回せる工程」「得意な工程」「本業では触っていない工程」に分ける | 「全部できます」と言わないための準備 |
| 三、本業の会社の名前があったから通じていたこと（返信率、応募の質）を、正直に書き出す | 依頼側の名前で動くときに作り直す前提 |
| 四、最初に入る工程を一つ決める | 稼働が読みやすい連絡・送信・原稿のどれか |
| 五、「工程のどこを頼まれても、翌週から回せる」の一言を作る | 「採用をやっていました」で終わらせない |
| 六、候補者の情報と本業の情報を、副業に持ち込まない線を決める | 型だけ持ち込む |
| 七、登録先に、工程の一覧と、最初に受ける工程と、稼働の時間を登録する | 担当者が足りない依頼側 |
| 八、一つの工程を一件受け、前後の詰まりを見つけて提案した記録を残す | 範囲を広げる材料に |

順番の要点は、「二」の工程の一覧です。採用担当の経験は幅が広く、その幅を「全部できます」と言うと何も伝わりません。工程を一覧にして、翌週から回せるものと、得意なものと、本業では触っていないもの（たとえば新卒の説明会、紹介会社との交渉、採用の予算）を分けておくと、面談で「これはできる、これは経験が薄い」と正直に答えられ、依頼側の信頼が上がります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「採用担当の経験は普通すぎて、副業では差がつかない」というものです。実際には、人事の副業の案件で最も多いのは「工程の一部を、すぐに、手を動かして回してほしい」という依頼で、その依頼に翌週から応えられる人は多くありません。設計や助言ができる人は、手を動かす工程を受けたがらず、手を動かせる人は、工程の前後の詰まりに気づけません。全工程を一人で回してきた採用担当は、その両方を持っていて、差は「普通の経験」の中にあります。

順番として、本業の規定と守秘の条件を専門家に確認し、工程を一覧にして分け、会社の名前があったから通じていたことを書き出し、最初に入る工程を一つ決め、翌週から回せる一言を作り、情報を持ち込まない線を決め、登録先に一覧と工程と時間を登録し、一件受けて前後の詰まりを見つけた記録を残す。この順番で、採用担当の経験は「普通すぎるもの」から「翌週から回せて、詰まりも見える形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、工程の一覧を明確にし、最初に受ける工程と稼働の時間を示している担当者に、担当者が足りない依頼側がついています。採用担当の転身は、経験の幅を語ることではなく、工程を一つに絞って入るところから始まります。

## まとめ

- 採用担当の経験は**「募集から入社までの全工程を、自分の手で、同時に、回してきた」型**で売れる。**工程ごとの実務・詰まりを見つける目・両方への連絡の型・一人で回す段取り**の四つ
- **「採用をやっていました」ではなく「工程のどこを頼まれても、翌週から回せる」**と売る
- 売りにくい点は**「何でもできる」は何も伝わらない・自社の看板の有無・本業との重なり**。工程を一覧にして一つで入り、文面は依頼側の名前で作り直し、本業と同じ職種・業界は線を引く
- 案件は**稼働が読みやすい工程（連絡・送信・原稿）**から。面接の代行は本業との時間の調整が要る
- 単価は**時間か回数か成果物**で。全工程が見えることを根拠に加える。成果報酬は最初は避け、可否は専門家に確認
- 頼まれた工程の**外を見る目**が、実務だけの担当者との差になる

## よくある質問

### 本業でも採用をしています。同じ職種の採用を副業で受けてよいですか

本業の会社と依頼側が同じ職種を同じ媒体で採用している場合、候補者と情報が重なり、本業の会社との守秘と利益相反の線に関わります。本業の会社の副業の規定と、候補者の情報の扱いの条件を確認し、同じ職種・同じ業界の案件は避けるか、本業の会社の許可を得る形にします。個別の判断は、弁護士や社会保険労務士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に整理しています。

### 本業の会社ではスカウトの返信がよく来ていたのに、副業の依頼側では来ません

本業の会社の名前があったから返信が来ていた、ということが多いです。依頼側の会社の名前を知らない候補者が、それでも読む理由を、文面の最初に置き直します。「あなたの経歴のここを見ました」「この会社のこの点が、あなたの次に合うと思いました」を先に書き、会社の説明は後に回します。本業の型をそのまま使わず、依頼側の会社に合わせて作り直す前提で入ると、落差に驚かずに済みます。文面の型は[スカウト代行の副業案件](/media/fukugyo-scout-daikou-fukugyo/)に、評価される担当者の共通点は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に書いています。

### 「全部お願いしたい」と言われました。全工程の経験があるので受けてよいですか

受ける前に、稼働の時間を計算します。全工程を一人で回すのは、本業で週の大半を使っていた仕事で、副業の稼働では収まりません。「まず連絡と送信を私が、求人票と面接は御社の担当者が。それで回らなければ、次の月に範囲を相談しましょう」と、工程を分けて段階的に広げる形で示します。全部を受けて回らなくなると、依頼側の信頼も自分の本業も崩れます。範囲外の依頼への対応は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に、時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に整理しています。
