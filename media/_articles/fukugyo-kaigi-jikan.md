依頼側から「来週、打ち合わせできますか」と言われるたびに、本業の予定と照らして、昼休みか、有給か、夜遅くかを考える。毎回の調整が負担で、結局、本業の時間に抜けることもある。副業の打ち合わせの時間帯は、どう決めればよいのか。結論を先に書くと、**副業の打ち合わせの時間帯は、「依頼側の都合に合わせる」のではなく、「自分が固定で出られる時間帯を二つ示し、その中で依頼側に選んでもらう」形で決めます。都度合わせると、本業の昼休みや有給や夜遅くが打ち合わせで消え、毎回の調整が負担になります。「火曜と木曜の夜八時から九時」「土曜の朝九時から十時」のように固定の候補を示せば、依頼側はその前提で予定を組み、調整の負担が消えます。時間帯は、契約の前に示し、契約に入れます。**稼働の時間帯は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、定例の進め方は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に、平日日中の連絡は[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)にまとめています。

## 都度合わせると崩れる理由

打ち合わせを依頼側の都合に都度合わせると、どこが崩れるかです。

| 都度合わせると | 何が起きるか |
|---|---|
| 依頼側は日中を提案する | 本業の昼休みに抜ける、有給を使う、本業中に離席する、のどれかになる |
| 毎回、本業の予定と照らす | 調整の負担が毎回かかる。返事が遅れ、依頼側が待つ |
| 「今回だけ」が積み重なる | 依頼側が「日中も出られる人」と認識し、日中の提案が標準になる |
| 夜遅くに合わせる | 睡眠が削れ、本業に響く |
| 打ち合わせの時間が読めない | 副業の枠が打ち合わせで埋まり、作業の時間が残らない |
| 家族の予定と重なる | 家族に「またか」と見られる |

理由の要点は、「依頼側は、担当者の時間帯を知らなければ、社員と同じ日中を提案する」ことです。依頼側に悪気はなく、担当者が日中に出られないことを知らないだけです。固定の時間帯を先に示せば、依頼側はその中で選び、日中の提案はなくなります。示さなければ、毎回、日中の提案から始まり、毎回、調整が要ります。本業への影響は[本業のパフォーマンスへの影響](/media/fukugyo-honngyou-eikyou/)に、有給の扱いは[有給を使って対応してよいか](/media/fukugyo-yuukyuu/)に書いています。

## 固定の候補を二つ示す方法

打ち合わせの時間帯は、固定の候補を二つ示します。一つでは依頼側が選べず、三つ以上では自分の枠が減ります。

| 示し方 | 内容 | 例 |
|---|---|---|
| 平日の夜を一つ | 本業の後、夕食の後など、毎週同じ曜日と時刻 | 「火曜の夜八時から九時」 |
| 週末の朝か、平日の早朝を一つ | 家族の予定が入る前の時間帯 | 「土曜の朝九時から十時」または「木曜の朝七時から八時」 |
| 長さを決める | 三十分か一時間。長い打ち合わせは要らない | 「三十分で。延びる場合は次回に」 |
| 頻度を決める | 週に一度か、二週に一度 | 「定例は隔週の火曜」 |
| 候補の外は原則なしと伝える | 「この二つ以外は、原則として出られません。緊急の場合はご相談ください」 | 契約の前に |
| 契約に入れる | 打ち合わせの時間帯と頻度を、契約の条件として書く | 「定例：隔週火曜二十時から三十分」 |

示し方の要点は、「契約の前に示し、契約に入れる」ことです。契約の後に「実は日中は出られません」と言うと、依頼側は「聞いていない」となります。契約の前に、「打ち合わせはこの二つの時間帯で」と示し、その条件で受けてもらえる依頼側と契約します。契約に入れておけば、後から日中を提案されても、「契約の時間帯で」と戻せます。契約の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、時間帯の固定は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に整理しています。

### エラベルの見解

担当する側から見ると、打ち合わせの時間帯で消耗する担当者は、「依頼側に合わせるのが礼儀」と思っている人です。依頼側の提案に毎回合わせ、昼休みに抜け、有給を使い、夜遅くに出て、本業と睡眠と家族の時間が削れ、続かなくなっています。依頼側は、担当者が無理をしていることに気づいていません。固定の時間帯を示すことは、失礼ではなく、依頼側が予定を組みやすくすることです。

見ていて差がつくのは、固定の時間帯を、「出られる時間」ではなく「出る時間」として示しているかです。「夜なら出られます」と幅で示すと、依頼側は夜のどこかで毎回提案し、調整が残ります。「火曜の夜八時から九時」と点で示すと、依頼側はその点に合わせ、調整が消えます。点で示している担当者は、打ち合わせの時刻が毎回同じで、依頼側の担当者もその時刻を空けておく習慣になり、定例として定着しています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、打ち合わせの時間帯を登録の時点で示している担当者には、その時間帯で回る依頼側がついています。時間帯は、幅ではなく点で示すものです。

## 時間帯ごとの向き不向き

打ち合わせの時間帯には、それぞれ向き不向きがあります。自分と依頼側の両方で見ます。

| 時間帯 | 自分にとって | 依頼側にとって | 向く依頼側 |
|---|---|---|---|
| 平日の早朝（七時から八時） | 本業の前で頭が冴えている。家族の予定の前 | 始業前で、出勤前の担当者には負担。在宅の担当者には出やすい | 在宅勤務が多い依頼側、早朝に動く経営者 |
| 平日の昼（十二時から十三時） | 本業の昼休み。本業の端末や場所を使わない工夫が要る。本業の規則を確認 | 依頼側も昼休みで、出やすい | 近場で、短い確認だけの依頼側 |
| 平日の夜（十九時から二十一時） | 本業の後。疲れているが、最も確保しやすい | 依頼側の担当者は退勤後。残業扱いになることがある | 夜も動く依頼側、経営者が直接担当する依頼側 |
| 平日の夜遅く（二十一時以降） | 睡眠が削れる | 依頼側の担当者に負担 | 避ける |
| 週末の朝（九時から十時） | 家族の予定の前。頭が冴えている | 依頼側の担当者は休日。休日出勤扱いになることがある | 経営者が直接担当する依頼側、週末も動く依頼側 |
| 週末の日中 | 家族の予定と重なる | 依頼側の担当者は休日 | 避ける |

向き不向きの要点は、「依頼側の担当者にとっての負担」も見ることです。自分が出やすい時間帯でも、依頼側の担当者が退勤後や休日なら、その担当者に負担がかかり、打ち合わせが続きません。平日の夜か早朝で、依頼側の担当者も出やすい時刻を、二つの候補から依頼側に選んでもらいます。経営者が直接担当する依頼側は時間帯の自由度が高く、人事の担当者がいる依頼側は就業時間の中が出やすい、という傾向があります。早朝の稼働は[早朝の稼働という選択](/media/fukugyo-hayaasa/)に、週末は[週末だけの稼働は可能か](/media/fukugyo-shuumatsu/)に書いています。

## 打ち合わせの種類ごとの頻度と長さ

打ち合わせは、種類によって頻度と長さが違います。全部を同じ枠で受けると、枠が足りなくなります。

| 種類 | 頻度 | 長さ | 時間帯 |
|---|---|---|---|
| 定例の確認 | 週に一度か隔週 | 三十分 | 固定の候補の一つ |
| 判断を仰ぐ相談 | 必要なとき。定例にまとめるのが基本 | 十五分 | 定例の中で。急ぎは文面で |
| 月次の振り返り | 月に一度 | 一時間 | 固定の候補の一つを、その月だけ長く |
| 契約の更新の相談 | 更新の一か月前 | 一時間 | 固定の候補の一つ |
| 面接官との打ち合わせ | 面接の前 | 三十分 | 面接官の都合に合わせる必要があるが、候補は自分が示す |
| 初回の顔合わせ | 契約の前に一度 | 一時間 | 固定の候補の一つ。対面なら別途調整 |
| 問題が起きたとき | 発生時 | 三十分 | 固定の候補の直近。緊急なら例外 |

種類の要点は、「判断を仰ぐ相談を、定例にまとめる」ことです。判断が要るたびに打ち合わせを組むと、枠が打ち合わせで埋まります。判断が要ることは、文面で先に送り、定例で確認する形にすれば、打ち合わせの回数が減ります。文面で済むことは文面で、打ち合わせは定例だけ。この形が、副業の枠を守ります。定例の進め方は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に、質問の仕方は[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/)に、報告の頻度は[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/)に整理しています。

## 打ち合わせを減らす代替手段

打ち合わせは、減らせるものが多いです。代替手段です。

| 打ち合わせの代わりに | 内容 | 向く場面 |
|---|---|---|
| 書面の報告 | 週に一度、状態と判断が要ることを文面で送る | 定例の一部を置き換える |
| 判断の文面 | 「AかBか、期限は〇日」と文面で聞く | 判断を仰ぐ相談 |
| 録画や音声の共有 | 説明が要ることを、録画や音声で送り、依頼側が都合のよいときに見る | 資料の説明、提案の説明 |
| 共有の文書 | 進捗と判断待ちの項目を、共有の文書で常に見える形に | 進捗の確認 |
| 短い確認の文面 | 「確認です。〇〇でよいですか」と一問だけ | 小さな確認 |
| 月次の振り返りの資料 | 資料を先に送り、打ち合わせは質問だけに | 月次の振り返り |

代替手段の要点は、「打ち合わせは、文面で済まないことだけに使う」ことです。報告、判断、説明、確認は、文面や録画で済みます。文面で済まないのは、依頼側の考えを聞き出すこと、関係を作ること、複数の人の合意を取ることです。それだけを打ち合わせにし、他は文面にすれば、打ち合わせは週に一度、三十分で足ります。文面の書き方は[連絡手段の分け方](/media/fukugyo-mail/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に書いています。

## 時間帯が合わない依頼側の扱い

固定の候補を示しても、依頼側の時間帯と合わないことがあります。扱いです。

| 状況 | 扱い |
|---|---|
| 依頼側が日中しか出られない | 打ち合わせを文面と録画に置き換え、対面は月に一度だけ。それでも合わなければ、その依頼側は自分の枠に合わない |
| 依頼側の担当者が夜と週末を避けたい | 早朝の候補を出す。それでも合わなければ、文面中心の形を提案する |
| 経営者が担当で、夜遅くを提案してくる | 「二十一時以降は出られません」と線を引き、夜八時か早朝を提案する |
| 依頼側が毎回違う時刻を提案してくる | 契約の時間帯に戻す。「契約の火曜二十時でお願いします」 |
| 緊急の打ち合わせを頻繁に求められる | 緊急の定義を決める。緊急でないものは定例に |
| 時間帯が合わないまま契約した | 更新の節目で、時間帯を契約に入れ直す。合わなければ更新しない |

扱いの要点は、「時間帯が合わない依頼側は、自分の枠に合わない依頼側」と割り切ることです。範囲が合っていても、打ち合わせの時間帯が合わなければ、毎回の調整で本業か睡眠か家族の時間が削れ、続きません。文面と録画で置き換えても合わなければ、その依頼側は受けず、時間帯が合う依頼側を選びます。登録先なら、時間帯を登録の時点で示せるので、合わない依頼側とは最初からつながりません。案件の選び方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、更新時の直し方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に整理しています。

## 決める順番

打ち合わせの時間帯を決める順番です。

| 順番 | 内容 |
|---|---|
| 一、自分が固定で出られる時間帯を、平日の夜か早朝で一つ、週末の朝か平日の早朝で一つ選ぶ | 家族と共有し、その時間帯は空けておく |
| 二、長さと頻度を決める | 三十分、週に一度か隔週 |
| 三、契約の前に、二つの候補と長さと頻度を示す | 「打ち合わせはこの二つの時間帯で、三十分、隔週で」 |
| 四、依頼側に選んでもらう | 二つのうち、依頼側の担当者が出やすい方 |
| 五、契約に入れる | 曜日、時刻、長さ、頻度 |
| 六、文面で済むことは文面にする | 報告、判断、説明、確認 |
| 七、緊急の定義を決める | 緊急以外は定例に |
| 八、毎回違う時刻を提案されたら、契約の時間帯に戻す | 「契約の時間帯でお願いします」 |

順番の要点は、「一」で、家族と共有してから依頼側に示すことです。家族と共有せずに依頼側に示すと、家族の予定と重なり、家族との関係が崩れます。家族と決めた時間帯を、依頼側に示す。この順番が、両立を保ちます。家族との共有は[家族の理解を得る](/media/fukugyo-kazoku/)に、時間帯の固定は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「打ち合わせの時間帯は、依頼側に合わせるものだ」というものです。実際には、依頼側は担当者の時間帯を知らないので、示されなければ社員と同じ日中を提案するだけで、示されればその中で選びます。合わせるのではなく、示す。示した時間帯で受けられる依頼側と契約する。これが、副業の打ち合わせの時間帯の決め方です。

順番として、固定で出られる時間帯を二つ選び、家族と共有し、長さと頻度を決め、契約の前に示し、依頼側に選んでもらい、契約に入れ、文面で済むことは文面にし、緊急の定義を決め、毎回違う時刻を提案されたら契約の時間帯に戻す。この順番で、打ち合わせは「毎回調整するもの」から「決まった時刻に行うもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、打ち合わせの時間帯を明確にしている担当者には、その時間帯で回る依頼側がついています。時間帯は、合わせるものではなく、示すものです。

## まとめ

- 打ち合わせの時間帯は**依頼側に合わせるのではなく、固定の候補を二つ示して依頼側に選んでもらう**
- 候補は**幅ではなく点で**（「夜なら」ではなく「火曜の夜八時から九時」）。契約の前に示し、契約に入れる
- 時間帯は**依頼側の担当者の負担も見る**。平日の夜か早朝で、依頼側も出やすい時刻を
- **判断を仰ぐ相談は定例にまとめ、文面で済むことは文面に**。打ち合わせは週に一度三十分で足りる
- 時間帯が合わない依頼側は**自分の枠に合わない依頼側**。文面と録画で置き換え、それでも合わなければ受けない
- 時間帯は**家族と共有してから**依頼側に示す

## よくある質問

### 固定の時間帯を示すと、「融通が利かない人」と思われませんか

逆です。固定の時間帯を示す担当者は、依頼側にとって予定が組みやすく、「この曜日のこの時刻は空けておく」という習慣になります。融通が利かないと思われるのは、時間帯を示さずに毎回の提案を断る場合です。「この二つの時間帯なら出られます。緊急の場合はご相談ください」と、候補と例外を添えて示せば、依頼側は融通が利かないとは感じません。示し方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に整理しています。

### 依頼側の面接官との打ち合わせは、面接官の都合に合わせるしかありません

面接官の都合は依頼側の中のことなので、担当者を通して、自分の候補の時間帯を面接官に伝えてもらいます。面接官が日中しか出られないなら、面接官向けの準備資料を文面で送り、質問を文面で受ける形にし、打ち合わせは要るときだけにします。面接官との打ち合わせが毎回日中になるなら、その工程は自分の枠に合わない工程で、範囲から外すか、依頼側の担当者が面接官との調整を担う形にします。面接官との関係は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に書いています。

### 契約の後に、依頼側の担当者が変わり、日中を提案されるようになりました

契約に時間帯が入っていれば、「契約の時間帯でお願いします」と戻します。入っていなければ、担当者が変わったタイミングで、「打ち合わせはこの二つの時間帯でお願いしています」と改めて示し、次の更新で契約に入れます。担当者の交代は、条件を改めて示す機会です。示さずに新しい担当者に合わせ始めると、日中の提案が標準になります。更新時の条件の入れ方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に整理しています。
