財務にスカウトを送っても返信が来ない会社の文面には、共通点があります。「財務経理担当を募集しています」「経営に近いポジションです」「会社の成長を数字で支えてください」と書かれていて、財務なのか経理なのか、自社がどの状況（資金繰り・調達・上場準備・予算管理）なのか、経営者が財務の判断をどこまで委ねるのかが無い。財務の経験者はこれを読んで、「実態は経理」「経営者が全部決める会社」と判断し、閉じます。結論を先に書くと、**財務へのスカウトは、状況と転向元で対象を絞り、一行目で候補者が担った状況の一点に触れ、自社が財務であって経理ではないこと・状況の種類・経営者が委ねる範囲・経理との分担を先に書き、機微な情報は書かず、会社の紹介は後ろに回す**型にすると、返信が変わります。母集団形成の全体は[財務の母集団形成](/media/rpo-zaimu-boshuudan/)に、経理向けの文面は[経理向けスカウト文面の型](/media/rpo-keiri-scout/)にまとめています。

## 財務がスカウトを読まない理由

他の職種と共通する理由（定型文は読まれない）に加えて、財務に特有の理由があります。

一つ目は、「財務」の名前の経理の募集を見慣れていることです。財務の経験者には、「財務経理」「財務担当」と書かれた経理の募集のスカウトが多く届きます。一行目で「本当に財務か」を疑い、経理の言葉（決算、記帳、月次）が並ぶと閉じます。

二つ目は、経営者が委ねる範囲を最初に確かめることです。財務は経営者との距離が最も近く、「経営者が財務の判断を全部持ち、財務は資料を作るだけ」の会社を、経験者は最も避けます。委ねる範囲が書かれていないと、「委ねないのだろう」と読まれます。

三つ目は、状況が分からないと判断できないことです。資金繰りの管理か、調達か、上場準備か、予算管理か。自分の経験と自社の状況が合うかが分からない文面は、読まれません。

四つ目は、「経営に近い」「成長を支える」といった言葉に、実態の無さを感じることです。財務向けのスカウトは、この種の言葉で埋まっていることが多く、経験者は読み飛ばします。

この四つから、文面の型が決まります。財務であって経理ではないと示す、委ねる範囲を書く、状況を示す、形容詞を使わない。

## 先に決めるのは対象：状況と転向元で絞る

文面の前に、誰に送るかを決めます。財務では、「自社の状況」と「それに合う転向元」の決定が、対象の絞り込みです。

状況で絞ります。資金繰りと銀行対応なら「資金繰りの管理」「銀行との折衝」の経験、調達なら「増資」「投資家との対応」の経験、上場準備なら「上場準備」「内部統制の構築」の経験、予算管理なら「予算の策定」「事業計画の数字」の経験。「財務」の肩書だけで検索すると、状況が混ざり、経理の人も混ざります。

転向元で分けます。銀行出身、監査法人出身、投資の会社出身、コンサルティング出身、事業会社の財務。それぞれ持っているものが違い、一行目で触れる一点と訴求が変わります。

| 転向元 | 一行目で触れる一点 | 訴求 |
|---|---|---|
| 銀行 | 担当した企業への融資や資金繰りの支援 | 事業会社の側で資金を動かせること。銀行の考え方を活かせること |
| 監査法人・会計事務所 | 監査や上場準備の支援の経験 | 支援する側から、作る側に回れること |
| 投資の会社・証券 | 投資先の財務や調達の支援 | 一つの会社の調達を最初から最後まで担えること |
| コンサルティング | 事業計画や予算の設計 | 計画を作るだけでなく、実行と結果まで見られること |
| 事業会社の財務 | 担った状況の種類 | 自社の状況との近さ。委ねる範囲の広さ |

対象の要点は、「転向元によって、訴求が変わる」ことです。銀行出身の人には「事業会社の側で」、監査法人出身の人には「支援から作る側へ」、と持っているものと動機に合わせて書きます。[スカウトの対象の絞り方](/media/scout-persona-sakusei/)も参考になります。

### エラベルの見解

相談で多いのは、「財務の経験者に数十通送ったが、返信がゼロ」というご相談です。文面を見ると、一行目が「財務経理担当を募集しております」、業務内容が「決算、資金繰り、銀行対応、経営への報告」、経営者が委ねる範囲は無し。財務の経験者から見ると、「財務経理」の時点で経理の募集に読め、「決算」が並ぶことで確信し、委ねる範囲が無いことで「資料を作るだけの会社」と判断します。読まれない理由がそろっています。

見ていて差がつくのは、「一行目で候補者の状況に触れ、二行目で『財務であって経理ではない』ことと委ねる範囲を言えるか」です。「〇〇の状況で、銀行との対応と資金繰りの管理を担われてきたご経歴を拝見しました。当社では、経理は別の担当がいて、財務として資金繰りの管理と銀行との対応を主体で担い、経営者は最終の判断をする形を考えています」。この二行で、経験者は「本当に財務」「委ねる会社」と判断します。エラベルでは、財務の担当者に、文面の中心を「財務であって経理ではないこと」と「委ねる範囲」にするよう最初にお願いしています。

## 文面の型：一行目は候補者の状況、二行目は財務であることと委ねる範囲

| 順 | 中身 | 書き方 |
|---|---|---|
| 一 候補者の経歴の一点 | 担った状況の種類、銀行や投資家との対応の経験、作った計画や整えた体制のどれか一つ | 「〇〇の状況で、銀行との対応と資金繰りの管理を担われてきたご経歴を拝見しました」 |
| 二 財務であることと、経営者が委ねる範囲 | 経理ではなく財務であること、経理との分担、何を財務が主体で担い、何を経営者が持つか | 「当社では経理は別の担当がいて、財務として資金繰りの管理と銀行との対応を主体で担っていただき、経営者は最終の判断をします」 |
| 三 自社の状況の種類 | 資金繰りの管理か、調達か、上場準備か、予算管理か。種類まで。詳細は書かない | 「成長のための調達を進めている段階です」 |
| 四 経営との関係 | 誰に報告し、どのくらいの頻度で経営者と数字を見るか。財務の意見の扱い | 「経営者と週に一度、資金の状況と計画を見ます。投資の判断には財務の意見を入れます」 |
| 五 いまの財務の体制 | 一人目か、チームか。仕組みが整っているか、作るところからか。正直に | 「一人目の財務として、資金繰りの管理の仕組みを作るところからお願いしたい」 |
| 六 機微な情報の扱い | 詳細は面接で秘密保持のもとで、と示す | 「資金の状況の詳細は、面接の際に秘密保持のもとでお伝えします」 |
| 七 会社の紹介 | 事業と規模を短く | 三行以内 |
| 八 次の一歩 | 経営者本人が出る短い面談 | 「経営者本人と、三十分ほど財務の話をさせてください」 |

型の要点は、「二で財務であることと委ねる範囲を、会社の紹介より前に書く」ことです。財務の経験者は、会社の事業より、本当に財務か、経営者が委ねるかで判断します。機微な情報（金額、交渉の状況、上場の時期）は文面に書かず、六で「面接で秘密保持のもとで」と示します。

## 刺さる訴求と、外す訴求

| 刺さる訴求 | 外す訴求 |
|---|---|
| 財務であって経理ではないこと。経理との分担の明示 | 「財務経理」「決算と資金繰り」 |
| 経営者が委ねる範囲の具体（銀行との対応を主体で、投資の判断に意見を） | 「経営に近いポジション」「経営者の右腕」 |
| 自社の状況の種類の明示 | 状況を書かない。「成長を支える」 |
| 経営者と数字を見る頻度と、財務の意見の扱い | 「経営陣と密に連携」 |
| 一人目なら、財務の仕組みを作る裁量 | 「裁量があります」だけ |
| 転向元に合わせた訴求（事業会社の側で、支援から作る側へ、一つの会社の調達を最初から最後まで） | 全転向元に同じ文面 |
| 機微な情報を面接で秘密保持のもとで示す姿勢 | 機微な情報を文面に書く。または何も示さない |
| 経営者本人が面談に出ること | 人事だけの面談 |
| 立て直しなら、経営者が支援する姿勢と、動かせる範囲 | 厳しい状況を隠す |

訴求の要点は、「『財務経理』『経営に近い』を使わない」ことです。前者は経理の募集の合図、後者は実態の無さの合図として、財務の経験者に読まれます。財務の範囲と委ねる範囲を具体で書きます。

## 送った後の運用

返信が来たあとの運用で、財務に特有の注意を整理します。

一つ目は、面談に経営者本人が出ることです。財務の候補者は、面談で「経営者が本当に委ねるか」「経営者と数字の話ができるか」を確かめます。人事や管理部門の責任者だけの面談では確かめられず、見送ります。

二つ目は、財務の分かる人が同席することです。社外取締役、顧問、監査法人や銀行の担当。判断の質を聞く役で、経営者だけでは評価しにくい部分を補います。

三つ目は、機微な情報を段階的に、秘密保持のもとで示すことです。一次面談では状況の概要と委ねる範囲、二次以降で秘密保持の合意のもとに資金繰りの表や調達の状況。隠して入社してもらっても、初日に分かります。

四つ目は、転向元ごとの確認です。銀行出身の人には「事業会社の日々の資金繰りの経験」、監査法人出身の人には「資金の判断の経験」、コンサルティング出身の人には「実務の運用の経験」を面談で確かめます。

五つ目は、記録です。財務の候補者の情報は、機微な情報に触れる可能性があるので、依頼側の環境の中で厳重に扱います。[スカウトの重複防止](/media/scout-jyufuku-boushi/)も参考になります。

## 代行に出せる範囲

| 工程 | 代行に出せる | 社内で持つ |
|---|---|---|
| 対象の決定 | 状況と転向元で絞る検索の条件の提案 | 状況と委ねる範囲の確定 |
| 検索と一覧化 | 出せる | — |
| 文面の型作り | 出せる。機微な情報を含めない書き方で | 財務か経理か・状況・委ねる範囲・経営との関係・体制の中身を経営者が出す |
| 一行目の個別化 | 出せる。経歴の状況の一点を書く | — |
| 送信 | 出せる | 名義と時間帯 |
| 返信の一次対応 | 出せる | — |
| 面談の設定 | 出せる | 経営者と財務の分かる人の面談の枠の確保。秘密保持の合意の用意 |
| 面談 | — | 経営者と財務の分かる人が出る |
| 記録と数の整理 | 出せる | 機微な情報の扱いの確認 |

分け方の要点は、「委ねる範囲と機微な情報は、経営者にしか出せず、代行に渡す情報は求人票とスカウトに書く範囲にとどめる」ことです。代行との秘密保持の契約を確認したうえで、詳細は経営者が面接で直接示します。

### エラベルの見解

担当する側から見ると、財務のスカウトで最も時間がかかるのは、依頼側の経営者から「委ねる範囲」を引き出すことです。経営者は「財務を任せたい」と言いますが、銀行との対応を自分が出続けるのか、調達の交渉を財務に任せるのか、投資の判断に財務の意見を入れるのかは、言葉になっていないことが多い。ここを「銀行との対応は財務が主体、最終の判断は経営者」まで具体化しないと、文面の中心が書けません。

エラベルでは、財務の案件で担当者を紹介するとき、依頼側の経営者に「財務か経理か」「状況」「委ねる範囲」を先に決めていただき、それが担当者に渡ってから文面に入るようお伝えしています。機微な情報は担当者にも渡さず、面接で経営者が直接示す形にしています。委ねる範囲が正直に書かれた文面は、返信の総数は増えなくても、財務の経験者からの返信が来て、面談後の辞退が減ります。

## まとめ

- 財務がスカウトを読まない理由は**「財務」の名前の経理の募集を見慣れている・経営者が委ねる範囲を最初に確かめる・状況が分からないと判断できない・「経営に近い」に実態の無さを感じる**
- 先に決めるのは**対象**。**状況と転向元（銀行・監査法人・投資の会社・コンサルティング・事業会社の財務）で絞り、転向元ごとに訴求を変える**
- 文面の型は**一行目に候補者の状況の一点→財務であることと委ねる範囲→状況の種類→経営との関係→体制（正直に）→機微な情報は面接で秘密保持のもとで→会社の紹介（短く）→経営者本人が出る面談**
- 刺さる訴求は**財務であることの明示・委ねる範囲・状況・経営との関係・転向元に合わせた具体**。外す訴求は**「財務経理」「経営に近い」「成長を支える」**
- 面談には**経営者本人と財務の分かる人**が出て、**機微な情報を段階的に秘密保持のもとで示す**
- 代行に出せるのは**状況で絞った検索・個別化・送信・一次対応・面談の設定・記録**。委ねる範囲と機微な情報は経営者から。代行に渡す情報は求人票の範囲まで

## よくある質問

### 「財務経理」と書いているのは、両方を担ってほしいからです。どう書けばよいですか

両方を担う募集でも、優先を先に書きます。財務が中心なら、「財務として資金繰りの管理と銀行との対応を主体で担い、経理の月次の締めも兼ねる」と、財務を一行目に、経理は後に。経理が中心なら逆です。「財務経理」と並べると、財務の経験者は経理の募集に読み、経理の人は財務の部分を読み飛ばします。優先を決めて一行目に置き、もう一方は「兼ねる」と書けば、優先する側の経験者が、兼ねる部分も含めて判断できます。両方を深く持つ人は少ないので、優先しない側は入社後か外部（税理士）で補う前提にします。

### 経営者が委ねる範囲を、スカウトに書いてよいのですか

書いたほうが、財務の経験者からの返信が来ます。「銀行との対応は財務が主体、最終の判断は経営者」「投資の判断には財務の意見を入れる」という範囲は、機微な情報ではなく、役割の設計です。書かないと、「経営者が全部持つ会社」と最悪を想定されます。書く前に、経営者が本当にその範囲を委ねるかを確かめます。書いて実際は違う、が最も離職を生みます。委ねる範囲が狭いなら狭いと書き、「段階的に広げる」と方針を添えれば、それに合う人が返信します。

### 資金繰りが厳しいことを、スカウトに書くべきですか

状況の種類（「資金繰りの管理と銀行との対応が中心」）までは書き、詳細（金額、交渉の状況）は書きません。「詳細は面接の際に秘密保持のもとでお伝えします」と示せば、財務の経験者は「正直に扱う会社」と受け取ります。厳しい状況を隠して「安定した財務」に見せると、面接か入社後に分かり、信用を失います。財務の経験者の中には、立て直しに魅力を感じる人がいて、「立て直しを経営者が支援する」姿勢を添えると、その層が返信します。開示の範囲と秘密保持の扱いは、専門家にご確認ください。
