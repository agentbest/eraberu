一通目のスカウトに返信が無い。二通目を送りたいが、同じ文面をそのまま再送するのは気が引ける。かといって、何をどう変えればよいか分からず、「もう一度お送りします」と添えて同じ文を送るか、結局送らないかのどちらかになっている。結論を先に書くと、**二通目は、一通目の再送ではありません。「件名」「一段落目」「材料」「長さ」「次の一歩」の五つを変え、一度目に送ったことに一言触れたうえで、一通目に無かった別の面を短く見せる一通です。役割や会社の説明を繰り返す必要は無く、一通目より短く、次の一歩はより軽くします**。何回まで送るかの判断は[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/)に、一通目の構成は[スカウト本文の構成](/media/scout-reibun-kouzou/)にまとめています。

## 二通目が書けない構造

二通目が書けない、あるいは同じ文の再送になるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 二通目の役割が無い | 「もう一度届ける」としか考えておらず、一通目と同じことを言うしかない |
| 一通目に全部書いてしまった | 役割も会社も条件も一通目で出し切り、二通目に出す材料が残っていない |
| 「読まれなかった」と決めつけている | 読んだが動かなかった相手にも、同じ文を「見落としですか」と送る |
| 一通目に触れない | 二通目が初回のふりをして届き、相手は「同じものが二回来た」と受け取る |
| 二通目のほうが長い | 「今度こそ」と説明を足し、一通目より重くなる |
| 次の一歩が同じ | 一通目と同じ「面談しませんか」で、相手のハードルが下がらない |
| 型が無い | 担当者が毎回ゼロから書き、書く負荷で送られない |

構造の大半は、「二通目の役割を決めていない」ことです。役割が決まれば、変える要素も決まります。

## 二通目の役割

二通目の役割は、一通目と分けて考えます。一通目は「自分宛てだと分かり、役割が見え、興味を持てば返せる」一通です。二通目は、次の三つのどれかです。

| 役割 | 相手の状態 | 二通目で見せるもの |
|---|---|---|
| 見落としを拾う | 一通目を開いていない、または開いたが読んでいない | 件名を変え、一段落目で「先日ご連絡した件」と触れ、一通目の要点を一文で |
| 動かなかった理由に別の面を見せる | 読んだが、役割か会社か条件のどこかで止まった | 一通目に無かった面（役割の別の側面、一緒に働く人、働き方、会社の別の事実） |
| ハードルを下げる | 読んで興味はあるが、「面談」が重い | 「ご質問だけでも」「一言で結構です」と、次の一歩を軽くする |

どの役割かは、相手の状態で決めます。媒体の開封の情報が見られるなら、開いていない相手は「見落としを拾う」、開いた相手は「別の面を見せる」か「ハードルを下げる」です。見られない場合は、三つを一通に薄く入れます。「先日の件」と触れ、別の面を一つ見せ、次の一歩を軽くする。それが二通目の基本の形です。

## 変える五つの要素

二通目で変える要素は、五つです。

| 要素 | 一通目 | 二通目 |
|---|---|---|
| 件名 | 役割と「あなた宛て」が分かる件名 | 別の切り口。一通目が役割名なら、二通目は「〇〇のご経験の方へ」や「一緒に働く人について」など |
| 一段落目 | 相手の経歴の、どこを見て送ったか | 「先日、〇〇の件でご連絡しました。改めて」と一度目に触れ、前回と違う経歴の部分に触れる |
| 材料 | 役割の中身、会社、条件 | 一通目に書かなかったもの一つ。役割の別の面、一緒に働く人、働き方、会社の事実。役割と会社の説明は繰り返さない |
| 長さ | 一画面程度 | 一通目より短く。三〜五文 |
| 次の一歩 | 面談の提案 | より軽く。「ご質問だけでも」「一言のご返信でも」「ご興味が無ければ、今後のご連絡は控えます」 |

要点は、「一通目に触れる」と「別の面を一つ」と「短く軽く」です。一通目に触れないと、相手は「同じものが二回来た」と受け取ります。別の面が無いと、「催促」に見えます。長いと、「押し売り」に見えます。件名の作り方は[スカウトの件名の作り方](/media/scout-kenmei/)に、一段落目の個別化は[パーソナライズはどこまでやるべきか](/media/scout-personalize/)に書いています。

## 変えない要素

変えないものもあります。変えると、別の会社からのスカウトに見えます。

| 要素 | 理由 |
|---|---|
| 送り主の名前 | 一通目と同じ人から。人が変わると「たらい回し」に見える |
| 役割そのもの | 二通目で別の役割を持ち出すと、「誰でもいいのか」と見える。役割の別の面を見せるのであって、役割を変えるのではない |
| 相手を見て送ったという姿勢 | 二通目も、相手の経歴のどこかに触れる。一通目と違う箇所でよい |
| 断りやすさ | 「ご興味が無ければ返信は不要」の姿勢は、一通目より強く |
| 事実の正しさ | 一通目と矛盾する条件や説明を書かない。一通目の文面を見ながら書く |

二通目は、一通目の続きです。同じ人から、同じ役割で、別の面を見せる。この連続性が崩れると、二通目は独立した別のスカウトになり、一通目の意味が消えます。

## 二通目の型と例

二通目の型を、役割別に示します。〇〇は、相手の経歴や役割の実際の内容に置き換えます。

| 役割 | 型 |
|---|---|
| 見落としを拾う | 「先日、〇〇の役割についてご連絡しました。改めてお送りします。△△のご経験を拝見し、この役割の□□の部分で活きると考えています。ご質問だけでも、お気軽にご返信ください。ご興味が無ければ、今後のご連絡は控えます」 |
| 別の面を見せる | 「先日ご連絡した〇〇の件で、一点だけ補足します。この役割で一緒に働くのは△△の経験のある□□で、前回書かなかった〇〇の進め方について、直接お話しできます。一言でも、ご返信いただければ幸いです。ご興味が無ければ、ご返信は不要です」 |
| ハードルを下げる | 「先日の〇〇の件です。面談とまでいかなくても、『この役割は実際どうか』というご質問だけでも、お答えします。返信は一言で構いません。ご興味が無ければ、今後のご連絡は控えます」 |

三つとも、「一度目に触れる」「別の面か軽い一歩」「断りやすさ」の三つが入り、短い。役割の説明と会社の紹介は入っていません。一通目に書いたからです。

### エラベルの見解

相談で最も多い失敗は、「二通目に、一通目の文面の頭に『先日お送りしましたが、ご覧いただけましたでしょうか』を足しただけのものを送っていた」というものです。一通目と同じ役割の説明、同じ会社の紹介、同じ「面談しませんか」が、催促の一文の後に続く。読んで動かなかった相手には「同じものがまた来た」で、開いていなかった相手にも「長い」で終わります。一通目を短く要約した一文と、一通目に書かなかった「一緒に働く人」の一段落と、「ご質問だけでも」の一歩に変えたら、二通目からの返信が来るようになりました。二通目は、再送ではなく、別の面を見せる一通でした。

見ていて差がつくのは、担当者が「一通目を書く時点で、二通目の材料を残しているか」です。一通目に役割も会社も条件も働き方も全部書く担当者と、「一通目は役割と『なぜあなたに』まで。働き方と一緒に働く人は二通目に取っておきます」と、最初から二通に分けて設計する担当者がいます。後者は、二通目に困りません。

発注側にできるのは、担当者に「一通目に書かなかった材料は何か」を聞くことです。答えられれば、二通目は書けます。

## 送らないほうがよい相手

二通目を送らないほうがよい相手もいます。

| 相手 | 理由 |
|---|---|
| 一通目に断りの返信があった | 意思の表明。二通目は送らない |
| 「今は考えていない」と返信があった | 断りの一種。時期を言われたなら、その時期の少し前に、二通目ではなく新しい一通として |
| 一通目の条件が合っていないと分かった | 経歴を見直して、年収や勤務地が合わないと分かったなら、送らない。合わないものを二回送るのは相手の時間を奪う |
| 一通目から間が空きすぎた | 数か月空いたなら、二通目ではなく、新しい理由での再送。[時間を空けて再送するときの書き方](/media/scout-kikan-aketa/) |
| 一通目が明らかに間違っていた | 名前や経歴の取り違え。二通目ではなく、訂正とお詫びを短く |

二通目は、「一通目が届いており、断られておらず、条件が合っている」相手に送ります。それ以外は、二通目の問題ではありません。

## 二通目の運用

二通目を、担当者が毎回ゼロから書かないための運用です。

| 項目 | 内容 |
|---|---|
| 間隔 | 一通目から一〜二週間。短いと催促、長いと忘れられる。詳しくは[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/) |
| 型の用意 | 役割ごとに、二通目の型を三種類（見落とし・別の面・ハードルを下げる）。一段落目の経歴の部分だけ個別に |
| 材料の一覧 | 役割ごとに、「一通目に書かない材料」を一覧にしておく。一緒に働く人、働き方、役割の別の面、会社の別の事実 |
| 開封の情報 | 媒体で見られるなら、開いていない相手と開いた相手で型を分ける。仕様は媒体の公式の案内で確認 |
| 記録 | 誰に、いつ、どの型で送ったか。返信の有無。三通目を送るかの判断に使う |
| 振り返り | 週に一度、二通目からの返信の内訳を見る。どの型が、どの層に効いたか |

運用の要点は、「材料の一覧」です。二通目に困るのは、材料が無いからです。一覧があれば、担当者は選ぶだけで書けます。

## 外注する場合の範囲

二通目の設計を、スカウト代行に出す場合の範囲です。

**出せる工程。** 一通目の文面の確認と「二通目に残す材料」の切り出し、役割ごとの二通目の型（三種類）の作成、材料の一覧の作成、送る相手と送らない相手の基準の作成、一段落目の個別化、送信の間隔の管理、記録、週次の振り返りと型の修正、三通目の判断。

**社内に残す判断。** 二通目で見せる材料の承認（一緒に働く人の情報、働き方の事実など、社内でないと出せないもの）、送り主の名前の扱い、断りの返信があった相手の扱いの方針。

**外注の効きどころ。** 二通目は、「一通目の文面を把握し、書かなかった材料を持ち、間隔を管理して送る」工程で、社内では「気づいたら再送」になりやすいところです。担当者が一通目を設計する時点で二通目の材料を残し、型を三種類用意し、間隔を管理して送れば、二通目は再送ではなくなります。担当者は複数の会社の二通目を見ているので、「この層には別の面、この層にはハードルを下げる」の型を持ち込めます。

**外注しても動かない場合。** 二通目で見せる材料（一緒に働く人、働き方の事実）を社内が出さない、送り主を毎回変える、断りの返信があった相手にも送ることを求める。社内の判断で、代行を替えても直りません。

二通目は、五つを変え、一度目に触れ、別の面を短く見せれば、再送ではなくなります。外注は、材料の切り出しと型と間隔の管理を担う手段です。

### エラベルの見解

担当する側から見ると、二通目の相談で最も多いのは、「二通目の返信が、一通目より丁寧に来る」ことに驚かれる場面です。「先日ご連絡した件で、一点だけ補足します」と、一通目に触れたうえで短く別の面を見せると、相手は「一度目を覚えていて、押しつけずに、材料を足してくれた」と受け取ります。一通目は流し読みした相手が、二通目で「この人は自分を見ている」と思う。二通目は、一通目より返信率が高いことも珍しくありません。

逆に、二通目で一通目と同じ文を送ると、一通目で持たれた印象まで下がります。「一通目は個別に見えたが、二通目で機械的だと分かった」となるからです。二通目は、一通目の評価を上げも下げもする一通です。

発注側にできるのは、二通目の文面を、一通目と並べて読むことです。並べて、同じことを言っていないか、別の面が一つ入っているか、短いか。それだけで判断できます。

## まとめ

- 書けないのは**役割が無い・一通目に全部書いた・読まれなかったと決めつけ・一通目に触れない・二通目のほうが長い・次の一歩が同じ・型が無い**構造
- 役割は**見落としを拾う・動かなかった理由に別の面を見せる・ハードルを下げる**の三つ。相手の状態で決め、分からなければ三つを薄く一通に
- 変えるのは**件名・一段落目・材料・長さ・次の一歩**の五つ。一度目に触れ、別の面を一つ、一通目より短く、次の一歩は軽く
- 変えないのは**送り主・役割そのもの・相手を見た姿勢・断りやすさ・事実の正しさ**。二通目は一通目の続き
- 型は**見落とし型・別の面型・ハードルを下げる型**の三種類。役割と会社の説明は繰り返さない
- 送らないのは**断りの返信・今は考えていない・条件が合わない・間が空きすぎた・一通目が間違っていた**相手
- 運用は**間隔・型の用意・材料の一覧・開封の情報・記録・振り返り**。材料の一覧があれば担当者は選ぶだけ
- 外注できるのは**材料の切り出し・型・一覧・基準・個別化・間隔・記録・振り返り・三通目の判断**。社内に残るのは**材料の承認・送り主・断りの扱い**

## よくある質問

### 二通目は、一通目からどれくらい空けて送ればよいですか

一〜二週間が目安です。数日だと催促に見え、一か月を超えると一通目を覚えていません。媒体で開封の情報が見られるなら、開いていない相手は一週間ほどで「見落としを拾う」型、開いた相手は二週間ほどで「別の面を見せる」型、と分けられます。媒体ごとの再送の仕様や制限は、公式の案内で確認してください。間隔と回数の考え方は[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/)に書いています。

### 二通目で、条件（年収など）を出したほうがよいですか

一通目で出していないなら、二通目の「別の面」の一つにはなります。ただし、条件を出すかどうかは役割と層で決めるもので、二通目だからという理由で出すものではありません。条件で動く層には効き、条件で判断されたくない役割には逆効果です。出すなら、一通目と矛盾しない事実として、短く。条件をスカウトの段階で出すかの判断は[スカウト段階で条件を出すか](/media/scout-kyuuyo-teiji/)に書いています。

### 二通目にも返信が無い場合、三通目は送りますか

原則は二通目までです。三通目は、「新しい理由」があるときだけ送ります。役割の内容が変わった、新しい事実が加わった、相手が言った時期が来た、など。理由が無い三通目は、催促にしか見えません。三通目を送らない相手は、記録に残し、三か月ほど空けて、新しい理由があれば新しい一通として送ります。空けた後の書き方は[時間を空けて再送するときの書き方](/media/scout-kikan-aketa/)に書いています。
