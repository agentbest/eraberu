内製化の支援で、依頼側の社内の担当を育てる場面があります。担当者は自分がやってきたことを「隣で見せる」か「説明する」かで教えようとしますが、見せても説明しても、担当は自分で回せるようにはなりません。育つのは、本人が型で回し、自分の記録を読み、判断の場面で問われたときです。結論を先に書くと、**社内の採用担当を育てるのは、型で回す・記録で振り返る・境目を判断する・型を直すの四段を三か月ごとに一段ずつ上げることで、最初の三か月は型どおりに回すことだけを求め、振り返りは担当者が評価せず本人が記録を読む形にし、判断の場面では「どう決めますか」と問って答えを渡さず、判断は経営者に置いて担当を孤立させず、育つ目印を「担当者に聞かずに決めたこと」の数で見ます。**内製化の全体は[内製化を支援する](/media/fukugyo-skill-uchisei-shien/)に、会社側から見た育て方は[社内の採用担当を育てる](/media/rpo-jinji-ikusei/)に、スカウトの担当に絞った型は[スカウト担当者の育て方](/media/scout-tantousha-ikusei/)に書いています。ここでは、副業の担当者が育てる側に立つ型に絞ります。

## 「隣で見せる」だけで育たない理由

| 教え方 | 何が起きるか |
|---|---|
| 隣で担当者がやるのを見せる | 見ているだけで、本人は動いていない |
| 全部を説明する | 覚えられない。説明された順に動けない |
| 担当者が判断して、本人が作業 | 判断の仕方を学ばない。担当者に聞けば済む |
| 「センス」に期待する | 育つ人と育たない人が分かれ、育たない人が責められる |
| 一度に全工程 | どれも中途半端 |

育つ順番は、「型で回せる」→「自分の記録を読める」→「型に無い場面で判断できる」→「型を直せる」です。前の段が無いまま次の段を求めると、本人は自信を失います。

## 四段を三か月ごとに

| 段 | 本人がすること | 担当者がすること | 期間の考え方 |
|---|---|---|---|
| 一：型で回す | 型（候補者リスト、評価シート、文面の型、日程の型）どおりに回す。判断はしない | 型を一枚で渡す。回っているかを週次で見る。判断は担当者か経営者 | 最初の三か月 |
| 二：記録で振り返る | 自分の記録（送った数、返信、面接の記録）を月次で読み、「型のどこが使いにくいか」を言う | 振り返りの場を作り、評価せず問う | 次の三か月 |
| 三：境目を判断する | 型に無い場面（この人に送るか、この条件で進めるか）で、自分で決める | 「どう決めますか」と問い、答えを渡さない。決めた後に「なぜ」を聞く | 次の三か月 |
| 四：型を直す | 記録と判断から、型の一行を自分で直す | 直した型を確かめ、依頼側の場所に置く | 次の三か月 |

三か月ごとに一段は目安で、本人の状況で前後します。段を飛ばさないことが要点です。

### エラベルの見解

担当する側から見ると、育成で最も差がつくのは、「最初の三か月は型どおりに回すことだけを求める」を守れるかです。受ける側は、本人に早く判断してほしくて、最初から「どう思う？」と聞きます。型で回した経験が無い本人は、答えられず、「自分には向いていない」と感じます。最初の三か月は、型どおりに回して記録が揃うことだけを目標にし、判断は担当者と経営者が行う。三か月で記録が揃えば、本人は自分の記録を読める材料を持ち、二段目に進めます。エラベルで担当者を選ぶ企業には、「社内の担当に、最初から判断を求めていませんか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、育成の一枚の一段目に「この期間に求めること：型どおりに回す。求めないこと：判断」と書き、依頼側の経営者にも見せること。

## 振り返りは担当者が評価せず、本人が記録を読む

| 担当者がやらないこと | 担当者がやること |
|---|---|
| 「ここが悪い」と指摘する | 「この記録を見て、気づいたことは」と問う |
| 本人の力量を点数で評価する | 記録の揃い（型どおりか）を見る |
| 担当者のやり方と比べる | 型と比べる。「型のどこが使いにくかったか」 |
| 振り返りの内容を経営者に個別に報告する | 「型の直すところ」として傾向を報告 |

振り返りの型は、[面接官トレーニングを行う](/media/fukugyo-skill-mensetsukan/)の「記録の振り返り」と同じです。本人が自分の記録を読んで気づいたことは残り、担当者が指摘したことは残りません。

## 判断の場面で問い、答えを渡さない

| 本人の問い | 担当者の返し |
|---|---|
| 「この人に送ってよいですか」 | 「要件の必須と照らすと、どうですか」 |
| 「この条件で進めてよいですか」 | 「条件を決めるのは誰でしたか。その人に、どう伝えますか」 |
| 「面接官が評価シートを書いてくれません」 | 「運用ルールの一枚では、誰がいつ書くことになっていますか。守られていないなら、どこを軽くしますか」 |
| 「返信が来ません」 | 「返信ゼロのときに疑う順番の一枚を、どこまで確かめましたか」 |

答えを渡すと、本人は次も聞きます。問いを返すと、本人は型と記録に戻り、自分で決めます。決めた後に「なぜそう決めたか」を聞き、記録に残してもらいます。判断の型は、これまでの記事の一枚（[要件の型](/media/fukugyo-skill-youken-hearing/)、[返信ゼロが続くときに疑う順番](/media/scout-henshin-nashi-genin/)）にあり、担当者は「どの一枚を見るか」を示すまでです。

## 経営者との関係

| 決めること | 中身 |
|---|---|
| 判断は経営者 | 要件、条件、合否、優先は経営者か決める人。担当に押しつけない |
| 担当を孤立させない | 担当が経営者に直接聞ける場（週次の短い確認）を置く。担当者を経由しない形に |
| 経営者に育成の一枚を見せる | 「いまの段」と「求めること・求めないこと」を共有。経営者が段を飛ばした要求をしないように |
| 担当の評価 | 担当者はしない。経営者が、記録の揃いと「聞かずに決めたこと」で見る |

担当が「担当者に聞けば済む」状態は、担当者が抜けたら止まります。経営者と担当の間に直接の場を作り、担当者は横に立ちます。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「育っているかは、担当者の感覚で分かる」というものです。感覚で「育った」と言うと、経営者には伝わらず、担当者が抜けた後に「やっぱり回らない」となります。育つ目印は、「担当者に聞かずに、本人が決めたことの数」で見えます。月次で、本人が「今月、自分で決めたこと」を三つ挙げられれば、三段目に入っています。挙げられなければ、二段目です。受ける側がその場で使える判断としては、月次の振り返りの最後に「今月、私に聞かずに決めたことは」と聞き、その数を育成の一枚に書くこと。数が増えていれば育っていて、増えていなければ段を戻します。

## 担当者が抜けた後の相談相手

| 相談の内容 | 相談先 |
|---|---|
| 型の使い方、記録の読み方 | 型の一枚とマニュアル。[マニュアルを作る](/media/fukugyo-skill-manual/) |
| 判断（要件、条件、合否） | 経営者か決める人 |
| 法令や制度 | 専門家（社労士等）。窓口を一枚に |
| 型に無い新しい場面 | 月次の確認の契約があれば担当者。無ければ、同じ立場の人（外部の勉強会、他社の採用担当） |

担当者が抜けた後に、本人が「誰に聞けばよいか」を持っていれば、止まりません。相談先の一覧を、引き継ぎの一枚の「連絡先」に含めます。

## 育成の負担を稼働に入れる

育てる仕事は、回す仕事より時間がかかります。「一緒にやる」段では、担当者が一人で回す時間の倍近くかかることもあります。育成を契約に含めるときは、四段の期間と、各段の担当者の稼働を見積もりに入れます。含めずに引き受けると、稼働が足りず、「隣で見せる」に戻ります。見積もりの型は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 最初から判断を求めている | 一段目に戻す。「型どおりに回す」だけを三か月 |
| 本人が担当者に聞き続ける | 問いを返す。「どの一枚を見ますか」 |
| 振り返りで本人が黙る | 担当者が評価していないか確かめる。「気づいたことは」の問いだけに |
| 経営者が担当に判断を押しつける | 育成の一枚を見せ、判断は経営者と確認 |
| 本人が「向いていない」と言う | 段を戻す。型で回せていることを記録で示す |
| 担当者が抜けた後に止まった | 相談先の一覧と、型の一枚が依頼側の場所にあるかを確かめる |

## まとめ

- 「隣で見せる」「説明する」では育たない。**型で回し、記録を読み、判断で問われる**ことで育つ
- 四段は**型で回す→記録で振り返る→境目を判断する→型を直す**。三か月ごとに一段。飛ばさない
- 最初の三か月は**型どおりに回すことだけ**。判断を求めない
- 振り返りは**担当者が評価せず、本人が記録を読む**
- 判断の場面で**「どう決めますか」と問い、答えを渡さない**。決めた後に「なぜ」を聞く
- **判断は経営者**。担当と経営者の直接の場を作り、担当者を経由しない
- 育つ目印は**「担当者に聞かずに決めたこと」の数**
- 抜けた後の**相談先の一覧**を残す。育成の負担を稼働に入れる

## よくある質問

### 依頼側の担当が、採用の経験がまったく無い人です

一段目（型で回す）から始めれば、経験は要りません。型の一枚があれば、日程調整と連絡と記録の更新は、初日から回せます。経験の無い人ほど、型どおりに回すことに抵抗が無く、記録が揃います。経験のある人のほうが、「自分のやり方」で型を崩し、記録が揃わないことがあります。最初の三か月で「型どおりに回せた」を本人の成功にします。

### 依頼側の担当が二人います。同時に育てますか

二人を同じ段で育てると、担当者の稼働が倍になり、判断の場面で二人の意見が割れます。一人を主にし、もう一人は「記録の更新」など一部の工程から始める形にします。主の担当が三段目に入ったら、もう一人を一段目から。主の担当が、もう一人に型を渡す役になれば、担当者の負担が減り、主の担当の四段目（型を直す）にもなります。

### 育成の途中で、依頼側から「その担当は向いていないので替えたい」と言われました

担当者は本人の力量を評価しません。「いまの段と、記録の揃い、聞かずに決めたことの数」を事実として示し、判断は依頼側です。段を飛ばして求めていた場合は、それを伝えます。替える判断になった場合、型と記録が依頼側の場所にあれば、次の担当は一段目から始められ、ゼロには戻りません。本人への伝え方は依頼側の人事の領域で、担当者は関わりません。
