大手企業の人事として、整った仕組みの中で、新卒の大量の採用や、事業部をまたぐ中途の採用を、決められた手順で、多くの関係者と調整しながら回してきた。この経験は、人事の部門が小さい会社が多い副業で売れるのか。大手の人事の経験は、仕組みがあったから回っていたもので、仕組みのない会社では通じないと感じる人が多いところです。結論を先に書くと、**大手企業の人事の経験は、「整った仕組みの中で、大量の採用と複雑な調整を、決められた手順で抜けなく回してきた」型で売れます。売れるのは、「仕組みを小さい会社の規模に翻訳する型」「大量の応募を漏れなく回す設計」「多くの関係者の調整と合意の型」「手順と記録で品質を保つ運用」の四つです。小さい会社には仕組みがなく、そのままでは応募が増えたとき、関係者が増えたとき、判断でもめたときに止まります。大手の仕組みをそのまま持ち込むのではなく、「なぜその仕組みがあるのか」を知っている人が、要る分だけ軽くして持ち込めば、小さい会社でも回ります。「大手の人事でした」ではなく、「整った仕組みの『なぜそうなっているか』を知っていて、小さい会社に要る分だけ持ち込む」と売ります。**中小企業の人事の経験は[中小企業の人事が副業でできること](/media/fukugyo-chusho-jinji-fukugyo/)に、金融機関の人事の経験は[金融機関の人事が副業でできること](/media/fukugyo-kinyu-jinji-fukugyo/)に、人事企画の経験は[人事企画が副業でできること](/media/fukugyo-jinji-kikaku-fukugyo/)にまとめています。

## この経歴の何が売れるか

大手企業の人事の経験を、人事の部門が小さい会社の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| 大手企業の人事の経験 | 小さい会社の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 整った仕組み（要件の型、選考の段階、記録、承認の流れ）の中で動いてきた | 仕組みの一つひとつが「何のためにあるか」を知っていて、小さい会社に要るものだけを軽くして持ち込む | 仕組みがなく、応募が増えると止まる依頼側が多い |
| 新卒の大量の応募を、段階ごとに漏れなく回してきた | 応募が多いときの、段階ごとの基準と人数と日程の設計と、連絡の漏れをなくす運用 | 応募が多いと処理が追いつかず、連絡が漏れる依頼側が多い |
| 事業部、現場、役員、労務、法務など多くの関係者と調整してきた | 経営者、現場、人事の意見が割れる採用で、誰が何を決めるかを整理し、合意を作る型 | 意見が割れて採用が止まる依頼側が多い |
| 手順と記録で品質を保ち、監査や説明に耐える形で運用してきた | 面接の記録と決めた理由を残し、後から説明できる形にする | 記録が残らず、決めた理由を説明できない依頼側が多い |
| 採用の予算と実績を、経営に報告してきた | 採用の数字を集め、経営者が判断できる形で見せる型 | 採用の数字が担当者の頭の中にしかない依頼側が多い |
| 外注先（媒体、紹介、代行）を、契約と品質の両面で管理してきた | 外注先の提案の見方、契約の確認項目、品質の見方 | 外注先を営業の勧めで選び、管理できていない依頼側が多い |
| 制度（等級、評価、報酬）と採用の条件を整合させてきた | 採用の条件を、既存の社員との整合で決める枠組み | 採用のたびに条件が例外になる依頼側が多い |

売れるものの要点は、「仕組みの『なぜ』を知っていて、要る分だけ持ち込める」ことです。小さい会社には仕組みがなく、仕組みのある会社の人事が来ると、仕組みをそのまま持ち込んで重すぎるか、仕組みがないことに戸惑って動けないか、のどちらかになりがちです。大手の人事が売れるのは、仕組みの一つひとつが何のためにあり、どれが小さい会社にも要り、どれが要らないかを判断できるからです。「記録は要るが、承認の段階は要らない」「基準は要るが、評価の項目は三つでよい」と、翻訳できる人は多くありません。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

大手企業の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 仕組みに頼っていた | 「仕組みがあったから回っていたので、仕組みのないうちでは動けないのでは」。自分でも、仕組みのない環境の経験がない不安 | 仕組みに頼っていたことを認めたうえで、「仕組みの『なぜ』を知っている」ことを売る。「この仕組みは応募が増えたときに要る、この仕組みは御社には要らない」と判断できることを、面談で見せる |
| 小さい会社の速さと粗さに合わない | 「大手の丁寧さで進められたら、うちの採用は遅くなる」 | 手順を「基準・記録・説明」の三つに絞り、小さい会社の速さで回る形を先に見せる。粗さを直そうとせず、「粗くても止まらない」形を作る |
| 自分で手を動かした経験が薄い | 「大手では分業で、スカウトの送信や日程の調整は自分でやっていないのでは」 | 手を動かす工程は経験が薄いことを認め、範囲に入れないか、別の担当者と組む。売るのは「設計と運用の型」だと最初に分ける |

扱い方の要点は、「仕組みに頼っていたことを認め、仕組みの『なぜ』を売る」ことです。大手の人事の経験がある人は、仕組みのない会社に入ると、仕組みがないこと自体を問題として語り、依頼側は「うちを否定された」と感じます。「御社に今、仕組みがないのは自然です。応募が増えたとき、面接官が増えたとき、判断でもめたときに止まるので、その三つに備える最小限の仕組みだけ、先に作りましょう」と語れば、同じ経験が「要る分だけ持ち込める人」として伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、大手企業の人事から転身して続いている人と、面談で止まる人の差は、仕組みがないことをどう扱うかです。止まる人は、依頼側の採用の流れを聞いて「記録がない」「承認の流れがない」「基準がない」と、ないものを数え上げ、依頼側の経営者は「うちはそういう会社ではない」と感じて終わります。続いている人は、同じ状況で「今の御社の規模なら、この流れで回っています。ただ、応募が月に何件を超えると、連絡が漏れ始めます。そのときに要るのは、一枚の進捗の表だけです」と、要るものを一つだけ示します。経営者は、否定されずに、備えを一つ渡されたと感じ、そこから頼みます。

見ていて差がつくのは、大手の仕組みを「軽くする」ときの判断の質です。大手の人事の経験がある人は、仕組みを軽くしようとして、項目を減らすだけで済ませがちで、それでは小さい会社にはまだ重いことがあります。「大手で十項目あった面接の評価を三項目に減らす」のではなく、「大手で評価の項目が十あったのは、面接官が多くて基準を揃えるためだった。御社は面接官が二人なので、項目ではなく『見る点を三つ、口頭で揃える』だけでよい」と、仕組みの『なぜ』に戻って判断した人は、依頼側から「大手のやり方ではなく、うちのやり方を作ってくれた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「整った仕組みの『なぜ』を知っていて、小さい会社に要る分だけ持ち込む」と翻訳の言葉で書いている担当者に、応募が増えて困っている依頼側がついています。大手の人事の転身は、仕組みを持ち込むことではなく、仕組みの『なぜ』に戻って要る分を選ぶところから始まります。

## 案件の探し方

大手企業の人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 応募が増えて回らなくなった会社の、段階ごとの選考の設計 | 大量の応募を回してきた経験でそのまま入れる | 「応募が増えて連絡が漏れ始めた依頼側」を探す |
| 面接官が増えて判断がばらつく会社の、基準と記録の型 | 手順と記録で品質を保ってきた経験で入れる | 「面接官が増えた依頼側」を探す |
| 経営者と現場で意見が割れる採用の、合意の型 | 多くの関係者と調整してきた経験で入れる | 「意見が割れて採用が止まる依頼側」を探す |
| 外注先（媒体、紹介、代行）の提案の見方と管理 | 外注先を管理してきた経験で入れる | 「外注先を管理できていない依頼側」を探す |
| 採用の数字の見える化と経営者への報告 | 経営に報告してきた経験で入れる | 「採用の数字が頭の中にしかない依頼側」を探す |
| 拡大期に入った会社の、最小限の仕組みづくり | 仕組みの『なぜ』を知っている経験で入れる | 「これから人が増える依頼側」を探す |

探し方の要点は、「仕組みがなくて止まり始めた会社」から入ることです。仕組みがなくても回っている会社では、大手の型は必要とされず、「重い」と見られます。応募が増え、面接官が増え、関係者が増え、判断でもめ始めた会社では、仕組みがないことで止まり始めており、大手の型が唯一の打ち手になります。案件の相談で「最近、回らなくなってきた」「前は社長一人で決められたが」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。大手企業の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 仕組みの設計の成果物 | 段階ごとの選考の設計、基準と記録の型、合意の型は、成果物として形が明確 | 一式の成果物で受ける |
| 仕組みの運用 | 作った仕組みを回す運用は、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 大手の肩書 | 単価の期待は上がるが、小さい会社では「高そう」「重そう」と頼みにくくなる | 工程と成果物で示し、肩書で値付けしない |
| 手を動かす工程を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 翻訳の価値 | 「要る分だけ持ち込む」判断は、仕組みをそのまま持ち込む人にはできず、価値が見えれば高い | 「これは要らないと判断した」ことも成果として報告に残す |
| 仕組みが残ること | 作った仕組みは依頼側に残るので、作って終わりになると契約が続かない | 「次に要る仕組み」を、依頼側の成長に合わせて提案する |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「仕組みは成果物で、運用は月額で受け、肩書で値付けしない」ことです。大手の人事の経験で受ける工程は、仕組みの設計という成果物が明確で、成果物で受けると単価の根拠が伝わります。大手の肩書は、小さい会社では「高そう」「重そう」に働くので、肩書ではなく工程と成果物で示します。「要らないと判断した」ことも成果として報告に残すと、翻訳の価値が依頼側に見えます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

大手企業の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、社員と仕組みの情報の守秘の条件を確認する | 大手は兼業の規程が細かい。個別の判断は専門家に |
| 二、自分が使ってきた仕組みを一つずつ挙げ、「何のためにあるか」「どの規模で要るか」を書き出す | 仕組みの『なぜ』の一覧 |
| 三、その一覧から、「小さい会社にも要るもの」と「要らないもの」を分ける | 翻訳の準備 |
| 四、仕組みに頼っていた部分と、自分の判断で動いた部分を、正直に分ける | 手を動かす工程は薄い、と認める |
| 五、得意な工程（設計・段階・調整・記録・数字・外注先の管理）と、薄い工程（手を動かす、仕組みのない環境で即興で動く）を分ける | 正直に示す準備 |
| 六、範囲を、最小限の仕組みの設計、段階ごとの選考、基準と記録、合意の型、外注先の見方、数字の見える化に絞る | 手を動かす工程は最初は範囲外 |
| 七、「整った仕組みの『なぜ』を知っていて、小さい会社に要る分だけ持ち込む」の一言を作る | 「大手の人事でした」で終わらせない |
| 八、登録先に、範囲と、翻訳の型と、仕組みがなくて止まり始めた依頼側に向いていることを登録する | 回らなくなってきた依頼側 |
| 九、最小限の仕組みづくりを一件受け、「要らないと判断したもの」も含めて報告に残す | 次の仕組みに広げる材料に |

順番の要点は、「二」と「三」の仕組みの『なぜ』の一覧です。大手の人事の経験は、仕組みを「使ってきた」経験で、「なぜあるか」を言葉にしないと、そのまま持ち込むしかなくなります。使ってきた仕組みを一つずつ挙げ、何のためにあり、どの規模から要るかを書き出し、小さい会社に要るものと要らないものを分けておくと、面談で「御社にはこれだけでよい」と言えます。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「大手の人事の経験は、仕組みがあったから回っていたもので、仕組みのない会社では通じない」というものです。実際には、仕組みのない会社は、応募が増え、面接官が増え、関係者が増えたときに止まり、そこで要るのは、仕組みをそのまま持ち込む人でも、仕組みがないことに戸惑う人でもなく、仕組みの一つひとつが何のためにあるかを知っていて、要る分だけを軽くして持ち込める人です。大手の人事は、仕組みを使ってきたからこそ、その『なぜ』を知っています。通じないのは、仕組みに頼っていたことを認めずにそのまま持ち込む場合で、『なぜ』に戻って要る分を選べば、規模は関係ありません。

順番として、本業の規定と守秘の条件を専門家に確認し、仕組みの『なぜ』と要る規模を一覧にし、小さい会社に要るものと要らないものを分け、仕組みに頼っていた部分を正直に認め、得意な工程と薄い工程を分け、範囲を最小限の設計と段階と基準と合意と外注先と数字に絞り、要る分だけ持ち込む一言を作り、登録先に範囲と翻訳の型を登録し、一件受けて要らないと判断したものも含めて残す。この順番で、大手の人事の経験は「仕組みがないと通じないもの」から「仕組みの『なぜ』を知る翻訳の型」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、翻訳の工程を明確にし、手を動かす工程を含まないことを示している担当者に、回らなくなってきた依頼側がついています。大手の人事の転身は、仕組みを持ち込むことではなく、仕組みの『なぜ』に戻って要る分を選ぶところから始まります。

## まとめ

- 大手企業の人事の経験は**「整った仕組みの中で、大量の採用と複雑な調整を、決められた手順で抜けなく回してきた」型**で売れる。**仕組みの翻訳・大量の応募の設計・関係者の調整・手順と記録**の四つ
- **「大手の人事でした」ではなく「整った仕組みの『なぜ』を知っていて、小さい会社に要る分だけ持ち込む」**と売る
- 売りにくい点は**仕組みに頼っていた・小さい会社の速さと粗さに合わない・手を動かした経験が薄い**。頼っていたことを認めて『なぜ』を売り、「基準・記録・説明」に絞って軽くし、手を動かす工程は範囲外と示す
- 案件は**仕組みがなくて止まり始めた会社**から。「最近、回らなくなってきた」が入り口
- 単価は**仕組みは成果物、運用は月額**で。肩書で値付けしない。「要らないと判断した」ことも成果に。成果報酬は最初は避け、可否は専門家に確認
- 仕組みを軽くするときは、**項目を減らすのではなく『なぜ』に戻って判断する**

## よくある質問

### 依頼側に「大手のやり方は、うちには合わない」と最初に言われました

その通りだと認めたうえで、持ち込むのは大手のやり方ではないと示します。「大手のやり方をそのまま持ち込むつもりはありません。大手に仕組みがあるのは、人が多いからで、御社には要らないものがほとんどです。ただ、応募が増えたときと、面接官が増えたときに止まる会社を見てきたので、その二つに備える最小限だけ、一緒に作れればと思います」と、要るものを一つか二つに絞って返します。合わないと言われるのは、仕組みを持ち込まれることへの警戒なので、持ち込まないと示せば消えます。経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、改善の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

### 前の会社の要件の型や面接の評価表を、参考として使ってよいですか

使いません。会社の業務で作った型と評価表は、一般に会社のものと整理されることが多く、持ち出して使うと守秘と著作の線に問題が出ます。使えるのは、「なぜその項目があったか」「どの規模で要るか」という『なぜ』の理解だけで、型と表そのものは、依頼側に合わせて新しく作ります。大手は兼業と守秘の規程が細かいことが多いので、個別の判断は、弁護士や社会保険労務士にご確認ください。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

### スカウトの送信や日程調整を自分でやったことがありません。案件が取れないのではないですか

手を動かす工程が薄いことは隠さず、「スカウトの送信や日程の調整は御社の担当者か別の担当者が、私は段階の設計と基準と記録と、外注先の見方と数字を担います」と分担を示します。手を動かす工程が得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。回らなくなってきた依頼側には、手を動かす人より「止まらない形を作る人」が求められており、そこでは手を動かした経験の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、評価される担当者の共通点は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に整理しています。
