人事が一人いる会社の案件は、副業の人にとって最も回しやすい相手です。型があり、判断する人がいて、相談相手がいる。ただ、担当との役割分担を決めずに始めると、担当の仕事を奪っているように見えたり、逆に担当に指示する形になったりして、担当との関係が崩れます。担当が協力しなくなれば、副業の人は社内で動けません。結論を先に書くと、**副業の人は、担当の代わりでも担当の上でもなく、「担当の手が回らない一つの業務を受け、その業務の実行を担い、判断と社内の窓口は担当に残す」形で分担する**と、担当の立場を守りながら動けます。分担は、面談と初回打ち合わせで担当と一緒に決め、書面にします。相手の規模ごとの違いは[企業規模で絞るという戦い方](/media/fukugyo-kibo-tokka/)に、現場との関係は[現場との関係の作り方](/media/fukugyo-genba-chousei/)にまとめています。

## 分担の原則

担当と副業の人の分担を、原則として整理します。

| 領域 | 担当 | 副業の人 |
|---|---|---|
| 判断 | 合否、条件、優先順位（または判断する人に上げる） | 判断の材料を選択肢の形で用意 |
| 社内の窓口 | 現場、経営者、経理との連絡 | 担当が出せる材料を作る |
| 日中の即応 | 応募者への定型返信、当日の日程変更、電話 | 夜や週末に本返信と整理 |
| 手が回らない一つの業務 | 型と基準を持ち、確認する | 実行する。数をこなす |
| 型の管理 | 型の所有者。変更の判断 | 型の改善を提案し、実行 |
| 情報 | 応募者情報と社内情報の管理 | 担当の環境の中で扱い、外に出さない |
| 対外の名乗り | 会社の採用窓口 | 担当の名前か、会社の窓口の名前で |

原則の要点は、「判断・窓口・即応・型の所有は担当、実行は副業の人」ということです。副業の人が判断や窓口を持つと、担当の仕事を奪う形になります。実行に徹すると、担当は「手が空いた」と感じ、協力します。

## 業務ごとの分け方

同じ業務の中でも、担当と副業の人で分ける部分があります。業務ごとに示します。

| 業務 | 担当 | 副業の人 |
|---|---|---|
| スカウト運用 | 誰に送るかの基準、送信の承認（または任せる範囲を決める） | 検索、文面の作成、送信、返信の一次対応 |
| 求人票 | 要件の決定、最終の承認 | 初稿の作成、修正、媒体ごとの調整 |
| 応募者対応 | 日中の定型返信、当日の変更、電話 | 本返信の下書き、日程候補の提示、記録 |
| 書類選考 | 合否の判断、判断する人への引き上げ | 基準に沿った一次絞り、要約の作成 |
| 面接 | 面接官の調整、実施、評価の回収 | 質問の案、候補者の要約、記録（オンライン同席の場合） |
| 進捗管理 | 表の所有、社内への報告 | 表の更新、週次のまとめ |
| 媒体の管理 | 契約、費用の判断 | 運用、効果の数の整理、改善の提案 |

分け方の要点は、「一つの業務の中で、判断と実行を分ける」ことです。「スカウト運用を任せる」と言われても、誰に送るかの基準は担当が持ち、送信は副業の人が担う。この分け方があると、担当は「自分の業務を外に出した」ではなく「実行を手伝ってもらっている」と受け取ります。

### エラベルの見解

登録の相談で多いのは、「担当が最初は歓迎していたのに、途中から協力してくれなくなった」という話です。経緯を聞くと、副業の人が良かれと思って型を変え、現場に直接連絡し、経営者に直接報告していた。担当から見ると、自分の業務が外の人に持っていかれ、自分の頭越しに社内が動いている。担当は、副業の人を「自分の立場を脅かす人」と感じ、協力をやめました。副業の人に悪気はなく、動きやすさを優先しただけです。

見ていて差がつくのは、「担当を、全部の窓口にしているか」です。型を変えるなら担当に提案し、担当が決める。現場に頼むなら担当を通す。経営者への報告は担当と一緒に。担当が全部の窓口にいる状態なら、担当は「自分が回している」と感じ、副業の人を「自分を助ける人」として扱います。エラベルの登録でも、人事が一人の会社で長く続いている人は、担当を窓口にする動きを徹底していて、担当から「いなくなると困る」と言われています。

## 担当の立場を守る動き方

分担を決めたあと、日々の動きで担当の立場を守る型を、番号付きで整理します。

1. **型の変更は、提案して担当が決める。** 「文面をこう変えると、返信が増えると思います。変えてよいですか」。勝手に変えない。
2. **現場・経営者・経理への連絡は、担当を通す。** 直接連絡が来ても、担当に共有しながら返す。
3. **報告は、担当に先に、判断する人には担当と一緒に。** 判断する人に直接送る場合も、担当を写しに入れる。
4. **成果は、担当の成果として見える形にする。** 「担当の方の基準で一次絞りをしたところ、面接の通過率が上がりました」。自分の手柄にしない。
5. **担当の判断を、待つ。** 判断が遅くても、自分で判断しない。期限を付けて待つ。
6. **担当が知らないことを、社内で話さない。** 担当より先に、現場や経営者が知る状態を作らない。
7. **担当の負担を減らすことを、自分の仕事にする。** 担当が「手が空いた」と感じる状態が、協力の源。
8. **担当の型を尊重する。** 自分の型のほうが良いと思っても、まず担当の型で回し、数で示してから提案する。

動き方の要点は、「四で、成果を担当の成果にする」ことです。副業の人の成果は、担当の成果として社内に見えるほうが、担当は協力します。自分の手柄にすると、担当の立場が弱くなり、協力が消えます。区切りの数は、依頼側との書面では自分の成果として示しますが、社内では担当の成果として見える形にします。

## 担当との定例の型

担当との週次の確認は、判断待ちを消す時間です。担当が一人で忙しい前提で、型を示します。

| 項目 | 内容 |
|---|---|
| 時間 | 短く。十五〜三十分。担当の空く時間帯に固定 |
| 事前 | 週ごとの一枚を前日に送る。担当が読む時間が無ければ、冒頭で数だけ一分 |
| 中身 | 判断待ちを選択肢の形で。担当が判断できないものは、判断する人に上げる項目として整理 |
| 担当の負担 | 「私が用意するので、決めていただくだけです」 |
| 担当の困りごと | 「いま一番手が回らないのは何ですか」を毎回一つ聞く。次に受ける業務の候補になる |
| 決まったこと | その日のうちに書面で。担当と判断する人の両方に |
| 担当が来られない週 | 書面版。期限付きの一覧で |

定例の要点は、「担当の困りごとを毎回一つ聞く」ことです。担当の手が回らないことは、時期で変わります。毎回聞いておくと、区切りで範囲を広げる相談が、担当の困りごとに沿った形でできます。[定例会の進め方](/media/fukugyo-teirei-shinkou/)を参照してください。

## 分担が崩れる兆候と失敗

分担が崩れ始める兆候と、崩す失敗を整理します。

| 兆候・失敗 | 意味 | 直し方 |
|---|---|---|
| 担当の返事が遅くなった | 担当が副業の人を警戒し始めている | 担当を窓口にできているかを見直す |
| 現場や経営者から直接連絡が来るようになった | 担当を飛ばす経路ができている | 担当に共有しながら返す。担当を戻す |
| 担当の型を勝手に変えた | 動きやすさを優先 | 提案して担当が決める形に戻す |
| 判断する人に直接報告した | 早く伝えたい | 担当を写しに。担当と一緒に |
| 自分の成果として社内に見えている | 手柄になっている | 担当の成果として見える形に |
| 担当の判断を待たずに進めた | 遅いので | 期限を付けて待つ。自分で判断しない |
| 担当より自分のほうが詳しいと態度に出た | 経験の差 | 担当の型を尊重。数で示してから提案 |
| 担当の困りごとを聞かなくなった | 自分の範囲に集中 | 毎回一つ聞く |
| 担当が「全部やってもらえる」と手を引き始めた | 逆方向の崩れ。担当が判断から離れる | 判断と窓口は担当に残す。丸投げにしない |

崩れの要点は、「担当を飛ばす経路ができたとき」が最も重い兆候だという点です。現場や経営者から直接連絡が来るのは、動きやすいようで、担当の立場を崩しています。担当に戻します。

### エラベルの見解

担当する側として登録した人の話を聞くと、人事が一人の会社で続いている人は、担当を「自分の上司」のように扱っています。型は担当のもの、判断は担当、窓口は担当、成果は担当のもの。自分は実行と材料の用意。この位置づけが、担当にとっては最も安心で、副業の人にとっては最も動きやすい。担当より前に出ようとした人は、担当の協力を失い、社内で動けなくなっています。

依頼側から見ると、人事が一人の会社で副業の人を入れることは、担当の負担を減らすためであって、担当を置き換えるためではありません。エラベルは、企業と担当者の間に立つ窓口として、案件を出すときに依頼側の担当が誰で、何に手が回っていないかをお伝えしています。分担を担当と一緒に決め、担当を窓口にする型を持っていただくと、担当から「続けてほしい」という声が出て、案件が続きます。

## まとめ

- 副業の人は**担当の代わりでも上でもなく、手が回らない一つの業務の実行を担い、判断と窓口と即応と型の所有は担当に残す**
- 業務の中でも**判断と実行を分ける**。「任せる」と言われても、基準は担当、実行は自分
- 担当の立場を守る動きは**型の変更は提案して担当が決める・連絡は担当を通す・報告は担当に先に・成果は担当の成果に・判断を待つ・担当の型を尊重**
- 定例は**短く・判断待ちを選択肢で・担当の困りごとを毎回一つ聞く・書面で確定**
- 崩れる兆候は**担当の返事が遅い・担当を飛ばす経路・型を勝手に変えた・直接報告・自分の手柄**。逆に担当が判断から離れるのも崩れ
- 担当を**自分の上司のように扱う**位置づけが、最も安心で最も動きやすい

## よくある質問

### 担当の型が明らかに良くないのですが、どう提案すればよいですか

まず担当の型で一か月回し、数を出します。「担当の型で一か月やったところ、返信率はこのくらいでした。冒頭を変える型を試させていただけませんか。二週間で比べます」。数で示してから、試す提案をし、担当が決める。担当の型を否定せず、比べる形にすれば、担当は受け入れやすい。結果が良ければ、「担当の型を土台に、冒頭だけ変えました」と、担当の型の改善として社内に見せます。自分の型を持ち込んで置き換える形は、担当の立場を崩します。

### 経営者から「担当を通さずに直接報告してほしい」と言われました

担当を写しに入れる形で応じます。「承知しました。〇〇さん（担当）にも共有しながらお送りします」。経営者が担当を飛ばしたい理由が、担当への不信なら、それは経営者と担当の問題で、副業の人が間に入ると担当の立場が悪くなります。経営者に直接報告しつつ担当を写しに入れれば、経営者の希望にも応え、担当も知らないままにはなりません。担当を外した報告を続けると、担当は副業の人を経営者側の人と見て、協力しなくなります。

### 担当が「全部やってもらって助かる」と、判断からも手を引き始めました

分担の逆方向の崩れです。担当が判断と窓口から離れると、副業の人が判断を負い、範囲が広がり、担当の立場も消えます。「判断と社内の窓口は、〇〇さんにお願いしたいです。私は材料を用意します」と、分担に戻します。担当が忙しくて判断できないなら、判断の項目を減らし、選択肢の形で短く出す。担当が判断する人として機能する状態を保つことが、担当の立場を守り、自分の範囲も守ります。[丸投げ案件をどう扱うか](/media/fukugyo-marunage/)を参照してください。
