同じ採用代行を使っても、機能する不動産会社と機能しない不動産会社があります。差を作るのは代行の腕ではなく、発注側の条件です。報酬の形を先に出す判断をしているか、早期離職の理由を分けているか、資格の扱いを整理しているか、店舗をまたいで観点と記録が一つか、型と職種で経路を分けているか、記録が社内にあるか、任せる工程が絞られているか。結論を先に書くと、**不動産業界で採用代行が機能するのは、報酬・離職・資格・店舗・経路・記録・工程の七つで「社内に残すものを残している」会社で、機能しないのは「営業は辞めるもの。報酬の形は面接で。全部任せたい」会社です。**発注の前に七つで自社を確かめ、機能しない条件があれば、発注の前にそれを変えます。工程の切り分けは[不動産業界の採用代行](/media/rpo-fudosan-rpo/)に、課題の分解は[不動産業界の採用課題](/media/rpo-fudosan-kadai/)に、営業職の切り分けは[営業採用を代行に出す判断基準](/media/rpo-sales-rpo/)に書いています。ここでは、不動産業界の七つの対に絞ります。

## 七つの対

| 軸 | 機能する条件 | 機能しない条件 |
|---|---|---|
| 報酬 | 営業の報酬の形（固定と成果の比率、成果の考え方）を求人票と初回の連絡で出す判断をし、表示の文言は専門家の確認を経ている | 「報酬の形は面接で」 |
| 離職 | 早期離職の理由を退職面談で分け、求人票の実態と受け入れの体制を直している | 「営業は辞めるもの」。辞めた分を採り続ける |
| 資格 | 資格と担える業務の関係を会社と専門家で整理し、「必須・取得の支援・歓迎」の区分が要件と求人票にある | 「資格は後で」「あれば尚可」だけ |
| 店舗 | 店舗をまたいで観点と記録の形が一つ。決めるのは店長。店長の枠を接客の少ない時間帯で週に一つ預けられる | 「店舗は店長に任せている」。基準も記録もばらばら |
| 経路 | 売買・賃貸・管理・開発と、営業・管理・事務で経路を分けている | 一つの媒体で全部 |
| 記録 | 一覧と面接の記録が社内の環境にあり、店舗と型ごとに見られる | 記録が代行の環境。店舗ごとに別 |
| 工程 | 任せる工程が絞られ、残す工程（報酬の形・資格・見極め・受け入れ・条件）の担当がいる | 「全部任せたい」 |

七つのうち一つでも機能しない条件にあると、代行はその部分で止まります。

## 報酬：先に出す判断をしているか

| 機能する | 機能しない |
|---|---|
| 固定と成果の比率と、成果の考え方を、求人票と初回の連絡で出す | 「面接で話す」。面接で「思っていたのと違う」 |
| 形に合わせて、経路と文面と面接の観点を分ける | 両方の層を同じ文面で集める |
| 表示の文言は専門家の確認を経ている | 担当者が独自に書く |

報酬の形の判断と表示の文言には、法令上の整理があると一般に整理されているため、会社と専門家（社労士等）で決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

不動産業界で最も多い機能しない条件は「離職」の扱いです。「営業は辞めるもの」で、辞めた分を代行に採らせ続ける。代行は穴を埋めるだけで、費用は出続け、店舗は常に教える負担を抱えます。退職面談で理由を「報酬の形・受け入れ・実態・店長との関係・私的な事情」に分けると、直す場所は採用の入口ではなく、求人票の実態と受け入れの体制です。それを直してから代行に出すと、採った人が残り、募集の回数が減ります。エラベルで担当者を選ぶ企業には、「直近一年で辞めた営業の理由を、分類して数えていますか」を、私たちから先に聞いています。数えていなければ、代行の前に退職面談の記録からです。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 離職：理由を分けて直しているか

| 機能する | 機能しない |
|---|---|
| 退職面談の記録があり、理由を分類して数えている | 「一身上の都合」しか無い |
| 分類ごとに、求人票の実態・受け入れの体制・店長との接点を直している | 採用の入口だけを直す |
| 募集の回数が減っている | 同じ店舗で募集を繰り返す |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 資格：整理されているか

| 機能する | 機能しない |
|---|---|
| 資格の有無で担える業務と配置がどう変わるかを、会社と専門家で整理している | 「あれば尚可」で募集し、採った後に分かる |
| 「必須・取得の支援・歓迎」の区分が、要件と求人票に同じ形である | 区分が無い |
| 書類の一次確認で有無を照合し、区分で分ける | 面接まで確かめない |

## 店舗：観点と記録が一つか

| 機能する | 機能しない |
|---|---|
| 観点（この役割に期待すること）と記録の形（事実と判断）が一枚で、全店舗の店長に渡っている | 店舗ごとに店長の勘 |
| 決めるのは店長 | 人事が決める（店舗の実態と合わない） |
| 店長の枠を、接客の少ない時間帯で週に一つ先に預かる | 接客と重なり、日程が延びる |
| 一覧に「店舗」の列があり、店舗をまたいで見られる | 店舗ごとに別の記録 |

揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

### エラベルの見解

「全部任せたい」という不動産会社は、多くの場合、本部の人事が店舗ごとの募集を追い切れず、店長に任せた結果、基準も記録もばらばらになった状態です。その状態で全部を任せると、報酬の形の判断も資格の整理も店舗の基準も代行に寄り、代行にはできないので止まります。エラベルは担当者を工程ごとに選べる形にしているので、本部の人事が「報酬の形と資格の整理（専門家と）・観点と記録の形の一枚・条件の判断」に絞り、店長は「週に一枠の面接と受け入れ」に絞り、「型ごとの母集団形成・一次対応・日程・店舗をまたぐ記録」を担当者が担う、という組み方ができます。店舗をまたぐ記録が一つになると、本部はどの店舗で詰まっているかを見られます。工程の切り分けは[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)や[求人媒体の運用は代行に出せるか](/media/rpo-task-baitai-unyou-daikou/)に書いています。

## 経路：型と職種で分けているか

| 機能する | 機能しない |
|---|---|
| 売買の営業はスカウトと掲載型、賃貸の営業は掲載型と地域、管理は掲載型と紹介、と分けている | 一つの媒体で全部 |
| 型ごとに応募の数を記録している | 全部を一つの数で |
| 報酬の形に合わせて、営業の経路と文面を分けている | 形に関係なく同じ文面 |

## 記録：社内の環境にあるか

| 機能する | 機能しない |
|---|---|
| 一覧と面接の記録が社内の環境にあり、「店舗」「型」の列で見られる | 記録が代行の環境。店舗ごとに別 |
| 週次の一枚で、店舗ごとの数と止まりが本部に届く | 月末の報告だけ |
| 契約が終わっても、記録と型（観点の一枚、要件、資格の区分、求人票）が社内に残る | 契約が終わると消える |

記録の扱いは[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。

## 工程：絞られているか

| 機能する | 機能しない |
|---|---|
| 「売買の営業の母集団形成と一次対応」「全店舗の日程と記録」のように、型と工程で任せる範囲が明確 | 「採用を全部」 |
| 残す工程（報酬の形・資格・見極め・受け入れ・条件・合否）の担当が決まっている | 残す工程の担当がいない |
| 一つの型・一つの工程で三か月回し、記録で効いたかを見てから広げる | 最初から全型・全工程 |

## 機能しない条件を変える順番

| 順 | 変えること | 費用 |
|---|---|---|
| 一 | 離職：退職面談の記録を集め、理由を分類 | かからない |
| 二 | 報酬：先に出すかを判断。表示の文言は専門家と | 専門家の確認 |
| 三 | 資格：会社と専門家で区分を整理 | 専門家の確認 |
| 四 | 店舗：観点と記録の形を一枚に。店長の枠 | かからない |
| 五 | 記録：一覧を社内の環境に、店舗の列を | かからない |
| 六 | 工程：任せる工程を一つに絞る（一次対応と日程から） | 契約の範囲が小さくなる |
| 七 | 経路：型と職種で分ける | かからない |

一・四・五・七は発注の前に社内で変えられます。二と三は専門家の確認が要り、六は契約の設計です。

## 機能しているかを見る記録

| 見ること | 機能している目印 |
|---|---|
| 早期離職の件数と募集の回数 | 減っていれば離職が機能 |
| 辞退の理由 | 「報酬」「条件」が減っていれば報酬が機能 |
| 担える業務が限られた件数 | ゼロなら資格が機能 |
| 店舗ごとの日数と通過の記録の差 | 差が小さければ店舗が機能 |
| 型ごとの応募の数 | 偏りが減っていれば経路が機能 |

件数のまま並べ、前の募集と比べます。割合や外部の平均で断定しません。見る指標は[採用代行との定例会で見るべき数字](/media/rpo-teirei/)に書いています。

## まとめ

- 代行が機能するかは**代行の腕より発注側の条件**で決まる
- 七つの対は**報酬・離職・資格・店舗・経路・記録・工程**
- 最も多い機能しない条件は**離職の扱い**。「営業は辞めるもの」をやめ、理由を分けて求人票と受け入れを直してから代行に
- **報酬の形と資格は会社と専門家**。個別の判断は専門家にご確認ください
- **「全部任せたい」は機能しない**。本部は報酬・資格・観点の一枚・条件に、店長は週に一枠と受け入れに絞る
- 変える順番は**離職→報酬→資格→店舗→記録→工程→経路**
- 店舗をまたぐ記録が一つになると、**どの店舗で詰まっているか**が見える

## よくある質問

### 店舗の数が多く、全店舗の店長に一枚を渡して回る気がしません

一枚は「観点三つ・記録の欄」だけの短いもので、店長ごとに五分の読み合わせで足ります。全店舗を同時にせず、詰まりの大きい店舗から順に、代行の担当者が読み合わせを担います。一枚が店舗に残れば、店長が替わっても基準は残ります。全店舗を一度に揃えようとして止まるより、一店舗ずつ広げるほうが、結果として早い。

### 成果の報酬の比率が高く、応募が減るのが怖くて形を出せません

出さずに集めると、面接と入社後に辞退と離職で減り、結局は同じです。出せば応募は減り、その形で働く人だけが来て、定着します。「応募の数」と「入社と定着」のどちらを成果にするかは会社の判断です。判断の材料として、辞退の理由（「報酬」が何件か）と早期離職の理由（「報酬の形が聞いていたのと違う」が何件か）を記録で並べます。表示の文言は専門家の確認を経た内容にします。

### 管理の部門は営業と違い、離職も少ないのに採れません

管理の課題は、離職ではなく経路と要件のことが多い。「管理の経験者」ではなく「〇〇の型の物件の〇〇（入居者対応・修繕・オーナー対応など）を、〇〇の戸数の規模で担った経験」に要件を絞り、経路を掲載型と紹介会社に置き、資格の扱いを区分で書きます。営業と同じ媒体で同じ文面では届きません。型ごとに分けることが、管理の採用の機能する条件です。
