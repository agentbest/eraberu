選考が進んでから「志望度が低い」「他社に決めそうだ」と依頼側が焦り、最終面接で経営者が会社の魅力を熱く語る。それでも辞退される。「口説く」は、候補者の迷いに答えていないので効きません。動機づけは、熱意を伝えることではなく、候補者がなぜ動き、何で迷っているかを知り、それに選考の各段で答えることです。結論を先に書くと、**動機づけの設計は、ターゲット像の「動く理由」と「迷う理由」を出発点に、面談・一次・二次・最終・内定後の各段で「誰が、何を渡すか」を決め、見極めと動機づけを同じ人が同じ時間にやらない形にし、候補者の迷いを記録から拾って次の段に渡し、盛らず・約束せず・急かさずに行います。**ターゲット像の作り方は[ターゲット像を1枚にまとめる](/media/fukugyo-skill-persona/)に、面接の設計は[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)に書いています。ここでは、動機づけの型に絞ります。

## 「口説く」が効かない理由

| 口説き方 | 候補者に起きること |
|---|---|
| 会社の魅力を長く語る | 候補者はすでに知っている。迷いには答えていない |
| 「あなたが必要だ」と熱意 | 全員に言っていると分かる |
| 条件を上げる | 条件で迷っていない人には効かない。条件で迷っている人にも「なぜ最初から出さなかったか」と不信 |
| 最終で経営者が一気に | 遅い。迷いは一次から積み上がっている |
| 「早く決めてほしい」 | 急かされて引く |

候補者は、「自分の迷いに答えてくれたか」で決めます。迷いは人によって違い、選考の途中で変わります。だから、各段で聞き、各段で答える設計が要ります。

## 出発点は「動く理由」と「迷う理由」

| 一枚の欄 | 動機づけでの使い方 |
|---|---|
| 動く理由 | 各段で「それがここにある」と、実例で示す。言葉ではなく、任せる仕事・一緒に働く人・最初の三か月で |
| 迷う理由 | 各段で先回りして触れる。候補者が口にする前に、「〇〇を気にされる方が多いのですが」と |
| 比べる相手 | 比べる相手に無いものを、押しつけずに一つだけ |
| 決め手 | 最終と内定後で、決め手になる情報と人を用意する |

ターゲット像の一枚は推測から始まるので、各段で候補者から聞いた迷いで書き換えます。書き換えた迷いが、次の候補者の動機づけの材料になります。

### エラベルの見解

担当する側から見ると、動機づけで最も差がつくのは、「見極めと動機づけを、同じ人が同じ時間にやらない」形にできるかです。一次面接で、面接官が観点を確かめながら会社の魅力も語ろうとすると、どちらも薄くなり、候補者は「見られている」と感じて迷いを口にしません。見極めの段では見極めに徹し、動機づけは面談（カジュアル面談）と各段の最後の時間、内定後の接点に置く。役割を分けると、面接官の負担も減ります。エラベルで担当者を選ぶ企業には、「面接で、見極めと動機づけを同じ人が同時にやっていませんか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、各段の一枚に「この段で渡すこと（動機づけ）」の欄を作り、「この段で確かめること（見極め）」と分けて書くこと。同じ欄に混ぜないだけで、面接官の動きが変わります。

## 段ごとの設計

| 段 | 誰が | 渡すこと（動機づけ） | 聞くこと（迷いを拾う） |
|---|---|---|---|
| カジュアル面談 | 現場の責任者か、いまうまくやっている人 | 役割の実態。動く理由に対応する実例 | 「何を知りたいか」「何で迷いそうか」 |
| 一次 | 現場の責任者 | 見極めに徹する。最後の数分で、任せる仕事と最初の三か月を具体に | 候補者の質問。記録の「質問と迷い」の欄に |
| 二次 | 一緒に働く人 | 一緒に働く人の実感。前の段で出た迷いに、現場の言葉で答える | 二次で新しく出た迷い |
| 最終 | 経営者 | 決め手。会社の方針と、この人にこの役割を任せる理由。前の段の迷いのうち、経営者しか答えられないものに答える | 最後に残っている迷い |
| 内定後 | 依頼側の採用担当と、現場の責任者 | 迷いへの答えの続き。一緒に働く人との接点。入社までの見通し | 他社の状況、決めるための不足 |

各段の「聞くこと」が、次の段の「渡すこと」になります。記録の「候補者の質問と迷い」の欄が、この橋渡しです。評価シートの型は[評価シートを作る](/media/fukugyo-skill-hyouka-sheet/)に書いています。カジュアル面談の設計は[カジュアル面談を設計する](/media/fukugyo-skill-casual/)に書いています。

## 候補者の迷いを記録から拾う

| 迷いの出どころ | 拾い方 |
|---|---|
| スカウトの返信 | 最初に聞いてきたこと。[返信対応のテンプレート](/media/fukugyo-skill-henshin-taiou/)の記録 |
| 面談・面接の記録 | 「候補者の質問と迷い」の欄 |
| 日程調整のやり取り | 日程を延ばす、返事が遅れる、は迷いの目印 |
| 辞退の理由 | 前の候補者の辞退の理由は、次の候補者の迷いの候補 |

拾った迷いは、候補者ごとに一行で、次の段の一枚の「この段で答えること」に書きます。氏名は媒体のIDか応募の番号で、迷いの要約だけです。迷いを聞き出すための問いは、面接の観点とは別で、「今日の話で、気になったことはありますか」「決めるために、足りない情報はありますか」の二つで足ります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「志望度が低い候補者は、動機づけで上げられる」というものです。実際には、動機づけで変わるのは「迷っている人」で、「動く理由が無い人」は変わりません。動く理由が無い人に時間をかけると、面接官は疲れ、動く理由がある人への対応が薄くなります。カジュアル面談と一次で「動く理由」が語れない候補者は、動機づけの対象ではなく、選考を進めるかどうかを依頼側が判断する対象です。受ける側がその場で使える判断としては、各段の記録に「動く理由（候補者の言葉）」を一行残し、空欄の候補者には動機づけの設計を厚くしないこと。厚くするのは、動く理由があって、迷いが具体な候補者です。

## 盛らない・約束しない・急かさない

| 避けること | 理由 | 代わりに |
|---|---|---|
| 実態より良い役割の説明 | 入社後にずれ、早期の離職につながる | 実例で。いまうまくやっている人の言葉で |
| 昇進や報酬の約束 | 保証できない。約束になると後で問題 | 「実績としてこういう例がある」まで。条件は依頼側が所定の形で |
| 「あなたしかいない」 | 全員に言っていると分かる | 「この役割にこの経歴が要る理由」を具体に |
| 「他社より早く決めて」 | 急かされて引く | 「決めるために足りない情報は何か」を聞き、渡す |
| 他社の悪口 | 候補者の判断を侮ることになる | 比べる相手に無いものを一つだけ、押しつけずに |

収入や昇進を保証するように読める表現、実態と異なる待遇の説明は、動機づけの場でも避けます。条件の提示は依頼側が所定の形で行い、担当者は口頭で条件に触れません。性別や年齢などに触れる言い回しも、募集や採用で法令上の決まりがあると一般に整理されているため、動機づけの会話でも使いません。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## 担当者が候補者に直接接する範囲

| 契約の範囲 | 担当者がやること |
|---|---|
| 設計のみ | 段ごとの一枚に「渡すこと」「聞くこと」を書く。面談・面接には出ない |
| 面談の同席あり | カジュアル面談で「聞くこと」を担う。見極めはしない |
| 内定後の接点あり | 依頼側の名義で、迷いへの答えの続きを渡す。条件と約束には触れない |

担当者が候補者に直接接する場合は、依頼側の名義で、答えてよい範囲を先に決めます。範囲は[返信対応のテンプレート](/media/fukugyo-skill-henshin-taiou/)の「答えてよい範囲と依頼側に渡す範囲」と同じです。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 最終で経営者が「口説く」だけになる | 最終の一枚に「前の段で出た迷いのうち、経営者が答えること」を書いて渡す |
| 迷いが記録に残っていない | 評価シートの「質問と迷い」の欄を作る。面接の最後の二つの問いを一枚に |
| 面接官が見極めと動機づけを同時にやる | 一枚の欄を分ける。「最後の数分で渡す」と時間を分ける |
| 動く理由が無い候補者に時間を使う | 記録の「動く理由」が空欄なら、選考を進めるかを依頼側に判断してもらう |
| 内定後に接点が無く辞退 | 内定後の「誰が、何を、いつ」を設計に足す。[内定辞退が続くときに見直す3点](/media/rpo-jitai-ooi/) |

## まとめ

- 「口説く」は迷いに答えていないので効かない。動機づけは**動く理由と迷う理由に各段で答える**こと
- 出発点は**ターゲット像の一枚**。各段で聞いた迷いで書き換える
- 段ごとに**誰が・何を渡し・何を聞くか**。前の段で聞いた迷いが、次の段で渡すこと
- **見極めと動機づけを同じ人が同じ時間にやらない**。一枚の欄を分ける
- 迷いは**記録から拾う**。「気になったこと」「足りない情報」の二つの問い
- 動機づけの対象は**動く理由があって迷っている人**。動く理由が無い人は依頼側の判断へ
- **盛らない・約束しない・急かさない**。条件は依頼側が所定の形で。個別の判断は専門家にご確認ください

## よくある質問

### 候補者が他社と比べていて、条件で負けそうです

条件で迷っているなら、条件の判断は依頼側です。担当者ができるのは、「候補者は条件の〇〇で迷っている」を依頼側に正確に渡すことと、条件以外の迷い（役割、一緒に働く人、次の転職での見え方）に答えることです。条件を上げるかどうかを担当者が示唆しません。条件以外の迷いに答え切ったうえで、それでも条件で決まるなら、それは候補者の判断です。

### 動機づけの設計をしたのに、辞退が減りません

辞退の理由を集めます。理由が「迷う理由」の一枚に無いものなら、ターゲット像の推測がずれていて、動機づけが的外れだった可能性があります。理由が「速さ」（他社が先に決まった）なら、動機づけではなく日程調整の問題です。理由が条件なら、条件の出し方の問題です。動機づけの設計が効くのは、迷いに答えられていなかった辞退だけで、全部の辞退には効きません。理由の集め方は[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に書いています。

### 副業の担当者が、候補者に直接動機づけをしてよいですか

契約の範囲によります。設計だけの契約なら、担当者は候補者に接しません。接する契約なら、依頼側の名義で、答えてよい範囲の中で、迷いへの答えを渡します。担当者が自分の言葉で会社を売り込むと、依頼側の意図と違う約束になることがあるので、渡す内容は依頼側と決めた実例に限ります。担当者にできて依頼側にできないことは、「迷いを聞き出すこと」のほうで、そこに役割を置くと、依頼側との分担が明確になります。
