「面接の数が多くて手が回らない。一次面接をやってもらえないか」。人事の副業では、こう頼まれることがあります。面接は、人事の経験がある人にとって慣れた業務で、依頼側にとっては最も時間を取られる工程です。ただ、面接の実施そのものを外部の人が担うと、候補者は「会社の人と話している」と思い、評価が副業の人の主観になり、合否や条件の判断まで求められます。結論を先に書くと、**面接代行は「設計・準備・記録・進行」と「評価の決定・合否・条件の提示」に分け、前者は受け、後者は依頼側に残す形で受ける**のが線です。面接を丸ごと引き受けるのではなく、依頼側が判断できる材料を面接から取り出す役に徹します。会社の代表として話す責任は[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/)に、判断の線全般は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)にまとめています。

## 面接代行の中身を分解する

「面接をやる」を分解すると、副業の人が受けられる部分と、受けない部分が見えます。

| 工程 | 内容 | 副業の人が受けられるか |
|---|---|---|
| 設計 | 見る点を三つに絞る、質問の案を作る、評価の型を作る | 受けられる。依頼側の要件に沿って |
| 準備 | 候補者の要約、日程調整、面接官への事前の共有 | 受けられる |
| 進行 | 面接の場で、時間を管理し、質問の順に沿って聞く | 条件付き。依頼側の担当が同席するか、進行役であることを候補者に示す |
| 記録 | 候補者の発言を、評価の型に沿って記録する | 受けられる。事実の記録に徹する |
| 評価の整理 | 記録を、見る点ごとに三段階と理由で整理する | 受けられる。ただし「整理」であって「決定」ではない |
| 評価の決定 | 候補者を通すか見送るかの評価を確定する | 受けない。依頼側の面接官か判断する人 |
| 合否の判断 | 次に進めるか、見送るか | 受けない。依頼側 |
| 条件の提示 | 年収、勤務条件、入社日 | 受けない。依頼側 |
| 候補者への結果連絡 | 通過・見送りの連絡 | 依頼側の判断のあと、依頼側の名前で。文面の下書きは受けられる |

分解の要点は、「進行は条件付き、評価の決定から先は受けない」ことです。面接の進行を副業の人が担う場合、候補者にはその人が会社の面接官に見えます。評価の決定まで担うと、副業の人の主観が合否を決める形になり、依頼側は判断の根拠を持てません。

## 依頼側と決める役割

面接代行を受けるとき、依頼側と決める役割を整理します。

| 項目 | 決めること | 型 |
|---|---|---|
| 面接の段階 | 一次だけか、二次以降も関わるか | 一次の進行と記録まで。二次以降は依頼側 |
| 同席 | 依頼側の担当が同席するか | 同席が基本。同席できない場合は、進行役として候補者に示す |
| 候補者への見え方 | 副業の人をどう紹介するか | 「採用担当の〇〇（役割）」。面接官としての評価者ではなく、進行と記録の役と示すか、依頼側と決める |
| 評価の型 | 見る点、段階、理由の書き方 | 依頼側の要件に沿って、副業の人が作り、依頼側が確認 |
| 評価の決定者 | 誰が確定するか | 依頼側の面接官か判断する人。副業の人は整理まで |
| 判断に迷う候補者 | どう扱うか | 判断する人に上げる。副業の人が決めない |
| 候補者の質問への対応 | 面接中に条件や社風を聞かれたら | 「担当から」か、同席の担当が答える。[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/) |
| 記録の置き場 | どこに残すか | 依頼側の環境の中。自分の側に残さない |

役割の要点は、「評価の決定者を、副業の人以外に決める」ことです。副業の人が記録と整理を出し、依頼側の誰かが確定する。この一段があるだけで、判断の責任は依頼側に残り、副業の人は材料の役に徹せます。

### エラベルの見解

登録の相談で多いのは、「一次面接を任され、自分の評価で通した候補者が二次で全員見送られ、依頼側から『見る目が無い』と言われた」という話です。副業の人の評価の基準と、依頼側の面接官の基準が違っていた。評価の型が無く、副業の人の主観で通していた。依頼側は、副業の人の評価を「会社の一次の判断」として扱い、結果が合わなかったときに副業の人に責任を向けました。

見ていて差がつくのは、「評価の型を、依頼側の要件から作っているか」です。見る点を三つ、各三段階、理由を一行。この型を依頼側の要件から作り、依頼側が確認し、面接ではその型に沿って記録する。副業の人の主観ではなく、依頼側の基準で整理された記録が出ます。エラベルの登録でも、面接代行を続けている人は、型で記録し、決定は依頼側に残しています。「見る目」ではなく「型」で仕事をしている人が、面接代行で信頼されています。

## 面接代行を受ける手順

面接代行を受けるときの手順を、番号付きで整理します。

1. **「面接をやってほしい」の中身を分解して聞く。** 設計か、進行か、評価か、合否か。依頼側は分けて考えていないことが多い。
2. **受ける部分と受けない部分を伝える。** 「設計・準備・進行・記録・評価の整理まで受けます。評価の決定と合否は御社でお願いします」。
3. **評価の型を、依頼側の要件から作る。** 見る点を三つ、各三段階、理由を一行。依頼側が確認。[現場との関係の作り方](/media/fukugyo-genba-chousei/)
4. **候補者への見え方を決める。** 進行役として示すか、面接官の一人として示すか。名義は[どの名義で候補者に接するか](/media/fukugyo-daimei/)
5. **同席の有無を決める。** 依頼側の担当が同席する形が基本。できない場合は、面接中の質問への対応を決める。
6. **面接では、型に沿って質問し、記録する。** 候補者の発言を事実として記録。自分の印象は「所感」として分けて書く。
7. **面接後、記録を型に沿って整理し、依頼側に渡す。** 整理であって決定ではない、と明記。
8. **判断に迷う候補者は、判断する人に上げる。** 「見る点の一と二が高く、三が低い。判断をお願いします」。
9. **合否と結果連絡は依頼側。** 文面の下書きは受けられる。
10. **区切りで、型の精度を見直す。** 一次で通した候補者が二次でどうなったか。型を直す。

手順の要点は、「六で、事実と所感を分けて記録する」ことです。「経験が浅そうだった」は所感で、「〇〇の経験は一年と回答」は事実です。事実を型に沿って記録し、所感は別の欄に。依頼側は事実で判断でき、所感は参考にとどまります。

## 候補者への見え方

面接の進行を副業の人が担うとき、候補者にどう見えるかと、その扱いを整理します。

| 見え方 | 起きること | 扱い |
|---|---|---|
| 会社の面接官 | 副業の人の言葉が会社の言葉になる。評価者だと思われる | 話してよいこと一覧の範囲で。条件や社風は「担当から」 |
| 進行役 | 「この人は進行で、評価は別の人」と分かる | 冒頭で「本日は私が進行し、〇〇（担当）が同席します」と示すと、候補者は役割を理解する |
| 外部の人 | 依頼側が「外部の採用支援の方」と紹介した場合 | 候補者が「なぜ外部の人が」と思うことがある。依頼側と、紹介の仕方を決める |

見え方の要点は、「進行役として示す」形が、候補者にも副業の人にも無理がないことです。会社の面接官として振る舞うと、言葉の責任が重くなり、外部と示すと候補者が戸惑う。進行と記録の役として示し、評価は同席の担当か後の判断者、と伝えれば、候補者は自然に受け取ります。

## 面接代行で起きる失敗

面接代行に特有の失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 面接を丸ごと引き受ける | 「面接をやって」をそのまま受ける | 分解して、受ける部分と受けない部分を伝える |
| 評価の型を作らずに面接する | 経験があるので型が無くてもできる | 型を作る。主観ではなく依頼側の基準で |
| 自分の評価で通す・見送る | 一次は任されたと思う | 整理まで。決定は依頼側 |
| 事実と所感を混ぜて記録する | 印象が強い | 事実は型に、所感は別欄に |
| 面接中に条件や社風を答える | 候補者に聞かれる | 「担当から」。同席の担当が答える |
| 候補者に外部だと言わずに面接官として振る舞い、後で外部と分かる | 依頼側と見え方を決めていない | 見え方を決める。進行役として示す |
| 判断に迷う候補者を自分で決める | 判断する人が忙しい | 上げる。決めない |
| 一次の結果が二次と合わないのに型を直さない | 振り返りが無い | 区切りで型を見直す |
| 面接の稼働を時間で読まない | 面接は一件三十分でも、準備と記録で倍かかる | 準備と記録の時間を稼働に含める |
| 記録を自分の側に残す | 後で見返したい | 依頼側の環境の中に。[情報の取り扱いと端末の分離](/media/fukugyo-security/) |

失敗の要点は、「自分の評価で通す・見送る」が最も重い失敗だという点です。一次面接を任されると、通す・見送るを自分が決めていると思いがちですが、副業の人が決めると、判断の責任が副業の人に移り、結果が合わなかったときに責任を向けられます。整理まで、と線を引きます。

### エラベルの見解

担当する側として登録した人の話を聞くと、面接代行で続いている人は、自分を「面接官」ではなく「面接の設計者と記録者」と位置づけています。型を作り、進行し、事実を記録し、型に沿って整理し、決定は依頼側に渡す。依頼側から見ると、面接の質が上がり（型があるので評価がぶれない）、面接の負担が減り（準備と記録を副業の人が担う）、判断の根拠が残る（記録が事実で書かれている）。面接官として評価まで担う副業の人より、設計と記録に徹する副業の人のほうが、依頼側の評価は高い。

依頼側から見ると、面接を外部の人に任せることは、候補者との接点と判断の両方を外に出すことで、不安が大きい工程です。エラベルは、企業と担当者の間に立つ窓口として、面接に関わる案件では、担当者の役割を設計・準備・進行・記録に限り、評価の決定と合否は依頼側に残す形をお伝えしています。面接代行を「面接を代わりにやる」ではなく「面接から判断の材料を取り出す」役として受けていただくことをお勧めしています。

## まとめ

- 面接代行は**設計・準備・進行・記録・評価の整理**と**評価の決定・合否・条件の提示**に分け、前者を受け、後者を依頼側に残す
- 進行は**条件付き**（担当の同席か、進行役として候補者に示す）。評価の決定から先は受けない
- 依頼側と決めるのは**段階・同席・候補者への見え方・評価の型・決定者・迷う候補者の扱い・質問への対応・記録の置き場**
- 面接では**型に沿って質問し、事実と所感を分けて記録**。整理であって決定ではないと明記
- 候補者には**進行役として示す**形が無理がない
- 最も重い失敗は**自分の評価で通す・見送る**。「見る目」ではなく「型」で仕事をする

## よくある質問

### 依頼側が「一次の合否はあなたが決めていい」と言います

決めません。「一次の合否を私が決めると、判断の責任が私に移り、二次で合わなかったときに御社が根拠を持てなくなります。私は型に沿って記録と整理を出し、合否は御社のどなたかに確定していただく形でお願いします」と伝えます。依頼側が「そこまでの時間が無い」と言うなら、整理を「通過推奨・要判断・見送り推奨」の三つに分けて出し、「通過推奨と見送り推奨は御社の確認だけ、要判断だけ御社が判断」という形にすると、依頼側の負担は小さく、決定は依頼側に残ります。

### 面接中に候補者から条件を聞かれました。同席の担当がいません

「条件については、次の面接で担当から詳しくお伝えします。今日は経験とご希望を伺わせてください」と返し、面接後に依頼側の担当に「候補者から条件の質問がありました」と共有します。同席の担当がいない面接は、この場面が起きることを想定して、「条件・社風・評価に関する質問は担当から」という返し方を、面接の前に決めておきます。それでも候補者が納得しないなら、「面接後に担当から連絡します」と引き取り、依頼側に対応してもらいます。[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/)を参照してください。

### 一次で通した候補者が、二次で全員見送りになりました

型の精度の問題か、一次と二次で見ている点が違うかのどちらかです。区切りで、一次の記録と二次の評価を並べ、どこがずれているかを依頼側と見ます。一次の型に、二次で見ている点が入っていなければ、型に足す。一次の三段階の基準が甘ければ、基準を直す。「見る目が無い」という話にせず、「型のここがずれていた」という話にすると、依頼側も一緒に直せます。型で仕事をしていれば、直すのは型で、自分の評価ではありません。
