面接代行を初めて受けるとき、見えにくいのは「面接の前後に何があるか」です。募集文には「面接官業務」とだけあり、実際には、要件の確認、質問と評価の型の承認、候補者への名乗り方の決定、記録の置き場、評価の整理の渡し方、面接後の連絡の担当と、面接そのものの前後に工程が付きます。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→第1週→第2週以降→月次→終了と更新」の五つの段階で進み、契約前に範囲・面接の枠と数・候補者への見え方・評価の決定者・記録の置き場・聞いてはいけないこと・報告を決め、第1週は面接に出ずに要件の確認と型の承認と面接官との打ち合わせに使い、第2週から面接の進行と記録と評価の整理と週次の報告を回し、月次で二次以降や入社後のずれから質問と深さを直し、引き継げる形で終えます。**案件の型と求められる経験は[面接代行の副業案件](/media/fukugyo-mensetsu-daikou-fukugyo/)に、事故を避ける線は[面接代行で気をつけること](/media/fukugyo-mensetsu-daikou-chuui/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

面接代行は、候補者の前に立つ仕事です。名乗り方と評価の決定者が決まっていないまま面接に出ると、その場で困ります。契約前に決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 型作りだけか、進行と記録か、同席と記録か、育成か。評価の整理までで、決定は含まないこと | 「通す人を決めてほしい」が後から足される |
| 面接の枠と数 | 週に何枠、どの曜日と時間帯か。一回の面接の時間と、記録の時間 | 直前の日程変更が重なり、本業に響く |
| 候補者への見え方 | 外部の進行役として名乗るか、同席の一人として紹介されるか。社員を装う形は受けない | 候補者に「御社では」と聞かれて困る |
| 評価の決定者 | 会社側の誰が、整理を読んで、いつまでに決めるか | 整理が読まれず、候補者への連絡が遅れる |
| 記録の置き場 | 会社の管理する場所。録音や録画の扱いと候補者の同意 | 記録が自分の端末に残る |
| 聞いてはいけないこと | 会社の一覧があるか。無ければ作るか | 法令上の論点に触れる質問をしてしまう。専門家にご確認ください |
| 次の連絡の担当 | 面接後、候補者に誰がいつ連絡するか | 候補者が放置される |
| 報告 | 週次か、形式、誰が読むか。入社後のずれの共有を受けられるか | 型が直せず、実績にもならない |

止まりやすいのは、「まず来週の面接に出てください」で始めるときです。名乗り方と評価の決定者と記録の置き場だけは、面接に出る前に決めます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に書いています。

## 第1週：面接に出ない週

第1週は、面接に出ません。要件の確認と、質問と評価の型の承認と、面接官との打ち合わせに使います。一般的な質問表で面接に出ると、会社が判断できる記録になりません。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 要件の確認（必須と歓迎、いまうまくやっている人の共通点、入社後にずれた人の傾向、この段階で何を見るか） | 現場の責任者が出る時間。過去の面接の記録 | 人事だけから聞いて、現場が見たい項目が抜ける |
| 質問と評価の型の設計（項目、聞く順、掘る深さ、時間の配分） | 型の承認 | 「志望動機」「強みと弱み」だけの表になる |
| 記録の型（事実・所感・確認が要る点の三つの欄。項目ごと） | 置き場の確定 | 所感だけの記録の型 |
| 聞いてはいけないことの確認 | 一覧の共有か作成 | 一般常識で分かると思って確認しない |
| 面接官との打ち合わせ（同席する場合。役割の分担、質問の順、記録の担当） | 面接官の時間 | 面接官と初対面で面接に入る |
| 名乗り方と、候補者に伝えてよいことの一覧 | 一覧の共有 | 当日に候補者から会社のことを聞かれて答えられない |
| 模擬面接（可能なら会社の社員を相手に一度） | 社員の時間 | 初回の面接が本番 |

止まりやすいのは、「面接の経験があるから型は要らない」と第1週を飛ばすときです。型は自分のためではなく、面接官ごとのばらつきを無くし、会社が判断できる記録を渡すためのものです。要件の聞き方は[質問の仕方](/media/fukugyo-shitsumon-shikata/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「第1週に面接に出ない」ことを会社に納得してもらえるかで、その後の難易度が決まります。会社は面接官が足りず、来週の面接を埋めたい。そこで担当者が押されて型の無いまま面接に出ると、記録が所感になり、通した人が入社後にずれたときに「外の人の見る目のせい」で終わります。エラベルで担当者を選ぶ企業には、「最初の一週間は要件と型の承認に使い、面接は二週目から入ります」と、私たちから先に伝えています。受ける側がその場で使える判断としては、契約前の稼働の計画に「第1週は面接に出ない。要件の確認と型の承認と面接官との打ち合わせに使う」と書いて渡すこと。どうしても初週から面接を求められるなら、会社の面接官が主で自分は同席と記録、という形にして、型は並行して作ります。

## 第2週以降：進行・記録・評価の整理・週次の報告

第2週から面接に出ます。ここからは、進める、聞く、記録する、整理を渡す、の繰り返しです。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 面接前の準備（応募書類を読み、型の項目ごとに掘る点を決める） | 面接ごとに、直前ではなく前日まで | 応募書類を読まずに入り、書いてあることを聞く |
| 進行（名乗り、流れの説明、型に沿って聞く、時間内に全項目、候補者の質問を受ける、次の連絡の時期を伝える） | 面接ごと | 話が盛り上がって型を外れ、項目が抜ける |
| 記録（事実・所感・確認が要る点。項目ごと。面接中にほぼ埋める） | 面接中と直後 | 後回しにして事実が所感に置き換わる |
| 評価の整理を渡す（項目ごとの事実、所感、確認が要る点。決定は会社） | 面接の当日か翌日まで | 「通過でよいと思います」と決定に踏み込む |
| 次の連絡の担当への引き渡し（候補者から出た質問、伝えた次の連絡の時期） | 整理と同時に | 候補者が放置される |
| 週次の報告（面接の数、整理を渡した数、決定の遅れ、候補者から多かった質問、型の直したい点一つ） | 週に一度、決めた曜日 | 数字だけで、型の何を直すかが無い |

止まりやすいのは、整理の最後に「通過でよいと思います」と書くときです。決定は会社です。書くなら「必須の項目はすべて事実で確認できました。確認が要る点は〇〇です」と、事実と確認点で終えます。合否への関わり方は[合否にどこまで関わるか](/media/fukugyo-gouhi/)に、報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

## 月次：二次以降と入社後のずれから型を直す

月に一度、会社と見直しの時間を持ちます。見るのは、通過率ではなく、「一次で通した人が二次以降や入社後にどうずれたか」と「確認が要る点が多い項目はどこか」です。

| 見ること | 直すところ |
|---|---|
| 一次で通した人が二次で見送られた理由 | 一次の型に足りない項目か、掘る深さ。二次の面接官が見ている項目を一次の型に足す |
| 入社後にずれた人の共通点（共有を受けられる場合） | 面接で掘り切れていなかった項目。質問の深さを直す |
| 確認が要る点が多い項目 | 質問の立て方が浅い。掘る手順を型に書き足す |
| 候補者から多かった質問 | 会社が事前に伝える情報の不足。会社に返す |
| 決定の遅れ | 決める人と期限の見直しを会社に提案 |

止まりやすいのは、月次で「もっと厳しく見ます」と感覚で調整するときです。厳しくしても精度は上がりません。型に戻し、足りない項目を足すか、掘る深さを直します。一度に全部を変えず、一つずつ変えて比べます。

### エラベルの見解

同じ料金・同じ面接の数でも、結果が分かれるのは、月次の見直しで「二次以降の面接官が見ている項目を一次の型に取り込むか」です。一次で通した人が二次で見送られ続けるとき、「一次の見る目が甘い」と感覚で締める担当者は、通過が減って面接の枠が無駄になり、三か月目に「効果が無い」と契約を終えられます。二次で見送られた理由を一人ずつ聞いて、「二次の面接官は〇〇の項目を見ています。一次の型に無いので足します。一次で掘っておけば二次の時間が減ります」と型の言葉で返す担当者は、次の月から二次の通過が上がり、面接官の時間も減ります。エラベルで長く続いている担当者は、月次の報告に「二次以降で見送られた理由」と「一次の型に足す項目」の二つの欄を持っています。受ける側がその場で使える形としては、二次の結果を共有してもらう約束を契約前に入れ、見送られた理由を一人ずつ記録の表に足しておくこと。月次には、それを並べるだけで提案になります。

## 終了と更新：引き継ぎと次の提案

契約の期間が来たら、更新か終了かを会社が決めます。どちらでも、引き継げる形にして終えます。

- **残すもの。** 質問と評価の型（承認されたもの、月次で直した履歴）、記録の型、聞いてはいけないことの一覧、候補者に伝えてよいことの一覧、二次以降で見送られた理由と一次の型に足した項目の一覧
- **返すもの。** 採用管理システムなどの権限、共有された資料。面接の記録と候補者の情報は自分の手元に一切残さない
- **次の提案。** 更新するなら、次の期間で直す型。終了するなら、社内の面接官が型で回せるようにする育成の工程と手順書

引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 候補者の情報の扱い

面接代行は、応募書類と面接の記録という個人情報を扱う仕事です。応募書類は会社の管理する場所でだけ読み、記録も会社の管理する場所に置き、自分の端末やクラウドに残しません。録音や録画は、会社の決まりと候補者の同意に従い、自分の端末で録らないことを基本にします。候補者が面接で話した内容を、会社の外で話しません。聞いてはいけないことに当たる話が出ても、記録に残しません。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[セキュリティの基本](/media/fukugyo-security/)に書いています。個別の判断は専門家にご確認ください。

## 稼働時間は何で決まるか

週に何時間かかるかは、面接の数と、一回あたりの「準備＋面接＋記録と整理」の時間で決まり、週次の報告と月次の見直しが足されます。面接そのものの時間は全体の一部で、準備と記録を含めると倍近くになることが多い。受ける前に、「一回の面接に、準備と記録でどれだけ足すか」と「週の枠の数」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、最初の一か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→第1週→第2週以降→月次→終了と更新**の五つの段階
- 契約前に**範囲・面接の枠と数・候補者への見え方・評価の決定者・記録の置き場・聞いてはいけないこと・次の連絡の担当・報告**を決める。名乗り方と決定者と記録の置き場は面接に出る前に
- 第1週は**面接に出ない**。要件の確認と型の承認と面接官との打ち合わせに使い、そのことを稼働の計画に書いておく
- 第2週以降は**前日までに準備→型に沿って進行→事実・所感・確認が要る点で記録→当日か翌日に整理を渡す→次の連絡の担当に引き渡す**。「通過でよいと思います」と書かない
- 月次は**二次以降や入社後のずれ**から、一次の型に足す項目と掘る深さを直す。感覚で厳しくしない
- 終了時は**型・記録の型・一覧・ずれと足した項目**を残し、記録と候補者の情報を手元に一切残さない
- 候補者の情報は**会社の管理する場所でだけ扱い、録音は会社の決まりと同意に従う**

## よくある質問

### 面接の直前に日程が変わることが多く、本業に響きます

契約前に、面接の枠を曜日と時間帯で固定し、「枠の外の面接は受けない」「変更は前日の何時まで」と決めます。決めていない案件では、候補者の都合に合わせて会社が枠を動かし、外の担当者がそれに合わせる形になります。枠を固定すると候補者との調整が難しくなる会社もあるので、そのときは枠を少し広く取り、その中で調整してもらいます。固定できない案件は、進行と記録の型ではなく、型作りか育成の型に変えます。

### 面接中に、候補者から年収や合否の見込みを聞かれました

「条件と選考の結果は、会社からご連絡します。次の連絡は〇日頃です」と返し、質問があったことを記録して会社に渡します。外部の進行役として名乗っていれば、この返し方は自然です。見込みを口にすると、会社の判断と違ったときに候補者との間で約束になります。年収の幅など、会社が「候補者に伝えてよい」と決めた情報があれば、その範囲は答えられるので、第1週に一覧をもらっておきます。

### 一次で通した人が二次でほとんど見送られます

一次の型に、二次の面接官が見ている項目が無いことが多い。二次で見送られた理由を一人ずつ聞き、二次の面接官が使っている項目を一次の型に足します。「一次の見る目が甘い」と締めるのではなく、項目と深さを直します。二次の結果の共有を受けられない案件では、この直しができないので、契約前に共有の約束を入れます。共有が無いまま「通過率を下げてほしい」と言われたら、何の項目で下げるのかを会社に決めてもらいます。
