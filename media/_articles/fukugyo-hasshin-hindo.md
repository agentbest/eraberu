発信を始めてみたが、毎日書いている人を見ると自分の頻度では足りない気がする。一方で、本業と副業の合間に毎日は無理で、始めても止まりそうだと感じる。結論を先に書くと、**人事の副業の発信は、頻度で決まるのではなく、止まらないことで決まります。頻度は「本業の繁忙期でも守れる間隔」を上限にし、案件の稼働を削らない範囲で決めます。**毎日書いて三か月で止まるより、二週間に一度を一年続けるほうが、依頼側からは「続けている人」に見え、発信が案件の入口として機能します。止まること自体は珍しくないので、止まったときの再開の形も先に決めておきます。発信の進め方は[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/)に、書く内容の見つけ方は[発信のネタの見つけ方](/media/fukugyo-hasshin-neta/)に、書いてはいけない線は[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)にまとめています。

## 頻度より続くことが効く理由

発信が案件につながる仕組みを見ると、頻度が効く場面は限られています。

| 依頼側が発信を見る場面 | 何を見ているか | 頻度の効き方 |
|---|---|---|
| 登録先や紹介で候補に上がった後、発信を確認する | この人はどう考える人か。依頼側の話を外に出さない人か | 直近の投稿が数本あれば足りる。毎日は要らない |
| 発信を見て問い合わせようと思う | 判断の仕方が自分たちの状況に合うか | 内容が効く。頻度は「最近も書いているか」の確認程度 |
| 過去に見た発信を思い出して声をかける | 「あの考え方の人」として記憶に残っているか | 続いていることが効く。長い期間、同じ考え方で書いていること |
| 最終の投稿が古い | 「もう副業をしていないのでは」と思う | ここで頻度ではなく「止まっていないか」が効く |

効く仕組みの要点は、「止まっていないこと」が「頻度が高いこと」より依頼側に見えることです。依頼側は、毎日投稿しているかを数えません。直近の投稿がいつかと、内容が判断の仕方かを見ます。毎日投稿して止まった人の発信は、最終の投稿が古い時点で「止まった人」に見えます。二週間に一度でも続いていれば、「続けている人」に見えます。

## 頻度の上限を稼働から決める

頻度は、書きたい気持ちではなく、本業と副業の稼働から決めます。発信の稼働は、副業の稼働の一部です。

| 手順 | 内容 |
|---|---|
| 一、副業の稼働の上限を確認する | 月に副業に使える時間の上限。案件の稼働が優先で、発信はその余り。[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/) |
| 二、本業の繁忙期の稼働を見る | 一年で最も本業が忙しい月に、副業に使える時間はどれだけか |
| 三、一本にかかる時間を測る | 短い投稿なら数分、記事なら数時間。実際に書いて測る |
| 四、繁忙期の余りで書ける本数を出す | 繁忙期の副業の余りの時間を、一本の時間で割る。それが繁忙期に書ける本数 |
| 五、その本数を年間の頻度にする | 繁忙期に書ける本数で、一年を通す。閑散期に増やさない |

決め方の要点は、「繁忙期の本数で通す」ことです。閑散期に多く書き、繁忙期に止まると、依頼側から見て「止まった」になります。繁忙期でも書ける本数を通年の頻度にすれば、止まりません。閑散期に余った時間は、投稿を書き溜めて繁忙期に出す形に使えます。本業の繁忙期の副業の回し方は[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「発信の頻度が低いと、依頼側に熱意が無いと思われる」というものです。実際には、依頼側の担当者が発信の頻度を熱意の指標として見ている例は、見ている限りありません。依頼側が見ているのは、発信の内容が判断の仕方になっているかと、直近の投稿が止まっていないかの二つで、頻度が高いことで評価が上がることはほとんどありません。

むしろ、頻度が高い発信で、内容が出来事の記録になっている人は、依頼側から「うちのことも書かれる」と警戒されます。毎日書こうとすると、判断の仕方だけでは書くことが無くなり、出来事に手が伸びます。頻度を落として、一本ずつ判断の仕方として書くほうが、依頼側の信頼につながります。エラベルでは、担当者の発信を依頼側に提示することはありませんが、依頼側が自分で確認したときに、頻度ではなく内容で判断している様子が見えています。

## 場所ごとの目安の考え方

発信の場所によって、一本の重さと、止まったときの見え方が違います。場所ごとに頻度の考え方を変えます。

| 場所 | 一本の重さ | 止まったときの見え方 | 頻度の考え方 |
|---|---|---|---|
| 短い投稿のSNS | 軽い。数分で書ける | 最終投稿の日付が目立つ。数週間空くと「止まった」に見える | 短い間隔で、一本を軽く。書き溜めが効く。[Xでの発信のしかた](/media/fukugyo-x-unyou/) |
| 記事のサービス | 重い。数時間かかる | 数か月空いても「止まった」には見えにくい | 長い間隔で、一本を厚く。[noteで実績を見せる](/media/fukugyo-note/) |
| 経歴の一覧の場所 | 更新は稀 | 止まっていても気にされない | 範囲や経歴が変わったときだけ。[LinkedInのプロフィール整備](/media/fukugyo-linkedin/) |
| 自分のサイト | 更新は稀 | 「最終更新」を出さなければ気にされない | 年に数回。[自分のサイトは要るか](/media/fukugyo-hp/) |

場所の要点は、「短い投稿の場所は止まると目立ち、記事の場所は目立たない」ことです。両方をやると、短い投稿の頻度に引きずられて稼働が足りなくなります。稼働が限られるなら、記事の場所を軸にし、短い投稿は記事の告知だけにすると、止まったときに目立ちにくくなります。

## 頻度を上げて起きること

頻度を上げると、届く範囲は広がりますが、副業の場合は別のことも起きます。

| 起きること | 内容 |
|---|---|
| 案件の稼働が削られる | 発信の時間が案件の時間を圧迫し、依頼側への稼働が下がる。依頼側から見れば、担当者が発信に時間を使っている状態 |
| 内容が出来事に寄る | 判断の仕方だけでは書くことが尽き、案件の出来事を書き始める。五つの線を越えやすくなる |
| 本業の関係者に見つかりやすくなる | 投稿が増えると、検索や共有で本業の関係者の目に触れる機会が増える |
| 止まったときの落差が大きい | 毎日から突然止まると、「何かあったのか」と見える。低い頻度から止まるより目立つ |
| 発信が目的になる | 案件のための発信が、発信のための発信になり、案件の稼働より優先される |

起きることの要点は、「案件の稼働が削られる」ことです。発信は案件の入口ですが、いま受けている案件の稼働より優先されるものではありません。依頼側から見て、担当者の発信が増えて稼働が下がっていれば、次の更新に響きます。発信の頻度は、案件の稼働の余りで決まるもので、逆ではありません。

## 止まったときの再開の形

発信は止まります。本業の繁忙、案件の山、体調で、数週間から数か月空くことは珍しくありません。止まることを前提に、再開の形を決めておきます。

| 決めること | 内容 |
|---|---|
| 止まった理由を書かない | 「しばらく空いてしまいました」と書かない。空いたことに触れず、いつもの投稿を出す |
| 再開の一本目を先に用意しておく | 止まる前に、再開用の一本を書き溜めておく。再開のときに書く負担を無くす |
| 頻度を下げて再開する | 止まる前と同じ頻度に戻そうとしない。止まった理由が続いているなら、頻度を下げる |
| 止まっている間の見え方を整えておく | プロフィールに範囲と経歴が書かれていれば、投稿が止まっていても「何をしている人か」は分かる。[プロフィールの書き方](/media/fukugyo-profile/) |
| 止まることを稼働の計画に入れる | 「繁忙期は止める」と最初から決めておけば、止まっても計画どおり |

再開の要点は、「止まった理由を書かない」ことです。空いたことを謝ると、読む側は「止まっていた」ことに気づきます。触れずにいつもの投稿を出せば、読む側の多くは気づきません。再開の一本目を先に用意しておけば、止まった後に「何を書くか」から考える負担が無く、再開しやすくなります。

## 頻度を落としてよい時期

頻度を落とすことは、失敗ではなく、稼働の調整です。落としてよい時期を決めておきます。

| 時期 | 理由 |
|---|---|
| 本業の繁忙期 | 副業の稼働そのものが減る。案件を優先し、発信は止めてよい |
| 案件の稼働が上限に近い | 案件が忙しいなら、発信の入口は要らない時期。案件に集中する。[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/) |
| 案件の立ち上げの時期 | 新しい案件の最初の数週間は稼働が読めない。[案件の最初の時期の進め方](/media/fukugyo-shoki-90nichi/) |
| 発信が出来事に寄り始めたとき | 書くことが尽きて出来事を書き始めたら、頻度を落として、判断の仕方に戻す |
| 続けるか迷っているとき | 副業を続けるか迷っているなら、発信の頻度を上げても意味が無い。先に続けるかを決める |

時期の要点は、「案件の稼働が上限に近いときは発信を落とす」ことです。発信は次の案件の入口なので、いま案件で手一杯なら、入口を広げる必要はありません。案件が落ち着いたら、頻度を戻します。この上げ下げを、稼働の計画として最初から入れておくと、迷わずに済みます。

### エラベルの見解

担当する側から見ると、発信が長く続いている人は、頻度を決めるときに「書ける本数」ではなく「止まらない本数」で決めています。書ける本数で決めると、閑散期の本数になり、繁忙期に止まります。止まらない本数で決めると、繁忙期の本数になり、通年で続きます。続いている人の頻度は、周りから見ると低く見えますが、依頼側から見ると「ずっと書いている人」です。

順番として、発信を始める前に、本業の繁忙期の月を一つ選び、その月に副業の案件の稼働を引いた余りで、何本書けるかを出す。それを通年の頻度にして始める。閑散期に余った時間は、頻度を上げるのではなく、書き溜めに使う。この順番で決めた頻度は低いですが、止まりません。エラベルでは、担当者の発信の頻度を登録の条件にしていませんし、依頼側への提示にも使っていません。発信は、続いていれば案件の入口の一つになり、止まっていても登録の経歴で提示できるので、頻度で無理をする必要はありません。

## まとめ

- 発信は**頻度ではなく、止まらないこと**で決まる。依頼側が見るのは直近の投稿と内容
- 頻度の上限は**本業の繁忙期に副業の案件の稼働を引いた余り**で決め、通年で通す。閑散期は書き溜めに使う
- 場所ごとに**短い投稿は止まると目立ち、記事は目立たない**。稼働が限られるなら記事を軸に
- 頻度を上げると**案件の稼働が削られ、内容が出来事に寄り、本業に見つかりやすく、止まったときの落差が大きい**
- 止まったら**理由を書かず、用意した一本目で、頻度を下げて再開**。プロフィールが整っていれば止まっても困らない
- 落としてよいのは**本業の繁忙期・案件の稼働が上限に近い・案件の立ち上げ・出来事に寄り始めた・続けるか迷っている**とき

## よくある質問

### 月に一度でも、発信として意味はありますか

続いていれば意味があります。月に一度を一年続けると、判断の仕方が十本以上並び、依頼側が読めば「この人はこう考える人」と分かります。毎日書いて三か月で止まった人の投稿は、量は多くても最終の投稿が古く、「止まった人」に見えます。月に一度なら、記事の場所を軸にして、一本を厚く書く形が合います。

### 書き溜めた投稿を、予約で出し続けるのはよいですか

止まらないための方法として有効です。閑散期に書き溜めて、繁忙期に予約で出せば、繁忙期でも頻度を保てます。ただし、書き溜めた投稿が出ている間に、範囲や考え方が変わっていると、古い内容が出続けることになります。予約で出す投稿は、判断の仕方や型のように、時間が経っても変わらない内容にしておきます。

### 発信を止めて、登録先のプロフィールだけにしてもよいですか

構いません。発信は案件の入口の一つで、無くても登録先の経歴で依頼側に提示できます。発信の稼働が案件の稼働を圧迫しているなら、止めて案件に集中するほうが、依頼側からの評価も次の紹介も良くなります。再開したくなったら、頻度を低く決めて始め直せば足ります。
