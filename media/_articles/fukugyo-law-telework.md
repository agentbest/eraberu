副業で人事を受けると、テレワークの労務管理の相談を受けることがあります。「在宅の日の労働時間をどう把握すればよいか」「中抜けを認めてよいか」「通信費は誰が持つか」「評価が出社組に偏っていないか」。自分の本業や副業先での運用をそのまま答えると、依頼先の労働時間制度や就業規則と噛み合わないことがあります。この記事は、厚生労働省の「テレワークの適切な導入及び実施の推進のためのガイドライン」に沿って、依頼先のテレワークの労務管理を整えるときの要点を整理したものです。結論を先に書くと、**ガイドラインは「全ての労働時間制度でテレワークが実施可能」としたうえで、労働時間の把握（客観的記録か自己申告）、中抜け時間と移動時間の扱い、長時間労働対策、費用負担、人事評価、安全衛生、労災について、あらかじめ労使で話し合ってルールを定め、就業規則に規定しておくことを求めています。副業の人事が持つのは、この論点を洗い出して依頼先の運用に落とすところまでで、就業規則の変更の手続や個別の判断は社会保険労務士や弁護士の範囲です。**個別の判断は、社会保険労務士や弁護士にご確認ください。法改正の追い方は[法改正の追い方と情報源](/media/fukugyo-law-houkaisei/)に、副業許可制度は[企業側から見た副業許可制度](/media/fukugyo-law-fukugyo-kyoka/)にまとめています。

## 導入のときに、労使で決めておくこと

ガイドラインは、テレワークを制度として導入し実施するに当たって、あらかじめ労使で十分に話し合い、ルールを定めておくことが重要だとして、次の項目を挙げています。

| 決めること | 実務で詰める点 |
|---|---|
| 導入目的 | 何のためにテレワークをするか（働き方、事業継続、採用など） |
| 対象業務 | 職種で一律に外さず、業務ごとに実施できるかを見る |
| 対象となり得る労働者の範囲 | 雇用形態の違いのみを理由に対象から除外しない |
| 実施場所 | 自宅、サテライトオフィス、その他（使用者が許可する場所） |
| テレワーク可能日 | 希望制、当番制、頻度 |
| 申請等の手続 | 誰にどう申請し、誰が認めるか |
| 費用負担 | 通信費、光熱費、機器。限度額と請求の方法 |
| 労働時間管理の方法 | 把握の方法と、労働時間制度 |
| 中抜け時間の取扱い | 把握するか、しないか。把握するならどう扱うか |
| 連絡方法 | 通常時と緊急時 |

ガイドラインは、対象業務について「テレワークに向かないと安易に結論づけるのではなく、管理職側の意識を変えることや、業務遂行の方法の見直しを検討することが望ましい」とし、対象者については、正規と非正規の雇用形態の違いのみを理由に対象から除外することのないよう留意する必要がある、としています。オフィスに出勤する労働者のみに業務が偏らないよう留意することも求めています。

## 労働時間：制度の選び方と、把握の方法

**制度の選び方。**ガイドラインは、労働基準法に定められた全ての労働時間制度でテレワークが実施可能であり、導入前の制度を維持したままテレワークを行うことが可能だ、としています。そのうえで、通常の労働時間制度でも、就業規則にあらかじめ定めておくことで、テレワークの日の始業・終業の時刻を労働者ごとに変更できるようにすることが可能だとし、フレックスタイム制は「テレワークになじみやすい制度」だと整理しています。

**事業場外みなし労働時間制。**ガイドラインは、テレワークでこの制度を適用できるのは、①情報通信機器が使用者の指示により常時通信可能な状態におくこととされていないこと、②随時使用者の具体的な指示に基づいて業務を行っていないこと、の両方を満たす場合だとしています。①については、勤務時間中に労働者が自分の意思で通信回線を切断できる場合や、応答のタイミングを労働者が判断できる場合は満たすとされ、情報通信機器を所持していることのみをもって適用されないことはない、と明記されています。②については、使用者の指示が業務の目的・目標・期限等の基本的事項にとどまり、一日のスケジュールをあらかじめ決めるなど作業量や時期や方法を具体的に特定するものでない場合は満たす、とされています。

**把握の方法。**ガイドラインは、労働時間の適正な把握のガイドラインも踏まえ、客観的な記録による把握（テレワークに使用する情報通信機器の使用時間の記録、サテライトオフィスへの入退場の記録）と、自己申告による把握の二つを示しています。自己申告による場合、使用者は、労働時間の実態を記録し適正に申告することの十分な説明、パソコンの使用状況など客観的な事実と申告された時刻に著しい乖離があることを把握した場合の補正、自己申告できる時間外労働の時間数に上限を設けるなど適正な申告を阻害する措置を講じないこと、といった措置を講ずる必要があるとされています。簡便な方法として、一日の終業時に始業・終業の時刻をメール等で報告させる例が挙げられています。

### エラベルの見解

担当する側から見ると、テレワークの労務管理の整備で難易度が分かれるのは、「制度を選べるか」ではなく「依頼先が今どの制度で動いているかを先に確かめられるか」です。相談で見ていると、うまくいかない例は、依頼先の労働時間制度を確かめないまま「テレワークならみなし労働でよいのでは」と提案し、事業場外みなし労働時間制の二つの要件（常時通信可能な状態におくこととされていないこと、随時具体的な指示に基づいて業務を行っていないこと）を満たさない運用のまま導入してしまう形です。チャットで即時の応答を求め、一日のスケジュールを指示している運用なら、要件を満たしません。

先に確かめるのは、依頼先の今の労働時間制度と、テレワークの日の実際の働き方（応答をいつまでに求めているか、指示はどこまで具体的か）の二つです。ガイドラインが「全ての労働時間制度でテレワークが実施可能」としている以上、多くの依頼先では今の制度のまま、把握の方法と中抜けの扱いを決めれば足ります。制度を変えるのは、フレックスタイム制にして始業・終業の自由度を上げたい、といった目的があるときだけです。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「今の制度のままで足りる場合」を見分けられる人は、無駄な制度変更をさせない担当者として選ばれています。

## 中抜け時間、移動時間、長時間労働対策

**中抜け時間。**ガイドラインは、テレワーク中に一定程度業務から離れる時間について、労働基準法上、使用者は把握することとしても、把握せず始業・終業の時刻のみを把握することとしても、いずれでもよい、としています。取扱いの例として、①把握する場合は休憩時間として扱い終業時刻を繰り下げたり、時間単位の年次有給休暇として扱う、②把握しない場合は始業・終業の時刻の間の時間について休憩時間を除き労働時間として扱う、の二つが挙げられています。これらの取扱いは、あらかじめ就業規則等で定めておくことが重要だとされています。

**移動時間。**勤務時間の一部についてテレワークを行う場合（午前は自宅、午後は出社など）の就業場所間の移動時間について、ガイドラインは、労働者による自由利用が保障されている時間は休憩時間として扱うことが考えられるとし、一方で、使用者が具体的な業務のために急きょ出勤を求めた場合など、移動を命じ自由利用が保障されていない場合の移動時間は労働時間に該当する、としています。

**休憩の一斉付与。**労働基準法第34条第2項は原則として休憩を一斉に付与することを定めていますが、ガイドラインは、テレワークを行う労働者について、労使協定により一斉付与の原則を適用除外とすることが可能だ、としています。

**長時間労働対策。**ガイドラインは、テレワークでは使用者の管理の程度が相対的に弱くなり、時間帯にかかわらず指示や報告が行われやすく、仕事と生活の区別が曖昧になるおそれがあるとして、次の手法を挙げています。時間外等のメール送付の抑制、所定外深夜・休日のシステムへのアクセス制限、時間外等の労働が可能な時間帯や時間数をあらかじめ設定する手続、長時間労働等を行う労働者への注意喚起、勤務間インターバル制度の利用。あわせて、テレワークを実施している者が時間外等のメール等に対応しなかったことを理由に不利益な人事評価を行うことは適切な人事評価とはいえない、とも書かれています。

## 費用負担、人事評価、安全衛生、労災

**費用負担。**ガイドラインは、費用負担の取扱いは企業ごとに様々なので、労使のどちらがどのように負担するか、使用者が負担する場合の限度額、労働者が請求する場合の請求方法などを、あらかじめ労使で十分に話し合い、就業規則等に規定しておくことが望ましい、としています。特に、労働者に情報通信機器や作業用品その他の負担をさせる定めをする場合は、当該事項について就業規則に規定しなければならない（労働基準法第89条第5号）と明記されています。在宅勤務で通信費や電気料金が増える場合、業務に要した実費を勤務の実態を踏まえて合理的・客観的に計算して支給することも考えられる、とされています。

**人事評価。**ガイドラインは、上司が部下に求める内容や水準をあらかじめ具体的に示し、評価対象期間中に達成状況について共通の認識を持つ機会を設けることが望ましいとし、情意面を評価する場合は評価対象となる具体的な行動の内容や評価の方法をあらかじめ見える化して示すことが望ましい、としています。テレワークを実施せずオフィスで勤務していることを理由に出勤者を高く評価することは、テレワークを行おうとすることの妨げになり適切な人事評価とはいえない、とも書かれています。

**安全衛生。**自宅等でテレワークを実施する場合も、労働安全衛生法等に基づく措置（健康相談の体制の整備、雇入れ時や作業内容変更時の安全衛生教育、健康診断とその事後措置、長時間労働者への医師の面接指導、ストレスチェックとその事後措置など）を講ずる必要があるとされています。自宅等の作業場には事務所衛生基準規則等が一般には適用されないものの、同等の作業環境となるよう教育・助言を行い、チェックリストを活用して状況の報告を求めることが重要だ、とされています。メンタルヘルスについては、上司等が心身の変調に気づきにくい状況を念頭に、健康相談体制の整備やコミュニケーションの活性化のための措置を実施することが望ましい、としています。

**労災。**ガイドラインは、テレワークを行う労働者についても、労働契約に基づいて事業主の支配下にあることによって生じた災害は業務上の災害として労災保険給付の対象になるとし、私的行為等が原因であるものは業務上の災害と認められない、としています。労働者がこの点を十分理解していない可能性があるため、使用者が周知することが望ましいとされ、労働時間の記録を適切に保存し、負傷した場合の災害発生状況を可能な限り記録しておくことを労働者に周知することが望ましい、とも書かれています。

**就業規則と労働条件の明示。**ガイドラインは、テレワークのルールを就業規則に定めて周知することが望ましいとし、労働者の都合で柔軟に場所を選べる場合は、使用者の許可基準を示したうえで「使用者が許可する場所」でテレワークが可能である旨を定めることが考えられる、としています。労働契約の締結時には就業の場所に関する事項を明示することとされており、雇入れ直後からテレワークを行わせることが通常想定される場合は雇入れ直後の就業の場所として、契約期間中に行うことが通常想定される場合は変更の範囲として、テレワークを行う場所を明示する必要がある、とされています。最低賃金は、テレワークを行う場所にかかわらず、労働者の属する事業場がある都道府県のものが適用される点にも触れられています。

### エラベルの見解

外に出してよいのは、論点の洗い出し、依頼先の現状の確認、就業規則の条文の案、申請と把握の様式、中抜けと移動時間の運用の設計、チェックリストを使った作業環境の確認の仕組み、評価の見える化の案までで、「就業規則の変更の手続そのもの」「事業場外みなし労働時間制を適用してよいかの個別の判断」「労災に当たるかの判断」「割増賃金の計算」は、社会保険労務士や弁護士の範囲です。特に、みなし労働時間制の適用の可否は、依頼先の実際の指示の出し方と応答の求め方に当てはめる判断なので、副業の人事が「適用できます」と言い切る場所ではありません。

担当する側から見ると、この案件で結果が分かれるのは、条文を整えることより「依頼先の実際の運用を先に聞けるか」です。チャットの応答をいつまでに求めているか、一日の予定をどこまで指示しているか、中抜けは今どう扱われているか、通信費は誰が持っているか、評価で出社組と在宅組に差が出ていないか。この五つを聞くと、依頼先で実際に起きている問題が見えます。条文だけ整えて運用を聞かない人は、「規程はできたが現場は変わらない」で終わります。エラベルでは、依頼側が担当者を選べるので、現場の運用から入る人は、制度と運用の両方を任せられる担当者として選ばれています。

## まとめ

- ガイドラインは**全ての労働時間制度でテレワークが実施可能**とし、導入前の制度を維持したまま実施できるとしている。制度を変えるのは目的があるときだけ
- 労働時間の把握は**客観的な記録**か**自己申告**。自己申告の場合は説明、著しい乖離の補正、申告を阻害する措置を講じないこと、が求められる
- **中抜け時間は把握してもしなくてもよい**。把握するなら休憩や時間単位の年休として扱い、あらかじめ就業規則等で定めておく
- **費用負担は労使で話し合って就業規則等に規定**する。労働者に負担させる定めをする場合は就業規則への規定が必要（労働基準法第89条第5号）
- **出社を理由に高く評価すること、時間外のメールに対応しなかったことを理由に不利益に評価することは、適切な人事評価とはいえない**
- 副業の人事が持つのは**論点の洗い出しと条文の案と運用の設計まで**。手続と個別の判断は社会保険労務士や弁護士に確認する

## よくある質問

### 依頼先が「テレワークだから、みなし労働時間制にしたい」と言っています

事業場外みなし労働時間制は、①情報通信機器が使用者の指示により常時通信可能な状態におくこととされていないこと、②随時使用者の具体的な指示に基づいて業務を行っていないこと、の両方を満たす場合に適用できるとガイドラインは整理しています。依頼先が、チャットで即時の応答を求めていたり、一日のスケジュールを具体的に指示していたりするなら、要件を満たさない可能性があります。まず実際の運用を確かめ、適用の可否は社会保険労務士に確認してもらいます。多くの依頼先では、今の制度のまま把握の方法と中抜けの扱いを決めれば足ります。法令の追い方は[法改正の追い方と情報源](/media/fukugyo-law-houkaisei/)に整理しています。

### 在宅の日の通信費と光熱費は、会社が全部出すべきですか

ガイドラインは、どちらがどのように負担するかは企業ごとに様々なので、労使で十分に話し合い、限度額や請求の方法を含めて就業規則等に規定しておくことが望ましい、としています。在宅勤務に伴って通信費や電気料金が増える場合、業務に要した実費を勤務の実態を踏まえて合理的・客観的に計算して支給することも考えられる、とも書かれています。「全部出すべき」と決まっているわけではなく、話し合って決めて規定する、という整理です。在宅勤務手当の税務上の扱いは、国税庁の資料があるとガイドライン内で案内されており、税務の判断は税理士に確認してください。

### 副業でテレワークの制度を作る案件は、どれくらいの期間で受けられますか

論点の洗い出しと現状の確認に数回、条文の案と様式の作成に数回、依頼先の労使の話し合いを挟んで仕上げる、という形が多く、期間を区切って受けやすい案件です。依頼先の就業規則の変更の手続は社会保険労務士に渡すので、副業の人事が持つのは案と運用の設計までになります。受ける前に、依頼先に社会保険労務士がいるか、いない場合は誰が手続を持つかを確かめておくと、範囲がはっきりします。受ける前に確認することは[人事の副業の始め方](/media/fukugyo-hajimekata/)に、単価の考え方は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に整理しています。
