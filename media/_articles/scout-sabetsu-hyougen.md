スカウトの文面や、対象の選び方が、年齢や性別や国籍などの属性による差別と受け取られないか。不安はあるが、何が問題になるかの線が分からず、「悪意は無いから大丈夫」で担当者に任せている。ある日、候補者から「この文面は年齢で選んでいますよね」と返信が来て、初めて考える。結論を先に書くと、**差別的表現の確認は、「悪意が無いか」では見られません。「属性を指定・限定・優遇・排除していないか」の四つの形で文面を見て、「対象の選び方が属性になっていないか」を検索の条件で見ます。何が法令で制限されるかは国や時点で変わるので、線そのものは専門家に確認し、社内では「送る前に、決めた箇所を、決めた手順で見る」ことを仕組みにします**。品質の確認の全体は[品質チェックの仕組み](/media/scout-daikou-check/)に、属性で絞らない対象の選び方は[女性候補者へのアプローチ設計](/media/scout-josei-scout/)と[シニア層へのスカウト](/media/scout-senior-scout/)にまとめています。

## 確認が無い構造

差別的表現が、意図せず入るのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「悪意が無い」で見ている | 悪意の有無ではなく、表現と選び方の形が問題になる。悪意が無くても入る |
| 線を知らない | 何が制限されるかを、人事も担当者も確認したことが無い |
| 属性を「魅力」として書く | 「若い方が活躍」「女性が多い職場」「日本人のみ」を、良かれと思って書く |
| 対象の選び方が属性 | 検索の条件で年齢や性別を絞り、文面は問題無くても、選び方が属性 |
| 役割の要件と属性が混ざっている | 「体力が要る」→「若い方」、「細やかさ」→「女性」と、要件を属性に翻訳する |
| 担当者任せ | 発注側が文面を見ておらず、担当者の感覚で送っている |
| 指摘を受けても直さない | 候補者からの指摘を「クレーム」として処理し、文面を見直さない |

構造の大半は、「線を確認していない」ことと「送る前に見る手順が無い」ことです。線は専門家に、手順は社内で作ります。

## 問題になる四つの形

属性（年齢、性別、国籍、出身、家族の状況、身体の状況、信条など）に関して、問題になりやすい表現の形は四つです。どの属性が、どの形で制限されるかは法令によるので、個別の判断は専門家に確認してください。ここでは「形」を示します。

| 形 | 内容 | 例の形 |
|---|---|---|
| 指定 | 属性を対象として名指しする | 「〇〇歳以下の方」「女性の方」「日本国籍の方」 |
| 限定 | 属性を条件として絞る | 「〇〇歳までの方に限ります」「男性のみ」 |
| 優遇 | 属性を持つ人を好む・歓迎すると書く | 「若い方を歓迎」「女性が活躍中なので女性を優先」 |
| 排除 | 属性を持つ人を対象から外す | 「〇〇歳以上の方はご遠慮ください」「外国籍の方は不可」 |

四つの形の要点は、「良かれと思った表現」も形に当たることです。「女性が活躍しやすい職場です」は職場の説明で、「女性を歓迎します」は優遇の形です。「経験豊富なシニアの方」は指定の形です。属性を、対象の説明や魅力として書いた時点で、形に当たります。属性ではなく、役割の要件と職場の事実で書きます。

## 文面で見る箇所

スカウトの文面で、四つの形が入りやすい箇所です。

| 箇所 | 入りやすい表現 | 直し方 |
|---|---|---|
| 件名 | 「若手募集」「女性活躍」「〇〇代の方へ」 | 役割名と経験の言い換えで。「〇〇のご経験をお持ちの方へ」 |
| 一段落目 | 「お若いながら」「女性でありながら」「ご年齢を考えると」 | 属性に触れず、経歴の事実に触れる |
| 役割の説明 | 「若い力が必要」「体力に自信のある方」「細やかな気配りができる女性」 | 役割の要件を具体的な業務で。「立ち仕事が中心」「顧客との細かい調整が多い」 |
| 職場の説明 | 「平均年齢〇〇歳の若い職場」「女性ばかりの職場」「日本人中心」 | 職場の事実は書けるが、対象を示唆する形にしない。書くなら中立に |
| 条件 | 「〇〇歳まで」「未婚の方」「扶養の無い方」 | 属性の条件を書かない。書く必要があると考えるなら、その要件が法令上許されるかを専門家に |
| 歓迎の表現 | 「〇〇の方、大歓迎」（属性が入る場合） | 経験や意欲で。「〇〇の経験がある方」 |
| 写真や画像 | 特定の属性だけが写っている | 文面の確認の対象に含める |

箇所の要点は、「役割の要件を属性に翻訳しない」ことです。「体力が要る」なら「立ち仕事が中心」と業務で書く。誰が向いているかは、読んだ人が判断します。年齢や性別の偏りの構造は[年齢構成が偏っている](/media/rpo-nenrei-katayori/)と[女性比率を上げたいが応募が偏る](/media/rpo-josei-hiritsu/)に書いています。

## 対象の選び方で見る箇所

文面が問題無くても、対象の選び方が属性になっていれば、同じ問題です。

| 箇所 | 起きていること | 直し方 |
|---|---|---|
| 検索の条件 | 年齢の範囲、性別、国籍で絞る | 経験、職種、スキル、勤務地の希望で絞る。媒体の検索の項目で属性が使える場合も、使わない方針を決める |
| 一覧からの選別 | 検索の結果から、写真や名前や年齢で選ぶ | 経歴の事実で選ぶ。選ぶ基準を言葉にしておく |
| 除外の条件 | 「〇〇歳以上は除く」「外国籍は除く」 | 除外は経歴の事実で。属性で除外しない |
| 役割ごとの対象の定義 | 「若手向けの役割」「女性向けの役割」と役割に属性を付ける | 役割に経験と要件を付ける |
| 名義の使い分け | 「女性には女性の名義から」など、属性で名義を分ける | 層（経験の深さなど）で分ける。[複数名義で送り分ける](/media/scout-fukusuu-meigi/) |
| 記録の項目 | 送信ログの「層」の区分が属性 | 層の区分を経験と職種で定義する |

選び方の要点は、「記録の層の区分」です。送信ログに「二十代」「女性」のような区分があれば、選び方が属性になっている証拠です。区分を「経験の深さ」「現職の業種」「職種」で定義し直します。検索の条件で属性が使える媒体もありますが、使えることと使ってよいことは別です。媒体の仕様は公式の案内で、可否は専門家に確認してください。

## 送る前の確認の手順

差別的表現の確認を、担当者の感覚ではなく手順にします。

| 順 | 確認 | 誰が |
|---|---|---|
| 一 | 検索の条件に、属性の項目が無いか | 担当者 |
| 二 | 文面の件名・一段落目・役割・職場・条件・歓迎の箇所に、四つの形が無いか | 担当者（型の作成時）と発注側（型の承認時） |
| 三 | 役割の要件が、属性に翻訳されていないか（「体力」→「若い」など） | 発注側 |
| 四 | 職場の説明が、対象を示唆する形になっていないか | 発注側 |
| 五 | 型の変更のたびに、一〜四をやり直す | 担当者と発注側 |
| 六 | 迷う表現は、送らずに専門家に確認する | 発注側 |
| 七 | 候補者や社内からの指摘は、記録して型を見直す | 発注側 |

手順の要点は、「型の承認時に発注側が見る」ことです。担当者は文面の型を作り、発注側が承認して送り始める。承認のとき、四つの形の観点で一度読む。それだけで、大半は止まります。個別の文面（一段落目の個別化など）は担当者が見ますが、型が問題無ければ、個別の部分で属性が入ることは少ない。

### エラベルの見解

相談で最も多い失敗は、「『二十代が中心の若い職場で、同年代の仲間と』という文面を、良かれと思って送り続けていた」というものです。悪意は無く、職場の雰囲気を伝えたかっただけです。しかし、読んだ人には「二十代以外は対象ではない」と伝わり、候補者から指摘が来ました。「役割の範囲と裁量、チームの人数と役割の分担」に書き換え、職場の雰囲気は「意見を出しやすい」「決まるのが早い」と事実で書いたら、指摘は無くなり、対象の幅も広がりました。属性で書いた「魅力」は、対象を狭めてもいました。

見ていて差がつくのは、担当者が「役割の要件を業務で書く」癖を持っているかです。「若い方」と書きそうになったら「何が要るのか」を考え、「立ち仕事が中心」「夜間の対応がある」と業務に戻す担当者と、属性で書いてしまう担当者がいます。前者の文面は、指摘を受けにくいだけでなく、役割の中身が具体的なので返信も来ます。

発注側にできるのは、文面の型を承認するときに、「この表現は属性を指しているか」と一度だけ自分に聞くことです。

## 指摘を受けたときの対応

候補者や社内から指摘があったときの動きです。

| 段階 | 対応 |
|---|---|
| 指摘が来た | 当日に受け止める。「ご指摘ありがとうございます。表現を見直します」と一言。反論しない |
| 表現の確認 | 指摘された箇所が四つの形に当たるかを見る。当たるなら型を直す。当たらないと思っても、受け取られ方の問題として直すかを検討 |
| 型の修正 | 型を直し、新しい名前を付ける。直した型で、以後の送信 |
| 送信の停止 | 修正までの間、その型での送信を止める |
| 記録 | 指摘の内容、直した箇所、日付を記録。次の型の作成で参照 |
| 専門家への確認 | 法令に関わる可能性がある指摘は、専門家に確認 |
| 社内への共有 | 人事と担当者と、社内で文面を書く人に共有 |

対応の要点は、「反論しない」ことです。「そういう意図ではありません」は、受け取った側には意味がありません。意図ではなく、表現の形が問題です。受け止めて、直します。

## 外注する場合の範囲

差別的表現の確認を、スカウト代行に出す場合の範囲です。

**出せる工程。** 文面の型の四つの形での自己確認、役割の要件を業務で書く型の作成、検索の条件から属性の項目を外す設定、層の区分を経験と職種で定義する記録の設計、送る前の確認の手順の実施、個別の文面の確認、指摘を受けたときの型の修正と記録、社内で文面を書く人向けの確認の観点の資料。

**社内に残す判断。** 何が法令で制限されるかの確認（専門家との連携）、文面の型の承認（四つの形の観点で読む）、役割の要件の定義（属性に翻訳されていないか）、職場の説明の事実の提供、指摘を受けたときの対応の決定、社内で文面を書く人への徹底。

**外注の効きどころ。** 差別的表現の確認は、「形で見て、手順で見る」運用で、社内では「悪意が無いから大丈夫」で担当者任せになりやすい工程です。担当者が四つの形を知り、要件を業務で書く型を持ち、検索の条件から属性を外し、送る前の手順を回せば、意図しない表現は大半が止まります。担当者は複数の会社の文面を見ているので、「この表現は指摘を受けた」の経験を持ち込めます。ただし、法令の線は専門家に、型の承認は発注側が担います。

**外注しても動かない場合。** 発注側が「若い人だけ送って」「女性だけ」と属性での対象の指定を求める、型を承認せずに送らせる、指摘を「クレーム」として反論する、役割の要件を属性でしか説明しない。社内の判断で、代行を替えても直りません。

差別的表現は、悪意の有無ではなく、四つの形と選び方を、送る前の手順で見れば止まります。線は専門家に、手順は社内で作り、外注は型の作成と手順の実施を担う手段です。

### エラベルの見解

担当する側から見ると、この相談で最も多いのは、「発注側から、属性での対象の指定が来る」ことです。「三十代前半までで」「男性を中心に」「日本人で」。悪意は無く、「今のチームに合う人」を思い浮かべた結果です。担当者がそのまま受ければ、選び方が属性になり、文面にも滲みます。

担当者ができるのは、「なぜその属性か」を聞き、要件に戻すことです。「三十代前半まで」は「これから育てる前提の経験の浅い人」かもしれず、「男性中心」は「夜間の現場の対応がある」かもしれません。要件に戻せば、属性で絞らずに済み、対象も広がります。属性の指定を受けたときに要件に戻せるかは、担当者の力量です。

発注側にできるのは、対象を伝えるとき、属性ではなく「何をしてほしいか」「何ができる人か」で伝えることです。属性で伝えたくなったら、「それは何の代わりに言っているのか」を一度考えます。

## まとめ

- 確認が無いのは**悪意の有無で見る・線を知らない・属性を魅力として書く・選び方が属性・要件と属性が混ざる・担当者任せ・指摘を直さない**構造
- 形は**指定・限定・優遇・排除**の四つ。良かれと思った表現も形に当たる。どの属性がどう制限されるかは専門家に
- 文面で見るのは**件名・一段落目・役割・職場・条件・歓迎・画像**。要件を属性に翻訳せず、業務で書く
- 選び方で見るのは**検索の条件・一覧からの選別・除外の条件・役割の定義・名義の分け方・記録の層の区分**。層は経験と職種で定義
- 手順は**検索の条件→文面の箇所→要件の翻訳→職場の示唆→型の変更のたびに→迷えば専門家→指摘は記録**。型の承認時に発注側が見る
- 指摘には**反論しない・確認・型の修正と新しい名前・停止・記録・専門家・共有**
- 外注できるのは**自己確認・要件を業務で書く型・条件の設定・記録の設計・手順の実施・個別の確認・修正と記録・観点の資料**。社内に残るのは**法令の確認・型の承認・要件の定義・事実の提供・対応の決定・社内の徹底**

## よくある質問

### 年齢や性別を書いてよい場合はありますか

法令上、一定の条件のもとで年齢や性別に関する記載が認められる場合があると言われますが、その条件と範囲は法令の定めによるもので、この記事で断定できません。書く必要があると考える場合は、送る前に専門家に確認してください。多くの場合、属性ではなく役割の要件と業務で書けば、書く必要そのものが無くなります。

### 「女性が活躍しています」は書いてよいですか

職場の事実を中立に書くことと、対象を示唆することの間に線があります。「女性が活躍しやすい環境です」は職場の説明として書かれることが多い一方、「女性を歓迎します」「女性の方へ」は優遇や指定の形です。書くなら、事実として、対象を示唆しない形で、他の属性を排除する含みが無いかを見ます。迷う場合は、書かずに、役割と職場の具体的な事実（制度、働き方、チームの構成の考え方）で書きます。個別の表現の可否は専門家に確認してください。

### 媒体の検索で年齢が絞れます。使ってはいけませんか

媒体の機能として使えることと、使ってよいことは別です。検索の条件で属性を絞れば、文面が問題無くても選び方が属性になります。自社の方針として「検索の条件で属性を使わない」を決め、経験・職種・スキル・勤務地の希望で絞ります。媒体の検索の項目の仕様は公式の案内で、属性による絞り込みの可否は専門家に確認してください。属性で絞らない対象の選び方は[シニア層へのスカウト](/media/scout-senior-scout/)と[外国籍候補者へのスカウト](/media/scout-gaikokujin-scout/)にも書いています。
