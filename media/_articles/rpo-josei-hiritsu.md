社内の女性の比率が低く、経営者は「上げたい」と言う。ただ、求人を出しても応募は男性に偏り、女性の応募者は選考で残らず、採っても数年で辞める。「女性限定」の募集はできないと聞いているし、何をすればよいか分からない。結論を先に書くと、**女性の比率が上がらないのは、「女性を採ろう」としているからではなく、応募・選考・職場の各段階に「女性がためらう壁」があり、それが見えていないからです。壁は、求人票の言葉、経路、選考の観点、職場の実態にあります。壁を取り除けば、応募の偏りは減り、選考で残り、続きます。性別に関する採用の扱いは法令上の定めがあるので、専門家と公的機関の案内で確認しながら進めます**。女性候補者へのアプローチは[女性候補者へのアプローチ設計](/media/scout-josei-scout/)に、候補者体験の全体は[候補者体験が悪いまま放置されている](/media/rpo-taiken-warui/)にまとめています。

## 応募が偏る構造

女性の応募が少なく、選考で残らず、続かないのは、次の構造で起きます。

| 段階 | 起きていること |
|---|---|
| 求人票 | 言葉、写真、働き方の記述が、暗黙に男性を想定している。「体力」「長時間」「飲み会」など |
| 経路 | 使っている媒体や紹介会社の利用者が、男性に偏っている |
| 選考 | 面接官が全員男性。観点に「長時間働けるか」のような暗黙の前提がある。私的な事情に踏み込む質問 |
| 職場の実態 | 女性の管理職がいない、働き方の柔軟さが無い、育児や介護との両立の実態が見えない |
| 社内の理解 | 「女性を採れ」と言うだけで、なぜ、どう、が現場に共有されていない |
| 「女性を採る」の発想 | 性別で採ろうとして、法令上の扱いに触れる。または、「女性だから」で役割を限定する |
| 続かない | 採っても、働き方の実態と、周囲の理解と、成長の機会が無く、辞める |

構造の要点は、「壁が各段階にあり、見えていない」ことです。「女性を採ろう」の発想では、壁は見えません。「なぜためらうか」の視点で、壁を探します。

## 法令上の扱いの確認

性別に関する採用の扱いは、法令上の定めがあります。進める前に、専門家と公的機関の案内で確認します。

**性別を理由にした募集や採用の扱い。** 「女性限定」「男性限定」の募集、性別を理由にした選考の扱いは、法令上の定めがあります。原則と例外は、専門家と公的機関の案内で確認します。

**格差の改善のための取り組みの扱い。** 女性の比率が低い場合に、改善のために取れる取り組みの範囲と条件は、法令上の定めがあります。「何ができ、何ができないか」を、専門家に確認します。

**面接で聞いてはいけないこと。** 結婚、出産、家族の事情などの私的な事情に関する質問は、法令上の扱いがあります。面接官に一枚で共有します。

**求人票の表現。** 性別を限定する表現、性別を想定した表現の扱い。専門家に確認します。

**社内の制度と実態。** 働き方、評価、昇進に、性別による不利益な扱いが無いか。法令上の扱いと、社内の規程を確認します。

法令上の扱いの要点は、「女性を採る」ではなく「壁を取り除く」形で進めることです。壁を取り除くことは、性別に関わらず、応募をためらう人を減らすことでもあります。

## 求人票の壁の取り除き方

求人票にある「ためらわせる壁」を探し、取り除きます。

| 壁 | 取り除き方 |
|---|---|
| 暗黙に男性を想定した言葉 | 「体力に自信のある方」「バリバリ働ける方」「タフな」など。役割に本当に要るかを見直し、要るなら具体的な業務で書く |
| 写真や素材の偏り | 写真が全員男性。働いている人の実態に合わせ、多様な人が写る素材に。素材の作り方は[使える写真・素材がない](/media/rpo-shashin-nai/) |
| 働き方の記述が無い | 時間、リモート、休日、柔軟さの実態を書く。「無い」なら無いと書く。隠さない |
| 両立の実態が見えない | 育児や介護と仕事の両立の実態（制度と、実際に使っている人の有無）。制度があるだけでなく、実態を |
| 成長の機会が見えない | 評価と昇進の仕組み、女性の管理職やリーダーの有無。いなければ、いないと書き、「今後こうしたい」を |
| 「女性歓迎」だけ | 「女性歓迎」と書いて中身が変わらなければ、かえって不信。法令上の扱いも専門家に確認 |
| 役割の記述が薄い | 「何を決める役割か」「誰と働くか」。役割が明確なら、性別に関わらず、自分に合うかを判断できる |
| 応募の手前の窓口が無い | 「まず話を聞く」場（カジュアル面談）があれば、応募をためらう人が一歩踏み出せる |

求人票の要点は、「実態を、隠さず、具体的に書く」ことです。良く見せると、面接か入社後に分かって離れます。実態が良くないなら、「今後こうしたい」を経営者の言葉で添えます。

求人票の表現は、性別に関する法令上の扱いを専門家に確認します。

## 経路の見直し

使っている経路の利用者が偏っていれば、応募も偏ります。

**媒体と紹介会社の利用者の層を、確認する。** 各媒体や紹介会社の利用者の層（性別を含む）を、公式の案内や担当者に聞いて確認します。偏っていれば、別の経路を足します。

**女性の利用者が多い媒体や、両立を重視する層向けの経路を、足す。** 各媒体の特徴は公式の案内で確認します。

**社員の紹介を、女性の社員からも。** 社員の紹介は、紹介する社員の知り合いに偏ります。女性の社員にも、具体的に頼みます。

**スカウトで、「返信をためらわせる壁」を取り除く。** 文面の言葉、働き方の実態、応募の手前の窓口。設計は[女性候補者へのアプローチ設計](/media/scout-josei-scout/)に書いています。

**カジュアル面談を、入口に置く。** 応募をためらう人が、「まず話を聞く」で一歩踏み出せます。面談は選考にしない（[カジュアル面談が選考になってしまう](/media/rpo-casual-mendan-kadai/)）。

**両立を支援する仕組みや、再就職の支援の経路を、確認する。** 公的機関や自治体の支援の仕組みがあることがあります。公的機関の案内で確認します。

経路の要点は、「偏った経路に、偏っていない経路を足す」ことです。一つの経路に頼ると、その経路の偏りがそのまま応募の偏りになります。

### エラベルの見解

相談で最も多い失敗は、「女性の比率を上げたいので、求人票に『女性歓迎』と足しただけで、中身は変えなかった」というものです。求人票には「体力に自信のある方」「残業あり」が残り、写真は全員男性、面接官も全員男性、働き方の実態は書かれていない。「歓迎」の言葉だけでは、壁は消えません。求人票の言葉と写真と働き方の実態を直し、面接官に女性を入れ、カジュアル面談を入口に置いたら、応募の偏りが減りました。「女性歓迎」と書くことではなく、壁を取り除くことでした。

見ていて差がつくのは、担当者が「壁を探す」視点を持っているかどうかです。「女性向けの求人票にしましょう」と言う担当者と、「いまの求人票と選考と職場に、応募をためらわせる壁がどこにあるかを探しましょう。求人票の言葉、写真、働き方の記述、面接官の構成、質問の内容」と、壁を一つずつ探す担当者がいます。後者は、性別に関わらず、応募をためらう人を減らします。

発注側にできるのは、「女性を採りたい」を「応募をためらわせる壁を取り除きたい」と言い換えて、担当者に依頼することです。

## 選考の壁

選考にある壁を探し、取り除きます。

| 壁 | 取り除き方 |
|---|---|
| 面接官が全員男性 | 面接官に女性を入れる。「一緒に働く人」として。いなければ、いないことを候補者に正直に |
| 観点に暗黙の前提 | 「長時間働けるか」「転勤できるか」のような前提が、役割に本当に要るかを見直す。要るなら、性別に関わらず全員に同じ確認 |
| 私的な事情への質問 | 結婚、出産、家族の事情に関する質問は、法令上の扱いがある。「聞かない一覧」を専門家に確認して面接官に共有 |
| 「女性だから」の役割の限定 | 「女性はこの役割」と限定する発想。役割は性別ではなく、経験と適性で |
| 評価の基準の曖昧さ | 基準が曖昧だと、面接官の暗黙の前提が判定に入る。観察できる言葉の基準（[評価基準が言語化できていない](/media/rpo-hyouka-kijun/)）で、前提を排除 |
| 面接官ごとの判定のばらつき | 男性の面接官と女性の面接官で判定が違う場合、基準のどこで読みが違うかを話す |
| 動機づけの内容 | 「うちは男性が多いけど大丈夫」のような言い方。職場の実態と、今後の方針を、事実として |
| 選考の記録 | 性別ごとの通過率を記録し、極端な差があれば、観点と基準を見直す |

選考の要点は、「暗黙の前提を、観察できる基準に置き換える」ことです。基準が言葉になっていれば、前提が判定に入りにくくなります。

面接での質問の扱いは、法令上の定めがあるので、専門家に確認のうえ、面接官に一枚で共有します。

## 職場の実態の見直し

採っても続かないなら、職場の実態に壁があります。求人票と選考を直しても、職場が変わらなければ、続きません。

**働き方の実態を、見る。** 時間、リモート、休日、柔軟さ。制度があっても、使われていなければ、実態は無いのと同じ。「使っている人がいるか」を見ます。

**両立の実態を、見る。** 育児や介護と仕事の両立を、実際にしている人がいるか。いれば、その人の話を（本人の同意のうえで）求人票と面接で。いなければ、「これから作る」を経営者の言葉で。

**成長の機会と、昇進の実態を、見る。** 女性の管理職やリーダーがいるか。評価と昇進の仕組みに、性別による差が無いか。法令上の扱いと社内の規程を確認します。

**周囲の理解を、作る。** 「なぜ多様な人を採るか」「どう接するか」を、受け入れる部署に説明します。「女性だから」の特別扱いでも、無視でもなく、「同じ社員として」。

**相談の窓口を、持つ。** 働き方や職場の関係で困ったときの相談先。人事、または外部の窓口。

**辞めた理由を、聞いて記録する。** 女性の社員が辞めた理由を（差し支えない範囲で）聞き、記録します。壁がどこにあるかが、見えます。

**経営者が、方針を示す。** 「女性の比率を上げる」ではなく、「多様な人が働ける職場を作る。そのために、働き方と評価と職場の理解を変える」。経営者の言葉で、社内に。

職場の実態の要点は、「制度ではなく実態」と「経営者の方針」です。制度を作っただけでは変わらず、経営者が方針を示さなければ現場は動きません。

## 外注する場合の範囲

女性の比率と応募の偏りの問題を、採用代行に出す場合の範囲です。

**出せる工程。** 各段階の壁の点検（求人票、経路、選考、職場の実態）、法令上の扱いの確認の専門家への橋渡し、求人票の言葉と写真と働き方の記述の直し（専門家の確認を経て）、経路の利用者の層の確認と経路の追加、スカウトの文面（壁を取り除く形）、カジュアル面談の設計と運用、面接官の構成の案、観点と基準の見直し（暗黙の前提の排除）、「聞かない一覧」の整理（専門家の確認を経て）、面接官向けの一枚、性別ごとの通過率の記録、辞めた理由の聞き取りと記録、受け入れる部署への説明の資料、経営者の方針の文面の案。

**社内に残す判断。** 経営者の方針の決定、働き方と評価と昇進の制度の見直し（専門家との連携）、面接官の指名、役割と要件の決定、判定、内定、職場の実態の変更の決定。

**外注の効きどころ。** 応募の偏りは、「壁が見えていない」ことが根本で、社内の人には見えにくい壁を、外部の担当者が候補者の視点で探せます。担当者は複数の会社の求人票と選考を見ているので、「この言葉は壁になる」「この質問は法令上の扱いに触れる」の型を持ち込めます。ただし、法令上の扱いは、担当者も専門家に確認します。職場の実態の変更は、社内の判断です。

**外注しても動かない場合。** 経営者が「女性を採れ」と言うだけで方針を示さない、面接官の構成を変えない、働き方の実態を変えない、辞めた理由を聞かない。社内の判断で、代行を替えても直りません。

応募の偏りは、壁を取り除けば減ります。外注は、壁を探し、取り除く設計を持ち込む手段です。

### エラベルの見解

担当する側から見ると、この相談で最も多いのは、「採用の壁は直したが、職場の実態が変わっていない」ことです。求人票と選考を直して、女性の応募が増え、採れた。ただ、職場は変わっておらず、働き方の柔軟さも、両立の実態も、成長の機会も無い。数年で辞め、「やはり続かない」になる。

採用の壁と、職場の壁は、両方を直す必要があります。採用だけ直すと、「入口は開いたが中は変わっていない」状態になり、入った人が最も困ります。

発注側にできるのは、採用の壁を直すと同時に、職場の実態（働き方、両立、評価、周囲の理解）を、経営者の方針として変え始めることです。

## よくある質問

### 「女性限定」で募集してはいけませんか

性別を限定した募集や選考の扱いは、法令上の定めがあり、原則と例外があります。専門家と公的機関の案内で確認します。「女性を採る」の発想ではなく、「応募をためらわせる壁を取り除く」形で進めれば、法令上の扱いに沿いながら、応募の偏りを減らせます。壁を取り除くことは、性別に関わらず、応募をためらう人を減らすことでもあります。改善のための取り組みとして何ができるかは、専門家に確認します。

### 面接官に女性がいません

一緒に働く人として、女性の社員がいれば面接官に入れます。いなければ、いないことを候補者に正直に伝え、「今後こうしたい」を経営者の言葉で添えます。面接官が全員男性でも、観点を観察できる基準にし、私的な事情への質問を「聞かない一覧」で排除し、面接官向けの一枚で共有すれば、暗黙の前提が判定に入りにくくなります。カジュアル面談に女性の社員が出る形も、応募の手前の壁を下げます。

### 採っても、数年で辞めてしまいます

採用の壁を直しても、職場の実態（働き方の柔軟さ、両立の実態、成長の機会、周囲の理解）が変わっていなければ、続きません。辞めた理由を（差し支えない範囲で）聞き、記録すれば、壁がどこにあるかが見えます。働き方の制度が「あるが使われていない」なら、使える形に。両立をしている人がいなければ、「これから作る」を経営者の方針として示します。採用の壁と職場の壁は、両方を直します。
