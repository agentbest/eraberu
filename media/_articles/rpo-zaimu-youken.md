財務の求人票の必須要件には、「事業会社での財務の実務経験」「〇〇規模の資金調達の実績」「上場準備の経験」「銀行との交渉の経験」「会計や財務の資格」「経験十年以上」が並びがちです。全部を満たす人は市場にほとんどおらず、いても条件が高く、自社の状況（資金繰りの管理が中心なのか、調達なのか、上場準備なのか）と合わない経験を求めていることもあります。結論を先に書くと、**財務の採用要件は、先に財務か経理か・自社の状況・経営者が委ねる範囲を決め、必須を「入社初日に自社の状況で財務が成り立つか」で三つ以内に絞り、資格・実績の大きさ・年数・事業会社での財務経験は必須にせず、状況に合う経験の中身（どの状況で、何を、どこまで担ったか）で書く**と、経験者だけでなく、状況に合う転向層（銀行、監査法人、投資の会社、コンサルティング）も母集団に入ります。状況を決めずに要件を積むと、全部の状況の要件が混ざり、誰にも当てはまらなくなります。母集団形成は[財務の母集団形成](/media/rpo-zaimu-boshuudan/)に、代行に出す工程の線は[財務採用を代行に出す判断基準](/media/rpo-zaimu-rpo/)にまとめています。

## 財務で要件が膨らむ理由

他の職種と共通する理由（現場の希望を全部書く、前任者を基準にする、失敗を避けたい）に加えて、財務に特有の理由があります。

一つ目は、財務と経理の要件を混ぜることです。「決算の経験」と「資金繰りの管理」と「銀行との交渉」が並ぶと、経理の要件と財務の要件が混ざり、両方を深く持つ人を探すことになります。

二つ目は、実績の大きさを求めることです。「〇〇規模の調達」「上場の実績」は、大きな会社や特定の段階の会社にいた人を選び、自社の状況（資金繰りの管理が中心、調達はこれから）と合わないことがあります。しかも、大きな調達や上場は、本人の力量だけでなく、会社の事業と時期で決まります。

三つ目は、全部の状況の経験を求めることです。資金繰りの管理も、調達も、上場準備も、予算管理も。一人で全部を経験した人は限られ、自社がいま必要なのは一つか二つです。

四つ目は、「事業会社での財務の経験」を必須にすることです。財務の経験者は少なく、事業会社での経験に限ると、銀行・監査法人・投資の会社・コンサルティングからの転向層を全部弾きます。

五つ目は、資格と年数です。資格は知識の目安で、自社の状況で判断できるかを示さず、年数と判断の質は一致しません。

## 必須と歓迎を分ける基準

基準は「入社初日に、自社の状況で財務が成り立つか」です。財務では「自社の状況で」を先に決めます。資金繰りの管理と銀行対応が中心なら、その経験。調達が中心なら、調達の経験。上場準備が中心なら、その経験。

| 項目の例 | 必須になる場合 | 歓迎になる場合 |
|---|---|---|
| 資金繰りの管理の経験 | 資金繰りの管理が中心の状況なら必須 | 他の状況なら歓迎 |
| 銀行との対応（融資、交渉）の経験 | 銀行対応を財務に委ねる状況なら必須 | 経営者が銀行対応を持つなら歓迎 |
| 調達（増資、投資家との対応）の経験 | 調達が中心の状況なら必須 | 他の状況なら歓迎 |
| 上場準備・内部統制の経験 | 上場準備が中心なら必須 | 他の状況なら歓迎 |
| 予算の策定と事業計画の数字の経験 | 予算管理と投資の判断が中心なら必須 | 他の状況なら歓迎 |
| 経営者と数字で対話した経験 | どの状況でも必須に近い（財務は経営者との距離が最も近い） | — |
| 財務の仕組みを作った経験 | 一人目で仕組みが無い状態なら必須に近い | 整った体制に加わるなら歓迎 |
| 経理の実務 | 財務が経理を兼ねる場合は、経理の水準を別に必須に | 経理が別にいるなら歓迎 |
| 事業会社での財務の経験 | — | 必須にしない。状況に合う経験で（転向層を入れる） |
| 実績の大きさ（調達の規模、上場） | — | 必須にしない。「自社の状況に近い規模で」に |
| 資格 | — | 必須にしない。知識の目安として歓迎に |
| 経験年数 | — | 必須にしない |

基準の要点は、「事業会社での財務の経験を必須にせず、自社の状況に合う経験を必須にする」ことです。銀行で融資と資金繰りの支援をしてきた人は、事業会社の財務の経験は無くても、資金繰りと銀行対応の状況に合う経験を持っています。

### エラベルの見解

相談で多いのは、「事業会社で財務の経験があって、調達の実績があって、上場準備も分かって、銀行とも交渉できる人」というご要望です。自社の状況は、資金繰りの管理と銀行対応が中心で、調達も上場もまだ先。この要件で来る人は、市場に数える程度で、来ても自社の状況を「物足りない」と感じます。要件が、自社の状況と合っていません。

見ていて差がつくのは、「自社の状況から、必須を逆算しているか」です。「資金繰りの管理と銀行対応が中心、経営者は最終の判断、仕組みは作るところから」なら、必須は「資金繰りの管理の経験」「銀行との対応の経験」「経営者と数字で対話した経験」の三つ。調達も上場も資格も、歓迎か不要です。しかも、この三つなら、銀行出身の人も母集団に入ります。エラベルでは、財務の要件を整理するとき、依頼側の経営者に状況と委ねる範囲を先に決めていただき、そこから必須を逆算しています。

## 必須を三つに絞る手順

財務向けに、絞る手順を番号付きで整理します。

1. **財務か経理かを分ける。** 経理の要件は別に。財務が経理を兼ねるなら、経理の水準を別の要件として。
2. **自社の状況を決める。** 資金繰りの管理・調達・上場準備・予算管理のどれが中心か。二つまで。
3. **経営者が委ねる範囲を決める。** 銀行との対応、調達の交渉、投資の判断への関わり。
4. **いまの財務の体制を把握する。** 一人目か、仕組みがあるか、経理との分担。
5. **現場（経営者、財務の分かる人がいればその人、経理）の希望を全部書き出す。** ここでは絞らない。
6. **一つずつ、「初日に自社の状況で財務が成り立つか」を問う。** 成り立たないものだけ残す。
7. **残ったものが三つを超えたら、「入社後に覚えられるか」「外部（税理士、監査法人、顧問）が補えるか」を問う。** 他の状況の経験、資格、経理の実務（別にいるなら）は歓迎へ。
8. **事業会社での経験・実績の大きさ・資格・年数を、状況に合う経験の中身に書き換える。** 「〇〇規模の調達の実績」ではなく「資金繰りの管理と銀行との対応を主体で担った経験」。
9. **歓迎に回したものを、優先順位を付けて三〜五つ書く。** 面接で見る点になる。
10. **転向元ごとの要件の書き方を決める。** 銀行、監査法人、投資の会社、コンサルティングから、それぞれ何を必須にし、何を面接で確認するか。
11. **経営者・財務の分かる人（外部でも）・人事で確認する。** 「この三つがあれば、他は入社後に補える」と言えるか。

手順の要点は、「二と三を先にやる」ことです。状況と委ねる範囲が決まれば、必須はそこから逆算でき、転向元も決まります。

## 経歴で確かめられる要件と、面接でしか分からない要件

財務では、経歴の実績が会社の事業と時期で決まるので、確かめ方の区別が重要です。

| 確かめる方法 | 要件の例 | 見方 |
|---|---|---|
| 経歴で確かめられる | 担った状況の種類（資金繰り・調達・上場準備・予算管理）、銀行や投資家との対応の有無、規模の目安、転向元、経営者との距離（報告先が誰だったか） | 書類の一次絞りで。「財務を担当」ではなく、「どの状況で、何を、どこまで担ったか」の記述があるかを見る |
| 経歴では分からない | 判断の質（借りるか増資かの判断の根拠）、経営者への説明の仕方、厳しい状況での動き方、銀行や投資家との関係の作り方、機微な情報の扱いの姿勢 | 面接で、経営者と財務の分かる人が聞く。「一番難しかった資金の判断を、状況の把握から結果まで順に」。[構造化面接](/media/rpo-kouzou-mensetsu/) |
| 経歴でも面接でも分かりにくい | 実際の資金繰りの表の作り方、計画の質 | 自社の状況を題材にした短い課題（機微な情報を出さない範囲で）や、顧問としての試行 |

分け方の要点は、「面接で、一つの資金の判断を状況の把握から結果まで話してもらう」ことです。実績の大きさの裏に、誰が判断したか、どんな根拠だったか、経営者にどう説明したかが、一つの判断の話で見えます。

## 転向元ごとの要件の書き方

財務の経験者は少なく、転向元ごとに要件の書き方を変えると、母集団が広がります。

| 転向元 | 持っているもの | 合う状況 | 要件の書き方 | 面接で確認すること |
|---|---|---|---|---|
| 銀行 | 融資の審査、企業の資金繰りの理解、銀行の考え方 | 資金繰りの管理と銀行対応 | 「企業の融資や資金繰りの支援を担った経験」 | 事業会社の側で日々の資金を動かす経験の有無。支援する側から動かす側への動機 |
| 監査法人・会計事務所 | 数字の正確さ、内部統制、上場準備の支援 | 上場準備、決算の高度化 | 「上場準備や内部統制の支援の経験」 | 資金の判断の経験の有無。作る側に回る動機 |
| 投資の会社・証券 | 投資家の視点、調達の構造 | 調達 | 「投資先の財務や調達の支援の経験」 | 日々の資金繰りの経験の有無。一つの会社に腰を据える動機 |
| コンサルティング | 事業計画、予算の設計 | 予算管理と投資の判断 | 「事業計画や予算の設計の経験」 | 実務の運用の経験の有無。計画を作るだけでなく結果まで見る動機 |
| 事業会社の財務 | 状況による | 前職の状況が近ければ | 「〇〇の状況で〇〇を担った経験」 | 前職の状況と委ねられた範囲が自社と近いか |
| 経理から財務へ | 数字の正確さ、会社の実態の理解 | 財務が経理を兼ねる小さな会社 | 「経理を担いながら資金繰りや銀行対応に関わった経験」 | 財務の判断の経験の有無 |

書き方の要点は、「状況によって、合う転向元が違う」ことです。資金繰りと銀行対応なら銀行から、上場準備なら監査法人から、調達なら投資の会社から。状況を決めれば、転向元と書き方が決まります。

## 要件が決まらないときの原因

| 原因 | 起きていること | 直し方 |
|---|---|---|
| 財務と経理が分かれていない | 「財務経理」で両方の要件 | 分ける。財務が中心なら経理は歓迎か別の要件 |
| 状況が決まっていない | 「財務ができる人」 | 資金繰り・調達・上場準備・予算管理のどれかを決める |
| 委ねる範囲が決まっていない | 「任せる」だけ | 銀行対応、調達の交渉、投資の判断への関わりを決める |
| 全部の状況を求めている | 「調達も上場も銀行も」 | いま必要な一つか二つに |
| 事業会社の経験を必須にしている | 転向層を弾いている | 状況に合う経験で書き、転向元を入れる |
| 実績の大きさで書いている | 安心のため | 「自社の状況に近い規模で」に |
| 財務の分かる人が要件の議論にいない | 経営者と人事だけで決めている | 外部の財務の分かる人（社外取締役、顧問、監査法人や銀行の担当）を入れる |
| 市場の実態を知らない | 「この要件で普通にいるはず」 | 代行や媒体に、その要件での人数を聞く。転向層を含めて |

原因の要点は、「状況と委ねる範囲が決まっていない」ことが最も多い点です。この二つが決まれば、必須は逆算でき、転向元も決まります。

## 代行に出せる工程

| 工程 | 社内で持つ | 代行に出せる |
|---|---|---|
| 財務か経理か・状況・委ねる範囲の決定 | 経営者が判断 | 決める打ち合わせの進行 |
| 必須と歓迎の分離 | 「初日に成り立つか」の判断は社内 | 問いを立て、一つずつ確認する進行 |
| 事業会社の経験・実績・資格・年数の書き換え | 中身は社内が出す | 状況に合う経験の中身の言葉に直す |
| 転向元ごとの要件の設計 | 判断 | 状況に合う転向元からの書き方と確認の提案 |
| 機微な情報の扱いの設計 | 経営者が決める | 求人票とスカウトに含めない書き方 |
| 市場の実態の確認 | 判断 | その要件での人数を示す。転向層を含めて |
| 求人票への反映 | 確認 | 書く |
| 書類の一次絞り | 判断の質の妥当性 | 状況と転向元の分類。「どの状況で、何を、どこまで担ったか」の記述の有無 |
| 面接で見る点の整理 | 経営者と財務の分かる人が使う | 歓迎の要件と、「一つの資金の判断を順に」の質問の案 |

分け方の要点は、「状況と委ねる範囲は、経営者が決める」ことです。代行は、決める打ち合わせの進行と、決まったものの言語化、転向元の設計を担えます。機微な情報は代行に渡さず、求人票とスカウトに含めない書き方にします。

### エラベルの見解

担当する側から見ると、財務の要件で最も時間がかかるのは、依頼側の経営者が「事業会社での財務の経験」と「実績の大きさ」を手放すことです。安心のために求めたこの二つが、市場を数える程度に狭め、しかも自社の状況と合わない人を探す原因になっている、と分かるまでに時間がかかります。状況と委ねる範囲から逆算すると、必須は「自社の状況に合う経験」「経営者と数字で対話した経験」「仕組みを作った経験（一人目なら）」に落ち着き、銀行や監査法人からの転向層が母集団に入ります。

エラベルでは、財務の案件で要件が整理されていない場合、担当者の最初の仕事を「経営者と外部の財務の分かる人を交えて、状況と委ねる範囲を決める打ち合わせの進行」にすることをお勧めしています。状況と委ねる範囲が決まると、求人票の一行目が書け、転向元が見え、財務の経験者の少なさを転向層で補えます。飛ばして「事業会社で調達と上場の実績がある人」を待つと、数か月が過ぎます。

## まとめ

- 財務の必須要件は、**先に財務か経理か・状況・経営者が委ねる範囲を決め、「入社初日に自社の状況で財務が成り立つか」で三つ以内**に
- 要件が膨らむ理由は**財務と経理を混ぜる・実績の大きさを求める・全部の状況を求める・事業会社の経験を必須にする・資格と年数で書く**
- **事業会社での財務経験・実績の大きさ・資格・年数は必須にしない**。状況に合う経験の中身（どの状況で、何を、どこまで担ったか）で書く
- **経営者と数字で対話した経験**は、どの状況でも必須に近い
- 絞る手順は**財務か経理か→状況→委ねる範囲→体制→全部書き出す→初日に成り立つか→覚えられるか・外部が補えるか→経験の中身に書き換え→歓迎に優先順位→転向元ごとの書き方→三者で確認**
- **面接では一つの資金の判断を状況の把握から結果まで話してもらう**
- **状況によって合う転向元が違う**（銀行、監査法人、投資の会社、コンサルティング、事業会社、経理から）
- 決まらない原因の多くは**状況と委ねる範囲が決まっていない**こと

## よくある質問

### 事業会社での財務の経験が無い人に、財務を任せて大丈夫ですか

自社の状況に合う経験があれば、大丈夫なことが多い。銀行で企業の融資と資金繰りを見てきた人は、資金繰りの管理と銀行対応の状況に、事業会社の財務の経験者より詳しいこともあります。監査法人で上場準備を支援してきた人は、上場準備の状況に合います。確認するのは、「支援する側から、自分で動かす側に回れるか」「事業会社の日々の資金繰りの感覚があるか」で、面接で「一つの資金の判断を順に」話してもらい、経営者と財務の分かる人が判断の質を見ます。事業会社の経験を必須にすると、母集団が数える程度になります。

### 調達の実績がある人でないと、これからの調達を任せられませんか

調達の実績は、本人の力量だけでなく、前職の会社の事業と時期で決まります。実績のある人が自社でも調達できるとは限らず、実績が無くても調達の構造を知っている人（投資の会社出身、調達を支援した経験のある人）が自社の調達を進められることもあります。「〇〇規模の調達の実績」を必須にせず、「調達の構造を理解し、投資家や銀行との対応を担った経験」で書きます。面接で「調達の判断で最も難しかったこと」を聞けば、実績の裏の判断の質が見えます。調達が中心の状況でも、実績より、自社の事業を投資家に説明できるかで判断します。

### 資格を必須にしないと、財務の知識が担保されませんか

資格は知識の目安にはなりますが、自社の状況で判断できるかを示しません。資格があって判断の経験が無い人と、資格が無くて厳しい状況で判断してきた人がいます。資格は歓迎に置き、必須は状況に合う経験で書きます。知識の水準は、面接で財務の分かる人が「一つの資金の判断を順に」聞けば、資格の有無に関わらず分かります。資格を必須にすると、銀行や投資の会社からの転向層（資格を持っていないことが多い）を弾き、母集団が狭まります。
