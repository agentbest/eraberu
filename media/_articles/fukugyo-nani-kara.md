人事や採用の仕事を何年かやってきて、副業で活かしたい。ただ、何から手を付ければよいか分からない。副業の案件を探しに行っても、プロフィールに何を書けばよいか、いくらで受ければよいか、本業の会社に言うべきかで止まる。結論を先に書くと、**最初にやるのは「案件を探す」ことではありません。「経験の棚卸し」「本業の副業の規定の確認」「受けられる時間の固定」「一つの業務に絞った見せ方」の四つを先に済ませます。この四つが無いまま案件を探すと、何を書けばよいか分からず、受けてから時間が足りず、本業との関係で止まります。四つは合わせて数日で済み、済ませてから探すと、最初の一件が決まりやすくなります**。最初の九十日の全体は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、時間の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)にまとめています。本業の規定と法令に関わる部分は一般的な整理にとどめ、個別の判断は専門家にご確認ください。

## 最初で止まる構造

副業を始めようとして、最初で止まるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 案件から探している | 案件の一覧を見て、「自分にできるか」を一件ずつ考え、決められない |
| 経験が言葉になっていない | 「採用を担当していた」までしか言えず、何を頼めるかが依頼側に伝わらない |
| 本業の規定を見ていない | 副業が認められているか、届け出が要るかを知らず、不安のまま止まる |
| 時間が決まっていない | 「空いた時間で」と考え、受けてから時間が足りなくなる |
| 全部できると書いている | 「人事全般」と書き、依頼側は何を頼めばよいか分からず、声がかからない |
| 単価で止まる | 「いくらが妥当か」で悩み、探すところまで進まない |
| 完璧に準備しようとする | ポートフォリオ、職務経歴書、名刺、サイト。全部そろえてからと考え、始まらない |

構造の大半は、「探す前に決めることを、探しながら決めようとしている」ことです。四つを先に済ませれば、探す段階で迷いません。

## 先に済ませる四つ

案件を探す前に済ませる、四つです。

| 順 | やること | 済んだ状態 | 所要 |
|---|---|---|---|
| 一 | 経験の棚卸し | やってきたことを「頼める業務」の単位で三〜五個、書き出せている | 半日 |
| 二 | 本業の規定の確認 | 副業の可否、届け出の要否、禁止の範囲（競業、時間、情報）を、就業規則で確認した | 一時間 |
| 三 | 受けられる時間の固定 | 本業が忙しい週でも固定できる時間を、週の曜日と時間帯で決めた | 一時間 |
| 四 | 一つの業務に絞った見せ方 | 三〜五個のうち、最初に受ける一つを選び、その一つを「範囲」「経験」「進め方」で三文に書いた | 半日 |

四つの要点は、「順番」です。棚卸しが無いと、見せ方が書けません。規定を見ないと、受けてから問題になります。時間が固定されていないと、見せ方に「週何時間」が書けません。一から四の順で、合わせて数日です。

## 一：経験の棚卸し

やってきたことを、「頼める業務」の単位に分けます。肩書きではなく、手が動く範囲で書きます。

| 書き方 | 例の形 |
|---|---|
| 肩書きではなく業務 | 「採用担当」ではなく「求人票の作成」「スカウトの文面の作成と送信」「一次面接の実施」「候補者の日程調整」「内定者のフォロー」 |
| 使った道具と媒体 | 「〇〇（媒体名）でのスカウト運用」「△△（ツール名）での応募者管理」。具体的な名前で |
| 数と期間 | 「月に〇〇通」「年に〇〇名の採用」「三年間」。自分の実績の数字は書いてよい |
| 何が変わったか | 「返信率が上がった」「日程調整の日数が短くなった」。変化を一行 |
| できないこと | 「合否の決定」「年収の提示」「労務の判断」は、外部の立場ではやらないと決める |

棚卸しの要点は、「三〜五個に絞る」ことです。十個書くと、次の「一つに絞る」ができません。自分が最も長くやり、最も数字で語れるものから、三〜五個です。実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に、経歴書の組み替えは[副業用の職務経歴書](/media/fukugyo-shokumu-keirekisho/)に書いています。

## 二：本業の規定の確認

副業を始める前に、本業の会社の規定を確認します。ここを飛ばすと、受けてから止まります。

| 確認すること | 見る場所 | 分かれる対応 |
|---|---|---|
| 副業の可否 | 就業規則の副業・兼業の条項 | 認められている、届け出制、許可制、禁止 |
| 届け出や許可の手続き | 就業規則、人事への確認 | 書式、提出先、期間 |
| 禁止の範囲 | 競業の禁止、情報の持ち出しの禁止、労働時間の制限 | 同業の会社の案件を避ける、本業の情報を使わない、時間の上限 |
| 本業への影響 | 就業規則の「本業に支障が無いこと」の条項 | 稼働時間を固定し、本業の時間帯に副業をしない |
| 相談先 | 人事、上司、社外の専門家 | 規定の解釈は専門家に |

確認の要点は、「禁止の範囲」です。副業が認められていても、競業の禁止と情報の持ち出しの禁止は、ほぼ全ての規定にあります。人事の副業は、本業と同じ業界の会社から声がかかりやすいので、競業の範囲を先に確認します。規定の解釈と、法令上の扱いは、専門家に確認してください。許可の申請の出し方は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、本名を出すかは[本名を出さずに受けられるか](/media/fukugyo-honmyo/)に書いています。

## 三：受けられる時間の固定

「空いた時間で」ではなく、「本業が忙しい週でも固定できる時間」を決めます。

| 決めること | 内容 |
|---|---|
| 週の時間 | 本業の最も忙しい週を思い出し、それでも確保できる時間。多くの人は週に三〜六時間から |
| 曜日と時間帯 | 「平日の夜」「土曜の午前」のように、曜日と時間帯で固定する。「空いたら」にしない |
| 連絡の時間帯 | 依頼側から連絡が来たとき、いつ返せるか。「平日は夜に、土日は午前に確認」など |
| 増やせる条件 | 本業の繁忙期が過ぎたら、慣れたら。増やす判断は三か月後 |
| 減らす条件 | 本業の繁忙期。減らすときは依頼側に事前に |

時間の要点は、「少なくても固定」です。週三時間でも、固定されていれば、依頼側は予定が立ちます。週十時間でも、不安定なら、依頼側は頼めません。時間の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

### エラベルの見解

登録の相談で最も多いのは、「全部できます、と書いてあるが、何を頼めばよいか分からない」というプロフィールです。「採用全般、人事制度、労務、研修」と並び、経験は本物でも、依頼側は「この人に、何を、いくらで頼めるか」が読めません。棚卸しで三〜五個に分け、最初の一つに絞り、「〇〇の媒体でのスカウト運用（検索、文面、送信、一次返信まで）を、週に五時間で」と書き直した人は、その月に声がかかりました。全部できるより、一つが具体的なほうが、頼まれます。

見ていて差がつくのは、「時間を固定しているか」です。「週に十時間くらい、調整できます」と書く人と、「火曜と木曜の夜に二時間ずつ、土曜の午前に二時間、合計六時間」と書く人がいます。後者は、依頼側が予定を立てられるので、頼まれやすい。少なくても固定されている時間が、最初の一件を決めます。

エラベルでは、登録の時点で稼働の時間帯を書いていただきますが、それは依頼側が「この人なら、この曜日に動いてもらえる」と分かるためです。固定できる時間が週に数時間でも、案件はあります。

## 四：一つの業務に絞った見せ方

棚卸しした三〜五個のうち、最初に受ける一つを選び、三文で書きます。

| 選ぶ基準 | 内容 |
|---|---|
| 最も長くやった | 経験の年数と数が最も語れるもの |
| 一人で完結する | 社内の他の人の協力が無くてもできる業務。スカウトの文面、求人票、日程調整など |
| 固定した時間に収まる | 週三〜六時間で、一つの区切りまでできる |
| 本業の規定に触れない | 競業に当たらない、本業の情報を使わない |
| 需要がある | 依頼側が外に出しやすい業務。スカウトの運用、求人票の作成、一次対応、面接の設計 |

| 三文の形 | 例の形 |
|---|---|
| 範囲 | 「〇〇（媒体名）でのスカウト運用を、検索条件の設計・文面の作成・送信・一次返信の対応まで受けます」 |
| 経験 | 「前職で三年間、月に〇〇通を送り、△△職の採用を年に〇〇名担当しました」 |
| 進め方と時間 | 「週に六時間（火・木の夜と土曜の午前）で、初月は文面の型と対象の基準を作り、二か月目から送信します」 |

見せ方の要点は、「範囲」です。「スカウトできます」ではなく、「検索から一次返信まで」と、どこまでやるかを書きます。範囲が書いてあれば、依頼側は見積もりを作れます。範囲の固め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## 案件を探すのはその後

四つを済ませたら、案件を探します。探し方と、最初の一件の選び方です。

| 項目 | 内容 |
|---|---|
| 探す先 | 人事・採用に特化した登録先、知人の紹介、本業で接点のあった会社（規定に触れない範囲で）、一般の副業の仲介 |
| 出す情報 | 四で書いた三文と、棚卸しの一覧。全部を出さず、一つを前面に |
| 最初の一件の選び方 | 範囲が明確、期間が短い（一〜三か月）、固定した時間に収まる、依頼側に人事の担当がいる（相談相手がいる） |
| 避ける一件 | 範囲が「採用全般」で曖昧、期間が長い、稼働が読めない、合否や年収の判断を求められる |
| 受ける前に確認すること | 範囲、期間、時間、報酬の形、含まない業務、判断は誰か、連絡の手段と頻度、成果物の権利、秘密保持 |
| 単価 | 相場を探すより、「時間×自分の時給」から根拠を作る。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) |

探す段階の要点は、「最初の一件は、範囲が明確で期間が短いもの」です。最初から大きな案件を取ろうとせず、一〜三か月で終わる一件を、固定した時間で終わらせる。それが二件目につながります。面談で聞かれることは[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に書いています。

## やらなくてよいこと

始める前に「やらなければ」と思いがちだが、最初は要らないことです。

| やらなくてよいこと | 理由 |
|---|---|
| ポートフォリオを完璧に作る | 最初の一件は、三文と棚卸しで足りる。ポートフォリオは一件目の成果物で作る。[ポートフォリオの作り方](/media/fukugyo-portfolio/) |
| 開業の届け出や屋号 | 税務の扱いは、収入が発生してからでも間に合うことが多い。ただし判断は専門家に。[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/) |
| 名刺やサイト | 最初の一件には要らない |
| 複数の業務を同時に売る | 一つに絞る。二つ目は一件目が終わってから |
| 単価の相場の調査 | 相場より、時間×時給の根拠。相場は案件によって幅が大きく、調べても決まらない |
| 資格の取得 | 人事の副業で、資格が必須の案件は限られる。経験の棚卸しが先 |
| 全部の登録先に登録する | 一つか二つに絞る。多いと、それぞれのプロフィールの更新で止まる |

やらなくてよいことの要点は、「一件目の前に整えるものは、四つだけ」ということです。それ以外は、一件目が終わってから、その成果物で整えます。

### エラベルの見解

担当する側として登録した人の中で、最初の一件が早く決まるのは、「一つに絞って、時間を固定して、範囲を書いた人」です。経験の深さや年数の差より、この三つが揃っているかで、声がかかる速さが変わります。逆に、経験が十年あっても、「人事全般、週十時間くらい、応相談」と書いた人には、声がかかりにくい。依頼側が、何を頼めるか読めないからです。

四つを済ませるのに、数日です。数日で、探す段階の迷いが消えます。案件を探しながら決めようとすると、一件ごとに「自分にできるか」「時間はあるか」「本業は大丈夫か」を考え、決められないまま数か月が過ぎます。

エラベルでは、登録の時点で「一つの業務」「固定した時間」「範囲」を書いていただく形にしています。書けていれば、条件の合う案件のときだけ声がかかり、合わない案件で悩む時間が減ります。稼働時間と単価は、ご自身で決めていただけます。

## まとめ

- 止まるのは**案件から探す・経験が言葉でない・規定を見ない・時間が決まらない・全部できると書く・単価で止まる・完璧に準備する**構造
- 先に済ませるのは**経験の棚卸し（半日）→本業の規定の確認（一時間）→受けられる時間の固定（一時間）→一つの業務に絞った見せ方（半日）**。合わせて数日
- 棚卸しは**肩書きでなく業務・道具と媒体の名前・数と期間・何が変わったか・できないこと**。三〜五個に絞る
- 規定は**可否・手続き・禁止の範囲（競業、情報、時間）・本業への影響・相談先**。解釈は専門家に
- 時間は**忙しい週でも固定できる時間・曜日と時間帯・連絡の時間帯・増やす条件・減らす条件**。少なくても固定
- 見せ方は**最も長く・一人で完結・時間に収まる・規定に触れない・需要がある**一つを、**範囲・経験・進め方と時間**の三文で
- 探すのはその後。**最初の一件は範囲が明確で期間が短いもの**。受ける前に範囲・期間・時間・報酬・含まない業務・判断・連絡・権利・秘密保持を確認
- やらなくてよいのは**完璧なポートフォリオ・届け出（判断は専門家に）・名刺とサイト・複数を同時に・相場の調査・資格・全部の登録先**

## よくある質問

### 経験が三年程度でも、始められますか

年数より、棚卸しで「頼める業務」が一つ書けるかです。三年間、スカウトの送信と返信の対応をしてきたなら、「〇〇の媒体でのスカウト運用」は頼める業務です。年数が短くても、一つの業務で数と変化が語れれば、最初の一件は取れます。逆に、十年あっても業務の単位で書けなければ、頼まれません。まず、三〜五個の棚卸しから始めてください。

### 本業の会社が副業を禁止しています。どうすればよいですか

就業規則の禁止の条項を確認し、禁止の範囲（全面か、届け出や許可で認められるか、特定の業種だけか）を見ます。全面の禁止なら、規定を変えずに始めることは勧めません。届け出や許可で認められるなら、申請の準備をします。規定の解釈と、法令上の扱い（副業の制限がどこまで有効か）は、個別の事情によるので、専門家に確認してください。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、申請の書き方を整理しています。

### 四つを済ませたのに、声がかかりません

三つを見直します。一つ目、「範囲」が具体的か。「スカウトできます」ではなく「検索から一次返信まで」になっているか。二つ目、時間が「曜日と時間帯」で固定されているか。「週十時間くらい」になっていないか。三つ目、絞った一つの業務に需要があるか。依頼側が外に出しにくい業務（合否の判断、労務の判断）を前面にしていないか。三つとも整っていれば、登録先を一つ足すか、知人の紹介を頼みます。最初の一件は、時間がかかることもあります。時間を固定した状態で、待てる形にしておきます。
