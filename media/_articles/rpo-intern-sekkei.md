新卒の採用のために、インターンをやりたい。他社がやっているから、やらないと学生に知られない。ただ、何日で、何をしてもらい、誰が見て、選考とどうつなげるかが決まっていない。去年やってみたが、学生は「見学と雑用だった」と言い、応募にはつながらなかった。結論を先に書くと、**インターンは、「やれば採れる」ものではありません。「目的」「期間と形」「中身」「受け入れと担当」「選考との関係」の五つを先に決めなければ、学生の時間と社内の時間を消費して終わります。五つを決めれば、インターンは「会社を知ってもらい、合う学生と出会う場」になります。選考との関係と学生の扱いは、法令上の定めと公的機関の案内があるので、専門家と確認します**。新卒の定着は[新卒が定着しない](/media/rpo-shinsotsu-teichaku/)に、新卒と中途の配分は[新卒と中途のどちらに投資すべきか](/media/rpo-shinsotsu-ka-chuuto/)にまとめています。インターンと採用選考の関係、学生の扱い、報酬の有無に関する扱いは、公的機関の案内と専門家（社労士など）で確認します。

## インターンが機能しない構造

インターンが機能しないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 目的が無い | 「他社がやっているから」。会社を知ってもらうのか、選考の一部か、決まっていない |
| 中身が無い | 「とりあえず来てもらって、見学と説明」。学生は「何も分からなかった」と帰る |
| 受け入れの担当がいない | 現場が「忙しいのに」で、学生が放置される |
| 期間と形が、目的と合っていない | 一日で「会社を深く知る」は無理。数週間で「見学だけ」は無駄 |
| 選考との関係が曖昧 | 「インターンで評価して選考する」のか「選考とは無関係」なのか。学生にも社内にも不明確。法令上の扱いも確認していない |
| 学生の扱いが決まっていない | 報酬の有無、業務をさせるかどうか、保険。法令上の扱いを確認していない |
| 振り返りが無い | やって終わり。学生の声も、社内の負担も、記録していない |
| 「採用につながらなかった」で止める | 目的が無いので、つながったかどうかも判断できない |

構造の大半は、「五つを決めていない」ことです。決めれば、機能します。

## 目的の決め方

インターンの目的を、最初に決めます。目的で、期間も中身も変わります。

| 目的 | 中身 | 向いている形 |
|---|---|---|
| 会社を知ってもらう | 知名度が無い会社が、学生に会社と仕事を知ってもらう。応募の入口 | 短期（一日〜数日）。会社と仕事の説明、社員との対話、簡単な体験 |
| 仕事を体験してもらう | 職種の仕事を、実際に体験してもらう。「自分に合うか」を学生が判断する材料 | 数日〜数週間。実際の業務の一部、成果物、社員との協働 |
| 合う学生と出会う | 会社が、自社に合う学生を見つける。ただし、選考との関係は法令上の扱いを確認 | 数日〜数週間。課題と協働。相互の見極め |
| 学生の声を聞く | 学生から見た会社の課題、採用の改善の材料 | 短期。対話と振り返り |
| 長期で関わってもらう | 業務を担ってもらい、卒業後の入社につなげる。報酬と契約の形は法令上の扱いを確認 | 数か月〜。実際の業務、報酬、契約 |

目的は、一つに絞るか、主と従を決めます。「知ってもらう」と「見極める」を同時に一日でやろうとすると、どちらも薄くなります。

目的が「合う学生と出会う」「選考につなげる」の場合、インターンと採用選考の関係には法令上の扱いと公的機関の案内があります。専門家に確認のうえで設計します。

## 期間と形の型

目的に合わせて、期間と形を決めます。

| 形 | 期間 | 中身の型 | 受け入れの負担 |
|---|---|---|---|
| 一日型 | 一日 | 会社と仕事の説明、社員との対話、簡単な体験、振り返り | 小。担当者一人と、社員の対話の時間 |
| 数日型 | 二〜五日 | 職種の体験、小さな課題、成果物の発表、社員との協働 | 中。担当者と、現場の受け入れ |
| 数週間型 | 二〜四週間 | 実際の業務の一部、成果物、社員との協働、振り返り | 大。現場の受け入れと教える人 |
| 長期型 | 数か月〜 | 実際の業務、報酬、契約。卒業後の入社につなげる | 大。契約と報酬と業務の管理。法令上の扱いを専門家に確認 |
| オンライン型 | 一日〜数日 | 説明、対話、オンラインの課題 | 小。場所の制約が無い |

形の要点は、「目的と負担の釣り合い」です。「知ってもらう」が目的なら、一日型で足ります。「体験してもらう」なら、数日型。「長期で関わってもらう」なら、契約と報酬の設計が要ります。

社内の受け入れの負担を、先に見積もります。負担が見えないまま「数週間型」を始めると、現場が回らず、学生が放置されます。

学生の扱い（報酬の有無、業務をさせるかどうか、保険、労働時間の扱い）は、形によって法令上の扱いが違います。公的機関の案内と専門家で確認します。

## 中身の設計

学生が「来てよかった」と思い、会社が「合う学生と出会えた」と思う中身の設計です。

| 項目 | 設計 |
|---|---|
| 最初の一時間 | 会社の説明（事業、役割、働き方の実態）、インターンの目的と流れの説明、担当者の紹介。「何のために来てもらったか」を最初に |
| 仕事の体験 | 見学ではなく、手を動かす。「〇〇の一部を、実際にやってみる」。成果物がある形 |
| 社員との対話 | 若手の社員、現場の責任者、経営者。「入社して最初の一年で何をしたか」「大変だったこと」を、具体的に。用意した話ではなく、対話 |
| 課題 | 数日型以上なら、小さな課題。「〇〇について、提案をまとめる」。発表と、社員からの反応 |
| 実態を隠さない | 良いところだけでなく、大変なところ、課題。学生は、隠されると気づく |
| 学生からの質問 | 何でも聞ける時間。答えられないことは「確認して連絡する」 |
| 振り返り | 最後に、学生から「感じたこと」「気になったこと」を聞く。会社の改善の材料 |
| 次の案内 | 応募の流れ、次の接点（説明会、面談）。法令上の扱いに沿って |

中身の要点は、「見学と説明だけにしない」ことと「実態を隠さない」ことです。学生は、手を動かし、社員と対話し、実態を見て、「自分に合うか」を判断します。

「雑用」は、中身になりません。「業務の一部を、成果物がある形で」が、体験です。

### エラベルの見解

相談で最も多い失敗は、「他社がやっているからと、一日のインターンを、会社の説明とオフィスの見学と昼食で組み、学生から『何も分からなかった』と言われ、応募ゼロ」というものです。目的が無く、中身が見学だけでした。目的を「仕事を体験して、自分に合うかを判断してもらう」に絞り、一日の中に「〇〇の一部を実際にやる」時間と、若手の社員との対話と、振り返りを入れたら、学生の反応が変わり、応募につながりました。「やる」ことではなく、「何のために、何をするか」でした。

見ていて差がつくのは、担当者が「目的」から入るかどうかです。「インターンを設計します」で他社の形を持ち込む担当者と、「何のためにやるか（知ってもらう・体験してもらう・出会う・長期）を決めて、期間と中身と受け入れをそこから決めましょう。選考との関係は専門家に確認します」と、目的から入る担当者がいます。後者のインターンは、学生と会社の両方に意味があります。

発注側にできるのは、「インターンをやりたい」の前に、「何のために」を一つに絞ることです。

## 受け入れと担当

インターンの受け入れの担当と、社内の準備です。

**担当者を、一人決める。** 人事か、採用代行の担当者。全体の進行、学生との連絡、社内の調整。

**現場の受け入れの担当を、決める。** 仕事の体験を担う部署と、教える人。「忙しいのに」を避けるため、事前に責任者から依頼し、教える時間を調整します。

**社員の対話の相手を、決める。** 若手の社員、現場の責任者、経営者。事前に「何を話すか」（入社して最初の一年、大変だったこと、続けている理由）を共有。用意した美談ではなく、対話。

**学生への案内を、事前に。** 日程、場所（オンラインなら接続）、持ち物、服装、当日の流れ、担当者の連絡先。

**学生の扱いを、事前に決める。** 報酬の有無、業務の範囲、保険、個人情報の扱い、機密の扱い。法令上の扱いは公的機関の案内と専門家で確認。

**受け入れの環境。** 机、機器、アカウント（要る場合）、昼食の案内。初日に揃っていること。

**社内への周知。** 「〇日にインターンの学生が来る。この部署で、この内容」。周知が無いと、社内が戸惑い、学生が居心地の悪さを感じる。

**緊急時の対応。** 体調不良、事故。連絡先と対応の手順。保険の扱いは専門家に確認。

受け入れの要点は、「担当と現場と対話の相手を、事前に決めて依頼する」ことです。当日に「誰か対応して」では、学生は放置されます。

## 選考との関係と法令上の扱い

インターンと採用選考の関係は、学生にも社内にも明確にします。法令上の定めと公的機関の案内があるので、専門家に確認します。

**関係を、明確にする。** 「インターンは選考ではない」「インターンの参加が、選考に影響しない」「インターンの後に、応募の案内をする」など。自社の方針を、法令上の扱いを確認のうえで決めます。

**学生に、事前に伝える。** 案内の段階と、当日の最初に。「インターンと選考の関係はこうです」。曖昧にすると、学生は「評価されている」と感じ、体験に集中できません。

**社内にも、伝える。** 現場の受け入れの担当と対話の相手に。「学生を評価する場ではない」（方針がそうなら）。「評価する場」と現場が思うと、対話が面接になります。

**インターンの記録の扱い。** 学生の情報、課題の成果物、対話の内容を、どう扱うか。個人情報の扱いと、選考への使用の可否は、法令上の扱いを専門家に確認します。

**時期に関する扱い。** インターンの実施の時期、選考の開始の時期に関する公的機関の案内があります。確認して従います。

**報酬と業務の扱い。** 業務をさせる場合の報酬、労働時間、保険の扱い。形によって法令上の扱いが違います。専門家に確認します。

**方針は、毎年確認する。** 法令と公的機関の案内は変わることがあります。毎年、実施の前に確認します。

選考との関係の要点は、「明確にし、伝え、法令上の扱いに沿う」ことです。曖昧なまま「インターンで見極めよう」とすると、学生の信頼と法令上の扱いの両方で問題になります。

## 振り返りと改善

インターンは、やって終わりにせず、振り返って改善します。

**学生の声を、集める。** 最後の振り返りで、「感じたこと」「気になったこと」「他社と比べて」。任意のアンケートも。学生の声が、会社の改善の材料です。

**社内の声を、集める。** 受け入れた現場、対話の相手、担当者。「負担はどうだったか」「学生の反応は」「次に変えたいこと」。

**目的に対して、どうだったかを見る。** 「知ってもらう」なら、参加者の数と、その後の応募。「体験してもらう」なら、学生の「合うかどうか」の判断ができたか。「出会う」なら、（法令上の扱いに沿って）その後の接点。

**費用と時間を、記録する。** 社内の時間（担当者、現場、対話の相手）と、費用（学生の交通費、昼食、報酬など）。次の設計の材料。

**インターンから応募・入社した人の、その後を見る。** 定着したか。インターンが「合う学生と出会う場」として機能したかの、最終の確認。

**次の設計に、反映する。** 「中身の〇〇は良かった」「受け入れの△△が足りなかった」。一つずつ改善。

**やめる判断も、持つ。** 目的に対して機能せず、負担が大きいなら、形を変えるか、やめる。「他社がやっているから」で続けない。

振り返りの要点は、「目的に対して、どうだったか」を見ることです。目的が無いと、振り返りもできません。

## 外注する場合の範囲

インターンの設計を、採用代行に出す場合の範囲です。

**出せる工程。** 目的の整理の進行、期間と形の案、中身の設計（説明、体験、対話、課題、振り返り）、受け入れの担当と現場への依頼の整理、社員の対話の相手への事前の共有の資料、学生への案内の文面、学生の扱いの整理（法令上の扱いの確認の専門家への橋渡し）、選考との関係の整理（専門家の確認を経て）と学生と社内への伝え方、当日の進行、学生の声と社内の声の収集、振り返りと次の設計への反映、費用と時間の記録。

**社内に残す判断。** 目的の決定、実施の決定、現場の受け入れの担当と教える人の指名、社員の対話の相手の指名、学生の扱いの方針（専門家との連携）、選考との関係の方針（専門家との連携）、予算。

**外注の効きどころ。** インターンは、「目的が無く、中身が見学だけ」になりやすい取り組みです。担当者が目的から設計し、中身を体験と対話にし、受け入れと当日の進行を担えば、社内は現場の受け入れと対話に集中できます。担当者は複数の会社のインターンを見ているので、「この目的なら、この形と中身」の型を持ち込めます。ただし、法令上の扱いは、担当者も専門家に確認します。

**外注しても動かない場合。** 目的を決めない、現場が受け入れを断る、選考との関係を曖昧なままにする、振り返りをしない。社内の判断で、代行を替えても直りません。

インターンは、五つを先に決めれば機能します。外注は、五つを決める手順と、設計と進行を持ち込む手段です。

### エラベルの見解

担当する側から見ると、インターンの相談で最も多いのは、「学生の時間を軽く見ている」ことです。学生は、学業と他社のインターンと就職活動の中で、一日か数日を使って来ます。「来てもらえばよい」で見学と説明だけにすると、学生は「時間を無駄にした」と感じ、その感想は他の学生に伝わります。

学生の一日を、「会社にとって意味のある一日」ではなく「学生にとって意味のある一日」として設計する。手を動かす体験、社員との本当の対話、実態を隠さない説明、学生の声を聞く振り返り。それで、学生は「来てよかった」と言い、その言葉が次の学生を呼びます。

発注側にできるのは、インターンの中身を、「学生がこの一日で何を得るか」から設計することです。

## よくある質問

### インターンをやれば、新卒の応募は増えますか

目的と中身が無ければ、増えません。「知ってもらう」を目的に、手を動かす体験と社員との対話と実態を隠さない説明で設計すれば、学生は「来てよかった」と言い、その言葉が次の学生を呼び、応募につながります。見学と説明だけのインターンは、学生の時間を消費し、「時間を無駄にした」という感想が伝わります。目的に対して振り返り、改善を続けることが前提です。「やれば採れる」ではありません。

### インターンで学生を評価して、選考に使ってよいですか

インターンと採用選考の関係、インターンの記録の選考への使用、実施の時期には、法令上の定めと公的機関の案内があります。自社の方針を決める前に、専門家に確認します。方針を決めたら、学生に案内の段階と当日の最初に明確に伝え、社内の受け入れの担当と対話の相手にも伝えます。曖昧なまま「見極めよう」とすると、学生の信頼と法令上の扱いの両方で問題になります。

### 現場が「忙しいので受け入れられない」と言います

受け入れの負担を、形で調整します。一日型なら、現場の負担は「体験の一時間と、対話の三十分」程度に収まります。数週間型は、教える人と時間の調整が要るので、現場の負担が大きいことを責任者が認め、教える時間の分の業務を調整します。事前に責任者から依頼し、「何を、何時間」を明確にすれば、「忙しいのに」は減ります。当日に「誰か対応して」では、現場は断り、学生は放置されます。
