機械設計の採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、機械を知らない人に設計者の採用が回せるのか」「図面を見ないと判断できないのに、外の人に何ができるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、機械設計の中身と対象と工程の整理・任せる範囲・図面の扱い・要件の決定・設計の質の評価・合否の判断は社内に残す**のが線です。機械設計は、電気設計や建築設計と同じく「設計の分かる人」は社内にいます。足りないのは、採用の工程を回す人と、「何を設計し、どこまで任せるか」を候補者に伝わる形で書く工程です。そこが代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、隣接する電気設計の線は[電気設計採用を代行に出す判断基準](/media/rpo-denki-sekkei-rpo/)にまとめています。

## 機械設計採用が他の職種と違う点

一つ目は、「機械設計」の中身が会社によって違い、市場も違うことです。量産製品の設計（筐体、機構、部品）、受注装置の設計（一品ものの生産設備、検査装置、搬送装置）、治具や金型の設計、部品の設計。量産製品の設計者は、コストと量産性と品質を見ながら設計し、受注装置の設計者は、納期と一品ごとの要求を見ながら設計します。動き方が違い、すぐに入れ替わるわけではありません。「機械設計募集」だけでは、どれを求めているかが候補者に伝わりません。

二つ目は、担当する工程と扱う対象で求める人が変わることです。工程は、構想設計（何をどう作るかを決める）、詳細設計（部品の図面）、解析、試作と評価、量産移行。構想から任せるのと、決まった構想で部品図を描くのでは、求める人が違います。対象は、装置の大きさ、精度、動く速さ、材料。精密な小型の機構と、大型の搬送装置では、持っているものが違います。

三つ目は、候補者が「何を設計し、構想から関われるか、作る側とどう関わるか」を最初に確かめることです。機械設計者は、扱う製品や装置、担当する工程、自分で構想を決められるか、電気やソフトとの分担、製造や生産技術との関係（作れる設計かを誰が見るか、試作の予算を誰が決めるか）を見ます。「機械設計業務全般」では、この判断ができません。

四つ目は、設計の質は社内で見られるが、採用の工程を回す人がいないことです。設計部長が図面を見て、面接で設計の考え方と判断を聞くことはできます。しかし、求人票を書き、媒体を運用し、スカウトを送り、応募者に当日返信し、設計部長の面接の日程を確保する、という工程を回す人が、社内にいません。

五つ目は、経験者の母数が少なく、引き抜きの競争になることです。機械設計者は、いまどこかの会社で製品や装置を担当していて、転職を考えていない人が多い。求人を出して待つ採用では届かず、こちらから届ける採用の比重が大きくなります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 機械設計の中身（量産・装置・治具金型・部品）の整理 | 残す | 自社がどれを求めているか。社内にしか分からない |
| 対象と工程の整理 | 残す | 何の製品や装置か、構想からか詳細からか。設計部長が決める |
| 任せる範囲の決定 | 残す | 構想を決めるところまで任せるか。電気・ソフト・製造との分担。設計部長が決める |
| 図面の扱いの決定 | 残す | 候補者の図面をいつ、誰が、どう見るか。守秘の扱い |
| 要件の決定 | 残す | 中身・対象・工程から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（中身・対象・工程と任せる範囲が決まっていれば） | 決まったものを候補者に伝わる言葉にする。扱う製品や装置を具体的に |
| 媒体の選定と運用 | 任せられる | 機械設計に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 中身・対象・工程に合わせた検索と、担当した製品や装置に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、図面の提出の案内 |
| 設計部長の面接の日程の確保 | 任せられる | 開発の締切の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 中身・対象・工程の分類は任せられる。図面と設計の質の評価は残す |
| 図面と設計の考え方の評価 | 残す | 設計部長が見る |
| 任せる範囲と開発の実態の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断。他社との比較が厳しい |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。担当中の開発の区切りに合わせた入社日の調整 |

線の要点は、「機械設計の中身・対象・工程と、任せる範囲が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の経験に合う設計か」を判断する材料になります。

### エラベルの見解

相談で多いのは、「機械設計を募集しているが、応募が来ない。来ても、自社と違う中身の人」というご相談です。求人票を見ると、「機械設計募集。機械設計業務全般。3D CAD経験者優遇」と書かれていて、量産製品なのか受注装置なのか、何の製品や装置なのか、構想から任せるのか部品図なのかが無い。量産の人も装置の人も治具の人も、「自分向けか分からない」で閉じるか、全員が応募して中身が合わないかのどちらかになっていました。

見ていて差がつくのは、「何を設計し、どこまで任せるかを一文で言えるか」です。「当社は食品工場向けの搬送装置を受注で設計しており、採る人には、顧客の要求から構想を決め、詳細設計と組立の立ち会いまでを担当してほしい。電気設計は別の担当と分担し、加工は協力工場で、作れる設計かは生産技術と一緒に見る」。一文で中身・対象・工程が分かれば、量産の筐体の人は自分向けでないと分かり、装置を構想から担いたい人は自分向けだと分かります。エラベルでは、機械設計の案件をお受けする前に、依頼側に「中身・対象・工程」と「任せる範囲」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、四つを社内で確認します。

**一つ目：機械設計の中身・対象・工程。** 量産製品か受注装置か治具金型か部品か。何の製品や装置か。構想からか、詳細からか、解析や試作評価や量産移行も含むか。採る人に任せる工程はどこからどこまでか。

**二つ目：任せる範囲と分担。** 構想を自分で決められるか、決まった構想で設計するか。電気設計、ソフト、生産技術、製造、品質保証との分担はどうか。作れる設計かを誰が見るか、試作の予算を誰が決めるか。担当する製品や装置の数と規模。将来、どこまで広げるか。

**三つ目：いまの設計の状態と実態。** 誰が何を担当していて、何が属人化していて、何が止まっているか。設計部長が全部を見ていて回らない、図面と現物が合っていない、設計変更が製造に伝わっていない。開発の締切前の実態、休日の形、出張（客先での組立や立ち会い、協力工場）の頻度。正直に把握し、「どこまで書くか」を決めます。

**四つ目：設計部長が、面接にどのくらい時間を出せるか。** 開発の締切の中で、面接の枠をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

四つのうち、一つ目と二つ目が代行に出す前提です。三つ目と四つ目は、代行と一緒に整理できます。

## 設計部長の関与のさせ方

機械設計の採用では、設計部長の関与が要ります。図面を見る、面接で設計の考え方と判断を聞く、任せる範囲と開発の実態を正直に話す。しかし設計部長は開発の締切を抱えていて、「採用は総務の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると設計部長がどう楽になるか」を具体的に示すことです。「この人が入れば、部長が抱えている搬送装置の詳細設計を一つ渡せる」。そして、負担を最小にする形で頼みます。面接の枠は代行が締切の合間に押さえる、図面と経歴は代行が整理して渡す、任せる範囲の説明の要点は代行が用意する。設計部長がやるのは、図面を見て設計の考え方を聞くことと、実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で設計部長が「設計の話」をすることの価値を、設計部長自身に理解してもらうことです。機械設計者は、面接で設計の話が通じるかを見ています。経営者だけの面接では、候補者は「設計を分かっている会社か」を判断できず、辞退します。設計部長が「この装置で一番難しいのは、この機構の精度と速さの両立で、こう考えている」と話すと、候補者は「設計者として扱われる会社」と判断します。

## 代行を選ぶときの確認項目

機械設計の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者にメーカーや設計部門の経験があるか。** 機械設計そのものでなくても、製造業の技術部門や、技術者の採用を回した経験。量産・装置・治具金型の違いと、工程の違いを知っているか
- **中身・対象・工程と任せる範囲を求人票にどう書くか、案を出せるか。** 「機械設計業務全般」で済まさず、扱う製品や装置と工程を書けるか
- **機械設計に届く媒体と経路の経験。** 技術者に強い媒体、スカウト、知人経由、協力工場や取引先とのつながり、大学や高専とのつながり。経路ごとの経験と、引き抜きの競争の中での動き方
- **図面の扱いの段取り。** 候補者の図面をいつ、どう受け取り、誰に渡し、守秘をどう扱うか
- **設計部長の日程を押さえる段取り。** 開発の締切の合間に面接の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。製造業を知らない担当者は、量産と装置を区別せずに求人票を作り、図面の扱いを雑にして、候補者に「設計を分かっていない会社」と読まれます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、機械設計の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「中身と対象が絞れていない」と指摘されることです。代行が求人票を作ろうとして、「量産ですか、装置ですか。何の装置ですか。構想から任せますか」と聞かれ、答えられない。これは代行に出したから起きる問題ではなく、出す前から絞れていなかったものが表に出ただけです。ここで中身を決めます。

二つ目は、応募者の経路と中身が分かれることです。大手メーカーの設計部門、中小の装置メーカー、治具や金型の設計会社、設計会社や派遣、生産技術や製造から設計へ。それぞれ持っているものが違い、任せる工程と合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることを変えます。

三つ目は、「作る側との関係」で候補者が判断を変えることです。「作れる設計かを誰が見るか」「試作の予算を誰が決めるか」「設計変更をどう製造に伝えるか」が曖昧だと、機械設計者は「作れない図面を描かされて、製造に責められる」か「製造の言いなりで設計が決められない」のどちらかを想像します。面接で設計部長が、製造や生産技術との関係を正直に話すことで、候補者の判断が変わります。

### エラベルの見解

担当する側から見ると、機械設計の採用で最も効くのは、「何を設計し、構想から任せるか」と「作る側との関係」を求人票に書くことです。機械設計者は、扱う製品や装置で面白そうかを判断し、構想から関われるかと、作る側との関係で「設計者として扱われるか」を判断します。「機械設計業務全般」と「3D CAD経験者優遇」だけの求人票は、どの中身の設計者にも「自分向けか分からない」で閉じられます。

エラベルでは、機械設計の案件で担当者を紹介するとき、最初の一週間で設計部長から「中身・対象・工程」「任せる範囲」「製造や生産技術との関係」「開発の実態」を聞き取り、一文にするところから始めてもらっています。図面と設計の質の評価は設計部長が行い、面接で設計の話ができる形を担当者が段取りします。

## まとめ

- 機械設計採用が他と違うのは**中身（量産・装置・治具金型・部品）で市場が分かれる・工程と対象で求める人が変わる・候補者が「何を設計し、構想から関われるか、作る側とどう関わるか」を最初に確かめる・設計の分かる人はいるが採用の工程を回す人がいない・経験者が少なく引き抜きの競争**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、中身と対象と工程・任せる範囲・図面の扱い・要件・設計の質の評価・合否は残す**
- 代行に出す前に**中身・対象・工程、任せる範囲と分担（作る側との関係を含む）、いまの設計の状態と実態、設計部長の面接の時間**を確認する
- 設計部長の関与は**採用でどう楽になるかを示し、負担を最小にして、設計の話をする価値を理解してもらう**
- 代行を選ぶときは**製造業の経験・任せる範囲の書き方・経路の経験・図面の扱い・日程の段取り**を確認する
- 出したあとは**中身が絞れていないことが表に出る・経路と中身が分かれる・作る側との関係で判断が変わる**。判断は設計部長と経営者、材料は代行

## よくある質問

### 量産製品と受注装置の両方を設計してほしいのですが

両方を担ってもらうとしても、「最初にどちらを主に」を決めます。量産製品の設計者はコストと量産性を、受注装置の設計者は納期と一品ごとの要求を見て設計し、動き方が違います。両方を深く経験した人は限られます。「主は受注装置の構想から詳細まで。量産部品の改良は二年目から」のように、主と従と順番を書けば、装置の経験者が「量産の改良なら」と判断できます。両方を同じ重さで必須にすると、該当者がいなくなります。

### 候補者の図面はどう受け取ればよいですか

一次対応の段階で「これまで設計された製品や装置が分かる資料（図面、写真、概要）を見せていただけますか」と案内し、受け取り方（データか印刷か、守秘の扱い）を明示します。候補者の図面には前職の守秘がかかっているものが多く、候補者が見せられる範囲（公開されている製品の写真、概要の説明、守秘に触れない部分の図面）で出してもらいます。図面が出せない場合は、面接で「担当した装置の構成と、一番苦労した機構」を口頭で聞き、設計部長が判断します。受け取った資料は設計部長だけが見て、面接後に返すか削除するかを伝えます。この段取りは代行に出せます。

### 経験者がいないので、生産技術や製造の人を設計者として採れますか

作る側を知っている人が設計に移るのは、経路の一つです。ただし、構想設計や強度の判断は別の経験で、教える体制と期間が要ります。「教える設計部長がいるか」「最初に任せる工程（部品図の修正、既存装置の改良から）」「一人で担当できるまでの目安」を決め、経験者の募集と分けて出します。経験者の募集に「未経験歓迎」を足すと、経験者は「誰でもいい会社」と読んで見送るので、分けて出します。
