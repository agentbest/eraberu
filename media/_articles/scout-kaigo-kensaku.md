介護職にスカウトを送る前の検索で、「介護経験、〇〇（資格）」で条件を組むと、特養で重い介護度の方を担当してきた人、有料やグループホームで比較的自立した方を担当してきた人、デイや訪問で日勤だけの人が、同じ一覧に出てきます。加えて、通えない勤務地の人も混ざります。もう一つ大きいのは、経験者だけを探すと、少ない市場で競合と同じ人に送ることになり、返信が来ないこと。介護職の検索で最初にやるべきは、自施設の業態と介護度と勤務地を決め、経験者を採るか未経験を採るかを決め、経験者と未経験者で読み方を分けることです。結論を先に書くと、**検索条件は、先に自施設の業態と介護度と勤務地と、経験者を採るか未経験を採るかを決め、資格や年数ではなく経験（業態・介護度・夜勤の経験・役割）で組み、要件の必須だけにし、経験者は「どの業態でどの介護度の方を、どの体制で、何を担ったか」で読み、未経験は「前職で人と接してきたか、体力と夜勤の希望、勤務地」で読み、業態は絞ったまま勤務地を通える範囲まで広げ、未経験の層を前職の種類で厚くして送る順を決めます**。文面の型は[介護職へのスカウト文面](/media/scout-kaigo-bunmen/)に、要件の作り方は[介護職の採用要件の作り方](/media/rpo-kaigo-youken/)に書いていますので、ここでは「検索条件とターゲティング」に絞ります。媒体ごとの検索の仕様には触れません。仕様は各媒体の公式情報でご確認ください。介護職員の配置や資格に関わる法令上の扱いは専門家にご確認ください。

## 先に「業態と介護度」「勤務地」「経験者か未経験か」を決める

自施設の業態（特養、老健、有料、グループホーム、デイ、訪問など）と介護度（重い方が中心か、自立した方が中心か）、勤務地（通える範囲）、経験者を採るか未経験を採るか（両方なら条件を二つ）を決めます。三つで探す人が変わります。

| 決めること | 探す人が変わる点 |
|---|---|
| 業態と介護度 | 重い介護度の施設と自立した方の施設は、身体的負担も業務の中身も違う。経験者は業態と介護度で読む |
| 勤務地 | 通える範囲の人。介護職は勤務地で生活が決まり、夜勤があれば通勤の負担も大きい |
| 経験者か未経験か | 経験者は業態と介護度と夜勤の経験で。未経験は前職と体力と夜勤の希望で。条件も文面も分ける |

止まりやすいのは、「介護経験者」で業態と介護度を決めないときと、経験者だけを探して競合と同じ人に送るときです。決め方は[介護職の採用要件の作り方](/media/rpo-kaigo-youken/)に書いています。

## 資格や年数ではなく経験で組む（経験者と未経験で分ける）

条件に入れるのは、資格や年数ではなく、要件の必須に当たる経験です。資格は、配置に法令上必要な場合だけ必須にし、それ以外は歓迎にします。経験者と未経験で条件を分けます。

| 向き | 要件 | 検索条件に |
|---|---|---|
| 経験者 | 必須：〇〇（業態）で〇〇（介護度）の方を担当した経験 | 業態と介護度の言葉で |
| 経験者 | 必須：夜勤の経験（夜勤の枠なら） | プロフィールで読む |
| 経験者 | 歓迎：資格、リーダー経験、年数 | 入れない（配置に必要な資格は別） |
| 未経験 | 必須：勤務地が通える範囲 | 勤務地で |
| 未経験 | 読む：前職で人と接してきたか（接客、販売、保育、サービス）、体力と夜勤の希望 | プロフィールで読む |
| 未経験 | 歓迎：資格の取得への関心 | 入れない |

止まりやすいのは、資格を「安心だから必須」にして数人しか出ないときです。配置に必要な資格だけを必須にし、それ以外は外します。資格の要否は専門家にご確認ください。

## 経験者は「どの業態でどの介護度の方を、どの体制で、何を担ったか」で読む

経験者の経験の中身は、四つで読めます。どの業態で、どの介護度の方を、どの体制で（夜勤の有無と回数、職員の人数）、何を担ったか（介助、リーダー、記録、家族対応、機器の使用）。四つが書いてある人は、資格や年数が何であっても合うかが読めます。

| プロフィールの記述 | 読み方 |
|---|---|
| 「介護職として施設勤務」 | 業態も介護度も無い。中身が読めない |
| 「特養で介護度〇〇が中心の方を担当。夜勤月〇回。リフトを使用」 | 業態、介護度、夜勤、機器の経験が分かる |
| 「グループホームで自立した方の生活支援。日勤のみ」 | 業態と介護度が違う。重い介護度の施設には身体的負担の差を文面で触れる |
| 「デイサービスで送迎と入浴介助。夜勤無し」 | 日勤のみ。夜勤の枠には合わない。日勤の枠なら対象 |
| 「ユニットリーダーとして〇名のチームを担当」 | リーダーの経験。リーダーを任せるなら有力 |
| 「希望：〇〇（地域）、日勤のみ」 | 勤務地と働き方の希望。枠と照らす |

止まりやすいのは、資格と年数だけで判断するときです。「施設勤務」の人に「特養で夜勤あり」と送っても、経歴と合うかが分かりません。

## 未経験は「前職で人と接してきたか、体力と夜勤の希望、勤務地」で読む

未経験者の見どころは、三つです。前職で人と接してきたか（接客、販売、保育、飲食、サービス）、体力と夜勤の希望（体を使う仕事の経験、夜勤や交代制の経験、日勤のみの希望）、勤務地（通える範囲）。介護の経験は無いので、「介護に関心がある」の記述があれば加点しますが、無くても前職と勤務地で対象になります。

| プロフィールの記述 | 読み方 |
|---|---|
| 「接客で〇年。お客様と話すのが好き」 | 人と接する経験。未経験の有力な対象 |
| 「保育で〇年。体を使う仕事に慣れている」 | 人と接し、体力もある。有力 |
| 「工場で交代制勤務」 | 夜勤の経験。夜勤の枠に慣れやすい |
| 「事務で〇年。人と接する仕事に変わりたい」 | 転向の意欲。体力と夜勤の希望を文面で確かめる |
| 「希望：〇〇（地域）、日勤のみ、資格を取りたい」 | 勤務地と働き方と関心が分かる |

止まりやすいのは、未経験者を「介護に関心がある」の記述だけで探すときです。関心を書いている人は少なく、前職と勤務地で広く読んだほうが対象は増えます。

### エラベルの見解

相談で最も多い思い込みは、「介護職は資格と経験がある人を探すしかない」というものです。実際には、経験者は市場に少なく、競合も同じ人に送っていて、返信が来にくい。未経験者は、前職で人と接してきた人が多くいて、競合が送っていないことが多く、迎え入れる仕組みがあれば戦力になります。ある施設では、資格と経験で検索して数人にしか送れず、返信も無い状態でした。担当者が入って、業態と介護度を「特養、介護度〇〇が中心」と決め、経験者向けは業態と介護度と夜勤の経験で読み、未経験向けは「接客」「販売」「保育」「交代制」の記述と勤務地で読む形にし、文面を二つに分けたところ、経験者からの返信は少しでしたが、未経験者から複数の返信が来て、育成の仕組みで受け入れました。介護職の検索は、資格と経験で機械的に絞るより、経験者と未経験者で読み方を分け、未経験の層を前職で厚くするほうが合います。

## 業態は絞ったまま、勤務地を通える範囲まで広げ、未経験の層を前職の種類で厚くする

対象が少ないときは、業態を広げるのではなく、勤務地を「通える範囲」まで広げ、未経験の層を前職の種類で厚くします。業態が違う経験者（グループホームから特養、デイから入所）は身体的負担と夜勤の有無が違うので、文面で違いに触れれば対象になることもありますが、まず勤務地と未経験の層で広げます。

| 広げる方向 | 見どころ | 文面 |
|---|---|---|
| 勤務地を通える範囲まで | 住んでいる地域、以前の施設の場所、通勤の手段 | 件名に地域を出し、通勤の目安と夜勤明けの帰り方を書く |
| 未経験の層（接客・販売・飲食） | 人と接する経験 | 前職が活きることを一行目に。不安への答えを厚く |
| 未経験の層（保育・サービス） | 人と接し、体を使う経験 | 同上。体力への答えを事実で |
| 未経験の層（交代制の経験） | 夜勤や交代制の経験 | 夜勤の枠に。夜勤の時期と体制を書く |
| 隣の業態の経験者 | 業態が違うが介護の経験がある。転向の記述 | 業態の違い（介護度、夜勤）に先に触れる |

止まりやすいのは、対象が少ないからと、通えない勤務地の人に送るときです。介護職は夜勤明けの通勤も負担で、通えない人は動きません。

## 送る順の付け方

| 順 | 条件 |
|---|---|
| 一（経験者） | 業態と介護度が自施設と合い、夜勤の経験が枠と合い、勤務地が通える範囲で、四つが書いてあり、一行目に書ける一点がある |
| 二（経験者） | 業態が近く、介護度がやや違う。文面で身体的負担の差に先に触れる |
| 三（未経験） | 前職で人と接してきて、勤務地が通える範囲で、体力と夜勤の希望が枠と合う。未経験の文面で送る |
| 四（未経験） | 前職が事務などで転向の意欲がある。勤務地が合う。不安への答えを厚く書いて送る |
| 送らない | 勤務地が通えない。働き方の希望が枠と合わない（日勤のみを望む人に夜勤の枠のみ）。四つも前職も読めず資格と年数だけ。一行目に書ける一点が無い |

止まりやすいのは、「資格があるから」で送るときです。業態と介護度と勤務地と働き方の近さで順を付けます。

## 条件の保存と見直し

組んだ条件は、「経験者・夜勤枠用」「経験者・日勤枠用」「未経験・接客系用」「未経験・交代制経験用」のように向きと枠と前職ごとに名前を付けて保存し、送った結果と一緒に記録します。月に一度、返信が来た人の共通点（業態、介護度、夜勤、前職、勤務地）を見て、条件と読み方を直します。保存の仕方は[検索条件の保存と使い回し](/media/scout-kensaku-hozon/)に書いています。

### エラベルの見解

担当する側から見ると、介護職の検索で会社ごとに差がつくのは、「未経験を採る仕組みを作って、未経験の層を対象に入れているか」です。業態と介護度と勤務地は施設長に聞けば決まりますが、「経験者と資格者」だけを探す施設では、少ない市場で競合と同じ人に送り続けて返信が来ません。育成の仕組み（最初の一か月、指導者、手順書、夜勤の時期、資格の支援）を作っている施設では、前職で人と接してきた未経験の層を対象に入れられ、競合が送っていない層に届き、採用が回り始めます。エラベルでスカウトの検索を担当する人には、条件を組む前に、施設長と本部に「業態と介護度と勤務地は何か、経験者を採るか未経験を採るか、未経験を採るなら育成の仕組みはあるか」を聞いてもらっています。文面の型は[介護職へのスカウト文面](/media/scout-kaigo-bunmen/)に書いています。

## 代行に出す場合の範囲

担当者が持つのは、要件から必須の経験を取り出して条件を組むこと、出てきた人を経験者は「どの業態でどの介護度の方を、どの体制で、何を担ったか」で、未経験は「前職で人と接してきたか、体力と夜勤の希望、勤務地」で読んで絞ること、向きと枠と層で送る順を付けること、条件と結果を記録して月に一度見直すこと、です。会社が持つのは、業態と介護度と勤務地の決定、経験者を採るか未経験を採るかの決定、育成の仕組みの用意、要件の必須と歓迎の区別（配置に必要な資格は専門家に確認）、施設長と本部が担当者に話す時間、です。担当者が介護職の経歴（業態、介護度、夜勤）と未経験者の前職を読める経験があるかは、担当者を選ぶときに確かめます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## まとめ

- 先に**業態と介護度・勤務地・経験者を採るか未経験を採るか**を決める。三つで探す人と読み方が変わる
- 検索条件は**資格や年数ではなく経験（業態・介護度・夜勤の経験・役割）**で組み、**経験者と未経験で条件を分ける**。資格は配置に法令上必要な場合だけ必須に
- 経験者は**「どの業態でどの介護度の方を、どの体制で、何を担ったか」**、未経験は**「前職で人と接してきたか、体力と夜勤の希望、勤務地」**で読む
- 対象が少ないときは**業態は絞ったまま、勤務地を通える範囲まで広げ、未経験の層を前職の種類（接客・販売・保育・交代制）で厚くする**
- **通えない勤務地の人、働き方の希望が枠と合わない人には送らない**
- 条件は**向きと枠と前職ごとに分けて保存し、返信が来た人の共通点で月に一度直す**

## よくある質問

### 未経験者を採ると、教える手間で現場が回らなくなりませんか

育成の仕組み（最初の一か月は指導者が付いて日勤のみ、手順書、夜勤は数か月後）を先に作れば、現場の負担は最初の一か月に集中し、その後は戦力になります。仕組みが無いまま未経験者を入れると、現場が疲れて未経験者も辞めます。仕組みを作るかどうかを施設長と本部が決め、作るなら未経験の層を対象に入れ、作らないなら経験者だけを探します。経験者だけでは市場が少ないことを踏まえて決めます。

### 資格を持っている人を優先したいのですが

配置に法令上必要な資格は必須にし、それ以外は歓迎にとどめます。資格があっても業態と介護度が違えば身体的負担の差で合わないことがあり、資格が無くても前職で人と接してきた未経験者は、仕組みがあれば戦力になり、資格は入職後に支援して取れます。資格の要否は配置から決め、法令上の扱いは専門家にご確認ください。資格の取得を支援する施設は、その支援を文面に書くと、未経験者に響きます。

### 出てくる人が少なすぎます

資格か年数で絞っているか、経験者だけを探しているか、勤務地を狭く取りすぎているかを見ます。資格を配置に必要な範囲だけにし、年数を外し、勤務地を「通える範囲」（夜勤明けの帰り方も含めて）まで広げ、未経験の層を前職の種類で読む形にします。経験者だけでは市場が少ないので、未経験の層を含めることが前提になります。含めるなら、育成の仕組みを先に作ります。
