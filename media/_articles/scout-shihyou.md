スカウトの指標として、何を見ればよいのか。返信率は見ている。ただ、その数字が良いのか悪いのかも、次に何をすればよいのかも、そこからは出てこない。代行のレポートには数字が並ぶが、読んでも「で、どうする」が決まらない。結論を先に書くと、**スカウトの指標は、「返信率」一つではなく、送信・開封・返信・面談・応募・内定の六段について、「数」「日数」「層」の三つを並べます。そのうえで、自社がいま動かせる指標を三つに絞り、それだけを毎週見ます。六段全部を毎週見ると、数字を眺めるだけで終わります**。どの単位で切るかは[どの単位で効果を検証するか](/media/scout-kensho-tan-i/)に、採用全体のKPIの置き方は[採用KPIに何を置くべきか](/media/rpo-kpi-erabenai/)にまとめています。

## 指標が役に立たない構造

指標を見ているのに、次の行動につながらないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 返信率一つしか無い | 返信の前（開封）と後（面談、応募）が見えず、どこで落ちているか分からない |
| 数しか見ていない | 「返信が十件」だけで、返信までの日数も、返信した人の層も無い |
| 段が飛んでいる | 送信と内定だけ。間の四段が無く、どこを直せばよいか分からない |
| 全部を毎週見ている | 六段×三つで十八の数字を眺め、どれも動かさない |
| 動かせない指標を追っている | 「内定率」を上げようとするが、スカウト運用で直接動かせるのは送信と文面と対象 |
| 良し悪しの基準が外にある | 「相場より低い」で判断するが、役割と層と媒体が違えば比べられない |
| 報告が数字の羅列 | 「次に何を変えるか」が無く、報告を受けて終わる |

構造の大半は、「段が揃っていない」ことと、「動かせるものに絞っていない」ことです。揃えて、絞れば、指標は行動につながります。

## 六段の指標

スカウト運用の段は、六つです。段ごとに「数」を取ります。

| 段 | 数 | 率（前の段に対して） | 主に効く要素 |
|---|---|---|---|
| 送信 | 送った通数 | — | 対象の選び方、送信の体制 |
| 開封 | 開かれた通数（媒体で見られる場合） | 開封率 | 件名、送り主、時間帯 |
| 返信 | 返信が来た数。前向き・質問・断りの内訳 | 返信率 | 一段落目、材料、長さ、次の一歩、対象の層 |
| 面談 | 面談に至った数 | 面談率 | 日程の出し方、面談の位置づけ、追客 |
| 応募 | 面談の後、応募（選考に進む意思）に至った数 | 応募率 | 面談の質、役割と条件の見せ方 |
| 内定・入社 | 内定を出した数、入社した数 | 内定率、入社率 | 選考の設計、条件、辞退への対応 |

六段のうち、スカウト運用で直接動かせるのは、送信・開封・返信・面談の四段です。応募と内定は、面談以降の社内の選考で決まります。ただし、応募と内定を見ないと、「返信は来るが、層が違って内定に至らない」を見落とします。四段を動かし、六段を見る、が形です。

## 数と日数と層の三つの見方

六段の「数」に加えて、「日数」と「層」を見ます。この二つが無いと、数字の理由が分かりません。

| 見方 | 内容 | 分かること |
|---|---|---|
| 数 | 段ごとの件数と、前の段に対する率 | どの段で落ちているか |
| 日数 | 段から段までの日数。送信から返信まで、返信から面談まで、面談から応募まで | どの段で止まっているか。数は落ちていないのに日数が長い段は、追客の問題 |
| 層 | 各段に残っている人の層。経験の深さ、現職、年代の幅 | 「数は来ているが層が違う」を見つける。返信は多いのに面談で落ちるなら、対象の層のずれ |

三つの見方の要点は、「数だけで判断しない」ことです。返信率が同じでも、返信までの日数が短く前向きな内容が多いか、日数が長く断りが多いかで、次にやることは変わります。層が違えば、文面ではなく対象を直します。

## 動かせる指標に絞る

六段を並べたら、毎週見る指標は三つに絞ります。絞る基準は、「いま落ちている段」と「自社で動かせるか」です。

| 落ちている段 | 絞る三つの例 | 動かす要素 |
|---|---|---|
| 開封で落ちている | 開封率、送信数、件名の型別の開封率 | 件名、送り主、時間帯 |
| 返信で落ちている | 返信率、返信の前向きの割合、返信までの日数 | 一段落目、材料、対象の層 |
| 面談で落ちている | 面談率、返信から面談までの日数、面談に至った人の層 | 日程の出し方、追客、面談の位置づけ |
| 応募・内定で落ちている | 応募率、面談に来た人の層、辞退の理由の内訳 | 対象の層（スカウト側）、面談と選考（社内側） |
| どこも大きくは落ちていない | 送信数、返信率、面談率 | 送信の量と体制 |

絞る要点は、「三つ以外は月に一度だけ見る」ことです。毎週は三つ、月次で六段全部。三つは、落ちている段が変わったら入れ替えます。三か月同じ三つを見続けているなら、落ちている段が動いていないか、絞り方が合っていないかのどちらかです。

## 指標の読み違い

指標を見るときに、よく起きる読み違いです。

| 読み違い | 実際 |
|---|---|
| 返信率が上がったので文面が良くなった | 対象の層を変えた、送信数を減らして厳選した、時期が良かった、のどれかかもしれない。何を変えたかを添えて読む |
| 返信率が高い役割は順調 | 層が広くて取りやすいだけで、面談以降で落ちているかもしれない。六段で見る |
| 断りの返信は失敗 | 断りの返信は、読まれた証拠。返信が無いより情報が多い。断りの理由を層別に見ると、対象のずれが分かる |
| 開封率が低いのは件名が悪い | 送り主の名前、時間帯、媒体の表示の仕様の場合もある。件名だけ変えて比べる |
| 面談率が低いのは候補者の意欲が低い | 日程の候補が合わない、返信から日程の提示までが遅い、追客が無い、の場合が多い。日数を見る |
| 内定率が低いのはスカウトの問題 | 面談以降の選考の設計や条件の場合が多い。層が合っているなら、スカウト側の問題ではない |
| 他社の数字と比べて低い | 役割・層・媒体・送り主が違えば比べられない。比べるなら自社の前月と |

読み違いの要点は、「率の変化に、変えたことを添える」ことです。何も変えていないのに率が動いたなら、時期か対象の偶然です。何かを変えて率が動いたなら、それが原因の候補です。

### エラベルの見解

相談で最も多い失敗は、「返信率が上がったのを喜んでいたら、面談に来る人の層が変わっていて、選考でほぼ全員を落としていた」というものです。担当者が返信率を上げるために対象を広げ、返信は増えたが、採りたい層ではなかった。返信率一つを追った結果です。六段を並べ、返信した人の層と面談に至った率を足したら、「対象を広げた分の返信は、面談率も応募率も低い」とすぐ分かり、対象を戻して、返信率は下がりましたが、面談以降の数は増えました。指標は、一つを上げるためではなく、六段の流れを見るためにあります。

見ていて差がつくのは、担当者が「断りの返信」をどう扱うかです。断りを「失敗」として数えるだけの担当者と、「断りの理由を層別に分けると、対象のずれが分かる」と読む担当者がいます。後者の運用は、対象の精度が月ごとに上がります。

発注側にできるのは、返信率だけを聞くのをやめ、「返信した人の層は、採りたい層でしたか」と聞くことです。

## 報告の型

指標の報告に、最低限入れる項目です。数字の羅列ではなく、「次に何を変えるか」が付いている形です。

| 項目 | 内容 |
|---|---|
| 今月の六段 | 数と率。前月と並べる |
| 日数 | 段から段までの日数。前月と並べる |
| 層 | 各段に残っている人の層の内訳 |
| 今月変えたこと | 何の軸を、どう変えたか。一つ |
| 変えた結果 | 対応する指標が、どう動いたか。変えていないなら「変えていない」 |
| 落ちている段 | 六段のどこか。前月から動いたか |
| 来月の三つ | 毎週見る三つの指標と、動かす要素 |
| 来月変えること | 一つ |

報告の要点は、「今月変えたこと」と「来月変えること」が一つずつ入っていることです。これが無い報告は、数字の羅列です。レポートに入れてもらう項目の交渉は[レポートに入れてもらう項目](/media/scout-daikou-report/)に、週次の十五分の型は[週次の振り返りで見る数字](/media/scout-furikaeri/)に書いています。

## 外注する場合の範囲

指標の設計を、スカウト代行に出す場合の範囲です。

**出せる工程。** 六段の記録の整備、日数と層の記録の追加、毎週見る三つの指標の選定と入れ替え、週次の確認、月次の報告（六段・日数・層・変えたこと・来月の三つ・来月変えること）、指標の読み違いの指摘、落ちている段の特定、動かす要素の提案と実施（送信・開封・返信・面談の四段）、断りの理由の層別の整理。

**社内に残す判断。** 採りたい層の定義（層の指標の基準）、応募・内定の段の記録の提供（面談以降は社内で起きる）、毎週見る三つの承認、動かす要素の承認（対象の層の変更、材料の追加など）、面談以降の落ちに対する社内の対応。

**外注の効きどころ。** 指標は、「六段を揃え、日数と層を足し、三つに絞り、変えたことを添えて報告する」運用で、社内では「返信率だけを見て、上がった下がったで一喜一憂」になりやすい工程です。担当者が記録の型と報告の型を持ち込み、落ちている段に合わせて三つを選び、四段を動かせば、指標は行動につながります。担当者は複数の会社の六段を見ているので、「この役割でこの段が落ちるなら、まずここ」という出発点を持ち込めます。ただし、応募と内定の段は社内で決まるので、そこの記録と対応は社内からしか出ません。

**外注しても動かない場合。** 面談以降の結果を社内が記録しない、採りたい層を定義しない、返信率だけで評価する、「次に何を変えるか」の提案を受けても承認しない。社内の判断で、代行を替えても直りません。

指標は、六段の数・日数・層を並べ、動かせる三つに絞り、変えたことを添えて見れば、行動につながります。外注は、記録と報告の型と、四段を動かす手を担う手段です。

### エラベルの見解

担当する側から見ると、指標の相談で最も多いのは、「日数を見ていない」ことです。数は落ちていないのに、返信から面談まで二週間かかっている。候補者は「話を聞きたい」と返信したのに、日程の提示が遅く、その間に他社で決まる。返信率も面談率も大きくは落ちないので、数だけ見ていると気づきません。日数を足すと、「返信から日程の提示まで、平均で四日」のような事実が出て、それが最も動かしやすい指標になります。

日数は、記録に日付があれば計算できます。送信日、返信日、面談の日。三つの日付を残すだけで、二つの日数が出ます。数字の中で、最も安く取れて、最も効く指標です。

発注側にできるのは、「返信から面談まで、いま何日かかっていますか」と担当者に聞くことです。答えられなければ、日付が記録されていません。

## まとめ

- 役に立たないのは**返信率一つ・数だけ・段が飛んでいる・全部を毎週・動かせない指標・基準が外・数字の羅列**構造
- 段は**送信・開封・返信・面談・応募・内定**の六つ。直接動かせるのは前の四段、見るのは六段
- 見方は**数・日数・層**の三つ。数だけで判断しない
- 毎週見るのは**落ちている段に合わせた三つ**。それ以外は月に一度。落ちている段が変わったら入れ替える
- 読み違いは**率の変化に変えたことを添える**ことで防ぐ。断りの返信は情報、他社とは比べない
- 報告は**六段・日数・層・今月変えたこと・結果・落ちている段・来月の三つ・来月変えること**。変えることが一つずつ入る
- 外注できるのは**記録・日数と層・三つの選定・週次・月次・読み違いの指摘・段の特定・四段の実施・断りの整理**。社内に残るのは**採りたい層・面談以降の記録・三つの承認・要素の承認・社内の対応**

## よくある質問

### 返信率の良し悪しの基準はありますか

役割・層・媒体・送り主・時期で大きく変わるので、外の基準と比べても判断できません。比べるのは自社の前月です。同じ役割・同じ層・同じ媒体で、前月と比べて上がったか下がったか、そのとき何を変えたか。それが良し悪しの基準になります。媒体側が参考の数値を出している場合もありますが、条件が違うので目安に留め、公式の案内で確認してください。

### 代行のレポートに開封率がありません

媒体によっては開封の情報が取れないものがあります。取れない媒体なら、開封の段は空欄で構いません。その場合、件名の効果は返信率で間接的に見るしかないので、件名を変えるときは他を固定して返信率で比べます。媒体で開封の情報が取れるかどうかは、公式の案内で確認してください。取れるのに出ていないなら、レポートに足してもらいます。

### 指標を見る会議が長くなります。何を削ればよいですか

毎週の会議で六段全部を見ているなら、三つに絞ります。三つと、「今週変えたこと」「来週変えること」だけで、十五分で終わります。六段全部と日数と層は、月に一度の会議で見ます。会議が長いのは、指標が多いからではなく、「次に何を変えるか」が決まらずに数字を眺めているからです。三つに絞ると、変えることが決まりやすくなります。週次の型は[週次の振り返りで見る数字](/media/scout-furikaeri/)に書いています。
