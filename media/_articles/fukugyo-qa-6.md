副業を始めたら、報酬はいつ入るのか。本業の給与のように毎月決まった日に入るのか、稼働のたびに入るのか、それとも案件が終わってからなのか。始める前に見当がつかず、生活の計画が立てられない。結論を先に書くと、**人事の副業の報酬は、多くの場合、「稼働した月の締め日の後、依頼側か窓口の支払日に」振り込まれます。稼働してから入金まで、一か月以上空くのが普通で、最初の入金は、始めてから二か月前後先になることが多いです。**時期は契約の形と入口で変わるので、契約の前に確認し、最初の入金までの期間を見込んでおけば、慌てません。締め日と支払日の確認の仕方は[支払いサイトの確認](/media/fukugyo-shiharai-site/)に、請求を出す時期は[請求のタイミング](/media/fukugyo-seikyuu-timing/)に、口座の準備は[決済・振込先の準備](/media/fukugyo-kessai/)にまとめています。税や契約の解釈は、専門家にご確認ください。

## 支払いの流れの基本

報酬が入るまでの流れは、本業の給与とは違います。流れを知っておくと、時期の見当がつきます。

| 段階 | 起きること | 目安 |
|---|---|---|
| 一、稼働 | その月に作業する | 月の初めから終わりまで |
| 二、締め | 依頼側か窓口の締め日で、その月の稼働が確定する | 月末が多いが、二十日や十五日の会社もある |
| 三、報告と請求 | 稼働の報告と請求書を出す。窓口経由なら窓口の形式で報告する | 締め日の前後。締め日の後に出す形も |
| 四、依頼側の確認と処理 | 依頼側の担当者が確認し、経理が処理する。窓口経由なら窓口が依頼側に請求する | 数日から数週間 |
| 五、支払い | 依頼側か窓口の支払日に振り込まれる | 締め日の翌月末が多いが、翌々月の会社もある |
| 六、入金の確認 | 自分の口座で確認し、記録に残す | 支払日の当日か翌営業日 |

流れの要点は、「稼働と入金の間に、締めと処理の期間が挟まる」ことです。本業の給与は、会社が毎月決まった日に処理して振り込みますが、副業の報酬は、自分が報告と請求を出し、依頼側が処理して、支払日に振り込む、という段階を踏みます。段階のどこかで止まると、入金が遅れます。

## 稼働から入金までに時間がかかる理由

一か月以上空くのは、依頼側の事情によるもので、遅れているわけではありません。

| 理由 | 内容 |
|---|---|
| 締め日で稼働が確定する | 月の途中で稼働した分は、その月の締め日まで確定しない。締め日の前に請求は出せない |
| 依頼側の支払日が決まっている | 多くの会社は、支払いをまとめて特定の日に行う。「月末締め・翌月末払い」なら、月初の稼働から入金まで二か月近く |
| 依頼側の社内の承認がある | 請求書が担当者から経理に回り、承認を経て支払いの手続きに入る。数日から数週間かかる |
| 窓口経由なら、窓口の処理が挟まる | 窓口が依頼側に請求し、依頼側から窓口に入金があってから、窓口が担当者に振り込む。一段階多い |
| 請求の締めに間に合わないと翌月扱いになる | 請求書が締め日に間に合わなければ、次の締めで処理され、一か月ずれる |

理由の要点は、「請求の締めに間に合わないと、一か月ずれる」ことです。自分の側で請求が遅れると、依頼側の処理は次の締めになり、入金は一か月先になります。締め日と、請求書が経理に届く必要のある日を、契約の前に聞いておくことが、入金の時期を守る最も確かな方法です。請求の出し方は[請求書の書き方](/media/fukugyo-seikyuusho/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「稼働したら、その月のうちに報酬が入る」というものです。実際には、稼働した月の締めの後に請求し、依頼側の支払日に入るので、最初の入金は始めてから二か月前後先になることが多いです。これを知らずに始めると、最初の一か月が過ぎても入金が無く、「支払われないのでは」と不安になります。知っていれば、それは遅れではなく、普通の流れだと分かります。

見ていて差がつくのは、契約の前に締め日と支払日を聞き、最初の入金の日を自分で計算しているかです。計算している人は、その日まで入金が無くても不安にならず、その日を過ぎたら確認に動けます。計算していない人は、いつ入るか分からないまま待ち、遅れているのかどうかも判断できません。エラベルでは、依頼側との契約の際に締め日と支払日を確認し、担当者に最初の入金の見込みの時期を伝えています。時期が分かっていれば、待つことは不安ではなく、予定になります。

## 契約の形と入口で変わる時期

報酬の時期は、契約の形と、案件の入口で変わります。

| 契約の形・入口 | 支払いの時期 | 注意 |
|---|---|---|
| 月額固定・直接契約 | 毎月、締め日の後の支払日に固定の額 | 稼働が月の途中から始まった初回は、日割りかどうかを確認 |
| 時間単価・直接契約 | 毎月、締め日で確定した時間分を、支払日に | 月末の稼働分が翌月の請求になるか、見込みで出すかを決めておく |
| 成果報酬 | 契約で決めた成果の時点（内定承諾、入社など）の後に | 成果の確認の時期と、支払いまでの期間を契約で決める。[成果報酬型は受けるべきか](/media/fukugyo-seika/) |
| 固定と成果の組み合わせ | 固定分は毎月、成果分は成果の時点の後に | 別々の請求になるか、一枚にするかを依頼側と決める |
| 仲介サービス経由 | サービスの締めと支払日に。手数料を引いた額 | サービスごとに時期が違う。登録時に確認 |
| 登録型の窓口経由 | 窓口の締めと支払日に | 窓口が依頼側から入金を受けてから担当者に支払う形なら、直接契約より遅くなることがある |

形の要点は、「成果報酬は、いつ入るかが読めない」ことです。成果が出るまで入金が無く、成果の定義が曖昧だと、いつ確定するかも分かりません。生活の計画に入れる報酬は、固定か時間単価の分だけにし、成果報酬は入ったら加える、という見立てにします。契約の形の違いは[契約はどうなるか](/media/fukugyo-qa-5/)に、収入の見立ては[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に書いています。

## 最初の入金までの期間の見込み方

始める前に、最初の入金がいつになるかを、自分で見込んでおきます。

| 手順 | 内容 | 例 |
|---|---|---|
| 一、稼働を始める日を置く | 契約の開始日 | 〇月の初め |
| 二、締め日を確認する | 依頼側か窓口の締め日 | 月末 |
| 三、請求を出す日を決める | 締め日の前後で、依頼側が指定する日 | 月末の数日前 |
| 四、支払日を確認する | 依頼側か窓口の支払日 | 翌月末 |
| 五、最初の入金の日を出す | 開始した月の締め→支払日 | 〇月に始めたら、翌月末に最初の入金 |
| 六、その間の生活の計画を立てる | 最初の入金までの期間、副業の収入は無い前提で | 二か月分は本業の収入だけで計画する |

見込みの要点は、「最初の入金までの期間は、副業の収入を計画に入れない」ことです。始めてすぐに副業の収入を当てにすると、入金の時期とずれて困ります。最初の入金までは本業の収入だけで計画し、入金が始まってから副業の分を計画に入れます。入金の記録の付け方は[決済・振込先の準備](/media/fukugyo-kessai/)に整理しています。

## 契約の前に確認する項目

報酬の時期に関わることは、契約の前に確認します。聞いておかないと、入金が読めません。

| 確認する項目 | 聞き方 |
|---|---|
| 締め日 | 「稼働の締め日はいつですか」 |
| 支払日 | 「お支払いはいつになりますか」 |
| 請求書が届く必要のある日 | 「請求書はいつまでにお送りすればよいですか」 |
| 支払いの方法 | 「銀行振込でよろしいですか」 |
| 振込手数料の扱い | 「振込手数料はどちらの負担になりますか」 |
| 初回の扱い | 「月の途中から始まる場合、初回は日割りになりますか」 |
| 窓口経由の場合、窓口の支払日と手数料 | 「窓口の締め日と支払日、手数料はどうなりますか」 |
| 遅れた場合の連絡先 | 「お支払いが遅れた場合、どなたに確認すればよいですか」 |

確認の要点は、「請求書が届く必要のある日」を聞くことです。締め日が月末でも、「請求書は月末の三営業日前まで」のような決まりがある会社があり、それを過ぎると翌月扱いになります。締め日と、請求書の期限は、別に聞きます。確認の全体は[支払いサイトの確認](/media/fukugyo-shiharai-site/)に、初回の打ち合わせで聞く項目は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に書いています。

## 入金額が請求額と違う場合

入金があっても、請求した額と違うことがあります。違いの理由を知っておくと、慌てません。

| 違いの理由 | 内容 | 対処 |
|---|---|---|
| 振込手数料が引かれている | 依頼側が手数料を引いて振り込む契約 | 契約で確認していれば問題ない。記録に差を書く |
| 窓口の手数料が引かれている | 窓口経由の案件で、窓口の手数料分 | 登録時に率を確認していれば問題ない。記録に書く |
| 源泉徴収の処理 | 依頼側の経理が税の処理をして振り込む場合がある | 仕組みは専門家に。依頼側から処理の書類が出ることがある |
| 日割りや稼働の差 | 初回の日割り、時間単価の稼働の確定の差 | 稼働の報告と突き合わせる |
| 依頼側の処理の誤り | 額の入力の誤り、二重の処理 | 依頼側の担当者に事実を伝えて確認する |
| 請求の一部が保留になっている | 依頼側の確認が済んでいない項目がある | 担当者に「どの項目が保留か」を聞く |

違いの要点は、「差の理由を、記録に書く」ことです。入金額が請求額と違うたびに、理由を記録しておけば、年の終わりに専門家に渡すときに説明でき、依頼側との認識のずれも早く見つかります。理由が分からない差は、その月のうちに依頼側か窓口に聞きます。記録の型は[決済・振込先の準備](/media/fukugyo-kessai/)に、税の処理は[確定申告はどうするか](/media/fukugyo-qa-10/)を見たうえで、専門家にご確認ください。

## 遅れたときの対処

支払日を過ぎても入金が無いときの対処です。順番を守ると、関係を壊さずに済みます。

| 順 | 対処 | 内容 |
|---|---|---|
| 一 | 自分の側を確認する | 請求書を出したか、締めに間に合っていたか、口座の情報が正しかったか |
| 二 | 支払日から数営業日待つ | 依頼側の処理の都合で数日ずれることがある |
| 三 | 担当者に事実で確認する | 「〇日のお支払い予定分が、まだ確認できていません。処理の状況を教えていただけますか」 |
| 四 | 理由を聞き、新しい日を確認する | 依頼側の側の遅れなら、いつ振り込まれるかを文面で |
| 五 | それでも入らなければ、文面で催告する | 契約と請求の内容を示し、期限を切って。窓口経由なら窓口に |
| 六 | 専門家に相談する | 催告の後も入らなければ、次の手続きは専門家に |

対処の要点は、「一」の自分の側を先に確認することです。請求書を出し忘れていた、締めに間に合っていなかった、口座の番号が違っていた、という自分の側の原因は珍しくありません。それを確認せずに依頼側に催促すると、自分の側の原因だった場合に信頼を失います。詳しい手順は[報酬が支払われないときの対処](/media/fukugyo-mibarai/)に整理しています。契約の解釈と手続きは、専門家にご確認ください。

### エラベルの見解

担当する側から見ると、報酬の時期で困っていない人は、契約の前に締め日と支払日と請求の期限を聞き、最初の入金の日を自分で計算し、請求を毎月同じ日に出し、入金を記録している人です。この四つがあれば、入金は予定通りに来るか、来なければ理由をすぐ確認できます。困っている人は、時期を聞かずに始め、いつ入るか分からないまま待ち、遅れているのかどうかも判断できない状態です。

順番として、契約の前に締め日・支払日・請求の期限・手数料の扱いを聞き、最初の入金の日を計算し、その日までは副業の収入を計画に入れず、請求を毎月同じ日に出し、入金を記録し、支払日を過ぎたら自分の側を確認してから依頼側に聞く。この順番で、報酬の時期は不安ではなく予定になります。エラベルでは、依頼側との契約の際に締め日と支払日を確認し、担当者への支払いの時期を最初に伝える形にしています。報酬の時期が読めることは、副業を続けるための土台です。

## まとめ

- 報酬は**稼働した月の締め日の後、支払日に**振り込まれる。稼働から入金まで一か月以上空くのが普通
- 最初の入金は**始めてから二か月前後先**になることが多い。その間は副業の収入を計画に入れない
- 時期は**契約の形（固定・時間・成果）と入口（直接・仲介・窓口）**で変わる。成果報酬は読めない
- 契約の前に**締め日・支払日・請求の期限・支払方法・手数料・初回の扱い・窓口の条件・遅れた場合の連絡先**を確認する
- 入金額が請求額と違うときは**理由を記録に書く**。分からない差はその月のうちに聞く
- 遅れたら**自分の側を確認→数営業日待つ→担当者に事実で確認→新しい日を文面で→催告→専門家**

## よくある質問

### 最初の入金まで二か月も空くのは、普通ですか

普通です。月の初めに稼働を始め、月末に締め、翌月末に支払われる契約なら、最初の入金は二か月近く先になります。これは遅れではなく、多くの会社の支払いの仕組みによるものです。二か月より短い会社もあれば、長い会社もあり、契約の前に締め日と支払日を聞けば分かります。始めてから一か月で入金が無いことを心配する前に、契約で決まった支払日を確認してください。

### 依頼側から「支払いは案件が終わってからまとめて」と言われました

案件が数か月続くなら、終わってからまとめて支払う形は、その間の入金が無く、途中で終わった場合の扱いも曖昧になります。「毎月の締めでお願いできますか」と相談し、難しければ「〇か月ごと」のように区切りを入れる形を提案します。依頼側の予算の都合で難しい場合は、契約書に支払いの時期と、途中で終わった場合の扱いを明記してもらいます。まとめ払いの契約は、契約の解釈を専門家に確認したうえで受けるかを決めます。

### 窓口経由だと、直接契約より入金が遅くなりますか

窓口が依頼側から入金を受けてから担当者に支払う形なら、依頼側の支払日の後に窓口の処理が入り、直接契約より遅くなることがあります。逆に、窓口が依頼側の入金を待たずに担当者に支払う形なら、直接契約と変わらないか、早いこともあります。窓口ごとに違うので、登録の時点で「締め日と支払日はいつですか」「依頼側の入金を待つ形ですか」と聞いておきます。時期が分かっていれば、遅いこと自体は問題になりません。
