農業法人や生産者が採用代行を検討するときは、露地・施設・畜産・加工販売の職務、通年と季節の人数、募集地域と受け入れ体制を分けて整理します。人数と雇用条件、作業・生活の実態、採否や配属の判断は自社で確認し、必要な専門判断は専門家に相談します。求人原稿、候補者連絡と日程、情報と記録、入社準備の補助をどこまで任せられるかは、支援先の対応と契約で確認します。地域の採用の型は[地方企業の採用代行](/media/rpo-chihou-kigyo-rpo/)に、外国人の受け入れの分け方は[外国人採用に踏み出せない](/media/rpo-gaikokujin/)に書いています。

## 農業業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 型で求める人と経路が違う | 露地は季節と体力、施設は通年と設備、畜産は毎日の世話と生き物、加工と販売は接客と企画。来る人も動く理由も違う | 型と雇用の形ごとに求人票と経路を分ける必要がある |
| 季節で人数が動く | 繁忙期と閑散期で必要な人数が違い、通年の雇用と季節の雇用が混在する。毎年同じ時期に足りない | 季節の逆算と、通年の母集団（毎年来る人の記録）が要る |
| 地域と住居と移住が前提 | 候補者の生活そのもの（住居、移動、家族、地域との関係）を設計する必要がある | 住居と移住の情報を整理して先に出すかで応募が変わる |
| 憧れで来て実態でずれる | 「自然の中で」「移住して」の希望で応募が来るが、天候と体力と作業の単調さと収入の型で離れる | 実態を先に出して合う人に絞ることが要 |
| 在留・資格・契約と経営者の時間 | 外国人の受け入れ、機械の資格、契約の形に法令上の整理がある。経営者は現場で採用に時間が無い | 整理は会社と専門家。一次対応を残すと流れる |

外部の支援だけで採用や定着が決まるわけではありません。どの工程の実務を補えるかと、現場が確認・判断する内容を対応させます。入社準備や受け入れの事務まで一律に対象外とせず、業務の範囲、現地での担当、本人情報と権限を確認して分担します。

## 工程ごとの「任せられる・残す」

| 工程 | 社内で確認・判断すること | 外部へ相談する実務と確認事項 |
|---|---|---|
| 人数と雇用・職務条件 | 作付けと出荷、必要人数と期間、仕事と条件の決定 | 要件と募集計画の整理、対象職務・地域への対応 |
| 在留・資格・契約 | 個別条件を専門家と確認し、判断担当を決める | 必要情報の収集・記録、専門家への受け渡し範囲 |
| 求人原稿と募集経路 | 作業・時間・収入・住まい等の事実確認 | 原稿作成、広告・紹介と運用、社内の承認 |
| 候補者の一次確認 | 職務に必要な経験・能力の基準、採否の判断 | 経歴の照合と情報不足の区分、本人情報と権限 |
| 連絡・面談と見学体験 | 回答・承認者、面談枠と現地の実施体制 | 返信・日程と案内、体験の実施は内容・安全・費用等を確認 |
| 入社準備と受け入れ | 配属、教える人、住まい等の用意と本人説明 | 書類案内・日程・情報整理など、支援可能な範囲を確認 |
| 記録と再連絡 | 保存・利用の条件と本人の意向、終了時の扱い | 接触と選考の記録、連絡・停止、引き継ぎ |

「季節ごとの人数」と「生活の立ち上げ」は、農業に特有の残す工程です。在留と資格と契約の形は、法令上の整理があると一般に整理されているため、会社と専門家が扱います。個別の判断は専門家にご確認ください。

### エラベルの見解

農業業界で多くの法人が見落とすのは、「毎年同じ時期に足りない」のに、毎年ゼロから集めていることです。繁忙期の前に募集を出し、集まった人で乗り切り、閑散期に離れ、次の年にまた募集を出す。前の年に来た人の記録（誰が、どの作業を、どれくらい、どう働いたか、また来たいか）が経営者の頭の中にあり、声をかける型が無い。「毎年来る人の記録」を会社に置き、繁忙期の前に定期の連絡をする。それだけで、毎年の募集の負担が変わり、作業を知っている人が戻ってきます。無ければ、代行に出す最初の工程は記録の型と定期の連絡です。過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 型と季節と人数 | 露地・施設・畜産・加工販売のどの型で、通年・季節・外国人のどの形を、いつからいつまで、何名。作付けと出荷の計画からの逆算 |
| 整理 | 在留、機械の資格、契約の形を、会社と専門家で整理したか |
| 実態 | 天候と体力、作業の一日の流れ、単調な期間、収入の型、繁忙期の稼働を、経営者が語れるか |
| 生活 | 住居、移動、地域の生活、家族の受け入れの情報が一枚にあるか。用意できるものは何か |
| 枠 | 経営者の面接と体験の枠を、作業の合間に週に一つ先に預けられるか |
| 受け入れ | 最初の一か月の作業、教える人、生活の立ち上げの手伝いが決まっているか |
| 記録 | 型と雇用の形と季節をまたいで、毎年来る人を含む一覧があるか |

「実態を経営者が語れるか」と「生活の情報が一枚にあるか」が要です。要件の言い換えは[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 型と雇用の形ごとに代行の型が違う

| 型・形 | 採用の特徴 | 代行に出しやすい工程 |
|---|---|---|
| 通年の中核（施設、畜産、加工販売） | 長く働く人。経験か育成。生活の設計が要 | 農業の学校と移住の窓口に届く経路、生活の情報の整理、一次対応 |
| 季節の雇用（露地の繁忙期） | 毎年来る人と新しい人。期間と作業と住居 | 毎年来る人の記録と定期の連絡、季節の経路、一次対応 |
| 外国人の受け入れ | 在留の整理が前提。受け入れの体制 | 整理された形に沿った運用、記録。判断は会社と専門家 |
| 加工と販売 | 接客と企画。農業の外からも来る | 隣接の職種に届く経路、要件の言い換え |

複数の型と形を持つ法人は、それぞれ代行の型が違うことを前提に、形ごとに「任せる・残す」を決めます。外国人の受け入れの手順は[外国人採用の実務の進め方](/media/rpo-task-gaikokujin-saiyo-susumekata/)に書いています。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| 農業業界の経験 | 担当者が農業法人の採用を担った経験があるか。型と季節の違いを知っているか |
| 生活の情報の扱い | 住居と移住の情報を一枚にして求人票に添える型を持っているか |
| 実態で絞る文面 | 憧れの応募を天候と体力と収入の型で絞る求人票を作った経験があるか。「自然の中で」だけの文面を勧めてこないか |
| 季節の運用 | 毎年来る人の記録と定期の連絡、繁忙期の前の逆算の運用ができるか |
| 整理への理解 | 在留と資格と契約の判断には踏み込まず、整理された形に沿って運用するか |
| 費用 | 「工程・稼働時間・担当人数」をそろえて比べる。額の大小だけで決めない |

費用は、依頼する工程と稼働時間で大きく変わるため、同じ工程で比べる軸をそろえます。内訳の見方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 段階 | 確認する状態 | 社内と支援先で行うこと |
|---|---|---|
| 開始前 | 職務条件・作業と生活の情報、必要な専門確認がそろうか | 不足情報と承認担当・期限を決める |
| 募集開始 | 原稿と経路、返信・面談枠の準備ができたか | 承認後に掲載・連絡し、問い合わせと未回答を記録する |
| 選考中 | 職務に合う候補と辞退理由、日程の停滞 | 条件・説明と体制を見直し、見学体験は内容と担当を確認する |
| 入社が決まった後 | 本人との条件合意と受け入れ準備 | 配属・教える人・生活準備と事務を分担する |
| 次の繁忙期の前 | 計画と必要人数、過去候補の連絡条件 | 本人の意向と保存・利用条件を確かめ、募集と連絡を計画する |

応募が減っただけで絞り込みの成功とは判断できません。対象者への到達、求人の条件・公開状態、職務に合う応募数、返信と辞退・面談までの経過を確認します。体験の実施や一年後の定着も記録できますが、目的・職務と本人の状況をそろえて見ます。応募数・定着率の単独の増減や、固定の月数だけで代行の効果や原因を決めません。

### エラベルの見解

農業業界で見落とされやすいのは「生活の情報」が求人票に無いことです。候補者は、作業の内容と同じくらい、「どこに住むのか」「車は要るのか」「買い物と病院はどこか」「家族は来られるか」「地域とどう関わるのか」を見ています。ところが求人票は作業と条件だけで、生活の情報は面接で聞かれてから答える。移住を伴う応募では、生活の情報が無いと応募の前で止まり、あっても不安なまま来て離れます。住居、移動、地域の生活、家族の受け入れを一枚にして求人票に添える。用意できるもの（住居、車、地域とのつなぎ）と、本人が用意するものを分けて書く。添えていなければ、経路を増やす前に生活の情報の整理です。地域の採用の組み直しは[地方拠点の採用が進まない](/media/rpo-chihou-saiyo/)に書いています。

## まとめ

- 職務と通年・季節の雇用、地域と必要人数・期限をそろえる
- 社内の判断と、原稿・連絡・日程・入社準備等の外部実務を契約で分担する
- 在留・資格・契約の個別判断は専門家との担当を確認する
- 作業と条件・生活情報を事実確認し、本人の判断に必要な内容を伝える
- 過去候補への再連絡は、保存・利用条件と本人の意向を確認する
- 固定の採用月や応募減少を成功とせず、対象候補から面談・入社までの記録で見直す
- 費用は同じ範囲・期間と社内時間をそろえて比べる

## よくある質問

### 小さな農業法人で、代行を使うほどの規模ではありません

規模が小さいほど、経営者の時間が採用の詰まりになりやすく、一次対応と生活の情報の整理と毎年来る人への連絡だけを出す効果は大きい。「大げさ」になるのは全部を出す場合で、一次対応と記録だけなら小さく始められます。経営者は面接と体験と受け入れに絞る、という分け方です。地域の複数の法人で代行の担当者を分け合う形もあります。

### 外国人の受け入れを代行に任せられますか

在留の整理と受け入れの体制の判断は、法令上の整理があると一般に整理されているため、会社と専門家（行政書士等）で行います。個別の判断は専門家にご確認ください。代行が担えるのは、整理された形に沿った募集の運用、一次対応、書類の整理、記録、受け入れの記録までで、在留の判断には踏み込みません。受け入れの分け方は[外国人採用に踏み出せない](/media/rpo-gaikokujin/)に書いています。

### 移住で来た人が一年で離れます

離れる理由を記録で分けます。「作業の実態（天候、体力、単調な期間）」「収入の型」「生活（住居、移動、孤立）」「地域との関係」のどれかで、直す場所が違います。作業と収入は求人票に先に書いて絞る、生活は情報と用意で立ち上げを手伝う、地域との関係は最初の三か月に会社がつなぐ。「移住者は定着しない」で片付けると、直す場所が消えます。受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。
