副業の単価を上げたい、という相談を受けたとき、私たちが最初に聞くのは「いくらにしたいか」ではなく「いま何を渡していますか」です。単価が上がるのは、交渉がうまくいったときではなく、**依頼側の中で「この人に払う理由」が言葉になったとき**だからです。結論を先に書くと、**単価を上げるには、工程の記録・成果の定義・再現できる型・引き受ける範囲の広がりの四つのうち、どれかを先に相手の手元に残します。そのうえで、契約更新の節目に、値上げではなく「範囲と条件の見直し」として出します。**以下は一般的な整理で、個別の契約条件や税務の判断は税理士・社会保険労務士にご確認ください。単価の型そのものは[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、時間で受ける場合は[時給型の相場と決め方](/media/fukugyo-jikyuu/)に、月額で受ける場合は[月額固定型の相場と稼働時間](/media/fukugyo-getsugaku/)に書いています。

## 上がる理由になる四つ

| 示すもの | 依頼側にとっての意味 | 出し方 |
|---|---|---|
| 工程の記録 | 何にどれだけ時間がかかっているかが分かり、社内で説明できる | 月次の稼働報告を工程ごとに一枚で |
| 成果の定義 | 払っているものが「時間」から「動いたこと」に変わる | 開始時に成果の定義を合意し、毎月その数字を出す |
| 再現できる型 | 担当者が代わっても回る。社内に残る | 手順書、文面のひな型、チェックの一覧を渡す |
| 引き受ける範囲の広がり | 社内で分散していた作業が一人にまとまる | いまの範囲の隣にある作業を、自分から提案する |

四つのうち、最も早く効くのは**工程の記録**です。記録が無い状態では、依頼側は「月10万円で何をしてもらっているか」を社内で説明できません。説明できないものは、値上げの対象にならないどころか、担当者が代わった瞬間に切られます。記録の取り方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、報告の型は[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/)に書いています。

## 出す順番

単価の話を切り出す前に、三か月から半年かけて順番に出します。

| 時期 | やること |
|---|---|
| 一か月目 | 工程ごとの稼働の記録を始め、月次の報告を一枚で出す |
| 二〜三か月目 | 成果の定義を合意する（面談設定の件数、返信率、日数の短縮など、自分の作業で動く範囲のもの） |
| 三〜四か月目 | 再現できる型を渡す（文面のひな型、手順、判断の基準） |
| 四〜六か月目 | 範囲の隣にある作業を一度だけ引き受けてみて、稼働と成果を記録する |
| 更新の節目 | 記録と成果を並べて、範囲と条件の見直しとして出す |

成果の定義は、自分で動かせる範囲に限るのが要点です。「採用が決まった人数」を成果に置くと、面接の日程や現場の判断など、自分の手の届かないところで結果が決まります。定義の仕方は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に書いています。

### エラベルの見解

単価を上げる相談で、いちばん惜しいのは**「頑張っているのに評価されない」で止まっている**場合です。実際には頑張っていて、成果も出ている。ただ、それが依頼側の手元に何も残っていない。スカウトの返信率が上がっていても、毎月の報告が口頭やチャットの流れの中だけなら、担当者の記憶にしか残りません。月に一枚、「今月やったこと・工程ごとの時間・動いた数字・来月の打ち手」を出す。それだけで、依頼側は社内の会議でその一枚を使えるようになり、単価の話をするときに根拠が相手の手元にあります。エラベルで案件を受ける方には、単価の相談の前に、この一枚を三か月続けることをお伝えしています。交渉の巧拙より、こちらのほうが効きます。

## いつ、どう切り出すか

単価の話は、月の途中に突然出すのではなく、**契約更新の節目**に合わせます。更新の一か月前に、次の期間の条件として出すのが自然な形です。

| 出し方 | 例 |
|---|---|
| 記録から始める | 「この三か月の稼働は、想定の月◯時間に対して実際は月◯時間でした」 |
| 範囲の変化を示す | 「開始時の範囲に、◯◯と◯◯が加わっています」 |
| 成果を並べる | 「返信率は◯%から◯%、面談設定は月◯件から◯件になりました」 |
| 提案として出す | 「次の期間は、範囲を◯◯までとして、月額を◯万円でお願いできますか」 |
| 代わりの案も出す | 「もし予算が難しければ、範囲を◯◯までに戻す形でも構いません」 |

最後の一行があるかどうかで、話の性質が変わります。値上げの要求ではなく、**範囲と条件の組み合わせを一緒に決め直す話**になるからです。更新時の交渉の型は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。

## 断られたときの選択肢

| 選択肢 | 中身 | 向く場面 |
|---|---|---|
| 範囲を戻す | 単価が据え置きなら、増えた作業を範囲から外す | 稼働が増えて実質時給が下がっている |
| 時期を決めて再度出す | 「半年後にもう一度話させてください」と合意する | 依頼側の予算の期が決まっている |
| 終える | 期間の満了で終え、別の案件に移る | 実質時給が下限を割っている |

断られること自体は珍しくありません。まずいのは、断られた後に**何も変えずに続けること**です。稼働が増えたまま単価が据え置きなら、実質時給は下がり続けます。どれを選ぶにしても、次の節目までに状態を変えます。終える場合の引き継ぎは[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)に書いています。

## 消費税とインボイスが単価の話に効く時期

業務委託で受けていて、適格請求書発行事業者の登録をしていない場合、依頼側は原則として仕入税額控除ができません。国税庁のタックスアンサーNo.6498は、適格請求書等保存方式の下では一定の事項が記載された帳簿および適格請求書等の保存が仕入税額控除の要件になるとしています。ただし、一定期間は経過措置があり、国税庁のQ&A問113は期間と割合を次のとおり示しています。

| 期間 | 依頼側が控除できる割合 |
|---|---|
| 令和5年10月1日から令和8年9月30日まで | 80% |
| 令和8年10月1日から令和10年9月30日まで | 70% |
| 令和10年10月1日から令和12年9月30日まで | 50% |
| 令和12年10月1日から令和13年9月30日まで | 30% |

**令和8年（2026年）10月1日から、割合が80%から70%に下がります。**登録していない状態で継続して受けている案件では、この時期に依頼側の負担が増えるため、単価の話が向こうから出てくることがあります。上げる交渉をしているつもりが、実質的な引き下げの話になることもあるので、更新が近いなら、登録するかどうかと、登録した場合の手取りを先に計算しておきます。登録すれば納税義務が生じ、登録しなければ依頼側の負担が増える、という二択なので、どちらが自分にとって得かは金額次第です。判断は税理士にご確認ください。請求書の作り方は[請求書の書き方](/media/fukugyo-seikyuusho/)に書いています。

なお、報酬から源泉徴収されるかどうかは、報酬の中身で変わります。国税庁のタックスアンサーNo.2792は、源泉徴収の対象となる代表的なものとして、原稿料や講演料など、弁護士・公認会計士・司法書士等の特定の資格を持つ人などに支払う報酬・料金、などを挙げています。人事の業務委託として受ける報酬がどう扱われるかは支払う側が判断するため、請求書の形を含めて事前に確認しておくと、入金額が想定と違う、という事故が減ります。

### エラベルの見解

単価が上がらない人と上がる人の差は、経験年数でも交渉の強さでもなく、**「次に何を足せるか」を自分から出しているかどうか**です。依頼側は、いまの作業に満足していても、そこから増やす発想は持ちません。目の前の採用で手一杯だからです。「いまのスカウトの運用に、月一回、候補者の傾向の整理を足しませんか」と出せるのは、毎月の記録を見ている受け手の側です。足したものが依頼側の会議で使われれば、次の更新の話は自然に範囲と単価の話になります。エラベルで案件を受ける方には、更新の一か月前に「次の期間で足せること」を一つ用意しておくことをお伝えしています。

## 上げる前に確かめること

| 確かめる | 理由 |
|---|---|
| 本業の就業規則 | 副業の届出や範囲の定めを確かめる。範囲が広がると本業側の確認が要ることがある |
| 実質時給 | 月額 ÷ 実際の稼働時間。下限（本業の時間単価）を割っていないか |
| 範囲の書面 | 開始時の範囲と、いまの実際の範囲がどれだけずれているか |
| 記録の有無 | 三か月分の工程ごとの記録が手元にあるか |
| 成果の定義 | 自分で動かせる範囲の指標で合意しているか |

厚生労働省の「副業・兼業の促進に関するガイドライン」は、副業・兼業を行うに当たって労働者と企業が留意すべき事項を整理しています。範囲を広げる話は、本業側の届出や競業の定めに触れることがあるため、受ける前に自分で確かめます。個別の判断は社会保険労務士にご確認ください。

## まとめ

- 単価が上がるのは交渉がうまくいったときではなく、**依頼側の中で払う理由が言葉になったとき**
- 示すのは**工程の記録・成果の定義・再現できる型・範囲の広がり**の四つ
- 最も早く効くのは**月に一枚の記録**。三か月続けてから話す
- 切り出すのは**契約更新の節目**。値上げではなく**範囲と条件の見直し**として出す
- **代わりの案（範囲を戻す）も一緒に出す**と、話が対立にならない
- 断られたら、**範囲を戻す・時期を決めて再度出す・終える**のどれかを選ぶ。何も変えずに続けない
- **令和8年10月1日から、免税事業者からの仕入れで依頼側が控除できる割合が80%から70%に下がる**。更新が近いなら先に計算しておく
- 個別の判断は税理士・社会保険労務士にご確認ください

## よくある質問

### 成果は出ているのに、記録を出すのは押しつけがましくないですか

月次の報告は、単価の交渉のためというより、依頼側が社内で説明するための材料です。人事の担当者は、上長や経営に「この費用で何をしてもらっているか」を説明する場面があり、そのときに使える一枚があると助かります。押しつけになるのは、報告が長い場合です。A4一枚、工程ごとの時間と動いた数字と来月の打ち手だけ、に収めると、読む側の負担になりません。

### 最初に安く受けてしまいました。途中で上げられますか

途中で上げるのは難しいので、**更新の節目**まで待ち、その間に記録と成果を作ります。そのうえで、「開始時の範囲から◯◯が増えています」「実質の時給は◯円になっています」と事実を並べて出します。開始時に安く受けた理由（経験を積むため、実績にするため）が自分の中で終わっているなら、次の期間で変える、という話は自然です。変わらないなら、終えて別の案件に移る判断も含めて考えます。

### 依頼側から「他の人はもっと安い」と言われました

比べているものが同じかを確かめます。同じ「スカウト代行」でも、送信だけなのか、要件の整理から文面の設計、返信対応、記録まで含むのかで、稼働も成果も違います。自分の見積りが工程ごとに分かれていれば、「その金額は、この工程までの話ではないですか」と事実で返せます。それでも同じ範囲でより安い相手がいるなら、金額で競うのではなく、範囲を狭めるか、終えるかを選びます。範囲の固め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。
