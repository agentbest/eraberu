ヘッドハンターとして、市場の中から候補者を見つけ、直接声をかけ、口説き、企業に引き合わせてきた。この経験は、企業側の人事の副業で売れるのか。紹介の立場と、企業の担当者の立場は違い、どう売ればよいのか。結論を先に書くと、**ヘッドハンターの経験は、「市場のどこに誰がいるかを知り、直接声をかけ、口説く」型で売れます。売れるのは、「幹部や専門職の直接採用の設計」「候補者の探し方の型」「口説きの面談」「依頼側の魅力の言語化」の四つです。幹部や専門職を直接採りたいが、どこにいるか分からず、声をかけても返信が来ない依頼側は多く、市場の地図と口説きの型を持つ人が求められています。ただし、副業では「紹介」ではなく「依頼側の担当者として動く」形に切り替え、紹介の経験で得た候補者と情報は持ち込みません。紹介の形で報酬を受けることには許可が関わるため、その線は専門家にご確認ください。**人材紹介の経験の評価は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に、幹部採用の設計は[経営者・役員が副業でできること](/media/fukugyo-kigyou-keiei-fukugyo/)に、スカウトの運用は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)にまとめています。

## この経歴の何が売れるか

ヘッドハンターの経験を、依頼側の担当者としての工程に置き換えた棚卸しです。紹介の候補者と情報は含めず、「型」として抜き出します。

| ヘッドハンターの経験 | 担当者としての工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 市場のどこに誰がいるかを知っている | 依頼側が探す職種と層が、どの媒体、どの経路、どの会社の周辺にいるかの「探し方の型」を設計する | 「どこにいるか分からない」依頼側が多い |
| 直接声をかけてきた | 依頼側の名前で、幹部や専門職に直接声をかける文面と経路の型 | 声をかけても返信が来ない依頼側が多い |
| 口説いてきた | 転職を考えていない候補者の関心を引き出し、依頼側の魅力と結びつける面談の型 | 面談で口説けず、候補者が離れる依頼側が多い |
| 企業の魅力を候補者に伝えてきた | 依頼側の魅力（事業、裁量、経営者、将来）を、候補者の言葉に置き換える | 自社の魅力を言葉にできていない依頼側が多い |
| 幹部の採用の要件を整理してきた | 幹部の採用で、何を求め、何を譲れるか、要件と条件を整理する | 幹部の要件が曖昧で、探しても決まらない依頼側が多い |
| 候補者の辞退と失注の理由を見てきた | 辞退の理由を奥まで聞き、条件と伝え方に反映する | 辞退の理由が分からない依頼側が多い |
| 経営者と直接やり取りしてきた | 依頼側の経営者と、幹部採用の判断の材料を整える対話 | 経営者が幹部採用の判断を先送りしている依頼側が多い |

売れるものの要点は、「市場の地図と口説きの型は、紹介の立場でなくても使える」ことです。ヘッドハンターの価値は、候補者を「持っている」ことだと思われがちですが、副業で売れるのは、候補者ではなく、「どこにいるか」「どう声をかけるか」「どう口説くか」の型です。型は、依頼側の担当者として、依頼側の名前で使えます。紹介の経験で得た候補者と情報は、紹介の会社と候補者のものなので、持ち込みません。人材紹介の経験の売り方は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に、幹部採用の設計は[経営者・役員が副業でできること](/media/fukugyo-kigyou-keiei-fukugyo/)に書いています。

## 売りにくい点とその扱い

ヘッドハンターの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 紹介と担当者の立場の違い | 「候補者を紹介してくれるのか、探し方を教えてくれるのか」「結局、紹介の手数料を取るのでは」 | 「紹介ではなく、依頼側の担当者として、依頼側の名前で探し、声をかけ、口説きます。紹介の手数料は受けません」と最初に示す。紹介の形で報酬を受けることには許可が関わるため、専門家に確認し、副業では担当者の形に徹する |
| 候補者の情報の線 | 「前の会社で持っていた候補者を連れてくるのでは」。自分にとっても、前の会社との守秘の線 | 紹介の経験で得た候補者と情報は持ち込まない。探し方の型だけを持ち込み、候補者は依頼側の名前で新しく探す |
| 成果報酬の習慣 | 「入社が決まったら成果報酬」の形に慣れていて、副業でもその形を求めがち | 副業では、判断が依頼側にあり、自分で結果を左右できる範囲が狭い。時間か月額か成果物で受ける。成果報酬は、許可の問題と結果の不確実さの両方から、最初は避ける |

扱い方の要点は、「紹介の形を捨て、担当者の形に徹する」ことです。ヘッドハンターの習慣で、「候補者を持ってきて、決まったら報酬」の形で副業を受けようとすると、職業紹介の許可に関わる線に触れる可能性があり、前の会社の候補者と情報の持ち出しにもなります。副業では、依頼側の担当者として、依頼側の名前で、依頼側の媒体と経路で新しく探し、時間か月額か成果物で報酬を受けます。紹介の形で報酬を受けることの可否と条件は、専門家にご確認ください。法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)の「法令で気をつける点」に、成果報酬の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に、守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に整理しています。

### エラベルの見解

担当する側から見ると、ヘッドハンターから転身して続いている人と、途中で止まる人の差は、口説きの腕ではなく、「紹介の形を捨てているか」です。止まる人は、副業でも「候補者を連れてきて、決まったら報酬」の形を求め、依頼側との契約の形が曖昧になり、前の会社の候補者を持ち込む形になって、前の会社との関係と依頼側との信用の両方を失っています。続いている人は、「依頼側の担当者として、依頼側の名前で探す」形に切り替え、時間か月額で受け、市場の地図と口説きの型で依頼側の直接採用を動かし、依頼側から「自社で幹部を採れるようになった」と評価されています。

見ていて差がつくのは、依頼側の魅力を、候補者の言葉に置き換えているかです。ヘッドハンターは、複数の企業の魅力を候補者に伝えてきたので、「この規模の会社の、この事業の、この経営者の、何が候補者に響くか」を言葉にする型を持っています。依頼側の多くは、自社の魅力を社内の言葉でしか言えず、幹部や専門職に響いていません。型を持つ人が依頼側の魅力を言語化すると、スカウトの返信と面談の関心が変わり、依頼側から「うちの魅力をこう言えばよかったのか」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、市場の地図と口説きの型を明確にし、紹介との線を示している担当者に、幹部や専門職を直接採りたい依頼側がついています。ヘッドハンターの転身は、腕ではなく、立場の切り替えで始まります。

## 案件の探し方

ヘッドハンターから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 幹部や専門職の直接採用の設計 | 幹部の要件を整理してきた経験で入れる | 「幹部を直接採りたいが、どこにいるか分からない依頼側」を範囲の一言に |
| 候補者の探し方の型の設計 | 市場の地図で入れる | 「この職種と層は、この媒体とこの経路で」を成果物の形で |
| 依頼側の名前での直接の声かけの運用 | 直接声をかけてきた経験で入れる | 「返信が来ない依頼側」を範囲の一言に。依頼側の媒体と経路で |
| 口説きの面談の設計と同席 | 口説いてきた経験で入れる | 「面談で候補者が離れる依頼側」を範囲の一言に |
| 依頼側の魅力の言語化 | 企業の魅力を伝えてきた経験で入れる | 「自社の魅力を言葉にできない依頼側」に、成果物の形で |
| 経営者が直接担当する依頼側 | 経営者と直接やり取りしてきた | 登録先で、経営者が直接担当する規模の依頼側を選ぶ |

探し方の要点は、「幹部や専門職を直接採りたい依頼側」に絞ることです。ヘッドハンターの型が最も効くのは、一般の職種の大量採用ではなく、幹部や専門職の少数の採用で、依頼側が紹介の費用を払わずに自社で採りたいと考えている場面です。その依頼側に、「紹介ではなく、御社の担当者として、御社の名前で探し、口説きます」と示せば、紹介との違いが明確で、価値が伝わります。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、経営者との対話は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。ヘッドハンターの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 紹介の手数料との比較 | 紹介の手数料と、担当者としての副業の単価は、決まり方が全く違う | 紹介の手数料の感覚を持ち込まない。担当者の工程の単価で |
| 幹部採用の設計の価値 | 幹部の採用は依頼側にとって失敗の損失が大きく、設計と口説きの価値は高い | 設計は成果物で、口説きの面談は回数で受ける |
| 探し方の型の価値 | 依頼側が自分で探せるようになる型は、依頼側にとって長く効く | 型は成果物で、単価に反映させる |
| 成果報酬の扱い | 許可の問題と結果の不確実さから、副業では最初は避ける | 時間か月額か成果物で。可否は専門家に確認 |
| 直接の声かけの運用 | 送信と返信の管理は、月額で受けやすい | 月に何時間、と枠を決めて月額に |
| 前の会社との契約の条件 | 紹介の会社に所属していた場合、退職後の競業や守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「紹介の手数料の感覚を、副業に持ち込まない」ことです。ヘッドハンターの報酬は、紹介の成功に対する手数料で、金額の桁が副業の単価と違います。その感覚で副業の単価を見ると、「安すぎる」と感じますが、副業は担当者の工程に対する報酬で、決まり方が別物です。設計は成果物、口説きの面談は回数、運用は月額、と分けて、担当者の工程の単価で受けます。前の会社との契約に、退職後の競業や守秘の条件がある場合は、それを確認し、個別の判断は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

ヘッドハンターから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、紹介の形で報酬を受けることの可否と、前の会社との契約の条件を、専門家に確認する | 職業紹介の許可、競業、守秘 |
| 二、副業では「依頼側の担当者として動く」形に徹する、と決める | 紹介の形を捨てる |
| 三、市場の地図と口説きの型を、候補者と前の会社の情報を含まない「型」で書き出す | 探し方、声かけ、口説き、魅力の言語化、幹部の要件 |
| 四、範囲を、幹部や専門職の直接採用の設計、探し方の型、声かけの運用、口説きの面談、魅力の言語化に絞る | 判断は依頼側 |
| 五、単価を、成果物、回数、月額に分けて決める | 紹介の手数料の感覚を持ち込まない |
| 六、「紹介ではなく、御社の担当者として、御社の名前で探し、口説く」の一言を作る | 立場の切り替えを言葉に |
| 七、登録先に、範囲と、紹介との線を登録する | 幹部や専門職を直接採りたい依頼側 |
| 八、探し方の型か魅力の言語化を一件、成果物で受け、依頼側の名前で声かけを回す | 次の工程に広げる材料に |

順番の要点は、「一」と「二」を、案件を探す前にやることです。ヘッドハンターの転身では、紹介の形のまま副業を受けると、許可の問題、前の会社との契約、候補者の情報の持ち出しの三つに触れる可能性があり、後から問題になると、依頼側にも迷惑がかかります。専門家に確認し、担当者の形に徹すると決めてから、型を売ります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「ヘッドハンターの価値は候補者を持っていることで、副業では候補者を持ち込めないから価値が無い」というものです。実際には、副業で売れるのは候補者ではなく、市場の地図、声かけ、口説き、魅力の言語化、幹部の要件の整理という「型」で、型は依頼側の担当者として、依頼側の名前で使えます。候補者を持ち込む形は、許可と守秘と前の会社との関係の三つで危うく、型を持ち込む形が、安全で価値が高いです。

順番として、紹介の形の可否と前の会社との契約を専門家に確認し、担当者の形に徹すると決め、型を候補者と前の会社の情報を含まない形で書き出し、範囲を幹部や専門職の直接採用の設計と型と運用と面談と言語化に絞り、単価を成果物と回数と月額に分け、紹介ではなく担当者として、の一言を作り、登録先に範囲と線を登録し、型か言語化を一件成果物で受ける。この順番で、ヘッドハンターの転身は、「候補者を持ち込む危ういもの」から「型で依頼側の直接採用を動かすもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、市場の地図と口説きの型を明確にし、紹介との線を示している担当者に、幹部や専門職を直接採りたい依頼側がついています。ヘッドハンターの転身は、腕ではなく、立場の切り替えで始まります。

## まとめ

- ヘッドハンターの経験は**「市場のどこに誰がいるかを知り、直接声をかけ、口説く」型**で売れる。**幹部や専門職の直接採用の設計・探し方の型・口説きの面談・魅力の言語化**の四つ
- 売れるのは**候補者ではなく型**。紹介の経験で得た候補者と情報は持ち込まない
- **副業では「紹介」ではなく「依頼側の担当者として動く」形に徹する**。紹介の形で報酬を受けることの可否は専門家に確認
- 売りにくい点は**紹介と担当者の立場の違い・候補者の情報の線・成果報酬の習慣**。時間か月額か成果物で受ける
- 案件は**幹部や専門職を直接採りたい依頼側**から。紹介の費用を払わずに自社で採りたい場面
- 単価は**紹介の手数料の感覚を持ち込まず、設計は成果物、面談は回数、運用は月額**で。前の会社との契約の条件は専門家に確認

## よくある質問

### 前の会社で担当していた候補者から、転職の相談を受けています。副業の依頼側に紹介してよいですか

紹介しません。前の会社で得た候補者との関係と情報は、前の会社と候補者のものであり、副業の依頼側に回すと、前の会社との守秘と競業の線、候補者の信頼、依頼側との契約の形の三つに問題が出ます。候補者から相談を受けたときは、副業の依頼側とは切り離し、候補者には公的な窓口や紹介の会社を案内する形にします。副業では、依頼側の名前で、依頼側の媒体と経路で、新しく探します。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に整理しています。

### 依頼側から「決まったら成果報酬で」と言われました。ヘッドハンターの頃と同じ形なので、受けやすいです

副業では、最初は避けることをお勧めします。理由は二つで、一つは、副業の担当者として動く場合、判断は依頼側にあり、候補者の意思もあり、自分で結果を左右できる範囲が紹介のときより狭いこと。もう一つは、「決まったら報酬」の形が、職業紹介の許可に関わる線に触れる可能性があることです。時間か月額か成果物で受け、成果報酬の可否と形は、専門家にご確認ください。成果報酬の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に書いています。

### 依頼側の名前で声をかけると、ヘッドハンターの頃より返信が来ません

紹介の会社の名前と、複数の案件を持っている立場で声をかけていた頃と、依頼側一社の名前で声をかける今とでは、候補者の受け取り方が違います。依頼側の名前で返信が来る型は、「依頼側の魅力を候補者の言葉に置き換える」「相手の経歴を読み込んで一言を添える」「依頼側の経営者からの一言を添える」「転職を考えていない相手に、まず話を聞く形で誘う」など、一社の担当者としての型です。ヘッドハンターの頃の型を、一社の立場に組み替えます。文面の型は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に、魅力の言語化は[文章力をどう磨くか](/media/fukugyo-writing/)に整理しています。
