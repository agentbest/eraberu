人事の副業を考えるとき、「スカウト専門」のように一つに絞るべきか、「採用まわりは何でも」と幅広く受けるべきかで迷う人は多い。特化すると案件の幅が狭くなりそうで、幅広にすると何の人か分からなくなりそうで、どちらにも不安がある。結論を先に書くと、**特化と幅広は、どちらが正しいかではなく、始める時期・相手の会社の規模・自分の経験の厚みで答えが変わり、始めるときは特化、一件目が終わってから段階的に広げる**のが、無理のない順番です。最初から幅広で始めると、依頼側から「頼める人」に見えず、最初の一件が決まりません。得意領域の決め方は[得意領域の決め方](/media/fukugyo-tokui-ryouiki/)に、業界で絞る考え方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)にまとめています。

## 特化と幅広の違い

まず、二つの形が何を意味するかを整理します。言葉のイメージと、副業での実態は少し違います。

| 観点 | 特化（一つの業務） | 幅広（採用まわり全般） |
|---|---|---|
| プロフィールの見え方 | 何の人か一目で分かる | 経験は広いが、何を頼めるか分かりにくい |
| 案件の当たり方 | その業務で困っている依頼側に届く | 依頼側が「この人に何を」と迷う |
| 一件の範囲 | 狭く、成果物が明確 | 広く、範囲が曖昧になりやすい |
| 単価の根拠 | その業務の型と数で説明できる | 稼働時間で説明することになる |
| 向く相手 | 人事はいるが、その業務に手が回らない会社 | 人事がいない小規模の会社で、採用全体を見てほしい |
| 必要な経験 | 一つの業務の数と型 | 採用全体を回した経験と、判断の線引き |
| 続けやすさ | 型があるので時間が読める | 範囲が広がりやすく、時間が読めない |
| 広げ方 | 一件目のあとに二つ目を足す | 最初から広いので、深める方向 |

違いの要点は、「幅広は、経験が厚い人が選べる形」ということです。採用全体を回し、どこまでが自分の範囲でどこからが依頼側の判断かを線引きできる人なら、幅広で受けられます。経験が浅い人が幅広を選ぶと、範囲が曖昧になり、判断まで求められ、時間が読めなくなります。

## 時期と相手で答えが変わる

特化か幅広かは、固定の答えではなく、三つの条件で変わります。

| 条件 | 特化が向く | 幅広が向く |
|---|---|---|
| 始める時期 | 副業を始めたばかり。一件目がまだ | 数件を終え、依頼側との関係ができている |
| 相手の規模 | 人事がいて、特定の業務に手が回らない会社 | 人事がいない小規模の会社で、採用全体を見てほしい |
| 自分の経験 | 一つの業務に数と型がある | 採用全体を回した経験と、判断の線引きができる |
| 時間 | 週の時間が限られている | まとまった時間を出せる |
| 相手との関係 | 初めての相手 | 一件目を終えた相手から、範囲を広げて頼まれる |
| 単価の考え方 | 型と数で単価を出したい | 稼働時間で月額を出したい |

条件の要点は、「幅広は、特化で一件目を終えたあとに、相手との関係の中で生まれる」ことです。初めての相手に幅広で入るのは難しく、一件目を終えた相手から「ほかもお願いできる？」と広がるのが、幅広の自然な形です。

### エラベルの見解

登録の相談で多いのは、「幅広く書いたほうが、案件が来る確率が上がるのでは」という声です。実際は逆で、幅広く書いた登録は、運営がどの案件に当ててよいか分からず、依頼側が読んでも何を頼めるか分からず、最初の一件が決まりません。特化して書いた登録は、当たる案件は少ないが、当たったときに決まります。確率の問題ではなく、判断できるかどうかの問題です。

見ていて差がつくのは、「一件目のあとに、幅を広げる形で受けているか」です。特化で一件目を受け、依頼側との関係ができると、「求人票も見てもらえる？」「一次面接の設定もお願いできる？」と広がります。この広がりは、依頼側が自分の仕事ぶりを見たうえで頼んでいるので、範囲も単価も決めやすい。エラベルの登録でも、一つの業務で始めた人が、同じ依頼側から範囲を広げて続けている例が多く、最初から幅広で書いた人より、結果的に広く受けています。

## 特化から始めて広げる手順

始めは特化、あとから広げる順番を、番号付きで整理します。

1. **一つの業務を得意領域として決める。** 数・型の変化・需要の三つで。[得意領域の決め方](/media/fukugyo-tokui-ryouiki/)を参照。
2. **含むことと含まないことを書き、登録・発信・面談を一つの軸で組み立てる。** [プロフィールの書き方](/media/fukugyo-profile/)を参照。
3. **一件目を、狭い範囲で受ける。** 型のある、成果物が明確な、期間の区切れる案件。[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)を参照。
4. **一件目の中で、範囲の外の困りごとを聞いておく。** 受けないが、依頼側が何に困っているかは把握する。
5. **一件目の区切りで、続けるかと、範囲を広げるかを話す。** 依頼側から広げる相談があれば、二つ目の業務として書面を更新する。[契約更新のタイミング](/media/fukugyo-koushin/)を参照。
6. **広げるときは、一つずつ。** 一度に「採用全般」に広げず、二つ目の業務を足す形で。単価も業務ごとに。
7. **別の依頼側には、特化のまま入る。** 一件目の依頼側で幅が広がっても、新しい依頼側には一つの業務で入る。
8. **数件を終えたら、幅広で受けるかを考える。** 採用全体を回した経験と、判断の線引きができるようになっていれば、人事のいない小規模の会社を相手に、幅広で受ける選択肢が出てくる。

手順の要点は、「七で、新しい相手には特化で入る」ことです。既存の相手で幅が広がっても、新しい相手にとっては初めての人なので、何の人かが分かる形で入ります。幅広は、関係の中で生まれるもので、プロフィールに書くものではありません。

## 幅広から始める失敗

最初から幅広で始めると、起きやすい失敗があります。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 一件目が決まらない | 何の人か分からず、依頼側が判断できない | 一つの業務に絞り直す |
| 範囲が曖昧なまま始まる | 「採用まわり全般」で受けると、含まないことが無い | 含まないことを書く。判断は依頼側に |
| 判断まで求められる | 幅広で入ると、合否や条件の判断も頼まれる | 判断の線を最初に引く。[スコープクリープへの対応](/media/fukugyo-scope-creep/) |
| 時間が読めない | 範囲が広いので、稼働が膨らむ | 業務ごとに時間を決める |
| 単価の根拠が無い | 稼働時間でしか説明できない | 業務ごとに型と数で説明する |
| 経験の薄い業務を頼まれる | 幅広と書いたので、得意でない業務も来る | 得意領域を前に出し、それ以外は含まないと書く |
| 依頼側が小規模で相談相手がいない | 幅広を求める相手は、人事がいないことが多い | 相談相手がいるかを面談で確認。いなければ範囲を狭く |
| 何でも屋として安く見られる | 専門性が見えず、稼働時間の対価になる | 型と数を前に出す |

失敗の要点は、「幅広は、依頼側にとっては便利だが、受ける側にとっては範囲と時間と単価の全部が曖昧になる形」ということです。経験が厚く、線引きができる人なら回せますが、始めたばかりの人には負担が大きい。

## 広げるときの判断

特化で始めて、広げるかどうかを判断する場面が来ます。判断の観点を整理します。

| 観点 | 広げてよい | まだ広げない |
|---|---|---|
| 一件目の状態 | 区切りまで終え、依頼側の評価が分かっている | 途中。評価が分からない |
| 広げる業務の経験 | 棚卸しで数と変化がある業務 | 数も変化も無い業務 |
| 時間 | いまの稼働に余裕がある | いまの稼働で手一杯 |
| 依頼側の相談相手 | 判断する人がいて、線引きができている | 判断まで求められている |
| 単価 | 業務ごとに単価を出せる | 月額に吸収されそう |
| 本業との関係 | 広げる業務が本業の規定と線の内側 | 競業や情報の重なりが出る。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 別の依頼側 | 新しい相手には特化で入れている | 新しい相手にも幅広で入ろうとしている |

判断の要点は、「広げるのは、いまの依頼側との関係の中で、一つずつ」ということです。プロフィールを幅広に書き換えるのではなく、既存の依頼側で二つ目の業務を足し、その経験が数になったら、次の相手に二つ目を提示できるようになる、という順番です。

### エラベルの見解

担当する側として登録した人の話を聞くと、幅広で受けている人は、例外なく、特化で始めて数件を終えた人です。最初から幅広で登録した人は、一件目が決まらないか、決まっても範囲が曖昧で続かないかのどちらかになっています。幅広は、目指す形ではなく、特化で積み重ねた結果として到達する形です。

依頼側から見ると、特化した人は「この業務なら任せられる」と判断しやすく、幅広の人は「何を任せればよいか」を自分で考えることになります。人事がいる会社は前者を、人事がいない小規模の会社は後者を求めることが多い。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口なので、登録は特化で書いていただき、広がりは依頼側との関係の中で作っていただく形をお勧めしています。登録の範囲が狭いほど、最初の連絡は早くなります。

## まとめ

- 特化と幅広は**どちらが正しいかではなく、時期・相手の規模・経験の厚みで答えが変わる**
- 幅広は**経験が厚く、判断の線引きができる人が、一件目を終えた相手との関係の中で選べる形**
- 始めは**特化**。一つの業務で一件目を受け、区切りで依頼側から広げる相談があれば、二つ目を足す
- 新しい相手には**特化のまま入る**。幅広はプロフィールに書くものではなく、関係の中で生まれる
- 幅広から始めると**一件目が決まらない・範囲が曖昧・判断まで求められる・時間と単価が読めない**
- 広げる判断は**一件目の評価・経験・時間・相談相手・単価・本業との線**で、一つずつ

## よくある質問

### 人事が一人もいない会社から、採用全体を見てほしいと言われました。受けてよいですか

採用全体を回した経験があり、どこまでが自分の範囲でどこからが依頼側の判断かを線引きできるなら、受けられます。経験が浅い場合は、「まずスカウトの運用だけ」のように、一つの業務から入り、区切りで広げる形を提案してください。人事がいない会社は、相談相手もいないことが多く、幅広で入ると判断まで求められます。面談で、判断する人（経営者など）が採用に関わり続けるかを確認し、関わらないなら範囲を狭くします。

### 特化すると、その業務の需要が無くなったときに困りませんか

一つの業務に固定し続けるわけではないので、困りません。特化は、一件目を決めるための形で、一件目が終われば二つ目を足せます。数件を終えるころには、二つか三つの業務で受けられるようになっていて、一つの需要が減っても、ほかで受けられます。最初から幅広にして需要の変化に備えるより、特化で一件目を決めて、段階的に広げるほうが、結果的に受けられる幅は広くなります。

### 経験は十分あります。最初から幅広で受けてはいけませんか

採用全体を回し、判断の線引きができ、まとまった時間を出せるなら、幅広で受ける選択肢はあります。その場合も、プロフィールには「採用全般」ではなく、「採用全体の設計と運用。ただし合否と条件の判断は依頼側」のように、含まないことを書いてください。また、相手は人事がいない小規模の会社になることが多いので、相談相手がいるか、支払いの仕組みがあるかを面談で確認します。幅広で受ける場合も、単価は稼働時間だけでなく、業務ごとの型と数で説明できるようにしておくと、安く見られることを防げます。
