「評価シートを作ってほしい」と頼まれて、観点を並べて五段階の点数欄を付けた表を渡すと、面接官は全員に三か四を付け、総合点は横並びになり、決める人は結局「印象」で決めます。点数の表は、書いた本人にも後で読めません。評価シートの役割は、点数を集めることではなく、「候補者が語った事実」と「基準に照らした判断」を分けて残し、決める人が決められるようにすることです。結論を先に書くと、**評価シートは、観点・事実・判断（通す・迷う・通さないの三択）・候補者の質問と迷い・次の段への引き継ぎの構造で、質問集と同じ観点の並びにし、総合点を作らず、面接官が五分で書ける長さにして、決める人が読む一枚に集約します。**質問集の型は[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)に、面接全体の設計は[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)に書いています。ここでは、シートの型に絞ります。

## 点数だけのシートが役に立たない理由

| 点数のシート | 起きること |
|---|---|
| 観点ごとに五段階 | 面接官は三か四に寄せる。差が出ない |
| 総合点で並べる | 観点の重みが均等になり、必須の観点で落ちた人が総合で通る |
| 点数の根拠が無い | 後で「なぜ四か」を本人も説明できない |
| 「コミュニケーション力」に点数 | 基準が無い観点に点数を付けても、印象の数値化 |
| 面接官ごとに点数の甘さが違う | 同じ候補者で、面接官によって総合点が変わる |

点数は、基準が一行の言葉で決まっていて、事実が書かれていて、初めて意味を持ちます。それが揃っているなら、点数ではなく三択で足ります。

## シートの構造

| 欄 | 中身 | 書き方 |
|---|---|---|
| 観点 | 段ごとに三つ前後。質問集と同じ並び | 事前に印刷 |
| 事実 | 候補者が語った場面。状況・役割・判断・行動・結果のうち聞けたもの | 一行〜三行。候補者の言葉に近く |
| 判断 | 通す・迷う・通さないの三択。基準（一行）に照らして | 一語。基準はシートに印刷しておく |
| 候補者の質問と迷い | 候補者が聞いてきたこと、迷っている様子だったこと | 判断には使わない。次の段と最終の材料 |
| 次の段への引き継ぎ | 掘りきれなかった観点、確かめてほしいこと | 一行 |
| 聞いてはいけない項目 | （欄は作らない）。触れてしまった場合は記録せず、依頼側に伝える | — |

総合点の欄は作りません。総合の判断は、決める人が、観点ごとの三択と事実を並べて行います。「印象」「人柄」の欄も作りません。欄があれば埋められ、判断に混ざります。

### エラベルの見解

担当する側から見ると、評価シートで最も差がつくのは、「総合点を作らない」を依頼側に通せるかどうかです。依頼側は、候補者を並べて比べたいので、総合点を欲しがります。ただ、総合点があると、必須の観点で「通さない」が付いた人が、他の観点の点で総合で上位になり、決める人がその矛盾に気づかないまま通します。観点ごとの三択を横に並べた表（候補者×観点）を見せれば、「通さない」が一つでもある人は一目で分かり、総合点は要らなくなります。エラベルで担当者を選ぶ企業には、「評価シートに総合点の欄がありますか。それで必須の観点が埋もれていませんか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、総合点の代わりに「候補者×観点の三択の表」を決める人に渡すこと。並べて比べたい要望は、この表で満たせます。

## 三択にする理由

| 三択 | 意味 | 五段階との違い |
|---|---|---|
| 通す | 基準を満たす事実が語られた | 四と五の区別は要らない。通すか通さないか |
| 迷う | 近い事実はあるが、基準に届くか読めない | 三に寄せる逃げ道ではなく、「次の段で確かめる」の合図 |
| 通さない | 基準を満たさない。または語れなかった | 一と二の区別は要らない |

「迷う」は、面接官が判断を保留する欄ではなく、「この観点は次の段で掘ってほしい」という引き継ぎです。迷うが付いた観点は、次の段の一枚の「確かめてほしいこと」に自動で入る形にします。三択の基準の一行は、[評価基準が言語化できていない](/media/rpo-hyouka-kijun/)の「通した人と落とした人の違い」から起こします。

## 五分で書ける長さ

| 長さの目安 | 理由 |
|---|---|
| 観点は三つ前後 | 多いと事実の欄が埋まらない |
| 事実は各一〜三行 | 面接の直後に思い出せる範囲 |
| 判断は一語 | 三択 |
| 引き継ぎは一行 | 次の面接官が読む長さ |
| 全体で一枚 | 二枚になるなら観点が多い |

面接の直後に五分で書く時間を、日程の枠に含めます。時間が経つと事実が印象に変わります。枠の預かり方は[日程調整を速くする](/media/fukugyo-skill-nittei/)に書いています。

## 決める人が読む一枚への集約

| 集約の形 | 中身 |
|---|---|
| 候補者×観点の表 | 各段の三択を横に並べる。「通さない」に色を付ける |
| 事実の抜粋 | 「迷う」と「通さない」の観点だけ、事実の欄を添える |
| 候補者の迷い | 各段で出た質問と迷いをまとめる。最終の面接官が答える材料 |
| 判断が割れた観点 | 面接官ごとの事実と判断を並べる。担当者は並べるまで。決めるのは決める人 |

担当者が「総合するとこの人が良い」と書かないのは、決めるのが依頼側だからです。集約は、決める人が事実に戻れる形にするところまでです。判断を依頼側に残す線は[面接代行を受けるときの注意](/media/fukugyo-mensetsu-daikou-chuui/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「評価シートは、面接のためのもの」というものです。実際には、評価シートが最も役に立つのは、入社後です。入社した人が三か月後に「思っていたのと違う」となったとき、面接のシートを開けば、「この観点は迷うだった」「この事実を通すと読んだが、基準がずれていた」と戻れます。それが、要件と基準を直す材料になります。シートが点数だけだと、戻っても何も分かりません。受ける側がその場で使える判断としては、シートの保管の形を、入社した人については入社後も残す（依頼側の決まりの範囲で）、通らなかった人については依頼側の決まりに従って扱う、と最初に決めること。保管の期間と方法は、個人情報の扱いに関わるので、依頼側の決まりと専門家の確認に従います。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## シートに書かないこと

| 書かないこと | 理由 |
|---|---|
| 性別・年齢・国籍・家族の状況・出身地・宗教や思想・健康の状態 | 募集や採用で法令上の決まりがあると一般に整理されている項目。欄を作らず、面接官が触れてしまっても書かない |
| 印象・人柄・雰囲気 | 基準に無い。判断に混ざる |
| 他の候補者との比較 | シートは一人分。比較は集約の表で |
| 面接官の推測 | 「たぶん〇〇だろう」は事実ではない。事実の欄には語られたことだけ |
| 候補者の私的な情報 | 面接で話題に出ても、判断に使わないものは書かない |

何が該当するかは、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が総合点を欲しがる | 候補者×観点の三択の表で並べる。必須の観点が埋もれる構造を示す |
| 面接官が全部「迷う」にする | 基準の一行が無いか曖昧。通した人と落とした人の違いから起こし直す |
| 事実の欄が「良かった」で埋まる | 質問集の掘る問いに戻る。事実は候補者の言葉で |
| シートが二枚になる | 観点を三つ前後に。段への割り振りを見直す |
| 面接官が書く時間が無い | 五分の枠を日程に含める。欄を減らす |
| 入社後に振り返る材料が無い | 保管の形を最初に決める。依頼側の決まりに従う |

## まとめ

- 点数のシートは**根拠が残らず、総合点が必須の観点を埋める**
- 構造は**観点・事実・判断（三択）・候補者の質問と迷い・次の段への引き継ぎ**。総合点と印象の欄は作らない
- 判断は**通す・迷う・通さない**。「迷う」は次の段への引き継ぎ
- **質問集と同じ観点の並び**、面接官が**五分で書ける一枚**
- 決める人には**候補者×観点の三択の表**と、迷う・通さないの事実の抜粋。総合の判断は担当者が書かない
- シートは**入社後に戻る材料**。保管の形を最初に決める
- **書かないこと**を先に決める。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側の既存の評価シートが五段階の点数です。全部作り直しますか

作り直さず、欄を足して減らします。既存の観点は残し、各観点に「事実」の欄を足し、点数を三択に置き換える案を出します。総合点の欄は「集約の表で代える」と提案し、消すかどうかは依頼側の判断に残します。既存のシートを全部変えると、過去の候補者の記録と比べられなくなるので、切り替えの日を決めて、それ以降の候補者から新しい形にします。既存の直し方は[求人原稿を書き直す手順](/media/fukugyo-skill-kyujin-genkou/)と同じで、差分で出します。

### 適性検査の結果は、シートのどこに書きますか

シートの観点には書きません。適性検査の結果の扱いは、依頼側と検査の提供元の決まりに従い、担当者が解釈しません。決める人が読む集約の一枚に、「適性検査の結果は別紙」と添えるまでです。面接のシートに検査の結果を混ぜると、面接官が検査の結果に引っ張られて事実を書かなくなります。

### 面接官が「通す・通さないは、自分が決めることではない」と言って三択を書きません

三択は最終の合否ではなく、「この観点で、基準に照らしてどう見えたか」の判断で、決める人が使う材料だと伝えます。「面接官の判断は観点ごとで、最終の決定は決める人がします」と、役割を分けて説明します。それでも書けないなら、事実の欄だけを書いてもらい、判断は決める人が事実から読む形にします。事実が書かれていれば、判断の欄が空でも、シートは機能します。
