新卒のスカウトは、絞り込みで出てきた一覧から誰に送るかを決める作業が、実質の仕事です。学生には職務経歴がないので、中途のように「経験年数で切る」ことができません。結論を先に書くと、**Wantedlyの新卒選定は「検索結果一覧に出るアイコンで優先順位をつける」「気になるリストのラベル・メモ・評価で判断を残す」「非表示で母数を整える」の三つを型にします**。仕様は変わるので、契約する前に公式の案内で確認してください。以下は、2026年9月23日時点でWantedlyのヘルプセンターに記載されている内容に基づいて整理しています。運用の回し方は[Wantedly（新卒）の運用スケジュールと送信計画](/media/scout-shinsotsu-wantedly-shinsotsu-unyou/)に、文面は[Wantedly（新卒）のスカウト文面の型](/media/scout-shinsotsu-wantedly-shinsotsu-template/)にまとめています。

## 一覧のアイコンを読む

ヘルプセンターの「スカウトの検索結果一覧について」は、検索結果に表示されるアイコンを三つに分けて説明しています。**プロフィール本文を読む前に、この行が判断の材料になります。**

**一、貴社に対してのアクションを表すアイコン。**

| アイコン | 意味（ヘルプセンターの記載） |
|---|---|
| **募集をブックマーク** | 「あなたの会社の募集をブックマークしていることを表します」 |
| **募集を閲覧** | 「あなたの会社の募集を閲覧していることを表します」 |
| **会社をフォロー** | 「あなたの会社をフォローしていることを表します」 |
| **直近でのアクション** | 「直近で募集を閲覧するなど何かアクションがあった場合は、プロフィール写真の右下に目のアイコンが表示されます」 |
| **◯社が興味あり** | 「直近1ヶ月に該当候補者を閲覧した企業数」 |

**この五つが、新卒の優先順位の一段目です。**すでに自社の募集を見ている学生は、文面の一行目に書ける材料を持っています。逆に「◯社が興味あり」の数が大きい学生は、他社からも声がかかっている状態なので、返信までの時間が短くなります。

**二、候補者の状況を表すアイコン。**

| アイコン | 意味（ヘルプセンターの記載） |
|---|---|
| **直近でスカウトを受け取る設定にしている** | 「直近でスカウトを受け取る設定にした候補者の写真の右下に青いマークが表示されます」 |
| **転職・副業意欲** | 「候補者がプロフィール上で設定している転職・副業意欲を表します」 |
| **Premiumメンバーシップ利用** | 「WantedlyのPremiumメンバーシップを利用しているユーザーです。**スカウトチケットを消費せずにスカウトを送信できます**」 |

**Premiumメンバーシップの表示は、チケットの配分に効きます。**チケットを消費せずに送れる相手が一覧で分かるので、**限られたチケットを他の候補者に回せます**。選定のときに、この印がある学生を別枠で数えておきます。

**三、候補者のSNSを表すアイコン。**同ページは「アイコンをクリックするとそのSNSに遷移します。（**プレミアムプランのみ**）」として、Github、X（旧：Twitter）、LinkedInを挙げています。技術職の新卒選考では、Githubの有無が判断材料になります。

**四、閲覧済みの表示。**同ページは「過去閲覧した候補者はグレーアウトして表示されます」としたうえで、「閲覧済みの候補者がその後転職意欲やプロフィール文を更新すると**グレーアウト表示のままで『◯日前にプロフィール更新』と記載されます**」「**最終閲覧日から180日が経過した場合のみ、未閲覧状態（グレーアウト表示されていない状態）に戻ります**」と説明しています。

**「プロフィール更新」の表示を拾います。**一度見て送らなかった学生が、その後プロフィールを更新していたら、状況が変わった可能性があります。グレーアウトのままでも更新の表示は出るので、定期的にここを見る担当を決めておきます。

## 判断を残す仕組みにする

**「気になる」リストの三つの機能。**ヘルプセンターの「スカウトの『気になる』について」は、気になるリストに追加すると次のことができるとしています。

- **ラベル機能**：「気になるリストに追加した候補者をラベリングすることができます。気になるリストの中から**ラベルで検索**することができます。ラベルを追加すると候補者一覧のプロフィール下に設定したラベルが表示されます」
- **メモ機能**：「気になるリストに追加した候補者にメモを残すことができます。メモを残すと**候補者一覧のプロフィール下にメモの内容が表示されます**」
- **評価機能**：「気になるリストに追加した候補者を**3段階でレーティング**することができます」

**この三つが、選定基準を型にする道具です。**頭の中の基準を、ラベルと評価に落とします。

| 使うもの | 何を入れるか |
|---|---|
| **ラベル** | 募集との対応（◯◯職候補）、学年、志向の分類。**あとで検索できる**単位にする |
| **メモ** | 「なぜこの評価なのか」を一行。一覧に表示されるので、他の人も読める |
| **評価（3段階）** | 送る優先度。今週送る／来週以降／送らない |

**メモの一行が、引き継ぎの資料になります。**複数人で回す場合や外部に出す場合、なぜその判断をしたのかが残っていないと、基準がぶれます。一覧にメモが表示される仕様なので、書いた瞬間に共有される形です。

**「非表示」で母数を整えます。**ヘルプセンターの「スカウトの『非表示』について」は「スカウトの候補者について、特定の候補者を今後検索結果に表示しないことが可能です。検索条件に合致する場合でも非表示に設定されていると、その候補者は候補者一覧に表示されなくなります」としたうえで、「候補者一覧に表示されることはなくなりますが、**スカウト画面左の『非表示』から非表示に設定している候補者を一覧で確認することは可能**です」と説明しています。

**毎週同じ人を見返す時間をなくせます。**条件に合うが送らないと決めた学生を非表示にしておくと、翌週の抽出結果がきれいになります。判断を取り消したくなったら、非表示の一覧から戻せます。

**「送信済み」も選定の材料です。**ヘルプセンターの「スカウトの『送信済み』について」は「過去にスカウトを送信した候補者の一覧です」とし、絞り込みでソートでき、「以前に送信したメッセージの内容もこちらよりご確認いただくことができます」としています。同じ学生に別の募集から重ねて送っていないかを、ここで確かめます。

### エラベルの見解

依頼側から見ると、新卒の選定でいちばん困るのは「見る項目が多すぎて決まらない」ことです。学歴、学部、サークル、インターン歴、ゼミ、資格、自己紹介文。全部を見ようとすると、一人あたり五分かかり、百人見るのに八時間かかります。

実務で効くのは、**見る順番を固定すること**です。第一段階は一覧のアイコンだけで振り分ける。自社への興味を示すアイコンがある学生、Premiumメンバーシップの印がある学生、直近でスカウトを受け取る設定にした学生。ここで三段階の評価を付けてしまいます。第二段階でプロフィール本文を読むのは、評価が上位の人だけ。この二段構えにすると、一人あたりの時間が三分の一になります。

そして、**送らないと決めた人を非表示にする**ことを習慣にします。これをやっていないと、毎週同じ人が検索結果に出てきて、毎週同じ判断をやり直すことになります。非表示にしても一覧から確認できる仕様なので、間違えても戻せます。

もう一つ、**選定基準そのものを文章にする**ことを勧めています。ラベルの名前と評価の三段階が何を意味するかを、一枚に書く。「評価3＝今週送る」「評価2＝来週以降」「評価1＝送らない」。これがないと、担当者ごとに基準がずれます。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、基準を文章にしてから動く担当者かどうかを、面談で確かめてみてください。

## 新卒の選定基準を組む

新卒で使える判断材料は限られています。絞り込みで取れるものと、プロフィールを読んで取るものに分けます。

**絞り込みで取れるもの（ヘルプセンター「スカウト対象ユーザーの絞り込みについて」）。**

| 材料 | 使用可能プラン |
|---|---|
| 職種（大分類・小分類）、地域、年齢 | 全プラン |
| 自社への興味（ブックマーク／閲覧／フォロー／ストーリー閲覧／ストーリーいいね） | 全プラン |
| プロフィール項目（**検索結果の一覧画面に選択した項目が表示されます**） | 全プラン |
| つながり（あなたの知り合い／社員の知り合い） | 全プラン |
| フリーワード（必須） | 全プラン |
| フリーワード（歓迎・除外） | プレミアムプラン |
| **新卒フィルター（卒業年度・インターン歴）** | プラスプラン・プレミアムプラン |
| 転職意欲・副業意欲・意欲の更新時期・最終ログイン | プラスプラン・プレミアムプラン |
| 他社からの興味 | プレミアムプラン |

**「プロフィール項目」を先に設定します。**同ページは、プロフィール項目について「選択した項目を記載している候補者を検索できます。また**検索結果の一覧画面に選択した項目が表示されます**」としています。一覧で見たい項目を先に選んでおくと、プロフィールを開かずに判断できる範囲が広がります。

**選定の型。**

| 段階 | やること |
|---|---|
| 0 | 新卒フィルターで**卒業年度**を指定。職種・地域を足して母数を確定 |
| 0 | 一覧に出す**プロフィール項目**を選ぶ。フリーワード（必須）を決める |
| 1 | 一覧のアイコンで振り分け。自社への興味／直近でのアクション／受け取り設定／Premium |
| 1 | 「気になる」に追加し、**ラベル**と**3段階の評価**を付ける |
| 2 | 評価の上位だけプロフィール本文を読む。**メモ**に一行、理由を書く |
| 2 | 送らないと決めた人は**非表示**にする |
| 3 | 「送信済み」で重複を確認してから、募集を紐づけて送信 |

**インターン歴の扱いを決めておきます。**新卒フィルターはインターン歴で「なし」を選べる仕様です。長期インターン経験を重視するのか、経験がない学生も対象にするのか。ここを決めないまま抽出すると、毎回違う母数が出てきます。

**「◯社が興味あり」で優先度を決めます。**直近1ヶ月に該当候補者を閲覧した企業数が表示されるので、数が多い学生は競合が多い状態です。送るなら早く、文面も具体的に。数が少ない学生は、じっくり口説ける代わりに、こちらから見つけた理由を丁寧に書く必要があります。**同じ評価でも、送り方を変える材料になります。**

**180日の仕様を運用に入れます。**閲覧済みのグレーアウトは、最終閲覧日から180日が経過した場合のみ未閲覧状態に戻るとされています。長期の新卒採用では、同じ学年の学生を何度も見ることになるので、**いつ見たか**が分かる状態を保つことが、重複作業を防ぎます。

### エラベルの見解

依頼側から見ると、選定を外に出すときに心配なのは「自社の基準で選んでくれるか」です。これは、基準を渡していないことが原因であることがほとんどです。「優秀な学生を」では、誰も同じ判断ができません。

渡すべきなのは、**過去に採った人と、採らなかった人**です。去年入社した三人のプロフィールと、最終面接まで行って見送った三人のプロフィール。この六人を見せて「この違いを言葉にしてください」と頼むと、基準が出てきます。会社が言葉にできていない基準を、外の人が言語化する。これが、選定を外に出すときの最初の仕事です。

そのうえで、ラベルと評価の定義を決めます。定義さえ揃えば、判断は任せられます。逆に、定義を決めずに「いい人を選んで」と渡すと、返ってくるのは誰にでも当てはまる選定結果です。

もう一つ、**選定の記録が残る形で渡す**ことを条件にしておきます。気になるリストのメモに理由が書かれていれば、社内で見返せます。途中で内製に戻すときも、基準ごと引き継げます。エラベルは依頼側が担当者を選べる仕組みなので、記録の残し方まで最初に約束できる担当者かどうかを、面談で聞いてみてください。媒体を複数使う場合の整理は[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)にまとめています。

## まとめ

- 検索結果一覧のアイコンで、**自社への興味**（ブックマーク／閲覧／フォロー／直近でのアクション）と**◯社が興味あり**（直近1ヶ月に閲覧した企業数）が分かる
- **Premiumメンバーシップ利用**の候補者には「**スカウトチケットを消費せずにスカウトを送信できます**」とされている。チケット配分の材料になる
- **SNSアイコン（Github／X／LinkedIn）はプレミアムプランのみ**
- 閲覧済みはグレーアウト。プロフィール更新があれば「◯日前にプロフィール更新」と表示され、**最終閲覧日から180日経過で未閲覧状態に戻る**
- 「気になる」の**ラベル・メモ・3段階の評価**で判断を残す。メモは候補者一覧のプロフィール下に表示される
- 送らないと決めた候補者は**非表示**にして母数を整える。非表示の一覧からいつでも確認できる。仕様は変わるので、公式の案内でご確認ください

## よくある質問

### プロフィールを開かずに判断できますか

Wantedlyのヘルプセンター「スカウトの検索結果一覧について」は、一覧に表示されるアイコンとして、貴社に対してのアクション（募集をブックマーク／募集を閲覧／会社をフォロー／直近でのアクション／◯社が興味あり）、候補者の状況（直近でスカウトを受け取る設定にしている／転職・副業意欲／Premiumメンバーシップ利用）、候補者のSNS（プレミアムプランのみ）を挙げています。また「スカウト対象ユーザーの絞り込みについて」は、プロフィール項目について「検索結果の一覧画面に選択した項目が表示されます」としています。一覧で見たい項目を先に設定しておくと、開かずに振り分けられる範囲が広がります。

### 一度見た候補者は、あとから分かりますか

「スカウトの検索結果一覧について」は「過去閲覧した候補者はグレーアウトして表示されます」としています。あわせて、閲覧済みの候補者がその後転職意欲やプロフィール文を更新すると、グレーアウト表示のままで「◯日前にプロフィール更新」と記載される、最終閲覧日から180日が経過した場合のみ未閲覧状態に戻る、と説明されています。したがって、更新があった候補者は見分けられる形です。仕様は変わるので、公式の案内でご確認ください。

### 選定の理由を社内で共有できますか

「スカウトの『気になる』について」は、気になるリストに追加した候補者について、ラベル機能（ラベルで検索でき、候補者一覧のプロフィール下に表示される）、メモ機能（メモを残すと候補者一覧のプロフィール下にメモの内容が表示される）、評価機能（3段階でレーティングできる）を挙げています。メモが一覧に表示される仕様なので、判断の理由を一行書いておくと、そのまま共有されます。複数人で回す場合や、選定を外部に任せる場合は、ラベルと評価の定義を先に文章にしておくのが実務です。
