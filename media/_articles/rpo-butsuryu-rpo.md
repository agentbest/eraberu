物流・運送の採用代行は、職種・業務と拠点、必要な資格・勤務条件を整理して依頼範囲を決めます。**原稿・媒体運用・連絡・日程や記録等の実務と、社内の確認・承認・採否、安全・配置等の責任を区別します。**受け入れ準備を支援するサービスもあるため、外部に頼める範囲を一律には決めず、現地の対応と責任を確認します。[ドライバー採用の判断基準](/media/rpo-driver-rpo/)、[倉庫・物流スタッフ採用の判断基準](/media/rpo-soko-rpo/)も参照できます。

## 物流・運送業界の採用が難しい五つの理由

| 確認する領域 | 今回の条件 | 委託時の確認 |
|---|---|---|
| 職種・業務 | ドライバー、倉庫、運行管理・事務等の実際の仕事 | 一社で全職種が不可と決めず、対応職種と工程を確認 |
| 資格 | 業務・車両と必要資格、取得状況 | 一次照合と資格・安全・配置の判断を分ける |
| 勤務条件 | 時間・休日、拘束・休息等の実際の運用 | 正確な原稿・回答と承認先、変更の処理 |
| 勤務地 | 本人の希望、通勤・転居の意向 | 地域・職種と媒体条件への対応を確認 |
| 継続募集 | 増員・欠員、採用・離職と現場体制 | 募集が続く理由を離職だけと決めない |

依頼先が担える設計・実務・受け入れ準備等を確認し、社内の判断・承認と現地の責任者を決めます。母集団形成と連絡速度だけを委託の効果とせず、実際の工程と成果物で確認します。

## 工程ごとの「任せられる・残す」

| 工程 | 外部に相談する内容 | 社内で確認・判断すること |
|---|---|---|
| 要件・条件 | 聞き取りと原稿・確認項目の下書き | 業務・必要資格、給与・勤務と教育体制 |
| 募集経路 | 許可された媒体の運用等 | 対象職種・地域、利用条件と予算・原稿承認 |
| 連絡・日程 | 対応時間・件数を合意した実務 | 条件回答の承認、候補日と不在時の担当 |
| 書類 | 合意した項目の照合・記録 | 不明・不一致の確認先、資格・適性等の判断 |
| 現地・配置 | 対応可否と分担を個別に相談 | 安全・運行・配置と評価の責任者 |
| 受け入れ | 資料・日程等の準備支援を個別確認 | 必要な指導・教育等の条件と現場での実施責任 |
| 報告・終了 | 記録・成果物の引き継ぎ | 必要項目・共有権限、出力・連携と返還削除・権限停止 |

「免許と資格」「労働時間の実態」は、物流・運送に特有の残す工程で、法令上の整理があると一般に整理されているため、会社と専門家が決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

継続募集は、離職だけでなく増員、必要資格や条件、地域・時期や選考の滞留等でも起こり得ます。入社と離職の対象人数・期間、必要人数と媒体・選考実績を確認します。本人が伝えた退職理由と会社の推測を区別し、受け入れと採用実務の改善を並行して検討します。[早期離職の確認](/media/rpo-souki-rishoku/)も参照できます。

## 代行に出す前に社内で確認すること

| 確認 | 整理する内容 |
|---|---|
| 業務と人数 | 職種ごとの仕事内容、必要人数と時期、拠点・勤務地 |
| 資格 | 必要区分と取得状況の確認方法、一次照合と判断の責任者 |
| 条件と説明 | 給与・勤務と実際の運用、原稿と条件回答の承認 |
| 採用・離職 | 対象人数・期間と実績、本人が伝えた理由と不明なこと |
| 受け入れ | 必要な指導等の条件、担当・実施記録と現地責任 |
| 日程 | 候補者と社員の都合、勤務・休息と現場体制に合う候補日 |
| 記録 | 項目・定義、共有先と権限・保存、交代と終了の処理 |

「労働時間の実態」は、法令上の整理があると一般に整理されているため、求人票に書く前に専門家の確認を経ておきます。

## 職種の型ごとに代行の型が違う

| 職種 | 相談する実務の例 | 社内の確認 |
|---|---|---|
| ドライバー | 原稿・媒体・連絡・日程と記録 | 資格・運転と安全、配置・受け入れ。[ドライバーの採用要件](/media/rpo-driver-youken/) |
| 倉庫 | 業務・勤務条件に合う経路と連絡等 | 現場業務・資格安全面と受け入れ。[倉庫スタッフの採用要件](/media/rpo-soko-youken/) |
| 運行管理・配車等 | 対象職務の原稿・経路と選考事務 | 必要な知識・資格と実績、配置責任 |
| 事務 | 原稿と応募・連絡・日程等 | 担当業務・条件と評価・採否 |

「物流・運送の採用に強い代行」でも、ドライバーと倉庫と管理の型を分けて持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種の型ごとの経路 | 「ドライバーと倉庫で、経路と文面をどう変えますか」 |
| 免許と労働時間の扱い | 「免許の区分を書類でどう照合しますか。労働時間の実態は社内と専門家で決めた範囲で書く前提で、どこまで任せられますか」 |
| 常に募集している状態への対応 | 「募集が止まらない会社で、離職の理由をどう採用に戻しますか」 |
| 担当者の経歴 | 「担当する方は、物流・運送のどの職種の型の採用を、どの工程で担った経験がありますか」 |
| 返事の速さと記録の置き場所 | 「候補者への返事は何営業日以内か。記録はどこに置くか」 |
| 費用の構造 | 「月額に含まれる工程と拠点の数は」 |

費用は、含まれる工程と拠点の数で変わり、金額の相場を先に聞くより「同じ工程・同じ拠点数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 確認する情報 | 対応の検討 |
|---|---|---|
| 資格と業務が合わない | 要件、取得状況・限定等と照合の記録 | 責任者へ確認し、原稿・確認項目を見直す |
| 説明に相違がある | 原稿・面接・回答と実際の条件、本人の指摘 | 条件と承認・更新の運用を確認 |
| 離職がある | 対象人数・期間、本人回答と教育・現場体制 | 一つの原因に決めず、必要な対策を並行検討 |
| 増員が間に合わない | 必要時期・人数と採用・教育期間、予測変更 | 計画・募集条件・体制を照合する |
| 日程が決まらない | 社内判断待ち・本人希望と候補日、不在時 | 時間帯・形式・担当者を確認。固定週一や即日を保証しない |
| 記録を引き継げない | 保存・出力・権限と契約条件 | 事前に自社保持・引き継ぎを確認し、利用終了時の停止とデータ処理を分ける |

問題が起きたら、確認済みの事実と仮説、担当・期限を分けて記録します。表の項目だけで原因を説明できるとは限らないため、新しい条件や本人の回答を踏まえて見直します。

### エラベルの見解

仕事内容と勤務条件は正確に説明し、原稿・面接・連絡で相違がないか確認します。記載すれば応募が減って定着が上がるとは一律に言えません。表示・応募・選考・入社後の実績を同じ定義で確認し、本人の質問・希望も踏まえて改善します。[求人原稿の作成](/media/rpo-task-kyujin-genko-susumekata/)も参照できます。

## まとめ

- 職種・業務・拠点と必要人数・時期を具体化する
- 外部が担う実務と、社内の事実確認・承認・安全配置と採否の責任を分ける
- 受け入れ準備等も支援可否を確認し、一律に外部不可とはしない
- 継続募集を離職だけで説明せず、複数の条件と実績を見る
- 原稿の正確さだけで応募減・定着向上を保証しない
- 共有権限・保存・終了時の記録とデータ処理を決める

## よくある質問

### ドライバーが常に足りず、募集を止められません

必要人数と増員・欠員、採用と離職の対象人数・期間を確認します。離職が多い場合も理由を推測で決めず、本人が伝えた内容と受け入れ・勤務体制を点検します。同時に媒体・条件・連絡選考の実績を確認し、委託する実務と社内の改善を分けます。一つ直せば募集が止まるとは保証しません。

### 免許の無い人を採って、取得を支援する形は成り立ちますか

免許の区分と運転できる車両と配置の関係は、法令上の整理があると一般に整理されているので、会社と専門家で「取得までに担える業務」「支援の中身（費用の扱い、期間、取れなかった場合）」を決めてから募集します。決めずに「入社後に取ってください」で採ると、担える業務が無いか、支援の話で揉めます。要件と求人票には区分（必須・取得の支援・歓迎）を同じ形で書きます。個別の判断は専門家にご確認ください。

### 倉庫の繁忙期の増員を、毎年ぎりぎりで回しています

需要の予測と必要時期・人数、採用と教育の期間、社内の判断・受け入れ体制を照合します。毎年同じ時期や人数と決めず、予測の変更を共有します。外部には対応できる媒体・工程と件数・時間を確認し、過去就業者への再連絡や派遣からの変更は本人の意思と情報利用・契約等の条件を先に確認します。[要員計画と採用計画](/media/rpo-jinin-keikaku/)も参照できます。
