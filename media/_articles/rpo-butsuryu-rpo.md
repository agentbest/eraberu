物流・運送業界の会社が採用代行を検討するとき、動機は「ドライバーが常に足りず、募集を出し続けている」「倉庫の人が集まらず、繁忙期に回らない」であることが多い。ただ、物流・運送の採用は、他の業界と違う難しさがあります。ドライバー・倉庫・管理・事務で経路も要件も違い、免許と資格が要件と配置に関わり、労働時間の扱いに法令上の整理があり、拠点が地域に分かれて勤務地と時間帯で候補者が絞られ、常に募集している状態で採用の担当が疲弊している。結論を先に書くと、**物流・運送業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、免許と資格の要件の決定・労働時間の実態の判断・配置と条件の判断・受け入れは社内に残さないと、採れても配置できず、離れます。**代行に出す前に、難しさを自社の状況で分解し、職種の型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[ドライバー採用を代行に出す判断基準](/media/rpo-driver-rpo/)や[倉庫・物流スタッフ採用を代行に出す判断基準](/media/rpo-soko-rpo/)に書いています。ここでは、物流・運送業界で共通する切り分けに絞ります。

## 物流・運送業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 職種の型で経路と要件が違う | ドライバーは免許と地域の経路、倉庫は地域の掲載型と派遣からの切り替え、管理は掲載型と紹介、事務は掲載型 | 一つの代行で全部は回らない |
| 免許と資格が配置に関わる | 免許の区分で運転できる車両と配置が変わり、法令上の整理がある | 要件に免許をどう置くかは会社と専門家。代行は照合まで |
| 労働時間の扱いに法令上の整理 | 拘束の時間や休息の扱いに法令上の整理があり、求人票に書ける実態が決まる | 実態の判断は会社と専門家。代行は範囲の中で書く |
| 勤務地と時間帯で絞られる | 拠点が地域に分かれ、早朝や夜間の時間帯で候補者が限られる | 地域の経路と、時間帯を先に出す必要 |
| 常に募集している | 離職が多く、募集が止まらず、採用の担当が疲弊 | 採用の入口だけ直しても、受け入れと実態が合わなければ繰り返す |

五つのうち、代行で解決できるのは母集団形成と速さで、免許・労働時間・配置・受け入れの判断は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 免許と資格の要件の決定 | 残す | 配置と車両に関わる。会社と専門家。法令上の整理がある |
| 労働時間の実態の判断（求人票に何を書くか） | 残す | 法令上の整理がある。会社と専門家 |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の車両で〇〇の型の配送（ルート・長距離・拠点間など）を担った経験」に。代行が整え、責任者が確認 |
| 母集団形成（型ごとの経路） | 任せられる | ドライバーは地域の経路と免許の区分で、倉庫は地域の掲載型。型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 常に募集している状態で最も負担が大きい工程 |
| 書類の一次確認 | 一部任せられる | 「免許の区分・型・担った範囲」の照合は外で。運転の実力と安全の確認は社内 |
| 運転と安全の見極め（面接、同乗、適性の確認） | 残す | 運行の責任者。安全に関わる |
| 配置（拠点、時間帯、車両）の判断 | 残す | 運行の責任者 |
| 受け入れ（最初の三か月、同乗の期間、教える人） | 残す | 拠点の責任者。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 一覧と週次の一枚。拠点をまたいで一つに |

「免許と資格」「労働時間の実態」は、物流・運送に特有の残す工程で、法令上の整理があると一般に整理されているため、会社と専門家が決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

物流・運送業界で多くの会社が見落とすのは、「常に募集している」状態が、採用の入口の問題ではなく、離職の問題であることです。応募を増やし、採り、数か月で離れ、また募集する。代行に「もっと集めて」と頼んでも、穴を埋めるだけで費用が出続けます。退職面談で理由を集め、「労働時間の実態が聞いていたのと違う」「同乗の期間が無く一人で出された」「拠点の人間関係」「条件」のどれかに分けると、直す場所は求人票の実態と受け入れの体制です。エラベルで担当者を選ぶ企業には、「直近で辞めたドライバーの理由を、実態・受け入れ・拠点・条件のどれかで分けていますか」を、私たちから先に聞いています。分けていなければ、代行の前に退職面談の記録からです。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種の型と経路 | ドライバー・倉庫・管理・事務のどれを採るか。型ごとの経路 |
| 免許と資格の要件 | 免許の区分と配置の関係。必須か、取得の支援か。法令上の整理は専門家に確認済みか |
| 労働時間の実態 | 求人票に書ける実態（時間帯、拘束の考え方、休日）を、会社と専門家で確認済みか |
| 離職の理由 | 退職面談の記録があるか。実態・受け入れ・拠点・条件のどれか |
| 受け入れの体制 | 同乗の期間、教える人、最初の三か月の到達点が、拠点ごとにあるか |
| 面接と同乗の枠 | 運行の責任者の枠を週に決まった数出せるか |
| 記録の形 | 拠点をまたいで一つの一覧があるか |

「労働時間の実態」は、法令上の整理があると一般に整理されているため、求人票に書く前に専門家の確認を経ておきます。

## 職種の型ごとに代行の型が違う

| 職種の型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| ドライバー | 地域の経路と免許の区分での母集団形成、一次対応 | 運転と安全の見極め、配置、同乗の受け入れ。[ドライバーの採用要件の作り方](/media/rpo-driver-youken/) |
| 倉庫 | 地域の掲載型の運用、一次対応、繁忙期の増員の運用 | 現場の見学と実態の説明。[倉庫・物流スタッフの採用要件の作り方](/media/rpo-soko-youken/) |
| 管理（運行・配車） | 掲載型と紹介の母集団形成、一次対応 | 運行の知識の見極め |
| 事務 | 掲載型、一次対応 | 部門の責任者の見極め |

「物流・運送の採用に強い代行」でも、ドライバーと倉庫と管理の型を分けて持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種の型ごとの経路 | 「ドライバーと倉庫で、経路と文面をどう変えますか」 |
| 免許と労働時間の扱い | 「免許の区分を書類でどう照合しますか。労働時間の実態は社内と専門家で決めた範囲で書く前提で、どこまで任せられますか」 |
| 常に募集している状態への対応 | 「募集が止まらない会社で、離職の理由をどう採用に戻しますか」 |
| 担当者の経歴 | 「担当する方は、物流・運送のどの職種の型の採用を、どの工程で担った経験がありますか」 |
| 返事の速さと記録の置き場所 | 「候補者への返事は何営業日以内か。記録はどこに置くか」 |
| 費用の構造 | 「月額に含まれる工程と拠点の数は」 |

費用は、含まれる工程と拠点の数で変わり、金額の相場を先に聞くより「同じ工程・同じ拠点数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 応募は来るが、免許の区分で配置できない | 要件に免許の区分が無い | 会社と専門家で区分を整理し、要件と一次確認に |
| 面接で「時間帯が聞いていない」と辞退 | 時間帯と労働時間の実態を先に出していない | 専門家の確認を経た実態を、求人票と初回の連絡に |
| 採れたが、数か月で離れて、また募集 | 受け入れ（同乗、教える人）が無い。実態のずれ | 退職面談で理由を分け、求人票と受け入れを直す |
| 倉庫の繁忙期に間に合わない | 増員の計画と採用の一枚が無い | 繁忙期の前に一枚で準備 |
| 面接の枠が取れない | 運行の責任者が現場で手一杯 | 週に一枠を先に預かる。早朝や夕方の枠も |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「免許の区分」「実態」「受け入れ」「計画」「枠」に戻ります。

### エラベルの見解

物流・運送業界で「実態を求人票に書くと応募が減る」という懸念は、どの会社にもあります。ただ、時間帯や拘束の実態を書かずに採った人は、入社後に「聞いていない」で離れ、募集を繰り返します。実態を書くと応募は減りますが、減るのは「その実態では働かない人」で、残った応募は定着します。書ける実態の範囲は法令上の整理があるため、会社と専門家で決めた範囲の中で、正直に書く。エラベルは担当者を工程ごとに選べる形にしているので、「実態を書いた求人票での地域の経路の運用と一次対応と記録」を担当者が担い、運行の責任者は「見極めと配置と受け入れ」に絞る、という組み方ができます。実態の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## まとめ

- 物流・運送業界の難しさは、**職種の型・免許と資格・労働時間の扱い・勤務地と時間帯・常に募集している状態**の五つ
- **母集団形成・一次対応・日程・記録は任せられ、免許と資格の要件・労働時間の実態の判断・見極めと配置・受け入れ・条件は残す**
- **免許・資格・労働時間は会社と専門家**。法令上の整理がある。代行は照合と範囲の中の作業まで。個別の判断は専門家にご確認ください
- 「常に募集している」は**離職の問題**。退職面談で理由を分け、求人票の実態と受け入れを直してから代行に
- 職種の型（ドライバー・倉庫・管理・事務）ごとに**経路と代行の型が違う**
- 実態を先に出すと**応募は減り、定着が上がる**

## よくある質問

### ドライバーが常に足りず、募集を止められません

止められないのは、離職が採用を上回っているからで、採用の入口だけ直しても止まりません。退職面談で理由を「実態・受け入れ・拠点・条件」に分け、最も多い理由を一つ直す（同乗の期間を置く、時間帯の実態を先に書く、など）と、離職が減り、募集が減ります。代行には「一次対応と日程と記録」を出して担当の負担を減らし、その時間を退職面談と受け入れの設計に使う形が、止める道です。

### 免許の無い人を採って、取得を支援する形は成り立ちますか

免許の区分と運転できる車両と配置の関係は、法令上の整理があると一般に整理されているので、会社と専門家で「取得までに担える業務」「支援の中身（費用の扱い、期間、取れなかった場合）」を決めてから募集します。決めずに「入社後に取ってください」で採ると、担える業務が無いか、支援の話で揉めます。要件と求人票には区分（必須・取得の支援・歓迎）を同じ形で書きます。個別の判断は専門家にご確認ください。

### 倉庫の繁忙期の増員を、毎年ぎりぎりで回しています

繁忙期の時期は毎年分かっているので、「増員の計画と採用の一枚」を繁忙期の数か月前に作り、地域の経路の運用と一次対応を代行に出して、時期に合わせて募集を始めます。派遣からの切り替えや、前年の短期の人への再度の声かけ（本人の同意と会社の決まりの範囲で）も経路になります。毎年ぎりぎりになるのは、計画が採用の一枚に無いからで、一枚があれば代行は時期に合わせて動けます。計画のつなぎ方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。
