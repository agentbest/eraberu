紹介会社との定例を組むと、最初の数回は「最近の市場はどうですか」「他社の動きは」と情報の交換になり、紹介会社の営業の話を聞いて終わります。それでも推薦は変わりません。定例は、関係を保つための場ではなく、「先月の推薦のどこがずれていて、今月どう直すか」を一つ決める場です。結論を先に書くと、**紹介会社との定例は、先月の数を並べる→見送りの理由を要件の言葉で戻す→依頼書のずれを一か所直す→今月の優先を伝える→次回の日を決める、の順で短く回し、依頼側の窓口が主で担当者は進行と記録、頻度は推薦の量で変え、全社に同じ形で行い、契約の条件の話は依頼側に渡し、記録を一枚に残します。**紹介会社の管理の四つは[紹介会社を管理する](/media/fukugyo-skill-agent-kanri/)に、依頼書は[紹介会社への依頼書を作る](/media/fukugyo-skill-agent-brief/)に、定例の進行の型は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に書いています。ここでは、紹介会社との定例に絞ります。

## 近況の交換で終わる理由

| 定例の形 | 何が起きるか |
|---|---|
| 「最近どうですか」から始まる | 市場の話と営業の話で時間が消える |
| 数を見ない | 先月の推薦が良かったのか悪かったのかが分からない |
| 見送りの理由を戻さない | 紹介会社は同じずれで推薦を続ける |
| 依頼書を開かない | 要件のずれが直らない |
| 決めることが無い | 出ても出なくても同じ場になり、来なくなる |

定例の価値は、時間の長さではなく、「一つ直したか」で決まります。一つ直れば、次の月の推薦が変わります。

## 進行の型

| 順 | 中身 | 目安 |
|---|---|---|
| 一 | 先月の数を並べる。推薦・一次に進んだ数・面接・内定・入社。件数のまま | 短く。一枚を見せる |
| 二 | 見送りの理由を要件の言葉で戻す。「必須の〇〇が読めなかったのが〇件」「会社の型が遠かったのが〇件」 | 候補者の個人的な評価は言わない |
| 三 | 依頼書のずれを一か所直す。必須の言葉か、条件の幅か、見送りの傾向か | 一か所だけ。版を上げる |
| 四 | 今月の優先を伝える。採用計画で優先の役割、急ぐ役割 | 依頼側の窓口が伝える |
| 五 | 次回の日を決める。紹介会社からの質問に答える | 答えられないものは依頼側に持ち帰る |

一と二が中心で、三で一つ決めます。四と五は短く。全体で三十分に収める形にすると、紹介会社も出やすくなります。数字の並べ方は[数字で語る](/media/fukugyo-suuji/)に書いています。

### エラベルの見解

担当する側から見ると、紹介会社との定例で最も差がつくのは、「見送りの理由を要件の言葉で戻す」を定例の中心に置けるかです。受ける側は、定例で「今月もよろしくお願いします」と関係を保とうとします。ただ、紹介会社が知りたいのは、「なぜ見送られたか」で、それが分かれば次の推薦の精度を自分で上げられます。「見送り三件のうち二件は、必須の〇〇が職務経歴書の記述では読めず、面接でも確かめられませんでした。推薦の理由に、〇〇を担った場面を一行添えていただけると助かります」と、要件の言葉で戻す。これだけで、紹介会社の推薦の書き方が変わります。エラベルで担当者を選ぶ企業には、「紹介会社との定例で、見送りの理由を伝えていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、定例の前に、先月の見送りの理由を要件の分類で数えておくこと。数えてあれば、定例の二の段は二分で済みます。

## 出る人

| 役割 | 誰が | やること |
|---|---|---|
| 主 | 依頼側の窓口（人事） | 今月の優先を伝える。条件や契約の質問に答える（範囲内で） |
| 進行と記録 | 副業の担当者 | 一枚を用意し、順に進め、記録を残す |
| 必要なとき | 現場の責任者 | 要件のずれが大きいとき、任せる仕事を直接説明する |
| 紹介会社 | 担当者（できれば固定） | 推薦の状況、候補者の反応、依頼書への質問 |

担当者が主になると、紹介会社は担当者を依頼側の決定者と見なし、条件や契約の話を担当者に持ちかけます。主は依頼側の窓口に置き、担当者は進行と記録に徹します。契約の範囲で担当者が窓口を兼ねる場合も、「決めるのは依頼側」を定例の冒頭で伝えます。

## 頻度は推薦の量で変える

| 紹介会社の状態 | 頻度の考え方 |
|---|---|
| 推薦が毎週ある | 月に一度の定例＋週次の短い連絡 |
| 推薦が月に数件 | 月に一度 |
| 推薦が二か月無い | 定例より先に、依頼書を渡し直すか取引を見直すかを依頼側が判断 |
| 新しく取引を始めた | 最初の月は二回。依頼書の読み合わせと、最初の推薦の振り返り |

頻度は担当者の稼働にも関わります。取引する社数を絞っていれば、月に一度ずつで回ります。絞っていなければ、定例が稼働を圧迫し、形だけになります。

## 全社に同じ形で

| 揃えるもの | 理由 |
|---|---|
| 進行の型 | 会社ごとに違うと、記録を比べられない |
| 一枚の形 | 数の並べ方が同じなら、月次の一覧にそのまま入る |
| 見送りの理由の戻し方 | 一社にだけ詳しく戻すと、他社との差が出る |
| 今月の優先 | 全社に同じ優先を伝える。一社にだけ先に伝えない |

紹介会社に個別の便宜（他社に無い情報、先行の連絡）を作ると、後で「あの会社だけ優遇している」となり、依頼側の信頼に関わります。関係の深さは、便宜ではなく、返事の速さと理由の戻し方で作ります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「定例で紹介会社の営業の話を聞くのも仕事のうち」というものです。実際には、営業の話（新しいサービス、他社の事例、市場の動向）は、定例の時間を消し、決めることを押し出します。営業の話は「定例の外で、依頼側の窓口宛てに」と最初に線を引き、定例は先月の数と見送りの理由と依頼書の修正に絞る。紹介会社にとっても、決まる求人の情報のほうが、営業の時間より価値があります。受ける側がその場で使える判断としては、定例の冒頭に「今日決めることは、依頼書のずれを一か所直すことです」と一言置くこと。目的が先に共有されると、話が流れにくくなります。

## 契約の条件の話が出たとき

| 話 | 扱い |
|---|---|
| 「手数料の率を見直したい」 | 依頼側の窓口に。担当者は答えない。定例の場で決めない |
| 「返金の規定について」 | 同上。契約の事項 |
| 「独占で任せてほしい」 | 依頼側の判断。担当者は「持ち帰ります」 |
| 「他社より優先してほしい」 | 全社に同じ形、と伝える |
| 「条件を上げてもらえないか（候補者のために）」 | 依頼側に渡す。担当者は答えない |

契約の条件は依頼側と紹介会社の間の事項で、担当者は関与しません。定例の場で持ち上がっても、「依頼側で確認して、別途お返事します」と切り分けます。契約の条件に法令が関わる場合は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。

## 定例の記録の一枚

| 項目 | 中身 |
|---|---|
| 日付、紹介会社、出た人 | 記録の基本 |
| 先月の数 | 推薦・一次・面接・内定・入社。件数 |
| 戻した見送りの理由 | 要件の分類と件数 |
| 依頼書の修正 | 直した箇所と版 |
| 今月の優先 | 伝えた役割 |
| 紹介会社からの質問と持ち帰り | 依頼側に渡すもの。期限 |
| 次回 | 日付 |

候補者の氏名は書かず、件数と分類だけです。記録は依頼側の共有の場所に、紹介会社ごとに期間の順で置きます。月次の紹介会社ごとの一枚（[紹介会社を管理する](/media/fukugyo-skill-agent-kanri/)）の元になります。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 営業の話で時間が消える | 冒頭に「今日決めること」を置く。営業の話は定例の外に |
| 見送りの理由が言えない | 定例の前に要件の分類で数えておく。候補者の評価ではなく照合の結果 |
| 依頼側の窓口が出られない | 担当者が進行し、「決めるのは依頼側」と冒頭で伝える。持ち帰りの期限を明記 |
| 紹介会社の担当者が毎回替わる | 固定を依頼する。替わるなら依頼書の読み合わせから |
| 定例が形だけになる | 「一つ直したか」を記録で見る。直すことが無い月は短く終える |
| 契約の話を担当者に持ちかけられる | 「依頼側で確認します」。定例の場で決めない |

## まとめ

- 定例は近況の交換ではなく、**先月の推薦のずれを一つ直す場**
- 進行は**数を並べる→見送りの理由を要件の言葉で戻す→依頼書を一か所直す→今月の優先→次回**。三十分に収める
- **主は依頼側の窓口、担当者は進行と記録**。「決めるのは依頼側」を冒頭で
- 頻度は**推薦の量で変える**。二か月推薦が無ければ定例より先に依頼側の判断
- **全社に同じ形**。個別の便宜を作らない
- **契約の条件は定例で決めない**。依頼側に渡す。個別の判断は専門家にご確認ください
- 記録は**件数と分類だけ**。氏名を書かず、共有の場所に

## よくある質問

### 紹介会社から「定例は要らない。推薦があれば連絡する」と言われました

推薦が月に数件以下なら、定例を月に一度の短い連絡（先月の数と見送りの理由を一枚で送る）に変えても構いません。定例の形より、「見送りの理由が戻る」「依頼書が更新される」ことが要点です。それすら要らないと言う紹介会社は、依頼側の求人の優先順位が低いので、取引を続けるかを依頼側が判断します。

### 副業の稼働で、全社の定例に出られません

出る社数を絞るか、定例を「一枚を送って質問を受ける」形に変えます。推薦の多い上位の数社だけ定例に出て、残りは一枚の送付で回す形にすれば、稼働に収まります。どの社に出るかは、月次の一覧の推薦の数で決め、依頼側と合意します。稼働の設計は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に書いています。

### 定例で紹介会社から「御社の面接官の対応が悪いと候補者が言っている」と言われました

候補者の声は、依頼側の選考を直す材料なので、記録して依頼側に渡します。ただし、その場で面接官を評価したり、謝ったりしません。「候補者の声として持ち帰り、選考の設計に反映するか依頼側で判断します」と伝えます。日程の遅さや連絡の不備なら、[日程調整を速くする](/media/fukugyo-skill-nittei/)の型で直せることが多い。面接官の対応そのものは、[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)の一枚（候補者に渡すこと）の見直しの材料にします。
