調理師の採用を代行に出すか迷う会社は、「求人を出しても経験者が来ず、来ても料理長と合わずに辞める」「求人票を作って媒体に出す工程はお願いしたいが、料理を知らない人に調理師の採用が回せるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接と試作の日程の確保・内定後の対応は代行に任せられ、業態とジャンルとポジションの整理・任せる範囲・労働時間と休みの実態の開示範囲・料理長への道筋と独立の支援の方針・要件の決定・腕と料理の考え方の評価・合否の判断は社内に残す**のが線です。調理師は、ホールやキッチンの補助のスタッフとは違い、料理を作る職人で、料理長の考え方と料理のスタイルと任される範囲で「この厨房で腕を振るいたいか」を判断します。「料理長の考え方と任される範囲と労働時間の実態を候補者に伝わる形で書き、腕は試作で見る」ことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じ飲食のホールとキッチンのスタッフの線は[飲食店スタッフ採用を代行に出す判断基準](/media/rpo-inshoku-rpo/)にまとめています。

## 調理師採用が他の職種と違う点

一つ目は、業態とジャンルとポジションで求める人と市場が全く違うことです。業態は、レストラン、ホテル、給食や社員食堂、病院や施設の給食、居酒屋、料亭。ジャンルは、和食、洋食、中華、製菓、その他の専門。ポジションは、料理長、二番手、部門（前菜、魚、肉、デザート）、仕込み。フランス料理の二番手を探すのと、施設の給食の調理師を探すのでは、届く層も判断材料も違います。「調理師募集」だけでは、どの業態のどのジャンルのどのポジションかが候補者に伝わりません。

二つ目は、候補者が「料理長の考え方と料理のスタイル」「任される範囲（メニューの開発、仕入れ、原価の管理、部門の責任）」「仕込みから閉店までの労働時間と休み」「料理長への道筋と独立の支援」「厨房の設備と食材の質」を最初に確かめることです。調理師は、料理長の下で腕を磨き、いずれ料理長か独立を目指す人が多く、「この料理長の下で、どこまで任され、どう成長できるか」で判断します。労働時間は、仕込みから閉店までの実態で、休みは週に何日で、それを隠した求人は信じられません。

三つ目は、腕が試作と実技でしか分からないことです。経歴に「〇〇で五年」と書いてあっても、包丁の扱い、火の入れ方、味の決め方、段取りは、厨房で作ってもらわないと分かりません。面接だけで判断すると、入ってから「聞いていた腕と違う」になります。

四つ目は、経験者は取り合いで、独立志向の人が多く、料理長との相性で定着が決まることです。腕のある調理師は、周辺の店で取り合いになり、いずれ独立を考えている人が多い。料理長との相性が合わなければ、腕があっても短期で離れます。「料理長がどういう人で、どういう料理を作るか」を隠した求人は、相性の合わない人を集めます。

五つ目は、料理長は厨房に立っていて、採用の工程を回す人がいないことです。料理長は仕込みから閉店まで厨房にいて、面接と試作の時間を取るのも、応募者に返信するのも難しい。オーナーや本部が回そうとしても、厨房の実態と料理長の考え方を言葉にできず、求人票が「調理師募集。経験者優遇」になります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 業態とジャンルとポジションの整理 | 残す | どの店で、どのジャンルの、どのポジションを任せるか。社内にしか分からない |
| 任せる範囲の決定 | 残す | メニューの開発、仕入れ、原価の管理、部門の責任をどこまで任せるか。料理長が決める |
| 労働時間と休みの実態の開示範囲の決定 | 残す | 仕込みの開始と閉店の時間、中休み、週の休みの日数を、どこまで正直に書くか。料理長とオーナーが決める |
| 料理長への道筋と独立の支援の方針の決定 | 残す | 二番手から料理長への道筋、独立の支援（のれん分け、修業の期間）。オーナーが決める |
| 要件の決定 | 残す | 業態とジャンルとポジションから。外部は整理を手伝える |
| 求人票の作成 | 任せられる（業態とジャンルとポジションと方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。料理長の考え方と料理のスタイルを料理長の言葉で |
| 媒体の選定と運用 | 任せられる | 調理師に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | ジャンルとポジションと勤務地に合わせた検索と、修業してきた店や料理に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、面接と試作の日程、厨房の見学の案内 |
| 料理長の面接と試作の日程の確保 | 任せられる | 仕込みの前や中休みに面接と試作の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 業態・ジャンル・ポジション・勤務地の分類は任せられる。腕の評価は残す |
| 腕と料理の考え方の評価 | 残す | 料理長が試作と面接で見る |
| 料理長の考え方と任せる範囲と労働時間の実態の説明 | 残す（代行が同席可） | 料理長が自分の言葉で話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 料理長とオーナーの判断 |
| 条件の決定と提示 | 残す | 会社の判断。ポジションと腕で条件の幅が広い |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。現在の店の区切りに合わせた入社日の調整 |

線の要点は、「業態とジャンルとポジション、任せる範囲、労働時間と休みの実態、料理長への道筋と独立の支援の方針が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「この料理長の下で腕を振るいたいか」「生活が成り立つか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「調理師の求人を出しても経験者が来ず、来ても料理長と合わずに辞める」というご相談です。求人票を見ると、「調理師募集。経験者優遇。フレンチ。月給〇〇以上」と書かれていて、ポジションも、料理長の考え方と料理のスタイルも、任せる範囲も、仕込みから閉店までの労働時間も、休みの日数も、料理長への道筋も無い。調理師はこれを読んで、「どういう料理長の下で何を任されるか分からない」と判断し、応募しないか、応募して料理長と合わずに辞めていました。

見ていて差がつくのは、「料理長の考え方と任せる範囲と労働時間の実態を一文で言えるか」です。「〇〇のフランス料理店で、二番手を探している。料理長は〇〇で修業し、『素材を触りすぎない』を大事にしている。二番手には魚の部門と、週替わりの一品の考案を任せ、仕入れは料理長と一緒に市場へ。仕込みは〇時から、閉店は〇時、中休みあり、休みは週に二日で月に一度は連休。二番手から料理長への道筋があり、独立の支援もしている。厨房の設備は〇〇」。一文で料理長と範囲と実態が分かれば、候補者は「この料理長の下で腕を振るいたいか」を判断できます。エラベルでは、調理師の案件をお受けする前に、依頼側に「業態とジャンルとポジション」と「料理長の考え方と任せる範囲と労働時間の実態」を伺い、料理長の言葉で一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：業態とジャンルとポジション。** どの店で、どのジャンルの、どのポジション（料理長、二番手、部門、仕込み）を任せるか。厨房の人数と構成。

**二つ目：料理長の考え方と料理のスタイルと、任せる範囲。** 料理長が何を大事にしているか（素材、火入れ、伝統、創作）を料理長の言葉で。採る人に、メニューの開発、仕入れ、原価の管理、部門の責任をどこまで任せるか。将来どこまで広げるか。

**三つ目：労働時間と休みの実態。** 仕込みの開始と閉店の時間、中休みの有無と実態、週の休みの日数、連休の取り方、繁忙期の実態。正直に把握し、「どこまで書くか」を決めます。調理師は労働時間の実態を隠した求人を信じません。労働時間に関わる法令上の扱いは、専門家にご確認ください。

**四つ目：料理長への道筋と独立の支援。** 二番手から料理長への道筋（時期、条件）、独立の支援（のれん分け、修業の期間、独立後の関係）、複数店舗があれば料理長のポストの数。

**五つ目：料理長が、面接と試作にどのくらい時間を出せるか。** 仕込みの前や中休みに、面接と試作と厨房の見学の時間をどう確保するか。試作の形（何を作ってもらうか、食材、時間）を決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 料理長の関与のさせ方

調理師の採用では、料理長の関与が要ります。試作で腕を見る、面接で料理の考え方を聞く、自分の考え方と料理のスタイルと任せる範囲を自分の言葉で話す、厨房を見せる。しかし料理長は厨房に立っていて、「採用はオーナーの仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると料理長がどう楽になるか」を具体的に示すことです。「二番手が入れば、料理長が魚の部門を持たなくて済む」「料理長が休める日が増える」。そして、負担を最小にする形で頼みます。面接と試作の枠は代行が中休みに押さえる、経歴は代行が整理して渡す、試作の食材と段取りは代行が用意する。料理長がやるのは、試作で腕を見ることと、料理の考え方を聞くことと、自分の考え方と任せる範囲と実態を話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で料理長が「自分の料理の考え方」を自分の言葉で話すことの価値を、料理長自身に理解してもらうことです。調理師は、料理長との相性で続けるかを決めます。料理長が「素材を触りすぎないのが自分の料理。二番手には魚を任せて、週替わりの一品は自由に考えてほしい。仕込みは〇時からで正直長いが、休みは週に二日を守っている」と話すと、候補者は「この料理長の下で腕を振るいたいか」を判断できます。相性が合わない人は面接で見送り、合う人が残ります。

## 代行を選ぶときの確認項目

調理師の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に飲食や厨房の経験があるか。** 調理そのものでなくても、飲食の本部や店舗の運営、調理師の採用を回した経験。業態とジャンルとポジションの違い、料理長の考え方の聞き取り方、労働時間の実態の書き方を知っているか
- **料理長の考え方と任せる範囲と労働時間の実態を求人票にどう書くか、案を出せるか。** 「調理師募集。経験者優遇」で済まさず、料理長の言葉と範囲と実態を書けるか
- **調理師に届く媒体と経路の経験。** 調理師向けの媒体、スカウト、料理長のつながり（修業先、同門）、調理の専門学校、他店の調理師の紹介、独立志向の人への届け方。経路ごとの経験
- **試作の段取り。** 試作の形（何を作ってもらうか）、食材と時間の用意、料理長が見るポイントの整理。試作を面接に組み込めるか
- **料理長の日程を押さえる段取り。** 仕込みの前や中休みに面接と試作の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。厨房を知らない担当者は、料理長の考え方を言葉にできず、試作を面接に組み込めず、「経験者優遇」の求人票を作って料理長と合わない人を集めます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、調理師の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「料理長の考え方を料理長の言葉で書かないと、相性の合う人が来ない」と言われることです。オーナーや本部が書いた「こだわりの料理」は、どの店も書いていて信じられません。料理長本人の言葉で「何を大事にしているか」を書くことで、相性の合う人が応募し、合わない人が見送ります。

二つ目は、応募者のジャンルとポジションと経路が分かれることです。同じジャンルの二番手の経験者、別のジャンルからの転向、ホテルや給食から専門店へ、専門店からホテルや給食へ（労働時間の安定を求めて）、専門学校の卒業者、独立を考えている人。それぞれ持っているものと動く理由が違い、任せるポジションと合うかも違います。代行の担当者に分類をしてもらい、試作と面接で確かめることを変えます。

三つ目は、「労働時間の実態」と「独立の支援」で候補者が判断を変えることです。仕込みから閉店までの実態を隠して採ると、入ってから離れます。独立志向の人には、独立の支援の有無と形が判断材料で、「独立させない」方針なら、それも正直に書きます。隠すより、正直に書いて合う人を採るほうが、定着します。

### エラベルの見解

担当する側から見ると、調理師の採用で最も効くのは、「料理長の考え方と料理のスタイルを料理長の言葉で書き、任せる範囲と労働時間の実態を隠さない」ことと、「試作を面接に組み込む」ことです。調理師は、料理長との相性と任される範囲で「この厨房で腕を振るいたいか」を判断し、腕は試作でしか分かりません。「調理師募集。経験者優遇。月給〇〇以上」の求人票と、面接だけの選考では、料理長と合わない人を採って短期で離れます。

エラベルでは、調理師の案件で担当者を紹介するとき、最初の一週間で料理長とオーナーから「業態とジャンルとポジション」「料理長の考え方と料理のスタイル」「任せる範囲」「労働時間と休みの実態」「料理長への道筋と独立の支援」を聞き取り、料理長の言葉で一文にし、試作の形を決めるところから始めてもらっています。腕と料理の考え方の評価は料理長が試作と面接で行い、労働時間に関わる法令上の扱いは、専門家にご確認いただくようお伝えしています。

- 調理師採用が他と違うのは**業態とジャンルとポジションで市場が全く違う・候補者が料理長の考え方と任される範囲と労働時間と道筋と設備を最初に確かめる・腕は試作でしか分からない・経験者は取り合いで独立志向が多く料理長との相性で定着が決まる・料理長は厨房に立っていて採用の工程を回す人がいない**の五つ
- **求人票・媒体・スカウト・一次対応・面接と試作の日程・内定後は任せられ、業態とジャンルとポジション・任せる範囲・労働時間と休みの実態・道筋と独立の支援・要件・腕と考え方の評価・合否は残す**
- 代行に出す前に**業態とジャンルとポジション、料理長の考え方と任せる範囲、労働時間と休みの実態（法令上の扱いは専門家に確認）、料理長への道筋と独立の支援、料理長の面接と試作の時間**を確認する
- 料理長の関与は**採用でどう楽になるかを示し、負担を最小にして、自分の考え方を自分の言葉で話す価値を理解してもらう**
- 代行を選ぶときは**厨房の経験・料理長の言葉と実態の書き方・調理師に届く経路・試作の段取り・日程の段取り**を確認する
- 出したあとは**料理長の言葉が要ることが表に出る・ジャンルとポジションと経路が分かれる・労働時間の実態と独立の支援で判断が変わる**。判断は料理長とオーナー、材料は代行

## よくある質問

### 仕込みから閉店まで長いのが実態です。正直に書くと来ませんか

隠して入ってから分かるほうが、短期で離れて教えた時間が無駄になります。「仕込みは〇時から、閉店は〇時、中休みあり。正直長いが、休みは週に二日を守り、月に一度は連休」のように、実態と、守っていることを一緒に書きます。調理師は、この業界の労働時間の実態を知っていて、正直に書く店を「隠さない店」と読みます。労働時間の安定を求める人は給食やホテルに向かい、腕を磨くために長時間を受け入れる人は専門店に来ます。どちらの層を採るかを決め、実態に合う層に届けます。労働時間に関わる法令上の扱いは、専門家にご確認ください。

### 独立したい人を採ると、すぐ辞めませんか

独立志向の人は、腕のある調理師に多く、独立の支援の有無と形で判断します。「独立させない」方針なら、それを正直に書き、料理長への道筋を示します。独立を支援する方針なら、「〇年の修業の後、のれん分けか独立の支援。独立後も食材の仕入れで関係を続けている」のように書き、独立までの期間を店の戦力として計画します。隠して採ると、独立の話が出たときに揉めます。方針を決めて正直に書けば、合う人が来ます。

### 試作は、何を作ってもらえばよいですか

料理長が見たいことで決めます。包丁の扱いと段取りを見るなら「この食材で一品、三十分で」、味の決め方を見るなら「店の定番を一品、レシピは渡す」、創作の力を見るなら「この食材で自由に一品」。食材と時間と道具を代行が用意し、料理長は作る様子と仕上がりを見て、料理の考え方を聞きます。試作の無い面接は、腕を確かめられず、入ってから「聞いていた腕と違う」になります。試作の段取りは代行に出せる工程です。
