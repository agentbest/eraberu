人事の副業を始めたい。範囲も時間も決めた。次は案件を探す段階だが、どこで探せばよいか分からない。登録先は多く、どれが人事に向いているのか、全部に登録すべきか、知人に頼むにはどう言えばよいか。探し始める前に止まっている。結論を先に書くと、**案件を探す経路は、「人事・採用に特化した登録先」「知人の紹介」「本業の接点（規定の範囲で）」「一般の副業の仲介」の四つです。四つ全部を使うのではなく、自分の範囲と時間に合わせて一つか二つに絞ります。多くの経路に登録すると、それぞれのプロフィールの更新と連絡の対応で時間が消え、案件は決まりません。絞った経路で、範囲と時間を明確に出し、合う案件を待つほうが、決まります**。探す前に決めることは[何から手を付けるか](/media/fukugyo-nani-kara/)に、経験が浅いときの案件の条件は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)にまとめています。

## 探し方で止まる構造

案件を探す段階で止まるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 経路を知らない | 「副業 案件」で検索し、一般の仲介しか見つからず、人事の案件が少なく見える |
| 全部に登録しようとする | 登録先が多く、全部に登録し、プロフィールの更新と連絡で時間が消える |
| 範囲と時間が決まる前に探している | 案件を見ながら「自分にできるか」を考え、決められない |
| 知人に頼む言葉が無い | 「副業を探している」では、知人は何を紹介すればよいか分からない |
| 本業の接点を使ってよいか分からない | 本業で接点のあった会社に声をかけてよいか、規定と利益相反が不安で動けない |
| 案件の質を見分けられない | 範囲が曖昧な案件、判断を含む案件、単価だけ高い案件に引かれる |
| 決まらないと経路を増やす | 決まらない理由を見ずに、登録先を増やし、さらに時間が消える |

構造の大半は、「経路を絞らず、範囲と時間が決まる前に探している」ことです。経路を一つか二つに絞り、範囲と時間を出せば、探す時間は減り、決まりやすくなります。

## 四つの経路と向き不向き

案件を探す四つの経路と、それぞれの向き不向きです。

| 経路 | 内容 | 向く人 | 注意 |
|---|---|---|---|
| 人事・採用に特化した登録先 | 人事・採用の副業に絞った登録先。依頼側も人事の案件を出しに来る | 範囲を「型に沿う」「型を作る」で書ける人。人事の経験がある人 | 登録先の仕組み（案件の出方、報酬の形、契約の形）を確認する |
| 知人の紹介 | 元同僚、前職の上司、人事のつながりから、「〇〇を探している会社がある」と紹介される | つながりがある人。範囲を一言で言える人 | 紹介は関係が絡むので、範囲と条件を最初に書面で |
| 本業の接点（規定の範囲で） | 本業で接点のあった会社（取引先、媒体の担当者、紹介会社）から声がかかる | 本業で外部との接点が多い人 | 本業の規定、競業、情報の切り分け、利益相反を先に確認。判断は専門家に。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 一般の副業の仲介 | 業種を問わない副業の仲介。人事の案件は一部 | 人事以外の経験も売れる人。まず数を見たい人 | 人事の案件は少なく、範囲が曖昧なものが混ざる。見分けが要る |

経路の要点は、「一つ目と二つ目で足りることが多い」ことです。人事の副業は、人事に特化した登録先か、人事のつながりからの紹介で決まることが多い。一般の仲介は、案件の数は多いが、人事の案件の質が読みにくい。本業の接点は、規定と利益相反の確認が先です。

## 経路ごとの探し方

四つの経路それぞれで、どう動くかです。

| 経路 | 動き方 |
|---|---|
| 特化した登録先 | 範囲（一つの業務、含むことと含まないこと）、経験（数と変化）、時間（曜日と時間帯）、期間の希望を書いて登録する。案件の連絡が来たら、四つの条件（型がある、成果物が明確、期間が短い、判断を含まない）で見る |
| 知人の紹介 | 「〇〇（一つの業務）を、週〇時間で受けられる。〇〇のような会社があれば教えてほしい」と、範囲と時間と相手の像を一言で伝える。「副業を探している」だけでは紹介できない |
| 本業の接点 | まず本業の規定を確認し、競業と情報の切り分けの線を引く。線の内側で、接点のある会社から声がかかったときに受ける。自分から営業をかける形は、本業との関係で慎重に。判断は専門家に |
| 一般の仲介 | 「人事」「採用」で絞り、案件の説明で型と成果物と期間と判断を見る。曖昧な案件は、面談で四つを聞く |

動き方の要点は、「知人の紹介は、範囲と時間と相手の像を一言で」です。知人は、あなたの経験の全部は知りません。「スカウトの運用を週六時間で。人事が一人の会社があれば」と言えば、知人は思い当たる会社を挙げられます。

## 探す前に決めておくこと

経路を選ぶ前に、決めておくことです。決まっていないと、どの経路でも決まりません。

| 決めること | 内容 | 決まっていないと |
|---|---|---|
| 一つの業務 | 最初に受ける業務を一つ。範囲を「含むこと」と「含まないこと」で | 案件を見ても「自分にできるか」が判断できない |
| 経験の中身 | 数と変化。「三年で〇〇通、型を変えて返信率が上がった」 | プロフィールが「人事全般」になる |
| 時間 | 固定できる曜日と時間帯 | 案件の稼働が合うか判断できない |
| 期間の希望 | 一〜三か月で区切るか、長期か | 長期の案件に引かれ、区切れない |
| 相手の像 | 人事が一人の会社か、大手か。業界の制限（本業の競業を避ける） | 合わない相手の案件に時間を使う |
| 本業の規定 | 副業の可否、届け出、競業と情報の線。解釈は専門家に | 受けてから問題になる |
| 単価の根拠 | 「時間×時給」の土台。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) | 案件の単価で迷う |

決めることの要点は、「探す前に、探す時間の何倍もかけて決める」ことです。決まっていれば、探す時間は短く、案件を見た瞬間に「合う」「合わない」が分かります。決まっていないと、探す時間が長く、決まりません。

### エラベルの見解

登録の相談で多いのは、「五つの登録先に登録したが、どこからも声がかからない」という声です。プロフィールを見ると、五つとも「人事全般、週十時間程度、応相談」で、更新も止まっていました。経路を一つに絞り、「スカウト運用の一次対応まで、火木の夜と土曜の午前で週六時間、まず三か月」と書き直したら、その経路から声がかかりました。経路の数ではなく、範囲と時間の明確さで決まります。

見ていて差がつくのは、「知人に一言で言えるか」です。「副業を探しています」と言う人には、知人は何も紹介できません。「求人票の作成を週四時間で。採用を始めたばかりの会社があれば」と言える人には、知人が思い当たる会社を挙げます。一言で言える範囲と時間が、紹介の経路を開きます。

エラベルでは、登録の時点で範囲と時間を書いていただくので、書けていれば、合う案件のときだけ声がかかります。書けていなければ、書けるようになってから登録していただくほうが、決まりやすくなります。

## 案件の見分け方

どの経路でも、案件を見たときに見分ける観点です。

| 観点 | 受けてよい | 慎重に | 受けない |
|---|---|---|---|
| 範囲 | 一つの業務で、含むことと含まないことが書ける | 「採用支援」など広いが、面談で絞れそう | 「人事全般」「お任せ」 |
| 型 | 依頼側に型がある | 型は無いが、自分が作れる経験がある | 型が無く、作る経験も無い |
| 成果物 | 「週〇通」「初稿」「一覧」と明確 | 面談で決められそう | 「良くしてほしい」 |
| 期間 | 一〜三か月で区切る | 長期だが、区切りを提案できそう | 期限が無く、区切れない |
| 判断 | 合否・条件・優先順位は依頼側 | 面談で線を引けそう | 判断を求められる |
| 相手 | 人事の担当がいる、または経営が採用に関わっている | 人事の担当がいないが、経営が相談相手になれそう | 相談相手がいない |
| 本業との関係 | 競業でなく、情報の切り分けができる | 業界が近いが、線を引ける | 競業、取引先、情報が重なる |
| 単価 | 根拠と合う | 低いが、一件目として型を身につける価値がある | 高いが、判断や広い範囲の対価 |

見分け方の要点は、「慎重に」の列を、面談で確かめることです。案件の説明だけで判断せず、面談で四つ（型、成果物、期間、判断）を聞けば、「受けてよい」に動くか、「受けない」に動くかが分かります。[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に、聞くことを書いています。

## 探しても決まらないときの見直し

経路を絞り、範囲と時間を出しても、決まらないときの見直しです。経路を増やす前に見ます。

| 見直すこと | 問い | 直し方 |
|---|---|---|
| 範囲 | 「含むこと」と「含まないこと」が書けているか。一つの業務に絞れているか | 一つに絞り、含まないことを足す |
| 経験の中身 | 数と変化があるか。「人事全般」になっていないか | 「〇年で〇〇通、〇〇を変えて〇〇が変わった」に |
| 時間 | 曜日と時間帯で固定されているか。「週十時間くらい」になっていないか | 曜日と時間帯に |
| 相手の像 | 需要のある相手（人事が少数の会社）を想定しているか | 相手の像を変える |
| 業務の需要 | 絞った業務に、依頼側の需要があるか。判断を含む業務を前面にしていないか | 需要のある業務（スカウトの運用、求人票、一次対応、記録）に |
| 単価 | 根拠と市場がずれていないか | 一件目は控えめに、二件目で上げる |
| 経路 | 選んだ経路が、自分の範囲に合っているか | 一つ足す。ただし三つ以上にしない |
| 待つ時間 | 登録から何か月か | 最初の一件は時間がかかることがある。三か月は待つ |

見直しの要点は、「経路を増やす前に、範囲と経験と時間を見直す」ことです。決まらない理由の大半は、経路の数ではなく、プロフィールの中身です。中身を直してから、それでも決まらなければ、経路を一つ足します。

## 待つ間にやること

登録して、案件を待つ間にやることです。待つ時間を、次の案件の準備に使います。

| やること | 内容 |
|---|---|
| 型を書き留める | 本業の型（文面、基準、手順）を、自分の言葉で書き留める。案件が来たとき、すぐ使える |
| 数を記録する | 本業の作業の数を、月ごとに記録する。実績が増える |
| 一つの業務を深める | 絞った業務を、本業で数を出してやる。「〇〇なら任せられる」を厚くする |
| 経路の一言を用意する | 知人に言う一言（範囲、時間、相手の像）を用意し、機会があれば伝える |
| 規定と線を確認する | 本業の規定、競業、情報の線を、専門家に確認しておく。案件が来たとき、すぐ判断できる |
| プロフィールを月に一度見直す | 数と変化を更新する。更新の止まったプロフィールは、見られない |

待つ間の要点は、「プロフィールを月に一度見直す」ことです。登録して放置すると、数も変化も古くなります。月に一度、本業の数を足せば、プロフィールは生きます。

### エラベルの見解

担当する側として登録した人の中で、最初の一件が早く決まるのは、「経路を一つか二つに絞り、範囲と時間を明確に書き、月に一度更新している」人です。五つに登録して放置した人より、一つに絞って更新している人のほうが、早く決まっています。

案件を探すことは、案件の数を見ることではなく、「自分の範囲と時間に合う案件が、自分を見つけられる状態にする」ことです。範囲と時間が明確なら、依頼側が探せます。曖昧なら、どの経路にいても見つかりません。

エラベルでは、範囲と時間を書いていただいた登録に、条件が合う案件のときだけご連絡しています。合わない案件の連絡は来ないので、探す時間と断る時間が減ります。

- 探す前に**一つの業務・経験の中身・時間・期間・相手の像・規定・単価の根拠**を決める。探す時間の何倍もかけて
- 見分けるのは**範囲・型・成果物・期間・判断・相手・本業との関係・単価**。「慎重に」は面談で確かめる

## よくある質問

### 登録先は、いくつに登録すればよいですか

一つか二つです。人事・採用に特化した登録先を一つと、必要なら知人の紹介の経路を用意する。それで足りることが多い。三つ以上に登録すると、プロフィールの更新と連絡の対応で時間が消え、どの登録先でも中身が薄くなります。一つに絞って、範囲と時間を明確に書き、月に一度更新するほうが、決まりやすくなります。決まらなければ、中身を見直してから、一つ足します。

### 知人に紹介を頼むのは、気が引けます

「副業を探している」と頼むと、知人は何を紹介すればよいか分からず、双方が気まずくなります。「〇〇（一つの業務）を、週〇時間で受けられるようになった。〇〇のような会社で困っているところがあれば、教えてほしい」と、範囲と時間と相手の像を一言で伝えれば、知人は「紹介する」ではなく「思い当たる会社を挙げる」だけで済み、気が引けません。紹介が決まったら、範囲と条件を書面にして、知人の関係に頼らない形にします。

### 本業で接点のある会社から声がかかりました。受けてよいですか

先に、本業の規定（副業の可否、競業の禁止、情報の持ち出し）と、利益相反（競合、候補者の重なり、情報の流れ）を確認します。接点のある会社は、本業の取引先や媒体の担当者であることが多く、本業との関係に影響します。規定と線の内側なら受けられますが、本業の上司に伝えるべきかも含めて、判断は専門家に確認してください。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、見分け方を書いています。
