「管理職向けの研修を設計してほしい」という依頼で、教えたい内容（マネジメントの基本、コミュニケーション、評価の仕方）を並べて一日の研修を組むと、受講者は「勉強になりました」と言い、翌週の行動は何も変わりません。内容から作った研修は、内容を渡すことはできても、行動を変えることはできません。結論を先に書くと、**研修の設計は、「受講者の翌週の行動を一つ決める」ことから逆算し、受講者のいまの状態・変わってほしい行動・行動に要る知識と練習・進行・翌週から一か月の確認の五つを組み、受講者の状態は上司への聞き取りと事前の確認で把握し、演習は受講者の実際の場面で行い、上司を研修の前と後に巻き込み、効果は満足度ではなく翌週の行動で見ます。**講師を案件として受ける形は[研修講師の副業の実務](/media/fukugyo-kensyu-koushi-shigoto/)に書いています。ここでは、設計の型に絞ります。

## 内容から作ると「聞いて終わり」になる

| 内容から作った研修 | 何が起きるか |
|---|---|
| 教えたいことを全部入れる | 一日が説明で埋まり、練習の時間が無い |
| 一般的な教材をそのまま | 受講者の実際の場面と離れ、「うちは違う」で終わる |
| 満足度のアンケートで評価 | 「分かりやすかった」と「行動が変わった」は別 |
| 上司が関わらない | 翌週、上司が研修の内容を知らず、行動が続かない |
| 一回で全部 | 一回で変わる行動は一つ。全部は無理 |

研修で変わるのは、「一つの行動」です。一つに絞り、その行動に要るものだけを教え、練習し、翌週に上司が見る。それで初めて、研修は行動になります。

## 出発点は「翌週の行動を一つ」

| 依頼の言葉 | 翌週の行動に置き換える |
|---|---|
| 「管理職のマネジメント力を上げたい」 | 「管理職が、部下との1on1で、自分が話すより問いを多くする」 |
| 「面接官の見る目を揃えたい」 | 「面接官が、評価シートの事実の欄を、候補者の言葉で書く」 |
| 「新人に報連相を教えたい」 | 「新人が、判断に迷ったときに、上司に『いま迷っています』と当日中に言う」 |
| 「評価者研修をしたい」 | 「評価者が、面談で本人に場面を先に話してもらう」 |

行動は、「誰が、どの場面で、何をする」の形で、翌週に上司が見て分かるものにします。決めるのは依頼側で、担当者は依頼の言葉を行動に置き換える案を出します。

### エラベルの見解

担当する側から見ると、研修の設計で最も差がつくのは、「変わってほしい行動を一つに絞る」を依頼側に通せるかです。受ける側は、依頼側の「せっかく集めるのだから」に応えて、内容を足します。足すほど、練習の時間が減り、受講者はどの行動を変えればよいか分からなくなります。「今回の研修で変わる行動は一つです。他は次回に」と、最初に線を引く。一つが変われば、依頼側は次の一つを頼みます。エラベルで担当者を選ぶ企業には、「その研修で、受講者の翌週の行動は何が変わりますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、設計の一枚の先頭に「翌週の行動」を一行で書き、内容の各項目が「その行動に要るか」で削ること。要らない項目は、次回の材料に回します。

## 逆算する五つ

| 決めること | 中身 | 出どころ |
|---|---|---|
| 受講者のいまの状態 | その行動を、いまどのくらいしているか。していない理由（知らない・やり方が分からない・機会が無い・やる意味が分からない） | 上司への聞き取り、事前の確認（受講者への短い問い） |
| 変わってほしい行動 | 一つ。「誰が、どの場面で、何をする」 | 依頼側と決める |
| 行動に要る知識と練習 | 知識は最小。練習は受講者の実際の場面で | 行動から逆算 |
| 進行 | 説明は短く、演習を長く。受講者が自分の場面で試し、互いに見る | 練習の設計 |
| 翌週から一か月の確認 | 上司が翌週に行動を見る。一か月後に「やったか」を一言 | 上司との合意 |

「していない理由」が「知らない」なら知識を、「やり方が分からない」なら練習を、「機会が無い」なら研修ではなく仕組みを、「やる意味が分からない」なら上司からの説明を、と手当てが変わります。研修で直せるのは前の二つで、後の二つは研修では直りません。

## 受講者の状態は上司と事前の確認で

| 手段 | 聞くこと |
|---|---|
| 上司への聞き取り | 「部下が、その行動をしている場面を見たことがあるか」「していない理由は何だと思うか」 |
| 受講者への事前の確認 | 「その場面で、いまどうしているか」を一問。答えは研修の演習の材料に |
| 過去の記録 | 評価シートや1on1の傾向があれば、その行動に関わる部分 |

受講者の状態を知らずに設計すると、知っていることを教えるか、できないことを飛ばすかになります。事前の確認は短く、一問か二問で足ります。受講者の答えは、研修の中で本人の場面として使い、記録には残しません。

## 演習は受講者の実際の場面で

| 一般的な演習 | 実際の場面の演習 |
|---|---|
| 架空の事例で議論 | 受講者が事前の確認で書いた「自分の場面」で試す |
| 講師が模範を見せる | 受講者同士で、一人が試し、一人が見て、一つ気づきを言う |
| 正解を教える | 型（問いの順、記録の欄）を渡し、型で試す |
| 全員で一つの事例 | 各自の場面。互いに見ることで、他の場面も学ぶ |

演習の時間が全体の半分以上を占める形にします。説明は、演習に要る型の説明だけです。型の作り方は、[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)や[1on1を設計する](/media/fukugyo-skill-1on1/)のように、「一枚で渡せる型」があれば、研修は型の練習の場になります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「研修の効果は、終了後のアンケートで測る」というものです。アンケートで分かるのは、受講者がその日に感じたことで、翌週の行動ではありません。「分かりやすかった」研修で行動が変わらないことも、「難しかった」研修で行動が変わることもあります。効果は、翌週に上司が「その行動をしたか」を見て、一か月後に「続いているか」を一言で受け取ることで見ます。受ける側がその場で使える判断としては、研修の設計の一枚に「翌週、上司が見ること」の行を置き、上司に研修の前に「翌週、この行動を見てください」と伝えること。上司が見ると分かっていれば、受講者も行動します。

## 上司を前と後に巻き込む

| 時期 | 上司にしてもらうこと |
|---|---|
| 研修の前 | 受講者に「なぜこの研修か」「翌週に何を見るか」を一言伝える |
| 研修の後（翌週） | その行動をした場面を一つ見て、本人に一言（良かった点） |
| 一か月後 | 「続いているか」を人事に一言 |

上司が関わらない研修は、翌週に「研修で何をやったの」で終わります。上司の負担は、前と後に一言ずつで足ります。上司への案内の一枚を、担当者が作ります。

## 既製の教材や外部の講座を使うとき

| 使い方 | 線 |
|---|---|
| 既製の教材 | 「翌週の行動」に要る部分だけを使う。全部を使わない |
| 外部の講座 | 講座の内容を「翌週の行動」に対応させ、前後の上司の関わりを担当者が設計する |
| 他社の研修の資料 | 写さない。構造の参考まで |
| 教材の費用 | 依頼側の判断。担当者は「行動に要るか」で選定の項目を並べるまで |

外部の講座や教材の内容と費用は変わるので、担当者が断定しません。既製のものを使う場合も、「翌週の行動」から逆算する設計は同じです。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が内容を足したがる | 「翌週の行動」を一つに。足す内容は次回に |
| 受講者の状態が分からない | 上司への聞き取りと、一問の事前の確認 |
| 演習が架空の事例 | 受講者の実際の場面に。事前の確認の答えを使う |
| 満足度で評価される | 翌週の行動を見る形を、研修の前に上司と合意 |
| 上司が関わらない | 前と後の一言の案内を作り、上司に渡す |
| 一回で全部を変えようとする | 一つずつ。三か月に一回、次の一つ |

## まとめ

- 内容から作ると**聞いて終わり**。出発点は**翌週の行動を一つ**
- 逆算する五つは**いまの状態・変わってほしい行動・要る知識と練習・進行・翌週からの確認**
- 「していない理由」で手当てが変わる。**研修で直せるのは「知らない」「やり方が分からない」**だけ
- 受講者の状態は**上司への聞き取りと一問の事前の確認**で
- 演習は**受講者の実際の場面**で、全体の半分以上。説明は型の説明だけ
- 効果は**満足度ではなく翌週の行動**。上司が見る形を研修の前に合意
- **上司を前と後に一言ずつ**巻き込む
- 既製の教材は「行動に要る部分」だけ。費用と内容は断定しない

## よくある質問

### 依頼側が「一日の研修」を前提にしています

一日で変わる行動は一つで、一つなら半日で足りることが多い。「半日で一つの行動を変え、三か月後に次の一つ」と提案します。一日にする場合は、午前に一つ、午後にもう一つ、と分け、それぞれに演習と翌週の確認を付けます。一日で五つの内容を詰めると、どれも行動になりません。時間の長さより、行動の数と演習の時間で設計します。

### 受講者が「忙しくて研修に出られない」と言います

出られない理由が「やる意味が分からない」なら、研修の前に上司から「なぜこの研修か」を伝えてもらいます。研修の時間を短くする（半日、二時間）ことも有効です。出席の判断は依頼側で、担当者は「短くしても行動は変えられる」設計を示します。出席を強いるより、出た人の翌週の行動が変わり、周りが「出てよかった」と聞く形のほうが、次の回の出席につながります。

### 研修の内容が、法令や制度に関わるもの（労務、ハラスメント防止など）です

法令や制度の内容を教える研修は、内容の正確さに専門家の確認が要ります。担当者は「翌週の行動」から逆算する設計と進行を担い、内容は専門家（社労士等）が監修するか、専門家が講師を務める形にします。担当者が法令の内容を断定して教えることはしません。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。
