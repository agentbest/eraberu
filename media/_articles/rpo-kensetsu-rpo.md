建設業界の会社が採用代行を検討するとき、動機は「施工管理が足りず、現場を受けられない」「職人が高齢になり、若い人が来ない」であることが多い。ただ、建設の採用は、他の業界と違う難しさがあります。施工管理・設計・技能職・事務で経路も要件も違い、資格が要件と配置に関わって法令上の整理があり、現場が動くと責任者が面接に出られず、勤務地が現場ごとに変わり、働き方の実態が定着を左右する。結論を先に書くと、**建設業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、資格と配置の要件の決定・技術と経験の見極め・現場の計画との照合・働き方と条件の判断は社内に残さないと、採れても現場に配置できません。**代行に出す前に、難しさを自社の状況で分解し、職種の型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[施工管理採用を代行に出す判断基準](/media/rpo-sekou-kanri-rpo/)や[建築設計採用を代行に出す判断基準](/media/rpo-kenchiku-sekkei-rpo/)に書いています。ここでは、建設業界で共通する切り分けに絞ります。

## 建設業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 職種の型で経路と要件が違う | 施工管理はスカウトと紹介、設計は紹介と学校、技能職は地域の経路と学校と知人、事務は掲載型 | 一つの代行で全部は回らない。型ごとに代行の型が要る |
| 資格が要件と配置に関わる | 資格の有無で配置できる現場と役割が変わり、法令上の整理がある | 要件に資格をどう置くかは会社と専門家が決める。代行は照合まで |
| 現場が動くと責任者が面接に出られない | 現場の責任者は日中は現場にいて、面接の枠が取れない | 枠の預かり方を変える必要（夕方、現場の近く、オンライン） |
| 勤務地が現場ごとに変わる | 現場の場所と期間で通勤や宿泊が変わる | 実態を先に出さないと、面接と入社後に辞退 |
| 働き方の実態が定着を左右 | 現場の時間、休日、天候、繁忙期 | 求人票に実態を書くかで、応募と定着が変わる |

五つのうち、代行で解決できるのは母集団形成と速さで、資格・見極め・計画・働き方の判断は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 現場の計画から採る数と時期を決める | 残す | 受注の見込みと現場の責任者が決める |
| 資格と配置の要件の決定 | 残す | 会社と専門家。法令上の整理がある |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の工事の〇〇の規模で、〇〇を担った経験」に。代行が整え、責任者が確認 |
| 母集団形成（型ごとの経路） | 任せられる | 施工管理はスカウトと紹介、技能職は地域の経路。型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 現場の責任者の負担を減らす。速さが要る |
| 書類の一次確認 | 一部任せられる | 「工事の型・規模・担った範囲・資格の有無」の照合は外で。深さは社内 |
| 技術と経験の見極め（面接） | 残す | 現場の責任者 |
| 働き方と勤務地の実態の説明 | 残す | 現場の責任者。見学があれば現場で |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 一覧と週次の一枚 |

「資格と配置の要件」は、建設に特有の残す工程で、法令上の整理があると一般に整理されているため、会社と専門家が決めます。代行は、資格の有無を書類で照合するまでです。個別の判断は専門家にご確認ください。

### エラベルの見解

建設業界で多くの会社が見落とすのは、「現場の責任者の面接の枠」の預かり方です。責任者は日中は現場にいて、事務所での面接の枠が取れない。代行が候補者を集めても、面接が数週間先になり、施工管理の経験者は他社で決まります。枠の預かり方を変えると回ります。「現場が終わった後の夕方の一枠」「現場の近くで」「オンラインで三十分」を、週に一つ先に決めておく。エラベルで担当者を選ぶ企業には、「現場の責任者の面接の枠は、どの時間帯に、どの形で取れていますか」を、私たちから先に聞いています。枠の形を変えれば、責任者の負担を増やさずに、日程の確定を即日にできます。枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種の型と経路 | 施工管理・設計・技能職・事務のどれを採るか。型ごとの経路 |
| 資格と配置の要件 | 資格をどう要件に置くか（必須か、入社後の取得の支援か）。法令上の整理は専門家に確認済みか |
| 現場の計画と採用の一枚 | 受注の見込みと、要る職種・人数・時期 |
| 現場の責任者の面接の枠 | 時間帯と形（夕方、現場の近く、オンライン）を週に一つ |
| 働き方と勤務地の実態 | 現場の時間、休日、天候、繁忙期、現場ごとの勤務地と宿泊を、求人票に書くか |
| 条件の幅 | 年収の幅と働き方を先に出せるか |
| 記録の形 | 一覧と記録が社内の環境にあるか |

「資格と配置の要件」は、採用の前に会社と専門家で整理しておきます。整理が無いまま募集すると、採った人を配置できないことが起きます。

## 職種の型ごとに代行の型が違う

| 職種の型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| 施工管理 | スカウトと紹介会社の母集団形成、一次対応 | 工事の型と規模と担った範囲の見極め。資格の扱い。[施工管理の採用要件の作り方](/media/rpo-sekou-kanri-youken/) |
| 設計 | 紹介と学校の経路、一次対応 | 設計の実績の見極め。[建築設計の採用要件の作り方](/media/rpo-kenchiku-sekkei-youken/) |
| 技能職（職人） | 地域の経路と学校と知人の経路の運用、一次対応 | 技能の見極めは現場で。育てる体制 |
| 事務 | 掲載型の母集団形成、一次対応 | 部門の責任者の見極め |
| 未経験・若手 | 学校と地域の経路、説明会の運用 | 育てる体制。資格の取得の支援 |

「建設業界の採用に強い代行」でも、施工管理と技能職の両方の型を持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種の型ごとの経路 | 「施工管理と職人で、経路と文面をどう変えますか」 |
| 資格の扱い | 「資格の有無を、書類でどう照合しますか。資格に関わる判断は社内と専門家で持ちます。その前提でどこまで任せられますか」 |
| 現場の責任者の枠の預かり方 | 「日中は現場にいる責任者の面接を、どう組みますか」 |
| 担当者の経歴 | 「担当する方は、建設業界のどの職種の型の採用を、どの工程で担った経験がありますか」 |
| 返事の速さと記録の置き場所 | 「候補者への返事は何営業日以内か。記録はどこに置くか」 |
| 費用の構造 | 「月額に含まれる工程と職種の型の数は」 |

費用は、含まれる工程と職種の型の数で変わり、金額の相場を先に聞くより「同じ工程・同じ型で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 施工管理の応募は来るが、工事の型と規模が合わない | 要件が「施工管理の経験〇年」のまま | 「〇〇の工事の〇〇の規模で、〇〇を担った経験」に |
| 採ったが、資格の関係で配置できない | 資格と配置の要件を整理せずに募集した | 会社と専門家で整理し、要件に置き直す |
| 面接が数週間先で辞退 | 責任者の枠が無い | 枠の形を変える（夕方、現場の近く、オンライン） |
| 面接で「現場の時間と休日は聞いていない」と辞退 | 実態を先に出していない | 求人票と初回の連絡に |
| 技能職が集まらない | 代行の得意な経路（スカウト）だけ回している | 地域の経路と学校と知人の経路を任せる工程に足す |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「要件の言葉」「資格の整理」「枠の形」「実態」「型ごとの経路」に戻ります。

### エラベルの見解

建設業界で技能職の採用は、「若い人が来ない」で止まっている会社が多い。来ないのは、経路が地域の掲載型だけで、学校と知人の経路（社員の紹介、協力会社のつながり）を使っておらず、求人票に「育てる体制」と「資格の取得の支援」と「働き方の実態」が無いからです。技能職の候補者（特に若手）は、「誰に教わり、何年で何ができるようになり、資格をどう取れるか」で動きます。エラベルは担当者を工程ごとに選べる形にしているので、「技能職の地域の経路と学校の経路の運用と一次対応」を担当者が担い、現場の責任者は「育てる体制と実態の説明」に絞る、という組み方ができます。育てる体制の考え方は[新卒採用の実務の進め方](/media/rpo-task-shinsotsu-unyou-susumekata/)に書いています。

## まとめ

- 建設業界の難しさは、**職種の型・資格と配置・現場の責任者の枠・現場ごとの勤務地・働き方の実態**の五つ
- **母集団形成・一次対応・日程・記録は任せられ、資格と配置の要件・見極め・計画との照合・働き方と条件は残す**
- **資格と配置の要件は会社と専門家**。法令上の整理がある。代行は照合まで。個別の判断は専門家にご確認ください
- 現場の責任者の枠は**形を変えて預かる**（夕方、現場の近く、オンライン）
- 職種の型（施工管理・設計・技能職・事務）ごとに**経路と代行の型が違う**
- 働き方と勤務地の実態を**先に出す**。応募は減り、辞退と離職が減る
- 技能職は**学校と知人の経路と、育てる体制と資格の支援**で

## よくある質問

### 施工管理の経験者が市場にいないと言われます

「施工管理の経験〇年」で探すと、対象が広すぎて逆に絞れません。「〇〇の工事（建築・土木・設備など）の〇〇の規模で、〇〇（工程・安全・品質・原価のどれか）を担った経験」に絞ると、スカウトと紹介会社の推薦が変わります。資格を必須にするか、入社後の取得の支援にするかは、配置に関わる法令上の整理と会社の判断で、専門家に確認します。経験者がいないなら、「担った範囲を広げたい人」を育てる形（要件を一段下げ、育てる体制を置く）もあります。

### 現場の責任者が「面接はできない。人事で決めてくれ」と言います

技術と経験の見極めは、責任者にしかできません。責任者の負担を減らすには、一次（書類の照合と一次対応）を外に出し、責任者の面接を「夕方の三十分、オンライン」で週に一枠にします。人事だけで決めた採用は、現場で「合わない」となり、責任者の負担が後で増えます。「三十分の面接」と「合わない人を教え直す時間」を比べれば、面接のほうが軽い、と伝えます。

### 資格の扱いを、どう要件に書けばよいか分かりません

資格の有無と配置の関係は、法令上の整理があると一般に整理されているので、会社と専門家（行政書士・社労士等）で整理してから要件に置きます。「必須の資格」「入社後に取得を支援する資格」「歓迎の資格」の三つに分け、求人票にもその区分で書きます。代行の担当者は、書類で資格の有無を照合するまでで、配置の可否や取得の見込みを判断しません。個別の判断は専門家にご確認ください。
