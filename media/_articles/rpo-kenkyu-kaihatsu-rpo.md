研究開発の採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、研究の中身を知らない人に研究者の採用が回せるのか」「研究者は求人媒体を見ていないのに、代行に出して意味があるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、研究開発の中身と分野とテーマの整理・テーマの自由度と成果の測り方の決定・学位の要否・要件の決定・研究の質の評価・合否の判断は社内に残す**のが線です。研究開発は、設計や生産技術と同じく「研究の分かる人」は社内にいます。足りないのは、採用の工程を回す人と、「何のテーマを、どこまで自由に、どう評価するか」を候補者に伝わる形で書く工程です。そこが代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、隣接する機械設計の線は[機械設計採用を代行に出す判断基準](/media/rpo-kikai-sekkei-rpo/)にまとめています。

## 研究開発採用が他の職種と違う点

一つ目は、「研究開発」の中身が会社によって全く違い、市場も違うことです。基礎研究（事業化まで遠い、論文や特許が成果）、応用研究（要素技術を製品に近づける）、新製品の開発（事業部門と一緒に製品にする）、既存製品の改良（性能、コスト、不具合）、要素技術の探索。基礎研究をしてきた人と、既存製品の改良をしてきた人は、持っているものと動く理由が違います。「研究開発募集」だけでは、どれを求めているかが候補者に伝わりません。

二つ目は、分野で経路も評価も全く違うことです。材料、化学、バイオ、電気、機械、ソフト、それぞれの中の細かい分野。分野が違えば、いる場所（大学の研究室、研究機関、大手の研究所、同分野のメーカー）も、成果の測り方（論文、特許、製品、性能）も違います。

三つ目は、候補者が「テーマの自由度」「研究環境」「事業化までの距離」「成果の測り方」「学位の扱い」を最初に確かめることです。研究者は、自分でテーマを決められるか、決められたテーマを担うか。設備と予算はどのくらいか。論文や学会での発表ができるか。事業化までどのくらい遠いか。成果は論文で測るのか、製品で測るのか。博士や修士の学位をどう扱うか（給与、役割、期待）。「研究開発業務全般」では、この判断ができません。

四つ目は、研究の質は社内で見られるが、採用の工程を回す人がいないことです。研究所長や開発部長が論文や発表を読み、面接で研究の考え方を聞くことはできます。しかし、求人票を書き、媒体を運用し、スカウトを送り、応募者に当日返信し、研究所長の面接の日程を確保する、という工程を回す人が、社内にいません。

五つ目は、大学や研究機関との接点が経路になることです。研究者は求人媒体をほとんど見ておらず、研究室のつながり、学会、共同研究、指導教員の紹介、研究機関の任期の区切りが、動く経路になります。この経路は、研究所長や研究者自身が持っていて、採用の担当者は持っていません。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 研究開発の中身（基礎・応用・開発・改良・要素技術）の整理 | 残す | 自社がどれを求めているか。社内にしか分からない |
| 分野とテーマの整理 | 残す | どの分野の、何のテーマか。守秘の範囲でどこまで書くか。研究所長が決める |
| テーマの自由度と成果の測り方の決定 | 残す | 自分でテーマを決められるか、論文と特許と製品のどれで評価するか、発表の可否。研究所長と経営者が決める |
| 学位の要否と扱いの決定 | 残す | 博士や修士を要件にするか、学位による給与と役割の違い。研究所長と経営者が決める |
| 要件の決定 | 残す | 中身・分野・テーマから。外部は整理を手伝える |
| 求人票の作成 | 任せられる（中身・分野・テーマと自由度が決まっていれば） | 決まったものを候補者に伝わる言葉にする。テーマを守秘の範囲で具体的に |
| 媒体の選定と運用 | 任せられる | 研究者に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる（研究所長が候補者の論文や発表を確認する工程を挟む） | 分野とテーマに合わせた検索と、候補者の研究に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、研究概要の提出の案内 |
| 研究所長・開発部長の面接の日程の確保 | 任せられる | 学会や実験の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 中身・分野・テーマ・学位の分類は任せられる。研究の質の評価は残す |
| 研究の質と考え方の評価 | 残す | 研究所長が論文や発表を読み、面接で聞く |
| テーマの自由度と環境と評価の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断。学位と経路で条件の幅が広い |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。学位の取得や任期の区切りに合わせた入社日の調整 |

線の要点は、「研究開発の中身・分野・テーマと、テーマの自由度と成果の測り方が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の研究が活きるか」「研究者として扱われるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「研究開発を募集しているが、応募が来ない。来ても、自社と違う分野の人か、研究の経験の無い人」というご相談です。求人票を見ると、「研究開発募集。新製品の研究開発業務全般。修士以上歓迎」と書かれていて、基礎か応用か開発か、何の分野の何のテーマか、テーマを自分で決められるか、成果をどう測るか、発表できるかが無い。研究者はこれを読んで、「何を研究する会社か分からない」「研究者として扱われるか分からない」と判断し、応募しません。

見ていて差がつくのは、「何のテーマを、どこまで自由に、どう評価するかを一文で言えるか」です。「当社は〇〇材料の応用研究で、採る人には、〇〇の要素技術を三年で製品に近づけるテーマを担ってほしい。テーマの方向は会社が決めるが、手法は研究者が決める。成果は特許と製品への搭載で測り、論文と学会発表は守秘の範囲で認める。設備は〇〇があり、予算は研究者が提案して所長が決める」。一文で中身・分野・テーマ・自由度・評価・環境が分かれば、基礎研究を続けたい人は自分向けでないと分かり、要素技術を製品に近づけたい人は自分向けだと分かります。エラベルでは、研究開発の案件をお受けする前に、依頼側に「中身・分野・テーマ」と「テーマの自由度と成果の測り方」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：研究開発の中身・分野・テーマ。** 基礎か応用か開発か改良か要素技術か。どの分野の、何のテーマか。守秘の範囲で、テーマをどこまで求人票に書けるか。採る人に任せるテーマの範囲と、事業化までの距離。

**二つ目：テーマの自由度と成果の測り方。** テーマを研究者が決められるか、方向は会社が決めて手法は研究者か、全部決まっているか。成果を論文で測るのか、特許か、製品への搭載か、性能の達成か。論文と学会発表を認めるか、守秘の範囲はどこか。

**三つ目：研究環境と学位の扱い。** 設備、予算の決め方、共同研究の有無、大学や研究機関との関係。博士や修士を要件にするか、学位による給与と役割の違いをどうするか。博士を採るなら、博士に何を期待するか（テーマの提案か、専門の深さか）。

**四つ目：いまの研究開発の状態と実態。** 誰が何のテーマを担当していて、何が止まっているか。研究所長が全部を見ていて回らない、事業部門との距離、繁忙期（学会前、製品化の締切前）の実態、休日の形、出張（学会、共同研究先、顧客先）の頻度。正直に把握し、「どこまで書くか」を決めます。

**五つ目：研究所長や開発部長が、面接にどのくらい時間を出せるか。** 学会や実験の中で、面接の枠と研究室の見学の時間をどう確保するか。候補者の論文や発表を事前に読む時間を取れるか。

五つのうち、一つ目と二つ目が代行に出す前提です。三つ目以降は、代行と一緒に整理できます。

## 研究所長の関与のさせ方

研究開発の採用では、研究所長や開発部長の関与が要ります。候補者の論文や発表を読む、面接で研究の考え方を聞く、テーマの自由度と環境と評価を正直に話す、研究室を見せる。そして、大学や研究機関との接点を経路として使う。しかし研究所長は自分の研究と学会を抱えていて、「採用は人事の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると研究所長がどう楽になるか」を具体的に示すことです。「この人が入れば、所長が抱えている〇〇のテーマを渡せる」。そして、負担を最小にする形で頼みます。面接の枠は代行が学会の合間に押さえる、論文と経歴は代行が整理して渡す、自由度と環境の説明の要点は代行が用意する。研究所長がやるのは、論文を読んで研究の考え方を聞くことと、実態を正直に話すことと、研究室のつながりで声をかけることだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で研究所長が「研究の話」をすることの価値を、研究所長自身に理解してもらうことです。研究者は、面接で研究の話が通じるかを見ています。人事だけの面接では、候補者は「研究を分かっている会社か」を判断できず、辞退します。研究所長が「このテーマで一番難しいのはここで、こう考えている。いま困っているのはこの部分」と話すと、候補者は「研究者として扱われる会社」と判断します。

## 代行を選ぶときの確認項目

研究開発の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に研究開発や技術部門の経験があるか。** 研究そのものでなくても、メーカーの研究所や技術部門、研究者や技術者の採用を回した経験。基礎と応用と開発の違い、分野による経路の違い、学位の扱いを知っているか
- **中身・分野・テーマと自由度を求人票にどう書くか、案を出せるか。** 「研究開発業務全般」で済まさず、テーマと自由度と評価を守秘の範囲で書けるか
- **研究者に届く媒体と経路の経験。** 研究者向けの媒体、スカウト、大学や研究機関との接点（研究室、学会、指導教員）、博士やポスドクの任期の区切り。経路ごとの経験
- **論文や発表を読む工程の段取り。** スカウトの前に研究所長が候補者の論文を確認する工程を組めるか。候補者の研究概要を受け取る段取り
- **研究所長の日程を押さえる段取り。** 学会や実験の合間に面接の枠を確保する方法

五つのうち、一つ目と三つ目が大きい。研究開発を知らない担当者は、基礎と開発を区別せずに求人票を作り、研究者のいない媒体に出して、「研究を分かっていない会社」と読まれます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、研究開発の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「テーマの自由度と成果の測り方が決まっていない」と指摘されることです。代行が求人票を作ろうとして、「テーマは研究者が決められますか。成果は論文ですか製品ですか。発表はできますか」と聞かれ、答えられない。これは代行に出したから起きる問題ではなく、出す前から決まっていなかったものが表に出ただけです。ここで自由度と評価を決めます。

二つ目は、応募者の経路と中身と学位が分かれることです。大学のポスドクや博士課程の修了者、研究機関の任期付き研究者、大手メーカーの研究所、同分野のメーカーの開発部門、修士で開発をしてきた人。それぞれ持っているものと動く理由が違い、任せるテーマと合うかも違います。代行の担当者に分類をしてもらい、研究所長が論文を読む対象を絞ります。

三つ目は、「事業化までの距離」と「成果の測り方」で候補者が判断を変えることです。基礎研究をしてきた人は、製品への搭載で評価されることに慣れておらず、開発をしてきた人は、論文で評価されることに慣れていません。面接で研究所長が、事業化までの距離と評価の実態を正直に話すことで、候補者の判断が変わります。隠して入社後に分かると、離職の原因になります。

### エラベルの見解

担当する側から見ると、研究開発の採用で最も効くのは、「何のテーマを、どこまで自由に、どう評価するか」を求人票に書くことです。研究者は、テーマで自分の研究が活きるかを判断し、自由度と評価で「研究者として扱われるか」を判断します。「研究開発業務全般」と「修士以上歓迎」だけの求人票は、どの中身の研究者にも「何を研究する会社か分からない」で閉じられます。

エラベルでは、研究開発の案件で担当者を紹介するとき、最初の一週間で研究所長から「中身・分野・テーマ」「テーマの自由度と成果の測り方」「研究環境と学位の扱い」「実態」を聞き取り、守秘の範囲で一文にするところから始めてもらっています。研究の質の評価は研究所長が論文と面接で行い、大学や研究機関との接点を経路として使う段取りを担当者が組みます。

## まとめ

- 研究開発採用が他と違うのは**中身（基礎・応用・開発・改良・要素技術）で市場が分かれる・分野で経路も評価も全く違う・候補者が「自由度」「環境」「事業化までの距離」「評価」「学位の扱い」を最初に確かめる・研究の分かる人はいるが採用の工程を回す人がいない・大学や研究機関との接点が経路**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、中身と分野とテーマ・自由度と評価・学位の要否・要件・研究の質の評価・合否は残す**
- 代行に出す前に**中身・分野・テーマ、自由度と成果の測り方、研究環境と学位の扱い、いまの状態と実態、研究所長の面接の時間**を確認する
- 研究所長の関与は**採用でどう楽になるかを示し、負担を最小にして、研究の話をする価値と研究室のつながりを経路にする価値を理解してもらう**
- 代行を選ぶときは**研究開発の経験・テーマと自由度の書き方・研究者に届く経路・論文を読む工程の段取り・日程の段取り**を確認する
- 出したあとは**自由度と評価が決まっていないことが表に出る・経路と中身と学位が分かれる・事業化までの距離と評価で判断が変わる**。判断は研究所長と経営者、材料は代行

## よくある質問

### テーマを研究者に自由に決めさせる余裕がありません。書くと来ませんか

隠して面接や入社後に分かるほうが、辞退と離職を生みます。「テーマの方向は会社が決め、手法と進め方は研究者が決める。三年で製品に近づける目標がある」と正直に書きます。自由度が小さいこと自体より、「自由に研究できる」と書いて実態が違うことを、研究者は嫌います。基礎研究を続けたい人は見送りますが、要素技術を製品に近づけたい人は、方向が決まっていることをむしろ好みます。自由度を広げる予定があるなら、「段階的に」と添えます。

### 博士を必須にすべきですか

任せるテーマと、博士に何を期待するかによります。テーマの提案と専門の深さを期待し、大学や研究機関との共同研究の窓口を担ってもらうなら、博士が合います。決まったテーマを製品に近づける開発なら、修士で開発をしてきた人のほうが合うことがあります。「あったほうが安心」で博士を必須にすると、母集団が大きく減り、博士を採っても期待と役割がずれれば離れます。博士を採るなら、学位による給与と役割の違いを決め、求人票に書きます。

### 研究者は求人媒体を見ていません。どこに出せばよいですか

研究者向けの媒体に出した上で、研究所長のつながり（研究室、学会、共同研究先、指導教員）を経路にします。博士やポスドクは任期の区切りで動くので、その時期に指導教員経由で声をかける。学会で会社の研究を発表し、興味を持った人に声をかける。共同研究先の研究者に、区切りの時期を聞いておく。この経路は研究所長しか持っておらず、代行は「いつ、誰に、何を伝えるか」の段取りと、声をかけた後の対応を担います。
