建築設計の採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、設計を知らない人に設計者の採用が回せるのか」「作品を見ないと判断できないのに、外の人に何ができるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、分野と用途と段階の整理・任せる範囲・作品の扱い・労働時間の実態の開示・資格の要否・要件の決定・設計の質の評価・合否の判断は社内に残す**のが線です。建築設計は、施工管理と同じく「設計の分かる人」は社内にいます。足りないのは、採用の工程を回す人と、「どんな建物を、どこまで任せるか」を候補者に伝わる形で書く工程です。そこが代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じ建設業の施工管理の線は[施工管理採用を代行に出す判断基準](/media/rpo-sekou-kanri-rpo/)にまとめています。

## 建築設計採用が他の職種と違う点

一つ目は、分野と用途と段階で市場が分かれることです。分野は意匠・構造・設備。用途は住宅・非住宅（事務所、工場、商業、医療、教育、公共）。段階は基本設計・実施設計・確認申請・監理。意匠の住宅を担ってきた人と、構造の非住宅を担ってきた人は、市場がまったく違います。「建築設計募集」だけでは、どれを求めているかが候補者に伝わりません。

二つ目は、候補者が「どんな建物を、どこまで任されるか」を最初に確かめることです。設計者は、担当する建物の用途と規模、担当する段階（基本設計から関われるか、実施設計の図面だけか）、自分の名前で担当できるか、を見ます。「設計業務全般」では、この判断ができません。

三つ目は、作品が判断材料になることです。候補者はポートフォリオで自分を示し、会社側は作品で設計の質を見ます。同時に候補者は、会社の作品を見て「この会社の設計に加わりたいか」を判断します。会社の作品と設計の考え方を示さない求人は、設計者に読まれません。

四つ目は、設計の質は社内で見られるが、採用の工程を回す人がいないことです。設計部長や所長が作品を見て面接で設計の考え方を聞くことはできます。しかし、求人票を書き、媒体を運用し、スカウトを送り、応募者に当日返信し、設計部長の面接の日程を確保する、という工程を回す人が、社内にいません。

五つ目は、資格の要否が事務所の登録や配置と結びつくことです。一級・二級建築士の資格は、設計できる建物の規模や用途、事務所の登録や管理建築士の配置に関わります。資格を必須にするか、入社後の取得を前提にするかは、自社でどう配置するかで決まります。法令上の要件は、行政書士など専門家にご確認ください。

もう一つ、設計事務所には「労働時間が長い」という印象があり、候補者は実態を確かめます。繁忙期、締切前の実態、休日の形。ここを正直に書かないと、面接で辞退されます。

この点から、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 分野・用途・段階の整理 | 残す | 自社がどの分野と用途を手がけ、採る人にどの段階を任せるか。社内にしか分からない |
| 任せる範囲の決定 | 残す | 基本設計から任せるか、実施設計からか。自分の名前で担当できるか。設計部長が決める |
| 作品の扱いの決定 | 残す | 会社の作品をどこまで見せるか、候補者の作品をどう見るか、守秘の扱い |
| 労働時間の実態の開示範囲 | 残す | 繁忙期、締切前、休日の形を、どこまで正直に書くか |
| 資格の要否の決定 | 残す | 事務所の登録と配置から。専門家に確認 |
| 要件の決定 | 残す | 分野・用途・段階・資格から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（分野・用途・段階と任せる範囲が決まっていれば） | 決まったものを候補者に伝わる言葉にする。会社の作品と設計の考え方を載せる |
| 媒体の選定と運用 | 任せられる | 建築設計に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 分野・用途・段階に合わせた検索と、候補者の作品に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、作品の提出の案内 |
| 設計部長・所長の面接の日程の確保 | 任せられる | 締切の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 分野・用途・段階・資格の分類は任せられる。作品の質の評価は残す |
| 作品と設計の考え方の評価 | 残す | 設計部長や所長が見る |
| 労働時間の実態と任せる範囲の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断 |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。担当中の案件の区切りに合わせた入社日の調整 |

線の要点は、「分野・用途・段階と、任せる範囲が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分がやりたい設計か」を判断する材料になります。

### エラベルの見解

相談で多いのは、「設計者を募集しているが、応募が来ない。来ても、自社の用途と違う経験の人か、図面を描くだけの人」というご相談です。求人票を見ると、「建築設計募集。意匠設計業務全般。一級建築士歓迎。経験者優遇」と書かれていて、用途も段階も任せる範囲も、会社の作品も無い。設計者はこれを読んで、「どんな建物か分からない」「図面を描かされるだけかもしれない」と判断し、応募しません。

見ていて差がつくのは、「どんな建物を、どこまで任せるかを一文で言えるか」です。「当社は非住宅の意匠設計が中心で、事務所と医療施設が多い。採る人には、基本設計から関わり、実施設計と監理まで自分の名前で担当してほしい。直近の作品はこの三つ」。一文で用途と段階と任せる範囲が分かり、作品が見えれば、住宅の人は自分向けでないと分かり、非住宅を基本設計から担いたい人は自分向けだと分かります。エラベルでは、建築設計の案件をお受けする前に、依頼側に「分野・用途・段階」と「任せる範囲」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：分野・用途・段階。** 意匠か構造か設備か。住宅か非住宅か、非住宅ならどの用途か。採る人に任せる段階は、基本設計からか、実施設計からか、申請や監理も含むか。

**二つ目：任せる範囲。** 自分の名前で担当できるか、所長や設計部長の下で図面を担うか。担当する案件の規模と数。将来、どこまで広げるか。

**三つ目：作品の扱い。** 会社の作品を求人票やスカウトでどこまで見せるか（公開されているものか、守秘のあるものか）。候補者の作品をいつ、誰が、どう見るか。候補者の作品の守秘をどう扱うか。

**四つ目：労働時間の実態。** 繁忙期、締切前、休日の形、在宅の可否。実態を設計部長と確認し、「どこまで書くか」を決めます。書けない項目があるなら、それは候補者が面接で聞く項目で、面接で辞退される項目です。

**五つ目：資格の要否。** 事務所の登録と配置で、法令上どの資格が要るか。採る人がその配置を担うなら必須、担わないなら入社後の取得を前提にできるか。専門家に確認します。

五つのうち、一つ目と二つ目が代行に出す前提です。三つ目以降は、代行と一緒に整理できます。

## 設計の分かる人の関与のさせ方

建築設計の採用では、設計部長や所長の関与が要ります。作品を見る、面接で設計の考え方を聞く、任せる範囲と労働時間の実態を正直に話す。しかし設計部長は締切を抱えていて、「採用は総務の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると設計部長がどう楽になるか」を具体的に示すことです。「この人が入れば、部長が抱えている実施設計を一つ渡せる」。そして、負担を最小にする形で頼みます。面接の枠は代行が締切の合間に押さえる、作品は代行が整理して渡す、任せる範囲の説明の要点は代行が用意する。設計部長がやるのは、作品を見て設計の考え方を聞くことと、実態を正直に話すことだけにします。現場の協力の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で設計部長が「会社の設計の考え方」を話すことの価値を、設計部長自身に理解してもらうことです。候補者は経営者の話より、設計部長の話を信じます。設計部長が「うちはこう考えて設計している。締切前は正直厳しい。ただ、基本設計から任せる」と話すと、候補者は「設計者として扱われる会社」と判断します。これは代行にはできない工程です。

## 代行を選ぶときの確認項目

建築設計の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に建築や設計事務所の経験があるか。** 設計そのものでなくても、設計事務所や建設会社の管理部門、建築業界の採用を回した経験。分野・用途・段階の違いと、作品の扱いを知っているか
- **任せる範囲と労働時間の実態を求人票にどう書くか、案を出せるか。** 「設計業務全般」で済まさず、用途と段階と任せる範囲を書けるか
- **建築設計に届く媒体と経路の経験。** 建築に強い媒体、スカウト、設計者のコミュニティ、大学や専門学校とのつながり。経路ごとの経験
- **作品の扱いの段取り。** 候補者の作品をいつ、どう受け取り、誰に渡し、守秘をどう扱うか
- **設計部長の日程を押さえる段取り。** 締切の合間に面接の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。建築を知らない担当者は、「設計業務全般」の求人票を作り、作品の扱いを雑にして、設計者に「設計を分かっていない会社」と読まれます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、建築設計の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「会社の作品と設計の考え方を見せないと届かない」と言われることです。求人票に作品が無く、設計の考え方も無いと、設計者は「どんな会社か分からない」で閉じます。公開できる作品を選び、設計の考え方を設計部長が一文にする。これは代行に出したから起きる問題ではなく、出す前から無かったものが表に出ただけです。

二つ目は、応募者の経路と経歴が分かれることです。組織設計事務所出身、アトリエ系の設計事務所出身、ゼネコンの設計部出身、ハウスメーカー出身、施工側から設計へ。それぞれ持っているものが違い、任せる段階と合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることを変えます。

三つ目は、任せる範囲と労働時間の実態で、候補者が判断を変えることです。「基本設計から任せる」と書いて、面接で「最初は実施設計から」と言えば辞退されます。「締切前は厳しい」を隠して、面接で分かれば辞退されます。求人票に書いたことと面接で言うことを、設計部長と代行で合わせておきます。

### エラベルの見解

担当する側から見ると、建築設計の採用で最も効くのは、「どんな建物を、どこまで任せるか」と「会社の作品と設計の考え方」を求人票に載せることです。設計者は、この二つで「自分がやりたい設計か」「この会社の設計に加わりたいか」を判断します。「設計業務全般」と「経験者優遇」だけの求人票は、設計者に読まれません。

エラベルでは、建築設計の案件で担当者を紹介するとき、最初の一週間で設計部長から「分野・用途・段階」「任せる範囲」「設計の考え方」を聞き取り、公開できる作品を選ぶところから始めてもらっています。作品と設計の質の評価は設計部長や所長が行い、資格の配置に関わる法令上の要件は、専門家にご確認いただくようお伝えしています。

## まとめ

- 建築設計採用が他と違うのは**分野・用途・段階で市場が分かれる・候補者が「どんな建物を、どこまで任されるか」を最初に確かめる・作品が判断材料・設計の分かる人はいるが採用の工程を回す人がいない・資格が登録と配置に結びつく・労働時間の実態を確かめられる**
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、分野と用途と段階・任せる範囲・作品の扱い・実態の開示・資格の要否・要件・設計の質の評価・合否は残す**
- 代行に出す前に**分野・用途・段階、任せる範囲、作品の扱い、労働時間の実態、資格の要否**を確認する
- 設計部長の関与は**採用でどう楽になるかを示し、負担を最小にして、設計の考え方を話す価値を理解してもらう**
- 代行を選ぶときは**建築の経験・任せる範囲の書き方・経路の経験・作品の扱い・日程の段取り**を確認する
- 出したあとは**作品と考え方を見せる必要が表に出る・経路と経歴が分かれる・任せる範囲と実態で判断が変わる**。判断は設計部長と経営者、材料は代行

## よくある質問

### 会社の作品を求人票に載せてよいのですか

公開されている作品（竣工して発表済み、施主の了解があるもの）を選んで載せます。守秘のある案件や施主の了解が無いものは載せません。載せる作品が無い場合は、「設計の考え方」を設計部長が一文にして載せ、作品は面接で見せる形にします。設計者は作品を見て会社を判断するので、何も見せない求人票は読まれません。載せる範囲の判断は、施主との契約と守秘の扱いを確かめてからです。

### 一級建築士を必須にすべきですか

事務所の登録や配置で法令上要るか、採る人がその配置を担うかによります。担うなら必須、別の人が担っていて採る人は設計を担う役なら、資格が無くても配置でき、「入社後取得を支援」で母集団を広げられます。「あったほうが安心」で必須にすると、二級で非住宅の実施設計を担ってきた人や、取得前の若手が外れます。登録と配置に関わる法令上の要件は、行政書士など専門家にご確認ください。

### 候補者の作品はどう受け取ればよいですか

一次対応の段階で「作品（ポートフォリオ）を見せていただけますか」と案内し、受け取り方（データか印刷か、守秘の扱い）を明示します。候補者の作品には、前職の守秘がかかっているものがあり、候補者が見せられる範囲で出してもらいます。受け取った作品は設計部長だけが見て、面接後に返すか削除するかを伝えます。作品の扱いが雑な会社は、設計者に「設計を分かっていない」と読まれます。この段取りは代行に出せます。
