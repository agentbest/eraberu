登録先のプロフィールに写真の欄がある。SNSのアイコンをどうするか、名刺に写真を入れるか、発信で顔を出すかで迷う。本業の同僚に見つかりたくないが、顔が無いと依頼側に警戒されそうにも感じる。結論を先に書くと、**人事の副業で顔写真は、無くても案件は決まります。依頼側が見ているのは経歴と担当できる範囲で、顔写真は判断の材料に入っていません。出すかどうかは、名前を実名にするかとは別に決めてよく、出さないなら、依頼側との面談で顔が合うことだけ整えておけば足ります。**出すなら、登録先・発信・名刺で同じ一枚を使い、本業の会社の写真は使いません。名前の判断は[実名で発信するか](/media/fukugyo-honmyou-hasshin/)と[本名を出さずに受けられるか](/media/fukugyo-honmyo/)に、プロフィール全体の書き方は[プロフィールの書き方](/media/fukugyo-profile/)にまとめています。

## 顔写真は案件の決まり方に効くか

依頼側が担当者を選ぶときに見ている順番を確認すると、顔写真の位置が分かります。

| 依頼側が見る順 | 見るもの | 顔写真の関わり |
|---|---|---|
| 一 | 担当できる業務の範囲 | 関わらない |
| 二 | 経歴（規模・業界・立場・決めていた範囲） | 関わらない |
| 三 | 稼働の条件（時間、時間帯、リモートか対面か） | 関わらない |
| 四 | 面談での受け答え | ここで顔が合う。写真は面談の前の確認程度 |
| 五 | 実績の示し方 | 関わらない |

順番の要点は、顔写真が判断の材料になる場面が無いことです。依頼側の担当者は、範囲と経歴で候補を絞り、面談で決めます。面談はオンラインでも対面でも顔が合うので、写真が無くても「どんな人か」は面談で分かります。写真があることで面談の前に安心する依頼側はいますが、写真が無いことで候補から外す依頼側は、ほとんどいません。範囲と経歴の整え方は[受ける範囲の決め方](/media/fukugyo-scope/)と[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に書いています。

## 出すことで変わること

顔を出すと、案件の決まり方は変わりませんが、別のことが変わります。出すかどうかは、この変わることを受け入れられるかで決めます。

| 変わること | 内容 |
|---|---|
| 本業の関係者に見つかりやすくなる | 名前を仮名にしていても、顔で分かる。本業に伝えていない場合は、経路が増える |
| 候補者に見つかることがある | 依頼側の採用で接した候補者が、後で発信を見て、副業の担当者だったと分かる |
| 発信と登録先と名刺が一枚でつながる | 依頼側が発信を見て登録先に辿り着いたとき、同じ人だと分かりやすい |
| 面談の前に依頼側が安心する | 「どんな人か」の不安が面談前に減る。効く場面は限られる |
| 写真を撮り直す手間が続く | 年数が経つと写真と実物が離れる。数年に一度は撮り直す |
| 後から消しにくい | 出した写真は保存されることがあり、出すのをやめても完全には消えない |

変わることの要点は、「本業と候補者に見つかりやすくなる」ことです。名前を仮名にしていても、顔を出せば仮名の意味が薄れます。本業に副業を伝えていない場合や、候補者との接点が多い工程を担当している場合は、顔を出さないほうが、名前の判断と整合します。本業に伝える形は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)を見たうえで、規定の解釈は専門家にご確認ください。

### エラベルの見解

相談で最も多い思い込みは、「顔写真が無いと、依頼側に隠しごとがあるように見える」というものです。実際には、依頼側の担当者が写真の有無を気にした例は、見ている限りほとんどありません。依頼側が気にするのは、面談で話したときに、経歴に書いてあることと話す内容が合っているかです。写真があっても、経歴と話が合わなければ選ばれず、写真が無くても、合っていれば選ばれます。

一方で、副業の担当者側は、写真を出すかどうかで長く迷い、その間にプロフィールの範囲の欄が空いたままになっていることがあります。写真は後からいつでも足せますが、範囲の欄が空いていると、依頼側はその人を候補に入れられません。順番として、範囲と経歴を先に埋め、写真は出すと決めたときに足す。エラベルでは、登録の際に顔写真を必須にしておらず、依頼側への提示も経歴と範囲で行っています。写真が無い担当者が選ばれている例は珍しくありません。

## 出さないときに整えておくこと

顔を出さないと決めたら、その分、依頼側と窓口が迷わないように整えておくことがあります。

| 整えること | 内容 |
|---|---|
| 面談では顔を出す | 登録先や発信で顔を出さなくても、依頼側との面談はカメラをつける。ここで顔を出さないと、依頼側は判断できない |
| アイコンを一つに決める | 発信と登録先のアイコンを、写真の代わりに同じ図柄にする。場ごとに違うと、同じ人だと分かりにくい |
| 経歴と範囲を写真の分だけ具体に書く | 写真で補えない「どんな人か」を、経歴の書き方で補う。決めていた範囲、進め方の考え方を書く |
| 名刺は写真無しの形にする | 名刺に写真を入れないのは一般的で、無いことで困ることはない。[名刺をどうするか](/media/fukugyo-meishi/) |
| 対面の場面で困らない準備 | 依頼側の社内の人に紹介される場面や、候補者との面談に同席する場面は、顔が出る。それは前提として受け入れる。[対面が必要になる場面](/media/fukugyo-taimen/) |

整えることの要点は、「面談では顔を出す」ことです。公開の場で顔を出さないことと、依頼側との面談で顔を出さないことは別で、後者は依頼側が判断できなくなります。面談でカメラをつけない担当者は、依頼側から見て「どんな人か分からない」まま契約することになり、選ばれにくくなります。面談の進め方は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に書いています。

## 名前と顔を別に決める理由

名前を実名にするか仮名にするかと、顔を出すかどうかは、一緒に決めがちですが、別に決めたほうが選択肢が広がります。

| 組み合わせ | どういう状態か | 向く人 |
|---|---|---|
| 実名・顔あり | 発信、登録先、名刺がすべて本人と結びつく | 本業に伝えていて、独立の見込みがあり、発信を実績として残したい |
| 実名・顔なし | 名前で辿れるが、顔では見つからない | 本業に伝えているが、候補者との接点が多い工程を担当している |
| 仮名・顔あり | 名前では辿れないが、顔で分かる | 少ない。仮名の意味が薄れるので、ほとんど選ばれない |
| 仮名・顔なし | 名前でも顔でも辿れない。内容で判断される | 本業に伝えていない。まず内容で発信したい |

別に決める要点は、「仮名・顔あり」を避けることです。名前を分けても顔で分かるので、仮名にした理由が消えます。仮名なら顔も出さず、実名なら顔は状況で決める、という組み合わせにすると、整合します。仮名から実名への切り替えと同じで、顔も「出さない」から「出す」へは後から変えられますが、逆は難しいので、迷うなら出さないところから始めます。

## 出すなら、どんな写真か

出すと決めたら、写真は一枚に決めて、どこでも同じものを使います。

| 決めること | 内容 |
|---|---|
| 一枚に決める | 登録先、発信、名刺、経歴のページで同じ写真にする。場ごとに違う写真だと、同じ人だと分かりにくい |
| 本業の会社の写真を使わない | 本業の会社が撮った社員紹介の写真、本業の名刺の写真は使わない。本業の情報の持ち出しになる |
| 背景に本業と依頼側の情報を入れない | オフィスの背景、会社のロゴ、依頼側の場所が写らないようにする |
| 実物と離れすぎない | 面談で「写真と違う」と思われると、経歴も疑われる。数年に一度は撮り直す |
| 服装は面談と同じにする | 面談のときの服装と写真の服装が揃っていると、依頼側の印象が一致する |
| 候補者に見られる前提で選ぶ | 候補者との面談に同席する場合、候補者は後で発信を見ることがある。採用の場にふさわしい写真にする |

写真の要点は、「本業の会社の写真を使わない」ことです。本業で撮った写真は、本業の会社が用意したもので、副業の場で使うと、本業の名刺を使うのと同じ問題になります。撮り直すなら、自分で用意した場所と服装で撮ります。撮影の費用は副業の経費になるかどうかを含め、[経費にできるもの](/media/fukugyo-keihi/)を見たうえで、判断は専門家にご確認ください。

### エラベルの見解

担当する側から見ると、顔を出すかどうかで案件が変わった例は見当たりませんが、出し方が揃っていないことで依頼側が迷った例はあります。発信のアイコンと登録先の写真と名刺の写真がすべて違うと、依頼側は「同じ人か」を確認する手間が増えます。出すなら一枚に揃え、出さないなら全部出さない。どちらかに揃っていれば、依頼側は迷いません。

順番として、顔を出すかを決める前に、名前を実名にするか仮名にするかを決め、仮名なら顔も出さない、実名なら本業と候補者との関係で決める。この順番で決めると、名前と顔の組み合わせが整合し、後から直すことが減ります。エラベルでは、登録の際の写真の有無を依頼側への提示の条件にしていません。写真を出すか迷って登録を止めるより、範囲と経歴を先に整えて登録し、写真は決まってから足すことをお願いしています。

## まとめ

- 顔写真は**無くても案件は決まる**。依頼側が見るのは範囲・経歴・条件・面談で、写真は判断の材料に入らない
- 出すと変わるのは**本業と候補者に見つかりやすくなる・場がつながる・面談前の安心・撮り直しの手間・後から消しにくい**
- 出さないなら**面談では顔を出す・アイコンを一つに・経歴を具体に・名刺は写真無し・対面の場面は前提として受け入れる**
- 名前と顔は**別に決める**。仮名なら顔も出さず、実名なら状況で決める。「仮名・顔あり」は仮名の意味が薄れる
- 出すなら**一枚に決める・本業の写真を使わない・背景に情報を入れない・実物と離れない・面談と同じ服装・候補者に見られる前提**
- 出し方が**揃っていないこと**が依頼側を迷わせる。出すなら全部、出さないなら全部

## よくある質問

### 登録先のプロフィールの写真の欄が空だと、依頼側に選ばれにくくなりますか

見ている限り、写真の有無で選ばれ方が変わった例はほとんどありません。依頼側が候補を絞るのは、担当できる範囲と経歴です。写真の欄が空でも、範囲と経歴が具体に書かれていれば候補に入ります。逆に、写真があっても範囲の欄が「採用全般」のように曖昧だと、候補に入りません。空欄を埋めるなら、写真より範囲の欄を先に埋めてください。

### 候補者との面談に同席するとき、顔を出さない選択はできますか

面談に同席する以上、候補者には顔が見えます。オンラインでカメラを切ることは、候補者から見て不自然で、依頼側の採用の印象を下げるので、同席するなら顔は出す前提です。候補者に顔を見せたくない場合は、同席する工程を受けないという範囲の決め方になります。候補者との接し方は[候補者への対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に整理しています。

### 過去に発信で顔を出していて、今は出したくありません

今後の投稿から出さないようにし、プロフィールの写真を図柄に替えることはできます。ただし、過去の投稿の写真は、保存や引用で残っていることがあり、完全には消せません。本業や候補者との関係で困る可能性があるなら、過去の投稿を消すか非公開にしたうえで、それでも残る可能性は受け入れる形になります。名前の切り替えと同じで、「出さない」から「出す」へは戻れますが、逆は難しいことを前提に、今後の判断をします。
