カジュアル面談の代行を初めて受けるとき、見えにくいのは「面談の前後に何があるか」です。募集文には「カジュアル面談の対応」とだけあり、実際には、出る人の確定、語ることの骨格、誘いの文面の承認、日程の往復、当日の案内、同席と記録、翌日の連絡、応募に進んだ率の記録と、面談そのものの前後に工程が並びます。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→第1週→第2週以降→月次→終了と更新」の五つの段階で進み、契約前に範囲・面談に出る人・枠・自分の紹介の仕方・選考にしない決まり・連絡の名義と文面・記録の置き場・報告を決め、第1週は誘わずに目的と出る人の確認と設計と文面の承認と出る人との打ち合わせに使い、第2週から誘いと日程と同席と記録と翌日までの連絡と週次の報告を回し、月次で応募に進んだ率を出る人・語ること・連絡ごとに見て直し、引き継げる形で終えます。**案件の型と求められる経験は[カジュアル面談の代行の副業案件](/media/fukugyo-casual-mendan-fk-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

カジュアル面談は、候補者が「まだ応募していない」段階で会社と接する場です。面談に出る人と、選考にしない決まりが無いまま始めると、面談が面接になり、候補者が離れます。契約前に決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 誘いと日程だけか、同席と記録と連絡か、設計と型作りか、育成か。単独で面談に出る前提でないこと | 「会社の話も担当者が」が後から足される |
| 面談に出る人 | 会社側の誰が出るか（現場の責任者、経営者、複数）。語ることの骨格があるか | 出る人によって内容がばらつく。担当者が語らされる |
| 面談の枠 | 出る人の枠（曜日と時間帯）。一回の時間。オンラインか対面か | 設定までが遅く、候補者が他社に行く |
| 候補者への自分の紹介の仕方 | 「採用の進行を担当している」と外部の担当として示すか | 社員を装う形になる |
| 選考にしない決まり | 面談で評価をつけない。経歴を掘らない。選考に進めるかは候補者の意思を確かめてから会社が判断 | 面談が面接に変わり、候補者が引く |
| 連絡の名義と文面 | 誘い、日程、当日の案内、翌日の連絡の文面の承認者。名義 | 承認の無い文面が会社の名前で出る |
| 記録の置き場 | 会社の管理する場所。録音の扱いと候補者の同意 | 候補者の情報が自分の端末に残る |
| 報告と評価 | 週次か、形式。何で評価されるか（設定までの日数、面談の数、応募に進んだ率のどれか） | 動かせない数字で評価される |

止まりやすいのは、「まず溜まっている返信者に面談の案内を出してください」で始めるときです。出る人と枠と選考にしない決まりだけは、誘う前に決めます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に書いています。

## 第1週：誘わない週

第1週は、候補者を誘いません。目的と出る人の確認、語ることの骨格と流れの設計、文面の承認、記録の型、出る人との打ち合わせに使います。設計の無いまま誘うと、面談の中身が出る人任せになり、ばらつきます。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 目的と出る人の確認（誰を、何のために、誰が出て、面談後に何が起きてほしいか） | 出る人の確定と枠 | 目的が「とりあえず会う」のまま |
| 語ることの骨格（事業、チーム、働き方、いま困っていること、候補者に期待すること。良く見せない） | 出る人が骨格を自分の言葉で埋める時間 | 人事が作った台本を出る人に読ませる |
| 流れの設計（自己紹介、会社の話、候補者の関心を聞く、質問、次の一歩の説明。時間の配分） | 流れの承認 | 経歴の確認から始まり、面接になる |
| 選考にしない決まりの共有（評価をつけない、経歴を掘らない、掘り始めたときの戻し方） | 出る人の合意 | 出る人が「見極めたい」と思っている |
| 誘い・日程・当日の案内・翌日の連絡の文面の承認 | 承認と名義の確定 | 誘いの文面が選考の案内になっている |
| 記録の型（関心、二度以上触れたこと、質問、懸念、次の一歩の希望。評価の欄は無し） | 置き場の確定 | 評価の欄がある記録の型 |
| 出る人との打ち合わせ（役割の分担、自分の紹介の仕方、戻し方の合図） | 出る人の時間 | 出る人と初対面で面談に入る |

止まりやすいのは、「面談は現場が慣れているから設計は要らない」と第1週を飛ばすときです。慣れている現場ほど、面接の癖で経歴を掘ります。聞き方は[質問の仕方](/media/fukugyo-shitsumon-shikata/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「語ることの骨格を、出る人が自分の言葉で埋めてくれるか」で、その後の難易度が決まります。人事が台本を作って出る人に読ませる形では、候補者の質問に本人の言葉で答えられず、面談が説明会になります。出る人が骨格の項目（いま困っていること、候補者に期待すること）を自分の言葉で埋めた会社では、面談の後に候補者が「あの人と働くイメージがついた」と言い、応募に進みます。エラベルで担当者を選ぶ企業には、「骨格は担当者が作りますが、中身は出る方が自分の言葉で埋めてください。三十分で構いません」と、私たちから先に伝えています。受ける側がその場で使える判断としては、骨格の項目を五つ以内にして、出る人に「一項目を一分で話すとしたら」と口頭で埋めてもらい、それを記録すること。書いてもらうより、口頭のほうが本人の言葉になります。

## 第2週以降：誘い・日程・同席と記録・翌日の連絡・週次の報告

第2週から誘いを始めます。ここからは、誘う、日程を合わせる、案内を出す、同席して記録する、翌日に連絡する、記録する、の繰り返しです。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 誘い（スカウトの返信者や応募前の候補者に、面談の趣旨と「選考ではない」ことを添えて） | 返信が来た当日か翌日 | 選考の案内の文面で誘う。遅れる |
| 日程（出る人の枠から候補日を出し、候補者と合わせ、確定を両方に出す） | 誘いへの返事が来た当日 | 出る人の枠を先に押さえていない。往復が三回を超える |
| 当日の案内（接続先や場所、出る人の紹介、流れ、所要時間、「選考ではない」の再掲） | 前日まで | 案内が無く、候補者が面接だと思って来る |
| 同席と記録（自分の紹介、進行の補助、関心・二度以上触れたこと・質問・懸念・次の一歩の希望を記録。面接に変わりそうなら戻す） | 面談ごと | 評価を書く。記録を後回しにして印象に置き換わる |
| 翌日までの連絡（二度以上触れたことに触れ、次の一歩の選択肢を出す。合否と条件に触れない） | 面談の翌日まで | 定型の一文だけ。遅れて熱が冷める |
| 候補者の質問の受け渡し（面談で答えられなかった質問を出る人に渡し、返事を候補者に戻す） | 翌日の連絡と同時 | 質問が宙に浮く |
| 記録の表（誘い日、面談日、出る人、関心、次の一歩、応募に進んだか） | 面談ごと | 集計できない形。自分の端末に置く |
| 週次の報告（誘い、設定、面談、応募に進んだ数、設定までの日数、候補者から多かった質問、次に直すこと一つ） | 週に一度、決めた曜日 | 数字だけで、直すことが無い |

止まりやすいのは、日程の往復が長くなることです。出る人の枠を先に押さえ、候補日を三つ出し、二往復で決めます。連絡の速さの考え方は[連絡の速さ](/media/fukugyo-renraku-sokudo/)に、報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

## 月次：応募に進んだ率を、出る人・語ること・連絡ごとに見る

月に一度、会社と見直しの時間を持ちます。見るのは、面談の数ではなく、「応募に進んだ率」を、出る人・語ること・連絡で分けたものです。

| 見ること | 直すところ |
|---|---|
| 出る人ごとの応募に進んだ率 | 率が低い出る人の語り方（台本になっていないか、経歴を掘っていないか）。同席で拾って本人と振り返る |
| 候補者が二度以上触れたことの傾向 | 語ることの骨格に足す項目。会社が事前に出す情報 |
| 面談後の連絡から応募までの日数 | 連絡の速さと、次の一歩の選択肢の出し方 |
| 面談に来なかった人（日程が合わなかった、当日来なかった） | 誘いの文面、設定までの日数、当日の案内 |
| 面談の後に応募しなかった人の理由（分かる範囲で） | 語ることと実態のずれ。会社に返す |

止まりやすいのは、月次で「面談の数を増やします」で終わるときです。数を増やしても、出る人の語り方と連絡が変わらなければ、率は変わりません。一度に全部を変えず、一つずつ変えて比べます。

### エラベルの見解

同じ料金・同じ面談の数でも、結果が分かれるのは、月次の見直しで「出る人ごとの率を、本人に返せるか」です。出る人によって率が違うとき、それを言わずに連絡の文面だけを直し続ける担当者は、三か月目に「応募が増えない」と契約を終えられます。同席の記録から「〇〇さんの面談では、候補者が経歴を聞かれる時間が長く、会社の話が短い。骨格の三つ目と四つ目が出ていない」と、責めずに事実で本人に返し、次の面談で一緒に直す担当者は、次の月から率が上がります。出る人に返すのは気が重いですが、外の担当者だからできる仕事です。社内の人事は、現場の責任者に「面談の語り方を変えてください」とは言いにくい。エラベルで長く続いている担当者は、月次の報告に「出る人ごとの率」と「同席で拾った直すところ」を、本人と先に共有した上で載せています。受ける側がその場で使える形としては、出る人への返しを月次の会議ではなく、面談の直後に一言で行うこと。「今日は後半、経歴の話が長くなりましたね。次は会社の話を先に」と、その場で言えば、会議で言う必要が無くなります。

## 終了と更新：引き継ぎと次の提案

契約の期間が来たら、更新か終了かを会社が決めます。どちらでも、引き継げる形にして終えます。

- **残すもの。** 語ることの骨格（出る人が埋めたもの）、流れの設計、選考にしない決まりと戻し方、誘い・日程・案内・翌日の連絡の文面の型、記録の型、記録の表（会社の管理する場所に）、出る人ごとの率と直した履歴
- **返すもの。** 採用管理システムやスカウト媒体の権限、共有された資料。候補者の情報は自分の手元に一切残さない
- **次の提案。** 更新するなら、次の期間で直す語ることと連絡。終了するなら、社内で回す手順書と、最初の一か月で見る数字

引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 候補者の情報の扱い

カジュアル面談では、候補者が現職の事情や転職の動機を、選考ではないからと率直に話します。それは選考の材料にせず、会社の外で話さず、記録は関心と次の一歩に絞ります。記録は会社の管理する場所に置き、自分の端末やクラウドに残しません。録音や録画は、会社の決まりと候補者の同意に従い、自分の端末で録らないことを基本にします。面談で聞いた内容を、選考に進んだあとの面接官に「評価」として渡さないことも、会社と決めておきます。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[セキュリティの基本](/media/fukugyo-security/)に書いています。個別の判断は専門家にご確認ください。

## 稼働時間は何で決まるか

週に何時間かかるかは、誘う人数（誘いと日程の往復の時間）、面談の数（同席と記録と翌日の連絡の時間）、週次の報告で決まります。誘いと日程は人数に比例し、面談に進む割合で同席の時間が決まります。受ける前に「週に何人誘うか」と「面談は週に何枠か」と「同席の有無」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、最初の一か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→第1週→第2週以降→月次→終了と更新**の五つの段階
- 契約前に**範囲・面談に出る人・枠・自分の紹介の仕方・選考にしない決まり・連絡の名義と文面・記録の置き場・報告と評価**を決める。出る人と枠と決まりは誘う前に
- 第1週は**誘わない**。目的と出る人の確認、語ることの骨格（出る人が口頭で自分の言葉で埋める）、流れ、文面の承認、記録の型、出る人との打ち合わせに使う
- 第2週以降は**当日か翌日に誘う→出る人の枠から候補日三つで二往復→前日までに案内→同席して関心と二度以上触れたことを記録→翌日までに関心に触れて次の一歩の選択肢を出す**
- 月次は**応募に進んだ率を出る人・語ること・連絡で分けて見る**。出る人への返しは面談の直後に一言で
- 終了時は**骨格・流れ・決まり・文面の型・記録の型・率と直した履歴**を残し、候補者の情報を手元に一切残さない
- 面談で聞いた率直な話は**選考の材料にせず、会社の外で話さない**

## よくある質問

### 出る人が「面談で見極めたい」と言います

選考にしない決まりの共有のときに、「見極めは選考でやれます。面談で見極めると、候補者は面接だと感じて応募に進みません。面談では会社の話をして、候補者に選んでもらう場にしましょう」と伝えます。それでも掘りたい出る人には、「候補者の関心を聞く時間」を流れに入れ、そこで候補者が自分から話すことを聞く形にします。掘る質問は、選考に進んでからの面接に回します。面談が面接になった回の記録は、評価として残しません。

### 候補者から「これは選考ですか」と聞かれました

「選考ではありません。会社の話を聞いていただいて、進むかどうかは〇〇さんに決めていただく場です」と答え、誘いと当日の案内にも同じ一文を入れておきます。面談の中で経歴を掘る場面があると、この一文が嘘になるので、出る人と戻し方を決めておきます。面談後に候補者が応募を選んだら、そこから先が選考であることを、翌日の連絡で明確にします。

### 翌日の連絡に、何を書けばよいのか迷います

記録の「二度以上触れたこと」の欄から書き始めます。「面談で二度お尋ねいただいた〇〇について、〇〇さんから補足があります」と一つ触れ、面談で出た候補者の質問への返事を添え、次の一歩の選択肢（応募、二回目の面談、追加の情報、いまは連絡だけ）を出します。合否や条件には触れません。文面は承認された型を使い、関心の部分だけを候補者ごとに書き換えます。この形なら、一通に長い時間はかかりません。
