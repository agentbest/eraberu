発信を始めたものの、数本書いたところで何を書けばよいか分からなくなった。案件の話は書けないし、一般論は他の人が書いている。結論を先に書くと、**人事の副業の発信のネタは、案件の出来事ではなく、案件の中で自分が繰り返している判断から取ります。「迷った場面で何を決めたか」「途中で直した型」「依頼側や候補者から聞かれた質問」の三つを案件の中で記録しておけば、依頼側と候補者を出さずに書けるネタは尽きません。**ネタが尽きるのは、書くことが無いからではなく、出来事しか見ていないからです。判断に目を向けると、当たり前にやっていることがすべてネタになります。書いてはいけない線は[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)に、頻度の決め方は[発信の頻度](/media/fukugyo-hasshin-hindo/)に、発信の進め方は[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/)にまとめています。

## ネタが尽きる本当の理由

ネタが尽きたと感じるとき、実際に起きていることは決まっています。

| 感じていること | 実際に起きていること |
|---|---|
| 書くことが無い | 出来事を探している。案件の出来事は書けないので、書けるものが無いように見える |
| 一般論しか書けない | 自分の判断を「当たり前」だと思い、書く価値が無いと決めている |
| 他の人が書いている | 同じテーマでも、自分がどう判断しているかは他の人と違う。テーマの重複を気にしている |
| 案件が無いと書けない | 案件の話を書こうとしている。判断の仕方は、案件が無くても書ける |
| 専門的なことを書かないといけない | 依頼側が読みたいのは専門知識ではなく、この人はどう進める人か |

理由の要点は、「出来事を探している」ことです。出来事は依頼側と候補者に結びついているので、書けません。書けるのは、出来事から取り出した判断で、それは自分の中にいくらでもあります。「当たり前にやっていること」が、依頼側から見れば「この人の進め方」です。

## 出来事ではなく判断からネタを取る

同じ場面でも、出来事として見るか、判断として見るかで、書けるかどうかが変わります。

| 場面 | 出来事として書く（書けない） | 判断として書く（書ける） |
|---|---|---|
| 候補者が日程の都合で辞退した | 「今日、候補者が日程の理由で辞退した」 | 「面接の枠を先に固定しないと、母集団があっても辞退が出る。自分は最初に面接官の時間を押さえる」 |
| 依頼側の求人票が曖昧だった | 「クライアントの求人票がひどかった」 | 「求人票の要件が五つ以上あるときは、三つに絞ることを最初に提案する」 |
| スカウトの返信が来なかった | 「今週の返信率が低い」 | 「返信が来ないとき、文面より先に、送っている相手の絞り方を疑う」 |
| 依頼側から範囲外の仕事を頼まれた | 「クライアントから急に面接をやってくれと言われた」 | 「範囲外の依頼が来たとき、断るのではなく、範囲の見直しとして話す」 |
| 単価の交渉で迷った | 「今の案件の単価が安い」 | 「単価は相場ではなく、自分の稼働の上限と時間で決めている」 |

取り方の要点は、「その場面で、自分は何を決めるようになったか」を書くことです。出来事には依頼側と候補者と時期が含まれますが、判断にはそれが含まれません。判断として書けば、五つの線を越えず、依頼側が読みたい「この人の進め方」になります。事例として書く場合の粗くし方は[事例の書き方](/media/fukugyo-jirei-kakikata/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「自分がやっていることは当たり前なので、書いても誰も読まない」というものです。実際には、依頼側の担当者は人事の実務を毎日やっているわけではなく、担当者にとっての「当たり前」は、依頼側にとっては「そうやって進めるのか」という発見です。求人票の要件を三つに絞る、面接の枠を先に固定する、返信が来ないときは文面より相手の絞り方を疑う。担当者には当たり前でも、依頼側はそれを知らないから外に頼んでいます。

エラベルで担当者の経歴を整えるとき、「案件で繰り返していることは何ですか」と聞くと、最初は「特に無い」と返ってきます。そこから一つずつ聞いていくと、十を超える判断が出てきます。それを経歴に書くと、依頼側の反応が変わります。発信のネタも同じ場所にあります。当たり前だと思っていることを、一つずつ書き出すと、それがネタの一覧になります。

## ネタの三つの源泉

判断からネタを取るとき、案件の中の三つの場面を見ておくと、取りやすくなります。

| 源泉 | 何を取るか | 例 |
|---|---|---|
| 迷った場面 | 迷ったときに、何を基準に決めたか | 「受けるか断るか迷った案件で、自分は固定できる時間があるかで決めた」 |
| 直した型 | 最初の型が合わず、途中でどう直したか | 「スカウトの文面の冒頭を、役割の説明から会社の状況の説明に変えたら、返信の質が変わった」 |
| 聞かれた質問 | 依頼側や候補者、同じ立場の人から、何を聞かれたか | 「依頼側に『媒体を増やすべきか』と聞かれたとき、自分はこう答えている」 |

三つの要点は、「聞かれた質問」が最も取りやすいことです。聞かれた質問は、誰かが知りたかったことなので、書けば読む人がいます。依頼側から聞かれたこと、候補者から聞かれたこと、同じ立場の仲間から聞かれたことを、質問の形で書き留めておき、自分の答えを投稿にします。質問の中身は依頼側の情報を含むことがあるので、粗くして一般化します。同じ立場の人から聞かれる場面は[同じ立場の仲間を作る](/media/fukugyo-nakama/)に書いています。

## 案件の中で記録しておく方法

ネタは、案件が終わってから思い出すより、案件の中で書き留めるほうが、依頼側の情報と切り分けやすくなります。

| 記録するとき | 何を書くか | 書き方の要点 |
|---|---|---|
| 初回の打ち合わせの後 | 最初に確認したことと、最初に決めたこと | 依頼側の情報を書かず、「自分は最初に〇〇を確認する」の形で |
| 迷ったとき | 何で迷い、何を基準に決めたか | 「〇〇と〇〇で迷い、〇〇を基準に〇〇にした」の一行 |
| 型を直したとき | 直す前と後、直した理由 | 型そのものは依頼側の情報を抜いた形で |
| 質問されたとき | 質問と、自分の答え | 質問は一般化して。「媒体を増やすべきか」のような形に |
| 定例や報告の後 | 依頼側に説明して、伝わったこと・伝わらなかったこと | 伝わらなかったことは、書き方を変えるネタになる |
| 案件が終わったとき | この案件で繰り返した判断を三つ | 終了時にまとめると、事例の材料にもなる |

記録の要点は、「依頼側の情報を最初から書かない」ことです。記録の時点で判断だけを書いておけば、投稿にするときに粗くする手間がありません。記録は、稼働の記録の表に「判断」の列を足す形で足ります。[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)の型に一列足せば、案件ごとの判断の一覧が自然にできます。

## 一つの判断を複数の投稿に分ける型

一つの判断は、切り口を変えると複数の投稿になります。ネタが少なくても、切り口で増やせます。

| 切り口 | 一つの判断「求人票の要件は三つに絞る」から |
|---|---|
| なぜそうするか | 「要件が五つ以上あると、候補者は自分が合うか判断できず、応募が減る」 |
| どうやるか | 「三つに絞るとき、依頼側に『この中で一つだけ残すなら』と聞く」 |
| うまくいかない場合 | 「絞れないときは、依頼側の中で採用の目的が揃っていない。先にそこを合わせる」 |
| 依頼側にどう説明するか | 「『要件を減らす』ではなく『応募が来る形にする』と説明する」 |
| 初めての人への説明 | 「副業で最初に求人票を任されたら、まず要件の数を数える」 |
| 自分が変わったこと | 「以前は要件をそのまま載せていた。絞るようになって、面接で聞くことが変わった」 |

分ける型の要点は、「一つの判断につき、なぜ・どうやる・うまくいかない場合・依頼側への説明」の四つは書けることです。十の判断があれば、四十の投稿になります。頻度を低く決めていれば、それで一年以上続きます。切り口ごとに書くと、同じ判断を別の角度から何度も伝えることになり、読む側に「この人の進め方」として残ります。

## 書けないネタの見分け方

判断から取っても、書けないネタはあります。書く前に見分けます。

| 書けないネタ | なぜ書けないか | 代わりに |
|---|---|---|
| 一つの案件でしか起きていない判断 | その案件の状況と結びつき、依頼側が特定される | 複数の案件で繰り返すようになってから書く |
| 依頼側の体制や事情が前提の判断 | 「人事が一人で経営者が面接に出る会社では」は体制の特定になる | 体制を粗くし、「人事の専任がいない体制では」に |
| 候補者の反応が中心の判断 | 候補者の話が抜けると成り立たない | 候補者を消して成り立たないなら書かない |
| 依頼側との交渉の具体 | 単価や条件の交渉は契約の情報 | 交渉の「決め方」だけにする。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) |
| 法令の解釈を含む判断 | 断定すると事故になる | 「一般に〜と整理されている」と添え、専門家に確認してから |
| 本業で身につけた判断で、本業の内情を含むもの | 本業の情報の持ち出し | 本業の内情を抜いて、判断だけにできるなら書く。できないなら書かない |

見分けの要点は、「複数の案件で繰り返している判断だけを書く」ことです。一つの案件でしか起きていないことは、まだ判断ではなく出来事で、その案件と結びついています。二つ以上の案件で同じ判断をするようになったら、それは自分の型で、書いても案件は特定されません。

### エラベルの見解

担当する側から見ると、発信が続いている人と続かない人の差は、文章の上手さではなく、記録の有無です。案件の中で判断を書き留めている人は、発信のときに記録から選ぶだけで済み、「何を書くか」で止まりません。書き留めていない人は、発信のたびに思い出そうとし、思い出せるのは出来事なので、書けないか、線を越えるかのどちらかになります。

順番として、発信を始める前に、いまの案件で繰り返している判断を十個書き出す。それが無いなら、発信を始めるのはまだ早く、案件の中で記録を始めるのが先です。十個あれば、切り口で四十本になり、頻度を低く決めていれば一年続きます。エラベルでは、担当者の経歴を整えるときに聞く「繰り返している判断」を、担当者自身が発信の種にしている例があります。経歴の中身と発信の種は同じもので、どちらかを整えれば、もう一方も整います。経歴の書き方は[プロフィールの書き方](/media/fukugyo-profile/)に整理しています。

## まとめ

- ネタが尽きるのは**出来事を探しているから**。書けるのは出来事から取り出した判断で、それは尽きない
- 同じ場面でも**出来事として書けば書けず、判断として書けば書ける**。「その場面で自分は何を決めるようになったか」
- 源泉は**迷った場面・直した型・聞かれた質問**の三つ。聞かれた質問が最も取りやすい
- 案件の中で**初回の後・迷ったとき・型を直したとき・質問されたとき・報告の後・終了時**に判断だけを記録する
- 一つの判断は**なぜ・どうやる・うまくいかない場合・依頼側への説明**の四つの切り口で複数の投稿になる
- 書けないのは**一つの案件でしか起きていない・体制が前提・候補者が中心・交渉の具体・法令の解釈・本業の内情**。複数の案件で繰り返す判断だけを書く

## よくある質問

### まだ案件が一件しかありません。ネタは取れますか

一件の案件の中でも、迷った場面と聞かれた質問は起きているので、記録は始められます。ただし、一件でしか起きていない判断は、その案件と結びついているので、投稿にするのは待ちます。本業の経験で繰り返している判断のうち、本業の内情を含まないものは、副業の案件が一件でも書けます。「本業で身につけた、求人票の要件の絞り方」のような形です。本業の情報を含まないかは、[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)の線で確かめてください。

### 他の人がすでに同じことを書いています。書く意味はありますか

同じテーマでも、自分がどう判断しているかは他の人と違います。依頼側が読んでいるのは、テーマの新しさではなく、「この人はこう進める人か」です。他の人と同じテーマで、自分の判断を書けば、それは自分の発信になります。逆に、他の人が書いていないテーマを探すと、自分が繰り返していない判断を書くことになり、内容が薄くなります。

### 判断を書くと、自分の型を他の人に真似されませんか

型は真似されますが、依頼側が頼んでいるのは型ではなく、その型で進める人です。同じ型を読んだ人が同じように進められるなら、それは型が広まっただけで、自分の案件が減るわけではありません。むしろ、型を公開している人は「この型で進める人」として依頼側に覚えられ、案件の入口が増える傾向があります。真似されて困る型があるなら、それは公開せず、面談で話す形にします。
