施工管理の採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、現場を知らない人に施工管理の採用が回せるのか」「経験者がそもそも市場にいないのに、代行に出して意味があるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、現場の条件の開示範囲・工事の種類と規模の整理・資格の要否・要件の決定・現場の技術と段取りの評価・合否の判断は社内に残す**のが線です。施工管理は、法務や人事と違って「現場の分かる人」は社内にいます。足りないのは、採用の工程を回す人と、現場の条件を候補者に伝わる形で正直に書く工程です。そこが代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、現場の協力の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)にまとめています。

## 施工管理採用が他の職種と違う点

一つ目は、経験者の母数が少なく、引き抜きの競争になることです。施工管理の経験者は、いまどこかの現場にいて、転職を考えていない人が多い。求人を出して待つ採用では届かず、こちらから届ける採用（スカウト、紹介、知人経由）の比重が大きくなります。

二つ目は、工事の種類と規模で市場が分かれることです。建築（新築、改修）、土木、設備（空調、給排水）、電気、内装。それぞれ経歴も市場も違い、建築の施工管理が土木の現場をすぐに回せるわけではありません。規模も、大型の現場と小規模の現場では動き方が違います。「施工管理募集」だけでは、どの種類と規模かが候補者に伝わりません。

三つ目は、候補者が最初に確かめるのが現場の条件だということです。工期と繁忙期、休日（週休の形、現場の休み方）、残業の実態、転勤や出張の範囲、直行直帰の可否、現場の場所、一人で持つ現場の数。施工管理の経験者は、これを最初に確かめ、正直に書かれていない求人を疑います。面接で実態が分かって辞退される原因の多くがここです。

四つ目は、現場の判断の質は社内で見られるが、採用の工程を回す人がいないことです。所長や工事部長が面接で技術と段取りを見ることはできます。しかし、求人票を書き、媒体を運用し、スカウトを送り、応募者に当日返信し、現場の所長の面接の日程を確保する、という工程を回す人が、社内にいません。所長は現場にいて、日程が取れない。ここで候補者が離れます。

五つ目は、資格の要否が現場の配置と結びつくことです。施工管理技士の資格は、現場の規模や請負の形によって、法令上の配置に関わります。資格を必須にするか、入社後の取得を前提にするかは、自社の現場でどう配置するかで決まります。法令上の配置の要件は、行政書士など専門家にご確認ください。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 工事の種類と規模の整理 | 残す | 自社がどの種類と規模の現場を持ち、どの現場に配置するか。社内にしか分からない |
| 現場の条件の開示範囲の決定 | 残す | 工期・休日・残業・転勤・直行直帰・持つ現場の数を、どこまで正直に書くか。経営者と工事部長が決める |
| 資格の要否の決定 | 残す | 現場の配置から。専門家に確認 |
| 要件の決定 | 残す | 種類・規模・条件・資格から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（条件の開示範囲が決まっていれば） | 決まったものを候補者に伝わる言葉にする。現場の条件を「相談」でごまかさない |
| 媒体の選定と運用 | 任せられる | 施工管理に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 種類と規模に合わせた検索と、文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、流れの案内。ここが遅れると他社に決まる |
| 所長・工事部長の面接の日程の確保 | 任せられる | 現場の予定を押さえ、候補者と合わせる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 種類・規模・資格・経験年数の分類は任せられる。技術と段取りの妥当性は残す |
| 現場の技術と段取りの評価 | 残す | 所長や工事部長が面接で聞く |
| 現場の条件の説明 | 残す（代行が同席可） | 実態を正直に話す。ここで言うことが求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断。施工管理は他社との比較が厳しい |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。現職の引き止めに対応する時期 |

線の要点は、「現場の条件の開示範囲が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の生活に合う現場か」を判断する材料になります。

### エラベルの見解

相談で多いのは、「施工管理を募集しているが、応募が来ない。来ても面接で辞退される」というご相談です。求人票を見ると、「施工管理募集。建築工事の施工管理全般。休日は会社カレンダーによる。残業あり。転勤の可能性あり」と書かれていて、工事の種類も規模も曖昧で、現場の条件が「による」「あり」で済まされています。施工管理の経験者は、この書き方を「実態は厳しい」と読み、応募しないか、面接で実態を聞いて辞退しています。

見ていて差がつくのは、「現場の条件を数字ではなく、実態の形で正直に書けるか」です。「新築の中規模建築が中心。現場は都内と近郊で、転勤は無く、直行直帰が基本。休日は現場の休みに合わせて週休の形で、繁忙期は土曜が出る月がある。残業は現場の段階で差があり、竣工前に集中する。一人が持つ現場は一つ」。ここまで書けば、条件が合わない人は応募せず、合う人は「正直な会社」として応募します。エラベルでは、施工管理の案件をお受けする前に、依頼側に「現場の条件をどこまで書くか」を伺い、書けない項目があるなら、その理由を確認しています。

## 代行に出す前に社内で確認すること

代行に出す前に、四つを社内で確認します。

**一つ目：工事の種類と規模、配置する現場。** 建築・土木・設備・電気・内装のどれか。新築か改修か。規模はどのくらいか。採る人をどの現場に配置するか。これが決まると、要件と市場が決まります。

**二つ目：現場の条件の実態。** 工期と繁忙期、休日の形、残業の実態、転勤や出張の範囲、直行直帰、現場の場所、一人が持つ現場の数、職人や協力会社との関係。実態を経営者と工事部長で確認し、「どこまで書くか」を決めます。書けない項目があるなら、それは候補者が面接で聞く項目で、面接で辞退される項目です。

**三つ目：資格の要否。** 自社の現場の規模と請負の形で、法令上どの配置が要るか。資格を必須にするか、入社後の取得を前提にするか。専門家に確認します。

**四つ目：所長や工事部長が、面接にどのくらい時間を出せるか。** 現場の予定の中で、面接の枠をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

四つのうち、二つ目が最も大きい。現場の条件を正直に書けない会社は、代行に出しても、面接での辞退が続きます。

## 現場の協力の取り付け方

施工管理の採用では、所長や工事部長の協力が要ります。面接に出る、条件を正直に話す、候補者の質問に答える。しかし現場は忙しく、「採用は総務の仕事」と考えていることが多い。

協力を取り付けるには、「採用が決まると現場がどう楽になるか」を具体的に示すことです。「この現場に一人入れば、所長が二つ持っている現場を一つに戻せる」。そして、現場の負担を最小にする形で頼みます。面接の枠は代行が押さえる、書類は代行が整理して渡す、条件の説明の要点は代行が用意する。所長がやるのは、面接で技術と段取りを聞くことと、条件を正直に話すことだけにします。詳しくは[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接の場で所長が「現場の実態」を話すことの価値を、所長自身に理解してもらうことです。候補者は経営者の話より、所長の話を信じます。所長が「うちの現場は竣工前は正直きつい。ただ、その後にまとめて休める形にしている」と話すと、候補者は「正直な会社」と判断します。これは代行にはできない工程です。

## 代行を選ぶときの確認項目

施工管理の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に建設業の経験があるか。** 施工管理そのものでなくても、建設会社の管理部門や、建設業の採用を回した経験。現場の条件の書き方と、候補者の見る目を知っているか
- **現場の条件を求人票にどう書くか、案を出せるか。** 「による」「あり」で済まさず、実態の形で書けるか
- **施工管理に届く媒体と経路の経験。** 建設業に強い媒体、スカウト、紹介、知人経由。経路ごとの経験と、引き抜きの競争の中での動き方
- **一次対応の速さ。** 応募や返信への当日対応ができるか。施工管理は他社の動きが速い
- **所長や工事部長の日程を押さえる段取り。** 現場の予定の中で面接の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。建設業を知らない担当者は、現場の条件を「相談」で書き、候補者に疑われます。一次対応が遅い代行は、候補者を他社に取られます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、施工管理の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「現場の条件をもっと正直に書かないと届かない」と言われることです。「休日は会社カレンダーによる」を「繁忙期は土曜が出る月がある」に直す提案が来る。経営者は「書くと来なくなる」と思いますが、書かないと面接で辞退されます。ここで開示範囲を決め直します。

二つ目は、提示条件が他社と比べられることです。施工管理の候補者は、複数の会社を同時に見ていて、条件を比べます。年収だけでなく、休日の形、転勤の有無、持つ現場の数。代行から「この条件では他社に決まる」と報告が来たとき、条件を変えるかは経営者の判断で、代行はその材料を出します。年収の見せ方は[提示年収が市場と合っていない](/media/rpo-nenshu-awanai/)に書いています。

三つ目は、内定後の引き止めです。施工管理の経験者は、現職の会社が引き止めます。「現場が終わるまで」「次の現場の所長に」と条件を出されて、辞退することがある。内定後の連絡を代行が続け、入社日まで候補者との接点を切らさないことで、辞退を減らします。

### エラベルの見解

担当する側から見ると、施工管理の採用で最も効くのは、「現場の条件を実態の形で正直に書く」ことと、「一次対応を当日にする」ことです。前者で面接での辞退が減り、後者で他社に取られる候補者が減ります。どちらも、社内に採用の工程を回す人がいない会社では、回りません。

エラベルでは、施工管理の案件で担当者を紹介するとき、最初の一週間で経営者と工事部長から現場の条件の実態を聞き取り、「どこまで書くか」を決めていただくところから始めてもらっています。技術と段取りの評価は所長や工事部長が面接で行い、資格の配置に関わる法令上の要件は、専門家にご確認いただくようお伝えしています。

## まとめ

- 施工管理採用が他と違うのは**経験者が少なく引き抜きの競争・種類と規模で市場が分かれる・候補者が最初に現場の条件を確かめる・現場の分かる人はいるが採用の工程を回す人がいない・資格が配置と結びつく**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、条件の開示範囲・種類と規模・資格の要否・要件・技術の評価・合否は残す**
- 代行に出す前に**種類と規模と配置・現場の条件の実態と開示範囲・資格の要否・所長の面接の時間**を確認する
- 現場の協力は**採用で現場がどう楽になるかを示し、負担を最小にして、所長が実態を話す価値を理解してもらう**
- 代行を選ぶときは**建設業の経験・条件の書き方・経路の経験・一次対応の速さ・日程の段取り**を確認する
- 出したあとは**条件をもっと正直に書く提案が来る・他社と比べられる・内定後に引き止められる**。判断は経営者、材料は代行

## よくある質問

### 現場の条件を正直に書くと、誰も来なくなりませんか

正直に書いて来ない条件なら、書かなくても面接で辞退されます。書くことで減るのは「面接に来て辞退する人」で、増えるのは「条件を分かった上で応募する人」です。書き方は、「残業あり」ではなく「竣工前に集中し、その後にまとめて休める形」のように、実態と会社の工夫を一緒に書きます。工夫が無い項目は、工夫を作ってから書くか、書いた上で面接で所長が正直に話すか、のどちらかです。「による」「あり」で済ませるのが、最も候補者に疑われます。

### 施工管理技士の資格を必須にすべきですか

自社の現場の規模と請負の形で、法令上どの配置が要るかによります。配置に資格が要る現場に採る人を置くなら必須、入社後に取得する前提で置ける現場があるなら「入社後取得」で母集団を広げられます。資格を「あったほうが安心」で必須にすると、母集団が大きく減ります。配置に関わる法令上の要件は、行政書士など専門家にご確認ください。

### 経験者がいないので、未経験を採って育てる形はどうですか

経験者の市場が薄い中では、現実的な選択肢の一つです。ただし、未経験の採用は経験者の採用とは別の工程で、「教える所長がいるか」「資格取得を支援する仕組みがあるか」「最初に持たせる現場の規模」を決めてから募集します。未経験向けの求人票を経験者向けと分け、「教える体制」と「取得までの道筋」を書きます。経験者の募集に「未経験歓迎」を足すと、経験者は「誰でもいい会社」と読んで見送るので、分けて出します。
