インサイドセールスの求人票の必須要件には、「インサイドセールスの実務経験」「一日〇〇件以上の架電の実績」「法人営業の経験」「経験二年以上」が並びがちです。インサイドセールスの経験者は限られ、架電の数は商談の質を示さず、法人営業の経験は分担が違えば再現されません。結論を先に書くと、**インサイドセールスの採用要件は、先に自社の分担（マーケティング・インサイドセールス・フィールドセールスが何を）と指標（数か質か受注への貢献か）を決め、必須を「入社初日に自社の分担で接触が成り立つか」で三つ以内に絞り、肩書・架電の数・年数は必須にせず、「顧客の課題を聞き出す接触」の経験で書く**と、経験者だけでなく転向層も母集団に入り、質の高い商談を作れる人が採れます。肩書と架電の数で書くと、テレアポの経験者が来て、商談の質が上がりません。母集団形成は[インサイドセールスの母集団形成](/media/rpo-inside-sales-boshuudan/)に、営業全般の要件は[営業の採用要件の作り方](/media/rpo-sales-youken/)にまとめています。

## インサイドセールスで要件が膨らむ理由

営業全般と共通する理由（「営業経験」が広すぎる、成績を必須にする）に加えて、インサイドセールスに特有の理由があります。

一つ目は、「インサイドセールスの経験」を必須にすることです。インサイドセールスは比較的新しい職種で、経験者は限られます。しかも、経験者でも前職の分担と指標が違えば、自社で同じ動きはできません。肩書を必須にすると、母集団が狭く、しかも合わないことがある要件になります。

二つ目は、架電の数を必須にすることです。「一日〇〇件」の実績は、量をこなせることの目安にはなりますが、課題を聞き出して質の高い商談を作れるかを示しません。数を必須にすると、テレアポの経験者が集まり、質を作る人を弾きます。

三つ目は、営業の経験を必須にすることです。フィールドセールスの経験は、商談の質が分かる点で役立ちますが、架電の量に耐えられるか、初回の接触を自分でしてきたかは別です。営業の経験を必須にすると、カスタマーサポートなどの転向層を弾きます。

四つ目は、ツールの経験を必須にすることです。顧客管理や架電のツールは、同種のものを使っていれば数週間で移行できます。

五つ目は、年数です。年数と、課題を聞き出す接触の力は一致しません。

## 必須と歓迎を分ける基準

基準は「入社初日に、自社の分担で接触が成り立つか」です。インサイドセールスでは「自社の分担で」を先に決めます。マーケティングが見込みを集める前提か、自分で探す前提か。指標は数か質か。

| 項目の例 | 必須になる場合 | 歓迎になる場合 |
|---|---|---|
| 顧客の課題を聞き出す接触の経験 | 質の高い商談を作る役割なら必須 | — |
| 電話やメールでの接触の経験 | 電話が中心の接触なら必須 | 対面の接触が中心の経験は歓迎（電話に慣れるか面接で確認） |
| 商談につなげた経験（聞き出したことを次の段階に渡した経験） | 商談化が成果の役割なら必須 | 聞き出すだけで渡さない役割（サポート）は歓迎 |
| 架電の量に耐えた経験 | 一日の接触の数が多い型なら必須 | 数が少なく質を追う型なら歓迎 |
| 見込み客を自分で探した経験 | 自社が見込みを作らない前提なら必須 | マーケティングが作る前提なら歓迎 |
| 目標に向き合った経験 | 売る側の目標がある役割なら必須（目標の種類は問わない） | — |
| 商材や業界の知識 | 専門性が極めて高く初日から要る場合 | 入社後に覚えられるなら歓迎 |
| インサイドセールスの肩書 | — | 必須にしない。「課題を聞き出す接触」の経験で |
| 架電の数の実績 | — | 必須にしない。「量に耐えた経験」を歓迎に |
| ツール | — | 必須にしない。同種のツールの経験を歓迎に |
| 経験年数 | — | 必須にしない |

基準の要点は、「肩書と架電の数を必須にせず、課題を聞き出す接触と、それを商談につなげた経験を必須にする」ことです。この二つがあれば、肩書がカスタマーサポートでもフィールドセールスでも、自社の分担で動けます。

### エラベルの見解

相談で多いのは、「インサイドセールスの経験があって、一日〇〇件の架電ができて、法人営業も分かる人」というご要望です。この要件で来る人は少なく、来ても、架電の数で選ばれたテレアポの経験者か、フィールドセールスの経験があってインサイドセールスに戻りたくない人です。要件を「自社の分担で接触が成り立つか」で問うと、肩書も架電の数も要らず、「課題を聞き出す接触」と「商談につなげた経験」の二つが残ります。

見ていて差がつくのは、「自社の分担と指標から、必須を逆算しているか」です。「マーケティングが見込みを集め、インサイドセールスが課題を聞き出して商談を作り、質と受注への貢献で評価する」なら、必須は「課題を聞き出す接触の経験」「商談につなげた経験」「目標に向き合った経験」の三つ。肩書も架電の数も営業の経験も、歓迎か不要です。エラベルでは、インサイドセールスの要件を整理するとき、依頼側に分担と指標を先に決めていただき、そこから必須を逆算しています。

## 必須を三つに絞る手順

インサイドセールス向けに、絞る手順を番号付きで整理します。

1. **分担を決める。** マーケティングが何を、インサイドセールスが何を、フィールドセールスが何を。見込みは誰が作るか。
2. **指標を決める。** 商談の数か、質か、受注への貢献か。
3. **架電の量と型を決める。** 一日の接触の数の目安、ツール、トークの型。
4. **現場（営業の責任者、マーケティング、フィールドセールス）の希望を全部書き出す。** ここでは絞らない。
5. **一つずつ、「初日に自社の分担で接触が成り立つか」を問う。** 成り立たないものだけ残す。
6. **残ったものが三つを超えたら、「入社後に覚えられるか」「自社が補えるか」を問う。** ツール、商材、架電の型は歓迎へ。
7. **肩書・架電の数・営業の経験・年数を、接触の経験の中身に書き換える。** 「インサイドセールス経験二年」ではなく「顧客の課題を電話で聞き出し、商談につなげた経験」。
8. **歓迎に回したものを、優先順位を付けて三〜五つ書く。** 面接で見る点になる。
9. **目標と評価、フィールドセールスとの関係を、要件と一緒に確認する。** 要件に合う人が、自社の指標と関係で続けられるか。
10. **営業の責任者・マーケティング・フィールドセールス・人事で確認する。** 「この三つがあれば、他は入社後に補える」と言えるか。

手順の要点は、「一から三を先にやる」ことです。分担・指標・架電の型が決まれば、必須はそこから逆算できます。

## 経歴で確かめられる要件と、面接でしか分からない要件

インサイドセールスでは、経歴の肩書と架電の数が実態を表さないので、確かめ方の区別が重要です。

| 確かめる方法 | 要件の例 | 見方 |
|---|---|---|
| 経歴で確かめられる | 接触してきた相手の種類、接触の手段（電話、メール、対面）、聞き出したことを次の段階に渡したか、前職の分担（見込みは誰が作ったか）、扱った商材の種類 | 書類の一次絞りで。「架電〇〇件」ではなく、「課題を聞き出して商談につなげた」記述があるかを見る |
| 経歴では分からない | 聞き出し方の質、断られたときの切り替え、質と量のどちらを重視するか、目標への向き合い方、フィールドセールスとの連携の姿勢 | 面接で、営業の責任者が聞く。「一番質の高い商談を作ったときの、最初の接触から引き渡しまでを順に」。[構造化面接](/media/rpo-kouzou-mensetsu/) |
| 経歴でも面接でも分かりにくい | 実際の電話での聞き出し方、声の印象、切り替えの速さ | 短いロールプレイ（自社の見込み客の実例を題材に）や、営業の責任者との同席の試行 |

分け方の要点は、「面接で、一つの商談を最初の接触から引き渡しまで話してもらう」ことです。架電の数の裏に、どんな聞き出し方があったか、何を聞いて商談と判断したか、フィールドセールスにどう渡したかが、一つの商談の話で見えます。

## 転向元ごとの要件の書き方

インサイドセールスの経験者は限られるので、転向元ごとに要件の書き方を変えると、母集団が広がります。

| 転向元 | 持っているもの | 要件の書き方 | 面接で確認すること |
|---|---|---|---|
| インサイドセールスの経験者 | 分担の中での動き方、商談化の経験 | 「課題を聞き出して商談につなげた経験」 | 前職の分担と指標が自社と近いか |
| カスタマーサポート | 顧客の課題を聞き出す接触、解決の提案 | 「顧客の課題を聞き出し、解決を提案した経験」。商談化は歓迎に | 売る側の目標に向き合えるか |
| フィールドセールス | 商談の質が分かる、受注への流れを知っている | 「初回の接触から商談を自分で作った経験」 | 架電の量に耐えられるか、フィールドに戻りたいだけでないか |
| テレアポ・電話営業（課題の聞き取りをしてきた人） | 架電の量に慣れている | 「架電の中で課題を聞き取り、商談につなげた経験」 | 数だけでなく質を作れるか |
| 営業事務・営業アシスタント（接触の経験がある人） | 営業組織の流れ、見込み客の管理 | 「見込み客に接触して情報を聞き出した経験」 | 目標に向き合えるか、接触の量に耐えられるか |
| 未経験（教える体制がある場合） | 顧客との対話の素養 | 「顧客と対話して合意や情報を得た経験」。接触の型は入社後 | 電話への抵抗、目標への向き合い方 |

書き方の要点は、「転向元によって、必須にするものと面接で確認するものが違う」ことです。カスタマーサポートからの転向層には「課題を聞き出す接触」を必須にして「売る側の目標」を面接で確認し、フィールドセールスからの転向層には「商談を自分で作った経験」を必須にして「架電の量」を面接で確認します。

## 要件が決まらないときの原因

| 原因 | 起きていること | 直し方 |
|---|---|---|
| 分担が決まっていない | 「インサイドセールスを置きたい」だけ | マーケティング・インサイドセールス・フィールドセールスの分担を決める |
| 指標が決まっていない | 数か質か曖昧 | 商談の数か質か受注への貢献かを決める |
| 見込み客の質と量を把握していない | 「マーケティングが集めている」 | 月の件数と質を把握。少なければ募集の性質が変わる |
| 肩書と架電の数で書いている | 書きやすい | 接触の経験の中身に書き換える |
| フィールドセールスとの関係が設計されていない | 渡した商談の扱いが決まっていない | 結果を戻す仕組み、一緒に振り返る仕組みを決める |
| 営業の責任者が要件の議論にいない | 人事と経営だけで決めている | 営業の責任者とフィールドセールスの責任者を入れる |
| 市場の実態を知らない | 「インサイドセールスの経験者が普通にいるはず」 | 代行や媒体に、その要件での人数を聞く。転向層を含めた数も |

原因の要点は、「分担と指標が決まっていない」ことが最も多い点です。この二つが決まれば、必須は逆算でき、転向元ごとの書き方も決まります。

## 代行に出せる工程

| 工程 | 社内で持つ | 代行に出せる |
|---|---|---|
| 分担・指標・架電の型の決定 | 判断 | 決める打ち合わせの進行 |
| 見込み客の質と量の把握 | 社内が出す | 一覧にする |
| 必須と歓迎の分離 | 「初日に成り立つか」の判断は社内 | 問いを立て、一つずつ確認する進行 |
| 肩書・架電の数・年数の書き換え | 中身は社内が出す | 接触の経験の中身の言葉に直す |
| 転向元ごとの要件の設計 | 判断 | 転向元ごとの書き方と確認の提案 |
| 目標と評価、フィールドセールスとの関係の確認 | 営業の責任者が決める | 要件との整合の確認 |
| 市場の実態の確認 | 判断 | その要件での人数を示す。転向層を含めて |
| 求人票への反映 | 確認 | 書く |
| 書類の一次絞り | 接触の質の妥当性 | 転向元の分類。「課題を聞き出して商談につなげた」記述の有無 |
| 面接で見る点の整理 | 営業の責任者が使う | 歓迎の要件と、転向元ごとの確認の質問の案 |

分け方の要点は、「分担・指標・見込み客の状態は、社内でしか決められない」ことです。代行は、決める打ち合わせの進行と、決まったものの言語化、転向元ごとの設計を担えます。

### エラベルの見解

担当する側から見ると、インサイドセールスの要件で最も時間がかかるのは、依頼側が「インサイドセールスの経験」と「架電の数」を手放すことです。安心のために積んだこの二つが、母集団を狭め、テレアポの経験者を集める原因になっている、と分かるまでに時間がかかります。分担と指標から逆算すると、必須は「課題を聞き出す接触」「商談につなげた経験」「目標に向き合った経験」に落ち着き、転向層が母集団に入ります。

エラベルでは、インサイドセールスの案件で要件が整理されていない場合、担当者の最初の仕事を「分担と指標を決める打ち合わせの進行」にすることをお勧めしています。分担と指標が決まると、求人票の一行目が書け、転向元ごとの訴求と確認が設計でき、経験者の少なさを転向層で補えます。

## まとめ

- インサイドセールスの必須要件は、**先に分担と指標を決め、「入社初日に自社の分担で接触が成り立つか」で三つ以内**に
- 要件が膨らむ理由は**肩書を必須にする・架電の数を必須にする・営業の経験を必須にする・ツールを必須にする・年数で書く**
- **肩書・架電の数・営業の経験・年数は必須にしない**。「課題を聞き出す接触」「商談につなげた経験」「目標に向き合った経験」で書く
- 絞る手順は**分担→指標→架電の型→全部書き出す→初日に成り立つか→覚えられるか・補えるか→接触の経験に書き換え→歓迎に優先順位→目標とフィールドセールスとの関係を確認→四者で確認**
- **面接では一つの商談を最初の接触から引き渡しまで話してもらう**
- **転向元ごとに必須と確認を分ける**（カスタマーサポート、フィールドセールス、テレアポの一部、営業事務の一部、未経験）
- 決まらない原因の多くは**分担と指標が決まっていない**こと

## よくある質問

### 架電の数を必須にしないと、量をこなせない人を採ってしまいませんか

架電の数は、量をこなせることの目安にはなりますが、課題を聞き出して質の高い商談を作れるかを示しません。数を必須にすると、テレアポの経験者が集まり、質を作る人を弾きます。自社の型が数を重視するなら、「架電の量に耐えた経験」を必須に入れますが、その場合も「課題を聞き出す接触」と組み合わせます。量への耐性は、面接で「一日の接触の数の目安はこのくらいです。前職と比べてどうですか」と聞き、転向元（カスタマーサポート、フィールドセールス）ごとに確認します。

### インサイドセールスの経験者を採りたいのですが、応募が来ません

経験者は限られ、しかも前職の分担と指標が自社と違えば、経験者でも合わないことがあります。「インサイドセールスの経験」を必須から外し、「課題を聞き出す接触」と「商談につなげた経験」で書くと、カスタマーサポート、フィールドセールス、テレアポの一部からの転向層が母集団に入ります。転向元ごとに、持っているものと確認することが違うので、面接で分けて確かめます。経験者にこだわるより、自社の分担で動ける素養のある人を転向層から採り、自社の分担と型を教えるほうが、現実的です。

### カスタマーサポートの人を採って、本当に商談を作れますか

顧客の課題を聞き出す接触に慣れている点で、インサイドセールスに向く素養があります。商談につなげる部分（聞き出したことを、次の段階に渡す判断と伝え方）は、自社の型を教えれば身に付くことが多い。ただし、売る側の目標（商談の数や質の目標、歩合）に向き合えるかは、人によります。面接で、転向の動機（顧客の課題を解決する側に回りたい、など）と、目標への向き合い方を確かめます。動機があって目標に向き合える人は、聞き出す力があるぶん、テレアポの経験者より質の高い商談を作ることがあります。
