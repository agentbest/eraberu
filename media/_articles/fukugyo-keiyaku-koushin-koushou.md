契約の更新が近い。最初に決めた範囲より実際にやっていることは広がっていて、稼働も想定より多い。更新のときに条件を直したいが、単価の話を持ち出すと関係が悪くなりそうで、言い出せない。結論を先に書くと、**更新時の条件見直しは、単価から入らず、「範囲」「稼働」「単価」の順に、実際の記録を根拠にして出します。範囲が最初の契約と変わっていれば、稼働もそれに合わせて変わっていて、単価はその二つの結果として決まるからです。**出す時期は更新の一か月前で、依頼側が社内で判断する時間を残します。単価だけを持ち出すと、依頼側は「値上げの要求」と受け取り、範囲と稼働の話が後回しになります。更新そのものの流れは[契約更新のされ方](/media/fukugyo-koushin/)に、値上げを切り出す時期は[値上げを申し出るタイミング](/media/fukugyo-neage-timing/)に、最初の条件の決め方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)にまとめています。契約の解釈は、専門家にご確認ください。

## 更新が条件を直す機会である理由

契約の途中で条件を直すのは難しく、更新の節目が、双方にとって直しやすい機会になります。

| 理由 | 内容 |
|---|---|
| 依頼側も見直す時期 | 依頼側は更新のときに、続けるか・範囲を変えるか・予算を組み直すかを社内で判断している。こちらの見直しと同じ時期 |
| 実績の記録が揃っている | 一期分の稼働の記録と、範囲の実態が手元にある。根拠を持って話せる |
| 契約書を書き直す機会 | 途中で条件を変えると覚書が要るが、更新なら新しい契約書に入れられる |
| 双方が「続ける」を前提にしている | 更新の話が出ている時点で、依頼側は続けたいと思っている。条件の話を聞く姿勢がある |
| 断る選択肢が双方にある | 折り合わなければ更新しない、という選択肢が双方にあるので、対等に話せる |

理由の要点は、「依頼側も見直す時期」だということです。依頼側の担当者は、更新の前に社内で予算と範囲を確認しています。その時期にこちらの見直しを出せば、担当者は社内の判断に合わせて扱えます。時期を外すと、担当者は社内の手続きをやり直すことになり、それだけで見直しが通りにくくなります。

## 見直す三つの項目と順番

見直しは、範囲、稼働、単価の順に出します。順番を変えると、話が単価に寄ります。

| 順 | 項目 | 見直すこと | なぜこの順か |
|---|---|---|---|
| 一 | 範囲 | 最初の契約の範囲と、実際にやっている工程の差。増えた工程、減った工程 | 範囲が決まらないと、稼働も単価も決まらない。依頼側も範囲の話なら聞きやすい |
| 二 | 稼働 | 範囲に対して、実際にかかった時間。想定との差。次の期に必要な時間 | 範囲が変わっていれば、稼働の差は自然な結果として説明できる |
| 三 | 単価 | 範囲と稼働が決まった後の、月額または時間単価。上げるか、据え置くか | 範囲と稼働の結果として出すと、値上げの要求ではなく、実態に合わせる話になる |

順番の要点は、「単価は結果」だということです。範囲が広がり、稼働が増えていれば、単価を据え置いたままでは実質的に下がっています。それを「範囲がこう変わり、稼働がこうなったので、単価をこう直したい」と出せば、依頼側は実態の話として聞きます。単価だけを「上げてほしい」と出すと、依頼側は根拠を求め、その根拠が範囲と稼働なので、結局同じ話を後からすることになります。範囲の広がりの扱いは[範囲が広がっていくとき](/media/fukugyo-scope-creep/)に、稼働の記録は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「更新のときに条件を直すと、更新されなくなる」というものです。実際には、更新されなくなるのは条件を直したからではなく、直し方が「単価だけ」で、しかも根拠が無いときです。範囲と稼働の記録を根拠に、実態に合わせる形で出した見直しが、それだけで更新を止めた例は、見ている限りほとんどありません。依頼側の担当者は、範囲が広がっていることを知っているので、実態に合わせる話は想定の範囲です。

逆に、条件を直さずに更新を重ねると、範囲だけが広がり、稼働が増え、単価が変わらない状態が固定されます。担当者が気づかないうちに、実質的に安く受け続けることになり、どこかで「続けられない」となって、突然の終了になります。それは依頼側にとっても損失です。エラベルでは、更新の節目に担当者と依頼側の双方に範囲と稼働の実態を確認しており、実態と契約がずれているときは、更新の前に直すことを勧めています。直さない更新は、次の期のずれを大きくするだけです。

## 根拠にする記録

見直しを出すとき、根拠になるのは自分の記憶ではなく、一期分の記録です。記録が無いと、依頼側は判断できません。

| 記録 | 何を示すか | 無いとどうなるか |
|---|---|---|
| 工程ごとの稼働時間 | 範囲のどの工程にどれだけ時間がかかったか。契約の想定との差 | 「思ったより忙しい」としか言えず、依頼側は判断できない |
| 増えた工程の一覧 | 最初の契約に無かった工程を、いつから、どの頻度でやっているか | 範囲の広がりを示せず、「それも含まれている」と言われる |
| 依頼側への報告の記録 | 定例や報告で、何を伝え、何が決まったか | 「そんな話は聞いていない」と言われる |
| 結果の記録 | 母集団、返信、面接の進み方など、状態の変化 | 稼働が増えた分、何が変わったかを示せない。[実績の示し方](/media/fukugyo-jisseki-shimeshikata/) |
| 依頼側からの評価 | 定例やメールで依頼側が言った評価の言葉 | 見直しが「自分の言い分」だけになる。[レビューをもらう](/media/fukugyo-review/) |

記録の要点は、「工程ごとの稼働時間」です。これがあれば、「契約の想定は週にこれだけで、実際はこの工程が増えてこれだけになっている」と、依頼側が見て分かる形で出せます。記録は、月に一度、工程ごとにまとめておけば、更新のときに一期分を並べるだけで済みます。記録の付け方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)の型で足ります。

## 依頼側に出す時期と形

見直しは、更新の一か月前に、文面で出します。口頭で先に伝えてから文面にする形でも構いませんが、文面が無いと担当者は社内に回せません。

| 時期 | やること |
|---|---|
| 更新の二か月前 | 一期分の記録をまとめる。範囲・稼働・単価の見直しの内容を自分の中で決める。[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)と照らす |
| 更新の一か月前 | 定例か個別の打ち合わせで、口頭で見直しの内容を伝える。その日のうちに文面で送る |
| 文面の形 | 一、いまの範囲と実際の範囲の差。二、稼働の記録と想定との差。三、次の期の範囲と稼働の提案。四、それに合わせた単価。五、社内の判断に時間が要れば教えてほしい |
| 依頼側の返事を待つ間 | 催促しない。稼働は落とさない。担当者が社内で判断している |
| 更新の二週間前 | 返事が無ければ、一度だけ「ご判断の時期を教えていただけますか」と確認する |
| 更新の直前 | 折り合いがついたら、新しい契約書に反映されているか確認する。書面にしないまま更新しない |

時期の要点は、「一か月前」です。これより遅いと、担当者が社内で判断する時間が無く、「今回は据え置きで、次回に」と先送りされます。これより早いと、担当者はまだ更新を考えておらず、話が宙に浮きます。更新の時期が契約書で決まっていない場合は、[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に書いた区切りで、自分から更新の時期を決めておきます。

## 依頼側から見直しを求められたとき

更新のときに、依頼側から範囲の縮小や単価の引き下げを求められることもあります。そのときも、同じ順番で考えます。

| 依頼側の求め | 考えること | 返し方 |
|---|---|---|
| 範囲を狭めたい | 狭めた範囲で、自分の稼働と単価が成り立つか。狭めた分、他の案件に稼働を回せるか | 「狭める範囲に合わせて稼働と単価も見直す」と、三つを一緒に話す |
| 単価を下げたい | 範囲と稼働を据え置いて単価だけ下げるのか。下げるなら範囲か稼働も減らせるか | 「単価を下げるなら、範囲か稼働のどちらを減らすか」と返す。単価だけ下げるのは受けない |
| 稼働を増やしたい | 本業と他の案件の稼働の上限に収まるか。[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/) | 収まるなら範囲と単価も合わせて。収まらないなら「この稼働までなら」と上限を示す |
| 成果報酬に変えたい | 成果の定義と、自分で動かせる範囲か。[成果報酬型は受けるべきか](/media/fukugyo-seika/) | 定義が曖昧なら受けない。受けるなら固定と成果の組み合わせを提案する |

求められたときの要点は、「単価だけを動かさない」ことです。依頼側が単価を下げたいと言うとき、範囲と稼働が据え置きなら、実質的に安く受けることになります。「単価を下げるなら、範囲か稼働を減らす」と返せば、依頼側は予算に合わせて範囲を選べ、こちらは稼働に見合う単価を保てます。折り合わなければ、更新しない選択肢もあります。

## 折り合わなかったときの扱い

見直しが通らないこともあります。通らなかった場合の扱いを、出す前に決めておきます。

| 結果 | 扱い |
|---|---|
| 据え置きで更新を求められた | 範囲を最初の契約に戻すことを条件に据え置きを受けるか、据え置きのまま一期だけ続けて次の更新で改めて出すか。据え置きで範囲も広いまま、は受けない |
| 一部だけ通った | 通った部分を新しい契約書に入れ、通らなかった部分は次の更新の課題として記録に残す |
| 更新しないと言われた | 見直しが理由か、依頼側の事情かを確認する。引き継ぎを整えて終える。[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/) |
| 自分から更新しないと決めた | 更新の一か月前までに伝え、引き継ぎを整える。[引き継ぎの進め方](/media/fukugyo-hikitsugi/) |
| 返事が来ないまま更新日を過ぎた | 契約書の自動更新の条項を確認する。自動更新なら旧条件で続いているので、改めて文面で確認する。契約の解釈は専門家に |

折り合わない場合の要点は、「据え置きで範囲も広いまま」を受けないことです。それを受けると、次の期はさらに範囲が広がり、次の更新で直すのがもっと難しくなります。据え置きを受けるなら、範囲を戻す。範囲を広いままにするなら、単価を直す。どちらかを取れば、次の期のずれは小さくなります。

### エラベルの見解

担当する側から見ると、更新の条件見直しがうまくいく人は、更新のときに初めて記録を見せるのではなく、毎月の報告で範囲と稼働の実態を依頼側に伝え続けています。毎月伝えていれば、更新のときに担当者はすでに実態を知っていて、見直しは「その実態を契約に反映する」だけの話になります。更新のときに初めて記録を出すと、担当者は驚き、社内で説明する材料を一から集めることになります。

順番として、毎月の報告に工程ごとの稼働と範囲の変化を一行入れ、更新の二か月前に一期分をまとめ、一か月前に文面で出す。この順番なら、更新の話は交渉ではなく確認になります。エラベルでは、依頼側と担当者の間で範囲と稼働のずれが出たとき、更新を待たずに窓口が確認に入る形を取っています。ずれは小さいうちに直すほうが、双方の負担が小さく、更新のときに大きな見直しをせずに済みます。毎月の報告の形は[報告のしかた](/media/fukugyo-houkoku/)に整理しています。

## まとめ

- 更新は**依頼側も見直す時期**で、記録が揃い、契約書を書き直せる。条件を直す機会として使う
- 見直しは**範囲→稼働→単価**の順。単価は結果として出す。単価だけを持ち出さない
- 根拠は**工程ごとの稼働時間・増えた工程・報告の記録・結果の記録・依頼側の評価**。記憶ではなく記録
- 出すのは**更新の一か月前に文面で**。二か月前にまとめ、二週間前に一度だけ確認、直前に契約書を確認
- 依頼側から求められても**単価だけを動かさない**。「単価を下げるなら範囲か稼働を減らす」
- 折り合わなければ**据え置きで範囲も広いまま**は受けない。範囲を戻すか単価を直すかのどちらかを取る。契約の解釈は専門家に

## よくある質問

### 最初の契約から範囲が広がっていますが、依頼側は気づいていないようです

気づいていないのではなく、記録として見ていないことが多いです。更新の見直しで急に出すと驚かれるので、まず次の月の報告から「今月は〇〇の工程が加わり、稼働がこれだけになりました」と一行入れます。数か月それを続けてから更新の見直しを出すと、担当者は実態を知った状態で判断できます。更新まで時間が無い場合は、見直しの文面に「これまでの報告で触れていなかった点も含めて整理しました」と添え、記録を一期分並べます。

### 単価を上げたいのですが、範囲も稼働も変わっていません

範囲も稼働も変わっていない場合、単価を上げる根拠は、結果の変化か、自分の市場での単価の変化になります。結果の変化があれば、それを根拠に出せますが、依頼側は「結果は依頼側の条件も関係する」と見るので、通りにくいことがあります。市場の変化を根拠にするのは、依頼側にとって説明しにくい話です。範囲か稼働のどちらかに変化を作り、それを根拠にする形のほうが、通りやすい傾向があります。値上げの時期の考え方は[値上げを申し出るタイミング](/media/fukugyo-neage-timing/)に書いています。

### 仲介サービスや窓口を通した案件で、条件の見直しは誰に出しますか

窓口を通します。依頼側との契約が窓口と依頼側の間にある場合、担当者が依頼側に直接条件の話をすると、窓口の契約と食い違います。窓口に、範囲・稼働・単価の見直しの内容を、記録と一緒に出し、窓口が依頼側と話す形になります。窓口によっては、条件の見直しの時期や手順が決まっているので、更新の二か月前に窓口に確認しておくと、時期を外しません。
