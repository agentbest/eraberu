JAC Recruitmentについて「運用代行」を調べている場合、言葉の当てはめ方から確かめる必要があります。この会社は人材紹介のサービスで、採用担当者様向けのページには候補者データベースの検索やスカウト送信についての記載がありません。企業が日々回す運用が無いので、その運用を外に出すという形にはなりません。代わりに考えるのは、採用の工程のうちどこが紹介で埋まり、どこが空くのかという整理です。この記事では工程を並べて、空いた部分をどう埋めるかを順に書きます。以下は2026年10月16日時点で公式サイトに記載されている内容に基づいています。

## 工程を並べて、紹介が埋める部分を見る

採用の工程を十に分けて、紹介で埋まるかどうかを並べます。体制としては、業界・職種別に編成された200以上の専門チームがあり、コンサルタントが直接会った候補者から提案する形で、企業と候補者の両方を同じコンサルタントが担当する両面型とされています。

| 工程 | 紹介で埋まるか |
|---|---|
| 採用計画と人数の決定 | 埋まらない |
| 要件の決定 | 埋まらない |
| 要件の文書化 | 一部（相談はできる） |
| 候補者の探索 | 埋まる |
| 候補者への接触と動機づけ | 埋まる |
| 推薦の受け取りと一次整理 | 埋まらない |
| 面接の日程調整 | 一部（調整の連絡は入る） |
| 会うかどうかの判断 | 埋まらない |
| 条件の提示と交渉 | 一部（交渉の仲介は入る） |
| 入社後のオンボーディング | 埋まらない |

埋まるのは候補者の探索と動機づけです。累計43万件以上の採用を支援し、約14,000社の採用課題に応えてきたとされる体制で、国内13ヵ所の拠点と海外10ヵ国に拠点があります。つまり、接点を作る部分が強い一方、自社の中で決める工程はそのまま残ります。

## 紹介では埋まらない工程

表で「埋まらない」とした工程を見ると、共通点があります。どれも自社の判断か、自社の中の作業です。

- 採用計画と人数、要件の決定
- 推薦の受け取りと一次整理
- 会うかどうかの判断
- 入社後のオンボーディング

このうち、判断を伴わないのは二つ目だけです。推薦を受け取って、要件に対して何が合っていて何が足りないかを並べる作業は、基準があれば誰でもできます。ここは外に出せます。一方で、足りない部分を許容するかどうかの判断は社内に残ります。整理と評価を分けておくと、外に出す範囲が決まります。運用の進め方は[スカウト運用設計の記事](/media/scout-jac-unyou-sekkei/)に時期ごとにまとめています。

### エラベルの見解

紹介を使っている会社で詰まるのは、ほぼ決まって推薦の受け取りから面接までのあいだです。探索と動機づけは紹介側が担うので、候補者は用意されます。そこから先、推薦を読んで判断し、日程を出すところが社内の手で止まります。相談で多いのは、月に十件の推薦が届いているのに、面接に進んだのが二件で、残り八件の返答が二週間止まっていた、という形です。これは要件の問題ではなく、受け取る体制の問題です。改善の順番としては、見送りの基準を文章にして、基準で判断できるものは現場に回さず一次判断で返す。これだけで返答の速さが変わります。外に出すなら、ここの整理を任せるのが最も効きます。

## JAC RPO はどこを埋めるか

同社はJAC RPOという採用代行のサービスを持っています。採用計画の立案から候補者の獲得、選考、入社に至るまで採用活動のすべてのプロセスを一貫して支援し、入社後のオンボーディングまでを含めた包括的な支援を提供するとされています。単なる採用業務の代行ではなく、採用プロセスそのものを最適化することを重視するという説明です。

つまり、先の表で「埋まらない」とした工程の多くに手が入る形です。対象はミドル・ハイクラスのマネジメント層、業界スペシャリスト、グローバル人材で、ヘルスケア、製造、IT、Web、コンサルティング、エネルギーなど幅広い業界に対応し、中途採用から新卒採用までとされています。紹介で候補者を受けるのか、進め方そのものを整えるのかで、選ぶものが変わります。候補者が足りないなら紹介、社内に進め方が無いならRPO、という分かれ方です。料金の記載はないので、範囲と費用は商談で確認してください。

## 社内に残す判断と、残すべき記録

どちらを使う場合でも、社内に残すものがあります。判断としては三つです。

1. 要件の中身（必須を三つに絞り、譲れる経験を決める）
2. 会うかどうかの基準（確認するだけで判断できる形にする）
3. 提示できる条件の上限と、その決裁者

記録としては二つです。推薦ごとの返答した日と結果、そして見送りの理由です。推薦の履歴は紹介会社側にありますが、なぜ見送ったのかという判断の記録は自社で残さないと消えます。これが残っていないと、三か月後に要件を直すときの材料がありません。分類は、経験が足りない、年収が合わない、勤務地が合わない、面接で合わなかった、という短い形で構いません。件数を数えると直す場所が見えます。測り方は[推薦の指標の見方](/media/rpo-jac-henshinritsu/)に整理しています。

### エラベルの見解

相談で多い思い込みは、紹介会社に頼めば採用が進むというものです。実際には、候補者が用意されたあとに社内で止まるかどうかで結果が分かれます。止めないために要るのは、見送りの基準と、面接に出せる人の時間です。どちらも費用では増えません。エラベルは採用代行会社ではなく担当者を選べる窓口なので、経歴を見てから誰に任せるかを企業が決める形にしています。契約は担当者ご本人または所属先と企業のあいだで直接結んでいただき、エラベルへお支払いいただくのは採用が1名決まったときの10万円（税別）だけです。紹介を使いながら、受け取る側の実務を人に任せるという組み合わせもあります。埋まらない工程のうち、判断を伴わない部分を誰が担うかを決めてください。

## まとめ

- 企業が日々回す運用が無いので、運用を外に出すという形にはならない
- 紹介で埋まるのは候補者の探索と動機づけ。自社の中で決める工程は残る
- 残る工程のうち、推薦の受け取りと一次整理だけは基準があれば外に出せる
- JAC RPOは採用計画から入社・オンボーディングまでを含むため、埋まる範囲が広い
- 要件、会うかどうかの基準、条件の決裁は社内に残し、見送り理由の記録を自社で残す

## よくある質問

### Q. JAC Recruitmentに運用代行を頼めますか

人材紹介のサービスなので、企業が回す運用を代行するという形ではありません。同社はJAC RPOという採用代行のサービスを持っており、採用計画の立案から候補者の獲得、選考、入社、オンボーディングまでを一貫して支援するとされています。範囲と費用は商談で確認してください。

### Q. 紹介とJAC RPOは、どちらを選べばよいですか

候補者が足りないなら紹介、社内に採用の進め方そのものが無いならRPOという分かれ方です。両方を使う形が可能かも含めて、範囲を文書で確認してから決めてください。

### Q. 外部の代行会社に任せられるのはどこですか

推薦の受け取りと一次整理、面接の日程調整、要件の文書化、見送り理由の記録と振り返りの整理です。会うかどうかの判断と条件の決定は社内に残します。整理と評価を分けておくと、任せる範囲が決まります。
