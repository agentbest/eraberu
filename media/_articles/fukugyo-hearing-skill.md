依頼側との初回の打ち合わせで、聞くべき項目は聞いたはずなのに、後から「そういう事情があったのか」と分かることが続く。候補者との面談でも、話は聞けているが、辞退の本当の理由は分からないまま終わる。ヒアリングが弱いと感じるが、何を変えればよいのか。結論を先に書くと、**ヒアリング力は、質問の数や項目の網羅で決まるのではなく、「事実と解釈を分けて聞く」「答えを聞いたら記録で確かめる」「相手が言わなかったことを次に聞く」「聞いた内容をその日に一枚に戻す」の四つの習慣で磨かれます。**項目の一覧を埋めるヒアリングは、相手の解釈を集めるだけで、事実に届きません。四つの習慣を案件ごとに繰り返すと、聞き漏らしは減り、聞いた内容が依頼側と自分の共有の事実になります。ヒアリングで押さえる項目は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、初回の打ち合わせの進め方は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に、現状の把握は[現状把握のしかた](/media/fukugyo-genjou-haaku/)にまとめています。

## ヒアリングが弱いと感じる場面

弱さを感じる場面を並べると、共通の原因が見えます。

| 場面 | 何が起きているか |
|---|---|
| 初回の打ち合わせで項目は聞いたのに、後から事情が分かる | 相手の「解釈」を聞いて、「事実」を確かめていない。「応募が少ない」を聞いて、記録の応募数を見ていない |
| 依頼側の担当者の話が長く、要点が分からない | 相手の話を、工程や範囲の枠に当てはめて聞いていない |
| 候補者の辞退の理由が「他社に決まった」しか分からない | 言われたことをそのまま受け取り、言わなかったこと（なぜ他社を選んだか）を聞いていない |
| 聞いたことを、後で思い出せない | その日に記録に戻していない |
| 同じことを二度聞いてしまう | 記録が無く、前に聞いたことを見返していない |
| 相手が「特に問題ない」と言い、それ以上聞けない | 「問題ない」の中身（何を問題と思っていないか）を確かめていない |
| 聞いた内容が、依頼側の認識とずれていた | 聞いた内容を相手に戻して、確認していない |

場面の要点は、「相手の言葉を、そのまま事実として受け取っている」ことです。相手が言うことは、相手の解釈で、事実とは限りません。「応募が少ない」は解釈で、記録の応募数が事実です。「他社に決まった」は理由の表面で、なぜ他社かが中身です。解釈を事実と取り違えると、後から「そういう事情が」となります。

## 弱さの正体は、質問の数ではない

ヒアリングが弱いと感じると、質問を増やそうとしますが、増やしても弱さは消えません。

| 増やしても効かない理由 | 内容 |
|---|---|
| 項目を埋めることが目的になる | 一覧を上から聞いていくと、答えを埋めることに意識が向き、答えの中身を考えなくなる |
| 相手が疲れる | 質問が多いと、相手は「尋問」と感じ、答えが短くなる |
| 解釈が増えるだけ | 質問を増やしても、返ってくるのは相手の解釈で、事実は増えない |
| 言わなかったことは、質問の数では出てこない | 相手が言わないことは、聞き方を変えないと出てこない |
| 記録に戻さなければ、聞いた量に関わらず残らない | 聞いた量が多いほど、記録に戻すのが重くなり、戻さなくなる |

正体の要点は、「弱さは、聞く量ではなく、聞いた後の扱いにある」ことです。聞いたことを、事実と解釈に分け、記録で確かめ、言わなかったことを次に聞き、一枚に戻す。この扱いが無いと、質問をいくら増やしても、ヒアリングは弱いままです。項目の一覧は、[ヒアリングで押さえる項目](/media/fukugyo-hearing/)にありますが、一覧は「何を聞くか」で、「どう扱うか」は別です。

### エラベルの見解

相談で最も多い思い込みは、「ヒアリングが上手い人は、質問が上手い人だ」というものです。実際には、依頼側の状況を正確に把握している担当者を見ると、質問が特別に上手いわけではありません。共通しているのは、相手の答えを聞いた後に「それは記録で確かめられるか」と考え、確かめていることです。「応募が少ない」と聞けば、「ATSで応募数を見せていただけますか」と続ける。「返信が来ない」と聞けば、「媒体の管理画面の送信と返信の数を見せていただけますか」と続ける。答えを記録で確かめる習慣が、ヒアリングの精度を決めています。

見ていて差がつくのは、打ち合わせの後、その日のうちに聞いた内容を一枚に戻し、相手に「このように理解しました」と送っているかです。送っている人は、相手から「そこは違う」「それに加えて」と返事が来て、聞き漏らしとずれが、その日のうちに埋まります。送っていない人は、聞いたつもりの内容と相手の認識がずれたまま進み、数週間後に「そういう事情が」と分かります。エラベルでは、担当者が依頼側との打ち合わせの後に、聞いた内容を一枚に戻して共有する形をお願いしています。ヒアリングは、聞く場面ではなく、聞いた後の扱いで決まります。

## 磨くための四つの習慣

四つの習慣を、案件ごとに繰り返します。どれも、一回の打ち合わせの中と直後でできます。

| 習慣 | 内容 | いつ |
|---|---|---|
| 一、事実と解釈を分けて聞く | 相手の答えを「事実（記録で確かめられること）」と「解釈（相手の感じ方や見立て）」に分けて受け取る。解釈には「それはどの記録で分かりますか」と続ける | 打ち合わせの中 |
| 二、答えを聞いたら記録で確かめる | 解釈として聞いたことを、依頼側の記録（ATS、媒体の管理画面）で確かめる。合っていれば事実、違っていれば記録を相手に見せる | 打ち合わせの中か直後 |
| 三、相手が言わなかったことを次に聞く | 相手の話に出てこなかった工程、人、時期を、一枚に戻すときに見つけ、次の打ち合わせで聞く | 一枚に戻すとき、次の打ち合わせ |
| 四、聞いた内容をその日に一枚に戻す | 打ち合わせの当日に、聞いた内容を工程と範囲で整理した一枚にし、相手に「このように理解しました」と送る | 打ち合わせの当日 |

四つの要点は、「四」の一枚に戻すことが、他の三つを動かすことです。一枚に戻すと、事実と解釈が分かれていないことに気づき、記録で確かめていないことに気づき、言わなかったことが空欄として見えます。一枚に戻さなければ、三つは頭の中で曖昧なまま消えます。一枚の形は、議事録と同じで足ります。議事録の型は[議事録の残し方](/media/fukugyo-gijiroku/)に書いています。

## 事実と解釈を分ける聞き方

「一」の、事実と解釈を分けて聞く具体です。相手の言葉を、二つに仕分けます。

| 相手の言葉 | 事実か解釈か | 続ける問い |
|---|---|---|
| 「応募が少ない」 | 解釈 | 「先月の応募数は、記録ではどのくらいでしたか」 |
| 「先月の応募は〇件だった」 | 事実 | 「その前の月は」（比較の起点） |
| 「候補者の質が低い」 | 解釈 | 「書類で通過しなかった理由で、多かったのは何ですか」 |
| 「面接官が忙しくて日程が組めない」 | 解釈（半分事実） | 「提示から確定まで、平均でどのくらいかかっていますか」 |
| 「前の担当者は良くなかった」 | 解釈 | 「前の担当者の範囲は何で、どこで困りましたか」 |
| 「うちは採用が難しい業界だ」 | 解釈 | 「難しいと感じるのは、どの工程ですか」 |
| 「早く決めたい」 | 解釈（期待） | 「いつまでに、何名の想定ですか」 |

分け方の要点は、「解釈を否定せず、事実に続ける」ことです。「応募が少ない」を「本当ですか」と疑うと、相手は構えます。「記録ではどのくらいでしたか」と続ければ、相手は記録を見に行き、事実が出てきます。解釈は、相手が困っている場所を示す手がかりで、事実は、その困りごとの中身です。両方を聞き、分けて記録します。事実の集め方は[現状把握のしかた](/media/fukugyo-genjou-haaku/)に、事実から課題を構造にする方法は[課題を構造化する](/media/fukugyo-kouzou-ka/)に整理しています。

## 言わなかったことの見つけ方

「三」の、相手が言わなかったことを見つける方法です。言わなかったことは、聞き方を変えないと出てきません。

| 見つけ方 | 内容 |
|---|---|
| 工程で空欄を見る | 聞いた内容を工程（母集団→反応→書類→日程→面接→内定→承諾）に当てはめ、話に出てこなかった工程を見つける。出てこなかった工程は、相手が見ていないか、問題無いと思っているか |
| 人で空欄を見る | 話に出てきた人（担当者、面接官、経営者、現場）と、出てこなかった人を見る。出てこなかった人が、判断や遅れに関わっていることがある |
| 時期で空欄を見る | 「今」の話は出ても、「いつから」「以前は」が出てこないことが多い。比較の起点が無い |
| 「問題ない」の中身を聞く | 「特に問題ない」と言われた工程について、「その工程の数字は、記録ではどうですか」と、記録で確かめる |
| 候補者の側から見る | 依頼側の話は依頼側の側からで、候補者の側から見た話（なぜ辞退したか、何を不安に思ったか）は出てこない。辞退の理由の記録を見る |
| 前任や過去の施策を聞く | 「以前に試したこと」は、聞かないと出てこない。試して効かなかったことを知らずに、同じ提案をすることを防ぐ |

見つけ方の要点は、「工程で空欄を見る」ことです。相手は、困っている工程の話を長くし、困っていない（と思っている）工程の話をしません。一枚に戻すとき、工程の枠に当てはめれば、空欄の工程が見え、そこを次に聞けます。空欄の工程に、実は最も大きな落ち幅があることも珍しくありません。工程の型は[課題を構造化する](/media/fukugyo-kouzou-ka/)に書いています。

## 聞いた内容を戻す一枚

「四」の、聞いた内容をその日に戻す一枚の形です。相手に送り、認識を揃えます。

| 項目 | 内容 |
|---|---|
| 事実（記録で確かめたこと） | 工程ごとの数字、体制、時期。出どころを添える |
| 解釈（相手の見立て） | 相手が困っていると言ったこと、原因と思っていること。「〇〇さんの見立てとして」と分ける |
| まだ確かめていないこと | 解釈として聞いたが、記録で確かめていないこと。次に確かめる |
| 言わなかったこと（空欄） | 工程・人・時期で、話に出てこなかったこと。次に聞く |
| 自分の理解 | 「このように理解しました。違う点があればお知らせください」 |
| 次の打ち合わせで聞くこと | 空欄と、確かめていないことの一覧 |

一枚の要点は、「事実と解釈を分けて書く」ことです。分けて書いて相手に送ると、相手は「これは事実で、これは自分の見立てだ」と自分でも整理でき、「見立てのほうは、記録で確かめたほうがよいですね」となることがあります。一枚は長くせず、議事録に添える形で足ります。送るときの形は[メールの書き方と運用](/media/fukugyo-mail/)に、認識を揃える意味は[期待値のずれ](/media/fukugyo-shippai-1/)に整理しています。

## 案件ごとに振り返る形

四つの習慣は、案件ごとに振り返ると、次の案件で精度が上がります。

| 振り返ること | 内容 |
|---|---|
| 後から分かった事情は何か | 案件の途中で「そういう事情が」と分かったことを書き出す。初回に聞けなかった理由（解釈のまま受け取った、空欄を見なかった）を見る |
| 記録で確かめて、解釈と違っていたものは何か | 相手の解釈と記録がずれていた例。次の案件で、同じ種類の解釈は最初から記録で確かめる |
| 空欄になりやすい工程はどこか | 自分が聞き漏らしやすい工程や人や時期。次の案件で、最初から聞く項目に足す |
| 一枚に戻して、相手から訂正が来たものは何か | 自分の理解がずれやすい場所。次の案件で注意する |
| 候補者から聞けなかったことは何か | 辞退の理由の中身など、聞けなかったこと。聞き方を変える |
| 自分の聞く項目の一覧を更新する | 振り返りで見つかったことを、次の案件の一覧に足す |

振り返りの要点は、「後から分かった事情を、初回に聞けなかった理由まで見る」ことです。「聞き漏らした」で終わらせず、「解釈のまま受け取った」「その工程を空欄のままにした」と理由を見れば、次の案件で同じ漏らし方をしなくなります。振り返りの記録は、依頼側の情報を抜いて、自分の側に残します。自分の型の育て方は[事例を流用しない](/media/fukugyo-jirei-ryuuyou/)に書いています。

### エラベルの見解

担当する側から見ると、依頼側の状況を正確に把握している人は、質問の数が多い人ではなく、聞いた後の扱いが決まっている人です。相手の答えを事実と解釈に分け、解釈は記録で確かめ、一枚に戻して相手に送り、空欄を次に聞く。この流れが習慣になっているので、初回の打ち合わせで全部を聞けなくても、数回で依頼側の状況が事実として揃います。質問を増やそうとしている人は、一回で全部を聞こうとして、解釈を大量に集め、事実に届いていません。

順番として、打ち合わせの中で解釈を事実に続けて聞き、直後に記録で確かめ、当日に一枚に戻して送り、返事で訂正を受け、空欄を次に聞き、案件の終わりに後から分かった事情を振り返る。この順番を案件ごとに繰り返すと、ヒアリングは磨かれます。エラベルでは、担当者が依頼側との打ち合わせの後に一枚に戻して共有する形をお願いしていますが、それはヒアリングの精度を上げる最も簡単な習慣だからです。ヒアリング力は、聞く技術ではなく、聞いた後の扱いです。

## まとめ

- ヒアリング力は**質問の数ではなく、聞いた後の扱い**で決まる。項目を埋めても、解釈が集まるだけ
- 四つの習慣は**事実と解釈を分けて聞く・答えを記録で確かめる・言わなかったことを次に聞く・その日に一枚に戻す**
- 解釈は**否定せず、事実に続けて聞く**。「記録ではどのくらいでしたか」
- 言わなかったことは**工程・人・時期の空欄**で見つける。「問題ない」は記録で確かめる
- 一枚は**事実と解釈を分けて書き、相手に送り、訂正を受ける**
- 案件ごとに**後から分かった事情を、聞けなかった理由まで振り返り、次の一覧に足す**

## よくある質問

### 依頼側の担当者が忙しく、打ち合わせの時間が短いです

短い時間なら、聞く項目を絞り、記録で確かめられることは打ち合わせで聞かず、記録を見せてもらうことで代えます。「応募数と返信数は、ATSと管理画面を見せていただければ自分で確認します」と伝え、打ち合わせでは記録に無いこと（体制、判断の所在、困っていること）だけを聞きます。聞いた内容は当日に一枚に戻し、空欄は文面で聞けば、打ち合わせの時間は短くて済みます。短い定例の使い方は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に整理しています。

### 候補者から辞退の本当の理由を聞き出せません

候補者は、断る相手に本当の理由を言いにくいので、「他社に決まった」で終わることが多いです。聞き出そうとするより、辞退の連絡への返信で「今後のために、差し支えなければ、決め手になった点を一つだけ教えていただけますか」と、一つだけ、任意で、短く聞きます。返ってこなくても追わず、返ってきたものを記録に残します。数件溜まると、傾向が見えます。候補者への接し方は[候補者への対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

### 一枚に戻して送っても、依頼側から返事が来ません

返事が無いことは、「違いが無い」と受け取って構いませんが、最初の打ち合わせで「一枚に戻して送ります。違いがあればお知らせください。無ければそのまま進めます」と伝えておくと、返事が無いことが合意の形になります。返事が無いまま進めて後でずれが分かった場合は、「〇日にお送りした内容で進めていました」と示せます。それでも大きな空欄がある場合は、次の定例で口頭で聞きます。返事の扱いは[議事録の残し方](/media/fukugyo-gijiroku/)に整理しています。
