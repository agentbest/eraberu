副業では、本業の時間に返せないので、返信が遅れる。依頼側から「連絡が遅い」と思われていないか不安になる。速さは、日中に返せない副業では担保できないのか。結論を先に書くと、**連絡の速さは、「早く返すこと」ではなく、「いつ返るかが依頼側に分かっていて、その通りに返ること」で担保します。依頼側が「遅い」と感じるのは、返るまでの時間の長さではなく、いつ返るか分からず待たされることです。「稼働時間に一度まとめて返す」「返す時刻を予告する」「翌日に依頼側が動ける材料を先に渡す」の三つを揃えれば、日中に返せなくても、依頼側は「速い」と感じます。速さは、反応の早さではなく、予測できることです。**平日日中の連絡の扱いは[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)に、打ち合わせの時間帯は[打ち合わせの時間帯の決め方](/media/fukugyo-kaigi-jikan/)に、連絡手段の分け方は[連絡手段の分け方](/media/fukugyo-mail/)にまとめています。

## 速さの正体

依頼側が「速い」「遅い」と感じる正体を見ます。反応の時間の長さではありません。

| 依頼側が「遅い」と感じる | 依頼側が「速い」と感じる |
|---|---|
| いつ返るか分からず、待っている | いつ返るか分かっていて、その時刻に返る |
| 返ってきても、中身が「確認します」だけで、また待つ | 返ってきたときに、判断か次の動きが入っている |
| 返る日と返らない日がある | 毎回同じ時刻に返る |
| 急ぎと言ったのに返らない | 急ぎの定義が合っていて、急ぎは決めた経路で返る |
| 依頼側が次に何をすればよいか分からず止まる | 依頼側が自分で動ける材料が先に渡されている |
| 返信が来るまで、依頼側の作業が止まる | 返信を待たずに依頼側が動ける形になっている |

正体の要点は、「待たされること」と「止まること」が、遅さの正体だということです。夜に返っても、依頼側が「夜に返る」と分かっていて、返信に判断が入っていて、翌日に動ける材料があれば、依頼側は待たされず、止まりません。逆に、日中に「確認します」とだけ返しても、依頼側は待たされ、止まります。速さは、反応の時間ではなく、依頼側が待たず止まらないことです。判断の入れ方は[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に書いています。

## 依頼側が速いと感じる三つの条件

日中に返せない担当者が、依頼側に「速い」と感じてもらう条件は三つです。

| 条件 | 内容 | 依頼側の感じ方 |
|---|---|---|
| 一、返る時刻が決まっていて、その通りに返る | 「連絡は毎日二十一時までに返します」と決め、毎日その時刻までに返す | 「夜には返る」と分かり、待たされない |
| 二、返信に判断か次の動きが入っている | 「確認します」ではなく、「〇〇で進めます」「AかBか、〇日までにご判断ください」 | 一往復で進み、また待つことがない |
| 三、翌日に依頼側が動ける材料が先に渡されている | 「明日、候補者から返信があれば、△△と返してください」と、翌日の日中の動きを夜のうちに渡す | 日中に担当者がいなくても、依頼側が止まらない |

三つの要点は、「一」の、返る時刻を決めて守ることが、全部の土台だということです。時刻が決まっていれば、依頼側は待たず、その時刻に合わせて自分の作業を組みます。時刻が決まっていても守れなければ、「決まっていない」のと同じです。「二十一時までに」と決めたら、二十一時までに返す。返せない日は、その前に「今日は返せません。明日の朝に」と一言送る。守ることで、時刻の約束が信用になります。稼働時間の固定は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、翌日の材料の渡し方は[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)に整理しています。

### エラベルの見解

担当する側から見ると、依頼側から「連絡が速い」と評価されている担当者は、日中に返している人ではありません。日中に返せないが、毎晩同じ時刻に返り、返信に判断が入っていて、翌日に依頼側が動ける材料を渡している人です。依頼側は、日中に担当者がいないことを不便と感じておらず、「夜に返れば全部進む」と感じています。逆に、日中に返すが「確認します」だけの担当者は、反応は早いのに「遅い」と評価されています。

見ていて差がつくのは、返せない日に、返せないことを先に送っているかです。毎晩二十一時に返すと決めていても、体調や家族の事情で返せない日はあります。その日に、二十一時を過ぎてから黙っていると、依頼側は「今日は返らない」と気づくまで待ちます。「今日は返せません。明日の朝に返します」と、返せないと分かった時点で一言送っている担当者は、返せない日でも、依頼側を待たせていません。エラベルでは、依頼側が担当者を選ぶ仕組みなので、連絡の時刻を明確にし、守っている担当者が、依頼側から続けて選ばれています。速さは、返る時刻の約束と、その約束を守ることです。

## 返信の時刻を固定する方法

返信の時刻を固定し、守る方法です。

| 方法 | 内容 |
|---|---|
| 毎日の返信の時刻を一つ決める | 「毎日二十一時までに」。稼働の時間帯の終わりに置く |
| 稼働しない日を決め、その日は返らないと伝える | 「水曜と日曜は返しません。翌稼働日に返します」 |
| 返信の時刻を契約に入れる | 「連絡への返信は、稼働日の二十一時までに」 |
| 稼働の開始時に、連絡を全部読んで優先順位をつける | 返す前に全部を読む。優先順位の高いものから |
| 返信に、判断か次の動きを入れる | 「確認します」で終わらせない |
| 返せない日は、返せないと分かった時点で一言 | 「今日は返せません。明日の朝に」 |
| 週に一度、返信の時刻を守れたかを見る | 守れなかった日が続くなら、稼働の枠か案件の数を見直す |

方法の要点は、「返信の時刻を、稼働の時間帯の終わりに置く」ことです。稼働の始めに置くと、返信に時間を取られ、作業の時間が減ります。稼働の中で作業を進め、終わりに返信をまとめれば、作業の結果を返信に入れられ、「確認します」ではなく「対応しました」と返せます。返信の時刻は、稼働の終わりに固定します。稼働の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、契約への入れ方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## 返せないときの一言の型

返せない日、遅れる日に送る一言の型です。型があれば、その場で考えずに送れます。

| 場面 | 一言 |
|---|---|
| 今日の稼働ができない | 「本日は稼働できません。連絡は明日〇時までに返します」 |
| 返信が予定の時刻に間に合わない | 「本日の返信は〇時までかかります。お待たせしてすみません」 |
| 判断に時間がかかる | 「〇〇の件、判断に材料が要るので、△日までに返します。それまでに□□を確認します」 |
| 依頼側の判断待ちで自分が止まっている | 「〇〇の件、御社のご判断をお待ちしています。〇日までにいただければ、△日に進めます」 |
| 稼働しない日に連絡が来た | （返さない。事前に「稼働しない日は返しません」と伝えてある） |
| 数日止まる | 「〇日から△日まで稼働できません。進行中の□□は、〇〇の状態です。急ぎは電話に」 |

型の要点は、「いつ返すか」を毎回入れることです。「遅れます」だけでは、依頼側はまた待ちます。「〇時までに」「△日までに」と時刻を入れれば、依頼側はその時刻まで待たず、自分の作業を組めます。遅れる連絡は、遅れることではなく、いつ返るかを伝えるためのものです。遅れの連絡は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、止まる日の伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

## 待たせない仕組み

返信の速さとは別に、依頼側を待たせない仕組みを作ります。仕組みがあれば、返信が要る場面そのものが減ります。

| 仕組み | 内容 | 減る連絡 |
|---|---|---|
| 翌日の材料を先に渡す | 夜の返信で、翌日の日中に起きそうなことへの対応を先に書く | 翌日の日中の「どうすればいいですか」 |
| 共有の文書に進捗と判断待ちを常に出す | 進捗、判断待ちの項目、次の動きを、共有の文書で常に見える形に | 「今どうなっていますか」 |
| 判断の型を依頼側に渡す | 「こういう場合はこうする」の型を、依頼側の社員が使える形に | 「この場合はどうすれば」 |
| 自動返信を設定する | 稼働しない日と時間帯に、「〇時までに返します」と自動で返る | 「見ていますか」 |
| 週の予定を先に共有する | 「今週は火曜に求人票、木曜にスカウト文面を出します」 | 「いつ出ますか」 |
| 急ぎの経路を一つ決める | 急ぎだけ電話。それ以外は夜 | 急ぎでない「急ぎ」 |

仕組みの要点は、「共有の文書に進捗と判断待ちを常に出す」ことです。依頼側の連絡の多くは、「今どうなっているか」「次に何をすればよいか」で、それが共有の文書で常に見えていれば、連絡そのものが要りません。返信の速さを上げるより、返信が要る場面を減らす方が、依頼側にとっては速く感じられます。共有の文書の作り方は[稼働ログの付け方](/media/fukugyo-log/)に、報告の頻度は[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/)に書いています。

## 速さが落ちる兆候と直し方

連絡の速さは、気づかないうちに落ちます。兆候と直し方です。

| 兆候 | 原因 | 直し方 |
|---|---|---|
| 返信の時刻を守れない日が週に何日もある | 稼働の枠が足りない。案件が多い | 枠を見直す。案件を減らす |
| 返信が「確認します」ばかりになっている | 稼働の中で作業が進んでいない。返信を稼働の始めにしている | 返信を稼働の終わりに。作業の結果を返信に入れる |
| 依頼側から「今どうなっていますか」が増えた | 共有の文書が更新されていない | 共有の文書を稼働のたびに更新する |
| 依頼側から日中に連絡が増えた | 翌日の材料を渡していない。急ぎの定義が崩れている | 夜の返信に翌日の材料を入れる。急ぎの定義を確認する |
| 返信を後回しにしたくなる | 疲れている。燃え尽きの兆候 | 休みを入れる。[燃え尽きを防ぐ](/media/fukugyo-burnout/) |
| 返せない日に一言を送り忘れる | 型が決まっていない | 一言の型を決め、送る習慣に |

兆候の要点は、「返信を後回しにしたくなる」が、疲れの兆候だということです。連絡の速さが落ちるとき、多くは稼働の枠か疲れの問題で、連絡の技術の問題ではありません。返信を後回しにしたくなったら、連絡の型を直すより先に、休みと枠を見ます。疲れの見分け方は[疲労とどう付き合うか](/media/fukugyo-tsukare/)に、枠の見直しは[長く続けるための設計](/media/fukugyo-choki/)に整理しています。

## 担保する順番

連絡の速さを担保する順番です。

| 順番 | 内容 |
|---|---|
| 一、返信の時刻を一つ決める | 稼働の時間帯の終わりに。「毎日二十一時までに」 |
| 二、稼働しない日と、急ぎの定義と経路を決める | 「水曜と日曜は返さない」「急ぎは採用が止まるもの。電話に」 |
| 三、契約の前に伝え、契約に入れる | 「返信は稼働日の二十一時までに。日中は返せません」 |
| 四、返信に判断か次の動きを入れる型を作る | 「確認します」で終わらせない |
| 五、翌日の材料を、夜の返信で先に渡す | 翌日の日中に依頼側が動ける形に |
| 六、共有の文書に、進捗と判断待ちを常に出す | 「今どうなっていますか」を減らす |
| 七、返せない日の一言の型を決める | 「今日は返せません。明日〇時までに」 |
| 八、週に一度、時刻を守れたかを見る | 守れていなければ、枠と疲れを見る |

順番の要点は、「一」から「三」を、契約の前に決めて伝えることです。契約の後に返信の時刻を決めても、依頼側は「日中も返る」と期待した後で、期待を変えるのは難しくなります。契約の前に、「返信は二十一時までに。日中は返せません」と伝え、その条件で受けられる依頼側と契約する。これが、連絡の速さを担保する土台です。契約前の伝え方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、信頼の積み方は[信頼を積む小さな行動](/media/fukugyo-shinrai/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「日中に返せない副業では、連絡の速さで評価されるのは無理だ」というものです。実際には、依頼側が「速い」と感じるのは、返るまでの時間ではなく、いつ返るか分かっていて、返信で進み、翌日に止まらないことです。日中に返せなくても、この三つがあれば「速い」と評価され、日中に返しても、「確認します」だけなら「遅い」と評価されます。速さは、反応ではなく、予測できることです。

順番として、返信の時刻を稼働の終わりに一つ決め、稼働しない日と急ぎの定義と経路を決め、契約の前に伝えて契約に入れ、返信に判断か次の動きを入れる型を作り、翌日の材料を夜の返信で先に渡し、共有の文書に進捗と判断待ちを常に出し、返せない日の一言の型を決め、週に一度時刻を守れたかを見る。この順番で、連絡の速さは「日中に返せないから無理なもの」から「時刻の約束で担保するもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、返信の時刻を明確にして守っている担当者が、日中に返せなくても依頼側から続けて選ばれています。速さは、早さではなく、約束です。

## まとめ

- 連絡の速さは**早く返すことではなく、いつ返るかが分かっていて、その通りに返ること**
- 依頼側が「遅い」と感じるのは**待たされることと止まること**。返る時間の長さではない
- 速いと感じる三つの条件は**返る時刻が決まっていて守られる・返信に判断か次の動きが入っている・翌日の材料が先に渡されている**
- 返信の時刻は**稼働の時間帯の終わりに固定**し、契約の前に伝えて契約に入れる
- 返せない日は**「いつ返すか」を一言で**。「遅れます」だけでは依頼側はまた待つ
- **共有の文書に進捗と判断待ちを常に出す**と、返信が要る場面そのものが減る。返信を後回しにしたくなったら疲れの兆候

## よくある質問

### 依頼側の担当者は日中に返信が欲しいようで、夜の返信では遅いと言われます

「夜に返る」だけでは、依頼側は日中に止まります。夜の返信に、翌日の日中に依頼側が動ける材料（「候補者から返信があれば△△と返してください」「面接官から質問があればこの資料を」）を入れ、共有の文書に進捗と判断待ちを常に出せば、依頼側は日中に担当者がいなくても止まりません。それでも日中の返信が要ると言われるなら、日中の即応が要る工程が自分に来ているので、その工程を依頼側の社員に持ってもらう相談をします。工程の分け方は[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)に整理しています。

### 複数の依頼側を持っていて、返信の時刻を守れなくなってきました

返信の時刻を守れないのは、稼働の枠に対して案件が多い合図です。返信の時刻を遅くするより、案件の数を減らすか、稼働の枠を広げるかを決めます。一時的に守れないなら、「今週は返信が〇時までかかります」と依頼側に先に伝えます。守れない状態を伝えずに続けると、時刻の約束そのものが信用を失います。案件の数は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、枠の見直しは[長く続けるための設計](/media/fukugyo-choki/)に書いています。

### 返信に判断を入れると言われても、判断は依頼側がするものではないですか

判断の所在は依頼側にあり、担当者が勝手に決めることではありません。「判断を入れる」とは、「自分の範囲の中で決められることは決めて報告する」と、「依頼側の判断が要ることは、選択肢と期限を添えて仰ぐ」の二つです。「確認します」は、どちらでもない返信で、依頼側は次に何が起きるか分かりません。「〇〇は私の範囲で△△と進めます」「□□は御社のご判断が要るので、AかBか〇日までに」と、範囲の内と外を分けて返します。判断の所在の守り方は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に、仰ぎ方は[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/)に整理しています。
