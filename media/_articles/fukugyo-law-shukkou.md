副業で人事を受けていると、グループ会社への出向や、関係会社への転籍の相談を受けることがあります。「出向」と「転籍」は日常の会話では混ざりますが、法的な扱いはまったく違います。特に転籍は、会社が一方的に命じられるものではありません。この記事は、出向と転籍の前提を、条文と厚生労働省の資料に沿って整理したものです。結論を先に書くと、**厚生労働省のパンフレットは、出向（在籍出向）を命ずるには、労働者に対して個別的な同意を得るか、出向先での賃金・労働条件、出向の期間、復帰の仕方などが就業規則等で労働者の利益に配慮して整備されているか、のいずれかを満たす必要があるとされている、と説明しています。そのうえで、労働契約法第14条は「使用者が労働者に出向を命ずることができる場合において、当該出向の命令が、その必要性、対象労働者の選定に係る事情その他の事情に照らして、その権利を濫用したものと認められる場合には、当該命令は、無効とする」と定めています。転籍（移籍出向）については、労働者本人の同意（合意）を要し、使用者は一方的に労働者に転籍を命ずることはできない（民法第625条第1項）、と説明されています。**個別の事案の判断は弁護士にご確認ください。配置転換は[配置転換の限界](/media/fukugyo-law-haichi-tenkan/)に、転勤は[転勤命令の有効性](/media/fukugyo-law-tenkin/)にまとめています。

## 出向と転籍の違い

| | 出向（在籍出向） | 転籍（移籍出向） |
|---|---|---|
| 元の会社との労働契約 | 残る | 終了する |
| 命じるための前提 | 個別的な同意を得る、または就業規則等で労働者の利益に配慮して整備されている | **労働者本人の同意（合意）を要する** |
| 一方的に命じられるか | 前提を満たす場合に命じ得るが、権利濫用に当たれば無効 | **一方的に命ずることはできない**（民法第625条第1項） |
| 復帰 | 復帰の仕方を定めておく | 元の会社には戻らない |

厚生労働省のパンフレットでは、出向（在籍出向）を命ずるには、次のいずれかを満たす必要があるとされている、と説明されています。

- 労働者に対して個別的な同意を得る
- 出向先での賃金・労働条件、出向の期間、復帰の仕方などが、就業規則等で、労働者の利益に配慮して整備されている

そのうえで、出向の命令は、使用者がその命令をできる場合でも、出向の必要性、対象労働者の選定に係る事情等に照らして、その権利を濫用したものと認められる場合には、その命令は無効となる、とされています。

転籍については、パンフレットは「転籍（移籍出向）は、労働者本人の同意（合意）を要し、使用者は一方的に労働者に転籍を命ずることはできません（民法第625条第1項）」と明記しています。

**実務での意味。**依頼先が「グループ会社に移ってもらう」と言うとき、それが出向なのか転籍なのかで、必要な手続がまったく変わります。まずここを確かめます。転籍であれば、本人の同意なしには進められません。

## 条文と、権利濫用の判断

**労働契約法第14条（出向）。**「使用者が労働者に出向を命ずることができる場合において、当該出向の命令が、その必要性、対象労働者の選定に係る事情その他の事情に照らして、その権利を濫用したものと認められる場合には、当該命令は、無効とする。」

条文は「その必要性」と「対象労働者の選定に係る事情」を明示しています。実務では、この二つを説明できる形にすることが中心になります。

**無効とされた裁判例。**厚生労働省のパンフレットには、出向命令が無効とされた裁判例として、一貫してデスクワークの仕事をしてきた労働者を、希望退職募集への応募の勧奨を断った段階で子会社に出向させて単純作業に従事させることは、退職勧奨を断った労働者が自主退職することを期待して行われたものであって業務上の必要性がなく、また人選の合理性も認めることもできないことから、権利の濫用として無効となる場合があるとする裁判例が紹介されています。

引用されている裁判例（東京地裁 平成25年11月12日判決）では、事業内製化による固定費の削減を目的とするものである限りは出向命令に業務上の必要性を認めることができるとしつつ、余剰人員の人選が基準の合理性、過程の透明性、人選作業の慎重さや緻密さに欠けていたこと、人選は事業内製化を一次的な目的とするものではなく退職勧奨の対象者を選ぶために行われたとみるのが相当であること、子会社における作業は立ち仕事や単純作業が中心で出向者には個人の机やパソコンも支給されていないこと、それまで一貫してデスクワークに従事してきた原告らのキャリアや年齢に配慮した異動とはいい難いこと等から、本件出向命令は人事権の濫用として無効というほかない、という内容が示されています。

パンフレットは、このような出向命令は、働く方々が安心して働ける職場環境という観点からは不適切であることから、出向を命ずるに当たっては、こうした裁判例や労働契約法第14条の規定を十分に踏まえた上で対応するように、としています。

### エラベルの見解

担当する側から見ると、出向で最も見落とされるのは「復帰の仕方」です。厚生労働省のパンフレットが、就業規則等で整備すべきものとして、出向先での賃金・労働条件、出向の期間と並べて「復帰の仕方など」を挙げているのは、そこが本人にとって最も大きい不安だからです。相談で見ていると、出向の規程に賃金の補填と期間は書いてあるのに、復帰の条件が書かれていない依頼先が多くあります。本人からすると、「いつ、どういう形で戻れるのか」が分からないまま送り出されることになります。

副業の人事が入るなら、規程の点検をここから始めます。出向の期間（原則の長さ、延長する場合の手続）、復帰の時期と条件、復帰後の処遇（等級、賃金、配属）、出向中の評価は誰がどう行うか、昇格の扱い、社会保険や労災の扱い。これを埋めると、出向は「送り出して終わり」ではなく制度になります。この整備は、グループ会社を持つ依頼先では繰り返し使われるので、一度作れば長く残ります。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、出向の規程の整備に関わった経験がある人は、そこを経歴に書いておくと選ばれます。

## 実務に落とす形

副業の人事が整えるのは、次の形です。命令の有効性や契約の適法性の判断は弁護士に渡します。

**出向（在籍出向）の場合。**

| 論点 | 整えること |
|---|---|
| 前提 | 個別的な同意を得るのか、就業規則等の整備に拠るのか |
| 規程の中身 | 出向先での賃金・労働条件、出向の期間、復帰の仕方。労働者の利益に配慮して整備されているか |
| 必要性 | なぜその出向が必要か、なぜその時期か（条文が「その必要性」を挙げている） |
| 人選 | 基準、当てはめの過程、記録（条文が「対象労働者の選定に係る事情」を挙げている） |
| 労働条件 | 出向中の賃金の負担、差額の補填、賞与、退職金の通算、休暇の扱い |
| 指揮命令と管理 | 出向元と出向先のどちらが何を持つか（勤怠、評価、安全衛生、ハラスメントの相談窓口） |
| 保険 | 労働保険・社会保険の扱い。手続の担当 |
| 本人への説明 | 内示の前に事情を聞く場、伝える内容、考える時間、相談の窓口 |
| 出向中 | 出向元の誰が定期的に本人と話すか。放置しない |
| 復帰 | 時期、条件、復帰後の処遇。決めておく |

**転籍の場合。**

本人の同意（合意）が前提です。実務としては、転籍後の労働条件（賃金、役職、勤務地、業務内容）、退職金や勤続年数の扱い、有給休暇の扱い、社会保険の手続を書面で示し、本人が検討する時間を確保します。会社が一方的に命じられるものではないので、同意が得られない場合にどうするかも、あらかじめ経営と整理しておきます。繰り返し面談して同意を迫る形は、別の問題を生みます。詳しくは[退職勧奨の進め方](/media/fukugyo-law-taishoku-kanshou/)に整理しています。転籍の条件と書面の内容は、弁護士や社会保険労務士にご確認ください。

**出向元と出向先の取り決め。**出向は、本人との関係だけでなく、会社間の取り決めも要ります。費用の負担、指揮命令の範囲、安全衛生や労災の扱い、ハラスメントが起きたときの対応、個人情報の扱い、期間と復帰。これを書面にしておくと、出向中に問題が起きたときに、どちらが対応するかで揉めません。

### エラベルの見解

外に出してよいのは、出向と転籍の区別の整理、規程の点検と条文の案、必要性と人選の説明の整理、労働条件と保険の扱いの一覧、出向元と出向先の取り決めの項目、本人への説明の設計、復帰の道筋の設計までで、「この出向命令は有効か」「この規程で要件を満たすか」「この転籍の条件でよいか」といった判断は、弁護士や社会保険労務士の範囲です。

担当する側から見ると、この領域で最も注意すべきは、出向が「辞めてもらうための手段」として使われようとする場面です。厚生労働省が引用する裁判例は、まさにその構図を問題にしています。退職勧奨を断った人を、キャリアと関係のない単純作業に就かせ、机もパソコンも与えない。形は出向でも、目的が別のところにあれば、後から実態が問われます。副業の人事は、「その出向先で、本人は何をするのか」「必要な設備はあるのか」「復帰の道筋はあるのか」を確かめる立場にいます。ここで立ち止まれるかどうかが、会社と本人の双方を守ります。エラベルでは、依頼側が担当者を選べるので、この問いを出せる人が、結果として長く関わっています。

## まとめ

- **出向（在籍出向）**を命ずるには、**労働者に対して個別的な同意を得る**か、**出向先での賃金・労働条件、出向の期間、復帰の仕方などが就業規則等で労働者の利益に配慮して整備されている**か、のいずれかを満たす必要があるとされている
- 労働契約法第14条は、出向の命令が**その必要性、対象労働者の選定に係る事情その他の事情**に照らして権利を濫用したものと認められる場合には**無効とする**、と定めている
- **転籍（移籍出向）は労働者本人の同意（合意）を要し、使用者は一方的に命ずることはできない**（民法第625条第1項）
- 退職勧奨を断った人を、キャリアに配慮しない単純作業に就かせる出向が**人事権の濫用として無効**とされた裁判例がある
- 規程で見落とされやすいのは**復帰の仕方**。期間、復帰の時期と条件、復帰後の処遇まで決めておく
- 出向元と出向先の間の取り決め（費用、指揮命令、安全衛生、ハラスメント、個人情報、期間）も書面にする。判断は弁護士にご確認ください

## よくある質問

### 「グループ会社に移ってもらう」と言われました。何から確かめますか

出向なのか転籍なのかを確かめます。元の会社との労働契約が残るなら出向、終了するなら転籍です。転籍であれば、厚生労働省のパンフレットが明記しているとおり、労働者本人の同意（合意）を要し、使用者は一方的に命ずることはできません。出向であれば、個別的な同意を得るのか、就業規則等の整備に拠るのかを確かめ、後者なら規程の中身（賃金・労働条件、期間、復帰の仕方）が整備されているかを点検します。判断は弁護士にご確認ください。

### 出向の規程はありますが、復帰について書かれていません

厚生労働省のパンフレットは、就業規則等で整備すべきものとして、出向先での賃金・労働条件、出向の期間と並べて「復帰の仕方など」を挙げています。復帰の条件が書かれていない規程は、この点が空いています。実務としては、出向の期間（原則の長さ、延長の手続）、復帰の時期と条件、復帰後の処遇（等級、賃金、配属）を追加する案を作り、就業規則の変更の手続は社会保険労務士に確認してもらいます。本人にとっては最も不安な部分なので、整備の優先度は高くなります。

### 本人が転籍に同意しない場合、どうなりますか

転籍は本人の同意（合意）を要するものなので、同意がなければ進められません。同意が得られなかった場合にどうするか（元の会社での配置を検討するのか、別の手段を検討するのか）を、あらかじめ経営と整理しておきます。繰り返し面談して同意を迫る形は、自由な意思決定を妨げる構図に近づき、別の問題を生みます。転籍後の条件を書面で示し、本人が検討する時間を確保する形にします。進め方と書面の内容は、弁護士や社会保険労務士にご確認ください。
