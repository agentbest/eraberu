中小企業診断士として、中小企業の経営を見てきた。事業の計画、財務、組織。人事の実務はしたことがないが、中小企業の経営者が「人が採れない」と言う場面に、何度も立ち会ってきた。この経験は、採用の副業で売れるのか。結論を先に書くと、**中小企業診断士の経験は、「採用を事業と経営の数字の中に置いて設計する」工程で売れます。売れるのは、「事業の計画と人員の計画の接続」「採用の投資の判断（費用対効果と優先順位）」「経営者への助言と対話」「補助や支援の制度の情報整理」の四つです。中小企業の採用は、経営者が「人が足りない」と感じてから場当たりに始まることが多く、事業の数字から採用を設計できる人が求められています。ただし、「診断します」という売り方では、採用の副業としては伝わりません。「経営者が採用に投資する判断を、数字で整える」と売ります。**経営者・役員の経験の売り方は[経営者・役員が副業でできること](/media/fukugyo-kigyou-keiei-fukugyo/)に、経営者直下の動き方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、数字の見せ方は[数字で語る](/media/fukugyo-suuji/)にまとめています。

## この経歴の何が売れるか

中小企業診断士の経験を、採用の工程に置き換えた棚卸しです。

| 診断士の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 事業の計画を読み、作ってきた | 事業の計画から、どの職種を、いつまでに、何人、どの順で採るかを引く | 「人が足りない」で採用が始まり、事業との接続が無い依頼側が多い |
| 財務の数字を見てきた | 採用の費用（媒体、紹介、代行、社員の工数）と、採れた場合の効果を、依頼側の数字で並べ、投資の判断を整える | 採用の費用が場当たりで、投資として見られていない依頼側が多い |
| 経営者と対話してきた | 経営者の「人が採れない」の奥にある、事業の課題と組織の課題を聞き出す | 採用の問題に見えて、事業か組織の問題である依頼側が多い |
| 補助や支援の制度を扱ってきた | 採用や雇用に関わる公的な支援や制度の情報を、依頼側が使えるかどうかの整理の入口として示す（内容と要件は、依頼側が公的な窓口と専門家に確認する） | 制度の存在を知らない依頼側が多い |
| 業界と地域の中小企業を見てきた | 同じ規模と業界の企業が、採用でどこで詰まり、どう抜けたかの型を持っている | 「うちの規模では無理」と感じている依頼側に、型を示せる |
| 組織の課題を診てきた | 採用の前に、配置と評価と定着で解ける課題を切り分ける | 採らなくても解ける課題を、採用で解こうとしている依頼側が多い |
| 報告書を作ってきた | 採用の状態と判断の材料を、経営者に伝わる形で報告する | 採用の報告が無い、または感覚で語られている依頼側 |

売れるものの要点は、「採用を、経営の数字の中に置ける」ことが価値だということです。中小企業の採用は、人事の担当者がいないことも多く、経営者が感覚で始め、費用が見えないまま続きます。事業の計画から人員の計画を引き、費用と効果を並べ、投資として判断できる形にする。この工程は、経営と財務を見てきた人にしかできません。採用の実務の経験が無くても、この工程で売れます。経営者への助言は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、課題の切り分けは[課題を構造化する](/media/fukugyo-kouzou-ka/)に書いています。

## 売りにくい点とその扱い

中小企業診断士の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 採用の実務を知らない | 「求人票やスカウトや面接の実務ができるのか」「人事の仕組みを知らないのでは」 | 範囲を、事業との接続、投資の判断、経営者への助言、制度の情報整理に絞る。実務は依頼側か実務の担当者が担う形に |
| 診断で終わる懸念 | 「診断の報告書をもらっても、採用が動かない」 | 診断ではなく、「経営者が判断できる形に整え、最初の判断まで一緒に行う」を範囲に入れる。判断が出るところまでを成果物に |
| 独占業務や資格の名称との線 | 「診断士として受けるのか、個人として受けるのか」「他の士業の領域に踏み込むのでは」 | 採用の副業は、診断士の資格に基づく業務としてではなく、経営と数字の経験を活かす個人の業務として受ける形が多い。労務や税や法の判断に踏み込まず、専門家に委ねる線を示す。資格の名称の使い方と業務の線は、資格の規範と専門家にご確認ください |

扱い方の要点は、「診断で終わらない」ことです。診断士の習慣で、診断の報告書を出して終わると、副業の依頼側では採用が動かず、「診断だけだった」と見られます。「事業の計画から人員の計画を引き、費用と効果を並べ、経営者が最初の判断（どの職種を、いつ、どの手段で）を下すところまで」を範囲に入れ、判断が出るところまでを成果物にします。労務、税、法の判断は、それぞれの専門家の領域なので踏み込まず、「専門家にご確認ください」と線を引きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、実務の学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に、資格の考え方は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に整理しています。

### エラベルの見解

担当する側から見ると、中小企業診断士から転身して続いている人と、一件で終わる人の差は、経営の知識の広さではなく、「診断の報告書で終わるか、経営者の判断が出るところまで行くか」です。一件で終わる人は、採用の課題を診断し、報告書にまとめ、依頼側の経営者は「よく分かったが、で、何をすれば」となり、採用が動きません。続いている人は、事業の計画から人員の計画を引き、費用と効果を依頼側の数字で並べ、「この職種を、この時期に、この手段で」という最初の判断を経営者と一緒に下し、その判断を実務の担当者に渡しています。

見ていて差がつくのは、採用の問題に見えるものを、採用以外で解けないかを先に見ているかです。「人が採れない」と言う依頼側の多くは、配置を変えれば足りる、評価を直せば辞めない、業務を減らせば要らない、という場合があり、それを見ずに採用を始めると、費用だけがかかります。診断士の経験で、採用の前に組織と業務を見て、「採らなくても解ける」を先に示せる人は、依頼側の経営者から「余計な費用を止めてくれた」と信用されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、採用を経営の数字で設計し、判断が出るところまでを担う担当者に、経営者が直接相談したい依頼側がついています。中小企業診断士の転身は、診断ではなく、判断で始まります。

## 案件の探し方

中小企業診断士から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 事業の計画と人員の計画の接続 | 事業の計画を読む経験で入れる | 「事業の計画から、どの職種を、いつ、何人、どの順で採るかを引く」を範囲の一言に |
| 採用の投資の判断の整理 | 財務の数字を見る経験で入れる | 「採用の費用と効果を、御社の数字で並べ、投資として判断できる形に」を示す |
| 経営者への定期の助言 | 経営者と対話してきた経験で入れる | 「月に一度、採用の判断の材料を整える相談の相手」の形で |
| 採用の前の、組織と業務の切り分け | 組織を診てきた経験で入れる | 「採らなくても解ける課題を先に切り分ける」を提案の形で |
| 制度の情報整理の入口 | 制度を扱ってきた経験で入れる | 「使える可能性のある支援の一覧と、確認先」を示す。内容と要件の確認は依頼側と専門家に |
| 経営者が直接担当する規模の依頼側 | 経営の判断の工程が判断につながる | 登録先で、人事の担当者がいない規模の依頼側を選ぶ |

探し方の要点は、「人事の担当者がいない規模の依頼側を選ぶ」ことです。人事の担当者がいる依頼側では、採用の工程が担当者の権限の中で回っていて、経営の数字から設計する工程が入りにくいです。人事の担当者がいない依頼側では、経営者が採用を自分で回していて、事業の数字から設計する助言がそのまま判断になります。診断士の経験が最も効く相手を選びます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、経営者との面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。中小企業診断士の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 経営の判断の工程であること | 実務の作業より、設計と判断の工程は価値で決まりやすい | 時間単価ではなく、設計の成果物か月額の顧問で受ける |
| 依頼側の規模が小さいこと | 人事の担当者がいない規模の依頼側は、予算が小さい | 月額を小さくし、範囲を絞る。回数で調整する |
| 採用の費用を減らす価値 | 採らなくても解ける課題を示し、費用を止めた価値は、依頼側にとって分かりやすい | 「止めた費用」を成果として示せる形にする |
| 診断士としての単価との比較 | 診断士の業務の単価と、採用の副業の単価は決まり方が違う | 診断士の単価を持ち込まず、採用の設計の工程の単価で |
| 実務を含めるか | 実務を含めると、実務の工程の単価が混ざる | 実務は分けて、依頼側か実務の担当者に |
| 契約の形 | 個人で受けるか、自分の事務所で受けるか。資格の名称を使うか | 契約と税と資格の名称の扱いが変わるため、専門家にご確認ください |

単価の要点は、「設計と判断の工程を、月額の顧問の形で受ける」ことです。事業と採用の接続、投資の判断、経営者への助言は、月に一度の対話で依頼側の採用の方向が決まる工程で、時間で測ると価値が測れません。月に何回、何時間、と枠を決めた月額の顧問の形か、設計一式の成果物の形で受け、実務は分けます。自分の事務所で受けるか、資格の名称を使うかは、契約と税と規範の扱いが変わるため、専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、法人で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)に整理しています。

## 始める順番

中小企業診断士から採用の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、これまで見てきた企業で「人が採れない」の奥にあった、事業と組織の課題を、企業の情報を含まない型で書き出す | 守秘の線を守った型 |
| 二、採用の副業を、診断士の業務としてではなく、経営と数字の経験を活かす個人の業務として受ける形を、専門家に確認する | 資格の名称と業務の線 |
| 三、労務、税、法の判断には踏み込まないと決め、専門家に委ねる線を自分の言葉で書く | 他の士業の領域との線 |
| 四、範囲を、事業との接続、投資の判断、経営者への助言、制度の情報整理の入口に絞る | 実務は依頼側か実務の担当者 |
| 五、「診断で終わらない」を範囲に入れる。経営者の最初の判断が出るところまで | 成果物の定義 |
| 六、「経営者が採用に投資する判断を、数字で整える」の一言を作る | 「診断します」とは言わない |
| 七、登録先に、範囲と規模を登録する | 人事の担当者がいない規模の依頼側を選ぶ |
| 八、月額の顧問か成果物で一件受け、最初の判断が出るところまでを担う | 判断を実務の担当者に渡す |

順番の要点は、「二」と「三」の、資格と他の士業との線を、始める前に専門家に確認しておくことです。診断士の資格の名称の使い方、採用の副業を診断士の業務として受けるかどうか、労務や税や法の判断に踏み込まない線は、資格の規範と個別の状況で変わります。始めてから問題になると、依頼側にも迷惑がかかります。専門家に確認し、自分の範囲を明確にしてから、案件を探します。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「中小企業診断士の経験は、経営の助言であって、採用の副業とは別物だ」というものです。実際には、中小企業の採用は、経営の判断が入らないまま場当たりに始まることが多く、事業の数字から採用を設計し、投資として判断できる形にする工程は、診断士の経験がそのまま活きる工程です。別物ではなく、経営の助言の中の、採用に絞った形です。ただし、診断で終わると採用は動かないので、判断が出るところまでを範囲に入れることが条件です。

順番として、見てきた企業の課題を型で書き出し、資格と他の士業との線を専門家に確認し、範囲を事業との接続と投資の判断と助言と制度の情報整理に絞り、診断で終わらないを範囲に入れ、数字で整える一言を作り、登録先に範囲と規模を登録し、月額の顧問か成果物で一件受けて最初の判断が出るところまでを担う。この順番で、中小企業診断士の転身は、「診断する人」から「採用の判断を整える人」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、採用を経営の数字で設計し、判断が出るところまでを担う担当者に、経営者が直接相談したい依頼側がついています。中小企業診断士の転身は、診断ではなく、判断で始まります。

## まとめ

- 中小企業診断士の経験は**「採用を事業と経営の数字の中に置いて設計する」工程**で売れる。**事業と人員の接続・投資の判断・経営者への助言・制度の情報整理の入口**の四つ
- **「診断します」ではなく「経営者が採用に投資する判断を、数字で整える」**と売る
- 売りにくい点は**採用の実務・診断で終わる懸念・資格と他の士業との線**。実務は分け、判断が出るところまでを範囲に入れ、労務や税や法は専門家に委ねる
- **採らなくても解ける課題を先に切り分ける**。余計な費用を止めた価値は分かりやすい
- 案件は**人事の担当者がいない規模の依頼側**から。助言がそのまま判断になる
- 単価は**月額の顧問か設計の成果物で、実務と分ける**。資格の名称と契約の形は専門家に確認

## よくある質問

### 診断士として受けるのと、個人として受けるのと、どちらがよいですか

採用の副業は、診断士の資格に基づく業務としてではなく、経営と数字の経験を活かす個人の業務として受ける形が多いですが、資格の名称の使い方と、業務の線は、資格の規範と個別の状況で変わります。始める前に、資格の規範と、契約と税の扱いを、専門家にご確認ください。どちらの形でも、労務や税や法の判断には踏み込まず、それぞれの専門家に委ねる線は同じです。契約の形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)に整理しています。

### 依頼側から、雇用に関する補助や支援の制度について聞かれました。答えてよいですか

「使える可能性のある制度の存在」と「確認先（公的な窓口や専門家）」を示すところまでにし、要件を満たすかどうか、申請の可否、金額の判断には踏み込みません。制度の内容と要件は変わり、個別の状況で結果が違うため、依頼側が公的な窓口と専門家に確認する形にします。情報整理の入口としての価値はありますが、判断を引き受けると、外れたときに依頼側に損失が出ます。専門家との分担は[取っておくと役に立つ資格](/media/fukugyo-shikaku-toru/)に書いています。

### 採用の実務の経験が無いので、経営者に「で、誰がやるの」と言われそうです

範囲を最初に示し、実務は依頼側か実務の担当者が担う形にします。「私は事業の計画から採用の設計と投資の判断を整えます。求人票やスカウトの実務は、御社の担当者か、実務の担当者と分担します」と伝えます。エラベルのような登録先では、設計を担う担当者と実務を担う担当者を分けて依頼できる依頼側もあり、自分の範囲を明確にしておけば、「誰がやるの」には「実務の担当者と」と答えられます。実務も含めて担いたいなら、実務の工程を学び、小さく受けて経験を作ります。分担の形は[チームで動くときの分担](/media/fukugyo-chiimu/)に整理しています。
