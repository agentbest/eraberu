薬剤師にスカウトを送る前の検索で、「薬剤師、経験〇年以上」で条件を組むと、調剤薬局で働いてきた人、ドラッグストアで調剤と販売をしてきた人、病院の薬剤部にいた人、企業で開発や学術をしてきた人が、同じ一覧に出てきます。加えて、門前の診療科が違う人、通えない勤務地の人も混ざります。薬剤師の資格は共通でも、業態と業務と勤務地が合わない人は動きません。薬剤師の検索で最初にやるべきは、自社の業態と店舗の場所と診療科と業務を決め、年数ではなく「どの業態のどの診療科の店舗で、何を担い、どこで働きたいか」で探すことです。結論を先に書くと、**検索条件は、先に自社の業態と店舗の場所と診療科と業務（在宅・管理・かかりつけ）を決め、年数ではなく経験（業態・門前の診療科・担った業務・店舗の規模）で組み、要件の必須だけにし、プロフィールを「どの業態のどの診療科の店舗で、何を担い、どこで働きたいか」で読み、業態は絞ったまま勤務地を通える範囲まで広げ、復職とパートの層を厚くして送る順を決めます**。文面の型は[薬剤師へのスカウト文面](/media/scout-yakuzaishi-bunmen/)に、要件の作り方は[薬剤師の採用要件の作り方](/media/rpo-yakuzaishi-youken/)に書いていますので、ここでは「検索条件とターゲティング」に絞ります。媒体ごとの検索の仕様には触れません。仕様は各媒体の公式情報でご確認ください。薬剤師の配置や業務に関わる法令上の扱いは専門家にご確認ください。

## 先に「業態」「店舗の場所と診療科」「業務」を決める

自社の業態（調剤薬局、ドラッグストアの調剤、病院、企業）、店舗の場所（駅や地域、通える範囲）と門前の診療科、任せる業務（調剤と服薬指導が主か、在宅か、管理薬剤師か、かかりつけか）を決めます。三つで探す人が変わります。

| 決めること | 探す人が変わる点 |
|---|---|
| 業態 | 調剤薬局と病院とドラッグストアは、業務の中身と働き方が違う。業態は絞る |
| 店舗の場所と診療科 | 通える範囲の人。門前の診療科が近い人は処方の傾向を知っている |
| 業務 | 在宅を任せるなら在宅の経験者。管理なら管理の経験者。かかりつけならその取り組みの経験者 |

止まりやすいのは、「薬剤師」で業態と勤務地を決めないときです。一覧が混ざり、通えない人に送ることになります。決め方は[薬剤師の採用要件の作り方](/media/rpo-yakuzaishi-youken/)に書いています。

## 年数ではなく経験で組む

条件に入れるのは、年数ではなく、要件の必須に当たる経験です。資格は前提なので条件に入れますが、それ以上の資格（認定薬剤師など）は歓迎にします。

| 要件 | 検索条件に | 理由 |
|---|---|---|
| 必須：薬剤師の資格 | 入れる | 前提 |
| 必須：〇〇（業態）の経験 | 業態の言葉で（「調剤薬局」「病院薬剤師」「ドラッグストア」） | 業態の中核 |
| 必須：〇〇（業務）の経験（在宅・管理を任せる場合） | 業務の言葉で（「在宅」「管理薬剤師」「かかりつけ」） | 業務の中核 |
| 勤務地 | 通える範囲で | 生活を決める |
| 歓迎：認定薬剤師などの資格 | 入れない | 資格と業務の経験は一致しない |
| 歓迎：年数 | 入れない | 年数より業態と業務 |

止まりやすいのは、年数と認定の資格と特定の診療科を「かつ」で組んで、数人しか出ないときです。年数と認定を外し、業態と業務と勤務地で読みます。

## プロフィールを「どの業態のどの診療科の店舗で、何を担い、どこで働きたいか」で読む

薬剤師の経験の中身は、四つで読めます。どの業態の、どの診療科の店舗で（門前、処方箋の傾向）、何を担い（調剤、在宅、管理、かかりつけ、販売）、どこで働きたいか（勤務地の希望、通勤の範囲、時間の希望）。四つが書いてある人は、年数が何であっても合うかが読めます。

| プロフィールの記述 | 読み方 |
|---|---|
| 「薬剤師として調剤業務」 | 業態も診療科も業務の中身も無い。中身が読めない |
| 「調剤薬局で〇〇科門前の店舗。在宅を月〇件担当。処方箋は一日〇〇枚程度」 | 業態、診療科、業務、店舗の規模が分かる |
| 「管理薬剤師として〇年。〇名の店舗を運営」 | 管理の経験。任せる時期を短くできる |
| 「ドラッグストアで調剤と登録販売者の指導」 | 業態が違う。調剤薬局への転向は業務の一部が共通 |
| 「病院薬剤部で病棟業務。〇〇領域」 | 業態が違う。調剤薬局への転向は服薬指導の深さが活きる |
| 「希望：〇〇（地域）、時短、土日休み」「育児のため〇年離職」 | 勤務地と時間の希望。復職の層 |

止まりやすいのは、年数と資格だけで判断するときです。「調剤業務」の人に「〇〇科門前で在宅を」と送っても、経歴と合うかが分かりません。

### エラベルの見解

相談で最も多い思い込みは、「薬剤師は資格があれば誰でも同じ仕事ができるから、条件は資格と年数で足りる」というものです。実際には、業態と業務と勤務地が合わない薬剤師は動かず、送っても「通えない」「業態が違う」で返信が来ません。ある会社では、資格と年数で検索して勤務地を見ずに送っていましたが、返信の大半が「通勤できない」で、面談に来た人も業態が病院で調剤薬局の働き方を知らず、辞退が続いていました。担当者が入って、自社の募集を「調剤薬局、〇〇駅の〇〇科門前、在宅あり。管理は〇か月後」と決め、年数を外し、業態と業務の言葉でプロフィールを読み、勤務地の希望が通える範囲の人と、その地域に住んでいる人に絞ったところ、送る相手は減りましたが返信が来て、面談で合いました。薬剤師の検索は、資格と年数で機械的に絞るより、業態と業務で読み、勤務地で絞るほうが合います。

## 業態は絞ったまま、勤務地を通える範囲まで広げ、復職とパートの層を厚くする

対象が少ないときは、業態を広げるのではなく、勤務地を「通える範囲」まで広げ、復職とパートの層を厚くします。業態が違う人（病院から調剤薬局、ドラッグストアから調剤薬局）は業務の一部が共通なので、文面で業態の違いに触れれば対象になることもありますが、まず勤務地と層で広げます。

| 広げる方向 | 見どころ | 文面 |
|---|---|---|
| 勤務地を通える範囲まで | 住んでいる地域、以前の店舗の場所、「〇〇線沿線」の希望 | 件名に駅や地域を出し、通勤の目安を書く |
| 復職の層 | 「育児のため離職」「復職を希望」「ブランク」の記述 | 復職の支援（研修、慣らしの期間、時短）を事実で書く |
| パートの層 | 「時短」「週〇日」「土日休み」の希望 | パートの条件（時間、曜日、時給の幅）を事実で書く |
| 隣の業態 | 病院やドラッグストアで、調剤薬局への転向の記述 | 業態の違いに先に触れ、共通する業務と教育を書く |

止まりやすいのは、対象が少ないからと、通えない勤務地の人に送るときです。「読んでいない」と受け取られます。

## 送る順の付け方

| 順 | 条件 |
|---|---|
| 一 | 業態と業務が自社と合い、勤務地が通える範囲で、四つが書いてあり、一行目に書ける一点がある |
| 二 | 業態が合い、勤務地が通える範囲。業務の経験は一部（在宅の経験が無いなど）。伸ばす方針を文面に書ける |
| 三 | 復職やパートの層。勤務地と時間の希望が自社と合う。支援と条件を事実で書いて送る |
| 四 | 隣の業態で、調剤薬局への転向の記述があり、勤務地が合う。業態の違いに先に触れる文面で送る |
| 送らない | 勤務地が通えない。業態が違い転向の記述も無い。四つが読めず資格と年数だけ。一行目に書ける一点が無い |

止まりやすいのは、「年数が長いから」「認定があるから」で送るときです。業態と業務と勤務地の近さで順を付けます。

## 条件の保存と見直し

組んだ条件は、「〇〇駅周辺用」「在宅経験者用」「復職層用」「パート用」のように勤務地と業務と層ごとに名前を付けて保存し、送った結果と一緒に記録します。月に一度、返信が来た人の共通点（業態、診療科、業務、勤務地、層）を見て、条件と読み方を直します。保存の仕方は[検索条件の保存と使い回し](/media/scout-kensaku-hozon/)に書いています。

### エラベルの見解

担当する側から見ると、薬剤師の検索で会社ごとに差がつくのは、「復職とパートの層を対象に入れる体制があるか」です。業態と勤務地は本社に聞けば決まりますが、「フルタイムの経験者」だけを探す会社では、対象が狭く、しかも同じ人に競合も送っています。復職の支援（研修、慣らしの期間）とパートの条件（時短、曜日）を用意している会社では、対象が大きく広がり、競合が送っていない層に届きます。エラベルでスカウトの検索を担当する人には、条件を組む前に、本社と薬局長に「業態と店舗の場所と診療科と業務は何か、復職とパートを受け入れる体制はあるか」を聞いてもらっています。文面の型は[薬剤師へのスカウト文面](/media/scout-yakuzaishi-bunmen/)に書いています。

## 代行に出す場合の範囲

担当者が持つのは、要件から必須の経験を取り出して条件を組むこと、出てきた人を「どの業態のどの診療科の店舗で、何を担い、どこで働きたいか」で読んで絞ること、勤務地と復職とパートの層で送る順を付けること、条件と結果を記録して月に一度見直すこと、です。会社が持つのは、業態と店舗と業務の決定、復職とパートを受け入れる体制の用意、要件の必須と歓迎の区別、本社と薬局長が担当者に話す時間、です。担当者が薬剤師の経歴（業態、業務、店舗の規模）を読める経験があるかは、担当者を選ぶときに確かめます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## まとめ

- 先に**業態・店舗の場所と診療科・業務（在宅・管理・かかりつけ）**を決める。三つで探す人が変わる
- 検索条件は**年数ではなく経験（業態・門前の診療科・担った業務・店舗の規模）**で組む。認定の資格は歓迎に
- プロフィールは**「どの業態のどの診療科の店舗で、何を担い、どこで働きたいか」**で読む。「調剤業務」では中身が読めない
- 対象が少ないときは**業態は絞ったまま、勤務地を通える範囲まで広げ、復職とパートの層を厚くする**
- **通えない勤務地の人には送らない**。薬剤師は勤務地で生活が決まる
- 条件は**勤務地と業務と層ごとに分けて保存し、返信が来た人の共通点で月に一度直す**

## よくある質問

### 病院やドラッグストアの薬剤師にも送ってよいですか

勤務地が通える範囲で、調剤薬局への転向の記述（「調剤薬局で働きたい」「病棟から外来へ」など）があれば送れます。病院の薬剤師は服薬指導の深さが活き、ドラッグストアの薬剤師は調剤の経験が共通します。文面では業態の違いに先に触れ、調剤薬局の働き方（処方箋の量、患者との関係、土日）と教育の体制を事実で書きます。転向の記述が無い人に送っても、業態を変える動機が無いので動きにくい。

### 復職の薬剤師は、すぐに戦力になりますか

ブランクの長さと、以前の業態で変わります。調剤薬局の経験があって数年のブランクなら、研修と慣らしの期間があれば戦力になることが多い。支援の体制（研修、最初の数か月の配置、相談の相手）を用意し、文面に事実で書きます。復職の層は競合が送っていないことが多く、支援を書ける会社にとっては有力な対象です。

### 出てくる人が少なすぎます

年数か認定か診療科で絞っているか、勤務地を狭く取りすぎているかを見ます。年数と認定を外し、勤務地を「通える範囲」（沿線、車での通勤圏）まで広げ、復職とパートの層を含めます。それでも少ないなら、隣の業態で転向の記述がある人を含めます。業態を広げるより、勤務地と層で広げるほうが、合う人に届きます。
