障害者雇用の実務は、「これから始める」会社と「始めたが定着しない」会社から出る副業案件です。制度のことは分かったが何を任せればよいか分からない、受け入れた人が数か月で辞めた、配慮のことを誰に何を伝えればよいか分からない、支援機関とのやり取りが人事一人に集まっている。その状態で「障害者雇用の実務を手伝ってほしい」と外に出されます。ただ、この仕事には、二つの重い線があります。一つは、制度の数値と要件と法的な判断、助成に関わる手続きには、公的な窓口と専門家の枠組みがあると一般に整理されており、副業の人が受ける範囲ではないこと。もう一つは、障害の内容と配慮の情報が、一般の個人情報より重く、扱いを誤れば本人に直接の不利益が及ぶことです。結論を先に書くと、**障害者雇用の実務の副業案件で受けられるのは、会社が「任せる仕事」を業務の分解で切り出すのを支え、受け入れ（配慮の確認と伝える範囲、上司と同僚への説明、支援機関との連携の型）を設計し、定着の面談と記録の仕組みを作り、確認が要る点を公的な窓口と専門家に橋渡しする範囲で、案件は「業務の切り出しの支援」「受け入れの設計と支援機関との連携の型」「定着の面談と記録の仕組み」「型作りと引き継ぎ」の四つの型に分かれます。進め方は、制度の確認は公的な窓口と専門家に、と会社と決める→業務の分解と切り出し→配慮の情報の扱い（本人の同意、伝える範囲と相手）を決める→受け入れの設計→支援機関との連携の型→定着の面談と記録→見直し、の順で、制度の数値と要件と法的な判断と助成の手続きには入らず、障害の内容と配慮の情報を本人の同意の範囲でだけ扱い、本人への回答は会社と支援機関と専門家、処遇は会社と専門家、の線を先に引いておきます。**障害者雇用の担当の経験の売り方は[障害者雇用担当が副業でできること](/media/fukugyo-shougaisha-koyou-tantou-fukugyo/)に、受け入れの型はオンボーディングと共通で[オンボーディング設計の副業案件](/media/fukugyo-onboarding-sekkei-fukugyo/)に、法令の線は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。ここでは、障害者雇用の実務の案件に絞ります。個別の判断は専門家にご確認ください。

## 先に確かめる：副業で受けられる範囲と、受けられない範囲

| 受けられる範囲（会社と支援機関と専門家を支える） | 受けられない範囲（公的な窓口と専門家、または会社の判断） |
|---|---|
| 業務の分解と切り出し（「任せられる仕事が無い」を、業務を分解して崩す） | 制度の数値と要件の判断（雇用の義務、算定、報告に関わること） |
| 受け入れの設計（配慮の確認の型、伝える範囲と相手、上司と同僚への説明の型、環境の整え方の一覧） | 助成に関わる手続きと要件の判断 |
| 支援機関（公的な窓口、就労の支援機関など）との連携の型（誰が、いつ、何を相談するか） | 障害の内容や配慮の要否に関する医学的・専門的な判断 |
| 定着の面談の型と記録の仕組み（本人の同意の範囲で。会社の人が行う） | 本人への処遇、契約、条件の判断 |
| 確認が要る点を、公的な窓口と専門家に橋渡しする質問の型 | 本人の障害の内容を、同意の範囲を超えて会社の誰かに伝えること |
| 記録の整備（配慮の情報は、同意の範囲と置き場を限って） | 本人からの相談への回答（配慮、処遇、健康） |

「受けられない範囲」は、公的な窓口、支援機関、専門家（社会保険労務士、医療の専門家など）と会社が持ちます。契約前に書面に残し、個別の判断は専門家にご確認ください。

## 障害者雇用の実務の案件の四つの型

募集文は「障害者雇用の推進支援」「受け入れ体制の構築」「定着支援」と書かれていることが多いですが、任される範囲は四つに分かれます。募集文の「制度の対応」を「受け入れと定着の運用の設計」に直して提案します。

| 型 | 任される範囲 | 依頼側と支援機関と専門家が持つこと | 受ける側の稼働の性質 |
|---|---|---|---|
| 業務の切り出しの支援 | 各部署の業務を分解し、切り出せる業務の一覧と、任せ方（手順、確認、頻度）を作る | 切り出す業務の決定、配置 | 部署への聞き取り。数週間で区切れる |
| 受け入れの設計と支援機関との連携の型 | 配慮の確認の型（本人の同意、伝える範囲と相手）、上司と同僚への説明の型、環境の一覧、支援機関との連携（誰が、いつ、何を） | 配慮の決定と実行、支援機関との契約、本人への伝達 | 入社の前に整える。判断に入らない |
| 定着の面談と記録の仕組み | 定着の面談の型（会社の人が行う）、記録の型（同意の範囲で）、支援機関との情報の共有の型、つまずきの兆しの見方 | 面談の実施、対応の判断 | 月次。自分は面談をしない |
| 型作りと引き継ぎ | 切り出しの型、受け入れの型、連携の型、定着の型、記録の型を作り、社内で回せるようにする | 以後の運用 | 期間が決まっている。終わったら手を離す |

止まりやすいのは、「受け入れの設計」で受けたのに、「制度上、何人採ればよいか」「助成はどうすれば」と、制度と手続きの判断を求められるときです。公的な窓口と専門家に確認する形に整え、自分は答えません。

## 求められる経験を棚卸しする

依頼側が見ているのは、「制度に詳しいか」ではなく、「任せる仕事を作り、受け入れて、定着する運用を、配慮の情報を守りながら作れるか」です。社内で障害者雇用に関わった経験を、四つに分けて棚卸しします。

| 経験 | 依頼側にとっての意味 | 棚卸しの書き方 |
|---|---|---|
| 業務の分解で切り出した | 「任せられる仕事が無い」を崩せる | どの部署の何を分解し、何を切り出したか |
| 配慮の情報の扱いを型にした | 本人の同意、伝える範囲と相手を決めて守った | どういう型で、誰に何を伝え、何を伝えなかったか |
| 支援機関と連携した | 誰が、いつ、何を相談するかを型にし、人事一人に集まらない形にした | 連携の型と、それで減った負担 |
| 定着の面談と記録を回した | 会社の人が行う面談の型と記録で、つまずきの兆しを拾い、対応につないだ | 面談の型と、拾った兆しと対応（個人が特定されない形） |

いちばん差がつくのは二つ目です。障害の内容と配慮の情報は、本人の同意なく上司や同僚に伝わると、本人に直接の不利益が及びます。同意と範囲と相手を決めて守れる人が、この仕事を続けられます。

### エラベルの見解

担当する側から見ると、障害者雇用の案件は、「会社が『配慮の情報を、本人の同意の範囲でだけ扱う』と決められるか」で、受けられるかが決まります。決められる会社では、担当者は業務の切り出しと受け入れと定着の型に集中でき、本人は安心して配慮を伝えられ、定着します。決められない会社（「上司には全部伝えたい」「同僚にも知らせたい」）では、本人の同意を超えた情報の流れが起き、本人が辞め、会社と担当者の両方に問題が残ります。エラベルで担当者を選ぶ企業に、私たちがまず聞くのは「配慮の情報を、誰にどこまで伝えるかを、本人と決める形にできますか」です。「全部共有したい」という会社には、受け入れの前に、扱いの型を決めてもらいます。受ける側がその場で使える判断としては、受ける前に「配慮の情報は、本人の同意の範囲でだけ、決めた相手にだけ」を伝え、同意が無ければ受けないこと。この線は、本人を守るためであり、会社を守るためでもあります。

## 進め方の順番

| 順 | やること | ここで決めておくこと |
|---|---|---|
| 一 | 制度の数値と要件と助成の確認は、公的な窓口と専門家に、と会社と決める。自分の範囲を書面に | 確認の担当（会社）。専門家の有無 |
| 二 | 業務の分解と切り出し（各部署の業務を、手順・確認・頻度で分解し、切り出せるものの一覧と任せ方） | 切り出す業務の決定と配置は会社 |
| 三 | 配慮の情報の扱いを決める（本人の同意の取り方、伝える範囲、伝える相手、置き場、記録に書く範囲） | 型を契約に書く。本人に説明するのは会社 |
| 四 | 受け入れの設計（配慮の確認の型、上司と同僚への説明の型（同意の範囲で）、環境の一覧、最初の三か月の計画） | 実行は会社。説明するのは会社の人 |
| 五 | 支援機関との連携の型（誰が、いつ、何を相談するか。人事一人に集まらない形。本人の同意の範囲で共有する情報） | 支援機関との契約と窓口は会社 |
| 六 | 定着の面談と記録の仕組み（面談は会社の人。型と記録。つまずきの兆しの見方。同意の範囲で） | 面談する人。対応の判断は会社と支援機関 |
| 七 | 見直し（三か月と半年で、切り出した業務、配慮、面談の型を直す。判断は会社） | 見直しの時期 |

止まりやすいのは、二を飛ばして「まず採用を」と進めるときです。任せる仕事が無いまま迎えると、本人は「仕事が無い」と感じ、定着しません。業務の切り出しの考え方は[障害者雇用担当が副業でできること](/media/fukugyo-shougaisha-koyou-tantou-fukugyo/)に書いています。

## 外部の立場で踏み込まない線

障害者雇用の実務は、本人に直接の不利益が及ぶ情報と、公的な枠組みの近くで働く仕事です。線は、労務の中でも厳しく引きます。

- **制度の数値と要件と法的な判断をしない。** 雇用の義務、算定、報告、助成の要件と手続きは、公的な窓口と専門家（社会保険労務士など）に会社が確認する。自分は「確認が要る点」として整理するまで。個別の判断は専門家にご確認ください
- **障害の内容や配慮の要否の専門的な判断をしない。** 医学的・専門的な判断は、医療の専門家と支援機関。自分は配慮の「確認の型」（本人に聞く項目、同意の取り方）を作るまで
- **配慮の情報を、本人の同意の範囲を超えて扱わない。** 誰に、何を、どこまで伝えるかは本人と会社が決める。自分は型を作り、同意の範囲の外の情報を見ない、記録に書かない、伝えない
- **本人への回答は会社と支援機関と専門家。** 本人からの配慮、処遇、健康の相談は、事実を整理して会社に渡す。自分が答えない。自分が本人と直接やり取りする場面は、会社が決めた範囲で
- **処遇と契約と条件に入らない。** 賃金、契約の形、勤務の条件は、会社と専門家。配慮と処遇を混ぜて自分が判断しない
- **上司と同僚への説明を代わりにしない。** 説明の型は作るが、話すのは会社の人。同意の範囲を守った説明かを、型で確かめる
- **支援機関との窓口を自分が持たない。** 連携の型は作るが、窓口は会社。支援機関との情報の共有は、本人の同意の範囲で、会社が行う
- **本業や他の依頼側の事例を持ち込まない。** 特定の障害の事例を「前の会社ではこうだった」と持ち込まない。個人が特定されなくても、配慮の情報の持ち込みは重い

線の詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[労務実務の副業案件](/media/fukugyo-roumu-jitsumu-fukugyo/)と[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、依頼側の「制度の要件を満たすために、まず採る」と、受ける側の「配慮のことは上司に全部伝えたほうが親切」の両方です。実際には、任せる仕事が無いまま採った人は定着せず、本人の同意を超えて伝わった配慮の情報は本人に不利益を生み、どちらも本人と会社の両方を傷つけます。同じ料金で同じ範囲を任されても、結果が分かれるのは、担当者が「制度と配慮を先に」置くか「仕事と同意を先に」置くかです。制度の数値から入り、配慮の情報を上司と同僚に広く共有した担当者の受け入れは、本人が「仕事が無い」「知られたくないことが知られている」と感じ、数か月で終わります。業務の分解で任せる仕事を先に作り、配慮の情報は本人と決めた範囲と相手にだけ伝え、支援機関と連携の型で組んだ担当者の受け入れは、本人が仕事の中で力を出し、定着します。受ける側がその場で使える判断としては、受け入れの設計の最初の一枚を「任せる仕事の一覧」にし、二枚目を「配慮の情報の同意と範囲と相手」にすること。この二枚が無いまま採用の話を進めません。

## 向く人と向かない人

| 向く | 向かない |
|---|---|
| 業務を分解して「任せられる仕事」を作るのが苦にならない | 「任せられる仕事が無い」で止まる |
| 配慮の情報を、本人の同意の範囲でだけ扱い、求められても超えない | 「上司には全部伝えたほうがよい」と思う |
| 制度と助成と専門的な判断を、公的な窓口と専門家に渡せる | 制度の数値を自分で答えたくなる |
| 支援機関との連携を型にし、窓口を会社に置ける | 自分が支援機関との窓口になってしまう |
| 定着の面談を会社の人が行う形にし、自分は型と記録に留まれる | 自分が本人の相談相手になりたい |

「自分が本人の相談相手になりたい」人は、良い人ですが、この仕事では本人を会社と支援機関から切り離し、配慮の情報を自分が抱える形になります。

## まとめ

- 障害者雇用の実務で受けられるのは**業務の切り出しの支援・受け入れの設計と支援機関との連携の型・定着の面談と記録の仕組み・型作りと引き継ぎ**。**制度の数値と要件と法的な判断、助成の手続き、専門的な判断は受けない**（公的な窓口と専門家の枠組みがあると一般に整理されている。個別の判断は専門家にご確認ください）
- **配慮の情報は、本人の同意の範囲でだけ、決めた相手にだけ**。型を契約に書き、同意の外の情報は見ない、書かない、伝えない
- 求められるのは**業務の分解で切り出した・配慮の情報の扱いを型にした・支援機関と連携した・定着の面談と記録を回した**の四つ。制度の知識ではない
- 進め方は**制度の確認は公的な窓口と専門家に→業務の分解と切り出し→配慮の情報の扱い→受け入れの設計→連携の型→定着の面談と記録→見直し**。「まず採用を」から入らない
- 線は**制度と助成と専門的な判断をしない・同意の範囲を超えない・本人への回答は会社と支援機関と専門家・処遇に入らない・説明は会社の人・窓口は会社・他社の事例を持ち込まない**
- 受け入れの設計の最初の一枚は**任せる仕事の一覧**、二枚目は**配慮の情報の同意と範囲と相手**

## よくある質問

### 会社から「制度上、何人採ればよいか、助成はいくらか教えてほしい」と言われました

答えません。制度の数値と要件と助成は、公的な窓口と専門家（社会保険労務士など）が確かめるもので、状況で変わります。「その点は、公的な窓口と専門家に御社から確認してください。確認する項目と、御社の状況の事実は、私が整理してお渡しします。私は、任せる仕事の切り出しと、受け入れと定着の運用を設計します」と、範囲を分けます。数値を自分の記憶で答えると、間違いが会社の判断に直結します。個別の判断は専門家にご確認ください。

### 上司から「本人の障害の内容を、部署の全員に伝えたい」と言われました

本人の同意の範囲を超える共有は、しない形にします。「伝える範囲と相手は、本人と会社が決めた同意の範囲に沿います。部署の全員に伝えるなら、本人の同意を改めて確かめ、伝える内容も本人と決めてください。同意の無い共有は、本人に直接の不利益が及ぶことがあります」と、型に戻します。上司が同僚に伝えたい理由（仕事の割り振り、配慮の実行）は、障害の内容ではなく「仕事の上で配慮すること」の形で伝えれば足りることが多く、その形を型にします。

### 障害者雇用の実務の単価はどう決めればよいですか

「業務の切り出し（部署の数）」「受け入れの設計と連携の型（成果物）」「定着の面談と記録の仕組み（型を作る工程と、月次の確認）」「型作りと引き継ぎ」を分けて見込みます。制度と助成の確認、支援機関との窓口、本人との面談は含めません。相場は範囲と受け入れの人数で幅が大きく、公開されている案件でも一律ではありません。単価の考え方は[単価の相場と考え方](/media/fukugyo-tanka-souba/)に、始め方は[障害者雇用の実務で副業を始めるには](/media/fukugyo-shougai-koyou-hajimekata/)に書いています。
