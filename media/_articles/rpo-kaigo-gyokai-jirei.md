同じ採用代行を使っても、機能する介護の会社と機能しない会社があります。差を作るのは代行の腕ではなく、発注側の条件です。離職の理由を分けているか、資格の区分を整理しているか、実態を求人票に書いているか、型で分けているか、施設長の枠を預けられるか、記録が社内にあるか、任せる工程が絞られているか。結論を先に書くと、**介護業界で採用代行が機能するのは、離職・資格・実態・型・枠・記録・工程の七つで「社内に残すものを残している」会社で、機能しないのは「業界だから辞めるもの。実態は面接で。全部任せたい」会社です。**発注の前に七つで自社を確かめ、機能しない条件があれば、発注の前にそれを変えます。工程の切り分けは[介護業界の採用代行](/media/rpo-kaigo-gyokai-rpo/)に、課題の分解は[介護業界の採用課題](/media/rpo-kaigo-gyokai-kadai/)に、職種の切り分けは[介護職採用を代行に出す判断基準](/media/rpo-kaigo-rpo/)に書いています。ここでは、介護業界の七つの対に絞ります。

## 七つの対

| 軸 | 機能する条件 | 機能しない条件 |
|---|---|---|
| 離職 | 退職面談で理由を分け、夜勤の開始の時期と教える人を設計し、募集の回数が減っている | 「業界だから辞めるもの」。辞めた分を採り続ける |
| 資格 | 資格の区分と配置と加算の関係を会社と専門家で整理し、「必須・取得の支援・歓迎」の区分が要件と求人票にある | 「資格は後で」「介護職募集」だけ |
| 実態 | 夜勤の回数と開始の時期・身体的な負担・利用者の状態を求人票に書き、見学と体験を段に置いている | 「実態は面接で」「アットホーム」だけ |
| 型 | 施設・在宅・通所で求人票と経路を分けている | 「介護職の一本で」 |
| 枠 | 施設長と管理者の面接の枠を、申し送りの後・日勤の終わりの前・オンラインで週に一つ預けられる | 「施設長は現場で面接に出られない」 |
| 記録 | 一覧と面接の記録が施設をまたいで社内の環境にある | 記録が代行の環境。施設ごとに別 |
| 工程 | 任せる工程が絞られ、残す工程（資格・実態の判断・見極めと配置・受け入れ・条件）の担当がいる | 「全部任せたい」 |

七つのうち一つでも機能しない条件にあると、代行はその部分で止まります。

## 離職：理由を分けて直しているか

| 機能する | 機能しない |
|---|---|
| 退職面談の記録があり、「夜勤の開始・教える人・実態・人間関係・条件・私的な事情」に分けて数えている | 「一身上の都合」しか無い |
| 夜勤の開始の時期（最初の三か月は日勤で教える人と一緒に、など）と教える人が受け入れの一枚にある | 一か月目から一人で夜勤 |
| 募集の回数が減っている | 同じ施設で募集を繰り返す |

### エラベルの見解

介護業界で最も多い機能しない条件は「離職」の扱いです。「業界だから」で、辞めた分を代行に採らせ続ける。代行は穴を埋めるだけで、費用は出続け、現場は常に教える負担を抱えます。退職面談で理由を分けると、「夜勤の開始が早すぎた」「教える人がいなかった」が最も多いことが珍しくなく、受け入れの一枚（夜勤の開始の時期、教える人、最初の三か月の到達点）を作るだけで離職が減る施設があります。エラベルで担当者を選ぶ企業には、「受け入れの一枚に、夜勤の開始の時期と教える人は書いてありますか」を、私たちから先に聞いています。無ければ、代行の前に受け入れの設計です。受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 資格：区分が整理されているか

| 機能する | 機能しない |
|---|---|
| 資格の区分と配置と加算の関係を会社と専門家で整理している | 「介護職募集」で、採った後に配置と加算に合わない |
| 「必須・取得の支援・歓迎」の区分が要件と求人票に同じ形である | 区分が無い |
| 書類の一次確認で区分を照合 | 面接まで確かめない |

資格と配置と加算の関係は、法令上の整理があると一般に整理されているため、会社と専門家（社労士等）が決めます。代行は照合まで。個別の判断は専門家にご確認ください。

## 実態：求人票に書き、見学を置いているか

| 機能する | 機能しない |
|---|---|
| 夜勤の回数と開始の時期・身体的な負担・利用者の状態・一緒に働く人・最初の三か月を実態の言葉で | 「アットホーム」「未経験歓迎」だけ |
| 見学と体験を選考の段に置く | 見学が無く、入職後に「聞いていない」 |
| 早期離職の理由を求人票に戻す | 「本人の事情」で片付ける |

実態の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 型：分けているか

| 機能する | 機能しない |
|---|---|
| 施設（夜勤あり、チーム）・在宅（移動あり、一人）・通所（日勤のみ、送迎）で求人票と経路を分けている | 「介護職の一本」 |
| 型ごとに応募の数を記録 | 全部を一つの数で |
| 型ごとに「動く理由」を実態で書いている | 「やりがい」だけ |

要件の作り方は[介護職の採用要件の作り方](/media/rpo-kaigo-youken/)に書いています。

### エラベルの見解

「全部任せたい」という介護の会社は、多くの場合、施設長が現場と採用と受け入れを一人で抱え、法人の本部は加算と運営で手一杯で、採用を見る人がいない状態です。その状態で全部を任せると、資格の整理も実態の判断も配置も代行に寄り、代行にはできないので止まります。エラベルは担当者を工程ごとに選べる形にしているので、本部が「資格の整理の橋渡し（専門家と）・求人票の型・条件」に絞り、施設長は「週に一枠の面接と見学と受け入れ」に絞り、「型ごとの経路の運用・一次対応・日程・施設をまたぐ記録」を担当者が担う、という組み方ができます。施設長の負担が減ると、受け入れの時間ができ、離職が減り、募集が減ります。工程の切り分けは[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)や[求人媒体の運用は代行に出せるか](/media/rpo-task-baitai-unyou-daikou/)に書いています。

## 枠：施設長の時間を形を変えて預けられるか

| 機能する | 機能しない |
|---|---|
| 申し送りの後、日勤の終わりの前、オンライン、で週に一枠を先に | 日中に都度調整 |
| 一次（書類の照合と一次対応）を外に出し、施設長は面接と見学だけ | 施設長が全段に出る |
| 面接と見学を同じ日に | 別の日で、日程が延びる |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 記録：施設をまたいで社内にあるか

| 機能する | 機能しない |
|---|---|
| 一覧に「施設」「型」の列があり、施設をまたいで段階と数が見える | 施設ごとに別。代行の環境 |
| 週次の一枚で、施設ごとの数と止まりが本部に届く | 月末の報告だけ |
| 契約が終わっても、記録と型（資格の区分、実態を書いた求人票、受け入れの一枚、経路の一覧）が社内に残る | 契約が終わると消える |

記録の扱いは[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。

## 工程：絞られているか

| 機能する | 機能しない |
|---|---|
| 「施設の介護職の地域の経路の運用と一次対応」「看護職の紹介の母集団形成」のように、型と工程で任せる範囲が明確 | 「採用を全部」 |
| 残す工程（資格・実態の判断・見極めと配置・受け入れ・条件・合否）の担当が決まっている | 残す工程の担当がいない |
| 一つの施設・一つの工程で三か月回し、記録で効いたかを見てから広げる | 最初から全施設・全工程 |

## 機能しない条件を変える順番

| 順 | 変えること | 費用 |
|---|---|---|
| 一 | 離職：退職面談の記録を集め、夜勤の開始の時期と教える人を受け入れの一枚に | 教える人の時間 |
| 二 | 資格：会社と専門家で区分を整理 | 専門家の確認 |
| 三 | 実態：求人票に書き、見学を段に | 施設長の時間 |
| 四 | 枠：申し送りの後かオンラインで週に一つ | かからない |
| 五 | 記録：施設をまたぐ一覧を社内の環境に | かからない |
| 六 | 工程：任せる工程を一つに絞る（一次対応と日程から） | 契約の範囲が小さくなる |
| 七 | 型：施設・在宅・通所で分ける | かからない |

四・五・七は発注の前に社内で変えられます。一と三は現場の時間、二は専門家の確認が要り、六は契約の設計です。

## 機能しているかを見る記録

| 見ること | 機能している目印 |
|---|---|
| 早期離職の件数と募集の回数 | 減っていれば離職が機能 |
| 配置できなかった件数 | ゼロなら資格が機能 |
| 辞退と早期離職の理由 | 「夜勤」「負担」「働き方」が減っていれば実態が機能 |
| 型ごとの応募の数 | 偏りが減っていれば型が機能 |
| 段階ごとの日数 | 短くなっていれば枠が機能 |

件数のまま並べ、前の募集と比べます。割合や外部の平均で断定しません。見る指標は[採用代行との定例会で見るべき数字](/media/rpo-teirei/)に書いています。

## まとめ

- 代行が機能するかは**代行の腕より発注側の条件**で決まる
- 七つの対は**離職・資格・実態・型・枠・記録・工程**
- 最も多い機能しない条件は**離職の扱い**。「業界だから」をやめ、夜勤の開始の時期と教える人から直す
- **資格・配置・加算は会社と専門家**。個別の判断は専門家にご確認ください
- **「全部任せたい」は機能しない**。本部は資格と型と条件に、施設長は面接と見学と受け入れに絞る
- 変える順番は**離職→資格→実態→枠→記録→工程→型**
- 施設長の負担が減ると**受け入れの時間ができ、離職が減り、募集が減る**

## よくある質問

### 施設長が「面接は自分でやる。他は任せたい」と言います

それが機能する形です。「一次対応と日程と記録」を外に出し、施設長は「週に一枠の面接と見学と受け入れ」に絞る。施設長が面接で決めることは変わらず、負担だけが減ります。一つの施設で「返事と日程を外に出したら面接に来る人が増えた」記録が出れば、他の施設にも広げられます。

### 加算の要件に関わる資格の人を、急いで採らなければなりません

加算の要件と資格の区分の関係は、法令上の整理があると一般に整理されているため、会社と専門家で「どの区分の資格の人が、何人、いつまでに」を先に整理します。整理した区分を要件と依頼書に書き、紹介会社と資格の区分に合う媒体で集め、書類の一次確認で区分を照合します。急ぐほど、区分を曖昧にせず、返事の速さと枠の預かりで縮めます。個別の判断は専門家にご確認ください。

### 新しい施設の開設に、開設の時期までに人が揃いません

開設の計画が立った段階で、採用の一枚に「職種・資格の区分・人数・時期・募集の開始」を置き、応募から入職までの日数から逆算します。開設の直前に募集を始めると、資格の区分と実態を曖昧にしたまま採り、開設後に離れます。既存の施設からの異動と、新規の採用を同じ一枚に置き、異動で埋まる分を先に決めると、採る数が読めます。計画のつなぎ方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。
