面接官トレーニングを自社で進めようとして、「面接のコツをまとめた資料を配って研修する」から始めると、面接官は半日の研修を聞き流し、翌週には自分の聞き方に戻り、記録は「良い印象」のままで、評価のばらつきも、一次で通した人が二次で落ちる率も変わりません。面接官トレーニングで最初にやるべきは、研修の資料を作ることではなく、「何を見る面接官を育てるか」を絞り、面接官に「型に沿う」ことを会社として求め、研修は短くして、同席と振り返りに時間を使うことです。面接官が変わるのは、研修を受けたときではなく、自分の面接を型に照らして振り返ったときです。結論を先に書くと、**進め方は、面接で何を見るかの観点を絞る→面接官を決めて「型に沿う」合意を取る→型（質問・記録・時間配分・聞いてはいけない事項）を一枚にする→研修を三十分で設計して実施する→模擬面接を一回行う→実際の面接に二回同席して直後に振り返る→面接記録を月に一度、面接官と一緒に読む→面接官ごとの通過率と二次での結果を見て型を直す、の八つの手順**です。代行に出す場合の切り分けは[面接官トレーニングは代行に出せるか](/media/rpo-task-mensetsukan-kunren-daikou/)に、ばらつきの直し方は[面接官によって評価がばらつくとき](/media/rpo-mensetsukan-bara/)に書いていますので、ここでは自社で進める手順に絞ります。面接で聞いてはいけない事項は法令に関わるので、専門家にご確認ください。

## 手順の全体

| 手順 | やること | 誰が | 頻度 |
|---|---|---|---|
| 一 | 面接で何を見るかの観点を絞る | 責任者と人事 | 職種ごとに一度 |
| 二 | 面接官を決めて「型に沿う」合意を取る | 責任者 | 最初に一度、面接官が替わるたび |
| 三 | 型を一枚にする | 人事 | 職種ごとに一度 |
| 四 | 研修を三十分で設計して実施する | 人事 | 面接官ごとに一度 |
| 五 | 模擬面接を一回行う | 人事と面接官 | 面接官ごとに一度 |
| 六 | 実際の面接に二回同席して直後に振り返る | 人事と面接官 | 面接官ごとに二回 |
| 七 | 面接記録を月に一度、面接官と一緒に読む | 人事と面接官 | 月に一度 |
| 八 | 通過率と二次での結果を見て型を直す | 人事と責任者 | 四半期に一度 |

手順の要点は、四の「研修」が三十分で、五から七に時間を使うことです。多くの会社は四に半日を使い、五から七がありません。

## 手順一：面接で何を見るかの観点を絞る

職種ごとに、各段階（一次・二次・最終）で確かめる観点を二つか三つに絞ります。要件のうち書類で読めないものを取り出し、「一次で落とす理由になるもの」を一次に、それ以外を二次以降に置きます。観点が絞れないと、型も研修も作れません。決め方は[一次面接の進め方](/media/rpo-task-ichiji-mensetsu-susumekata/)と[評価基準が言語化できていないとき](/media/rpo-hyouka-kijun/)に書いています。

止まりやすいのは、責任者が「全部見たい」と言うときです。三十分で四つ以上は見られません。「一次で落とす理由になるもの」だけを一次に残します。

## 手順二：面接官を決めて「型に沿う」合意を取る

面接官を職種と段階ごとに決め、責任者から面接官に「型に沿って面接する」「研修と模擬面接と同席と振り返りを受ける」ことを求め、合意を取ります。「自分のやり方で」を許すと、研修は聞き流されます。

| 合意すること | 伝え方 |
|---|---|
| 型に沿って聞く | 質問は台本ではなく、外してはいけない項目。聞き方は自分の言葉で |
| 根拠で記録する | 「良い印象」ではなく、場面と行動で |
| 研修と模擬面接と同席を受ける | 評価のためではなく、型を揃えるため |
| 記録の振り返りを受ける | 月に一度、十分 |

止まりやすいのは、面接官が現場の責任者で、人事が求めにくいときです。経営者か上位の責任者から求めてもらいます。

## 手順三：型を一枚にする

観点ごとの「過去の場面を聞く」質問、根拠付きの記録の様式、時間配分、聞いてはいけない事項の一覧を、一枚にまとめます。一枚を超えると使われません。聞いてはいけない事項は、専門家に確認したものを載せます。

| 一枚の中身 | 書くこと |
|---|---|
| 観点 | 二つか三つ |
| 質問 | 観点ごとに一つか二つ。「その案件で、あなたが決めたことは」 |
| 深掘り | 「上司が決めた部分と、自分が決めた部分は」 |
| 記録 | 観点ごとに「場面と行動」→「見立て（十分・不足・判断できず）」 |
| 時間配分 | 最初三分、観点二十分、候補者の質問五分、次の案内二分 |
| 聞いてはいけない事項 | 専門家に確認した一覧 |

止まりやすいのは、質問を二十問並べるときです。三十分で聞ける量にします。質問の作り方は[面接で何を聞けばよいか分からないとき](/media/rpo-mensetsu-shitsumon/)に書いています。

### エラベルの見解

これをやる前に、先に手順二の「型に沿う」合意を取っておかないと、手順四以降は面接官に届きません。相談で多いのは、「良い型を作って研修もしたのに、面接官が使わない」というご相談です。聞くと、面接官は現場の責任者で、人事が「使ってください」と言えず、面接官は「参考にします」で自分のやり方を続けていました。経営者から「一次面接はこの型で。記録は根拠で」と求めてもらい、同席と振り返りを「評価ではなく型を揃えるため」と伝えてからは、面接官は型を使い始めました。型の良し悪しより、会社が面接官に求めているかどうかで決まります。エラベルで面接官トレーニングを担当する人には、型を作る前に、責任者から面接官への合意を取ってもらっています。

## 手順四：研修を三十分で設計して実施する

研修は三十分にします。内容は、「なぜ観点を絞るか」「なぜ場面を聞くか」「なぜ根拠で記録するか」「聞いてはいけない事項」の四つだけ。面接のコツや心構えは入れません。一枚を配って、その場で一問だけ模擬で聞いてみます。

| 時間 | 内容 |
|---|---|
| 五分 | なぜ観点を絞るか（三十分で見られる量） |
| 十分 | なぜ場面を聞くか。「強みは」と「その案件で決めたことは」の違いを実演 |
| 十分 | なぜ根拠で記録するか。「良い印象」と「場面と行動」の記録を並べる |
| 五分 | 聞いてはいけない事項 |

止まりやすいのは、研修を「面接官の心構え」から始めて長くなるときです。心構えは変わりません。型と、なぜその型かだけにします。

## 手順五：模擬面接を一回行う

研修の後、面接官ごとに、人事が候補者役になって模擬面接を一回行います。十五分程度。終わったら、面接官が記録を書き、人事が「観点に沿っていたか」「場面を聞けたか」「記録に根拠があるか」を一つずつ返します。

止まりやすいのは、模擬面接を省いて実際の面接に入るときです。研修で分かったつもりでも、聞いてみると「強みは」に戻ります。一回でよいので模擬を入れます。

## 手順六：実際の面接に二回同席して直後に振り返る

面接官の実際の面接に、人事が二回同席します。同席者は質問せず、記録を取ります。面接の直後に十分、「この場面で観点から外れた」「ここで深掘りできた」「記録のこの行は印象になっている」と、具体的に返します。「良かったです」で終わらせません。

| 振り返りで見ること | 返し方 |
|---|---|
| 観点に沿って聞けたか | 「二つ目の観点の質問が無かった」 |
| 場面を聞けたか | 「強みを聞いたので、用意した答えが返った」 |
| 深掘りできたか | 「『自分が決めた部分は』と聞けば、より分かった」 |
| 記録に根拠があるか | 「この行は『良い印象』なので、場面に直す」 |
| 聞いてはいけない事項に触れていないか | 該当があれば一覧を確認 |

止まりやすいのは、面接官が同席を嫌がるときです。「評価のためではなく、型を揃えるため」を責任者から伝え、それでも難しければ手順七の記録の振り返りから始めます。

## 手順七：面接記録を月に一度、面接官と一緒に読む

月に一度、面接官の記録を人事と面接官が一緒に読みます。十分程度。「根拠が書けているか」「観点に沿っているか」「印象で終わっていないか」を見て、印象になっている行を場面に直します。面接官は自分の記録を見て初めて、「自分は印象で書いている」と気づきます。

止まりやすいのは、人事だけが記録を見て、面接官に返さないときです。面接官本人と一緒に読みます。

## 手順八：四半期に一度、通過率と二次での結果を見て型を直す

面接官ごとの通過率、記録の質、一次で通した人が二次でどうだったかを見ます。通過率の差が大きければ、記録を見比べて観点の見立てのずれを直します。一次で通した人が二次で毎回同じ点で落ちるなら、一次の観点にその点を足します。型を直したら、一枚を更新し、面接官に伝えます。

止まりやすいのは、通過率の差を面接官の評価に使うときです。差は観点の見立てのずれであることがほとんどで、面接官の良し悪しではありません。評価に使うと、数字を良く見せる動機が生まれます。

## 外の人に頼む場合の境目

八つの手順のうち、一の観点の決定、二の面接官の決定と合意を求めること、八の評価と配置の判断は会社が持ちます。三の一枚、四の研修、五の候補者役、六の同席と振り返り、七の記録の確認、八の記録と材料は、外の人に出せます。切り分けの詳しい話は[面接官トレーニングは代行に出せるか](/media/rpo-task-mensetsukan-kunren-daikou/)に書いています。

外に出す判断の目安は、「観点と合意はあるが、研修と模擬面接と同席と振り返りに人事の時間が取れない」ときです。合意が無いまま外に出しても、面接官は動きません。

### エラベルの見解

担当する側から見ると、面接官トレーニングで会社ごとに差がつくのは、手順七の「記録を面接官本人と一緒に読んでいるか」です。研修と同席は、面接官が替わるたびに繰り返せます。しかし、記録を本人と読まない会社では、面接官は同席が終わると元に戻り、記録は再び印象になります。月に一度、自分の記録を人事と読んでいる面接官は、「この行は印象だ」と自分で直すようになり、型が定着します。エラベルでは、面接官トレーニングを担当する人に、最初の一週間で観点を責任者と確認し、面接官への合意を責任者から取ってもらい、型の一枚を作り、聞いてはいけない事項を専門家に確認してもらい、最初の三十分の研修を設計するところまでをお願いしています。ここまでできると、担当者は模擬面接と同席と月に一度の記録の振り返りを回し、会社は観点の決定と合意と四半期の見直しだけになります。

## まとめ

- 面接官トレーニングは**「資料を配って研修する」ではなく、観点を絞り、型に沿う合意を取り、同席と振り返りに時間を使う**
- 手順は**観点を絞る→面接官と合意→型を一枚に→研修三十分→模擬面接一回→同席二回と振り返り→月に一度記録を一緒に読む→四半期に一度型を直す**の八つ
- 研修は**三十分・型と「なぜその型か」だけ**。心構えは入れない
- **模擬面接を一回、同席を二回**。直後に「この場面で外れた」と具体的に返す
- 面接官が変わるのは**自分の記録を見て「印象で書いている」と気づいたとき**
- 通過率の差は**面接官の評価に使わない**。観点の見立てのずれとして型を直す

## よくある質問

### 面接官が多く、全員に模擬面接と同席をする時間がありません

観点と型の一枚と三十分の研修は全員に、模擬面接と同席は通過率が外れている面接官と新しい面接官から順に行います。全員に一度にやろうとせず、四半期に数人ずつ回します。記録の振り返り（手順七）は、時間が短いので全員に行えます。

### 経営者が最終面接をしていて、型に沿ってくれません

最終面接は一次・二次と型が違います。経営者には、一次と二次で確かめたことの記録を渡し、最終では「確かめ済みのことを聞き直さない」「期待を伝える」「懸念に答える」に時間を使う形を提案します。研修ではなく、記録の共有と最終面接の目的の整理から入ります。経営者の面接が候補者の辞退につながっている場合は、その記録（最終面接後の辞退の理由）を材料にします。

### 型に沿うと面接が堅くなると言われます

質問は読み上げる台本ではなく、外してはいけない項目です。聞き方は面接官の言葉で構いません。堅くなるのは、質問を順に読み上げて答えを書き取る面接です。観点ごとに場面を聞き、答えに合わせて深掘りする形なら会話になります。記録も面接中に全部書かず、直後に根拠と見立てを書けば足ります。
