カスタマーサポートへのスカウトで返信が来ない文面には、共通する型があります。件名が「カスタマーサポート募集！未経験歓迎」、本文が「アットホームな職場でお客様の笑顔のために働けます」で、相手の経歴には触れていない。経験者は、その文面を「未経験向けの求人が自分に来た」「クレームの多さを隠している」と読みます。知りたいのは、チャネルと相手（電話かチャットかメールか、個人か法人か）、クレームの割合と一人で抱えない体制、時間帯とシフトと在宅、いまの職場より何が良くなるか、そして自分の経歴のどこを見て送ってきたか。ここが書いてある文面に返信が来て、書いてない文面は開かれずに終わります。結論を先に書くと、**件名は相手の経験の一点と自社の中身、本文は「一行目→チャネルと相手と中身→クレームの扱いとSVの体制→時間帯とシフトと在宅→良くなる一点をSVの言葉で→条件の幅→返信の手間を下げる締め」の順**で組みます。カスタマーサポートに何を訴求するかは[カスタマーサポート向けスカウトの訴求](/media/rpo-cs-support-scout/)に書いていますので、ここでは「件名と本文の型」に絞ります。

## 先に決めるのは「中身」と「クレームの扱い」

文面を書く前に、現場のSV（スーパーバイザー）に、中身とクレームの扱いを聞いて決めます。中身は、チャネル（電話、チャット、メール、複数）、相手（個人、法人、法人の技術担当）、扱う商品やサービス、一日の件数の目安、対応の型（マニュアルどおりか、判断の余地があるか）です。クレームの扱いは、割合の目安、一人で抱えない決まり（SVが引き取る基準）、対応後のフォローです。ここを人事が想像で書くと、面接で現場と食い違い、辞退されます。

| 決めること | 文面のどこに使うか |
|---|---|
| チャネルと相手と扱う商品 | 件名と本文の二段目 |
| クレームの割合と、一人で抱えない決まり | 本文の三段目。隠さない |
| SVの体制（何人に一人、どう支えるか） | 本文の三段目 |
| 時間帯とシフトと在宅（実態） | 本文の四段目 |
| いまより良くなる一点（SVの言葉で） | 本文の五段目 |

止まりやすいのは、SVに聞かずに「アットホーム」「やりがい」で書くときです。経験者は、抽象語が多い文面ほど「実態を隠している」と読みます。

## 件名の型

件名は「相手の経験の一点＋自社の中身」です。「カスタマーサポート募集」「未経験歓迎」「アットホーム」は、経験者の受信箱では埋もれるか、避けられます。

| 型 | 例の形 |
|---|---|
| 相手の一点＋中身 | 「〇〇（相手が対応してきたチャネルと相手）のご経験について｜〇〇（商品）の法人チャットサポート」 |
| 相手の一点＋良くなる一点 | 「〇〇（相手の経験）を見て｜クレームを一人で抱えない体制の〇〇サポート」 |
| 相手の層＋中身 | 「〇〇（接客・店舗）で〇〇をされてきた方へ｜〇〇の電話とメールのサポート、在宅あり」 |

件名でやってはいけないのは、「未経験歓迎」「アットホーム」「お客様の笑顔」「即戦力」だけで組むこと、給与を件名の先頭に置くこと、伏せ字で煽ることです。件名のNGは[スカウト件名のNG例](/media/scout-kenmei-ng/)に書いています。

## 本文の型

本文は七段で組みます。読む側が最初に見るのは一行目と、「クレームの扱いとSVの体制」です。

| 順 | 書くこと | 長さ | 注意 |
|---|---|---|---|
| 一 | 相手の経験の一点（何を見て送ったか） | 一〜二文 | チャネルと相手と扱った商品の一点。経歴の要約にしない |
| 二 | チャネルと相手と中身（一日の件数の目安、対応の型） | 二〜三文 | 「幅広い業務」ではなく、チャネルと相手を具体に |
| 三 | クレームの扱いとSVの体制 | 二〜三文 | 割合の目安を隠さない。一人で抱えない決まりとSVが引き取る基準を書く |
| 四 | 時間帯とシフトと在宅（実態） | 一〜二文 | 「相談可」ではなく、実態を書く。在宅の条件も |
| 五 | いまより良くなる一点（SVの言葉で） | 一〜二文 | 一点だけ。良く見せず、実態を書く |
| 六 | 条件の幅（給与の幅、雇用形態、昇給の道） | 一〜二文 | 幅で書く。SVへの道があれば書く |
| 七 | 締め（返信の手間を下げる。一言の返信でよい、日程の候補を出す） | 一文 | 応募を求めない。書類を求めない |

止まりやすいのは、三段目を書かずに飛ばすときです。経験者は「クレームに触れていない文面」を「隠している」と読みます。

## 転向元・層で一行目を変える

カスタマーサポートへの転向元と層は、大きく六つあります。一行目と、重心を置く段が変わります。

| 転向元・層 | 一行目の変え方 | 重心を置く段 |
|---|---|---|
| 経験者（同じチャネル・相手） | 対応してきたチャネルと商品の一点に触れる | 三段目（クレームの扱い）と五段目（良くなる一点） |
| BtoB技術サポート | 扱ってきた製品や技術の一点に触れ、法人の技術担当が相手であることを書く | 二段目（中身）と三段目 |
| 接客・店舗からの転向 | 接客の一点に触れ、対面と電話やチャットの違いに先に触れる | 二段目と四段目（時間帯とシフト） |
| 在宅希望 | 経験の一点に触れ、在宅の条件（週何日、機材、研修は出社か）を先に書く | 四段目 |
| 主婦層・時間に制約のある層 | 経験の一点に触れ、時間帯とシフトの実態（急な休みの扱い）を先に書く | 四段目と六段目（雇用形態） |
| SV志望 | 後輩の育成や手順の改善の一点に触れ、SVへの道と時期を書く | 六段目（昇給の道）と三段目（SVの体制） |

止まりやすいのは、六つの層に同じ一行目を送るときです。在宅希望に在宅の条件を書かず、SV志望に道を書かないと、自分に来た文面だと読まれません。

### エラベルの見解

相談で最も多いのは、「未経験歓迎、アットホームで送っているのに、経験者から返信が来ない」という会社です。文面を見ると、チャネルも相手も書いてなく、クレームの扱いにも時間帯にも触れず、「お客様の笑顔のために」で終わっている。経験者は、その文面を「クレームが多くて人が辞めるから、未経験にも送っている」と読みます。ある会社では、担当者がSVと話して、三段目を「一日の対応のうちクレームに当たるのは一部で、一人で抱えない決まりがあり、〇〇の状態になったらSVが引き取る。対応後にSVと振り返る」と書き直しました。件名を「〇〇（相手が対応してきた商品）のサポートのご経験について｜〇〇の法人チャットサポート、在宅週〇日」に変え、一行目を相手の経験の一点にしたところ、経験者から返信が来て、面接で「クレームの扱いが書いてあったので、隠していないと思った」と言われました。カスタマーサポートの文面は、良く見せる言葉を削り、SVの言葉で中身とクレームの扱いを書くほうが届きます。

## 書いてはいけないこと

- 「未経験歓迎」「アットホーム」「成長できる」「お客様の笑顔」「即戦力」だけで中身を書かない
- クレームに触れない（触れない文面は「隠している」と読まれる）
- 時間帯とシフトを「相談可」だけで書く（実態を書く）
- 在宅を「あり」だけで書く（週何日、機材、研修は出社か、を書く）
- 給与を一行目に置く（中身の前に給与を出すと、条件だけで比べられる）
- 相手の現職を批判する（「いまの職場は大変ではないですか」）
- 書類の提出を求める締め（「履歴書をお送りください」）

## 送る前の確認

| 確認すること | 見る場所 |
|---|---|
| 一行目が相手の経験の一点になっているか | 本文の一段目 |
| チャネルと相手と中身が具体に書いてあるか | 本文の二段目 |
| クレームの割合と一人で抱えない決まりがSVの言葉で書いてあるか | 本文の三段目 |
| 時間帯とシフトと在宅が実態どおりか（現場に確認したか） | 本文の四段目 |
| 「未経験歓迎」「アットホーム」が残っていないか | 全体 |
| 層に合う一行目と重心になっているか | 本文の一段目と重心の段 |
| 締めが返信の手間を下げているか（一言でよい、日程の候補） | 本文の七段目 |

## 返信が来ないときの直す順番

| 順 | 直すところ | 見る指標 |
|---|---|---|
| 一 | 件名（相手の一点＋中身になっているか。「未経験歓迎」が残っていないか） | 開封 |
| 二 | 一行目（相手の経験の一点か、経歴の要約か） | 開封後の返信 |
| 三 | 三段目（クレームの扱いとSVの体制が書いてあるか） | 返信の中身（「詳しく聞きたい」が出るか） |
| 四 | 四段目（時間帯とシフトと在宅の実態） | 面接での質問と辞退の理由（ここを聞かれるなら書き足りない） |
| 五 | 送る相手（層と中身が合っているか） | 返信率が層で違うか |

一度に全部を変えず、一つずつ変えて比べます。比べ方は[スカウト文面のA/Bテスト](/media/scout-abtest/)に書いています。

### エラベルの見解

担当する側から見ると、カスタマーサポートの文面で会社ごとに差がつくのは、「SVが担当者にクレームの実態を話すか」です。文面の型は同じでも、SVが「クレームは少ないです」としか言わない会社では、担当者は三段目を書けず、経験者に「隠している」と読まれます。SVが「一日のうちこのくらいがクレームで、こういう状態になったら自分が引き取る、対応後は一緒に振り返る」と話した会社では、文面がそのままSVの言葉になり、経験者から返信が来て、面接後の辞退が減りました。エラベルでカスタマーサポートのスカウトを担当する人には、文面を書く前に、SVに「チャネルと相手、一日の件数、クレームの割合と引き取る基準、時間帯とシフトと在宅の実態」を直接聞いてもらっています。対象の絞り方は[カスタマーサポート向けスカウトの訴求](/media/rpo-cs-support-scout/)に書いています。

## 代行に出す場合の範囲

担当者が持つのは、SVから中身とクレームの扱いと体制と時間帯の実態を聞き出すこと、相手の経験の一点を読んで一行目を書くこと、層ごとに文面を分けること、返信率を見て件名と一行目と三段目を直すこと、です。会社が持つのは、SVが担当者に話す時間、中身と良くなる一点と条件の幅の決定、時間帯とシフトと在宅の実態の確認、面接で文面と実態がずれないこと、です。担当者がカスタマーサポートの経歴（チャネル、相手、商品、SV経験）を読める経験があるかは、担当者を選ぶときに確かめます。

## まとめ

- 件名は**相手の経験の一点＋自社の中身**。「未経験歓迎」「アットホーム」「カスタマーサポート募集」は埋もれるか避けられる
- 本文は**一行目→チャネルと相手と中身→クレームの扱いとSVの体制→時間帯とシフトと在宅→良くなる一点をSVの言葉で→条件の幅→返信の手間を下げる締め**の順
- **クレームに触れない文面は「隠している」と読まれる**。割合の目安と一人で抱えない決まりを書く
- 転向元・層（**経験者・BtoB技術・接客からの転向・在宅希望・主婦層・SV志望**）で一行目と重心を変える
- **時間帯とシフトと在宅は「相談可」「あり」ではなく実態を書く**。給与は一行目に置かない
- 返信が来ないときは**件名→一行目→三段目→四段目→送る相手**の順で一つずつ直す

## よくある質問

### クレームの割合を書くと、返信が減りませんか

クレームを避けたい人からの返信は減りますが、「一人で抱えなくてよいなら」と考える経験者からの返信が増え、面接後の辞退が減ります。書かない文面は、経験者に「隠している」と読まれて返信が来ないか、来ても面接で聞かれて辞退されます。割合の目安と一緒に、一人で抱えない決まりとSVが引き取る基準を書くのが型です。割合はSVに聞いた実態を書き、良く見せません。

### 未経験の人にも送りたいのですが、「未経験歓迎」を書いてはいけませんか

経験者に送る文面と、未経験の層（接客や店舗からの転向）に送る文面を分けます。経験者向けに「未経験歓迎」が入っていると、「自分向けではない」「未経験でも回る仕事なのか」と読まれます。転向の層に送るなら、「未経験歓迎」ではなく、接客の経験の一点に触れ、対面と電話やチャットの違いと、研修の中身を書きます。同じ文面を全員に送らないことが、両方に届く近道です。

### 在宅を書きたいのですが、条件が細かくて長くなります

四段目に、週何日か、研修は出社か、機材はどうするか、の三つだけを書きます。それ以上の細かい条件は、面接で伝えます。在宅希望の層には、この三つが書いてあるかで返信が決まります。「在宅あり」だけで書くと、面接で条件を聞いて辞退されるので、三つは省きません。実態は現場に確認してから書きます。
