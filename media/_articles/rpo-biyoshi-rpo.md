美容師の採用を代行に出すか迷うサロンは、「求人を出しても応募が来ず、来てもすぐ辞めるか独立する」「オーナーが施術の合間に面接と返信をしていて、サロンが回らない」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接と技術確認の日程の確保・内定後の対応は代行に任せられ、スタイリストかアシスタントかとサロンのスタイルの整理・歩合と指名と練習の方針・教育とデビューまでの方針・雇用の形の方針・要件の決定・技術と接客とサロンとの相性の評価・合否の判断は社内に残す**のが線です。美容師は、スタイリストかアシスタントかで市場が全く違い、サロンの雰囲気とスタイルで届く層が変わり、候補者がサロンの投稿を見て判断し、歩合と練習と休みの実態を強く確かめます。「サロンのスタイルと歩合と練習と教育の実態を候補者に伝わる形で書き、オーナーの面接と返信の負担を減らす」ことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じく技術と師匠との相性で決まる調理師の線は[調理師採用を代行に出す判断基準](/media/rpo-chourishi-rpo/)にまとめています。

## 美容師採用が他の職種と違う点

一つ目は、スタイリストかアシスタントかで市場と判断材料が全く違うことです。スタイリストは、自分の指名客を持ち、歩合と指名の扱いとサロンのスタイルで判断し、指名客を連れて動くこともあります。アシスタントは、教育とデビューまでの期間と練習の実態とオーナーの人柄で判断します。「美容師募集」だけでは、どちらを求めているかが候補者に伝わりません。

二つ目は、サロンの雰囲気とスタイルと客層と単価で届く層が変わることです。カラーが得意なサロン、メンズに強いサロン、高単価のサロン、低単価で回転の速いサロン、地域密着のサロン。美容師は、自分の得意と作りたいスタイルに合うサロンを選び、サロンの投稿（施術の写真、スタッフの様子）を見て雰囲気を判断します。求人票の言葉より、投稿が先に見られています。

三つ目は、候補者が「歩合と指名の扱い」「営業後の練習と労働時間」「休みの取り方」「教育とデビューまでの期間」「オーナーや店長の人柄」「業務委託か雇用か」を最初に確かめることです。美容師は、歩合の率と指名の扱いで収入が決まり、営業後の練習が労働時間に入るかで生活が決まり、休みの取り方（定休日、連休）と教育のカリキュラムとデビューまでの期間で将来が決まります。練習の時間の扱いは、法令上の労働時間に関わるので、専門家にご確認ください。

四つ目は、国家資格で母数が限られ、離職と独立と復職が多いことです。美容師は、免許が無いと施術ができず、母数が限られます。一方で、離職と独立が多く、結婚や出産で離れた復職の層（資格を持ちながら働いていない人）が多い。時短や週数日で復帰したい層に届けることが、母集団を広げます。免許と業務の範囲は法令で定められているので、専門家にご確認ください。

五つ目は、オーナーや店長は施術に入っていて、採用の工程を回す人がいないことです。オーナーは予約が入っていて、面接と返信を施術の合間にしていて、応募が来ても返信が遅れて他のサロンに決まります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| スタイリストかアシスタントかとサロンのスタイルの整理 | 残す | どちらを採るか、サロンのスタイルと客層と単価と得意。社内にしか分からない |
| 歩合と指名と練習の方針の決定 | 残す | 歩合の率と指名の扱い、営業後の練習の有無と時間の扱い（法令上の扱いは専門家に確認）。オーナーが決める |
| 教育とデビューまでの方針の決定 | 残す | アシスタントの教育のカリキュラム、デビューまでの目安、練習の形。オーナーと店長が決める |
| 雇用の形の方針の決定 | 残す | 正社員か業務委託（面貸し）か、それぞれの条件。契約の扱いは専門家に確認 |
| 要件の決定 | 残す | スタイリストかアシスタントかとスタイルから。外部は整理を手伝える |
| 求人票の作成 | 任せられる（スタイルと方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。サロンの投稿と整合させる |
| 媒体の選定と運用 | 任せられる | 美容師に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | スタイリストかアシスタントかと得意と勤務地に合わせた検索と、候補者の作品や投稿に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、面接と技術確認の日程、サロンの見学の案内 |
| オーナー・店長の面接と技術確認の日程の確保 | 任せられる | 予約の合間や定休日に面接と技術確認の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | スタイリストかアシスタントか・得意・勤務地・免許の分類は任せられる。技術と相性の評価は残す |
| 技術と接客とサロンとの相性の評価 | 残す | オーナーや店長が技術確認と面接で見る |
| 歩合と練習と休みの実態の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | サロンの判断 |
| 条件の決定と提示 | 残す | サロンの判断。歩合と指名で条件の幅が広い |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。現在のサロンの区切り（指名客の引き継ぎ）に合わせた入社日の調整 |

線の要点は、「スタイリストかアシスタントかとサロンのスタイル、歩合と指名と練習の方針、教育とデビューまでの方針、雇用の形が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「このサロンで自分のスタイルを作れるか」「収入と生活が成り立つか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「美容師の求人を出しても応募が来ず、来てもすぐ辞める」というご相談です。求人票を見ると、「スタイリスト・アシスタント募集。アットホームなサロン。歩合あり。経験者優遇」と書かれていて、スタイリストとアシスタントのどちらを採るかも、サロンのスタイルと客層と単価も、歩合の率と指名の扱いも、営業後の練習の有無も、休みも、教育のカリキュラムもデビューまでの期間も無い。美容師はサロンの投稿を見た上で求人票を読み、「投稿は良いのに、条件が何も書いていない」と判断し、応募しないか、条件を聞いて辞退していました。

見ていて差がつくのは、「サロンのスタイルと歩合と練習と教育の実態を一文で言えるか」です。「〇〇駅前のサロンで、カラーが得意、客層は二十代から三十代の女性、単価は〇〇程度。スタイリストを一名、歩合は売上の〇割から、指名は全額本人に。営業後の練習は無く、練習はアシスタントの教育の時間として営業時間内に確保。休みは週に二日で月に一度は連休。アシスタントはカリキュラムがあり、デビューまでの目安は〇年。オーナーは『自分のスタイルを作ってほしい。指名客は本人のもの』と言っている」。一文でスタイルと実態が分かれば、候補者は「このサロンで自分のスタイルを作れるか」を判断できます。エラベルでは、美容師の案件をお受けする前に、依頼側に「スタイリストかアシスタントかとサロンのスタイル」と「歩合と練習と教育の実態」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：スタイリストかアシスタントかと、サロンのスタイル。** どちらを何名採るか。サロンの得意（カラー、カット、メンズ、ヘッドスパ）、客層、単価、投稿で見せているスタイル。スタイリストなら、指名客を連れてくることを期待するか、サロンの客を担当してもらうか。

**二つ目：歩合と指名と練習の方針。** 歩合の率と、指名の扱い（指名料の配分、指名客が本人のものか）、固定給の部分。営業後の練習の有無と時間と、その時間の扱い（労働時間に入るか）。練習の時間の扱いは、法令に関わるので専門家に確認します。

**三つ目：教育とデビューまでの方針。** アシスタントの教育のカリキュラム、デビューまでの目安、練習の形（営業時間内か、モデルの手配）、教育を担当する人。スタイリストの技術の研修（新しい技術、講習）。

**四つ目：雇用の形と、休みと労働時間の実態。** 正社員か業務委託（面貸し）か、それぞれの条件と契約（専門家に確認）。定休日と週の休みの日数、連休の取り方、営業時間と実態の労働時間、繁忙期（年末、卒業と入学の時期）。

**五つ目：オーナーや店長が、面接と技術確認にどのくらい時間を出せるか。** 予約の合間や定休日に、面接と技術確認（カットやカラーのモデルでの確認）とサロンの見学の時間をどう確保するか。返信と日程の調整をオーナーから外し、代行に出す設計。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## オーナーの関与のさせ方

美容師の採用では、オーナーや店長の関与が要ります。技術確認で技術を見る、面接で接客とサロンとの相性を見る、サロンのスタイルと歩合と練習と教育の実態を正直に話す。しかしオーナーは予約が入っていて、面接と返信が施術の合間になり、返信が遅れて他のサロンに決まります。

関与を取り付けるには、「採用の工程のどこをオーナーから外すか」を具体的に示すことです。「求人票と返信と日程の調整は代行が担い、オーナーは定休日の面接と技術確認だけ」。そして、負担を最小にする形で頼みます。面接と技術確認の枠は代行が定休日や予約の合間に押さえる、経歴と作品は代行が整理して渡す、モデルの手配と実態の説明の要点は代行が用意する。オーナーがやるのは、技術と相性を見ることと、実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接でオーナーが「サロンのスタイルの考え方と、歩合と練習と教育の実態」を自分の言葉で話すことの価値を、オーナー自身に理解してもらうことです。美容師は、オーナーとの相性で続けるかを決め、オーナーの人柄を最も気にしています。オーナーが「自分のスタイルを作ってほしい。指名客は本人のもの。営業後の練習はさせない。デビューは〇年で、自分が教える」と話すと、候補者は「このオーナーの下なら」と判断します。

## 代行を選ぶときの確認項目

美容師の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に美容業界やサロンの経験があるか。** 美容師そのものでなくても、サロンの運営やチェーンの本部、美容師の採用を回した経験。スタイリストとアシスタントの違い、歩合と指名の仕組み、練習の実態、サロンの投稿が候補者に見られていることを知っているか
- **サロンのスタイルと実態を求人票にどう書くか、案を出せるか。** 「アットホーム」「歩合あり」で済まさず、スタイルと客層と単価と歩合の率と指名の扱いと練習と教育とデビューまでの期間を書けるか
- **美容師に届く媒体と経路の経験。** 美容師向けの媒体、スカウト、美容専門学校、他のサロンのスタイリストへの届け方、復職の層、業務委託を望む人。経路ごとの経験
- **オーナーの負担を減らす設計。** 返信と日程の調整と一次対応をオーナーから外し、面接と技術確認だけを残す形にできるか。モデルの手配ができるか
- **オーナーの日程を押さえる段取り。** 定休日や予約の合間に面接と技術確認の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。美容業界を知らない担当者は、「アットホーム、歩合あり」の求人票を作り、オーナーの負担を減らせず、技術確認を組めません。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、美容師の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「歩合の率と指名の扱いと練習の実態を書かないと届かない」と言われることです。「歩合あり」だけの求人票は、「率が低いのだろう」と読まれ、練習の実態が無い求人票は「営業後に長時間の練習がある」と読まれます。率と扱いと実態を書くことで、候補者が判断できます。練習の時間の扱いは、法令に関わるので専門家に確認します。

二つ目は、応募者のスタイリストかアシスタントかと経路が分かれることです。他のサロンのスタイリスト（指名客を持つ人）、デビューしたばかりのスタイリスト、アシスタント、専門学校の卒業者、復職の層（時短や週数日）、業務委託を望む人。それぞれ持っているものと動く理由が違い、サロンのスタイルと合うかも違います。代行の担当者に分類をしてもらい、面接と技術確認で確かめることを変えます。

三つ目は、サロンの投稿と求人票の印象が違うと辞退されることです。投稿では明るく自由な雰囲気なのに、求人票と面接では「営業後に練習」「休みは少ない」と分かれば、候補者は「投稿は作られたもの」と読みます。投稿と求人票と面接で言うことを合わせておきます。

### エラベルの見解

担当する側から見ると、美容師の採用で最も効くのは、「歩合の率と指名の扱いと営業後の練習の有無を隠さず書く」ことと、「返信と日程の調整をオーナーから外す」ことです。美容師は、歩合と指名で収入を、練習で生活を判断し、「歩合あり」「アットホーム」の求人票を信じません。そして、オーナーが施術の合間に返信しているサロンは、応募が来ても他のサロンに決まります。

エラベルでは、美容師の案件で担当者を紹介するとき、最初の一週間でオーナーから「スタイリストかアシスタントかとサロンのスタイル」「歩合と指名と練習の方針」「教育とデビューまでの方針」「雇用の形と休みの実態」を聞き取り、一文にするところから始めてもらっています。技術と接客と相性の評価はオーナーが技術確認と面接で行い、返信と日程の調整とモデルの手配は担当者が回します。練習の時間の扱いと業務委託の契約と免許の扱いは、専門家にご確認いただくようお伝えしています。

- 代行に出す前に**スタイリストかアシスタントかとスタイル、歩合と指名と練習の方針（練習の時間の扱いは専門家に確認）、教育とデビューまでの方針、雇用の形と休みの実態、オーナーの面接と技術確認の時間**を確認する
- オーナーの関与は**採用の工程のどこをオーナーから外すかを示し、負担を面接と技術確認だけにして、実態を自分の言葉で話す価値を理解してもらう**
- 代行を選ぶときは**美容業界の経験・実態の書き方・美容師に届く経路・オーナーの負担を減らす設計とモデルの手配・日程の段取り**を確認する
- 出したあとは**歩合の率と練習の実態を書く必要が表に出る・スタイリストかアシスタントかと経路が分かれる・投稿と求人票の印象の差で辞退される**。判断はオーナー、材料は代行

## よくある質問

### 営業後の練習があるのが実態です。書くと来ませんか

隠して入ってから分かるほうが、辞退と離職を生みます。営業後の練習の有無と時間と、その時間の扱い（労働時間に入るか、手当があるか）を正直に書きます。練習の時間の扱いは法令上の労働時間に関わるので、専門家に確認した上で、実態を整えてから書きます。営業時間内に練習の時間を確保しているサロンは、それ自体が訴求になります。営業後の練習を避けたい人は見送りますが、扱いが明確なら受け入れられる人には届きます。

### スタイリストが指名客を連れて独立するのが心配です

独立が多い職種で、隠せません。「指名客は本人のもの」と明確にするサロンと、「サロンの客」とするサロンがあり、どちらの方針かを正直に書きます。独立を前提に、「〇年の後に独立の支援（物件、機材、独立後の関係）」を示すサロンは、独立志向の腕のあるスタイリストに届きます。独立させたくないなら、店長や複数店舗への道筋と、業務委託（面貸し）の選択肢を示します。方針を決めて正直に書けば、合う人が来ます。業務委託の契約は、専門家にご確認ください。

### 復職の美容師に届けるには、何を書けばよいですか

「時短や週数日から」「ブランクへの練習の時間（営業時間内に）」「子どもの行事や急な休みへの対応」「土日のどちらかの免除」「歩合と固定の組み合わせ」「サロンの近さ」を書き、地域の求人として出します。結婚や出産で離れた美容師は、資格を持ちながら働いていない人が多く、「戻ってもよいと思えるサロン」を探しています。フルタイムと土日と営業後の練習が前提の求人票には応募しません。時短と週数日の枠を作り、その層に届けます。免許と業務の範囲は、専門家にご確認ください。
