依頼側の人事の担当者と、現場の責任者の意見が合わない。担当者からは「現場が要件を決めてくれない」と聞き、現場からは「人事が候補者を絞りすぎる」と聞く。どちらからも「外部の目で見て、どう思いますか」と聞かれ、答えた内容が、いつの間にか「外部の人もそう言っている」と、片方の主張に使われていた。結論を先に書くと、**外部の担当者が社内の力関係に巻き込まれるのは、外部の立場を「中立の第三者」と思われ、片方の主張の裏付けとして使われるからです。巻き込まれると、もう片方から見て「あちらの味方」になり、その後の仕事が進まなくなります。**線は三本で、「依頼側との窓口は担当者一人に固定する」「判断は依頼側に返し、自分の意見を主張として出さない」「話すのは事実だけで、評価や推測は言わない」です。外部の立場でできることの整理は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に、現場との関係は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に、経営者と直接話す場面は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)にまとめています。

## 巻き込まれる典型の場面

巻き込まれる場面は、どの依頼側でも似た形で起きます。

| 場面 | 何が起きるか | 巻き込まれ方 |
|---|---|---|
| 人事と現場の要件の対立 | 人事は「幅広く」、現場は「絞って」と言い、要件が決まらない | どちらかに「外部の目で、どちらが正しいと思うか」と聞かれ、答えると、その答えが片方の主張に使われる |
| 担当者と上長の方針の違い | 担当者は型を整えたい、上長は早く数字を出したい | 担当者から「上長を説得する材料をくれ」と頼まれ、上長から「担当者は何をしているのか」と聞かれる |
| 経営者と人事の距離 | 経営者が人事を通さず、外部の担当者に直接指示する | 人事の担当者を飛び越えて動くことになり、担当者から見て「経営者の側の人」になる |
| 前任の担当者との比較 | 「前の外部の人はこうしていた」と、現任の担当者の方針を否定する材料に使われる | 前任との違いを聞かれ、答えると、現任の批判に使われる |
| 複数の外部の担当者の間 | 依頼側が複数の外部を入れていて、評価を比べている | 他の外部の担当者の仕事について聞かれ、答えると、その人の評価に使われる |
| 候補者の合否をめぐる対立 | 面接官と人事で合否の判断が割れている | 「外部から見てどう思うか」と聞かれ、答えると、合否の判断に外部が関わったことになる |

場面の要点は、「『外部の目で見て』と聞かれたとき」が入口だということです。この問いは、中立の意見を求めているように聞こえますが、多くの場合、聞く側はすでに答えを持っていて、外部の裏付けを探しています。答えれば、その答えは「外部の人もそう言っている」として、社内の議論に使われます。

## 巻き込まれた後に起きること

片方の味方と見られた後、何が起きるかを知っておくと、線の重さが分かります。

| 起きること | 内容 |
|---|---|
| もう片方から協力が得られなくなる | 現場の味方と見られれば人事が、人事の味方と見られれば現場が、情報を出さず、日程を組まず、返事を遅らせる |
| 自分の範囲の仕事が止まる | 面接官の予定が取れない、要件が決まらない、記録に協力してもらえない。自分の工程が、社内の対立で止まる |
| 担当者との関係が壊れる | 担当者を飛び越えて上長や経営者と話したことで、担当者が「自分の立場を脅かす人」と見る |
| 契約の更新に影響する | 更新の判断をする人が、自分を「あちらの味方」と見ていれば、更新されない |
| 判断の責任を負わされる | 「外部の人がそう言ったから」と、社内の判断の責任を外部に置かれる |
| 依頼側の社内の情報を、意図せず別の人に渡すことになる | 片方から聞いた話を、もう片方に伝えることで、情報の流れを作ってしまう |

起きることの要点は、「自分の範囲の仕事が、社内の対立で止まる」ことです。外部の担当者の仕事は、依頼側の社内の複数の人の協力で成り立っています。片方の味方と見られた瞬間に、もう片方の協力が消え、仕事は止まります。中立を保つことは、姿勢の問題ではなく、仕事を進めるための条件です。

### エラベルの見解

相談で最も多い思い込みは、「外部の立場だから、社内の対立とは無関係でいられる」というものです。実際には、外部の立場だからこそ、社内の対立で使われます。社内の人の意見は「立場があるから」と割り引かれますが、外部の人の意見は「立場が無いから中立だ」と見られ、裏付けとして重宝されます。だから、外部の担当者の一言は、社内の人の一言より、対立の中で重く使われます。

見ていて差がつくのは、「外部の目で見てどう思うか」と聞かれたときの答え方です。巻き込まれない人は、「私の立場では判断できませんが、事実としては〇〇です」と、判断を返し、事実だけを話しています。事実は、どちらの主張にも使えず、使われても事実なので問題になりません。巻き込まれる人は、「私は〇〇のほうがよいと思います」と意見を言い、それが主張の裏付けになっています。エラベルでは、担当者が依頼側の社内の判断に踏み込まず、判断の材料（事実）を出すところまでを役割としています。判断を返す担当者は、社内のどの立場の人からも「使いやすい」ではなく「信頼できる」と見られています。

## 外部の担当者が狙われる構造

なぜ外部の担当者が、社内の対立の裏付けに使われるのかを、構造で見ます。

| 構造 | 内容 |
|---|---|
| 立場が無いと見られる | 社内の人の意見は「人事の立場」「現場の立場」と割り引かれるが、外部の意見は「立場が無い」と見られ、割り引かれない |
| 専門性があると見られる | 「人事の専門家がそう言っている」は、社内の議論で強い |
| 責任を負わない | 外部の人の意見で決めれば、決めた側は「外部の助言に従った」と責任を薄められる |
| 反論しにくい | 外部の人は社内の議論に参加しないので、意見を引用されても、その場で訂正できない |
| 契約で動いている | 依頼側の担当者が契約の窓口なら、担当者の側に立つと見られやすい。逆に、経営者が契約の窓口なら、経営者の側と見られる |

構造の要点は、「外部の意見は、社内の議論で割り引かれずに使われる」ことです。自分では「一つの意見」として言ったことが、社内では「外部の専門家の判断」として扱われます。だから、意見を言わず、事実を出す。事実は、どう使われても事実で、自分の判断として扱われることはありません。判断の所在の考え方は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)に書いています。

## 兆しの見つけ方

巻き込まれる前に、兆しがあります。

| 兆し | 何が起きているか |
|---|---|
| 「外部の目で見てどう思うか」と聞かれる回数が増えた | 裏付けとして使われ始めている |
| 担当者以外の社内の人から、直接連絡が来るようになった | 窓口が複数になり、どちらかの側に寄りやすくなっている |
| 「〇〇さんには言わないでほしい」と前置きされた | 片方の側の情報を、もう片方に隠す形で受け取っている。すでに巻き込まれかけている |
| 自分の言った言葉が、別の人から聞こえてきた | 意見が引用され、社内で使われている |
| 依頼側の社内の人の評価を聞かれた | 「担当者はどうか」「面接官はどうか」。答えると、人の評価に関わる |
| 前任や他の外部の担当者との比較を求められた | 比較が、現任の批判や、他の外部の評価に使われる |
| 定例に、担当者以外の人が入ってきて、担当者と意見が割れた | 定例が対立の場になっている |

兆しの要点は、「『〇〇さんには言わないでほしい』と前置きされたとき」が、最も明確な兆しだということです。この前置きは、片方の側の情報を、もう片方に隠す形で預けられることで、預かった時点で、その側に立ったことになります。この前置きが来たら、「私は担当者を通して動いているので、担当者に共有できない話は伺えません」と、その場で線を引きます。

## 巻き込まれないための三本の線

三本の線を、最初から引いておきます。

| 線 | 内容 | 使い方 |
|---|---|---|
| 一、窓口は担当者一人に固定する | 依頼側との連絡と判断の確認は、契約の窓口である担当者を通す。他の社内の人から直接連絡が来ても、「担当者を通してください」か、担当者に共有したうえで対応する | 担当者を飛び越えない。担当者に共有できない話は受けない。[現場との関係の作り方](/media/fukugyo-genba-chousei/) |
| 二、判断は依頼側に返す | 「どちらが正しいか」「どうすべきか」を聞かれても、自分の意見を主張として出さない。「私の立場では判断できません。判断の材料として、事実は〇〇です」 | 意見を求められたら、選択肢と事実を出し、選ぶのは依頼側という形にする。[改善提案の伝え方](/media/fukugyo-kaizen-teian/) |
| 三、話すのは事実だけ | 依頼側の記録で確認できること、自分の範囲で起きたことだけを話す。人の評価、推測、他社との比較は言わない | 「担当者はどうか」と聞かれたら「私の範囲では、担当者との連絡は滞りなく進んでいます」と、事実で答える。評価はしない |

三本の要点は、「一」の窓口の固定が、他の二本の土台になることです。窓口が担当者一人なら、他の社内の人から意見を求められる場面そのものが減ります。求められても、「担当者に共有します」と言えば、隠す形の情報は受けずに済みます。経営者が直接指示してくる場合も、担当者に共有したうえで動く形にすれば、担当者を飛び越えたことになりません。経営者との距離は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、社内の人事担当との分担は[社内の人事担当との役割分担](/media/fukugyo-shanai-jinji/)に整理しています。

## 巻き込まれてしまったときの抜け方

すでに片方の味方と見られている場合、抜ける順番があります。

| 手順 | 内容 |
|---|---|
| 一、自分の言葉が使われたことを認める | 「私の発言が、そのように使われたことを承知しました」と、事実として受け止める。言い訳をしない |
| 二、判断を返し直す | 「私の発言は判断ではなく、事実の共有でした。判断は御社でしていただくものです」と、使われた発言の位置づけを直す |
| 三、窓口を担当者に戻す | 他の社内の人との直接の連絡を減らし、担当者を通す形に戻す。担当者に「今後は担当者を通して動きます」と伝える |
| 四、もう片方の側に、事実で接する | 味方と見られなかった側に、自分の範囲の事実（進捗、記録）を丁寧に共有し、仕事で信頼を戻す。意見は言わない |
| 五、対立そのものには触れない | 対立の解消を自分の役割にしない。自分の範囲の仕事を、両方の協力を得て進めることに集中する |
| 六、抜けられないなら、更新の節目で終える | 対立が深く、どちらの側に立っても仕事が進まないなら、その案件は自分の範囲で動ける状態ではない。[合わない案件の見分け方](/media/fukugyo-awanai-anken/) |

抜け方の要点は、「対立を解消しようとしない」ことです。巻き込まれた人が、対立を自分で解消しようとすると、さらに深く巻き込まれます。自分の役割は、自分の範囲の仕事で、対立の解消ではありません。両方に事実で接し、自分の範囲を進め、対立には触れない。この形で、時間をかけて中立の位置に戻ります。

## 担当者が替わったときの注意

依頼側の担当者が替わると、力関係が変わり、巻き込まれ方も変わります。

| 状況 | 注意 |
|---|---|
| 新任が前任と方針が違う | 前任の方針を、新任の前で擁護しない。「前任のときはこうしていました」は事実として、「こうすべき」は言わない |
| 新任が前任の批判を求めてくる | 「前任の方はどうでしたか」と聞かれても、評価はしない。「前任の方とは、こういう進め方で合意していました」と、事実だけ |
| 新任が、自分を前任の側と見る | 前任と親しかった外部の担当者は、新任から「前任の側の人」と見られやすい。新任と最初に窓口と判断の所在を合意し直す |
| 前任が別の部署に残っている | 前任から連絡が来ても、新任を通す。前任との直接の連絡は、新任に共有できる範囲で |
| 新任が経営者や上長と対立している | 巻き込まれる構造が新しく始まる。三本の線を、新任との最初の打ち合わせで引き直す |

注意の要点は、「新任との最初の打ち合わせで、窓口と判断の所在を合意し直す」ことです。前任との合意は新任に引き継がれておらず、新任は自分をどう見るかを決めていません。最初に「窓口は新任の方一人、判断は御社、私は事実を出す」と伝えれば、新任は自分を「前任の側」ではなく「外部の担当者」として見ます。担当者の交代への備えは[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

### エラベルの見解

担当する側から見ると、社内の対立がある依頼側で長く続いている人は、対立を見ていないのではなく、対立を見たうえで、三本の線を守っている人です。窓口を担当者に固定し、意見を求められたら判断を返し、事実だけを話す。対立の両側から「外部の目で」と聞かれても、同じ答え方をしているので、どちらの側にも立たず、どちらからも「信頼できる」と見られています。

順番として、案件の最初に窓口を担当者一人に決め、判断は依頼側に返すと合意し、「外部の目で」と聞かれたら事実だけを答え、「〇〇さんには言わないで」と前置きされたら線を引き、巻き込まれたら対立の解消を役割にせず自分の範囲に戻る。担当者が替わったら、線を引き直す。この順番で、社内の力関係は、自分の仕事を止めるものではなくなります。エラベルでは、依頼側の窓口を一人に決め、担当者の判断の範囲を契約で明確にする形を取っています。窓口が一人であることは、担当者が社内の対立に巻き込まれないための、仕組みの側の線です。

## まとめ

- 巻き込まれるのは**外部の立場が「中立の第三者」と見られ、片方の主張の裏付けに使われる**から
- 入口は**「外部の目で見てどう思うか」と聞かれたとき**。答えれば、その答えが社内で使われる
- 巻き込まれると**もう片方の協力が消え、自分の範囲の仕事が止まり、更新に影響する**
- 兆しは**「外部の目で」が増える・担当者以外から直接連絡が来る・「〇〇さんには言わないで」と前置きされる・自分の言葉が別の人から聞こえる**
- 線は三本。**窓口は担当者一人・判断は依頼側に返す・話すのは事実だけ**
- 巻き込まれたら**認め・判断を返し直し・窓口を戻し・もう片方に事実で接し・対立の解消を役割にしない**
- 担当者が替わったら**線を引き直す**

## よくある質問

### 担当者自身が、上長との対立で私を味方につけようとしています

担当者が契約の窓口でも、担当者の主張の裏付けにはなりません。「担当者の方の考えは理解しました。上長の方への説明に使える事実として、〇〇と〇〇があります」と、事実を材料として渡し、「私の意見として上長に伝える」形は避けます。担当者が上長に「外部の人もそう言っている」と言いたがるなら、「私の立場では判断はできないので、事実の共有として使ってください」と線を引きます。担当者を助ける形は、意見の裏付けではなく、担当者が使える事実を渡すことです。提案の材料の渡し方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

### 経営者から直接「人事の担当者は頼りないから、君が進めてくれ」と言われました

経営者の言葉に乗って担当者を飛び越えると、担当者との関係が壊れ、その後の仕事が進みません。「担当者の方と一緒に進める形で、ご期待に応えます」と、担当者を通す形を保ちます。経営者からの指示は担当者に共有し、担当者を通して動きます。経営者が担当者を外したいなら、それは依頼側の社内の判断で、外部の担当者が関わることではありません。経営者との距離の取り方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

### 対立が深く、どちらの側とも仕事が進みません

三本の線を守っても、対立が深すぎて自分の範囲の仕事が進まないなら、その案件は、外部の担当者が動ける状態にありません。担当者に「私の範囲の仕事を進めるために、〇〇と〇〇の協力が要る」と事実で伝え、それでも動かなければ、更新の節目で終えることを考えます。対立の解消は自分の役割ではなく、解消されないまま契約を続けても、成果は出ず、評価も下がります。終え方は[合わなかったらやめられるか](/media/fukugyo-qa-7/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に整理しています。
