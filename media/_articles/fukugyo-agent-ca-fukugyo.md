人材紹介の会社で、キャリアアドバイザー（CA）として、候補者側を担当してきた。転職の相談を受け、求人を提案し、面接の対策をし、内定の後の迷いに寄り添い、辞退の本音を聞いてきた。この経験は、企業側の人事の副業で売れるのか。候補者の味方だった自分が、企業側に立てるのか。結論を先に書くと、**CAの経験は、「候補者と向き合い、転職の理由を聞き、企業と合わせ、辞退の本音を知っている」型で売れます。売れるのは、「候補者との面談の設計と実施」「辞退の理由の聞き取り」「候補者の目線での求人票と面接の改善」「内定から入社までの繋ぎ」の四つです。企業側の担当者は、候補者が何で決め、何で離れるかを、候補者の本音として聞く機会が無く、CAはそれを毎日聞いてきています。「候補者の側にいました」ではなく、「候補者が何で決め、何で離れるかを、企業側で使う」と売ります。紹介の形は捨て、候補者の情報は持ち込みません。**人材紹介の経験の評価は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に、RAの経験の売り方は[人材紹介のリクルーティングアドバイザーが副業でできること](/media/fukugyo-agent-ra-fukugyo/)に、キャリアコンサルタントの売り方は[キャリアコンサルタントが副業でできること](/media/fukugyo-kyaria-consultant-fukugyo/)にまとめています。

## この経歴の何が売れるか

CAの経験を、企業側の担当者としての工程に置き換えた棚卸しです。担当した候補者と前の会社の情報は含めず、「型」として抜き出します。

| CAの経験 | 企業側の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 候補者の転職の理由を聞いてきた | 依頼側の面談で、候補者の転職の理由と求めるものを引き出し、依頼側と合うかを確かめる面談の型 | 面談が会社の説明で終わり、候補者の本音が分からない依頼側が多い |
| 辞退の本音を聞いてきた | 辞退した候補者から、当たり障りのない答えの奥にある理由を聞き、求人票と面接と条件に反映する | 辞退の理由が「他社に決めた」で止まっている依頼側が多い |
| 候補者と一緒に求人票を読んできた | 求人票を「候補者が読んでどこで冷めるか」で直す | 求人票が社内の言葉で書かれている依頼側が多い |
| 面接の対策をしてきた | 候補者がどの質問で困り、どの面接官の態度で離れるかを知っていて、面接の設計を候補者の目線で直す | 面接で候補者が離れている依頼側が多い |
| 内定の後の迷いに寄り添ってきた | 内定から入社までの繋ぎの型（連絡の頻度、不安の聞き取り、家族への説明の支援） | 内定の後に辞退される依頼側が多い |
| 複数の求人を候補者に提案してきた | 候補者が複数の企業を比べるときに何を見るかの型。依頼側の魅力を候補者の言葉に置き換える | 自社の魅力を候補者の言葉で言えない依頼側が多い |
| 多数の候補者を同時に動かしてきた | 複数の候補者の進捗と連絡を漏れなく管理する型 | 候補者が複数になると連絡が漏れる依頼側が多い |

売れるものの要点は、「候補者の本音を、企業側は聞けない」ことです。企業側の担当者に、候補者は本音を言いません。辞退の理由も、面接で困ったことも、他社と比べて何が弱かったかも、企業には伝わりません。CAは、候補者の側にいたからこそ、その本音を毎日聞いてきています。その型を企業側で使うと、依頼側の採用は、候補者の側から見えるようになります。面談の型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に、内定の繋ぎは[新卒採用担当が副業でできること](/media/fukugyo-shinsotsu-tantou-fukugyo/)に書いています。

## 売りにくい点とその扱い

CAの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 候補者の味方の立場 | 「候補者の味方になって、うちの採用に不利なことをするのでは」。自分にとっても、候補者を企業側の目的で見ることへの抵抗 | 「依頼側と候補者が合うかを確かめる」立場に立つ。合わない候補者を無理に進めないことは、候補者にも依頼側にも利益がある、と整理する。立場を最初に示す |
| RAとの分業の穴 | CAは候補者側の担当で、企業の要件の聞き取りや求人の設計はRAが担っていたので、「企業側の工程を知っているのか」 | 企業側の工程（要件の聞き取り、求人の設計、企業との交渉）は経験が薄いことを正直に示し、候補者の目線の工程を主に売る。企業側の工程は、依頼側の担当者と一緒に学ぶ |
| 候補者の情報の線 | 「前の会社で担当していた候補者を連れてくるのでは」 | 担当した候補者と情報は持ち込まない。型だけを持ち込む。退職後の競業と守秘の条件を確認する。紹介の形で報酬を受けることの可否は専門家に |

扱い方の要点は、「候補者の味方から、合うかを確かめる立場へ」の切り替えを、自分の中で整理することです。CAは、候補者の味方であることが仕事の土台で、企業側の副業に入るとき、その土台と企業の目的が衝突すると感じることがあります。「合わない候補者を無理に進めないことは、候補者にも依頼側にも利益がある」と整理すれば、候補者を守ることと企業側の採用を担うことは衝突しません。この整理を、依頼側と候補者の両方に示します。法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)の「法令で気をつける点」に、前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、CAから転身して続いている人と、案件が取れないか一件で終わる人の差は、「候補者の側にいました」と言うか、「候補者が何で決め、何で離れるかを知っていて、御社の求人票と面接と繋ぎを候補者の目線で直します」と言うかです。前者は依頼側に「うちの味方ではない人」と映り、後者は「候補者の本音を知っている人」と映ります。CAの経験は、候補者側の言葉のまま売ると警戒され、企業側の工程に置き換えると強く伝わります。

見ていて差がつくのは、辞退の理由を聞き取る場面で、CAの頃と同じ深さで聞けているかです。企業側の担当者として辞退の理由を聞くと、候補者は「他社に決めました」と当たり障りなく答えます。CAの経験がある人は、「他社のどこが決め手でしたか」「うちで気になった点は」「もし条件が違ったら」と、候補者が本音を言いやすい聞き方の型を持っていて、企業側の立場でも奥まで聞けています。その理由を求人票と面接と条件に反映した人は、依頼側の辞退が減り、「辞退の理由を初めて知った」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、候補者の本音を知る型を明確にし、立場を示している担当者に、候補者の側が見えていない依頼側がついています。CAの転身は、候補者の知識ではなく、立場の整理と聞き方の型で始まります。

## 案件の探し方

CAから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 候補者との面談の設計と実施 | 面談の技法でそのまま入れる | 「候補者の本音を引き出し、御社と合うかを確かめる面談」を範囲の一言に |
| 辞退の理由の聞き取りと反映 | 辞退の本音を聞いてきた経験で入れる | 「辞退が多い依頼側」を範囲の一言に |
| 求人票を候補者の目線で直す | 候補者と求人票を読んできた経験で入れる | 「候補者が読んでどこで冷めるか」で直す、を成果物の形で |
| 面接の設計を候補者の目線で直す | 面接の対策をしてきた経験で入れる | 「面接で候補者が離れる依頼側」を範囲の一言に |
| 内定から入社までの繋ぎ | 内定の後の迷いに寄り添ってきた経験で入れる | 「内定辞退が多い依頼側」を範囲の一言に |
| 依頼側の魅力の言語化 | 複数の求人を提案してきた経験で入れる | 「候補者が比べるときに見る点で、御社の魅力を言葉に」を成果物の形で |

探し方の要点は、「辞退が多い依頼側」から入ることです。辞退は、選考の途中でも内定の後でも、依頼側にとって最も理由が分からず、最も損失が大きい詰まりで、CAの辞退の本音を聞く型が最も効きます。一件で辞退を減らせれば、面談と求人票と面接の改善に広げられます。企業側の工程（要件の聞き取り、求人の設計）は、経験が薄い部分なので、最初は範囲に入れないか、依頼側と一緒に学びながら担います。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。CAの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 紹介の手数料との比較 | 紹介の手数料と、担当者の副業の単価は、決まり方が全く違う | 手数料の感覚を持ち込まない。担当者の工程の単価で |
| 面談の技法の価値 | 候補者の本音を引き出す面談は、人事経験者でも得意な人が少なく、評価される | 面談は回数で受ける |
| 辞退の削減の価値 | 辞退を減らす価値は、依頼側にとって分かりやすい | 「減った辞退」を成果として示せる形に |
| 求人票と面接の改善 | 成果物で受けやすい | 成果物で受ける |
| 企業側の工程を含まないこと | 要件の聞き取りや求人の設計を含まない範囲は、含む範囲より単価は下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 紹介の習慣で誘われやすいが、判断は依頼側にあり、許可の線にも関わる | 時間か回数か成果物で。可否は専門家に確認 |
| 前の会社との契約の条件 | 退職後の競業と守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「面談を回数で受け、辞退の削減を成果として示せる形にする」ことです。CAの経験の核は面談で、面談は一回あたりの時間が読みやすく、回数で受けると単価の議論が明確になります。辞退の理由の聞き取りと反映は、「減った辞退」として依頼側に価値が見えるので、更新の根拠になります。成果報酬は、判断が依頼側にあることと、許可の線に関わることから、最初は避け、可否は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

CAから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、紹介の形で報酬を受けることの可否と、前の会社との契約の条件を、専門家に確認する | 職業紹介の許可、競業、守秘 |
| 二、「候補者の味方」から「合うかを確かめる立場」への切り替えを、自分の言葉で書く | 立場の整理 |
| 三、候補者から聞いてきた「決める理由」「離れる理由」「辞退の本音」を、候補者と企業の情報を含まない型で書き出す | 型の抜き出し |
| 四、得意な工程（面談、辞退の理由、候補者の目線の改善、繋ぎ）と、薄い工程（要件の聞き取り、求人の設計、企業との交渉）を分ける | 正直に示す準備 |
| 五、範囲を、面談、辞退の理由、求人票と面接の候補者の目線での改善、繋ぎ、魅力の言語化に絞る | 企業側の工程は最初は範囲外か、依頼側と一緒に |
| 六、「候補者が何で決め、何で離れるかを、企業側で使う」の一言を作る | 「候補者の側にいました」で終わらせない |
| 七、登録先に、範囲と、立場と、紹介との線を登録する | 辞退が多い依頼側 |
| 八、辞退の理由の聞き取りか面談を一件、回数か成果物で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「二」の立場の切り替えを、自分の言葉で書いておくことです。CAは候補者の味方であることに誇りを持っていて、企業側に立つことに抵抗を感じることがあります。「合わない候補者を無理に進めないことは、候補者にも依頼側にも利益がある。合う候補者を、候補者の本音を知る型で見つけることが、候補者のためでもある」と整理しておけば、抵抗は消え、依頼側にも候補者にも誠実に動けます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「CAは候補者の味方なので、企業側の副業とは相性が悪い」というものです。実際には、依頼側は候補者の本音を聞けず、候補者が何で決め、何で離れるかが見えておらず、それを知っている人を求めています。相性が悪いのは、立場を整理せずに候補者の味方のまま入る場合で、「合うかを確かめる」立場に立てば、候補者の本音を知る型は、企業側で最も価値のある視点になります。

順番として、紹介の形の可否と前の会社との契約を専門家に確認し、立場の切り替えを自分の言葉で書き、候補者から聞いてきた理由を型で書き出し、得意な工程と薄い工程を分け、範囲を候補者の目線の工程に絞り、候補者が何で決め何で離れるかを企業側で使う一言を作り、登録先に範囲と立場と線を登録し、辞退の理由の聞き取りか面談を一件受けて型を残す。この順番で、CAの転身は、「候補者の味方で相性が悪いもの」から「候補者の本音を企業側に届ける形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、候補者の本音を知る型を明確にし、立場と線を示している担当者に、候補者の側が見えていない依頼側がついています。CAの転身は、候補者の知識ではなく、立場の整理と聞き方の型で始まります。

## まとめ

- CAの経験は**「候補者と向き合い、転職の理由を聞き、企業と合わせ、辞退の本音を知っている」型**で売れる。**面談の設計と実施・辞退の理由の聞き取り・候補者の目線での求人票と面接の改善・内定の繋ぎ**の四つ
- **「候補者の側にいました」ではなく「候補者が何で決め、何で離れるかを、企業側で使う」**と売る
- 売りにくい点は**候補者の味方の立場・RAとの分業の穴・候補者の情報の線**。「合うかを確かめる」立場に切り替え、企業側の工程が薄いことは正直に示し、候補者と情報は持ち込まない
- 最も効くのは**辞退の本音を聞く型**。企業側の担当者には候補者が本音を言わない
- 案件は**辞退が多い依頼側**から。面談と求人票と面接の改善に広げる
- 単価は**紹介の手数料の感覚を持ち込まず、面談は回数、改善は成果物**で。成果報酬は最初は避け、可否は専門家に確認

## よくある質問

### 前の会社で担当していた候補者から、今も転職の相談を受けます。副業の依頼側に合いそうですが、紹介してよいですか

紹介しません。前の会社で担当した候補者との関係と情報は、前の会社と候補者のものであり、副業の依頼側に回すと、前の会社との守秘と競業の線、候補者の信頼、紹介の許可の線の三つに問題が出ます。相談を受けたときは、副業の依頼側とは切り離し、候補者には紹介の会社や公的な窓口を案内する形にします。副業では、依頼側の名前で、依頼側の媒体と経路で集まった候補者と向き合います。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に整理しています。

### 企業側の面談で、候補者に「この会社はやめた方がいい」と思ったとき、どうすればよいですか

候補者に直接「やめた方がいい」と助言することは、企業側の担当者の立場では避けます。代わりに、候補者が気になっている点を聞き取り、依頼側に「合わない理由」として材料を渡します。依頼側がその点を直せるなら直し、直せないなら依頼側が判断します。合わない候補者を無理に進めないことは依頼側の利益でもあり、「この候補者は〇〇の点で合わない可能性があります」と伝えることは、依頼側のためになります。候補者の味方でいる形は、依頼側に材料を渡す形で保てます。候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

### 企業の要件の聞き取りや求人の設計は、RAがやっていたので経験がありません

最初は範囲に入れず、候補者の目線の工程（面談、辞退の理由、求人票と面接の候補者の目線での改善、繋ぎ）に絞って受けて構いません。「要件の聞き取りと求人の設計は御社の担当者が。私は候補者の目線で、求人票のどこで冷めるか、面接のどこで離れるか、辞退の本音は何かを担います」と示せば、範囲が明確です。企業側の工程も担いたいなら、依頼側の担当者と一緒に要件を聞き取りながら型を学びます。RAの経験がある人と組む形も、エラベルのような登録先では可能なことがあります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、分担は[チームで動くときの分担](/media/fukugyo-chiimu/)に整理しています。
