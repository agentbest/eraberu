メーカー業界の会社が採用代行を検討するとき、動機は「設計や生産技術の経験者が来ない」「工場の現場の人が集まらない」であることが多い。ただ、メーカーの採用は、他の業界と違う難しさがあります。技術職と現場職と事務職で経路も要件も違い、拠点が地方にあって勤務地で候補者が絞られ、製品と工程の知識が要件に入るので経歴の言葉に直しにくく、採用の担当が総務や人事の兼務で時間が無い。結論を先に書くと、**メーカー業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、製品と工程の要件の決定・技術の見極め・勤務地と条件の判断は社内に残さないと、採れても現場に合いません。**代行に出す前に、難しさを自社の状況で分解し、職種の型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[機械設計採用を代行に出す判断基準](/media/rpo-kikai-sekkei-rpo/)、[生産技術採用を代行に出す判断基準](/media/rpo-seisan-gijutsu-rpo/)、[品質管理採用を代行に出す判断基準](/media/rpo-hinshitsu-kanri-rpo/)に、地方の拠点の考え方は[地方企業の採用代行](/media/rpo-chihou-kigyo-rpo/)に書いています。ここでは、メーカー業界で共通する切り分けに絞ります。

## メーカー業界の採用が難しい四つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 職種の型で経路と要件が違う | 技術職（設計・生産技術・品質・研究開発）はスカウトと紹介、現場職（製造・保全）は掲載型と地域の経路、事務職は掲載型。同じ代行で全部は回らない | 職種の型ごとに代行の型が要る |
| 勤務地で候補者が絞られる | 工場や拠点が地方にあり、通える範囲か転居できる人に限られる | 母集団が小さい。地域の経路と、転居の条件を先に出す必要 |
| 製品と工程の知識が要件に入る | 「〇〇の製品の〇〇の工程」の経験が必須になり、代行が経歴の言葉に直しにくい | 要件の整理に社内の技術者の時間が要る |
| 採用の担当が兼務 | 総務や人事が採用も見ていて、返事と日程が遅れる | 一次対応と日程を外に出すと効きやすい |

四つのうち、代行で解決できるのは母集団形成と速さで、要件と見極めと勤務地の判断は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 製品と工程の要件の決定 | 残す | 社内の技術者と現場の責任者が決める |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の製品の〇〇の工程で、〇〇を担った経験」に。代行が整え、技術者が確認 |
| 母集団形成（媒体・スカウト・地域の経路） | 任せられる | 職種の型ごとの経路の型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 兼務の担当の負担を減らす。速さが要る |
| 書類の一次確認 | 一部任せられる | 「製品の型・工程・担った範囲」の照合は外で。技術の深さは社内 |
| 技術の見極め（面接、現場の見学） | 残す | 社内の技術者と現場の責任者 |
| 勤務地と転居の条件の判断 | 残す | 会社の判断。先に出すかどうかも |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 一覧と週次の一枚 |

「勤務地と転居の条件」は、メーカーに特有の残す工程です。先に出すかどうかで、母集団の大きさと辞退の数が変わります。

### エラベルの見解

メーカー業界で多くの会社が見落とすのは、「職種の型ごとに代行の型が違う」ことです。設計の経験者はスカウトと紹介で、製造の現場の人は地域の掲載型とハローワークや学校の経路で、事務職は掲載型で、と経路が違うのに、一つの代行に「採用を全部」と頼み、代行は得意な型（多くはスカウト）だけを回し、現場職が集まらない。「設計はスカウトの母集団形成を代行に、現場職は地域の経路の運用を代行に、事務職は自社で」のように、職種の型ごとに任せる工程を分けると、機能します。エラベルで担当者を選ぶ企業には、「いま採りたい職種は、技術職・現場職・事務職のどの型で、それぞれの経路は決まっていますか」を、私たちから先に聞いています。答えが「全部まとめて」なら、代行の前に型の分け方が要ります。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種の型と経路 | 技術職・現場職・事務職のどれを採るか。型ごとの経路 |
| 要件を決める技術者の時間 | 「〇〇の製品の〇〇の工程」を経歴の言葉に直す作業に、技術者が最初の一回出られるか |
| 勤務地と転居の条件 | 通える範囲、転居の支援、単身赴任の扱いを、先に出すか |
| 面接と現場の見学の枠 | 技術者と現場の責任者の枠。見学は候補者の判断の材料になる |
| 条件の幅 | 年収の幅と働き方（交替勤務、残業の実態）を先に出せるか |
| 記録の形 | 一覧と記録が社内の環境にあるか。兼務の担当でも更新できる形か |

「勤務地と転居の条件」を先に出すと応募は減りますが、面接での辞退と入社後の離職が減ります。出すかどうかは会社の判断です。

## 職種の型ごとに代行の型が違う

| 職種の型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| 技術職（設計・生産技術・品質・研究開発） | スカウトと紹介会社の母集団形成、一次対応 | 製品と工程の要件、技術の見極めは社内。[電気設計採用を代行に出す判断基準](/media/rpo-denki-sekkei-rpo/) |
| 現場職（製造・保全・検査） | 地域の掲載型と学校・地域の経路の運用、一次対応 | 現場の見学と、働き方の実態の説明は社内 |
| 事務職 | 掲載型の母集団形成、一次対応 | 部門の責任者の見極め |
| 新卒（技術系） | 学校の経路と説明会の運用 | 育てる体制 |

「メーカーの採用に強い代行」でも、技術職と現場職の両方の型を持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種の型ごとの経路 | 「設計の経験者と、製造の現場の方で、経路をどう変えますか」 |
| 製品と工程の要件を整える形 | 「〇〇の製品の〇〇の工程、という要件を、社内の技術者とどう経歴の言葉にしますか」 |
| 地方の拠点への対応 | 「勤務地が〇〇の場合、地域の経路と転居の条件をどう扱いますか」 |
| 担当者の経歴 | 「担当する方は、メーカーのどの職種の型の採用を、どの工程で担った経験がありますか」 |
| 返事の速さと記録の置き場所 | 「候補者への返事は何営業日以内か。記録はどこに置くか」 |
| 費用の構造 | 「月額に含まれる工程と職種の型の数は」 |

費用は、含まれる工程と職種の型の数で変わり、金額の相場を先に聞くより「同じ工程・同じ型で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 設計の応募は来るが、製品と工程が合わない | 要件が「設計経験〇年」のまま | 「〇〇の製品の〇〇の工程」を技術者と経歴の言葉に |
| 現場職が集まらない | 代行の得意な経路（スカウト）だけ回している | 地域の経路の運用を任せる工程に足す |
| 面接で「勤務地が遠い」と辞退 | 勤務地と転居の条件を先に出していない | 求人票と初回の連絡に |
| 入社後に「聞いていた働き方と違う」 | 交替勤務や残業の実態を求人票に書いていない | 実態を書く。現場の見学を段に置く |
| 兼務の担当が返事を返せず、候補者が流れる | 一次対応を社内に残した | 一次対応と日程を外に出す |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「要件の言葉」「職種の型ごとの経路」「勤務地と働き方の実態」「一次対応の分担」に戻ります。

### エラベルの見解

メーカー業界で採用の担当が総務や人事の兼務であることは珍しくなく、その状態で候補者への返事が数日遅れ、日程が一週間先になり、候補者が他社で決まります。代行に出して最も早く効くのは、「一次対応と日程調整」です。兼務の担当は要件の確認と面接の設定だけになり、候補者への返事は翌営業日中に返る。エラベルは担当者を工程ごとに選べる形にしているので、「一次対応と日程だけ」から始め、回ってから母集団形成を足す、という順番が組めます。最初から全部を任せるより、兼務の担当の負担が最も大きい工程から外に出すほうが、効果が早く見えます。工程の切り分けは[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)に書いています。

## まとめ

- メーカー業界の難しさは、**職種の型で違う経路と要件・勤務地・製品と工程の知識・兼務の担当**の四つ
- **母集団形成・一次対応・日程・記録は任せられ、製品と工程の要件・技術の見極め・勤務地と条件は残す**
- **職種の型（技術職・現場職・事務職）ごとに代行の型が違う**。「全部まとめて」では回らない
- 要件は**「〇〇の製品の〇〇の工程で、〇〇を担った経験」**に。技術者の最初の一回
- **勤務地と転居の条件、働き方の実態を先に出す**かは会社の判断。出すと応募は減り、辞退と離職が減る
- 兼務の担当がいる会社は、**一次対応と日程から**外に出すと効果が早い
- 代行を選ぶときは**職種の型ごとの経路と、担当者の経歴を型と工程で**確かめる

## よくある質問

### 技術者が「要件は自分で見れば分かる。言葉にする時間は無い」と言います

技術者が見れば分かる要件を、代行と紹介会社は見られません。最初の一回、いまうまくやっている人に「入った頃にすぐできたことと、時間がかかったこと」を三十分聞き、「〇〇の製品の〇〇の工程で、〇〇を担った経験」の形にすれば、その後は月次の確認で足ります。要件が言葉になっていれば、書類の一次確認を外に出せ、技術者の時間は面接だけになります。要件の作り方は[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

### 工場が地方にあり、そもそも候補者がいません

勤務地で絞られる母集団を、地域の経路（地元の掲載型、学校、ハローワーク、地域の紹介会社）と、転居できる人への経路（スカウト、転居の支援の明示）に分けます。地域の経路の運用は代行に出せ、転居の支援を出すかは会社の判断です。「候補者がいない」の前に、地域の経路を全部使っているか、転居の条件を先に出しているかを確かめます。地方の考え方は[地方企業の採用代行](/media/rpo-chihou-kigyo-rpo/)に書いています。

### 現場の見学を選考に入れたいのですが、代行に任せられますか

見学の日程調整と案内は任せられます。見学で何を見せ、誰が説明し、候補者の質問に誰が答えるかは、現場の責任者が決めます。見学は、候補者が「働き方の実態」を判断する材料で、見学の後の辞退は「実態を知って判断した」結果なので、入社後の離職より良い。見学を選考のどの段に置くかは、面接の設計の中で決めます。設計の考え方は[一次面接の進め方](/media/rpo-task-ichiji-mensetsu-susumekata/)に書いています。
