病院やクリニック、介護施設の人事として、看護師や介護職や療法士などの資格職を、常に足りない中で採り続け、紹介会社と付き合い、配置の基準とシフトに合わせて人を入れ、辞める人の穴を埋めてきた。この経験は、業界の外を含めた人事の副業で売れるのか。医療・介護の採用は業界の事情が強く、外では通じないと感じる人が多いところです。結論を先に書くと、**医療・介護の人事の経験は、「資格職を、常に足りない状態で、配置基準とシフトと紹介会社の中で採り続けてきた」型で売れます。売れるのは、「常に募集し続ける体制の設計」「紹介会社と自力の採用の使い分け」「資格と配置の制約の中での要件づくり」「定着のための受け入れの設計」の四つです。業界の外でも、常に人が足りない職種（ドライバー、施工、保育、店舗、コールセンター）を持つ会社は、同じ構造で困っています。「病院・施設の人事でした」ではなく、「足りない職種を、止まらずに採り続ける体制を作る」と売ります。**教育機関の人事の経験は[教育機関の人事が副業でできること](/media/fukugyo-kyouiku-jinji-fukugyo/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に、採用担当の経験は[採用担当が副業でできること](/media/fukugyo-saiyo-tantou-fukugyo/)にまとめています。

## この経歴の何が売れるか

医療・介護の人事の経験を、業界の内外の採用の工程に置き換えた棚卸しです。在籍した施設の内情は含めず、「型」として抜き出します。

| 医療・介護の人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 常に募集を出し続け、辞める人の穴を埋め続けてきた | 「欠員が出たら募集」ではなく、「常に募集し、常に面接し、常に入る」体制の設計 | 欠員が出てから慌てて募集し、繁忙期に人が足りない依頼側が多い |
| 紹介会社と付き合い、手数料と自力の採用を比べてきた | 紹介会社に頼る職種と、自力で採る職種の切り分け。紹介会社の提案の見方と、条件の交渉の型 | 紹介会社の手数料が膨らみ、自力の採用ができていない依頼側が多い |
| 配置の基準とシフトの制約の中で要件を決めてきた | 「この資格・この経験・この勤務ができる人」という制約の多い要件を、応募が来る形に整える | 制約が多くて求人票が条件の羅列になり、応募が来ない依頼側が多い |
| 入職の直後に辞める人を減らす受け入れを工夫してきた | 最初の一か月の受け入れ（同行、相談の相手、シフトの配慮）を設計する | 入ってすぐ辞める依頼側が多い |
| 現場の管理者（師長、施設長、主任）と採用を進めてきた | 現場の管理者が採用と受け入れに関わる分担の設計 | 現場が採用に関わらず、人事だけで回している依頼側が多い |
| 資格の確認、免許の手続き、届出を扱ってきた | 有資格者の採用で、資格の確認と手続きを採用の流れに組み込む | 資格の確認が抜けて、後で問題になる依頼側が多い |
| 求職者が施設を比べる目線（給与、夜勤、人間関係、通勤）を知ってきた | 応募者が「他と比べて何を見るか」を、求人票と面接に反映する | 自施設の何が選ばれる理由かを言葉にできない依頼側が多い |

売れるものの要点は、「常に足りない状態を、止まらずに回す体制を作れる」ことです。多くの会社の採用は、欠員が出たら募集して、決まったら止める形で動いており、常に足りない職種にはこの形が合いません。医療・介護の人事は、「募集を止めない」「面接を止めない」「入る人を止めない」体制を、紹介会社と自力の両方を使って回してきています。この型は、業界の外でも、常に人が足りない職種を持つ会社にそのまま合います。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

医療・介護の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 業界の外で通じるか | 「医療の採用は特殊で、うちには合わない」。自分にとっても、業界の外の職種を知らない不安 | 「常に足りない職種を採り続ける体制」の型として語る。業界の言葉（配置基準、夜勤、師長）を、外の言葉（必要な人数、シフト、現場の管理者）に置き換える |
| 紹介会社への依存 | 「紹介会社に頼る採用しかしてこなかったのでは」。自力の採用（媒体、スカウト、求人票）の経験が薄いことがある | 紹介会社を使ってきた経験を、「紹介会社の提案の見方と条件の交渉」として売る。自力の採用の工程は、経験が薄ければ範囲に入れないか、別の担当者と組む |
| 現場の言葉の強さ | 「現場の管理者に押し切られて、人事の判断が通らなかったのでは」 | 現場の管理者と一緒に進める分担の型として売る。「押し切られる」ではなく「現場を採用に巻き込む」と言い換える |

扱い方の要点は、「業界の言葉を、構造の言葉に置き換える」ことです。医療・介護の人事の経験がある人は、配置基準や夜勤や師長といった業界の言葉で経験を語り、それが業界の外の依頼側には「うちとは違う」と聞こえます。「必要な人数が法令で決まっている中で、常に足りない職種を採り続けてきた」「シフトで現場が回るかを見ながら要件を決めてきた」「現場の管理者と一緒に採用を進めてきた」と、構造の言葉に置き換えれば、同じ経験が業界の外の依頼側にも「うちと同じ」と伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、医療・介護の人事から転身して続いている人と、面談で止まる人の差は、業界の言葉で語るか、「足りない職種」の構造で語るかです。止まる人は、看護師や介護職の採用の話を業界の言葉で語り、業界の外の依頼側は「うちは医療ではない」と感じて終わります。続いている人は、「御社で、常に足りない職種はどれですか」と聞き、依頼側が「ドライバー」「店舗のスタッフ」と答えたところで、「それは、私が採り続けてきた職種と同じ構造です」と言い、募集を止めない体制の型を見せます。依頼側は、自分の会社の詰まりが「欠員が出てから動く形」にあることに気づき、そこから頼みます。

見ていて差がつくのは、紹介会社の使い方を「依存」ではなく「使い分け」として設計しているかです。医療・介護の人事の経験がある人は、紹介会社の手数料の重さと、それでも頼らざるを得ない構造を知っています。「急ぎで埋める職種は紹介会社、時間をかけて自力で採る職種は媒体と受け入れの改善」と切り分け、紹介会社の提案の見方と条件の交渉の型を持ち込んだ人は、依頼側の紹介の手数料が下がり、「初めて紹介会社と対等に話せた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「足りない職種を、止まらずに採り続ける体制を作る」と構造の言葉で書いている担当者に、常に人が足りない依頼側がついています。医療・介護の人事の転身は、業界の知識ではなく、構造の言葉への置き換えから始まります。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 医療・介護・福祉の依頼側の採用 | 業界の言葉と資格の意味が分かり、説明の手間がない | 同じ業界の依頼側を探す |
| 常に足りない職種の募集を止めない体制の設計 | 常時募集の経験でそのまま入れる | 「欠員が出てから慌てる依頼側」を探す |
| 紹介会社の提案の見方と条件の交渉 | 紹介会社と付き合ってきた経験で入れる | 「紹介の手数料が膨らんでいる依頼側」を探す |
| 制約の多い要件を応募が来る形に整える | 配置とシフトの制約の中で要件を決めてきた経験で入れる | 「求人票が条件の羅列になっている依頼側」を探す |
| 入職の直後の受け入れの設計 | 早期の離職を減らしてきた経験で入れる | 「入ってすぐ辞める依頼側」を探す |
| 現場の管理者を採用に巻き込む分担 | 師長や施設長と進めてきた経験で入れる | 「現場が採用に関わらない依頼側」を探す |

探し方の要点は、「業界の内側から入り、構造の言葉で外に広げる」ことです。最初は医療・介護・福祉の依頼側が、業界の言葉が通じるので入りやすいです。ただ、業界の中の依頼側は紹介会社との付き合いが長く、副業の担当者に払う予算が限られることもあります。「常に足りない職種」を持つ業界の外の依頼側（物流、建設、保育、飲食、店舗、コールセンター）に、構造の言葉で広げる準備を並行します。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。医療・介護の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 紹介の手数料との比較 | 紹介会社の手数料を減らせる設計は、依頼側の支出に直接効き、価値が見えやすい | 「紹介の手数料が減った分」を成果として示せる形に |
| 体制の設計の成果物 | 募集を止めない体制の設計は、成果物として形が明確 | 一式の成果物で受ける |
| 運用の継続 | 常に募集する体制は、作った後も回し続ける運用が要り、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 業界の内側の予算 | 医療・介護の依頼側は予算が限られることがあり、単価が下がりやすい | 業界の外の依頼側を並行して持つ |
| 自力の採用の工程を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 受け入れの設計 | 早期の離職を減らす価値は、やり直しの損失として依頼側に分かりやすい | 「辞めなかった」を成果として残せる形に |
| 成果報酬の扱い | 採用の成否は依頼側の条件と現場の動きに左右され、責任の線が引きにくい。紹介の形で報酬を受けることは許可の線に関わる | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「体制の設計は成果物で、運用は月額で受け、紹介の手数料との比較で価値を示す」ことです。医療・介護の人事の経験で受ける工程は、紹介会社の手数料という分かりやすい比較の対象があり、「自力で採れる体制を作ると、この分の手数料が要らなくなる」と価値を示せます。ただ、紹介の形で報酬を受けることは、職業紹介の許可の線に関わるので、副業の担当者は紹介ではなく、体制の設計と運用で受けます。可否は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に、数字に出ない成果の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に整理しています。

## 始める順番

医療・介護の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、所属する法人の副業の規定と、職員と患者・利用者の情報の守秘の条件を確認する | 医療・介護は個人情報の扱いが重い。個別の判断は専門家に |
| 二、「常に足りない職種をどう採り続けてきたか」を、施設の情報を含まない型として書き出す | 募集を止めない体制、紹介会社の使い分け、受け入れの工夫 |
| 三、業界の言葉を、構造の言葉に置き換える | 「配置基準」→「必要な人数が決まっている」、「夜勤」→「シフトの制約」、「師長・施設長」→「現場の管理者」 |
| 四、得意な工程（体制・紹介会社の使い分け・要件・受け入れ・現場の巻き込み）と、薄い工程（媒体・スカウト・読ませる文面）を分ける | 正直に示す準備 |
| 五、範囲を、体制の設計、紹介会社の提案の見方、制約の中の要件、受け入れ、現場の分担に絞る | 自力の採用の実務は経験に応じて |
| 六、「足りない職種を、止まらずに採り続ける体制を作る」の一言を作る | 「病院・施設の人事でした」で終わらせない |
| 七、紹介の形で報酬を受けないと決め、体制と運用で受ける線を書く | 許可の線。個別の判断は専門家に |
| 八、登録先に、範囲と、業界の内側の経験と、構造の言葉の一言を登録する | 常に人が足りない依頼側 |
| 九、体制の設計か受け入れの設計を一件受け、「募集が止まらなかった月」を残す | 業界の外に広げる材料に |

順番の要点は、「三」の置き換えと「七」の線です。業界の言葉を構造の言葉に置き換えないと、業界の外の依頼側に届きません。紹介会社と近い経験があるので、「候補者を紹介してくれれば手数料を」と誘われることがありますが、紹介の形で報酬を受けることは許可の線に関わるので、体制と運用で受けると決めておきます。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「医療・介護の採用は特殊で、業界の外では通じない」というものです。実際には、常に人が足りない職種を持つ会社は業界の外に多く、それらの会社は「欠員が出てから動く」形のまま繁忙期に人が足りなくなっています。募集を止めない体制、紹介会社との使い分け、制約の中の要件、入職の直後の受け入れ。医療・介護の人事が日常として回してきたこの型は、業界の外のその会社にとって、持っていない打ち手です。特殊なのは経験ではなく、語る言葉です。

順番として、法人の規定と守秘の条件を専門家に確認し、採り続けてきた型を施設の情報を含まずに書き出し、業界の言葉を構造の言葉に置き換え、得意な工程と薄い工程を分け、範囲を体制と使い分けと要件と受け入れに絞り、止まらずに採り続ける体制を作る一言を作り、紹介で受けない線を決め、登録先に範囲と一言を登録し、一件受けて募集が止まらなかった月を残す。この順番で、医療・介護の人事の経験は「特殊で通じないもの」から「足りない職種を採り続ける体制を作る形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、体制の工程を明確にし、紹介で受けない線を示している担当者に、常に人が足りない依頼側がついています。医療・介護の人事の転身は、業界の外に出ることではなく、構造の言葉で語るところから始まります。

## まとめ

- 医療・介護の人事の経験は**「資格職を、常に足りない状態で、配置基準とシフトと紹介会社の中で採り続けてきた」型**で売れる。**募集を止めない体制・紹介会社と自力の使い分け・制約の中の要件・受け入れの設計**の四つ
- **「病院・施設の人事でした」ではなく「足りない職種を、止まらずに採り続ける体制を作る」**と売る
- 売りにくい点は**業界の外で通じるか・紹介会社への依存・現場の言葉の強さ**。業界の言葉を構造の言葉に置き換え、紹介会社の経験は「使い分けと交渉」として売り、現場は「巻き込み」と言い換える
- 案件は**業界の内側から入り、常に足りない職種を持つ外側に広げる**。物流・建設・保育・飲食・店舗も同じ構造
- 単価は**体制の設計は成果物、運用は月額**で。紹介の手数料との比較で価値を示す。紹介の形で報酬を受けない。成果報酬は最初は避け、可否は専門家に確認
- 職員と患者・利用者の情報は**持ち込まない**。個別の判断は専門家に

## よくある質問

### 業界の外の依頼側に、医療・介護の経験をどう説明すればよいですか

業界の言葉を使わず、構造の言葉で説明します。「必要な人数が決まっている中で、常に足りない職種を、募集を止めずに採り続けてきました。紹介会社と自力の採用を使い分け、入った直後に辞めない受け入れを作ってきました」と言えば、常に人が足りない職種を持つ依頼側には「うちと同じ」と伝わります。そのうえで、「御社で常に足りない職種はどれですか」と聞き、その職種で型を当てはめて見せます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、面談で聞かれることは[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に整理しています。

### 前の施設で付き合いのあった紹介会社を、依頼側に紹介してよいですか

前の施設との契約の中で知った紹介会社の条件や手数料の情報は、前の施設のものであり、守秘の条件に関わります。紹介するなら、公開されている情報と、依頼側が自分で問い合わせる形にし、前の施設の契約の条件は持ち込みません。紹介会社から紹介の見返りを受ける形は、依頼側との利益相反と、職業紹介の許可の線に関わるので避けます。個別の判断は、弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### 媒体やスカウトの経験がほとんどありません。案件が取れないのではないですか

自力の採用の実務が薄いことは隠さず、「媒体とスカウトは御社の担当者か別の担当者が、私は募集を止めない体制と、紹介会社の使い分けと、要件と受け入れを担います」と分担を示します。媒体とスカウトが得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。常に人が足りない依頼側には、媒体の技術より「止まらない体制」が求められており、そこでは実務の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、現場の管理者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
