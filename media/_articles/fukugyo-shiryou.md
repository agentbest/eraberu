本業で資料を作り慣れている人ほど、副業でも丁寧な資料を作ろうとします。スライドで十数枚、経緯から結論まで、図も入れて。ただ、副業の枠は週に数時間で、依頼側の担当や判断する人が資料を読む時間はもっと短い。作る時間が稼働を食い、読まれない資料が残ります。結論を先に書くと、**副業で作る資料は「報告」「提案」「型」の三種類で、どれも一枚・表・箇条書きで作り、依頼側が数分で読んで動ける形にする**と、作る時間が短く、読まれ、使われます。スライドは要りません。報告の三層は[報告のしかた](/media/fukugyo-houkoku/)に、提案の一枚は[提案のまとめ方](/media/fukugyo-teian/)に、定例会での使い方は[定例会の進め方](/media/fukugyo-teirei-shinkou/)にまとめています。

## 三種類の資料

副業で作る資料を三つに分け、それぞれの目的と形を示します。

| 種類 | 目的 | 読む人 | 形 | 作る時間の目安 |
|---|---|---|---|---|
| 報告 | 動いていることと、数を伝える。相手が次に動ける | 担当（週ごとは判断する人も） | 稼働ごとは数行、週ごとは一枚の表 | 稼働ごと十五分、週ごと三十分 |
| 提案 | 依頼側が「やる・やらない」を決める | 判断する人 | 一枚。六つの項目 | 一〜二時間（一か月に一回） |
| 型 | 直した仕組みを、依頼側が自分で回せるようにする | 担当（次の担当も） | 手順の箇条書きと、文面の雛形 | 二〜三時間（区切りに一回） |

三種類の要点は、「どれも一枚か、箇条書き」ということです。三種類とも、読む人が短時間で読んで、次に動くための資料です。飾りや経緯は、読む時間を増やすだけです。

## 共通の作り方

三種類に共通する、作り方の手順を番号付きで整理します。

1. **読む人と、読んだあとに何をしてほしいかを一行で決める。** 「担当が翌朝に送信する」「経営者が来週から始めてよいと決める」「次の担当がこの手順で回す」。
2. **数から埋める。** 報告なら今週の数、提案なら現状の数と見る数、型なら手順の数（何通、何日以内）。
3. **表か箇条書きにする。** 文章で書かない。項目と値、手順と内容。
4. **相手が動くことを、目立つ位置に置く。** 報告なら「翌朝に動くもの」、提案なら「決めてほしいこと」、型なら「毎週やること」。
5. **経緯・考え・背景を削る。** 聞かれたら答える。資料には結果と手順だけ。
6. **応募者の名前・依頼側の内情・本業の情報を含めない。** 数と種類、一般化した手順。
7. **一枚に収まるかを見る。** 収まらなければ、数の表を削るか、項目を減らす。型は複数枚になってもよいが、一手順一行。
8. **同じ型で作り続ける。** 毎回、項目と順番を変えない。読む人が慣れる。
9. **作る時間の上限を決める。** 上限を超えたら、削って出す。作り込まない。
10. **送る時間を固定する。** 報告は稼働の終わり、提案は区切りの前、型は区切りに。

作り方の要点は、「一で、読んだあとに何をしてほしいかを決める」ことです。これが決まると、載せるものと削るものが決まります。決めずに作ると、全部を載せたくなります。

### エラベルの見解

登録の相談で多いのは、「提案のスライドを十枚作ったが、経営者に渡っていない」という話です。担当が読んで、要約して経営者に伝えようとして、伝えきれずに止まっている。本業の会議用の資料の作り方を、副業に持ち込んだ形です。本業では、資料を作る時間も、読む会議の時間も確保されています。副業では、どちらも無い。

見ていて差がつくのは、「資料を、読む人の時間に合わせて作っているか」です。担当が翌朝の五分で読む報告、経営者が数分で決める提案、次の担当が迷わず回せる型。それぞれの読む人の時間を先に想像して、その時間で読める形にする。エラベルの登録でも、資料が短く、表と箇条書きで、毎回同じ型の人は、依頼側から「分かりやすい」と評価され、資料を作る時間が稼働を食っていません。資料の質は、丁寧さではなく、読む人が動けるかで決まります。

## 型の資料の書き方

三種類のうち、型の資料だけは、副業を終えたあとも依頼側に残るものです。書き方を詳しく示します。

| 項目 | 書くこと | 例 |
|---|---|---|
| 目的 | この仕組みで何を保つか。一行 | 「応募から一次返信までを一日以内に保つ」 |
| 誰が | 各手順の担当。役割名で（担当、判断する人）。個人名は書かない | 「担当が日中の定型返信、副業の人が夜の本返信」 |
| いつ | 頻度と期限。曜日、時間帯、日数 | 「応募当日の日中に定型返信、翌々日までに本返信」 |
| 何を | 手順を、一手順一行で | 「一 応募の通知を確認する。二 定型文面Aを送る。三 管理の表に日付を入れる」 |
| どの文面で | 文面の雛形。差し込む箇所を〇〇で | 「〇〇様、ご応募ありがとうございます。〇日以内に…」 |
| 見る数 | この仕組みが回っているかを何で見るか | 「応募から返信までの日数を、週に一度、表で確認」 |
| 崩れたとき | 数が悪くなったら、どこを見るか | 「日数が伸びたら、定型返信の分担が動いているかを先に見る」 |

型の要点は、「自分がいなくても回る」ように書くことです。自分の名前や、自分にしか分からない判断が入っていると、自分がいないと止まります。役割名で書き、判断の基準を書き、崩れたときの見方を書く。この型があると、依頼側は「仕組みを残してくれた」と受け取り、次の依頼につながります。型の書き方の考え方は[noteで実績を見せる](/media/fukugyo-note/)と同じで、社名や候補者の情報は含めません。

## 情報を含めない線

資料に含めてはいけないものを整理します。資料は依頼側の中で回り、型は次の担当にも渡るので、線を守ります。

| 含めない | 代わりに書くこと |
|---|---|
| 応募者の名前、連絡先、経歴の詳細 | 数と種類。「未返信八件」「経験三年以上の応募三件」 |
| 依頼側の予算、社内の人間関係、経営の事情 | 業務に必要な範囲の分担と判断の流れだけ |
| 本業の会社の手順、文面、数値 | 一般化した型。自分の言葉で |
| 別の依頼側の情報 | 含めない。案件ごとに資料を分ける |
| 個人名（担当、判断する人） | 役割名。「担当」「判断する人」 |
| 自分の感想、評価、愚痴 | 数と構造。「日数が伸びた週は分担が動いていない」 |

線の要点は、「型の資料は、次の担当にも渡る」ことを前提に書くことです。個人名や内情が入っていると、担当が変わったときに渡せません。役割名と手順だけなら、誰にでも渡せます。[情報の取り扱いと端末の分離](/media/fukugyo-security/)を参照してください。

## 資料作りが稼働を食う失敗

資料で起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| スライドで作る | 本業の習慣 | 一枚の表と箇条書きに |
| 経緯から書く | 順序どおりに説明したい | 結果と、相手が動くことから |
| 全部を載せる | 把握した全部を見せたい | 読んだあとにしてほしいことに関わる部分だけ |
| 図を作る | 分かりやすくしたい | 表で足りる。図は作る時間が長い |
| 毎回形を変える | 良くしようとする | 同じ型で。読む人が慣れる |
| 作る時間の上限が無い | 作り込む | 上限を決め、超えたら削って出す |
| 応募者の名前を入れる | 具体的に書きたい | 数と種類 |
| 型に自分の名前と判断を入れる | 自分がやっている前提 | 役割名と基準。自分がいなくても回る形 |
| 資料を送るだけで、動くことを書かない | 読めば分かると思う | 「翌朝に送信をお願いします」を目立つ位置に |
| 資料を作ることが仕事になる | 作ると仕事をした気になる | 資料は手段。作る時間は稼働の一割以下に |

失敗の要点は、「資料を作ることが、仕事になってしまう」点です。資料は、相手が動くための手段で、作ることに時間を使うほど、稼働が減ります。

### エラベルの見解

担当する側として登録した人の話を聞くと、依頼側から「仕組みを残してくれた」と言われる人は、型の資料が簡素です。役割名と手順と文面の雛形と見る数。飾りが無く、次の担当がそのまま使える。逆に、丁寧なスライドで型を作った人は、次の担当が「読むのに時間がかかる」と使わず、仕組みが残っていません。残る資料は、丁寧な資料ではなく、使える資料です。

依頼側から見ると、副業の人が作る資料は、その人がいなくなったあとにも残るものです。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口ですが、依頼側から次の案件の相談を受ける人は、前の案件で型の資料を残しています。「あの人が残した手順で回っている」という状態が、次の依頼を生みます。資料は、報告・提案・型の三種類を、一枚・表・箇条書きで。この型を一つ持っていただくことをお勧めしています。

## まとめ

- 資料は**報告・提案・型**の三種類。どれも**一枚・表・箇条書き**で、読む人が数分で読んで動ける形に
- 作り方は**読んだあとにしてほしいことを一行で→数から→表か箇条書き→動くことを目立つ位置→経緯を削る→情報を含めない→一枚→同じ型→時間の上限→送る時間を固定**
- 型の資料は**目的・誰が（役割名）・いつ・何を（一手順一行）・どの文面で・見る数・崩れたとき**。自分がいなくても回る形
- 含めないのは**応募者の情報・依頼側の内情・本業の情報・別の依頼側・個人名・感想**
- 失敗は**スライド・経緯から・全部載せる・図・毎回形を変える・上限が無い・資料が仕事になる**
- 残る資料は**丁寧な資料ではなく、使える資料**

## よくある質問

### 依頼側から、スライドで資料を作ってほしいと言われました

何のための資料かを聞きます。社内の会議で経営者に説明するためなら、提案の一枚を渡して「これを会議で使ってください。スライドが要るなら、この一枚を貼るだけで足ります」と伝えます。それでもスライドが要ると言われたら、範囲と時間の話に戻ります。スライドを作る時間は、稼働の枠から出るので、その時間分、本命の作業が減ることを伝え、それでも依頼側が望むなら、作る時間を稼働に含めて対応します。資料の形式は、依頼側の要望より、読む人が動けるかで決めるのが基本です。

### 型の資料を作る時間が、区切りの前に取れません

型は、三か月目の九週目と十週目に、少しずつ作ります。区切りの直前にまとめて作ろうとすると、時間が足りません。二か月目に仕組みを回しながら、手順と文面を書き留めておけば、三か月目はそれを整えるだけで済みます。稼働ごとの記録（やったことの種類と数）が、型の手順の下書きになります。記録を残しておくことが、型を作る時間を短くします。[稼働開始から九十日の設計](/media/fukugyo-shoki-90nichi/)を参照してください。

### 資料を作っても、依頼側が使ってくれません

使われない資料は、長いか、相手が動くことが書かれていないか、相手の言葉になっていないかのどれかです。担当に「この資料のどこが使いにくいですか」と聞き、担当の言葉で直す。型の資料なら、担当と一緒に一度回してみて、迷った箇所を直す。作って渡すだけでは使われず、一緒に使ってみて直すと使われます。三種類とも、一度目は下書きとして渡し、相手の反応で直して確定する、という二段で作ると、使われる資料になります。
