「採用のことは全部お任せしたい」。人事がいない会社の経営者から、こう言われることがあります。信頼されているようで、任される範囲も広く、一見すると良い案件に見えます。ただ、「全部任せる」は、多くの場合「判断する人がいない」と同じ意味です。そのまま受けると、合否も条件も優先順位も自分が決めることになり、副業の枠を越えます。結論を先に書くと、**丸投げ案件は、断るか受けるかの二択ではなく、「実行は自分、判断は依頼側」の形に組み替えられるかを面談で確かめ、組み替えられれば受け、組み替えられなければ受けない**のが扱い方です。組み替えの鍵は、依頼側の中に判断する人を一人立ててもらうことです。判断する人が不在の信号は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、範囲の広がりへの対応は[スコープクリープへの対応](/media/fukugyo-scope-creep/)にまとめています。

## 丸投げが生まれる背景

依頼側が「全部任せたい」と言うとき、背景はいくつかに分かれます。背景によって、組み替えられるかどうかが変わります。

| 背景 | 依頼側の状態 | 組み替えられるか |
|---|---|---|
| 人事がおらず、経営者が採用に時間を割けない | 判断する時間が無い。判断したくないわけではない | 組み替えられる。判断の時間を週に少しだけ確保してもらう |
| 採用のやり方が分からない | 何を判断すればよいか分からない | 組み替えられる。判断の項目を自分が示せば、依頼側は判断できる |
| 前の担当が辞めて、引き継ぎが無い | 現状が分からない | 組み替えられる。現状把握を先に |
| 採用に関心が無い | 判断する意思が無い。結果だけ欲しい | 組み替えにくい。判断する人が立たない |
| 副業の人を人事の代わりだと思っている | 雇用の代替として見ている | 組み替えにくい。範囲と時間の前提が違う |
| 以前に外注して失敗した | 外注に任せれば済むと思っている、または不信 | 組み替えられることもある。前回の失敗の原因を聞く |

背景の要点は、「判断する時間が無いのか、判断する意思が無いのか」の違いです。時間が無いだけなら、判断の項目を絞って、週に短い時間で判断してもらう形に組み替えられます。意思が無いなら、判断する人が立たず、組み替えられません。

## 丸投げのまま受けると起きること

組み替えずに受けた場合、どう崩れるかを整理します。

| 時期 | 起きること |
|---|---|
| 最初の週 | 権限は渡されるが、要件も判断の基準も無い。自分で決めて始める |
| 一か月目 | 応募が来て、合否を自分が判断し始める。判断の根拠が自分の中にしか無い |
| 二か月目 | 範囲が広がる。面接の設定、条件の提示、内定の連絡。依頼側は「任せている」ので関わらない |
| 三か月目 | 稼働が倍になる。単価は当初のまま。採用が決まらないと「任せたのに」となる |
| その後 | 判断の責任を負わされる形になり、続けられなくなる。型も残らない |

崩れ方の要点は、「判断の責任が、書面に無いまま自分に移る」ことです。書面の範囲は「採用支援」でも、実態は人事の代わりで、判断の結果（採用できない、合わない人を採った）が自分に向きます。

### エラベルの見解

登録の相談で多いのは、「全部任せると言われて始めたら、経営者が採用にまったく関わらず、合否も条件も自分が決めることになった」という話です。依頼側に悪気は無く、信頼して任せたつもりです。ただ、副業の人が合否や条件を決める形は、範囲としても、責任としても、副業の枠を越えています。「任せる」が「判断も含めて任せる」になっていることに、依頼側も受ける側も気づいていません。

見ていて差がつくのは、「面談で、判断する人を立ててもらっているか」です。「全部お任せいただくのは嬉しいのですが、合否と条件の判断だけは、御社のどなたかに持っていただく必要があります。週に三十分、判断の時間をいただけますか」と、最初に言う。依頼側が「それなら」と応じれば、丸投げは「実行は自分、判断は依頼側」の形に変わります。エラベルの登録でも、丸投げの依頼を組み替えて受けた人は続いていて、組み替えずに受けた人は途中で終えています。

## 組み替える手順

丸投げの依頼を、「実行は自分、判断は依頼側」の形に組み替える手順を、番号付きで整理します。面談から初回打ち合わせまでの流れです。

1. **「全部」の中身を分解する。** 面談で、採用の流れ（募集→応募→選考→面接→内定→承諾）を並べ、各段階で何が起きるかを一緒に見る。依頼側は「全部」を分解して考えていないことが多い。
2. **実行と判断を分ける。** 各段階で、「作業」と「決めること」を分ける。文面を書く（作業）、誰に送るか（判断の基準）、書類を絞る（作業）、通過させるか（判断）。
3. **判断する人を立ててもらう。** 「決めることは、御社のどなたが持ちますか」。経営者本人か、兼務の誰か。立たなければ、組み替えられない。
4. **判断の時間を決めてもらう。** 「週に三十分、判断の時間をください」。曜日と時間帯で。
5. **判断の項目を、自分が用意すると伝える。** 「判断していただく項目は、私が選択肢の形で用意します。AかBか、で決めていただければ」。判断の負担を最小にする。
6. **最初の三か月の範囲を、一つの業務に絞る。** 「全部」ではなく、「まずスカウトの運用から」。[専門特化と何でも屋のどちらがよいか](/media/fukugyo-senmon-tokka/)
7. **書面に、判断の線を書く。** 「合否・条件・優先順位の判断は依頼側。副業の人は実行と、判断のための材料の用意」。
8. **初回打ち合わせで、判断の流れを確認する。** 誰に、どのツールで、どのくらいで返事が来るか。[初回打ち合わせの進め方](/media/fukugyo-shodan/)
9. **最初の一か月で、判断の項目を選択肢の形で出し続ける。** 依頼側が判断に慣れる。
10. **区切りで、判断の分担が回ったかを確認する。** 回っていれば範囲を広げる相談ができ、回っていなければ範囲を狭くする。

手順の要点は、「五で、判断の負担を最小にする」ことです。依頼側が判断を手放したいのは、判断が面倒だからです。選択肢の形で「AかBか」まで用意すれば、判断は数分で済み、依頼側は判断する人として機能します。

## 組み替えられないときの判断

手順を踏んでも組み替えられない場合があります。そのときの判断を整理します。

| 状態 | 判断 |
|---|---|
| 判断する人が立たない（「そこも任せたい」） | 受けない。「判断を含む形はお受けしていません」と範囲の違いで断る |
| 判断する人は立ったが、時間が取れない | 範囲を、判断を仰がずに完結する業務（文面の型作り、記録の整理）に狭めて受けるか、断る |
| 判断はするが、返事が遅い | 返事の目安を書面に。目安が守れなければ区切りで見直す |
| 判断の項目を用意しても「お任せします」と返ってくる | 一か月続けて変わらなければ、区切りで終える。判断の責任を負わない |
| 「任せたのに採用できない」と言われる | 判断の分担を書面で示す。結果の責任は判断する側にあることを、記録で示す |

判断の要点は、「判断の責任を、書面と記録で自分の外に置く」ことです。判断の項目を選択肢の形で出し、依頼側が決めた記録を残す。それが無いと、結果の責任が自分に向きます。

## 丸投げに見えて違う案件

「全部任せる」と言われても、実は丸投げではない案件もあります。区別を整理します。

| 言葉 | 実態 | 扱い |
|---|---|---|
| 「全部任せる」＝「作業は全部任せる。判断はする」 | 判断する人がいて、時間もある。作業の手が足りないだけ | 丸投げではない。範囲を一つずつ広げる前提で受けられる |
| 「全部任せる」＝「やり方を決めてほしい。決めた通りに動く」 | 判断はするが、何を判断すればよいか分からない | 組み替えられる。判断の項目を用意すれば回る |
| 「全部任せる」＝「結果だけ欲しい。関わりたくない」 | 判断する意思が無い | 丸投げ。組み替えられなければ受けない |
| 「全部任せる」＝「人事を雇う代わりに」 | 雇用の代替 | 範囲と時間の前提が違う。副業の枠では受けない |

区別の要点は、「判断する意思があるか」で分けることです。意思があって時間や知識が無いだけなら、組み替えられます。意思が無いなら、丸投げです。面談で「合否はどなたが決めますか」と聞いたときの答え方で、意思の有無はほぼ分かります。

### エラベルの見解

担当する側として登録した人の話を聞くと、丸投げの依頼を受けて続いている人は、依頼側を「判断する人」に育てています。最初の一か月、判断の項目を選択肢の形で毎週出し、依頼側が「AかBか」を決める。二か月目には、依頼側が自分で判断の基準を持ち始め、三か月目には、副業の人が用意しなくても判断できるようになる。「全部任せたい」と言っていた経営者が、採用の判断をする人になっています。

依頼側から見ると、丸投げは、採用をどう進めればよいか分からない状態の表れであることが多い。エラベルは、企業と担当者の間に立つ窓口として、案件を出す前に依頼側の判断する人を確認していますが、「全部任せたい」という依頼側には、判断の分担を最初にお伝えしています。担当者ご自身にも、面談で判断する人を立ててもらう型を持っていただくと、丸投げの依頼が、続く案件に変わります。

## まとめ

- 「全部任せる」は多くの場合**判断する人がいない**と同じ。そのまま受けると判断の責任が自分に移る
- 背景は**時間が無い・やり方が分からない・引き継ぎが無い・関心が無い・人事の代わり・外注の失敗**。**判断する意思があるか**で組み替えられるかが決まる
- 組み替えは**「全部」を分解→実行と判断を分ける→判断する人を立てる→判断の時間→判断の項目を自分が用意→一つの業務に絞る→書面に判断の線→初回打ち合わせ→選択肢の形で出し続ける→区切りで確認**
- **判断の負担を最小にする**（AかBか）と、依頼側は判断する人として機能する
- 組み替えられなければ**受けない**。判断の責任は**書面と記録で自分の外に**
- 丸投げに見えて違う案件は**判断する意思の有無**で区別

## よくある質問

### 経営者が「自分は採用のことは分からないから、あなたが決めて」と言います

「分からない」は、判断の意思が無いのではなく、判断の項目が分からない状態です。「決めていただくのは、AかBかの選択だけです。材料は私が用意します」と伝え、最初の判断を一つ、選択肢の形で出してみます。「この二人のうち、面接に進めるのはどちらですか。基準はこうです」。経営者が決められれば、組み替えられます。「どちらでもいい」「そこも任せる」と返ってくるなら、判断する意思が無いので、範囲を狭くするか、受けません。

### 判断する人を立ててもらったのですが、その人が忙しくて判断が返ってきません

判断の項目を減らし、期限を付けます。週に一つか二つ、選択肢の形で、「〇日までに」と書いて送る。それでも返らなければ、判断が返らないと止まることを数で示し（判断待ちで止まった応募者の数と日数）、区切りで「判断の時間が取れないなら、範囲を判断を仰がない業務に狭めます」と提案します。判断が返らない案件を、自分で判断して進めることだけは避けます。判断の責任が自分に移ります。

### 丸投げを組み替えて受けましたが、区切りで「思ったより採用が進まない」と言われました

判断の分担と、数を示します。「私が用意した判断の項目のうち、〇件が判断待ちで止まり、平均〇日かかっています。実行の側では、文面と送信と一次対応をこの数でこなしました」。採用が進まない原因が判断の側にあるなら、それを数で示し、判断の時間を増やしてもらうか、範囲を狭くするかを相談します。実行の側に原因があるなら、仕組みを直します。「任せたのに」という言葉には、書面の判断の線と、記録で応えます。責めずに、数で。
