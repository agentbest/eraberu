本業の平日、副業の夜と週末。気づけば、何か月も休みがない。案件が途切れたときが休みのつもりだったが、途切れると次を探すので、休んだ気がしない。副業の休みは、どう作ればよいのか。結論を先に書くと、**副業の休みは、「案件が途切れたときに取るもの」ではなく、「案件を受ける前にカレンダーに入れるもの」です。週に一日は副業に触れない日、年に数回は数週間の休みを、案件より先に置きます。依頼側には稼働しない日を先に伝え、休みの中では連絡も見ません。休みを後回しにすると、途切れたときが休みになり、途切れは不安なので休めず、疲れが溜まって副業が止まります。休みを先に置くことが、長く続けるための設計の土台です。**続ける設計は[長く続けるための設計](/media/fukugyo-choki/)に、時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、稼働の上限は[超過稼働の扱い](/media/fukugyo-choka-kadou/)にまとめています。

## 休みが後回しになる理由

副業の休みは、意識しないと後回しになります。理由を見ておきます。

| 理由 | 何が起きるか |
|---|---|
| 副業の時間が、本業の外の時間だから | 本業の休み（週末、有給）が、副業の稼働の時間になる。休みが二重に消える |
| 案件が途切れたときが休みだと思っているから | 途切れると次を探すので、休まない。途切れは不安なので、休んだ気がしない |
| 稼働に上限がないから | 受けられるだけ受け、休みの枠が残らない |
| 依頼側に稼働しない日を伝えていないから | いつでも連絡が来て、いつでも返す状態になる |
| 休むと信用が落ちると思っているから | 実際には、いつ稼働するかが分かっている方が信用される |
| 休んでいる間も連絡を見るから | 連絡を見ると、頭は副業に戻る。休んだことにならない |
| 自分の休みが最後に回るから | 本業、家族、副業、の後に自分の休み。残らない |

理由の要点は、「案件が途切れたときが休み」という考え方が、休みを消していることです。案件が途切れたときは、次を探す時期で、不安もあり、休めません。休みは、案件があるときに、案件と別に取るものです。案件と休みを分けて置くには、休みを先に決めるしかありません。稼働の上限は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、途切れたときの動き方は[次の案件につなげる](/media/fukugyo-tsugi-e/)に書いています。

## 三つの休み

副業の休みは、三つに分けて設計します。

| 休み | 内容 | 置き方 | 無いと |
|---|---|---|---|
| 一、週の休み | 週に一日は、副業に触れない日。端末も開かない | 曜日で固定する。本業の休みと重ねてもよいが、その日は副業もしない | 週に一度も頭が切り替わらず、疲れが溜まる |
| 二、年の休み | 年に数回、数週間、副業を止める。家族の長期休暇、自分の休養 | 年の初めに、時期を決めてカレンダーに入れる。案件の区切りをその前に置く | 年に一度も止まらず、燃え尽きる |
| 三、案件の間の休み | 一件が終わって次が始まるまでの、数日から一週間 | 終わった直後に次を始めない。振り返りと休みを置く | 案件が連続し、振り返りもなく、同じ失敗を繰り返す |

三つの要点は、「一」の週の休みが、最も効くことです。週に一日、副業に触れない日があるだけで、頭が切り替わり、翌週の稼働の質が上がります。曜日で固定し、家族と依頼側に伝え、その日は副業の端末を開きません。「二」の年の休みは、案件の区切りと合わせて置くと、依頼側の負担が小さくなります。案件の区切りは[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に、案件の間の振り返りは[事例の書き方](/media/fukugyo-jirei-kakikata/)に整理しています。

### エラベルの見解

担当する側から見ると、何年も続いている担当者は、例外なく、週に一日は副業に触れない日を持っています。稼働が多い人ではなく、休みを固定している人が続いています。依頼側にとって、担当者が週に一日休むことは困ることではなく、「その日は返事が来ない」と分かっていれば予定が組めます。困るのは、いつ返事が来るか分からないことです。休みを固定して伝えることは、依頼側の予定を組みやすくすることでもあります。

見ていて差がつくのは、休みの中で連絡を見ないかです。休みの日に依頼側の連絡を見て、「返さなくては」と考え、結局返している人は、休んだことになっていません。続いている人は、休みの日は副業の端末を開かず、連絡は翌稼働日にまとめて返しています。依頼側には「〇曜は稼働しません。連絡は翌稼働日に返します」と伝えてあるので、依頼側も急ぎの連絡はその日を避けています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働する日としない日を明確にしている担当者が、依頼側との予定が組みやすく、続けて選ばれています。休みは、副業の質を保つ稼働の一部です。

## 休みを案件より先に入れる方法

休みを先に入れるには、順番と道具を決めます。

| 方法 | 内容 |
|---|---|
| 年の初めに、年の休みを入れる | 家族の長期休暇、自分の休養の時期を、一年分カレンダーに入れる。案件はその外に置く |
| 週の休みの曜日を決める | 「水曜と日曜は副業に触れない」のように、曜日で固定する |
| 案件を受けるとき、休みを確認してから稼働を見積もる | 「この案件の期間に、年の休みが入っていないか」「週の稼働は、休みを除いた日で足りるか」 |
| 案件の区切りを、年の休みの前に置く | 契約の期間や更新の時期を、年の休みの前に合わせる。休みの中で案件が動かないように |
| 案件が終わったら、次を始める前に数日置く | 終わった直後に次を受けない。振り返りと休みを置く |
| 休みの日は、副業の端末を開かない | 端末を物理的に別の場所に置く。通知を切る |
| 休みの予定を家族と共有する | 家族の予定と重ね、家族の時間として使う |

方法の要点は、「案件を受けるとき、休みを確認してから稼働を見積もる」ことです。案件を受けるときは、稼働の見積もりに集中し、休みを忘れます。「この案件の期間に、年の休みが入っているか」を確認し、入っているなら、その期間は稼働しないことを依頼側に伝えてから受けます。受けてから「その週は休みでした」と言うと、信用が落ちます。稼働の見積もりは[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、複数案件の場合は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に書いています。

## 依頼側への伝え方

休みは、依頼側に先に伝えることで、取れるようになります。

| 伝えること | 伝え方 | 伝えないと |
|---|---|---|
| 週の稼働しない日 | 契約のときに「〇曜と△曜は稼働しません。連絡は翌稼働日に返します」 | いつでも返事が来ると思われ、休みの日に連絡が来る |
| 年の休み | 決まった時点で、一か月以上前に「〇月〇日から△日まで稼働しません。その前に□□を終えます」 | 直前に伝えると、依頼側の採用が止まる |
| 休みの前に終えること | 休みの前に、区切りをつけて出す。進行中のものの状態を共有する | 休みの中で依頼側が困る |
| 休みの中の連絡の扱い | 「休みの中の連絡は、休み明けに返します。急ぎの場合は〇〇まで」 | 休みの中に連絡が来て、返さないと不安になる |
| 休み明けの再開日 | 「〇日から再開します」 | 依頼側がいつ戻るか分からない |
| 案件の間の休み | 次の案件の相談があったとき、「〇日から始められます」と数日置く | 終わった直後に次が始まり、休めない |

伝え方の要点は、「年の休みは一か月以上前に伝え、その前に区切りをつける」ことです。依頼側にとって、担当者が数週間止まることは、採用が止まることと同じです。一か月以上前に伝え、休みの前に区切りをつけ、進行中のものの状態を共有すれば、依頼側は休みの間の動き方を決められます。直前に伝えると、依頼側の採用が止まり、信用が落ちます。稼働の報告は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に、区切りのつけ方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に整理しています。

## 休みの中で連絡を見ない仕組み

休みを取っても、連絡を見ると休んだことになりません。見ない仕組みを作ります。

| 仕組み | 内容 |
|---|---|
| 副業の端末を分ける | 副業の連絡は副業用の端末にだけ来る形にし、休みの日はその端末を開かない。[私物端末で作業してよいか](/media/fukugyo-tanmatsu/) |
| 通知を切る | 副業のメールとチャットの通知を、休みの日は切る |
| 自動返信を使う | 年の休みは、副業のメールに自動返信を設定し、再開日と急ぎの連絡先を書く |
| 端末を物理的に離す | 休みの日は、副業の端末を別の部屋に置く |
| 家族に預ける | 家族に「今日は副業の端末を見ない」と宣言し、見ていたら指摘してもらう |
| 休みの前に、連絡が来そうなことを先に済ませる | 休みの前に、進行中のものの状態を共有し、依頼側が聞きたいことを先に答えておく |
| 見てしまったら、返さない | 見てしまっても、返信は翌稼働日。「見た」ことを依頼側に知らせない |

仕組みの要点は、「意志で見ないのではなく、仕組みで見えなくする」ことです。休みの日に連絡を見ないと決めても、通知が来れば見てしまいます。通知を切り、端末を離し、自動返信を設定すれば、見る機会そのものが減ります。それでも見てしまったら、返さないと決めておきます。端末と通知の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、メールの運用は[メールの書き方と運用](/media/fukugyo-mail/)に書いています。

## 休みが取れていない兆候と直し方

休みが取れていないことは、自分では気づきにくいものです。兆候を見ます。

| 兆候 | 状態 | 直し方 |
|---|---|---|
| 最後に副業に触れなかった日を思い出せない | 週の休みがない | 今週、一日を空ける。曜日を固定する |
| 案件が途切れることが不安で、終わる前に次を受けている | 案件の間の休みがない | 次の案件の開始を、数日後ろにずらす |
| 年の休みを取ったのがいつか思い出せない | 年の休みがない | 来年の休みを、今、カレンダーに入れる |
| 休みの日に、依頼側の連絡を見て返している | 休みが休みになっていない | 通知を切る。端末を離す。翌稼働日に返すと伝える |
| 家族に「休んでいない」と言われた | 休みの枠がない、または守れていない | 家族と休みの日を決め、家族の時間として使う |
| 本業の休みも、副業で埋まっている | 本業の休みが副業の稼働になっている | 本業の休みの一部を、副業もしない日にする |
| 「やめたい」と思う回数が増えた | 疲れが溜まっている | 一週間、副業を止める。止めてから、休みの設計を作り直す |

兆候の要点は、「やめたい」と思う回数が増えたら、副業が合わないのではなく、休みが足りていないと疑うことです。疲れているときは、副業をやめることで楽になろうとしますが、休みを入れれば続けられることが多いです。一週間止めて、休みの設計を作り直してから、続けるかを決めます。やめる判断は[副業をやめるとき](/media/fukugyo-yameru/)に、設計の見直しは[長く続けるための設計](/media/fukugyo-choki/)に整理しています。

## 休みを設計する順番

休みを設計する順番です。これから始める人も、続けている人も、同じ順番です。

| 順番 | 内容 |
|---|---|
| 一、年の休みを、年の初めにカレンダーに入れる | 家族の長期休暇と、自分の休養の時期 |
| 二、週の休みの曜日を決める | 「〇曜と△曜は副業に触れない」 |
| 三、休みを除いた日で、週の稼働の上限を決める | 休みを引いた残りで、本業と生活に影響が出ない時間 |
| 四、依頼側に、稼働しない日と年の休みを伝える | 契約のときに。年の休みは一か月以上前に |
| 五、休みの中で連絡を見ない仕組みを作る | 端末を分ける、通知を切る、自動返信 |
| 六、案件を受けるとき、休みを確認してから稼働を見積もる | 案件の期間に年の休みが入っていないか |
| 七、案件が終わったら、数日置いてから次を始める | 振り返りと休み |
| 八、年に一度、休みが取れたかを見る | 取れていなければ、来年の休みを先に入れ直す |

順番の要点は、「一」と「二」を、稼働の上限より先に決めることです。稼働の上限を先に決めると、休みは残った時間から探すことになり、残りません。休みを先に置き、残りで上限を決める。この順番が、休みを消さない唯一の方法です。上限の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、家族との共有は[家族の理解を得る](/media/fukugyo-kazoku/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「副業は本業の余りの時間でやるものだから、休みは要らない」というものです。実際には、本業の余りの時間は、本来は休みの時間で、そこに副業を入れると、休みが消えます。続いている担当者は、副業の時間と、休みの時間を、本業の外の時間の中で分けて置いています。休みが無い副業は、質が落ち、疲れが溜まり、止まります。

順番として、年の休みを年の初めに入れ、週の休みの曜日を決め、休みを除いた日で稼働の上限を決め、依頼側に稼働しない日と年の休みを伝え、休みの中で連絡を見ない仕組みを作り、案件を受けるとき休みを確認し、案件が終わったら数日置き、年に一度、休みが取れたかを見る。この順番で、休みは「取れたら取るもの」から「先に置いてあるもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働する日としない日を明確にしている担当者が、依頼側との予定を組みやすく、長く選ばれています。休みは、副業を長く続けるための、最初の設計です。

## まとめ

- 副業の休みは**案件が途切れたときに取るものではなく、案件を受ける前にカレンダーに入れるもの**
- 三つの休みは**週に一日の副業に触れない日・年に数回の数週間・案件の間の数日**。週の休みが最も効く
- **休みを先に置き、残りで稼働の上限を決める**。逆にすると休みは残らない
- 依頼側には**稼働しない日を契約のときに、年の休みは一か月以上前に**伝え、休みの前に区切りをつける
- 休みの中で**連絡を見ない仕組み**（端末を分ける・通知を切る・自動返信）を作る。意志ではなく仕組み
- **「やめたい」が増えたら、休みが足りていないと疑う**。一週間止めて設計を作り直す

## よくある質問

### 週に一日休むと、稼働が減って、受けられる案件が減りませんか

週に一日休んでも、残りの稼働の質が上がるので、成果は減りません。休みなく稼働すると、質が落ち、同じ作業に時間がかかり、結果として稼働あたりの成果が減ります。受けられる案件の数は、休みではなく、稼働の上限で決まります。上限を決めるとき、休みを先に引いて残りで決めれば、案件の数は最初からその前提で決まります。上限の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に整理しています。

### 年の休みを取りたいのですが、案件の途中で止めると依頼側に迷惑がかかりませんか

一か月以上前に伝え、休みの前に区切りをつけ、進行中のものの状態を共有すれば、依頼側は休みの間の動き方を決められ、迷惑にはなりません。迷惑になるのは、直前に伝える、区切りをつけずに止まる、休みの中で連絡が途絶える、の三つです。案件の区切り（更新の時期など）と年の休みを合わせて置けば、さらに負担が小さくなります。区切りのつけ方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

### 休みの日に、依頼側から急ぎの連絡が来たら、どうすればよいですか

「急ぎ」の定義を、契約のときに依頼側と決めておきます。候補者の辞退や、面接の当日の変更など、依頼側の採用が止まる事態だけを急ぎとし、それ以外は翌稼働日に返すと合意します。急ぎの連絡の経路（電話など）を一つだけ開けておき、それ以外の経路は休みの日は見ません。急ぎの定義が決まっていれば、休みの日に「これは急ぎか」と迷うことがなくなります。連絡の運用は[メールの書き方と運用](/media/fukugyo-mail/)に整理しています。
