依頼側から、一人の稼働では収まらない範囲の相談が来た。断るには惜しいので、同じ立場の知人と二人で受けられないかと考える。結論を先に書くと、**複数人で案件を受けること自体はできますが、始める前に「契約の形」「報酬の分け方」「一人が抜けたときの扱い」の三つを文書にし、依頼側には全員の名前と担当する工程を伝えて了解を得てから始めます。**この順番を飛ばして「まず始めて、あとで決めよう」とすると、報酬の話が途中でこじれ、依頼側からは「聞いていない人が動いている」と見られます。複数人で受ける形は、一人で受けるより準備が要り、案件の規模がその準備に見合うかを先に考えます。始まった後の分担の決め方は[チームで動くときの分担](/media/fukugyo-chiimu/)に、受けた業務を後から他の人に回す話は[再委託してよいか](/media/fukugyo-saitaku/)に、法人を窓口にする判断は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)にまとめています。契約の形として問題がないかは、弁護士などの専門家にご確認ください。

## 複数人で受けるのが向く案件と向かない案件

複数人で受ける準備の手間に見合うかは、案件の形で決まります。

| 向く案件 | なぜ向くか |
|---|---|
| 工程がはっきり分かれている | スカウトと一次対応、求人票と日程調整のように、工程で担当を分けられる |
| 期間が数か月以上ある | 準備の手間が、案件の期間に対して小さくなる |
| 依頼側が複数人で受けることを認めている | 依頼側の情報管理と契約の型が、複数人を前提にできる |
| 稼働の山が読める | 採用の時期に合わせて、二人で山を分けられる |

| 向かない案件 | なぜ向かないか |
|---|---|
| 一人で受けられる規模 | 準備と調整の手間のほうが大きい。一人で受けて、足りない分は依頼側と稼働を見直す |
| 判断が多く、一貫性が要る | 要件の整理や面接の設計は、一人で通したほうが一貫する |
| 依頼側が「この人に頼む」と決めている | 複数人にすると、依頼側が選んだ前提が崩れる |
| 短期で終わる | 分担の準備が終わる前に案件が終わる |

向く・向かないの要点は、「工程で分けられるか」と「依頼側が認めるか」の二つです。工程で分けられない案件を二人でやると、同じ工程を二人が触ることになり、候補者と依頼側から見て誰が担当か分からなくなります。依頼側が認めていない案件を二人でやると、再委託と同じ問題になります。一人で受けきれない範囲を頼まれたときの断り方や調整は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)と[受ける範囲の決め方](/media/fukugyo-scope/)に書いています。

## 契約の形は三つある

複数人で受けるとき、依頼側との契約の形は大きく三つに分かれます。どれにするかで、責任と報酬の流れが変わります。

| 形 | 契約の相手 | 責任 | 報酬の流れ | 向く場面 |
|---|---|---|---|---|
| 一人が契約し、中で分ける | 依頼側と代表の一人 | 代表が依頼側に対して全責任を持つ | 依頼側→代表→他の人 | 依頼側の契約の手続きを増やしたくない。代表が窓口として動ける |
| 全員がそれぞれ契約する | 依頼側と各自 | 各自が自分の工程に責任を持つ | 依頼側→各自 | 依頼側が複数の契約を受けられる。責任と報酬を分けたい |
| 窓口の会社や仲介を通す | 依頼側と窓口 | 窓口が依頼側に対して持ち、各自は窓口に対して持つ | 依頼側→窓口→各自 | 仲介や登録型の窓口を使っている。契約の形を窓口に任せたい |

形の要点は、「誰が依頼側に対して責任を持つか」です。一人が契約する形は、依頼側の手続きは軽い一方で、代表が他の人の工程の品質にも責任を持ちます。他の人との間の取り決めが文書になっていないと、依頼側から見れば代表のミスなのに、代表は内容を知らない、という状態になります。全員が契約する形は、責任が分かれる分、依頼側の手続きが増え、依頼側が受けられるかは会社によります。どの形が自分たちの場合に問題ないかは、専門家にご確認ください。

### エラベルの見解

相談で最も多い思い込みは、「二人で受ければ、依頼側にとって手厚くなるので喜ばれる」というものです。実際には、依頼側の担当者が求めているのは、稼働の量ではなく「誰に聞けば分かるか」が一つに決まっていることです。二人で受けて、それぞれが依頼側とやり取りすると、依頼側から見れば窓口が二つになり、手厚いのではなく手間が増えた状態になります。

二人で受けることが依頼側に喜ばれるのは、窓口が一人で、もう一人が中で工程を担い、依頼側から見た担当者が一人のまま稼働が増えている場合です。依頼側に伝えるときも、「二人で担当します」ではなく、「窓口と報告は私が担い、送信の工程を〇〇さんが担います」と工程で伝えると、依頼側は自分が誰と話せばよいかを迷いません。エラベルでは、依頼側が担当者を見て選ぶので、複数人で受けるときも、選ばれた人が窓口であり続ける形をお願いしています。

## 報酬の分け方

複数人で受ける案件で、最もこじれるのが報酬の分け方です。始める前に決め、文書にします。

| 分け方 | 内容 | 向く場面 | 注意 |
|---|---|---|---|
| 工程ごとに配分を決める | 「送信の工程は全体の〇割」のように、工程に対して配分を決める | 工程がはっきり分かれている | 工程の重さの見立てが違うともめる。始める前にすり合わせる |
| 稼働時間で分ける | 各自の記録した稼働時間の比で分ける | 工程が混ざる。稼働の記録を各自が付けている | 記録の粒度が違うと不公平になる。[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)の型を揃える |
| 固定の比率で分ける | 最初に決めた比率で、稼働に関わらず分ける | 期間が短く、稼働の差が小さい | 稼働の差が大きくなると不満が出る |
| 窓口の分を先に引く | 依頼側との窓口、報告、契約の手間の分を先に引き、残りを分ける | 一人が契約し、中で分ける形 | 窓口の分の大きさを先に決める |

分け方の要点は、「窓口の手間を報酬に入れるか」を先に決めることです。一人が契約して窓口になる形では、その人が依頼側とのやり取り、報告、請求、他の人への支払いをすべて担います。この手間を報酬に入れないと、窓口の人の稼働が実質的に高くなり、後で不満になります。単価の考え方は[最初の1件の価格の決め方](/media/fukugyo-shoninka/)と[単価の相場の見方](/media/fukugyo-tanka-souba/)に書いています。

報酬の受け渡しも決めておきます。一人が契約する形では、依頼側からの入金を代表が受け、他の人に支払います。この支払いは、代表から見れば他の人への業務委託の報酬になり、税や請求の扱いが関わるので、専門家に確認してください。全員が契約する形なら、各自が依頼側に請求するので、中での受け渡しは起きません。請求の型は[請求書の書き方](/media/fukugyo-seikyuusho/)に、入金の管理は[決済・振込先の準備](/media/fukugyo-kessai/)に整理しています。

## 依頼側への伝え方

複数人で受けることは、契約の前に依頼側に伝えます。伝える内容を整理しておくと、依頼側は判断しやすくなります。

| 伝えること | 内容 |
|---|---|
| 全員の名前と経歴 | 誰が入るかと、その人の担当する工程の経験。依頼側が「この人なら」と判断できる材料 |
| 工程の担当 | どの工程を誰が担うか。窓口は誰か |
| 情報の扱い | 全員が依頼側との秘密保持と同じ内容を守ること。候補者の情報に触れる人を限ること。[個人情報の扱い](/media/fukugyo-kojin-jouhou/) |
| 媒体のアカウント | 送信を分担するなら、人数分の発行を依頼する。共有しない |
| 契約の形 | 一人が契約するのか、全員が契約するのか。依頼側の手続きで受けられる形を聞く |
| 抜けたときの扱い | 一人が本業の都合で抜けたとき、誰がその工程を引き継ぐか |

伝え方の要点は、「依頼側に選ばせる」ことです。複数人で受けることを決めてから伝えるのではなく、「この形で受けられますが、いかがでしょうか」と、依頼側が受けるかどうかを判断できる形にします。依頼側が「一人で受けてほしい」と言えば、範囲を小さくして一人で受けるか、断るかを選びます。依頼側が了解すれば、その了解を文面で残しておきます。

## 始める前に文書にしておくこと

依頼側の了解が出たら、自分たちの間で取り決めを文書にします。口頭で済ませると、途中で話が変わります。

| 項目 | 内容 |
|---|---|
| 契約の形と契約する人 | どの形で、誰が依頼側と契約するか |
| 工程の担当と窓口 | 工程ごとの担当。依頼側との窓口。報告を出す人 |
| 報酬の分け方と支払いの時期 | 分け方の方法、窓口の分の扱い、依頼側から入金があってから何日以内に分けるか |
| 稼働の記録の方法 | 各自が同じ型で記録する。記録を見せ合う時期 |
| 情報の扱い | 依頼側との秘密保持と同じ内容を、自分たちの間でも約束する。案件が終わったときの情報の処分 |
| 抜けたときの扱い | 抜ける場合は何日前に伝えるか。工程を誰が引き継ぐか。報酬はどう精算するか。[引き継ぎの進め方](/media/fukugyo-hikitsugi/) |
| 実績の書き方 | 終わった後、各自が自分の実績としてどう書くか。[実績の示し方](/media/fukugyo-jisseki-shimeshikata/) |
| 終わり方 | 案件が終わったらチームも解散か、次も組むか |

文書の要点は、「抜けたときの扱い」を起きないものと考えず、起きる前提で書くことです。副業は本業の都合で稼働が変わるものなので、複数人で受ければ、誰かが抜ける場面は珍しくありません。抜けたときの引き継ぎと精算が決まっていれば、抜けること自体は問題になりません。決まっていないと、抜けた人と残った人の間で報酬の話がこじれ、依頼側への稼働も止まります。文書の形式は簡単なもので構いませんが、契約として問題がないかは専門家にご確認ください。

### エラベルの見解

担当する側から見ると、複数人で受けてうまく続いている組は、案件が来てから組んだのではなく、案件が来る前から互いの範囲と稼働を知っています。案件が来てから急いで相手を探し、相手の経験や稼働の癖を知らないまま始めると、工程の分け方も報酬の分け方も見立てが合わず、始まってから直すことになります。

順番として、複数人で受けたいなら、先に同じ立場の人と互いの範囲と稼働を把握しておき、案件が来たときに「この人とこの工程で」とすぐ言える状態にしておく。その状態が無いなら、その案件は一人で受けられる範囲に小さくするか、依頼側に別の担当者を足してもらうほうが、結果は良くなります。エラベルでは、依頼側が担当者を追加したいとき、いまの担当者が人を連れてくるのではなく、依頼側が新しく選ぶ形にしています。組む相手を自分で探すより、依頼側が選んだ人と工程を分けるほうが、契約も情報の扱いも整った状態で始められます。同じ立場の人との関係の作り方は[同じ立場の仲間を作る](/media/fukugyo-nakama/)に書いています。

## まとめ

- 複数人で受けるなら**契約の形・報酬の分け方・抜けたときの扱い**を始める前に文書にし、依頼側に全員の名前と工程を伝えて了解を得る
- 向くのは**工程が分かれている・期間がある・依頼側が認めている・稼働の山が読める**案件。一人で受けられる規模なら一人で
- 契約の形は**一人が契約して中で分ける・全員が契約する・窓口を通す**の三つ。誰が依頼側に責任を持つかで選ぶ
- 報酬は**工程ごと・稼働時間・固定の比率**のどれかで、**窓口の手間を入れるか**を先に決める。受け渡しの税の扱いは専門家に
- 依頼側には**名前と経歴・工程の担当・情報の扱い・アカウント・契約の形・抜けたときの扱い**を伝え、依頼側に選ばせる
- 文書には**抜けたときの扱い**を起きる前提で書く。案件が来る前に、組む相手の範囲と稼働を知っておく

## よくある質問

### 依頼側に伝えずに、二人で受けて一人の名前で進めることはできますか

依頼側は本人の経歴を見て契約しているので、伝えずにもう一人が動くことは、再委託と同じ問題になります。候補者の情報にもう一人が触れた時点で、依頼側との秘密保持の約束の外に出ます。二人で受けるなら、契約の前に伝えて了解を得ることが前提です。伝えたら断られそうだと感じるなら、その案件は一人で受けられる範囲に小さくするか、断るほうが安全です。

### 報酬の分け方で、相手ともめたらどうすればよいですか

始める前の文書に立ち返ります。文書が無い場合は、稼働の記録を互いに出し、工程ごとの重さを話し合って決めるしかありません。決まらない場合は、その案件の分け方は稼働時間の比で決め、次からは始める前に文書にすると決めます。文書があってももめる場合は、文書のどこが曖昧だったかを見て、次の案件で直します。

### 相手が途中で本業が忙しくなり、抜けると言ってきました

文書に決めた引き継ぎと精算の手順に沿って進めます。まず、依頼側に「担当の工程が替わる」ことを伝え、残った人が引き継ぐか、依頼側に別の担当者を足してもらうかを依頼側と決めます。抜ける人の報酬は、抜けるまでの稼働の記録で精算します。抜けること自体を責めるより、依頼側への稼働を止めないことを優先すると、依頼側との関係は続きます。
