内定辞退の連絡が来ると、依頼側は「何が悪かったのか」と担当者に聞き、担当者は「条件でしょうか」「他社が魅力的だったのでしょうか」と推測で答えます。辞退は内定後に起きますが、原因は選考の途中にあります。内定を出してから打てる手は少なく、選考の各段で打つ手のほうが多い。結論を先に書くと、**内定辞退は、速さ（他社が先に決まった）・迷い（答えていない迷いがあった）・接点（内定後に静かになった）の三つの原因に分け、原因ごとに日程と確定の速さ・各段で迷いを拾って答える・内定後の接点の設計で手当てし、辞退の理由を集めて記録し、次の候補者に活かす形で減らします。**会社側から見た見直しの三点は[内定辞退が続くときに見直す3点](/media/rpo-jitai-ooi/)に、理由の集め方は[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に書いています。ここでは、副業の担当者が選考の中で打つ手に絞ります。

## 辞退は内定後に起きるが、原因は途中にある

| 内定後に見える現象 | 実際の原因の場所 |
|---|---|
| 「他社に決めました」 | 日程調整と確定の遅さ。他社が先に内定を出した |
| 「考えた結果、見送ります」 | 選考の途中で出た迷いに、誰も答えていない |
| 「返事が来ない」→辞退 | 内定後に接点が無く、他社の面談が続く中でこの会社だけ静かだった |
| 「条件が合いません」 | 条件の出し方（幅を先に、額は面談で）か、条件そのもの。後者は依頼側の判断 |
| 「家族に反対されました」 | 迷いの一つ。入社後の見通しが本人から家族に説明できる形で渡っていない |

内定を出してからできるのは、接点と、条件の判断（依頼側）だけです。速さと迷いは、選考の途中でしか手当てできません。

## 三つの原因と見分け方

| 原因 | 見分けるための問い | 記録のどこを見るか |
|---|---|---|
| 速さ | 最初の連絡から内定まで何日か。他社と比べてどうか | 候補者リストの送信日・確定日、日程調整の往復回数と止まった日数 |
| 迷い | 選考の各段で記録した迷いのうち、答えていないものがあるか | 評価シートの「候補者の質問と迷い」の欄と、次の段の一枚の「答えること」 |
| 接点 | 内定から辞退までの間に、依頼側から何回、誰が連絡したか | 内定後の接点の記録 |

三つは重なることがあります。速さが遅く、迷いも残り、内定後も静か、という辞退は珍しくありません。記録があれば、どれが大きかったかが読めます。記録が無ければ、推測になります。

### エラベルの見解

担当する側から見ると、内定辞退で最も差がつくのは、「辞退が出た後に慌てない」ことです。受ける側は、辞退が出ると、内定後の接点を厚くする（食事に誘う、社員を紹介する）ことに走ります。ただ、辞退の原因が速さや迷いにあるなら、内定後の接点を厚くしても、次の候補者も同じ場所で辞退します。辞退が出たら、その候補者の記録を「速さ・迷い・接点」の三つで読み、原因の場所を特定し、次の候補者の選考のその場所を直す。それが、辞退を「減らす」ということです。エラベルで担当者を選ぶ企業には、「直近の辞退が、速さ・迷い・接点のどれだったか、記録で言えますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、辞退が出るたびに、三つのどれかを記録に一語で書くこと。三件たまれば、依頼側の選考のどこが弱いかが見えます。

## 原因ごとの手当て

| 原因 | 手当て | 詳しくは |
|---|---|---|
| 速さ | 面接官の枠を先に預かる。候補を三つ以上。確定を即日。段を減らす | [日程調整を速くする](/media/fukugyo-skill-nittei/)、[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/) |
| 迷い | 各段の記録に「質問と迷い」の欄。次の段の一枚に「答えること」。オファー面談でこちらから触れる | [動機づけの設計](/media/fukugyo-skill-douki-zuke/)、[オファー面談の設計](/media/fukugyo-skill-oferring/) |
| 接点 | 内定後の「誰が・いつ・何を」を先に決める。期限には接点を添える | [内定者フォローの進め方](/media/rpo-task-naitei-follow-susumekata/) |

手当ては、辞退した候補者にではなく、次の候補者に対して行います。辞退した候補者を引き戻すことは、この記事の範囲ではありません。

## 内定後の接点の設計

| 時期 | 誰が | 中身 |
|---|---|---|
| 内定の当日 | 人事 | 条件の書面と、オファー面談の日程 |
| オファー面談 | 人事と現場の責任者 | 残っている迷いへの答え、入社後の見通し、決め方と期限 |
| 期限の中間 | 現場の責任者か一緒に働く人 | 候補者が選んだ接点（もう一度話す、見学、同僚との会話） |
| 期限の前 | 人事 | 「決めるために足りないものは」の一度だけの確認 |
| 決定後、入社まで | 人事と現場 | 入社日までの流れ、必要な手続き、一緒に働く人との顔合わせ |

接点は多ければよいのではなく、「候補者が決めるための材料が渡る接点」であることが要点です。用も無く連絡すると、押されていると感じます。接点の記録は、候補者リストの欄に日付と誰がを一行で残します。

## 辞退の理由を集める形

| 集め方 | 中身 |
|---|---|
| 誰が聞くか | 選考で最も話した人（現場の責任者）。人事や担当者より本音が出やすい |
| いつ聞くか | 辞退の連絡の直後に一度だけ。時間が経つと聞けない |
| どう聞くか | 「今後の参考に、決め手になったことを一言いただけますか」。理由を問い詰めない |
| 何を記録するか | 理由の要約と、速さ・迷い・接点のどれか。氏名は媒体のIDで |
| 聞けなかったら | 追わない。記録に「理由不明」。記録の他の欄（速さ・迷い）から推定して一語 |

「一身上の都合」しか返ってこないときの掘り方は[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/)に書いています。理由を聞くのは、その候補者を引き戻すためではなく、次の候補者のためだと、依頼側と共有しておきます。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「辞退の理由が条件なら、条件を上げるしかない」というものです。実際には、「条件が合わない」と言う候補者の多くは、条件だけで決めているのではなく、迷いが残ったまま最後に条件で比べています。迷いに答え切れていれば、同じ条件でも決まることがあり、答えていなければ、条件を上げても決まりません。条件を上げるかどうかは依頼側の判断で、担当者が示唆しませんが、「条件の前に、迷いが残っていなかったか」を記録で確かめる、を先に置きます。受ける側がその場で使える判断としては、「条件」が理由の辞退を記録するとき、「迷い」の欄も同時に見て、答えていない迷いがあったかを一語で書くこと。条件だけの辞退か、迷いが残った上での条件か、を分けて依頼側に渡します。

## 踏み込まない線

| 線 | 理由 |
|---|---|
| 辞退を撤回させようとしない | 理由を一度聞き、記録して閉じる。引き戻しは候補者の判断を侮ることになる |
| 条件を上げる判断を担当者がしない、示唆しない | 依頼側の判断 |
| 収入や昇進を保証するように話さない | 保証できない。約束になる |
| 家族の状況などの私的な事情を聞き出さない | 募集や採用で法令上の決まりがあると一般に整理されている項目にも関わる。本人が自分から言う範囲で受け取る |
| 辞退した候補者の情報を他の目的に使わない | 記録は次の候補者の選考の改善のためだけ |

辞退に伴う費用の取り決め（紹介会社との返金など）は、依頼側と紹介会社の契約の事項で、担当者は関与しません。取り決めの考え方は[内定辞退が出たときの返金・補填の取り決め](/media/rpo-naitei-jitai-henkin/)に書いています。個人情報の扱いや法令に関わる点は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。

## 辞退を記録して次に活かす

| 記録 | 次の候補者への活かし方 |
|---|---|
| 速さ・迷い・接点のどれか | 三件たまれば、選考の弱い場所が見える。手当ての優先順位 |
| 迷いの中身 | ターゲット像の「迷う理由」に足す。次の候補者に先回りする |
| 他社の型（分かれば） | ターゲット像の「比べる相手」に足す |
| 条件の差（分かれば） | 依頼側に渡す。判断は依頼側 |

記録は、依頼側の共有の場所に、候補者の氏名を書かずに置きます。月に一度、辞退の記録を依頼側と読み、次の候補者の選考で直す場所を一つ決めます。数字は自分が扱った件数として伝え、「辞退率」のような割合で断定しません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 辞退が出るたびに内定後の接点を厚くする | 記録で原因の場所を特定してから手当てする。速さと迷いが原因なら接点を厚くしても減らない |
| 辞退の理由が集まらない | 聞く人を現場の責任者に。直後に一度だけ。集まらなくても記録の他の欄から推定 |
| 依頼側が「条件を上げるしかない」と言う | 「迷いが残っていたか」を記録で示す。条件の判断は依頼側 |
| 記録が無く、原因が推測になる | 今回の辞退は推測と書く。次の候補者から記録の欄を作る |
| 辞退した候補者を引き戻そうとする | 理由を一度聞いて閉じる。担当者は引き戻しに関与しない |

## まとめ

- 辞退は内定後に起きるが、**原因は速さ・迷い・接点の三つで、選考の途中にある**
- 原因は**記録で見分ける**。速さは日程の記録、迷いは評価シートの欄、接点は内定後の記録
- 手当ては**次の候補者に**。速さは日程と段、迷いは各段で拾って答える、接点は先に設計
- 内定後の接点は**決めるための材料が渡るもの**だけ。用も無く連絡しない
- 辞退の理由は**現場の責任者が直後に一度だけ**。氏名を書かずに記録
- 「条件」の辞退は**迷いが残っていたかを先に見る**。条件の判断は依頼側
- **撤回させない・条件を示唆しない・私的な事情を聞き出さない**。個別の判断は専門家にご確認ください

## よくある質問

### 内定を出す前に、辞退しそうな候補者を見分けられますか

記録で兆しは読めます。日程の返事が遅くなる、各段で新しい迷いが出続ける、「他社も受けている」と自分から言う、オファー面談の日程が取れない。これらが重なる候補者は、迷いが残っています。見分けて落とすためではなく、迷いに答える接点を厚くするために使います。兆しを「志望度が低い」と決めつけて対応を薄くすると、辞退を自分で作ることになります。

### 依頼側が「辞退した人にもう一度連絡して引き戻してほしい」と言います

担当者は引き戻しに関与しません。辞退は候補者の判断で、理由を一度聞いて記録し、閉じます。依頼側がどうしても連絡したい場合は、依頼側の人事か現場の責任者が、条件や約束に触れない形で一度だけ、と伝えます。引き戻しに成功しても、入社後に「押し切られた」と感じて早期に離職することがある、という構造も添えます。担当者の役割は、次の候補者で同じ場所で辞退が出ないようにすることです。

### 副業の稼働で、内定後の接点まで担当できません

接点の設計（誰が・いつ・何を）を一枚にして依頼側に渡し、実施は依頼側が行う形にします。接点の実施は依頼側の人事と現場が担うほうが、候補者にとっても自然です。担当者は、接点の記録が候補者リストに残っているかを月に一度確かめ、辞退が出たときに記録を読む役割に留めます。範囲は契約に書きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。
