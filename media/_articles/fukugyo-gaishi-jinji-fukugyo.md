外資系の会社の人事として、本社の方針を日本の現場に落とし、職務を定義して採用し、成果で評価し、採用も退職も速く回してきた。この経験は、日本の会社が多い人事の副業で売れるのか。外資系の人事のやり方は、日本の会社には合わない、英語が前提、ドライに見える、と感じる人が多いところです。結論を先に書くと、**外資系の人事の経験は、「本社の方針と日本の現場の間で、職務を定義し、成果で評価し、採用と退職を速く回してきた」型で売れます。売れるのは、「職務の定義で要件を書く型」「成果で見る評価と採用の接続」「速い意思決定で回す採用」「本社と現場の翻訳」の四つです。日本の会社でも、要件が「人柄」と「経験何年」で止まり、面接で何を見るか決まっておらず、決めるのが遅くて候補者に逃げられ、経営者の方針が現場に伝わっていない詰まりは多く、外資系の人事の型が効きます。「外資の人事でした」ではなく、「仕事を定義して、それができる人を、速く公平に採る形を作る」と売ります。**英語が要るかどうかは[英語は必要か](/media/fukugyo-eigo/)に、金融機関の人事の経験は[金融機関の人事が副業でできること](/media/fukugyo-kinyu-jinji-fukugyo/)に、IT企業の人事の経験は[IT企業の人事が副業でできること](/media/fukugyo-it-jinji-fukugyo/)にまとめています。

## この経歴の何が売れるか

外資系の人事の経験を、日本の会社の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| 外資系の人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 職務を定義し、その職務に人を当ててきた | 要件を「この仕事をする人」として、責任の範囲と成果と必要な力で書く型 | 要件が「人柄」と「経験何年」で止まり、面接で何を見るか決まっていない依頼側が多い |
| 成果で評価し、評価と報酬と採用の条件をつなげてきた | 採用の条件を、入社後に何をどこまでやれば評価されるかとセットで決める | 採用の条件と入社後の評価がつながっておらず、入った人が戸惑う依頼側が多い |
| 採用の意思決定を速く回してきた | 面接の回数を絞り、判断する人を決め、日数で管理する選考の設計 | 決めるのが遅く、候補者に逃げられる依頼側が多い |
| 本社の方針を日本の現場に落とし、現場の声を本社に戻してきた | 経営者の方針を現場の言葉に、現場の実情を経営者の言葉に置き換える翻訳 | 経営者の方針が現場に伝わらない依頼側が多い |
| 退職の場面を、手順と書面で扱ってきた | 辞める人の理由の聞き取りと、手続きの流れと、採用への反映 | 退職の場面で感情的になり、理由が採用に戻らない依頼側が多い |
| 多様な背景の人を、同じ基準で見てきた | 面接官の判断を、基準と記録で揃える仕組み | 面接官の「合う・合わない」で決まる依頼側が多い |
| 限られた人事の人数で、多くの機能を回してきた | 小さい人事の部門で、何を自分で持ち、何を外に出すかの切り分け | 人事が一人で、何を優先すべきか分からない依頼側が多い |

売れるものの要点は、「仕事を定義して、それができる人を、速く公平に採る型」です。日本の会社の採用は、「うちに合う人」「経験がある人」という言葉で要件を決め、面接官の印象で判断し、時間をかけて決める形で動いており、それが「何を見ればよいか分からない」「決めるのが遅い」という詰まりになります。外資系の人事は、職務を定義し、基準で見て、速く決めることを日常として回してきており、その型は、要件と判断と速さで困っている日本の会社にそのまま合います。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、評価制度の案件は[評価制度の設計の副業案件](/media/fukugyo-hyouka-seido-fukugyo/)に書いています。

## 売りにくい点とその扱い

外資系の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 日本の会社に合わないと見られる | 「外資のやり方をそのまま持ち込まれたら、社員が反発する」。自分にとっても、日本の会社の空気を知らない不安 | 外資の言葉（ジョブディスクリプション、パフォーマンス、ヘッドカウント）を、日本の会社の言葉（仕事の定義、成果、人数の枠）に置き換える。「合わない」のは言葉で、型は合う |
| 英語が前提と思われる | 「英語の案件しか受けないのでは」「英語ができないうちには関係ない」 | 英語は道具で、売るのは型だと最初に示す。英語が要る案件は別に受けられるが、日本語だけの案件を主にする |
| ドライに見える | 「成果で切る人事は、うちには冷たすぎる」 | 「成果で見る」は「基準を先に決めて、公平に見る」ことだと言い換える。基準がないほうが、面接官の好き嫌いで決まって不公平になる、と構造で語る |

扱い方の要点は、「外資の言葉を日本の会社の言葉に置き換え、ドライではなく公平と言い換える」ことです。外資系の人事の経験がある人は、外資の言葉のまま経験を語り、それが日本の会社の経営者には「うちとは違う世界」と聞こえます。「仕事を先に定義して、それができる人を、基準で見て、速く決める。決める基準を先に出すので、面接官の好き嫌いで決まらず、候補者にも公平です」と言えば、同じ経験が「うちに足りないもの」として伝わります。英語は道具として脇に置き、型を前に出します。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、外資系の人事から転身して続いている人と、面談で止まる人の差は、外資の言葉で語るか、依頼側の言葉で語るかです。止まる人は、ジョブディスクリプションとパフォーマンスの話を外資の言葉のまま語り、依頼側の経営者は「うちは日本の会社なので」と感じて終わります。続いている人は、「御社の求人票の要件には、何と書いてありますか」と聞き、依頼側が「コミュニケーション能力、経験三年以上、当社の理念に共感できる方」と答えたところで、「それだと、面接官は何を見ればよいか分かりません。この仕事で半年後にやってほしいことを三つ書くと、見る点が決まります」と、依頼側の言葉で返します。経営者は、自分の会社の要件が「何も決めていない」ことに気づき、そこから頼みます。

見ていて差がつくのは、速く決める型を、依頼側の意思決定の癖に合わせて設計しているかです。外資系の人事の経験がある人は、「判断する人を一人決めて、日数で切る」型を持っていますが、日本の会社では「みんなで決めたい」「社長の一言で覆る」癖があり、そのまま持ち込むと止まります。「面接は二回まで、判断する人は現場の責任者と経営者の二人、内定を出すまでの日数を決めて、超えたら理由を書く」と、依頼側の癖を残しつつ速さを入れた人は、選考の日数が縮み、依頼側から「初めて候補者に逃げられなかった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「仕事を定義して、それができる人を、速く公平に採る形を作る」と依頼側の言葉で書いている担当者に、要件と判断と速さで困っている依頼側がついています。外資系の人事の転身は、外資のやり方ではなく、依頼側の言葉への置き換えから始まります。

## 案件の探し方

外資系の人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 外資系や海外との取引がある依頼側の採用 | 会社の構造と言葉が分かり、説明の手間がない。英語が要る案件は別の強みに | 同じ構造の依頼側を探す |
| 要件を「仕事の定義」で書き直す | 職務を定義してきた経験でそのまま入れる | 「要件が『人柄』と『経験何年』で止まっている依頼側」を探す |
| 面接の基準と記録の型づくり | 同じ基準で見てきた経験で入れる | 「面接官の好き嫌いで決まる依頼側」を探す |
| 選考を速く回す設計 | 速い意思決定で回してきた経験で入れる | 「決めるのが遅くて候補者に逃げられる依頼側」を探す |
| 採用の条件と入社後の評価の接続 | 成果と評価と採用をつなげてきた経験で入れる | 「入った人が何を期待されているか分からない依頼側」を探す |
| 経営者の方針と現場の翻訳 | 本社と現場の間で動いてきた経験で入れる | 「経営者の方針が現場に伝わらない依頼側」を探す |

探し方の要点は、「要件が決まっていない会社」から入ることです。要件が仕事の定義で書かれ、面接の基準があり、速く決められる会社では、外資系の型は既存の人事と重なります。要件が「人柄」と「経験何年」で止まり、面接官の印象で決まり、決めるのが遅い会社では、外資系の型が唯一の打ち手になります。案件の相談で「良い人が来ない」「面接で何を見ればよいか分からない」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、英語の要否は[英語は必要か](/media/fukugyo-eigo/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。外資系の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 仕事の定義の成果物 | 職務の定義で書いた要件は、成果物として形が明確 | 一式の成果物で受ける |
| 面接の基準と記録の成果物 | 基準の一枚と記録の型は、成果物で受けやすい | 一式の成果物で受ける |
| 選考の速さの設計 | 流れの設計は成果物、運用は月額で | 作る工程は成果物、回す工程は月額で |
| 英語が要る案件 | 英語での面接や本社とのやり取りが要る案件は、できる人が少なく、単価の根拠になる | 英語は別の強みとして、要る案件でだけ根拠にする |
| 「合わない」と見られること | 単価より前に頼まれない | 依頼側の言葉に置き換えた形を先に見せる |
| 集める工程を含まないこと | 媒体とスカウトの運用を含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「仕事の定義と基準は成果物で、運用は月額で受け、英語は要る案件でだけ根拠にする」ことです。外資系の人事の経験で受ける工程は、仕事の定義と面接の基準という成果物が明確で、成果物で受けると単価の根拠が伝わります。英語は、要る案件ではできる人が少なく単価の根拠になりますが、日本語だけの案件で英語を前に出すと、依頼側は「うちには関係ない」と感じます。型を前に出し、英語は脇に置きます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

外資系の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、本社の方針と社員の情報の守秘の条件を確認する | 外資系は本社の規程が別にあることが多い。個別の判断は専門家に |
| 二、「職務をどう定義し、どう基準で見て、どう速く決めてきたか」を、会社の情報を含まない型として書き出す | 定義の書き方、基準の作り方、速さの設計 |
| 三、外資の言葉を、日本の会社の言葉に置き換える | 「ジョブディスクリプション」→「仕事の定義」、「パフォーマンス」→「成果」、「ヘッドカウント」→「人数の枠」 |
| 四、「ドライ」を「公平」に言い換える | 基準を先に決めるから、好き嫌いで決まらない |
| 五、得意な工程（仕事の定義・基準・速さ・評価との接続・翻訳）と、薄い工程（媒体・スカウト・日本の会社の空気）を分ける | 正直に示す準備 |
| 六、範囲を、仕事の定義、面接の基準と記録、選考の速さ、採用と評価の接続、翻訳に絞る | 集める工程は最初は範囲外 |
| 七、「仕事を定義して、それができる人を、速く公平に採る形を作る」の一言を作る | 「外資の人事でした」で終わらせない |
| 八、登録先に、範囲と、日本語だけの案件を主にすることと、英語が要る案件は別に受けられることを登録する | 要件が決まっていない依頼側 |
| 九、仕事の定義で要件を書き直す案件を一件受け、「面接官が見る点が揃った」形を残す | 次の工程に広げる材料に |

順番の要点は、「三」と「四」の置き換えです。外資系の人事の経験は、外資の言葉のまま語ると「別の世界」に聞こえ、「成果で見る」と語ると「冷たい」に聞こえます。日本の会社の言葉に置き換え、ドライを公平に言い換えておくと、同じ経験が「うちに足りないもの」として伝わります。英語は道具として脇に置き、要る案件でだけ前に出します。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「外資系の人事のやり方は、日本の会社には合わない」というものです。実際には、日本の会社の採用の詰まりの多くは、要件が決まっておらず、面接の基準がなく、決めるのが遅いことから来ていて、外資系の人事が日常として回してきた「仕事を定義して、基準で見て、速く決める」型が、そのまま打ち手になります。合わないのは、外資の言葉と本社の仕組みのまま持ち込む場合で、日本の会社の言葉に置き換え、依頼側の意思決定の癖を残しつつ速さを入れれば、合わないものはほとんどありません。合わないのは言葉であって、型ではありません。

順番として、本業の規定と守秘の条件を専門家に確認し、定義と基準と速さの型を会社の情報を含まずに書き出し、外資の言葉を日本の会社の言葉に置き換え、ドライを公平に言い換え、得意な工程と薄い工程を分け、範囲を定義と基準と速さと接続と翻訳に絞り、速く公平に採る形を作る一言を作り、登録先に範囲と英語の扱いを登録し、一件受けて面接官が見る点が揃った形を残す。この順番で、外資系の人事の経験は「日本の会社に合わないもの」から「要件と判断と速さの打ち手」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、定義と基準の工程を明確にし、集める工程を含まないことと英語の扱いを示している担当者に、要件が決まっていない依頼側がついています。外資系の人事の転身は、外資のやり方ではなく、依頼側の言葉への置き換えから始まります。

- 売りにくい点は**日本の会社に合わないと見られる・英語が前提と思われる・ドライに見える**。外資の言葉を日本の会社の言葉に置き換え、英語は道具として脇に置き、ドライを公平に言い換える
- 案件は**要件が「人柄」と「経験何年」で止まっている会社**から。「良い人が来ない」「面接で何を見ればよいか分からない」が入り口
- 単価は**仕事の定義と基準は成果物、運用は月額**で。英語は要る案件でだけ根拠にする。成果報酬は最初は避け、可否は専門家に確認
- 速さの設計は、**依頼側の意思決定の癖を残しつつ入れる**。外資の型をそのまま持ち込まない

## よくある質問

### 英語ができません。外資系の人事の経験は、英語なしでも売れますか

売れます。売るのは「仕事を定義して、基準で見て、速く決める」型で、英語はその型を外資系の会社で使うときの道具にすぎません。日本語だけの依頼側の案件では、英語は要りません。英語ができないことを隠す必要も、英語の案件を無理に受ける必要もなく、「日本語の案件を主に受けます」と登録しておけば、依頼側の期待もずれません。英語の要否は[英語は必要か](/media/fukugyo-eigo/)に、評価される担当者の共通点は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に整理しています。

### 依頼側の経営者から「うちは家族的な会社なので、成果で切るやり方は合わない」と言われました

「成果で切る」ではなく「基準を先に決める」と言い換えて返します。「基準がないと、面接官の好き嫌いで決まり、入った人も何を期待されているか分からず、かえって不公平になります。家族的な会社ほど、基準を先に示すほうが、入った人が安心します」と、構造で語ります。退職の場面の速さは持ち込まず、採用の要件と面接の基準と選考の速さに範囲を絞れば、家族的な会社にも合います。合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

### 本社の人事の仕組みや資料を、日本の会社に持ち込んでよいですか

持ち込みません。本社の仕組みと資料は会社のものであり、守秘の条件に関わります。外資系の会社は、本社の規程が日本の会社の規程とは別にあることが多く、守秘の範囲も広いことがあります。持ち込むのは「仕事を定義する型」「基準の作り方」「速さの設計の型」だけで、資料は依頼側に合わせて新しく作ります。個別の判断は、弁護士や社会保険労務士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に整理しています。
