副業の案件で迷うことがあっても、本業の同僚には副業の話ができず、依頼側には弱みを見せられない。単価の決め方、断り方、稼働の調整を、毎回一人で考えている。結論を先に書くと、**人事の副業は、同じ立場の仲間を数人持っているほうが続きます。仲間に求める役割は「迷ったときに相談できる」「受けきれない案件を回し合える」「互いの範囲と稼働を知っている」の三つで、この三つを満たす相手が数人いれば足ります。**大きな集まりに入る必要はなく、同じように副業をしている人と、互いの範囲を知り合う関係を少しずつ作ります。ただし、仲間との間に依頼側の情報を持ち込まない線を先に引いておかないと、相談のつもりが情報の漏れになります。集まりの使い方は[勉強会や交流会の使い方](/media/fukugyo-benkyoukai/)と[コミュニティへの参加](/media/fukugyo-community/)に、複数人で受ける形は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)にまとめています。

## 仲間がいると何が変わるか

一人で副業を続けている人と、同じ立場の仲間がいる人で、続き方に差が出る場面があります。

| 場面 | 一人のとき | 仲間がいるとき |
|---|---|---|
| 単価を決める | 相場を検索して迷い、安く受ける | 同じ範囲で受けている人の考え方を聞ける。数字ではなく決め方が分かる |
| 断るか受けるか迷う | 断ると次が無いと感じて受ける | 「自分なら断る」「この条件なら受ける」と聞けて、判断の基準が持てる |
| 依頼側とのやり取りで困る | 依頼側の言い分を一人で受け止め、自分が悪いと思う | 同じ経験をした人から、よくあることかどうかを聞ける |
| 受けきれない案件が来る | 断るしかない | 範囲が合う仲間に紹介できる。逆に紹介してもらえる |
| 本業が忙しくなる | 稼働が下がり、案件が止まる | 依頼側の了解のうえで、工程を一時的に頼める相手がいる |
| 続けるか迷う | 誰にも言えず、静かにやめる | 続けている人の話を聞いて、自分の続け方を考えられる |

変わることの要点は、「判断の基準が持てる」ことです。副業の判断は、本業の経験だけでは足りない部分があり、同じ立場の人の考え方を聞くことで、自分の基準ができます。単価や断り方の判断は、[最初の1件の価格の決め方](/media/fukugyo-shoninka/)や[断り方](/media/fukugyo-kotowaru/)に書いてありますが、自分の場合に当てはめるときに、同じ立場の人の話が効きます。

## 仲間に求める三つの役割

仲間は多いほどよいわけではなく、役割で考えると、数人で足ります。

| 役割 | 内容 | 相手に求めること |
|---|---|---|
| 相談できる相手 | 単価、断り方、依頼側とのやり取りで迷ったときに、考え方を聞ける | 同じ立場で副業をしていて、自分より少し先を歩いている。依頼側の情報を聞き出さない |
| 案件を回し合える相手 | 自分の範囲に合わない案件を紹介できる。逆に紹介してもらえる | 範囲が自分と少し違う。互いに紹介の礼儀を守る。[紹介につなげる](/media/fukugyo-shoukai-renkei/) |
| 範囲と稼働を知り合っている相手 | 複数人で受ける案件が来たとき、すぐに組める | 互いの範囲、稼働できる時間、得意な工程を知っている。[チームで動くときの分担](/media/fukugyo-chiimu/) |

役割の要点は、「一人の相手に三つを求めない」ことです。相談できる相手が、案件を回し合える相手とは限りません。範囲が同じ人は相談相手として合いますが、案件を回し合うには範囲が少し違う人のほうが向きます。役割ごとに一人か二人いれば、合わせて数人になります。

### エラベルの見解

担当する側から見ると、長く続いている人の多くは、同じ立場の相談相手を一人か二人持っています。相談の内容は、案件の中身ではなく、「この条件は受けてよいか」「この断り方で角が立たないか」といった判断の仕方です。一人で判断していると、依頼側の言い分をそのまま受け止めて安く受けたり、逆に警戒しすぎて断ったりと、判断が振れます。同じ立場の人に聞くと、振れ幅が小さくなります。

一方で、仲間との間で依頼側の名前や候補者の話を出してしまう人がいます。相談のつもりでも、依頼側から見れば情報が外に出たことになります。相談は、依頼側と候補者を特定できない形にし、「こういう条件の案件で、こういう場面で迷っている」という構造だけにする。この線を守れる相手が、相談相手として長く続きます。エラベルでは、担当者どうしが依頼側の情報を共有することは認めていませんが、判断の仕方を互いに聞くことは、続けるうえで役に立つと考えています。

## 作る場所と作り方

同じ立場の仲間は、探しに行くより、いくつかの場所で少しずつ知り合っていくほうが、合う人に出会えます。

| 場所 | 出会える人 | 作り方の要点 |
|---|---|---|
| 人事の勉強会や交流会 | 本業で人事をしている人。副業をしている人も混ざる | 副業の話を自分から少し出すと、している人が声をかけてくる |
| 副業や複業の集まり | 職種を問わず副業をしている人 | 人事の人は少ないが、判断の仕方は職種を超えて共通する部分がある |
| 登録先や仲介サービスのつながり | 同じ窓口で受けている人 | 窓口が交流の場を持っていれば、範囲が近い人に会える |
| SNSでの発信 | 発信を見て声をかけてくる人。自分が声をかけたくなる人 | 発信の内容が「判断の仕方」なら、同じ考え方の人が集まる。[SNS発信から案件につなげる](/media/fukugyo-sns-hasshin/) |
| 過去の同僚や前職の人事 | すでに信頼がある人。副業をしている場合がある | 副業をしていると分かれば、最も早く相談相手になる。本業の会社の情報は持ち込まない |
| 依頼側で一緒に動いた外部の担当者 | 同じ案件で別の工程を担った人 | 案件が終わった後に、範囲と稼働を知り合った関係が残る |

作り方の要点は、「副業をしていることを、話してよい場所では話す」ことです。副業をしていることを隠していると、同じ立場の人に出会えません。本業の会社に伝えていない場合は、本業の関係者がいる場では話せませんが、それ以外の場では話してよいことが多いです。話すときは、依頼側の名前と候補者の話は出さず、「人事の副業で、スカウトの運用を受けている」程度にとどめます。

## 依頼側の情報を持ち込まない線

仲間との関係で最も気をつけるのは、依頼側と候補者の情報を持ち込まないことです。相談のつもりで話したことが、依頼側から見れば情報の漏れになります。

| 話してよいこと | 話さないこと |
|---|---|
| 「こういう規模・業界の会社で、こういう範囲を受けている」 | 依頼側の会社名、担当者の名前 |
| 「この条件で迷っている」という構造 | 依頼側の求人の内容、給与の幅、選考の基準 |
| 「候補者とのやり取りでこういう場面があった」という一般化した話 | 候補者の名前、経歴、選考の状況 |
| 自分の単価の決め方、断り方の考え方 | 依頼側と合意した具体の単価と契約の条件 |
| 自分の稼働の管理の仕方 | 依頼側の社内の事情、組織の話 |

線の要点は、「依頼側と候補者が特定できる情報は出さない」ことです。会社名を出さなくても、業界と規模と状況を細かく話せば特定できることがあります。相談は、判断の構造だけにし、詳細は削ります。[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[情報の取り扱いと端末の分離](/media/fukugyo-security/)に書いた線は、仲間との会話にもそのまま当てはまります。本業の会社の情報も同じで、本業の採用の内情を副業の仲間に話すことは、本業に対する情報の持ち出しになります。

## 関係を続ける工夫

同じ立場の仲間は、作るより続けるほうが難しいです。副業は本業の合間なので、連絡が途切れやすいからです。

| 工夫 | 内容 |
|---|---|
| 相談するときは構造にして短く | 「この条件で受けるか迷っている。あなたなら」と一言で聞ける形にする。長い相談は相手の負担になる |
| 相談されたら同じように返す | 相手が迷ったときに、自分の考え方を短く返す。一方的に聞くだけの関係は続かない |
| 案件を回すときは礼儀を守る | 紹介するときは相手の範囲と稼働を確認してから。紹介された案件の結果は伝える |
| 頻度を決めない | 定期に会う約束は、本業の都合で守れなくなる。迷ったときに連絡できる関係で足りる |
| 互いの範囲の変化を知らせる | 範囲が広がった、稼働が変わったときに、一言伝えておく。次に案件を回すときに合う |
| 依頼側の情報を持ち込まない相手を選ぶ | 会社名や候補者の話を聞き出そうとする相手とは、相談の関係を続けない |

工夫の要点は、「頻度を決めない」ことです。副業の仲間との関係は、定期の集まりより、迷ったときに連絡できることに価値があります。定期に会う約束をすると、本業が忙しい時期に守れず、それが理由で関係が途切れます。数か月に一度でも、迷ったときに「あなたなら」と聞ける相手がいれば、続いていることになります。

### エラベルの見解

仲間を作る前に、自分の範囲と稼働を言葉にしておかないと、相談も紹介も噛み合いません。「人事の副業をしている」だけでは、相手は何を相談してよいか、何を回してよいか分かりません。「スカウトの運用と求人票を、週にこれだけの時間で受けている」と言える状態にしてから仲間を作ると、相手も自分の範囲を言い、互いに何を頼めるかが決まります。

エラベルでは、担当者どうしの横のつながりを作ることは仕組みとしては持っていませんが、依頼側が担当者を追加するときに、いまの担当者と範囲が違う人を選ぶ形にしています。そのため、同じ依頼側で別の工程を担った担当者どうしが、案件の後に範囲を知り合った関係として残ることがあります。仲間は、探して作るものというより、自分の範囲を言える状態にしておくと、案件を通して自然にできるものです。範囲の言葉の決め方は[受ける範囲の決め方](/media/fukugyo-scope/)に、それをプロフィールに書く形は[プロフィールの書き方](/media/fukugyo-profile/)に整理しています。

## まとめ

- 同じ立場の仲間は**相談できる・案件を回し合える・範囲と稼働を知り合っている**の三つの役割で、数人いれば足りる
- 仲間がいると**判断の基準が持てる**。単価、断り方、依頼側とのやり取りで、振れ幅が小さくなる
- 一人の相手に三つの役割を求めない。役割ごとに一人か二人
- 作る場所は**勉強会・副業の集まり・登録先のつながり・SNS・過去の同僚・同じ案件の外部の担当者**。副業をしていることを話してよい場所では話す
- **依頼側と候補者が特定できる情報は持ち込まない**。相談は判断の構造だけにし、詳細は削る
- 続けるには**構造にして短く・同じように返す・紹介の礼儀・頻度を決めない・範囲の変化を知らせる・情報を聞き出す相手とは続けない**

## よくある質問

### 周りに副業をしている人事の人がいません。どこから始めればよいですか

人事の勉強会や交流会で、自分から副業の話を少し出すと、している人が声をかけてくることがあります。それでも見つからなければ、職種を問わない副業の集まりで、判断の仕方を聞ける相手を探します。人事でなくても、単価の決め方や断り方の考え方は共通する部分があります。範囲と稼働を知り合う相手は、案件を通して知り合う形もあるので、急がなくて構いません。

### 仲間に依頼側を紹介してもらったとき、お礼はどうすればよいですか

金銭のお礼は、紹介する側も受ける側も期待しないことが多く、かえって関係を難しくすることがあります。紹介された案件の結果を伝え、自分の範囲に合わない案件が来たときに逆に紹介する、という形で返すのが一般的です。紹介の礼儀と、紹介者の顔を立てる進め方は[知人紹介で受けるときの注意](/media/fukugyo-shoukai/)に書いています。

### 仲間との会話で、うっかり依頼側の会社名を出してしまいました

出してしまった情報は戻せないので、その場で「会社名は忘れてほしい」と伝え、以後の会話ではその依頼側の話を出さないようにします。相手が信頼できる人なら、それで広がることは少ないです。依頼側との秘密保持の内容によっては、依頼側に伝えるべき場合もあるので、契約の内容を確認し、迷えば専門家に相談してください。次からは、相談を判断の構造だけにする線を、話す前に決めておきます。
