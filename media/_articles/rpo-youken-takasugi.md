半年、募集を出している。応募は来るが、書類で全員落ちる。面接に進んだ数人も、「経験が足りない」で落ちる。紹介会社には「その要件では該当者がいない」と言われる。要件を下げたいが、現場は「これができないと困る」と譲らない。結論を先に書くと、**要件が高すぎて誰も通らないとき、「要件を下げる」と言うと現場は抵抗します。代わりに、「役割を分ける」「育てる範囲を決める」「要件を観察できる言葉に直す」の三つで、要件の水準を変えずに通る人を作ります。それでも通らないなら、市場に合わせて調整しますが、調整の判断は現場と一緒に、記録を根拠に行います**。要件が固まらない場合は[採用要件が固まらない](/media/rpo-youken-katame/)に、必須と歓迎の線引きは[必須要件と歓迎要件の線が引けない](/media/rpo-must-want/)にまとめています。

## 要件が高すぎる状態の見分け方

「要件が高すぎる」かどうかは、記録で分かります。

| 兆候 | 見方 |
|---|---|
| 書類の通過率が極端に低い | 応募のほとんどが書類で落ちる。要件と応募者の層が合っていない |
| 面接で「経験が足りない」が落とす理由の大半 | 面接に進んでも、経験の水準で落ちる。要件の水準が市場より高い |
| 紹介会社が「該当者がいない」と言う | 紹介会社は市場を見ている。複数社が同じことを言えば、要件が市場に無い |
| 半年以上、内定が出ていない | 期間が長いのに結果が出ない |
| 要件の数が多い | 必須が六つ以上。全部を満たす人は、市場に少ない |
| 要件が「全部できる人」になっている | 「〇〇も△△も□□も」。一人でなく、二人分の要件 |
| 既存社員が、その要件を満たしていない | 「今いる人が、この要件で応募したら通るか」。通らないなら、高すぎる |

最後の項目が、最も分かりやすい確認です。既存社員の中で、その役割を担っている人が、要件を満たしていないなら、要件は実態より高く書かれています。

## 高すぎる原因

要件が高くなる原因は、いくつかあります。

**「理想の人」で書いている。** 実際にやることではなく、「こういう人がいたら」で書いている。原因の中で最も多いです。

**複数の役割を、一人に載せている。** 「営業もできて、企画もできて、管理もできる」。一人分の役割ではなく、二人分、三人分の役割を、一つの求人にしている。

**「即戦力」を「全部できる」と読み替えている。** 「入社してすぐ動ける」を、「何も教えなくてよい」と解釈し、育てる範囲をゼロにしている。

**過去の失敗への反応。** 「前に採った人が〇〇できなかった」から、〇〇を必須にし、次に△△が問題になれば△△も必須にし、積み上がっている。

**現場の不安。** 「教える時間が無い」「失敗されると困る」。不安が、要件の高さになっている。

**市場を見ていない。** 「この要件の人が、この条件で、市場にいるか」を確認せずに書いている。

**抽象語で書いている。** 「高いコミュニケーション力」「リーダーシップ」。抽象語は、面接官ごとに高く解釈され、誰も通らなくなる。

原因が分かれば、「下げる」以外の対処が見えます。

## 下げずに通る人を作る三つの方法

「要件を下げる」と言わずに、通る人を作る方法です。

**一、役割を分ける。** 二人分の要件を、一人に載せている場合。「営業と企画と管理」を、「営業」の求人と「企画と管理」の求人に分けます。分ければ、それぞれの要件は一人分になり、通る人が出ます。または、「最初の三か月はこの範囲、一年でこの範囲」と、時期で分けます。

**二、育てる範囲を決める。** 「全部できる人」ではなく、「〇〇はできる人を採り、△△は入社後三か月で教える」。育てる範囲を決めれば、必須は減ります。育てる型（教える人、三か月の予定、到達点）を一緒に決めます。型の作り方は[未経験採用に踏み切るか迷っている](/media/rpo-mikeiken-saiyo/)に書いています。

**三、要件を観察できる言葉に直す。** 「高いコミュニケーション力」を「顧客の要望を聞き取って、社内に文章で伝えられる」に。「リーダーシップ」を「三名以上のチームの目標を決めて、進捗を管理した経験」に。観察できる言葉にすると、面接官の解釈の高さが揃い、「実は満たしている人」が通ります。

三つとも、要件の「水準」は下げていません。載せ方と、範囲と、言葉を変えています。現場に「下げてください」と言うのではなく、「分けましょう」「育てる範囲を決めましょう」「言葉を直しましょう」と言います。

## 市場に合わせる調整

三つの方法でも通らないなら、市場に合わせて調整します。

**紹介会社と媒体の担当者に、「どの要件で該当しなくなるか」を聞く。** 「〇〇の経験が必須で、年収がこの幅なら、該当者はほぼいない」のように、具体的に返ってきます。数字を資料に載せる場合は出典を明記します。

**同じ職種の他社の求人票と、要件を比べる。** 自社の要件が、同じ条件の他社より高いか。高ければ、市場で負けています。

**「要件を維持して条件を上げる」か「条件を維持して要件を調整する」か。** 市場に合わせるには、どちらかです。両方を維持したままでは、通りません。判断は責任者と、記録を根拠に。条件の考え方は[提示年収が市場と合っていない](/media/rpo-nenshu-awanai/)に書いています。

**「経験の年数」より「経験の中身」で調整する。** 「五年以上」を「三年以上」にするより、「〇〇を自分で設計した経験」のように中身で書けば、年数が短くても中身が合う人が通ります。

**「業界の経験」を「隣の経験」に広げる。** 「同業界での経験」を必須にすると、市場が狭い。「〇〇の動き（顧客と話す、数字を追う）の経験」に広げれば、隣の業界から通る人が出ます。

**調整した要件で、三か月試す。** 調整の効果を、応募と面接の記録で見ます。通る人が出れば、調整は正しい。出なければ、次の調整。

市場に合わせる調整は、「妥協」ではなく、「市場にいる人の中から、役割に合う人を見つける」ことです。

### エラベルの見解

相談で最も多い失敗は、「要件が高すぎて半年誰も通らないので、人事が『要件を下げましょう』と現場に言い、現場が『下げたら困る』と拒み、そのまま一年募集が続いた」というものです。「下げる」と言われた現場は、抵抗します。同じ要件を「役割を分ける」「〇〇は入社後三か月で教える範囲にする」「言葉を観察できる形に直す」と言い換えて提案したら、現場は「それなら」と応じました。水準は変えていません。載せ方と範囲と言葉を変えただけで、通る人が出ました。

見ていて差がつくのは、担当者が「下げる」以外の言葉を持っているかどうかです。「要件を下げましょう」しか言えない担当者と、「分ける・育てる範囲を決める・言葉を直す」の三つを、現場の言葉で提案できる担当者がいます。後者は、現場を敵にしません。

発注側にできるのは、現場に「要件を下げてほしい」と言わず、担当者に「下げずに通る人を作る方法を、現場と一緒に考えてほしい」と依頼することです。

## 現場との合意の取り方

要件を直すには、現場の合意が要ります。取り方です。

| 場面 | 型 |
|---|---|
| 記録を見せる | 「半年で応募〇件、書類で通ったのが△件、面接で通ったのがゼロ。紹介会社二社が該当者なしと言っている」。感覚でなく記録で |
| 「既存社員は通るか」を聞く | 「今いる〇〇さんが、この要件で応募したら通りますか」。通らないなら、要件が実態より高いと現場が気づく |
| 「最初の三か月にやること」を聞く | 「入社した人が、最初の三か月で実際にやることは何ですか」。理想でなく実際から要件を作り直す |
| 「下げる」と言わない | 「分ける」「育てる範囲を決める」「言葉を直す」と言う |
| 育てる負担を、見える形で示す | 「〇〇を入社後に教える場合、教える人は△△さん、週に□時間、三か月」。負担が見えれば、現場は判断できる |
| 現場の不安を聞く | 「失敗されると困る」「教える時間が無い」。不安に対処する設計（役割の段階、教える型）を一緒に作る |
| 試す期間を決める | 「直した要件で三か月試して、記録で判断する」。永久の変更ではなく、試行として |
| 決める人 | 割れたら、役割の直属の責任者が決める |

合意の要点は、「現場が悪い」にしないことです。要件が高いのは、現場の不安と、書き方の問題です。不安に対処し、書き方を変えれば、現場は応じます。

## 要件を直した後の確認

要件を直したら、効果を確認します。

**書類の通過率の変化。** 直す前と後で、書類で通る率が変わったか。

**面接で落とす理由の変化。** 「経験が足りない」が減り、「役割の認識」「相性」のような、面接で本来見るべき理由に変わったか。

**紹介会社の反応の変化。** 「該当者がいない」から、推薦が来るようになったか。

**通った人が、入社後に困っていないか。** 要件を直して採った人が、三か月で到達点に届いているか。届いていれば、直した要件は正しかった。届いていなければ、育てる範囲か要件を見直す。

**現場の実感。** 「直した要件で採った人は、現場でどうか」を、現場の責任者に聞く。

**三か月ごとの見直し。** 記録を見て、要件をさらに調整するか、戻すか、維持するかを決める。

確認が無いと、「直したが効いたか分からない」で終わり、次の採用で同じ議論を繰り返します。

## 外注する場合の範囲

要件が高すぎる問題を、採用代行に出す場合の範囲です。

**出せる工程。** 高すぎる状態の記録での確認、原因の切り分け、役割を分ける案、育てる範囲の案（教える型を含む）、観察できる言葉への書き換え、市場との合いの確認（紹介会社と媒体の担当者への聞き取り）、他社の求人票との比較、現場との合意の場の設計と進行、直した要件での求人票、直した後の記録と確認の材料、三か月ごとの見直しの材料。

**社内に残す判断。** 役割の決定、要件の決定と変更、育てる範囲と教える人の決定、条件の決定、現場の合意。

**外注の効きどころ。** 要件が高すぎる会社は、人事と現場の間で「下げる・下げない」の対立になっています。外部の担当者が「分ける・育てる範囲・言葉」の三つを持ち込み、記録と市場の情報を添えて現場と話せば、対立は「一緒に設計する」形に変わります。担当者は現場の敵ではないので、現場の不安を聞き出しやすい面があります。

**外注しても動かない場合。** 現場が「全部できる人でないと困る」を譲らず、育てる負担を認めない、責任者が決めない。社内の判断で、代行を替えても直りません。

要件の高さは、載せ方と範囲と言葉で変わります。外注は、変え方を持ち込む手段です。

### エラベルの見解

担当する側から見ると、要件が高すぎる相談で最も多いのは、「即戦力」の意味の取り違えです。「即戦力」を「何も教えなくてよい人」と解釈し、育てる範囲をゼロにしている。ただ、どんな経験者でも、自社のやり方、顧客、社内の関係は、入社後に覚えます。教える範囲がゼロの採用は、ありません。

「即戦力」を「〇〇はできる状態で来て、△△は入社後三か月で覚える人」と定義し直すと、必須は減り、通る人が出ます。教える範囲を「ゼロ」から「三か月で覚えられる範囲」にするだけです。

発注側にできるのは、「即戦力」の中身を、現場と一緒に「できる状態で来ること」と「入社後に覚えること」に分けることです。

## よくある質問

### 現場が「要件を下げたら困る」と言います

「下げる」と言わないことです。「役割を分ける」「〇〇は入社後三か月で教える範囲にする」「言葉を観察できる形に直す」と提案します。水準は変えず、載せ方と範囲と言葉を変えます。記録（半年で通った人がゼロ、紹介会社が該当者なし）を見せ、「今いる〇〇さんがこの要件で応募したら通りますか」と聞きます。現場の不安（教える時間が無い、失敗されると困る）を聞き、教える型と役割の段階で不安に対処します。

### 要件を緩めると、質の低い人が来ませんか

「緩める」と「観察できる言葉に直す」「育てる範囲を決める」は違います。「五年以上の経験」を「〇〇を自分で設計した経験」に直せば、年数は短くても中身が合う人が通り、年数は長くても中身が無い人は通りません。質は、要件の高さではなく、要件の的確さで決まります。抽象語で高く書いた要件は、質の高い人も落とし、抽象語を満たす人だけを通します。

### 紹介会社に「該当者がいない」と言われました

「どの要件で、該当しなくなりますか」と聞きます。「〇〇が必須で、年収がこの幅なら」のように具体的に返ってきます。その要件を、「役割を分ける」「育てる範囲にする」「隣の経験に広げる」のどれかで扱えるかを、現場と検討します。それでも維持するなら、条件を市場に合わせるかどうかの判断です。要件と条件の両方を維持したままでは、市場にいない人を探し続けることになります。
