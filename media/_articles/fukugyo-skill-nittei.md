返信が来て、面談に進むことになった。ここで日程が決まるまでに一週間かかると、候補者は他社で先に進み、依頼側は「候補者の熱が冷めた」と言います。ただ、冷めたのではなく、待たされたのです。日程調整が遅いのは、候補者の都合ではなく、往復の回数が多いことと、社内で止まる日数があることが原因です。結論を先に書くと、**日程調整は、面接官の枠を先に預かる・候補を三つ以上出す・一往復で決める・確定を即日返すの四つの原則で組み、社内で止まる日数をゼロにし、往復の回数と止まった日数を記録して改善します。**会社側から見た構造は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に、案件として受ける形は[日程調整の代行の副業の実務](/media/fukugyo-nittei-chousei-fk-shigoto/)に書いています。ここでは、速くする型に絞ります。

## 遅くなる原因は候補者ではない

| 遅くなる場面 | 実際の原因 |
|---|---|
| 候補者に「ご都合を」と聞き、返ってきた日が面接官と合わない | 面接官の枠を先に押さえていない。往復が増える |
| 候補者の希望を面接官に確認し、返事が二日来ない | 社内で止まっている |
| 一つの候補日だけ出して、合わずにやり直し | 候補の数が少ない |
| 確定の連絡を翌日にまとめて送る | 確定が遅れ、その間に候補者が他社を入れる |
| 面接官が複数で、全員の都合を合わせる | 往復が面接官の数だけ増える |

どれも候補者の側ではなく、依頼側の側の構造です。担当者が変えられるのは、この構造です。

## 四つの原則

| 原則 | 中身 | 効果 |
|---|---|---|
| 先に枠を預かる | 面接官から、週の中で面談に使える枠を先にもらっておく | 候補者に聞く前に、出せる候補がある |
| 候補を三つ以上出す | 曜日と時間帯を散らして三つ以上。「この中で合う日を」 | 一往復で決まる確率が上がる |
| 一往復で決める | 候補者が選んだら、面接官に確認せず確定する（枠を預かっているので） | 社内で止まる日数がゼロ |
| 確定を即日返す | 候補者の返信を見たその日に、確定と当日の案内を返す | 候補者が他社を入れる前に固める |

四つのうち、最も効くのは「先に枠を預かる」です。これが無いと、残りの三つが成り立ちません。

### エラベルの見解

担当する側から見ると、日程調整で最も差がつくのは、面接官から枠を「預かる」交渉ができるかどうかです。受ける側は、面接官に「候補者の希望はこの日ですが、ご都合はいかがですか」と毎回聞きます。それでは面接官が返事をするまで止まります。「毎週この曜日のこの時間帯を、面談の枠として二つ空けておいてください。埋まらなければ前日に解放します」と先にもらえば、候補者に即日で候補を出せます。エラベルで担当者を選ぶ企業には、「面接官の枠を、担当者が先に預かれる形になっていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、案件の最初に「枠を預かる」を依頼側との合意事項に入れること。面接官が「忙しくて枠は出せない」と言うなら、「候補者が流れる原因は、面接官の返事を待つ日数です」と、構造で説明します。

## 枠を預かる交渉

| 手順 | 中身 |
|---|---|
| 一 | 面接官ごとに、週の中で面談に使える曜日と時間帯を聞く。「一週間に二枠」のように数で |
| 二 | 埋まらなかった枠は、前日にどう扱うか決める（解放する、翌週に持ち越す） |
| 三 | 枠の変更は、面接官から担当者に先に連絡してもらう形にする |
| 四 | 枠の一覧を、依頼側と共有する場所に置く。担当者の手元だけに置かない |
| 五 | 面接官が複数なら、「誰か一人が入れば実施」の形にできるかを確認する |

複数の面接官の全員が入る形は、往復が増えます。一次は一人、二次は二人、のように、段階ごとに人数を絞る提案をします。人数と段階は依頼側が決めます。

## 候補者への提示の文面の型

| 要素 | 書くこと |
|---|---|
| 面談の形 | オンラインか対面か、所要時間、相手（役職まで） |
| 候補 | 三つ以上。曜日と時間帯を散らす。「〇日（〇）〇時〜、〇日（〇）〇時〜、〇日（〇）〇時〜」 |
| 選び方 | 「合う日をひとつお選びください。合わなければ、ご都合の良い曜日と時間帯を二つほどお知らせください」 |
| 期限 | 「〇日までにご返信いただけると、枠を確保できます」 |

候補が一つも合わないときのために、「曜日と時間帯を二つ」と先に聞いておくと、二往復目で決まります。返信の型は[返信対応のテンプレート](/media/fukugyo-skill-henshin-taiou/)の「前向き」の型と同じで、四行以内にします。

## 確定後にやること

| やること | 中身 |
|---|---|
| 確定の連絡 | 即日。日時、形、相手、当日の接続先か場所、当日の連絡先 |
| 面接官への連絡 | 同日。候補者の媒体のIDと、面談で確かめること（要件の面接で確かめる項目） |
| リマインド | 前日に候補者と面接官の両方へ。接続先を再掲 |
| 当日の連絡先 | 候補者が遅れる・つながらないときに連絡できる先。担当者が動けない時間なら依頼側の窓口 |
| 記録 | 候補者リストに、確定日と往復の回数 |

確定の連絡に「当日の連絡先」が無いと、当日つながらなかったときに候補者が諦めます。副業の担当者が本業で動けない時間帯なら、依頼側の窓口を書きます。動けない時間の扱いは[平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「日程調整は、決まれば終わり」というものです。実際には、決まってから当日までの間に、候補者が来なくなることがあります。来ない理由は、候補者の性格ではなく、確定から当日までの連絡の設計にあります。リマインドが無い、接続先が分からない、当日の連絡先が無い、日程が遠すぎる。この四つを設計で潰すと、来ない数は減ります。日程が遠いのは、枠が少ないことが原因なので、枠を預かる交渉に戻ります。受ける側がその場で使える判断としては、確定の連絡を、「日時」だけでなく「当日の接続先と連絡先」まで入れた型にして、前日のリマインドを候補者リストの送信日と同じ記録で管理すること。来ない数を減らす設計は[面接のドタキャン・無断欠席を減らす](/media/rpo-mensetsu-kettai/)に書いています。

## 記録で改善する

| 記録すること | 見ること |
|---|---|
| 往復の回数 | 候補者と何往復で決まったか。二往復を超えるなら候補の出し方 |
| 社内で止まった日数 | 面接官の返事待ちが何日あったか。ゼロでなければ枠の預かり方 |
| 最初の連絡から確定までの日数 | 全体の速さ |
| 確定から当日までの日数 | 遠いなら枠の数 |
| 来なかった数と理由 | リマインドと連絡先の設計 |

記録は候補者リストの欄に足します。月に一度、往復の回数と止まった日数を依頼側に一行で伝え、枠の数や面接官の人数の見直しを提案します。数字は自分が扱った範囲の数として伝えます。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 踏み込まない線

| 線 | 理由 |
|---|---|
| 面接官の予定を担当者が勝手に動かさない | 枠は預かるもので、面接官の予定を担当者が決めるものではない |
| 候補者の連絡先を手元に残さない | 媒体のメッセージか、依頼側のシステムで連絡する。私用の連絡先で受けない |
| 面談の内容や評価に踏み込まない | 日程調整の範囲で受けたなら、面談の中身は依頼側のもの |
| 候補者に「合格の見込み」を言わない | 日程を早めるために期待を持たせない |

候補者の連絡先を扱う場合は、依頼側の決まりに従います。個人情報の扱いに法令が関わる場合は、個別の判断は専門家にご確認ください。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 面接官が枠を出さない | 「返事待ちの日数が候補者が流れる原因」と構造で説明し、まず一枠から |
| 候補が全部合わない | 「曜日と時間帯を二つ」を先に聞いておく。候補を出すときに散らす |
| 確定の連絡が翌日以降になる | 確定は即日と決め、返信を見る時間を固定する |
| 面接官が複数で決まらない | 段階ごとに人数を絞る提案。「誰か一人が入れば実施」 |
| 当日に候補者がつながらない | 確定の連絡に接続先と連絡先を入れる型に。前日のリマインド |
| 候補者が日程の変更を繰り返す | 一度は受け、二度目は「次の候補で確定できなければ、改めてご連絡ください」と期限を置く。判断は依頼側 |

## まとめ

- 遅いのは候補者ではなく、**往復の回数と社内で止まる日数**
- 四つの原則：**先に枠を預かる・候補を三つ以上・一往復で決める・確定を即日**。最も効くのは枠を預かること
- 枠は**数で預かり、埋まらなかった枠の扱いも決め、共有の場所に置く**
- 候補者への提示は**形・候補三つ以上・選び方・期限**の四行
- 確定後は**即日の確定連絡・面接官への連絡・前日のリマインド・当日の連絡先**
- **往復の回数・止まった日数・来なかった数**を記録し、月に一度、枠と人数の見直しを提案
- 面接官の予定を勝手に動かさない、連絡先を手元に残さない、見込みを言わない。個別の判断は専門家にご確認ください

## よくある質問

### 日程調整のツールを使えば速くなりますか

ツールは「候補を出す」と「確定を返す」を自動にしますが、「枠を預かる」は自動になりません。面接官が枠をツールに入れなければ、ツールは空のままです。ツールの導入より先に、枠を預かる合意を取ります。合意ができていれば、ツールは往復を減らす助けになります。ツールの選び方と費用は依頼側の判断で、担当者は「枠を預かれているか」を先に確かめます。

### 候補者が「来週以降なら」と言い、枠が今週しかありません

翌週の枠を面接官からもらいに行きます。ここで「今週の枠しかありません」と返すと、候補者は他社に行きます。枠を預かる合意に「候補者の希望に合わせて翌週の枠を追加でもらえる」を含めておくと、この場面で止まりません。追加の枠が出ないなら、依頼側に「この候補者は翌週以降の希望です。枠が出なければ流れます」と、判断を渡します。

### 副業の稼働で、確定を即日返せない日があります

返せない日を先に依頼側に伝え、その日の確定は依頼側の窓口が返す形にします。確定の文面の型を共有の場所に置いておけば、依頼側でも返せます。「即日」は担当者一人で守るものではなく、依頼側と分担して守るものです。連絡の速さの担保は[連絡の速さをどう担保するか](/media/fukugyo-renraku-sokudo/)に書いています。
