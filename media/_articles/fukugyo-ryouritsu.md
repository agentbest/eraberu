副業を始めて数か月、本業が忙しくなり、副業の締め切りが迫り、家族には「またか」と言われ、寝不足で本業のミスが増えた。両立ができていない。時間が足りないのか、副業が向いていないのか。結論を先に書くと、**本業と副業の両立が崩れる原因は、「時間が足りない」ではなく、「枠が固定されていない」「本業の時間に副業が侵入している」「休みがない」「家族と共有していない」「崩れたときの止め方がない」の五つです。時間が多くても、五つのどれかが欠けていれば崩れ、時間が少なくても、五つが設計されていれば続きます。両立は、時間の量ではなく、設計で決まります。五つを一つずつ設計すれば、両立は続きます。**時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、長く続ける設計は[長く続けるための設計](/media/fukugyo-choki/)に、本業への影響は[本業のパフォーマンスへの影響](/media/fukugyo-honngyou-eikyou/)にまとめています。

## 崩れる五つの原因

両立が崩れる原因は、五つに分かれます。どれも「時間が足りない」に見えますが、正体は違います。

| 原因 | 見え方 | 正体 | 詳しく |
|---|---|---|---|
| 一、枠が固定されていない | 「時間がない」 | 「空いた時間でやる」形で、空いた時間が来ない。稼働の枠を曜日と時刻で固定していない | [本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/) |
| 二、本業の時間に副業が侵入している | 「本業が忙しくて副業ができない」 | 本業の時間に副業の連絡を見て、本業の集中が切れ、本業が遅れ、副業の時間が減る | [平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/) |
| 三、休みがない | 「疲れて続かない」 | 本業の外の時間が全部副業になり、頭が切り替わる日がない | [休む設計](/media/fukugyo-yasumi/) |
| 四、家族と共有していない | 「家族に反対される」 | 枠と目的と負担の埋め方を家族と決めていない。家族から見れば「いつも副業をしている」 | [家族の理解を得る](/media/fukugyo-kazoku/) |
| 五、崩れたときの止め方がない | 「もう無理」 | 本業の繁忙期や家族の事情で崩れたとき、縮小や一時停止の形がなく、消えるか全部やめるかになる | [副業をやめるとき](/media/fukugyo-yameru/) |

五つの要点は、「時間が足りない」という感覚の裏に、多くの場合、五つのどれかがあることです。時間を増やそうとしても、五つが欠けていれば、増やした時間も同じように消えます。「時間が足りない」と感じたら、時間ではなく、五つのどれが欠けているかを見ます。

## 崩れ方の順番

両立は、一度に崩れるのではなく、順番に崩れます。順番を知っておくと、早い段階で止められます。

| 段階 | 何が起きるか | 原因 |
|---|---|---|
| 一、副業の締め切りが迫り、夜遅くまで稼働する | 枠を超えて稼働し、睡眠が削れる | 枠が固定されていない |
| 二、本業の時間に副業の連絡を見始める | 「少しだけ」と本業中に返す。本業の集中が切れる | 本業の時間への侵入 |
| 三、本業の評価に兆候が出る | 締め切りが遅れる、会議で上の空、上司に「大丈夫?」と聞かれる | 侵入と睡眠不足 |
| 四、家族に指摘される | 「またか」「家にいるのに」と言われる | 家族との共有がない、休みがない |
| 五、疲れが抜けず、副業の連絡を開くのが重くなる | 燃え尽きの兆候 | 休みがない |
| 六、「もう無理」と、案件の途中で止める | 依頼側との関係と、戻れる道が消える | 止め方がない |

順番の要点は、「一」の段階で止めれば、それ以降が起きないことです。締め切りに追われて夜遅くまで稼働した週があったら、それが崩れの始まりです。その週に、枠を見直し、依頼側に締め切りの相談をすれば、「二」以降に進みません。「三」の本業の評価に兆候が出た段階では、副業を縮めるしかなくなります。燃え尽きの段階は[燃え尽きを防ぐ](/media/fukugyo-burnout/)に、疲れの見分け方は[疲労とどう付き合うか](/media/fukugyo-tsukare/)に書いています。

### エラベルの見解

担当する側から見ると、両立が崩れて止まる担当者は、稼働が多い人ではありません。週に数時間の稼働でも、枠を固定せず、本業中に連絡を返し、休みがなく、家族に伝えておらず、崩れたときに消えてしまう人が止まっています。逆に、週に十時間の稼働でも、五つを設計している人は何年も続いています。両立できるかどうかは、時間の量とほとんど関係がなく、設計の有無で決まっています。

見ていて差がつくのは、「一」の段階、つまり締め切りに追われて夜遅くまで稼働した週に、それを崩れの始まりとして扱っているかです。続いている人は、その週のうちに枠を見直し、依頼側に締め切りの相談をし、翌週には枠に戻しています。止まる人は、「今週だけ」と流し、翌週も同じことが起き、本業中に連絡を返し始め、気づいたときには本業の評価と家族の関係に響いています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠と稼働しない日を明確にしている担当者が、依頼側との関係でも両立でも安定しています。両立は、時間を作ることではなく、崩れの始まりで止めることです。

## 原因ごとの防ぎ方

五つの原因を、それぞれ防ぐ方法です。

| 原因 | 防ぎ方 | 具体的に |
|---|---|---|
| 一、枠が固定されていない | 稼働の枠を曜日と時刻で固定し、その中で受ける | 「火・木の夜二時間、土曜の朝二時間」。枠を超える案件は受けない。[週何時間から受けられるか](/media/fukugyo-kadou-jikan/) |
| 二、本業の時間への侵入 | 本業の時間は副業の端末を開かない。依頼側に「日中は返せない」と伝える | 端末を分け、通知を切る。急ぎの定義と経路を決める。[私物端末で作業してよいか](/media/fukugyo-tanmatsu/) |
| 三、休みがない | 週に一日、副業に触れない日を固定する。年の休みを先に入れる | 案件より先にカレンダーに。依頼側に稼働しない日を伝える。[休む設計](/media/fukugyo-yasumi/) |
| 四、家族と共有していない | 枠と目的と収入の使い道と止める条件と負担の埋め方を、始める前に家族と決める | 枠の外では副業に触れない。月に一度状況を話す。[家族の理解を得る](/media/fukugyo-kazoku/) |
| 五、止め方がない | 一時停止と縮小の形を、始めるときに決めておく | 「本業の繁忙期は稼働を半分に」「家族の事情が変わったら一時停止」。伝え方も決めておく。[副業をやめるとき](/media/fukugyo-yameru/) |

防ぎ方の要点は、「五」の止め方を、始めるときに決めておくことです。本業の繁忙期、家族の事情、体調の変化は、続けていれば何度も起きます。そのときに、一時停止と縮小の形が決まっていれば、消えずに調整でき、事情が戻れば枠を戻せます。決まっていないと、崩れたときに「消える」か「全部やめる」かになり、戻れる道がなくなります。止め方は、両立の最後の砦です。

## 両立が崩れ始めた兆候

崩れは、兆候が出ます。早く気づくための一覧です。

| 兆候 | どの原因か | すぐやること |
|---|---|---|
| 枠を超えて稼働した週があった | 一 | 翌週は枠に戻す。超えた理由（締め切り、範囲）を見る |
| 本業中に副業の連絡を見た | 二 | 端末をかばんに入れる。通知を切る |
| 副業に触れない日が二週間ない | 三 | 今週、一日を空ける |
| 家族に「またか」と言われた | 四 | 枠を見える形にし直す。負担の埋め方を実行する |
| 上司に「大丈夫?」と聞かれた | 二・三 | 副業を縮める。睡眠を確保する |
| 副業の連絡を開くのが重い | 三 | 一週間止める。成果を状態で書き出す |
| 締め切りが重なり、どれかを落としそう | 一 | 依頼側に締め切りの相談を、落とす前にする |
| 「もう無理」と思った | 五 | 縮小か一時停止の形で止める。消えない |

兆候の要点は、「枠を超えて稼働した週があった」が、最初の兆候だということです。他の兆候は、この後に出ます。枠を超えた週に、翌週は枠に戻すと決めていれば、他の兆候は出ません。枠を超えることを「頑張った」と捉えると、崩れの始まりを見逃します。枠を超えた週は、崩れの始まりです。締め切りの相談は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、超過の扱いは[超過稼働の扱い](/media/fukugyo-choka-kadou/)に整理しています。

## 崩れたときの立て直し方

崩れてしまった後の、立て直し方の順番です。

| 順番 | 内容 |
|---|---|
| 一、今の案件を、縮小か一時停止の形で止める | 「来月から稼働を半分に」「〇月まで一時停止」。案件の途中で消えない |
| 二、本業と睡眠と家族を、先に戻す | 副業の設計は後。本業の評価、睡眠、家族との関係を戻す |
| 三、五つのどれが欠けていたかを見る | 枠、侵入、休み、家族、止め方 |
| 四、欠けていたものを設計に足す | 枠の固定、端末の分離、休みの固定、家族との共有、止め方の形 |
| 五、枠を、崩れる前の半分に置いて再開する | 戻れることを確かめてから広げる |
| 六、依頼側に、再開と枠を伝える | 「〇日から、週〇時間で再開します」 |
| 七、再開して一か月、兆候が出ていないかを見る | 出ていれば、枠をさらに小さく |
| 八、三か月続いたら、枠を少しずつ広げる | 広げるたびに五つを確認する |

立て直し方の要点は、「一」で、案件の途中で消えないことです。崩れたときに最も避けるべきは、依頼側に何も言わずに止まることです。縮小か一時停止の形で伝え、案件は区切りまで終えるか、引き継ぎを残します。これで、戻れる道が残ります。「二」の本業と睡眠と家族を先に戻すのは、副業の設計を考える余裕を作るためです。崩れた状態で設計を考えても、極端な判断に寄ります。止め方は[副業をやめるとき](/media/fukugyo-yameru/)に、再開は[燃え尽きを防ぐ](/media/fukugyo-burnout/)の戻り方に書いています。

## 両立を設計する順番

これから始める人も、続けている人も、両立を設計する順番です。

| 順番 | 内容 | 詳しく |
|---|---|---|
| 一、家族と、枠と目的と止める条件を決める | 始める前に。家族が「崩れている」と言える形に | [家族の理解を得る](/media/fukugyo-kazoku/) |
| 二、休みを先にカレンダーに入れる | 週に一日、年に数回 | [休む設計](/media/fukugyo-yasumi/) |
| 三、稼働の枠を曜日と時刻で固定する | 休みを引いた残りで | [本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/) |
| 四、本業の時間に副業が入らない仕組みを作る | 端末を分ける、通知を切る、依頼側に「日中は返せない」と伝える | [平日日中の連絡にどう対応するか](/media/fukugyo-heijitsu-taiou/) |
| 五、止め方を決める | 一時停止と縮小の形と、伝え方 | [副業をやめるとき](/media/fukugyo-yameru/) |
| 六、枠の中で終わる案件だけを受ける | 範囲と稼働を契約に入れる | [業務範囲を書面で固める](/media/fukugyo-scope/) |
| 七、稼働の中の順番と、タスクの一枚を決める | 細切れの稼働で前回の続きから動ける形に | [時間配分の決め方](/media/fukugyo-jikan-haibun/)・[タスク管理のしかた](/media/fukugyo-tasuku-kanri/) |
| 八、月に一度、五つと兆候を確認する | 枠を超えた週、本業中の連絡、休み、家族の言葉、やめたいと思った回数 | [長く続けるための設計](/media/fukugyo-choki/) |

順番の要点は、「一」の家族との共有を、案件を受ける前にやることです。家族と枠を決めずに案件を受けると、家族の予定と重なり、家族が「いつも副業をしている」と感じ、四つ目の原因が最初から入ります。家族と決めた枠を、依頼側に示す。この順番が、両立の土台です。

### エラベルの見解

相談で最も多い思い込みは、「両立できないのは、時間が足りないからだ」というものです。実際には、時間が足りないと感じている人の多くは、枠を固定していないか、本業の時間に副業が入っているか、休みがないか、家族と共有していないか、止め方がないかのどれかで、時間を増やしても同じことが起きています。逆に、五つを設計している人は、週に数時間でも両立が続いています。両立は、時間の量ではなく、設計です。

順番として、家族と枠と目的と止める条件を決め、休みを先に入れ、稼働の枠を固定し、本業の時間に副業が入らない仕組みを作り、止め方を決め、枠の中で終わる案件だけを受け、稼働の中の順番とタスクの一枚を決め、月に一度五つと兆候を確認する。この順番で、両立は「時間を捻出して頑張るもの」から「設計の中で回るもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠と稼働しない日と連絡の時間帯を明確にしている担当者が、両立でも依頼側との関係でも安定しています。両立が崩れる原因は五つで、五つは全部、設計できます。

## まとめ

- 両立が崩れる原因は**時間ではなく、枠の固定・本業の時間への侵入・休み・家族との共有・止め方の五つ**の欠け
- 崩れる順番は**枠を超えた週 → 本業中の連絡 → 本業の評価 → 家族の指摘 → 燃え尽き → 途中で消える**。最初の段階で止める
- **枠を超えて稼働した週は崩れの始まり**。「頑張った」と捉えず、翌週は枠に戻す
- 止め方は**始めるときに決めておく**。一時停止と縮小の形があれば、崩れても消えずに戻れる
- 崩れたら**案件の途中で消えず、縮小か一時停止で止め、本業と睡眠と家族を先に戻し、枠を半分にして再開**
- 設計の順番は**家族との共有 → 休み → 枠 → 侵入を防ぐ仕組み → 止め方 → 枠の中の案件 → 稼働の順番 → 月に一度の確認**

## よくある質問

### 本業が繁忙期に入り、副業の枠が全く取れません。両立が崩れていますか

繁忙期に枠が取れないことは、崩れではなく、止め方を使う場面です。「本業の繁忙期は稼働を半分にする」「〇月は一時停止する」と、始めるときに決めておいた形で、依頼側に一か月前に伝えます。繁忙期の時期が分かっているなら、年の初めに依頼側に伝えておきます。崩れるのは、繁忙期に枠を変えずに、夜遅くまで稼働して本業と睡眠を削るときです。繁忙期は、枠を縮めるのが正しい対応です。伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

### 両立のために、副業の稼働を減らしたら、収入が減って意味がなくなります

両立が崩れて副業を止めると、収入はゼロになります。稼働を減らして続ける方が、長期の収入は多くなります。また、稼働を減らしても、稼働の中の順番（催促、作業、記録、返信）を固定すれば、同じ稼働で出る成果は増え、単価の見直しの根拠になります。収入は、稼働の量ではなく、稼働の質と継続で決まります。時間配分は[時間配分の決め方](/media/fukugyo-jikan-haibun/)に、収入の見立ては[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に書いています。

### 五つ全部を設計するのは大変です。一つだけやるなら、どれですか

「休みを先にカレンダーに入れる」です。週に一日、副業に触れない日を固定するだけで、疲れが溜まらず、本業の時間に副業が入る誘惑が減り、家族もその日を家族の時間として見られ、崩れの兆候に気づく余裕ができます。休みが一日あれば、他の四つを考える時間も生まれます。休みがない状態で他の四つを設計しようとしても、疲れていて設計ができません。休みの入れ方は[休む設計](/media/fukugyo-yasumi/)に整理しています。
