面接官によって質問が違い、評価もばらばら。「構造化面接を入れるべきだ」と分かっている。ただ、質問の設計、評価の尺度、面接官の訓練、と考えると大きく、手が回らない。結局、今日も面接官が思いついた質問で面接をしている。結論を先に書くと、**構造化面接は、完全な形で入れようとすると入りません。最小の形は、「観点ごとの質問」「通す基準」「記録の型」の三つを一枚にして、面接官に渡すことです。一枚があれば、面接は「面接官の思いつき」から「同じ観点を同じ質問で確認する」に変わります。訓練は、最初の数回の同席で足ります。完全な構造化は、一枚を回してから、少しずつ広げます**。評価基準の作り方は[評価基準が言語化できていない](/media/rpo-hyouka-kijun/)に、面接官のばらつきは[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)にまとめています。

## 構造化面接が入らない理由

「入れたい」のに入らないのは、次の理由です。

| 理由 | 中身 |
|---|---|
| 完全な形を目指している | 質問の体系、尺度、訓練、検証。全部を揃えてから始めようとして、始まらない |
| 設計する時間が無い | 人事が一人、または兼務で、設計に割く時間が取れない |
| 面接官の訓練が大変に見える | 「研修を何時間もやらないと」と思っている |
| 面接官が抵抗する | 「決まった質問では人を見られない」「自分の質問のほうが良い」 |
| 評価基準が言語化されていない | 基準が無いので、質問も記録も作れない |
| 役割が決まっていない | 何を見るかが無いので、構造化のしようがない |
| 「構造化面接」の言葉が大きい | 専門的な手法に見えて、自社には無理だと思っている |

入らない理由の大半は、「大きく見えている」ことです。小さくすれば、入ります。

## 最小の構造化の三つ

構造化面接の最小の形は、三つです。

**一、観点ごとの質問。** 見る観点を三〜四つに絞り、観点ごとに質問を二〜三個。全部の面接官が、同じ質問を使います。「〇〇を設計した場面で、何を、どう決めましたか」「この役割は〇〇を決める役割ですが、ご経験のどこが活きますか」。

**二、通す基準。** 観点ごとに、「通す状態」と「通さない状態」を観察できる言葉で。「自分で設計し、判断した場面を具体的に語れる（通す）／所属した事実は語れるが、自分が何を決めたかを語れない（通さない）」。作り方は[評価基準が言語化できていない](/media/rpo-hyouka-kijun/)に書いています。

**三、記録の型。** 観点ごとに「通す・通さない・判断できず」の三択と、根拠を場面で一〜二行。面接の直後に五分で書ける形。

三つが一枚に収まっていれば、それが最小の構造化面接です。「同じ観点を、同じ質問で確認し、同じ基準で判定し、同じ型で記録する」。これで、面接官の思いつきは消えます。

尺度（五段階の点数など）、質問の順番の厳密な統一、面接官の認定制度、といった要素は、最小の形には含めません。後で足せます。

## 一枚の作り方

三つを一枚にする作り方です。二〜三時間で作れます。

**役割の記述から、観点を三〜四つ取る。** [ジョブディスクリプションがない](/media/rpo-jd-nai/)の一枚の「何ができないと詰まるか」が、観点の元です。役割の記述が無ければ、現場の責任者に「最初の三か月で、これができないと回らないものは」と聞きます。

**観点ごとに、質問を二〜三個作る。** 「〇〇した場面を、具体的に教えてください」の型。過去の具体的な場面を聞く質問（「〇〇のとき、どうしましたか」）が、仮定の質問（「〇〇だったら、どうしますか」）より、確認しやすいです。

**観点ごとに、通す状態と通さない状態を書く。** 過去に通した人と落とした人の違いから。面接官に「何が違ったか」を聞いて作ります。

**記録の型を作る。** 観点×三択の表と、根拠の欄、総合の判定、申し送りの欄。一枚の下半分に。

**段階ごとの担当を書く。** 一次はどの観点、二次はどの観点、最終はどの観点。同じ観点を三回聞かない。

**面接官の一人に、読んでもらう。** 「この質問で、この観点は確認できそうか」「この基準で、判定できそうか」。面接官の言葉で直します。

**一枚に収める。** 表と裏で一枚。二枚以上になったら、観点か質問を減らします。

作り方の要点は、「面接官の言葉で作る」ことです。人事が作った質問を配るより、面接官が「自分が使っている質問」を出し合って揃えるほうが、使われます。

## 面接官への渡し方

一枚を、面接官に渡す方法です。研修は要りません。

| 場面 | 渡し方 |
|---|---|
| 最初の説明 | 三十分。「なぜ一枚か（判定を揃える、記録を残す、候補者に理由を伝える）」「一枚の使い方」「質問は一枚のものを使い、深掘りは自由」 |
| 抵抗への対応 | 「決まった質問では人を見られない」に対して、「観点と質問は揃え、深掘りと会話は自由。見ることを制限するのではなく、何を見るかを揃える」 |
| 面接の前日 | 一枚と、候補者の経歴の要点を、面接官に渡す。面接官向けの一枚 |
| 最初の数回 | 経験のある面接官か、担当者が同席する。面接の後に五分の振り返り。「一枚の観点は確認できたか」「判定に迷った点は」 |
| 記録の確認 | 最初の数回は、記録を担当者が見て、「根拠が場面で書かれているか」を確認。感想になっていれば、型を再確認 |
| 面接官同士の比較 | 同じ候補者を二人で見た回で、判定を比べる。ずれていれば、基準のどこで読みが違ったかを話す |
| 定期の振り返り | 月に一度、三十分。「判断できずが多い観点」「面接官間のずれ」を見て、質問と基準を直す |

渡し方の要点は、「研修ではなく、一枚と同席」です。何時間もの研修より、一枚を持って面接に出て、同席者と五分振り返るほうが、身に付きます。

面接官の抵抗は、「見ることを制限される」という誤解から来ます。「何を見るかを揃えるだけで、どう見るかは自由」と伝えます。

### エラベルの見解

相談で最も多い失敗は、「構造化面接を入れようと、質問の体系と五段階の尺度と面接官の研修を設計し始めて、半年経っても面接は思いつきのまま」というものです。完全な形を目指したので、始まりませんでした。観点三つ、質問六つ、通す基準、記録の型を一枚にして、翌週の面接から使い、最初の三回は担当者が同席したら、一か月で面接官の判定が揃い始めました。完全な構造化は、一枚を回してから足せばよいものでした。

見ていて差がつくのは、担当者が「一枚で始める」提案をできるかどうかです。「構造化面接の設計には時間がかかります」と言う担当者と、「まず、観点三つと質問と基準と記録の一枚を作って、翌週から使いましょう。同席します」と言う担当者がいます。後者は、来週から面接が変わります。

発注側にできるのは、「構造化面接を入れたい」を「一枚を作って、来週から使いたい」と言い換えて依頼することです。

## 最初の一回の回し方

一枚を作ったら、最初の一回をどう回すかです。

**一つの求人で始める。** 全職種に一度に入れず、いま動いている一つの求人で始めます。

**次の面接から使う。** 「準備が整ってから」ではなく、次の面接から。一枚があれば、準備は整っています。

**担当者か経験のある面接官が同席する。** 最初の一回は、一枚を作った人が同席し、面接官が一枚を使えているかを見ます。

**面接の後、五分で振り返る。** 「一枚の質問で、観点は確認できたか」「基準で判定できたか」「記録は五分で書けたか」「使いにくかった点は」。

**使いにくかった点を、その日に直す。** 質問が答えにくい、基準が判定しにくい、記録の欄が足りない。その日のうちに一枚を直します。

**二回目、三回目も同じ。** 三回回せば、一枚は使える形になり、面接官は一枚に慣れます。

**四回目から、同席を外す。** 記録だけを担当者が見て、根拠が場面で書かれていれば、一人で回せています。

最初の一回で完璧を求めません。「使ってみて直す」を三回繰り返せば、一枚は定着します。

## 少しずつ広げる順番

一枚が回り始めたら、広げる順番です。

**一、他の求人に広げる。** 一つの求人で回った一枚の型を、他の求人に。観点と質問と基準は求人ごとに変わりますが、型は同じです。

**二、段階ごとの担当を明確にする。** 一次・二次・最終で、どの観点を誰が見るかを、求人ごとに固定します。

**三、面接官ごとの判定の集計を始める。** 面接官ごとの通過率、段階間の判定の一致、判断できずの多い観点。月に一度見ます。集計の見方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

**四、入社後の実態と照らす。** 通した人の三か月後の到達と、面接の判定を照らし、観点と基準を直します。

**五、必要なら、尺度を入れる。** 三択で足りない場面（候補者が多く、細かい順位が要る）が出たら、観点ごとの尺度を検討します。合計点にはしません。

**六、面接官の育成の型にする。** 新しい面接官には、一枚と最初の数回の同席。「見ていれば分かる」を無くします。

広げる順番の要点は、「一枚が回ってから」です。回る前に広げると、全部が中途半端になります。

## 外注する場合の範囲

構造化面接の導入を、採用代行に出す場合の範囲です。

**出せる工程。** 観点の抽出（役割の記述から、または現場の責任者への聞き取り）、質問の作成、通す基準の文の案（面接官への「何が違ったか」の聞き取りから）、記録の型、一枚の作成、面接官への説明の進行、面接官向けの一枚（候補者ごと）の作成、最初の数回の同席と振り返りの進行、記録の確認、一枚の修正、面接官ごとの判定の集計、入社後との照合の材料、他の求人への展開、新しい面接官への渡し方の型。

**社内に残す判断。** 観点と基準の決定、面接官の指名、段階ごとの担当の決定、判定そのもの、一枚の変更の決定、尺度を入れるかどうかの判断。

**外注の効きどころ。** 構造化面接が入らない会社は、「設計の時間が無い」「面接官の訓練が大変に見える」の二つで止まっています。担当者が一枚を作り、面接官に説明し、最初の数回に同席すれば、二つとも解消します。担当者は面接官の誰でもないので、面接官同士の判定のずれを、対立ではなく材料として扱えます。

**外注しても動かない場合。** 面接官が一枚を使わない、責任者が「自分の面接は変えない」を譲らない、記録を取らない。社内の判断で、代行を替えても直りません。

構造化面接は、一枚と同席で始められます。外注は、一枚を作り、同席する手段です。

### エラベルの見解

担当する側から見ると、構造化面接の相談で最も多いのは、「面接官が『決まった質問では人を見られない』と言う」ことです。この抵抗は、「質問を全部固定され、会話ができなくなる」という誤解から来ています。

一枚は、「何を見るか」と「最初の質問」を揃えるもので、深掘りと会話は自由です。「〇〇した場面を教えてください」の後、面接官がどう掘るかは、面接官の力です。揃えるのは入口だけで、面接官の見る力は、むしろ「何を見るか」が決まっているほうが発揮されます。

発注側にできるのは、面接官に「質問を固定する」ではなく「何を見るかを揃える。深掘りは自由」と伝えることです。

## よくある質問

### 構造化面接を入れるには、どのくらいの準備が要りますか

最小の形（観点ごとの質問・通す基準・記録の型の一枚）なら、二〜三時間で作れ、次の面接から使えます。面接官の訓練は、三十分の説明と、最初の数回の同席と五分の振り返りで足ります。完全な形（質問の体系、尺度、認定制度）を目指すと、半年かかっても始まりません。一枚で始めて、回ってから広げます。

### 面接官が「決まった質問では人を見られない」と言います

「質問を全部固定する」のではなく、「何を見るか（観点）と、最初の質問を揃える。深掘りと会話は自由」と伝えます。一枚は、面接官の見る力を制限するものではなく、「何を見るか」を揃えることで、見る力を観点に集中させるものです。抵抗する面接官には、最初の数回、一枚を使った面接に同席してもらい、「揃えても会話はできる」ことを見てもらいます。

### 五段階の点数を付けたほうがよいですか

最小の形では、観点ごとに「通す・通さない・判断できず」の三択で足ります。五段階の点数は、面接官ごとに「三」の意味が違い、合計点にするとばらつきが足し合わさります。候補者が多く、細かい順位が要る場面が出てから、観点ごとの尺度を検討します。その場合も、合計点にはせず、観点ごとに残します。
