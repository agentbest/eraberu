副業で人事を受けると、まず求人票を見ることになります。そして、だいたい直すところが出てきます。月給に固定残業代が溶け込んでいる、職種名が実際の業務と違う、募集が終わっているのに掲載が残っている。どれも悪意があるわけではなく、前任者の書式を引き継いだままになっているだけです。結論を先に書くと、**職業安定法第5条の4第1項は、広告等により求人や労働者の募集に関する情報を提供するときは「当該情報について虚偽の表示又は誤解を生じさせる表示をしてはならない」と定め、第2項は、労働者の募集を行う者及び募集受託者に対して、募集に関する情報を「正確かつ最新の内容に保たなければならない」と定めています。**これは2022年（令和4年）の改正で整えられた条文です。個別の判断はハローワークや都道府県労働局にご確認ください。求人票の出し方は、採用の他の手続とつながっています。[個人情報保護法と採用実務](/media/fukugyo-law-kojin-jouhou/)、[面接で聞いてはいけないこと](/media/fukugyo-law-shitsumon-ng/)もあわせてご覧ください。

## 第5条の4が定める三つのこと

条文は三項からなります。それぞれ主語が違うので、自社がどれに当たるかを先に確かめます。

**第1項（虚偽・誤解を生じさせる表示の禁止）。**「公共職業安定所、特定地方公共団体及び職業紹介事業者、労働者の募集を行う者及び募集受託者、募集情報等提供事業を行う者並びに労働者供給事業者は、この法律に基づく業務に関して新聞、雑誌その他の刊行物に掲載する広告、文書の掲出又は頒布その他厚生労働省令で定める方法（以下この条において「広告等」という。）により求人若しくは労働者の募集に関する情報…を提供するときは、当該情報について虚偽の表示又は誤解を生じさせる表示をしてはならない」。**自社で募集をかける会社は「労働者の募集を行う者」として、ここに入ります。**

同法施行規則第4条の3第1項は、この「厚生労働省令で定める方法」として、書面の交付、ファクシミリ、電子メール等の送信のほか、放送、有線放送、自動公衆送信装置その他電子計算機と電気通信回線を接続してする方法その他これらに類する方法を挙げています。**自社の採用サイトも、求人媒体も、ここに含まれます。**

**第2項（正確かつ最新に保つ義務）。**「労働者の募集を行う者及び募集受託者は、この法律に基づく業務に関して広告等により労働者の募集に関する情報その他厚生労働省令で定める情報を提供するときは、正確かつ最新の内容に保たなければならない」。**募集をかける会社そのものに向けられた義務です。**

**第3項（正確かつ最新に保つための措置）。**職業紹介事業者、募集情報等提供事業を行う者、労働者供給事業者に対して、厚生労働省令で定めるところにより措置を講ずることを求めています。施行規則第4条の3第4項は、情報の提供の中止や訂正の求めがあったときの遅滞ない対応、正確でない・最新でないことを確認したときの訂正の有無の確認または提供の中止、および事業者の区分に応じた措置を定めています。

## 指針が挙げる「誤解を生じさせる表示」の四つ

指針（平成11年労働省告示第141号）の「求人等に関する情報の的確な表示に関する事項」では、誤解を生じさせることのないよう留意する事項として、次の四つが挙げられています。

- **（一）** 関係会社を有する者が労働者の募集を行う場合、**労働者を雇用する予定の者を明確にし**、当該関係会社と混同されることのないよう表示しなければならないこと
- **（二）** 労働者の募集と、**請負契約による受注者の募集**が混同されることのないよう表示しなければならないこと
- **（三）** 賃金等（賃金形態、基本給、定額的に支払われる手当、通勤手当、昇給、固定残業代等に関する事項）について、**実際の賃金等よりも高額であるかのように表示してはならない**こと
- **（四）** 職種又は業種について、**実際の業務の内容と著しく乖離する名称を用いてはならない**こと

**（三）が一番よく当たります。**月給の表示に固定残業代が含まれているのに、その旨が書かれていない求人票です。指針は、労働条件等の明示の項で、一定時間分の時間外労働・休日労働・深夜労働に対する割増賃金を定額で支払う仕組みを採用する場合は、名称のいかんにかかわらず、固定残業代に係る計算方法（固定残業時間および金額を明らかにするものに限る）、固定残業代を除外した基本給の額、固定残業時間を超える分についての割増賃金を追加で支払うこと等を明示すること、と定めています。**三つセットで書く**のがポイントです。

**（四）も現場でよく起きます。**実態が定型的な事務なのに「マーケティング職」と書く、テレフォンアポイントメントの業務に「コンサルタント」の名称を使う。採用したい気持ちから盛った職種名は、入社後のミスマッチと早期離職に直結します。

**（一）（二）は、グループ企業と業務委託の場面です。**採用の主体が親会社なのか子会社なのか、雇用なのか業務委託なのか。応募者から見て分かる形になっているかを確かめます。

### エラベルの見解

担当する側から見ると、求人票の点検は、案件に入って最初の一週間でできる仕事のうち、もっとも成果が見えやすいものです。条文と指針に照らして直すべき箇所が、たいてい三つか四つは出ます。しかも、直すのに稟議も予算も要りません。信用をつくる最初の一手として、これ以上効率のよい作業はあまりありません。

ただし、伝え方は選びます。「これは法令違反の可能性があります」と切り出すと、採用担当は身構えます。実務で通りやすいのは、応募者の視点に翻訳することです。固定残業代の話なら「この書き方だと、内定を出した後で『聞いていた金額と違う』と言われます」。職種名の話なら「入社三か月で辞めた人の理由、たぶんここです」。会社が損をする話にすると、直す判断が早くなります。条文は、直すと決まったあとの根拠として出します。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、こうした入り方ができる人は、短い案件でも次につながります。

## 求人票の点検と、掲載後の運用

副業の人事が作るのは、次の形です。個別の適否の判断はハローワークや都道府県労働局にご確認ください。

職業安定法第5条の3第1項は、労働者の募集を行う者等に対し、従事すべき業務の内容及び賃金、労働時間その他の労働条件を明示しなければならないと定めています。同法施行規則第4条の2第3項は、明示すべき事項として次を挙げています。

| 号 | 明示事項 |
|---|---|
| 一 | 労働者が従事すべき業務の内容に関する事項（**従事すべき業務の内容の変更の範囲**を含む） |
| 二 | 労働契約の期間に関する事項 |
| 二の二 | 試みの使用期間に関する事項 |
| 二の三 | 有期労働契約を更新する場合の基準に関する事項（通算契約期間または更新回数の上限の定めがある場合は当該上限を含む） |
| 三 | 就業の場所に関する事項（**就業の場所の変更の範囲**を含む） |
| 四 | 始業及び終業の時刻、所定労働時間を超える労働の有無、休憩時間及び休日に関する事項 |
| 五 | 賃金（臨時に支払われる賃金、賞与等を除く）の額に関する事項 |
| 六 | 健康保険・厚生年金・労災保険・雇用保険の適用に関する事項 |
| 七 | 労働者を雇用しようとする者の氏名又は名称に関する事項 |
| 八 | 労働者を派遣労働者として雇用しようとする旨（派遣労働者として雇用しようとする場合に限る） |
| 九 | 就業の場所における**受動喫煙を防止するための措置**に関する事項 |

**「変更の範囲」が入っています。**業務の内容と就業の場所について、変更の範囲まで明示することとされています。転勤や職種変更の可能性がある会社は、ここを書き足す作業が要ります。転勤の扱いは、募集の要件としても意味を持つので、[性別による募集差別の禁止](/media/fukugyo-law-seibetsu/)もあわせてご覧ください。

**掲載した後の運用も条文にあります。**指針は、法第5条の4第2項に基づき労働者の募集に関する情報を正確かつ最新の内容に保つに当たって、次の措置を講ずる等適切に対応しなければならないとしています。

- **（一）** 募集を終了した場合または内容を変更した場合には、当該募集に関する情報の提供を**速やかに終了し、又は速やかに変更する**とともに、情報の提供を依頼した募集情報等提供事業を行う者に対して、提供の終了または内容の変更を依頼すること
- **（二）** 募集に関する情報を提供するに当たっては、**当該情報の時点を明らかにすること**
- **（三）** 募集情報等提供事業を行う者から情報の訂正または変更を依頼された場合には、**速やかに対応すること**

**媒体に依頼するところまでが義務の形です。**自社サイトの掲載を止めただけでは足りません。掲載を依頼している媒体にも、終了や変更を伝えます。求人媒体を複数使っている会社では、ここが抜けます。掲載中の媒体を一覧にして、募集終了時に一斉に連絡する運用にします。

**指針は、明示の内容を変更したときの扱いも定めています。**第一項明示を変更・特定・削除・追加した場合は、求人票等の内容を検証し、修正等を行うべきである、とされています。また、第一項明示は「そのまま労働契約の内容となることが期待されているものである」とし、安易に変更・削除・追加してはならないこと、学校卒業見込者等については特に配慮が必要であり、変更・削除・追加は不適切であること、とされています。

### エラベルの見解

外に出してよいのは、求人票の点検表、明示事項の一覧との突き合わせ、固定残業代の書き方の型、掲載媒体の一覧と募集終了時の連絡手順、変更があったときの検証の流れまでで、「この表示が虚偽または誤解を生じさせる表示に当たるか」といった個別の判断は、ハローワークや都道府県労働局の範囲です。

担当する側から見ると、求人票の仕事の本体は、条文との突き合わせではなく、**書けない会社に書かせること**です。「業務の内容の変更の範囲」を書こうとすると、会社は自分が何を約束しているのか分からなくなります。就業の場所の変更の範囲を書こうとすると、転勤があるのかないのか、実際には誰も決めていないことが分かります。ここで手が止まる会社は多い。でも、止まったこと自体が発見です。求人票は、会社が自分の雇用の形を言語化する場所で、書けないなら決まっていないということです。決めるところまで伴走できるかどうかが、この案件の価値を分けます。エラベルでは、依頼側が担当者を選べるので、求人票から人事制度の整理まで持っていった経験は、経歴に書いておくと効きます。

## まとめ

- 職業安定法第5条の4第1項は、広告等による求人情報の提供について「**虚偽の表示又は誤解を生じさせる表示をしてはならない**」と定めている
- 第2項は、労働者の募集を行う者及び募集受託者に対し、募集に関する情報を「**正確かつ最新の内容に保たなければならない**」と定めている
- 指針が挙げる留意事項は、**雇用予定者の明確化／労働者募集と請負受注者募集の区別／実際より高額に見える賃金表示の禁止／実際の業務と著しく乖離する職種名の禁止**の四つ
- **固定残業代**は、計算方法（時間数と金額）、除外した基本給の額、超過分の追加支払いの三つを明示する
- 施行規則第4条の2第3項の明示事項には、**業務の内容の変更の範囲**、**就業の場所の変更の範囲**、**受動喫煙を防止するための措置**が入っている
- 募集終了・内容変更のときは、**自社の掲載を止めるだけでなく、媒体にも終了・変更を依頼する**。個別の判断はハローワークや労働局にご確認ください

## よくある質問

### 月給に固定残業代が含まれている求人票は、どう直しますか

指針（平成11年労働省告示第141号）は、一定時間分の時間外労働、休日労働及び深夜労働に対する割増賃金を定額で支払うこととする労働契約を締結する仕組みを採用する場合は、名称のいかんにかかわらず、固定残業代に係る計算方法（固定残業時間および金額を明らかにするものに限る）、固定残業代を除外した基本給の額、固定残業時間を超える時間外労働等についての割増賃金を追加で支払うこと等を明示すること、と定めています。また、賃金等について実際の賃金等よりも高額であるかのように表示してはならない、ともされています。したがって、三つをセットで書く形に直します。記載内容の個別の適否は、ハローワークや都道府県労働局にご確認ください。

### 募集が終わった求人が媒体に残っています

指針は、法第5条の4第2項に基づき募集に関する情報を正確かつ最新の内容に保つに当たって、募集を終了した場合または内容を変更した場合には、当該募集に関する情報の提供を速やかに終了し、または速やかに変更するとともに、情報の提供を依頼した募集情報等提供事業を行う者に対して提供の終了または内容の変更を依頼すること、としています。自社での掲載停止に加えて、媒体への依頼までが求められる形です。実務では、掲載中の媒体の一覧を作り、募集終了のタイミングで一斉に連絡する運用にします。

### 職種名を工夫して応募を増やしたいと言われました

指針は、職種又は業種について、実際の業務の内容と著しく乖離する名称を用いてはならないこと、としています。応募を増やす目的で実態と違う名称を使うのは、この留意事項から外れます。実務では、名称を変えるのではなく、業務の内容の記述を具体的にする方向で作り直します。指針は、労働条件等の明示について、求職者等に具体的に理解されるものとなるよう内容等の水準・範囲等を可能な限り限定すること、業務の内容に関しては職場環境を含め可能な限り具体的かつ詳細に明示すること、とも定めています。個別の表現の適否は、ハローワークや都道府県労働局にご確認ください。
