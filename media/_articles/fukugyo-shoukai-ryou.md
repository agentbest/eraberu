副業を続けている人は、「案件は紹介で回っている」と言う。自分もそうなりたいが、紹介はどこから来るのか、いつから回り始めるのか、何をすれば紹介が来るのかが分からない。結論を先に書くと、**紹介で仕事が回り始めるのは、「登録先や公募で受けた案件を丁寧に終え、終了時に一言添え、自分の範囲を一言で言える相手が数人できた後」です。紹介は最初から来るものではなく、自分で取った最初の数件を丁寧に終えた結果として来ます。段階は三つあり、「自分で取る時期」「終了時の一言と再依頼が出る時期」「紹介が紹介を生む時期」の順です。最初の時期に紹介を待っていると、何も始まりません。最初の数件は自分で取り、紹介は結果として来る。この順番を押さえると、紹介で回る状態に近づけます。**紹介の頼み方は[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/)に、ネットワークの作り方は[人事のネットワークの作り方](/media/fukugyo-nettowaku/)に、声がかかる状態は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)にまとめています。

## 紹介が回り始めるまでの三つの段階

紹介で仕事が回る状態は、一度に来るものではなく、三つの段階を経ます。

| 段階 | 状態 | 案件の入口 | この段階でやること |
|---|---|---|---|
| 一、自分で取る時期 | 副業を始めて、最初の数件を受けるまで | 登録先、公募、知人への声かけ | 範囲を一言にし、登録先と公募で受ける。案件の中で記録と型を残し、言った通りに動く |
| 二、再依頼と終了時の一言の時期 | 最初の数件を終え、依頼側の担当者に「次も」と言われ始める | 以前の依頼側の再依頼、終了時に添えた一言からの声かけ | 終了時に「次に手が要るときは〇〇の範囲で」と添える。範囲を伝えた相手の一覧を持つ |
| 三、紹介が紹介を生む時期 | 以前の依頼側の担当者や社内の人が、別の会社や別の部署に自分を紹介し始める | 紹介、紹介先からの再依頼、同じ立場の人からの案件の回し合い | 紹介で受けた案件も、同じ丁寧さで終える。紹介元に結果を一言報告する |

段階の要点は、「二」が来るまでは、「一」を丁寧にやるしかないことです。紹介は、自分の動き方を実際に見た人が、他の人に伝えることで生まれます。実際に見た人がいない「一」の時期には、紹介は来ません。「一」で受けた案件を丁寧に終え、終了時に一言添えることで、「二」が始まり、「二」の相手が別の場所に移ったり、別の会社の人事に聞かれたりして、「三」が始まります。最初の案件の取り方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、最初の案件の進め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に書いています。

## 最初の数件を自分で取る理由

「紹介で回るようになりたい」と思う人ほど、最初の数件を自分で取ることを避けます。自分で取る理由を見ます。

| 紹介を待つと | 自分で取ると |
|---|---|
| 自分の動き方を見た人がいないので、紹介が生まれない | 案件の中で動き方を見た人（担当者、社内の人）ができる |
| 副業が始まらず、範囲を確かめる機会がない | 案件の中で、自分の範囲と得意な工程が確かめられる |
| 知人に頼む形になり、知人の関係に負担がかかる | 登録先と公募なら、関係に負担がかからない |
| 案件の実績がなく、紹介されても相手が判断できない | 「〇〇の範囲で数件受けた」と言える |
| 紹介が来るまでの間、何もしていない状態が続く | 案件が動いている間に、次の入口ができる |

理由の要点は、「紹介は、自分の動き方を見た人が生む」ことです。見た人を作るには、案件を受けるしかなく、最初の案件は、紹介ではなく登録先か公募で取ります。登録先は、依頼側が担当者を選ぶ仕組みなので、範囲と条件を登録しておけば、自分で探しに行かなくても、最初の案件の入口になります。エラベルもその一つです。

### エラベルの見解

担当する側から見ると、紹介で回っている担当者と、紹介が来ない担当者の差は、範囲の広さや経験の長さではなく、「最初の数件を丁寧に終えたか」と「終了時に一言添えたか」の二つです。丁寧に終えた案件の担当者は、依頼側の担当者に「前に頼んだ人」として残り、担当者が別の会社に移ったとき、社内の別の部署で採用が始まったとき、業界の知り合いに「誰かいないか」と聞かれたときに、名前が挙がっています。

見ていて差がつくのは、紹介で受けた案件を、紹介元への報告で締めているかです。紹介で受けた案件を終えたとき、紹介元に「〇〇さんのご紹介の案件、無事に終わりました。ありがとうございました」と一言報告している人は、紹介元が「紹介してよかった」と感じ、次も紹介します。報告していない人は、紹介元が結果を知らないままになり、次の紹介がためらわれます。紹介は、紹介元の信用を借りる行為なので、結果を返すことで、次の紹介につながります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、丁寧に終えた案件の担当者が、依頼側の担当者の移動先で選び直されることがあり、これが紹介と同じ働きをしています。

## 紹介が生まれる場面

紹介は、どの場面で生まれるかを知っておくと、その場面に備えられます。

| 場面 | 何が起きるか | 備え |
|---|---|---|
| 以前の依頼側の担当者が、別の会社に移った | 移った先で採用が始まり、「前に頼んだ人」を思い出す | 終了時の一言と、連絡の経路（副業用のメール、登録先のプロフィール） |
| 以前の依頼側の社内で、別の部署の採用が始まった | 担当者が「前に外部の〇〇さんに頼んだ」と社内に伝える | 案件の中で、担当者を通して社内に丁寧に動いた実績 |
| 依頼側の担当者が、業界の知り合いに「誰かいないか」と聞かれた | 「〇〇の範囲なら△△さん」と名前が挙がる | 範囲の一言が、担当者の頭に残っている |
| 同じ立場の人が、自分の範囲に合わない案件を受けた | 「この範囲は△△さんが得意」と回してくる | 同じ立場の人に、範囲を伝えている。[同じ立場の仲間を作る](/media/fukugyo-nakama/) |
| 登録先の窓口が、依頼側に担当者を提案する | 過去の案件の記録と評価から、範囲が合う担当者を提案する | 登録先での過去の案件を丁寧に終えている。[紹介につなげる](/media/fukugyo-shoukai-renkei/) |
| 地域や業界の人事の集まりで、採用の相談が出た | 「〇〇地域の採用なら△△さん」と名前が挙がる | 集まりで範囲を伝え、翌日に一言送っている。[人事のネットワークの作り方](/media/fukugyo-nettowaku/) |

場面の要点は、紹介が生まれる場面のほとんどが「自分がいない場所」で起きることです。依頼側の担当者が別の会社で思い出す、社内で名前を挙げる、知り合いに聞かれて答える。どれも、自分はその場にいません。自分がいない場所で名前が挙がるには、相手の頭の中に「範囲の一言」と「頼んでよかった記憶」が残っていることが条件です。その二つを残す作業が、案件を丁寧に終えることと、終了時の一言です。終了時の作業は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に整理しています。

## 紹介が来ない原因の切り分け

数件は終えたのに、紹介が来ない。原因は、いくつかに分かれます。

| 原因 | 見分け方 | 直し方 |
|---|---|---|
| 終了時に一言添えていない | 案件が終わったとき、「次に手が要るときは」と伝えたか | 以前の依頼側の担当者に、近況として一言送る。「〇〇の範囲を続けています」 |
| 範囲が伝わっていない | 依頼側の担当者が、自分を「〇〇の人」と一言で言えるか | 範囲を一言にし、終了時と発信で伝える。[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/) |
| 案件の終わり方が悪かった | 終了時に、記録と型を依頼側に残したか。途中で止めたことがあるか | 次の案件を丁寧に終える。過去の案件の担当者に、区切りの挨拶を送る |
| 連絡の経路がない | 依頼側の担当者が、自分に連絡する手段を持っているか | 副業用のメールと登録先のプロフィールを伝える。[メールの書き方と運用](/media/fukugyo-mail/) |
| 受けられる条件が伝わっていない | 担当者が「今は忙しそう」「もう副業をやめたかも」と思っていないか | 稼働の状況と、いつから受けられるかを近況で伝える |
| まだ時期が来ていない | 終えた案件が一、二件で、担当者の移動や別の採用が起きていない | 待ちながら、登録先と公募で次の案件を取る。紹介は結果として来る |

切り分けの要点は、「まだ時期が来ていない」を最初に疑うことです。紹介は、依頼側の担当者の移動や、別の採用の発生という、自分では動かせない出来事で生まれます。終えた案件が一、二件なら、まだ出来事が起きていないだけで、直すことは何もありません。待つ間に、登録先と公募で次の案件を取り、丁寧に終える。それが、紹介が生まれる可能性を増やす唯一の方法です。案件が続かない原因の切り分けは[案件が続かない原因の切り分け](/media/fukugyo-tsuzukanai/)に書いています。

## 紹介で受けるときの条件の整え方

紹介で受ける案件は、紹介元の顔があるので、条件を曖昧にしがちです。紹介だからこそ、条件を整えます。

| 整えること | 内容 | 曖昧にすると |
|---|---|---|
| 範囲を書面で決める | 紹介元から聞いた話と、依頼側の期待が違うことがある。依頼側と直接、範囲を書面で決める | 紹介元の顔を立てて、範囲外を受け続ける。[知人紹介で受けるときの注意](/media/fukugyo-shoukai/) |
| 単価と条件は依頼側と決める | 紹介元を通さず、依頼側と直接。紹介元が「安くしてあげて」と言っても、自分の条件で | 紹介元の関係に引きずられて、条件が下がる |
| 紹介元に依頼側の情報を流さない | 紹介元が「どうなった?」と聞いても、依頼側の中身は話さない。「無事に進んでいます」まで | 依頼側の情報が紹介元に流れ、守秘の線を越える |
| 断るときは紹介元に先に伝える | 範囲や条件が合わず断るときは、依頼側に断る前に、紹介元に「合わなかったので辞退する」と伝える | 紹介元が依頼側から先に聞き、面目を失う |
| 終わったら紹介元に一言報告する | 「無事に終わりました。ありがとうございました」。中身は話さない | 紹介元が結果を知らず、次の紹介をためらう |
| 窓口があるなら窓口を通す | 登録先の依頼側を紹介されたときは、窓口を通して契約する。直接契約は登録先の規約に反することがある | 規約違反と、登録先との関係の悪化。[直接契約の誘いを受けたら](/media/fukugyo-chokusetsu/) |

整え方の要点は、「範囲と条件は、紹介元を通さず、依頼側と直接決める」ことです。紹介元は、案件の入口を作ってくれた人であって、契約の当事者ではありません。紹介元の顔を立てて条件を曖昧にすると、範囲外を受け続ける、単価が下がる、といった形で自分に返ってきます。紹介元には「入口をありがとう」と「終わりました」だけを返し、中身は依頼側と決めます。契約の決め方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に、範囲の線は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

## 紹介に頼りすぎない配分

紹介で回り始めると、登録先や公募をやめたくなりますが、配分を残します。

| 配分 | 理由 |
|---|---|
| 紹介と再依頼を軸にし、登録先を残す | 紹介は、依頼側の担当者の移動など、自分で動かせない出来事に依存する。途切れる時期がある |
| 登録先のプロフィールを更新し続ける | 紹介が途切れた時期に、登録先が入口になる。更新が止まると、提案されなくなる |
| 紹介で受ける案件も、範囲で選ぶ | 紹介だから受ける、ではなく、範囲と条件が合うから受ける。合わなければ断る |
| 紹介元が一人に偏らないようにする | 一人の紹介元に依存すると、その人との関係が変わったとき、案件が全部止まる |
| 同じ立場の人に案件を回す | 受ける一方では、回し合いが続かない。範囲に合わない案件は、仲間に回す |
| 紹介の状況を月に一度見る | 紹介の入口が何本あり、どこから来ているかを見て、偏りがあれば登録先と公募を増やす |

配分の要点は、「紹介は途切れる時期がある」ことを前提に、登録先を残すことです。紹介は、相手の出来事で生まれるので、自分では時期を選べません。紹介が続いている時期に登録先をやめると、途切れた時期に入口がなくなります。登録先のプロフィールと条件を更新し続け、紹介と登録先の二本を持つ形が、副業を続けるうえで安定します。複数の入口の持ち方は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、単価と稼働の関係は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「紹介で回るようになるには、人脈が要る」というものです。実際には、紹介で回っている担当者の人脈は広くなく、以前の依頼側の担当者が数人と、同じ立場の人が数人です。その数人が、案件の中で動き方を見ていて、範囲を一言で言え、終了時の一言を覚えている。それだけで、紹介は回ります。人脈を広げに行くより、目の前の案件を丁寧に終えることが、紹介への最短の道です。

順番として、範囲を一言にし、登録先と公募で最初の数件を取り、案件の中で言った通りに動いて記録と型を残し、終了時に「次に手が要るときは〇〇の範囲で」と添え、連絡の経路を残し、紹介が来たら範囲と条件を依頼側と直接決め、紹介元には入口の礼と終了の報告だけを返し、紹介が回り始めても登録先を残す。この順番で、紹介は「待つもの」から「結果として来るもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、丁寧に終えた案件が、次の案件の入口として働きます。紹介で回る状態は、人脈ではなく、終え方で作られます。

## まとめ

- 紹介が回り始めるのは**登録先や公募で受けた案件を丁寧に終え、終了時に一言添え、範囲を一言で言える相手が数人できた後**
- 段階は**自分で取る時期 → 再依頼と終了時の一言の時期 → 紹介が紹介を生む時期**。最初の数件は自分で取る
- 紹介は**自分がいない場所**で生まれる。相手の頭に「範囲の一言」と「頼んでよかった記憶」を残す
- 紹介が来ないときは**まだ時期が来ていない**を最初に疑い、待つ間に登録先と公募で次を取る
- 紹介で受けるときも**範囲と条件は依頼側と直接決め、紹介元には入口の礼と終了の報告だけ**を返す
- 紹介は途切れる時期があるので**登録先を残し、紹介元を一人に偏らせない**

## よくある質問

### 副業を始めたばかりで、知人に「案件があったら紹介して」と頼んでもよいですか

頼んで構いませんが、「案件があったら」という漠然とした頼み方では、知人は何を紹介すればよいか分かりません。「〇〇の範囲を、週に数時間で受けている。採用で手が足りない話があれば、教えてほしい」と、範囲と条件を一言で伝えます。それでも、始めたばかりでは動き方を見た人がいないので、紹介は来にくいです。知人への声かけと並行して、登録先と公募で最初の案件を取り、丁寧に終えることが先です。頼み方は[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/)に整理しています。

### 紹介で受けた案件の単価が、紹介元の関係で下げられそうです

紹介元が「知り合いだから安くしてあげて」と言っても、単価は依頼側と自分で決めるものです。「ご紹介ありがとうございます。条件は〇〇さんと直接決めさせてください」と紹介元に伝え、依頼側とは自分の単価で話します。依頼側が単価を下げたいなら、範囲を狭めることで応じます。紹介元の顔を立てて単価を下げると、その単価が続き、他の案件との差で自分が苦しくなります。単価の下げ方の考え方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。

### 紹介元に、案件がどうなったか詳しく聞かれます

「無事に進んでいます」「無事に終わりました。ありがとうございました」までで、依頼側の採用の中身、候補者、条件は話しません。紹介元が依頼側と近い関係でも、依頼側の情報を自分から流す形は、守秘の線を越えます。「中身は依頼側との約束で話せませんが、ご紹介のおかげで助かりました」と伝えれば、紹介元は納得します。守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に整理しています。
