副業を始めるとき、依頼側とどんな契約を結ぶのか。本業は雇用契約だが、副業も雇用になるのか。契約書は依頼側が用意するのか、自分で作るのか。何を見ればよいのかが分からない。結論を先に書くと、**人事の副業の多くは「業務委託」の契約で、雇用ではありません。契約書は依頼側か窓口が用意することが多く、自分で作る場面は少ないですが、読んで確認するのは自分です。見るのは「範囲」「期間」「報酬と支払い」「秘密保持」「再委託」「終了」の六つの条項で、分からない条項は結ぶ前に聞きます。**口約束で始めることは避け、簡単でも文面を残します。契約の期間の考え方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に、請求と契約の分担は[請求や契約は自分でやるのか](/media/fukugyo-qa-15/)に、条件の合意の仕方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)にまとめています。契約の解釈は、弁護士などの専門家にご確認ください。

## 副業の契約の形

副業の契約は、いくつかの形があります。人事の副業で多いのは業務委託です。

| 形 | 内容 | 人事の副業での多さ |
|---|---|---|
| 業務委託 | 依頼側から業務を受け、自分の裁量で進め、成果か業務の遂行に対して報酬を受ける。一般に、雇用のような指揮命令の関係ではないと整理されている | 最も多い |
| 雇用（パート、アルバイト） | 依頼側に雇われ、指揮命令の下で働く。労働時間の管理がある | 少ない。本業の会社の規定で、二重の雇用に制限があることも |
| 窓口や仲介を通した契約 | 窓口と依頼側の契約の下で、窓口と自分の間の取り決めがある。形は業務委託が多い | 多い |
| 顧問契約 | 定期的な助言に対して報酬を受ける形。業務委託の一種 | 経験が長い人に一部 |

形の要点は、「業務委託と雇用の違いを、一般的な整理として知っておく」ことです。業務委託は、自分の裁量で進める形で、依頼側から細かい指揮命令を受けるものではないと整理されています。実態が雇用に近いのに業務委託の形になっている場合、問題になることがあるとされていますが、判断は専門家の領域です。自分の契約がどの形で、実態と合っているかは、契約の前に専門家にご確認ください。

## 契約書で読む六つの条項

契約書は長く見えますが、副業で読むべきところは六つに絞れます。

| 条項 | 何が書かれているか | 確認すること |
|---|---|---|
| 一、範囲 | 何を業務として受けるか | 自分の範囲の一言と合っているか。「採用業務全般」のように広すぎないか。[受ける範囲の決め方](/media/fukugyo-scope/) |
| 二、期間 | いつからいつまでか。更新の方法 | 最初は短い期間か。自動更新か、合意で更新か |
| 三、報酬と支払い | 額、計算の方法（固定・時間・成果）、締め日、支払日、手数料 | 支払いの時期が読めるか。[報酬はいつ支払われるか](/media/fukugyo-qa-6/) |
| 四、秘密保持 | 依頼側の情報を外に出さない約束。範囲と期間 | 自分が守れる内容か。終了後も続くか。実績として書くときの扱い |
| 五、再委託 | 受けた業務を他の人に回してよいか | 禁止か、承諾が要るか。[再委託してよいか](/media/fukugyo-saitaku/) |
| 六、終了 | 途中で終える方法、通知の期間、終了時の情報の扱い | 合わなかったときに終えられるか。[合わなかったらやめられるか](/media/fukugyo-qa-7/) |

六つの要点は、「一」の範囲が、契約書の中で最も自分に関わることです。範囲が広く書かれていると、依頼側は契約書を根拠に範囲外の依頼をでき、自分は断りにくくなります。自分の範囲の一言を、契約書の範囲の条項に反映してもらいます。他の条項は、依頼側の型のままでも問題が無いことが多いですが、読んで分からなければ聞きます。契約書を読むときに迷いやすい点は[請求や契約は自分でやるのか](/media/fukugyo-qa-15/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「契約書は依頼側が用意するものだから、内容は依頼側に任せてよい」というものです。実際には、依頼側が用意する契約書は、依頼側の型で、依頼側に有利な形になっていることが普通です。範囲が広く、終了の通知の期間が長く、秘密保持が広い。それ自体は悪意ではなく、依頼側の法務が自社を守る形にしているだけです。読まずに結ぶと、後で「契約書にこう書いてある」と言われて、自分の範囲や終え方が縛られます。

見ていて差がつくのは、契約書の範囲の条項を、自分の範囲の一言に合わせてもらっているかです。「採用業務全般」を「スカウトの検索・送信・一次返信・面接の設定」に直してもらった人は、後で範囲外の依頼が来ても、契約書を根拠に線を引けます。直さなかった人は、契約書が範囲を広げる根拠になります。エラベルでは、依頼側と担当者の契約の範囲を、担当者の範囲の一言に合わせて整えており、依頼側の型のまま結ぶことはしていません。契約書は、依頼側を守るだけでなく、担当者を守るものでもあります。

## 契約書が無いと言われたとき

依頼側から「契約書は無くてよい」「口約束で」と言われることがあります。そのときの対処です。

| 依頼側の言い方 | 何が起きるか | 対処 |
|---|---|---|
| 「契約書は面倒なので無しで」 | 範囲、報酬、終了で後でもめたとき、自分を守るものが無い | 「簡単なもので構わないので、文面を残させてください」と、六つの条項をメールで送り、返事をもらう |
| 「まず始めて、契約書は後で」 | 始まった後に契約書が来ず、そのまま続く | 「始める前に、範囲と報酬と支払いの三つだけでも文面で」と、最低限を先に決める |
| 「知人の紹介だから信頼で」 | 紹介者の顔を立てて、文面を求めにくい | 「紹介者に迷惑をかけないためにも、文面で残したい」と、紹介者を理由にする。[知人紹介で受けるときの注意](/media/fukugyo-shoukai/) |
| 「うちには外部との契約の型が無い」 | 依頼側に契約の経験が無い | 自分の側で六つの条項を書いたメールを送り、「この内容で進めさせてください」と返事をもらう |
| 「秘密保持だけ結んで、業務の契約は無しで」 | 秘密保持の義務だけ自分が負い、報酬や範囲の約束が無い | 秘密保持と一緒に、範囲と報酬と支払いを文面に入れてもらう |

対処の要点は、「契約書の形でなくても、六つの条項を文面で残す」ことです。正式な契約書が無くても、範囲・期間・報酬と支払い・秘密保持・再委託・終了をメールで送り、「この内容で進めます」と依頼側から返事があれば、取り決めの記録になります。口約束で始めて、後で範囲や報酬でもめると、自分を守るものが無くなります。文面の残し方が契約として有効かは、専門家にご確認ください。

## 窓口経由の契約の形

登録型の窓口や仲介サービスを通す場合、契約の形が直接契約とは違います。

| 項目 | 直接契約 | 窓口経由 |
|---|---|---|
| 契約の相手 | 依頼側 | 窓口（窓口が依頼側と契約している） |
| 契約書 | 依頼側の型か、自分で用意 | 窓口の型。窓口と自分の間の取り決め |
| 範囲 | 依頼側と直接決める | 窓口が依頼側と決めた範囲の中で、自分の範囲を窓口と決める |
| 報酬 | 依頼側から直接 | 窓口から。手数料が引かれることがある |
| 秘密保持 | 依頼側と結ぶ | 窓口と結び、窓口が依頼側と結んでいる。両方の内容を確認 |
| 終了 | 依頼側との契約の終了の条項 | 窓口との取り決めと、窓口と依頼側の契約の両方に関わる |
| 条件の変更 | 依頼側と直接 | 窓口を通す |

窓口経由の要点は、「契約の相手が窓口で、依頼側との条件の話は窓口を通す」ことです。依頼側と直接契約していないので、範囲や報酬の見直しを依頼側に直接持ちかけると、窓口の契約と食い違います。窓口との取り決めを読み、条件の変更は窓口に伝えます。窓口の使い分けは[副業マッチングサービスの使い分け](/media/fukugyo-platform/)に整理しています。

## 契約の前に依頼側と決めること

契約書に書かれていなくても、契約の前に依頼側と決めておくと、後で困らないことがあります。

| 決めること | 内容 | なぜ契約の前か |
|---|---|---|
| 成果の定義 | 自分の範囲の出口を何で見るか | 契約の後に決めると、依頼側は採用の数字で見る。[成果をどう定義しておくか](/media/fukugyo-seika-teigi/) |
| 報告の形と頻度 | 三層の報告の経路と日 | 始まってから合わせると、行き違いが起きる。[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/) |
| 判断の所在 | 自分で決めてよいことと、依頼側に確認すること | 契約書には書かれないことが多い。議事録で残す |
| 本業の繁忙期 | 稼働が下がる時期 | 契約の後に言うと、調整になる。前に言えば予定になる。[稼働が合わなくなったら](/media/fukugyo-qa-12/) |
| 対面の頻度と費用 | どのくらい対面が要るか、移動の費用の扱い | 契約の後に「来てほしい」と言われても線が引きにくい |
| 実績としての扱い | 契約が終わった後に、依頼側の名前や業務を実績として書けるか | 秘密保持の範囲に関わる。[クライアントに実績公開の許可を取る](/media/fukugyo-kyoka-toru/) |
| 他の案件の有無 | 複数の依頼側を持っているか、持つ可能性があるか | 隠して後で分かると信頼を失う。[複数社を同時に受けられるか](/media/fukugyo-qa-9/) |

決めることの要点は、「契約書に書かれないことほど、契約の前に決めておく」ことです。成果の定義、報告の形、判断の所在は、契約書の条項にはならないことが多く、決めないまま始めると、数か月後に噛み合わなくなります。契約の前の打ち合わせで決め、議事録かメールで残します。初回の打ち合わせで決める項目は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に書いています。

## 専門家に確認すべき点

契約について、自分で判断せず専門家に確認すべき点を分けておきます。

| 確認する点 | 誰に | なぜ |
|---|---|---|
| 業務委託と雇用の線。自分の契約の形が実態と合っているか | 弁護士、社会保険労務士 | 実態が雇用に近い場合の扱いは、専門家の領域 |
| 秘密保持の範囲と期間が、自分にとって重すぎないか | 弁護士 | 終了後も長く続く義務や、広すぎる範囲は、後で実績を書く場面などで効いてくる |
| 損害賠償の条項 | 弁護士 | 自分の責任の範囲と上限。上限が無い場合の扱い |
| 競業の制限 | 弁護士 | 他の案件を受けることや、本業との関係に制限がかかるか |
| 途中で終えた場合の責任 | 弁護士 | 通知の期間を守れなかった場合の扱い |
| 本業の会社の規定との関係 | 社会保険労務士、本業の会社の窓口 | 副業の許可の範囲に、契約の形の制限があるか |
| 税の扱い | 税理士 | 業務委託の報酬の扱いと、申告の要否。[確定申告はどうするか](/media/fukugyo-qa-10/) |

専門家の要点は、「最初の一件の契約書だけは、一度専門家に見てもらう」ことです。六つの条項の読み方と、自分にとって不利な点の見分け方は、一度教わると、二件目からは自分で読める部分が増えます。毎回頼む必要はなく、最初の型を作るときに一度、と考えます。本業の規定は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。

### エラベルの見解

担当する側から見ると、契約で困っていない人は、契約書を全部理解している人ではなく、六つの条項を読み、範囲を自分の一言に合わせてもらい、分からない条項を結ぶ前に聞き、契約書に書かれないことを打ち合わせで決めて残している人です。困っている人は、依頼側の型のまま結び、後で範囲や終了の条項に縛られている人です。

順番として、契約書が来たら六つの条項を読み、範囲を自分の一言に合わせてもらい、分からない条項は依頼側か専門家に聞き、契約書に無いこと（成果の定義、報告、判断の所在、繁忙期、対面、実績の扱い、他の案件）を打ち合わせで決めて文面に残し、それから結ぶ。契約書が無いと言われたら、六つの条項をメールで送って返事をもらう。この順番で、契約は縛るものではなく、自分の範囲と条件を守るものになります。エラベルでは、依頼側と担当者の契約の型を整え、範囲を担当者の一言に合わせ、契約書に書かれないことも最初の打ち合わせで決める形を取っています。契約の形が整っていることは、担当者が安心して始められる土台です。

## まとめ

- 副業の契約の多くは**業務委託**で、雇用ではない。一般的な整理を知り、自分の契約の形は専門家に
- 契約書で読むのは**範囲・期間・報酬と支払い・秘密保持・再委託・終了**の六つ。**範囲を自分の一言に合わせてもらう**
- 契約書が無いと言われても**六つの条項を文面で残す**。口約束で始めない
- 窓口経由は**契約の相手が窓口**。条件の変更は窓口を通す
- 契約書に書かれないこと（**成果の定義・報告・判断の所在・繁忙期・対面・実績の扱い・他の案件**）は契約の前に決めて残す
- **最初の一件の契約書は一度専門家に**。二件目からは自分で読める部分が増える

## よくある質問

### 依頼側の契約書に、自分に不利に見える条項があります。直してもらえますか

直してもらえることは多いです。「範囲をこの工程に限定していただけますか」「終了の通知の期間を一か月にしていただけますか」のように、具体の条項と直したい内容を伝えます。依頼側の法務の型で直せない条項もあり、その場合は「この条項は変えられない」と言われます。変えられない条項が自分にとって重すぎるなら、受けない判断もあります。どの条項が重すぎるかの判断は、専門家にご確認ください。交渉の仕方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。

### 電子契約で結ぶと言われました。紙と何が違いますか

電子契約は、紙の契約書と同じ内容を、電子の仕組みで署名して結ぶ形で、多くの会社で使われています。読むべき条項は紙と同じ六つで、違いは署名の方法と控えの保管です。控えは自分の側にも保存しておきます。電子契約の仕組みの有効性や、印鑑が要るかどうかは、依頼側の仕組みによるので、依頼側に確認します。分からない点は、専門家にご確認ください。

### 契約の途中で、範囲や報酬を変えたくなったら、契約書を作り直すのですか

契約の途中で条件を変える場合、契約書を作り直すか、変更の内容を覚書やメールで残す形が一般的です。更新の節目なら、新しい契約書に反映してもらいます。途中で変える場合は、「〇月〇日から、範囲を〇〇に変更し、報酬を〇〇にする」と文面で合意し、双方の控えに残します。口頭で変えて文面に残さないと、後で「そんな話だったか」になります。条件の見直しの進め方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。文面の形が契約として有効かは、専門家にご確認ください。
