スカウトに返信が来て、日程も決まった。ところが、当日に来ない。前日の夜に「都合が悪くなりました」と来る。連絡も無く、面談の時間が過ぎる。面談の相手（責任者など）の時間が無駄になり、社内から「スカウトで来る候補者は意識が低い」と言われ、面談の枠を空けてもらえなくなる。結論を先に書くと、**ドタキャンは、候補者の意識の問題ではなく、「確定から当日までの空白」「確定の重さ」「当日の入り口」「面談の相手」「キャンセルの出口」の五つの設計の問題です。確定から当日まで接点が無く、確定が軽く、当日の入り方が分からず、相手が誰か分からず、断りにくい。この五つを設計すれば、ドタキャンは減り、キャンセルは事前の連絡に変わります**。面接の無断欠席の構造は[面接のドタキャン・無断欠席を減らす](/media/rpo-mensetsu-kettai/)に、面談の設定までは[面談設定率をどう上げるか](/media/scout-mendan-settei-ritsu/)にまとめています。

## ドタキャンが起きる構造

面談のドタキャンが起きるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 確定から当日までの空白 | 日程が決まってから当日まで、一週間以上、何の連絡も無い。候補者の中で優先順位が下がる |
| 確定が軽い | 「では〇日に」で終わり、場所や方法や相手が書かれていない。候補者は「本当に決まったのか」と感じる |
| 当日の入り口が分からない | オンラインのリンクが直前まで来ない、来社の場合の場所や受付が分からない。当日に迷い、諦める |
| 面談の相手が分からない | 誰と話すのか、何を話すのかが無い。候補者にとって「行く理由」が弱い |
| キャンセルの出口が無い | 都合が悪くなったとき、どう連絡すればよいか分からず、言いにくく、結果として無断になる |
| スカウトの候補者の特性 | 自分から応募した人と違い、「声をかけられた側」なので、優先順位は低い。設計で補う必要がある |
| 他社の選考が進んだ | 面談の日までに他社が決まった。事前に連絡してもらえる関係が無いと、無断になる |

構造の大半は、「確定した後の設計が無い」ことです。確定までは丁寧で、確定した後は当日まで放置、という運用がドタキャンを生みます。

## ドタキャンの種類

ドタキャンを、種類で分けます。種類ごとに、防ぎ方と対応が違います。

| 種類 | 状況 | 主な原因 | 防ぎ方 |
|---|---|---|---|
| 無断 | 連絡無く来ない | キャンセルの出口が無い。空白で忘れた | 出口の設計、前日の確認 |
| 直前の連絡あり | 前日や当日に「都合が悪く」 | 優先順位が下がった。他社が進んだ | 空白の設計、面談の相手 |
| 事前の連絡あり | 数日前に「日程を変えたい」 | 都合の変化。ドタキャンではなく再調整 | 再調整の型を用意 |
| 当日の入り口で消える | リンクが開けない、場所が分からず来ない | 当日の入り口の設計 | 入り口の明示 |
| 面談の直前に辞退 | 「やはり今回は」と前日に | 面談の位置づけが重く感じた。行く理由が弱い | 確定の重さ、面談の相手 |

種類の要点は、「事前の連絡がある再調整は、ドタキャンに数えない」ことです。連絡があって日程が動くのは、設計が機能している証拠です。減らすのは、無断と直前です。

## 五つの設計

ドタキャンを減らす、五つの設計です。

| 設計 | 内容 |
|---|---|
| 確定から当日までの空白を埋める | 確定の翌日に一通、前日に一通。内容は「楽しみにしています」ではなく、面談の相手の一言、当日話すこと、事前に見てほしいもの |
| 確定を重くする | 確定の連絡に、日時、方法（オンラインか来社か）、所要時間、相手の名前と立場、話すこと、当日の入り口、連絡先を全部書く。「決まった」と候補者が感じる形に |
| 当日の入り口を明示する | オンラインならリンクを確定時と前日の二回。来社なら場所、受付、目印、到着後の動き。当日の連絡先 |
| 面談の相手を伝える | 相手の名前、立場、その人と話す意味。可能なら相手からの一言を前日の連絡に |
| キャンセルの出口を作る | 確定の連絡に「ご都合が変わった場合は、この連絡先に一言ください。日程は改めて調整します」を必ずしも詫びを求めない形で書く。断りやすく |

五つの要点は、「確定の連絡に全部書く」ことです。確定の連絡が「では〇日〇時で」だけだと、他の四つも無い状態になります。確定の連絡の型を作り、五つを全部含めます。日程の提示から確定までは[日程の提示のしかた](/media/scout-nichiji-teiji/)に書いています。

## 確定から当日までの接点の型

確定から当日までに送る、接点の型です。

| タイミング | 送り主 | 内容 |
|---|---|---|
| 確定時 | 担当者 | 日時、方法、所要時間、相手の名前と立場、話すこと、入り口、連絡先、キャンセルの出口。全部 |
| 確定の翌日〜数日以内 | 面談の相手（責任者など） | 「〇日にお話しできるのを楽しみにしています。当日は△△についてお話しします。事前に□□をご覧いただけると話が早いです」。二〜三文 |
| 前日 | 担当者 | 日時と入り口の再掲、リンクの再送、「ご都合が変わった場合は一言ください」。相手の一言があれば添える |
| 当日の朝（オンラインの場合） | 担当者 | リンクの再送と、開始の時刻。一文 |
| 当日、開始の五分後に来ない | 担当者 | 「接続でお困りでしたら、この番号に」。一文。責めない |

型の要点は、「面談の相手からの一通」です。担当者や人事からの連絡は「事務」に見えますが、面談の相手からの一通は「会う人からの言葉」で、候補者の優先順位を上げます。二〜三文で足り、相手の負担は小さい。担当者が下書きを作り、相手の名前で送ってもらいます。

### エラベルの見解

相談で最も多い失敗は、「面談の確定を『では〇日〇時でお願いします』の一文で済ませ、当日までの一週間、何も送らず、当日の三十分前にオンラインのリンクを送っていた」というものです。候補者の側では、確定の実感が無く、一週間の間に優先順位が下がり、当日のリンクを見落として、無断の形になっていました。確定の連絡に五つを全部書き、翌日に面談の相手から二文、前日に担当者から入り口の再掲、に変えたら、無断は無くなり、都合が変わった人は事前に連絡してくるようになりました。ドタキャンは、候補者ではなく、確定の後の設計の問題でした。

見ていて差がつくのは、担当者が「面談の相手からの一通」を取りに行くかです。「責任者は忙しいので」と担当者だけで連絡する担当者と、「二文だけ、責任者の名前で送ってもらいます。下書きは私が作ります」と言う担当者がいます。後者の面談は、候補者が来ます。

発注側にできるのは、面談の相手に、「確定の翌日に、担当者が用意した二文を自分の名前で送ってください」を頼むことです。

## 当日来なかったときの対応

設計しても、来ないことはあります。そのときの対応です。

| 状況 | 対応 |
|---|---|
| 開始の五分後 | 「接続でお困りでしたら」の一文。責めない |
| 開始の十五分後 | 面談の相手を解放する。候補者には「本日はご都合が合わなかったようですので、改めて日程をご相談できればと思います」と一通。詫びを求めない |
| 翌日に連絡が来た | 再調整の型で、日程を出し直す。理由は聞かない。一度目は通常どおり |
| 翌日にも連絡が無い | 三日後に一度だけ、「日程を改めてご相談できればと思います。ご興味が無ければご返信は不要です」。それで終わり |
| 二度目の無断 | 三度目の設定はしない。記録に残し、プールにも入れない |
| 面談の相手への説明 | 「候補者の意識」ではなく、「確定後の設計のどこが抜けたか」で説明する。相手が「スカウトの候補者は来ない」と思わないように |

対応の要点は、「責めない」と「面談の相手への説明」です。責めると、候補者は戻りません。面談の相手に「候補者が悪い」と説明すると、枠を空けてもらえなくなります。設計のどこが抜けたかを説明し、直します。

## 記録と振り返り

ドタキャンを減らすには、記録と振り返りが要ります。

| 項目 | 内容 |
|---|---|
| 確定日と面談日 | 確定から面談までの日数。長いほどドタキャンが増えるなら、近い日程を優先する |
| 接点の記録 | 確定時、翌日、前日、当日の連絡を送ったか。相手からの一通があったか |
| 結果 | 実施、無断、直前の連絡、事前の再調整、当日の入り口で消えた |
| 理由 | 連絡があった場合の理由。「他社が決まった」「都合」「やはり今回は」 |
| 面談の相手 | 相手が誰だったか。相手によってドタキャンの率が違うか |
| 月次の振り返り | 種類ごとの件数。設計の五つのどこが抜けていたか。近い日程と遠い日程での差 |

記録の要点は、「接点の記録と結果を並べる」ことです。「相手からの一通があった面談」と「無かった面談」で、ドタキャンの率が違えば、その一通の効果が自社の記録で分かります。指標の見方は[スカウト運用で見るべき指標](/media/scout-shihyou/)に書いています。

## 外注する場合の範囲

ドタキャンの対策を、スカウト代行に出す場合の範囲です。

**出せる工程。** 確定の連絡の型の作成（五つを全部含む）、確定から当日までの接点の型の作成と送信（担当者からのもの）、面談の相手からの一通の下書きと依頼、当日の入り口の情報の整備とリンクの送信、来なかったときの連絡、再調整の型の作成と実施、記録と月次の振り返り、面談の相手への説明の資料（設計のどこが抜けたか）。

**社内に残す判断。** 面談の相手の決定と、相手からの一通を送ることの協力、来社の場合の場所と受付の情報の提供、当日の連絡先の担当（社内の人が受ける場合）、二度目の無断の扱いの承認、面談の相手への説明の実施。

**外注の効きどころ。** ドタキャンは、「確定の後の五つを設計し、接点を送り、来なかったときに責めずに対応し、記録で振り返る」運用で、社内では「確定したら当日まで放置」になりやすい工程です。担当者が確定の型と接点の型を持ち、相手からの一通を下書きし、当日の入り口を整え、来なかったときの連絡を型で送れば、無断は減り、キャンセルは事前の連絡に変わります。担当者は複数の会社の面談を見ているので、「この日数を超えると来ない」「この一通で来る」を持ち込めます。ただし、面談の相手からの一通と、場所や受付の情報は、社内からしか出ません。

**外注しても動かない場合。** 面談の相手が一通を送らない、来社の場所や受付の情報を渡さない、来なかった候補者を「意識が低い」と決めつけて再調整を認めない、面談の相手への説明を「候補者のせい」にする。社内の判断で、代行を替えても直りません。

ドタキャンは、確定の後の五つを設計し、接点を送り、責めずに対応すれば減ります。外注は、確定と接点の型と当日の入り口と来なかったときの対応と記録を担う手段です。

### エラベルの見解

担当する側から見ると、ドタキャンの相談で最も多いのは、「確定から面談までが長い」ことです。面談の相手の枠が二週間先しか空いておらず、確定から面談まで二週間。その間に候補者は他社の面談を三つ受け、優先順位が下がります。二週間先の面談は、確定の時点で来ない可能性が高い。

近い日程の枠を空けておく。それができないなら、二週間の間に接点を二回以上入れる。どちらかです。日数を短くするほうが、接点を増やすより効きます。

発注側にできるのは、面談の相手に、「一週間以内の枠を、週に一つ空けてください」を頼むことです。

## まとめ

- 起きるのは**空白・確定が軽い・入り口が分からない・相手が分からない・出口が無い・スカウトの候補者の特性・他社が進んだ**構造
- 種類は**無断・直前の連絡・事前の再調整・入り口で消える・直前の辞退**。事前の再調整はドタキャンに数えない
- 設計は**空白を埋める（翌日と前日）・確定を重くする（全部書く）・入り口を明示・相手を伝える・出口を作る**。確定の連絡に全部書く
- 接点は**確定時（担当者、全部）・翌日（面談の相手、二〜三文）・前日（担当者、再掲と出口）・当日の朝（リンク）・五分後（責めない一文）**
- 来なかったら**五分後の一文・十五分後に解放と一通・翌日の連絡には再調整・三日後に一度・二度目は設定しない・相手には設計で説明**
- 記録は**確定から面談までの日数・接点の記録・結果の種類・理由・相手・月次の振り返り**。接点と結果を並べる
- 外注できるのは**確定の型・接点の型と送信・相手の一通の下書き・入り口の整備・来なかったときの連絡・再調整・記録と振り返り・説明の資料**。社内に残るのは**相手の決定と協力・場所と受付・当日の連絡先・二度目の扱い・説明の実施**

## よくある質問

### 前日の確認の連絡は、候補者に負担ではありませんか

内容によります。「明日、お越しいただけますか」と返事を求める形は、負担です。「明日〇時、リンクはこちらです。ご都合が変わった場合は一言ください」と、返事を求めず、入り口と出口だけを書く形なら、候補者は「親切」と受け取ります。返事は要りません。前日の連絡は、確認ではなく、入り口の再掲と出口の提示です。

### オンラインの面談で、リンクを送っても開かれません

リンクを送る回数と、タイミングを見直します。確定時、前日、当日の朝の三回。当日の朝の一通は、リンクと開始の時刻だけの一文で、候補者がその一通を開けば入れる形にします。加えて、「接続でお困りでしたら、この番号に」の連絡先を、当日の朝の一通に入れます。開始の五分後に来なければ、その番号に連絡が来るか、こちらから一文を送ります。リンクの再送は、負担ではなく、入り口の明示です。

### 来社の面談で、場所が分かりにくいと言われます

確定の連絡と前日の連絡に、住所、最寄りの駅からの道順、建物の目印、受付での動き（誰を呼び出すか）、到着後の連絡先を書きます。可能なら地図のリンクと、建物の入り口の写真。「当日は受付で〇〇をお呼び出しください」まで書くと、候補者は迷いません。来社の場合、入り口の設計がドタキャンと遅刻の大半を決めます。職場を見せる場としての面談は[職場見学への誘導](/media/scout-shokuba-kengaku/)にも書いています。
