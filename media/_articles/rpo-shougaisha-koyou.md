障害者雇用の法定雇用率を満たしていない。「採らなければ」と求人を出したが、応募が来ない。来ても、何を任せればよいか分からず、面接で何を聞いてよいかも分からない。過去に採った人は、半年で辞めた。「数を満たす」ことだけが目的になっていて、何から手を付ければよいか分からない。結論を先に書くと、**法定雇用率が達成できないのは、「数を満たす」ことから入っているからです。数から入ると、役割が無く、受け入れが無く、採っても続かず、また数が足りなくなります。「任せられる役割を作る」「受け入れの体制を整える」「続く雇用にする」から始めれば、結果として数が満たされます。制度の内容、支援の仕組み、法令上の扱いは、公的機関の案内と専門家で確認しながら進めます**。受け入れの型の考え方は[候補者体験が悪いまま放置されている](/media/rpo-taiken-warui/)の入社後の項目と共通です。法定雇用率の水準、対象となる範囲、届出、助成などの制度は、公的機関の案内と専門家（社労士など）で確認します。

## 達成できない構造

法定雇用率が達成できないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「数を満たす」から入っている | 役割も受け入れも無いまま、「〇人採る」だけが目的。採っても続かない |
| 任せる役割が無い | 「何をしてもらえばよいか分からない」。既存の仕事を切り出していない |
| 受け入れの体制が無い | 配慮の内容、教える人、相談の窓口が無い。採った後に現場が困る |
| 経路と支援の仕組みを知らない | 公的な支援の仕組み、専門の紹介の窓口、就労の支援の機関を使っていない |
| 面接で何を聞いてよいか分からない | 配慮の確認と、私的な事情への踏み込みの線が分からず、聞けない |
| 社内の理解が無い | 「なぜ採るか」「どう接するか」を、社内に説明していない |
| 過去の失敗で止まっている | 「前に採った人が続かなかった」で、設計を見直さずに避けている |
| 制度と法令の扱いを、確認していない | 対象、届出、支援の制度を、公的機関の案内と専門家で確認していない |

構造の大半は、「数から入って、役割と受け入れを作っていない」ことです。

## 最初に整理すること

障害者雇用を進めるとき、最初に整理することです。

| 整理すること | 中身 | 誰と |
|---|---|---|
| 制度と法令の扱い | 法定雇用率の水準、対象となる範囲、届出、支援と助成の制度。最新の内容 | 公的機関の案内、専門家（社労士など） |
| 自社の現状 | 現在の雇用の状況、不足の数、期限 | 人事、専門家 |
| 任せられる役割の候補 | 既存の業務の中で、切り出せる仕事。新たに作る仕事 | 現場の責任者、人事 |
| 受け入れの体制 | 配慮の内容、教える人、相談の窓口、社内の理解 | 現場の責任者、人事、経営者 |
| 使える支援の仕組み | 公的な就労の支援の機関、専門の紹介の窓口、職場の定着の支援 | 公的機関の案内、専門家 |
| 経営者の方針 | 「数を満たす」ではなく「続く雇用にする」方針。経営者が社内に示す | 経営者 |

整理の要点は、「制度と法令は公的機関と専門家で確認し、役割と受け入れは社内で作る」ことです。両方が要ります。制度だけ分かっても役割が無ければ採れず、役割があっても制度を知らなければ支援を使えません。

## 役割の作り方

「何をしてもらえばよいか分からない」を、役割を作ることで解決します。

**既存の業務を、書き出す。** 各部署の業務を、細かく書き出します。「資料の整理」「データの入力」「備品の管理」「検品」「清掃」「メールの仕分け」「システムの確認」など。部署の責任者と一緒に。

**切り出せる仕事を、探す。** 書き出した業務の中で、「まとまった量がある」「手順が決まっている」「他の業務と切り離せる」ものを探します。複数の部署から集めて、一つの役割にする形もあります。

**「本人の得意」から作る形も。** 候補者の得意なこと（集中力、正確さ、特定の技能）に合わせて、役割を作る。採用の過程で、本人と支援の機関と相談しながら。

**役割を、書面にする。** 何を、どのくらいの量で、どういう手順で、誰と、どこで。役割の記述（[ジョブディスクリプションがない](/media/rpo-jd-nai/)）と同じ考え方で、配慮の項目を足します。

**「数を満たすための仕事」にしない。** 意味の無い仕事を作ると、本人も周囲も続きません。「会社にとって要る仕事」を切り出します。

**役割は、本人に合わせて調整する。** 最初に作った役割を固定せず、本人の得意と、周囲との関係を見て、調整します。支援の機関の助言を受けます。

役割の要点は、「会社にとって要る仕事を、切り出して、書面にする」ことです。役割が書面にあれば、求人票も、面接も、受け入れも、そこから作れます。

## 経路と支援の仕組み

障害者雇用には、公的な支援の仕組みと、専門の経路があります。制度の内容と使い方は、公的機関の案内と専門家で確認します。

| 経路・仕組み | 中身 | 確認先 |
|---|---|---|
| 公的な職業紹介の障害者向けの窓口 | 求人の受付、候補者の紹介、相談 | 公的機関の案内 |
| 就労の支援の機関 | 就労に向けた支援を行う機関。候補者の紹介、職場への定着の支援、会社への助言 | 公的機関の案内 |
| 障害者雇用に特化した紹介会社や媒体 | 候補者の紹介、求人の掲載 | 各社の公式の案内 |
| 特別支援学校などの学校 | 新卒の経路。実習の受け入れから | 学校との連携 |
| 職場の実習や体験の仕組み | 採用の前に、職場で実習や体験をしてもらう仕組み | 公的機関の案内、支援の機関 |
| 職場の定着の支援 | 入社後、支援の機関の担当者が職場と本人を支える仕組み | 公的機関の案内、支援の機関 |
| 助成や支援の制度 | 雇用や職場の環境の整備に関する助成や支援 | 公的機関の案内、専門家 |

経路の要点は、「支援の機関と一緒に進める」ことです。会社だけで探し、会社だけで受け入れる形より、支援の機関の助言と定着の支援を受ける形のほうが、続く雇用になります。

制度の内容、対象、手続きは変わることがあります。公的機関の案内で、最新の内容を確認します。

### エラベルの見解

相談で最も多い失敗は、「法定雇用率の期限が迫り、『とにかく〇人』で求人を出し、役割を決めずに採り、現場が『何をしてもらえばよいか分からない』で放置し、半年で辞めた。また数が足りなくなった」というものです。数から入ったので、役割も受け入れも無かった。既存の業務を書き出し、切り出せる仕事を役割にし、支援の機関と一緒に候補者を見て、実習から始め、定着の支援を受ける形にしたら、続く雇用になり、結果として数も満たされました。「数」ではなく「役割と受け入れ」からでした。

見ていて差がつくのは、担当者が「支援の機関と一緒に進める」ことを最初に提案するかどうかです。「障害者雇用の求人を出しましょう」で一般の求人と同じ流れにする担当者と、「まず制度を公的機関と専門家で確認し、役割を現場と切り出し、支援の機関に相談して、実習から始めましょう」と、支援の仕組みを使う担当者がいます。後者は、続く雇用を作ります。

発注側にできるのは、「数を満たす」ではなく「続く雇用にする」を方針として、経営者が社内に示すことです。

## 見極めと配慮の確認

面接での見極めと、配慮の確認の仕方です。法令上の扱いがあるので、専門家に確認のうえ、面接官に共有します。

**役割に対する適性を、見る。** 役割の記述に対して、「この仕事ができそうか」「得意なことは何か」を、本人と（必要なら支援の機関の担当者と）確認します。障害の種類や程度ではなく、役割に対する適性で。

**配慮の内容を、本人に確認する。** 「業務を行ううえで、会社に配慮してほしいことはありますか」。本人が伝えたい配慮を、本人の言葉で聞きます。会社が一方的に決めない。

**聞き方の線。** 配慮の確認は、業務に関わる範囲で。障害の詳細や私的な事情への踏み込みは、法令上の扱いがあります。「何を聞いてよいか、何を聞いてはいけないか」は、専門家に確認のうえ、面接官に一枚で共有します。

**支援の機関の担当者の同席。** 本人が希望すれば、支援の機関の担当者が面接に同席する形があります。本人の得意と配慮を、担当者が補足できます。

**実習や体験で、見る。** 面接だけで判断せず、職場の実習や体験の仕組み（公的機関の案内で確認）を使って、実際の業務で適性と配慮を確認します。

**通す・通さないの理由を、役割に対する事実で。** 障害を理由にした判断は、法令上の扱いがあります。判断は役割への適性で行い、理由も役割に対する事実で。専門家に確認します。

見極めの要点は、「役割への適性で見る」ことと「配慮は本人の言葉で聞く」ことです。障害の種類や程度で判断する形は、法令上の扱いに反する可能性があり、専門家に確認します。

## 受け入れと定着

採用の後の受け入れと、続く雇用にする設計です。

| 項目 | 設計 |
|---|---|
| 配慮の実施 | 面接で確認した配慮を、入社前に整える。作業の環境、時間、手順、道具。内容は本人と合意 |
| 最初の一か月の予定 | 何を、誰と、どうやって覚えるか。書面で。本人の理解の仕方に合わせた形（図、手順書、実演など） |
| 教える人 | 一人決める。教える時間の分、その人の業務を調整。支援の機関の助言を受けられる形に |
| 相談の窓口 | 業務の相談（教える人）と、それ以外の相談（人事、または支援の機関）。本人が相談しやすい形 |
| 支援の機関との連携 | 定着の支援の仕組みを使い、支援の機関の担当者と定期的に連絡。困りごとを早く把握 |
| 周囲の理解 | 受け入れる部署に、事前に説明。「役割」「配慮の内容（本人が同意した範囲で）」「どう接するか」 |
| 体調や状況の変化への対応 | 変化があれば、役割や配慮を調整。本人と支援の機関と相談 |
| 評価と処遇 | 役割に対する評価。制度は社内の規程と法令に沿い、専門家に確認 |
| 定期の振り返り | 月に一度、本人と教える人と人事（と支援の機関）で。「役割は合っているか」「配慮は足りているか」 |

受け入れの要点は、「配慮を入社前に整える」ことと「支援の機関と連携して定着を支える」ことです。会社だけで抱えると、困りごとに気づくのが遅れます。

周囲の理解は、本人が同意した範囲で、受け入れる部署に説明します。説明が無いと、周囲は「どう接すればよいか分からない」で距離を置きます。

## 社内の理解

障害者雇用を続く雇用にするには、社内の理解が要ります。

**経営者が、方針を示す。** 「法定雇用率を満たすため」ではなく、「会社として、多様な人が働ける職場を作る。障害者雇用はその一部」。経営者の言葉で。

**受け入れる部署に、事前に説明する。** 役割、配慮の内容（本人が同意した範囲で）、どう接するか、困ったときの相談先。「特別扱い」でも「無視」でもなく、「同じ社員として、配慮のうえで」。

**教える人を、支える。** 教える人が一人で抱えない。支援の機関の助言、人事の相談、教える時間の確保。

**成功の例を、社内に共有する。** 「〇〇の役割で、〇〇さんが活躍している」。本人の同意のうえで。次の受け入れが楽になります。

**社内の研修や学ぶ機会を、持つ。** 障害に関する基本の理解、接し方。公的機関や支援の機関が提供する研修や資料を使います。

**「数」を社内の目標にしない。** 「〇人採る」を目標にすると、役割と受け入れが後回しになります。「続く雇用」を目標に。

社内の理解の要点は、「経営者の方針」と「受け入れる部署への事前の説明」です。この二つが無いと、現場は困り、本人は孤立します。

## 外注する場合の範囲

障害者雇用の問題を、採用代行に出す場合の範囲です。

**出せる工程。** 最初の整理の進行（制度の確認の公的機関と専門家への橋渡し、現状の整理）、既存の業務の書き出しと切り出せる仕事の整理（現場の責任者との聞き取り）、役割の書面化、支援の機関との連携の窓口、経路の設計と運用（公的な窓口、特化した紹介会社、学校、実習の仕組み）、求人票、面接での配慮の確認の仕方の整理（専門家の確認を経て）、面接官向けの一枚、実習や体験の設計、受け入れの型の案、受け入れる部署への説明の資料、支援の機関との定期の連絡の窓口、定期の振り返りの型。

**社内に残す判断。** 経営者の方針の決定、役割の決定、配慮の内容の合意（本人と）、教える人の指名と業務の調整、判定、内定、評価と処遇の制度（専門家との連携）、社内への説明。

**外注の効きどころ。** 障害者雇用は、「数から入って役割と受け入れが無い」状態から、「役割と受け入れを作り、支援の機関と連携する」形に変えることが要点です。担当者が整理と切り出しと連携の窓口を担えば、社内は役割の決定と配慮の合意と受け入れに集中できます。担当者は複数の会社の障害者雇用を見ているので、「この業務は切り出しやすい」「支援の機関との連携はこう」の型を持ち込めます。ただし、制度と法令上の扱いは、担当者も公的機関と専門家で確認します。

**外注しても動かない場合。** 経営者が「数を満たせばよい」を譲らない、現場が業務の書き出しに応じない、受け入れる部署への説明を認めない。社内の判断で、代行を替えても直りません。

障害者雇用は、役割と受け入れから始めれば、続く雇用になります。外注は、整理と切り出しと連携を持ち込む手段です。

### エラベルの見解

担当する側から見ると、障害者雇用の相談で最も多いのは、「支援の機関を使っていない」ことです。会社だけで求人を出し、会社だけで面接し、会社だけで受け入れる。支援の機関には、候補者の紹介、実習の仕組み、定着の支援、会社への助言があります。使わない理由は、「知らなかった」がほとんどです。

公的機関の案内で支援の仕組みを確認し、支援の機関に一度相談する。それだけで、「何をしてもらえばよいか分からない」「続かない」の大半に、助言と支援が付きます。

発注側にできるのは、求人を出す前に、公的機関の案内で支援の仕組みを確認し、支援の機関に相談することです。

## よくある質問

### 何をしてもらえばよいか、分かりません

各部署の業務を細かく書き出し、「まとまった量がある」「手順が決まっている」「他の業務と切り離せる」仕事を探します。複数の部署から集めて一つの役割にする形もあります。候補者の得意なことに合わせて役割を作る形も、支援の機関と相談しながら進められます。「数を満たすための仕事」ではなく、「会社にとって要る仕事」を切り出します。役割を書面にすれば、求人票も面接も受け入れも、そこから作れます。

### 面接で、障害のことをどこまで聞いてよいですか

業務を行ううえでの配慮を、本人の言葉で聞きます。「配慮してほしいことはありますか」。障害の詳細や私的な事情への踏み込みは、法令上の扱いがあります。「何を聞いてよいか、何を聞いてはいけないか」は、専門家に確認のうえ、面接官に一枚で共有します。本人が希望すれば、支援の機関の担当者が同席する形もあります。判断は役割への適性で行い、通す・通さないの理由も役割に対する事実で。障害を理由にした判断は、専門家に確認します。

### 前に採った人が半年で辞めました。何が悪かったのですか

多くの場合、役割が無い（何をしてもらえばよいか分からず放置）、配慮が整っていない、教える人がいない、相談の窓口が無い、支援の機関と連携していない、周囲に説明していない、のどれかです。辞めた理由を（本人か支援の機関から）聞ければ、直す先が分かります。次に採る前に、役割の書面、配慮の合意、教える人、相談の窓口、支援の機関との連携、受け入れる部署への説明を整えます。同じ設計で採れば、同じ理由で辞めます。
