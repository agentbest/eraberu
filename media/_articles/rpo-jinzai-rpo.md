人材業界の会社（人材紹介、人材派遣、求人媒体、採用の支援）が採用代行を検討するとき、動機は「自社の採用が後回しになっていて、応募への返事が数日遅れる」「キャリアアドバイザーと営業の離職が多く、募集が止まらない」であることが多い。「採用のプロが代行を使うのは恥」という抵抗もあります。ただ、人材業界の自社の採用は、他の業界と違う難しさがあります。担当者が事業と兼務で自社の採用に時間が無く、職種で求める人と経路が違い、目標と成果報酬と稼働の実態が求人票に無く、候補者が同業からの転職で実態を知っているため覆えず、離職が採用を上回り、経営者の面接の目が厳しい。結論を先に書くと、**人材業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、職種ごとの要件と目標の実態の決定・自社の紹介の型との相性の見極め・受け入れは社内に残さないと、採れても数か月で離れ、また募集することになります。**「自社でできる」ことと「自社でやれている」ことは別で、代行に出す前に、難しさを自社の状況で分解し、職種ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種としての営業の切り分けは[営業採用を代行に出す判断基準](/media/rpo-sales-rpo/)に書いています。ここでは、人材業界の自社の採用で共通する切り分けに絞ります。

## 人材業界の自社の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 採用の専門家が自社の採用だけ後回し | 担当者が紹介・派遣・媒体の営業と兼務で、顧客の採用が先。自社の応募への返事が数日後 | 一次対応を残すと流れる。「自社でできる」が「やれていない」 |
| 職種で求める人と経路が違う | キャリアアドバイザーは対人と傾聴、法人営業は新規と数字、コーディネーターは調整と速さ、媒体の営業は提案。来る人も動く理由も違う | 職種ごとに求人票と経路を分ける必要がある |
| 目標と成果報酬と稼働の実態 | 月の目標、成果報酬の比率、面談と架電の件数、稼働の長さが求人票に無い | 実態を先に出すかで応募と定着が変わる |
| 同業からの転職で実態を知っている | 候補者は業界の型（目標の詰め方、稼働、離職）を知っており、「アットホーム」で覆えない | 実態を語らないと、面接で見抜かれて辞退 |
| 離職が採用を上回り、経営者の目が厳しい | 早期離職が続き、経営者が業界出身で面接の通過が少なく、募集が止まらない | 受け入れと評価の観点を直さないと、代行で母集団を増やしても往復 |

五つのうち、代行で解決できるのは母集団形成と速さで、実態・相性・受け入れは社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 職種ごとの要件と目標の実態の決定 | 残す | 会社の判断。目標と成果報酬の設計は経営 |
| 紹介と派遣の許可や表示に関わる整理 | 残す | 会社と専門家。法令上の整理がある |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の領域で、〇〇の型の紹介を、〇〇の件数で担った経験」に。代行が整え、責任者が確認 |
| 母集団形成（同業、隣接の業界、営業と対人の経験者に届く経路） | 任せられる | 型があれば外で回せる。自社の候補者データベースとは分ける |
| 一次対応（返信・日程） | 任せられる | 兼務の担当者の負担を減らす。速さが要る |
| 書類の一次確認 | 一部任せられる | 「領域・型・件数・対人の経験」の照合は外で。自社の型との相性は社内 |
| 見極め（面接、同行、ロールプレイ） | 残す | 経営者と現場の責任者。観点と基準を先に決める |
| 受け入れ（最初の三か月の目標、教える人、同行） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 職種をまたいで一つの一覧。自社の顧客向けの記録とは分ける |

「目標の実態の決定」と「自社の型との相性の見極め」は、人材業界に特有の残す工程です。紹介と派遣の許可や求人の表示は、法令上の整理があると一般に整理されているため、会社と専門家が扱います。個別の判断は専門家にご確認ください。

### エラベルの見解

人材業界で多くの会社が見落とすのは、「自社でできる」と「自社でやれている」の差です。担当者は採用の型を知っていて、求人票も書けるし、面接もできる。ただ、顧客の採用が先で、自社の応募への返事は後回しになり、日程が延び、候補者は他社で決まる。「できる」のに「やれていない」のは、時間の問題で、腕の問題ではありません。ここで代行に出すのは、腕を借りるのではなく、時間を買うことです。「一次対応と日程と記録」を外に出し、担当者は「要件と実態の決定、面接、受け入れ」に絞る。エラベルで担当者を選ぶ企業には、「自社の応募への返事は、誰が、何日以内に返していますか」を、私たちから先に聞いています。答えが「担当者が顧客の対応の合間に」なら、代行に出す最初の工程は一次対応です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種と人数 | キャリアアドバイザー・法人営業・コーディネーター・媒体の営業・両面のどれを、何名 |
| 要件 | 領域と型と件数と対人の経験を「必須・歓迎」に分けているか。未経験を採るなら、受け入れの型があるか |
| 実態 | 月の目標、成果報酬の比率と条件、面談と架電の件数、稼働の長さ、離職の状況を、責任者が語れるか |
| 評価の観点 | 経営者と現場で、面接の観点と基準が揃っているか。通過が少ない理由が分かっているか |
| 枠 | 経営者と責任者の面接の枠を、週に一つ先に預けられるか |
| 受け入れ | 最初の三か月の目標、教える人、同行の型が決まっているか |
| 記録 | 自社の採用の一覧が、顧客向けの記録と分けてあるか |

「実態を責任者が語れるか」と「評価の観点が揃っているか」が要です。観点の揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

## 職種ごとに代行の型が違う

| 職種 | 採用の特徴 | 代行に出しやすい工程 |
|---|---|---|
| キャリアアドバイザー | 対人と傾聴。同業と隣接（販売、接客、教育）からの転身 | 隣接の業界に届く母集団形成、一次対応 |
| 法人営業 | 新規と数字。営業の経験者から | 営業の経験者に届く経路、一次対応、記録 |
| コーディネーター（派遣） | 調整と速さ。登録者と企業の間 | 母集団形成、一次対応 |
| 媒体の営業 | 提案と継続。広告や媒体の営業の経験者から | 経路の運用、記録 |
| 両面（一人で法人と個人） | 両方の経験。同業からが中心 | 同業に届く経路、要件の言い換え |

未経験を採る職種（キャリアアドバイザー、コーディネーター）は、受け入れの型が無いと離れます。経験者を採る職種（法人営業、両面）は、実態を語らないと同業の候補者に見抜かれます。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| 人材業界の経験 | 担当者が人材業界の自社の採用を担った経験があるか。職種の違いを知っているか |
| 実態の扱い | 目標と成果報酬の実態を求人票に書く型を持っているか。覆う文面を勧めてこないか |
| 自社のデータベースとの分け方 | 自社の候補者データベースと採用の母集団を混ぜない運用ができるか |
| 一次対応の速さ | 翌営業日中に返す体制があるか |
| 記録の型 | 顧客向けの記録と分けて、自社の採用の一覧を作れるか |
| 費用 | 「工程・稼働時間・担当人数」をそろえて比べる。額の大小だけで決めない |

費用は、依頼する工程と稼働時間で大きく変わるため、同じ工程で比べる軸をそろえます。内訳の見方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 時期 | 起きること | 社内の対応 |
|---|---|---|
| 最初の二週間 | 実態と要件の聞き取り。職種ごとの求人票の作り直し | 責任者が実態（目標、成果報酬、稼働、離職）を語る一時間を取る |
| 一か月目 | 母集団形成と一次対応が回り、応募が増える | 枠を預ける。面接とロールプレイを同じ日に組む |
| 二か月目 | 書類の照合で要件に合わない応募が減る。辞退の理由が見える | 辞退の理由が「目標」「稼働」「成果報酬」なら実態か条件の見直し |
| 三か月目 | 入社。受け入れが始まる | 最初の三か月の目標、教える人、同行。離れたら理由を記録 |
| 半年 | 定着と成果が見える | 受け入れと評価の観点を直す材料に |

出したあとに「応募は増えたが面接で通らない」となるなら、評価の観点が揃っていないか、要件が高すぎる印です。代行のせいにする前に、通らなかった理由を観点ごとに記録し、要件と観点を見直します。

### エラベルの見解

人材業界で見落とされやすいのは「同業の候補者は実態を知っている」ことです。目標の詰め方、成果報酬の条件、稼働の長さ、離職の多さは、業界の中では知られていて、「アットホーム」「裁量が大きい」で覆っても、面接で「月の目標はいくつですか」「成果報酬の条件は」「昨年の離職は何名ですか」と聞かれます。答えを濁すと辞退され、答えて実態が厳しければ辞退されます。ここで直すのは文面ではなく、実態そのものです。目標と成果報酬と稼働を「同業の経験者が聞いても納得する形」に整え、求人票の先頭に書く。応募が減るなら、それは実態を変える判断の材料です。エラベルで担当者を選ぶ企業には、「昨年の離職の人数と理由を、面接で候補者に話せますか」を、私たちから先に聞いています。話せないなら、代行に出す前に、実態を一枚に書き出し、変える部分と伝える部分を分けるところからです。営業の離職の分け方は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。

## まとめ

- 人材業界の難しさは**自社の採用が後回し・職種で違う・目標と成果報酬の実態・同業に覆えない・離職と厳しい目**の五つ
- 外に出せるのは**母集団形成・一次対応・日程・記録**。残すのは**要件と目標の実態の決定・相性の見極め・受け入れ**
- **紹介と派遣の許可や表示は会社と専門家**。個別の判断は専門家にご確認ください
- 代行は**腕を借りるのではなく時間を買う**。最初に出す工程は一次対応
- 職種ごとに**代行の型が違う**。未経験は受け入れ、経験者は実態
- **実態は覆わず整える**。同業の候補者は知っている
- 費用は**同じ工程で比べる軸をそろえる**

## よくある質問

### 採用の会社が採用代行を使うのは、顧客に対して格好がつきません

代行に出すのは腕ではなく時間で、顧客の採用を優先した結果、自社の採用に時間が無いという状態は、顧客にとってむしろ誠実です。加えて、自社の採用を代行に出して機能した経験は、顧客に代行を勧めるときの根拠になります。「自社でも一次対応を外に出して、返事の日数がこう変わった」と語れる会社は、顧客からの信頼が増します。格好の問題ではなく、時間と経験の問題です。

### 自社の候補者データベースから採ればよいのではないですか

自社のデータベースは顧客の求人のために登録した人のもので、自社の採用に使うには、登録の目的と本人の同意の扱いを確かめる必要があります。個人情報の扱いに関わるため、会社と専門家で整理し、個別の判断は専門家にご確認ください。運用の面でも、顧客に紹介する候補者と自社に採る候補者が混ざると、顧客との信頼に関わります。自社の採用の母集団は、データベースとは別の経路で作るのが、多くの会社の型です。

### 未経験のキャリアアドバイザーを採りたいのですが、すぐ辞めます

未経験は、最初の三か月の受け入れで決まります。目標を三か月は抑え、教える人を決め、面談に同行し、到達点を一枚にする。それが無いと、入社の日から目標を持たされ、面談の型を知らないまま数字を詰められて離れます。代行は母集団形成と一次対応を担えますが、受け入れは現場です。受け入れの型を作ってから未経験を採る、の順番が、往復を止めます。受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。
