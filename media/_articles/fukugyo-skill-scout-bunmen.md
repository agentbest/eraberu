スカウトの文面は、会社の紹介を長く書いても、条件を並べても、返信は来ません。受け取る側は、開いた瞬間に「自分宛てか、全員に送っているか」を見分け、全員宛てなら閉じます。文面を書く仕事は、うまい文章を書くことではなく、「その人の経歴を読んで送っている」と一段落で分からせ、読み進めた先で「この役割は自分に関係がある」と判断できる形にすることです。結論を先に書くと、**スカウト文面は、その人の経歴に触れる一段落・この役割がある理由と任せる仕事・迷う理由への先回り・返信しやすい結びの四つの段落で書き、優先度「上」には個別に、「中」には型に一段落足して使い分け、盛らず・条件を並べず・急かさず、返信の結果で書き換えます。**件名の条件は[スカウトの件名の作り方](/media/scout-kenmei/)に、職種ごとの例は[営業へのスカウト文面](/media/scout-sales-bunmen/)などに書いています。ここでは、一通を組み立てる型に絞ります。

## 返信が来ない文面の共通点

| 形 | 受け取る側に起きること |
|---|---|
| 会社紹介から始まる | 「全員に送っている」と読んで閉じる |
| 「あなたのご経歴を拝見し」だけで、何を見たか書いていない | 定型と分かる |
| 条件（年収・休日・福利厚生）が並ぶ | 条件で釣る印象。合う人ほど慎重になる |
| 「ぜひ一度お話を」で終わる | 何をすればよいか分からず、返信の負荷が高い |
| 長い | 読む前に閉じる |
| 「急募」「今だけ」 | 急かされて引く |

返信が来る文面は、短く、先頭の一段落が「その人宛て」で、途中で「この役割の中身」が分かり、結びで「返信のしかた」が具体です。

## 四つの段落

| 段落 | 書くこと | 材料 |
|---|---|---|
| 一：その人の経歴に触れる | プロフィールのどこを見て、なぜ声をかけたか。担った仕事の中身の言葉で | [プロフィールの見極め方](/media/fukugyo-skill-screening/)で○を付けた根拠 |
| 二：この役割がある理由と任せる仕事 | なぜいま採るか（一文）。入ってすぐ任せること（二〜三つ） | 要件の一枚、[ジョブディスクリプションを書く](/media/fukugyo-skill-jd/)の六つの要素 |
| 三：迷う理由への先回り | その人が迷いそうなこと（会社の規模、次の転職での見え方、報酬の水準）に一言 | ターゲット像の一枚の「迷う理由」 |
| 四：返信しやすい結び | 「まずは〇〇について、三十分ほど情報交換を」のように、負荷の低い次の一歩 | 依頼側と決めた次の一歩 |

四つで、短く収めます。会社の紹介は、二の「この役割がある理由」の一文に溶かします。読む人が会社を知りたければ、採用ページのリンクを末尾に置けば足ります。

### エラベルの見解

担当する側から見ると、文面で最も差がつくのは、一段落目に「プロフィールのどこを見たか」を、担った仕事の中身の言葉で書けているかです。「ご経歴を拝見し、ぜひ」は誰にでも書けます。「〇〇向けの新規開拓を、提案から契約まで一人で担当されてきた点を拝見し」と書くと、受け取る側は「読んでいる」と分かり、次の段落に進みます。ここに書けるのは、見極めで○を付けた根拠そのものです。見極めと文面は別の工程ではなく、○の根拠がそのまま一段落目になります。エラベルで担当者を選ぶ企業には、「文面の一段落目に、その方の職歴の記述が入っていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、一段落目に、その人のプロフィールから拾った言葉が一つも無ければ、送らないこと。全員宛ての文面を上の人に送ると、上の人ほど返信しません。

## 優先度による使い分け

| 優先度 | 文面 | 時間の使い方 |
|---|---|---|
| 上 | 四つの段落を個別に書く。特に一と三 | 一人ずつ。ここに時間を使う |
| 中 | 型（二と四は共通）に、一を個別に足す。三は共通でよい | 一段落だけ書く |
| 下 | 送らない | 使わない |

型は、二と四を共通にした文面を、求人ごとに一つ用意します。「中」の人には、その型の先頭に、その人のプロフィールから拾った一段落を足します。一段落だけでも、「読んでいる」は伝わります。全員に同じ文面を送るより、中の人にも一段落足すほうが、返信の結果は変わります。優先度の付け方は[候補者リストの作り方](/media/fukugyo-skill-list/)に書いています。

## 件名

件名は、開かれるかどうかを決めます。本文が良くても、件名で開かれなければ届きません。

| 件名の条件 | 書き方 |
|---|---|
| 自分宛てだと分かる | その人の職種か経験の言葉を入れる |
| 役割が見える | 「〇〇の立ち上げ」「〇〇を一人で担う役割」 |
| 誰からか分かる | 依頼側の会社名か、送り主の役職 |

「【急募】」「【高年収】」のような記号と条件は入れません。件名の詳細と避ける形は[スカウトの件名の作り方](/media/scout-kenmei/)に書いています。

## 依頼側の名前で送る文面の確認

スカウトは、依頼側の会社の名前で届きます。副業の担当者が書いた文面でも、受け取る側から見れば依頼側の言葉です。

| 確認すること | 誰に |
|---|---|
| 二の「この役割がある理由」「任せる仕事」が実態と合っているか | 現場の責任者 |
| 三の「迷う理由への先回り」で、言ってよい範囲か（報酬の水準、働き方など） | 依頼側の採用担当 |
| 四の「次の一歩」を、誰が受けるか（面談の相手、日程の調整） | 依頼側の採用担当 |
| 送り主の名義（代表、現場の責任者、採用担当） | 依頼側 |
| 表現の可否（盛っていないか、法令や媒体の規約に触れないか） | 依頼側の決まりに従う |

型の文面は、送り始める前に一度確認を取ります。個別の一段落は、見極めの根拠を写すだけなので、毎回の確認は要らない形を依頼側と決めておきます。毎通確認を取ると、送信が止まります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「文面は一度作れば、あとは送るだけ」というものです。実際には、文面は返信の結果で書き換えるもので、最初の型が当たることはほとんどありません。返信が来た人の共通点（どの段落に反応したか、返信で何を聞いてきたか）を見ると、三の「迷う理由」がずれていた、二の「任せる仕事」が抽象的だった、と分かります。それを型に戻して書き換え、次の送信で試す。この往復を続けると、型が求人ごとに固まります。受ける側がその場で使える判断としては、返信が来たら、返信の本文で「候補者が最初に聞いてきたこと」を一言記録すること。それが次の型の三段落目になります。返信がゼロのときは、文面より先に疑うことがあります。順番は[返信ゼロが続くときに疑う順番](/media/scout-henshin-nashi-genin/)に書いています。

## 盛らない・条件を並べない・急かさない

| 避けること | 理由 | 代わりに |
|---|---|---|
| 実態より良い役割の説明 | 面談で「違った」となり、依頼側の信頼が落ちる | 二を、要件の一枚と現場の確認のとおりに |
| 年収や待遇の数字を本文の先頭に | 条件で釣る印象。数字は媒体の求人票の欄で見られる | 三で「報酬は現職の水準を踏まえてご相談」のように、迷う理由への先回りとして触れる程度に |
| 「急募」「今週中に」 | 急かされて引く | 四で、負荷の低い次の一歩を |
| 「あなたしかいない」 | 全員に送っていると分かる | 一で、具体の根拠を |
| 収入や昇進を保証するように読める表現 | 保証できない | 実績のあることだけを、実績として |

性別や年齢などに触れる表現や、それを示唆する言い回しは、募集や採用で法令上の決まりがあると一般に整理されているため、文面に入れず、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 一段落目に書くことが無い | 見極めの○の根拠が無い。優先度を見直す。中なら型の一段落、下なら送らない |
| 文面が長くなる | 会社紹介を二の一文に溶かす。条件を消す。四つの段落以外を削る |
| 依頼側が会社紹介を長く入れたがる | 「開いた瞬間に全員宛てと読まれる」構造を伝え、採用ページのリンクで代える |
| 返信は来るが、面談の日程が決まらない | 四の「次の一歩」が重い。「三十分の情報交換」「まずはメッセージで質問だけでも」に下げる |
| 上の人から返信が来ない | 一段落目が根拠になっていない。見極めの基準が印象に流れていないかも確かめる |
| 毎通、依頼側の確認待ちで止まる | 型を先に確認し、個別の一段落は確認なしで送る形を合意する |

## まとめ

- 返信が来ないのは、**開いた瞬間に「全員宛て」と読まれる**から
- **四つの段落**：その人の経歴に触れる／この役割がある理由と任せる仕事／迷う理由への先回り／返信しやすい結び
- 一段落目は**見極めで○を付けた根拠**を、担った仕事の中身の言葉で。根拠が無ければ送らない
- **上は個別に、中は型に一段落足す、下は送らない**
- 件名は**自分宛て・役割が見える・誰からか分かる**。記号と条件は入れない
- 文面は**依頼側の言葉**。型は事前に確認、個別の一段落は確認なしで送る形を合意
- **盛らない・条件を並べない・急かさない**。個別の判断は専門家にご確認ください
- 文面は**返信の結果で書き換える**。候補者が最初に聞いてきたことが、次の三段落目

## よくある質問

### 一段落目を書くのに時間がかかり、送る数が減ります

一段落目は、見極めのときに書いた「○の根拠」をそのまま使います。見極めと文面を別々にやると二度手間になるので、見極めのときに、○の根拠を「文面に貼れる一文」の形で書いておきます。それでも時間がかかるなら、上の人数を絞るか、中の人には型に一文だけ足す形にします。数を増やすために一段落目を省くと、返信が減り、結果として送った数の意味が無くなります。

### 依頼側から「もっと熱意のある文面にしてほしい」と言われました

熱意は、形容詞や感嘆符ではなく、「どこを見たか」の具体さと、「なぜいま採るか」の理由で伝わります。「御社の熱意は、一段落目の具体さと、二段落目の理由で伝えます。形容詞を足すと、全員宛てに見えます」と伝え、依頼側が挙げる熱意の中身（この事業をこうしたい、この役割にこういう人が要る）を、二段落目の「この役割がある理由」に書きます。感嘆符と「ぜひ」の連発は、返信を減らします。

### 返信が来たあとのやり取りも、副業の担当者が書きますか

契約の範囲によります。初回の返信への対応（日程の調整、質問への回答）を担当者が行うのか、依頼側に渡すのかを、送り始める前に決めておきます。担当者が対応する場合は、依頼側の名義で答える範囲（報酬、働き方、選考の流れ）を確認してからにします。答えられない質問は「担当の者から改めて」と依頼側に渡します。分担の型は[返信が来たあとの対応分担](/media/scout-daikou-henshin-taiou/)に書いています。
