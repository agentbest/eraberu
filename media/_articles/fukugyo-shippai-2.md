契約はスカウトの運用だった。数か月経った今、求人票も書き、面接の日程も組み、内定者への連絡もしている。単価は最初のままで、稼働は倍になっている。いつからこうなったのか、思い出せない。結論を先に書くと、**範囲の膨張は、一度の大きな追加ではなく、「ついでに」「今回だけ」「前の人はやっていた」の小さな積み重ねで起きます。一つ一つは断るほどではなく、気づいたときには稼働が枠を超えています。防ぐ線は三本で、「契約の範囲を工程で書く」「契約外の稼働を分けて記録する」「更新の節目で範囲と条件を直す」です。**膨張そのものが悪いのではなく、膨らんだ分が契約と条件に反映されないまま続くことが失敗です。範囲外の依頼への対応は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に、断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、抱え込みの構造は[断れずに抱え込む](/media/fukugyo-shippai-10/)にまとめています。

## 膨らむ五つの経路

範囲は、五つの経路から膨らみます。経路ごとに、依頼の形が違います。

| 経路 | 依頼の形 | なぜ受けてしまうか |
|---|---|---|
| 一、「ついでに」 | 「送信のついでに、返信の対応もお願いできますか」 | 隣の工程で、断るほどではないと感じる |
| 二、「今回だけ」 | 「今回だけ、面接の日程も組んでもらえますか」 | 一度なら、と受ける。次も来る |
| 三、「前の人はやっていた」 | 「前の担当者は、求人票も見てくれていました」 | 比べられて、自分もやらないといけないと感じる |
| 四、成果の後の期待 | 「スカウトがうまくいったので、次は内定者のフォローも」 | 評価された嬉しさで、範囲を考えずに受ける |
| 五、依頼側の型の不在 | 依頼側に型が無く、「どうすればよいか」を聞かれ、答えているうちに、その工程を担うことになる | 答えることと、担うことの線が曖昧になる |

五つの要点は、「一」の「ついでに」が、最も多く、最も気づきにくいことです。隣の工程は、自分の範囲と地続きに見え、受けることに違和感がありません。しかし、隣の工程を一つ受ければ、その隣がまた隣になり、地続きで範囲は広がり続けます。「五」は、依頼側に型が無い案件で起きやすく、専任がいない会社の依頼で注意が要ります。依頼側の型の有無は[どんな会社から依頼が来るのか](/media/fukugyo-qa-11/)に書いています。

## 膨らんだ後に起きること

範囲が膨らんだまま続くと、次のことが起きます。

| 起きること | 内容 |
|---|---|
| 稼働が枠を超える | 契約の範囲の稼働に、契約外の稼働が上乗せされ、本業の枠を削り始める |
| 単価が実質的に下がる | 同じ報酬で稼働が倍になれば、時間あたりの報酬は半分になる |
| 本来の範囲の品質が落ちる | 膨らんだ分に稼働を取られ、契約の範囲の工程が薄くなる |
| 更新のときに根拠が無い | 膨らんだ分を記録していなければ、「範囲が広がった」と示せず、条件を直せない |
| 依頼側の認識が固定される | 依頼側は「この範囲で、この報酬」が当たり前になり、戻すのが難しくなる |
| 範囲の一言が言えなくなる | 自分が何を担当しているかを、一言で言えなくなる。次の案件の範囲も決められない |
| 突然、続けられなくなる | 限界が来て、膨らんだ分も本来の分も止まる。[断れずに抱え込む](/media/fukugyo-shippai-10/) |

起きることの要点は、「依頼側の認識が固定される」ことです。膨らんだ範囲を数か月続けると、依頼側にとってそれが「契約の範囲」になります。後で「本来の範囲はここまで」と言っても、依頼側は「今までやっていたのに」と感じます。膨らんだ範囲が固定される前に、記録し、更新で直すことが要ります。

### エラベルの見解

相談で最も多い思い込みは、「範囲が広がるのは、依頼側に信頼されている証拠だから、よいことだ」というものです。半分は正しく、信頼されていなければ範囲は広がりません。ただ、広がった範囲が契約と条件に反映されないまま続くと、それは信頼の証拠ではなく、安く広く使われている状態になります。依頼側に悪気は無く、「頼めばやってくれる」が続いているだけですが、結果は同じです。

見ていて差がつくのは、範囲が広がったときに、それを「記録し、更新で条件に反映する」形にしているかです。広がった工程を稼働報告の「契約外」の行に書き、更新の二か月前に「範囲がこう広がったので、条件をこう直したい」と出す人は、範囲が広がるたびに条件が上がり、信頼と報酬が一緒に育っています。記録せずに受け続ける人は、範囲だけが広がり、条件は最初のままで、どこかで限界が来ています。エラベルでは、担当者の稼働報告に「契約外」の工程を分けて書く形をお願いし、更新の節目で範囲と条件を見直す形を取っています。範囲の膨張は、記録があれば成長になり、無ければ失敗になります。

## 依頼側も気づいていない構造

範囲の膨張は、依頼側が意図して起こしているのではなく、依頼側も気づいていないことが多いです。

| 依頼側の側で起きていること | 内容 |
|---|---|
| 「ついでに」を、追加と思っていない | 隣の工程を頼むとき、担当者は「小さいこと」と思っていて、範囲の追加とは認識していない |
| 担当者が替わり、範囲を知らない | 前任が広げた範囲を、新任は「最初からの範囲」と思っている |
| 型が無いので、範囲の線が引けない | 依頼側に採用の型が無いと、どこまでが外部の範囲かを、依頼側も決められない |
| 稼働の実態が見えていない | 外部の担当者の稼働がどれだけ増えているかは、報告に「契約外」の行が無ければ、依頼側には見えない |
| 断られないので、続けている | 断られたことが無いので、「頼めばやってくれる」が続く。悪気は無い |

構造の要点は、「依頼側には、範囲が広がっていることが見えていない」ことです。依頼側から見れば、「小さいことを頼んでいる」だけで、それが積み重なって稼働が倍になっているとは思っていません。だから、事実を見せれば、依頼側は「そんなに増えていたのか」となり、条件の見直しに応じることが多いです。事実を見せる形は[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/)に、見直しの進め方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に整理しています。

## 兆しの見つけ方

膨張が固定される前に、兆しがあります。

| 兆し | 何が起きているか |
|---|---|
| 稼働ログに、契約の工程に無い作業が増えている | 契約外の工程が積み上がっている。最初の兆し |
| 「ついでに」「今回だけ」と言われる回数が増えた | 膨張の経路が開いている |
| 自分の範囲を一言で言えなくなった | 範囲が地続きで広がり、線が消えている |
| 稼働報告に書けない稼働がある | 契約外の稼働を、報告に載せる根拠が無い |
| 更新の話が「今の条件で」と当然のように来る | 依頼側の認識が固定され始めている |
| 本来の範囲の工程が、以前より薄くなった | 膨らんだ分に稼働を取られている |
| 「前の人はやっていた」と言われた | 前任が広げた範囲を、引き継がされている |

兆しの要点は、「稼働ログの契約外の作業」が最初に見える兆しだということです。ログを付けていれば、契約の工程に無い作業が現れた時点で気づけます。ログが無ければ、稼働が枠を超えて初めて気づきます。ログの付け方は[稼働ログの付け方](/media/fukugyo-log/)に書いています。

## 膨張を防ぐ三つの線

三本の線を、契約の最初から引いておきます。

| 線 | 内容 | 使い方 |
|---|---|---|
| 一、契約の範囲を工程で書く | 「採用業務全般」ではなく「スカウトの検索・送信・一次返信・面接の設定まで」と、工程で書き、受けない工程も書く。契約書の範囲の条項に反映してもらう | 依頼が来たら「範囲の中か外か」を見る。外なら「範囲の外なので」と言える。[受ける範囲の決め方](/media/fukugyo-scope/)、[契約はどうなるか](/media/fukugyo-qa-5/) |
| 二、契約外の稼働を分けて記録する | 範囲外の依頼を受けた場合、稼働ログと稼働報告に「契約外」の行を作り、工程と時間を書く | 依頼側にも毎月見える。更新のときの根拠になる。書けない稼働は受けない |
| 三、更新の節目で範囲と条件を直す | 更新の二か月前に、一期分の契約外の記録を並べ、「範囲に入れて条件を直す」「依頼側に戻す」「止める」の選択肢を出す | 膨らんだ分を、契約と条件に反映する。固定される前に |

三本の要点は、「二」の記録が、「三」の見直しの根拠になることです。記録が無ければ、「範囲が広がった」は自分の感覚で、依頼側には示せません。記録があれば、「〇月から〇〇の工程が加わり、月に〇時間」と事実で示せ、依頼側は判断できます。範囲外の依頼が来たときの対応は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に、その場での断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

## 膨らんでしまった後の戻し方

すでに膨らんでいる場合、戻す順番があります。急に戻すと、依頼側との関係が崩れます。

| 手順 | 内容 |
|---|---|
| 一、契約の範囲と、実際の範囲を並べる | 契約書の範囲の条項と、稼働ログの実際の工程を並べ、差を一覧にする |
| 二、差の稼働を出す | 契約外の工程に、月にどれだけの時間を使っているかを、ログから出す |
| 三、依頼側に事実として見せる | 「契約の範囲は〇〇でしたが、現在は△△と□□も担当しており、月に〇時間になっています」。責めずに事実で |
| 四、三つの選択肢を出す | 「範囲に入れて条件を見直す」「御社の社内に戻す（型と手順を渡す）」「止める（期限を切って）」。依頼側に選んでもらう。[改善提案の伝え方](/media/fukugyo-kaizen-teian/) |
| 五、決まったら契約に反映する | 更新なら新しい契約書に。途中なら覚書かメールで。文面に残す |
| 六、範囲の一言を書き直す | 新しい範囲を一言にし、登録先のプロフィールも直す。[プロフィールの書き方](/media/fukugyo-profile/) |

戻し方の要点は、「四」で「現状のまま続ける」を選択肢に入れないことです。「現状のまま」を入れると、依頼側はそれを選び、膨らんだ範囲が固定されます。範囲に入れて条件を直すか、戻すか、止めるかの三つにし、「今の範囲で今の条件」は無いことを示します。依頼側に戻すときは、型と手順を渡せば、「投げ返した」ではなく「引き継いだ」になります。戻し方の詳細は[断れずに抱え込む](/media/fukugyo-shippai-10/)に書いています。

## 範囲を広げるべきときとの見分け

範囲が広がることは、失敗ではなく成長でもあります。膨張と成長の違いを見分けます。

| 項目 | 膨張（失敗） | 成長（広げるべき） |
|---|---|---|
| 広がり方 | 「ついでに」「今回だけ」で、なし崩しに | 更新の節目で、意図して |
| 契約への反映 | 反映されていない。契約の範囲は最初のまま | 新しい範囲が契約に書かれている |
| 条件への反映 | 条件は最初のまま | 範囲に合わせて稼働と単価が見直されている |
| 記録 | 契約外の稼働として記録されていないか、記録があっても使われていない | 記録を根拠に、範囲と条件が決まっている |
| 自分の範囲の一言 | 言えなくなっている | 新しい一言になっている |
| 依頼側の認識 | 「頼めばやってくれる」 | 「この範囲を、この条件で頼んでいる」 |
| 工程の帯 | 同じ帯の工程が横に増えている（隣の工程） | 上の帯の工程が加わっている（型を作る、設計する） |

見分けの要点は、「契約と条件に反映されているか」です。同じ工程が加わるのでも、更新の節目で契約に書かれ、条件が見直されていれば成長で、なし崩しに加わり条件が最初のままなら膨張です。広げること自体を避けるのではなく、広げるときは節目で、契約と条件と一緒に広げます。広げる順番は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に、工程の帯の考え方は[どれくらい稼げるか](/media/fukugyo-qa-2/)に整理しています。

### エラベルの見解

担当する側から見ると、範囲が広がって収入と信頼が育っている人と、範囲が広がって疲れて止まった人は、広がった範囲の中身は似ています。違いは、広がった分を記録し、更新の節目で契約と条件に反映しているかどうかです。前者は、範囲が広がるたびに条件が上がり、依頼側からも「この範囲をこの条件で頼んでいる」と認識されています。後者は、範囲だけが広がり、条件は最初のままで、依頼側からは「頼めばやってくれる人」と認識され、限界が来て止まっています。

順番として、契約の範囲を工程で書き、範囲外の依頼が来たら線に当て、受けるなら契約外として記録し、稼働報告に契約外の行を毎月書き、更新の二か月前に一期分を並べて、範囲に入れるか戻すか止めるかを依頼側と決め、契約と条件に反映する。この順番で、範囲の広がりは膨張ではなく成長になります。エラベルでは、担当者の稼働報告に契約外の工程を分けて書く形をお願いし、更新の節目で範囲と条件を見直す形を取っています。範囲は、広げるものではなく、記録して反映するものです。

## まとめ

- 範囲の膨張は**「ついでに」「今回だけ」「前の人は」の小さな積み重ね**で起き、気づくのは稼働が枠を超えてから
- 膨らんだまま続くと**稼働が枠を超え・単価が実質的に下がり・本来の品質が落ち・更新の根拠が無く・依頼側の認識が固定される**
- 依頼側には**範囲が広がっていることが見えていない**。事実を見せれば応じることが多い
- 兆しは**稼働ログの契約外の作業**が最初。範囲の一言が言えなくなったら、線が消えている
- 線は三本。**契約の範囲を工程で書く・契約外の稼働を分けて記録する・更新の節目で範囲と条件を直す**
- 戻すときは**契約と実際を並べ・差の稼働を出し・事実で見せ・三つの選択肢（現状維持は入れない）・契約に反映・一言を書き直す**
- **契約と条件に反映されていれば成長、されていなければ膨張**

## よくある質問

### 「ついでに」と頼まれた小さな作業を、毎回断るのは角が立ちませんか

毎回断る必要はなく、受けるなら「契約外」として記録し、更新で反映すれば、角は立ちません。角が立つのは、その場で断ることではなく、受け続けて限界が来て突然止まることです。受けるときに「これは契約の範囲外なので、稼働の記録に契約外として残し、更新のときにご相談します」と一言添えれば、依頼側は「範囲外だと認識している」と分かり、更新の見直しも驚かれません。その場の判断の仕方は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に整理しています。

### 前任が広げた範囲を、自分が引き継いでいます。戻せますか

戻せます。前任の範囲は前任の契約で、自分の契約は自分の範囲です。「前任の方が担当されていた〇〇は、私の契約の範囲には入っていないので、範囲に入れて条件を見直すか、御社の社内で担当していただくか、ご相談したい」と、契約の前か、最初の更新で出します。前任との比較で「やってくれていた」と言われても、「前任の方の契約の範囲と、私の範囲は別です」と、事実で線を引きます。担当者が替わった後の範囲の確認は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)にも書いています。

### 範囲を広げたいのですが、膨張にならないように広げるにはどうすればよいですか

更新の節目で、意図して広げます。「次の期は、〇〇の工程を範囲に加えたい。稼働は月に〇時間増え、単価はこう見直したい」と、範囲と稼働と条件を一緒に出し、契約に反映してもらいます。なし崩しに加わった工程を後から契約に入れるのではなく、加える前に契約に入れる順番です。広げる工程は、同じ帯の隣の工程より、上の帯（型を作る、設計する）の工程を選ぶと、単価の帯も上がります。広げる順番は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に、条件の出し方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。
