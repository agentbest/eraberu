医療業界の会社（病院・診療所・訪問の事業所）が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。看護師の離職が採用を上回り、募集が止まらない。資格と配置の基準に合う要件が無く、採っても配置できない。夜勤と診療科の実態を先に出さず、入職後に離れる。病院と診療所と訪問の型と職種で経路が違うのに、一つの媒体で募集している。看護部長と各部門の責任者の面接の枠が取れず、日程が延びて、事務と補助は他で決まる。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**医療業界の採用課題は、離職・資格・実態・経路・枠の五つに分解し、自社の記録（職種ごとの離職の時期と理由、配置できなかった件数、辞退と早期離職の理由、型と職種ごとの応募の数と経路、段階ごとの日数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、紹介会社に費用を使って採り、離れて、また募集する、という往復になります。代行に出す工程の切り分けは[医療業界の採用代行](/media/rpo-iryo-rpo/)に、職種ごとの母集団形成は[看護師の母集団形成](/media/rpo-kangoshi-boshuudan/)や[薬剤師の母集団形成](/media/rpo-yakuzaishi-boshuudan/)に書いています。ここでは、医療業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 離職 | 看護師の募集が止まらない。採っても一年以内に離れる | 職種ごとの離職の時期と理由。募集の回数 |
| 資格 | 採ったが、資格の区分や経験で配置と人員の基準に合わない | 配置できなかった件数。要件に区分と経験の範囲が無い |
| 実態 | 面接で「夜勤の回数は聞いていない」。入職後に「診療科の忙しさが違う」 | 辞退と早期離職の理由が「夜勤」「診療科」「人員」 |
| 経路 | 病院は来るが訪問が来ない。看護師は来るが事務が来ない（またはその逆） | 型と職種ごとの応募の数と経路 |
| 枠 | 日程が延びて「他で決まった」。事務と補助が先に他へ | 段階ごとの日数。責任者の枠の数 |

五つは同時に起きることもありますが、直すのは一つずつです。医師の採用は、紹介と大学のつながりで動く別の問題なので、五つとは分けて扱います。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 職種ごとの離職の時期と理由、募集の回数 | 離職が採用を上回っていれば離職。入口より先に |
| 二 | 要件に資格の区分と経験の範囲があるか。配置できなかった件数 | 無ければ資格 |
| 三 | 辞退と早期離職の理由 | 「夜勤」「診療科」「人員」なら実態 |
| 四 | 型と職種ごとの応募の数と経路 | 偏りがあれば経路 |
| 五 | 段階ごとの日数 | 長ければ枠 |

一が最初なのは、離職を止めずに入口を直しても、穴を埋め続けることになるからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

医療業界で最も多い詰まりは「離職」で、しかも職種で分けずに見られていることです。看護師の離職と事務の離職は、時期も理由も違います。看護師は「夜勤の開始が早かった」「プリセプターがいなかった」「診療科の忙しさが聞いていたのと違った」が並び、事務は「業務の範囲が広すぎた」「教える人がいなかった」が並びます。職種を混ぜて「離職が多い」と言うと、直す場所が見えません。エラベルで担当者を選ぶ企業には、「看護師と事務で、離職の理由を分けて記録していますか」を、私たちから先に聞いています。答えが「まとめて数えている」なら、代行の前に記録の分け方です。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 離職の課題：職種ごとに理由が違う

| 職種 | 離職の理由 | 直す場所 |
|---|---|---|
| 看護師 | 夜勤の開始が早すぎた | 受け入れの体制（夜勤の開始の時期、最初の三か月の到達点） |
| 看護師 | プリセプターがいなかった | 教える人を決める。週次の接点 |
| 看護師 | 診療科の忙しさや人員の配置が聞いていたのと違う | 求人票と見学で実態を |
| 事務・補助 | 業務の範囲が広すぎた | 求人票に範囲を。最初の一か月の到達点 |
| 事務・補助 | 教える人がいなかった | 教える人を決める |
| 共通 | 条件 | 会社の判断 |
| 共通 | 私的な事情 | 直す場所は無い。上を確かめた後 |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 資格の課題：区分と経験の範囲が要件に無い

| 状態 | 直し方 |
|---|---|
| 「看護師募集」だけで、資格の区分（正看護師・准看護師）と経験の範囲が無い | 会社と専門家で、資格の区分と配置と人員の基準の関係を整理し、「必須・歓迎」の区分に |
| 採ってから配置に合わないと分かる | 書類の一次確認で区分と経験の範囲を照合 |
| 事務と補助に「資格不問」と書いたが、実際は特定の経験が要る | 要件を「〇〇の経験」に言い換えて書く |

資格と配置と人員の基準の関係は、法令上の整理があると一般に整理されているため、会社と専門家（社労士等）で整理します。代行は照合まで。個別の判断は専門家にご確認ください。要件の作り方は[看護師の採用要件の作り方](/media/rpo-kangoshi-youken/)に書いています。

## 実態の課題：夜勤と診療科を先に出していない

| 求人票に無いこと | 書き方 |
|---|---|
| 夜勤の回数と形 | 「月に〇回程度、二交代か三交代か」の実態 |
| 夜勤の開始の時期 | 「最初の三か月は日勤で、プリセプターと一緒に」の実態 |
| 診療科と忙しさ | 「〇〇科で、〇〇の患者が中心」の実態 |
| 人員の配置 | 「日勤〇名、夜勤〇名の体制」の実態 |
| 事務の業務の範囲 | 「受付・会計・レセプトのどこまでか」の実態 |

見学を選考の段に置くと、候補者が実態を見て判断でき、入職後のずれが減ります。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

### エラベルの見解

医療業界で見落とされやすいのは「経路」が職種と型で違うことです。病院の看護師は資格の区分に合う媒体と学校と紹介で動き、訪問の看護師は地域の経路と知人で動き、事務と補助は掲載型で速さで決まります。全部を一つの媒体に出して「応募が少ない」と言うと、どの職種にも刺さりません。「病院の看護師（夜勤あり、〇〇科）」「訪問の看護師（日勤、一人で訪問）」「医療事務（受付と会計）」と分け、職種と型ごとに経路と文面を変える。エラベルで担当者を選ぶ企業には、「看護師と事務で、求人票と経路を分けていますか」を、私たちから先に聞いています。分けていなければ、媒体を増やす前に分け方です。経路の組み合わせは[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に書いています。

## 経路の課題：職種と型で違う

| 職種と型 | 動く理由 | 合う経路 |
|---|---|---|
| 病院の看護師 | 診療科の経験を積みたい、夜勤の手当、教育の体制 | 資格の区分に合う媒体、学校、紹介 |
| 訪問の看護師 | 一人で患者と向き合いたい、日勤 | 地域の経路、知人 |
| 診療所の看護師 | 日勤、家の近く | 地域の掲載型、知人 |
| 薬剤師・技師 | 専門の設備と症例 | 資格の区分に合う媒体、学校 |
| 事務・補助 | 家の近く、速い返事 | 掲載型、地域の経路 |

職種と型ごとに求人票と経路を分け、職種と型ごとに応募の数を記録します。

## 枠の課題：看護部長と責任者が現場で手一杯

| 状態 | 直し方 |
|---|---|
| 日中の面接が取れない | 申し送りの後、外来の終わりの後、オンライン、の枠を週に一つ先に預かる |
| 候補者の希望を聞いてから調整 | 枠を預かっているので、候補を三つ出して即日で確定 |
| 面接と見学が別の日 | 同じ日に組む |
| 看護部長が全段に出る | 一次（書類の照合と一次対応）を外に出し、看護部長は面接と見学だけ |
| 事務と補助の返事が数日後 | 一次対応を外に出し、翌営業日中に返す |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 離職 | 退職面談の型、職種ごとの記録の分類 | 受け入れの体制（夜勤の開始の時期、プリセプター）、実態の見直し |
| 資格 | 書類での区分と経験の照合 | 区分と配置の整理（会社と専門家） |
| 実態 | 求人票に落とす作業、見学の日程 | 実態を語る。見学で何を見せるか |
| 経路 | 職種と型ごとの経路の運用 | 分け方と求人票の実態 |
| 枠 | 日程の運用、一次対応 | 枠の形を変えて出す |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[医療業界で採用代行が機能する条件・機能しない条件](/media/rpo-iryo-jirei/)に書いています。

## まとめ

- 「採れない」には**離職・資格・実態・経路・枠**の五つが混ざっている。医師は別に扱う
- **記録で一つに特定してから直す**。最初は職種ごとの離職の時期と理由と募集の回数
- 最も多い詰まりは**離職**で、職種を混ぜて数えられている。看護師と事務で分ける
- **資格・配置・人員の基準は会社と専門家**。個別の判断は専門家にご確認ください
- 実態（夜勤・診療科・人員・業務の範囲）を**先に出し、見学を段に**
- 経路は**職種と型ごとに分ける**
- 枠は**申し送りの後・外来の後・オンラインで週に一つ**先に預かり、事務と補助は翌営業日中に返す

## よくある質問

### 看護師は業界全体で足りないので、自社だけでは直せないのではないですか

同じ地域で離職が少なく募集が止まっている病院はあります。違いは、夜勤の開始の時期を遅らせているか、プリセプターがいるか、診療科の実態を先に出しているか、職種と型で経路を分けているか、です。「業界全体」にすると、直す場所が消えます。五つを記録で確かめ、一つずつ直しても採れないなら、条件の判断に進みますが、それは五つを確かめた後です。

### 紹介会社の費用が重く、直接の応募を増やしたいです

職種と型ごとに経路（資格の区分に合う媒体、学校、地域の掲載型、知人、地域の紹介）を並べ、使っていない経路を開きます。求人票に実態と受け入れ（夜勤の開始の時期、プリセプター）を書くと、直接の応募が定着し、紹介会社への依存が減ります。紹介会社を使う場合も、依頼書を「型・診療科・資格の区分・実態」で渡し、返事を翌営業日中に返すと、推薦の質が変わります。経路の比重は、記録（経路ごとの入職と定着の件数）を並べて会社が決めます。紹介会社との付き合い方は[人材紹介会社との折衝の進め方](/media/rpo-task-agent-taiou-susumekata/)に書いています。

### 事務と補助が採れないのは、条件が低いからではないですか

条件の前に、返事の速さを確かめます。事務と補助は複数に同時に応募し、先に返事が来た所で決まるため、返事が数日後なら条件を上げても届きません。「応募から返事までの日数」を記録し、翌営業日中に返す形にしてから、応募の数と辞退の理由を見ます。それでも辞退の理由が「条件」に集まるなら、会社の判断に進みます。順番を逆にすると、条件を上げても速さで負けたままです。
