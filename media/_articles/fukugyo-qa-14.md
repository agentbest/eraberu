副業の案件の相談が来た。依頼側は本業の会社とは業界が違うので、競合ではないと思うが、募集している職種は本業でも採用している職種だ。これは競合になるのか、受けてよいのかが分からない。結論を先に書くと、**本業の会社と依頼側が競合になるかは、事業が同じかどうかだけでは決まりません。「事業の重なり」「候補者の重なり」「情報の流れ」の三つの軸で見て、一つでも重なるなら、受ける前に本業の会社の規定と、依頼側の両方に確認します。**業界が違っても、同じ職種を同じ時期に同じ媒体で採用していれば、候補者が重なり、本業と副業の両方に不利益が出ます。逆に、業界が近くても、職種も地域も違えば、重ならないことがあります。競合かどうかは、業界の名前ではなく、実際に何が重なるかで判断します。利益相反の詳しい整理は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、本業の規定の確認は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、踏み込みすぎない線の引き方は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)にまとめています。規定と契約の解釈は、専門家にご確認ください。

## 事業だけでは足りない理由

「業界が違えば競合ではない」という判断は、人事の副業では足りません。人事の副業は、採用という同じ市場で動くからです。

| 見方 | 見落とすこと |
|---|---|
| 業界で見る | 業界が違っても、同じ職種（エンジニア、営業、管理部門）を採用していれば、候補者の市場は同じ |
| 商品やサービスで見る | 商品が違っても、同じ地域で同じ規模の会社なら、採用の候補者は重なる |
| 会社の名前で見る | 名前が違っても、親会社や関連会社が本業と関係していることがある |
| 依頼側の説明で見る | 依頼側は自社の競合を知っていても、担当者の本業の会社との関係は知らない |
| 契約書の競業の条項で見る | 条項は「同業他社」と書かれていることが多く、候補者の重なりまでは書かれていない |

足りない理由の要点は、「人事の副業は、依頼側の事業ではなく、依頼側の採用に関わる」ことです。本業の会社と依頼側が事業で競合していなくても、採用で競合していれば、自分が両方の採用に関わることになり、候補者の情報や採用の進め方が、意図せずどちらかに流れます。採用の市場で見る視点は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 三つの軸で見る

競合かどうかは、三つの軸で見ます。どれか一つでも重なれば、確認が要ります。

| 軸 | 重なる例 | 重ならない例 |
|---|---|---|
| 事業の重なり | 本業の会社と同じ商品やサービスを、同じ顧客に売っている。親会社や関連会社が同じ | 商品も顧客も違う。資本の関係も無い |
| 候補者の重なり | 同じ職種を、同じ地域で、同じ時期に、同じ媒体で採用している。本業で接した候補者が、依頼側の候補者にもなり得る | 職種が違う。地域が違う。本業では採用していない職種 |
| 情報の流れ | 本業で知った採用の進め方、候補者の傾向、媒体の運用の工夫が、依頼側で使える。逆に依頼側で知ったことが本業で使える | 本業の採用と依頼側の採用が、進め方も市場も違い、一方で知ったことがもう一方で役に立たない |

三つの要点は、「候補者の重なり」が最も見落とされることです。本業がメーカーで、依頼側がサービス業でも、両方がエンジニアを東京で採用していれば、候補者は重なります。本業でスカウトを送った候補者に、副業でもスカウトを送る場面が起きます。これは、候補者から見れば「同じ人から別の会社の案内が来た」ことになり、本業と依頼側の両方の信用に関わります。候補者の情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「業界が違えば、競合の心配は要らない」というものです。実際には、登録の相談で「本業とはまったく違う業界なので大丈夫です」と言った方の案件で、後から候補者の重なりが分かった例があります。本業も依頼側も、同じ職種を同じ地域で採用していて、担当者が本業で接した候補者が依頼側の候補として出てきました。担当者は業界の違いで判断していたので、候補者の重なりを想定していませんでした。

見ていて差がつくのは、受ける前に「本業ではどの職種を、どの地域で、どの媒体で採用しているか」を自分で整理しているかです。整理している人は、依頼側の相談が来たとき、職種・地域・媒体の重なりをすぐ見て、重なるなら受けないか、依頼側に伝えて判断を仰いでいます。整理していない人は、業界の違いだけで受け、後で気づきます。エラベルでは、登録の際に本業の業界と、本業で採用している職種の範囲を聞き、依頼側の相談と重なる可能性がある案件は、提示の前に担当者に確認しています。競合の判断は、業界ではなく、採用の市場で行います。

## 受けてよい案件と避ける案件の線

三つの軸で見た結果を、受ける・確認する・避けるの三つに分けます。

| 三つの軸の状態 | 判断 | やること |
|---|---|---|
| どれも重ならない | 受けてよい | 本業の規定の一般的な確認（副業の許可）だけ |
| 候補者だけ重なる（職種・地域・時期・媒体のどれかが同じ） | 確認する | 本業の会社の規定を確認し、依頼側に「本業で同じ職種を採用している」と伝え、依頼側の判断を仰ぐ。受けるなら、本業で接した候補者には副業で接しない線を決める |
| 情報の流れだけ重なる | 確認する | 本業で知った進め方や傾向を、依頼側で使わない線を自分で引けるか。引けないなら避ける |
| 事業が重なる | 避ける | 本業の規定で競業が禁じられていることが多い。禁じられていなくても、依頼側から見て「競合の社員が自社の採用に入る」形になり、依頼側も避ける |
| 事業と候補者の両方が重なる | 避ける | 本業と依頼側の両方に不利益が出る。判断の余地は無い |
| 親会社や関連会社が同じ | 避けるか、両方に確認 | 資本の関係は、事業の重なりと同じ扱い。本業の会社のグループの規定を確認 |

線の要点は、「候補者だけ重なる」を確認なしで受けないことです。ここが最も判断が分かれ、本人は「業界が違うから」と受けがちです。本業の規定と依頼側の判断の両方を確認し、受けるなら、本業で接した候補者には副業で接しないという線を、自分の中で決めておきます。線の引き方は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)にも書いています。

## 本業の会社の規定を確認する

競合の判断は、自分の感覚ではなく、本業の会社の規定に沿って行います。

| 確認すること | 見る場所 | 要点 |
|---|---|---|
| 副業の許可の範囲 | 就業規則の副業に関する条項 | 「同業他社での副業を禁ずる」のような競業の制限があるか |
| 競業の定義 | 就業規則、誓約書、入社時の書類 | 「同業」が事業で定義されているか、より広いか |
| 届け出の要否 | 副業の申請の様式 | 依頼側の業種や業務の内容を届け出る欄があるか |
| 秘密保持の範囲 | 入社時の誓約書 | 本業で知った候補者の情報や採用の進め方が、秘密保持の対象か |
| 退職後の競業の制限 | 誓約書 | 副業の依頼側が、退職後の制限の対象になり得るか |

規定の要点は、「競業の定義が事業で書かれていても、秘密保持の範囲で候補者の情報が対象になっていることが多い」ことです。競業の条項に触れなくても、本業で知った候補者の情報を副業で使えば、秘密保持に触れます。規定を読んで分からない場合は、本業の会社の窓口に「このような副業は規定に触れるか」を確認するか、社会保険労務士などの専門家に相談します。届け出の書き方は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。規定の解釈は、専門家にご確認ください。

## 依頼側に伝えるべきこと

競合の可能性は、本業の会社だけでなく、依頼側にも関わります。依頼側にも、受ける前に伝えます。

| 伝えること | 伝え方 | 理由 |
|---|---|---|
| 本業の業界 | 「本業は〇〇業界の会社です」。会社名は出さない | 依頼側が、自社との事業の重なりを判断できる |
| 本業で採用している職種 | 「本業でも〇〇職を採用しています」 | 依頼側が、候補者の重なりを判断できる |
| 本業で接した候補者には接しない線 | 「本業で接点のある候補者には、御社の案件では接しません」 | 依頼側が、担当者の線引きを知る |
| 本業の情報を持ち込まない線 | 「本業の採用の進め方や候補者の情報は、御社の案件では使いません」 | 依頼側が、担当者の情報の扱いを知る |
| 本業の規定の確認の状況 | 「本業の規定では、この案件は問題ないことを確認しています」 | 依頼側が、後から本業の問題で担当者が止まる不安を持たない |

伝える要点は、「本業の会社名は出さない」ことです。業界と職種を伝えれば、依頼側は重なりを判断でき、会社名まで出す必要はありません。会社名を出すと、依頼側がその会社との関係で判断し、本業の情報を副業に持ち込んだ形にもなります。依頼側が「本業の会社名を教えてほしい」と言った場合は、「業界と職種でご判断いただければ」と返します。本業の情報の線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 途中で競合になったときの扱い

受けたときは重なっていなくても、途中で重なることがあります。そのときの扱いを決めておきます。

| 変化 | 扱い |
|---|---|
| 本業の会社が、依頼側と同じ職種の採用を始めた | 候補者の重なりが発生。本業の規定を確認し、依頼側に伝え、線（本業で接した候補者には接しない）を守れるかを見る。守れないなら、更新の節目で終える |
| 依頼側が、本業の会社と同じ事業を始めた | 事業の重なりが発生。本業の規定で競業に当たる可能性。本業の窓口か専門家に確認し、該当するなら終える |
| 本業で異動し、採用の担当になった | 情報の流れが変わる。本業で知る採用の情報が増え、副業に持ち込まない線が難しくなる。線を引き直すか、終える |
| 依頼側が本業の会社の関連会社に買収された | 資本の関係が発生。両方に確認し、多くの場合は終える |
| 本業で接した候補者が、依頼側の候補に出てきた | その候補者には副業で接しない。依頼側に「別の案件で接点のある候補者がいる」とだけ伝え、他の担当者に対応してもらう |

変化の要点は、「重なりに気づいたら、隠さずに両方に伝える」ことです。途中で重なったことを黙って続けると、後で分かったときに、本業と依頼側の両方から「知っていて続けた」と見られます。気づいた時点で伝え、判断を本業の規定と依頼側に委ねれば、終えることになっても関係は保てます。案件を終えるときの手順は[引き継ぎの進め方](/media/fukugyo-hikitsugi/)に、終えた後の入口は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に整理しています。

### エラベルの見解

担当する側から見ると、競合の問題で止まった人は、「業界が違うから大丈夫」と自分で判断して受けた人です。三つの軸で見て、重なりに気づき、本業の規定と依頼側に確認してから受けた人は、問題になっていません。確認の手間は、受ける前の数日で済み、それを省いて後で分かったときの損失は、本業と副業の両方に及びます。

順番として、本業で採用している職種・地域・媒体を自分で整理し、依頼側の相談が来たら三つの軸で重なりを見て、重なるなら本業の規定を確認し、依頼側に業界と職種を伝えて判断を仰ぎ、受けるなら線を決めて守り、途中で重なったら隠さず伝える。この順番で、競合の問題は避けられます。エラベルでは、登録の際に本業の業界と採用している職種を聞き、依頼側の相談との重なりを見て提示しているので、担当者が一人で判断する場面を減らしています。競合の判断は、担当者だけの責任にせず、窓口と依頼側と本業の規定で支えるものです。

## まとめ

- 競合かどうかは**事業の重なり・候補者の重なり・情報の流れ**の三つの軸で見る。業界の名前では決まらない
- **候補者の重なり**が最も見落とされる。業界が違っても、同じ職種を同じ地域で採用していれば重なる
- 判断は**どれも重ならない→受ける・候補者か情報だけ重なる→確認する・事業が重なる→避ける**
- 本業の規定は**競業の定義と秘密保持の範囲**を見る。候補者の情報は秘密保持に触れることが多い
- 依頼側には**本業の業界と職種と線引き**を伝える。会社名は出さない
- 途中で重なったら**隠さず両方に伝え、判断を委ねる**。終えることになっても関係は保てる

## よくある質問

### 本業が人事ではなく、別の職種です。それでも競合を気にする必要がありますか

本業が人事でなくても、本業の会社が依頼側と同じ職種を採用していれば、候補者の重なりは起きます。ただし、本業で採用に関わっていなければ、候補者の情報や採用の進め方を知る機会は少なく、情報の流れの重なりは小さくなります。事業の重なりと、本業の規定の競業の制限は、職種に関わらず確認します。本業が人事でない場合の副業の始め方は[人事の副業に向いている人](/media/fukugyo-tekisei/)にも書いています。

### 依頼側から「本業の会社の採用のやり方を教えてほしい」と言われました

本業の採用の進め方は、本業の会社の情報で、依頼側に伝えることは情報の持ち出しになります。「本業の情報はお伝えできませんが、一般的な進め方として〇〇があります」と、自分の判断の仕方や公開されている一般的な方法として答えます。依頼側が本業の情報を求め続けるなら、その案件は情報の流れの重なりが大きく、続けるのが難しい案件です。情報の線は[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)に整理した線と同じです。

### 本業の会社に、副業の依頼側の業種を届け出ないといけませんか

本業の会社の副業の申請の様式に、依頼側の業種や業務の内容を書く欄があれば、届け出ます。欄が無くても、競業の制限がある場合は、依頼側の業種が制限に当たらないかを、本業の窓口に確認しておくと、後で問題になりません。届け出るときも、依頼側の会社名は、依頼側との秘密保持で出せないことがあるので、業種と業務の内容で届け出る形にし、会社名が要るかは本業の窓口に確認します。届け出の書き方は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、規定の解釈は専門家にご確認ください。
