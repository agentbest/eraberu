「面接官の見る目が無い」「面接で見抜けなかった」。依頼側からこう聞くと、面接官の研修を提案したくなります。ただ、面接がうまくいかない原因のほとんどは、面接官の腕ではなく、「何回で、誰が、何を確かめ、どう記録し、誰が決めるか」が決まっていないことです。設計が無いと、腕の良い面接官でも、段階ごとに同じことを聞き、記録は印象になり、決める人が曖昧なまま内定が出ます。結論を先に書くと、**面接の設計は、回数と段階・各段の面接官・各段で確かめる項目・記録の形・決める人の五つを先に決め、要件の一枚の「面接で確かめる項目」を段階に割り振り、面接官に一枚で渡し、記録は観点ごとに事実と判断を分け、決めるのは依頼側に残します。**要件の一枚の作り方は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)に、面接を実施する側で受けるときの注意は[面接代行を受けるときの注意](/media/fukugyo-mensetsu-daikou-chuui/)に書いています。ここでは、設計の型に絞ります。

## 面接官の腕ではなく設計の問題

| 起きること | 設計の欠け |
|---|---|
| 一次と二次で同じことを聞く | 各段で確かめる項目が割り振られていない |
| 面接官によって評価が違う | 観点と基準と記録の形が揃っていない |
| 「人柄が良い」で通る | 確かめる項目が性質の言葉のまま |
| 最終で経営者が「違う」と言い、全部やり直し | 経営者が確かめることが最終に置かれていない。決める人が曖昧 |
| 記録が残らず、辞退の理由も入社後のずれも振り返れない | 記録の形が無い |

評価のばらつきの構造は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。見る目を揃えるのではなく、設計を揃えます。

## 設計で決める五つ

| 決めること | 中身 |
|---|---|
| 回数と段階 | 何回か。各段の役割（一次・二次・最終）。多いほど候補者が流れる |
| 各段の面接官 | 誰が出るか。役割で決める（現場の責任者、一緒に働く人、経営者） |
| 各段で確かめる項目 | 要件の一枚の「面接で確かめる項目」を段階に割り振る。重ねない |
| 記録の形 | 観点ごとに、事実（候補者が語った場面）と判断（基準に照らしてどうか）を分けて書く |
| 決める人 | 各段の通過を誰が決めるか。最終の決定は誰か。面接官の多数決にしない |

五つを一枚にして、依頼側と合意してから面接を始めます。途中で変えると、前後の候補者で基準が変わります。

### エラベルの見解

担当する側から見ると、面接の設計で最も差がつくのは、「各段で確かめる項目を重ねない」ことです。受ける側は、一次で全部を確かめようとして、一次が長くなり、二次でも同じことを聞き、候補者は「何度も同じ話をさせられた」と感じます。一次は「経歴で読めたことの確認」、二次は「性質や動き方を場面で聞く」、最終は「決め手になる情報を渡し、候補者の迷いに答える」と割り振ると、各段が短くなり、候補者の負担が減り、面接官も自分の段で何を聞けばよいかが明確になります。エラベルで担当者を選ぶ企業には、「一次と二次で、確かめることが分かれていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、要件の一枚の「面接で確かめる項目」を一つずつ、一次・二次・最終のどれか一つに振ること。二つの段に振った項目があれば、どちらか一つにします。

## 段階への割り振り

| 段 | 確かめること | 面接官 | 形 |
|---|---|---|---|
| 一次 | 経歴で読めた必須が、本当か（担った範囲、役割、一人でか） | 現場の責任者 | 職歴を追い、「その仕事で、あなたが担った部分は」と範囲を聞く |
| 二次 | 性質や動き方（要件の「面接で確かめる項目」の中心）。一緒に働けるか | 一緒に働く人、隣の部門 | 「〇〇した場面を、具体的に」と過去の場面を聞く |
| 最終 | 決め手。候補者の迷いに答え、会社の方針と合うか | 経営者 | 見極めより、候補者が決めるための情報を渡す |

段階の数は依頼側の判断です。三段が多ければ二段に、一次と二次を同日に、という形もあります。段が増えるほど候補者が流れるので、段を増やす提案はしません。過去の場面を聞く型は[面接で何を聞けばよいか分からない](/media/rpo-mensetsu-shitsumon/)に書いています。

## 面接官に渡す一枚

| 項目 | 中身 |
|---|---|
| この段の役割 | 一次なら「経歴の確認」、二次なら「場面を聞く」 |
| 確かめる項目 | この段に振られた項目だけ。三つ前後 |
| 各項目の聞き方 | 「〇〇した場面を具体的に」の形で、項目ごとに一つ |
| 基準 | 各項目で、通す・迷う・通さないの目安を一行ずつ |
| 聞かないこと | 他の段で確かめる項目。基準にしてはいけない項目 |
| 候補者に渡すこと | 役割の実態、次の段の案内。候補者の質問への答え方 |
| 記録の形 | 下の表 |

一枚は求人ごとに作り、段ごとに一枚です。面接官が替わっても同じ一枚を渡します。候補者の氏名と経歴の全文は載せず、媒体のIDか応募の番号と、前の段の記録の要約だけにします。

## 記録の形：事実と判断を分ける

| 項目 | 事実（候補者が語った場面） | 判断（基準に照らして） |
|---|---|---|
| 確かめる項目一 | 「〇〇の案件で、〇〇部門と対立し、〇〇して合意まで持っていった」 | 通す（基準：他部門との合意の場面を具体に語れる） |
| 確かめる項目二 | 「前職では上司の指示で動いていたことが多い」 | 迷う（基準：決まりの無いことを自分で決めた場面） |
| 確かめる項目三 | 語れなかった | 通さない |
| 候補者の質問と迷い | 「リモートの頻度」「次の転職での見え方」 | （判断は書かない。次の段への引き継ぎ） |

事実と判断を分けるのは、後で「なぜ通したか」を振り返れるようにするためと、面接官ごとの判断の差を、事実の欄で確かめられるようにするためです。「人柄が良い」「印象が良い」は判断の欄にも書きません。基準に無い項目だからです。基準の作り方は[評価基準が言語化できていない](/media/rpo-hyouka-kijun/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「面接の設計をしたら、合否も設計者が出せる」というものです。実際には、副業の担当者が合否を出すと、依頼側の判断が外部に寄り、入社後に問題が起きたときに責任の所在が曖昧になります。担当者がやるのは、設計と、一枚と、記録の形と、記録を並べて「基準に照らすとこうなります」と示すところまでで、通す・通さないを決めるのは依頼側です。この線は、契約の範囲にも、職業紹介に関わる法令の整理にも関わるので、依頼側の決まりと専門家の確認に従います。受ける側がその場で使える判断としては、記録の「判断」の欄を、担当者ではなく面接官が書く形にすること。担当者は記録の形を整え、欄が埋まっているかを確かめ、決める人に並べて渡します。判断を依頼側に残す形は[面接代行を受けるときの注意](/media/fukugyo-mensetsu-daikou-chuui/)に書いています。

## 決める人を決める

| 決めること | 決め方 |
|---|---|
| 各段の通過 | その段の面接官が、記録の判断の欄に基づいて。複数なら誰が最終判断か |
| 最終の決定 | 経営者か、依頼側が指名した一人。多数決にしない |
| 判断が割れたとき | 事実の欄を並べ、基準に照らして決める人が決める。担当者は並べるまで |
| 基準に無い理由で落とすとき | 「その理由を基準に足しますか」と依頼側に確認する。足すなら以後の候補者にも適用 |

多数決にしないのは、面接官の数で結果が変わるからです。決める人が一人いて、他の面接官の記録を材料にする形が、ぶれません。

## 基準にしてはいけない項目

性別、年齢、国籍、家族の状況、出身地などを面接の質問や判断の基準にすることには、募集や採用で法令上の決まりがあると一般に整理されています。面接官に渡す一枚の「聞かないこと」に明記し、記録にも書きません。面接官が聞いてしまった場合は、記録から除き、依頼側に伝えます。何が該当するかは、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「面接官の研修をしてほしい」と言う | 研修の前に設計の五つを一枚にして見せる。設計があれば研修は一枚の読み合わせで足りることが多い |
| 段ごとの項目が分けられない | 要件の「面接で確かめる項目」が多すぎる。三〜五つに絞ってから振る |
| 面接官が一枚を読まない | 面接の直前に五分で読み合わせる。一枚を短くする |
| 記録が印象で埋まる | 事実の欄を先に埋めてもらう。事実が無ければ判断を書かない形に |
| 最終で経営者が全部ひっくり返す | 経営者が確かめることを最終の一枚に書き、一次・二次で確かめたことを最終で聞き直さない合意を取る |
| 担当者が合否を求められる | 記録を並べて基準に照らした見え方を示すまで。決めるのは依頼側と伝える |

## まとめ

- 面接がうまくいかないのは面接官の腕ではなく、**設計が無い**から
- 決めるのは**回数と段階・各段の面接官・各段で確かめる項目・記録の形・決める人**の五つ
- 「面接で確かめる項目」を**段階に一つずつ振り、重ねない**。一次は経歴の確認、二次は場面、最終は決め手
- 面接官には**段ごとの一枚**。役割・項目・聞き方・基準・聞かないこと・記録の形
- 記録は**事実と判断を分ける**。「人柄が良い」は書かない
- **決めるのは依頼側**。多数決にせず、決める人を一人に。担当者は設計と記録を並べるまで
- **基準にしてはいけない項目**は聞かない・書かない。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側の面接の回数が多く、候補者が途中で辞退します

段ごとに確かめる項目を並べ、重なっている項目を示します。重なりを消すと、段を減らせることが多い。「一次と二次を同日に」「二次と最終を同じ相手で」のような形を、候補者の辞退の数と一緒に提案します。段の数は依頼側の判断なので、担当者は「重なり」と「辞退の数」を材料として並べるまでです。辞退の構造は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)にも書いています。

### 面接官が「型どおりに聞くと、候補者の本当の姿が見えない」と言います

型は質問を固定するものではなく、確かめる項目と記録の形を固定するものです。項目に沿って「〇〇した場面を具体的に」と聞き、そこから深掘りするのは面接官の自由です。「聞き方は自由で、確かめる項目と記録の形だけ揃えます」と伝えると、面接官の抵抗は減ります。深掘りの途中で基準に無いことを見つけたら、記録の「事実」の欄に書き、基準に足すかは依頼側が決めます。

### 記録を書く時間が面接官に無い、と言われます

記録の欄を減らします。「確かめる項目ごとに、事実を一行、判断を一語」で足ります。面接の直後に五分で書く形を、日程の枠に含めて預かります。記録が無いと、判断が割れたときに戻る材料が無く、入社後のずれも振り返れません。「記録は面接官のためではなく、決める人が決めるための材料です」と、使い道で説明します。
