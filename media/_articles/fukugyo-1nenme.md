人事になって一年目。周りに副業をしている人がいて、自分も興味はある。ただ、まだ本業の型も覚え切っていない状態で、副業を受けてよいのか。本業に支障が出ないか。そもそも、一年目に頼む会社があるのか。結論を先に書くと、**人事一年目は、「副業で稼ぐ」を急ぐ時期ではありません。一年目にできることは、「本業で型を覚える」「やった作業を単位で棚卸しする」「条件が揃えば小さく一件だけ試す」の三つで、これは二年目以降の副業の土台になります。一年目で副業に時間を使うより、本業で型を覚えるほうが、二年目からの副業の範囲と単価を大きくします。ただし、本業でやった作業の単位で、型がある小さい案件なら、一年目でも受けられるものはあります**。経験が浅いときの案件の選び方は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に、三年目からの広がりは[人事3年目からできること](/media/fukugyo-3nenme/)にまとめています。本業の副業の規定に関わる部分は、個別の判断は専門家にご確認ください。

## 一年目で迷う構造

一年目に、副業を始めるべきか迷うのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 周りと比べている | 副業をしている先輩や同期を見て、「自分も」と焦る。先輩は三年目以降であることが多い |
| 本業の型がまだ無い | 本業で「なぜそうするか」が分からない状態で、外に出しても、型に沿って動けない |
| やった作業を数えていない | 一年間でやった作業（送信、連絡、調整、記録）を、業務の単位で数えていない |
| 「まだ何もできない」と思っている | 一年目でも、作業の単位では「できること」がある |
| 本業の規定を見ていない | 一年目は試用や研修の期間で、副業の扱いが違う場合がある。規定の確認が先 |
| 時間が読めない | 一年目は本業の繁忙が読めず、固定できる時間が分からない |
| 収入を期待している | 一年目の副業で、まとまった収入は期待できない |

構造の大半は、「周りと比べて急いでいる」ことです。一年目は、急がずに土台を作る時期です。

## 一年目の経験の中身

一年目にやったことを、「型を作った」「型に沿って動いた」「見ていた」の三つに分けます。副業で売れるのは、二つ目です。

| 区分 | 内容 | 副業での扱い |
|---|---|---|
| 型を作った | 文面の型、対象の基準、手順を、自分で設計した | 一年目にはほぼ無い。あれば売れる |
| 型に沿って動いた | 先輩の型に沿って、スカウトを送った、応募者に連絡した、日程を調整した、記録を書いた | 売れる。「型に沿って正確に動く」経験 |
| 見ていた | 先輩の面接に同席した、会議で採用の議論を聞いた | 売れないが、二年目以降の理解の土台 |

中身の要点は、「型に沿って動いた」を数えることです。一年目の一年間で、スカウトを何通送ったか、応募者に何件連絡したか、日程を何件調整したか。数があれば、「型に沿って動く」経験として売れます。棚卸しの仕方は[何から手を付けるか](/media/fukugyo-nani-kara/)に書いています。

## 一年目にできること・できないこと

一年目の経験で、副業として受けられることと、受けられないことです。

| 受けられること | 条件 | 受けられないこと | 理由 |
|---|---|---|---|
| 型に沿ったスカウトの送信と一次返信 | 依頼側に型がある。本業で送った経験がある | 文面の型の作成 | 型を作った経験が無い |
| 応募者への連絡と日程調整 | 依頼側の連絡の型がある | 対象の基準の設計 | 基準を作った経験が無い |
| 採用の記録の入力と整備 | 記録の表がある | 面接の設計と評価 | 面接の経験がほぼ無い |
| 面接の準備（日程、資料、案内） | 依頼側の手順がある | 合否や条件の判断 | 経験の有無に関わらず外部は受けない |
| 内定者への定期の連絡 | 連絡の型がある | 採用の全体の設計 | 全体を見た経験が無い |

できることの要点は、「型に沿って動く作業」に限られることです。それでも、依頼側に型がある小さい案件なら、受けられます。受けられる案件の四つの条件は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に書いています。

## 副業を急がないほうがよい理由

一年目に副業を急がず、本業で型を覚えることを勧める理由です。

| 理由 | 内容 |
|---|---|
| 二年目以降の範囲が広がる | 一年目に本業で型を覚え、二年目で型を直す経験をすると、三年目には「型を作れる」側に入る。副業の範囲が作業から設計に広がる |
| 単価の根拠ができる | 型を持っていれば、単価の根拠になる。一年目の作業の単価と、三年目の型の単価は違う |
| 本業の評価が土台になる | 一年目は本業での信頼を作る時期。副業に時間を使って本業が疎かになると、両方を失う |
| 規定と時間が読めるようになる | 一年目は繁忙の波が読めない。二年目になれば、固定できる時間が分かる |
| 「なぜそうするか」が分かる | 型に沿って動くだけでなく、型の理由が分かると、依頼側の型が違っても対応できる |
| 一年目の副業の収入は小さい | 作業の単価で、週数時間。収入を期待すると、条件の合わない案件を受ける |

急がない理由の要点は、「二年目以降の範囲と単価」です。一年目に副業で作業を売るより、本業で型を覚えるほうが、三年目の副業が大きくなります。急がないのは、諦めることではなく、土台を作ることです。

### エラベルの見解

登録の相談で、一年目の方から「今から始めないと遅れる」という声を聞きます。ただ、担当する側として長く続いている人の多くは、三年目以降に始めています。一年目に本業で型を覚え、二年目で型を直す経験をし、三年目で「型を持っている」と言えるようになってから、副業に出ています。一年目から始めた人が悪いわけではありませんが、一年目の副業は作業に限られ、二年目に本業が忙しくなると止まることが多い。

見ていて差がつくのは、一年目に「やった作業を数えているか」です。数えていない人は、二年目になっても「何ができるか分からない」と言います。数えている人は、二年目に「一年で〇〇通送り、〇〇件調整した」と言え、そこから範囲を書けます。

エラベルでは、一年目の方の登録も受けていますが、「急がなくてよい」とお伝えしています。本業で型を覚えた後のほうが、合う案件が広がります。

## 一年目にやっておくと二年目に効くこと

副業を急がない代わりに、一年目にやっておくと、二年目以降の副業に効くことです。

| やること | 内容 | 二年目に効く形 |
|---|---|---|
| 作業の数を記録する | 送った通数、連絡した件数、調整した件数、書いた記録の数を、月ごとに | 「一年で〇〇通」と実績の数字になる |
| 型を書き留める | 先輩の文面の型、対象の基準、手順を、自分の言葉で書き留める | 「型を持っている」の元になる |
| 「なぜそうするか」を聞く | 型の理由を、先輩に聞いて書き留める | 依頼側の型が違っても、理由から対応できる |
| 一つの業務を深くやる | スカウト、求人票、日程調整のどれか一つを、一年間、数を出してやる | 「〇〇なら任せられる」の一つができる |
| 本業の規定を確認しておく | 副業の可否、届け出、試用や研修の期間の扱い。解釈は専門家に | 二年目に始めるとき、すぐ動ける。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/) |
| 固定できる時間を観察する | 一年間の繁忙の波を見て、忙しい週でも空く曜日と時間帯を見つける | 二年目に「固定できる時間」が言える |

効くことの要点は、「作業の数を記録する」ことです。一年目の数は、二年目の実績です。記録していなければ、「たくさんやった」しか言えません。月ごとに数えておけば、二年目に範囲と実績を書けます。

## それでも一件試すなら

一年目でも、条件が揃っていて一件試したい場合の、条件と注意です。

| 条件 | 内容 |
|---|---|
| 本業の規定で認められている | 一年目は試用や研修の期間で扱いが違う場合がある。規定を確認し、解釈は専門家に |
| 固定できる時間が週に三時間ある | 一年目で読めない場合は、まだ早い |
| 本業でやった作業の単位で、型がある案件 | 「型に沿った送信と一次返信」「日程調整」「記録の入力」のどれか |
| 期間が短い | 一〜二か月で区切る |
| 単価と収入を期待しない | 「型を身につける期間」と割り切る。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) |
| 本業の上司に相談できる関係がある | 一年目の副業は、本業の信頼に関わる。隠して始めない |
| 本業の情報と切り分ける | 本業の候補者、取引先、社内の情報は使わない。同業は避ける。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |

試す場合の要点は、「本業の規定と上司との関係」です。一年目は、本業での信頼を作る時期です。規定に触れたり、上司に隠したりして始めると、本業の信頼を失い、副業どころではなくなります。条件が揃わなければ、二年目まで待ちます。

## 注意すること

一年目に副業を考えるときの、注意です。

| 注意 | 内容 |
|---|---|
| 本業を優先する | 副業のために本業の時間や質を削らない。削った時点で、両方を失う |
| 「一年目でもできる」を「一年目で稼げる」と読まない | できるのは型に沿う作業で、収入は小さい |
| 経験を大きく見せない | 「スカウト運用の経験があります」ではなく「型に沿った送信と一次返信の経験が一年あります」 |
| 周りの副業と比べない | 先輩の副業は、先輩の経験の年数と範囲で成り立っている |
| 本業の情報を持ち出さない | 本業で作った文面、候補者の情報、社内の資料を、副業で使わない |
| 待つことを選択肢に入れる | 「今は始めない」も判断。二年目、三年目に始めるほうが大きくなる |

注意の要点は、「本業を優先する」ことです。一年目の副業で得られるものより、本業で失うもののほうが大きい。副業は、本業の型を覚えた後に、その型を外で使うものです。

### エラベルの見解

担当する側として登録した一年目の方に、「急がなくてよい」とお伝えするのは、二年目、三年目に登録した方のほうが、範囲が広く、単価も高く、続いているからです。一年目の副業で作業を売った方が、二年目に本業が忙しくなって止まり、三年目に「もう一度」と戻ってきたとき、範囲は三年目の型で書けるようになっていました。一年目の副業は、無くても三年目には影響しませんでした。

一年目にやっておくと効くのは、副業そのものではなく、作業の数の記録と、型を書き留めることです。それがあれば、いつ始めても、範囲と実績が書けます。

エラベルでは、登録の時期に制限はありません。一年目に登録して、二年目や三年目に条件が揃ってから案件を受ける形もできます。

## まとめ

- 迷うのは**周りと比べる・型が無い・作業を数えていない・何もできないと思う・規定を見ない・時間が読めない・収入を期待**構造
- 経験は**型を作った（ほぼ無い）・型に沿って動いた（売れる）・見ていた（土台）**に分ける。型に沿って動いた数を数える
- できるのは**型に沿った送信と一次返信・連絡と日程調整・記録の整備・面接の準備・内定者の連絡**。できないのは**型の作成・基準の設計・面接の設計と評価・判断・全体の設計**
- 急がないのは**二年目以降の範囲・単価の根拠・本業の評価・規定と時間・なぜそうするか・一年目の収入は小さい**から
- 一年目にやるのは**作業の数の記録・型を書き留める・理由を聞く・一つを深く・規定の確認・時間の観察**
- 試すなら**規定・週三時間・型がある作業・短い期間・収入を期待しない・上司との関係・情報の切り分け**が揃ったとき
- 注意は**本業を優先・稼げると読まない・大きく見せない・比べない・持ち出さない・待つも選択肢**

## よくある質問

### 一年目でも、登録だけしておいてよいですか

構いません。登録の時点で、範囲を「型に沿った作業」で書き、時間を「まだ固定できない」なら小さく書いておけば、合う案件があるときだけ声がかかります。無理に受ける必要はなく、二年目や三年目に条件が揃ってから受けることもできます。登録しておくと、「二年目に何を書けるか」を意識して、一年目の作業を数えるようになります。

### 同期が一年目から副業で稼いでいます。遅れていませんか

遅れていません。同期の副業が、人事の経験を使ったものか、別の経験（学生時代の活動、前職）を使ったものかを見ると、人事一年目の経験だけで大きな案件を受けている人は少ない。一年目に本業で型を覚え、二年目以降に始めた人のほうが、三年目の副業は大きい。比べるなら、三年目の時点で比べてください。

### 本業の上司に、副業のことを言うべきですか

本業の規定によります。届け出や許可が要る規定なら、言わずに始めることは勧めません。規定で認められていて届け出が不要でも、一年目は上司との信頼を作る時期なので、相談しておくほうが、後で問題になりにくい。規定の内容と、言うべきかの判断は、就業規則を確認したうえで、迷えば専門家に確認してください。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、申請の書き方を整理しています。
