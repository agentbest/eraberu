最初の案件が決まり、契約書の話が進んでいる。そこで「振込先を教えてください」と言われ、本業の給与が入る口座をそのまま伝えてよいのか、屋号や別名義の口座が要るのか、仲介サービスを通す場合は何が違うのかが分からず止まる。結論を先に書くと、**副業の報酬を受け取る準備は、「副業専用の口座を一つ用意する」「受け取り方を契約前に確認する」「入金の記録を置く場所を決める」の三つで足ります。**専用の口座は、屋号付きの特別なものでなくてよく、本人名義の普通口座を一つ分ければ十分です。税や届け出に関わる部分は会社や状況で扱いが変わるので、個別の判断は税理士などの専門家にご確認ください。請求書そのものの書き方は[請求書の書き方](/media/fukugyo-seikyuusho/)に、締め日と支払日の見方は[支払いサイトの確認](/media/fukugyo-shiharai-site/)にまとめています。

## 専用口座を一つ分ける理由

副業の報酬を、本業の給与と同じ口座で受け取ること自体は、多くの場合は問題になりません。それでも一つ分けることを勧めるのは、後で「どれが副業の入金か」を探す手間が、案件が増えるほど大きくなるからです。給与、生活費の引き落とし、副業の報酬が同じ通帳に並ぶと、年の終わりに副業の収入を集計するとき、一行ずつ見分けることになります。

| 分ける理由 | 起きること |
|---|---|
| 収入の集計が一目でできる | 副業専用の口座なら、入金の合計がそのまま副業の収入になる |
| 未入金に気づける | 「今月入るはずの案件が入っていない」を、通帳を開いただけで見つけられる |
| 経費の支払いをまとめられる | 副業で使うツールや書籍の支払いを同じ口座から出せば、経費の記録も一か所に集まる |
| 本業の給与と混ざらない | 家計の口座に副業の入金が混ざると、使ってよい額が分からなくなる |
| 依頼側に伝える口座が一つで済む | 案件ごとに違う口座を伝えると、自分でも管理できなくなる |

口座は、いま持っている本人名義の普通口座で構いません。屋号付きの口座や事業用の口座は、開業届を出した後に検討すれば足りるもので、最初の一件のために新しく作る必要はありません。手元に使っていない口座が一つあれば、それを副業用に割り当てるのが最も早い方法です。

## 受け取り方は入口で三つに分かれる

報酬の受け取り方は、案件がどこから来たかで変わります。仲介サービスを通す場合、企業と直接契約する場合、知人の紹介で受ける場合の三つで、請求の出し方と入金の経路が違います。

| 入口 | 請求の出し方 | 入金の経路 | 自分で用意するもの |
|---|---|---|---|
| 仲介サービス経由 | サービスの画面で稼働を報告し、サービスが請求をまとめる | サービスから、手数料を引いた額が振り込まれる | サービスに登録する振込先の口座 |
| 企業と直接契約 | 自分で請求書を作り、依頼側の経理に送る | 依頼側の経理から、請求書の口座に振り込まれる | 請求書の型と、振込先の口座 |
| 知人の紹介 | 直接契約と同じだが、紹介者を通して条件が決まることがある | 依頼側から直接、または紹介者の会社を経由する | 誰に請求を出すかの確認 |

仲介サービス経由の場合、自分で請求書を作らないことが多く、振込先の口座をサービスに登録すれば準備はほぼ終わります。ただし、手数料が引かれた額が入金されるので、契約した単価と入金額がずれます。これを知らずに「入金が少ない」と慌てる人がいます。手数料の率や、いつの稼働分がいつ振り込まれるかは、サービスによって違うので、登録時に画面で確認してください。

直接契約の場合は、請求書を自分で作り、依頼側の経理の締め日に合わせて出します。振込先は請求書に書くので、口座を決めておかないと請求書が完成しません。知人の紹介では、請求を依頼側に直接出すのか、紹介者の会社を通すのかが曖昧なまま始まることがあり、最初に確認しておくと後でもめません。紹介で受けるときの整理は[知人紹介で受けるときの注意](/media/fukugyo-shoukai/)にあります。

## 契約前に確認しておく項目

振込先を伝える前に、依頼側に確認しておくと、後で請求と入金の行き違いが減る項目です。契約書に書かれていれば読めば済みますが、書かれていないことも多いので、口頭でも聞いておきます。

| 確認する項目 | なぜ要るか |
|---|---|
| 締め日と支払日 | 「月末締め・翌月末払い」のように決まっている。知らないと、入金がいつか分からない |
| 振込手数料をどちらが持つか | 依頼側が引いて振り込む場合、入金額が請求額より少なくなる |
| 支払方法 | 銀行振込が多いが、仲介サービスの決済や、依頼側の支払いシステムを使う場合がある |
| 請求書の宛名と送り先 | 会社名、部署、担当者、送るメールアドレス。経理が別の窓口のこともある |
| 請求書に必要な項目 | 依頼側の経理が指定する記載事項があることがある。登録番号を求められる場合は専門家に相談する |
| 稼働の報告の形 | 時間で請求するなら、稼働の記録をどの形で出すか。請求と報告が合わないと支払いが止まる |

確認の要点は、「締め日と支払日」と「振込手数料」です。この二つが分かっていれば、入金の予定日と予定額が読めます。読めていれば、入金が遅れたときにすぐ気づけて、[報酬が支払われないときの対処](/media/fukugyo-mibarai/)の手順に入れます。読めていないと、「まだ入っていないが、いつ入る予定だったのかも分からない」状態になります。

### エラベルの見解

相談で最も多い思い込みは、「副業の口座は屋号付きの事業用口座でないと、依頼側に失礼になる」というものです。実際には、依頼側の経理が見ているのは、請求書の口座名義と振込先が一致していて、振り込んだ後に「届いていない」と言われないことだけです。本人名義の普通口座で、請求書に書いた名義と口座が合っていれば、経理は止まりません。

むしろ止まるのは、請求書の名義と口座の名義が違うとき、口座番号の桁が抜けているとき、支店名が旧名称のときです。依頼側の経理は、振込先の不備があると、確認のメールを一往復してから振り込むので、それだけで支払いが一か月ずれることがあります。口座を選ぶときに気にするべきは、見た目の格ではなく、請求書に書く情報を正確に写せるかどうかです。通帳かアプリの口座情報の画面を開き、金融機関名、支店名、口座種別、口座番号、口座名義のカナを、そのまま請求書の型に入れておくと、以後は写し間違いが起きません。

## 口座名義と本名の扱い

本名を出さずに副業をしたい人は、口座の名義で迷います。銀行の口座は本人名義なので、請求書に口座を書けば、依頼側には本名が伝わります。仲介サービス経由なら、依頼側にはサービス上の名前しか見えず、振込先の口座はサービスにだけ登録する形になるので、依頼側に本名が渡らない場合があります。

| 状況 | 本名の扱い |
|---|---|
| 仲介サービス経由 | 振込先はサービスに登録する。依頼側に口座情報は渡らないことが多い |
| 企業と直接契約 | 請求書に口座名義を書くので、本名は伝わる。契約書にも本名が要る |
| 知人の紹介 | 直接契約と同じ。紹介者の会社を通す場合は、その会社に本名が要る |

直接契約で本名を出さずに済ませる方法は、基本的にありません。契約と請求は本人の名前で結ぶものなので、公開する名前と契約に使う名前を分ける、という整理になります。この分け方は[本名を出さずに受けられるか](/media/fukugyo-honmyo/)に書いています。本業の会社に副業が知られる経路は、口座ではなく住民税などの別の話なので、そこは専門家に確認してください。

## 続けるための記録の付け方

口座と受け取り方が決まったら、入金の記録を一か所に置きます。案件が一件のうちは通帳を見れば済みますが、二件、三件と増えると、どの入金がどの案件の何月分かが分からなくなります。記録は、表計算の一枚で十分です。

| 記録する列 | 内容 |
|---|---|
| 案件名 | 依頼側の会社名か、仲介サービス上の案件名 |
| 稼働の月 | いつの稼働分か |
| 請求日と請求額 | 請求書を出した日と、その額 |
| 入金予定日 | 締め日と支払日から計算した日 |
| 入金日と入金額 | 実際に入った日と額。手数料が引かれていればその差も書く |
| 状態 | 未請求・請求済・入金済・遅延 |

記録の要点は、「入金予定日」の列を作ることです。請求を出したときに予定日を書いておけば、月に一度、予定日を過ぎて入金済になっていない行を探すだけで、遅れに気づけます。年の終わりには、入金額の列を合計すれば副業の収入になり、確定申告の準備がそのまま進みます。申告の要否や方法は状況で変わるので、[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/)を見たうえで、個別の判断は専門家にご確認ください。

記録に使うツールは、本業の会社のアカウントで作らないことです。本業の会社のドライブに副業の入金表があると、情報の分離の面で問題になります。副業用のアカウントと端末の分け方は[情報の取り扱いと端末の分離](/media/fukugyo-security/)に整理しています。

### エラベルの見解

担当する側から見ると、決済の準備は「案件が決まってから考える」人と「登録の時点で整えている」人で、最初の一件の立ち上がりに差が出ます。案件が決まってから口座を選び、請求書の型を作り、締め日を聞いていると、契約から初回の請求までに手戻りが何度か起きます。依頼側から見れば、稼働は始まっているのに請求が来ない、来た請求書の口座に不備がある、という状態です。

順番として、口座を決め、請求書の型に口座情報を入れ、入金の記録表を作るところまでを、案件が決まる前に済ませておくと、契約後は締め日と支払日を聞くだけで動けます。エラベルでは、登録の段階で振込先や請求の形を細かく求めることはしていませんが、案件が決まった後に「請求はどうすれば」という相談を受けることが多く、そのたびに同じ三つを案内しています。先に整えておく人ほど、二件目以降も同じ型で回せています。

## まとめ

- 準備は**副業専用の口座を一つ・受け取り方の確認・記録の置き場**の三つ。屋号付きの口座は最初の一件には要らない
- 受け取り方は**仲介サービス経由・企業と直接契約・知人の紹介**で違う。仲介経由は手数料が引かれた額が入る
- 契約前に**締め日と支払日・振込手数料・支払方法・請求書の宛名と項目・稼働の報告の形**を確認する
- 依頼側の経理が止まるのは**口座の格ではなく、請求書の名義と口座情報の不備**
- 直接契約では**本名は口座と契約で伝わる**。公開する名前と契約の名前を分ける整理になる
- 記録は**入金予定日の列**を作り、月に一度、予定日を過ぎた行を探す。税や申告の判断は専門家に

## よくある質問

### 副業用に新しく口座を作らないといけませんか

作らなくても構いません。いま持っている本人名義の口座のうち、使っていないものを副業用に割り当てれば足ります。新しく作るなら、振込の通知がすぐ届くネット銀行が管理しやすい傾向がありますが、金融機関の選び方に決まりはありません。大切なのは、副業の入金だけが集まる口座が一つあることで、その口座がどこの銀行かではありません。

### 仲介サービス経由で、契約した単価より入金が少ないのはなぜですか

多くの仲介サービスは、依頼側から集金した額から、サービスの手数料を引いて振り込みます。契約画面で見た単価が「依頼側が払う額」なのか「自分が受け取る額」なのかは、サービスによって表示が違うので、登録時に確認してください。入金の記録表に、請求額と入金額の両方を書いておけば、差が手数料なのか、支払いの遅れなのかが分かります。差が説明のつかない額なら、サービスの窓口に問い合わせます。

### 登録番号や開業届を求められたら、どうすればよいですか

依頼側の経理から、請求書に登録番号を書くよう求められることや、開業届の有無を聞かれることがあります。要否は、自分の収入の規模や依頼側の事情で変わり、一律に答えられるものではありません。この記事では扱わず、税理士などの専門家に、自分の状況を伝えて確認してください。依頼側には「確認して連絡します」と返せば、それで契約が止まることはほとんどありません。
