学校法人や大学、専門学校の人事として、教員の公募を回し、職員の採用と異動を扱い、規程に沿った手続きと委員会の運営をし、年度の暦に合わせて人事を動かしてきた。この経験は、民間の会社が多い人事の副業で売れるのか。教育機関の人事は、民間とは進め方が違い、そのまま通じないと感じる人が多いところです。結論を先に書くと、**教育機関の人事の経験は、「年度の暦で動き、資格と専門性で人を見て、公募と規程と委員会で決めてきた」型で売れます。売れるのは、「専門職の採用の要件づくり」「年度の計画で募集を回す設計」「規程と書面で公平に選ぶ手順」「教員と職員という二つの人事を扱う目」の四つです。民間の会社でも、資格や専門性で人を見る採用、年度や期の計画で回す採用、手順の公平さが問われる採用はあり、そこで教育機関の型が効きます。「学校の人事でした」ではなく、「専門職を、公平な手順で、年度の暦に合わせて採る」と売ります。**医療・介護の人事の経験は[医療・介護の人事が副業でできること](/media/fukugyo-iryou-jinji-fukugyo/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に、人事企画の経験は[人事企画が副業でできること](/media/fukugyo-jinji-kikaku-fukugyo/)にまとめています。

## この経歴の何が売れるか

教育機関の人事の経験を、民間の会社の採用の工程に置き換えた棚卸しです。在籍した学校の内情は含めず、「型」として抜き出します。

| 教育機関の人事の経験 | 民間の採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 教員の公募で、資格・業績・専門性を要件にしてきた | 資格や専門性が要る職種（技術職、専門職、有資格者）の要件を、資格の名前ではなく「できること」と「証拠」で書く | 専門職の要件が「資格あり」で止まり、面接で何を見ればよいか分からない依頼側が多い |
| 年度の暦に合わせて、採用の計画を前年から組んできた | 期の計画から逆算し、いつ募集を出し、いつ決めるかを組む。繁忙期と閑散期の見通し | 採用が場当たりで、繁忙期に人が足りない依頼側が多い |
| 規程に沿った手順で、書面と委員会で選んできた | 面接官の判断を、基準と記録で揃え、後から説明できる手順にする | 面接官の好き嫌いで決まり、後から説明できない依頼側が多い |
| 教員と職員という、性質の違う二つの人事を扱ってきた | 専門職と事務職、正社員と契約社員など、扱いの違う人事を同時に回す目 | 職種ごとに扱いが違うことを整理できていない依頼側が多い |
| 公募の要項を書き、外部に公開してきた | 求人票を、誰が読んでも同じ意味に取れる形で書く | 求人票が社内の言葉で書かれている依頼側が多い |
| 非常勤や任期付きの雇用を扱ってきた | 契約社員や業務委託など、雇用の形が違う人の採用と条件の整理 | 雇用の形の違いを整理せずに採用している依頼側が多い |
| 委員会や会議で、複数の立場の合意を作ってきた | 経営者・現場・人事の意見が割れる採用で、合意の手順を設計する | 意見が割れて採用が止まる依頼側が多い |

売れるものの要点は、「専門性で人を見る採用と、公平さが問われる採用を、手順で回せる」ことです。民間の採用は速さを重視しますが、専門職の採用や、複数の面接官が関わる採用では、速さより「何を基準に、どう決めたか」を説明できることが求められます。教育機関の人事は、その手順を日常として回してきており、民間で手順がないまま止まっている採用に、型を持ち込めます。年度の計画で回す設計は、期の計画で採用を考える会社にそのまま合います。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

教育機関の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 民間の速さとの差 | 「学校のペースでは、うちの採用には遅い」。自分にとっても、月単位で動いてきた感覚が週単位に合うかの不安 | 手順の型は持ち込み、期間は依頼側に合わせて縮める。「公募で月単位だった手順を、週単位に圧縮するとこうなる」と示す |
| 公募の型に寄りすぎ | 「公募の要項のような求人票では、応募が来ない」。スカウトや媒体の運用の経験が薄い | 求人票の「誰が読んでも同じ意味」の型は活かし、読ませる文面は依頼側や別の担当者と作る。スカウトと媒体は範囲に入れないか、別の担当者と組む |
| 営利の感覚の薄さ | 「採用の費用対効果の話ができるのか」。予算の使い方が、民間の感覚と違う | 費用の話は「年度の予算を計画で使い切る」経験として語れる。採用の費用を期の計画に組み込む型は、民間でも通じる |

扱い方の要点は、「手順の型は持ち込み、速さは依頼側に合わせる」ことです。教育機関の人事の経験がある人は、公募と委員会の手順を月単位で回してきたので、民間の週単位の採用に不安を感じます。手順の中身（基準、記録、合意の取り方）は変えず、期間だけを圧縮すれば、民間でも回ります。「公募なら三か月の手順を、御社では三週間で回すと、この手順になります」と示せば、速さの不安は消えます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、教育機関の人事から転身して続いている人と、面談で止まる人の差は、学校の手順を「そのまま」語るか、「圧縮して」語るかです。止まる人は、公募と委員会の手順を学校の言葉のまま説明し、依頼側の経営者は「うちはそんなに待てない」と感じて終わります。続いている人は、同じ手順を「基準を先に決める、記録を残す、合意を取る」の三つに絞り、「これを御社の速さで回すとこうなります」と、週単位の形で見せます。経営者は、自分の会社に「基準と記録と合意」がないことに気づき、そこから頼みます。

見ていて差がつくのは、専門職の要件を「資格あり」で終わらせず、「できること」と「証拠」で書いているかです。教育機関の人事は、教員の公募で、資格の名前ではなく業績と専門性の証拠で人を見てきています。民間の技術職や有資格者の採用で、「この資格を持っていること」で止まっていた要件を、「入社後にこれができること、その証拠としてこれを見る」に書き直した人は、面接官が何を見ればよいかが揃い、依頼側から「初めて専門職の面接で判断ができた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「専門職を、公平な手順で、年度の暦に合わせて採る」と工程で書いている担当者に、専門職の採用で困っている依頼側がついています。教育機関の人事の転身は、学校の経験を隠すことではなく、手順を圧縮して見せるところから始まります。

## 案件の探し方

教育機関の人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 専門職・有資格者の要件づくり | 資格と専門性で人を見てきた経験でそのまま入れる | 「専門職の要件が『資格あり』で止まっている依頼側」を探す |
| 面接の基準と記録の手順づくり | 規程と書面で選んできた経験で入れる | 「面接官の好き嫌いで決まる依頼側」を探す |
| 期の計画に合わせた採用の年間の設計 | 年度の暦で動いてきた経験で入れる | 「繁忙期に人が足りなくなる依頼側」を探す |
| 雇用の形が違う人の採用と条件の整理 | 非常勤や任期付きを扱ってきた経験で入れる | 「契約社員と正社員の扱いが整理されていない依頼側」を探す |
| 意見が割れる採用の合意の手順 | 委員会で合意を作ってきた経験で入れる | 「経営者と現場で意見が割れて採用が止まる依頼側」を探す |
| 教育・医療・福祉など、資格職の多い業界の採用 | 業界の言葉と資格の意味が分かる | 同じ業界の依頼側を探す |

探し方の要点は、「専門職の採用で手順がない会社」から入ることです。営業職や事務職の大量の採用では、教育機関の型は速さに負けます。技術職や有資格者など、専門性で人を見る採用で、要件が「資格あり」で止まり、面接官の判断がばらつき、決めた理由を後から説明できない会社では、教育機関の型が唯一の打ち手になります。教育・医療・福祉など、資格職の多い業界の依頼側は、業界の言葉が通じるので、さらに入りやすくなります。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。教育機関の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 専門職の要件の成果物 | 「できること」と「証拠」で書いた要件は、成果物として形が明確 | 一式の成果物で受ける |
| 面接の手順の成果物 | 基準と記録の型は、成果物で受けやすい | 一式の成果物で受ける |
| 年間の設計 | 期の計画に合わせた採用の設計は、成果物で受けやすい | 一式の成果物で受ける |
| 手順の運用 | 作った手順を採用のたびに回す運用は、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 速さの不安 | 「遅い」と思われると単価が下がる | 圧縮した手順を先に見せる |
| スカウトと媒体を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 採用の成否は依頼側の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「要件と手順と年間の設計は成果物で、運用は月額で受ける」ことです。教育機関の人事の経験で受ける工程は、要件と手順と計画という成果物が明確で、成果物で受けると単価の根拠が伝わります。作った手順を回す運用は月額で受け、更新の根拠にします。「遅い」と思われないよう、圧縮した手順を先に見せることが、単価を保つ前提になります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

教育機関の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、所属する法人の副業の規定と、教職員の情報の守秘の条件を確認する | 学校法人は規程が細かい。個別の判断は専門家に |
| 二、公募と委員会の手順を、「基準・記録・合意」の三つに絞って、学校の情報を含まない型として書き出す | 手順の中身 |
| 三、その手順を、週単位に圧縮した形を作る | 民間の速さに合わせる |
| 四、学校の言葉を、民間の言葉に置き換える | 「公募」→「募集」、「業績」→「実績と証拠」、「委員会」→「面接官の合議」 |
| 五、得意な工程（要件・手順・年間の設計・雇用の形の整理・合意）と、薄い工程（スカウト・媒体の運用・読ませる文面）を分ける | 正直に示す準備 |
| 六、「専門職を、公平な手順で、年度の暦に合わせて採る」の一言を作る | 「学校の人事でした」で終わらせない |
| 七、登録先に、範囲と、圧縮した手順と、資格職の多い業界の経験を登録する | 専門職の採用で手順がない依頼側 |
| 八、専門職の要件づくりか面接の手順づくりを一件受け、「基準で決まった採用」を残す | 次の工程に広げる材料に |

順番の要点は、「三」の圧縮と「四」の置き換えです。教育機関の人事の経験は、そのまま語ると民間には遅く、難しく聞こえます。手順を「基準・記録・合意」に絞って週単位に圧縮し、学校の言葉を民間の言葉に置き換えておくと、同じ経験が「手順のない会社に手順を持ち込める人」として伝わります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「学校の人事は特殊で、民間では通じない」というものです。実際には、民間の採用で足りないものの一つが「基準と記録と合意の手順」で、教育機関の人事はそれを日常として回してきています。通じないのは、公募と委員会の手順を学校の速さと言葉のまま持ち込む場合で、圧縮して置き換えれば、専門職の採用や意見が割れる採用で、民間の人事にはない型になります。特殊なのは経験ではなく、語り方です。

順番として、法人の規定と守秘の条件を専門家に確認し、手順を基準・記録・合意に絞って書き出し、週単位に圧縮し、学校の言葉を民間の言葉に置き換え、得意な工程と薄い工程を分け、専門職を公平な手順で採る一言を作り、登録先に範囲と圧縮した手順を登録し、一件受けて基準で決まった採用を残す。この順番で、教育機関の人事の経験は「特殊で通じないもの」から「専門職の採用に手順を持ち込む形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、手順の工程を明確にし、スカウトと媒体を含まないことを示している担当者に、専門職の採用で困っている依頼側がついています。教育機関の人事の転身は、学校の経験を隠すことではなく、手順を圧縮して語るところから始まります。

## まとめ

- 教育機関の人事の経験は**「年度の暦で動き、資格と専門性で人を見て、公募と規程と委員会で決めてきた」型**で売れる。**専門職の要件・年度の計画・公平な手順・二つの人事を扱う目**の四つ
- **「学校の人事でした」ではなく「専門職を、公平な手順で、年度の暦に合わせて採る」**と売る
- 売りにくい点は**民間の速さとの差・公募の型に寄りすぎ・営利の感覚の薄さ**。手順は「基準・記録・合意」に絞って週単位に圧縮し、学校の言葉を置き換え、スカウトと媒体は範囲外と示す
- 案件は**専門職の採用で手順がない会社**から。資格職の多い業界（教育・医療・福祉）はさらに入りやすい
- 単価は**要件と手順と年間の設計は成果物、運用は月額**で。「遅い」と思われないよう圧縮した手順を先に見せる。成果報酬は最初は避け、可否は専門家に確認
- 専門職の要件は**「資格あり」で終わらせず、「できること」と「証拠」で書く**

## よくある質問

### 民間の会社の採用を経験したことがありません。面談で不利になりますか

隠さずに、「民間の採用の実務の経験はありませんが、専門職の要件と面接の手順は、公募と委員会で回してきました。御社の速さに合わせて圧縮した手順を持ってきました」と示します。民間の経験がないことを補おうとせず、持っている型を圧縮した形で見せるほうが、依頼側には伝わります。速さが要る工程（スカウト、媒体、読ませる文面）は、依頼側の担当者か別の担当者と組む形も、エラベルのような登録先では可能なことがあります。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、面談で聞かれることは[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に整理しています。

### 学校法人に勤めながら副業をしてよいのでしょうか

法人の副業の規定と、教職員としての守秘と兼業の条件を先に確認します。学校法人は規程が細かく、兼業の届出や許可が要ることがあります。私立と公立、教員と職員でも扱いが違います。個別の判断は、所属する法人の規程を確認したうえで、社会保険労務士や弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

### 教育業界の依頼側（塾、学校、教育サービス）に絞ったほうがよいですか

最初は絞るほうが入りやすいです。業界の言葉と資格の意味が分かり、依頼側は説明の手間が省けます。ただ、教育業界の依頼側だけでは案件の数が限られるので、専門職の採用で手順がない会社（技術職、有資格者、医療・福祉）に広げる準備を並行します。「教育業界の人事の経験」と「専門職を公平な手順で採る型」の二つを登録しておくと、業界の内外の両方から声がかかります。業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に、案件を増やす考え方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に整理しています。
