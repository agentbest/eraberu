スカウトは「パーソナライズが大事」と言われる。ただ、一人ずつ全文を書いていたら、一日に数通しか送れない。定型で送ると、返信が来ない。どこまで個別に書き、どこから型にしてよいのか、線が引けない。結論を先に書くと、**パーソナライズは、「全文を個別に」でも「全文を定型に」でもなく、「候補者が『自分宛て』と分かる部分」だけを個別にします。それは、一段落目（なぜあなたに送ったか）です。二〜四段落目は、役割ごとの型で足ります。一段落目に時間を集中し、その深さを相手と役割で変えれば、時間と返信の両方が成り立ちます**。本文の構成は[スカウト本文の構成](/media/scout-reibun-kouzou/)に、型と個別の比率は[テンプレートと個別文の比率](/media/scout-tenpure-hiritsu/)にまとめています。

## どこまでやるかで迷う構造

パーソナライズの範囲で迷うのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「全文か定型か」の二択 | 中間（一部を個別、一部を型）を考えていない |
| パーソナライズの目的が無い | 「個別に書く」こと自体が目的になり、どこを個別にすれば効くかを考えていない |
| 全文を個別に書いて、送れない | 一通に三十分かかり、一日に数通。対象に届く数が足りない |
| 定型で送って、返信が無い | 「ご経歴を拝見して」の定型。候補者に「一斉送信」と見える |
| 個別にする部分が、効かない部分 | 「〇〇社でのご活躍」のような、経歴の表面をなぞるだけ。個別に見えるが、「自分を見た」とは伝わらない |
| 送信数を追っている | 数を送るために定型に。質より量の評価 |
| 担当者ごとにばらばら | ある担当者は全文個別、別の担当者は全部定型。比べられない |
| 深さの段階が無い | 「個別にする」の中身が、一言添えるだけから、経歴を深く読むまで、決まっていない |

構造の大半は、「どこを個別にすれば効くか」を決めていないことです。

## パーソナライズの目的

パーソナライズの目的を、置き直します。

**目的は、「候補者が『自分宛て』と分かる」こと。** 「個別に書く」ことではなく、候補者の受信箱で「これは自分に送られた」と判断されることです。

**「自分宛て」が伝わる最小は、「相手の経歴の具体的な一つに触れ、役割との対応を一文で言う」こと。** これがあれば、他が型でも、「自分宛て」は伝わります。

**「自分宛て」が伝わらない個別は、意味が無い。** 「〇〇社でのご活躍を拝見し」は、会社名を差し替えただけで、「自分を見た」とは伝わりません。経歴の表面ではなく、中身に触れます。

**全文を個別にしても、「自分宛て」は一段落目で決まる。** 二〜四段落目を個別に書いても、候補者はそこまで読む前に「自分宛てか」を判断しています。

**パーソナライズは、時間の配分の問題。** 一通に使える時間を、「自分宛て」に効く部分（一段落目）に集中する。効かない部分（会社の説明の言い回し）に使わない。

目的の要点は、「個別に書く量」ではなく「自分宛てが伝わるか」で測ることです。

## 個別にする部分と型にする部分

四段の構成で、個別にする部分と型にする部分を分けます。

| 段 | 個別にする | 型にする | 理由 |
|---|---|---|---|
| 件名 | 相手の経歴に触れる部分 | 型（「〇〇のご経験を、△△の役割で」の形） | 受信箱で「自分宛て」を判断される |
| 一段落目 | 全部。経歴の具体的な一つと、役割との対応 | — | 「自分宛て」が決まる段 |
| 二段落目 | 「なぜ今」の一文を、相手の状況に合わせることも | 決める・誰と・どこまで。役割ごとの型 | 役割は相手で変わらない |
| 三段落目 | 相手が重く見そうな点の順番を変えることも | 会社の段階・理由・人・実態。型 | 会社の事実は相手で変わらない |
| 四段落目 | — | 次の一歩・返信のしやすさ・送り主・断りやすさ。型 | 相手で変わらない |
| 返信後の二通目 | 相手の質問に答える形で、個別 | 質問への答えの型を蓄積 | 質問は相手ごとに違う |

分ける要点は、「一段落目は全部個別、二〜四段落目は役割ごとの型」です。[文面の標準化と属人化の間](/media/scout-hyoujun-ka/)と同じ考え方です。

型は、役割ごとに一つ。同じ役割なら、二〜四段落目は同じ。一段落目だけを相手ごとに書けば、一通あたりの時間は、経歴を読む時間と、二〜三文を書く時間です。

## 個別にする部分の深さの段階

一段落目の「個別」には、深さの段階があります。相手と役割で使い分けます。

| 段階 | 中身 | 時間の目安 | 向いている相手 |
|---|---|---|---|
| 一、経歴の一つに触れる | 「〇〇で△△を担当されたご経験」。公開の経歴から一つ選び、役割との対応を一文 | 数分 | 動いている人、要件との合いが明確な人 |
| 二、経歴の中身に触れる | 「〇〇で△△の課題を、□□のやり方で解決されたご経験」。経歴の記述を読み込み、中身に触れる | 五〜十分 | 動いていない人、経験の深い人 |
| 三、経歴と役割の対応を具体的に | 「△△のご経験は、当社の□□の課題（具体的に）に、こう活きると考えています」。自社の課題と、相手の経験の対応を具体的に | 十〜十五分 | 幹部、専門職、競合が多い相手 |
| 四、相手の発信や実績に触れる | 公開されている発信、登壇、実績に触れる。「〇〇についての発信を拝見し」 | 十五分〜 | 幹部、経営幹部、発信のある専門職。[幹部・役員クラスへのアプローチ](/media/scout-kanbu-scout/) |

深さの要点は、「相手と役割に合わせて、段階を選ぶ」ことです。全員に段階四をやると、送れません。全員に段階一だと、経験の深い人には薄く見えます。

段階を選ぶ基準は、「その相手を採れたときの価値」と「競合の多さ」です。価値が高く、競合が多い相手ほど、深く。

公開されていない情報（私的な事情、非公開の経歴）には触れません。公開の範囲で。

### エラベルの見解

相談で最も多い失敗は、「『パーソナライズが大事』と聞いて、全文を一人ずつ書き始め、一日に三通しか送れず、三か月で返信が二件。『パーソナライズは効かない』と定型に戻した」というものです。個別にする部分を絞っていませんでした。二〜四段落目を役割ごとの型にし、一段落目だけを段階一〜二で書く形にしたら、一日に二十通送れ、返信率も上がりました。「全文か定型か」ではなく、「一段落目だけ個別」でした。

見ていて差がつくのは、担当者が「一段落目に時間を集中する」かどうかです。「一人ずつ丁寧に書きます」と全文に時間を使う担当者と、「二〜四段落目は型にして、一段落目に時間を使います。相手によって深さを変えます」と、配分を設計する担当者がいます。後者は、数と質の両方を保ちます。

発注側にできるのは、担当者に「全文を個別に」ではなく、「一段落目を、相手に合わせた深さで」と依頼することです。

## 時間の配分

一通あたりの時間を、どう配分するかです。

| 作業 | 時間の目安 | 個別か型か |
|---|---|---|
| 経歴を読む | 二〜五分（段階で変わる） | 個別 |
| 件名の個別部分を書く | 一分 | 個別 |
| 一段落目を書く | 三〜十分（段階で変わる） | 個別 |
| 二〜四段落目を差し込む | 一分（型をコピーし、役割名などを確認） | 型 |
| 全体を読み返す | 一〜二分 | — |
| 合計 | 段階一で十分弱、段階二で十五分ほど、段階三で二十分ほど | — |

配分の要点は、「経歴を読む時間と一段落目を書く時間が、大半」であることです。二〜四段落目に時間を使わない。

一日に使える時間から、送れる数が決まります。「一日に二時間」なら、段階一で十通ほど、段階二で八通ほど。送る相手を絞れば、深さを上げられます。

「送信数」ではなく「返信数」で評価すれば、深さを上げて数を減らす判断ができます。

## やりすぎの兆候とやらなさすぎの兆候

パーソナライズの範囲が合っているかを、兆候で見ます。

| やりすぎの兆候 | やらなさすぎの兆候 |
|---|---|
| 一通に三十分以上かかり、送れる数が対象に対して少なすぎる | 一段落目が「ご経歴を拝見して」だけ。返信で「一斉送信ですか」と聞かれる |
| 二〜四段落目まで個別に書き直している | 全員に同じ件名 |
| 相手の私的な情報や、公開されていない情報に触れようとしている | 経歴を読まずに送っている。経歴の読み違えの返信が来る |
| 一段落目が長く、褒め言葉が多い | 経験の深い人にも、段階一で送っている |
| 深さの段階を、全員に最大にしている | 深さの段階を、全員に最小にしている |
| 送る相手を絞りすぎて、母数が足りない | 送る相手を絞らず、要件と合わない人にも送っている |

兆候の要点は、「送れる数」と「返信率」の両方を見ることです。片方だけ見ると、やりすぎかやらなさすぎに偏ります。

やりすぎの兆候が出たら、二〜四段落目を型に戻し、深さの段階を相手で分けます。やらなさすぎの兆候が出たら、一段落目を段階一以上にし、経歴を読んでから書く運用に。

## 運用の型

パーソナライズを、運用にします。

| 項目 | 運用 |
|---|---|
| 型の整備 | 役割ごとに、二〜四段落目の型を一つ。件名の型を三〜四 |
| 一段落目の深さの基準 | 相手の層（動いているか、経験の深さ、幹部か、競合の多さ）で、段階一〜四を決める基準を書面に |
| 経歴を読む運用 | 送る前に、公開の経歴を読む。読んだ内容のメモ（触れる部分）を残す |
| 一段落目の記録 | 送った一段落目を記録。返信が来た一段落目と、来なかった一段落目を比べる |
| 返信の分析 | 返信で「〇〇に触れていただいて」と言われた部分が、効いた部分。記録して、次に活かす |
| 経歴の読み違えの確認 | 返信や辞退で「経歴が違う」と指摘されたら、読む運用を見直す |
| 深さと数の見直し | 月に一度、深さの段階ごとの返信率と、送れた数を見て、配分を見直す |
| 担当者間の統一 | 型と深さの基準を共有。担当者ごとにばらばらにしない |
| 触れてはいけないこと | 私的な事情、公開されていない情報、法令上の扱いがあるもの。専門家に確認のうえ一覧に |

運用の要点は、「一段落目を記録し、効いた部分を次に活かす」ことです。どの経歴のどの部分に触れると返信が来るかは、記録で分かります。経歴のどこに触れるかは、シリーズの次の記事で。

## 外注する場合の範囲

パーソナライズの範囲を、スカウト代行に出す場合の範囲です。

**出せる工程。** 個別にする部分と型にする部分の整理、役割ごとの二〜四段落目の型の作成、件名の型の作成、深さの段階の基準の設計、経歴を読んで一段落目を書く作業（段階に応じて）、一段落目の記録と返信との対応の分析、深さの段階ごとの返信率と送れた数の記録、月次の配分の見直し、触れてはいけないことの一覧（専門家の確認を経て）、担当者間の統一。

**社内に残す判断。** 役割の記述の確定、深さの段階の基準の承認、送る相手の絞り込みの方針、送り主の名義、評価の軸（送信数か返信数か）の決定。

**外注の効きどころ。** パーソナライズは、「経歴を読んで一段落目を書く」時間が要り、社内では「時間が無いので定型」になりやすい工程です。担当者が型を整え、一段落目に時間を集中し、深さを相手で変えて書けば、数と質が両立します。担当者は複数の会社のスカウトを見ているので、「この層にはこの深さ」「この一段落目は返信が来る」の型を持ち込めます。ただし、評価の軸を返信数に変えるのは社内の判断です。

**外注しても動かない場合。** 社内が「送信数」の評価を変えない、「全文を個別に」を求める、経歴を読む時間を認めない。社内の判断で、代行を替えても直りません。

パーソナライズは、一段落目に集中すれば、数と質が両立します。外注は、一段落目を書く時間と、深さの設計を担う手段です。

### エラベルの見解

担当する側から見ると、パーソナライズの相談で最も多いのは、「個別に見えるが、自分宛てとは伝わらない」文面です。「〇〇社でのご活躍を拝見し、ぜひご連絡したく」。会社名は差し替えているが、経歴の中身には触れていない。候補者は、「会社名を入れただけの定型」と見抜きます。

「〇〇社で△△を担当されたご経験が、当社の□□の役割で活きる」。経歴の中身と、役割との対応。これが「自分宛て」です。会社名の差し替えは、パーソナライズではありません。

発注側にできるのは、一段落目に「経歴の中身」と「役割との対応」が入っているかを、担当者の文面で確認することです。

## よくある質問

### 全文を一人ずつ書かないと、パーソナライズとは言えませんか

「自分宛て」が伝わるのは、一段落目（経歴の具体的な一つと、役割との対応）です。二〜四段落目（役割、会社、次の一歩）は、相手で変わらないので、役割ごとの型で足ります。全文を個別に書いても、候補者は一段落目で「自分宛てか」を判断するので、二〜四段落目の個別化は返信に効きにくいです。一段落目に時間を集中し、深さを相手で変えれば、一日に送れる数を保ちながら、「自分宛て」を伝えられます。

### 経歴を読む時間がありません

経歴を読まずに書いた一段落目は、「自分宛て」が伝わらず、返信が来ません。送信数を減らしてでも、経歴を読んで書きます。段階一（経歴の一つに触れる）なら、読む時間は数分です。評価を「送信数」から「返信数」に変えれば、読む時間が正当化されます。時間が取れないなら、「経歴を読んで一段落目を書く」作業をスカウト代行の担当者に出し、社内は型と深さの基準の承認に集中します。

### 個別に書いているのに、返信が来ません

「個別に見えるが、自分宛てとは伝わらない」文面になっていないかを確認します。「〇〇社でのご活躍を拝見し」は、会社名を差し替えただけで、経歴の中身に触れていません。「〇〇社で△△を担当されたご経験が、当社の□□の役割で活きると考えた」のように、経歴の中身と役割との対応を書きます。それでも返信が無ければ、送る相手が要件と合っていない可能性があります。[開封率と返信率のどちらを先に改善するか](/media/scout-kaifuuritsu/)で、落ちている場所を見分けます。
