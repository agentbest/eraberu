人材派遣の会社で、コーディネーターとして、企業の要件を聞き、登録している人の中から合う人を選び、就業の後も面談で支えてきた。この経験は、企業の直接採用の副業で売れるのか。派遣と直接採用は違い、派遣の形は副業では扱えない。結論を先に書くと、**人材派遣のコーディネーターの経験は、「要件の聞き取りと、人と仕事の合わせ方と、就業後の面談」で売れます。売れるのは、「依頼側の要件の言語化」「候補者と業務の適性の合わせ方」「入社後の定着の面談」「多数の候補者の同時進行」の四つです。依頼側の多くは、要件を言葉にできず、候補者と業務の相性を見られず、入社後の面談をしていません。コーディネーターは、それを毎日やってきています。派遣の形（自社で雇用して送り出す）は副業では持ち込まず、「要件を聞き、合わせ、定着させる型」を、依頼側の直接採用に転用して売ります。派遣や紹介の形で人を動かすことには許可が関わるため、その線は専門家にご確認ください。**人材紹介の経験の売り方は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に、候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に、ヒアリングの項目は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)にまとめています。

## この経歴の何が売れるか

派遣のコーディネーターの経験を、直接採用の工程に置き換えた棚卸しです。派遣の登録者と前の会社の情報は含めず、「型」として抜き出します。

| コーディネーターの経験 | 直接採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 企業の要件を聞き取ってきた | 依頼側の「こういう人がほしい」を、業務の中身、要る技能、要らない技能、職場の条件に分解して言葉にする | 要件が「良い人」で止まっている依頼側が多い |
| 人と仕事を合わせてきた | 候補者の経験と性格と希望を、業務と職場の条件に合わせて見る観点の型 | 経歴だけで見て、入社後に合わない依頼側が多い |
| 就業後の面談で支えてきた | 入社後の最初の期間に、本人と現場の両方から状況を聞き、ずれを早く直す面談の型 | 入社後の面談が無く、辞めてから気づく依頼側が多い |
| 多数の登録者を同時に動かしてきた | 複数の候補者の進捗と連絡を、漏れなく管理する型 | 候補者が複数になると連絡が漏れる依頼側が多い |
| 現場と本人の間で調整してきた | 現場の言い分と本人の言い分の両方を聞き、間を取り持つ | 現場と候補者の間に立つ人がいない依頼側が多い |
| 急な欠員に対応してきた | 急ぎの採用で、要件を絞り、短い期間で候補者を動かす段取り | 急な欠員で慌てる依頼側 |
| 多業種の職場を見てきた | 業種と職種ごとに、どんな人が定着し、どんな人が辞めるかの型 | 「うちの職場に合う人が分からない」依頼側 |

売れるものの要点は、「要件の聞き取りと、人と仕事の合わせ方と、定着の面談は、派遣でも直接採用でも同じ型」だということです。コーディネーターは、企業と人の間に立って、要件を言葉にし、相性を見て、就業後を支えることを、毎日やってきています。その型は、派遣の形を外しても、依頼側の直接採用にそのまま使えます。派遣の登録者を副業の依頼側に回すことは、前の会社の情報の持ち出しであり、許可の線にも関わるので、持ち込むのは型だけです。要件の聞き取りは[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、定着の面談は[キャリアコンサルタントが副業でできること](/media/fukugyo-kyaria-consultant-fukugyo/)に、並行の管理は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に書いています。

## 売りにくい点とその扱い

派遣のコーディネーターの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 派遣と直接採用の違い | 「派遣は自社の登録者から選ぶが、直接採用は探すところからで、探せるのか」「派遣の短期の感覚で、長期の採用を見られるのか」 | 探す工程（母集団づくり）は範囲に入れないか、依頼側の媒体と経路で学びながら担う。合わせる工程と定着の工程を主に売る。長期の定着を見る観点は、就業後の面談の経験で示す |
| 前の会社との線 | 「前の会社の登録者を連れてくるのでは」「前の会社の顧客を持ち込むのでは」 | 登録者と顧客の情報は持ち込まない。型だけを持ち込む。退職後の競業と守秘の条件を確認する |
| 派遣や紹介の形の許可の線 | 「副業で、人を紹介したり派遣したりする形になるのでは」 | 副業では、依頼側の担当者として、依頼側の直接採用を手伝う形に徹する。自分が人を雇って送る形、紹介の手数料を受ける形は取らない。許可に関わる線は専門家に確認する |

扱い方の要点は、「派遣と紹介の形を捨て、依頼側の担当者として動く」ことです。コーディネーターの習慣で、「合う人を連れてくる」形で副業を受けようとすると、前の会社の登録者の持ち出しと、派遣や紹介の許可の線の両方に触れます。副業では、依頼側の担当者として、依頼側の名前で候補者を探し（または依頼側が集めた候補者を）、合わせ、定着させる形に徹します。許可に関わる線は、専門家にご確認ください。法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)の「法令で気をつける点」に、前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、派遣のコーディネーターから転身して続いている人と、案件が取れない人の差は、経験の長さではなく、「派遣の言葉のまま売っているか、直接採用の工程に置き換えているか」です。取れない人は、「派遣のコーディネーターでした」で終わり、依頼側は「うちは派遣を使わない」で終わります。続いている人は、「御社の要件を業務と技能と職場の条件に分解して言葉にし、候補者との相性を見て、入社後の面談で定着させます」と工程で示し、依頼側は「うちの詰まりはそこだ」となります。

見ていて差がつくのは、就業後の面談の型を、直接採用の定着の面談に持ち込んでいるかです。コーディネーターは、就業後の面談で、本人と現場の両方から状況を聞き、ずれを早く直すことを繰り返してきていて、この型は依頼側の直接採用ではほとんど行われていません。入社後の最初の期間に、本人と現場の両方に面談し、ずれを拾って直す人は、依頼側の早期離職を減らし、「採用の後ろの詰まりを埋めてくれた」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、要件の言語化と合わせ方と定着の型を明確にし、派遣の形との線を示している担当者に、定着で詰まっている依頼側がついています。コーディネーターの転身は、派遣の知識ではなく、型の転用で始まります。

## 案件の探し方

派遣のコーディネーターから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 依頼側の要件の言語化 | 要件を聞き取ってきた経験でそのまま入れる | 「『良い人がほしい』を、業務と技能と職場の条件に分解する」を範囲の一言に |
| 候補者と業務の相性の見方の型 | 人と仕事を合わせてきた経験で入れる | 「経歴だけでなく、業務と職場に合うかを見る観点」を成果物の形で |
| 入社後の定着の面談 | 就業後の面談の経験で入れる | 「入社後に辞める依頼側」を範囲の一言に |
| 複数の候補者の同時進行の管理 | 多数を動かしてきた経験で入れる | 「候補者が複数になると漏れる依頼側」を範囲の一言に |
| 現場と候補者の間の調整 | 間で調整してきた経験で入れる | 「現場と候補者の間に立つ人がいない依頼側」に |
| 急な欠員の採用の段取り | 急な対応の経験で入れる | 「急ぎの採用の段取り」を示す。探す工程は依頼側の媒体と経路で |

探し方の要点は、「入社後に辞める依頼側」から入ることです。依頼側にとって、採れたのに辞めることは、採用の費用と時間が消える最も分かりやすい損失で、定着の面談の型が最も効きます。一件で早期離職を減らせれば、要件の言語化と相性の見方に広げられます。探す工程（母集団づくり）は、コーディネーターの経験では弱い部分なので、最初は範囲に入れないか、依頼側の媒体と経路で学びながら担います。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。派遣のコーディネーターの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 派遣の料金との比較 | 派遣の料金は、雇用と管理を含む形で決まっていて、個人の副業の単価とは別物 | 派遣の料金の感覚を持ち込まない。担当者の工程の単価で |
| 定着の面談の価値 | 早期離職を減らす価値は、依頼側にとって分かりやすい | 面談は回数で受ける。「減った離職」を成果として示せる形に |
| 要件の言語化と相性の型 | 成果物で受けやすい | 成果物で受けると、単価の議論が明確になる |
| 探す工程を含まないこと | 母集団づくりを含まない範囲は、含む範囲より単価は下がるが、責任の線が明確 | 合わせる工程と定着の工程で単価を出す |
| 判断を含まないこと | 合否の判断は依頼側。自分は相性の観点と面談の結果を材料として渡す | 判断を引き受けない |
| 前の会社との契約の条件 | 退職後の競業と守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「派遣の料金の感覚を持ち込まず、定着の面談を回数で受ける」ことです。派遣の料金は、雇用と管理と就業後の支援を含む形で決まっていて、副業の個人の単価とは決まり方が違います。副業では、要件の言語化と相性の型を成果物で、定着の面談を回数で、複数の候補者の管理を月額で、と分けて受けます。前の会社との契約に退職後の条件がある場合は、それを確認し、個別の判断は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

派遣のコーディネーターから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、前の会社との契約の条件（退職後の競業、守秘、登録者と顧客との接触）を確認する | 個別の判断は専門家に |
| 二、派遣や紹介の形で人を動かすことの許可の線を、専門家に確認し、副業では依頼側の担当者の形に徹すると決める | 形の切り替え |
| 三、要件の聞き取り、相性の見方、就業後の面談の型を、登録者と顧客の情報を含まない形で書き出す | 型の抜き出し |
| 四、派遣の言葉を、直接採用の言葉に置き換える | 「就業後の面談」→「入社後の定着の面談」、「登録者」→「候補者」 |
| 五、範囲を、要件の言語化、相性の見方、定着の面談、同時進行の管理、現場との調整に絞る | 探す工程は最初は範囲外か、学びながら |
| 六、「要件を聞き、合わせ、定着させる型を、直接採用に」の一言を作る | 「派遣のコーディネーターでした」で終わらせない |
| 七、登録先に、範囲と、派遣の形との線を登録する | 入社後に辞める依頼側 |
| 八、定着の面談か要件の言語化を一件、回数か成果物で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「二」の形の切り替えを、案件を探す前にやることです。コーディネーターの転身では、「合う人を連れてくる」形のまま副業を受けると、前の会社の登録者の持ち出しと、派遣や紹介の許可の線の両方に触れます。専門家に確認し、依頼側の担当者の形に徹すると決めてから、型を売ります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「派遣のコーディネーターの経験は派遣の会社の中のもので、企業の直接採用では使えない」というものです。実際には、要件の聞き取り、人と仕事の合わせ方、就業後の面談は、依頼側の直接採用で最も欠けている工程で、コーディネーターが毎日やってきた型がそのまま効きます。使えないのは派遣の形であって、型ではありません。形を捨て、型を直接採用に転用した人が、定着の詰まりを埋めています。

順番として、前の会社との契約の条件を確認し、許可の線を専門家に確認して担当者の形に徹すると決め、型を登録者と顧客の情報を含まない形で書き出し、派遣の言葉を直接採用の言葉に置き換え、範囲を要件と相性と定着と管理と調整に絞り、型を直接採用に、の一言を作り、登録先に範囲と線を登録し、定着の面談か要件の言語化を一件受けて型を残す。この順番で、コーディネーターの転身は、「派遣の中の経験」から「直接採用の定着を埋める型」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、要件の言語化と合わせ方と定着の型を明確にし、派遣の形との線を示している担当者に、定着で詰まっている依頼側がついています。コーディネーターの転身は、派遣の知識ではなく、型の転用で始まります。

## まとめ

- 派遣のコーディネーターの経験は**「要件の聞き取りと、人と仕事の合わせ方と、就業後の面談」**で売れる。**要件の言語化・相性の見方・定着の面談・同時進行の管理**の四つ
- **派遣の形は持ち込まず、「要件を聞き、合わせ、定着させる型」を直接採用に転用**して売る
- 売りにくい点は**派遣と直接採用の違い・前の会社との線・許可の線**。探す工程は最初は範囲外、登録者と顧客の情報は持ち込まず、許可の線は専門家に確認
- 最も効くのは**就業後の面談の型を、入社後の定着の面談に持ち込む**こと
- 案件は**入社後に辞める依頼側**から。要件の言語化と相性の見方に広げる
- 単価は**派遣の料金の感覚を持ち込まず、要件と相性は成果物、定着の面談は回数、管理は月額**で。前の会社との条件は専門家に確認

## よくある質問

### 前の会社の登録者で、依頼側に合いそうな人がいます。声をかけてよいですか

声をかけません。前の会社の登録者との関係と情報は、前の会社と本人のものであり、副業の依頼側に回すと、前の会社との守秘と競業の線、本人の信頼、派遣や紹介の許可の線の三つに問題が出ます。副業では、依頼側の名前で、依頼側の媒体と経路で候補者を探すか、依頼側が集めた候補者を合わせる形にします。個別の判断は専門家にご確認ください。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に整理しています。

### 探す工程（母集団づくり）の経験が無く、依頼側に「候補者を集めてほしい」と言われると困ります

範囲を、要件の言語化、相性の見方、定着の面談、同時進行の管理に絞り、探す工程は依頼側か別の担当者が担う形にします。「候補者を集めるのは御社の媒体と経路で。集まった候補者を、要件に合わせて見て、入社後に定着させるところを担います」と示せば、範囲が明確です。探す工程も担いたいなら、依頼側の媒体でスカウトの運用を学びながら、小さく担います。エラベルのような登録先では、工程ごとに担当者を分けて依頼できる依頼側もあります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、スカウトの運用は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に書いています。

### 派遣では短期の就業が多く、長期の採用の見方に自信がありません

就業後の面談で、本人と現場の両方から状況を聞き、ずれを早く直す型は、期間の長短に関係なく、入社後の定着に効きます。長期の採用で見るべきこと（数年後の役割、成長の道筋）は、依頼側の判断の領域で、自分は「入社後の最初の期間にずれを拾って直す」工程を担います。長期の見方は、依頼側の経営者や現場の責任者と一緒に、案件の中で学びます。短期の経験は、「最初の期間で辞める理由」を最もよく知っているという強みでもあります。定着の面談の型は[キャリアコンサルタントが副業でできること](/media/fukugyo-kyaria-consultant-fukugyo/)に整理しています。
