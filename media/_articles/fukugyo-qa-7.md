副業を始めてみたいが、依頼側と合わなかったとき、簡単にやめられるのかが不安だ。一度受けたら長く縛られるのではないか、やめると言ったら揉めるのではないか。結論を先に書くと、**人事の副業は、契約の期間と終了の条項に沿えば、やめられます。多くの案件は数か月の期間で区切られ、更新の節目で終えられる形になっています。不安を減らすには、「最初の契約を三か月程度で区切る」「終了の条項を契約の前に読む」「合わないと感じたら更新の節目で終える」「引き継ぎを整えて終える」の四つを、始める前に知っておくことです。**やめること自体は問題ではなく、やめ方で依頼側との関係が残るかどうかが決まります。契約の期間の考え方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、依頼側から終了を言われた場合は[契約を切られたとき](/media/fukugyo-kaiyaku-sareta/)にまとめています。契約の解釈は、専門家にご確認ください。

## やめられるかを決める契約の仕組み

やめられるかどうかは、気持ちではなく、契約の三つの条項で決まります。

| 条項 | 何が書かれているか | 読み方 |
|---|---|---|
| 契約の期間 | 「〇月〇日から〇月〇日まで」「三か月」など | 期間が来れば、更新しなければ終わる。期間が長いほど、途中でやめにくい |
| 更新の方法 | 「双方の合意で更新」「申し出が無ければ自動で更新」など | 自動更新なら、終える意思を期限までに伝える必要がある |
| 途中で終える方法 | 「〇日前までに書面で通知すれば解約できる」など | 期間の途中でも、通知の期間を守れば終えられることが多い。通知の期間が長いと、すぐにはやめられない |

仕組みの要点は、「三つの条項を、契約の前に読む」ことです。期間が一年で、途中の解約に三か月の通知が要る契約なら、合わないと感じてからやめるまでに時間がかかります。期間が三か月で、一か月前の通知で終えられる契約なら、合わなければ短い期間で終えられます。契約の前に読んで、やめにくい条項なら、期間を短くすることを依頼側と相談します。条項の読み方は[請求や契約は自分でやるのか](/media/fukugyo-qa-15/)に、条件の相談の仕方は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に書いています。条項の解釈は、専門家にご確認ください。

## 最初の契約を短く区切る理由

最初の一件は、依頼側にとっても自分にとっても「合うかどうか分からない」状態です。短く区切ると、双方が動きやすくなります。

| 短く区切る利点 | 内容 |
|---|---|
| 合わなければ短い期間で終えられる | 三か月なら、合わないと分かった時点から、長くても数か月で終わる |
| 依頼側も「まず試す」形で受けやすい | 依頼側も、外部の担当者が合うか分からない。短い期間なら決めやすい |
| 更新の節目で条件を直せる | 三か月で範囲・稼働・単価のずれが見え、更新のときに直せる。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |
| 「やめる」ではなく「更新しない」で終えられる | 途中で解約するより、期間が来て更新しない形のほうが、双方の負担が小さい |
| 続けば、更新で長くできる | 合えば、二期目から半年や一年にすればよい |

短く区切る要点は、「やめる」と「更新しない」は、依頼側の受け取り方が違うことです。途中で「やめます」と言うと、依頼側は理由を探します。期間が来て「今期で終えたい」と言うと、依頼側は節目の判断として受け取ります。最初を短く区切っておけば、合わなかったときの終え方が、後者になります。期間の決め方は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「一度受けたら、やめると言い出しにくく、長く縛られる」というものです。実際には、依頼側の担当者も、外部の担当者が合わなければ終えたいと思っていて、期間を区切って始めることを望んでいることが多いです。「まず三か月で」と担当者の側から言うことも珍しくありません。縛られるのは、契約の期間と終了の条項を読まずに、長い期間で結んだときだけです。

見ていて差がつくのは、合わないと感じたときに、「やめる」ではなく「今期で終える」と言えるように、最初から期間を区切っているかです。区切っている人は、合わなければ更新の節目で「今期で終えさせてください」と伝え、引き継ぎを整えて終え、依頼側との関係は残ります。区切っていない人は、途中で「やめたい」と言い出せずに続け、稼働が落ち、依頼側から終了を告げられる形になり、関係は残りません。エラベルでは、依頼側と担当者の最初の契約を短い期間で区切る形を勧めており、更新の節目で双方が続けるかを判断できるようにしています。やめられる仕組みがあるほうが、始めやすく、続きやすくなります。

## 合わないと感じたときの見分け方

「合わない」と感じたとき、それが本当に合わないのか、一時的なものかを分けます。分けずにやめると、次の案件でも同じところで止まります。

| 感じていること | 一時的か、本当に合わないか | 見分け方 |
|---|---|---|
| 依頼側の担当者と話がかみ合わない | 最初の数週間なら一時的なことが多い | 一か月経っても、報告の形と頻度を合わせてもかみ合わないなら、本当に合わない。[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/) |
| 範囲が広がって疲れる | 範囲の問題で、案件の問題ではない | 範囲を戻す相談をして、戻らなければ合わない。[範囲が広がっていくとき](/media/fukugyo-scope-creep/) |
| 稼働が枠を超える | 枠の問題か、範囲の問題か | 稼働ログで見る。範囲を絞れば枠に入るなら、案件の問題ではない |
| 依頼側の判断が遅く、進まない | 依頼側の体制の問題 | 判断の所在と期限を決めても変わらなければ、その依頼側の体制に自分が合わない。[権限がないと動けない場面](/media/fukugyo-kengen-nai/) |
| 業務の内容そのものが面白くない | 範囲の中身の問題 | 別の工程なら面白いのか、人事の業務全体が合わないのか。前者なら範囲を変える、後者なら副業の向き不向き |
| 依頼側の情報の扱いや、候補者への姿勢に疑問がある | 本当に合わない | 改善の提案をして変わらなければ、続けない。[注意したほうがよい依頼](/media/fukugyo-chuui-kigyou/) |

見分けの要点は、「範囲と稼働の問題は、案件を変えなくても直せる」ことです。合わないと感じる理由の多くは、範囲が広すぎるか、稼働が枠を超えているかで、これは案件の問題ではなく条件の問題です。条件を直して、それでも合わないなら、案件が合わないと判断します。直す前にやめると、次の案件でも範囲と稼働の問題が起きます。直し方は[続かない人の共通点](/media/fukugyo-tsuzukanai/)に書いています。

## やめる時期の選び方

合わないと判断したら、やめる時期を選びます。時期で、依頼側の受け取り方と、自分の負担が変わります。

| 時期 | 依頼側の受け取り方 | 自分の負担 |
|---|---|---|
| 契約の期間の終わり（更新しない） | 節目の判断として受け取る。最も自然 | 引き継ぎを整える時間がある。最後の請求も明確 |
| 途中だが、通知の期間を守って | 契約に沿った終了として受け取る。理由は聞かれる | 通知から終了までの間、稼働を保ちながら引き継ぎを整える |
| 依頼側の採用の区切り（内定が出た、募集が終わった） | 「一区切りついたので」と受け取りやすい | 区切りに合わせるので、引き継ぎが軽い |
| 依頼側の担当者の交代 | 新任にとっては、外部の担当者が替わることの負担が小さい時期 | 前任との経緯を新任に説明しなくて済む |
| 途中で、通知の期間を守れずに | 契約に反する形。信頼を失う。契約によっては責任が生じる | 避ける。やむを得ない場合は、事情を伝え、依頼側の判断に委ねる。[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/) |

時期の要点は、「契約の期間の終わりに合わせる」ことです。合わないと感じてから、次の更新の節目までの数週間から数か月は、稼働を保ちながら、引き継ぎを整える期間にします。この期間に手を抜くと、「合わないから雑になった」と見られ、終え方が悪くなります。節目までの期間の過ごし方は[契約更新のされ方](/media/fukugyo-koushin/)にも書いています。

## やめ方で信頼が残る形

同じ「やめる」でも、やめ方で、依頼側との関係が残るか切れるかが決まります。

| やること | 内容 |
|---|---|
| 一、決めたら早く伝える | 更新の節目の一か月以上前に、「今期で終えさせてください」と伝える。依頼側が次を探す時間を残す |
| 二、理由は短く、依頼側を責めない | 「本業の都合で稼働が取れなくなる」「自分の範囲と合わなくなった」など、事実を一文。依頼側の体制や担当者への不満は言わない |
| 三、終了日までの稼働を保つ | 終えると決めた後も、候補者への対応と依頼側への報告を落とさない |
| 四、引き継ぎを整える | 記録、型、判断の所在、進行中の候補者の状況を、依頼側の仕組みの中に残す。[引き継ぎの進め方](/media/fukugyo-hikitsugi/) |
| 五、最後の請求とアカウントを確認する | 最後の稼働分の請求の日、アカウントの停止、資料の返却を文面で確認する。[アカウント管理のしかた](/media/fukugyo-account-kanri/) |
| 六、終わりに一言残す | 「次に採用の手が要るときは、お声がけください」。範囲が合う別の案件なら受けられることを示す |

やめ方の要点は、「二」の理由で依頼側を責めないことです。合わない理由が依頼側の側にあっても、それを終了の理由として伝えると、依頼側は反論するか、印象を悪くするかで、関係が切れます。「自分の範囲と合わなくなった」「本業の都合で」と、自分の側の事実として伝えれば、依頼側は受け取りやすく、後で別の案件で声がかかることもあります。窓口を通している案件では、窓口に先に伝え、窓口が依頼側との間に入る形もあります。

## やめた後の入口の残し方

やめた案件は、終わりではなく、次の入口の一つになります。残し方を知っておきます。

| 残し方 | 内容 |
|---|---|
| 依頼側の担当者との連絡の経路 | 終了時に「次に手が要るときは」と一言添えておけば、担当者が別の採用や別の会社で思い出す。[紹介を頼むタイミング](/media/fukugyo-shoukai-tanomu/) |
| 自分の実績 | 依頼側の情報を抜いた形で、範囲と判断と進め方を記録に残す。合わなかった案件でも、担当した工程は実績になる。[実績の示し方](/media/fukugyo-jisseki-shimeshikata/) |
| 合わなかった理由の言葉 | 「判断が遅い体制は合わない」「範囲が曖昧な依頼は合わない」のように、次の案件を選ぶ基準として言葉にする |
| 範囲の一言の更新 | やめた経験で範囲が絞れたなら、登録先のプロフィールの範囲を書き直す。[プロフィールの書き方](/media/fukugyo-profile/) |
| 窓口との関係 | 窓口を通していた案件なら、終了の経緯を窓口に伝え、次の案件の提示に活かしてもらう |

入口の要点は、「合わなかった理由を、次の案件を選ぶ基準にする」ことです。やめた経験は、自分がどの型の依頼側と合うかを教えてくれます。「判断が速い依頼側なら合う」「範囲が明確な依頼なら合う」と分かれば、次の案件の選び方が変わり、二件目は続きやすくなります。依頼側の型の見分け方は[どんな会社から依頼が来るのか](/media/fukugyo-qa-11/)に整理しています。

### エラベルの見解

担当する側から見ると、合わない案件を終えても次の案件が続いている人は、終え方が整っています。更新の節目の一か月以上前に伝え、理由は自分の側の事実で、終了日まで稼働を保ち、引き継ぎを依頼側の仕組みに残し、最後に一言添える。この形で終えた案件の依頼側から、数か月後に別の案件の相談が来ることは珍しくありません。合わなかったのは範囲や体制の相性で、担当者への信頼は残っているからです。

順番として、最初の契約を短く区切り、終了の条項を読み、合わないと感じたら範囲と稼働の問題かを分け、条件を直しても合わないなら更新の節目で終えると決め、早く伝え、稼働を保ち、引き継ぎを整え、一言残す。この順番で、やめることは失敗ではなく、次の案件の選び方を教えてくれる経験になります。エラベルでは、依頼側と担当者の契約を短い期間で区切り、更新の節目で双方が判断できる形にしており、合わなかった場合も窓口が間に入って終え方を整えています。やめられる仕組みは、始めるための仕組みでもあります。

## まとめ

- やめられるかは**契約の期間・更新の方法・途中で終える方法**の三つの条項で決まる。契約の前に読む
- **最初の契約は三か月程度で区切る**。「やめる」ではなく「更新しない」で終えられる
- 合わないと感じたら**範囲と稼働の問題か、案件の問題か**を分ける。条件を直してから判断する
- やめる時期は**契約の期間の終わり**に合わせる。節目まで稼働を保ち、引き継ぎを整える
- やめ方は**早く伝え・理由は自分の側の事実で・稼働を保ち・引き継ぎを整え・請求とアカウントを確認し・一言残す**
- やめた案件は**次の入口**。合わなかった理由を、次の案件を選ぶ基準にする

## よくある質問

### 始めて数週間で、明らかに合わないと感じています。すぐやめてよいですか

数週間なら、まず一時的なものか本当に合わないかを分けます。担当者との話のかみ合わなさや、範囲の広がりは、最初の数週間に起きやすく、報告の形を合わせたり範囲を戻したりすれば直ることが多いです。直しても合わないなら、契約の終了の条項を見て、通知の期間を守って終えるか、最初の契約の期間まで続けて更新しないかを選びます。すぐやめるより、契約に沿って終えるほうが、依頼側との関係は残ります。候補者への不利益や情報の扱いに問題がある場合は、その限りではなく、早く終えることを優先します。

### やめると伝えたら、依頼側から引き止められました

引き止めの内容が、範囲や稼働や単価の見直しなら、それで合う形になるかを考えます。合わない理由が条件の問題なら、見直しで続けられることがあります。合わない理由が依頼側の体制や情報の扱いなら、条件を変えても合わないので、「ありがたいのですが、今期で終えさせてください」と、判断を変えずに伝えます。引き止めに応じて続け、結局また合わなくなると、二度目の終え方はより難しくなります。断り方は[断り方](/media/fukugyo-kotowaru/)に整理しています。

### 途中でやめると、報酬や損害の請求で不利になりませんか

契約の終了の条項に沿って、通知の期間を守り、引き継ぎを整えて終えれば、一般に、途中で終えたこと自体で不利になることは多くないと整理されています。問題になるのは、通知の期間を守らずに突然止めた場合や、引き継ぎをせずに依頼側に損が出た場合です。契約書の終了と損害の条項は、契約の前に読み、分からなければ専門家にご確認ください。最後の稼働分の請求は、終了日までの稼働で出し、文面で確認しておきます。
