「障害者雇用の数が足りないので、採用を手伝ってほしい」という依頼は、数を満たすことから始まると、採ってもすぐに離れ、また数が足りなくなります。数の前に、「どの役割を担ってもらうか」「受け入れの体制はあるか」「配慮の情報は誰が扱うか」「続ける仕組みはあるか」が要ります。結論を先に書くと、**障害者雇用の実務は、役割を作る・受け入れを整える・配慮の窓口を決める・続ける仕組みを置くの四つを回すもので、役割は切り出しではなく担ってもらう仕事として作り、配慮の情報は本人の同意の範囲で会社の中だけに置いて担当者は手元に持たず、支援機関との窓口は依頼側に置き、法令上の義務や制度の適用は専門家に確認し、週次・月次のリズムで回し、定着の面談は会社の人が行います。**案件として受ける形は[障害者雇用の実務の副業の実務](/media/fukugyo-shougai-koyou-shigoto/)に、会社側から見た考え方は[障害者雇用の法定雇用率が達成できない](/media/rpo-shougaisha-koyou/)に書いています。ここでは、日々の運用を回す型に絞ります。

## 「数を満たす」から始めると続かない

| 数から始める形 | 何が起きるか |
|---|---|
| 「〇人採る」だけが決まっている | 役割が無く、入社後に仕事が無い |
| 受け入れの担当がいない | 現場が困り、本人が孤立する |
| 配慮の情報が現場に広がる | 本人の信頼を失い、扱いの問題になる |
| 支援機関と会社の窓口が曖昧 | 連絡が担当者に集まり、担当者が替わると切れる |
| 続ける仕組みが無い | 定着の面談が無く、離れる兆しに気づかない |

数は、四つが回った結果として満たされます。数から始めると、採用と離職を繰り返します。法令上の義務（雇用率など）の内容と適用は、依頼側と専門家で確認し、担当者が断定しません。

## 回す四つ

| 回すこと | 中身 | 担当 |
|---|---|---|
| 役割を作る | 部署の仕事を聞き取り、担ってもらう仕事を決める。「切り出し」ではなく「役割」として | 担当者が聞き取りと一覧、依頼側が決定 |
| 受け入れを整える | 受け入れの担当（毎日短く話す人）、環境、一緒に働く人への共有（本人の同意の範囲で） | 依頼側の現場と人事。担当者は設計 |
| 配慮の窓口を決める | 配慮に関する相談と情報を扱う人を、会社の中で一人に決める | 依頼側の人事。担当者は扱わない |
| 続ける仕組みを置く | 定着の面談の型、支援機関との連携の型、見直しの周期 | 担当者が型、会社の人が実施 |

四つのうち、担当者が最も関われるのは「役割を作る」と「続ける仕組みの型」です。「受け入れ」と「配慮の窓口」は、依頼側の中に置きます。

### エラベルの見解

担当する側から見ると、障害者雇用の実務で最も差がつくのは、「役割を作る」を「仕事の切り出し」で終わらせないことです。受ける側は、部署から「誰でもできる作業」を集めて一覧にし、それを役割にします。集めた作業は、量が安定せず、現場が「頼む作業が無い」となり、本人は「自分の仕事が無い」と感じます。「この部署で、この仕事を、この人が担う」と、役割として決め、量と期限と相談先を付ける。役割になっていれば、本人は自分の仕事として動け、現場も一緒に働く人として扱います。エラベルで担当者を選ぶ企業には、「障害者雇用の方の仕事は、作業の寄せ集めではなく、役割になっていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、役割の一枚に「担う仕事・量の目安・期限・相談先・一緒に働く人」の五つを書き、一つでも空欄なら役割になっていないとして、聞き取りに戻ること。

## 役割を作る手順

| 順 | 中身 |
|---|---|
| 一 | 部署ごとに「いま、誰かがやっていて、続いている仕事」を聞き取る。作業ではなく仕事の単位で |
| 二 | その仕事のうち、量が安定していて、期限が明確で、相談先を置けるものを候補に |
| 三 | 候補を「担う仕事・量の目安・期限・相談先・一緒に働く人」の五つで一枚に |
| 四 | 本人の得意と配慮（本人が自分から言った範囲で）と照らす。照らすのは本人と配慮の窓口 |
| 五 | 依頼側が役割を決める。担当者は一枚を作るまで |

聞き取りの型は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)と同じです。「この仕事を任せられる人」を要件にし、障害の種類や程度を要件にしません。

## 配慮の情報の扱い

| 決めること | 中身 |
|---|---|
| 誰が扱うか | 会社の中で一人（配慮の窓口）。担当者は扱わない |
| 何を記録するか | 本人が同意した配慮の内容だけ。障害の詳細や医療の情報は、本人の同意の範囲を超えて記録しない |
| 誰に共有するか | 本人が同意した範囲の人に、同意した内容だけ。一緒に働く人への共有も同意の範囲で |
| 担当者の手元 | 置かない。役割の一枚には配慮の情報を書かない |
| 支援機関との共有 | 本人の同意の範囲で、依頼側の窓口が |

配慮の情報は、個人情報の中でも扱いに注意が要るもので、法令上の整理があると一般に整理されています。担当者は「役割」と「仕組みの型」を扱い、配慮の情報には触れません。個別の判断は専門家にご確認ください。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## 支援機関との連携

| 決めること | 中身 |
|---|---|
| 会社の窓口 | 依頼側の人事の一人。担当者ではない |
| 連携の型 | 誰が、いつ（入社前、入社後の節目、困りごとが出たとき）、何を（役割の状況、本人の同意の範囲の情報）、共有するか |
| 支援機関からの助言 | 受け入れの設計と続ける仕組みに反映する。反映の判断は依頼側 |
| 担当者の役割 | 連携の型を一枚にし、窓口が依頼側にあることを確かめるまで |

支援機関との連絡が担当者に集まると、担当者が替わったときに切れます。窓口は依頼側に置き、担当者は型を作ります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「定着の面談を、担当者が本人と行うのが丁寧」というものです。実際には、副業の担当者が本人と面談すると、本人は「会社の外の人」に配慮の情報を話すことになり、担当者が替わったときに関係が切れ、配慮の情報が担当者の手元に残ります。面談は会社の人（受け入れの担当か配慮の窓口）が行い、担当者は面談の型（聞くこと・聞かないこと・記録の形）を渡すまでです。受ける側がその場で使える判断としては、面談の型の「記録の形」を、「役割の状況（担う仕事が回っているか）」と「本人が伝えたい困りごと（同意の範囲）」の二つだけにし、配慮の詳細を書く欄を作らないこと。

## 週次・月次のリズム

| 頻度 | 中身 | 誰が |
|---|---|---|
| 毎日 | 受け入れの担当が短く話す。今日の仕事の確認 | 現場 |
| 週次 | 役割の状況（量、期限、相談の有無）を一行 | 現場の責任者 |
| 月次 | 定着の面談。役割の状況と、本人が伝えたい困りごと | 会社の人 |
| 節目（三か月・半年） | 役割の見直し、支援機関との共有（同意の範囲で） | 依頼側の人事と現場 |
| 担当者 | 週次と月次の記録の形が回っているかを確かめる。役割の一枚を見直す | 担当者 |

リズムは、通常のオンボーディングと定着の型と同じです。型は[オンボーディングを設計する](/media/fukugyo-skill-onboarding/)と[定着まで見る](/media/fukugyo-skill-teichaku/)に書いています。障害者雇用だからといって、特別な型を作りません。配慮の情報の扱いと、支援機関との連携の二つを足すだけです。

## 法令上の義務と制度の適用は専門家に

雇用率、届け出、助成の制度、合理的な配慮の範囲などは、法令上の整理があり、内容も変わります。担当者は「一般にこう」と断定せず、依頼側の決まりと専門家（社労士等）の確認に従います。役割の一枚と仕組みの型に「専門家に確認する項目」の欄を置き、依頼側が確認した内容で埋めます。個別の判断は専門家にご確認ください。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「〇人採る」から始める | 役割の一枚を先に。役割の数が採る数の根拠 |
| 仕事が作業の寄せ集め | 役割の五つ（担う仕事・量・期限・相談先・一緒に働く人）で作り直す |
| 配慮の情報が現場に広がった | 配慮の窓口を一人に決め、共有の範囲を本人の同意で。担当者は触れない |
| 支援機関の連絡が担当者に来る | 依頼側の窓口に戻す |
| 定着の面談を担当者がしている | 会社の人に移し、型を渡す |
| 法令の内容を担当者が断定した | 専門家の確認に戻す |

## まとめ

- **数から始めると続かない**。役割・受け入れ・配慮の窓口・続ける仕組みの四つを回した結果が数
- 役割は**切り出しではなく担ってもらう仕事**。担う仕事・量・期限・相談先・一緒に働く人の五つ
- **配慮の情報は会社の中の一人が、本人の同意の範囲で**。担当者は扱わず、手元に置かない
- **支援機関との窓口は依頼側**。担当者は連携の型を作るまで
- リズムは**通常のオンボーディングと定着の型と同じ**。足すのは配慮の扱いと支援機関の連携の二つ
- 定着の面談は**会社の人が行い**、担当者は型と記録の形まで
- **法令上の義務と制度の適用は専門家に**。担当者は断定しない。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側から「どんな障害の人なら採れるか」と聞かれました

障害の種類や程度を採用の基準にする問いには答えません。「どの役割を担ってもらうかを先に決め、その役割を担える人を、本人の得意と本人が言う配慮の範囲で照らします」と、役割から始める形に置き換えます。照らすのは本人と配慮の窓口で、担当者は役割の一枚を作るまでです。基準に関わる法令上の整理は専門家に確認します。

### 現場から「受け入れの余裕が無い」と言われました

役割の一枚の「一緒に働く人」と「相談先」が埋まらない部署では、受け入れができません。埋まる部署から始めます。全部署に同時に受け入れを求めず、一つの役割を一つの部署で回し、その型を次の部署に広げます。受け入れの担当の負担は「毎日短く話す」で足り、一日中つく必要は無いことを、現場に伝えます。

### 支援機関から、会社の受け入れ体制への指摘がありました

指摘は、受け入れの設計と続ける仕組みを直す材料です。依頼側の窓口が受け取り、担当者は指摘を「受け入れの一枚のどこを直すか」に落として依頼側に渡します。直すかどうかは依頼側の判断です。支援機関との関係は依頼側のもので、担当者が支援機関と直接やり取りする形にはしません。
