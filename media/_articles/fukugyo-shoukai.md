人事の副業で最初の案件が決まる経路として、知人の紹介は多いものの一つです。「採用で困っている会社がある」と元同僚や前職のつながりから声がかかり、相手も自分のことをある程度聞いているので、立ち上がりが早い。一方で、紹介には紹介者の関係が乗ります。範囲の線を引きにくい、条件を言い出しにくい、合わないと分かっても断りにくい。結論を先に書くと、**紹介で受けるときは「紹介者の顔を立てる」と「範囲と条件を書面で決める」を分けて考え、紹介者には感謝を、依頼側には書面を、それぞれ別に出す**のが、関係を保ったまま続けられる形です。紹介者への配慮を理由に書面を省くと、後で困ったときに紹介者まで巻き込むことになります。案件の探し方全体は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、直接契約で自分が担うことは[企業から直接受けるには](/media/fukugyo-chokusetsu/)にまとめています。

## 紹介が生まれる構造と、そこに乗る関係

紹介は、紹介者が「困っている会社」と「できる人」の両方を知っているときに生まれます。この構造を理解しておくと、紹介者が何を期待し、何を心配しているかが見えます。

| 登場する人 | 立場 | 期待していること | 心配していること |
|---|---|---|---|
| 紹介者 | 依頼側とも自分とも関係がある | 困っている知人を助けたい。自分の紹介が役に立ったと思いたい | 紹介した人が合わなかったとき、自分の信用が下がる |
| 依頼側 | 採用で困っている。紹介者を信頼している | 紹介者が言うなら、と期待している。範囲や条件は詳しく考えていないことが多い | 知人の紹介なので、条件の交渉や断ることがしにくい |
| 自分 | 紹介を受けた側 | 最初の案件を決めたい。紹介者の期待に応えたい | 範囲が曖昧なまま始まる。合わないときに断れない |

構造の要点は、「三者とも、関係を壊したくないから、条件の話を後回しにする」ことです。紹介者は紹介した手前、条件に口を出しにくい。依頼側は知人の紹介なので値切りにくいし、範囲も厳密に言いにくい。自分は紹介者の顔を立てたいので、書面を出すのをためらう。三者がそれぞれ遠慮した結果、範囲も条件も曖昧なまま始まり、曖昧さは全部、受けた側の負担になります。

## 受ける前に、紹介者と依頼側それぞれに確認すること

紹介を受けたら、紹介者と依頼側で確認することが違います。紹介者には「紹介の中身」を、依頼側には「案件の中身」を聞きます。

| 相手 | 確認すること | 聞き方の例 |
|---|---|---|
| 紹介者 | 依頼側は自分の何を聞いているか | 「どんなふうに伝えてもらっていますか」 |
| 紹介者 | 依頼側の状況（人事の有無、判断する人、困っている中身） | 「採用のどこで困っているか、聞いていますか」 |
| 紹介者 | 紹介者自身が依頼側とどんな関係か（取引先、友人、元同僚） | 「〇〇さんとはどういうお付き合いですか」 |
| 紹介者 | 紹介者が案件に関わり続けるか、つなぐだけか | 「この先は直接やり取りしてよいですか」 |
| 依頼側 | 範囲（一つの業務で、含むことと含まないこと） | 「まず何を任せたいと考えていますか」 |
| 依頼側 | 判断する人と相談相手 | 「合否や条件は、どなたが決めますか」 |
| 依頼側 | 時間と期間 | 「週にどのくらい、いつまでを想定していますか」 |
| 依頼側 | 支払いの仕組み（締め日、支払日、誰が払うか） | 「お支払いの流れを教えてください」 |
| 自分 | 本業の規定と利益相反 | 紹介者や依頼側が本業の取引先や競合に当たらないか |

確認の要点は、「紹介者が案件に関わり続けるか」を早めに聞くことです。紹介者がつなぐだけなら、以後は依頼側と直接の関係になり、条件も直接決められます。紹介者が関わり続ける（間に入る、報告を受ける、紹介料を受け取る）なら、紹介者の立場が案件に影響し続けるので、その前提で書面を作ります。紹介者が依頼側から紹介料を受け取る形は、内容によっては職業安定法の整理が絡むことがあるとされているので、気になる場合は専門家に確認してください。

### エラベルの見解

相談で多いのは、「元上司の紹介で受けたが、範囲が最初から広く、しかも元上司が『あいつなら何でもできる』と伝えていた」という状態です。紹介者は善意で自分を高く伝えます。依頼側はそれを聞いて、範囲を広く想定します。自分は紹介者の顔を立てて、広い範囲を受けてしまう。この連鎖は、紹介者に「どう伝えてもらっているか」を最初に聞けば止まります。

見ていて差がつくのは、「紹介者の伝え方を、自分の言葉で上書きできるか」です。「〇〇さんには何でもできると言ってもらったようですが、副業で受けられるのはスカウトの運用と一次対応までで、面接の設定と合否の判断は含みません」と、依頼側との最初の面談で自分から言う。紹介者の善意を否定せずに、範囲だけを自分の言葉に戻す。それができれば、紹介の案件でも範囲は守られます。

## 条件を書面で決める手順

紹介の案件で書面を出す手順です。紹介者への配慮と書面を分けることが、全体を貫く考え方です。

1. **紹介者に感謝を伝え、以後は依頼側と直接やり取りする了解を取る。** 「ありがとうございます。この先は〇〇さんと直接お話しさせてください」と伝えます。紹介者が関わり続けたい意向なら、どこまで関わるかをここで決めます。
2. **依頼側との最初の面談で、範囲を自分の言葉で伝える。** 紹介者の伝え方に関わらず、含むことと含まないことを言います。[案件の範囲の決め方](/media/fukugyo-scope/)に、線の引き方があります。
3. **面談で四つの条件を確かめる。** 型があるか、成果物が明確か、期間が区切れるか、判断を含まないか。[面談で聞かれること](/media/fukugyo-mensetsu/)を参照してください。
4. **条件を書面にして依頼側に出す。** 含むこと、含まないこと、時間、期間、報酬の形、締め日と支払日、秘密保持。「紹介なので書面は不要」とは考えず、紹介だからこそ出します。書面を出すときは「〇〇さんに紹介していただいたご縁を大事にしたいので、お互いに後で困らないように書面にさせてください」と添えると、依頼側にも紹介者にも受け入れられやすくなります。
5. **単価は根拠を示して決める。** 紹介の関係で値切られやすく、自分から下げやすい。時間×時給の土台を示し、一件目は控えめでも根拠は残します。[最初の一件の価格の決め方](/media/fukugyo-shoninka/)と[安請け合いの防ぎ方](/media/fukugyo-yasuuke/)が参考になります。
6. **期間を区切る。** 一〜三か月で区切り、区切りで続けるかを話します。紹介の案件は長期になりやすく、区切りが無いと辞めるタイミングを失います。[契約期間の決め方](/media/fukugyo-keiyaku-kikan/)を参照してください。
7. **紹介者に、始まったことだけ報告する。** 条件や依頼側の内情は伝えません。「おかげさまで始まりました」だけで十分です。案件の内容を紹介者に流すと、依頼側の情報が外に出ることになります。

手順の要点は、「一と七で紹介者との関係を閉じ、二から六は依頼側と二人で決める」ことです。紹介者を案件の中に入れ続けると、条件の話が三者の話になり、決まりにくくなります。感謝と報告は紹介者に、書面は依頼側に、と相手を分けます。

## 紹介ならではの失敗

紹介の案件で起きやすい失敗です。いずれも、紹介者の関係が条件の話を止めるところで起きます。

| 失敗 | 起きる構造 | 防ぎ方 |
|---|---|---|
| 紹介者の伝え方のまま範囲が広がる | 「何でもできる」と伝わり、そのまま受ける | 最初の面談で、範囲を自分の言葉に戻す |
| 書面を出せない | 紹介なので書面は失礼だと感じる | 紹介だからこそ書面。ご縁を大事にしたいと添えて出す |
| 単価を自分から下げる | 紹介者の顔を立てて安く受ける | 根拠を示す。下げるなら一件目だけと決める |
| 断れない | 合わないと分かっても、紹介者の手前で断れない | 断り方を用意しておく（次の章） |
| 紹介者が間に入り続ける | 報告を求められ、条件の話が三者になる | 一の段階で、直接やり取りする了解を取る |
| 依頼側の情報が紹介者に流れる | 近況として案件の内容を話してしまう | 報告は「始まった」「終わった」だけ |
| 本業との衝突 | 紹介者が本業の取引先で、確認せずに受ける | 受ける前に規定と利益相反を確認。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 紹介料の扱いが不明 | 紹介者が依頼側から何かを受け取っているが、自分は知らない | 一の段階で聞く。整理が分からなければ専門家に |

失敗の要点は、「紹介者への配慮と、依頼側との条件を、同じ話にしてしまう」点です。配慮は配慮として紹介者に返し、条件は条件として依頼側と決める。分ければ、配慮が条件を曖昧にすることはなくなります。

## 断るときと、途中で終えるときの伝え方

紹介の案件で一番難しいのは、断ることと、途中で終えることです。紹介者の顔を潰さずに伝える型を持っておくと、判断が遅れません。

| 場面 | 依頼側への伝え方 | 紹介者への伝え方 |
|---|---|---|
| 面談で合わないと分かった | 「今回お任せいただきたい範囲と、副業で受けられる範囲が違うので、お役に立てません」と範囲の違いで断る | 「お話を聞かせていただきましたが、範囲が合わずお受けできませんでした。ご紹介はありがたかったです」 |
| 範囲は合うが時間が合わない | 「稼働できる曜日と時間帯が、ご希望と合いません」と時間で断る | 同上。理由は時間と伝える |
| 判断まで求められている | 「合否や条件の判断は御社で持っていただく前提でないと、お受けできません」と線を示す | 「判断を含む範囲だったので、副業では難しいとお伝えしました」 |
| 途中で範囲が広がり続ける | 書面を示し、「書面の範囲でお受けしています。追加は別途ご相談ください」と戻す | 伝えない。依頼側と二人で解決する |
| 途中で終える | 区切りの時点で「この区切りで一度終えさせてください」と伝える。理由は本業や時間で | 「区切りで一度終えました。ありがとうございました」 |

伝え方の要点は、「断る理由を、相手の良し悪しではなく、範囲か時間の違いにする」ことです。範囲か時間の違いなら、依頼側も紹介者も、誰も悪くありません。「合わなそう」「大変そう」と伝えると、依頼側の評価に聞こえ、紹介者の顔が潰れます。範囲と時間を最初に決めておけば、断る理由はいつでも、その違いで言えます。

### エラベルの見解

担当する側として登録した人の話を聞くと、紹介の案件が続いている人と、紹介の案件で疲れて副業をやめた人の差は、「書面を出したか」の一点に近い状態です。書面を出した人は、範囲が広がったときに書面に戻れ、区切りで終えられ、紹介者との関係も保てています。出さなかった人は、範囲が広がり、単価が下がり、断れず、最後に紹介者との関係まで気まずくなっています。

紹介は、最初の案件を決める経路として有効です。ただ、紹介者の関係が条件の話を止める構造は、どの紹介にもあります。エラベルは、企業と担当者の間に立つ窓口なので、紹介者の関係が乗らない形で、範囲と条件を最初から書面にした案件を出しています。紹介の案件を受けながら、関係の絡まない案件も一つ持っておくと、紹介の案件を「断れるもの」として扱えるようになり、結果的に紹介の案件も続けやすくなります。

## まとめ

- 紹介では**紹介者の顔を立てる**と**範囲と条件を書面で決める**を分ける。感謝は紹介者に、書面は依頼側に
- 紹介は**三者とも関係を壊したくないから条件を後回しにする**構造。曖昧さは受けた側の負担になる
- 紹介者には**伝え方・依頼側の状況・関係・関わり続けるか**を、依頼側には**範囲・判断する人・時間と期間・支払い**を確認する
- 手順は**直接やり取りの了解→範囲を自分の言葉で→四つの条件→書面→根拠のある単価→期間の区切り→紹介者には始まったことだけ**
- 失敗は**配慮と条件を同じ話にする**ところで起きる
- 断る理由は**相手の良し悪しではなく、範囲か時間の違い**にする。誰も悪くならない

## よくある質問

### 紹介してくれた人に、条件や単価を相談してもよいですか

紹介者が人事の経験者で、相場を知っているなら、単価の相場観を聞くことはできます。ただし、依頼側との条件そのものを紹介者に相談すると、紹介者が間に入る形になり、条件の話が三者の話になります。相場観は聞いても、依頼側との条件は依頼側と二人で決める、と分けてください。依頼側の内情や案件の中身は、紹介者に伝えない形が基本です。

### 紹介の案件は、単価を下げるべきですか

紹介だからという理由で下げる必要はありません。紹介者の顔を立てたいという気持ちから自分で下げると、その単価が基準になり、二件目以降も上げにくくなります。時間×時給の土台を示して、根拠のある単価を出してください。一件目として型を身につける期間と割り切って控えめにする判断はあり得ますが、その場合も「一件目だけ」「区切りで見直す」と書面に残します。紹介者への感謝は、単価ではなく、仕事の質と報告で返します。

### 紹介者が依頼側から紹介料を受け取っているようです。問題ありますか

紹介者と依頼側の間で何が取り交わされているかは、自分の契約とは別の話ですが、内容によっては職業安定法の整理が絡むことがあるとされています。個人の副業を紹介する行為がどう扱われるかは、紹介の形や対価の有無で変わり、一般に線引きが難しいとされています。自分の契約が依頼側との業務委託として明確になっていれば、まず自分の範囲と条件を書面にすることが先です。紹介料の扱いが気になる場合は、紹介者に率直に聞いたうえで、必要なら専門家に確認してください。
