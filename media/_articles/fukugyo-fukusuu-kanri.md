一件のときは回っていた副業が、二件目を受けたら急に回らなくなった。それぞれの案件の定例と締め日が別々にあり、どちらかの候補者の対応が入ると、もう一方が止まる。結論を先に書くと、**複数の案件を回すスケジュールは、案件ごとに時間を作るのではなく、「週の稼働の枠を先に置き、その枠に案件を割り当て、締め日と定例と請求の日を一枚に並べる」形にします。案件ごとに時間を作ると、案件が増えるたびに枠が増え、本業の時間を侵食します。枠を先に固定し、その中に案件を入れれば、枠を超える案件は受けられないことが分かり、受ける数の上限も見えます。**一件の稼働の見立ては[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/)に、一週間の稼働の置き方は[1週間のスケジュール例](/media/fukugyo-schedule/)に、稼働の上限は[稼働時間の上限](/media/fukugyo-kadou-jikan/)にまとめています。

## 案件ごとに時間を作る方法が崩れる理由

一件のときは「この案件のために火曜と木曜の夜」で回ります。二件目も同じように時間を作ると、崩れます。

| 崩れ方 | 何が起きるか |
|---|---|
| 枠が足し算で増える | 一件目に週二回、二件目にも週二回。合計が週四回になり、本業と生活の時間が減る |
| 候補者の対応が枠を越える | 候補者からの返信は、案件の枠の日に来るとは限らない。枠の外で対応すると、もう一方の案件の枠を使う |
| 定例が重なる | 二件の依頼側の定例が同じ曜日に入る。動かせるのは自分の側だけで、依頼側の都合は動かない |
| 締め日と請求の日が別々 | 依頼側ごとに締め日が違い、月末に両方の稼働報告と請求が重なる |
| 片方の山がもう片方を潰す | 一件目の採用が佳境に入ると、二件目の稼働が止まる。二件目の依頼側から見れば、理由の無い停滞 |
| 上限が見えない | 案件ごとに時間を作ると、「もう一件受けられるか」が分からず、受けてから崩れる |

崩れる要点は、「上限が見えない」ことです。案件ごとに時間を作る方法は、枠が案件の数だけ増えるので、どこで止めるべきかが分かりません。枠を先に固定すれば、枠に入らない案件は受けられないと分かり、上限が自分で見えます。

## 週の稼働の枠を先に置く

案件を見る前に、週の中で副業に使える枠を決めます。この枠は、案件が増えても増やしません。

| 手順 | 内容 |
|---|---|
| 一、本業と生活の時間を先に置く | 本業の勤務、通勤、家族との時間、睡眠を先にカレンダーに置く。残った時間が副業の候補 |
| 二、繁忙期でも守れる枠を選ぶ | 残った時間のうち、本業が最も忙しい月でも空いている枠だけを副業の枠にする。閑散期の余りは枠に入れない |
| 三、枠を種類で分ける | 「まとまった作業の枠」（文面の作成、記録の整理）と「短い対応の枠」（返信、確認）に分ける。短い枠は毎日、まとまった枠は週に数回 |
| 四、定例の枠を別に持つ | 依頼側との定例は、依頼側の都合で決まる。定例用の枠を、まとまった枠とは別に確保する |
| 五、予備の枠を一つ残す | 候補者の対応の山や、依頼側の急な依頼に使う枠を、週に一つ空けておく。使わなければ休む |

枠を置く要点は、「二」の繁忙期でも守れる枠にすることです。閑散期の時間で枠を決めると、繁忙期に枠が消え、案件が止まります。繁忙期の枠で決めれば、通年で守れます。時間の確保の考え方は[副業の時間を確保する](/media/fukugyo-jikan-kakuho/)に、平日の夜や早朝の使い方は[平日の夜に副業をする](/media/fukugyo-heijitsu-yoru/)と[早朝に副業をする](/media/fukugyo-hayaasa/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「二件目は、一件目と同じだけの時間が要る」というものです。実際には、二件目に要る時間は、二件目の範囲と工程で決まり、一件目とは違います。一件目がスカウトの運用で週にまとまった時間が要る案件でも、二件目が日程調整と一次対応なら、短い枠で回ることがあります。案件ごとに時間を足すのではなく、枠の種類（まとまった枠、短い枠）に、案件の工程を割り当てると、同じ枠に二件が入ることがあります。

見ていて差がつくのは、「枠を先に固定しているか」です。固定している人は、二件目の相談が来たとき、「この工程なら短い枠に入る」「この工程はまとまった枠が埋まっているので受けられない」と、その場で判断できます。固定していない人は、「何とかなる」と受けて、一件目の稼働を削ります。エラベルでは、担当者の稼働の枠を登録の時点で聞いていて、依頼側の相談が来たとき、その枠に入る範囲かを見て提示しています。枠が明確な担当者ほど、合う案件が来て、合わない案件は来ません。

## 案件を枠に割り当てる基準

枠が決まったら、案件の工程を枠に入れます。案件を丸ごと入れるのではなく、工程で分けて入れます。

| 工程 | 入れる枠 | 理由 |
|---|---|---|
| スカウトの検索と文面の作成 | まとまった枠 | 集中が要る。細切れでは進まない |
| スカウトの送信 | まとまった枠か、短い枠の複数回 | 送信そのものは短時間で分けられる |
| 候補者への返信、日程調整 | 短い枠（毎日） | 返信の速さが要る。毎日の短い枠で回す |
| 依頼側との定例 | 定例の枠 | 依頼側の都合で固定 |
| 稼働報告と請求 | まとまった枠（月に一度） | 月末に集中する。締め日から逆算して枠に入れる |
| 記録の整理 | まとまった枠の末尾か、短い枠 | 溜めると重くなる。こまめに |
| 候補者の山（一次面接が集中する週など） | 予備の枠 | 山は予測できるので、前の週に予備の枠を空けておく |

割り当ての要点は、「候補者への返信は毎日の短い枠に、それ以外はまとまった枠に」です。複数の案件を持つと、毎日の短い枠に全案件の返信が入り、まとまった枠は案件ごとに曜日を分けます。「火曜はA社のまとまった枠、木曜はB社」のように、一日に一案件のまとまった作業にすると、切り替えの負担も減ります。ツールの切り替えの負担は[ツールを統一するか合わせるか](/media/fukugyo-tool-toitsu/)に書いています。

## 締め日・定例・請求の日を一枚に並べる

複数の案件で最も見落とすのは、依頼側ごとに違う日付です。一枚に並べます。

| 並べる項目 | 内容 |
|---|---|
| 定例の日と時間 | 案件ごとに。重なったら、自分の側で動かせるものを動かす。動かせなければ、片方の依頼側に相談 |
| 稼働報告を出す日 | 締め日から逆算した日。[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/) |
| 請求書を出す日 | 稼働報告と同じ日。[請求のタイミング](/media/fukugyo-seikyuu-timing/) |
| 入金の予定日 | 支払日。入金の確認の日として |
| 契約の更新の日 | 二か月前と一か月前に印を付ける。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |
| 依頼側の採用の山 | 面接が集中する週、内定の時期など、依頼側から聞いた予定 |
| 本業の繁忙期 | 自分の側の山。副業の枠を減らす時期として |

並べる要点は、「月の中で日付が重なる週を見つける」ことです。二件の稼働報告と請求が同じ週に重なるなら、片方を数日前倒しして、まとまった枠を分けます。定例が同じ曜日なら、時間帯をずらせるか依頼側に相談します。一枚に並べて初めて、重なりが見えます。カレンダーは副業用の一つに、案件ごとの色で入れると、重なりが見た目で分かります。

## 案件の山が重なったときの調整

予備の枠を空けていても、二件の山が同じ週に重なることがあります。そのときの調整の順番を決めておきます。

| 順 | 調整 | 内容 |
|---|---|---|
| 一 | 予備の枠を使う | 空けておいた枠に、山の分を入れる |
| 二 | まとまった枠の中身を入れ替える | 山が来ていない案件のまとまった作業（文面の改良、記録の整理）を翌週に回し、その枠を山の案件に使う |
| 三 | 依頼側に先に伝える | 「今週は候補者の対応が集中するため、〇〇の作業は来週に回します」と、山が来ていない案件の依頼側に先に伝える。黙って遅らせない |
| 四 | 優先順位を依頼側と決める | 両方の山が同時なら、それぞれの依頼側に「今週はここまで」を伝え、優先を確認する |
| 五 | 枠を増やさない | 山だからと本業や生活の枠を削らない。削ると翌週に響き、両方の案件が崩れる |

調整の要点は、「三」の先に伝えることです。山が来ていない案件の依頼側は、自分の案件が後回しになった理由を知りません。「今週は他の案件が」とは言わず、「今週は〇〇の作業を来週に回します」と、その依頼側の案件の中の話として伝えます。伝えていれば、遅れは調整で、伝えなければ停滞です。本業が忙しいときの伝え方は[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/)に整理しています。

## 本業の繁忙期の扱い

本業の繁忙期は、副業の枠そのものが減ります。複数の案件があるとき、減った枠をどう配るかを決めておきます。

| 決めること | 内容 |
|---|---|
| 繁忙期の枠を先に決めておく | 「〇月は短い枠だけ。まとまった枠は無し」のように、年の初めに決める |
| 繁忙期に受けられる範囲を各依頼側に伝えておく | 契約のときに「〇月は稼働が下がる」と伝えておけば、繁忙期に改めて言う必要が無い |
| 減った枠の配り方 | 候補者への返信は全案件で維持し、まとまった作業は全案件で止めるか減らす。片方だけを止めない |
| 繁忙期に山が来る案件 | 契約のときに、依頼側の採用の山と自分の繁忙期が重ならないかを見る。重なるなら、範囲を絞るか、時期をずらす |
| 繁忙期の前に前倒しする | 文面の改良、記録の整理、型の更新のように、時期を選ばない作業を繁忙期の前に済ませておく |

繁忙期の要点は、「片方だけを止めない」ことです。繁忙期に一件だけを止めると、その依頼側から見て「自分の案件は優先度が低い」と映ります。全案件で同じように「返信は維持、まとまった作業は減らす」とすれば、どの依頼側にも同じ説明ができます。繁忙期の見立ては[稼働時間の上限](/media/fukugyo-kadou-jikan/)に、繁忙期を含めた年間の見立ては[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に書いています。

## 崩れたときの立て直し

枠を決めていても、崩れることはあります。崩れたときに、案件を減らす前に、立て直す順番があります。

| 手順 | 内容 |
|---|---|
| 一、稼働ログで実態を見る | どの案件のどの工程に、枠を超えて時間が使われているかを、記憶ではなくログで見る。[稼働ログの付け方](/media/fukugyo-log/) |
| 二、超えている工程を特定する | 多くの場合、候補者の対応か、範囲外の依頼が枠を超えている |
| 三、範囲外なら依頼側と話す | 範囲外の工程が増えているなら、それは範囲の話。[範囲が広がっていくとき](/media/fukugyo-scope-creep/) |
| 四、範囲内なら枠の割り当てを直す | 範囲内で超えているなら、工程の枠の割り当てが合っていない。まとまった枠と短い枠の配分を直す |
| 五、それでも超えるなら案件を減らす | 枠の割り当てを直しても超えるなら、案件の数が枠を超えている。更新の節目で一件を終える。[契約期間の目安](/media/fukugyo-keiyaku-kikan/) |

立て直しの要点は、「案件を減らす前に、範囲と割り当てを見る」ことです。崩れた原因が範囲の広がりなら、範囲を戻せば枠に収まります。割り当ての問題なら、配分を直せば収まります。案件の数が問題なのは、その二つを直しても超えるときだけで、そこで初めて減らします。順番を飛ばして案件を減らすと、減らした後も同じ崩れ方をします。

### エラベルの見解

担当する側から見ると、複数の案件を長く回している人は、案件の数を先に決めていません。週の枠を先に決め、枠に入る範囲の案件だけを受け、枠が埋まったら受けない。案件の数は、その結果として決まっています。逆に、「三件まで」のように数を先に決めた人は、三件の範囲と工程の合計が枠を超えて崩れるか、逆に枠が余っているのに受けないかのどちらかになっています。

順番として、枠を決め、その枠の種類（まとまった枠、短い枠、定例の枠、予備の枠）を決め、案件の相談が来たら工程を枠に当てはめて、入るなら受け、入らないなら断るか範囲を絞る。この順番なら、案件の数は自然に決まり、崩れる前に上限が見えます。エラベルでは、担当者の稼働の枠を登録の時点で聞き、依頼側の相談の範囲がその枠に入るかを見て提示しています。枠が明確な担当者は、受けた案件が枠に収まっているので、長く続いています。

## まとめ

- 案件ごとに時間を作ると**枠が足し算で増え、上限が見えず、崩れる**
- **週の枠を先に置く**。本業と生活の時間を先に置き、繁忙期でも守れる枠だけを副業に。まとまった枠・短い枠・定例の枠・予備の枠に分ける
- 案件は**工程で分けて枠に入れる**。候補者への返信は毎日の短い枠、それ以外はまとまった枠で一日一案件
- **締め日・定例・請求・入金・更新・依頼側の山・本業の繁忙期を一枚に並べ**、重なる週を見つけて前倒しする
- 山が重なったら**予備の枠→枠の中身の入れ替え→先に伝える→優先を依頼側と決める**。枠は増やさない
- 繁忙期は**片方だけを止めず、全案件で同じ配り方**にする
- 崩れたら**ログで実態を見て、範囲と割り当てを直し、それでも超えるなら更新の節目で減らす**

## よくある質問

### 二件の依頼側の定例が、どちらも同じ曜日の同じ時間を希望しています

自分の側で動かせる余地が無いなら、後から決まった依頼側に「その時間は別の予定が固定されているため、別の曜日か時間帯でお願いできますか」と相談します。「別の案件の定例と重なる」とは言わず、自分の都合として伝えます。どちらも動かせないなら、片方を隔週にする、片方をメールでの報告に替える、といった形を依頼側と相談します。定例の形の選択肢は[定例会の進め方](/media/fukugyo-teirei-shinkou/)に整理しています。

### 候補者の返信が夜遅くや休日に来ます。毎日の短い枠に収まりません

短い枠を「返信を確認して対応する時間」として一日の中で決め、その時間の外に来た返信は、次の枠で対応する形にします。候補者には、最初の連絡で「返信は翌日以降になることがあります」と伝えておけば、遅れは問題になりません。すべての返信に即座に対応しようとすると、枠の外の時間が副業に侵食され、本業と生活が崩れます。返信の速さの期待は、依頼側とも最初にすり合わせておきます。

### 三件目の相談が来ました。受けてよいか、どう判断すればよいですか

三件目の範囲と工程を、いまの枠に当てはめます。候補者への返信が中心なら毎日の短い枠に入るか、まとまった作業が要るなら空いているまとまった枠があるか、定例の枠が空いているか、予備の枠を残せるかを見ます。すべて入るなら受け、入らないなら、範囲を絞って入る形にできるかを依頼側と相談し、それでも入らないなら断ります。数ではなく、枠に入るかで判断します。断り方は[断り方](/media/fukugyo-kotowaru/)に書いています。
