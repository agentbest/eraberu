依頼側の本社が遠方にあり、「月に一度は来てほしい」と言われた。地方の拠点の採用で、現地の面接に同席してほしいと言われた。出張が要る案件は、受けてよいのか、条件をどう決めればよいのか。結論を先に書くと、**出張が要る案件は、「出張の回数」「費用の負担」「移動時間の扱い」「本業の休みとの関係」の四つを、契約の前に決めてから受けます。決めずに受けると、移動時間が稼働に数えられず、交通費や宿泊費が持ち出しになり、本業の有給や週末が副業の出張で消えます。四つを決め、出張を減らす代替案を出したうえで、それでも出張が要るなら、条件を書面にして受ける。出張は、対面の延長ではなく、別の条件として扱います。**対面を求められる場面は[対面が必要になる場面](/media/fukugyo-taimen/)に、リモートで完結する案件は[フルリモートで完結する案件](/media/fukugyo-remote/)に、有給の扱いは[有給を使って対応してよいか](/media/fukugyo-yuukyuu/)にまとめています。

## 出張が要る場面の種類

副業で出張が要ると言われる場面は、いくつかの種類に分かれ、本当に出張が要るかどうかが違います。

| 場面 | 依頼側の言い分 | 本当に出張が要るか | 代替案 |
|---|---|---|---|
| 初回の顔合わせ | 「一度会っておきたい」 | 要らないことが多い | オンラインの顔合わせ。対面は契約後の区切りで |
| 地方の拠点の面接の同席 | 「現地の面接官と一緒に見てほしい」 | 依頼側の面接の形による | オンラインの同席。面接官向けの準備資料と、事後の振り返りで代える |
| 現地の説明会や見学会の運営 | 「当日の運営を手伝ってほしい」 | 当日の運営は現地が要る | 運営は現地の社員に任せ、準備と事後を自分が担う |
| 遠方の本社での定例の打ち合わせ | 「月に一度は来て報告してほしい」 | 要らないことが多い | オンラインの定例。対面は四半期に一度など |
| 現場の責任者との関係づくり | 「現場を見て、雰囲気を知ってほしい」 | 最初の一度は価値がある | 最初の一度だけ対面。以後はオンライン |
| 紙の書類、契約の締結 | 「書類に押印してほしい」 | 要らないことが多い | 電子での締結、郵送 |
| 問題が起きたときの対応 | 「来て説明してほしい」 | 問題の内容による | まずオンラインで説明。対面が要るなら、その一度だけ |

種類の要点は、「依頼側は、対面の方が早いと思っているだけで、出張が必須とは限らない」ことです。依頼側に悪気はなく、社員と同じ感覚で「来てもらう」と言っています。副業の担当者にとって、出張は移動時間と費用と本業の休みが乗る、別の条件です。場面ごとに、本当に出張が要るかを見て、代替案を出します。対面の場面の考え方は[対面が必要になる場面](/media/fukugyo-taimen/)に書いています。

## 受ける前に決める四つのこと

出張が要ると分かったら、契約の前に四つを決めます。決めずに受けると、全部が持ち出しになります。

| 決めること | 決め方 | 決めないと |
|---|---|---|
| 一、出張の回数 | 月に何回、年に何回。「必要に応じて」ではなく、上限を数で。超える場合は都度相談 | 「来てほしい」が積み重なり、毎月出張になる |
| 二、費用の負担 | 交通費、宿泊費、現地の移動費を、誰が、どの形で負担するか。実費精算か、定額か。上限はあるか | 交通費と宿泊費が持ち出しになる |
| 三、移動時間の扱い | 移動時間を稼働に含めるか、含めないか。含めるなら全部か、一部か。含めないなら、出張の日の稼働をどう数えるか | 往復で一日消えても、稼働は現地の数時間だけになる |
| 四、本業の休みとの関係 | 出張の日が本業の休み（有給、週末）に当たるか。本業の許可の条件に出張が含まれているか | 有給を副業の出張で使い、本業の休みが消える。本業の許可の範囲を越える |

四つの要点は、「三」の移動時間を、最初に決めることです。副業の担当者は、時間で報酬を受けることが多く、移動時間が稼働に入らないと、出張の日は往復で一日消えるのに、報酬は現地の数時間分だけになります。「移動時間は稼働に含める」「移動時間は含めないが、出張の日は一日分の定額」など、形を決めます。依頼側は移動時間を稼働と思っていないことが多いので、自分から出します。契約での決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、経費の考え方は[経費にできるもの](/media/fukugyo-keihi/)に、稼働の数え方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に整理しています。

### エラベルの見解

担当する側から見ると、出張が要る案件で条件が崩れる担当者は、出張を「対面の延長」として受けています。対面は近場で数時間で済みますが、出張は移動で一日消え、費用がかかり、本業の休みを使います。それを対面と同じ感覚で「行きます」と受けると、移動時間は稼働に数えられず、費用は持ち出しになり、有給が副業の出張で消えます。依頼側は、担当者が持ち出していることに気づいていないので、言わなければ続きます。

見ていて差がつくのは、出張を頼まれたときに、代替案を先に出しているかです。「現地の面接に同席してほしい」と言われて、「行きます」と答える人と、「オンラインで同席し、面接官向けの準備資料と事後の振り返りで補う形ではどうでしょう。それでも現地が要る場面があれば、その回だけ伺います」と答える人では、出張の回数が全く違います。依頼側は、代替案を出されて初めて、出張が必須ではないことに気づきます。エラベルでは、依頼側が担当者を選ぶ仕組みなので、対面と出張の可否と条件を登録の時点で明確にしている担当者には、その条件に合う依頼側がついています。出張は、対面の延長ではなく、別の条件です。

## 出張を減らす代替案の出し方

出張を頼まれたら、受ける前に代替案を出します。代替案の出し方です。

| 頼まれたこと | 代替案 | 出し方 |
|---|---|---|
| 面接の同席 | オンラインの同席。面接官向けの準備資料。事後の振り返りの型 | 「同席はオンラインで。準備資料と振り返りで、現地と同じ効果を出します」 |
| 定例の報告 | オンラインの定例。書面の報告。対面は四半期に一度 | 「定例はオンラインで。対面は四半期に一度、まとめてご報告します」 |
| 説明会の運営 | 準備と事後を自分が担い、当日は現地の社員に | 「当日の運営は現地の方に。台本と資料と事後の集計は私が用意します」 |
| 現場の見学 | 最初の一度だけ対面。以後は現場の責任者とのオンラインの定期の会話 | 「最初に一度伺い、以後は月に一度、現場の方とオンラインで話す形で」 |
| 書類の押印 | 電子での締結、郵送 | 「電子契約か郵送で対応できます」 |
| 問題の説明 | まずオンラインで説明。対面が要るなら、その一度だけ | 「まずオンラインで状況をご説明します。そのうえで対面が要れば伺います」 |

出し方の要点は、「代替案で、現地と同じ効果を出す方法を添える」ことです。「行けません」だけでは、依頼側は「やる気がない」と感じます。「オンラインで同席し、準備資料と振り返りで補う」と、現地に行かなくても同じ効果が出る方法を添えれば、依頼側は出張が必須ではないことに気づきます。代替案を出しても出張が要ると言われたら、四つを決めて受けます。提案の出し方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に、断り方は[断り方](/media/fukugyo-kotowaru/)に書いています。

## 出張中の情報と端末の扱い

出張は、移動中と現地で、依頼側の情報を扱う場面が増えます。扱いの線です。

| 場面 | 線 |
|---|---|
| 移動中（電車、飛行機） | 依頼側の情報を画面に出さない。考える作業だけ。[通勤時間の使い方](/media/fukugyo-tsuukin/) |
| 宿泊先 | 宿泊先の回線で依頼側のシステムに接続しない。副業用の回線を使う。[ネットワーク環境の注意](/media/fukugyo-vpn/) |
| 現地の会議室 | 依頼側の会議室で、別の依頼側の情報を開かない。案件ごとに情報を分ける |
| 現地で受け取る紙の資料 | 持ち帰るか、その場で返すかを依頼側と決める。持ち帰るなら、保管と廃棄の方法を決める |
| 端末の紛失 | 出張中は紛失の機会が増える。端末にパスワードと遠隔での消去を設定する。[パスワードとアカウントの管理](/media/fukugyo-password/) |
| 本業の端末 | 副業の出張に本業の端末を持っていかない。持っていく場合は、副業の作業に使わない |
| 現地の飲食の場 | 依頼側の社員との飲食の場で、別の依頼側や本業の話をしない |

扱いの要点は、「本業の端末を副業の出張に持っていかない」ことです。出張中は、本業の端末しか持っていない場面で副業の作業をしたくなりますが、本業の端末で副業の情報を扱うと、本業の端末の記録に残ります。副業の出張には、副業用の端末だけを持ち、本業の端末は置いていくか、副業の作業には使いません。端末の分け方は[私物端末で作業してよいか](/media/fukugyo-tanmatsu/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に整理しています。

## 本業の出張との混同を避ける線

本業でも出張がある人は、副業の出張と混同しやすくなります。線を引いておきます。

| 混同の形 | 何が起きるか | 線 |
|---|---|---|
| 本業の出張のついでに、副業の依頼側を訪ねる | 本業の出張費で副業の移動をした形になる。本業の会社の規則に反することがある | 本業の出張と副業の出張は分ける。ついでに訪ねるなら、副業の分の移動費は自分か依頼側が負担し、本業の勤務時間の外で |
| 本業の出張中に、副業の連絡を返す | 本業の時間に副業をしている形。本業の端末や回線を使う可能性 | 本業の出張中は、副業の連絡は本業の勤務時間の外で、副業用の端末で |
| 副業の出張を、本業の出張と同じ日に組む | 本業の会社が「本業の出張のついでに副業をしている」と見る | 日を分ける。分けられないなら、本業の会社に事前に確認する |
| 本業の名刺を副業の出張で使う | 本業の会社の名前で副業をしている形になる | 副業用の名刺を使う。[名刺をどうするか](/media/fukugyo-meishi/) |
| 本業の出張先の地域で、副業の依頼側と会う | 本業の関係者と鉢合わせる | 本業の関係者がいない場所と時間を選ぶ |

線の要点は、「本業の出張と副業の出張は、費用も時間も端末も分ける」ことです。本業の出張のついでに副業の依頼側を訪ねることは、効率がよく見えますが、本業の出張費で副業の移動をした形になり、本業の会社の規則に反することがあります。ついでに訪ねるなら、副業の分の移動費と時間を明確に分け、本業の勤務時間の外にします。分けられないなら、日を変えます。本業との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、本業に知られる経路は[副業は会社にばれるか](/media/fukugyo-qa-1/)に書いています。

## 出張が要る案件を受けるかの判断の順番

出張が要る案件を、受けるかどうか判断する順番です。

| 順番 | 内容 |
|---|---|
| 一、出張が要る場面を、依頼側に具体的に聞く | 何のために、どこに、どのくらいの頻度で |
| 二、場面ごとに、本当に出張が要るかを見る | 代替案で同じ効果が出るか |
| 三、代替案を出す | 現地と同じ効果を出す方法を添えて |
| 四、それでも出張が要るなら、回数の上限を決める | 月に何回、年に何回 |
| 五、費用の負担と、移動時間の扱いを決める | 実費か定額か。移動時間を稼働に含めるか |
| 六、本業の休みと許可の条件を確認する | 出張の日が本業の休みに当たるか。許可の範囲に出張が含まれるか |
| 七、四つを書面にして、契約に入れる | 口頭で決めない |
| 八、四つを満たせないなら、断る | 「出張の条件が合わないので、リモートで完結する範囲であれば受けられます」 |

順番の要点は、「八」の、四つを満たせないなら断る、と決めておくことです。出張が要る案件は、四つの条件が揃わないと、移動時間、費用、本業の休みのどれかが持ち出しになります。「範囲がよい案件だから」と条件を曖昧にして受けると、出張のたびに持ち出しが増え、続きません。「リモートで完結する範囲なら受けられます」と、範囲を絞って受ける形も出せます。断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、リモートで完結する形は[フルリモートで完結する案件](/media/fukugyo-remote/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「出張が要ると言われたら、行くか断るかの二択だ」というものです。実際には、出張が要ると言われた場面の多くは、代替案で同じ効果が出せ、代替案を出すことで出張の回数が減ります。それでも出張が要る場面は、回数、費用、移動時間、本業の休みの四つを決めれば、条件として受けられます。二択ではなく、代替案と条件の設定で、受けられる形を作ります。

順番として、出張が要る場面を具体的に聞き、本当に要るかを見て、代替案を出し、それでも要るなら回数の上限、費用の負担、移動時間の扱い、本業の休みと許可を決め、書面にして契約に入れ、四つを満たせないなら断る。この順番で、出張は「持ち出しになるもの」から「条件として決めたもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、対面と出張の可否と条件を明確にしている担当者には、その条件に合う依頼側がついています。出張は、対面の延長ではなく、別の条件です。

## まとめ

- 出張が要る案件は**回数・費用の負担・移動時間の扱い・本業の休みとの関係**の四つを契約の前に決めてから受ける
- 依頼側の「来てほしい」は**対面の方が早いと思っているだけ**で、必須とは限らない。場面ごとに代替案を出す
- **移動時間を稼働に含めるか**を最初に決める。決めないと往復で一日消えて報酬は数時間分
- 代替案は**現地と同じ効果を出す方法を添えて**出す。「行けません」だけでは通らない
- 出張中は**依頼側の情報を画面に出さず、副業用の端末と回線だけを使い、本業の端末を持っていかない**
- **本業の出張と副業の出張は費用も時間も端末も分ける**。四つを満たせないなら、リモートの範囲に絞るか断る

## よくある質問

### 依頼側が「交通費は出す」と言っていますが、移動時間の話が出ません

交通費と移動時間は別の話で、依頼側は移動時間を稼働と思っていないことが多いです。自分から「移動時間の扱いを決めさせてください」と出します。「移動時間は稼働に含める」「移動時間は含めないが、出張の日は一日分の定額」「移動時間の半分を稼働に含める」など、形を提案し、依頼側と決めます。出張の日は往復で一日消えるので、移動時間が何らかの形で報酬に反映されないと、出張のたびに持ち出しになります。決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、稼働の数え方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に整理しています。

### 出張の日が平日で、本業の有給を使う必要があります。使ってよいですか

有給の使い道は本人の自由が原則ですが、副業の許可の条件に「本業の勤務に影響しない範囲」があることが多く、有給を副業の出張で使い続けると、本業の休みが消え、本業に響きます。会社の規則と許可の条件を確認し、個別の判断は専門家にご確認ください。使うとしても、回数の上限を決め、本業の繁忙期は避けます。有給を使わずに済むよう、出張の日を週末にできないか、代替案で出張を減らせないかを先に見ます。有給の扱いは[有給を使って対応してよいか](/media/fukugyo-yuukyuu/)に書いています。

### 地方在住で、依頼側が都市部にあります。毎回の出張は無理です

地方在住で都市部の依頼側を受ける場合、出張の回数は最初に上限を決め、多くの場面をオンラインで済ませる形にします。「対面は四半期に一度。それ以外はオンライン」と最初に伝え、その条件で受けられる依頼側を選びます。エラベルのような登録先では、対面の可否を登録の時点で示せるので、リモート前提の依頼側とつながれます。地方在住の副業の考え方は[地方在住でもできるか](/media/fukugyo-qa-8/)に、リモートで完結する形は[フルリモートで完結する案件](/media/fukugyo-remote/)に整理しています。
