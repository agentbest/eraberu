副業を始めるとき、作業環境は後回しにされがちです。手元の端末で、リビングで、空いた時間に。始めはそれで動きますが、応募者の情報を扱う仕事を、本業の端末や家族と共用の端末で続けると、情報の事故が起きます。家族のいる場所で候補者の話をすると、依頼側の情報が漏れます。結論を先に書くと、**副業の作業環境は、快適さより「本業と分ける・家庭と分ける・枠で分ける」の三つが軸で、端末・場所・時間をそれぞれ分けると、情報の事故と本業への影響を防げます。**高価な設備は要らず、分けることが要ります。ツールの選び方は[使うツールをそろえる](/media/fukugyo-tool/)に、時間の枠の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)にまとめています。

## 三つを分ける

作業環境で分けるものを、三つに整理します。

| 分けるもの | 何と分けるか | 分けないと起きること |
|---|---|---|
| 端末 | 本業の端末、家族と共用の端末 | 本業の規定に触れる。応募者の情報が家族の目に触れる。本業の情報と副業の情報が混ざる |
| 場所 | 家族のいる場所、本業の職場 | 会議の音声や画面が家族に届く。職場で副業をすると規定に触れる |
| 時間 | 本業の時間、家庭の時間 | 本業中に副業の連絡を見る。家庭の時間に副業が侵食する |

分け方の要点は、「三つとも、物理的に分ける」ことです。「気をつける」では分かれません。端末を別にする、部屋か机を別にする、枠の外では端末を開かない。物理的に分けると、気をつけなくても混ざりません。

## 端末の分け方と、最低限の安全対策

端末は、副業の情報の入口です。分け方と、最低限の対策を整理します。

| 項目 | 内容 |
|---|---|
| 本業の端末を使わない | 本業の端末での副業は、多くの会社で規定に触れる。使わない |
| 家族と共用の端末を使わない | 応募者の情報が家族の目に触れる。副業専用か、自分専用の端末に |
| 副業専用の端末が望ましい | 高価でなくてよい。ブラウザで依頼側の環境にアクセスできれば足りる |
| 端末のロック | 起動時と離席時のロック。家族が開けないように |
| 保存しない運用 | 応募者の情報は依頼側の環境の中で扱い、端末に保存しない。[使うツールをそろえる](/media/fukugyo-tool/) |
| 更新と対策 | 基本的な更新と、標準の対策を有効に。詳細は専門家や依頼側の規程に |
| 通信 | 自宅の回線で。公衆の無線は、応募者の情報を扱う作業には使わない |
| 画面の向き | 家族や来客から画面が見えない向きに |
| 紛失時の備え | 端末を失くしても情報が残らないよう、保存しない運用を徹底。遠隔でロックできる設定があれば有効に |

対策の要点は、「保存しない運用が、最大の安全対策」ということです。端末に情報が無ければ、紛失しても、家族が開いても、漏れるものがありません。端末の対策の詳細は変わるので、依頼側の規程と専門家の案内に従ってください。

### エラベルの見解

登録の相談で多いのは、「本業の端末は使わないが、家族と共用のノートで副業をしている」という状態です。本人は問題ないと思っていますが、応募者の履歴書が家族の目に触れる可能性があり、依頼側から見ると、個人情報の扱いとして受け入れにくい。依頼側は、副業の人の端末が誰と共用かまでは聞かないので、本人が線を引くしかありません。

見ていて差がつくのは、「副業を始める前に、端末を分けているか」です。高価な端末は要りません。依頼側の環境にブラウザでアクセスできれば、古い端末でも足ります。分けることで、依頼側の情報が自分の生活の中に入らず、副業を終えたときに端末ごと切り離せます。エラベルの登録でも、情報の扱いについて「専用の端末で、保存しない運用をしています」と言える人は、依頼側から権限を渡されるのが早く、信用の立ち上がりが違います。

## 家で作業する場所の作り方

副業の作業の多くは家で行います。場所の作り方を整理します。

| 項目 | 内容 | 無いとき |
|---|---|---|
| 専用の机か部屋 | 副業の端末を置く場所を固定する。家族の生活の動線と分ける | 机の一角でもよい。使うときだけ広げる形は続かない |
| 会議ができる場所 | ビデオ会議の音声が家族に届かない、家族の生活音が相手に届かない場所 | 会議の時間帯を家族の不在時に。無理なら音声だけの会議に |
| 画面の向き | 家族や来客から画面が見えない向き | 覗き見防止のフィルムを使う |
| 資料の扱い | 紙の資料を置かない。印刷しない | 印刷が要る業務は範囲から外す |
| 家族への説明 | 副業の時間と場所を家族に伝え、その時間は入らない了解を得る | 了解が無い場所は使えない。分担を決める。[介護・育児との両立](/media/fukugyo-kaigo-ikuji/) |
| 枠の外は閉じる | 枠が終わったら端末を閉じ、机を離れる | 開いたままにすると、枠の外で見てしまう |

場所の要点は、「家族への説明を先にする」ことです。場所を作っても、家族が副業の時間に入ってくれば、会議の音声が届き、画面が見えます。副業の時間と場所を家族と決めることが、場所を作る前提です。

## 外で作業するときの注意

家で作業できないとき、外で作業することがあります。注意を整理します。

| 場面 | 注意 |
|---|---|
| カフェや共用の作業場 | 応募者の情報を扱う作業はしない。文面の型作りや記録の整理など、情報を含まない作業に限る |
| 公衆の無線 | 応募者の情報を扱う作業には使わない。自分の回線か、通信の保護がある形で |
| 画面 | 覗き見防止のフィルム。離席時はロックか持ち歩く |
| 通話・会議 | 依頼側の社名や候補者の名前が周りに聞こえる場所ではしない |
| 移動中 | 端末を開かない。紛失と覗き見の両方の危険 |
| 本業の職場 | 副業の作業はしない。昼休みでも規定に触れることがある。判断は専門家に |
| 出張先 | 宿泊先の回線の安全性が読めないので、情報を含まない作業に限る |

注意の要点は、「外では、情報を含まない作業だけ」ということです。文面の型作り、自分の記録の整理、翌週の計画。応募者の情報や依頼側の社内情報に触れる作業は、家の環境でだけ行います。

## 環境を整える手順

作業環境を整える手順を、番号付きで整理します。案件が決まる前に済ませます。

1. **本業の規定を確認する。** 本業の端末の使用、職場での副業、情報の持ち出しに関する規定。判断がつかない点は専門家に。[副業の許可申請](/media/fukugyo-kyoka-shinsei/)
2. **副業用の端末を用意する。** 手持ちの自分専用の端末があればそれで。無ければ、ブラウザが使える程度のもので足りる
3. **端末のロックと基本の対策を有効にする。** 起動時のロック、離席時の自動ロック、更新
4. **保存しない運用を決める。** 依頼側の環境の中で作業し、端末にダウンロードしない
5. **家の中に、副業の場所を決める。** 机か部屋。家族と時間と場所を決める
6. **会議ができる時間帯と場所を決める。** 家族の不在時か、音声が届かない場所
7. **枠の外で端末を開かない習慣を作る。** 枠が終わったら閉じる。通知を切る
8. **外で作業するときの線を決める。** 情報を含まない作業だけ。公衆の無線は使わない
9. **依頼側に、環境を伝える。** 「専用の端末で、御社の環境の中だけで作業し、保存しません」
10. **案件が終わったら、権限を返し、端末に何も残っていないことを確認する。**

手順の要点は、「九で、依頼側に伝える」ことです。環境を整えたことを伝えれば、依頼側は安心して権限を渡せます。伝えなければ、依頼側は副業の人の環境を知らないまま、情報を渡すことになります。

## 環境が原因で崩れる失敗

作業環境が原因で起きる失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 本業の端末で副業 | 手元にある。便利 | 使わない。規定に触れる |
| 家族と共用の端末で応募者の情報を開く | 専用が無い | 自分専用に。無ければ保存しない運用を徹底 |
| リビングで会議 | 場所が無い | 家族の不在時か、音声だけの会議に |
| 端末を開いたままにする | 枠の外で見てしまう | 枠が終わったら閉じる |
| 紙に印刷する | 読みやすい | 印刷しない。印刷が要る業務は範囲外 |
| カフェで応募者の書類を開く | 家で時間が取れない | 外では情報を含まない作業だけ |
| 家族が副業の時間に入ってくる | 説明していない | 時間と場所を家族と決める |
| 案件が終わっても情報が残る | 保存する運用だった | 保存しない運用に。終了時に確認 |
| 本業の職場で昼休みに副業 | 時間が無い | しない。規定に触れることがある |
| 快適さを優先して環境を整えすぎる | 設備にお金と時間をかける | 分けることが先。快適さは後 |

失敗の要点は、「分けていないことで起きる」点です。端末、場所、時間のどれかが本業や家庭と混ざると、情報の事故か本業への影響のどちらかにつながります。

### エラベルの見解

担当する側として登録した人の話を聞くと、長く続いている人の作業環境は、質素です。古い端末を副業専用にし、机の一角を副業の場所にし、枠が終わったら閉じる。設備にお金をかけていません。かけているのは、分けることだけです。快適な環境を作ってから始めようとした人は、始める前に時間を使い、始めてからも快適さを追って、分けることが後回しになっています。

依頼側から見ると、副業の人の作業環境は見えません。だからこそ、本人が「専用の端末で、御社の環境の中だけで作業し、保存しません」と言えるかどうかが、信用の材料になります。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口ですが、依頼側に副業の人を紹介するとき、情報の扱いについて本人が説明できることが、依頼側の安心につながっています。環境を整えることは、自分のためというより、依頼側に説明できる状態を作ることです。

## まとめ

- 作業環境は**快適さより「本業と分ける・家庭と分ける・枠で分ける」**。端末・場所・時間を物理的に分ける
- 端末は**本業と共用を使わず、副業専用に**。高価でなくてよい。**保存しない運用が最大の安全対策**
- 家の場所は**専用の机か部屋・会議ができる場所・画面の向き・紙を置かない・家族への説明・枠の外は閉じる**
- 外では**情報を含まない作業だけ**。公衆の無線は使わない。本業の職場では作業しない
- 手順は**規定→端末→ロック→保存しない運用→場所→会議の時間帯→枠の外で開かない→外の線→依頼側に伝える→終了時に確認**
- 失敗は**分けていない**ことで起きる。設備より、分けることが先

## よくある質問

### 副業専用の端末を買う余裕がありません

手持ちの自分専用の端末（家族と共用でないもの）があれば、それで足ります。無ければ、依頼側の環境にブラウザでアクセスできる程度の、安価か中古の端末で十分です。副業の作業の大半は、依頼側の環境の中でブラウザ上で行うので、高い性能は要りません。端末を分けることが目的で、性能は目的ではありません。どうしても用意できないなら、家族と共用の端末に自分専用のアカウントを作り、保存しない運用を徹底し、離席時にロックする形で始め、一件目の報酬で専用の端末を用意する順番もあります。

### 家が狭く、専用の場所を作れません

部屋である必要はなく、机の一角で足ります。重要なのは、副業の枠の時間に、その場所で家族に入られないこと、会議の音声が届かないことです。場所が作れないなら、会議の時間帯を家族の不在時に合わせるか、音声だけの会議にする。画面は覗き見防止のフィルムで守る。枠が終わったら端末を閉じて、場所を生活に戻す。場所の広さより、時間帯と家族の了解で分ける形になります。

### 依頼側から、端末や環境について何も聞かれません。伝える必要がありますか

聞かれなくても、伝えたほうがよい。依頼側は副業の人の環境を知らないまま、応募者の情報を渡すことになります。「専用の端末で、御社の環境の中だけで作業し、端末には保存しません」と一言伝えれば、依頼側は安心し、権限を渡しやすくなります。書面の情報の扱いの項目にも入れておくと、依頼側にとっても、自分にとっても、後で確認できる根拠になります。伝えることが、信用の材料になります。
