営業として働いてきた。初対面の相手に連絡し、関心を聞き出し、断られても関係を続け、紹介をもらう。人事の仕事はしたことがないが、採用の「候補者に連絡して、会って、決めてもらう」という流れは、営業に似ている気がする。副業で人事に転身できるのか、何が売れるのか。結論を先に書くと、**営業の経験は、「候補者との接点を作り、動かす」工程で、そのまま売れます。売れるのは、「スカウト文面と返信後の面談の設計」「辞退の理由の聞き取りと引き止めの設計」「紹介や経路の開拓」の三つです。採用で最も止まりやすいのは、候補者に連絡が届かない、返信が来ない、面談で関心が高まらない、辞退の理由が分からない、という接点の工程で、営業の技能がそのまま効きます。「営業から人事へ」ではなく、「採用の接点の工程を、営業の技能で」と売ります。**人事未経験の売り方は[人事未経験が副業でできること](/media/fukugyo-mikeiken-jinji-fukugyo/)に、未経験の区分は[人事未経験でも受けられる仕事はあるか](/media/fukugyo-mikeiken/)に、ヒアリングの技能は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)にまとめています。

## この経歴の何が売れるか

営業の技能を、採用の工程に置き換えた棚卸しです。

| 営業の技能 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 初対面の相手に短い文面で返信をもらう | スカウト文面を、一通目で返信をもらう構成にする。件名、最初の一文、相手に合わせた一言 | スカウトの返信が来ない依頼側が多い |
| 相手の関心と困りごとを聞き出す | 候補者との面談で、転職の理由と求めるものを聞き出し、依頼側の魅力と結びつける | 面談が会社の説明で終わり、候補者の関心が高まらない依頼側が多い |
| 断られた後も関係を続ける | 辞退した候補者、見送った候補者との関係を残し、次の機会につなげる | 辞退で関係が切れ、候補者の蓄積がない依頼側が多い |
| 断られた理由を聞く | 辞退の理由を、当たり障りのない答えの奥まで聞き、文面と条件に反映する | 辞退の理由が「他社に決めた」で止まっている依頼側が多い |
| 紹介をもらう | 社員や候補者からの紹介の仕組みを設計し、紹介が回る形にする | 紹介が偶然に頼っている依頼側が多い |
| 経路を開拓する | 媒体、紹介、直接応募、発信、と候補者の経路を増やす | 一つの媒体に頼っている依頼側が多い |
| 数字で追う習慣 | 連絡、返信、面談、選考、内定、入社の段階の数を追い、落ちているところを見る | 「応募が少ない」としか見えていない依頼側に、段階で見る型を渡せる |
| 相手の言葉で話す | 求人票と面談で、社内の言葉ではなく候補者の言葉で話す | 求人票が社内の言葉で書かれている依頼側が多い |

売れるものの要点は、「採用の接点の工程は、営業の工程とほぼ同じ構造」だということです。スカウトは初回の接触、面談は関心の聞き出し、辞退は失注、紹介は紹介。営業でやってきたことを、候補者に対してやる。この置き換えができれば、人事の肩書きが無くても、依頼側にとっての価値は明確です。スカウト文面の書き方は[文章力をどう磨くか](/media/fukugyo-writing/)に、面談の設計は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、紹介の仕組みは[紹介につなげる](/media/fukugyo-shoukai-renkei/)に書いています。

## 売りにくい点とその扱い

営業の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 押しの強さへの警戒 | 「候補者を押して入社させるのでは」「無理に引き止めて、入社後に辞めるのでは」 | 「押す」ではなく「合うかを一緒に確かめる」と最初に示す。合わない候補者は無理に進めない、と線を引く。入社後の定着まで見る姿勢を示す |
| 候補者の判断を任せられるか | 「関心を高めるのは得意でも、合うかどうかの判断は」 | 判断を売らない。面談で聞き出したことを材料として渡し、判断は依頼側が持つ |
| 人事の工程を知らない | 「内定の出し方、条件の提示、入社の手続きを知らないのでは」 | 範囲を接点の工程に絞る。スカウト、面談、辞退の理由、紹介、経路。工程の運用と条件は依頼側 |

扱い方の要点は、「押す」ではなく「合うかを一緒に確かめる」と、最初に示すことです。営業の転身で依頼側が最も警戒するのは、「営業の押しで入社させて、すぐ辞める」ことです。この警戒に、「合わない候補者は無理に進めません。入社後に続くかまで見て、合う人を進めます」と最初に答えれば、営業の技能は警戒ではなく強みとして受け取られます。営業で身についた「無理に売らない」判断は、採用でも同じです。判断の線は[業務範囲を書面で固める](/media/fukugyo-scope/)に、人事の工程の学び方は[学び直しの進め方](/media/fukugyo-gakushuu/)に、候補者との関係は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に整理しています。

### エラベルの見解

担当する側から見ると、営業から転身して続いている人と、最初の案件が取れない人の差は、「営業の経験を人事に活かします」と言うか、「スカウトの返信が来るところまでと、面談で候補者の関心が高まるところまでを担います」と言うかです。前者は依頼側に「何をしてくれるのか分からない」と映り、後者は「うちの詰まりはそこだ」と映ります。採用の接点の工程で困っている依頼側は多く、営業の技能は工程で示せば強く伝わります。

見ていて差がつくのは、辞退の理由を、当たり障りのない答えの奥まで聞いているかです。「他社に決めました」で止めず、「他社のどこが決め手でしたか」「うちで気になった点はありましたか」と、営業で失注の理由を聞くのと同じように聞いている担当者は、依頼側の求人票と条件と面談を直す材料を持ち帰り、次の候補者の辞退が減っています。人事の経験者でも、辞退の理由をここまで聞く人は多くなく、営業の技能が最も差になる工程です。エラベルでは、依頼側が担当者を選ぶ仕組みなので、接点の工程を明確にし、「押さない」線を示している担当者に、その詰まりを抱えた依頼側がついています。営業の転身は、押す力ではなく、聞く力で始まります。

## 案件の探し方

営業から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| スカウト文面の作成と改善 | 初回の接触の技能で入れる | 「一通目で返信をもらう構成」を示す。営業の文面の実績を、スカウトに置き換えて |
| 候補者との面談の設計と同席 | 関心を聞き出す技能で入れる | 「候補者の転職の理由と求めるものを聞き出し、依頼側の魅力と結びつける」を示す |
| 辞退の理由の聞き取りと反映 | 失注の理由を聞く技能で入れる | 「辞退の理由を奥まで聞いて、求人票と条件と面談に反映する」を示す |
| 紹介の仕組みの設計 | 紹介をもらう技能で入れる | 「社員と候補者からの紹介が回る形」を提案の形で |
| 経路の開拓 | 経路を増やす技能で入れる | 「一つの媒体に頼らない経路」を提案の形で |
| 営業職の採用 | 自分の職種の候補者の目線が分かる | 「営業職の候補者が求人票のどこを見るか、面談で何を聞きたいか分かる」を示す。最初の案件に向く |

探し方の要点は、「営業職の採用から入る」ことです。自分の職種なら、候補者がどこを見ているか、何に惹かれ、何で冷めるか、辞退の本当の理由は何かが分かり、人事の経験が無くても依頼側にとって価値があります。営業職の採用で一件受け、スカウト文面と面談と辞退の理由の型を作れば、他の職種にも広げられます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、面談で聞かれることは[副業案件の面談で聞かれること](/media/fukugyo-mensetsu/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。営業の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 接点の工程の技能の強さ | スカウトの返信、面談での関心、辞退の理由は、人事経験者でも得意な人が少なく、営業の技能が高く評価される | 「未経験だから安く」ではなく、接点の工程の単価で |
| 判断を含まない範囲 | 判断を含まない範囲は、判断を含む範囲より単価は下がる | 材料と接点に徹し、判断は依頼側に |
| 成果報酬の誘い | 営業の経験があると、「入社が決まったら成果報酬で」と誘われやすい | 成果報酬は、判断が依頼側にある以上、自分で結果を左右できない。時間か成果物で受ける方が安定する |
| 自分の職種の採用 | 営業職の採用では、職種の理解が評価される | 他の職種より単価を下げない |
| 型の蓄積 | スカウト文面の型、面談の型、辞退の理由の聞き取りの型は、依頼側に残す価値が高い | 型を残す形で、更新の根拠にする |
| 最初の案件 | 人事の実績が無いので、範囲を絞って小さく | 単価を下げるのではなく、範囲と時間を小さくする |

単価の要点は、「成果報酬の誘いに、最初は乗らない」ことです。営業の転身では、依頼側から「入社が決まったら成果報酬で」と誘われやすく、営業の感覚で受けたくなります。ただ、採用の判断は依頼側にあり、候補者の意思もあり、自分の力で結果を左右できる範囲は営業より狭いです。時間か成果物で受け、実績ができて判断の構造が分かってから、成果報酬を検討します。成果報酬を含む単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の見せ方は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に整理しています。

## 始める順番

営業から人事の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、営業の技能を、採用の接点の工程に置き換えて書き出す | 初回の接触、関心の聞き出し、失注の理由、紹介、経路、数字 |
| 二、「押さない」線を、自分の言葉で書く | 合わない候補者は進めない。入社後の定着まで見る |
| 三、人事の主要な工程と言葉を一通り学ぶ | 応募から入社までの流れ、内定と条件の提示、個人情報の扱い |
| 四、範囲を接点の工程に絞る | スカウト、面談、辞退の理由、紹介、経路。運用と条件と判断は依頼側 |
| 五、営業職の採用を、最初の範囲にする | 候補者の目線が分かる職種から |
| 六、「採用の接点の工程を、営業の技能で」の一言を作る | 「営業から人事へ」とは言わない |
| 七、登録先に、範囲を工程で登録する | スカウト文面、面談の設計、辞退の理由の聞き取り |
| 八、時間か成果物で一件受け、型を残す | 成果報酬は後で |

順番の要点は、「二」の「押さない」線を、自分の言葉で書いておくことです。営業の転身への依頼側の懸念は、「押して入社させて、すぐ辞める」の一点に集まります。この懸念に、最初の面談で自分の言葉で答えられれば、営業の技能は懸念ではなく強みになります。営業でも、無理に売った顧客は続かなかったはずで、その経験をそのまま言葉にします。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「営業の経験は、人事では押しが強いと嫌われる」というものです。実際には、採用で最も止まりやすいのは接点の工程で、候補者に届かない、返信が来ない、面談で関心が高まらない、辞退の理由が分からない、という依頼側の詰まりに、営業の技能はそのまま効きます。嫌われるのは、押すことであって、営業の技能ではありません。「押さない」線を示し、聞く力を前に出せば、営業の転身は依頼側に歓迎されます。

順番として、営業の技能を接点の工程に置き換え、「押さない」線を自分の言葉で書き、人事の工程と言葉を学び、範囲を接点に絞り、営業職の採用から始め、工程と技能を結びつけた一言を作り、登録先に工程で登録し、時間か成果物で一件受けて型を残す。この順番で、営業の転身は、「押しが警戒される転身」から「接点の詰まりを埋める形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、接点の工程を明確にし、「押さない」線を示している担当者に、その詰まりを抱えた依頼側がついています。営業の転身は、押す力ではなく、聞く力と線の提示で始まります。

## まとめ

- 営業の経験は**「候補者との接点を作り、動かす」工程**でそのまま売れる。**スカウトと面談・辞退の理由の聞き取り・紹介と経路の開拓**の三つ
- **「営業から人事へ」ではなく「採用の接点の工程を、営業の技能で」**と売る
- 売りにくい点は**押しの強さへの警戒・候補者の判断・人事の工程**。「押さない」線を最初に示し、判断は依頼側に、範囲は接点に絞る
- 最も差になるのは**辞退の理由を奥まで聞くこと**。人事経験者でも少ない技能
- 案件は**営業職の採用から**。成果報酬の誘いには最初は乗らず、時間か成果物で
- 順番は**技能の置き換え → 「押さない」線 → 工程の学習 → 範囲を接点に → 営業職から → 一言 → 登録 → 一件**

## よくある質問

### 依頼側から「入社が決まったら成果報酬で」と言われました。営業の経験があるので自信はあります

最初の案件では、時間か成果物で受けることをお勧めします。営業と違い、採用の判断は依頼側が持ち、候補者の意思もあり、自分の力で結果を左右できる範囲が狭いです。スカウトで返信をもらい、面談で関心を高めても、依頼側の面接で見送られる、条件で辞退される、ということが起きます。実績ができて、その依頼側の判断の構造が分かってから、成果報酬を検討します。成果報酬の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

### 候補者との面談で、営業のように「クロージング」してよいですか

「合うかを一緒に確かめる」形にし、押して決めさせる形は避けます。営業のクロージングは、相手が決めるための最後の一押しですが、採用では、押されて入社した候補者は続かず、依頼側と候補者の両方に損があります。面談では、候補者の転職の理由と求めるものを聞き出し、依頼側の魅力と結びつけ、合わない点があれば正直に伝えます。その姿勢が、候補者の信頼と、依頼側の信用の両方を作ります。面談の設計は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、候補者との関係は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に書いています。

### 営業の顧客や人脈を、副業の候補者の経路に使ってよいですか

本業の営業の顧客や人脈を、副業の候補者の経路に使うことは避けます。本業の会社の情報と関係を副業に持ち込む形になり、本業との利益相反と守秘の線を越えます。副業の経路の開拓は、依頼側の社員の紹介、依頼側の候補者の蓄積、公開の媒体と発信で行います。営業で身についた「経路を開拓する技能」は使えますが、「本業で作った経路そのもの」は使いません。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。
