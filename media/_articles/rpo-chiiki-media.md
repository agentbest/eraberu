全国型の求人媒体に出しても、応募が来ない。地域の求人媒体（フリーペーパー、地域の求人サイト、地元の新聞、地域の情報誌）の営業が来て、「地元の人にはこちらが届く」と言う。使うべきか、費用に見合うか、判断できない。結論を先に書くと、**地域の求人媒体は、「全国型で来ないから」で足すものではなく、「地域で働く人を採る職種か」と「その媒体の利用者の層が、募集の職種に合うか」で決めるものです。合えば、全国型より届くことがあります。合わなければ、費用の無駄です。決めたら、一つの求人で、最短の期間で、小さく試し、自社の記録で判断します**。媒体の選び方の全体は[どの媒体を使えばよいか分からない](/media/rpo-media-erabenai/)に、地方の採用は[地方拠点の採用が進まない](/media/rpo-chihou-saiyo/)にまとめています。媒体の仕様、費用、掲載の条件は、各媒体の公式の案内で確認します。

## 地域媒体を迷う構造

地域の求人媒体を使うかどうかで迷うのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「全国型で来ないから」で足そうとしている | 応募が来ない原因が、経路なのか、求人票なのか、速さなのかを見ていない |
| 営業の勧めで判断しようとしている | 媒体の営業は、自社の媒体を勧める。中立ではない |
| 利用者の層を確認していない | 「地元の人が見る」の中身（年齢、職種、状況）を、聞いていない |
| 職種が、地域で採る職種かを分けていない | 全国から専門の経験者を採る職種に、地域媒体は向かない |
| 費用と効果の見方が無い | 「安い」「高い」の印象で、自社の記録で比べていない |
| 一度に大きく契約しそうになっている | 年間の契約や、複数の媒体を同時に |
| 求人票を、全国型と同じにしようとしている | 地域媒体の利用者に合わせた書き方を考えていない |
| 「地域の会社らしさ」を見せる材料が無い | 地域の媒体では、「地元の会社」であることが伝わる材料が要る |

構造の大半は、「職種と利用者の層で判断していない」ことです。

## 地域媒体の位置づけ

地域の求人媒体を、採用の経路の中でどう位置づけるかです。一般的な傾向であり、個々の媒体の実態は公式の案内と担当者に確認します。

| 特徴 | 中身 |
|---|---|
| 届く相手 | その地域で働きたい人。通勤の範囲で探している人。地域に根ざして暮らしている人 |
| 形 | フリーペーパー、地域の求人サイト、地元の新聞の求人欄、地域の情報誌、地域のラジオやテレビ。形で届く層が違う |
| 向く職種 | 地域で働く人を採る職種。事務、販売、サービス、製造、介護、物流、飲食、地域の営業など |
| 向かない職種 | 全国から専門の経験者を採る職種。動いていない経験者に届けたい場合 |
| 費用の形 | 掲載の期間や枠で決まることが多い。形は媒体により違う。公式の案内で確認 |
| 全国型との違い | 全国型は競合が多く埋もれやすい。地域媒体は、その地域の求人の中で見られる |
| 「地元の会社」の見え方 | 地域媒体に出ていること自体が、「地元で採っている会社」として見られる |

位置づけの要点は、「地域で働く人を採る職種の、主力の一つになりうる」ことです。全国型で来ない専門職を、地域媒体で採ろうとしても、届きません。

## 使う判断と使わない判断

地域媒体を使う判断と、使わない判断の材料です。

| 使う判断 | 使わない判断 |
|---|---|
| 地域で働く人を採る職種 | 全国から専門の経験者を採る職種 |
| 通勤の範囲が、地域に限られる | リモートで、地域を問わない |
| 媒体の利用者の層が、募集の職種と合う（担当者に聞いて確認） | 利用者の層が合わない、または担当者が答えられない |
| 全国型で、その地域からの応募が無い | 全国型で、その地域からの応募が既に来ている |
| 応募が来ない原因が、経路である（求人票と速さは直してある） | 応募が来ない原因が、求人票か速さである（先にそちらを直す） |
| 最短の期間で、一つの求人で試せる | 年間の契約しか無い |
| 「地元の会社」であることを見せる材料がある | 地元との関わりが薄く、見せる材料が無い |
| 地域の拠点の採用 | 本社の専門職の採用 |

使わない判断も、正しい判断です。「営業に勧められたから」「全国型で来ないから」で足すと、費用の無駄になります。

応募が来ない原因が経路でないなら（求人票が薄い、返信が遅い）、地域媒体を足しても同じことが起きます。先に、求人票と速さを直します。

## 選び方と確認すること

地域媒体を選ぶときに、確認することです。

**利用者の層を、担当者に聞く。** 「この媒体の読者や利用者は、どういう年齢、職種、状況の人が多いか」「この職種の求人で、応募の傾向はどうか」。答えが具体的か。曖昧なら、その職種に強くない可能性があります。

**同じ職種の他社の求人が、出ているかを見る。** その媒体に、同じ職種の求人が出ていれば、その職種の人が見ている。多すぎれば、競合。

**形（紙かサイトか）で、届く層が違う。** 紙の媒体は、手に取る層。サイトは、検索する層。地域と職種で、どちらが合うか。担当者と、地域の人（社員）に聞く。

**掲載の期間、枠、費用、更新の条件を、書面で確認する。** 口頭と書面が違うことがある。書面が正。自動更新の有無も。公式の案内と契約書で確認。

**最短の期間で試せるかを聞く。** 「一号だけ」「一か月だけ」「一つの求人だけ」で試せるか。年間の契約しか無い媒体は、最初は避ける。

**応募の受付の形を確認する。** 媒体経由の応募が、どう届くか（メール、電話、媒体の仕組み）。自社の応募の窓口に集められるか。

**同業の会社に聞く。** 同じ地域で同じ職種を採っている会社が、どの地域媒体で効いたか。規模や状況が違えば同じ結果にはならないが、候補の絞り込みには使える。

**地域の人（社員）に聞く。** 「地元で仕事を探すとき、何を見るか」。社員の経路が、候補者の経路。

確認の要点は、「利用者の層と、最短の期間で試せるか」です。この二つが確認できない媒体は、候補から外します。

### エラベルの見解

相談で最も多い失敗は、「全国型で応募が来ないので、営業に勧められた地域のフリーペーパーに年間で出した。募集の職種は専門の経験者で、フリーペーパーの読者の層と合わず、一年で応募は数件、全部要件に合わなかった」というものです。職種と利用者の層が合っていませんでした。同じ会社の、地域の事務の職種を、同じフリーペーパーに一号だけ出したら、応募が来て、一人が決まりました。媒体が悪いのではなく、職種との合いでした。

見ていて差がつくのは、担当者が「職種と層の合い」から入るかどうかです。「地域媒体も試しましょう」と言う担当者と、「この職種は地域で働く人を採る職種なので、地域媒体が合う可能性があります。担当者に利用者の層を聞いて、一号だけ、一つの求人で試しましょう」と、合いと試し方から入る担当者がいます。後者は、年間の契約で失敗しません。

発注側にできるのは、地域媒体の営業に「利用者の層」と「最短の期間」を聞き、答えが曖昧なら契約しないことです。

## 求人票の書き方

地域媒体の求人票は、全国型とは書き方を変えます。

| 項目 | 地域媒体での書き方 |
|---|---|
| 地元の会社であること | 「〇〇（地域）で△年」「地元の△△と取引」など、地域との関わりを事実として。地域媒体の読者は「地元の会社か」を見る |
| 通勤の実態 | 「〇〇駅から徒歩」「車通勤可、駐車場あり」。地域の読者は、通勤の手段を見る |
| 働き方の実態 | 時間、休日、残業、シフト。地域で働く人は、生活との両立を重く見る |
| 役割の中身 | 「一日に何をするか」「誰と働くか」。業務の箇条書きではなく、日々の様子 |
| 一緒に働く人 | 「〇〇さん（地元出身）」など、同意のうえで。地域の読者は「知っている人がいるか」「地元の人がいるか」を見る |
| 未経験の場合 | 「入社後に教えること」「最初の一か月の予定」。地域媒体の読者には、未経験から応募する人が多いことがある |
| 条件 | 正確に。地域の水準と比べる。数字は自社の制度から |
| 応募の方法 | 電話、メール、媒体の仕組み。複数の方法を。地域の読者には、電話で応募したい人もいる |
| 写真 | 職場と一緒に働く人の、普段の様子。地域の読者は、「どんな場所か」を写真で見る |

書き方の要点は、「地元の会社であること」と「通勤と働き方の実態」です。全国型の求人票の「役割と成長」を前に出す書き方は、地域媒体の読者には届きにくいことがあります。

紙の媒体は、文字数の制約が強いことがあります。所定の枠の中で、上の項目を優先します。仕様は各媒体の公式の案内で確認します。

## 小さく試す運用

地域媒体を使うと決めたら、小さく試します。

**一つの求人で。** 複数の求人を同時に出さない。媒体の効きと、求人の効きを分けて見る。

**最短の期間で。** 「一号だけ」「一か月だけ」。年間の契約で始めない。

**求人票は、地域媒体向けに調整してから。** 全国型の求人票をそのまま出すと、媒体の効きが分からない。

**応募の受付を、他の経路と同じ窓口に。** 媒体経由の応募も、同じ表で、同じ速さで対応。電話の応募には、電話で受け付ける体制を。

**記録を取る。** 応募の数、要件に合う数、面接に進んだ数、内定の数。他の経路と並べて。数字は自社の記録から。

**「応募の数」ではなく「面接に進んだ数」で見る。** 応募が多くても、要件に合わなければ意味が無い。

**期間が終わったら、続ける・変える・止めるを決める。** 面接に進む人が来ていれば続ける。来ていなければ、求人票を直して再度か、別の媒体か、地域媒体を止める。

**続けるなら、頻度を決める。** 「毎号」ではなく、「募集のあるときだけ」「四半期に一度」。地域媒体に出続けること自体が、「地元で採っている会社」の印になる面もあるが、費用と効果で決める。

試す運用の要点は、「一つの求人、最短の期間、記録で判断」です。

## 他の経路との組み合わせ

地域媒体を、他の経路と組み合わせます。

**地域で働く人を採る職種は、地域媒体を主力の一つに。** 加えて、公的な職業紹介（[ハローワークをどう使うか](/media/rpo-hellowork/)）、社員の紹介、地域の学校、地域のつながり。

**専門の経験者を採る職種は、地域媒体を使わない。** 主力はスカウト、紹介会社、特化型の媒体。

**地域の拠点の採用は、地域媒体と地元の経路を組み合わせる。** [地方拠点の採用が進まない](/media/rpo-chihou-saiyo/)。

**求人票の原本を一つ持ち、地域媒体向けに調整する。** 原本を直したら、地域媒体の求人票も更新。

**応募の受付を、一つの窓口に。** 全経路の応募を、同じ表で、同じ速さで。

**経路ごとの記録を、月に一度見る。** 「この職種は地域媒体が効く」「この職種は効かない」を記録で判断。媒体の棚卸しは[媒体を増やしすぎて管理できない](/media/rpo-media-oosugi/)。

組み合わせの要点は、「職種ごとに主力と補助を分ける」ことです。地域媒体だけ、全国型だけ、ではなく、職種で使い分けます。

## 外注する場合の範囲

地域媒体を使うかの問題を、採用代行に出す場合の範囲です。

**出せる工程。** 職種ごとの向き不向きの整理、応募が来ない原因の切り分け（経路か求人票か速さか）、地域媒体の候補の整理と担当者への確認（利用者の層、最短の期間、費用、応募の受付の形）、同業や社員への聞き取り、地域媒体向けの求人票の調整、小さく試す設計と実行、応募の受付と対応（電話を含む体制の設計）、記録と他の経路との比較、続ける・変える・止めるの判断の材料、他の経路との組み合わせの設計。

**社内に残す判断。** 地域媒体を使うかどうか、契約の可否と費用、地元の会社であることを見せる内容、一緒に働く人の写真と話の公開の同意、判定、内定。

**外注の効きどころ。** 地域媒体は、「営業の勧めで判断する」「年間で契約して失敗する」ことが起きやすい経路です。担当者が職種との合いを見て、利用者の層を確認し、最短の期間で小さく試し、記録で判断すれば、無駄な契約を避けられます。担当者は複数の会社で複数の地域媒体を見ているので、「この職種と地域なら、この形の媒体」の見立てを持ち込めます。ただし、媒体の仕様と費用は、担当者も公式の案内で確認します。

**外注しても動かない場合。** 営業の勧めで年間の契約をしてしまう、求人票を全国型のまま出す、応募の対応を後回しにする、記録を取らない。社内の判断で、代行を替えても直りません。

地域媒体は、職種と層が合えば、効く経路です。外注は、合いを見て、小さく試す手順を持ち込む手段です。

### エラベルの見解

担当する側から見ると、地域媒体の相談で最も多いのは、「地元の会社であることを、求人票に書いていない」ことです。地域媒体の読者は、「地元の会社か」「地元の人が働いているか」「通勤できるか」を最初に見ます。全国型の求人票の「役割と成長」を前に出した書き方では、地域媒体の読者には届きません。

「〇〇（地域）で△年」「〇〇駅から徒歩」「地元出身の社員がいる」。地域の読者が見る情報を、前に出す。それだけで、同じ媒体でも応募が変わります。

発注側にできるのは、地域媒体の求人票に、「地元の会社であること」と「通勤の実態」を、事実として書くことです。

## よくある質問

### 全国型で応募が来ないので、地域媒体に切り替えるべきですか

「切り替える」の前に、応募が来ない原因を見ます。求人票が薄い、返信が遅い、が原因なら、地域媒体に変えても同じことが起きます。先に求人票と速さを直します。原因が経路で、募集の職種が「地域で働く人を採る職種」なら、地域媒体が合う可能性があります。担当者に利用者の層を聞き、一つの求人で最短の期間で試し、記録で判断します。専門の経験者を採る職種なら、地域媒体は向かず、スカウトや紹介会社が主力です。

### 地域媒体の営業に「年間契約がお得」と言われています

年間の契約は、最初は避けます。「一号だけ」「一か月だけ」「一つの求人だけ」で試せるかを聞き、試せないなら候補から外します。「お得」でも、職種と利用者の層が合わなければ、一年分の費用が無駄になります。試して、面接に進む人が来ると分かってから、頻度と期間を決めます。契約の条件（期間、枠、費用、更新、解約）は、口頭ではなく書面で確認し、自動更新の有無を見ます。

### 紙の媒体とサイトの媒体、どちらがよいですか

地域と職種と届けたい層で違います。紙は、手に取る層（地域で暮らし、紙の媒体を見る習慣がある人）に届き、サイトは、検索する層に届きます。媒体の担当者に「この職種の応募の傾向」を聞き、社員に「地元で仕事を探すとき、何を見るか」を聞き、同業に「どの媒体で効いたか」を聞いて、候補を絞ります。決めきれなければ、一つずつ、一つの求人で、最短の期間で試し、記録で比べます。両方に薄く出すと、どちらが効いたか分からなくなります。
