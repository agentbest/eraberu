採用のために、SNSのアカウントを作った。「何か投稿しないと」で、会社のお知らせと、社員のランチの写真と、オフィスの様子を投稿している。反応はほぼ無く、応募にもつながらず、担当者は「何を投稿すればよいか分からない」と言って、三か月で止まった。結論を先に書くと、**採用SNSで発信するのは、「バズる投稿」でも「会社の告知」でもなく、「候補者が応募の前に知りたいこと」です。役割の中身、一緒に働く人、働き方の実態、選考の流れ、会社が向かう先。この五つを、続けられる頻度で、実態のまま出します。SNSは、応募を集める場ではなく、候補者が会社を調べたときに「この会社は、こういう仕事を、こういう人と、こういう働き方でしている」と分かる場です**。採用サイトの効果が無い場合は[採用サイトを作ったのに効果がない](/media/rpo-shanai-chinmoku/)に、素材が無い場合は[使える写真・素材がない](/media/rpo-shashin-nai/)にまとめています。

## 発信が続かない構造

採用SNSの発信が続かない、効かないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 目的が無い | 「他社がやっているから」。応募を集めるのか、会社を知ってもらうのか、決まっていない |
| 何を出すかが決まっていない | 「何か投稿しないと」で、告知とランチの写真。候補者が知りたいことではない |
| 「バズる」を目指している | 反応の数を追い、候補者に関係ない投稿になる。または、反応が無くて止まる |
| 担当者が一人で、決まっていない | 「手が空いたら」で、続かない。担当が異動すると止まる |
| 頻度が決まっていない | 最初は毎日、二週間で止まる。続けられる頻度で始めていない |
| 素材が無い | 写真も、社員の話も、役割の記述も無く、投稿を作れない |
| 実態を良く見せようとする | 「アットホーム」「風通しが良い」。候補者は、実態を知りたい |
| 効果を測っていない | 「反応が無い」で止める。応募との関係を見ていない |
| 会社の公式の告知と、採用の発信が混ざっている | 会社のニュースの合間に、採用の投稿。候補者向けの流れになっていない |

構造の大半は、「目的」と「何を出すか」と「続けられる体制」が無いことです。

## 目的の置き方

採用SNSの目的を、置き直します。

**「応募を集める」を目的にしない。** SNSの投稿から直接応募が来ることは、少ないです。目的にすると、「応募が来ない」で止まります。

**「候補者が会社を調べたときの受け皿」を目的にする。** 求人票やスカウトや紹介で会社を知った候補者が、会社名で検索し、SNSを見る。そのときに「この会社は、こういう仕事を、こういう人と、こういう働き方でしている」と分かる。採用サイトと同じ役割です。役割の置き直しは[採用サイトを作ったのに効果がない](/media/rpo-shanai-chinmoku/)に書いています。

**「実態を、継続して見せる」を目的にする。** 採用サイトは一度作ったら固定されますが、SNSは日々の実態を出せます。「この会社は、いま、こういう仕事をしている」が、時間とともに積み上がります。

**「社員が外で話せる材料」を目的にする。** 社員が知り合いに会社を説明するとき、SNSの投稿を見せられる。リファラルの材料になります。[リファラル採用が広がらない](/media/rpo-referral-susumanai/)。

**知名度を「少しずつ作る」を目的にする。** 短期の効果ではなく、年単位の積み上げ。[知名度がなくて応募が集まらない](/media/rpo-chimeido-nai/)。

目的の要点は、「応募の数」ではなく「候補者が見たときに分かるか」で測ることです。

## 候補者が知りたい五つ

候補者が応募の前に知りたいことは、五つです。この五つを、順に、繰り返し出します。

| 知りたいこと | 出すもの | 例 |
|---|---|---|
| 一、役割の中身 | 「何を決める役割か」「一日に何をしているか」「どんな仕事があるか」 | 「営業の〇〇さんの一日」「今週、△△の役割で決めたこと」「この役割の、一つの案件の流れ」 |
| 二、一緒に働く人 | 社員の顔と、具体的な話 | 「入社して最初の三か月で何をしたか」「一番大変だったこと」「続けている理由」。本人の同意のうえで |
| 三、働き方の実態 | 時間、リモート、休日、柔軟さ。制度ではなく実態 | 「今日はリモートの人が何人」「〇〇さんは、こういう働き方をしている」。数字は自社の記録 |
| 四、選考の流れ | 応募から内定まで、何回、何を見るか、どのくらいで | 「選考はこう進む」「面接で聞くこと」「よくある質問」 |
| 五、会社が向かう先 | 事業の方向、なぜこの役割が要るか、経営者の言葉 | 「今年、〇〇に取り組む理由」「この役割を募集する理由」。経営者の顔で |

五つの要点は、「候補者が求人票では分からないこと」を出すことです。求人票は役割と条件、SNSは日々の実態と人。

五つを、一つずつ、繰り返し出します。「今週は役割の中身、来週は一緒に働く人」のように。五つが揃えば、候補者は「この会社で働く自分」を想像できます。

## 投稿の型

五つを出す、投稿の型です。

| 型 | 中身 | 頻度の目安 |
|---|---|---|
| 一日の流れ | 「〇〇の役割の、ある一日」。時間ごとに、何をしているか。写真は普段の様子 | 月に一〜二回 |
| 社員の話 | 一人の社員の、具体的な話。「最初の三か月」「大変だったこと」「続けている理由」。顔写真と一言。本人の同意のうえで | 月に一〜二回 |
| 仕事の場面 | 会議、作業、顧客との場面（公開できる範囲で）。何をしている場面かを一言 | 週に一回 |
| 働き方の実態 | 「今日のオフィスとリモートの人数」「〇〇さんの働き方」。数字は自社の記録から | 月に一〜二回 |
| 選考の説明 | 「選考の流れ」「面接で聞くこと」「よくある質問への答え」 | 募集のたび |
| 経営者の言葉 | 「この役割を募集する理由」「今年取り組むこと」。経営者の顔で、短く | 月に一回 |
| 募集の案内 | 役割の一行と、求人票へのリンク。「募集」だけの投稿は、他の投稿の合間に | 募集のたび |
| 入社した人 | 「〇〇さんが入社しました。この役割で、こういう理由で」。本人の同意のうえで | 入社のたび |
| 候補者からの質問への答え | 面接や面談でよく聞かれることを、投稿で答える | 月に一回 |

型の要点は、「普段の様子を、実態のまま」です。演出した写真、用意された美談は、候補者に見抜かれます。スマートフォンで撮った普段の場面と、社員の率直な言葉のほうが、届きます。

写真と社員の話の扱い（同意、公開の範囲）は、[使える写真・素材がない](/media/rpo-shashin-nai/)に書いています。

### エラベルの見解

相談で最も多い失敗は、「採用SNSを始めて、毎日投稿しようと決め、ネタが尽きてランチの写真と『今日も頑張ります』になり、二か月で止まった」というものです。目的が無く、何を出すかが決まっておらず、頻度が続けられないものでした。目的を「候補者が調べたときの受け皿」に置き、五つ（役割、人、働き方、選考、向かう先）を週に一〜二回、担当者が社員に十分の聞き取りをして投稿する形にしたら、一年続き、面接に来た候補者から「SNSを見て、〇〇さんの話が印象に残っていた」と言われるようになりました。バズることではなく、続けることでした。

見ていて差がつくのは、担当者が「五つ」で設計するかどうかです。「SNSを運用します」で告知とランチの写真を投稿する担当者と、「候補者が知りたい五つを、週に一〜二回、社員への十分の聞き取りで作りましょう。反応の数ではなく、面接で『見た』と言われるかで測ります」と、五つと頻度と測り方で設計する担当者がいます。後者は、続きます。

発注側にできるのは、「SNSをやりたい」の前に、「候補者が知りたい五つを出せる素材（役割の記述、社員の話、働き方の実態）があるか」を確認することです。

## 続けられる体制

SNSは、続かなければ意味がありません。続けられる体制です。

**担当者を一人決める。** 人事か、採用代行の担当者。「手が空いたら」ではなく、担当として。

**頻度を、続けられる量で決める。** 週に一〜二回。「毎日」は続きません。最初は少なく、続いたら増やす。

**投稿の素材を、社員から集める仕組み。** 月に一度、社員に十分の聞き取り（「最近の仕事で印象に残ったこと」「今週決めたこと」）。担当者が投稿にまとめる。社員に投稿を書かせない。

**投稿の予定を、月の初めに決める。** 「第一週は役割の中身、第二週は社員の話、第三週は働き方、第四週は経営者の言葉」。予定があれば、「何を投稿するか」で迷わない。

**確認の手順を、軽く。** 投稿の前に、責任者が確認する場合、当日に返す形に。確認に一週間かかると、続きません。社員の話と写真は、本人の同意を最初に取る。

**素材の管理を、共有の場所に。** 写真、社員の話、役割の記述。担当者が異動しても続けられる形。

**担当者が異動したら、引き継ぐ。** 投稿の予定、素材の場所、同意の記録、アカウントの管理。

**三か月ごとに、振り返る。** 「続いているか」「五つが出せているか」「面接で『見た』と言われたか」。

体制の要点は、「担当者と、続けられる頻度と、素材を集める仕組み」です。三つが無いと、三か月で止まります。

## やってはいけないこと

採用SNSで、やってはいけないことがあります。

**実態を良く見せる。** 「アットホーム」「風通しが良い」「残業ゼロ」と書いて、実態が違えば、面接か入社後に分かり、不信と口コミになります。

**社員の同意なく、顔や話を出す。** 写真、名前、話の公開は、本人の書面の同意のうえで。用途を限定し、取り下げの申し出に応じる。同意の扱いは[使える写真・素材がない](/media/rpo-shashin-nai/)に書いています。

**顧客や取引先の情報を、無断で出す。** 仕事の場面の写真や話に、顧客や取引先の情報が入っていないか。公開できる範囲を確認する。

**候補者の情報を出す。** 面接に来た人、内定者の情報は、出しません。入社した人も、本人の同意のうえで。

**社員に投稿を強制する。** 「全員、週に一回投稿」のような形は、社員の負担と不自然な投稿を生みます。担当者がまとめる形に。

**反応の数を、社員に求める。** 「いいね」の数で社員を評価する形は、避けます。

**炎上しそうな内容を出す。** 社会的な話題、他社への言及、内部の問題。採用SNSでは触れません。

**アカウントの管理を、個人に任せる。** 会社のアカウントを、担当者の個人のアカウントと混ぜない。管理者と権限を会社で持つ。

**募集だけを投稿する。** 「募集中」の投稿だけが並ぶアカウントは、「採用のためだけ」に見え、候補者は見ません。

やってはいけないことの要点は、「実態を偽らない」と「同意と権利を守る」です。この二つを外すと、採用SNSは会社の信用を損ないます。

## 効果の見方

採用SNSの効果を、「反応の数」で見ないことが要点です。

**面接で「見た」と言われたか。** 面接や面談で、「SNSを見ました」「〇〇さんの話が印象に残っています」と言われたか。記録します。

**採用サイトへの流れ。** SNSから採用サイトや求人票への流れがあるか。計測の道具と設定は各サービスの公式の案内で確認します。

**候補者の質問の変化。** 面接で「働き方は」「一緒に働く人は」の質問が減ったか。SNSで答えていれば、減ります。

**辞退の理由の変化。** 「思っていたのと違う」の辞退が減ったか。SNSで実態を見せていれば、減ります。

**社員が外で話せるようになったか。** 社員が知り合いに「SNSを見て」と言えるようになったか。

**続いているか。** 三か月、半年、一年。続いていること自体が、最初の効果です。

**五つが出せているか。** 役割、人、働き方、選考、向かう先。偏っていないか。

**反応の数は、参考にとどめる。** 多ければ良いとは限らず、少なくても候補者に届いていることがあります。

効果の要点は、「候補者との接点で、SNSの効果を聞く」ことです。反応の数より、面接での一言が、効果の証拠です。

## 外注する場合の範囲

採用SNSの発信を、採用代行に出す場合の範囲です。

**出せる工程。** 目的の置き直しの整理、五つを出すための素材の整理（役割の記述、社員の話、働き方の実態、選考の流れ、経営者の言葉）、月の投稿の予定の作成、社員への聞き取り（月に一度、十分）と投稿への文章化、写真の撮り方の案内と素材の管理、投稿の作成と（社内の方針に沿った）投稿の運用、同意の書式の案（専門家の確認を経て）、やってはいけないことの一覧、三か月ごとの振り返り、面接での「見た」の記録、採用サイトへの流れの計測の設定の支援。

**社内に残す判断。** SNSを行うかどうか、アカウントの管理者と権限、公開する内容の承認、社員の話と写真の公開の同意の取得、経営者の言葉、顧客や取引先の情報の公開の範囲、投稿の最終の確認。

**外注の効きどころ。** 採用SNSは、「担当者がいない」「何を出すか分からない」「続かない」の三つで止まります。担当者が五つの設計と月の予定と社員への聞き取りと投稿の作成を担えば、社内は「同意の取得」と「内容の承認」だけで済み、続きます。担当者は複数の会社の採用の発信を見ているので、「候補者が反応する型」を持ち込めます。ただし、実態を偽らないことと、同意と権利は、社内の責任です。

**外注しても動かない場合。** 社内が実態を良く見せることを譲らない、社員の同意を取らない、経営者が言葉を出さない、確認に一週間かかる。社内の判断で、代行を替えても直りません。

採用SNSは、五つを続けられる頻度で出せば、候補者の受け皿になります。外注は、五つを設計し、続ける手段です。

### エラベルの見解

担当する側から見ると、採用SNSの相談で最も多いのは、「反応の数で判断して、止めてしまう」ことです。三か月投稿して、反応が少ないので「効果が無い」と止める。ただ、候補者は「いいね」を押しません。黙って見て、面接に来ます。面接で「SNSを見ました」と言われるまで、効果は見えません。

反応の数ではなく、「面接で『見た』と言われたか」で測る。それを記録し始めると、「反応は少ないが、来た人は見ている」が分かります。

発注側にできるのは、面接の最初に「当社のSNSや採用サイトをご覧になりましたか」と聞く一言を、面接官の型に入れることです。

## よくある質問

### 採用SNSは、本当に応募につながりますか

SNSの投稿から直接応募が来ることは少ないです。効くのは、求人票やスカウトや紹介で会社を知った候補者が、会社名で検索してSNSを見たときに、「こういう仕事を、こういう人と、こういう働き方でしている」と分かることです。その候補者が応募に進み、面接で「SNSを見ました」と言います。「応募を集める場」ではなく「調べたときの受け皿」として設計し、面接で「見たか」を聞いて効果を測ります。反応の数で判断すると、効いているのに止めてしまいます。

### 何を投稿すればよいか、ネタが尽きます

「バズるネタ」を探すから尽きます。候補者が知りたい五つ（役割の中身、一緒に働く人、働き方の実態、選考の流れ、会社が向かう先）を、順に繰り返し出します。素材は、月に一度、社員に十分の聞き取り（「最近の仕事で印象に残ったこと」「今週決めたこと」）をすれば、集まります。「〇〇さんの一日」「今週決めたこと」「よくある質問への答え」は、毎月違う内容になります。月の初めに四週分の予定を決めれば、「何を投稿するか」で迷いません。

### 社員が投稿に協力してくれません

社員に投稿を書かせない形にします。担当者が月に一度、十分の聞き取りをして、投稿にまとめる。社員の負担は十分です。顔写真と話の公開は、本人の書面の同意のうえで、用途を限定し、取り下げに応じます。顔を出したくない社員には、後ろ姿や手元や、話だけの形を用意します。「全員、週に一回投稿」のような強制は、負担と不自然な投稿を生み、協力が減ります。協力してくれる社員から始め、投稿が形になれば、他の社員も協力しやすくなります。
