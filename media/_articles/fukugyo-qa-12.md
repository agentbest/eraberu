副業を始めたいが、本業の繁忙期や家庭の事情で、途中で稼働が取れなくなる可能性がある。そうなったとき、依頼側に迷惑をかけ、契約を切られ、信用を失うのではないかと不安で、踏み出せない。結論を先に書くと、**稼働が合わなくなること自体は、副業では普通に起きます。依頼側が困るのは、稼働が減ることではなく、減ることを知らされないまま作業が遅れることです。「先に伝える」「範囲を絞る」「時期を区切る」「戻す見込みを示す」の四つで調整すれば、多くの案件は続き、続かなくても関係は保てます。**やめるのは最後の選択肢で、その前に調整の余地があります。本業が忙しいときの具体的な伝え方は[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/)に、遅れそうなときの連絡は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、契約の途中で終える場合は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)にまとめています。契約の解釈は、専門家にご確認ください。

## 稼働が合わなくなる場面

稼働が合わなくなる原因は、いくつかの型に分かれます。型で、調整の仕方が変わります。

| 場面 | 起きること | 続く期間 |
|---|---|---|
| 本業の繁忙期 | 決算、大きな案件、年度の切り替えで、副業の枠が消える | 数週間から数か月。毎年同じ時期に来ることが多い |
| 本業の異動や昇進 | 業務が変わり、慣れるまで副業の枠が取れない | 数か月。落ち着けば戻ることが多い |
| 家庭の事情 | 育児、介護、家族の体調 | 予測しにくい。長引くこともある |
| 自分の体調 | 数日から数週間、動けない | 短期のことが多いが、繰り返すなら根本の見直しが要る |
| 副業の案件の山が重なった | 複数の案件で、面接や内定の時期が重なる | 数週間。案件の数の問題 |
| 見積もりの甘さ | 受けた範囲が、自分の枠より大きかった | 直さない限り続く。範囲の問題 |

場面の要点は、「毎年同じ時期に来る繁忙期は、予測できる」ことです。予測できるものは、契約のときに「〇月は稼働が下がる」と伝えておけば、その時期が来ても調整ではなく予定になります。予測できない家庭の事情や体調は、起きた時点で先に伝えます。本業の繁忙期を織り込んだ枠の決め方は[稼働時間の上限](/media/fukugyo-kadou-jikan/)に書いています。

## 依頼側が困るのは、稼働の減少ではない

依頼側の担当者が「困る」と感じる場面を見ると、稼働の減少そのものではないことが分かります。

| 状況 | 依頼側の担当者の受け取り方 |
|---|---|
| 「来月は稼働を半分にしたい」と一か月前に言われた | 「分かりました。優先を決めましょう」。困らない |
| 何も言われず、返信が遅くなり、作業が止まった | 「どうなっているのか」。困る。信頼が下がる |
| 「今週は動けません。来週から再開します」と当日に言われた | 「了解です」。困らない。候補者への対応だけ確認する |
| 期限を過ぎてから「実は忙しくて」と言われた | 「なぜ早く言わなかったのか」。困る。次の約束が信じられなくなる |
| 「三か月ほど休止したい。〇月に戻れる見込み」と言われた | 「では〇月まで社内で回します」。困らない。戻る見込みがあれば待つ |
| 「もう無理なので辞めます」と突然言われた | 「引き継ぎはどうなるのか」。困る。関係が切れる |

受け取り方の要点は、「先に言われれば困らず、後で分かれば困る」ことです。稼働が半分になっても、休止しても、先に伝えて優先を決めれば、担当者は社内で調整できます。伝えずに遅れると、担当者は社内で説明できず、外部の担当者を信じられなくなります。担当者の社内の立場は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「稼働が減ったら、依頼側に見限られる」というものです。実際には、依頼側の担当者は、外部の担当者が副業であることを知っていて、本業の都合で稼働が変わることを想定しています。担当者が見限るのは、稼働が減った人ではなく、減ることを伝えずに遅れた人です。「来月は稼働を下げたい」と先に言った担当者が、それを理由に契約を切られた例は、見ている限りほとんどありません。

見ていて差がつくのは、稼働が減るときに「範囲を絞る提案」を添えているかです。「稼働が減ります」だけでは、担当者は何を諦めればよいか分かりません。「稼働が減るので、候補者への返信と日程調整は維持し、スカウトの新規の送信は来月まで止めたい」と言えば、担当者は社内に「新規の送信を一時止める」と伝えられ、採用の予定を調整できます。エラベルでは、担当者の稼働が変わるとき、依頼側より先に窓口に伝えてもらい、窓口が依頼側と範囲と時期を調整する形も取っています。稼働の調整は、担当者一人で抱えず、窓口と依頼側と一緒に行うものです。

## 調整の四つの手順

稼働が合わなくなったら、四つの手順で調整します。順番を守ると、依頼側は困りません。

| 手順 | 内容 | 要点 |
|---|---|---|
| 一、先に伝える | 稼働が減ると分かった時点で、依頼側に伝える。確定前でも「可能性がある」と予告する | 遅れてから謝るのではなく、遅れる前に伝える。[遅れそうなときの連絡](/media/fukugyo-okure-renraku/) |
| 二、範囲を絞る | 減った稼働で維持するものと、止めるものを分けて提案する。候補者に関わるものを優先して維持する | 「全部を薄く」ではなく「一部を止めて残りは維持」 |
| 三、時期を区切る | 「〇月まで」「〇週間」と、稼働が減る期間を示す。分からなければ「〇日に改めて見込みを伝える」 | 期間が無いと、依頼側は「いつまで続くのか」で不安になる |
| 四、戻す見込みを示す | 「〇月から元の稼働に戻る見込み」と、戻る形を示す。戻れない可能性があるなら、それも言う | 戻る見込みがあれば、依頼側は待つ判断ができる |

四つの要点は、「二」の範囲を絞るときに、候補者に関わるものを維持することです。候補者への返信や日程調整が止まると、候補者が離れ、依頼側の採用に戻せない損が出ます。スカウトの新規の送信や、記録の整理や、型の改良は、止めても後で戻せます。減った稼働は、候補者に関わる工程に集中させます。工程の優先の付け方は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に書いています。

## 稼働が合わなくなる前に契約で決めておくこと

稼働の調整は、契約のときに決めておくと、起きたときに慌てません。

| 決めておくこと | 内容 |
|---|---|
| 本業の繁忙期 | 「〇月と〇月は本業の都合で稼働が下がります」と、契約の前に伝える。契約書か覚書に入れるかは依頼側と相談 |
| 稼働が下がるときの連絡の期限 | 「稼働が変わる場合は、〇週間前までにお伝えします」 |
| 稼働が下がるときに維持する工程 | 「稼働が減っても、候補者への返信と日程調整は維持します」 |
| 休止の扱い | 「〇か月以上稼働できない場合は、休止か終了かをご相談します」 |
| 契約の途中で終える場合の期間 | 契約書の終了の条項。何日前に伝えれば終えられるか。[契約期間の目安](/media/fukugyo-keiyaku-kikan/) |
| 最後の請求の扱い | 途中で終える場合、終了日までの稼働をどう請求するか。[請求のタイミング](/media/fukugyo-seikyuu-timing/) |

決めておく要点は、「本業の繁忙期を契約の前に伝える」ことです。伝えておけば、繁忙期が来たときの稼働の減少は、調整ではなく「契約のときに言っていた通り」になります。依頼側も、その時期に社内で回す準備ができます。契約の前に伝える項目は[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)に整理しています。契約書への書き方は、専門家にご確認ください。

## 休止と終了の違い

稼働が長く取れないとき、「休止」と「終了」は別のものです。違いを知って選びます。

| 項目 | 休止 | 終了 |
|---|---|---|
| 契約 | 契約は残し、稼働を止める。または一度終えて、再開の約束をする | 契約を終える |
| 依頼側の側 | その間、社内で回すか、別の担当者で補う。戻る前提で型と記録を保つ | 引き継ぎを受け、次の担当者を探す |
| 戻る形 | 「〇月に戻る」と決めた時期に、同じ範囲で再開する | 再開するなら、新しい契約として |
| 向く場面 | 数か月で戻る見込みがある。依頼側が待てる。型と記録が依頼側に残っている | 戻る見込みが無い。依頼側が待てない。戻っても同じ範囲は受けられない |
| 依頼側との合意 | 休止の期間、その間の連絡の有無、戻るときの条件を文面で | 終了日、引き継ぎ、最後の請求を文面で |
| 報酬 | 休止中は無い。契約の形によっては最低の稼働が定められていることがあり、確認が要る | 終了日までの稼働分 |

違いの要点は、「戻る見込みがあり、依頼側が待てるなら休止」です。休止は、依頼側にとっても、次の担当者を探す手間が無く、型と記録が保たれるので、待てる範囲なら休止を選ぶ依頼側は多いです。休止の間、依頼側の社内で回す形にするには、自分が止まっても回る状態が要ります。その状態の作り方は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。休止中の契約の扱いは、契約書と依頼側の合意によるので、専門家にご確認ください。

## 戻すときの形

稼働を減らしたり休止したりした後、戻すときにも形があります。戻し方を間違えると、戻った後に再び合わなくなります。

| やること | 内容 |
|---|---|
| 戻る時期を先に伝える | 「〇月から戻ります」と、戻る数週間前に伝える。依頼側が社内の分担を戻す準備をする |
| 前より小さく戻す | 減らす前の稼働に一度に戻さず、まず維持していた工程に一つ足す形で。様子を見て広げる |
| 戻った最初の月は密に報告する | 依頼側が「戻った」と実感できるように、進捗の報告を密にする。[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/) |
| 減った原因を直してから戻す | 本業の繁忙期なら、次の繁忙期の時期を契約に入れる。範囲の問題なら、範囲を絞ったまま戻す |
| 休止中の依頼側の変化を確認する | 担当者の交代、採用の方針の変更、ツールの変更。休止前と同じ前提で始めない |
| 戻れない場合は早く伝える | 戻る見込みで休止したが戻れないと分かったら、分かった時点で伝え、終了の手順に入る |

戻す要点は、「前より小さく戻す」ことです。減らす前の稼働に一度に戻すと、減らした原因（繁忙期、家庭の事情）が完全に解消していない場合、再び合わなくなります。維持していた工程に一つずつ足していけば、合わなくなる兆しが早く見え、再び減らすときの調整も小さく済みます。止まった後の再開の考え方は[続かない人の共通点](/media/fukugyo-tsuzukanai/)にも書いています。

### エラベルの見解

担当する側から見ると、稼働が合わなくなっても案件が続いている人は、稼働が減らない人ではなく、減るときに先に伝え、範囲を絞り、時期を区切り、戻す見込みを示している人です。依頼側の担当者は、その四つがあれば社内で調整でき、外部の担当者を「稼働が変わっても信頼できる人」として扱います。続かない人は、稼働が減ったこと自体ではなく、伝えずに遅れたことで、信頼を失っています。

順番として、契約のときに本業の繁忙期と稼働が変わるときの連絡の期限を伝え、減ると分かった時点で先に伝え、候補者に関わる工程を維持して残りを止め、時期を区切り、戻す見込みを示す。長く取れないなら、戻る見込みと依頼側の待てる範囲で休止か終了を選び、戻すときは前より小さく戻す。この順番で、稼働が合わなくなることは、副業の終わりではなく、調整の一場面になります。エラベルでは、担当者の稼働が変わるとき、窓口が依頼側との間で範囲と時期を調整する形を取っていて、担当者が一人で依頼側に伝えるより、双方の負担が小さくなっています。稼働の変化は、隠すものではなく、仕組みで支えて調整するものです。

## まとめ

- 稼働が合わなくなることは**普通に起きる**。依頼側が困るのは稼働の減少ではなく、**伝えられないまま遅れること**
- 調整は**先に伝える→範囲を絞る（候補者に関わる工程を維持）→時期を区切る→戻す見込みを示す**の四つ
- 契約のときに**本業の繁忙期・連絡の期限・維持する工程・休止の扱い・途中で終える期間・最後の請求**を決めておく
- **戻る見込みがあり依頼側が待てるなら休止、無ければ終了**。休止には、自分が止まっても回る状態が要る
- 戻すときは**時期を先に伝え、前より小さく戻し、最初の月は密に報告し、減った原因を直してから**
- やめるのは**最後の選択肢**。その前に、範囲・時期・休止の調整がある

## よくある質問

### 稼働が合わなくなったら、契約を切られて損害を請求されませんか

契約書の終了の条項に沿って、決められた期間の前に伝えて終えれば、一般に、稼働が取れなくなったこと自体で損害を求められることは多くないと整理されています。問題になるのは、伝えずに作業を放置して依頼側に損が出た場合や、契約の期間を守らずに突然止めた場合です。先に伝え、引き継ぎを整えて終えれば、関係は保てます。契約書の終了と損害の条項は、契約の前に読み、分からなければ専門家にご確認ください。

### 家庭の事情で、いつ戻れるか分かりません。休止と終了のどちらを選ぶべきですか

戻る時期が分からない場合、依頼側に「見込みが立たない」と正直に伝え、依頼側が待てるかを聞きます。待てるなら「〇か月後に改めて見込みを伝える」という形の休止、待てないなら終了です。自分で「戻れるはず」と決めて休止を選び、結局戻れないと、依頼側は待った分だけ困ります。分からないことは分からないと伝え、判断を依頼側と一緒にするほうが、関係は保てます。家庭の事情との両立は[介護や育児と両立する](/media/fukugyo-kaigo-ikuji/)にも書いています。

### 稼働を減らす連絡をしたら、依頼側から「それなら別の人に頼む」と言われました

依頼側の判断として受け入れ、引き継ぎを整えて終えます。稼働を減らす連絡を先にしたことで、依頼側は次の担当者を探す時間を持て、自分は引き継ぎを整えて終えられます。伝えずに遅れて切られる場合と比べ、関係は保たれ、稼働が戻ったときに別の案件で声がかかることもあります。終えるときの手順は[引き継ぎの進め方](/media/fukugyo-hikitsugi/)に、終えた後の入口は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に整理しています。
