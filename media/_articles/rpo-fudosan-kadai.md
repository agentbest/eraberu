不動産業界の会社が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。営業の報酬の形を先に出さず、面接で辞退される。営業の早期離職が多く、採用の入口だけを直して繰り返している。資格の扱いが整理されておらず、採っても担える業務が限られる。店舗ごとに面接の基準がばらばらで、店長の枠が取れない。会社の型で経路が違うのに、一つの媒体で募集している。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**不動産業界の採用課題は、報酬の形・早期離職・資格・店舗・経路の五つに分解し、自社の記録（辞退の理由、早期離職の時期と理由、担える業務が限られた件数、店舗ごとの日数と基準、型ごとの応募の数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、媒体と紹介会社を増やして採り、早期に離れて、また募集する、という往復になります。代行に出す工程の切り分けは[不動産業界の採用代行](/media/rpo-fudosan-rpo/)に、営業の早期離職は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。ここでは、不動産業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 報酬の形 | 面接や内定の段階で「報酬の形が思っていたのと違う」と辞退 | 辞退の理由が「報酬」「条件」 |
| 早期離職 | 採っても数か月で離れ、また募集 | 早期離職の時期と理由。募集の回数 |
| 資格 | 採ったが、資格の関係で担える業務が限られる | 担える業務が限られた件数。要件に資格の区分が無い |
| 店舗 | 店舗によって通過の基準が違う。店長の面接の枠が取れず日程が延びる | 店舗ごとの段階の日数と通過の記録の差 |
| 経路 | 売買の営業は来るが管理が来ない（またはその逆） | 型ごとの応募の数と経路 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 早期離職の時期と理由、募集の回数 | 繰り返していれば早期離職。採用の入口より先に |
| 二 | 辞退の理由 | 「報酬」「条件」なら報酬の形 |
| 三 | 要件に資格の区分があるか。担える業務が限られた件数 | 無ければ資格 |
| 四 | 店舗ごとの日数と通過の記録 | 差が大きければ店舗 |
| 五 | 型ごとの応募の数と経路 | 偏りがあれば経路 |

一が最初なのは、早期離職を止めずに採用の入口を直しても、穴を埋め続けることになるからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

不動産業界で最も多い詰まりは「早期離職」で、しかもそれが採用の課題として扱われていないことです。「営業は辞めるもの」と諦め、辞めた分を採り続ける。採用の費用は出続け、店舗は常に教える負担を抱えます。退職面談で理由を集め、「報酬の形が聞いていたのと違う」「教える人がいなかった」「ノルマの実態が求人票に無かった」に分けると、直す場所は採用の入口ではなく、求人票の実態と受け入れの体制です。エラベルで担当者を選ぶ企業には、「直近で辞めた営業の理由を、報酬・受け入れ・実態のどれかで分けていますか」を、私たちから先に聞いています。分けていなければ、代行の前に退職面談の記録からです。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

## 報酬の形の課題：先に出していない

| 先に出していないこと | 起きること | 直し方 |
|---|---|---|
| 固定と成果の比率 | 面接で「思っていたのと違う」 | 求人票と初回の連絡に、形と考え方を。額ではなく形 |
| 成果の計算の考え方 | 内定後に辞退 | 考え方（何が成果に数えられるか）を実態で |
| 報酬の形で変わる候補者の層 | 両方の層が混ざり、面接でずれる | 形に合わせて、経路と文面と面接の観点を分ける |

報酬の形を先に出すかは会社の判断で、表示の文言には法令上の整理があると一般に整理されているため、専門家の確認を経た内容にします。個別の判断は専門家にご確認ください。条件の出し方の考え方は[スカウト段階で条件を出すか](/media/scout-kyuuyo-teiji/)に書いています。

## 早期離職の課題：入口だけを直している

| 離職の理由 | 直す場所 |
|---|---|
| 報酬の形が聞いていたのと違う | 求人票と初回の連絡に、形と考え方を実態で |
| 教える人がいなかった | 受け入れの体制（最初の三か月の到達点、教える人）。店舗ごとに |
| ノルマや働き方の実態が求人票に無かった | 求人票に実態を |
| 店長との関係 | 1on1の型、店長の面接の観点 |
| 私的な事情 | 直す場所は無い。上の四つを確かめた後 |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 資格の課題：扱いが整理されていない

| 状態 | 直し方 |
|---|---|
| 「資格があれば尚可」だけで募集 | 会社と専門家で、担える業務と配置の関係を整理し、「必須・取得の支援・歓迎」の区分に |
| 採ってから担える業務が分かる | 書類の一次確認で資格の有無を照合し、区分で分ける |
| 取得の支援の中身が無い | 若手を採るなら、支援の中身（費用の扱い、時間、取れなかった場合）を決め、求人票に |

資格と業務の関係は、法令上の整理があると一般に整理されているため、会社と専門家（行政書士・社労士等）で整理します。代行は照合まで。個別の判断は専門家にご確認ください。

### エラベルの見解

不動産業界で見落とされやすいのは「店舗」の課題です。店舗ごとに店長が面接し、基準も記録もばらばらで、店舗をまたいで比べられず、店長が替わると基準が変わる。店長の面接の枠は接客の時間と重なり、日程が延びる。直すのは、「決めるのは店長、観点と記録の形は一つ」に分け、店長に一枚（この役割に期待すること、確かめる項目、記録の欄）を渡すことと、店長の枠を週に一つ、接客の少ない時間帯で先に預かることです。エラベルで担当者を選ぶ企業には、「店舗ごとの面接の観点と記録の形は、一つに揃っていますか」を、私たちから先に聞いています。揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

## 店舗の課題：基準と枠がばらばら

| 状態 | 直し方 |
|---|---|
| 店舗ごとに基準が違う | 観点と記録の形を一つに。決めるのは店長 |
| 店長の枠が接客と重なる | 接客の少ない時間帯で週に一枠を先に預かる |
| 店舗ごとに記録が別 | 一つの一覧に「店舗」の列を置く |
| 店長が替わると基準が変わる | 一枚が店舗に残る形に |

## 経路の課題：型で違う

| 会社の型・職種 | 合う経路 |
|---|---|
| 売買仲介の営業 | スカウト型の媒体、掲載型 |
| 賃貸仲介の営業 | 掲載型、地域の経路 |
| 管理 | 掲載型、紹介会社 |
| 開発・投資 | 紹介会社、スカウト（対象が少ない） |
| 事務 | 掲載型 |

型ごとに経路を分け、型ごとに応募の数を記録します。経路の考え方は[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 報酬の形 | 形に合わせた経路と文面 | 形の判断。表示の文言（専門家と） |
| 早期離職 | 退職面談の型、記録の分類 | 求人票の実態、受け入れの体制 |
| 資格 | 書類での有無の照合 | 区分の整理（会社と専門家） |
| 店舗 | 日程の運用、一覧の統合 | 観点と記録の形を一つに。店長の枠 |
| 経路 | 型ごとの経路の運用 | 型と経路の判断 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[不動産業界で採用代行が機能する条件・機能しない条件](/media/rpo-fudosan-jirei/)に書いています。

## まとめ

- 「採れない」には**報酬の形・早期離職・資格・店舗・経路**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は早期離職の時期と理由と募集の回数
- 最も多い詰まりは**早期離職**で、採用の課題として扱われていない。入口の前に、求人票の実態と受け入れ
- 報酬の形は**先に出す**かを会社が判断。表示の文言は専門家に。個別の判断は専門家にご確認ください
- 資格は**会社と専門家で区分を整理**してから採る
- 店舗は**「決めるのは店長、観点と記録は一つ」**。店長の枠を接客の少ない時間帯で週に一つ
- 経路は**会社の型と職種で分ける**

## よくある質問

### 営業の離職が多いのは業界の構造で、直せないのではないですか

同じ業界で定着している会社はあります。違いは、報酬の形を先に出しているか、受け入れの体制があるか、実態を求人票に書いているか、店長との接点があるか、です。「業界の構造」にすると、直す場所が消えます。退職面談で理由を分け、一つずつ直しても離職が減らないなら、報酬の形そのものの判断に進みますが、それは四つを確かめた後です。

### 店長が「面接は自分の勘でやる。一枚は要らない」と言います

決めるのは店長のままで、観点と記録の形だけを揃えます。「店長の勘」を否定するのではなく、「なぜ通したかを後で説明できるように、事実を一行書いてください」と、記録の形だけを頼みます。記録があれば、店舗をまたいで比べられ、早期離職の理由を面接の記録に戻せます。店長が替わったときに基準が残ることも、店舗にとっての利益です。

### 未経験を採って、資格を取ってもらいながら育てたいです

資格の無い間に担える業務と、取得の支援の中身（費用の扱い、時間の確保、取れなかった場合の扱い）を、会社と専門家で先に決めます。受け入れの体制（教える人、最初の三か月の到達点）も先に。決めずに「入社後に取ってください」で採ると、担える業務が無いか、支援の話で揉め、早期に離れます。要件と求人票には区分（必須・取得の支援・歓迎）を同じ形で書きます。個別の判断は専門家にご確認ください。
