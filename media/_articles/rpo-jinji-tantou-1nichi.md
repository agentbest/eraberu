採用担当が「忙しくて回らない」と言う。応募への返信は遅れ、面接の日程は組めず、求人票は古いまま。責任者は「何にそんなに時間がかかっているのか」と思うが、担当者も「全部」としか言えない。増員すべきか、外注すべきか、判断できない。結論を先に書くと、**「忙しい」は、分解しなければ判断できません。採用担当の一日を、工程ごとの時間に分解すれば、「何に、どれだけ」が見え、「減らす工程」「外に出す工程」「残す工程」が決まります。分解した結果、増員が要るのか、外注で足りるのか、運用を直せば済むのかが、根拠を持って分かります**。人事が一人で回らない場合は[人事が一人で回らない](/media/rpo-jinji-hitori-kadai/)に、外注の線は[どこまで外注してよいか分からない](/media/rpo-gaichu-hanni/)にまとめています。

## 業務量が見えない構造

採用担当の業務量が見えないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「忙しい」の一言で終わっている | 何に、どれだけ時間を使っているかを、担当者も責任者も知らない |
| 記録していない | 一日の時間の使い方を、記録したことが無い |
| 工程に分けていない | 「採用」を一つの塊として見ていて、工程ごとの時間が無い |
| 割り込みが多く、見えない | 応募の通知、面接官からの連絡、候補者からの問い合わせ。細切れの対応が、合計で大きい |
| 「判断」と「作業」が混ざっている | 判断に使う時間と、作業に使う時間が分かれていない |
| 兼務なら、本業と混ざっている | 採用に使った時間が、本業の時間と区別されていない |
| 増員か外注かの判断に、根拠が無い | 「忙しいから増員」「忙しいから外注」を、分解せずに決めようとしている |
| 担当者が「忙しい」と言いにくい | 「忙しい＝能力が無い」と思われる不安で、言わない |

構造の大半は、「記録していない」ことです。一週間記録すれば、見えます。

## 一日を分解する手順

採用担当の一日を、分解する手順です。

**一週間、時間の使い方を記録する。** 三十分単位で、「何をしたか」を書く。「応募の確認と返信」「日程調整」「面接の同席」「求人票の修正」「面接官との連絡」「候補者からの問い合わせ」「媒体の管理」「記録の更新」「責任者への報告」「その他」。割り込みも、その都度。

**工程ごとに、合計する。** 一週間の合計を、工程ごとに。「応募の確認と返信：六時間」「日程調整：五時間」「面接の同席：八時間」…。

**工程ごとに、「判断」「材料」「作業」に分ける。** 応募の返信は作業、書類の判断は判断、求人票の案は材料。[どこまで外注してよいか分からない](/media/rpo-gaichu-hanni/)の三分割で。

**割り込みの時間を、別に数える。** 「候補者からの問い合わせ」「面接官からの連絡」「責任者からの確認」。割り込みは、細切れで合計が大きく、集中を切ります。

**兼務なら、採用と本業を分ける。** 採用に使った時間だけを合計。

**一枚にまとめる。** 工程、時間、判断・材料・作業の区分、割り込みの時間。

分解の要点は、「一週間、三十分単位で記録する」ことです。記憶で振り返ると、大きな仕事（面接）が過大に、細切れの仕事（返信、問い合わせ）が過小に見えます。記録すれば、細切れの合計が大きいことが見えます。

## 工程ごとの時間の目安

分解した結果を、工程ごとに見ます。一般的な傾向であり、自社の記録で確かめます。

| 工程 | 区分 | 時間が大きくなりやすい理由 | 減らす・出す余地 |
|---|---|---|---|
| 応募の確認と返信 | 作業 | 媒体が複数で、管理画面を回る。一件ずつ文面を考える | 窓口を一つに、文面を型に、自動返信、担当者に出す |
| 書類の判断 | 判断 | 基準が無く、一件ずつ迷う | 基準を書面に。一次の絞り込みは作業として出す |
| 日程調整 | 作業 | 候補者と面接官の間で往復する | 枠を先に押さえる、予約制、担当者に出す |
| 面接の同席 | 作業（進行） | 全部の面接に人事が出る | 同席をやめる。面接官に一枚を渡す |
| 面接の判定の取りまとめ | 材料 | 面接官の判定がメールで来て、転記する | 判定の型を面接官に。直後に五分で書く |
| 求人票の修正 | 材料 | 現場との読み合わせが無く、机上で直す | 型を持つ。現場と三十分で |
| 媒体の管理 | 作業 | 媒体が多い | 媒体を絞る。担当者に出す |
| 面接官との連絡 | 作業 | 判定の催促、日程の確認 | 期限を決める。催促を担当者に |
| 候補者からの問い合わせ | 作業（割り込み） | 案内に情報が足りず、聞かれる | 案内に場所・形式・面接官・期限を入れる |
| 紹介会社との連絡 | 作業 | 会社が多い | 絞る。窓口を一つに |
| 記録の更新 | 作業 | 表が複数、更新が溜まる | 表を一つに。その日に更新 |
| 責任者への報告 | 材料 | 数字を毎回集計する | 月次の一枚の型 |
| 内定の条件の調整 | 判断＋作業 | 決裁の往復 | 余地を事前に決める |
| 受け入れの準備 | 作業 | 機器、アカウント、案内 | 手順を型に。担当者に出す |

目安の要点は、「作業の合計が、判断の合計より大きい」ことが多い、ということです。作業に埋もれて、判断の時間が無い。分解すると、「作業を減らす・出す」で、判断の時間が生まれます。

## 分解した後の三つの判断

分解した一枚から、三つの判断をします。

**一、減らす工程。** 運用を変えれば、時間そのものが減る工程。窓口を一つに、文面を型に、枠を先に押さえる、同席をやめる、媒体を絞る、案内に情報を入れる。費用ゼロで、今週から。

**二、外に出す工程。** 減らしても残る「作業」を、担当者（採用代行）か、社内の別の人（庶務、現場）か、道具（自動返信、予約制、ATS）に出す。

**三、残す工程。** 「判断」と「材料の一部」。書類と面接の判定、要件と条件の決定、責任者への報告、面接官の指名。採用担当の時間を、ここに集中する。

三つの判断の後、「残す工程」の時間が、採用担当の時間に収まるかを見ます。収まれば、増員も外注も要らず、運用の見直しで済みます。収まらなければ、「出す工程」を増やすか（外注）、「残す工程」を分担するか（増員）を、根拠を持って判断します。

| 分解の結果 | 判断 |
|---|---|
| 減らすと出すで、残す工程が担当者の時間に収まる | 運用の見直しで済む。増員も外注も要らない |
| 減らしても、作業が多く残る | 作業を外に出す（採用代行、道具、社内の別の人） |
| 作業を出しても、判断の工程が多すぎる | 判断を分担する人が要る（増員、または現場に判断の一部を） |
| 兼務で、採用に使える時間が週に数時間しか無い | 判断だけを残し、材料と作業の大半を出す |

判断の要点は、「増員か外注か」を分解の結果で決めることです。分解せずに決めると、増員しても作業に埋もれ、外注しても判断が止まります。

### エラベルの見解

相談で最も多い失敗は、「採用担当が『忙しい』と言うので、人事をもう一人採ったが、二人とも応募の返信と日程調整に埋もれて、判断の時間は増えなかった」というものです。分解せずに増員しました。一週間記録すると、作業が七割、判断が二割、割り込みが一割。作業を型と道具と担当者に出したら、一人で判断に集中でき、二人目は要りませんでした。「忙しい」の中身は、増員で解決する種類のものではなかったのです。

見ていて差がつくのは、担当者が「まず一週間記録しましょう」と言うかどうかです。「忙しいなら、こちらで作業を引き受けます」と即座に言う担当者と、「まず一週間、三十分単位で記録して、工程ごとに分けましょう。減らせる工程と出す工程と残す工程を決めてから、こちらが引き受ける範囲を決めます」と、分解から入る担当者がいます。後者は、要らない外注をしません。

発注側にできるのは、「忙しい」と聞いたら、増員も外注も決める前に、「一週間、記録してほしい」と頼むことです。

## 減らす工程

分解の結果、運用を変えれば減る工程です。費用ゼロで、今週から。

| 工程 | 減らし方 |
|---|---|
| 応募の確認 | 全媒体の通知を一つの受信先に。毎朝十分で全部を確認。媒体を絞る |
| 返信 | 文面の型（受付、案内、結果、内定、不合格）。名前と職種を差し替えるだけに。自動返信の併用 |
| 日程調整 | 面接官の枠を、週に二枠、先に押さえる。候補者には枠を提示。予約制の道具 |
| 面接の同席 | 人事の同席をやめる。面接官に、観点と質問と記録の型の一枚を渡す |
| 判定の取りまとめ | 面接官が直後に五分で、型に沿って記録。人事が転記しない |
| 候補者からの問い合わせ | 案内に、場所・形式・面接官・所要時間・結果の期限を入れる。問い合わせが減る |
| 面接官への催促 | 判定の期限（直後）を決まりに。催促の回数が減る |
| 記録の更新 | 表を一つに。その日に更新。溜めない |
| 責任者への報告 | 月次の一枚の型。毎回集計しない |
| 紹介会社との連絡 | 会社を絞る。窓口を一つに。連絡の文面を型に |

減らす工程の要点は、「型と窓口と枠」です。一件ずつ考える、複数の場所を回る、往復する、を無くせば、作業の時間は半分以下になることがあります。

## 出す工程と残す工程

減らした後、外に出す工程と、残す工程です。

| 出す工程（作業と材料の一部） | 出す先 |
|---|---|
| 応募の受付と返信、表の更新 | 採用代行の担当者、自動返信、社内の庶務 |
| 日程調整と案内 | 担当者、予約制の道具 |
| 書類の一次の絞り込み（基準に沿って） | 担当者 |
| 面接の記録の整理、結果の連絡 | 担当者 |
| 媒体の管理、紹介会社との連絡 | 担当者 |
| 求人票の案、観点の案、報告の一枚 | 担当者（材料。社内が決める） |
| 受け入れの準備の手配 | 担当者、社内の庶務 |

| 残す工程（判断） | 担当者 |
|---|---|
| 役割と要件の決定 | 責任者と現場 |
| 書類と面接の判定 | 採用担当と面接官 |
| 条件の決定、上げられる余地 | 責任者 |
| 面接官の指名 | 責任者 |
| 内定を出すか | 責任者と採用担当 |
| 責任者への報告と判断の依頼 | 採用担当 |
| 現場と経営者との調整 | 採用担当 |

出す工程と残す工程の要点は、「残す工程が、判断だけになっているか」です。作業が残っていれば、まだ出せます。判断が出ていれば、社内に残りません。

出す先は、採用代行だけではありません。道具（自動返信、予約制、ATS）、社内の別の人（庶務、現場）も、出す先です。

## 分解を続ける運用

一度分解して終わりにせず、続けます。

**三か月に一度、一週間の記録を取る。** 運用を変えた後、時間がどう変わったかを見る。

**「残す工程」の時間が、収まっているかを見る。** 収まっていなければ、まだ減らせる工程、出せる工程がある。

**割り込みの時間を、見る。** 割り込みが増えていれば、案内や期限の運用が緩んでいる。

**採用の量が変わったら、分解し直す。** 求人が増えた、繁忙期、急な増員。量が変われば、線も変わる。

**採用担当に、「忙しい」を言いやすくする。** 「忙しい＝能力が無い」ではなく、「忙しい＝分解する材料」と、責任者が示す。

**分解の一枚を、責任者と共有する。** 「採用担当の時間は、こう使われている」。責任者が知れば、増員や外注や運用の判断ができる。

**運用の変更の効果を、記録する。** 「文面を型にしたら、返信の時間が週に六時間から二時間に」。

運用の要点は、「三か月に一度、一週間」です。毎日記録し続ける必要はなく、定期的に一週間記録すれば、変化が見えます。

## 外注する場合の範囲

採用担当の業務量の問題を、採用代行に出す場合の範囲です。

**出せる工程。** 一週間の記録の型の作成、記録の集計と工程ごとの分解、判断・材料・作業の区分、減らす工程の案と運用の変更（文面の型、窓口の一本化、枠の先押さえ、案内の中身、記録の型）、出す工程の引き受け（受付、返信、日程、絞り込み、記録、連絡、媒体と紹介会社の管理、材料の案）、残す工程の整理と時間の見積もり、増員か外注か運用かの判断の材料、三か月ごとの記録と見直し。

**社内に残す判断。** 減らす・出す・残すの決定、増員か外注か運用かの決定、判断の工程（要件、判定、条件、面接官、内定）、責任者への報告。

**外注の効きどころ。** 採用担当の「忙しい」は、分解すると「作業に埋もれている」ことが大半で、作業は担当者に出せます。担当者が分解を手伝い、減らす運用を持ち込み、出す工程を引き受ければ、採用担当は判断に集中できます。担当者は複数の会社の採用担当の時間の使い方を見ているので、「この工程は、この型で半分になる」の見立てを持ち込めます。分解した結果、外注が要らないと分かることもあり、それも正しい結果です。

**外注しても動かない場合。** 採用担当が記録を取らない、責任者が分解の一枚を見ない、「忙しいから増員」を分解せずに決める。社内の判断で、代行を替えても直りません。

「忙しい」は、分解すれば判断できます。外注は、分解と、出す工程を担う手段です。

### エラベルの見解

担当する側から見ると、業務量の相談で最も多いのは、「割り込みの時間が、見えていない」ことです。「面接の同席が多い」と担当者は言いますが、記録すると、面接の同席は週に八時間、候補者からの問い合わせと面接官からの連絡とその都度の応募の確認が、細切れで合計十時間。集中を切られ、判断の時間が無くなっていました。

割り込みは、案内に情報を入れ、期限を決め、確認の時間を固定すれば、大きく減ります。記録しなければ、割り込みは「忙しさ」の中に埋もれて見えません。

発注側にできるのは、採用担当に「割り込みも、その都度記録して」と頼むことです。

## よくある質問

### 採用担当が「忙しい」と言うので、増員すべきですか

増員の前に、一週間、三十分単位で記録し、工程ごとに分解します。「忙しい」の中身が「作業に埋もれている」なら、運用（文面の型、窓口の一本化、枠の先押さえ）と、作業を出す（担当者、道具、社内の別の人）ことで、増員なしで判断の時間が生まれます。分解した結果、「判断の工程が多すぎて一人では回らない」なら、増員か、判断の一部を現場に分担します。分解せずに増員すると、二人とも作業に埋もれます。

### 記録を取る時間すら無いと言われます

三十分単位で、一言メモするだけです。「応募確認」「日程」「面接」「問い合わせ」。一日で数分。一週間だけ。記録を取らないと、「忙しい」のまま、増員も外注も運用の見直しも、根拠を持って決められません。記録を取ること自体を、採用代行の担当者に頼む形（担当者が採用担当の一日を横で見て記録する）もあります。「記録する時間が無い」状態が、最も分解が要る状態です。

### 兼務なので、採用にどれだけ使っているか分かりません

一週間、採用に使った時間だけを記録します。本業の合間の細切れ（応募の確認、返信、日程の往復）が、合計で大きいことが見えます。兼務の場合、「採用に使える時間は週に何時間か」を先に決め、その中に「判断」だけを残し、材料と作業の大半を出す線にします。固定の時間の決め方は[他業務と兼務で採用が進まない](/media/rpo-kenmu/)に書いています。
