経営者に「採用はどうなっている」と聞かれて、「頑張っています」としか言えない。応募が何件来て、面接が何件で、内定が何件で、辞退が何件か。どの経路から来て、何日かかっているか。数字が無い。数字が無いので、媒体を足すか切るか、要件を変えるか、判断が感覚になる。結論を先に書くと、**採用の数字は、「分析」を目指すと大きくなり、始まりません。最初に取るのは四つ、応募・面接・内定・辞退の数を、経路ごとと日数で数えるだけです。四つが毎月取れれば、判断は感覚から記録に変わり、経営者にも説明できます。分析は、四つが半年溜まってからです**。応募者の表の作り方は[応募者管理がスプレッドシートのまま](/media/rpo-ats-nai/)に、経営者への報告は[経営者に採用の状況が伝わらない](/media/rpo-keieisha-rikai/)にまとめています。

## 数字が取れていない構造

採用の数字が取れていないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 記録する場所が無い | 応募者の表が無い、または媒体ごと・人ごとに分かれている。数えられない |
| 記録する項目が決まっていない | 経路、日付、段階、結果を記録していない。後から数えようとしても、無い |
| 「分析」を目指して、始まらない | 「採用のダッシュボードを作ろう」と大きく考え、項目が増え、着手できない |
| 数字を見る場が無い | 取っても、誰も見ない。見なければ、取る意味が無くなり、取らなくなる |
| 判断が、数字と結びついていない | 「媒体を足す」「要件を変える」を、数字ではなく感覚で決めている |
| 数字を取る担当がいない | 「人事が取る」と言うが、人事は応募の対応で手一杯 |
| 経営者が数字を求めていない | 「採れたか採れていないか」だけを聞き、途中の数字を問わない |

数字が無いことの問題は、「判断が感覚になる」ことです。感覚の判断は、当たることもありますが、外れたときに理由が分からず、次に活かせません。

## 最初に取る四つの数字

最初に取るのは、四つです。

| 数字 | 何を数えるか | 何のために |
|---|---|---|
| 応募 | 応募が来た数。経路ごと、求人ごと | 経路が効いているか。求人票が届いているか |
| 面接 | 書類を通って面接に進んだ数。段階ごと | 応募の質（要件に合う人が来ているか）。書類の判断の速さ |
| 内定 | 内定を出した数。承諾した数 | 面接の質。内定の承諾率 |
| 辞退 | 各段階で辞退した数と、理由 | どの段階で、なぜ離れているか |

四つを、「経路ごと」と「日数」で数えます。

**経路ごと。** 媒体A、媒体B、紹介会社、社員の紹介、直接。経路ごとに応募・面接・内定・辞退を並べれば、「どの経路から、面接に進む人が来ているか」が見えます。

**日数。** 応募から受付の返信まで、書類の判断まで、面接まで、内定まで。日数が、「待たせていないか」の指標です。

四つと経路と日数で、「どこで止まっているか」「どの経路が効いているか」「速さは足りているか」が分かります。それ以上の数字は、四つが溜まってからです。

## 数字を取る仕組み

四つを、毎月取れる仕組みです。

**応募者の表に、必要な列を持つ。** 応募日、経路、求人、段階、各段階の日付、結果、辞退の理由。表の列があれば、数えるだけです。列の型は[応募者管理がスプレッドシートのまま](/media/rpo-ats-nai/)に書いています。

**表を、その日に更新する。** 応募が来た日、判定が出た日、連絡した日。更新されていない表からは、正しい数字は出ません。

**月に一度、決まった日に数える。** 「毎月一日に、前月の分を数える」。担当者を決め、カレンダーに入れます。

**数える形を、一枚の型にする。** 経路×段階の表と、日数の平均と最長。毎月同じ形で出せば、比べられます。

**辞退の理由を、欠かさず聞いて記録する。** 辞退の連絡があったら、「差し支えなければ理由を」。「条件」「他社」「対応」「役割」のような分類で記録します。分類が無いと、集計できません。

**ATSを使っているなら、集計の機能で出す。** 手で数えなくても出せることがあります。機能はATSの公式の案内で確認します。ただし、表の更新が正しくなければ、ATSの集計も正しくありません。

**取れない数字は、無理に取らない。** 「求人票の閲覧数」「スカウトの開封率」など、媒体によっては取れないものがあります。取れるものだけ取ります。

仕組みの要点は、「表の更新」と「月に一度の定例」です。この二つが無いと、数字は取れません。

## 数字の読み方

四つの数字を、どう読むかです。

| 見るもの | 読み方 |
|---|---|
| 経路ごとの応募 | 多い経路が良い経路ではない。面接に進む数で見る |
| 経路ごとの面接に進む率 | 応募のうち面接に進んだ割合。率が低い経路は、要件に合わない人が来ている。求人票か経路の見直し |
| 段階ごとの通過 | 書類で落ちる、一次で落ちる、最終で落ちる。どこで落ちているかで、直す先が変わる |
| 内定の承諾率 | 内定を出したうち承諾した割合。低ければ、条件・速さ・訴求の問題 |
| 辞退の段階と理由 | 書類の後に辞退（対応の速さ）、面接の後に辞退（面接の印象）、内定の後に辞退（条件・他社）。理由の内訳で直す先が分かる |
| 日数 | 応募から返信、判断、面接、内定まで。三日、三日、一週間、三週間が目安。超えていれば、遅い |
| 月ごとの変化 | 先月と比べて、増えたか減ったか。変えたこと（求人票、媒体、速さ）の効果が見える |

読み方の要点は、「数字そのもの」ではなく、「どこで止まっているか」を読むことです。応募が少ないのか、面接に進まないのか、内定を辞退されるのか。止まっている段階が、直す先です。

一般の相場や他社の数字と比べません。自社の先月と比べます。数字を資料に載せる場合は、自社の記録の数字だけを使います。

### エラベルの見解

相談で最も多い失敗は、「採用のダッシュボードを作ろうと、二十項目の指標を設計し、半年経っても一つも取れていなかった」というものです。項目が多く、記録の列が無く、更新する人がいなかった。応募・面接・内定・辞退の四つを、経路と日数で、月に一度数える形に戻したら、翌月から数字が出て、「紹介会社Aからは面接に進む人がいない」「内定後の辞退の理由の大半が条件」が見え、判断が変わりました。四つで足ります。

見ていて差がつくのは、担当者が「毎月一日に、四つの数字を一枚で出す」を定例にするかどうかです。「数字はATSで見られます」と言うだけの担当者と、「毎月一日に、経路×段階の表と日数の一枚を出して、止まっている段階と直す先を添えます」と、定例にする担当者がいます。後者がいれば、数字は判断に使われます。

発注側にできるのは、担当者に「毎月一日に四つの数字を一枚で」を依頼し、その一枚を責任者が見る場を作ることです。

## 経営者への出し方

四つの数字を、経営者にどう出すかです。

**一枚に収める。** 経路×段階の表、日数、止まっている段階、直す先、決めてほしいこと。一枚で。

**数字だけでなく、読み方を添える。** 「応募二十件」ではなく、「応募二十件、先月の十件から増加。ただし面接に進んだのは二件で、要件に合わない応募が多い。求人票の要件の書き方を見直す」。

**止まっている段階を、先に言う。** 「いま止まっているのは、内定後の辞退です。三件中二件が条件を理由に辞退」。経営者が判断すべき場所が、先に分かります。

**先月との比較を、欠かさず入れる。** 「先月からこう変わった。変えたことは〇〇」。変化が見えれば、経営者は「効いている・いない」を判断できます。

**決めてほしいことを、数字に結びつける。** 「内定後の辞退の理由が条件なので、年収の上限を見直すかどうかを決めてほしい」。数字が根拠になります。

**取れない数字は、取れないと言う。** 「求人票の閲覧数は、この媒体では取れません」。無理に推測の数字を出さない。

経営者への報告の型は[経営者に採用の状況が伝わらない](/media/rpo-keieisha-rikai/)に書いています。四つの数字が、その報告の土台です。

## 数字で判断を変える運用

数字を取る目的は、判断を変えることです。運用です。

**月に一度、数字を見て、一つ変える。** 「紹介会社Aからは面接に進む人がいないので、求人の説明をやり直す」「書類の判断が五日かかっているので、三日に」。一つずつ。

**変えたことを、記録する。** 「〇月に、求人票の要件を変えた」。翌月の数字と照らせば、効果が分かります。

**三か月、同じ形で数字を取る。** 一か月では、たまたまの変動が大きい。三か月で傾向を見ます。

**効いていない経路を、切る判断の材料にする。** 「三か月、面接に進む人がゼロ」なら、切る候補。棚卸しは[媒体を増やしすぎて管理できない](/media/rpo-media-oosugi/)に書いています。

**辞退の理由の内訳で、直す先を決める。** 「対応」が多ければ速さと丁寧さ、「条件」が多ければ年収と見せ方、「役割」が多ければ求人票と面接での説明。

**数字が良くなったら、何が効いたかを記録する。** 「求人票の一行目を変えたら、面接に進む率が上がった」。次の求人に使えます。

**半年溜まったら、分析を足す。** 経路ごとの費用と内定の数、面接官ごとの通過率、段階間の一致。四つの数字が半年溜まれば、分析の材料になります。

運用の要点は、「一つ変える→翌月見る→記録する」の繰り返しです。数字を取るだけで、変えなければ、意味がありません。

## 外注する場合の範囲

採用の数字が取れていない問題を、採用代行に出す場合の範囲です。

**出せる工程。** 応募者の表の列の設計（数字が取れる形に）、表の毎日の更新、辞退の理由の聞き取りと分類の記録、月に一度の集計（経路×段階、日数）、一枚の作成（読み方、止まっている段階、直す先、決めてほしいこと）、責任者への報告の場の準備、変えたことの記録、三か月の傾向の整理、半年後の分析（経路ごとの費用対効果、面接官ごとの通過率など）。

**社内に残す判断。** 何を数えるかの決定、数字を見る場の設定、数字に基づく判断（媒体を切る、要件を変える、条件を見直す）、経営者への報告の受け止め。

**外注の効きどころ。** 数字が取れていない会社は、「表の更新」と「月に一度の集計」をする人がいません。担当者が表を毎日更新し、辞退の理由を聞き、月に一度一枚を出せば、数字は定例で出ます。担当者は複数の会社の数字を見ているので、「この段階で止まっているなら、直す先はここ」の見立ても持ち込めます。ただし、他社の数字を自社の判断の根拠にはしません。

**外注しても動かない場合。** 責任者が一枚を見ない、数字を見ても判断を変えない、面接官が判定を出さず表が更新できない。社内の判断で、代行を替えても直りません。

数字は、四つを毎月取れば、判断が変わります。外注は、取る人と出す定例を置く手段です。

### エラベルの見解

担当する側から見ると、数字の相談で最も多いのは、「数字を取っているが、見ていない」ことです。表はあり、月に一度集計もしている。ただ、集計した一枚を、誰も見る場が無い。人事のフォルダに溜まっているだけ。

数字を取る目的は、判断を変えることです。見る場（月に一度、責任者と三十分）が無ければ、取る意味がありません。場を作り、「今月は何を一つ変えるか」を決める。それで、数字は動き始めます。

発注側にできるのは、「数字を取ってほしい」に加えて、「毎月見る場を作る」ことです。場が無い数字は、取っても変わりません。

## よくある質問

### 採用のKPIを、何にすればよいですか

最初は、応募・面接・内定・辞退の四つを、経路ごとと日数で数えることから始めます。「KPI」として目標の数字を置く前に、実際の数字が取れている状態を作ります。四つが半年溜まれば、「面接に進む率をこのくらいに」「内定の承諾率をこのくらいに」と、自社の記録を元に目標を置けます。一般の相場を目標にすると、自社の実態と合いません。KPIの合意の仕方は[KPIの合意のしかた](/media/rpo-kpi-goui/)に書いています。

### 数字を取る時間がありません

応募者の表を、その日に更新する運用があれば、月に一度の集計は一時間で済みます。表が無い、または更新されていないなら、集計に時間がかかるのではなく、集計する元が無い状態です。先に表を一つにして、列を決め、更新の担当を置きます。更新の担当と集計を、採用代行の担当者に出す形もあります。「取る時間が無い」のではなく、「取る仕組みが無い」ことが多いです。

### 数字を経営者に出しても、反応がありません

数字だけを出していないかを確認します。「応募二十件、面接二件、内定ゼロ」だけでは、経営者は判断できません。「止まっているのは書類から面接の段階で、要件に合わない応募が多い。求人票の要件を変える。決めてほしいのは、要件の〇〇を歓迎に下げてよいか」と、読み方と直す先と決めてほしいことを添えます。数字は、判断の材料として出します。材料が無い数字は、読み流されます。
