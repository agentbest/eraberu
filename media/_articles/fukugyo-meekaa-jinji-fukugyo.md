メーカーの人事として、本社と工場と研究所という性質の違う職場の採用を担い、新卒を年間の計画で採り、技術職と技能職と事務職を分けて見て、制度の中で長く働く人を育ててきた。この経験は、人事の副業で売れるのか。メーカーの人事は、じっくり採って長く育てる形で動いており、速さを求める副業の依頼には合わないと感じる人が多いところです。結論を先に書くと、**メーカーの人事の経験は、「工場と本社と技術という性質の違う職場を、年間の計画と制度の中で、長く働く前提で採って育ててきた」型で売れます。売れるのは、「技術職と技能職と事務職を分けて採る型」「新卒と中途を年間の計画で回す設計」「工場の現場の管理者を採用に巻き込む型」「長く働く前提の要件と受け入れ」の四つです。人事の部門が小さい会社でも、職種によって採り方を変える必要があり、年間の計画で回したい採用があり、現場の管理者を巻き込めておらず、採ってもすぐ辞める詰まりを抱えています。「メーカーの人事でした」ではなく、「性質の違う職場を、計画と制度で、長く働く人を採る形にする」と売ります。**建設業の人事の経験は[建設業の人事が副業でできること](/media/fukugyo-kensetsu-jinji-fukugyo/)に、IT企業の人事の経験は[IT企業の人事が副業でできること](/media/fukugyo-it-jinji-fukugyo/)に、新卒採用の経験は[新卒採用担当が副業でできること](/media/fukugyo-shinsotsu-tantou-fukugyo/)にまとめています。

## この経歴の何が売れるか

メーカーの人事の経験を、業界の内外の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| メーカーの人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 技術職・技能職・事務職を、要件も経路も面接も分けて採ってきた | 職種の性質ごとに、要件の書き方・経路・面接の見る点・受け入れを分けて設計する | 全職種を同じ流れで採用し、職種ごとの詰まりが見えない依頼側が多い |
| 新卒を年間の計画で採り、中途を欠員と計画の両方で採ってきた | 年間の採用の計画（いつ、どの職種を、新卒か中途か）と、欠員の対応を分けて回す設計 | 採用が場当たりで、計画と欠員の区別がない依頼側が多い |
| 工場の現場の管理者（工場長、課長、班長）と一緒に採用を進めてきた | 現場の管理者が要件と面接と受け入れに関わる分担の設計 | 現場が採用に関わらず、人事だけで回している依頼側が多い |
| 長く働く前提で、要件と受け入れと育成を設計してきた | 「入って三年後にどうなっているか」から逆算した要件と、受け入れと育成の流れ | 採ってすぐ辞める依頼側が多い |
| 技術系の学校や大学との関係を作り、経路を持ってきた | 媒体以外の経路（学校、地域、社員の紹介）を持つ母集団の設計 | 媒体だけに頼り、応募が来ない依頼側が多い |
| 制度（等級、評価、報酬、異動）を運用しながら採用の条件を決めてきた | 採用の条件を、既存の社員の制度との整合で決める枠組み | 採用のたびに条件が例外になる依頼側が多い |
| 本社と工場の間で、人事の方針を伝え、現場の声を戻してきた | 経営と現場の間の翻訳（方針を現場の言葉に、現場の不満を経営の言葉に） | 経営と現場が噛み合わない依頼側が多い |

売れるものの要点は、「職種の性質を分けて、計画で回し、長く働く人を採る型」です。多くの会社の採用は、職種の性質に関わらず同じ流れで動き、計画がなく、採った後の育成が見えていません。メーカーの人事は、性質の違う職場を同時に見て、年間の計画で回し、長く働く前提で採ってきており、その型は、複数の職種を持ち、計画で回したく、辞めない人を採りたい会社にそのまま合います。「遅い」ように見える型は、「長く働く人を採る」ための型です。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

メーカーの人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 遅いと見られる | 「メーカーのじっくりした採用は、うちの速さに合わない」。自分にとっても、週単位の採用の経験が薄い不安 | 「長く働く人を採る」ための型として語り、期間は依頼側に合わせて縮める。「新卒で一年かけていた流れを、中途の一か月に圧縮するとこうなる」と示す |
| 自社の仕組みに寄りすぎ | 「大きいメーカーの制度と仕組みは、うちの規模には合わない」 | 仕組みをそのまま持ち込まず、「職種を分ける」「計画と欠員を分ける」「現場を巻き込む」の三つの型だけを、依頼側の規模に合わせて軽くする |
| スカウトの経験の薄さ | 「ダイレクトリクルーティングはできるのか」。応募と学校の経路が中心で、スカウトの経験が薄いことがある | スカウトの運用は範囲に入れないか、別の担当者と組む。売るのは「職種の分け方、計画、現場の巻き込み、長く働く設計」だと最初に分ける |

扱い方の要点は、「じっくりを『長く働く人を採る型』と言い換え、仕組みではなく三つの型だけを持ち込む」ことです。メーカーの人事の経験がある人は、自分の経験を「時間をかけて丁寧に」と語りがちで、それが速さを求める依頼側には「遅い」と聞こえます。「採ってすぐ辞めない人を採るために、職種を分けて、計画で回し、現場を巻き込んできた」と語れば、同じ経験が、採ってすぐ辞めて困っている依頼側に「今のうちに必要なもの」として伝わります。仕組みは持ち込まず、型だけを軽くして持ち込みます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、メーカーの人事から転身して続いている人と、面談で止まる人の差は、「じっくり」を語るか、「辞めない」を語るかです。止まる人は、メーカーの丁寧な採用と育成の流れを語り、依頼側の経営者は「うちはそんなに時間をかけられない」と感じて終わります。続いている人は、「最近辞めた人は、入って何か月でしたか」と聞き、依頼側が「半年もたなかった」と答えたところで、「それは、採るときに三年後を見ていないからです。要件と受け入れを、長く働く前提で作り直します」と返します。経営者は、速さを求めて採った人が辞め続けていることに気づき、そこから頼みます。

見ていて差がつくのは、職種を分けて採る型を、依頼側の職種の数に合わせて軽くしているかです。メーカーの人事の経験がある人は、技術職・技能職・事務職・営業職と細かく分けた仕組みを持っていますが、そのまま持ち込むと、依頼側には重すぎます。「御社の職種は、現場に出る人と事務の人の二つに分けるだけで十分です。要件の書き方と面接で見る点と受け入れの担当を、この二つで分けます」と、依頼側の規模に合わせて二つに絞った人は、仕組みが回り、依頼側から「初めて職種ごとに採り方を変えた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「性質の違う職場を、計画と制度で、長く働く人を採る形にする」と型の言葉で書いている担当者に、採ってすぐ辞めて困っている依頼側がついています。メーカーの人事の転身は、じっくりを語ることではなく、辞めない型を軽くして見せるところから始まります。

## 案件の探し方

メーカーの人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 製造・技術系の依頼側の採用 | 業界の言葉と職種が分かり、説明の手間がない | 同じ業界の依頼側を探す |
| 職種の性質ごとに採り方を分ける設計 | 分けて採ってきた経験でそのまま入れる | 「全職種を同じ流れで採用している依頼側」を探す |
| 年間の採用の計画と欠員の対応の設計 | 計画で回してきた経験で入れる | 「採用が場当たりの依頼側」を探す |
| 現場の管理者を採用に巻き込む分担 | 工場の管理者と進めてきた経験で入れる | 「現場が採用に関わらない依頼側」を探す |
| 長く働く前提の要件と受け入れの設計 | 育成まで見てきた経験で入れる | 「採ってすぐ辞める依頼側」を探す |
| 学校や地域の経路を持つ母集団の設計 | 学校との関係を作ってきた経験で入れる | 「媒体だけに頼っている依頼側」を探す |

探し方の要点は、「複数の職種を持ち、採ってすぐ辞める会社」から入ることです。一つの職種だけを速く採りたい会社では、メーカーの型は重すぎます。現場に出る職種と事務の職種の両方を持ち、計画で回したい採用があり、採っても辞めて困っている会社では、メーカーの型が唯一の打ち手になります。業界の外では、物流、建設、食品、設備の保守、複数の職種を持つ地域の会社が、同じ構造です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、業界を絞る戦い方は[業界特化という戦い方](/media/fukugyo-gyoukai-tokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。メーカーの人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 職種ごとの設計の成果物 | 職種ごとの要件・経路・面接・受け入れの一覧は、成果物として形が明確 | 一式の成果物で受ける |
| 年間の計画の成果物 | 計画と欠員の対応を分けた設計は、成果物で受けやすい | 一式の成果物で受ける |
| 現場の巻き込みの運用 | 現場の管理者との目線合わせは、回数で受けやすい | 月に何回・何分で決める |
| 長く働く設計の価値 | 早期の離職を減らす価値は、やり直しの損失として依頼側に分かりやすいが、成果が出るまで時間がかかる | 中期の契約で受け、途中の成果（受け入れの担当が決まった、三か月の面談が回った）を報告で見せる |
| 「遅い」と見られること | 単価より前に頼まれない | 圧縮した形を先に見せる |
| スカウトを含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 採用と定着は依頼側の条件と現場の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「設計は成果物で、現場の巻き込みは回数で受け、定着は途中の成果を見せる」ことです。メーカーの人事の経験で受ける工程は、職種ごとの設計と年間の計画という成果物が明確で、成果物で受けると単価の根拠が伝わります。長く働く設計は成果が出るまで時間がかかるので、中期の契約で受け、途中の成果を報告で見せて更新の根拠にします。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、数字に出ない成果の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、契約の期間は[契約期間の目安](/media/fukugyo-keiyaku-kikan/)に整理しています。

## 始める順番

メーカーの人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、社員と技術の情報の守秘の条件を確認する | メーカーは技術の守秘が重い。個別の判断は専門家に |
| 二、「性質の違う職場をどう分けて、どう計画で回し、どう長く働く人を採ってきたか」を、会社の情報を含まない型として書き出す | 分け方、計画、現場の巻き込み、長く働く設計 |
| 三、「じっくり」を「辞めない人を採る型」に言い換える | 時間の長さではなく、三年後から逆算する型で語る |
| 四、仕組みではなく、三つの型（職種を分ける、計画と欠員を分ける、現場を巻き込む）だけを、小さい会社に合わせて軽くした形を作る | 「職種は二つに分けるだけ」の形 |
| 五、得意な工程（職種の分け方・計画・現場の巻き込み・長く働く設計・学校の経路）と、薄い工程（スカウト・速い選考）を分ける | 正直に示す準備 |
| 六、範囲を、職種ごとの設計、年間の計画、現場の巻き込み、長く働く要件と受け入れに絞る | スカウトは最初は範囲外 |
| 七、「性質の違う職場を、計画と制度で、長く働く人を採る形にする」の一言を作る | 「メーカーの人事でした」で終わらせない |
| 八、登録先に、範囲と、軽くした型と、複数の職種を持つ依頼側に向いていることを登録する | 採ってすぐ辞めて困っている依頼側 |
| 九、職種ごとの設計か長く働く要件づくりを一件受け、「辞めなかった三か月」を残す | 次の工程に広げる材料に |

順番の要点は、「三」の言い換えと「四」の軽くする作業です。メーカーの人事の経験は、「時間をかけて丁寧に」と語ると遅く聞こえ、大きい会社の仕組みのまま語ると重く聞こえます。「辞めない人を採る型」と言い換え、三つの型だけを小さい会社に合わせて軽くした形を見せれば、同じ経験が「うちに足りないもの」として伝わります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「メーカーの人事は遅くて重く、小さい会社の速い採用には向いていない」というものです。実際には、速く採ることだけを追った会社ほど、採った人がすぐ辞め、採用をやり直し続けています。職種を分けて採る型、計画と欠員を分ける設計、現場を巻き込む分担、三年後から逆算する要件と受け入れ。メーカーの人事が日常として回してきたこの型は、その会社にとって、持っていない打ち手です。向いていないのではなく、「速く採る」から「辞めない人を採る」に依頼側の目的が変わったときに、必要になる型です。

順番として、本業の規定と守秘の条件を専門家に確認し、分けて計画で長く働く人を採ってきた型を会社の情報を含まずに書き出し、じっくりを辞めない型に言い換え、三つの型だけを軽くし、得意な工程と薄い工程を分け、範囲を職種ごとの設計と計画と巻き込みと長く働く設計に絞り、長く働く人を採る形にする一言を作り、登録先に範囲と型を登録し、一件受けて辞めなかった三か月を残す。この順番で、メーカーの人事の経験は「遅くて重いもの」から「辞めない人を採る型」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、長く働く設計の工程を明確にし、スカウトを含まないことを示している担当者に、採ってすぐ辞めて困っている依頼側がついています。メーカーの人事の転身は、じっくりを語ることではなく、辞めない型を軽くして見せるところから始まります。

- メーカーの人事の経験は**「工場と本社と技術という性質の違う職場を、年間の計画と制度の中で、長く働く前提で採って育ててきた」型**で売れる。**職種を分けて採る型・年間の計画・工場の管理者の巻き込み・長く働く前提の設計**の四つ
- **「メーカーの人事でした」ではなく「性質の違う職場を、計画と制度で、長く働く人を採る形にする」**と売る
- 売りにくい点は**遅いと見られる・自社の仕組みに寄りすぎ・スカウトの経験の薄さ**。「じっくり」を「辞めない」に言い換え、仕組みではなく三つの型だけを軽くし、スカウトは範囲外と示す
- 案件は**複数の職種を持ち、採ってすぐ辞める会社**から。物流・建設・食品・設備の保守・地域の会社も同じ構造
- 単価は**設計は成果物、現場の巻き込みは回数**で。定着は途中の成果を見せる。成果報酬は最初は避け、可否は専門家に確認
- 職種の分け方は、**依頼側の職種の数に合わせて二つに絞る**。大きい会社の細かい仕組みを持ち込まない

## よくある質問

### 依頼側から「とにかく早く一人採ってほしい」と言われました。じっくり型は合わないのでは

目的を確認します。「早く一人」の裏に「前の人がすぐ辞めた」があるなら、速さだけで採ると同じことが起きます。「早く採るのは御社の担当者か別の担当者が進めて、私は次の人が辞めない要件と受け入れを、並行して用意します」と、速さを止めない形で範囲を示します。前に辞めた人の理由を一つ聞き取り、「次の人の要件に、その一点を入れておきます」と、募集にすぐ効く形で返すと、じっくり型が後回しになりません。範囲の伝え方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に整理しています。

### 前の会社の技術系の学校との関係を、依頼側の採用に使ってよいですか

前の会社の名前で作った学校との関係は、前の会社のものであり、守秘と競業の線に関わります。持ち込むのは「学校との関係の作り方の型」だけにし、依頼側の学校との関係は、依頼側の名前で新しく作ります。人を紹介する形で使うと、職業紹介の許可の線にも関わります。個別の判断は、弁護士や社会保険労務士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### スカウトの経験がほとんどありません。案件が取れないのではないですか

スカウトの経験が薄いことは隠さず、「スカウトは御社の担当者か別の担当者が、私は職種ごとの設計と、計画と、現場の巻き込みと、長く働く要件と受け入れを担います」と分担を示します。スカウトが得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。採ってすぐ辞めて困っている依頼側には、スカウトの技術より「辞めない設計」が求められており、そこではスカウトの薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
