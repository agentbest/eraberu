本業で何年も人事をしていても、副業の最初の案件は不安になります。会社の仕組みの外で、権限も関係も無く、週に数時間で、外部の人として動く。本業の経験がそのまま通用するのか、動けないのではないか、成果が出なかったらどうするか。不安は自然ですが、不安のまま始めると、判断を引き受けたり、範囲を広げたり、隠したりして、崩れます。結論を先に書くと、**初案件の不安は七つに整理でき、それぞれに「型」という備えがあり、型を持って入れば不安は消えないまでも小さくなり、不安が原因の失敗は防げます。**不安は無くすものではなく、型で扱うものです。最初の三か月の設計は[稼働開始から九十日の設計](/media/fukugyo-shoki-90nichi/)に、線の引き方は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)にまとめています。

## 七つの不安と、その正体

初案件で出る不安を七つに分け、それぞれ何が不安の元になっているかを整理します。

| 不安 | 不安の元 | 実際 |
|---|---|---|
| 一 本業の経験が通用するか | 本業の仕組み（権限、関係、型）に支えられていたことに気づく | 通用するのは「型」の部分。仕組みに頼っていた部分は、副業では自分で作る |
| 二 権限が無い中で動けるか | 社内の人事なら当たり前にできることができない | 権限は依頼側に用意してもらうもの。一覧にして頼めば届く |
| 三 時間が守れるか | 本業と家庭と副業の枠が読めない | 枠を先に固定し、枠で回る範囲を受ければ守れる |
| 四 判断を求められたらどうするか | 断り方が分からない | 判断は依頼側。止まる言葉を持てば返せる |
| 五 成果が出なかったら | 成果の定義が曖昧 | 自分が動かせる数を成果と定義し、区切りで示す |
| 六 情報の事故を起こしたら | 本業では会社が守っていた | 保存しない運用と端末の分離で、事故の機会を減らす。起きたら伝える |
| 七 依頼側に頼りないと思われないか | 経験を全部見せないと信頼されないと思う | 範囲を守り、数を出し、線を引く人が信頼される。全部を見せる人ではない |

七つの要点は、「不安の元の多くは、本業の仕組みに頼っていた部分」ということです。本業では、権限も関係も情報の管理も、会社の仕組みがあった。副業では、その部分を自分の型で作ります。型ができれば、経験は通用します。

## それぞれの備え方

七つの不安に対する備えを、型として整理します。

| 不安 | 備え（型） | 参照 |
|---|---|---|
| 一 経験が通用するか | 本業の型を一般化して書き出す。文面の型、基準の型、記録の型。副業ではこれを持ち込む | [得意領域の決め方](/media/fukugyo-tokui-ryouiki/) |
| 二 権限が無い | 権限の一覧（媒体、情報、連絡、名乗り、費用の経路、現場の経路）を初回打ち合わせで出す | [権限がないと動けない場面](/media/fukugyo-kengen-nai/) |
| 三 時間が守れるか | 本業・家庭・休息を先に置き、残りで枠を固定。枠で回る範囲だけ受ける。枠の外で見ない | [本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/) |
| 四 判断を求められたら | 「〇〇さんにご判断いただきます。材料はこの形で用意します」を口癖に。判断の項目を選択肢の形で | [合否判断に関わってよいか](/media/fukugyo-gouhi/) |
| 五 成果が出なかったら | 面談で成果を「自分が動かせる数」に定義し直す。開始時点の値を記録し、区切りで並べる | [期待値のすり合わせ](/media/fukugyo-kitai-chousei/) |
| 六 情報の事故 | 依頼側の環境の中で扱い、端末に保存しない。専用の端末。起きたらすぐ伝える | [情報の取り扱いと端末の分離](/media/fukugyo-security/) |
| 七 頼りないと思われる | 範囲を書面に、含まないことまで。数で報告。線の手前で止まる。全部を見せない | [プロフィールの書き方](/media/fukugyo-profile/) |

備えの要点は、「七つとも、案件が始まる前に用意できる」ことです。型の書き出し、権限の一覧、枠の固定、止まる言葉、成果の定義、端末の分離、書面の範囲。どれも、案件が決まってから初回打ち合わせまでの間に整えられます。

### エラベルの見解

登録の相談で多いのは、「経験は十年あるのに、副業となると何もできない気がする」という声です。話を聞くと、本業では権限があり、現場との関係があり、社内の型があり、情報の管理は会社の仕組みだった。副業では、そのどれも無い。「何もできない」と感じるのは、経験が無いからではなく、仕組みが無いからです。仕組みの部分を自分の型で作れば、十年の経験は通用します。

見ていて差がつくのは、「不安を、型に変換しているか」です。「権限が無くて動けないかも」を「権限の一覧を出す」に、「判断を求められたら」を「止まる言葉を持つ」に、「成果が出なかったら」を「成果の定義を数にする」に。不安を型に変えた人は、初案件でも一件目の区切りで数を示し、二件目に進んでいます。エラベルの登録でも、初案件の前に型を準備している人は、最初の一か月の立ち上がりが早く、依頼側から「初めてとは思えない」と言われています。

## 不安が出る時期

七つの不安は、出る時期が違います。時期ごとに、どの不安が出やすいかと、そのときの備えを整理します。

| 時期 | 出やすい不安 | そのときの動き |
|---|---|---|
| 登録の前 | 一（経験が通用するか）、七（頼りないと思われる） | 型を書き出す。プロフィールを範囲と時間で書く |
| 面談の前後 | 五（成果が出なかったら）、四（判断を求められたら） | 成果の定義を自分の言葉で用意。判断の線を書面に |
| 初回打ち合わせ | 二（権限が無い） | 権限の一覧を出す。発行日を決める |
| 最初の週 | 三（時間が守れるか）、二 | 枠の中で動く。権限が届くまでは権限が要らない作業 |
| 一か月目 | 五、七 | 週ごとの一枚を渡す。小さな改善を渡す。[早い段階で成果を出す](/media/fukugyo-quick-win/) |
| 二か月目 | 三、四 | 一つに集中。判断待ちは一覧で |
| 区切り | 五 | 開始時点と現在の数を並べる |
| トラブル時 | 六 | 止める・伝える・記録する。[トラブルが起きたときの動き方](/media/fukugyo-trouble/) |

時期の要点は、「不安が出る時期を知っていれば、出たときに驚かない」ことです。一か月目に「成果が出ていない」と不安になるのは、一か月目は把握の月だから当然です。時期を知っていれば、不安は「予定どおり」になります。

## 備えても残る不安との付き合い方

型を持っても、不安は残ります。残る不安との付き合い方を整理します。

| 残る不安 | 付き合い方 |
|---|---|
| 「本当にこれでよいのか」 | 書面と型に戻る。書面のとおりに動いていれば、よい |
| 「依頼側は満足しているか」 | 週次の確認で聞く。「いまの進め方で問題ありませんか」。聞けば分かる |
| 「もっとできるのでは」 | 範囲の外は範囲の外。もっとやると崩れる。区切りで広げる |
| 「一件目で失敗したら終わり」 | 一件目は型を身につける期間。数が出なくても、型と学んだことが残れば次がある |
| 「本業に影響しないか」 | 枠の外で見ない。通知を切る。影響の兆候（本業中に考える）が出たら範囲を狭くする |
| 「一人で抱えている」 | 依頼側の担当と一緒に動く。登録先の運営に相談する。一人ではない |
| 「向いていないのでは」 | 一件目の区切りまでは判断しない。区切りで、数と学んだことを見て決める |

付き合い方の要点は、「書面と型に戻る」ことです。不安は、何をすればよいか分からないときに大きくなります。書面と型があれば、次にやることは決まっていて、不安は小さくなります。

## 不安が原因で起きる失敗

不安のまま動くと起きる失敗を整理します。備えがあれば防げるものです。

| 失敗 | 元の不安 | 起きる構造 | 直し方 |
|---|---|---|---|
| 経験を全部見せようとして範囲が広がる | 七 | 頼りなく思われたくない | 範囲を一つに。含まないことを書く |
| 判断を引き受ける | 四、七 | 断ると頼りないと思われる | 止まる言葉を持つ。判断する人が信頼される |
| 枠の外で対応する | 三、七 | 遅いと思われたくない | 枠を最初に伝える。枠の中で動く人が信頼される |
| 権限が無いまま担当のアカウントを借りる | 二 | 早く動きたい | 一覧を出して待つ |
| 一か月目に成果を急ぐ | 五 | 何もしていないと思われる | 週ごとの一枚と小さな改善を渡す |
| 情報を端末に保存して作業する | 六とは逆に、慣れで | 作業しやすい | 保存しない運用 |
| トラブルを隠す | 六、七 | 信用を失うと思う | 伝えると信用が育つ |
| 依頼側に確認しない | 七 | 聞くと頼りなく見えると思う | 聞く人が信頼される。「確認して折り返します」 |
| 単価を低くする | 七、五 | 自信が無い | 一件目は控えめでも、根拠は示す。[最初の一件の価格の決め方](/media/fukugyo-shoninka/) |
| 一件目で全部を学ぼうとする | 一 | 経験を積みたい | 一つの業務を直し切る。全部は次の案件で |

失敗の要点は、「七（頼りないと思われる）が、多くの失敗の元」ということです。頼りなく思われたくない気持ちが、範囲を広げ、判断を引き受け、枠の外で動かせ、隠させます。実際には、範囲を守り、判断を返し、枠の中で動き、伝える人が信頼されます。

### エラベルの見解

担当する側として登録した人の話を聞くと、初案件を無事に終えた人は、不安が無かった人ではなく、不安を型に変えていた人です。「権限が無くて動けないかも」と思ったから権限の一覧を作り、「判断を求められたら」と思ったから止まる言葉を用意し、「成果が出なかったら」と思ったから成果の定義を数にした。不安が、備えを作らせています。不安を感じない人のほうが、備えが無く、崩れます。

依頼側から見ると、初案件の副業の人は、経験があっても外部の仕組みに慣れていないことが多く、そこを支える必要があります。エラベルは、企業と担当者の間に立つ窓口として、初めての案件の担当者には、権限・判断の線・情報の扱い・成果の定義を依頼側と決めた形で案件をお伝えしています。それでも、日々の場面で線の手前で止まり、枠の中で動き、伝えるのは担当者ご自身です。七つの不安と備えの型を持っていただくことで、初案件は「初めて」に見えなくなります。

## まとめ

- 初案件の不安は**経験が通用するか・権限が無い・時間が守れるか・判断を求められたら・成果が出なかったら・情報の事故・頼りないと思われる**の七つ
- 不安の元の多くは**本業の仕組みに頼っていた部分**。仕組みの部分を自分の型で作れば経験は通用する
- 備えは**型の書き出し・権限の一覧・枠の固定・止まる言葉・成果の定義・端末の分離・書面の範囲**。案件が始まる前に用意できる
- 不安は**出る時期が決まっている**。時期を知っていれば「予定どおり」になる
- 残る不安は**書面と型に戻る**。次にやることが決まっていれば小さくなる
- **頼りないと思われたくない気持ち**が多くの失敗の元。範囲を守り、判断を返し、枠の中で動き、伝える人が信頼される

## よくある質問

### 経験は長いのですが、副業は初めてで、面談で何をアピールすればよいか分かりません

アピールではなく、範囲と時間と型を伝えます。「〇〇（一つの業務）を、火木の夜と土曜午前で。本業で〇年、〇〇を数千通。文面の型は四つに分けて冒頭を変える形で運用しています」。経験の長さを語るより、一つの業務の型を具体的に言うほうが、依頼側は「この人に頼める」と判断できます。副業が初めてであることは、聞かれなければ言わなくてよく、聞かれたら「副業としては初めてですが、業務の型は本業で身につけています」と、型に話を戻します。[面談で聞かれること](/media/fukugyo-mensetsu/)を参照してください。

### 一件目で失敗したら、二件目が無いのではと怖いです

一件目は、型を身につける期間です。数が出なくても、型と業務の数と学んだことが残れば、実績台帳の一行になり、二件目で使えます。「一件目で数が出なかった。原因は判断の目安が決まっていなかったこと。次は初回打ち合わせで決める」は、二件目の面談で「学んだこと」として話せ、依頼側は「原因を見ている人」と受け取ります。失敗と呼ばれるのは、崩れて途中で終え、何も残らなかった場合で、型と記録があれば、それは失敗ではありません。[実績の積み上げ方](/media/fukugyo-jisseki-tsumu/)を参照してください。

### 依頼側に質問するのが怖くて、分からないまま進めてしまいます

分からないまま進めるほうが、依頼側の信用を失います。「確認して折り返します」「この点、〇〇と〇〇のどちらでしょうか」と聞く人は、依頼側から「見えている人」「勝手に進めない人」として信頼されます。質問を、判断待ちの一覧として週に一度まとめて出す形にすれば、聞く回数は減り、依頼側の負担も小さくなります。聞くことは頼りなさではなく、線を守っている証拠です。一件目の最初の週は、聞くことが仕事だと考えてください。[ヒアリングで押さえる項目](/media/fukugyo-hearing/)を参照してください。
