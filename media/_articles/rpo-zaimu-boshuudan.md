財務の募集で起きる母集団の問題は、応募がまったく来ない場合と、経理の人ばかり来る場合、自社の状況（資金繰り・調達・上場準備・予算管理）と違う経験の人が来る場合、面接まで進んで「経営者が財務の判断を手放さない」と分かって辞退される場合に分かれます。原因の多くは、求人票で財務か経理かが曖昧なことと、経営者が委ねる範囲が決まっていないことにあります。結論を先に書くと、**財務の母集団形成は、「求人票で財務か経理か・状況・任せる範囲・経営との関係・経理との分担を示す」「出し先を状況に合う転向層のいる場所にする」「スカウトを状況で分ける」「面接で委ねる範囲と情報を正直に伝える」の順に見直し、前の段階が直る前に次に進まない**ことが要です。財務の経験者は市場に少なく、しかも「財務」の名前で経理を募集する会社を知っているので、求人票の一行目で実態を疑います。代行に出す工程の線は[財務採用を代行に出す判断基準](/media/rpo-zaimu-rpo/)に、経理の母集団形成は[経理の母集団形成](/media/rpo-keiri-boshuudan/)にまとめています。

## 四つの症状を分ける

最初に、どの症状かを分けます。

応募がほとんど無い場合は、財務の経験者が市場に少ないことに加えて、求人票が「実態は経理」と読まれて見送られているか、条件（財務の経験者の条件は幅が広い）で見送られているかです。

経理の人ばかり来る場合は、求人票が財務と経理を混ぜていることが原因です。「財務経理」「決算と資金繰り」と並ぶと、経理の人が応募します。

状況と違う経験の人が来る場合は、求人票が自社の状況を示していないことが原因です。「財務担当」だけだと、資金繰りの人も、調達の人も、上場準備の人も応募します。

面接まで進んで辞退される場合は、経営者が委ねる範囲が曖昧か、面接で「全部自分がやる」と伝わったかです。

どの症状かは、応募者を経理か財務か、状況の種類、転向元で分類し、面接での候補者の質問を記録すれば分かります。

## 見直す順番の一番目：求人票に「財務か経理か・状況・範囲・関係・分担」があるか

求人票を開いて、次の六つが読み取れるかを確認します。

- **財務か経理か。** 記帳と決算ではなく、資金繰り・調達・予算・投資を担う役割であることが一行目で分かる形に
- **自社の状況。** 資金繰りの管理と銀行対応が中心か、調達が中心か、上場準備が中心か、予算と投資の判断が中心か。状況の種類まで
- **任せる範囲と、経営者が持つ範囲。** 銀行との対応を任せるか、調達の交渉を任せるか、投資の判断に財務の意見をどう扱うか
- **経営との関係。** 誰に報告し、どのくらいの頻度で経営者と数字を見るか。財務の意見が判断に反映されるか
- **経理との分担。** 経理の担当がいるか、財務が経理も兼ねるか
- **機微な情報の開示の段階。** 求人票では状況の種類まで。詳細は面接で秘密保持のもとで、と示す

六つのうち、一つ目と三つ目が最も抜けます。財務か経理かが曖昧だと経理の人が来て、任せる範囲が無いと財務の経験者は「経営者が全部やる会社」と疑います。

機微な情報（資金繰りの金額、調達の交渉の状況、上場の時期）は、求人票には書きません。状況の種類（「資金繰りの管理と銀行対応が中心」「調達を進めている」）まで書き、詳細は面接で、秘密保持の合意のもとで示します。

### エラベルの見解

相談で多いのは、「財務を募集して数か月、財務の経験者からの応募がゼロで、経理の人ばかり」というご相談です。求人票を見ると、「財務経理担当募集。月次・年次決算、資金繰り管理、銀行対応」と書かれていて、財務の経験者から見ると「実態は経理で、資金繰りは経営者がやっているだろう」に読めます。財務の経験者は、この種の求人票を見慣れていて、見送っています。

見ていて差がつくのは、「一行目で財務の範囲を宣言し、経営者が委ねる範囲を書いているか」です。「成長のための調達を進めており、銀行との対応と資金繰りの管理、事業計画の数字を担う財務。経理は別の担当。銀行との対応は財務が主体で、経営者は最終の判断」。ここまで書けば、経理の人は自分向けでないと分かり、調達の経験がある財務の人は「本当に財務を求めている」と判断します。エラベルでは、財務の担当者に、求人票の一行目で財務か経理かを明確にし、委ねる範囲を依頼側の経営者と決めるところから始めてもらっています。

## 見直す順番の二番目：出し先が状況に合う転向層のいる場所か

求人票が整ったら、出し先を見ます。財務の経験者は少なく、状況に合う転向層を含める設計が母集団の大きさを決めます。

| 出し先 | 向く状況 | 注意 |
|---|---|---|
| 管理部門・財務に強い媒体 | 財務の経験者に絞って届けたい | 経験者は限られる。転向層に届く書き方を |
| ダイレクトリクルーティングの媒体 | 状況に合う経験の人に、こちらから届けたい | 状況で検索を分ける。機微な情報は文面に書かない |
| 銀行からの転向層 | 資金繰りの管理と銀行との対応が中心 | 銀行の考え方を知っている。事業会社に移りたい動機を確認 |
| 監査法人・会計事務所からの転向層 | 上場準備、内部統制、決算の高度化 | 数字の正確さに強い。資金の判断の経験は面接で確認 |
| 証券・投資の会社からの転向層 | 調達（増資）が中心 | 投資家の視点を知っている。日々の資金繰りの経験は面接で確認 |
| コンサルティングからの転向層 | 予算と事業計画の数字、投資の判断 | 計画を作る力。実務の運用の経験は面接で確認 |
| 事業会社の財務からの転向層 | 状況による | 前職の状況が自社と近いか |
| 経理から財務へ移りたい人 | 財務が経理を兼ねる小さな会社 | 資金繰りや銀行対応の経験の有無で分ける |
| 社外取締役・顧問・投資家からの紹介 | 一人目の財務 | 財務の人材を知っていることが多い |
| 社員の紹介 | 社内に管理部門の人がいる | 求人票の六つを社員に渡す。[リファラルが進まない理由](/media/rpo-referral-susumanai/) |

出し先の要点は、「状況によって、合う転向元が違う」ことです。資金繰りと銀行対応なら銀行から、上場準備なら監査法人から、調達なら投資の会社から。状況を決めずに出し先を選ぶと、合わない転向元に費用と時間を使います。

## 見直す順番の三番目：スカウトが状況で分けられているか

ダイレクトリクルーティングで返信が来ない場合、検索の条件と文面を見ます。

検索の条件は、状況で分けます。資金繰りと銀行対応なら「資金繰りの管理」「銀行との折衝」「融資」の経験、調達なら「増資」「投資家との対応」の経験、上場準備なら「上場準備」「内部統制」の経験、予算管理なら「予算の策定」「事業計画」の経験。「財務」の肩書だけで検索すると、状況が混ざります。

文面は、一行目で候補者の経歴の一点に触れます。財務の場合、触れる一点は「担った状況の種類」「銀行や投資家との対応の経験」「作った計画や整えた体制」のどれかで、自社の状況と重なるものです。「〇〇の状況で、銀行との対応と資金繰りの管理を担われてきたご経歴を拝見しました。当社も同じ状況です」。その後に、財務の範囲、状況の種類、任せる範囲、経営との関係、経理との分担を書きます。機微な情報の詳細は書きません。文面の型は[財務向けスカウト文面の型](/media/rpo-zaimu-scout/)に詳しく書きます。

## 見直す順番の四番目：面接で委ねる範囲と情報を正直に伝えているか

応募も返信もあるのに、面接で辞退される場合、面接で何を伝えているかを見ます。財務の候補者は、面接で「経営者は財務の判断をどこまで委ねるか」「資金の状況は実際どうか」「経営者と数字の話ができるか」を確かめます。

面接には、経営者本人と、財務の分かる人（社外取締役、顧問、監査法人や銀行の担当）が出ます。経営者が「銀行との対応は財務が主体、最終の判断は自分」と直接話すと、候補者は委ねる範囲を確かめられます。財務の分かる人が判断の質を聞きます。

面接で、資金の状況を正直に伝えることが要点です。資金繰りが厳しいなら厳しいと、秘密保持の合意のもとで、詳細を示します。隠して入社してもらっても、初日に帳簿を見れば分かります。正直に伝え、「それでも」と言う候補者を選びます。

## 機微な情報の扱い

財務の採用では、情報の開示の段階を決めておきます。

| 段階 | 開示する範囲 | 開示しない範囲 |
|---|---|---|
| 求人票 | 状況の種類（資金繰りの管理が中心、調達を進めている、上場を準備している） | 金額、銀行との交渉の状況、調達の相手、上場の時期 |
| スカウト | 求人票と同じ範囲 | 同上 |
| 一次面接 | 状況の概要。経営者が委ねる範囲 | 詳細な数字 |
| 二次面接以降 | 秘密保持の合意のもとで、資金繰りの表、調達の状況、上場の計画 | — |
| 内定後 | 業務に必要な全部 | — |

扱いの要点は、「求人票とスカウトには状況の種類まで、詳細は面接で秘密保持のもとで」ということです。代行に出す情報も、求人票とスカウトに書く範囲にとどめます。詳細を代行に渡す場合は、代行との秘密保持の契約を確認します。

## 社内で持つ工程と、外に出せる工程

| 段階 | 社内で持つ | 外に出せる |
|---|---|---|
| 求人票の中身 | 財務か経理か、状況、任せる範囲、経営との関係、経理との分担を経営者が出す | 聞き取って候補者に伝わる言葉にする。一行目の案。機微な情報を含めない書き方 |
| 出し先 | 予算と契約の判断。社外取締役や顧問への紹介の相談 | 状況に合わせた転向層を含めた経路の提案、運用、数の整理 |
| スカウト | 状況と範囲の確定 | 状況で分けた検索、一行目の個別化、送信、一次対応 |
| 面接 | 経営者と財務の分かる人の面接の枠、判断の質の評価、委ねる範囲と情報の説明 | 一次返信、日程調整、転向元と状況の分類、進捗の管理 |

分け方の要点は、「委ねる範囲と機微な情報は、経営者にしか決められず、経営者にしか説明できない」ことです。外部は、決まったものを言葉にし、状況に合う転向層を含めた経路で探す役です。

### エラベルの見解

担当する側から見ると、財務の母集団形成で最も効くのは、求人票の一行目で「財務であって経理ではない」と示し、経営者が委ねる範囲を書くことです。財務の経験者は、「財務」の名前の経理の募集を見慣れていて、この二つが無い求人票を疑います。二つがあると、応募の総数は増えなくても、財務の経験者と、状況に合う転向層の応募が来ます。

エラベルでは、財務の案件で担当者を紹介するとき、最初の一か月は求人票の六つの項目を経営者と一緒に埋め、とくに委ねる範囲を経営者に決めていただくことに使うようお伝えしています。媒体やスカウトはその後です。財務は、探し方より、経営者が何を委ねるかの明確さで、母集団が決まります。

## まとめ

- 財務の母集団の問題は**応募が来ない・経理の人が来る・状況と違う経験の人が来る・面接で委ねる範囲の実態で辞退される**の四つ
- 見直す順番は**求人票の財務か経理か・状況・範囲・関係・分担→出し先→スカウトの状況分け→面接で委ねる範囲と情報を正直に**。前の段階が直る前に次に進まない
- 求人票には**財務か経理か（一行目）・状況の種類・任せる範囲と経営者が持つ範囲・経営との関係・経理との分担・機微な情報の開示の段階**の六つ
- 出し先は**状況によって合う転向元が違う**。銀行、監査法人、投資の会社、コンサルティング、事業会社の財務
- スカウトは**状況で検索を分け、一行目で担った状況の一点に触れる**。機微な情報は書かない
- 面接には**経営者と財務の分かる人**が出て、**委ねる範囲を直接伝え、資金の状況を秘密保持のもとで正直に**
- 機微な情報は**求人票とスカウトでは状況の種類まで、詳細は面接で秘密保持のもとで**

## よくある質問

### 財務の経験者が少なすぎて、母集団が作れません

経験者だけを待つと作れません。自社の状況に合う転向元（銀行、監査法人、投資の会社、コンサルティング）を経路に含めます。銀行出身の人は資金繰りと銀行対応に、監査法人出身の人は上場準備と内部統制に、投資の会社出身の人は調達に、それぞれ持っているものがあり、事業会社の財務としては未経験でも、自社の状況に合う素養があります。要件で「事業会社での財務の経験」を必須にせず、状況に合う経験（銀行との折衝、内部統制の構築、投資家との対応）で書くと、転向層が母集団に入ります。転向元ごとに、持っているものと確認すること（事業会社の日々の資金繰りの経験があるか、など）を分けて、面接で確かめます。

### 資金繰りが厳しい状況を、どこまで候補者に伝えればよいですか

求人票とスカウトでは「資金繰りの管理と銀行対応が中心」と状況の種類まで。一次面接では概要と、経営者が委ねる範囲。二次面接以降で、秘密保持の合意のもとで、資金繰りの表や銀行との交渉の状況を示します。厳しい状況を隠して採ると、初日に帳簿を見て分かり、信用を失います。財務の経験者の中には、立て直しの経験があり、厳しい状況に魅力を感じる人がいます。段階を踏んで正直に伝え、「それでも」と言う人を選びます。開示の範囲と秘密保持の扱いは、専門家にご確認ください。

### 経営者が「銀行との対応は自分がやり続けたい」と言っています

その場合、財務に委ねる範囲は「資金繰りの管理、事業計画の数字、銀行に出す資料の作成」で、銀行との対応そのものは経営者、と正直に書きます。それに合う人（銀行との対応の経験より、数字の管理と計画に強い人）を探します。「財務を任せる」と書いて実際は経営者が銀行との対応を手放さない、が最も離職を生みます。経営者が銀行との対応を手放したくない理由（銀行との関係を保ちたい、まだ財務を信頼できない）があるなら、最初は経営者が出て、財務が同席し、段階的に移す形を求人票に書くこともできます。
