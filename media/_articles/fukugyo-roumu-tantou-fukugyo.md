労務の担当として、入社と退職の手続き、勤怠と給与の締め、社会保険の届出、就業規則の運用、社員からの相談の窓口を担ってきた。この経験は、人事の副業、とくに採用まわりの副業で売れるのか。労務は採用と部門が分かれていることが多く、採用の副業と聞くと自分には関係がないと感じる人が多いところです。結論を先に書くと、**労務の経験は、「入社から退職までの手続きと条件を、抜けなく、期日どおりに、書面で回してきた」型で売れます。売れるのは、「内定から入社までの手続きの設計」「採用の条件の整合の確認」「入社後のつまずきの早期の把握」「採用担当者が知らない手続きの線」の四つです。人事の部門が小さい会社では、採用の担当者が内定を出した後、書類の案内が遅れ、条件の説明が口頭で食い違い、入社の初日に準備ができておらず、そこで候補者の信頼が崩れます。「労務をしていました」ではなく、「採用が決まった後に、抜けと遅れで人が離れない形を作る」と売ります。**社会保険労務士の資格を持つ人の売り方は[社会保険労務士が副業でできること](/media/fukugyo-sharoushi-fukugyo/)に、人事企画の経験は[人事企画が副業でできること](/media/fukugyo-jinji-kikaku-fukugyo/)に、人事マネージャーの経験は[人事マネージャー経験を活かす](/media/fukugyo-manager/)にまとめています。なお、労務の手続きと法令に関わる個別の判断は、社会保険労務士・弁護士にご確認ください。

## この経歴の何が売れるか

労務の経験を、依頼側の採用の工程に置き換えた棚卸しです。在籍した会社の社員の情報は含めず、「型」として抜き出します。

| 労務の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 入社の手続きを、期日と書類の一覧で回してきた | 内定から入社までに「いつ・誰が・何を・どの書面で」を一覧にし、遅れと抜けをなくす | 内定の後の案内が遅れ、候補者が不安になる依頼側が多い |
| 労働条件の通知と雇用契約の書面を整えてきた | 面接で口頭で伝えた条件と、書面の条件が食い違わないように、採用の前に整合を確認する | 口頭と書面の条件が違い、入社の直前にもめる依頼側が多い |
| 勤怠と給与の締めを回してきた | 採用の条件（勤務時間、休日、手当）が、既存の社員の制度と矛盾しないかを確かめる | 採用のたびに条件が例外になり、後で説明できなくなる依頼側が多い |
| 社員からの相談の窓口を担ってきた | 入社の直後に、つまずきや不安を早く拾う仕組み（面談の設定、相談の窓口の案内） | 入った人の不満が、辞めるまで誰にも届かない依頼側が多い |
| 退職の手続きと理由の把握をしてきた | 退職の手続きの場で聞いた理由を、採用の要件と条件に戻す | 辞める理由が採用に戻らない依頼側が多い |
| 社会保険や届出の期日を守ってきた | 採用担当者が知らない手続きの期日と線を、採用の流れに組み込む | 採用担当者が手続きを後回しにして、期日を過ぎる依頼側が多い |
| 就業規則を運用し、例外を扱ってきた | 採用で「特別扱い」を頼まれたとき、既存の規則と照らして可否と影響を整理する | 経営者の一存で条件を決め、後で不公平が出る依頼側が多い |

売れるものの要点は、「内定の後から入社の後までの期間を、抜けなく設計できる」ことです。採用の担当者は、内定を出すところまでを自分の仕事だと考えることが多く、その後の書類と条件と初日の準備は、誰の仕事でもないまま遅れます。候補者は、内定の後の対応の遅れと食い違いで、その会社への信頼を失います。労務の経験は、この期間を「期日と書面と担当」で設計でき、そこで人が離れない形を作れます。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に書いています。

## 売りにくい点とその扱い

労務の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 採用の実務が薄い | 「募集やスカウトや面接はできるのか」。自分にとっても、候補者と向き合う経験が薄い不安 | 募集から内定までの実務は範囲に入れないか、別の担当者と組む。売るのは「内定の後から入社の後まで」だと最初に分ける |
| 地味に見える | 「手続きは総務でもできる」「そこにお金を払うほどではない」 | 手続きそのものではなく、「内定の後の遅れと食い違いで候補者が離れる」損失の話で売る。手続きは手段で、目的は辞退と早期の離職を減らすこと |
| 法令の線の重さ | 「社労士でもないのに、法令の判断をされるのは困る」。自分にとっても、判断の責任を負えない不安 | 法令の判断はしない。「一般にこう整理されている」「この点は社労士か弁護士に確認する」と線を引き、判断が要る点を見つけて専門家につなぐ役割にする |

扱い方の要点は、「手続きの人ではなく、内定の後に人が離れない形を作る人として売る」ことです。労務の担当者は、自分の仕事を手続きの言葉で語る癖があり、それが依頼側には「総務の仕事」に聞こえます。「内定を出した後、案内が遅れて辞退された」「入社の初日に机も口座の案内もなく、その人はひと月で辞めた」という依頼側の損失の場面で語れば、同じ経験が採用の成果に直結するものとして伝わります。法令の線は、判断せずに見つけてつなぐ役割に徹します。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、労務から転身して続いている人と、面談で止まる人の差は、依頼側に「内定の後、入社までに何を送っていますか」と聞くかどうかです。止まる人は、自分の手続きの経験を並べ、依頼側は「手続きは今のところ回っている」と答えて終わります。続いている人は、その質問をして、依頼側が「内定の連絡と、入社日の前に書類を渡すくらい」と答えたところで、「その間に候補者が何を不安に思うか」を話し、内定から入社までの一覧を見せます。依頼側は、自分の会社に「その期間の設計がない」ことに初めて気づきます。

見ていて差がつくのは、条件の食い違いを、採用の前に見つけているかです。労務の経験がある人は、面接で口頭で伝わる条件（勤務時間、休日、手当、試用期間の扱い）が、書面にする段階で食い違うことを知っています。採用の担当者が候補者に条件を伝える前に、労務の目で「書面にしたときにこうなります」と確認する一手を入れた人は、入社の直前のもめごとが消え、依頼側から「初めて内定の後で辞退されなかった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「採用が決まった後に、抜けと遅れで人が離れない形を作る」と成果の言葉で書いている担当者に、内定の後で候補者を失っている依頼側がついています。労務の転身は、手続きの知識ではなく、内定の後の期間の設計から始まります。

## 案件の探し方

労務から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 内定から入社までの手続きの一覧づくりと運用 | 入社の手続きを回してきた経験でそのまま入れる | 「内定の後の案内が遅れる依頼側」を探す |
| 採用の条件と書面の整合の確認 | 労働条件の通知と契約の書面を整えてきた経験で入れる | 「入社の直前に条件でもめた依頼側」を探す |
| 入社の初日から一か月の準備と相談の窓口の設計 | 社員の相談の窓口の経験で入れる | 「入った人が早く辞める依頼側」を探す |
| 退職の理由を採用に戻す整理 | 退職の手続きの経験で入れる | 「辞める理由が採用に戻らない依頼側」を探す |
| 採用の「特別扱い」の可否と影響の整理 | 就業規則の運用と例外の扱いの経験で入れる | 「経営者の一存で条件が決まる依頼側」を探す |
| 採用担当者への手続きの期日と線の手引き | 届出の期日を守ってきた経験で入れる | 「初めて採用担当を置いた依頼側」を探す |

探し方の要点は、「内定の後で候補者を失っている会社」から入ることです。募集がうまくいかない会社では、労務の経験は募集の技術に負けます。内定は出ていて、その後の辞退や、入社の直後の離職がある会社では、募集の技術では解決できず、労務の「抜けなく回す」経験が唯一の打ち手になります。案件の相談で「内定を出したのに来なかった」「入ってすぐ辞めた」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。労務の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 内定の後の期間の価値 | 内定の後の辞退と早期の離職の損失は、依頼側にとって分かりやすい | 「内定の後で辞退されなかった」「初日の準備が揃った」を成果として残す |
| 一覧と手引きの成果物 | 内定から入社までの一覧、条件の確認の項目、初日の準備の手引きは、成果物として形が明確 | 一式の成果物で受ける |
| 運用の継続 | 一覧を作った後、採用のたびに回す運用は、月額で受けやすい | 作る工程は成果物、回す工程は月額で |
| 採用の実務を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 手続きの言葉での見積もり | 「手続きの代行」で出すと、総務の作業として見られ、単価が下がる | 辞退と離職を減らす設計として示す |
| 法令の判断を含まないこと | 判断を含まない範囲は責任が明確で、専門家への橋渡しは依頼側にとって価値がある | 「判断が要る点を見つけて専門家につなぐ」を範囲に明記する |
| 成果報酬の扱い | 辞退や離職は依頼側の条件と管理職の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「作る工程は成果物で、回す工程は月額で受け、手続きの代行として見積もらない」ことです。労務の工程は、一覧と手引きを作る工程と、採用のたびに回す工程に分かれます。作る工程は成果物で受け、回す工程は月額で受けると、単価の根拠が明確になります。「手続きの代行」と書くと総務の作業として見られるので、「内定の後の辞退と早期の離職を減らす設計と運用」と書きます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、数字に出ない成果の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

労務から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、社員の情報の守秘の条件を確認する | 労務は個人情報の扱いが重い。個別の判断は専門家に |
| 二、法令の判断を副業でしないと決め、「一般にこう整理されている」「ここは専門家に」の線を自分の言葉で書く | 責任の線 |
| 三、「内定から入社の後まで」の手続きと条件の流れを、会社の情報を含まない一覧の型として書き出す | いつ・誰が・何を・どの書面で |
| 四、得意な工程（内定の後、条件の整合、初日の準備、相談の窓口、退職の理由）と、薄い工程（募集・面接・候補者対応）を分ける | 正直に示す準備 |
| 五、範囲を、内定の後の一覧と運用、条件の整合、初日から一か月の準備、退職の理由の整理に絞る | 採用の実務は最初は範囲外か、別の担当者と組む |
| 六、「採用が決まった後に、抜けと遅れで人が離れない形を作る」の一言を作る | 「労務をしていました」で終わらせない |
| 七、内定から入社までの一覧の見本を、架空の会社で一枚作る | 面談で見せる道具 |
| 八、登録先に、範囲と、法令の判断を含まないことと、採用の実務を含まないことを登録する | 内定の後で候補者を失っている依頼側 |
| 九、内定の後の一覧づくりを一件受け、「初日の準備が揃った」形を残す | 次の工程に広げる材料に |

順番の要点は、「二」の法令の線を自分の言葉で書くことです。労務の経験がある人は、法令の知識を持っているので、依頼側から判断を求められ、つい答えてしまいます。副業では、その判断の責任を負えません。「一般にはこう整理されていますが、御社の場合の判断は社労士か弁護士に確認しましょう」と、判断が要る点を見つけて専門家につなぐ役割に徹すると決め、その言葉を用意しておくと、面談でも案件の中でも線を守れます。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、案件ごとの情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「労務の経験は、採用の副業とは関係がない」というものです。実際には、採用の損失の一部は、内定の後に起きています。案内の遅れ、条件の食い違い、初日の準備の不足、入った直後の不満の放置。どれも募集の技術では防げず、「抜けなく、期日どおりに、書面で回す」労務の型でしか防げません。関係がないように見えるのは、採用の担当者が内定までを自分の仕事だと思っていて、その後を誰も見ていないからで、そこを見る人が要ると気づいた依頼側は、労務の経験を探しています。

順番として、本業の規定と守秘の条件を専門家に確認し、法令の判断をしない線を自分の言葉で書き、内定から入社の後までの流れを一覧の型として書き出し、得意な工程と薄い工程を分け、範囲を内定の後に絞り、抜けと遅れで人が離れない形を作る一言を作り、一覧の見本を一枚作り、登録先に範囲と線を登録し、一件受けて初日の準備が揃った形を残す。この順番で、労務の経験は「採用とは関係がないもの」から「内定の後で人を失わない設計」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、内定の後の工程を明確にし、法令の判断と採用の実務を含まないことを示している担当者に、内定の後で候補者を失っている依頼側がついています。労務の転身は、手続きの知識ではなく、内定の後の期間の設計から始まります。

## まとめ

- 労務の経験は**「入社から退職までの手続きと条件を、抜けなく、期日どおりに、書面で回してきた」型**で売れる。**内定から入社までの手続きの設計・条件の整合・入社後の把握・手続きの線**の四つ
- **「労務をしていました」ではなく「採用が決まった後に、抜けと遅れで人が離れない形を作る」**と売る
- 売りにくい点は**採用の実務が薄い・地味に見える・法令の線の重さ**。損失の場面で語り、実務は範囲外と示し、法令の判断はせず専門家につなぐ
- 案件は**内定の後で候補者を失っている会社**から。「内定を出したのに来なかった」「入ってすぐ辞めた」が入り口
- 単価は**作る工程は成果物、回す工程は月額**で。手続きの代行として見積もらない。成果報酬は最初は避け、可否は専門家に確認
- 法令に関わる個別の判断は、**社会保険労務士・弁護士にご確認ください**

## よくある質問

### 依頼側から「この人を雇うとき、試用期間の扱いはどうすればいいか」と聞かれました。答えてよいですか

一般的な整理として知っていることは、「一般にはこう整理されています」と前置きして伝えて構いません。ただ、依頼側の就業規則と契約の書き方に照らした個別の判断は、副業の担当者が責任を負えないので、「御社の規則で確認し、社労士か弁護士に見てもらいましょう」と、判断が要る点を見つけて専門家につなぐ役割に徹します。答えを出す人ではなく、答えが要る点を見つける人だと最初に示しておくと、依頼側の期待もずれません。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、範囲外の依頼への対応は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に整理しています。

### 給与の計算や社会保険の届出そのものを副業で受けてよいですか

社員の給与と社会保険の情報は、個人情報の中でも扱いが重く、副業の担当者がアクセスする範囲と管理の方法を、依頼側と書面で決める必要があります。届出の代行は、業として行う場合の資格の線に関わることがあり、可否は社会保険労務士・弁護士にご確認ください。採用まわりの副業では、給与と届出そのものは範囲に入れず、「採用担当者が知らない手続きの期日と線を、採用の流れに組み込む」役割にとどめるほうが、責任の線が明確です。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、アカウントの扱いは[アカウント管理のしかた](/media/fukugyo-account-kanri/)に書いています。

### 募集や面接の経験がないと、案件が取れないのではないですか

採用の実務が薄いことは隠さず、「募集と面接は御社の担当者か別の担当者が、私は内定の後から入社の後までを担います」と分担を示します。募集の実務が得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。内定の後で候補者を失っている依頼側には、募集の実務より内定の後の設計が求められており、そこでは実務の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
