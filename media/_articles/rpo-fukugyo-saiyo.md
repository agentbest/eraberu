副業で週に数時間、関わってもらっている人がいる。仕事の質が良く、社内の評判も良い。「この人に、社員として来てほしい」と思う。ただ、本人には本業があり、副業の条件と本採用の条件は違う。どう切り出せばよいか、断られたら副業の関係も壊れないか、と迷う。結論を先に書くと、**副業から本採用につなげるのは、「良い人だから後から誘う」のではなく、最初から「本採用の可能性がある関わり方」として設計しておくことで、自然になります。副業は、お互いを見る期間です。見た結果を、役割と条件と時期で組み直して、切り出します**。副業人材に採用業務を委託する実務は[副業人材に採用業務を委託するときの実務](/media/rpo-fukugyo-jinzai-itaku/)に、業務委託から採用する形は[業務委託で入ってもらってから採用する](/media/rpo-gyoumu-itaku-saiyo/)にまとめています。

## 副業から本採用で起きていること

副業の人材を本採用につなげようとする会社では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 「良い人」と分かってから、急に誘う | 副業の契約に、本採用の可能性を置いていなかった。本人は想定していない |
| 副業の役割のまま、本採用の条件を出す | 副業で任せていた範囲と、社員として任せる範囲が違う。役割を組み直していない |
| 条件が、副業の報酬と本採用の給与で釣り合わない | 副業の時間単価と、社員の年収の換算が合わず、本人が「下がる」と感じる |
| 本人の本業の事情を、聞いていない | 本業を辞められるのか、辞めたいのか、いつなら動けるのか。聞かずに誘う |
| 断られたら、副業の関係が気まずくなる | 誘い方が「本採用でなければ困る」に聞こえ、副業を続けにくくなる |
| 社内の同意が無い | 現場は本採用を望んでいるが、責任者や経営者は「副業のままでよい」。誘ってから社内で揉める |
| 副業の人と社員の間の、扱いの違いが曖昧 | 副業の人に、社員と同じ責任を期待している。線が引かれていない |

副業から本採用は、うまく設計すれば、最も外れの少ない採用の経路です。お互いを見た上で決めるからです。設計しなければ、気まずさと条件のずれで終わります。

## 最初から可能性を置く設計

副業で関わってもらう最初の段階で、本採用の可能性を置きます。

**副業の契約の段階で、「将来、本採用の話をする可能性がある」と伝える。** 「副業で関わっていただく中で、お互いに合えば、社員としてのご相談をすることがあります。その場合も、副業のままを選んでいただいて構いません」。最初に言えば、後の切り出しが自然になります。

**副業の役割を、「本採用の役割の一部」として切り出す。** 副業で任せる範囲を、社員として任せたい役割の一部にします。副業の中で、本採用の役割への適性が見えます。

**副業の期間を、区切る。** 「まず三か月」「半年」。区切りが、本採用の話をする自然な時期になります。

**副業の中で、お互いが見るものを決めておく。** 会社が見るもの（仕事の質、社内との相性、役割の適性）、本人が見るもの（会社の実態、一緒に働く人、事業の中身）。「見る期間」であることを、お互いに認識します。

**副業の人の扱いを、社員と分ける。** 責任の範囲、決められること、会議への参加、社内の情報へのアクセス。副業は副業の範囲で。社員と同じ責任を副業に求めない。契約の形と法令上の扱いは専門家に確認します。

**社内の責任者と、本採用の可能性を共有しておく。** 「この副業の方は、本採用の候補として関わってもらっている」。現場だけが望んで、責任者が知らない状態を避けます。

最初に置いておけば、「良い人だから急に誘う」ではなく、「最初から話していた可能性を、時期が来たので相談する」になります。

## 本採用を切り出す時期と伝え方

切り出す時期と、伝え方です。

| 項目 | 型 |
|---|---|
| 時期 | 副業の区切り（三か月、半年）の少し前。区切りの振り返りの場で |
| 誰が | 副業の人と最も接している責任者。人事だけが切り出すと、「事務的」に見える |
| 場 | 一対一で、時間を取って。立ち話や、メールだけで切り出さない |
| 最初の一言 | 「最初にお伝えした、社員としてのご相談をさせてください。断っていただいても、副業は続けていただけます」 |
| 伝える内容 | なぜ来てほしいか（副業で見えた具体的な働き）、どんな役割か、条件の幅、時期の希望 |
| 聞く内容 | 本業の状況、本人の希望（本採用に興味があるか、時期、条件、働き方）、迷う点 |
| 決めない | その場で答えを求めない。「考えていただいて、〇日までにお返事を」 |
| 断りやすさ | 「副業のまま」が選べることを、繰り返し伝える。断ったことで関係が変わらないことを示す |

伝え方の要点は、「断っても副業は続く」を先に言うことです。これが無いと、本人は「断ると副業も終わる」と感じ、断りにくくなり、断った後に気まずくなります。

「なぜ来てほしいか」は、具体的に。「副業で〇〇を進めていただいたとき、△△の判断が的確でした。社員として、この役割を担っていただきたい」。「良い人だから」では、伝わりません。

## 役割と条件の組み直し

副業の役割と条件を、本採用の役割と条件に組み直します。

**役割は、副業の範囲より広くなる。** 副業で任せていた範囲に加えて、社員として任せる範囲。「何を決める役割か」「誰と働くか」「どこまで担うか」を、改めて書面にします。

**条件は、副業の報酬から換算しない。** 副業の時間単価を年収に換算すると、社員の給与と合わないことが多いです。自社の役割の幅で提示し、副業の報酬との違いを説明します。「副業の報酬は時間あたりで、社員の給与は役割と責任に対して」。

**副業で見えた適性を、条件に反映する。** 副業で実績が見えている分、幅の中で高めの位置に置けることがあります。「副業で〇〇が確認できたので、この位置で」。

**既存社員との整合を、先に見る。** 副業の人を本採用にするとき、同じ役割の既存社員の水準と整合させます。

**働き方を、聞く。** 本業を辞めて専念するのか、当面は本業と並行するのか。並行するなら、社員としての働き方（時間、日数）をどう設計するか。制度と法令上の扱いは専門家に確認します。

**時期を、本人の本業の事情に合わせる。** 本業の退職には、時間がかかります。「いつでも」ではなく、「本業の区切りに合わせて、〇か月後から」。

**副業から社員への切り替えの手続きを、整理する。** 副業の契約の終了と、雇用契約の開始。契約の形が変わるので、手続きと法令上の扱いは専門家に確認します。

組み直しは、副業の延長ではなく、新しい採用として行います。求人票に相当する役割の書面と、条件の提示と、内定の流れを踏みます。

### エラベルの見解

相談で最も多い失敗は、「副業の人が良かったので、現場が『社員になりませんか』と立ち話で誘い、本人は『考えます』と言ったまま、副業も気まずくなって離れた」というものです。最初に可能性を置いておらず、役割も条件も無く、責任者も知らず、断りやすさも示していませんでした。副業の契約の段階で「お互いに合えば、社員としてのご相談をすることがあります」と伝え、半年の区切りで責任者が一対一で切り出していれば、本人は考える材料を持てました。

見ていて差がつくのは、担当者が「副業を、見る期間として設計する」かどうかです。「副業の人を紹介します」で終わる担当者と、「副業の役割を、本採用の役割の一部として切り出し、三か月の区切りで、お互いが見るものを決めましょう。本採用の可能性は契約の段階で伝えます」と、最初から設計する担当者がいます。後者は、副業を採用の経路にします。

発注側にできるのは、副業の人に関わってもらう前に、「本採用の可能性があるか」を決めて、あるなら最初に伝えることです。

## 本人の本業との関係

副業の人には、本業があります。本業との関係を、丁寧に扱います。

**本業の就業規則を、本人が確認しているか。** 副業が本業で認められているか、本採用の話をすることに問題が無いか。本人の確認事項ですが、会社としても配慮します。法令上の扱いは専門家に確認します。

**本業を辞める判断は、本人のもの。** 「辞めて来てください」と迫らない。「本業の状況を教えてください」と聞き、本人の判断を待ちます。

**本業の退職の時期に、合わせる。** 引き継ぎ、退職の予告期間。本人の本業に迷惑がかからない時期で。

**本業と並行する期間を、設けられるか。** 本業を辞める前に、副業の時間を増やす、段階的に移る、といった形が取れるか。制度と法令上の扱いは専門家に確認します。

**本業の会社との関係に、配慮する。** 本人が本業の会社と円満に離れられるよう、急がせない。本人の評判は、本人の資産です。

**本業を続ける選択を、尊重する。** 「本業は辞めない、副業のままで」という答えも、尊重します。その場合、副業の関係を続ける設計に戻ります。

本業との関係を雑に扱うと、本人の信頼を失い、本採用も副業も終わります。

## 断られた場合の関係の続け方

本採用を断られることは、あります。関係を続ける設計です。

**断られたら、理由を聞いて、受け入れる。** 「本業を続けたい」「条件が合わない」「時期が合わない」。理由を聞き、無理に翻意させない。

**副業の関係を、そのまま続ける。** 「断られたので副業も終わり」にしない。最初に「断っても副業は続く」と伝えた約束を守ります。

**理由が「時期」なら、時期を改めて話す。** 「いまは本業を辞められないが、一年後なら」という答えなら、一年後に改めて。それまでは副業で。

**理由が「条件」なら、条件を見直せるかを社内で判断する。** 見直せるなら、改めて提示。見直せないなら、副業のまま。

**理由が「働き方」なら、働き方の設計を見直せるか。** 週に三日の社員、リモート中心、といった形が取れるなら、提示。制度と法令上の扱いは専門家に確認します。

**断られた事実を、社内で共有する。** 現場が「なぜ来てくれないのか」と本人に直接聞く状態を避けます。責任者から現場に、「本人の判断で、副業を続けてもらう」と伝えます。

断られても、副業の人が続けてくれるなら、会社にとっては損失ではありません。断り方と、断られ方が、関係を決めます。

## 外注する場合の範囲

副業から本採用につなげる設計を、採用代行に出す場合の範囲です。

**出せる工程。** 副業の契約の段階での可能性の伝え方の文面、副業の役割の切り出し（本採用の役割の一部として）、お互いが見るものの整理、区切りの設計、本採用の役割の書面化、条件の幅の案（既存社員との整合の整理）、切り出しの場の準備（責任者向けの話す型）、本人の希望の聞き取りの型、本業との関係の整理の支援、切り替えの手続きの整理（専門家の確認を経て）、断られた場合の関係の続け方の設計。

**社内に残す判断。** 本採用の可能性を置くかどうかの決定、役割と条件の決定、切り出す時期と誰が切り出すか、既存社員との整合、契約の形の決定、断られた場合の条件の見直しの判断。

**外注の効きどころ。** 副業から本採用は、「最初の設計」と「切り出しの型」で決まります。担当者が契約の段階から設計に入り、区切りごとの振り返りを回し、切り出しの型を責任者に渡せば、社内は判断と対話に集中できます。契約の形の切り替えは、担当者も専門家に確認のうえで進めます。

**外注しても動かない場合。** 責任者が「副業のままでよい」と「本採用にしたい」の間で決めない、現場が勝手に誘う、条件を副業の報酬から換算することを譲らない。社内の判断で、代行を替えても直りません。

副業から本採用は、設計すれば、最も外れの少ない採用です。外注は、設計を最初から入れる手段です。

### エラベルの見解

担当する側から見ると、副業から本採用の相談で最も多いのは、「副業の人に、社員と同じ責任を期待している」ことです。副業は週に数時間で、責任の範囲も限られます。「もっと関わってほしい」「もっと責任を持ってほしい」と感じ始めたら、それは本採用の話をする時期です。副業のまま責任を増やすと、本人は「割に合わない」と感じ、離れます。

「副業の範囲を超えて期待し始めた」を、本採用を切り出す合図にします。副業のまま期待を膨らませない。

発注側にできるのは、副業の人への期待が副業の範囲を超えていないかを、区切りごとに確認することです。超えていれば、切り出す時期です。

## よくある質問

### 副業の契約の段階で、本採用の話をするのは早すぎませんか

早すぎません。「お互いに合えば、社員としてのご相談をすることがあります。その場合も、副業のままを選んでいただけます」と伝えるだけです。約束ではなく、可能性の共有です。最初に伝えておけば、後の切り出しが「最初に話していたこと」になり、本人も想定できます。伝えていないと、後の切り出しが「急な話」になり、本人は驚き、断りにくさと気まずさが生まれます。

### 副業の報酬より、社員の給与のほうが低くなります

副業の時間単価を年収に換算すると、社員の給与と合わないことは多いです。副業の報酬は「時間あたりの成果に対して」、社員の給与は「役割と責任と継続に対して」で、性質が違います。換算せず、自社の役割の幅で提示し、違いを説明します。副業で見えた適性を、幅の中で高めの位置に反映できることもあります。それでも本人が「下がる」と感じて断るなら、副業のままを尊重します。

### 現場が、副業の人に直接「社員になりませんか」と言ってしまいました

責任者が、改めて一対一で話す場を持ちます。「現場からお話があったと思いますが、改めて、会社としてご相談させてください。断っていただいても、副業は続けていただけます」。現場の発言を否定せず、会社としての話に置き直します。役割と条件を書面で用意し、本人の希望を聞き、その場で答えを求めません。今後、現場が直接誘わないよう、責任者から現場に伝えます。
