採用のマネージャーとして、複数の募集を同時に回し、採用の担当者を束ね、媒体と外注先を選び、経営に採用の数字を報告してきた。この経験は、副業で売れるのか。マネージャーの経験は「管理」で、副業で頼まれるのは「作業」のように思え、何を売ればよいかで迷う人が多いところです。結論を先に書くと、**採用マネージャーの経験は、「複数の募集を同時に回し、担当者と媒体と外注先を束ね、採用の数字に責任を持ってきた」型で売れます。売れるのは、「採用の体制の設計」「担当者の育成と指示の型」「媒体と外注先の使い分けの判断」「採用の数字の管理」の四つです。人事の部門が小さい会社では、採用の担当者が一人で、誰にも指示されず、誰にも育てられず、媒体と外注先を自分の感覚で選び、数字を誰にも見せていません。「採用の責任者でした」ではなく、「採用が回る体制を作り、担当者が動ける形にする」と売ります。**人事マネージャー全般の経験の売り方は[人事マネージャー経験を活かす](/media/fukugyo-manager/)に、人事責任者の経験は[人事責任者・CHROが副業でできること](/media/fukugyo-chro-fukugyo/)に、採用代行の経験者の売り方は[採用代行の経験者が副業でできること](/media/fukugyo-rpo-keikensha-fukugyo/)にまとめています。

## この経歴の何が売れるか

採用マネージャーの経験を、依頼側の採用の工程に置き換えた棚卸しです。在籍した会社の採用の内情は含めず、「型」として抜き出します。

| 採用マネージャーの経験 | 依頼側の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 複数の募集を同時に回し、優先順位を決めてきた | 走っている募集を並べ、どれを先に埋め、どれを止め、どれを外に出すかを決める体制の設計 | 全職種を同時に募集して、担当者が一人で溺れている依頼側が多い |
| 採用の担当者を育て、指示してきた | 一人の担当者に、週の動き方、優先順位の付け方、経営者への報告の型を渡す | 担当者が一人で、誰にも教わらず自己流になっている依頼側が多い |
| 媒体と外注先を選び、成果を比べてきた | 「この職種はこの媒体、この工程は外注、これは社内」の使い分けの判断と、外注先の提案の見方 | 媒体と外注先を営業の勧めで選び、比べる軸がない依頼側が多い |
| 採用の数字を管理し、経営に報告してきた | 工程ごとの数字を集め、どこで落ちているかを見せ、経営者と担当者が手を打つ会議の型 | 採用の数字が担当者の頭の中にしかない依頼側が多い |
| 現場の管理職に面接と要件で協力を求めてきた | 管理職が面接に動く分担と、面接の負荷の設計 | 管理職が面接に出ず、選考が止まる依頼側が多い |
| 採用の予算を組み、使い方を決めてきた | 限られた予算で、媒体・外注・紹介にどう配分するかの判断の型 | 予算の配分を考えずに媒体に払い続けている依頼側が多い |
| 採用の失敗を組織として振り返ってきた | 辞退と早期の離職を、要件・選考・条件・受け入れのどこに戻すかの整理 | 失敗が担当者の責任で終わり、仕組みに戻らない依頼側が多い |

売れるものの要点は、「一人の担当者が動ける体制を、外から作れる」ことです。人事の部門が小さい会社では、採用の担当者が一人で、マネージャーがいません。その担当者は、優先順位も、週の動き方も、媒体の選び方も、経営者への報告の仕方も、誰にも教わらずにやっています。採用マネージャーの経験は、その担当者の上に立つのではなく、隣から体制と型を渡し、担当者が自分で回せる形にします。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に、数字の扱いは[数字で語る](/media/fukugyo-suuji/)に書いています。

## 売りにくい点とその扱い

採用マネージャーの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 自分で手を動かすことへの抵抗 | 「マネージャーだった人が、スカウトの送信や日程の調整を自分でやってくれるのか」。自分にとっても、作業に戻ることへの抵抗 | 手を動かす工程を受けるかどうかを、最初に自分で決める。受けないなら分担を示し、受けるなら「体制を作るために最初の一か月は自分で回す」と期間を切る |
| 大きいチームの前提 | 「担当者が何人もいた会社のやり方が、一人の担当者の会社に合うのか」 | チームの管理の話をしない。「担当者一人が週に何をどの順番でやるか」に落とす。体制の設計は「誰が何を」の一枚で済ませる |
| 成果への責任の線 | 「責任者だった人なら、採用の成果に責任を持ってくれるのでは」という期待。自分にとっても、責任を負いたくなる癖 | 採用の成否は依頼側の判断と現場の動きに左右されるので、責任を負う形では受けない。「体制と型を作り、数字で見せる」までを範囲にし、書面で線を引く |

扱い方の要点は、「手を動かす工程を受けるかどうかを、自分で先に決める」ことです。採用マネージャーの経験がある人は、手を動かす工程に戻ることに抵抗があり、その抵抗を曖昧にしたまま案件に入ると、依頼側の期待とずれます。「手は動かさず、体制と型を作る」と決めるなら分担を示し、「体制を作るために最初は自分で回す」と決めるなら期間を切って示します。どちらでも構いませんが、決めずに入らないことです。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、マネージャーの経験と作業の関係は[人事マネージャー経験を活かす](/media/fukugyo-manager/)に整理しています。

### エラベルの見解

担当する側から見ると、採用マネージャーから転身して続いている人と、一件で終わる人の差は、依頼側の採用の担当者を「部下」として見るか、「この案件の主役」として見るかです。一件で終わる人は、前の会社で部下に指示していた癖で、依頼側の担当者に指示を出し、担当者は「外部の人に管理される」と感じて動かなくなり、経営者も「担当者との関係が悪くなった」と感じます。続いている人は、担当者の隣に座り、「今週はこの募集を先に」「経営者にはこの数字を見せると通る」と、担当者が自分で決めたように動ける型を渡します。担当者が「初めて仕事の進め方が分かった」と言い、経営者は担当者の変化を見て契約を続けます。

見ていて差がつくのは、体制の設計を「誰が何を」の一枚で済ませているかです。採用マネージャーの経験がある人は、体制を会議体と役割の一覧で丁寧に設計しがちで、担当者が一人の会社ではそれが重すぎます。「経営者は要件の承認と最終の面接」「担当者は媒体と日程と一次の面接」「現場の管理職は二次の面接と受け入れ」「外注は媒体の運用」と、一枚に「誰が何を」を書き、それだけで回した人は、依頼側から「初めて採用が自分の仕事だと全員が思った」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「採用が回る体制を作り、担当者が動ける形にする」と工程で書いている担当者に、担当者が一人で溺れている依頼側がついています。採用マネージャーの転身は、管理の経験ではなく、担当者を主役にする型から始まります。

## 案件の探し方

採用マネージャーから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 採用の体制の設計（誰が何を） | 体制を作ってきた経験でそのまま入れる | 「担当者が一人で全部やっている依頼側」を探す |
| 一人の担当者の育成と週の型 | 担当者を育ててきた経験で入れる | 「初めて採用担当を置いた依頼側」を探す |
| 募集の優先順位の整理 | 複数の募集を回してきた経験で入れる | 「募集が多くてどれも決まらない依頼側」を探す |
| 媒体と外注先の使い分けと提案の見方 | 媒体と外注先を比べてきた経験で入れる | 「営業の勧めで媒体を選んでいる依頼側」を探す |
| 採用の数字の管理と会議の型 | 数字を管理してきた経験で入れる | 「採用の数字が頭の中にしかない依頼側」を探す |
| 管理職が面接に動く分担 | 現場に協力を求めてきた経験で入れる | 「管理職が面接に出ない依頼側」を探す |

探し方の要点は、「担当者が一人で溺れている会社」から入ることです。採用の担当者が複数いて、マネージャーがいる会社では、採用マネージャーの経験は既存のマネージャーと重なります。担当者が一人で、経営者が直接指示していて、担当者が何から手を付ければよいか分からない会社では、重ならずに効きます。案件の相談で「担当者を採ったが、うまく動けていない」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。採用マネージャーの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 体制の設計の成果物 | 「誰が何を」の一枚と、担当者の週の型は、成果物として形が明確 | 一式の成果物で受ける |
| 担当者の育成の運用 | 週に一度の担当者との打ち合わせは、回数で受けやすい | 週に何回・何分で決める |
| 手を動かす工程を含むかどうか | 含むと稼働が増えて月額は上がるが、体制を作る工程の価値が作業に埋もれる | 含むなら期間を切り、含まないなら分担を示す |
| 成果への責任を負わないこと | 責任を負う形は単価が上がるように見えるが、依頼側の判断に左右され、線が引けない | 「体制と型を作り、数字で見せる」までを範囲に |
| 媒体と外注先の判断の価値 | 予算の配分の判断は、依頼側の支出に直接効き、価値が見えやすい | 「提案の見方」を成果物に |
| 大きい会社の肩書 | 単価の期待は上がるが、担当者が一人の会社では頼みにくくなる | 工程と成果物で示し、肩書で値付けしない |
| 成果報酬の扱い | 採用の成否は依頼側の判断と現場の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「体制の設計は成果物で、担当者の育成は回数で受け、成果への責任を負わない」ことです。採用マネージャーの経験がある人は、責任者だった癖で採用の成果に責任を負いたくなり、依頼側もそれを期待しますが、副業の担当者が採用の成否の責任を負う形は、依頼側の判断と現場の動きに左右されるので、線が引けません。「誰が何を」の一枚と担当者の週の型を成果物で、週の打ち合わせを回数で受け、数字で見せるまでを範囲にします。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

採用マネージャーから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、採用の内情と外注先の契約の守秘の条件を確認する | 個別の判断は専門家に |
| 二、手を動かす工程を受けるかどうかを、自分で決める | 受けないなら分担を示す、受けるなら期間を切る |
| 三、「複数の募集をどう回し、担当者をどう動かし、媒体と外注先をどう比べたか」を、会社の情報を含まない型として書き出す | 優先順位の決め方、週の型、比べる軸 |
| 四、部下に指示する癖を、隣から型を渡す形に変える練習をする | 担当者を主役にする |
| 五、範囲を、体制の設計、担当者の育成、優先順位、媒体と外注先の判断、数字の管理に絞る | 成果への責任は負わない |
| 六、「採用が回る体制を作り、担当者が動ける形にする」の一言を作る | 「採用の責任者でした」で終わらせない |
| 七、「誰が何を」の一枚の見本を、架空の会社で作る | 面談で見せる道具 |
| 八、登録先に、範囲と、成果物の形と、手を動かす工程の扱いを登録する | 担当者が一人で溺れている依頼側 |
| 九、体制の設計か担当者の週の型を一件受け、「担当者が自分で回した週」を残す | 次の工程に広げる材料に |

順番の要点は、「二」の手を動かす工程を受けるかどうかを先に決めることと、「四」の指示する癖を変えることです。採用マネージャーの経験は、部下に指示して動かす形で積まれていて、副業でそのまま出すと、依頼側の担当者を部下として扱ってしまいます。「今週はこの募集を先にやりましょう」ではなく、「今、走っている募集を並べると、どれが一番急ぎだと思いますか」と聞いて、担当者が自分で決めたように動ける形に変える練習を、案件に入る前にしておきます。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、報告の型は[報告のしかた](/media/fukugyo-houkoku/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「採用マネージャーの経験は、担当者が何人もいる会社でしか使えない」というものです。実際には、担当者が一人の会社ほど、その担当者に優先順位も週の型も報告の仕方も教える人がおらず、経営者は「担当者を採ったのに動かない」と感じています。そこで求められているのはチームの管理ではなく、一人の担当者が自分で回せる体制と型で、採用マネージャーの経験はその会社で最も効きます。使えないように見えるのは、チームの管理の言葉で語っているからで、「担当者一人が週に何をどの順番でやるか」に落とせば、人数は関係ありません。

順番として、本業の規定と守秘の条件を専門家に確認し、手を動かす工程を受けるかどうかを決め、募集と担当者と媒体の型を会社の情報を含まずに書き出し、指示する癖を隣から渡す形に変え、範囲を体制と育成と判断と数字に絞り、採用が回る体制を作る一言を作り、誰が何をの一枚の見本を作り、登録先に範囲と形を登録し、一件受けて担当者が自分で回した週を残す。この順番で、採用マネージャーの経験は「大きいチームの管理」から「一人の担当者を動ける形にする工程」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、体制と型の工程を明確にし、手を動かす工程の扱いと成果への責任の線を示している担当者に、担当者が一人で溺れている依頼側がついています。採用マネージャーの転身は、管理の経験ではなく、担当者を主役にする型から始まります。

## まとめ

- 採用マネージャーの経験は**「複数の募集を同時に回し、担当者と媒体と外注先を束ね、採用の数字に責任を持ってきた」型**で売れる。**体制の設計・担当者の育成・媒体と外注先の判断・数字の管理**の四つ
- **「採用の責任者でした」ではなく「採用が回る体制を作り、担当者が動ける形にする」**と売る
- 売りにくい点は**手を動かすことへの抵抗・大きいチームの前提・成果への責任の線**。受けるかどうかを先に決め、「誰が何を」の一枚に落とし、責任を負う形では受けない
- 案件は**担当者が一人で溺れている会社**から。「担当者を採ったが動けていない」が入り口
- 単価は**体制の設計は成果物、育成は回数**で。成果への責任を負わない。成果報酬は最初は避け、可否は専門家に確認
- 依頼側の担当者を**部下ではなく主役**として扱う。指示ではなく、自分で決めたように動ける型を渡す

## よくある質問

### 依頼側の担当者が、私の言うことを聞いてくれません。マネージャーとして指示する立場ではないので、どうすればよいですか

指示する立場ではないので、指示は聞かれなくて当然です。担当者が動かないのは、外部の人に管理されることへの抵抗と、自分の仕事のやり方を否定された感覚から来ていることが多いです。「今、一番困っていることは何ですか」から聞き直し、担当者が困っている一点を一緒に解く形に変えます。担当者が「助かった」と感じた後に、週の型や優先順位の話を、担当者の言葉で一緒に決めます。経営者に「担当者が動かない」と報告する前に、担当者との関係を作り直すほうが、案件は続きます。聞き取りの磨き方は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)に、改善の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

### 前の会社で使っていた外注先や媒体の担当者を、依頼側に紹介してよいですか

前の会社との契約の中で知った外注先の条件や実績の情報は、前の会社のものであり、守秘の条件に関わります。紹介するなら、公開されている情報と、依頼側が自分で問い合わせる形にし、前の会社の契約の条件や値引きの情報は持ち込みません。紹介の見返りを外注先から受ける形は、依頼側との利益相反になるので避けます。個別の判断は、弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### 経営者から「採用の成果に責任を持ってほしい」と言われました。責任者の経験があるので、受けてよいですか

採用の成否は、依頼側の要件と条件と現場の管理職の動きに左右され、副業の担当者が責任を負う形では線が引けません。「体制と型を作り、数字で見せ、手を打つ判断の材料を出すところまでを、私の責任として持ちます。採用の成否は、御社の判断と現場の動きで決まります」と、責任の線を書面で示します。責任を負う形で受けて、依頼側の判断で決まらなかったときに、関係も単価も崩れます。成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
