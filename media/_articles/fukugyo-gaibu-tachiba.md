副業の人は、社内の人事と比べて、できないことが多い。権限が無い、社内の関係が無い、稼働が週に数時間、社内の事情を知らない。これを制約とだけ見ると、「社内の人事の劣化版」として動くことになり、価値が出ません。ただ、外部であることは、社内の人事にはできない動きを可能にもします。結論を先に書くと、**外部の立場だからできることは「前提を問い直せる」「数で見られる」「型を持ち込める」「他社の経験で相対化できる」「関係に縛られず線を引ける」の五つで、これを社内の人事の補完として出すと、副業の人にしか出せない価値になります。**出しすぎると反発されるので、出し方には型があります。担当との分担は[社内の人事担当との役割分担](/media/fukugyo-shanai-jinji/)に、踏み込みすぎない線は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)にまとめています。

## 制約と強みは同じ源から来る

外部の制約と、外部の強みは、同じ性質の裏表です。並べて見ると、制約を強みに読み替えられます。

| 外部の性質 | 制約として見ると | 強みとして見ると |
|---|---|---|
| 社内の前提を知らない | 説明が要る。空気が読めない | 前提を問い直せる。「なぜそうしているのか」を聞ける |
| 社内の関係が無い | 現場に直接頼めない | 関係に縛られず、線を引ける。誰にも遠慮しなくてよい |
| 稼働が短い | 全部はできない | 数で見るしかないので、数で見る習慣が付く |
| 他社の経験がある | 社内の事情に合わない型を持ち込む危険 | 他社の経験で、社内の当たり前を相対化できる |
| いずれ終わる | 続けられない | 型にして残すしかないので、型が残る |
| 利害が無い | 社内の評価に関わらない | 社内の評価を気にせず、事実を言える |

源の要点は、「制約を消そうとすると、強みも消える」ことです。社内の人事のように振る舞おうとして前提を学び、関係を作り、遠慮を覚えると、外部の強みが無くなります。制約を受け入れたまま、強みを出します。

## 五つの強みと、効く場面

五つの強みを、それぞれどんな場面で効くか、どう出すかで整理します。

| 強み | 効く場面 | 出し方 |
|---|---|---|
| 一 前提を問い直せる | 「ずっとこうしている」が採用を止めているとき。要件、選考の流れ、媒体の選び方 | 「なぜこの流れですか」と、責めずに聞く。聞かれて初めて、依頼側が理由の無さに気づく |
| 二 数で見られる | 「応募が来ない」「合わない人ばかり」など、感覚で語られているとき | 段階ごとの数と日数を並べる。[現状把握のしかた](/media/fukugyo-genjou-haaku/) |
| 三 型を持ち込める | 文面、基準、記録の型が無く、担当が毎回考えているとき | 一般化した型を「たたき台」として出す。押しつけない |
| 四 他社の経験で相対化できる | 「うちは特殊だから」で改善が止まっているとき | 「他の会社でも同じ状況がありました」と、社名を出さずに一般化して。特殊でないことを示す |
| 五 関係に縛られず線を引ける | 現場と人事、経営者と担当で意見が違い、社内では言いにくいとき | 両方を並べて書面にし、判断する人に上げる。どちらの味方もしない |

効く場面の要点は、「四で、社名を出さずに一般化する」ことです。他社の経験は、外部の人の最大の材料ですが、社名や内情を出すと、前の依頼側の情報を漏らすことになります。「同じ規模の会社で」「同じ職種の採用で」と一般化して、経験の型だけを出します。[情報の取り扱いと端末の分離](/media/fukugyo-security/)を参照してください。

### エラベルの見解

登録の相談で多いのは、「社内の人事と同じことをしているだけで、自分が入る意味があるのか分からない」という声です。話を聞くと、担当の型に沿って実行し、担当の判断を待ち、担当を通して動いている。分担としては正しいのですが、外部の強みを出していません。実行だけなら、社内で人を増やせば済みます。

見ていて差がつくのは、「実行を担いながら、外部の目で見たことを、区切りで一つ出しているか」です。「実行していて気づいたのですが、書類確認が十日かかっていて、そこで候補者が離れています。この流れは、なぜこうなっていますか」。前提を問い直す一言が、依頼側にとっては、社内の誰からも聞けなかったことです。エラベルの登録でも、依頼側から「外部の目が入ってよかった」と言われる人は、実行の分担を守りながら、区切りで外部の目を一つ出しています。

## 強みを出す手順

五つの強みを、反発されずに出す手順を、番号付きで整理します。

1. **最初の一か月は、出さない。** 把握と実行に徹する。外部の目は、実態を見てから出す。
2. **数で見たことを、先に出す。** 前提を問い直す前に、数を並べる。「書類確認に十日かかっています」。数は誰の意見でもない。
3. **前提を問い直すときは、質問の形で。** 「この流れは、なぜこうなっていますか」。「変えるべきです」と言わない。
4. **型は、たたき台として出す。** 「他の会社で使っていた型を、一般化したものです。御社に合わせて直してください」。
5. **他社の経験は、一般化して、社名を出さず、一つだけ。** 多く出すと「よそはよそ」と反発される。
6. **意見の違いは、両方を並べて、判断する人に。** 自分の意見を足さない。
7. **区切りで、一つだけ出す。** 五つを全部出さない。一つ出して、依頼側の反応を見る。
8. **受け入れられなければ、引く。** 外部の目は、提案であって決定ではない。決めるのは依頼側。

手順の要点は、「二で、数を先に出す」ことです。外部の人の意見は、それだけでは「よそ者の口出し」と受け取られます。数を先に出すと、意見ではなく事実の話になり、依頼側は受け取れます。

## 強みを出しすぎて反発される失敗

外部の強みは、出し方を誤ると反発を生みます。失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 最初の週から前提を問い直す | 実態を見る前に意見を言う | 一か月は把握と実行 |
| 「変えるべきです」と言う | 質問ではなく主張 | 質問の形で。「なぜですか」 |
| 型を持ち込んで置き換える | 自分の型が正しいと思う | たたき台。担当の型を土台に |
| 「前の会社では」を繰り返す | 他社の経験を出しすぎる | 一般化して一つだけ。社名を出さない |
| 現場と人事の間で、どちらかの味方をする | 正しいと思う側に立つ | 両方を並べて判断する人に |
| 数を出さずに意見を言う | 経験で分かるつもり | 数を先に |
| 五つを全部出す | 価値を示したい | 区切りで一つ |
| 受け入れられなくて食い下がる | 正しいと思う | 引く。決めるのは依頼側 |
| 社内の事情を知らないまま断言する | 外部の目を過信 | 「社内の事情が分からないので、違っていたら教えてください」を添える |
| 外部の強みを出そうとして、実行が疎かになる | 提案に時間を使う | 実行が土台。強みは区切りに一つ |

失敗の要点は、「外部の強みは、実行の分担を守った上で、区切りに一つ」ということです。実行が疎かで意見だけ言う外部の人は、依頼側から見て最も価値が低い。

## 社内の人事との補完

外部の強みは、社内の人事の弱みを補う形で出すと、最も受け入れられます。補完の形を整理します。

| 社内の人事が持つもの | 社内の人事に無いもの | 外部の人が補うもの |
|---|---|---|
| 社内の前提と事情 | 前提を疑う機会 | 前提を問い直す質問 |
| 感覚と経験 | 数で見る時間 | 段階ごとの数と日数 |
| 自社の型 | 他社の型を知る機会 | 一般化した型のたたき台 |
| 「うちは特殊」という認識 | 他社との比較 | 「同じ状況は他にもある」という相対化 |
| 社内の関係 | 関係に縛られない発言 | 両方を並べた書面 |

補完の要点は、「社内の人事が持つものを否定しない」ことです。社内の前提、感覚、自社の型は、外部の人には無い財産です。それを土台に、無いものを足す。「御社の型を土台に、他社の型を一つ足すと」という出し方が、補完の形です。

## 外部の立場を保つ工夫

長く続くほど、外部の人は社内に近づき、外部の強みが薄れます。保つ工夫を整理します。

| 工夫 | 内容 |
|---|---|
| 社内の前提を「そういうものか」で終わらせない | 慣れてきたら、慣れたことを記録する。「なぜ」を持ち続ける |
| 数を出し続ける | 感覚で分かるようになっても、数で見る習慣を止めない |
| 別の依頼側を一つ持つ | 一つの会社に長くいると、その会社の常識が自分の常識になる。[複数案件の掛け持ち](/media/fukugyo-fukusuu-anken/) |
| 一般化した型を更新し続ける | いまの依頼側の型を、一般化して自分の側に |
| 社内の人間関係に入らない | 社内の派閥、評価、噂に関わらない |
| 区切りで、外部の目を一つ出す習慣を保つ | 慣れても、区切りに一つ |

工夫の要点は、「別の依頼側を一つ持つ」ことです。一社だけに長くいると、外部の立場が薄れます。もう一社を持つと、相対化の材料が更新され、外部の目が保たれます。

### エラベルの見解

担当する側として登録した人の話を聞くと、依頼側から「外部の目が入ってよかった」と言われる人は、外部の強みを「区切りに一つ」出す習慣を持っています。実行の分担を守り、数を出し、区切りで前提を一つ問い直す。依頼側にとっては、社内では誰も言わなかったことを、数と一緒に、質問の形で聞かれる経験です。反発は起きず、依頼側は考え始めます。

依頼側から見ると、副業の人に期待しているのは、社内の人事の代わりではなく、社内に無い視点です。エラベルは、企業と担当者の間に立つ窓口として、依頼側に「副業の人事に期待できること」をお伝えするとき、実行の手だけでなく、外部の目も含めています。制約を受け入れたまま強みを出す型を持っていただくと、副業の人にしか出せない価値になります。

## まとめ

- 外部の制約と強みは**同じ源**。制約を消そうとすると強みも消える
- 五つの強みは**前提を問い直せる・数で見られる・型を持ち込める・他社の経験で相対化できる・関係に縛られず線を引ける**
- 出す手順は**一か月は出さない→数を先に→質問の形で→たたき台として→一般化して社名を出さず一つだけ→両方を並べて判断する人に→区切りで一つ→受け入れられなければ引く**
- 失敗は**最初から出す・主張する・置き換える・「前の会社では」を繰り返す・味方をする・全部出す・食い下がる・実行が疎か**
- 社内の人事が持つものを**否定せず、無いものを足す**補完の形
- 外部の立場を保つには**「なぜ」を持ち続け、数を出し続け、別の依頼側を一つ持つ**

## よくある質問

### 前提を問い直したら、担当が「そういうものなので」と流しました

一度流されても、引きます。外部の目は提案で、決めるのは依頼側です。ただ、流された前提が数に出ているなら、区切りで数と一緒にもう一度、質問の形で出します。「書類確認の日数が、この一か月も十日のままで、その間に辞退が三件ありました。この流れは変えられないものですか」。数が積み重なると、「そういうもの」では流せなくなります。二回出して流されたら、それはその会社の決定で、自分の範囲の中で回る形に集中します。

### 他社の経験を話すと、前の依頼側の情報を漏らすことになりませんか

社名、数値、時期、個人名、内情を出さず、型と状況だけを一般化して話せば、漏らすことにはなりません。「同じ規模の事業会社で、書類確認の日数が長くて辞退が出ていたことがあり、判断の目安を三営業日にしたら減りました」は、一般化した経験です。「〇〇社では」「月に五十件の応募で」は、特定につながります。迷ったら、より広く一般化するか、話しません。他社の経験を出すのは、区切りに一つで足ります。

### 長く続けているうちに、社内の人のような感覚になってきました

外部の強みが薄れている兆候です。三つのことを試してください。一つ、いまの依頼側の前提で「なぜ」と思わなくなったことを書き出す。それが、慣れてしまった前提です。二つ、数を出す習慣を戻す。感覚で分かるつもりでも、数で見ると違うことがあります。三つ、別の依頼側を一つ持つ。相対化の材料が更新され、いまの依頼側を外から見られるようになります。社内の人のような感覚は、関係が良い証拠でもありますが、外部の価値とは別のものです。
