半年、採れていない。応募が少ないからなのか、書類で落としすぎているのか、面接で落ちているのか、内定を出しても辞退されているのか。「全部が問題」に見えて、何から直せばよいか分からない。媒体を足すべきか、要件を緩めるべきか、条件を上げるべきか、判断できない。結論を先に書くと、**採用ファネルの詰まりは、段階ごとの「数」と「日数」を一枚に並べれば、一か所に見えます。全部が問題に見えるのは、並べていないからです。並べれば、「応募は来ているが書類で九割落としている」「面接には進むが内定後に辞退されている」のように、詰まりは一か所か二か所に絞れます。絞れれば、直す先が決まります**。数字の取り方は[採用の数字が取れていない](/media/rpo-data-nai/)に、KPIの置き方は[採用KPIに何を置くべきか](/media/rpo-kpi-erabenai/)にまとめています。

## 詰まりが見えない構造

ファネルのどこが詰まっているか見えないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 段階ごとの数を数えていない | 「応募が何件、面接が何件」が無い。「採れていない」の一言で終わる |
| 日数を見ていない | 数は数えても、各段階に何日かかっているかを見ていない。速さの詰まりが見えない |
| 段階の切り方が曖昧 | 「選考中」が一括り。書類なのか、一次なのか、最終なのかが分かれていない |
| 「全部が問題」と思っている | 応募も少ないし、面接も弱いし、辞退もある。全部に手を付けて、どれも中途半端 |
| 感覚で詰まりを決めている | 「応募が少ないから媒体を足そう」を、数字を見ずに決めている |
| 求人ごとに分けていない | 複数の求人をまとめて見て、求人ごとの詰まりが混ざる |
| 見る場が無い | 数字があっても、月に一度並べて見る場が無い |

詰まりは、見れば見えます。見ていないだけです。

## ファネルの段階の切り方

段階を、自社の選考の流れに合わせて切ります。

| 段階 | 数えるもの | 日数 |
|---|---|---|
| 応募 | 応募が来た数（経路ごと） | — |
| 受付 | 受付の返信を出した数 | 応募から返信まで |
| 書類 | 書類を通した数／落とした数 | 応募から判断まで |
| 一次面接 | 一次を設定した数／実施した数／通した数／辞退した数 | 判断から面接まで |
| 二次面接 | 同上 | 一次から二次まで |
| 最終面接 | 同上 | 二次から最終まで |
| 内定 | 内定を出した数／承諾した数／辞退した数 | 最終から内定まで、内定から返事まで |
| 入社 | 入社した数／内定後の辞退の数 | 承諾から入社まで |

段階の切り方の要点は、「自社の流れに合わせる」ことと、「各段階で辞退の数を分けて数える」ことです。「一次を通さなかった」と「一次の前に辞退された」は、直す先が違います。

面談（カジュアル面談）がある場合は、「面談→応募」を最初に足します。

## 段階ごとに数と日数を並べる型

段階ごとの数と日数を、一枚に並べます。

**縦に段階、横に「数」「通過の率」「辞退の数」「日数」。** 求人ごとに一枚。月に一度。

**通過の率は、前の段階に対して。** 「書類を通した数÷応募の数」「一次を通した数÷一次を実施した数」。段階ごとの率が、詰まりの目安です。

**辞退の数は、段階ごとに。** 「一次の前に辞退」「内定の後に辞退」。辞退の理由も添えます。

**日数は、平均と最長。** 平均が目安を超えていれば遅い。最長が極端なら、特定の候補者が放置されています。

**経路ごとにも並べる。** 応募・書類通過・面接・内定を、経路ごとに。経路によって、詰まる段階が違うことがあります。

**先月の数字を、隣に置く。** 変化が見えます。

一枚の型ができれば、毎月同じ形で出せ、比べられます。数字の取り方は[採用の数字が取れていない](/media/rpo-data-nai/)に書いています。

## 詰まりの読み方と直す先

一枚を見て、詰まりを読み、直す先を決めます。

| 詰まりの兆候 | 読み方 | 直す先 |
|---|---|---|
| 応募が極端に少ない | 経路か求人票が届いていない | 媒体の見直し、求人票の一行目、知名度の代わりの材料。[どの媒体を使えばよいか分からない](/media/rpo-media-erabenai/) |
| 応募はあるが、書類で九割落ちる | 要件に合わない応募が来ている。求人票の要件が伝わっていないか、経路が合っていない | 要件の書き方（必須とあれば良い）、経路の見直し。[必須要件と歓迎要件の線が引けない](/media/rpo-must-want/) |
| 書類は通るが、一次の前に辞退が多い | 応募から面接までが遅い、案内が雑 | 返信と日程の速さ、案内の中身。[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/) |
| 一次で大半が落ちる | 書類の判断と面接の観点がずれている。または面接官が厳しすぎる | 書類の基準と面接の観点の対応、面接官の基準。[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/) |
| 一次は通るが、二次・最終で落ちる | 段階ごとの観点が重複しているか、責任者の基準が別 | 段階ごとの観点の分け方、責任者の基準の言語化 |
| 最終まで進むが、内定を辞退される | 条件、速さ、訴求、他社との比較 | 年収のすり合わせ、内定までの速さ、動機づけ。[年収交渉で毎回折り合わない](/media/rpo-nenshu-kousho/) |
| 内定を承諾したが、入社前に辞退 | 承諾から入社までの接点が無い、他社の内定 | 承諾後の接点、入社までの連絡 |
| 各段階の日数が長い | 面接官の判定が遅い、日程が組めない | 判定の期限、面接の枠の先押さえ |

読み方の要点は、「率が最も低い段階」と「日数が最も長い段階」を探すことです。その二つが、詰まりです。

詰まりが一か所なら、そこだけ直します。二か所なら、上流（応募に近いほう）から直します。上流を直さずに下流を直しても、下流に流れてくる人が変わらないからです。

### エラベルの見解

相談で最も多い失敗は、「採れていないので、媒体を二つ足し、要件を緩め、年収を上げた。三つ同時に変えて、応募は増えたが、内定後の辞退は変わらず、何が効いたか分からなかった」というものです。段階ごとに並べると、応募は足りていて、書類も一次も通っていて、詰まりは「内定後の辞退」の一か所でした。辞退の理由は「他社の条件」より「内定までの日数」。最終から内定まで二週間かかっていました。内定の判断を三日にしたら、辞退が減りました。媒体も要件も、変える必要はありませんでした。

見ていて差がつくのは、担当者が「一枚に並べてから提案する」かどうかです。「応募を増やしましょう」と最初に言う担当者と、「段階ごとの数と日数を並べました。詰まりは内定後の辞退で、日数が原因です。まずここを」と、並べてから絞る担当者がいます。後者は、変えなくてよいものを変えません。

発注側にできるのは、担当者に「何を直すか」の前に「段階ごとの一枚」を出してもらうことです。

## 複数の求人の見方

複数の求人が動いている場合の見方です。

**求人ごとに、一枚を分ける。** まとめて見ると、求人ごとの詰まりが混ざります。営業職は応募が少なく、事務職は内定後の辞退が多い、のように、詰まりは求人で違います。

**共通の詰まりを探す。** 全部の求人で日数が長いなら、選考の運用（判定の期限、日程の枠）の問題で、求人ごとではなく全体で直します。

**求人ごとに違う詰まりは、求人ごとに直す。** 営業職は経路、事務職は内定の速さ、のように。

**優先順位を付ける。** 全部の求人を同時に直さず、「採れないと最も困る求人」から。優先順位の付け方は[とりあえず募集を出しているだけになっている](/media/rpo-toriaezu-boshu/)に書いています。

**経路ごとの一枚も、求人ごとに。** 「この求人は紹介会社から面接に進む人が来ているが、媒体からは来ていない」のように、求人と経路の組み合わせで見ます。

複数の求人を見る要点は、「まとめない」ことです。まとめると、平均されて詰まりが見えなくなります。

## 詰まりを直した後の確認

詰まりを直したら、効果を確認します。

**翌月の一枚で、直した段階の率と日数を見る。** 「内定後の辞退が三件から一件に」「最終から内定までの日数が二週間から三日に」。数字で。

**一つだけ変えて、一つだけ見る。** 同時に複数を変えると、何が効いたか分かりません。詰まりが一か所なら、一つだけ変えます。

**三か月、同じ形で見る。** 一か月の変動は、たまたまのことがあります。三か月で傾向を見ます。

**直した段階が改善したら、次の詰まりを探す。** 詰まりが一つ解消すると、次の段階の詰まりが見えてきます。「内定後の辞退が減ったら、今度は最終で落ちる率が目立つ」のように。

**変えたことと、結果を記録する。** 「〇月に内定の判断を三日にした→内定後の辞退が減った」。次の求人で使えます。

**改善しなければ、詰まりの読みが違う。** 直しても変わらないなら、その段階が詰まりではなかったか、直し方が違ったか。一枚を見直します。

確認の要点は、「変えたことを、翌月の数字で見る」ことです。見なければ、直したかどうか分かりません。

## 外注する場合の範囲

ファネルの詰まりが見えない問題を、採用代行に出す場合の範囲です。

**出せる工程。** 段階の切り方の設計（自社の流れに合わせて）、段階ごとの数と日数の集計、一枚の作成（求人ごと、経路ごと、先月との比較）、詰まりの読みと直す先の案、辞退の理由の聞き取りと分類、直す先の実行（速さの改善、求人票の直し、経路の見直しなど、範囲は別途）、翌月の確認、変えたことと結果の記録、複数の求人の優先順位の案。

**社内に残す判断。** 段階の切り方の承認、直す先の決定、要件や条件を変える判断、求人の優先順位の決定、面接官の基準の決定。

**外注の効きどころ。** 詰まりが見えない会社は、「並べる人」がいません。担当者が段階ごとの一枚を毎月出し、詰まりを読み、直す先を絞れば、「全部が問題」は「一か所の問題」になります。担当者は複数の会社のファネルを見ているので、「この兆候ならこの段階」の読みを持ち込めます。ただし、他社の率を自社の目標にはしません。

**外注しても動かない場合。** 責任者が一枚を見ない、詰まりが見えても直す先を決めない、面接官が判定を出さず数字が取れない。社内の判断で、代行を替えても直りません。

詰まりは、並べれば見えます。外注は、並べる人を置く手段です。

### エラベルの見解

担当する側から見ると、ファネルの相談で最も多いのは、「率だけ見て、日数を見ていない」ことです。「一次の通過率が低い」と言うので見ると、一次を通した人は多く、一次の前に辞退した人が多い。辞退の理由は、応募から面接まで三週間かかっていたこと。率の問題ではなく、日数の問題でした。

数と率だけでは、「落とした」と「辞退された」が混ざります。辞退を分けて数え、日数を並べると、「落としているのではなく、待たせて逃している」が見えます。

発注側にできるのは、一枚に「辞退の数」と「日数」の列を、必ずしも率だけでなく入れることです。

## まとめ

- 見えないのは**段階ごとの数が無い・日数を見ない・段階が曖昧・全部が問題に見える・感覚で決める・求人ごとに分けない・見る場が無い**構造
- 段階は**応募・受付・書類・一次・二次・最終・内定・入社**を自社の流れで切り、各段階で辞退を分けて数える
- 一枚は**縦に段階・横に数と率と辞退と日数・経路ごとにも・先月を隣に**。求人ごとに、月に一度
- 読み方は**率が最も低い段階と日数が最も長い段階**が詰まり。兆候ごとに直す先が決まる。一か所ならそこだけ、二か所なら上流から
- 複数の求人は**まとめず求人ごとに・共通の詰まりは全体で・違う詰まりは求人ごとに・優先順位・経路も求人ごとに**
- 直した後は**翌月の一枚で見る・一つだけ変えて一つだけ見る・三か月で傾向・次の詰まりを探す・記録・改善しなければ読みを見直す**
- 外注できるのは**段階の設計・集計・一枚・読みと直す先・辞退の聞き取り・実行・確認・記録・優先順位**。社内に残るのは**承認・直す先の決定・要件と条件の判断・優先順位・面接官の基準**

## よくある質問

### 応募が少ないので、まず媒体を足すべきですか

段階ごとの一枚を出してから決めます。応募が少なくても、来ている応募が書類と面接を通って内定まで進んでいるなら、詰まりは応募の段階で、媒体や求人票を直す判断です。応募が少なく、かつ書類で九割落ちているなら、応募の数より質の問題で、要件の書き方や経路の見直しです。応募は足りていて内定後に辞退されているなら、媒体を足しても意味がありません。並べる前に足すと、変えなくてよいものを変えます。

### 全部の段階で、少しずつ詰まっています

「少しずつ」は、並べて見ると、一か所か二か所が目立つことが多いです。率が最も低い段階と、日数が最も長い段階を探します。本当に全部が同じくらいなら、共通の原因（選考の運用の速さ、担当がいない）があります。その場合は、段階ごとではなく、運用全体（返信の期限、判定の期限、日程の枠）を直します。全部に少しずつ手を付けるより、共通の原因を一つ直すほうが効きます。

### 一次の通過率が低いのは、面接官が厳しいからですか

「一次を通さなかった」と「一次の前に辞退された」を分けて数えます。落としているなら、面接官の基準か、書類の判断との対応のずれです。辞退されているなら、応募から面接までの日数か、案内の雑さです。混ざったまま「面接官が厳しい」と決めると、直す先を間違えます。日数と辞退の理由を見てから、判断します。
