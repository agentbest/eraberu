社員インタビューの記事を頼まれて、「入社のきっかけは」「やりがいは」「会社の魅力は」「今後の目標は」と聞き、その順に書くと、読み手には「どの会社の記事にもある」文章になります。候補者は、社員の「やりがい」を知りたいのではなく、「自分がこの会社に入ったら、実際どうなるか」を知りたい。それに答える社員の言葉は、「やりがいは」では出てきません。結論を先に書くと、**社員インタビューは、この記事が答える候補者の迷いを一つ決め、その迷いに近い経験の社員に、五つの問い（最初の三か月・前の会社と違うこと・一日の時間・自分で決めた場面・辞めようと思ったこと）で場面を掘って聞き、迷いへの答えを先頭に本人の言葉のまま一枚にし、本人の確認と依頼側の承認を経て、私的な情報を載せず、盛らずに公開します。**企画の立て方は[採用広報の企画を立てる](/media/fukugyo-skill-koho-kikaku/)に、記事の執筆を案件として受ける形は[採用広報の記事執筆の副業の実務](/media/fukugyo-saiyo-koho-fk-shigoto/)に書いています。ここでは、一本を書く型に絞ります。

## 「やりがい」を聞くと他社にも書ける言葉になる

| 聞く問い | 返ってくる言葉 | 候補者に起きること |
|---|---|---|
| 「やりがいは」 | 「お客様に喜ばれること」「成長を感じること」 | どの会社でも同じ。読み飛ばす |
| 「会社の魅力は」 | 「風通しが良い」「挑戦できる」 | 実態が分からない |
| 「入社のきっかけは」 | 「理念に共感して」 | 準備された答え |
| 「今後の目標は」 | 「もっと成長したい」 | 判断の材料にならない |

問いが抽象なら、答えも抽象です。場面を聞けば、答えは実態になります。

## 答える迷いを先に一つ決める

| 候補者の迷い（ターゲット像から） | この記事で答えること | 聞く相手 |
|---|---|---|
| 「裁量は本当にあるのか」 | 自分で決めて進めた場面 | 入社二〜三年目で、案件を一人で持っている人 |
| 「小さい会社に移って次の転職で不利にならないか」 | 前の会社と違うこと、ここで得た経験 | 大手から移ってきた人 |
| 「入ってすぐ何をするのか」 | 最初の三か月 | 入社一年以内の人 |
| 「一緒に働く人はどんな人か」 | 一日の時間、誰と何をしているか | 現場の中心の人 |

一本で一つの迷いに答えます。全部に答えようとすると、どれも薄くなります。迷いはターゲット像の「迷う理由」の欄から選びます。ターゲット像の作り方は[ターゲット像を1枚にまとめる](/media/fukugyo-skill-persona/)に書いています。

### エラベルの見解

担当する側から見ると、社員インタビューで最も差がつくのは、「聞く相手を、答える迷いから選ぶ」ができるかです。受ける側は、依頼側が指名した「話が上手い人」「会社を好きな人」に聞きます。話は上手くても、候補者の迷いに答えられる経験を持っていなければ、記事は一般論になります。「裁量」に答えるなら、実際に自分で決めて動いた人。「次の転職」に答えるなら、大手から移ってきた人。迷いから相手を選ぶと、話が上手くなくても、場面が出ます。エラベルで担当者を選ぶ企業には、「インタビューの相手は、候補者の迷いから選んでいますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、依頼側が相手を指名してきたら、「この記事はどの迷いに答えますか」を先に決め、その迷いに合う経験の人かを確かめること。合わなければ、答える迷いを変えるか、相手を変えます。

## 五つの問い

| 問い | 出てくるもの |
|---|---|
| 入った頃、最初の三か月で何をしましたか | 入社直後の実態。誰と何を引き継いだか |
| 前の会社と、一番違うことは何ですか | 他社との差。良いことも、戸惑ったことも |
| いま、一日の時間を何に使っていますか | 仕事の実態。会議と作業の比率、誰と話しているか |
| 決まりの無いことを、自分で決めて進めた場面を一つ教えてください | 裁量の実態 |
| 辞めようと思ったことはありますか。そのとき、なぜ残りましたか | 迷いと、その解消。候補者が最も知りたいこと |

五つを全部聞いても、記事に載せるのは答える迷いに関わる部分です。残りは、次の記事の材料になります。五つ目は、依頼側が「載せたくない」と言うことがありますが、候補者にとって最も信頼できる部分です。載せるかどうかは、本人と依頼側の判断です。

## 聞き方は場面を掘る

| 掘る問い | 例 |
|---|---|
| 状況 | 「そのとき、どういう状況でしたか」 |
| 役割 | 「その中で、あなたが担当していたのは」 |
| 判断 | 「なぜ、そう進めようと思いましたか」 |
| 行動 | 「具体的に、誰に何をしましたか」 |
| 結果 | 「どうなりましたか。いまなら、どうしますか」 |

一般論が返ってきたら、「たとえば、どんな場面ですか」と一つに絞ります。掘り方は面接の質問集の型と同じで、[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)に書いています。インタビューは面接ではないので、評価はせず、場面を引き出すことに徹します。

## 書く構造

| 部 | 中身 |
|---|---|
| 先頭 | この記事が答える迷いと、本人の一言（結論） |
| 場面 | 五つの問いのうち、迷いに関わる場面を一つか二つ。状況・役割・判断・行動・結果の順 |
| 本人の言葉 | 書き起こしのまま。担当者の言葉に直さない。整えるのは重複と言い淀みだけ |
| 実態のまま | 良いことだけでなく、戸惑ったこと、大変だったことも本人の言葉で |
| 末尾 | 「こういう人に向いている」を本人の言葉で。会社の宣伝は書かない |

会社紹介、理念、制度の説明は、この記事には書きません。それは採用サイトの別のページに置きます。記事は「一人の社員の、一つの迷いへの答え」で足ります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「インタビューの記事は、良いことだけを書くもの」というものです。実際には、「戸惑ったこと」「辞めようと思ったこと」が書かれている記事のほうが、候補者は信頼し、面接で「あの記事を読んで」と言います。良いことだけの記事は、「どうせ良いことしか書かない」と読まれ、迷いに答えません。本人が話した戸惑いを、本人の言葉のまま載せ、それがどう解消されたかまで書く。載せるかは本人と依頼側の判断ですが、担当者は「載せたほうが候補者に届く」と構造で伝えます。受ける側がその場で使える判断としては、原稿に「大変だったこと」の段落が無ければ、五つ目の問いに戻って聞き直すこと。

## 本人の確認と依頼側の承認

| 順 | 中身 |
|---|---|
| 一 | 書き起こしを本人に渡し、「言った覚えのないこと」「載せたくないこと」を消してもらう |
| 二 | 原稿を本人に渡し、修正の権利があることを伝える。本人の修正は原則そのまま受ける |
| 三 | 現場の責任者に、「実態と合っているか」を確認。盛りがあれば外す |
| 四 | 依頼側の人事に、載せてよい範囲（社内の情報、他の社員に触れる部分）を確認 |
| 五 | 表記の可否を依頼側の決まりと専門家で確認（必要なとき） |

本人が「載せたくない」と言った部分は、理由を聞かずに消します。本人の氏名と顔写真を出すかは本人の意向で、出さない場合は「〇〇の役割・入社〇年目」の形にします。公開後に「消してほしい」と言われたときの扱いは、依頼側の決まりで先に決めておきます。

## 載せないこと

| 載せない | 理由 |
|---|---|
| 本人の私的な情報（家族、健康、住まいの詳細） | 本人の同意があっても最小に。募集や採用で法令上の決まりがあると一般に整理されている項目にも関わる |
| 他の社員や取引先を特定できる話 | 第三者の権利 |
| 社内の機密（顧客名、数字、開発中のもの） | 守秘。依頼側の承認の範囲で |
| 収入や昇進を保証するように読める表現 | 保証できない。本人の例は例として |
| 担当者が作った言葉 | 本人の言葉でないものは、本人の記事ではない |
| 前の会社の批判 | 本人と依頼側の信用に関わる |

表記の可否に法令が関わる場合は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)と[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「やりがい」の項目を求める | 「候補者の迷いに答える」目的を伝え、五つの問いの答えの中から「やりがい」に当たる場面を拾う形に |
| 本人が一般論しか話さない | 「たとえば」で一つの場面に絞る。状況から順に掘る |
| 本人の言葉を担当者が整えすぎる | 書き起こしに戻る。整えるのは重複と言い淀みだけ |
| 戸惑いや大変だったことが無い | 五つ目の問いに戻る。本人が話さなければ無理に載せない |
| 依頼側が戸惑いの部分を消したがる | 候補者の信頼の構造を伝える。判断は本人と依頼側 |
| 本人が公開後に不安になった | 依頼側の決まりに従って対応。担当者は本人と依頼側の間を取り持つまで |

## まとめ

- 「やりがいは」と聞くと**他社にも書ける言葉**になる。場面を聞く
- **答える迷いを一つ決め、その迷いに近い経験の人**に聞く。話の上手さで選ばない
- **五つの問い**：最初の三か月・前の会社と違うこと・一日の時間・自分で決めた場面・辞めようと思ったこと
- 聞き方は**状況・役割・判断・行動・結果**で場面を掘る。評価はしない
- 書く構造は**迷いへの答えを先頭・場面・本人の言葉のまま・実態のまま**。会社紹介は書かない
- **本人の確認→現場の照合→依頼側の承認**。本人が消したい部分は理由を聞かずに消す
- **私的な情報・第三者・機密・保証・作った言葉・前職の批判**は載せない。個別の判断は専門家にご確認ください

## よくある質問

### 一時間の聞き取りで、記事は何本書けますか

五つの問いに答えてもらえば、答える迷いごとに一本ずつ、二本から三本の材料が出ることが多い。ただし、一本ごとに本人の確認と依頼側の承認が要るので、公開は一本ずつにします。二本目以降は、「前回の聞き取りの別の場面を、別の迷いに答える形で」と本人に伝え、改めて確認を取ります。同じ人の記事が続くと読者に偏るので、二本目は別の人にすることが多いです。

### 依頼側から「代表のインタビューを書いてほしい」と言われました

代表の記事も、答える迷いを一つ決めます。「この会社はどこに向かうのか」「経営者はどういう人か」は、候補者の迷いの一つです。五つの問いは、代表向けに変えます。「創業の頃、最初の三か月で何をしたか」「前の会社（や前の事業）と違うこと」「いま、一日の時間を何に使っているか」「決まりの無いことを自分で決めた場面」「やめようと思ったこと」。代表の記事も、理念の説明ではなく場面で書くと、候補者に届きます。

### 社員インタビューを外部のライターに任せることになりました

問いと材料と照合は担当者が担い、文章の整えをライターに任せる形にします。ライターに「五つの問い」と「答える迷い」と「本人の言葉のまま」の三つを渡し、原稿は本人の確認と現場の照合を通します。ライターの選定と費用は依頼側の判断です。ライターが「やりがい」の型で書いてきたら、問いに戻します。分担の考え方は[採用広報の企画を立てる](/media/fukugyo-skill-koho-kikaku/)に書いています。
