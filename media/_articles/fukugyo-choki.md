副業を始めて数か月は続いたが、本業が忙しくなると止まり、また始めては止まる。何年も続けている人は、何が違うのか。意志が強いのか、時間があるのか。結論を先に書くと、**副業を長く続けている人は、頑張り方や意志ではなく、「稼働の上限」「休む枠」「案件の入口」「範囲の更新」「やめ方」の五つを先に設計しています。続かない人は、この五つを決めずに始め、本業や家族の事情が変わったときに、設計がないので止まります。続く人は、事情が変わっても設計の中で調整でき、止まりません。続くかどうかは、意志ではなく、設計で決まります。**時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、稼働の上限は[超過稼働の扱い](/media/fukugyo-choka-kadou/)に、やめ方は[副業をやめるとき](/media/fukugyo-yameru/)にまとめています。

## 続かない人と続く人の差

副業が続かない人と続く人の差は、始め方にあります。

| 続かない人 | 続く人 |
|---|---|
| 空いた時間でやる。枠を決めていない | 週の枠を先に固定し、その中で受ける |
| 来る案件を全部受ける。上限がない | 稼働の上限を決め、超えたら断る |
| 休みを決めていない。案件が途切れたときが休み | 休む枠を先に決め、案件をその外に置く |
| 案件の入口が一つ。途切れると探しに行く | 入口を複数持ち、途切れても次が来る |
| 始めたときの範囲のまま。飽きるか、合わなくなる | 年に一度、範囲を見直し、広げるか絞るかを決める |
| やめ方を決めていない。事情が変わると消える | 一時停止と縮小の形を決めてあり、事情が変わっても消えない |
| 本業や家族の事情が変わると、副業が最初に崩れる | 事情が変わったときの調整の仕方が決まっている |

差の要点は、「続く人は、事情が変わることを前提に設計している」ことです。本業の繁忙、家族の事情、体調の変化は、何年も続ければ何度も起きます。設計がなければ、そのたびに副業が止まり、再開のたびにゼロから作り直すことになります。設計があれば、事情に合わせて枠を縮め、休み、入口を残し、事情が戻ったら枠を広げるだけです。始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、続かない原因は[案件が続かない原因の切り分け](/media/fukugyo-tsuzukanai/)に書いています。

## 五つの設計

長く続けるための五つの設計を、それぞれ決めておきます。

| 設計 | 決めること | 決め方 | 決めていないと |
|---|---|---|---|
| 一、稼働の上限 | 週の稼働の上限と、上限を超えたときの対応 | 本業と生活に影響が出ない時間で固定する。超えたら新規を断る。[週何時間から受けられるか](/media/fukugyo-kadou-jikan/) | 受けすぎて、本業か体調に響き、全部止まる |
| 二、休む枠 | 週に一日は副業に触れない日、年に数回は数週間の休み | 案件を受ける前に、休む枠をカレンダーに先に入れる。依頼側にも稼働しない日を伝える | 休みがなく、疲れが溜まり、やめたくなる |
| 三、案件の入口 | 登録先、再依頼、紹介、発信の複数 | 一つが途切れても次が来る状態にする。登録先のプロフィールを更新し続ける。[人事のネットワークの作り方](/media/fukugyo-nettowaku/) | 途切れるたびに探しに行き、疲れる |
| 四、範囲の更新 | 年に一度、受ける範囲を見直す | 続けたい工程、やめたい工程、新しく試したい工程を分ける。範囲の一言を更新する | 同じ範囲を続けて飽きるか、合わなくなって続かない |
| 五、やめ方 | 一時停止、縮小、終了の形と、それぞれの伝え方 | 事情が変わったときに、消えずに調整できる形を先に決めておく。[副業をやめるとき](/media/fukugyo-yameru/) | 事情が変わると消え、戻れなくなる |

五つの要点は、「一」と「二」が土台だということです。稼働の上限と休む枠がなければ、他の三つを設計しても、疲れで崩れます。上限と休みを先に決め、その中で入口と範囲とやめ方を設計します。休みは、案件が途切れたときにたまたま取るものではなく、先に枠として置くものです。休む枠の作り方は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)の「時間帯が読めない前提」の考え方が参考になり、上限の扱いは[超過稼働の扱い](/media/fukugyo-choka-kadou/)に書いています。

### エラベルの見解

担当する側から見ると、何年も続いている担当者と、数か月で止まる担当者の差は、経験の長さや稼働の多さではなく、「休む枠を先に決めているか」です。続いている人は、週に一日は副業に触れず、年に数回は数週間の休みを取り、その予定を依頼側にも先に伝えています。依頼側は、稼働しない日が分かっていれば困りません。止まる人は、休みを決めずに案件を受け、途切れたときが休みになり、途切れが休みなので次を探す気力もなく、そのまま止まっています。

見ていて差がつくのは、年に一度、範囲を見直しているかです。同じ範囲を何年も続けていると、飽きるか、市場や自分の状況と合わなくなります。見直している人は、続けたい工程を残し、やめたい工程を外し、新しく試したい工程を一つ足して、範囲の一言を更新しています。その更新が、登録先のプロフィールと依頼側への伝え方に反映され、案件の質が保たれています。見直していない人は、範囲が古いまま案件を受け、合わない案件が増え、続かなくなっています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲と条件を更新し続けている担当者ほど、その時点で合う依頼側から選ばれ続けています。続ける設計は、始めるときに作り、年に一度、更新するものです。

## 年に一度の見直しの項目

五つの設計は、作って終わりではなく、年に一度見直します。見直しの項目です。

| 項目 | 見ること | 直すこと |
|---|---|---|
| 稼働の実態 | 過去一年の週ごとの稼働が、上限を超えた週が何回あったか | 超えた週が多ければ、上限を上げるか、受ける案件を減らす |
| 休みの実態 | 副業に触れない日が、週に一日取れていたか。数週間の休みを取ったか | 取れていなければ、来年の休みの枠を先にカレンダーに入れる |
| 案件の入口 | 過去一年の案件が、どの入口から来たか。偏りはないか | 一つに偏っていれば、他の入口を足す |
| 範囲 | 続けたい工程、やめたい工程、新しく試したい工程 | 範囲の一言を更新し、登録先のプロフィールを直す |
| 収入と単価 | 年間の収入と、案件ごとの単価の幅 | 単価が低い案件が多ければ、次の更新で見直す。[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/) |
| 本業と家族への影響 | 本業の評価、家族からの反応、体調 | 影響が出ていれば、上限を下げる |
| やめたいと思った回数 | 過去一年で、やめたいと思ったのは何回、何が原因か | 原因が稼働なら上限、案件なら範囲、疲れなら休みを直す |
| 副業の目的 | 始めたときの目的が、今も同じか | 目的が変わっていれば、範囲と稼働をそれに合わせる |

見直しの要点は、「やめたいと思った回数と原因」を記録しておくことです。やめたいと思う瞬間は、設計のどこかが崩れている合図です。原因が稼働なら上限を、案件なら範囲を、疲れなら休みを直します。記録がなければ、やめたい気持ちだけが残り、原因が分からず、次の年も同じことが起きます。記録の残し方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、目的の置き方は[副業で月いくらを目指せるか](/media/fukugyo-nenshuu-mokuhyou/)に整理しています。

## 続ける中で変わるものへの対応

何年も続けると、本業、家族、体、市場が変わります。変わったときの対応を、設計の中に入れておきます。

| 変わるもの | 起きること | 設計の中での対応 |
|---|---|---|
| 本業の忙しさ | 繁忙期、昇進、異動で、副業の枠が減る | 上限を一時的に下げる。新規を止め、今の案件は区切りまで。一時停止の形を使う |
| 家族の事情 | 子育て、介護、引っ越しで、時間帯が読めなくなる | 稼働の時間帯を、読める時間帯に絞る。稼働しない時間帯を依頼側に伝える。[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/) |
| 体調 | 疲れやすくなる、集中が続かなくなる | 上限を下げ、休む枠を増やす。夜の稼働を朝に変える。[早朝の稼働という選択](/media/fukugyo-hayaasa/) |
| 市場 | 求められる工程や道具が変わる | 年に一度の範囲の見直しで、新しく試す工程を一つ足す。[副業で学び続ける](/media/fukugyo-gakushuu/) |
| 自分の関心 | 同じ工程に飽きる。別の工程に興味が出る | 範囲の更新で、続けたい工程とやめたい工程を分ける |
| 依頼側の顔ぶれ | 長く続いた依頼側が終わる。新しい依頼側が増える | 入口を複数持っていれば、終わっても次が来る。終わりは丁寧に閉じる |

対応の要点は、「変わったときに、副業を止めるのではなく、設計の数値を変える」ことです。本業が忙しくなったら上限を下げ、家族の事情が変わったら時間帯を絞り、体調が変わったら休みを増やす。設計があれば、変えるのは数値だけで、副業そのものは止まりません。設計がないと、変わるたびに副業が止まります。時間帯の選び方は[平日夜だけで受けられる案件](/media/fukugyo-heijitsu-yoru/)と[週末だけの稼働は可能か](/media/fukugyo-shuumatsu/)に書いています。

## 設計が崩れる兆候と直し方

設計は、気づかないうちに崩れます。兆候を知っておくと、早く直せます。

| 兆候 | 崩れているところ | 直し方 |
|---|---|---|
| 週の稼働が、上限を超える週が続いている | 稼働の上限 | 新規を止める。今の案件の範囲を狭める。上限を超えた分は依頼側に報告する |
| 副業に触れない日が、何週間もない | 休む枠 | 今週、一日を空ける。来月の休みをカレンダーに入れる |
| 案件が途切れると、不安で条件を下げて受ける | 案件の入口 | 入口を数える。登録先のプロフィールを更新する。仲間に範囲を伝え直す |
| 同じ案件を、義務のように続けている | 範囲の更新 | 続けたい工程とやめたい工程を書き出す。次の更新で範囲を直す |
| 「もうやめようか」と思う回数が増えた | 五つのどれか | 原因を書き出す。稼働なら上限、案件なら範囲、疲れなら休み |
| 本業の評価が下がった、家族に指摘された | 稼働の上限と休む枠 | 上限を下げる。休みを増やす。副業を一時停止する |
| 依頼側の連絡に返すのが遅くなった | 稼働の上限 | 受けている量が枠を超えている。案件を減らす |

兆候の要点は、「やめようかと思う回数」が、最も早い兆候だということです。その回数が増えたら、副業が合わないのではなく、設計のどこかが崩れています。原因を書き出し、崩れたところの数値を変えます。それでも続くなら、一時停止の形で休みます。終了は、設計を直しても続く場合の最後の選択です。疲れのときの判断は[副業をやめるとき](/media/fukugyo-yameru/)に、稼働の報告は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に整理しています。

## 設計を作る順番

これから始める人も、続けている人も、この順番で設計を作ります。

| 順番 | 内容 |
|---|---|
| 一、休む枠を先にカレンダーに入れる | 週に一日、年に数回の数週間。案件より先に入れる |
| 二、週の稼働の上限を決める | 休む枠を引いた残りから、本業と生活に影響が出ない時間で固定する |
| 三、案件の入口を複数にする | 登録先に範囲と条件を登録する。仲間と依頼側に範囲を一言で伝える |
| 四、範囲の一言を作り、年に一度の更新日を決める | 続けたい工程、やめたい工程、試したい工程を、毎年同じ月に見直す |
| 五、一時停止と縮小の形を決めておく | 事情が変わったときの伝え方と、登録先の休止の方法を、先に確認しておく |
| 六、やめたいと思った日を記録する | 日付と原因。年に一度の見直しで使う |
| 七、年に一度、見直す | 稼働、休み、入口、範囲、収入、影響、やめたい回数、目的 |
| 八、変わったら、数値を変える | 副業を止めるのではなく、上限、休み、時間帯、範囲の数値を変える |

順番の要点は、「一」の休む枠を、案件より先に入れることです。案件を受けてから休みを探すと、休みは見つかりません。休む枠を先に入れ、残りで上限を決め、その中で案件を受ける。この順番が、何年も続く設計の土台です。時間の枠の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、入口の作り方は[紹介で仕事が回るようになるまで](/media/fukugyo-shoukai-ryou/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「副業が続かないのは、意志が弱いからだ」というものです。実際には、続かない人は、稼働の上限と休む枠を決めずに始め、本業や家族の事情が変わったときに、調整の仕方がなくて止まっています。意志の問題ではなく、設計の問題です。続いている人も、意志が強いわけではなく、事情が変わったときに数値を変えるだけで済む設計を持っているだけです。

順番として、休む枠を先にカレンダーに入れ、週の稼働の上限を決め、案件の入口を複数にし、範囲の一言と年に一度の更新日を決め、一時停止と縮小の形を先に決め、やめたいと思った日を記録し、年に一度見直し、変わったら数値を変える。この順番で、副業は「続けるもの」から「続く設計になっているもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲と条件を更新し続け、稼働しない日を明確にしている担当者が、長く選ばれ続けています。長く続けるのは、頑張ることではなく、設計することです。

## まとめ

- 長く続く人は**稼働の上限・休む枠・案件の入口・範囲の更新・やめ方**の五つを先に設計している。意志ではなく設計
- **休む枠を案件より先にカレンダーに入れ**、残りで上限を決め、その中で受ける
- 年に一度**稼働・休み・入口・範囲・収入・影響・やめたい回数・目的**を見直す
- 本業・家族・体調・市場が変わったら**副業を止めるのではなく、上限・休み・時間帯・範囲の数値を変える**
- **「やめようか」と思う回数**が最も早い兆候。原因が稼働なら上限、案件なら範囲、疲れなら休みを直す
- 終了は設計を直しても続く場合の最後の選択。**一時停止と縮小の形を先に決めておく**

## よくある質問

### 副業を始めて半年ですが、もう疲れています。長く続けられる気がしません

半年で疲れているなら、稼働の上限と休む枠が決まっていない可能性が高いです。今週、副業に触れない日を一日作り、過去の週ごとの稼働を数え、上限を超えていたら新規を止めます。今の案件は区切りまで終え、そこで一度、休む枠と上限を設計し直してから続けます。疲れているときに「続けられない」と決めると終了に寄るので、休んでから決めます。休みの取り方は[副業をやめるとき](/media/fukugyo-yameru/)の一時停止の考え方が使えます。

### 稼働しない日を依頼側に伝えると、案件が取れなくなりませんか

伝えた方が、案件は続きます。依頼側が困るのは、稼働しない日があることではなく、いつ稼働するか分からないことです。「水曜と日曜は稼働しません。連絡は翌稼働日に返します」と先に伝えれば、依頼側はその前提で動けます。伝えずに休むと、「返事が来ない」となり、信用が下がります。稼働の時間帯の伝え方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、報告の型は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に整理しています。

### 年に一度の見直しで、範囲を変えたら、今の依頼側に迷惑がかかりませんか

今の案件の範囲は、契約の更新の節目で変えます。年に一度の見直しは、「次に受ける案件の範囲」と「登録先のプロフィール」を更新するもので、今の案件を途中で変えるものではありません。今の案件でやめたい工程があるなら、更新の一か月前に「次の期間から、この工程は範囲から外したい」と相談します。更新時の相談の仕方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。
