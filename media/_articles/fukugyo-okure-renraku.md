今週中に出すと約束した求人票の案が、本業の急な残業で間に合いそうにない。まだ二日あるので何とかなるかもしれないと思い、連絡せずにいたら、期限の日に「まだですか」と聞かれた。結論を先に書くと、**遅れそうなときの連絡は、「遅れると分かった時点で」「新しい期限と、理由と、依頼側への影響を添えて」「候補者に関わるものは他より先に」伝えます。間に合うかもしれないと思って連絡を待つ時間が、最も信頼を減らします。**遅れてから謝る連絡と、遅れる前に伝える連絡では、同じ遅れでも依頼側の受け取り方が違います。前者は「管理できない人」、後者は「見通しを持っている人」になります。本業が忙しいときの稼働の下げ方は[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/)に、無理な依頼の断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、依頼側との連絡の型は[メールの書き方と運用](/media/fukugyo-mail/)にまとめています。

## 遅れの連絡が遅れる構造

遅れそうだと分かっていても、連絡が遅れるのには理由があります。理由が分かると、連絡を早められます。

| 理由 | 頭の中で起きていること | 実際に起きること |
|---|---|---|
| 間に合うかもしれない | 「明日頑張れば」「本業が早く終われば」 | 頑張っても間に合わず、期限の直前か過ぎてから連絡する |
| 悪い知らせを先延ばしにしたい | 「言いにくい」「がっかりされたくない」 | 先延ばしにするほど、言いにくさが増す |
| 遅れの大きさが分からない | 「どのくらい遅れるか分からないので、分かってから」 | 分かる頃には、期限を過ぎている |
| 依頼側の反応が怖い | 「怒られる」「信頼を失う」 | 遅れてから伝えるほうが、信頼の損失は大きい |
| 遅れを自分の力で吸収しようとする | 「睡眠を削れば」「他の案件を後回しにすれば」 | 本業か他の案件か体調に影響し、別の遅れを生む |

構造の要点は、「間に合うかもしれない」が最も多く、最も危ないことです。間に合う可能性が半分でも、連絡を待てば、間に合わなかった半分のときに、期限を過ぎてからの連絡になります。連絡しておいて間に合えば、「早く出せました」で済み、依頼側の評価は下がりません。連絡の遅れは、遅れそのものより重く見られます。

## 伝える時点の決め方

「遅れると分かった時点」を、自分の中で具体に決めておきます。決めておかないと、「まだ分からない」で先延ばしになります。

| 時点 | 判断の基準 | 伝えるか |
|---|---|---|
| 残り時間と残り作業を比べて、足りないと分かった | 残りの副業の枠（時間）に、残りの作業が入らない | 伝える。この時点が最も早い |
| 本業の予定が変わり、副業の枠が消えた | 予定していた夜や週末の枠が、本業や家庭の都合で使えなくなった | 伝える。枠が戻る見込みがあっても伝える |
| 依頼側からの情報待ちで止まっている | 依頼側の返事や資料が来ないと進められない | 伝える。「〇〇をいただければ〇日に出せます」の形で。依頼側の側の遅れも、自分から伝える |
| 作業をしてみたら、見込みより重かった | 求人票の案が、想定より調整が要ると分かった | 伝える。「見込みより時間がかかっている」を隠さない |
| 体調を崩した | 数日動けない | 伝える。理由は「体調」で足りる。詳細は要らない |
| まだ間に合う可能性が高いが、余裕が無い | 残り時間と残り作業がぎりぎり | 伝える。「予定通り出せる見込みですが、余裕が無いため、遅れる場合は〇日までにご連絡します」と、予告だけしておく |

時点の要点は、「残りの枠と残りの作業を比べる」ことです。感覚ではなく、副業の枠（時間）に作業が入るかで判断すれば、「間に合うかもしれない」の曖昧さが消えます。枠の置き方は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、稼働ログで残り作業を見る形は[稼働ログの付け方](/media/fukugyo-log/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「遅れの連絡をすると、依頼側の評価が下がる」というものです。実際には、依頼側の担当者の評価が下がるのは、遅れの連絡ではなく、連絡が無いまま期限が来ることです。担当者は、外部の担当者の遅れを、自分の上長や面接官に説明する立場にあります。遅れる前に連絡があれば、担当者は社内に「〇日に変更」と伝えられます。連絡が無ければ、担当者は期限の日に「まだ来ていない」と社内で言うことになり、担当者自身の立場が悪くなります。

見ていて差がつくのは、遅れの連絡に「新しい期限」と「依頼側への影響」が入っているかです。「遅れます、すみません」だけでは、担当者は社内に何も伝えられません。「〇日に出します。それまでの間、候補者への連絡は予定通り続けます」と書かれていれば、担当者は社内に「〇日に変更、候補者の対応は影響なし」と言えます。エラベルでは、担当者が依頼側との約束に遅れそうなとき、分かった時点で新しい期限と影響を添えて伝える形をお願いしています。この形で連絡している担当者は、遅れがあっても更新が続いています。

## 文面に入れる四つのこと

遅れの連絡は、短い文面で、四つのことを入れます。長い謝罪より、四つが揃っているほうが、依頼側は動けます。

| 要素 | 内容 | 例 |
|---|---|---|
| 一、何が遅れるか | 遅れる作業と、元の期限 | 「〇日にお出しする予定だった求人票の案について」 |
| 二、新しい期限 | 一度で守れる日。楽観の日ではなく | 「〇日にお出しします」 |
| 三、理由（短く） | 一文。詳しい事情は要らない。嘘は言わない | 「本業の予定が急に入り、今週の作業の時間が取れなくなりました」 |
| 四、依頼側への影響と、影響を抑える手 | 遅れで何が変わるか、変わらないか。先に出せる部分があれば出す | 「求人票の掲載が数日ずれますが、スカウトの送信は予定通り続けます。要件の部分だけ先に本日お送りします」 |

四つの要点は、「二」の新しい期限を、一度で守れる日にすることです。「明日には」と楽観の日を言って、また遅れると、二度目の遅れの連絡になり、信頼の損失は一度目より大きくなります。新しい期限は、余裕を見て、一度で守れる日にします。「四」の先に出せる部分は、あれば全部でなくても出しておくと、依頼側は「止まっていない」と感じます。

## 候補者に関わる遅れは先に

遅れの中で、候補者に関わるものは、他の遅れより優先して伝え、対応します。

| 候補者に関わる遅れ | 起きること | 優先する理由 |
|---|---|---|
| 候補者への返信が遅れる | 候補者が他社で決まる。依頼側の印象が下がる | 候補者は依頼側の外の人で、遅れの影響が依頼側に戻せない |
| 日程の確定が遅れる | 候補者が予定を空けて待っている | 候補者の時間を使わせている |
| 面接の準備の資料が遅れる | 面接官が準備できない。面接の質が下がる | 候補者が受ける面接に影響する |
| 内定者への連絡が遅れる | 内定者が不安になり、辞退につながる | 承諾の判断に影響する |
| 選考結果の連絡が遅れる | 候補者が結果を待っている | 候補者の次の判断を止めている |

優先の要点は、「候補者への影響は、依頼側の中で吸収できない」ことです。求人票の案の遅れは、依頼側の中で予定をずらせば済みます。候補者への返信の遅れは、候補者が離れれば戻せません。候補者に関わる作業が遅れそうなら、その部分だけでも依頼側の担当者に「候補者への返信を代わりにお願いできますか」と頼むか、最低限の返信（「〇日までにご連絡します」）だけは自分で出します。候補者との接し方は[候補者への対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に整理しています。

## 遅れの種類ごとの伝え方

遅れの原因によって、伝え方と、依頼側に頼むことが変わります。

| 種類 | 伝え方 | 依頼側に頼むこと |
|---|---|---|
| 本業の都合（残業、出張、繁忙） | 「本業の予定で今週の作業時間が取れなくなりました」。詳細は不要 | 新しい期限の了承 |
| 家庭や体調 | 「私用（体調）で数日作業できません」。詳細は不要 | 新しい期限の了承。候補者に関わる部分の代替 |
| 作業の見込み違い | 「見込みより調整が要ると分かりました」。何が想定より重かったかを一言 | 新しい期限の了承。必要なら、範囲を絞る相談 |
| 依頼側の情報待ち | 「〇〇をいただければ、〇日にお出しできます」。依頼側の遅れを責めない書き方で | 情報の提供 |
| 依頼側の社内の承認待ち | 「承認をいただき次第、〇日で進めます」 | 承認の見込みの共有 |
| 複数の案件の重なり | 「今週は作業の時間が限られており」。他の案件の名前は出さない | 新しい期限の了承 |

種類の要点は、「依頼側の側の遅れも、自分から伝える」ことです。依頼側の返事や資料が来ないために遅れる場合、黙って待つと、依頼側から見れば「外部の担当者が遅れている」ように見えます。「〇〇をいただければ〇日に」と伝えれば、遅れの所在が明確になり、依頼側の担当者も社内で動けます。責める書き方にせず、「いただければ進められます」の形にします。依頼側の側で止まっている場面は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)に書いています。

## 遅れた後の立て直し

遅れの連絡をした後、新しい期限を守ることと、遅れの印象を残さないことが要ります。

| やること | 内容 |
|---|---|
| 新しい期限は早めなくてよいが、守る | 早く出せても、まず新しい期限を守る。二度目の変更は無し |
| 出したときに、遅れに触れすぎない | 「遅れて申し訳ありませんでした」を一度だけ。何度も謝ると、遅れの印象が残る |
| 先に出せる部分は出す | 全部が揃うのを待たず、揃った部分から出す。「要件の部分は本日、全体は〇日に」 |
| 稼働報告に事実として書く | 「〇〇は〇日に予定していたが、本業の都合で〇日に変更した」と一行。隠さない。[稼働報告のフォーマット](/media/fukugyo-kadou-houkoku/) |
| 次の約束は余裕を持って決める | 遅れた直後の次の期限は、いつもより余裕を見る。連続の遅れを避ける |
| 遅れの原因が続くなら、稼働の話にする | 本業の繁忙が続くなら、期限の話ではなく、稼働を下げる話として依頼側と相談する。[本業が忙しくて稼働できないとき](/media/fukugyo-choka-kadou/) |

立て直しの要点は、「遅れの原因が続くなら、稼働の話に切り替える」ことです。本業の繁忙が数週間続くのに、期限の延長を繰り返すと、依頼側は「毎回遅れる」と感じます。「〇月は稼働を下げたい」と先に伝えれば、遅れではなく、稼働の調整として扱われます。

## 繰り返さないための見直し

遅れが起きたら、原因を見て、次に同じ遅れが起きない形に直します。

| 原因 | 見直し |
|---|---|
| 期限を楽観で決めていた | 期限を決めるとき、本業の繁忙を織り込む。「余裕を見て〇日」と依頼側に伝える |
| 副業の枠が本業に侵食された | 枠を繁忙期でも守れる形に置き直す。[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/) |
| 作業の重さを見誤った | 稼働ログで、同じ種類の作業に実際にかかった時間を見て、次の見積もりに使う |
| 依頼側の情報待ちが多い | 最初の打ち合わせで、必要な情報と期限を先に伝える。[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/) |
| 複数の案件の期限が重なった | 締め日と期限を一枚に並べ、重なる週を前倒しする |
| 受けている量が枠を超えている | 範囲か案件の数を、更新の節目で見直す。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |

見直しの要点は、「期限を決めるときに、本業の繁忙を織り込む」ことです。遅れの多くは、期限を決めた時点で、本業の予定を楽観していたことから起きます。期限を依頼側と決めるとき、「本業の予定を見て、余裕を持って〇日でよいですか」と、最初から余裕を入れておけば、遅れの連絡そのものが減ります。

### エラベルの見解

担当する側から見ると、遅れがあっても依頼側との関係が続いている人は、遅れの回数が少ないのではなく、遅れの連絡が早く、文面に新しい期限と影響が入っています。依頼側の担当者は「この人は遅れるときも見通しを持っている」と受け取り、遅れを管理の一部として扱えます。関係が切れる人は、遅れの回数が同じでも、連絡が期限の直前か過ぎてからで、依頼側の担当者が社内で説明できない状態を作っています。

順番として、遅れそうだと分かった時点で、残りの枠と残りの作業を比べ、入らないなら即座に、新しい期限・理由・影響・先に出せる部分を一つの文面で伝え、候補者に関わる部分は先に手を打ち、新しい期限は一度で守り、報告に事実として残し、原因を見直す。この順番で、遅れは信頼の損失ではなく、見通しを示す機会になります。エラベルでは、担当者が依頼側との約束に遅れそうなとき、依頼側より先に窓口に伝えてもらう形も取っていて、窓口が依頼側との間で期限や稼働を調整することもあります。遅れは、隠すものではなく、早く伝えて一緒に調整するものです。

## まとめ

- 遅れの連絡は**分かった時点で・新しい期限と理由と影響を添えて・候補者に関わるものは先に**
- 連絡が遅れるのは**「間に合うかもしれない」が最も多く、最も危ない**。連絡して間に合えば損は無い
- 伝える時点は**残りの枠と残りの作業を比べて、入らないと分かったとき**。感覚ではなく枠で判断する
- 文面は**何が遅れるか・新しい期限（守れる日）・理由（短く）・影響と先に出せる部分**の四つ
- **候補者に関わる遅れは依頼側の中で吸収できない**。最低限の返信だけでも出すか、担当者に代替を頼む
- **依頼側の側の遅れも自分から伝える**。「〇〇をいただければ〇日に」の形で
- 遅れた後は**新しい期限を一度で守り・謝罪は一度だけ・報告に事実として書き・原因が続くなら稼働の話に切り替える**
- 見直しは**期限に本業の繁忙を織り込む**ことから

## よくある質問

### 遅れの理由が本業の残業です。本業のことを依頼側にどこまで言うべきですか

「本業の予定で作業の時間が取れなくなりました」で足ります。本業の会社名、残業の理由、社内の事情は言いません。依頼側は、副業であることを知っているので、本業の都合で稼働が変わることは想定しています。詳しい事情を言うと、本業の情報を外に出すことになり、依頼側も聞きたくない話になります。理由は一文、新しい期限と影響を丁寧に、が形です。

### 遅れの連絡をしたら、依頼側から「それでは困る」と言われました

依頼側の側の事情（掲載の予定、面接の予定）で、新しい期限では間に合わない場合です。「では、どの部分を優先すれば、御社の予定に間に合いますか」と、範囲を絞る相談に切り替えます。全部を新しい期限で出す代わりに、依頼側が急ぐ部分だけを元の期限で出し、残りを後にする形です。それでも無理なら、依頼側の社内の人に一部を引き取ってもらう相談をします。無理な要求への対応は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

### 遅れそうな気がするが、まだ分からない段階です。連絡すべきですか

「予定通り出せる見込みですが、本業の予定次第で遅れる可能性があります。遅れる場合は〇日までにご連絡します」と、予告だけしておきます。これで、遅れなければ何も起きず、遅れる場合も、依頼側は予告を受けているので、急な連絡になりません。予告の期限（〇日まで）は、元の期限より数日前にし、依頼側が調整できる時間を残します。予告があると、依頼側は「この人は見通しを共有してくれる」と受け取ります。
