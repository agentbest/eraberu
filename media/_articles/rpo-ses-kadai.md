SES業界の会社が「出せる人がいない」と言うとき、その言葉には五つの違う問題が混ざっています。採る数が案件の見込みではなく「待機が何人まで許せるか」で決まり、要件が「案件に出せる人」のままで対象が絞れず、同業のSESに動く理由が文面に無く、未経験を採るのに育てる体制が無く、待機中に人が離れる。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**SES業界の採用課題は、採る数の根拠・案件の型・動く理由・育てる体制・待機の五つに分解し、自社の記録（稼働と待機の人数、案件の見込み、書類と面接の一致、返信の数、離職の時期）で詰まりを一つに特定してから直します。**「出せる人がいない」を一つの問題として扱うと、媒体と紹介会社を増やして採り、待機が増えて費用が出て、採用を止め、次の案件で人がいない、を繰り返します。代行に出す工程の切り分けは[SES業界の採用代行](/media/rpo-ses-rpo/)に、SIer業界との違いは[SIer業界の採用課題](/media/rpo-sier-kadai/)に書いています。ここでは、SES業界の課題を分解する順番に絞ります。

## 「出せる人がいない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 採る数の根拠 | 採ると待機が増え、止めると人が足りない、の往復 | 稼働・待機の人数と、案件の見込みの一枚が無い |
| 案件の型 | 応募は来るが、面接で「出せる案件が無い」 | 書類で○の人が面接で通らない。要件が「案件に出せる人」 |
| 動く理由 | 経験者からスカウトの返信が来ない。来ても「自社開発に行きたい」 | 返信の数。辞退の理由 |
| 育てる体制 | 未経験を採ったが、研修の途中で離れる。研修後に案件に出せない | 研修中の離職。研修後の待機 |
| 待機 | 案件の合間に離れる。待機中に他社へ | 離職の時期が待機の期間と重なる |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 稼働・待機の人数と、案件の見込みの一枚があるか | 無ければ採る数の根拠。これが最初 |
| 二 | 書類の○と面接の一致 | ○が面接で通らないなら案件の型 |
| 三 | 返信の数と辞退の理由 | 少なければ動く理由 |
| 四 | 研修中と研修後の離職と待機 | 多ければ育てる体制 |
| 五 | 離職の時期と待機の期間の重なり | 重なっていれば待機 |

一が無い会社では、二以降を見ても採る数が決まらないので、一から作ります。

### エラベルの見解

SES業界で最も多い詰まりは「採る数の根拠」です。営業が「来月から三人出せる案件がありそう」と言い、採用が三人採り、案件が遅れて三人が待機し、費用が出て、経営者が採用を止め、案件が動いたときに人がいない。この往復は、採用の問題ではなく、案件の見込みと採用の一枚がつながっていないことから起きます。直すのは、案件の型ごとに「稼働の人数・待機の人数・見込みの案件と時期・見込みの確度」を一枚に並べ、採る数と時期をそこから決めることです。エラベルで担当者を選ぶ企業には、「いまの採用の数は、どの一枚から決まっていますか」を、私たちから先に聞いています。一枚が無ければ、代行の前に一枚を作ります。作り方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

## 採る数の根拠の課題：待機の許容で決まっている

| 状態 | 直し方 |
|---|---|
| 営業の感覚で採る数を決める | 案件の型ごとに、稼働・待機・見込み・確度の一枚を月次で |
| 見込みの確度を見ていない | 「確定」「高い」「低い」で分け、確定と高いだけを採る数の根拠に |
| 採る時期が見込みの時期と合っていない | 募集の開始から入社までの日数を過去の記録から出し、見込みの時期から逆算 |
| 待機の費用だけを見て止める | 待機を「次の案件までの育成の期間」として設計し、上限を決める |

一枚は営業と採用と経営者が同じものを見る形にします。営業の見込みが採用に伝わらない会社では、代行を使っても採る数が読めません。

## 案件の型の課題：「案件に出せる人」のまま

| ずれている要件 | 直した要件 |
|---|---|
| 「案件に出せる人」 | 「〇〇業界の〇〇の工程の案件に、〇〇の経験で出せる人」 |
| 「SE経験〇年」 | 「〇〇の工程を担った経験。〇〇の技術の範囲」（年数は歓迎に） |
| 「幅広く対応できる人」 | 型ごとに要件を分ける。一人で全部の型に出せる人を探さない |

案件の型は、過去に出した案件を「業界・工程・常駐の形」で三つ程度に分けると作れます。型があれば、案件が個別に決まっていなくても、要件は絞れます。要件の作り方は[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 動く理由の課題：同業に動く理由が無い

| 候補者の層 | 動く理由 | 自社の実態で対応できるか |
|---|---|---|
| 案件の選び方に不満 | 案件の型を選べる、希望を聞く仕組み | 実態にあるか |
| 単価と還元の考え方に不満 | 還元の考え方が明確 | 実態を説明できるか（額ではなく考え方） |
| 育つ道筋が無い | 待機中の育成、資格や技術の支援 | 実態にあるか |
| 常駐先で孤立 | 社内の相談先、定期の接点 | 実態にあるか |
| 自社開発に行きたい | SESでは対応できない | 対象から外す |

「SESからSESに動く理由」は、自社の実態の中にしか作れません。単価や還元の額を文面に書いて差を出すのではなく、考え方と仕組みの実態で差を出します。動く理由の作り方は[自社紹介はどこまで書くか](/media/scout-kaisha-shoukai/)に書いています。

### エラベルの見解

SES業界で見落とされやすいのは「待機」の課題です。待機の期間を「案件が無い間」として放置すると、本人は「自分は要らないのでは」と感じ、待機中に他社へ移ります。待機を「次の案件の型に向けた育成の期間」として設計し、教える人と中身と期限を決めておくと、待機は離職の理由ではなく、育つ道筋の一部になります。それは「SESに転職する理由」にもなります。エラベルで担当者を選ぶ企業には、「待機中の方は、何をしていますか」を、私たちから先に聞いています。答えが「自習」なら、待機の設計が要ります。受け入れと育成の考え方は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 育てる体制の課題：未経験を採るのに体制が無い

| 状態 | 直し方 |
|---|---|
| 研修の中身と教える人が決まっていない | 「誰が、何を、どのくらいの期間」を一枚に。体制で受け入れられる数だけ採る |
| 研修後に出す案件の型が無い | 研修の到達点を、案件の型の要件と揃える |
| 研修が座学だけ | 研修の後半で、案件の型に近い実務を |
| 研修中の離職を見ていない | 離職の時期と理由を記録し、研修の設計に戻す |

未経験の採用は、母集団より育てる体制で決まります。体制が無ければ、経験者の採用に絞る判断もあります。体制の考え方は[新卒採用の実務の進め方](/media/rpo-task-shinsotsu-unyou-susumekata/)に書いています。

## 待機の課題：案件の合間に離れる

| 状態 | 直し方 |
|---|---|
| 待機中が「自習」 | 次の案件の型に向けた育成の中身と、教える人と、期限を決める |
| 待機中に社内との接点が無い | 週次の短い接点。相談先を決める |
| 待機の上限が無い | 上限の期間を決め、超える前に営業と採用の一枚に戻す |
| 待機の費用だけを見る | 待機を育成の投資として、上限の中で設計する |

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 採る数の根拠 | 募集から入社までの日数の記録 | 稼働・待機・見込みの一枚。営業と採用の共有 |
| 案件の型 | 型ごとの要件を「経歴で読める言葉」に整える作業 | 型を決める |
| 動く理由 | 文面と求人票に落とす作業 | 実態を語る。仕組み（案件の選び方、還元の考え方）を作る |
| 育てる体制 | 受け入れの型の設計 | 教える人と中身と期間 |
| 待機 | 接点の型 | 待機中の育成の設計と上限 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[SES業界で採用代行が機能する条件・機能しない条件](/media/rpo-ses-jirei/)に書いています。

## 法令上の整理は専門家に

派遣と請負の線引き、常駐先での指揮命令の扱い、待機中の労務の扱いは、法令上の整理があると一般に整理されていて、採用の課題の分解の前提になります。求人票や面接で候補者に説明する内容にも関わるため、専門家（社労士等）の確認を経た内容で進めます。個別の判断は専門家にご確認ください。線引きの考え方は[採用代行と人材派遣の違い](/media/rpo-haken-tono-chigai/)に書いています。

## まとめ

- 「出せる人がいない」には**採る数の根拠・案件の型・動く理由・育てる体制・待機**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は稼働・待機・見込みの一枚があるか
- 最も多い詰まりは**採る数の根拠**。営業の感覚ではなく、案件の型ごとの一枚から
- 要件は**案件の型**で切る。「案件に出せる人」のままにしない
- 動く理由は**自社の実態の中にしか作れない**。額ではなく考え方と仕組みで
- 未経験は**育てる体制で受け入れられる数だけ**。待機は**育成の期間として設計**し上限を決める
- **法令上の整理は専門家に**。個別の判断は専門家にご確認ください

## よくある質問

### 営業と採用が別で、見込みが採用に伝わりません

月次の会議でなくても、「案件の見込みが立ったら、営業から採用の担当に一言」の形から始めます。一言が「稼働・待機・見込み」の一枚に入れば、採る数と時期が読めます。一枚は営業・採用・経営者が同じものを見る形にし、月に一度、三者で見直します。仕組みは後から整えればよく、最初は一言の習慣で足ります。

### 単価の還元の考え方を文面に書いてよいですか

還元の「考え方」と「仕組み」（どう決まるか、どう見えるか）は書けます。額や率を書く場合は、実態と一致していること、変わったときに更新すること、他社との比較で誤解を生まないことを、会社の判断と専門家の確認で決めます。額で差を出す文面は、他社が額を上げれば効かなくなります。考え方と仕組みと育つ道筋で差を出すほうが、続きます。

### 待機が長引いた人を、どうすればよいか分かりません

待機の上限を決めていない状態です。上限を決め、上限の中では次の案件の型に向けた育成を設計し、上限を超える前に営業と採用の一枚に戻して、案件の見込みと採る数を見直します。個別の人の処遇（配置、労務の扱い）は会社の判断と専門家の領域で、採用の課題の分解の外です。採用の側でできるのは、待機を生む採る数の根拠を直すことです。
