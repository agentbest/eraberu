候補者と話すとき、副業の人は自分の言葉で話しているつもりでも、候補者にはその会社の言葉として届きます。「リモートは柔軟です」「残業は少ないほうです」「たぶん次の面接に進めます」。人事の経験があるので、それらしく言えてしまい、候補者はそれを会社の約束として受け取ります。入社後に違えば、会社の信用に関わり、依頼側との関係にも響きます。結論を先に書くと、**候補者の前では、副業の人の言葉は会社の言葉になるので、言ってよい範囲を依頼側と「話してよいこと一覧」として決め、一覧に無いことは「担当からお伝えします」で返す**のが、会社の代表として話す責任の果たし方です。責任を負うのではなく、責任が生じない範囲で話します。候補者対応の四つの観点は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に、名義の決め方は[どの名義で候補者に接するか](/media/fukugyo-daimei/)にまとめています。

## 言葉が約束になる構造

副業の人の一言が、会社の約束になる構造を整理します。

| 副業の人の発言 | 候補者の受け取り方 | 入社後に違ったとき |
|---|---|---|
| 「リモートは柔軟だと思います」 | この会社はリモートができる | 「話が違う」。会社への不信、早期退職 |
| 「残業は少ないほうです」 | 残業が少ない会社 | 同上 |
| 「たぶん次に進めます」 | 通過の見込みがある | 見送りになったとき、「言ったのに」 |
| 「年収はこのくらいの幅です」 | 提示される額の目安 | 提示額が下なら、辞退か不信 |
| 「上司になる人は温和です」 | 職場の雰囲気 | 違えば、人事に騙されたと感じる |
| 「この会社は成長しています」 | 安定と将来性 | 業績が悪化したとき、「聞いていた話と違う」 |

構造の要点は、「副業の人の推測や印象が、会社の事実として残る」ことです。副業の人は社内の実態を限られた範囲でしか知らず、推測で答えることになります。推測が候補者には事実になり、事実と違えば会社の責任になります。

## 会社の代表として話す場面

副業の人が会社の代表として話すことになる場面を整理します。

| 場面 | 何が会社の言葉になるか | 注意 |
|---|---|---|
| スカウトの文面 | 会社の魅力、募集の背景、条件の概要 | 依頼側が確認した文面だけを送る。自分の言葉で盛らない |
| 応募者への返信 | 選考の流れ、期間、次の連絡の目安 | 依頼側と決めた内容の範囲で |
| 日程調整の連絡 | 面接の形式、所要時間、担当者 | 事実だけ |
| 候補者からの質問への回答 | 条件、社風、業務内容、評価 | 一覧にあることだけ。無いものは「担当から」 |
| 面接の同席（オンライン） | 面接中の発言、候補者への説明 | 記録役に徹する。発言は依頼側の担当が |
| 見送りの連絡 | 見送りの事実と、理由の有無 | 依頼側の方針の範囲で |
| 辞退を受けたとき | 引き止めの言葉、条件の再提示 | 引き止めは依頼側の判断。自分から条件を出さない |

場面の要点は、「候補者からの質問への回答」が最も危ういという点です。文面や連絡は事前に確認できますが、質問への回答はその場で出ます。その場で答えられてしまうことが、責任を生みます。

### エラベルの見解

登録の相談で多いのは、「候補者に『リモートは柔軟です』と言ったら、入社後にリモートが認められず、依頼側から『そんなことは言っていない』と言われた」という話です。副業の人は、依頼側の担当が雑談で「リモートも柔軟にやっている」と言ったのを聞いていて、候補者にそのまま伝えた。担当の雑談と、会社の制度は別で、副業の人が候補者に言った瞬間に、会社の約束になりました。

見ていて差がつくのは、「話してよいこと一覧を、依頼側と作っているか」です。条件、勤務形態、業務内容、社風について、候補者に伝えてよい内容を、依頼側が確認した形で一覧にする。一覧に無いことは、「担当からお伝えします」。エラベルの登録でも、候補者との間で問題が起きていない人は、この一覧を持っていて、答えられることと答えないことが、依頼側と共有されています。人事の経験があるほど答えられてしまうので、一覧で自分を縛ります。

## 話してよいこと一覧の作り方

依頼側と作る「話してよいこと一覧」の型を、番号付きで整理します。初回打ち合わせか、最初の一か月の間に作ります。

1. **候補者からよく来る質問を、依頼側の担当と出し合う。** 条件（年収の幅、勤務時間、休日、リモート、残業）、業務内容、社風、選考の流れ、入社時期。
2. **各質問について、「副業の人が答えてよい内容」「担当が答える」「面接で伝える」の三つに分ける。** 選考の流れと日程は副業の人、条件と社風は担当か面接で、が基本。
3. **副業の人が答えてよい内容は、文言まで依頼側が確認する。** 「選考は書類・一次面接・最終面接の三段階で、応募から結果まで三週間ほどです」のように、事実として言える形に。
4. **「担当から」に分けたものは、返し方の文面を決める。** 「条件については、面接の際に担当から詳しくお伝えします」。
5. **一覧に無い質問が来たときの返し方を決める。** 「窓口に確認して、〇日以内に折り返します」。その場で答えない。
6. **一覧を、依頼側の環境に置く。** 担当も見られる形で。
7. **月に一度、一覧を見直す。** 新しい質問、条件の変更を反映。
8. **面接に同席する場合の役割を決める。** 記録役。候補者への説明は担当。

作り方の要点は、「三で、文言まで依頼側が確認する」ことです。「選考は三段階です」という事実でも、依頼側が確認した文言でないと、副業の人の解釈が入ります。一覧の文言は、会社の言葉として依頼側が確認します。

## 言ってよい範囲と言わない範囲

一覧の中身の目安として、言ってよい範囲と言わない範囲を整理します。依頼側との一覧が優先です。

| 言ってよい（依頼側が確認した事実） | 言わない（推測、印象、判断、約束になるもの） |
|---|---|
| 選考の流れ、段階、期間の目安 | 合否の見込み、通過の可能性 |
| 面接の形式、所要時間、担当者の役割 | 面接官の評価、社内の議論 |
| 募集している職種と、募集の背景（依頼側の確認済みの文言） | 条件の詳細（年収、評価、昇給）。「幅」でも言わない |
| 勤務地、勤務形態の制度としての事実（依頼側の確認済み） | 制度の運用の実態（「実際は柔軟」「実際は厳しい」） |
| 入社時期の目安 | 社風、人間関係、上司の人柄 |
| 次の連絡の目安 | 会社の業績、将来性、安定性 |
| 応募の方法、必要な書類 | 他の候補者の状況 |

範囲の要点は、「制度の事実は言えるが、運用の実態は言わない」ことです。「リモート制度があります」は依頼側が確認した事実として言えますが、「実際は柔軟です」は運用の印象で、副業の人の言葉が約束になります。実態は、面接で担当が候補者に直接伝えます。

## 話す責任で起きる失敗

会社の代表として話す場面で起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 担当の雑談を候補者に伝える | 聞いた話を事実だと思う | 一覧にある確認済みの文言だけ |
| 「たぶん」「思います」で答える | 断定を避けたつもり | 「たぶん」でも約束になる。「担当から」に |
| 条件の幅を言う | 候補者に判断材料を渡したい | 幅でも言わない。面接で |
| 社風を自分の印象で語る | 候補者との会話が弾む | 語らない。面接で担当が |
| 本業の会社の常識で答える | 「普通はこうです」 | その会社の事実だけ。普通は関係ない |
| 見送りの理由を自分の解釈で言う | 候補者に納得してほしい | 依頼側の方針の範囲で。解釈は言わない |
| 辞退を引き止めて条件を出す | もったいない | 引き止めは依頼側の判断 |
| スカウト文面を自分の言葉で盛る | 返信率を上げたい | 依頼側が確認した文面。盛った分は約束になる |
| 一覧に無い質問にその場で答える | 答えられる | 「確認して折り返します」 |
| 一覧を作らずに始める | 面倒 | 最初の一か月で作る |

失敗の要点は、「答えられることと、答えてよいことは別」という点に尽きます。人事の経験があるほど、条件も社風も見込みも、それらしく答えられます。答えた瞬間に、会社の言葉になります。

### エラベルの見解

担当する側として登録した人の話を聞くと、候補者との間で問題を起こしていない人は、候補者からの質問に対して「答えない」ことに慣れています。「それは担当からお伝えします」「確認して折り返します」を、丁寧に、しかし迷わず言える。候補者は、答えてもらえないことより、窓口が分かれていることとして受け取り、不満にはなりません。逆に、何でも答える人は、候補者には親切に見えますが、答えた内容が会社の約束になり、後で会社の信用を損ねています。

依頼側から見ると、副業の人が候補者に何を言っているかは見えません。だからこそ、話してよいこと一覧を一緒に作ることが、依頼側の安心になります。エラベルは、企業と担当者の間に立つ窓口として、担当者にお願いする業務では、候補者に伝える内容を依頼側が確認する形をお伝えしています。会社の代表として話す責任は、責任を引き受けることではなく、責任が生じる発言をしないことで果たされます。

## まとめ

- 候補者の前では**副業の人の言葉は会社の言葉**。推測や印象が会社の事実として残り、違えば会社の信用に関わる
- 最も危ういのは**候補者からの質問への回答**。その場で答えられてしまうことが責任を生む
- 依頼側と**話してよいこと一覧**を作る。質問を出し合い、**副業の人が答えてよい・担当が答える・面接で伝える**に分け、文言まで依頼側が確認
- 言ってよいのは**選考の流れ・形式・募集の背景（確認済み）・制度としての事実**。言わないのは**見込み・条件・運用の実態・社風・評価・業績**
- 一覧に無いことは**「担当から」「確認して折り返します」**。その場で答えない
- **答えられることと、答えてよいことは別**。責任は、責任が生じる発言をしないことで果たす

## よくある質問

### 候補者が「あなた個人の意見でいいので教えてほしい」と言います

個人の意見でも、候補者には会社の言葉として残ります。「私は選考の窓口なので、個人の意見としてもお伝えする立場にありません。面接で担当に直接聞いていただけるよう、ご質問をお伝えしておきます」と返します。候補者は本音を聞きたがりますが、副業の人が個人として答えた内容は、入社後に違ったときに「人事が言った」になります。候補者の質問を面接に持ち込む手伝いをすることが、候補者の役に立つ形です。

### スカウトの文面で、会社の魅力を伝えないと返信が来ません

魅力は、依頼側が確認した事実で伝えます。「〇〇の事業を〇年続けている」「〇〇の職種を〇名の体制で」「制度として〇〇がある」。事実の組み合わせで魅力は伝わり、返信も来ます。「柔軟」「風通しが良い」「成長できる」のような印象の言葉は、候補者には約束として残り、文面の返信率は上がっても、入社後のずれを生みます。文面は依頼側が確認したものだけを送り、盛りたくなったら、依頼側に「この事実を足してよいか」と確認します。

### 面接に同席していて、担当が候補者に事実と違うことを言いました

その場では何も言いません。面接のあとに、担当に「先ほどの〇〇の点、私の認識と違っていたのですが、どちらが正しいですか」と確認し、事実と違っていれば、候補者への訂正は担当から行ってもらいます。副業の人が面接中に訂正すると、担当の立場が崩れ、候補者は混乱します。面接に同席するときの役割は記録で、発言は担当、と最初に決めておけば、その場で迷いません。訂正が要る場合の手順も、一覧を作るときに決めておきます。
