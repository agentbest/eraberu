エネルギー業界の会社（電力、ガス、石油、再生可能エネルギー、新電力とエネルギーサービス）が採用代行を検討するとき、動機は「保守と保安の技術職が採れず、現場の責任者が採用に追われている」「再エネの案件が増えて開発と建設の人が足りない」「中途の採用を増やしたいが新卒の型しか無い」であることが多い。ただ、エネルギーの採用は、他の業界と違う難しさがあります。型で求める人と経路が違い、技術職は資格と保安が前提で市場が狭く、現場は勤務地が限られ、伝統的な会社は中途の型が無く承認の段が多く、再エネは案件で人数が動き、法人営業は速さで決まる。結論を先に書くと、**エネルギー業界の採用代行は、母集団形成・一次対応・日程調整・勤務地と生活の情報の整理・記録は外に出せる一方、資格と保安の要件の決定・承認の手順・技術の見極め・案件との相性・受け入れは社内に残さないと、採れても配置できず、勤務地と実態のずれで離れます。**代行に出す前に、難しさを自社の状況で分解し、型と職種ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種としての切り分けは[電気設計採用を代行に出す判断基準](/media/rpo-denki-sekkei-rpo/)に、中途の型と承認の段は[金融業界の採用代行](/media/rpo-kinyu-rpo/)に、建設の案件の型は[建設業界の採用代行](/media/rpo-kensetsu-rpo/)に書いています。ここでは、エネルギー業界で共通する切り分けに絞ります。

## エネルギー業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 型で求める人と経路が違う | 電力とガスは保安と地域、石油はプラント、再エネは開発と建設と運用保守、新電力は営業と技術と変化。来る人も動く理由も違う | 型と職種ごとに求人票と経路を分ける必要がある |
| 資格と保安が前提で市場が狭い | 技術職は資格と保安の体制に法令上の整理があり、有資格者は同業と隣接からしか来ない | 要件の決定は会社と専門家。代行は照合と隣接への言い換えまで |
| 勤務地が限られ転勤と地方が前提 | 発電所、プラント、保守の拠点は地方で、住居と移動と家族の設計が要る | 勤務地と生活の情報を先に出すかで応募が変わる |
| 中途の型が無く承認の段が多い | 新卒の一括採用の型が強く、中途の求人票と観点と経路が流用。決裁の段で日数が延びる | 中途の型を作り、承認の段を逆算する |
| 案件で人数が動き、営業は速さ | 再エネは開発・建設・運用保守の案件ごとに人数と時期が動く。法人営業は複数に同時に応募して速さで決まる | 通年の母集団と逆算、営業は一次対応の速さ |

五つのうち、代行で解決できるのは母集団形成と速さと情報の整理と中途の型で、資格・承認・見極め・相性・受け入れは社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 資格と保安の要件の決定（配置と体制を含む） | 残す | 会社と専門家。法令上の整理がある |
| 承認の手順（決裁、確認） | 残す | 会社の手順。代行は日程の逆算と書類の整理まで |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の設備で、〇〇の保守を、〇〇の規模で担った経験」に。代行が整え、責任者が確認 |
| 母集団形成（同業、隣接のプラントと設備、建設、電気設計） | 任せられる | 型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 現場の責任者の負担を減らす。営業は速さが要る |
| 勤務地と生活の情報の整理 | 任せられる | 拠点、住居、移動、転勤の型、家族の情報を一枚にする作業は外で。用意は会社 |
| 書類の一次確認 | 一部任せられる | 「資格・設備・保守の範囲・規模」の照合は外で。技術の質は社内 |
| 見極め（面接、技術の確認、現場を見せる） | 残す | 現場の責任者。保安の体制との相性 |
| 案件との相性の判断（再エネ） | 残す | どの案件に付けるかは事業の責任者 |
| 中途の運用の型（求人票、観点、経路） | 一緒に | 代行が型を持ち込み、会社が中身を決める |
| 受け入れ（最初の三か月、教える人、保安の教育、生活の立ち上げ） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 型と職種と拠点をまたいで一つの一覧。承認の段の日数を含む |

「資格と保安の要件」と「勤務地の設計」は、エネルギーに特有の残す工程です。資格と保安は、法令上の整理があると一般に整理されているため、会社と専門家が扱います。個別の判断は専門家にご確認ください。

### エラベルの見解

エネルギー業界で多くの会社が見落とすのは、「有資格者は同業からしか来ない」と決めて、要件を「経験者」のまま同業の掲載型にだけ出していることです。資格は前提でも、経験の中身を「設備・保守の範囲・規模」に分解すると、プラント、ビルの設備、建設の電気、製造の生産設備からも読めます。資格を「必須」「入社後に取得」「歓迎」に分け、取得の支援の中身を求人票に書くと、隣接から来る人が増えます。エラベルで担当者を選ぶ企業には、「技術職の要件は、資格の名前だけになっていませんか。設備と範囲と規模で書いていますか」を、私たちから先に聞いています。資格の名前だけなら、経路を増やす前に要件の言い換えです。要件の作り方は[電気設計の採用要件の作り方](/media/rpo-denki-sekkei-youken/)に、言い換えの手順は[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 型と職種と拠点と人数 | 電力・ガス・石油・再エネ・新電力のどの型で、保守・保安・開発・建設・運用・営業・事務のどれを、どの拠点で、何名 |
| 要件 | 資格と保安の要件を会社と専門家で整理し、「必須・入社後に取得・歓迎」に分けているか。設備と範囲と規模で書いているか |
| 承認の手順 | 決裁と確認の段と日数が決まっているか |
| 中途の型 | 中途の求人票・観点・経路が、新卒の流用でないか |
| 実態 | 保安の体制、当直と呼び出し、転勤の型、案件の山と谷、離職の状況を責任者が語れるか |
| 生活 | 拠点の住居、移動、転勤の型、家族の情報が一枚にあるか。用意できるものは何か |
| 枠 | 現場の責任者と決裁者の面接の枠を、週に一つ先に預けられるか |
| 受け入れ | 最初の三か月、教える人、保安の教育、生活の立ち上げが決まっているか |
| 記録 | 型と職種と拠点をまたいで、承認の段の日数を含む一覧があるか |

「要件が設備と範囲と規模で書けているか」と「勤務地と生活の情報が一枚にあるか」が要です。

## 型ごとに代行の型が違う

| 型 | 採用の特徴 | 代行に出しやすい工程 |
|---|---|---|
| 電力・ガス | 保安と地域。新卒の型が強い。承認の段が多い | 中途の運用の型、隣接に届く経路、日程の逆算、記録 |
| 石油・プラント | 設備と保守の規模。転勤と地方 | 勤務地と生活の情報の整理、プラントの隣接に届く経路、一次対応 |
| 再生可能エネルギー | 開発・建設・運用保守の案件ごと。速さと変化 | 通年の母集団、案件の見込みからの逆算、一次対応、記録 |
| 新電力・エネルギーサービス | 営業と技術と変化。事業会社に近い | 営業の母集団形成と一次対応の速さ、技術の隣接に届く経路 |

複数の型を持つ会社は、型ごとに代行の型が違うことを前提に、型ごとに「任せる・残す」を決めます。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| エネルギー業界の経験 | 担当者がエネルギーか設備かプラントの技術職の採用を担った経験があるか。型の違いを知っているか |
| 要件の言い換え | 資格の名前だけの要件を「設備・範囲・規模」に言い換え、隣接に届けた経験があるか |
| 勤務地と生活の情報 | 拠点と住居と転勤の型を一枚にして求人票に添える型を持っているか |
| 手順の理解 | 承認の段を前提に、日程を逆算した経験があるか。資格と保安の判断には踏み込まないか |
| 案件の変動への対応 | 案件の見込みから逆算し、通年で母集団を持つ運用ができるか |
| 費用 | 「工程・稼働時間・担当人数」をそろえて比べる。額の大小だけで決めない |

費用は、依頼する工程と稼働時間で大きく変わるため、同じ工程で比べる軸をそろえます。内訳の見方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 時期 | 起きること | 社内の対応 |
|---|---|---|
| 最初の二週間 | 要件と実態と手順と生活の情報の聞き取り。中途の求人票の作り直し | 責任者が実態を語る一時間。資格と保安の整理と承認の段を渡す |
| 一か月目 | 母集団形成と一次対応が回り、隣接からの応募が増える | 枠を預ける。決裁の日程を月の初めに決める |
| 二か月目 | 書類の照合で要件に合わない応募が減る。段ごとの日数が見える | 日数が長い段を直す。辞退の理由が「勤務地」なら生活の情報と用意の見直し |
| 三か月目 | 入社。受け入れが始まる | 教える人、保安の教育、生活の立ち上げ。離れたら理由を記録 |
| 案件の受注（再エネ） | 見込みから逆算して募集を前倒し | 通年の母集団から声をかける |

出したあとに「応募は増えたが承認で止まる」となるなら、手順の日数が逆算されていない印です。代行のせいにする前に、段ごとの日数を記録で見ます。

### エラベルの見解

エネルギー業界で見落とされやすいのは「勤務地と生活の情報」が求人票に無いことです。発電所やプラントや保守の拠点は地方で、候補者は仕事の内容と同じくらい「どこに住むのか」「転勤はどの型か」「家族はどうなるか」を見ています。ところが求人票は「勤務地：各事業所」で、転勤の型も住居も面接で聞かれてから答える。応募の前で止まり、来ても不安なまま入社して、転勤で離れます。拠点ごとの住居、移動、転勤の型（地域の中か全国か、期間の目安）、家族の情報を一枚にして添える。エラベルで担当者を選ぶ企業には、「転勤の型と拠点の住居の情報を、求人票に添えていますか」を、私たちから先に聞いています。添えていなければ、経路を増やす前に生活の情報の整理です。地域の採用の組み直しは[地方拠点の採用が進まない](/media/rpo-chihou-saiyo/)に書いています。

## まとめ

- エネルギー業界の難しさは**型で違う・資格と保安で市場が狭い・勤務地と転勤・中途の型が無く承認の段が多い・案件で動き営業は速さ**の五つ
- 外に出せるのは**母集団形成・一次対応・日程・勤務地と生活の情報の整理・記録**。残すのは**資格と保安の要件・承認・見極め・相性・受け入れ**
- **資格・保安は会社と専門家**。個別の判断は専門家にご確認ください
- 要件は**資格の名前だけでなく設備と範囲と規模で書き、隣接から読める**形に
- **勤務地と転勤の型と生活の情報を一枚にして添える**
- 型ごとに**代行の型が違う**。中途の型を新卒と分ける
- 費用は**同じ工程で比べる軸をそろえる**

## よくある質問

### 保安の体制に関わるので、外部に採用を任せられません

保安の要件と体制の判断は社内に残し、代行に渡す工程を分けます。一次対応と日程は氏名と連絡先と日程だけで担えます。書類の照合は、整理された要件（資格、設備、範囲、規模）に沿って行い、判断は社内です。資格と保安は、法令上の整理があると一般に整理されているため、会社と専門家で整理し、個別の判断は専門家にご確認ください。代行は整理された形に沿った運用を担い、判断には踏み込みません。

### 新電力で、営業が採れずに離れます

新電力の法人営業は、複数に同時に応募して速さで決まる職種で、返事が数日後なら条件を上げても届きません。一次対応を翌営業日中にし、面接の枠を先に預ける。離れる理由は「目標」「商品の実態」「教える人」に分けて記録し、受け入れ（最初の三か月の目標、同行）を直す。速さと受け入れの二つで、往復が止まります。営業の離職の分け方は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。

### 再エネの案件が読めず、いつ何名要るか決められません

決められない前提で、通年で母集団を持つ型に変えます。案件が決まってから募集を始めると、資格の照合と現場の面接と承認の段を通すのに時間がかかり、開始に間に合いません。開発・建設・運用保守の職種ごとに要件に合う候補者と接点を持ち、記録し、見込みが立った時点で声をかける。代行はこの通年の運用を担えます。過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。
