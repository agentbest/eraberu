エンゲージメント施策を副業で初めて受けるとき、見えにくいのは「施策を決める前に何を見て、決めたあとに誰が動き、何で効いたかを判断するか」です。募集文には「エンゲージメント向上施策の企画と実行」とだけあり、実際には、成功の定義、下がっている箇所の特定、四つの型からの選択、管理職が動く設計、実行の進行、三か月ごとの行動の記録と、企画の前後に工程が並び、しかも実行するのは会社と管理職です。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→特定と選択肢→会社の選択と設計→実行の進行→三か月の見直し→終了と引き継ぎ」の六つの段階で進み、契約前に範囲と成功の定義と管理職の時間と材料の共有と決定と費用と実行が会社であることと処遇に関わる施策の扱いと効果の見方と期間を決め、材料を匿名性を守った形で読んで下がっている箇所を一つに絞り四つの型から選択肢を出し、会社が一つ選んで管理職が動く型と頻度と記録と三か月の計画を設計し、管理職への説明と最初の一か月の確認とつまずきの整理と記録で進行を支え、三か月で行動の変化を見て直し、型と記録を引き継いで個人の情報を残さずに終えます。**案件の型と施策の四つの型は[エンゲージメント施策の副業案件](/media/fukugyo-engagement-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

エンゲージメント施策は、「効果」の定義が曖昧なまま始まりやすく、三か月後に「上がらなかった」で終わりやすい仕事です。契約前に、効果の見方まで決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 特定と選択肢だけか、設計と進行までか、効果の記録と見直しまでか、型作りか。イベントの運営は含まない | 「イベントの運営も」で稼働が取られる |
| 成功の定義（行動で） | 誰の、どの行動が、どう変われば成功か。サーベイの点の目標ではなく行動で | 点で評価され、点が動かなければ失敗になる |
| 管理職の時間 | 施策のために管理職が週にどれだけ動けるか。会社が確保するか | 施策が人事のイベントに落ちる |
| 材料の共有（匿名性を守った形） | サーベイの結果（出せる単位）、1on1のテーマの傾向、離職の記録（個人が特定されない形）、面談の傾向 | 個人の回答や中身を渡される |
| 施策の決定と費用と実行は会社 | 選択肢は出すが、選ぶのも費用を出すのも実行するのも会社と管理職 | 自分が主催者になる |
| 処遇に関わる施策の扱い | 報酬、手当、休暇、働き方の制度に関わる施策は、専門家の関与を前提に別の範囲で | 人事制度の設計に踏み込む。個別の判断は専門家にご確認ください |
| 効果の見方 | 行動の変化（面談の実施率、役割の明確化の進み、情報の共有の回数、承認の場の実施）を主に。サーベイと離職は結果として | 三か月でサーベイの点だけを見る |
| 期間 | 三か月を一区切りに。何区切りか | だらだら続く |

止まりやすいのは、「サーベイの点を〇〇まで上げたい」を成功の定義にして始めるときです。点は結果で、施策で直接動かせるのは行動です。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 特定と選択肢：材料を読み、下がっている箇所を一つに、四つの型から選択肢

施策の前に、下がっている箇所を一つに絞ります。材料は、匿名性を守った形で受け取ります。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 材料を読む（サーベイの出せる単位の傾向、1on1のテーマの傾向、離職の時期と理由の傾向、面談の傾向） | 材料の共有（個人が特定されない形） | 個人の回答や中身を読む |
| 下がっている箇所を一つに絞る（上司との関係か、役割の曖昧さか、情報の不足か、承認の無さか。施策で動かせる箇所） | 絞ることへの合意 | 全部を直そうとする |
| 四つの型から選択肢（二〜三つ。それぞれに「管理職が何をするか」「要る時間」「効果の見方（行動）」「歪みやすい箇所」の欄） | 選ぶのは会社 | 「管理職が何をするか」が空欄の施策を入れる |
| イベントや福利厚生の要望の扱い（四つの型に紐づけられるなら紐づけ、紐づかないなら「効きにくい」と伝える） | 要望の整理 | 要望をそのまま施策にする |
| 処遇に関わる施策の切り分け（選択肢に入れるなら、専門家の関与が前提と明記） | 専門家の関与の判断 | 自分で設計する |

止まりやすいのは、材料の中で「この管理職の部署が低い」と個人を特定するときです。傾向として扱い、管理職を裁かず、型と時間の問題として選択肢を出します。課題の絞り方は[課題の言語化](/media/fukugyo-kadai-teigi/)に、選択肢の出し方は[提案のまとめ方](/media/fukugyo-teian/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「選択肢の一つ一つに『管理職が何をするか』を書けるか」で、効くかどうかが決まります。「社内報を充実させる」「懇親会を増やす」には、管理職の行動が無く、日常が変わりません。「上司の1on1で、月に一度、本人への期待を一つ言葉にして伝える」には、管理職の行動があり、型にでき、記録でき、三か月後に「上司から期待を伝えられた」の項目が動きます。エラベルで担当者を選ぶ企業には、「施策の選択肢は、管理職の方が何をするかが書けるものだけをお出しします。書けないものは、効きにくいとお伝えします」と、私たちから先に伝えています。受ける側がその場で使える判断としては、選択肢の表に「管理職が何をするか」の欄を最初の列に置くこと。最初の列が埋まらない行は、表に載せません。

## 会社の選択と設計：一つに絞る、管理職が動く型と頻度と記録、三か月の計画

会社が一つ選んだら、管理職が日常で動く形に設計します。

| 作るもの | 中身 | 落とし穴 |
|---|---|---|
| 会社の選択の書面 | 選んだ施策、理由、成功の定義（行動）、期間。決めた人の名前 | 書面が無く、途中で施策が増える |
| 管理職が動く型 | 何を（例：期待を一つ伝える）、どう（面談の中で、一枚の型で）、どのくらいの時間で | 型が無く「意識して」で終わる |
| 頻度と記録 | 月に何回、誰が、何を記録するか（実施したか、何を伝えたか。部下の反応は書かない） | 記録が部下の評価に使われる形 |
| 最初の三か月の計画 | 一か月目（説明と初回）、二か月目（続ける）、三か月目（見直し）。管理職ごとの予定 | 計画が無く、初回だけで止まる |
| 管理職への説明の資料 | なぜこの施策か（下がっている箇所を傾向で）、何をするか（型）、要る時間、記録、何をしないか（部下の評価に使わない） | 管理職を責める資料 |
| 社員への伝え方（会社から） | 何が変わるか、いつから、なぜ。管理職が動く前に社員が知っている形 | 社員に何も伝えず始める |

止まりやすいのは、型を「意識してください」で終えることです。行動は、型と頻度と記録が無いと続きません。面談の型の作り方は[1on1・メンタリングの副業の実務](/media/fukugyo-one-on-one-shigoto/)の管理職の1on1の型と共通です。

## 実行の進行：管理職への説明、最初の一か月の確認、つまずきの整理、記録

実行は会社と管理職が行い、自分は進行の支援と記録です。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 管理職への説明の場（会社の責任者が話す。自分は資料と進行の補助。質問への答えは型で） | 最初に一度 | 自分が説明して「外から来た施策」になる |
| 最初の一か月の確認（型どおりに動いたか、管理職ごとの実施の記録。動かなかった理由） | 二週目と四週目 | 動かなかった管理職を責める |
| つまずきの整理（型が使いにくい、時間が取れない、部下の反応に戸惑う、を分けて、型の直しか時間の確保かを会社に返す） | 出るたび | つまずきを放置する |
| 記録（実施率、型の使われ方、つまずき。部下の個人の反応は書かない） | 週次か月次 | 部下の反応を個人で記録する |
| 社員側の反応の把握（1on1のテーマの傾向やサーベイの出せる単位で。個人は特定しない） | 月次 | 社員に「上司はどうだったか」を個別に聞く |
| 週次か月次の報告（実施率、つまずきと直したこと、次に直すこと一つ） | 決めた頻度 | 効果を急いで報告する |

止まりやすいのは、最初の一か月で実施率が低いときに、施策を変えることです。変える前に、型と時間の問題を分けて直します。報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

### エラベルの見解

同じ料金・同じ施策でも、結果が分かれるのは、「最初の一か月の実施率を、管理職の責任にしないでいられるか」です。実施率が低いとき、「管理職の意識が低い」と報告した担当者の施策は、管理職が身構え、二か月目にさらに落ちます。「実施率が低い管理職には共通して、面談の枠が取れていない。会議の削減か枠の固定を会社が決めれば動く」と、型と時間の問題に分けて会社に返した担当者の施策は、二か月目に上がります。管理職は、施策に反対しているのではなく、時間と型が無いだけのことが多い。エラベルで長く続いている担当者は、報告に「実施率」と「動かなかった理由の分類（型・時間・その他）」の欄を持ち、「意識」という言葉を使っていません。受ける側がその場で使える形としては、動かなかった理由を「型」「時間」「その他」の三つに分ける欄を、記録の型に最初から作ることです。

## 三か月の見直し：行動の変化、サーベイと離職は結果として、直す

三か月の区切りで、会社と見直します。見るのは、行動の変化が主で、サーベイと離職は結果です。

| 見ること | 読み方 | 直すところ |
|---|---|---|
| 行動の変化（実施率、型の使われ方、つまずきの減り方） | 型が日常に入ったか | 型か頻度か時間 |
| 社員側の反応（サーベイの出せる単位、1on1のテーマの傾向） | 下がっていた箇所が動いたか（三か月では動かないこともある） | 施策を変えるか続けるか（会社） |
| 離職（時期と理由の傾向） | 下がっていた箇所に関わる離職が変わったか | 結果として記録 |
| 管理職の困りごと | 型の使いにくさ、時間 | 型を直す。時間を会社が確保 |
| 次の三か月 | 同じ施策を続けるか、次の箇所に移るか | 決めるのは会社 |

止まりやすいのは、三か月でサーベイの点が動かないと「効かなかった」と施策を変えることです。行動が変わっていれば、点は遅れて動きます。行動が変わっていなければ、施策ではなく実行の問題です。

## 終了と引き継ぎ：型と記録、個人の情報を残さない

- **残すもの。** 下がっている箇所の見方の型、施策の選択肢の型（管理職が何をするかの欄付き）、管理職が動く型と頻度と記録の型、管理職への説明の資料、実施の記録（個人が特定されない形）、三か月の見直しの記録
- **返すもの。** 材料（サーベイ、1on1の傾向、離職の記録）へのアクセス。個人の情報を自分の手元に一切残さない
- **次の提案。** 同じ施策の継続、次の箇所への展開、社内で回す型の引き継ぎ

引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 材料の扱い

エンゲージメント施策の材料は、サーベイの結果、1on1のテーマの傾向、離職の記録、面談の記録で、いずれも社員の本音と個人の事情を含みます。受け取るのは匿名性を守った傾向だけにし、個人の回答や中身や離職者の個別の事情を読まず、「この人が」「この管理職が」と特定せず、記録に個人の反応を書きません。管理職の実施の記録は、管理職の評価に使わせず、型と時間の改善の材料にします。材料を自分の端末に置かず、会社の管理する場所でだけ扱います。他の依頼側や本業の施策や数字を持ち込みません。個別の判断は専門家にご確認ください。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 稼働時間は何で決まるか

全体の時間は、「特定と選択肢（材料の量、選択肢の数）」「設計（型、計画、説明の資料）」「実行の進行（管理職の人数×確認の頻度×三か月）」「三か月の見直し」の合計で決まり、実行そのものは会社と管理職が行うので自分の稼働には乗りません。管理職の人数が多いと、確認と記録の時間が比例して増えます。イベントの運営を含めると、当日の稼働が別に乗るので、含めるなら別の範囲にします。受ける前に「管理職の人数」「確認の頻度」「期間」「イベントの運営を含まないこと」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、最初の三か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→特定と選択肢→会社の選択と設計→実行の進行→三か月の見直し→終了と引き継ぎ**の六つの段階
- 契約前に**範囲・成功の定義（行動で）・管理職の時間・材料の共有（匿名性を守った形）・決定と費用と実行は会社・処遇に関わる施策の扱い・効果の見方・期間**を決める。「点を〇〇まで」を成功の定義にしない
- 特定は**材料を傾向で読み、下がっている箇所を一つに絞り、四つの型から「管理職が何をするか」が書ける選択肢だけを出す**。管理職を裁かない
- 設計は**会社が一つ選んで書面に、管理職が動く型と頻度と記録、三か月の計画、管理職への説明の資料、社員への伝え方**。「意識して」で終えない
- 進行は**説明は会社の責任者が話し、最初の一か月の実施率を確認し、動かなかった理由を「型・時間・その他」に分けて会社に返す**
- 見直しは**行動の変化が主、サーベイと離職は結果**。三か月で点が動かなくても行動が変わっていれば続ける
- 材料は**匿名性を守った傾向だけを受け取り、個人を特定せず、管理職の記録を評価に使わせない**

## よくある質問

### 会社が「三か月でサーベイの点が上がらなかったので、施策を変えたい」と言います

行動の変化を先に見せます。「管理職の面談の実施率はこう上がり、期待を伝えた記録はこう残っています。行動が変わったのは三か月前からで、サーベイの点は遅れて動きます。次の三か月は同じ施策を続けて、点の変化を見ませんか」と、行動と点の時間差を伝えます。行動が変わっていないなら、施策ではなく実行の問題（型か時間）で、そこを直します。施策を三か月ごとに変えると、どれも日常に入らず、社員は「また新しいことが始まった」と受け取ります。判断は会社です。

### 施策の一環で、報酬や休暇の制度を変えたいと言われました

処遇に関わる施策は、人事制度の設計と同じ重さで、専門家（社会保険労務士など）の関与が要ります。「報酬や休暇の制度は、専門家の関与と、決めるのは経営者という前提で、別の範囲として進めましょう。エンゲージメント施策としては、上司・役割・情報・承認の四つの型で、制度に触れない施策を先に進めます」と、範囲を分けます。個別の判断は専門家にご確認ください。制度に関わる設計の条件は[人事制度の設計の副業案件](/media/fukugyo-jinji-seido-fukugyo/)に書いています。

### 管理職から「施策のせいで面談が増えて、業務が回らない」と言われました

管理職を責めず、時間の問題として会社に返します。「面談の枠を取るために、会議を一つ減らすか、面談の時間を短くするか、会社に決めてもらいます」と、型か時間のどちらを直すかを整理し、会社が決める形にします。管理職の時間が無いまま施策を続けると、形だけになり、管理職は施策を嫌います。時間を作ることが最初の施策になることもあります。管理職の声は、施策を直す最も良い材料です。
