飲食業界の会社が採用代行を検討するとき、動機は「ホールとキッチンが常に足りず、店長が営業と採用を一人で抱えている」「出店に店長候補が間に合わない」であることが多い。ただ、飲食の採用は、小売と似た難しさに加えて、業界に特有の難しさがあります。ホール・キッチン・調理師・店長候補で経路も要件も違い、応募者は先に返事が来た店で決まり、店長は仕込みと営業で面接の時間が取れず、営業時間と土日の実態が定着を左右し、離職が多く常に募集している。結論を先に書くと、**飲食業界の採用代行は、店舗の一次対応・日程・記録・地域の経路の運用は外に出せる一方、店舗の見極め・シフトと条件の判断・受け入れ・調理の技能の見極めは社内に残さないと、採れても店舗で続きません。**代行に出す前に、難しさを自社の状況で分解し、職種の型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[飲食店スタッフ採用を代行に出す判断基準](/media/rpo-inshoku-rpo/)や[調理師採用を代行に出す判断基準](/media/rpo-chourishi-rpo/)に、小売との共通点は[小売業界の採用代行](/media/rpo-kouri-rpo/)に書いています。ここでは、飲食業界で共通する切り分けに絞ります。

## 飲食業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 職種の型で経路と要件が違う | ホールとキッチンのパート・アルバイトは地域の経路と速さ、調理師は技能と紹介、店長候補は掲載型と登用 | 一つの代行で全部は回らない |
| 先に返事が来た店で決まる | 応募者は複数の店に同時に応募し、当日の返事で決まる | 一次対応を店長に残すと流れる |
| 店長が仕込みと営業で面接に出られない | 面接の枠は営業の合間（アイドルの時間帯）か営業の前後に限られる | 枠の預かり方を変える必要 |
| 営業時間と土日の実態 | 夜の営業、土日、繁忙の実態が求人票に無いと入店後に離れる | 実態を先に出すかで応募と定着が変わる |
| 常に募集している | 離職が多く、募集が止まらず、店長が疲弊 | 採用の入口だけ直しても、受け入れと実態が合わなければ繰り返す |

五つのうち、代行で解決できるのは速さと母集団形成で、見極め・シフト・受け入れ・技能の判断は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 店舗ごとの採る数と時期（繁忙期・出店） | 残す | 本部と店長が決める |
| 店舗の求人票の型（営業時間・土日・シフト・実態） | 一緒に | 本部が型を作り、店舗の実態を店長が埋める。代行が整える |
| 店舗の母集団形成（地域の経路、店頭、知人） | 一部任せられる | 地域の媒体の運用は外で。店頭と知人は店舗 |
| 店舗の一次対応（返信・日程） | 任せられる | 当日の返事が要る工程。店長に残すと流れる |
| 店舗の見極め（面接） | 残す | 店長。観点と記録の形は一つに |
| 調理の技能の見極め（実技、試食） | 残す | 料理長か店長 |
| シフトと条件の判断 | 残す | 店長と本部 |
| 店舗の受け入れ（最初の一週間、教える人） | 残す | 店長。離職を減らす要 |
| 店長候補の要件と登用 | 残す | 本部 |
| 記録と報告 | 任せられる | 店舗をまたいで一つの一覧 |

「店舗の一次対応」を外に出すことが、飲食で最も早く効く工程です。店長の時間が営業と受け入れに戻ります。

### エラベルの見解

飲食業界で多くの会社が見落とすのは、「店長の面接の枠」が営業の構造で決まっていることです。昼と夜の営業の間（アイドルの時間帯）か、営業の前後にしか枠が無く、応募者の希望と合わないと日程が延び、応募者は他の店で決まる。枠の預かり方を「アイドルの時間帯に三十分、週に二つ」と先に決め、応募者にその候補を当日中に出して確定する。応募者の希望を聞いてから調整する形をやめるだけで、面接に来る人が増えます。エラベルで担当者を選ぶ企業には、「店長の面接の枠は、営業のどの時間帯に、週にいくつ決まっていますか」を、私たちから先に聞いています。決まっていなければ、枠の設計が最初です。枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種の型と経路 | ホール・キッチン・調理師・店長候補のどれを採るか。型ごとの経路 |
| 当日の返事の体制 | 応募に当日中に返す窓口があるか。店長に残すか外に出すか |
| 店長の枠 | アイドルの時間帯か営業の前後で、週に決まった数出せるか |
| 求人票の型 | 営業時間・土日・シフト・繁忙・一緒に働く人・最初の一週間を、店舗ごとに埋められる型があるか |
| 離職の理由 | 退職の記録があるか。実態・受け入れ・店長との関係・条件のどれか |
| 受け入れ | 最初の一週間の教える人と到達点が、店舗ごとにあるか |
| 記録の形 | 店舗をまたいで一つの一覧があるか |

「当日の返事の体制」と「店長の枠」が、飲食で最も詰まります。

## 職種の型ごとに代行の型が違う

| 職種の型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| ホール・キッチンのパート・アルバイト | 地域の媒体の運用、一次対応（当日の返事、日程）、記録 | 店長の見極め、シフト、受け入れ。[飲食店スタッフの採用要件の作り方](/media/rpo-inshoku-youken/) |
| 調理師 | 紹介と掲載型の母集団形成、一次対応 | 技能の見極め（実技）、料理長との相性。[調理師の採用要件の作り方](/media/rpo-chourishi-youken/) |
| 店長候補 | 掲載型とスカウトの母集団形成、一次対応 | 登用の道筋、見極め |
| 本部（企画・開発・管理） | スカウトと紹介、一次対応 | 部門の責任者の要件と見極め |

「飲食の採用に強い代行」でも、ホールとキッチンの速さの型と、調理師と店長候補の型の両方を持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 店舗の一次対応の速さ | 「店舗への応募に、何時間以内に返しますか。営業中と閉店後の応募はどうしますか」 |
| 店長の枠の預かり方 | 「アイドルの時間帯にしか出られない店長の面接を、どう組みますか」 |
| 型ごとの経路 | 「ホールのアルバイトと調理師で、経路と文面をどう変えますか」 |
| 店舗をまたぐ運用 | 「複数の店舗の募集を、一つの一覧と一つの観点でどう回しますか」 |
| 担当者の経歴 | 「担当する方は、飲食のどの型の採用を、どの工程で担った経験がありますか」 |
| 記録の置き場所 | 「店舗をまたぐ記録はどこに置きますか。契約が終わったら」 |
| 費用の構造 | 「月額に含まれる工程と店舗の数は」 |

費用は、含まれる工程と店舗の数で変わり、金額の相場を先に聞くより「同じ工程・同じ店舗数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 応募は増えたが、面接に来ない | 返事が店長に残っていて遅い。枠が応募者の希望と合わない | 一次対応を外に出し、当日中に。枠を先に預かる |
| 入店後にすぐ辞める | 営業時間と土日の実態が求人票に無い。最初の一週間の教える人がいない | 求人票の型に実態を。受け入れの一枚 |
| 調理師が採れない | ホールと同じ型で探している | 紹介と技能の見極めの型で |
| 店舗によって通過が違う | 観点と記録の形が店舗ごと | 一枚を全店長に。決めるのは店長 |
| 繁忙期と出店に間に合わない | 店舗ごとの計画と採用の一枚が無い | 数か月前に一枚で準備 |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「一次対応の分担」「枠」「実態と受け入れ」「型」「計画」に戻ります。

### エラベルの見解

飲食業界で「常に募集している」状態は、採用の入口の問題ではなく、離職の問題です。退職の理由を集めると、「営業時間と土日が聞いていたのと違った」「最初の一週間に誰も教えてくれなかった」「店長との関係」が並びます。求人票の型に実態を書き、最初の一週間の教える人を決め、店長の負担（返事と日程）を外に出して受け入れの時間を作る。それで離職が減り、募集が減ります。エラベルは担当者を工程ごとに選べる形にしているので、「店舗の一次対応と日程と記録」を担当者が担い、店長は「面接の三十分と最初の一週間の受け入れ」に絞る、という組み方ができます。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に、受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## まとめ

- 飲食業界の難しさは、**職種の型・先に返事が来た店で決まる・店長の枠・営業時間と土日の実態・常に募集**の五つ
- **店舗の一次対応・日程・記録・地域の経路の運用は任せられ、見極め・シフトと条件・受け入れ・技能の見極めは残す**
- 最も早く効くのは**店舗の一次対応を外に出す**こと。店長の枠は**アイドルの時間帯か営業の前後で週に決まった数**を先に
- 店長は**「面接の三十分と最初の一週間の受け入れ」**に絞る
- 求人票の型に**営業時間・土日・シフト・繁忙・一緒に働く人**を店舗ごとに埋める
- 調理師と店長候補は**ホールとキッチンの型と分けて**
- 「常に募集」は**離職の問題**。実態と受け入れを直してから代行に

## よくある質問

### 個人の店で、店長が私一人です。代行に出す意味はありますか

店長一人の店ほど、返事と日程を外に出す効果は大きい。営業中に応募を見られず、翌日に返す間に応募者は他の店で決まります。「一次対応と日程」だけを代行に出し、店長は面接と受け入れだけにする形なら、店舗の数に関係なく機能します。費用は含まれる工程で変わり、一工程なら小さい。判断は店長で、代行は「同じ工程で比べる軸」をそろえるまでです。

### 調理師の採用で、技能をどう確かめればよいか分かりません

調理師の技能は、書類と面接では読めず、実技（試食、仕込みの一部）で確かめます。実技の内容と見る観点（衛生、段取り、味の再現、指示の受け方）は、料理長が決めます。代行は、実技の日程と候補者への案内までで、技能の判断はしません。要件は「〇〇の型の店で、〇〇の規模の仕込みと営業を担った経験」で絞り、紹介と掲載型で集めます。要件の作り方は[調理師の採用要件の作り方](/media/rpo-chourishi-youken/)に書いています。

### 出店が続き、店長候補が育っていません

社内の登用の道筋（副店長からの期間、到達点、判断の基準）を一枚にすることが先です。外から採る店長候補も、登用の道筋が無い会社では定着しません。外から採る場合は、ホールとキッチンの型では届かず、「〇〇の型の店で、〇〇の規模のチームと売上を担った経験」に絞り、掲載型とスカウトで、「この会社で店長として担うこと」「本部との関係」を実態で書きます。出店の計画と店長候補の採用を、採用の一枚の同じ行に置きます。
