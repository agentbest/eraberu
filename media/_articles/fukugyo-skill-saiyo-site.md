「採用サイトを作り直したい」という依頼で、制作会社と一緒に見た目を新しくし、写真を撮り直し、代表のメッセージを載せても、応募は変わりません。採用サイトを見る候補者は、スカウトや求人票を見た後に「この会社は実際どうか」を確かめに来ています。確かめたいことに答えていないサイトは、見た目が良くても閉じられます。結論を先に書くと、**採用サイトの作り直しは、デザインではなく「候補者が検索した先で判断できる六つの要素（この会社で働く理由・任せる仕事の実態・一緒に働く人・最初の三か月・選考の流れ・応募の入口）」を置くことで、材料は要件の一枚とターゲット像といまうまくやっている人の言葉、盛らず、制作会社と担当者の範囲を切り分け、公開後は検索から来た人の応募を見ます。**スカウトからの導線は[採用サイトへの導線](/media/scout-saiyo-site-doushen/)に、会社側の手順は[採用サイトの運用の進め方](/media/rpo-task-saiyo-site-susumekata/)に書いています。ここでは、作り直しの型に絞ります。

## 見た目を新しくしても応募が変わらない理由

| 作り直しの形 | 候補者に起きること |
|---|---|
| デザインと写真を刷新 | 「きれい」で終わる。判断の材料が無い |
| 代表のメッセージが先頭 | 候補者は仕事の実態を知りたい。理念は後 |
| 「働く環境」「福利厚生」の一覧 | どの会社にもある。差が分からない |
| 社員の笑顔の写真 | 実態が分からない |
| 応募の入口が奥にある | 判断した後に、どこから応募すればよいか分からない |

候補者は、スカウトの文面や求人票で「この役割」に関心を持ち、サイトで「この会社の実態」を確かめ、合うと判断したら応募します。サイトは、その確かめに答える場です。広報とスカウトの関係は[採用広報とスカウトの連携](/media/scout-koho-renkei/)に書いています。

## 置く六つ

| 要素 | 中身 | 材料 |
|---|---|---|
| この会社で働く理由 | ターゲット像の「動く理由」に対応する実態。三つに絞った魅力 | [自社の魅力を3つに絞る](/media/fukugyo-skill-uriba/) |
| 任せる仕事の実態 | 役割ごとに、実際の一日、扱う案件、裁量の範囲 | いまうまくやっている人の一日 |
| 一緒に働く人 | チームの構成、上長、隣の部門。社員の言葉で | いまうまくやっている人の言葉 |
| 最初の三か月 | 入社してからの流れ。誰と何を引き継ぐか | 求人票の六つの要素 |
| 選考の流れ | 段の数、各段で何を確かめるか、日数の目安 | [面接の設計](/media/fukugyo-skill-mensetsu-sekkei/) |
| 応募の入口 | 各ページから一回で応募か「まず話を聞く」に進める | カジュアル面談の入口 |

六つは、求人票の六つの要素と重なります。求人票が役割ごとの一枚なら、サイトは会社全体で六つを置き、役割ごとのページに求人票をつなげます。求人票の型は[ジョブディスクリプションを書く](/media/fukugyo-skill-jd/)に書いています。

### エラベルの見解

担当する側から見ると、採用サイトで最も差がつくのは、「いまうまくやっている人の言葉」を材料にできるかです。受ける側は、制作会社のインタビューで「やりがいは」「会社の魅力は」と聞き、社員は「成長できる」「風通しが良い」と答え、それがそのまま載ります。それは他社にも書ける言葉です。「入った頃、最初の三か月で何をしましたか」「前の会社と一番違うことは何ですか」「いま、一日の時間を何に使っていますか」と聞くと、実態の言葉が出て、それは他社に書けません。エラベルで担当者を選ぶ企業には、「採用サイトの社員の言葉は、『前の会社と違うこと』を聞いて書かれていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、制作会社のインタビューの前に、聞く問いを担当者が三つ用意して渡すこと。問いが変われば、載る言葉が変わります。聞き方は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)と同じです。

## 材料は三つ

| 材料 | 何に使うか |
|---|---|
| 要件の一枚 | 役割ごとのページの「任せる仕事」「求める経験」 |
| ターゲット像の一枚 | 「この会社で働く理由」を動く理由に対応させる。「迷う理由」に先回りするページの構成 |
| いまうまくやっている人の言葉 | 「一緒に働く人」「任せる仕事の実態」「最初の三か月」 |

三つが無いまま制作会社に発注すると、制作会社は一般的な採用サイトの型で作ります。三つを先に揃え、発注の一枚に添えます。ターゲット像の作り方は[ターゲット像を1枚にまとめる](/media/fukugyo-skill-persona/)に書いています。

## 盛らない・実態と違うことを書かない

| 避けること | 理由 | 代わりに |
|---|---|---|
| 実態より良い働き方の記述 | 入社後に「違った」となり、早期の離職につながる | いまの実態を、社員の言葉で |
| 「成長」「やりがい」「アットホーム」 | 他社にも書ける | 実態の場面（「入社二年目から案件の予算を任せている」など、実績があるものだけ） |
| 収入や昇進を保証するように読める表現 | 保証できない | 実績としてある例を、例として |
| 一部の人の例を全体のように | 「一年で〇〇になれる」 | 「一年で〇〇になった人がいる」まで |
| 性別や年齢に触れる表現 | 募集や採用で法令上の決まりがあると一般に整理されている | 依頼側の決まりと専門家の確認に従う |

採用サイトの表記には、募集に関わる法令上の整理（労働条件の明示、差別的な表現の禁止など）が関わることがあります。表記の可否は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## 制作会社と担当者の範囲

| 担当者が担う | 制作会社が担う | 依頼側が決める |
|---|---|---|
| 六つの要素の構成と、材料の三つ | デザイン、実装、写真の撮影 | 発注先、費用、公開の判断 |
| 社員に聞く問いの用意 | インタビューの実施と原稿（担当者が問いを渡す） | 掲載する社員と内容の承認 |
| 原稿の「実態と合っているか」の確認（現場の責任者と） | 原稿の文章の整え | 表記の可否（専門家の確認） |
| 公開後に見る数字の設計 | 計測の実装 | 見直しの判断 |

担当者が制作の作業（デザイン、実装）に踏み込むと、稼働が消えます。担当者の役割は、「何を置くか」と「材料」と「実態との照合」です。制作会社の選定と費用は依頼側の判断で、担当者は「六つの要素を置ける構成か」を確かめる項目を並べるまでです。費用や相場は断定しません。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「採用サイトは、公開したら終わり」というものです。実際には、公開した後に、検索から来た人が応募したか、面接で「サイトの〇〇を見て」という声が出たか、を見て初めて、六つのどれが効いていて、どれが読まれていないかが分かります。見ないまま次の作り直しをすると、また見た目の話になります。受ける側がその場で使える判断としては、公開の前に「見る数字」を二つ決めること。「サイト経由の応募の数」と「面接で『サイトを見て』と言った候補者の数」。後者は面接の記録の「候補者の質問と迷い」の欄に一語足せば取れます。数字は件数のまま並べ、割合で断定しません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 進め方の順

| 順 | 中身 |
|---|---|
| 一 | いまのサイトを六つの要素で診断する。無いもの、他社にも書ける言葉で書かれているもの |
| 二 | 材料の三つを揃える。無ければ先に作る |
| 三 | 六つの要素の構成の一枚を作り、依頼側と合意 |
| 四 | 社員に聞く問いを用意し、制作会社に渡す |
| 五 | 原稿を現場の責任者と「実態と合っているか」で確認。盛りを外す |
| 六 | 表記の可否を依頼側の決まりと専門家で確認 |
| 七 | 公開。見る数字を二つ決めておく |
| 八 | 三か月後に数字を見て、六つのどれを直すか一つ決める |

一の診断は、[求人原稿を書き直す手順](/media/fukugyo-skill-kyujin-genkou/)と同じで、ゼロから作り直さず、欠けと抽象語を見つけるところから始めます。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側がデザインの話から始める | 六つの要素で診断した一枚を先に見せ、「何を置くか」を先に決める |
| 社員の言葉が「成長できる」ばかり | 問いを変える。「前の会社と違うこと」「最初の三か月」「一日の時間の使い方」 |
| 代表のメッセージを先頭に置きたがる | 「この会社で働く理由」の中に、動く理由に対応する形で置く。先頭は仕事の実態 |
| 制作会社の型に流される | 発注の一枚に六つの要素と材料を添え、構成を先に合意 |
| 実態より良い原稿になる | 現場の責任者と照合。「いま、本当にそうか」 |
| 公開後に何も見ない | 見る数字を二つ、公開の前に決める |

## まとめ

- 見た目を新しくしても応募は変わらない。サイトは**候補者が検索した先で確かめる場**
- 置くのは**働く理由・仕事の実態・一緒に働く人・最初の三か月・選考の流れ・応募の入口**の六つ
- 材料は**要件の一枚・ターゲット像・いまうまくやっている人の言葉**。制作会社に渡す問いを担当者が用意する
- **盛らない**。他社にも書ける言葉を消し、実態の場面を社員の言葉で。表記の可否は専門家に。個別の判断は専門家にご確認ください
- 担当者は**何を置くか・材料・実態との照合**。制作と費用は制作会社と依頼側
- 公開の前に**見る数字を二つ**決め、三か月後に一つ直す

## よくある質問

### 予算が無く、制作会社に頼めないと言われました

六つの要素は、既存のサイトの中身を書き換えるだけでも置けます。デザインを変えずに、「任せる仕事の実態」「最初の三か月」「選考の流れ」のページを足すか、既存のページの文章を実態の言葉に直す。それだけで、確かめに来た候補者への答えになります。見た目の刷新は、六つが揃ってからでも遅くありません。文章の直し方は[求人原稿を書き直す手順](/media/fukugyo-skill-kyujin-genkou/)と同じです。

### 社員インタビューに出てくれる人がいません

インタビューの形にせず、「いまうまくやっている人に、三つの問いを聞いて、本人の言葉を確認の上で載せる」形にします。顔写真と氏名を出すかは本人の意向で、出さなくても「〇〇の役割・入社〇年目」の形で載せられます。載せる内容は本人が確認し、依頼側が承認します。本人が「載せたくない」と言えば載せません。

### 採用サイトの効果を、依頼側に数字で示せと言われました

公開の前に決めた二つの数字（サイト経由の応募の数、面接で「サイトを見て」と言った数）を、件数のまま並べます。公開の前と後で比べられるように、公開前の数も記録しておきます。「応募が〇倍になった」のような割合の断定は、件数が少ないうちはしません。サイトの効果は、応募の数だけでなく、面接で候補者が「実態を知って来ている」かでも見えます。それは面接官の記録から拾えます。
