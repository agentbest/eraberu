数か月前に送って、返信が無かった候補者がいる。役割はまだ空いていて、その人の経歴は今も合っている。もう一度送りたい。しかし、前回と同じ文面は送れないし、「その後いかがですか」も何かが違う。どう書けばよいか分からず、手が止まっている。結論を先に書くと、**時間を空けた再送は、二通目でも追客でもなく、「新しい一通」として書きます。先頭に置くのは「久しぶりに」ではなく「新しい理由」（役割が変わった、会社に新しい事実が加わった、相手の経歴が動いた、相手が言った時期が来た）です。前回送ったことに一言触れ、相手の状況が変わっている前提で、前回と違う切り口で短く書きます**。一〜二週間以内の二通目は[2通目の文面をどう変えるか](/media/scout-nido-me/)に、送る回数の判断は[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/)にまとめています。

## 空けた後の再送が書けない構造

時間を空けた再送が書けない、または書いても返信が来ないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「再送」と考えている | 前回の文面をベースに手直ししようとし、前回と同じ話になる |
| 新しい理由が無い | 「まだ空いているので」が理由で、相手には「埋まらなかったのか」と見える |
| 前回に触れない | 前回を隠して初回のふりをし、相手が覚えていた場合に信頼を落とす |
| 「久しぶりに」が先頭 | 時間が経ったことを先に言い、肝心の理由が後ろに埋もれる |
| 相手の変化を見ていない | 数か月で相手の経歴や状況は動いているのに、前回と同じ経歴の箇所に触れる |
| 前回の文面が残っていない | 誰に何を送ったかの記録が無く、前回と同じことを書いてしまう |
| 送ってよい相手の基準が無い | 断られた相手にも送り、「しつこい」と見られる |

構造の大半は、「再送」という言葉で考えていることです。新しい一通として考えると、書けます。

## 再送してよい相手の条件

時間を空けた再送は、誰にでも送るものではありません。条件で分けます。

| 相手の状態 | 再送 | 理由 |
|---|---|---|
| 前回、返信が無かった | 可 | 意思の表明が無い。新しい理由があれば送れる |
| 前回、「今は考えていない」と返信があった | 可（時期に配慮） | 時期を言われたならその少し前に。言われていないなら三か月以上空けて |
| 前回、「興味が無い」「連絡不要」と返信があった | 不可 | 意思の表明。役割が大きく変わっても、原則は送らない |
| 前回、やり取りが途中で止まった | 可 | 追客の対象だった相手。止まった段階に触れて送る。[追客（フォローアップ）の設計](/media/scout-tsuiokuri/) |
| 前回、選考で不採用にした | 条件付き | 「前に落とした」を隠さず、なぜ今回は合うかを書く。[不採用にした人にもう一度声をかけたい](/media/rpo-fugouhi-saikatsuyou/) |
| 前回から経歴が変わり、条件が合わなくなった | 不可 | 経歴を見直して合わないなら送らない |
| 媒体上で、活動を止めている | 不可か保留 | 媒体の表示で判断。仕様は公式の案内で確認 |

再送の前に、前回の記録と、相手の今の経歴の両方を見ます。どちらかが無いと、判断できません。

## 新しい理由の作り方

時間を空けた再送の先頭に置く、「新しい理由」です。「まだ空いているので」は理由になりません。

| 理由の種類 | 例 | 書き方 |
|---|---|---|
| 役割が変わった | 役割の範囲が広がった、裁量が増えた、チームの体制が変わった | 「前回ご連絡した〇〇の役割ですが、△△の点が変わりました」 |
| 会社に新しい事実が加わった | 新しい事業、新しい拠点、新しい体制、働き方の制度 | 「その後、□□が加わり、改めてご連絡したいと考えました」 |
| 相手の経歴が動いた | 媒体上の職歴や経験の更新 | 「〇〇のご経験を新たに拝見し、この役割の△△に、より近くなったと考えました」 |
| 相手が言った時期が来た | 「〇月頃なら」「今のプロジェクトが終われば」 | 「以前、〇月頃とおっしゃっていたので、改めて」 |
| 別の役割が合う | 前回と別の役割で、相手の経歴に合うものが出た | 「前回とは別の役割ですが、△△のご経験に合うと考え」。ただし「誰でもいい」に見えないよう、なぜ合うかを一文で |
| 一緒に働く人が話せる | 前回に無かった、役割の責任者との接点 | 「今回は、〇〇の責任者から直接お話しできます」 |

新しい理由が一つも無いなら、送りません。理由が無い再送は、「埋まらなかったので、また送った」にしか見えません。理由が生まれるまで待つか、生まれるように社内で動くかです。

## 書き方の型

時間を空けた再送の、書き方の型です。順番が要点です。

| 順番 | 要素 | 書き方 |
|---|---|---|
| 一 | 新しい理由 | 先頭に。「前回ご連絡した〇〇の役割で、△△が変わりました」。「久しぶりに」「ご無沙汰しております」は先頭に置かない |
| 二 | 前回に一言触れる | 「以前、〇月頃にご連絡した者です」。隠さない。一文で |
| 三 | 相手の今の経歴に触れる | 前回と違う箇所。「〇〇のご経験を拝見し」。相手が変わっている前提で |
| 四 | 新しい理由の中身 | 変わった点、加わった事実を、二〜三文で。役割と会社の全体の説明は繰り返さない |
| 五 | 次の一歩 | 軽く。「ご質問だけでも」「一言のご返信でも」 |
| 六 | 断りやすさ | 「ご興味が無ければ、今後のご連絡は控えます」。前回より強く |
| 七 | 送り主 | 前回と同じ人が望ましい。変わったなら「前回は〇〇からご連絡しましたが」と一言 |

長さは、一通目より短く、二通目と同じくらい。三〜六文です。役割と会社の説明を繰り返すと長くなり、「前回と同じ」に見えます。新しい理由と、相手の今の経歴と、軽い一歩。それだけです。

### エラベルの見解

相談で最も多い失敗は、「半年前に送った候補者に、『ご無沙汰しております。以前ご連絡した役割がまだ募集中ですので、改めてお送りします』と、前回の文面をそのまま付けて送っていた」というものです。相手には「半年埋まらなかった役割」と「自分を見ずに一覧から送っている会社」の二つが伝わります。返信は来ず、来ても断りです。「役割の範囲が変わり、〇〇の裁量が加わった」を先頭に、「以前ご連絡しました」を一文で、相手の新しい経歴に触れ、「一言でも」と変えたら、半年前に返信が無かった相手から返信が来ました。時間を空けた再送は、前回の続きではなく、新しい理由の一通でした。

見ていて差がつくのは、担当者が「前回の記録」を持っているかです。いつ、誰に、何を、どの切り口で送ったかが残っていれば、「前回と違う切り口」が決められます。残っていないと、前回と同じ箇所に触れ、同じ材料を出し、相手に「また同じか」と見られます。

発注側にできるのは、社内に新しい事実（役割の変化、体制、制度）が生まれたとき、それを担当者に伝えることです。新しい理由の多くは、社内からしか出ません。

## 送るタイミング

時間を空けた再送を、いつ送るかの判断です。

| 区分 | タイミング |
|---|---|
| 返信が無かった相手 | 二通目まで送り終えてから、三か月以上。新しい理由が生まれたとき |
| 「今は考えていない」の相手 | 時期を言われたなら、その少し前（一か月前ほど）。言われていないなら三か月以上 |
| 途中で止まった相手 | 追客をやめてから三か月以上 |
| 不採用だった相手 | 半年以上。役割が変わったか、相手の経歴が動いたとき |
| 相手の経歴が動いたのを見つけた | 動いてすぐ。ただし前回から一か月以上は空ける |
| 役割や会社が変わった | 変わってすぐ。「変わった」が理由なので、鮮度がある |

タイミングの要点は、「新しい理由が生まれた時点」です。「三か月経ったから」ではなく、「三か月経って、かつ新しい理由がある」で送ります。理由が先で、期間は最低限の間隔です。送る時間帯や曜日の考え方は[スカウトの送信時間帯](/media/scout-soushin-jikantai/)に書いています。

## 運用と記録

時間を空けた再送を、思いつきではなく運用として回すための項目です。

| 項目 | 内容 |
|---|---|
| 前回の記録 | 誰に、いつ、どの役割で、どの切り口で、どの材料で送ったか。返信の有無と内容 |
| 再送の候補の一覧 | 返信が無かった相手、時期を言われた相手、止まった相手を、状態別に一覧に。[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)の考え方と同じ |
| 新しい理由の一覧 | 社内で起きた変化（役割、体制、制度、事実）を、日付付きで一覧に。理由が生まれたら再送の候補と突き合わせる |
| 相手の変化の確認 | 再送の前に、媒体上の経歴を見直す。条件が合わなくなっていないか、新しい経験が加わっていないか |
| 送らない相手の管理 | 「連絡不要」の相手は一覧に印を付け、再送の候補から外す。外し漏れが最も信頼を落とす |
| 個人情報の扱い | 記録は個人情報。保管の期間、アクセスの範囲、媒体の規約に沿う。個別の判断は専門家に確認 |
| 振り返り | 再送からの返信を、理由の種類別に見る。どの理由が動くか |

運用の要点は、「新しい理由の一覧」と「再送の候補の一覧」を突き合わせることです。理由が生まれたとき、誰に送れるかがすぐ分かります。

## 外注する場合の範囲

時間を空けた再送を、スカウト代行に出す場合の範囲です。

**出せる工程。** 前回の記録の整備、再送の候補の一覧の作成と状態別の分類、送ってよい相手と送らない相手の切り分け、相手の経歴の変化の確認、新しい理由ごとの文面の型の作成、個別の文面の作成、送るタイミングの管理、送信、記録、理由の種類別の振り返り、社内の変化を「新しい理由」に翻訳する下書き。

**社内に残す判断。** 新しい理由の元になる事実（役割の変化、体制、制度）を担当者に伝えること、「連絡不要」の相手を再送しない方針の承認、不採用だった相手への再送の可否、個人情報の保管と規約の扱いの方針。

**外注の効きどころ。** 時間を空けた再送は、「前回の記録を持ち、候補の一覧を保ち、社内の変化を拾い、理由が生まれた時点で送る」運用が要り、社内では「思い出したときに、前回の文面で送る」になりやすい工程です。担当者が記録と一覧を持ち、社内の変化を聞き出し、理由の型で書けば、再送は新しい一通になります。担当者は複数の会社の再送を見ているので、「この理由はこの層に動く」の型を持ち込めます。ただし、新しい理由の元になる事実は、社内からしか出ません。

**外注しても動かない場合。** 社内の変化を担当者に伝えない、「まだ空いているから」だけで送ることを求める、「連絡不要」の相手にも送ることを求める、前回の記録を渡さない。社内の判断で、代行を替えても直りません。

時間を空けた再送は、新しい理由を先頭に、前回に一言触れ、相手の変化を前提に短く書けば、新しい一通になります。外注は、記録と一覧と理由の型を担う手段です。

### エラベルの見解

担当する側から見ると、時間を空けた再送の相談で最も多いのは、「新しい理由が、社内にあるのに、担当者に伝わっていない」ことです。役割の範囲が変わった、責任者が替わった、リモートの制度が入った、新しい拠点ができた。どれも再送の理由になるのに、「採用とは関係ない社内の話」として担当者に届きません。担当者は理由が無いので送れず、候補の一覧は眠ったままです。

月に一度、「社内で何か変わりましたか」を担当者が聞く。それだけで、再送の理由が見つかります。再送は、文面の技術より、理由の供給で決まります。

発注側にできるのは、社内の変化を、採用と関係があるかを自分で判断せずに、そのまま担当者に伝えることです。関係があるかは、担当者が判断します。

## まとめ

- 書けないのは**再送と考えている・新しい理由が無い・前回に触れない・久しぶりが先頭・相手の変化を見ていない・前回の文面が無い・基準が無い**構造
- 送ってよいのは**返信が無かった・今は考えていない（時期に配慮）・途中で止まった・不採用（条件付き）**。送らないのは**連絡不要・条件が合わなくなった・活動を止めている**
- 新しい理由は**役割が変わった・会社の新しい事実・相手の経歴が動いた・言われた時期が来た・別の役割が合う・一緒に働く人が話せる**。理由が無ければ送らない
- 型は**新しい理由→前回に一言→相手の今の経歴→理由の中身→軽い一歩→断りやすさ→送り主**。三〜六文、役割と会社の説明は繰り返さない
- タイミングは**理由が生まれた時点**。最低限の間隔は三か月（不採用は半年）、変化が理由ならすぐ
- 運用は**前回の記録・候補の一覧・理由の一覧・相手の変化の確認・送らない相手の管理・個人情報・振り返り**。理由と候補を突き合わせる
- 外注できるのは**記録・一覧・切り分け・変化の確認・理由の型・文面・タイミング・送信・記録・振り返り・社内の変化の翻訳**。社内に残るのは**事実を伝える・連絡不要の方針・不採用への再送の可否・個人情報の方針**

## よくある質問

### 何か月空ければ再送してよいですか

期間より、新しい理由の有無で決めます。理由が無ければ、一年空けても送らないほうがよく、役割が大きく変わったなら一か月でも送れます。目安として、返信が無かった相手は二通目の後に三か月以上、「今は考えていない」の相手は言われた時期の少し前か三か月以上、不採用だった相手は半年以上です。媒体によっては同じ相手への再送に仕様上の制限がある場合があるので、公式の案内で確認してください。

### 前回、返信が無かったことに触れると、相手が気まずくなりませんか

触れ方の問題です。「ご返信をいただけませんでしたが」は責める形で、気まずくなります。「以前、〇月頃にご連絡した者です」と事実だけを一文で書き、すぐ新しい理由に移れば、相手は「覚えていて、新しい話を持ってきた」と受け取ります。触れないほうが問題で、相手が覚えていた場合に「初回のふりをした」と見られます。前回の返信の有無には触れず、送ったことにだけ触れます。

### 前回と送り主が変わってしまいました。どう書けばよいですか

「前回は〇〇からご連絡しましたが、今回は△△からお送りします」と一文で書きます。隠すと、相手が前回の名前を覚えていた場合に不自然です。担当が替わった理由は書かなくてよく、「引き続き、この役割を担当しています」程度で足ります。送り主が変わる場合は、前回の記録（何を、どの切り口で送ったか）を新しい送り主が読んでから書きます。読まずに書くと、前回と同じ箇所に触れてしまいます。担当者の引き継ぎの考え方は[担当者の引き継ぎが無い](/media/rpo-hikitsugi-nai/)に書いています。
