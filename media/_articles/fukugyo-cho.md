人事責任者やCHROとして、採用から制度、組織まで、人事の全体を経営の立場で見てきた。副業で活かしたい。ただ、経営レベルの経験は、週数時間の副業の枠には大きすぎる。作業を受けるには重すぎる。「顧問」の形で受けると、範囲が曖昧で、月に一度の会議に出て助言するだけになり、成果が見えない。結論を先に書くと、**責任者・CHROの経験は、「経営の視点」のままでは副業の形になりません。「採用の設計」「人事の立ち上げ」「経営への翻訳」の三つに切り出し、それぞれを成果物と期間で区切り、判断は依頼側に渡した形で、人事の機能が無いか弱い会社に出します。「顧問」ではなく「設計して渡す」形にすると、副業の枠に収まり、成果も見えます**。マネージャー経験の売り方は[人事マネージャー経験を活かす](/media/fukugyo-manager/)に、三年目からの範囲は[人事3年目からできること](/media/fukugyo-3nenme/)にまとめています。

## 責任者経験が副業で形にならない構造

責任者・CHROの経験が、副業で形にならないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「経営の視点」を売ろうとしている | 依頼側には「何をしてくれるか」が読めない。視点は成果物にならない |
| 副業の枠に対して経験が大きい | 週数時間で「人事の全体」は見られない。全体を見ようとして、範囲が広がる |
| 「顧問」の形に流れる | 月に一度の会議で助言する形。範囲も成果物も曖昧で、依頼側も自分も成果が分からない |
| 判断を渡せない | 責任者として決めてきたので、副業でも決めたくなる。外部の立場では決められない |
| 相手を選んでいない | 大手には責任者がいる。売れるのは、人事の機能が無いか弱い会社 |
| 作業との距離が遠い | 作業から離れて長く、作業の案件は受けられない。受ける必要も無い |
| 単価の基準が無い | 責任者の報酬と副業の単価の間で、基準が作れない |

構造の大半は、「視点を売り、顧問の形に流れる」ことです。切り出して、成果物と期間で区切れば、形になります。

## 経験の三つの切り出し

責任者・CHROの経験を、副業の形になる三つに切り出します。

| 切り出し | 内容 | 成果物の形 |
|---|---|---|
| 採用の設計 | 事業の計画から採用の計画を逆算し、経路（スカウト、公募、紹介）の主従と、体制と、指標を設計する | 採用の計画の一枚、経路と体制の設計書、指標の表 |
| 人事の立ち上げ | 人事の機能が無い会社で、最初の人事担当者が回せる形（採用の型、記録、手順、最低限の制度の考え方）を作り、渡す | 立ち上げの手順書、型と記録の表、担当者への引き渡し |
| 経営への翻訳 | 現場の採用の状況を経営が判断できる形に翻訳し、経営の目標を人事の計画に落とす。経営向けの報告の形を作る | 報告の型、経営会議の資料の型、要件と目標の翻訳の一枚 |

切り出しの要点は、「制度や労務の設計は、切り出しに入れていない」ことです。制度や労務は、法令に関わり、専門家の領域と重なり、副業の枠で責任を負える範囲を超えることが多い。責任者経験のうち、副業で形にしやすいのは、採用の設計と立ち上げと翻訳です。制度や労務に関わる依頼は、専門家との連携を前提にするか、受けません。

## 切り出しごとの相手と成果物

三つの切り出しそれぞれで、売れる相手と、出す成果物です。

| 切り出し | 売れる相手 | 出す成果物 | 期間の目安 |
|---|---|---|---|
| 採用の設計 | 事業が伸びて採用が急に増えた会社。経営が採用を「人事に任せた」まま設計が無い会社 | 採用の計画（目標、経路、歩留まりの逆算、必要な送信数と稼働）、体制の設計、指標の表 | 一〜二か月 |
| 人事の立ち上げ | 人事の担当者がいない、または初めての人事担当者を置いた会社 | 立ち上げの手順書、採用の型と記録の表、最初の三か月の運用の計画、担当者への引き渡し | 二〜三か月 |
| 経営への翻訳 | 経営と人事がずれている会社。経営が採用の数字を読めない会社 | 経営向けの報告の型、目標と要件の翻訳の一枚、経営会議での説明の資料 | 一か月 |

相手の要点は、「人事の機能が無いか弱い会社」です。責任者経験は、責任者がいない会社で最も効きます。大手には責任者がいて、社内の事情を知る人が設計します。売れる相手を選ぶと、案件は決まりやすくなります。

## 顧問との違い

責任者経験の副業は、「顧問」の形に流れやすい。顧問と、この記事で勧める「設計して渡す」形の違いです。

| 項目 | 顧問 | 設計して渡す |
|---|---|---|
| 範囲 | 曖昧。「人事全般について助言」 | 三つの切り出しの一つ。成果物で区切る |
| 成果物 | 無いことが多い。会議での発言 | 計画の一枚、設計書、手順書、報告の型 |
| 期間 | 長期。終わりが無い | 一〜三か月。渡して終わる |
| 時間 | 月に一度の会議。実は準備で時間がかかる | 週数時間で、成果物を作る |
| 判断 | 助言の形で判断に踏み込みやすい | 素案と設計を出し、判断は依頼側 |
| 成果の見え方 | 見えない。「役に立っているか分からない」 | 成果物と、その後の依頼側の運用で見える |
| 次の案件 | 実績として語りにくい | 成果物が実績になる |

違いの要点は、「成果物と期間」です。顧問の形が悪いわけではありませんが、副業の枠では、範囲が曖昧になり、時間が読めず、成果が見えず、次につながりにくい。設計して渡す形なら、副業の枠に収まり、実績が残ります。

### エラベルの見解

登録の相談で、責任者・CHRO経験の方から「顧問の形で受けたい」という声を聞きます。受けた方の中には、月に一度の会議で助言し、半年経って「何が変わったか分からない」と依頼側に言われ、終わった方もいます。範囲が曖昧で、成果物が無かったからです。「採用の計画と体制の設計を一か月で作り、経営会議で説明する資料まで出す」と成果物で区切った方は、一か月で終え、依頼側がその計画で採用を動かし、次の案件の実績になりました。責任者経験は、視点ではなく設計で売れます。

見ていて差がつくのは、「判断を渡せるか」です。責任者は、最終の判断をしてきました。副業では、設計と素案を出し、決めるのは依頼側の経営です。「この計画で行くべきです」ではなく、「この計画と、この代替案があります。判断は御社で」と言える方は、続きます。決めたくなる方は、依頼側の経営と衝突します。

エラベルでは、責任者・CHRO経験の方には、「設計して渡す」形で、人事の機能が無い会社の案件をご紹介することが多くなります。

## 判断を渡す難しさ

責任者経験の人が、副業で最も難しいのは、「判断を渡す」ことです。

| 場面 | 決めたくなること | 渡す形 |
|---|---|---|
| 採用の計画 | 「この経路に集中すべき」 | 「経路ごとの見立てと、主従の案と、代替案。判断は御社」 |
| 体制 | 「この担当者を替えるべき」 | 「回っていない箇所と、体制の案。人の判断は御社」 |
| 候補者 | 「この人は採るべき」 | 「要件との照合の結果と、懸念。合否は御社」 |
| 条件 | 「年収はこれで出すべき」 | 「市場の見立てと、幅の案。提示は御社」 |
| 経営との衝突 | 「経営が間違っている」 | 「経営の目標と現場の状況のずれを、一枚で示す。判断は経営」 |

渡す形の要点は、「案と代替案と懸念を出し、決めるのは依頼側」です。責任者として決めてきた人には、もどかしい形です。ただ、外部の立場で決めると、依頼側の意思決定への介入になり、責任の範囲を超えます。決めたい気持ちが強いなら、副業ではなく、責任者として入る転職か、独立が合います。[向いていない人](/media/fukugyo-mukanai/)の「自分で決めたい」に書いています。

## 範囲と期間と単価

責任者経験で受けるときの、範囲と期間と単価の考え方です。金額は案件によるので書きませんが、根拠の作り方を示します。

| 項目 | 考え方 |
|---|---|
| 範囲 | 三つの切り出しの一つ。成果物で区切る。制度と労務は、専門家との連携を前提にするか、含めない。判断は含まない |
| 期間 | 一〜三か月。渡して終わる。長期の伴走は、成果物を区切って複数の期間に分ける |
| 時間 | 週数時間。成果物を作る時間と、依頼側との確認の時間。会議の出席は最小限 |
| 単価の根拠 | 成果物（計画、設計書、手順書、報告の型）と、それが依頼側にもたらす変化（採用が設計に沿って動く、人事が回り始める、経営が判断できる）。責任者の報酬を根拠にしない |
| 単価の出し方 | 「時間×時給」を土台に、成果物の価値で上乗せ。[最初の1件の価格の決め方](/media/fukugyo-shoninka/) |
| 見積もり | 工程・時間・成果物・含まない業務を一枚に。[見積もりの出し方](/media/fukugyo-mitsumori/) |
| 複数の案件 | 一件を渡して終える形なら、複数を順に受けられる。同時は時間が固定できない。[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/) |

考え方の要点は、「責任者の報酬を根拠にしない」ことです。責任者の報酬は、常駐と責任と判断の対価です。副業では、常駐せず、判断も渡すので、根拠は成果物と変化になります。根拠が違えば、単価の考え方も違います。

## 避けるべき形

責任者経験で、受けると続かないか、問題になる形です。

| 形 | 理由 |
|---|---|
| 「人事全般の顧問」 | 範囲が曖昧、成果物が無い、判断に踏み込む |
| 制度や労務の設計を単独で | 法令に関わる。専門家の領域と重なる。副業の枠で責任を負える範囲を超える |
| 経営の判断への関与 | 「経営会議で決めてほしい」は、外部の立場を超える |
| 本業の情報の持ち出し | 本業の制度、資料、候補者の情報を使う。責任者は情報を多く持っているので、線を引く。線は専門家に |
| 本業と同業か、取引先 | 利益相反。責任者は業界の関係が広いので、特に注意。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) |
| 常駐に近い稼働 | 「週に二日来てほしい」は、副業の枠を超える。本業の規定にも関わる |
| 「名前を貸す」形 | 実際の稼働が無く、名前だけ出す形。責任の所在が曖昧になる |

避ける形の要点は、「制度と労務」と「経営の判断への関与」です。責任者経験は、この二つに最も近いので、依頼側から求められやすい。ただ、副業の枠と外部の立場では、責任を負えません。求められたら、専門家との連携か、範囲の外と伝えます。

### エラベルの見解

担当する側として登録した責任者・CHRO経験の方で続いている方は、「設計して渡す」形を、一〜三か月で繰り返しています。採用の計画を一か月で作り、経営に説明し、渡す。人事の立ち上げを三か月で作り、担当者に渡す。それを、人事の機能が無い会社で、順に受けています。

責任者経験の価値は、「人事の機能が無い会社に、機能の設計を持ち込む」ところにあります。大手で全体を見ていた経験を、小さい会社で「最初の設計」に翻訳する。翻訳できる方は、副業の枠でも、責任者経験を活かせます。

エラベルでは、責任者・CHRO経験の方の登録の際、制度と労務を範囲に含めるかを確認しています。含める場合は、専門家との連携を前提にしていただいています。

## まとめ

- 形にならないのは**視点を売る・経験が大きい・顧問に流れる・判断を渡せない・相手を選ばない・作業と遠い・単価の基準が無い**構造
- 切り出しは**採用の設計・人事の立ち上げ・経営への翻訳**の三つ。制度と労務は専門家との連携か含めない
- 相手は**人事の機能が無いか弱い会社**。採用が急に増えた会社、初めての人事担当者を置いた会社、経営と人事がずれた会社
- 顧問との違いは**範囲・成果物・期間・時間・判断・成果の見え方・次の案件**。設計して渡す
- 判断は**案と代替案と懸念を出し、決めるのは依頼側**。決めたいなら副業ではなく転職か独立
- 範囲と期間と単価は**一つに絞る・一〜三か月・週数時間・成果物と変化を根拠・責任者の報酬を根拠にしない**
- 避けるのは**全般の顧問・制度と労務の単独・経営の判断への関与・情報の持ち出し・同業と取引先・常駐・名前貸し**

## よくある質問

### 「CHROとして経営会議に出てほしい」と言われました。受けてよいですか

出席そのものより、そこで何をするかで判断します。「採用の計画を説明し、経営の質問に答える」なら、成果物（計画）の説明として受けられます。「経営会議で人事の方針を決めてほしい」は、外部の立場で判断に関与することになり、受けません。出席の回数と時間も、副業の枠に収まる範囲（成果物の説明のための一〜二回）に限ります。継続的な出席は、顧問の形に流れ、範囲が曖昧になります。

### 制度や評価の設計を頼まれました。責任者としてやってきたので受けられますか

責任者として社内でやってきた経験と、外部の副業の立場で設計することは、責任の範囲が違います。制度や評価は法令に関わり、労務の専門家の領域と重なります。副業の枠で単独で受けると、責任を負える範囲を超えることがあります。受けるなら、専門家（社会保険労務士など）との連携を前提にし、自分の範囲を「考え方の整理と素案」に限り、法令に関わる部分は専門家に確認する形にします。受けるかどうか自体を、専門家に相談してから決めることを勧めます。

### 責任者の報酬と比べて、副業の単価が低く感じます

根拠が違うので、比べられません。責任者の報酬は、常駐と責任と判断の対価です。副業では、常駐せず、判断も渡し、成果物を作って渡します。単価の根拠は、成果物と、それが依頼側にもたらす変化です。「時間×時給」を土台に、成果物の価値で上乗せする形で根拠を作ります。低く感じるなら、成果物の価値（依頼側の採用が設計に沿って動く、人事が回り始める）を言葉にして、根拠に加えます。それでも合わないなら、副業ではなく、責任者として入る形が合います。[最初の1件の価格の決め方](/media/fukugyo-shoninka/)に書いています。
