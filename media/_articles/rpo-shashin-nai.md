求人媒体の会社紹介に、写真を載せたい。採用サイトを作りたい。ただ、使える写真が無い。あるのは数年前の集合写真で、写っている社員の半分は辞めている。オフィスの写真は暗く、スマートフォンで撮ったもの。「素材が無いから、採用ページが作れない」で止まっている。結論を先に書くと、**素材が無いのは、撮る機会が無かったからではなく、「何を見せたいか」が決まっていないからです。候補者が見たいものは決まっています。それを決めれば、社内で撮れるものと、プロに頼むものが分かれ、プロに頼む範囲は小さくなります。素材が無いことを、採用ページや求人票を作らない理由にしません**。採用サイトの効果が無い場合は[採用サイトを作ったのに効果がない](/media/rpo-shanai-chinmoku/)に、求人原稿が古い場合は[求人原稿を何年も更新していない](/media/rpo-kyujin-genkou-furui/)にまとめています。

## 素材が無い会社で起きていること

使える素材が無い会社では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 「素材が無いから作れない」で止まる | 素材が先、と思っている。何を見せたいかが無いので、何を撮ればよいかも分からない |
| 古い写真を使い続けている | 辞めた社員が写っている、当時の制服やオフィス。候補者が入社して「写真と違う」 |
| 媒体の写真の枠が空白か、素材集の写真 | 空白は「本気で採っていない」に見え、素材集の写真は「実態を隠している」に見える |
| プロに頼むと費用がかかるので、先延ばし | 全部をプロに頼む前提で、費用が大きく見えている |
| 社員の写真の同意が曖昧 | 過去に撮った写真の公開の同意が無く、使ってよいか分からない |
| 撮っても、保存場所がばらばらで見つからない | 誰かのスマートフォンや個人のフォルダにあり、次に使うときに探せない |
| 写真以外の素材（図、文章、動画）を考えていない | 「素材＝写真」と思っていて、他の見せ方を検討していない |

素材は、候補者に「実態」を見せるためのものです。「何の実態を見せたいか」から始めます。

## 候補者が見たい素材

候補者が採用の場面で見たいものは、決まっています。

| 候補者が知りたいこと | 見せる素材 |
|---|---|
| どんな場所で働くか | オフィスや現場の、実際の様子。整えすぎない。普段の状態 |
| 誰と働くか | 一緒に働く人の顔と、仕事をしている様子。集合写真より、数人が仕事をしている場面 |
| 何をする仕事か | 仕事の場面。会議、作業、顧客との場面。役割が想像できるもの |
| 会社の雰囲気 | 昼休み、雑談、会議の空気。演出ではなく、普段 |
| 働き方の実態 | リモートの様子、フレックスの実態、オフィスの時間帯ごとの様子 |
| 社員の話 | 顔写真と、具体的な話（最初の三か月、大変だったこと、続けている理由） |
| 会社の規模と実態 | 社員数や拠点の数字は自社の記録から。写真より、事実の記述 |

候補者は、「きれいな写真」より「実態が分かる写真」を見たいです。プロが撮った演出の写真より、社内で撮った普段の写真のほうが、判断の材料になることがあります。

見たい素材が決まれば、「何を撮るか」が決まります。「とりあえず撮ろう」では、使える素材は集まりません。

## 社内で撮れるものと撮り方

プロに頼む前に、社内で撮れるものがあります。

**オフィスや現場の様子。** スマートフォンで、明るい時間帯に、普段の状態を撮ります。片付けすぎない。人が働いている時間に撮れば、雰囲気が写ります。

**仕事の場面。** 会議、作業、打ち合わせ。「撮りますね」と一言かけて、普段どおりに続けてもらい、数枚撮ります。ポーズを取らせない。

**一緒に働く人。** 数人が仕事をしている場面。顔が写る場合は、事前に同意を取ります（後述）。

**社員の顔写真。** 自然光の入る場所で、背景をシンプルに、正面から。スマートフォンで十分です。表情は、笑顔を強要しない。

**昼休みや雑談の場面。** 雰囲気が最も写る場面です。撮られることに抵抗が無い人がいる場面で。

**撮り方の要点。** 明るい時間帯、窓の近く、逆光を避ける、ブレないように両手で持つ、数枚撮って選ぶ、縦と横の両方を撮る（媒体によって枠の形が違う）。

**撮る人を決める。** 人事か、写真が好きな社員か。「誰か撮って」では撮られません。

社内で撮った写真は、演出が無い分、実態が伝わります。「プロのような写真」を目指さず、「実態が分かる写真」を目指します。

## 社員の写真の同意と扱い

社員の写真を公開するには、同意と扱いの決め事が要ります。

**公開の前に、本人の同意を書面で取る。** 「採用の媒体、採用サイト、会社のSNSに掲載する」と、用途を明示して同意を取ります。口頭の同意は、後で「そんなつもりは無かった」になります。同意の書式と法令上の扱いは、専門家に確認します。

**用途を限定する。** 採用の用途で同意を取った写真を、広告や他の用途に使わない。用途を広げるなら、改めて同意を取ります。

**退職した社員の写真は、使わない。** 退職時に、写真の取り下げを本人に確認します。退職者が写っている写真を使い続けると、候補者が入社後に「あの人はいない」と気づき、不信になります。

**取り下げの申し出に、応じる。** 社員が「やはり公開をやめたい」と言ったら、応じます。応じる旨を、同意の書面に書いておきます。

**写真の管理者を決める。** 誰の写真が、どこに、いつから使われているかを、一覧で管理します。取り下げのときに、全部の掲載先から外せる状態に。

**顔を出さない選択肢を用意する。** 顔を出したくない社員には、後ろ姿、手元、遠景など、顔が写らない撮り方を用意します。

同意の扱いを曖昧にすると、写真を使うたびに不安が残ります。決め事があれば、安心して使えます。

### エラベルの見解

相談で最も多い失敗は、「素材が無いので、プロに頼んで一日かけて撮影し、費用をかけたが、演出が強すぎて『実態と違う』と面接で言われた」というものです。きれいなオフィス、笑顔の社員、整った会議。候補者が入社して見たのは、普段のオフィスでした。「何を見せたいか」を決めずにプロに頼むと、プロは「きれいに撮る」ことをします。実態を見せたいなら、社内で普段を撮るほうが合っていました。

見ていて差がつくのは、担当者が「素材が無い」を「作れない理由」にしないかどうかです。「素材が揃ってから作りましょう」と待つ担当者と、「まず、スマートフォンでオフィスと仕事の場面を十枚撮ってください。同意の書式はこちらで用意します。それで求人票と採用ページの初版を出します」と、あるもので進める担当者がいます。後者は、止まりません。

発注側にできるのは、「プロに頼む予算が付いたら」を待たず、「社内で撮れるものから」と担当者に言うことです。

## 写真以外の素材

素材は写真だけではありません。

**役割の記述。** 「何を決める役割か」「誰と働くか」「どこまで担うか」の文章は、写真より判断の材料になります。素材が無くても、文章は書けます。

**社員の話（文章）。** 顔写真が無くても、名前（または仮名）と役割と具体的な話があれば、素材になります。「入社して最初の三か月で何をしたか」「大変だったこと」「続けている理由」。聞き取りは三十分。

**一日の流れ。** 「ある社員の一日」を、時間ごとに文章で。写真が無くても、働き方が想像できます。

**図。** 組織の図、選考の流れの図、役割の関係の図。写真より、構造が伝わります。簡単な図は、社内で作れます。

**数字。** 社員数、拠点の数、平均の在籍年数など。自社の記録の数字だけを使い、出典を明記します。

**短い動画。** スマートフォンで、オフィスを歩く三十秒、社員が仕事を一言で話す三十秒。編集は最小限。動画の公開も、写っている人の同意が要ります。

**候補者からの質問と答え。** 面接でよく聞かれる質問と、その答え。候補者が知りたいことが、そのまま素材になります。

写真が無いから採用ページが作れない、は成り立ちません。文章と図と数字で、初版は作れます。写真は、揃ったら足します。

## プロに頼む範囲と頼み方

社内で撮れないもの、社内で撮った写真では足りないものは、プロに頼みます。範囲を絞ります。

**プロに頼む価値があるもの。** 採用サイトの一番目立つ場所の写真、社員の顔写真を揃えたい場合、印刷物に使う場合。

**プロに頼まなくてよいもの。** 普段のオフィス、仕事の場面、雰囲気。社内で撮った普段の写真のほうが、実態が伝わります。

**頼むときに伝えること。** 「候補者に実態を見せたい。演出は最小限に。普段の状態を撮ってほしい」。伝えないと、プロは「きれいに」撮ります。

**撮る一覧を、先に渡す。** 「オフィスの全景、会議の場面、顔写真を〇人、仕事の場面を三種類」。一覧が無いと、撮影の日に迷い、撮り漏れが出ます。

**縦と横の両方を頼む。** 媒体によって枠の形が違います。

**写真の権利の扱いを、契約で確認する。** 撮った写真を、どの用途に、いつまで使えるか。二次利用の可否。契約の条項は専門家に確認します。

**費用は、範囲を絞れば抑えられる。** 半日で、顔写真と主要な場面だけ、のように絞ります。全部をプロに、は要りません。

プロは、「社内で撮れないもの」を撮ってもらう相手です。「全部」を頼む相手ではありません。

## 素材の管理

撮った素材を、次に使えるように管理します。

| 管理すること | 型 |
|---|---|
| 保存場所 | 共有のフォルダに一か所。個人のスマートフォンや個人のフォルダに置かない |
| 整理の単位 | 「撮影日」と「種類（オフィス・仕事の場面・顔写真・雰囲気）」でフォルダを分ける |
| 同意の記録 | 写っている社員の名前と、同意の書面の保存場所を、写真ごとに一覧で |
| 使用の記録 | どの写真を、どの媒体・サイトに、いつから使っているか |
| 退職時の処理 | 退職者が写っている写真を一覧から特定し、掲載先から外す |
| 更新の頻度 | 年に一度、古くなった写真を撮り直す。オフィスや社員が変わったら、その都度 |
| 管理者 | 一人決める。人事か、採用代行の担当者 |

管理が無いと、次に使うときに「あの写真はどこにあるか」「使ってよいか」で止まります。撮ることより、管理することが、素材を資産にします。

## 外注する場合の範囲

素材の問題を、採用代行に出す場合の範囲です。

**出せる工程。** 候補者が見たい素材の整理と撮るものの一覧、社内で撮る場合の撮り方の案内、同意の書式の案（専門家の確認を経て）、社員の話の聞き取りと文章化、役割の記述と一日の流れと図の作成、写真が無い状態での採用ページと求人票の初版、プロに頼む範囲の整理と依頼の一覧、素材の管理の型の作成と運用。

**社内に残す判断。** 何を見せるかの決定、社員の写真の公開の可否、同意の取得、プロへの依頼と費用、写真の権利の契約。

**外注の効きどころ。** 素材の問題は、「何を見せたいか」の整理と、「無くても進める」判断の問題です。担当者が整理し、文章と図で初版を作り、社内で撮れるものの一覧を渡せば、「素材が無いから作れない」は無くなります。同意と管理の型も、担当者が用意できます。

**外注しても動かない場合。** 社内が「プロの写真が揃ってから」を譲らない、社員が写真の公開を全員拒む、同意の書式を整えない。社内の判断で、代行を替えても直りません。

素材は、「何を見せたいか」が決まれば揃います。外注は、決めることと、無くても進めることを速くする手段です。

### エラベルの見解

担当する側から見ると、素材の相談で最も多いのは、「素材集の写真を使っている」ことです。媒体の会社紹介に、明らかに自社ではない、きれいなオフィスと笑顔の人の写真。候補者は、素材集の写真だと分かります。「実態を隠している」と受け取り、応募の前に離れます。

素材集の写真を外して、社内でスマートフォンで撮った普段のオフィスと仕事の場面に替えると、応募の質が変わります。「きれいではないが、本当の場所」が、候補者の判断の材料になります。

発注側にできるのは、素材集の写真を今日外すことです。空白のほうが、素材集よりましです。空白は、社内で撮った写真で埋めます。

## まとめ

- 素材が無い会社は**「素材が先」で止まる・古い写真・空白か素材集・プロ前提で先延ばし・同意が曖昧・保存がばらばら・写真以外を考えていない**
- 候補者が見たいのは**働く場所・一緒に働く人・仕事の場面・雰囲気・働き方の実態・社員の話・規模の事実**。きれいさより実態
- 社内で撮れるのは**オフィス・仕事の場面・一緒に働く人・顔写真・雰囲気**。明るい時間帯に普段どおりを、撮る人を決めて
- 社員の写真は**書面で用途を明示して同意・用途を限定・退職者は使わない・取り下げに応じる・管理者・顔を出さない選択肢**。書式と法令上の扱いは専門家に確認
- 写真以外に**役割の記述・社員の話・一日の流れ・図・数字（自社の記録）・短い動画・質問と答え**。写真が無くても初版は作れる
- プロには**目立つ場所の写真・顔写真を揃える・印刷物**を、演出は最小限と伝え、撮る一覧を渡し、権利の扱いを契約で確認して、範囲を絞る
- 管理は**一か所・撮影日と種類・同意の記録・使用の記録・退職時の処理・年一の更新・管理者**
- 外注できるのは**整理・撮り方・同意の書式・聞き取りと文章化・初版・プロへの依頼の整理・管理の型**。社内に残るのは**何を見せるか・公開の可否・同意の取得・費用・契約**

## よくある質問

### スマートフォンで撮った写真では、見劣りしませんか

候補者が見たいのは「きれいな写真」ではなく「実態が分かる写真」です。プロの演出の写真より、社内で撮った普段のオフィスと仕事の場面のほうが、判断の材料になることがあります。明るい時間帯に、窓の近くで、普段どおりの場面を数枚撮って選べば、十分です。目立つ場所の一枚だけプロに頼む、という組み合わせもあります。

### 社員が写真に写ることを嫌がります

強要しません。顔を出さない撮り方（後ろ姿、手元、遠景）を用意し、顔を出してよい人だけ顔写真を撮ります。社員の話は、顔写真が無くても、名前（または仮名）と役割と具体的な話があれば素材になります。同意は書面で、用途を明示し、取り下げに応じる旨を書いておけば、応じる人は増えます。全員が拒む場合は、オフィスと仕事の場面（顔が写らない）と、文章と図で作ります。

### 素材が揃うまで、採用ページを作るのを待つべきですか

待ちません。役割の記述、社員の話（文章）、一日の流れ、図、選考の流れで、初版は作れます。写真は、社内で撮ったものから足し、プロの写真は揃ったら差し替えます。「素材が揃ってから」を待つと、半年、一年と止まります。その間の応募と辞退が、素材の無さより大きい損失です。
