教育業界の法人や会社（学校法人、塾と予備校、専門学校、通信教育とオンラインの事業者）が採用代行を検討するとき、動機は「年度の切り替わりに向けて教員と講師が足りず、校長や教室長が採用に追われている」「非常勤の講師の募集が年中止まらない」であることが多い。ただ、教育の採用は、他の業界と違う難しさがあります。型で求める人と経路が違い、教員と講師は免許と資格と専門性が前提で年度の暦に合わせて揃え、常勤と非常勤と学生の講師で採用の型が別で、候補者が授業の方針と担当のコマ数と生徒の層と保護者対応の実態で選び、採用の判断が校長や教室長や委員会にあり、教員と事務職の二つの人事を同時に回す。結論を先に書くと、**教育業界の採用代行は、母集団形成・一次対応・日程調整・記録は外に出せる一方、免許と資格の要件の決定・授業の方針と実態の判断・模擬授業の見極め・受け入れは社内に残さないと、採れても担当させられず、方針が合わずに離れます。**代行に出す前に、難しさを自社の状況で分解し、型と講師の区分ごとに「任せる・残す」を決めることが、代行が機能する条件です。年度の暦で動く点は[保育業界の採用代行](/media/rpo-hoiku-rpo/)と、資格が前提の点は[医療業界の採用代行](/media/rpo-iryo-rpo/)と共通しています。ここでは、教育業界で共通する切り分けに絞ります。

## 教育業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 型で求める人と経路が違う | 学校法人は公募と規程と委員会、塾と予備校は教室ごとの速さ、専門学校は実務の経験、オンラインは教材と配信の力 | 型ごとに求人票と経路と選考の段を分ける必要がある |
| 免許と資格と専門性が前提で年度の暦 | 教員は免許、専門学校は分野の実務の経験と資格が要件になることがあり、切り替わりまでに教科と科目ごとに揃える | 要件の決定は会社と専門家。代行は照合と時期の逆算まで |
| 常勤・非常勤・学生で型が別 | 常勤は方針と長期、非常勤はコマ数と時間帯と掛け持ち、学生の講師は時給と時間の自由と辞めやすさ | 区分ごとに母集団と経路と受け入れが違う |
| 方針と実態で選ばれる | 授業の方針、担当のコマ数、生徒の層、保護者対応の量、授業以外の仕事（校務、事務、営業）の量 | 実態を先に出すかで応募と定着が変わる |
| 判断が校長・教室長・委員会にある | 面接と模擬授業に校長や教室長が出る。学校法人は委員会の日程で決まる | 一次対応を残すと流れる。枠を先に預ける必要がある |

五つのうち、代行で解決できるのは母集団形成と速さで、要件・方針・見極めは社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 免許と資格の要件の決定 | 残す | 会社と専門家。法令上の整理がある |
| 授業の方針と実態の判断（求人票に何を書くか） | 残す | 校長、教室長、教務の責任者 |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の型で、〇〇の科目を、〇〇の層に教えた経験」に。代行が整え、責任者が確認 |
| 母集団形成（掲載型、学校、学生、紹介、教育の経験者に届く経路） | 任せられる | 型と区分があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 校長と教室長の負担を減らす。切り替わり前は特に |
| 書類の一次確認 | 一部任せられる | 「免許・資格・科目・教えた経験」の照合は外で。方針との相性は社内 |
| 模擬授業と面接の見極め | 残す | 校長、教室長、教科の責任者 |
| 委員会と規程の手順（学校法人） | 残す | 法人の手順。代行は書類の準備と日程の補助まで |
| 受け入れ（最初の三か月、担当のコマ数、教える人） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 教科と教室と区分をまたいで一つの一覧。切り替わりに向けた進捗 |

「免許と資格の要件」と「模擬授業の見極め」は、教育に特有の残す工程です。免許と資格は、法令上の整理があると一般に整理されているため、会社と専門家が決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

教育業界で多くの法人が見落とすのは、「非常勤の講師の募集」が年中止まらない理由です。非常勤と学生の講師は、コマ数と時間帯と掛け持ちで動き、辞めやすく、切り替わりだけでなく学期の途中でも欠員が出ます。ところが募集は常勤と同じ求人票と同じ経路で、教室長が手が空いたときに返事をする。応募は来ますが、返事が遅く、コマ数と時間帯が合わず、決まっても数か月で離れる。「非常勤の一次対応と日程」を外に出し、コマ数と時間帯を求人票の先頭に置き、翌営業日中に返す。それだけで、同じ応募の数から決まる人数が変わります。エラベルで担当者を選ぶ企業には、「非常勤の講師の応募への返事は、誰が、何日以内に返していますか」を、私たちから先に聞いています。答えが「教室長が手が空いたときに」なら、代行に出す最初の工程は非常勤の一次対応です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 型と区分と人数 | どの型（学校・塾・専門・オンライン）で、常勤・非常勤・学生のどの区分を、どの科目で、切り替わりまでに何名 |
| 要件 | 免許と資格と実務の経験を「必須・歓迎」に分けているか。会社と専門家で整理したか |
| 実態 | 授業の方針、担当のコマ数、生徒の層、保護者対応の量、授業以外の仕事の量を、責任者が語れるか |
| 選考の段 | 模擬授業を段に置いているか。学校法人は委員会の日程が決まっているか |
| 枠 | 校長と教室長の面接の枠を、授業の合間・夜の授業の前・オンラインで週に一つ先に預けられるか |
| 受け入れ | 最初の三か月の担当のコマ数、教える人、到達点が決まっているか |
| 記録 | 教科と教室と区分をまたいで一つの一覧があるか |

「実態を責任者が語れるか」が要です。要件の言い換えは[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 型ごとに代行の型が違う

| 型 | 採用の特徴 | 代行に出しやすい工程 |
|---|---|---|
| 学校法人 | 公募と規程と委員会。年度の暦で動く。教員と事務職の二つの人事 | 公募の運用、一次対応、書類の準備、記録 |
| 塾と予備校 | 教室ごとの速さ。非常勤と学生の講師が多い。学期の途中の欠員 | 非常勤の母集団形成と一次対応、教室をまたいだ日程と記録 |
| 専門学校 | 分野の実務の経験者を教員に。企業からの転身 | 実務の経験者に届く経路、要件の言い換え |
| 通信教育とオンライン | 教材の作成と配信の力。授業の場が無いので模擬授業の代わりが要る | 母集団形成、課題の運用、一次対応 |

複数の型を持つ法人は、型ごとに代行の型が違うことを前提に、型ごとに「任せる・残す」を決めます。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| 教育業界の経験 | 担当者が教員や講師の採用を担った経験があるか。型と区分の違いを知っているか |
| 非常勤と学生への経路 | コマ数と時間帯で届く経路の運用をしたことがあるか |
| 年度の暦への逆算 | 切り替わりから逆算して、科目ごとにいつまでに何名の応募が要るかを組めるか |
| 一次対応の速さ | 翌営業日中に返す体制があるか |
| 記録の型 | 教科と教室と区分をまたいで一つの一覧にできるか |
| 費用 | 「工程・稼働時間・担当人数」をそろえて比べる。額の大小だけで決めない |

費用は、依頼する工程と稼働時間で大きく変わるため、同じ工程で比べる軸をそろえます。内訳の見方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 時期 | 起きること | 社内の対応 |
|---|---|---|
| 最初の二週間 | 実態と要件の聞き取り。型と区分ごとの求人票の作り直し | 責任者が実態を語る一時間を取る |
| 一か月目 | 母集団形成と一次対応が回り、応募が増える | 枠を預ける。模擬授業と面接を同じ日に組む |
| 二か月目 | 書類の照合で要件に合わない応募が減る。辞退の理由が見える | 辞退の理由が「コマ数」「方針」「授業以外の仕事」なら実態の見直し |
| 三か月目 | 入職。受け入れが始まる | 最初の三か月のコマ数、教える人。離れたら理由を記録 |
| 切り替わり前 | 科目と教室をまたいで同時に進む | 一覧で進捗を見る |

出したあとに「応募は増えたが方針が合わない人ばかり」となるなら、実態が求人票に落ちていない印です。代行のせいにする前に、責任者が語った実態が求人票にあるかを確かめます。

### エラベルの見解

教育業界で見落とされやすいのは「授業以外の仕事」の扱いです。塾の講師は生徒の面談と保護者対応と営業（体験授業からの入会）を、学校の教員は校務と部活動と保護者対応を、専門学校の教員は就職の支援と企業との連携を担い、授業の時間より長いことがあります。ところが求人票は「授業を担当」だけで、授業以外の仕事の量が無い。応募は来ますが、面接で聞いて辞退し、入職して量に驚いて離れます。「授業のコマ数」「授業以外の仕事の中身と量」「一週間の時間の使い方」を責任者が語り、求人票に書く。エラベルで担当者を選ぶ企業には、「授業以外の仕事を、求人票に書いていますか」を、私たちから先に聞いています。書いていなければ、経路を増やす前に実態の書き出しです。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## まとめ

- 教育業界の難しさは**型で違う・免許と資格と年度の暦・常勤と非常勤と学生・方針と実態で選ばれる・判断が校長と教室長と委員会にある**の五つ
- 外に出せるのは**母集団形成・一次対応・日程・記録**。残すのは**免許と資格の要件・方針と実態の判断・模擬授業の見極め・受け入れ**
- **免許と資格は会社と専門家**。個別の判断は専門家にご確認ください
- 最初に出す工程は**非常勤の一次対応**。校長と教室長の時間を見極めと受け入れに戻す
- 型ごとに**代行の型が違う**。複数の型は型ごとに決める
- **授業以外の仕事**を求人票に書く
- 費用は**同じ工程で比べる軸をそろえる**

## よくある質問

### 学校法人で、公募と委員会の手順が決まっています。代行が入る余地はありますか

公募と委員会の手順は残す工程で、代行と矛盾しません。代行が担うのは、公募の周知（経路の運用）、応募への一次対応、書類の照合と準備、委員会の日程の補助、記録です。手順のうち「規程で決まっている部分」と「運用で決まっている部分」を分けると、運用の部分（周知の範囲、返事の速さ、書類の整え方）は外に出せることが多い。規程の解釈は法人の判断で、代行は手順に沿った運用までです。

### 塾で、教室ごとに教室長が採用しています。法人でまとめる必要はありますか

教室ごとの速さは塾の強みなので、面接と模擬授業と受け入れは教室長に残します。まとめる効果があるのは、母集団形成と一次対応と記録です。教室ごとに別の媒体に別の文面で出し、返事の速さが教室長次第になっていると、教室をまたいだ応募（隣の教室なら通える人）を取りこぼし、法人で進捗が見えません。一次対応と記録を法人（または代行）でまとめ、面接以降は教室長、という分け方が合います。

### オンラインの事業で、模擬授業ができません

授業の場が無い型では、模擬授業の代わりに「課題」を段に置きます。教材の一部を作る、短い動画を撮る、生徒の質問に文章で答える、といった課題を代行が運用し、評価は教務の責任者が残す。課題の設計（何を見るか、どの基準で）は社内、運用（送付、回収、日程）は外、という分け方です。評価の観点を揃える型は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。
