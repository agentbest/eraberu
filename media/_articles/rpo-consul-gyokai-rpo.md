コンサル業界で採用代行を使う際は、**領域・職位と必要業務、採用時期や社内の稼働から工程を選び、提案・事実確認・承認と実務を分けます。**一般的なRPO案内だけでは、専門課題の設計評価や顧客情報の扱いまで対応できるとは分かりません。今回の経験と範囲を確認し、要件・条件と採否の社内承認、記録や権限を合意します。[職種別の判断](/media/rpo-consultant-rpo/)と[採用コンサルとの違い](/media/rpo-consul-tono-chigai/)も参照できます。

## 自社の状況から確認する五つの切り口

| 切り口 | 確認すること |
|---|---|
| 領域・職位 | 必要業務と評価方法、教育・分担や条件 |
| 日程・承認 | 候補枠・回答期限、未対応と不在代替 |
| 説明内容 | 原稿と面談の事実、本人からの質問と回答 |
| 経歴・募集経路 | 個人の経験と希望、媒体紹介等への到達と実績 |
| 採用時期 | 確定・見込みの需要、配置と教育、入社準備 |

五つは原因を網羅する分類や業界共通の実態ではありません。要件整理や評価方法の提案から相談する場合も、今回の専門経験と範囲を確かめます。支援先が変わっても社内承認や情報確認は必要で、外注だけで課題が解決するとは保証しません。

## 工程ごとに提案・承認と実務を分ける

| 工程 | 外部へ相談する作業の例 | 社内で確認すること |
|---|---|---|
| 要件・職位 | 職務整理・案の文書化 | 業務実態と評価、条件・職位の承認 |
| 課題・評価方法 | 設計支援や記録形式 | 専門経験と範囲、内容と採否の承認 |
| 原稿・募集経路 | 取材制作・運用 | 事実と公開、媒体利用条件・予算 |
| 書類・候補者対応 | 承認した項目の確認と案内 | 判断権限と例外回答、根拠の記録 |
| 日程・課題の送付回収 | 作業可否を確認して分担 | 版・期限と必要情報、共有保存権限 |
| 配置・受け入れ | 準備資料や日程等の補助 | 業務と教育担当、本人の条件希望 |
| 記録・報告 | 入力・集計と進捗整理 | 正確さと利用範囲、保存と終了処理 |

表はすべての支援先の対応保証ではありません。案件との適合も抽象的な相性だけでなく、必要業務・条件と本人の能力や希望、教育から判断します。役職名だけで承認・面接担当を固定しません。

### エラベルの見解

たとえば、評価者の予定・承認を確認できず案内が止まる場面が考えられます。これは想定例で、業界の発生頻度や改善実績ではありません。候補枠と代替、案内期限を相談し、週一枠・即日確定・同日面接に固定しません。最初は日程だけとせず、原稿や評価記録等の並行支援も検討します。[日程の滞留](/media/rpo-nittei-chousei-osoi/)も参照できます。

## 代行に出す前に社内で確認すること

| 確認 | 内容 |
|---|---|
| 職務・時期 | 必要業務と人数、確定・見込みの需要、代替策 |
| 要件・評価 | 理由と確認方法、社内承認、必要な専門経験 |
| 原稿・説明 | 実態と条件、公開できる素材と事実確認者 |
| 候補者対応 | 連絡期限・候補枠、承認者と不在代替 |
| 受け入れ | 教育・業務分担と条件、準備と支援工数 |
| 記録 | 対象定義と未完了、共有先・保存と利用権限 |

初期整理から頼む場合は、契約前に確定する事項と支援中に決める事項、素材提供・承認の時間を分けます。パートナーが実態を語ることや特定の準備時間だけを前提にしません。[要件づくり](/media/rpo-consultant-youken/)も参照できます。

## 出身区分だけで委託範囲を決めない

| 分けて確認するもの | 確認する内容 |
|---|---|
| 経歴・能力 | 本人の担当経験と今回の必要業務 |
| 採用区分 | 新卒・中途等、教育と条件の設計 |
| 募集経路 | 媒体紹介等と到達・応募選考の記録 |
| 希望 | 本人が確認できる条件や動機、未確認事項 |

同業なら即戦力、事業会社ならコンサル未経験、新卒なら応募が大量とは推定しません。対象職務と条件・時期、到達や社内工数から媒体と作業を比較します。出身区分を理由に評価基準を自動的に変える説明もしません。[母集団形成](/media/rpo-consultant-boshuudan/)も参照できます。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| 対応経験 | 今回の領域職位・媒体と作業、担当と代替体制 |
| 課題・評価 | 専門対応の可否、提案と内容確認・承認 |
| 候補者対応 | 対応時間・件数、回答期限と例外、不在代替 |
| 変更 | 需要や件数変化に伴う範囲・期間と費用の条件 |
| 情報・媒体 | 外部利用条件、素材・記録の利用と共有権限 |
| 費用・契約 | 初期継続・追加作業と実費、期間と更新解約 |

工程と件数時間・期間、初期追加作業と実費、社内の引き継ぎ・確認工数までそろえます。未採用でも費用が生じる場合を含め、支払と終了条件を確認します。[費用内訳](/media/rpo-hiyou-uchiwake/)と[支援先の選び方](/media/rpo-erabikata/)も参照できます。

## 開始後の予定と実績を分けて確認する

| 場面 | 確認すること |
|---|---|
| 開始準備 | 素材・承認、媒体権限と手順、未確定事項と期限 |
| 募集・運用 | 到達と応募選考、未対応と作業量、社内外の確認 |
| 面接・判断 | 評価方法と根拠、案内承認と日数・本人希望 |
| 条件・入社 | 条件説明と本人意思、手続き・教育と配置準備 |
| 見直し | 需要や条件変化、稼働費用と契約変更・終了 |

二週間で準備、一か月で応募増、三か月で入社という共通の予定は置けません。開始時の仮定と実績を分けます。応募が増え通過が増えなくても、要件・評価が原因とは確定せず、到達した対象や条件、期間と未完了、実施記録も確認します。

### エラベルの見解

面接官ごとの通過率差は、対象職務と候補者、課題・面接条件や件数に影響されるため、それだけで評価の偏りは分かりません。必要業務と評価の理由、実際の根拠・未確認事項を記録します。記録を整えれば同じ応募から通過が増えるとは保証せず、集客と運用の見直しも並行して検討します。[評価のばらつき](/media/rpo-mensetsukan-bara/)も参照できます。

## まとめ

- 職務・時期と滞留、社内の権限・稼働から委託工程を選ぶ
- 設計評価への専門対応を確認し、提案・事実確認・承認と実務を分ける
- 出身区分だけで能力・希望や委託範囲、評価方法を決めない
- 日程先行・週一枠等を固定せず、必要な並行支援を相談する
- 開始予定を効果保証とせず、条件・対象と工数費用をそろえて確認する

## よくある質問

### コンサルティング会社が採用代行を使うのは、自社の専門性と矛盾しませんか

必要な専門経験と実務を工程ごとに比較し、社内で確認承認する事項を決めます。社内の一次対応が損とは一律に評価せず、権限と稼働、支援先の範囲・体制と総費用を見ます。成果物の利用、担当交代・再委託と未完了業務、情報返還削除・権限停止も契約と手順で確認します。

### 案件の受注が読めず、いつ何名要るか決められません

確定・見込みの需要、職務と必要時期、教育や配置・外部支援等の代替策を整理します。通年接点が適切かも対象と工数から検討し、情報の利用目的・範囲、本人希望と連絡停止、保存期限や共有権限を確認します。受注後募集では間に合わないと一律に断定しません。[過去応募者との接点](/media/rpo-talent-pool-katsuyou/)も参照できます。

### 事業会社からの転身者を採りたいのですが、ケースで落ちます

出身区分だけで専門性やコンサル経験、落ちた原因を推定しません。必要業務と評価方法・根拠、候補者の担当経験や実施条件を照合します。職務に必要な理由から要件を定め、教育・分担で補える範囲と実際の支援を確認します。
