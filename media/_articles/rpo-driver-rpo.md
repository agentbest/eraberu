ドライバーの採用を代行に出すか迷う運送会社は、「求人を出しても応募が来ず、来ても面接で辞退される」「求人票を作って媒体に出す工程はお願いしたいが、運送の実態を知らない人にドライバーの採用が回せるのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、運行の形と車両と荷物の整理・拘束時間と休みの実態の開示範囲・給与の内訳と事故の扱いの方針・免許取得の支援の方針・要件の決定・運転と安全への姿勢の評価・合否の判断は社内に残す**のが線です。ドライバーは、運行の形と車両で市場が分かれ、免許の区分と運転者の拘束時間や休息に法令上の基準が関わり、候補者が「拘束時間と休みと給与の内訳と事故の扱い」を他の職種より強く確かめます。「運行の実態を正直に示し、給与の内訳と事故の扱いを明確にする」ことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、隣接する倉庫の線は同じ職種別の記事にまとめていきます。

## ドライバー採用が他の職種と違う点

一つ目は、運行の形と車両の種類で求める人と市場が全く違うことです。運行の形は、長距離（泊まりを伴う）、地場（日帰り）、ルート配送（決まった先を回る）、宅配（個人宅、件数が多い）、引越（作業を伴う）、それ以外（タンク、重機、冷凍など）。車両は、大きさと種類で運転できる免許が違います。長距離の大型を運転してきた人と、地場のルート配送で小型を運転してきた人は、持っているものと動く理由が違います。「ドライバー募集」だけでは、どの運行のどの車両かが候補者に伝わりません。

二つ目は、免許の区分と運転者の拘束時間や休息に法令上の基準が関わることです。車両の大きさによって必要な免許の区分が決まり、運転者の拘束時間と休息と運転時間には法令上の基準があり、健康診断や適性の確認にも定めがあります。求人票に書く拘束時間や運行の形は、この基準の範囲で成り立っている必要があり、候補者はそれを知っています。免許の区分と拘束時間や休息の基準と健康や適性の確認は、法令で定められているので、専門家にご確認ください。

三つ目は、候補者が「車両と荷物と手積み手降ろしの有無」「日帰りか泊まりか」「拘束時間と休み」「給与の内訳（固定か歩合か、残業の扱い）」「事故のときの扱い（修理代の負担、保険）」「車両の年式と整備」「運行管理者の人柄」を最初に確かめることです。ドライバーは、運行の実態で働き方と体と収入が決まります。手積み手降ろしがあるか、泊まりが何日か、一日の拘束が何時間で休みが何日か、給与が固定か歩合か、事故のときに自己負担があるか、車両が古くて故障が多いか、運行管理者が無理な配車をしないか。「配送業務全般」「月収〇〇万可能」では、この判断ができません。

四つ目は、経験者は取り合いで、未経験は免許取得の支援が要ることです。経験者は限られ、運送会社同士で取り合いになります。未経験を採るなら、免許の取得（費用、期間、取得までの業務）の支援と、同乗の指導の仕組みが要ります。

五つ目は、運行管理者や所長は配車と点呼を回していて、採用の工程を回す人がいないことです。運行管理者は日々の配車と点呼と事故対応を回していて、面接の時間を取るのも難しい。事務が回そうとしても、運行の実態を知らず、求人票が抽象的になります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 運行の形と車両と荷物の整理 | 残す | どの運行の、どの車両で、どの荷物を、どの先に運ぶか。社内にしか分からない |
| 拘束時間と休みの実態の開示範囲の決定 | 残す | 一日の拘束、泊まりの日数、休みの日数と取り方を、どこまで正直に書くか。法令上の基準の範囲で成り立っているかを専門家に確認 |
| 給与の内訳と事故の扱いの方針の決定 | 残す | 固定か歩合か、残業の扱い、事故のときの負担と保険。経営者が決める |
| 免許取得の支援の方針の決定 | 残す | 未経験を採るか、免許の取得の費用と期間と取得までの業務、同乗の指導。経営者が決める |
| 要件の決定 | 残す | 運行の形と車両と免許の区分から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（運行の形と車両と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。「月収〇〇万可能」ではなく内訳で |
| 媒体の選定と運用 | 任せられる | ドライバーに届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 運行の形と免許の区分と勤務地に合わせた検索と、運転してきた車両に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、営業所と車両の見学の案内 |
| 運行管理者・所長の面接の日程の確保 | 任せられる | 配車と点呼の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 免許の区分・運行の経験・勤務地の分類は任せられる。運転と安全への姿勢の評価は残す |
| 運転と安全への姿勢の評価 | 残す | 運行管理者や所長が面接と同乗で見る。健康や適性の確認は法令に沿って |
| 運行の実態と給与の内訳と事故の扱いの説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断 |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。現職の運行の区切りに合わせた入社日の調整 |

線の要点は、「運行の形と車両と荷物、拘束時間と休みの実態、給与の内訳と事故の扱い、免許取得の支援の方針が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の免許と経験で運転できるか」「体と収入と生活が成り立つか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「ドライバーの求人を出しても応募が来ない。来ても面接で辞退される」というご相談です。求人票を見ると、「ドライバー募集。配送業務全般。月収〇〇万円可能。経験者優遇。未経験歓迎」と書かれていて、運行の形も、車両も、荷物と手積み手降ろしの有無も、拘束時間と休みも、給与の内訳も、事故の扱いも無い。経験者はこれを読んで、「実態を隠している」「月収〇〇万は歩合で長時間の話だろう」と判断し、面接で実態を聞いて辞退していました。

見ていて差がつくのは、「運行の実態と給与の内訳を一文で言えるか」です。「〇〇営業所の地場配送で、車両は〇〇クラス、荷物は〇〇でパレット積みが中心、手積みは一部。日帰りで、一日の拘束は〇〇時間程度、休みは月に〇日で希望はほぼ通る。給与は固定の基本に、残業は実績で全額、歩合は無い。事故のときは会社の保険で対応し、自己負担は無い。車両は〇年以内で、整備は自社。運行管理者は〇〇の経験が長く、無理な配車はしないと言っている」。一文で実態と内訳が分かれば、候補者は自分の免許と経験と生活で判断できます。エラベルでは、ドライバーの案件をお受けする前に、依頼側に「運行の形と車両と荷物」と「拘束時間と休みと給与の内訳と事故の扱い」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：運行の形と車両と荷物。** 長距離か地場かルートか宅配か引越か。車両の大きさと種類と、必要な免許の区分。荷物の種類と、手積み手降ろしの有無と割合、パレットやリフトの使用。配送先の種類と件数。

**二つ目：拘束時間と休みの実態。** 一日の拘束の目安、泊まりの日数、休みの日数と取り方、繁忙期の実態。法令上の基準の範囲で成り立っているかを、専門家に確認します。求人票に書く実態が基準を超えていると、候補者に見抜かれ、問題にもなります。

**三つ目：給与の内訳と事故の扱い。** 固定か歩合か、基本と手当の内訳、残業の扱い、繁忙期と閑散期の差。事故のときの修理代の負担、保険の範囲、自己負担の有無。「月収〇〇万可能」の根拠（どの運行で、どのくらいの拘束で）。

**四つ目：免許取得の支援と未経験の受け入れ。** 未経験を採るか。免許の取得の費用の負担、期間、取得までの業務（助手、倉庫、小型から）、同乗の指導の期間と担当者。免許の区分と取得の要件は、専門家に確認します。

**五つ目：運行管理者や所長が、面接にどのくらい時間を出せるか。** 配車と点呼の合間に、面接の枠と営業所と車両の見学の時間をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 運行管理者の関与のさせ方

ドライバーの採用では、運行管理者や所長の関与が要ります。面接で運転と安全への姿勢を見る、営業所と車両を見せる、運行の実態と配車の考え方を正直に話す、同乗で運転を見る。しかし運行管理者は配車と点呼を回していて、「採用は事務の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると運行管理者がどう楽になるか」を具体的に示すことです。「この人が入れば、配車の穴が減り、既存のドライバーの拘束を減らせる」。そして、負担を最小にする形で頼みます。面接の枠は代行が点呼の合間に押さえる、経歴は代行が整理して渡す、実態の説明の要点は代行が用意する。運行管理者がやるのは、運転と安全への姿勢を見ることと、営業所と車両を見せて実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で運行管理者が「配車の考え方」を話すことの価値を、運行管理者自身に理解してもらうことです。ドライバーの候補者は、事務の話より、運行管理者の話を信じ、運行管理者が無理な配車をする人かどうかを最も気にしています。運行管理者が「うちは基準を守った配車しかしない。無理な依頼は断る。事故のときは会社が対応する」と話すと、候補者は「安心して運転できる会社」と判断します。

## 代行を選ぶときの確認項目

ドライバーの採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に運送業や物流業界の経験があるか。** ドライバーそのものでなくても、運送会社の管理部門や、ドライバーの採用を回した経験。運行の形と車両と免許の区分の違い、拘束時間と休息の基準の存在、給与の内訳の見方を知っているか
- **運行の実態と給与の内訳を求人票にどう書くか、案を出せるか。** 「配送業務全般」「月収〇〇万可能」で済まさず、運行の形と車両と荷物と拘束時間と休みと給与の内訳と事故の扱いを書けるか
- **ドライバーに届く媒体と経路の経験。** ドライバー向けの媒体、スカウト、免許を持ちながら運送業を離れた人、未経験で免許取得を希望する人、女性ドライバー、シニア、紹介会社との併用の設計。経路ごとの経験
- **法令上の基準への理解。** 求人票に書く拘束時間や運行の形が基準の範囲か、免許の区分が車両に合っているかを、専門家に確認する体制があるか
- **運行管理者の日程を押さえる段取り。** 配車と点呼の合間に面接の枠を確保する方法。営業所と車両の見学と同乗を組み込めるか

五つのうち、一つ目と四つ目が大きい。運送業を知らない担当者は、運行の実態を書けず、基準を超える求人票を作り、候補者に「実態を隠している」と読まれ、場合によっては問題にもなります。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、ドライバーの採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「給与の内訳と事故の扱いを書かないと届かない」と言われることです。「月収〇〇万可能」は、経験者に「歩合で長時間の話」と読まれ、事故の扱いが無い求人票は「自己負担があるのだろう」と読まれます。内訳と扱いを書くことで、経験者が判断できます。

二つ目は、応募者の免許と経験と経路が分かれることです。同じ運行の経験者、別の運行の経験者（長距離から地場へ、宅配からルートへ）、免許を持ちながら運送業を離れた人、未経験で免許取得を希望する人、女性、シニア。それぞれ持っているものと動く理由が違い、任せる運行と車両と合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることを変えます。

三つ目は、「拘束時間の実態」と「運行管理者の人柄」で候補者が判断を変えることです。「拘束時間は法令の範囲」と書いて、面接で実態が違えば辞退されます。運行管理者が「基準を守った配車しかしない」と話し、営業所の雰囲気と車両の年式を見せることで、候補者の判断が変わります。基準を超える実態があるなら、採用の前にそこを直します。それが無いと、誰を採っても離れ、問題にもなります。

### エラベルの見解

担当する側から見ると、ドライバーの採用で最も効くのは、「運行の実態と給与の内訳と事故の扱いを、隠さず求人票に書く」ことです。ドライバーの候補者は、運行の形と車両と手積みの有無で「自分に運転できるか」を判断し、拘束時間と休みと給与の内訳と事故の扱いで「体と収入と生活が成り立つか」を判断します。「配送業務全般。月収〇〇万可能」の求人票は、経験者に「実態を隠している」と読まれます。

エラベルでは、ドライバーの案件で担当者を紹介するとき、最初の一週間で運行管理者と経営者から「運行の形と車両と荷物」「拘束時間と休みの実態」「給与の内訳と事故の扱い」「免許取得の支援」を聞き取り、法令上の基準の範囲で成り立っているかを専門家に確認した上で、一文にするところから始めてもらっています。運転と安全への姿勢の評価は運行管理者が面接と同乗で行い、免許の区分と拘束時間や休息の基準と健康や適性の確認は、専門家にご確認いただくようお伝えしています。

## まとめ

- ドライバー採用が他と違うのは**運行の形と車両で求める人と市場が全く違う・免許の区分と拘束時間や休息に法令上の基準が関わる・候補者が運行の実態（車両と荷物と手積み・日帰りか泊まりか・拘束時間と休み・給与の内訳・事故の扱い・車両の年式・運行管理者）を最初に確かめる・経験者は取り合いで未経験は免許取得の支援が要る・運行管理者は配車と点呼で採用の工程を回す人がいない**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、運行の形と車両と荷物・拘束時間と休みの実態・給与の内訳と事故の扱い・免許取得の支援・要件・運転と安全への姿勢の評価・合否は残す**
- 代行に出す前に**運行の形と車両と荷物、拘束時間と休みの実態（基準の範囲かを専門家に確認）、給与の内訳と事故の扱い、免許取得の支援と未経験の受け入れ、運行管理者の面接の時間**を確認する
- 運行管理者の関与は**採用でどう楽になるかを示し、負担を最小にして、配車の考え方を話す価値を理解してもらう**
- 代行を選ぶときは**運送業の経験・実態と内訳の書き方・経路の経験・法令上の基準への理解・日程の段取り**を確認する
- 出したあとは**内訳と事故の扱いを書く必要が表に出る・免許と経験と経路が分かれる・拘束時間の実態と運行管理者の人柄で判断が変わる**。判断は運行管理者と経営者、材料は代行

## よくある質問

### 「月収〇〇万円可能」と書かないと、他社に負けませんか

「月収〇〇万可能」は、経験者に「歩合で長時間の話」「最大値で普通は届かない」と読まれ、信じられません。書くなら、内訳と根拠を一緒に書きます。「基本〇〇に、残業は実績で全額、無事故の手当。地場の日帰りで一日の拘束〇〇時間程度の場合、月に〇〇程度。歩合は無い」。内訳と根拠が書いてあれば、候補者は自分の運行で計算でき、信じます。内訳を書けない「月収〇〇万可能」は、応募を減らします。給与の表示に関わる法令上の扱いは、専門家にご確認ください。

### 拘束時間が長いのが実態です。正直に書くと来ませんか

法令上の基準の範囲で成り立っている実態なら、正直に書きます。「一日の拘束は〇〇時間程度、休みは月に〇日」。基準を超えている実態なら、書く以前に、採用の前に運行を直します。基準を超える実態を隠して採った人は、入社後に離れ、問題にもなります。基準の範囲で成り立っていて、他社より拘束が長いなら、給与の内訳と休みの取り方と車両の整備と事故の扱いで、候補者が比べられる形にします。拘束時間と休息の基準は、専門家にご確認ください。

### 未経験を採って免許を取らせる形は、うまくいきますか

免許の取得の費用の負担、期間、取得までの業務（助手、倉庫、小型から）、同乗の指導の期間と担当者を決め、求人票に書けば、未経験の層から応募が来ます。取得までの業務が無く「免許を取ってから来て」では、未経験者は動けません。取得の費用を会社が負担する場合の扱い（一定期間の勤務の条件など）は、法令に関わるので専門家に確認します。免許の区分と取得の要件も、専門家にご確認ください。
