「エンゲージメントを上げたい」という依頼で、社内イベント、表彰、福利厚生の追加を並べた施策の一覧を作ると、実施はされても、サーベイの数字も離職も変わりません。エンゲージメントが下がる箇所は、たいてい「自分に何が期待されているか分からない」「上司と話す機会が無い」「自分で決められる範囲が分からない」「会社の方針が伝わらない」のどれかで、イベントや制度では触れません。結論を先に書くと、**エンゲージメント施策は、サーベイの変化・離職の理由・1on1のテーマの傾向を材料に、下がっている箇所を一つ特定し、四つの型（仕事の明確さ・上司との接点・判断の余地・情報の共有）から一つを選び、管理職の行動の変化として頻度と記録を置いて設計し、三か月で行動の変化を見て、サーベイと離職は結果として後で見る形で作ります。**案件として受ける形は[エンゲージメント施策の副業の実務](/media/fukugyo-engagement-shigoto/)に、サーベイの設計は[組織サーベイを設計する](/media/fukugyo-skill-survey/)に書いています。ここでは、施策の作り方の型に絞ります。

## イベントや制度を足しても変わらない理由

| 足す施策 | 何が起きるか |
|---|---|
| 社内イベント、懇親会 | その日は盛り上がるが、翌日の仕事は変わらない |
| 表彰の制度 | 表彰される人以外には関係が無い |
| 福利厚生の追加 | 「あってよい」が、下がっている箇所に触れない |
| 理念の浸透の研修 | 聞いて終わる |
| 全部を同時に | どれが効いたか分からず、次が決められない |

下がっている箇所は、日々の仕事の中（期待・上司・判断・情報）にあります。そこに触れる施策は、管理職の行動の変化として設計するしかありません。

## 下がっている箇所を一つ特定する

| 材料 | 読むこと |
|---|---|
| サーベイの変化 | 前回より下がった設問。部門で差が大きい設問 |
| 離職の理由 | 退職の面談の記録から、傾向として。「上司」「仕事の中身」「見通し」など |
| 1on1のテーマの傾向 | 月次で人事に戻る傾向。「人間関係」「仕事の進め方」が増えている部門 |
| 現場の責任者の困りごと | 「部下が何を考えているか分からない」など |

三つ以上の材料が同じ箇所を指していれば、そこが「下がっている箇所」です。一つの材料だけで決めず、突き合わせます。特定は一つに絞ります。二つ以上を同時に直すと、どれが効いたか分かりません。読み方は[採用データを分析する](/media/fukugyo-skill-data-bunseki/)の「問いを一つ立てる」と同じで、個人の情報は扱わず、傾向だけで読みます。

### エラベルの見解

担当する側から見ると、エンゲージメント施策で最も差がつくのは、「施策を管理職の行動の変化として設計する」ができるかです。受ける側は、施策を「人事が実施するもの」（イベント、制度、研修）として設計します。それは人事が動けば実施でき、管理職の行動は変わらず、社員の日々は変わりません。「上司との接点」が下がっているなら、施策は「管理職が隔週で1on1を型どおりに回す」であり、「仕事の明確さ」なら「管理職が期初に部下ごとの期待を一枚で伝える」です。人事は型と記録の形を渡し、動くのは管理職。エラベルで担当者を選ぶ企業には、「その施策で、管理職の行動は何が変わりますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、施策の一枚に「管理職が、いつ、何をするか」の行を置き、空欄なら施策になっていないとして作り直すこと。

## 四つの型から一つ

| 下がっている箇所 | 施策の型 | 管理職の行動 | 頻度 |
|---|---|---|---|
| 仕事の明確さ | 部下ごとの期待を一枚で伝える | 期初に、等級の期待と目標を部下と確認する | 期初と月次 |
| 上司との接点 | 1on1を型どおりに回す | 隔週か月一で、本人が話したいことを聞く | 隔週か月一 |
| 判断の余地 | 「自分で決めてよい範囲」を明示する | 部下ごとに、相談せずに決めてよいことを一枚で | 期初と、役割が変わったとき |
| 情報の共有 | 部門の方針と会社の動きを定期に伝える | 月次で、方針の一枚を部門で共有し、質問を受ける | 月次 |

四つのどれも、費用がかからず、管理職の行動で始められます。一つを選び、三か月続けます。それぞれの型の詳細は、[目標管理を設計する](/media/fukugyo-skill-mbo/)、[1on1を設計する](/media/fukugyo-skill-1on1/)、[等級制度を設計する](/media/fukugyo-skill-grade/)に書いています。

## 施策の一枚

| 欄 | 中身 |
|---|---|
| 下がっている箇所 | 一つ。根拠（どの材料が指しているか） |
| 施策の型 | 四つのどれか |
| 管理職が、いつ、何をするか | 行動と頻度。一行 |
| 人事が渡すもの | 型の一枚、記録の形 |
| 記録 | 管理職が「やったか」を月次で一言。中身は書かない |
| 三か月後に見ること | 行動の変化（やった回数）。サーベイと離職は結果として後で |
| 対象の部門 | 一つの部門から。全社は後 |

「三か月後に見ること」を、サーベイのスコアや離職率にしません。三か月では結果は動かず、動かないことで施策が止まります。見るのは「管理職の行動が変わったか」で、結果は次のサーベイと、半年後の離職で見ます。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「施策の効果は、サーベイのスコアの上昇で示す」というものです。スコアは、施策以外の要因（業績、人の入れ替わり、時期）で動き、三か月では施策の効果と分けられません。「スコアを上げます」と約束すると、上がらなかったときに施策そのものが疑われ、管理職の行動の変化まで止まります。約束するのは「管理職の行動が変わる形を作ること」までで、スコアと離職は「結果として、次の回で変化を見る」に留めます。受ける側がその場で使える判断としては、施策の提案の一枚に「この施策で変わること：管理職の行動」「変わらないかもしれないこと：短期のスコア」を並べて書くこと。数字は件数と変化のまま並べ、割合で断定しません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 三か月の回し方

| 時期 | 中身 | 誰が |
|---|---|---|
| 最初 | 管理職に、施策の一枚と型を五分で読み合わせ。「なぜこの一つか」を材料で伝える | 担当者と人事 |
| 一か月目の終わり | 管理職が「やったか」を一言。つまずきを聞く（中身ではなく、型の負担） | 人事。担当者は整理 |
| 二か月目 | つまずきに応じて型を軽くする。頻度を下げる、記録を減らす | 担当者が案 |
| 三か月目の終わり | 行動の変化（やった回数、続いているか）を件数で。次の三か月を続けるか、型を変えるか | 依頼側が決める |
| 次のサーベイ | 下がっていた設問の変化を見る。結果として | 依頼側 |

管理職が「忙しくてできない」と言うつまずきは、型が重いことが多い。型を軽くします。「やる意味が分からない」なら、材料（なぜこの箇所か）を伝え直します。管理職を責める形にしません。

## 個人の情報を扱わない

| 扱わない | 代わりに |
|---|---|
| サーベイの個人の回答 | 単位ごとの傾向 |
| 1on1の中身 | テーマの傾向と件数 |
| 退職者の個別の理由 | 傾向として分類 |
| 「エンゲージメントが低い社員」の特定 | 特定しない。箇所を直す |

施策は「箇所」を直すもので、「人」を直すものではありません。特定の社員を対象にした働きかけは、本人の同意と依頼側の決まりに関わり、担当者は設計しません。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側がイベントや制度から始める | 材料で下がっている箇所を特定し、四つの型を並べる。イベントは否定せず「日々の仕事に触れる施策を先に」 |
| 下がっている箇所が絞れない | 材料を突き合わせる。三つ以上が指す箇所。無ければサーベイの設計に戻る |
| 施策が人事の実施で終わる | 「管理職が、いつ、何をするか」の行を置く |
| 三か月でスコアが動かない | 見るのは行動の変化。スコアは次の回で |
| 管理職が続けられない | 型を軽くする。頻度を下げる |
| 全社で同時に始めて止まった | 一つの部門に戻す |

## まとめ

- イベントや制度を足しても、**日々の仕事の中の箇所**には触れない
- 施策は**下がっている箇所を一つ特定する**から。材料はサーベイの変化・離職の理由・1on1の傾向。三つ以上が指す箇所
- 型は**仕事の明確さ・上司との接点・判断の余地・情報の共有**から一つ。費用はかからない
- 施策は**管理職の行動の変化**として設計。「いつ、何をするか」の行が空欄なら施策ではない
- **三か月で見るのは行動の変化**。スコアと離職は結果として次の回で。**上昇を約束しない**
- **一つの部門から**。つまずいたら型を軽くする。管理職を責めない
- 個人の情報を扱わず、**人ではなく箇所を直す**

## よくある質問

### 依頼側から「エンゲージメントを測るツールを入れたい」と言われました

測ることと直すことは別です。ツールを入れても、下がっている箇所を特定して管理職の行動を変える設計が無ければ、数字を見て終わります。「測る仕組みは御社の判断で。私は下がっている箇所を一つ特定し、管理職の行動の施策を作ります」と役割を分けます。ツールの指標の解釈は、依頼側の条件と合わないことがあるので、前回との変化を主に読みます。ツールの選定と費用は依頼側の判断です。

### 経営者が「社員のやる気が無い」と言い、社員のせいにしています

「やる気」は測れず、直せません。材料（サーベイの変化、離職の理由、1on1の傾向）で、下がっている箇所を「期待・上司・判断・情報」のどれかに置き換えて示します。箇所が見えれば、「社員のせい」ではなく「仕組みの箇所」として経営者が動けます。経営者の見方を否定せず、材料で置き換える形にします。

### 施策を続けているのに、離職が減りません

離職の理由を分類し、施策の箇所と対応しているかを確かめます。施策が「上司との接点」で、離職の理由が「仕事の見通し」なら、箇所が違います。対応していれば、三か月では結果に出ないだけで、半年後に見ます。離職の分け方は[定着まで見る](/media/fukugyo-skill-teichaku/)と同じで、採用の段階のずれ（要件・求人票・面接・内定後・受け入れ）も確かめます。施策のせいにも、社員のせいにもせず、箇所を読み直します。
