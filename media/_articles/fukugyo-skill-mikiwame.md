「見極めの精度を上げてほしい」という依頼は、「面接官の目を鍛えてほしい」と同じ意味で使われることが多いです。ただ、見極めは勘ではなく、「この判断をした人が、その後どうなったか」を記録で突き合わせることで上がります。突き合わせが無いまま面接を重ねても、面接官は自分の判断が合っていたかを知る機会が無く、精度は上がりません。結論を先に書くと、**見極めの精度は、書類の○△×と面接の結果・面接の三択と入社後の状態・落とした人の理由と辞退の理由の三つを突き合わせ、直すのは面接官ではなく基準と観点、精度を数字で断定せず、依頼側と月に一度振り返る形で上げます。**書類の見極めは[プロフィールの見極め方](/media/fukugyo-skill-screening/)に、面接の記録は[評価シートを作る](/media/fukugyo-skill-hyouka-sheet/)に、面接官の揃え方は[面接官トレーニングを行う](/media/fukugyo-skill-mensetsukan/)に書いています。ここでは、突き合わせの型に絞ります。

## 精度が上がらない理由

| 状態 | なぜ上がらないか |
|---|---|
| 判断の記録が印象 | 後で「なぜ通したか」に戻れない |
| 入社後の状態を採用側が知らない | 判断が合っていたかを確かめる材料が無い |
| 落とした人がその後どうなったかを見ない | 落とす基準が厳しすぎたかが分からない |
| 辞退の理由を集めていない | 「通した」判断の後に何が起きたかが分からない |
| 面接官の目を鍛えようとする | 面接官は自分の判断の結果を知らないので、鍛えようが無い |

精度は、判断（記録）と結果（その後）を並べたときに初めて見えます。並べる材料が無いと、精度という言葉自体が意味を持ちません。

## 三つの突き合わせ

| 突き合わせ | 並べるもの | 見えること |
|---|---|---|
| 一：書類と面接 | 書類の○△×（必須ごと）と、一次面接の三択 | 書類で○を付けた必須が、面接で通らない→書類の読み方か、必須の言葉がずれている |
| 二：面接と入社後 | 面接の三択（観点ごと）と、入社後の状態（一定の期間後） | 面接で通した観点が、入社後にずれている→基準か観点がずれている。迷うを引き継がずに通した→設計 |
| 三：落とした人と辞退 | 落とした理由（基準のどれか）と、通した人の辞退の理由 | 落とす基準が、実は辞退と関係ない→基準の重み。辞退の理由が面接の観点に無い→観点の欠け |

三つとも、担当者が「判断が間違っていた」と言うためのものではなく、「基準と観点をどう直すか」を見るためのものです。人ではなく、型を直します。

### エラベルの見解

担当する側から見ると、見極めの精度で最も差がつくのは、「入社後の状態を、採用の記録と同じ観点で見る」形を作れるかです。受ける側は、採用は採用、入社後は現場、と分けて考えます。ただ、面接で「決まりの無いことを自分で決めて進めた場面」を観点にしたなら、入社後に「決まりの無いことを自分で決めて進めているか」を、同じ観点で現場に聞かなければ、面接の判断が合っていたかは分かりません。エラベルで担当者を選ぶ企業には、「入社した方の様子を、面接の観点と同じ言葉で現場に聞いていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、評価シートの観点を、そのまま「入社後の確認の一枚」の項目にすること。新しい項目を作らず、面接の観点ごとに「入社後、どう見えているか」を現場の責任者に一行で書いてもらえば、突き合わせができます。

## 入社後の状態を見る時期と項目

| 時期の考え方 | 見る項目 | 誰に聞くか |
|---|---|---|
| 最初の三か月の終わり頃 | 面接の観点ごとに「入社後、どう見えているか」。任せる仕事を一人で回せているか | 現場の責任者 |
| 半年前後 | 面接で「迷う」だった観点が、その後どうなったか。本人が「思っていたのと違う」と感じていることは何か | 現場の責任者。本人は依頼側の決まりの範囲で |
| 早期に離職した場合 | 離職の理由が、面接の観点にあったか、無かったか | 依頼側の人事 |

時期は依頼側の決まりに従います。担当者が本人に直接聞くことは、契約の範囲と依頼側の決まりで決めます。聞く項目は面接の観点だけで、私的な事情や健康の状態などには触れません。

## 直すのは面接官ではなく基準と観点

| 突き合わせで見えたこと | 直すもの |
|---|---|
| 書類で○が面接で通らない | 必須の言葉を「経歴で読める言葉」に直す。[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/) |
| 面接で通した観点が入社後にずれる | 基準の一行を、入社後にずれた人の事実から起こし直す |
| 迷うが引き継がれずに通っている | 面接の設計。迷うが次の段の一枚に自動で入る形に |
| 入社後の問題が、面接の観点に無い | 観点の欠け。足すかは依頼側が決める。足すなら要件の一枚から |
| 落とした基準が辞退と無関係 | 基準の重み。必須と歓迎の境目を見直す |
| 辞退の理由が観点に無い | 観点ではなく、内定後の接点と条件の出し方の問題。[内定辞退が続くときに見直す3点](/media/rpo-jitai-ooi/) |

「面接官の〇〇さんの判断が甘い」という結論には行きません。同じ面接官でも、基準の一行が明確なら判断は揃います。揃わないなら、基準の言葉を直します。

## 精度を数字で断定しない

「面接の精度が〇割上がりました」「見極めの正答率は〇%です」のような言い方は、突き合わせの件数が少ない副業の範囲では根拠になりません。入社後の状態を「合っていた・ずれていた」の二択で数えても、数件では傾向にならず、次の候補者で反転します。

| 断定する言い方 | 置き換え |
|---|---|
| 「精度が上がった」 | 「面接で通した観点と、入社後の見え方が、この人たちでは一致していた」 |
| 「この基準は正しい」 | 「この基準で通した人は、いまのところ入社後もこの観点でずれていない」 |
| 「面接官の判断が甘い」 | 「この観点で、事実の欄と判断がずれている記録がある。基準の一行を見直したい」 |

数字は自分が扱った範囲の件数として伝え、割合にしません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「見極めの精度は、選考の中で完結する」というものです。実際には、入社後にずれた人の多くは、面接で「迷う」が付いていて、それが最終で引き継がれずに通っています。つまり見極めの精度の問題は、面接官の目ではなく、「迷う」の扱いの問題であることが多い。「迷う」を次の段に引き継ぐ形と、最終で「迷うが残っている観点」を決める人が見る形があれば、精度は上がります。受ける側がその場で使える判断としては、突き合わせの一枚を作るとき、入社後にずれた人について「面接で迷うが付いていたか」の列を最初に見ること。付いていれば設計の問題、付いていなければ観点か基準の問題、と分かれます。

## 依頼側との振り返りの形

| 頻度と場 | 中身 |
|---|---|
| 月に一度 | 突き合わせの一枚を、依頼側の採用担当と決める人と一緒に読む |
| 一枚の中身 | 入社した人ごとに、面接の観点×三択と、入社後の見え方。落とした人の理由の分布。辞退の理由の分布 |
| 結論の形 | 「基準の〇〇を直す」「観点〇〇を足すか、御社で決めてください」「設計の迷うの引き継ぎを直す」のどれか |
| やらないこと | 面接官の名前を挙げて評価しない。候補者の氏名を書かない |

振り返りの一枚に、候補者の氏名や個人が特定できる情報は書きません。入社した人については、依頼側の決まりの範囲で、観点ごとの見え方だけを扱います。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## 担当者が触れてよい情報の範囲

| 触れてよい（契約の範囲で） | 触れない |
|---|---|
| 評価シートの観点・事実・判断 | 候補者の私的な事情、健康の状態 |
| 入社後の観点ごとの見え方（現場の責任者の一行） | 入社後の人事評価の点数、給与 |
| 辞退の理由の要約 | 辞退した人の連絡先、その後の勤務先 |
| 落とした理由（基準のどれか） | 基準に無い理由（書かれていないはず） |

見極めの精度の振り返りで扱う情報は、採用の判断に使った記録と、それに対応する入社後の見え方に限ります。それ以外の情報を求めません。範囲は契約に書き、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 入社後の状態を誰も見ていない | 面接の観点をそのまま項目にした一枚を、現場の責任者に一行ずつ書いてもらう形を作る |
| 記録が印象で、突き合わせられない | 突き合わせは今後の候補者から。まず評価シートを事実と判断の形に |
| 依頼側が面接官の評価を求める | 「直すのは基準と観点で、人の評価はしません」。型の改善として返す |
| 件数が少なく、傾向が読めない | 読めないと書く。一件ずつの「面接の判断と入社後の見え方」を並べるだけでも、基準の言葉の直しには使える |
| 辞退の理由が「一身上の都合」しか無い | 集め方の問題。[内定辞退の理由を正しく集める方法](/media/rpo-jitai-riyuu/) |

## まとめ

- 精度は勘ではなく、**判断の記録と、その後の結果を突き合わせる**ことで上がる
- 突き合わせは**書類と面接・面接と入社後・落とした人と辞退**の三つ
- 入社後の状態は**面接の観点と同じ言葉**で、現場の責任者に一行ずつ
- 直すのは**面接官ではなく、基準と観点と設計**。「迷う」の引き継ぎを先に見る
- **精度を数字で断定しない**。件数として伝え、割合にしない
- 依頼側と**月に一度**、一枚で振り返る。面接官の名前と候補者の氏名は出さない
- 触れる情報は**採用の記録と観点ごとの見え方**まで。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側が「入社後の情報は現場のもので、採用側に渡せない」と言います

人事評価や給与の情報は求めません。求めるのは、面接の観点と同じ言葉で「入社後、どう見えているか」の一行だけで、それは採用の判断を確かめるためのものだと伝えます。「面接で見た〇〇が、入社後にどう見えていますか」という問いは、現場の責任者にとっても、採用に要件を伝えるための材料になります。それでも渡せないなら、突き合わせの二つ目は諦め、一つ目と三つ目で進めます。

### 副業の案件が短期で、入社後まで見られません

契約の範囲で、入社後の突き合わせができないことは普通にあります。その場合は、一つ目（書類と面接）と三つ目（落とした人と辞退）を案件の中で行い、二つ目のための「入社後の確認の一枚」（面接の観点と同じ項目）を依頼側に渡して、案件の後に依頼側が使える形にします。突き合わせの型を残すことが、短期の案件でできる精度の上げ方です。引き継ぎの形は[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)に書いています。

### 突き合わせたら、要件そのものがずれていると分かりました

見極めの問題ではなく、要件の問題です。入社後にずれた人の観点が、面接では全部「通す」だったなら、面接は要件どおりに機能していて、要件が実態とずれています。要件の一枚に戻り、いまうまくやっている人と、入社後にずれた人の違いから、必須と面接で確かめる項目を起こし直します。担当者は「要件のここがずれています」と材料を示すまでで、要件を変えるのは依頼側です。
