採用イベント（ミートアップ、説明会、座談会）の企画・運営を初めて受けるとき、見えにくいのは「当日の前後に何があるか」です。募集文には「採用イベントの企画運営」とだけあり、実際には、対象の像の確認、社員の時間の確保、費用の承認と支払いの流れ、告知の場所と文面、申込の受け皿、社員への聞き出し、進行表、前日の案内、当日の進行、翌日の連絡、記録と、当日の前後に工程が並びます。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→開催の一か月前→一週間前から当日→翌日→振り返りと次の会」の五つの段階で進み、契約前に範囲・誰に何のために何を持ち帰るか・登壇する社員と時間・費用の承認と支払いの流れ・参加者情報の方針・当日の稼働・翌日の連絡の名義・評価を決め、一か月前に形とテーマと告知と申込の受け皿と進行表と社員の中身の聞き出しを整え、一週間前から当日に申込内容の共有と手配と前日の案内と進行を回し、翌日に一言添えた連絡と記録を出し、振り返りで効いた形を残して次の会か引き継ぎにつなげます。**案件の型と求められる経験は[採用イベントの企画・運営の副業案件](/media/fukugyo-meetup-unei-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

イベントは、当日の稼働が目立ち、前後の工程と費用と参加者情報が見落とされます。契約前に決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 当日の運営だけか、企画から集客と当日までか、翌日の連絡と記録を含むか、型作りか。回数（単発か、継続か） | 「集客もお願いすればよかった」と当日に言われる |
| 誰に・何のために・何を持ち帰るか | 対象の像、目的（面談へ、認知、社員の対話）、持ち帰るもの（社員と話した体験、テーマの話） | 「集める」から始まり、誰にも届かない |
| 登壇する社員と時間 | 当日、参加者と話す社員は誰か。何人、何分。事前の聞き出しの時間 | 担当者が会社の説明をする役になる |
| 費用の承認と支払いの流れ | 会場、飲食、ツール、告知の費用の上限と承認者。会社が直接払う流れ。立て替えをしない | 自分の名義で契約する |
| 参加者情報の方針 | 申込の情報の置き場、保存の期間、利用の範囲（翌日の連絡、面談の案内まで）。会社の管理する場所でだけ扱う | 情報が自分の端末に残る。専門家にご確認ください |
| 当日の稼働 | 日程と時間の固定。変更の期限。平日の夜か土日か | 当日の変更で本業に響く |
| 翌日の連絡の名義 | 会社の名義か、外部の担当として名乗るか。文面の承認者 | 承認の無い文面が会社の名前で出る |
| 評価 | 参加者の数か、社員と話して翌日に次の案内が届いた参加者の数と面談に進んだ数か | 参加者の数で評価される |

止まりやすいのは、「まず一回やってみましょう」で日程だけ決めて始めるときです。対象の像と登壇する社員と費用の流れだけは、告知の前に決めます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 開催の一か月前：形とテーマ、告知、申込の受け皿、進行表、聞き出し

告知に期間が要るので、一か月前から準備します。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 形とテーマ（五人から。テーマで集める。時間は短く。会場かオンラインか。参加者一人が社員と話せる時間を計算） | 形の承認。費用の上限 | 大きな会を最初から作る。一人が社員と話せる時間が数分 |
| 告知の場所（対象がいる場所：社員の紹介、過去の応募者、紹介会社と媒体の担当者、テーマの近い既存のイベント、共催） | 社員への紹介の依頼。過去の応募者への連絡の可否 | 自社の告知だけ |
| 告知の文面（誰に、何を持ち帰れるか、選考ではないこと、社員が誰か、日時と場所、申込の方法） | 文面の承認 | 会社の説明の文面 |
| 申込の受け皿（会社の管理する仕組み。申込時に聞くこと：関心のテーマ、聞きたいこと） | 受け皿の用意 | 自分のツールで受ける |
| 進行表（最初の五分で目的と流れと選考でないこと、テーマの話、社員との対話を最も長く、質問、持ち帰るものの確認と次の案内、終了後の立ち話。分単位） | 進行表の承認 | 会社の説明が最も長い進行表 |
| 社員の中身の聞き出し（場面を聞く。「最近時間がかかった仕事」「入った頃に困ったこと」。当日話す骨格を三つ） | 社員の時間 | 台本を渡して読ませる |
| 記録の表（申込、参加、社員と話した人、翌日の連絡、面談に進んだ人、効いた形） | 記録を出す人 | 表が無い |

止まりやすいのは、告知の文面に「誰に」が無いときです。「エンジニア向け」ではなく「〇〇で〇〇に困っている方へ」と像で書きます。集め方は[採用イベントに人が来ない](/media/rpo-meetup-hito-konai/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「一か月前に、対象がいる場所への告知を会社に動いてもらえるか」で、参加者が決まります。自社のサイトやSNSでの告知だけでは、対象に届きません。社員の紹介、過去の応募者への連絡、紹介会社と媒体の担当者への案内は、会社が動かないとできない告知で、担当者の文面の工夫では代わりになりません。エラベルで担当者を選ぶ企業には、「告知は担当者が文面を作りますが、社員の方の紹介と、過去の応募者への連絡と、紹介会社への案内は、御社に動いていただきます」と、私たちから先に伝えています。受ける側がその場で使える判断としては、告知の計画を「場所ごとに、誰が動くか」の表にして会社に渡すこと。「会社が動く」の欄が空のまま告知を始めると、当日に人が来ません。

## 一週間前から当日：共有、手配、前日の案内、進行、立ち話

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 申込内容の社員への共有（誰が来て、何に関心があり、何を聞きたいか） | 一週間前と前日 | 社員が参加者を知らずに当日を迎える |
| 手配（会場、機材、飲食、名札、オンラインの接続先。費用は会社の流れで） | 一週間前まで | 自分で立て替える |
| 前日の案内（参加者に、場所か接続先、流れ、社員の紹介、選考ではないこと。社員に、参加者の一覧と骨格） | 前日 | 案内が無く、来ない人が出る |
| 当日の進行（受付、最初の五分、テーマの話、社員との対話を最も長く、質問、持ち帰るものの確認と次の案内） | 当日 | 会社の説明が長くなる。時間が伸びる |
| 終了後の立ち話（社員と参加者が個別に話す時間を取る。担当者は片付けと記録） | 当日 | 終了と同時に解散 |
| 当日の記録（誰が誰と話し、何を聞き、何に関心を示したか。評価は書かない） | 当日中 | 記録せずに帰る |

止まりやすいのは、当日に社員が会社の説明を長く話し、対話の時間が削れることです。進行表で対話を最も長く取り、説明が伸びたら「ここからは〇〇さんに直接聞いていただく時間です」と切り替えます。カジュアル面談の進行との共通点は[カジュアル面談の代行の副業の実務](/media/fukugyo-casual-mendan-fk-shigoto/)に書いています。

## 当日のトラブルの流れ

来ないときに考えるのではなく、契約前に決めた流れで動きます。

| 起きること | やること | やらないこと |
|---|---|---|
| 参加者が一人も来ない | 開始時刻から一定の時間待ち、社員と振り返りをして、翌日に申込者へ連絡（別の日の案内） | 担当者の失敗として謝り続ける |
| 一人しか来ない | 開く。社員と一人が長く話せる会にする | 中止にする |
| 社員が遅れる・来られない | 事前に決めた代わりの社員に連絡。いなければ、参加者に事情を伝えて、質問の時間と後日の面談の案内に切り替える | 担当者が会社の説明で埋める |
| 機材や接続の不具合 | 予備の接続先と連絡先を前日の案内に入れておく。復旧しなければ、対話の形に切り替える | 参加者を待たせ続ける |
| 参加者が選考の話（合否、条件）を聞く | 「選考ではないので、ご希望があれば後日、会社からご案内します」と返し、記録して会社に渡す | その場で答える |
| 参加者同士のトラブル、体調の不良 | 会社の連絡先に当日連絡。安全を優先 | 自分で収める |

止まりやすいのは、社員が来られないときに担当者が会社の説明で埋めることです。会社の説明は社員の言葉でないと届きません。質問の時間と後日の面談の案内に切り替えます。

### エラベルの見解

同じ料金・同じ回数でも、結果が分かれるのは、翌日の連絡に「当日の話」を書けるかです。それは、当日の記録を、誰が誰と何を話したかの形で残しているかで決まります。当日を回すことに手一杯で記録を残さなかった担当者の翌日の連絡は、「本日はありがとうございました」の定型になり、面談に進む人は出ません。受付と進行の合間に、「〇〇さんは〇〇さんに〇〇を聞いていた」と一行ずつ残した担当者の翌日の連絡は、「〇〇の件、〇〇さんから補足があります」と書けて、面談の設定が続きます。エラベルで長く続いている担当者は、進行表の横に「参加者ごとの一行」の欄を作り、当日中に埋めています。受ける側がその場で使える形としては、終了後の立ち話の時間を「記録の時間」と決め、社員と参加者が話している間に、その日の一行を全員分書き終えることです。

## 翌日：一言添えた連絡、質問への答え、面談の案内、記録

イベントの成果は翌日に決まります。翌日までに、参加者ごとに連絡を出します。

| 順 | 書くこと | 落とし穴 |
|---|---|---|
| 一 | 感謝と、当日の話への一言（「〇〇さんに聞いていた〇〇の件」） | 定型だけ |
| 二 | 当日に答えられなかった質問への答え（社員から取って） | 質問が宙に浮く |
| 三 | 次の一歩の選択肢（面談、社員との個別の話、次の会、資料の送付、いまは連絡だけ） | 応募だけを求める |
| 四 | 選考の合否や条件に触れない締め | 「ぜひご応募を」で終わる |

連絡は、会社の名義か承認された形で、承認された型を使い、当日の話の部分だけを参加者ごとに書き換えます。記録の表に、翌日の連絡の日付と、返事と、面談に進んだかを残します。連絡の速さは[連絡の速さ](/media/fukugyo-renraku-sokudo/)に、報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

## 振り返りと次の会：効いた形、やめる判断の材料、引き継ぎ

会のあと、会社と振り返りの時間を持ちます。見るのは、参加者の数ではなく、「社員と話して、翌日に次の案内が届き、面談に進んだ参加者」です。

| 見ること | 読み方 | 次の会 |
|---|---|---|
| 申込→参加→社員と話した→翌日の連絡→面談 | どこで落ちたか | 落ちた工程を直す |
| 告知の場所ごとの申込 | どこから来たか | 来た場所に厚く |
| 参加者一人が社員と話せた時間 | 短ければ、人数か社員の数 | 形を直す |
| 効いた形（テーマ、時間、人数、社員） | 面談に進んだ人が多かった形 | その形を続ける。テーマを変え、社員は交代で |
| 続けるか、やめるか | 数回続けて面談に進まないなら、やめる判断の材料を出す | 判断は会社 |

終了時は、企画の型、告知の型と場所の一覧、進行表、翌日の連絡の型、記録の表、効いた形の一覧を残し、参加者情報を自分の手元に残しません。引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 参加者情報の扱い

イベントの申込と当日の記録には、参加者の名前、連絡先、所属、関心、当日の発言が含まれます。会社の管理する場所（申込の仕組み、共有の表）でだけ扱い、自分の端末やツールに残しません。翌日の連絡は会社の名義か承認された形で出し、参加者との個別のやり取りを自分で続けません。当日の写真と発言を外に出すなら、本人の同意を会社が取ります。参加者情報の保存の期間と利用の範囲は会社の方針に従い、方針が無ければ作ることを提案します。個別の判断は専門家にご確認ください。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## 稼働時間は何で決まるか

一回の会にかかる時間は、「企画と形の設計」「告知の文面と場所ごとの調整」「申込の受付と社員への共有」「社員の中身の聞き出し」「手配」「前日の案内」「当日（準備、本番、片付け、記録）」「翌日の連絡（参加者の数に比例）」「振り返り」の合計で決まり、当日の時間は全体の一部です。参加者の数が増えると、翌日の連絡の時間が増えます。継続の会なら、二回目から企画と型の時間は減ります。受ける前に「回数」「参加者の目安」「当日の時間」「翌日の連絡を含むか」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、最初の一回の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→開催の一か月前→一週間前から当日→翌日→振り返りと次の会**の五つの段階
- 契約前に**範囲・誰に何のために何を持ち帰るか・登壇する社員と時間・費用の承認と支払いの流れ・参加者情報の方針・当日の稼働・翌日の連絡の名義・評価**を決める。対象の像と社員と費用の流れは告知の前に
- 一か月前に**五人から始める形とテーマ・対象がいる場所への告知（場所ごとに誰が動くかの表）・会社の管理する申込の受け皿・対話を最も長く取る進行表・社員の中身の聞き出し**を整える
- 当日は**申込内容を社員に共有し、前日の案内を出し、進行表で対話を守り、終了後の立ち話の時間に参加者ごとの一行を記録する**
- トラブルは**決めた流れで。社員が来られなくても担当者が会社の説明で埋めない**
- 翌日に**当日の話への一言・質問への答え・次の一歩の選択肢**を、承認された型で参加者ごとに出す
- 振り返りは**申込→参加→社員と話した→翌日の連絡→面談**のどこで落ちたかを見て、効いた形を続ける。やめる判断は会社
- 参加者情報は**会社の管理する場所でだけ扱い、自分のツールに残さず、写真と発言は同意を会社が取る**

## よくある質問

### 会社が「五人では少ない。五十人集めてほしい」と言います

「参加者一人が社員と話せる時間」で説明します。五十人で社員二人なら、一人あたりの対話は数分で、持ち帰るものが無く、翌日の連絡に書く材料もありません。「五十人の説明会と、五人の対話の会を、面談に進んだ人数で比べさせてください」と、判断は会社に置いたまま、比べる提案をします。それでも五十人を求める会社には、五十人の会は説明会として別に設計し、対話の会を別に持つ形を提案します。集める数で評価される契約は、受ける前に評価の基準を直します。

### 翌日の連絡を、参加者ごとに書く時間がありません

当日の記録が無いと、翌日に書けません。終了後の立ち話の時間を記録の時間にして、参加者ごとの一行を当日中に書き終えます。翌日は、承認された型の「当日の話」の部分に、その一行を入れるだけにします。一人あたり数分で済む形にしておけば、参加者の数が増えても回ります。参加者が多くて回らないなら、企画の段階で人数を減らすか、翌日の連絡を会社の人事と分担します。

### 社員が「イベントで話すのは苦手」と言います

台本を渡さず、事前の聞き出しで「最近時間がかかった仕事」「入った頃に困ったこと」を聞き、その三つを骨格として本人に返します。当日は、担当者が「〇〇さん、あの〇〇の件を」と振る形にすると、話しやすくなります。話す時間は短くし、参加者からの質問に答える時間を長く取ると、苦手な社員でも回ります。それでも難しい社員には無理をさせず、別の社員と交代します。強制した登壇は、参加者に伝わります。
