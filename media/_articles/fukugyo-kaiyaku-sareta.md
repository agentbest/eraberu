副業の案件は、自分の意思で終えることもあれば、依頼側から終了を告げられることもあります。採用が一段落した、予算が縮んだ、担当が変わった、期待した成果が出なかった。理由は様々で、自分に非が無いことも多い。ただ、告げられた瞬間は動揺し、感情的な返しをしたり、引き継ぎを省いたりして、関係と実績と次の経路を失う人がいます。結論を先に書くと、**契約を切られたときは、「理由を確かめる」「引き継ぎを丁寧に」「実績を残す」「関係を保つ」「次の経路を動かす」の五つを順に行い、終わり方を自分の側でコントロールする**と、切られたこと自体は次の妨げになりません。終わりを告げたのは依頼側でも、終わり方を決めるのは自分です。引き継ぎの残し方は[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)に、次への動きは[次の案件につなげる](/media/fukugyo-tsugi-e/)にまとめています。

## 切られる理由の種類

依頼側が終了を告げる理由を、種類ごとに整理します。理由によって、受け止め方と次の動きが変わります。

| 理由 | 依頼側に起きていること | 自分の側の要因 | 受け止め方 |
|---|---|---|---|
| 採用が一段落した | 必要な人数が採れた、募集が止まった | 無い。成果が出た結果 | 型を残して終える。次の採用で声がかかる形に |
| 予算の縮小 | 事業の状況で外部費用を削る | 無い | 範囲を狭めて続ける提案もできるが、無理はしない |
| 担当や判断する人の交代 | 新しい担当が外部の人を知らない、方針が変わった | 前提の引き継ぎが無かった可能性 | 新しい担当に型と現状を渡す。続かなくても関係は残す |
| 成果への不満 | 期待した数が出なかった | 成果の定義のずれ、範囲の外の原因、型の精度 | 数で振り返る。ずれの原因を自分の側と依頼側の側に分ける |
| 関係の悪化 | 範囲の広がりを断った、意見が合わなかった | 断り方、線の引き方 | 振り返る。線を引いたこと自体は正しいことが多い |
| 内製化 | 人事を採用した、社内で回せるようになった | 無い。型を残した結果でもある | 型が残ったことを成果として実績に |
| 理由が告げられない | 依頼側の事情 | 分からない | 一度だけ理由を聞く。答えが無ければ深追いしない |

種類の要点は、「自分の側に要因が無い理由が多い」ことです。採用の一段落、予算、内製化は、むしろ成果の結果です。切られたことを自分の失敗と決めつける前に、理由の種類を見ます。

## 五つの動き方

告げられてから、最後の稼働までの動きを、五つに分けて番号付きで整理します。

**一 理由を確かめる**

1. その場で反論しない。「承知しました。理由を伺ってもよいですか」と、一度だけ聞く
2. 理由の種類を把握する。自分の側の要因があるか、無いか
3. 成果への不満なら、数で振り返る材料を用意する（責めるためではなく、次のため）

**二 引き継ぎを丁寧に**

4. 終わりの日と、引き継ぎを渡す日を書面で決める
5. 型・いまの状態・未完了の一覧・権限の整理の四つを渡す。[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)
6. 切られた側でも、引き継ぎの質を落とさない。ここが最も見られている

**三 実績を残す**

7. 開始時点から終了時点までの数を、区切りの一枚にして依頼側に送る
8. 実績台帳に一行を埋める。一般化した型、業務の数、変化、学んだこと。[実績の積み上げ方](/media/fukugyo-jisseki-tsumu/)
9. 依頼側の評価がもらえそうなら、三つの質問で一度だけ頼む。[レビューをもらう](/media/fukugyo-review/)

**四 関係を保つ**

10. 最後の連絡は、礼と、型で迷ったときの連絡の範囲を一言。「次の採用のときにご縁があれば」
11. 依頼側の悪口を、どこにも言わない・書かない
12. 契約と請求の控えを整理し、最後の請求を出す。[請求書の書き方](/media/fukugyo-seikyuusho/)

**五 次の経路を動かす**

13. 登録先のプロフィールを、台帳から更新する。時間の枠を「受けられる」に戻す
14. 発信があれば、一般化した型を一本足す
15. 別の依頼側があれば、そちらの稼働を保つ

動き方の要点は、「六で、切られた側でも引き継ぎの質を落とさない」ことです。切られた直後の引き継ぎは、依頼側が最も見ている場面で、ここが丁寧だと、「次の採用のときに」が本気の言葉になります。

### エラベルの見解

登録の相談で多いのは、「成果が出ていないと言われて切られ、悔しくて引き継ぎを最低限にして終えた」という話です。気持ちは分かりますが、依頼側から見ると、「切られたら手を抜く人」という記憶が残り、次の採用のときにも、経営者仲間への紹介のときにも、名前が出ません。切られたこと自体は依頼側の判断ですが、引き継ぎの質は自分の判断で、後者のほうが長く残ります。

見ていて差がつくのは、「切られた案件の終わり方が、自分で終えた案件と同じか」です。理由を一度聞き、引き継ぎを四つ渡し、数を送り、礼を伝える。自分で終える案件と同じ動きをする人は、切られた依頼側から半年後に再開の連絡が来ることがあります。エラベルの登録でも、切られた案件を丁寧に終えた人は、その依頼側から次の採用のときに指名されていて、切られたことが経路を閉じていません。

## 感情的にならないための型

告げられた瞬間に、感情的な返しをしないための型を整理します。

| 場面 | やりがちな返し | 型 |
|---|---|---|
| 告げられた直後 | 「なぜですか」と詰める、「私の何が」と食い下がる | 「承知しました。理由を伺ってもよいですか」。一度だけ |
| 理由が成果への不満 | 「それは御社の分担が」と反論する | 「数で振り返る材料を用意します。次のために」。その場で反論しない |
| 理由が告げられない | 「納得できません」 | 「承知しました。引き継ぎの日程を決めさせてください」。深追いしない |
| 担当の交代が理由 | 「前の担当は」と比べる | 新しい担当に型と現状を渡す。比べない |
| 引き継ぎの場 | 淡々と、最低限に | 自分で終える案件と同じ質で |
| 最後の連絡 | 皮肉や恨みを含める | 礼と、次の縁への一言 |
| 終わったあと | 発信やコミュニティで依頼側の話をする | 一切しない。一般化した型と学んだことだけ |

型の要点は、「その場で反論しない」ことです。反論したくなる理由（分担が動かなかった、判断が遅かった）は事実でも、告げられた場で言うと、関係が終わります。数で振り返る材料を用意し、区切りの一枚で事実として示せば、依頼側は受け取れます。

## 切られたあとに見直すこと

終わったあと、次のために見直すことを整理します。自分を責めるためではなく、型を直すためです。

| 見直すこと | 問い | 直し方 |
|---|---|---|
| 成果の定義 | 依頼側と成果の定義が合っていたか | 面談で成果を自分が動かせる数に置き換える。[期待値のすり合わせ](/media/fukugyo-kitai-chousei/) |
| 範囲の外の原因 | 数が動かなかった原因が範囲の外にあったのに、区切りで示していたか | 区切りで、範囲の外の原因を数で示す習慣 |
| 担当の交代への備え | 担当が変わったとき、前提を引き継いだか | 型と現状を渡し、初回打ち合わせをやり直す |
| 兆候の見落とし | 返事の遅れ、判断待ちの滞留、範囲外の増加に気づいていたか | 兆候が出た時点で動く。[継続してもらうために](/media/fukugyo-keizoku/) |
| 型の精度 | 一つを直し切って型にできていたか | 三か月の三段を守る |
| 依頼側の分散 | 一つの依頼側に稼働が集中していなかったか | 二件目を持つ。[案件を増やすタイミング](/media/fukugyo-anken-fuyasu/) |
| 線の引き方 | 断り方や線の引き方が、関係を壊す形になっていなかったか | 範囲か時間の違いで。相手の評価にしない |

見直しの要点は、「自分の側に要因が無い理由なら、見直すのは依頼側の分散だけ」ということです。採用の一段落や予算で切られたなら、自分の型は正しかった。次に備えるのは、一つの依頼側に依存しない形です。

## 終わり方の失敗

切られたときの終わり方で起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| その場で反論する | 悔しい | 一度だけ理由を聞く。反論は区切りの一枚で事実として |
| 引き継ぎを最低限にする | 手を抜きたくなる | 自分で終える案件と同じ質で |
| 数を送らない | 意味が無いと思う | 開始時点と終了時点の数を、区切りの一枚で。実績台帳の元になる |
| 依頼側の悪口を言う | 発散したい | 一切しない。狭い業界では伝わる |
| 最後の請求を出しにくい | 気まずい | 書面のとおりに出す。[未払いのときの対応](/media/fukugyo-mibarai/) |
| 権限を返さない | 忘れる | 書面に沿って返し、停止を確認 |
| 実績台帳に書かない | 失敗だと思う | 一行を埋める。学んだことも |
| 登録先の時間を更新しない | 落ち込む | 「受けられる」に戻す。次の経路を動かす |
| 切られた理由を、自分の能力の問題と決めつける | 自信を失う | 理由の種類を見る。自分の側に要因が無い理由が多い |
| 切られた依頼側を避け続ける | 気まずい | 礼を伝えて終えていれば、次の採用のときに連絡が来ることがある |

失敗の要点は、「切られたことと、終わり方は別」という点です。切られたことは依頼側の判断で、終わり方は自分の判断です。終わり方が丁寧なら、切られたことは記憶に残らず、丁寧さが残ります。

### エラベルの見解

担当する側として登録した人の話を聞くと、副業を長く続けている人は、切られた経験を持っています。採用の一段落、予算、担当の交代。切られること自体は、続けていれば起きます。違いは、切られたあとの動きです。丁寧に終え、数を残し、台帳に一行を足し、登録を更新し、次の案件に入る。切られた依頼側から、半年後に「また採用を始めるので」と連絡が来ることも珍しくない。

依頼側から見ると、契約を終える判断は、副業の人の能力とは別の事情で行うことが多く、終えた後も「良い人だった」という記憶が残れば、次の採用のときに声をかけます。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口ですが、案件が終わった担当者に、次の案件をお伝えするとき、前の依頼側からの評価が材料になります。丁寧に終えた案件は、次の案件の入口です。

## まとめ

- 切られる理由は**採用の一段落・予算・担当の交代・成果への不満・関係の悪化・内製化・告げられない**。**自分の側に要因が無い理由が多い**
- 五つの動きは**理由を確かめる→引き継ぎを丁寧に→実績を残す→関係を保つ→次の経路を動かす**
- **切られた側でも引き継ぎの質を落とさない**。最も見られている場面
- 感情的にならない型は**一度だけ理由を聞く・その場で反論しない・比べない・礼で終える・悪口を言わない**
- 見直すのは**成果の定義・範囲の外の原因の示し方・担当の交代への備え・兆候・型の精度・依頼側の分散・線の引き方**
- **切られたことと終わり方は別**。終わり方が丁寧なら、切られたことは経路を閉じない

## よくある質問

### 成果が出ていないと言われましたが、原因は依頼側の分担が動かなかったことです。伝えるべきですか

その場では伝えず、区切りの一枚で、数と事実として示します。「開始時点と終了時点の数はこうです。数が動かなかった週は、日中の一次返信の分担が入っていない週と重なっています。次に採用を進める際は、分担の運用を先に決めると変わると思います」。責めるのではなく、次のための整理として。依頼側は、切る判断を変えないかもしれませんが、事実は記録に残り、次の採用のときに「あの人の言っていた分担」として思い出されます。その場で反論すると、事実であっても、言い訳として受け取られます。

### 担当が変わって、新しい担当から「外部の人は要らない」と言われました

新しい担当は、前の担当との前提を知りません。切られる前に、型と現状の一枚と区切りの数を新しい担当に渡し、「前の担当の方とこう進めていました。続けるかどうか、これを見てご判断ください」と伝えます。それでも終了なら、丁寧に引き継ぎます。新しい担当が、型を見て「これは使える」と思えば、続くこともあります。担当の交代は、続かなくなる最大の理由の一つなので、交代の時点で動くことが、切られる前の備えになります。[継続してもらうために](/media/fukugyo-keizoku/)を参照してください。

### 切られたことで自信を失い、次の案件を探す気になれません

理由の種類を、もう一度見てください。採用の一段落、予算、担当の交代、内製化なら、自分の側に要因はありません。成果への不満でも、成果の定義のずれや範囲の外の原因であることが多く、自分の能力の問題と決めつける根拠は薄い。実績台帳に、その案件の一行（型、数、変化、学んだこと）を埋めてみると、残ったものが見えます。残ったものがあれば、次の案件で使えます。登録先の時間を「受けられる」に戻すだけでも、次の一歩になります。一つの依頼側に依存していたなら、次は二件目を持つことが、同じ不安を減らします。
