「いずれは採用を自社で回せるようにしたい。内製化を手伝ってほしい」という依頼は、担当者にとって「自分の仕事を無くす」依頼に見えます。ただ、内製化を支援できる担当者は、依頼側から信頼され、次の依頼と紹介につながります。一方で、担当者が抜けた瞬間に止まる内製化は、支援になっていません。結論を先に書くと、**内製化の支援は、型（様式と基準）・記録（依頼側の環境で依頼側が更新）・判断（会社が決めることを会社が決めている状態）の三つを依頼側に移すことで、工程ごとに「担当者がやる→一緒にやる→依頼側がやり担当者が見る→依頼側だけ」の四段で進め、移す順番は記録の揃いから、社内の担当を一人決め、完了の条件を一枚で合意し、後の関わり方を決めます。**会社側から見た道筋は[内製化に向けたロードマップ](/media/rpo-uchisei-ikou/)に、代行から戻す手順は[採用代行から内製に戻すときの手順](/media/rpo-uchisei-modoshi/)に、社内の担当の育て方は[社内の採用担当を育てる](/media/fukugyo-skill-jinji-ikusei/)に書いています。ここでは、担当者が支援する型に絞ります。

## 「担当者が抜けたら止まる」で失敗する理由

| 内製化の形 | 何が起きるか |
|---|---|
| 担当者が回し続け、期限が来たら渡す | 型も記録も担当者の頭の中で、渡した翌日に止まる |
| マニュアルを渡して終わり | 読まれず、記録の更新が止まる |
| 社内の担当が決まっていない | 「誰がやるか」で止まる |
| 判断を担当者がしていた | 依頼側が判断の仕方を知らず、決められない |
| 全工程を同時に渡す | 一度に覚えられず、全部が中途半端 |

内製化は「渡す」ことではなく、「依頼側が回している状態を作る」ことです。担当者がいる間に、依頼側が回している状態にします。

## 三つの移し先

| 移すもの | 移した状態 | 確かめ方 |
|---|---|---|
| 型 | 様式（候補者リスト、評価シート、依頼書、文面の型、報告の一枚）と基準の一行が、依頼側の場所にあり、依頼側が直せる | 依頼側の担当が、型を一つ直せるか |
| 記録 | 記録が依頼側の環境（ATS、共有の場所）にあり、依頼側の担当が更新している | 週次の確認で、担当者が更新した行がゼロか |
| 判断 | 会社が決めること（要件、優先、条件、合否）を、会社が自分で決めている。担当者に「どうすれば」と聞かれない | 月次のレポートの「判断してほしいこと」を、依頼側が自分で挙げられるか |

三つのうち、最後まで残るのが「判断」です。型と記録が移っても、依頼側が「担当者に聞けば決めてくれる」状態なら、内製化は終わっていません。判断の所在は[マニュアルを作る](/media/fukugyo-skill-manual/)の「判断の所在を明記する」に書いています。

### エラベルの見解

担当する側から見ると、内製化の支援で最も差がつくのは、「担当者が抜けても回るか」を、担当者がいる間に試せるかです。受ける側は、期限まで自分で回し、期限に渡します。試していないので、渡した翌週に止まり、「やっぱり続けてほしい」となります。それは信頼ではなく、依存です。「今月は私が触らず、御社だけで回してみてください。詰まったところを一緒に直します」を、契約の終わりの二か月前に一度入れる。回れば内製化は完了で、回らなければ直す場所が分かります。エラベルで担当者を選ぶ企業には、「担当者が一か月触らなくても、採用は回りますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、内製化の計画の一枚に「担当者が触らない月」を最初から入れること。

## 工程ごとに四段で移す

| 段 | 担当者 | 依頼側の担当 | 期間の考え方 |
|---|---|---|---|
| 一：担当者がやる | 回す。型と記録を依頼側の場所に置く | 見る | 型と記録が揃うまで |
| 二：一緒にやる | 依頼側の担当と一緒に回す。判断の場面で「どう決めますか」と問う | 一緒に回す | 一〜二か月 |
| 三：依頼側がやり、担当者が見る | 触らない。週次で記録を見て、詰まりを一言 | 回す | 一〜二か月 |
| 四：依頼側だけ | 月次の確認か、終了 | 回す | — |

工程（検索・見極め・文面・日程・面接・内定後・報告）ごとに、いまどの段かを一枚で見える形にします。全工程を同時に段を上げず、記録が揃った工程から上げます。

## 移す順番は記録の揃いから

| 順 | 工程 | 理由 |
|---|---|---|
| 一 | 記録の運用（一覧の更新、週次の確認） | 記録が依頼側で回らないと、他の工程を見られない |
| 二 | 日程調整と連絡（確定の即日、返信の型） | 型があれば回しやすく、効果が見えやすい |
| 三 | 見極めと面接の記録 | 評価シートの型があれば、面接官が回せる |
| 四 | 検索とスカウト文面 | 型と検証の記録があれば回せる。判断（対象の層）が要る |
| 五 | 要件・媒体・紹介会社の管理 | 判断が多い。最後に |

順番は依頼側の状況で変わりますが、「記録が先、判断の多い工程が後」は共通です。運用の型は[送信運用を回す](/media/fukugyo-skill-soushin-unyou/)と[ATSの運用ルールを作る](/media/fukugyo-skill-ats-unyou/)に書いています。

## 社内の担当を一人決める

| 決めること | 中身 |
|---|---|
| 誰が | 採用を主に担う人。兼務でもよいが、一人に決める |
| 週の時間 | 内製化の後に、その人が採用に使える時間。無理のない数 |
| 育て方 | 四段の「一緒にやる」の中で。型で回し、記録で振り返り、判断の場面で問われる |
| 経営者の関わり | 判断（要件、条件、合否）は経営者か決める人。担当に押しつけない |

担当が決まらないまま内製化を進めると、「誰がやるか」で止まります。担当の育て方は[社内の採用担当を育てる](/media/fukugyo-skill-jinji-ikusei/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「内製化を支援すると、自分の契約が早く終わる」というものです。実際には、内製化を支援した担当者は、依頼側に「この人は自分たちのために動いた」と残り、月次の確認の契約、次の課題（制度、定着）の依頼、他社への紹介につながります。内製化を渋る担当者は、依頼側から「自分の契約のために囲っている」と見られ、更新のときに切られます。内製化を進めることが、長い関係を作ります。受ける側がその場で使える判断としては、内製化の計画の一枚に「内製化の後の関わり方」の欄を置き、「月次の確認」「次の課題」「終了」のどれかを、依頼側と最初に話しておくこと。関係の続け方は[紹介につなげる](/media/fukugyo-shoukai-renkei/)に書いています。

## 完了の条件を一枚で合意

| 条件 | 確かめ方 |
|---|---|
| 型が依頼側の場所にあり、依頼側が直せる | 依頼側の担当が、型を一つ直した |
| 記録が依頼側だけで更新されている | 担当者が触らない月に、記録が止まらなかった |
| 判断が依頼側で行われている | 月次の「判断してほしいこと」を、依頼側が自分で挙げた |
| 社内の担当が決まり、週の時間がある | 一人と時間が一枚に書いてある |
| 引き継ぎの四つが揃っている | [引き継ぎ資料を作る](/media/fukugyo-skill-hikitsugi/)の一枚 |

完了の条件を最初に合意しておくと、「まだ不安だから続けて」で契約が曖昧に延びることも、「もう十分」で早く切られることも減ります。条件は契約に書きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## 内製化の後の関わり方

| 形 | 中身 |
|---|---|
| 月次の確認 | 月に一度、記録を見て詰まりを一言。稼働は短く |
| 次の課題 | 採用の後の課題（定着、制度、育成）を、別の契約で |
| 終了 | 引き継ぎの一枚を渡し、手元の情報を消して終える |
| 再開の条件 | 「採用の人数が増えたら」「新しい職種を採るとき」など、依頼側から声がかかる形 |

どれにするかは依頼側が決めます。担当者は三つを並べ、判断を渡します。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 担当者が回し続けている | 四段の一枚を作り、工程ごとにいまの段を書く。二段に上げる工程を決める |
| 社内の担当が決まらない | 決まるまで内製化を進めない。「誰がやるか」を依頼側に |
| 依頼側が判断を担当者に聞く | 「どう決めますか」と問い返す。判断の所在を一枚に |
| 担当者が触らない月に止まった | 止まった工程の段を一つ戻し、型か記録を直す |
| 依頼側が「まだ不安」と延ばす | 完了の条件に照らす。条件を満たしていれば、月次の確認の形を提案 |
| 担当者が内製化を渋ってしまう | 後の関わり方を先に話す。内製化が関係を作る |

## まとめ

- 「担当者が抜けたら止まる」内製化は支援ではない。**依頼側が回している状態を、担当者がいる間に作る**
- 移すのは**型・記録・判断**の三つ。最後まで残るのは判断
- 工程ごとに**担当者がやる→一緒に→依頼側がやり担当者が見る→依頼側だけ**の四段。同時に上げない
- 順番は**記録の揃いから、判断の多い工程は最後**
- **社内の担当を一人**と週の時間を決める。判断は経営者
- **担当者が触らない月**を計画に入れ、回るかを試す
- **完了の条件を一枚で合意**し、契約に書く。後の関わり方（月次・次の課題・終了）を最初に話す

## よくある質問

### 依頼側に採用の担当を置ける人がおらず、内製化が現実的ではありません

担当が置けない間は、内製化ではなく「型と記録を依頼側の場所に置いた状態で、担当者が回す」形を続けます。その状態なら、担当者が替わっても別の担当者が回せ、依頼側が担当を置けたときに四段を始められます。「内製化の前段」として、型と記録の移行だけを進めます。担当を置くかどうかは依頼側の判断で、担当者は「置けた場合に要る時間」を示すまでです。

### 内製化を進めたら、依頼側が「もう来なくてよい」と急に終了を言いました

完了の条件を最初に合意していれば、条件に照らして「揃っているか」を確かめ、揃っていれば引き継ぎの一枚を渡して終えます。揃っていなければ、「この工程はまだ三段目なので、一か月は週次で見ます」と、残りを示します。それでも終了なら、引き継ぎの一枚を丁寧に残し、手元の情報を消して終えます。急な終了は、担当者の側に落ち度が無くても起きるので、契約の終了の条件（予告の期間）を最初に書いておきます。

### 内製化の途中で、依頼側の担当が辞めてしまいました

四段の一枚に「いまの段」が工程ごとに書いてあれば、次の担当が来たときに、どの工程から一緒にやるかが分かります。担当が辞めた工程は、段を一つ戻し、担当者が一時的に回します。新しい担当が決まるまで内製化を止めるか、担当者が回し続けるかは、依頼側の判断です。型と記録が依頼側の場所にあれば、担当が替わっても内製化はゼロには戻りません。
