本業で新卒採用を担当してきた。年間の計画、説明会、選考の設計、内定者の繋ぎ。ただ、副業の案件は中途採用が多く、新卒の経験は使えないのではないかと感じる。新卒採用の経験は、副業でどう売ればよいのか。結論を先に書くと、**新卒採用の経験は、「年間の計画で母集団を作り、複数の候補者を同時に動かし、内定から入社までを繋ぐ」という運用の型で売れます。売れるのは、「初めて新卒を採る依頼側の年間の設計」「説明会と選考の設計」「内定者の繋ぎと辞退の防止」「学生向けの文面と伝え方」の四つです。新卒の経験は新卒にしか使えないと思われがちですが、大量・並行・長期の運用の型は、中途採用の母集団づくりや複数の候補者の同時進行にもそのまま使えます。「新卒しか知らない」ではなく、「大量・並行・長期の運用の型を、中途にも」と売ります。**人事未経験の売り方は[人事未経験が副業でできること](/media/fukugyo-mikeiken-jinji-fukugyo/)に、候補者対応の線は[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/)に、複数の候補者の管理は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)にまとめています。

## この経歴の何が売れるか

新卒採用担当の経験を、副業の工程に置き換えた棚卸しです。新卒の依頼側と、中途の依頼側の両方に置き換えます。

| 新卒採用の経験 | 新卒の依頼側への置き換え | 中途の依頼側への置き換え |
|---|---|---|
| 年間の計画を立て、逆算して動いてきた | 初めて新卒を採る依頼側の、一年の流れ（広報、説明会、選考、内定、繋ぎ、入社）の設計 | 中途の採用の計画を、月ごとの母集団と選考の流れに落とす |
| 説明会やイベントで母集団を作ってきた | 説明会の設計、話す内容の構成、参加から応募への流れ | 中途の会社説明の場（面談前の説明、カジュアル面談）の設計 |
| 多数の候補者を並行で管理してきた | 選考の進捗を一覧で管理し、漏れなく動かす型 | 複数の候補者を同時に進める中途の選考で、進捗と連絡を管理する型 |
| 内定者の繋ぎと辞退の防止をしてきた | 内定から入社までの接点の設計（連絡の頻度、集まり、不安の聞き取り） | 中途の内定から入社までの繋ぎ（入社前の不安の聞き取り、辞退の防止） |
| 学生向けの文面を書いてきた | 学生に伝わる言葉と構成 | 経験の浅い層、第二新卒層の候補者向けの文面 |
| 面接官（現場の社員）を巻き込んできた | 面接官の選定、面接官向けの準備資料、評価の観点の統一 | 中途でも同じ。面接官向けの準備資料と評価の観点 |
| 選考の基準を設計してきた | 経験ではなく可能性で見る基準の設計 | 経験の浅い層を採る中途の基準の設計 |

売れるものの要点は、「新卒の経験は、大量・並行・長期の運用の型として、中途にも使える」ことです。中途採用の依頼側で多い詰まりは、複数の候補者を同時に進めると連絡が漏れる、内定の後に辞退される、母集団を計画的に作れない、というもので、これは新卒採用の担当が毎年やってきた運用そのものです。新卒の経験を「新卒の知識」ではなく「運用の型」として棚卸しすれば、中途の依頼側にも売れます。並行の管理は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、面接官との連携は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に書いています。

## 売りにくい点とその扱い

新卒採用担当の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 中途との違い | 「新卒しかやったことがないなら、中途の即戦力の見極めはできないのでは」 | 見極めではなく運用で売る。「候補者の見極めは御社の判断で。私は母集団づくり、並行の管理、内定の繋ぎの運用を担います」と範囲を示す |
| 季節の偏り | 「新卒は時期が決まっているが、副業は年中動けるのか」 | 本業の繁忙期（新卒の選考の時期）を先に依頼側に伝え、その時期は稼働を縮める形で受ける。年間の設計の案件は、繁忙期の外に置く |
| 依頼側の規模 | 「大手の新卒採用の型は、うちの規模では使えないのでは」 | 型を依頼側の規模に合わせて縮める。「説明会は数人、選考は一段階」など、小さい規模の設計を示す |

扱い方の要点は、「見極めではなく運用で売る」ことです。新卒採用の担当は、経験ではなく可能性で候補者を見てきたので、中途の即戦力の見極めには不安があります。その不安は正直に扱い、見極めは依頼側の判断に置き、自分は運用（母集団、並行の管理、繋ぎ、文面、面接官の準備）を担う形にします。運用の型は、中途でも新卒でも同じです。本業の繁忙期の伝え方は[本業と副業の両立｜崩れる原因と防ぎ方](/media/fukugyo-ryouritsu/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、新卒採用の担当から転身して続いている人と、案件が取れない人の差は、「新卒採用をやっていました」と言うか、「複数の候補者を同時に進めて漏れなく動かし、内定から入社まで繋ぐ運用を担います」と言うかです。前者は中途の依頼側に「うちは新卒を採らない」で終わり、後者は「うちの詰まりはそこだ」となります。新卒の経験は、知識として売ると狭く、運用の型として売ると広いです。

見ていて差がつくのは、内定から入社までの繋ぎを、中途の依頼側に持ち込んでいるかです。中途採用の依頼側の多くは、内定を出したら終わりと思っていて、入社までの数週間から数か月に候補者と接点を持たず、その間に辞退されています。新卒採用の担当は、内定者の繋ぎを毎年やってきていて、連絡の頻度、不安の聞き取り、入社前の準備の共有の型を持っています。この型を中途に持ち込んだ人は、依頼側の内定辞退が減り、「採用の最後の詰まりを埋めてくれた」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、運用の型を明確にし、見極めとの線を示している担当者に、並行の管理や内定の繋ぎで詰まっている依頼側がついています。新卒採用の担当の転身は、知識ではなく、運用の型で始まります。

## 案件の探し方

新卒採用担当から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 初めて新卒を採る依頼側の年間の設計 | 年間の計画の経験で入れる | 「初めて新卒を採る依頼側の一年の流れ」を範囲の一言に。本業の繁忙期の外で |
| 中途の複数の候補者の並行の管理 | 並行の管理の経験で入れる | 「候補者が複数いると連絡が漏れる依頼側」を範囲の一言に |
| 内定から入社までの繋ぎ | 繋ぎの経験で入れる | 「内定辞退が多い依頼側」を範囲の一言に |
| 会社説明の場の設計 | 説明会の経験で入れる | 「カジュアル面談や説明の場で、候補者の関心が高まる構成」を示す |
| 面接官向けの準備資料と評価の観点 | 面接官を巻き込んできた経験で入れる | 「面接官ごとに評価がばらつく依頼側」を範囲の一言に |
| 経験の浅い層を採る依頼側の基準と文面 | 可能性で見る基準の経験で入れる | 「第二新卒や経験の浅い層を採りたい依頼側」を範囲の一言に |

探し方の要点は、「内定辞退が多い依頼側」から入ることです。中途の依頼側にとって、内定辞退は最も損失が大きく、原因が分からず、新卒の担当が持つ繋ぎの型が最も効きます。一件で内定辞退を減らせれば、並行の管理や母集団の設計に広げられます。新卒の年間の設計は、本業の繁忙期と重なるので、繁忙期の外で受けます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、始め方は[人事の副業の始め方](/media/fukugyo-hajimekata/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。新卒採用担当の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 運用の型の価値 | 並行の管理と繋ぎの型は、依頼側の内定辞退と漏れを減らし、価値が分かりやすい | 「減った辞退」「減った漏れ」を成果として示せる形に |
| 見極めを含まない範囲 | 見極めを含まない範囲は、含む範囲より単価は下がるが、責任の線が明確 | 運用に徹し、見極めは依頼側に |
| 成果物で受けやすい工程 | 年間の設計、説明の場の構成、繋ぎの流れ、面接官向けの資料は、成果物で受けやすい | 成果物で受けると、単価の議論が明確になる |
| 並行の管理の継続 | 候補者の進捗の管理は、月額で受けやすい | 月に何時間、と枠を決めて月額に |
| 本業の繁忙期 | 繁忙期は稼働を縮めるので、月額を年間で均さない | 繁忙期の月は月額を下げるか、その月は稼働しない形を契約に |
| 最初の案件 | 中途の実績が無いので、範囲を絞って小さく | 単価を下げるのではなく、範囲と時間を小さくする |

単価の要点は、「本業の繁忙期を、契約の前に伝え、その月の稼働と月額を分ける」ことです。新卒採用の担当は、本業の選考の時期に稼働が取れなくなります。年間で同じ月額にすると、繁忙期に稼働できず、依頼側との約束が崩れます。「〇月と△月は本業の繁忙期のため、稼働を半分に、月額もその分に」と契約に入れておけば、崩れません。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、繁忙期の伝え方は[長く続けるための設計](/media/fukugyo-choki/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に整理しています。

## 始める順番

新卒採用担当から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、新卒採用で回してきた運用を、「新卒の知識」ではなく「運用の型」で書き出す | 年間の設計、母集団、並行の管理、繋ぎ、文面、面接官の準備 |
| 二、それぞれの型を、中途の依頼側の工程に置き換える | 並行の管理→中途の選考の管理、繋ぎ→中途の内定から入社 |
| 三、見極めは依頼側に置く、と決める | 運用で売る |
| 四、本業の繁忙期を書き出し、その時期の稼働の形を決める | 契約の前に伝える |
| 五、範囲を、年間の設計、並行の管理、繋ぎ、説明の場、面接官の準備、経験の浅い層の基準と文面に絞る | 依頼側の規模に合わせて縮める |
| 六、「大量・並行・長期の運用の型を、中途にも」の一言を作る | 「新卒しか知らない」とは言わない |
| 七、登録先に、範囲と繁忙期を登録する | 内定辞退が多い依頼側、並行で漏れる依頼側 |
| 八、内定の繋ぎか並行の管理を一件、成果物か月額で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「二」の置き換えを、案件を探す前にやることです。新卒の運用を新卒の言葉のまま持っていると、中途の依頼側に伝わりません。「説明会」を「説明の場」に、「内定者フォロー」を「内定から入社までの繋ぎ」に、「選考管理」を「複数の候補者の並行の管理」に、と中途の依頼側の言葉に置き換えてから、案件を探します。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「新卒採用の経験は、中途が中心の副業では使えない」というものです。実際には、中途採用の依頼側の詰まりの多くは、並行の管理、内定の繋ぎ、計画的な母集団づくりで、新卒採用の担当が毎年やってきた運用そのものです。使えないのではなく、新卒の言葉のまま売っているから伝わらないだけで、運用の型に置き換えれば、中途にも売れます。

順番として、新卒の運用を型で書き出し、中途の工程に置き換え、見極めは依頼側に置き、本業の繁忙期の稼働の形を決め、範囲を絞り、運用の型を中途にも、の一言を作り、登録先に範囲と繁忙期を登録し、内定の繋ぎか並行の管理を一件受けて型を残す。この順番で、新卒採用担当の転身は、「新卒しか知らない人」から「大量・並行・長期の運用ができる人」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、運用の型を明確にし、見極めとの線と繁忙期を示している担当者に、並行の管理や内定の繋ぎで詰まっている依頼側がついています。新卒採用担当の転身は、知識ではなく、運用の型で始まります。

## まとめ

- 新卒採用の経験は**「年間の計画で母集団を作り、複数の候補者を同時に動かし、内定から入社までを繋ぐ」運用の型**で売れる。**年間の設計・説明の場と選考の設計・内定の繋ぎ・学生向けの文面**の四つ
- **「新卒しか知らない」ではなく「大量・並行・長期の運用の型を、中途にも」**と売る
- 売りにくい点は**中途との違い・季節の偏り・依頼側の規模**。見極めは依頼側に置き、繁忙期は契約の前に伝え、型は規模に合わせて縮める
- 最も効くのは**内定から入社までの繋ぎ**。中途の依頼側は内定で終わりと思っていて、そこで辞退されている
- 案件は**内定辞退が多い依頼側**から。並行の管理と母集団の設計に広げる
- 単価は**成果物と月額で、繁忙期の月は稼働と月額を分けて契約に**

## よくある質問

### 新卒しか経験がなく、中途の候補者の見極めができるか不安です

見極めは依頼側の判断に置き、自分は運用（母集団、並行の管理、繋ぎ、文面、面接官の準備）を担う形で受けます。「候補者の見極めは御社で。私は候補者が漏れなく動き、内定の後に辞退されない運用を担います」と最初に示せば、見極めの不安は範囲の外になります。運用を回すうちに、依頼側の判断の観点が分かり、見極めの材料（確認できたこと、確認が要ること）を渡せるようになります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### 本業の新卒採用の繁忙期に、副業の稼働が取れません

繁忙期を契約の前に伝え、その時期の稼働の形を契約に入れます。「〇月から△月は本業の繁忙期のため、稼働を半分にします。その月の月額もその分に。緊急の連絡は電話で」と決めておけば、依頼側はその前提で予定を組みます。繁忙期に重ならない案件（中途の内定の繋ぎ、並行の管理）を中心に受け、新卒の年間の設計は繁忙期の外で受けます。繁忙期の設計は[長く続けるための設計](/media/fukugyo-choki/)に、伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に書いています。

### 本業で使っている学校との関係や、説明会の資料を、副業の依頼側に使ってよいですか

本業で作った学校との関係や、本業の説明会の資料そのものは、副業に持ち込みません。本業の会社の関係と資料を副業に使う形になり、本業との利益相反と守秘の線を越えます。副業の依頼側には、「説明の場の構成の型」「学校との関係の作り方の型」を渡し、関係と資料は依頼側が自分で作る形にします。本業で得た「型」は使えますが、「本業で作った関係と資料そのもの」は使いません。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、型の作り方は[副業の学びを本業に還す](/media/fukugyo-honngyou-hanei/)に整理しています。
