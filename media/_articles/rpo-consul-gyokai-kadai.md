コンサル業界の採用が進まないときは、**日程と承認、評価方法、説明内容、募集経路と採用時期を、職務・条件と実際の記録から確認します。**以下は検討の切り口で、原因を五つに限定したり、一つに確定してからしか対応できないとしたりするものではありません。複数の課題が重なる場合は、進行中の候補者対応と改善を並行します。[任せる範囲](/media/rpo-consul-gyokai-rpo/)と[母集団形成](/media/rpo-consultant-boshuudan/)も参照できます。

## 原因を決めつけずに確認する五つの切り口

| 切り口 | 確認する記録・条件 |
|---|---|
| 日程・承認 | 工程の起終点、待ち時間、未対応と承認・案内期限 |
| 評価 | 必要業務と評価方法、根拠と未確認事項 |
| 説明内容 | 原稿・面談と実態、本人からの質問や確認できた理由 |
| 募集経路 | 到達と応募選考、媒体紹介等、重複や対象の違い |
| 採用時期 | 確定・見込みの需要、教育と配置、本人の希望・入社準備 |

一つの症状に複数の原因がある場合もあり、記録だけでは分からないこともあります。優先度は候補者への影響・期限と社内外の稼働から決め、確認できた事実と仮説を分けます。

## 件数・率と理由の前提をそろえる

| 見るもの | 原因判断の前に確認すること |
|---|---|
| 工程別の日数 | 起終点と未完了、候補者と社内の待ち時間 |
| 面接官別の通過 | 職務と候補者、課題・面接条件と件数 |
| 辞退理由 | 本人に確認できた範囲、複数理由と未確認 |
| 経路別の実績 | 募集条件・時期、重複と選考中の対象 |
| 入社までの期間 | 採用準備と本人の事情、需要・条件の変化 |

他社で決まったから日程、通過率に差があるから評価、出身区分別で低いから経路と、自動的には判定しません。少数の実績や対象条件の違いも確認して対応を検討します。[採用ファネル](/media/rpo-funnel/)も参照できます。

### エラベルの見解

たとえば、評価者の予定と承認が確認できず、候補者へ案内できない場面が考えられます。これは想定例で、業界で最も多い原因という実績ではありません。候補枠の確保、代替担当と案内期限を相談し、週一枠・即日確定だけで解決すると保証しません。[日程の滞留](/media/rpo-nittei-chousei-osoi/)も参照できます。

## 日程・承認の課題を確認する

| 確認すること | 検討する対応 |
|---|---|
| 候補者と評価者の予定 | 候補枠と案内期限、変更・不在代替 |
| 複数工程の実施 | 目的と準備、本人の希望・負担から日程を組む |
| 実施方法 | 対面・オンラインの必要条件と利用環境 |
| 面接と承認の担当 | 職務理解と権限、必要人数と稼働を確認 |
| 辞退・未返信 | 本人から確認できた理由と未確認を区別 |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 必要業務と評価の根拠を照合する

| 確認すること | 検討する対応 |
|---|---|
| 抽象的な印象だけが残る | 必要業務と評価方法、判断根拠を記録 |
| 面接官別で通過率が違う | 対象と実施条件、件数や評価根拠を確認 |
| 出身区分で評価を変えている | 今回の職務に必要な要件・理由と照合 |
| 応募や通過が少ない | 到達と条件、要件と評価・期間を併せて検討 |

評価方法の提案や記録整備を相談する場合は、必要な専門経験と作業範囲を個別に確認します。社内の要件・評価方法と採否の承認、実務を分け、記録だけで原因が確定するとは考えません。[評価のばらつき](/media/rpo-mensetsukan-bara/)も参照できます。

## 原稿・面談の説明と実態を確認する

| 確認する内容 | 説明時の留意点 |
|---|---|
| 案件・職務 | 担当する範囲と変更条件、利用できる情報 |
| 勤務条件と稼働 | 実際の運用、繁閑と勤務時間等の条件 |
| 教育・昇格 | 制度と適用条件、保証されない見込みを区別 |
| チーム・支援 | 誰が何を担い、質問・相談を受けるか |
| 実績等の説明 | 集計範囲・期間と根拠、秘密や個人情報を確認 |

候補者が評判を知っているか、何を希望するかは個別に確認します。原稿を事実と条件に沿って説明し、公開・変更の確認者を決めます。正確な説明だけで辞退が減るとは保証しません。[原稿作成](/media/rpo-task-kyujin-genko-susumekata/)も参照できます。

### エラベルの見解

同業なら即戦力、事業会社出身なら専門性が高くコンサル未経験、新卒なら特定の成長希望があるとは推定しません。本人の担当経験・希望と必要業務への適合、教育の実態を確認します。出身区分を理由に評価基準を自動的に変えず、要件の理由と確認方法を共有します。[採用要件](/media/rpo-consultant-youken/)も参照できます。

## 出身区分と募集経路を分けて確認する

| 分けて記録するもの | 確認する内容 |
|---|---|
| 経歴 | 本人の担当経験と確認できた能力 |
| 採用区分・職務 | 新卒・中途等と必要な業務、教育・条件 |
| 募集経路 | 媒体・紹介等と到達、応募選考の実績 |
| 本人の希望 | 確認できた動機・条件と未確認事項 |

原稿・経路の適否は、職務への到達と応募選考、条件と時期、費用や社内外の工数から比較します。出身企業だけで最適媒体や動機を決めません。

## 採用時期・需要と配置を確認する

| 確認すること | 検討する対応 |
|---|---|
| 確定・見込みの需要 | 必要な職務と時期、配置・外部支援等の代替策 |
| 継続的な接点 | 利用目的・本人希望、連絡停止・保存期間と権限 |
| 需要が変わる場合 | 教育・業務分担と予算、契約稼働の変更条件 |

人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に、過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 外に出せる部分と社内で直す部分

| 工程 | 相談する支援の例 | 社内で確認すること |
|---|---|---|
| 日程 | 案内・調整と記録 | 候補枠・承認期限と代替 |
| 要件・評価 | 整理や文書化、記録の形式 | 専門経験と範囲、方法と採否の承認 |
| 原稿 | 取材・制作と更新 | 事実・条件と公開、利用できる素材 |
| 募集経路 | 媒体比較・運用 | 職務への到達、費用と権限 |
| 時期 | 計画整理・進捗や連絡 | 需要共有の必要範囲と教育・配置 |

表は各社が標準対応する範囲を示すものではありません。今回の業界領域・職位と作業への経験、プラン包含と媒体利用条件、必要情報と共有権限を確認します。担当交代と成果物・未完了業務、情報返還削除・権限停止も合意します。[支援条件の確認](/media/rpo-consul-gyokai-jirei/)も参照できます。

## まとめ

- 五つの切り口は確認の材料で、原因を限定・一つに固定しない
- 日数・率や辞退理由は、定義・対象と条件、未確認事項を分ける
- 出身区分だけで能力・希望や評価基準、募集経路を決めない
- 承認・日程と評価、原稿や集客を必要に応じて並行して改善する
- 社内外の権限・工数費用と専門対応、情報や成果物の終了まで確認する

## よくある質問

### パートナーの時間は案件に使うべきで、採用の枠を先に取るのは難しいです

案件と採用の双方の期限・工数を確認し、候補枠や代替評価者、実施方法と承認期限を相談します。週一枠が小さい負担、損失のほうが大きいとは一律に判断しません。記録を示せば多くのパートナーが応じると保証せず、対応可能な体制を確認します。

### 独立系で規模が小さく、新卒は採っていません

規模と採用区分だけで、経路が二つ、パートナーの枠が主要原因、通年接点が必要とは判断しません。職務と採用時期、社内権限・稼働と実際の滞留から、必要な分担と経路を比較します。

### 紹介会社を増やしても、通過が増えません

応募と通過の数だけで、評価が原因と確定しません。推薦・原稿と依頼要件、到達した対象や条件、期間と未完了、評価方法・根拠を併せて確認します。紹介会社へのフィードバックも共有可能な範囲と社内承認を決めます。評価を直すまで経路を見直さないと固定せず、必要な対応を並行して検討します。[推薦の質](/media/rpo-agent-shitsu/)も参照できます。
