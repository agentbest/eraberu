中小企業の人事として、社長の会社で、人事と総務と労務を一人か二人で兼ね、長く働く社員と地域のつながりの中で、限られた予算で人を採り、辞めないように面倒を見てきた。この経験は、副業で売れるのか。中小企業の人事の経験は、専門性が薄く、自社のやり方に慣れすぎていて、他の会社には通じないと感じる人が多いところです。結論を先に書くと、**中小企業の人事の経験は、「社長の会社で、人事と総務と労務を一人で兼ね、長く働く社員と地域の中で、限られた予算で採ってきた」型で売れます。売れるのは、「予算が少ない会社の採用の回し方」「社長と社員の間に立つ型」「地域と紹介と学校で母集団を作る型」「一人で兼ねる仕事の切り分け」の四つです。人事の副業の依頼側の多くは、同じように予算と人が少ない会社で、そこでは大きい会社の仕組みも、ベンチャーの速さも通じず、「少ない予算と人で、それでも採る」型が求められています。「中小企業の人事でした」ではなく、「予算も人も少ない会社で、それでも採れる形を作る」と売ります。**創業期の経験は[スタートアップの人事が副業でできること](/media/fukugyo-startup-jinji-fukugyo/)に、拡大期の経験は[ベンチャーの人事が副業でできること](/media/fukugyo-venture-jinji-fukugyo/)に、中小企業診断士の資格を持つ人の売り方は[中小企業診断士が副業でできること](/media/fukugyo-chuushoukigyou-shindanshi-fukugyo/)にまとめています。

## この経歴の何が売れるか

中小企業の人事の経験を、依頼側の採用の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| 中小企業の人事の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 少ない予算で、媒体を選び、無料の経路を使い、採ってきた | 予算が少ない会社の採用の設計（無料の経路、費用対効果の高い媒体、紹介の仕組み） | 予算がなくて採用に手が打てない依頼側が多い |
| 社長の意向と社員の実情の間に立ってきた | 社長の「こういう人が欲しい」を社員が納得する要件に落とし、社員の不満を社長に伝わる形で戻す | 社長と社員が噛み合わない依頼側が多い |
| 地域のつながり、社員の紹介、地元の学校で母集団を作ってきた | 媒体に頼らない母集団の設計（地域、紹介、学校、取引先） | 媒体に出しても応募が来ない依頼側が多い |
| 人事と総務と労務を一人で兼ね、優先順位を付けてきた | 一人で複数の機能を持つとき、何を先に、何を後に、何を外に出すかの切り分け | 人事の担当者が一人で溺れている依頼側が多い |
| 長く働く社員の中に、新しい人を入れてきた | 古い社員と新しい人の間の受け入れの設計（教える人、距離の取り方、最初の一か月） | 新しい人が古い社員の中で浮いて辞める依頼側が多い |
| 採用した人の入社の手続きから、辞めるときの手続きまで、一人で回してきた | 内定の後から退職までの手続きを、抜けなく回す流れ | 手続きが抜けて後で問題になる依頼側が多い |
| 社長の家族や古参の社員という、会社ごとの事情の中で動いてきた | 会社ごとの事情（家族、古参、地域の関係）を踏まえた採用の進め方 | 事情を知らない外部の人が来て、社員が反発する依頼側が多い |

売れるものの要点は、「予算も人も少ない会社で、それでも採る型」です。人事の副業の依頼側は、多くが予算と人の少ない会社で、大きい会社の仕組みを持ち込まれても回らず、ベンチャーの速さを求められても動けません。中小企業の人事は、その制約の中で採り、辞めないように面倒を見てきており、制約を前提にした型を持っています。この型は、同じ制約を持つ依頼側に、そのまま合います。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、社長との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

## 売りにくい点とその扱い

中小企業の人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 専門性が薄いと見られる | 「人事も総務も労務も兼ねていた人は、どれも浅いのでは」。自分でも、専門と言えるものがない不安 | 「制約の中で採る」ことを専門として語る。「予算が少ない、人が少ない、地域が限られる、古参がいる。その中で採って辞めさせない型」は、大きい会社の人事が持っていない専門性 |
| 自社のやり方に慣れすぎ | 「一つの会社に長くいた人は、他の会社のやり方に合わせられないのでは」 | 自社のやり方ではなく、「会社ごとの事情を読む型」として語る。長くいたからこそ、事情の読み方と、事情を踏まえた進め方を知っている |
| 変化に弱いと見られる | 「新しい媒体やツールを知らないのでは」 | 知らないものは知らないと認め、「予算が少ない会社では、新しいものより、無料の経路と紹介と受け入れのほうが効く」と、依頼側の制約に合わせた打ち手で語る |

扱い方の要点は、「兼任を『浅い』ではなく『制約の中で採る専門性』と言い換える」ことです。中小企業の人事の経験がある人は、自分の経験を「何でも少しずつ」と語りがちで、それが依頼側には「専門がない」に聞こえます。「予算が少ない中で、無料の経路と紹介で母集団を作り、社長と社員の間に立って要件を決め、古参の中に新しい人を入れて辞めさせない。それを一人で回してきた」と語れば、同じ経験が、同じ制約を持つ依頼側に「うちの事情が分かる人」として伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、中小企業の人事から転身して続いている人と、面談で止まる人の差は、「専門は何か」と聞かれたときの答え方です。止まる人は、「人事全般です」「採用も労務もやっていました」と答え、依頼側の経営者は「専門がない人」と感じて終わります。続いている人は、「予算と人が少ない会社で、それでも採って辞めさせない、というのが専門です」と答え、「御社の採用の予算は、年にどれくらいですか」と聞きます。経営者が「ほとんどない」と答えたところで、「それなら、媒体より、社員の紹介と地元の学校と無料の経路から作ります。前の会社でもそうしていました」と返します。経営者は、予算がないことを弱みではなく前提として扱ってくれる人だと感じ、そこから頼みます。

見ていて差がつくのは、古参の社員の中に新しい人を入れる受け入れを、最初から設計しているかです。中小企業の人事の経験がある人は、長く働く社員の中に新しい人が入ると、教える人が決まらず、距離感がつかめず、浮いて辞めることを知っています。「入る前に、教える人を一人決めて、社長からその人に『頼む』と言ってもらい、最初の一か月は毎週その人と私で様子を聞く」という受け入れを、採用の前に決めた人は、新しい人が定着し、依頼側から「初めて新しい人が半年もった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「予算も人も少ない会社で、それでも採れる形を作る」と制約の言葉で書いている担当者に、同じ制約を持つ依頼側がついています。中小企業の人事の転身は、専門性を探すことではなく、制約の中で採ってきたことを専門性として語るところから始まります。

## 案件の探し方

中小企業の人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 予算と人が少ない会社の採用 | 同じ制約の中で採ってきた経験でそのまま入れる | 「採用の予算がほとんどない依頼側」を探す |
| 媒体に頼らない母集団の設計 | 地域と紹介と学校で作ってきた経験で入れる | 「媒体に出しても応募が来ない依頼側」を探す |
| 社長の「いい人」を要件に落とし、社員に納得させる | 社長と社員の間に立ってきた経験で入れる | 「社長と社員が噛み合わない依頼側」を探す |
| 古参の中に新しい人を入れる受け入れの設計 | 長く働く社員の中に人を入れてきた経験で入れる | 「新しい人が浮いて辞める依頼側」を探す |
| 一人の人事担当者の切り分けと段取り | 一人で兼ねてきた経験で入れる | 「人事が一人で溺れている依頼側」を探す |
| 内定の後から退職までの手続きの流れ | 一人で回してきた経験で入れる。判断は専門家に | 「手続きが抜けている依頼側」を探す |

探し方の要点は、「同じ制約を持つ会社」から入ることです。予算があり、人事の部門があり、媒体で応募が来る会社では、中小企業の型は必要とされません。予算が少なく、人事が一人か兼任で、媒体に出しても来ず、古参の社員がいる会社では、中小企業の型が唯一の打ち手になります。同じ地域の会社は、地域のつながりの経験がそのまま効くので、さらに入りやすいです。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。中小企業の人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 依頼側の予算の少なさ | 同じ制約を持つ依頼側は、副業の担当者に払う予算も少なく、単価が下がりやすい | 範囲を絞って小さく受け、成果が見えたら広げる。複数の依頼側を持つ |
| 母集団の設計の成果物 | 媒体に頼らない経路の設計は、成果物として形が明確 | 一式の成果物で受ける |
| 受け入れの設計の成果物 | 古参の中に入れる受け入れの手順は、成果物で受けやすい | 一式の成果物で受ける |
| 社長との壁打ち | 社長と社員の間に立つ役割は、回数で受けやすい | 月に何回・何分で決める |
| 媒体の費用の削減 | 無料の経路と紹介で採れれば、媒体の費用が減り、依頼側の支出に直接効く | 「媒体の費用が減った分」を成果として示せる形に |
| 法令の判断を含まないこと | 労務の手続きの判断を含まない範囲は責任が明確 | 「判断が要る点を見つけて専門家につなぐ」を範囲に明記する |
| 成果報酬の扱い | 採用の成否は社長の判断と社員の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「小さく受けて複数の依頼側を持ち、媒体の費用の削減で価値を示す」ことです。中小企業の人事の経験で受ける依頼側は、予算が少ないので、一つの依頼側から大きな月額を得る形は合いません。範囲を絞って小さく受け、成果が見えたら広げ、複数の依頼側を持つ形にします。無料の経路と紹介で採れれば媒体の費用が減るので、その分を価値として示すと、単価の話がしやすくなります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、掛け持ちの考え方は[複数案件を掛け持ちできるか](/media/fukugyo-fukusuu-anken/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

中小企業の人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、社員と社長の家族と取引先の情報の守秘の条件を確認する | 中小企業は社長との距離が近く、許可の取り方に配慮が要る。個別の判断は専門家に |
| 二、「予算と人が少ない中で、どう採って、どう辞めさせなかったか」を、会社の情報を含まない型として書き出す | 経路、社長との間、受け入れ、切り分け |
| 三、「何でも少しずつ」を「制約の中で採る専門性」に言い換える | 兼任を浅さではなく専門性として語る |
| 四、自社のやり方と、「会社ごとの事情を読む型」を分ける | やり方は捨て、読む型だけを持ち込む |
| 五、法令に関わる労務の判断を副業でしないと決め、「ここは専門家に」の線を自分の言葉で書く | 責任の線 |
| 六、範囲を、少ない予算の採用、母集団の設計、社長と社員の間、受け入れ、一人の切り分けに絞る | 労務の判断は範囲外 |
| 七、「予算も人も少ない会社で、それでも採れる形を作る」の一言を作る | 「中小企業の人事でした」で終わらせない |
| 八、登録先に、範囲と、同じ制約を持つ依頼側に向いていることと、地域を登録する | 予算と人が少ない依頼側 |
| 九、母集団の設計か受け入れの設計を一件受け、「媒体を使わずに採れた」形を残す | 次の依頼側に広げる材料に |

順番の要点は、「三」の言い換えと「一」の許可の取り方です。中小企業の人事の経験は、「何でも少しずつ」と語ると浅く聞こえ、「制約の中で採る専門性」と語ると、同じ制約を持つ依頼側に強く伝わります。本業の会社は社長との距離が近く、副業の許可を取る場面で、社長の受け止め方に配慮が要ることが多いので、規定の確認とあわせて、伝え方も考えておきます。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「中小企業の人事は専門性がなく、副業で売れるものがない」というものです。実際には、人事の副業の依頼側の多くは、予算と人が少ない会社で、大きい会社の仕組みもベンチャーの速さも通じません。そこで求められているのは、予算が少ない中で母集団を作り、社長と社員の間に立ち、古参の中に新しい人を入れて辞めさせない型で、それを持っているのは、同じ制約の中で人事をやってきた人だけです。専門性がないのではなく、「制約の中で採る」ことを専門性だと自分で認めていないだけです。

順番として、本業の規定と守秘の条件を専門家に確認し、制約の中で採った型を会社の情報を含まずに書き出し、兼任を専門性に言い換え、自社のやり方と事情を読む型を分け、労務の判断をしない線を書き、範囲を少ない予算の採用と母集団と社長との間と受け入れと切り分けに絞り、それでも採れる形を作る一言を作り、登録先に範囲と向いている依頼側と地域を登録し、一件受けて媒体を使わずに採れた形を残す。この順番で、中小企業の人事の経験は「専門性のないもの」から「同じ制約を持つ会社の打ち手」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、制約の中の工程を明確にし、労務の判断を含まないことを示している担当者に、予算と人が少ない依頼側がついています。中小企業の人事の転身は、専門性を探すことではなく、制約の中で採ってきたことを専門性として語るところから始まります。

## まとめ

- 中小企業の人事の経験は**「社長の会社で、人事と総務と労務を一人で兼ね、長く働く社員と地域の中で、限られた予算で採ってきた」型**で売れる。**少ない予算の採用・社長と社員の間・地域の母集団・兼任の切り分け**の四つ

- 売りにくい点は**専門性が薄いと見られる・自社のやり方に慣れすぎ・変化に弱いと見られる**。兼任を「制約の中で採る専門性」に言い換え、やり方ではなく事情を読む型を持ち込み、知らないものは認めて制約に合う打ち手で語る
- 案件は**同じ制約を持つ会社**から。同じ地域の会社はさらに入りやすい
- 単価は**小さく受けて複数の依頼側を持ち、媒体の費用の削減で価値を示す**。労務の判断は含まない。成果報酬は最初は避け、可否は専門家に確認
- 古参の中に新しい人を入れる受け入れは、**採用の前に設計する**

## よくある質問

### 本業の社長に、副業の許可をどう切り出せばよいですか

規定の確認が先で、そのうえで伝え方を考えます。中小企業では社長との距離が近く、「辞めるつもりか」「うちの仕事が手薄になるのでは」と受け止められやすいです。「本業の稼働は変えない」「同業や取引先の案件は受けない」「本業で得た情報は持ち込まない」を先に示し、副業で得た型を本業にも活かせることを添えると、受け止められやすくなります。規定で禁止されている場合や、判断に迷う場合は、社会保険労務士や弁護士にご確認ください。利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、時間の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に整理しています。

### 地元の学校や取引先とのつながりを、依頼側の採用に使ってよいですか

本業の会社の名前で作ったつながりは、本業の会社のものであり、守秘と利益相反の線に関わります。持ち込むのは「地域と学校と取引先で母集団を作る型」だけにし、依頼側のつながりは、依頼側の名前で新しく作ります。人を紹介する形で使うと、職業紹介の許可の線にも関わります。個別の判断は、弁護士や社会保険労務士にご確認ください。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

### 労務の手続きも一人でやっていました。副業でも労務を受けてよいですか

「手続きの一覧と流れ」を作ることと、「手続きの中身を判断する」ことを分けます。何をいつまでにやるか、抜けがないかの流れは、副業の担当者が示せます。中身の判断（法令との整合、条件の解釈）は責任を負えないので、社会保険労務士や弁護士に確認する形にし、その線を範囲に明記します。給与や社会保険の情報は個人情報の扱いが重く、アクセスの範囲と管理の方法を依頼側と書面で決める必要があります。個別の判断は、専門家にご確認ください。労務の経験の売り方は[労務担当が副業でできること](/media/fukugyo-roumu-tantou-fukugyo/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。
