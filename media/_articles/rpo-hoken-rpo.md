保険業界の会社と代理店（生命保険、損害保険、代理店、少額短期）が採用代行を検討するとき、動機は「営業職員の募集が止まらず、支社長や所長が採用に追われている」「代理店で社長が一人で採用していて手が回らない」「引受と査定の専門職が採れない」であることが多い。ただ、保険の採用は、他の業界と違う難しさがあります。型で求める人と経路が違い、募集に関わる職種は登録と資格が前提で、営業職員は数で採って数で離れる型が根強く、代理店は社長が一人で担い、内勤の専門職は市場が狭い。結論を先に書くと、**保険業界の採用代行は、母集団形成・一次対応・日程調整・書類の整理・記録は外に出せる一方、登録と資格の要件の決定・募集の表示の整理・商品と報酬の実態の判断・見極め・受け入れは社内に残さないと、採れても登録できず、登録できても数か月で離れます。**代行に出す前に、難しさを自社の状況で分解し、型と職種ごとに「任せる・残す」を決めることが、代行が機能する条件です。金融の型として共通する点（承認の段、中途の型）は[金融業界の採用代行](/media/rpo-kinyu-rpo/)に、営業の職種としての切り分けは[営業採用を代行に出す判断基準](/media/rpo-sales-rpo/)に書いています。ここでは、保険業界で特有の切り分けに絞ります。

## 保険業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 型で求める人と経路が違う | 生保の営業職員は対人と紹介、損保は代理店の営業と査定、代理店は地域と社長の人柄、少額短期は商品と速さ | 型ごとに求人票と経路を分ける必要がある |
| 登録と資格が前提で表示に法令上の整理 | 募集に関わる職種は登録と資格が要件で、募集の文面と報酬の表示に法令上の整理がある | 要件と表示の整理は会社と専門家。代行は照合と文面の確認まで |
| 数で採って数で離れる型 | 営業職員を数で採り、知人への提案から始め、数か月で離れる。受け入れが無いまま募集が止まらない | 母集団を増やしても往復。受け入れと実態を直さないと機能しない |
| 代理店は社長が一人で担う | 小規模で、社長が営業と採用と教育を担い、面接の枠が取れず、返事が遅れる | 一次対応を残すと流れる |
| 内勤の専門職は市場が狭い | 引受・査定・支払・数理・システムは同業と隣接からしか来ない | 要件の言い換えと経路の広げ方 |

五つのうち、代行で解決できるのは母集団形成と速さで、登録・表示・実態・受け入れは社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 登録と資格の要件の決定 | 残す | 会社と専門家。法令上の整理がある |
| 募集の文面と報酬の表示の整理 | 残す | 会社と専門家。法令上の整理がある。代行は整理された表示に沿って書く |
| 商品と報酬と稼働の実態の判断（求人票に何を書くか） | 残す | 支社長、所長、社長 |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の型で、〇〇の商品を、〇〇の顧客に担った経験」に。代行が整え、責任者が確認 |
| 母集団形成（隣接の対人の職種、同業、専門職に届く経路） | 任せられる | 型があれば外で回せる |
| 一次対応（返信・日程） | 任せられる | 支社長と所長と社長の負担を減らす |
| 書類の一次確認と整理 | 一部任せられる | 「登録・資格・型・経験」の照合と、登録に回す書類の整理は外で。判断は社内 |
| 見極め（面接、ロールプレイ） | 残す | 責任者。対人の型と数字への向き合い方 |
| 受け入れ（最初の三か月の目標、教える人、同行、知人への提案の扱い） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 型と職種をまたいで一つの一覧。登録までの日数を含む |

「募集の表示の整理」と「知人への提案の扱い」は、保険に特有の残す工程です。登録と資格と表示は、法令上の整理があると一般に整理されているため、会社と専門家が扱います。個別の判断は専門家にご確認ください。

### エラベルの見解

保険業界で多くの会社が見落とすのは、「数で採って数で離れる」型が採用の詰まりそのものになっていることです。営業職員を毎月数で採り、最初の三か月は知人への提案で数字を作り、知人が尽きると離れ、また数で採る。募集が止まらないのは市場の問題ではなく、型の問題です。ここで代行に「もっと母集団を」と頼むと、往復が速くなるだけです。代行に出す前に、「最初の三か月の目標を知人の数に依存しない形にする」「教える人と同行を決める」「商品と報酬の実態を先に出す」を会社が決める。エラベルで担当者を選ぶ企業には、「入社した営業職員は、最初の三か月に誰に提案し、誰が同行しましたか」を、私たちから先に聞いています。答えが「知人に、一人で」なら、代行の前に受け入れの設計です。営業の離職の分け方は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 型と職種と人数 | 生保・損保・代理店・少額短期のどの型で、営業職員・法人営業・代理店の営業・引受・査定・支払・事務・システムのどれを、何名 |
| 要件と登録 | 登録と資格と経験を「必須・入社後に登録・歓迎」に分けているか。会社と専門家で整理したか |
| 表示 | 募集の文面と報酬の表示が、会社と専門家で整理されているか |
| 実態 | 商品、報酬の型（固定と成果の比率）、目標、稼働、知人への提案の扱い、離職の状況を、責任者が語れるか |
| 枠 | 支社長・所長・社長の面接の枠を、週に一つ先に預けられるか |
| 受け入れ | 最初の三か月の目標、教える人、同行の型が決まっているか |
| 記録 | 型と職種をまたいで、登録までの日数を含む一覧があるか |

「実態を責任者が語れるか」と「表示が整理されているか」が要です。要件の言い換えは[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 型ごとに代行の型が違う

| 型 | 採用の特徴 | 代行に出しやすい工程 |
|---|---|---|
| 生命保険（営業職員） | 数で採る型。対人と紹介。受け入れが要 | 隣接の対人の職種に届く母集団形成、一次対応、受け入れの記録 |
| 損害保険 | 代理店の営業と査定と支払。専門職が中心 | 専門職に届く経路、要件の言い換え、記録 |
| 代理店 | 小規模。社長が一人で担う。地域と人柄 | 一次対応、日程、地域の経路の運用 |
| 少額短期 | 商品と速さ。事業会社に近い | 母集団形成、一次対応、速さ |

複数の型を持つ会社は、型ごとに代行の型が違うことを前提に、型ごとに「任せる・残す」を決めます。代理店の小規模の体制は[三十名規模の会社の採用体制の作り方](/media/rpo-jugyoin-30-taisei/)に書いています。

## 代行を選ぶときの確認項目

| 確認 | 見ること |
|---|---|
| 保険業界の経験 | 担当者が保険の職種の採用を担った経験があるか。型の違いを知っているか |
| 表示の扱い | 整理された表示に沿って文面を書く型を持っているか。整理の外に出る表現を勧めてこないか |
| 受け入れの理解 | 「数で採る」型の往復を知っていて、受け入れの記録を担えるか |
| 専門職への経路 | 引受・査定・支払・数理の同業と隣接に届く経路の運用をしたことがあるか |
| 一次対応の速さ | 翌営業日中に返す体制があるか |
| 費用 | 「工程・稼働時間・担当人数」をそろえて比べる。額の大小だけで決めない |

費用は、依頼する工程と稼働時間で大きく変わるため、同じ工程で比べる軸をそろえます。内訳の見方は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 時期 | 起きること | 社内の対応 |
|---|---|---|
| 最初の二週間 | 実態と要件と表示の聞き取り。型と職種ごとの求人票の作り直し | 責任者が実態を語る一時間。表示の整理を渡す |
| 一か月目 | 母集団形成と一次対応が回り、応募が増える | 枠を預ける。面接とロールプレイを同じ日に組む |
| 二か月目 | 書類の照合で登録の要件に合わない応募が減る。辞退の理由が見える | 辞退の理由が「報酬」「知人への提案」「稼働」なら実態か型の見直し |
| 三か月目 | 入社と登録。受け入れが始まる | 最初の三か月の目標、教える人、同行。離れたら理由を記録 |
| 半年 | 定着と数字が見える | 「数で採る」型を変える判断の材料に |

出したあとに「応募は増えたが数か月で離れる」となるなら、受け入れが無い印です。代行のせいにする前に、最初の三か月の型が一枚にあるかを確かめます。

### エラベルの見解

保険業界で見落とされやすいのは「知人への提案」の扱いです。営業職員の最初の数字を知人への提案で作る型は、候補者にとって重い負担で、面接で「最初は知り合いに売るのですか」と聞かれ、濁すと辞退され、答えて重ければ辞退されます。ここで直すのは文面ではなく、型そのものです。最初の三か月を「会社が用意した接点（既存の顧客、紹介の仕組み、法人の窓口）から始め、知人への提案は本人の判断」にすると、来る人の層が変わり、離れる理由が減ります。エラベルで担当者を選ぶ企業には、「最初の三か月の数字は、何から作る設計ですか」を、私たちから先に聞いています。答えが「知人から」なら、代行に出す前に、最初の接点の設計です。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## まとめ

- 保険業界の難しさは**型で違う・登録と資格と表示・数で採って数で離れる・代理店は社長が一人・専門職の狭さ**の五つ
- 外に出せるのは**母集団形成・一次対応・日程・書類の整理・記録**。残すのは**登録と資格の要件・表示の整理・実態の判断・見極め・受け入れ**
- **登録・資格・表示は会社と専門家**。個別の判断は専門家にご確認ください
- **「数で採る」型を変えずに母集団を増やすと往復が速くなるだけ**。受け入れが先
- 型ごとに**代行の型が違う**。代理店は一次対応から
- **知人への提案に依存しない最初の三か月**を設計する
- 費用は**同じ工程で比べる軸をそろえる**

## よくある質問

### 募集の文面に規制があるので、外部に求人票を書かせられません

表示の整理は会社と専門家で行い、代行は整理された表示の範囲で文面を書き、会社が確認してから出す、という分け方です。整理の外に出る表現（報酬の見込み、収入の例など）を代行が勧めてくることがあれば、それは選ばない理由になります。表示は法令上の整理があると一般に整理されているため、会社と専門家で整理し、個別の判断は専門家にご確認ください。整理が一枚にあれば、代行は求人票の作業を担えます。

### 代理店で、社長の人柄で採ってきました。代行で変わりますか

社長の人柄は面接と受け入れで発揮する部分で、代行と矛盾しません。変わるのは、社長の時間です。応募への返事と日程と書類の整理を外に出し、社長は面接と受け入れに絞る。返事が翌営業日中になるだけで、社長の人柄に会う前に流れていた候補者が面接まで来ます。地域の経路（知人、既存の顧客、地域の掲載型）の運用も、型があれば外に出せます。

### 引受と査定の専門職は、同業からしか採れないのではないですか

要件の言い換えで隣接から読めるようになります。「査定の経験者」を「〇〇の種類の事故や請求を、〇〇の件数で、〇〇の基準で判断した経験」に分解すると、共済、事業会社の債権や与信の管理、医療の事務からも読めます。経路は同業の掲載型だけでなく、専門の集まりと知人と紹介に広げる。それでも来ないなら、条件と裁量の判断に進みますが、それは要件と経路を直した後です。金融の専門職の言い換えは[金融業界の採用課題](/media/rpo-kinyu-kadai/)に書いています。
