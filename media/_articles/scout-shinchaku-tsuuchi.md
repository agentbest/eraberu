媒体に新しく登録した候補者、経歴を更新した候補者、活動を再開した候補者は、他社も見ている。登録の直後は媒体を見ている時間が長く、返信も来やすい。早く送りたい。しかし、急いで送ると文面が雑になり、要件に合っているかの判断も甘くなる。新着を毎日見る運用は、始めても続かない。結論を先に書くと、**新着への即時アプローチは、「早く送る」を目的にせず、「新着を見る時間を固定する」「その場で送るかを判断する基準を持つ」「一段落目だけ個別にする型を用意する」「送った後に後追いで確認する」の四つで、速さと質を両立させます。速さは、急ぐことではなく、決めておくことで出ます**。送信の時間帯の考え方は[送信する時間帯と曜日](/media/scout-soushin-jikantai/)に、転職の動きの見え方での順番は[母集団が広すぎるときの絞り方](/media/scout-boshuudan-hirosugi/)にまとめています。

## 即時が効かない構造

新着に早く送ろうとして、うまくいかないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「早く」が目的になっている | 速さのために文面と判断を削り、雑なスカウトが早く届くだけ |
| 見る時間が決まっていない | 「気づいたら見る」で、気づかない日が続く |
| その場で送るかの基準が無い | 新着を見ても「良さそう」で送るか、迷って送らないか |
| 個別化に時間がかかる | 通常の文面の型で書こうとして、一通に時間がかかり、新着の間に送れない |
| 後追いが無い | 急いで送った分、間違い（名前、経歴の取り違え）が起きるが、確認していない |
| 通知に振り回される | 媒体の通知が来るたびに手を止め、他の作業が進まない |
| 新着だけを追う | 新着に集中し、既存の候補者への送信と追客が止まる |

構造の大半は、「速さを、急ぐことで出そうとしている」ことです。速さは、見る時間と基準と型を決めておくことで出ます。

## 新着が動く理由

新着の候補者に早く送ることが効くのは、次の理由です。理由を知っておくと、何を急ぎ、何を急がなくてよいかが分かります。

| 理由 | 内容 | 含意 |
|---|---|---|
| 媒体を見ている時間が長い | 登録や更新の直後は、媒体を開く頻度が高い。届いた通知を読む | 届いてすぐ開かれるので、件名と一段落目の効きが大きい |
| 他社からの通数が少ない | 登録の直後は、まだ他社からのスカウトが溜まっていない | 埋もれない。ただし数日で溜まる |
| 意思が固まっていない | 登録の直後は、どの会社を見るかが決まっていない | 役割の見せ方で、比較の土俵に入れる |
| 経歴の更新は動きの表れ | 経歴を更新した人は、転職を考え始めた可能性がある | 更新の内容（新しい経験、新しい希望）に触れると、自分宛てと分かる |
| 活動の再開は再検討の表れ | 活動を止めていた人が再開したなら、前回と状況が変わっている | 過去に送った人なら、時間を空けた再送の型で。[時間を空けて再送するときの書き方](/media/scout-kikan-aketa/) |

理由の要点は、「効くのは数日」ということです。登録の日に送る必要はなく、数日以内であれば効きます。「当日中に」と急ぐより、「数日以内に、決めた時間に」で十分です。

## 見る時間の固定

新着を見る時間を、日々の運用に固定します。

| 項目 | 内容 |
|---|---|
| 頻度 | 毎営業日に一度。役割の数と新着の量で、二度にする場合も |
| 時間 | 送信の時間帯の前。見て、その場で送るかを判断し、送信の時間帯に送る |
| 所要 | 一度に十五〜三十分。長くなるなら、基準が緩いか、役割が多すぎる |
| 見る範囲 | 保存した検索の条件に合う新着だけ。全件の新着は見ない。[検索条件の保存と使い回し](/media/scout-kensaku-hozon/) |
| 担当 | 担当者。担当者が休みの日は、誰が見るか（見ない日を作らない） |
| 記録 | 見た日、新着の数、その場で送った数、保留した数 |

固定の要点は、「送信の時間帯の前に見る」ことです。見てから送るまでを、一つの流れにします。見る時間と送る時間が離れると、「見たが送っていない」新着が溜まります。

## その場で送るかの基準

新着を見て、その場で送るか、保留にするか、送らないかを決める基準です。迷わないために、三つに分けます。

| 判断 | 基準 | 動き |
|---|---|---|
| その場で送る | 保存した検索の「外せない一つ」を満たし、「経歴の特徴」に近く、送ってはいけない相手ではない | 一段落目だけ個別の型で、その日の送信の時間帯に送る |
| 保留にする | 外せない一つは満たすが、経歴の特徴から遠い。または、要件との照合に時間が要る | 保留の一覧に入れ、週次の送信で通常の型で送る。数日以内 |
| 送らない | 外せない一つを満たさない。送ってはいけない相手。活動の状態が新着に見えるだけで、実際は動いていない | 記録に「見たが送らない」と理由を残す |

基準の要点は、「その場で送る」の条件を狭くすることです。「良さそう」で全部その場で送ると、雑になります。外せない一つと経歴の特徴に近い人だけをその場で送り、残りは保留で数日以内。速さが効く相手に、速さを使います。絞りと順番の基準は[母集団が広すぎるときの絞り方](/media/scout-boshuudan-hirosugi/)に書いています。

## 速さのための文面の型

新着にその場で送るための、文面の型です。通常の型より、個別にする部分を絞ります。

| 要素 | 新着向けの型 |
|---|---|
| 件名 | 役割ごとの型をそのまま。変えない |
| 一段落目 | ここだけ個別に。新着なら「ご登録を拝見し」、更新なら「〇〇のご経験を新たに拝見し」と、新着や更新の事実と、経歴の一点に触れる。二〜三文 |
| 役割の説明 | 役割ごとの型をそのまま |
| 会社の説明 | 型をそのまま |
| 次の一歩 | 型をそのまま。新着には「まずはお話だけでも」と軽く |
| 長さ | 通常より短く。新着は他社からの通数が少ない分、長さで競う必要が無い |
| 確認 | 送る前に、名前と、一段落目の経歴の一点が、その人のものかを一度だけ見る |

型の要点は、「一段落目だけ個別に、あとは型」です。一段落目に二〜三分、確認に一分。一通五分以内で送れます。個別化の範囲の考え方は[パーソナライズはどこまでやるべきか](/media/scout-personalize/)に書いています。

### エラベルの見解

相談で最も多い失敗は、「新着に当日中に送ることを目標にし、担当者が通知のたびに手を止めて送っていたら、名前の取り違えと、経歴の一点の誤りが月に何件も起き、候補者から『別の人宛てでは』と返信が来た」というものです。速さを急ぐことで出そうとして、確認が抜けていました。見る時間を一日一度に固定し、その場で送る基準を狭くし、一段落目だけ個別の型にし、送る前に名前と一点を見る、に変えたら、送るまでの日数は一〜二日で変わらず、誤りはゼロになりました。速さは、急ぐことではなく、決めておくことで出ました。

見ていて差がつくのは、担当者が「新着だけを追わない」かです。新着の通知に反応して、既存の候補者への送信と追客が止まる担当者と、「新着は朝の三十分、それ以外の時間は通常の送信と追客」と分ける担当者がいます。後者は、新着も既存も止まりません。

発注側にできるのは、「新着には当日中に」ではなく、「新着は数日以内に、決めた時間に」を担当者と合意することです。

## 後追いの確認

速く送った分、後から確認することを決めておきます。

| 項目 | 内容 |
|---|---|
| 送った翌日 | その場で送った分の、名前と一段落目の一点を、もう一度見る。誤りがあれば、短く訂正の一通 |
| 一週間後 | 新着への送信の返信率を、通常の送信と分けて見る。新着の層として送信ログに記録 |
| 保留の消化 | 保留の一覧が、数日以内に通常の型で送られているか |
| 送らなかった分 | 「見たが送らない」の理由が、基準と合っているか。基準が厳しすぎないか |
| 月に一度 | 新着の層の返信率と面談率を、通常の層と比べる。新着への即時が効いているか。効いていなければ、見る頻度を下げる |

確認の要点は、「新着の層を分けて記録する」ことです。新着への即時が効いているかは、分けて見ないと分かりません。効いていれば続け、効いていなければ、見る頻度を下げて通常の運用に戻します。検証の単位は[どの単位で効果を検証するか](/media/scout-kensho-tan-i/)に書いています。

## 媒体の通知機能との関係

媒体には、保存した条件に合う新着を通知する機能があることが多い。使い方です。

| 項目 | 内容 |
|---|---|
| 通知の設定 | 保存した検索の条件で設定する。全件の新着を通知にすると、見きれない。仕様は公式の案内で確認 |
| 通知への反応 | 通知が来るたびに手を止めない。決めた時間にまとめて見る |
| 通知の受け先 | 担当者の受け先に。担当者が休みの日の受け先も決める |
| 通知の精度 | 通知は媒体の判定で、自社の基準ではない。通知が来た人も、その場で送るかの基準で判断する |
| 通知が無い媒体 | 決めた時間に、保存した検索で「更新の新しい順」に並べて見る。仕様は公式の案内で確認 |
| 通知の記録 | 通知の数と、その場で送った数の比を見る。比が低ければ、通知の条件を狭める |

関係の要点は、「通知に振り回されない」ことです。通知は「新着があった」を知らせる道具で、「今すぐ送れ」ではありません。決めた時間に、まとめて見て、基準で判断します。

## 外注する場合の範囲

新着への即時アプローチを、スカウト代行に出す場合の範囲です。

**出せる工程。** 新着を見る時間の設計と実施、保存した検索の条件での新着の確認、その場で送るかの基準の作成（絞りと順番の基準から）と判断、新着向けの文面の型の作成、一段落目の個別化と送る前の確認、保留の一覧の管理と数日以内の消化、送った翌日の確認と訂正、新着の層での記録、週次と月次の比較、媒体の通知の設定と受け先の管理、担当者が休みの日の代替。

**社内に残す判断。** 「その場で送る」の基準の承認（外せない一つと経歴の特徴）、新着への即時を続けるか戻すかの判断（月次の比較から）、社内の人が新着に直接送る場合の運用（表に書く、基準に従う）。

**外注の効きどころ。** 新着への即時は、「毎営業日に、決めた時間に、基準で判断し、型で送り、後追いで確認する」運用で、社内では「気づいたら見る」で続かないか、「通知のたびに送る」で雑になる工程です。担当者が見る時間を固定し、基準を持ち、型で送り、翌日に確認すれば、速さと質が両立します。担当者は複数の会社で新着への対応を見ているので、「この媒体の新着はこの時間に見ると効く」「この役割は新着の効きが大きい」を持ち込めます。ただし、基準の元になる要件と、続けるか戻すかの判断は、社内でしか決められません。

**外注しても動かない場合。** 「新着には当日中に、全員に」と速さと量を同時に求める、基準を承認せず「良さそうな人に」と言う、月次の比較を見ずに即時を続けさせる、社内の人が新着に直接送って表に書かない。社内の判断で、代行を替えても直りません。

新着への即時アプローチは、見る時間と基準と型と後追いを決めておけば、急がなくても速く、雑にならずに送れます。外注は、固定した時間での確認と判断と型での送信と後追いを担う手段です。

### エラベルの見解

担当する側から見ると、新着の相談で最も多いのは、「新着への即時が、自社で効いているかを見ていない」ことです。「新着には早く」は一般に言われることで、多くの会社が取り入れます。ただ、役割と媒体と層によって、効き方は違います。新着の層を分けて記録し、通常の層と比べると、「新着の返信率は高いが面談に至らない」「新着と通常で差が無い」という会社も、実際にあります。

差が無ければ、新着を毎日見る運用はやめて、週次の送信に戻してよい。差があれば続ける。判断の材料は、分けた記録だけです。

発注側にできるのは、月に一度、「新着の層と通常の層で、返信率と面談率はどう違いますか」と担当者に聞くことです。

- 動く理由は**見ている時間が長い・他社の通数が少ない・意思が固まっていない・更新は動きの表れ・再開は再検討の表れ**。効くのは数日

- 基準は**その場で送る（外せない一つと特徴に近い）・保留（数日以内に通常の型）・送らない（理由を記録）**。その場で送るを狭く
- 型は**一段落目だけ個別・あとは型・短く・送る前に名前と一点を確認**。一通五分以内

## よくある質問

### 新着には、登録の当日中に送るべきですか

当日である必要はありません。効くのは数日で、当日と翌日と翌々日で大きな差は出にくい。当日を目標にすると、通知のたびに手が止まり、確認が抜けます。「毎営業日の決めた時間に見て、その日の送信の時間帯に送る」なら、新着から一〜二日で届き、確認も抜けません。登録の直後に媒体を見ている時間が長いのは事実ですが、数日は続きます。媒体ごとの新着の表示や通知の仕様は、公式の案内で確認してください。

### 新着が多すぎて、決めた時間で見きれません

保存した検索の条件が広すぎます。新着は「外せない一つ」で絞った条件で見ます。それでも多いなら、役割の優先順位で、今週送る役割の新着だけを見ます。全役割の全新着を見る必要はありません。見きれない量を見ようとして、見ない日ができるより、絞って毎日見るほうが効きます。役割の優先順位は[複数職種があるときの優先順位](/media/scout-shokushu-yuusen/)に書いています。

### 経歴を更新した人と、新規に登録した人で、送り方は変えますか

一段落目を変えます。新規の登録なら「ご登録を拝見し」と登録の事実に、更新なら「〇〇のご経験を新たに拝見し」と更新の内容に触れます。更新の内容に触れると、「自分の更新を見て送ってきた」と分かり、自分宛てだと伝わります。過去に送ったことがある人が更新した場合は、新着ではなく、時間を空けた再送として扱い、前回に一言触れます。送信ログで過去の送信を照合してから送ります。
