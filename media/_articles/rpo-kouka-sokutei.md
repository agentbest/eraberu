この半年で、求人票を直し、媒体を一つ足し、面接の回数を減らし、返信を速くした。応募は少し増えた気がするが、何が効いたのかが分からない。効いたものを続け、効かなかったものを止めたいが、区別できない。次に何をすればよいかも、決められない。結論を先に書くと、**施策の効果が測れないのは、「複数を同時に変えて、全部を測ろうとしている」からです。同時に変えれば、何が効いたかは分かりません。「一つ変えて、一つの数字を見て、記録する」の型を作れば、測れます。測る仕組みは、大きな道具ではなく、この型と、一枚の記録です**。数字の取り方は[採用の数字が取れていない](/media/rpo-data-nai/)に、KPIの置き方は[採用KPIに何を置くべきか](/media/rpo-kpi-erabenai/)にまとめています。

## 効果が測れない構造

施策の効果が測れないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 複数を同時に変えている | 求人票と媒体と面接を同じ月に変えた。応募が増えても、どれが効いたか分からない |
| 「変える前」の数字が無い | 変えた後の数字だけあり、比べる元が無い |
| 見る数字を決めていない | 「効いたか」を、何で見るかが無い。応募か、面接か、内定か、日数か |
| 記録が無い | 「いつ、何を変えたか」が記録に無く、後から思い出せない |
| 期間が短い | 変えて一週間で「効かない」と判断する。一か月の変動は大きい |
| 「全部を測ろう」として始まらない | 「効果測定の仕組み」を大きく設計しようとして、着手できない |
| 施策と数字が、対応していない | 求人票を直したのに、内定の数で見ている。求人票が効くのは応募と書類の段階 |
| 測れない施策を、測ろうとしている | 「採用サイトを作った」「SNSを始めた」の効果は、短期の数字には出にくい |

構造の大半は、「同時に変える」と「記録が無い」の二つです。この二つを直せば、測れます。

## 測る前に決めること

測る前に、三つを決めます。

**一、何を変えるか（一つ）。** 「今月は、求人票の一行目を変える」。一つだけ。複数を変えたくなっても、順番に。

**二、何の数字で見るか（一つ）。** 変える施策に対応する数字。求人票なら「応募の数と書類通過率」、返信の速さなら「応募から面接までの辞退の数」、面接の観点なら「面接の通過率と入社後の到達」。施策と数字の対応は次の章。

**三、いつまで見るか。** 「一か月」「三か月」。施策によって、効果が出る期間が違う。求人票は一か月で応募に出るが、SNSは半年以上かかる。

三つが決まれば、「変える前の数字を記録→変える→期間の後に数字を見る→記録する」で、測れます。

「全部を測る仕組み」は要りません。三つを決めて、一枚に記録するだけです。

## 「一つ変えて一つ見る」の型

型は、五つの手順です。

| 手順 | やること |
|---|---|
| 一、変える前の数字を記録する | 見る数字の、直近一〜三か月の値。「応募が月に二十件、書類通過が三件」 |
| 二、一つだけ変える | 「求人票の一行目を、役割と裁量に変えた」。日付を記録 |
| 三、他は変えない | 期間の間、媒体も、返信の速さも、面接も、変えない。変えたくなったら、次の期間に |
| 四、期間の後に、同じ数字を見る | 「応募が月に三十件、書類通過が六件」 |
| 五、記録して、判断する | 「効いた→続ける」「効かなかった→戻すか、別の変え方」「分からない→もう一期間見る」 |

型の要点は、「三、他は変えない」です。ここが守れないと、何が効いたか分かりません。「同時に三つ変えたい」なら、三か月かけて一つずつ。急がば回れです。

急ぎで複数を変えざるを得ない場合（急な増員など）は、「効果は測れない」と割り切り、測ることより採ることを優先します。落ち着いてから、一つずつ測ります。

## 施策ごとの見る数字

施策と、見る数字の対応です。対応していない数字で見ると、効いていても見えません。

| 施策 | 見る数字 | 効果が出る期間の目安 |
|---|---|---|
| 求人票の書き直し（一行目、役割、要件） | 応募の数、書類通過率、応募者の要件との合い | 一か月 |
| 媒体を足す・変える | その経路からの応募と面接に進んだ数、面接一件あたりの費用 | 一〜三か月 |
| 返信の速さ（当日に） | 応募から面接までの辞退の数、応募から面接までの日数 | 一か月 |
| 面接の日程の枠を先に押さえる | 応募から面接までの日数、面接前の辞退 | 一か月 |
| 面接の観点と質問の一枚 | 面接の通過率、面接官間の判定の一致、入社後三か月の到達 | 一〜六か月 |
| 内定の判断の速さ | 最終から内定までの日数、内定後の辞退 | 一か月 |
| 年収のすり合わせを早く | 内定後の辞退（条件を理由とするもの） | 一〜三か月 |
| 受け入れの型（最初の三か月） | 入社三か月の在籍、三か月の到達点 | 三〜六か月 |
| 社員の紹介の頼み方 | 紹介の数、紹介からの面接と入社 | 一〜三か月 |
| 採用サイト、SNS、記事 | 面接での「見た」の数、候補者の質問の変化、辞退の理由の変化 | 三か月〜一年 |
| 紹介会社への説明のやり直し | 推薦の数、推薦からの面接に進む率 | 一〜三か月 |
| カジュアル面談の導入 | 面談から応募に進む率、応募の手前で離れる人の変化 | 一〜三か月 |

対応の要点は、「施策が効く段階の数字で見る」ことです。求人票を直して「内定の数」で見ると、内定は面接や条件にも左右されるので、効いていても見えません。

## 記録の一枚

施策の記録を、一枚にします。

| 列 | 内容 |
|---|---|
| 日付 | 変えた日 |
| 施策 | 何を変えたか。具体的に。「求人票の一行目を『〇〇を自分で決める役割』に」 |
| 見る数字 | 対応する数字。「応募の数、書類通過率」 |
| 変える前 | 直近一〜三か月の値 |
| 期間 | いつまで見るか |
| 変えた後 | 期間の後の値 |
| 判断 | 効いた／効かなかった／分からない |
| 次 | 続ける／戻す／別の変え方／もう一期間 |
| 備考 | 期間中に起きた他の変化（繁忙期、市場の変化など） |

一枚の要点は、「変える前」を記録することです。変えた後だけでは、比べられません。

一枚は、月に一度、責任者と見ます。「今月変えたこと」「先月変えたことの結果」「来月変えること」。この場が、施策の効果を判断の材料に変えます。

半年溜まれば、「自社で効いた施策の一覧」ができます。次の求人で、効いたことから始められます。

### エラベルの見解

相談で最も多い失敗は、「半年で十の施策を同時に打ち、応募は増えたが、何が効いたか分からず、翌年に全部をもう一度やろうとして、人事が疲弊した」というものです。同時に変え、記録が無かった。「一つ変えて一つ見る」に変え、月に一つ、一枚に記録したら、半年で「効いた三つ」と「効かなかった三つ」が分かり、翌年は効いた三つに集中できました。十を同時に打つより、一つずつのほうが、結果として早く改善しました。

見ていて差がつくのは、担当者が「一つずつ」を提案するかどうかです。「全部やりましょう」と言う担当者と、「今月は求人票の一行目だけ変えて、応募と書類通過率を見ましょう。来月に返信の速さ。同時に変えると、何が効いたか分からなくなります」と、順番を作る担当者がいます。後者は、半年後に「効いたこと」を持っています。

発注側にできるのは、「全部やって」ではなく、「一つずつ、記録して」と担当者に依頼することです。

## 測れない施策の扱い

施策の中には、短期の数字では測れないものがあります。扱いです。

**採用サイト、SNS、記事、採用広報。** 効果は、面接での「見た」、候補者の質問の変化、辞退の理由の変化、で見ます。数字ではなく、面接での一言。三か月から一年の単位で。

**知名度を作る取り組み。** 年単位。短期の数字で判断しない。「続いているか」が最初の指標。

**大学や紹介会社との関係。** 年単位。「関係ができたか」を、接点の数と質で。

**受け入れと育成。** 入社三か月・半年・一年の在籍と到達で。採用の数字ではなく、定着の数字。

**測れない施策は、「測れない」と決めて続けるか止めるかを判断する。** 「測れないからやらない」でも「測れないから漫然と続ける」でもなく、「この施策は年単位で、この兆候（面接での『見た』など）で見る」と決める。

**測れない施策に、測れる施策の判断を混ぜない。** 「SNSを始めた月に応募が増えた」は、SNSの効果とは限らない。同じ月に変えた別の施策か、市場の変化か。

測れない施策の要点は、「兆候で見る」ことと「年単位で見る」ことです。短期の数字で判断すると、効いているのに止めます。

## 測る運用

効果を測る運用を、続けます。

**月に一度、一枚を見る場。** 責任者と人事（または担当者）で、三十分。「今月変えたこと」「先月の結果」「来月変えること」。

**月に一つ、変える。** 急ぎでなければ、月に一つ。三か月で三つ。半年で六つ。

**変える前に、数字を記録する。** 「変えてから記録しよう」では、変える前が無い。

**期間中は、他を変えない。** 変えたくなったら、次の月に。

**結果を、記録する。** 効いた、効かなかった、分からない。分からないは、もう一期間。

**効いた施策を、型にする。** 「求人票の一行目を役割と裁量にすると、書類通過率が上がる」が分かったら、次の求人票にも。

**効かなかった施策を、記録として残す。** 「〇〇は効かなかった」も、次に同じことを繰り返さないための材料。

**年に一度、一枚を振り返る。** 「この一年で効いたこと、効かなかったこと」。翌年の計画の元。

運用の要点は、「月に一度の場」と「月に一つ」です。場が無ければ記録は見られず、一つでなければ測れません。

## 外注する場合の範囲

施策の効果を測る仕組みが無い問題を、採用代行に出す場合の範囲です。

**出せる工程。** 「一つ変えて一つ見る」の型の設計、施策と見る数字の対応の整理、変える前の数字の記録（応募者の表からの集計）、施策の順番の案（何から変えるか）、一枚の作成と毎月の更新、月に一度の場の準備と進行、変えた後の数字の集計と判断の材料、効いた施策の型への反映、測れない施策の兆候の記録（面接での「見た」、質問の変化、辞退の理由）、年に一度の振り返りの一枚。

**社内に残す判断。** 何を変えるかの決定、変える順番の決定、効いた・効かなかったの判断、続ける・戻すの決定、測れない施策を続けるかどうかの判断。

**外注の効きどころ。** 効果測定は、「記録する人」と「一つずつを守らせる人」がいれば回ります。担当者が一枚を作り、変える前の数字を記録し、月に一度の場を回し、「今月は一つだけ」を守らせれば、社内は「何を変えるか」と「判断」に集中できます。担当者は複数の会社の施策の効き方を見ているので、「この詰まりなら、この施策から」の順番の見立てを持ち込めます。ただし、他社で効いた施策が自社で効くとは限らず、自社の記録で判断します。

**外注しても動かない場合。** 責任者が「全部同時に」を譲らない、月に一度の場に出ない、変える前の数字を記録させない。社内の判断で、代行を替えても直りません。

効果は、一つずつ変えて記録すれば、測れます。外注は、型と記録と場を持ち込む手段です。

### エラベルの見解

担当する側から見ると、効果測定の相談で最も多いのは、「効果測定の仕組み」を大きく設計しようとして、始まらないことです。「採用のダッシュボードを作る」「全施策を計測する」。設計に数か月かかり、その間、施策は同時に打たれ、何も測れない。

要るのは、「一つ変えて、一つ見て、一枚に記録する」だけです。今日、求人票の一行目を変えて、応募の数を記録し、一か月後に見る。それが、効果測定の全部です。大きな仕組みは、要りません。

発注側にできるのは、「効果測定の仕組みを作ろう」ではなく、「今月、一つ変えて、一つ見よう」と決めることです。

## まとめ

- 測れないのは**同時に変える・変える前の数字が無い・見る数字が無い・記録が無い・期間が短い・全部を測ろうとして始まらない・施策と数字が対応していない・測れない施策を測ろうとする**構造
- 測る前に**何を変えるか（一つ）・何の数字で見るか（一つ）・いつまで見るか**を決める。大きな仕組みは要らない
- 型は**変える前を記録→一つだけ変える→他は変えない→期間の後に同じ数字を見る→記録して判断**。「他は変えない」が要点
- 施策と数字は**求人票は応募と書類通過・媒体はその経路の面接・速さは辞退と日数・面接の一枚は通過率と入社後・内定の速さは内定後の辞退・受け入れは在籍・広報は面接での「見た」**で対応させる
- 一枚は**日付・施策・見る数字・変える前・期間・変えた後・判断・次・備考**。月に一度、責任者と見る
- 測れない施策は**兆候で・年単位で・測れないと決めて続けるか止めるか・測れる施策の判断を混ぜない**
- 運用は**月に一度の場・月に一つ・変える前に記録・期間中は他を変えない・結果を記録・効いたものを型に・効かなかったものも残す・年に一度振り返る**
- 外注できるのは**型・対応の整理・記録・順番の案・一枚と更新・場の進行・集計と材料・型への反映・兆候の記録・振り返り**。社内に残るのは**何を変えるか・順番・判断・続けるか戻すか・測れない施策の判断**

## よくある質問

### 施策を一つずつ変えていたら、時間がかかりすぎませんか

同時に変えて何が効いたか分からず、翌年に全部をやり直すほうが、時間がかかります。月に一つ、半年で六つの施策を測れば、「効いた三つ」に翌年から集中できます。急ぎで複数を変えざるを得ない場合（急な増員など）は、「測れない」と割り切って採ることを優先し、落ち着いてから一つずつ測ります。詰まりの段階（[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)）から、効きそうな順に一つずつ変えれば、時間は無駄になりません。

### 変える前の数字を、記録していませんでした

今日から記録します。応募者の表があれば、直近一〜三か月の数字は遡って集計できます。無ければ、今月を「変える前」として記録し、来月から変えます。「変える前が無いから測れない」で止まるより、「今月から記録して、来月から一つずつ」で始めます。表の作り方は[応募者管理がスプレッドシートのまま](/media/rpo-ats-nai/)に書いています。

### 採用サイトやSNSの効果が、数字に出ません

短期の数字には出にくい施策です。効果は、面接の最初に「当社のサイトやSNSをご覧になりましたか」と聞いて記録する「見た」の数、候補者の質問の変化（「働き方は」が減ったか）、辞退の理由の変化（「思っていたのと違う」が減ったか）で見ます。三か月から一年の単位で。「応募が増えたか」で判断すると、効いているのに止めてしまいます。「測れない」と決めて、兆候で見て、続けるかどうかを年単位で判断します。
