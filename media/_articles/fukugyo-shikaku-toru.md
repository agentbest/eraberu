人事の副業を始めるにあたって、何か資格を取っておいたほうがよいのか。資格があれば案件が来やすくなるのか、単価が上がるのか。取るなら、どれがよいのか。結論を先に書くと、**人事の副業で、資格は「案件を取る条件」にはなりません。依頼側の担当者が見ているのは、担当できる範囲と、範囲の中で動いた経験で、資格の有無で選ぶ場面はほとんどありません。資格が役に立つのは、「範囲の言葉を裏付ける材料」としてと、「法令に関わる場面で、自分の範囲の外だと線を引く判断力」としての二つです。**取るなら、「自分の範囲のどこを裏付けたいか」を先に決め、その範囲に合う資格を選びます。範囲が決まっていない段階で資格から入ると、範囲と関係の無い資格を持つことになります。範囲の決め方は[受ける範囲の決め方](/media/fukugyo-scope/)に、経歴の書き方は[プロフィールの書き方](/media/fukugyo-profile/)に、法令に関わる線は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)にまとめています。資格の要件、試験の内容、費用は変わるので、公式の情報でご確認ください。

## 資格が案件に直接効かない理由

依頼側が担当者を選ぶとき、資格が判断に入らない理由を、依頼側の側から見ます。

| 依頼側が見ているもの | なぜ資格より優先されるか |
|---|---|
| 担当できる範囲が一言で言えるか | 依頼側は「何を頼めるか」を知りたい。資格の名前からは、何を頼めるかが分からない |
| 範囲の中で動いた経験 | 「スカウトの運用を〇年、型に沿って正確に回した」は、資格より依頼側の頼みたいことに近い |
| 依頼側の仕組みの中で動けるか | 情報の扱い、記録の残し方、判断の所在を守れるか。資格では測れない |
| 稼働の条件が合うか | 時間帯、頻度、対面の可否。資格と無関係 |
| 成果を状態で見せられるか | 報告の形。資格と無関係 |
| 面談での受け答え | 経歴と話す内容が合っているか。資格は話の材料になることはあるが、判断の中心ではない |

効かない理由の要点は、「依頼側の頼みたいことと、資格が示すことが、ずれている」ことです。依頼側は「日程調整を任せて回るか」「文面を書けるか」を知りたく、資格は「制度の知識がある」「試験に通った」を示します。二つは別のもので、資格があっても頼めることは分からず、無くても頼めることは分かります。依頼側が見ている軸は[評価される副業人材の共通点](/media/fukugyo-hyouka-sareru/)に書いています。

## 役に立つ二つの形

資格が役に立つ場面は、二つに絞られます。この二つを目的に取るなら、意味があります。

| 形 | 内容 | 例 |
|---|---|---|
| 一、範囲の言葉を裏付ける材料 | 範囲の一言に書いた工程について、「その領域の体系的な知識がある」と示す。経験の年数が浅いときに、経験を補う | 「労務に関わる相談を受ける範囲」と書くなら、労務の資格が範囲の裏付けになる。「採用の設計」と書くなら、採用や人事の体系的な資格が補う |
| 二、法令に関わる場面で線を引く判断力 | 採用の工程で、法令に触れる可能性のある場面（求人の表現、選考の質問、条件の提示、個人情報の扱い）に気づき、「ここは専門家に」と線を引ける | 資格の勉強で法令の骨格を知っていれば、依頼側から法令に関わる相談が来たとき、断定せずに「一般に〜と整理されていますが、専門家にご確認ください」と言える |

二つの要点は、「二」の判断力が、実務では「一」の裏付けより効くことです。副業の担当者は、法令の解釈を断定してはいけませんが、法令に触れる場面に気づかないと、気づかずに越えます。資格の勉強で法令の骨格を知っていれば、「これは法令に関わるから、自分の範囲の外で、専門家に」と線を引けます。線を引く力は、資格の名前ではなく、勉強の中身から来ます。法令に関わる線は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)と[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「資格を取れば、案件が来やすくなり、単価も上がる」というものです。実際には、登録の相談で資格の有無を聞かれることは少なく、依頼側が担当者を選ぶ場面で、資格が決め手になった例も、見ている限りほとんどありません。依頼側が聞くのは「何を頼めるか」「どのくらい経験があるか」で、資格はその答えにはなりません。単価も、工程の帯で決まり、資格では動きません。

見ていて差がつくのは、資格を「取ってから範囲を決める」か「範囲を決めてから、要れば取る」かです。後者の人は、自分の範囲の中で、経験が浅い部分や、法令に関わる部分を裏付けるために資格を取り、範囲の一言と資格が対応しています。前者の人は、範囲と関係の無い資格を持ち、経歴に書いても依頼側は「で、何を頼めるのか」となります。エラベルでは、登録の際に資格の有無を条件にしておらず、範囲の一言と工程の経験で依頼側に提示しています。資格は、範囲の裏付けとして書けば材料になり、範囲より先に置けば材料になりません。

## 範囲ごとに裏付けになる資格の種類

自分の範囲に応じて、裏付けになる資格の種類を、種類の単位で整理します。特定の資格の要件や内容は、公式の情報で確認します。

| 範囲 | 裏付けになる資格の種類 | なぜ裏付けになるか | 注意 |
|---|---|---|---|
| 採用の運用（スカウト、求人票、日程調整） | 特に要らない。経験と型が裏付け | 実務の経験が最も伝わる。資格が無くても範囲は書ける | 資格を探すより、型と実績を整える |
| 採用の設計（要件、選考の流れ、KPI） | 人事や採用の体系的な知識を示す民間の資格 | 設計の経験が浅いとき、体系を知っていることの補い | 実務の設計の経験のほうが強い。補いとして |
| 労務に関わる相談を受ける範囲 | 労務や社会保険の国家資格 | 労務の相談は法令に直結し、資格が無いと受けられない業務がある。資格があっても、副業の範囲で受けてよいかは別に確認 | 資格が無いなら、労務の相談は範囲に入れない。専門家につなぐ |
| 候補者のキャリアの相談、面談 | キャリアの相談に関わる国家資格や民間の資格 | 面談の型と倫理を体系的に学んでいることの補い | 面談の経験が浅いときの補い。経験があれば必須ではない |
| 個人情報の扱い | 情報の扱いに関わる民間の資格 | 依頼側の情報管理の確認で、扱いの知識を示せる | 資格より、実際の扱い（端末の分離、置き場）を整えていることが先 |
| 英語での対応 | 英語の試験 | 工程の経験と一緒に書けば、読む・書く力の目安になる | 点数だけでは、どの工程でできるかは伝わらない。[英語は必要か](/media/fukugyo-eigo/) |

種類の要点は、「採用の運用の範囲では、資格は要らない」ことです。人事の副業の多くは採用の運用で、そこで依頼側が見るのは経験と型です。資格が裏付けになるのは、設計、労務、キャリアの相談、情報の扱いのように、体系的な知識や法令が関わる範囲で、しかも「補い」としてです。労務の相談は、資格が無いと受けられない業務があるので、範囲に入れる前に、資格の有無と、副業で受けてよいかを、公式の情報と専門家で確認します。

## 資格が要る業務と要らない業務の線

副業の範囲に入れる業務のうち、資格が要るものと要らないものを分けます。要るものは、資格が無ければ範囲に入れません。

| 業務 | 資格 | 扱い |
|---|---|---|
| スカウト、求人票、日程調整、候補者対応、記録、報告 | 要らない | 経験と型で範囲に入れる |
| 採用の設計、KPI、型づくり | 要らない | 経験で範囲に入れる。資格は補い |
| 面接の準備、面接官への資料 | 要らない | 経験で |
| 労務の相談（就業規則、給与、保険、労働時間） | 資格が無いと受けられない業務があるとされている | 資格が無いなら範囲に入れない。あっても、副業で受けてよいかを確認。専門家につなぐのが基本 |
| 法令の解釈（求人の表現、選考の質問、条件の提示、個人情報） | 解釈は専門家の領域 | 資格の有無に関わらず、断定しない。気づいて線を引くところまで |
| 候補者のキャリアの相談 | 資格が要る形と要らない形がある | 依頼側の採用の一部としての面談なら、資格は必須ではない。相談そのものを業務にするなら確認 |
| 有料の職業紹介に当たる業務 | 許可が要るとされている | 副業の担当者が個人で行うものではない。依頼側の採用の代行の範囲に留める。判断は専門家に |

線の要点は、「労務の相談と職業紹介に当たる業務は、資格や許可の問題で、範囲に入れる前に確認する」ことです。人事の経験があると、依頼側から労務の相談や、候補者の紹介のような依頼が来ることがありますが、それは資格や許可が関わる領域で、副業の担当者が自分の判断で受けるものではありません。「その範囲は資格や許可が関わるので、専門家にご確認ください」と線を引きます。線の引き方は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)に、断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に書いています。資格や許可の要否の判断は、専門家にご確認ください。

## 取るかどうかの決め方

資格を取るかどうかは、範囲を起点に決めます。取らない判断も、十分にあります。

| 手順 | 内容 |
|---|---|
| 一、範囲の一言を決める | 資格より先に、自分の範囲を工程で決める |
| 二、範囲の中で、裏付けが弱い部分を見る | 経験が浅い工程、法令に関わる工程、体系的な知識が要る工程があるか |
| 三、その部分を裏付ける資格の種類を見る | 上の表で、範囲に対応する種類 |
| 四、資格の要件と内容と費用と時間を、公式の情報で確認する | 副業の枠の中で、勉強の時間が取れるか |
| 五、経験で裏付けられないかを先に考える | 資格より、小さい案件で経験を作るほうが早く、依頼側にも伝わることが多い |
| 六、それでも取るなら、範囲の言葉と対応する形で取る | 取った後、範囲の一言と資格を並べて書けるか |

決め方の要点は、「五」の経験で裏付けられないかを先に考えることです。採用の運用の範囲では、資格の勉強に使う時間を、小さい案件を一件回すことに使うほうが、範囲の裏付けとして依頼側に伝わります。資格が要るのは、労務や法令のように、経験だけでは裏付けられない範囲か、資格が無いと受けられない業務を範囲に入れたいときです。経験の作り方は[実績を積む](/media/fukugyo-jisseki-tsumu/)に、経験が浅いときの案件の選び方は[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に整理しています。

## 資格の名前を経歴や範囲にどう書くか

資格を持っている場合、経歴と範囲にどう書くかで、依頼側の受け取り方が変わります。

| 書き方 | 依頼側の受け取り方 |
|---|---|
| 資格の名前だけを並べる | 「で、何を頼めるのか」。範囲が分からない |
| 範囲の一言の後に、裏付けとして添える | 「労務に関わる相談の一次対応（〇〇の資格あり。判断は専門家につなぐ）」のように、範囲と資格が対応している |
| 資格を範囲の代わりにする | 「〇〇の資格を持っています」だけでは、依頼側は範囲を読めない |
| 資格で受けられる業務を、範囲を超えて書く | 資格があっても、副業で受けてよい業務かは別。範囲を超えて書くと、依頼側の期待がずれる |
| 資格の勉強中であることを書く | 「取得に向けて勉強中」は、依頼側にとっては判断の材料にならない。取ってから書く |

書き方の要点は、「範囲の一言が先で、資格はその裏付けとして添える」ことです。依頼側は範囲を読んで判断し、資格はその範囲の信頼を少し補います。順番が逆だと、依頼側は資格から範囲を推測することになり、推測は外れます。経歴の書き方は[プロフィールの書き方](/media/fukugyo-profile/)に、実績の示し方は[実績の示し方](/media/fukugyo-jisseki-shimeshikata/)に書いています。

## 資格より先にやること

資格を取る前に、副業の範囲を裏付けるためにやることがあります。多くは、資格より早く、依頼側に伝わります。

| やること | 内容 | なぜ資格より先か |
|---|---|---|
| 範囲を工程で一言にする | 「スカウトの運用と求人票」のように | 依頼側が最初に見るもの。[受ける範囲の決め方](/media/fukugyo-scope/) |
| 小さい案件を一件回す | 型に沿った工程で、一件 | 範囲の裏付けとして最も強い |
| 型を持つ | 文面、手順、報告の型 | 「この型で進める人」として伝わる。[事例を流用しない](/media/fukugyo-jirei-ryuuyou/) |
| 記録の習慣を作る | 稼働ログ、判断のメモ | 依頼側の信頼の条件。[稼働ログの付け方](/media/fukugyo-log/) |
| 情報の扱いを整える | 端末の分離、置き場、線 | 情報の扱いの資格より、実際に整えていることが依頼側に伝わる。[情報の取り扱いと端末の分離](/media/fukugyo-security/) |
| 法令に関わる場面の一覧を持つ | 求人の表現、選考の質問、条件の提示、個人情報。「ここは専門家に」と線を引く場面を知っておく | 資格の勉強の一部を、実務の線引きとして先に持つ |

先にやることの要点は、「法令に関わる場面の一覧を持つ」ことが、資格の勉強の実務的な代わりになることです。資格を取らなくても、採用の工程で法令に触れる可能性のある場面を一覧で知っておけば、「ここは自分の範囲の外」と線を引けます。一覧は、公的な機関が公開している採用に関する案内から、場面の種類だけを拾えば作れます。解釈は書かず、「この場面は専門家に」とだけ持ちます。

### エラベルの見解

担当する側から見ると、資格を持っている人と持っていない人で、案件の決まり方に差はほとんどありません。差があるのは、範囲が一言で言えるか、範囲の中の経験があるか、情報の扱いが整っているか、法令に関わる場面で線を引けるか、です。四つ目の「線を引ける」は、資格の勉強で身につくこともありますが、資格を持たずに、場面の一覧を持って線を引いている人も多くいます。

順番として、範囲を工程で決め、小さい案件で経験を作り、型と記録と情報の扱いを整え、法令に関わる場面の一覧を持ち、そのうえで範囲の裏付けが弱い部分があれば、対応する資格を公式の情報で確認して、副業の枠で取れるなら取る。資格が要る業務（労務の相談など）は、資格が無ければ範囲に入れず、専門家につなぐ。この順番で、資格は範囲の裏付けになり、範囲より先に置いて空回りすることはありません。エラベルでは、登録の際に資格の有無を条件にしておらず、範囲と経験で提示しています。資格は、範囲を裏付ける材料の一つで、範囲の代わりではありません。

## まとめ

- 資格は**案件を取る条件にならない**。依頼側が見るのは範囲と経験で、資格の有無で選ぶ場面はほとんど無い
- 役に立つのは**範囲の言葉を裏付ける材料**と**法令に関わる場面で線を引く判断力**の二つ。後者が実務では効く
- 採用の運用の範囲では**資格は要らない**。裏付けになるのは設計・労務・キャリアの相談・情報の扱いの範囲で、補いとして
- **労務の相談と職業紹介に当たる業務は、資格や許可の問題**。範囲に入れる前に公式の情報と専門家で確認し、無ければ専門家につなぐ
- 取るかは**範囲を決めてから、裏付けが弱い部分を見て、経験で裏付けられないかを先に考え、それでも要るなら**
- 書くときは**範囲の一言が先、資格は裏付けとして添える**。勉強中は書かない
- 資格より先に**範囲の一言・小さい案件・型・記録・情報の扱い・法令に関わる場面の一覧**

## よくある質問

### 人事の経験が浅いので、資格で補いたいです

経験が浅い段階で依頼側に伝わるのは、資格より、「型に沿って正確に動いた経験」です。小さい案件を一件、依頼側の型に沿って回すほうが、資格の勉強に同じ時間を使うより、範囲の裏付けとして強く、依頼側にも伝わります。資格で補いたい範囲が、労務や法令のように経験だけでは裏付けられないものなら、資格に意味がありますが、採用の運用の範囲なら、一件の経験が先です。経験の作り方は[人事1年目でもできること](/media/fukugyo-1nenme/)と[経験が浅くても受けられる案件](/media/fukugyo-keiken-asai/)に書いています。

### 依頼側から「労務のことも相談に乗ってほしい」と言われました

労務の相談は、資格が無いと受けられない業務があるとされ、資格があっても副業の範囲で受けてよいかは別に確認が要ります。「労務に関わるご相談は、資格や許可が関わる領域なので、社会保険労務士などの専門家にご確認ください。私の範囲は採用の〇〇です」と、範囲の線で伝えます。人事の経験があると相談が来やすいですが、範囲の外として線を引くことが、依頼側にとっても安全です。線の引き方は[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/)に、断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。判断は専門家にご確認ください。

### 資格の勉強をしていて、法令の知識が増えました。依頼側に法令の解釈を伝えてよいですか

資格の有無に関わらず、法令の解釈を断定して依頼側に伝えることは避けます。「一般に〜と整理されています。個別の判断は専門家にご確認ください」と、一般的な整理と、専門家への案内までにします。知識が増えたことは、「この場面は法令に関わる」と気づいて線を引く力として活かし、解釈を伝える力としては使いません。依頼側が解釈を求め続けるなら、専門家につなぐことが、依頼側にとっても自分にとっても安全です。法令に関わる線は[権限がないと動けない場面](/media/fukugyo-kengen-nai/)に書いています。
