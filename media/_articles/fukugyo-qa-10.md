副業を始めたら確定申告が要ると聞いた。本業では会社が年末調整をしてくれていたので、自分で申告をしたことが無い。何をいつまでにやればよいのか、そもそも自分は申告が要るのかが分からず、それが副業を始めない理由の一つになっている。結論を先に書くと、**確定申告の要否、方法、期限、様式は、制度と自分の状況で決まるもので、この記事では断定しません。税理士などの専門家に確認します。自分でやるのは、「入金と経費の記録を年初から付ける」「専門家に相談する時期を決める」「本業の会社への影響を先に聞く」の三つで、これは副業を始めた日からできます。**申告の手続きそのものより、その前の記録と相談の時期で、年末の負担が決まります。申告の進め方の考え方は[確定申告の進め方](/media/fukugyo-kakutei-shinkoku/)に、経費の考え方は[経費にできるもの](/media/fukugyo-keihi/)に、収入の見立ては[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)にまとめています。要否と方法の判断は、専門家にご確認ください。

## この記事で扱わないこと

確定申告について、次のことは、制度に関わり、改定があり、個人の状況で変わるため、この記事では扱いません。

| 扱わないこと | 理由 | 誰に聞くか |
|---|---|---|
| 申告が必要になる基準 | 収入の額や形、本業の状況で変わる | 税理士 |
| 所得の区分（事業か雑か） | 副業の形と規模で変わり、判断に幅がある | 税理士 |
| 申告の方法と様式 | 制度の改定がある | 税理士、または税務署の窓口 |
| 期限 | 年によって変わることがある | 税理士、または税務署の窓口 |
| 住民税の扱い | 自治体と本業の会社の処理で変わる | 税理士、または自治体の窓口 |
| 開業届、青色申告、登録番号の要否 | 自分の状況と、将来の見込みで変わる | 税理士 |
| 経費として認められる範囲の判断 | 個別の支出の判断は専門家の領域 | 税理士 |

扱わない要点は、「自分で調べて判断せず、専門家に聞く」ことです。調べれば情報は出てきますが、自分の状況に当てはまるかの判断は、情報を読むだけでは分かりません。専門家に一度聞けば、その後の年は同じ形で進められます。最初の年だけは、専門家に聞く前提で動きます。

## 副業を始める前に知っておく一年の流れ

申告の細部は専門家に任せるとして、一年の流れだけは、始める前に知っておくと、慌てません。

| 時期 | 起きること | 自分でやること |
|---|---|---|
| 副業を始めた日 | 入金と経費が発生し始める | 記録の表を作り、初日から付ける。副業用の口座を分ける。[決済・振込先の準備](/media/fukugyo-kessai/) |
| 最初の数か月 | 入金の形（手数料の差、源泉の有無）が分かってくる | 入金の記録に、請求額と入金額の差を書く。分からない差は依頼側か窓口に聞く |
| 年の半ば | 一年の収入の見込みが立ってくる | 専門家に一度相談し、要否と、年末までにやることを聞く。ここが最も大切な時期 |
| 年末 | 一年の入金と経費が揃う | 記録を締め、専門家に渡す形にする。本業の年末調整との関係を確認 |
| 年明けから申告の時期 | 申告が要る場合、手続きをする | 専門家の指示に従う。期限は専門家か窓口に確認 |
| 申告の後 | 住民税の処理が動く | 本業の会社への影響を、専門家に聞いた内容で確認 |

流れの要点は、「年の半ばに専門家に一度相談する」ことです。年末に初めて相談すると、記録の抜けや経費の仕分けを遡ってやり直すことになり、専門家も年末は忙しく、相談の時間が取れません。年の半ばに「今年はこのくらいの収入になりそうだが、申告は要るか、年末までに何をしておくか」を聞いておけば、年末は記録を締めるだけで済みます。

### エラベルの見解

相談で最も多い思い込みは、「確定申告が難しそうだから、副業は始められない」というものです。実際には、申告の手続きは、専門家に頼めば自分で細部を理解しなくても済みますし、年に一度のことです。難しくなるのは、手続きではなく、記録が無い状態で年末を迎えることです。入金がいつ、いくら、どこから来たか、経費が何に、いくらかかったかを、一年分遡って思い出すのは、誰にとっても難しい。初日から記録を付けていれば、年末にやることは、記録を締めて専門家に渡すだけです。

見ていて差がつくのは、副業用の口座を分けているかです。分けていれば、入金の記録は口座の明細がそのまま使え、記録の表と突き合わせるだけで済みます。本業の給与と同じ口座だと、一年分の明細から副業の入金を一行ずつ探すことになります。エラベルでは、担当者の報酬の振込先を登録の時点で聞いていますが、副業用の口座を分けることを勧めているのは、申告の準備を軽くするためでもあります。申告は、専門家に任せられますが、記録は自分にしか付けられません。

## 初年度に自分で整えておく三つ

申告そのものは専門家に任せても、自分で整えておかないと専門家も動けないものが三つあります。

| 整えること | 内容 | 要点 |
|---|---|---|
| 一、入金と経費の記録 | 入金：日付、依頼側か窓口、請求額、入金額、差の理由。経費：日付、内容、額、副業との関係 | 表計算の一枚で足りる。初日から。月に一度、口座の明細と突き合わせる |
| 二、専門家に相談する時期 | 年の半ばに一度、年末に一度。初年度は二回 | 「収入の見込みがこのくらい」と言える状態で相談する。[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/) |
| 三、本業の会社への影響の確認 | 副業の収入が、本業の会社の処理（年末調整、住民税）にどう関わるか | 専門家に聞き、本業の会社の規定と合わせて確認する。[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/) |

三つの要点は、「一」の記録に、請求額と入金額の差の理由を書くことです。仲介サービスの手数料、依頼側の経理の処理による差など、入金額が請求額と違うことは普通にあります。差の理由を書いておかないと、年末に「なぜこの額なのか」が分からず、専門家も判断できません。分からない差は、その月のうちに依頼側か窓口に聞いておきます。入金の記録の型は[決済・振込先の準備](/media/fukugyo-kessai/)に、経費の記録の考え方は[経費にできるもの](/media/fukugyo-keihi/)に書いています。

## 専門家に聞く項目の整理

専門家に相談するとき、聞くことを整理しておくと、一度の相談で済みます。

| 聞くこと | 相談のときに用意するもの |
|---|---|
| 自分の収入の見込みで、申告は要るか | 年初からの入金の記録と、年末までの見込み |
| 所得の区分はどうなるか | 副業の形（業務委託か、窓口経由か）、稼働の頻度、契約の内容 |
| 経費として整理してよい支出は何か | 経費の記録。副業との関係が説明できる形で |
| 年末までにやっておくことは何か | 記録の表。抜けている項目があれば、ここで分かる |
| 本業の年末調整との関係はどうなるか | 本業の会社から受け取る書類の種類 |
| 住民税の処理で、本業の会社に何が伝わるか | 本業の会社の規定。副業を伝えているかどうか |
| 開業届や青色申告は、自分の状況で意味があるか | 来年以降の副業の見込み |
| 来年から変えたほうがよい記録の付け方はあるか | 今年の記録の表 |

聞く項目の要点は、「記録の表を持って行く」ことです。記録が無いと、専門家は「まず記録を付けてください」から始めることになり、相談が一度で済みません。記録があれば、専門家はそれを見て、要否と、年末までにやることと、来年の記録の付け方を、その場で答えられます。専門家の探し方が分からない場合は、本業の会社の福利厚生や、自治体の相談の窓口から始める方法もあります。

## 本業の会社との関係で先に確認すること

確定申告は、本業の会社との関係にも関わります。申告の前に、本業の側で確認しておくことがあります。

| 確認すること | なぜ | 誰に |
|---|---|---|
| 本業の会社に副業を伝えているか | 申告や住民税の処理で、副業の存在が本業の会社に伝わる経路があるとされている。伝えていないなら、その経路を専門家に聞く | 専門家、本業の会社の規定 |
| 本業の年末調整で何を出すか | 副業の収入を本業の年末調整に含めるかどうかは、制度による。専門家に聞く | 専門家 |
| 本業の会社の規定で、副業の収入の申告に決まりがあるか | 副業の許可の条件に、収入の報告が含まれていることがある | 本業の会社の規定、窓口 |
| 副業の収入が、本業の社会保険などに影響するか | 制度と収入の形で変わる | 専門家 |

確認の要点は、「本業に副業を伝えていない場合、申告と住民税の経路を専門家に先に聞く」ことです。「申告をしたら本業に知られるか」は、多くの人が気にする点ですが、経路と対処は制度と自治体と本業の処理で変わり、一律には言えません。専門家に自分の状況を伝えて聞くのが、最も確かです。本業に伝える形は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に、本業との線引きは[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## よくある誤解

確定申告について、始める前の人が持ちやすい誤解を、断定を避けて整理します。

| 誤解 | 実際 |
|---|---|
| 「副業の収入が少なければ何もしなくてよい」 | 要否は収入の額だけでなく、形や本業の状況で変わる。少なくても確認が要ることがある。専門家に |
| 「窓口経由なら、窓口が申告してくれる」 | 窓口が請求を集約しても、自分の申告は自分（か自分が頼んだ専門家）がする。窓口は支払いの記録を出すことはあっても、申告はしない |
| 「経費を多く付ければ得になる」 | 経費は副業に直接要った支出で、判断は専門家の領域。多く付けることが目的になると、後で問題になる |
| 「申告をすれば本業に知られる、しなければ知られない」 | 申告の有無と、本業に知られる経路は別の話。しないことで問題が生じることもある。専門家に |
| 「一年目は申告が要らない」 | 一年目かどうかで要否は決まらない。収入の形と額で決まる。専門家に |
| 「年末に一度専門家に頼めば済む」 | 記録が無いと専門家も動けない。記録は自分で、年初から |

誤解の要点は、「要否と方法は、自分で判断せず専門家に聞く」に尽きます。誤解の多くは、自分の状況に当てはまらない情報を、当てはまると思って判断したことから起きています。自分の状況を専門家に伝えて聞けば、誤解は消えます。

## 相談の時期の決め方

専門家に相談する時期は、初年度と二年目以降で変わります。

| 年 | 時期 | 内容 |
|---|---|---|
| 初年度 | 副業を始めて数か月後（年の半ばまで） | 収入の見込みを持って、要否と、年末までにやることと、記録の付け方を聞く |
| 初年度 | 年末 | 記録を締めて渡し、申告の要否の最終確認と、手続きの依頼 |
| 初年度 | 申告の後 | 本業への影響と、来年の記録の付け方を確認 |
| 二年目以降 | 年末に一度 | 記録を締めて渡す。前年と同じ形なら、相談は短く済む |
| 二年目以降 | 収入の形が変わったとき | 直接契約が増えた、法人の話が出た、収入が大きく変わった。そのときに一度。[法人として受ける場合](/media/fukugyo-houjin-keiyaku/) |

時期の要点は、「初年度は年の半ばに一度」です。ここで聞いておけば、年末の負担は記録を締めるだけになり、二年目からは年末の一度で済みます。初年度の年の半ばの相談を飛ばすと、年末に記録の整え直しから始まり、専門家も忙しい時期で、二年目も同じことを繰り返します。

### エラベルの見解

担当する側から見ると、確定申告で困っていない人は、税に詳しい人ではなく、初日から記録を付け、年の半ばに一度専門家に聞いた人です。記録があり、専門家に聞いた内容があれば、年末は記録を締めて渡すだけで、申告の細部を自分で理解する必要はありません。困っている人は、記録が無く、年末に初めて専門家を探し、一年分を遡って整えている人です。

順番として、副業を始めた日に記録の表と副業用の口座を用意し、月に一度、口座の明細と突き合わせ、年の半ばに記録を持って専門家に一度相談し、年末に記録を締めて渡す。この順番で、確定申告は副業を始めない理由にはなりません。エラベルでは、担当者の報酬の支払いの記録を出せる形にしていますが、記録の表と専門家への相談は、担当者自身が行うものです。申告は専門家に任せ、記録は自分で付ける。この分担が、最も負担の少ない形です。

## まとめ

- 申告の**要否・方法・期限・区分・経費の判断は専門家に**。この記事では断定しない
- 自分でやるのは**入金と経費の記録を年初から・専門家に相談する時期を決める・本業への影響を先に聞く**の三つ
- 一年の流れは**初日に記録を始め・数か月で入金の形を把握し・年の半ばに専門家に一度・年末に記録を締めて渡す**
- 記録には**請求額と入金額の差の理由**を書く。副業用の口座を分けると突き合わせが楽
- 専門家には**記録の表を持って行き、要否・区分・経費・年末までにやること・本業との関係・住民税・来年の記録**を聞く
- 本業に副業を伝えていないなら**申告と住民税の経路を専門家に先に聞く**
- **初年度は年の半ばに一度、年末に一度**。二年目からは年末の一度で済む

## よくある質問

### 専門家に頼む費用が、副業の収入に見合わない気がします

初年度に一度相談して、記録の付け方と自分の状況での要否を聞いておけば、二年目からは相談の時間が短く、費用も小さくなります。相談の費用は、記録が無い状態で年末に一年分を整えてもらう費用より、多くの場合は小さく済みます。本業の会社の福利厚生や、自治体の相談の窓口で、初回の相談が受けられることもあるので、探してみてください。費用の判断は、収入の規模と自分の状況で変わるので、一度聞いてから決めます。

### 窓口や仲介サービスから、支払いの記録の書類は出ますか

窓口や仲介サービスによって、年間の支払いの記録を出すところと、出さないところがあります。登録の時点で「年間の支払いの記録は出ますか」と聞いておき、出るならそれを申告の材料の一つにし、出ないなら自分の記録と口座の明細で整えます。どちらの場合も、自分の記録は付けておきます。窓口の書類は入金の記録の裏付けにはなりますが、経費の記録は自分にしかありません。

### 副業を始めた年の途中で、専門家に相談する前に年末が来てしまいました

年末でも、記録の表と口座の明細があれば、専門家は判断できます。記録が無い場合は、口座の明細と、依頼側や窓口からの支払いの連絡、請求書の控えを集め、遡って表にします。時間はかかりますが、揃えれば専門家に渡せます。年末は専門家が忙しいので、早めに連絡し、記録を揃えている間に相談の予約を取ります。来年からは、年の半ばに一度相談する形にします。
