求人票の要件を書こうとして、止まる。「〇〇の経験」は必須か、歓迎か。現場は「必須」と言い、人事は「必須にしたら誰も来ない」と言う。結局、全部を必須に書くか、全部を「歓迎」で曖昧に書くか、どちらかになる。結論を先に書くと、**必須と歓迎の線は、「それが無いと、入社後三か月で詰まるか」の一つの問いで引けます。詰まるなら必須、詰まらないが早くなるなら歓迎、どちらでもないなら書かない。線は一度で決めず、面接で「必須にしたものは本当に必須だったか」を確かめて、直します**。要件が固まらない場合は[採用要件が固まらない](/media/rpo-youken-katame/)に、高すぎる場合は[採用要件が高すぎて誰も通らない](/media/rpo-youken-takasugi/)にまとめています。

## 線が引けない構造

必須と歓迎の線が引けないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「必須」の意味が決まっていない | 「無いと成り立たない」なのか「あると良い」なのか、人によって解釈が違う |
| 現場は全部を必須にしたい | 「無いと困る」の基準が「あると助かる」になっている |
| 人事は全部を歓迎にしたい | 応募を減らしたくない。必須を減らすと、書類で絞れなくなる |
| 「理想の人」で考えている | 理想には、全部が必須に見える |
| 線を引く基準が無い | 「要る・要らない」を、感覚で決めている |
| 一度引いた線を、確かめていない | 面接で「必須にしたが要らなかった」「歓迎にしたが要った」が分かっても、直していない |
| 抽象語で書いている | 「コミュニケーション力」は、必須にも歓迎にもできない。観察できないから |

線が引けないのは、能力の問題ではなく、基準が無いことの問題です。基準を一つ置きます。

## 線を引く一つの問い

「それが無いと、入社後三か月で詰まるか」。この問いで、線を引きます。

**詰まるなら、必須。** 「〇〇の経験が無いと、最初の三か月で担当する業務が回らない」。教える時間も無く、代わりの人もいない。これは必須です。

**詰まらないが、あれば早いなら、歓迎。** 「△△の経験があれば、立ち上がりが一か月早い。無くても三か月で覚えられる」。これは歓迎です。

**どちらでもないなら、書かない。** 「□□の経験があると、何となく良さそう」。三か月に影響しないなら、要件ではありません。書くと、応募の入口を狭めるだけです。

**「三か月」は、役割によって変える。** 立ち上がりに半年かかる役割なら「半年」。要点は、「理想の姿」ではなく「入社直後の一定期間」で問うことです。

**問う相手は、現場の責任者。** 「最初の三か月に、実際にやること」を知っているのは現場です。「無いと詰まるか」も、現場が答えられます。

**問い方を変えない。** 「要りますか」と聞けば、全部「要る」と返ります。「無いと三か月で詰まりますか」と聞けば、「詰まる」と「詰まらないが早い」に分かれます。

一つの問いで、必須は三〜四に、歓迎は二〜三に収まることが多いです。それ以上になるなら、「三か月で実際にやること」が多すぎるか、役割が二人分です。

## 必須にしてはいけないもの

必須に置くと、通るべき人を落とすものがあります。

| 必須にしてはいけないもの | 理由 | 代わりの書き方 |
|---|---|---|
| 抽象語 | 「コミュニケーション力」「リーダーシップ」「主体性」は、面接官ごとに解釈が違い、誰も通らないか、誰でも通る | 観察できる言葉に。「顧客の要望を聞き取って、社内に文章で伝えた経験」 |
| 経験の年数 | 「五年以上」は、年数が長くて中身が無い人を通し、年数が短くて中身がある人を落とす | 中身で書く。「〇〇を自分で設計した経験」 |
| 業界の経験 | 「同業界での経験」は、隣の業界から通る人を落とし、市場を狭める | 動きで書く。「〇〇（顧客と話す、数字を追う）の経験」 |
| 入社後に教えられるもの | 「自社の製品の知識」「社内の手順」は、入社後に教える。必須にすると、誰も満たさない | 育てる範囲として、求人票には「入社後に習得」と書く |
| 学歴 | 役割の遂行に直接関係しない学歴は、要件にしない。法令上の扱いも確認 | 書かない |
| 私的な事情 | 年齢、性別、家族構成などは、法令上の扱いがあり、要件にしない | 書かない。専門家に確認 |
| 「複数の役割の全部」 | 「営業も企画も管理も」は、二人分。一人には無い | 役割を分ける |
| 「あると良い」の積み上げ | 過去の失敗のたびに足した要件 | 「無いと三か月で詰まるか」で問い直す |

必須は、「無いと詰まる」ものだけです。「あると安心」は、必須ではありません。

## 歓迎の使い方

歓迎は、「書いておけば良い」ものではなく、使い方があります。

**書類の判断で、必須が同じなら歓迎で順位を付ける。** 必須を満たす応募が複数あるとき、歓迎の数で面接の順番を決めます。

**面接で、歓迎を確認する。** 歓迎に挙げたものが、実際にあるか、どの程度かを面接で聞きます。「無くても通す」が前提です。

**条件の幅の中の位置を決める材料にする。** 歓迎を多く満たす人は、幅の中で高めの位置。歓迎が無い人は、幅の中で標準の位置。

**育てる範囲を決める材料にする。** 歓迎に挙げたものが無い人を採る場合、その部分が入社後に育てる範囲になります。

**歓迎を必須のように扱わない。** 「歓迎」と書いたのに、面接で「これが無いから落とす」と判断するなら、それは必須です。線を引き直します。

**歓迎の数を絞る。** 歓迎が十個並ぶ求人票は、「全部無いとダメに見える」求人票です。二〜三に絞ります。

歓迎は、「あると良い」を並べる欄ではなく、「必須を満たす人の中で、どう見るか」の基準です。

### エラベルの見解

相談で最も多い失敗は、「必須が八つ、歓迎が十二個の求人票を出して、半年応募が来なかった」というものです。現場に「無いと三か月で詰まりますか」と一つずつ聞いたら、必須は三つ、歓迎は二つになりました。残りは「あると安心」と「入社後に教えられるもの」でした。線を引き直して出したら、翌月から応募が来ました。要件を「下げた」のではなく、「無いと詰まるもの」だけを必須にしただけです。

見ていて差がつくのは、担当者が「問いを変える」かどうかです。「これは必須ですか」と聞く担当者と、「これが無いと、入社後三か月で詰まりますか」と聞く担当者がいます。前者は全部「必須」と返り、後者は「詰まる」と「詰まらないが早い」に分かれます。問いが、線を引きます。

発注側にできるのは、要件を決める場で、「要るか」ではなく「無いと詰まるか」と問う型を持つことです。

## 線を引いた後の書き方

線を引いたら、求人票にどう書くかです。

| 項目 | 書き方 |
|---|---|
| 必須 | 三〜四つ。観察できる言葉で。「〇〇を自分で設計した経験」「△△の顧客と直接やり取りした経験」 |
| 歓迎 | 二〜三つ。「あれば立ち上がりが早い」と添える。「□□の経験があれば、〇〇の業務に早く入れます」 |
| 入社後に習得 | 必須でも歓迎でもなく、「入社後に教えます」と明記。「自社の製品と手順は、最初の三か月で習得いただきます」 |
| 合わない人 | 「こういう方には向きません」を一つ。「細かい指示を待つ働き方を望む方には合いません」 |
| 三か月の姿 | 「入社後三か月で、〇〇を担当していただきます」。必須の根拠が見える |
| 一年後の姿 | 「一年後には、△△まで広げていただきたいと考えています」。成長の見通し |
| 順番 | 役割→三か月の姿→必須→歓迎→入社後に習得→合わない人→一年後の姿→条件 |

「入社後に習得」を書くと、候補者は「全部できなくてよい」と分かり、応募の入口が広がります。「合わない人」を書くと、合わない人が応募の前に自分で判断し、書類と面接の手間が減ります。

抽象語が残っていないか、最後に確認します。「力」「性」で終わる言葉は、大半が抽象語です。

## 面接での確かめ方と直し方

線は、面接で確かめて直します。

**面接の記録に、「必須の確認」の欄を持つ。** 必須の一つひとつについて、「確認できた・できなかった・判断できず」を記録します。

**「必須にしたが、無くても通した」が出たら、歓迎に下げる。** 面接官が「これは無いが、通したい」と判断した必須は、実は必須ではありません。

**「歓迎にしたが、無いから落とした」が出たら、必須に上げる。** 面接官が「これが無いから落とす」と判断した歓迎は、実は必須です。

**「判断できず」が多い必須は、質問が悪い。** 面接で確認できない必須は、観察できる言葉になっていないか、質問が用意されていません。言葉と質問を直します。

**入社した人の三か月で、確かめる。** 「必須にしたものが無い人を採った場合、三か月で詰まったか」「必須を満たす人を採って、三か月で回ったか」。入社後の記録が、線の正しさの最終の確認です。

**三か月ごとに、線を見直す。** 面接の記録と入社後の記録を見て、必須と歓迎を上げ下げします。

**変えた理由を記録する。** 「〇〇を必須から歓迎に。理由は面接で無くても通した例が三件、入社後も詰まらなかったから」。

線は、仮説です。面接と入社後で検証し、直します。一度引いた線を固定しないことが、要点です。

## 外注する場合の範囲

必須と歓迎の線の問題を、採用代行に出す場合の範囲です。

**出せる工程。** 現場の責任者への「無いと三か月で詰まるか」の聞き取りと進行、必須にしてはいけないものの点検、観察できる言葉への書き換え、歓迎の絞り込みと使い方の整理、求人票の書き方（入社後に習得、合わない人、三か月と一年後の姿を含む）、面接官向けの必須の確認の質問と記録の欄、面接の記録の集計（必須の確認の結果）、入社後の三か月の確認の型、三か月ごとの見直しの材料、変更の履歴。

**社内に残す判断。** 必須と歓迎の決定、線の変更の決定、入社後に教える範囲と教える人の決定、法令上の扱いの確認（専門家との連携）。

**外注の効きどころ。** 線が引けない会社は、現場と人事が「必須・歓迎」で対立しています。外部の担当者が「無いと三か月で詰まるか」の問いを持ち込み、現場に一つずつ聞けば、線は一時間で引けます。面接の記録の集計と、線の見直しの材料も、担当者の定例の仕事になります。

**外注しても動かない場合。** 現場が「全部無いと詰まる」を譲らない、人事が「必須をゼロに」を譲らない、面接の記録を取らない。社内の判断で、代行を替えても直りません。

線は、問いと検証で引けます。外注は、問いを持ち込み、検証を回す手段です。

### エラベルの見解

担当する側から見ると、線の相談で最も多いのは、「必須」の中に「入社後に教えられるもの」が入っていることです。「自社の製品の知識」「社内の手順」「業界の慣習」。これらは、どんな経験者でも入社後に覚えるものです。必須に入っていると、誰も満たしません。

「入社後に習得」の欄を求人票に作り、そこに移すだけで、必須は減り、候補者は「全部できなくてよい」と分かります。必須を減らすのではなく、置き場所を変えるだけです。

発注側にできるのは、必須の一つひとつに「これは入社後に教えられるか」と問うことです。教えられるなら、必須ではありません。

## まとめ

- 線が引けないのは**必須の意味が無い・現場は全部必須・人事は全部歓迎・理想で考える・基準が無い・確かめていない・抽象語**の構造
- 問いは**「無いと入社後三か月で詰まるか」**。詰まるなら必須、早くなるなら歓迎、どちらでもないなら書かない。現場の責任者に、「要るか」でなく「詰まるか」と問う
- 必須にしてはいけないのは**抽象語・年数・業界・入社後に教えられるもの・学歴・私的な事情・複数の役割の全部・あると良いの積み上げ**。法令上の扱いは専門家に確認
- 歓迎は**書類の順位・面接での確認・条件の幅の位置・育てる範囲の材料**に使い、必須のように扱わず、二〜三に絞る
- 書き方は**必須三〜四を観察できる言葉で・歓迎二〜三に「早い」を添えて・入社後に習得を明記・合わない人を一つ・三か月と一年後の姿・順番**
- 面接で**必須の確認を記録し・無くても通したら歓迎に・無いから落としたら必須に・判断できずなら質問を直し・入社後三か月で確かめ・三か月ごとに見直し・理由を記録**

## よくある質問

### 現場が「全部必須」と言って譲りません

問いを変えます。「必須ですか」ではなく、「これが無いと、入社後三か月で詰まりますか」。一つずつ聞くと、「詰まる」と「詰まらないが早い」に分かれます。「今いる〇〇さんが、この要件で応募したら通りますか」と聞くと、実態より高く書いていることに現場が気づきます。「入社後に教えられるか」と聞くと、教えられるものが必須から外れます。「下げてください」とは言わず、問いで分けます。

### 必須を減らすと、書類で絞れなくなりませんか

必須を「観察できる言葉」で書けば、絞れます。「五年以上」より「〇〇を自分で設計した経験」のほうが、書類で判断しやすく、的確に絞れます。必須が多くて抽象的な求人票は、絞れているように見えて、通るべき人を落とし、通るべきでない人を通しています。必須は数ではなく、的確さで絞ります。歓迎は、必須を満たす人の中で順位を付ける材料にします。

### 一度決めた線を、変えてもよいですか

変えます。線は仮説で、面接と入社後で検証するものです。面接で「必須にしたが無くても通した」が出たら歓迎に、「歓迎にしたが無いから落とした」が出たら必須に。入社後三か月で「必須が無い人が詰まったか」を確かめます。三か月ごとに見直し、変えた理由を記録します。一度決めた線を固定すると、実態とずれた要件で採用を続けることになります。
