「採用のデータを分析してほしい」と頼まれて、一覧をあらゆる切り口で集計し、「〇〇の傾向が見られます」と並べた資料を渡しても、依頼側は「で、何をすれば」と止まります。データを眺めて傾向を探す分析は、切り口の数だけ「傾向」が出て、どれも行動につながりません。分析は、問いから始めるものです。結論を先に書くと、**採用データの分析は、問いを一つ立て、その問いに答えられる記録があるかを確かめ、条件を揃えて比べ、割合と平均で断定せず、相関を原因と言わず、結果を「直す場所を一つ」に落として一枚で渡し、外部の統計を持ち込まずに行います。**記録の元は[スプレッドシートで採用管理を作る](/media/fukugyo-skill-spreadsheet/)に、段階ごとの見方は[採用ファネルを可視化する](/media/fukugyo-skill-funnel/)に、数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。ここでは、分析の型に絞ります。

## 傾向を探す分析が何も生まない理由

| やってしまうこと | 何が起きるか |
|---|---|
| 一覧をあらゆる切り口で集計 | 切り口の数だけ「傾向」が出る。どれを信じるか決められない |
| 「〇〇の傾向が見られます」で終わる | 何を直すかが無い |
| 件数が少ないのに割合で語る | 一件の差で数字が倍になり、次の月に反転する |
| 相関を原因として語る | 「〇〇の経路は通過率が高い」→経路のせいではなく、その経路の候補者の層のせい |
| 外部の統計と比べる | 依頼側の職種・規模・時期と合わず、比較にならない |

分析は、「何を知りたいか」が先で、「何が出るか」は後です。問いが無い分析は、切り口の展示になります。

## 問いから始める

| 問いの型 | 例 | 答えに要る記録 |
|---|---|---|
| どこが詰まりか | 「先月、候補者はどの段で最も減ったか。どの段で日数がかかったか」 | 段階・最終更新日・見送りと辞退の理由 |
| この手当ては効いたか | 「求人票のタイトルを変えた前後で、応募の数はどうか」 | 応募日・求人・変更した日 |
| この経路はどうか | 「スカウト経由の候補者は、どの段で落ちているか」 | 経路・段階・理由 |
| この要件は合っているか | 「書類で必須〇〇を○にした人は、一次でどうだったか」 | 書類の○△×・一次の三択 |
| 辞退はなぜか | 「辞退の理由は、速さ・迷い・接点・条件のどれが多いか」 | 辞退の理由の分類 |

問いは一つずつです。二つ以上を同時に追うと、記録の切り方が混ざります。問いの立て方は[課題を構造化する](/media/fukugyo-kouzou-ka/)の「工程で分け、止まっている場所を記録で特定する」と同じです。

### エラベルの見解

担当する側から見ると、データ分析で最も差がつくのは、「答えを出せる記録があるか」を分析の前に確かめられるかです。受ける側は、問いを立てた後、すぐに集計を始めます。ただ、「手当ては効いたか」に答えるには、手当てを実施した日が記録されていなければならず、「経路ごとの落ち方」には、経路の列が埋まっていなければなりません。記録が無いまま集計すると、空欄を除いた偏った数字が出て、それが「傾向」として語られます。エラベルで担当者を選ぶ企業には、「その分析に要る記録は、御社の一覧に埋まっていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、問いを立てたら、答えに要る列を書き出し、その列の埋まり具合を先に見ること。埋まっていなければ、「今月から記録して、来月答えます」と伝えます。

## 副業の件数では「傾向」より「一件ずつ」

副業の稼働で扱う候補者の数は、統計的な傾向を語れる数ではないことがほとんどです。それでも分析はできます。「傾向」ではなく、「一件ずつの事実」を並べる形にします。

| 傾向の形（件数が要る） | 一件ずつの形（少なくても読める） |
|---|---|
| 「一次の通過率が下がった」 | 「一次で見送りになった三人は、全員が観点〇〇で通さないだった」 |
| 「スカウト経由は辞退が多い」 | 「辞退した二人は、どちらもスカウト経由で、理由は速さだった」 |
| 「タイトルの変更で応募が増えた」 | 「変更後の応募は四件で、うち三件が変更で足した言葉に触れていた」 |

一件ずつ並べると、件数が少なくても「直す場所」が見えます。基準の一行のずれ、経路の速さ、タイトルの言葉。これは、傾向を待たずに次の手当てに使えます。

## 比べるときは条件を揃える

| 比べたいこと | 揃えること | 揃わないと |
|---|---|---|
| 手当ての前後 | 期間の長さ、経路、求人 | 時期の差や経路の差が混ざる |
| 経路の間 | 期間、求人、段階 | 求人の違いが経路の違いに見える |
| 求人の間 | 期間、経路 | 経路の違いが求人の違いに見える |
| 面接官の間（依頼側の判断で） | 段、候補者の層 | 層の違いが面接官の違いに見える |

揃えられないときは、比べません。「この二つは条件が違うので、比べられません」も分析の結果です。検証の三条件は[文面を検証する](/media/fukugyo-skill-ab-test/)に書いています。

## 割合と平均で断定しない、相関を原因と言わない

| 言わない | 代わりに |
|---|---|
| 「通過率〇%」 | 「〇人中〇人が通った。件数が少ないので、割合は揺れる」 |
| 「平均〇日」 | 「〇日、〇日、〇日。一件が長く、他は短い」（平均は一件に引っ張られる） |
| 「〇〇の経路は質が高い」 | 「〇〇の経路の候補者は、会社の型が近い人が多かった。経路のせいか層のせいかは分けられない」 |
| 「〇〇が原因」 | 「〇〇と同時に起きている。原因かどうかは、〇〇だけを変えて確かめる」 |

相関を原因と言うと、依頼側はその「原因」を直し、効かず、分析の信頼が落ちます。原因かどうかは、一箇所だけ変える検証で確かめるものです。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「分析の結果は、多ければ多いほど価値がある」というものです。実際には、分析の価値は「直す場所が一つに決まるか」で決まり、結果の数ではありません。十の発見を並べた資料より、「一次で見送りになった三人は全員が観点〇〇で通さない。基準の一行を見直す」の一行のほうが、依頼側は動けます。受ける側がその場で使える判断としては、分析の一枚を書き終えたら、「直す場所」の欄が一つになっているかを確かめること。二つ以上あるなら、どちらが先かを決めて一つにします。決めるのは依頼側ですが、案は一つに絞って出します。

## 依頼側に渡す一枚

| 欄 | 中身 |
|---|---|
| 問い | 一つ |
| 使った記録と期間 | どの列を、いつからいつまで。埋まっていない列があれば明記 |
| 結果 | 件数のまま。一件ずつの事実 |
| 読み方 | 何が言えて、何が言えないか。揃えられなかった条件 |
| 直す場所 | 一つ。担当者の案 |
| 次に確かめること | 直した後、何を、いつ見るか |

一枚に収めます。集計の表は添付に回します。レポートの型は[レポートを作る](/media/fukugyo-skill-report/)に書いています。

## 外部の統計を持ち込まない

「一般に返信率は〇%」「業界の平均の採用日数は〇日」のような外部の数値は、依頼側の職種・規模・媒体・時期と合わず、比較の基準になりません。持ち込むと、依頼側の数字が「良い・悪い」の印象で語られ、直す場所の特定から遠ざかります。基準は、依頼側の過去の記録（先月、前期）です。記録が無ければ、今月が来月の基準です。

## 個人情報の扱い

分析で扱うのは、一覧の番号・段階・経路・日付・理由の分類までで足ります。氏名・連絡先・評価の自由記述は、分析に要りません。分析用に一覧を別の場所に写すときも、個人情報の列を除いて写します。担当者の端末に落とさず、依頼側の環境で行います。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[情報の取り扱いと端末の分離](/media/fukugyo-security/)に書いています。個人情報の扱いに法令が関わる場合は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「何か傾向を見つけてほしい」と言う | 問いを一緒に立てる。「いま一番困っていることは何か」から一つに |
| 記録が埋まっていない | 「今月から記録して来月答える」。埋まっている列で答えられる問いに変える |
| 件数が少なく傾向が読めない | 一件ずつの事実で並べる。傾向を待たない |
| 依頼側が割合や平均を求める | 件数を並べ、依頼側が計算できる形に。揺れることを添える |
| 「〇〇が原因」と言いたくなる | 「同時に起きている」に留め、一箇所だけ変える検証を提案する |
| 直す場所が複数出る | 一つに絞る。残りは次の問いに |

## まとめ

- 傾向を探す分析は、切り口の数だけ傾向が出て**何も生まない**。分析は**問い**から
- 問いは**一つ**。答えに要る**記録があるか**を先に確かめる
- 副業の件数では**「傾向」より「一件ずつの事実」**。少なくても直す場所は見える
- 比べるときは**条件を揃える**。揃わなければ比べない
- **割合と平均で断定しない、相関を原因と言わない**。原因は一箇所だけ変えて確かめる
- 結果は**直す場所を一つ**に落として一枚で
- **外部の統計を持ち込まない**。基準は依頼側の過去の記録
- 分析に**個人情報は要らない**。番号と分類だけ。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側が「他社と比べてうちはどうか」を知りたがります

他社の数字は、条件（職種・規模・媒体・時期）が違うので、比べられません。「御社の先月と今月」「御社のこの経路とあの経路」のように、依頼側の中で条件を揃えた比較に置き換えます。外部の数値を担当者が持ち込むと、根拠を問われて答えられません。「比べるなら、御社の記録の中で」と、比較の対象を変える提案をします。

### 分析ツールやAIを使って、もっと高度な分析をしたいと言われました

道具を変えても、問いと記録が無ければ、出てくるのは切り口の展示です。まず問いを一つ立て、記録を揃え、一件ずつの事実で答える。それができてから、件数が増えて傾向を語れる段階になれば、道具を検討します。道具の選定と費用は依頼側の判断です。担当者は「いまの件数と記録で、道具が何を足すか」を分けて渡します。

### 分析の結果、依頼側の面接官の一人が「通さない」を多く付けていると分かりました

面接官の評価に踏み込みません。「その面接官の段で、通さないの理由は観点〇〇に集中している。観点〇〇の基準の一行が、他の面接官と読み方が違う可能性がある」と、基準の問題として返します。人の問題にすると、面接官は記録を書かなくなり、次の分析ができなくなります。面接官の揃え方は[面接官トレーニングを行う](/media/fukugyo-skill-mensetsukan/)に書いています。
