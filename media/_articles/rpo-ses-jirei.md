同じ採用代行を使っても、機能するSESの会社と機能しない会社があります。差を作るのは代行の腕ではなく、発注側の条件です。採る数が一枚から決まっているか、要件が案件の型で切られているか、育てる体制があるか、待機が設計されているか、動く理由を実態で語れるか、記録が社内にあるか、任せる工程が絞られているか。結論を先に書くと、**SES業界で採用代行が機能するのは、採る数・案件の型・体制・待機・動く理由・記録・工程の七つで「社内に残すものを残している」会社で、機能しないのは「案件が取れそうだから何人でも、全部任せたい」会社です。**発注の前に七つで自社を確かめ、機能しない条件があれば、発注の前にそれを変えます。工程の切り分けは[SES業界の採用代行](/media/rpo-ses-rpo/)に、課題の分解は[SES業界の採用課題](/media/rpo-ses-kadai/)に、SIer業界の条件は[SIer業界で採用代行が機能する条件・機能しない条件](/media/rpo-sier-jirei/)に書いています。ここでは、SES業界の七つの対に絞ります。

## 七つの対

| 軸 | 機能する条件 | 機能しない条件 |
|---|---|---|
| 採る数 | 案件の型ごとの稼働・待機・見込み・確度の一枚から、採る数と時期が決まっている | 「案件が取れそうだから何人でも」。待機が増えたら止める |
| 案件の型 | 「業界・工程・常駐の形」の型で要件が切られている | 「案件に出せる人なら誰でも」 |
| 体制 | 未経験を採るなら、教える人・中身・期間が決まっている。経験者なら技術の見極めを担う人がいる | 「研修はこれから考える」。見極めが無い |
| 待機 | 待機が「次の案件の型に向けた育成の期間」として設計され、上限がある | 待機は自習。上限が無い |
| 動く理由 | 案件の選び方・還元の考え方・育つ道筋・相談先を、実態で語れる | 「SESだから」。額だけで差を出そうとする |
| 記録 | 一覧と面接の記録が社内の環境にあり、代行がそこに書く | 記録が代行の環境。契約が終わると消える |
| 工程 | 任せる工程が絞られ、残す工程（配属・稼働の管理・育成・条件）の担当がいる | 「全部任せたい」 |

七つのうち一つでも機能しない条件にあると、代行はその部分で止まります。

## 採る数：一枚から決まっているか

| 機能する | 機能しない |
|---|---|
| 営業・採用・経営者が同じ一枚（稼働・待機・見込み・確度）を月次で見る | 営業の感覚で「三人」 |
| 見込みの確度で採る数を分けている | 「取れそう」を全部数える |
| 募集から入社までの日数を記録から出し、見込みの時期から逆算 | 「来月から」 |

採る数の根拠が無い会社では、代行が何人集めても、待機か不足のどちらかになります。一枚の作り方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

### エラベルの見解

SES業界で最も多い機能しない条件は、「体制」です。「未経験を採って育てる」と言う会社で、研修の中身と教える人が決まっておらず、代行が未経験の母集団を集め、採り、研修が回らず、途中で離れる。会社は「代行が集めた人の質が低い」と言いますが、原因は体制です。直し方は、募集の前に「誰が、何を、どのくらいの期間教え、研修の後にどの型の案件に出すか」を一枚にし、その体制で受け入れられる人数だけを採ること。体制が無いなら、経験者の採用に絞る判断もあります。エラベルで担当者を選ぶ企業には、「研修の一枚（教える人・中身・期間・その後の案件の型）はありますか」を、私たちから先に聞いています。無ければ、未経験の募集の前に一枚を作ります。体制の考え方は[新卒採用の実務の進め方](/media/rpo-task-shinsotsu-unyou-susumekata/)に書いています。

## 案件の型：要件が切られているか

| 機能する | 機能しない |
|---|---|
| 過去の案件を「業界・工程・常駐の形」で三つ程度の型に分け、型ごとに要件がある | 「案件に出せる人」の一本 |
| 代行が型ごとに「担った工程の言葉」に整え、社内が確認 | 代行が広く集める |
| 型が変われば要件が変わる、と伝わる | 去年の要件のまま |

型は社内でしか作れません。作る作業は、過去の案件を並べて三十分で足ります。

## 体制：育てる人と見極める人がいるか

| 機能する | 機能しない |
|---|---|
| 未経験：教える人・中身・期間・その後の案件の型が一枚に | 「研修はこれから考える」 |
| 経験者：技術の見極めを担う人がいて、面接の枠を週に決まった数出せる | 見極めが無く、書類だけで採る |
| 受け入れられる数だけ採る | 母集団の数に合わせて採る |

## 待機：設計されているか

| 機能する | 機能しない |
|---|---|
| 待機中の育成の中身・教える人・期限が決まり、上限がある | 自習。上限が無い |
| 待機中に社内との週次の接点がある | 連絡が無い |
| 待機の上限を超える前に、一枚に戻して採る数を見直す | 待機が増えてから採用を止める |

待機が設計されていない会社では、採った人が案件の合間に離れ、代行の成果が消えます。

## 動く理由：実態で語れるか

| 機能する | 機能しない |
|---|---|
| いまうまくやっている人の「前の会社と違うこと」「続けている理由」が一枚にあり、文面と面接で使える | 「SESだから」「単価が高い」 |
| 案件の選び方・還元の考え方・育つ道筋・相談先を、仕組みとして説明できる | 説明できない。担当者の口頭 |
| 「自社開発に行きたい」層は対象から外している | 全層に送る |

動く理由は、会社の実態の中にしか作れません。代行の文面の腕では補えません。作り方は[自社紹介はどこまで書くか](/media/scout-kaisha-shoukai/)に書いています。

### エラベルの見解

「全部任せたい」というSESの会社は、多くの場合、営業が採用を兼ねていて、案件の営業と採用の両方で手一杯です。その状態で全部を任せると、採る数の根拠も案件の型も配属の判断も代行に寄り、代行にはできないので止まります。エラベルは担当者を工程ごとに選べる形にしているので、営業を兼ねる責任者が「一枚の更新・案件の型・配属の判断」だけに時間を使い、「母集団形成・一次対応・日程・記録」を担当者が担う、という組み方ができます。責任者の時間は、月に一度の一枚の更新と、型ごとの要件の確認と、面接の一段で足ります。工程の切り分けは[母集団形成は代行に出せるか](/media/rpo-task-boshuudan-daikou/)や[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)に書いています。

## 記録：社内の環境にあるか

| 機能する | 機能しない |
|---|---|
| 一覧と面接の記録が社内のATSか共有の場所にあり、代行がそこに書く | 記録が代行の環境 |
| 週次の一枚で、段階ごとの数と止まりが届く | 月末の報告だけ |
| 契約が終わっても、記録と型（案件の型の要件、文面、依頼書）が社内に残る | 契約が終わると消え、次の募集でゼロから |

SESは募集を繰り返すので、型が残るかどうかで、二回目以降の速さが変わります。記録の扱いは[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。

## 工程：絞られているか

| 機能する | 機能しない |
|---|---|
| 「経験者のスカウトの母集団形成と一次対応」「未経験の掲載型の母集団形成と一次対応」のように、層と工程で任せる範囲が明確 | 「採用を全部」 |
| 残す工程（採る数・案件の型・配属・育成・待機・条件）の担当が決まっている | 残す工程の担当がいない |
| 一つの層・一つの工程で三か月回し、記録で効いたかを見てから広げる | 最初から全層・全工程 |

## 機能しない条件を変える順番

| 順 | 変えること | 費用 |
|---|---|---|
| 一 | 採る数：稼働・待機・見込みの一枚を作る | かからない（責任者の時間） |
| 二 | 案件の型：過去の案件を三つの型に分け、型ごとに要件 | かからない |
| 三 | 体制：未経験なら研修の一枚。経験者なら見極める人と枠 | 教える人の時間 |
| 四 | 待機：育成の中身と上限 | 教える人の時間 |
| 五 | 記録：一覧を社内の環境に | かからない |
| 六 | 工程：任せる工程を一つに絞る | 契約の範囲が小さくなる |
| 七 | 動く理由：いまうまくやっている人に聞いて一枚に | かからない |

一・二・五・七は発注の前に社内で変えられます。三と四は教える人の時間が要り、六は契約の設計です。

## 機能しているかを見る記録

| 見ること | 機能している目印 |
|---|---|
| 採った人の入社から最初の案件までの日数 | 短ければ採る数と案件の型が機能 |
| 研修中と待機中の離職 | 減っていれば体制と待機が機能 |
| 経験者からの返信の数 | 増えていれば動く理由が機能 |
| 週次の一枚と、型が次の募集に写せたか | 写せていれば記録が機能 |
| 任せた工程の数字 | 動いていれば工程が機能 |

件数のまま並べ、前の募集と比べます。割合や外部の平均で断定しません。見る指標は[採用代行との定例会で見るべき数字](/media/rpo-teirei/)に書いています。

## 法令上の整理は専門家に

派遣と請負の線引き、常駐先での指揮命令の扱い、待機中の労務の扱いは、法令上の整理があると一般に整理されていて、求人票と面接で候補者に説明する内容に関わります。専門家（社労士等）の確認を経た内容で進め、代行の担当者が独自に説明する形にはしません。個別の判断は専門家にご確認ください。線引きの考え方は[採用代行と人材派遣の違い](/media/rpo-haken-tono-chigai/)に書いています。

## まとめ

- 代行が機能するかは**代行の腕より発注側の条件**で決まる
- 七つの対は**採る数・案件の型・体制・待機・動く理由・記録・工程**
- 最も多い機能しない条件は**体制**。未経験の募集の前に研修の一枚
- 採る数は**一枚から**。「案件が取れそうだから何人でも」は機能しない
- **「全部任せたい」は機能しない**。営業を兼ねる責任者は一枚・型・配属に絞り、残りを任せる
- 変える順番は**採る数→案件の型→体制→待機→記録→工程→動く理由**
- **法令上の整理は専門家に**。個別の判断は専門家にご確認ください

## よくある質問

### 案件の見込みが読めず、一枚が作れません

見込みを「確定・高い・低い」の三段で分け、確定と高いだけを採る数の根拠にします。低い見込みは一枚に載せるが数えない。最初は営業の感覚で三段に分けるだけでよく、月次で「見込みどおりだったか」を見て、確度の付け方を直します。一枚は完成させるものではなく、月次で直すものです。

### 経験者を採りたいのですが、スカウトの返信が来ません

「SESに転職する理由」が文面に無いことが多い。いまうまくやっている人に「前の会社と違うこと」「ここで続けている理由」を聞き、案件の選び方・還元の考え方・育つ道筋・相談先の実態を一枚にし、文面の二段落目に置きます。「自社開発に行きたい」層は対象から外し、「SESの中で動く理由がある」層に絞ります。実態に動く理由が無ければ、文面では補えず、仕組みを作るほうが先です。

### 代行に出したのに、採った人が待機のまま辞めました

待機が設計されていない条件です。採用の側ではなく、待機中の育成の中身・接点・上限が無いことが原因で、代行の問題ではありません。待機を「次の案件の型に向けた育成の期間」として設計し、週次の接点と上限を置きます。上限を超える前に一枚に戻し、採る数を見直します。待機の設計が無いまま採用を続けると、同じことが繰り返されます。
