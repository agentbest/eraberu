新卒採用を始める会社から、「いつ何をすればよいのか」「インターンシップで会った学生に、いつから選考の話をしてよいのか」と聞かれます。中途採用と違い、新卒には年度ごとの日程の原則があり、そこにインターンシップの取扱いが重なるため、順番を知らないまま動くと、学生に伝える内容や情報の使い方でつまずきます。結論を先に書くと、**新卒採用の日程は、政府の関係省庁連絡会議が毎年度まとめる「就職・採用活動日程に関する考え方」に沿って、広報活動が卒業・修了年度に入る直前の3月1日以降、採用選考活動が卒業・修了年度の6月1日以降、正式な内定日が10月1日以降を原則としています。これは企業の採用活動を法的に拘束するものではなく要請ですが、インターンシップで取得した学生情報をいつから使えるかは、三省合意で実施時期ごとに分けられています。**自社の設計は、この原則と、実態としての早期化の両方を前提にして決めます。中途との配分は[新卒と中途のどちらに投資すべきか](/media/rpo-shinsotsu-ka-chuuto/)に、実務の手順は[新卒採用の実務の進め方](/media/rpo-task-shinsotsu-unyou-susumekata/)に書いています。

## 日程の原則

内閣官房の「2027年度卒業・修了予定者の就職・採用活動日程に関する考え方」（令和7年12月26日、就職・採用活動日程に関する関係省庁連絡会議）は、従来同様、次の日程ルールを原則としています。

| 区分 | 時期 |
|---|---|
| 広報活動開始 | 卒業・修了年度に入る直前の3月1日以降 |
| 採用選考活動開始 | 卒業・修了年度の6月1日以降 |
| 正式な内定日 | 卒業・修了年度の10月1日以降 |

同資料には、専門活用型インターンシップ（実施期間は2週間以上）に参加した人材についての採用選考活動開始の例外は従前のとおりとする、という注が付いています。

日程の位置づけについて、同資料は次のように書いています。2017年度まで日本経済団体連合会が「採用選考に関する指針」を策定していたが、採用活動の多様化等を踏まえ、2018年以降、政府において毎年度、関係省庁連絡会議を開催し、「就職・採用活動日程に関する考え方」を取りまとめ、経済団体等に要請を行っている。そして、**企業の採用活動は本来企業自身による自由な経済活動の性格を有するものであり、本要請は企業の採用活動を法的に拘束するものではない**が、学生が学業等に専念し、安心して就職活動に取り組める環境の実現を目指して行うものである、としています。

つまり、守らなければ罰則がある種類のものではありません。ただし、要請に沿って動くことが学生と大学からの信頼に関わり、「オワハラ」等の防止に向けた取組みの要請も同時に行われています。同資料は、都道府県労働局・ハローワークが学生からの相談を受け付け、事実確認の上で適切に対処すること、大学のキャリアセンター等と連携することにも触れています。

## 実態は早期化している

同じ資料には、政府が把握している実態も書かれています。要点は、原則の日程と実際の動きがずれている、ということです。

- インターンシップ等には学生の約7割が参加しており、参加は卒業・修了前年度の7月から本格化している
- インターンシップ等への参加者の約7割は「早期選考の案内」を受け、約6割はその後の採用説明会・セミナーに参加、約5割はその後の採用試験や面接等を受けている
- 4月までに累計で学生の約9割が採用面接を受け、約7割が内々定を得ている
- 企業側では、広報活動を2月以前に開始した企業が約6割、採用選考活動を5月以前に開始した企業が約7割

この数値は、内閣府の学生アンケートおよび文部科学省の企業・大学等へのアンケートに基づくものとして同資料に記載されているものです。資料は、2028年度（2029年3月）以降の卒業・修了予定者の就職・採用活動について、経済界や大学側と十分に議論を行い、実効性ある合意点を丁寧に探りながら見直しの検討を進める、としています。**日程の枠組みは今後変わる可能性がある**ということなので、年度ごとに連絡会議の資料を確認する前提で設計します。

### エラベルの見解

新卒を始める会社が最初に迷うのは、「原則に合わせるか、実態に合わせるか」です。ここで決めるべきなのは時期そのものではなく、**自社が学生と出会う場所**です。実態が早いのは、インターンシップ等が実質的な出会いの場になっているからで、3月の広報解禁から動き始める会社は、その時点で学生の多くがすでに複数社と接点を持っている状態に入ります。原則を守りながら早い時期に出会うには、インターンシップを含むキャリア形成支援の取組を設計し、その情報の使い方を三省合意に沿って管理する、という形になります。エラベルで担当者を選ぶ企業には、「3月から始める前提ですか、それとも前年の夏から接点を作る前提ですか」を、私たちから先に聞いています。この一つで、必要な準備の時期も人手も変わります。インターンの設計は[インターンをどう設計するか](/media/rpo-intern-sekkei/)に書いています。

## インターンシップで得た学生情報をいつ使えるか

文部科学省・厚生労働省・経済産業省の「インターンシップを始めとする学生のキャリア形成支援に係る取組の推進に当たっての基本的考え方」（令和4年6月13日一部改正）は、学生のキャリア形成支援に係る産学協働の取組を四つの類型に整理し、そのうちタイプ3とタイプ4をインターンシップとしています。

| 類型 | 名称 |
|---|---|
| タイプ1 | オープン・カンパニー |
| タイプ2 | キャリア教育 |
| タイプ3 | 汎用型能力・専門活用型インターンシップ |
| タイプ4 | 高度専門型インターンシップ（試行） |

そのうえで、令和5年度以降の取組で取得した学生情報の取扱いを、実施（開始）時期ごとに次のように整理しています（令和6年度以降の卒業・修了予定者が対象）。

| 取組の実施（開始）時期 | 基本的な取扱い | 趣旨を含むことが示された場合 |
|---|---|---|
| 卒業・修了前年次2月末まで（広報活動開始時期「前」） | 学生情報は、広報活動・採用選考活動に使用できない | タイプ3のインターンシップに限り、3月以降は広報活動に、6月以降は採用選考活動に使用できる |
| 卒業・修了前年次3月〜卒業・修了年次5月末まで（広報活動開始時期「後」かつ採用選考活動開始時期「前」） | 学生情報を広報活動に使用できる | タイプ3のインターンシップに限り、6月以降は採用選考活動に使用できる |
| 卒業・修了年次6月以後（採用選考活動開始時期「後」） | 学生情報を使用できる | — |

なお同資料は、広報活動・採用選考活動において、学生が企業に対し自ら提出したエントリーシートや成績表等にタイプ1〜4の取組への参加事実やフィードバック結果が記載されている場合は、他の成績書類と同様に使用して差し支えない、としています。

## タイプ3の要件

上の表で「タイプ3に限り」とされている扱いを使うには、タイプ3の要件を満たす必要があります。同資料の別紙2は、産学協議会基準に準拠したインターンシップの要件として次を挙げています。

| 要件 | 中身 |
|---|---|
| 就業体験要件 | 就業体験を行うことが前提。実施期間の半分を超える日数を職場での就業体験に充てる（テレワークが常態化している場合はテレワークを含む） |
| 指導要件 | 就業体験では職場の社員が学生を指導し、終了後に学生へフィードバックを行う |
| 実施期間要件 | 汎用的能力活用型は5日間以上、専門能力活用型は2週間以上 |
| 実施時期要件 | 学業との両立に配慮する観点から、大学の正課および博士課程を除き、学部3年・4年ないし修士1年・2年の長期休暇期間（夏休み、冬休み、入試休み・春休み）に実施する |
| 情報開示要件 | 募集要項等に9項目（趣旨、実施時期・期間・場所・募集人数・選抜方法・無給/有給等、就業体験の内容、求められる能力、フィードバック、採用活動開始以降に限り学生情報を活用する旨、実施計画、実績概要、採用選考活動等の実績概要）を記載し、HP等で公表する |

「1日の職場見学」や「説明会に作業体験を付けたもの」は、この要件に当たりません。自社の取組がどの類型かを決めずに「インターン」と呼ぶと、情報の使い方を誤ります。

### エラベルの見解

新卒の日程で最も多い事故は、悪意のない情報の使い方です。前年の夏に開いた1日のプログラム（類型でいえばタイプ1にあたることが多い）で集めた学生の情報を、そのまま秋に「早期選考のご案内」として使ってしまう。実施した側は接点を続けたいだけですが、取扱いの整理からは外れます。防ぐ方法は単純で、**プログラムごとに「これはタイプいくつか」「取得した情報をいつから何に使えるか」を、実施の前に一枚にしておく**ことです。運用を代行に出す場合も、この一枚を先に渡します。エラベルで担当者を選ぶ企業には、「夏のプログラムで集めた学生情報を、いつから何に使う予定ですか」を、私たちから先に聞いています。答えが決まっていないなら、募集を出す前に決めるところからです。

## 年間の動き（原則に沿って組む場合）

上の原則と取扱いを前提に、卒業・修了前年度から入社までを並べると、次のようになります。時期は原則に沿ったもので、自社の方針によって前後します。

| 時期 | 動き | 主に動く工程 |
|---|---|---|
| 前年度 春 | 要件と人数の決定。プログラムの設計（類型を決める）。情報開示要件に沿った募集要項の公表 | 要件、設計 |
| 前年度 夏（長期休暇） | インターンシップ等の実施。学生への就業体験とフィードバック | 受け入れ、運用 |
| 前年度 秋〜冬 | 実施の振り返り。冬のプログラム。学生情報は取扱いの整理に沿って管理 | 運用、記録 |
| 前年度 3月1日以降 | 広報活動開始。説明会、エントリーの受付、求人情報の公開 | 母集団形成、一次対応 |
| 卒業年度 6月1日以降 | 採用選考活動開始。面接、選考 | 日程調整、面接 |
| 卒業年度 10月1日以降 | 正式な内定日。内定式 | 内定者フォロー |
| 卒業年度 10月〜3月 | 内定者フォロー、入社準備 | フォロー、受け入れ準備 |
| 入社 4月 | 入社、受け入れ | オンボーディング |

内定を出してからの接点は[内定者フォローの進め方](/media/rpo-task-naitei-follow-susumekata/)に、入社後の定着は[新卒が定着しない](/media/rpo-shinsotsu-teichaku/)に書いています。

## 代行に出せる工程と社内に残す工程

| 工程 | 任せられるか |
|---|---|
| 要件と人数の決定、プログラムの類型の決定 | 残す |
| 学生情報の取扱いの方針（いつから何に使うか） | 残す |
| 募集要項の作成と情報開示（9項目の記載） | 一緒に |
| 説明会・エントリーの運用、一次対応、日程調整 | 任せられる |
| 就業体験の受け入れ、社員によるフィードバック | 残す |
| 面接、見極め | 残す |
| 内定者フォローの運用（連絡、日程、記録） | 任せられる |
| 内定を出す判断、条件 | 残す |
| 記録と報告（応募・段ごとの日数・辞退の理由） | 任せられる |

新卒は、前年度の夏から入社まで一年以上続き、中途と違って同じ時期に大量の一次対応が発生します。運用を外に出し、要件と見極めと受け入れを社内に残す形が合います。代行に出す範囲の考え方は[新卒採用の運用は代行に出せるか](/media/rpo-task-shinsotsu-unyou-daikou/)に、内定者フォローは[内定者フォローは代行に出せるか](/media/rpo-task-naitei-follow-daikou/)に書いています。

## まとめ

- 原則は**広報3月1日以降・選考6月1日以降・正式な内定10月1日以降**（関係省庁連絡会議）
- この要請は**企業の採用活動を法的に拘束するものではない**が、学生と大学からの信頼に関わる
- 実態は早期化しており、資料自体が**2028年度以降の見直しの検討**に触れている。年度ごとに確認する
- インターンシップで得た学生情報は、**実施時期と類型（タイプ3かどうか）で使える時期が違う**
- タイプ3には**就業体験・指導・実施期間・実施時期・情報開示**の要件がある
- プログラムごとに「類型」と「情報をいつから何に使うか」を**実施の前に一枚**にする
- 運用は外に出せる。**要件・見極め・受け入れ**は社内に残す

## よくある質問

### 要請に従わない会社もあります。自社も早く動いてよいのでしょうか

要請は法的に拘束するものではない、と資料自体が明記しています。そのうえで、早く動く場合に確認すべきなのは、日程そのものより情報の使い方です。インターンシップ等で取得した学生情報を広報活動・採用選考活動に使う時期は三省合意で整理されており、ここを外すと、学生と大学との関係に影響します。早く出会うこと自体は、タイプ3の要件を満たすインターンシップを設計すれば、整理の中でできます。

### 中小企業で、3月から始めて間に合いますか

同じ資料には、中小企業においては内定が本来出るべき10月1日の時点で必要な内定者数を確保できておらず、人材確保に苦しんでいる状況も見られる、という経済界からの指摘が記載されています。3月から始める前提であれば、母集団の作り方（学校との関係、地域の経路、紹介）と、返事と日程の速さで差をつけることになります。前年度の夏から接点を作る前提に変えるなら、プログラムの設計と受け入れの体制が先に要ります。どちらを選ぶかは、社内で受け入れに割ける人手で決めます。

### インターンシップの運用を代行に出しても、学生情報の管理は大丈夫ですか

管理の方針（どの類型で、取得した情報をいつから何に使うか、誰が保管するか）を社内で決め、一枚にして代行に渡すのが前提です。運用（募集要項の公開、応募の受付、日程、当日の連絡、記録）は外に出せますが、方針の決定と、就業体験での指導とフィードバックは社内に残ります。個人情報の取扱いについては、委託先との契約と社内の規程に沿って決める必要があるため、個別の判断は専門家にご確認ください。
