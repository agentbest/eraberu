副業で人事を受けていると、依頼先から「本人に辞めてもらう方向で話したい」と相談されることがあります。退職勧奨は解雇とは違い、本人が同意して退職するものですが、進め方によっては違法と判断されることがあります。しかも、この領域は人事担当者が一人で抱え込みやすく、面談の場で言ってはいけないことを言ってしまう事故が起きます。この記事は、退職勧奨の前提を、厚生労働省の資料が引用する裁判例に沿って整理したものです。結論を先に書くと、**厚生労働省のパンフレットは、裁判例では被勧奨者の自由な意思決定を妨げる退職勧奨は違法な権利侵害に当たるとされる場合があるとし、最高裁の判決として「ことさらに多数回、長期にわたる退職勧奨は、いたずらに被勧奨者の不安感を増し、不当に退職を強要する結果となる可能性が高く、退職勧奨は、被勧奨者の家庭の状況、名誉感情等に十分配慮すべきであり、勧奨者の数、優遇措置の有無等を総合的に勘案し、全体として被勧奨者の自由な意思決定が妨げられる状況であった場合には、当該退職勧奨行為は違法な権利侵害となる」という内容を引用しています。**個別の事案の判断は必ず弁護士にご確認ください。整理解雇は[整理解雇の4要素](/media/fukugyo-law-seiri-kaiko/)に、懲戒処分は[懲戒処分の要件](/media/fukugyo-law-choukai/)にまとめています。

## 裁判例が示す、線のありか

厚生労働省のパンフレット「適切な労務管理のポイント」には、退職勧奨について次の内容が記載されています。

**違法になり得る場合。**裁判例では、被勧奨者の自由な意思決定を妨げる退職勧奨は、違法な権利侵害に当たるとされる場合がある、とされています。

**最高裁の判決（最高裁第一小法廷 昭和55年7月10日判決）。**パンフレットには、次の内容が引用されています。「ことさらに多数回、長期にわたる退職勧奨は、いたずらに被勧奨者の不安感を増し、不当に退職を強要する結果となる可能性が高く、退職勧奨は、被勧奨者の家庭の状況、名誉感情等に十分配慮すべきであり、勧奨者の数、優遇措置の有無等を総合的に勘案し、全体として被勧奨者の自由な意思決定が妨げられる状況であった場合には、当該退職勧奨行為は違法な権利侵害となる。」

ここから、実務で意識する観点が読み取れます。

| 観点 | 判決の言葉 |
|---|---|
| 回数 | ことさらに多数回 |
| 期間 | 長期にわたる |
| 勧奨する人の数 | 勧奨者の数 |
| 条件 | 優遇措置の有無 |
| 本人の事情への配慮 | 被勧奨者の家庭の状況、名誉感情等に十分配慮すべき |
| 全体としての評価 | 全体として被勧奨者の自由な意思決定が妨げられる状況であったか |

**退職誘導を目的とした行為。**パンフレットは、同様に、退職誘導を目的とした行為も、退職させるための嫌がらせとして不法行為責任を負うとする裁判例がある、としています。引用されている裁判例（東京地裁平成14年7月9日判決）では、一連の行為が、その経緯に照らすと原告を会社の中で孤立化させ退職させるための嫌がらせといわざるを得ないとされ、長期間にわたり繰り返し行われたこと、会社の代表者らが当初からこのような事実を知りながら特段の防止措置をとらなかったこと、一部の行為は業務命令として行われたことからすると、代表者らの指示ないし了解に基づいて行われたものというべきであるから、民法第709条の不法行為責任を負う、という内容が示されています。

**読み取れること。**「面談で強く迫る」だけが問題になるのではありません。仕事を与えない、孤立させる、といった退職に向かわせるための扱いも、問題になり得るという整理です。パワーハラスメントの指針でも、「管理職である労働者を退職させるため、誰でも遂行可能な業務を行わせること」が過小な要求の該当例として挙げられています。詳しくは[パワハラの判断基準](/media/fukugyo-law-power-hara/)に整理しています。

### エラベルの見解

担当する側から見ると、この領域で副業の人事にできる最も価値のある仕事は、「面談を設計して、担当者を一人にしない」ことです。相談で見ていると、事故が起きるのは、上司が一人で本人と話し、感情的なやり取りになり、その場で言ってはいけないことを言ってしまう場面です。「次はないと思ってほしい」「残っても居場所はない」といった言い方は、判決が指摘する「自由な意思決定が妨げられる状況」に近づきます。担当者本人も、後から「そんなつもりはなかった」と言うしかなくなります。

設計できるのは、誰が同席するか、一回の面談の時間、間隔、回数の上限、何を伝えて何を伝えないか、本人が持ち帰って考える時間をどう確保するか、記録を誰がどう残すか、です。判決が「勧奨者の数」を考慮要素に挙げている以上、複数人で囲む形は避けます。一方で、担当者を一人にしないために同席者を置くことは、記録の正確さと担当者の保護の両方に効きます。この設計は人事の経験がある人にしかできず、しかも事前にしか作れません。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、この局面の設計に関わった経験がある人は、そこを経歴に書いておくと選ばれます。

## 面談の設計と、記録の残し方

副業の人事が作るのは、次の形です。個別の事案での進め方と、伝える内容の適否は、弁護士に確認しながら決めます。

| 論点 | 決めること |
|---|---|
| 誰が話すか | 担当者と同席者。囲む形にしない。判決は勧奨者の数を考慮要素に挙げている |
| 回数と間隔 | 回数の上限と、面談と面談の間隔。判決は「ことさらに多数回」「長期にわたる」を指摘している |
| 一回の長さ | 時間の上限を決め、長時間にしない |
| 場所 | 本人が萎縮しない場所。人目のある場所も、密室も避ける |
| 伝えること | 会社の状況、本人にどう考えてほしいか、条件（優遇措置がある場合） |
| 伝えないこと | 退職しない場合の不利益をほのめかす言い方、人格に関わる言い方 |
| 考える時間 | 持ち帰って考える期間、相談先（家族や専門家）に相談してよいこと |
| 断られたとき | どう終えるか。繰り返さない形をあらかじめ決めておく |
| 記録 | いつ、誰が、何を話し、本人が何と答えたか。面談ごとに残す |
| 合意した場合 | 退職の条件を書面にする。口頭での約束にしない |

**「断られたら終わる」形にする。**判決が「ことさらに多数回、長期にわたる」ことを問題にしている以上、断られた後も繰り返す形は危険です。あらかじめ「一度断られたら、その件はそこで終える」と決めておくと、現場が判断に迷いません。経営が「もう一度話してほしい」と言ったときに、人事が止められる根拠にもなります。

**記録は本人のためでもある。**面談の記録は、会社を守るためだけでなく、本人が後から「何を言われたか」を確かめるためのものでもあります。記録を取ることを本人に伝え、内容を確認してもらう形にすると、双方にとって安全です。

**合意したら書面に。**退職の条件（退職日、退職金や手当の扱い、有給休暇の扱い、会社都合か自己都合か）は書面にします。口頭の約束は、後から食い違います。書面の内容と、離職理由の扱いは、社会保険労務士や弁護士にご確認ください。

**断られた後の扱い。**退職に同意しなかった人に対して、仕事を外す、孤立させるといった扱いをすることは、引用されている裁判例が示すとおり、不法行為責任を問われ得ます。断られた後に本人の処遇をどうするかも、事前に決めておきます。

### エラベルの見解

外に出してよいのは、面談の設計（担当者、同席者、回数、間隔、時間、場所）、伝えることと伝えないことの整理、記録の様式、断られた後の扱いの決めごと、合意した場合の書面の項目の整理までで、「この進め方は違法か」「この言い方は問題か」「この条件でよいか」といった判断は、弁護士の範囲です。副業の人事が面談の場に同席することも、慎重に判断します。同席すれば、後から事実関係の当事者になります。

担当する側から見ると、この局面で依頼先に伝えるべきことは、「退職勧奨は、本人が納得して同意する場合にのみ成立するものだ」という前提です。経営が「辞めてもらうことが決まっている」という前提で話を始めると、面談は説得ではなく圧力になり、判決が指摘する状況に近づきます。同意しない可能性があることを前提に設計し、断られた場合にどうするか（整理解雇を検討するのか、配置を変えるのか、そのまま雇用を続けるのか）を先に決めておく。ここまで整理すると、経営も面談の担当者も落ち着いて臨めます。エラベルでは、依頼側が担当者を選べるので、この整理を持ち込める人は、難しい局面でこそ頼まれています。

## まとめ

- 厚生労働省のパンフレットは、裁判例では**被勧奨者の自由な意思決定を妨げる退職勧奨は違法な権利侵害に当たるとされる場合がある**としている
- 引用されている最高裁の判決は、**ことさらに多数回、長期にわたる退職勧奨**は不当に退職を強要する結果となる可能性が高いとし、**被勧奨者の家庭の状況、名誉感情等に十分配慮**すべきであり、**勧奨者の数、優遇措置の有無等を総合的に勘案**して、**全体として自由な意思決定が妨げられる状況**であった場合には違法な権利侵害となる、という内容
- **退職誘導を目的とした行為**も、退職させるための嫌がらせとして**不法行為責任**を負うとする裁判例が引用されている（孤立化させる、業務命令として行うなど）
- 設計するのは、**担当者と同席者／回数と間隔／一回の長さ／場所／伝えることと伝えないこと／考える時間／断られたときの終え方／記録**
- **一度断られたらそこで終える**形をあらかじめ決めておく。断られた後の処遇も事前に決める
- 副業の人事が持つのは**設計と記録の型まで**。進め方や言い方の適否の判断は弁護士にご確認ください

## よくある質問

### 経営から「何度でも話して同意を取ってほしい」と言われました

引用されている最高裁の判決は、ことさらに多数回、長期にわたる退職勧奨は不当に退職を強要する結果となる可能性が高いとしており、全体として自由な意思決定が妨げられる状況であった場合には違法な権利侵害となる、という内容です。この記載を示したうえで、回数と期間の上限を先に決めることを提案します。そのうえで、同意が得られなかった場合にどうするか（整理解雇を検討するのか、配置を変えるのか、そのまま雇用を続けるのか）を経営に決めてもらいます。進め方の適否は弁護士にご確認ください。

### 面談に、副業の人事が同席してもよいですか

慎重に判断します。同席すると、後から事実関係についての当事者になり、記録の正確さや証言の問題に巻き込まれます。設計と記録の様式を作り、社内の担当者が実施する形が無難です。どうしても同席が求められる場合は、役割（記録係なのか、説明する側なのか）を先に決め、契約の範囲に含まれるかを確かめます。実施の前に弁護士に相談しておくことも、あわせて提案します。

### 同意してもらえた場合、何を書面にすればよいですか

退職日、退職金や手当の扱い、有給休暇の扱い、離職理由の扱い、引き継ぎの範囲、会社から貸与しているものの返却、といった項目を書面にします。口頭の約束は後から食い違い、双方にとって不利になります。離職理由の扱い（会社都合か自己都合か）は、本人の失業等給付に関わるので、事実に即した扱いになっているかを確かめます。書面の内容と離職理由の扱いは、社会保険労務士や弁護士にご確認ください。退職に伴う手続の流れは[入退社手続きの流れ](/media/fukugyo-law-nyuutai-shoku/)に整理しています。
