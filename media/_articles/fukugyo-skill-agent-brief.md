紹介会社に「求人票を送っておきました」で済ませると、推薦は求人票の言葉どおりに来て、「幅広い業務」「主体性のある方」の解釈は紹介会社ごとに違い、依頼側は「ずれている」と言います。求人票は候補者に向けて書いたもので、紹介会社が推薦の判断に使う情報（なぜ採るか、過去に見送った理由、条件の幅、返事の期限）は入っていません。結論を先に書くと、**紹介会社への依頼書は、読者を紹介会社の担当者と定め、なぜ採るか・任せる仕事・必須と歓迎・面接で確かめる項目・条件の幅・選考の流れと日数・過去に見送った理由・窓口と返事の期限の八つを一枚にし、必須は経歴で読める言葉で三〜五つ、条件は幅で、候補者に見せてよい情報と紹介会社だけの情報を分け、全社に同じ一枚を同じ日に渡し、月次で見送りの理由から更新します。**紹介会社の管理は[紹介会社を管理する](/media/fukugyo-skill-agent-kanri/)に、要件の一枚は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)に、求人票は[ジョブディスクリプションを書く](/media/fukugyo-skill-jd/)に書いています。ここでは、依頼書の型に絞ります。

## 求人票をそのまま渡すと推薦がずれる

| 求人票の言葉 | 紹介会社に起きること |
|---|---|
| 「幅広い業務」 | 何を任せるか分からず、広く推薦する |
| 「主体性のある方」 | 判断できず、無視される |
| 必須が十行 | 全部を満たす人がおらず、推薦が来ない。または一部を無視して推薦する |
| 「なぜ採るか」が無い | 欠員か増員かで、推薦する層が変わるのに、分からない |
| 条件が「応相談」 | 候補者に伝えられず、面談前に離れる |
| 返事の期限が無い | 推薦しても返事が来ないと思い、後回しにする |

紹介会社の担当者は、複数の依頼側の求人を持っていて、推薦しやすい求人から動きます。推薦しやすいとは、「誰を推薦すればよいかが分かり、返事が来る」求人です。

## 読者は紹介会社の担当者

| 読者 | 知りたいこと |
|---|---|
| 紹介会社の担当者 | 誰を推薦すればよいか。推薦したらどう扱われるか。候補者に何を伝えてよいか |
| その先の候補者 | 求人票で足りる。依頼書は候補者向けではない |

依頼書は、求人票とは別に作ります。求人票を添付し、依頼書は「紹介会社が推薦を判断するための一枚」として渡します。

### エラベルの見解

担当する側から見ると、依頼書で最も差がつくのは、「過去に見送った理由」を載せているかどうかです。受ける側は、要件と条件を丁寧に書きますが、「こういう人は見送りました」を書きません。紹介会社は、要件を読んで推薦しても、見送りの傾向を知らなければ、同じずれを繰り返します。「会社の型が大手だけの方は、裁量の幅で合わなかった」「必須の〇〇が、記述では読めたが面接で確かめられなかった」と、要件の言葉で三行あれば、推薦の精度が変わります。エラベルで担当者を選ぶ企業には、「紹介会社への依頼書に、過去に見送った理由が書いてありますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、依頼書に「見送りの傾向」の欄を作り、月次の記録から三行を写すこと。候補者の個人的な情報は書かず、要件との照合の結果だけです。

## 載せる八つ

| 項目 | 中身 | 出どころ |
|---|---|---|
| なぜ採るか | 欠員・増員・新しい仕事。一文 | 要件の一枚 |
| 任せる仕事 | 三〜五つ。最初の三か月も一行 | 求人票の六つの要素 |
| 必須と歓迎 | 必須は経歴で読める言葉で三〜五つ。歓迎は別枠 | 要件の一枚 |
| 面接で確かめる項目 | 経歴では読めないので、紹介会社に「推薦の理由に書いてほしい場面」として | 要件の一枚 |
| 条件の幅 | 年収の幅、働き方、勤務地。額は面談で。依頼側が出してよい範囲で | 依頼側 |
| 選考の流れと日数 | 段の数、各段の面接官の役割、推薦から結果までの目安の日数 | 面接の設計 |
| 過去に見送った理由 | 要件の言葉で三行。会社の型、必須の読み方 | 月次の記録 |
| 窓口と返事の期限 | 誰に送るか。推薦への一次の返事は何営業日以内 | 依頼側と合意 |

八つで一枚です。会社紹介は求人票と採用ページに任せ、依頼書には入れません。条件の幅を出すかどうか、どこまで出すかは依頼側の判断で、担当者が決めません。条件の出し方の考え方は[スカウト段階で条件を出すか](/media/scout-kyuuyo-teiji/)と同じです。

## 必須は経歴で読める言葉で

| 依頼側の言葉 | 依頼書に書く言葉 |
|---|---|
| 「即戦力」 | 「〇〇の案件を一人で担当した経験。提案から契約まで」 |
| 「経験五年以上」 | 「一人で案件を持ち、トラブルを自分で収めた経験」（年数は歓迎に） |
| 「コミュニケーション力」 | 面接で確かめる項目に。「他部門と意見が分かれた件を合意まで持っていった場面を、推薦の理由に書いてほしい」 |
| 「〇〇の資格」 | 法令上要るなら必須。要らないなら歓迎 |

紹介会社は、候補者の履歴書と職務経歴書で必須を照合します。読める言葉でなければ照合できません。切り分けの型は[採用要件の整理の副業の実務](/media/fukugyo-youken-seiri-shigoto/)に書いています。

## 候補者に見せてよい情報と、紹介会社だけの情報

| 候補者に見せてよい | 紹介会社だけ |
|---|---|
| 任せる仕事、必須と歓迎、条件の幅、選考の流れ | なぜ採るか（前任者の退職など、詳細があるとき） |
| 会社の型、一緒に働く人 | 過去に見送った理由 |
| 求人票の全部 | 返事の期限、窓口 |

依頼書に「候補者に見せてよい範囲」を明記します。明記しないと、紹介会社が「なぜ採るか」の詳細や見送りの傾向を候補者に伝え、依頼側の意図と違う形で情報が広がります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「紹介会社ごとに依頼書の内容を変えたほうが、関係が深まる」というものです。実際には、会社ごとに違う情報を渡すと、推薦の基準が会社ごとに変わり、記録を比べられなくなります。「あの会社には条件の幅を広く伝えた」「この会社には見送りの傾向を伝えていない」が混ざると、推薦のずれが依頼書の違いのせいか紹介会社のせいかが分からなくなります。全社に同じ一枚を、同じ日に渡す。関係の深さは、依頼書の中身ではなく、返事の速さと見送りの理由の戻し方で作ります。受ける側がその場で使える判断としては、依頼書に「版」と「渡した日」を書き、全社に同じ版が渡っているかを一覧で確かめること。版が違う会社があれば、最新の版を渡し直します。

## 月次で更新する

| 見ること | 更新 |
|---|---|
| 見送りの理由の分類 | 「過去に見送った理由」の三行を、直近の傾向に書き換える |
| 推薦が来ない | 必須が多すぎるか、条件の幅が読めないか。依頼側と見直し |
| 推薦は来るが一次に進まない | 必須の言葉が読める言葉になっていない。書き換え |
| 要件が変わった | 必須・歓迎・任せる仕事を書き換え、版を上げる |
| 選考の流れが変わった | 段と日数を書き換え |

更新したら、全社に同じ日に渡し直します。更新の履歴（版、日、変えた箇所）を依頼書の末尾に残します。月次の記録の並べ方は[紹介会社を管理する](/media/fukugyo-skill-agent-kanri/)に書いています。

## 書いてはいけない項目

性別、年齢、国籍、家族の状況、出身地などを条件にする表現や、それを示唆する言い回し（「若手」「〇〇な女性」など）は、募集や採用で法令上の決まりがあると一般に整理されています。依頼書は紹介会社だけが読むものでも、同じです。依頼側から「こういう人を」と口頭で言われても、依頼書には書かず、「その点は書けません。専門家にご確認ください」と伝えます。何が該当するかは、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

また、手数料の率や返金の規定は、依頼側と紹介会社の契約の事項で、依頼書には書きません。契約の条件は担当者が扱いません。

## 依頼側に確認してもらう順番

| 順 | 確認する人 | 確認すること |
|---|---|---|
| 一 | 現場の責任者 | 任せる仕事、必須と歓迎、面接で確かめる項目が実態と合っているか |
| 二 | 依頼側の人事 | 条件の幅をどこまで出すか。候補者に見せてよい範囲。返事の期限を守れるか |
| 三 | 依頼側の決まりに従った確認 | 表現の可否 |

求人票と同じ順で、現場から上に確認します。返事の期限は、依頼側が守れる期限にします。守れない期限を書くと、紹介会社との信頼が落ちます。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「求人票で足りる」と言う | 求人票に無い四つ（なぜ採るか・見送りの傾向・条件の幅・返事の期限）を示し、紹介会社が推薦を判断できないことを伝える |
| 条件の幅を出したがらない | 出すかどうかは依頼側の判断。出さない場合、紹介会社が候補者に伝えられず面談前に離れる構造を添える |
| 必須が減らせない | 「無いと最初に何が困るか」を一つずつ。要件の一枚に戻る |
| 見送りの理由が記録に無い | 今月から記録。依頼書の欄は「今後追記」と明記 |
| 会社ごとに違う版が渡っている | 一覧で版を確かめ、最新を同じ日に渡し直す |
| 返事の期限が守られない | 期限を依頼側が守れる長さに直す。担当者が期限の前日に確認 |

## まとめ

- 求人票は候補者向け。紹介会社には**推薦の判断に使う一枚**を別に
- 読者は**紹介会社の担当者**。会社紹介は入れない
- 載せるのは**なぜ採るか・任せる仕事・必須と歓迎・面接で確かめる項目・条件の幅・選考の流れと日数・過去に見送った理由・窓口と返事の期限**の八つ
- 必須は**経歴で読める言葉で三〜五つ**。性質は面接で確かめる項目に
- **候補者に見せてよい範囲を明記**。条件の幅を出すかは依頼側の判断
- **全社に同じ一枚を同じ日に**。版と渡した日を書く
- **月次で見送りの理由から更新**し、全社に渡し直す
- 基準にしてはいけない項目と契約の条件は書かない。**個別の判断は専門家にご確認ください**

## よくある質問

### 紹介会社から「もっと詳しい情報がほしい」と言われました

何が知りたいかを聞きます。「なぜ採るか」の詳細（前任者の退職の経緯など）なら、依頼側の判断で、紹介会社だけの情報として口頭で伝える範囲を決めます。「一緒に働く人」の詳細なら、求人票の六つの要素に足します。「条件の詳細」なら、依頼側が出してよい範囲の判断です。依頼書を長くするのではなく、定例の場で口頭で補い、依頼書に足すべきものだけを次の版に入れます。

### 複数の求人を一つの依頼書にまとめてよいですか

求人ごとに一枚です。一つにまとめると、必須と条件の幅が混ざり、紹介会社が照合できません。共通の部分（選考の流れ、窓口、返事の期限、候補者に見せてよい範囲）は型にして、求人ごとに八つの残りを差し替えます。求人が多いときは、優先順位（採用計画の順）を添えて、紹介会社にどれから動いてほしいかを伝えます。

### 依頼書を作ったのに、紹介会社の推薦が変わりません

依頼書が読まれていないか、依頼書以外の四つ（社数・返事の期限・見送りの理由の戻し・記録）が揃っていないかのどちらかです。定例の場で依頼書を一緒に読み、「この必須で照合していますか」と確かめます。読まれているのに変わらないなら、返事の期限が守られていないことが多い。紹介会社は、依頼書の良し悪しより、返事が来るかどうかで動きます。四つの揃え方は[紹介会社を管理する](/media/fukugyo-skill-agent-kanri/)に書いています。
