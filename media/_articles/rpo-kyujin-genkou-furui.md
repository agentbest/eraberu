媒体に出している求人原稿は、数年前に前任者が書いたもの。業務の中身も、条件も、組織も、当時と変わっている。直したいが、時間が無く、そのまま更新を押している。応募は年々減り、来ても「原稿と話が違う」と面接で言われる。結論を先に書くと、**求人原稿が古いのは、「直す時間が無い」からではなく、「直す型と、直す担当と、直す頻度」が決まっていないからです。型があれば、一本を直すのに数時間で済みます。まず、いま動いている求人から優先順位を付けて直し、次に、更新が止まらない体制を作ります**。採用サイトの効果が無い場合は[採用サイトを作ったのに効果がない](/media/rpo-shanai-chinmoku/)に、写真や素材が無い場合は[使える写真・素材がない](/media/rpo-shashin-nai/)にまとめています。

## 古い原稿で起きていること

求人原稿が古いまま掲載されていると、次のことが起きます。

| 起きていること | 背景 |
|---|---|
| 応募が減る | 業務の箇条書きが当時のままで、いまの役割の魅力が書かれていない。候補者は他社の新しい原稿と比べている |
| 実態とずれた人が来る | 原稿の業務と、いまの業務が違う。原稿を見て応募した人が、面接で「話が違う」と離れる |
| 条件が古い | 年収の幅、働き方、休日が、制度の変更前のまま。良くなった条件が伝わらず、悪くなった条件は面接で発覚する |
| 組織の情報が古い | 「〇名のチーム」「〇〇部の配属」が変わっている。入社後に「聞いていた組織と違う」 |
| 媒体ごとに内容が違う | 一つの媒体だけ直し、他は古いまま。候補者が複数の媒体で見比べて、不信になる |
| 最終更新日が古い | 媒体に表示される更新日が古いと、候補者は「本気で採っていない」と受け取る |
| 社内の誰も原稿を読んでいない | 現場も責任者も、いまの原稿に何が書いてあるかを知らない |

古い原稿は、応募を減らすだけでなく、合わない人を呼び、合う人を遠ざけます。

## 更新の優先順位の付け方

全部を一度に直すのは無理です。優先順位を付けます。

**いま募集中で、応募が来ていない求人。** 最優先。原稿が古いことが、応募が来ない原因である可能性が高い。

**いま募集中で、実態とのずれで辞退が出ている求人。** 面接で「話が違う」が出ている求人。原稿を直せば、ずれた応募が減り、面接の時間の無駄が減る。

**いま募集中で、条件が変わった求人。** 条件が良くなったのに反映されていない求人は、機会の損失。悪くなったのに反映されていない求人は、面接での不信。

**近く募集する予定の求人。** 募集の前に直しておけば、出した瞬間から新しい原稿。

**募集していないが、媒体に残っている求人。** 掲載を止めるか、直して残すか。止めるなら、止める。放置しない。

**募集していない職種の原稿の型。** 次に募集するときのために、型だけ整えておく。急がない。

優先順位を付ければ、「全部直さないと」の重さが消え、一本ずつ進められます。

## 原稿を直す手順

一本の原稿を直す手順です。型があれば、数時間で済みます。

**いまの原稿を、現場の責任者と一緒に読む。** 「ここは今も同じか」「ここは変わったか」を、一行ずつ。現場の責任者は、原稿を読んだことが無いことが多く、読めば「ここは違う」がすぐ出ます。三十分。

**役割を、いまの言葉で書き直す。** 「何を決める役割か」「誰と働くか」「どこまで担うか」。業務の箇条書きではなく、役割の記述に。現場の責任者の言葉を、そのまま使います。

**「この会社で働く理由」を足す。** 古い原稿には、業務と条件しか無いことが多い。「なぜこの役割が要るのか」「この役割で何が得られるか」を、現場の責任者と話して書きます。

**条件を、制度の現在の内容に合わせる。** 年収の幅、働き方、休日、手当。制度の担当（労務）に確認し、規程のとおりに正確に書きます。

**組織の情報を、現在に合わせる。** チームの人数、配属先、一緒に働く人。数字は自社の記録から。

**要件を、「必須」と「あれば良い」に分ける。** 古い原稿は、要件が全部必須に見えることが多い。分ければ、応募の入口が広がります。

**選考の流れと速さを書く。** 「書類の判断は三日以内、面接は二回、内定まで三週間」。古い原稿には無いことが多い項目です。

**現場の責任者に、最終の確認をしてもらう。** 「これで、いまの実態と合っているか」。合っていれば、公開。

直した日を記録します。次の更新のときに、「いつ、何を直したか」が分かります。

## 直す型の作り方

一本を直したら、その手順を型にします。次からは、型に沿って直します。

| 項目 | 型の内容 |
|---|---|
| 構成 | 役割・誰と働くか・どこまで担うか・この会社で働く理由・要件（必須とあれば良い）・条件・組織・選考の流れ・応募の方法 |
| 各項目の書き方 | 項目ごとに、良い例と悪い例を一つずつ。「業務の箇条書き」が悪い例、「役割の記述」が良い例 |
| 確認する相手 | 役割と組織は現場の責任者、条件は労務、全体は採用の責任者 |
| 確認の観点 | 「いまの実態と合っているか」「候補者が読んで、自分がやることを想像できるか」「条件は規程のとおりか」 |
| 直す頻度 | 募集の開始時、条件や組織の変更時、三か月ごとの定期 |
| 直した記録 | 直した日、直した項目、確認した相手を一行で |
| 媒体ごとの調整 | 原本を一つ持ち、媒体の形式に合わせて調整する。原本を直したら、全媒体に反映 |

型があれば、原稿を直すのは「型に沿って埋める作業」になり、誰がやっても同じ質になります。前任者が辞めても、型が残れば続けられます。

型の作り方は、[採用のやり方が分かる人が社内にいない](/media/rpo-nouhau-nai/)に書いた「六種類の書面」の一つです。

### エラベルの見解

相談で最も多い失敗は、「求人原稿が古いと分かっていたが、直す時間が無く、二年間そのまま更新を押し続けた」というものです。二年の間に、条件は二回変わり、組織は変わり、役割も変わっていました。原稿を見て応募した人が面接で「話が違う」と離れ、面接の時間だけが消えていました。一本を直すのに、現場の責任者と三十分読み合わせて、二時間で書き直せました。「時間が無い」のではなく、「何をどう直せばよいかが分からない」ので着手できなかった、というのが実態でした。

見ていて差がつくのは、担当者が「現場の責任者と一緒に原稿を読む」かどうかです。原稿を机上で直す担当者と、現場の責任者に三十分もらって一行ずつ「ここは今も同じですか」と確認する担当者がいます。後者の原稿は、実態と合い、現場の言葉が入ります。

発注側にできるのは、担当者に「現場の責任者の三十分」を渡すことです。それが無いと、担当者は古い原稿を言い換えるだけになります。

## 更新を続ける体制

一度直しても、また古くなります。続ける体制です。

**担当を決める。** 求人原稿の更新の担当者を一人。人事か、採用代行の担当者。

**頻度を決める。** 募集の開始時、条件や組織の変更時、三か月ごとの定期。カレンダーに入れます。

**変更の連絡が来る形にする。** 条件が変わったら労務から、組織が変わったら現場から、原稿の担当者に連絡が来る形。連絡が無ければ、担当者は変更を知りません。

**三か月ごとに、現場の責任者と読み合わせる。** 募集中の求人について、三十分。「変わったところはあるか」。

**最終更新日を、意識する。** 媒体に表示される更新日が三か月以上前なら、直す。候補者は更新日を見ています。

**直した記録を残す。** 「いつ、何を、誰と」。次の担当者が、履歴を辿れます。

**更新の状況を、月次の報告に入れる。** 責任者への月次の報告に、「原稿の更新の状況」を一行。放置されにくくなります。

体制は、担当と頻度と連絡の形の三つで足ります。難しい仕組みは要りません。

## 媒体ごとの反映

複数の媒体に出している場合、直した原稿を全媒体に反映します。

**原本を一つ持つ。** 媒体ごとに別々に書かず、原本を一つ持ち、媒体の形式に合わせて調整します。原本を直したら、全媒体に反映します。

**媒体ごとの形式の違いを、記録しておく。** 文字数の上限、項目の構成、写真の扱い。媒体ごとの調整の仕方を型にしておけば、反映が速くなります。仕様は各媒体の公式の案内で確認します。

**反映した日を、媒体ごとに記録する。** 「原本を直した日」と「各媒体に反映した日」がずれていると、媒体ごとに内容が違う状態になります。

**紹介会社に渡している求人票も、同じ日に直す。** 媒体だけ直して、紹介会社に渡した求人票が古いままだと、紹介会社の推薦がずれます。

**採用サイトの求人の一覧も、同じ日に直す。** サイトの求人が古いと、候補者が見比べて不信になります。

**スカウトの文面も、原稿に合わせて直す。** スカウトで伝えている役割と条件が、原稿と違えば、返信した候補者が離れます。

反映の漏れは、媒体が増えるほど起きます。媒体が多すぎる場合は[媒体を増やしすぎて管理できない](/media/rpo-media-oosugi/)に書いた棚卸しと合わせて進めます。

## 外注する場合の範囲

求人原稿の更新を、採用代行に出す場合の範囲です。

**出せる工程。** 原稿の棚卸しと優先順位の整理、現場の責任者との読み合わせの進行、役割と働く理由の聞き取りと書き直し、要件の分け方の案、条件と組織の確認の依頼（労務と現場への確認は担当者が取りまとめ）、原本の作成と媒体ごとの調整、全媒体・紹介会社・サイト・スカウト文面への反映、直した記録、型の作成、三か月ごとの定期の読み合わせの設定と進行、月次の報告への反映。

**社内に残す判断。** 役割と要件の決定、条件の決定、公開の承認、現場の責任者の三十分の確保。

**外注の効きどころ。** 原稿の更新は、「型に沿って埋める作業」と「現場と労務への確認」の手間の問題です。担当者が手順と反映を回し、社内の人は読み合わせの三十分と承認だけで済みます。担当者は複数の会社の原稿を見ているので、「候補者が読んで想像できる書き方」を持ち込めます。

**外注しても動かない場合。** 現場の責任者が読み合わせの三十分を出さない、条件の変更が担当者に伝わらない、承認が遅い。社内の判断で、代行を替えても直りません。

原稿の更新は、時間ではなく型の問題です。外注は、型を持ち込み、回す手段です。

### エラベルの見解

担当する側から見ると、原稿が古い会社の相談で最も多いのは、「原稿を直す＝一から書き直す」と思っている」ことです。一から書き直すのは重いので、着手できません。実際は、現場の責任者と一行ずつ「ここは同じか、違うか」を確認し、違うところだけ直せば、大半は数時間で済みます。

もう一つ多いのは、「直す前に、まず良い原稿の例を見たい」という要望です。他社の原稿を真似ても、自社の実態にはなりません。良い例より、現場の責任者の言葉です。「この役割は何を決める役割ですか」と聞いて、返ってきた言葉を、そのまま原稿にします。

発注側にできるのは、担当者に「他社の例」ではなく「現場の責任者の三十分」を渡すことです。

## まとめ

- 古い原稿は**応募が減る・ずれた人が来る・条件が古い・組織が古い・媒体ごとに違う・更新日が古い・誰も読んでいない**
- 優先順位は**募集中で応募が無い・ずれで辞退が出ている・条件が変わった・近く募集する・募集していないが残っている・型だけ整える**の順
- 直す手順は**現場と読み合わせ・役割をいまの言葉で・働く理由を足す・条件を規程のとおり・組織を現在に・要件を分ける・選考の流れを書く・現場の最終確認・直した日を記録**
- 型は**構成・各項目の書き方の例・確認する相手・確認の観点・頻度・記録・媒体ごとの調整**
- 体制は**担当・頻度・変更の連絡の形・三か月ごとの読み合わせ・更新日の意識・記録・月次の報告**
- 反映は**原本を一つ・媒体の形式を記録・反映日を記録・紹介会社とサイトとスカウト文面も同じ日に**
- 外注できるのは**棚卸し・読み合わせの進行・書き直し・確認の取りまとめ・反映・記録・型・定期の設定**。社内に残るのは**決定・承認・現場の三十分**

## よくある質問

### 原稿を直す時間が、本当にありません

一本を直すのに要るのは、現場の責任者との読み合わせ三十分と、書き直し二時間ほどです。「一から書き直す」のではなく、「いまの原稿を一行ずつ確認して、違うところだけ直す」形にすれば、重くありません。それでも時間が無いなら、書き直しの二時間を外部の担当者に出し、社内は読み合わせの三十分と承認だけにします。

### 直した原稿で、応募が増える保証はありますか

保証はありませんが、古い原稿は、応募を減らし、合わない人を呼び、合う人を遠ざけています。直せば、少なくとも「実態と違う」で離れる人と、面接での不信は減ります。応募が増えるかどうかは、媒体の選び方、返信の速さ、条件の水準も関わるので、原稿だけで決まりません。ただ、原稿が古いままでは、他を直しても効きにくいです。

### 媒体が多くて、全部に反映するのが大変です

原本を一つ持ち、媒体ごとの形式の調整の仕方を型にしておけば、反映は作業になります。それでも大変なら、媒体の数が多すぎます。過去半年で面接に進んだ人がいない媒体は、切る候補です。媒体を絞れば、反映の手間も減ります。棚卸しの手順は[媒体を増やしすぎて管理できない](/media/rpo-media-oosugi/)に書いています。
