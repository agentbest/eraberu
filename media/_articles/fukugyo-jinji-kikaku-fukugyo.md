人事企画として、人員計画を作り、等級や評価や報酬の制度を設計し、人事の数字をまとめて経営に報告し、制度の改定を通してきた。この経験は、人事の副業、とくに採用まわりの副業で売れるのか。人事企画は本社の仕事で、採用の現場からは離れて見え、小さい会社には制度が要らないようにも思えます。結論を先に書くと、**人事企画の経験は、「人事の課題を数字と構造で捉え、制度と計画に落とし、経営に通してきた」型で売れます。売れるのは、「採用の数字の見える化」「採用計画と人員計画の設計」「採用の条件の枠組みづくり」「経営への報告の型」の四つです。人事の部門が小さい会社では、採用の数字が担当者の頭の中にしかなく、何人応募して何人面接して何人決まったかを経営者が知らず、採用の計画が「欠員が出たら募集」で、採用の条件が毎回の交渉で決まり、経営者への報告が「頑張っています」で終わっています。「企画をしていました」ではなく、「採用を、経営が判断できる数字と計画の形にする」と売ります。**人事責任者の経験の売り方は[人事責任者・CHROが副業でできること](/media/fukugyo-chro-fukugyo/)に、労務の経験は[労務担当が副業でできること](/media/fukugyo-roumu-tantou-fukugyo/)に、人事コンサルタントの経験は[人事コンサルタントが副業でできること](/media/fukugyo-consultant-jinji-fukugyo/)にまとめています。

## この経歴の何が売れるか

人事企画の経験を、依頼側の採用の工程に置き換えた棚卸しです。在籍した会社の制度の内容は含めず、「型」として抜き出します。

| 人事企画の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 人事の数字を集め、経営に見せる形に整えてきた | 採用の数字（応募・面接・内定・入社・辞退）を工程ごとに並べ、どこで落ちているかを見える形にする | 採用の数字が担当者の頭の中にしかない依頼側が多い |
| 事業計画から人員計画を引いてきた | 事業の目標から、いつ・どの職種を・何人採るかを計画に落とし、募集の順番を決める | 採用が「欠員が出たら募集」の繰り返しになっている依頼側が多い |
| 等級・評価・報酬の制度を設計してきた | 採用の条件（年収の枠、等級の当てはめ、手当）を、既存の社員との整合で決める枠組みを作る | 採用のたびに条件が交渉で決まり、後で不公平が出る依頼側が多い |
| 制度の改定を経営会議で通してきた | 採用の予算・体制・条件の変更を、経営者が判断できる材料の形で出す | 人事の議題が経営会議で決まらない依頼側が多い |
| 人事の課題を構造で捉えてきた | 「採れない」を、要件・母集団・選考・条件・受け入れのどこの問題かに切り分ける | 「採れない」の原因が分からず、媒体を変え続ける依頼側が多い |
| 他社の制度や市場の情報を集めて比べてきた | 採用の条件を決めるとき、公開の情報を集めて依頼側に判断の材料として渡す | 条件の妥当性を判断する材料がない依頼側が多い |
| 制度を作った後の運用の定着を追ってきた | 採用の仕組み（要件の型、面接の記録、数字の集め方）が担当者に定着するまでを追う | 仕組みを作っても回らない依頼側が多い |

売れるものの要点は、「採用を、感覚ではなく数字と計画で語れる形にできる」ことです。採用の担当者は、目の前の募集と面接に追われ、数字を集めて経営者に見せる時間がありません。経営者は、数字がないので「もっと頑張れ」しか言えず、担当者は疲弊します。人事企画の経験は、採用の数字を工程で見える形にし、どこに手を打つべきかを経営者と担当者が同じ画面で判断できる形にします。数字の扱いは[数字で語る](/media/fukugyo-suuji/)に、データのスキルは[データを扱うスキル](/media/fukugyo-data-skill/)に、指標の設計は[KPIを設計する](/media/fukugyo-kpi-sekkei-skill/)に書いています。

## 売りにくい点とその扱い

人事企画の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 採用の実務が薄い | 「募集やスカウトや面接はできるのか」。自分にとっても、候補者と向き合う経験が薄い不安 | 募集から内定までの実務は範囲に入れないか、別の担当者と組む。売るのは「数字と計画と枠組み」だと最初に分ける |
| 大きい会社の仕組みに見える | 「等級や評価の制度は、うちの規模には早い」「本社の企画は現場を知らない」 | 制度の話から入らない。採用の数字を一枚にするところから入り、依頼側の規模で「最初に見える化する数字」に絞る |
| 成果が間接的 | 数字を見える化しても、採用が決まるのは担当者と現場で、自分の成果として見えにくい | 「どこで落ちているかが分かり、手を打った」を成果として残す。数字の見える化で「何が決まったか」を報告で示す |

扱い方の要点は、「制度の人ではなく、採用の数字と計画の人として売る」ことです。人事企画の担当者は、自分の経験を制度の言葉で語る癖があり、それが人事の部門が小さい会社の経営者には「うちにはまだ早い」と聞こえます。「応募から入社までの数字を一枚にして、どこで落ちているかを見せます」「事業の目標から、募集の順番を決めます」と、採用の数字と計画の言葉で語れば、同じ経験が今の依頼側に必要なものとして伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、人事企画から転身して続いている人と、面談で止まる人の差は、最初に制度の話をするか、数字の話をするかです。止まる人は、等級や評価の制度の整備を提案し、依頼側の経営者は「まず人を採りたい」と感じて終わります。続いている人は、「先月、何人応募して、何人面接して、何人内定を出して、何人辞退しましたか」と聞き、経営者が答えられないところで、「まず、その数字を一枚にします」と言います。経営者は、自分の会社の採用が数字で見えていないことに気づき、そこから頼みます。

見ていて差がつくのは、数字の見える化を、担当者の負担にならない形で設計しているかです。人事企画の経験がある人は、集める項目を丁寧に設計しがちで、項目が多いと採用の担当者は入力しなくなり、数字が止まります。工程ごとの人数と辞退の理由だけに絞り、担当者が週に一度数分で更新できる形にした人は、数字が回り、経営者と担当者が同じ画面で話せるようになり、依頼側から「初めて採用の会議が数字で進んだ」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「採用を、経営が判断できる数字と計画の形にする」と採用の言葉で書いている担当者に、数字がなくて困っている依頼側がついています。人事企画の転身は、制度の設計ではなく、採用の数字の一枚から始まります。

## 案件の探し方

人事企画から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 採用の数字の見える化 | 人事の数字を整えてきた経験でそのまま入れる | 「採用の数字が頭の中にしかない依頼側」を探す |
| 採用計画と募集の順番の設計 | 人員計画の経験で入れる | 「欠員が出たら募集、の依頼側」を探す |
| 採用の条件の枠組みづくり | 報酬と等級の設計の経験で入れる | 「採用のたびに条件が交渉で決まる依頼側」を探す |
| 経営者への報告の型づくり | 経営会議で通してきた経験で入れる | 「採用の報告が『頑張っています』で終わる依頼側」を探す |
| 「採れない」の切り分け | 課題を構造で捉えてきた経験で入れる | 「媒体を変え続けている依頼側」を探す |
| 採用の仕組みの定着の支援 | 制度の運用の定着を追ってきた経験で入れる | 「仕組みを作っても回らない依頼側」を探す |

探し方の要点は、「採用の数字が見えていない会社」から入ることです。数字が見えていて、計画があり、条件の枠組みがある会社では、人事企画の経験は既存の人事と重なります。採用の担当者が一人で、経営者が数字を知らず、募集の順番も条件も場当たりの会社では、人事企画の経験は重ならずに効きます。案件の相談で「採用がうまくいっているのか分からない」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。人事企画の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 数字の見える化の成果物 | 一枚の集計の型と、集め方の手順は、成果物として形が明確 | 一式の成果物で受ける |
| 採用計画の成果物 | 事業の目標から引いた採用の計画は、成果物で受けやすい | 一式の成果物で受ける |
| 経営者への報告の運用 | 月に一度の報告の作成と同席は、回数で受けやすい | 月に何回・何分で決める |
| 採用の実務を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 制度の言葉での見積もり | 「制度の設計」で出すと、依頼側の規模には早いと判断される | 採用の数字と計画の言葉と成果物で示す |
| 成果の間接性 | 採用が決まるのは担当者と現場で、数字の見える化の価値は「何が決まったか」で示す | 「数字を見て、この手を打つと決まった」を報告で残す |
| 成果報酬の扱い | 採用の成否は担当者と現場の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「成果物一式と報告の回数で受け、制度の言葉で見積もらない」ことです。人事企画の工程は、数字の型と計画と枠組みという成果物が明確で、成果物で受けると単価の根拠が伝わります。数字の見える化は一度作ると依頼側に残るので、その後は「月に一度、数字を見て経営者と担当者が手を打つ会議」の作成と同席を回数で受け、更新の根拠にします。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、数字に出ない成果の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

人事企画から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、制度と人事の数字の守秘の条件を確認する | 個別の判断は専門家に |
| 二、「人事の課題を数字と構造でどう捉え、どう経営に通してきたか」を、会社の情報を含まない型として書き出す | 数字の集め方、切り分けの順番、経営者への出し方 |
| 三、制度の言葉を、採用の数字と計画の言葉に置き換える | 「人員計画」→「事業の目標から決める募集の順番」、「報酬制度」→「採用の条件の枠組み」 |
| 四、得意な工程（数字・計画・枠組み・報告）と、薄い工程（募集・スカウト・面接・候補者対応）を分ける | 正直に示す準備 |
| 五、範囲を、採用の数字の見える化、採用計画、条件の枠組み、経営者への報告、切り分けに絞る | 採用の実務は最初は範囲外か、別の担当者と組む |
| 六、「採用を、経営が判断できる数字と計画の形にする」の一言を作る | 「企画をしていました」で終わらせない |
| 七、採用の数字の一枚の見本を、架空の数字で作る | 面談で見せる道具。実在の会社の数字は使わない |
| 八、登録先に、範囲と、成果物の形と、採用の実務を含まないことを登録する | 数字が見えていない依頼側 |
| 九、採用の数字の見える化を一件受け、「数字を見て決まった手」を残す | 次の工程に広げる材料に |

順番の要点は、「七」の一枚の見本を作ることです。人事企画の経験は、口で説明すると「本社の企画の人」に聞こえますが、応募から入社までの数字を工程で並べた一枚を見せれば、「うちの採用をこの形で見せてくれる人」に変わります。架空の数字で、工程ごとの人数、辞退の理由の内訳、前の月との比べ方を一枚にまとめておけば、面談でも登録先でもそのまま使えます。実在の会社の数字は使いません。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、報告の型は[報告のしかた](/media/fukugyo-houkoku/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「人事企画の経験は、制度のある大きい会社でしか使えない」というものです。実際には、人事の部門が小さい会社ほど、採用の数字が見えておらず、計画がなく、条件が場当たりで、経営者が判断の材料を持っていません。そこで求められているのは制度ではなく、採用を数字と計画で見える形にする人で、人事企画の経験はその会社で最も効きます。使えないように見えるのは、制度の言葉で語っているからで、採用の数字の一枚から入れば、規模は関係ありません。

順番として、本業の規定と守秘の条件を専門家に確認し、数字と構造で捉える型を会社の情報を含まずに書き出し、制度の言葉を採用の数字と計画の言葉に置き換え、得意な工程と薄い工程を分け、範囲を数字と計画と枠組みと報告に絞り、経営が判断できる形にする一言を作り、数字の一枚の見本を作り、登録先に範囲と形を登録し、一件受けて数字を見て決まった手を残す。この順番で、人事企画の経験は「大きい会社の制度」から「小さい会社の採用を数字で動かす形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、数字と計画の工程を明確にし、採用の実務を含まないことを示している担当者に、数字がなくて困っている依頼側がついています。人事企画の転身は、制度の設計ではなく、採用の数字の一枚から始まります。

## まとめ

- 人事企画の経験は**「人事の課題を数字と構造で捉え、制度と計画に落とし、経営に通してきた」型**で売れる。**採用の数字の見える化・採用計画の設計・条件の枠組み・経営への報告**の四つ
- **「企画をしていました」ではなく「採用を、経営が判断できる数字と計画の形にする」**と売る
- 売りにくい点は**採用の実務が薄い・大きい会社の仕組みに見える・成果が間接的**。制度の話から入らず、数字の一枚から入り、「何が決まったか」を成果として残す
- 案件は**採用の数字が見えていない会社**から。「採用がうまくいっているのか分からない」が入り口
- 単価は**成果物一式と報告の回数**で。制度の言葉で見積もらない。成果報酬は最初は避け、可否は専門家に確認
- 数字の見える化は、**担当者が数分で更新できる形**に絞る。項目を増やすと止まる

## よくある質問

### 依頼側の経営者から「等級と評価の制度を作ってほしい」と言われました。人事企画の経験があるので受けてよいですか

受けるかどうかは、依頼側の規模と、その制度が今の採用の詰まりに効くかで決めます。人事の部門が小さい会社では、制度を作っても運用する人がおらず、作って終わりになることが多いです。「制度の前に、採用の条件の枠組みだけ先に決めませんか。それで採用のたびの交渉がなくなります」と、今の詰まりに効く小さい形から提案します。制度そのものを受けるなら、運用が回るまでを範囲に含めるかどうかを書面で決めます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、改善の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

### 前の会社の人事の数字や制度の情報を、参考として使ってよいですか

使いません。前の会社の数字と制度の内容は、その会社の情報であり、守秘の条件に関わります。使えるのは、数字の集め方、切り分けの順番、経営者への出し方といった「型」だけで、具体的な数字と制度の中身は新しく依頼側のものを作ります。市場の相場として依頼側に渡す情報は、公開されているものだけを出典とともに渡します。個別の判断は、弁護士や社会保険労務士にご確認ください。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

### 募集や面接の実務ができないと、案件が取れないのではないですか

採用の実務が薄いことは隠さず、「募集と面接は御社の担当者か別の担当者が、私は数字と計画と枠組みと報告を担います」と分担を示します。募集の実務が得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。採用の数字が見えていない依頼側には、募集の実務より数字と計画が求められており、そこでは実務の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
