本業と副業を続けていると、疲れが抜けない。休んでも戻らない気がする。疲れているから副業をやめるべきなのか、疲れは副業につきものなのか。結論を先に書くと、**副業の疲れは、「体の疲れ」「頭の疲れ」「気持ちの疲れ」の三種類に分かれ、原因も戻し方も違います。体の疲れは睡眠と休みで戻り、頭の疲れは副業に触れない時間で戻り、気持ちの疲れは成果が見えることと相談で戻ります。三つを分けずに「疲れた」と一括りにすると、休んでも戻らず、副業そのものをやめる判断に寄ります。疲れの種類を見分け、種類ごとに戻し方を持ち、疲れた状態で案件の判断をしない。疲れをなくすのではなく、種類を見分けて戻すことが、疲労との付き合い方です。**燃え尽きの防ぎ方は[燃え尽きを防ぐ](/media/fukugyo-burnout/)に、休みの設計は[休む設計](/media/fukugyo-yasumi/)に、本業への影響は[本業のパフォーマンスへの影響](/media/fukugyo-honngyou-eikyou/)にまとめています。体の不調が続くときは、副業の設計より先に、医療機関にご相談ください。

## 疲れの三種類の見分け方

疲れは、種類によって兆候が違います。自分の疲れがどれかを見分けます。

| 種類 | 兆候 | 見分け方 |
|---|---|---|
| 体の疲れ | 眠い、体が重い、朝起きられない、集中が続かない | 睡眠時間を戻すと、数日で戻る。休みの日に寝ると楽になる |
| 頭の疲れ | 考えがまとまらない、文章が書けない、判断が遅い、同じことを何度も考える | 副業のことを考えない時間を取ると戻る。寝ても戻らないが、別のことをすると戻る |
| 気持ちの疲れ | 副業の連絡を開くのが重い、意味が見えない、依頼側に会いたくない、「どうせ」と思う | 寝ても、別のことをしても戻らない。成果が見えるか、誰かに話すと少し軽くなる |

見分け方の要点は、「休みの日に寝て楽になるか」を最初に見ることです。寝て楽になれば体の疲れで、睡眠と休みで戻ります。寝ても戻らないが、別のことをすると戻るなら頭の疲れで、副業に触れない時間が要ります。寝ても別のことをしても戻らないなら気持ちの疲れで、成果の見え方と相談が要ります。種類を見分ければ、戻し方が決まります。気持ちの疲れが続く場合は[燃え尽きを防ぐ](/media/fukugyo-burnout/)に書いた段階を確認してください。

## 種類ごとの原因と戻し方

三種類の疲れは、原因も戻し方も違います。

| 種類 | 副業での原因 | 戻し方 | 戻し方を間違えると |
|---|---|---|---|
| 体の疲れ | 夜の稼働で睡眠が削れている。週末も稼働して休みがない。座りっぱなし | 睡眠時間を先に確保し、その残りで稼働する。週に一日は副業に触れず、体を休める。夜の稼働を早朝に変える | 「気合が足りない」と稼働を増やし、悪化する |
| 頭の疲れ | 本業と副業で、頭の切り替えがない。複数の依頼側の情報を同時に持っている。判断が多い | 副業に触れない日を作る。案件の数を減らす。判断を依頼側に仰ぐ形にし、一人で抱えない。通勤や散歩で、副業のことを考えない時間を作る | 「休んだのに戻らない」と、体の疲れの戻し方（寝る）だけを続ける |
| 気持ちの疲れ | 成果が見えない。依頼側から反応がない。一人で抱えている。範囲外の仕事が増えている | 成果を状態で書き出す。依頼側に結果を教えてもらう。仲間や家族に話す。範囲外を断る | 「甘えだ」と抑え込み、燃え尽きに進む |

戻し方の要点は、「頭の疲れ」と「気持ちの疲れ」を、体の疲れの戻し方（寝る）だけで戻そうとしないことです。頭と気持ちの疲れは、寝ても戻りません。「休んだのに戻らない」となり、「副業が合わないのでは」という判断に寄ります。頭の疲れは副業に触れない時間で、気持ちの疲れは成果の見え方と相談で戻します。成果の見え方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、相談相手は[相談できる相手を持つ](/media/fukugyo-mentor/)に、範囲外の断り方は[断り方](/media/fukugyo-kotowaru/)に整理しています。

### エラベルの見解

担当する側から見ると、「疲れたので副業をやめます」と伝えてくる担当者の多くは、体の疲れではなく、頭か気持ちの疲れを抱えています。話を聞くと、睡眠は取れているが、複数の依頼側の情報を同時に持っていて頭が切り替わらない、あるいは、採用が決まらず成果が見えず気持ちが沈んでいる、という状態です。それを「疲れた」と一括りにし、寝ても戻らないので、「副業が合わない」と判断しています。種類を見分けていれば、案件の数を減らすか、成果を状態で見直すかで、続けられた人たちです。

見ていて差がつくのは、疲れた状態で、案件の判断をしないと決めているかです。疲れているときは、判断が「やめる」「断る」「全部引き受ける」のどれかに極端に寄ります。続いている人は、「疲れているときは判断しない。一週間置いてから決める」と決めていて、極端な判断を避けています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠と稼働しない日を明確にしている担当者が、疲れを溜めずに続けています。疲れは、なくすものではなく、種類を見分けて戻すものです。

## 疲れが溜まる副業の形

疲れが溜まりやすい副業の形と、溜まりにくい形を比べます。

| 溜まりやすい形 | 溜まりにくい形 | 疲れの種類 |
|---|---|---|
| 夜の稼働で、睡眠を削っている | 早朝か、睡眠を確保した残りの時間で稼働 | 体 |
| 週末も夜も副業。触れない日がない | 週に一日は副業に触れない日を固定 | 体・頭 |
| 複数の依頼側を同時に持ち、情報が混ざる | 一件か、多くても二件。案件ごとに情報を分ける | 頭 |
| 判断を一人で抱えている | 判断は依頼側に仰ぐ。迷うことは仲間に相談 | 頭・気持ち |
| 成果を採用の可否で見ている | 成果を範囲の中の状態の変化で見る | 気持ち |
| 範囲外の仕事が増えている | 範囲を書面で決め、範囲外は見積もりで返す | 頭・気持ち |
| 締め切りが固い工程で、常に追われている | 締め切りが柔らかい工程か、余裕を持った締め切り | 頭 |
| 連絡がいつでも来て、いつでも返している | 稼働しない日と時間帯を依頼側に伝え、その外では返さない | 頭 |

形の要点は、「複数の依頼側を同時に持つこと」が、頭の疲れの最大の原因だということです。案件の数が増えると、稼働時間が同じでも、頭の中で持っている情報が増え、切り替えの負担が増えます。頭の疲れが続くなら、稼働時間を減らすより、案件の数を減らす方が効きます。案件の数は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、時間帯は[早朝の稼働という選択](/media/fukugyo-hayaasa/)に書いています。

## 疲れた状態でしてはいけない判断

疲れているときは、判断が極端に寄ります。疲れた状態でしない判断を決めておきます。

| してはいけない判断 | 疲れているとどうなるか | 代わりに |
|---|---|---|
| 副業をやめる | 「もう無理」と終了を決める。戻れる道を消す | 一週間止めてから決める。止めるなら一時停止で |
| 新しい案件を受ける | 「断ると次が来ない」と不安で受け、疲れが増える | 一週間置いてから返事をする。「来週お返事します」 |
| 依頼側に不満を伝える | 疲れで言葉が強くなり、関係が壊れる | 疲れが戻ってから、範囲と条件の話として伝える |
| 範囲を広げる | 「頼まれたから」と範囲外を引き受ける | 「範囲を確認してからお返事します」と一度持ち帰る |
| 単価や条件を変える | 「安くてもいいから楽にしたい」と条件を下げる | 更新の節目まで待つ |
| 本業を辞める | 「副業の方が楽」と、疲れの逃げ場として決める | 疲れが戻ってから、理由を分けて考える。[副業を本業にする判断](/media/fukugyo-honngyou-ni-suru/) |

判断の要点は、「疲れているときは、判断を一週間先に送る」ことです。疲れた状態での判断は、「やめる」か「全部引き受ける」かの極端に寄り、どちらも後で後悔します。「来週お返事します」と一言で先に送り、疲れが戻ってから判断します。一週間送っても、ほとんどの判断は間に合います。断り方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、やめる判断は[副業をやめるとき](/media/fukugyo-yameru/)に整理しています。

## 疲れを記録して枠を直す

疲れは、記録すると、原因と枠の直し方が見えます。

| 記録すること | 書き方 | 使い方 |
|---|---|---|
| 週ごとの疲れの種類と程度 | 「体：中。頭：強。気持ち：弱」のように、三種類を三段階で | 頭の疲れが強い週が続くなら、案件の数か判断の量を減らす |
| その週の稼働時間と案件の数 | 週の稼働と、同時に持っていた案件の数 | 疲れと稼働、疲れと案件の数の関係を見る |
| その週の睡眠 | 平均の睡眠時間の目安 | 体の疲れと睡眠の関係を見る |
| 副業に触れなかった日の数 | 週に何日 | ゼロの週が続くなら、休みの固定が崩れている |
| 疲れた原因と思うこと | 「締め切りが重なった」「依頼側の反応がなかった」 | 種類ごとの原因を特定する |
| 戻し方と、戻ったか | 「日曜に寝た→体は戻った。頭は戻らず」 | 戻し方が種類に合っているかを確認する |

記録の要点は、「疲れの種類を三段階で書く」ことです。「疲れた」とだけ書いても、後から何も分かりません。「体：中。頭：強。気持ち：弱」と書けば、頭の疲れが続いていることが見え、案件の数を減らす判断につながります。月に一度、記録を見て、枠を直します。稼働の記録は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、枠の見直しは[長く続けるための設計](/media/fukugyo-choki/)に書いています。

## 疲れと付き合う順番

疲れと付き合う順番です。疲れをなくすのではなく、種類を見分けて戻す形にします。

| 順番 | 内容 |
|---|---|
| 一、睡眠時間を先に確保する | 副業の稼働は、睡眠を確保した残りで。体の疲れの土台 |
| 二、週に一日、副業に触れない日を固定する | 体と頭の疲れを戻す日 |
| 三、案件の数を、一件か二件にする | 頭の疲れの最大の原因を減らす |
| 四、成果を状態で見る習慣を作る | 気持ちの疲れの原因を減らす |
| 五、相談できる相手を持つ | 一人で抱えない |
| 六、週ごとに疲れの種類を三段階で記録する | 「体・頭・気持ち」 |
| 七、疲れているときは判断を一週間先に送る | 極端な判断を避ける |
| 八、月に一度、記録を見て枠を直す | 種類に合った戻し方になっているか |

順番の要点は、「一」の睡眠を、副業の稼働より先に確保することです。副業の疲れの多くは、夜の稼働で睡眠を削ることから始まり、体の疲れが頭と気持ちの疲れに広がります。睡眠を先に確保し、残りで稼働する。この順番が、疲れの土台を作らない方法です。時間の枠の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、稼働の上限は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「疲れているのは、副業が合っていないからだ」というものです。実際には、疲れの種類を見分けると、体の疲れなら睡眠、頭の疲れなら案件の数、気持ちの疲れなら成果の見え方で戻ることが多く、副業そのものが合わないケースは多くありません。疲れを一括りにして「合わない」と判断すると、戻せる疲れで副業をやめることになります。

順番として、睡眠を先に確保し、週に一日副業に触れない日を固定し、案件の数を減らし、成果を状態で見て、相談できる相手を持ち、疲れの種類を三段階で記録し、疲れているときは判断を一週間先に送り、月に一度記録を見て枠を直す。この順番で、疲れは「副業をやめる理由」から「枠を直す材料」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、案件の数と稼働しない日を明確にしている担当者が、疲れを溜めずに長く続けています。疲労との付き合い方は、疲れの種類を見分けることから始まります。

## まとめ

- 副業の疲れは**体・頭・気持ちの三種類**で、原因も戻し方も違う。**寝て楽になるか**で最初に見分ける
- 体の疲れは**睡眠と休み**、頭の疲れは**副業に触れない時間と案件の数を減らすこと**、気持ちの疲れは**成果を状態で見ることと相談**で戻す
- 頭と気持ちの疲れを**寝るだけで戻そうとしない**。「休んだのに戻らない」は種類の間違い
- 疲れが溜まる最大の形は**複数の依頼側を同時に持つこと**。稼働時間より案件の数を減らす
- **疲れた状態で判断しない**。やめる・受ける・範囲を広げる・条件を変える・本業を辞めるは、一週間先に送る
- 疲れは**三段階で記録し、月に一度枠を直す**。体の不調が続くなら医療機関へ

## よくある質問

### 休みの日に寝ても、月曜になると疲れが戻っていません

寝ても戻らないなら、体の疲れではなく、頭か気持ちの疲れです。頭の疲れなら、副業のことを考えない時間（散歩、家族との時間、副業と無関係の趣味）を、休みの日に入れます。寝るだけでは、頭は副業のことを考え続けています。気持ちの疲れなら、成果を状態で書き出し、誰かに話します。どちらか分からなければ、両方を試し、どちらで楽になったかを記録します。それでも続くなら、案件の数を減らすか、一週間止めます。止め方は[燃え尽きを防ぐ](/media/fukugyo-burnout/)に整理しています。

### 疲れていることを依頼側に伝えてよいですか

「疲れている」とは伝えず、「稼働の枠を見直したい」と伝えます。「来月から稼働を〇時間にさせてください」「範囲を□□に絞らせてください」「締め切りに余裕をいただけますか」と、枠と範囲と締め切りの話にします。疲れを伝えると、依頼側は「大丈夫か」と不安になり、任せる範囲を狭めることがあります。枠の話にすれば、依頼側は条件の調整として受け止めます。伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、更新時の条件の直し方は[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/)に書いています。

### 本業も忙しく、副業の疲れなのか本業の疲れなのか分かりません

分けなくて構いません。疲れは一つの体に溜まり、本業と副業で分けて戻すことはできません。副業で直せるのは、副業の枠だけなので、副業の稼働と案件の数と休みを、本業の忙しさに合わせて縮めます。本業が繁忙期なら、副業を一時停止するか、枠を半分にします。本業の疲れを副業で補うことはできず、副業を縮めることで、全体の疲れを減らします。本業への影響の見方は[本業のパフォーマンスへの影響](/media/fukugyo-honngyou-eikyou/)に整理しています。
