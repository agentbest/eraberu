医療業界の会社（病院・診療所・訪問の事業所）が採用代行を検討するとき、動機は「看護師が常に足りず、看護部長が採用に追われている」「事務と補助の職種の募集が止まらない」であることが多い。ただ、医療の採用は、他の業界と違う難しさがあります。職種ごとに資格と免許が前提で配置に法令上の整理があり、病院と診療所と訪問で働き方の型が違い、看護師は夜勤と診療科の実態が定着を左右し、医師は紹介と学閥のつながりで動いて一般の経路が効きにくく、事務と補助の職種は速さで決まる。結論を先に書くと、**医療業界の採用代行は、看護師と事務の母集団形成・一次対応・日程調整・記録は外に出せる一方、資格と配置の要件の決定・診療科と夜勤の実態の判断・現場の見極め・医師の採用は社内に残さないと、採れても配置できず、離れます。**代行に出す前に、難しさを自社の状況で分解し、職種と型ごとに「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[看護師採用を代行に出す判断基準](/media/rpo-kangoshi-rpo/)や[薬剤師採用を代行に出す判断基準](/media/rpo-yakuzaishi-rpo/)に、介護との共通点は[介護業界の採用代行](/media/rpo-kaigo-gyokai-rpo/)に書いています。ここでは、医療業界で共通する切り分けに絞ります。

## 医療業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 資格と免許が前提で配置に法令上の整理 | 職種ごとに資格が要件で、人員の基準と配置に法令上の整理がある | 要件に資格をどう置くかは会社と専門家。代行は照合まで |
| 病院・診療所・訪問で型が違う | 夜勤の有無、診療科、一人で対応する場面、規模が違う | 型ごとに求人票と経路が要る |
| 看護師は夜勤と診療科の実態 | 夜勤の回数、診療科の忙しさ、人員の配置の実態が求人票に無いと入職後に離れる | 実態を先に出すかで応募と定着が変わる |
| 医師は一般の経路が効きにくい | 紹介と大学や学会のつながりで動く。掲載型とスカウトでは届きにくい | 医師の採用は社内（院長・部長）の関係が中心。代行は補助まで |
| 事務と補助は速さで決まる | 医療事務、看護補助、受付は複数に同時に応募し、先に返事が来た所で決まる | 一次対応を残すと流れる |

五つのうち、代行で解決できるのは看護師と事務の母集団形成と速さで、資格・配置・実態・医師は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 資格と配置の要件の決定（人員の基準を含む） | 残す | 会社と専門家。法令上の整理がある |
| 診療科と夜勤の実態の判断（求人票に何を書くか） | 残す | 看護部長と各部門の責任者 |
| 要件を「経歴で読める言葉」に整える | 一緒に | 「〇〇の型の施設の〇〇科で、〇〇を担った経験」に。代行が整え、責任者が確認 |
| 看護師の母集団形成（紹介、学校、資格の区分に合う媒体） | 任せられる | 型があれば外で回せる |
| 事務と補助の母集団形成と一次対応 | 任せられる | 速さが要る工程 |
| 看護師の一次対応（返信・日程） | 任せられる | 看護部長の負担を減らす |
| 書類の一次確認 | 一部任せられる | 「資格・型・診療科・担った範囲」の照合は外で。現場の適性は社内 |
| 現場の見極め（面接、見学） | 残す | 看護部長、各部門の責任者 |
| 医師の採用（紹介、大学との関係） | 残す | 院長と部長。代行は日程と記録の補助まで |
| 受け入れ（最初の三か月、プリセプター、夜勤の開始の時期） | 残す | 現場。離職を減らす要 |
| 条件の判断 | 残す | 会社の判断 |
| 記録と報告 | 任せられる | 職種と部門をまたいで一つの一覧 |

「資格と配置の要件」と「医師の採用」は、医療に特有の残す工程です。人員の基準と配置は、法令上の整理があると一般に整理されているため、会社と専門家が決めます。個別の判断は専門家にご確認ください。

### エラベルの見解

医療業界で多くの会社が見落とすのは、「看護部長の時間」が採用の詰まりになっていることです。看護部長は、現場の管理と教育と労務に加えて、応募への返事と面接の日程と面接と受け入れを一人で担い、返事が数日遅れ、日程が延び、候補者は他の病院で決まります。「一次対応と日程と記録」を外に出し、看護部長は「面接と見学と受け入れの設計」に絞る。それだけで、同じ応募の数から入職する人数が変わり、受け入れの時間ができて離職が減ります。エラベルで担当者を選ぶ企業には、「看護師の応募への返事は、誰が、何日以内に返していますか」を、私たちから先に聞いています。答えが「看護部長が手が空いたときに」なら、代行に出す最初の工程は一次対応です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 職種と型 | 看護師・薬剤師・技師・事務・補助のどれを、病院・診療所・訪問のどの型で採るか。医師は別に |
| 資格と配置の要件 | 資格の区分と人員の基準と配置の関係。法令上の整理は専門家に確認済みか |
| 診療科と夜勤の実態 | 夜勤の回数と開始の時期、診療科の忙しさ、人員の配置を、求人票に書くか |
| 離職の理由 | 退職面談の記録があるか。実態・受け入れ・人間関係・条件のどれか |
| 受け入れ | プリセプターと最初の三か月の到達点と夜勤の開始の時期が、部門ごとにあるか |
| 面接と見学の枠 | 看護部長と各部門の責任者の枠を週に決まった数出せるか |
| 記録の形 | 職種と部門をまたいで一つの一覧があるか |

「資格と配置の要件」は、採用の前に会社と専門家で整理しておきます。

## 職種と型ごとに代行の型が違う

| 職種・型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| 看護師（病院） | 紹介と学校と資格の区分に合う媒体の運用、一次対応 | 診療科と夜勤の実態、見極め、受け入れ。[看護師の採用要件の作り方](/media/rpo-kangoshi-youken/) |
| 看護師（診療所・訪問） | 地域の経路と紹介、一次対応 | 一人で対応する場面の実態、見極め |
| 薬剤師・技師 | 紹介と資格の区分に合う媒体、一次対応 | 部門の責任者の要件と見極め |
| 医療事務・補助・受付 | 地域の掲載型の運用、一次対応（当日の返事） | 部門の責任者の見極め、受け入れ |
| 医師 | 日程と記録の補助 | 院長と部長の関係と判断が中心 |

「医療の採用に強い代行」でも、看護師と事務の速さの型と、医師の補助の型は別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 職種と型ごとの経路 | 「病院の看護師と、訪問の看護師で、経路と文面をどう変えますか」 |
| 資格と配置の扱い | 「資格の区分を書類でどう照合しますか。配置と人員の基準に関わる判断は社内と専門家で持ちます」 |
| 夜勤と診療科の実態の扱い | 「夜勤の回数と診療科の実態を、求人票と初回の連絡でどう伝えますか」 |
| 医師の採用の範囲 | 「医師の採用は院長と部長の関係が中心です。その前提で、どこまで補助できますか」 |
| 担当者の経歴 | 「担当する方は、医療業界のどの職種と型の採用を、どの工程で担った経験がありますか」 |
| 記録の置き場所 | 「職種と部門をまたぐ記録はどこに置きますか。契約が終わったら」 |
| 費用の構造 | 「月額に含まれる工程と職種の数は」 |

費用は、含まれる工程と職種の数で変わり、金額の相場を先に聞くより「同じ工程・同じ職種数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 看護師の応募は来るが、診療科と夜勤の実態で辞退 | 実態を先に出していない | 求人票と初回の連絡に。見学を段に |
| 採れたが、資格の区分で配置と人員の基準に合わない | 要件に区分が無い | 会社と専門家で整理し、要件と一次確認に |
| 事務の応募が来るが、面接に来ない | 返事が遅い | 一次対応を外に出し、当日中に |
| 医師の採用を代行に頼んだが動かない | 一般の経路が効きにくい職種 | 院長と部長の関係を中心に。代行は日程と記録の補助に |
| 採れたが、数か月で離れて、また募集 | 受け入れ（プリセプター、夜勤の開始の時期）が無い | 退職面談で理由を分け、受け入れの一枚 |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「実態」「資格の区分」「速さ」「医師の経路」「受け入れ」に戻ります。

### エラベルの見解

医療業界で「常に募集している」状態は、看護師と事務で原因が違います。看護師は、夜勤と診療科の実態と受け入れ（プリセプターの体制、夜勤の開始の時期）の問題で、離職が採用を上回っている。事務と補助は、返事の速さで他の施設に負けている。同じ「人が足りない」でも、直す場所が違うので、職種ごとに記録を分けて見ます。エラベルは担当者を工程ごと・職種ごとに選べる形にしているので、「看護師の紹介と学校の経路の運用と一次対応」と「事務の当日の返事と日程」を分けて担当者が担い、看護部長は「実態の判断と面接と見学と受け入れ」に絞る、という組み方ができます。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に、受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## まとめ

- 医療業界の難しさは、**資格と配置の法令上の整理・型で違う働き方・看護師の夜勤と診療科・医師の経路・事務の速さ**の五つ
- **看護師と事務の母集団形成・一次対応・日程・記録は任せられ、資格と配置の要件・実態の判断・見極め・医師の採用・受け入れは残す**
- **資格・配置・人員の基準は会社と専門家**。個別の判断は専門家にご確認ください
- 看護部長の時間が詰まり。**一次対応と日程を外に出し、面接と受け入れに絞る**
- 看護師は**夜勤と診療科の実態と受け入れ**、事務は**速さ**、と職種で直す場所が違う
- 医師は**院長と部長の関係が中心**。代行は補助まで

## よくある質問

### 看護部長が「採用は自分の仕事。外に出したくない」と言います

決めることと見極めることは看護部長のままで、外に出すのは「返事と日程と記録」だけです。「返事が数日遅れる間に候補者は他の病院で決まる。返事と日程は外で当日中に、面接と受け入れは看護部長で」と、分担で話します。看護部長の時間が受け入れの設計（プリセプターの体制、夜勤の開始の時期）に戻ると、離職が減り、募集が減ります。それが看護部長の本来の仕事の時間になります。

### 医師の採用も代行に頼めますか

医師の採用は、紹介と大学や学会のつながりで動くことが多く、一般の経路（掲載型、スカウト）では届きにくい職種です。代行に頼めるのは、院長と部長が動く際の日程の調整と記録の補助、医師の紹介会社への依頼書の整理までで、母集団形成そのものは社内の関係が中心です。代行に「医師を採ってほしい」と頼んで動かない場合、原因は代行の腕ではなく、経路の構造です。

### 人員の基準を満たすために、急いで看護師を採らなければなりません

人員の基準と資格の区分と配置の関係は、法令上の整理があると一般に整理されているため、会社と専門家で「どの区分の人が、何人、いつまでに」を先に整理します。整理した区分を要件と依頼書に書き、紹介会社と資格の区分に合う媒体で集め、返事の速さと枠の預かりで縮めます。急ぐほど、実態（夜勤、診療科）を曖昧にせず、入職後の離職を防ぎます。個別の判断は専門家にご確認ください。
