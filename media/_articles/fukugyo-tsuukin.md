往復の通勤で一日一時間以上ある。この時間を副業に使えれば、夜の稼働が減る。ただ、電車で候補者の情報を見てよいのか、依頼側への返信を歩きながら送ってよいのか、どこまでが許されるのかが分からない。結論を先に書くと、**通勤時間に向く副業の作業は、「依頼側の情報を画面に出さない、頭の中で済む準備」だけです。候補者の経歴を電車で開く、依頼側の連絡を駅で返す、求人票を私物の携帯で直す、はどれも、覗き見、誤送信、本業の端末や回線との混同、という事故のもとです。通勤は「考える時間」に使い、「触る時間」は自宅の副業用の環境に置きます。通勤で考えたことを、自宅で短時間で形にする。この分け方で、通勤は副業の時間になり、事故は起きません。**時間の枠は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、端末の線は[私物端末で作業してよいか](/media/fukugyo-tanmatsu/)に、情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)にまとめています。

## 通勤で扱ってはいけない情報の線

通勤中は、公共の場にいます。扱ってはいけない情報の線を、先に引きます。

| 情報 | 通勤で扱うと | 線 |
|---|---|---|
| 候補者の経歴、連絡先、選考の状況 | 隣の人に画面が見える。落とした端末から漏れる。本業の関係者に見られる | 通勤では開かない。自宅の副業用の環境でだけ |
| 依頼側の求人の中身、社内の情報、条件 | 同じ。依頼側が特定される会話や画面 | 通勤では開かない。頭の中で考えるだけ |
| 依頼側とのやり取り（メール、チャット） | 歩きながら返すと、誤送信、宛先違い、本業の連絡との混同が起きる | 通勤では読むだけにするか、読まない。返信は自宅で |
| 依頼側のシステム（採用管理、スカウト媒体） | 公共の回線や本業の回線からの接続。ログインの情報が残る | 通勤では接続しない。[ネットワーク環境の注意](/media/fukugyo-vpn/) |
| 自分の記録（稼働、判断、型） | 依頼側の情報が含まれていれば、同じ | 依頼側の情報を含まない部分だけ、通勤で見てよい |
| 本業の情報 | 副業の作業中に本業の情報が混ざる | 通勤中は、本業と副業のどちらの情報も開かないのが最も安全 |

線の要点は、「依頼側の情報は、通勤では画面に出さない」ことです。副業の情報の事故で多いのは、覗き見と誤送信で、どちらも通勤中に起きやすいものです。依頼側は、担当者が電車で候補者の経歴を見ているとは思っていません。見ていたことが分かれば、契約の問題になります。線は、「開かない」で引きます。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、端末の管理は[パスワードとアカウントの管理](/media/fukugyo-password/)に書いています。

## 通勤に向く作業と向かない作業

線を引いたうえで、通勤に向く作業と向かない作業を分けます。

| 向く作業（頭の中で済む） | 向かない作業（画面と情報が要る） |
|---|---|
| 今週の副業の段取りを考える。何を、いつ、どの順で | 候補者の経歴を読む、選考の判断をする |
| 依頼側への提案の骨子を考える。何を提案し、なぜか | 依頼側への提案の資料を作る |
| 求人票やスカウト文面の「構成」を考える。何を最初に書き、何を削るか | 求人票やスカウト文面を実際に書く、直す |
| 面接官向けの準備資料の「項目」を考える | 準備資料に候補者の情報を入れる |
| 判断に迷っていることを、整理する。何と何で迷い、何が決め手か | 依頼側に判断を仰ぐ連絡を送る |
| 自分の範囲の一言、プロフィールの文面を考える | 登録先のプロフィールを更新する |
| 人事の一般的な知識や、業界の動きを学ぶ（依頼側の情報を含まない） | 依頼側のシステムに接続して作業する |
| 依頼側の情報を含まない、自分の型の改善を考える | 稼働の記録に、依頼側の名前と作業を書く |

向く作業の要点は、どれも「考えること」で、「触ること」ではないことです。副業の作業のうち、考える部分は、実は自宅でやると時間がかかります。自宅の副業の時間は、画面を触る時間として貴重で、考える時間に使うともったいない。通勤で考え、自宅で触る。この分け方で、自宅の副業の時間が短くなり、夜の稼働が減ります。自宅の時間の使い方は[平日夜だけで受けられる案件](/media/fukugyo-heijitsu-yoru/)に整理しています。

### エラベルの見解

担当する側から見ると、通勤時間を副業に使っている人のうち、事故を起こさずに続いている人と、事故を起こす人の差は、「通勤で画面を開くかどうか」の線を引いているかです。続いている人は、通勤では依頼側の情報を一切開かず、考えることだけをして、自宅で短時間で形にしています。事故を起こす人は、「少しだけ」と電車で候補者の経歴を開き、隣の席の人が同じ会社の人だった、という形で問題になります。依頼側にとって、通勤で見られていたことは、「見られたかもしれない」だけで契約の問題になります。

見ていて差がつくのは、通勤で考えたことを、その場で「依頼側の情報を含まないメモ」にしているかです。「提案の骨子：範囲を絞る、理由は三つ」「求人票：最初の一文を仕事内容から」といった、依頼側が特定されないメモを、自分の副業用のメモ帳に残しておけば、自宅で開いたときにすぐ形にできます。考えるだけで残さないと、自宅で思い出すところから始まり、通勤で考えた意味がなくなります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、情報の扱いが丁寧な担当者ほど、依頼側から続けて選ばれています。通勤の使い方は、時間の使い方であると同時に、情報の扱い方です。

## 頭の中で済む準備の種類

通勤で「考える」といっても、漠然と考えると何も残りません。準備の種類を決めておきます。

| 種類 | 通勤で考えること | 残すメモ（依頼側の情報を含まない） |
|---|---|---|
| 段取り | 今週の副業の時間で、何をどの順でやるか | 「火：求人票の構成。木：スカウト文面。土：稼働の記録」 |
| 提案の骨子 | 依頼側に提案したいことの、結論と理由と、想定される反論 | 「結論：範囲を絞る。理由：三つ。反論：人手が減る→期間を区切る」 |
| 文面の構成 | 求人票、スカウト、面接官向けの資料の、構成と削るところ | 「最初の一文は仕事の中身。条件は後。長い部分は表に」 |
| 判断の整理 | 迷っていることの、選択肢と決め手と、依頼側に聞くべきこと | 「AかB。決め手は期間。期間は依頼側に確認」 |
| 学び | 人事の一般的な知識、業界の動き、自分の型の改善 | 「面接の準備資料に、評価の観点を先に書く」 |
| 範囲の一言 | 自分の範囲、プロフィール、次に受けたい案件の条件 | 「範囲：スカウト運用と求人票。週数時間。次は面接設計を一つ試す」 |

種類の要点は、「メモには依頼側の名前も候補者の名前も書かない」ことです。「A社の求人票」ではなく「求人票の構成」、「〇〇さんの選考」ではなく「判断の整理」と書けば、メモが誰かに見られても、落としても、依頼側の情報は漏れません。自宅で開いたときに、自分だけがどの案件のことか分かる形にします。判断の整理の仕方は[分からないことの聞き方](/media/fukugyo-shitsumon-shikata/)に、提案の作り方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に書いています。

## 通勤で作った下書きを自宅で仕上げる流れ

通勤で考えたことを、自宅で形にする流れを固定します。

| 順番 | 場所 | 内容 |
|---|---|---|
| 一、朝の通勤で、今日の副業の作業を一つ決める | 通勤 | 「今日は求人票の構成を考える」 |
| 二、通勤で構成を考え、依頼側の情報を含まないメモに残す | 通勤 | 「最初の一文は仕事の中身。条件は後」 |
| 三、帰りの通勤で、メモを見返し、足りない点を足す | 通勤 | 「削るところ：福利厚生の羅列」 |
| 四、自宅の副業用の環境で、依頼側の情報を開く | 自宅 | 求人票の原稿を開く |
| 五、メモの構成に沿って、短時間で形にする | 自宅 | 考えてあるので、書く時間だけで済む |
| 六、依頼側に送る前に、一度読み直す | 自宅 | 誤送信、宛先、情報の混入を確認 |
| 七、稼働の記録に、自宅の作業時間を書く | 自宅 | 通勤の考えた時間は、稼働に含めるかを依頼側と決めておく |

流れの要点は、「七」の、通勤で考えた時間を稼働に含めるかどうかを、依頼側と決めておくことです。時間で報酬を受ける契約なら、通勤で考えた時間を稼働に含めると、依頼側は「電車で考えた時間に払うのか」と感じることがあります。含めない形にするか、「構成を考える時間」として合意しておくかを、契約のときに決めます。稼働の記録は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、報告は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に整理しています。

## 本業の端末や回線を使わない理由

通勤中は、本業の端末を持っていることが多く、それで副業の作業をしたくなります。使わない理由です。

| 使うと | 何が起きるか |
|---|---|
| 本業の端末で副業のメールを読む | 本業の端末の記録に、副業の情報が残る。本業の会社が端末を確認したときに見える |
| 本業の回線で副業のシステムに接続する | 本業の通信の記録に残る。本業の会社の規則に反することがある |
| 本業の携帯で依頼側と電話する | 通話の記録が本業に残る。本業の会社の費用で副業の通話をした形になる |
| 本業の端末に副業の資料を保存する | 本業の情報と副業の情報が混ざる。退職時に返す端末に副業の情報が残る |
| 副業の端末で本業の情報を見る | 逆も同じ。本業の情報が副業の端末に残る |

理由の要点は、「端末と回線は、本業と副業で完全に分ける」ことです。通勤中に本業の端末しか持っていないなら、副業の作業は「考えること」だけにし、触る作業は自宅の副業用の端末で行います。副業用の携帯を持つなら、通勤で見るのは依頼側の情報を含まないメモまでです。端末の分け方は[私物端末で作業してよいか](/media/fukugyo-tanmatsu/)に、回線の考え方は[ネットワーク環境の注意](/media/fukugyo-vpn/)に、本業に知られる経路は[副業は会社にばれるか](/media/fukugyo-qa-1/)に書いています。

## 通勤の使い方を決める順番

通勤時間を副業に使うと決めたら、この順番で決めます。

| 順番 | 内容 |
|---|---|
| 一、通勤で開かない情報を決める | 候補者、依頼側の中身、やり取り、システム。「開かない」で線を引く |
| 二、通勤で使う端末を決める | 本業の端末は使わない。副業用の携帯を持つなら、メモ帳だけ |
| 三、メモの形を決める | 依頼側と候補者の名前を書かない。自分だけが分かる形 |
| 四、通勤でやる準備の種類を決める | 段取り、提案の骨子、文面の構成、判断の整理、学び、範囲の一言 |
| 五、自宅で仕上げる流れを固定する | 通勤で考え、メモに残し、自宅で開いて形にし、読み直して送る |
| 六、通勤の時間を稼働に含めるかを依頼側と決める | 契約のときに合意しておく |
| 七、通勤で副業をしない日を決める | 毎日使うと疲れる。通勤で本を読む日、休む日も残す |

順番の要点は、「七」の、通勤で副業をしない日も残すことです。通勤は、本業と副業の間の、頭を切り替える時間でもあります。毎日副業のことを考えると、本業に着いたときに副業のことが残り、家に着いたときに本業のことが残ります。週に何日かは、通勤を副業に使わない日にします。休む設計は[長く続けるための設計](/media/fukugyo-choki/)に、時間帯の選び方は[早朝の稼働という選択](/media/fukugyo-hayaasa/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「通勤時間を使えば、副業の稼働が増やせる」というものです。実際には、通勤で増やせるのは「考える時間」で、「触る時間」は増やせません。触る作業を通勤でやろうとすると、依頼側の情報を公共の場で開くことになり、事故のもとです。続いている人は、通勤を考える時間に使って自宅の触る時間を短くし、結果として稼働を増やさずに成果を増やしています。

順番として、通勤で開かない情報を決め、本業の端末は使わず、依頼側の名前を含まないメモの形を決め、段取りや構成や判断の整理を通勤で考え、自宅で開いて短時間で形にし、読み直して送り、通勤の時間を稼働に含めるかを依頼側と決め、通勤で副業をしない日も残す。この順番で、通勤は事故の場所ではなく、副業の質を上げる時間になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、情報の扱いが丁寧で、短い稼働で成果を出す担当者が、続けて選ばれています。通勤の使い方は、時間の工夫ではなく、線の引き方です。

## まとめ

- 通勤に向く作業は**依頼側の情報を画面に出さない、頭の中で済む準備**だけ。候補者や依頼側の情報は通勤で開かない
- 通勤は**考える時間**、自宅は**触る時間**。分けると自宅の稼働が短くなる
- 通勤で考えたことは**依頼側と候補者の名前を含まないメモ**に残し、自宅で開いて形にする
- 準備の種類は**段取り・提案の骨子・文面の構成・判断の整理・学び・範囲の一言**
- **本業の端末と回線は副業に使わない**。通勤で本業の端末しかないなら、考えることだけ
- 通勤の時間を稼働に含めるかは**依頼側と先に決める**。通勤で副業をしない日も残す

## よくある質問

### 副業用の携帯を持っていれば、電車で候補者の情報を見てもよいですか

端末が副業用でも、公共の場で候補者の情報を画面に出すことは避けます。問題は端末ではなく、隣の人に見える、落とす、本業の関係者がいる、という場所の問題です。副業用の携帯で通勤中に見てよいのは、依頼側と候補者の名前を含まない自分のメモまでです。候補者の情報は、自宅の副業用の環境でだけ開きます。個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に整理しています。

### 依頼側から通勤中に急ぎの連絡が来たら、どうすればよいですか

読むのは構いませんが、返信は自宅か、人のいない場所で落ち着いてからにします。急ぎでも、「拝見しました。〇時までに返します」と一言だけ返し、中身の返答は後にします。歩きながら、電車の中で中身のある返信を書くと、誤送信と宛先違いが起きます。稼働しない時間帯を先に依頼側に伝えておけば、通勤中に急ぎの連絡が来ること自体が減ります。連絡の型は[メールの書き方と運用](/media/fukugyo-mail/)に、時間帯の伝え方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

### 車で通勤しています。運転中に副業のことを考えてもよいですか

運転中は、運転に集中してください。副業のことを考えるのは、信号待ちや駐車後ではなく、運転していない時間にします。音声で本や講座を聞くことは、運転に支障がない範囲であれば、学びの時間として使えますが、依頼側の情報を含む音声（面談の録音など）は、車内でも流さないでください。同乗者や、窓を開けたときに外に聞こえることがあります。学びの時間の作り方は[副業で学び続ける](/media/fukugyo-gakushuu/)に整理しています。
