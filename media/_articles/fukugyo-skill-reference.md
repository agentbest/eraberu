「リファレンスチェックをしてほしい」という依頼を、「前職での評判を調べる」「裏を取る」と受け取ると、事故になります。本人の知らないところで前職に連絡する、本人が指定していない相手に聞く、面接の観点と関係ない評判を集める。どれも、個人情報と募集・採用に関わる法令の整理、そして候補者との信頼に関わります。結論を先に書くと、**リファレンスチェックは、本人の同意と依頼側の決まりを前提に、本人が指定した相手に、面接の観点と同じ項目で「過去の場面の事実」だけを聞き、聞いてはいけない項目に触れず、記録と共有の範囲を限定し、結果の扱いは依頼側の判断に残して、担当者は整理までを行います。**会社側から見た手順は[リファレンスチェックの進め方](/media/rpo-task-reference-check-susumekata/)に、代行に出す範囲は[リファレンスチェックは代行に出せるか](/media/rpo-task-reference-check-daikou/)に書いています。ここでは、副業の担当者が関わるときの型に絞ります。

## 「裏を取る」で進めると事故になる

| やってしまうこと | 何が起きるか |
|---|---|
| 本人に知らせずに前職へ連絡 | 本人の同意が無い。個人情報と信頼の両方の問題。転職活動が現職に知られる |
| 本人が指定していない相手に聞く | 同意の範囲外。聞かれた側も答える立場に無い |
| 「どんな人でしたか」と評判を聞く | 面接の観点と関係ない印象が集まり、判断に混ざる |
| 聞いた内容を面接官全員に回す | 共有の範囲が広がり、管理できない |
| 結果で不採用にする判断を担当者がする | 決めるのは依頼側 |

リファレンスチェックは、「調査」ではなく、「本人の同意のもとで、面接で確かめた観点を、第三者の事実で補う」ものです。この位置づけを依頼側と共有してから始めます。

## 前提：本人の同意と依頼側の決まり

| 前提 | 中身 |
|---|---|
| 本人の同意 | 実施すること、聞く相手、聞く項目、結果の用途を本人に説明し、同意を得る。書面の形は依頼側の決まりに従う |
| 依頼側の決まり | 実施するかどうか、どの段階で、誰が、どう記録し、どう保管するか。依頼側の規程と専門家の確認に従う |
| 聞く相手の指定 | 本人が指定した人（前職の上司・同僚など）。依頼側が指定しない |
| 現職への配慮 | 現職に聞く場合は、本人の転職活動が現職に知られる。本人の意向を優先 |

同意の取り方、記録の保管、法令上の整理は、依頼側の決まりと専門家の確認に従います。担当者が「これで大丈夫」と判断しません。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)と[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

### エラベルの見解

担当する側から見ると、リファレンスチェックで最も差がつくのは、「聞く項目を面接の観点に限る」ことができるかどうかです。受ける側は、せっかく前職の人に聞けるのだから、と「勤務態度」「人間関係」「退職の理由」まで聞きたくなります。ただ、面接の観点に無い項目を聞くと、判断の基準に無い情報が集まり、それが合否に混ざります。混ざった判断は、後で説明できません。面接で「迷う」が付いた観点について、「〇〇のような場面で、この方はどう動いていましたか」と、過去の場面の事実だけを聞く。それで、リファレンスチェックは面接の補いとして機能します。エラベルで担当者を選ぶ企業には、「リファレンスで聞く項目は、面接の観点と同じですか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、聞く項目の一枚を、評価シートの観点をそのまま写して作ること。新しい項目を足しません。

## 聞く項目：面接の観点と同じ

| 面接の観点（例） | リファレンスで聞く形 |
|---|---|
| 決まりの無いことを自分で決めて進めた | 「決まりや前例が無い仕事を、この方がどう進めていたか、具体的な場面があれば教えてください」 |
| 他部門と対立した件を合意まで持っていった | 「他の部門と意見が分かれた場面で、この方はどう動いていましたか」 |
| 一人で案件を回した | 「この方が一人で担当していた仕事の範囲を教えてください」 |
| 面接で「迷う」が付いた観点 | その観点だけを重点的に |

聞くのは「事実（場面）」で、「評価（良かったか）」ではありません。「良い人でしたか」と聞くと、答える側は良く言うか、言葉を濁すかで、判断に使えません。「〇〇の場面で、どう動いていましたか」と聞くと、事実が返ります。聞き方の型は[面接質問集を作る](/media/fukugyo-skill-shitsumon-shuu/)の掘る問い（状況・役割・判断・行動・結果）と同じです。

## 聞いてはいけない項目

| 聞かない項目 | 理由 |
|---|---|
| 性別・年齢・国籍・家族の状況・出身地・宗教や思想・健康の状態 | 募集や採用で法令上の決まりがあると一般に整理されている項目。第三者から聞くのも同じ |
| 退職の理由の詳細（本人の私的な事情） | 本人が面接で語った範囲を超えない |
| 前職の内部の情報（機密、他の社員のこと） | 答える側の守秘に関わる |
| 給与や評価の点数 | 依頼側の判断に混ざる。本人の同意の範囲外であることが多い |
| 「良い人でしたか」の総合評価 | 事実ではない |

答える側が自分から話し始めたときも、記録しません。「その点は結構です」と止めます。

## 記録と共有の範囲

| 決めること | 中身 |
|---|---|
| 記録の形 | 観点ごとに、答える側が語った場面の事実。評価や印象は書かない |
| 誰が読むか | 決める人と、依頼側の人事。面接官全員には回さない |
| 保管 | 依頼側の決まりに従う。担当者の手元に残さない |
| 本人への開示 | 依頼側の決まりに従う。担当者が判断しない |
| 答えた人の情報 | 氏名と連絡先は依頼側の記録に。担当者の手元に残さない |

記録は、評価シートの観点と同じ並びにし、「面接ではこう、リファレンスではこう」と横に置けるようにします。突き合わせの形は[見極めの精度を上げる](/media/fukugyo-skill-mikiwame/)と同じです。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「リファレンスで悪い話が出たら不採用」というものです。実際には、リファレンスの結果は、面接の観点を補う材料の一つで、それだけで決めるものではありません。答える側の立場（本人と合わなかった上司かもしれない）、場面の解釈、本人が面接で語ったことの整合。これらを並べて、決める人が決めます。担当者は、面接の記録とリファレンスの記録を観点ごとに並べ、「ここは一致、ここは食い違い」を示すまでです。食い違いがあれば、本人に確かめる機会を設けるかどうかも、依頼側の判断です。受ける側がその場で使える判断としては、リファレンスの記録に「判断」の欄を作らないこと。事実の欄だけにし、判断は決める人が面接の記録と合わせて行います。合否に関わる線は[合否判断に関わってよいか](/media/fukugyo-gouhi/)に書いています。

## 担当者が実施するか、設計だけか

| 関わり方 | 担当者がやること | 前提 |
|---|---|---|
| 設計だけ | 本人への説明の文面、聞く項目の一枚、記録の形、共有の範囲を作る。実施は依頼側 | 契約の範囲に「設計」 |
| 実施も担う | 上に加えて、依頼側の名義で答える側に連絡し、聞き、記録する | 契約の範囲に「実施」。依頼側の決まりで外部の担当者が実施してよいこと。本人の同意にその旨が含まれること |
| 外部の専門の事業者を使う | 事業者の選定の材料を整え、記録の受け取りと観点の並べ方を担う | 依頼側と事業者の契約。担当者は関与しない |

副業の担当者が実施する場合、答える側から見ると「依頼側の人」です。名義、答えてよい範囲、聞いた内容の扱いを、依頼側と先に決めます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。実施が依頼側の決まりや法令の整理で外部に出せない場合は、設計だけに留めます。

## 進め方の順

| 順 | 中身 |
|---|---|
| 一 | 依頼側の決まりを確認する。実施の可否、段階、記録と保管、外部の担当者の関与 |
| 二 | 聞く項目の一枚を、評価シートの観点から作る。「迷う」の観点を重点に |
| 三 | 本人に説明し、同意を得る。相手の指定を本人から。書面の形は依頼側の決まりで |
| 四 | 答える側に、依頼側の名義で連絡。目的、所要時間、聞く項目の概要を先に伝える |
| 五 | 観点ごとに場面の事実を聞く。聞いてはいけない項目に触れない |
| 六 | 記録を観点ごとに。判断の欄は作らない。決める人と人事にだけ渡す |
| 七 | 担当者の手元の記録を消す。依頼側の記録が正 |

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「本人に知らせずに」と言う | 同意が前提であることを伝え、依頼側の決まりと専門家の確認を求める。同意無しでは担当者は関与しない |
| 本人が相手を指定できない | 無理に実施しない。実施しないことを依頼側に伝え、判断は依頼側 |
| 答える側が評判を語り始める | 「〇〇の場面で、どう動いていましたか」と事実に戻す。評判は記録しない |
| 依頼側が結果で即決しようとする | 面接の記録と観点ごとに並べ、一致と食い違いを示す。判断は依頼側 |
| 記録が面接官全員に回る | 共有の範囲を先に決める。決める人と人事だけ |

## まとめ

- 「裏を取る」ではなく、**本人の同意のもとで、面接の観点を第三者の事実で補う**もの
- 前提は**本人の同意と依頼側の決まり**。聞く相手は本人が指定。判断は専門家の確認に従う
- 聞く項目は**面接の観点と同じ**。「迷う」の観点を重点に。評判ではなく場面の事実
- **聞いてはいけない項目**に触れない。答える側が話し始めても記録しない
- 記録は**観点ごとに事実だけ**。判断の欄を作らない。決める人と人事にだけ
- 結果の扱いは**依頼側の判断**。担当者は面接の記録と並べて一致と食い違いを示すまで
- 実施するか設計だけかは**契約と依頼側の決まり**で。個別の判断は専門家にご確認ください

## よくある質問

### 候補者が「現職に知られたくないので、リファレンスは受けたくない」と言います

本人の意向を優先します。現職に聞かない形（前職の相手だけ）で実施できるか、実施しないかは、依頼側の判断です。担当者は、本人の意向を正確に依頼側に伝え、「現職への連絡は本人の同意が無ければ行わない」を確認します。受けないことを理由に不利に扱うかどうかも依頼側の判断で、担当者は判断しません。

### 答える側が、本人の悪い話を長く語りました

観点に関わる場面の事実だけを記録し、それ以外は記録しません。答える側の立場（本人との関係）を一行で残し、決める人が読むときの材料にします。悪い話が出たこと自体で判断せず、面接の記録と観点ごとに並べます。食い違いがあれば、本人に確かめる機会を設けるかは依頼側の判断です。担当者が「この人は危ない」と伝えることはしません。

### リファレンスの結果を、本人に伝えてよいですか

依頼側の決まりに従います。担当者が判断しません。本人から「何と言われましたか」と聞かれても、「結果の扱いは会社の決まりに従います」と答え、内容には触れません。答える側の情報を本人に伝えることも、答える側との関係に関わるため、依頼側の決まりと専門家の確認に従います。
