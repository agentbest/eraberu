日程調整の代行を初めて受けるとき、見えにくいのは「往復の前に何を決めておくか」です。募集文には「面接の日程調整」とだけあり、実際には、面接官の枠、段階ごとの所要時間、候補者の優先順位、名乗り方、カレンダーの権限、変更時の決まり、記録の表と、往復を始める前に決めることが並びます。決めずに始めると、遅い原因が自分の外にあるまま評価されます。結論を先に書くと、**1案件は「契約前→第1週→第2週以降→月次→終了と更新」の五つの段階で進み、契約前に範囲・段階と面接官の数・枠の空け方・カレンダーの権限・名乗り方と文面・情報の扱い・確認する時間帯・変更時の決まり・報告と評価を決め、第1週は往復を始めずに枠を空けてもらい順序と型と文面と記録の表を整え、第2週から候補日の提示と当日返信と確定と共有と前日の連絡と変更の受付と週次の報告を回し、月次で止まった日数を三つに分けて見て枠と順序と文面を直し、引き継げる形で終えます。**案件の型と求められる経験は[日程調整の代行の副業案件](/media/fukugyo-nittei-chousei-fk-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

日程調整は、始めてしまえば毎日回りますが、始める前に決めていないことは、毎日の遅れになって返ってきます。契約前に決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 往復だけか、確定から前日の連絡までか、複数段階の一式か、仕組み作りか。カレンダーの登録を含むか | 「面接官への共有もお願い」が後から足される |
| 段階と面接官の数 | 一次から最終まで何段階、面接官は何人、段階ごとの所要時間 | 誰の枠がどこにあるか分からない |
| 枠の空け方 | 面接官の枠を、誰が、いつ、週単位で空けるか。枠が足りないときの判断者 | 候補日を出せずに待つ。待ち時間が自分の評価になる |
| カレンダーの権限 | 閲覧だけか、登録までか。誤操作時の連絡の流れ。面接以外の予定を見ない約束 | 予定を上書きする事故。他人の予定を知ってしまう |
| 名乗り方と文面 | 会社の担当者の名義か、外部の担当として名乗るか。文面の承認者。名義の人が返信を読めるか | 承認の無い文面が会社の名前で出る。返信が名義の人に届かない |
| 候補者の情報の扱い | 会社の管理する場所でだけ扱う。連絡先を自分の連絡帳に入れない。秘密保持の契約 | 連絡先が自分の端末に残る |
| 確認する時間帯 | 平日のどの時間帯に確認し、当日中に返すか。返せないときの扱い | 候補者を待たせる |
| 変更時の決まり | 会社都合の変更の扱い（丁寧に、すぐ代替）、候補者都合の扱い（再提示）、当日の欠席の扱い | 変更が混乱する |
| 報告と評価 | 週次か、形式。何で評価されるか（自分の返信の速さか、確定までの日数か） | 枠の遅れで評価される |

止まりやすいのは、「まず溜まっている候補者に連絡してください」で始めるときです。枠と名乗り方と情報の扱いだけは、連絡を始める前に決めます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に書いています。

## 第1週：往復を始めない週

第1週は、候補者との往復を始めません。枠を空けてもらい、順序と型と文面と記録の表を整えます。溜まっている候補者には、受付の連絡（「日程のご案内を〇日までにお送りします」）だけを出します。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 面接官の枠を空けてもらう（週単位で、面接官ごとに、段階ごとの所要時間で） | 面接官が枠を出す時間。枠が足りないときの判断者の確定 | 枠を出さずに「候補者の都合を聞いてから」になる |
| 順序と優先順位（段階の順、同時に進む候補者の優先順位の決め方） | 優先順位の決め方の承認 | 優先順位が無く、枠の取り合いになる |
| 候補日の型（候補日を三つ、時間帯に幅を持たせて、二往復で決める型） | 型の承認 | 「ご都合をお知らせください」の型 |
| 文面の承認（候補日の提示、確定、前日の連絡、変更、当日の欠席への連絡） | 承認と名義の確定 | 段階ごとに文面を作り直す |
| 記録の表（候補者、段階、返信日、提示日、確定日、面接日、変更の有無と理由。返信→提示、提示→確定、確定→面接の日数が出る形） | 置き場（会社の管理する場所） | 日数が出ない表。自分の端末に置く |
| 面接官への共有の形（カレンダーの登録か、一覧か、前日の連絡の形） | 面接官の合意 | 面接官ごとに違う形で共有する |
| 溜まっている分の扱い（受付の連絡だけ先に出し、枠が空いたら優先順位の順に提示） | 受付の連絡の文面の承認 | 枠が無いまま溜まっている分に連絡して待たせる |

止まりやすいのは、「日程調整に準備は要らない」と第1週を飛ばすときです。枠と型が無いまま始めると、往復が三回を超え、遅い原因が自分に見えます。

### エラベルの見解

担当する側から見ると、この仕事は「第1週に枠を空けてもらえるか」で、その後の全部が決まります。枠が週単位で空いた会社では、第2週から候補日を当日に出せて、往復は二回で決まり、担当者の速さがそのまま評価になります。枠が空かないまま始めた会社では、担当者は「面接官に確認中です」を候補者に繰り返し、その待ち時間で評価されます。エラベルで担当者を選ぶ企業には、「最初の一週間で面接官の枠を週単位で出してください。枠が出た週から候補日を当日にお出しします」と、私たちから先に伝えています。受ける側がその場で使える判断としては、契約前の稼働の計画に「第1週は枠と型と文面と記録の表。候補者には受付の連絡だけ。往復は枠が出た週から」と書いて渡すこと。枠が出なければ、往復を始めない理由が書面に残ります。

## 第2週以降：提示・当日返信・確定と共有・前日の連絡・変更・報告

第2週から往復を始めます。ここからは、出す、返す、確定する、共有する、思い出させる、変更を受ける、記録する、の繰り返しです。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 候補日の提示（枠から三つ、時間帯に幅を持たせて、優先順位の順に） | 候補者の返信が来た当日 | 一つだけ出す。同じ時間帯ばかり出す（在職中の候補者が選べない） |
| 当日返信（候補者の返事に当日中に返す。決まらなければ次の三つを出す） | 決めた時間帯に毎日 | 翌日に持ち越す。「面接官に確認します」で止める |
| 確定の連絡（候補者と面接官の両方に。日時、所要時間、接続先か場所、当日の担当者の名前） | 確定した当日 | 面接官への共有が漏れる。候補者にだけ送る |
| カレンダーの登録（含む場合。面接の予定だけ。既存の予定は触らない） | 確定と同時 | 誤操作。面接以外の予定に触れる |
| 前日の連絡（候補者に、当日の担当者の名前と接続先と所要時間。面接官に、候補者の名前と段階） | 面接の前日 | 出さない。当日の担当者の名前が違う |
| 変更の受付（会社都合は理由と謝罪と代替の三つをすぐ。候補者都合は再提示。当日の欠席は会社の決まりで） | 起きた当日 | 会社都合の変更を淡々と送る |
| 記録（返信日、提示日、確定日、面接日、変更の有無と理由） | 起きるたび | 後でまとめて書く。日数が出ない |
| 週次の報告（件数、返信→提示、提示→確定、確定→面接の日数、変更の件数と理由、止まっている箇所、次に直すこと一つ） | 週に一度、決めた曜日 | 件数だけで、止まっている箇所が無い |

止まりやすいのは、候補日を一つだけ出して往復が増えることと、面接官への共有が漏れて面接官が当日に知ることです。候補日は三つ、共有は候補者と面接官の両方に同時に、を型にします。連絡の速さは[連絡の速さ](/media/fukugyo-renraku-sokudo/)に、報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

## 月次：止まった日数を三つに分けて見る

月に一度、会社と見直しの時間を持ちます。見るのは、件数ではなく、「返信→提示」「提示→確定」「確定→面接」の三つの日数と、変更の件数と理由です。

| 長い箇所 | 原因の候補 | 直すところと直す人 |
|---|---|---|
| 返信→提示 | 面接官の枠が空いていない。自分の確認の時間帯が足りない | 枠を週単位で空ける（会社）。確認の時間帯を足す（自分） |
| 提示→確定 | 候補日の幅が狭い（在職中の候補者が選べない）。往復が多い | 時間帯に幅を持たせる。三つ出して二往復の型に戻す（自分） |
| 確定→面接 | 枠が先すぎる。面接官の予定が埋まっている | 枠の数を増やす、面接官を足す（会社） |
| 変更が多い | 会社都合の変更（仮で入れている、面接官の予定管理）。候補者都合の変更 | 会社都合は枠の空け方の見直し（会社）。候補者都合は前日の連絡の徹底（自分） |
| 当日の欠席 | 前日の連絡が無い。確定から面接までが長い | 前日の連絡を型に（自分）。枠を近くに（会社） |

止まりやすいのは、月次で「もっと速く返します」と自分の努力だけで終えるときです。三つの日数のうち、自分で縮められるのは提示→確定だけで、返信→提示と確定→面接は枠の問題です。分けて見せます。一度に全部を変えず、一つずつ変えて比べます。

### エラベルの見解

同じ料金・同じ件数でも、結果が分かれるのは、月次の見直しで「枠の問題を会社に返せるか」です。確定までの日数が縮まらないとき、「もっと速く返します」と自分の努力で終える担当者は、返信→提示の日数が縮まらず、三か月目に「速くならない」と契約を終えられます。三つの日数を並べて、「提示→確定は二日で安定しています。返信→提示が五日で止まっていて、原因は枠です。週単位で先に空けていただければ、当日に出せます」と、記録で分けて会社に返す担当者は、次の月から確定までの日数を縮めます。枠の問題を面接官に直接言うのは難しいので、人事の責任者か経営者に、日数と辞退の件数で返します。エラベルで長く続いている担当者は、週次の報告の最初の行に三つの日数を書き、月次はそれを並べるだけで提案にしています。受ける側がその場で使える形としては、記録の表の日数の欄を、週次の報告にそのまま貼れる形にしておくこと。集計に時間をかけず、毎週同じ形で出し続けることが、会社を動かします。

## 終了と更新：引き継ぎと次の提案

契約の期間が来たら、更新か終了かを会社が決めます。どちらでも、引き継げる形にして終えます。

- **残すもの。** 枠の空け方の決まり、順序と優先順位の決め方、候補日の型、文面の型（提示・確定・前日・変更・欠席）、記録の表（会社の管理する場所に）、月次の三つの日数の推移と直した履歴
- **返すもの。** カレンダーの権限、採用管理システムの権限、共有された資料。候補者の連絡先は自分の手元に一切残さない
- **次の提案。** 更新するなら、次の期間で直す枠と型。終了するなら、社内で回す手順書と、最初の一か月で見る三つの日数

引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 候補者の情報の扱い

日程調整は、候補者の連絡先と、面接官のカレンダーに触れる仕事です。候補者の連絡先は会社の管理する場所（採用管理システムや会社のメール）でだけ扱い、自分の端末の連絡帳やメッセージアプリに入れません。記録の表も会社の管理する場所に置きます。面接官のカレンダーは、面接の予定だけを見て、登録し、面接以外の予定を見ない、話さない。カレンダーで知った面接官の予定を、候補者にも社外にも話しません。候補者から面接の前に送られた質問や事情は、会社に渡し、自分で判断しません。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[アカウントの管理](/media/fukugyo-account-kanri/)に書いています。個別の判断は専門家にご確認ください。

## 稼働時間は何で決まるか

週に何時間かかるかは、進行中の候補者の数と、一人あたりの往復の回数、変更の件数、確認する時間帯の回数で決まります。候補日を三つ出して二往復の型なら、一人あたりの往復は少なく、確認の時間帯を毎日一〜二回持てば、当日返信は保てます。変更が多い会社では、変更の対応が稼働の大きな部分になります。受ける前に「同時に進む候補者の数の目安」と「確認する時間帯」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、最初の一か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→第1週→第2週以降→月次→終了と更新**の五つの段階
- 契約前に**範囲・段階と面接官の数・枠の空け方・カレンダーの権限・名乗り方と文面・情報の扱い・確認する時間帯・変更時の決まり・報告と評価**を決める。枠と名乗り方と情報の扱いは連絡の前に
- 第1週は**往復を始めない**。枠を空けてもらい、順序と候補日の型と文面と記録の表と共有の形を整え、溜まっている分には受付の連絡だけ
- 第2週以降は**返信が来た当日に三つ提示→当日返信→確定を両方に→前日の連絡→変更は会社都合を丁寧に**。共有の漏れを型で防ぐ
- 月次は**返信→提示・提示→確定・確定→面接の三つの日数**で見る。自分で縮められるのは提示→確定。他は枠の問題として会社に返す
- 終了時は**枠の決まり・型・文面・記録の表・日数の推移**を残し、連絡先とカレンダーの権限を返す
- 候補者の連絡先は**自分の連絡帳に入れず、面接官の予定は面接以外を見ない**

## よくある質問

### 溜まっている候補者に、第1週から日程を出さないと辞退されませんか

第1週に出すのは「受付の連絡」です。「日程のご案内を〇日までにお送りします」と期日を添えて当日中に出せば、候補者は待てます。困るのは、連絡が無いことと、期日を過ぎることです。枠が無いまま「ご都合をお知らせください」と出すと、候補者の返事を受けてから面接官に聞く往復が生まれ、結局は待たせます。枠が出た週から候補日を出すほうが、確定までの日数は短くなります。

### 面接官への共有が漏れて、面接官が当日に知りました

確定の連絡を、候補者と面接官の両方に同時に出す型にします。片方ずつ送ると漏れます。カレンダーの登録を含む場合は、登録と同時に面接官にも一文を送ります。前日の連絡も、候補者と面接官の両方に出します。漏れた回は記録に残し、月次で「共有の型を変えた」と報告します。面接官が複数いる会社では、面接官ごとの一覧を会社の管理する場所に置き、確定のたびに更新します。

### 候補者から「面接ではどんなことを聞かれますか」「結果はいつ出ますか」と聞かれました

会社が「候補者に伝えてよい」と決めた範囲（選考の流れ、所要時間、次の連絡の時期の目安）は答え、面接の中身と結果に関わることは「会社の担当者からお伝えします」と返し、質問を記録して会社に渡します。名乗り方が外部の担当なら、この返し方は自然です。会社の担当者の名義で送っている場合は、名義の人に質問を渡して、名義の人から返す形にします。自分で答えると、会社の判断と違ったときに約束になります。
