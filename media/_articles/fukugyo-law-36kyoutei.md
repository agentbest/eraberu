副業で人事を受けて三六協定を見せてもらうと、去年のコピーに日付だけ変えたものが出てくることがあります。過半数代表者の欄に、総務の担当者の名前が毎年同じように入っている。結論を先に書くと、**労働基準法第36条第1項は「使用者は、…労働者の過半数を代表する者との書面による協定をし、厚生労働省令で定めるところによりこれを行政官庁に届け出た場合においては、…その協定で定めるところによつて労働時間を延長し、又は休日に労働させることができる」と定めています。**締結だけでは足りず、**届け出て初めて効力が生じる**書き方です。個別の判断は労働基準監督署にご確認ください。上限の枠は[時間外労働の上限規制](/media/fukugyo-law-jikangai/)に、労働時間の考え方は[労働時間の原則と例外](/media/fukugyo-law-roudou-jikan/)にまとめています。

## 締結と届出、そして相手方

**なぜ協定が要るのか。**労働基準法第32条は週四十時間・一日八時間を超えて労働させてはならないとし、第35条は毎週少なくとも一回の休日を求めています。第36条第1項は、これらの規定に**かかわらず**労働させることができる例外を作る仕組みです。協定がなければ、時間外労働も休日労働もさせられません。

**相手方（第36条第1項）。**「当該事業場に、**労働者の過半数で組織する労働組合**がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては**労働者の過半数を代表する者**」。

**過半数代表者の二つの要件（施行規則第6条の2第1項）。**

- 一 **法第四十一条第二号に規定する監督又は管理の地位にある者でないこと**
- 二 法に規定する協定等をする者を**選出することを明らかにして実施される投票、挙手等の方法による手続により選出された者**であつて、**使用者の意向に基づき選出されたものでないこと**

**第一号に該当する者がいない事業場（第2項）。**管理監督者しかいない事業場については、一部の協定等について第二号に該当する者を過半数代表者とする、という読替えが置かれています（第36条はこの読替えの対象に含まれていません）。

**不利益取扱いの禁止と配慮（第6条の2第3項・第4項）。**「使用者は、労働者が過半数代表者であること若しくは**過半数代表者になろうとしたこと**又は過半数代表者として**正当な行為をしたこと**を理由として**不利益な取扱いをしないようにしなければならない**」。「使用者は、過半数代表者が法に規定する協定等に関する事務を**円滑に遂行することができるよう必要な配慮を行わなければならない**」。

**「選出することを明らかにして」がポイントです。**何のための代表者かを示さずに選ばれた人、総務が指名した人、親睦会の幹事が自動的に兼ねている人は、この要件から外れます。実務でいちばんよく見つかる不備がここです。

**単位は事業場です。**第36条第1項は「当該事業場に」と書いています。本社と支店、店舗ごとに、それぞれの事業場で締結し、**所轄労働基準監督署長**に届け出ます。届出先も事業場ごとに変わります。

## 協定に定める事項

**法定事項（第36条第2項）。**

- 一 労働時間を延長し、又は休日に労働させることができることとされる**労働者の範囲**
- 二 **対象期間**（一年間に限るものとする）
- 三 労働時間を延長し、又は休日に労働させることができる**場合**
- 四 対象期間における**一日、一箇月及び一年**のそれぞれの期間について労働時間を延長して労働させることができる時間又は労働させることができる**休日の日数**
- 五 その他厚生労働省令で定める事項

**省令事項（施行規則第17条第1項）。**ただし書きで、第四号から第七号までは特別条項の定めをしない場合には不要とされています。

- 一 協定（労働協約による場合を除く）の**有効期間の定め**
- 二 第36条第2項第四号の**一年の起算日**
- 三 **第36条第6項第二号及び第三号に定める要件を満たすこと**
- 四 **限度時間を超えて労働させることができる場合**
- 五 限度時間を超えて労働させる労働者に対する**健康及び福祉を確保するための措置**
- 六 限度時間を超えた労働に係る**割増賃金の率**
- 七 限度時間を超えて労働させる場合における**手続**

**記録の保存（第17条第2項）。**「使用者は、前項第五号に掲げる措置の**実施状況に関する記録**を同項第一号の有効期間中及び当該有効期間の満了後**五年間**保存しなければならない」。附則第71条により、当分の間は**三年間**です。

**第三号が見落とされます。**施行規則第17条第1項第三号は「**第36条第6項第二号及び第三号に定める要件を満たすこと**」を協定に定める事項として挙げています。単月百時間未満・複数月平均八十時間以下を満たす旨を、協定に書き込む形です。様式にもチェック欄があります。

**様式（施行規則第16条）。**

| 場合 | 様式 |
|---|---|
| 通常の三六協定 | **様式第九号** |
| **特別条項**（第36条第5項に規定する事項の定めをする場合） | **様式第九号の二** |
| 第36条第11項に規定する業務（新たな技術、商品又は役務の研究開発に係る業務） | **様式第九号の三** |

**更新の特例（第16条第3項）。**「法第三十六条第一項の協定…を**更新しようとするとき**は、使用者は、**その旨の協定を所轄労働基準監督署長に届け出ることによつて**、前二項の届出に代えることができる」。内容を変えずに期間だけ延ばす場合の簡便な方法です。

**有効期間の考え方。**指針は有効期間の長さそのものを定めていませんが、協定の内容を定期的に見直す観点から、**一年とするのが実務では一般的**です。施行規則第17条第1項第二号が「一年の起算日」を定める事項としているので、起算日と有効期間の関係を整理しておきます。

### エラベルの見解

担当する側から見ると、三六協定の案件で最初にやるのは**過半数代表者の選出手続を確かめること**です。ここが崩れていると、三六協定だけでなく、変形労働時間制、フレックス、有給の時間単位・計画的付与、休憩の一斉付与の例外、裁量労働制、すべての労使協定の土台が揺らぎます。逆に言えば、ここを直すと一度にすべてが固まります。

確かめ方は単純で、**去年どうやって選んだかを聞く**だけです。たいてい「総務でお願いしました」「前の人から引き継ぎました」と返ってきます。そこで施行規則第6条の2第1項第二号を見せます。「選出することを明らかにして実施される投票、挙手等の方法による手続により選出された者であつて、**使用者の意向に基づき選出されたものでないこと**」。この一文で、会社は自分の手続の位置が分かります。

直し方も単純です。社内メールや掲示で「三六協定を締結する過半数代表者を選出します」と周知し、立候補と投票の期間を置き、結果を記録する。電子的な投票でも構いません。半日でできる作業です。そして、この記録が残ることで、翌年からは同じ手順を回すだけになります。

**管理監督者は代表者になれない**点も、現場に伝えます。部長や工場長が代表者になっている協定は、第一号の要件から外れます。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この土台の整理をやった経験は、経歴に書いておくと効きます。

## 点検の手順と、指針の留意事項

副業の人事が作るのは、次の形です。個別の適否の判断は労働基準監督署にご確認ください。

| 点検する項目 | 見るところ |
|---|---|
| 事業場の一覧 | 本社・支店・店舗ごとに協定があるか。届出先の監督署を特定 |
| 相手方 | 過半数労働組合があるか。ない場合の過半数代表者 |
| 選出手続 | **選出することを明らかにして**実施された投票・挙手等か。記録があるか |
| 代表者の資格 | **管理監督者でないこと**。役職から確かめる |
| 労働者の範囲 | 誰が対象か。パート・有期を含めているか |
| 対象期間 | 一年間になっているか。**一年の起算日**が書かれているか |
| 延長できる場合 | 業務の区分が細分化されているか。抽象的な記載になっていないか |
| 時間・日数 | **一日・一箇月・一年**それぞれ。休日の日数 |
| 第6項の要件 | **単月百時間未満・複数月平均八十時間以下を満たす旨**が書かれているか |
| 特別条項 | 限度時間を超える場合、健康福祉確保措置、割増賃金の率、手続。**月数（年六箇月以内）** |
| 有効期間 | 定めがあるか。起算日との関係 |
| 様式と届出 | 様式第九号／第九号の二／第九号の三。**届出の控えがあるか** |
| 周知 | 就業規則と同様に、労働者に周知されているか |
| 記録の保存 | 健康福祉確保措置の実施状況。有効期間中＋満了後三年間 |

**届出の控えを確かめます。**締結しているが届け出ていない、という会社があります。第36条第1項は「届け出た場合においては」と書いているので、控えの有無は最初に見ます。受付印のある写しを、事業場ごとに保管しているかを確かめます。

**周知も忘れずに。**労働基準法第106条第1項は、就業規則と並んで第36条第1項に規定する協定を、掲示・備付け・書面の交付その他省令で定める方法により労働者に周知させなければならないと定めています。金庫に入っているだけの協定は、この義務を満たしていません。周知の方法は[就業規則の作成義務](/media/fukugyo-law-shugyo-kisoku/)にまとめています。

**指針が定める留意事項。**指針（平成30年厚生労働省告示第323号）は、労使当事者の責務として「労働時間の延長及び休日の労働は**必要最小限にとどめられるべき**」であることへの留意を求め（第2条）、使用者の責務として、協定の範囲内で労働させた場合であっても**労働契約法第5条の安全配慮義務を負う**ことへの留意を求めています（第3条第1項）。第4条は、業務の種類について「**業務の区分を細分化することにより当該業務の範囲を明確にしなければならない**」としています。

**一箇月に満たない期間の目安（指針第6条・別表）。**有期契約などで一箇月に満たない期間において労働する労働者について、**一週間十五時間、二週間二十七時間、四週間四十三時間**を超えないようにするよう努めなければならない、とされています。

**休日労働（指針第7条）。**労働させることができる**休日の日数をできる限り少なくし**、休日に労働させる**時間をできる限り短くする**ように努めなければならない、とされています。

### エラベルの見解

外に出してよいのは、事業場の一覧、選出手続の設計と記録の様式、協定の項目立て、届出と周知の段取り、記録の保存の仕組みまでで、「この選出手続で要件を満たすか」「この記載で足りるか」といった個別の判断は、労働基準監督署や社会保険労務士の範囲です。

担当する側から見ると、三六協定は**会社の労務管理の健康診断**として使えます。協定を一枚見れば、事業場の管理ができているか、過半数代表者の手続が回っているか、業務の区分を言語化できているか、上限の数字を理解しているかが分かります。案件に入って最初の一週間でここを見ると、その後の進め方が決まります。

そして、協定を直す作業は、**現場との関係を作る入口**にもなります。過半数代表者を選ぶには、全従業員に周知する必要があります。そのタイミングで、労働時間について何を困っているかを聞ける。制度の話から入って現場の声を集める、という順番は、外部から入る人事にとって自然な流れです。

指針は「時間外・休日労働協定をするように努めなければならない」という書き方で、労使当事者の責務を定めています。協定は会社が一方的に作るものではなく、労使で決めるものだという前提が置かれています。ここを本気で回そうとすると、協定の更新が年に一度の対話の機会になります。**書類を作る仕事を、対話の仕組みに変えられるか**が、この領域で経験が効くところです。エラベルでは、依頼側が担当者を選べるので、この設計を経験した人は、制度まわりの案件で指名されます。

## まとめ

- 第36条第1項は、**書面による協定**をし、**行政官庁に届け出た場合**に時間外・休日労働をさせることができるとしている。**締結だけでは足りない**
- 相手方は、**過半数労働組合**、なければ**過半数代表者**。単位は**事業場**
- 過半数代表者の要件は、**管理監督者でないこと**と、**選出することを明らかにして実施される投票・挙手等により選出され、使用者の意向に基づき選出されたものでないこと**
- 協定に定めるのは、**労働者の範囲／対象期間（一年間）／延長できる場合／一日・一箇月・一年の時間と休日の日数**と、省令の**有効期間／一年の起算日／第6項第二号・第三号の要件を満たすこと**など
- 様式は、通常が**様式第九号**、特別条項が**様式第九号の二**、研究開発業務が**様式第九号の三**。**更新は「その旨の協定」の届出で代えられる**
- 健康福祉確保措置の**実施状況の記録**を、有効期間中および満了後**三年間**（省令は五年間、附則により当分の間三年間）保存する。個別の判断は労働基準監督署にご確認ください

## よくある質問

### 去年と同じ内容なら、届出を省略できますか

労働基準法施行規則第16条第3項は「法第三十六条第一項の協定…を更新しようとするときは、使用者は、**その旨の協定を所轄労働基準監督署長に届け出ることによつて**、前二項の届出に代えることができる」と定めています。つまり、様式による届出に代えて更新の旨の協定を届け出る方法が認められているのであって、届出そのものを省略できるわけではありません。あわせて、過半数代表者の選出は改めて行う必要があります。手続の個別の判断は、労働基準監督署にご確認ください。

### 過半数代表者は誰でもよいのですか

労働基準法施行規則第6条の2第1項は、二つの要件を定めています。第一号は「法第四十一条第二号に規定する監督又は管理の地位にある者でないこと」、第二号は「法に規定する協定等をする者を選出することを明らかにして実施される投票、挙手等の方法による手続により選出された者であつて、使用者の意向に基づき選出されたものでないこと」です。したがって、管理監督者は代表者になれず、会社が指名した人も要件から外れます。第3項は代表者になろうとしたことを理由とする不利益取扱いの禁止、第4項は必要な配慮を定めています。選出方法の個別の適否は、労働基準監督署にご確認ください。

### 協定は本社でまとめて結べばよいですか

労働基準法第36条第1項は「**当該事業場に**」と書いており、協定は事業場ごとに締結し、**所轄労働基準監督署長**に届け出る形です。したがって、本社、支店、店舗、工場といった事業場ごとに、それぞれの過半数代表者（または過半数労働組合）と締結します。なお、一定の要件を満たす場合に本社一括での届出が認められる取扱いがあるため、自社が該当するかは所轄の労働基準監督署にご確認ください。
