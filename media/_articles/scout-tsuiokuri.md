スカウトに返信が来て、やり取りが始まったのに、途中で止まる。面談をしたのに、その後の音沙汰が無い。「考えます」と言われたまま、連絡が無い。追いかけたいが、しつこくなるのが怖く、放置している。放置した候補者は、他社に決まる。結論を先に書くと、**追客（フォローアップ）は、「返信が無い人」と「返信の後に止まった人」を分けて設計します。前者は再送の問題で、後者が追客の問題です。止まった段階（返信の後、日程の前、面談の後、応募の前、内定の後）ごとに、「いつ」「誰が」「何を」送るかを決め、回数と間隔と、やめる判断を先に決めておけば、しつこくならずに追えます**。返信が無い人への再送は[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/)に、面談の後の流れは[スカウトのCTAは面談か応募か](/media/scout-cta/)にまとめています。

## 追客が設計されていない構造

追客が設計されていないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「返信が無い人」と「止まった人」を分けていない | 両方を「追う」で一括りにし、再送の話と追客の話が混ざる |
| 止まった段階を見ていない | 「日程の前で止まった」と「面談の後で止まった」では、送るものが違う |
| 追うタイミングが無い | 「気づいたら送る」で、一週間後だったり、一か月後だったり |
| 誰が追うかが決まっていない | 人事か、面談の担当者か、代行か。誰も追わない |
| 何を送るかが無い | 「その後いかがですか」だけ。相手にとっての新しい材料が無い |
| しつこさの怖さで、放置している | 「追うと嫌がられる」で、一度も追わない |
| やめる判断が無い | 追い始めたら、いつまで追うかが無く、追い続けるか、途中で忘れる |
| 記録が無い | 誰を、いつ、何回追ったかが無く、重複するか、漏れる |

構造の大半は、「段階ごとに、いつ・誰が・何を」が無いことです。設計すれば、追えます。

## 追客の対象の分け方

追客の対象を、止まった段階で分けます。「返信が無い人」は、追客ではなく再送の対象です。

| 止まった段階 | 状態 | 追客の位置づけ |
|---|---|---|
| 返信が無い | 一度目のスカウトに返信が無い | 再送の対象。[同じ候補者に何回送ってよいか](/media/scout-soushin-hindo/) |
| 返信の後、日程の前 | 「話を聞きたい」と返信が来たが、日程の候補を送っても返事が無い | 追客の対象。最も惜しい段階 |
| 日程が決まった後、面談の前 | 日程は決まったが、前日の確認に返事が無い、当日に来ない | 追客の対象。理由の確認 |
| 面談の後、応募の前 | 面談をしたが、応募の意思の返事が無い | 追客の対象。面談の後の設計 |
| 応募の後、選考の途中 | 応募したが、書類の提出や面接の日程で止まった | 追客の対象。選考の運用 |
| 内定の後、返事の前 | 内定を出したが、承諾の返事が無い | 追客の対象。内定後の接点 |
| 「今は動けない」と言った人 | 時期を言って止まった | 追客の対象。時期に合わせて |
| 「考えます」と言った人 | 判断を保留した | 追客の対象。考える材料を渡す |

分け方の要点は、「止まった段階で、送るものが違う」ことです。「日程の前」なら日程の候補を出し直し、「面談の後」なら面談の補足と応募の流れ、「内定の後」なら迷いを聞く。

## 段階ごとの追客の型

段階ごとに、「いつ」「誰が」「何を」を決めます。

| 段階 | いつ | 誰が | 何を |
|---|---|---|---|
| 返信の後、日程の前 | 候補を送って三日後に一度、一週間後に一度 | 担当者（人事か代行） | 「先日の日程の候補、まだ有効です。合わなければ、ご都合を」。新しい候補も添えて |
| 面談の前日に返事が無い | 前日に一度 | 担当者 | 「明日〇時、お待ちしています。接続はこちら。ご都合が変わればお知らせを」 |
| 面談の当日に来ない | 当日に一度 | 担当者 | 「ご都合が変わりましたか。改めて候補をお送りします」。責めない |
| 面談の後、応募の前 | 翌日に一度、一週間後に一度 | 面談の担当者（役割の責任者など） | 翌日：感謝、補足、応募の流れ。一週間後：「もし迷っている点があれば」 |
| 応募の後、書類で止まった | 三日後に一度 | 担当者 | 「書類の提出で、お困りの点があれば。形式は自由で構いません」 |
| 選考の日程で止まった | 三日後に一度 | 担当者 | 新しい候補を添えて |
| 内定の後、返事の前 | 三日後に一度（期限の前）、期限の日に一度 | 責任者か面接官 | 「迷っている点があれば、お話しします」。一緒に働く人との接点の提案 |
| 「今は動けない」 | 相手が言った時期の少し前に一度 | 最初の送り主 | 「以前、〇月頃とおっしゃっていたので。状況はいかがですか」 |
| 「考えます」 | 一週間後に一度 | 面談の担当者か最初の送り主 | 「考える材料として、〇〇を補足します」。新しい材料を添えて |

型の要点は、「段階ごとに、回数は一〜二回、間隔は数日から一週間、送る人は段階に合った人」です。全段階を人事が追う形は、「事務的」に見えます。面談の後は面談の担当者から、内定の後は責任者から。

## 追客の文面

追客の文面の、書き方です。「その後いかがですか」だけにしません。

| 要素 | 書き方 |
|---|---|
| 前回に触れる | 「先日の面談で〇〇についてお話ししました」。何の続きかを明示 |
| 新しい材料 | 「補足として、△△をお伝えします」「一緒に働く□□と話す場も設けられます」。前回に無かったもの |
| 相手の迷いに触れる | 「迷っている点があれば、お聞かせください」。「決めてください」ではなく |
| 次の一歩を軽く | 「一言のご返信でも」「ご質問だけでも」 |
| 断りやすさ | 「ご興味が無ければ、ご返信は不要です」「今回はご縁が無くても、またご連絡させてください」 |
| 期限があるなら事実として | 「内定の返事の期限は〇日です。延ばすことも相談できます」。急かさない |
| 送り主の名前 | 段階に合った人の名前で。面談の後なら面談の担当者 |
| 長さ | 短く。三〜五文 |
| 責めない | 「ご返信がありませんが」「お忙しいとは思いますが」を書かない |

文面の要点は、「新しい材料」と「断りやすさ」です。「その後いかがですか」は、新しい材料が無く、相手に「返事を催促された」と受け取られます。「補足があります」なら、相手は「材料が増えた」と受け取ります。

### エラベルの見解

相談で最も多い失敗は、「面談の後、応募の返事が無い候補者に、人事から一週間ごとに『その後いかがですか』を三回送り、返事が来ず、口コミに『催促された』と書かれた」というものです。誰が（人事）、何を（催促）、何回（三回）、が全部ずれていました。面談の担当者（役割の責任者）から、翌日に「感謝と補足と応募の流れ」、一週間後に「迷っている点があれば」の二回だけ、「ご縁が無くても、またご連絡を」を添えて、に変えたら、返事が来る率が上がり、断りの返事も丁寧に来るようになりました。追客は、催促ではなく、材料の追加でした。

見ていて差がつくのは、担当者が「段階ごとに、誰が送るか」を分けるかどうかです。「追客はこちらで一括で送ります」と人事や代行から全部送る担当者と、「面談の後は面談の担当者から、内定の後は責任者から送る形にします。文面は私が下書きします」と、段階に合った人から送る設計をする担当者がいます。後者の追客は、催促に見えません。

発注側にできるのは、面談の担当者と責任者に、「追客の一通を、自分の名前で送る」役割を渡すことです。

## 追客をやめる判断

追客は、やめる判断を先に決めます。決めないと、追い続けるか、途中で忘れます。

| やめる場面 | 判断 |
|---|---|
| 段階ごとの回数を送り切った | 「返信の後、日程の前」で三日後と一週間後の二回を送って返事が無ければ、やめる。三か月後に、新しい理由があれば再送の対象に |
| 「今後の連絡は不要」と言われた | 即座にやめる。記録して、送らない |
| 「他社に決まった」と言われた | やめる。「おめでとうございます。またご縁があれば」で終わる。半年以上経ってから、新しい理由があれば |
| 「今は動けない」と時期を言われた | その時期まで待つ。時期の前に一度だけ |
| 断りの返事が来た | やめる。感謝して終わる。翻意を促さない |
| 返事が無いまま、内定の期限が過ぎた | 期限の日に一度連絡し、返事が無ければ、内定を取り下げる旨を丁寧に伝えて、やめる |
| 追客の後、明らかに関心が無い返事 | 「特に」「大丈夫です」のような短い返事。一度だけ「ご縁があればまた」で終わる |
| 記録で、追客の効果が無い段階 | 「この段階の追客は、返事が来ない」と記録で分かれば、その段階の追客をやめるか、型を変える |

やめる判断の要点は、「回数を送り切ったらやめる」と「意思の表明に従う」です。「まだ返事が来ていないから」で追い続けることが、催促になります。

やめた候補者は、消えるのではなく、「三か月後に新しい理由があれば再送の対象」に戻ります。追客をやめることと、関係を切ることは、別です。

## 追客の記録と運用

追客を、記録して運用します。

| 項目 | 運用 |
|---|---|
| 候補者の段階の記録 | 候補者ごとに、いまどの段階で止まっているかを、表で。「返信の後、日程の前」「面談の後、応募の前」 |
| 追客の予定 | 段階ごとの型に沿って、「いつ、誰が、何を」の予定を、候補者ごとに入れる。三日後、一週間後 |
| 追客の実施の記録 | 送った日、送った人、送った内容（型）、返事の有無と内容 |
| 毎日の確認 | 担当者が毎朝、「今日、追客の予定がある候補者」を表で確認し、送る（または、送る人に依頼する） |
| 送る人への依頼 | 面談の担当者や責任者が送る場合、担当者が下書きを用意し、「今日送ってください」と依頼。送ったかを確認 |
| やめる判断の記録 | 「回数を送り切った」「意思の表明」「他社に決まった」を記録し、追客の対象から外す。再送の対象に戻す時期も |
| 効果の記録 | 段階ごとに、追客の一回目と二回目の返事の率。効いている段階と効いていない段階 |
| 週次の振り返り | 「今週、どの段階で何人が止まり、追客で何人が動いたか」。[週次の振り返りで見る数字](/media/scout-furikaeri/)の中で |
| 三か月ごとの見直し | 段階ごとの型（いつ、誰が、何を）を、効果の記録で見直す |

運用の要点は、「候補者ごとに段階と追客の予定を持ち、毎朝確認する」ことです。「気づいたら送る」では、一週間後だったり忘れたりします。

追客の記録は、個人情報を含みます。規程と法令に沿って扱い、アクセスできる人を限定します。

## 外注する場合の範囲

追客の設計を、スカウト代行に出す場合の範囲です。

**出せる工程。** 追客の対象の分け方（再送と追客の区別、段階の定義）、段階ごとの型（いつ、誰が、何を）の作成、追客の文面の型（段階ごと）、やめる判断の基準、候補者の段階の記録の表と毎日の確認、担当者自身が送る段階の追客の実施（返信の後の日程、書類の停滞、選考の日程など）、面談の担当者や責任者が送る段階の下書きと依頼と確認、やめる判断の記録と再送の対象への戻し、効果の記録と週次の振り返り、三か月ごとの見直し。

**社内に残す判断。** 面談の担当者と責任者が追客を自分の名前で送ることの合意、内定の期限の扱い（延長の可否）、やめる判断の基準の承認、個人情報の扱いの方針（専門家との連携）。

**外注の効きどころ。** 追客は、「候補者ごとの段階を把握し、毎日確認し、段階に合った人から送る」運用が要り、社内では「気づいたら人事が催促」になりやすい工程です。担当者が段階を記録し、予定を管理し、自分で送る段階は送り、責任者が送る段階は下書きして依頼すれば、追客は催促にならず、止まった候補者が動きます。担当者は複数の会社の追客を見ているので、「この段階でこの材料を送ると動く」の型を持ち込めます。ただし、面談の後と内定の後は、社内の人の名前で送ることが要ります。

**外注しても動かない場合。** 面談の担当者や責任者が追客の一通を送らない、内定の期限を延ばさず催促だけする、意思の表明を無視して追い続けることを求める。社内の判断で、代行を替えても直りません。

追客は、段階ごとに、いつ・誰が・何を、とやめる判断を決めれば、しつこくならずに追えます。外注は、段階の記録と予定の管理と、自分で送る段階の実施を担う手段です。

### エラベルの見解

担当する側から見ると、追客の相談で最も多いのは、「返信の後、日程の前で止まった候補者を、追っていない」ことです。「話を聞きたい」と返信が来た。日程の候補を送った。返事が無い。そこで、放置。最も惜しい段階です。候補者は「話を聞きたい」まで来ていて、日程の候補が合わなかったか、見落としたか、忙しかっただけかもしれません。

三日後に「まだ有効です。合わなければご都合を」と新しい候補を添えて一度、一週間後にもう一度。それだけで、この段階の候補者の一部は動きます。追客の中で、最も効く段階です。

発注側にできるのは、「返信の後、日程の前」で止まった候補者が、いま何人いるかを、担当者に聞くことです。

## まとめ

- 設計されていないのは**返信が無い人と止まった人を分けない・段階を見ない・タイミングが無い・誰が追うか無い・何を送るか無い・怖さで放置・やめる判断が無い・記録が無い**構造
- 対象は**返信が無い（再送）・返信の後日程の前・日程の後面談の前・面談の後応募の前・応募の後選考の途中・内定の後返事の前・今は動けない・考えます**に分ける
- 型は**段階ごとに、いつ（三日後・一週間後・翌日・前日・当日・期限の前）・誰が（担当者・面談の担当者・責任者・最初の送り主）・何を（新しい候補・感謝と補足と流れ・迷いを聞く・時期の確認・考える材料）**。回数は一〜二回
- 文面は**前回に触れ・新しい材料・迷いに触れ・次の一歩を軽く・断りやすさ・期限は事実として・段階に合った人の名前・短く・責めない**。催促ではなく材料の追加
- やめるのは**回数を送り切った・不要と言われた・他社に決まった・時期を言われた（待つ）・断りの返事・期限が過ぎた・関心が無い返事・記録で効果が無い**。やめても三か月後に再送の対象に戻る
- 運用は**段階の記録・予定・実施の記録・毎日の確認・送る人への依頼と確認・やめる記録・効果・週次・三か月ごと**。気づいたら送るをやめる
- 外注できるのは**分け方・型・文面・基準・表と確認・自分で送る段階の実施・下書きと依頼・やめる記録・効果と振り返り・見直し**。社内に残るのは**担当者と責任者が送る合意・期限の扱い・基準の承認・個人情報の方針**

## よくある質問

### 追客すると、しつこいと思われませんか

しつこく見えるのは、「回数が多い」「間隔が短い」「新しい材料が無い」「催促の言葉」「意思の表明を無視」のときです。段階ごとに一〜二回、数日から一週間の間隔で、前回に無かった材料（補足、新しい候補、一緒に働く人との接点）を添え、「ご興味が無ければ返信は不要」と断りやすさを付け、意思の表明があればやめる。この形なら、しつこいとは見えず、「丁寧に対応してくれる会社」と見えます。追わずに放置するほうが、候補者を失います。

### 面談の後、「考えます」と言われたまま連絡がありません

一週間後に、面談の担当者（役割の責任者など）から、「考える材料」を添えて一度送ります。「先日はありがとうございました。考える材料として、〇〇を補足します。一緒に働く△△と話す場も設けられます。迷っている点があれば、お聞かせください。ご縁が無くても、またご連絡させてください」。人事からの「その後いかがですか」は催促に見えます。一週間後の一回で返事が無ければ、追客はやめ、三か月後に新しい理由があれば再送の対象に戻します。

### 内定を出した後、返事が来ません

返事の期限の三日前に、責任者か面接官から「迷っている点があれば、お話しします。一緒に働く人と話す場も設けられます」と一度。期限の日に、「期限は本日ですが、延ばすことも相談できます」と一度。「決めてください」ではなく、「迷いを聞く」と「期限を相談できる」を伝えます。それでも返事が無ければ、期限の翌日に、内定を取り下げる旨を丁寧に伝えて終わります。内定後の辞退の構造は[年収交渉で毎回折り合わない](/media/rpo-nenshu-kousho/)と[候補者体験が悪いまま放置されている](/media/rpo-taiken-warui/)にも書いています。
