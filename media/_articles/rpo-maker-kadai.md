メーカー業界の会社が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。技術職・現場職・事務職の経路を分けずに一つの媒体で募集している。要件が「設計経験〇年」のままで、製品と工程が言葉になっていない。勤務地と転居の条件を先に出さず、面接で辞退される。交替勤務や残業の実態が求人票に無く、入社後に離れる。採用の担当が総務や人事の兼務で、返事と日程が遅い。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**メーカー業界の採用課題は、経路・要件・勤務地・働き方の実態・速さの五つに分解し、自社の記録（職種の型ごとの応募の数、書類と面接の一致、辞退の理由、早期離職の理由、段階ごとの日数）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、媒体を増やす施策に費用を使い、要件と勤務地と速さで止まる、という結果になります。代行に出す工程の切り分けは[メーカー業界の採用代行](/media/rpo-maker-rpo/)に、職種ごとの母集団形成は[機械設計採用を代行に出す判断基準](/media/rpo-kikai-sekkei-rpo/)や[生産技術採用を代行に出す判断基準](/media/rpo-seisan-gijutsu-rpo/)に書いています。ここでは、メーカー業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 経路 | 技術職は来るが現場職が来ない（またはその逆） | 職種の型ごとの応募の数と経路 |
| 要件 | 設計の応募は来るが、面接で「製品と工程が違う」 | 書類で○の人が面接で通らない。要件が「経験〇年」 |
| 勤務地 | 面接や内定の段階で「勤務地が遠い」「転居はできない」と辞退 | 辞退の理由が「勤務地」 |
| 働き方の実態 | 入社後に「聞いていた働き方と違う」と離れる | 早期離職の理由が「働き方」 |
| 速さ | 「他社に決まった」。日程が一週間先 | 段階ごとの日数。兼務の担当の返事の日数 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 職種の型ごとの応募の数と、使っている経路 | 型で偏りがあれば経路 |
| 二 | 書類の○と面接の一致 | ○が面接で通らないなら要件 |
| 三 | 辞退の理由 | 「勤務地」なら勤務地。「他社に決まった」なら速さ |
| 四 | 早期離職の理由 | 「働き方」なら働き方の実態 |
| 五 | 段階ごとの日数と、返事の日数 | 長ければ速さ |

一から五を順に見ると、詰まりは一か所に絞れます。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

メーカー業界で最も多い詰まりは「経路」です。設計の経験者を採りたいのに掲載型の媒体だけで募集し、現場職を採りたいのにスカウトの媒体を契約している。職種の型と経路がずれていると、どれだけ費用を使っても応募は来ません。設計はスカウトと紹介会社、現場職は地域の掲載型と学校とハローワーク、事務職は掲載型、と型ごとに経路を分けるだけで、応募の数は変わります。エラベルで担当者を選ぶ企業には、「技術職と現場職で、経路を分けていますか」を、私たちから先に聞いています。答えが「同じ媒体で」なら、直すのは媒体の数ではなく型ごとの経路です。経路の考え方は[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に書いています。

## 経路の課題：職種の型と経路がずれている

| 職種の型 | 合う経路 | 合わない経路 |
|---|---|---|
| 技術職（設計・生産技術・品質・研究開発） | スカウト型の媒体、紹介会社、学校（新卒） | 地域の掲載型だけ |
| 現場職（製造・保全・検査） | 地域の掲載型、ハローワーク、学校、地域の紹介、リファラル | スカウト型の媒体だけ |
| 事務職 | 掲載型、地域の経路 | スカウト型 |

型ごとに経路を分け、型ごとに応募の数を記録します。一つの経路で全部を採ろうとしないことが要点です。

## 要件の課題：製品と工程が言葉になっていない

| ずれている要件 | 直した要件 |
|---|---|
| 「機械設計の経験三年以上」 | 「〇〇の製品の〇〇（部品・ユニット）を、構想から図面まで担った経験」（年数は歓迎に） |
| 「生産技術の経験者」 | 「〇〇の工程の設備の立ち上げか改善を、自分で計画して実施した経験」 |
| 「品質管理の経験」 | 「〇〇の工程で、不良の原因を自分で特定して対策した経験」 |
| 「〇〇のソフトが使える」 | 歓迎に。「使って何を設計したか」が必須 |

製品と工程の言葉は、社内の技術者にしか出せません。「いまうまくやっている人が、入った頃にすぐできたことと時間がかかったこと」から起こします。要件の作り方は[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 勤務地の課題：転居の条件を先に出していない

| 先に出していないこと | 起きること | 直し方 |
|---|---|---|
| 勤務地（工場の場所） | 面接で「遠い」と辞退 | 求人票の先頭と初回の連絡に |
| 転居の支援（社宅、引越しの費用の扱い） | 転居できる人が応募しない | 支援があるなら先に。無ければ通える範囲に絞る |
| 転勤の有無 | 内定後に辞退 | 実態を先に |
| 単身赴任の扱い | 入社後に「聞いていない」 | 実態を先に |

勤務地を先に出すと応募は減りますが、減るのは「勤務地で離れる人」で、その人は面接か入社後に離れます。先に出すかは会社の判断です。

### エラベルの見解

メーカー業界で見落とされやすいのは「働き方の実態」です。交替勤務、繁忙期の残業、休日出勤の頻度、工場の環境（温度、立ち仕事）を求人票に書かず、「アットホームな職場」と書いて採り、入社後に「聞いていない」で離れる。実態は隠すほど離職になり、書くほど応募は減るが定着します。現場の見学を選考の段に置くと、候補者が実態を見て判断でき、入社後のずれが減ります。エラベルで担当者を選ぶ企業には、「入社した方が三か月で『聞いていたのと違う』と言ったことは何ですか」を、私たちから先に聞いています。その答えが、求人票に書くべき実態です。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 働き方の実態の課題：求人票に無い

| 求人票に無いこと | 書き方 |
|---|---|
| 交替勤務の形 | 「〇交替、〇週間で交替」の実態 |
| 繁忙期の残業 | 「〇月と〇月は繁忙で、残業が増える」の実態 |
| 工場の環境 | 立ち仕事、温度、音の実態。見学で確かめられること |
| 一緒に働く人 | 現場のチームの構成、教える人 |
| 最初の三か月 | 誰と何を覚えるか |

現場の見学を、面接の一段として設計します。見学の後の辞退は、実態を知って判断した結果で、入社後の離職より良い。

## 速さの課題：兼務の担当で遅れる

| 遅れる場所 | 直し方 |
|---|---|
| 候補者への返事 | 翌営業日中に返す窓口。兼務なら外に出す |
| 面接の日程の確定 | 技術者と現場の責任者の枠を先に預かり、確定を即日 |
| 段の数 | 一次と見学を同日に |
| 内定の判断 | 決める人を一人に |

速さは、費用がかからず、今日から変えられます。兼務の担当の負担が最も大きい「一次対応と日程」を外に出すと、効果が早い。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 経路 | 型ごとの経路の運用 | 型と経路の判断 |
| 要件 | 「経歴で読める言葉」に整える作業 | 製品と工程の要件を決める（技術者） |
| 勤務地 | 求人票と初回の連絡に書く作業 | 転居の支援と転勤の実態を出す判断 |
| 働き方の実態 | 求人票に落とす作業。見学の日程 | 実態を語る。見学で何を見せるか |
| 速さ | 一次対応、日程の確定 | 枠を出す |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[メーカー業界で採用代行が機能する条件・機能しない条件](/media/rpo-maker-jirei/)に書いています。

## まとめ

- 「採れない」には**経路・要件・勤務地・働き方の実態・速さ**の五つが混ざっている
- **記録で一つに特定してから直す**。職種の型ごとの応募→書類と面接の一致→辞退の理由→早期離職の理由→日数の順
- 最も多い詰まりは**経路**。技術職・現場職・事務職で経路を分ける
- 要件は**「〇〇の製品の〇〇の工程で、〇〇を担った経験」**に。技術者の最初の一回
- **勤務地と転居の条件、働き方の実態を先に出す**。応募は減り、辞退と離職が減る
- **現場の見学**を選考の段に。候補者が実態を見て判断できる
- 速さは**一次対応と日程を外に出す**と早い

## よくある質問

### 現場職の応募がまったく来ません

経路が「スカウト型の媒体だけ」か「掲載型の一つだけ」になっていることが多い。地域の掲載型、ハローワーク、学校、地域の紹介、社員のリファラルを全部並べて、使っていない経路を足します。求人票に勤務地と働き方の実態が書かれているかも確かめます。それでも来なければ、通える範囲の母集団の大きさの問題で、転居の支援を出すか、勤務の形を変えるかの判断になります。地方の考え方は[地方企業の採用代行](/media/rpo-chihou-kigyo-rpo/)に書いています。

### 技術者が「製品と工程は口で説明すれば分かる」と言い、要件を書きません

口で説明した要件は、代行と紹介会社に伝わらず、ずれた推薦が続きます。最初の一回だけ、いまうまくやっている人の「入った頃にすぐできたことと時間がかかったこと」を三十分聞き、担当者が「〇〇の製品の〇〇の工程で、〇〇を担った経験」の形に整え、技術者が確認する形にします。技術者が書くのではなく、話してもらって担当者が整える、なら時間は取れます。

### 求人票に働き方の実態を書くと、応募がゼロになりそうです

実態を書かずに採った人は、入社後に離れ、募集を繰り返すことになります。実態を書いて応募が減るなら、その実態で採れる母集団が小さい、ということで、経路を増やすか、働き方の実態を変えるか、条件で補うかの判断になります。判断は会社のものですが、「書かずに採る」は選択肢に入れません。書いた上で、現場の見学で実態を見せ、それでも来た人が定着します。
