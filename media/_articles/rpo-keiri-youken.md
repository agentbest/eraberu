経理の求人票の必須要件には、「簿記の資格」「年次決算の経験」「上場企業または大手での経理経験」「特定の会計ソフトの使用経験」「経験五年以上」が並びがちです。この要件で来る人は、大企業の経理の一部を担ってきた人が多く、一人経理で記帳から決算の準備まで全部を回す自社には合わないことがあります。結論を先に書くと、**経理の採用要件は、先に自社の水準（記帳まで、月次まで、年次まで、開示まで）・規模（一人かチームか）・税理士との分担を決め、必須を「入社初日に自社の水準と分担で経理が成り立つか」で三つ以内に絞り、資格・会社の規模・会計ソフト・年数は必須にせず、担った水準と規模の経験（何を、どこまで、一人でかチームでか）で書く**と、自社の経理を回せる人の母集団が生まれます。水準と規模を決めずに要件を積むと、「上場企業で決算をした資格保持者」を探すことになり、自社の一人経理には合いません。母集団形成は[経理の母集団形成](/media/rpo-keiri-boshuudan/)に、代行に出す工程の線は[経理採用を代行に出す判断基準](/media/rpo-keiri-rpo/)にまとめています。

## 経理で要件が膨らむ理由

他の職種と共通する理由（現場の希望を全部書く、前任者を基準にする、失敗を避けたい）に加えて、経理に特有の理由があります。

一つ目は、資格を必須にすることです。簿記の資格は、知識の目安にはなりますが、自社の水準で実務が回せるかを示しません。資格があって実務が浅い人と、資格が無くて一人経理を長く回してきた人がいます。

二つ目は、会社の規模を実績にすることです。「上場企業での経験」「大手での経験」は、大きな会社の経理の一部を深く担った証明で、一人で全部を回す自社での再現を示しません。むしろ、大企業の経理は分業が進んでいて、記帳から決算までの全体を一人で見た経験が無いことが多い。

三つ目は、決算の経験を「年次決算」と一括りにすることです。年次決算の「準備」を税理士と分担した経験と、年次決算を「締めた」経験と、開示の資料を作った経験は、水準が違います。自社の分担で税理士が決算を締めるなら、締めた経験は要りません。

四つ目は、会計ソフトを必須にすることです。会計ソフトは、同種のものを使っていれば数週間で移行できます。

五つ目は、年数です。年数と、自社の水準で回せるかは一致しません。

## 必須と歓迎を分ける基準

基準は「入社初日に、自社の水準と分担で経理が成り立つか」です。経理では「自社の水準と分担で」を先に決めます。一人経理で月次まで社内、年次は税理士と分担なら、その水準と分担の経験。

| 項目の例 | 必須になる場合 | 歓迎になる場合 |
|---|---|---|
| 記帳と請求・支払の処理 | 社内で記帳する場合は必須 | 記帳を外部に出している場合は歓迎 |
| 月次の締めを一人で担った経験 | 一人経理で月次まで社内なら必須 | チームで分担する場合は「月次の一部を担った経験」で足りる |
| 年次決算の準備を税理士と分担した経験 | 年次を税理士と分担する体制なら必須 | 税理士が全部締める体制なら歓迎 |
| 年次決算を締めた経験 | 社内で決算を締める体制なら必須 | 税理士と分担する体制なら歓迎 |
| 開示や連結の経験 | 開示や連結を社内で担う場合は必須 | それ以外は不要 |
| 外部（税理士、会計事務所）と分担して回した経験 | 分担がある体制なら必須 | 社内で全部やる体制なら歓迎 |
| 一人で全体を回した経験 | 一人経理なら必須 | チームなら歓迎 |
| 業務を整理し直した経験（立て直し） | 引き継ぎが無い状態なら必須に近い | 整った状態なら歓迎 |
| 経営に数字を説明した経験 | 経営者と月次の数字を見る役割なら歓迎 | — |
| 簿記の資格 | — | 必須にしない。知識の目安として歓迎に |
| 上場企業や大手での経験 | — | 必須にしない。開示や連結を担う場合だけ「開示の経験」として |
| 特定の会計ソフト | — | 必須にしない。同種のソフトの経験を歓迎に |
| 経験年数 | — | 必須にしない |

基準の要点は、「資格と会社の規模を必須にせず、自社の水準と分担と同じ形で担った経験を必須にする」ことです。一人経理の自社に、上場企業の経理の一部を担った経験は要りません。要るのは、一人で月次を締め、年次を税理士と分担した経験です。

### エラベルの見解

相談で多いのは、「簿記の資格があって、上場企業で決算の経験があって、うちの会計ソフトが使える人」というご要望です。自社は一人経理で、記帳から月次まで社内、年次は税理士と分担。この要件で来る人は、大企業の経理の一部を深く担った人で、一人で全体を回した経験が無く、税理士との分担にも慣れていません。要件が、自社の水準と規模に合っていません。

見ていて差がつくのは、「自社の水準・規模・分担から、必須を逆算しているか」です。「一人経理、月次まで社内、年次は税理士と分担、引き継ぎは一部」なら、必須は「一人で月次を締めた経験」「年次の準備を税理士と分担した経験」「業務を整理し直した経験」の三つ。資格も会社の規模もソフトも、歓迎か不要です。エラベルでは、経理の要件を整理するとき、依頼側に顧問の税理士を交えて水準と分担を先に決めていただき、そこから必須を逆算しています。

## 必須を三つに絞る手順

経理向けに、絞る手順を番号付きで整理します。

1. **自社の水準を決める。** 記帳まで、月次まで、年次まで、開示まで。どこまでを社内で。
2. **規模と体制を決める。** 一人経理か、チームか。上司は誰か。相談相手は誰か。
3. **税理士や外部との分担を書き出す。** 記帳、月次、年次、申告の担い手。
4. **引き継ぎの状態を把握する。** 文書化の有無、止まっている業務。
5. **現場（経営者、税理士、経理の分かる人がいればその人）の希望を全部書き出す。** ここでは絞らない。
6. **一つずつ、「初日に自社の水準と分担で経理が成り立つか」を問う。** 成り立たないものだけ残す。
7. **残ったものが三つを超えたら、「入社後に覚えられるか」「税理士や外部が持てるか」を問う。** 会計ソフト、業界の慣行、税理士が担う工程は歓迎へ。
8. **資格・会社の規模・ソフト・年数を、担った水準と規模の経験に書き換える。** 「上場企業で決算の経験」ではなく「一人経理として月次を締め、年次の準備を税理士と分担した経験」。
9. **歓迎に回したものを、優先順位を付けて三〜五つ書く。** 面接で見る点になる。
10. **経営者・税理士・人事で確認する。** 「この三つがあれば、他は入社後に補える」と言えるか。

手順の要点は、「三で、税理士との分担を書き出す」ことです。分担が決まると、社内で担う水準が決まり、必須はそこから逆算できます。

## 経歴で確かめられる要件と、面接や実技でしか分からない要件

経理では、経歴の「経理を担当」が水準を表さないので、確かめ方の区別が重要です。

| 確かめる方法 | 要件の例 | 見方 |
|---|---|---|
| 経歴で確かめられる | 担った水準（記帳まで、月次まで、年次まで、開示まで）、規模（一人かチームか、会社の規模）、税理士との分担の有無、使ったソフトの種類、立て直しの経験の有無 | 書類の一次絞りで。「経理業務全般」ではなく、「何を、どこまで、一人でかチームでか」の記述があるかを見る |
| 経歴では分からない | 実務の正確さ、月次の締めの段取り、判断に迷う仕訳への向き合い方、税理士との連携の仕方、業務を整理する力、経営への説明の仕方 | 面接で、経理の分かる人（税理士でも）が聞く。「月次の締めの手順を最初から順に」「判断に迷った仕訳の例」。[構造化面接](/media/rpo-kouzou-mensetsu/) |
| 経歴でも面接でも分かりにくい | 実際の処理の速さと正確さ | 短い実技（仕訳の判断、簡単な資料の作成）や、業務委託での試行 |

分け方の要点は、「面接で、月次の締めの手順を最初から順に話してもらう」ことです。「経理を担当」の裏に、どこまでを自分が担い、どこから税理士に渡し、どう締めていたかが、手順の話で見えます。

## 転向層を母集団に入れる要件の書き方

経理は経験者の母数が多いですが、自社の水準と規模に合う人に絞ると狭くなります。転向層を入れる書き方を整理します。

| 転向元 | 持っているもの | 要件の書き方 | 面接で確認すること |
|---|---|---|---|
| 会計事務所・税理士事務所の担当 | 複数の会社の記帳と決算、税理士との連携 | 「複数の会社の記帳から決算の準備までを担った経験」。一人経理に向く | 一つの会社の経理を深く持つことを望んでいるか |
| 大企業の経理（一部の業務の担当） | 特定の業務の深さ、正確さ | チームの一員なら「〇〇の業務を担った経験」。一人経理なら「全体を回した経験」を確認 | 一人で全体を回せるか。小さな会社の裁量に魅力を感じるか |
| 小さな会社の一人経理 | 全体を回す力、税理士との分担 | 「一人で月次を締め、年次を税理士と分担した経験」 | 自社の水準（決算まで社内か）と合うか |
| 経理以外の管理部門（総務、人事）で経理を兼務 | 管理部門の全体像、小さな会社の実務 | 「管理部門で経理を兼務し、月次の締めに関わった経験」。水準は面接で | 経理を専任で担う意欲 |
| 営業事務や販売管理の担当 | 請求と入金の管理、数字の扱い | 記帳と請求・支払が中心の募集なら「請求と入金の管理の経験」。月次の締めは歓迎に | 経理の水準を上げる意欲。教える体制が要る |

書き方の要点は、「一人経理なら会計事務所からの転向層、チームなら大企業からの転向層が合いやすい」ことです。自社の規模で、合う転向元が変わります。

## 要件が決まらないときの原因

| 原因 | 起きていること | 直し方 |
|---|---|---|
| 水準が決まっていない | 「経理ができる人」 | どこまでを社内で担うかを決める |
| 税理士との分担が曖昧 | 「税理士と相談しながら」 | 記帳、月次、年次、申告の担い手を書き出す |
| 引き継ぎの状態を把握していない | 前任者が辞めて誰も分からない | 税理士に全体を整理してもらう |
| 資格と会社の規模で書いている | 書きやすい | 担った水準と規模の経験に書き換える |
| 前任者を基準にしている | 「前の人は決算まで一人で」 | 前任者が入社時に持っていたものと、社内で身に付けたものを分ける。前任者が辞めた理由も見る |
| 経理の分かる人が要件の議論にいない | 経営者と人事だけで決めている | 顧問の税理士を要件の整理に入れる |
| 市場の実態を知らない | 「この要件で普通にいるはず」 | 代行や媒体に、その要件での人数を聞く |

原因の要点は、「税理士との分担が曖昧」なことが経理に特有だという点です。分担が決まれば、社内の水準が決まり、必須は逆算できます。

## 代行に出せる工程

| 工程 | 社内で持つ | 代行に出せる |
|---|---|---|
| 水準・規模・分担の決定 | 判断（税理士を交えて） | 決める打ち合わせの進行 |
| 引き継ぎの状態の把握 | 社内と税理士が出す | 一覧にする |
| 必須と歓迎の分離 | 「初日に成り立つか」の判断は社内 | 問いを立て、一つずつ確認する進行 |
| 資格・規模・ソフト・年数の書き換え | 中身は社内が出す | 担った水準と規模の経験の言葉に直す |
| 転向層を入れる要件の設計 | 判断 | 自社の規模に合う転向元からの書き方の提案 |
| 市場の実態の確認 | 判断 | その要件での人数を示す |
| 求人票への反映 | 確認 | 書く |
| 書類の一次絞り | 実務の水準の妥当性 | 水準と規模の分類。「何を、どこまで、一人でかチームでか」の記述の有無 |
| 面接で見る点の整理 | 経理の分かる人が使う | 歓迎の要件と、「月次の締めの手順を順に」の質問の案 |

分け方の要点は、「水準と分担は、税理士を交えて社内で決める」ことです。代行は、決める打ち合わせの進行と、決まったものの言語化、転向層の設計を担えます。

### エラベルの見解

担当する側から見ると、経理の要件で最も時間がかかるのは、依頼側が「資格」と「大企業の経験」を手放すことです。安心のために求めたこの二つが、自社の一人経理に合わない人を探す原因になっている、と分かるまでに時間がかかります。水準と規模と分担から逆算すると、必須は「一人で月次を締めた経験」「年次の準備を税理士と分担した経験」「業務を整理し直した経験」に落ち着き、会計事務所からの転向層が母集団に入ります。

エラベルでは、経理の案件で要件が整理されていない場合、担当者の最初の仕事を「税理士を交えて水準と分担を決める打ち合わせの進行」にすることをお勧めしています。分担が決まると、社内の水準が決まり、求人票の一行目が書け、自社の規模に合う転向層が見えます。飛ばして「資格と大企業の経験」を待つと、来ても一人経理を回せない人を採ることになります。

## まとめ

- 経理の必須要件は、**先に水準・規模・税理士との分担を決め、「入社初日に自社の水準と分担で経理が成り立つか」で三つ以内**に
- 要件が膨らむ理由は**資格を必須にする・会社の規模を実績にする・決算の経験を一括りにする・ソフトを必須にする・年数で書く**
- **資格・会社の規模・ソフト・年数は必須にしない**。担った水準と規模の経験（何を、どこまで、一人でかチームでか）で書く
- 絞る手順は**水準→規模と体制→税理士との分担→引き継ぎの状態→全部書き出す→初日に成り立つか→覚えられるか・税理士が持てるか→経験に書き換え→歓迎に優先順位→三者で確認**
- **面接では月次の締めの手順を最初から順に話してもらう**。実技も短く
- **一人経理なら会計事務所からの転向層、チームなら大企業からの転向層**が合いやすい
- 決まらない原因に**税理士との分担が曖昧**なことが経理に特有

## よくある質問

### 簿記の資格を必須にしないと、実務の水準が分かりません

資格は、知識の目安にはなりますが、自社の水準で実務が回せるかを示しません。実務の水準は、面接で「月次の締めの手順を最初から順に」と聞くか、短い実技（仕訳の判断）で確かめます。資格は歓迎に置き、必須は「自社の水準と分担と同じ形で担った経験」で書きます。資格を必須にすると、資格が無くても一人経理を長く回してきた人や、会計事務所で実務を積んだ人を弾き、母集団が狭まります。実務の水準の評価は、経理の分かる人（税理士でも）が担います。

### 上場企業の経理の経験者なら、うちの経理は簡単に回せますか

回せないことがあります。上場企業の経理は分業が進んでいて、特定の業務（売掛の管理、固定資産、連結の一部）を深く担ってきた人が多く、記帳から決算の準備までの全体を一人で回した経験が無いことがあります。しかも、大企業の仕組み（承認の流れ、システム）が無い小さな会社で、自分で全部を組み立てることに戸惑うことがあります。一人経理なら、「一人で全体を回した経験」を必須にし、会社の規模は問いません。上場企業の経験者でも、子会社で全体を回した人や、小さな会社から移った人は合います。

### 税理士に何を任せ、社内に何を残せばよいか、自分でも決められません

顧問の税理士に、「いま何を税理士が担っていて、何を社内が担っていて、社内の担い手が変わるならどう分担するのが現実的か」を整理してもらいます。税理士は、自社の帳簿と申告を見ていて、分担の現実的な形を最も知っています。整理の結果、「記帳は社内、月次の締めは社内で税理士が確認、年次の決算と申告は税理士」のような分担が決まれば、社内の水準が決まり、要件が逆算できます。税理士との分担を決めずに募集すると、入社した人が「税理士がやると思っていた」「社内でやると思っていた」のずれに直面します。
