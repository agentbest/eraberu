介護職の採用を代行に出すか迷う施設は、「求人を出しても応募が来ず、紹介会社と派遣に頼っているが費用が重い」「未経験でも採りたいのに、未経験の人にどう届ければよいか分からない」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、業態と施設と業務の整理・配置と夜勤の方針・未経験の育成と資格取得の支援の方針・要件の決定・介護の姿勢と利用者との関わりの評価・合否の判断は社内に残す**のが線です。介護職は、看護師や薬剤師と違って無資格や未経験でも入れる分、母集団の中心が「経験者」ではなく「未経験・異業種からの転向・地域の主婦層やシニア・外国人」にあります。「未経験を迎え入れる仕組みを作り、施設の実態を正直に示す」ことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じ施設系の看護師の線は[看護師採用を代行に出す判断基準](/media/rpo-kangoshi-rpo/)にまとめています。

## 介護職採用が他の職種と違う点

一つ目は、業態で業務と市場が違うことです。特別養護老人ホーム（介護度の高い利用者、夜勤あり）、老人保健施設（在宅復帰を目指す、リハビリと連携）、有料老人ホーム（施設によって介護度と接遇の要求が違う）、グループホーム（認知症の少人数）、デイサービス（日勤のみ、送迎あり）、訪問介護（一人で訪問、移動あり）。夜勤の有無、身体的負担、利用者との関わり方が違い、「介護職募集」だけでは、どの業態のどの業務かが候補者に伝わりません。

二つ目は、無資格や未経験でも入れる一方で、資格が配置や加算に関わることです。介護福祉士や研修の修了は、施設の配置基準や加算の要件に関わり、資格を持つ人の数が施設の運営に影響します。無資格で採って、働きながら資格を取ってもらう道筋を作ることが、母集団を広げつつ配置を満たす方法になります。配置基準と加算の要件は、法令と制度で定められているので、専門家にご確認ください。

三つ目は、母集団の中心が未経験・異業種からの転向・地域の主婦層やシニア・外国人にあることです。経験者は限られ、施設同士で取り合いになります。未経験の人にとって、介護は「自分にできるか分からない」「体力的に不安」「夜勤が不安」な仕事で、その不安に答える求人票と、迎え入れる育成の仕組みが無いと、応募に至りません。外国人の採用は、在留資格と制度が関わるので、専門家にご確認ください。

四つ目は、候補者が「夜勤の回数と体制」「利用者の介護度」「職員の人数と一人あたりの利用者数」「身体的負担と機器（移乗、入浴、介護ロボットやリフト）」「休みの取り方」「施設長と人間関係」「資格取得の支援」「給与の内訳」を最初に確かめることです。経験者は施設の実態で判断し、未経験者は「自分にできるか」「教えてもらえるか」で判断します。「介護業務全般」では、どちらも判断できません。

五つ目は、施設長や主任は現場にいて、採用の工程を回す人がいないことです。施設長は利用者の対応と職員の管理を回していて、面接の時間を取るのも難しい。本部の事務が回そうとしても、施設の実態を知らず、求人票が抽象的になります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 業態と施設と業務の整理 | 残す | どの業態のどの施設で、どの業務（身体介護、生活援助、レクリエーション、送迎、記録）を任せるか。社内にしか分からない |
| 配置と夜勤の方針の決定 | 残す | 夜勤の回数と体制、配置基準と加算の要件をどう満たすか、資格者の割合。法令に関わるので専門家に確認 |
| 未経験の育成と資格取得の支援の方針の決定 | 残す | 未経験を採るか、教える体制（指導者、期間、手順）、資格取得の支援（費用、時間、研修）、外国人の受け入れ。施設長と経営者が決める |
| 要件の決定 | 残す | 業態・施設・業務と未経験の方針から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（業態・施設・業務と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。未経験の不安に答える形で |
| 媒体の選定と運用 | 任せられる | 介護職と未経験の層に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 業態・業務・勤務地に合わせた検索と、担当してきた施設や異業種の経験に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、施設見学の案内。未経験者には不安に答える連絡 |
| 施設長・主任の面接の日程の確保 | 任せられる | 利用者の対応の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 業態・業務・勤務地・資格・経験の有無の分類は任せられる。介護の姿勢の評価は残す |
| 介護の姿勢と利用者との関わりの評価 | 残す | 施設長や主任が面接と見学で見る |
| 施設の実態と方針の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 施設の判断 |
| 条件の決定と提示 | 残す | 施設の判断。資格の手当、夜勤の手当、加算の扱いで条件の幅が広い |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。未経験者には入職前の不安に答える連絡 |

線の要点は、「業態と施設と業務、配置と夜勤の方針、未経験の育成と資格取得の支援の方針が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、経験者が「この施設で働けるか」を、未経験者が「自分にできるか、教えてもらえるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「介護職の求人を出しても応募が来ず、紹介会社と派遣に頼っているが、費用が重くて経営を圧迫している。未経験でもよいのに来ない」というご相談です。求人票を見ると、「介護職員募集。未経験歓迎。資格取得支援あり。夜勤あり」と書かれていて、業態も、利用者の介護度も、職員の人数も、夜勤の回数と体制も、身体的負担と機器も、教える体制の中身も、資格取得の支援の中身も無い。経験者は「施設の実態が分からない」で見送り、未経験者は「未経験歓迎と書いてあるが、本当に教えてもらえるのか分からない」で見送っていました。

見ていて差がつくのは、「施設の実態と、未経験を迎え入れる仕組みを一文で言えるか」です。「〇〇市の特別養護老人ホームで、利用者は〇〇人、介護度は高め。職員は日勤〇人、夜勤は二人体制で月に〇回程度。移乗にはリフトを使い、入浴は機械浴。未経験の人には指導者を一人つけて、最初の一か月は日勤で基本の介助から。資格取得は費用を施設が負担し、研修の時間は勤務扱い。休みは月に〇日で希望はほぼ通る。施設長は〇〇の経験が長く、こういう人」。一文で実態と仕組みが分かれば、経験者は施設の実態で判断でき、未経験者は「教えてもらえる」「体力的に工夫がある」と判断できます。エラベルでは、介護職の案件をお受けする前に、依頼側に「業態・施設・業務」と「夜勤と育成と資格取得の方針」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：業態と施設と業務。** どの業態の、どの施設で、どの業務を任せるか。利用者の人数と介護度、職員の人数と一人あたりの利用者数、身体介護の割合、送迎や記録の有無、訪問介護なら一日の訪問件数と移動。

**二つ目：配置と夜勤の方針。** 夜勤の回数と体制（何人夜勤か）、配置基準と加算の要件をどう満たしているか、資格者の割合、採る人が入ることでどう変わるか。夜勤の免除や回数の調整の方針。法令に関わるので、専門家に確認します。

**三つ目：未経験の育成と資格取得の支援の方針。** 未経験を採るか、何人まで受け入れられるか。教える体制（指導者の配置、期間、手順、最初に任せる業務）。資格取得の支援（費用の負担、研修の時間の扱い、取得後の手当）。外国人の受け入れ（在留資格と制度に関わるので専門家に確認）。子育て中の層やシニアの受け入れ（時間帯、身体的負担の配慮）。

**四つ目：いまの施設の状態と実態。** 誰が何を担当していて、何が属人化していて、何が止まっているか。施設長が全部を見ていて回らない、夜勤が組めず一部の人に偏っている、離職が続いて教える余裕が無い、身体的負担で辞める人が多い。残業の実態、休みの希望が通る率、離職の状況と原因。正直に把握し、「どこまで書くか」を決めます。

**五つ目：施設長や主任が、面接にどのくらい時間を出せるか。** 利用者の対応の合間に、面接の枠と施設見学の時間をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 施設長の関与のさせ方

介護職の採用では、施設長や主任の関与が要ります。面接で介護の姿勢を見る、施設を見せる、施設の実態と方針を正直に話す、未経験者の不安に答える。しかし施設長は利用者の対応と職員の管理を回していて、「採用は本部の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると施設長がどう楽になるか」を具体的に示すことです。「この人が入れば、夜勤の偏りが減る」「派遣の費用が減る」。そして、負担を最小にする形で頼みます。面接の枠は代行が利用者の対応の合間に押さえる、経歴は代行が整理して渡す、実態の説明の要点は代行が用意する。施設長がやるのは、介護の姿勢を見ることと、施設を見せて実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で施設長が「施設の実態」を話し、未経験者の不安に答えることの価値を、施設長自身に理解してもらうことです。介護職の候補者は、本部の話より、施設長の話を信じます。未経験者は「自分にできるか」を施設長の言葉で確かめます。施設長が「最初の一か月は日勤で、指導者と一緒に基本の介助から。移乗はリフトがあるから腰を痛めにくい。夜勤は慣れてから、最初は一緒に入る」と話すと、未経験者は「教えてもらえる施設」と判断します。

## 代行を選ぶときの確認項目

介護職の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に介護施設や福祉業界の経験があるか。** 介護職そのものでなくても、施設の管理部門や、介護職の採用を回した経験。業態の違い、施設の実態の見方、配置基準と加算の存在、未経験の育成の仕組みを知っているか
- **施設の実態と未経験を迎え入れる仕組みを求人票にどう書くか、案を出せるか。** 「介護業務全般」「未経験歓迎」で済まさず、介護度と職員の人数と夜勤の体制と身体的負担と機器と教える体制と資格取得の支援を書けるか
- **介護職と未経験の層に届く媒体と経路の経験。** 介護職向けの媒体、地域の求人、主婦層やシニアに届く経路、異業種からの転向、外国人の受け入れの経路（制度は専門家に確認）、紹介会社と派遣との併用の設計。経路ごとの経験
- **紹介会社と派遣への依存から自施設採用へ移す設計。** 併用しながら自施設で採る仕組みをどう作るか。費用と離職の見え方を整理できるか
- **施設長の日程を押さえる段取り。** 利用者の対応の合間に面接の枠を確保する方法。施設見学を組み込めるか

五つのうち、一つ目と三つ目が大きい。福祉業界を知らない担当者は、施設の実態を書けず、未経験の層に届く経路を持たず、紹介会社と派遣との差が出ません。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、介護職の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「未経験を迎え入れる仕組みが無いと、未経験歓迎と書いても来ない」と言われることです。「未経験歓迎」と書いても、教える体制と最初に任せる業務と資格取得の支援の中身が無いと、未経験者は「本当に教えてもらえるのか」を疑います。仕組みが無いなら、採用の前に施設長と作ります。

二つ目は、応募者の経験と経路が分かれることです。介護の経験者、異業種からの転向（接客、販売、製造）、地域の主婦層、シニア、外国人、子育て中でパートを希望する人。それぞれ持っているものと動く理由と不安が違い、任せる業務と合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることと、不安に答える内容を変えます。

三つ目は、「身体的負担」と「離職の状況」の実態で、候補者が判断を変えることです。介護の経験者は、移乗と入浴の負担と機器の有無を確かめ、離職が続いている施設を地域の評判で知っています。未経験者は、体力的な不安を持っています。施設長が身体的負担の実態と機器と工夫を正直に話し、離職が続いているなら原因と対策を話すことで、候補者の判断が変わります。

### エラベルの見解

担当する側から見ると、介護職の採用で最も効くのは、「未経験を迎え入れる仕組み（教える体制、最初に任せる業務、資格取得の支援、身体的負担への工夫）を、中身まで求人票に書く」ことです。介護職の母集団の中心は未経験の層で、その層は「未経験歓迎」の言葉ではなく、「本当に教えてもらえるか」「体力的に続くか」の答えで動きます。「介護業務全般。未経験歓迎」の求人票では、経験者にも未経験者にも届きません。

エラベルでは、介護職の案件で担当者を紹介するとき、最初の一週間で施設長と本部から「業態・施設・業務」「配置と夜勤の方針」「未経験の育成と資格取得の支援」「実態」を聞き取り、一文にするところから始めてもらっています。介護の姿勢と利用者との関わりの評価は施設長が面接と見学で行い、配置基準と加算の要件、外国人の受け入れの制度は、専門家にご確認いただくようお伝えしています。

## まとめ

- 介護職採用が他と違うのは**業態で業務と市場が違う・無資格や未経験でも入れる一方で資格が配置と加算に関わる・母集団の中心が未経験と異業種と地域の主婦層やシニアと外国人・候補者が施設の実態（夜勤・介護度・職員の人数・身体的負担と機器・休み・施設長・資格取得の支援・給与の内訳）と「自分にできるか」を最初に確かめる・施設長は現場にいて採用の工程を回す人がいない**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、業態と施設と業務・配置と夜勤の方針・未経験の育成と資格取得の支援・要件・介護の姿勢の評価・合否は残す**
- 代行に出す前に**業態と施設と業務、配置と夜勤の方針（専門家に確認）、未経験の育成と資格取得の支援と外国人の受け入れ（制度は専門家に確認）、いまの施設の状態と実態、施設長の面接の時間**を確認する
- 施設長の関与は**採用でどう楽になるかを示し、負担を最小にして、施設の実態を話し未経験者の不安に答える価値を理解してもらう**
- 代行を選ぶときは**福祉業界の経験・実態と仕組みの書き方・未経験の層に届く経路・紹介会社と派遣から自施設採用へ移す設計・日程の段取り**を確認する
- 出したあとは**仕組みが要ることが表に出る・経験と経路が分かれる・身体的負担と離職の状況で判断が変わる**。判断は施設長と経営者、材料は代行

## よくある質問

### 未経験を採って、本当に戦力になりますか

教える体制と最初に任せる業務と資格取得の道筋があれば、なります。未経験の人は、最初の一か月は日勤で指導者と一緒に基本の介助から始め、慣れてから夜勤に入り、働きながら研修を修了して資格を取る。この道筋を施設が用意し、求人票に書くことで、未経験の層から応募が来て、定着します。仕組みが無いまま「未経験歓迎」と書いて採ると、教える余裕が無く、早期に離職します。仕組みを作ることが、未経験採用の前提です。配置基準と加算に関わる資格者の割合は、専門家にご確認ください。

### 身体的負担が大きいのが実態です。正直に書くと来ませんか

隠して面接や入職後に分かるほうが、辞退と離職を生みます。「移乗にはリフトを使い、入浴は機械浴。身体介護の割合は〇割程度。腰痛の予防の研修をしている」のように、実態と、施設の工夫を一緒に書きます。工夫が無いなら、採用の前に機器の導入や手順の見直しをします。身体的負担で辞める人が多い施設は、採用を増やしても離職が続きます。負担を減らす工夫そのものが、求人票の訴求になります。

### 外国人の介護職を採りたいのですが

外国人の採用は、在留資格の種類と制度によって、受け入れの形と施設側の要件が決まっています。受け入れの形（制度の種類）、施設側の体制（日本語の支援、生活の支援、指導者）、費用と期間を、専門家に確認した上で決めます。採用代行が担えるのは、受け入れの形が決まった後の、求人票と経路と一次対応と面接の段取りです。制度に関わる判断と手続きは、専門家にご確認ください。
