毎年、決算期や年度末や商戦の時期になると、現場が忙しくなり、採用が止まる。面接官の日程が取れない。書類の判断が返ってこない。人事も本業の繁忙で、応募への返信が遅れる。候補者は一か月待たされ、他社に決まる。繁忙期が明けて再開すると、候補者はいなくなっていて、また応募を集めるところから。結論を先に書くと、**繁忙期に採用が止まるのは、「忙しいから仕方ない」ではなく、「止まらない工程と、止めてよい工程を分けていない」からです。応募への返信、日程の枠、結果の連絡は、繁忙期でも止めません。求人票の見直しや新しい経路の開拓は、止めてよい。分けて、繁忙期の前に準備し、繁忙期の中は最小の型で回します**。急な欠員での立ち上げは[急な欠員でスカウトを立ち上げる](/media/scout-kyuu-boshuu/)に、急な増員は[急な増員要請に対応できない](/media/rpo-kyuu-zouin/)にまとめています。

## 繁忙期に止まる構造

繁忙期に採用が止まるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 採用が「空いた時間」に置かれている | 繁忙期は空いた時間が無くなり、採用がゼロになる |
| 全部の工程を、同じ人が担っている | 面接官も人事も繁忙。全部が同時に止まる |
| 止めてよい工程と止めてはいけない工程が、分かれていない | 「忙しいから全部止める」になる |
| 繁忙期を、想定していない | 毎年来るのに、毎年「今年は忙しくて」で止まる |
| 候補者に、繁忙期を伝えていない | 候補者は「連絡が無い」としか受け取らない |
| 繁忙期の前に、進めておかない | 繁忙期の直前に求人を出し、繁忙期に応募が来て、対応できない |
| 繁忙期の後の立て直しが、一からになる | 止まっている間の候補者を失い、再開時に応募から集め直す |

繁忙期は、毎年来ます。来ることが分かっているものに、準備しないことが、問題です。

## 止まらない工程と止めてよい工程

工程を、繁忙期でも止めてはいけないものと、止めてよいものに分けます。

| 止めてはいけない工程 | 理由 | 繁忙期の担い方 |
|---|---|---|
| 応募への受付の返信 | 止めると候補者が流れる | 自動返信か、担当者か、繁忙でない人 |
| 書類の判断 | 三日以内が目安。止めると候補者が流れる | 基準を書面にし、繁忙でない人か担当者が一次の絞り込み。判断は現場に「観点一つ」で |
| 面接の日程調整 | 止めると候補者が流れる | 繁忙期の面接の枠を、先に押さえておく |
| 面接の結果の連絡 | 止めると口コミに書かれる | 面接の直後に五分で判定。連絡は担当者 |
| 選考中の候補者への連絡 | 放置は辞退と不信 | 「繁忙期のため、次のご連絡は〇日です」と伝える |
| 内定者との接点 | 入社前の辞退を防ぐ | 月に一度の連絡は続ける |

| 止めてよい工程 | 理由 | 繁忙期の後に |
|---|---|---|
| 求人票の見直し | 繁忙期の前に済ませておく | 繁忙期の後に、応募の記録を見て直す |
| 新しい経路の開拓 | 繁忙期に応募が増えても対応できない | 繁忙期の後に |
| 面接の基準や観点の見直し | 面接官の時間が要る | 繁忙期の後に |
| 採用ページや素材の更新 | 急がない | 繁忙期の後に |
| 紹介会社との関係作り（新規） | 繁忙期に推薦が来ても対応できない。既存の関係は維持 | 繁忙期の後に |
| 新しい求人の開始 | 繁忙期に出しても回らない | 繁忙期の前か後に |

分ける要点は、「候補者が待っている工程は止めない」ことです。候補者がいない工程（見直し、開拓、新規）は、止めてよい。

## 繁忙期の前にやること

繁忙期が来る前に、準備します。繁忙期の一か月前が目安です。

**繁忙期の時期を、カレンダーに入れる。** 「毎年、〇月〜△月が繁忙期」。分かっているものを、書き出します。

**繁忙期に入る候補者の数を、想定する。** 「繁忙期の前に出した求人から、繁忙期中に応募が何件、面接が何件来そうか」。自社の記録から。

**面接の枠を、繁忙期の中に先に押さえる。** 面接官と相談し、「繁忙期でも、週に一枠は面接に使う」を先に押さえます。繁忙期に入ってから頼んでも、取れません。

**書類の判断の基準を、書面にする。** 繁忙期に現場が判断できない場合、担当者か繁忙でない人が一次の絞り込みをできるように。

**面接官向けの一枚を、用意しておく。** 繁忙期の面接官が、準備の時間を取れなくても面接できるように。

**候補者への連絡の文面を、繁忙期用に用意する。** 「〇月〜△月は繁忙期のため、ご連絡に通常より時間をいただくことがあります。次のご連絡は〇日です」。

**新しい求人は、繁忙期の前に出すか、後に回す。** 繁忙期の直前に出すと、繁忙期に応募が来て、対応できません。「繁忙期の二か月前に出す」か「繁忙期の後に出す」か。

**繁忙期の間の担当を、決める。** 人事が繁忙なら、採用代行の担当者か、繁忙でない部門の人か。「誰が応募を見て、返信を出すか」。

**内定者との接点の予定を、入れておく。** 繁忙期でも、月に一度の連絡は入れておきます。

準備の要点は、「繁忙期に頼まない」ことです。面接の枠も、判断の基準も、担当も、繁忙期の前に決めておきます。

## 繁忙期の中で回す型

繁忙期の中は、最小の型で回します。

| 工程 | 繁忙期の型 |
|---|---|
| 応募の確認 | 毎朝十分。担当者か繁忙でない人が。受付の返信は当日 |
| 書類の判断 | 一次の絞り込みは担当者。現場には「観点一つで、五分で」。三日以内 |
| 面接 | 先に押さえた枠で。一次は三十分、オンライン。面接官向けの一枚を前日に |
| 面接の判定 | 面接の直後に五分。「後でまとめて」を認めない |
| 結果の連絡 | 判定が出た日に、担当者が文面の型で |
| 選考中の候補者 | 週に一度、「進み具合と次の連絡の日」を伝える。放置しない |
| 内定者 | 月に一度の連絡 |
| 新しい応募 | 受付と一次の絞り込みは行う。面接は枠の範囲で。枠を超える分は、「繁忙期のため、面接は〇月以降になります」と伝えて待ってもらうか、辞退を受け入れる |
| 止める工程 | 求人票の見直し、新しい経路、新しい求人、基準の見直しは、繁忙期の後に |

回す型の要点は、「毎朝十分」「面接は先に押さえた枠」「判定は直後に五分」の三つです。三つが回れば、候補者は流れません。

「枠を超える応募は待ってもらう」判断は、候補者に正直に伝えることが前提です。「繁忙期のため」と伝えれば、待つ候補者もいます。伝えずに放置するより、はるかに良いです。

### エラベルの見解

相談で最も多い失敗は、「繁忙期の直前に求人を三本出し、繁忙期に応募が五十件来て、誰も見られず、繁忙期が明けたら全員が他社に決まっていた」というものです。求人を出す時期が、繁忙期と合っていませんでした。繁忙期の二か月前に出して繁忙期の前に面接を進めるか、繁忙期の後に出すか。時期を変えるだけで、五十件は無駄になりませんでした。

見ていて差がつくのは、担当者が「繁忙期のカレンダー」を持っているかどうかです。「求人を出しましょう」と時期を見ずに言う担当者と、「御社の繁忙期は〇月〜△月ですね。求人は繁忙期の二か月前に出して、面接の枠は繁忙期の中に週一枠を先に押さえましょう。繁忙期の間は、私が毎朝応募を見て返信します」と、時期から設計する担当者がいます。後者は、繁忙期に止まりません。

発注側にできるのは、担当者に「自社の繁忙期の時期」を最初に伝えることです。伝えていなければ、担当者は繁忙期を知りません。

## 繁忙期の後の立て直し

繁忙期が明けたら、立て直します。

**繁忙期中の候補者の状態を、確認する。** 選考中の候補者、待ってもらった候補者、内定者。「まだいるか、進めるか」を、明けた週に全員に連絡します。

**待ってもらった候補者を、優先して進める。** 繁忙期に「〇月以降」と伝えた候補者を、最初に面接に入れます。

**止めていた工程を、順に再開する。** 求人票の見直し、新しい経路、新しい求人。優先順位を付けて。

**繁忙期の記録を、振り返る。** 「繁忙期に応募が何件、面接が何件、辞退が何件、辞退の理由は」。来年の準備の材料です。

**来年の繁忙期の準備を、カレンダーに入れる。** 「来年の繁忙期の一か月前に、準備を始める」。今年の振り返りから、変えることを一つ決めます。

**面接官と現場に、感謝を伝える。** 繁忙期の中で面接の枠を出してくれた面接官に、責任者から。来年も枠を出してもらうために。

立て直しの要点は、「明けた週に全員に連絡する」ことです。繁忙期の間に待たせた候補者は、明けても連絡が無ければ、離れます。

## 年間の採用の時期の設計

繁忙期を前提に、年間の採用の時期を設計します。

**繁忙期を、年間のカレンダーに入れる。** 自社の繁忙期（決算、年度末、商戦、季節の要因）を、月で書き出します。複数あれば、全部。

**採用にかかる期間を、自社の記録で持つ。** 「応募から入社まで、この職種は三か月」。

**求人を出す時期を、逆算する。** 「繁忙期の前に入社してほしいなら、繁忙期の四か月前に求人を出す」「繁忙期の後でよいなら、繁忙期が明けてすぐ出す」。

**面接の集中する時期を、繁忙期と重ねない。** 求人を出してから面接が集中するのは、出した一〜二か月後。その時期が繁忙期と重ならないように、出す時期を調整します。

**内定の時期と、候補者の市場の動きを見る。** 候補者が動きやすい時期（賞与の後、年度の変わり目など）があります。市場の動きは[夏・冬のボーナス時期の転職市場](/media/scout-natsu-fuyu/)に書いています。自社の繁忙期と、候補者の動く時期を、重ねて見ます。

**年間の求人の予定を、一枚にする。** 「〇月に営業の求人を出す、△月に面接、□月に内定、入社は◇月」。職種ごとに。要員計画との対応は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

**予定どおりに行かないことを、前提にする。** 予定は仮で、四半期ごとに見直します。

年間の設計があれば、「繁忙期だから止まる」は、「繁忙期は最小で回し、前後で進める」に変わります。

## 外注する場合の範囲

繁忙期に採用が止まる問題を、採用代行に出す場合の範囲です。

**出せる工程。** 繁忙期の時期の整理と年間のカレンダー、止めない工程と止める工程の分け方の案、繁忙期の前の準備（面接の枠の依頼の調整、基準の書面、一枚、文面の型、担当の設計）、繁忙期の中の運用（毎朝の応募の確認と返信、一次の絞り込み、日程調整、判定の催促、結果の連絡、候補者と内定者への定期の連絡）、繁忙期の後の立て直し（全員への連絡、待ってもらった候補者の優先、止めた工程の再開）、繁忙期の記録の振り返り、年間の求人の予定の一枚、来年の準備のカレンダー。

**社内に残す判断。** 繁忙期の時期の決定、面接官が出す枠の決定、繁忙期に判断を任せる範囲の決定、待ってもらう候補者の扱いの方針、求人を出す時期の決定。

**外注の効きどころ。** 繁忙期の問題は、「繁忙期に動ける人がいない」ことが根本です。担当者は社内の繁忙とは無関係に動けるので、繁忙期の間の「毎朝の確認と返信、絞り込み、日程、連絡」を担当者が回せば、止まりません。面接官の枠だけは社内が要るので、繁忙期の前に担当者が枠の調整を進めます。

**外注しても動かない場合。** 面接官が繁忙期に枠を一つも出さない、責任者が繁忙期の準備を認めない、求人を出す時期を変えない。社内の判断で、代行を替えても直りません。

繁忙期は、準備と最小の型で乗り切れます。外注は、繁忙期に動ける人を置く手段です。

### エラベルの見解

担当する側から見ると、繁忙期の相談で最も多いのは、「面接官が繁忙期に枠をゼロにする」ことです。「繁忙期は無理」と、一つも出さない。週に一枠、三十分のオンライン面接でも、あれば候補者は流れません。ゼロだと、全員が流れます。

「繁忙期でも週に一枠」を、繁忙期の前に責任者から面接官に頼んでもらう。頼むのは責任者で、担当者ではありません。担当者が頼んでも、「忙しい」で終わります。

発注側にできるのは、繁忙期の前に、責任者から面接官に「週に一枠」を頼むことです。

## まとめ

- 止まるのは**採用が空いた時間に置かれる・全部を同じ人が担う・止める工程と止めない工程が分かれていない・想定していない・候補者に伝えない・前に進めておかない・後の立て直しが一から**の構造
- 止めない工程は**受付の返信・書類の判断・日程調整・結果の連絡・選考中の候補者への連絡・内定者との接点**。止めてよい工程は**求人票の見直し・新しい経路・基準の見直し・素材の更新・新規の紹介会社・新しい求人**
- 前には**カレンダー・候補者の数の想定・面接の枠を先に・基準を書面に・一枚・繁忙期用の文面・新しい求人は前か後に・担当を決める・内定者の予定**。繁忙期に頼まない
- 中は**毎朝十分・一次は担当者・先に押さえた枠・判定は直後に五分・連絡は当日・週に一度の進み具合・内定者は月に一度・枠を超える分は正直に伝えて待ってもらう・止める工程は後に**
- 後は**明けた週に全員に連絡・待ってもらった候補者を優先・止めた工程を順に・記録を振り返る・来年の準備をカレンダーに・面接官に感謝**
- 年間は**繁忙期をカレンダーに・採用の期間を記録で持つ・出す時期を逆算・面接の集中と繁忙期を重ねない・候補者の動く時期と重ねて見る・一枚・四半期で見直す**
- 外注できるのは**カレンダー・分け方・前の準備・中の運用・後の立て直し・振り返り・年間の一枚**。社内に残るのは**時期の決定・枠の決定・任せる範囲・待ってもらう方針・出す時期**

## よくある質問

### 繁忙期は、採用を完全に止めてもよいですか

候補者が待っている工程（受付の返信、書類の判断、日程、結果の連絡、選考中と内定者への連絡）は、止めません。止めると、候補者が流れ、口コミに書かれ、繁忙期の後に一から集め直すことになります。止めてよいのは、候補者がいない工程（求人票の見直し、新しい経路、新しい求人、基準の見直し）です。「全部止める」ではなく、「最小で回す」にします。面接の枠が週に一つでもあれば、候補者は流れにくくなります。

### 面接官が繁忙期に面接の時間を出せません

繁忙期の前に、責任者から面接官に「週に一枠、三十分のオンライン面接」を頼んでもらいます。繁忙期に入ってから頼んでも、取れません。一枠でもゼロとは違います。枠を超える応募は、「繁忙期のため、面接は〇月以降になります」と正直に伝え、待ってもらうか、辞退を受け入れます。伝えずに放置するより、はるかに良いです。それでも枠がゼロなら、繁忙期の前後に採用の時期を寄せる設計にします。

### 繁忙期の直前に、急に求人を出すことになりました

繁忙期に応募が来て、対応できない可能性が高いです。出すなら、「受付の返信と一次の絞り込みは担当者が行い、面接は繁忙期の中の週一枠で、枠を超える分は繁忙期の後に」と、回す型を先に決めます。候補者には「〇月〜△月は繁忙期のため、面接は□月以降になることがあります」と、求人票か案内で伝えます。出す時期を繁忙期の後にずらせるなら、ずらすほうが、候補者を無駄にしません。急な増員への対応は[急な増員要請に対応できない](/media/rpo-kyuu-zouin/)に書いています。
