中途の採用で成果を出してきた担当者が、新卒の設計を頼まれると、中途の型（要件の一枚・スカウト・面接の設計）をそのまま当てて、ずれます。新卒は、経歴で読めるものがほとんど無く、複数の候補者を同じ時期に動かし、内定から入社までが長い。中途の型の一部は使えますが、組み方が違います。結論を先に書くと、**新卒採用の設計は、年間の流れ・役割と要件・育てる体制・内定から入社までの接点の四つで組み、要件は経歴ではなく「場面で確かめる項目」を中心にし、選考は複数を同時に動かす段として設計し、内定後の接点は時期ごとに置き、育てる体制が無ければ採らない判断を依頼側に残し、時期や慣行は依頼側と専門家で確認します。**案件として受ける形は[新卒採用の設計の副業の実務](/media/fukugyo-shinsotsu-sekkei-shigoto/)に、会社側の手順は[新卒採用の実務の進め方](/media/rpo-task-shinsotsu-unyou-susumekata/)に、定着の構造は[新卒が定着しない](/media/rpo-shinsotsu-teichaku/)に書いています。ここでは、設計の型に絞ります。

## 中途の型をそのまま当てるとずれる

| 中途の型 | 新卒でずれる点 |
|---|---|
| 要件の必須は「経歴で読める言葉」 | 経歴が無い。読めるのは学業・活動・アルバイトの場面まで |
| 一人ずつ、随時 | 同じ時期に複数を同時に動かす。段の設計が「一人」ではなく「群」 |
| 内定から入社まで短い | 長い。その間に他社の内定、迷い、辞退が起きる |
| 入社後は「最初の三か月」で一人で回す | 育てる期間が長い。育てる体制が無ければ採っても定着しない |
| 求人票は役割ごと | 役割が決まっていないことが多い。「配属」の設計が要る |

中途の型で使えるのは、「面接で確かめる項目を場面で聞く」「記録は事実と判断を分ける」「迷いに答える」の三つです。それ以外は組み直します。新卒と中途の配分の考え方は[新卒と中途のどちらに投資すべきか](/media/rpo-shinsotsu-ka-chuuto/)に書いています。

## 設計の四つ

| 決めること | 中身 |
|---|---|
| 年間の流れ | いつ募集し、いつ選考し、いつ内定を出し、いつ入社か。時期の慣行は変わるので依頼側と確認 |
| 役割と要件 | 入社後にどの役割に就くか（配属の決め方）。要件は「場面で確かめる項目」が中心 |
| 育てる体制 | 入社後、誰が、どのくらいの期間、何を教えるか。無ければ採らない判断 |
| 内定から入社までの接点 | 時期ごとに、誰が、何を。迷いに答える |

四つのうち、依頼側が最も見落とすのは「育てる体制」です。体制が無いまま採ると、入社後に放置され、定着しません。設計の段階で「育てる体制が無ければ、今年は採らない」を選択肢に入れ、依頼側が判断します。

### エラベルの見解

担当する側から見ると、新卒の設計で最も差がつくのは、「育てる体制」を採る前に確かめているかです。受ける側は、母集団の作り方（説明会、媒体、インターン）に力を入れ、入社後のことは現場に任せます。ただ、新卒は入社後に一年かけて育つもので、教える人と時間が無ければ、採った意味がありません。「入社後、最初の一年で、誰が、週に何時間、何を教えますか」を依頼側に聞き、答えが無ければ、母集団の設計より先に体制の話をします。エラベルで担当者を選ぶ企業には、「新卒を採る前に、育てる人と時間を決めていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、設計の一枚の先頭に「育てる体制」の欄を置き、埋まらなければ次の欄に進まないこと。

## 要件は「場面で確かめる項目」が中心

| 中途の要件 | 新卒の要件 |
|---|---|
| 必須（経歴で読める） | 学業・活動・アルバイトの記述で読めるものは少ない。「必須」は最小に |
| 歓迎 | 専攻や資格。法令上要るもの以外は歓迎 |
| 面接で確かめる項目 | 中心。「決まりの無いことを自分で決めて進めた場面」「意見が分かれた相手と合意した場面」を、学業や活動の中で |

新卒の要件は、「入社後に育てられる人か」を場面で見るものです。「即戦力」の言葉は使いません。要件の起こし方は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)と同じで、「いまうまくやっている若手が、入った頃どうだったか」から起こします。

基準にしてはいけない項目（性別・国籍・家族の状況など）は、新卒でも同じです。学校名だけで判断することの扱いも、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。

## 選考は複数を同時に動かす段

| 段 | 新卒での設計 |
|---|---|
| 入口 | 説明会、インターン、媒体からの応募。複数の入口から同じ段に合流させる |
| 書類 | 読めるものが少ないので、絞りは緩く。「面接で確かめる項目」に関わる記述があるか |
| 面接 | 同じ観点、同じ基準で、多数の候補者を同じ時期に。面接官の枠を大きく預かる |
| 内定 | 決める人が、記録を横に並べて。一人ずつではなく群で見る |
| 内定後 | 下の接点 |

面接の設計（観点・基準・記録）は中途と同じ型で、[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/)と[評価シートを作る](/media/fukugyo-skill-hyouka-sheet/)に書いています。違うのは、同じ時期に多数を動かすので、面接官の枠を先に大きく預かることと、記録を横に並べて比べる形にすることです。

## 内定から入社までの接点

| 時期の考え方 | 誰が | 何を |
|---|---|---|
| 内定の直後 | 人事 | 迷いに答える。他社の状況は無理に聞かない |
| 中間 | 一緒に働く予定の若手 | 「入った頃どうだったか」を話す。押さない |
| 入社の前 | 現場の責任者 | 最初の三か月と配属の見通し |
| 入社の直前 | 人事 | 手続きと、入社日からの流れ |

接点は「押す」ためではなく、迷いに答えるためのものです。頻度が高すぎると負担になり、無いと他社に流れます。時期ごとに一つ。内定辞退の構造は[内定辞退を減らす](/media/fukugyo-skill-jitai-boushi/)に、動機づけの型は[動機づけの設計](/media/fukugyo-skill-douki-zuke/)に書いています。内定後の接点の内容や頻度に関する慣行や決まりは、依頼側と専門家で確認します。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「新卒は母集団の数で決まる」というものです。実際には、母集団が多くても、要件が「場面で確かめる項目」になっておらず、面接の記録が印象で、内定後の接点が無ければ、辞退と早期離職で減ります。母集団は一つの要素で、四つの設計が揃って初めて機能します。数を集める施策（説明会の規模、媒体の数）に費用を使う前に、四つの一枚を作ることを勧めます。受ける側がその場で使える判断としては、依頼側が「母集団を増やしたい」と言ったら、「去年の内定辞退と入社一年以内の離職の数」を先に聞くこと。そこに数字があれば、母集団より先に直す場所があります。

## 時期と慣行は依頼側と専門家で確認

新卒の採用には、募集や選考の時期、内定の出し方、学生への情報提供などについて、慣行や法令上の整理があると一般に整理されています。これらは変わることがあり、担当者が「一般にこの時期」と断定せず、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。担当者は、年間の流れの一枚に「確認する項目」を並べ、依頼側が確認した内容で埋めます。

## 学生の情報の扱い

| 決めること | 中身 |
|---|---|
| 取得する情報 | 選考に要る最小に。学業と活動の記述、連絡先 |
| 同意と保管 | 依頼側の決まりに従う。担当者は手元に持たない |
| 選考に使わない情報 | 家族の状況、思想、健康の状態など。取得しない |
| 内定後の情報 | 入社の手続きに要るものは依頼側の人事が扱う |

学生の情報の扱いも、応募者の情報と同じく個人情報の扱いに関わります。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が母集団の施策から始める | 四つの一枚を先に。去年の辞退と離職の数を聞く |
| 育てる体制が無い | 「今年は採らない」を選択肢に。判断は依頼側 |
| 要件が「即戦力」「優秀」のまま | 場面で確かめる項目に。若手が入った頃の場面から |
| 面接官の枠が足りない | 同じ時期に多数を動かす前提で、枠を大きく預かる |
| 内定後に接点が無く辞退 | 時期ごとに一つの接点 |
| 時期や慣行を担当者が断定した | 依頼側と専門家の確認に戻す。一枚は「確認する項目」の形に |

## まとめ

- 中途の型をそのまま当てるとずれる。使えるのは**場面で聞く・記録を分ける・迷いに答える**の三つ
- 設計は**年間の流れ・役割と要件・育てる体制・内定から入社までの接点**の四つ
- **育てる体制を先に**。無ければ「採らない」を選択肢に。判断は依頼側
- 要件は**場面で確かめる項目が中心**。「即戦力」を使わない。基準にしてはいけない項目は同じ
- 選考は**複数を同時に動かす段**。枠を大きく預かり、記録を横に並べる
- 内定後の接点は**時期ごとに一つ、押さず、迷いに答える**
- **時期と慣行は依頼側と専門家で確認**。担当者は断定しない。個別の判断は専門家にご確認ください
- 学生の情報は最小に、担当者は手元に持たない

## よくある質問

### 依頼側が初めて新卒を採る会社で、何も決まっていません

四つの一枚を、育てる体制から順に依頼側と一緒に埋めます。初めての会社では、「一人だけ採る」形から始めることを勧めます。一人なら、育てる体制も配属も内定後の接点も設計しやすく、翌年に増やす判断の材料になります。時期や慣行の確認は、専門家と一緒に進めます。初めての会社に「一般的な新卒採用の型」を持ち込むと、体制と合わず崩れます。

### 第二新卒は、新卒の型と中途の型のどちらで設計しますか

どちらでもなく、依頼側の役割と育てる体制の中で位置づけます。経歴が短いので中途の必須は読めず、社会人の経験があるので新卒の育てる期間より短い。「場面で確かめる項目」は新卒の型、「最初の三か月」は中途の型に近い形で組みます。位置づけの考え方は[第二新卒をどう位置づけるか](/media/rpo-second-shinsotsu/)に書いています。

### インターンを新卒の選考につなげたいと言われました

インターンと選考の関係は、慣行や法令上の整理に関わることがあるので、依頼側の決まりと専門家の確認に従います。設計の型としては、インターンの目的（知ってもらう・体験してもらう・見極める）を先に決め、選考との関係を参加者に明示する形にします。インターンの設計は[インターンを設計する](/media/fukugyo-skill-intern/)に書いています。
