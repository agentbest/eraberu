人材紹介の会社で、リクルーティングアドバイザー（RA）として、企業側を担当してきた。要件を聞き、求人を作り、候補者を推薦し、決まらないときは企業に理由を返す。この経験は、企業側の人事の副業で売れるのか。紹介の立場と、企業の担当者の立場は違う。結論を先に書くと、**RAの経験は、「企業の要件を聞き、求人を作り、決まらない理由を企業側に返す」型で売れます。売れるのは、「要件の言語化と求人の設計」「決まらない理由の切り分け」「面接と条件の設計への助言」「複数の企業を見てきた型」の四つです。RAは、多くの企業の「決まらない理由」を、候補者側の反応を通して見てきていて、企業側の担当者になると、その理由を最初から直せます。ただし、紹介の形は捨て、「企業側の担当者として、決まらない理由を直す」と売ります。紹介の経験で得た候補者と情報は持ち込みません。**人材紹介の経験の評価は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に、CAの経験の売り方は[人材紹介のキャリアアドバイザーが副業でできること](/media/fukugyo-agent-ca-fukugyo/)に、ヘッドハンターの売り方は[ヘッドハンターが副業でできること](/media/fukugyo-headhunter-fukugyo/)にまとめています。

## この経歴の何が売れるか

RAの経験を、企業側の担当者としての工程に置き換えた棚卸しです。紹介の候補者と前の会社の情報は含めず、「型」として抜き出します。

| RAの経験 | 企業側の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 企業の要件を聞き取り、求人を作ってきた | 依頼側の「こういう人がほしい」を、業務、技能、経験、条件に分解し、候補者に伝わる求人票にする | 要件が曖昧で、求人票が社内の言葉になっている依頼側が多い |
| 決まらない理由を企業に返してきた | 「応募が来ない」「面接で落ちる」「辞退される」を、要件、求人票、面接、条件、速さのどこに原因があるかで切り分ける | 「決まらない」としか見えていない依頼側に、原因の場所を示せる |
| 候補者側の反応を企業に伝えてきた | 候補者が求人票のどこで冷め、面接のどこで離れ、条件のどこで辞退するかの型 | 候補者側の反応が見えていない依頼側が多い |
| 面接の設計に助言してきた | 面接の回数、面接官、質問、判断の速さについて、候補者が離れない設計を助言する | 面接の回数が多く、判断が遅く、辞退される依頼側が多い |
| 条件の設計に助言してきた | 市場の候補者に対して、条件のどこが弱く、どこを変えれば決まるかを、数値を断定せずに構造で示す | 条件が市場とずれていることに気づいていない依頼側 |
| 多数の企業を見てきた | 規模と業界ごとに、決まる企業と決まらない企業の違いの型 | 「うちだけがうまくいかない」と感じている依頼側に、型を示せる |
| 企業の担当者と関係を作ってきた | 依頼側の担当者と経営者の間で、採用の判断を引き出す対話 | 判断が遅れ、候補者を逃す依頼側 |

売れるものの要点は、「決まらない理由を、候補者側の反応から見てきた」ことが価値だということです。RAは、企業に候補者を推薦し、断られ、辞退され、その理由を候補者側（CA）から聞き、企業に返すことを繰り返してきています。企業側の担当者は、その理由を外から知る機会が無く、RAの経験がある人は、決まらない理由を最初から直せます。求人票の作り方は[求人原稿のライティングの副業の実務](/media/fukugyo-kyujin-raiting-shigoto/)に、課題の切り分けは[課題を構造化する](/media/fukugyo-kouzou-ka/)に、面接の設計は[面接代行の副業案件](/media/fukugyo-mensetsu-daikou-fukugyo/)に書いています。

## 売りにくい点とその扱い

RAの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 紹介と担当者の立場の違い | 「候補者を紹介してくれるのか」「結局、紹介の手数料の話になるのでは」 | 「紹介ではなく、御社の担当者として、決まらない理由を直します。手数料は受けません」と最初に示す。紹介の形で報酬を受けることの可否は専門家に確認し、副業では担当者の形に徹する |
| CAとの分業の穴 | RAは企業側を担当し、候補者との直接の面談はCAが担っていたので、「候補者と直接話せるのか」 | 候補者との面談は、経験が薄いことを正直に示し、最初は範囲に入れないか、依頼側の担当者と一緒に担う。要件と求人と切り分けと助言を主に売る |
| 候補者の情報の線 | 「前の会社で推薦した候補者を連れてくるのでは」 | 紹介の経験で得た候補者と情報は持ち込まない。型だけを持ち込み、候補者は依頼側の名前で新しく探す。退職後の競業と守秘の条件を確認する |

扱い方の要点は、「CAとの分業の穴を、正直に示す」ことです。RAは企業側の担当で、候補者との直接の面談や口説きはCAが担っていたことが多く、その部分は経験が薄いことがあります。それを隠して「候補者の面談もできます」と受けると、依頼側の期待とずれます。「候補者との面談は、御社の担当者と一緒に担いながら型を作ります。要件と求人と決まらない理由の切り分けは、私の得意な工程です」と、得意と薄い部分を分けて示します。紹介の形の可否は、専門家にご確認ください。法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)の「法令で気をつける点」に、前の会社との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、RAから転身して続いている人と、案件が取れない人の差は、「紹介会社にいました」と言うか、「決まらない理由を、要件、求人票、面接、条件、速さのどこにあるかで切り分けて、直します」と言うかです。前者は依頼側に「紹介の営業」と映り、後者は「うちの詰まりを見つけてくれる人」と映ります。RAの経験は、紹介の言葉のまま売ると警戒され、企業側の工程に置き換えると強く伝わります。

見ていて差がつくのは、「決まらない理由」を、依頼側が受け入れられる形で返しているかです。RAは、紹介の立場では企業に遠慮して理由を柔らかく返していたことが多く、企業側の担当者になると、逆に率直に返しすぎて依頼側が身構えることがあります。「面接の回数が多すぎます」ではなく、「候補者は二回目の面接の後に辞退が多く、判断を一回目で出せる形にすると減ります。理由は〇〇です」と、候補者側の反応と直し方を添えて返す人は、依頼側から「外の目で見てくれる人」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、決まらない理由の切り分けと直し方を明確にし、紹介との線を示している担当者に、決まらないことで詰まっている依頼側がついています。RAの転身は、紹介の知識ではなく、立場の切り替えと返し方で始まります。

## 案件の探し方

RAから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 決まらない理由の切り分け | 理由を企業に返してきた経験でそのまま入れる | 「決まらない依頼側」を範囲の一言に。「要件、求人票、面接、条件、速さのどこか」で切り分ける |
| 要件の言語化と求人票の設計 | 求人を作ってきた経験で入れる | 「『良い人』を業務と技能と条件に分解し、候補者に伝わる求人票に」を成果物の形で |
| 面接の設計への助言 | 面接に助言してきた経験で入れる | 「面接の回数と判断の速さで辞退が減る設計」を提案の形で |
| 条件の設計への助言 | 条件に助言してきた経験で入れる | 「条件のどこが弱いかを構造で示す」。数値は断定せず、依頼側の情報と公開の情報で |
| 採用の判断を引き出す対話 | 企業の担当者と関係を作ってきた経験で入れる | 「判断が遅れて候補者を逃す依頼側」を範囲の一言に |
| 紹介会社を使っているが決まらない依頼側 | 紹介会社の側の動き方を知っている | 「紹介会社に何をどう伝えれば推薦が来るか」を助言の形で |

探し方の要点は、「紹介会社を使っているが決まらない依頼側」を狙うことです。RAは、紹介会社がどんな企業に推薦を出し、どんな企業を後回しにするかを、中から見てきています。依頼側が紹介会社に何をどう伝えれば推薦が来るか、要件のどこを直せば紹介会社が動くかを助言できるのは、RAの経験がある人だけです。ただし、前の会社を優先させる形は取らず、依頼側の側に立ちます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に、経営者との対話は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。RAの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 紹介の手数料との比較 | 紹介の手数料と、担当者の副業の単価は、決まり方が全く違う | 手数料の感覚を持ち込まない。担当者の工程の単価で |
| 切り分けと設計の価値 | 決まらない理由の切り分けと、要件と求人票の設計は、成果物で受けやすく、価値が分かりやすい | 成果物で受ける |
| 助言の継続 | 面接と条件と判断への助言は、月額の顧問の形で受けやすい | 月に何回、何時間、と枠を決めて月額に |
| 候補者との面談を含まないこと | 面談を含まない範囲は、含む範囲より単価は下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 成果報酬の扱い | 紹介の習慣で誘われやすいが、判断は依頼側にあり、許可の線にも関わる | 時間か月額か成果物で。可否は専門家に確認 |
| 前の会社との契約の条件 | 退職後の競業と守秘の条件があることがある | 契約を確認し、個別の判断は専門家に |

単価の要点は、「紹介の手数料の感覚を、副業に持ち込まない」ことです。RAの報酬は紹介の成功に対する手数料で、副業の担当者の単価とは決まり方が別物です。切り分けと設計は成果物、助言は月額、と分けて、担当者の工程の単価で受けます。成果報酬は、判断が依頼側にあることと、許可の線に関わることから、最初は避け、可否は専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

RAから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、紹介の形で報酬を受けることの可否と、前の会社との契約の条件を、専門家に確認する | 職業紹介の許可、競業、守秘 |
| 二、副業では「企業側の担当者として動く」形に徹する、と決める | 紹介の形を捨てる |
| 三、担当してきた企業の「決まらない理由」を、企業と候補者の情報を含まない型で書き出す | 要件、求人票、面接、条件、速さの五つで分類 |
| 四、得意な工程（要件、求人、切り分け、助言）と、薄い工程（候補者との面談）を分ける | 正直に示す準備 |
| 五、範囲を、要件の言語化、求人票の設計、切り分け、面接と条件と判断への助言に絞る | 面談は最初は範囲外か、依頼側と一緒に |
| 六、「企業側の担当者として、決まらない理由を直す」の一言を作る | 「紹介会社にいました」で終わらせない |
| 七、登録先に、範囲と、紹介との線を登録する | 決まらない依頼側、紹介会社を使っているが決まらない依頼側 |
| 八、決まらない理由の切り分けを一件、成果物で受け、直すところまで回す | 次の工程に広げる材料に |

順番の要点は、「三」で、決まらない理由を五つ（要件、求人票、面接、条件、速さ）で分類して書き出しておくことです。RAの経験の核は、この分類の型で、依頼側との最初の面談で「御社はどこで決まらないか」を聞きながら、五つのどこかに当てはめられれば、その場で価値が伝わります。分類の型を持たずに面談に行くと、「紹介会社にいました」で終わります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「RAは企業に候補者を売る営業で、企業側の人事とは逆の立場だ」というものです。実際には、RAは企業の要件を聞き、求人を作り、決まらない理由を候補者側から聞いて企業に返す、という企業側の採用の外部の目を、毎日担ってきています。逆の立場なのではなく、企業側の採用の詰まりを、外から最もよく見てきた立場です。立場を企業側の担当者に切り替え、紹介の形を捨てれば、その目がそのまま価値になります。

順番として、紹介の形の可否と前の会社との契約を専門家に確認し、担当者の形に徹すると決め、決まらない理由を五つで分類した型を書き出し、得意な工程と薄い工程を分け、範囲を要件と求人と切り分けと助言に絞り、企業側の担当者として決まらない理由を直す、の一言を作り、登録先に範囲と線を登録し、切り分けを一件成果物で受けて直すところまで回す。この順番で、RAの転身は、「候補者を売る営業」から「決まらない理由を直す担当者」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、切り分けと直し方を明確にし、紹介との線を示している担当者に、決まらないことで詰まっている依頼側がついています。RAの転身は、紹介の知識ではなく、立場の切り替えと分類の型で始まります。

## まとめ

- RAの経験は**「企業の要件を聞き、求人を作り、決まらない理由を企業側に返す」型**で売れる。**要件の言語化と求人の設計・決まらない理由の切り分け・面接と条件への助言・多数の企業の型**の四つ
- **「紹介会社にいました」ではなく「企業側の担当者として、決まらない理由を直す」**と売る。紹介の形は捨て、可否は専門家に確認
- 売りにくい点は**紹介と担当者の立場・CAとの分業の穴・候補者の情報の線**。候補者との面談が薄いことは正直に示し、候補者と情報は持ち込まない
- 決まらない理由は**要件・求人票・面接・条件・速さ**の五つで分類し、候補者側の反応と直し方を添えて返す
- 案件は**決まらない依頼側、紹介会社を使っているが決まらない依頼側**から。ただし前の会社を優先させない
- 単価は**紹介の手数料の感覚を持ち込まず、切り分けと設計は成果物、助言は月額**で。成果報酬は最初は避ける

## よくある質問

### 前の会社の紹介会社を、依頼側に紹介してよいですか

依頼側の側に立つ担当者として、複数の紹介会社の使い方を助言することはできますが、前の会社だけを勧める、前の会社から紹介の報酬を受ける、という形は避けます。前の会社との契約に退職後の条件がある場合はそれを確認し、紹介の報酬を受けることの可否は専門家にご確認ください。依頼側には、「紹介会社に何をどう伝えれば推薦が来るか」という使い方の型を渡し、どの紹介会社を使うかは依頼側が選ぶ形にします。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法令の注意は[人材紹介の経験は評価されるか](/media/fukugyo-agent-keiken/)に整理しています。

### 候補者との面談の経験がほとんどありません。範囲に入れなくてよいですか

最初は範囲に入れず、要件と求人票と切り分けと助言に絞って受けて構いません。「候補者との面談は御社の担当者が。私は決まらない理由を切り分け、要件と求人票を直し、面接と条件の設計を助言します」と示せば、範囲が明確です。面談も担いたいなら、依頼側の担当者と一緒に面談に同席し、型を学びながら小さく担います。CAの経験がある人と組む形も、エラベルのような登録先では可能なことがあります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、分担は[チームで動くときの分担](/media/fukugyo-chiimu/)に書いています。

### 依頼側の条件が市場とずれていると感じます。数値で示してよいですか

自分の記憶や前の会社の内部の情報で数値を断定することは避けます。「候補者側の反応として、この条件で辞退が多い傾向があります。公開の情報と、御社の過去の辞退の理由で確認しましょう」と、構造と確認の流れで示します。前の会社で知った他社の条件の情報は、守秘の線を越えるので使いません。数値は、依頼側の情報と公開の情報から一緒に集め、判断は依頼側が持ちます。数字の扱いは[数字で語る](/media/fukugyo-suuji/)に、守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に整理しています。
