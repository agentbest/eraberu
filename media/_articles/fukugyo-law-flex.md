副業で人事を受けていると、「フレックスにしたい」という相談が増えています。採用の場面でも、勤務時間の柔軟さは聞かれる項目になりました。ところが、導入した会社の書類を見ると、就業規則だけで運用していたり、コアタイムの定めが協定にしかなかったりします。結論を先に書くと、**労働基準法第32条の3第1項は「使用者は、就業規則その他これに準ずるものにより、その労働者に係る始業及び終業の時刻をその労働者の決定に委ねることとした労働者については、…書面による協定により、次に掲げる事項を定めたときは、…労働させることができる」と定めています。**つまり、**就業規則等での定め**と**労使協定**の二つが揃って初めて成り立ちます。個別の判断は労働基準監督署にご確認ください。他の制度との比較は[変形労働時間制の要件](/media/fukugyo-law-henkei/)に、裁量労働制は[裁量労働制の要件](/media/fukugyo-law-sairyou/)にまとめています。

## 二段構えの要件

**一段目：就業規則その他これに準ずるもの。**条文は「**その労働者に係る始業及び終業の時刻をその労働者の決定に委ねることとした労働者**については」としています。**始業と終業の時刻を労働者が決める**という定めを、就業規則（常時十人未満の事業場では就業規則に準ずるもの）に置きます。就業規則の整備は[就業規則の作成義務](/media/fukugyo-law-shugyo-kisoku/)にまとめています。

**二段目：労使協定。**過半数労働組合等との**書面による協定**で、次を定めます。

- 一 この項の規定による労働時間により労働させることができることとされる**労働者の範囲**
- 二 **清算期間**（その期間を平均し一週間当たりの労働時間が第32条第1項の労働時間を超えない範囲内において労働させる期間をいい、**三箇月以内の期間**に限るものとする）
- 三 **清算期間における総労働時間**
- 四 その他厚生労働省令で定める事項

**省令事項（施行規則第12条の3第1項）。**

- 一 **標準となる一日の労働時間**
- 二 労働者が**労働しなければならない時間帯を定める場合**には、その時間帯の開始及び終了の時刻（**コアタイム**）
- 三 労働者が**その選択により労働することができる時間帯に制限を設ける場合**には、その時間帯の開始及び終了の時刻（**フレキシブルタイム**）
- 四 清算期間が**一箇月を超えるもの**である場合にあつては、協定の**有効期間の定め**

**コアタイムとフレキシブルタイムは任意です。**条文は「定める場合には」「制限を設ける場合には」と書いており、置かなければならないものではありません。完全に自由な設計（いわゆるスーパーフレックス）も、条文の上では成り立ちます。ただし、置くなら協定に開始と終了の時刻を書く必要があります。

**「標準となる一日の労働時間」は定めます。**年次有給休暇を取得した日の労働時間の扱いなどに使う数字です。第一号は「定める場合には」という限定が付いていないので、コアタイムの有無にかかわらず定めます。

## 清算期間が1か月を超える場合

**原則の枠（第32条の3第1項）。**清算期間を平均し一週間当たりの労働時間が**週四十時間**を超えない範囲内。

**一箇月を超える場合の追加（第32条の3第2項）。**読替えにより、「労働時間を超えず、かつ、当該清算期間をその開始の日以後**一箇月ごとに区分した各期間**…ごとに当該各期間を平均し一週間当たりの労働時間が**五十時間を超えない**」ことが求められます。

**つまり二重の縛りです。**清算期間全体の平均で週四十時間以内であることに加えて、**月ごとに区切った各期間の平均で週五十時間以内**であることが要ります。ある月に働きすぎて翌月で調整する、という運用には上限がかかります。

**届出（第32条の3第4項）。**第32条の2第2項（行政官庁への届出）が準用されます。ただし書きで「**清算期間が一箇月以内のものであるときは、この限りでない**」とされているので、**一箇月を超える場合だけ届出が必要**という整理です。施行規則第12条の3第2項は、様式第三号の三により所轄労働基準監督署長に届け出ることを定めています。

**週所定労働日数が五日の労働者の特例（第32条の3第3項）。**読替えにより、労使協定で労働時間の限度について「**当該清算期間における所定労働日数を一日八時間に乗じて得た時間**」とする旨を定めたときは、清算期間における日数を七で除して得た数でその時間を除して得た時間を基準とする、という調整が認められています。暦日数と所定労働日数のずれを調整するための規定です。

**途中入退社の精算（第32条の3の2）。**「使用者が、清算期間が一箇月を超えるものであるときの当該清算期間中の前条第一項の規定により労働させた期間が**当該清算期間より短い労働者**について、当該労働させた期間を平均し**一週間当たり四十時間を超えて労働させた場合**においては、その超えた時間（第三十三条又は第三十六条第一項の規定により延長し、又は休日に労働させた時間を除く。）の労働については、**第三十七条の規定の例により割増賃金を支払わなければならない**」。清算期間の途中で入社・退職した人については、実際に働いた期間で平均して精算します。

### エラベルの見解

担当する側から見ると、フレックスの案件で最初に決めるべきなのは**清算期間の長さ**です。一箇月にするか、それを超えるか。ここで手続も管理の手間も変わります。一箇月以内なら届出は不要で、各月の平均週五十時間の縛りもかかりません。三箇月にすると、季節や案件の波に合わせられる代わりに、届出と月ごとの上限管理が加わり、途中入退社の精算も要ります。

実務では、まず一箇月で始めることを勧めています。運用が回ってから、本当に三箇月が必要かを判断する。最初から三箇月で設計して、管理が追いつかずに形骸化した会社を何度か見ました。**制度は、回せる範囲から入れる**のが確実です。

もう一つ、フレックスは**労働時間の把握をやめる制度ではありません**。始業・終業の時刻を労働者が決めるだけで、実際に何時間働いたかは会社が把握します。清算期間の総労働時間との過不足を計算する必要があるので、むしろ把握の精度は上がります。「フレックスにしたから勤怠は自己申告でよい」という運用になっている会社は、ここから直します。把握の方法は[テレワークの労務管理](/media/fukugyo-law-telework/)でも触れています。

そして、フレックスは**採用の材料になります**。求人票に「フレックスタイム制（コアタイムなし）」と書けるかどうかで、応募の集まりが変わります。制度を入れる目的を「働きやすさ」で終わらせず、採用の数字で語れるようにすると、経営の判断が早くなります。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この接続を示せる人は、制度まわりの案件で指名されます。

## 両立支援との接続と、会社に渡すもの

**育児介護休業法の「始業時刻変更等の措置」。**同法第23条第2項第二号は、業務の性質等により三歳未満の子を養育する労働者に所定労働時間の短縮措置を講じないこととする場合の代替措置として、「**労働基準法第三十二条の三第一項の規定により労働させること**その他の労働者の申出に基づく厚生労働省令で定める…措置」を挙げています。**フレックスタイム制が、条文上の措置として位置づけられている**ということです。

同法第23条の3第1項は、三歳から小学校就学の始期に達するまでの子を養育する労働者について、五つの措置のうち**二以上**を講ずることを求めており、その第一号が「始業時刻変更等の措置であって厚生労働省令で定めるもの」です。詳しくは[短時間勤務制度](/media/fukugyo-law-jitan/)にまとめています。

**短時間勤務より使いやすい場面があります。**所定労働時間を短縮すると賃金も下がりますが、フレックスは総労働時間を維持したまま時間帯を動かせます。保育園の送迎や通院の付き添いといった用事は、時間帯の調整で足りることがあります。選択肢として並べて示すと、本人が選べます。

副業の人事が作るのは、次の形です。個別の適否の判断は労働基準監督署にご確認ください。

| 作るもの | 中身 |
|---|---|
| 就業規則の条文 | **始業及び終業の時刻を労働者の決定に委ねる**旨。対象者の範囲 |
| 労使協定 | 対象者の範囲／清算期間（三箇月以内）／総労働時間／標準となる一日の労働時間 |
| コアタイム | 置くかどうか。置くなら開始と終了の時刻を協定に |
| フレキシブルタイム | 制限を設けるかどうか。設けるなら開始と終了の時刻を協定に |
| 総労働時間の算式 | 清算期間の暦日数から計算。月ごとの目安を一覧にする |
| 一箇月超の場合 | **各月平均で週五十時間以内**の監視。**届出**（様式第三号の三）と有効期間の定め |
| 過不足の処理 | 不足した場合の繰越や控除の扱い、超過した場合の割増。就業規則に明記 |
| 途中入退社 | 清算期間が一箇月を超える場合の精算（第32条の3の2） |
| 勤怠の運用 | 始業・終業の記録方法。把握をやめない |
| 会議・連絡の設計 | コアタイムがない場合の打ち合わせの取り方、連絡可能時間の目安 |
| 深夜・休日 | フレックスでも深夜割増と休日労働は別に管理 |
| 求人票の記載 | 就業時間の欄にどう書くか。[募集時の労働条件明示](/media/fukugyo-law-boshuu-jouken/)を参照 |

**過不足の処理を先に決めます。**清算期間の総労働時間に対して実際の労働時間が不足した場合の扱い（次の清算期間に繰り越すのか、賃金から控除するのか）は、条文に書かれていません。就業規則で定めておかないと、毎回もめます。繰越の可否には条文上の考え方があるため、設計の適否は労働基準監督署や社会保険労務士にご確認ください。

**コアタイムがない場合の会議設計。**制度を入れた会社で一番よく起きる不満は、「打ち合わせの時間が決まらない」です。フレキシブルタイムを設けない場合でも、社内の会議は特定の時間帯に寄せる、非同期で進められる仕事を増やす、といった運用の設計が要ります。**制度と働き方はセットで直します。**

### エラベルの見解

外に出してよいのは、就業規則の条文案、労使協定の項目立て、総労働時間の算式、届出の段取り、過不足処理の設計、勤怠運用と会議設計までで、「この協定で要件を満たすか」「この繰越の扱いが認められるか」といった個別の判断は、労働基準監督署や社会保険労務士の範囲です。

担当する側から見ると、フレックスの案件で価値が出るのは**「入れない部署」を決められるかどうか**です。店舗、工場のライン、電話の一次受け。時間帯を動かせない仕事は、どの会社にもあります。ここに無理に入れると、現場が破綻します。逆に、全社一律にしないと不公平だという声が出て、導入そのものが止まることもあります。

実務では、**職種ごとに使える制度を並べた一枚**を作ります。フレックスが向く職種、シフト制が向く職種、変形労働時間制が向く職種。そのうえで、フレックスが使えない職種には別の柔軟さ（時差出勤、半日単位の有給、シフトの希望提出）を用意する。**同じ制度ではなく、同じ程度の柔軟さを配る**という設計にすると、納得が得られます。

この整理は、待遇差の説明にも接続します。雇用形態や職種で扱いが違うことの理由を書き分ける作業は、[同一労働同一賃金](/media/fukugyo-law-doitsu-roudou/)の整理と同じ筋です。制度を一つ入れる案件から、人事制度全体の話に広がるのは、このためです。エラベルでは、依頼側が担当者を選べるので、この広がりを経験した人は、次の案件で選ばれやすくなります。

## まとめ

- 要件は二段。**就業規則その他これに準ずるもの**で**始業及び終業の時刻を労働者の決定に委ねる**定めを置き、**労使協定**で必要事項を定める
- 協定事項は、**対象労働者の範囲／清算期間（三箇月以内）／清算期間における総労働時間**と、省令の**標準となる一日の労働時間／コアタイム（定める場合）／フレキシブルタイム（制限を設ける場合）／一箇月超の場合の有効期間**
- **コアタイムとフレキシブルタイムは任意**。**標準となる一日の労働時間は定める**
- 清算期間が**一箇月を超える**場合は、全体平均で週四十時間以内に加えて、**一箇月ごとに区分した各期間の平均で週五十時間以内**
- **届出が必要なのは、清算期間が一箇月を超える場合**（様式第三号の三）
- **第32条の3の2**は、清算期間が一箇月を超える場合の**途中入退社の精算**を定めている。個別の判断は労働基準監督署にご確認ください

## よくある質問

### コアタイムは設けないといけませんか

労働基準法施行規則第12条の3第1項第二号は「労働者が労働しなければならない時間帯を**定める場合には**、その時間帯の開始及び終了の時刻」を協定で定める事項としています。「定める場合には」という書き方なので、コアタイムを設けないことも条文の上では成り立ちます。同様に、第三号のフレキシブルタイムも「制限を設ける場合には」とされています。一方、第一号の「標準となる一日の労働時間」にはこうした限定がありません。設計の適否は、労働基準監督署にご確認ください。

### 清算期間を3か月にすると、何が変わりますか

労働基準法第32条の3第2項は、清算期間が一箇月を超える場合について読替えを置き、清算期間を平均して週四十時間を超えないことに加えて、清算期間を一箇月ごとに区分した各期間を平均し一週間当たりの労働時間が五十時間を超えないことを求めています。また第4項ただし書により、清算期間が一箇月以内のときは届出が不要とされているので、一箇月を超える場合は届出が必要になります。施行規則第12条の3第1項第四号により、協定に有効期間の定めも要ります。さらに第32条の3の2により、途中入退社の場合の精算が必要になります。自社の運用に耐えるかを見てから決めるのが実務です。

### フレックスでも残業代は発生しますか

フレックスタイム制は、清算期間を平均して週四十時間を超えない範囲内で、特定の週や日に法定労働時間を超えて働かせることを認める仕組みです。清算期間の法定労働時間の総枠を超えた部分については、割増賃金の対象になります。また、清算期間が一箇月を超える場合は、各月の平均で週五十時間を超えた部分の扱いも生じます。深夜（午後十時から午前五時）の割増賃金や休日労働は、フレックスかどうかにかかわらず別に管理します。計算方法の個別の判断は、労働基準監督署や社会保険労務士にご確認ください。
