物流・運送の採用課題は、必要人数と採用・離職、資格と担当業務、条件説明、募集経路、連絡・選考の日程等に分けて確認します。**複数の要因が重なる場合があり、原因を一つに特定してから一つずつ直すことを固定の手順にはしません。**職種・拠点・期間をそろえた記録と本人の回答を手がかりに、必要な改善を並行して検討します。[物流・運送業界の採用代行](/media/rpo-butsuryu-rpo/)、[ドライバーの母集団形成](/media/rpo-driver-boshuudan/)も参照できます。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 離職 | 募集が止まらない。採っても数か月で離れる | 離職の時期と理由。募集の回数 |
| 免許 | 採ったが、免許の区分で配置できる車両が無い | 配置できなかった件数。要件に区分が無い |
| 実態 | 面接で「時間帯が聞いていない」。入社後に「拘束が思っていたのと違う」 | 辞退と早期離職の理由が「時間」「働き方」 |
| 経路 | 拠点によって応募の数が違う。倉庫の繁忙期に間に合わない | 拠点ごとの経路と応募の数 |
| 枠 | 日程が延びて「他社に決まった」 | 段階ごとの日数。責任者の枠の数 |

複数の問題がある場合は、資格・安全上の必要な確認を優先しながら、緊急性・影響と担当できる体制を踏まえて進めます。確認できない原因は不明とし、仮説と事実を区別します。

## 確認する記録と判断を分ける

| 領域 | 確認する記録 | 判断の注意 |
|---|---|---|
| 必要人数・離職 | 増員・欠員、入社と離職の時期・対象人数、本人の回答 | 継続募集を離職だけで説明しない |
| 資格・業務 | 実際の業務と資格区分、取得状況・照合の記録 | 不明な区分や配置は責任者へ確認する |
| 条件説明 | 求人・回答と勤務実態、本人の質問や辞退理由 | 「時間」という回答だけで原因を特定しない |
| 経路 | 職種・拠点ごとの表示・応募・選考 | 応募数の偏りだけで媒体の問題と決めない |
| 日程 | 連絡、社内承認、候補日と本人希望の調整時間 | 遅れを面接枠だけの原因としない |

採用と受け入れの見直しは、必要に応じて並行して進められます。どの工程が止まっているかと、誰が確認・判断するかを明確にします。[採用ファネルの見方](/media/rpo-funnel/)も参照できます。

### エラベルの見解

離職が課題かどうかは自社の対象人数・期間と本人が伝えた理由等で確認します。業界で最も多い原因と根拠なく断定せず、増員・条件・地域や募集実務等も検討します。退職理由は不明なら不明とし、現場の推測で書き換えません。[早期離職の確認](/media/rpo-souki-rishoku/)も参照できます。

## 離職の課題：採用を上回っている

| 確認する領域 | 点検する内容 |
|---|---|
| 教育・指導 | 必要な指導等の条件と実施記録、担当者・相談先。任意の同乗日数だけで足りるとは判断しない |
| 条件説明 | 勤務時間・休日等と原稿・面接の説明の整合、変更・回答の承認 |
| 職場体制 | 相談先と対応できる時間、問題発生時の処理 |
| 提示条件 | 本人の希望と、変更できる範囲・責任者 |
| 不明・私的事情 | 必要以上に詳細を集めず、配慮の希望は本人に確認。理由不明を推測で埋めない |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## 免許の課題：区分が要件に無い

| 状態 | 直し方 |
|---|---|
| 「ドライバー募集」だけで、免許の区分が無い | 会社と専門家で、車両と配置と免許の区分の関係を整理し、「必須・取得の支援・歓迎」の区分に |
| 採ってから配置できる車両が無いと分かる | 書類の一次確認で区分を照合 |
| 取得の支援の中身が無い | 若手を採るなら、支援の中身（費用の扱い、期間、取れなかった場合）を決め、求人票に |

実際の業務・車両に必要な資格と、取得状況・限定等の確認方法を責任者が整理します。外部の一次照合と資格・安全・配置の判断を分け、不明・不一致は社内へ確認します。取得支援は年齢だけで対象や希望を決めず、本人の希望と制度の実施条件を確認します。

## 実態の課題：先に出していない

| 求人票に無いこと | 書き方 |
|---|---|
| 時間帯 | 「早朝の開始」「夜間」など、実態の時間帯 |
| 拘束と休息の考え方 | 法令上の整理があるため、会社と専門家で決めた範囲の中で |
| 休日 | 「週の休日の形」の実態 |
| 配送の型 | ルート・長距離・拠点間など。一日の流れ |
| 一緒に働く人と最初の三か月 | 同乗の相手、教える人 |

労働時間の実態の書き方には法令上の整理があるため、専門家の確認を経た範囲で、正直に書きます。求人票の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

### エラベルの見解

募集経路は職種・拠点ごとの候補と利用条件を整理し、表示・応募・選考の実績を確認します。地域だけで差を説明せず、同時に仕事内容・勤務条件や連絡状況も確認します。新しい経路がどの拠点にも使える、一覧を作れば応募が増えるとは扱いません。[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)も参照できます。

## 経路の課題：拠点ごとに地域の掲載型だけ

| 検討する経路 | 確認する条件 |
|---|---|
| 求人媒体・スカウト | 対象職務・勤務地、現行機能と課金・外部利用条件 |
| 知人による紹介 | 本人の意思、共有する情報と紹介者の負担 |
| 学校等 | 求人受付の条件、担当業務・資格と教育体制 |
| 過去の候補者・短期就業者 | 再連絡の可否と利用目的、本人の希望と停止方法 |
| 派遣からの変更・紹介等 | 本人の意思と契約・手続き、関係先の確認 |

拠点ごとに経路の一覧を作り、応募の数を記録します。前年の短期の人への声かけは、本人の同意と会社の決まりの範囲で行い、個人情報の扱いは専門家の確認に従います。

## 枠の課題：運行の責任者が現場で手一杯

| 状態 | 確認する対策 |
|---|---|
| 面接候補日が少ない | 勤務・休息と現場体制、本人希望を踏まえて候補日・形式を検討 |
| 日程が決まらない | 社内判断待ち、候補者との調整、不在時を分けて記録 |
| 見学等と別日になる | 内容・資格安全面・所要時間と負担を確認し、同日を固定しない |
| 判断する人が曖昧 | 職務に合う評価・承認責任者と期限を決める |

枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 外に出せる部分と社内で直す部分

| 領域 | 外部に相談する実務 | 社内の確認・判断 |
|---|---|---|
| 記録 | 必要範囲での整理・集計 | 本人回答と推測の区別、共有項目・権限と保存 |
| 資格・条件 | 資料照合や原稿下書きの対応可否 | 資格・安全・配置、勤務条件と回答承認 |
| 経路 | 許可された媒体運用等 | 利用する経路・契約と予算 |
| 日程 | 対応時間・件数を合意した調整 | 候補日と承認、不在時の引き継ぎ |
| 受け入れ | 資料・日程等の補助を個別相談 | 必要な教育と現地・安全・配置の責任 |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[物流・運送業界で採用代行が機能する条件・機能しない条件](/media/rpo-butsuryu-jirei/)に書いています。

## まとめ

- 必要人数・採用離職・資格・説明・経路・日程を分けて確認する
- 原因を一つに固定せず、必要な対策を体制に合わせて並行する
- 本人の回答と不明・会社の推測を区別する
- 資格・安全・配置と、一次照合・連絡等の実務を分ける
- 候補日・返信・教育期間は一律の日数や時間帯で決めない
- 経路・条件・実績をそろえ、記録の権限と共有範囲を確認する

## よくある質問

### 業界全体で人が足りないので、自社だけでは直せないのではないですか

自社で見直せる実務・条件・体制と、地域や需要等の外部条件を分けて確認します。課題を一つ直せば採用できるとは限らず、必要人数・条件・募集経路・連絡選考・受け入れ等を並行して検討できます。提示条件の判断も固定順の最後に先送りしません。

### 倉庫の繁忙期の短期の人を、翌年も採りたいです

前年の短期の人への再度の声かけは、本人の同意（連絡を続けてよいという意向）と会社の個人情報の扱いの決まりの範囲で行います。同意の記録が無い人には送りません。今年の短期の人には、終了時に「来年も声をかけてよいか」を聞き、同意の記録を残す形にします。同意の取り方と記録の扱いは、専門家の確認に従います。個別の判断は専門家にご確認ください。プールの考え方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

### 免許の取得を支援する制度を作りたいのですが、何を決めればよいですか

支援の中身（費用の扱い、取得までの期間と担える業務、取れなかった場合の扱い、取得後の一定期間の扱い）は、法令上の整理があると一般に整理されているため、会社と専門家（社労士等）で決めます。決めた内容を、要件と求人票に区分（必須・取得の支援・歓迎）で書きます。採用の側は「区分と支援の中身が求人票にあるか」を確かめるまでで、制度の設計は専門家の領域です。個別の判断は専門家にご確認ください。
