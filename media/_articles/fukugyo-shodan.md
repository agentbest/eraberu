面談で条件が合い、書面を交わし、案件が決まった。次にあるのが、稼働を始める前の初回打ち合わせです。面談は「受けるかどうか」を決める場でしたが、初回打ち合わせは「どう回すか」を決める場で、目的が違います。ここを飛ばして稼働に入ると、情報が届かない、判断が返ってこない、何を最初にやればよいか分からない、で最初の週から止まります。結論を先に書くと、**初回打ち合わせでは、範囲の再確認・情報の受け渡し・判断の流れ・連絡と返信の枠・稼働の記録の形・最初の一週間の作業・区切りの日・依頼側の背景の八つを決め、決めた内容を打ち合わせのあとに書面で送る**と、開始後に止まりません。面談で聞いたことと重なる部分もありますが、契約後に改めて確認することで、依頼側の担当と自分の認識がそろいます。面談での確認は[面談で聞かれること](/media/fukugyo-mensetsu/)に、条件のすり合わせは[条件のすり合わせ](/media/fukugyo-jouken-suriawase/)にまとめています。

## 面談と初回打ち合わせの違い

二つの場は目的が違うので、聞くことも決めることも違います。

| 観点 | 面談 | 初回打ち合わせ |
|---|---|---|
| 時期 | 契約前 | 契約後、稼働前 |
| 目的 | 受けるかどうかを決める | どう回すかを決める |
| 相手 | 依頼側の判断する人（経営者、人事責任者） | 日々やり取りする担当。判断する人も同席が望ましい |
| 決めること | 範囲、時間、期間、単価、判断の線 | 情報の受け渡し、判断の流れ、連絡の枠、記録、最初の作業、区切り |
| 結果 | 書面（契約） | 運用のメモ（打ち合わせ後に送る） |
| 所要 | 三十分〜一時間 | 一時間ほど |

違いの要点は、「面談で決めたことを、担当と一緒に運用に落とす」場だということです。面談の相手が経営者で、日々の担当が別の人なら、担当は面談の内容を知らないことがあります。初回打ち合わせで、担当と一緒に確認し直します。

## 事前の準備

初回打ち合わせの前に、自分の側で用意するものを整理します。

| 準備 | 内容 |
|---|---|
| 面談で決めたことの一覧 | 範囲（含むこと・含まないこと）、時間、期間、単価、判断の線。書面から抜き出す |
| 八つの確認項目のメモ | 下の表。聞き漏らさないために |
| 自分の運用の型 | 連絡の枠、記録の表、判断待ちの一覧の形。依頼側に仕組みが無ければ、こちらから出す。[フルリモートで完結する案件](/media/fukugyo-remote/) |
| 情報の扱いの方針 | 依頼側の環境の中で作業する、端末に保存しない。[情報の取り扱いと端末の分離](/media/fukugyo-security/) |
| 最初の一週間にやることの案 | 依頼側の状況が分からなくても、「まず現状の把握と、型の確認から」と提案できる形 |
| 質問の順番 | 八つを、どの順で聞くか |

準備の要点は、「自分の運用の型を持って行く」ことです。依頼側、とくに人事が一人か、いない会社は、副業の人をどう動かせばよいか分かっていません。こちらが型を出せば、打ち合わせが短く済み、依頼側も安心します。

### エラベルの見解

登録の相談で多いのは、「契約したあと、最初の一週間、何をすればよいか分からずに過ぎた」という声です。依頼側から権限が届かない、担当が忙しくて連絡が取れない、何から手を付けるか決まっていない。初回打ち合わせを持たずに稼働に入ると、この状態になります。面談で「よろしくお願いします」と言い合った時点で、依頼側は動き始めたと思い、自分は指示を待つ。どちらも待っていて、一週間が消えます。

見ていて差がつくのは、「初回打ち合わせを、自分から設定しているか」です。「稼働の前に一時間、運用を決める打ち合わせをさせてください」と、契約の直後に自分から言う。依頼側は、副業の人がそこまで段取りするとは思っていないので、この一言で「回してくれる人」として見ます。エラベルの登録でも、初回打ち合わせを自分から設定し、八つを確認して、打ち合わせ後に書面で送る人は、最初の週から稼働が動き、依頼側の評価が最初から高い。

## 当日の進行と、八つの確認項目

初回打ち合わせの進行を、番号付きで整理します。一時間の目安で、前半に確認、後半に最初の作業と区切りを決めます。

1. **依頼側の背景を聞く（十分）。** いま採用がどういう状況か、何に困っているか、これまで何をしてきたか。面談で聞いていても、担当の口から改めて聞く。担当の困りごとが、面談の相手（経営者）の困りごとと違うことがある。
2. **範囲を再確認する（五分）。** 書面の「含むこと・含まないこと」を読み上げ、担当の認識と合っているかを確認する。担当が「これもお願いできる？」と言ったら、その場で受けず、書面の範囲を示し、必要なら区切りで相談する。
3. **情報の受け渡しを決める（十分）。** 媒体の管理画面、応募者管理の仕組み、共有フォルダの権限。自分専用のアカウントをいつまでに作ってもらうか。応募者情報は依頼側の環境の中で扱い、端末に保存しないことを伝える。[使うツールをそろえる](/media/fukugyo-tool/)
4. **判断の流れを決める（十分）。** 合否、条件、優先順位の判断は誰がするか。判断を仰ぐときは、どのツールで、どのくらいで返事が来るか。返事の目安を決める。
5. **連絡と返信の枠を決める（五分）。** 自分の稼働の曜日と時間帯。その枠で返信すること。枠の外は見ないこと。緊急の定義と、緊急時の連絡先（依頼側の担当が担う）。[連絡手段の分け方](/media/fukugyo-mail/)
6. **稼働の記録の形を決める（五分）。** 日付、時間、やったこと、次にやることを、依頼側の共有フォルダに置く。週次の確認の時間（短く、固定）。[稼働管理の方法](/media/fukugyo-kadou-kanri/)
7. **最初の一週間の作業を決める（十分）。** 現状の把握（いまの文面、いまの応募状況、いまの管理の表）と、型の確認から。最初から成果を出そうとしない。「一週目は現状を見て、二週目から型を当てる」と伝える。
8. **区切りの日を決める（五分）。** 一か月後か、契約の区切り。そこで、範囲・時間・単価・続けるかを見直す。[契約更新のタイミング](/media/fukugyo-koushin/)

進行の要点は、「一で、担当の困りごとを聞き直す」ことです。面談の相手が経営者なら、経営者の困りごと（採用が決まらない）と、担当の困りごと（手が回らない）は違います。担当の困りごとに合わせて最初の作業を決めると、担当が動きやすくなります。

## 打ち合わせのあとにやること

打ち合わせで決めたことは、その日のうちに書面で送ります。

| やること | 内容 |
|---|---|
| 運用のメモを送る | 八つの項目について決めたことを、一枚に。依頼側の担当と、判断する人の両方に |
| 決まらなかったことを明記する | 「権限の発行日は未定。〇日までにご連絡ください」のように、宙に浮かせない |
| 最初の一週間の作業を書く | 何を、いつまでに、何を渡すか |
| 記録の表を置く | 依頼側の共有フォルダに、空の表を置く。権限が届いていなければ、届いたら置くと伝える |
| 稼働の初日を確認する | 「〇曜の夜から始めます」 |

あとの要点は、「決まらなかったことを、決まらなかったと書く」ことです。曖昧なまま始めると、決まらなかったことが自分の負担になります。書面に「未定」と書けば、依頼側も決める必要に気づきます。

## 決めきれなかったときの扱い

一時間で八つ全部が決まらないことはあります。決まらなかった項目ごとの扱いを整理します。

| 決まらなかった項目 | 扱い |
|---|---|
| 権限の発行日 | 発行までは、権限が要らない作業（型の確認、文面の下書き）から始める。発行日を書面で確認 |
| 判断の返事の目安 | 「まず一週間、返事の実態を見て、二週目に目安を決める」と提案。実態を記録 |
| 緊急の定義 | 「緊急は依頼側が担う。副業の人には緊急対応を求めない」を仮の形に |
| 週次の確認の時間 | 書面での確認から始める。口頭は月に一度 |
| 最初の作業 | 「現状の把握」を最初の作業にする。何を把握したかを一週目の終わりに渡す |
| 区切りの日 | 契約の期間の区切りを使う。無ければ一か月後 |
| 担当が同席できなかった | 経営者と決めた内容を、担当に書面で送り、短い確認の時間を別に取る |

扱いの要点は、「決まらない項目があっても、仮の形で始める」ことです。全部が決まるまで始めないと、時間が消えます。仮の形を書面に書き、一週目の実態を見て決め直します。

## ありがちな失敗

初回打ち合わせで起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 打ち合わせを持たずに始める | 面談で終わった気になる | 契約の直後に自分から設定する |
| 担当が同席していない | 経営者とだけ話す | 担当の同席を依頼する。無理なら書面と別の確認 |
| 範囲の再確認で「これも」を受ける | 断りにくい | 書面を示す。区切りで相談 |
| 最初から成果を出そうとする | 期待に応えたい | 一週目は現状の把握。型を当てるのは二週目から |
| 判断の目安を決めない | 依頼側が答えられない | 仮の目安で始め、実態を見て決める |
| 記録の形を出さない | 依頼側に仕組みがある前提 | こちらから表を出す |
| 打ち合わせ後に書面を送らない | 口頭で決まった気になる | その日のうちに送る。未定も書く |
| 一時間を超えて長く話す | 背景の話が長い | 進行の時間を決めて、残りは書面で |
| 情報の扱いを伝えない | 聞かれない | こちらから伝える。依頼側の安心になる |
| 区切りの日を決めない | 続く前提で話す | 一か月後か契約の区切りを決める |

失敗の要点は、「打ち合わせを持たない」ことが最大の失敗であり、持てば残りの失敗は防げるという点です。

### エラベルの見解

担当する側として登録した人の話を聞くと、最初の一か月が順調だった人は、初回打ち合わせで「最初の一週間は現状の把握」と決めています。依頼側の文面、応募の状況、管理の表を見て、何がどうなっているかを一枚にまとめて渡す。それだけで、依頼側は「状況を整理してくれた」と受け取り、二週目から型を当てる作業が受け入れられやすくなります。最初から成果を出そうとした人は、依頼側の状況を知らないまま型を当てて、合わずにやり直しています。

依頼側から見ると、初回打ち合わせを自分から設定し、八つを確認し、書面で送ってくる副業の人は、社内の人より段取りが良い人に見えます。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口ですが、案件が決まったあとの初回打ち合わせは、担当者ご自身に設定していただいています。ここで運用が決まるかどうかが、その案件が続くかどうかを分けるので、型を持って臨んでいただくことをお勧めしています。

## まとめ

- 初回打ち合わせは**面談（受けるかどうか）とは別の、どう回すかを決める場**。契約後、稼働前に自分から設定する
- 準備は**面談で決めたことの一覧・八つの確認項目・自分の運用の型・情報の扱いの方針・最初の一週間の案**
- 八つは**背景・範囲の再確認・情報の受け渡し・判断の流れ・連絡と返信の枠・記録の形・最初の一週間・区切りの日**
- 打ち合わせ後に**その日のうちに書面で送る**。決まらなかったことは**未定と書く**
- 決まらない項目は**仮の形で始め、一週目の実態を見て決め直す**
- **最初の一週間は現状の把握**。最初から成果を出そうとしない

## よくある質問

### 依頼側が「打ち合わせは要らない、すぐ始めてほしい」と言います

「すぐ始めるために、一時間だけ運用を決めさせてください」と伝えます。権限の発行、判断の流れ、連絡の枠が決まっていないと、始めても止まるので、結果的に遅くなります。それでも時間が取れないなら、八つの項目を書面にして送り、「この形で始めます。違う点があれば教えてください」と、書面で合意する形にします。打ち合わせが無くても、書面で運用を決めれば、止まらずに始められます。

### 面談の相手が経営者で、日々の担当が誰か分かりません

初回打ち合わせを設定するときに、「日々のやり取りは、どなたとさせていただけますか」と聞き、その人の同席を依頼します。人事が一人の会社なら、その一人が担当です。人事がいない会社なら、経営者本人か、兼務の誰かになります。担当が決まっていない会社は、判断の流れも決まっていないことが多いので、初回打ち合わせで「担当は〇〇さん、判断は経営者」と決めてもらいます。決まらなければ、経営者が担当と判断の両方を担う前提で始め、書面に書きます。

### 初回打ち合わせで、面談で聞いた話と違うことを言われました

担当と経営者で、困りごとや範囲の認識が違うことはよくあります。その場で決め直さず、「書面ではこうなっています。担当の方のご要望はこうですね」と、両方を書き出して、判断する人（経営者）に確認する形にします。範囲が広がる方向なら、書面の範囲で始めて、区切りで相談する。範囲が狭まる方向なら、狭い範囲で始めて問題ありません。認識の違いは、初回打ち合わせで見つかるのが一番よく、稼働に入ってから見つかると直しにくくなります。
