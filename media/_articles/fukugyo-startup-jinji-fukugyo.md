スタートアップの最初の人事として、社員が数人から数十人になる時期に、創業者の隣で、採用も労務も制度も、何もない状態から一人で立ち上げてきた。この経験は、副業で売れるのか。スタートアップの人事の経験は、規模が小さく、何でも屋に見え、創業者の色が強すぎて、他の会社には通じないと感じる人が多いところです。結論を先に書くと、**スタートアップの人事の経験は、「最初の人事として、創業者の隣で、何もない状態から、採用も労務も制度も一人で立ち上げてきた」型で売れます。売れるのは、「最初の人事担当者が最初にやることの順番」「創業者との付き合い方と役割の分け方」「少ない人数で回す採用の最小の形」「人事の機能を一人で持つときの切り分け」の四つです。人事がいない会社は、業種と規模を問わず多く、そこでは経営者が人事の判断を一人で抱え、最初の人事担当者を置くべきか、置くなら何から頼むべきかが分かっていません。「スタートアップの人事でした」ではなく、「人事がいない会社に、最初の人事の型を持ち込む」と売ります。**拡大期の経験は[ベンチャーの人事が副業でできること](/media/fukugyo-venture-jinji-fukugyo/)に、その経験の評価のされ方は[スタートアップ人事の経験は評価されるか](/media/fukugyo-startup-keiken/)に、中小企業の経験は[中小企業の人事が副業でできること](/media/fukugyo-chusho-jinji-fukugyo/)にまとめています。

## この経歴の何が売れるか

スタートアップの人事の経験を、人事がいない会社の工程に置き換えた棚卸しです。在籍した会社の内情は含めず、「型」として抜き出します。

| スタートアップの人事の経験 | 人事がいない会社の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 何もない状態で、最初に何をやるかを決めてきた | 人事がいない会社で、最初に作る一つ（雇用の書面か、採用の要件か、勤怠か）を決める順番 | 何から手を付ければよいか分からない依頼側が多い |
| 創業者と直接やり取りし、判断の速さと揺れの両方に付き合ってきた | 経営者の判断の速さを活かし、揺れを止める付き合い方。「決めてもらうこと」と「自分で決めること」の分け方 | 経営者の一言で方針が揺れる依頼側が多い |
| 数人の採用を、媒体もなく予算もなく、知人と紹介と自分で探すことで回してきた | 予算が少ない会社の、最小の採用の形（経路、要件、面接、書面） | 採用に予算をかけられず、何もできていない依頼側が多い |
| 採用と労務と制度と総務を、一人で同時に持ってきた | 人事の機能を一人で持つとき、何を自分で、何を外に、何を後回しにするかの切り分け | 最初の人事担当者に何を頼めばよいか分からない依頼側が多い |
| 最初の雇用契約、最初の就業規則、最初の給与の仕組みを作ってきた | 会社として最低限そろえる書面と手続きの一覧と、その順番 | 書面がそろっておらず、後で問題になる依頼側が多い |
| 創業者の想いを、採用の言葉に置き換えてきた | 経営者の頭の中の「こういう人が欲しい」を、要件と求人票と面接の基準に落とす | 経営者の「いい人」が言葉になっていない依頼側が多い |
| 最初の社員が辞める場面を経験してきた | 少ない人数の会社で人が辞めるときの影響と、辞める前に打つ手 | 一人辞めると会社が揺れる依頼側が多い |

売れるものの要点は、「人事がいない会社で、最初の人事が最初にやることを知っている」ことです。人事がいない会社の経営者は、人事の機能を自分で抱え、何から手を付ければよいかが分からず、最初の人事担当者を置いても何を頼めばよいか分かりません。スタートアップの最初の人事は、その状態を自分で経験し、順番を持っています。この型は、業種と規模を問わず、人事がいない会社にそのまま合います。創業者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に書いています。

## 売りにくい点とその扱い

スタートアップの人事の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 規模が小さすぎると見られる | 「数十人の会社の人事では、うちの規模には足りない」。自分でも、大きい会社の人事を知らない不安 | 「人事がいない会社」に絞る。規模ではなく「人事がいるかいないか」で依頼側を選ぶ。人事がいる会社の案件は、最初は避ける |
| 何でも屋に見える | 「採用も労務も総務もやっていた人は、どれも浅いのでは」 | 何でもやった中で「最初に何を作ったか」と「何を外に出したか」の切り分けを語る。浅く広くではなく、「順番と切り分けを知っている」と売る |
| 創業者の色が強い | 「前の会社の創業者のやり方が染みついていて、うちには合わないのでは」 | 創業者の色は捨て、「創業者と付き合う型」だけを持ち込む。「速い判断を活かし、揺れを止める」付き合い方は、どの経営者にも通じる |

扱い方の要点は、「規模ではなく『人事がいない』で依頼側を選び、何でも屋を『順番と切り分け』に言い換える」ことです。スタートアップの人事の経験がある人は、自分の経験を「小さい会社で何でもやった」と語りがちで、それが依頼側には「浅い」に聞こえます。「人事がいない状態から、最初に雇用の書面を、次に採用の要件を、次に勤怠を作り、労務の手続きは社労士に出した」と、順番と切り分けで語れば、同じ経験が「人事がいない会社に最初の型を持ち込める人」として伝わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、スタートアップの人事から転身して続いている人と、面談で止まる人の差は、依頼側の規模を見るか、「人事がいるかどうか」を見るかです。止まる人は、依頼側の規模が前の会社より大きいと、自分の経験が足りないと感じて引き、小さいと「同じような会社」として前の会社のやり方をそのまま持ち込みます。続いている人は、規模を見ずに「御社に人事の担当者はいますか」と聞き、いないと分かったところで、「それなら、最初に作るものは決まっています。雇用の書面と、採用の要件と、勤怠の三つで、この順番です」と返します。経営者は、自分が人事の判断を一人で抱えていることと、最初にやることが決まっていることに気づき、そこから頼みます。

見ていて差がつくのは、経営者の判断の速さを止めずに、揺れだけを止めているかです。スタートアップの人事の経験がある人は、創業者の速い判断と揺れる方針の両方に付き合ってきており、「揺れを止めるために判断を遅くする」のではなく、「決めてもらうことと自分で決めることを分けて、揺れる余地を減らす」型を持っています。「採用の条件は経営者が決める、要件の書き方と面接の流れは私が決める、と最初に分けましょう」と提案した人は、経営者の一言で方針が揺れることが減り、依頼側から「初めて採用が止まらなくなった」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「人事がいない会社に、最初の人事の型を持ち込む」と状態の言葉で書いている担当者に、人事がいない依頼側がついています。スタートアップの人事の転身は、規模を気にすることではなく、「人事がいない」状態に順番を持ち込むところから始まります。

## 案件の探し方

スタートアップの人事から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 人事がいない会社の、最初の人事の立ち上げ | 最初の人事としての経験でそのまま入れる | 「人事の担当者がいない依頼側」を探す |
| 経営者が抱えている人事の判断の切り分け | 創業者と役割を分けてきた経験で入れる | 「経営者が一人で人事を抱えている依頼側」を探す |
| 予算が少ない会社の最小の採用の形 | 媒体も予算もない中で採ってきた経験で入れる | 「採用に予算をかけられない依頼側」を探す |
| 最低限そろえる書面と手続きの一覧づくり | 最初の契約と規則を作ってきた経験で入れる。判断は専門家に | 「書面がそろっていない依頼側」を探す |
| 経営者の「いい人」を要件に落とす | 創業者の想いを言葉にしてきた経験で入れる | 「経営者の『いい人』が言葉になっていない依頼側」を探す |
| 初めて人事担当者を採る会社の、役割の設計 | 一人で持つ切り分けの経験で入れる | 「初めて人事を採る依頼側」を探す |

探し方の要点は、「人事がいない会社」から入り、規模と業種は問わないことです。人事の部門があり、担当者がいる会社では、スタートアップの型は既存の人事と重なります。人事がいない会社は、業種と規模を問わず多く、そこでは経営者が判断を一人で抱えており、最初の人事の順番を知っている人が求められています。案件の相談で「人事は私（経営者）がやっている」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。スタートアップの人事の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 最初の立ち上げの成果物 | 最初に作る書面と要件と勤怠の一覧と順番は、成果物として形が明確 | 一式の成果物で受ける |
| 経営者の壁打ち | 判断の切り分けと壁打ちは、回数で受けやすい | 月に何回・何分で決める |
| 依頼側の予算の少なさ | 人事がいない会社は予算が少ないことが多く、単価が下がりやすい | 範囲を最初の一つに絞り、小さく始めて広げる |
| 一人で持つ切り分けの価値 | 「何を外に出すか」の判断は、依頼側の支出に直接効く | 「社労士に出す範囲が決まった」を成果物に |
| 何でも屋と見られること | 単価が下がる | 順番と切り分けの言葉で示す |
| 法令に関わる部分を含まないこと | 書面と手続きの判断を含まない範囲は責任が明確 | 「判断が要る点を見つけて専門家につなぐ」を範囲に明記する |
| 成果報酬の扱い | 採用の成否は経営者の判断に左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「最初の一つを成果物で小さく受け、壁打ちを回数で受け、法令の判断を含まない」ことです。スタートアップの人事の経験で受ける依頼側は、予算が少ないことが多く、最初から広い範囲で受けると単価が合いません。「最初に作る一つ」を成果物で小さく受け、経営者の壁打ちを回数で受け、成果が見えたところで次の一つを提案する形にします。書面と手続きは、判断せずに専門家につなぐ役割として範囲に明記し、責任の線を引きます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果の定義は[成果をどう定義しておくか](/media/fukugyo-seika-teigi/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

スタートアップの人事から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、事業と社員と創業者の情報の守秘の条件を確認する | 個別の判断は専門家に |
| 二、「何もない状態で、最初に何を作り、次に何を作り、何を外に出したか」を、会社の情報を含まない型として書き出す | 順番と切り分け |
| 三、創業者の色と、創業者と付き合う型を分ける | 色は捨て、型だけを持ち込む |
| 四、「何でもやった」を「順番と切り分けを知っている」に言い換える | 浅く広くではなく、最初の人事の型で語る |
| 五、法令に関わる書面と手続きの判断を副業でしないと決め、「ここは専門家に」の線を自分の言葉で書く | 責任の線 |
| 六、範囲を、最初の立ち上げの順番、経営者の壁打ち、最小の採用の形、書面と手続きの一覧、人事担当者の役割の設計に絞る | 法令の判断は範囲外 |
| 七、「人事がいない会社に、最初の人事の型を持ち込む」の一言を作る | 「スタートアップの人事でした」で終わらせない |
| 八、登録先に、範囲と、人事がいない依頼側に向いていることと、規模と業種を問わないことを登録する | 人事がいない依頼側 |
| 九、最初の一つの立ち上げを一件受け、「経営者が抱えていた判断が一つ減った」形を残す | 次の一つに広げる材料に |

順番の要点は、「三」の分け方と「四」の言い換えです。スタートアップの人事の経験は、創業者の色に染まっていて、そのまま語ると「あの会社のやり方」に聞こえます。創業者の色は捨て、「速い判断を活かし、揺れを止める」付き合い方の型だけを持ち込みます。「何でもやった」は「浅い」に聞こえるので、「最初に何を作り、何を外に出したか」の順番と切り分けで語ります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「スタートアップの人事の経験は小さすぎて、ちゃんとした会社では通じない」というものです。実際には、人事がいない会社は業種と規模を問わず多く、そこでは経営者が人事の判断を一人で抱え、何から手を付ければよいか分からず、最初の人事担当者に何を頼めばよいかも分かっていません。最初に作る一つの順番、経営者との役割の分け方、予算が少ない中の最小の採用、一人で持つときの切り分け。スタートアップの最初の人事が自分で経験してきたこの型は、その会社にとって、持っていない打ち手です。小さすぎるのではなく、「人事がいない」状態を知っている人が少ないだけです。

順番として、本業の規定と守秘の条件を専門家に確認し、作った順番と切り分けを会社の情報を含まずに書き出し、創業者の色と型を分け、何でも屋を順番と切り分けに言い換え、法令の判断をしない線を書き、範囲を立ち上げの順番と壁打ちと最小の採用と一覧と役割の設計に絞り、最初の人事の型を持ち込む一言を作り、登録先に範囲と向いている依頼側を登録し、一件受けて経営者の判断が一つ減った形を残す。この順番で、スタートアップの人事の経験は「小さすぎるもの」から「人事がいない会社の最初の打ち手」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、最初の立ち上げの工程を明確にし、法令の判断を含まないことを示している担当者に、人事がいない依頼側がついています。スタートアップの人事の転身は、規模を気にすることではなく、「人事がいない」状態に順番を持ち込むところから始まります。

- スタートアップの人事の経験は**「最初の人事として、創業者の隣で、何もない状態から、採用も労務も制度も一人で立ち上げてきた」型**で売れる。**最初にやる順番・創業者との役割分担・最小の採用の形・一人で持つ切り分け**の四つ

- 案件は**人事がいない会社**から。規模と業種は問わない。「人事は私がやっている」が入り口
- 単価は**最初の一つを成果物で小さく、壁打ちを回数**で。法令の判断を含まない。成果報酬は最初は避け、可否は専門家に確認
- 経営者の判断の**速さは活かし、揺れだけを止める**。決めてもらうことと自分で決めることを分ける

## よくある質問

### 前の会社では、就業規則や雇用契約も自分で作っていました。副業でも作ってよいですか

書面の「一覧と順番」を作ることと、書面の「中身を判断する」ことを分けます。何をそろえるべきか、どの順番で作るかは、副業の担当者が示せます。中身の判断（条文、労働条件、法令との整合）は、副業の担当者が責任を負えないので、社会保険労務士や弁護士に確認する形にし、その線を範囲に明記します。前の会社で作った書面は、会社のものなので持ち込まず、型だけを使います。個別の判断は、専門家にご確認ください。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、労務の経験の売り方は[労務担当が副業でできること](/media/fukugyo-roumu-tantou-fukugyo/)に整理しています。

### 依頼側の経営者が、前の会社の創業者と全く違うタイプで、付き合い方が分かりません

創業者の色ではなく、付き合う型で対応します。どの経営者にも共通するのは、「判断が速い代わりに揺れる」か「判断が遅い代わりに揺れない」かのどちらかに寄ることで、前者には「決めてもらうことと自分で決めることを分ける」、後者には「決める材料と期限を先に出す」型が効きます。前の創業者のやり方を基準にせず、目の前の経営者がどちらに寄っているかを最初の面談で見て、型を選びます。経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、聞き取りの磨き方は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)に書いています。

### 人事がいる会社の案件は、受けないほうがよいですか

最初は避けるほうが、経験が活きます。人事がいる会社では、スタートアップの型は既存の人事と重なり、「浅い」と見られやすいです。人事がいない会社で、最初の立ち上げの成果を積んでから、人事が一人しかいない会社の「二人目の役割の設計」や、人事がいる会社の「新しい拠点の立ち上げ」に広げると、同じ型が通じます。合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に、利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。
