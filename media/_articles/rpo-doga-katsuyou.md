採用に動画を使う会社が増えている。「うちも作るべきか」と迷う。制作会社に頼めば費用がかかり、社内で作れば質が不安。作っても、候補者が見るのか、応募につながるのか、分からない。経営者は「動画があれば応募が増えるのでは」と言う。結論を先に書くと、**動画は、「作るべきか」で考えるものではなく、「文章と写真で伝わらないものがあるか」で決めるものです。あれば、動画で伝えます。無ければ、作る意味は薄いです。伝わらないものは、「人の話し方と空気」「場所の動きと音」「手順の流れ」の三つに絞られます。あるなら、短く、社内で、実態のまま作ります。プロに頼むのは、限られた場面です**。素材の作り方は[使える写真・素材がない](/media/rpo-shashin-nai/)に、スカウトに動画を添える是非は[動画や資料を添えるべきか](/media/scout-doga-tenpu/)にまとめています。

## 動画を使うかの判断で起きていること

動画を採用に使うかどうかで、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 「他社が作っているから」で作ろうとする | 目的が無い。作ること自体が目的になる |
| 「動画があれば応募が増える」と思っている | 動画は、応募を集めるものではなく、調べた候補者に実態を見せるもの |
| 制作会社に頼む前提で、費用で止まる | 社内で作れるものと、プロに頼むものを分けていない |
| 社内で作ると「質が低い」と思っている | 候補者が見たいのは、きれいさではなく実態。社内の普段の動画のほうが伝わることがある |
| 何を撮ればよいか分からない | 「会社紹介動画」の一本を目指し、中身が決まらない |
| 長い動画を作ろうとしている | 数分の「会社紹介」。候補者は見切らない |
| 作って終わり | 置き場と使い方が無く、採用サイトの隅に置いて見られない |
| 効果が分からない | 見られたかどうか、応募に関係したかを、測っていない |

構造の大半は、「作るべきか」から入っていることです。「伝わらないものがあるか」から入ります。

## 動画でしか伝わらないもの

文章と写真で伝わらず、動画で伝わるものは、三つに絞られます。

| 伝わらないもの | 中身 | 候補者が知りたいこと |
|---|---|---|
| 一、人の話し方と空気 | 社員や経営者が、どういう話し方で、どういう表情で、どういう空気で話すか | 「この人と一緒に働けるか」「この経営者についていけるか」 |
| 二、場所の動きと音 | オフィスや現場が、実際にどう動いているか。音、人の動き、時間の流れ | 「この場所で働く自分を想像できるか」 |
| 三、手順の流れ | 仕事の一連の流れ。手を動かす様子、道具の使い方、作業の進み方 | 「この仕事を、自分がやっているところを想像できるか」 |

三つ以外（会社の説明、制度の説明、役割の記述、選考の流れ）は、文章と写真で足ります。動画にする意味は薄く、候補者も文章のほうが早く読めます。

三つのうち、自社の採用で「伝わっていない」ものがあるかを確認します。「面接で、社員の雰囲気を聞かれる」なら一が伝わっていない。「現場の様子が分からないと言われる」なら二。「仕事の中身が想像できないと辞退される」なら三。

伝わっていないものが無ければ、動画は要りません。あれば、それだけを動画にします。

## 使う判断と使わない判断

動画を使う判断と、使わない判断の材料です。

| 使う判断 | 使わない判断 |
|---|---|
| 三つのどれかが、伝わっていない | 三つとも、文章と写真で足りている |
| 面接で「雰囲気は」「現場は」「仕事の中身は」と繰り返し聞かれる | 面接でその質問が出ない |
| 「思っていたのと違う」で辞退される。動画で実態を見せれば減りそう | 辞退の理由が、条件や速さで、実態のずれではない |
| 社内で、短い動画を撮れる人と場面がある | 撮れる人も場面も無く、プロに頼む費用も出せない |
| 続けて撮れる体制がある（一本で終わりにしない） | 一本作って終わりになりそう |
| 置き場と使い方が決まっている | 置く場所も使う場面も無い |
| 社員の同意が取れる | 社員が映ることを全員が拒む |
| 実態を隠さず見せられる | 良く見せる演出が要る（演出は逆効果） |

使わない判断も、正しい判断です。「他社が作っているから」で、伝わっていないものが無いのに作っても、費用と時間を消費して終わります。

使う判断をしたら、「何を伝えるか」を一つに絞ります。「会社紹介動画」のような全部入りは、作りません。

## 社内で作る型

社内で、短い動画を作る型です。スマートフォンで足ります。

| 型 | 中身 | 長さ | 撮り方 |
|---|---|---|---|
| 社員の一言 | 社員が、「入社して最初の三か月で何をしたか」「一番大変だったこと」を一つ話す | 短く。一分以内 | 自然光の場所で、正面から。台本は無し。一度話してもらい、撮り直しは一回まで |
| 経営者の一言 | 経営者が、「なぜこの役割が要るか」「候補者に伝えたいこと」を一つ話す | 短く。一分以内 | 同上。経営者の顔と話し方が見えれば足りる |
| オフィスや現場を歩く | 入口から、席まで、または現場の一角を、歩きながら撮る | 短く。三十秒から一分 | 普段の時間帯に。片付けすぎない。人が働いている様子が入る（同意のうえで） |
| 手順の流れ | 仕事の一つの手順を、手元を中心に撮る | 短く。一〜二分 | 手元と道具。説明は一言。顧客や取引先の情報が映らないように |
| 一日の断片 | 朝、昼、夕方の場面を、数秒ずつつなぐ | 短く。一分以内 | 一日の流れが分かる断片。編集は最小限（つなぐだけ） |
| 面接官の自己紹介 | 面接の前に候補者に送る、面接官の顔と一言 | 短く。三十秒 | 「面接でお会いする〇〇です。こういう話をします」。候補者の緊張が下がる |

社内で作る要点は、「短く、台本無しで、実態のまま」です。演出、台本、きれいな照明は、要りません。候補者が見たいのは、「本当の話し方と空気」で、演出はそれを消します。

編集は、最小限で足ります。つなぐ、不要な部分を切る、文字を一言入れる。凝った編集は、手間がかかり、続きません。

映る社員の同意は、書面で、用途を限定し、取り下げに応じます。同意の扱いは[使える写真・素材がない](/media/rpo-shashin-nai/)と同じです。

### エラベルの見解

相談で最も多い失敗は、「制作会社に頼んで、数分の会社紹介動画を作り、採用サイトのトップに置いたが、面接で『見ました』と言う候補者がおらず、応募も変わらなかった」というものです。「伝わっていないもの」を確認せず、全部入りの動画を作りました。面接で聞かれていたのは「一緒に働く人の雰囲気」でした。社員三人の一分の一言を、スマートフォンで撮って求人票に添えたら、面接で「〇〇さんの動画を見て」と言われるようになりました。数分の会社紹介より、一分の社員の一言でした。

見ていて差がつくのは、担当者が「伝わっていないものがあるか」から入るかどうかです。「採用動画を作りましょう」と制作会社を紹介する担当者と、「面接で何を聞かれ、辞退の理由は何かを見て、文章と写真で伝わっていないものがあるかを確認しましょう。あれば、それだけを短く社内で撮ります」と、必要性から入る担当者がいます。後者は、要らない動画を作りません。

発注側にできるのは、「動画を作りたい」の前に、「面接で何を聞かれているか」を担当者に渡すことです。

## プロに頼む範囲

社内で作れないもの、プロに頼む価値があるものです。

**プロに頼む価値がある場面。** 採用サイトのトップに置く一本（会社の顔になるもの）、複数の拠点や現場を一つにまとめる場合、音や照明が難しい現場（工場、屋外など）、経営者の言葉を一本にまとめる場合。

**プロに頼まなくてよい場面。** 社員の一言、オフィスを歩く、手順の流れ、面接官の自己紹介。社内の普段の動画のほうが伝わります。

**頼むときに伝えること。** 「候補者に実態を見せたい。演出は最小限に。台本は無し。普段の様子を撮ってほしい」。伝えないと、プロは「きれいに」作ります。

**撮る一覧と、伝えたいことを一つに絞って渡す。** 「全部入り」を頼まない。「社員の話し方と空気」なら、それだけ。

**長さを、短く指定する。** 「一〜二分以内」。プロは長く作りがちです。

**権利の扱いを、契約で確認する。** 動画をどの用途に、いつまで使えるか。二次利用の可否。映る社員の同意の扱い。契約の条項は専門家に確認します。

**費用は、範囲を絞れば抑えられる。** 半日で、一本だけ、のように絞ります。

プロに頼む要点は、「社内で撮れないものだけ」と「演出しないと伝える」ことです。

## 置き場と使い方

作った動画を、候補者が見る場所と場面に置きます。

| 置き場・使い方 | 中身 |
|---|---|
| 求人票に添える | 「この役割の社員の一言」を、求人票のリンクで。媒体が動画に対応していれば埋め込み。仕様は各媒体の公式の案内で |
| スカウトの返信後に送る | 一段落目の代わりではなく、返信が来た後の補足として。[動画や資料を添えるべきか](/media/scout-doga-tenpu/) |
| 面接の案内に添える | 「面接官の自己紹介」「オフィスを歩く」を、面接の前に。候補者の緊張が下がり、面接の質が上がる |
| 採用サイトの役割のページに | その役割の「一日の断片」「手順の流れ」を、役割の説明の横に |
| 採用サイトの社員の紹介に | 社員の文章の話に、「一言」の動画を添える |
| 内定者への連絡に | 内定から入社までの接点として、「一緒に働く人の一言」「オフィスの様子」 |
| SNSに | 短い動画を、SNSの投稿として。[採用SNSで何を発信すればよいか](/media/rpo-sns-nani/) |
| カジュアル面談の前に | 面談の前に「会社の空気」を見てもらう |

使い方の要点は、「候補者の流れの中の、見る意味がある場面に置く」ことです。採用サイトのトップに一本置いて終わりでは、見られません。求人票、スカウトの返信後、面接の前、内定後。それぞれの場面で、その場面に合う動画を使います。

動画は、一本の大作より、場面ごとの短い動画を複数持つほうが、使えます。

## 効果の見方

動画の効果を、「再生の数」で見ないことが要点です。

**面接で「見た」と言われたか。** 面接の最初に「動画をご覧になりましたか」と聞き、記録。「〇〇さんの動画を見て」と言われれば、効いています。

**面接で、雰囲気や現場や仕事の中身を聞かれなくなったか。** 動画で答えていれば、質問が減ります。

**辞退の理由の変化。** 「思っていたのと違う」が減ったか。

**面接の質の変化。** 面接官の自己紹介の動画を送った後、候補者の緊張が下がり、面接で話が深まったか。面接官の実感で。

**求人票やスカウトの返信への影響。** 動画を添えた求人票と添えない求人票、動画を送った候補者と送らない候補者で、進み方に差があるか。自社の記録で。

**再生の数は、参考にとどめる。** 多ければ良いとは限らず、少なくても面接に来た人が見ていれば、効いています。

**続けて作れているか。** 一本で終わっていないか。場面ごとの短い動画が増えているか。

効果の要点は、「面接で聞く」ことです。再生の数で判断すると、効いているのに止めます。

## 外注する場合の範囲

動画を採用に使うかの問題を、採用代行に出す場合の範囲です。

**出せる工程。** 「伝わっていないものがあるか」の確認（面接の質問と辞退の理由の記録から）、使う判断と使わない判断の材料、伝えるものを一つに絞る整理、社内で作る型の設計と撮り方の案内、撮影の進行（社員への依頼、日程、同席）、最小限の編集、同意の書式の案（専門家の確認を経て）、プロに頼む場合の範囲の整理と依頼の一覧、権利の扱いの整理（専門家への橋渡し）、置き場と使い方の設計（求人票、スカウト、面接の案内、採用サイト、内定者、SNS）、面接での「見たか」の記録、三か月ごとの振り返り。

**社内に残す判断。** 動画を使うかどうかの決定、映る社員の同意の取得、経営者が話す内容、公開の範囲（顧客や取引先の情報）、プロへの依頼と費用、権利の契約。

**外注の効きどころ。** 動画は、「作るべきか」で迷い、「作ったが使われない」で終わりやすい素材です。担当者が必要性から確認し、伝えるものを一つに絞り、社内で短く撮る型を持ち込み、置き場と使い方を設計すれば、要らない動画を作らず、要る動画は使われます。担当者は複数の会社の採用の動画を見ているので、「この場面には、この短い動画」の型を持ち込めます。

**外注しても動かない場合。** 経営者が「立派な会社紹介動画」を譲らない、社員が映ることを全員が拒む、置き場と使い方を決めない。社内の判断で、代行を替えても直りません。

動画は、伝わらないものがあるときに、短く、実態のまま作れば、効きます。外注は、必要性の確認と、型と、使い方を持ち込む手段です。

### エラベルの見解

担当する側から見ると、動画の相談で最も多いのは、「一本の大作を作って、終わり」ということです。数分の会社紹介動画を、費用をかけて作り、採用サイトのトップに置く。一年後、社員も制度も変わっているのに、動画はそのまま。候補者は「古い」と気づきます。

動画は、大作を一本ではなく、場面ごとの短い動画を、社内で、続けて作るものです。社員の一言は、社員が変われば撮り直す。オフィスを歩くのは、移転したら撮り直す。「一分の動画を、年に数本」が、「数分の大作を、一本」より、はるかに使えます。

発注側にできるのは、「一本の大作」ではなく「場面ごとの短い動画を続けて」を方針にすることです。

## まとめ

- 起きているのは**他社がやっているから・応募が増えると思う・制作会社の前提で費用で止まる・社内は質が低いと思う・何を撮るか分からない・長い・作って終わり・効果が分からない**
- 動画でしか伝わらないのは**人の話し方と空気・場所の動きと音・手順の流れ**の三つ。それ以外は文章と写真で足りる
- 使うのは**三つのどれかが伝わっていない・面接で繰り返し聞かれる・実態のずれで辞退される・社内で撮れる・続けられる・置き場がある・同意が取れる・隠さず見せられる**とき。使わない判断も正しい
- 社内で作るのは**社員の一言・経営者の一言・オフィスを歩く・手順の流れ・一日の断片・面接官の自己紹介**。短く、台本無し、実態のまま、編集は最小限、同意は書面で
- プロに頼むのは**サイトのトップの一本・複数拠点のまとめ・難しい現場・経営者の一本**。演出しないと伝え、一つに絞り、短く、権利を契約で
- 置き場は**求人票・スカウトの返信後・面接の案内・採用サイトの役割と社員・内定者・SNS・面談の前**。場面ごとの短い動画を複数
- 効果は**面接で「見た」か・質問の変化・辞退の理由の変化・面接の質・求人票やスカウトへの影響・続けて作れているか**。再生の数は参考
- 外注できるのは**必要性の確認・判断の材料・絞り込み・型と撮り方・撮影の進行・編集・同意の書式・プロへの依頼の整理・権利の橋渡し・置き場と使い方・記録・振り返り**。社内に残るのは**使うかどうか・同意・経営者の内容・公開の範囲・費用・契約**

## よくある質問

### 採用動画を作れば、応募は増えますか

動画は、応募を集めるものではなく、調べた候補者に「文章と写真で伝わらないもの」（人の話し方と空気、場所の動きと音、手順の流れ）を見せるものです。伝わっていないものが無ければ、作っても応募は変わりません。面接で「雰囲気は」「現場は」「仕事の中身は」と繰り返し聞かれている、「思っていたのと違う」で辞退されている、なら、それを短い動画で見せれば、質問と辞退が減り、面接の質が上がります。「作れば増える」ではなく、「伝わっていないものを見せる」です。

### 社内で撮った動画では、質が低くて逆効果になりませんか

候補者が見たいのは、きれいさではなく実態です。スマートフォンで撮った、台本無しの社員の一分の一言のほうが、制作会社の演出された数分の動画より、「本当の話し方と空気」が伝わります。自然光の場所で、正面から、一度話してもらい、撮り直しは一回まで。編集はつなぐだけ。「質が低い」と感じるのは、テレビや広告の動画と比べているからで、候補者は比べていません。演出は、実態を消すので、逆効果です。

### 制作会社に頼んで作った動画が、見られていません

「全部入りの会社紹介」を、採用サイトのトップに一本置いて終わりになっていることが多いです。見られるのは、候補者の流れの中の場面（求人票、スカウトの返信後、面接の前、内定後）に、その場面に合う短い動画を置いたときです。既にある動画を、短く切り出して場面ごとに使う形もあります。今後は、「伝わっていないもの」を一つに絞り、社内で短く撮り、場面ごとに置く形にします。面接の最初に「動画をご覧になりましたか」と聞いて、効果を測ります。
