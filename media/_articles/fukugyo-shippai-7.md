週に何時間と決めて始めたのに、ある週は候補者の返信が集中して倍になり、別の週は本業の急な残業で半分になる。依頼側に「今週はどれくらい動けますか」と聞かれても、答えられない。稼働が読めないまま、約束が守れず、信頼が落ちていく。結論を先に書くと、**稼働が読めなくなるのは、「候補者の動きは自分で決められない」「本業の予定は後から変わる」「自分の見積もりが楽観的」の三つが重なるからです。この三つは無くせません。だから、読めるようにするのではなく、読めない前提で稼働を組みます。**枠を本業の繁忙期でも守れる量で固定し、候補者の山を予告し、予備の枠を空け、依頼側と読めなさを共有する。この形なら、読めなくても約束は守れます。稼働の上限の決め方は[稼働時間の上限](/media/fukugyo-kadou-jikan/)に、複数の案件の枠の組み方は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に、稼働が合わなくなったときの調整は[稼働が合わなくなったら](/media/fukugyo-qa-12/)にまとめています。

## 読めなくなる三つの要因

稼働が読めなくなる要因は三つあり、どれも自分の努力では無くせません。

| 要因 | 内容 | なぜ無くせないか |
|---|---|---|
| 一、候補者の動きは自分で決められない | 返信が来る日、辞退の連絡、面接の日程の変更。候補者の都合で、いつ来るかが決まる | 候補者は依頼側の外の人で、こちらの予定に合わせない |
| 二、本業の予定は後から変わる | 急な残業、出張、会議の追加、繁忙期のずれ | 本業の都合は、副業の予定より優先され、後から入る |
| 三、自分の見積もりが楽観的 | 「文面の作成は一時間」と見積もり、実際は三時間かかる。「今週は余裕がある」と思い、実際は無い | 人は、自分の作業の時間を短く、自分の余裕を多く見積もる傾向がある |

三つの要点は、「無くせないものを、読めるようにしようとしない」ことです。候補者の動きを予測しようとしても、本業の予定を固定しようとしても、見積もりを正確にしようとしても、どれも限界があります。読めないことを前提に、読めなくても回る形を作るほうが、確かです。

## 読めないまま進めると起きること

読めない稼働を、読めるつもりで進めると、次のことが起きます。

| 起きること | 依頼側から見えること |
|---|---|
| 「今週は〇時間動ける」と言って、動けなかった | 「言ったことと違う」。信頼が下がる |
| 候補者の山が来て、他の工程が止まった | 「なぜ止まったのか分からない」。理由が伝わらない |
| 本業の残業で、期限を過ぎた | 「遅れた」。遅れの理由は依頼側に関係ない |
| 見積もりより時間がかかり、請求が想定を超えた | 「聞いていた額と違う」。時間単価の契約で起きる |
| 楽観で受けた量が回らず、全部が薄くなった | 「品質が落ちた」 |
| 読めないことを隠して、毎回「何とかします」と言った | 「何とかならなかった」が続く。言葉が信じられなくなる |
| 読めない不安で、稼働を実態より多く確保した | 本業と生活を削り、別の支障が出る。[本業に支障が出る](/media/fukugyo-shippai-9/) |

起きることの要点は、「読めないこと自体ではなく、読めるふりをしたことで信頼が落ちる」ことです。依頼側は、副業の担当者の稼働が本業の都合で変わることを想定しています。想定していないのは、「〇時間動ける」と言われて動けなかったことです。読めないなら、読めないと伝えたほうが、依頼側は予定を組めます。

### エラベルの見解

相談で最も多い思い込みは、「稼働を正確に読めるようになれば、失敗しなくなる」というものです。実際には、稼働を正確に読めている担当者は、見ている限りほとんどいません。長く続いている人も、候補者の動きと本業の予定は読めていません。読めていないのに続いているのは、読めない前提で、枠を固定し、山を予告し、予備を空けているからです。読めるようになろうとした人は、読めない現実に毎回裏切られ、疲れて止まっています。

見ていて差がつくのは、依頼側に「読めない部分」を先に伝えているかです。「候補者の返信が集中する週は、他の工程が遅れることがあります」「本業の都合で、週によって稼働が変わります。ただし、候補者への返信は毎日の枠で維持します」と最初に伝えている人は、稼働が変わっても依頼側から「言っていた通り」と受け取られています。伝えていない人は、同じ変動が「約束と違う」になります。エラベルでは、担当者の稼働を「週に〇時間」ではなく「固定できる枠と、変動する部分」で依頼側に伝えており、読めなさを最初に共有する形にしています。読めないことは、隠すものではなく、共有するものです。

## 兆しの見つけ方

稼働が読めなくなる前に、兆しが出ます。

| 兆し | 何が起きているか |
|---|---|
| 「今週は〇時間」と言った週の実績が、毎回ずれている | 見積もりが楽観的。ログと見積もりを比べていない |
| 候補者の山が来るたびに、他の工程が止まる | 山を予告していない。予備の枠が無い |
| 本業の急な予定で、副業の期限が毎月一度は動く | 枠が本業の繁忙を織り込んでいない |
| 依頼側に「今週はどうですか」と聞かれることが増えた | 依頼側が稼働を読めなくなっている。こちらから先に伝えていない |
| 「何とかします」と言う回数が増えた | 読めないことを隠している |
| 稼働ログを付けなくなった | 実態を見るのが辛くなっている。または、枠を超えて記録の余裕が無い |
| 時間単価の請求が、毎月大きく変わる | 稼働の変動が請求に直結し、依頼側の予算を読めなくしている |

兆しの要点は、「見積もりと実績のずれを、ログで見ているか」です。ずれを見ていなければ、楽観的な見積もりは直りません。毎週、見積もりと実績を並べ、ずれの大きさと方向を見る。それだけで、次の見積もりは実態に近づきます。ログの付け方は[稼働ログの付け方](/media/fukugyo-log/)に書いています。

## 読めない前提の稼働の組み方

読めない三つの要因を、それぞれ読めない前提で扱う組み方です。

| 要因 | 組み方 | 内容 |
|---|---|---|
| 候補者の動き | 毎日の短い枠を固定し、山の時期を予告する | 候補者への返信は毎日の短い枠で受ける。面接や内定が集中する時期は、依頼側の採用の予定から先に見え、その週は予備の枠を当てる |
| 本業の予定 | 枠を本業の繁忙期でも守れる量で固定し、変動する部分を分ける | 「固定できる枠」と「余裕があれば使う枠」に分け、依頼側には固定できる枠だけを約束する。余裕の枠は、使えたら使う |
| 自分の見積もり | ログの実績で見積もり、余裕を掛ける | 「文面の作成」の見積もりは、ログの過去の実績から。初めての作業は、見積もりに余裕を掛ける。期限は余裕を見て言う |
| 全体 | 予備の枠を週に一つ空ける | 山、本業の急な予定、見積もりのずれのどれが来ても、予備の枠で吸収する。使わなければ休む |

組み方の要点は、「依頼側に約束するのは、固定できる枠だけ」だということです。「週に十時間」と言うと、十時間が約束になり、本業の都合で八時間になった週は「約束と違う」になります。「固定できるのは火・木の夜と土曜の午前で、余裕があればそれ以上動きます」と言えば、固定の部分が約束で、それ以上は上乗せになります。同じ稼働でも、伝え方で依頼側の受け取り方が変わります。枠の置き方は[週何時間必要か](/media/fukugyo-qa-4/)に、繁忙期の織り込み方は[稼働時間の上限](/media/fukugyo-kadou-jikan/)に整理しています。

## 依頼側と読めなさを共有する

読めない部分は、隠さずに依頼側と共有します。共有の形が決まっていれば、変動が問題になりません。

| 共有すること | 伝え方 | 時期 |
|---|---|---|
| 固定できる枠と変動する部分 | 「固定できるのは〇〇。それ以上は本業の都合で週により変わります」 | 契約の前 |
| 本業の繁忙期 | 「〇月と〇月は本業の都合で稼働が下がります」 | 契約の前 |
| 候補者の山への対応 | 「面接や内定が集中する週は、他の工程を翌週に回すことがあります。候補者への返信は維持します」 | 契約の前と、山が見えたとき |
| 週の見込み | 「今週は固定の枠に加えて、〇〇ができる見込みです」 | 週の初めの進捗の報告で |
| 変動が起きたとき | 「本業の予定が入り、今週は固定の枠だけになります。〇〇は来週に回します」 | 分かった時点で、すぐ。[遅れそうなときの連絡](/media/fukugyo-okure-renraku/) |
| 時間単価の場合の請求の幅 | 「月の稼働は〇時間から〇時間の幅になる見込みです」 | 契約の前。依頼側の予算のため |

共有の要点は、「週の初めに、その週の見込みを一行で伝える」ことです。「今週は固定の枠に加えて、文面の改良ができる見込み」「今週は本業の都合で固定の枠だけ」と、週の初めに伝えておけば、依頼側はその週の期待を合わせられ、変動が「約束と違う」になりません。進捗の報告に一行足すだけで済みます。報告の形は[報告の頻度をどう決めるか](/media/fukugyo-report-hindo/)に書いています。

## 見積もりの精度を上げる記録の使い方

三つの要因のうち、「自分の見積もりが楽観的」だけは、記録で直せます。

| 手順 | 内容 |
|---|---|
| 一、作業の種類ごとに、ログの実績を集計する | 「文面の作成」「求人票の案」「面接の準備」など、作業の種類ごとに、実際にかかった時間を月ごとに見る |
| 二、見積もりと実績のずれを記録する | 「見積もり一時間、実績三時間」のように、ずれを残す。ずれの方向（いつも長いか）と大きさを見る |
| 三、次の見積もりは実績で出す | 「文面の作成は、実績では平均でこれくらい」を、次の見積もりに使う。感覚で出さない |
| 四、初めての作業は余裕を掛ける | 実績が無い作業は、似た作業の実績に余裕を掛けて見積もる |
| 五、期限は見積もりに余裕を足して言う | 見積もりが三時間なら、期限は三時間で終わる日ではなく、余裕を持った日にする |
| 六、月に一度、見積もりの癖を見る | 「自分はいつも見積もりが短い」「候補者の対応の時間を入れ忘れる」のような癖を、ログから見つける |

記録の要点は、「見積もりは感覚ではなく、ログの実績で出す」ことです。感覚で出す見積もりは、毎回楽観的になります。ログの実績で出せば、少なくとも過去と同じ精度になり、ずれを記録すれば、精度は上がっていきます。数か月続けると、自分の見積もりの癖が分かり、癖を織り込んだ見積もりができるようになります。

## 読めなくなったときの立て直し

すでに稼働が読めず、約束を守れていない場合の立て直しです。

| 手順 | 内容 |
|---|---|
| 一、約束を「固定できる枠」だけに戻す | 依頼側に「稼働の見込みを見直し、固定できる枠だけをお約束する形にしたい」と伝える。余裕の枠は上乗せに |
| 二、本業の繁忙期を織り込み直す | 過去数か月のログで、本業の都合で消えた枠を見て、繁忙期でも守れる量に固定の枠を減らす |
| 三、候補者の山の時期を依頼側から聞く | 依頼側の採用の予定（面接の集中、内定の時期）を聞き、その週に予備を当てる |
| 四、見積もりをログで出し直す | 感覚の見積もりをやめ、ログの実績で出す |
| 五、週の見込みを毎週伝える形にする | 週の初めの報告に、その週の見込みを一行足す |
| 六、範囲が枠に入らないなら、範囲を絞る | 固定の枠に範囲が入らないなら、範囲の見直しを依頼側と話す。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |

立て直しの要点は、「一」で約束を固定できる枠に戻すことです。読めない稼働で約束を続けると、守れない約束が積み重なり、信頼が落ち続けます。約束を固定できる枠だけに戻せば、守れる約束になり、それ以上は上乗せとして評価されます。依頼側には「見直したい」と正直に伝えれば、「言っていた通りに動けなくて困る」より、受け入れられます。範囲の見直しの進め方は[範囲が広がっていくとき](/media/fukugyo-scope-creep/)に整理しています。

### エラベルの見解

担当する側から見ると、稼働が読めなくて困っている人は、読めるようになろうとしていて、読めないことを隠しています。長く続いている人は、読めないことを認めていて、固定できる枠だけを約束し、変動する部分は「余裕があれば」と伝え、週の初めに見込みを一行伝え、予備の枠を空けています。同じように読めていないのに、後者は依頼側から「安定している」と評価されています。

順番として、固定できる枠を本業の繁忙期で決め、依頼側には固定の枠だけを約束し、変動する部分と繁忙期を先に伝え、候補者の山を依頼側の予定から予告し、予備の枠を空け、見積もりはログの実績で出し、週の初めに見込みを伝える。この順番で、稼働は読めなくても、約束は守れます。エラベルでは、担当者の稼働を「固定できる枠」と「変動する部分」に分けて依頼側に伝え、依頼側にも担当者の稼働が本業の都合で変わることを前提にしてもらっています。読めなさを共有する仕組みが、担当者と依頼側の両方を守ります。

## まとめ

- 稼働が読めないのは**候補者の動き・本業の予定・自分の楽観的な見積もり**の三つが重なるから。どれも無くせない
- 信頼が落ちるのは**読めないこと自体ではなく、読めるふりをしたこと**
- 兆しは**見積もりと実績のずれ・山のたびに止まる・依頼側から聞かれる・「何とかします」が増える・ログが止まる**
- 組み方は**毎日の短い枠を固定し山を予告する・固定できる枠と変動する部分を分ける・見積もりはログで出し余裕を掛ける・予備の枠を空ける**
- 依頼側には**固定できる枠だけを約束し、変動する部分・繁忙期・山への対応・週の見込みを先に伝える**
- 見積もりは**感覚ではなくログの実績で**。ずれを記録して癖を知る
- 立て直しは**約束を固定の枠に戻す→繁忙期を織り込み直す→山を聞く→ログで見積もる→週の見込みを伝える→範囲を絞る**

## よくある質問

### 依頼側から「週に何時間動けるか、はっきり決めてほしい」と言われました

「固定できる枠」を曜日と時間帯で答え、「それ以上は本業の都合で週により変わるが、固定の枠は守る」と伝えます。「週に〇時間」と一つの数で答えると、その数が約束になり、変動のたびに「約束と違う」になります。固定の枠と変動の部分を分けて答えれば、依頼側は固定の枠で予定を組め、変動の部分は上乗せとして扱えます。時間単価の契約なら、月の稼働の幅も伝え、依頼側の予算の見込みに使ってもらいます。

### 候補者の山がいつ来るか、依頼側にも分からないと言われました

依頼側の採用の予定（募集の開始、書類の締め、面接の週、内定の時期）を聞けば、山の時期はおおよそ見えます。依頼側の担当者も予定を持っていないなら、「面接が集中しそうな週が見えたら、一週間前に教えてほしい」と頼み、その週に予備の枠を当てます。まったく見えない場合は、毎週の予備の枠を大きめに取り、使わなければ休む形にします。山の対応で他の工程が遅れることは、契約の前に伝えておきます。

### 見積もりを実績で出しても、依頼側の期待より長くなります

実績で出した見積もりが依頼側の期待より長いなら、それは見積もりの問題ではなく、範囲と稼働と依頼側の期待のずれです。「実績ではこれだけかかっている」と事実で示し、「期待に合わせるなら範囲を絞るか、稼働を増やすか、期限を延ばすか」の選択肢を出して、依頼側に選んでもらいます。期待に合わせて見積もりを短くすると、また守れない約束になります。期待のすり合わせは[期待値のすり合わせ](/media/fukugyo-kitai-chousei/)に、選択肢の出し方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。
