事業開発へのスカウトで返信が来ない文面には、共通する型があります。件名が「新規事業の立ち上げメンバー募集」、本文が「裁量を持ってゼロイチで事業を作れます」で、相手の経歴には触れていない。事業開発の経験者は、どの会社も「新規事業」「裁量」「ゼロイチ」と書くので、三語を信じていません。知りたいのは、形だけの新規事業ではないか、何を作るのかテーマはあるのか、予算と権限はどこまでか、撤退の基準と失敗の扱いはどうなっているか、既存事業との関係で動けるのか、経営者がどういう人か、そして自分の事業のどこを見て送ってきたのか。ここが書いてある文面に返信が来て、書いてない文面は開かれずに終わります。結論を先に書くと、**件名は相手の事業の一点と自社の中身とテーマの有無、本文は「一行目→中身とテーマの有無→予算と権限と撤退の基準を経営者の言葉で→既存事業との関係と経営者との距離と出口→経営者がどういう人か→条件の幅→経営者と直接話す締め」の順**で組みます。事業開発に何を訴求するかは[事業開発向けスカウトの訴求](/media/rpo-jigyo-kaihatsu-scout/)に書いていますので、ここでは「件名と本文の型」に絞ります。

## 先に決めるのは「中身・テーマの有無・予算と権限・撤退の基準」

文面を書く前に、経営者に四つを、経営者の言葉で聞いて決めます。何を作るのか（中身。既存の顧客に新しい商品か、新しい顧客に既存の技術か、全く別の事業か）、テーマは決まっているのか（決まっている・候補がある・一緒に決める、のどれか）、予算と権限はどこまでか（いくらまで、誰の承認で、人は採れるか）、撤退の基準はあるか（いつ何が出なければ止めるか、止めたあと本人はどうなるか）。四つが無い「新規事業」は、読む側に「経営者の思いつきに付き合わされる」と読まれます。

| 決めること | 文面のどこに使うか |
|---|---|
| 中身（何を作るか） | 件名と本文の二段目 |
| テーマの有無（決まっている・候補・一緒に決める） | 本文の二段目。詳細は書かず、有無と段階だけ |
| 予算と権限（経営者の言葉で） | 本文の三段目 |
| 撤退の基準と失敗の扱い | 本文の三段目。隠さない |
| 既存事業との関係（資源を使えるか、邪魔されないか） | 本文の四段目 |
| 経営者との距離と出口（直下か、成功したらどうなるか） | 本文の四段目 |

止まりやすいのは、経営者に聞かずに人事が「新規事業」「裁量」で書くときです。予算と撤退の基準を経営者が決めていない会社は、文面の三段目が書けません。書けないなら、先に決めます。

## 件名の型

件名は「相手の事業の一点＋自社の中身とテーマの有無」です。「新規事業」「ゼロイチ」「立ち上げメンバー」は、事業開発の受信箱では埋もれます。

| 型 | 例の形 |
|---|---|
| 相手の一点＋中身 | 「〇〇（相手が作った事業）を見て｜〇〇（既存の顧客）に〇〇（新しい商品）を作る事業開発」 |
| 相手の一点＋テーマの段階 | 「〇〇（相手の事業）の立ち上げについて｜テーマは決まっていて、予算と権限を持って動く一人目」 |
| 相手の転向元＋中身 | 「〇〇（営業・ファーム）で〇〇をされてきた方へ｜〇〇の開拓が中心の事業開発」 |

件名でやってはいけないのは、「新規事業」「裁量」「ゼロイチ」「挑戦」だけで組むこと、テーマの詳細を件名に書くこと（社外に出る）、伏せ字で煽ることです。件名のNGは[スカウト件名のNG例](/media/scout-kenmei-ng/)に書いています。

## 本文の型

本文は七段で組みます。読む側が最初に見るのは一行目と、「予算と権限と撤退の基準」です。

| 順 | 書くこと | 長さ | 注意 |
|---|---|---|---|
| 一 | 相手の事業の一点（何を見て送ったか） | 一〜二文 | 成功か失敗かは問わない。畳んだ事業にも触れてよい |
| 二 | 中身とテーマの有無（何を作るか、テーマは決まっているか） | 二〜三文 | テーマの詳細は書かない。有無と段階だけ |
| 三 | 予算と権限と撤退の基準（経営者の言葉で） | 二〜三文 | 「裁量」と書かず、範囲と基準を書く。失敗の扱いも |
| 四 | 既存事業との関係、経営者との距離、出口 | 二〜三文 | 資源を使えるか、直下か、成功したら何になるか |
| 五 | 経営者がどういう人か（経歴、決め方、新規事業への関わり方） | 一〜二文 | 良く見せず、事実を書く |
| 六 | 条件の幅（報酬、役職、株式報酬があれば） | 一〜二文 | 幅で書く。決まっていないことは決まっていないと書く |
| 七 | 締め（経営者と直接話す場、選考の前の面談） | 一文 | 応募を求めず、経営者と話す場を出す |

止まりやすいのは、三段目を「裁量を持って進めてもらいます」で書くときです。事業開発の読む側は「裁量」を「予算も権限も決まっていない」と読みます。

## 転向元で一行目を変える

事業開発への転向元は、大きく五つあります。一行目と、重心を置く段が変わります。

| 転向元 | 一行目の変え方 | 重心を置く段 |
|---|---|---|
| 起業経験者（畳んだ人を含む） | 作った事業の一点に触れ、資源と権限と撤退の扱いを先に書く | 三段目（予算と権限と撤退） |
| スタートアップ出身 | 立ち上げた事業や機能の一点に触れ、既存の資源で速く検証できることを書く | 四段目（既存事業との関係） |
| 大企業の新規事業 | 担った新規事業の一点に触れ、判断の速さと撤退の基準の明確さを書く | 三段目と四段目（経営者との距離） |
| ファーム出身 | 案件の一点に触れ、「提言までではなく実行まで」を先に書く | 二段目（中身）と四段目（出口） |
| 営業からの転向 | 開拓や交渉の一点に触れ、開拓と交渉が中心であることと、事業を作る側に回る場を書く | 二段目と五段目（経営者） |

止まりやすいのは、五つの転向元に同じ一行目を送るときです。大企業の新規事業の人に「判断の速さ」を書かず、営業からの転向に「開拓が中心」を書かないと、自分に来た文面だと読まれません。

### エラベルの見解

相談で最も多いのは、「新規事業、裁量、ゼロイチで送っているのに返信が来ない」という会社です。文面を見ると、何を作るのかも、テーマが決まっているのかも、予算と権限も、撤退の基準も書いてなく、「一緒に新規事業を作りましょう」で終わっている。読む側は、その文面を「経営者の思いつきで、予算も決まっていない」と読みます。ある会社では、担当者が経営者と話して、三段目を「初年度の予算は〇〇の範囲で、この人の判断で使える。人は一名まで採れる。半年で〇〇の検証が出なければ止める。止めたら既存事業の企画に戻る」と、経営者の言葉で書き直しました。件名を「〇〇（相手が畳んだ事業）の立ち上げを見て｜〇〇に〇〇を作る、テーマの決まった事業開発」に変え、一行目で畳んだ事業の判断に触れたところ、起業経験者から返信が来て、面談で「撤退の基準と止めたあとの扱いが書いてあったのは初めてだ」と言われました。事業開発の文面は、良く見せる言葉を削り、経営者の言葉で予算と権限と撤退を書くほうが届きます。

## 書いてはいけないこと

- 「新規事業」「裁量」「ゼロイチ」「挑戦」だけで中身を書かない
- テーマの詳細を書く（社外に出る。有無と段階だけにする）
- 予算と権限が決まっていないのに「裁量を持って」と書く
- 撤退の基準が無いのに書かない。無いなら「一緒に決める」と書く
- 既存事業との関係で動けないのに「既存の資源を使えます」と書く
- 経営者が新規事業に関わらないのに「経営者直下」と書く
- 相手の畳んだ事業を失敗として扱う（判断の経験として触れる）
- 応募を求める締め（「ぜひご応募ください」）

## 送る前の確認

| 確認すること | 見る場所 |
|---|---|
| 一行目が相手の事業の一点になっているか | 本文の一段目 |
| 中身とテーマの有無が書いてあり、テーマの詳細は書いていないか | 本文の二段目 |
| 予算と権限と撤退の基準が経営者の言葉になっているか | 本文の三段目 |
| 「裁量」「ゼロイチ」で範囲をごまかしていないか | 本文の三段目 |
| 既存事業との関係と経営者との距離と出口が実態どおりか | 本文の四段目 |
| 転向元に合う一行目と重心になっているか | 本文の一段目と重心の段 |
| 締めが経営者と話す場になっているか | 本文の七段目 |

## 返信が来ないときの直す順番

| 順 | 直すところ | 見る指標 |
|---|---|---|
| 一 | 件名（相手の一点＋中身になっているか） | 開封 |
| 二 | 一行目（相手の事業の一点か、経歴の要約か） | 開封後の返信 |
| 三 | 三段目（予算と権限と撤退の基準が経営者の言葉か） | 返信の中身（「詳しく聞きたい」が出るか） |
| 四 | 四段目（既存事業との関係、経営者との距離、出口） | 面談での質問（ここを聞かれるなら書き足りない） |
| 五 | 送る相手（転向元と中身が合っているか） | 返信率が転向元で違うか |

一度に全部を変えず、一つずつ変えて比べます。比べ方は[スカウト文面のA/Bテスト](/media/scout-abtest/)に書いています。

### エラベルの見解

担当する側から見ると、事業開発の文面で会社ごとに差がつくのは、「経営者が予算と権限と撤退の基準を先に決めているか」です。文面の型は同じでも、経営者が「新規事業をやりたい。予算は成果を見て」としか言わない会社では、担当者は三段目を書けず、「裁量」と書くしかありません。経営者が「予算はこの範囲、この人の判断で使える、半年でこれが出なければ止める、止めたら企画に戻る」と話した会社では、文面がそのまま経営者の言葉になり、返信が来ました。エラベルで事業開発のスカウトを担当する人には、文面を書く前に、経営者に「何を作るか、テーマは決まっているか、予算と権限はどこまでか、撤退の基準と止めたあとの扱いはどうか」を直接聞いてもらっています。決まっていなければ、文面の前に決めてもらいます。対象の絞り方は[事業開発を探すときの検索条件](/media/scout-jigyo-kaihatsu-kensaku/)に書いています。

## 代行に出す場合の範囲

担当者が持つのは、経営者から中身とテーマの有無と予算と権限と撤退の基準を聞き出すこと、相手の事業の一点を読んで一行目を書くこと、転向元ごとに文面を分けること、返信率を見て件名と一行目と三段目を直すこと、です。会社が持つのは、経営者が担当者に話す時間、中身とテーマと予算と権限と撤退の基準の決定、経営者と直接話す場の設定、面談で文面と実態がずれないこと、です。担当者が事業開発の経歴（起業、スタートアップ、大企業の新規事業、ファーム、営業）を読める経験があるかは、担当者を選ぶときに確かめます。

## まとめ

- 件名は**相手の事業の一点＋自社の中身とテーマの有無**。「新規事業」「ゼロイチ」「立ち上げメンバー」は埋もれる
- 本文は**一行目→中身とテーマの有無→予算と権限と撤退の基準を経営者の言葉で→既存事業との関係と経営者との距離と出口→経営者がどういう人か→条件の幅→経営者と直接話す締め**の順
- 「裁量」「ゼロイチ」と書かず、**予算と権限の範囲と撤退の基準を書く**。テーマの詳細は書かない
- 転向元（**起業経験者・スタートアップ出身・大企業の新規事業・ファーム出身・営業からの転向**）で一行目と重心を変える
- **予算と権限と撤退の基準が決まっていないなら、文面の前に決める**
- 返信が来ないときは**件名→一行目→三段目→四段目→送る相手**の順で一つずつ直す

## よくある質問

### 予算も撤退の基準も、まだ決まっていません

決まっていない状態で「裁量を持って」と送ると、読む側に見透かされます。二つの選び方があります。一つは、文面の前に経営者が決めること。初年度の予算の範囲、この人の判断で使える範囲、いつ何が出なければ止めるか、止めたあと本人はどうなるか、の四つです。もう一つは、決まっていないことを正直に書き、「予算と撤退の基準は、入ってもらう前に経営者と一緒に決める」と書くこと。後者は、起業経験者には通ることがありますが、大企業の新規事業の経験者には敬遠されます。

### テーマを書かないと、何をするか伝わらないのではないですか

テーマの詳細は社外に出るので書きません。書くのは、中身（既存の顧客に新しい商品か、新しい顧客に既存の技術か、全く別か）と、テーマの段階（決まっている・候補がある・一緒に決める）です。この二つがあれば、読む側は自分に合うかを判断できます。詳細は、経営者との面談で、秘密保持の扱いを決めてから話します。「面談でテーマの詳細を話す」と書けば、面談に来る理由にもなります。

### 畳んだ事業の経験がある人に、どう触れればよいですか

一行目で、事業を作った判断と畳んだ判断の両方に触れます。「〇〇を立ち上げ、〇〇の判断で止められた経緯を見て」のように、失敗ではなく判断として扱います。事業開発の要件で確かめるのは、成功したかではなく、仮説を立てて検証し、続けるか止めるかを判断した経験です。畳んだ人はその経験を持っています。そのうえで三段目で、自社の撤退の基準と止めたあとの扱いを書けば、「この会社は失敗の扱いを分かっている」と読まれます。要件の考え方は[事業開発の採用要件の作り方](/media/rpo-jigyo-kaihatsu-youken/)に書いています。
