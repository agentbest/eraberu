「採用広報を始めたい。企画を立ててほしい」と頼まれて、「社員紹介」「オフィス紹介」「代表インタビュー」「制度の紹介」とネタを並べた年間の一覧を作ると、最初の数本で止まります。書く人がいない、ネタが尽きる、何のために書いているか分からない。企画が続かないのは、発信するネタから始めているからで、「誰の、どの迷いに、どの場で答えるか」から始めれば、ネタは実態から出続けます。結論を先に書くと、**採用広報の企画は、ターゲット像の「迷う理由」と「情報の取り方」を出発点に、読者の層・答える迷い・場・材料・書く人・頻度・見る数字を一枚にし、ネタは五つの問いを社員に繰り返して実態から拾い、続けられる頻度で組み、盛らず、効果は面接での声と経路の応募で見て、担当者は企画と材料と照合までを担います。**会社側から見た手順は[採用広報・オウンドメディアの進め方](/media/rpo-task-saiyo-koho-susumekata/)に、ネタの拾い方は[採用広報のネタが尽きた](/media/rpo-koho-neta/)に、記事の執筆を案件として受ける形は[採用広報の記事執筆の副業の実務](/media/fukugyo-saiyo-koho-fk-shigoto/)に書いています。ここでは、企画の型に絞ります。

## ネタから始める企画が続かない理由

| 企画の形 | 何が起きるか |
|---|---|
| ネタの一覧を年間で作る | 誰に向けて書くかが無く、書く人が困る |
| 「社員紹介」「オフィス紹介」 | 候補者の迷いに答えていない。読まれない |
| 流行の形式（動画、対談）から入る | 制作の負担が大きく、続かない |
| 数を目標にする（月〇本） | 質が落ち、実態と離れる |
| 効果を見ない | 続ける理由が無くなる |

採用広報は、候補者が「この会社は実際どうか」を確かめるときの答えを、先に置いておくものです。答えるべき問いが決まれば、ネタは問いから出ます。

## 出発点はターゲット像の二つの欄

| ターゲット像の欄 | 企画での使い方 |
|---|---|
| 迷う理由 | 答える問い。「小さい会社に移って次の転職で不利にならないか」→「辞めた後の経験がどう活きているか」の記事 |
| 情報の取り方 | 場の選択。媒体で探す人には採用サイトと求人票、SNSで見る人にはSNS、知人経由ならリファラルの材料 |
| 動く理由 | 「この会社で働く理由」の記事。魅力の三つに対応 |
| 比べる相手 | 比べる相手との差が出る点を、実態で |

ターゲット像が無いまま企画を立てると、ネタの一覧に戻ります。ターゲット像の作り方は[ターゲット像を1枚にまとめる](/media/fukugyo-skill-persona/)に書いています。

### エラベルの見解

担当する側から見ると、採用広報の企画で最も差がつくのは、「答える迷い」を一本ごとに決めているかです。受ける側は、「社員インタビューを月一本」と決めて、誰に何を聞くかは後で考えます。すると、聞く問いが「やりがいは」になり、答えは「成長できる」になり、候補者の迷いには答えません。「この記事は、『裁量が本当にあるのか』という迷いに答える」と決めてから社員を選び、「決まりの無いことを自分で決めた場面」を聞けば、記事は迷いへの答えになります。エラベルで担当者を選ぶ企業には、「広報の一本ごとに、候補者のどの迷いに答えるかが決まっていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、企画の一枚の各行に「答える迷い」の列を作り、空欄の行は企画しないこと。

## 企画の一枚

| 列 | 中身 |
|---|---|
| 読者の層 | ターゲット像のどの層か（役割、いまどこで何をしているか） |
| 答える迷い | ターゲット像の「迷う理由」から一つ |
| 場 | 採用サイト・記事・SNS・イベント・求人票への追記。情報の取り方に合わせる |
| 材料 | 誰の、どの言葉か。いまうまくやっている人、現場の責任者、経営者 |
| 書く人 | 社内の誰か、外部の担当者か。聞く問いは担当者が用意 |
| 頻度 | 続けられる頻度。月一本でよい |
| 見る数字 | 面接での「〇〇を見て」の声の数、経路の応募の数 |
| 書いてはいけないこと | 下の表 |

一行が一本です。年間の一覧ではなく、三か月分を作り、三か月ごとに見直します。

## ネタは五つの問いを社員に繰り返す

| 問い | 出てくるもの | 答える迷い |
|---|---|---|
| 入った頃、最初の三か月で何をしたか | 最初の三か月の実態 | 「入ってすぐ何をするのか」 |
| 前の会社と一番違うことは何か | 他社との差 | 「ここでしか得られないものは」 |
| いま、一日の時間を何に使っているか | 仕事の実態 | 「幅広い業務の中身は」 |
| 決まりの無いことを自分で決めた場面は | 裁量の実態 | 「裁量は本当にあるか」 |
| 辞めようと思ったことがあるか。なぜ残ったか | 迷いと解消 | 「迷ったとき、何が支えになるか」 |

同じ五つの問いを、違う社員に繰り返すと、ネタは尽きません。社員ごとに答えが違い、それが実態の幅になります。「新しいネタ」を探さず、問いを固定して相手を変えます。聞き方は[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/)と同じです。

## 続けられる頻度で組む

| やりがちなこと | 直す |
|---|---|
| 週一本の目標 | 月一本から。三か月続いたら増やす |
| 動画や対談から始める | 文章の記事から。負担が小さい |
| 社員に「書いてください」 | 担当者が問いで聞き、本人の言葉で書き起こし、本人が確認 |
| 外部のライターに全部 | 問いと材料は担当者が用意。文章の整えだけ外部に |
| 公開日を厳密に | 「月に一本」。日は決めない |

頻度は、担当者の稼働と、社員の時間で決まります。続かない企画は、企画ではありません。SNSの続け方は[採用SNSで何を発信すればよいか](/media/rpo-sns-nani/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「広報の効果は、閲覧の数で見る」というものです。閲覧の数は、採用に関係ない人の閲覧も含み、候補者の迷いに答えたかを示しません。採用広報の効果は、「面接で候補者が『〇〇の記事を見て』と言ったか」と「その経路からの応募が動いたか」で見ます。面接の記録の「候補者の質問と迷い」の欄に、「見た記事」を一語足せば取れます。閲覧の数より件数が少なく見えますが、採用に効いたかは、こちらのほうが分かります。受ける側がその場で使える判断としては、企画の一枚の「見る数字」に閲覧の数を置かないこと。置くなら参考の列にし、主は面接での声と経路の応募にします。数字は件数のまま並べ、割合で断定しません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 盛らない・書いてはいけないこと

| 書かない | 理由 |
|---|---|
| 実態より良い働き方、制度の適用の見込み | 入社後に「違った」となる |
| 収入や昇進を保証するように読める表現 | 保証できない |
| 一部の人の例を全体のように | 実績は例として |
| 性別・年齢などに触れる表現 | 募集や採用で法令上の決まりがあると一般に整理されている項目 |
| 候補者の情報、選考の内部 | 個人情報と守秘 |
| 他社の名前を出した比較 | 権利と関係に関わる |
| 社員の私的な情報 | 本人の同意の範囲で。同意があっても最小に |

社員の言葉を載せるときは、本人が原稿を確認し、依頼側が承認します。本人が「載せたくない」と言えば載せません。載せた後に本人から「消してほしい」と言われたら、依頼側の決まりに従って対応します。表記の可否に法令が関わる場合は、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。発信の線は[発信で書いてはいけないこと](/media/fukugyo-hasshin-nglines/)と[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## 担当者は企画と材料と照合まで

| 担当者が担う | 社内か外部が担う | 依頼側が決める |
|---|---|---|
| 企画の一枚 | 文章の執筆（担当者が担う契約もある） | 公開の可否 |
| 五つの問いで社員に聞き、材料を作る | 写真、デザイン、実装 | 載せる社員と内容の承認 |
| 原稿の「実態と合っているか」の照合（現場の責任者と） | 配信の作業 | 表記の可否（専門家の確認） |
| 見る数字の設計と、三か月ごとの見直し | 計測の実装 | 続けるかどうか |

担当者が執筆まで担う契約なら、稼働に執筆の時間を含めます。企画だけの契約なら、執筆は依頼側か外部で、担当者は問いと材料と照合を渡します。範囲は契約に書きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| ネタの一覧から始まっている | ターゲット像の「迷う理由」に戻り、答える迷いを一本ごとに決める |
| 社員の言葉が「成長できる」ばかり | 五つの問いに変える |
| 書く人がいない | 担当者が問いで聞いて書き起こす。本人は確認だけ |
| 頻度が高すぎて止まる | 月一本に。三か月続いたら増やす |
| 効果を閲覧の数で問われる | 面接での声と経路の応募を主に。閲覧は参考 |
| 原稿が盛られる | 現場の責任者と「いま、本当にそうか」で照合 |

## まとめ

- ネタから始める企画は続かない。**誰の・どの迷いに・どの場で答えるか**から
- 出発点は**ターゲット像の「迷う理由」と「情報の取り方」**
- 企画の一枚は**読者の層・答える迷い・場・材料・書く人・頻度・見る数字**。三か月分を作り、三か月ごとに見直す
- ネタは**五つの問いを社員に繰り返す**。新しいネタを探さず、相手を変える
- **続けられる頻度**。月一本から。文章から
- **盛らない・書いてはいけないことの線**。本人の確認と依頼側の承認。個別の判断は専門家にご確認ください
- 効果は**面接での声と経路の応募**。閲覧の数を主にしない。件数のまま
- 担当者は**企画・材料・照合**まで。執筆と制作は契約の範囲で

## よくある質問

### 依頼側が「他社のような、話題になる広報をやりたい」と言います

話題になることと、候補者の迷いに答えることは別です。話題になった広報が、採用に効いたかは、面接での声と経路の応募で見なければ分かりません。「まず、候補者の迷いに答える一本を月に一本、三か月続けて、面接での声を見ましょう」と、小さく始める形を提案します。話題を狙う企画は、制作の負担が大きく、外れたときに何も残りません。迷いに答える記事は、外れても採用サイトの材料として残ります。

### 社員が「自分の言葉が公開されるのは嫌だ」と言います

本人の意向を優先します。氏名と顔を出さず、「〇〇の役割・入社〇年目」の形で載せることを提案し、それでも嫌なら載せません。本人の言葉を載せる場合は、原稿を本人が確認し、修正の権利があることを先に伝えます。公開後に「消してほしい」と言われたときの扱いも、依頼側の決まりで先に決めておきます。載せてくれる社員は、無理に増やさず、五つの問いに答えてくれる数人で足ります。

### 広報の企画を、採用サイトの作り直しと同時に頼まれました

順番は、企画が先です。企画の一枚で「答える迷い」と「場」が決まれば、採用サイトに置く六つの要素の材料が揃い、サイトの作り直しが企画に沿った形になります。同時に進めるなら、サイトの六つの要素と企画の「場」の列を対応させ、サイトのページと記事が同じ迷いに答える形にします。サイトの型は[採用サイトを作り直す](/media/fukugyo-skill-saiyo-site/)に書いています。
