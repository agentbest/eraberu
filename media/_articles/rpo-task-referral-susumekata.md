リファラル採用を自社で設計しようとして、「制度を作って全社に案内する」から始めると、社員は「誰を紹介すればよいか分からない」「気まずい」「評価に響くのでは」と動かず、たまに紹介があっても最初の連絡が遅く、社員には何も戻らず、不採用になると気まずくなり、数か月で紹介はゼロになります。リファラルで最初にやるべきは、制度を作ることではなく、「社員がなぜ紹介しないか」を聞き、「責任者がどう頼み、紹介の後に何を戻すか」を決めることです。それができれば、制度は簡単なもので足ります。結論を先に書くと、**進め方は、方針と謝礼の扱いを決める→社員が紹介しない理由を聞き取る→頼み方の一枚と渡せる材料を作る→責任者が個別に頼む場を作る→受付と最初の連絡と面談の型を作る→社員への戻しの型を作る→不採用時の連絡の型を作る→記録の表を作り、月に一度、紹介と進みと戻しを見る、の八つの手順**です。代行に出す場合の切り分けは[リファラル採用の設計は代行に出せるか](/media/rpo-task-referral-daikou/)に、広がらない構造は[リファラル採用が広がらないとき](/media/rpo-referral-susumanai/)に書いていますので、ここでは自社で進める手順に絞ります。謝礼の法令上の扱いは専門家にご確認ください。

## 手順の全体

| 手順 | やること | 誰が | 頻度 |
|---|---|---|---|
| 一 | 方針と謝礼の扱いを決める | 経営者 | 最初に一度 |
| 二 | 社員が紹介しない理由を聞き取る | 人事 | 最初に一度、半年に一度 |
| 三 | 頼み方の一枚と渡せる材料を作る | 人事 | 募集ごと |
| 四 | 責任者が個別に頼む場を作る | 責任者 | 募集ごと、繰り返し |
| 五 | 受付と最初の連絡と面談の型を作る | 人事 | 最初に一度 |
| 六 | 社員への戻しの型を作る | 人事 | 最初に一度 |
| 七 | 不採用時の連絡の型を作る | 人事 | 最初に一度 |
| 八 | 記録の表を作り、紹介と進みと戻しを見る | 人事 | 月に一度 |

手順の要点は、二が「聞く」で、四が「責任者が頼む」であることです。多くの会社は一と、制度の全社案内だけをやって、二と四がありません。

## 手順一：方針と謝礼の扱いを決める

どの募集でリファラルを使うか（全募集か、特定の職種か）、謝礼を出すか出さないか、出すなら条件（入社時か、一定期間の在籍後か）と額、法令上の扱いを決めます。謝礼は前面に出さず、「感謝の形」にとどめます。専門家にご確認ください。

| 決めること | 考え方 |
|---|---|
| 対象の募集 | まず一つの職種で型を作る |
| 謝礼の有無 | 無くても動く。出すなら前面に出さない |
| 謝礼の条件と額 | 条件を明確に。法令上の扱いを専門家に確認 |
| 評価との関係 | 「関係ない」と明言する |
| 不採用時の扱い | 「社員の責任ではない」と明言する |

止まりやすいのは、謝礼の額の議論に時間を使うときです。謝礼は動く理由の主ではありません。額より、明言の文面を先に決めます。

## 手順二：社員が紹介しない理由を聞き取る

社員数人に、一対一で「紹介しない理由」を聞きます。「誰を紹介すればよいか分からない」「知り合いに勧めてよいか迷う」「気まずい」「手間」「評価に響くのでは」「以前紹介したが何も戻らなかった」「謝礼が目的に見えるのが嫌」。理由は会社ごとに違い、聞かないと分かりません。

| 理由 | 直す手順 |
|---|---|
| 誰を紹介すればよいか分からない | 三（頼み方の一枚で像を具体に） |
| 気まずい・手間 | 五（名前と連絡先だけ。最初の連絡は人事） |
| 評価に響くのでは | 一（明言） |
| 何も戻らなかった | 六（戻しの型） |
| 不採用のとき気まずい | 七（不採用時の連絡の型） |

止まりやすいのは、聞かずに「社員は忙しいから」と決めつけるときです。聞くと、忙しさより「誰か分からない」「何も戻らない」のほうが多い。

### エラベルの見解

これをやる前に、先に手順二の「聞き取り」をしておかないと、手順三以降の型は的を外します。相談で多いのは、「頼み方の一枚も戻しの型も作ったのに、紹介が来ない」というご相談です。聞くと、社員が動かない理由は「以前紹介した知り合いが不採用になり、その後の連絡が無く、知り合いに気まずい思いをさせた」ことで、型を作っても「もう紹介したくない」が残っていました。責任者がその社員に直接、当時の対応を謝り、不採用時の連絡の型を作ってから紹介が再開しました。型は、社員が動かない理由に合わせて作るものです。エラベルでリファラルの設計を担当する人には、型を作る前に、社員数人から理由を聞き取ってもらっています。

## 手順三：頼み方の一枚と渡せる材料を作る

募集ごとに、「こういう人を（像を具体的に、役割で）」「この理由で」「いつまでに」「名前と連絡先だけでよい」「意向が無くても構わない」「評価に関係ない」「不採用でも社員の責任ではない」を一枚にします。社員が知り合いに渡せる材料（求人の一枚、社員の記事、会社の紹介）も用意します。

| 一枚に書くこと | 例 |
|---|---|
| どんな人 | 既存顧客の対応が長く、大手の分業に物足りなさを感じている人 |
| どの役割 | 〇〇チームで、担当を持って顧客を回す |
| なぜ今 | 顧客が増えて、担当を分ける時期 |
| いつまでに | 来月中に一次面接まで |
| 社員にしてほしいこと | 名前と連絡先だけ。声かけは人事がする |
| 明言 | 評価に関係ない。不採用でも社員の責任ではない |

止まりやすいのは、「良い人がいたら紹介して」と像を曖昧にするときです。社員は「良い人」を思い浮かべられません。「前職の同僚で既存営業が長い人」のように、社員の知り合いの範囲で像を描きます。

## 手順四：責任者が個別に頼む場を作る

制度の全社案内では動きません。責任者が、社員に個別に、名前を挙げて頼みます。「〇〇さん、前職で一緒だった人で、こういう人はいませんか。あなたのチームに入る人です」。一度で終わらず、募集のたびに繰り返します。頼む相手は、その職種の経験者が知り合いにいそうな社員から始めます。

止まりやすいのは、責任者が「案内は出したから」で個別に頼まないときです。頼む時間は一人数分です。責任者の予定に「今週三人に頼む」を入れます。

## 手順五：受付と最初の連絡と面談の型を作る

社員から名前と連絡先を受け取ったら、人事がその日のうちに紹介された人に連絡し、カジュアル面談を入口にします。社員に「声をかけておいて」と頼まない。紹介された人への最初の連絡は、「〇〇さんからご紹介いただき」と紹介者の名前を出してよいか社員に確認してから送ります。

| 場面 | 誰が | いつ |
|---|---|---|
| 社員から名前と連絡先を受け取る | 人事 | ― |
| 紹介された人への最初の連絡 | 人事 | 当日中 |
| カジュアル面談の設定 | 人事 | 連絡から数日以内 |
| 面談 | 社員か会社の人 | ― |

止まりやすいのは、最初の連絡が「来週まとめて」になるときです。紹介された人は社員から「会社から連絡が行く」と聞いていて、来なければ社員が気まずくなります。当日中に送ります。面談の設計は[カジュアル面談の進め方](/media/rpo-task-casual-mendan-susumekata/)に書いています。

## 手順六：社員への戻しの型を作る

紹介した社員に、受け取った当日「連絡しました」、面談が終わったら「お話ししました」、選考に進んだら「一次面接に進みました」、結果が出たら結果を、と一行ずつ戻します。感謝は責任者から伝えます。過去に紹介してもらって戻していない分も、今から戻します。

| 節目 | 戻すこと | 誰が |
|---|---|---|
| 受け取った当日 | 「連絡しました」 | 人事 |
| 面談後 | 「お話ししました」 | 人事 |
| 選考に進んだ | 「〇次に進みました」 | 人事 |
| 結果 | 結果と感謝 | 結果は人事、感謝は責任者 |

止まりやすいのは、「結果が出てからまとめて」で途中を戻さないときです。社員は途中で「どうなったのかな」と思い、聞けずにいます。一行でよいので節目ごとに戻します。

## 手順七：不採用時の連絡の型を作る

紹介された人には、人事が先に丁寧に連絡します。紹介した社員には、結果だけを伝え、「紹介してくれたこと自体に感謝している」「評価には関係ない」を責任者から伝えます。理由の詳細は社員に伝えず、「本人には丁寧に連絡済み」と伝えて、社員が知り合いに何と言えばよいか困らないようにします。

止まりやすいのは、社員に不採用の理由を詳しく伝えるときです。社員は知り合いに言えず、板挟みになります。結果と感謝だけにします。

## 手順八：記録の表を作り、月に一度、紹介と進みと戻しを見る

紹介ごとに、紹介した社員、紹介された人、受付日、最初の連絡日、面談日、選考の進み、結果、社員への戻しの日、を一行で残します。月に一度、紹介の数、進んだ数、戻しが抜けていないか、誰が紹介してくれているかを見て、責任者に伝えます。

止まりやすいのは、紹介の数だけを見て「少ない」で終わるときです。戻しが抜けていないか、頼んだ社員の数はどうか、を先に見ます。紹介が少ないのは、頼んでいないか、戻していないかのどちらかであることが多い。

## 外の人に頼む場合の境目

八つの手順のうち、一の方針、四の責任者が頼むこと、六の感謝、七の明言、判定は会社が持ちます。二の聞き取り、三の一枚と材料、五の受付と最初の連絡と面談の設定、六の戻しの運用、七の紹介された人への連絡、八の記録は、外の人に出せます。切り分けの詳しい話は[リファラル採用の設計は代行に出せるか](/media/rpo-task-referral-daikou/)に書いています。

外に出す判断の目安は、「責任者は頼む気があるが、聞き取りと型と紹介後の運用に人事の時間が取れない」ときです。責任者が頼まないまま外に出しても、紹介は始まりません。

### エラベルの見解

担当する側から見ると、リファラルで会社ごとに差がつくのは、手順四の「責任者が個別に頼んでいるか」です。聞き取りも型も戻しも、担当者が作って回せます。しかし、責任者が「案内は出した」で止まる会社では、どれだけ型が良くても紹介は来ません。責任者が週に数人に個別に頼む会社では、型が粗くても紹介が来て、担当者が紹介後を回すことで続きます。エラベルでは、リファラルの設計を担当する人に、最初の一週間で方針と明言の文面を会社と確認し、社員数人に理由を聞き取り、頼み方の一枚を作り、責任者に「今週三人に頼む」を合意してもらい、受付と最初の連絡と戻しの型を決めるところまでをお願いしています。ここまでできると、担当者は紹介の後を速く丁寧に回し、会社は責任者が頼むことと感謝と判定だけになります。

## まとめ

- リファラルは**「制度を作って案内する」ではなく、社員が紹介しない理由を聞き、責任者が頼み、紹介の後を戻す**ところから始める
- 手順は**方針と謝礼→聞き取り→頼み方の一枚と材料→責任者が個別に頼む→受付と最初の連絡と面談→戻し→不採用時の連絡→記録**の八つ
- 像は**「良い人」ではなく、社員の知り合いの範囲で具体に**
- 社員には**名前と連絡先だけ**。最初の連絡は人事が当日中に
- 戻しは**受け取った当日から結果まで一行ずつ**。感謝は責任者から
- 不採用時は**紹介された人に先に丁寧に、社員には結果と感謝だけ**

## よくある質問

### 紹介がゼロのまま数か月です。何から直せばよいですか

手順二の聞き取りから始めます。社員数人に一対一で「紹介しない理由」を聞くと、会社ごとの理由が分かります。「誰か分からない」なら一枚を、「何も戻らない」なら戻しを、「気まずい」なら最初の連絡を人事が持つ形を、の順で直します。同時に、責任者が個別に頼んでいるかを確かめます。頼んでいなければ、そこが最初です。

### 紹介された人が、明らかに要件に合わないときはどうしますか

要件に合わなくても、紹介された人には当日中に連絡し、カジュアル面談を入口にします。面談で「いまの募集とは合わないが、こういう募集が出たら」と伝え、関係を続けます。社員には「お話ししました。今回の募集とは合いませんでしたが、今後の募集で改めてご連絡します」と戻します。合わないことを社員のせいにしないことが、次の紹介につながります。

### 謝礼を出す場合、いくらが適切ですか

一つの額で決まるものではなく、会社の考え方と法令上の扱いで変わります。謝礼は動く主な理由ではないので、額の議論より、条件を明確にし（入社時か、一定期間の在籍後か）、前面に出さず、法令上の扱いを専門家に確認したうえで決めます。額を上げても紹介は増えにくく、「金目当てと思われたくない」と社員が引くこともあります。個別の判断は専門家にご確認ください。
