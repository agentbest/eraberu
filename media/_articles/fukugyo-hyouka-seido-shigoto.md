評価制度の設計を初めて受けるとき、見えにくいのは「シートを作る前に何を決め、作ったあとに何を回せば納得されるか」です。募集文には「評価制度の設計」とだけあり、実際には、何を評価するかの決定、いまの評価の実態、評価者と社員の声、観点の言葉、運用の設計、処遇との接続の判断、目線合わせ、面談の型、最初の期の伴走と、シートの前後に工程が並びます。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→実態の整理→観点と運用の設計→会社の決定と接続→目線合わせと導入→最初の評価の期間の伴走と見直し」の六つの段階で進み、契約前に範囲と処遇との接続の有無・何を評価するかを決める人・専門家の関与・聞き取り・声の扱い・個人の評価に入らないこと・終わりの定義を決め、いまの評価の決まり方と困りごとを整理し、観点を三〜五に絞って行動の言葉にして運用を設計し、会社が承認して処遇との接続は会社と専門家が決め、評価者の目線合わせと面談の型と社員への説明の支援を行い、最初の評価の期間を伴走して歪みを直す材料を出し、引き継いで終えます。**案件の型と人事制度との違いは[評価制度の設計の副業案件](/media/fukugyo-hyouka-seido-fukugyo/)に、処遇に結びつく設計の重さは[人事制度の設計の副業の実務](/media/fukugyo-jinji-seido-shigoto/)に書いていますので、ここでは「評価制度の1案件の流れ」に絞ります。

## 契約前：決めておくこと

評価制度は、「シート一枚」と軽く見られやすく、「賞与にも使いたい」で急に重くなります。契約前に、範囲の上限を決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲と処遇との接続の有無 | 観点と基準の言葉、運用、目線合わせと面談、伴走のどこまでか。評価の結果を昇給・賞与・昇格に結びつける設計を含むか（含むなら人事制度の設計の条件で） | 「賞与にも」で処遇の設計に踏み込む |
| 何を評価するかを決める人 | この会社で高く評価される人は何が違うかを、経営者が決めるか | 担当者が一般的な観点を並べる |
| 専門家の関与 | 処遇との接続を含む場合、社会保険労務士などが確かめる。費用は会社 | 労務の判断が抜ける。個別の判断は専門家にご確認ください |
| 評価者と社員の聞き取り | 経営者、評価者（管理職）、社員に、別々に聞く時間 | 経営者だけの観点になる |
| 声の扱い | 評価者と社員の声を、個人が特定されない「構造」として共有する | 話した社員が不利になる |
| 個人の評価に入らないこと | 「〇〇さんは何点か」を判断しない。目線合わせは架空の例で | 個人の評価に巻き込まれる |
| 評価面談の役割 | 面談は評価者が行う。担当者は型と練習と記録 | 担当者が面談に出る |
| 終わりの定義 | シートの納品か、最初の評価の期間の終わりか。評価の基準 | 納品で終わり、運用で歪む |

止まりやすいのは、「まずシートの案を見せてほしい」で始めるときです。何を評価するかが決まっていない案は、一般的なシートになり、その会社に合いません。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 実態の整理：いまの評価の決まり方、評価者の困りごと、社員の納得していないこと

制度が無い会社にも、評価は実態として行われています。まず、それを見ます。

| 聞く相手 | 聞くこと | 落とし穴 |
|---|---|---|
| 経営者 | 高く評価した人とそうでない人の違い。評価で見ているもの。評価の結果がいまどう使われているか（昇給、賞与、昇格、何も無い） | 「頑張っている人」で終わる。一段掘る |
| 評価者（管理職、別々に） | 評価で困ること。部下に説明できないこと。他の評価者との差を感じる場面。時間 | 一緒に聞いて本音が出ない |
| 社員（別々に、または匿名で） | 何が評価されていると感じるか。納得していないこと。理由を聞いたことがあるか | 個人が特定される形で共有する |
| 過去の評価の記録（個人が特定されない形で） | 分布、評価者ごとの傾向、理由の書かれ方 | 記録が無い。無いなら「無い」が実態 |

聞いたことは、「いまの評価の決まり方」「評価者の困りごと」「社員の納得していないこと」の三つに整理し、個人が特定されない形で会社に渡します。聞き方は[ヒアリングの技能](/media/fukugyo-hearing-skill/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「実態の整理で、経営者の『高く評価した人とそうでない人の違い』を一言にできるか」で、観点の質が決まります。経営者は「頑張っている人」「任せられる人」と言いますが、一段掘ると「自分で決めて進めた人」「他部署を巻き込んで合意した人」のように、行動の言葉が出ます。その言葉が観点の土台になり、一般的な観点（主体性、協調性）を並べるより、社員に「うちの会社らしい」と受け取られます。エラベルで担当者を選ぶ企業には、「最初に、経営者の方に『去年、高く評価した人とそうでない人の違い』を一段掘って伺います。観点はそこから作ります」と、私たちから先に伝えています。受ける側がその場で使える判断としては、実態の整理の記録に「経営者の一言」の欄を作り、掘れた言葉をそのまま残すこと。観点の言葉は、その欄から作ります。

## 観点と運用の設計：三〜五の観点、行動の言葉、誰がいつどう評価しどう伝えるか

実態の整理から、観点と運用を設計します。

| 作るもの | 中身 | 落とし穴 |
|---|---|---|
| 観点（三〜五） | 経営者の一言と、評価者と社員の声から、この会社で高く評価される行動を三〜五に絞る。役割で違えば分ける | 十個並べる。一般的な観点を写す |
| 行動の言葉 | 各観点を「〇〇した場面を具体的に語れる」の形に。高い状態と低い状態を場面で書く | 抽象語のまま |
| 見ない観点 | 評価しないと決めること（性格、私生活、評価者との相性など）。基準にしてはいけない項目は入れない | 見ない観点を決めず、何でも見る |
| 運用 | 誰が（一次、二次）、いつ（期の長さ、面談の時期）、どう評価し（自己評価の有無、証拠の集め方）、どう記録し（観点ごとの場面）、どう伝えるか（面談の型、理由の書き方） | 運用を決めずにシートだけ |
| 記録の型 | 観点ごとに「見た場面」と「判定」と「本人に伝える理由」の欄 | 点数だけの記録 |
| 「二人で同じ判定になるか」の試し | 架空の例で、評価者二人に観点ごとの判定をしてもらい、ずれた観点の言葉を直す | 試さずに導入する |

止まりやすいのは、観点が五つを超えることです。増えるほど評価者は迷い、面談で理由を言えなくなります。言葉の型は[面接の評価基準の言語化](/media/rpo-hyouka-kijun/)と共通です。

## 会社の決定と接続：観点と運用の承認、処遇との接続は会社と専門家

| 順 | やること | 落とし穴 |
|---|---|---|
| 一 | 観点と行動の言葉と見ない観点を、経営者が承認し、理由を書面に | 担当者の案のまま導入する |
| 二 | 運用（誰が、いつ、どう、どう伝えるか）を会社が決める | 決めずに評価の時期を迎える |
| 三 | 処遇との接続（範囲に含む場合）を会社が決め、専門家が就業規則と労務を確かめる | 接続を担当者が設計する。専門家を飛ばす |
| 四 | 決まった制度を会社の文書として確定する | 担当者の資料のまま |

止まりやすいのは、処遇との接続を「あとで決める」として導入し、最初の評価の結果が出てから賞与に結びつける話になるときです。接続は導入の前に決め、専門家が確かめます。個別の判断は専門家にご確認ください。

### エラベルの見解

同じ料金・同じ範囲でも、結果が分かれるのは、「導入の前に『二人で同じ判定になるか』を試すか」です。観点の言葉を作って、試さずに導入した担当者の制度は、最初の評価で評価者ごとに判定が割れ、面談で理由が言えず、社員が「評価者次第だ」と受け取ります。架空の例を一つ作り、評価者二人に観点ごとの判定をしてもらい、ずれた観点の言葉を直してから導入した担当者の制度は、最初の評価から判定がそろい、面談で「この場面をこう見た」と言えます。試しは、時間にして一時間で済みますが、その一時間を飛ばした制度は、最初の期で信頼を失います。エラベルで長く続いている担当者は、観点の言葉の横に「二人で同じ判定になったか」の印を付け、印の無い観点は導入しません。受ける側がその場で使える形としては、観点ごとに架空の「高い例」「低い例」を一つずつ書いて、評価者に判定してもらうことです。

## 目線合わせと導入：評価者の場、面談の型と練習、社員への説明の支援

決まった制度を、評価者と社員に届けます。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 評価者の目線合わせの場（同じ架空の例で、観点ごとの判定を話し合う。差が出た観点の言葉を直す） | 評価者の時間（三十分から一時間） | やらずに評価を始める |
| 評価面談の型（観点ごとに「見た場面」と「判定」と「次に期待すること」を伝える順。時間。本人の話を聞く時間） | 型の承認 | 型が無く、評価者が点数を読み上げる |
| 面談の練習（評価者同士で、架空の例で、型に沿って話す） | 評価者の時間 | 練習せずに本番 |
| 社員への説明の支援（何を評価するか、見ない観点、誰がいつどう評価するか、理由が伝わること。話すのは経営者と評価者） | 説明の場 | 担当者が説明する |
| 質問と不安の記録（説明で出た質問、個別の不安を、個人が特定されない形で） | 記録の共有先 | 記録せずに進む |

止まりやすいのは、目線合わせを「評価者が忙しいから」と飛ばすことです。目線合わせの無い評価は、甘辛が出て、社員の不満が評価者に向き、評価者が制度を嫌います。資料の作り方は[資料の作り方](/media/fukugyo-shiryou/)に書いています。

## 最初の評価の期間の伴走と見直し：分布、面談、反応、歪みを直す材料、引き継ぎ

制度は、最初の評価の期間で決まります。範囲に含めているなら、伴走します。

| 見ること | やること |
|---|---|
| 評価の分布（評価者ごと、観点ごと。個人名は出さない） | 評価者ごとの甘辛を、基準の言葉の問題として評価者に返す |
| 面談の実施（行われたか、型に沿ったか、理由が伝わったか） | 行われていない面談の理由を聞き、型を直す |
| 社員の反応（納得、疑問、不満。個人が特定されない形で） | 理由の伝え方と、観点の言葉を直す材料 |
| 判定に迷った観点 | 言葉を直す。「二人で同じ判定になるか」を再度試す |
| 経営者の例外（制度と違う判断） | 記録し、「制度に入れるか、例外のままか」を会社に決めてもらう |
| 見直しの材料（期の終わりに、観点、運用、目線合わせの型を直す案） | 決めるのは会社 |

終了時は、観点と行動の言葉（会社の文書）、見ない観点、運用の一覧、記録の型、面談の型、目線合わせの進行、伴走の記録（個人が特定されない形）、見直しの材料を残し、個人の評価の情報を自分の手元に一切残しません。引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 評価の情報の扱い

評価制度の設計では、過去の評価の記録、評価者の傾向、個人の評価、社員の不満を扱います。個人が特定される形で共有せず、分布や傾向は個人名を出さずに扱い、自分の端末に残さず、会社の外で話さず、他の依頼側や本業に持ち込みません。目線合わせは架空の例で行い、実在の社員を例にしません。基準にしてはいけない項目（性別、年齢、国籍、私生活など）が観点の候補に出ても入れず、そのことを会社に伝えます。処遇との接続に関わる判断は専門家に渡します。個別の判断は専門家にご確認ください。利益相反の見分け方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 稼働時間は何で決まるか

全体の時間は、「実態の整理（聞き取りの人数）」「観点と運用の設計（役割の数）」「試しと目線合わせ（評価者の人数）」「導入（説明の場の回数、面談の練習）」「伴走（最初の評価の期間の月数、評価者の人数）」の合計で決まり、会社の決定を待つ期間と、処遇との接続を含む場合の専門家の確認の期間は自分では縮められません。工程ごとに範囲と見積もりを分け、「決定待ちの期間は稼働に含めない」と決めておけば、見込みが立ちます。数値は案件ごとに違うので、実態の整理が終わった時点で以後の工程を見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→実態の整理→観点と運用の設計→会社の決定と接続→目線合わせと導入→最初の評価の期間の伴走と見直し**の六つの段階
- 契約前に**範囲と処遇との接続の有無・何を評価するかを決める人・専門家の関与・聞き取り・声の扱い・個人の評価に入らない・面談の役割・終わりの定義**を決める。接続を含むなら人事制度の設計の条件で
- 実態の整理は**経営者の「高く評価した人とそうでない人の違い」を一段掘り、評価者と社員に別々に聞き、構造として共有する**
- 設計は**観点を三〜五に絞り「〇〇した場面を語れる」の形に、見ない観点を決め、運用と記録の型を作り、「二人で同じ判定になるか」を架空の例で試す**
- 決定は**経営者が承認して書面に。処遇との接続は会社が決めて専門家が確かめる**。導入の前に
- 導入は**目線合わせの場・面談の型と練習・社員への説明は会社の人が話す**。目線合わせを飛ばさない
- 伴走は**分布・面談の実施・社員の反応・迷った観点・経営者の例外**を記録し、見直しの材料を出す。決めるのは会社
- 評価の情報は**個人が特定されない形で扱い、架空の例を使い、手元に残さず、外に持ち出さない**

## よくある質問

### 経営者が「高く評価した人とそうでない人の違い」を言えません

一段ずつ掘ります。「去年、昇給や賞与で差を付けた人はいますか」「その人は、他の人と何が違いましたか」「その違いが出た場面を一つ教えてください」。場面が出れば、行動の言葉になります。それでも出ないなら、評価者と社員の声から「この会社で評価されていると感じる行動」を集め、経営者に「これが御社の評価の実態です。この中で、これからも評価したいものはどれですか」と選んでもらいます。経営者が選ばない観点は、導入しても運用で守られません。

### 評価者から「架空の例では意味が無い。実際の部下で目線合わせしたい」と言われます

実在の社員を例にした目線合わせは、その社員の評価を評価者の間で話し合う形になり、本人の知らないところで評価が固まります。架空の例でも、観点ごとの判定の差は十分に出ます。「実際の部下の評価は、目線合わせで基準がそろってから、評価者ご自身が行ってください。ここでは基準の言葉をそろえるために、架空の例を使います」と返します。実在の例を使いたいという要望は、個人の評価に担当者が入る入口になるので、受けません。

### 最初の評価で、経営者が制度と違う評価を付けました

記録し、「制度に入れるべき観点が抜けていたのか、例外なのか」を会社に決めてもらいます。制度と違う評価が続くなら、観点が経営者の実態とずれていて、実態の整理が足りなかった可能性があります。経営者の判断を否定せず、「その評価の理由を、観点の言葉で言うとどうなりますか」と聞き、観点に足すか、例外として記録するかを決めてもらいます。例外が制度を上書きし続けるなら、見直しの材料として、期の終わりに会社に返します。
