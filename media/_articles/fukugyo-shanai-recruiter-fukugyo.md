本業で社内リクルーターとして、自社の候補者を直接探し、スカウトを送り、面談し、現場と一緒に選考を回してきた。この経験は、副業で最もそのまま使えるはずだが、本業と重なる部分が多く、どこまで売ってよいのか、本業との線が気になる。結論を先に書くと、**社内リクルーターの経験は、「自社で候補者を直接探し、口説き、選考を回してきた」型で、そのまま依頼側の直接採用の設計と運用に売れます。売れるのは、「スカウトの運用」「候補者との面談」「現場との連携」「採用管理の仕組みと数字の管理」の四つです。副業の依頼側の多くは、直接採用を始めたいが運用の型が無く、社内で回してきた人が求められています。ただし、本業の候補者、媒体のアカウント、社内の情報は持ち込まず、本業の会社と競合する依頼側は避けます。「社内でやってきたことを、社外で」と工程で売り、線は本業との利益相反で引きます。**スカウト代行の副業の実務は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に、本業との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、採用管理の仕組みは[ATSを扱えると何が変わるか](/media/fukugyo-ats-skill/)にまとめています。

## この経歴の何が売れるか

社内リクルーターの経験を、副業の工程に置き換えた棚卸しです。本業の情報を含まない「型」として抜き出します。

| 社内リクルーターの経験 | 副業の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| スカウト媒体を運用してきた | 依頼側の媒体で、検索の条件、送る相手の選び方、文面、送る時間帯、返信への対応の運用を設計し、回す | 媒体を契約したが返信が来ない依頼側が多い |
| 候補者と面談してきた | 返信後の面談で、候補者の関心を聞き出し、依頼側の魅力と結びつけ、選考に進む形にする | 面談が会社の説明で終わる依頼側が多い |
| 現場の面接官と連携してきた | 現場の要件の聞き取り、面接官向けの準備資料、面接後の振り返りの型 | 現場と人事の間で要件がずれている依頼側が多い |
| 採用管理の仕組みを運用してきた | 候補者の進捗、連絡、選考の記録を、仕組みの中で回す型 | 進捗が個人のメモにあり、担当者が変わると消える依頼側が多い |
| 数字で採用を管理してきた | 送信、返信、面談、選考、内定、入社の段階の数を追い、落ちているところを見る | 「応募が少ない」としか見えていない依頼側が多い |
| 求人票と募集の文面を直してきた | 求人票を候補者の目線で直す。媒体ごとの文面の型 | 求人票が社内の言葉で書かれている依頼側が多い |
| 経営層に採用の状況を報告してきた | 採用の状態を、依頼側の経営者に伝わる形で報告する型 | 報告が感覚で語られている依頼側が多い |

売れるものの要点は、「社内で回してきた運用が、そのまま依頼側の直接採用の運用になる」ことです。社内リクルーターの経験は、人事の副業の中で最も直接的に売れる経験で、置き換えの手間がほとんどありません。ただし、売れるのは「型」で、本業の候補者、媒体のアカウント、社内の要件と情報は、持ち込みません。型と情報を分けて棚卸しします。スカウトの運用は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に、面接官との連携は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に、数字の見せ方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 売りにくい点とその扱い

社内リクルーターの転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 本業との利益相反 | 「本業の会社と同じ候補者を取り合うのでは」「本業の候補者を回すのでは」。自分にとっても、本業の会社に知られたときの懸念 | 本業の会社と競合する依頼側、候補者の層が重なる依頼側を避ける。本業の候補者、媒体のアカウント、社内の情報を持ち込まない。副業の許可の条件を確認する |
| 自社の看板が無い状態 | 「本業では会社の名前で返信が来ていたのでは。うちの名前で返信が来るのか」 | 看板に頼らないスカウトの型（文面、相手の選び方、時間帯）を示す。依頼側の魅力を候補者の言葉に置き換える型を持つ |
| 本業の稼働との重なり | 「本業でもスカウトを送っていて、副業でも送るなら、本業の時間に副業をするのでは」 | 稼働の時間帯を分ける。本業の端末と媒体のアカウントを副業に使わない。副業の稼働は本業の時間外で、副業用の端末で |

扱い方の要点は、「本業との利益相反の線を、他の経歴より厳しく引く」ことです。社内リクルーターは、本業と副業の工程が同じなので、線が曖昧になりやすく、本業の会社から見て「自社の候補者と情報を外に持ち出している」と映る危険が最も高い経歴です。競合と候補者の層の重なりを避け、本業の候補者と媒体のアカウントと社内の情報を一切持ち込まず、本業の端末を使わず、副業の許可の条件を確認する。この線を守れば、社内リクルーターの経験は最も売りやすい経験になります。利益相反の見分け方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、端末の分け方は[私物端末で作業してよいか](/media/fukugyo-tanmatsu/)に、許可の申請は[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。

### エラベルの見解

担当する側から見ると、社内リクルーターから転身して続いている人と、途中で止まる人の差は、スカウトの腕ではなく、「本業との線を最初に引いているか」です。止まる人は、本業と同じ分野の依頼側を受け、本業の媒体の感覚で候補者を探し、本業の会社から「候補者を外に回している」と見られ、副業を止めることになっています。続いている人は、本業と分野も候補者の層も違う依頼側を選び、本業の情報を一切持ち込まず、副業の許可の条件の中で動き、本業の会社との関係も保っています。

見ていて差がつくのは、自社の看板が無い状態でも返信が来るスカウトの型を持っているかです。社内リクルーターの中には、会社の名前で返信が来ていたことに気づかず、副業の依頼側で同じ文面を送って返信が来ず、戸惑う人がいます。看板に頼らない型（相手の経歴を読み込んで一言を添える、依頼側の魅力を候補者の言葉に置き換える、送る時間帯を選ぶ）を持っている人は、依頼側の規模に関わらず返信を出し、依頼側から「うちの名前でも返信が来た」と評価されています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、社内で回してきた運用の型を明確にし、本業との線を示している担当者に、直接採用を始めたい依頼側がついています。社内リクルーターの転身は、腕ではなく、線と型で始まります。

## 案件の探し方

社内リクルーターから入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 直接採用を始めたい依頼側の、スカウトの運用の設計と実行 | 媒体の運用の経験でそのまま入れる | 「媒体を契約したが返信が来ない依頼側」を範囲の一言に。本業と分野が違う依頼側を選ぶ |
| 返信後の面談の設計と実施 | 面談の経験で入れる | 「面談で候補者の関心が高まらない依頼側」を範囲の一言に |
| 現場との連携の型 | 面接官と連携してきた経験で入れる | 「現場と人事の要件がずれている依頼側」を範囲の一言に |
| 採用管理の仕組みの運用の型 | 仕組みを運用してきた経験で入れる | 「進捗が個人のメモにある依頼側」に、仕組みの中で回す型を |
| 採用の数字の管理と報告 | 数字で管理してきた経験で入れる | 「段階の数で落ちているところを示す」を示す |
| 本業と分野が違う依頼側 | 利益相反を避ける | 登録先で、本業の会社と競合しない分野と規模の依頼側を選ぶ |

探し方の要点は、「本業と分野が違う依頼側を選ぶ」ことです。社内リクルーターの経験は、本業と同じ分野の依頼側で最も効きますが、そこは利益相反の危険が最も高い場所でもあります。分野が違っても、スカウトの運用、面談、現場との連携、仕組み、数字の型は同じように効きます。本業と分野も候補者の層も違う依頼側を選び、型で価値を出します。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、スカウト代行の最初の一件は[スカウト代行で副業を始めるには](/media/fukugyo-scout-daikou-hajimekata/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。社内リクルーターの転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 運用の経験の直接性 | 社内で回してきた運用がそのまま使え、依頼側にとって即戦力 | 「未経験の分野だから」と単価を下げない。運用の工程の単価で |
| スカウトの運用の形 | 送信数と返信の管理は、月額で受けやすい。文面の型は成果物で | 月額の運用と、成果物の設計を分ける |
| 面談の回数 | 候補者との面談は、回数で受けやすい | 一回あたりと、月の回数の上限を決める |
| 成果報酬の誘い | 「入社が決まったら」と誘われやすい | 判断は依頼側にあるので、最初は時間か月額で。実績ができてから検討 |
| 本業と分野が違うこと | 分野の知識が浅い分、候補者の見極めは依頼側に | 見極めを含まない範囲で、運用の単価 |
| 本業の副業の条件 | 本業の許可の条件に、報酬や競合の制限があることがある | 許可の条件を確認する |

単価の要点は、「運用の経験の直接性を、単価に反映させる」ことです。社内リクルーターの経験は、置き換えの手間が無く、依頼側にとって最初の月から動く即戦力です。「本業と分野が違うから」「副業だから」と単価を下げる必要はなく、運用の工程の単価で受けます。ただし、候補者の見極めは、分野が違う分、依頼側に置き、運用に徹します。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、成果報酬の考え方は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に、スカウト代行の案件の型は[スカウト代行の副業案件](/media/fukugyo-scout-daikou-fukugyo/)に整理しています。

## 始める順番

社内リクルーターから副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、副業の許可の条件（競合の制限、報酬の制限、情報の扱い）を確認する | 本業の会社の規則と、個別の判断は専門家に |
| 二、本業の会社と競合する分野、候補者の層が重なる分野を、避ける対象として書き出す | 利益相反の線 |
| 三、社内で回してきた運用を、本業の情報を含まない「型」で書き出す | 候補者、媒体のアカウント、社内の要件は含めない |
| 四、看板に頼らないスカウトの型を、自分の言葉で書く | 文面、相手の選び方、時間帯、依頼側の魅力の置き換え |
| 五、稼働の時間帯と端末を、本業と完全に分ける | 本業の時間外、副業用の端末、副業用の媒体のアカウント |
| 六、「社内でやってきたことを、社外で」の一言を作る | 工程で。本業の会社名は出さない |
| 七、登録先に、範囲と、避ける分野を登録する | 本業と分野が違う依頼側を選ぶ |
| 八、スカウトの運用か面談を一件、月額か回数で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「一」と「二」を、他の経歴より慎重にやることです。社内リクルーターの副業は、本業と工程が同じなので、本業の会社から見て利益相反と情報の持ち出しに映りやすく、許可の条件と競合の線を最初に確認しておかないと、副業だけでなく本業も危うくなります。確認し、線を引いてから、型を売ります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「社内リクルーターの経験は、そのまま副業に使えるから簡単だ」というものです。実際には、そのまま使えるからこそ、本業との線が曖昧になりやすく、本業の候補者や媒体や情報を持ち込む形になって、本業の会社との関係を壊す人がいます。簡単なのは型の置き換えで、難しいのは線の引き方です。線を引いた人だけが、最も売りやすい経験を、安全に売れています。

順番として、副業の許可の条件を確認し、競合と候補者の層の重なりを避ける対象として書き出し、社内の運用を本業の情報を含まない型で書き出し、看板に頼らないスカウトの型を書き、稼働の時間帯と端末を本業と分け、社内でやってきたことを社外で、の一言を作り、登録先に範囲と避ける分野を登録し、スカウトの運用か面談を一件受けて型を残す。この順番で、社内リクルーターの転身は、「本業と混ざる危ういもの」から「最も直接的に売れる経験」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、運用の型を明確にし、本業との線を示している担当者に、直接採用を始めたい依頼側がついています。社内リクルーターの転身は、腕ではなく、線と型で始まります。

## まとめ

- 社内リクルーターの経験は**「自社で候補者を直接探し、口説き、選考を回してきた」型**で、そのまま依頼側の直接採用の設計と運用に売れる。**スカウトの運用・面談・現場との連携・仕組みと数字の管理**の四つ
- 売れるのは**「型」で、本業の候補者・媒体のアカウント・社内の情報は持ち込まない**
- **本業との利益相反の線を、他の経歴より厳しく引く**。競合と候補者の層の重なりを避け、端末と時間帯を分け、許可の条件を確認
- **自社の看板が無くても返信が来るスカウトの型**を持つ。会社の名前で返信が来ていたことに気づく
- 案件は**本業と分野が違う依頼側**から。型は分野が違っても効く
- 単価は**運用の直接性を反映し、下げない**。運用は月額、設計は成果物、面談は回数で。成果報酬は実績ができてから

## よくある質問

### 本業で使っている媒体のアカウントで、副業の依頼側の候補者も探してよいですか

使いません。本業の会社が契約している媒体のアカウントは、本業の会社のものであり、副業に使うと、本業の会社の契約に反し、本業の会社の費用で副業をした形になります。副業の依頼側には、依頼側が契約する媒体のアカウントを使い、依頼側の契約の範囲で運用します。本業の媒体で見た候補者を副業の依頼側に回すことも、本業の情報の持ち出しになります。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に整理しています。

### 本業と同じ職種の採用を頼まれました。一番得意な分野ですが、受けてよいですか

本業の会社と競合するか、候補者の層が重なるかを確認します。同じ職種で、同じ経験年数の候補者を取り合う関係なら、本業の会社から見て「自社の候補者を競合に回している」形になり、副業の許可の前提が崩れます。職種が同じでも、地域や規模や事業が違い、候補者の層が重ならないなら、受けられることがあります。迷うなら受けない方が安全で、本業の会社の許可の担当に確認する方法もあります。得意な分野を捨てるのではなく、分野が違う依頼側で型を使います。見分け方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

### 社内では会社の名前で返信が来ていました。副業の依頼側の名前で返信が来るか不安です

社内リクルーターの多くが、最初にぶつかる壁です。会社の名前に頼らない型を、副業を始める前に作ります。相手の経歴を読み込んで一言を添える、依頼側の魅力（規模が小さいからこその裁量、事業の面白さ、働き方）を候補者の言葉に置き換える、送る時間帯と件名を選ぶ、返信が来なかった相手への二通目の型を持つ。これらは、社内でも本当は効いていたはずの型で、会社の名前に隠れて見えていなかっただけです。文面の型は[スカウト代行の副業の実務](/media/fukugyo-scout-daikou-shigoto/)に、文章の技能は[文章力をどう磨くか](/media/fukugyo-writing/)に整理しています。
