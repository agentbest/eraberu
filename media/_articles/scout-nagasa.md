スカウトの文面を、どのくらいの長さにすればよいか分からない。短くすると「薄い」「本気ではない」と見えそうで、長くすると「読まれない」と言われる。「何文字が適切か」を探しても、答えが見つからない。結論を先に書くと、**スカウトの文面の長さは、文字数では決まりません。「スマートフォンで一〜二画面に収まる」と「候補者の四つの判断（自分宛てか、興味があるか、この会社でよいか、返信するか）が終わる」の二つの基準で決めます。二つを満たす最短が、適切な長さです。長い文面は、書き手が「全部伝えたい」からで、候補者が「全部知りたい」からではありません**。本文の構成は[スカウト本文の構成](/media/scout-reibun-kouzou/)に、パーソナライズの範囲は[パーソナライズはどこまでやるべきか](/media/scout-personalize/)にまとめています。媒体ごとの文字数の上限や表示の仕組みは、公式の案内で確認します。

## 長さで迷う構造

文面の長さで迷うのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「何文字」で考えている | 文字数の正解を探している。文字数は、媒体と端末と内容で変わる |
| 「全部伝えたい」 | 会社、事業、役割、条件、福利厚生、選考。全部を入れて、長くなる |
| 「短いと薄い」と思っている | 短い文面を「手抜き」と感じ、長くして誠意を示そうとする |
| 候補者の読み方を想像していない | スマートフォンで、受信箱から開いて、数秒で判断する読み方を、想像していない |
| 段ごとの長さを決めていない | 四段の構成があっても、各段が長くなる |
| 削る基準が無い | 「どれも大事」で、削れない |
| 相手と段階で変えていない | 動いていない人への最初の一通と、返信の後の二通目が、同じ長さ |
| 試していない | 一つの長さで送り続け、比べていない |

構造の大半は、「文字数で考える」ことと「全部伝えたい」ことです。基準を変えれば、決まります。

## 長さを決める二つの基準

文面の長さは、二つの基準で決めます。

**基準一：スマートフォンで一〜二画面に収まる。** 候補者の多くは、スマートフォンで受信箱を見て、開いて、スクロールせずに、または一〜二回のスクロールで、判断します。三画面以上は、読み切られません。「一〜二画面」は、媒体の表示の仕組み（文字の大きさ、行間）で文字数が変わるので、自社のアカウントで実際に表示して確認します。

**基準二：候補者の四つの判断が終わる。** 「自分宛てか」「興味があるか」「この会社でよいか」「返信するか」。四つの判断に要る情報が入っていれば、足りています。入っていなければ、短くても薄いです。四つの判断は[スカウト本文の構成](/media/scout-reibun-kouzou/)の四段に対応します。

二つの基準の関係は、「基準二を満たす最短が、基準一に収まっているか」です。四つの判断に要る情報を入れて、一〜二画面に収まっていれば、適切な長さです。収まらなければ、四つの判断に要らない情報が入っています。

「短いと薄い」は、基準二を満たしていないときだけです。四つの判断に要る情報が入っていれば、短くても薄くありません。

## 四段ごとの長さの目安

四段の構成に沿った、段ごとの長さの目安です。文字数ではなく、文の数で。

| 段 | 内容 | 文の数の目安 | 長くなりやすい原因 |
|---|---|---|---|
| 一段落目 | なぜあなたに。経歴の具体的な部分と、役割との対応 | 二〜三文 | 経歴の複数の部分に触れる。褒め言葉を足す |
| 二段落目 | 何をする役割か。決める・誰と・どこまで・なぜ今 | 三〜四文 | 業務の箇条書きを入れる。役割の背景を長く説明する |
| 三段落目 | なぜこの会社か。段階・役割の位置・人・働き方の実態 | 二〜四文 | 会社の沿革、事業の全部、理念を入れる |
| 四段落目 | 次の一歩。話す場・返信のしやすさ・送り主・断りやすさ | 二〜三文 | 条件の詳細、選考の流れの全部、複数のリンク |
| 署名 | 送り主の名前と肩書と会社名 | 一〜二行 | 会社の説明を署名に入れる |

合計で、十〜十四文ほど。スマートフォンで一〜二画面に収まる範囲です。

目安の要点は、「一段落目は二〜三文で足りる」ことです。一段落目を長くすると、「自分宛て」が薄まります。相手の経歴の一つと、役割との対応の一文で、二〜三文です。

## 長くなる原因と削り方

文面が長くなる原因と、削り方です。

| 原因 | 削り方 |
|---|---|
| 会社の紹介を入れている | 三段落目に段階と理由だけ。沿革、事業の全部、理念は採用サイトへ（リンク一つ） |
| 業務の箇条書きを入れている | 二段落目に「決める・誰と・どこまで・なぜ今」を文で。箇条書きは求人票へ |
| 条件の詳細を入れている | 四段落目に幅で一文か、「面談でお話しします」。詳細は求人票か面談で |
| 福利厚生の一覧を入れている | 働き方の実態を一文。一覧は採用サイトへ |
| 選考の流れを全部入れている | 「まず話を聞く場」の案内だけ。流れは返信の後で |
| 褒め言葉を重ねている | 「素晴らしいご経歴」「ぜひ」を外す。経歴の具体的な部分に触れるだけで、褒めたことになる |
| 同じことを言い換えて繰り返している | 一つのことは一度だけ |
| 「弊社は」「貴殿の」のような硬い言葉 | 「私たちは」「あなたの」。または主語を省く |
| 複数のリンク | 一つまで |
| 「ご多忙のところ恐縮ですが」のような前置き | 外す。一段落目から本題 |

削り方の要点は、「四つの判断に要らないものを外す」ことです。要るかどうかは、「これが無いと、候補者は四つのどの判断ができないか」で確認します。どの判断にも要らなければ、外します。

削った情報は、消えるのではなく、「返信の後」「面談」「採用サイト」「求人票」に移ります。スカウトの文面は、返信をもらうためのもので、全部を伝えるためのものではありません。

### エラベルの見解

相談で最も多い失敗は、「スカウトの文面が三画面分あり、会社の沿革から福利厚生まで全部入っていて、返信率が低かった。『誠意を込めて長く書いた』つもりだった」というものです。候補者の側から見ると、「自分宛てか」が分かる前に、会社の話が延々と続き、閉じていました。四つの判断に要るものだけに削って一〜二画面にしたら、同じ役割で返信が増えました。長さは誠意ではなく、候補者の負担でした。

見ていて差がつくのは、担当者が「削る」提案をできるかどうかです。「もっと魅力を伝えましょう」と足す担当者と、「四つの判断に要らないものを外して、一〜二画面にしましょう。会社の説明はリンク一つに」と、削る担当者がいます。後者の文面は、読まれます。

発注側にできるのは、「全部伝えたい」を手放し、「四つの判断に要るものだけ」を許すことです。

## 短くなりすぎる原因と足し方

逆に、短すぎて薄い文面の原因と、足し方です。

| 原因 | 足し方 |
|---|---|
| 一段落目に、経歴の具体的な部分が無い | 「〇〇で△△を担当されたご経験」の一文を足す。「ご経歴を拝見して」だけは、無いのと同じ |
| 役割が職種名だけ | 「何を決める役割か」の一文を足す。「〇〇職」だけでは、興味の判断ができない |
| 「なぜ今」が無い | 「事業が〇〇の段階に来て、この役割が要る」の一文を足す |
| 一緒に働く人が見えない | 「〇〇と一緒に」の一文を足す。人が見えないと、会社の判断ができない |
| 次の一歩が「ご連絡ください」だけ | 「まず三十分、話を聞く場を設けられます。選考ではありません」を足す |
| 送り主が組織名 | 人の名前と肩書を足す |
| 断りやすさが無い | 「ご興味が無ければ返信は不要です」を足す |

足し方の要点は、「四つの判断のどれかが欠けている」ことを見つけて、その一文を足すことです。短い文面が薄いのは、文字数が少ないからではなく、判断に要る情報が欠けているからです。

「短いから薄い」と感じたときに、会社の説明や褒め言葉を足すと、長くなるだけで、薄さは直りません。欠けている判断の一文を足します。

## 相手と段階で変える長さ

長さは、相手と段階で変えます。一律ではありません。

| 相手・段階 | 長さの考え方 |
|---|---|
| 動いていない人への最初の一通 | 最も短く。一段落目と二段落目を中心に、一画面。「まず開いて、自分宛てと役割を知ってもらう」 |
| 動いている人（転職の意向がある）への最初の一通 | 四段を揃えて、一〜二画面。判断の材料が要る |
| 返信が来た後の二通目 | 相手の質問に答える形で、質問の数に応じて。会社の説明や条件は、ここで |
| 幹部や経営幹部の候補者 | 一段落目に経営の課題を。二〜三画面になることもあるが、「経営者の言葉」であることが前提。[幹部・役員クラスへのアプローチ](/media/scout-kanbu-scout/) |
| 未経験や隣の職種の相手 | 「隣の経験がどう活きるか」の説明が要るので、一段落目がやや長くなる。[未経験歓迎求人のスカウト](/media/scout-mikeiken-boshuu/) |
| 過去の応募者や退職者 | 前回の経緯に触れる一文が足されるので、やや長くなる。[過去の応募者への再アプローチ](/media/scout-kako-oubosha/) |
| 再送（一度返信が無かった相手への二度目） | 最初の一通より短く。「先日ご連絡した件、一言だけ」 |

変える要点は、「最初の一通は短く、返信の後で足す」ことです。最初の一通で全部を伝えようとするから、長くなります。返信が来れば、聞かれたことに答える形で、いくらでも伝えられます。

## 長さを試して直す運用

長さは、試して直します。

| 項目 | 運用 |
|---|---|
| 自社の文面の現状 | スマートフォンで表示し、何画面か、四つの判断が終わるかを確認 |
| 試す単位 | 週に一つの長さ（「一画面の短い版」「二画面の標準版」）。同じ役割、同じ層の相手に |
| 変えないもの | 長さを試す週は、件名と対象と一段落目の型を変えない |
| 記録 | 長さの版ごとに、送信数、開封数（取れれば）、返信数、返信の内容（質問が多いか、そのまま面談に進むか） |
| 判断 | 返信率が高い長さを続ける。「短い版で返信が来るが質問が多い」なら、質問の答えを二通目の型に |
| 相手と段階ごと | 動いていない人、動いている人、再送、で長さの版を分けて記録 |
| 媒体の仕様 | 文字数の上限、表示の仕組み（一段落目の冒頭が受信箱に出るか）は公式の案内で確認 |
| 見直しの頻度 | 月に一度、長さの版ごとの返信率を見て、標準の長さを決める |

運用の要点は、「二つの版を、週ごとに、同じ相手の層に」です。長さだけを変えて比べれば、適切な長さが自社の記録で分かります。一般の「何文字が良い」と比べません。

## 外注する場合の範囲

スカウト文面の長さの問題を、スカウト代行に出す場合の範囲です。

**出せる工程。** 現状の文面のスマートフォンでの表示の確認と画面数の把握、四つの判断が終わるかの点検、長くなる原因の特定と削る作業、短すぎる場合の欠けている判断の特定と一文の追加、四段ごとの長さの整理、相手と段階ごとの長さの版の作成（最初の一通、二通目、再送、幹部、未経験、過去の応募者）、長さの版を試す運用の設計と実行、記録と月次の見直し、媒体の仕様の確認。

**社内に残す判断。** 削る情報の承認（「会社の説明を外してよいか」）、役割の記述の確定、条件を書くかどうかの方針、送り主の名義、版の承認。

**外注の効きどころ。** 文面の長さは、書き手には「全部大事」に見え、削れません。外部の担当者は、候補者の目で「四つの判断に要らないもの」を見つけ、削れます。担当者は複数の会社のスカウトを見ているので、「この段のこの一文は要らない」「この相手にはこの長さ」の見立てを持ち込めます。ただし、削る情報の承認は社内です。

**外注しても動かない場合。** 社内が「会社の説明を全部入れてほしい」を譲らない、「短いと薄い」の印象を変えない、試す運用を認めない。社内の判断で、代行を替えても直りません。

長さは、二つの基準で決まり、試して直せます。外注は、候補者の目で削り、試す運用を回す手段です。

### エラベルの見解

担当する側から見ると、長さの相談で最も多いのは、「一段落目が長い」ことです。「素晴らしいご経歴を拝見し、感銘を受けました。〇〇のご経験、△△のご経験、□□のご実績、いずれも当社が求めるものです」。褒め言葉と、経歴の複数の部分に触れて、一段落目だけで一画面。候補者は、「自分宛て」を確認する前に、褒め言葉に疲れます。

一段落目は、経歴の一つと、役割との対応の一文。二〜三文。「〇〇で△△を担当されたご経験が、当社の□□を決める役割で活きると考え、ご連絡しました」。それで、「自分宛て」は伝わります。

発注側にできるのは、一段落目から褒め言葉を外し、経歴の一つに絞ることを、担当者に許すことです。

## よくある質問

### スカウトの文面は、何文字が適切ですか

文字数では決まりません。媒体の表示の仕組み、端末（スマートフォンかパソコンか）、内容で、同じ文字数でも見え方が違います。「スマートフォンで一〜二画面に収まる」と「候補者の四つの判断（自分宛てか、興味があるか、この会社でよいか、返信するか）が終わる」の二つの基準で決めます。自社のアカウントでスマートフォンに表示して、何画面かを確認します。文字数の上限は媒体の公式の案内で確認しますが、上限まで書く必要はありません。

### 短い文面だと、本気ではないと思われませんか

短さではなく、「自分宛ての一文が無い」ことが、本気ではないと見える原因です。「〇〇で△△を担当されたご経験が、□□を決める役割で活きると考えた」の一文があれば、短くても「この会社は自分を見て送っている」と伝わります。逆に、三画面の長い文面でも、一段落目が「ご経歴を拝見して」だけなら、一斉送信に見えます。本気は、長さではなく、相手の経歴の具体的な部分に触れているかで伝わります。

### 会社のことを、もっと伝えたいです

スカウトの文面は、返信をもらうためのもので、会社の全部を伝えるためのものではありません。三段落目に「会社の段階、この役割が要る理由、一緒に働く人、働き方の実態」を二〜四文で書き、詳しくは採用サイトへのリンク一つで。返信が来たら、二通目と面談で、聞かれたことに答える形で、いくらでも伝えられます。最初の一通に全部を入れると、読まれずに閉じられ、何も伝わりません。
