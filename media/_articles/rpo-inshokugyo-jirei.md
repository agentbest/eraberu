同じ採用代行を使っても、機能する飲食の会社と機能しない会社があります。差を作るのは代行の腕ではなく、発注側の条件です。当日中に返す窓口があるか、店長の枠が先に決まっているか、実態を求人票に書いているか、離職の理由を分けているか、型を分けているか、記録が社内にあるか、任せる工程が絞られているか。結論を先に書くと、**飲食業界で採用代行が機能するのは、速さ・枠・実態・離職・型・記録・工程の七つで「社内に残すものを残している」会社で、機能しないのは「返事は閉店後に店長が。飲食は辞めるもの。全部任せたい」会社です。**発注の前に七つで自社を確かめ、機能しない条件があれば、発注の前にそれを変えます。工程の切り分けは[飲食業界の採用代行](/media/rpo-inshokugyo-rpo/)に、課題の分解は[飲食業界の採用課題](/media/rpo-inshokugyo-kadai/)に、小売の条件は[小売業界で採用代行が機能する条件・機能しない条件](/media/rpo-kouri-jirei/)に書いています。ここでは、飲食業界の七つの対に絞ります。

## 七つの対

| 軸 | 機能する条件 | 機能しない条件 |
|---|---|---|
| 速さ | 応募への返事と面接の候補の提示を、店長の外の窓口が当日中に（営業中と閉店後の応募も） | 「返事は閉店後に店長が」 |
| 枠 | 店長の面接の枠を、アイドルの時間帯か営業の前後に週に二つ先に決め、応募者にその候補を出す | 「枠は応募者の希望で都度」 |
| 実態 | 本部の求人票の型に、営業時間・土日・繁忙・一緒に働く人・最初の一週間を店長が埋めている | 「実態は面接で」「アットホーム」だけ |
| 離職 | 退職の理由を「実態・受け入れ・店長との関係・条件」で分け、受け入れの一枚と実態を直している | 「飲食は辞めるもの」。辞めた分を採り続ける |
| 型 | 調理師（技能の実技）と店長候補（登用の道筋）は、ホールとキッチンの型と分けている | 全部を同じ媒体と速さの型で |
| 記録 | 一覧に「店舗」の列があり、店舗をまたいで社内の環境にある | 店舗ごとに別。代行の環境 |
| 工程 | 任せる工程が絞られ、残す工程（店長の見極め・技能の見極め・シフトと条件・受け入れ）の担当がいる | 「全部任せたい」 |

七つのうち一つでも機能しない条件にあると、代行はその部分で止まります。

## 速さ：当日中に返す窓口があるか

| 機能する | 機能しない |
|---|---|
| 営業中と閉店後の応募も、店長の外の窓口が当日中に返す | 店長が閉店後に見て翌日 |
| 返事と一緒に、先に決めた枠の候補を出す | 応募者の希望を聞いてから |
| 面接の結果を当日か翌日に。入店の日を面接で | 「後日連絡」 |

### エラベルの見解

飲食業界で最も多い機能しない条件は「枠」です。店長は「応募者の都合に合わせる」つもりで希望を聞き、その希望がアイドルの時間帯と合わず、調整の往復で数日が過ぎ、応募者は他の店で決まる。「応募者の都合に合わせる」より、「アイドルの時間帯に週に二つ、先に決めて候補として出す」ほうが、応募者にとっても早く決まって助かります。エラベルで担当者を選ぶ企業には、「店長の面接の枠は、週に何曜日の何時と決まっていますか」を、私たちから先に聞いています。決まっていなければ、代行の前に枠の設計です。枠の預かり方は[面接の日程調整の進め方](/media/rpo-task-nittei-chousei-susumekata/)に書いています。

## 枠：先に決まっているか

| 機能する | 機能しない |
|---|---|
| アイドルの時間帯か営業の前後に、週に二つ | 都度調整 |
| 埋まらない枠は前日に解放 | 枠が無い |
| 店舗ごとの枠を一覧に | 店長の頭の中 |

## 実態：求人票の型に店長が埋めているか

| 機能する | 機能しない |
|---|---|
| 本部が型（営業時間・土日・繁忙・シフトの単位・一緒に働く人・最初の一週間・まかないや休憩）を作り、店舗の実態を店長が埋める | 本部の求人票をそのまま全店舗で |
| 応募の減少を受け入れ、入店と定着で見る | 応募の数を成果にして隠す |
| 早期離職の理由を求人票の型に戻す | 「本人の事情」で片付ける |

実態の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 離職：理由を分けて直しているか

| 機能する | 機能しない |
|---|---|
| 退職の記録があり、理由を分類して数えている | 「一身上の都合」しか無い |
| 分類ごとに、実態・受け入れ（教える人、最初の一週間）・店長の接点を直している | 採用の入口だけを直す |
| 募集の回数が減っている | 同じ店舗で募集を繰り返す |

受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に、離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

### エラベルの見解

「全部任せたい」という飲食の会社は、多くの場合、店長が営業と採用と受け入れを一人で抱え、本部は出店と数字で手一杯で、採用を見る人がいない状態です。その状態で全部を任せると、シフトも見極めも受け入れも代行に寄り、代行にはできないので止まります。エラベルは担当者を工程ごとに選べる形にしているので、「店舗の一次対応と日程と記録」を担当者が担い、店長は「面接の三十分と最初の一週間の受け入れ」に、本部は「求人票の型・観点の一枚・計画・条件」に絞る、という組み方ができます。店長の負担が減ると、受け入れの時間ができ、離職が減り、募集が減ります。工程の切り分けは[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)や[求人媒体の運用は代行に出せるか](/media/rpo-task-baitai-unyou-daikou/)に書いています。

## 型：分けているか

| 機能する | 機能しない |
|---|---|
| 調理師は紹介と掲載型で「〇〇の型の店で〇〇を担った経験」に絞り、技能は実技で | ホールと同じ媒体と文面 |
| 店長候補は掲載型とスカウトで「〇〇の規模のチームと売上を担った経験」に絞り、登用の道筋が一枚にある | 「店長候補募集」だけ |
| 型ごとに応募の数を記録 | 全部を一つの数で |

調理師の要件の作り方は[調理師の採用要件の作り方](/media/rpo-chourishi-youken/)に書いています。

## 記録：店舗をまたいで社内にあるか

| 機能する | 機能しない |
|---|---|
| 一覧に「店舗」「型」の列があり、応募から返事までの時間と面接に来た数も記録 | 店舗ごとに別。代行の環境 |
| 週次の一枚で、店舗ごとの数と止まりが本部に届く | 月末の報告だけ |
| 契約が終わっても、記録と型（求人票の型、観点の一枚、枠の一覧、受け入れの一枚）が社内に残る | 契約が終わると消える |

記録の扱いは[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。

## 工程：絞られているか

| 機能する | 機能しない |
|---|---|
| 「店舗の一次対応と日程と記録」「調理師の紹介の母集団形成」のように、型と工程で任せる範囲が明確 | 「採用を全部」 |
| 残す工程（店長の見極め・技能の見極め・シフトと条件・受け入れ・登用・合否）の担当が決まっている | 残す工程の担当がいない |
| 一つの店舗・一つの工程で三か月回し、記録で効いたかを見てから広げる | 最初から全店舗・全工程 |

## 機能しない条件を変える順番

| 順 | 変えること | 費用 |
|---|---|---|
| 一 | 速さ：当日中に返す窓口を店長の外に | かからない（本部で）か、代行の一工程 |
| 二 | 枠：アイドルの時間帯か営業の前後に週に二つ | かからない |
| 三 | 実態：求人票の型を作り、店長が埋める | 本部の時間 |
| 四 | 記録：店舗の列のある一覧を社内の環境に | かからない |
| 五 | 工程：任せる工程を一つに絞る（一次対応から） | 契約の範囲が小さくなる |
| 六 | 離職：退職の記録を集め、受け入れの一枚 | 教える人の時間 |
| 七 | 型：調理師と店長候補を分ける | かからない |

一から五は発注の前に社内で変えられます。六は教える人の時間、七は本部の判断です。

## 機能しているかを見る記録

| 見ること | 機能している目印 |
|---|---|
| 応募から返事までの時間、面接に来た数 | 当日中になり、来た数が増えていれば速さと枠が機能 |
| 早期離職の理由 | 「働き方」「シフト」が減っていれば実態が機能 |
| 募集の回数 | 減っていれば離職が機能 |
| 型ごとの応募の数 | 調理師と店長候補が増えていれば型が機能 |
| 週次の一枚が届いているか | 届いていれば記録が機能 |

件数のまま並べ、前の募集と比べます。割合や外部の平均で断定しません。見る指標は[採用代行との定例会で見るべき数字](/media/rpo-teirei/)に書いています。

## まとめ

- 代行が機能するかは**代行の腕より発注側の条件**で決まる
- 七つの対は**速さ・枠・実態・離職・型・記録・工程**
- 最も多い機能しない条件は**枠**。「応募者の都合に合わせる」より「アイドルの時間帯に週に二つ先に決めて候補を出す」
- **「全部任せたい」は機能しない**。店長は面接と受け入れに、本部は型と観点と計画と条件に絞る
- 変える順番は**速さ→枠→実態→記録→工程→離職→型**。一〜五は発注前に社内で
- 店長の負担が減ると**受け入れの時間ができ、離職が減り、募集が減る**

## よくある質問

### 個人経営の店で、本部がありません。求人票の型は誰が作りますか

代行の担当者が型を作り、店長が実態を埋める形にします。型の項目（営業時間・土日・繁忙・シフトの単位・一緒に働く人・最初の一週間・まかないや休憩）は店の規模に関係なく同じで、埋めるのは店長の三十分です。本部が無い店ほど、返事と日程を外に出す効果が大きく、店長は面接と受け入れに集中できます。判断は店長で、代行は「同じ工程で比べる軸」をそろえるまでです。

### 調理師に実技をしてもらう時間が営業と重なります

実技は営業の前（仕込みの時間帯）に、料理長と三十分で組みます。仕込みの一部を一緒にやる形なら、営業の負担になりません。実技の内容と観点（衛生・段取り・味の再現・指示の受け方）は料理長が決め、代行は日程の調整と候補者への案内までです。書類と面接だけで採った調理師が現場で合わないと、営業に直接響くので、実技の三十分は省きません。

### 繁忙期の前に一気に採る形を、毎年繰り返しています

繁忙期の時期は毎年決まっているので、店舗ごとの採用の一枚に「時期・人数・募集の開始」を置き、応募から入店までの日数から逆算して、数か月前に募集を始めます。前年の繁忙期の短期の人への再度の声かけ（本人の同意と会社の決まりの範囲で）も経路になります。同意の取り方と記録の扱いは専門家の確認に従います。計画のつなぎ方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。
