営業の求人票の必須要件には、「法人営業の経験三年以上」「営業成績の上位」「同業界での経験」「新規開拓の経験」「マネジメントの経験」が並びがちです。書きやすい代わりに、どれも自社の営業の型で再現できるかを示しません。「法人営業」は相手も売り方も単価も幅が広く、「成績の上位」は型が違えば再現されず、「同業界」は商材の知識であって営業の力ではありません。結論を先に書くと、**営業の採用要件は、先に自社の営業の型（相手・売り方・単価と期間・任せる段階）を決め、必須を「入社初日に自社の型で営業が成り立つか」で三つ以内に絞り、成績・業界・年数・マネジメントは必須にせず、型の経験（誰に、何を、どう、どの段階を）で書く**と、自社で再現できる人の母集団が生まれます。型を決めずに要件を書くと、「営業経験者」の広い母集団から、面接で合う人を探す作業になります。母集団形成は[営業の母集団形成](/media/rpo-sales-boshuudan/)に、代行に出す工程の線は[営業採用を代行に出す判断基準](/media/rpo-sales-rpo/)にまとめています。

## 営業で要件が膨らむ理由

他の職種と共通する理由（現場の希望を全部書く、前任者を基準にする、失敗を避けたい）に加えて、営業に特有の理由があります。

一つ目は、「営業経験」が広すぎることです。法人か個人か、新規か既存か、単価と期間、段階。この組み合わせで別の仕事なのに、「法人営業の経験」の一言で括ると、自社の型と違う経験も含まれます。

二つ目は、成績を必須にすることです。「上位の成績」「目標達成率」は、前職の型と環境（見込みを誰が作ったか、商材の売りやすさ、目標の水準）で決まり、自社の型で再現されるとは限りません。

三つ目は、業界の経験を必須にすることです。同業界の経験は、商材の知識と人脈の面で立ち上がりを早くしますが、営業の型が違えば再現されません。逆に、隣接する業界で同じ型の営業をしてきた人は、商材を覚えれば再現されます。業界を必須にすると、後者を弾きます。

四つ目は、「新規も既存も」「見込みの創出から契約まで」と、段階を全部求めることです。自社が見込みを作る体制なら、見込みの創出の経験は初日には要りません。

五つ目は、年数とマネジメントです。年数と売る力は一致せず、マネジメントは個人として売る募集なら要りません。

## 必須と歓迎を分ける基準

基準は「入社初日に、自社の型で営業が成り立つか」です。営業では「自社の型で」を先に決めます。相手・売り方・単価と期間・任せる段階の四つ。

| 項目の例 | 必須になる場合 | 歓迎になる場合 |
|---|---|---|
| 相手の経験（法人か個人か、規模、誰と話すか） | 自社の相手と同じ相手に売った経験 | 近い相手（規模が違う、話す相手が違う）は歓迎 |
| 売り方の経験（新規か既存か、電話か訪問か紹介か） | 自社の売り方と同じ売り方の経験 | 近い売り方は歓迎 |
| 単価と期間の経験 | 自社と近い単価と期間で売った経験 | 大きく違う単価と期間は歓迎にとどめ、面接で確認 |
| 段階の経験 | 自社が任せる段階を担った経験（見込みの創出からなら、その経験） | 自社が任せない段階は歓迎 |
| 商材の知識（業界の経験） | 商材の知識が無いと初日から話せない場合 | 商材は入社後に覚えられるなら歓迎 |
| 見込みの創出の経験 | 営業が見込みを作る体制 | 自社が見込みを作る体制なら歓迎 |
| 成績 | — | 必須にしない。「自社と同じ型で目標を達成した経験」を歓迎に |
| 経験年数 | — | 必須にしない |
| マネジメントの経験 | リードとして採る募集 | 個人として売る募集なら不要 |
| 資格（業界による） | 法令で資格が要る商材 | それ以外は歓迎 |

基準の要点は、「成績と業界を必須にしない」ことです。成績は型が違えば再現されず、業界は商材の知識で入社後に覚えられます。必須は、自社の型と同じ型で売った経験です。

### エラベルの見解

相談で多いのは、「同業界で成績上位の法人営業の経験者」というご要望です。この要件で来る人は、同業の競合にいる人で、競業避止や情報の扱いの問題があり、条件も高い。しかも、同業界で成績が良くても、自社の型（見込みの創出から任せる、単価が違う、相手の規模が違う）と違えば、再現されません。業界と成績で絞ると、狭くて、しかも合わないことがある要件になります。

見ていて差がつくのは、「自社の営業の型から、必須を逆算しているか」です。「中小企業の経営者に、新規で、〇〇の幅の単価を、見込みの創出から契約まで」なら、必須は「中小企業の経営者に売った経験」「新規で見込みの創出から担った経験」「近い単価と期間で売った経験」の三つ。業界も成績も年数も、歓迎か不要です。エラベルでは、営業の要件を整理するとき、依頼側に営業の型の一文を先に決めていただき、そこから必須を逆算しています。

## 必須を三つに絞る手順

営業向けに、絞る手順を番号付きで整理します。

1. **自社の営業の型を一文にする。** 相手・売り方・単価と期間・任せる段階。
2. **見込みを誰が作るかを決める。** 自社（マーケティング、既存の顧客、紹介）か、営業本人か。
3. **現場（営業の責任者、経営者）の希望を全部書き出す。** ここでは絞らない。
4. **一つずつ、「初日に自社の型で営業が成り立つか」を問う。** 成り立たないものだけ残す。
5. **残ったものが三つを超えたら、「入社後に覚えられるか」「自社が補えるか」を問う。** 商材の知識、ツール、見込みの創出（自社が作るなら）は歓迎へ。
6. **成績・業界・年数・マネジメントを、型の経験に書き換える。** 「成績上位」ではなく「〇〇に〇〇を新規で提案し、見込みの創出から契約まで担った経験」。
7. **歓迎に回したものを、優先順位を付けて三〜五つ書く。** 面接で見る点になる。
8. **目標と評価の設計を、要件と一緒に確認する。** 要件に合う人が、自社の目標と評価で続けられるか。[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)
9. **営業の責任者・経営者・人事で確認する。** 「この三つがあれば、他は入社後に補える」と言えるか。

手順の要点は、「八で、目標と評価を要件と一緒に見る」ことです。営業は、要件に合う人を採っても、目標と評価が合わないと辞めます。要件と目標は、同時に設計します。

## 経歴で確かめられる要件と、面接でしか分からない要件

営業では、経歴の数字と肩書が実態を表さないので、確かめ方の区別がとくに重要です。

| 確かめる方法 | 要件の例 | 見方 |
|---|---|---|
| 経歴で確かめられる | 売った相手の種類と規模、売り方、単価と期間の目安、担った段階、商材の種類 | 書類の一次絞りで。「法人営業」ではなく、「誰に、何を、どう、どの段階を」の記述があるかを見る |
| 経歴では分からない | 商談の進め方、断られたときの対応、見込みの作り方、目標への向き合い方、報告の仕方、数字の裏の型 | 面接で、営業の責任者が聞く。「一番大きな案件を、最初の接触から契約まで順に話してください」。[構造化面接](/media/rpo-kouzou-mensetsu/) |
| 経歴でも面接でも分かりにくい | 実際の商談の質、顧客との関係の作り方 | 商談のロールプレイ（自社の商材を題材に、短く）や、営業の責任者との同行の試行 |

分け方の要点は、「面接で、一つの案件を最初から最後まで話してもらう」ことです。「成績上位」の裏に、どんな型があったか（見込みは誰が作ったか、商談は何回か、決め手は何か、失注はどう対応したか）が、一つの案件の話で見えます。

## 隣接する型からの転向層を入れる要件の書き方

営業は経験者の母数が多いので、自社の型と完全に同じ人だけでなく、隣接する型からの転向層を入れる書き方が、母集団の質を上げます。

| 転向元 | 持っているもの | 要件の書き方 |
|---|---|---|
| 隣接する業界の同じ型の営業 | 相手・売り方・単価・段階が同じ。商材が違う | 「〇〇（相手）に〇〇（売り方）で売った経験」。業界は歓迎に。商材は入社後 |
| 同じ相手に、違う単価で売ってきた営業 | 相手と売り方が同じ。単価と期間が違う | 相手と売り方を必須に。単価は面接で「期間の長さに耐えられるか」を確認 |
| 既存の深耕から新規へ移りたい営業 | 相手と商材の理解。新規の経験が浅い | 新規を任せる募集なら、新規の経験を必須に。既存から新規は面接で動機を確認 |
| 個人向けから法人向けへ移りたい営業 | 売る力の基礎。相手が違う | 法人の募集なら、法人の経験を必須にするか、法人の相手に近い経験（個人事業主など）を歓迎に |
| 営業以外からの転向（カスタマーサクセス、販売、コンサル） | 顧客との対話、提案の経験 | 自社が教える体制があるなら、「顧客に提案して合意を得た経験」を必須に。営業の型は入社後 |

書き方の要点は、「相手と売り方が同じなら、業界と単価が違っても転向層に入れる」ことです。営業の型の四つのうち、相手と売り方が最も再現性を決め、業界と単価は入社後に調整できることが多い。

## 要件が決まらないときの原因

| 原因 | 起きていること | 直し方 |
|---|---|---|
| 営業の型が一文になっていない | 「営業ができる人」 | 相手・売り方・単価と期間・段階を一文に |
| 見込みを誰が作るかが決まっていない | 「新規開拓もお願いしたい」 | 自社が作るか、営業が作るかを決める |
| 成績と業界で書いている | 書きやすい | 型の経験に書き換える |
| 前任者を基準にしている | 「前の人はこうだった」 | 前任者が入社時に持っていたものと、社内で身に付けたものを分ける。前任者が辞めた理由も見る |
| 目標と評価が決まっていない | 要件だけ議論している | 目標と評価を先に。要件に合う人が続けられる設計か |
| 営業の責任者が要件の議論にいない | 人事と経営だけで決めている | 営業の責任者を入れる。いなければ経営者が自分の型を言語化 |
| 市場の実態を知らない | 「この要件で普通にいるはず」 | 代行や媒体に、その要件での人数を聞く |

原因の要点は、「営業の型が一文になっていない」ことが最も多い点です。一文になれば、必須は逆算でき、転向層の範囲も決まります。

## 代行に出せる工程

| 工程 | 社内で持つ | 代行に出せる |
|---|---|---|
| 営業の型の決定 | 判断 | 一文にする打ち合わせの進行 |
| 見込みを誰が作るかの決定 | 判断 | 問いを立てる |
| 必須と歓迎の分離 | 「初日に成り立つか」の判断は社内 | 問いを立て、一つずつ確認する進行 |
| 成績・業界・年数の書き換え | 中身は社内が出す | 型の経験の言葉に直す |
| 転向層を入れる要件の設計 | 判断 | 隣接する型からの書き方の提案 |
| 目標と評価の確認 | 経営と営業の責任者が決める | 要件との整合の確認 |
| 市場の実態の確認 | 判断 | その要件での人数を示す |
| 求人票への反映 | 確認 | 書く |
| 書類の一次絞り | 売る力の妥当性 | 型の分類。「誰に、何を、どう、どの段階を」の記述の有無 |
| 面接で見る点の整理 | 営業の責任者が使う | 歓迎の要件と、「一つの案件を最初から最後まで」の質問の案 |

分け方の要点は、「営業の型と目標・評価は、社内でしか決められない」ことです。代行は、決める打ち合わせの進行と、決まったものの言語化、型での一次絞りを担えます。営業は応募が多いので、型での一次絞りを代行に出す効果が大きい。

### エラベルの見解

担当する側から見ると、営業の要件で最も時間がかかるのは、依頼側が「成績」と「業界」を手放すことです。安心のために積んだこの二つが、自社の型と合わない人を探す原因になっている、と分かるまでに時間がかかります。営業の型を一文にして、そこから逆算すると、必須は「同じ相手に、同じ売り方で、近い段階を担った経験」に落ち着き、成績と業界は歓迎になります。

エラベルでは、営業の案件で要件が整理されていない場合、担当者の最初の仕事を「営業の型を一文にする打ち合わせの進行」にすることをお勧めしています。型が決まると、求人票の一行目が書け、一次絞りの基準ができ、応募が多い営業の採用で、社内が面接に集中できる状態になります。型を決めずに「営業経験者」の応募を集めると、書類確認で社内が疲れます。

## まとめ

- 営業の必須要件は、**先に自社の営業の型（相手・売り方・単価と期間・任せる段階）を決め、「入社初日に自社の型で営業が成り立つか」で三つ以内**に
- 要件が膨らむ理由は**「営業経験」が広すぎる・成績を必須にする・業界を必須にする・段階を全部求める・年数とマネジメントで書く**
- **成績・業界・年数・マネジメントは必須にしない**。型の経験（誰に、何を、どう、どの段階を）で書く
- 絞る手順は**型を一文に→見込みを誰が作るか→全部書き出す→初日に成り立つか→覚えられるか・補えるか→型の経験に書き換え→歓迎に優先順位→目標と評価を一緒に確認→三者で確認**
- **面接では一つの案件を最初から最後まで話してもらう**。数字の裏の型が見える
- **相手と売り方が同じなら、業界と単価が違っても転向層に入れる**
- 決まらない原因の多くは**営業の型が一文になっていない**こと

## よくある質問

### 「成績上位」を必須にしないと、売れない人を採ってしまいませんか

「成績上位」は、前職の型と環境（見込みを誰が作ったか、商材、目標の水準）で決まる数字で、自社の型で再現されるかを示しません。型が違えば、成績上位でも自社では売れないことがあり、型が同じなら、成績が中位でも自社で売れることがあります。必須は「自社と同じ型で売った経験」にし、成績は「同じ型で目標を達成した経験」として歓迎に置きます。売れるかどうかは、面接で一つの案件を最初から最後まで話してもらい、営業の責任者が数字の裏の型を確かめることで、成績の数字より正確に分かります。

### 同業界の経験者でないと、商材の説明ができないのでは

商材の知識は、入社後に覚えられることがほとんどです。営業の型（相手・売り方・単価と期間・段階）が同じなら、商材が違っても、営業の進め方は再現されます。同業界に限ると、母集団が狭く、競合からの採用になり、競業避止や情報の扱いの問題も出ます。隣接する業界で同じ型の営業をしてきた人を対象に含め、商材の知識は入社後の受け入れで補います。商材の知識が無いと初日から話せない（専門性が極めて高い、法令で資格が要る）場合だけ、業界や資格を必須にします。

### 未経験を採って自社で育てたいのですが、要件はどう書けばよいですか

自社に教える体制（誰が、最初の三か月に何を教え、同行するか）があることが前提です。体制が無いと、未経験は定着しません。要件は、営業の型の経験ではなく、「顧客に提案して合意を得た経験」（販売、カスタマーサクセス、コンサルティングなど）や、「目標に向けて行動を続けた経験」を必須にし、営業の型は入社後に教える、と書きます。受け入れの体制を求人票に具体的に書くと、未経験の候補者は「育ててもらえる」と判断します。[未経験の採用](/media/rpo-mikeiken-saiyo/)を参照してください。
