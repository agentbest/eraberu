案件の終わりに「引き継ぎ資料を作ってください」と言われ、これまでやったことの履歴を時系列で書いて渡すと、翌日に動く人は「で、いま何が動いていて、私は何をすればよいのか」が分からず、担当者に連絡してきます。引き継ぎ資料は、過去の記録ではなく、翌日に動く人が困らないための一枚です。結論を先に書くと、**引き継ぎ資料は、型（使っている様式と基準）・状態（いま動いている候補者と案件の段階）・未完了（止まっていることと期限と判断待ち）・連絡先（依頼側の窓口と外部の窓口）の四つを一枚にし、状態は候補者リストとATSの一覧をそのまま使って書き写さず、未完了は「誰が・いつまでに・何を」で、担当者の手元の情報は消して「消した」と書き、判断の所在を残し、引き継ぎの相手が読んで一度回せるかで確かめます。**引き継ぎの考え方の全体は[引き継ぎ資料の残し方](/media/fukugyo-hikitsugi/)に、いつ辞めても困らない状態は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に、会社側から見た項目は[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。ここでは、一枚を作る型に絞ります。

## 履歴を渡しても翌日に困る理由

| 履歴の形 | 翌日に動く人に起きること |
|---|---|
| 時系列の作業の一覧 | 読む時間が無い。「いま」が分からない |
| 担当者の考えや感想 | 判断の根拠は分かっても、次の一歩が分からない |
| 候補者の情報を書き写した一覧 | ATSやリストと二重になり、どちらが正か分からない |
| 未完了が「〇〇を調整中」 | 誰が、いつまでに、何を、が無く、止まる |
| 連絡先が無い | 紹介会社や媒体の担当者に連絡できない |
| 担当者の手元の情報がどうなったか不明 | 個人情報が残っているか分からず、依頼側が不安になる |

翌日に動く人が知りたいのは、「型はどこにあるか」「いま何が動いているか」「何が止まっているか」「誰に連絡するか」の四つです。

## 四つの部

| 部 | 中身 | 形 |
|---|---|---|
| 型 | 使っている様式（候補者リスト、評価シート、依頼書、文面の型、報告の一枚）と基準の一行。置き場所 | 一覧と、置き場所へのリンク。中身は写さない |
| 状態 | いま動いている候補者と案件の段階。候補者リストとATSの一覧が正 | 「一覧を最終更新日の古い順に見る」の一行と、一覧の場所。書き写さない |
| 未完了 | 止まっていること。判断待ち。期限 | 「誰が・いつまでに・何を」の表 |
| 連絡先 | 依頼側の窓口（人事、現場の責任者、決める人）。外部の窓口（紹介会社、媒体、専門家）。担当者への連絡の可否と期間 | 表。個人の連絡先は依頼側の決まりで |

四つで一枚です。マニュアル（[マニュアルを作る](/media/fukugyo-skill-manual/)）があれば、「型」の部はマニュアルへのリンクで足ります。

### エラベルの見解

担当する側から見ると、引き継ぎで最も差がつくのは、「状態を書き写さない」を守れるかです。受ける側は、丁寧にしようとして、いま動いている候補者の一覧を引き継ぎ資料に書き写します。すると、翌日に候補者の段階が動いた瞬間に、引き継ぎ資料と一覧がずれ、翌日に動く人はどちらを信じるか迷います。「状態は一覧が正。引き継ぎ資料には、一覧の場所と見方だけを書く」。これで、引き継ぎ資料は古くならず、一覧が更新され続けます。エラベルで担当者を選ぶ企業には、「引き継ぎ資料に、候補者の状態が書き写されていませんか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、「状態」の部に候補者の番号を一つでも書きたくなったら、その候補者について書くべきことは「未完了」の部に「誰が・いつまでに・何を」として書き、状態は一覧に任せること。

## 未完了の書き方

| 列 | 中身 | 例の形 |
|---|---|---|
| 何が止まっているか | 一行。候補者は番号で | 「番号〇〇の日程が未確定」「依頼書の版の更新が未送付」 |
| 誰が | 次に動く人。依頼側の誰か | 「人事の〇〇」 |
| いつまでに | 期限。候補者が待っている場合は候補者への約束の日 | 「〇日までに」 |
| 判断待ちなら、誰の判断か | 決める人 | 「条件の提示は経営者の判断待ち」 |
| 放置したら何が起きるか | 一行 | 「候補者が他社に流れる」「紹介会社の推薦が止まる」 |

未完了は、多くて十行。多いなら、引き継ぎの前に減らします。「放置したら何が起きるか」があると、翌日に動く人が優先を付けられます。

## 担当者の手元の情報を消して「消した」と書く

| 手元にあったもの | 扱い | 引き継ぎ資料に書くこと |
|---|---|---|
| 候補者リストや記録の写し | 依頼側の環境が正であることを確かめてから消す | 「手元の写しは〇日に消した」 |
| 文面の下書き | 型として依頼側の場所に置いたものを正とし、手元を消す | 同上 |
| アカウント | 依頼側が停止。担当者は停止を確認 | 「アカウントは〇日に依頼側が停止」 |
| 聞き取りのメモ（個人の事情を含む） | 一枚に傾向だけを残し、メモは消す | 「聞き取りのメモは消した。傾向は〇〇の一枚に」 |
| 持ち出せるもの | 型の考え方（構造）だけ | — |

「消した」と書くことで、依頼側は個人情報が残っていない安心を持て、担当者は後で「持っているのでは」と疑われずに済みます。扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[アカウント管理のしかた](/media/fukugyo-account-kanri/)に書いています。

## 判断の所在を残す

| 残すこと | 中身 |
|---|---|
| 会社が決めたこと | 要件の必須、条件の幅、優先順位、媒体の選定。「〇日に〇〇が決めた」 |
| 担当者が決めてよかったこと | 優先度、文面の一段落目、日程の候補。「担当者の範囲」 |
| 保留になっていること | 決まっていない判断。誰が決めるか |
| 専門家に確認した（する）こと | 確認の窓口と、確認済みか未確認か |

判断の所在が無いと、翌日に動く人が「前の担当者が決めたのか、会社が決めたのか」で迷い、決まっていたことを決め直します。判断の履歴は、依頼側の記録（PROGRESSやレポートの一枚）にあれば、そこへのリンクで足ります。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「引き継ぎ資料は、案件の終わりに作るもの」というものです。実際には、四つのうち「型」と「連絡先」は案件の最初に、「状態」は一覧の運用として、「未完了」は週次の報告として、案件の途中で既にあるべきものです。終わりに作るのは、それらを一枚にまとめ、手元の情報を消して「消した」と書くことだけです。最初から四つが依頼側の場所にあれば、担当者が急に続けられなくなっても、依頼側は翌日に動けます。受ける側がその場で使える判断としては、案件の最初の週に、四つの部の空の一枚を依頼側の場所に置き、週次の報告の「止まっていること」を「未完了」の部に書く形にすること。

## 引き継ぎの相手が読んで一度回せるか

| 確かめ方 | 中身 |
|---|---|
| 相手に一枚だけを渡す | 口頭の説明をせずに、一枚を読んでもらう |
| 「明日、最初に何をしますか」を聞く | 未完了の一行目が言えれば、回る |
| 詰まった箇所を直す | 「型はどこ」「一覧はどこ」「誰に聞く」で詰まったら、その部を直す |
| 口頭の説明は最後に | 一枚で回らない部分だけを口頭で補い、補った内容を一枚に足す |

口頭の説明から始めると、説明した内容が一枚に無く、相手が忘れた時点で止まります。一枚で回る状態を作ってから、口頭で補います。

## 急に続けられなくなったときの最小の一枚

本業の都合で、引き継ぎの時間が取れないことがあります。そのときの最小の一枚は、「未完了（誰が・いつまでに・何を）」と「連絡先」と「手元の情報を消したこと」の三つです。型と状態は、依頼側の場所に既にあれば省けます。最小の一枚を、案件の最初から「もしもの一枚」として依頼側の場所に置いておくと、急な終わりでも依頼側が困りません。続けられなくなる前の準備は[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 履歴を書いてしまった | 四つの部に振り分け、履歴は依頼側の記録へのリンクに |
| 状態を書き写した | 消して、一覧の場所と見方に |
| 未完了が「調整中」で終わっている | 「誰が・いつまでに・何を」と「放置したら」を足す |
| 手元の情報が残っている | 依頼側の環境が正であることを確かめて消し、「消した」と書く |
| 判断の所在が無い | 会社が決めたこと、担当者の範囲、保留を分けて書く |
| 相手が読んで動けない | 「明日、最初に何をしますか」で詰まった部を直す |

## まとめ

- 履歴を渡しても翌日に困る。**型・状態・未完了・連絡先**の四つを一枚に
- **状態は書き写さない**。候補者リストとATSの一覧が正。場所と見方だけ
- 未完了は**「誰が・いつまでに・何を」と「放置したら何が起きるか」**。十行まで
- 手元の情報は**消して「消した」と書く**。持ち出せるのは構造だけ
- **判断の所在**（会社が決めたこと・担当者の範囲・保留・専門家の確認）を残す
- 相手が**一枚だけで「明日、最初に何をするか」を言えるか**で確かめる
- 四つは**案件の最初から**依頼側の場所に。急な終わりの最小の一枚も先に置く

## よくある質問

### 依頼側から「引き継ぎのために、しばらく連絡できる状態でいてほしい」と言われました

期間と範囲を決めて、契約に書きます。「一か月、週に一度、一枚に無いことの質問に答える」のような形です。期間と範囲が無いと、無償の対応が続きます。連絡の可否と期間は、引き継ぎ資料の「連絡先」の部に書きます。連絡が来ないように、一枚を「相手が読んで回る」状態にしておくことが先です。契約の形は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

### 後任が決まっておらず、誰に引き継げばよいか分かりません

依頼側の人事の窓口に、四つの一枚を渡します。後任が決まっていなくても、一枚が依頼側の場所にあれば、誰が引き継いでも回ります。「引き継ぎの相手が読んで回るか」の確かめは、人事の窓口の人に「明日、最初に何をしますか」を聞く形で行います。後任が決まったら、依頼側から一枚を渡してもらえば足ります。

### 引き継ぎ資料に、依頼側の課題や改善の提案を書いてよいですか

四つの一枚とは別の一枚にします。「未完了」に混ぜると、翌日に動く人が「やらなければならないこと」と「提案」を区別できません。提案は、「直す場所を一つ」に絞った一枚（[提案のまとめ方](/media/fukugyo-teian/)）として、依頼側が判断する材料に留めます。引き継ぎの一枚は、翌日に回るためのものだけにします。
