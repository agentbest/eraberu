人材開発や研修の担当として、新人研修や管理職研修を設計し、講師を手配し、教材を作り、研修の後に何が変わったかを追ってきた。この経験は、人事の副業、とくに採用まわりの副業で売れるのか。研修の担当は採用の担当と部門が分かれていることが多く、採用の実務からは離れて見えます。結論を先に書くと、**研修担当の経験は、「人が何をできるようになるべきかを分解し、教える順番を設計し、できたかを確かめてきた」型で売れます。売れるのは、「面接官の育成」「受け入れ研修の設計」「要件を『できること』で書き直す作業」「採用担当者の立ち上げ」の四つです。人事の部門が小さい会社では、面接官が面接のやり方を教わっておらず、新しく入った人に何を教えるかが決まっておらず、要件が「経験何年」で書かれていて、初めての採用担当者が何から手を付ければよいか分かっていません。どれも「できるようになる仕組み」がない詰まりで、研修担当の経験がそのまま効きます。「研修をしていました」ではなく、「採用に関わる人が判断できるようになる仕組みを作る」と売ります。**組織開発の経験の売り方は[組織開発担当が副業でできること](/media/fukugyo-soshiki-kaihatsu-fukugyo/)に、HRBPの経験は[HRBPが副業でできること](/media/fukugyo-hrbp-fukugyo/)に、人事マネージャーの経験は[人事マネージャー経験を活かす](/media/fukugyo-manager/)にまとめています。

## この経歴の何が売れるか

研修担当の経験を、依頼側の採用の工程に置き換えた棚卸しです。関わった会社の研修の内容は含めず、「型」として抜き出します。

| 研修担当の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 「何ができるようになるべきか」を分解して目標にしてきた | 要件を「経験何年」ではなく「入社後に何ができる人か」で書き直す | 要件が経歴の条件だけで、何を見ればよいか分からない依頼側が多い |
| 教える順番と教材を設計してきた | 面接官が何をどの順番で聞き、何で判断するかの手引きを作る | 面接官が自己流で、判断がばらつく依頼側が多い |
| 講師として人の前で教えてきた | 面接官の短い勉強会を設計し、進行する | 面接官に教える人がいない依頼側が多い |
| 研修の後に「できたか」を確かめてきた | 面接の記録の型を作り、判断の根拠を残し、後から振り返る | 面接の結果が「良かった」「なんとなく」で終わる依頼側が多い |
| 新人研修で、入社直後の人が何につまずくかを見てきた | 受け入れ研修（最初の一か月に、誰が、何を、どの順番で教えるか）を設計する | 入った人が放置され、早く辞める依頼側が多い |
| 管理職研修で、管理職が部下をどう見ているかを知ってきた | 面接官としての管理職の見方の癖を知り、手引きに反映する | 管理職の面接が「気が合うか」になっている依頼側が多い |
| 外部の講師や教材を選び、成果を評価してきた | 採用の外注先や媒体の提案を、「何ができるようになるか」で評価する | 提案を比べる軸がない依頼側が多い |

売れるものの要点は、「採用に関わる人が判断できるようになる仕組みを、教えるのではなく設計できる」ことです。採用の担当者は、面接官に「こう見てください」と口頭で伝えますが、それで面接官の判断が揃うことは少なく、揃えるには手引きと記録の型と短い勉強会と振り返りの設計が要ります。研修担当は、人が何かをできるようになる過程を設計してきており、その型を面接官と受け入れと採用担当者に当てはめられます。聞き取りの型は[ヒアリングで押さえる項目](/media/fukugyo-hearing/)に、改善を回す型は[改善を回す](/media/fukugyo-kaizen/)に書いています。

## 売りにくい点とその扱い

研修担当の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念と自分の懸念 | 扱い方 |
|---|---|---|
| 採用の実務が薄い | 「募集やスカウトや候補者対応はできるのか」。自分にとっても、採用の現場を知らない不安 | 募集から候補者対応までの実務は範囲に入れないか、別の担当者と組む。売るのは「面接官と受け入れと要件の仕組み」だと最初に分ける |
| 研修の言葉が通じない | 「研修」と言うと、依頼側は「集めて話を聞かせる時間」を想像し、「そんな時間はない」と引く | 研修と言わない。「面接官の手引き」「面接の記録の型」「最初の一か月の教える順番」と、成果物の名前で語る |
| 成果が遅い | 面接官が育ち、入った人が定着するまでには時間がかかり、時間単価で見せると評価が遅れる | 途中の成果（手引きができた、記録の型が回った、受け入れの担当が決まった）を報告で見せる形にする |

扱い方の要点は、「研修という言葉を捨て、成果物の名前で語る」ことです。人事の部門が小さい会社の経営者にとって、研修は「時間を取られるもの」で、価値より負担が先に立ちます。「面接官が使う一枚の手引き」「面接の後に書く記録の型」「新しく入った人の最初の一か月の手順」と成果物で示せば、同じものが「すぐ使える道具」に変わります。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に整理しています。

### エラベルの見解

担当する側から見ると、研修担当から転身して続いている人と、面談で止まる人の差は、成果物を先に見せるか、研修の計画を先に語るかです。止まる人は、「面接官研修を設計します」と言い、依頼側は「面接官を集める時間がない」と引きます。続いている人は、面接官の手引きの見本を一枚持っていき、「これを御社の要件で作り直し、面接官には十分で説明します」と言います。依頼側は、集める時間ではなく、一枚の道具と短い説明で判断が揃う形を見て、頼めると感じます。

見ていて差がつくのは、面接の記録の型を、面接官が書きたくなる形にしているかです。研修担当の経験がある人は、記録の項目を丁寧に作りがちで、項目が多いと面接官は書かなくなります。「見た点を三つ」「迷った点を一つ」「合否と理由を一行」と、書く量を面接の直後に数分で済む形にした人は、記録が回り、面接官の判断のずれが記録から見えるようになり、依頼側から「初めて面接を振り返れた」と評価されています。エラベルでは、依頼側が担当者の経歴を見て選ぶ仕組みなので、「採用に関わる人が判断できるようになる仕組みを作る」と成果物の言葉で書いている担当者に、面接官の判断がばらついて困っている依頼側がついています。研修担当の転身は、研修の計画ではなく、一枚の手引きから始まります。

## 案件の探し方

研修担当から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 面接官の手引きと記録の型づくり | 教える順番と教材の設計の経験でそのまま入れる | 「面接官によって合否が変わる依頼側」を探す |
| 面接官の短い勉強会の設計と進行 | 講師の経験で入れる | 「面接官に教える人がいない依頼側」を探す |
| 受け入れ研修（最初の一か月）の設計 | 新人研修の経験で入れる | 「入った人が放置されて早く辞める依頼側」を探す |
| 要件を「できること」で書き直す | 目標を分解してきた経験で入れる | 「要件が『経験何年』だけの依頼側」を探す |
| 初めての採用担当者の立ち上げ | 人を育てる設計の経験で入れる | 「初めて採用担当を置いた依頼側」を探す |
| 採用の外注先や媒体の提案の評価軸づくり | 外部の講師や教材を評価してきた経験で入れる | 「提案を比べる軸がない依頼側」を探す |

探し方の要点は、「面接官の判断がばらつく会社」から入ることです。募集がうまくいかない会社では、研修担当の経験は募集の技術に負けます。応募は来ていて、面接に進んでいて、面接官によって合否が変わる、面接の後に何を見たか説明できない、という会社では、募集の技術では解決できず、研修担当の「判断できるようになる仕組み」が唯一の打ち手になります。案件の相談で「面接官がバラバラで」という言葉が出たら、それが入り口です。案件の探し方は[副業案件の探し方](/media/fukugyo-anken-sagashi/)に、合わない案件の見分け方は[合わない案件の見分け方](/media/fukugyo-awanai-anken/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。研修担当の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 成果物の作りやすさ | 手引き、記録の型、受け入れの手順は成果物として形が明確 | 一式の成果物で受ける |
| 勉強会の設計と進行 | 回数で受けやすい | 一回あたりの時間と回数で決める |
| 成果が出るまでの期間 | 面接官が育ち、入った人が定着するまでは時間がかかる | 中期の契約で受け、途中の成果を報告で見せる |
| 採用の実務を含まないこと | 含まない範囲は月額が下がるが、責任の線が明確 | 得意な工程で単価を出す |
| 研修の言葉での見積もり | 「研修一回いくら」で出すと、依頼側は集める時間の負担で判断する | 成果物と短い説明の形で示す |
| 仕組みが残ること | 手引きと記録の型は、担当者が離れても依頼側に残る | 残るものの価値を説明し、更新の根拠は「次の仕組み」で作る |
| 成果報酬の扱い | 面接の判断や定着は面接官と管理職の動きに左右され、責任の線が引きにくい | 時間か回数か成果物で。可否は専門家に確認 |

単価の要点は、「成果物一式と勉強会の回数で受け、途中の成果を報告で見せる」ことです。研修担当の工程は、成果物が明確なので、時間単価より成果物で受けるほうが依頼側に伝わります。ただ、手引きと記録の型は一度作ると依頼側に残るので、作って終わりになると契約が続きません。「面接官の手引き」の次に「受け入れの手順」、その次に「採用担当者の立ち上げ」と、次の仕組みを提案する形で更新の根拠を作ります。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、数字に出ない成果の見せ方は[成果が数字に出ない業務の見せ方](/media/fukugyo-seika-mienai/)に、成果報酬は[成果報酬型は受けるべきか](/media/fukugyo-seika/)に整理しています。

## 始める順番

研修担当から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業の会社の副業の規定と、関わった研修の教材や内容の守秘と著作の条件を確認する | 前の会社の教材は持ち出さない。個別の判断は専門家に |
| 二、「人が何かをできるようになる過程をどう設計してきたか」を、会社の情報を含まない型として書き出す | 分解、順番、確かめ方 |
| 三、研修の言葉を、採用の成果物の名前に置き換える | 「面接官研修」→「面接官の手引きと十分の説明」、「オンボーディング研修」→「最初の一か月の教える順番」 |
| 四、得意な工程（面接官・受け入れ・要件・採用担当者の立ち上げ）と、薄い工程（募集・スカウト・候補者対応）を分ける | 正直に示す準備 |
| 五、範囲を、面接官の手引きと記録の型、勉強会、受け入れの手順、要件の書き直し、採用担当者の立ち上げに絞る | 採用の実務は最初は範囲外か、別の担当者と組む |
| 六、「採用に関わる人が判断できるようになる仕組みを作る」の一言を作る | 「研修をしていました」で終わらせない |
| 七、面接官の手引きの見本を、架空の要件で一枚作る | 面談で見せる道具 |
| 八、登録先に、範囲と、成果物の形と、採用の実務を含まないことを登録する | 面接官がバラバラな依頼側 |
| 九、面接官の手引きか受け入れの手順を一件受け、記録の型が回った形を残す | 次の仕組みに広げる材料に |

順番の要点は、「七」の見本を一枚作ることです。研修担当の経験は、口で説明すると「研修の人」に聞こえますが、一枚の手引きを見せれば「すぐ使える道具を作れる人」に変わります。架空の要件で、「この面接で見る点を三つ」「それぞれの聞き方」「良い答えと弱い答えの例」「記録に書くこと」を一枚にまとめておけば、面談でも登録先でもそのまま使えます。前の会社の教材は使わず、自分の型で新しく作ります。プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に、初案件の備えは[初案件で不安になりやすい点と備え方](/media/fukugyo-hatsu-anken-fuan/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「研修の担当は、採用の副業には向いていない」というものです。実際には、採用の詰まりの多くは、面接官が判断のしかたを教わっていないこと、入った人に何を教えるかが決まっていないこと、要件が「できること」で書かれていないことから来ていて、どれも「できるようになる仕組み」の不在です。募集の技術を持つ担当者は、この詰まりを直せません。研修担当の経験は、この三つに直接効きます。向いていないように見えるのは、研修の言葉で語っているからで、成果物の名前で語れば、採用の担当者には作れない道具を作れる人になります。

順番として、本業の規定と教材の守秘と著作の条件を専門家に確認し、できるようになる過程の設計の型を会社の情報を含まずに書き出し、研修の言葉を成果物の名前に置き換え、得意な工程と薄い工程を分け、範囲を面接官と受け入れと要件と採用担当者の立ち上げに絞り、判断できるようになる仕組みを作る一言を作り、手引きの見本を一枚作り、登録先に範囲と形を登録し、一件受けて記録の型が回った形を残す。この順番で、研修担当の経験は「採用に向いていないもの」から「面接官と受け入れの仕組みを作る形」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、成果物の形を明確にし、採用の実務を含まないことを示している担当者に、面接官がバラバラで困っている依頼側がついています。研修担当の転身は、研修の計画ではなく、一枚の手引きから始まります。

## まとめ

- 研修担当の経験は**「人が何をできるようになるべきかを分解し、教える順番を設計し、できたかを確かめてきた」型**で売れる。**面接官の育成・受け入れ研修の設計・要件の書き直し・採用担当者の立ち上げ**の四つ
- **「研修をしていました」ではなく「採用に関わる人が判断できるようになる仕組みを作る」**と売る
- 売りにくい点は**採用の実務が薄い・研修の言葉が通じない・成果が遅い**。研修と言わず成果物の名前で語り、実務は範囲外と示し、途中の成果を報告で見せる
- 案件は**面接官の判断がばらつく会社**から。「面接官がバラバラで」という言葉が入り口
- 単価は**成果物一式と勉強会の回数**で。仕組みは依頼側に残るので、次の仕組みで更新の根拠を作る。成果報酬は最初は避け、可否は専門家に確認
- 面談では研修の計画ではなく、**手引きの見本を一枚**見せる

## よくある質問

### 前の会社で作った面接官研修の教材を、副業で使ってよいですか

使いません。会社の業務で作った教材は、一般に会社のものと整理されることが多く、持ち出して使うと守秘と著作の線に問題が出ます。型（分解、順番、確かめ方）は自分の経験として使えますが、教材そのものは新しく作ります。前の会社との契約の条件と、個別の判断は、弁護士や社会保険労務士にご確認ください。情報の分け方は[案件ごとの情報の分け方](/media/fukugyo-jouhou-bunri/)に、利益相反の見方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。

### 面接官の勉強会を提案したら、「面接官を集める時間がない」と言われました

集めない形に変えます。手引きを一枚作り、面接官一人ひとりに十分で説明する形にすれば、集める時間は要りません。記録の型を回し、記録から見えた判断のずれを、次の面接の前に一言で伝える形にすれば、勉強会の代わりになります。研修担当の経験は「集めて教える」形に寄りがちですが、人事の部門が小さい会社では「集めずに揃える」設計のほうが回ります。範囲外の依頼への対応は[範囲外の依頼が増えたとき](/media/fukugyo-scope-creep/)に、改善の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に書いています。

### 募集やスカウトの実務ができないと、案件が取れないのではないですか

採用の実務が薄いことは隠さず、「募集は御社の担当者か別の担当者が、私は面接官と受け入れと要件の仕組みを担います」と分担を示します。募集の実務が得意な担当者と組む形も、エラベルのような登録先では可能なことがあります。面接官の判断がばらつく依頼側や、入った人が早く辞める依頼側には、募集の実務より仕組みの設計が求められており、そこでは実務の薄さは弱みになりません。分担の型は[複数人で案件を受ける](/media/fukugyo-kyoudou-anken/)に、経営者との付き合い方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に整理しています。
