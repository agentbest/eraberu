経理にスカウトを送っても返信が来ない会社の文面には、共通点があります。「経理担当を募集しています」「安定した環境で長く働けます」「経験を活かしてください」と書かれていて、どの水準（記帳まで、月次まで、決算まで）を、どの規模（一人か、チームか）で、税理士とどう分担し、引き継ぎはどうなっていて、繁忙期はどう働くのかが無い。経理の候補者はこれを読んで、「実態が分からない」「一人経理で引き継ぎが無いかもしれない」と判断し、閉じます。結論を先に書くと、**経理へのスカウトは、水準と規模で対象を絞り、一行目で候補者が担った水準と規模の一点に触れ、自社の水準・規模と体制・分担・引き継ぎの状態・繁忙の周期と働き方を先に書き、会社の紹介は後ろに回す**型にすると、返信が変わります。母集団形成の全体は[経理の母集団形成](/media/rpo-keiri-boshuudan/)に、代行に出す工程の線は[経理採用を代行に出す判断基準](/media/rpo-keiri-rpo/)にまとめています。

## 経理がスカウトを読まない理由

他の職種と共通する理由（定型文は読まれない）に加えて、経理に特有の理由があります。

一つ目は、水準と規模が分からないと判断できないことです。経理の候補者は、自分が担ってきた水準（記帳まで、月次まで、決算まで）と規模（一人か、チームか）で、自社で回せるかを判断します。「経理担当」だけでは、判断できません。

二つ目は、引き継ぎの状態を最初に確かめることです。経理の経験者は、「前任者が急に辞めて、何も分からない状態から一人で」という会社の負担を知っています。引き継ぎの状態が書かれていないと、「無いのだろう」と最悪を想定します。

三つ目は、繁忙期と働き方を見ることです。月次の締め、決算、申告の時期の残業、リモートの可否、紙の書類の扱い。書かれていないと、「聞いたら厳しい実態が出るだろう」と読まれます。

四つ目は、「安定」「長く働ける」といった言葉に、実態の無さを感じることです。経理向けのスカウトは、この種の言葉で埋まっていることが多く、経験者は読み飛ばします。

この四つから、文面の型が決まります。水準と規模を示す、引き継ぎの状態を書く、繁忙期と働き方を書く、「安定」を使わない。

## 先に決めるのは対象：水準と規模で絞る

文面の前に、誰に送るかを決めます。経理では、「水準」と「規模」の決定が対象の絞り込みの中心です。

水準で絞ります。一人経理で月次まで締めてほしいなら、「一人で月次を締めた」「決算の準備を税理士と分担した」経験。年次の決算や開示まで担ってほしいなら、「決算を締めた」「開示の資料を作った」経験。「経理」の肩書だけで検索すると、記帳だけの人も開示の担当者も混ざります。

規模で絞ります。一人経理なら、一人で全部を回した経験。チームの一員なら、分担の中で特定の業務を深く担った経験。大企業の一部を担った人に一人経理のスカウトを送っても、「全体を回したことが無い」と読まれます。

分担で絞ります。記帳を外部に出している会社なら、「外部と分担しながら社内の管理を回した」経験。社内で全部やる会社なら、「記帳から決算の準備まで」の経験。

対象には、会計事務所からの転向層を含めます。複数の会社の記帳と決算を見てきた人は、一人で全部を回す力があり、「一つの会社の経理を深く持ちたい」動機で事業会社に移ります。[スカウトの対象の絞り方](/media/scout-persona-sakusei/)も参考になります。

### エラベルの見解

相談で多いのは、「経理に数十通送ったが、返信が来ない」というご相談です。文面を見ると、一行目が「経理担当を募集しております」、二行目が「安定した環境で長く働いていただけます」、水準も規模も引き継ぎも無い。経理の候補者から見ると、実態が分からず、最悪を想定する材料しかありません。「安定」は、実態を書けない会社の合図として読まれています。

見ていて差がつくのは、「一行目で候補者の水準と規模に触れ、二行目で自社の実態を正直に言えるか」です。「一人経理として記帳から月次の締めまでを担い、年次を税理士と分担されてきたご経歴を拝見しました。当社も同じ体制で、前任者の退職により引き継ぎは一部のみ、業務の整理から一緒に進めていただける方を探しています」。この二行で、候補者は「自分の経験に合う」「実態を隠していない」と判断します。エラベルでは、経理の担当者に、文面の中心を「水準・規模・引き継ぎの状態」にするよう最初にお願いしています。

## 文面の型：一行目は候補者の水準と規模、二行目は自社の実態

| 順 | 中身 | 書き方 |
|---|---|---|
| 一 候補者の経歴の一点 | 担った水準と規模、税理士との分担の経験、立て直しの経験のどれか一つ | 「一人経理として記帳から月次の締めまでを担い、年次を税理士と分担されてきたご経歴を拝見しました」 |
| 二 自社の水準と規模と体制 | どこまでを社内で、一人かチームか、上司は誰か、相談相手は | 「当社も一人経理で、記帳から月次の締めまでを社内で。経営者が上司で、税理士が月に一度来ます」 |
| 三 税理士や外部との分担 | 記帳、決算、申告の分担 | 「記帳と月次は社内、年次の決算と申告は税理士と一緒に」 |
| 四 引き継ぎの状態 | 前任者から引き継げるか、資料はあるか、止まっている業務は。正直に | 「前任者は退職済みで、引き継ぎ資料は一部のみ。税理士と一緒に業務を整理し直すところから」 |
| 五 繁忙の周期と働き方 | 月次・年次・申告の時期の残業の実態、リモート、紙かデータか | 「月末の数日と決算期は残業があります。リモートは週の半分。請求書はデータで受け取る形に移行中」 |
| 六 会計の仕組み | 会計ソフト、経費や請求の仕組み | 具体的に |
| 七 経営との距離 | 数字を経営に説明する機会があるか | 「月次の数字を経営者と一緒に見ます」 |
| 八 会社の紹介 | 事業と規模を短く | 三行以内 |
| 九 次の一歩 | 経理の分かる人（税理士でも）と上司が出る短い面談 | 「顧問の税理士と経営者と一緒に、いまの経理の状態をお見せしながら三十分ほど」 |

型の要点は、「四の引き継ぎの状態と五の働き方を、会社の紹介より前に書く」ことです。経理の候補者は、会社の事業より、自社の実態で判断します。隠さずに書いた文面は、それだけで「正直な会社」として読まれます。

## 刺さる訴求と、外す訴求

| 刺さる訴求 | 外す訴求 |
|---|---|
| 水準と規模の具体（一人経理で月次まで、チームで決算まで） | 「経理業務全般」 |
| 税理士との分担の具体 | 「税理士と連携」だけ |
| 引き継ぎの状態の正直な記述（無いなら無いと、整理から） | 引き継ぎの状態を書かない |
| 繁忙期の残業の実態と、リモートや紙かデータかの具体 | 「安定した環境」「長く働ける」 |
| 相談相手がいること（税理士が月に一度、経営者が数字を一緒に見る） | 「一人で任せます」だけ |
| 一つの会社の数字を全部見られること（会計事務所からの転向層に） | 「幅広い業務」 |
| 経営に数字を説明する機会があること | 「経営に近い」だけ |
| 業務を整理し直す裁量（立て直しの場合） | 立て直しの状態を隠す |
| 会計の仕組みの具体と、データ化の方針 | 「最新のシステム」 |
| 決算を締めた経験を活かせる、または決算まで経験を広げられること | 「スキルアップできる」 |

訴求の要点は、「引き継ぎの状態と繁忙期の実態を隠さない」ことです。隠すと、返信の総数は増えるかもしれませんが、面談後の辞退か入社後の離職が増えます。正直に書くと、返信は減っても、その状態で回せる人だけが来ます。

## 送った後の運用

返信が来たあとの運用で、経理に特有の注意を整理します。

一つ目は、面談に経理の分かる人が出ることです。社内に経理の責任者がいなければ、顧問の税理士に同席してもらいます。税理士が「分担はこう、決算は一緒に」と直接話すと、候補者は相談相手がいることを確かめられます。

二つ目は、面談でいまの経理の状態を見せることです。何が動いていて、何が止まっていて、資料はどこまであるか。匿名化や概要の形で見せると、候補者は「やること」を判断できます。

三つ目は、面談で実務の水準を確かめることです。「月次の締めの手順を最初から順に」と聞くか、簡単な実技（仕訳の判断）を短く。経理は、経歴の肩書と実務の水準がずれることがあります。

四つ目は、繁忙期の実態を再確認することです。書いてあっても、候補者は読み飛ばしていることがあります。

五つ目は、記録です。[スカウトの重複防止](/media/scout-jyufuku-boushi/)も参考になります。

## 代行に出せる範囲

| 工程 | 代行に出せる | 社内で持つ |
|---|---|---|
| 対象の決定 | 水準と規模と分担で絞る検索の条件の提案 | 水準と規模の確定 |
| 検索と一覧化 | 出せる | — |
| 文面の型作り | 出せる | 水準・規模・分担・引き継ぎの状態・周期と働き方・会計の仕組みの中身を社内が出す |
| 一行目の個別化 | 出せる。経歴の水準と規模の一点を書く | — |
| 送信 | 出せる | 名義と時間帯 |
| 返信の一次対応 | 出せる | — |
| 面談の設定 | 出せる | 経理の分かる人（税理士でも）と上司の面談の枠の確保。経理の状態の資料の用意 |
| 面談 | — | 経理の分かる人と上司が出る |
| 記録と数の整理 | 出せる | — |

分け方の要点は、「引き継ぎの状態と分担は、社内でしか出せない」ことです。代行に「経理向けの文面を」と頼んでも、この二つが社内から出ていなければ、代行は「安定」「全般」で埋めるしかなく、外す訴求になります。

### エラベルの見解

担当する側から見ると、経理のスカウトで最も時間がかかるのは、依頼側から引き継ぎの状態を引き出すことです。依頼側は「前任者が辞めた」とは言いますが、何が文書化されていて、何が止まっていて、税理士がどこまで知っているかは、把握されていないことが多い。ここを、顧問の税理士を交えて把握しないと、文面に書けず、面談で候補者の「引き継ぎは」に答えられません。

エラベルでは、経理の案件で担当者を紹介するとき、依頼側に水準と規模と分担と引き継ぎの状態を先に把握していただき、それが担当者に渡ってから文面に入るようお伝えしています。渡らなければ、担当者の最初の仕事は、税理士を交えてこの四つを把握する打ち合わせです。実態が正直に書かれた文面は、返信の総数は減っても、面談後の辞退が減り、入社後の離職も減ります。

## まとめ

- 経理がスカウトを読まない理由は**水準と規模が分からない・引き継ぎの状態を最初に確かめる・繁忙期と働き方を見る・「安定」に実態の無さを感じる**
- 先に決めるのは**対象**。**水準・規模・分担で絞る**。会計事務所からの転向層を含める
- 文面の型は**一行目に候補者の水準と規模の一点→自社の水準と規模と体制→分担→引き継ぎの状態（正直に）→繁忙の周期と働き方→会計の仕組み→経営との距離→会社の紹介（短く）→税理士と上司が出る面談**
- 刺さる訴求は**水準・規模・分担・引き継ぎ・働き方・相談相手の具体**。外す訴求は**「全般」「安定」「長く働ける」「一人で任せます」**
- 面談には**経理の分かる人（税理士でも）と上司**が出て、**経理の状態を見せ、実務の水準を確かめ、繁忙期を再確認**
- 代行に出せるのは**水準と規模で絞った検索・個別化・送信・一次対応・面談の設定・記録**。引き継ぎの状態と分担は社内から

## よくある質問

### 引き継ぎが無いことをスカウトに書くと、返信が来ないのでは

整った引き継ぎを求める人からは来ませんが、その人は面談か入社後に「引き継ぎが無い」と分かって離れる人です。「前任者の退職で引き継ぎは一部のみ。税理士と一緒に業務を整理し直すところから」と書くと、立て直しの経験がある人、一人経理を回してきた人が返信します。引き継ぎの無さを隠して返信をもらっても、面談で聞かれて辞退されるので、先に書くほうが互いの時間を使いません。書き方は、状態だけでなく、「税理士が一緒に整理する」「経営者が時間を使う」と、立て直しに使える材料も添えます。

### 「安定した環境」は、経理の人にとって本当に魅力だと思うのですが

安定を求める経理の人はいますが、「安定した環境」という言葉だけでは、何が安定しているのか分かりません。会社の業績か、業務の仕組みか、人間関係か、働き方か。しかも、この言葉はどの会社の経理の募集にも書かれていて、経験者は読み飛ばします。安定を訴求するなら、具体で書きます。「月次の締めの手順は文書化されていて、税理士が月に一度確認する」「残業は月末の数日だけ」「リモートは週の半分」。具体があれば、安定は伝わります。

### 顧問の税理士が面談に出てくれません

税理士の時間が取れないなら、面談の前に税理士に「分担」と「いまの経理の状態」を書面で整理してもらい、面談で経営者がそれを候補者に見せます。「税理士が整理したもの」として見せれば、候補者は分担の実態を確かめられます。面談後に、候補者と税理士が短く話す機会（オンラインで十五分）を設ける形もあります。税理士が面談にも書面にも関わらない場合は、税理士との分担が曖昧な可能性があり、採用の前に分担を整えることが先です。
