同じ採用代行を使っても、機能する小売の会社と機能しない会社があります。差を作るのは代行の腕ではなく、発注側の条件です。当日中に返す窓口があるか、店舗をまたいで観点と記録が一つか、実態を求人票に書いているか、計画が一枚にあるか、本部の型を分けているか、記録が社内にあるか、任せる工程が絞られているか。結論を先に書くと、**小売業界で採用代行が機能するのは、速さ・店舗・実態・計画・本部・記録・工程の七つで「社内に残すものを残している」会社で、機能しないのは「返事は店長が手が空いたときに。店舗は店長に任せている。全部任せたい」会社です。**発注の前に七つで自社を確かめ、機能しない条件があれば、発注の前にそれを変えます。工程の切り分けは[小売業界の採用代行](/media/rpo-kouri-rpo/)に、課題の分解は[小売業界の採用課題](/media/rpo-kouri-kadai/)に、職種の切り分けは[販売スタッフ採用を代行に出す判断基準](/media/rpo-hanbai-rpo/)に書いています。ここでは、小売業界の七つの対に絞ります。

## 七つの対

| 軸 | 機能する条件 | 機能しない条件 |
|---|---|---|
| 速さ | 店舗への応募に当日中に返す窓口が店長の外にあり、面接の日程を即日で確定できる | 「返事は店長が手が空いたときに」 |
| 店舗 | 店舗をまたいで観点と記録の形が一つ。決めるのは店長。枠を開店前・閉店後・接客の少ない時間帯で週に一つ預けられる | 「店舗は店長に任せている」。基準も記録も枠もばらばら |
| 実態 | 求人票の型にシフト・土日・繁忙期・一緒に働く人・最初の一週間を店長が埋めている | 「実態は面接で」「働きやすい」だけ |
| 計画 | 繁忙期と出店の時期が店舗ごとの採用の一枚にあり、数か月前に募集を始める | 直前に「急いで」 |
| 本部 | バイヤー・店舗開発・企画は、店舗の型と分けてスカウトと紹介で | 店舗と同じ媒体と速さの型で |
| 記録 | 一覧に「店舗」の列があり、店舗をまたいで社内の環境にある | 店舗ごとに別。代行の環境 |
| 工程 | 任せる工程が絞られ、残す工程（店長の見極め・シフトと条件・受け入れ・本部の要件）の担当がいる | 「全部任せたい」 |

七つのうち一つでも機能しない条件にあると、代行はその部分で止まります。

## 速さ：当日中に返す窓口があるか

| 機能する | 機能しない |
|---|---|
| 応募への返事と日程の提示を、店長以外の窓口（本部か代行）が当日中に | 店長が接客の合間に、翌日以降に |
| 店長の枠を先に預かり、候補を出して即日で確定 | 店長の都合を都度確認 |
| 面接の結果を当日か翌日に。入店の日を面接で決める | 「後日連絡」 |

### エラベルの見解

小売業界で最も多い機能しない条件は「速さ」で、しかもそれが「店長の責任感」で隠れています。店長は「自分の店の人は自分が返事をする」と考え、接客の合間に見て、閉店後に返し、その間に応募者は別の店で決まる。店長の責任感は店舗の強みですが、返事の速さには向きません。「返事と日程は本部か代行が当日中に、面接と受け入れは店長が」と分けると、店長の負担が減り、入店が増えます。エラベルで担当者を選ぶ企業には、「店舗への応募に、誰が、何時間以内に返していますか」を、私たちから先に聞いています。「店長が翌日」なら、代行に出す最初の工程は一次対応です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 店舗：観点と記録が一つか

| 機能する | 機能しない |
|---|---|
| 観点（この役割に期待すること。三つ）と記録の形（事実と判断）が一枚で、全店長に渡っている | 店舗ごとに店長の勘 |
| 決めるのは店長 | 本部が決める（店舗の実態と合わない） |
| 枠を開店前・閉店後・接客の少ない時間帯で週に一つ先に | 接客と重なり、日程が延びる |
| 一覧に「店舗」の列 | 店舗ごとに別の記録 |

揃え方は[面接官によって評価がばらつく](/media/rpo-mensetsukan-bara/)に書いています。

## 実態：求人票の型に店長が埋めているか

| 機能する | 機能しない |
|---|---|
| 本部が型（シフト・土日・繁忙期・一緒に働く人・最初の一週間・店舗の環境）を作り、店舗の実態を店長が埋める | 本部の求人票をそのまま全店舗で |
| 応募の減少を受け入れ、入店と定着で見る | 応募の数を成果にして隠す |
| 早期離職の理由を求人票の型に戻す | 「本人の事情」で片付ける |

実態の書き方は[求人原稿の作成の進め方](/media/rpo-task-kyujin-genko-susumekata/)に書いています。

## 計画：店舗ごとの一枚にあるか

| 機能する | 機能しない |
|---|---|
| 繁忙期の時期と出店の予定が、店舗ごとの採用の一枚に「時期・人数・募集の開始」で置かれている | 直前に店長から「人が足りない」 |
| 募集の開始を、応募から入店までの日数から逆算 | 「来週から」 |
| 本部が月次で店舗ごとの一枚を見る | 店長任せ |

計画のつなぎ方は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に書いています。

### エラベルの見解

「全部任せたい」という小売の会社は、多くの場合、本部の人事が少人数で、店舗の数に対して手が回らず、店長に任せた結果、店舗ごとにばらばらになった状態です。その状態で全部を任せると、店舗の見極めもシフトも受け入れも代行に寄り、代行にはできないので止まります。エラベルは担当者を工程ごとに選べる形にしているので、本部が「観点の一枚・求人票の型・計画・条件」に絞り、店長が「面接の三十分と最初の一週間の受け入れ」に絞り、「店舗の一次対応・日程・店舗をまたぐ記録」を担当者が担う、という組み方ができます。店舗をまたぐ記録が一つになると、本部はどの店舗で詰まっているかを見られ、店長ごとの負担も見えます。工程の切り分けは[面接の日程調整は代行に出せるか](/media/rpo-task-nittei-chousei-daikou/)や[求人媒体の運用は代行に出せるか](/media/rpo-task-baitai-unyou-daikou/)に書いています。

## 本部：店舗の型と分けているか

| 機能する | 機能しない |
|---|---|
| バイヤー・店舗開発・企画は、スカウトと紹介の型で、要件を「担った範囲」で | 店舗と同じ掲載型と速さの型で |
| 本部の職種ごとに、部門の責任者が要件を決め、見極めを担う | 人事だけで決める |

本部の要件の作り方は[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 記録：店舗をまたいで社内にあるか

| 機能する | 機能しない |
|---|---|
| 一覧に「店舗」の列があり、店舗をまたいで段階と数が見える。応募から返事までの時間も | 店舗ごとに別。代行の環境 |
| 週次の一枚で、店舗ごとの数と止まりが本部に届く | 月末の報告だけ |
| 契約が終わっても、記録と型（観点の一枚、求人票の型、店舗ごとの計画）が社内に残る | 契約が終わると消える |

記録の扱いは[引き継ぎ資料に含める内容](/media/rpo-hikitsugi-shiryou/)に書いています。

## 工程：絞られているか

| 機能する | 機能しない |
|---|---|
| 「店舗の一次対応と日程と記録」「本部のバイヤーの母集団形成」のように、型と工程で任せる範囲が明確 | 「採用を全部」 |
| 残す工程（店長の見極め・シフトと条件・受け入れ・本部の要件と見極め・合否）の担当が決まっている | 残す工程の担当がいない |
| 一つの店舗・一つの工程で三か月回し、記録で効いたかを見てから広げる | 最初から全店舗・全工程 |

## 機能しない条件を変える順番

| 順 | 変えること | 費用 |
|---|---|---|
| 一 | 速さ：当日中に返す窓口を店長の外に | かからない（本部で）か、代行の一工程 |
| 二 | 店舗：観点と記録の一枚。店長の枠 | かからない |
| 三 | 実態：求人票の型を作り、店長が埋める | 本部の時間 |
| 四 | 記録：店舗の列のある一覧を社内の環境に | かからない |
| 五 | 工程：任せる工程を一つに絞る（一次対応から） | 契約の範囲が小さくなる |
| 六 | 計画：店舗ごとの一枚 | 本部の時間 |
| 七 | 本部：型を分ける | かからない |

一から五は発注の前に社内で変えられます。六と七は本部の時間が要りますが、費用はかかりません。

## 機能しているかを見る記録

| 見ること | 機能している目印 |
|---|---|
| 応募から返事までの時間、面接に来た数 | 当日中になり、来た数が増えていれば速さが機能 |
| 店舗ごとの通過と日数の差 | 差が小さければ店舗が機能 |
| 早期離職の理由 | 「シフト」「働き方」が減っていれば実態が機能 |
| 募集の開始と繁忙期・出店の差 | 数か月前になっていれば計画が機能 |
| 本部の職種の応募の数 | 増えていれば本部が機能 |

件数のまま並べ、前の募集と比べます。割合や外部の平均で断定しません。見る指標は[採用代行との定例会で見るべき数字](/media/rpo-teirei/)に書いています。

## まとめ

- 代行が機能するかは**代行の腕より発注側の条件**で決まる
- 七つの対は**速さ・店舗・実態・計画・本部・記録・工程**
- 最も多い機能しない条件は**速さ**で、店長の責任感で隠れている。返事と日程は店長の外で当日中に
- **「全部任せたい」は機能しない**。本部は観点の一枚・型・計画・条件に、店長は面接と受け入れに絞る
- 変える順番は**速さ→店舗→実態→記録→工程→計画→本部**。一〜五は発注前に社内で
- 店舗をまたぐ記録が一つになると、**どの店舗で詰まっているか**が見える

## よくある質問

### 店長が「自分の店の人は自分が返事をしたい」と譲りません

返事の速さと、面接と受け入れを分けて話します。「応募者は先に返事が来た店に行く。返事は当日中に本部（か代行）が返し、面接と受け入れは店長が。店長が決めることは変わらない」と伝えます。一店舗で「返事を分けたら入店が増えた」記録が出れば、他の店長にも伝わります。全店舗を一度に変えず、応募が多く返事が遅れている店舗から始めます。

### 繁忙期の前に一気に採る形を、毎年繰り返しています

繁忙期の時期は毎年決まっているので、店舗ごとの採用の一枚に「時期・人数・募集の開始」を置き、応募から入店までの日数から逆算して、数か月前に募集を始めます。前年の繁忙期の短期の人への再度の声かけ（本人の同意と会社の決まりの範囲で）も経路になります。同意の取り方と記録の扱いは専門家の確認に従います。毎年ぎりぎりになるのは、一枚が無いからで、一枚があれば代行は時期に合わせて動けます。

### パートとアルバイトの採用と、正社員の採用を同じ代行に任せられますか

任せられますが、型が違うので、工程を分けて契約します。パートとアルバイトは「速さと当日の返事と地域の経路」の型、正社員と店長候補は「掲載型とスカウトと登用の道筋」の型です。担当者の経歴も、それぞれの型で確かめます。一つの代行に両方を任せる場合も、記録は一つの一覧で「雇用の形」の列を置き、型ごとに効いたかを見ます。
