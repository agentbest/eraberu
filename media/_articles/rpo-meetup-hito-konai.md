採用のために、会社説明会や交流会を企画した。会場を押さえ、資料を作り、告知した。当日、来たのは数人。または、申し込みがゼロで中止。来た人も、応募にはつながらなかった。「イベントは、うちには向いていない」と諦めかけている。結論を先に書くと、**採用イベントに人が集まらないのは、「集める」ことから考えているからです。「誰に来てほしいか」「何のために開くか」「来た人に何を持ち帰ってもらうか」の三つが無いと、告知しても届かず、来ても応募につながりません。三つを決め、対象に届く集め方をし、小さく始めて続けます。大きな一回より、小さな継続です**。インターンの設計は[インターンをどう設計するか](/media/rpo-intern-sekkei/)に、知名度が無い場合は[知名度がなくて応募が集まらない](/media/rpo-chimeido-nai/)にまとめています。

## イベントに人が集まらない構造

採用イベントに人が集まらないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「集める」から考えている | 「何人集めるか」が先で、「誰に、何のために」が無い |
| 対象が曖昧 | 「求職者全般」「学生」。広すぎて、誰にも届かない |
| 告知が、自社の媒体だけ | 自社のサイトとSNSで告知。知らない会社のイベントは、知らない人には届かない |
| 内容が「会社の説明」 | 参加者が「求人票を読めば分かること」を、わざわざ聞きに来る理由が無い |
| 一回で大きくやろうとする | 会場、資料、集客に費用と時間をかけ、集まらないと止める |
| 来た人に、次が無い | イベントの後、連絡も接点も無く、応募につながらない |
| 知名度が無い会社が、大手と同じ形でやる | 大手は名前で集まる。知らない会社は、名前では集まらない |
| 参加のハードルが高い | 平日の日中、会社まで来る、事前の登録が長い。来にくい |

構造の大半は、「誰に、何のために、何を持ち帰ってもらうか」が無いことです。三つを決めます。

## 目的と対象の決め方

イベントの前に、三つを決めます。

| 決めること | 中身 | 例 |
|---|---|---|
| 誰に来てほしいか | 役割、経験、状況。「求職者全般」ではなく、像で | 「〇〇の経験があり、転職を考え始めた人」「△△を学んでいる学生」「業界を変えたい人」 |
| 何のために開くか | 会社を知ってもらう、仕事を体験してもらう、社員と話してもらう、特定の役割の応募を増やす | 「〇〇の役割を、業界の外の人に知ってもらう」 |
| 何を持ち帰ってもらうか | 参加者が、イベントの後に「得たもの」。会社の説明ではなく、参加者にとっての価値 | 「〇〇の仕事の実態が分かった」「この業界の働き方が分かった」「自分に合うかの判断材料」 |

「何を持ち帰ってもらうか」が要点です。参加者は、自分の時間を使って来ます。「会社の説明を聞いた」では、持ち帰るものがありません。「〇〇の仕事の実態が分かった」「業界の人と話せた」なら、来る理由になります。

対象が絞られていれば、告知の言葉も、集め方も、内容も、対象に合わせられます。「求職者全般」では、何も合わせられません。

## 集め方の設計

対象に届く集め方です。自社の媒体での告知だけでは、知らない人には届きません。

| 集め方 | 中身 | 向いている対象 |
|---|---|---|
| 対象がいる場所で告知 | 業界のコミュニティ、学校、専門の媒体、対象が使うSNSの場 | 対象が絞られている場合 |
| 社員の紹介 | 社員が知り合いに声をかける。「こういう会のがあるから、来ない？」 | 対象が社員の知り合いにいる場合 |
| 過去の応募者・面談した人 | 同意のある人に案内。「まず話を聞く場」として | 応募に至らなかった人、辞退した人 |
| 紹介会社・媒体の担当者 | 担当者に「こういう会を開く」と伝え、候補者に案内してもらう | 担当者との関係がある場合 |
| 他社との共催 | 同じ業界や地域の会社と共同で開く。集客の負担を分け、参加者の選択肢が増える | 知名度が無い会社同士 |
| 業界や地域の既存のイベントに出る | 自社で開かず、既存の場に参加者として、または登壇者として出る | 自社で集めるのが難しい場合 |
| テーマで集める | 「会社の説明会」ではなく、「〇〇の仕事の実態を話す会」「業界を変えた人の話を聞く会」。テーマに人が来る | 知名度が無い会社 |
| 参加のハードルを下げる | オンライン、夕方か土日、事前の登録は名前と連絡先だけ、途中参加と退出を可に | 全ての対象 |

集め方の要点は、「テーマで集める」ことと「対象がいる場所で告知する」ことです。知らない会社の説明会には来ませんが、「〇〇の仕事の実態を話す会」には、その仕事に関心がある人が来ます。

集める数は、多くなくてよいです。対象に合う人が五人来るほうが、合わない人が五十人来るより、採用につながります。

## 当日の中身の型

参加者が「持ち帰るもの」がある中身の型です。

| 時間 | 中身 | 注意 |
|---|---|---|
| 最初の五分 | 「今日の目的」と「流れ」と「選考ではないこと」を伝える。参加者の緊張を下げる | 「会社説明」から始めない |
| 十〜十五分 | テーマの話。「〇〇の仕事の実態」「業界の働き方」を、社員か経営者が具体的に。会社の紹介は、テーマの中で最小限に | 資料の読み上げにしない |
| 二十〜三十分 | 社員との対話。少人数の輪で、参加者が質問し、社員が答える。「入社して最初の一年」「大変だったこと」「続けている理由」 | 用意した美談ではなく、対話 |
| 十分 | 参加者からの質問。何でも。答えられないことは「確認して連絡する」 | 「質問はありませんか」で終わらせず、担当者が最初の質問を投げる |
| 最後の五分 | 「持ち帰ってもらいたいこと」の確認、次の接点の案内（面談、応募、次の会）、任意のアンケート | 「応募してください」と迫らない |
| 終了後 | 残りたい人との立ち話。社員が残る | 強制しない |

中身の要点は、「社員との対話の時間を最も長く」することです。参加者が持ち帰るのは、会社の説明ではなく、「社員と話して分かったこと」です。

登壇する社員には、事前に「何を話すか」（入社して最初の一年、大変だったこと、続けている理由）を共有し、「用意した話ではなく、対話で」と伝えます。

オンラインの場合も、同じ型で。少人数の輪は、分けた部屋の機能で。仕様は各サービスの公式の案内で確認します。

### エラベルの見解

相談で最も多い失敗は、「会社説明会を、平日の昼に自社の会議室で開き、自社のサイトで告知し、申し込みがゼロだった」というものです。対象が「求職者全般」で、内容が「会社の説明」で、告知が自社のサイトだけで、参加のハードルが高かった。対象を「〇〇の経験があり、業界を変えたい人」に絞り、テーマを「〇〇の仕事の実態を話す会」にし、オンラインで夕方に、業界のコミュニティと社員の紹介で集めたら、五人が来て、二人が面談に進みました。「集める」ではなく、「誰に、何のために」でした。

見ていて差がつくのは、担当者が「テーマ」で設計するかどうかです。「会社説明会を開きましょう」と言う担当者と、「知名度が無い会社の説明会には来ません。対象を絞って、テーマで集めて、社員との対話を中心に、オンラインで小さく開きましょう」と、テーマから設計する担当者がいます。後者は、合う人を集めます。

発注側にできるのは、「何人集めるか」ではなく「誰に、何を持ち帰ってもらうか」を担当者に伝えることです。

## イベント後の接点

イベントは、当日で終わりません。後の接点が、応募につながります。

**翌日に、参加への感謝と、次の案内を送る。** 「ご参加ありがとうございました。話に出た〇〇について、補足です。ご興味があれば、まず話を聞く場（面談）をご案内します」。同意のある連絡先に。

**質問への答えを、送る。** 当日「確認して連絡する」と言ったことを、翌日に。

**個別の面談を、案内する。** 「応募」ではなく、「まず話を聞く場」。面談は選考にしない（[カジュアル面談が選考になってしまう](/media/rpo-casual-mendan-kadai/)）。

**社員との接点を、続ける。** 当日話した社員と、参加者が個別に話せる場。「〇〇さんともう少し話したい」に応じる。

**次の会の案内。** 「次は〇月に、△△をテーマに開きます」。続けていることが、信用になります。

**参加者の記録。** 名前、連絡先（同意のうえで）、関心、当日の様子、その後の接点。個人情報の扱いは規程と法令に沿います。

**参加者の声を、次の会に反映する。** アンケートと、当日の質問から。「〇〇についてもっと知りたい」が多ければ、次のテーマに。

**応募しなくても、関係を続ける。** 今回応募しなくても、数か月後に動く人がいます。同意のある人には、募集の案内を。

イベント後の要点は、「翌日に連絡し、面談を案内し、関係を続ける」ことです。当日の後に何も無いイベントは、参加者の記憶から消えます。

## 小さく続ける運用

イベントは、大きく一回ではなく、小さく続けます。

**最初は、五人の会から。** 会議室かオンラインで、社員二人と参加者五人。費用はほぼゼロ。

**月に一度か、二か月に一度。** 続けられる頻度で。「年に一度の大きな会」より、「毎月の小さな会」。

**テーマを変えて、続ける。** 「〇〇の仕事の実態」「業界を変えた人の話」「入社して一年の話」「経営者と話す会」。テーマが変われば、来る人も変わります。

**登壇する社員を、交代で。** 一人に負担を集めない。話す型（最初の一年、大変だったこと、続けている理由）を共有すれば、誰でも話せます。

**記録を取る。** 回ごとに、参加者の数、対象に合っていたか、面談に進んだ数、応募の数。効果を見ます。

**効いたテーマと集め方を、続ける。** 「〇〇のテーマで、社員の紹介で集めた回が、面談に進む率が高い」なら、それを増やします。

**他社との共催を、検討する。** 同じ業界や地域の会社と。集客の負担を分け、参加者にとっても選択肢が増えます。

**やめる判断も、持つ。** 三回続けて対象に合う人が来ない、面談に進む人がゼロ、なら、形を変えるか、やめる。「他社がやっているから」で続けない。

続ける運用の要点は、「小さく、頻度を守り、記録を取る」ことです。大きく一回で失敗すると、「イベントは向いていない」になります。小さく続ければ、効く形が見えます。

## 外注する場合の範囲

採用イベントに人が集まらない問題を、採用代行に出す場合の範囲です。

**出せる工程。** 「誰に・何のために・何を持ち帰ってもらうか」の整理、対象に合わせたテーマの案、集め方の設計と実行（対象がいる場所への告知、社員の紹介の依頼文、過去の応募者への案内、紹介会社や媒体の担当者への連絡、共催の候補の整理）、当日の中身の設計と進行、登壇する社員への事前の共有、参加の受付と案内、当日の運営、翌日の連絡と面談の案内、参加者の記録（個人情報の扱いは専門家の確認を経て）、回ごとの効果の記録と振り返り、次の会の設計。

**社内に残す判断。** イベントを開くかどうか、対象とテーマの決定、登壇する社員の指名、公開する内容の承認、費用、共催の相手の決定。

**外注の効きどころ。** 採用イベントは、「集め方」と「当日の進行」と「後の接点」に手間がかかり、社内では「告知して当日を待つ」形になりやすい取り組みです。担当者が対象に届く集め方を実行し、当日を進行し、翌日の連絡と面談の案内を回せば、社内は「登壇して対話する」だけで済みます。担当者は複数の会社のイベントを見ているので、「知名度が無い会社は、このテーマとこの集め方で」の型を持ち込めます。

**外注しても動かない場合。** 対象を「求職者全般」から絞らない、内容を「会社の説明」から変えない、社員が登壇しない、翌日の連絡をしない。社内の判断で、代行を替えても直りません。

採用イベントは、対象とテーマと後の接点で決まります。外注は、集め方と進行と接点を回す手段です。

### エラベルの見解

担当する側から見ると、イベントの相談で最も多いのは、「一回で大きくやって、失敗して、止める」ことです。会場を押さえ、資料を作り、告知に費用をかけ、五十人を目標にして、五人しか来なかった。「イベントは向いていない」で終わり。

五人は、失敗ではありません。対象に合う五人なら、成功です。最初から五人の会として設計し、月に一度続け、記録を取れば、三回目には「この集め方とテーマで、面談に進む人が出る」が見えます。大きな一回より、小さな継続です。

発注側にできるのは、「何人集めるか」の目標を捨て、「対象に合う人が数人来て、面談に進むか」で見ることです。

## まとめ

- 集まらないのは**集めるから考える・対象が曖昧・告知が自社だけ・内容が会社の説明・一回で大きく・来た人に次が無い・大手と同じ形・ハードルが高い**構造
- 決めるのは**誰に（像で）・何のために・何を持ち帰ってもらうか**。持ち帰るものが来る理由
- 集め方は**対象がいる場所・社員の紹介・過去の応募者・紹介会社と媒体の担当者・他社との共催・既存のイベントに出る・テーマで集める・ハードルを下げる**。合う人が数人でよい
- 当日は**最初の五分で目的と流れと選考でないこと・テーマの話・社員との対話を最も長く・質問・持ち帰るものの確認と次の案内・終了後の立ち話**
- 後の接点は**翌日に感謝と案内・質問への答え・面談の案内・社員との接点・次の会・記録・声を反映・関係を続ける**
- 続けるのは**五人の会から・月に一度か二か月に一度・テーマを変えて・社員は交代で・記録・効いた形を続ける・共催・やめる判断**
- 外注できるのは**三つの整理・テーマ・集め方の実行・中身と進行・事前の共有・受付・運営・翌日の連絡・記録・振り返り・次の設計**。社内に残るのは**開くかどうか・対象とテーマ・登壇・承認・費用・共催の相手**

## よくある質問

### 告知しても、申し込みがゼロでした

対象が「求職者全般」で、内容が「会社の説明」で、告知が自社のサイトだけ、になっていないかを確認します。知らない会社の説明会には、来ません。対象を絞り（「〇〇の経験があり、業界を変えたい人」）、テーマで集め（「〇〇の仕事の実態を話す会」）、対象がいる場所（業界のコミュニティ、社員の紹介、紹介会社の担当者）で告知し、参加のハードルを下げます（オンライン、夕方、登録は名前と連絡先だけ）。五人の会として設計し直します。

### 来た人が、応募につながりません

当日の後に接点が無いことが原因であることが多いです。翌日に感謝と補足を送り、「まず話を聞く場（面談）」を案内し、話した社員との個別の接点を用意し、次の会を案内します。当日の中身が「会社の説明」中心で、社員との対話が短いと、参加者は持ち帰るものが無く、応募の判断材料になりません。対話の時間を最も長くし、「応募してください」と迫らず、面談の案内から。今回応募しなくても、同意のある人には関係を続けます。

### 大きなイベントに出展すべきですか

自社で集めるのが難しい場合、既存の大きなイベントに出展する形はあります。ただし、出展の費用と、当日の対応の人手と、出展の後の接点（連絡、面談）の運用が要ります。「出展すれば集まる」ではなく、「出展で接点を持った人に、翌日から連絡し、面談を案内する」までが一つの流れです。出展の前に、自社の小さな会で「対象とテーマと対話の型」を作っておけば、出展の場でも同じ型で話せます。出展の仕組みと費用は、主催の公式の案内で確認します。
