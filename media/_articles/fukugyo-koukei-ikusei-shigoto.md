後継者育成・タレントマネジメントを副業で初めて受けるとき、見えにくいのは「候補者の選抜に触れずに、どうやって育成の仕組みを作るか」と「候補者の情報をどう扱うか」です。募集文には「後継者育成計画の策定」とだけあり、実際には、どの役割にいつまでにの決定、要る経験の定義、候補者の決定（会社）、本人への伝え方（会社）、育成計画の型、機会の提供（会社）、進捗の記録、年に一度の見直し、登用の判断（会社）と、会社が決める工程と自分が型を作る工程が交互に並びます。分けたまま進めないと、選抜に引き込まれます。結論を先に書くと、**1案件は「契約前→役割と要る経験の定義→候補者の決定と育成計画の型→機会の設計と進捗の記録→年に一度の見直しの場→終了と引き継ぎ」の六つの段階で進み、契約前に範囲とどの役割にいつまでにと候補者を決めるのは会社であることと本人への伝え方と候補者の情報の扱いと事業承継の有無と処遇の扱いと見直しの頻度を決め、責任者に聞いて役割ごとに要る経験を経験の言葉で定義し、会社が候補者を決めたら要る経験といまある経験と足りない経験と機会と時期の型で計画を作り、会社が機会を提供して自分は進捗を事実で記録し、年に一度の見直しの場を進行して判断は会社が行い、型と仕組みを引き継いで候補者の情報を残さずに終えます。**案件の型と事業承継の線は[後継者育成・タレントマネジメントの副業案件](/media/fukugyo-koukei-ikusei-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

後継者育成は、候補者の一覧という、社内でも限られた人しか見ない情報を扱います。契約前に、扱いと役割の線を決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 役割と要る経験の定義だけか、育成計画の型と記録の仕組みまでか、見直しの場の進行までか、型作りか | 「候補者の選定も」が足される |
| どの役割に、いつまでに | 次の人が要る役割（三つまで）と時期。会社が決める | 「優秀な人全般」で計画が資質の話になる |
| 候補者を決めるのは会社 | 自分は要る経験と足りない経験の整理まで。「向いている」を言わない | 選抜の責任を負う |
| 本人への伝え方は会社 | 候補であることを伝えるか、どう伝えるか。自分は候補者に言わない | 会社の意思と違うことを本人に約束する |
| 候補者の情報の扱い | 候補者の一覧と計画と記録は、会社の管理する場所で、見る人を限って。自分の端末に置かない | 一覧が漏れる |
| 事業承継を含むか | 経営者自身の後継を含むなら、専門家（税理士、弁護士など）の関与を前提に、自分は要る経験と計画の型まで | 承継の計画を副業の人が担う形になる。個別の判断は専門家にご確認ください |
| 処遇に関わる設計は別 | 候補者の報酬や等級を変える設計は、専門家の関与を前提に別の範囲 | 人事制度の設計に踏み込む |
| 見直しの頻度と判断者 | 年に一度か半期。登用と候補の追加と外しを判断するのは誰か | 見直しが無く、計画が古くなる |
| 評価 | 要る経験の定義ができたか、計画が型になり機会が提供されたか、記録が回ったか。誰かが登用されたかではない | 登用の有無で評価される |

止まりやすいのは、「まず候補者のリストを作ってほしい」で始めるときです。要る経験が無いままのリストは、印象で選ばれた名前の一覧です。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 役割と要る経験の定義：責任者に聞き、経験の言葉で、JDと接続

候補者の前に、役割ごとに「要る経験」を定義します。資質ではなく、経験の言葉で書きます。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 役割の確認（次の人が要る役割の、いまの担当者と、その役割が何を決め、何を担うか。JDがあれば使う） | 責任者といまの担当者の時間 | JDが無いまま、役割を「部長」の肩書だけで扱う |
| 要る経験の定義（その役割を担うために、事前に積んでいる必要がある経験。「〇〇の規模の予算を一人で」「〇〇人の評価を」「〇〇の案件を最初から最後まで」） | 責任者の承認 | 「リーダーシップ」「経営視点」の資質で書く |
| 要る経験の数を絞る（五つまで。全部を満たす人はいない前提で、必須と歓迎に分ける） | 必須と歓迎の合意 | 十個並べる |
| 経験を積める機会の一覧（社内で、その経験を積める場（異動先、案件、代理）があるか。無ければ作る必要があること） | 機会の有無の確認 | 積める機会が社内に無い経験を必須にする |
| 書面（役割ごとに一枚。要る経験、必須と歓迎、積める機会） | 承認 | 個人の名前を書く |

止まりやすいのは、要る経験を「いまの担当者の経歴」で書くことです。いまの担当者が積んだ経験と、役割に要る経験は違います。役割から書きます。定義の型は[ジョブディスクリプションの作成の副業の実務](/media/fukugyo-jd-sakusei-shigoto/)の六項目と共通です。

### エラベルの見解

担当する側から見ると、この仕事は「要る経験を、社内で積める機会と一緒に定義できるか」で、計画が動くかが決まります。「〇〇の規模の事業を一人で回した経験」を必須にしても、社内にその規模の事業が一つしか無く、いまの担当者が握っていれば、誰もその経験を積めません。要る経験と積める機会を一緒に見て、積める機会が無い経験は「代理」や「一部の委任」で積める形に分解する、あるいは歓迎に落とす。エラベルで担当者を選ぶ企業には、「要る経験は、社内で積める機会と一緒に定義します。積めない経験を必須にすると、誰も育ちません」と、私たちから先に伝えています。受ける側がその場で使える判断としては、要る経験の一枚に「積める機会」の欄を作り、空欄の経験は必須から外すか、分解すること。空欄のまま残した必須は、計画を止めます。

## 候補者の決定と育成計画の型：会社が決め、経験で整理する

候補者は会社が決めます。自分は、決まった候補者について、要る経験に照らして整理し、計画の型を作ります。

| やること | 中身 | 落とし穴 |
|---|---|---|
| 候補者の決定（会社） | 責任者と経営者が、役割ごとに候補者を決める。自分は関わらない | 「誰がいいと思うか」に答える |
| 本人への伝え方（会社） | 伝えるか、どう伝えるか、伝えない場合の計画の扱い | 自分が本人に伝える |
| いまある経験の整理 | 候補者の経歴（会社が共有してよい範囲）を、要る経験に照らして「ある」「一部ある」「無い」に | 経歴の評価をする |
| 足りない経験 | 要る経験のうち、無いもの。必須を優先 | 「足りない」を本人の欠点として書く |
| 積む機会と時期 | 足りない経験を、どの機会（異動、案件、代理、社外、研修）で、いつまでに積むか。機会は会社が提供 | 機会を自分が約束する |
| 育成計画の一枚（候補者ごと） | 役割、要る経験、ある・一部・無い、積む機会と時期、進捗の欄。評価の言葉は無し | 「向いている度」の欄を作る |
| 見る人の限定 | 計画は会社の管理する場所で、見る人を限る | 広く共有する |

止まりやすいのは、いまある経験の整理で、「〇〇さんは経験は足りているが、人柄が」と資質の話に入ることです。経験の「ある・無い」だけを整理します。

## 機会の設計と進捗の記録：会社が提供し、事実で記録する

育成は、会社が機会を提供し、候補者が経験を積むことで進みます。自分は、機会の設計の型と、進捗の記録です。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 機会の設計（足りない経験を積める機会を、異動、案件の担当、代理、社外の経験、研修、から。誰が、いつ、何を任せるか） | 機会の決定と提供 | 研修だけで済ませる |
| 経験を積んだかの記録（機会を担ったか、要る経験がどこまで揃ったか。事実で。所感は書かない） | 記録を出す人（責任者か本人） | 「成長した」「まだ足りない」と評価を書く |
| 半期の確認（機会が提供されたか、遅れていれば理由（会社の都合か、本人の都合か）） | 確認の場 | 遅れを本人の責任にする |
| 候補者との接点（あるなら、会社が本人に説明している範囲で。自分から候補の話をしない） | 接点の範囲の決定 | 候補であることを匂わせる |
| 記録の置き場 | 会社の管理する場所で、見る人を限る | 自分の端末 |

止まりやすいのは、機会が「研修」だけになることです。要る経験は、実際に担うことでしか積めません。異動、案件、代理を、会社に決めてもらいます。

### エラベルの見解

同じ料金・同じ範囲でも、結果が分かれるのは、「進捗の記録に、評価の言葉を一つも入れないでいられるか」です。「〇〇さんは代理を担ったが、まだ判断が甘い」と書いた担当者の記録は、候補者の評価の材料になり、本人が知れば信頼を失い、記録が漏れれば会社の問題になります。「〇〇の代理を〇か月担った。要る経験のうち三つ目が『一部ある』になった」と事実だけを書いた担当者の記録は、次の見直しの場で会社が判断する材料になり、本人が読んでも納得できます。後継者育成の記録は、候補者の将来に直結するので、評価の言葉を入れた瞬間に重さが変わります。エラベルで長く続いている担当者は、記録の型に「所感」の欄を作らず、「積んだ機会」「揃った経験」の二つの欄だけを持っています。受ける側がその場で使える形としては、記録を書いたら、「甘い」「足りない」「成長」などの評価の言葉を検索して、残っていたら事実に書き換えることです。

## 年に一度の見直しの場：進捗、計画の直し、候補の追加と外し、登用の判断は会社

年に一度（または半期）、会社が候補者ごとの進捗を見て判断する場を、自分が進行します。判断は会社です。

| 順 | やること | 落とし穴 |
|---|---|---|
| 一 | 役割ごとに、次の人が要る時期の再確認（変わっていないか） | 時期を確かめずに進める |
| 二 | 候補者ごとの進捗（積んだ機会、揃った経験。事実で） | 評価の言葉で報告する |
| 三 | 計画の直し（機会が提供されなかった経験、時期の見直し） | 遅れを本人のせいにする |
| 四 | 候補の追加と外し（会社が判断。自分は「要る経験に照らして」の整理まで） | 自分が「外すべき」と言う |
| 五 | 登用の判断（要る経験が揃った候補者を登用するか。会社が判断） | 自分が「登用すべき」と言う |
| 六 | 記録（決めたことと理由。決めた人の名前で） | 記録が無い |

止まりやすいのは、場の中で「私は〇〇さんがよいと思います」と意見を言うことです。要る経験に照らした整理だけを出し、判断は会社に残します。決める場の進行は[提案のまとめ方](/media/fukugyo-teian/)の考え方と共通です。

## 終了と引き継ぎ：型と仕組み、候補者の情報を残さない

- **残すもの。** 役割と要る経験の定義の型（役割ごとの一枚）、育成計画の型、機会の一覧、進捗の記録の型、見直しの場の進行の型、決めたことの記録（会社の管理する場所に）
- **返すもの。** 候補者の一覧、計画、記録へのアクセス。候補者の経歴と情報を自分の手元に一切残さない
- **次の提案。** 見直しの場の進行の継続、他の役割への展開、社内の人事が回す型の引き継ぎ

止まりやすいのは、候補者の一覧を「参考に」と手元に残すことです。社内でも限られた人しか見ない情報で、終了後に持っている理由がありません。引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 候補者の情報の扱い

後継者育成で扱う候補者の一覧、経歴、足りない経験、進捗は、本人の将来の処遇に直結し、本人が知らないこともある情報です。会社の管理する場所で、見る人を限って扱い、自分の端末に置かず、評価の言葉を記録に入れず、本人に候補であることを自分から伝えず、他の依頼側や本業に持ち込みません。候補から外れた人の記録の扱い（削除か保管か）は会社の方針に従います。経営者自身の後継に関わる情報（株式、税務）には触れません。個別の判断は専門家にご確認ください。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に書いています。

## 稼働時間は何で決まるか

全体の時間は、「役割と要る経験の定義（役割の数×責任者への聞き取り）」「育成計画の型（候補者の数は会社が決める）」「機会の設計の支援」「進捗の記録（半期の確認）」「年に一度の見直しの場（準備と進行と記録）」の合計で決まります。候補者の選抜と評価は含まず、機会の提供は会社が行うので自分の稼働には乗りません。年に一度の見直しは、準備に時間がかかります。受ける前に「役割の数」「見直しの頻度」「記録の担当」を決めておけば、見込みが立ちます。数値は案件ごとに違うので、定義が終わった時点で以後の工程を見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→役割と要る経験の定義→候補者の決定と育成計画の型→機会の設計と進捗の記録→年に一度の見直しの場→終了と引き継ぎ**の六つの段階
- 契約前に**範囲・どの役割にいつまでに・候補者を決めるのは会社・本人への伝え方は会社・候補者の情報の扱い・事業承継の有無と専門家・処遇は別・見直しの頻度と判断者・評価**を決める。「まず候補者のリストを」では始めない
- 要る経験は**責任者に聞き、資質ではなく経験の言葉で、五つまで、積める機会と一緒に定義する**。積めない経験を必須にしない
- 候補者は**会社が決める**。自分は**要る経験に照らして「ある・一部・無い」を整理し、積む機会と時期の型にする**。資質の話に入らない
- 機会は**会社が提供**（異動・案件・代理・社外・研修）。記録は**積んだ機会と揃った経験の事実だけ**。評価の言葉を入れない
- 見直しの場は**自分が進行し、判断（計画の直し・候補の追加と外し・登用）は会社**。「私は〇〇さんがよい」と言わない
- 終了時は**型と仕組みを残し、候補者の一覧と情報を一切残さない**

## よくある質問

### 責任者から「候補者の〇〇さんは、経験は揃っているが人望が無い。どう思うか」と聞かれました

答えません。「経験の整理が私の範囲で、人望や資質の判断は御社です。要る経験に『人望』が要るなら、それを経験の言葉（〇〇人の組織で、〇〇を合意まで持っていった経験）に置き換えて、積める機会を設計しましょう」と、資質を経験に置き換える提案に変えます。個人の資質について意見を言った瞬間に、選抜の責任を負う形になります。

### 候補者に経験を積ませる機会が、社内にありません

要る経験を分解するか、歓迎に落とすか、社外の機会を会社が用意するかの三つを、会社に選んでもらいます。「〇〇の規模の事業を一人で」が無理なら、「〇〇の一部を代理で」「〇〇の案件を最初から最後まで」に分解して積める形にします。それでも無いなら、必須から歓迎に落とすか、社外の経験（出向、社外の案件）を会社が決めます。機会が無い必須を残したまま計画を続けると、候補者は「積めない」まま時間が過ぎ、辞めます。

### 見直しの場で、会社が「今年は誰も登用しない」と決めました

会社の判断で、自分は関わりません。記録に「決めたことと理由」を残し、計画の直し（次の一年で積む機会）を整理します。登用されないことが続くと候補者が離れることは、事実として（「候補者が離れる兆しがある」ではなく、「登用の時期が前回から延びている」と）会社に伝えます。登用を促す意見は言いません。判断の記録が積み重なれば、会社は自分で気づきます。
