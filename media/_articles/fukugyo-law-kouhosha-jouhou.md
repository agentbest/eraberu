副業で人事を受けていると、採用管理システムの中に何年も前の応募者が残ったままになっている会社に出会います。「いつまで持ってよいのか」と聞かれて、法律に「◯年」と書いてあるだろうと思って探すと、見つかりません。結論を先に書くと、**個人情報保護法第22条は「個人情報取扱事業者は、利用目的の達成に必要な範囲内において、個人データを正確かつ最新の内容に保つとともに、利用する必要がなくなったときは、当該個人データを遅滞なく消去するよう努めなければならない」と定めており、指針（平成11年労働省告示第141号）は、適正な管理のための措置の一つとして「収集目的に照らして保管する必要がなくなった個人情報を破棄又は削除するための措置」を挙げています。**条文が定めているのは年数ではなく、「必要がなくなったら消す」という方向です。年数は会社が決めます。個別の判断は弁護士や個人情報保護委員会・ハローワーク・都道府県労働局にご確認ください。応募時の取得の枠は[面接で聞いてはいけないこと](/media/fukugyo-law-shitsumon-ng/)に、第三者から集める場合は[リファレンスチェックの法的注意](/media/fukugyo-law-reference/)にまとめています。

## 条文が定めているのは年数ではない

まず、根拠になる条文を並べます。

**個人情報保護法第22条（データ内容の正確性の確保等）。**「個人情報取扱事業者は、利用目的の達成に必要な範囲内において、個人データを正確かつ最新の内容に保つとともに、利用する必要がなくなったときは、当該個人データを遅滞なく消去するよう努めなければならない」。**努めなければならない**という書き方なので、努力義務の形です。それでも、起点が「利用する必要がなくなったとき」に置かれていることは動きません。

**職業安定法第5条の5第1項。**求人者を含む主体に対して、「その業務の目的の達成に必要な範囲内で、厚生労働省令で定めるところにより、当該目的を明らかにして求職者等の個人情報を収集し、並びに当該収集の目的の範囲内でこれを保管し、及び使用しなければならない」と定めています。**保管も「収集の目的の範囲内」に縛られます。**同条第2項は「求職者等の個人情報を適正に管理するために必要な措置を講じなければならない」と定めています。

**指針（平成11年労働省告示第141号）。**個人情報の保管又は使用について、「収集目的の範囲に限られること。ただし、他の保管若しくは使用の目的を示して本人の同意を得た場合又は他の法律に定めのある場合はこの限りでないこと」と定めています。さらに「個人情報の適正な管理」の項で、講ずべき措置として次の四つを挙げています。

- イ 個人情報を目的に応じ必要な範囲において正確かつ最新のものに保つための措置
- ロ 個人情報の漏えい、滅失又は毀損を防止するための措置
- ハ 正当な権限を有しない者による個人情報へのアクセスを防止するための措置
- 二 **収集目的に照らして保管する必要がなくなった個人情報を破棄又は削除するための措置**

同項の柱書には、これらの措置を講ずるとともに「求職者等からの求めに応じ、当該措置の内容を説明しなければならないこと」とあります。**候補者から聞かれたら説明できる状態にしておく、ということです。**

つまり、年数を決めるための材料は二つです。一つは、その情報の**収集目的**が何だったか。もう一つは、その目的にとって**いつ必要がなくなるか**。この順番で考えます。

## 目的から逆算して期間を決める

採用で集める情報は、目的が混ざりがちです。ほどいて並べると、期間の目安が立ちます。

個人情報保護法第17条第1項は「個人情報を取り扱うに当たっては、その利用の目的（以下「利用目的」という。）をできる限り特定しなければならない」、第2項は、利用目的を変更する場合は「変更前の利用目的と関連性を有すると合理的に認められる範囲を超えて行ってはならない」と定めています。第21条第1項は「個人情報を取得した場合は、あらかじめその利用目的を公表している場合を除き、速やかに、その利用目的を、本人に通知し、又は公表しなければならない」、第2項は、契約書その他の書面に記載された本人の個人情報を取得する場合その他本人から直接書面に記載された個人情報を取得する場合は「あらかじめ、本人に対し、その利用目的を明示しなければならない」と定めています。

**目的を先に書くから、終わりが決まります。**「今回の募集職種の選考のため」と特定していれば、選考が終わった時点で目的が達成されます。「当社の採用活動全般のため」とだけ書いてあると、いつ終わるのかが決まらず、結果として消す判断ができなくなります。実務では、この曖昧さが「いつまでも残る」の正体です。

期間を決めるときに分けて考えるのは、次の四つです。

| 区分 | 考え方 |
|---|---|
| 不採用になった応募者 | 選考という目的は終わっている。第22条の「利用する必要がなくなったとき」に当たるかを検討する |
| 辞退した応募者 | 同上。加えて、辞退の理由の分析に使うなら、個人が分からない形にできないかを検討する |
| 内定に至らなかったが再応募を想定する人 | 目的が変わる。指針の「他の保管若しくは使用の目的を示して本人の同意を得た場合」の形にできるか |
| 採用に至った人 | 従業員の情報に変わる。労働関係の法令で保存が求められる書類があるため、別に確認する |

**タレントプールは、別の目的として立てます。**「将来またご案内するため」に情報を持ち続けるのは、当初の「今回の選考のため」という目的の範囲を超えます。指針は、収集目的の範囲を超える保管について「他の保管若しくは使用の目的を示して本人の同意を得た場合」を例外として挙げているので、目的を示して同意を取る形が素直です。同意を取っていないなら、保管の根拠が弱くなります。

**集計や分析は、個人が分からない形で残せることがあります。**応募経路ごとの通過率、選考期間、辞退の時期といった数字は、氏名や連絡先と切り離しても成り立ちます。個人が分からない形にできるなら、そちらに寄せると、保管の問題から外れます。

### エラベルの見解

担当する側から見ると、この相談は「何年ですか」と聞かれて始まるのに、答えを出すために必要なのは年数ではなく、**募集要項や応募フォームに何と書いてあるか**です。実際に見に行くと、利用目的の記載がないか、あっても「採用選考のため」の一行だけ、ということが多い。ここを直さずに保存年数だけ決めても、根拠が空のままです。最初の仕事は、応募の入口の文言を読むことです。

もう一つ、実務で効くのは、消す作業が現実に回るかを先に確かめることです。採用管理システムに一括削除の機能があるか、スプレッドシートや面接官の手元のメモにコピーが散っていないか、応募書類の紙が誰かの引き出しに残っていないか。「三年で削除する」と決めても、消す手順がなければ決めた意味がありません。逆に、消す手順が先に整っていれば、年数の議論は短く済みます。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、運用が回る形まで落とせる人は、採用管理の整理でそのまま指名されます。

## 会社に渡す保存ルール

副業の人事が作るのは、次の形です。年数そのものの妥当性や個別の適否の判断は、弁護士や個人情報保護委員会・ハローワーク・都道府県労働局にご確認ください。

| 作るもの | 中身 |
|---|---|
| 利用目的の文 | 応募フォーム・募集要項・面接案内に載せる。「できる限り特定」に耐える粒度で書く（第17条） |
| 通知・公表の形 | どこに掲示するか、いつ本人に伝えるか（第21条） |
| 区分ごとの期間 | 不採用者／辞退者／再応募想定／採用者。区分ごとに起算点と期間を書く |
| 起算点の定義 | 「選考終了日」「不採用通知日」など、日付が一意に決まる言葉にする |
| 保管場所の一覧 | 採用管理システム、共有フォルダ、メール、紙、面接官の手元。コピーが散る場所を全部書く |
| 削除の手順 | 誰が、いつ、どうやって消すか。年に何回の作業として回すか |
| 同意を取る形 | タレントプールに残す場合の、目的の示し方と同意の取り方、撤回の受け方 |
| 説明できる状態 | 指針は「求職者等からの求めに応じ、当該措置の内容を説明しなければならない」としている |
| 安全管理措置 | アクセスできる人を限る、持ち出しの扱いを決める（第23条、指針の管理措置） |

**紙とメールが残ります。**採用管理システムの削除だけを設計して終わる会社が多いのですが、実際に残っているのは、面接官に送った履歴書のPDF、共有フォルダの「選考用」フォルダ、印刷した応募書類、日程調整のメールスレッドです。保管場所の一覧を先に作ると、ここが見えます。

**マイナンバーは別扱いです。**採用に至った人から取得するマイナンバーは、別の法令の枠がかかります。[マイナンバーの取り扱い](/media/fukugyo-law-mynumber/)に整理しています。SNSの閲覧で得た情報の扱いは[SNSでの候補者調査の可否](/media/fukugyo-law-sns-chousa/)にまとめています。

### エラベルの見解

外に出してよいのは、利用目的の文案、区分と起算点の設計、保管場所の棚卸し、削除の手順、同意の取り方の設計、説明できる状態の整備までで、「この保存年数で法令上問題ないか」「この情報を残す根拠として足りるか」といった個別の判断は、弁護士や個人情報保護委員会の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この仕事の価値は、会社に「捨てる勇気」を持たせるところにあります。人事は情報を捨てたがりません。あとで必要になるかもしれない、という感覚があるからです。でも、条文が置いている起点は「利用する必要がなくなったとき」であって、「二度と使わないと言い切れるとき」ではありません。ここを言葉にして渡すと、決められるようになります。そのうえで、捨てて困る情報が本当にあるなら、それは目的を立て直して同意を取るべき情報だ、と整理できます。捨てる設計と残す設計を同時に出せるかが、この案件の分かれ目です。エラベルでは、依頼側が担当者を選べるので、採用管理の整理をやり切った経験は、経歴に書いておくと効きます。

## まとめ

- 法令が定めているのは年数ではなく方向。**個人情報保護法第22条**は「利用する必要がなくなったときは、当該個人データを遅滞なく消去するよう努めなければならない」と定めている
- 指針（平成11年労働省告示第141号）は、適正な管理の措置として「**収集目的に照らして保管する必要がなくなった個人情報を破棄又は削除するための措置**」を挙げている
- 職業安定法第5条の5は、**保管も「収集の目的の範囲内」**に限っている
- 期間を決める材料は、**収集目的が何だったか**と、**その目的にとっていつ必要がなくなるか**の二つ
- タレントプールに残すなら、指針の「**他の保管若しくは使用の目的を示して本人の同意を得た場合**」の形にできるかを検討する
- 指針は、措置の内容を**求職者等からの求めに応じて説明しなければならない**としている。個別の判断は弁護士や個人情報保護委員会にご確認ください

## よくある質問

### 応募者の情報は何年保存すればよいですか

法令に「応募者の情報は◯年」という定めは見当たりません。個人情報保護法第22条は「利用する必要がなくなったときは、当該個人データを遅滞なく消去するよう努めなければならない」と定め、指針（平成11年労働省告示第141号）は「収集目的に照らして保管する必要がなくなった個人情報を破棄又は削除するための措置」を挙げています。したがって、まず応募のときに示した利用目的を確認し、その目的がいつ達成されるかから逆算して、会社として期間を決める形になります。採用に至った人の書類は労働関係の法令で保存が求められるものがあるため、別に確認します。個別の判断は弁護士や個人情報保護委員会にご確認ください。

### 不採用になった人を、次の募集のために残しておきたいと言われました

「今回の選考のため」という目的で集めた情報を、将来の募集の案内に使うのは、当初の目的の範囲を超えます。指針は、収集目的の範囲を超える保管について「他の保管若しくは使用の目的を示して本人の同意を得た場合」を例外として挙げているので、目的を示して同意を取る形にできるかを検討します。実務では、不採用の通知にあわせて「今後のご案内のために情報を保持してよいか」を確認し、希望する人だけ残す形にすることがあります。個人情報保護法第17条第2項は、利用目的の変更を「変更前の利用目的と関連性を有すると合理的に認められる範囲」に限っています。設計の適否は弁護士や個人情報保護委員会にご確認ください。

### 候補者から「私の情報をどう管理しているのか」と聞かれました

指針（平成11年労働省告示第141号）は、個人情報の適正な管理について、正確性・最新性の確保、漏えい・滅失・毀損の防止、権限のない者によるアクセスの防止、保管する必要がなくなった情報の破棄・削除、という四つの措置を挙げたうえで、「求職者等からの求めに応じ、当該措置の内容を説明しなければならないこと」と定めています。説明できる形を先に作っておくのが実務です。具体的には、利用目的、保存の区分と期間、アクセスできる人の範囲、削除の手順を一枚にまとめておきます。回答の内容や範囲の個別の判断は、弁護士や個人情報保護委員会にご確認ください。
