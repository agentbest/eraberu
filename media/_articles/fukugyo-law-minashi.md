副業で人事を受けて求人票を見ると、固定残業代は最初に目が止まる項目です。「月給30万円（みなし残業45時間含む）」とだけ書かれている、基本給の額が書かれていない、超過分の追加支払が書かれていない。結論を先に書くと、**厚生労働省・都道府県労働局・ハローワークのリーフレットは「固定残業代制を採用する場合は、募集要項や求人票などに、次の①～③の内容すべてを明示してください」として、①固定残業代を除いた基本給の額、②固定残業代に関する労働時間数と金額等の計算方法、③固定残業時間を超える時間外労働、休日労働および深夜労働に対して割増賃金を追加で支払う旨、の三つを挙げています。**個別の判断は労働基準監督署にご確認ください。求人票全体の書き方は[求人情報の的確表示義務](/media/fukugyo-law-koushin-jouhou/)に、割増賃金の枠は[休憩・休日のルール](/media/fukugyo-law-kyuukei/)にまとめています。

## 二つの要件

**出発点は第37条。**労働基準法第37条第1項は、時間外・休日労働について「通常の労働時間又は労働日の賃金の計算額の二割五分以上五割以下の範囲内でそれぞれ**政令で定める率以上の率**で計算した割増賃金を支払わなければならない」と定めています。固定残業代は、この支払を定額で先に行う仕組みであって、**支払義務を免れる制度ではありません**。

**厚生労働省の裁判例の整理。**「確かめよう労働条件」の割増賃金不払いのページは、固定残業制について**基本給とは別に、割増賃金相当部分を明確に区別することが必要**であり、**法定額を下回る場合は差額の支払が必要**である、という方向を示したうえで、次の裁判例を挙げています。

**小里機材事件（最一小判 昭和63年7月14日）。**「基本給のうち時間外労働手当に当たる部分を**明確に区別して合意**し、かつ、労働基準法所定の計算方法による額がその額を上回るときは**その差額を当該賃金の支払期に支払うことを合意**した場合にのみ」対応できる、という整理が示されています。

**テックジャパン事件（最一小判 平成24年3月8日）。**月額四十一万円全体が基本給とされ、時間外部分が他と区別されていない場合について「**通常の労働時間の賃金に当たる部分と時間外の割増賃金に当たる部分とを判別することはできない**」と判示されています。

**日本ケミカル事件（最一小判 平成30年7月19日）。**当該手当が時間外労働等に対する対価として支払われるものとされているか否かは「**雇用契約書等の記載内容のほか、使用者の労働者に対する当該手当や割増賃金に関する説明の内容、労働者の実際の労働時間等の勤務状況などの事情を考慮して判断すべき**」とされています。

**国際自動車事件（最一小判 令和2年3月30日）。**「**通常の労働時間の賃金に当たる部分と同条の定める割増賃金に当たる部分とを判別することができることが必要**」という点が示されています。

**熊本総合運輸事件（最二小判 令和5年3月10日）。**実質的に通常の賃金に充てられる部分が名目上割増金に含まれる場合、判別はできない、と判示されています。

**整理すると、二つです。**一つは**判別できること**。通常の労働時間の賃金に当たる部分と、割増賃金に当たる部分が分けられること。もう一つは**対価性**。その手当が時間外労働等の対価として支払われるものとされていること。そして、**法定額が固定額を上回るときは差額を支払う**ことが前提になります。

**ハローワークのリーフレットも裁判例を引いています。**同リーフレットは、時間外割増賃金をめぐるトラブルの例として、月額四十一万円の基本給について「通常の労働時間の賃金に当たる部分と労働基準法第37条第1項の規定する時間外の割増賃金に当たる部分とを判別することはできないものというべきである」とした裁判例、販売手当について「各店舗の売上等に応じて支給されるものであり、これが従業員が時間外労働や深夜労働をした場合に支給される割増賃金と同様の性質を有するものとはいい難い」とした裁判例、そして「少なくとも労働者が自分が当月働いた分についてどれだけの時間外労働がなされ、それに対していくらの割増賃金が出ているのかを**概算的にでも有効・適切に知ることができなければ**、労使の合意に基づいた労働条件の中身としての賃金なり給与条件の合意が成立したことにはならない」とした裁判例を紹介しています。

## 求人票と契約書に書くこと

**若者雇用促進法に基づく指針。**同リーフレットが引用する指針の抜粋はこうです。「青少年が応募する可能性のある募集又は求人について、一定時間分の時間外労働、休日労働及び深夜労働に対する割増賃金を定額で支払うこととする労働契約を締結する仕組みを採用する場合は、**名称のいかんにかかわらず**、…固定残業代に係る**計算方法（固定残業代の算定の基礎として設定する労働時間数（固定残業時間）及び金額を明らかにするものに限る。）**、**固定残業代を除外した基本給の額**、**固定残業時間を超える時間外労働、休日労働及び深夜労働分についての割増賃金を追加で支払うこと**等を明示すること」。

**「名称のいかんにかかわらず」。**営業手当、職務手当、業務手当といった名前でも、実質が一定時間分の割増賃金の定額払いであれば、固定残業代として扱われます。同リーフレットも「『固定残業代』とは、**その名称にかかわらず**、一定時間分の時間外労働、休日労働および深夜労働に対して定額で支払われる割増賃金のことです」としています。

**記載例。**リーフレットは、時間外労働について固定残業代制を採用している場合の記載例として、次の形を示しています。

- ① **基本給（××円）**（②の手当を除く額）
- ② **□□手当**（時間外労働の有無にかかわらず、**○時間分**の時間外手当として**△△円**を支給）
- ③ **○時間を超える時間外労働分についての割増賃金は追加で支給**

注意点として、「□□」には固定残業代に該当する手当の名称を記載すること、「□□手当」に固定残業代以外の手当を含む場合は**固定残業代分を分けて記載**すること、**深夜労働や休日労働について固定残業代制を採用する場合も同様の記載が必要**であること、が挙げられています。

**職業安定法の指針も同じ内容です。**平成11年労働省告示第141号の指針は、労働条件等の明示に当たって、一定時間分の割増賃金を定額で支払う仕組みを採用する場合は、名称のいかんにかかわらず、固定残業代に係る計算方法（固定残業時間および金額を明らかにするものに限る）、固定残業代を除外した基本給の額、固定残業時間を超える分の割増賃金を追加で支払うこと等を明示すること、としています。**若者向けに限らず、募集全般にかかる形です。**

### エラベルの見解

担当する側から見ると、固定残業代の点検は**入って一週間でできて、効果が大きい**仕事の筆頭です。求人票を見れば、三点のうち何が欠けているかがすぐ分かります。そして、直すのに予算も稟議も要りません。

ただ、伝え方には順番があります。「法令違反の可能性があります」から入ると、採用担当は身構えます。実務で通りやすいのは、**応募者の視点に翻訳すること**です。「この書き方だと、内定を出した後で『聞いていた金額と違う』と言われます」「入社三か月で辞めた人の理由、たぶんここです」。会社が損をする話にすると、判断が早くなります。

そのうえで、もっと深い問題に触れます。固定残業代の時間数が四十五時間に設定されている会社は、**その時間を前提に人員計画を立てている**ということです。つまり、慢性的に月四十五時間の残業が発生する設計で採用している。ここに手をつけずに求人票だけ直しても、入社後の実態は変わりません。

だから、時間数の設定そのものを議論に載せます。直近一年の実際の残業時間を職種別に出して、固定残業の時間数と比べる。実態が二十時間なら、四十五時間の設定は応募者を遠ざけるだけです。逆に実態が六十時間なら、設定の問題ではなく業務量の問題です。**求人票の点検が、要員計画の見直しに接続する**のが、この案件の面白いところです。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この往復ができる人は、採用全体を任されやすくなります。

## 点検の手順

副業の人事が作るのは、次の形です。個別の適否の判断は労働基準監督署や社会保険労務士、弁護士にご確認ください。

| 点検する項目 | 見るところ |
|---|---|
| 該当の有無 | 名称にかかわらず、一定時間分の割増賃金の定額払いになっている手当がないか |
| 判別できるか | 通常の労働時間の賃金に当たる部分と、割増賃金に当たる部分が分かれているか |
| 対価性 | その手当が時間外労働等の対価として支払われるものとされているか。契約書・規程の記載、説明の内容 |
| 時間数と金額 | 固定残業代の**算定の基礎となる労働時間数**と**金額**が明らかになっているか |
| 基本給の額 | 固定残業代を**除外した**基本給の額が示されているか |
| 超過分の扱い | 固定残業時間を超えた分の割増賃金を**追加で支払う**旨が書かれているか。実際に払っているか |
| 差額の計算 | 法定の計算による額が固定額を上回るときの差額を、当該賃金の支払期に払う運用になっているか |
| 深夜・休日 | 深夜労働や休日労働について固定残業代制を採っているなら、同様の記載があるか |
| 本人が知れるか | 当月の時間外労働と割増賃金を、本人が概算でも知ることができる状態か |
| 就業規則・規程 | 賃金規程に固定残業代の定めがあるか。求人票・契約書と一致しているか |
| 求人票 | 三点が揃っているか。媒体ごとの表示も確かめる |
| 労働条件通知書 | [雇用契約書に書くこと](/media/fukugyo-law-koyou-keiyaku/)の明示事項と整合しているか |

**「本人が知れるか」を忘れないこと。**リーフレットが引用する裁判例は、労働者が当月の時間外労働と割増賃金を概算的にでも有効・適切に知ることができなければ合意が成立したことにはならない、という趣旨を示しています。給与明細に固定残業代の時間数と金額、当月の実際の時間外労働時間、超過分の支給額が表示されているかを確かめます。

**時間数の上限。**固定残業代の時間数そのものに条文上の上限はありませんが、三六協定の限度時間（原則として月四十五時間・年三百六十時間）や、第36条第6項の絶対的な上限との整合は確かめます。限度時間を超える時間数を前提にした設定は、三六協定の設計から見直す話になります。

**廃止・変更は不利益変更の問題になり得ます。**固定残業代を見直すときは、[就業規則を変更する手続き](/media/fukugyo-law-shugyo-kisoku-henkou/)の枠で考えます。個別の判断は弁護士にご確認ください。

### エラベルの見解

外に出してよいのは、点検表、求人票と契約書の記載案、給与明細の表示項目、実際の残業時間との比較資料、見直しの段取りまでで、「この手当が固定残業代として有効か」「過去分の差額をどう扱うか」といった個別の判断は、労働基準監督署や社会保険労務士、弁護士の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この領域で気をつけるのは**過去分の話を先に出さないこと**です。判別できない固定残業代が見つかると、過去に遡る問題が視野に入ります。ここを最初に言うと、会社は固まり、直すこと自体をやめようとします。

実務では、まず「これから先をどう直すか」だけを扱います。求人票の書き方、契約書の記載、給与明細の表示、超過分の支払の運用。ここまで進めると、会社のほうから「過去はどうすればよいか」と聞いてきます。そこで初めて、弁護士や社会保険労務士に相談する段取りを組みます。順番を逆にすると、案件が止まります。

そして、この案件の最終的な着地は、たいてい**「固定残業代をやめる」**です。三点を正しく書き、超過分を毎月計算して払い、明細に表示する。ここまでやると、実は普通に時間外労働の割増賃金を計算するのと手間が変わりません。であれば、求人票に「月給25万円＋残業代全額支給」と書いたほうが、応募者にも分かりやすく、社内の運用も簡単になります。**制度を外す提案ができるかどうか**が、この領域で経験が効くところです。エラベルでは、依頼側が担当者を選べるので、この結論まで導いた経験は、経歴に書いておくと効きます。

## まとめ

- 固定残業代は、労働基準法第37条の**支払義務を免れる制度ではない**。法定額が上回るときは**差額の支払**が前提
- 厚生労働省の裁判例の整理が示す二つの要件は、**判別できること**（通常の労働時間の賃金に当たる部分と割増賃金に当たる部分が分けられること）と、**対価性**（その手当が時間外労働等の対価として支払われるものとされていること）
- 対価性の判断は、**契約書等の記載内容のほか、説明の内容、実際の労働時間等の勤務状況**などの事情を考慮して行うとされている（日本ケミカル事件）
- 求人票・募集要項には、**①固定残業代を除いた基本給の額／②固定残業代に関する労働時間数と金額等の計算方法／③固定残業時間を超える分の割増賃金を追加で支払う旨**の三点すべてを明示する
- **名称のいかんにかかわらず**、実質が一定時間分の割増賃金の定額払いであれば固定残業代として扱われる
- 労働者が当月の時間外労働と割増賃金を**概算的にでも知ることができる**状態が求められる、という裁判例が紹介されている。個別の判断は労働基準監督署や弁護士にご確認ください

## よくある質問

### 「営業手当」という名前なら固定残業代になりませんか

厚生労働省・都道府県労働局・ハローワークのリーフレットは「『固定残業代』とは、その名称にかかわらず、一定時間分の時間外労働、休日労働および深夜労働に対して定額で支払われる割増賃金のことです」としています。若者雇用促進法に基づく指針も「名称のいかんにかかわらず」と書いています。したがって、手当の名前ではなく実質で判断されます。一方で、実際に売上等に応じて支給される手当について、割増賃金と同様の性質を有するものとはいい難いとした裁判例も紹介されています。自社の手当の性格の判断は、労働基準監督署や弁護士にご確認ください。

### 固定残業時間を超えた月は、どうすればよいですか

厚生労働省の裁判例の整理は、法定額が固定額を上回るときは差額の支払が必要である、という方向を示しています。小里機材事件の整理でも、労働基準法所定の計算方法による額がその額を上回るときは、その差額を当該賃金の支払期に支払うことを合意した場合に対応できる、とされています。求人票の三点明示にも「固定残業時間を超える時間外労働、休日労働および深夜労働に対して割増賃金を追加で支払う旨」が含まれています。実務では、毎月の実際の時間外労働時間を計算し、超過分を当該支払期に支払う運用と、給与明細での表示を整えます。個別の計算は社会保険労務士にご確認ください。

### 求人票には「月給30万円（みなし残業45時間含む）」だけでは足りませんか

厚生労働省・都道府県労働局・ハローワークのリーフレットは、固定残業代制を採用する場合に募集要項や求人票などに明示すべき内容として、①固定残業代を除いた基本給の額、②固定残業代に関する労働時間数と金額等の計算方法、③固定残業時間を超える時間外労働、休日労働および深夜労働に対して割増賃金を追加で支払う旨、の三つすべてを挙げています。金額の総額と時間数だけでは、①の基本給の額と③の追加支払が欠けます。記載例として「基本給（××円）」「□□手当（○時間分の時間外手当として△△円を支給）」「○時間を超える時間外労働分についての割増賃金は追加で支給」という形が示されています。個別の記載の適否は、ハローワークや労働基準監督署にご確認ください。
