採用の副業は、入社日で「完了」と扱われることが多い。ただ、入社した人が半年で辞めれば、依頼側にとって採用は成功していません。そして、辞めた理由の多くは、要件・求人票・面接・内定後のどこかにあり、入社後に戻って見なければ、次の採用で同じことが起きます。「定着まで見る」は、入社後の人の面倒を見ることではなく、採用の記録を入社後の事実で確かめることです。結論を先に書くと、**定着は、三か月・半年・一年の三つの節目で、面接の観点と求人票の「任せる仕事」を項目に、現場の責任者から一行ずつ受け取り、離職が出たときは採用のどの段階のずれかを分け、数字で断定せず、担当者は記録に戻すところまでを行います。**入社後の設計は[オンボーディングを設計する](/media/fukugyo-skill-onboarding/)に、判断と結果の突き合わせは[見極めの精度を上げる](/media/fukugyo-skill-mikiwame/)に書いています。ここでは、節目の型に絞ります。

## 入社で区切ると直らない

| 入社で区切ると | 何が起きるか |
|---|---|
| 要件の必須が実態と合っていたかが分からない | 次の採用でも同じ必須で探す |
| 面接で「通す」と判断した観点が正しかったかが分からない | 基準が直らない |
| 求人票の「任せる仕事」と実際の仕事のずれが見えない | 次の候補者にも同じ求人票を見せる |
| 内定後の接点が足りていたかが分からない | 辞退と早期離職が続く |
| 辞めた理由が「本人の事情」で片付く | 採用の側に戻る材料が無い |

採用の成果は、入社ではなく、入社した人が「面接で聞いた役割を、実際に担っている」状態です。それを確かめるのが、定着まで見ることです。

## 三つの節目で見ること

| 節目 | 見ること | 何のために |
|---|---|---|
| 三か月 | 求人票の「最初の三か月」の到達点に届いたか。「思っていたのと違うこと」は何か | 求人票と面接で渡した見通しと、実際のずれ |
| 半年 | 求人票の「任せる仕事」を一人で回しているか。面接で「迷う」だった観点がどう見えているか | 要件と面接の基準の確かめ |
| 一年 | 役割が広がっているか、固定されているか。本人が「次」をどう見ているか（現場の責任者の見立て） | ターゲット像の「動く理由」が満たされているか。求人票の「得られるもの」の実態 |

節目の時期は依頼側の決まりに従います。三つ全部を担当者が見られないことも多いので、少なくとも三か月の一枚は残します。

### エラベルの見解

担当する側から見ると、定着で最も差がつくのは、見る項目を「面接の観点と求人票の言葉」に限れるかどうかです。受ける側は、入社後の様子を聞くときに、「頑張っていますか」「馴染んでいますか」と聞きます。返ってくるのは印象で、採用の記録には戻せません。「面接で『決まりの無いことを自分で決めて進めた』を観点にしましたが、入社後にその場面はありましたか」「求人票の『〇〇を一人で回す』は、いまどの段階ですか」と、採用の記録の言葉で聞くと、事実が返り、要件と面接に戻せます。エラベルで担当者を選ぶ企業には、「入社した方の様子を、面接の観点の言葉で現場に聞いていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、節目の一枚を、評価シートの観点と求人票の「任せる仕事」をそのまま項目にして作ること。新しい項目を足さない。

## 節目の一枚

| 項目 | 中身 | 誰が書くか |
|---|---|---|
| 面接の観点（三つ前後） | 各観点で「入社後、どう見えているか」を一行 | 現場の責任者 |
| 求人票の「任せる仕事」 | 各仕事で「聞きながら」「一人で」「教える側」のどれか | 現場の責任者 |
| 「思っていたのと違うこと」 | 本人が確認の接点で言ったこと。要約 | 現場の責任者（本人から聞いた範囲で） |
| ずれの場所 | 求人票・面接・内定後・受け入れのどれか | 担当者が案を書き、依頼側が確認 |
| 次の採用に戻すこと | 要件の必須、面接の基準、求人票の言葉のどれをどう直すか | 担当者が案を書き、依頼側が決める |

一枚に、人事評価の点数、給与、私的な事情、健康の状態は書きません。本人の氏名は依頼側の記録にあるので、担当者の一枚には応募の番号で足ります。記録の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## 離職が出たときに分ける

| ずれの場所 | 見分ける問い | 戻す先 |
|---|---|---|
| 要件 | 面接では全観点「通す」だったのに、仕事が回らなかった | 必須と観点の見直し。[採用要件を引き出すヒアリングの型](/media/fukugyo-skill-youken-hearing/) |
| 求人票 | 「思っていたのと違う」が、任せる仕事や一緒に働く人の記述と実態の差だった | 求人票の言葉を実態に。[求人原稿を書き直す手順](/media/fukugyo-skill-kyujin-genkou/) |
| 面接 | 「迷う」が引き継がれずに通った。基準に無い理由で通した | 面接の設計と基準。[面接の設計](/media/fukugyo-skill-mensetsu-sekkei/) |
| 内定後 | 入社前に迷いが残っていた。接点が無かった | 内定後の接点。[内定辞退を減らす](/media/fukugyo-skill-jitai-boushi/) |
| 受け入れ | 到達点と担当が無く放置された | オンボーディングの五つ。[オンボーディングを設計する](/media/fukugyo-skill-onboarding/) |
| 本人の事情 | 上のどれにも当たらない | 戻す先は無い。記録に残すだけ |

「本人の事情」に片付けるのは、上の五つを確かめた後です。先に片付けると、採用の側に戻る材料が消えます。離職の時期と理由の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に、職種ごとの構造は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)や[新卒が定着しない](/media/rpo-shinsotsu-teichaku/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「定着率を上げることを、採用の成果として約束できる」というものです。定着には、採用の側では手当てできないこと（本人の事情、会社の方針の変化、上司の異動）が含まれます。「定着率〇%を目指します」と言うと、採用の側で直せない理由で下がったときに、担当者の信頼が落ちます。担当者ができるのは、「離職が出たときに、採用のどの段階のずれかを分けて、次の採用に戻す」ことまでです。受ける側がその場で使える判断としては、定着に関わる契約や提案で、成果を「節目の一枚を残し、離職のずれの場所を分けて戻すこと」と書き、定着率の数字を約束しないこと。数字は自分が見た件数として伝え、割合で断定しません。数字の伝え方は[数字で語る](/media/fukugyo-suuji/)に書いています。

## 担当者が本人と直接接する範囲

| 契約の範囲 | 担当者がやること |
|---|---|
| 記録だけ | 節目の一枚を現場の責任者から受け取り、ずれの場所を分けて依頼側に渡す。本人には接しない |
| 接点あり | 依頼側の決まりの範囲で、節目に本人と短く話す。聞くのは「思っていたのと違うこと」だけ。相談相手にはならない |
| 相談の窓口 | 依頼側の人事の領域。担当者は担わない。本人から相談があれば依頼側の窓口に渡す |

本人と話す場合も、担当者は「採用の側の人」であって、本人の相談相手や評価者ではありません。本人の私的な事情、健康の状態、上司への不満などを聞いても記録せず、依頼側の人事の窓口に渡します。範囲は契約に書きます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## 踏み込まない線

| 線 | 理由 |
|---|---|
| 人事評価に関わらない | 節目の一枚は採用の確かめのためで、評価のためではない |
| 労務・契約・試用期間の扱いに関わらない | 法令上の整理がある事項。依頼側の決まりと専門家の確認に従う |
| 本人を引き止めない | 離職は本人の判断。担当者はずれの場所を分けるまで |
| 上司の評価をしない | 「受け入れのずれ」は設計の問題として返す。人の評価にしない |
| 定着率を約束しない | 採用の側で直せない理由が含まれる |

入社後の扱いに法令が関わる場合は、個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 現場が「頑張っていますよ」としか言わない | 面接の観点と求人票の言葉で聞く。一行ずつ埋める形の一枚を渡す |
| 節目が来る前に案件が終わる | 三か月の一枚を依頼側に渡し、実施は依頼側。次の案件の冒頭で読む |
| 離職の理由が「本人の事情」で片付く | 五つのずれを先に確かめる。当たらなければ本人の事情 |
| 依頼側が定着率の約束を求める | 成果を「節目の一枚とずれの場所を戻すこと」と書く。数字は約束しない |
| 本人が担当者に相談してくる | 依頼側の窓口に渡す。担当者は記録しない |

## まとめ

- 採用の成果は入社ではなく、**面接で聞いた役割を実際に担っている状態**。入社で区切ると要件も面接も直らない
- 節目は**三か月・半年・一年**。少なくとも三か月の一枚は残す
- 見る項目は**面接の観点と求人票の「任せる仕事」**。「頑張っていますか」と聞かない
- 一枚は**現場の責任者が一行ずつ**。人事評価・私的な事情・健康の状態は書かない
- 離職は**要件・求人票・面接・内定後・受け入れ**のどれのずれかを分けてから、本人の事情
- **定着率を約束しない**。数字は件数として、割合で断定しない
- 人事評価・労務・引き止め・上司の評価に踏み込まない。**個別の判断は専門家にご確認ください**

## よくある質問

### 依頼側が「入社したら採用の仕事は終わり。入社後は見なくてよい」と言います

入社後を見ないと、次の採用で同じ要件・同じ求人票・同じ面接を繰り返すことになる、という構造を伝えます。三か月の一枚だけでも、現場の責任者が一行ずつ書けば、要件と面接の確かめができます。「入社後の人の面倒を見る」のではなく、「採用の記録を確かめる」ためだと、目的を分けて説明します。それでも不要と言われれば、一枚の形だけを渡し、実施は依頼側の判断に残します。

### 半年後に辞めた人がいて、依頼側が「面接で見抜けなかった」と言います

見抜けなかったのか、要件がずれていたのか、受け入れの問題かを、記録で分けます。面接の評価シートを開き、その人の観点ごとの判断を見ます。「迷う」があって引き継がれていなければ設計の問題、全部「通す」で仕事が回らなかったなら要件の問題、仕事は回っていて「思っていたのと違う」で辞めたなら求人票か受け入れの問題です。面接官の目の問題に着地させず、直す場所を示します。

### 定着まで見る仕事は、単価や稼働にどう入れますか

節目ごとに「一枚を受け取り、ずれの場所を分けて依頼側に渡す」を一単位として、稼働は短く見積もります。本人と話す接点を含めるかで稼働が変わるので、契約の範囲で分けます。定着率の成果報酬の形は、採用の側で直せない理由が含まれるため、担当者の側からは提案しません。契約の形は[業務範囲を書面で固める](/media/fukugyo-scope/)と[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。
