人事の副業を考えたとき、地方に住んでいることが不利になるのではないかと心配する人は多い。案件は都市部の会社が出すものが多く、対面の打ち合わせや面接の同席を求められたら受けられない。地元の会社は数が少なく、副業の人事に頼む習慣も無さそうに見える。結論を先に書くと、**人事の副業のうち、依頼側の需要が多い業務（スカウト運用、求人票、一次対応、記録）は遠隔で完結するので、地方在住でも受けられます。**住んでいる場所が影響するのは、面接の同席や説明会の運営のように現地が要る業務で、それを範囲から外せば、都市部の会社の案件も受けられます。範囲の決め方は[案件の範囲の決め方](/media/fukugyo-scope/)に、相手の規模の選び方は[企業規模で絞るという戦い方](/media/fukugyo-kibo-tokka/)にまとめています。

## 場所が影響する業務と、しない業務

人事の業務を、現地が要るかどうかで分けると、地方在住で受けられる範囲が見えます。

| 業務 | 現地が要るか | 遠隔で受ける条件 |
|---|---|---|
| スカウトの文面作成と送信 | 要らない | 媒体の権限を依頼側からもらう |
| 求人票の作成 | 要らない | 依頼側と一度、業務内容を聞く時間 |
| 応募者への一次対応（連絡、日程調整） | 要らない | 依頼側の連絡ツールを使う |
| 書類選考の一次絞り込み | 要らない | 基準を依頼側と決める。合否は依頼側 |
| 面接の記録、評価のまとめ | 要らない | オンライン面接に同席するか、記録を受け取る |
| 選考の進捗管理 | 要らない | 管理の表を共有 |
| 面接の同席（対面） | 要る | 範囲から外すか、オンラインに限る |
| 会社説明会、学校訪問 | 要る | 範囲から外す |
| 社内の関係者との調整 | 場合による | オンラインで足りるかを面談で確認 |
| 労務の手続き（書類の受け渡し） | 場合による | 電子化されていれば遠隔。紙なら外す |

切り分けの要点は、「依頼側の需要が多い業務ほど、遠隔で完結する」ことです。人事が一人の会社が手が回らないのは、スカウトの送信、応募者への連絡、記録といった、日々の量のある業務で、これらは場所を選びません。現地が要る業務は、依頼側もそもそも副業の人に頼むことが少ない。

## 遠隔で受けるための条件

遠隔で受けるには、依頼側との間で整えることがあります。面談で確認し、書面に入れます。

| 条件 | 内容 | 整っていないと |
|---|---|---|
| 連絡の手段と頻度 | どのツールで、週に何回、どの時間帯に | 連絡がつかず、止まる |
| 権限と情報の受け渡し | 媒体の権限、応募者情報、社内の連絡先をどう渡すか | 稼働できない、または自分の端末に情報が残る |
| 情報の扱い | 依頼側の規程に従う。自分の端末に残さない。個人情報の扱いは慎重に | 情報の事故になる |
| 相談相手 | 判断を仰ぐ相手が誰で、どのくらいで返事が来るか | 判断待ちで止まる |
| 稼働の見える化 | 日付、時間、やったことを、依頼側に見える形で記録。[稼働管理の方法](/media/fukugyo-kadou-kanri/) | 遠隔だと働きが見えず、信頼が育たない |
| 現地が要る場面の扱い | 現地が要る業務は範囲外と書面に。要る場合の交通費と時間の扱い | 呼ばれたときに揉める |
| 時差や生活時間 | 依頼側の稼働時間と自分の時間帯が合うか | 連絡の時間がずれる |

条件の要点は、「稼働の見える化を、対面より丁寧にする」ことです。同じ場所にいれば、働きぶりは見えます。遠隔では、記録と報告でしか見えません。週に一度の短い確認と、稼働の記録を書面に入れておくと、依頼側は安心し、自分は稼働の根拠を残せます。

### エラベルの見解

登録の相談で多いのは、「地方なので、地元の会社しか受けられないと思っていた」という声です。実際には、登録先で出る案件の多くは、スカウトの運用や一次対応のように場所を選ばない業務で、依頼側も遠隔を前提にしています。地元に絞る必要は無く、業務の型で受けられるかを見れば足ります。

見ていて差がつくのは、「現地が要る業務を、含まないことに明記しているか」です。「面接の対面同席と説明会の運営は含みません。オンラインの面接同席は可能です」と書いてあれば、依頼側は遠隔前提で頼めるかをその場で判断できます。書いていないと、面談で「来られますか」と聞かれ、そこで止まります。エラベルの登録でも、含まないことに現地の業務を書いている人は、地方在住でも都市部の会社の案件で連絡が来ています。

## 地元の会社と、都市部の会社の選び方

地方在住の人が受ける相手は、地元の会社と、都市部の会社（遠隔）の二つに分かれます。どちらを選ぶかの観点です。

| 観点 | 地元の会社 | 都市部の会社（遠隔） |
|---|---|---|
| 案件の数 | 少ない。副業の人事に頼む習慣が無いことも | 多い。遠隔前提の案件が多い |
| 接点の作り方 | 地元のつながり、商工会、勉強会。[勉強会・イベントからの接点](/media/fukugyo-benkyoukai/) | 登録先、発信、オンラインのコミュニティ |
| 現地の業務 | 受けられる。売りになる | 範囲から外す |
| 地域の採用市場の知識 | 売りになる。地元の候補者像と経路を知っている | 使いにくい |
| 本業との距離 | 近い。競合や取引先と重なりやすい。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/) | 遠い。線が引きやすい |
| 単価 | 地域の相場に引かれることがある | 業務の型と数で決めやすい |
| 関係の作り方 | 対面で信頼が育ちやすい | 記録と報告で育てる |

選び方の要点は、「地元は売りが大きく、本業との距離が近い。都市部は案件が多く、線が引きやすい」ということです。始めたばかりなら、本業との線が引きやすい都市部の会社の遠隔案件から入り、地元は地域の採用市場の知識が売りになる案件に絞る、という組み合わせが無理がありません。

## 地方在住ならではの売り

地方在住は、不利な面だけではありません。売りになる面もあります。

| 売り | 内容 | 活きる相手 |
|---|---|---|
| 地域の採用市場を知っている | 地元の候補者像、経路（学校、ハローワーク、地元媒体）、賃金の感覚 | その地域で採用したい都市部の会社。地元の会社 |
| 地方採用・移住採用の型 | 地方に人を呼ぶ採用で、候補者が気にすること | 地方に拠点を持つ会社。移住採用をしたい会社 |
| 時間帯の融通 | 都市部の会社と生活時間がずれることを、逆に使える | 早朝や夜の対応が要る会社 |
| 対面の少なさに慣れている | 遠隔の仕事の進め方を、日常的にしている | 遠隔前提の会社 |
| 地元の会社への理解 | 人事がいない地元の会社の事情を分かっている | 地元の小規模の会社 |

売りの要点は、「地域の採用市場の知識は、都市部の人事には無い」ことです。都市部の会社が地方の拠点で採用するとき、地元の候補者像と経路を知っている人は、業務の型に加えて、地域の型を持っています。これは、地方在住の人にしか出せない売りです。

## 地方在住で起きやすい失敗

地方在住で副業を受けるときに起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 地元だけで探す | 地方だから地元しか無理だと思う | 遠隔で完結する業務なら、場所を問わない |
| 現地が要る業務を含めてしまう | 範囲を広く書く | 含まないことに、対面の同席と説明会を明記 |
| 遠隔なのに稼働が見えない | 記録と報告が薄い | 稼働の記録と週一の確認を書面に |
| 呼ばれたときの扱いが決まっていない | 現地が要る場面を想定していない | 交通費と時間の扱いを書面に。原則は範囲外 |
| 地元の相場で単価が下がる | 地域の賃金感覚で決める | 業務の型と数で単価を説明。[最初の一件の価格の決め方](/media/fukugyo-shoninka/) |
| 本業と地元の会社が重なる | 地元は狭く、競合や取引先と重なる | 本業との線を先に。地元は地域の知識が売りになる案件に絞る |
| 情報が自分の端末に残る | 遠隔で情報を受け取り、保管の場所を決めていない | 依頼側の環境で作業。端末に残さない |
| 地域の知識を売りにしていない | 業務の型だけで勝負する | 地域の採用市場の知識を、プロフィールに一行 |

失敗の要点は、「場所を理由に範囲を狭めすぎるか、逆に現地の業務まで含めてしまうか」の両極です。遠隔で完結する業務を範囲にし、現地が要る業務を含まないことに書けば、場所は問題になりません。

### エラベルの見解

担当する側として登録した人の話を聞くと、地方在住で続いている人は、「場所を問わない業務」と「地域の知識が売りになる業務」を分けて、両方を持っています。都市部の会社のスカウト運用を遠隔で受けながら、地元で採用したい会社には地域の候補者像と経路を売りにする。この二本立てで、案件の数と売りの両方を確保しています。

エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口です。案件の多くは遠隔前提で、依頼側も場所を問いません。登録の含まないことに現地の業務を書いていただければ、対面が要る案件はご連絡せず、遠隔で完結する案件だけをお伝えできます。地方在住であることが、案件の連絡を減らす理由にはなっていません。

## まとめ

- 需要の多い業務（**スカウト運用・求人票・一次対応・記録**）は遠隔で完結する。地方在住でも受けられる
- 場所が影響するのは**対面の面接同席・説明会・紙の書類**。含まないことに明記する
- 遠隔で受ける条件は**連絡の手段と頻度・権限と情報の受け渡し・情報の扱い・相談相手・稼働の見える化・現地の扱い・時間帯**
- 始めたばかりなら**本業との線が引きやすい都市部の遠隔案件**から。地元は**地域の知識が売りになる案件**に絞る
- 地方在住の売りは**地域の採用市場の知識・地方採用の型・時間帯の融通・遠隔の慣れ**
- 失敗は**地元だけで探す・現地の業務を含める・稼働が見えない・地元の相場で下がる・本業と重なる**

## よくある質問

### 依頼側から「一度は会いたい」と言われました。行くべきですか

最初の面談は、オンラインで足りることが多いです。依頼側が対面を希望する場合は、交通費と時間の扱いを先に決めたうえで、受けるかを判断します。一度の対面が、その後の遠隔の稼働の信頼につながることはありますが、往復の時間と費用が稼働の対価と見合うかを見てください。対面を条件にする依頼側なら、遠隔で完結する業務を頼む前提になっていない可能性があるので、面談で稼働の形を確認します。

### 地元の会社に、副業の人事を使う習慣がありません。どう接点を作ればよいですか

地元の会社は、副業の人事という形を知らないことが多いので、「副業の人事です」ではなく、「採用のこの業務を、週この時間で手伝えます」と、業務と時間で伝えると分かりやすい。接点は、地元の勉強会や商工会、知人の紹介から。地域の採用市場の知識（地元の候補者像、経路）を一言添えると、都市部の人には無い売りとして伝わります。ただし、地元は狭く、本業の競合や取引先と重なりやすいので、本業との線を先に確認してください。

### 遠隔で受けると、依頼側との関係が薄くなりませんか

対面より薄くなりやすいのは事実です。補うのは、稼働の記録と、週に一度の短い確認です。日付、時間、やったこと、次にやることを、依頼側に見える形で残し、週に一度、短い時間で確認を取る。この二つがあると、遠隔でも働きぶりが見え、判断待ちで止まることも減ります。関係の薄さは、場所の問題ではなく、記録と確認の頻度の問題として扱うと、遠隔でも続けられます。
