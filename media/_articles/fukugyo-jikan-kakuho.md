人事の副業を始めた人が数か月でやめる理由を聞くと、業務が難しかったという話より、時間が取れなくなったという話のほうが多い。本業の繁忙期、家庭の事情、疲れ。「空いた時間でやろう」と始めた副業は、空いた時間が無くなった瞬間に消えます。結論を先に書くと、**副業の時間は「空いた時間」ではなく「先に確保した週の枠」で作るもので、本業・家庭・休息を先に置いてから残りに副業の枠を決め、その枠で回る範囲だけを受ける**と、両立が続きます。枠を決めずに受けると、副業が本業と家庭と休息を押し出し、どれかが崩れます。稼働時間の決め方の詳細は[稼働時間の決め方](/media/fukugyo-kadou-jikan/)に、時間帯ごとの特徴は[平日夜だけで受けられる案件](/media/fukugyo-heijitsu-yoru/)、[週末だけの稼働は可能か](/media/fukugyo-shuumatsu/)、[早朝の稼働という選択](/media/fukugyo-hayaasa/)にまとめています。

## 「空いた時間でやる」が消える構造

空いた時間で副業をしようとすると、どう消えていくかを整理します。

| 段階 | 起きること |
|---|---|
| 始めたとき | 平日夜と週末に、空いた時間が数時間ある。その時間で受ける |
| 本業の繁忙期 | 残業で夜が消える。週末に寄せる |
| 家庭の事情 | 週末が予定で消える。翌週に持ち越す |
| 持ち越しが溜まる | 依頼側への引き継ぎが遅れる。判断待ちが止まる |
| 焦って詰める | 深夜や休息の時間を削る。疲れる |
| 質が落ちる | 疲れた状態で作業し、依頼側の評価が下がる |
| やめる | 時間が取れないことを理由に、区切りで終える |

構造の要点は、「空いた時間は、本業と家庭の変動をそのまま受ける」ことです。副業の時間を最後に置くと、ほかの全部の変動が副業に集まります。副業の時間を先に確保して、変動はその外で吸収する形にしないと、続きません。

## 先に置くものと、あとに置くもの

週の時間を、先に置くものとあとに置くものに分けます。副業は最後ではなく、休息の次に置きます。

| 順番 | 置くもの | 内容 |
|---|---|---|
| 一 | 本業 | 定時と、繁忙期の残業の見込み。変えられない |
| 二 | 家庭 | 家事、育児、介護、家族との時間。分担を先に決める |
| 三 | 休息 | 睡眠、何もしない時間。週に一日は副業を入れない |
| 四 | 副業の枠 | 残りの中で、固定できる曜日と時間帯。週に数時間 |
| 五 | 予備 | 枠が消えたときに回す時間。週に一枠 |

順番の要点は、「三の休息を、四の副業より先に置く」ことです。休息を最後にすると、副業が休息を削り、疲れが本業に及びます。休息を先に置いた残りで副業の枠を決めれば、副業は本業にも家庭にも影響しません。

### エラベルの見解

登録の相談で多いのは、「時間はある程度作れると思う」という言い方です。「ある程度」は、本業と家庭の変動をまだ見ていない状態で、実際に始めると数週間で「思ったより取れない」に変わります。時間は作れるものではなく、先に確保して守るものです。確保できる時間が週に三時間なら、三時間で回る範囲を受ける。それで足ります。

見ていて差がつくのは、「休息を先に置いているか」です。副業を始めると、休息を削って時間を作ろうとする人が多い。最初の一か月はそれで回りますが、二か月目に疲れが本業に出て、三か月目に副業をやめる。休息を先に置いて、残りで副業の枠を決めた人は、枠が小さくても続いています。エラベルの登録でも、時間を「週六時間」と書いた人より、「火木の夜と土曜午前」と曜日と時間帯で書いた人のほうが、長く続いています。曜日と時間帯で書けるということは、枠が確保できているということです。

## 週の枠を確保する手順

副業の枠を確保する手順を、番号付きで整理します。

1. **一週間の予定を、時間帯ごとに書き出す。** 本業の定時、通勤、家事、家族との時間、睡眠。空欄が、いま空いている時間。
2. **本業の繁忙期の残業を、見込みで足す。** 月末、四半期末、採用の繁忙期。空欄が減る。
3. **家庭の分担を決める。** 副業の時間帯に、家事や育児を誰が担うか。家族と先に話す。[介護・育児との両立](/media/fukugyo-kaigo-ikuji/)
4. **休息を先に置く。** 週に一日は副業を入れない日。睡眠の時間を削らない。
5. **残った空欄から、固定できる曜日と時間帯を選ぶ。** 週に二〜三枠、合計で数時間。毎日にしない。
6. **予備の枠を一つ置く。** 固定の枠が消えたときに回す。使わなければ休息に。
7. **枠で回る範囲を決める。** 週三時間なら、文面と記録。週六時間なら、一つの業務の運用。[案件の範囲の決め方](/media/fukugyo-scope/)
8. **依頼側に、枠と、枠の外では動かないことを伝える。** 「火木の夜と土曜午前。それ以外は返信しません」
9. **一か月、枠が守れたかを記録する。** 守れなかった週の理由を書く。
10. **守れない週が続くなら、枠を減らすか、範囲を狭くする。** 枠を増やす方向には動かない。

手順の要点は、「十で、枠を増やさない」ことです。時間が足りないと感じたとき、枠を増やすと本業か家庭か休息が削れます。足りないなら範囲を狭くする。この方向で調整すれば、両立は崩れません。

## 枠を守る仕組み

枠を決めても、守れなければ意味がありません。守るための仕組みを整理します。

| 仕組み | 内容 |
|---|---|
| 枠の外で見ない | 枠の外では、副業の連絡を見ない。通知を切る。見ると本業に影響する |
| 枠の冒頭と終わりを固定 | 始める時間と終える時間を決める。途中でも終える |
| 前回の終わりに次回の作業を決める | 枠の冒頭で「何をやるか」を考えない |
| 枠の終わりに依頼側に渡す | 作ったものを自分の中に置かない。次の枠まで持ち越さない |
| 判断待ちを一覧にする | 止まった項目を書き出し、次の枠で確認する。止まったことを気にしない |
| 消えた枠は予備に回す | 翌週に二倍やろうとしない。予備の枠で一回分だけ |
| 繁忙期を依頼側に先に伝える | 「月末は稼働が減る」を書面に。減ることを問題にしない |
| 月に一度、記録を見る | 守れた週と守れなかった週。守れない理由が続くなら見直す |

仕組みの要点は、「枠の外で見ない」ことが最も効くという点です。副業の連絡を本業の合間に見ると、本業の集中が切れ、返事をしてしまい、枠の意味が無くなります。通知を切り、枠の中でだけ見る。それだけで、両立の大半は守られます。

## 時間が足りないときの見直し

枠を守っても、時間が足りないと感じるときがあります。見直しの順番を整理します。

| 見直すこと | 問い | 直し方 |
|---|---|---|
| 範囲 | 枠で回る範囲を超えていないか | 範囲を狭くする。含まないことを足す |
| 業務の種類 | 枠の時間帯に合わない業務が混ざっていないか | 即応が要る業務は依頼側に。[平日夜だけで受けられる案件](/media/fukugyo-heijitsu-yoru/) |
| 枠の冒頭の使い方 | 考える時間で消えていないか | 前回の終わりに決める |
| 判断待ち | 止まった項目に時間を使っていないか | 一覧にして待つ。次の枠で確認 |
| 依頼側の期待 | 枠の外の対応を期待されていないか | 枠と、外では動かないことを伝え直す |
| 案件の数 | 複数の案件で枠が分散していないか | 一つに絞る。[複数案件の掛け持ち](/media/fukugyo-fukusuu-anken/) |
| 単価 | 時間が足りないのに、単価で補おうとしていないか | 単価ではなく範囲で調整 |
| 枠の時間帯 | 疲れて質が落ちる時間帯になっていないか | 時間帯を変える。[早朝の稼働という選択](/media/fukugyo-hayaasa/) |

見直しの要点は、「枠を増やす前に、範囲と業務の種類を見る」ことです。足りない原因の大半は、枠の大きさではなく、枠で回らない業務を受けていることにあります。

## 両立が崩れる兆候

両立が崩れる前には、兆候があります。気づいた時点で範囲を狭くします。

| 兆候 | 意味 |
|---|---|
| 枠の外で副業の連絡を見ている | 本業に影響が出始めている |
| 休息の日に副業を入れた | 休息が削れている |
| 睡眠が減った | 疲れが溜まる。本業に出る |
| 本業の集中が切れる | 副業のことを本業中に考えている |
| 家族との時間が減ったと言われた | 家庭の分担が崩れている |
| 依頼側への引き継ぎが遅れている | 枠で回らない範囲になっている |
| 副業の記録が書けていない | 枠の終わりを守れていない |
| 副業を「やらなければ」と感じる | 続けたい理由が消えている |

兆候の要点は、「一つでも出たら、範囲を狭くする」ことです。兆候が出てから枠を増やすと、崩れが早まります。範囲を狭くして、枠の中で回る状態に戻してから、続けるかを考えます。

### エラベルの見解

担当する側として登録した人の話を聞くと、長く続いている人は、副業の時間を「週に何時間」ではなく「何曜日の何時から何時」で持っています。その枠の外では副業を見ない。枠が消えた週は、翌週に二倍やらず、予備の枠で一回分だけ。依頼側にも枠を伝えていて、枠の外の連絡は来ません。この人たちは、副業を生活の中の固定の予定として扱っています。

依頼側から見ると、枠が固定されている人は、稼働が読める人です。「火木の夜に動く」と分かっていれば、依頼側はそれに合わせて渡すものと待つものを分けられます。「空いたときにやります」の人は、いつ動くか分からず、依頼側は待つしかない。エラベルは、範囲と時間を書いた登録に、条件が合う案件のときだけご連絡する窓口なので、時間を曜日と時間帯で書いていただき、その枠で回る範囲の案件をお伝えしています。枠を先に確保していただくことが、続く案件の前提です。

## まとめ

- 副業の時間は**「空いた時間」ではなく「先に確保した週の枠」**。空いた時間は本業と家庭の変動で消える
- 置く順番は**本業→家庭→休息→副業の枠→予備**。休息を副業より先に
- 手順は**一週間を書き出す→繁忙期を足す→家庭の分担→休息を先に→固定の枠を二〜三つ→予備を一つ→枠で回る範囲→依頼側に伝える→記録→枠を増やさず範囲を狭くする**
- 枠を守る仕組みは**枠の外で見ない・冒頭と終わりを固定・前回の終わりに次回を決める・終わりに渡す・判断待ちの一覧・消えた枠は予備に・繁忙期を先に伝える・月一の記録**
- 足りないときは**枠を増やす前に、範囲と業務の種類を見る**
- 崩れる兆候が**一つでも出たら範囲を狭くする**

## よくある質問

### 週に何時間くらいなら、両立できますか

人によりますが、時間の量より、固定できるかどうかが重要です。週三時間でも、曜日と時間帯が固定されていれば続きます。週十時間でも、空いた時間で取ろうとすると消えます。一週間を書き出して、本業・家庭・休息を先に置いた残りから、固定できる枠を二〜三つ選んでください。その合計が、両立できる時間です。その時間で回る範囲を受ければ、量が少なくても案件は成り立ちます。

### 枠を決めても、本業の繁忙期に守れません

繁忙期は守れなくて構いません。守れないことを前提に、依頼側に先に伝え、書面に入れておきます。「月末と四半期末は稼働が減る」と書いてあれば、減ったときに止まったことになりません。繁忙期の枠は、記録と最低限の引き継ぎだけにして、作る作業は繁忙期の前後に寄せる。繁忙期が終わったら、二倍やって取り戻そうとせず、通常の枠に戻すだけにします。取り戻そうとすると、休息が削れて次の繁忙期に響きます。

### 副業を始めてから、家族との時間が減ったと言われました

両立が崩れる兆候の一つです。まず、副業の枠を家族と一緒に決め直してください。副業の時間帯に家事や育児を誰が担うか、週に一日は副業を入れない日をどこにするか。家族の了解が無い枠は、守れません。決め直したうえで、範囲を狭くし、枠の外では副業を見ない。家族との時間が戻らなければ、副業の量が生活に合っていないので、案件の区切りで減らすか、一度止めることも選択肢です。副業は、本業と家庭が回っている上に乗るものです。
