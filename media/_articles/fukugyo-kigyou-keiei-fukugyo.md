会社を経営してきた、あるいは役員として事業と組織を見てきた。人事の部署にいたわけではないが、採用の判断を何度も下し、幹部を採り、組織を作ってきた。この経験は、副業で人事として売れるのか。実務の手を動かす副業に、経営の経験は合うのか。結論を先に書くと、**経営者・役員の経験は、「採用を経営の判断として組み立てる」工程で売れます。売れるのは、「採用の優先順位と予算の設計」「依頼側の経営者への助言」「役員や幹部の採用の見極め」「採用の仕組みの設計」の四つです。ただし、「経営の経験を活かして指導します」という売り方は、依頼側の経営者に警戒されます。「依頼側の経営者が判断できる形に整える」と、助言と設計の工程で売ります。判断するのは依頼側の経営者で、自分は判断の材料と仕組みを作る側です。**経営者直下で動く場合の立ち回りは[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、本業との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法人で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)にまとめています。

## この経歴の何が売れるか

経営者・役員の経験を、採用の工程に置き換えた棚卸しです。

| 経営の経験 | 採用の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 事業の計画から人員の計画を引いてきた | 依頼側の事業の計画を聞き、どの職種を、いつまでに、何人、どの順で採るかを設計する | 「とにかく人が足りない」で採用が場当たりになっている依頼側が多い |
| 採用の予算と費用の判断をしてきた | 媒体、紹介、代行、社員の工数を、依頼側の予算と時間で組み合わせる設計 | 予算の配分が決まらず、一つの手段に偏っている依頼側が多い |
| 幹部や役員を採ってきた | 幹部の採用で、何を見るか、どう見極めるか、入社後にどう任せるかの設計と、面談の同席 | 幹部の採用で失敗した経験があり、次をどう進めるか迷っている依頼側が多い |
| 経営者として判断を下してきた | 依頼側の経営者が、採用の判断を下せる形に、材料と選択肢を整える | 経営者が採用の判断を先送りし、採用が止まっている依頼側が多い |
| 組織を作ってきた | 採用と配置と評価をつなげた、組織の仕組みを設計する | 採用だけを見て、入社後の配置と評価が無い依頼側が多い |
| 経営者の孤独を知っている | 依頼側の経営者が、社内に言えない採用の悩みを、相談できる相手になる | 経営者が採用の悩みを一人で抱えている依頼側が多い |
| 失敗の経験がある | 採用と組織で失敗した経験を、依頼側が同じ失敗をしないための材料にする | 失敗の型を知らずに、同じ失敗をしている依頼側が多い |

売れるものの要点は、「採用を、人事の作業ではなく、経営の判断として扱える」ことが価値だということです。多くの依頼側で、採用は人事の作業として扱われ、経営者の判断が入っていません。事業の計画から人員の計画を引き、予算を配分し、幹部の採用を見極め、判断できる形に整える。この工程は、経営の経験がある人にしかできません。実務の手を動かす経験が無くても、この工程で売れます。経営者への助言の立ち回りは[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、課題の整理の仕方は[課題を構造化する](/media/fukugyo-kouzou-ka/)に書いています。

## 売りにくい点とその扱い

経営者・役員の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 上から目線への警戒 | 「経営者だった人に、うちのやり方を否定されるのでは」「指導される立場になるのでは」 | 「指導」ではなく「材料と選択肢を整える」と最初に示す。判断は依頼側の経営者。自分の経験は、依頼側に押しつけず、選択肢の一つとして出す |
| 実務の手を動かすか | 「助言だけで、手は動かさないのでは」「求人票やスカウトの実務ができるのか」 | 範囲を最初に示す。設計と助言と幹部の採用の同席を担い、実務の手は依頼側か別の担当者が担う形にするか、実務も含めて担うなら、実務の経験を示す |
| 本業との利益相反 | 「今も経営している会社と、依頼側の事業が競合するのでは」「依頼側の情報を自分の会社に持ち帰るのでは」 | 自分の会社と競合する依頼側、取引のある依頼側を避ける。依頼側の情報を自分の会社に持ち込まない線を、契約で示す |

扱い方の要点は、「上から目線への警戒」を、最初に消すことです。経営者・役員の転身で依頼側の経営者が最も警戒するのは、「自分のやり方を否定され、指導される」ことです。この警戒があると、どんなに良い助言も届きません。「私の経験は選択肢の一つで、判断は御社の経営者が。私は判断できる形に材料を整えます」と最初に示し、依頼側の経営者を立てる姿勢を、言葉と態度で示します。利益相反の線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に整理しています。

### エラベルの見解

担当する側から見ると、経営者・役員から転身して続いている人と、最初の案件が取れないか一件で終わる人の差は、経営の経験の大きさではなく、「依頼側の経営者を立てているか」です。取れない人は、面談で自分の経営の実績を語り、依頼側のやり方を評価し、依頼側の経営者に「指導される側になる」と感じさせています。続いている人は、依頼側の経営者の悩みを聞き、選択肢を並べ、「どれを選ぶかは御社の判断で」と返し、依頼側の経営者に「判断しやすくなった」と感じさせています。

見ていて差がつくのは、幹部の採用で、「見極め」を売りにしながら、判断を引き受けていないかです。経営者・役員の経験があると、依頼側は「この人なら幹部の候補者を見抜ける」と期待し、判断を委ねようとします。それを引き受けると、外れたときに関係が壊れ、依頼側の経営者は「自分で判断しなかった」と後悔します。「私が見た観点と懸念はこれです。最終の判断は御社の経営者が」と、材料に徹している人は、幹部の採用が続いても信用が残っています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、経営の経験を「判断できる形に整える」工程で示している担当者に、経営者が直接相談したい依頼側がついています。経営者・役員の転身は、経験の大きさではなく、立て方で始まります。

## 案件の探し方

経営者・役員から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 採用の優先順位と予算の設計 | 事業の計画から人員の計画を引く経験で入れる | 「事業の計画から、どの職種を、いつ、何人、どの順で採るかを設計する」を範囲の一言に |
| 依頼側の経営者への定期の助言 | 経営者の悩みを聞ける立場で入れる | 「月に一度、採用の判断の材料を整える相談の相手」の形で |
| 幹部・役員の採用の設計と面談の同席 | 幹部を採ってきた経験で入れる | 「幹部の採用で、何を見るか、どう任せるかを設計し、面談に同席して観点と懸念を渡す」を示す |
| 採用と配置と評価をつなげた仕組みの設計 | 組織を作ってきた経験で入れる | 「採用だけでなく、入社後の配置と評価まで含めた仕組み」を提案の形で |
| 経営者が直接担当する依頼側 | 経営者同士で話せる | 登録先で、経営者が直接担当する規模の依頼側を選ぶ |
| 自分の経営してきた事業の分野の依頼側（競合を除く） | 分野の候補者と市場が分かる | 競合と取引先を避けたうえで、分野を範囲の一言に |

探し方の要点は、「経営者が直接担当する規模の依頼側を選ぶ」ことです。人事の担当者が窓口になる依頼側では、経営の判断の工程が担当者の権限の外にあり、助言と設計が実行に移りません。経営者が直接担当する依頼側なら、助言がそのまま判断につながり、設計が実行されます。自分の価値が出る相手を選びます。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、経営者直下の動き方は[経営者直下で動くときの立ち回り](/media/fukugyo-keieisha-chokka/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。経営者・役員の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 経営の判断の工程であること | 実務の作業の工程より、設計と助言の工程は単価の決まり方が違い、時間ではなく価値で決まりやすい | 時間単価ではなく、月額か、設計一式の成果物で受ける |
| 幹部の採用の設計と同席 | 依頼側にとって失敗の損失が大きい採用なので、設計と同席の価値は高い | 設計一式と、面談の同席の回数で受ける |
| 実務の手を動かす範囲を含むか | 実務を含めると、実務の工程の単価が混ざり、全体の単価が下がることがある | 設計と助言と、実務を分けて受ける。実務は別の担当者か依頼側に |
| 依頼側の規模 | 経営者が直接担当する規模の依頼側は、予算が小さいことがある | 月額を小さくし、範囲を絞る。回数で調整する |
| 自分の本業の経営との時間の配分 | 副業に使える時間が読みにくい | 月に何回、何時間、と枠を先に決める |
| 契約の形 | 個人で受けるか、自分の会社で受けるか | 自分の会社で受けると、契約と税の扱いが変わる。専門家にご確認ください |

単価の要点は、「設計と助言を、時間単価で受けない」ことです。経営の判断の工程は、一時間の相談で依頼側の採用の方向が決まることがあり、時間で測ると価値が測れません。月額の顧問の形か、設計一式の成果物の形で受け、実務の手を動かす部分は分けます。自分の会社で受けるかどうかは、契約と税の扱いが変わるため、専門家にご確認ください。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、法人で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)に整理しています。

## 始める順番

経営者・役員から人事の副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、採用と組織で下してきた判断と、その結果を書き出す | 成功と失敗の両方。失敗の型が材料になる |
| 二、自分の会社と競合する依頼側、取引のある依頼側を、避ける対象として書き出す | 利益相反の線 |
| 三、「指導しない」「判断は依頼側の経営者」を、自分の言葉で書く | 上から目線への警戒を消す準備 |
| 四、範囲を、設計と助言と幹部の採用に絞る | 実務の手を動かす範囲を含めるかを決める |
| 五、副業に使える枠を、月に何回、何時間で決める | 本業の経営との配分 |
| 六、「依頼側の経営者が判断できる形に整える」の一言を作る | 「経営の経験を活かす」とは言わない |
| 七、登録先に、範囲と分野と枠を登録する | 経営者が直接担当する規模の依頼側を選ぶ |
| 八、月額か成果物で一件受け、依頼側の経営者を立てる形で続ける | 判断は引き受けない |

順番の要点は、「三」の、「指導しない」「判断は依頼側の経営者」を自分の言葉で書いておくことです。経営者・役員の転身では、無意識に指導の言葉が出ます。「うちではこうしていた」「それは違う」という言葉は、依頼側の経営者に届きません。「一つの選択肢として」「御社の判断で」という言葉を、面談の前に用意しておきます。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「経営者・役員の経験は、実務の手を動かす副業には合わない」というものです。実際には、採用を経営の判断として組み立てる工程は、実務の経験ではなく経営の経験が要る工程で、依頼側の経営者が最も困っているところです。実務の手を動かさなくても、この工程で売れます。合わないのは、経営の経験ではなく、指導の姿勢です。

順番として、採用と組織の判断と結果を書き出し、利益相反の線を引き、「指導しない」を自分の言葉で書き、範囲を設計と助言と幹部の採用に絞り、枠を決め、「判断できる形に整える」の一言を作り、登録先に範囲と分野と枠を登録し、月額か成果物で一件受けて依頼側の経営者を立てる。この順番で、経営者・役員の転身は、「指導する人」から「判断を助ける人」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、経営の経験を「判断できる形に整える」工程で示し、経営者を立てている担当者に、経営者が直接相談したい依頼側がついています。経営者・役員の転身は、経験の大きさではなく、立て方で始まります。

## まとめ

- 経営者・役員の経験は**「採用を経営の判断として組み立てる」工程**で売れる。**優先順位と予算の設計・経営者への助言・幹部の採用の見極め・仕組みの設計**の四つ
- **「経営の経験を活かして指導」ではなく「依頼側の経営者が判断できる形に整える」**と売る。判断は依頼側の経営者
- 売りにくい点は**上から目線への警戒・実務の手を動かすか・本業との利益相反**。「指導しない」を最初に示し、範囲を分け、競合と取引先を避ける
- 幹部の採用で**判断を引き受けない**。観点と懸念を材料として渡す
- 案件は**経営者が直接担当する規模の依頼側**から。助言が判断につながる相手を選ぶ
- 単価は**設計と助言を時間単価で受けず、月額か成果物で**。実務と分ける。自分の会社で受ける場合は専門家に確認

## よくある質問

### 今も自分の会社を経営しています。副業として人事を受けてよいですか

自分の会社の事業と競合しない依頼側、取引のない依頼側であれば、受けられることがあります。ただ、自分の会社の役員としての義務や、株主や取引先との関係で制約がある場合があり、個別の判断は専門家にご確認ください。依頼側の情報を自分の会社に持ち込まない線を契約で示し、自分の会社の情報を依頼側に持ち込まない線も守ります。自分の会社で受けるか個人で受けるかは、契約と税の扱いが変わるため、これも専門家にご確認ください。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に、法人で受ける形は[法人として受ける場合](/media/fukugyo-houjin-keiyaku/)に整理しています。

### 依頼側の経営者が、私の助言を聞かず、自分のやり方を変えません

助言は、選択肢として出すもので、依頼側の経営者が選ばないなら、それが依頼側の判断です。「聞かない」と感じるときは、自分の助言が指導の形になっていないかを見ます。「こうすべきです」ではなく、「選択肢はA、B、Cで、それぞれの結果はこうです。どれを選ぶかは御社で」と、判断の材料の形に変えます。それでも変わらないなら、依頼側の経営者が今は変えたくない理由があり、その理由を聞くことが次の助言の材料になります。助言の出し方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に、通らなかったときは[提案が通らなかったとき](/media/fukugyo-hantai-sareta/)に書いています。

### 実務の手を動かす経験が無いので、求人票やスカウトを頼まれたら困ります

範囲を最初に示し、実務の手を動かす部分は依頼側か別の担当者が担う形にします。「私は設計と助言と幹部の採用の同席を担います。求人票やスカウトの実務は、御社の担当者か、実務の担当者に」と伝えます。エラベルのような登録先では、設計を担う担当者と実務を担う担当者を分けて依頼できる依頼側もあり、自分の範囲を明確にしておけば、実務を頼まれることは減ります。実務も含めて担いたいなら、実務の工程を学び、小さく受けて経験を作ります。範囲の示し方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、複数人での分担は[チームで動くときの分担](/media/fukugyo-chiimu/)に整理しています。
