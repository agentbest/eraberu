本業で外国人の採用を担当してきた。募集の経路、面接での伝え方、受け入れの準備、入社後の定着。この経験は、人事の副業で売れるのか。外国人採用は在留の資格や手続きが絡み、副業で扱ってよいのか迷う。結論を先に書くと、**外国人採用の担当の経験は、「初めて外国人を採用する依頼側の、募集から受け入れまでの運用の設計」で売れます。売れるのは、「母集団の経路と文面」「面接と条件の伝え方」「受け入れと定着の仕組み」「手続きの流れの整理」の四つです。人手が足りず外国人の採用を考え始めた依頼側は多く、何から手をつければよいか分からず止まっています。ただし、在留の資格の可否、手続きの判断、法的な要件は、副業の範囲に入れず、専門家と公的な窓口に委ねます。自分が担うのは、運用の設計と型です。**候補者の個人情報の扱いは[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、障害者雇用の担当の売り方は[障害者雇用の担当が副業でできること](/media/fukugyo-shougaisha-koyou-tantou-fukugyo/)に、法改正の追い方は[法改正の追い方](/media/fukugyo-houkaisei/)にまとめています。

## この経歴の何が売れるか

外国人採用の担当の経験を、副業の工程に置き換えた棚卸しです。在留と手続きの判断は含まず、運用の設計と型に絞ります。

| 担当の経験 | 副業の工程への置き換え | 依頼側にとっての価値 |
|---|---|---|
| 母集団の経路を作ってきた | 外国人の候補者がどこにいるか（媒体、学校、紹介、コミュニティ）を整理し、依頼側に合う経路を設計する | 「どこで探せばよいか分からない」依頼側が多い |
| 求人の文面を作ってきた | 求人票とスカウト文面を、日本語の前提を外し、伝わる言葉と構成にする。翻訳の要否と、翻訳する場合の確認の流れ | 求人票が日本語の前提で書かれ、伝わっていない依頼側が多い |
| 面接で条件と仕事を伝えてきた | 面接で、仕事の中身、条件、生活の面（住まい、通勤、言葉）を、誤解なく伝える型を作る | 面接で伝わったつもりが、入社後に「聞いていない」となる依頼側が多い |
| 受け入れの準備をしてきた | 入社前後に依頼側と本人が準備すること（住まい、口座、生活の案内、社内の言葉の整理）の一覧と流れ | 受け入れの準備が抜け、入社直後に本人が困る依頼側が多い |
| 定着の面談と仕組みを回してきた | 入社後の面談の頻度と、言葉と文化の前提のずれを早く拾う仕組み | 定着せず、早期に辞める依頼側が多い |
| 手続きの流れを見てきた | 手続きに関わることは「確認が要る」と示し、専門家と公的な窓口への確認先と、依頼側と本人が準備する書類の流れを整理する（可否と要件の判断はしない） | 手続きの流れを知らず、内定の後に止まる依頼側が多い |
| 現場の理解を作ってきた | 受け入れる現場向けの説明の型（言葉、文化、業務の伝え方） | 現場の不安と誤解が受け入れの壁になっている依頼側が多い |

売れるものの要点は、「在留と手続きの知識ではなく、運用の設計と型が売れる」ことです。依頼側が困っているのは、法的な要件より、「どこで探し、どう伝え、どう受け入れ、どう定着させるか」で、それは運用してきた人にしか設計できません。在留の資格の可否、手続きの判断、法的な要件は、変わるものであり、個別の状況で結果が違い、副業の範囲で扱うと事故になるので、「確認が要る」と示し、専門家と公的な窓口に委ねます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、現場との関係は[現場との関係の作り方](/media/fukugyo-genba-chousei/)に書いています。

## 売りにくい点とその扱い

外国人採用の担当の転身で売りにくい点は三つあり、扱い方があります。

| 売りにくい点 | 依頼側の懸念 | 扱い方 |
|---|---|---|
| 在留と手続きの判断との線 | 「この人を採用できるか、判断してくれるのか」「手続きも全部やってくれるのか」 | 可否と手続きの判断は範囲に入れない。「在留と手続きは、専門家と公的な窓口に確認する形で進めます。私は募集から受け入れの運用を担います」と契約の前に示す |
| 言葉と文化の前提 | 「うちの現場は日本語だけで、受け入れられるのか」「文化の違いで揉めないか」 | 言葉と文化の前提のずれを、面接と受け入れと定着の型で扱う。「日本語の水準」と「業務で要る言葉」を分けて整理する |
| 依頼側の理解の差 | 「経営者は前向きだが、現場が消極的」 | 現場向けの説明の型を範囲に入れる。設計だけでなく、最初の受け入れの一巡を一緒に回す |

扱い方の要点は、「在留と手続きの判断を、範囲に入れない」ことを、契約の前に示すことです。外国人採用で依頼側が最も知りたいのは、「この人を採用できるのか」ですが、その判断は法的な要件と個別の状況で決まり、副業の担当者が答えると、結果が違ったときに依頼側と本人の両方に損失が出ます。「可否と手続きは専門家と公的な窓口に。確認先を整理し、依頼側と本人が準備する流れを設計します」と、判断ではなく流れを担います。個人情報の線は[個人情報の扱い](/media/fukugyo-kojin-jouhou/)に、守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に、面接の型は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)に整理しています。

### エラベルの見解

担当する側から見ると、外国人採用の担当の経験で副業を続けている人と、一件で終わる人の差は、在留や手続きの知識の量ではなく、「可否の判断を範囲に入れていないか」と「面接で伝わったつもりを防ぐ型を持っているか」です。一件で終わる人は、依頼側から「この人は採用できますか」と聞かれて答える形になり、結果が違ったときに責任の所在が曖昧になって続けられなくなっています。続いている人は、「可否は専門家と公的な窓口に」と線を引き、募集の経路と文面、面接の伝え方、受け入れの準備、定着の面談を型で回し、依頼側から「初めてでも受け入れが動いた」と評価されています。

見ていて差がつくのは、面接で「伝わったつもり」を防ぐ型を持っているかです。外国人採用で最も多い早期離職の原因は、面接で仕事の中身と条件と生活の面が伝わったつもりになっていて、入社後に「聞いていない」となることです。担当の経験がある人は、「伝えたことを本人の言葉で言い直してもらう」「条件は書面と口頭の両方で」「生活の面（住まい、通勤、言葉）まで面接で確認する」という型を持っていて、入社後のずれを減らしています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、運用の設計と型を明確にし、在留と手続きの判断との線を示している担当者に、初めて外国人を採用する依頼側がついています。外国人採用の担当の転身は、法的な知識ではなく、運用の型で始まります。

## 案件の探し方

外国人採用の担当から入りやすい案件と、探し方です。

| 入りやすい案件 | 理由 | 探し方 |
|---|---|---|
| 母集団の経路と文面の設計 | 経路と文面を作ってきた経験で入れる | 「どこで探し、どう書くか」を範囲の一言に。初めて外国人を採用する依頼側 |
| 面接と条件の伝え方の型 | 面接で伝えてきた経験で入れる | 「伝わったつもりを防ぐ面接の型」を示す |
| 受け入れの準備の一覧と流れ | 受け入れを準備してきた経験で入れる | 「入社前後に準備することの一覧」を成果物の形で |
| 定着の面談と仕組み | 定着を回してきた経験で入れる | 「早期に辞める依頼側」を範囲の一言に |
| 手続きの流れの整理（判断を含まない） | 流れを見てきた経験で入れる | 「確認先と、依頼側と本人が準備する書類の流れ」を示す。可否と要件は専門家と窓口に |
| 現場向けの説明の型 | 現場の理解を作ってきた経験で入れる | 「現場の不安と誤解を減らす説明」を提案の形で |

探し方の要点は、「初めて外国人を採用する依頼側」と「採用したが早期に辞める依頼側」の二つに絞ることです。前者は経路と文面と受け入れの設計、後者は面接の伝え方と定着の仕組みが入口になります。どちらも、在留と手続きの判断ではなく、運用の設計で価値が出ます。手続きの相談から入ると、範囲が判断に寄るので、運用の詰まりから入ります。案件の探し方は[案件の探し方](/media/fukugyo-anken-sagashi/)に、面談で聞くことは[こちらから聞くべき質問](/media/fukugyo-mensetsu-shitsumon/)に書いています。

## 単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。外国人採用の担当の転身で、単価に影響する要素です。

| 要素 | 単価への影響 | 考え方 |
|---|---|---|
| 運用の設計の経験の希少さ | 実際に募集から定着までを回してきた人は少なく、依頼側にとって価値が高い | 経験の希少さを、運用の型で示す |
| 成果物で受けやすい工程 | 経路の一覧、文面の型、面接の型、受け入れの準備の一覧、確認先の整理は、成果物で受けやすい | 成果物で受けると、判断との線も明確になる |
| 最初の一巡の実行 | 設計だけでなく、最初の採用を一緒に回す部分は、工程で受ける | 設計の成果物と、一巡の実行を分けて見積もる |
| 定着の面談の継続 | 入社後の面談は、回数で受けやすい | 一回あたりと、月の回数の上限を決める |
| 言葉の対応を含むか | 翻訳や通訳を自分が担うか、外部に出すかで、範囲と単価が変わる | 翻訳と通訳は、範囲に入れるかを最初に決め、入れるなら別の項目で |
| 本業との利益相反 | 本業の会社と競合する依頼側、本業の候補者や紹介の関係を持ち込む形は避ける | 本業の関係と情報を副業に持ち込まない |

単価の要点は、「翻訳と通訳を範囲に入れるかを、最初に決める」ことです。外国人採用の担当の経験があると、依頼側は「言葉の対応も全部」と期待しがちで、範囲に入れないまま受けると、翻訳と通訳で稼働が消えます。運用の設計と、言葉の対応は、別の工程として分け、言葉の対応を担うなら別の項目で見積もります。設計の成果物、一巡の実行、定着の面談の回数、言葉の対応、と分けて示せば、依頼側は必要な部分だけを頼め、自分は範囲を守れます。単価の構造は[人事の副業単価の相場](/media/fukugyo-tanka-souba/)に、本業との線は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。

## 始める順番

外国人採用の担当から副業を始める順番です。

| 順番 | 内容 |
|---|---|
| 一、本業で回してきた運用（経路、文面、面接、受け入れ、定着、手続きの流れ）を、本業の会社と本人の情報を含まない型で書き出す | 守秘の線を守った型 |
| 二、在留と手続きの判断を範囲に入れない、と決める | 「確認が要る」と示し、専門家と公的な窓口への確認先を整理する形に |
| 三、個人情報の扱いの型を、自分の言葉で書く | 国籍や在留に関わる情報の扱いは、特に慎重に |
| 四、本業の会社との利益相反の線を引く | 競合、本業の候補者、本業で関わった学校や紹介の関係を持ち込まない |
| 五、範囲を、経路と文面、面接と条件の伝え方、受け入れと定着、手続きの流れの整理に絞る | 判断と法的な要件は範囲外。翻訳と通訳は別の項目 |
| 六、「募集から受け入れまでの運用を、実際に回してきた型で」の一言を作る | 「在留に詳しいです」とは言わない |
| 七、登録先に、範囲と、判断との線を登録する | 初めて採用する依頼側と、早期に辞める依頼側 |
| 八、経路と文面か、面接の型を一件、成果物で受け、型を残す | 次の工程に広げる材料に |

順番の要点は、「二」と「三」を、案件を探す前に決めることです。在留と手続きの判断を範囲に入れないこと、国籍や在留に関わる個人情報の扱いの型を持つことは、外国人採用の副業で最も重要な線で、この二つが曖昧なまま始めると、依頼側にも本人にも不利益が出ます。線を決め、契約に書き、その上で運用の設計を売ります。自己紹介の型は[自己紹介文のテンプレート](/media/fukugyo-jiko-shoukai/)に、プロフィールは[プロフィールの書き方](/media/fukugyo-profile/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「外国人採用は在留や手続きが絡むので、副業で扱うのは危ない」というものです。実際には、依頼側が困っているのは法的な要件より運用で、経路、文面、面接の伝え方、受け入れ、定着を実際に回してきた人の型は、判断を含めなくても価値が高いです。危ないのは、在留と手続きの判断を範囲に入れてしまう場合で、入れなければ、運用の設計として受けられます。

順番として、本業で回してきた運用を型で書き出し、在留と手続きの判断を範囲に入れないと決め、個人情報の扱いの型を書き、本業との利益相反の線を引き、範囲を運用の設計に絞り、翻訳と通訳は別の項目にし、実際に回してきた型の一言を作り、登録先に範囲と線を登録し、経路と文面か面接の型を一件成果物で受ける。この順番で、外国人採用の担当の転身は、「在留が絡むから危ないもの」から「運用の型で価値を出すもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、運用の設計と型を明確にし、判断との線を示している担当者に、初めて外国人を採用する依頼側がついています。外国人採用の担当の転身は、法的な知識ではなく、運用の型で始まります。

## まとめ

- 外国人採用の担当の経験は**「初めて外国人を採用する依頼側の、募集から受け入れまでの運用の設計」**で売れる。**経路と文面・面接と条件の伝え方・受け入れと定着・手続きの流れの整理**の四つ
- **在留の資格の可否、手続きの判断、法的な要件は範囲に入れない**。「確認が要る」と示し、専門家と公的な窓口に委ねる
- 面接で**「伝わったつもり」を防ぐ型**（本人の言葉で言い直してもらう・書面と口頭の両方・生活の面まで確認）を持つ
- **国籍や在留に関わる個人情報の扱いの型**を最初に示し、契約に書く
- 案件は**初めて採用する依頼側と、早期に辞める依頼側**から。手続きの相談ではなく運用の詰まりから入る
- 単価は**設計の成果物・一巡の実行・定着の面談・言葉の対応を分けて示す**。翻訳と通訳は別の項目に。本業の関係と情報は持ち込まない

## よくある質問

副業の範囲では答えず、「在留の資格の可否は、専門家（該当する士業）と公的な窓口に確認してください。確認先と、確認に要る情報の流れを整理してお渡しします」と、判断ではなく確認の流れを示します。答えてしまうと、要件が変わったときや個別の状況で結果が違ったときに、依頼側と本人の両方に損失が出ます。自分が担うのは、可否が確認された後の、受け入れの運用です。線の引き方は[業務範囲を書面で固める](/media/fukugyo-scope/)に、制度の変化の追い方は[法改正の追い方](/media/fukugyo-houkaisei/)に整理しています。

### 面接の通訳を頼まれました。範囲に入れてよいですか

通訳を担えるなら、運用の設計とは別の項目として、範囲と単価を分けて受けます。運用の設計の中に通訳を混ぜると、稼働が通訳で消え、設計の時間が残りません。担えないか、担いたくないなら、「通訳は外部の方にお願いし、私は面接の型と、通訳を介した面接で伝わったつもりを防ぐ確認の流れを担います」と分けます。通訳が入る面接では、伝えたことを本人の言葉で言い直してもらう確認が、特に要ります。範囲の分け方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

### 本業で関わっている学校や紹介の経路を、副業の依頼側に使ってよいですか

本業で作った学校や紹介との関係を、副業に持ち込むことは避けます。本業の会社の関係を副業に使う形になり、本業との利益相反と、学校や紹介先との信頼の両方に関わります。副業の依頼側には、「経路の種類と、経路ごとの特徴と、開拓の型」を渡し、経路そのものは依頼側が自分で開拓する形にします。本業で得た「経路の型」は使えますが、「本業で作った関係そのもの」は使いません。線の引き方は[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)に整理しています。
