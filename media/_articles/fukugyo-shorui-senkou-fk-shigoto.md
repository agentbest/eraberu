書類選考の代行を初めて受けるとき、見えにくいのは「仕分けの前後に何があるか」です。募集文には「書類選考のサポート」とだけあり、実際には、要件の確認、基準の承認、応募書類の扱いの契約、迷う人の返し方、連絡の文面の承認、週次の報告と、仕分けの前後に工程が付きます。順番を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→第1週→第2週以降→月次→終了と更新」の五つの段階で進み、契約前に範囲・応募数の目安・迷う人を決める人と期限・応募書類の扱いと契約・基準にしてはいけない項目・連絡の名義と文面・報告を決め、第1週は仕分けずに要件の確認と基準の承認と文面の承認と記録の表の準備に使い、第2週から受付と仕分けと切り出しと連絡と週次の報告を回し、月次で通過率と面接でのずれから基準を直し、引き継げる形で終えます。**案件の型と求められる経験は[書類選考の代行の副業案件](/media/fukugyo-shorui-senkou-fk-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

書類選考は、応募書類という個人情報を扱い、候補者への連絡が会社の名前で出る仕事です。口約束で始めません。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 仕分けだけか、基準の案からか、受付と連絡を含むか、面接の日程調整を含むか | 「連絡もお願い」が後から足される |
| 応募数の目安 | 一日、一週間の応募数。想定を超えたときの扱い | 稼働が読めず、連絡が遅れる |
| 迷う人を決める人と期限 | 会社側の誰が、何日以内に決めるか | 迷う人が手元に溜まり、候補者を待たせる |
| 応募書類の扱いと契約 | 会社の管理する場所（採用管理システムなど）でだけ見るか。保存・印刷・転送の禁止。秘密保持の契約 | 個人情報の扱いが決まらないまま始まる |
| 基準にしてはいけない項目 | 会社の一覧があるか。無ければ作るか | 法令上の論点に触れる形になる。専門家にご確認ください |
| 連絡の名義と文面 | 誰の名前で連絡するか。文面の承認者。問い合わせが来たときの流れ | 承認の無い文面が会社の名前で出る |
| 報告 | 週次か、形式、誰が読むか。通過率と面接でのずれを含むか | 基準の見直しが行われない |
| 評価 | 何で評価されるか（連絡の速さ、面接でのずれの少なさ、通過率のどれか） | 動かせない数字で評価される |

止まりやすいのは、「まず溜まっている分から見てください」で始めるときです。応募書類の扱いの契約と、迷う人を決める人だけは、始める前に決めます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、個人情報の扱いは[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## 第1週：仕分けない週

第1週は、仕分けません。要件の確認と、基準と文面の承認と、記録の表の準備に使います。溜まっている応募があっても、基準の無いまま仕分けると、見る人によって通す人が違う状態が外に移るだけです。

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 要件の確認（必須と歓迎、いまうまくやっている人の共通点、面接でずれた人の傾向） | 現場の責任者が出る時間。過去の選考の記録 | 人事だけから聞いて、現場の「良い人」が言葉にならない |
| 基準の案（必須を経歴で読める形に。通過・見送り・迷うの定義） | 基準の承認。基準にしてはいけない項目の確認 | 「経験〇年」「〇〇卒」のような、読めるが中身の無い基準にする |
| 迷う人の定義と返し方（どういう人を迷うに置くか。理由の書き方。誰に何日で返すか） | 決める人と期限の確定 | 迷うの定義が無く、通過と見送りに無理に振る |
| 連絡の文面の承認（受付、通過、見送り、日程調整） | 文面の承認。名義の確定 | 承認の前に送る。見送りの理由を個別に書く |
| 記録の表（応募日、仕分け、迷う理由、連絡日、面接の結果、ずれの有無） | 表の置き場所（会社の管理する場所） | 自分の端末に表を作る |

止まりやすいのは、溜まっている応募を見て、第1週から仕分け始めるときです。「溜まっている分は、受付の連絡だけ当日中に出し、仕分けは基準の承認後にまとめて行う」と分けます。要件の聞き方は[質問の仕方](/media/fukugyo-shitsumon-shikata/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「第1週に仕分けない」ことを会社に納得してもらえるかで、その後の難易度が決まります。会社は応募が溜まっていて、一日も早く仕分けてほしい。そこで担当者が押されて基準の無いまま仕分け始めると、通した人が面接でずれたときに、基準に戻せず、「見る目が無い」という評価になります。エラベルで担当者を選ぶ企業には、「最初の一週間は基準と文面の承認に使い、その間の応募には受付の連絡だけ出します」と、私たちから先に伝えています。受ける側がその場で使える判断としては、契約前の稼働の計画に「第1週は仕分けない。基準と文面の承認と記録の表に使う。溜まっている分は受付の連絡だけ出す」と書いて渡すこと。書いてあれば、会社も「まだ見てないのか」とは言いません。

## 第2週以降：受付・仕分け・切り出し・連絡・週次の報告

第2週から仕分けを始めます。ここからは、受け付ける、仕分ける、迷う人を返す、連絡する、記録する、の繰り返しです。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 受付（応募を確認し、受付の連絡を出す） | 決めた時間帯に毎日 | 週末にまとめる。候補者は待たない |
| 仕分け（基準に沿って通過・見送り・迷うの三つに。理由を一行で記録） | 受付と同じ時間帯に | 基準にない項目で判断する。感覚で厳しくしたり緩めたりする |
| 迷う人の切り出し（迷う理由を一行で書き、決める人に返す。期限を伝える） | 迷う人が出たその日に | 迷う人を手元に置いて、自分で決めようとする |
| 連絡（通過と見送り。承認された文面で、会社の名前で） | 仕分けの翌日まで | 承認の無い文面に変える。見送りの理由を個別に書く |
| 面接の日程調整（含む場合） | 通過の連絡と同時に候補日を出す | 面接官の枠を先に確保していない |
| 記録（表に応募日、仕分け、理由、連絡日を残す） | 仕分けのたび | 表を自分の端末に置く。あとで集計できない |
| 週次の報告（応募、通過、見送り、迷う、連絡の遅れ、面接でのずれ、次に直すこと一つ） | 週に一度、決めた曜日 | 数字だけ並べて、基準の何を直すかが無い |

止まりやすいのは、迷う人を「もう少し見てから」と手元に置くときです。迷う人はその日に返し、決める人の期限を記録します。期限を過ぎたら、遅れているのは会社側であることが記録に残ります。連絡の速さの考え方は[連絡の速さ](/media/fukugyo-renraku-sokudo/)に、報告の型は[報告の仕方](/media/fukugyo-houkoku/)に書いています。

## 月次：通過率と面接でのずれから基準を直す

月に一度、会社と見直しの時間を持ちます。見るのは、通過率の高低ではなく、「面接でずれた人の共通点」と「迷う人が多い理由」です。

| 見ること | 直すところ |
|---|---|
| 面接でずれた人の経歴と基準を並べる | 基準に足りなかった一行を足す |
| 迷う人が多い | 迷うの定義が広い。基準の必須がぼやけている。必須を経歴で読める形に直す |
| 通過が少なく面接の枠が埋まらない | 必須が多すぎる。歓迎に落とせる項目を会社に提案（決めるのは会社） |
| 通過は多いが面接に来ない | 連絡の速さと文面。面接の候補日の出し方 |
| 会社側の迷う人の返事が遅い | 決める人と期限の見直しを会社に提案 |

止まりやすいのは、月次で「通過率が高いので厳しくします」と感覚で調整するときです。厳しくしても精度は上がらず、通過率が下がるだけです。基準に戻し、足りない一行を足すか、ぼやけた一行を直します。一度に全部を変えず、一つずつ変えて比べます。

### エラベルの見解

同じ料金・同じ応募数でも、結果が分かれるのは、月次の見直しで「基準の一行に戻すか」です。面接でずれた人が出たとき、「次はもっと厳しく見ます」と返す担当者は、通過率が下がって面接の枠が埋まらず、三か月目に「効果が無い」と契約を終えられます。ずれた人の経歴と基準を並べて、「ずれた人は、経歴のこの項目が共通しています。基準にこの一行を足しませんか。逆に、この必須は歓迎に落としても面接でのずれは増えないと思います」と、基準の言葉で会社に返す担当者は、次の月から面接でのずれが減り、通過率も保てます。エラベルで長く続いている担当者は、月次の報告に「基準に足す一行」と「歓迎に落とせる一行」の二つの欄を持っています。受ける側がその場で使える形としては、面接でずれた人が出るたびに、その人の経歴と基準を並べた一行を記録の表に書き足しておくこと。月次には、それを並べるだけで提案になります。

## 終了と更新：引き継ぎと次の提案

契約の期間が来たら、更新か終了かを会社が決めます。どちらでも、引き継げる形にして終えます。

- **残すもの。** 基準表（承認されたもの、月次で直した履歴）、迷う人の定義と返し方、連絡の文面の型、記録の表（会社の管理する場所に）、面接でずれた人の共通点の一覧
- **返すもの。** 採用管理システムなどの権限、共有された資料。応募書類は自分の手元に一切残さない（残していないことを確かめて伝える）
- **次の提案。** 更新するなら、次の期間で直す基準。終了するなら、社内で回すための手順書と、最初の一か月で見る数字

止まりやすいのは、終了が決まってから引き継ぎの資料を作り始めるときです。基準表と記録の表を会社の管理する場所に置いて更新し続けていれば、終了時に渡すものはすでにそこにあります。引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に書いています。

## 応募書類の扱い

書類選考は、応募書類という個人情報をまとめて扱う仕事です。会社の管理する場所（採用管理システムや会社の共有の仕組み）の中でだけ見て、自分の端末やクラウドに保存せず、印刷せず、メールで転送しません。記録の表も会社の管理する場所に置き、表に書くのは仕分けの理由と日付にとどめ、応募書類の中身を写しません。基準にしてはいけない項目が応募書類にあっても、読み飛ばし、記録にも書きません。閲覧の記録が残る仕組みなら、その中で見ます。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)と[セキュリティの基本](/media/fukugyo-security/)に書いています。個別の判断は専門家にご確認ください。

## 稼働時間は何で決まるか

週に何時間かかるかは、応募数と、一件あたりに経歴を読んで理由を一行書く時間で決まり、それに連絡と記録の時間が足されます。応募数が多い時期と少ない時期で稼働が変わるので、受ける前に「一日の応募数の目安」と「超えたときの扱い」を決めておけば、見込みが立ちます。基準が経歴で読める形に整っているほど、一件あたりの時間は短くなります。数値は案件ごとに違うので、最初の一か月の実績で見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→第1週→第2週以降→月次→終了と更新**の五つの段階
- 契約前に**範囲・応募数の目安・迷う人を決める人と期限・応募書類の扱いと契約・基準にしてはいけない項目・連絡の名義と文面・報告・評価**を決める
- 第1週は**仕分けない**。要件の確認と基準と文面の承認と記録の表に使い、溜まっている分は受付の連絡だけ出す
- 第2週以降は**決めた時間帯に毎日、受付→仕分け→迷う人をその日に返す→翌日までに連絡→記録**を回し、週次で数字と「次に直すこと」を一つ報告する
- 月次は**面接でずれた人の経歴と基準を並べ、基準に足す一行と歓迎に落とせる一行**を提案する。感覚で厳しくしない
- 終了時は**基準表・迷う人の定義・文面の型・記録の表・ずれの共通点**を残し、応募書類を手元に一切残さない
- 応募書類は**会社の管理する場所でだけ見て、保存・印刷・転送をしない**

## よくある質問

### 溜まっている応募を第1週に見ないと、会社に断られませんか

「見ない」ではなく「受付の連絡だけ当日中に出して、仕分けは基準の承認後にまとめて行う」と伝えます。候補者にとって最も困るのは、応募したのに何の連絡も無いことなので、受付の連絡が出ていれば、仕分けが一週間後でも問題は小さい。基準の無いまま仕分けて面接でずれた人を通すほうが、会社の損は大きい。契約前の稼働の計画に第1週の中身を書いておけば、始まってから揉めません。

### 会社が迷う人の判断を返してくれません

記録の表に、返した日と期限を残しておき、期限を過ぎたら一度だけ催促します。それでも返らない場合、候補者への連絡は「選考中」の旨を出して待たせすぎないようにし、週次の報告で「迷う人の返事の遅れ」を数字で出します。月次では、決める人と期限の見直しを提案します。自分で決めて連絡してはいけません。合否の確定は会社のものです。関わり方の段階は[合否にどこまで関わるか](/media/fukugyo-gouhi/)に書いています。

### 採用管理システムを使ったことがありません

仕組みは会社ごとに違いますが、応募の一覧、書類の閲覧、ステータスの変更、連絡の送信、の四つができれば回ります。第1週に、会社の担当者に操作を一度見せてもらい、権限の範囲（見られるもの、変えられるもの）を確かめます。自分の端末に書類を落とさず、システムの中で完結させることが、操作の上手さより大切です。使い方の考え方は[採用管理システムの技能](/media/fukugyo-ats-skill/)に書いています。
