人事がいない。総務の担当者が兼務で採用と労務を見ているが、限界。人事を採ろうと「人事担当募集」の求人を出したが、応募が来ない。来ても、経験が浅く、一人で回せそうにない。経験者は、条件が合わないか、「一人で全部」の役割を敬遠する。人事がいないので、人事の採用を、人事の経験の無い人が進めている。結論を先に書くと、**人事が採れないのは、「人事経験者」という広い枠で探しているからです。人事の仕事は、採用、労務、評価、育成、制度と幅広く、全部を一人で担える経験者は少なく、いても「一人で全部」の役割は敬遠されます。自社の人事の役割を分け、「最初の一人に何を求めるか」を絞れば、探す相手が明確になり、届く経路も見極め方も決まります**。人事を育てる話は[社内の採用担当を育てる](/media/rpo-jinji-ikusei/)に、人事が一人で回らない場合は[人事が一人で回らない](/media/rpo-jinji-hitori-kadai/)にまとめています。

## 人事が採れない構造

人事担当が採れないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「人事経験者」の枠が広すぎる | 採用、労務、評価、育成、制度。全部の経験者を探している。市場に少ない |
| 「一人で全部」の役割 | 経験者ほど、「一人で全部」の役割を敬遠する。孤立と負担が見えるから |
| 求人票が、人事の仕事の中身を書いていない | 「人事業務全般」。何を任せるかが無く、応募の判断ができない |
| 人事の採用を、人事以外が進めている | 求人票の書き方も、見極めの観点も、人事の視点が無い |
| 条件が、市場と合っていない | 人事経験者の市場の水準を知らず、事務職と同じ幅で出している |
| 「人事を採ればすべて解決」と思っている | 人事が来ても、役割と権限と体制が無ければ、その人も回らずに辞める |
| 人事の経路を知らない | 人事経験者がいる場所（人事のコミュニティ、人事に強い紹介会社）を使っていない |

構造の大半は、「人事の役割を分けていない」ことです。分ければ、探す相手が明確になります。

## 自社の人事の役割の分け方

人事の仕事を、役割に分けます。

| 役割 | 中身 | 外に出せるか |
|---|---|---|
| 採用 | 求人票、経路、応募の対応、面接の設計と進行、内定、受け入れ | 大半を採用代行に出せる。判断は社内 |
| 労務 | 給与、社会保険、勤怠、手続き、規程の管理 | 大半を社労士や給与計算の外部に出せる。判断は社内 |
| 評価 | 評価の制度、運用、面談の設計 | 制度の設計は外部の支援が使える。運用は社内 |
| 育成 | 研修の企画、教える型、新人の受け入れ | 企画は外部の支援が使える。運用は現場と社内 |
| 制度 | 就業規則、人事制度、働き方の制度 | 設計は外部（社労士、コンサルタント）の支援が使える。決定は社内 |
| 組織 | 配置、異動、組織の変更、経営者との調整 | 社内 |
| 相談 | 社員からの相談、トラブルの対応 | 社内。外部の相談窓口を併用する会社もある |

分けると、「外に出せる役割」と「社内に残る役割」が見えます。全部を一人に求める必要は無く、「社内に残る役割」を担える人を、最初の一人として探します。

外に出せる役割を先に外に出せば、最初の一人に求めるものは小さくなります。採用は採用代行に、労務は社労士に。残るのは、判断と、組織と、相談。

## 最初の一人に求めるもの

役割を分けたら、最初の一人に何を求めるかを決めます。

**「全部できる人」ではなく、「社内に残る役割を担い、外に出す役割を管理できる人」。** 採用代行や社労士を使いながら、判断と組織と相談を担う人。全部を自分でやる人ではありません。

**自社の段階に合わせる。** 社員が数十人なら、採用と労務の基本が回せて、制度を少しずつ作れる人。数百人なら、制度と組織を担える人。段階が違えば、求める経験が違います。

**「最初の一人」に特有の要件。** 前例が無い状態で、型を作れる人。経営者と直接話せる人。「人事の部門がある会社で、その一部を担っていた人」より、「小さい会社で、人事を立ち上げた経験がある人」が合うことがあります。

**経験の幅より、深さと「立ち上げ」。** 採用・労務・評価・育成・制度の全部の経験より、「一つか二つを深く、かつ、無いところに作った経験」。

**外に出す役割の管理ができるか。** 採用代行や社労士と、どう付き合うか。「全部自分でやりたい」人は、外に出す前提の役割に合いません。

**役割の記述を、一枚にする。** 「何を決める役割か」「誰と働くか（経営者、現場の責任者、外部）」「どこまで担うか」「最初の三か月に何をするか」「何ができないと詰まるか」「どう評価されるか」。作り方は[ジョブディスクリプションがない](/media/rpo-jd-nai/)に書いています。

求めるものが決まれば、求人票に書け、見極めの観点が作れ、条件の幅も決まります。

## 人事経験者に届く経路

人事経験者は、他の職種と探す場所が違うことがあります。

| 経路 | 使い方 |
|---|---|
| 人事に強い紹介会社 | 人事の職種に特化した紹介会社は、人事の役割の中身を理解して推薦できる。自社の役割の一枚を渡す |
| スカウト型 | 「最初の人事として、型を作る役割」を一段落目に。「人事部門の一員」を求める人より、「作りたい人」に届く |
| 人事のコミュニティ | 人事の勉強会、集まり。経営者や責任者が参加し、会社と役割を話す |
| 副業・業務委託の人事から | 副業や業務委託で人事を担っている人に、まず関わってもらい、合えば本採用。契約の形と法令上の扱いは専門家に確認。[副業人材から本採用につなげる](/media/rpo-fukugyo-saiyo/) |
| 採用代行の担当者から | 採用代行の担当者の中に、社内の人事に転じる人がいる。ただし、代行会社との契約と関係に配慮 |
| 社内からの登用 | 総務や現場の責任者で、人事に関心のある人を、外部の支援を付けて人事に。「経験者を採る」の代わりになることがある |
| 経営者や役員の人脈 | 経営者の知り合いの人事経験者。小さい会社の最初の人事は、人脈で決まることが多い |

経路の要点は、「最初の人事として型を作る役割」を、経路の一段落目で伝えることです。「人事担当募集」では、届きません。

## 人事を見極める観点

人事経験者を、何で見極めるかです。人事の経験の無い人が面接する場合の観点でもあります。

| 観点 | 確認の仕方 |
|---|---|
| 立ち上げの経験 | 「無いところに、人事の型を作った経験はありますか。何を、どう作りましたか」。具体的な場面で |
| 深さのある領域 | 「採用・労務・評価・育成・制度のうち、最も深く担ったのはどれですか。具体的に」 |
| 外部との付き合い | 「採用代行や社労士と、どう仕事をしましたか」。「全部自分で」の人か、「外を使う」人か |
| 経営者との距離 | 「経営者と直接、人事の判断を話した経験はありますか」。最初の人事は、経営者と直接話す |
| 自社の段階への理解 | 「この規模の会社で、最初の人事として何から手を付けますか」。段階に合った答えか |
| 現場との関係 | 「現場が採用や評価に協力しないとき、どうしましたか」。人事は現場と経営者の間に立つ |
| 判断の型 | 「〇〇の判断で迷った場面と、どう決めたか」。人事は判断の連続 |
| 法令への姿勢 | 「法令上の扱いが分からないとき、どうしますか」。「専門家に確認する」と言えるか |

見極めの要点は、「立ち上げの経験」と「外を使う姿勢」です。「人事部門の一員として、決まった型を回していた人」は、最初の人事には合わないことがあります。

人事の経験の無い人が面接する場合、上の観点と質問を一枚にし、答えの「具体性」で判定します。具体的な場面を語れるかどうかは、人事の経験が無くても判断できます。技術的な確認（労務や制度の知識）は、外部（社労士、人事の顧問）に一部を頼む形もあります。

### エラベルの見解

相談で最も多い失敗は、「『人事担当募集・人事業務全般』で求人を出し、半年応募が無く、来た経験の浅い人を採り、その人が『一人で全部』に潰れて半年で辞めた」というものです。役割を分けず、外に出せる役割（採用、労務）を外に出さず、最初の一人に全部を載せました。採用は代行に、労務は社労士に出し、「判断と組織と相談を担い、外部を管理する最初の人事」と役割を絞って、人事に強い紹介会社に一枚を渡したら、二か月で「立ち上げの経験がある人」が推薦され、決まりました。

見ていて差がつくのは、担当者が「人事の役割を分ける」ところから入るかどうかです。「人事の求人を出しましょう」で「人事業務全般」と書く担当者と、「まず、御社の人事の役割を分けて、外に出せる役割を先に出しましょう。最初の一人に残る役割を絞ってから、求人を出します」と、分けてから出す担当者がいます。後者は、「一人で全部」の求人を出しません。

発注側にできるのは、「人事を採りたい」の前に、「人事の役割のうち、外に出せるものを出したか」を確認することです。

## 人事がいない間の進め方

最初の人事が採れるまでの間、人事の仕事をどう回すかです。

**採用は、採用代行に出す。** 求人票、経路、応募の対応、面接の設計、日程、連絡、記録。判断（要件、判定、内定）は経営者か責任者。人事の採用そのものも、代行に出せます。

**労務は、社労士や給与計算の外部に出す。** 給与、社会保険、手続き。判断は経営者か総務の責任者。

**制度と規程は、社労士や外部の支援で最低限を整える。** 就業規則、基本の制度。

**相談と組織は、経営者か責任者が持つ。** 外に出せない役割。最初の人事が来るまで、経営者が担います。

**人事の採用を、採用代行が進める。** 役割の分け方、一枚の作成、経路、見極めの観点、面接の設計。人事の経験の無い社内の人が進めるより、人事の採用を見ている担当者が進めるほうが、早く決まります。

**最初の人事が来たら、外に出した役割の管理を引き継ぐ。** 「採用は代行、労務は社労士。あなたは判断と組織と相談、そして外部の管理」。外に出した役割を、来た人事が全部引き取る形にしない。

人事がいない間の要点は、「外に出せる役割を先に出し、経営者は外に出せない役割だけを持つ」ことです。経営者が全部を抱えると、人事の採用そのものが進みません。

## 外注する場合の範囲

人事担当の採用を、採用代行に出す場合の範囲です。

**出せる工程。** 自社の人事の役割の分け方の整理、外に出せる役割の整理と外部の候補（社労士、給与計算など）の提示、最初の一人に求めるものの整理と役割の一枚、条件の幅の市場との確認（人事に強い紹介会社への聞き取り）、求人票、経路の設計と運用（人事に強い紹介会社への説明、スカウトの文面、コミュニティの活用の案）、見極めの観点と質問、面接官（経営者）向けの一枚、応募の受付と返信、日程調整、記録、条件のすり合わせ、内定、受け入れの型（最初の人事が来たときの外部の管理の引き継ぎ）、人事がいない間の採用の運用。

**社内に残す判断。** 役割の分け方の決定、外に出す役割の決定と契約、最初の一人に求めるものの決定、条件の決定、判定、内定、最初の人事の権限と体制の決定。

**外注の効きどころ。** 人事の採用は、「人事の視点で進める人が社内にいない」ことが最大の壁です。担当者が人事の役割を分け、最初の一人の役割を絞り、人事に届く経路と見極めの観点を持ち込めば、人事の経験の無い経営者でも判断できます。担当者は複数の会社の最初の人事の採用を見ているので、「この規模なら、最初の一人にはこれを求める」の型を持ち込めます。

**外注しても動かない場合。** 経営者が「一人で全部できる人」を譲らない、外に出せる役割を出さない、来た人事に権限と体制を渡さない。社内の判断で、代行を替えても直りません。

人事は、役割を分けて、最初の一人に求めるものを絞れば、採れます。外注は、分けて絞る手順と、人事に届く経路を持ち込む手段です。

### エラベルの見解

担当する側から見ると、人事の採用の相談で最も多いのは、「人事を採れば、採用も労務も評価も全部解決する」と経営者が思っていることです。人事が来ても、役割と権限と体制が無ければ、その人も「一人で全部」に潰れます。

人事を採る前に、「採用は代行、労務は社労士」と外に出し、経営者が「判断と組織と相談」を持ってみる。それで、最初の人事に何を求めるかが、経営者自身に見えてきます。「人事がいないから何もできない」ではなく、「人事がいない間に、外に出せるものを出し、残るものを知る」。

発注側にできるのは、人事の採用と並行して、外に出せる役割を今すぐ出すことです。

## まとめ

- 採れないのは**枠が広すぎる・一人で全部・中身を書いていない・人事以外が進めている・条件が市場と合わない・採れば解決と思う・経路を知らない**構造
- 役割は**採用・労務・評価・育成・制度・組織・相談**に分け、外に出せる役割（採用は代行、労務は社労士など）を先に出す
- 最初の一人には**社内に残る役割を担い外部を管理できる人・段階に合わせる・立ち上げの経験・深さと立ち上げ・外を使う姿勢・役割の一枚**
- 経路は**人事に強い紹介会社・スカウト（型を作る役割を一段落目に）・コミュニティ・副業や業務委託から・代行の担当者から・社内からの登用・人脈**
- 見極めは**立ち上げの経験・深さのある領域・外部との付き合い・経営者との距離・段階への理解・現場との関係・判断の型・法令への姿勢**。具体性で判定
- いない間は**採用は代行・労務は外部・制度は最低限を外部で・相談と組織は経営者・人事の採用は代行が進める・来たら外部の管理を引き継ぐ**
- 外注できるのは**役割の分け方・外部の候補・一枚・条件の確認・求人票・経路・観点・経営者向けの一枚・受付と日程と記録・すり合わせ・受け入れ・いない間の運用**。社内に残るのは**分け方の決定・外に出す決定と契約・求めるもの・条件・判定・内定・権限と体制**

## よくある質問

### 人事の経験が無い経営者が、人事を面接して見極められますか

見極められます。観点（立ち上げの経験、深さのある領域、外部との付き合い、経営者との距離、段階への理解、現場との関係、判断の型、法令への姿勢）と質問を一枚にし、答えの「具体性」で判定します。具体的な場面を語れるかどうかは、人事の経験が無くても判断できます。労務や制度の知識の確認は、社労士や人事の顧問に面接の一部を頼む形もあります。「人事業務全般の経験」で見ようとすると見極められませんが、役割を絞れば見極められます。

### 「一人で全部」の人事を採らないと、費用が二重になりませんか

「一人で全部」の人事は、市場に少なく、いても敬遠され、来ても潰れます。採用は代行、労務は社労士に出し、最初の人事は「判断と組織と相談、外部の管理」に絞るほうが、採れる確率も定着も上がります。費用は、人事一人の人件費と外部の費用を足したものと、「採れない期間の損失」「潰れて辞めた後の再採用」を並べて判断します。全部を一人に載せる形が、最も高くつくことが多いです。

### 社内の総務の担当者を、人事にすることはできますか

できます。人事に関心があり、現場と経営者の間に立てる人なら、外部の支援（採用代行、社労士、人事の顧問）を付けて、人事に登用する形があります。「経験者を外から採る」の代わりになり、自社を知っている強みがあります。ただし、「一人で全部」にしない、外に出せる役割は出す、育てる型（[社内の採用担当を育てる](/media/rpo-jinji-ikusei/)）を持つ、の三つは、外から採る場合と同じです。
