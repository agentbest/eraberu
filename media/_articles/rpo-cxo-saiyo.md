事業が大きくなり、財務を任せられるCFO、技術を任せられるCTO、事業の運営を任せられるCOOが要る。「CFO募集」と求人を出したが、応募は来ない。紹介会社に聞いても、「該当者は少なく、いても御社の規模と条件では」と言われる。たまに会えても、経営者と合うかどうか、何で判断すればよいか分からない。結論を先に書くと、**CxOクラスは、求人では探せません。求人に応募する形で動く層ではなく、「経営の課題」と「経営者の言葉」で、人脈・紹介・顧問から、時間をかけて見つける層です。探す前に、経営者が「何を任せ、どこまで権限を渡し、どういう関係を作るか」を決め、経営者自身が探す工程の中心に立ちます。数か月から一年かかることを前提に、動きます**。幹部・管理職の採用は[幹部・管理職が採用できない](/media/rpo-kanbu-saiyo/)に、後継者の話は[後継者候補を外から採るべきか](/media/rpo-koukei-sha/)にまとめています。

## CxOが求人で探せない理由

CxOクラスが、求人では探せない理由です。

| 理由 | 中身 |
|---|---|
| 求人に応募する形で動かない | CxOの候補者は、「募集を見て応募する」より、「話を聞いて、課題に興味を持って、経営者と合って決める」形で動く |
| 市場に出ている人が少ない | 現職で経営を担っている人は、転職の市場に出ていない。出ていても、紹介や人脈で決まる |
| 「募集」の形が、候補者に軽く見える | 「CFO募集」の求人票は、「経営の役割を、募集で埋めようとしている会社」と受け取られる |
| 経営者との相性が、決め手 | 経験や経歴より、「この経営者と一緒に経営できるか」で決まる。求人票では伝わらない |
| 条件と契約の形が、一般の採用と違う | 報酬、株式、役員か従業員か、契約の期間。求人票の「年収」の枠に収まらない |
| 時間がかかる | 数か月から一年。求人の「いつまでに」の感覚と合わない |
| 会社の段階と、候補者の経験の段階が合う必要がある | 大きな会社のCFOが、小さい会社の段階に合うとは限らない。逆も |

CxOの採用は、「募集」ではなく「探して、会って、口説く」工程です。求人票を出して待つ形は、最初から合いません。

## 探す前に経営者が決めること

CxOを探す前に、経営者が決めることがあります。決めていないと、探しても会えず、会っても決まりません。

| 決めること | 中身 |
|---|---|
| なぜ、いま、この役割か | 事業のどの段階で、どの課題が、経営者一人では解けなくなったか。「CFOが要る」ではなく、「資金の調達と財務の体制を、経営者以外が担う必要が出た」のように |
| 何を任せるか | 担う領域。財務なら、資金、会計、管理、投資家との関係、のどこまで |
| どこまで権限を渡すか | 決められること、経営者と決めること、経営者が決めること。役員会での位置づけ |
| 経営者との関係 | 「右腕」か「対等な経営のパートナー」か「特定の領域の専門家」か。関係の形で、探す人が変わる |
| 会社の段階 | いまの規模と、一〜三年後の姿。候補者の経験の段階と合わせる |
| 報酬と契約の形 | 報酬の幅、株式や持分の有無、役員か従業員か、契約の期間。専門家（弁護士、税理士、社労士）に確認 |
| 時間の見込み | 数か月から一年。その間、その領域を誰がどう担うか |
| 既存の幹部との関係 | 既存の役員や幹部が、新しいCxOをどう受け止めるか。先に話しておく |

決めることの要点は、「なぜ、いま、この役割か」を、経営の課題の言葉で語れることです。候補者は、この言葉で「興味を持つか」を決めます。

「何を任せるか」と「どこまで権限を渡すか」は、書面にします。書面が無いと、迎えた後に衝突します。書面の作り方は[幹部・管理職が採用できない](/media/rpo-kanbu-saiyo/)の役割の一枚と同じ考え方で、内容は経営の役割の単位です。

## 届く経路

CxOクラスに届く経路は、限られています。複数を、同時に、時間をかけて動かします。

| 経路 | 特徴 | 使い方 |
|---|---|---|
| 経営者の人脈 | 最も多い経路。取引先、投資家、前職の関係、経営者の集まり | 「こういう課題で、こういう役割を任せる人を探している」と、経営者が直接、繰り返し伝える。一度では届かない |
| 投資家・株主・顧問の紹介 | 会社の状況を知っている人からの紹介。候補者にも信用が伝わる | 課題と役割を共有し、紹介を頼む |
| 経営幹部に特化した紹介会社 | CxOの候補者を持つ紹介会社。役割と課題と経営者の人柄で推薦できる | 経営者が直接会い、課題を話す。手数料の水準と条件は各社の公式の案内と契約で確認 |
| 顧問・社外役員・業務委託から | まず顧問や社外の立場で関わってもらい、合えばCxOに。相性を時間をかけて見られる | 契約の形と法令上の扱いは専門家に確認。[業務委託で入ってもらってから採用する](/media/rpo-gyoumu-itaku-saiyo/) |
| 経営者の集まり・業界の場 | 経営者や経営幹部が集まる場で、会社と課題を話す | 「採用」の場ではなく、「知ってもらう」場。時間をかけて関係を作る |
| スカウト（経営者の名前で） | 動いていない人にも届く。経営者の名前と、経営の課題で | 定型は読まれない。一人ずつ、課題と役割を書く。文面は[幹部・役員クラスへのアプローチ](/media/scout-kanbu-scout/) |
| 内部の幹部の昇格 | 外から探す前に、内部に候補がいないか | いる場合は、外部の支援（顧問、育成）を付ける選択肢。いない場合は、いない理由を明確に |

経路の要点は、「経営者が、課題と役割を、自分の言葉で、繰り返し伝える」ことです。人事が代わりに伝える形では、CxOには届きません。

複数の経路を同時に動かし、数か月から一年かけます。「三か月で決まらないから諦める」形では、見つかりません。

## 経営者との相性の見極め

CxOの見極めは、経験や経歴より、「経営者と一緒に経営できるか」です。

| 観点 | 確認の仕方 |
|---|---|
| 課題への見方 | 「この課題を、どう見ますか。どこから手を付けますか」。経営者の見方と、違いがあるか。違いを対話で埋められるか |
| 権限の求め方 | 「何を決めさせてもらえれば、力を発揮できますか」。自社の「渡す権限」と合うか |
| 経営者との関係の作り方 | 「経営者と意見が違うとき、どうしますか」。従うでも押し通すでもなく、対話し、決めた後は動けるか |
| 会社の段階への理解 | 「この規模の、この段階で、最初の半年に何をしますか」。大きな会社の型を持ち込むだけか、段階に合わせられるか |
| 決めた経験と責任 | 「経営の判断で、自分が決めて、責任を取った最も大きなことは」。責任を自分の範囲で語れるか |
| 既存の幹部との関係 | 「既存の役員や幹部と、どう関係を作りますか」。いきなり変えるか、まず聞くか |
| 時間の使い方 | 「経営者と、どのくらいの頻度で、何を話したいですか」。関係の密度の希望が合うか |
| なぜ自社か | 「なぜ、この会社の、この課題を」。理由が具体的か。「経営の役割ならどこでも」ではないか |
| 価値観 | 「会社のこの判断（過去の判断の例）を、どう思いますか」。価値観の近さと、違いの許容 |

相性の見極めは、一回の面接では分かりません。複数回、時間をかけて、場面を変えて（食事、事業の現場、既存の幹部との対話）会います。顧問や社外の立場で数か月関わってもらう形が、最も確かです。

見極めの要点は、「違いがあるか」ではなく「違いを対話で埋められるか」です。経営者と全く同じ見方のCxOは、要りません。違う見方を持ち、対話し、決めた後は動ける人が、経営のパートナーです。

### エラベルの見解

相談で最も多い失敗は、「CFOが要ると思い、『CFO募集』の求人を紹介会社数社に出し、半年で数人に会ったが、『規模が合わない』『経営者と合わない』で決まらず、その間、財務の課題は放置された」というものです。求人で探す形が合っていませんでした。「なぜ、いま、CFOか」を経営の課題の言葉で整理し、経営者が投資家と顧問と経営者の集まりで直接伝え、まず顧問として関わってもらう形で二人に会い、一人が半年後にCFOとして入りました。求人を出していた半年は、動いていない半年でした。

見ていて差がつくのは、担当者が「求人で探さない」と最初に言えるかどうかです。「CxOの求人を紹介会社に出しましょう」と言う担当者と、「CxOは求人では探せません。まず経営者と、課題と任せることと権限を整理し、経営者の人脈と顧問の形から動きましょう。一年かかる前提です」と、探し方を変える担当者がいます。後者は、経営者の時間を正しい工程に使います。

発注側にできるのは、CxOの採用を「募集」ではなく「経営者が探して口説く工程」と捉え、経営者自身が時間を出すことです。

## 条件と契約の形

CxOの条件と契約は、一般の採用と違います。

**報酬の幅。** 役割と段階と市場で決めます。既存の役員との整合も見ます。市場の水準は、経営幹部に特化した紹介会社に聞きます。数字を資料に載せる場合は出典を明記します。

**株式や持分の有無。** 事業の段階によっては、報酬の一部を株式や持分で、という形があります。設計は専門家（弁護士、税理士）に確認します。

**役員か従業員か。** 取締役として迎えるか、執行の役員か、従業員として迎えるか。責任と権限と法令上の扱いが違います。専門家に確認します。

**契約の期間と、見直しの時期。** 役員なら任期、従業員なら試用の扱い。「一年で見直す」のような形。専門家に確認します。

**入社の時期。** 現職の引き継ぎがあり、内定から入社まで数か月かかることが多い。その間の接点を設計します。

**顧問や社外の立場から始める場合の契約。** 顧問契約、業務委託。そこからCxOに移る場合の契約の切り替え。専門家に確認します。

**既存の役員との整合。** 新しいCxOの報酬と権限が、既存の役員と整合しているか。整合しないと、既存の役員との関係が崩れます。

条件と契約の要点は、「専門家に確認する」ことと「既存の役員との整合」です。CxOの契約は、一般の雇用契約の型では収まりません。

## 迎えた後の最初の一年

CxOを迎えた後の、最初の一年です。

| 時期 | やること |
|---|---|
| 入社前 | 任せることと権限の書面を改めて共有。既存の役員と会う。経営者と月に一度以上話す |
| 最初の一か月 | 現状の把握。既存の幹部と社員に聞く。経営者と週に一度以上話す。大きな判断はまだ |
| 二〜三か月 | 課題の整理と、一年の計画の案。経営者と合意。役員会での位置づけを実際に動かす |
| 四〜六か月 | 計画の実行。渡した権限の範囲で判断を重ねる。経営者は口を出しすぎない |
| 半年の振り返り | 「なぜ、いま、この役割か」の課題に対して、どこまで来たか。権限の範囲を見直す |
| 一年の振り返り | 一年の計画の達成。関係の状態。契約の見直しの時期なら見直し |
| 経営者の接し方 | 渡した権限は渡す。持つと決めた権限は持つ。境界を守る。違いは対話で埋める |
| 既存の幹部との関係 | 衝突があれば、経営者が間に立つ。放置しない |

最初の一年の要点は、「経営者が境界を守る」ことと「違いを対話で埋め続ける」ことです。「任せる」と言って口を出す、「違う」と感じて距離を取る、のどちらも、CxOを孤立させます。

## 外注する場合の範囲

CxOの探し方を、採用代行に出す場合の範囲です。

**出せる工程。** 探す前に決めることの整理の支援（経営者への聞き取りと書面化）、「なぜ、いま、この役割か」の経営の課題の言葉での整理、経路の設計（人脈への声かけの整理、経営幹部に特化した紹介会社への説明の同席、経営者の名前でのスカウトの文面）、候補者との連絡と日程、見極めの観点と対話の場の設計（複数回、場面を変えて）、条件と契約の形の整理（専門家との連携の橋渡し）、顧問や社外の立場から始める形の設計、内定から入社までの接点の設計、最初の一年の振り返りの型、既存の役員との関係の設計の支援。

**社内に残す判断。** 「なぜ、いま、この役割か」の決定、任せることと権限の決定、関係の形の決定、経路の中心に立つこと（経営者）、相性の判断、条件と契約の決定（専門家との連携）、既存の役員への説明、境界の遵守。

**外注の効きどころ。** CxOの採用は、「経営者が探して口説く工程」で、担当者は経営者の代わりにはなれません。担当者ができるのは、経営者の時間を正しい工程に使うための準備（決めることの整理、経路、観点、文面、日程、契約の形の橋渡し）と、「求人で探さない」「一年かかる」を最初に伝えることです。担当者は複数の会社のCxOの探し方を見ているので、「この段階の会社は、この経路から、この形で」の見立てを持ち込めます。

**外注しても動かない場合。** 経営者が「なぜ、いま、この役割か」を語れない、権限を渡すことを決めない、経営者が人脈に動かない、既存の役員に話さない。社内の判断で、代行を替えても直りません。

CxOは、経営者が探す層です。外注は、経営者の探す工程を整え、時間を正しく使う手段です。

### エラベルの見解

担当する側から見ると、CxOの相談で最も多いのは、「経営者が『何を任せるか』を決めずに、『優秀な人がいれば』と探している」ことです。「CFOが要る」と言うが、財務のどこを任せ、どこまで権限を渡し、どういう関係を作るかが無い。候補者に会っても、候補者から「何を任せてもらえますか」と聞かれて、答えられない。

CxOの候補者は、「任せること」と「権限」と「経営者との関係」で、興味を持つかどうかを決めます。「優秀な人」を探す前に、「何を任せる人」を決める。それが、CxOを探す出発点です。

発注側にできるのは、「CxOが要る」と思ったときに、「なぜ、いま、何を任せ、どこまで渡し、どういう関係で」を、経営者自身が一枚に書くことです。

## よくある質問

### CxOの求人を、紹介会社に出してはいけませんか

経営幹部に特化した紹介会社には、「求人を出す」のではなく、「経営者が直接会い、課題と役割と関係の形を話す」形で依頼します。一般の紹介会社に「CFO募集」の求人票を渡す形では、CxOの候補者には届きにくく、届いても「募集で埋めようとしている会社」と受け取られます。紹介会社は経路の一つで、経営者の人脈、投資家や顧問の紹介、顧問や社外の立場から始める形を、同時に動かします。一年かかる前提で。

### 経営者と合うかどうかは、どう判断すればよいですか

一回の面接では分かりません。複数回、場面を変えて（会議室、食事、事業の現場、既存の幹部との対話）会い、「課題への見方」「権限の求め方」「意見が違うときの対話」「段階への理解」「価値観」を見ます。最も確かなのは、顧問や社外の立場で数か月関わってもらい、実際の判断の場面で相性を見ることです。「違いが無いか」ではなく、「違いを対話で埋められるか」で判断します。経営者と全く同じ見方の人は、経営のパートナーになりません。

### CxOを迎えるのに、一年もかけられません

一年かかる前提で動き、その間、その領域を誰がどう担うかを別に設計します。財務なら、顧問の税理士や会計事務所、業務委託のCFO経験者。技術なら、技術の顧問や業務委託。「CxOが来るまで何もしない」ではなく、「来るまでの間を外部で支え、来た後に引き継ぐ」形にします。急いで合わない人を迎えると、経営の中枢での衝突と離職になり、一年より長い損失になります。急ぐなら、顧問や社外の立場から始める形が、最も早く、最も確かです。
