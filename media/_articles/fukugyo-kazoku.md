副業を始めたいが、家族に言い出せない。言ってみたら、「家のことはどうするのか」「本業に響かないか」と反対された。理解を得るには、どう伝えればよいのか。結論を先に書くと、**家族の理解を得るには、「したい気持ち」ではなく、「枠（曜日と時間）」「目的」「収入の使い道」「止める条件」「家族の負担の埋め方」の五つを具体的に示して相談します。家族が反対する理由の多くは、副業そのものではなく、「いつ、どれだけ、何のために、家のことはどうなるのか」が見えないことへの不安です。五つを示せば、家族は判断の材料を持て、不安は具体的な相談に変わります。気持ちだけで伝えると、家族は反対するしかありません。**子育てとの両立は[子育てと両立する](/media/fukugyo-kodomo/)に、介護との両立は[介護と両立する](/media/fukugyo-kaigo/)に、休みの設計は[休む設計](/media/fukugyo-yasumi/)にまとめています。

## 家族が反対する理由の切り分け

家族の反対は、一つに見えて、いくつかの理由が混ざっています。切り分けると、答え方が変わります。

| 反対の理由 | 家族の言葉 | 本当の不安 | 答え方 |
|---|---|---|---|
| 家の負担が増える | 「家のことはどうするの」 | 自分の負担が増える。子育てや家事が偏る | 枠と、家族の負担の埋め方を示す |
| 本業に響く | 「本業がおろそかにならない?」 | 収入の柱が揺らぐ。評価が下がる | 稼働の上限と、本業の評価を見ながら止める条件を示す |
| 体を壊す | 「疲れているのに、大丈夫?」 | 健康。倒れたら家族が困る | 休む枠と、疲れたら止める条件を示す |
| 何をするのか分からない | 「副業って、何をするの」 | 怪しいことに関わらないか。会社の規則に触れないか | 範囲と、依頼側の種類と、会社の許可の状況を示す |
| 一緒の時間が減る | 「家族の時間はどうなるの」 | 関係が薄くなる | 枠の外は家族の時間、という分け方を示す |
| お金の使い道が分からない | 「そのお金は何に使うの」 | 家計との関係。自分に関係があるのか | 収入の使い道を示す |
| 前に失敗した | 「前もそう言って続かなかった」 | また負担だけ残るのでは | 前回と違う点（枠、止める条件）を示す |

切り分けの要点は、「反対の言葉と、本当の不安は違う」ことです。「家のことはどうするの」は、副業への反対ではなく、自分の負担が増えることへの不安です。その不安に、「大丈夫」と答えても消えません。枠と負担の埋め方を具体的に示すことで、不安は「その枠なら」という相談に変わります。反対の理由を一つずつ聞き、本当の不安を見つけてから答えます。

## 相談の前に固める五つのこと

家族に相談する前に、五つを自分で固めます。固めていない状態で相談すると、家族の質問に答えられず、「考えていない」と見られます。

| 固めること | 内容 | 例 |
|---|---|---|
| 一、枠 | 曜日と時間。週に何時間か。枠の外では副業をしない | 「火・木の夜九時から十一時と、土曜の早朝二時間。週六時間。それ以外は触らない」 |
| 二、目的 | 収入の補い、経験の継続、次の準備、気持ちの切り替え、のどれが主か | 「人事の経験を本業以外でも試して、数年後の選択肢を広げたい」 |
| 三、収入の使い道 | 家計に入れるか、貯めるか、自分の費用か。額の見立ては控えめに | 「最初の半年は多くを見込まない。入った分は〇〇の費用に」 |
| 四、止める条件 | 本業の評価、体調、家族の負担、のどれかが崩れたら止める、と決める | 「本業の評価が下がったら、体調を崩したら、家族に負担が偏ったら、一度止める」 |
| 五、家族の負担の埋め方 | 枠の時間に家族が担うことと、その代わりに自分が担うこと | 「火・木の夜は皿洗いを頼む。代わりに土曜の午後は自分が子どもを見る」 |

五つの要点は、「四」の止める条件を、自分から先に示すことです。家族が最も不安なのは、「始めたら止まらないのでは」ということです。止める条件を自分から示せば、家族は「崩れたら止まる」と分かり、始めることに同意しやすくなります。止める条件は、家族が「今、崩れている」と言える形にしておきます。枠の決め方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、収入の見立ては[副業で月いくらを目指せるか](/media/fukugyo-nenshuu-mokuhyou/)に、止め方は[副業をやめるとき](/media/fukugyo-yameru/)に書いています。

### エラベルの見解

担当する側から見ると、副業が続いている人と、家族の反対で止まる人の差は、副業への意欲ではなく、「始める前に家族と枠を決めたか」です。続いている人は、始める前に曜日と時間を家族と決め、枠の外では副業に触れず、家族はその枠を「副業の時間」として扱っています。止まる人は、家族に軽く伝えて始め、枠がないので常に副業のことをしている状態になり、家族の不満が溜まって、途中で止めています。依頼側から見ると、家族の理由で途中で止まる担当者は、案件の途中で消える担当者と同じです。

見ていて差がつくのは、止める条件を家族と一緒に決めているかです。「本業の評価が下がったら」「体調を崩したら」「家族に負担が偏ったら」と決め、家族が「今、負担が偏っている」と言える形にしている人は、家族が不満を溜める前に言葉にでき、枠を直して続いています。決めていない人は、家族が不満を言い出せず、溜まった不満が「もうやめて」という形で出て、副業が止まります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠を明確にしている担当者が、家族との両立でも、依頼側との関係でも安定しています。家族の理解は、一度得るものではなく、枠と条件で保ち続けるものです。

## 伝え方の順番

五つを固めたら、この順番で伝えます。順番を間違えると、最初の一言で反対されます。

| 順番 | 伝えること | 言い方 |
|---|---|---|
| 一、相談として切り出す | 決めたことの報告ではなく、相談 | 「副業を考えていて、相談したい。反対があれば聞きたい」 |
| 二、目的を一言で | なぜ副業をしたいか | 「人事の経験を本業以外でも試して、数年後の選択肢を広げたい」 |
| 三、枠を具体的に | 曜日と時間。枠の外では触らない | 「火・木の夜と土曜の早朝。週六時間。それ以外は触らない」 |
| 四、家族の負担の埋め方 | 家族に頼むことと、代わりに担うこと | 「火・木の夜は皿洗いを頼みたい。代わりに土曜の午後は子どもを見る」 |
| 五、止める条件 | 崩れたら止めると、自分から | 「本業の評価、体調、家族の負担のどれかが崩れたら、一度止める。崩れていると思ったら言ってほしい」 |
| 六、収入の使い道 | 控えめな見立てと使い道 | 「最初は多くを見込まない。入った分は〇〇に」 |
| 七、家族の懸念を聞く | 反対の理由を、一つずつ聞く | 「心配なところはどこ?」 |
| 八、試す期間を決める | 三か月など、期間を決めて試し、見直す | 「三か月やって、崩れていたら見直す」 |

順番の要点は、「一」の、相談として切り出すことです。「副業を始めることにした」と報告の形で伝えると、家族は「決めてから言うのか」と感じ、内容の前に反発します。「相談したい。反対があれば聞きたい」と切り出せば、家族は意見を言える立場になり、内容を聞いてくれます。「八」の試す期間も、家族の同意を得やすくします。「ずっと」ではなく「三か月試して見直す」なら、家族は同意しやすく、三か月後に見直すことで、理解が保たれます。

## 始めた後に理解を保つ行動

理解は、始めるときに得て終わりではありません。始めた後の行動で、保たれるか、崩れるかが決まります。

| 行動 | 内容 | しないと |
|---|---|---|
| 枠を守る | 枠の外では副業に触れない。連絡も見ない | 「いつも副業をしている」と見られ、理解が崩れる |
| 枠の時間を見える形にする | カレンダーや貼り紙で、副業の時間を家族が見えるように | 家族が「今日は副業の日か」と毎回聞く負担 |
| 負担の埋め方を実行する | 「代わりに担う」と言ったことを、実際にやる | 「頼むだけ頼んで、代わりはしない」となる |
| 月に一度、状況を話す | どんな案件を受けているか（依頼側の情報は含めない）、収入、疲れ具合 | 家族が何をしているか分からず、不安が戻る |
| 止める条件が崩れていないか、家族に聞く | 「負担が偏っていない?」と自分から聞く | 家族が言い出せず、不満が溜まる |
| 収入の使い道を守る | 言った通りに使う | 「結局何に使ったのか」となる |
| 家族の予定を優先する | 家族の行事、体調不良は、副業の枠より優先する | 「副業の方が大事なのか」となる |

行動の要点は、「枠を守る」ことです。家族の理解が崩れる最大の原因は、枠の外で副業に触れることです。枠の外で依頼側の連絡を見る、返信する、考え込む、といったことが続くと、家族から見れば枠は無いのと同じです。枠の外では副業の端末を触らない、と決めて守ります。枠の外の扱いは[通勤時間の使い方](/media/fukugyo-tsuukin/)に、稼働の記録は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に整理しています。

## 理解が崩れる兆候と直し方

家族の理解は、崩れる前に兆候が出ます。兆候を見て、早く直します。

| 兆候 | 崩れているところ | 直し方 |
|---|---|---|
| 「また副業?」と言われる | 枠の外で副業に触れている | 枠の外で端末を触らない。枠を見える形にし直す |
| 家事や子育ての分担で、小さな衝突が増えた | 負担の埋め方が実行されていない | 「代わりに担う」を実行する。負担の埋め方を決め直す |
| 家族が副業の話を聞きたがらない | 何をしているか見えず、関心が消えている | 月に一度、状況を話す。収入と使い道を伝える |
| 疲れていることを指摘される | 休む枠がない。稼働が枠を超えている | 休む枠を入れる。稼働を減らす |
| 家族の予定と副業が重なることが増えた | 家族の予定を優先していない | 家族の予定を先にカレンダーに入れ、副業はその外に |
| 「やめたら?」と言われる | 止める条件が崩れている | 一度止める。三か月後に見直す。止める約束を守る |

兆候の要点は、「やめたら?」と言われたら、一度止めることです。止める条件を家族と決めていたなら、家族がそう言うのは、条件が崩れている合図です。「もう少し」と続けると、約束を破ったことになり、次に始めるときの理解が得られなくなります。一度止め、枠と負担の埋め方を直し、三か月後に再開の相談をします。止め方は[副業をやめるとき](/media/fukugyo-yameru/)に、続ける設計は[長く続けるための設計](/media/fukugyo-choki/)に書いています。

## 家族との枠の見直しの仕方

枠は、家族の状況の変化に合わせて見直します。見直しの仕方です。

| 見直しの時期 | 見ること | 直すこと |
|---|---|---|
| 始めて三か月 | 枠が守れていたか。家族の負担は偏っていないか。収入と目的は合っているか | 枠を縮めるか、そのまま続けるか、広げるか |
| 家族の状況が変わったとき | 子どもの進学、家族の体調、引っ越し、本業の異動 | 枠を一時的に縮めるか、時間帯を変える |
| 年に一度 | 一年の稼働、収入、家族の負担、本業への影響 | 来年の枠と目的を決め直す |
| 家族から「見直したい」と言われたとき | 何が崩れているか、家族の言葉で聞く | その場で枠を直す。先延ばしにしない |

見直しの要点は、「家族から言われたときは、その場で直す」ことです。家族が「見直したい」と言うのは、不満が溜まった後です。「今度話そう」と先延ばしにすると、不満は「やめてほしい」に変わります。その場で聞き、枠を直し、直した枠を見える形にします。年に一度の見直しは、家族と一緒に、稼働と収入と負担を並べて話します。年に一度の見直しの項目は[長く続けるための設計](/media/fukugyo-choki/)に、子どもの成長に合わせた見直しは[子育てと両立する](/media/fukugyo-kodomo/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「家族に反対されているなら、副業は諦めるしかない」というものです。実際には、家族の反対の多くは、副業そのものへの反対ではなく、枠と目的と負担と止める条件が見えないことへの不安です。五つを具体的に示して相談すると、多くの家族は「その枠なら」と同意し、三か月試す形で始められています。諦める前に、五つを固めて相談する価値があります。

順番として、家族の反対の理由を切り分けて本当の不安を見つけ、枠と目的と収入の使い道と止める条件と負担の埋め方の五つを固め、相談として切り出し、目的、枠、負担の埋め方、止める条件、収入の使い道の順で伝え、懸念を聞き、三か月試す期間を決め、始めたら枠を守り、月に一度状況を話し、兆候が出たら早く直し、「やめたら?」と言われたら一度止める。この順番で、家族の理解は、一度得るものではなく、枠と条件で保ち続けるものになります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の枠を家族と決めている担当者が、依頼側との約束も守れています。家族の理解は、副業の土台です。

## まとめ

- 家族の理解は**「したい気持ち」ではなく、枠・目的・収入の使い道・止める条件・家族の負担の埋め方の五つ**を具体的に示して得る
- 反対の言葉と本当の不安は違う。**「家のことはどうするの」は負担の不安**。枠と埋め方で答える
- **止める条件を自分から先に示す**。家族が「今、崩れている」と言える形に
- 伝え方は**相談として切り出し、目的 → 枠 → 負担の埋め方 → 止める条件 → 収入 → 懸念を聞く → 三か月試す**
- 始めた後は**枠を守り、負担の埋め方を実行し、月に一度状況を話し、家族の予定を優先する**
- **「やめたら?」と言われたら一度止める**。約束を守ることが、次の理解につながる

## よくある質問

### 家族に相談せずに、こっそり始めてもよいですか

避けることをお勧めします。副業は、枠の時間に家にいて作業をするので、家族には気づかれます。気づかれたときに「隠していた」となり、内容の前に信頼が崩れます。また、隠している状態では、枠を見える形にできず、負担の埋め方も決められず、家族の不満が溜まっても言葉にされません。始める前に、五つを固めて相談する方が、続きます。会社への伝え方も同じ考え方で、[副業許可の申請の出し方](/media/fukugyo-kyoka-shinsei/)に整理しています。

### 配偶者が「本業に集中してほしい」と言います。どう答えればよいですか

「本業に集中してほしい」の本当の不安は、収入の柱が揺らぐことと、評価が下がることです。稼働の上限（週六時間など）と、本業の評価が下がったら止めるという条件を示し、「本業を優先する。副業はこの枠の中だけ。評価が下がったら止める」と伝えます。それでも不安なら、三か月試して、本業への影響を一緒に見る形を提案します。本業への影響の見方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に、上限の決め方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に書いています。

### 家族が副業の内容を聞きたがります。依頼側の情報をどこまで話してよいですか

依頼側の会社名、候補者、条件は、家族にも話しません。「〇〇業界の会社で、求人票の改善とスカウトの文面を担当している」と、範囲と構造で話します。家族に話したことが外に出ることはないと思いがちですが、家族が知人に話し、それが依頼側に届くことがあります。家族には「守秘の約束があるので、中身は話せない」と伝えれば、理解されます。守秘の線は[守秘の線を越える](/media/fukugyo-shippai-8/)に整理しています。
