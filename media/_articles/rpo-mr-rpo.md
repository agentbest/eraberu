MRの採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、医薬品の情報提供の規範を知らない人にMRの採用が回せるのか」「経験者は市場にいるはずなのに、なぜ自社に来ないのか」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、領域と製品と担当施設の整理・担当エリアと転勤の方針・評価の仕方・会社のMRに対する方針・要件の決定・情報提供の質と医師との関係の評価・合否の判断は社内に残す**のが線です。MRは、営業職の中でも「情報提供の規範と法令」が関わり、業界で人員の見直しが続いているという特有の事情があります。候補者は「この会社はMRをどう位置づけているか」を、他の営業職より強く確かめます。そこを候補者に伝わる形で書く工程が、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、営業職の共通の線は[営業採用を代行に出す判断基準](/media/rpo-sales-rpo/)にまとめています。

## MR採用が他の職種と違う点

一つ目は、領域と製品と担当施設で市場が分かれることです。領域は、プライマリー（生活習慣病など幅広い疾患）か、スペシャリティ（がん、希少疾患、中枢神経など専門性の高い疾患）か。製品は、新薬か、長期収載品か、後発品か。担当施設は、開業医か、市中病院か、大学病院か。オンコロジーの新薬を大学病院で担当してきたMRと、プライマリーの長期収載品を開業医で担当してきたMRは、持っているものと市場が違います。「MR募集」だけでは、どれを求めているかが候補者に伝わりません。

二つ目は、雇用の形で候補者の見方が変わることです。製薬企業の直接雇用か、コントラクトMR（製薬企業に派遣される形）か。コントラクトMRには、プロジェクトの期間、契約終了後の扱い、製薬企業への転籍の可能性を確かめる人が多く、直接雇用のMRには、会社のMRに対する方針（人員をどうするか、デジタルへの移行をどう考えているか）を確かめる人が多い。

三つ目は、候補者が「領域と製品」「担当エリアと転勤」「評価の仕方」「会社のMRに対する方針」を最初に確かめることです。MRは、担当エリアが生活を決め、転勤の有無と頻度が家族の事情に直結します。評価が売上の数字か、情報提供の質や面談の内容か、両方か。そして、業界で人員の見直しが続く中で、この会社はMRを増やすのか減らすのか、デジタルの情報提供とどう分担するのか。「MR業務全般」では、この判断ができません。

四つ目は、医療機関への情報提供に、業界の規範と法令が関わることです。医薬品の情報提供の方法、医療関係者との関係、提供できる情報の範囲には、業界の自主規範と法令があり、求人票やスカウトで「売上を上げる」「処方を増やす」を前面に出す書き方は、候補者に「規範を分かっていない会社」と読まれ、場合によっては問題にもなります。情報提供に関わる規範と法令の扱いは、専門家にご確認ください。

五つ目は、業界で人員の見直しが続き、経験者が市場に出ている一方で、領域と製品が合う人は限られることです。経験者は市場にいるのに、自社の領域と製品と施設に合う人、自社のエリアに住める人、自社のMRに対する方針を受け入れる人は限られます。「経験者はいるのに来ない」の原因は、多くの場合、求人票が領域と製品と方針を示していないことにあります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 領域・製品・担当施設の整理 | 残す | 自社がどの領域のどの製品を、どの施設で担当してもらうか。社内にしか分からない |
| 担当エリアと転勤の方針の決定 | 残す | どのエリアで、転勤があるか、頻度と範囲。営業本部が決める |
| 評価の仕方の決定 | 残す | 売上か、情報提供の質か、面談の内容か、どう組み合わせるか。営業本部と経営者が決める |
| 会社のMRに対する方針の決定と開示 | 残す | 人員をどうするか、デジタルとの分担、コントラクトなら期間と転籍の扱い。経営者が決める |
| 要件の決定 | 残す | 領域・製品・施設から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（領域・製品・施設と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。情報提供の規範に沿った表現で |
| 媒体の選定と運用 | 任せられる | MRに届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 領域・製品・施設・エリアに合わせた検索と、担当してきた領域に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、流れの案内 |
| 営業所長・エリアマネージャーの面接の日程の確保 | 任せられる | 訪問と同行の合間に面接の枠を押さえる。社内で回りにくい工程 |
| 書類の一次絞り | 条件付き | 領域・製品・施設・エリア・認定の分類は任せられる。情報提供の質の評価は残す |
| 情報提供の質と医師との関係の評価 | 残す | 営業所長やエリアマネージャーが面接で聞く |
| 評価の仕方と方針と実態の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断 |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。担当施設の引き継ぎの区切りに合わせた入社日の調整 |

線の要点は、「領域・製品・施設と、エリアと転勤と評価と方針が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の経験に合うか」「この会社でMRを続けられるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「MRを募集しているが、応募が来ない。経験者は市場にいるはずなのに」というご相談です。求人票を見ると、「MR募集。医薬情報担当者として医療機関への情報提供活動。MR認定歓迎。経験者優遇」と書かれていて、領域も製品も施設もエリアも転勤も評価も、会社のMRに対する方針も無い。経験者はこれを読んで、「どの領域のどの製品か分からない」「どこに住むのか分からない」「この会社はMRを続ける気があるのか分からない」と判断し、応募しません。

見ていて差がつくのは、「領域と製品と、会社のMRに対する方針を一文で言えるか」です。「当社は〇〇領域の新薬を、〇〇エリアの市中病院と開業医で担当するMRを探している。転勤は〇〇圏内で、頻度は数年に一度。評価は面談の内容と情報提供の質を主に、売上は補助的に見る。MRの人員はこの領域では増やす方針で、デジタルの情報提供は補完として使う」。一文で領域・製品・施設・エリア・転勤・評価・方針が分かれば、別の領域の人は自分向けでないと分かり、同じ領域で情報提供の質を評価されたい人は自分向けだと分かります。エラベルでは、MRの案件をお受けする前に、依頼側に「領域・製品・施設」と「エリアと転勤と評価と方針」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：領域・製品・担当施設。** どの領域の、どの製品（新薬か長期収載品か後発品か）を、どの施設（開業医か市中病院か大学病院か）で担当してもらうか。採る人に任せる施設の数と規模。

**二つ目：担当エリアと転勤の方針。** どのエリアか、住む場所の想定、転勤の有無と頻度と範囲、直行直帰の可否、車の扱い。家族の事情への配慮の方針。

**三つ目：評価の仕方。** 売上の数字か、面談の件数と内容か、情報提供の質か、どう組み合わせるか。情報提供の規範に沿った評価になっているか。評価の仕方は、候補者が最初に確かめ、入社後の定着を決める項目です。

**四つ目：会社のMRに対する方針。** この領域でMRの人員を増やすのか、維持か、減らすのか。デジタルの情報提供とどう分担するか。コントラクトMRなら、プロジェクトの期間、契約終了後の扱い、製薬企業への転籍の可能性。開示できる範囲を決めます。

**五つ目：情報提供の規範と法令の扱い。** 求人票とスカウトで使える表現、使えない表現。「処方を増やす」「売上を上げる」を前面に出さない。面接で候補者に何を聞き、何を聞かないか。専門家に確認します。

五つのうち、一つ目と二つ目と四つ目が代行に出す前提です。三つ目と五つ目は、代行と一緒に整理できますが、規範に関わる部分は専門家の確認が要ります。

## 営業所長の関与のさせ方

MRの採用では、営業所長やエリアマネージャーの関与が要ります。面接で情報提供の質と医師との関係の作り方を聞く、評価の仕方と方針と実態を正直に話す、同行の機会を作る。しかし営業所長は訪問と同行を抱えていて、「採用は本社の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると営業所長がどう楽になるか」を具体的に示すことです。「この人が入れば、所長が抱えている〇〇病院の担当を渡せる」。そして、負担を最小にする形で頼みます。面接の枠は代行が訪問の合間に押さえる、経歴は代行が整理して渡す、評価と方針の説明の要点は代行が用意する。営業所長がやるのは、情報提供の質と医師との関係を聞くことと、実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で営業所長が「この会社のMRの実態」を話すことの価値を、営業所長自身に理解してもらうことです。候補者は、本社の人事の話より、営業所長の話を信じます。営業所長が「うちの評価は面談の内容が主で、売上だけで詰められることは無い。ただ、担当施設は多い」と話すと、候補者は「正直な会社」と判断します。

## 代行を選ぶときの確認項目

MRの採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に製薬業界かMRの経験があるか。** MRそのものでなくても、製薬企業の管理部門や、MRの採用を回した経験。領域と製品と施設の違い、情報提供の規範を知っているか
- **領域・製品・方針を求人票にどう書くか、案を出せるか。** 「MR業務全般」で済まさず、領域と製品と施設とエリアと転勤と評価と方針を、規範に沿った表現で書けるか
- **MRに届く媒体と経路の経験。** 製薬業界に強い媒体、スカウト、業界内のつながり、コントラクトMRから直接雇用への経路。経路ごとの経験
- **情報提供の規範への理解。** 求人票とスカウトと面接で、使ってよい表現と使えない表現を知っているか。専門家に確認する体制があるか
- **営業所長の日程を押さえる段取り。** 訪問と同行の合間に面接の枠を確保する方法

五つのうち、一つ目と四つ目が大きい。製薬業界を知らない担当者は、「売上を上げる営業」として求人票を作り、候補者に「規範を分かっていない会社」と読まれ、場合によっては問題にもなります。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、MRの採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「会社のMRに対する方針を開示しないと届かない」と言われることです。業界で人員の見直しが続く中、候補者は「この会社は何年後もMRを置いているか」を最初に確かめます。方針を開示しない求人は、「開示できない方針がある」と読まれます。開示できる範囲を経営者が決めます。

二つ目は、応募者の領域と製品と施設と経路が分かれることです。スペシャリティの新薬を大学病院で担当してきた人、プライマリーの長期収載品を開業医で担当してきた人、後発品メーカーの人、コントラクトMRとして複数の製薬企業を経験した人、人員の見直しで市場に出た人。それぞれ持っているものと動く理由が違い、自社の領域と製品と合うかも違います。代行の担当者に分類をしてもらい、面接で確かめることを変えます。

三つ目は、担当エリアと転勤で候補者が判断を変えることです。「転勤あり」とだけ書いて、面接で「全国転勤で数年ごと」と分かれば辞退されます。逆に、エリアを絞って書けば、そのエリアに住みたい人（出身者、家族の事情）に届きます。エリアと転勤を実態の形で書き、面接で営業所長が同じことを話すことで、候補者の判断が変わります。

### エラベルの見解

担当する側から見ると、MRの採用で最も効くのは、「領域と製品」と「会社のMRに対する方針」を求人票に書くことです。MRの候補者は、領域と製品で自分の経験が活きるかを判断し、方針で「この会社でMRを続けられるか」を判断します。「MR業務全般」と「MR認定歓迎」だけの求人票は、どの領域の経験者にも「自分向けか分からない」「この会社の方針が分からない」で閉じられます。

エラベルでは、MRの案件で担当者を紹介するとき、最初の一週間で営業本部から「領域・製品・施設」「エリアと転勤」「評価の仕方」「MRに対する方針」を聞き取り、情報提供の規範に沿った表現で一文にするところから始めてもらっています。情報提供の質と医師との関係の評価は営業所長が面接で行い、規範と法令に関わる表現と扱いは、専門家にご確認いただくようお伝えしています。

## よくある質問

### 会社のMRに対する方針を、求人票に書いてよいのですか

開示できる範囲を経営者が決めた上で、書きます。「この領域ではMRの人員を維持する」「デジタルの情報提供は補完として使い、MRの面談を中心に置く」のように、方針の方向を書けば、候補者は判断できます。書かない求人は、業界で人員の見直しが続く中で、「開示できない方針がある」と読まれ、経験者ほど応募しません。将来の人員の数字や、未定のことを断定して書く必要はなく、「いま決まっている方向」を書きます。

### 「処方を増やす」「売上目標」を求人票に書いてはいけないのですか

医薬品の情報提供には業界の自主規範と法令があり、求人票やスカウトで「処方を増やす」「売上を上げる」を前面に出す書き方は、候補者に「規範を分かっていない会社」と読まれ、場合によっては問題にもなります。評価に売上の要素があるなら、「評価は面談の内容と情報提供の質を主に、売上は補助的に見る」のように、規範に沿った形で書きます。使ってよい表現と使えない表現は、専門家にご確認ください。

### コントラクトMRの募集では、何を書けばよいですか

プロジェクトの領域と製品と製薬企業の種類（開示できる範囲で）、期間、契約終了後の扱い（次のプロジェクトへの移行、製薬企業への転籍の可能性と実績）、担当エリアと転勤、評価の仕方を書きます。コントラクトMRの候補者が最初に確かめるのは、「このプロジェクトが終わった後どうなるか」です。転籍の実績があるなら書き、無いなら無いと書き、次のプロジェクトへの移行の実態を書きます。曖昧にすると、経験者ほど応募しません。
