社員の年齢を見ると、一つの層に偏っている。数年後に、その層が一斉に退職の時期を迎える。若手がいないので、技術も顧客との関係も継承されない。中堅がいないので、次の管理職が育たない。「若手を採ろう」と求人を出したが、来ない。来ても、教える人がいない。結論を先に書くと、**年齢構成の偏りは、「若手を採る」「シニアを採る」で直すものではありません。年齢を理由にした採用は法令上の扱いがあり、年齢で採ろうとしても来ません。偏りで「何が困るか」を特定し、困ることを「役割の設計」「育成」「採用」の三つで直します。採用は三つの一つで、年齢ではなく役割で採ります。直すには数年かかるので、今日から始めます**。若手の採用は[未経験採用に踏み切るか迷っている](/media/rpo-mikeiken-saiyo/)と[第二新卒をどう位置づけるか](/media/rpo-second-shinsotsu/)に、シニアの採用は[シニア人材の採用をどう設計するか](/media/rpo-senior-saiyo/)にまとめています。年齢に関する採用の扱いは、専門家と公的機関の案内で確認します。

## 偏りで起きていること

年齢構成が偏っている会社では、次のことが起きています。

| 偏りの形 | 起きていること |
|---|---|
| 一つの層に集中 | 数年後に一斉に退職の時期。技術、顧客、判断の基準が、一斉に失われる |
| 若手がいない | 技術と関係の継承先が無い。新しいやり方が入らない。若手が入っても、同年代がいなくて孤立する |
| 中堅がいない | 次の管理職が育たない。若手とベテランの間をつなぐ人がいない |
| ベテランがいない | 経験に基づく判断、顧客との長い関係、失敗の記憶が無い |
| 採用が止まっていた時期がある | その時期に入るはずだった層が、ごっそり抜けている |
| 「若手を採ろう」で求人を出すが来ない | 若手がいない会社に、若手は来にくい。教える人も、同年代もいない |
| 偏りを「仕方ない」と思っている | 「業界的に」「うちの規模では」で、直す設計をしていない |

偏りの問題は、「いま困っている」より「数年後に困る」ことが多く、後回しにされます。数年かけて直すものなので、今日始めなければ、数年後にも直っていません。

## 何が困るかの特定

「年齢が偏っている」だけでは、直す先が決まりません。「何が困るか」を特定します。

| 困ること | 中身 | 直す先 |
|---|---|---|
| 技術や知識の継承 | 特定の層にしか無い技術や知識が、退職で失われる | 書面化、育成、継承の相手の採用 |
| 顧客との関係の継承 | 長い付き合いの顧客との関係が、担当者の退職で切れる | 複数の担当、引き継ぎの期間、関係の記録 |
| 判断の基準の継承 | 「こういうときはこうする」が、ベテランの頭の中にしか無い | 判断の基準の書面化、若手への引き継ぎ |
| 次の管理職 | 管理職の後継がいない | 中堅の育成、外からの管理職の採用（[幹部・管理職が採用できない](/media/rpo-kanbu-saiyo/)） |
| 一斉の退職による人員の減少 | 数年後に、一度に多くの人が抜ける | 段階的な採用、退職の時期の分散（再雇用や働き方の変更など、制度は専門家に確認） |
| 新しいやり方が入らない | 同じ層だけで、変化が起きない | 役割の設計（新しい役割）、外からの採用、育成の機会 |
| 若手が孤立する | 若手が入っても、同年代がいなくて辞める | 複数の若手を同時に採る、受け入れの型、社外の同年代との接点 |

特定すると、「若手を採る」だけでは解決しないことが見えます。継承は書面化と育成で、次の管理職は中堅の育成で、一斉の退職は段階的な採用で、と直す先が分かれます。

## 年齢で採らない理由

「若手を採ろう」「シニアを採ろう」と、年齢で採ろうとしない理由です。

**法令上の扱い。** 年齢を理由にした募集や採用の扱いは、法令上の定めがあります。原則と例外は、専門家と公的機関の案内で確認します。「若手限定」「〇歳以下」のような形は、扱いを確認せずに使えません。

**年齢で採ろうとしても、来ない。** 若手がいない会社に、若手は来にくいです。「若手を歓迎」と書いても、教える人がいない、同年代がいない、働き方が合わない、が見えれば、来ません。

**役割で採れば、年齢は結果として広がる。** 「これから専門を積む役割」「経験を活かして仕組みを作る役割」のように役割で採れば、応募する層は役割に合わせて広がります。

**年齢の偏りの原因は、役割と育成の偏り。** 若手がいないのは、若手が担う役割が無いから。中堅がいないのは、中堅に育てる型が無いから。年齢ではなく、役割と育成を直します。

**「若い人」より「これから育つ人」。** 年齢ではなく、「育てる型に乗って、これから専門を積む人」を採ります。年齢は問いません。

年齢で採らない要点は、「役割と育成で採る」ことです。年齢の偏りは、役割と育成が偏っていた結果です。

## 役割と育成と採用の三つの直し方

偏りで困ることを、三つで直します。

| 直し方 | 中身 |
|---|---|
| 役割の設計 | 「これから専門を積む役割」「継承を受ける役割」「仕組みを作る役割」「管理職の候補の役割」を、社内に作る。役割が無ければ、その層は入っても居場所が無い。役割の記述は[ジョブディスクリプションがない](/media/rpo-jd-nai/) |
| 育成 | 継承の型（書面化、引き継ぎの期間、教える人）、若手を育てる型（[未経験採用に踏み切るか迷っている](/media/rpo-mikeiken-saiyo/)）、中堅を管理職に育てる型。育成が無ければ、採っても偏りは直らない |
| 採用 | 役割で採る。「これから専門を積む役割」なら未経験や第二新卒、「仕組みを作る役割」なら経験の深い人。年齢ではなく役割で。複数の層を、段階的に |

三つの要点は、「採用だけで直そうとしない」ことです。役割が無く、育成が無いまま採っても、採った人は居場所が無く、育たず、辞めます。

三つを、同時に、数年かけて進めます。「今年は役割の設計と育成の型、来年から採用を段階的に」のように。

### エラベルの見解

相談で最も多い失敗は、「年齢が偏っているので、若手を五人まとめて採った。教える人も、若手が担う役割も無く、五人のうち三人が一年で辞め、残った二人も孤立していた」というものです。採用だけで直そうとしました。「これから専門を積む役割」を切り出し、育てる型と教える人を決め、若手を二人ずつ段階的に採り、社外の同年代との接点を作る形に変えたら、定着し始めました。年齢の偏りは、役割と育成の偏りで、採用はその一部でした。

見ていて差がつくのは、担当者が「年齢で採る」提案をしないかどうかです。「若手向けの求人を出しましょう」と言う担当者と、「年齢では採れませんし、法令上の扱いもあります。偏りで何が困るかを特定して、役割と育成を先に作り、役割で段階的に採りましょう」と言う担当者がいます。後者は、数年後に直っている設計をします。

発注側にできるのは、「若手を採りたい」を「偏りで困ることを、役割と育成と採用で直したい」に言い換えて依頼することです。

## 年齢の偏りを直す採用の設計

三つのうち、採用の部分の設計です。

**役割で求人を出す。** 「これから専門を積む役割」「継承を受ける役割」「仕組みを作る役割」。年齢は書きません。役割の中身と、育てる型の有無と、一緒に働く人を書きます。

**複数の層を、段階的に。** 一度に一つの層を多く採ると、また偏ります。「今年は専門を積む役割を二人、来年も二人、仕組みを作る役割を一人」のように、段階的に。

**「育てる型がある」を、求人票に書く。** 若手がいない会社に若手が来ない理由は、「教える人がいない」が見えるからです。「最初の三か月の型がある」「教える人がいる」を、事実として書きます。事実でなければ、先に作ります。

**同時に複数の若手を採る。** 一人だけ採ると孤立します。二人以上を同時に採り、同年代がいる状態を作ります。

**経路を、層に合わせる。** 専門を積む役割は、未経験や第二新卒の経路（[第二新卒をどう位置づけるか](/media/rpo-second-shinsotsu/)）。仕組みを作る役割は、経験の深い人の経路（[シニア人材の採用をどう設計するか](/media/rpo-senior-saiyo/)）。

**受け入れの型を、層ごとに。** 専門を積む役割には育てる型、仕組みを作る役割には役割の書面と権限。

**継承の相手として採る場合、継承する人との接点を最初から。** 「〇〇さんの技術を引き継ぐ役割」なら、〇〇さんと一緒に働く期間を、入社の最初から。

採用の設計の要点は、「役割で、段階的に、複数の層を、受け入れの型と一緒に」です。

## 時間の見込み

年齢構成の偏りは、数年かけて直します。時間の見込みを持ちます。

**一年目：役割の設計と育成の型。** 「これから専門を積む役割」「継承を受ける役割」「管理職の候補の役割」を切り出し、育てる型と継承の型を作る。採用は、仕組みを作る役割や継承の相手から、少数で。

**二〜三年目：段階的な採用と育成。** 専門を積む役割を毎年数人、育てる型に乗せる。中堅を管理職に育てる型を回す。継承を進める。

**三〜五年目：偏りの緩和。** 複数の層が揃い始める。一斉の退職の時期に、継承と次の管理職が間に合う状態。

**年に一度、年齢構成と役割の対応を見る。** 「どの層が、どの役割を担っているか」「五年後にどうなるか」。要員計画（[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)）に、年齢構成の見通しを入れます。

**一斉の退職の時期を、先に見る。** 「〇年に、この層の退職の時期」。そこから逆算して、継承と採用の時期を決めます。退職の時期の分散（再雇用、働き方の変更など）の制度は、専門家に確認します。

時間の見込みの要点は、「今日始めなければ、数年後にも直っていない」ことです。「数年後に困る」問題は、いま始めるしか、直す方法がありません。

## 外注する場合の範囲

年齢構成の偏りを、採用代行に出す場合の範囲です。

**出せる工程。** 偏りで何が困るかの特定の進行（年齢構成と役割の対応の整理）、役割の切り出しの支援（専門を積む役割、継承を受ける役割、仕組みを作る役割）、育成と継承の型の案、採用の設計（役割で、段階的に、複数の層）、層ごとの求人票と経路と受け入れの型、年齢に関する法令上の扱いの確認の専門家への橋渡し、数年の計画の一枚、年に一度の年齢構成と役割の対応の確認、要員計画への年齢構成の見通しの反映。

**社内に残す判断。** 役割の決定、育成と継承の型の決定と教える人の指名、採用の段階と数の決定、退職の時期の分散に関する制度の判断（専門家との連携）、判定、内定、数年の計画の承認。

**外注の効きどころ。** 年齢構成の偏りは、「数年後の問題」として後回しにされ、「若手を採る」で失敗しやすい問題です。担当者が「何が困るか」を特定し、役割と育成と採用の三つに分け、数年の計画にすれば、今日から動き始められます。担当者は複数の会社の年齢構成の偏りを見ているので、「この偏りなら、この役割を先に」の型を持ち込めます。ただし、年齢に関する法令上の扱いは、担当者も専門家に確認します。

**外注しても動かない場合。** 経営者が「若手を採れば解決」を譲らない、役割を切り出さない、教える人を置かない、数年の計画を認めない。社内の判断で、代行を替えても直りません。

年齢構成の偏りは、役割と育成と採用で、数年かけて直します。外注は、三つに分けて計画にする手段です。

### エラベルの見解

担当する側から見ると、年齢構成の相談で最も多いのは、「若手が担う役割が社内に無い」ことです。ベテランが全部の役割を担っていて、若手が入っても「見て覚えて」しか無い。役割が無いので、若手は何をすればよいか分からず、辞める。

「これから専門を積む役割」を、ベテランの仕事から切り出す。「最初の三か月はこの範囲、一年でこの範囲」。役割があれば、若手は居場所を持ち、ベテランは継承の相手を持ちます。役割を切り出すことが、年齢構成を直す最初の一歩です。

発注側にできるのは、「若手を採る」の前に、「若手が担う役割を、ベテランの仕事から切り出す」ことです。

## よくある質問

### 若手を採りたいのですが、「若手限定」で募集できますか

年齢を理由にした募集や採用の扱いは、法令上の定めがあり、原則と例外があります。専門家と公的機関の案内で確認します。年齢で採ろうとしても、若手がいない会社には若手は来にくいです。「これから専門を積む役割」を切り出し、育てる型と教える人を作り、「型がある」を事実として求人票に書けば、年齢を書かなくても、その役割に合う層が応募します。年齢ではなく役割で採り、結果として年齢が広がる形にします。

### 数年後に一斉に退職する層がいます。間に合いますか

退職の時期から逆算して、今日始めます。継承（技術、顧客、判断の基準）は、書面化と引き継ぎの期間と継承の相手の採用で、数年かかります。次の管理職は、中堅の育成か外からの採用で。一斉の退職の時期の分散（再雇用、働き方の変更など）の制度は、専門家に確認します。「間に合うか」は、始める時期で決まります。今日始めなければ、数年後にも直っていません。

### 若手を採っても、すぐ辞めてしまいます

若手が担う役割が無い、教える人がいない、同年代がいなくて孤立する、のどれかであることが多いです。「これから専門を積む役割」を切り出し、育てる型（最初の三か月の予定、教える人、到達点）を作り、二人以上を同時に採って同年代がいる状態にし、社外の同年代との接点も用意します。辞めた若手に理由を聞き、記録すれば、どれが原因かが分かります。採用だけを繰り返しても、役割と育成が無ければ、同じ理由で辞めます。
