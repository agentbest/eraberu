小売業界の会社が採用代行を検討するとき、動機は「店舗のパートとアルバイトが常に足りず、店長が採用に追われている」「出店が続き、店長候補が採れない」であることが多い。ただ、小売の採用は、他の業界と違う難しさがあります。店舗の販売スタッフと本部の職種で経路も要件も違い、店舗が多く店長の基準と枠がばらばらで、パートとアルバイトは速さと当日の返事で決まり、繁忙期と出店で人数と時期が動き、シフトと働き方の実態が定着を左右する。結論を先に書くと、**小売業界の採用代行は、店舗の一次対応・日程・記録・本部の職種の母集団形成は外に出せる一方、店舗の見極め・シフトと条件の判断・受け入れ・本部の職種の要件と見極めは社内に残さないと、採れても店舗で続きません。**代行に出す前に、難しさを自社の状況で分解し、店舗と本部で「任せる・残す」を決めることが、代行が機能する条件です。職種ごとの切り分けは[販売スタッフ採用を代行に出す判断基準](/media/rpo-hanbai-rpo/)に、飲食との共通点は[飲食店スタッフ採用を代行に出す判断基準](/media/rpo-inshoku-rpo/)に書いています。ここでは、小売業界で共通する切り分けに絞ります。

## 小売業界の採用が難しい五つの理由

| 難しさ | 中身 | 代行への影響 |
|---|---|---|
| 店舗と本部で経路と要件が違う | 店舗のパートとアルバイトは地域の経路と速さ、正社員の販売は掲載型と登用、本部はスカウトと紹介 | 店舗の型と本部の型で、代行の型が要る |
| 店舗が多く店長がばらばら | 店長が面接し、基準も記録も枠も店舗ごと。店長は接客で面接の時間が取れない | 観点と記録の形を一つにし、枠の預かり方を変える必要 |
| 速さと当日の返事で決まる | パートとアルバイトの応募者は複数に同時に応募し、先に返事が来た店に行く | 一次対応を店長に残すと、返事が遅れて流れる |
| 繁忙期と出店で動く | 繁忙期の前と出店の前に、店舗ごとに人数と時期が動く | 計画と採用の一枚が店舗ごとに要る |
| シフトと実態が定着を左右 | シフトの組み方、土日の扱い、繁忙期の実態が求人票に無いと、入店後に離れる | 実態を先に出すかで、応募と定着が変わる |

五つのうち、代行で解決できるのは速さと母集団形成で、見極め・シフト・受け入れ・本部の要件は社内の関わりが要ります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 店舗ごとの採る数と時期（繁忙期・出店） | 残す | 本部と店長が決める |
| 店舗の求人票の型（シフト・実態・一緒に働く人） | 一緒に | 本部が型を作り、店舗の実態を店長が埋める。代行が整える |
| 店舗の母集団形成（地域の経路、店頭、知人） | 一部任せられる | 地域の媒体の運用は外で。店頭と知人は店舗 |
| 店舗の一次対応（返信・日程） | 任せられる | 当日の返事が要る工程。店長に残すと流れる |
| 店舗の見極め（面接） | 残す | 店長。ただし観点と記録の形は一つに |
| シフトと条件の判断 | 残す | 店長と本部 |
| 店舗の受け入れ（最初の一週間、教える人） | 残す | 店長。離職を減らす要 |
| 本部の職種の要件の決定 | 残す | 各部門の責任者 |
| 本部の職種の母集団形成（スカウト・紹介） | 任せられる | 型があれば外で回せる |
| 本部の職種の見極め | 残す | 部門の責任者 |
| 記録と報告 | 任せられる | 店舗をまたいで一つの一覧 |

「店舗の一次対応」を外に出すことが、小売で最も早く効く工程です。店長の時間が接客と受け入れに戻ります。

### エラベルの見解

小売業界で多くの会社が見落とすのは、「パートとアルバイトの応募者は、先に返事が来た店に行く」という構造です。応募が来ても、店長が接客で返事を翌日に回し、その間に応募者は別の店で決まる。媒体に費用を使っても、返事の遅さで消えています。一次対応（応募への返事と面接の日程）を外に出し、当日中に返し、店長の枠（開店前か閉店後か、接客の少ない時間帯）を先に預かって即日で確定する。それだけで、同じ応募の数から入店する人数が変わります。エラベルで担当者を選ぶ企業には、「店舗への応募に、当日中に返事が返っていますか」を、私たちから先に聞いています。返っていなければ、媒体を増やす前に一次対応の分担です。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に書いています。

## 代行に出す前に社内で確認すること

| 確認 | 中身 |
|---|---|
| 店舗と本部の型 | 店舗のパート・アルバイト・正社員、本部のどの職種を採るか |
| 店舗ごとの計画 | 繁忙期と出店の時期と、店舗ごとの採る数が一枚にあるか |
| 店舗の求人票の型 | シフト・土日の扱い・繁忙期・一緒に働く人・最初の一週間を、店舗ごとに埋められる型があるか |
| 店長の観点と記録の形 | 店舗をまたいで一つか。店長の枠を週に決まった数、接客の少ない時間帯で出せるか |
| 当日の返事の体制 | 応募に当日中に返す窓口があるか。店長に残すか外に出すか |
| 受け入れ | 最初の一週間の教える人と到達点が、店舗ごとにあるか |
| 記録の形 | 店舗をまたいで一つの一覧があるか |

「当日の返事の体制」が、小売で最も詰まります。店長に残したまま代行を使っても、返事の遅さで流れます。

## 店舗と本部で代行の型が違う

| 型 | 代行に向く工程 | 社内に残す度合い |
|---|---|---|
| 店舗のパート・アルバイト | 地域の媒体の運用、一次対応（当日の返事、日程）、記録 | 店長の見極め、シフト、受け入れ。[販売スタッフの採用要件の作り方](/media/rpo-hanbai-youken/) |
| 店舗の正社員・店長候補 | 掲載型とスカウトの母集団形成、一次対応 | 登用の判断、見極め |
| 本部（バイヤー・企画・店舗開発） | スカウトと紹介の母集団形成、一次対応 | 部門の責任者の要件と見極め |
| 本部（管理・事務） | 掲載型、一次対応 | 部門の責任者の見極め |

「小売の採用に強い代行」でも、店舗の速さの型と本部のスカウトの型の両方を持っているかは別です。

## 代行を選ぶときの確認項目

| 確認 | 聞き方 |
|---|---|
| 店舗の一次対応の速さ | 「店舗への応募に、何時間以内に返しますか。閉店後の応募はどうしますか」 |
| 店舗をまたぐ運用 | 「複数の店舗の募集を、一つの一覧と一つの観点でどう回しますか」 |
| 店長の枠の預かり方 | 「接客で日中に出られない店長の面接を、どう組みますか」 |
| 本部の職種の型 | 「バイヤーと店舗開発で、経路と文面をどう変えますか」 |
| 担当者の経歴 | 「担当する方は、小売のどの型（店舗・本部）の採用を、どの工程で担った経験がありますか」 |
| 記録の置き場所 | 「店舗をまたぐ記録はどこに置きますか。契約が終わったら」 |
| 費用の構造 | 「月額に含まれる工程と店舗の数は」 |

費用は、含まれる工程と店舗の数で変わり、金額の相場を先に聞くより「同じ工程・同じ店舗数で比べる軸」をそろえます。費用の構造は[採用代行の費用の内訳](/media/rpo-hiyou-uchiwake/)に、選び方の軸は[採用代行会社の選び方](/media/rpo-erabikata/)に書いています。

## 代行に出したあとに起きること

| 起きること | 原因 | 対応 |
|---|---|---|
| 応募は増えたが、入店する人が増えない | 返事が店長に残っていて遅い | 一次対応を外に出し、当日中に |
| 店舗によって通過の基準が違う | 観点と記録の形が店舗ごと | 一枚を全店長に。決めるのは店長 |
| 入店後にすぐ辞める | シフトと実態が求人票に無い。最初の一週間の教える人がいない | 求人票の型に実態を。受け入れの一枚 |
| 繁忙期に間に合わない | 店舗ごとの計画と採用の一枚が無い | 繁忙期の数か月前に一枚で準備 |
| 本部の職種が採れない | 店舗の型（掲載型と速さ）で本部を探している | 本部はスカウトと紹介の型で |
| 契約が終わると記録が消える | 記録が代行の環境 | 社内の環境に置く形を契約で |

出したあとの問題は、「一次対応の分担」「店舗の基準」「実態と受け入れ」「計画」「本部の型」に戻ります。

### エラベルの見解

小売業界で「店舗の採用は店長に任せている」という会社は多く、店長は接客と発注とシフトと採用を一人で抱えています。その状態で店長に「もっと採って」と言っても、返事が遅れ、面接が組めず、受け入れの時間も無い。代行に出す工程を「一次対応と日程と記録」に絞り、店長は「面接の三十分と、最初の一週間の受け入れ」だけにする。店長の負担は減り、入店する人は増えます。エラベルは担当者を工程ごとに選べる形にしているので、「店舗の一次対応と日程と店舗をまたぐ記録」を担当者が担い、本部は「観点の一枚・求人票の型・計画・条件」に絞る、という組み方ができます。店舗の受け入れの型は[入社後のオンボーディングの進め方](/media/rpo-task-onboarding-susumekata/)に書いています。

## まとめ

- 小売業界の難しさは、**店舗と本部の違い・店長のばらつき・速さと当日の返事・繁忙期と出店・シフトと実態**の五つ
- **店舗の一次対応・日程・記録・本部の母集団形成は任せられ、店舗の見極め・シフトと条件・受け入れ・本部の要件と見極めは残す**
- 最も早く効くのは**店舗の一次対応を外に出す**こと。応募者は先に返事が来た店に行く
- 店長は**「面接の三十分と最初の一週間の受け入れ」**に絞る。観点と記録の形は一つ、決めるのは店長
- 店舗の求人票は**型に実態（シフト・土日・繁忙期・一緒に働く人）**を店舗ごとに埋める
- 繁忙期と出店は**店舗ごとの計画と採用の一枚**で数か月前から
- 本部の職種は**店舗の型と分けて、スカウトと紹介の型**で

## よくある質問

### 店舗の数が多く、全店舗の一次対応を外に出すと費用が大きくなりませんか

全店舗を同時に出さず、応募が多く返事が遅れている店舗から順に出します。一店舗で「当日の返事で入店が増える」ことが記録で見えれば、次の店舗に広げる判断ができます。費用は含まれる工程と店舗の数で変わり、「店舗ごとに一次対応だけ」の形なら、全部を任せるより小さい。費用の判断は会社のもので、代行は「同じ工程・同じ店舗数で比べる軸」をそろえるまでです。

### パートとアルバイトの離職が多く、常に募集しています

離職の理由を集めると、「シフトが聞いていたのと違う」「最初の一週間に誰も教えてくれなかった」「土日の扱い」が多い。求人票の型に実態を書き、最初の一週間の教える人を店舗ごとに決めるだけで、離職は減ります。「常に募集」は採用の入口の問題ではなく、実態と受け入れの問題で、直せます。離職の分け方は[早期離職が続くのは採用のどの段階の問題か](/media/rpo-souki-rishoku/)に書いています。

### 店長候補を外から採りたいのですが、来ません

店長候補は、店舗のパートとアルバイトと同じ型（地域の掲載型と速さ）では届きません。「〇〇の型の店舗で、〇〇の規模のチームと売上を、〇〇まで担った経験」に要件を絞り、掲載型とスカウトの型で、「この会社で店長として担うこと」「登用の道筋」「本部との関係」を実態で書きます。社内の登用の道筋が無いと、外から来た店長候補も定着しません。登用と外部の採用を並べて、本部が判断します。
