インサイドセールスにスカウトを送っても返信が来ない会社の文面には、共通点があります。「インサイドセールスを募集しています」「架電でアポイントを獲得していただきます」「成長企業で営業組織を一緒に」と書かれていて、分担も、指標も、見込み客の状態も、フィールドセールスとの関係も無い。インサイドセールスの経験者はこれを読んで、「テレアポの募集をインサイドセールスと呼んでいる会社」と判断し、閉じます。結論を先に書くと、**インサイドセールスへのスカウトは、転向元ごとに対象を分け、一行目で候補者が聞き出してきた課題や作った商談の一点に触れ、分担・指標・見込み客の質と量・架電の型・フィールドセールスとの関係を先に書き、会社の紹介は後ろに回す**型にすると、返信が変わります。母集団形成の全体は[インサイドセールスの母集団形成](/media/rpo-inside-sales-boshuudan/)に、営業全般の文面は[営業向けスカウト文面の型](/media/rpo-sales-scout/)にまとめています。

## インサイドセールスがスカウトを読まない理由

営業全般と共通する理由（定型文、条件を隠す言葉）に加えて、インサイドセールスに特有の理由があります。

一つ目は、テレアポと区別が付かない文面が多いことです。「架電」「アポイント」の言葉が並ぶと、経験者は「テレアポの募集」と読みます。課題を聞き出すこと、商談の質、フィールドセールスとの分担が書かれていないと、区別が付きません。

二つ目は、見込み客の状態を最初に確かめることです。インサイドセールスの経験者は、「見込み客が来ない会社」「質の低い見込みばかりの会社」を避けます。マーケティングからどのくらいの見込みが、どんな質で来るかが書かれていないと、「見込みを自分で探す電話営業かもしれない」と読まれます。

三つ目は、指標を見ることです。数だけを追う指標の会社では、質の高い商談を作る動きが評価されず、架電の量で消耗します。指標に質が入っているかが書かれていないと、「数だけの会社」と読まれます。

四つ目は、フィールドセールスとの関係と、その先の道を見ることです。渡した商談の結果が戻るか、一緒に振り返るか、フィールドセールスに進む道があるか。書かれていないと、「商談を渡すだけで評価されない役」と読まれます。

この四つから、文面の型が決まります。テレアポと区別する、見込み客の状態を書く、指標に質を入れる、フィールドセールスとの関係と道を書く。

## 先に決めるのは対象：転向元ごとに分ける

文面の前に、誰に送るかを決めます。インサイドセールスでは、経験者だけでなく転向元ごとに対象を分け、それぞれに一行目と訴求を変えます。

| 転向元 | 検索の条件 | 一行目で触れる一点 | 訴求 |
|---|---|---|---|
| インサイドセールスの経験者 | 「課題の聞き取り」「商談化」「フィールドセールスへの引き渡し」の経験 | 聞き出してきた課題の種類、作った商談の質 | 分担と指標が整っていること、または作るところから |
| カスタマーサポートからの転向 | 「顧客の課題の聞き取り」「解決の提案」の経験 | 聞き出してきた課題と、提案した解決 | 聞き出す力を売る側で活かせること。目標の考え方 |
| フィールドセールスからの転向 | 「初回接触から自分で」「商談の創出」の経験 | 自分で作った商談と、受注への流れ | 商談の質を作る役割。架電の量の目安を正直に |
| テレアポの中で課題の聞き取りをしてきた人 | 「ヒアリング」「課題の把握」の記述 | 聞き取りをして商談につなげた経験 | 数だけでなく質で評価されること |

対象の要点は、「転向元によって、一行目と訴求が変わる」ことです。カスタマーサポートからの転向層には「聞き出す力を売る側で」、フィールドセールスからの転向層には「商談の質を作る役割」と、持っているものに合わせて書きます。[スカウトの対象の絞り方](/media/scout-persona-sakusei/)も参考になります。

### エラベルの見解

相談で多いのは、「インサイドセールスの経験者に数十通送ったが、返信が来ない」というご相談です。文面を見ると、一行目が「インサイドセールスを募集しております」、業務内容が「架電とアポイント獲得」、見込み客の状態も指標も無い。経験者から見ると、テレアポの募集に読め、しかも見込み客が来るかどうかも分からない。読まれない理由がそろっています。

見ていて差がつくのは、「一行目で候補者が聞き出してきた課題に触れ、二行目で自社の分担と指標を言えるか」です。「〇〇の顧客の課題を電話で聞き出し、〇〇の商談につなげてこられたご経歴を拝見しました。当社では、マーケティングが集めた見込み客に接触し、課題を聞き出して、フィールドセールスに質の高い商談を渡す役割を、商談の質と受注への貢献で評価しています」。この二行で、経験者は「テレアポではない」「指標に質がある」と判断します。エラベルでは、インサイドセールスの担当者に、文面の中心を「分担と指標」にするよう最初にお願いしています。

## 文面の型：一行目は候補者の接触、二行目は自社の分担と指標

| 順 | 中身 | 書き方 |
|---|---|---|
| 一 候補者の経歴の一点 | 聞き出してきた課題、接触してきた相手、作った商談の質のどれか一つ | 「〇〇の顧客の課題を聞き出し、〇〇の商談につなげてこられたご経歴を拝見しました」 |
| 二 自社の分担と指標 | マーケティング・インサイドセールス・フィールドセールスの分担と、成果の指標 | 「当社では、マーケティングが集めた見込み客に接触し、課題を聞き出して商談を作る役割を、質と受注への貢献で評価しています」 |
| 三 見込み客の質と量 | どのくらいの見込みが、どんな質で来るか。少ないなら正直に | 「月に〇〇件ほどの問い合わせがあり、〇〇の状況の見込み客が中心です」または「見込みはまだ少なく、増やす仕組みを一緒に作るところから」 |
| 四 架電の型 | 一日の接触の数の目安、ツール、トークの型、記録 | 具体的に。数だけを追わないなら、その方針も |
| 五 目標と評価 | 固定と歩合の仕組み、目標の考え方、質の評価の方法 | 隠さず、具体的に |
| 六 フィールドセールスとの関係と道 | 商談の結果が戻るか、一緒に振り返るか、フィールドセールスに進む道 | 「渡した商談の結果は毎週共有し、一緒に振り返ります。〇〇の成果でフィールドセールスへの道があります」 |
| 七 チームの体制 | 何人で、責任者は誰か、一人目か | 一人目なら、分担を作るところから |
| 八 商材と顧客 | 何を、誰に。短く | 三行以内 |
| 九 会社の紹介 | 事業と規模を短く | 三行以内 |
| 十 次の一歩 | 営業の責任者が出る短い面談 | 「営業の責任者と一緒に、見込み客の実例をお見せしながら三十分ほど」 |

型の要点は、「二で分担と指標を、三で見込み客の状態を、会社の紹介より前に書く」ことです。インサイドセールスの候補者は、会社の事業より、分担・指標・見込み客の状態で判断します。

## 刺さる訴求と、外す訴求

| 刺さる訴求 | 外す訴求 |
|---|---|
| 分担の具体（マーケティング・インサイドセールス・フィールドセールスが何を） | 「インサイドセールス募集」だけ |
| 指標に質が入っていること（商談の質、受注への貢献） | 「アポイント〇件」の数だけ |
| 見込み客の質と量の正直な記述 | 見込みの状態を書かない |
| 課題を聞き出す接触であること | 「架電」「アポ獲得」だけ。テレアポに読める |
| 架電の型と、数だけを追わない方針 | 「一日〇〇件」の量だけ |
| フィールドセールスとの関係（結果が戻る、一緒に振り返る） | 「営業チームと連携」だけ |
| フィールドセールスへの道と、その条件 | 道を書かない |
| 一人目なら、分担を作る裁量 | 「裁量があります」だけ |
| 固定と歩合の仕組み、目標の考え方 | 「頑張り次第で高収入」 |
| 転向元に合わせた訴求（聞き出す力を売る側で、商談の質を作る役割） | 全転向元に同じ文面 |

訴求の要点は、「テレアポに読める言葉を使わない」ことです。「架電」「アポ獲得」「一日〇〇件」が並ぶと、経験者は読まず、テレアポの経験者が返信します。「課題を聞き出す」「商談の質」「受注への貢献」の言葉で、役割を区別します。

## 送った後の運用

返信が来たあとの運用で、インサイドセールスに特有の注意を整理します。

一つ目は、返信の速さです。営業系の候補者は複数社を同時に受け、対応の速い会社から決めます。返信にはその日か翌日、面談の日程はその返信の中で提案します。

二つ目は、面談に営業の責任者が出て、見込み客の実例を見せることです。インサイドセールスの候補者は、面談で「どんな見込み客が、どのくらい来るか」を確かめます。実例（匿名化した問い合わせの内容、月の件数）を見せると、候補者は判断できます。

三つ目は、面談で指標と架電の型を再確認することです。数だけを追う指標か、質を見る指標か。一日の接触の数の目安。書いてあっても、候補者は読み飛ばしていることがあります。

四つ目は、転向元ごとの確認です。カスタマーサポートからの転向層には「売る側の目標に向き合えるか」、フィールドセールスからの転向層には「架電の量に耐えられるか、フィールドに戻りたいだけでないか」を面談で確かめます。

五つ目は、記録です。[スカウトの重複防止](/media/scout-jyufuku-boushi/)も参考になります。

## 代行に出せる範囲

| 工程 | 代行に出せる | 社内で持つ |
|---|---|---|
| 対象の決定 | 転向元ごとの検索の条件の提案 | 分担と指標の確定 |
| 検索と一覧化 | 出せる。「課題を聞き出す接触」の経験で | — |
| 文面の型作り | 出せる。転向元ごとに | 分担・指標・見込み客の状態・架電の型・フィールドセールスとの関係の中身を社内が出す |
| 一行目の個別化 | 出せる。経歴の接触の一点を書く | — |
| 送信 | 出せる | 名義と時間帯 |
| 返信の一次対応 | 出せる。その日か翌日に | — |
| 面談の設定 | 出せる | 営業の責任者の面談の枠の確保。見込み客の実例の用意 |
| 面談 | — | 営業の責任者が出る |
| 記録と数の整理 | 出せる | — |

分け方の要点は、「分担・指標・見込み客の状態は、社内でしか出せない」ことです。代行に「インサイドセールス向けの文面を」と頼んでも、この三つが社内から出ていなければ、代行は「架電とアポ獲得」で埋めるしかなく、テレアポの募集になります。

### エラベルの見解

担当する側から見ると、インサイドセールスのスカウトで最も時間がかかるのは、依頼側から見込み客の状態を引き出すことです。依頼側は「マーケティングが集めている」と言いますが、月に何件、どんな質か、聞くと把握されていないことが多い。ここを把握しないと、文面に書けず、面談で候補者の質問に答えられません。把握すると、「インサイドセールスの前にマーケティングを整える必要がある」と分かることもあります。

エラベルでは、インサイドセールスの案件で担当者を紹介するとき、依頼側に分担と指標の一文と、見込み客の質と量を先に把握していただき、それが担当者に渡ってから文面に入るようお伝えしています。渡らなければ、担当者の最初の仕事は、この三つを引き出す打ち合わせです。見込み客の状態が正直に書かれた文面は、返信の総数は減っても、面談後の辞退が減ります。

## まとめ

- インサイドセールスがスカウトを読まない理由は**テレアポと区別が付かない・見込み客の状態を確かめる・指標に質があるかを見る・フィールドセールスとの関係と道を見る**
- 先に決めるのは**対象**。**転向元（経験者・カスタマーサポート・フィールドセールス・テレアポの一部）ごとに分け、一行目と訴求を変える**
- 文面の型は**一行目に候補者の接触の一点→分担と指標→見込み客の質と量（正直に）→架電の型→目標と評価→フィールドセールスとの関係と道→体制→商材（短く）→会社の紹介（短く）→営業の責任者が出る面談**
- 刺さる訴求は**分担・質の指標・見込み客の状態・課題を聞き出す接触・フィールドセールスとの関係と道の具体**。外す訴求は**「架電」「アポ獲得」「一日〇〇件」などテレアポに読める言葉**
- 面談には**営業の責任者が出て、見込み客の実例を見せ、指標と架電の型を再確認**。転向元ごとの確認も
- 代行に出せるのは**転向元ごとの検索・個別化・送信・その日の一次対応・面談の設定・記録**。分担・指標・見込み客の状態は社内から

## よくある質問

### 見込み客の件数を文面に書くと、少なさが目立ちませんか

少ないなら、少ないと書いたほうが、面談後の辞退が減ります。「月に〇〇件」と書いて少ないと感じる人は、入社後に「少ない」と分かって離れる人です。少ない場合は、「見込みはまだ少なく、マーケティングと一緒に増やす仕組みを作るところから関わってほしい」と書くと、営業組織の設計に関心のある人が返信します。件数を書かないと、「見込みが無い会社かもしれない」と最悪を想定されて、返信が来ません。書く粒度は、月の件数の目安と、見込み客の状況の傾向で、個別の顧客の情報ではありません。

### カスタマーサポートの人に送って、売る側に転向してもらえますか

課題を聞き出す接触に慣れているカスタマーサポートの人は、インサイドセールスに向く素養があります。ただ、売る側の目標（商談の数や質の目標、歩合）に向き合うことに抵抗がある人もいます。一行目で「聞き出してきた課題と提案」に触れ、訴求で「聞き出す力を売る側で活かせる」と書き、目標と評価を正直に書いて、面談で「目標に向き合えるか」を確かめます。転向の動機（顧客の課題を解決する側に回りたい、など）がある人は、インサイドセールスとして定着しやすい。

### フィールドセールスに進む道を書くと、インサイドセールスに定着しない人が来ませんか

道を書かないと、意欲のある人が来ません。道を書き、「インサイドセールスとして〇〇の成果を出したら」と条件と期間の目安を示すと、定着しながら次を目指す人が来ます。道を隠して採ると、入社後に「道が無い」と分かって離れます。インサイドセールスを長く続けてほしいなら、インサイドセールスの中でのキャリア（リーダー、仕組みの設計、マーケティングとの連携の設計）を示します。道を示すことと、定着は両立します。
