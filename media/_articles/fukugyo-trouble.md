どれだけ線を引いても、トラブルは起きます。候補者から「対応が遅い」と苦情が来る、依頼側から「聞いていた話と違う」と言われる、応募者の情報を誤送信する、本業の同僚が候補者として現れる。起きたときに、一人で何とかしようとすると、状況が広がり、責任が曖昧になり、依頼側が後から知って信用を失います。結論を先に書くと、**トラブルは「候補者」「依頼側」「情報」「本業」の四種類に分かれ、どれも「止める・伝える・記録する・戻す」の順で対応し、一人で対処せず、依頼側の担当と一緒に動く**のが型です。トラブルそのものより、隠したこと、一人で動いたことのほうが、信用を失います。情報の事故の対応は[情報の取り扱いと端末の分離](/media/fukugyo-security/)に、期待のずれは[期待値のすり合わせ](/media/fukugyo-kitai-chousei/)にまとめています。

## 四種類のトラブル

副業で起きるトラブルを、四種類に分けます。種類によって、伝える相手と戻す先が違います。

| 種類 | 例 | 伝える相手 | 戻す先 |
|---|---|---|---|
| 一 候補者 | 対応が遅いという苦情、見送りへの不満、条件の食い違い、連絡の行き違い | 依頼側の担当 | 依頼側の窓口が対応。副業の人は事実を整理 |
| 二 依頼側 | 認識のずれ（範囲、成果、稼働）、支払いの遅れ、担当の交代による前提の消失、範囲外の要求 | 依頼側の担当と判断する人 | 書面。区切りでの見直し |
| 三 情報 | 誤送信、端末の紛失、別の依頼側への混入、候補者情報の漏れ | 依頼側の担当、すぐに | 依頼側の規程と指示。専門家 |
| 四 本業 | 本業の同僚や取引先が候補者に、本業の規定との衝突、本業に副業が伝わる | 本業の規定に従う。依頼側にも必要な範囲で | 本業の規定。専門家 |

四種類の要点は、「伝える相手が違う」ことです。候補者のトラブルは依頼側の担当に、情報のトラブルは依頼側にすぐ、本業のトラブルは本業の規定に沿って。相手を間違えると、対応が遅れます。

## 共通の対応の順番

四種類に共通する、対応の順番を番号付きで整理します。

1. **止める。** 気づいた時点で、そのトラブルに関わる作業を止める。誤送信なら追加の送信を止める。認識のずれなら、ずれたまま進めない。
2. **伝える。** 依頼側の担当に、何が、いつ、どこで、どの範囲で起きたかを、分かっている範囲で。分からないことは「確認中」と伝える。自分で対処してから伝えない。
3. **記録する。** 起きたこと、伝えた日時、伝えた内容、依頼側の指示を、時系列で。自分の側の記録には、候補者の名前や依頼側の内情を含めない。
4. **依頼側の指示に従う。** 対応の主体は依頼側。候補者への連絡、関係者への説明、関係機関への対応は、依頼側が判断する。
5. **戻す。** トラブルの原因が、範囲・判断・社内・法令のどの線に関わるかを見て、書面と運用に戻す。
6. **原因を段階で特定する。** 受け取り、作業、保管、連絡、判断のどこで起きたか。人の責任ではなく、構造で。
7. **同じ段階が起きない形に直す。** 運用の型を直し、書面を更新する。
8. **区切りで、依頼側と振り返る。** 起きたこと、対応、直したことを、一枚で。

順番の要点は、「二で、自分で対処してから伝えない」ことです。先に対処すると、状況が変わって把握できなくなり、依頼側は「なぜ先に言わなかったか」と感じます。伝えてから、依頼側と一緒に対処します。

### エラベルの見解

登録の相談で多いのは、「候補者から苦情が来て、自分で謝って収めたが、後で依頼側が知って『なぜ言わなかった』と言われた」という話です。副業の人は、依頼側に迷惑をかけたくなくて、自分で収めた。依頼側から見ると、自社の候補者に起きたことを、外部の人が自社に知らせずに処理していた。収まったこと自体より、知らされなかったことが信用を損ねました。

見ていて差がつくのは、「小さなトラブルでも、依頼側に伝える習慣があるか」です。「候補者から返信の遅れについてお声がありました。お詫びして、次の連絡の目安をお伝えしました。念のため共有します」。この一言があると、依頼側は「見えている」と感じ、副業の人を信頼します。エラベルの登録でも、長く続いている人は、小さなトラブルを隠さず、依頼側と一緒に対応する習慣を持っていて、依頼側から「安心して任せられる」と言われています。トラブルは、隠すと信用を失い、伝えると信用を作ります。

## 種類ごとの動き方

四種類それぞれで、共通の順番に加えて注意する点を整理します。

**候補者のトラブル**

| 場面 | 動き方 |
|---|---|
| 対応の遅れへの苦情 | お詫びと、次の連絡の目安を伝える。依頼側に共有。原因（分担の不足、判断待ち）を特定して直す |
| 見送りへの不満 | 依頼側の方針の範囲で丁寧に。理由の開示は依頼側の判断。自分の解釈を言わない。[候補者対応で気をつけること](/media/fukugyo-kouhosha-taiou/) |
| 条件の食い違い | 自分が言ったことと、依頼側の提示を並べて依頼側に。候補者への説明は依頼側から。[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/) |
| 候補者が感情的になった | 窓口を依頼側に移す。自分は事実の記録。一人で対応し続けない |

**依頼側のトラブル**

| 場面 | 動き方 |
|---|---|
| 「聞いていた話と違う」 | 書面と記録を示す。責めずに、どこでずれたかを一緒に見る。[期待値のすり合わせ](/media/fukugyo-kitai-chousei/) |
| 支払いの遅れ | 締め日と支払日の書面を示し、翌営業日に確認。[未払いのときの対応](/media/fukugyo-mibarai/) |
| 担当が変わって前提が消えた | 型と現状と書面を新しい担当に渡し、初回打ち合わせをやり直す |
| 範囲外の要求が強い | 書面を示し、区切りに送る。それでも続くなら、区切りで範囲の変更か終了を |

**情報のトラブル**

| 場面 | 動き方 |
|---|---|
| 誤送信 | 追加の送信を止め、依頼側にすぐ伝える。送信先への対応は依頼側の指示で。記録 |
| 端末の紛失 | 依頼側にすぐ伝える。保存しない運用なら情報は無いはずだが、権限の停止を依頼側に |
| 別の依頼側への混入 | 両方の依頼側に伝える。混入した情報の扱いは依頼側の指示で |
| 候補者情報の漏れの可能性 | 依頼側にすぐ。関係機関や本人への対応は依頼側の判断。専門家に |

**本業のトラブル**

| 場面 | 動き方 |
|---|---|
| 本業の同僚や取引先が候補者に | その候補者の対応から外れる。依頼側に「本業との関係で対応できない候補者がいる」と伝える（本業の詳細は言わない）。判断は専門家に |
| 本業の規定との衝突が分かった | 本業の規定を確認し、必要なら副業を止める。依頼側には範囲か時間の理由で。[副業の許可申請](/media/fukugyo-kyoka-shinsei/) |
| 本業に副業が伝わった | 本業の規定に従う。届け出が要るなら届け出る。隠さない |

種類ごとの要点は、「情報のトラブルは、すぐに」ということです。候補者や依頼側のトラブルは、数日の余裕があることもありますが、情報のトラブルは時間とともに広がります。気づいた時点で、その日のうちに伝えます。

## 一人で対処しない理由

トラブルを一人で対処しようとすることが、最も多い失敗です。理由を整理します。

| 一人で対処すると | 依頼側と一緒に対処すると |
|---|---|
| 状況が把握できないまま動き、広がる | 依頼側が全体を見て、対応の順番を決められる |
| 責任が副業の人に集まる | 責任の所在が依頼側の判断のもとに整理される |
| 依頼側が後から知り、信用を失う | 依頼側は「見えている」と感じ、信用が育つ |
| 候補者への対応が会社の方針とずれる | 会社の方針で対応できる |
| 情報のトラブルで、法令上の対応が漏れる | 依頼側の規程と専門家の判断で対応できる |
| 本業との衝突を自分だけで抱える | 必要な範囲で依頼側にも伝え、対応を分けられる |

理由の要点は、「一人で対処することが、責任を自分に集める」ことです。依頼側に迷惑をかけたくない気持ちは、結果的に依頼側の判断の機会を奪い、責任を自分に寄せます。

## トラブルのあとに見直すこと

対応が終わったあと、見直すことを整理します。同じことを起こさないためです。

| 見直すこと | 問い |
|---|---|
| 線 | 範囲・判断・社内・法令のどの線に近づいていたか。[踏み込みすぎない線引き](/media/fukugyo-ihan-shinai/) |
| 運用 | 受け取り・作業・保管・連絡・判断のどの段階で起きたか |
| 書面 | 書面に、その場面の扱いが書かれていたか。無ければ足す |
| 分担 | 依頼側の分担が動いていたか。動いていなければ、数で示して直す |
| 連絡先と手順 | トラブル時に誰に伝えるかが決まっていたか。無ければ書面に |
| 自分の習慣 | 隠そうとしたか、一人で動こうとしたか。伝える習慣を戻す |

見直しの要点は、「書面に足す」ことです。トラブルの多くは、書面に無い場面で起きます。起きた場面の扱いを書面に足せば、次は書面に沿って動けます。

## 動き方の失敗

トラブル対応で起きやすい失敗を整理します。

| 失敗 | 起きる構造 | 直し方 |
|---|---|---|
| 一人で収める | 迷惑をかけたくない | 伝えてから一緒に。小さくても伝える |
| 対処してから伝える | 先に何とかしたい | 止めて、伝えて、指示に従う |
| 隠す | 信用を失うと思う | 隠すほうが失う。伝えると信用が育つ |
| 候補者に自分の判断で謝罪・説明する | 早く収めたい | 依頼側の方針で。窓口を依頼側に |
| 情報のトラブルを翌週まで持ち越す | 稼働の枠の外 | 情報だけは、その日のうちに |
| 記録を残さない | 動くのに精一杯 | 時系列で。伝えた日時と内容 |
| 人の責任にする | 担当が遅いから | 構造で。段階で特定 |
| 本業との衝突を依頼側に詳しく話す | 説明したい | 本業の詳細は言わない。範囲か時間の理由で |
| トラブルのあと、書面を直さない | 収まったから | 起きた場面の扱いを足す |
| トラブルで自分を責め続ける | 責任感 | 段階で特定し、直して、次へ。区切りで振り返る |

失敗の要点は、「隠す・一人で動く・先に対処する」の三つで、トラブルの影響が広がります。この三つを避ければ、トラブルは信用を作る機会になります。

### エラベルの見解

担当する側として登録した人の話を聞くと、トラブルのあとに依頼側との関係が深まった人は、例外なく、隠さず、一人で動かず、伝えてから一緒に対応しています。依頼側から見ると、トラブルが起きたことより、そのとき副業の人がどう動いたかを見ています。伝えてくれた、一緒に対応してくれた、書面を直してくれた。この動きが、「この人は何かあったときに信頼できる」という評価になります。

依頼側から見ると、外部の人がトラブルを一人で処理することは、自社の候補者や情報に起きたことを自社が把握できない状態で、最も避けたいことです。エラベルは、企業と担当者の間に立つ窓口として、案件を出すときに、トラブル時の連絡先と手順を依頼側と担当者の間で決めていただくようお伝えしています。止める・伝える・記録する・戻すの型を持ち、一人で対処しない習慣を持っていただくことが、トラブルを信用に変える条件です。個別の対応、とくに情報や本業に関わるものは、専門家にご確認ください。

## まとめ

- トラブルは**候補者・依頼側・情報・本業**の四種類。伝える相手と戻す先が違う
- 共通の順番は**止める→伝える→記録する→指示に従う→戻す→段階で特定→直す→区切りで振り返る**
- **自分で対処してから伝えない**。伝えてから一緒に対処する
- **情報のトラブルはその日のうちに**。時間とともに広がる
- 一人で対処すると**責任が自分に集まり、依頼側は後から知って信用を失う**
- トラブルのあとは**書面に、起きた場面の扱いを足す**。隠す・一人で動く・先に対処する、の三つを避ければ、トラブルは信用を作る機会になる

## よくある質問

### 小さなことまで依頼側に伝えると、頼りない人だと思われませんか

逆です。小さなことを伝える人は、「見えている人」「隠さない人」として信頼されます。伝えないことが積み重なって、大きなトラブルになったときに、「小さいときに言ってくれていれば」となります。伝え方は、報告の一行で足ります。「候補者から〇〇についてお声があり、〇〇と対応しました。共有まで」。依頼側は、対応が済んでいることと、知らされたことの両方で安心します。頼りなく見えるのは、伝えないことで後から発覚したときです。

### 依頼側の担当が原因のトラブルを、担当に伝えにくいです

担当が原因でも、伝える相手は担当です。伝え方を、人の責任ではなく構造にします。「日中の一次返信が入っていない週があり、その週に候補者からお声がありました。分担の運用を見直させてください」。担当が悪い、ではなく、分担の運用が動いていなかった、と構造で伝えれば、担当は受け取れます。担当を飛ばして判断する人に伝えると、担当の立場が崩れ、以後の協力を失います。担当に伝えて、担当と一緒に判断する人に上げる形にします。[社内の人事担当との役割分担](/media/fukugyo-shanai-jinji/)を参照してください。

### 本業の同僚が候補者として応募してきました。依頼側に何と言えばよいですか

その候補者の対応から自分が外れることを、本業の詳細を言わずに伝えます。「本業との関係で、私が対応できない候補者が一名います。この方の対応は御社の担当の方でお願いできますか」。本業の社名や同僚であることは言いません。依頼側は、外部の人が利益相反を自ら申告したと受け取り、むしろ信頼します。候補者にも、自分が対応していたことは伝えません。本業の規定で、副業で本業の関係者と接した場合の扱いが決まっていることもあるので、規定を確認し、判断に迷う点は専門家にご確認ください。[本業と利益相反になる案件](/media/fukugyo-riekisouhan/)を参照してください。
