中途の求人に、社会人一〜三年目の応募が来る。経験は浅く、中途として見ると物足りない。ただ、新卒のように一から育てるほどでもない。給与はどう決めるのか、育て方は新卒と同じか、面接では何を見るのか。社内で決まっておらず、応募のたびに迷う。結論を先に書くと、**第二新卒は、「新卒でも中途でもない層」として、自社の役割と育てる型の中に、独自の位置を置きます。中途の観点で見れば物足りず、新卒の観点で見れば過剰です。「社会人の基礎はある。専門は浅い。育てれば早い」という層として、役割・給与・見極め・育て方を決めます**。未経験採用の判断は[未経験採用に踏み切るか迷っている](/media/rpo-mikeiken-saiyo/)に、新卒と中途の代行の分け方は[新卒と中途を同じ代行に任せるか](/media/scout-daikou-shinsotsu-chuuto/)にまとめています。

## 位置づけが曖昧な会社で起きていること

第二新卒の位置づけが決まっていない会社では、次のことが起きています。

| 起きていること | 背景 |
|---|---|
| 中途の求人で応募が来て、「経験が浅い」で落とす | 中途の観点（経歴の深さ）で見ている。第二新卒は、その観点では通らない |
| 新卒の枠で扱おうとして、本人が違和感を持つ | 社会人の経験があるのに、新卒と同じ研修と給与。本人は「中途で応募した」と思っている |
| 給与が決められない | 新卒の水準か、中途の水準か。基準が無く、候補者ごとに変わる |
| 面接官が、何を見ればよいか分からない | 経歴は浅く、新卒のような「学生時代の話」でもない。観点が無い |
| 育て方が決まっていない | 新卒の研修に入れるのか、中途のように現場に置くのか |
| 「早く辞めた人」という先入観で見ている | 一社目を短期で辞めたことを、理由を聞かずに減点している |
| 第二新卒向けの求人票が無い | 中途の求人票（経験者向け）か、新卒の求人票（学生向け）しか無い |

曖昧なまま応募を受けると、通すべき人を落とし、通した人にも合わない扱いをします。

## 第二新卒とは誰か

「第二新卒」の定義は、会社や媒体によって幅があります。自社で定義します。

**一般に言われる範囲。** 学校を卒業して就職し、おおむね数年以内に転職を考えている層。社会人の基礎（ビジネスの作法、組織で働く経験）はあるが、専門の経験は浅い。媒体ごとの定義は、各媒体の公式の案内で確認します。

**自社で決める要素。** 「卒業後、何年以内か」「社会人の経験が何か月以上あるか」「一社目の職種は問うか」。自社の役割と育てる型に合わせて、決めます。

**新卒との違い。** 社会人の基礎がある。会社と仕事の現実を知っている。「思っていたのと違った」を一度経験している。新卒の研修（作法、基礎）は要らないことが多い。

**中途との違い。** 専門の経験が浅い。即戦力ではない。育てる期間が要る。経歴の深さで見極められない。

**この層の特徴。** 一社目で「合わなかった」経験があるので、二社目では「合うかどうか」を慎重に見ている。役割と働き方の実態を知りたがる。育てる型がある会社を選ぶ傾向がある。

定義を決めると、求人票で「対象」を書け、面接官に「見る観点」を渡せます。

## 自社での位置づけの決め方

第二新卒を、自社のどこに置くかを決めます。

**どの役割に置くか。** 中途の役割をそのまま渡すと、専門の浅さで詰まります。新卒の役割を渡すと、本人が物足りません。「社会人の基礎を前提に、専門をこれから積む役割」を切り出します。未経験が最初に担う役割の切り出しと同じ考え方で、[未経験採用に踏み切るか迷っている](/media/rpo-mikeiken-saiyo/)に書いています。

**新卒の枠と中途の枠のどちらで管理するか。** 採用の数の管理、予算の管理を、どちらの枠で行うか。「第二新卒枠」を別に持つ会社もあります。

**育てる型は、新卒と中途のどちらに寄せるか。** 新卒の研修の「基礎」の部分は飛ばし、「専門」の部分から入る。中途の「現場に置いて任せる」形では、専門の浅さで詰まる。間の型を作ります。

**給与の水準を、どこに置くか。** 新卒の水準と、中途の水準の間。社会人の経験の年数と、一社目の経験の活かせる度合いで決めます。既存社員（同じ年次の新卒入社の社員）との整合を先に見ます。

**評価の仕組みは、どちらに乗せるか。** 新卒入社の同年次と同じ仕組みか、中途の仕組みか。整合を取ります。

**採用の責任者は、誰か。** 新卒の担当者か、中途の担当者か。どちらの経路でも応募が来るので、窓口を決めます。

位置づけが決まれば、応募のたびに迷わなくなります。

## 見極めの観点

第二新卒を、何で見極めるかです。中途の観点でも、新卒の観点でもない観点を作ります。

| 観点 | 確認の仕方 |
|---|---|
| 一社目で得たもの | 「一社目で、できるようになったことは何ですか」。短くても、具体的に語れるか |
| 辞める理由の妥当性 | 「なぜ辞める（辞めた）のですか」。理由が具体的で、自社では起きにくいものか。他責だけではないか |
| 二社目で求めるもの | 「次の会社で、何を大事にしますか」。一社目の経験から学んだ軸があるか |
| 役割の認識 | 「この役割で、最初の半年は何をすると思いますか」。専門が浅くても、役割を想像できるか |
| 社会人の基礎 | 応募からのやり取り、時間の守り方、報告の仕方。新卒より基礎があることの確認 |
| 覚える速さと、覚え方 | 「一社目で、新しいことをどう覚えましたか」。具体的な方法を語れるか |
| 続ける力 | 一社目を短期で辞めた場合、「次は続けられるか」を、理由と軸から判断する |
| 隣の経験 | 一社目の職種が違っても、活きる動き（顧客と話す、数字を追う、手順を回す）があるか |

「一社目を短期で辞めた」ことを、それだけで減点しません。理由と、そこから学んだ軸を聞きます。理由が具体的で、軸が自社に合えば、二社目では続く可能性が高いです。

観点を書面にし、面接官に渡します。中途の面接官が経歴の深さで見れば、第二新卒は全員落ちます。

### エラベルの見解

相談で最も多い失敗は、「中途の求人に来た第二新卒を、中途の面接官が『経験が浅い』で落とし続けた。半年後、経験者も第二新卒も採れていなかった」というものです。第二新卒の観点（一社目で得たもの、辞める理由の妥当性、二社目で求めるもの、覚え方）を作り、面接官に渡し、給与の基準と育てる型を決めたら、同じ応募から採れるようになりました。応募は来ていました。位置づけが無かっただけです。

見ていて差がつくのは、担当者が「第二新卒の観点」を別に作るかどうかです。「中途の観点で見てください」で終わる担当者と、「第二新卒は、経歴の深さでは見られません。一社目で得たもの、辞める理由、二社目の軸、覚え方で見る観点を作りました」と、別の観点を渡す担当者がいます。後者なら、面接官は見極められます。

発注側にできるのは、「第二新卒も採りたい」と言うだけでなく、「第二新卒の観点と、給与の基準と、育てる型を作ってほしい」と依頼することです。

## 給与と役割の設計

第二新卒の給与と役割を、既存社員との整合の中で設計します。

**同じ年次の新卒入社の社員を、基準にする。** 「卒業後二年で入社した第二新卒」と、「新卒で入社して二年目の社員」。同じ年次の社員の水準を基準に、一社目の経験の活かせる度合いで調整します。

**一社目の経験が活きる場合と、活きない場合で分ける。** 同じ職種からなら、活きる分を上乗せ。違う職種からなら、同じ年次の新卒入社と同じ水準から。

**役割は、「専門をこれから積む役割」として切り出す。** 中途の役割をそのまま渡さない。「最初の半年はこの範囲、一年でこの範囲」と、段階を決めます。

**役割が上がれば給与が上がる関係を、示す。** 「この役割でこの水準、この段階に上がればこの水準」。入社後の見通しが見えれば、入口の給与が中途より低くても、判断できます。制度と整合していることが前提です。

**中途の水準を期待して応募した人には、正直に伝える。** 「中途の求人に応募されましたが、経験の深さから、第二新卒の位置づけでの提示になります。理由はこうです」。隠すと、内定の場で辞退されます。

**制度の変更は、社内の規程と法令に沿う。** 給与の基準を新たに設ける場合は、専門家に確認します。

給与の基準が無いと、候補者ごとに変わり、既存社員との整合が崩れます。基準を先に作ります。

## 育てる型と受け入れ

第二新卒の育てる型は、新卒と中途の間に置きます。

| 項目 | 第二新卒の型 |
|---|---|
| 基礎の研修 | 新卒向けの作法や基礎は、省略か短縮。社会人の経験を前提に |
| 専門の育成 | 未経験と同じ型。到達点、三か月の予定、教える人、教える方法 |
| 到達点 | 新卒より早く設定できる。「三か月で〇〇、半年で△△、一年で一人で回せる」 |
| 教える人 | 一人決める。新卒の同期がいない分、相談の相手を明確に |
| 同年次の社員との接点 | 新卒入社の同年次の社員と接点を作る。「同期」の代わりになる |
| 一社目の経験の扱い | 「前の会社ではこうだった」を否定せず、自社の型との違いを説明する |
| 確認の頻度 | 毎日の短い確認と、週に一度の振り返り。一社目で「放置された」経験がある人が多いので、接点を密に |
| 育たない場合の判断 | 半年で到達点に届かない場合の判断を、先に決める |

受け入れの要点は、「一社目の失敗を繰り返さない」ことです。第二新卒は、一社目で「合わなかった」経験をしています。放置、役割の不明確さ、聞けない環境。同じことが起きれば、二社目も辞めます。

## 新卒・中途との並行

第二新卒の採用を、新卒と中途と並行して設計します。

**三つの層を、別の求人票にする。** 新卒向け、第二新卒向け、中途向け。一つの求人票に「新卒・第二新卒・中途歓迎」と書くと、どの層にも届きません。

**経路を分ける。** 新卒は学校と新卒の媒体、第二新卒は第二新卒向けの媒体と中途の媒体（若手の層）、中途はスカウトと紹介会社。媒体の対象は各媒体の公式の案内で確認します。

**面接官の観点を、層ごとに渡す。** 同じ面接官が三つの層を見るなら、三つの観点の書面を渡します。

**給与の基準を、三つの層で整合させる。** 新卒の水準、第二新卒の水準、中途の水準が、年次と経験で一本の線になっているか。

**育てる型を、層ごとに置く。** 新卒は基礎から、第二新卒は専門から、中途は受け入れと役割の確認から。

**採用の責任者を、決める。** 三つの層を一人が見るか、分けるか。分けるなら、第二新卒をどちらが持つか。

並行する設計は、「第二新卒を採るか採らないか」ではなく、「三つの層を、それぞれ採れる会社」を作ります。

## 外注する場合の範囲

第二新卒の採用を、採用代行に出す場合の範囲です。

**出せる工程。** 自社での第二新卒の定義の整理、位置づけの案（役割の切り出し、枠、育てる型の寄せ方）、見極めの観点と質問の作成、給与の基準の案（既存社員との整合の整理）、第二新卒向けの求人票、経路の設計と運用、応募の受付と層の振り分け、面接官への観点の共有、記録、育てる型と受け入れの案、新卒・中途との並行の設計。

**社内に残す判断。** 定義と位置づけの決定、給与の基準の決定、制度の変更、役割の段階の決定、教える人、判定、内定、育たない場合の判断。

**外注の効きどころ。** 第二新卒は、社内で「新卒でも中途でもない」ため、担当が決まらず、位置づけが曖昧になりやすい層です。担当者が定義と位置づけの案を出し、観点と基準と型を用意すれば、社内は決めるだけで済みます。応募の振り分け（この人は第二新卒の観点で、この人は中途の観点で）も、担当者が行えます。

**外注しても動かない場合。** 社内が「第二新卒枠」を認めない、給与の基準を決めない、中途の面接官が観点を変えない。社内の判断で、代行を替えても直りません。

第二新卒は、位置づけが決まれば採れる層です。外注は、位置づけを決める材料を揃える手段です。

### エラベルの見解

担当する側から見ると、第二新卒の相談で最も多いのは、「一社目を短期で辞めたことを、理由を聞かずに減点している」ことです。「すぐ辞める人」と決めつけて落とす。理由を聞くと、一社目の役割が求人票と違った、放置された、聞ける人がいなかった。自社で同じことが起きなければ、続く人です。

理由を聞き、二社目で求める軸を聞き、自社の実態と照らす。それで、「続く人」と「続かない人」は分かれます。短期の退職の事実だけでは、分かれません。

発注側にできるのは、面接官に「一社目を短期で辞めた理由を、必ずしも減点材料にしない」と伝えることです。理由と軸で見ます。

## まとめ

- 曖昧だと**中途の観点で落とす・新卒扱いで違和感・給与が決まらない・面接官が観点を持たない・育て方が無い・短期退職の先入観・求人票が無い**
- 定義は**一般の範囲を参考に、自社で「卒業後何年・経験何か月・一社目の職種」を決める**。新卒とは基礎の有無、中途とは専門の深さが違う
- 位置づけは**役割の切り出し・枠・育てる型の寄せ方・給与の水準・評価の仕組み・採用の責任者**を決める
- 見極めは**一社目で得たもの・辞める理由の妥当性・二社目の軸・役割の認識・社会人の基礎・覚え方・続ける力・隣の経験**。短期退職だけで減点しない
- 給与は**同年次の新卒入社を基準に・一社目の経験の活きる度合いで調整・役割の段階と対応・中途の水準を期待した人には正直に**。制度の変更は専門家に確認
- 育てる型は**基礎は省略・専門は未経験の型・到達点は早めに・教える人・同年次との接点・一社目の経験を否定しない・接点を密に**
- 並行は**三つの求人票・経路を分ける・観点を層ごとに・給与を一本の線に・型を層ごとに・責任者を決める**
- 外注できるのは**定義と位置づけの案・観点・基準の案・求人票・経路・振り分け・記録・型の案・並行の設計**。社内に残るのは**決定・基準・制度・教える人・判定・育たない場合の判断**

## よくある質問

### 第二新卒は、新卒と中途のどちらの枠で管理すればよいですか

自社の管理のしやすさで決めます。新卒の枠に入れれば、育てる型を新卒に寄せやすく、中途の枠に入れれば、応募の経路が中途と重なります。「第二新卒枠」を別に持つ会社もあります。どの枠でも、役割・給与・観点・育てる型は、第二新卒として別に決めます。枠の管理と、位置づけの設計は、別の話です。

### 一社目を数か月で辞めた人は、避けるべきですか

事実だけで判断しません。辞めた理由と、二社目で求める軸を聞きます。理由が具体的（役割が求人票と違った、放置された、聞ける人がいなかった）で、自社では起きにくいことなら、続く可能性があります。理由が曖昧、または他責だけなら、慎重に見ます。「短期で辞めた＝すぐ辞める人」と決めつけると、通すべき人を落とします。

### 給与を、中途の水準で出すべきですか

専門の経験の深さで見れば、中途の水準には届かないことが多いです。同じ年次の新卒入社の社員を基準に、一社目の経験の活きる度合いで調整します。中途の求人に応募して中途の水準を期待している人には、「第二新卒の位置づけでの提示になります。理由はこうです。役割が上がればこの水準です」と、正直に伝えます。内定の場で初めて伝えると、辞退されます。
