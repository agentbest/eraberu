親の介護が始まり、本業と介護で手一杯になりつつある。それでも、人事の経験を副業で活かしたい、あるいは、介護で本業の働き方を変えた分を副業で補いたい。介護と副業は両立できるのか。結論を先に書くと、**介護と副業の両立は、「介護の状況は変わる」ことを前提に、稼働の枠を小さく固定し、突発で止まる日があることを依頼側に先に伝え、止まったときの動き方を決めておけば、できます。両立できるかどうかは、介護の重さではなく、止まり方の設計で決まります。介護は、育児と違って、先が読めず、重くなる方向に変わることが多く、突発の対応が繰り返し起きます。それを隠して受けると、止まったときに信用が消えます。先に伝えて受ければ、止まっても信用は残ります。**育児・介護と両立できる業務と契約の形は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)に、時間帯が読めないときの枠の作り方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に、止まるときの伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)にまとめています。

## 介護の両立が育児と違う点

育児との両立と、介護との両立は、似ているようで違います。違いを押さえておくと、設計が変わります。

| 点 | 育児 | 介護 |
|---|---|---|
| 先の見通し | 成長とともに手が離れる方向。時期がある程度読める | 重くなる方向に変わることが多い。いつまで続くか読めない |
| 突発の頻度 | 体調不良など、時期によって波がある | 通院、体調の急変、施設や制度の手続きが、不定期に起きる |
| 周囲の理解 | 「子どもの事情」は説明しやすい | 「親の介護」は説明しにくく、本業にも依頼側にも伝えていない人が多い |
| 心理的な負担 | 疲れはあるが、先が見える | 先が見えず、気持ちが沈む時期がある。判断が鈍る |
| 制度 | 本業の育児の制度は整っていることが多い | 介護の制度は会社によって差がある。制度の内容は会社と専門家にご確認ください |
| 副業の位置づけ | 収入と経験の継続 | 収入の補い、本業を離れた場合の入口、気持ちの切り替えの場、のどれか |

違いの要点は、「介護は先が読めず、重くなる方向に変わる」ことです。育児の両立は、「今は大変だが、数年後は楽になる」を前提に設計できますが、介護は、「今より重くなったときに、どう縮めるか」を前提に設計します。副業の枠は、今の介護の状況ではなく、少し重くなった状況を想定して決めます。育児との両立の考え方は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)に書いています。

## 介護の段階ごとの副業の形

介護には段階があり、段階によって副業の形が変わります。今の段階と、次の段階を見ておきます。

| 段階 | 状況 | 副業の形 | 稼働の枠 |
|---|---|---|---|
| 見守り | 親は自立しているが、通院の付き添いや、たまの手助けが要る | 通常に近い形で受けられる。突発は月に数回 | 通常の枠。突発の日を依頼側に伝えておく |
| 部分的な介護 | 週に何日か、決まった手助けが要る。通院、食事、手続き | 決まった手助けの日を外した枠で受ける。時間帯が固定できる工程を選ぶ | 通常の半分程度。手助けの日は稼働しない |
| 日常的な介護 | 毎日手助けが要る。本業の働き方も変えている | 締め切りが柔らかい工程だけを、小さい枠で受ける。突発で止まる前提 | 週に数時間。止まる日があることを前提に |
| 施設や制度を使う移行期 | 施設の入所、制度の手続き、家族との調整で、突発が集中する | 一時停止か、今の案件を区切りまで。新規は受けない | 一時的にゼロに近い |
| 安定期 | 施設や支援が整い、手助けの時間が読めるようになる | 枠を少しずつ戻す。段階が上がる可能性を残して | 小さい枠から広げる |

段階の要点は、「今の段階ではなく、次の段階を想定して枠を決める」ことです。見守りの段階で通常の枠で受けていると、部分的な介護に移ったときに、案件の途中で枠が足りなくなります。今の段階より一つ重い段階でも回る枠で受けておけば、段階が変わっても案件を止めずに済みます。工程の選び方は[育児・介護と両立できるか](/media/fukugyo-kaigo-ikuji/)の「時間帯が読めない前提」の業務の考え方が使えます。

### エラベルの見解

担当する側から見ると、介護をしながら副業を続けている人と、続かなくなる人の差は、介護の重さではなく、「突発で止まる日があることを、先に依頼側に伝えているか」です。伝えている人は、止まった日に「本日は家庭の事情で稼働できません。明日〇時に再開します」と一言送るだけで済み、依頼側は「聞いていた通り」として受け止めます。伝えていない人は、止まった日に理由を説明するところから始まり、依頼側は「聞いていない」となり、続かなくなります。

見ていて差がつくのは、介護の状況が重くなったときに、案件を止めるのではなく、枠を縮めているかです。重くなった時点で「もう無理です」と案件を止める人は、戻れる道が消えます。「来月から稼働を半分にさせてください。範囲はこの工程だけに」と枠を縮める人は、案件は小さくなっても続き、状況が落ち着いたら戻せます。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の条件を小さく明確にしている担当者には、その条件に合う依頼側がついています。介護との両立は、介護を隠して頑張ることではなく、介護があることを前提に設計することです。

## 稼働の枠の決め方

介護と両立する稼働の枠は、通常の副業の枠とは決め方が違います。

| 決めること | 決め方 | 理由 |
|---|---|---|
| 週の稼働の上限 | 今の段階で取れる時間の、さらに半分程度 | 次の段階に移っても回る枠に。余った時間は休みに |
| 稼働する時間帯 | 介護の手助けが入らない時間帯。早朝か、手助けが終わった後 | 手助けの時間帯に稼働を置くと、毎回止まる。[早朝の稼働という選択](/media/fukugyo-hayaasa/) |
| 稼働しない日 | 通院や手助けの日を、先に依頼側に伝える | 「その日は返せない」が前提になる |
| 止まる日の想定 | 月に何日かは突発で止まる、と自分でも想定する | 止まった日に自分を責めず、動き方に移れる |
| 受ける工程 | 締め切りが柔らかく、途中で止めても影響が小さい工程 | 締め切りが固い工程は、突発で止まると依頼側の採用が止まる |
| 受ける案件の数 | 一件だけ | 複数の依頼側に突発の連絡を送る負担を避ける |
| 締め切りの置き方 | 自分の見積もりより、余裕を持たせて依頼側に伝える | 突発で止まっても、締め切りは守れる |

決め方の要点は、「上限を、今取れる時間の半分程度に置く」ことです。介護をしながらの副業で、取れる時間を全部稼働に入れると、休みがなくなり、突発が起きたときに締め切りが崩れます。半分に置けば、突発が起きても残りの半分で吸収でき、休みも残ります。稼働の上限の考え方は[週何時間から受けられるか](/media/fukugyo-kadou-jikan/)に、締め切りの余裕は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、案件の数は[複数案件のスケジュール管理](/media/fukugyo-fukusuu-kanri/)に書いています。

## 依頼側への伝え方

介護があることを、依頼側にどこまで、どう伝えるかです。

| 伝えること | 伝え方 | 伝えなくてよいこと |
|---|---|---|
| 突発で止まる日があること | 「家庭の事情で、月に何日か、当日に稼働できない日があります。その日は朝に連絡し、翌稼働日に再開します」 | 介護であること自体は、伝えても伝えなくてもよい |
| 稼働する時間帯と、しない日 | 「稼働は早朝と、〇曜と△曜の夜です。□曜は稼働しません」 | 介護の手助けの内容 |
| 締め切りの余裕 | 「締め切りは、余裕を持って置かせてください。早く終えたときは前倒しで出します」 | 余裕の理由の詳細 |
| 状況が変わる可能性 | 「事情が変わったときは、一か月前に稼働の見直しを相談させてください」 | 介護が重くなる見通し |
| 止まったときの連絡の型 | 「止まる日は朝に一言、再開の日時を添えて連絡します」 | 止まった理由の詳細 |

伝え方の要点は、「介護であることは伝えなくてよいが、突発で止まる日があることは伝える」です。介護を伝えることに抵抗がある人は多く、伝えなくて構いません。依頼側にとって必要なのは、理由ではなく、「止まる日があること」「止まったらどう連絡が来るか」「いつ再開するか」です。この三つが先に伝わっていれば、依頼側は困りません。伝え方の型は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に、稼働の報告は[稼働報告の書き方](/media/fukugyo-kadou-houkoku/)に整理しています。

## 突発で止まったときの動き方

介護の突発で止まった日の動き方を、先に決めておきます。決めてあれば、その場で考えずに済みます。

| 順番 | 内容 |
|---|---|
| 一、朝の時点で、今日は稼働できないと分かったら、一言送る | 「本日は家庭の事情で稼働できません。〇日〇時に再開します」。理由は書かない |
| 二、今日の締め切りがあれば、代わりの案を添える | 「本日予定の〇〇は、△日に出します。急ぎでしたら、途中までのものをお送りします」 |
| 三、依頼側からの連絡は、読めるなら読む。返信は再開時に | 「拝見しました。再開時に返します」まで |
| 四、再開したら、止まった間の連絡に最初に返す | 止まった間に来た連絡を、優先して処理する |
| 五、止まった日を記録する | 月に何日止まったか。枠の見直しの材料に |
| 六、止まる日が月に何日も続いたら、枠の見直しを相談する | 「来月から稼働を半分に」「範囲をこの工程だけに」 |
| 七、自分を責めない | 止まる日があることは、先に伝えてある前提の一部。動き方通りに動けば、信用は残る |

動き方の要点は、「一」の、朝の時点で一言送ることです。止まると分かった時点で送れば、依頼側はその日の予定を組み直せます。夕方になって「今日はできませんでした」と送ると、依頼側の一日が無駄になります。朝に一言、再開の日時つきで。この型を決めておけば、止まった日に考えることがなくなります。連絡の型は[遅れそうなときの連絡](/media/fukugyo-okure-renraku/)に、記録の残し方は[稼働時間の管理と申告](/media/fukugyo-kadou-kanri/)に書いています。

## 介護が重くなったときの縮小と一時停止

介護は重くなる方向に変わることが多く、そのときの動き方も先に決めておきます。

| 状況 | 動き方 | 伝え方 |
|---|---|---|
| 止まる日が月に何日も続く | 縮小。稼働を半分に、範囲を一つの工程に | 「来月から稼働を〇時間、範囲を□□だけにさせてください」。一か月前に |
| 段階が一つ上がった（部分的→日常的） | 縮小か一時停止。今の案件は区切りまで、新規は止める | 「家庭の事情が変わり、〇月の区切りで一度止めさせてください。落ち着いたら再開したいです」 |
| 施設や制度の移行期で、突発が集中する | 一時停止。期間を決める | 「〇月まで受けられません。その後に再開の相談をさせてください」 |
| 気持ちが沈み、判断が鈍っている | 一時停止。疲れているときに終了を決めない | 上と同じ。期間を決めて休む |
| 本業の働き方を変えた（短時間、休職） | 副業の位置づけを見直す。収入の補いなら枠を保ち、負担なら縮小 | 状況に応じて |
| 安定期に入った | 小さい枠から戻す。段階が上がる可能性を残す | 「落ち着いたので、〇時間から再開したいです」 |

縮小と一時停止の要点は、「終了ではなく、縮小か一時停止で止める」ことです。介護が重くなったときに副業を終了すると、介護が落ち着いた後に、戻る道がありません。介護の段階は、重くなった後に、施設や支援で安定することがあり、そのときに副業が入口として残っていると、生活と気持ちの支えになります。登録先の登録は消さず、休止にしておきます。一時停止と縮小の形は[副業をやめるとき](/media/fukugyo-yameru/)に、続ける設計は[長く続けるための設計](/media/fukugyo-choki/)に整理しています。

## 両立を続けるための順番

介護と副業の両立を続けるための順番です。

| 順番 | 内容 |
|---|---|
| 一、今の介護の段階と、次の段階を見る | 見守り、部分的、日常的、移行期、安定期のどれか。次はどれか |
| 二、次の段階でも回る枠を決める | 今取れる時間の半分程度。時間帯は手助けが入らない時間帯 |
| 三、受ける工程と案件の数を絞る | 締め切りが柔らかい工程を、一件だけ |
| 四、突発で止まる日があることを依頼側に伝える | 理由は伝えなくてよい。止まる連絡の型と再開の形を伝える |
| 五、止まった日の動き方を決めておく | 朝に一言、代わりの案、再開時に最初に返す、記録する |
| 六、止まった日を記録し、月に一度見る | 止まる日が増えたら、枠の見直しを一か月前に相談する |
| 七、重くなったら縮小か一時停止。終了しない | 登録先は休止に。戻る道を残す |
| 八、本業の制度と、介護の支援を使う | 本業の介護の制度、地域の支援は、会社と専門家にご確認ください。副業で補うより先に |

順番の要点は、「八」の、本業の制度と介護の支援を、副業より先に使うことです。介護の負担を副業で補おうとする前に、本業の介護の制度、地域の支援、家族との分担で、介護の負担そのものを減らせないかを見ます。制度と支援の内容は、会社と地域によって違うため、会社と専門家にご確認ください。副業は、その上で残った時間と気持ちの中で、小さい枠で続けるものです。副業を負担の補いに使うと、介護と本業と副業の全部が崩れます。本業との時間の分け方は[本業と両立する時間の作り方](/media/fukugyo-jikan-kakuho/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、「介護があると、副業は無理だ」というものです。実際には、介護をしながら続けている担当者は少なくなく、共通しているのは、枠を小さく固定し、止まる日があることを先に伝え、止まったときの動き方を決めていることです。介護の重さは人によって違いますが、止まり方の設計があれば、重くても小さい枠で続けられ、無ければ軽くても止まります。

順番として、今の段階と次の段階を見て、次の段階でも回る枠を決め、締め切りが柔らかい工程を一件だけ受け、止まる日があることを依頼側に伝え、止まった日の動き方を決めておき、止まった日を記録して月に一度見て、重くなったら縮小か一時停止にして終了せず、本業の制度と介護の支援を副業より先に使う。この順番で、介護と副業の両立は、「頑張って両立する」ものから、「止まる前提で設計された」ものになります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、稼働の条件を小さく明確にした担当者には、その条件で十分な依頼側がついています。両立できるかは、介護の重さではなく、止まり方の設計で決まります。

## まとめ

- 介護と副業の両立は**「介護の状況は変わる」前提で、枠を小さく固定し、止まる日があることを先に伝え、止まったときの動き方を決めておけば**できる
- 介護は育児と違い**先が読めず、重くなる方向に変わる**。今の段階ではなく次の段階でも回る枠で受ける
- 枠は**今取れる時間の半分程度、手助けが入らない時間帯、締め切りが柔らかい工程を一件だけ**
- 依頼側には**介護であることは伝えなくてよいが、止まる日があることと連絡の型と再開の形は伝える**
- 止まった日は**朝に一言、再開の日時つき、代わりの案を添える**。自分を責めない
- 重くなったら**縮小か一時停止。終了しない**。登録先は休止にして戻る道を残す。本業の制度と支援は副業より先に使う

## よくある質問

### 介護があることを、依頼側に伝えたくありません。隠して受けてもよいですか

介護であることは、伝えなくて構いません。ただし、「突発で止まる日があること」「止まったときの連絡の型」「再開の形」は伝えます。依頼側に必要なのは理由ではなく、止まる日があるという前提と、そのときの動き方です。「家庭の事情で、月に何日か当日に稼働できない日があります。その日は朝に連絡し、翌稼働日に再開します」で足ります。この三つを伝えずに受けると、止まった日に「聞いていない」となり、隠していたことが問題になります。伝え方は[無理なときの伝え方](/media/fukugyo-warukunai-kotowari/)に整理しています。

### 介護で本業を短時間勤務にしました。減った収入を副業で補えますか

補える部分はありますが、「補う」を目的にすると、枠が大きくなり、介護と本業と副業の全部が崩れます。まず、本業の介護の制度と、地域の支援で、介護の負担そのものを減らせないかを確認し、内容は会社と専門家にご確認ください。そのうえで、残った時間の半分程度を副業の枠にし、小さく始めます。減った収入を全部補うのではなく、一部を補う形で、続くことを優先します。収入の見立ては[年間の副業収入の見立て](/media/fukugyo-nenkan-shuunyuu/)に書いています。

### 介護が終わった後、副業を本格的に再開したいのですが、ブランクが心配です

介護中に小さい枠でも続けていれば、ブランクにはなりません。一時停止していた場合も、登録先の登録を休止にし、以前の依頼側との連絡の経路を残していれば、再開の相談から始められます。再開時は、枠を小さめに置き、続けられることを確かめてから広げます。介護中に得た、時間の使い方や優先順位の付け方は、副業の稼働管理にそのまま使えます。再開の進め方は[副業をやめるとき](/media/fukugyo-yameru/)の再開の項に、声がかかる状態の作り方は[声をかけてもらえる状態を作る](/media/fukugyo-koe-kake/)に整理しています。
