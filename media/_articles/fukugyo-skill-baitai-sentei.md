「どの媒体を使えばいいですか」は、副業の担当者が最も聞かれる質問の一つです。「前の会社で〇〇を使っていて良かったです」と答えると、その場は通りますが、根拠は「自分の経験」だけで、依頼側の状況とは関係がありません。媒体の提案は、媒体に詳しいことではなく、「この会社のこの求人には、なぜこの媒体か」を、依頼側が自分で判断できる形で示すことです。結論を先に書くと、**媒体の提案の根拠は、ターゲット像の「情報の取り方」・媒体の型と役割・依頼側の運用体制の三本柱で組み、料金や上限は断定せず「確認してから」に置き、主と従・期限・見る数字・やめる条件を一枚にして、依頼側に決めてもらいます。**会社側から見た組み合わせ方は[媒体の組み合わせ方](/media/scout-baitai-kumiawase/)に、切り替えの判断は[媒体を切り替える判断](/media/scout-baitai-kirikae/)に書いています。ここでは、副業の担当者が根拠を作る型に絞ります。

## 根拠が「使ったことがある」で止まる問題

| 根拠の出し方 | 依頼側に起きること |
|---|---|
| 「前職で〇〇を使っていて良かった」 | 前職と業種も規模も違う。再現しない |
| 「〇〇が有名だから」 | 有名な媒体は競合も多く、依頼側の求人が埋もれる |
| 「〇〇は安いから」 | 料金は変わる。安くても合う人がいなければ費用は無駄になる |
| 「〇〇の営業担当が勧めてきた」 | 媒体の営業の根拠は、媒体を売ることにある |

依頼側が聞きたいのは、「なぜうちに、この媒体か」です。答えるには、依頼側のターゲット像と、媒体の型と、依頼側が回せるかの三つが要ります。

## 根拠の三本柱

| 柱 | 何を見るか | 材料 |
|---|---|---|
| ターゲット像の「情報の取り方」 | その人は、求人をどこで見るか。自分で探すか、声をかけられて動くか、知人経由か | ターゲット像の一枚。[ターゲット像を1枚にまとめる](/media/fukugyo-skill-persona/) |
| 媒体の型と役割 | 自分で探す人に届く型か、声をかける型か、紹介か | 下の表 |
| 依頼側の運用体制 | 誰が、週に何時間、媒体を触れるか。スカウト文を書けるか、返信に翌日中に対応できるか | 依頼側への聞き取り |

三本のうち、依頼側が一番見落とすのは三本目です。声をかける型の媒体は、送る人と返信する人がいなければ動きません。体制が無いのに契約すると、費用だけが出ます。

### エラベルの見解

担当する側から見ると、媒体の提案で最も差がつくのは、三本目の「運用体制」を先に確かめるかどうかです。スカウト型の媒体は、ターゲット像が「声をかけられて動く人」なら合いますが、送る人と返信する人が社内にいなければ、契約した月から動きません。「この媒体は、週にこれだけの時間、誰が触りますか」を最初に聞くと、依頼側は「そこまで考えていなかった」となり、媒体の選択より先に体制の話になります。エラベルで担当者を選ぶ企業には、「媒体を決める前に、誰が運用するかを決めていますか」を、私たちから先に聞いています。受ける側がその場で使える判断としては、提案の一枚に「この媒体に要る運用の時間と役割」の欄を作り、依頼側に埋めてもらうこと。埋まらない媒体は、体制が無いので提案から外します。

## 媒体を型で分ける

個別の媒体名ではなく、型で分けて考えます。媒体の仕様は変わりますが、型は変わりにくいからです。

| 型 | 届く人 | 要る体制 | 向く状況 |
|---|---|---|---|
| 求人広告（掲載型） | 自分で探している人 | 原稿を書く人。応募への対応 | 職種の言葉で探す人が多い職種。原稿で差が出せるとき |
| スカウト型（データベース） | 声をかけられて動く人。探していない人も含む | 検索・文章・返信を回す人。継続的な時間 | 探している人が少ない職種。要件が具体で検索できるとき |
| 紹介（エージェント） | 紹介会社に登録している人 | 紹介会社への要件の伝達と、選考の速さ | 社内の体制が薄い。急ぐ。要件が明確 |
| リファラル（社員紹介） | 社員のつながりの中の人 | 社員への説明と、紹介しやすい仕組み | いまうまくやっている人が多い。組織の型が明確 |
| 自社（採用ページ・SNS） | 会社を知っている人 | 発信を続ける人 | 認知がある。中長期で母集団を作る |

ターゲット像の「情報の取り方」が「自分で探す」なら掲載型、「声をかけられて動く」ならスカウト型か紹介、「知人経由」ならリファラルが主の候補です。一つの型に決め打ちせず、主と従の二つで組みます。

## 料金や上限を断定しない

媒体の料金、掲載期間、送信の上限、機能は変わります。副業の担当者が「〇〇は月〇〇円で〇〇通送れます」と書いた提案は、契約の段階で違っていると、担当者の信頼が落ちます。

| 断定する書き方 | 置き換え |
|---|---|
| 「月額〇〇円」 | 「料金は掲載期間と枠で変わるため、媒体に見積もりを取ってから比べる」 |
| 「月〇〇通送れる」 | 「送信の上限はプランで決まるため、契約前に確認し、運用の時間と合わせる」 |
| 「〇〇の機能がある」 | 「〇〇の機能の有無と条件は、媒体の担当者に確認する」 |

比べるときは、「料金」ではなく「同じ稼働時間で何ができるか」「同じ期間で何を見るか」をそろえます。費用の見方は[媒体費と代行費を分けて見るべき理由](/media/rpo-baitai-hi-betsu/)に書いています。費用の判断は依頼側で、副業の担当者は比べる軸をそろえるところまでです。

## 提案の一枚

| 項目 | 書くこと |
|---|---|
| ターゲット像の情報の取り方 | 「自分で探す」「声をかけられて動く」「知人経由」のどれか。根拠（ターゲット像の一枚） |
| 主の媒体（型） | 型と、その型を選ぶ理由。個別の媒体は候補を二つまで |
| 従の媒体（型） | 主で届かない層を補う型 |
| 要る運用の時間と役割 | 週の時間、誰が何をするか。依頼側に埋めてもらう |
| 確認してから決めること | 料金・上限・機能。誰がいつ確認するか |
| 期限と見る数字 | いつまで試すか。閲覧数・応募数・返信率・面接に進んだ数のどれを見るか |
| やめる条件 | 期限までにどの数字がどうなら、従に切り替えるか |

「やめる条件」を最初に書くのは、媒体を続けるかどうかの判断を、感覚ではなく最初に決めた基準でできるようにするためです。切り替えの判断は[媒体を切り替える判断](/media/scout-baitai-kirikae/)に、数字の見方は[成果の数字の扱い](/media/fukugyo-suuji/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「媒体の提案は、最も良い一つを当てること」というものです。実際には、どの媒体が合うかは試すまで分からず、当てることより「試す形と、やめる条件」を先に決めることが仕事です。主と従を決め、期限と見る数字を書き、期限が来たら数字で判断する。当たらなくても、次の判断ができる形になっていれば、提案としては成立しています。受ける側がその場で使える判断としては、提案の一枚に「この提案が外れていたら、何で分かるか」を一行書くこと。それが書けない提案は、根拠が経験だけで、依頼側が判断できません。

## 依頼側に決めてもらう形

媒体の契約は費用が出ることなので、決めるのは依頼側です。副業の担当者は、比べる軸をそろえ、候補を絞り、判断の材料を一枚にするところまでです。

| 担当者がやること | 依頼側が決めること |
|---|---|
| 型を絞り、候補を二つまで出す | どの媒体と契約するか |
| 要る運用の時間と役割を示す | 誰が運用するか |
| 確認する項目（料金・上限・機能）を並べる | 費用の判断 |
| 期限・見る数字・やめる条件の案を出す | 期限と条件の確定 |

契約の手続きや、媒体との交渉を副業の担当者が代わりに行うかは、契約の範囲で決めます。範囲の決め方は[業務範囲を書面で固める](/media/fukugyo-scope/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 依頼側が「有名な媒体」を決め打ちしている | ターゲット像の情報の取り方と、運用体制の二つで照らす。合っていれば主に、合わなければ従か外す |
| 媒体の営業から提案が来ている | 営業の提案を、同じ一枚の項目に落として並べる。軸をそろえれば比べられる |
| 料金を依頼側がすぐ知りたがる | 「見積もりを取ってから比べる」を提案に入れる。担当者が数字を言わない |
| 運用の体制が無い | 体制が要らない型（紹介）を主にするか、運用を担当者の稼働に含めるかを、依頼側に決めてもらう |
| 期限が来ても判断しない | 提案の一枚の「やめる条件」に戻る。数字を並べ、判断を依頼側に求める |

## まとめ

- 根拠は**「使ったことがある」ではなく、ターゲット像の情報の取り方・媒体の型・運用体制**の三本柱
- 媒体は**型で分ける**（掲載型・スカウト型・紹介・リファラル・自社）。仕様は変わるが型は変わりにくい
- **運用体制**を先に確かめる。埋まらない媒体は外す
- **料金・上限・機能は断定しない**。「確認してから」に置き、比べる軸をそろえる
- 提案は**主と従・要る体制・確認事項・期限・見る数字・やめる条件**の一枚
- 「外れていたら何で分かるか」を書く。**当てることより、試す形とやめる条件**
- **決めるのは依頼側**。担当者は軸をそろえ、候補を絞り、材料を一枚にするまで

## よくある質問

### 使ったことのない媒体を提案してよいですか

型で根拠を組んでいれば、個別の媒体を使ったことがなくても提案できます。「この型が合う理由」を三本柱で示し、個別の媒体は「候補を二つ。料金・上限・機能は確認してから」と置きます。使ったことがないことは隠さず、「運用の細部は媒体の担当者に確認します」と伝えます。使ったことがあるかより、依頼側の状況に合う型を示せているかが根拠です。

### 依頼側から「一つに絞ってほしい」と言われました

主を一つに絞り、従は「主が期限までに見る数字に届かなかったときの候補」として添えます。一つだけ出すと、外れたときに次が無く、判断が止まります。「契約するのは主の一つで、従は契約せず候補として置いておく」と伝えれば、費用は一つ分で、判断の道筋は残ります。

### 媒体の担当者から、副業の担当者宛てに営業の連絡が来るようになりました

依頼側の窓口を通す形にします。副業の担当者が媒体と直接やり取りを深めると、依頼側から見て「誰が決めているのか」が曖昧になり、契約や費用の判断が担当者に寄ってしまいます。媒体との連絡は依頼側の担当者に集め、副業の担当者は「比べる軸をそろえる」役割に留めます。連絡の窓口の整理は[アカウント管理のしかた](/media/fukugyo-account-kanri/)に書いています。
