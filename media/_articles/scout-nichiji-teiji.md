スカウトに返信が来た。「話を聞いてみたい」。ここから、面談の日程を決めるまでに、三往復、四往復かかる。「ご都合をお聞かせください」と送ると、返事が来ない。来ても「来週なら」と曖昧で、また聞き返す。決まるまでに一週間かかり、その間に候補者の熱が冷め、他社が先に会う。結論を先に書くと、**日程の提示は、「ご都合はいかがですか」と聞くのではなく、「候補を複数、近い日から、幅を持たせて」出し、候補者が選ぶだけにします。候補者に考えさせる往復を無くせば、一往復で決まります。候補を出すには、面接官や面談の担当者の枠を先に押さえておくことが前提です**。面談への誘い方は[カジュアル面談への誘い方](/media/scout-casual-mendan-sasoi/)に、予約リンクの是非は[予約リンクを貼るべきか](/media/scout-yoyaku-link/)にまとめています。

## 日程で往復が増える構造

日程の調整で往復が増えるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「ご都合をお聞かせください」と聞いている | 候補者に、自分の予定を確認して書く負担を負わせる。負担が返事を遅らせる |
| 候補を出していない | 会社側が候補を出さないので、候補者が出し、会社が確認し、また往復 |
| 候補が一つ | 「〇日の〇時はいかがですか」の一つだけ。合わなければ、また往復 |
| 候補が遠い | 「再来週」の候補。候補者の熱が冷める |
| 面接官の枠を押さえていない | 候補者の返事を受けてから、面接官に聞く。面接官の返事を待ち、また候補者に |
| 時間帯が会社の都合だけ | 平日の日中だけ。現職の候補者は出られない |
| 形式が決まっていない | 対面かオンラインかを、候補者に聞く。往復が増える |
| 決まった後の確認が無い | 決まっても、前日の確認が無く、当日に来ない |

構造の大半は、「候補者に考えさせている」ことと「枠を先に押さえていない」ことです。

## 一往復で決める提示の型

日程を、一往復で決める提示の型です。

| 要素 | 内容 |
|---|---|
| 候補の数 | 三〜五つ。多すぎると選べず、少ないと合わない |
| 候補の近さ | 最初の候補を、返信の翌日から三日以内に。遠くても一週間以内 |
| 候補の幅 | 時間帯を分ける。平日の日中、平日の夕方以降、（可能なら）土日 |
| 形式 | オンラインを既定に。「オンラインで三十分。対面をご希望なら、その旨を」 |
| 所要時間 | 「三十分」を明記 |
| 選び方 | 「この中でご都合の合うものを、番号でお知らせください」。候補者は番号を返すだけ |
| 合わない場合 | 「いずれも合わない場合は、ご都合の良い曜日と時間帯をお知らせください」。合わないときの逃げ道 |
| 担当者 | 「〇〇（役割の責任者）が対応します」 |
| 送る速さ | 返信を受けたその日に |

提示の例の形です。

「ご返信ありがとうございます。三十分、オンラインでお話しする日程の候補です。ご都合の合うものを、番号でお知らせください。一、〇日（火）十九時。二、〇日（水）十二時。三、〇日（木）二十時。四、〇日（土）十時。いずれも合わない場合は、ご都合の良い曜日と時間帯を教えてください。〇〇（役割の責任者）が対応します」

型の要点は、「候補者は番号を返すだけ」にすることです。考える負担が無ければ、返事は早く来ます。

## 候補の出し方

候補を出すときの考え方です。

**近い日から出す。** 返信の翌日から三日以内に最初の候補。候補者の「話を聞いてみたい」は、時間とともに冷めます。一週間先の候補は、冷めた後です。

**時間帯を分ける。** 現職の候補者は、平日の日中に出にくい。夕方以降（十八時以降）、昼休み（十二時台）、土日、のどれかを候補に入れる。会社の都合の時間帯だけにしない。

**曜日を分ける。** 同じ曜日に固めない。月・水・金のように。

**三〜五つに絞る。** 十個並べると、候補者は選べない。三〜五つで、時間帯と曜日が分かれていれば、合う確率は高い。

**面談の担当者の枠から出す。** 担当者が先に押さえた枠（次の章）の中から。候補を出してから担当者に聞く形は、往復が増える。

**候補者の返信の内容に合わせる。** 返信に「平日は難しい」「夜なら」とあれば、その条件で候補を出す。読まずに定型の候補を出すと、往復が増える。

**急ぎの候補者には、当日か翌日の候補も。** 「今週中に話したい」と返信があれば、当日か翌日を入れる。

**オンラインを既定に。** 移動の時間が無く、候補者も担当者も枠を取りやすい。対面は希望があれば。

出し方の要点は、「候補者の側に立って、合いやすい候補を出す」ことです。会社の都合の候補を出しても、合いません。

## 候補者の都合に合わせる幅

候補者の都合に合わせる、幅の持たせ方です。

| 候補者の状況 | 合わせ方 |
|---|---|
| 現職で平日の日中に出にくい | 夕方以降、昼休み、土日の候補を入れる。「就業後でも構いません」と添える |
| 子育てや介護で時間が限られる | 「ご都合の良い時間帯を教えてください」を、候補と一緒に。短い時間（二十分）の選択肢も |
| 地方や海外にいる | オンラインを既定に。時差があれば、候補者の時間帯で候補を出す |
| 急ぎで決めたい | 当日か翌日の候補。「今日の〇時でも可能です」 |
| 忙しくて返信が遅い | 候補の期限を長めに。「来週まで有効です」。再送は一度だけ |
| 対面を希望 | 場所と行き方を明記。「〇〇駅から徒歩〇分。オンラインも可能です」 |
| 複数社と同時に動いている | 速さ。「明日でも可能です」。他社より先に会う |

幅の要点は、「会社の都合の枠に候補者を合わせる」のではなく、「候補者の都合に、会社が枠を出す」ことです。幅が無い提示は、「合わない」で往復が増えるか、候補者が離れます。

### エラベルの見解

相談で最も多い失敗は、「返信が来たら『ご都合の良い日時をいくつかお知らせください』と送り、返事が来ず、来ても『来週なら』で、また聞き返し、決まるまで一週間かかって、その間に他社に決まっていた」というものです。候補者に考えさせていました。返信の当日に、三日以内から始まる候補を四つ、時間帯を分けて番号で出し、「番号でお知らせください」に変えたら、大半が一往復で決まり、返信から面談までが三日以内になりました。候補者は、番号を返すだけでした。

見ていて差がつくのは、担当者が「返信の当日に、候補を出す」かどうかです。「ご都合を伺います」と聞く担当者と、「当日に、担当者の枠から、近い日の候補を四つ、時間帯を分けて番号で出します」と、出す担当者がいます。後者は、一往復で決めます。

発注側にできるのは、面談の担当者の枠を先に押さえて、担当者に渡すことです。枠が無ければ、候補は出せません。

## 面接官の枠の先押さえ

候補を出すには、面談や面接の担当者の枠を、先に押さえておきます。

**週に数枠を、固定で押さえる。** 「火曜の十九時、水曜の十二時、木曜の二十時、土曜の十時」のように、面談の担当者の予定に、週ごとに固定で入れる。候補者が来なければ、空けばよい。

**時間帯を分けて押さえる。** 日中だけでなく、夕方以降と昼休みと（可能なら）土日。候補者の都合に合う枠を持つ。

**複数の担当者で分担する。** 一人の担当者が全部の枠を持つと、負担が重い。役割の責任者、一緒に働く人、経営者で分ける。

**枠を、共有の予定表で管理する。** 誰が、いつ、どの枠を持っているかを、担当者（人事か代行）が見られる状態に。候補を出すときに、担当者に聞かずに出せる。

**枠が埋まったら、翌週の枠を出す。** 「今週は埋まっているので来週」ではなく、翌週の枠も先に押さえておく。

**繁忙期は、枠を減らしても、ゼロにしない。** 週に一枠でも。[繁忙期に採用が止まる](/media/rpo-tsuuki-hendou/)。

**枠の先押さえを、責任者から面談の担当者に頼む。** 担当者（人事や代行）が頼んでも、「忙しい」で終わる。責任者から。

先押さえの要点は、「候補者が来る前に、枠がある」ことです。来てから押さえる形は、往復が増え、遅れます。

## 日程が合わないときの対応

出した候補が合わないときの対応です。

**候補者から「いずれも合わない」と来たら、候補者の希望の曜日と時間帯を聞く。** 提示の型に「合わない場合はご都合の良い曜日と時間帯を」を入れておけば、返信で来る。

**希望に合わせて、枠を作る。** 固定の枠に無くても、担当者に「この日時は可能か」を確認し、当日に返す。候補者を待たせない。

**担当者を変える選択肢。** 役割の責任者の枠が合わなければ、一緒に働く人の枠で。「〇〇の代わりに、△△が対応します」と伝えて。

**短い時間の選択肢。** 三十分が取れないなら、「十五分でも」。まず接点を持つ。

**候補者の返信が無い場合。** 一週間後に、一度だけ「先日の日程の候補、まだ有効です。ご都合が合えば」。追わない。

**決まった後に、候補者から変更の連絡が来たら。** 当日に、新しい候補を出す。「変更はお気になさらず」と添える。

**決まった後に、会社側の都合で変更が要る場合。** 早く、詫びて、新しい候補を複数。会社側の変更は、候補者の信用に響く。担当者の枠を先に押さえていれば、起きにくい。

合わないときの要点は、「候補者に合わせて、会社が動く」ことです。「うちはこの枠しか無い」は、候補者を離します。

## 日程の記録と見直し

日程の提示を、記録して見直します。

| 項目 | 記録 |
|---|---|
| 返信から候補の提示までの日数 | 当日か、翌日か、それ以降か。当日を目標に |
| 候補の提示から決定までの往復の数 | 一往復か、二往復か、それ以上か。一往復を目標に |
| 返信から面談までの日数 | 三日以内か、一週間以内か、それ以上か |
| 決まらなかった数と理由 | 「候補が合わなかった」「返信が来なかった」「候補者が辞退した」 |
| 選ばれた時間帯の傾向 | 夕方以降が多いか、昼休みか、土日か。次の候補の出し方に反映 |
| 面談の当日の欠席 | 前日の確認をしていたか。欠席の理由 |
| 担当者ごとの枠の使われ方 | どの担当者の枠が使われ、どの枠が空くか。枠の見直し |
| 月に一度の見直し | 上の記録を見て、候補の出し方、枠の時間帯、担当者の分担を直す |

記録の要点は、「返信から面談までの日数」と「往復の数」です。この二つが減れば、候補者が離れる前に会えます。

## 外注する場合の範囲

日程の提示を、スカウト代行に出す場合の範囲です。

**出せる工程。** 提示の型の作成、返信への当日の候補の提示、面談の担当者の枠の共有の予定表の管理、候補者の返信に合わせた候補の調整、合わないときの担当者への確認と再提示、決定の連絡と前日の確認、変更への対応、候補者への一週間後の一度の連絡、記録（返信から提示、往復、返信から面談、決まらなかった理由、時間帯の傾向）と月次の見直し、枠の先押さえの責任者への依頼の整理。

**社内に残す判断。** 面談の担当者の指名と枠の確保（責任者から）、対面かオンラインかの方針、枠の時間帯の決定（夕方以降や土日を出すか）、担当者の分担。

**外注の効きどころ。** 日程の提示は、「返信の当日に候補を出す」速さと、「候補者に合わせて会社が動く」手間が要り、社内では「ご都合を伺います」で往復が増えやすい工程です。担当者が枠の予定表を見て当日に候補を出し、往復を一回で終わらせ、前日の確認まで回せば、返信から面談までの日数は短くなります。担当者は複数の会社の日程調整を見ているので、「この層はこの時間帯が合う」の型を持ち込めます。ただし、枠を出すのは社内の人です。

**外注しても動かない場合。** 面談の担当者が枠を先に押さえない、平日の日中しか枠を出さない、対面しか認めない。社内の判断で、代行を替えても直りません。

日程は、候補を複数・近い日から・幅を持たせて出せば、一往復で決まります。外注は、当日に出し、往復を減らす手段です。

### エラベルの見解

担当する側から見ると、日程の相談で最も多いのは、「平日の日中しか枠が無い」ことです。現職の候補者は、平日の日中に出られません。「合わない」で往復が増えるか、「日中は無理」で離れます。夕方以降の枠を、週に二つ入れる。それだけで、決まる率が変わります。

夕方以降の枠は、面談の担当者の負担です。責任者が「面談は採用の一部」として、担当者の時間を認める必要があります。「日中しか無理」は、候補者の側から見れば、「現職の人は来なくてよい」と言っているのと同じです。

発注側にできるのは、面談の担当者に、週に一〜二枠の夕方以降を、責任者から頼むことです。

## よくある質問

### 候補を出しても、「どれも合わない」と返ってきます

候補の時間帯が、会社の都合（平日の日中）に偏っていないかを確認します。現職の候補者は、平日の日中に出られません。夕方以降、昼休み、土日の候補を入れます。「合わない」と来たら、候補者の希望の曜日と時間帯を聞き、担当者に確認して、当日に新しい候補を出します。担当者の枠が合わなければ、別の担当者（一緒に働く人など）の枠で。「うちはこの枠しか無い」で往復するより、候補者に合わせて会社が動きます。

### 面談の担当者が「枠を先に押さえるのは無理」と言います

週に一〜二枠、三十分ずつ、固定で入れるだけです。候補者が来なければ、空きます。「候補者が来てから調整」だと、担当者の予定を毎回聞くことになり、担当者の負担はむしろ増えます。責任者から「面談は採用の一部で、週に一〜二枠は先に押さえる」と伝えてもらいます。一人の担当者に集中させず、役割の責任者、一緒に働く人、経営者で枠を分担すれば、一人あたりの負担は週に三十分〜一時間です。

### 日程が決まった後、当日に来ない候補者がいます

前日に、確認の連絡を送ります。「明日〇時、オンラインで、〇〇（担当者）がお待ちしています。接続はこちら」。接続の方法が分からない、日時を忘れた、が欠席の多くの理由です。前日の確認で減ります。それでも来ない場合、当日に「ご都合が変わりましたか。改めて候補をお送りします」と一度だけ送り、追わない。欠席の理由を記録し、前日の確認をしていたかを見直します。
