新卒採用の設計を副業で初めて受けるとき、見えにくいのは「一年の中で、いつ何が集中し、自分の稼働がどう動くか」と「内定のあとに何をすれば入社まで繋がるか」です。募集文には「新卒採用の企画運営」とだけあり、実際には、年間の計画、母集団作り、説明の場、選考の運用、内定期間の接点、入社後の接続と、一年にわたって工程が並び、しかも時期で稼働が大きく違います。順番と時期を知っていれば、契約前に決めておけます。結論を先に書くと、**1案件は「契約前→年間の設計→母集団作りと説明の場→選考の運用→内定から入社までの繋ぎ→入社後の接続と振り返り」の六つの段階で進み、契約前に範囲と人数と職種と理由と繁忙期の稼働と社員の時間と費用と連絡の名義と学生の情報の扱いと公的な指針の確認の担当と評価を決め、入社の日から逆算した年間の計画を作って確認が要る点に印を付け、経路ごとの動きと社員が語る説明の場を設計して進行し、段階ごとの型で複数の候補者を同時に動かして辞退の兆しを記録し（合否は会社）、内定期間に月に一度の接点と社員との接点と内定者同士の場と不安を聞く型を回し、入社後の三か月に引き渡して経路と段階と時期ごとの記録から次の年の計画を直します。**案件の型と新卒に固有の線は[新卒採用の設計の副業案件](/media/fukugyo-shinsotsu-sekkei-fukugyo/)に書いていますので、ここでは「1案件の流れ」に絞ります。

## 契約前：決めておくこと

新卒採用は、一年にわたり、時期で稼働が大きく違います。契約前に、稼働の幅と役割の線を決めます。

| 決めること | 確かめる中身 | 決めていないと起きること |
|---|---|---|
| 範囲 | 年間の設計だけか、説明の場と選考の運用までか、内定から入社までの繋ぎまでか、型作りか | 繁忙期に「これも」が足される |
| 人数と職種と理由 | 何人を、どの職種で、なぜ新卒で。入社の一年後に何をしているか。会社が決める | 「若い人が欲しい」で設計が始まる |
| 繁忙期の稼働 | 説明の場と選考の時期に、平日の日中に週にどれだけ動けるか。月ごとの稼働の幅 | 繁忙期に本業に響く |
| 社員の時間と費用 | 説明の場で語る社員、面接官、内定期間の接点に出る社員の時間。媒体や会場の費用の枠 | 社員が出ず、自分が語る形になる |
| 連絡の名義 | 学生への連絡は会社の名義か、外部の担当として名乗るか。文面の承認者 | 私的な連絡先を使う |
| 学生の情報の扱い | 学校名、成績、家族、選考の記録は会社の管理する場所で。学校と家族への連絡は会社 | 情報が自分の端末に残る |
| 公的な指針の確認は会社 | 採用活動の時期、内定の扱い、学校との関係の指針と慣行は、会社が確認。自分は「確認が要る点」の印まで | 自分の記憶で時期を決める。個別の判断は専門家にご確認ください |
| 評価 | 経路ごとの母集団、段階ごとの辞退、内定期間の辞退、入社の数。説明会の参加者の数ではない | 参加者の数で評価される |

止まりやすいのは、「来月の説明会から手伝って」で始めるときです。年間の計画と内定期間の接点が無いまま説明会だけを手伝うと、内定のあとで辞退されます。範囲の決め方は[業務範囲の決め方](/media/fukugyo-scope/)に、見積もりの出し方は[見積もりの出し方](/media/fukugyo-mitsumori/)に書いています。

## 年間の設計：入社の日から逆算、時期と経路と場と選考と繋ぎ、確認が要る点

計画は、入社の日から逆算して作ります。説明会の日程からは作りません。

| 作るもの | 中身 | 落とし穴 |
|---|---|---|
| 入社の日から逆算した時期 | 入社→内定期間（接点の月）→内定→選考の段階→説明の場→母集団作り、の順に時期を置く | 説明会の日程から作る |
| 母集団の経路 | 学校（求人の届け出は会社）、媒体、紹介、社員のつながり、既存のイベント。経路ごとに「誰が動くか」 | 媒体だけ |
| 説明の場 | 回数、規模、社員が語る中身、参加者が持ち帰るもの | 会社の紹介の場 |
| 選考の段階 | 段階ごとに何を見るか、型、連絡の速さ、日程の枠 | 段階が多く、期間が長い |
| 内定期間の接点 | 月ごとの接点（連絡、社員との接点、内定者同士の場、入社前の準備）。学業を妨げない時期と頻度 | 内定のあとが空欄 |
| 資源の一覧 | 社員の時間（語る、面接、接点）、費用の枠、自分の稼働の月ごとの幅 | 資源を見ずに計画する |
| 確認が要る点の印 | 採用活動の時期、内定の扱い、学校との関係など、公的な指針と慣行の確認が要る箇所。会社が確認してから確定 | 自分の記憶で時期を書く |

止まりやすいのは、内定期間の接点を「内定を出してから考える」にすることです。接点に出る社員の時間は、計画の段階で押さえます。定着の型は[新卒が定着しない](/media/rpo-shinsotsu-teichaku/)に書いています。

### エラベルの見解

担当する側から見ると、この仕事は「年間の計画で、内定期間の接点に出る社員の時間を先に押さえられるか」で、入社の数が決まります。説明の場と面接には社員の時間を取る会社でも、内定のあとの数か月は「人事が連絡しておけば」になりがちで、学生は「入ったらどんな人と働くのか」が分からないまま、他社の内定者の集まりに出て、そちらに決めます。計画の段階で「内定期間に社員と接する場を月に一度」と入れ、社員の時間を押さえた会社では、辞退が減ります。エラベルで担当者を選ぶ企業には、「年間の計画の中で、内定のあとの数か月に社員の方の時間を先に押さえます。そこが空くと、入社の日に来ません」と、私たちから先に伝えています。受ける側がその場で使える判断としては、年間の計画の表で、内定の月から入社の月までの行に「社員の名前」が入っているかを確かめること。空欄の行が、辞退が起きる月です。

## 母集団作りと説明の場：経路ごとの動き、社員が語る場、参加者ごとの記録

| やること | 依頼側に持ってもらうこと | 落とし穴 |
|---|---|---|
| 経路ごとの動き（学校への届け出は会社、媒体の掲載、社員のつながりへの声かけ、既存のイベントへの参加。誰が動くかの表） | 会社が動く経路の実行 | 媒体に出して待つ |
| 説明の場の設計（入社の一年後の姿、社員の場面、参加者が持ち帰るもの、質問の時間、選考でないことの明示） | 語る社員の時間。社員が語る中身の聞き出し | 会社の紹介と事業の説明が中心 |
| 説明の場の進行（受付、最初の五分、社員が語る、質問、次の案内。自分は進行と記録） | 社員が語る | 自分が会社の話をする |
| 参加者ごとの記録（関心、質問、次の段階への意思。学生の情報は会社の管理する場所で） | 記録の置き場 | 自分の端末に置く |
| 翌日の連絡（会社の名義で、次の段階の案内。選考の合否に触れない） | 文面の承認 | 連絡が遅れる |

止まりやすいのは、説明の場で自分が会社の話をすることです。学生が聞きたいのは社員の言葉で、外の人の説明は届きません。イベントの設計は[採用イベントの企画・運営の副業案件](/media/fukugyo-meetup-unei-fukugyo/)と共通です。

## 選考の運用：段階ごとの型、複数の候補者を同時に動かす、辞退の兆し、合否は会社

新卒の選考は、複数の候補者が同時に、複数の段階を進みます。途切れが辞退になります。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 段階ごとの型（書類で何を見るか、面接の型、課題の有無。面接の型は面接代行の型と共通） | 選考の前に | 段階ごとに見ることが決まっていない |
| 連絡（結果と次の案内を、決めた日数以内に。会社の名義で。学業の予定を聞いて日程を出す） | 段階ごとに当日か翌日 | 結果の連絡が遅れる。試験の時期に面接を入れる |
| 日程（面接官の枠を先に押さえ、候補日を複数出す） | 段階ごと | 枠が無く待たせる |
| 記録（候補者ごとに段階、日程、結果、辞退の兆し（返事が遅い、質問が減った）。会社の管理する場所で） | 動くたび | 記録が無く、誰がどこにいるか分からない |
| 辞退の兆しの共有（事実で会社に。対応は会社） | 出たとき | 自分が引き留める |
| 合否の整理（面接官の記録を整理して会社に。決めるのは会社） | 段階ごと | 自分が決める |

止まりやすいのは、結果の連絡が遅れることです。学生は複数の会社を同時に受けていて、連絡の遅い会社から辞退します。運用の型は[新卒採用の運用代行](/media/rpo-task-shinsotsu-unyou-daikou/)に、合否への関わり方は[合否にどこまで関わるか](/media/fukugyo-gouhi/)に書いています。

### エラベルの見解

同じ料金・同じ人数でも、結果が分かれるのは、「選考の途中の連絡を、決めた日数以内に出し続けられるか」です。説明の場を丁寧に作り、面接の型も整えた担当者でも、選考の途中で結果の連絡が一週間空くと、学生は「興味を持たれていない」と受け取り、次の段階に来ません。段階ごとに「結果は〇日以内に」と決め、面接官の記録を当日に整理して会社の判断を当日か翌日に取り、会社の名義で連絡を出し続けた担当者の選考は、途中の辞退が減ります。新卒は、内容より速さで辞退が起きる場面が多い。エラベルで長く続いている担当者は、記録の表に「結果の連絡までの日数」の欄を持ち、遅れた段階を会社に返しています。受ける側がその場で使える形としては、段階ごとの「結果の連絡の期限」を計画に書き、面接官と会社の判断の期限も一緒に決めておくことです。

## 内定から入社までの繋ぎ：月に一度の接点、社員との接点、内定者同士の場、不安を聞く型

内定のあとが、新卒採用の本体です。放置すると、入社の日に来ません。

| やること | 頻度の目安 | 落とし穴 |
|---|---|---|
| 条件の書面と来てほしい理由（会社が渡す。書面は会社の文書） | 内定の直後 | 口頭だけ |
| 月に一度の連絡（会社の名義で。会社の近況、入社に向けた準備、不安があれば聞く場の案内。学業を妨げない） | 月に一度 | 連絡が無い。頻度が高すぎて拘束に見える |
| 社員との接点（一緒に働く人と話す場。会社の人が出る） | 内定期間に数回 | 人事だけが連絡する |
| 内定者同士の場（同期になる人と会う場。参加は任意） | 内定期間に一〜二回 | 強制する |
| 不安を聞く型（条件、仕事の中身、雰囲気、家族の心配。会社の人が聞く。答えられないことは正直に） | 接点のたび | 不安を聞かずに、良い話だけ |
| 入社前の準備（必要なものの案内、初日の予定。労務の手続きは担当者と専門家） | 入社の前 | 準備の案内が遅い |
| 学業への配慮（試験や実習の時期を聞き、接点の時期をずらす。卒業に関わることを優先） | 接点の設計時 | 学業を妨げる接点 |
| 辞退の兆しの記録（返事が遅い、接点に来ない）。対応は会社。慰留に踏み込まない | 出たとき | 自分が説得する |

止まりやすいのは、接点の頻度を上げて「囲い込み」に見える形にすることです。接点は、来てほしい理由を伝え、不安を聞くためのもので、他社の選考を辞退させるためではありません。

## 入社後の接続と振り返り：三か月への引き渡し、記録、次の年の計画

| やること | 中身 |
|---|---|
| 入社後の三か月への引き渡し | オンボーディングの計画（初日、教える人、役割の書面、同期の場）に、内定期間の記録（関心、不安）を、本人の同意の範囲で渡す |
| 振り返りの記録 | 経路ごとの母集団の数、段階ごとの辞退の数と時期、内定期間の辞退の時期と理由（分かる範囲で）、入社の数、入社後の定着 |
| 次の年の計画を直す | 効いた経路、辞退が多かった段階と時期、接点の型を直す |
| 型と記録を残す | 年間の計画の型、説明の場の型、選考の型、繋ぎの型、記録の型。学生の情報は会社の管理する場所に |

引き継ぎの型は[引き継ぎの仕方](/media/fukugyo-hikitsugi/)に、入社後の型は[オンボーディング設計の副業案件](/media/fukugyo-onboarding-sekkei-fukugyo/)に書いています。

## 学生の情報の扱い

新卒採用では、学校名、学部、成績、家族の状況、選考の記録、内定期間の不安の中身に触れます。会社の管理する場所でだけ扱い、自分の端末に残さず、学校と家族への連絡は会社が行い、内定期間に聞いた不安（家族の反対、経済的な事情など）は、本人の同意の範囲でだけ会社に渡し、記録に詳しく書きません。家族に直接働きかける設計をせず、学生本人が家族に渡せる材料を会社が用意する形に留めます。辞退した学生の情報は、会社の方針に従って処理します。個別の判断は専門家にご確認ください。扱いの詳細は[候補者の個人情報の扱い](/media/fukugyo-kojin-jouhou/)に書いています。

## 稼働時間は何で決まるか

一年の稼働は、時期で大きく違います。年間の設計は最初に集中し、母集団作りと説明の場と選考は繁忙期に集中し（候補者の数に比例）、内定から入社までの繋ぎは月次で続き（内定者の数に比例）、入社後の接続と振り返りは最後に集中します。契約前に、月ごとの稼働の幅を表にして会社と合意し、繁忙期に本業に響かない範囲を決めます。数値は案件ごとに違うので、年間の設計が終わった時点で以後の月ごとの稼働を見直します。稼働の管理は[稼働時間の管理](/media/fukugyo-kadou-kanri/)に書いています。

## まとめ

- 1案件は**契約前→年間の設計→母集団作りと説明の場→選考の運用→内定から入社までの繋ぎ→入社後の接続と振り返り**の六つの段階
- 契約前に**範囲・人数と職種と理由・繁忙期の稼働・社員の時間と費用・連絡の名義・学生の情報の扱い・公的な指針の確認は会社・評価**を決める。「来月の説明会から」では始めない
- 年間の設計は**入社の日から逆算し、内定期間の接点に出る社員の時間を先に押さえ、確認が要る点に印を付けて会社が確認してから確定**
- 説明の場は**社員が語り、自分は進行と記録**。選考は**段階ごとの型で、結果の連絡の期限を決め、複数の候補者を途切れずに動かし、合否は会社**
- 内定期間は**月に一度の連絡・社員との接点・内定者同士の場・不安を聞く型・学業への配慮**。囲い込みにしない。慰留に踏み込まない
- 入社後は**三か月へ引き渡し、経路と段階と時期ごとの記録から次の年を直す**
- 学生の情報は**会社の管理する場所で、学校と家族への連絡は会社、不安の中身は同意の範囲で**

## よくある質問

### 説明会の参加者が少ないので、媒体を増やしたいと言われました

経路を「媒体」だけで考えず、学校、社員のつながり、既存のイベント、紹介、に広げます。会社が動く経路（学校への届け出、社員の声かけ）が空欄なら、媒体を増やしても届きません。「経路ごとに誰が動くかの表で、会社が動く欄を埋めましょう。媒体の追加は、費用の枠の中で会社が判断してください」と返します。参加者の数より、説明の場に来た人が次の段階に進む率を見ます。

### 内定者から「他社の選考も続けたい」と言われました

続けてよい旨を、会社の名義で伝えます。他社の選考の辞退を迫る形は設計しません。「来てほしい理由を改めて伝え、不安があれば聞く場を設ける」接点を続け、決めるのは本人に置きます。公的な指針や慣行に関わる点（内定の扱い）があれば、会社が確認します。個別の判断は専門家にご確認ください。他社と比べて決める学生に、比べる材料（条件の書面、一年後の姿、一緒に働く人）を会社が渡すことが、できる範囲です。

### 内定期間に、学生の家族が反対していると分かりました

家族に直接働きかける設計はしません。本人が家族に渡せる材料（条件の書面、会社の説明、一年後の姿）を会社が用意し、本人の希望があれば、会社の人が本人と一緒に説明する場を持つ形までに留めます。家族の反対の中身は、本人の同意の範囲でだけ会社に渡し、記録に詳しく書きません。決めるのは本人で、会社と自分は、本人が判断できる材料を整えるまでです。
