倉庫・物流スタッフの採用を代行に出すか迷う会社は、「派遣に頼ってきたが費用が重く、繁忙期に人が集まらない」「求人を出しても応募が来ず、来ても数日で辞める」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、業務と雇用の形と時間帯の整理・繁忙の波と人数の計画・環境と負担の実態の開示範囲・派遣から直接雇用へ移す方針・要件の決定・作業の姿勢の評価・合否の判断は社内に残す**のが線です。倉庫・物流スタッフは、業務と雇用の形で母集団が違い、繁忙の波で人数が変動し、母集団の中心が未経験と主婦層とシニアと外国人と学生にあります。「軽作業」の言葉を候補者が信じない中で、環境と負担の実態を正直に示し、派遣への依存から直接雇用の仕組みへ移すことが、代行に出す価値になります。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じ物流のドライバーの線は[ドライバー採用を代行に出す判断基準](/media/rpo-driver-rpo/)にまとめています。

## 倉庫・物流スタッフ採用が他の職種と違う点

一つ目は、業務の中身と雇用の形で母集団が違うことです。業務は、ピッキング、仕分け、検品、梱包、入出荷、フォークリフトの運転、在庫管理、現場リーダー。雇用の形は、正社員、パート、派遣、短期。フォークリフトを運転する正社員と、午前だけのパートのピッキングと、繁忙期だけの短期の仕分けでは、届く層も要件も違います。「倉庫スタッフ募集」だけでは、どの業務のどの雇用の形かが候補者に伝わりません。

二つ目は、繁忙の波で人数が変動し、短期の確保と定着の両立が要ることです。季節やセールで出荷が数倍になる倉庫では、繁忙期だけ人を増やし、閑散期は減らす。その波を派遣で埋めてきた会社が多く、費用が重く、繁忙期に人が集まらない。直接雇用のパートと短期を自社で確保し、定着した人を核にする仕組みが要ります。

三つ目は、候補者が「勤務地と通い方（駅から遠い、送迎バス、車通勤）」「時間帯とシフト（固定か変動か、週何日か）」「立ち仕事と重さ（何を何回持つか）」「倉庫の環境（冷蔵冷凍、夏の暑さ、空調）」「現場リーダーの人柄」「時給と昇給」を最初に確かめ、「軽作業」の言葉を信じないことです。倉庫の求人は「軽作業」で埋まっていて、実態は重い、寒い、暑い、立ちっぱなしだったことを、経験者は知っています。実態を隠した求人は、数日で辞める人を生みます。

四つ目は、母集団の中心が未経験と主婦層とシニアと外国人と学生にあり、派遣に依存しやすいことです。この層は、勤務地の近くに住んでいて、時間帯と曜日と身体的負担で仕事を選びます。「フルタイムの正社員」の求人では届かず、派遣会社に登録している層に自社の求人が届いていません。外国人の採用は、在留資格と制度が関わるので、専門家にご確認ください。

五つ目は、センター長や現場リーダーは出荷を回していて、採用の工程を回す人がいないことです。現場リーダーは日々の出荷と人の配置を回していて、面接の時間を取るのも難しい。本社の事務が回そうとしても、現場の実態を知らず、求人票が「軽作業」になります。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 業務と雇用の形と時間帯の整理 | 残す | どの業務を、正社員かパートか短期か、どの時間帯とシフトで任せるか。社内にしか分からない |
| 繁忙の波と人数の計画 | 残す | 繁忙期と閑散期の人数、短期で埋める分と定着させる分、派遣で残す分。センター長と経営者が決める |
| 環境と負担の実態の開示範囲の決定 | 残す | 重さと回数、冷蔵冷凍や暑さ、立ち仕事の時間を、どこまで正直に書くか。センター長が決める |
| 派遣から直接雇用へ移す方針の決定 | 残す | どの業務と時間帯を直接雇用に、派遣は何に残すか、費用の見え方。経営者が決める |
| 要件の決定 | 残す | 業務と雇用の形から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（業務と雇用の形と方針が決まっていれば） | 決まったものを候補者に伝わる言葉にする。「軽作業」ではなく実態で |
| 媒体の選定と運用 | 任せられる | 倉庫スタッフと地域の層に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 業務と雇用の形と勤務地に合わせた検索と、担当してきた作業に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 当日の連絡、日程、倉庫の見学の案内。未経験者には不安に答える連絡 |
| センター長・現場リーダーの面接の日程の確保 | 任せられる | 出荷の合間に面接の枠を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 業務・雇用の形・時間帯・勤務地・資格の分類は任せられる。作業の姿勢の評価は残す |
| 作業の姿勢の評価 | 残す | 現場リーダーが面接と見学と体験で見る |
| 環境と負担の実態の説明 | 残す（代行が同席可） | 実態を正直に話す。求人票と違うと数日で辞める |
| 合否の判断 | 残す | 会社の判断 |
| 条件の決定と提示 | 残す | 会社の判断。時給と昇給とシフトで条件の幅がある |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。初日に何をするかを伝える連絡 |

線の要点は、「業務と雇用の形と時間帯、繁忙の波と人数の計画、環境と負担の実態の開示範囲が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「自分の時間と体で続けられるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「倉庫の求人を『軽作業、未経験歓迎、シフト自由』で出しているが、応募が来ず、来ても数日で辞める。繁忙期は派遣に頼るしかなく、費用が重い」というご相談です。求人票を見ると、業務の中身も、時間帯とシフトの実態も、重さと回数も、冷蔵か常温かも、勤務地の通い方も、現場リーダーのことも無い。応募した人は、初日に「軽作業と書いてあったのに重い、寒い、立ちっぱなし」と分かって辞め、その評判が地域に広がっていました。

見ていて差がつくのは、「業務と雇用の形と環境の実態を一文で言えるか」です。「〇〇の倉庫で、日用品のピッキングと梱包。パートで週三日から、時間帯は朝の〇時から〇時か、昼の〇時から〇時の固定。持つ荷物は〇〇程度で、重いものは台車とリフト。常温で空調あり、夏は暑い時間帯に休憩を増やしている。駅から送迎バスで〇分、車通勤可。現場リーダーは〇〇の経験が長く、『初日は覚えなくていい、慣れるだけでいい』と言っている。繁忙期は〇月で、その時期は短期の募集を別に出す」。一文で実態が分かれば、候補者は自分の時間と体で判断でき、初日に辞める人が減ります。エラベルでは、倉庫の案件をお受けする前に、依頼側に「業務と雇用の形と時間帯」と「環境と負担の実態」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：業務と雇用の形と時間帯。** どの業務を、正社員かパートか短期か、どの時間帯とシフトで。週何日から、固定か変動か、土日の扱い。フォークリフトを運転する業務があるか。

**二つ目：繁忙の波と人数の計画。** 繁忙期と閑散期の出荷の差と時期、繁忙期に要る人数、短期で埋める分と定着させる分、派遣で残す分。繁忙期の募集をいつから始めるか。

**三つ目：環境と負担の実態。** 持つ荷物の重さと回数、台車とリフトの使用、冷蔵冷凍か常温か、夏の暑さと冬の寒さと空調、立ち仕事の時間と休憩、倉庫の広さと歩く距離。正直に把握し、「どこまで書くか」を決めます。

**四つ目：派遣から直接雇用へ移す方針。** どの業務と時間帯を直接雇用のパートで埋めるか、派遣は何に残すか、費用の見え方。派遣で働いている人を直接雇用に移す場合の扱いは、契約と法令に関わるので専門家に確認します。外国人の受け入れも、在留資格と制度に関わるので専門家に確認します。

**五つ目：センター長や現場リーダーが、面接にどのくらい時間を出せるか。** 出荷の合間に、面接の枠と倉庫の見学と体験の時間をどう確保するか。代行に日程の確保を出すなら、誰の予定を押さえるかを決めます。

五つのうち、一つ目と二つ目と三つ目が代行に出す前提です。四つ目と五つ目は、代行と一緒に整理できます。

## 現場リーダーの関与のさせ方

倉庫・物流スタッフの採用では、センター長や現場リーダーの関与が要ります。面接で作業の姿勢を見る、倉庫を見せる、環境と負担の実態を正直に話す、初日の受け入れを決める。しかし現場リーダーは出荷を回していて、「採用は本社の仕事」と考えていることが多い。

関与を取り付けるには、「採用が決まると現場リーダーがどう楽になるか」を具体的に示すことです。「定着した人が増えれば、繁忙期の派遣の教育に追われなくて済む」「初日に辞める人が減れば、教える時間が無駄にならない」。そして、負担を最小にする形で頼みます。面接の枠は代行が出荷の合間に押さえる、経歴は代行が整理して渡す、実態の説明の要点は代行が用意する。現場リーダーがやるのは、作業の姿勢を見ることと、倉庫を見せて実態を正直に話すことだけにします。関与の取り付け方は[現場が採用に協力してくれない](/media/rpo-genba-kyouryoku/)に書いています。

もう一つは、面接で現場リーダーが「初日に何をするか」を話すことの価値を、現場リーダー自身に理解してもらうことです。倉庫の候補者、とくに未経験者は、「初日についていけるか」を最も気にしています。現場リーダーが「初日は覚えなくていい、慣れるだけでいい。重いものは持たせない。分からなかったら聞いてくれれば、何度でも教える」と話すと、候補者は「続けられそう」と判断します。

## 代行を選ぶときの確認項目

倉庫・物流スタッフの採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に物流や倉庫の経験があるか。** 倉庫の作業そのものでなくても、物流会社の管理部門や、倉庫スタッフの採用を回した経験。業務の違い、雇用の形の違い、繁忙の波、環境と負担の見方を知っているか
- **環境と負担の実態を求人票にどう書くか、案を出せるか。** 「軽作業」で済まさず、重さと回数と環境と時間帯とシフトを書けるか
- **地域の層に届く媒体と経路の経験。** 地域の求人、主婦層とシニアと学生と外国人に届く経路、派遣に登録している層への届け方、短期と定着で分けた募集。経路ごとの経験
- **派遣から直接雇用へ移す設計。** 併用しながら自社で採る仕組みをどう作るか。費用と定着の見え方を整理できるか
- **現場リーダーの日程を押さえる段取り。** 出荷の合間に面接の枠を確保する方法。倉庫の見学と体験を組み込めるか

五つのうち、一つ目と三つ目が大きい。物流を知らない担当者は、「軽作業」の求人票を作り、地域の層に届く経路を持たず、派遣との差が出ません。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、倉庫・物流スタッフの採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「『軽作業』をやめて、重さと環境を正直に書かないと、初日に辞める人が減らない」と言われることです。「軽作業」で集めて初日に辞められるより、実態を書いて応募が減っても続く人を採るほうが、教える時間と費用が無駄になりません。実態を書くことで、地域の評判も変わります。

二つ目は、応募者の雇用の形の希望と経路が分かれることです。パートで午前だけの主婦層、夕方からの学生、日勤のシニア、フルタイムを望む未経験者、フォークリフトの免許を持つ経験者、派遣から直接雇用を望む人、外国人。それぞれ時間帯と身体的負担の許容と動く理由が違い、任せる業務と時間帯と合うかも違います。代行の担当者に分類をしてもらい、時間帯と業務を組み合わせます。

三つ目は、「繁忙期の短期」と「定着させる人」を分けて採る必要が表に出ることです。繁忙期の短期を定着の求人票で集めると、繁忙期が終わった後に「仕事が無い」と離れます。定着させる人を短期の求人票で集めると、繁忙期の負担で辞めます。短期と定着で求人票と経路を分け、短期から定着に移る道筋を作ります。

### エラベルの見解

担当する側から見ると、倉庫・物流スタッフの採用で最も効くのは、「『軽作業』を消して、重さと回数と環境と時間帯を正直に書く」ことと、「短期と定着で求人票と経路を分ける」ことです。倉庫の候補者は、「軽作業」を信じず、実態で「自分の時間と体で続けられるか」を判断します。実態を隠して集めた人は初日に辞め、その評判が地域に広がります。「軽作業、未経験歓迎、シフト自由」の求人票では、派遣への依存から抜けられません。

エラベルでは、倉庫の案件で担当者を紹介するとき、最初の一週間でセンター長と現場リーダーから「業務と雇用の形と時間帯」「繁忙の波」「環境と負担の実態」「初日の受け入れ」を聞き取り、一文にするところから始めてもらっています。作業の姿勢の評価は現場リーダーが面接と見学と体験で行い、フォークリフトの資格と外国人の受け入れと派遣からの移行は、専門家にご確認いただくようお伝えしています。

- 現場リーダーの関与は**採用でどう楽になるかを示し、負担を最小にして、初日に何をするかを話す価値を理解してもらう**
- 代行を選ぶときは**物流の経験・実態の書き方・地域の層に届く経路・派遣から直接雇用へ移す設計・日程の段取り**を確認する
- 出したあとは**「軽作業」をやめる必要が表に出る・雇用の形の希望と経路が分かれる・短期と定着を分けて採る必要が表に出る**。判断はセンター長と経営者、材料は代行

## よくある質問

### 派遣をやめて、自社だけで採れるようになりますか

いきなりやめるのではなく、併用しながら直接雇用の比重を上げる形が現実的です。定着させる業務と時間帯を直接雇用のパートで埋め、繁忙期の波の一部を自社の短期で埋め、残りを派遣で埋める。直接雇用の求人票に実態を書き、地域の層に届く経路を動かし、定着した人が増えてきたら、派遣の比重を下げます。派遣で働いている人を直接雇用に移す場合の扱いは、契約と法令に関わるので専門家にご確認ください。

### 冷蔵倉庫で寒く、荷物も重いのが実態です。正直に書くと来ませんか

隠して初日に辞められるほうが、教える時間と費用が無駄になり、地域の評判も下がります。「冷蔵で〇度程度、防寒着は会社が用意し、〇分ごとに暖かい休憩室で休憩。荷物は〇〇程度で、重いものは台車とリフト」のように、実態と、会社の工夫を一緒に書きます。寒さと重さを避けたい人は見送りますが、防寒と休憩と機器が分かれば続けられる人には届きます。工夫が無いなら、採用の前に休憩と機器を整えます。それが無いと、誰を採っても辞めます。

### 繁忙期だけ人が要ります。どう募集すればよいですか

繁忙期の短期は、定着の求人票とは分けて出します。「〇月から〇月までの短期、期間と時間帯と時給を明記、初日に何をするか、経験は要らない」の形で、学生や副業や短期を望む層に届く経路に出し、繁忙期の一か月以上前から募集を始めます。短期で働いた人の中から、定着に移ってもよい人に、繁忙期の終わりに声をかける道筋を作ると、翌年の繁忙期の核になります。短期と定着を同じ求人票で集めると、どちらの層も離れます。
