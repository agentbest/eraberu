案件に入って一週間で、直したほうがよい点がいくつも見えた。早く言ったほうが依頼側のためだと思い、最初の定例で提案したが、担当者の反応は薄く、「まず今のやり方でお願いします」と言われた。結論を先に書くと、**提案は、内容と同じくらい、出す時期で通るかどうかが決まります。出してよいのは、「最初の成果が出た直後」「依頼側が困りごとを自分から口にした直後」「契約の更新の二か月前」の三つのタイミングです。入って数日で出す提案は、内容が正しくても、依頼側から見れば「まだ何も見せていない人の意見」で、通りません。**見えた課題は記録しておき、時期が来たら出します。提案の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に、通らなかったときの扱いは[提案が通らなかったとき](/media/fukugyo-hantai-sareta/)に、最初の数週間の進め方は[早い段階で成果を出す](/media/fukugyo-quick-win/)にまとめています。

## 時期で通る通らないが決まる理由

同じ提案でも、出す時期で依頼側の受け取り方が変わります。理由は、依頼側の側の状態にあります。

| 依頼側の状態 | 提案の受け取り方 |
|---|---|
| 外部の担当者をまだ信頼していない | 「うちの事情を知らないのに」。内容を見る前に、立場で判断される |
| 外部の担当者が何かを見せた後 | 「この人の言うことは当たる」。内容を見る姿勢になる |
| 困りごとを自覚していない | 「今のままで困っていない」。提案は余計なものに見える |
| 困りごとを自分で口にした | 「それを何とかしたい」。提案は答えとして見える |
| 社内の予算や体制が固まっている時期 | 「今は変えられない」。時期の問題で保留になる |
| 予算や体制を組み直す時期 | 「次の期に入れられる」。提案が計画に乗る |

理由の要点は、「依頼側が提案を聞く姿勢になっているか」です。姿勢が無いときに出した提案は、内容がどれだけ正しくても、聞かれません。姿勢ができるのは、外部の担当者が何かを見せた後か、依頼側が自分で困りごとに気づいたときか、依頼側が計画を組み直す時期です。信頼を作る順番は[短期成果と中長期施策のバランス](/media/fukugyo-tanki-choki/)に、依頼側の社内の構造は[外部の立場だからできること](/media/fukugyo-gaibu-tachiba/)に書いています。

## 出してよい三つのタイミング

三つのタイミングは、依頼側が提案を聞く姿勢になっている瞬間です。

| タイミング | なぜ聞かれるか | 出す提案の例 |
|---|---|---|
| 最初の成果が出た直後 | 「この人に頼んでよかった」と担当者が感じている。次の提案を聞く姿勢がある | 成果の結果が示した次の課題。「返信は来るようになったので、次は面接の設定率を上げるために、面接官の枠の固定を」 |
| 依頼側が困りごとを自分から口にした直後 | 担当者が「何とかしたい」と思っている。提案は答えになる | その困りごとに直接答える提案。「日程が組めないとおっしゃっていた件、候補者に複数の候補日を最初から提示する形にできます」 |
| 契約の更新の二か月前 | 依頼側が次の期の範囲と予算を考える時期。提案が計画に乗る | 次の期の範囲に関わる提案。「次の期は、求人票の見直しを範囲に入れてはどうか」。[更新時の条件見直し](/media/fukugyo-keiyaku-koushin-koushou/) |

三つの要点は、「依頼側が困りごとを口にした直後」が最も通りやすいことです。担当者が「日程が組めなくて」と言ったとき、それは提案を求めている合図です。その場で「それなら、こういう形にできます」と答えれば、提案ではなく答えとして受け取られます。言われたときに答えられるように、見えた課題は先に整理しておきます。課題の整理の仕方は[課題の言語化](/media/fukugyo-kadai-teigi/)に整理しています。

### エラベルの見解

相談で最も多い思い込みは、「早く言ったほうが依頼側のためになるので、気づいたらすぐ提案すべきだ」というものです。実際には、入って数日の提案は、依頼側の担当者から見て「まだうちのことを知らない人が、一般論を言っている」に見えます。担当者は、その提案が正しいかどうかを判断する材料を、まだ外部の担当者について持っていません。正しい提案でも、聞く姿勢が無いときに出せば、通らないだけでなく、「早合点する人」という印象が残ります。

見ていて差がつくのは、入ってすぐに見えた課題を、提案せずに記録しているかです。記録している人は、最初の成果が出た後や、担当者が困りごとを口にしたときに、記録から取り出してすぐ出せます。時期を待った分、提案は依頼側の実態に合っていて、通ります。記録せずにすぐ出した人は、断られて、その課題を二度と出せなくなっています。エラベルでは、担当者が案件に入った最初の数週間は、提案より現状の把握と最初の成果に集中してもらい、提案はその後に出す形をお願いしています。順番を守った担当者の提案は、依頼側に「実態を見たうえでの提案」として受け取られています。

## 出さないほうがよい時期

三つ以外の時期の中でも、特に避けるべき時期があります。

| 時期 | なぜ避けるか |
|---|---|
| 入って数日から数週間 | 信頼が無く、依頼側の実態も見えていない。一般論に見える |
| 依頼側の採用の山の最中 | 担当者は目の前の面接と内定で手一杯。提案を考える余裕が無い |
| 依頼側で問題が起きている直後 | 辞退が続いた、内定を断られた直後に提案すると、「責められている」と受け取られる。落ち着いてから |
| 契約の更新の直前 | 更新の判断に影響する。「更新しないなら提案を」と聞こえることがある。二か月前までに |
| 自分の稼働が下がっている時期 | 「稼働が下がっているのに提案だけする」と映る。先に稼働を戻す |
| 依頼側の担当者が替わった直後 | 新任は状況を把握中。前任との経緯を知らない。新任向けに最初の成果を出してから |
| 依頼側の予算や体制が固まった直後 | 変えられない時期。次に組み直す時期まで待つ |

避ける要点は、「問題が起きている直後」です。辞退が続いた直後に「面接の枠を固定すべきだった」と提案すると、内容が正しくても、担当者は「後から言われた」と感じます。問題が起きたときは、まず対応を手伝い、落ち着いてから「再発を防ぐために」と出します。問題への対応は[トラブルへの対処](/media/fukugyo-trouble/)に、担当者の交代への備えは[いつ辞めても困らない状態を作る](/media/fukugyo-hikitsugi-junbi/)に書いています。

## 案件の段階ごとの提案の重さ

案件が進むにつれて、出せる提案の重さが変わります。段階に合わない重さの提案は通りません。

| 段階 | 出せる提案の重さ | 例 |
|---|---|---|
| 最初の数週間 | 出さない。自分の範囲の中で試すだけ | スカウトの文面や送る相手の絞り方を変える（提案ではなく自分の範囲の判断） |
| 最初の成果が出た後 | 軽い提案。依頼側の一人の判断で決まり、すぐ戻せるもの | 「候補者に複数の候補日を提示する形にしたい」「記録の型をこうしたい」 |
| 数か月経ち、記録が溜まった後 | 中くらいの提案。依頼側の社内の複数の人に関わるが、予算は要らないもの | 「面接官の枠を週に固定したい」「選考の段階の一つを書類で代替したい」 |
| 更新の二か月前 | 重い提案。範囲、予算、体制に関わるもの | 「次の期は求人票の見直しを範囲に入れたい」「媒体を追加したい」 |
| 型が整った後 | 仕組みの提案。依頼側の採用の進め方そのものに関わるもの | 「採用の工程ごとの担当と型を、社内の運用として文書にしたい」 |

段階の要点は、「軽い提案から始め、通った実績を積んでから重い提案を出す」ことです。最初に重い提案を出すと、依頼側は「まだ何も見せていないのに、うちの体制を変えようとしている」と感じます。軽い提案が通り、結果が出て、それから中くらい、重い、と上げていけば、依頼側は「この人の提案は当たる」と積み重ねで判断できます。範囲を広げる順番は[次の案件へ広げる](/media/fukugyo-tsugi-e/)に整理しています。

## 依頼側の社内の時期に合わせる

提案の時期は、自分の側の段階だけでなく、依頼側の社内の時期にも合わせます。

| 依頼側の時期 | 提案との関係 |
|---|---|
| 予算の期の変わり目 | 予算が要る提案は、次の期の予算を組む前に出す。組んだ後では入らない |
| 採用計画を立てる時期 | 範囲や体制に関わる提案は、計画を立てる時期に出すと、計画に乗る |
| 採用の山（面接や内定が集中する時期） | 提案は出さない。山が過ぎてから |
| 組織の変更や担当者の異動の時期 | 担当者が替わるなら、新任が落ち着いてから。前任に出しても引き継がれない |
| 依頼側の繁忙期（決算、大きな案件） | 担当者の余裕が無い。避ける |
| 上長への報告の時期 | 担当者が上長に報告する直前に、報告に使える材料として提案を渡すと、担当者が使いやすい |

合わせる要点は、「予算の期と採用計画の時期を最初に聞いておく」ことです。契約のときに「予算の期はいつからですか」「採用計画はいつ立てますか」と聞いておけば、重い提案を出す時期が決まります。聞いていないと、予算が固まった直後に出して、次の期まで待つことになります。最初に聞く項目は[初回打ち合わせの進め方](/media/fukugyo-shodan/)に、依頼側の社内の動きは[経営者直下で動くとき](/media/fukugyo-keieisha-chokka/)に書いています。

## 切り出し方

時期が来たら、提案を切り出します。切り出し方で、担当者の受け取り方が変わります。

| 場面 | 切り出し方 |
|---|---|
| 最初の成果が出た直後 | 成果の報告の中で、「この結果を見ると、次はここが課題になりそうです。整理して次回お持ちしてよいですか」と予告する |
| 依頼側が困りごとを口にした直後 | その場で、「それなら、こういう形にできます。詳しくは次回に」と、答えの方向だけ示す。詳細はその場で全部言わない |
| 更新の二か月前 | 「次の期の範囲を考えるにあたって、一つ提案があります」と、更新の話の一部として切り出す |
| 定例の終わり | 「一つ、気づいたことがあります。次回、整理して持ってきてよいですか」。予告して了解を取る |
| 稼働報告の「確認したいこと」の欄 | 「〇〇について、提案を整理しています。次回の定例で時間をいただけますか」。文面で予告 |

切り出す要点は、「予告して了解を取る」ことです。いきなり提案の本体を出すと、担当者は身構えます。「次回、整理して持ってきてよいですか」と聞き、「いいですよ」と返ってきたら、担当者は次回に提案が来ることを知った状態で聞けます。了解を取ってから出す提案は、了解なしに出す提案より、通りやすくなります。提案の本体の伝え方は[改善提案の伝え方](/media/fukugyo-kaizen-teian/)に整理しています。

## 待つ間にやること

時期が来るまで提案を出さない間、見えた課題を寝かせておくのではなく、出すときに通る形に整えておきます。

| やること | 内容 |
|---|---|
| 課題を記録する | 見えた課題を、事実（依頼側の記録で確認できるもの）と一緒にメモしておく。印象ではなく事実で |
| 事実を集める | 提案の根拠になる数字や出来事を、依頼側の記録から集めておく。時間が経つほど根拠が増える |
| 自分の範囲で試す | 提案の一部を自分の範囲で試し、結果を出しておく。「相手の絞り方を変えたらこうなった」が、求人票の提案の根拠になる |
| 選択肢を作っておく | 出すときに、二つか三つの選択肢と、それぞれの手間と効果を並べられるようにしておく |
| 担当者が使える形にしておく | 担当者が上長に説明できる一枚を、先に作っておく |
| 時期の合図を見る | 最初の成果、担当者の困りごとの言葉、更新の時期、予算の時期を、見逃さない |

待つ要点は、「自分の範囲で試す」ことです。提案の一部を自分の範囲で試して結果を出しておけば、時期が来たときの提案は「一般論」ではなく「試した結果に基づく提案」になり、通りやすくなります。待つ時間は、提案を強くする時間です。自分の範囲で試す考え方は[提案が通らなかったとき](/media/fukugyo-hantai-sareta/)の「自分の範囲でできる部分を切り出す」と同じです。

### エラベルの見解

担当する側から見ると、提案が通る人は、提案の数が少なく、時期が合っています。入ってすぐには出さず、最初の成果を見せ、担当者が困りごとを口にしたときに答え、更新の前に次の期の話として出す。この三つの時期に絞って、一つずつ出しています。通らない人は、気づいたらすぐ、いくつも出しています。内容の質は同じでも、時期と数で、依頼側の受け取り方が変わります。

順番として、案件に入ったら課題を記録し、提案せずに最初の成果に集中し、成果が出たら一つ目の軽い提案を出し、担当者の困りごとの言葉を待ち、更新の二か月前に重い提案を出す。この順番で、提案は「材料」として依頼側に届きます。エラベルでは、担当者が案件に入った最初の数週間は、提案より現状の把握と最初の成果を優先してもらっています。時期を待てる担当者は、依頼側から「実態を見てから言う人」と評価され、提案が通るだけでなく、判断を任される範囲も広がっています。

## まとめ

- 提案は**内容と同じくらい時期で通るかが決まる**。依頼側が聞く姿勢になっている瞬間に出す
- 出してよいのは**最初の成果が出た直後・依頼側が困りごとを口にした直後・更新の二か月前**の三つ
- 避けるのは**入って数日・採用の山の最中・問題が起きた直後・更新の直前・稼働が下がっている時期・担当者の交代直後・予算が固まった直後**
- **軽い提案から始め、通った実績を積んでから重い提案へ**。段階に合わない重さは通らない
- **予算の期と採用計画の時期を最初に聞き**、重い提案はその前に出す
- **予告して了解を取ってから出す**。困りごとを口にされたら、その場で答えの方向だけ示す
- 待つ間に**課題を記録し、事実を集め、自分の範囲で試し、選択肢と担当者向けの一枚を作っておく**

## よくある質問

### 入ってすぐに、明らかに直すべき問題を見つけました。待つべきですか

候補者に不利益が出ること（連絡の遅れ、情報の誤り）や、法令に関わる可能性があることは、提案ではなく事実として、すぐに伝えます。それ以外の「効率や質を上げる」提案は、待ちます。すぐ伝えるべきものかどうかの線は、「放置すると候補者や依頼側に取り返しのつかない損が出るか」です。出ないなら、記録して時期を待ちます。線の引き方は[会社の代表として話す責任](/media/fukugyo-kaisha-daihyou/)に整理しています。

### 担当者から「何か提案はありますか」と聞かれました。時期は来ていませんが答えるべきですか

聞かれたなら、答えます。ただし、重い提案は避け、「いま自分の範囲で試していることと、その結果を見てから整理したいこと」を短く伝えます。「〇〇を試していて、結果が見えたら、次の段階の提案を整理してお持ちします」と返せば、提案を出す姿勢は示しつつ、時期を待てます。聞かれたからと、記録していた課題を全部出すと、担当者は受け止めきれません。

### 更新の二か月前に出そうと思っていたら、更新の話が急に来ました

更新の話が来た時点で、「次の期の範囲について、一つ提案があるので、更新の条件と一緒に整理させてください」と伝え、数日で提案を出します。待つ間に事実と選択肢を整えていれば、数日で出せます。整えていなかった場合は、更新は現状の条件で進め、提案は更新後の最初の定例で「次の期の中で検討したいこと」として出します。更新の判断を提案で遅らせないほうが、依頼側との関係は保てます。
