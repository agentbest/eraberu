事業開発の採用を代行に出すか迷う会社は、「求人票を作って媒体に出す工程はお願いしたいが、まだテーマも決まっていない新規事業の人をどう募集すればよいか分からない」「事業開発と言っても、社内でも何をする役かが定まっていない」で止まります。結論を先に書くと、**求人票の作成・媒体の運用・スカウト・応募者への一次対応・面接の日程の確保・内定後の対応は代行に任せられ、事業開発の中身とテーマの整理・予算と権限と撤退の基準の決定・既存事業との関係の整理・要件の決定・構想と実行の力と経営者との相性の評価・合否の判断は社内に残す**のが線です。ただし、事業開発では「何を作るのか（テーマが決まっているか探索からか）」と「予算と権限と撤退の基準」が決まっていないと、任せる範囲も要件も決まらず、候補者に「形だけの新規事業」と読まれます。これを先に決めることが、代行に出す前の要点です。他の職種と共通する分け方は[人事採用を代行に出す判断基準](/media/rpo-jinji-rpo/)に、同じく経営者との距離が近い経営企画の線は[経営企画採用を代行に出す判断基準](/media/rpo-keiei-kikaku-rpo/)にまとめています。

## 事業開発採用が他の職種と違う点

一つ目は、「事業開発」の中身が会社ごとに全く違うことです。新規事業をゼロから立ち上げる役、他社との提携やアライアンスを作る役、大口の新規顧客を開拓する役、既存事業を隣の領域に広げる役。ゼロから立ち上げる人と、提携を作る人と、大口を開拓する人は、持っているものと動く理由が違います。「事業開発募集」だけでは、どれを求めているかが候補者に伝わりません。

二つ目は、テーマが決まっているか探索からかで求める人が変わることです。テーマが決まっていて実行を任せるなら、その領域の実行の経験が要り、テーマの探索から任せるなら、問いを立てて検証する経験が要ります。「新規事業を考えてほしい」と「この事業を立ち上げてほしい」では、届く層が違います。

三つ目は、候補者が「何を作るのか」「予算と権限」「撤退の基準と失敗の扱い」「既存事業との関係」「経営者との距離」「出口」を最初に確かめ、「新規事業」の言葉を警戒することです。事業開発の経験者は、「新規事業部」が形だけで、予算も権限も無く、既存事業の片手間で、失敗したら評価が下がる会社を、経験で知っています。予算と権限と撤退の基準が無い求人は、「形だけ」と読まれます。

四つ目は、成果が出るまでに時間がかかり、評価の仕組みが要ることです。新規事業は、数年は売上が立たないことが多く、その間の評価（検証の進み方、学びの質）と、撤退したときの扱い（評価が下がるか、次のテーマに移れるか）が決まっていないと、候補者は入らず、入っても離れます。

五つ目は、経験者が少なく、経路で持ち味が違うことです。起業の経験者（ゼロから作る力は強いが、大きな組織で動く経験が薄いことがある）、スタートアップ出身（速さと検証は強い）、大企業の新規事業（社内を動かす力は強いが、ゼロから作る経験が薄いことがある）、コンサルティングファーム出身（構想は強いが、実行が薄いことがある）、営業からの転向（顧客の開拓は強い）。自社の中身に合うかは、肩書では分かりません。

この五つから、代行に出せる工程が決まります。

## 工程ごとの「任せられる・残す」

| 工程 | 任せられるか | 理由 |
|---|---|---|
| 事業開発の中身とテーマの整理 | 残す | 立ち上げか提携か開拓か拡張か、テーマが決まっているか探索からか。社内にしか分からない |
| 予算と権限と撤退の基準の決定 | 残す | 使える予算、決められる範囲、撤退の基準と失敗したときの扱い、評価の仕組み。経営者が決める |
| 既存事業との関係の整理 | 残す | 既存事業の人員と顧客をどこまで使えるか、既存事業との利害の調整を誰がするか。経営者が決める |
| 要件の決定 | 残す | 中身とテーマと権限から。外部は整理を手伝える |
| 求人票の作成 | 任せられる（中身とテーマと権限が決まっていれば） | 決まったものを候補者に伝わる言葉にする。テーマの機微な情報は含めない |
| 媒体の選定と運用 | 任せられる | 事業開発に届く媒体と経路の経験があれば |
| スカウトの検索と送信 | 任せられる | 中身とテーマと経路に合わせた検索と、担当してきた事業や案件に触れた文面の個別化 |
| 応募者への一次対応 | 任せられる | 連絡、日程、流れの案内 |
| 経営者・事業責任者の面接の日程の確保 | 任せられる | 経営者の予定を押さえる。社内で最も回らない工程 |
| 書類の一次絞り | 条件付き | 経路と経験の種類（立ち上げ、提携、開拓）の分類は任せられる。構想と実行の力の評価は残す |
| 構想と実行の力と経営者との相性の評価 | 残す | 経営者が面接で、自社のテーマか仮のテーマを材料に確かめる |
| 予算と権限と撤退の基準と既存事業との関係の説明 | 残す（代行が同席可） | 経営者が自分の言葉で話す。求人票と違うと辞退される |
| 合否の判断 | 残す | 経営者の判断 |
| 条件の決定と提示 | 残す | 会社の判断。成果が出るまでの評価と報酬の仕組みを含む |
| 内定後の対応 | 任せられる | 辞退を防ぐ連絡。現職の区切りに合わせた入社日の調整 |

線の要点は、「事業開発の中身とテーマと、予算と権限と撤退の基準が、募集の前に社内で決まっているか」です。これが求人票とスカウトの中身になり、候補者が「形だけの新規事業ではないか」「自分の持ち味が活きるか」を判断する材料になります。

### エラベルの見解

相談で多いのは、「事業開発を募集しているが、応募が来ない。来ても、企画書は書けるが動かない人ばかり」というご相談です。求人票を見ると、「事業開発募集。新規事業の企画と立ち上げ、アライアンスの推進、新規顧客の開拓など。裁量を持って新しい事業を作れます」と書かれていて、中身が全部並び、テーマが決まっているかも、予算も、権限も、撤退の基準も、既存事業との関係も無い。事業開発の経験者はこれを読んで、「形だけの新規事業部」「予算も権限も無く、失敗したら評価が下がる」と判断し、応募しないか、企画書を書くだけの人が応募していました。

見ていて差がつくのは、「何を作るのか、予算と権限と撤退の基準を一文で言えるか」です。「当社の事業開発は、既存の〇〇の顧客に向けた新しいサービスをゼロから立ち上げること。テーマの方向は決まっていて、中身は任せる。予算は初年度〇〇の範囲で事業開発が決められ、既存事業の営業を〇名使える。撤退の基準は一年後の検証で決め、撤退しても評価は検証の質で見て、次のテーマに移れる。経営者の直下で、月に一度の判断の場がある。立ち上がれば事業責任者に」。一文で中身とテーマと予算と権限と撤退の基準と出口が分かれば、企画書だけの人は自分向けでないと分かり、ゼロから作って動かしたい人は「形だけではない」と判断します。エラベルでは、事業開発の案件をお受けする前に、依頼側に「中身とテーマ」と「予算と権限と撤退の基準」を伺い、一文にしていただいています。

## 代行に出す前に社内で確認すること

代行に出す前に、五つを社内で確認します。

**一つ目：事業開発の中身とテーマ。** 立ち上げか提携か開拓か拡張か。テーマが決まっているか（方向だけか、中身まで決まっているか）、探索から任せるか。テーマの機微な情報を、求人票とスカウトでどこまで書けるか。

**二つ目：予算と権限と撤退の基準。** 使える予算の範囲と、事業開発が自分で決められる範囲。人員（専任か、既存事業の人を使えるか）。撤退の基準（いつ、何で判断するか）と、撤退したときの扱い（評価、次のテーマ、既存事業への戻り方）。成果が出るまでの評価の仕組み（検証の進み方、学びの質で見るか）。

**三つ目：既存事業との関係。** 既存事業の顧客と営業と技術をどこまで使えるか、既存事業との利害（顧客の取り合い、人員の奪い合い）を誰が調整するか、既存事業の抵抗が予想されるなら、経営者がどう入るか。

**四つ目：経営者との距離と、いまの状態。** 経営者の直下か、事業責任者の配下か。判断の場の頻度と形。いま事業開発の役を誰が担っていて、何が止まっているか（企画はあるが動かない、既存事業の片手間で進まない、撤退の判断が先送りされている）。正直に把握します。

**五つ目：出口と、経営者が面接に出す時間。** 立ち上がったら事業責任者か子会社の社長か、独立の支援か。経営者が面接にどのくらい時間を出せるか。事業開発の面接は経営者か事業責任者が出るしかありません。

五つのうち、一つ目と二つ目が代行に出す前提です。三つ目以降は、代行と一緒に整理できます。

## 経営者の関与のさせ方

事業開発の採用では、経営者か事業責任者の関与が要ります。面接で自社のテーマか仮のテーマを材料に構想と実行の力を確かめる、予算と権限と撤退の基準を自分の言葉で話す、相性を見る。しかし経営者は忙しく、面接の日程が組めず、候補者が離れます。

関与を取り付けるには、「採用が決まると経営者がどう楽になるか」を具体的に示すことです。「この人が入れば、経営者が自分で抱えている新規事業の構想と検証を手放せる」。そして、負担を最小にする形で頼みます。面接の枠は代行が経営者の予定に先に押さえる、経歴は代行が整理して渡す、予算と権限と撤退の基準の説明の要点は代行が用意する。経営者がやるのは、テーマを材料に構想と実行の力を確かめることと、予算と権限と撤退の基準を自分の言葉で話すことだけにします。

もう一つは、面接で経営者が「予算と権限と撤退の基準」を自分の言葉で話すことの価値を、経営者自身に理解してもらうことです。事業開発の候補者は、人事の話より経営者の話を信じ、「形だけの新規事業ではないか」を最も気にしています。経営者が「初年度の予算は〇〇で、その範囲は事業開発が決めてよい。一年後の検証で続けるか決める。撤退しても、検証の質で評価して、次のテーマに移ってもらう。既存事業と揉めたら自分が入る」と話すと、候補者は「本気の新規事業」と判断します。

## 代行を選ぶときの確認項目

事業開発の採用を代行に出すとき、代行に確認する項目は五つです。

- **担当者に事業開発か、それに近い経験があるか。** 事業開発そのものでなくても、新規事業やスタートアップや事業会社の企画の経験、事業開発の採用を回した経験。中身の違い、テーマの有無による違い、予算と権限と撤退の基準の重要さを知っているか
- **中身とテーマと予算と権限と撤退の基準を求人票にどう書くか、案を出せるか。** 「新規事業の企画と立ち上げ。裁量」で済まさず、中身とテーマと予算と権限と撤退の基準と出口を、機微な情報を含めずに書けるか
- **事業開発に届く媒体と経路の経験。** 起業経験者、スタートアップ出身、大企業の新規事業、ファーム出身、営業からの転向、それぞれに届く経路と、中身に合う経路の見分け方
- **テーマの機微な情報の扱い。** 検討中のテーマの詳細を、代行の担当者にどこまで渡すか、代行側の管理の方法、契約
- **経営者の日程を押さえる段取り。** 経営者の予定に面接の枠を先に確保する方法。面接で使うテーマの材料の準備

五つのうち、一つ目と四つ目が大きい。事業開発を知らない担当者は、「新規事業。裁量」の求人票を作り、テーマの扱いを雑にして、候補者に「形だけの会社」と読まれます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## 代行に出したあとに起きること

代行に出したあと、事業開発の採用で起きやすいことを三つ挙げます。

一つ目は、代行の担当者から「予算と権限と撤退の基準が決まっていない」と指摘されることです。代行が求人票を作ろうとして、「予算はいくらの範囲ですか。撤退したら評価はどうなりますか」と聞かれ、答えられない。これは代行に出したから起きる問題ではなく、出す前から決まっていなかったものが表に出ただけです。ここで決めます。決まらないなら、事業開発を採る前に、経営者が新規事業をどう位置づけるかを決めることが先です。

二つ目は、応募者の経路と持ち味が分かれることです。起業経験者、スタートアップ出身、大企業の新規事業、ファーム出身、営業からの転向。それぞれ持っているもの（ゼロから作る、速く検証する、社内を動かす、構想する、顧客を開拓する）が違い、自社の中身に合うかも違います。代行の担当者に経路の分類をしてもらい、経営者が面接で確かめることを変えます。

三つ目は、面接で「既存事業との関係」を候補者が確かめることです。「既存事業の顧客を使えるか」「既存事業と揉めたら誰が入るか」を聞かれ、経営者が「調整してもらう」と答えれば、候補者は「既存事業に潰される」と判断します。既存事業との関係を経営者がどう整理しているかを、面接で自分の言葉で話します。

### エラベルの見解

担当する側から見ると、事業開発の採用で最も効くのは、「予算と権限と撤退の基準を、経営者の言葉で求人票に書き、面接で同じことを話す」ことです。事業開発の候補者は、「新規事業」「裁量」の言葉を信じず、「予算はいくらで、何を決められて、失敗したらどうなるか」で「本気の新規事業か」を判断します。この三つが書かれ、面接で経営者が同じことを話す会社は、候補者に「本気の会社」と読まれます。

エラベルでは、事業開発の案件で担当者を紹介するとき、最初の一週間で経営者から「中身とテーマ」「予算と権限と撤退の基準」「既存事業との関係」「出口」を聞き取り、経営者の言葉で一文にし、テーマの機微な情報の扱いを決めるところから始めてもらっています。構想と実行の力と相性の評価は経営者が面接で行い、経営者の面接の枠の確保は担当者が回します。機密情報の扱いに関わる判断は、専門家にご確認いただくようお伝えしています。

## まとめ

- 事業開発採用が他と違うのは**中身が会社ごとに全く違う・テーマが決まっているか探索からかで求める人が変わる・候補者が何を作るかと予算と権限と撤退の基準と既存事業との関係と出口を最初に確かめ「新規事業」を警戒する・成果が出るまで時間がかかり評価の仕組みが要る・経験者が少なく経路で持ち味が違う**の五つ
- **求人票・媒体・スカウト・一次対応・面接の日程・内定後は任せられ、中身とテーマ・予算と権限と撤退の基準・既存事業との関係・要件・構想と実行の力と相性の評価・合否は残す**
- 代行に出す前に**中身とテーマ・予算と権限と撤退の基準・既存事業との関係・経営者との距離といまの状態・出口と経営者の面接の時間**を確認する
- 経営者の関与は**採用でどう楽になるかを示し、負担を最小にして、予算と権限と撤退の基準を自分の言葉で話す価値を理解してもらう**
- 代行を選ぶときは**事業開発に近い経験・中身とテーマと権限の書き方・経路の経験・テーマの機微な情報の扱い・経営者の日程の段取り**を確認する
- 出したあとは**予算と権限と撤退の基準の未決が表に出る・経路と持ち味が分かれる・既存事業との関係を候補者が確かめる**。判断は経営者、材料は代行

## よくある質問

### テーマがまだ決まっていません。探索から任せたいのですが、どう募集すればよいですか

「テーマの探索から任せる」と正直に書き、探索の範囲（既存の顧客に向けて、既存の技術を使って、この領域で、など）と、探索の期間と予算と、テーマが決まるまでの評価（検証の進み方と学びの質で見る）を書きます。探索から任せられる人は、問いを立てて検証した経験を持つ人（起業経験者、スタートアップ出身、新規事業の探索の経験者）で、テーマが決まっている募集とは届く層が違います。探索の範囲と期間と評価が無い「新規事業を考えてほしい」は、「形だけ」と読まれます。

### 撤退の基準を求人票に書くと、後ろ向きに見えませんか

事業開発の経験者には、逆に読まれます。撤退の基準が書かれている会社は「新規事業を本気で回している会社」と読まれ、無い会社は「失敗したら評価が下がって終わりの会社」と読まれます。書くのは、「いつ、何で判断するか」と「撤退したときの扱い（検証の質で評価し、次のテーマに移れる、既存事業に戻れる）」です。撤退の基準と失敗の扱いを決めることは、事業開発を採る前提であり、新規事業を回す前提でもあります。

### 既存事業の反発が予想されます。どう書けばよいですか

隠さず、経営者がどう入るかを書きます。「既存事業の顧客と営業を使う。利害がぶつかったときは経営者が判断する」。既存事業との関係が整理されていない会社は、事業開発の候補者に「既存事業に潰される」と読まれます。整理するのは、既存事業の顧客と人員をどこまで使えるか、利害の調整を誰がするか、既存事業の評価に新規事業への協力をどう入れるか、です。整理が無いなら、採用の前に経営者が決めます。それが無いと、誰を採っても動けません。
