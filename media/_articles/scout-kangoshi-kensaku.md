看護師にスカウトを送る前の検索で、「看護師、経験〇年以上、夜勤可」で条件を組むと、急性期の病棟にいた人、回復期や療養にいた人、外来や訪問にいた人が、同じ一覧に出てきます。加えて、通えない勤務地の人も混ざります。もう一つ大きいのは、「夜勤可」を一律に必須にすると、日勤で働きたい潜在看護師（離職中で復職を考えている人）と子育て中の看護師が全部漏れること。看護師の資格は共通でも、業態と病棟と勤務地と働き方が合わない人は動きません。看護師の検索で最初にやるべきは、自施設の業態と病棟と業務と勤務地と夜勤の方針を決め、夜勤の枠と日勤の枠を分けて、年数ではなく「どの業態のどの病棟で、何を担い、どこで、どの働き方を望むか」で探すことです。結論を先に書くと、**検索条件は、先に自施設の業態と病棟と業務と勤務地と夜勤の方針を決め、年数ではなく経験（業態・病棟の種類・担った業務・患者層）で組み、夜勤の枠と日勤の枠を分けて要件の必須だけにし、プロフィールを「どの業態のどの病棟で、何を担い、どこで、どの働き方を望むか」で読み、業態は絞ったまま勤務地を通える範囲まで広げ、潜在看護師と子育て中の層を厚くして送る順を決めます**。文面の型は[看護師へのスカウト文面](/media/scout-kangoshi-bunmen/)に、要件の作り方は[看護師の採用要件の作り方](/media/rpo-kangoshi-youken/)に書いていますので、ここでは「検索条件とターゲティング」に絞ります。媒体ごとの検索の仕様には触れません。仕様は各媒体の公式情報でご確認ください。看護師の配置や勤務に関わる法令上の扱いは専門家にご確認ください。

## 先に「業態と病棟」「業務」「勤務地」「夜勤の方針」を決める

自施設の業態（急性期、回復期、療養、外来、訪問、施設など）と病棟の種類と患者層、任せる業務（受け持ち、リーダー、専門の処置など）、勤務地（通える範囲）、夜勤の方針（夜勤の枠で採るのか、日勤の枠も設けるのか、夜勤の回数の調整はできるか）を決めます。四つで探す人が変わります。

| 決めること | 探す人が変わる点 |
|---|---|
| 業態と病棟 | 急性期と療養と訪問は、業務の中身と働き方が違う。業態は絞る |
| 業務 | 受け持ちが主なら病棟の経験者。リーダーを任せるならリーダーの経験者 |
| 勤務地 | 通える範囲の人。看護師は勤務地で生活が決まる |
| 夜勤の方針 | 夜勤の枠だけなら夜勤ができる人。日勤の枠を設けるなら潜在看護師と子育て中の層が対象に入る |

止まりやすいのは、「夜勤可」を一律に必須にして、日勤の枠を設けないときです。対象が大きく狭まり、潜在看護師と子育て中の層が全部漏れます。決め方は[看護師の採用要件の作り方](/media/rpo-kangoshi-youken/)に書いています。

## 年数ではなく経験で組み、夜勤の枠と日勤の枠を分ける

条件に入れるのは、年数ではなく、要件の必須に当たる経験です。資格は前提なので入れますが、認定や年数は歓迎にします。夜勤の可否は、枠ごとに分けます。

| 要件 | 検索条件に | 理由 |
|---|---|---|
| 必須：看護師の資格 | 入れる | 前提 |
| 必須：〇〇（業態）の経験（または復職の研修で補える範囲） | 業態の言葉で（「急性期」「回復期」「療養」「訪問」） | 業態の中核 |
| 必須：〇〇（病棟の種類・患者層）の経験 | 病棟の言葉で | 業務が違う |
| 勤務地 | 通える範囲で | 生活を決める |
| 夜勤 | 夜勤の枠では入れる。日勤の枠では入れない | 枠で分ける |
| 歓迎：認定、リーダー経験、年数 | 入れない | 資格と年数は業務の経験と一致しない |

止まりやすいのは、「夜勤可」「ブランク〇年以内」を一律に必須にして、数人しか出ないときです。日勤の枠を設け、ブランクは研修で補える範囲を決めて、外します。

## プロフィールを「どの業態のどの病棟で、何を担い、どこで、どの働き方を望むか」で読む

看護師の経験の中身は、五つで読めます。どの業態の、どの病棟で（種類と患者層）、何を担い（受け持ち、リーダー、処置、教育）、どこで（勤務地の希望）、どの働き方を望むか（夜勤の可否、時短、日勤のみ、復職）。五つが書いてある人は、年数が何であっても合うかが読めます。

| プロフィールの記述 | 読み方 |
|---|---|
| 「看護師として病棟勤務」 | 業態も病棟も業務も無い。中身が読めない |
| 「急性期の〇〇科病棟で受け持ち〇名程度。夜勤月〇回。リーダー経験あり」 | 業態、病棟、業務、夜勤の経験が分かる |
| 「療養病棟で〇年。日勤のみを希望」 | 業態が療養。日勤の枠に合う |
| 「訪問看護で〇年。〇〇（地域）」 | 業態が訪問。病棟への転向は文面で触れれば対象 |
| 「育児で〇年離職。復職を希望。日勤で〇〇（地域）」 | 潜在看護師。日勤の枠と復職の支援があれば有力 |
| 「希望：〇〇（地域）、時短、夜勤は月〇回まで」 | 子育て中の層。夜勤の調整と時短があれば合う |

止まりやすいのは、年数と「夜勤可」だけで判断するときです。「病棟勤務」の人に「急性期の〇〇科でリーダーを」と送っても、経歴と合うかが分かりません。

### エラベルの見解

相談で最も多い思い込みは、「看護師は夜勤ができないと戦力にならないから、夜勤可を必須にするしかない」というものです。実際には、夜勤の枠と日勤の枠を分けて日勤の枠を設けると、対象が大きく広がり、潜在看護師と子育て中の層は競合が送っていないことが多い。ある施設では、「夜勤可、経験〇年、ブランク〇年以内」で検索して数人しか出ず、送っても返信が無い状態でした。担当者が入って、業態と病棟を「回復期の〇〇病棟」と決め、夜勤の枠と日勤の枠を分け、ブランクは研修で補える範囲として外し、勤務地を通える範囲に広げ、「復職」「日勤」「時短」「〇〇（地域）」の記述がある人を読む形にしたところ、対象は何倍にもなり、復職を考えている看護師と子育て中の看護師から返信が来て、面談で合いました。看護師の検索は、「夜勤可」で機械的に絞るより、業態と病棟で読み、枠と層で広げるほうが合います。

## 業態は絞ったまま、勤務地を通える範囲まで広げ、潜在看護師と子育て中の層を厚くする

対象が少ないときは、業態を広げるのではなく、勤務地を「通える範囲」まで広げ、潜在看護師と子育て中の層を厚くします。業態が違う人（訪問から病棟、療養から急性期）は業務の中身が違うので、文面で業態の違いに触れ、教育を厚く書けば対象になることもありますが、まず勤務地と層で広げます。

| 広げる方向 | 見どころ | 文面 |
|---|---|---|
| 勤務地を通える範囲まで | 住んでいる地域、以前の施設の場所、「〇〇線沿線」の希望 | 件名に駅や地域を出し、通勤の目安を書く |
| 潜在看護師（復職） | 「離職」「復職」「ブランク」の記述 | 復職の支援（研修、慣らしの期間、指導者）と日勤の枠を事実で書く |
| 子育て中の層 | 「時短」「日勤のみ」「夜勤は月〇回まで」「院内保育」の希望 | 両立の支援の中身（時短、夜勤の調整、院内保育、急な休みの扱い）を事実で書く |
| 隣の業態 | 訪問や療養から急性期へ、急性期から回復期へ、の転向の記述 | 業態の違いに先に触れ、教育の体制を書く |

止まりやすいのは、対象が少ないからと、通えない勤務地の人や、夜勤の枠しか無いのに日勤を望む人に送るときです。「読んでいない」と受け取られます。

## 送る順の付け方

| 順 | 条件 |
|---|---|
| 一 | 業態と病棟と業務が自施設と合い、勤務地が通える範囲で、働き方の希望が枠と合い、五つが書いてあり、一行目に書ける一点がある |
| 二 | 業態と病棟が合い、勤務地が通える範囲。業務の経験は一部。伸ばす方針を文面に書ける |
| 三 | 潜在看護師か子育て中の層。勤務地と働き方の希望が日勤の枠や両立の支援と合う。支援を事実で書いて送る |
| 四 | 隣の業態で、転向の記述があり、勤務地が合う。業態の違いに先に触れる文面で送る |
| 送らない | 勤務地が通えない。働き方の希望が枠と合わない（日勤のみを望む人に夜勤の枠のみ）。業態が違い転向の記述も無い。五つが読めず年数だけ。一行目に書ける一点が無い |

止まりやすいのは、「年数が長いから」「夜勤ができるから」で送るときです。業態と病棟と勤務地と働き方の近さで順を付けます。

## 条件の保存と見直し

組んだ条件は、「〇〇病棟・夜勤枠用」「日勤枠用」「復職層用」「子育て層用」のように病棟と枠と層ごとに名前を付けて保存し、送った結果と一緒に記録します。月に一度、返信が来た人の共通点（業態、病棟、業務、勤務地、働き方の希望、層）を見て、条件と読み方を直します。保存の仕方は[検索条件の保存と使い回し](/media/scout-kensaku-hozon/)に書いています。

### エラベルの見解

担当する側から見ると、看護師の検索で会社ごとに差がつくのは、「日勤の枠と両立の支援を用意できているか」です。業態と病棟と勤務地は看護部長に聞けば決まりますが、「夜勤ができる経験者」だけを探す施設では、対象が狭く、同じ人に競合も送っています。日勤の枠、時短、夜勤の回数の調整、院内保育、復職の研修を用意している施設では、対象が大きく広がり、競合が送っていない層に届きます。エラベルでスカウトの検索を担当する人には、条件を組む前に、看護部長と師長に「業態と病棟と業務は何か、勤務地はどこか、夜勤の方針は何か、日勤の枠と両立の支援と復職の支援はあるか」を聞いてもらっています。文面の型は[看護師へのスカウト文面](/media/scout-kangoshi-bunmen/)に書いています。

## 代行に出す場合の範囲

担当者が持つのは、要件から必須の経験を取り出して条件を組むこと、出てきた人を「どの業態のどの病棟で、何を担い、どこで、どの働き方を望むか」で読んで絞ること、勤務地と枠と層で送る順を付けること、条件と結果を記録して月に一度見直すこと、です。会社が持つのは、業態と病棟と業務と勤務地と夜勤の方針の決定、日勤の枠と両立の支援と復職の支援の用意、要件の必須と歓迎の区別（法令に関わる要件は専門家に確認）、看護部長と師長が担当者に話す時間、です。担当者が看護師の経歴（業態、病棟、業務）を読める経験があるかは、担当者を選ぶときに確かめます。担当者の経歴の見方は[担当者の経歴の見方](/media/rpo-tantousha-keireki/)に書いています。

## まとめ

- 先に**業態と病棟・業務・勤務地・夜勤の方針**を決める。四つで探す人が変わる
- 検索条件は**年数ではなく経験（業態・病棟の種類・業務・患者層）**で組み、**夜勤の枠と日勤の枠を分ける**。「夜勤可」を一律に必須にすると潜在看護師と子育て中の層が全部漏れる
- プロフィールは**「どの業態のどの病棟で、何を担い、どこで、どの働き方を望むか」**で読む。「病棟勤務」では中身が読めない
- 対象が少ないときは**業態は絞ったまま、勤務地を通える範囲まで広げ、潜在看護師と子育て中の層を厚くする**
- **通えない勤務地の人、働き方の希望が枠と合わない人には送らない**
- 条件は**病棟と枠と層ごとに分けて保存し、返信が来た人の共通点で月に一度直す**

## よくある質問

### 日勤の枠を設けると、夜勤の人手が足りなくなりませんか

日勤の枠で入った人が病棟に慣れ、子育ての状況が変われば、夜勤に入れるようになることがあります。加えて、日勤の人手が増えれば、夜勤ができる人の日勤の負担が減り、夜勤の回数の調整もしやすくなります。日勤の枠は夜勤の代わりではなく、病棟全体の人手を増やす入口です。夜勤の枠と日勤の枠の比率は、看護部長が病棟の状況で決めます。

### ブランクが長い潜在看護師は、戦力になりますか

ブランクの長さと、以前の業態で変わります。同じ業態の経験があって数年のブランクなら、研修と慣らしの期間と指導者があれば戦力になることが多い。復職の支援（研修の中身、慣らしの期間、指導者の配置、最初の数か月の受け持ちの数）を用意し、文面に事実で書きます。潜在看護師は競合が送っていないことが多く、支援を書ける施設にとっては有力な対象です。ブランクの上限は一律に決めず、研修で補える範囲を看護部長と決めます。

### 出てくる人が少なすぎます

「夜勤可」「ブランク〇年以内」「年数」で絞っているか、勤務地を狭く取りすぎているかを見ます。夜勤の枠と日勤の枠を分け、ブランクの上限を外し、年数を外し、勤務地を「通える範囲」（沿線、車での通勤圏）まで広げ、潜在看護師と子育て中の層を含めます。それでも少ないなら、隣の業態で転向の記述がある人を含めます。業態を広げるより、枠と勤務地と層で広げるほうが、合う人に届きます。
