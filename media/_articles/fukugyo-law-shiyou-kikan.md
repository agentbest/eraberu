副業で人事を受けていると、試用期間について会社から二つの誤解を聞きます。「試用期間中は自由に辞めてもらえる」と「試用期間中はまだ正式な社員ではない」です。どちらも、法令と裁判例の整理とは違います。結論を先に書くと、**厚生労働省（中央労働委員会）が公表しているあっせん事例の解説は「通常の試用期間中の契約関係に関しては、解約権留保付の労働契約がすでに成立していると解されている（三菱樹脂事件―最大判昭48・12・12）」としたうえで、「試用期間中の解約権の行使に関しては、通常の解雇より広い範囲における解雇の自由が認められるが、客観的に合理的な理由があり社会通念上相当と是認されるものでなくてはならない」と整理しています。**試用期間は「お試し」ではなく、解約権が留保されているだけの労働契約です。個別の判断は弁護士や労働基準監督署にご確認ください。解雇の枠組みは[解雇の要件](/media/fukugyo-law-kaiko/)に、内定の位置づけは[内定の法的性質](/media/fukugyo-law-naitei/)にまとめています。

## 試用期間中に、契約は成立している

**出発点。**上記のあっせん事例の解説は、裁判所がほぼ一貫して三菱樹脂事件の判断を踏襲し、「試用期間中には既に労働契約が成立しているとの前提に立って、試用期間中の契約関係は試用制度を前提に使用者に付与された**特別な解約権が留保されている労働契約**と解する見解を採用している」と説明しています。

**行使の基準。**同じ解説は、多くの裁判例が「試用期間中の解約権の行使に関し、通常の解雇より広い範囲における解雇の自由が認められるものの、その解約権は**試用制度の趣旨・目的に照らして客観的に合理的な理由があり社会通念上相当と是認されるものでなくてはならない**としている」とし、具体的な基準として「**採用当初知ることができなかったような事実が試用期間中に判明し、その者を引き続き雇用しておくのが適当でないと判断することに客観的合理性が認められるような場合**に解約権行使が相当であると認められると解している」と述べています。

**この一文が、実務の判定式です。**「採用当初知ることができなかった事実」かどうか。面接で確かめられたはずのことを、入社後に「思っていたのと違う」と言うのは、この基準から外れます。逆に、選考では見えなかった勤務態度や、経歴の記載と実際の技能の食い違いは、この枠に入り得ます。

**厚生労働省の裁判例ページも、同じ整理です。**「確かめよう労働条件」の試用期間のページは、試用期間を解約権が留保された契約と整理し、本採用拒否は留保された解約権の行使が許される場合でなければならない、としています。また、**労働能力や勤務態度等、業務への適性を判断するのに必要な合理的な期間を超える試用期間は公序良俗に反する**として無効とした裁判例（ブラザー工業事件）にも触れています。**長ければよい、というものではありません。**

**解雇の枠組みも重なります。**労働契約法第16条は「解雇は、客観的に合理的な理由を欠き、社会通念上相当であると認められない場合は、その権利を濫用したものとして、無効とする」と定めています。本採用拒否は、留保解約権の行使であって、この枠の中で見られます。

## 14日と30日、二つの日数

**解雇予告（労働基準法第20条第1項）。**「使用者は、労働者を解雇しようとする場合においては、少くとも三十日前にその予告をしなければならない。三十日前に予告をしない使用者は、三十日分以上の平均賃金を支払わなければならない」。ただし書きで、天災事変その他やむを得ない事由のために事業の継続が不可能となった場合と、労働者の責に帰すべき事由に基いて解雇する場合を除いています。

**適用除外（第21条）。**「前条の規定は、左の各号の一に該当する労働者については適用しない」として、一 日日雇い入れられる者、二 二箇月以内の期間を定めて使用される者、三 季節的業務に四箇月以内の期間を定めて使用される者、**四 試の使用期間中の者**を挙げています。ただし書きは「第四号に該当する者が**十四日を超えて引き続き使用されるに至つた場合**においては、この限りでない」としています。

**つまり、こうなります。**試用開始から14日を超えて使用されている労働者を解雇する場合は、第20条の解雇予告の規定が適用されます。14日を超えていない場合は適用されません。あっせん事例の解説も、この整理をそのまま述べています。

**ここを取り違えないこと。**「14日以内なら自由に解雇できる」ではありません。**予告の手続が要らなくなるだけ**で、解約権の行使が客観的に合理的な理由を欠き社会通念上相当と認められない場合に無効となり得る点は変わりません。手続の話と、理由の話は別です。

**解雇の理由の証明書（第22条第2項）。**「労働者が、第二十条第一項の解雇の予告がされた日から退職の日までの間において、当該解雇の理由について証明書を請求した場合においては、使用者は、遅滞なくこれを交付しなければならない」。第3項は「前二項の証明書には、**労働者の請求しない事項を記入してはならない**」と定めています。先のあっせん事例では、労働者が何度も請求したのに解雇理由証明書が発行されていないことが争点の一つになっていました。

**就業規則の記載（第89条第3号）。**「**退職に関する事項（解雇の事由を含む。）**」は、就業規則に記載しなければならない事項です。試用期間中の解雇についても、就業規則の解雇事由と結びつけて説明できる状態にしておきます。

**明示すべき事項。**労働基準法施行規則第5条第1項第一号の三は就業の場所及び従事すべき業務に関する事項を挙げ、職業安定法施行規則第4条の2第3項第二号の二は募集の段階で**試みの使用期間に関する事項**を明示することを求めています。募集時の明示は[募集時の労働条件明示](/media/fukugyo-law-boshuu-jouken/)にまとめています。

### エラベルの見解

担当する側から見ると、この相談で会社に伝えるべき一文は決まっています。**「試用期間は、判断を先送りするための期間ではなく、判断するための期間です」**。多くの会社は、試用期間を設けておきながら、その間に何を見るかを決めていません。三か月後に上司の印象だけで「合わなかった」と言い、そこから慌てて根拠を探し始めます。

実務でやることは、**試用期間中の評価の設計**です。何を見るのか。誰が見るのか。いつ面談するのか。記録をどこに残すのか。特に、途中の面談を一回ではなく複数回入れるのが効きます。一か月目、二か月目、終了前。ここで課題を本人に伝えた記録があるかどうかが、後から効きます。あっせん事例でも、会社側が「解雇手続上の一部不備と指導不足を認め」たことが解決の転換点になっていました。

もう一つ、実務で勧めているのは、**試用期間を採用の設計に折り返すこと**です。試用期間で問題が出る人は、選考でどこを見落としたのかが分かります。三人続けて同じ理由で躓いたなら、選考の質問か、職務要件の書き方に原因があります。試用期間の記録を採用の改善に回せると、この仕事は一段深くなります。エラベルは依頼側が担当者の経歴を見て選ぶ仕組みなので、この往復ができる人は、採用全体を任されやすくなります。

## 会社に渡すもの

副業の人事が作るのは、次の形です。個別の適否の判断は弁護士や労働基準監督署にご確認ください。

| 作るもの | 中身 |
|---|---|
| 期間の設定 | 何か月にするか。業務への適性を判断するのに必要な合理的な期間として説明できるか |
| 就業規則の条項 | 試用期間の定め、延長の可否と上限、本採用拒否の事由。第89条第3号の解雇の事由との対応 |
| 募集時の明示 | 試みの使用期間に関する事項。期間中と期間後で条件が異なる場合はそれぞれを示す |
| 評価項目 | 何を見るのか。職務要件から引く。人柄の印象ではなく、行動と成果で書く |
| 面談の設計 | 一か月目・二か月目・終了前。誰が、何を伝えるか |
| 記録の様式 | 指導した内容、本人の反応、改善の状況。日付を入れて残す |
| 14日の管理 | 開始日と、14日を超える日。第21条ただし書きの適用を誤らない |
| 予告の段取り | 30日前の予告か、平均賃金30日分の支払か。誰がいつ判断するか |
| 証明書の様式 | 第22条第2項の解雇理由証明書。請求しない事項を書かない |
| 延長の扱い | 延長するなら根拠規定があるか。本人への説明と同意の取り方 |

**延長には注意が要ります。**就業規則に根拠がないまま延長する運用は、後から争いになりやすい部分です。また、判断がつかないから延ばす、という使い方は、先に挙げた「判断するための期間」という考え方から外れます。取扱いの適否は弁護士にご確認ください。

**本採用拒否を決める前に、確かめる順番があります。**（一）選考の時点で知り得た事実ではないか。（二）就業規則の解雇事由のどれに当たるか。（三）指導と改善の機会を与えた記録があるか。（四）他の配置で活きる余地はないか。（五）14日を超えているか、予告または予告手当はどうするか。この順で並べると、会社は自分で判断の粗さに気づきます。

**懲戒とは別の話です。**あっせん事例では、会社が「懲戒解雇ではなく、試用期間中の普通解雇であるので、懲戒委員会の対象外と考えている」と主張し、労働者側は就業規則の懲戒手続が踏まれていないことを争点にしていました。就業規則の建て付けによって手続が変わるので、自社の規定を読んでから動きます。懲戒の枠組みは[懲戒処分の要件](/media/fukugyo-law-choukai/)にまとめています。

### エラベルの見解

外に出してよいのは、期間の設計、評価項目と面談の組み立て、記録の様式、14日と30日の管理表、証明書の様式、判断前に確かめる順番までで、「この本採用拒否が客観的に合理的な理由を欠き社会通念上相当と認められないか」といった個別の判断は、弁護士や労働基準監督署の範囲です。副業の人事が持つのは、手続と材料と設計であって、法的な結論ではありません。

担当する側から見ると、この領域で信頼を失う一番の近道は、会社に「大丈夫です」と言ってしまうことです。試用期間の相談は、たいてい切羽詰まった状態で来ます。来週で三か月になる、現場がもう限界だと言っている。ここで安心させたくなりますが、答えを出す立場ではありません。

代わりに出すのは、材料と時間です。記録を集める、就業規則の該当条項を特定する、14日と30日の日付を出す、弁護士に相談する段取りをつける。そして、**今回は間に合わないかもしれないと正直に言う**。そのうえで、次の人から同じことが起きないように評価と面談の仕組みを作る。この順番で動ける人は、短期では頼りなく見えても、半年後には会社の中核に近いところで仕事をしています。エラベルでは、依頼側が担当者を選び、担当者も条件を見て受ける形なので、この誠実さは条件の交渉でも効きます。

## まとめ

- 厚生労働省の資料は、試用期間中の契約関係を「**解約権留保付の労働契約がすでに成立している**」（三菱樹脂事件―最大判昭48・12・12）と整理している
- 解約権の行使は「**通常の解雇より広い範囲における解雇の自由が認められるが、客観的に合理的な理由があり社会通念上相当と是認されるもの**」でなければならない
- 具体的な基準は「**採用当初知ることができなかったような事実が試用期間中に判明し、その者を引き続き雇用しておくのが適当でないと判断することに客観的合理性が認められるような場合**」
- 労働基準法第21条第4号により、**試の使用期間中の者**には解雇予告の規定が適用されないが、**十四日を超えて引き続き使用されるに至った場合**は適用される
- 手続が不要になるのと、理由が要らなくなるのは**別の話**。労働契約法第16条の枠は変わらない
- **業務への適性を判断するのに必要な合理的な期間を超える試用期間**は公序良俗に反するとした裁判例がある。個別の判断は弁護士や労働基準監督署にご確認ください

## よくある質問

### 試用期間中なら、14日以内は自由に解雇できますか

労働基準法第21条は、試の使用期間中の者について第20条（解雇の予告）の規定を適用しないとしたうえで、十四日を超えて引き続き使用されるに至った場合はこの限りでないと定めています。したがって、14日以内であれば予告や予告手当の手続は要らない形ですが、解雇そのものの有効性は別の問題です。厚生労働省の資料は、試用期間中の解約権の行使について、通常の解雇より広い範囲における自由が認められるものの、客観的に合理的な理由があり社会通念上相当と是認されるものでなくてはならない、と整理しています。個別の判断は弁護士や労働基準監督署にご確認ください。

### 判断がつかないので試用期間を延長したいと言われました

延長については、まず就業規則に根拠となる定めがあるかを確かめます。定めがないまま延長する運用は、後から争いになりやすい部分です。また、厚生労働省の裁判例ページは、業務への適性を判断するのに必要な合理的な期間を超える試用期間は公序良俗に反するとして無効とした裁判例に触れています。実務としては、延長の可否を検討する前に、当初の期間に何を見て何を指導したのかを整理します。延長の可否と手続の個別の判断は、弁護士にご確認ください。

### 本採用しない場合、理由を書面で出す必要はありますか

労働基準法第22条第2項は、労働者が第20条第1項の解雇の予告がされた日から退職の日までの間において当該解雇の理由について証明書を請求した場合には、使用者は遅滞なくこれを交付しなければならないと定めています。第3項は、証明書に労働者の請求しない事項を記入してはならないとしています。したがって、請求があれば交付する義務がある前提で準備します。あわせて、就業規則には第89条第3号により退職に関する事項（解雇の事由を含む）を記載することとされているので、理由は就業規則の事由と対応づけて書けるようにしておきます。記載内容の個別の適否は、弁護士や労働基準監督署にご確認ください。
