採用がうまくいっていない。応募は少なく、来ても合わず、面接で落ち、内定を出せば辞退される。求人票も古い、媒体も惰性、面接も感覚、対応も遅い。「全部が問題」に見えて、何から手を付ければよいか分からない。動けないまま、また一か月が過ぎる。結論を先に書くと、**「全部が問題」は、手を付けられない状態です。「止まっている段階を一つ特定する」「費用ゼロで今週できることを三つやる」に分解すれば、動けます。全部を直そうとせず、最初の一週間で「一つの段階」と「三つの行動」を決め、一か月・三か月・半年の見取り図の中で、順に進めます**。詰まりの見つけ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に、効果の測り方は[施策の効果を測る仕組みがない](/media/rpo-kouka-sokutei/)にまとめています。

## 手を付けられない構造

何から手を付ければよいか分からないのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「全部が問題」に見える | 求人票、媒体、面接、対応。どれも直したいが、どれから直すかが無い |
| 止まっている段階を、見ていない | 応募が少ないのか、書類で落としすぎか、面接で落ちるか、辞退されるか。段階で見ていない |
| 数字が無い | 「うまくいっていない」の中身が、数字で見えない |
| 大きく直そうとしている | 「採用の仕組みを全部作り直す」と考えて、着手できない |
| 費用がかかると思っている | 「媒体を足す」「代行に頼む」「サイトを作る」と、費用のかかることばかり浮かぶ |
| 責任者の合意が無い | 「何から手を付けるか」を、人事が一人で悩んでいる。責任者と決めていない |
| 過去にやって効かなかった | 「求人票を直したが変わらなかった」で、次に手を付ける気力が無い |
| 時間が無い | 応募の対応で手一杯で、直す時間が取れない |

構造の大半は、「全部」で考えていることです。「一つ」と「三つ」に分解します。

## 最初の一週間でやること

動き出す最初の一週間です。

| 日 | やること |
|---|---|
| 一日目 | 応募者の表（無ければ媒体の管理画面と受信箱）から、直近三か月の「応募・書類通過・面接・内定・辞退」の数を、段階ごとに数える。日数（応募から返信、判断、面接、内定まで）も |
| 二日目 | 数えた数字を一枚に並べ、「止まっている段階」を一つ特定する。率が最も低い段階か、日数が最も長い段階 |
| 三日目 | 止まっている段階に対して、「費用ゼロで今週できること」を三つ挙げる（次の章） |
| 四日目 | 責任者に、一枚（数字、止まっている段階、三つの行動）を見せ、合意する。十五分 |
| 五日目 | 三つの行動のうち、一つ目を始める |

一週間の要点は、「数える→一つ特定する→三つ挙げる→合意する→一つ始める」です。この五つで、「全部が問題」は「一つの段階に、三つの行動」になります。

数える数字が無い場合、一日目は「今日から記録を始める」にします。過去の数字が無くても、止まっている段階は、応募の対応の実感（返信が遅れている、面接が組めない、辞退が多い）から仮に特定して、動きます。[採用の数字が取れていない](/media/rpo-data-nai/)。

## 止まっている段階の特定

段階ごとの数字から、止まっている段階を一つ特定します。

| 兆候 | 止まっている段階 | 最初に見る先 |
|---|---|---|
| 応募がほぼ無い | 応募 | 求人票の一行目と役割、経路の利用者の層 |
| 応募はあるが、書類で九割落ちる | 応募の質 | 要件の書き方（必須とあれば良い）、経路 |
| 書類は通るが、面接の前に辞退が多い | 応募から面接まで | 返信の速さ、日程の速さ、案内の中身 |
| 面接で大半が落ちる | 面接 | 書類の基準と面接の観点の対応、面接官の基準 |
| 最終まで進むが、内定を辞退される | 内定 | 内定までの速さ、条件のすり合わせ、動機づけ |
| 承諾したが、入社前に辞退 | 内定から入社 | 内定後の接点 |
| 入社したが、三か月で辞める | 受け入れ | 最初の三か月の型、教える人 |
| 各段階の日数が全部長い | 運用全体 | 担当、期限、判定の速さ |

特定の要点は、「一つに絞る」ことです。二つあれば、上流（応募に近いほう）から。上流を直さずに下流を直しても、流れてくる人が変わりません。

「全部の段階で少しずつ」に見える場合、共通の原因（担当がいない、期限が無い、判定が遅い）があります。その場合は、段階ではなく「運用全体」を止まっている段階として扱います。

## 費用ゼロで今週できる三つ

止まっている段階ごとに、費用ゼロで今週できる三つの例です。

| 止まっている段階 | 今週できる三つ |
|---|---|
| 応募 | 一、求人票の一行目を「何を決める役割か」に書き直す。二、社員に「〇〇ができる人、知り合いにいたら」と具体的に頼む。三、過去の応募者（同意のある人）に、募集の案内を送る |
| 応募の質 | 一、要件を「必須」と「あれば良い」に分けて書き直す。二、「入社後に教えること」を求人票に足す。三、「合わない人」を一つ書く |
| 応募から面接まで | 一、応募への返信を当日にする（担当と時間を決める）。二、面接官の枠を、来週と再来週に先に押さえる。三、面接の案内に、場所・形式・面接官・所要時間を入れる |
| 面接 | 一、観点を三つに絞り、質問を用意する。二、面接官向けの一枚を作り、次の面接から渡す。三、面接の直後に五分で判定を書く型を決める |
| 内定 | 一、最終面接の前に、社内で額と余地を決めておく。二、面接の最後に「〇日までに結果を」と期限を伝える。三、内定の条件を書面で、内訳を明記する |
| 内定から入社 | 一、承諾の翌日に、一緒に働く人から一言を送る。二、入社までの接点の予定を一枚にする。三、家族に説明できる材料を渡す |
| 受け入れ | 一、最初の一か月の予定を書面にする。二、教える人を一人決め、業務を調整する。三、毎日十分の接点を決める |
| 運用全体 | 一、応募を見る担当と時間を決める。二、各段階の期限（返信は当日、判断は三日、判定は当日）を決める。三、候補者の表を一つにして、日付の列を持つ |

三つの要点は、「費用ゼロ」と「今週」です。媒体を足す、代行に頼む、サイトを作る、は費用と時間がかかり、「今週」にはできません。まず、費用ゼロで今週できることを三つやり、翌月の数字を見ます。

三つは、一つずつ順に。同時に三つ変えると、何が効いたか分からなくなります。[施策の効果を測る仕組みがない](/media/rpo-kouka-sokutei/)。

### エラベルの見解

相談で最も多い失敗は、「全部が問題なので、採用の仕組みを全部作り直すと決めて、半年の計画を立て、計画を立てている間、採用は止まったまま」というものです。計画は立派でしたが、半年間、応募への返信は相変わらず三日後で、候補者は流れ続けていました。「止まっている段階」を「応募から面接まで」に特定し、「返信を当日に、枠を先に押さえ、案内に中身を入れる」の三つを今週やったら、翌月の辞退が減りました。全部の作り直しより、一つの段階の三つの行動でした。

見ていて差がつくのは、担当者が「今週できること」を出すかどうかです。「採用の全体を見直しましょう」と言う担当者と、「まず直近三か月の数字を数えて、止まっている段階を一つ特定し、費用ゼロで今週できることを三つ決めましょう。今日から」と、今週の行動に落とす担当者がいます。後者は、来週には動いています。

発注側にできるのは、担当者に「全体の改善」ではなく「今週できる三つ」を求めることです。

## 順番の決め方

三つをやった後、次に何をするかの順番です。

**翌月の数字を見て、効いたかを確認する。** 止まっていた段階の率と日数が変わったか。

**効いたら、次の段階へ。** 一つの段階が動くと、次の段階の詰まりが見えます。「応募から面接までの辞退が減ったら、今度は面接で落ちる率が目立つ」。次の段階に、また三つ。

**効かなかったら、三つを見直すか、段階の特定を見直す。** 「返信を当日にしたが辞退が減らない」なら、辞退の理由を聞いて、原因が速さ以外（案内の中身、面接官の印象）にあるかを見る。

**費用ゼロの三つが尽きたら、費用のかかる施策を検討する。** 求人票と速さと対応を直しても応募が来ないなら、経路（媒体、スカウト、紹介）の検討。それまでは、費用をかけない。[採用予算がない中で何から手を付けるか](/media/rpo-yosan-nai/)。

**責任者の判断が要るものは、材料を揃えて上げる。** 条件の見直し、要件の変更、面接官の指名、体制の追加。人事だけで決められないものは、数字と三つの行動の結果を材料に。

**「効いたこと」を型にする。** 「返信を当日にしたら辞退が減った」は、以後の運用の型。戻さない。

順番の要点は、「一つの段階が動いたら、次の段階へ」です。上流から下流へ、順に。

## 一か月・三か月・半年の見取り図

「全部」を、時間の軸に並べた見取り図です。

| 時期 | やること | 見る数字 |
|---|---|---|
| 最初の一週間 | 数える、止まっている段階を一つ特定、費用ゼロの三つを決める、責任者と合意、一つ始める | — |
| 一か月 | 三つを順にやる。応募の対応の運用（担当、時間、期限、表）を整える | 止まっていた段階の率と日数の変化 |
| 三か月 | 次の段階に三つ。求人票、面接の観点、内定の速さ、受け入れの型のうち、詰まりに合うものを順に | 段階ごとの率と日数。応募・面接・内定・辞退の数 |
| 半年 | 費用ゼロで直せるものが一巡。経路の見直し（媒体、スカウト、紹介）を、記録を根拠に検討。効いたことを型にする | 経路ごとの費用と面接に進んだ数。入社の数と定着 |
| 一年 | 体制（人事、代行、面接官）と、要員計画との対応を見直す。年間の採用の時期を設計 | 年間の応募・面接・内定・入社・定着。効いた施策の一覧 |

見取り図の要点は、「最初の三か月は費用ゼロ、半年から費用のかかる施策」です。費用ゼロで直せるものを直してから経路を検討すれば、経路の効果が正しく測れます。

見取り図は、責任者と共有します。「一週間で動き出し、三か月で段階を二つ直し、半年で経路を見直す」。時間の軸があれば、「全部を今すぐ」の焦りが減ります。

## 外注する場合の範囲

何から手を付ければよいか分からない問題を、採用代行に出す場合の範囲です。

**出せる工程。** 直近三か月の数字の集計と一枚の作成、止まっている段階の特定の案、費用ゼロで今週できる三つの案、責任者への一枚の作成、三つの実行（求人票の書き直し、返信の当日化、枠の調整、案内の文面、面接官向けの一枚、内定の書面の案、受け入れの型など）、翌月の数字の確認と次の段階の特定、一か月・三か月・半年の見取り図の作成と更新、効いた施策の型化、費用のかかる施策の検討の材料（半年から）。

**社内に残す判断。** 止まっている段階の確定、三つの行動の承認、責任者の判断が要る変更（条件、要件、面接官、体制）、費用のかかる施策の決定、見取り図の承認。

**外注の効きどころ。** 「何から手を付けるか」で止まっている会社は、「数える人」と「今週の行動に落とす人」がいません。担当者が数え、一つに特定し、三つに落とし、実行すれば、来週には動き出します。担当者は複数の会社の詰まりを見ているので、「この兆候ならこの段階、この段階ならこの三つ」の型を持ち込めます。費用のかかる施策は、費用ゼロの三つを一巡してから、記録を根拠に検討します。

**外注しても動かない場合。** 責任者が「全部を今すぐ」を譲らない、数字を数えさせない、費用ゼロの三つより先に媒体や代行を求める。社内の判断で、代行を替えても直りません。

「何から手を付けるか」は、一つの段階と三つの行動に分解すれば決まります。外注は、分解と実行を持ち込む手段です。

### エラベルの見解

担当する側から見ると、この相談で最も多いのは、「費用のかかることから考えている」ことです。「媒体を足すか」「代行に頼むか」「サイトを作るか」。どれも費用と時間がかかり、今週にはできず、決められないまま止まる。

費用ゼロで今週できることは、どの段階にも三つあります。返信を当日に、枠を先に押さえる、一行目を書き直す、面接官に一枚を渡す、内定の条件を書面で。費用ゼロの三つが、費用のかかる施策より効くことも多いです。

発注側にできるのは、「費用をかけるか」の前に、「費用ゼロで今週できる三つは何か」を担当者に聞くことです。

## まとめ

- 手を付けられないのは**全部が問題に見える・段階を見ていない・数字が無い・大きく直そうとする・費用がかかると思う・責任者の合意が無い・過去に効かなかった・時間が無い**構造
- 最初の一週間は**数える→止まっている段階を一つ特定→費用ゼロの三つを挙げる→責任者と合意→一つ始める**
- 止まっている段階は**応募・応募の質・応募から面接まで・面接・内定・内定から入社・受け入れ・運用全体**のどれか一つ。二つなら上流から
- 費用ゼロの三つは**段階ごとにある**（返信を当日に、枠を先に、一行目を書き直す、要件を分ける、面接官に一枚、内定を書面で、一か月の予定、担当と期限と表）。一つずつ順に
- 順番は**翌月の数字→効いたら次の段階→効かなければ見直す→費用ゼロが尽きたら費用のかかる施策→責任者の判断は材料を揃えて→効いたことを型に**
- 見取り図は**一週間で動き出す・一か月で三つと運用・三か月で次の段階・半年で経路を記録で検討・一年で体制と計画**。最初の三か月は費用ゼロ
- 外注できるのは**集計と一枚・段階の特定・三つの案・責任者への一枚・実行・翌月の確認・見取り図・型化・費用のかかる施策の材料**。社内に残るのは**段階の確定・三つの承認・責任者の判断が要る変更・費用の決定・見取り図の承認**

## よくある質問

### 本当に全部が問題で、一つに絞れません

全部に見えるとき、共通の原因があります。応募を見る担当がいない、各段階の期限が無い、判定が遅い。その場合、「運用全体」を止まっている段階として扱い、「応募を見る担当と時間を決める」「各段階の期限を決める」「候補者の表を一つにして日付の列を持つ」の三つから始めます。運用が回り始めると、段階ごとの数字が取れ、次に本当に止まっている段階が見えます。「全部」のまま動かないより、「運用全体」の三つから動きます。

### 費用ゼロの三つをやっても、変わりませんでした

翌月の数字で、止まっていた段階の率と日数を見ます。変わっていなければ、三つが段階に合っていなかったか、段階の特定が違っていたかです。辞退の理由を聞く、候補者の質問を記録する、紹介会社に聞く、で原因を一段深く見ます。「返信を当日にしたが辞退が減らない」なら、原因は速さ以外（案内の中身、面接官の印象、条件）です。三つを変えるか、段階を変えます。一度で当たらなくても、記録があれば次が決まります。

### 責任者が「早く媒体を足せ」「代行に頼め」と言います

費用のかかる施策の前に、費用ゼロの三つを提案します。「媒体を足しても、返信が三日後で面接が三週間先なら、応募は流れます。まず今週、返信を当日にし、枠を先に押さえ、案内に中身を入れます。翌月の数字を見て、それでも応募が足りなければ、媒体を検討します」。数字と時間の軸で示せば、責任者は「三つを先に」を認めやすくなります。費用ゼロで直せるものを直してから経路を検討すれば、経路の効果も正しく測れます。
