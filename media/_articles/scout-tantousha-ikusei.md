社内でスカウトを担当する人を、育てたい。ただ、何をどう教えればよいかが分からない。文面の良し悪しは「センス」に見え、任せると返信が来ないか、量を出そうとして雑になる。教える側も、自分がどうやっているかを言葉にできない。結論を先に書くと、**スカウト担当者は、「センス」ではなく四つの段で育ちます。「型で送る」（型に沿って一段落目だけ個別に書く）、「記録で振り返る」（送った結果を記録し、何が効いたかを見る）、「境目を判断する」（送るか送らないか、二通目を送るかの迷う候補者を判断する）、「型を直す」（記録から型と対象を直す）。三か月ごとに一段ずつ上げ、段ごとに渡すものと見るものを決めれば、誰でも育ちます**。体制の組み方は[社内のスカウト体制の作り方](/media/scout-taisei/)に、型の考え方は[文面の標準化と属人化の間](/media/scout-hyoujun-ka/)にまとめています。

## 担当者が育たない構造

スカウト担当者が育たず、任せられないままになるのは、次の構造で起きます。

| 構造 | 起きていること |
|---|---|
| 「センス」だと思っている | 文面の良し悪しを個人の資質と考え、教える方法を探していない |
| 最初から全部を任せる | 検索も文面も送信も返信も判断も、初日から一人で。何が悪かったか本人も分からない |
| 型が無い | 教える側が型を持っておらず、「こんな感じで」しか渡せない |
| 記録が無い | 送った結果が残らず、振り返る材料が無い。うまくいっても偶然、いかなくても偶然 |
| 見る人がいない | 送った文面を誰も見ず、良い点も悪い点も指摘されない |
| 段が無い | 「型で送る」ができる前に「型を直す」を求め、混乱する |
| 量だけを求める | 「月に何通」だけが目標で、質の見方が無い |

構造の大半は、「段を分けていない」ことです。四つの段に分け、一段ずつ上げれば、センスに関わらず育ちます。

## 育つ四つの段

スカウト担当者が育つ、四つの段です。段ごとに、できることと、期間の目安を示します。

| 段 | できること | 渡すもの | 期間の目安 |
|---|---|---|---|
| 一 型で送る | 承認済みの型に沿って、一段落目だけを個別に書き、決めた対象に送る。送信ログを当日に書く | 文面の型、対象の基準（絞りと順番）、送信ログの表、送ってはいけない一覧 | 最初の三か月 |
| 二 記録で振り返る | 週次で、自分の送信の返信率と返信の内容を見て、「何が効いたか」を一文で言える | 振り返りの型（週次の十五分）、指標の見方 | 次の三か月 |
| 三 境目を判断する | 送るか迷う候補者、二通目を送るか、追客するか、の境目を自分で判断し、理由を言える | 判断の基準と、迷ったときに聞く相手 | 次の三か月 |
| 四 型を直す | 記録から、型と対象の直すべき箇所を見つけ、直した型を提案できる。ABテストを設計できる | 型を直す権限、検証の型 | 一年目の後半以降 |

四つの要点は、「一段目は型に沿って書くだけ」ということです。一段目で「良い文面を書け」とは求めません。型に沿って、一段落目だけ個別に、当日に記録する。それができれば一段目は合格です。センスは要りません。

## 段ごとに渡すものと見るもの

段ごとに、教える側が渡すものと、見るものです。

| 段 | 渡すもの | 見るもの（週次） | 上がる条件 |
|---|---|---|---|
| 一 型で送る | 型、対象の基準、表、一覧。「一段落目は経歴の一点に触れる」の一つの指示 | 一段落目が経歴の一点に触れているか。名前と一点の誤りが無いか。当日に記録されているか。属性に触れていないか | 三か月、誤りが無く、記録が抜けず、一段落目が個別になっている |
| 二 記録で振り返る | 週次の振り返りの型（返信率、返信の内容、効いた点を一文） | 振り返りの一文が、記録に基づいているか。「なんとなく」でなく数字と内容で言えているか | 三か月、毎週の一文が記録に基づき、翌週に一つ変えている |
| 三 境目を判断する | 判断の基準（外せない一つ、二通目の条件、追客の段階）。迷ったときに聞く相手 | 境目の判断の理由が言えるか。基準と合っているか。聞くべきときに聞いているか | 三か月、判断の理由が基準で説明でき、大きな誤りが無い |
| 四 型を直す | 型を直す権限（提案→承認）、検証の型 | 直す提案が記録に基づいているか。一箇所ずつか。検証の設計ができているか | 提案した型が、検証で効いた |

見るものの要点は、「週次で、決めた箇所だけ見る」ことです。全部を見ると、教える側の稼働が尽きます。一段目なら「一段落目と誤りと記録」だけ。二段目なら「振り返りの一文」だけ。見る箇所を絞れば、週に十五分で足ります。振り返りの型は[週次の振り返りで見る数字](/media/scout-furikaeri/)に書いています。

## 教える側の役割

担当者を育てる、教える側（人事の責任者、先輩の担当者、代行の担当者）の役割です。

| 役割 | 内容 |
|---|---|
| 型を渡す | 自分の頭の中にある「こんな感じ」を、型として文書にする。型が無ければ、先に型を作る |
| 週次で見る | 段ごとに決めた箇所を、週に一度、十五分で見る。良い点を一つ、直す点を一つ |
| 理由を聞く | 「なぜこの一段落目にしたか」「なぜこの候補者に送ったか」を聞く。答えられれば育っている |
| 境目を一緒に判断する | 三段目までは、迷った候補者を一緒に見て、判断の理由を言葉にして渡す |
| 段を上げる判断 | 三か月ごとに、上がる条件を満たしたかを見て、次の段の渡すものを渡す |
| 直す権限を渡す | 四段目で、型を直す提案を受け、検証して承認する。担当者の型になっていく |
| 自分の型を疑う | 担当者の記録から、自分の型が効いていない箇所が見えたら、直す |

教える側の要点は、「良い点を一つ、直す点を一つ」です。直す点だけを指摘すると、担当者は型から外れる怖さで、一段落目まで定型にします。良い点を一つ言うと、その方向に伸びます。

### エラベルの見解

相談で最も多い失敗は、「人事の新しい担当者に、初日から『このアカウントで、この役割に、月に百通送って』と任せ、三か月後に返信率がゼロに近く、本人は『向いていない』と言って辞めた」というものです。段が無く、型も記録も無く、見る人もいませんでした。型と対象の基準と表を渡し、「一段落目だけ個別に」の一つの指示にし、週次で一段落目と誤りと記録だけを見て、良い点を一つ言う形にしたら、三か月で一段目を上がり、半年で振り返りの一文が言えるようになりました。センスではなく、段と型と週次の十五分でした。

見ていて差がつくのは、教える側が「自分の型を文書にしているか」です。「見て覚えて」「こんな感じで」と渡す教える側と、「型はこれ、対象の基準はこれ、一段落目はこう書く」と文書で渡す教える側がいます。後者の担当者は、三か月で一段目を上がります。前者の担当者は、一年経っても「センスが無い」と言われています。

発注側にできるのは、教える側に「型を文書にしてから、担当者に渡してください」と頼むことです。文書が無ければ、育成は始まっていません。

## 担当者が一人のときの育て方

社内に教える側がおらず、担当者が一人で始める場合の育て方です。

| 項目 | 内容 |
|---|---|
| 型を外から借りる | 代行の担当者に型を作ってもらい、それに沿って送る。または、公開されている型の考え方から自分で作り、送る前に誰かに読んでもらう |
| 記録を自分で見る | 週次の振り返りの型で、自分の送信を自分で見る。一文を書く |
| 見る人を作る | 責任者か、人事以外の誰かに、週に一度、一段落目を三通だけ読んでもらう。「自分宛てに見えるか」を聞く |
| 境目は聞く | 迷った候補者は、送らずに責任者に聞く。理由を聞き、記録する |
| 代行の担当者を教える側にする | 代行に出している場合、担当者の育成を代行の範囲に入れる。型を渡し、週次で見てもらう |
| 段を自分で上げる | 三か月ごとに、上がる条件を自分で確認する。満たしていなければ、同じ段を続ける |

一人のときの要点は、「見る人を作る」ことです。誰にも見られない送信は、良くも悪くもならず、同じことを繰り返します。一段落目を三通、週に一度、誰かに読んでもらうだけで、変わります。

## 育たないときの見直し

三か月経っても段が上がらないときの、見直しの観点です。担当者の資質の前に、渡したものと見方を疑います。

| 兆候 | 見直し |
|---|---|
| 一段落目が定型のまま | 「経歴の一点に触れる」の指示が伝わっていない。一点の例を三つ示す。良い例と悪い例を並べる |
| 名前や一点の誤りが続く | 送る前の確認の手順が無い。「名前と一点を見てから送る」を手順にする |
| 記録が抜ける | 記録の表が使いにくいか、当日に書く時間が無い。表を簡素にし、書く時間を予定に入れる |
| 振り返りの一文が「なんとなく」 | 指標の見方が渡っていない。返信率と返信の内容を、表で見せる |
| 境目で聞かずに送る | 聞く相手が決まっていないか、聞きにくい。聞く相手と、聞いてよいことを明示する |
| 量が出ない | 型が複雑か、対象の基準が曖昧で選定に時間がかかる。型を簡素に、基準を一つに |
| 本人が「向いていない」と言う | 段を下げる。一段目からやり直し、小さくできることを積む |

見直しの要点は、「担当者の資質を疑う前に、渡したものを疑う」ことです。型が複雑、基準が曖昧、見る箇所が多い、聞く相手がいない。この四つのどれかで、大半の「育たない」は説明できます。

## 外注する場合の範囲

スカウト担当者の育成を、スカウト代行に出す場合の範囲です。

**出せる工程。** 型の作成（文面、対象の基準、送信ログの表、判断の基準）、段ごとに渡すものの文書化、週次の確認（段ごとに決めた箇所を見て、良い点と直す点を一つずつ）、境目の判断の同席と理由の言語化、段を上げる判断の材料の整理、振り返りの型の作成と伴走、四段目の型の提案の検証、育たないときの見直しの提案、社内の担当者が独り立ちした後の型の引き継ぎ。

**社内に残す判断。** 担当者の選定と、育成に充てる稼働の確保、型の承認、段を上げる決定、境目の最終判断（社内の判断が要るもの）、直す権限をいつ渡すかの決定、教える側（社内の責任者）の関与の程度。

**外注の効きどころ。** 育成は、「型を渡し、段で分け、週次で決めた箇所を見て、三か月で上げる」運用で、社内では「センスに任せる」か「初日から全部」になりやすい工程です。担当者が型を作り、段ごとの渡すものを文書にし、週次で見て、境目を一緒に判断すれば、社内の担当者は三か月ごとに段を上がります。担当者は複数の会社で担当者の育成を見ているので、「この段でつまずく人はここが抜けている」「この指示で一段落目が変わる」を持ち込めます。ただし、担当者の選定と、稼働の確保と、段を上げる決定は、社内でしか行えません。

**外注しても動かない場合。** 育成に充てる稼働を社内が確保しない（担当者が他の業務で手一杯）、型を承認しない、週次の確認の時間を取らない、量だけを求めて質の段を無視する。社内の判断で、代行を替えても直りません。

スカウト担当者は、型と段と週次の十五分で育ちます。センスは要りません。外注は、型の作成と段の文書化と週次の確認と境目の判断を担い、社内の担当者が段を上がるのを支える手段です。

### エラベルの見解

担当する側から見ると、育成の相談で最も多いのは、「一段目を飛ばして、二段目や三段目を求めている」ことです。型に沿って送ることができていないのに、「返信率を見て改善して」「送るかどうかは自分で判断して」と言われる。担当者は、型が無いので改善のしようがなく、基準が無いので判断のしようがなく、止まります。

一段目は、地味です。型に沿って、一段落目だけ個別に、当日に記録する。三か月、それだけ。ただ、一段目が固まった担当者は、二段目以降が速い。飛ばした担当者は、どこかで一段目に戻ります。

発注側にできるのは、最初の三か月、担当者に「型に沿って送り、当日に記録する」以外を求めないことです。

## まとめ

- 育たないのは**センスだと思う・最初から全部・型が無い・記録が無い・見る人がいない・段が無い・量だけ**構造
- 段は**型で送る（三か月）→記録で振り返る（三か月）→境目を判断する（三か月）→型を直す（後半以降）**。一段目は型に沿って書くだけ
- 段ごとに**渡すもの（型・振り返りの型・判断の基準・直す権限）と見るもの（一段落目と誤りと記録・一文・判断の理由・提案）**を決める。週次で決めた箇所だけ
- 教える側は**型を渡す・週次で見る・理由を聞く・境目を一緒に・段を上げる・権限を渡す・自分の型を疑う**。良い点を一つ、直す点を一つ
- 一人なら**型を外から・記録を自分で・見る人を作る・境目は聞く・代行を教える側に・段を自分で**。見る人を作る
- 育たないなら**指示の伝わり・確認の手順・表と時間・指標の見方・聞く相手・型と基準の簡素化・段を下げる**。資質の前に渡したものを疑う
- 外注できるのは**型・段の文書化・週次の確認・境目の同席・上げる材料・振り返りの伴走・提案の検証・見直し・引き継ぎ**。社内に残るのは**選定と稼働・型の承認・上げる決定・最終判断・権限の時期・関与の程度**

## よくある質問

### 文面が上手い人と、そうでない人の差は、本当に埋まりますか

「上手い」の中身を分けると、埋まります。上手い人がやっているのは、型に沿い、一段落目で経歴の一点に触れ、送った結果を見て次を変える、の三つで、それぞれ一段目、一段目、二段目の内容です。「センス」に見えるのは、この三つを無意識にやっているからです。三つを段に分けて渡せば、無意識でなくてもできます。埋まらないのは、型が無く、記録が無く、見る人がいない場合です。

### 育成に、教える側の稼働はどれくらい要りますか

型を作る時間（最初に数時間〜一日）と、週次の確認（十五分）と、三か月ごとの段を上げる判断（三十分）です。週次の確認は、段ごとに決めた箇所だけを見るので、十五分で足ります。全部を見ようとすると、教える側の稼働が尽き、確認が止まり、育成も止まります。見る箇所を絞ることが、教える側の稼働を守ります。

### 代行に出しているので、社内に担当者を育てる必要はありませんか

「送る」「返す」「記録する」を代行に出しているなら、社内の担当者に要るのは「決める」（型の承認、対象の承認、境目の最終判断）の力です。これは、四つの段の三段目と四段目の内容で、代行の担当者と一緒に境目を判断し、型の提案を検証することで身につきます。代行に出していても、社内に「決める」人が育っていないと、代行を替えたときや内製に戻すときに、ゼロからになります。内製に戻す手順は[内製へ戻すときの手順](/media/scout-daikou-uchisei-ikou/)に、ノウハウの残し方は[ノウハウを社内に残す](/media/scout-daikou-nouhau/)に書いています。
