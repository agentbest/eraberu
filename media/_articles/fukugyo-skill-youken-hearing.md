依頼側に「どんな人を採りたいですか」と聞くと、「良い人」「即戦力」「うちに合う人」が返ってきます。そのまま検索条件や求人票にすると、対象は絞れず、面接でずれ、依頼側からは「思っていた人と違う」と言われます。要件を引き出すヒアリングは、聞く項目の多さではなく、「誰に、何を軸に、どの順で聞くか」で決まります。結論を先に書くと、**採用要件のヒアリングは、経営者・現場の責任者・いまうまくやっている人の三者に別々に聞き、「この役割で最初に困ることは何か」を軸に、抽象語を一段掘り、聞いたことを必須（経歴で読める）・歓迎・面接で確かめる項目の三つに切り分けて、一枚に戻して確認する型で行います。**要件の整理を案件として受ける形は[採用要件の整理の副業案件](/media/fukugyo-youken-seiri-fukugyo/)に、ヒアリング全般の磨き方は[ヒアリング力の磨き方](/media/fukugyo-hearing-skill/)に書いています。ここでは、要件を引き出す場面の型に絞ります。

## 要件が「良い人」で止まる理由

依頼側が要件を言葉にできないのは、考えていないからではなく、聞かれ方が「人物像」だからです。人物像を聞かれると、人は理想を並べます。理想は経歴で読めません。

| 聞き方 | 返ってくる答え | 検索と面接で使えるか |
|---|---|---|
| 「どんな人を採りたいですか」 | 良い人、即戦力、主体性のある人 | 使えない |
| 「この役割で、入ってすぐに何をしてもらいますか」 | 〇〇の案件を引き継いで、〇〇を一人で回してほしい | 使える（経歴で読める） |
| 「その仕事を、いま誰がどうやっていますか」 | 〇〇さんが、〇〇と〇〇を兼務で | 使える（実態が分かる） |
| 「その人が抜けたら、最初に何が困りますか」 | 〇〇の顧客への対応が止まる | 使える（必須の軸になる） |

人物像ではなく、仕事と困りごとを聞くと、要件は経歴の言葉になります。

## 聞く相手を三者に分ける

一人に聞いた要件は、その人の視点の要件です。三者に別々に聞き、食い違いを並べます。

| 相手 | 持っている要件 | 聞く軸 |
|---|---|---|
| 経営者 | この先の事業に要る人。「こうなってほしい」 | なぜ採るか、採れないと何が困るか、譲れない条件と譲れる条件 |
| 現場の責任者 | いま一緒に働いて困らない人。「これができないと回らない」 | 入ってすぐ任せること、最初に困ること、前に合わなかった人は何が合わなかったか |
| いまうまくやっている人 | 実際の仕事の中身。「これはすぐできた、これは時間がかかった」 | 入った頃にすぐできたことと時間がかかったこと、何が分かっていれば楽だったか |

一緒に聞くと、現場は経営者の前で本音を言わず、いまうまくやっている人は上司の前で自分の仕事を小さく言います。別々に聞きます。時間が取れないときは、いまうまくやっている人を優先します。必須と歓迎の境目が、最も具体に出るからです。

### エラベルの見解

担当する側から見ると、要件のヒアリングで最も差がつくのは、「いまうまくやっている人に聞けるか」です。経営者と現場の責任者だけに聞いた要件は、「欲しい人」の話で、実際の仕事の中身が薄い。いまうまくやっている人に「入ってすぐできたことと、時間がかかったこと」を聞くと、「〇〇の操作はすぐ覚えたが、〇〇部門との調整は半年かかった」と出て、〇〇の調整の経験が必須、〇〇の操作は歓迎、と分かれます。エラベルで担当者を選ぶ企業には、「経営者と現場の責任者に加えて、いまその仕事をうまくやっている方に三十分ください」と、私たちから先に伝えています。受ける側がその場で使える判断としては、聞き取りの日程を組むとき、いまうまくやっている人の枠を最初に押さえること。後回しにすると、忙しくて取れないまま要件が固まります。

## 問いの順番：「最初に困ること」を軸に

三者に共通して聞くのは「この役割で最初に困ることは何か」です。この一問が、必須と歓迎を分ける軸になります。順番を守ります。

| 順 | 問い | 引き出したいもの |
|---|---|---|
| 一 | なぜ採るのですか（欠員、増員、新しい仕事） | 採る理由。要件の重心 |
| 二 | 入ってすぐ、何を任せますか | 最初の仕事。経歴で読む項目の元 |
| 三 | その仕事で、最初に困ることは何ですか | 必須の軸 |
| 四 | いま、その仕事を誰がどうやっていますか | 実態。「幅広く」の中身 |
| 五 | 前に合わなかった人は、何が合わなかったのですか | 必須の裏側。面接で確かめる項目 |
| 六 | 譲れない条件と、実は譲れる条件は | 条件の幅 |
| 七 | 三か月後、何ができていれば「合っていた」と思いますか | 到達点。評価とつながる |

止まりやすいのは、一を飛ばして二から入るときです。なぜ採るかで、要件の重心が変わります。欠員なら前任者の仕事、増員なら分担、新しい仕事なら立ち上げの経験です。

## 抽象語を一段掘る

答えに抽象語が出たら、その場で一段掘ります。掘らずに書いた要件は、検索でも面接でも使えません。

| 抽象語 | 掘る問い | 出てくる言葉 |
|---|---|---|
| 主体性 | 「主体的だった人は、具体的に何をしましたか」 | 決まりの無いことを自分で決めて進めた |
| コミュニケーション能力 | 「誰と、何を、どう合わせる場面ですか」 | 他部署と対立した件を合意まで持っていった |
| 即戦力 | 「入って一週間で、何ができていてほしいですか」 | 〇〇の案件を、教えなくても一人で回せる |
| 経験〇年 | 「〇年あると、何ができると思いますか」 | 一人で案件を持ち、トラブルを自分で収めた |
| うちに合う | 「合わなかった人は、何が違いましたか」 | 決まりの無い環境で止まってしまった |

掘った言葉は、経歴で読める（担った仕事の中身）か、面接で確かめる（行動の場面）かのどちらかになります。年数と学歴と肩書は、掘ると中身の言葉に変わり、たいてい歓迎に落ちます。

## 必須・歓迎・面接で確かめる項目に切り分ける

聞いたことを、三つに分けます。分け方の基準は「無いと最初に困るか」です。

| 分類 | 基準 | 書き方 |
|---|---|---|
| 必須 | 無いと最初に困る。経歴で読める | 担った仕事の中身の言葉（「〇〇を一人で回した」） |
| 歓迎 | あれば助かる。入ってから覚えられる | 製品名、業界、資格、年数 |
| 面接で確かめる項目 | 経歴で読めない。性質や動き方 | 「〇〇した場面を具体的に語れる」の形 |

必須は三つから五つに絞ります。多いと対象が消え、少ないと面接でずれます。「必須をこのまま置くと、出てくる人の数はこの構造になります」と、市場の構造を添えて依頼側に決めてもらいます。切り分けの型は[採用要件の整理の副業の実務](/media/fukugyo-youken-seiri-shigoto/)に書いています。

### エラベルの見解

相談で最も多い思い込みは、受ける側の「必須が多いのは依頼側が譲らないからだ」というものです。実際には、必須が多いのは、聞き手が「その条件が無いと、最初に何が困りますか」と一つずつ聞いていないからです。「経験十年、〇〇の資格、〇〇業界」と並んだとき、「十年あると何ができるのですか」と聞けば「一人で案件を回せる」に変わり、それは経歴の「一人で担当した範囲」で読めて、年数は歓迎になります。資格は「無いと法令上できない仕事か」で必須か歓迎かが決まります。譲らない条件を否定せず、「困ること」に置き換えて並べると、依頼側が自分で減らします。受ける側がその場で使える判断としては、必須の候補が出るたびに「それが無いと、最初に何が困りますか」を一回ずつ挟むこと。答えが出ない条件は、歓迎に置きます。

## 聞いた内容を一枚に戻す

聞きっぱなしにせず、当日か翌日に一枚に戻して、三者に確認します。戻すのは、解釈ではなく、聞いた言葉と切り分けの案です。

| 一枚の項目 | 中身 |
|---|---|
| なぜ採るか | 一文で |
| 入ってすぐ任せること | 三つまで |
| 最初に困ること | 一文で |
| 必須（経歴で読める言葉） | 三〜五つ |
| 歓迎 | 製品名、業界、資格、年数など |
| 面接で確かめる項目 | 「〇〇した場面を語れる」の形 |
| 三者の食い違い | 誰が言ったかと、最初に困ることとの関係。裁定しない |
| 決めてもらうこと | 優先、条件の幅、必須の数 |

食い違いは、人の対立ではなく、軸との距離の問題として並べます。決めるのは依頼側です。一枚の型は[議事録の残し方](/media/fukugyo-gijiroku/)の考え方と共通です。

## 基準にしてはいけない項目が出たとき

聞き取りの中で、性別、年齢、国籍、家族の状況など、募集や採用で基準にすることに法令上の決まりがあると一般に整理されている項目が口にされることがあります。その場で議論せず、要件の一枚には書かず、「その点は要件には入れられません。専門家にご確認ください」と添えます。何が該当するかは、依頼側の決まりと専門家の確認に従います。個別の判断は専門家にご確認ください。線の詳細は[副業で法令違反をしないために](/media/fukugyo-ihan-shinai/)に書いています。

## よく起きる詰まりと直し方

| 詰まり | 直し方 |
|---|---|
| 経営者が出てこない | 三十分でよいので、「なぜ採るか」「採れないと何が困るか」「譲れない条件」の三つだけを聞く。取れなければ、要件を「経営者の確認待ち」と明記して仮に置く |
| 現場が前の担当者の悪口を長く話す | 「その方に足りなかったものは、経歴のどこで読めたと思いますか」と、要件の言葉に戻す。悪口は一枚に書かない |
| 「性質」の言葉が要件に入りたがる | 面接で確かめる項目の欄に移し、「〇〇した場面を語れる」の形に置き換えて渡す |
| 三者の食い違いが大きい | 裁定せず、軸（最初に困ること）との距離で並べ、依頼側に優先を決めてもらう |
| 聞き取りの時間が短い | 問いの順番の一〜三だけを聞き、残りは一枚で確認する形にする |

## まとめ

- 要件が「良い人」で止まるのは、**人物像を聞いているから**。仕事と困りごとを聞く
- **経営者・現場の責任者・いまうまくやっている人に別々に**聞く。いまうまくやっている人の枠を最初に押さえる
- 軸は**「この役割で最初に困ることは何か」**。問いは「なぜ採るか→入ってすぐ任せること→最初に困ること→いまの実態→合わなかった人→条件の幅→三か月後」の順
- **抽象語は一段掘る**。年数と学歴と肩書は、掘ると中身の言葉に変わり、歓迎に落ちる
- **必須（経歴で読める）・歓迎・面接で確かめる項目**に切り分け、必須は三〜五つ。「無いと最初に何が困るか」を一回ずつ挟む
- 聞いた内容は**一枚に戻し、食い違いは軸との距離で並べ、決めるのは依頼側**
- **基準にしてはいけない項目は書かず、専門家に**。個別の判断は専門家にご確認ください

## よくある質問

### 依頼側が「要件は求人票に書いてあるので、見てください」と言います

求人票を読んでから、「この必須が無いと、最初に何が困りますか」を一つずつ聞きます。求人票の必須は、前に誰かが書いた理想であることが多く、実態と離れています。いまうまくやっている人に「入ってすぐできたことと時間がかかったこと」を聞くと、求人票の必須のうち、実際に必須なのはいくつかが分かります。求人票を否定せず、実態で照らす形にします。

### 職種の知識が浅く、掘る問いが思いつきません

職種の知識より、「それが無いと最初に何が困りますか」「その仕事を、いま誰がどうやっていますか」「入ってすぐできたことは何ですか」の三つの問いで、依頼側に語ってもらいます。職種に詳しくないことは、「分からないので、具体的に教えてください」と言えることでもあり、依頼側の言葉で要件が出ます。聞いた言葉を、そのまま一枚に写します。

### 一枚に戻したら、依頼側が「これだけ？」と言いました

「これだけ」が正しい状態です。必須は三〜五つ、歓迎は別枠、性質は面接で、という形は、検索と書類選考と面接で使える形で、長い人物像より役に立ちます。「必須を増やすと、出てくる人がこの構造で減ります。面接で確かめる項目を厚くするほうが、面接でずれません」と、使い道で説明します。それでも増やしたい項目は、「無いと最初に何が困るか」を聞き、答えがあれば必須に、無ければ歓迎に置きます。
