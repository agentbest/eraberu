エネルギー業界の会社（電力、ガス、石油、再生可能エネルギー、新電力とエネルギーサービス）が「人が採れない」と言うとき、その言葉には五つの違う問題が混ざっています。技術職の要件が資格の名前だけで、同業の掲載型にしか出しておらず、隣接から読めない。拠点の勤務地と転勤の型と住居の情報が求人票に無く、応募の前で止まる。中途の求人票と面接の観点が新卒の流用で経験者に刺さらず、承認の段で日数が延びる。再エネの案件が決まってから募集して、開始に間に合わない。新電力の法人営業が、返事の遅さで流れて、目標で離れる。どれが原因かで、直す場所も、外に出せるかも変わります。結論を先に書くと、**エネルギー業界の採用課題は、要件・勤務地・中途の型と日数・時期・営業の五つに分解し、自社の記録（職種と経路ごとの応募、応募の前で止まった問い合わせの理由、経験者の応募の比率と段ごとの日数、案件の決定から入社までの日数、営業の返事の日数と離職の理由）で詰まりを一つに特定してから直します。**「人が採れない」を一つの問題として扱うと、紹介会社に費用を使って同業から採り、転勤で離れ、また同業から採る、という往復になります。代行に出す工程の切り分けは[エネルギー業界の採用代行](/media/rpo-energy-rpo/)に書いています。ここでは、エネルギー業界の課題を分解する順番に絞ります。

## 「採れない」に混ざっている五つ

| 課題 | 現れ方 | 記録で見えること |
|---|---|---|
| 要件 | 技術職の応募がほぼ無い。「有資格者は同業にしかいない」 | 職種と経路ごとの応募。要件が資格の名前だけ |
| 勤務地 | 問い合わせはあるが応募まで来ない。入社後に転勤で離れる | 応募の前で止まった理由が「勤務地」「転勤」「住居」。離職の理由が「転勤」 |
| 中途の型と日数 | 経験者の応募が少ない。内定の前に「他社で決まった」 | 経験者の比率。段ごとの日数。辞退の理由が「遅い」「見えない」 |
| 時期 | 案件が決まってから募集し、開始に間に合わない | 案件の決定から入社までの日数。通年の母集団の有無 |
| 営業 | 新電力の営業の募集が止まらない。返事が数日後 | 応募から返事までの日数。離職の理由が「目標」「商品」 |

五つは同時に起きることもありますが、直すのは一つずつです。

## 分解の順番

| 順 | 見ること | 判断 |
|---|---|---|
| 一 | 要件の書き方と、職種と経路ごとの応募 | 資格の名前だけで同業にしか出していなければ要件 |
| 二 | 応募の前で止まった理由、離職の理由 | 「勤務地」「転勤」「住居」なら勤務地 |
| 三 | 経験者の比率、段ごとの日数、辞退の理由 | 「遅い」「見えない」なら中途の型と日数 |
| 四 | 案件の決定から入社までの日数 | 開始に間に合っていなければ時期 |
| 五 | 営業の返事の日数と離職の理由 | 数日後で「目標」なら営業 |

一が最初なのは、要件が資格の名前だけだと、他を直しても隣接から読めず、母集団が同業に限られるからです。ファネルの並べ方は[採用ファネルのどこが詰まっているか分からない](/media/rpo-funnel/)に書いています。

### エラベルの見解

エネルギー業界で最も多い詰まりは「要件」で、しかも「有資格者は同業にしかいない」で市場の狭さのせいにされていることです。資格は前提でも、経験の中身を「設備・保守の範囲・規模」に分解すると、プラント、ビルの設備、建設の電気、製造の生産設備からも読めます。資格を「必須」「入社後に取得」「歓迎」に分け、取得の支援（期間、費用の扱い、取れなかった場合）を求人票に書くと、隣接から来る人が増えます。同業の掲載型にだけ出して「応募が無い」のは、市場が狭いのではなく、届く言葉と場所に出していないからです。エラベルで担当者を選ぶ企業には、「技術職の要件は、資格の名前だけになっていませんか」を、私たちから先に聞いています。名前だけなら、経路を増やす前に要件の言い換えです。要件の作り方は[電気設計の採用要件の作り方](/media/rpo-denki-sekkei-youken/)に書いています。

## 要件の課題：資格の名前だけで同業にしか出していない

| 状態 | 直し方 |
|---|---|
| 要件が「〇〇の資格を持つ経験者」だけ | 「〇〇の設備で、〇〇の保守を、〇〇の規模で担った経験」に分解し、必須と歓迎に分ける |
| 資格が全て必須 | 会社と専門家で保安の体制と配置を整理し、「必須・入社後に取得・歓迎」に分ける |
| 取得の支援が書かれていない | 支援の中身（期間、費用の扱い、取れなかった場合）を決め、求人票に |
| 同業の掲載型にしか出していない | プラント、ビルの設備、建設の電気、製造の生産設備の隣接に届く経路を開く |

資格と保安と配置は、法令上の整理があると一般に整理されているため、会社と専門家で整理します。個別の判断は専門家にご確認ください。要件の言い換えは[採用要件の定義の進め方](/media/rpo-task-youken-teigi-susumekata/)に書いています。

## 勤務地の課題：転勤と住居の情報が無い

| 求人票に無いこと | 書き方 |
|---|---|
| 勤務地 | 「勤務地：各事業所」ではなく、拠点の名前と場所 |
| 転勤の型 | 「地域の中か全国か、期間の目安、本人の希望の扱い」の実態 |
| 住居 | 「会社が用意するか、探す手伝いをするか。社宅と手当の考え方」 |
| 移動と生活 | 「車が要るか、買い物と病院と学校の距離」 |
| 家族 | 「家族と来られるか、単身の場合の帰省の扱い」 |
| 当直と呼び出し | 「当直の回数、呼び出しの頻度、休みの取り方」の実態 |

勤務地と生活の情報を一枚にして求人票に添えると、応募の前で止まっていた人が応募まで来ます。地域の採用の組み直しは[地方拠点の採用が進まない](/media/rpo-chihou-saiyo/)に書いています。

## 中途の型と日数の課題：新卒の流用と承認の段

| 新卒の型 | 中途の型 |
|---|---|
| 求人票は会社紹介と理念 | 担当の設備と範囲、裁量、一緒に働く人、最初の三か月 |
| 面接の観点は地頭と人柄 | 経験の照合（設備、範囲、規模、保安の体制） |
| 経路は新卒の媒体と学校 | 同業と隣接、専門の集まり、知人、紹介 |
| 段が多く、決裁は候補者ごと | 段は少なく、決裁の日程を月の初めに決めて逆算 |

段ごとの日数を記録し、「手順の日数」と「待ちの日数」を分けます。長いのは待ちであることが多く、枠を先に預け、書類を先に揃え、決裁の日程を先に決めると縮みます。速さの直し方は[日程調整が遅くて候補者が流れる](/media/rpo-nittei-chousei-osoi/)に、中途の型の分け方は[金融業界の採用課題](/media/rpo-kinyu-kadai/)に書いています。

### エラベルの見解

エネルギー業界で見落とされやすいのは「勤務地」が応募の前で止めていることです。技術職の要件を言い換えて隣接から読めるようにしても、「勤務地：各事業所」「転勤あり」だけでは、候補者は家族と生活を想像できず、応募の前で止まります。問い合わせの記録を見ると、「どこに住むのか」「転勤はどれくらいの頻度か」「家族はどうなるか」で止まっている。拠点の名前、転勤の型、住居と手当の考え方、家族の情報を一枚にして添える。転勤の型を「地域の中で、期間の目安はこれくらい、希望は聞く」と書けるかどうかは会社の判断で、代行は情報の整理と案内を担います。エラベルで担当者を選ぶ企業には、「転勤の型と拠点の住居の情報を、求人票に添えていますか」を、私たちから先に聞いています。添えていなければ、経路を増やす前に情報の整理です。

## 時期の課題：案件が決まってから募集する

| 状態 | 直し方 |
|---|---|
| 再エネの案件が決まってから募集を始める | 案件の見込みから逆算し、開発・建設・運用保守の職種ごとに通年で母集団を持つ |
| 通年の母集団が無い | 要件に合う候補者と接点を持ち、記録し、定期に連絡する |
| 案件が終わると余る | 開発から運用保守へ、職種をまたいで乗せられる要件の設計。人数の計画と案件の見込みを同じ表に |

人数の計画は[要員計画と採用計画がつながっていない](/media/rpo-jinin-keikaku/)に、過去の応募者との接点の持ち方は[過去の応募者を活かせていない](/media/rpo-talent-pool-katsuyou/)に書いています。

## 営業の課題：速さと受け入れ

| 状態 | 直し方 |
|---|---|
| 応募への返事が数日後 | 一次対応を外に出す。返事は翌営業日中 |
| 目標が最初から高く、離れる | 最初の三か月の目標を抑え、教える人と同行を決める |
| 商品と料金の型の実態が求人票に無い | 「扱う商品、料金の型の説明の難しさ、顧客の層」の実態を書く |
| 面接の枠が取れない | 責任者の枠を週に一つ先に預かる |

営業の離職の分け方は[営業がすぐ辞めてしまう](/media/rpo-eigyo-teichaku/)に書いています。

## 外に出せる部分と社内で直す部分

| 課題 | 外に出せる部分 | 社内で直す部分 |
|---|---|---|
| 要件 | 言い換えの作業、隣接に届く経路の運用、書類の照合 | 資格と保安の整理（会社と専門家）、必須と歓迎の判断、取得の支援の決定 |
| 勤務地 | 情報を一枚にする作業、案内 | 転勤の型の決定、住居と手当の用意 |
| 中途の型と日数 | 求人票の作り直し、経路の運用、日程の運用、段ごとの記録 | 観点の決定、決裁の日程の決め方、枠の形を変えて出す |
| 時期 | 通年の母集団の運用、定期の連絡、記録 | 案件の見込みの共有、人数の計画 |
| 営業 | 一次対応、日程、記録 | 受け入れの体制（最初の三か月の目標、教える人、同行）、実態の書き出し |

どの課題にも社内で直す部分があります。機能する条件と機能しない条件は[エネルギー業界で採用代行が機能する条件・機能しない条件](/media/rpo-energy-jirei/)に書いています。

## まとめ

- 「採れない」には**要件・勤務地・中途の型と日数・時期・営業**の五つが混ざっている
- **記録で一つに特定してから直す**。最初は要件の書き方と職種と経路ごとの応募
- 最も多い詰まりは**要件**で、「有資格者は同業にしかいない」で市場のせいにされている。設備と範囲と規模で言い換え、隣接に出す
- **資格・保安は会社と専門家**。個別の判断は専門家にご確認ください
- **勤務地と転勤の型と住居の情報を一枚にして添える**
- 中途の型を新卒と分け、**待ちの日数を消す**
- 時期は**案件の見込みから逆算し、通年で母集団を持つ**。営業は**速さと受け入れ**

## よくある質問

### 保安の体制上、資格は全員に必須で、緩められません

必須の範囲を緩めるかどうかは、会社と専門家が保安の体制と配置で整理する判断で、個別の判断は専門家にご確認ください。整理の結果として全員に必須であっても、要件の言い換え（設備と範囲と規模）と、隣接に届く経路と、勤務地の情報の整理は、必須の範囲に触れずにできます。有資格者の中で「同業以外にいる人」（プラント、ビルの設備、建設の電気）に届くかどうかが、母集団の広さを決めます。

### 転勤は会社の制度で、変えられません

制度を変えなくても、情報の整理はできます。転勤の型（地域の中か全国か、期間の目安、希望の扱い）、住居と手当の考え方、家族の情報を一枚にして添える。「転勤あり」の一言と、型と目安が書いてある一枚では、応募の前で止まる人の数が違います。制度そのものを見直す判断は、応募の前で止まった理由と離職の理由の記録を材料に、会社が決めます。

### 承認の段が多いのは本社の手順で、現場では変えられません

段の数は変えず、段の間の待ちを消します。決裁の日程を月の初めに決める、確認に回す書類を一次面接の前に揃える、面接官の枠を先に預ける、同じ日に二段を組む。どれも現場と人事の運用で、本社の手順に触れません。段ごとの日数を記録して「待ちの日数」を本社に見せると、手順の見直しの材料にもなります。承認の段の逆算は[金融業界の採用代行](/media/rpo-kinyu-rpo/)に書いています。
