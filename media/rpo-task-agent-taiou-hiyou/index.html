人材紹介会社を使った採用では、紹介会社とのやりとりにかなりの時間がかかります。求人の中身を説明し、推薦された候補者の書類を確認して返答し、選考の結果を伝え、内定の条件を調整する。契約する紹介会社が増えるほど、このやりとりは増えていきます。結論から書くと、紹介会社との折衝の外注は、やりとりを工程に分けて工数のかかり方を確かめ、契約する紹介会社の数と、推薦への返答の速さを前提に見積もると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。紹介手数料は、紹介会社ごとに決まりに沿って定められています。

紹介会社とのやりとりを工程に分ける

紹介会社とのやりとりは、次の工程に分けられます。

工程中身工数のかかり方
求人の説明紹介会社の担当者に、求人の中身や求める人物像を説明する紹介会社の数に比例して増える
推薦への返答推薦された候補者の書類を確認し、選考に進めるかを返答する推薦の数に比例して増える
選考の連絡面接の日程調整、結果の連絡、評価の共有選考に進んだ人数に比例して増える
条件の調整内定の条件を紹介会社を通じて調整する内定の数に比例して増える
関係の維持定期的な情報共有、紹介会社の見直し一定の頻度で発生する

この表のうち、工数が大きくなりやすいのは二つ目の「推薦への返答」です。推薦が多いのに返答が遅れると、紹介会社は自社への推薦の優先順位を下げ、良い候補者を他社に回すようになります。返答の速さは、紹介会社から良い推薦を受け続けるための大切な要素です。詳しい切り分けは人材紹介会社との折衝は代行に出せるかで書いています。

この記事の課題を、外部の支援で補うなら。記事内で、依頼できる業務と相談時の確認事項を紹介しています。

紹介会社の数が工数を左右する

紹介会社とのやりとりの工数は、契約する紹介会社の数で大きく変わります。紹介会社を増やせば推薦の数は増えますが、求人の説明や関係の維持の工数も増え、一社ごとの関係は薄くなりがちです。

外部に頼む前に、今契約している紹介会社を見直してください。推薦の数、選考の通過率、採用の実績を紹介会社ごとに並べると、成果を出している紹介会社と、そうでない紹介会社が分かります。成果の出ている紹介会社に絞り、その会社との関係を深めるほうが、工数を抑えながら採用の結果を上げられることがあります。

紹介会社の手数料については、職業安定法第32条の3が、有料職業紹介事業者が受け取れる手数料を、厚生労働省令で定めるものか、あらかじめ届け出た手数料表に基づくものに限っています。また第32条の16第3項は、紹介により就職した者の数や、手数料に関する事項などについて情報の提供を行わなければならないとしています。厚生労働省と都道府県労働局のリーフレットでは、「人材サービス総合サイト」で職業紹介事業者の紹介手数料の実績や、紹介した人の6か月以内の離職者数、返戻金制度の有無などを確認できると案内されています。紹介会社を見直すときは、こうした公開情報もあわせて確かめてください。

エラベルの見解

紹介会社との折衝の外注で多いのは、推薦への返答を外部に任せた結果、社内の評価の基準が伝わらず、合わない人が選考に進むケースです。外部の担当者は書類を確認できますが、自社の現場が何を重視しているかを理解していないと、判断がずれます。

外部に推薦への返答を任せるなら、書類選考の基準を言葉にして共有し、最初のうちは外部の判断と社内の判断を突き合わせて、ずれを直してください。同じ料金・同じ業務範囲でも、社内の基準を理解しようとする担当者かどうかで、選考の質が変わります。

料金の形と工数の見積もり方

紹介会社との折衝を外部に頼むときの料金の形は、月額固定、作業の量に応じた支払い、両者の組み合わせなどがあります。工数を見積もるときは、次の要素を確かめてください。

  1. 契約している紹介会社の数
  2. 月の推薦の数
  3. 選考に進む人数と、内定の数
  4. 条件の調整まで含むか：内定の条件の交渉を外部に任せるか、社内で行うか

条件の調整は、会社の給与体系や他の社員とのバランスに関わるため、最終的な判断は社内に残す必要があります。外部は、紹介会社との連絡の窓口を担う形が一般的です。紹介会社とのやりとりの進め方は人材紹介会社との折衝の進め方で書いています。

品質の見方

紹介会社との折衝の品質は、次の点で確かめられます。

  • 推薦への返答の速さ：推薦を受けてから返答するまでの日数
  • 紹介会社ごとの成果の見える化：推薦の数、通過率、採用の実績が紹介会社ごとに記録されているか
  • 評価の共有：不合格の理由が紹介会社に具体的に伝わり、次の推薦の質が上がっているか

料金の形は、上で挙げたほかに、採用が決まったときに支払う形もあります。

エラベルの見解

紹介会社との関係で、もう一つ考えてほしいのは、不合格の理由を具体的に伝えることです。「総合的に判断して」とだけ伝えていると、紹介会社は次にどんな人を推薦すればよいか分からず、合わない推薦が続きます。

不合格の理由を、求める経験とのずれ、志向の違いなど、具体的に伝えてください。理由が具体的に伝わる会社には、紹介会社も合う候補者を選んで推薦するようになります。外部に折衝を任せる場合も、この理由の伝え方を一緒に決めておくと、推薦の質が上がります。

よくある質問

人材紹介会社との折衝を外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。契約している紹介会社の数と推薦の数を伝えたうえで見積もりを取り、範囲をそろえて比べてください。

紹介会社との手数料の交渉も外部に任せられますか

連絡の窓口を外部が担うことはできますが、手数料や契約の条件の最終判断は、社内で行う必要があります。紹介会社の手数料表や返戻金の規定を確認し、契約の内容は社内で判断してください。

紹介会社は何社と契約するのがよいですか

一律の正解はありません。職種や採用の人数によって変わります。紹介会社ごとに推薦の数と通過率、採用の実績を記録し、成果の出ている紹介会社との関係を深める形で、数を見直していくのが現実的です。
