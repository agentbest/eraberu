はじめて採用を担当することになった。何から手をつければよいか分からないという段階で、まず押さえておきたいことを整理します。採用は工程の集まりで、それぞれに役割があります。全体像が見えると、いま何をすべきかも決まります。

採用の工程

採用という言葉のなかに、性質の違う作業が入っています。

工程中身
要件定義どんな人を、なぜ、いつまでに、いくらで採るか
採用計画職種ごとの人数、経路、予算、スケジュール
母集団形成媒体への掲載、スカウト、紹介会社への依頼
応募対応書類の受付、一次連絡、日程調整
選考書類選考、面接、評価
内定・入社条件の提示、内定者のフォロー、入社手続き
振り返り数値の集計、施策の見直し

この七つのうち、時間を使うのは三番目と四番目です。そして、結果を左右するのは一番目です。

要件が固まっていないまま母集団形成に進むと、来る候補者が毎回変わります。まず一番目を固めるのが順番になります。

最初にやること

一.現状を把握する

  • どの職種を、何人、いつまでに採るか
  • 過去の応募数、採用数
  • 使っている媒体、契約している紹介会社
  • 選考のフロー（何回面接があり、誰が出るか）

二.要件を一枚にまとめる

  • 必須と歓迎を分ける
  • 落とす理由を三つ書く
  • なぜその条件なのかを書く

三.現場と話す

  • どんな人が活躍しているか
  • 辞めた人はなぜ辞めたか
  • 面接で意見が割れるのはどんな候補者か

四.判断の流れを確認する

  • 書類の合否は誰が決めるか
  • 面接官は誰か、日程はどう確保するか
  • 条件は誰が決めるか

この四つを最初にやってください。ここが分からないまま運用を始めると、都度確認することになります。

いまの体制で何が足りないのか、一緒に洗い出します

エラベルの見解

最初にやることを一つだけ挙げるなら、「落とす理由を三つ書く」です。ここから始めると、採用の実務が動き出します。

「どんな人を採りたいか」を聞くと、たいてい抽象的な答えが返ってきます。主体性がある、コミュニケーション力が高い、成長意欲がある。どの会社でも同じ言葉が出ます。

一方、「どういう人は見送りますか」と聞くと、具体的になります。「この経験がないと厳しい」「この規模の環境から来ると合わない」「この期間で転職を繰り返している場合は慎重に見る」。

落とす基準のほうが、要件の輪郭をはっきりさせます。

そして、この三つが書けると、次の作業がすべて楽になります。検索条件を作るときの基準になり、書類を見るときの判断軸になり、代行に依頼するときの説明になる。

書けない場合は、現場に聞いてください。過去に見送った候補者について、なぜ見送ったかを聞く。実例から抽出すると書けます。

採用の実務は、この一枚から始まります。

よくある誤解

「良い人を採る」が目標になる。良い人の定義が曖昧だと、判断が分かれます。自社で活躍する人という定義に置き換えてください。

応募数を増やせば採用できる。要件に合わない応募が増えても、選考の手間が増えるだけです。質と量は分けて考えます。

面接で見極められる。短い時間で分かることには限りがあります。書類の段階と、面接で見る点を分けてください。

採用は人事の仕事。要件は現場が持ち、面接も現場が行います。人事だけでは進みません。

採れないのは母集団の問題。要件が厳しい、条件が市場と合っていない、判断が遅い。原因は工程のどこかにあります。切り分けが先です。

この五つは、実務を始めると自然に分かってきます。ただ、最初に知っておくと回り道が減ります。

優先順位

時間が限られている場合、何を優先するか。

一.要件の言語化。ここが固まらないと、何をしても結果が安定しません。

二.判断の速さ。書類の合否、面接の候補日。遅れると候補者は他社に流れます。

三.候補者への対応。連絡の速さと丁寧さ。放置は辞退の理由になります。

四.母集団の設計。どの経路で、どんな層に。

五.振り返り。数字を見て、次を決める。

一番目と二番目が最優先です。この二つが整っていれば、他が多少粗くても採用は進みます。

逆に、母集団を増やすことに時間を使っても、要件が曖昧で判断が遅ければ結果は出ません。

数字の見方

工程ごとに並べます。

  • 送信件数、応募件数
  • 書類の通過件数と通過率
  • 面接の実施件数と通過率
  • 内定件数、承諾件数

そして、上から順に見て、どこで落ちているかを特定します。

あわせて、時間の数字も見ます。応募から一次連絡までの日数、書類の合否までの日数、面接から次の面接までの日数。遅れている工程が分かります。

この二つを毎月見る習慣をつけてください。数字が動いたときに、原因を追えるようになります。

外部の使い方

採用の実務をすべて自分でやる必要はありません。

量のある工程は外に出せます。日程調整、応募者への連絡、スカウトの送信。判断が少なく、手順で伝えられる業務です。

判断は自社に残します。要件の決定、合否、条件の提示。

そして、外に出す前に要件を固めてください。要件が曖昧なまま外注すると、確認のやりとりが増えます。切り分けは採用代行とはにまとめています。

外部を使うことは、手を抜くことではありません。時間の使い先を、判断が要る工程に移すことです。

学び方

数字を見る習慣をつける。感覚ではなく、工程ごとの数字で判断する。

現場と話す。要件の背景、活躍している人、辞めた人。採用の判断の材料は、現場にあります。

書類を数多く見る。候補者を見る目は、数を見ないと養われません。

面接に同席する。判断の理由を聞くと、基準が分かります。

外部の視点を聞く。代行会社や紹介会社の担当者に、市場から見た自社の状況を聞く。社内では気づきにくい点が見えます。

この五つは、日常の業務の中でできます。特別な時間を取らなくても、意識するだけで学びになります。

担当者の経歴を見てから決められます

エラベルの見解

はじめて採用を担当する人に、一つだけ伝えるとしたら「候補者を待たせないこと」です。

採用の実務には多くの工程がありますが、候補者から見た体験のほとんどは待たされたかどうかで決まります。

応募したのに連絡が来ない。書類の結果が二週間分からない。面接の日程がなかなか決まらない。この間に、候補者の関心は他社に移ります。

そして、待たせる原因の多くは、社内の判断が滞っていることです。書類の合否を誰が決めるか決まっていない、面接官の日程が押さえられていない、条件の承認に時間がかかる。

だから、最初にやってほしいのは判断の流れを確認して、所要日数を決めることです。書類の合否は二営業日以内、候補日の提示は三営業日以内。

決めたら、守れる仕組みも作ります。誰が決めるか、不在のときは誰が代わるか。

この一つを整えるだけで、採用の結果は変わります。母集団を増やすことより、こちらのほうが早く効きます。

まとめ

  • 採用は七つの工程。時間を使うのは母集団形成と応募対応、結果を左右するのは要件定義
  • 最初にやるのは、現状の把握・要件を一枚にする・現場と話す・判断の流れの確認
  • 一つだけなら「落とす理由を三つ書く」。要件の輪郭がはっきりする
  • 誤解は、良い人が目標・応募数を増やす・面接で見極める・人事の仕事・母集団の問題
  • 優先順位は、要件の言語化 → 判断の速さ → 候補者への対応 → 母集団 → 振り返り
  • 数字は工程ごとに並べ、時間の数字も見る
  • 量のある工程は外に出せる。外に出す前に要件を固める
  • 一つだけ伝えるなら「候補者を待たせないこと」

よくある質問

何から手をつければよいですか

要件を一枚にまとめるところからです。必須と歓迎を分け、落とす理由を三つ書く。書けない部分は現場に聞いてください。この一枚があると、検索条件も、書類の判断も、外部への依頼も進めやすくなります。

応募が集まりません

工程を切り分けてください。母集団の量が出ていないのか、要件が厳しすぎるのか、条件が市場と合っていないのか。数字を見れば、どこで詰まっているかが分かります。応募数だけを増やそうとする前に、原因の特定が先です。

一人で全部はできません

量のある工程は外に出せます。日程調整、応募者への連絡、データの入力。判断が少なく、手順で伝えられる業務です。そのうえで、要件の言語化と判断の速さに時間を使ってください。この二つが整っていれば、採用は進みます。
