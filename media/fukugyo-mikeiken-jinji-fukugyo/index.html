人事副業 / 人事未経験

人事未経験が副業でできること｜経験の棚卸しと売り方｜人事の肩書きが無くても売れるのは「採用の工程のどこかに触れた経験」と「人事以外の職種で身についた、採用に転用できる技能」の二つ。「人事未経験」と名乗るのではなく、「〇〇の工程を、△△の職種の経験で」と範囲を絞って売る

人事の部署にいたことはない。ただ、営業で人と会い、部門で面接に出て、事務で応募者に連絡し、企画で文章を書いてきた。人事の副業に興味はあるが、「未経験」と名乗った時点で、依頼側に選ばれない気がする。何を、どう売ればよいのか。結論を先に書くと、人事の肩書きが無くても売れるのは、「採用の工程のどこかに触れた経験」と「人事以外の職種で身についた、採用に転用できる技能」の二つです。面接官として候補者を見た、応募者に連絡した、求人の文章を書いた、といった工程への接点と、営業の文面、企画の資料、事務の段取りといった転用できる技能を棚卸しし、「人事未経験」と名乗るのではなく、「〇〇の工程を、△△の職種の経験で」と範囲を絞って売ります。依頼側が頼むのは肩書きではなく、工程です。未経験の区分と受けられる業務は人事未経験でも受けられる仕事はあるかに、経験が浅いときの案件は経験が浅くても受けられる案件に、よくある質問は未経験でも受けられるかにまとめています。

この経歴の何が売れるか

人事の肩書きが無くても、売れるものは二つあります。棚卸しの表です。

売れるもの例どの工程で売れるか
採用の工程への接点（面接官）部門の面接官として候補者を見た。評価を書いた。合否の議論に出た面接官向けの準備資料、評価の観点の整理、面接の振り返りの型
採用の工程への接点（応募者の対応）応募者への連絡、日程調整、書類の受け取りを担当した応募者への一次連絡の文面、日程調整の運用、候補者の状態の管理
採用の工程への接点（求人の文章）部門の求人票の原稿を書いた、求人媒体の文面を直した求人票の改善、スカウト文面の作成
採用の工程への接点（受け入れ）新しく入った人の受け入れ、最初の期間の面談をした入社後の受け入れの型、最初の期間の面談の設計
転用できる技能（営業）初対面の相手に短い文面で返信をもらう。相手の関心を聞き出すスカウト文面、候補者との面談の設計、辞退の理由の聞き取り
転用できる技能（企画・マーケ）読み手を決めて文章を書く。数字で状態を見る。資料を作る求人票、採用の振り返りの資料、数字での報告
転用できる技能（事務・管理）段取り、記録、複数の相手との日程調整、ミスのない運用応募者の管理、日程調整、採用管理の仕組みの運用
転用できる技能（エンジニア・専門職）自分の職種の候補者が何を見ているか分かる。技術の言葉が分かる同じ職種の求人票とスカウト文面、面接官との橋渡し

売れるものの要点は、「人事の肩書きは無くても、採用の工程に触れていない人は少ない」ことです。面接官、応募者の対応、求人の文章、受け入れのどれかに、部門の立場で関わった経験があれば、それは採用の工程の経験です。「人事ではなかった」と括らず、工程で棚卸しします。転用できる技能は、工程と組み合わせて売ります。営業の文面の技能は、スカウト文面の工程で売れます。棚卸しの仕方は副業用の職務経歴書に、隣の経験ごとの売れる業務は人事未経験でも受けられる仕事はあるかに書いています。

売りにくい点とその扱い

人事未経験で売りにくい点は三つあり、それぞれ扱い方があります。

売りにくい点依頼側の懸念扱い方
判断の経験が無い「採用の可否や条件の判断を任せられない」判断を任される工程を売らない。判断は依頼側が持ち、自分は工程の中の作業と材料を担う、と最初から線を引く
人事の用語と仕組みを知らない「話が通じないのでは」主要な用語と工程の流れを、事前に一通り学ぶ。分からない用語は、その場で聞く。知ったふりをしない
信用の根拠が無い「人事の実績が無いのに、なぜ頼めるのか」肩書きではなく、工程の実績で示す。「部門の面接官として〇年、評価の観点を整理した」「営業で初対面の相手に返信をもらう文面を書いてきた」

扱い方の要点は、「判断を任される工程を売らない」ことです。人事未経験で最も崩れるのは、「採用の可否を見てほしい」「条件を決めてほしい」という判断の依頼を受けたときです。判断の経験が無い状態で判断を引き受けると、依頼側の採用を誤らせ、信用を失います。「判断は御社が。私は判断の材料と、工程の作業を担います」と、最初から線を引いて受けます。線の引き方は業務範囲を書面で固めるに、用語の学び方は学び直しの進め方に、実績の示し方は実績の示し方に整理しています。

肩書きではなく工程で経験を示し、判断は依頼側に置いて受けている担当者は、人事未経験でも依頼側から選ばれています。範囲と条件を登録しておいてください

エラベルの見解

担当する側から見ると、人事未経験で副業を始めて続いている人と、最初の案件が取れない人の差は、経験の有無ではなく、「人事未経験」と名乗るか、「〇〇の工程を△△の経験で」と名乗るかです。取れない人は、プロフィールに「人事は未経験ですが」と最初に書き、依頼側は「未経験の人に頼む理由が無い」と感じています。続いている人は、「部門の面接官として、評価の観点を整理し、面接官向けの準備資料を作ってきた」と工程で書き、依頼側は「その工程を頼める」と判断しています。

見ていて差がつくのは、判断を頼まれたときに、断って材料に変えているかです。「この候補者、どう思いますか」と聞かれて、「良いと思います」と答える人は、判断を引き受けた形になり、外れたときに信用を失います。「評価の観点で見ると、〇〇は合っていて、△△は確認が要ります。判断は御社で」と、材料に変えて返す人は、判断の所在を守りながら役に立っています。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲を工程で絞り、判断の線を明確にしている担当者に、その工程を頼みたい依頼側がついています。人事未経験の副業は、肩書きではなく、工程と線で始まります。

案件の探し方

人事未経験から入りやすい案件と、探し方です。

入りやすい案件理由探し方
求人票の改善文章の技能で入れる。判断は依頼側が持てる「求人票を読み手の目線で直す」を範囲の一言に。自分の職種の求人票から
スカウト文面の作成営業や企画の文面の技能で入れる「初対面の相手に返信をもらう文面」を実績で示す
面接官向けの準備資料面接官の経験で入れる「面接官として困ったことと、その解決の型」を示す
応募者の一次対応と日程調整事務の段取りで入れる「複数の相手との調整をミスなく回してきた」を示す
自分の職種の採用の橋渡し職種の言葉が分かる「〇〇職の候補者が求人票のどこを見るか分かる」を示す
採用の数字の整理と報告企画やマーケの数字の技能で入れる「状態を数字で見て報告する」を示す

探し方の要点は、「自分の職種の採用から入る」ことです。営業なら営業職の採用、エンジニアならエンジニアの採用、事務なら事務職の採用。自分の職種なら、候補者が何を見ているか、求人票のどこが響くか、面接で何を聞かれると答えにくいかが分かり、人事の経験が無くても、依頼側にとって価値があります。自分の職種の採用で一件受け、丁寧に終えれば、次は他の職種にも広げられます。案件の探し方は案件の探し方に、避けるべき案件は人事未経験でも受けられる仕事はあるかに、始め方は人事の副業の始め方に書いています。

単価の目安

単価は、具体的な額ではなく、決まり方の構造で考えます。人事未経験で、単価に影響する要素です。

要素単価への影響考え方
工程の経験の有無工程の経験（面接官、応募者の対応など）があれば、その工程では未経験の扱いにならない工程で示し、肩書きで示さない
転用できる技能の強さ営業の文面、企画の資料など、技能が強ければ、その技能が要る工程では評価される技能の実績を、採用の工程に置き換えて示す
判断を含まない範囲判断を含まない範囲は、判断を含む範囲より単価は下がる最初は判断を含まない範囲で、実績を作ってから広げる
自分の職種の採用職種の理解は、その職種の採用では評価される自分の職種の採用は、他の職種より単価を下げない
最初の案件実績が無いので、最初は範囲を絞り、小さく受ける単価を下げるのではなく、範囲と時間を小さくする
契約の形時間で受けるか、成果物で受けるか最初は成果物（求人票一本、スカウト文面一式）で受けると、単価の議論が明確になる

単価の要点は、「単価を下げるのではなく、範囲と時間を小さくする」ことです。未経験だから安く、と単価を下げると、その単価が続きます。範囲を「求人票一本」「スカウト文面一式」と小さくし、時間も小さくして受ければ、月の総額は小さくても、時間あたりの単価は工程の単価で受けられます。実績ができたら、範囲を広げます。単価の構造は人事の副業単価の相場に、収入の期待は人事未経験でも受けられる仕事はあるかの収入の項に、実績の積み方は実績の積み上げ方に整理しています。

単価を下げずに範囲と時間を小さくして受け、実績を作ってから広げる担当者は、未経験からでも続けられます。範囲と条件を登録しておいてください

始める順番

人事未経験から副業を始める順番です。

順番内容
一、採用の工程への接点を全部書き出す面接官、応募者の対応、求人の文章、受け入れ。部門の立場での経験も
二、転用できる技能を、採用の工程に置き換える営業の文面→スカウト文面、企画の資料→振り返りの資料
三、自分の職種の採用を、最初の範囲にする候補者の目線が分かる職種から
四、判断を含まない範囲に絞る判断は依頼側。自分は材料と作業
五、主要な用語と工程の流れを一通り学ぶ知ったふりをしない準備
六、「人事未経験」ではなく、「〇〇の工程を△△の経験で」の一言を作るプロフィールと自己紹介に
七、登録先に、範囲を工程で登録する肩書きではなく工程
八、成果物で一件受け、丁寧に終え、実績を型で残す次の範囲を広げる材料に

順番の要点は、「六」の一言を、「人事未経験」を含まない形で作ることです。「人事は未経験ですが、営業の経験を活かして」ではなく、「営業で培った、初対面の相手に返信をもらう文面で、スカウト文面を作ります」と、工程と技能だけで言います。未経験という言葉は、依頼側の判断の材料にならず、懸念だけを生みます。自己紹介の型は自己紹介文のテンプレートに、プロフィールはプロフィールの書き方に書いています。

エラベルの見解

相談で最も多い思い込みは、「人事の肩書きが無いなら、まず人事に転職して経験を積んでから、副業を考えるべきだ」というものです。実際には、依頼側が頼むのは肩書きではなく工程で、部門の面接官や応募者の対応や求人の文章の経験があれば、その工程は頼めます。転職を待つ必要はなく、工程を棚卸しし、自分の職種の採用から、判断を含まない範囲で、小さく始められます。

順番として、採用の工程への接点を書き出し、転用できる技能を工程に置き換え、自分の職種の採用を最初の範囲にし、判断を含まない範囲に絞り、用語と工程を学び、「人事未経験」を含まない一言を作り、登録先に工程で登録し、成果物で一件受けて丁寧に終える。この順番で、人事未経験の副業は、「肩書きが無いから無理なもの」から「工程で売るもの」になります。エラベルでは、依頼側が担当者を選ぶ仕組みなので、範囲を工程で絞り、判断の線を明確にしている担当者に、その工程を頼みたい依頼側がついています。人事未経験の副業は、肩書きではなく、工程で始まります。

まとめ

  • 肩書きが無くても売れるのは採用の工程への接点（面接官・応募者の対応・求人の文章・受け入れ）と、転用できる技能（営業の文面・企画の資料・事務の段取り・職種の理解）
  • 「人事未経験」と名乗らず、「〇〇の工程を△△の経験で」と工程で名乗る。依頼側が頼むのは肩書きではなく工程
  • 売りにくい点は判断の経験・用語・信用。判断を任される工程は売らず、判断は依頼側に置いて材料と作業を担う
  • 案件は自分の職種の採用から。候補者の目線が分かることが、人事の経験が無くても価値になる
  • 単価は下げずに、範囲と時間を小さくする。成果物で受け、実績を作ってから広げる
  • 順番は工程の接点の棚卸し → 技能の置き換え → 自分の職種 → 判断を含まない範囲 → 用語 → 一言 → 登録 → 成果物で一件

よくある質問

面接官の経験はありますが、部門の立場で数回出ただけです。売れますか

売れます。「数回」でも、候補者を見て評価を書き、合否の議論に出た経験は、面接官の目線を持っているということです。「面接官として困ったこと」（評価の観点が揃っていない、質問が場当たりになる、他の面接官と見方が違う）を書き出し、その解決の型（評価の観点の一覧、質問の順番、振り返りの型）を作れば、面接官向けの準備資料の工程で売れます。回数より、困ったことと解決の型を持っているかです。示し方は実績の示し方に整理しています。

依頼側から「候補者の合否を判断してほしい」と言われました。受けてよいですか

判断の経験が無い状態で、合否の判断を引き受けることは避けます。「判断は御社で。私は評価の観点に沿って、確認できたことと確認が要ることを整理してお渡しします」と、材料に変えて返します。それでも判断を求められるなら、その案件は自分の範囲に合わない案件です。判断を引き受けて外れると、依頼側の採用を誤らせ、信用を失い、次の案件が取れなくなります。範囲の線は業務範囲を書面で固めるに、断り方は断り方に書いています。

人事の資格を取ってから始めた方がよいですか

資格は、依頼側が担当者を選ぶ理由にはなりにくく、資格の取得を待つ間に、工程の経験で始められる案件を逃します。資格より先に、工程の接点と転用できる技能を棚卸しし、自分の職種の採用で一件受ける方が、実績になります。資格は、続けながら、範囲を広げる段階で、必要なら取ります。資格の考え方は取っておくと役に立つ資格に整理しています。

人事の経験を、副業で活かす

稼働時間も単価もご自身で決められます。エラベルは企業とあなたをつなぐ窓口です。

あわせて読む

  • 中小企業診断士が副業でできること｜経験の棚卸しと売り方｜中小企業診断士の経験は「採用を事業と経営の数字の中に置いて設計する」工程で売れる。事業の計画と人員の計画の接続、採用の投資の判断、経営者への助言、補助や支援の制度の情報整理の四つ。「診断します」ではなく、「経営者が採用に投資する判断を、数字で整える」と売る
  • 人事コンサルタントが副業でできること｜経験の棚卸しと売り方｜人事コンサルタントの経験は「採用の課題を構造化し、打ち手を設計する」工程で売れる。ただし副業の依頼側が求めるのは提案書ではなく「手が動くところまで」。設計と実行を分けず、「設計し、最初の一巡を一緒に回す」形で売る。コンサルの型をそのまま持ち込むと、費用と工数で合わない
  • 育児からの復職が副業でできること｜経験の棚卸しと売り方｜育児で離れていた期間は「空白」ではなく、離れる前の人事の経験と、育児中に身についた段取りと時間の使い方を、「今の稼働の枠で何ができるか」に組み替えて売る。空白の説明より、枠と範囲の明示が先
  • 経営者・役員が副業でできること｜経験の棚卸しと売り方｜経営者・役員の経験は「採用を経営の判断として組み立てる」工程で売れる。採用の優先順位と予算の設計、経営者への助言、役員や幹部の採用の見極め、採用の仕組みの設計の四つ。「経営の経験を活かす」ではなく、「依頼側の経営者が判断できる形に整える」と売る
