一次面接を外注したときの費用と工数の目安｜評価の基準と「聞いてはいけないこと」を共有してから任せる

一次面接は、書類選考を通過した候補者と最初に向き合う面接です。応募が多い職種では、一次面接の件数が多くなり、現場の社員や人事の時間を大きく使います。そのため、一次面接を外部に頼みたいと考える会社もあります。外部に任せることはできますが、面接は候補者を評価する場であり、外部の面接官が自社の基準で判断できるようにする準備が欠かせません。結論から書くと、一次面接の外注は、評価の基準を共有する手間まで含めて費用と工数を見積もり、合否の判断は社内に残す形で、採用選考時に配慮すべき事項を外部の面接官にも守ってもらう仕組みをつくると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

一次面接を工程に分ける

一次面接は、次の工程に分けられます。

工程中身担い手
準備候補者の書類を読み、面接で確かめることを決める外部が担える
実施面接を行い、候補者の経験や考え方を聞く外部が担える
評価の記録評価の基準に沿って、候補者の評価と理由を記録する外部が担える
合否の判断評価の記録を見て、次の選考に進めるかを決める社内が担う

外部に面接の実施と評価の記録を任せても、合否の判断は社内に残してください。外部の評価をそのまま合否にすると、自社の基準とのずれに気づけません。外部の評価を参考に、社内で最終的に判断する形が安全です。詳しい切り分けは一次面接は代行に出せるかで書いています。

評価の基準を共有する手間

一次面接の外注で、最初に工数がかかるのが、評価の基準の共有です。外部の面接官が自社の基準で候補者を評価できるようにするには、次のものを用意する必要があります。

  1. 評価の項目：何を確かめるか（経験の中身、考え方、志向など）
  2. 項目ごとの基準：どの状態なら次に進めるか、どの状態なら見送るか
  3. 質問の例：項目を確かめるための質問
  4. 評価の記録の形：評価と理由をどう書くか

これらが社内でまだ言葉になっていない場合は、外部と一緒につくることになり、その分の工数がかかります。最初の数件は、外部の面接官と社内の面接官が同席するか、外部の評価と社内の評価を突き合わせて、基準のずれを直してください。

エラベルの見解

一次面接の外注で多いのは、外部の面接官の評価が甘すぎる、または厳しすぎるケースです。基準を言葉で共有しても、実際に候補者を前にすると、面接官によって受け止め方が違います。外部の面接官が通した人が二次面接で次々に落ちる、あるいは外部が見送った人の中に会ってみたかった人がいた、ということが起きます。

最初の数週間は、外部の評価の記録を社内で読み、ずれがあれば基準の言葉を直してください。同じ料金・同じ業務範囲でも、このすり合わせに時間をかけてくれる担当者かどうかで、一次面接の質は大きく変わります。

聞いてはいけないことを共有する

面接で尋ねる内容にも気をつける必要があります。東京労働局の案内では、採用選考にあたって、応募者の基本的人権を尊重すること、応募者の適性と能力に基づいた基準により行うことを基本的な考え方としています。そのうえで、本籍・出生地、家族（職業・続柄・健康・地位・学歴・収入・資産など）、住宅状況、生活環境・家庭環境、宗教、支持政党、人生観・生活信条、尊敬する人物、思想、労働組合や社会運動、購読新聞・雑誌・愛読書などに関することを、応募用紙に記載させたり面接で尋ねたりして把握することは、就職差別につながるおそれがあるとされています。

外部の面接官は、自社の社員ではないため、こうした決まりへの理解が人によって違うことがあります。外部に一次面接を頼むときは、配慮すべき事項を共有し、質問の例もこれらに触れない形で用意してください。

料金の形と品質の見方

一次面接を外部に頼むときの料金の形は、面接の件数ごと、月額固定、他の選考の業務とまとめて頼む形などがあります。品質は、次の点で確かめられます。

  • 評価の一致：外部の評価と、社内の二次面接の結果がどれだけ一致しているか
  • 評価の記録の質：評価の理由が具体的に書かれ、二次面接で使えるか
  • 候補者の印象：一次面接のあとの候補者の反応や、辞退の理由

一次面接の進め方は一次面接の進め方で書いています。料金の形は、上で挙げたほかに、採用が決まったときに支払う形もあります。エラベルでは、採用決定時に1名10万円（税別）という形で、担当者を選んで採用の実務を任せられる仕組みを用意しています。

エラベルの見解

一次面接で、もう一つ考えてほしいのは、面接は候補者が会社を見る場でもあることです。外部の面接官が一次面接を担うと、候補者は「この会社の人と話していない」と感じることがあります。自社の社員と話せないまま選考が進むと、候補者の志望の気持ちが高まりにくくなります。

一次面接を外部に任せる場合でも、面接の中で、自社の社員と話せる時期や、二次面接で誰と会うかを候補者に伝えてください。外部の面接官が自社の一員として候補者に向き合い、次の段階への期待をつくれるかが、選考全体の結果を左右します。

まとめ

  • 一次面接は準備・実施・評価の記録・合否の判断に分け、合否の判断は社内に残す
  • 最初に評価の基準の共有に工数がかかる。最初の数件は、外部と社内の評価を突き合わせる
  • 採用選考では、本人の適性と能力に関係のない事項（本籍・家族・思想など）を尋ねないよう、外部の面接官にも共有する
  • 品質は、外部の評価と二次面接の結果の一致、記録の質、候補者の印象で確かめる
  • 面接は候補者が会社を見る場でもある。社員と話せる機会を伝える

よくある質問

一次面接を外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。月の面接の件数と、評価の基準の共有にかかる準備を伝えたうえで見積もりを取り、範囲をそろえて比べてください。

外部の面接官に合否まで決めてもらってもよいですか

外部の評価を参考にすることはできますが、次の選考に進めるかの判断は社内で行うことをおすすめします。外部の評価をそのまま合否にすると、自社の基準とのずれに気づきにくくなります。

面接で聞いてはいけない質問はどこで確認できますか

都道府県労働局や厚生労働省の公正採用選考に関するページで、採用選考時に配慮すべき事項が案内されています。外部に面接を頼む場合は、これらの事項を外部の面接官にも共有してください。
