SNS採用の運用を外注したときの費用と工数の目安｜投稿の本数より「続けられる体制」に費用をかける

SNSを使った採用は、求人媒体に頼らずに会社のことを知ってもらう手段として、取り入れる会社が増えています。社員の日常や職場の雰囲気を発信し、会社に関心を持った人とつながることができます。ただ、SNSは一度投稿して終わりではなく、続けて発信し、反応に答えることで少しずつ関心が集まる仕組みです。始めたものの数か月で投稿が止まってしまう会社も少なくありません。結論から書くと、SNS採用の外注は、企画・投稿・やりとり・振り返りの工程に分け、続けられる体制に費用をかける考え方で見積もると、判断しやすくなります。

外部への費用は会社、料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、この記事では金額の相場は扱いません。

工程に分ける

SNS採用の運用は、次の工程に分けられます。

工程中身担い手
企画どのSNSで、誰に、何を発信するかを決める。投稿の計画をつくる外部が案を出せる。方向は社内が決める
素材の用意社員の写真や話、職場の様子などの素材を集める社内の協力が要る
投稿の作成文章や画像、動画をつくって投稿する外部が担える。社内の確認が要る
やりとりコメントやメッセージに答える外部が一次対応を担える。採用の相談は社内につなぐ
振り返り反応の数、フォロワーの変化、応募への流れを見る外部が集計できる。方針は社内が決める

外部に頼むと、投稿の作成と振り返りの手間は大きく減ります。一方で、素材の用意には社員の協力が必要です。SNSで関心を集めるのは、会社の公式な発表より、実際に働く人の姿です。社員が登場する投稿をどれだけ用意できるかが、運用の質を左右します。詳しい切り分けはSNS採用の運用は代行に出せるかで書いています。

続けることに工数がかかる

SNS採用の工数で大きいのは、続けることです。投稿の本数を多く約束する見積もりよりも、無理なく続けられる頻度で、社員の素材を集め続ける体制をつくるほうが、長い目で見て成果につながります。

見積もりを取るときは、次の点を確かめてください。

  1. 投稿の頻度とSNSの数：どのSNSに、どのくらいの頻度で投稿するか
  2. 素材の集め方：社員の写真や話を、誰がどう集めるか
  3. やりとりの範囲：コメントやメッセージへの対応を、どこまで外部が担うか
  4. 確認の流れ：投稿を公開する前に、誰が確認するか

SNSの数を増やすと、それぞれに合わせた投稿の作成とやりとりが必要になり、工数が増えます。まずは自社の候補者がよく使うSNSに絞って始めるほうが、続けやすくなります。

エラベルの見解

SNS採用の外注で多いのは、外部が投稿をつくり続けているのに、社員の顔が見えないケースです。会社の紹介や求人の告知ばかりが並び、実際に働く人の姿がほとんど出てこない。これでは、求人媒体と同じ情報をSNSに流しているだけになり、関心は集まりにくくなります。

外部に頼むなら、社員の素材をどう集めるかを一緒に設計してください。月に一度、社員に短い質問に答えてもらう、職場の写真を撮る日を決める、といった仕組みがあれば、外部はそれをもとに投稿をつくれます。同じ料金・同じ業務範囲でも、社員の協力を引き出す仕組みまで考えてくれる担当者かどうかで、SNSの価値が変わります。

投稿の内容で気をつけること

SNSで仕事の内容や働き方、募集の情報に触れる場合は、内容の正確さに気をつけてください。職業安定法第5条の4は、労働者の募集を行う者などが、広告等により労働者の募集に関する情報を提供するときは、虚偽の表示または誤解を生じさせる表示をしてはならず、正確かつ最新の内容に保たなければならないと定めています。

SNSは気軽に投稿できる分、一部の社員の働き方を会社全体のことのように見せてしまったり、募集を終えた求人の告知が残ったりしやすい場です。また、社員が登場する投稿は、本人の了解を得てから公開し、退職した社員の投稿をどう扱うかも決めておいてください。SNS採用の進め方はSNS採用の運用の進め方で書いています。

料金の形と成果の確かめ方

SNS採用の運用を外部に頼むときの料金の形は、月額固定、投稿の本数ごと、広告の運用とまとめた形などがあります。エラベルでは、採用決定時に1名10万円（税別）という形で、担当者を選んで採用の実務を任せられる仕組みを用意しています。

成果は、フォロワーの数や反応の数だけでなく、次の点で確かめてください。

  • 応募への流れ：SNSから採用サイトや求人に来た人の数、応募した人の数
  • 面接での反応：SNSを見て会社に関心を持ったと話す候補者がいるか
  • 候補者の理解：SNSを見た候補者が、会社の雰囲気を理解したうえで選考に来ているか

エラベルの見解

SNS採用で、もう一つ考えてほしいのは、すぐに成果を求めすぎないことです。SNSで関心が集まるまでには時間がかかります。始めて数か月で応募が増えないからといってやめてしまうと、それまでの投稿が無駄になります。

外部に頼むときは、最初の数か月は応募数ではなく、投稿を続けられているか、社員の素材が集まっているか、反応が少しずつ増えているかを見てください。続けられる体制ができていれば、成果は後から付いてきます。

まとめ

  • SNS採用は企画・素材の用意・投稿の作成・やりとり・振り返りに分ける
  • 関心を集めるのは実際に働く人の姿。社員の素材を集め続ける仕組みが運用の質を左右する
  • 工数で大きいのは続けること。SNSの数を絞り、無理なく続けられる頻度で始める
  • 募集の情報は正確かつ最新に保ち、社員の投稿は本人の了解を得る
  • 最初は応募数より、続けられているか、反応が増えているかで確かめる

よくある質問

SNS採用の運用を外注したときの費用の相場はいくらですか

会社や料金の形、依頼する範囲によって大きく異なり、公的な統計もないため、一律の相場はお伝えできません。SNSの数、投稿の頻度、やりとりの範囲をそろえて見積もりを取り、比べてください。

どのSNSから始めればよいですか

採用したい候補者がよく使うSNSから始めるのが基本です。職種や年代によって使われるSNSが違うため、候補者の層を考えて選んでください。複数のSNSを同時に始めるより、一つに絞って続けるほうが成果につながりやすくなります。

コメントやメッセージへの対応も外部に任せられますか

一次対応は任せられますが、採用に関する具体的な相談や、候補者の個人的な質問は、社内につなぐ流れを決めておいてください。外部が答えてよい範囲と、社内に回す基準を最初に決めておくと安心です。
